# 40. flex-grow, flex-shrink & flex-basis

## Penjelasan

Tiga properti flex item yang mengontrol **ukuran**:

| Properti | Fungsi | Default |
|----------|--------|---------|
| `flex-grow` | Kemampuan item **tumbuh** mengisi ruang kosong | 0 |
| `flex-shrink` | Kemampuan item **menyusut** jika tidak cukup ruang | 1 |
| `flex-basis` | Ukuran **dasar** sebelum distribusi | auto |

Shorthand: `flex: grow shrink basis`

```css
.item { flex: 1; }           /* grow: 1, shrink: 1, basis: 0 */
.item { flex: auto; }         /* grow: 1, shrink: 1, basis: auto */
.item { flex: none; }         /* grow: 0, shrink: 0, basis: auto */
.sidebar { flex: 0 0 250px; } /* fixed 250px, tidak grow/shrink */
```

## Fungsi

- Membuat layout yang fleksibel — item membesar/mengecil sesuai ruang
- Layout sidebar + konten utama
- Card row dengan lebar yang bervariasi

## Cara Pengimplementasian

```css
/* Layout sidebar + konten */
.page-layout {
  display: flex;
  gap: var(--space-6);
}

.sidebar {
  flex: 0 0 250px;  /* tetap 250px, tidak berubah */
}

.main-content {
  flex: 1;          /* mengisi sisa ruang */
}

/* Card row sama lebar */
.card-row {
  display: flex;
  gap: var(--space-6);
}

.card {
  flex: 1;          /* semua card sama lebar */
  display: flex;
  flex-direction: column;
}

/* Featured card lebih besar */
.card.featured {
  flex: 2;          /* 2x lebih lebar dari card biasa */
}

/* Item yang tidak boleh mengecil */
.logo {
  flex: none;       /* ukuran sesuai konten, tidak berubah */
}

/* Basis berbeda untuk distribusi proporsional */
.item-a { flex: 1; }  /* 1 bagian */
.item-b { flex: 2; }  /* 2 bagian — 2x lebih lebar dari A */
```

## Analogi

Seperti **kue yang dibagi ke anak-anak**:
- **flex-grow** = seberapa besar anak **ingin tambah kue**. Anak A grow: 1 (minta 1 potong tambahan), Anak B grow: 2 (minta 2 potong)
- **flex-shrink** = jika kue tidak cukup, seberapa rela anak **mengurangi porsinya**. Anak A shrink: 1 (rela dikit), Anak B shrink: 0 (ngotot porsi penuh)
- **flex-basis** = jatah **dasar** setiap anak sebelum bagi tambahan/kekurangan
- **flex: 1** = "Semua anak dapat bagian yang sama"
- **flex: none** = "Anak ini porsi tetap, tidak mau tambah atau kurang"

## Dipakai Untuk Apa

- Sidebar fixed + konten fleksibel
- Card row dengan tinggi sama
- Navigasi dengan item proporsional
- Layout dashboard

## Kesalahan Umum

- **flex: 1 vs width: 100%**: flex: 1 membagi ruang antar item, width: 100% membuat item penuh — berbeda
- **flex-basis: 0 vs auto**: basis 0 = semua mulai dari 0, bagi rata. Basis auto = mulai dari ukuran konten
- **Lupa flex-shrink: 0**: item bisa menyusut di luar dugaan — set `flex-shrink: 0` jika ingin ukuran tetap
- **flex-grow di semua item**: jika semua grow: 1, ruang dibagi rata — tidak ada yang "lebih"

## Hubungan dengan Materi Sebelumnya

Poin 37-39: distribusi dan alignment flexbox. Tapi **ukuran** item belum terkontrol. **flex-grow, flex-shrink, flex-basis** adalah properti flex item yang menentukan seberapa fleksibel ukuran masing-masing item.

## Soal Latihan

### Soal 1
Tulis CSS untuk sidebar 250px tetap dan konten utama mengisi sisa ruang.

**Jawaban:**
```css
.sidebar { flex: 0 0 250px; }
.main { flex: 1; }
```

### Soal 2
Apa perbedaan `flex: 1` dan `flex: auto`?

**Jawaban:**
`flex: 1` = grow 1, shrink 1, basis 0 — semua mulai dari 0, ruang dibagi rata. `flex: auto` = grow 1, shrink 1, basis auto — mulai dari ukuran konten, lalu bagi ruang sisanya.

### Soal 3
Kapan menggunakan `flex: none`?

**Jawaban:**
Ketika item tidak boleh berubah ukuran — misal logo, icon, avatar. Ukuran tetap sesuai konten, tidak tumbuh atau menyusut.
