# 49. z-index & Stacking Context — Siapa di Atas Siapa

## Penjelasan

`z-index` menentukan urutan tumpukan elemen — siapa yang di atas siapa. Hanya bekerja pada elemen dengan `position` (bukan static).

```css
:root {
  --z-behind:   -1;
  --z-normal:    0;
  --z-elevated:  10;
  --z-sticky:    100;
  --z-overlay:   200;
  --z-modal:     300;
  --z-toast:     400;
}

header { z-index: var(--z-sticky); }
```

**Stacking context**: "ruang" tersendiri untuk tumpukan elemen. Elemen dalam stacking context yang berbeda ditumpuk berdasarkan context-nya, bukan z-index masing-masing.

## Fungsi

- Mengontrol urutan tumpukan — header di atas konten, modal di atas overlay
- Mencegah elemen bertumpuk tidak terduga

## Cara Pengimplementasian

```css
/* Z-index scale — konsisten */
:root {
  --z-behind:   -1;  /* background / dekorasi */
  --z-normal:    0;  /* konten normal */
  --z-elevated:  10; /* card hover, dropdown */
  --z-sticky:    100; /* sticky header */
  --z-overlay:   200; /* overlay / backdrop */
  --z-modal:     300; /* modal dialog */
  --z-toast:     400; /* notifikasi toast */
  --z-tooltip:   500; /* tooltip */
}

/* Header — di atas konten */
header {
  position: fixed;
  z-index: var(--z-sticky);
}

/* Modal backdrop */
.modal-backdrop {
  position: fixed;
  z-index: var(--z-overlay);
  inset: 0;
  background-color: rgba(0, 0, 0, 0.5);
}

/* Modal */
.modal {
  position: fixed;
  z-index: var(--z-modal);
  /* di atas backdrop */
}

/* Card hover — naik */
.project-card:hover {
  z-index: var(--z-elevated);
}

/* Stacking context tercipta dari: */
/* 1. position + z-index bukan auto */
/* 2. opacity < 1 */
/* 3. transform, filter, backdrop-filter */
/* 4. overflow: hidden/seroll + position */
```

## Analogi

Seperti **lemari bertingkat**:
- z-index = nomor laci. Laci 1 (z-index rendah) di bawah, laci 5 (z-index tinggi) di atas
- Stacking context = **lemari yang berbeda**. Laci 5 di Lemari A bisa di bawah Laci 1 di Lemari B — karena lemari berbeda, tidak bisa dibandingkan langsung

Masalah umum: "z-index: 9999 tidak menang!" Cek — apakah elemenmu dalam stacking context yang berbeda? Mungkin elemen lawan ada di context yang lebih tinggi.

## Dipakai Untuk Apa

- Header di atas konten
- Modal di atas backdrop
- Dropdown di atas konten
- Tooltip di atas semuanya
- Card hover naik ke atas

## Kesalahan Umum

- **z-index tanpa position**: tidak berfungsi — elemen harus punya position (relatif, absolute, fixed, sticky)
- **z-index: 9999 tanpa sistem**: tidak konsisten, menabrak elemen lain
- **Stacking context tidak disadari**: `opacity: 0.99` atau `transform` membuat stacking context baru — z-index lokal jadi relatif dalam context itu
- **Lupa stacking context**: z-index 9999 tetap kalah jika di dalam context z-index 1

## Hubungan dengan Materi Sebelumnya

Poin 47-48: positioning menempatkan elemen di luar aliran. Tapi ketika dua positioned element bertumpuk — siapa di atas? **z-index**. Dan **stacking context** menjelaskan mengapa kadang z-index tinggi tetap kalah.

## Soal Latihan

### Soal 1
Tulis z-index scale dengan variable untuk header (100), modal (300), toast (400).

**Jawaban:**
```css
:root {
  --z-header: 100;
  --z-modal: 300;
  --z-toast: 400;
}
```

### Soal 2
Apa itu stacking context?

**Jawaban:**
Grouping elemen dalam "lapisan" yang independen. Elemen dalam stacking context A (z-index 10) tetap di bawah stacking context B (z-index 1) jika context B lebih tinggi. z-index hanya berarti dalam context yang sama.

### Soal 3
Sebutkan 3 hal yang bisa menciptakan stacking context baru.

**Jawaban:**
1. `position` + `z-index` (bukan auto)
2. `opacity` kurang dari 1
3. `transform`, `filter`, `backdrop-filter`
