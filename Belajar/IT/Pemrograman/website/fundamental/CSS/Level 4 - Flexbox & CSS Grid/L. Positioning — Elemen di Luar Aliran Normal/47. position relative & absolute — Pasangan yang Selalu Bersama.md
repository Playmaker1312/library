# 47. position: relative & absolute — Pasangan yang Selalu Bersama

## Penjelasan

- **`position: relative`**: elemen tetap di aliran normal, bisa di-offset dari posisi aslinya, dan menjadi **anchor** untuk absolute children
- **`position: absolute`**: elemen **keluar dari aliran normal**, posisi relatif ke ancestor terdekat yang punya `position` bukan `static`

```css
.card {
  position: relative;    /* anchor */
}

.card .badge {
  position: absolute;    /* posisi relatif ke .card */
  top: var(--space-3);
  right: var(--space-3);
}
```

## Fungsi

- **Relative**: anchor untuk absolute children, offset halus tanpa pengaruhi layout
- **Absolute**: menempatkan elemen di posisi spesifik tanpa pengaruhi elemen lain

## Cara Pengimplementasian

```css
/* Pola paling umum: parent relative + child absolute */
.project-card {
  position: relative;
}

.project-card .badge {
  position: absolute;
  top: var(--space-3);
  right: var(--space-3);
  background-color: var(--color-primary);
  color: white;
  padding: var(--space-1) var(--space-3);
  border-radius: var(--radius-full);
  font-size: var(--text-xs);
}

/* Overlay full elemen */
.card-overlay {
  position: absolute;
  inset: 0; /* top:0; right:0; bottom:0; left:0 */
  background-color: rgba(0, 0, 0, 0.5);
  opacity: 0;
  transition: opacity 0.3s ease;
}

.card:hover .card-overlay {
  opacity: 1;
}

/* Icon di dalam input */
.input-wrapper {
  position: relative;
}

.input-wrapper .icon {
  position: absolute;
  top: 50%;
  left: var(--space-3);
  transform: translateY(-50%);
}

.input-wrapper input {
  padding-left: var(--space-10);
}

/* Tooltip */
.tooltip-trigger {
  position: relative;
}

.tooltip-trigger .tooltip {
  position: absolute;
  bottom: 100%;
  left: 50%;
  transform: translateX(-50%);
  /* tooltip di atas trigger */
}
```

## Analogi

Seperti **paku payung di papan pengumuman**:
- **Relative** = paku payung yang ditancapkan di papan — posisinya tercatat, bisa digeser sedikit (top/left offset), dan paku lain bisa dikaitkan di situ
- **Absolute** = stiker yang ditempel relatif ke paku payung — "5cm di kanan atas paku A"

Absolute child "melekat" ke parent yang punya `position: relative`. Jika tidak ada parent dengan position, absolute akan relatif ke `<body>` — biasanya tidak diinginkan.

## Dipakai Untuk Apa

- Badge di sudut card
- Overlay gambar
- Icon di dalam input
- Tooltip
- Dropdown menu
- Tombol close di modal

## Kesalahan Umum

- **Absolute tanpa parent relative**: elemen loncat ke body/root — posisi tidak terduga
- **Lupa inset properties**: `top`, `right`, `bottom`, `left` tidak diset — elemen di posisi default (sama seperti static)
- **Absolute mengubah display**: absolute membuat elemen jadi block — width: 100% jadi 100% dari parent, bukan viewport
- **Absolute keluar dari aliran**: elemen di bawahnya naik mengisi ruang — perlu padding/margin kompensasi

## Hubungan dengan Materi Sebelumnya

Poin 36-46: flexbox dan grid mengatur layout dalam **aliran normal**. Tapi kadang kita butuh elemen di **luar aliran** — badge di sudut card, overlay, tooltip. **Positioning** adalah jawabannya. Relative + Absolute adalah pasangan paling umum.

## Soal Latihan

### Soal 1
Tulis CSS untuk menempatkan badge di sudut kanan atas card.

**Jawaban:**
```css
.card { position: relative; }
.card .badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
```

### Soal 2
Apa yang terjadi pada elemen dengan `position: absolute` jika tidak ada parent yang punya `position`?

**Jawaban:**
Elemen akan relatif ke **initial containing block** (biasanya `<body>` atau `<html>`) — posisi mungkin tidak sesuai yang diinginkan.

### Soal 3
Mengapa absolute child butuh parent yang position: relative?

**Jawaban:**
Absolute membutuhkan "containing block" — ancestor terdekat dengan `position` selain `static`. `relative` anchor yang paling umum karena tidak mengubah layout.
