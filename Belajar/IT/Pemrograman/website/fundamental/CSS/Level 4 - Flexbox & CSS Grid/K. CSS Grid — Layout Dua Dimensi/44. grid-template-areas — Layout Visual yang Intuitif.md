# 44. grid-template-areas — Layout Visual yang Intuitif

## Penjelasan

`grid-template-areas` memungkinkan kita mendefinisikan layout menggunakan **nama area** — seperti sketsa visual di CSS.

```css
.page-layout {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
  gap: var(--space-6);
}

header  { grid-area: header; }
aside   { grid-area: sidebar; }
main    { grid-area: main; }
footer  { grid-area: footer; }
```

## Fungsi

- Layout visual yang mudah dibaca — seperti ASCII art
- Mudah diubah — pindah area cukup edit grid-template-areas
- Responsif — tinggal ubah template di media query

## Cara Pengimplementasian

```css
/* Layout dasar */
.layout {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  gap: var(--space-6);
  min-height: 100vh;
}

/* Tempatkan elemen ke area */
.layout-header { grid-area: header; }
.layout-sidebar { grid-area: sidebar; }
.layout-main { grid-area: main; }
.layout-footer { grid-area: footer; }

/* Responsif — ubah layout di mobile */
@media (max-width: 768px) {
  .layout {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "sidebar"
      "main"
      "footer";
  }
}

/* Layout yang lebih kompleks */
.dashboard {
  display: grid;
  grid-template-columns: 250px 1fr 300px;
  grid-template-areas:
    "sidebar header  widget"
    "sidebar main    widget"
    "sidebar footer  footer";
  gap: var(--space-4);
}

/* Karakter . (titik) = area kosong */
.grid {
  grid-template-areas:
    "header header header"
    "main   main   ."
    "footer footer footer";
}
/* Titik = area kosong di kolom 3 baris 2 */
```

## Analogi

Seperti **denah rumah** yang digambar di kertas:
```
"header  header"
"sidebar main"
"footer  footer"
```

Ini adalah denah rumah: Ruang tamu (header) di lantai atas selebar rumah. Kamar (sidebar) di kiri. Ruang keluarga (main) di kanan. Teras (footer) di bawah selebar rumah.

Denah ini mudah dibaca dan diubah — tukang bangunan (browser) tinggal mengikuti gambar. Ingin pindah kamar? Ubah di denah, bukan bongkar tembok.

## Dipakai Untuk Apa

- Layout halaman: header, sidebar, main, footer
- Dashboard dengan widget
- Layout yang berubah di mobile (responsive)

## Kesalahan Umum

- **Nama area tidak konsisten**: harus sama persis antara `grid-template-areas` dan `grid-area`
- **Area tidak membentuk persegi panjang**: grid area harus persegi panjang — tidak boleh bentuk L
- **Jumlah kolom tidak sama per baris**: setiap baris di grid-template-areas harus punya jumlah kolom yang sama
- **Lupa titik untuk area kosong**: gunakan `.` (satu atau lebih) untuk sel kosong

## Hubungan dengan Materi Sebelumnya

Poin 42-43: grid dengan kolom dan responsive. Tapi menempatkan elemen ke grid lines bisa rumit. **grid-template-areas** menyederhanakan — kita gambar layout pakai string, lalu tempatkan elemen dengan `grid-area`. Ini adalah cara paling intuitif untuk layout halaman.

## Soal Latihan

### Soal 1
Tulis grid layout dengan header, sidebar kiri, main, footer.

**Jawaban:**
```css
.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
header { grid-area: header; }
aside { grid-area: sidebar; }
main { grid-area: main; }
footer { grid-area: footer; }
```

### Soal 2
Apa fungsi karakter `.` (titik) di grid-template-areas?

**Jawaban:**
Menandai area kosong — tidak ada elemen yang ditempatkan di sel tersebut.

### Soal 3
Bagaimana cara membuat layout grid-template-areas yang responsif?

**Jawaban:**
Ubah `grid-template-areas` di dalam media query — layout berubah secara keseluruhan dengan mengubah string template.
