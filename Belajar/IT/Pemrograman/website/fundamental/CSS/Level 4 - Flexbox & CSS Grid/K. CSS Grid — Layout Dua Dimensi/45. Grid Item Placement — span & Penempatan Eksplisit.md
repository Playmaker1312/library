# 45. Grid Item Placement — span & Penempatan Eksplisit

## Penjelasan

Item grid bisa ditempatkan secara eksplisit ke baris/kolom tertentu, atau membentang (span) beberapa kolom/baris.

```css
.item {
  grid-column: 1 / 3;      /* dari line 1 ke line 3 = span 2 kolom */
  grid-row: 1 / 2;          /* dari line 1 ke line 2 = 1 baris */
  
  /* Alternatif: */
  grid-column: span 2;      /* bentang 2 kolom */
  grid-row: span 1;
  
  /* Shorthand: grid-area */
  grid-area: 1 / 1 / 3 / 3; /* row-start / col-start / row-end / col-end */
}
```

## Fungsi

- Membuat item tertentu lebih besar dari yang lain (featured)
- Penempatan item di posisi grid tertentu tanpa mengubah HTML
- Layout magazine/newspaper dengan item ukuran bervariasi

## Cara Pengimplementasian

```css
/* Featured project — lebih besar */
.projects-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: var(--space-6);
}

.project-card:first-child {
  grid-column: span 2;   /* featured: 2 kolom */
  grid-row: span 2;      /* featured: 2 baris */
}

/* Penempatan spesifik */
.logo    { grid-column: 1 / 2; grid-row: 1; }
.nav     { grid-column: 2 / 4; grid-row: 1; }
.sidebar { grid-column: 1 / 2; grid-row: 2 / 4; }
.main    { grid-column: 2 / 4; grid-row: 2 / 3; }
.footer  { grid-column: 1 / 4; grid-row: 3; }

/* Dengan named grid lines */
.container {
  display: grid;
  grid-template-columns: [start] 1fr [middle] 2fr [end];
  grid-template-rows: [top] auto [bottom];
}

.header {
  grid-column: start / end;  /* dari start ke end */
}

/* Grid item order — ubah urutan visual tanpa HTML */
.item:first-child { order: 3; }
.item:nth-child(2) { order: 1; }
.item:last-child { order: 2; }
```

## Analogi

Seperti **meja restoran untuk grup besar**:
- Sebagian besar meja untuk 2-4 orang (normal span: 1)
- Meja sudut bisa digabung untuk 8 orang (span: 2) — featured
- Kamu bisa tentukan meja mana yang digabung tanpa harus pindahkan kursi (HTML tetap)
- Nomor meja (grid lines) dari 1, 2, 3... menentukan posisi setiap meja

## Dipakai Untuk Apa

- Featured project lebih besar di portofolio
- Artikel utama lebih lebar di blog
- Gambar hero membentang penuh
- Layout magazine

## Kesalahan Umum

- **Lupa grid line dimulai dari 1**: `grid-column: 1 / 3` = mulai line 1, berakhir line 3 (2 kolom)
- **Span vs line numbers**: `span 2` lebih mudah daripada `1 / 3` — terutama jika jumlah kolom berubah
- **Item tumpang tindih**: jika dua item pakai grid area yang sama — gunakan z-index
- **Order untuk aksesibilitas**: mengubah order visual tidak mengubah urutan HTML — keyboard navigation tetap ikut HTML

## Hubungan dengan Materi Sebelumnya

Poin 42-44: grid dengan semua item sama besar. Tapi **featured item** perlu lebih menonjol. **Grid item placement** memungkinkan item tertentu membentang beberapa kolom/baris — membuat grid lebih dinamis dan menarik.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat item pertama di grid membentang 2 kolom.

**Jawaban:**
```css
.item:first-child {
  grid-column: span 2;
}
```

### Soal 2
Apa perbedaan `grid-column: 1 / 3` dan `grid-column: span 2`?

**Jawaban:**
`grid-column: 1 / 3` — mulai dari grid line 1, berakhir di line 3 (pasti 2 kolom). `span 2` — bentang 2 kolom, posisi otomatis mengikuti alur grid.

### Soal 3
Apa bahaya penggunaan `order` di grid item?

**Jawaban:**
Order hanya mengubah urutan visual — urutan HTML (dan fokus keyboard) tetap asli. Ini bisa menyebabkan kebingungan aksesibilitas jika tidak hati-hati.
