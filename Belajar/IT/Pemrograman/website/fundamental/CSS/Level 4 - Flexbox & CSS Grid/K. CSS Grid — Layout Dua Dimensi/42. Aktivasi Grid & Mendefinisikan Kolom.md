# 42. Aktivasi Grid & Mendefinisikan Kolom

## Penjelasan

CSS Grid adalah model layout **dua dimensi** — mengatur baris DAN kolom secara bersamaan.

```css
.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 3 kolom sama lebar */
  /* atau */
  grid-template-columns: repeat(3, 1fr); /* 3 kolom sama lebar */
  
  gap: var(--space-6);
}
```

Unit `fr` (fraction): bagian dari ruang yang tersisa setelah item fixed.

```
grid-template-columns: 1fr 2fr 1fr;  → 25% | 50% | 25%
grid-template-columns: 250px 1fr;     → 250px | sisanya
grid-template-columns: repeat(4, 1fr); → 4 kolom sama lebar
```

## Fungsi

- Layout dua dimensi — sempurna untuk galeri, dashboard, halaman utama
- Lebih powerful dari flexbox untuk layout kompleks
- Grid lines untuk penempatan presisi

## Cara Pengimplementasian

```css
/* Grid 3 kolom sama lebar */
.projects-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: var(--space-6);
}

/* Grid mixed: sidebar + konten */
.page-layout {
  display: grid;
  grid-template-columns: 250px 1fr;
  gap: var(--space-8);
}

/* Grid dengan ukuran spesifik */
.dashboard {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  min-height: 100vh;
  gap: var(--space-4);
}

/* Grid dengan named columns */
.container {
  display: grid;
  grid-template-columns: [sidebar] 250px [main] 1fr [end];
  gap: var(--space-6);
}
```

## Analogi

Flexbox seperti **rak piring** — satu dimensi. CSS Grid seperti **papan catur** — dua dimensi. Kamu tentukan berapa baris dan berapa kolom, lalu tempatkan item di persimpangan baris dan kolom tertentu.

Bayangkan papan catur 3x3:
```
[ A ] [ B ] [ C ]
[ D ] [ E ] [ F ]
[ G ] [ H ] [ I ]
```

Grid-template-columns = lebar tiap kolom. Grid-template-rows = tinggi tiap baris.

## Dipakai Untuk Apa

- Galeri proyek / portofolio
- Layout halaman (header, sidebar, main, footer)
- Dashboard cards
- Product grid di e-commerce

## Kesalahan Umum

- **Grid untuk komponen kecil**: navigasi 1 baris cukup pakai flexbox — Grid untuk layout yang lebih kompleks
- **Lupa fr itu proporsional**: `1fr 1fr` = 50% 50%, tapi `1fr 2fr 1fr` = 25% 50% 25%
- **Tidak set gap**: item menempel satu sama lain
- **Grid vs flexbox galau**: ingat — flex untuk 1 dimensi, grid untuk 2 dimensi

## Hubungan dengan Materi Sebelumnya

Poin 36-41: flexbox untuk layout satu dimensi (baris ATAU kolom). Navigasi, card row, centering — selesai dengan flexbox. Sekarang **CSS Grid** untuk layout dua dimensi (baris DAN kolom) — galeri proyek, layout halaman penuh.

## Soal Latihan

### Soal 1
Tulis CSS untuk grid 3 kolom sama lebar dengan jarak 24px.

**Jawaban:**
```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}
```

### Soal 2
Apa unit `fr` di CSS Grid?

**Jawaban:**
`fr` (fraction) = bagian proporsional dari ruang yang tersisa. `1fr 2fr` berarti kolom pertama 1 bagian, kolom kedua 2 bagian.

### Soal 3
Apa perbedaan grid dan flexbox secara fundamental?

**Jawaban:**
Flexbox untuk **satu dimensi** (baris ATAU kolom). CSS Grid untuk **dua dimensi** (baris DAN kolom). Grid untuk layout halaman, flexbox untuk komponen kecil.
