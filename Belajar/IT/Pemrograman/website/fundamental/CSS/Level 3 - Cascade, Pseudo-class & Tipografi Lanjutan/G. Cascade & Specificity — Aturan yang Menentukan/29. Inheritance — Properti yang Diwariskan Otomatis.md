# 29. Inheritance — Properti yang Diwariskan Otomatis

## Penjelasan

Beberapa properti CSS **diwariskan** (inherited) secara otomatis dari parent ke child. Jika tidak diset di child, child akan pakai nilai dari parent.

**Diwariskan**: `color`, `font-family`, `font-size`, `font-weight`, `line-height`, `text-align`

**Tidak diwariskan**: `margin`, `padding`, `border`, `background`, `width`, `height`, `display`

```css
body {
  color: #333;           /* diwariskan ke semua child */
  font-family: 'Inter', sans-serif; /* diwariskan */
  margin: 0;             /* TIDAK diwariskan */
}

p {
  /* color dan font-family otomatis dari body */
  /* margin tetap default browser (16px top/bottom) */ 
}
```

## Fungsi

- Menulis CSS lebih efisien — set sekali di parent, berlaku untuk semua child
- Konsistensi — semua teks di body otomatis pakai font yang sama

## Cara Pengimplementasian

```css
/* Inheritance berjalan otomatis */
body {
  color: var(--color-text);
  font-family: var(--font-sans);
  line-height: var(--leading-normal);
}
/* Semua teks di body otomatis dapat warna, font, line-height */

/* Tiga nilai khusus inheritance */
.child {
  color: inherit;     /* paksa ambil dari parent */
  font-size: initial; /* kembalikan ke nilai default CSS (medium = 16px) */
  all: unset;         /* inherit kalisa bisa, initial jika tidak */
}

/* Inherit untuk link dalam card */
.card a {
  color: inherit;     /* link pakai warna card, bukan biru default */
  text-decoration: none;
}

/* Initial untuk button font */
button {
  font-family: inherit; /* button pakai font body (default button pakai system font) */
}
```

## Analogi

Seperti **warisan dalam keluarga**:
- `color` di body = "warna rambut keluarga" — semua anak otomatis punya warna rambut yang sama (kecuali mereka "nge-dye" sendiri = set manual)
- `margin` = "nomor rekening bank" — tidak diwariskan, setiap anak punya sendiri
- `inherit` = anak paksa pakai warna rambut ortunya (padahal mungkin sudah di-dye)
- `initial` = anak cukur botak — kembali ke "default"
- `unset` = hapus semua warisan dan gaya default

## Dipakai Untuk Apa

- Set `color`, `font-family`, `line-height` di body — semua elemen teks konsisten
- Set `color: inherit` di link dalam card — link tidak kontras dengan teks card
- Reset `font-family: inherit` di button, input — form elements ikuti font body

## Kesalahan Umum

- **Mengira semua properti diwariskan**: margin, padding, border tidak diwariskan — harus di-set manual
- **Bingung kenapa link di card tidak berwarna card**: karena browser default style `a` (biru) override inheritance — perlu `color: inherit`
- **Nested inherit**: child dari child masih inherit — terus ke bawah sampai ada yang override

## Hubungan dengan Materi Sebelumnya

Poin 26-28: cascade dan specificity. **Inheritance** adalah konsep berbeda — bukan tentang siapa menang, tapi tentang **siapa mewariskan ke siapa**. Ini membuat CSS lebih efisien: set `font-family` sekali di body, seluruh halaman konsisten.

## Soal Latihan

### Soal 1
Sebutkan 3 properti yang diwariskan dan 3 yang tidak.

**Jawaban:**
Diwariskan: `color`, `font-family`, `line-height`. Tidak diwariskan: `margin`, `padding`, `border`.

### Soal 2
Apa fungsi `color: inherit` pada link di dalam card?

**Jawaban:**
Memaksa link untuk menggunakan warna teks dari parent-nya (card), bukan warna biru default browser. Ini membuat link lebih menyatu dengan teks card.

### Soal 3
Mengapa button dan input tidak otomatis memakai `font-family` body?

**Jawaban:**
Browser secara default memberikan style terpisah untuk form elements (button, input, select). Mereka tidak meng-inherit `font-family` dari body — perlu di-set manual: `button, input { font-family: inherit; }`.
