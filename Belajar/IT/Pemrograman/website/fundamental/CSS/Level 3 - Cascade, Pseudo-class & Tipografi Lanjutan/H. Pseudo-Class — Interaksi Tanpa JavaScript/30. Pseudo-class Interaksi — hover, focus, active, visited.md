# 30. Pseudo-class Interaksi — hover, focus, active, visited

## Penjelasan

Pseudo-class adalah kata kunci yang ditambahkan ke selector untuk men-style elemen berdasarkan **state** (kondisi) tertentu — bukan berdasarkan struktur HTML.

| Pseudo-class | Trigger | Contoh |
|-------------|---------|--------|
| `:hover` | Mouse di atas elemen | `a:hover { text-decoration: underline; }` |
| `:focus` | Elemen menerima fokus (klik/tab) | `input:focus { border-color: blue; }` |
| `:focus-visible` | Fokus dari keyboard (bukan mouse) | `button:focus-visible { outline: 2px solid; }` |
| `:active` | Sedang diklik (mouse ditekan) | `btn:active { transform: translateY(1px); }` |
| `:visited` | Link sudah pernah dikunjungi | `a:visited { color: purple; }` |

## Fungsi

- Memberi feedback visual interaksi — tanpa JavaScript
- Meningkatkan user experience — website terasa "hidup"

## Cara Pengimplementasian

```css
/* Tombol dengan semua state */
.btn {
  background-color: var(--color-primary);
  color: white;
  padding: var(--space-3) var(--space-6);
  border: none;
  border-radius: var(--radius-md);
  cursor: pointer;
  transition: background-color 0.2s ease, transform 0.1s ease;
}

.btn:hover {
  background-color: var(--color-primary-dark);
}

.btn:active {
  transform: translateY(1px);
}

.btn:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;
}

/* Link */
a { color: var(--color-primary); text-decoration: none; }
a:hover { text-decoration: underline; color: var(--color-primary-dark); }
a:visited { color: var(--color-primary-dark); }
a:active { color: var(--color-primary-light); }

/* Input */
input:focus {
  outline: none;
  border-color: var(--color-primary);
  box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.15);
}
```

## Analogi

Seperti **pintu rumah dengan sensor**:
- **Default**: pintu tertutup rapi (state normal)
- **:hover** = sensor gerak — saat orang mendekat, lampu menyala (tanpa sentuh)
- **:focus** = orang memegang handle pintu — siap dibuka (fokus)
- **:active** = handle diputar, pintu terbuka (sedang diklik)
- **:focus-visible** = orang datang dengan senter (keyboard), bukan tangan kosong

## Dipakai Untuk Apa

- Tombol — hover (gelap), active (ditekan), focus-visible (outline)
- Link — hover (underline), visited (warna berbeda)
- Card — hover (shadow/angkat)
- Form input — focus (border + shadow)

## Kesalahan Umum

- **Hanya set hover, lupa focus**: pengguna keyboard tidak dapat feedback
- **:focus vs :focus-visible**: :focus muncul di klik dan keyboard, :focus-visible hanya keyboard
- **:hover di mobile**: tidak ada hover di layar sentuh — pastikan semua state bisa diakses via tap
- **:visited terbatas**: untuk privasi, browser batasi properti yang bisa di-style di :visited (hanya color)

## Hubungan dengan Materi Sebelumnya

Poin 26-29: cascade, specificity, inheritance — semua tentang **aturan**. Sekarang kita masuk ke **interaksi**. Pseudo-class memungkinkan CSS bereaksi terhadap tindakan user (hover, klik, fokus) tanpa JavaScript. Ini membuat website portofolio terasa responsif dan hidup.

## Soal Latihan

### Soal 1
Tulis CSS untuk tombol yang berubah background saat di-hover dan sedikit turun saat di-click (active).

**Jawaban:**
```css
.btn { background-color: #2563eb; transition: 0.2s; }
.btn:hover { background-color: #1d4ed8; }
.btn:active { transform: translateY(1px); }
```

### Soal 2
Apa perbedaan `:focus` dan `:focus-visible`?

**Jawaban:**
`:focus` aktif saat elemen mendapat fokus — baik dari klik mouse maupun tab keyboard. `:focus-visible` hanya aktif saat fokus dari keyboard — berguna untuk menampilkan outline hanya untuk keyboard user, tidak untuk klik mouse.

### Soal 3
Mengapa `:hover` tidak cukup untuk aksesibilitas?

**Jawaban:**
Karena pengguna keyboard tidak bisa hover — mereka menggunakan Tab untuk navigasi. Tanpa `:focus` atau `:focus-visible`, mereka tidak tahu elemen mana yang aktif.
