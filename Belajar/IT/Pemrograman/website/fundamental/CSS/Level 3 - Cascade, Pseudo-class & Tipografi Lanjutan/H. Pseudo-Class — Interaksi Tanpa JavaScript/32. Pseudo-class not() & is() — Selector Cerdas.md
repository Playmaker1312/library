# 32. Pseudo-class not() & is() — Selector Cerdas

## Penjelasan

- **`:not()`**: memilih elemen yang **tidak** cocok dengan argumen
- **`:is()`**: grouping selector dengan specificity yang diambil dari argumen paling spesifik

```css
/* :not() — pengecualian */
.nav-item:not(:last-child) {
  border-bottom: 1px solid var(--color-border);
}

/* :is() — grouping cerdas */
:is(h1, h2, h3) a { color: var(--color-primary); }
/* Sama seperti: h1 a, h2 a, h3 a { color: var(--color-primary); } */
```

## Fungsi

- **:not()**: mengecualikan elemen tertentu dari suatu aturan
- **:is()**: grouping yang lebih ringkas dengan specificity cerdas

## Cara Pengimplementasian

```css
/* :not() — berbagai penggunaan */

/* Semua input kecuali checkbox dan radio */
input:not([type="checkbox"]):not([type="radio"]) {
  border: 1px solid var(--color-border);
  padding: var(--space-3);
}

/* Semua item kecuali yang punya class .disabled */
.menu-item:not(.disabled) {
  cursor: pointer;
}

/* Semua p kecuali yang pertama */
p:not(:first-child) {
  margin-top: var(--space-4);
}

/* :is() — berbagai penggunaan */
/* Specificity diambil dari argumen paling spesifik */
:is(.card, .blog) p {
  color: var(--color-text-muted);
}

/* Dengan selector kompleks */
:is(nav, footer) :is(a, button) {
  font-weight: var(--font-weight-medium);
}
```

## Analogi

Di rumah:
- **`:not()`** = "Semua orang di keluarga, **kecuali** Adik" — aturan "cuci tangan sebelum makan" berlaku untuk semua kecuali Adik (karena masih bayi)
- **`:is()`** = "Kakak, Ayah, dan Ibu" — satu aturan untuk beberapa orang sekaligus. Aturan "sepatu di rak" berlaku untuk Kakak, Ayah, dan Ibu — ditulis sekali, bukan tiga kali

## Dipakai Untuk Apa

- **:not()**: border-bottom semua item kecuali terakhir, style semua input kecuali checkbox
- **:is()**: grouping heading (h1, h2, h3) dengan satu aturan, nav + footer link style

## Kesalahan Umum

- **:not() dengan selector kompleks**: `:not(.a .b)` — artinya bukan elemen yang punya ancestor .a dan class .b — sering membingungkan
- **Specificity :is()**: specificity diambil dari argumen paling spesifik — `:is(#id, p)` punya specificity 0,1,0,0
- **:not() tidak bisa dipakai untuk :not(:not(...))**: tidak bisa bersarang di CSS3 (tapi didukung di CSS4)

## Hubungan dengan Materi Sebelumnya

Poin 30-31: pseudo-class untuk state dan posisi. **:not() dan :is()** adalah pseudo-class **logis** — membantu menulis CSS yang lebih ekspresif dan ringkas. Dengan :not(), kita bisa bilang "semua kecuali". Dengan :is(), kita grupkan selector tanpa mengulang.

## Soal Latihan

### Soal 1
Tulis CSS untuk memberi border-bottom ke semua item kecuali yang terakhir.

**Jawaban:**
```css
.item:not(:last-child) {
  border-bottom: 1px solid var(--color-border);
}
```

### Soal 2
Tulis ulang menggunakan `:is()`: h1 a, h2 a, h3 a { color: blue; }

**Jawaban:**
```css
:is(h1, h2, h3) a { color: blue; }
```

### Soal 3
Apa bahaya specificity di `:is()`?

**Jawaban:**
Specificity `:is()` diambil dari argumen **paling spesifik**. `:is(#header, p) a` punya specificity (0,1,0,1) bukan (0,0,0,2) — karena ada #header dengan specificity 0,1,0,0. Bisa menyebabkan bug yang sulit dilacak.
