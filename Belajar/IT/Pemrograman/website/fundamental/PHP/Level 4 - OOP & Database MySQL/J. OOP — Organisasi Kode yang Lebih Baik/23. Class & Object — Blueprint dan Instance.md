# Class & Object — Blueprint dan Instance

## Penjelasan

**Class** adalah cetak biru (blueprint) yang mendefinisikan properti (data) dan method (perilaku) dari suatu entitas. **Object** adalah wujud nyata (instance) yang dibuat dari class tersebut.

| Istilah | Analogi Perpustakaan | PHP |
|---------|----------------------|-----|
| Class | Cetak biru/formulir pendaftaran anggota | `class Anggota {}` |
| Object | Anggota perpustakaan sungguhan: Budi, Siti | `new Anggota()` |
| Properti | Kolom di formulir: nama, alamat, no_anggota | `public $nama` |
| Method | Aksi yang bisa dilakukan: meminjam, mengembalikan | `public function pinjamBuku() {}` |
| `$this` | Kata "saya" yang merujuk ke anggota itu sendiri | `$this->nama` |

Class mendefinisikan *apa yang dimiliki* dan *apa yang bisa dilakukan* oleh object. Dari satu class bisa dibuat banyak object, masing-masing dengan data yang berbeda.

```php
<?php
class Buku {
    // Properti
    public string $judul;
    public string $pengarang;
    public bool $tersedia;

    // Constructor — dipanggil otomatis saat object dibuat
    public function __construct(string $judul, string $pengarang, bool $tersedia = true) {
        $this->judul     = $judul;
        $this->pengarang = $pengarang;
        $this->tersedia  = $tersedia;
    }
}

// Membuat object dari class Buku
$buku1 = new Buku('PHP Dasar', 'Andi');
$buku2 = new Buku('Laravel Pro', 'Budi', false);

echo $buku1->judul;     // PHP Dasar
echo $buku2->tersedia;  // false (tidak ditampilkan, tipe bool)
?>
```

## Fungsi

Mengorganisir kode dengan menggabungkan data dan perilaku dalam satu kesatuan (enkapsulasi). Memungkinkan pembuatan banyak entitas dengan struktur yang sama tanpa duplikasi kode. Menjadi fondasi untuk konsep OOP lanjutan seperti inheritance, polymorphism, dan design pattern.

## Cara Pengimplementasian / Code

```php
<?php
// =====================
// Class: Anggota
// =====================
class Anggota {
    public string $nama;
    public string $email;
    private string $noAnggota;
    private array $bukuDipinjam = [];

    public function __construct(string $nama, string $email) {
        $this->nama   = $nama;
        $this->email  = $email;
        $this->noAnggota = 'AGT-' . strtoupper(uniqid());
    }

    public function getNoAnggota(): string {
        return $this->noAnggota;
    }

    public function pinjamBuku(string $judulBuku): void {
        $this->bukuDipinjam[] = [
            'judul'    => $judulBuku,
            'tanggal'  => date('Y-m-d'),
        ];
        echo "{$this->nama} meminjam buku: $judulBuku\n";
    }

    public function daftarPinjaman(): array {
        return $this->bukuDipinjam;
    }
}

// =====================
// Class: Buku
// =====================
class Buku {
    public string $judul;
    public string $pengarang;
    private string $isbn;
    public bool $tersedia;

    public function __construct(string $judul, string $pengarang, string $isbn) {
        $this->judul     = $judul;
        $this->pengarang = $pengarang;
        $this->isbn      = $isbn;
        $this->tersedia  = true;
    }

    public function getIsbn(): string {
        return $this->isbn;
    }

    public function tandaiDipinjam(): void {
        $this->tersedia = false;
    }

    public function tandaiDikembalikan(): void {
        $this->tersedia = true;
    }
}

// =====================
// Penggunaan Object
// =====================
$anggota1 = new Anggota('Siti Aminah', 'siti@email.com');
$anggota2 = new Anggota('Rudi Hartono', 'rudi@email.com');

$buku1 = new Buku('Belajar PHP', 'Andi', '978-123-456');
$buku2 = new Buku('Mastering Laravel', 'Budi', '978-789-012');

echo "=== Data Anggota ===\n";
echo "Nama: {$anggota1->nama}, No: {$anggota1->getNoAnggota()}\n";
echo "Nama: {$anggota2->nama}, No: {$anggota2->getNoAnggota()}\n";

echo "\n=== Transaksi ===\n";
$anggota1->pinjamBuku($buku1->judul);
$buku1->tandaiDipinjam();

echo "\n=== Daftar Pinjaman {$anggota1->nama} ===\n";
foreach ($anggota1->daftarPinjaman() as $p) {
    echo "- {$p['judul']} (pinjam: {$p['tanggal']})\n";
}

echo "\nStatus {$buku1->judul}: " . ($buku1->tersedia ? 'Tersedia' : 'Dipinjam') . "\n";
?>
```

## Analogi

**Class** adalah **cetak biru blanko formulir pendaftaran anggota perpustakaan** — ada kolom nama, alamat, nomor anggota, dan daftar aturan peminjaman. **Object** adalah **formulir yang sudah diisi oleh Budi, Siti, atau Rudi** — masing-masing berbeda isinya tetapi strukturnya sama. Begitu Budi mengisi namanya di kolom "Nama", itulah object: data konkret dari cetak biru yang sama. Pustakawan (programmer) bisa melihat data Budi (`$budi->nama`), menyuruh Budi meminjam buku (`$budi->pinjamBuku()`), atau memeriksa buku apa yang sedang Budi pinjam.

## Dipakai untuk Apa

- **Model data aplikasi**: Membuat entitas seperti `User`, `Product`, `Order` dengan struktur dan perilaku yang terdefinisi
- **CRUD operations**: Setiap entitas punya method untuk create, read, update, delete
- **Mengelompokkan logika bisnis**: Method dalam class langsung merepresentasikan aksi nyata (pinjam, bayar, kirim email)
- **Reusable code**: Satu class bisa dipakai berulang kali dengan data berbeda
- **Framework modern**: Laravel, Symfony, CodeIgniter semuanya berbasis class dan object

## Kesalahan Umum yang Sering Terjadi

- **Lupa `new`**: Menulis `$buku = Buku('PHP', 'Andi', '123')` tanpa `new` — error fatal.
- **Salah akses properti private**: Mengakses `$anggota->noAnggota` langsung padahal `private` — error; harus lewat method getter.
- **Lupa `$this->`**: Di dalam class, akses properti dengan `$this->nama`, bukan `$nama` — variabel lokal berbeda.
- **Constructor tidak diisi parameter wajib**: `new Buku()` padahal constructor butuh 3 parameter — error `ArgumentCountError`.
- **Typo properti**: `$this->judul` (salah eja) — PHP akan membuat properti baru secara otomatis (di mode non-strict) tanpa error, bikin bug samar.
- **Mengubah properti public sembarangan**: Properti `public $tersedia` bisa diubah dari luar tanpa aturan — lebih baik `private` + method setter.

## Soal Latihan & Jawaban

### Soal

Buat class `Rak` dengan properti `public string $nama`, `public string $lokasi`, `private array $daftarBuku = []`. Constructor menerima `$nama` dan `$lokasi`. Method `tambahBuku(string $judul): void` menambahkan judul ke `$daftarBuku`. Method `getDaftarBuku(): array` mengembalikan semua judul buku di rak tersebut. Buat object `$rakFiksi = new Rak('Fiksi', 'Lantai 2')`, tambahkan 2 buku, lalu tampilkan daftarnya.

### Jawaban

```php
<?php
class Rak {
    public string $nama;
    public string $lokasi;
    private array $daftarBuku = [];

    public function __construct(string $nama, string $lokasi) {
        $this->nama   = $nama;
        $this->lokasi = $lokasi;
    }

    public function tambahBuku(string $judul): void {
        $this->daftarBuku[] = $judul;
        echo "Buku '$judul' ditambahkan ke rak {$this->nama}\n";
    }

    public function getDaftarBuku(): array {
        return $this->daftarBuku;
    }
}

$rakFiksi = new Rak('Fiksi', 'Lantai 2');
$rakFiksi->tambahBuku('Harry Potter');
$rakFiksi->tambahBuku('The Hobbit');

echo "\n=== Daftar Buku di Rak {$rakFiksi->nama} ===\n";
foreach ($rakFiksi->getDaftarBuku() as $buku) {
    echo "- $buku\n";
}
?>
```
