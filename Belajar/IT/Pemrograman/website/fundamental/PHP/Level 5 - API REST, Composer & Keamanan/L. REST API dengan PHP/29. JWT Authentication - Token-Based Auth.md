# JWT Authentication — Token-Based Auth

## Penjelasan

**JWT (JSON Web Token)** adalah standar terbuka (RFC 7519) untuk pertukaran informasi terautentikasi antara dua pihak dalam format JSON. JWT digunakan untuk **token-based authentication** — setelah user login, server memberikan token terenkripsi yang disimpan client (localStorage/cookie) dan dikirim di setiap request ke API.

Struktur JWT terdiri dari tiga bagian yang dipisahkan titik (`.`):

| Bagian | Penjelasan | Contoh (decode) |
|--------|------------|-----------------|
| **Header** | Algoritma enkripsi & tipe token | `{"alg": "HS256", "typ": "JWT"}` |
| **Payload** | Data (claims) — siapa user, kapan expired | `{"sub": 1, "name": "admin", "iat": 1680000000, "exp": 1680086400}` |
| **Signature** | Tanda tangan digital — verifikasi token tidak diubah | `HMACSHA256(base64(header).base64(payload), secret)` |

Alur autentikasi JWT:

```
Client                    Server
  |                         |
  |-- POST /login --------->|  Cek username & password
  |  (username + password)  |  Buat JWT dengan secret key
  |<-- { token: "eyJ..." }--|  Kirim token ke client
  |                         |
  |-- GET /api/buku ------->|  Terima token di header
  |  Authorization: Bearer  |  Verifikasi signature & expiry
  |  eyJ...                 |  Jika valid, proses request
  |<-- { data: [...] }------|  Kirim response
```

## Fungsi

JWT menyediakan autentikasi **stateless** — server tidak perlu menyimpan session di database. Token berisi semua informasi yang server perlukan untuk memverifikasi identitas user. Ini sangat cocok untuk REST API yang melayani banyak client (web, mobile, third-party).

## Cara Pengimplementasian / Code

```php
<?php
// =====================
// 1. JWT Helper Class (tanpa library eksternal)
// =====================
class JWT {
    private const SECRET = 'k4t4_r4h4s1A_p3rpu5t4k44n_2026!';
    private const ALGO   = 'sha256';

    public static function encode(array $payload): string {
        // Header
        $header = self::base64UrlEncode(json_encode([
            'alg' => 'HS256',
            'typ' => 'JWT',
        ]));

        // Payload — tambahkan issued at (iat) dan expired (exp)
        $payload['iat'] = time();
        $payload['exp'] = time() + 3600; // 1 jam
        $payloadStr = self::base64UrlEncode(json_encode($payload));

        // Signature
        $signature = self::base64UrlEncode(
            hash_hmac(self::ALGO, "$header.$payloadStr", self::SECRET, true)
        );

        return "$header.$payloadStr.$signature";
    }

    public static function decode(string $token): ?array {
        $parts = explode('.', $token);
        if (count($parts) !== 3) return null;

        [$header, $payload, $signature] = $parts;

        // Verifikasi signature
        $expectedSig = self::base64UrlEncode(
            hash_hmac(self::ALGO, "$header.$payload", self::SECRET, true)
        );

        if (!hash_equals($expectedSig, $signature)) return null;

        $data = json_decode(self::base64UrlDecode($payload), true);
        if (!$data || !isset($data['exp'])) return null;

        // Cek expired
        if ($data['exp'] < time()) return null;

        return $data;
    }

    private static function base64UrlEncode(string $data): string {
        return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
    }

    private static function base64UrlDecode(string $data): string {
        return base64_decode(strtr($data, '-_', '+/'));
    }
}

// =====================
// 2. Middleware — Cek Token
// =====================
function authenticate(): ?array {
    $authHeader = $_SERVER['HTTP_AUTHORIZATION']
        ?? $_SERVER['REDIRECT_HTTP_AUTHORIZATION']
        ?? '';

    if (!preg_match('/^Bearer\s+(.+)$/i', $authHeader, $matches)) {
        http_response_code(401);
        echo json_encode(['error' => 'Token tidak ditemukan']);
        exit;
    }

    $payload = JWT::decode($matches[1]);
    if (!$payload) {
        http_response_code(401);
        echo json_encode(['error' => 'Token tidak valid atau sudah expired']);
        exit;
    }

    return $payload;
}

// =====================
// 3. Router + Auth (gabungan dengan materi 28)
// =====================
header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type, Authorization');

if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(200);
    exit;
}

class Router {
    private array $routes = [];

    public function addRoute(string $method, string $path, callable $handler, bool $protected = false): void {
        $this->routes[] = [
            'method'    => strtoupper($method),
            'path'      => $path,
            'handler'   => $handler,
            'protected' => $protected,
        ];
    }

    public function dispatch(): void {
        $method = $_SERVER['REQUEST_METHOD'];
        $uri    = rtrim(parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH), '/');

        foreach ($this->routes as $route) {
            $pattern = preg_replace('/\{(\w+)\}/', '(?P<$1>\d+)', $route['path']);
            $pattern = '#^' . $pattern . '$#';

            if ($route['method'] === $method && preg_match($pattern, $uri, $matches)) {
                // Cek autentikasi jika route dilindungi
                if ($route['protected']) {
                    authenticate();
                }

                $params = array_filter($matches, 'is_string', ARRAY_FILTER_USE_KEY);
                echo json_encode($route['handler']($params));
                return;
            }
        }

        http_response_code(404);
        echo json_encode(['error' => 'Endpoint tidak ditemukan']);
    }
}

// =====================
// 4. Handler dengan Auth
// =====================
function login(): array {
    $input = json_decode(file_get_contents('php://input'), true);

    // Simulasi database user (di produksi pakai tabel user)
    $users = [
        ['id' => 1, 'username' => 'admin',  'password' => 'rahasia123'],
        ['id' => 2, 'username' => 'petugas', 'password' => 'pustaka456'],
    ];

    foreach ($users as $user) {
        if ($user['username'] === ($input['username'] ?? '')
            && $user['password'] === ($input['password'] ?? '')) {
            $token = JWT::encode([
                'sub'      => $user['id'],
                'username' => $user['username'],
                'role'     => 'admin',
            ]);
            return ['token' => $token];
        }
    }

    http_response_code(401);
    return ['error' => 'Username atau password salah'];
}

function getProfile(array $params): array {
    $user = authenticate();
    return [
        'user_id'  => $user['sub'],
        'username' => $user['username'],
        'role'     => $user['role'],
    ];
}

// =====================
// 5. Daftar Route
// =====================
$router = new Router();
$router->addRoute('POST', '/api/login', 'login');
$router->addRoute('GET', '/api/profile', 'getProfile', true);

// Route publik
$router->addRoute('GET', '/api/buku', function () {
    return ['data' => 'Daftar buku publik (tanpa auth)'];
});

// Route terproteksi
$router->addRoute('POST', '/api/buku', function () {
    return ['message' => 'Buku ditambahkan (dengan auth)'];
}, true);

$router->dispatch();
```

## Analogi

JWT adalah **kartu anggota perpustakaan**. Saat Anda mendaftar (login), petugas membuatkan kartu yang berisi foto Anda, nama, tanggal berlaku (expired), dan tanda tangan digital (stempel basah). Setiap kali Anda ingin pinjam buku (akses endpoint terproteksi), Anda tunjukkan kartu itu. Petugas (server) tidak perlu membuka buku besar untuk mengecek siapa Anda — semua informasi sudah ada di kartu, dan stempel basah (signature) membuktikan kartu itu asli, bukan palsu. Kalau kartu expired (token lewat masa berlaku), Anda harus daftar ulang. Kartu ini bisa Anda simpan di dompet (localStorage) dan bawa ke mana pun tanpa perlu lapor ke petugas setiap saat.

## Dipakai untuk Apa

- **Autentikasi REST API** — menggantikan session-based auth untuk aplikasi SPA dan mobile
- **Single Sign-On (SSO)** — satu token bisa dipakai di beberapa layanan
- **API untuk third-party developer** — partner mendapat token dengan scope terbatas
- **Stateless microservices** — setiap service bisa verifikasi token tanpa call ke database user
- **Mobile app authentication** — token disimpan di device, tidak perlu login ulang setiap buka app

## Kesalahan Umum yang Sering Terjadi

- **Secret key hardcode di kode**: Secret disimpan di file yang ikut ke git — gunakan environment variable.
- **Expiry terlalu lama**: Token expired 30 hari — risiko keamanan; 15-60 menit lebih aman.
- **Tidak handle token expired**: Token expired tetap dianggap valid — selalu cek `exp` claim.
- **Menyimpan password di payload**: Payload JWT hanya di-base64, tidak terenkripsi — jangan simpan data sensitif.
- **Lupa verifikasi signature**: Hanya decode base64 tanpa cek signature — token palsu bisa lolos.
- **Tidak pakai HTTPS**: Token dikirim plain text — bisa dicuri lewat man-in-the-middle attack.
- **Token tidak di-blacklist setelah logout**: JWT stateless tetap valid sampai expired — implementasikan token blacklist untuk logout.

## Soal Latihan & Jawaban

### Soal

Buat endpoint `POST /api/register` yang menerima `username` dan `password`, lalu menyimpan user baru ke file `users.json` (atau database). Setelah register sukses, langsung kembalikan token JWT (auto-login). Validasi: username minimal 3 karakter, password minimal 6 karakter. Jika username sudah ada, return error 409 Conflict.

### Jawaban

```php
<?php
// =====================
// File: register.php
// =====================

function register(): array {
    $input = json_decode(file_get_contents('php://input'), true);
    $username = trim($input['username'] ?? '');
    $password = $input['password'] ?? '';

    // Validasi
    if (strlen($username) < 3) {
        http_response_code(400);
        return ['error' => 'Username minimal 3 karakter'];
    }
    if (strlen($password) < 6) {
        http_response_code(400);
        return ['error' => 'Password minimal 6 karakter'];
    }

    // Baca atau buat file users.json
    $filePath = __DIR__ . '/users.json';
    $users = [];
    if (file_exists($filePath)) {
        $users = json_decode(file_get_contents($filePath), true) ?? [];
    }

    // Cek duplikasi username
    foreach ($users as $user) {
        if ($user['username'] === $username) {
            http_response_code(409);
            return ['error' => 'Username sudah terdaftar'];
        }
    }

    // Simpan user baru
    $newUser = [
        'id'       => count($users) + 1,
        'username' => $username,
        'password' => password_hash($password, PASSWORD_DEFAULT),
        'role'     => 'user',
        'created_at' => date('Y-m-d H:i:s'),
    ];
    $users[] = $newUser;
    file_put_contents($filePath, json_encode($users, JSON_PRETTY_PRINT));

    // Buat token JWT
    $token = JWT::encode([
        'sub'      => $newUser['id'],
        'username' => $newUser['username'],
        'role'     => $newUser['role'],
    ]);

    http_response_code(201);
    return [
        'message' => 'Registrasi berhasil',
        'token'   => $token,
        'user'    => [
            'id'       => $newUser['id'],
            'username' => $newUser['username'],
            'role'     => $newUser['role'],
        ],
    ];
}

// Daftarkan route
$router->addRoute('POST', '/api/register', 'register');
?>
```
