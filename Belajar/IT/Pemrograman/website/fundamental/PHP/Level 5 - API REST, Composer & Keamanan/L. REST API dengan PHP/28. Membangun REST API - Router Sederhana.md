# Membangun REST API — Router Sederhana

## Penjelasan

**REST API (Representational State Transfer Application Programming Interface)** adalah arsitektur komunikasi antara client dan server menggunakan protokol HTTP. REST API memungkinkan aplikasi frontend (React, Vue, mobile app) berkomunikasi dengan backend PHP melalui format data JSON.

**Router** adalah komponen yang menerima HTTP request, membaca URL dan method (GET, POST, PUT, DELETE), lalu meneruskannya ke handler yang sesuai. Router sederhana membuat kita tidak perlu menulis banyak file PHP terpisah untuk setiap endpoint.

Prinsip dasar REST:

| HTTP Method | Fungsi | Contoh Endpoint | Operasi CRUD |
|-------------|--------|-----------------|--------------|
| GET | Membaca data | `GET /api/buku` | Read |
| POST | Menambahkan data | `POST /api/buku` | Create |
| PUT/PATCH | Mengupdate data | `PUT /api/buku/1` | Update |
| DELETE | Menghapus data | `DELETE /api/buku/1` | Delete |

Struktur URL RESTful menggunakan resource (noun) bukan aksi (verb):

| ❌ Bukan REST | ✅ RESTful |
|---------------|------------|
| `/api/getBuku.php` | `GET /api/buku` |
| `/api/addBuku.php` | `POST /api/buku` |
| `/api/deleteBuku.php?id=1` | `DELETE /api/buku/1` |

## Fungsi

Router dan REST API memisahkan **logika backend** dari **tampilan frontend**. Backend cukup mengembalikan JSON, dan frontend mana pun bisa mengonsumsinya. Router memungkinkan kode lebih terstruktur — setiap endpoint punya handler sendiri tanpa perlu membuat file `.php` terpisah untuk setiap halaman.

## Cara Pengimplementasian / Code

```php
<?php
// =====================
// 1. Router Sederhana — index.php (entry point)
// =====================
// Setup: arahkan semua request ke file ini menggunakan .htaccess
// atau built-in PHP server: php -S localhost:8000 index.php

header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type, Authorization');

// Handle preflight CORS request
if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(200);
    exit;
}

// =====================
// Class Router
// =====================
class Router {
    private array $routes = [];

    public function addRoute(string $method, string $path, callable $handler): void {
        $this->routes[] = [
            'method'  => strtoupper($method),
            'path'    => $path,
            'handler' => $handler,
        ];
    }

    public function dispatch(): void {
        $method = $_SERVER['REQUEST_METHOD'];
        $uri    = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
        $uri    = rtrim($uri, '/');

        foreach ($this->routes as $route) {
            $pattern = preg_replace('/\{(\w+)\}/', '(?P<$1>\d+)', $route['path']);
            $pattern = '#^' . $pattern . '$#';

            if ($route['method'] === $method && preg_match($pattern, $uri, $matches)) {
                $params = array_filter($matches, 'is_string', ARRAY_FILTER_USE_KEY);
                echo json_encode($route['handler']($params));
                return;
            }
        }

        http_response_code(404);
        echo json_encode(['error' => 'Endpoint tidak ditemukan']);
    }
}

// =====================
// 2. Database Connection (menggunakan PDO dari Level 4)
// =====================
class Database {
    private static ?PDO $instance = null;

    public static function getInstance(): PDO {
        if (self::$instance === null) {
            $dsn = "mysql:host=localhost;dbname=perpustakaan;charset=utf8mb4";
            self::$instance = new PDO($dsn, 'root', '', [
                PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES   => false,
            ]);
        }
        return self::$instance;
    }
}

// =====================
// 3. Handler Functions
// =====================
function getBuku(): array {
    $pdo  = Database::getInstance();
    $stmt = $pdo->query("SELECT * FROM buku ORDER BY judul");
    return ['data' => $stmt->fetchAll()];
}

function getBukuById(array $params): array {
    $pdo  = Database::getInstance();
    $stmt = $pdo->prepare("SELECT * FROM buku WHERE id = ?");
    $stmt->execute([$params['id']]);
    $buku = $stmt->fetch();

    if (!$buku) {
        http_response_code(404);
        return ['error' => 'Buku tidak ditemukan'];
    }
    return ['data' => $buku];
}

function createBuku(): array {
    $input = json_decode(file_get_contents('php://input'), true);

    if (!isset($input['judul'], $input['pengarang'])) {
        http_response_code(400);
        return ['error' => 'Field judul dan pengarang wajib diisi'];
    }

    $pdo  = Database::getInstance();
    $stmt = $pdo->prepare("INSERT INTO buku (judul, pengarang, tahun) VALUES (?, ?, ?)");
    $stmt->execute([
        $input['judul'],
        $input['pengarang'],
        $input['tahun'] ?? date('Y'),
    ]);

    http_response_code(201);
    return ['message' => 'Buku berhasil ditambahkan', 'id' => (int) $pdo->lastInsertId()];
}

function updateBuku(array $params): array {
    $input = json_decode(file_get_contents('php://input'), true);
    $pdo   = Database::getInstance();

    $stmt = $pdo->prepare("SELECT * FROM buku WHERE id = ?");
    $stmt->execute([$params['id']]);
    if (!$stmt->fetch()) {
        http_response_code(404);
        return ['error' => 'Buku tidak ditemukan'];
    }

    $judul    = $input['judul']    ?? null;
    $pengarang = $input['pengarang'] ?? null;
    $tahun    = $input['tahun']    ?? null;

    $fields = [];
    $values = [];
    if ($judul)    { $fields[] = 'judul = ?';    $values[] = $judul; }
    if ($pengarang) { $fields[] = 'pengarang = ?'; $values[] = $pengarang; }
    if ($tahun)    { $fields[] = 'tahun = ?';    $values[] = $tahun; }

    if (empty($fields)) {
        http_response_code(400);
        return ['error' => 'Tidak ada field yang diupdate'];
    }

    $values[] = $params['id'];
    $sql = "UPDATE buku SET " . implode(', ', $fields) . " WHERE id = ?";
    $pdo->prepare($sql)->execute($values);

    return ['message' => 'Buku berhasil diupdate'];
}

function deleteBuku(array $params): array {
    $pdo  = Database::getInstance();
    $stmt = $pdo->prepare("SELECT * FROM buku WHERE id = ?");
    $stmt->execute([$params['id']]);
    if (!$stmt->fetch()) {
        http_response_code(404);
        return ['error' => 'Buku tidak ditemukan'];
    }

    $pdo->prepare("DELETE FROM buku WHERE id = ?")->execute([$params['id']]);
    return ['message' => 'Buku berhasil dihapus'];
}

// =====================
// 4. Register Routes
// =====================
$router = new Router();

$router->addRoute('GET',    '/api/buku',     'getBuku');
$router->addRoute('GET',    '/api/buku/{id}', 'getBukuById');
$router->addRoute('POST',   '/api/buku',     'createBuku');
$router->addRoute('PUT',    '/api/buku/{id}', 'updateBuku');
$router->addRoute('DELETE', '/api/buku/{id}', 'deleteBuku');

$router->dispatch();
```

File `.htaccess` (untuk Apache — arahkan semua request ke index.php):
```
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.php [L]
```

## Analogi

Router REST API adalah **meja informasi perpustakaan**. Seorang pengunjung (client) datang dan menyampaikan permintaan: "Saya ingin pinjam buku" (POST /peminjaman), "Saya ingin lihat daftar buku" (GET /buku), atau "Saya ingin perpanjang peminjaman" (PUT /peminjaman/1). Petugas meja informasi (router) mendengar method permintaannya — apakah minta lihat (GET), minta tambah (POST), minta ubah (PUT), atau minta hapus (DELETE) — lalu meneruskannya ke bagian yang tepat: bagian sirkulasi untuk peminjaman, bagian katalog untuk daftar buku. Petugas tidak perlu mengerti detail kerja masing-masing bagian; dia hanya penerus (router). Dan pengunjung tidak perlu tahu di mana letak rak buku — cukup sampaikan permintaan ke meja informasi.

## Dipakai untuk Apa

- **Backend untuk aplikasi mobile dan SPA** — React, Vue, Angular, atau Flutter bisa pakai satu REST API yang sama
- **Microservice architecture** — setiap service punya REST API sendiri
- **Integrasi pihak ketiga** — menyediakan API untuk partner atau developer eksternal
- **Separation of concerns** — backend fokus pada logika data, frontend fokus pada UI
- **Stateless communication** — setiap request berdiri sendiri, tidak bergantung pada state server

## Kesalahan Umum yang Sering Terjadi

- **HTTP method salah**: Mengirim POST untuk membaca data — gunakan GET untuk read operation.
- **Lupa header Content-Type**: `header('Content-Type: application/json')` tidak diset — client menerima response sebagai teks biasa.
- **Tidak handle CORS**: Frontend di domain berbeda tidak bisa mengakses API — tambahkan header `Access-Control-Allow-Origin`.
- **Path pattern error**: Regex atau placeholder tidak cocok — route `{id}` tidak match dengan angka karena regex salah.
- **Tidak validasi input**: Langsung insert data dari `json_decode` tanpa validasi — riskan error dan SQL injection.
- **Error handling tidak konsisten**: Beberapa endpoint return array, beberapa return string — client bingung parsing response.
- **Tidak handle OPTIONS request**: Browser preflight CORS gagal — endpoint harus merespon method OPTIONS.

## Soal Latihan & Jawaban

### Soal

Buat endpoint baru di router di atas: `GET /api/anggota/{id}/pinjaman` yang mengembalikan daftar buku yang sedang dipinjam oleh anggota tertentu. Gunakan tabel `peminjaman` dengan kolom `id`, `anggota_id`, `buku_id`, `tanggal_pinjam`, `tanggal_kembali`. Jika anggota tidak ditemukan, return 404. Jika tidak ada pinjaman, return array kosong.

### Jawaban

```php
<?php
// Tambahkan handler ini ke file index.php yang sudah ada

function getPinjamanAnggota(array $params): array {
    $pdo = Database::getInstance();

    // Cek apakah anggota ada
    $stmt = $pdo->prepare("SELECT id, nama FROM anggota WHERE id = ?");
    $stmt->execute([$params['id']]);
    $anggota = $stmt->fetch();

    if (!$anggota) {
        http_response_code(404);
        return ['error' => 'Anggota tidak ditemukan'];
    }

    // Ambil pinjaman aktif anggota
    $stmt = $pdo->prepare("
        SELECT p.id, b.judul, b.pengarang, p.tanggal_pinjam
        FROM peminjaman p
        JOIN buku b ON b.id = p.buku_id
        WHERE p.anggota_id = ? AND p.tanggal_kembali IS NULL
        ORDER BY p.tanggal_pinjam DESC
    ");
    $stmt->execute([$params['id']]);
    $pinjaman = $stmt->fetchAll();

    return [
        'anggota'  => $anggota['nama'],
        'total'    => count($pinjaman),
        'data'     => $pinjaman,
    ];
}

// Daftarkan route
$router->addRoute('GET', '/api/anggota/{id}/pinjaman', 'getPinjamanAnggota');

// Contoh response sukses:
// {
//   "anggota": "Siti Aminah",
//   "total": 2,
//   "data": [
//     {"id": 1, "judul": "PHP Dasar", "pengarang": "Andi", "tanggal_pinjam": "2026-06-01"},
//     {"id": 2, "judul": "Laravel Pro", "pengarang": "Budi", "tanggal_pinjam": "2026-06-15"}
//   ]
// }
?>
```
