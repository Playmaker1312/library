# Keamanan API — Rate Limiting & Input Validation

## Penjelasan

**Keamanan API** adalah serangkaian praktik untuk melindungi REST API dari serangan dan penyalahgunaan. Dua aspek paling penting adalah **Rate Limiting** (membatasi jumlah request) dan **Input Validation** (memvalidasi setiap data yang masuk).

### Rate Limiting

Rate limiting membatasi berapa banyak request yang bisa dilakukan client dalam periode waktu tertentu. Tanpa rate limiting, API rentan terhadap:

- **Brute force attack** — mencoba ribuan password per detik
- **DDoS (Distributed Denial of Service)** — membanjiri server dengan request
- **Web scraping** — mencuri data besar-besaran secara otomatis
- **API abuse** — penyalahgunaan endpoint gratis

### Input Validation

Input validation memastikan setiap data yang diterima server sesuai dengan format, tipe, dan batasan yang diharapkan. Tanpa validasi yang ketat:

- **XSS (Cross-Site Scripting)** — menyisipkan script jahat
- **SQL Injection** — menyisipkan query SQL berbahaya
- **NoSQL Injection** — manipulasi query database NoSQL
- **Mass Assignment** — mengubah field yang tidak seharusnya
- **Buffer overflow** — input melebihi kapasitas

## Fungsi

Rate limiting menjaga **ketersediaan** (availability) API — server tidak kewalahan oleh request berlebihan. Input validation menjaga **integritas** (integrity) data — hanya data yang valid dan aman yang diproses. Keduanya adalah lapisan pertahanan pertama dalam keamanan API.

## Cara Pengimplementasian / Code

```php
<?php
// =====================
// 1. Rate Limiter — File-Based
// =====================
class RateLimiter {
    private string $storageDir;
    private int    $maxRequests;
    private int    $windowSeconds;

    public function __construct(int $maxRequests = 60, int $windowSeconds = 60) {
        $this->storageDir    = __DIR__ . '/../storage/ratelimit';
        $this->maxRequests   = $maxRequests;
        $this->windowSeconds = $windowSeconds;

        if (!is_dir($this->storageDir)) {
            mkdir($this->storageDir, 0777, true);
        }
    }

    public function check(string $identifier): bool {
        $file = $this->storageDir . '/' . md5($identifier) . '.json';
        $now  = time();

        $data = ['requests' => []];
        if (file_exists($file)) {
            $data = json_decode(file_get_contents($file), true) ?? $data;
        }

        // Hapus request yang sudah lewat window
        $data['requests'] = array_values(array_filter(
            $data['requests'],
            fn(int $timestamp) => ($now - $timestamp) < $this->windowSeconds
        ));

        // Cek apakah melebihi batas
        if (count($data['requests']) >= $this->maxRequests) {
            return false; // Rate limit exceeded
        }

        // Catat request baru
        $data['requests'][] = $now;
        file_put_contents($file, json_encode($data));

        return true;
    }

    public function getRemaining(string $identifier): int {
        $file = $this->storageDir . '/' . md5($identifier) . '.json';
        if (!file_exists($file)) return $this->maxRequests;

        $data = json_decode(file_get_contents($file), true);
        $active = array_filter($data['requests'] ?? [], fn($t) => (time() - $t) < $this->windowSeconds);

        return max(0, $this->maxRequests - count($active));
    }
}

// =====================
// 2. Input Validator
// =====================
class Validator {
    private array $errors = [];

    public function required(string $field, $value): self {
        if (empty($value) && $value !== '0' && $value !== 0) {
            $this->errors[] = "Field '$field' wajib diisi";
        }
        return $this;
    }

    public function minLength(string $field, string $value, int $min): self {
        if (strlen($value) < $min) {
            $this->errors[] = "Field '$field' minimal $min karakter";
        }
        return $this;
    }

    public function maxLength(string $field, string $value, int $max): self {
        if (strlen($value) > $max) {
            $this->errors[] = "Field '$field' maksimal $max karakter";
        }
        return $this;
    }

    public function email(string $field, string $value): self {
        if (!filter_var($value, FILTER_VALIDATE_EMAIL)) {
            $this->errors[] = "Field '$field' harus email yang valid";
        }
        return $this;
    }

    public function numeric(string $field, $value): self {
        if (!is_numeric($value)) {
            $this->errors[] = "Field '$field' harus angka";
        }
        return $this;
    }

    public function inArray(string $field, $value, array $allowed): self {
        if (!in_array($value, $allowed, true)) {
            $allowedStr = implode(', ', $allowed);
            $this->errors[] = "Field '$field' harus salah satu dari: $allowedStr";
        }
        return $this;
    }

    public function regex(string $field, string $value, string $pattern, string $message = null): self {
        if (!preg_match($pattern, $value)) {
            $this->errors[] = $message ?? "Field '$field' tidak valid";
        }
        return $this;
    }

    public function sanitize(string $value): string {
        return htmlspecialchars(strip_tags(trim($value)), ENT_QUOTES, 'UTF-8');
    }

    public function isValid(): bool {
        return empty($this->errors);
    }

    public function getErrors(): array {
        return $this->errors;
    }
}

// =====================
// 3. Middleware — Full Security Layer
// =====================
class SecurityMiddleware {
    private RateLimiter $rateLimiter;
    private Validator   $validator;

    public function __construct() {
        $this->rateLimiter = new RateLimiter(30, 60); // 30 request per 60 detik
        $this->validator   = new Validator();
    }

    public function handleRequest(): void {
        // 1. CORS + Headers keamanan
        header('Content-Type: application/json');
        header('Access-Control-Allow-Origin: *');
        header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS');
        header('Access-Control-Allow-Headers: Content-Type, Authorization');

        // Security headers
        header('X-Content-Type-Options: nosniff');
        header('X-Frame-Options: DENY');
        header('X-XSS-Protection: 1; mode=block');
        header('Strict-Transport-Security: max-age=31536000; includeSubDomains');
        header('Referrer-Policy: strict-origin-when-cross-origin');

        if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
            http_response_code(200);
            exit;
        }

        // 2. Rate Limiting — berdasarkan IP
        $clientIp = $_SERVER['REMOTE_ADDR']
                  ?? $_SERVER['HTTP_X_FORWARDED_FOR']
                  ?? 'unknown';

        if (!$this->rateLimiter->check($clientIp)) {
            http_response_code(429);
            echo json_encode([
                'error'     => 'Terlalu banyak request. Silakan coba lagi.',
                'retry_after' => 60,
            ]);
            exit;
        }

        // Set header rate limit info
        header('X-RateLimit-Limit: ' . 30);
        header('X-RateLimit-Remaining: ' . $this->rateLimiter->getRemaining($clientIp));
    }

    public function getValidator(): Validator {
        return $this->validator;
    }
}

// =====================
// 4. Integrasi dengan REST API
// =====================
$security = new SecurityMiddleware();
$security->handleRequest();

// Router sederhana (dari materi 28)
$uri    = rtrim(parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH), '/');
$method = $_SERVER['REQUEST_METHOD'];

if ($method === 'POST' && $uri === '/api/buku') {
    $input = json_decode(file_get_contents('php://input'), true);
    $v     = $security->getValidator();

    // Validasi input
    $v->required('judul', $input['judul'] ?? null)
      ->minLength('judul', $input['judul'] ?? '', 2)
      ->maxLength('judul', $input['judul'] ?? '', 255)
      ->required('pengarang', $input['pengarang'] ?? null)
      ->minLength('pengarang', $input['pengarang'] ?? '', 2)
      ->required('tahun', $input['tahun'] ?? null)
      ->numeric('tahun', $input['tahun'] ?? 0);

    if (!$v->isValid()) {
        http_response_code(422);
        echo json_encode(['errors' => $v->getErrors()]);
        exit;
    }

    // Sanitasi sebelum diproses
    $judul    = $v->sanitize($input['judul']);
    $pengarang = $v->sanitize($input['pengarang']);
    $tahun    = (int) $input['tahun'];

    // Simpan ke database (dengan prepared statements — aman dari SQL injection)
    $pdo = new PDO('mysql:host=localhost;dbname=perpustakaan;charset=utf8mb4', 'root', '');
    $stmt = $pdo->prepare("INSERT INTO buku (judul, pengarang, tahun) VALUES (?, ?, ?)");
    $stmt->execute([$judul, $pengarang, $tahun]);

    http_response_code(201);
    echo json_encode(['message' => 'Buku berhasil ditambahkan', 'id' => (int) $pdo->lastInsertId()]);
    exit;
}

// Rate limiter berbasis database (opsional — untuk production)
class DatabaseRateLimiter {
    private PDO $pdo;

    public function __construct(PDO $pdo) {
        $this->pdo = $pdo;
        $this->pdo->exec("
            CREATE TABLE IF NOT EXISTS rate_limits (
                id INT AUTO_INCREMENT PRIMARY KEY,
                identifier VARCHAR(64) NOT NULL,
                endpoint VARCHAR(255) NOT NULL,
                request_time INT NOT NULL,
                INDEX idx_identifier (identifier, request_time)
            ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4
        ");
    }

    public function check(string $identifier, string $endpoint, int $maxRequests = 60, int $windowSeconds = 60): bool {
        $windowStart = time() - $windowSeconds;

        // Hapus data lama
        $stmt = $this->pdo->prepare("DELETE FROM rate_limits WHERE request_time < ?");
        $stmt->execute([$windowStart]);

        // Hitung request dalam window
        $stmt = $this->pdo->prepare(
            "SELECT COUNT(*) FROM rate_limits WHERE identifier = ? AND request_time >= ?"
        );
        $stmt->execute([$identifier, $windowStart]);
        $count = (int) $stmt->fetchColumn();

        if ($count >= $maxRequests) return false;

        // Catat request
        $stmt = $this->pdo->prepare(
            "INSERT INTO rate_limits (identifier, endpoint, request_time) VALUES (?, ?, ?)"
        );
        $stmt->execute([$identifier, $endpoint, time()]);

        return true;
    }
}
```

## Analogi

Rate limiting adalah **aturan batas peminjaman buku di perpustakaan**. Setiap anggota hanya boleh meminjam maksimal 5 buku dalam satu waktu. Kalau ada anggota yang mencoba meminjam 20 buku sekaligus (brute force), petugas akan menolak dan menyuruhnya kembali lain hari. Input validation adalah **proses verifikasi data di formulir pendaftaran**. Petugas memeriksa: nama tidak boleh kosong, nomor telepon harus angka, email harus punya `@` dan domain, alamat tidak boleh lebih dari 255 karakter. Data yang tidak valid langsung ditolak — tidak akan dimasukkan ke sistem. Petugas juga membersihkan data: spasi berlebih dihapus, karakter aneh dibuang, format dibakukan. Seperti perpustakaan yang punya prosedur ketat untuk menjaga koleksi, API Anda harus punya prosedur ketat untuk menjaga data.

## Dipakai untuk Apa

- **Mencegah brute force login** — batasi percobaan login 5 kali per menit per IP
- **Melindungi endpoint publik** — API gratis tetap aman dari abuse
- **Validasi form registration** — nama, email, password, nomor telepon
- **Sanitasi input sebelum disimpan** — cegah XSS dan HTML injection
- **Filter upload file** — cek tipe file, ukuran, dan ekstensi
- **Whitelist parameter** — hanya field yang diizinkan yang diproses (cegah mass assignment)
- **Throttling berdasarkan user** — user gratis 100 req/jam, user premium 1000 req/jam

## Kesalahan Umum yang Sering Terjadi

- **Hanya validasi di frontend**: Validasi client-side mudah dilewati — selalu validasi di server.
- **Lupa sanitasi output**: Data dari database langsung ditampilkan ke HTML — rentan XSS; gunakan `htmlspecialchars()`.
- **Rate limiting hanya berdasarkan IP**: Pengguna VPN atau proxy bisa sharing IP yang sama — kombinasikan dengan token user.
- **Error message terlalu informatif**: "Password salah, karakter ke-3 seharusnya 'a'" — membantu attacker; pesan error harus generik.
- **Tidak handle Unicode/non-ASCII**: Input nama pengguna dengan aksara asing seperti 中文 atau العربية — pastikan charset UTF-8.
- **Mengandalkan filter_var saja**: `FILTER_SANITIZE_STRING` deprecated di PHP 8.1 — gunakan `htmlspecialchars()` + regex.
- **Blacklist validation**: Mencoba memblokir kata-kata tertentu (filter by bad words) — lebih baik whitelist (izinkan hanya yang baik).
- **Lupa batasi ukuran request**: Upload file 2GB tanpa pengecekan — server kehabisan memory; set `upload_max_filesize` dan `post_max_size`.

## Hubungan dengan Materi Sebelumnya

Materi 19 (Sanitasi & Validasi Dasar) adalah fondasi — materi ini memperluas ke API context dengan rate limiting. Materi 20 (Session Login) dilindungi dengan rate limiting pada endpoint login. ## Soal Latihan & Jawaban

### Soal

Buat sistem booking ruang baca perpustakaan lewat API dengan ketentuan:
1. Setiap anggota maksimal 2 kali booking per hari (rate limiting per user)
2. Validasi: `anggota_id` harus angka, `tanggal` format YYYY-MM-DD, `jam_mulai` antara 08:00-17:00, `durasi` antara 1-4 jam
3. Endpoint: `POST /api/booking`
4. Jika melebihi batas booking, return 429. Jika validasi gagal, return 422 dengan daftar error.

### Jawaban

```php
<?php
require_once __DIR__ . '/vendor/autoload.php';

header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: POST, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type');

if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(200);
    exit;
}

// =====================
// Database Connection
// =====================
$pdo = new PDO(
    'mysql:host=localhost;dbname=perpustakaan;charset=utf8mb4',
    'root', '',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

$pdo->exec("CREATE TABLE IF NOT EXISTS booking_ruang (
    id INT AUTO_INCREMENT PRIMARY KEY,
    anggota_id INT NOT NULL,
    tanggal DATE NOT NULL,
    jam_mulai TIME NOT NULL,
    durasi INT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4");

// =====================
// Validator (sederhana)
// =====================
$input = json_decode(file_get_contents('php://input'), true) ?? [];
$errors = [];

if (!isset($input['anggota_id']) || !is_numeric($input['anggota_id'])) {
    $errors[] = 'anggota_id harus angka';
}
if (!isset($input['tanggal']) || !preg_match('/^\d{4}-\d{2}-\d{2}$/', $input['tanggal'])) {
    $errors[] = 'tanggal harus format YYYY-MM-DD';
}
if (!isset($input['jam_mulai']) || !preg_match('/^\d{2}:\d{2}$/', $input['jam_mulai'])) {
    $errors[] = 'jam_mulai harus format HH:MM';
} elseif ($input['jam_mulai'] < '08:00' || $input['jam_mulai'] > '17:00') {
    $errors[] = 'jam_mulai harus antara 08:00 - 17:00';
}
$durasi = (int) ($input['durasi'] ?? 0);
if ($durasi < 1 || $durasi > 4) {
    $errors[] = 'durasi harus antara 1 - 4 jam';
}

if (!empty($errors)) {
    http_response_code(422);
    echo json_encode(['errors' => $errors]);
    exit;
}

// =====================
// Rate Limiting — max 2 booking per hari per anggota
// =====================
$anggotaId = (int) $input['anggota_id'];
$tanggal   = $input['tanggal'];

$stmt = $pdo->prepare(
    "SELECT COUNT(*) FROM booking_ruang WHERE anggota_id = ? AND tanggal = ?"
);
$stmt->execute([$anggotaId, $tanggal]);
$bookingHariIni = (int) $stmt->fetchColumn();

if ($bookingHariIni >= 2) {
    http_response_code(429);
    echo json_encode([
        'error' => 'Batas booking (2x/hari) tercapai untuk anggota ini',
        'limit' => 2,
        'remaining' => 0,
    ]);
    exit;
}

// =====================
// Simpan Booking
// =====================
$stmt = $pdo->prepare(
    "INSERT INTO booking_ruang (anggota_id, tanggal, jam_mulai, durasi) VALUES (?, ?, ?, ?)"
);
$stmt->execute([$anggotaId, $tanggal, $input['jam_mulai'], $durasi]);

http_response_code(201);
echo json_encode([
    'message'    => 'Booking ruang baca berhasil',
    'booking_id' => (int) $pdo->lastInsertId(),
    'sisa_booking_hari_ini' => 1 - $bookingHariIni,
]);
?>
```
