# Array Functions — Transformasi, Filter & Sort

## Penjelasan
PHP memiliki banyak fungsi array bawaan untuk memanipulasi koleksi data. Berikut yang paling esensial dikelompokkan berdasarkan kegunaan:

**Menambah/Menghapus Elemen:**
- `array_push($arr, ...)` — tambah elemen di akhir
- `array_pop($arr)` — hapus elemen terakhir
- `array_shift($arr)` — hapus elemen pertama
- `array_unshift($arr, ...)` — tambah elemen di awal

**Menggabung/Membandingkan:**
- `array_merge($a, $b)` — gabung dua atau lebih array
- `array_diff($a, $b)` — cari nilai di $a yang tidak ada di $b
- `array_intersect($a, $b)` — cari nilai yang ada di kedua array

**Transformasi:**
- `array_map($callback, $arr)` — terapkan fungsi ke setiap elemen
- `array_filter($arr, $callback)` — saring elemen berdasarkan kondisi
- `array_reduce($arr, $callback, $initial)` — reduksi array jadi satu nilai

**Sortir:**
- `sort($arr)` — urutkan ascending (index direset)
- `rsort($arr)` — urutkan descending (index direset)
- `asort($arr)` — urutkan ascending (pertahankan key-value)
- `ksort($arr)` — urutkan berdasarkan key
- `usort($arr, $callback)` — urutkan dengan logika kustom

**Lainnya:**
- `count($arr)` — hitung jumlah elemen
- `in_array($nilai, $arr)` — cek apakah nilai ada
- `array_key_exists($key, $arr)` — cek apakah key ada

## Fungsi
Memberikan kemampuan transformasi data collection yang efisien tanpa perlu menulis loop manual — kode lebih pendek, lebih jelas, dan lebih cepat dieksekusi.

## Cara Pengimplementasian / Code
```php
<?php
$buku = ["PHP Dasar", "Sejarah", "Algoritma", "Basis Data", "PHP Lanjut"];

// --- MENAMBAH / MENGHAPUS ---
array_push($buku, "Jaringan");
array_unshift($buku, "Pengantar IT");
$terakhirDiambil = array_pop($buku);  // "Jaringan"
$pertamaDiambil = array_shift($buku); // "Pengantar IT"

print_r($buku);
// ["Sejarah", "Algoritma", "Basis Data", "PHP Lanjut", "PHP Dasar"]

// --- MENGGABUNG ---
$bukuBaru = ["Framework Laravel", "React untuk Pemula"];
$koleksi = array_merge($buku, $bukuBaru);
print_r($koleksi);

// --- FILTER ---
$angka = [1, 50, 23, 100, 75, 10];

$genap = array_filter($angka, fn($n) => $n % 2 === 0);
print_r($genap); // [1 => 50, 3 => 100, 5 => 10]

// --- TRANSFORMASI ---
$dikalikan10 = array_map(fn($n) => $n * 10, $angka);
print_r($dikalikan10); // [10, 500, 230, 1000, 750, 100]

// --- REDUKSI ---
$total = array_reduce($angka, fn($carry, $n) => $carry + $n, 0);
echo "$total\n"; // 259

// --- SORTIR ---
$nilai = [85, 92, 78, 95, 88];
sort($nilai); // ascending, index direset
print_r($nilai); // [78, 85, 88, 92, 95]

$bukuAsosiatif = [
    "B001" => "PHP Dasar",
    "B003" => "Algoritma",
    "B002" => "Sejarah"
];
ksort($bukuAsosiatif); // urut berdasarkan key
print_r($bukuAsosiatif);
// ["B001" => "PHP Dasar", "B002" => "Sejarah", "B003" => "Algoritma"]

// --- CEK ---
echo count($nilai) . "\n";         // 5
echo in_array("Sejarah", $buku) ? "Ada" : "Tidak ada"; // Ada
echo array_key_exists("B001", $bukuAsosiatif) ? "Ada" : "Tidak ada"; // Ada
?>
```

## Analogi
Array functions seperti **berbagai prosedur operasional di perpustakaan**: `array_push` = petugas menambahkan buku baru ke ujung rak, `array_pop` = mengambil buku terakhir dari ujung rak, `array_merge` = menggabungkan dua katalog menjadi satu, `array_filter` = menyaring buku yang sudah kadaluarsa (tahun terbit > 20 tahun), `array_map` = petugas mengganti semua label buku lama dengan label baru sesuai format terkini, `array_reduce` = menghitung total seluruh buku di semua rak, `sort` = menata ulang buku berdasarkan abjad, `in_array` = mengecek apakah judul tertentu ada di koleksi.

## Dipakai untuk Apa
- **Menyiapkan data untuk view**: filter produk yang tersedia, mapping format tampilan
- **Sortir data**: daftar pengguna berdasarkan nama, produk berdasarkan harga
- **Agregasi**: total penjualan, rata-rata rating dari array nilai
- **Diff data**: cari item baru yang tidak ada di database (sinkronisasi)
- **Merge konfigurasi**: `array_merge($defaultConfig, $userConfig)`
- **Bulk operation**: terapkan diskon ke semua harga produk

## Kesalahan Umum yang Sering Terjadi
- **`sort` memodifikasi array asli**: `sort` mengubah array yang diberikan (pass by reference), bukan mengembalikan array baru.
- **Lupa `array_filter` mempertahankan key**: Hasil filter bisa punya index loncat (0, 2, 5) — gunakan `array_values()` untuk reset index.
- **Callback `array_map` urutan argumen**: `array_map(callback, array)` — callback menerima elemen array, bukan index.
- **`in_array` perbandingan longgar**: `in_array("85", $nilai)` akan true walau 85 integer vs string — gunakan `strict => true` jika perlu.
- **`array_merge` dengan numeric key**: Akan me-reset index jadi 0, 1, 2... — untuk mempertahankan key gunakan operator `+`.

## Soal Latihan & Jawaban
### Soal
Petugas punya array `$denda = [["nama" => "Andi", "denda" => 5000], ["nama" => "Budi", "denda" => 0], ["nama" => "Citra", "denda" => 15000], ["nama" => "Dewi", "denda" => 0]]`. Filter hanya yang punya denda > 0, lalu mapping untuk menampilkan string "Andi: Rp5.000" (format rupiah), lalu gabung dengan koma.

### Jawaban
```php
<?php
$denda = [
    ["nama" => "Andi", "denda" => 5000],
    ["nama" => "Budi", "denda" => 0],
    ["nama" => "Citra", "denda" => 15000],
    ["nama" => "Dewi", "denda" => 0]
];

$berdenda = array_filter($denda, fn($item) => $item["denda"] > 0);
$laporan = array_map(fn($item) => $item["nama"] . ": Rp" . number_format($item["denda"]), $berdenda);

echo implode(", ", $laporan);
// Output: Andi: Rp5.000, Citra: Rp15.000
?>
```
