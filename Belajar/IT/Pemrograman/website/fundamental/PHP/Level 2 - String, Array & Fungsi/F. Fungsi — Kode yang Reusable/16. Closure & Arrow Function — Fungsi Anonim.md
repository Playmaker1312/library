# Closure & Arrow Function — Fungsi Anonim

## Penjelasan
**Fungsi anonim** (*anonymous function*/closure) adalah fungsi tanpa nama. Di PHP ada dua bentuk:

**1. Closure (fungsi anonim)**
- Ditulis tanpa nama, bisa di-assign ke variabel
- Dapat mengakses variabel dari scope luar dengan `use ($var)`
- Sintaks: `$nama = function($param) use ($var) { ... };`

**2. Arrow Function (PHP 7.4+)**
- Sintaks lebih pendek dengan `fn`
- **Otomatis** mengakses variabel dari parent scope (tidak perlu `use`)
- Hanya bisa berisi satu ekspresi (tanpa kurung kurawal blok multi-baris)
- Sintaks: `$nama = fn($param) => $ekspresi;`

Keduanya sering digunakan sebagai **callback** — fungsi yang dikirim sebagai argumen ke fungsi lain seperti `array_map`, `array_filter`, `usort`, dll.

## Fungsi
Memungkinkan pembuatan fungsi kecil secara *inline* di tempat yang membutuhkan, tanpa harus mendefinisikan fungsi bernama terpisah. Arrow function memberikan sintaks yang lebih bersih untuk callback sederhana.

## Cara Pengimplementasian / Code
```php
<?php
// --- CLOSURE ---

// Closure di-assign ke variabel
$sapa = function($nama) {
    return "Halo, $nama!";
};
echo $sapa("Andi") . "\n"; // "Halo, Andi!"

// Closure dengan use() — mengakses variabel dari luar
$dendaPerHari = 2000;
$hitungDenda = function(int $hari) use ($dendaPerHari) {
    return $hari * $dendaPerHari;
};
echo $hitungDenda(5) . "\n"; // 10000

// use() dengan reference (&) — bisa mengubah variabel asli
$totalDenda = 0;
$tambahDenda = function(int $nominal) use (&$totalDenda) {
    $totalDenda += $nominal;
};
$tambahDenda(5000);
$tambahDenda(3000);
echo "Total denda: $totalDenda\n"; // 8000

// Closure sebagai callback
$buku = ["PHP Dasar", "Algoritma", "Sejarah", "Basis Data"];
$bukuPanjang = array_filter($buku, function($item) {
    return strlen($item) > 7;
});
print_r($bukuPanjung); // ["Algoritma", "Basis Data"]

// --- ARROW FUNCTION (PHP 7.4+) ---

// Arrow function sederhana
$kaliDua = fn($x) => $x * 2;
echo $kaliDua(10) . "\n"; // 20

// Arrow function otomatis mengakses parent scope (tanpa use)
$pajak = 0.11;
$hitungPajak = fn(int $harga) => $harga + ($harga * $pajak);
echo $hitungPajak(50000) . "\n"; // 55500

// Arrow function sebagai callback — jauh lebih pendek
$angka = [1, 2, 3, 4, 5, 6];
$genap = array_filter($angka, fn($n) => $n % 2 === 0);
print_r($genap); // [2, 4, 6]

$kuadrat = array_map(fn($n) => $n * $n, $angka);
print_r($kuadrat); // [1, 4, 9, 16, 25]

// usort dengan arrow function
$data = ["PHP", "Algoritma", "C", "JavaScript"];
usort($data, fn($a, $b) => strlen($a) <=> strlen($b));
print_r($data); // ["C", "PHP", "Algoritma", "JavaScript"]
?>
```

## Analogi
Closure seperti **petugas lepas harian** di perpustakaan — mereka tidak punya nama tetap (anonim), datang untuk tugas spesifik, dan bisa "membawa" informasi dari luar (seperti `use` membawa data dari ruang utama ke petugas). Arrow function seperti **petugas yang hanya punya satu instruksi sederhana** — misalnya petugas yang hanya bertugas "stempel tanggal kembali" — langsung selesai dalam satu langkah, tanpa perlu buku panduan tebal. Keduanya sering dipanggil untuk membantu petugas utama (fungsi seperti `array_filter`) melakukan tugas spesifik.

## Dipakai untuk Apa
- **Callback untuk array functions**: `array_map`, `array_filter`, `array_reduce`, `usort`
- **Event handler**: Fungsi yang dijalankan saat event tertentu terjadi
- **Function factory**: Closure yang mengembalikan closure lain
- **Data pipeline**: Rantai transformasi data dengan `array_map` + `array_filter`
- **Middleware / router**: Callback untuk menangani request HTTP
- **Lazy initialization**: Nilai dihitung hanya saat dibutuhkan

## Kesalahan Umum yang Sering Terjadi
- **Lupa `use` di closure**: Variabel dari luar tidak bisa diakses tanpa `use` — hasilnya `Undefined variable`.
- **Closure meng-copy nilai, bukan reference**: `use ($var)` mengambil *copy* nilai saat closure dibuat — jika `$var` berubah setelahnya, closure tetap pakai nilai lama. Gunakan `use (&$var)` untuk reference.
- **Arrow function multi-baris**: Arrow function (`fn`) hanya bisa satu ekspresi. Jika perlu beberapa baris, gunakan closure biasa.
- **Arrow function tidak bisa `return` eksplisit**: Ekspresi setelah `=>` otomatis menjadi return value — tidak perlu (dan tidak bisa) menulis `return`.
- **Urutan parameter callback**: `array_map` callback menerima elemen dulu; `usort` callback menerima `$a, $b`. Cek dokumentasi.

## Soal Latihan & Jawaban
### Soal
Petugas punya array `$anggota = ["Andi", "Budi", "Citra", "Dewi", "Eko"]`. Gunakan `array_filter` dengan arrow function untuk mengambil anggota yang namanya memiliki panjang >= 4 karakter. Lalu gunakan `array_map` dengan closure untuk mengubah setiap nama menjadi "Anggota: [Nama] — Status: Aktif". Tampilkan hasilnya.

### Jawaban
```php
<?php
$anggota = ["Andi", "Budi", "Citra", "Dewi", "Eko"];

$filtered = array_filter($anggota, fn($nama) => strlen($nama) >= 4);

$laporan = array_map(function($nama) {
    return "Anggota: $nama — Status: Aktif";
}, $filtered);

print_r($laporan);
/*
Array (
    [1] => Anggota: Budi — Status: Aktif
    [2] => Anggota: Citra — Status: Aktif
    [3] => Anggota: Dewi — Status: Aktif
)
*/
?>
```
