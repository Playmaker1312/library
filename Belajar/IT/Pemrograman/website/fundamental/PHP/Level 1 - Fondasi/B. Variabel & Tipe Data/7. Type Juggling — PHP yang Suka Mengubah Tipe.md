# Type Juggling — PHP yang Suka Mengubah Tipe

## Penjelasan
PHP adalah bahasa **dynamically typed** yang memiliki fitur *type juggling* (atau *type coercion*). Artinya, PHP secara otomatis mengubah tipe data suatu nilai tergantung konteks penggunaannya — kamu tidak perlu (dan tidak bisa) memaksa sebuah variabel untuk memiliki satu tipe tetap.

Contoh: jika kamu menjumlahkan string `"10"` dengan integer `5`, PHP otomatis mengubah string `"10"` menjadi integer `10`, lalu menjumlahkannya menjadi `15`. Jika kamu menggabungkan string `"Buku "` dengan angka `5`, PHP mengubah angka `5` menjadi string `"5"` — hasilnya `"Buku 5"`.

Aturan konversi otomatis:
- String numerik → diubah ke number saat operasi matematika
- Boolean `true` → jadi `1` di konteks angka; `false` → `0`
- Null → jadi string `""` atau angka `0` tergantung konteks
- Array, object, resource → tidak bisa di-juggling ke scalar

## Fungsi
Membuat PHP lebih fleksibel dan "ramah" — kamu tidak perlu ribet melakukan konversi manual untuk operasi sederhana. Ini berguna terutama saat menangani input dari form (yang selalu berupa string).

## Cara Pengimplementasian / Code
```php
<?php
// String ke integer (penjumlahan)
$total = "10" + 5;           // 15 (string "10" diubah ke int)
echo "10 + 5 = $total\n";

// Integer ke string (penggabungan)
$pesan = "Jumlah buku: " . 7; // "Jumlah buku: 7"
echo "$pesan\n";

// Boolean ke integer
$tersedia = true;
echo "Tersedia: " . ($tersedia + 0) . "\n"; // 1

// String ke float
$harga = "25000.50" * 2;     // 50001 (float)
echo "Harga x2: $harga\n";

// Null dalam operasi
$stok = null;
echo "Stok: " . ($stok + 10) . "\n"; // 10 (null jadi 0)

// Perbandingan longgar (==) vs ketat (===)
var_dump("10" == 10);   // bool(true)  — type juggling, nilai sama
var_dump("10" === 10);  // bool(false) — tipe berbeda

// Jebakan: concat vs tambah
echo "5" + "3" . "\n";   // 8 (penjumlahan)
echo "5" . "3" . "\n";   // "53" (penggabungan string)
?>
```

## Analogi
Di perpustakaan, ada kotak masuk bernama "Drop Box" untuk pengembalian buku. Pengunjung memasukkan apa pun: buku, majalah, DVD, catatan. Petugas (PHP) secara otomatis mengelompokkan isinya ke rak yang sesuai — buku ke rak buku, DVD ke rak DVD — tanpa perlu pengunjung memberi label. Tapi kadang petugas salah: jika pengunjung memasukkan novel ke kotak "referensi", petugas tetap menerimanya dan meletakkannya di rak referensi (type juggling). Kadang cocok, kadang tidak. Makanya terkadang kamu perlu mengecek tipe secara manual.

## Dipakai untuk Apa
- Memproses input form (semua input dari `$_POST`/`$_GET` adalah string — type juggling memudahkan perbandingan dengan angka)
- Operasi matematika dari data yang sumbernya tidak konsisten tipenya
- Perbandingan nilai dari database (integer dari DB vs string dari input)
- Memudahkan rapid prototyping — tidak perlu mikir tipe data

## Kesalahan Umum yang Sering Terjadi
- **Perbandingan longgar (`==`) dengan string "0" vs false**: `"0" == false` menghasilkan `true` — bisa jadi bug logika.
- **Operasi plus (`+`) vs concat (`.`)**: Tertukar antara `+` (aritmatika) dan `.` (string). Contoh: `echo "5" + "3"` = `8`, bukan `"53"`.
- **Mengandalkan type juggling berlebihan**: Kode jadi tidak terprediksi. Pakai `===` (perbandingan ketat) untuk keamanan.
- **String non-numerik dioperasi matematika**: `"abc" + 5` hasilnya `5` (string `"abc"` diubah ke `0`), tanpa error — hanya warning di PHP 8+.

## Hubungan dengan Materi Sebelumnya
Materi sebelumnya (variabel) memperkenalkan bahwa variabel bisa menampung data apa pun. Type juggling adalah konsekuensi dari dinamika itu: karena tipe tidak tetap, PHP harus cerdas mengonversi. Ini penting dipahami sebelum belajar operator (materi 10) dan perbandingan, karena type juggling memengaruhi hasil operasi.

## Soal Latihan & Jawaban
### Soal
Di perpustakaan, ada data berikut:
- `$jumlahBuku` = "12" (string)
- `$jumlahRak` = 3 (integer)
- `$namaRak` = "Rak A"

Prediksi output dari kode berikut (tanpa menjalankan), lalu tulis kode untuk membuktikannya:
1. `echo $jumlahBuku + $jumlahRak;`
2. `echo $namaRak . $jumlahRak;`
3. `var_dump($jumlahBuku == $jumlahRak * 4);`
4. `echo $namaRak + $jumlahBuku;`

### Jawaban
```php
<?php
$jumlahBuku = "12";  // string
$jumlahRak = 3;       // integer
$namaRak = "Rak A";   // string

echo "1. " . ($jumlahBuku + $jumlahRak) . "\n";
// 15 — string "12" diubah ke int 12, 12 + 3 = 15

echo "2. " . ($namaRak . $jumlahRak) . "\n";
// "Rak A3" — integer 3 diubah ke string "3", digabung

echo "3. ";
var_dump($jumlahBuku == $jumlahRak * 4);
// bool(true) — 12 == 12, type juggling membuat "12" == 12 true

echo "4. " . ($namaRak + $jumlahBuku) . "\n";
// 12 — string "Rak A" diubah ke int 0, 0 + 12 = 12 (Warning di PHP 8+)
?>
```
