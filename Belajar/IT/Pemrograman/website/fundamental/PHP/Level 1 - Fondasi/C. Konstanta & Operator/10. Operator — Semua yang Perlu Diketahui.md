# Operator — Semua yang Perlu Diketahui

## Penjelasan
Operator adalah simbol yang memberitahu PHP untuk melakukan suatu operasi (matematika, perbandingan, logika, dll.) pada satu atau lebih nilai (operand). Jenis-jenis operator di PHP:

1. **Aritmatika**: `+`, `-`, `*`, `/`, `%` (modulus), `**` (pangkat)
2. **Assignment**: `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `.=`
3. **Perbandingan**: `==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`, `<=>` (spaceship)
4. **Logika**: `&&` / `and`, `||` / `or`, `!` / `not`, `xor`
5. **String**: `.` (concatenation), `.=`
6. **Increment/Decrement**: `++$x`, `$x++`, `--$x`, `$x--`
7. **Array**: `+` (union), `==`, `===`, `!=`, `<>`, `!==`
8. **Ternary**: `$x ? $a : $b`
9. **Null coalescing**: `$x ?? $default` (PHP 7+)
10. **Spaceship**: `$a <=> $b` (PHP 7+ — return -1, 0, atau 1)

## Fungsi
Operator adalah alat untuk memanipulasi data — menghitung, membandingkan, menggabungkan, mengevaluasi kondisi. Tanpa operator, variabel hanya bisa menyimpan nilai statis tanpa bisa diproses lebih lanjut.

## Cara Pengimplementasian / Code
```php
<?php
// 1. ARITMATIKA
$a = 10;
$b = 3;
echo "10 + 3 = " . ($a + $b) . "\n";    // 13
echo "10 - 3 = " . ($a - $b) . "\n";    // 7
echo "10 * 3 = " . ($a * $b) . "\n";    // 30
echo "10 / 3 = " . ($a / $b) . "\n";    // 3.3333
echo "10 % 3 = " . ($a % $b) . "\n";    // 1 (sisa bagi)
echo "10 ** 3 = " . ($a ** $b) . "\n";  // 1000 (pangkat)

// 2. ASSIGNMENT
$total = 0;
$total += 50;   // $total = $total + 50
$total -= 10;   // $total = $total - 10
$total *= 2;    // $total = $total * 2
echo "Total: $total\n";                 // 80

// 3. PERBANDINGAN
var_dump(5 == "5");   // true  (longgar)
var_dump(5 === "5");  // false (ketat — tipe beda)
var_dump(5 != "5");   // false (longgar)
var_dump(5 !== "5");  // true  (ketat)
var_dump(7 <=> 5);    // 1   (7 > 5)
var_dump(5 <=> 5);    // 0   (sama)
var_dump(3 <=> 5);    // -1  (3 < 5)

// 4. LOGIKA
$isMember = true;
$isLibrarian = false;
var_dump($isMember && $isLibrarian); // false (AND)
var_dump($isMember || $isLibrarian); // true  (OR)
var_dump(!$isMember);                // false (NOT)

// 5. STRING
$namaDepan = "Perpustakaan";
$namaBelakang = "Digital";
$gabung = $namaDepan . " " . $namaBelakang; // concat
echo "$gabung\n"; // "Perpustakaan Digital"

$gabung .= " Nasional"; // $gabung = $gabung . " Nasional"
echo "$gabung\n";       // "Perpustakaan Digital Nasional"

// 6. INCREMENT/DECREMENT
$counter = 5;
echo $counter++ . "\n"; // 5 (post-increment: tampilkan dulu, lalu +1)
echo $counter . "\n";   // 6
echo ++$counter . "\n"; // 7 (pre-increment: +1 dulu, lalu tampilkan)

// 7. TERNARY
$stok = 0;
$status = $stok > 0 ? "Tersedia" : "Kosong";
echo "Status: $status\n";

// 8. NULL COALESCING
$denda = null;
$biaya = $denda ?? 2000; // jika $denda null, pakai 2000
echo "Biaya: $biaya\n";

// Prioritas operator
echo "5 + 3 * 2 = " . (5 + 3 * 2) . "\n";     // 11 (perkalian dulu)
echo "(5 + 3) * 2 = " . ((5 + 3) * 2) . "\n"; // 16 (parentheses override)
?>
```

## Analogi
Perpustakaan punya prosedur operasional:
- **Aritmatika**: Menghitung total denda (jumlah hari x tarif), menghitung jumlah buku per rak.
- **Assignment**: Memperbarui stok buku setelah peminjaman (`$stok -= 1`).
- **Perbandingan**: Memeriksa apakah anggota sudah terdaftar (`$isMember === true`).
- **Logika**: Mengizinkan akses hanya jika anggota **dan** buku tersedia.
- **String**: Menggabungkan nomor rak dan nomor urut menjadi kode buku.
- **Ternary**: Menentukan label "Tersedia" atau "Dipinjam" berdasarkan kondisi.
- **Null coalescing**: Jika data peminjam kosong, gunakan default "Anonim".

## Dipakai untuk Apa
- **Aritmatika**: Menghitung harga, jumlah halaman, denda, statistik
- **Perbandingan**: Filter data, validasi login, cek otorisasi
- **Logika**: Kontrol akses (admin/user), menentukan aksi berdasarkan kondisi
- **String**: Membangun query SQL, generate kode buku, format output
- **Ternary/Null coalescing**: Menyederhanakan if-else pendek, default values
- **Spaceship**: Sorting array multidimensional, pengurutan data

## Kesalahan Umum yang Sering Terjadi
- **Tertukar `=` (assignment) dengan `==` (perbandingan)**: `if ($a = 5)` akan selalu true karena meng-assign 5 ke $a. Harusnya `$a == 5`.
- **Salah prioritas operator**: `5 + 3 * 2` = 11, bukan 16. Pakai kurung jika ragu.
- **`++$x` vs `$x++`**: Pre-increment vs post-increment — salah paham bisa menyebabkan bug kenaikan.
- **Menggunakan `and`/`or` vs `&&`/`||`**: Berbeda prioritas. `$x = true and false` — `$x` bernilai `true` karena `=` lebih kuat dari `and`. Jika pakai `&&`, hasilnya `false`.
- **Perbandingan longgar `==` untuk string "0"**: `"0" == false` = `true`, `"0" == null` = `true`. Sumber bug umum.

## Hubungan dengan Materi Sebelumnya
Operator adalah alat yang menggerakkan data. Di materi 6-8 kamu belajar menyimpan data (variabel), mengubahnya otomatis (type juggling), dan mengonversinya secara manual (type casting). Sekarang dengan operator, kamu bisa mulai memproses data itu: menjumlah, membandingkan, menggabungkan, dan mengambil keputusan. Operator adalah "tangan" yang bekerja dengan data.

## Soal Latihan & Jawaban
### Soal
Buat program perpustakaan yang menghitung denda keterlambatan:
- `$hariPinjam` = 14 (hari seharusnya dikembalikan)
- `$hariKembali` = 18 (hari aktual pengembalian)
- `$dendaPerHari` = 1500

Hitung:
1. Jumlah hari terlambat (gunakan operator aritmatika)
2. Total denda (hari terlambat × denda per hari)
3. Cek apakah denda > 5000 (gunakan perbandingan)
4. Tampilkan pesan: jika total ≥ 10000, "Denda besar" ; jika < 10000, "Denda ringan" (gunakan ternary)
5. Tampilkan semua hasil

### Jawaban
```php
<?php
$hariPinjam = 14;
$hariKembali = 18;
$dendaPerHari = 1500;

$hariTelat = $hariKembali - $hariPinjam;
$totalDenda = $hariTelat * $dendaPerHari;
$dendaBesar = $totalDenda >= 10000;
$pesan = $totalDenda >= 10000 ? "Denda besar" : "Denda ringan";

echo "Hari keterlambatan: $hariTelat hari\n";
echo "Total denda: Rp" . number_format($totalDenda) . "\n";
echo "Denda >= Rp10.000? " . ($dendaBesar ? "Ya" : "Tidak") . "\n";
echo "Kategori: $pesan\n";
?>
```
