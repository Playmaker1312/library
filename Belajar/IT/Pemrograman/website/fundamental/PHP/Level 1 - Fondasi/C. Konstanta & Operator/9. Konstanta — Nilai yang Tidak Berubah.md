# Konstanta — Nilai yang Tidak Berubah

## Penjelasan
Konstanta adalah wadah untuk menyimpan nilai yang — tidak seperti variabel — **tidak bisa diubah** setelah dideklarasikan. Begitu konstanta diberi nilai, nilai itu tetap selama eksekusi program. Jika kamu mencoba mengubahnya, PHP akan mengeluarkan notice dan mengabaikan perubahan tersebut.

Cara mendefinisikan konstanta:
1. **`define()`**: Fungsi untuk membuat konstanta. Bisa dipanggil di mana saja, termasuk di dalam blok kode.
2. **Keyword `const`**: Tersedia sejak PHP 5.3. Harus dideklarasikan di level teratas (tidak bisa di dalam loop atau if).

Perbedaan utama konstanta vs variabel:
- Konstanta tidak didahului `$`
- Konstanta hanya bisa diberi nilai sekali
- Konstanta secara otomatis bersifat *global* — bisa diakses dari mana saja
- Nama konstanta case-sensitive secara default (kecuali parameter `case_insensitive` di `define()`)
- Konstanta hanya bisa menyimpan nilai scalar (bool, int, float, string) atau array (sejak PHP 7)

## Fungsi
Menyimpan nilai tetap yang digunakan berulang kali di seluruh aplikasi — seperti nama aplikasi, versi, konfigurasi database, atau kode tetap lainnya. Ini mencegah "magic numbers" dan memudahkan perubahan di satu tempat.

## Cara Pengimplementasian / Code
```php
<?php
// Cara 1: define()
define("NAMA_PERPUSTAKAAN", "Perpustakaan Ilmu Pengetahuan");
define("TAHUN_BERDIRI", 2025);
define("VERSI_SISTEM", "1.0.0");
define("MAX_PINJAM_BUKU", 5);
define("IS_OPEN", true);

// Cara 2: const (harus di top-level scope)
const DENDA_PER_HARI = 2000;
const KATEGORI_BUKU = ["Fiksi", "Non-Fiksi", "Referensi", "Ilmiah"];

// Menggunakan konstanta
echo "Selamat datang di " . NAMA_PERPUSTAKAAN . "\n";
echo "Berdiri tahun: " . TAHUN_BERDIRI . "\n";
echo "Denda keterlambatan: Rp" . DENDA_PER_HARI . "/hari\n";
echo "Maksimal pinjam: " . MAX_PINJAM_BUKU . " buku\n";

// Konstanta array
echo "Kategori: " . implode(", ", KATEGORI_BUKU) . "\n";

// Magic constants (bawaan PHP)
echo "File ini: " . __FILE__ . "\n";
echo "Baris ini: " . __LINE__ . "\n";
echo "Folder ini: " . __DIR__ . "\n";

// Mencoba mengubah konstanta — akan error notice
// define("NAMA_PERPUSTAKAAN", "Baru"); // Notice: Constant already defined
// NAMA_PERPUSTAKAAN = "Baru"; // Parse error: syntax error
?>
```

## Analogi
Konstanta seperti **plang nama perpustakaan** yang dipasang di depan gedung. Nama itu permanen — tidak bisa diganti setiap hari. Setiap kali ada pengunjung bertanya "Ini perpustakaan apa?", kamu tinggal menunjuk plang itu. Jika kamu ingin mengganti nama, kamu harus mengganti plang secara sadar (mengedit definisi konstanta), bukan menempel plang baru di atasnya. Berbeda dengan variabel yang seperti papan pengumuman (isinya bisa diganti kapan saja).

## Dipakai untuk Apa
- Menyimpan konfigurasi tetap: nama aplikasi, versi, API key, URL base
- Mendefinisikan kode tetap: status code, role user, limit angka
- Konstanta matematika/fisika: `PI`, `GRAVITASI`, `SPEED_OF_LIGHT`
- Status enum: `STATUS_AKTIF`, `STATUS_NONAKTIF`, `STATUS_TUNDA`
- Database credentials di file konfigurasi (jangan di-hardcode di file utama)
- Magic constants untuk debugging: `__FILE__`, `__LINE__`, `__DIR__`

## Kesalahan Umum yang Sering Terjadi
- **Lupa bahwa konstanta tidak punya `$`**: Menulis `$NAMA_PERPUSTAKAAN` akan membuat variabel baru, bukan mengakses konstanta.
- **Mendefinisikan ulang konstanta**: Menyebabkan `Notice: Constant already defined`. Selalu cek dengan `defined()` sebelum `define()`.
- **Menggunakan konstanta di dalam string quoted**: `"Nama: NAMA_PERPUSTAKAAN"` tidak akan diekstrak. Harus pakai concatenation `.` atau gunakan variabel.
- **Menempatkan `const` di dalam loop/if**: Tidak bisa. `const` hanya untuk top-level scope. Gunakan `define()` jika butuh kondisi.
- **Menganggap konstanta bisa diubah**: Tidak bisa. Jika butuh nilai yang bisa berubah, pakai variabel.

## Hubungan dengan Materi Sebelumnya
Setelah variabel (materi 6), konstanta adalah "saudara" yang lebih kaku. Di materi 9 ini kamu belajar membedakan kapan pakai variabel (data yang berubah) dan kapan pakai konstanta (data tetap). Pengetahuan ini mendukung semua materi selanjutnya, terutama saat membuat konfigurasi aplikasi dan menghindari hardcode nilai berulang.

## Soal Latihan & Jawaban
### Soal
Buat sistem informasi perpustakaan dengan konstanta-konstanta berikut:
- `NAMA_PERPUS` = "Perpustakaan Digital Nasional"
- `DENDA_PER_HARI` = 1500
- `MAX_HARI_PINJAM` = 14
- `JAM_BUKA` = "08:00"
- `JAM_TUTUP` = "20:00"

Tampilkan info perpustakaan dalam format:
```
=== Perpustakaan Digital Nasional ===
Jam Operasional: 08:00 - 20:00
Denda: Rp1.500/hari
Maksimal Pinjam: 14 hari
```

### Jawaban
```php
<?php
define("NAMA_PERPUS", "Perpustakaan Digital Nasional");
const DENDA_PER_HARI = 1500;
define("MAX_HARI_PINJAM", 14);
define("JAM_BUKA", "08:00");
define("JAM_TUTUP", "20:00");
?>
<!DOCTYPE html>
<html>
<head>
    <title><?= NAMA_PERPUS ?></title>
</head>
<body>
    <h1>=== <?= NAMA_PERPUS ?> ===</h1>
    <p>Jam Operasional: <?= JAM_BUKA ?> - <?= JAM_TUTUP ?></p>
    <p>Denda: Rp<?= number_format(DENDA_PER_HARI) ?>/hari</p>
    <p>Maksimal Pinjam: <?= MAX_HARI_PINJAM ?> hari</p>
</body>
</html>
```
