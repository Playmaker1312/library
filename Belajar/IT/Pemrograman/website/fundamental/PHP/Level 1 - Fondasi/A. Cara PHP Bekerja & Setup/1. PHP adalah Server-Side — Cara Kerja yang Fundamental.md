# PHP adalah Server-Side — Cara Kerja yang Fundamental

## Penjelasan
PHP (Hypertext Preprocessor) adalah bahasa pemrograman *server-side*, artinya kode PHP tidak dijalankan di komputer pengguna (browser/client), melainkan di server. Saat user mengakses file `.php` melalui browser, request dikirim ke server. Server membaca file PHP, menjalankan instruksi di dalamnya (misalnya mengambil data dari database, memproses form, dll.), lalu menghasilkan output HTML **murni** yang dikirim kembali ke browser. Browser hanya melihat hasil HTML — kode PHP-nya tidak pernah terlihat oleh user.

Alur kerja PHP:
1. User mengetik URL di browser → mengirim HTTP Request ke server.
2. Server (Apache/Nginx) menerima request dan melihat file `.php`.
3. Server meneruskan file ke interpreter PHP (PHP engine).
4. PHP memproses kode, menghasilkan output (biasanya HTML).
5. Server mengirim HTTP Response berisi HTML tadi ke browser.
6. Browser merender HTML dan menampilkannya ke user.

## Fungsi
Menjadi "jembatan" antara data di server (database, file system) dengan tampilan di browser. PHP memungkinkan halaman web menjadi dinamis — konten berubah-ubah tergantung logika, data, atau input user — tanpa harus mengubah file HTML secara manual.

## Cara Pengimplementasian / Code
```php
<?php
// File: index.php
// Kode PHP ditulis di dalam tag <?php ... ?>
$waktu = date("H");
if ($waktu < 12) {
    $salam = "Selamat pagi";
} else {
    $salam = "Selamat siang";
}
?>
<!DOCTYPE html>
<html>
<head>
    <title>Cara Kerja PHP</title>
</head>
<body>
    <h1><?php echo $salam; ?></h1>
    <p>Sekarang jam <?php echo date("H:i"); ?></p>
    <p>Lihat sumber halaman ini — kamu tidak akan melihat kode PHP-nya.</p>
</body>
</html>
```

Jalankan di browser melalui `http://localhost/level1/1.php` (setelah setup XAMPP/Laragon).

## Analogi
Bayangkan perpustakaan besar. Kamu (user) datang ke loket dan meminta rekomendasi buku tentang "sejarah Indonesia". Pustakawan (PHP) masuk ke gudang (server/database), mencari buku yang sesuai (logika PHP), mencatat judul dan lokasi bukunya di secarik kertas (output HTML), lalu memberikan kertas itu kepadamu. Kamu hanya menerima kertas hasil catatan — kamu tidak pernah melihat bagaimana pustakawan mencari di dalam gudang. Kertas itu adalah HTML; proses di gudang adalah kode PHP.

## Dipakai untuk Apa
- Website dinamis (portal berita, toko online, blog, forum)
- Sistem login dan otentikasi pengguna
- Aplikasi web berbasis data (sistem perpustakaan digital, inventory)
- REST API backend untuk mobile app
- CMS seperti WordPress, Joomla, Drupal

## Kesalahan Umum yang Sering Terjadi
- **Mengklik file .php langsung di Windows Explorer**: File akan terbuka sebagai teks mentah, tidak dijalankan. Harus diakses melalui `http://localhost/...`.
- **Menyangka kode PHP bisa dilihat user**: Tidak mungkin karena sudah diproses di server. Yang sampai ke browser hanyalah output HTML.
- **Tidak menjalankan server lokal**: File `.php` tidak akan berfungsi tanpa server (XAMPP/Laragon) yang aktif.

## Hubungan dengan Materi Sebelumnya
Ini adalah fondasi paling dasar. Semua materi selanjutnya (variabel, fungsi, database, OOP) adalah "alat" yang digunakan PHP di dalam server untuk menghasilkan output yang lebih kompleks. Paham alur request-response ini penting agar kamu tidak bingung saat nanti belajar form, session, atau API.

## Soal Latihan & Jawaban
### Soal
Seorang petugas perpustakaan ingin membuat halaman sambutan dinamis. Jika saat ini jam 10.00, tulislah kode PHP & HTML yang menampilkan "Selamat datang di Perpustakaan Digital — Jam: 10:00". Gunakan variabel untuk menyimpan pesan dan jam.

### Jawaban
```php
<?php
$jam = date("H:i");
$pesan = "Selamat datang di Perpustakaan Digital — Jam: $jam";
?>
<!DOCTYPE html>
<html>
<head>
    <title>Perpustakaan Digital</title>
</head>
<body>
    <h1><?php echo $pesan; ?></h1>
</body>
</html>
```
