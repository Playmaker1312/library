# Menggabungkan PHP dan HTML — Cara yang Benar

## Penjelasan
PHP dirancang untuk disisipkan ke dalam HTML. Ada dua pendekatan utama:

1. **Embedding (PHP di dalam HTML)**: Menulis tag `<?php ... ?>` di tengah-tengah template HTML. Ini paling umum untuk view/tampilan.
2. **Mencetak HTML dari dalam PHP**: Menggunakan `echo` atau `print` untuk mencetak tag HTML sebagai string.

Keduanya sah, tapi untuk keterbacaan dan maintainability, pendekatan embedding lebih disarankan. Di file `.php`, kamu bisa bolak-balik antara mode HTML dan PHP kapan saja.

Aturan penting:
- Blok PHP bisa ditaruh di mana saja dalam file `.php`
- File `.php` boleh berisi HTML tanpa kode PHP sama sekali (tapi percuma)
- Kamu bisa buka-tutup tag `<?php ... ?>` berkali-kali dalam satu file

## Fungsi
Memungkinkan halaman web statis (HTML) berubah menjadi dinamis dengan logika PHP. Contoh: menampilkan nama user yang login, daftar buku dari database, atau konten yang berbeda berdasarkan waktu.

## Cara Pengimplementasian / Code
### Embedding (PHP di dalam HTML):
```php
<!DOCTYPE html>
<html>
<head>
    <title><?php echo $pageTitle; ?></title>
</head>
<body>
    <h1><?php echo $pageTitle; ?></h1>
    <ul>
    <?php for ($i = 1; $i <= 5; $i++): ?>
        <li>Buku nomor <?php echo $i; ?></li>
    <?php endfor; ?>
    </ul>
</body>
</html>
```

### Mencetak HTML dari dalam PHP:
```php
<?php
$pageTitle = "Daftar Buku";
echo "<!DOCTYPE html>";
echo "<html><head><title>$pageTitle</title></head><body>";
echo "<h1>$pageTitle</h1>";
echo "<ul>";
for ($i = 1; $i <= 5; $i++) {
    echo "<li>Buku nomor $i</li>";
}
echo "</ul>";
echo "</body></html>";
```

### Short echo tag (<?=):
```php
<h1><?= $pageTitle ?></h1>
<!-- Sama dengan: <?php echo $pageTitle; ?> -->
```

## Analogi
Perpustakaan memiliki formulir cetak (HTML) dengan kolom-kolom kosong. Pustakawan (PHP) mengisi kolom-kolom itu dengan data dari katalog (logika/database). Pengunjung melihat formulir yang sudah diisi lengkap — mereka tidak melihat proses pengisiannya. Tag `<?php ... ?>` adalah titik di mana pustakawan mulai menulis.

## Dipakai untuk Apa
- Template halaman web yang menampilkan data dinamis (daftar buku, profil user, artikel)
- Form registrasi/login dengan validasi server-side
- Dashboard admin dengan data real-time
- Halaman error kustom (404, 500) yang informatif

## Kesalahan Umum yang Sering Terjadi
- **Menumpuk echo untuk HTML panjang**: Membuat kode susah dibaca. Gunakan embedding saja.
- **Lupa menutup tag PHP**: Semua kode setelah `<?php` dianggap PHP sampai ketemu `?>` atau akhir file.
- **Salah memahami `<?=`**: Short tag `<?=` hanya boleh jika `short_open_tag` diaktifkan (biasanya sudah aktif di PHP 5.4+).
- **Nested quotes kacau**: `echo "<a href='$url'>"` — kutip ganda di luar, tunggal di dalam. Atau sebaliknya.

## Hubungan dengan Materi Sebelumnya
Di materi 3 kamu belajar membuat file `.php` dengan output teks. Sekarang kamu belajar menggabungkannya dengan HTML. Ini adalah skill inti: 90% file PHP di dunia nyata adalah campuran HTML dan PHP. Materi ini menjadi jembatan menuju pembuatan aplikasi web lengkap.

## Soal Latihan & Jawaban
### Soal
Buat halaman profil perpustakaan dengan:
- Judul "Profil Perpustakaan"
- Nama perpustakaan (variabel: `$nama`)
- Tahun berdiri (variabel: `$tahun`)
- Daftar 3 layanan dalam bentuk list HTML (gunakan array `$layanan` dan loop `foreach`)

Gunakan pendekatan embedding dan short echo tag `<?= ?>` untuk data yang ditampilkan.

### Jawaban
```php
<?php
$nama = "Perpustakaan Ilmu Pengetahuan";
$tahun = "2025";
$layanan = ["Peminjaman Buku", "Ruang Baca", "Literasi Digital"];
?>
<!DOCTYPE html>
<html>
<head>
    <title>Profil Perpustakaan</title>
</head>
<body>
    <h1><?= $nama ?></h1>
    <p>Tahun berdiri: <?= $tahun ?></p>
    <h2>Layanan Kami</h2>
    <ul>
    <?php foreach ($layanan as $l): ?>
        <li><?= $l ?></li>
    <?php endforeach; ?>
    </ul>
</body>
</html>
```
