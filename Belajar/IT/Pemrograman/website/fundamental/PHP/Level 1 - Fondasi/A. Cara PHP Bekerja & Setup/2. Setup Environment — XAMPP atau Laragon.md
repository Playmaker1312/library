# Setup Environment — XAMPP atau Laragon

## Penjelasan
Untuk menjalankan PHP di komputer lokal, kamu butuh "server palsu" — lingkungan yang meniru server sungguhan. Dua tools paling populer untuk ini adalah **XAMPP** dan **Laragon**. Keduanya adalah paket all-in-one yang berisi:
- **PHP** (interpreter)
- **Apache** / **Nginx** (web server)
- **MySQL** / **MariaDB** (database)
- **phpMyAdmin** (antarmuka database via browser)

**XAMPP**:
- Tersedia untuk Windows, macOS, Linux
- Kontrol panel terpisah (start/stop Apache & MySQL manual)
- Lebih "mentah" — cocok untuk belajar karena kamu mengerti masing-masing komponen

**Laragon**:
- Khusus Windows
- Lebih modern, ringan, dan praktis
- Bisa langsung create virtual host dengan satu klik
- Mendukung Node.js, Python, Git terintegrasi

## Fungsi
Memberikan lingkungan server lokal sehingga file `.php` bisa diproses oleh interpreter PHP dan diakses melalui browser via `http://localhost/...`, bukan dibuka langsung sebagai file teks.

## Cara Pengimplementasian / Code
### Setup dengan XAMPP:
1. Download XAMPP dari https://www.apachefriends.org/
2. Install (default: `C:\xampp`)
3. Buka XAMPP Control Panel → klik **Start** pada Apache (dan MySQL jika perlu)
4. Simpan file `.php` kamu di folder `C:\xampp\htdocs\`
5. Buka browser, akses `http://localhost/nama_file.php`

### Setup dengan Laragon:
1. Download Laragon dari https://laragon.org/
2. Install (default: `C:\laragon`)
3. Buka Laragon → klik **Start All**
4. Simpan file `.php` di `C:\laragon\www\`
5. Buka browser, akses `http://localhost/nama_file.php`

### Cek apakah PHP sudah berjalan:
Buat file `info.php` di folder project:
```php
<?php
phpinfo();
```
Akses `http://localhost/info.php` — jika muncul halaman informasi PHP, berarti setup berhasil.

## Analogi
XAMPP/Laragon seperti **membangun perpustakaan mini di rumahmu**. Kamu tidak perlu menyewa gedung besar (server hosting) untuk latihan. Kamu punya rak buku mini (folder `htdocs`), petugas (Apache), dan katalog (PHP). Semua ada dalam satu paket. Laragon seperti perpustakaan modern dengan fitur otomatis; XAMPP seperti perpustakaan klasik di mana kamu harus menyalakan AC dan lampu secara manual.

## Dipakai untuk Apa
- Belajar dan eksperimen PHP tanpa biaya hosting
- Development lokal sebelum部署 ke server sungguhan
- Membuat dan menguji aplikasi web di komputer sendiri
- Menjalankan CMS seperti WordPress di lokal

## Kesalahan Umum yang Sering Terjadi
- **Tidak menjalankan server**: Apache harus dalam status "Running", bukan "Stopped".
- **Menyimpan file di folder salah**: File harus di `htdocs` (XAMPP) atau `www` (Laragon), bukan di desktop.
- **Port bentrok**: Aplikasi lain (Skype, Docker) kadang memakai port 80. Ganti port Apache di config atau hentikan aplikasi lain.
- **Mengklik file .php langsung**: Harus via `http://localhost/...`, bukan double-click file.

## Hubungan dengan Materi Sebelumnya
Di materi sebelumnya kita belajar bahwa PHP butuh server. Sekarang kamu punya server lokal. Tanpa setup ini, semua kode PHP yang akan kamu tulis di materi selanjutnya tidak akan bisa dijalankan. Ini adalah "gudang" tempat semua proyek PHP kamu akan ditempatkan.

## Soal Latihan & Jawaban
### Soal
Setelah menginstal XAMPP/Laragon, buat folder `perpustakaan` di dalam `htdocs`/`www`. Di dalamnya, buat file `index.php` yang menampilkan teks "Sistem Informasi Perpustakaan — Versi 1.0". Tuliskan kode file tersebut dan URL yang harus diketik di browser untuk mengaksesnya.

### Jawaban
```php
<?php
echo "Sistem Informasi Perpustakaan — Versi 1.0";
?>
```
URL di browser: `http://localhost/perpustakaan/index.php` atau cukup `http://localhost/perpustakaan/`
