# Session — Sistem Login Sederhana

## Penjelasan
HTTP adalah protokol **stateless** — server tidak ingat siapa kamu di setiap request. **Session** adalah mekanisme untuk menyimpan data sementara di server yang "diingat" antar halaman. Cara kerja:

1. `session_start()` — memulai atau melanjutkan session
2. PHP menyimpan data session di file/server dan memberikan **session ID** (cookie `PHPSESSID`) ke browser
3. Setiap request berikutnya, browser mengirim session ID, dan PHP memuat data `$_SESSION` yang sesuai
4. `$_SESSION` adalah array asosiatif superglobal — baca/tulis seperti array biasa
5. `session_destroy()` — menghapus semua data session (digunakan saat logout)

Flow login sederhana:
```
Login form → validasi → set $_SESSION['user'] → halaman dashboard
                                                      ↓
                                              session_destroy() → logout
```

## Fungsi
Mempertahankan state pengguna di aplikasi web stateless. Memungkinkan sistem login/logout, keranjang belanja, preferensi pengguna, dan data sementara lainnya yang bertahan selama sesi browser.

## Cara Pengimplementasian / Code
```php
<?php
session_start();
?>
<!DOCTYPE html>
<html>
<body>

<?php
// =====================
// LOGIN — file: login.php
// =====================
if (isset($_POST['login'])) {
    $username = $_POST['username'] ?? '';
    $password = $_POST['password'] ?? '';

    // Simulasi validasi (di real app, cek ke database)
    if ($username === 'admin' && $password === 'rahasia') {
        $_SESSION['user'] = [
            'username' => $username,
            'nama'     => 'Administrator Perpustakaan',
            'role'     => 'admin',
        ];
        $_SESSION['login_time'] = time();
        header('Location: dashboard.php');
        exit;
    } else {
        $error = 'Username atau password salah!';
    }
}
?>

<?php if (!isset($_SESSION['user'])): ?>
    <!-- Form Login -->
    <form method="post">
        <h2>Login Perpustakaan</h2>
        <?php if (isset($error)) echo "<p style='color:red'>$error</p>"; ?>
        <input type="text"     name="username" placeholder="Username" required>
        <input type="password" name="password" placeholder="Password" required>
        <button type="submit"  name="login">Login</button>
    </form>
<?php endif; ?>

</body>
</html>
```

```php
<?php
// =====================
// DASHBOARD — file: dashboard.php
// =====================
session_start();

// Cek apakah user sudah login
if (!isset($_SESSION['user'])) {
    header('Location: login.php');
    exit;
}

$user = $_SESSION['user'];
$loginTime = date('d M Y H:i', $_SESSION['login_time']);
?>
<!DOCTYPE html>
<html>
<body>
    <h2>Selamat datang, <?= htmlspecialchars($user['nama']) ?>!</h2>
    <p>Login sebagai: <strong><?= $user['role'] ?></strong></p>
    <p>Waktu login: <?= $loginTime ?></p>
    <a href="logout.php">Logout</a>
</body>
</html>
```

```php
<?php
// =====================
// LOGOUT — file: logout.php
// =====================
session_start();

// Hapus semua data session
$_SESSION = [];

// Hapus cookie session jika ada
if (ini_get('session.use_cookies')) {
    $params = session_get_cookie_params();
    setcookie(session_name(), '', time() - 3600,
        $params['path'], $params['domain'],
        $params['secure'], $params['httponly']
    );
}

// Hancurkan session
session_destroy();

header('Location: login.php');
exit;
?>
```

## Analogi
Session seperti **kartu anggota perpustakaan**. Saat pertama datang (login), pustakawan membuatkan kartu dengan data dirimu (`$_SESSION`). Kartu itu unik — hanya kamu yang punya (session ID via cookie). Setiap kali kamu ke perpustakaan (request halaman), kamu tunjukkan kartu itu, dan pustakawan tahu namamu, status keanggotaanmu, dan buku apa yang sedang kamu pinjam. Saat pulang (logout), kartu dikembalikan dan data kamu dilupakan.

## Dipakai untuk Apa
- **Login/logout**: Menjaga status autentikasi pengguna di seluruh halaman
- **Keranjang pinjaman**: Menyimpan daftar buku yang akan dipinjam sebelum checkout
- **Flash messages**: Notifikasi satu kali pakai (materi 21)
- **Tracking aktivitas**: Mencegah akses ke halaman tertentu tanpa login
- **Multi-step form**: Menyimpan data sementara di form bertahap

## Kesalahan Umum yang Sering Terjadi
- **Lupa `session_start()` di setiap halaman**: `$_SESSION` tidak akan terisi — seperti lupa menyapa pustakawan.
- **Tidak cek apakah user sudah login**: Halaman dashboard bisa diakses tanpa login — tinggal ketik URL langsung.
- **Menyimpan password di session**: JANGAN. Simpan hanya user ID, lalu ambil data dari database saat perlu.
- **Session tidak di-destroy saat logout**: Data login masih ada di server — bisa disusupi jika session ID bocor.
- **Session timeout tidak diatur**: User login di warnet, lupa logout — orang berikutnya bisa akses session yang sama.
- **header() setelah output**: `header('Location: ...')` harus sebelum output HTML, atau gunakan `ob_start()`.

## Hubungan dengan Materi Sebelumnya
Materi 18-19 mengajarkan cara menerima dan membersihkan input form — session menggunakan input tersebut (username & password) untuk autentikasi. Materi 6 (variabel) dan 13 (array asosiatif) penting karena `$_SESSION` adalah array. Setelah session, materi 21 (flash messages) memanfaatkan session untuk notifikasi satu kali pakai.

## Soal Latihan & Jawaban
### Soal
Buat sistem login mini dengan 2 halaman: `login.php` (form username & password) dan `profile.php` (hanya bisa diakses jika sudah login). Gunakan username "anggota" dan password "buku123". Di halaman profile, tampilkan "Selamat datang, [username]" dan link logout.

### Jawaban
```php
<?php
// login.php
session_start();

// Jika sudah login, langsung redirect
if (isset($_SESSION['user'])) {
    header('Location: profile.php');
    exit;
}

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $user = $_POST['username'] ?? '';
    $pass = $_POST['password'] ?? '';

    if ($user === 'anggota' && $pass === 'buku123') {
        $_SESSION['user'] = $user;
        header('Location: profile.php');
        exit;
    } else {
        echo "Username atau password salah.";
    }
}
?>
<form method="post">
    <input type="text"   name="username" placeholder="Username" required>
    <input type="password" name="password" placeholder="Password" required>
    <button type="submit">Login</button>
</form>
```

```php
<?php
// profile.php
session_start();

if (!isset($_SESSION['user'])) {
    header('Location: login.php');
    exit;
}
?>
<h2>Selamat datang, <?= htmlspecialchars($_SESSION['user']) ?>!</h2>
<a href="logout.php">Logout</a>
```

```php
<?php
// logout.php
session_start();

header('Location: login.php');
exit;
?>
```
