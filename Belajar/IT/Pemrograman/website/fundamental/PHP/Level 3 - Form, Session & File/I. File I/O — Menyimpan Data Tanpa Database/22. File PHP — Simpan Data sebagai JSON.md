# File PHP — Simpan Data sebagai JSON

## Penjelasan
JSON (JavaScript Object Notation) adalah format teks ringan untuk pertukaran data yang mudah dibaca manusia dan mesin. PHP memiliki fungsi bawaan untuk bekerja dengan JSON:

| Fungsi | Keterangan |
|--------|------------|
| `json_encode($data)` | Mengubah array/object PHP → string JSON |
| `json_decode($json, true)` | Mengubah string JSON → array PHP (true) atau object (false) |
| `file_put_contents($path, $data)` | Menulis data ke file |
| `file_get_contents($path)` | Membaca seluruh isi file ke string |
| `json_last_error_msg()` | Mendapatkan pesan error JSON terakhir |

Dengan kombinasi fungsi di atas, kamu bisa menggunakan file JSON sebagai **database sederhana** — cocok untuk prototyping, aplikasi kecil, atau belajar tanpa perlu setup MySQL.

Struktur data JSON:
```php
<?php
$buku = [
    ['id' => 1, 'judul' => 'PHP Dasar', 'pengarang' => 'Andi', 'tersedia' => true],
    ['id' => 2, 'judul' => 'Laravel Pro', 'pengarang' => 'Budi', 'tersedia' => false],
];
// json_encode → [{"id":1,"judul":"PHP Dasar","pengarang":"Andi","tersedia":true},...]
?>
```

## Fungsi
Menyimpan dan membaca data persisten tanpa database. Berguna untuk menyimpan konfigurasi, data session alternatif, cache, data aplikasi sederhana, dan sebagai pengenal konsep serialisasi data sebelum beralih ke database sesungguhnya.

## Cara Pengimplementasian / Code
```php
<?php
// =====================
// HELPER: Manajemen Buku via JSON
// =====================
define('DATA_FILE', __DIR__ . '/buku.json');

// Inisialisasi file jika belum ada
function initData(): void {
    if (!file_exists(DATA_FILE)) {
        file_put_contents(DATA_FILE, json_encode([], JSON_PRETTY_PRINT));
    }
}

// Ambil semua data buku
function getSemuaBuku(): array {
    initData();
    $json = file_get_contents(DATA_FILE);
    $data = json_decode($json, true);
    return is_array($data) ? $data : [];
}

// Simpan satu buku baru
function tambahBuku(string $judul, string $pengarang, int $tahun): array {
    $buku  = getSemuaBuku();
    $idBaru = count($buku) > 0 ? max(array_column($buku, 'id')) + 1 : 1;

    $bukuBaru = [
        'id'        => $idBaru,
        'judul'     => $judul,
        'pengarang' => $pengarang,
        'tahun'     => $tahun,
        'tersedia'  => true,
        'ditambahkan' => date('Y-m-d H:i:s'),
    ];

    $buku[] = $bukuBaru;
    file_put_contents(DATA_FILE, json_encode($buku, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE));

    return $bukuBaru;
}

// Hapus buku berdasarkan ID
function hapusBuku(int $id): bool {
    $buku   = getSemuaBuku();
    $awal   = count($buku);
    $buku   = array_filter($buku, fn($b) => $b['id'] !== $id);

    if (count($buku) === $awal) {
        return false; // ID tidak ditemukan
    }

    file_put_contents(DATA_FILE, json_encode(array_values($buku), JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE));
    return true;
}

// Cari buku berdasarkan judul
function cariBuku(string $keyword): array {
    $buku = getSemuaBuku();
    return array_filter($buku, function($b) use ($keyword) {
        return stripos($b['judul'], $keyword) !== false;
    });
}
?>

<?php
// =====================
// Contoh Penggunaan
// =====================
// Tambah beberapa buku
tambahBuku('Belajar PHP untuk Pemula', 'Andi Programmer', 2025);
tambahBuku('Mastering Laravel 11', 'Budi Framework', 2026);
tambahBuku('JavaScript Modern', 'Citra Coding', 2025);

// Tampilkan semua buku
echo "=== Semua Buku ===\n";
foreach (getSemuaBuku() as $b) {
    $status = $b['tersedia'] ? 'Tersedia' : 'Dipinjam';
    echo "[{$b['id']}] {$b['judul']} — {$b['pengarang']} ({$b['tahun']}) — $status\n";
}

// Cari buku
echo "\n=== Pencarian: Laravel ===\n";
foreach (cariBuku('Laravel') as $b) {
    echo "{$b['judul']} oleh {$b['pengarang']}\n";
}

// Hapus buku ID 1
hapusBuku(1);

echo "\n=== Setelah Hapus ===\n";
echo "Total buku tersimpan: " . count(getSemuaBuku()) . "\n";
?>
```

## Analogi
File JSON seperti **buku katalog besar di meja pustakawan**. Setiap kali anggota meminjam buku, pustakawan menulis catatan di buku katalog itu (file_put_contents). Saat ada yang bertanya "Apakah buku X tersedia?", pustakawan membuka buku katalog (file_get_contents), membaca daftarnya (json_decode), lalu menjawab. Tanpa database — cukup buku catatan, pena, dan pustakawan yang rajin menulis. Kalau listrik padam (server mati), data tidak hilang karena tersimpan di buku fisik (file).

## Dipakai untuk Apa
- **Data konfigurasi**: `config.json` untuk pengaturan aplikasi
- **Cache API**: Menyimpan respons API agar tidak request ulang tiap kali
- **Database prototyping**: Uji coba fitur CRUD tanpa setup database
- **Data sementara**: Log aktivitas pengguna, counter kunjungan
- **Export/import data**: Backup data dalam format universal
- **Aplikasi kecil**: To-do list, catatan pribadi, katalog buku sederhana

## Kesalahan Umum yang Sering Terjadi
- **Lupa `true` di `json_decode()`**: Default `false` mengembalikan object — akses dengan `->` bukan `[]`, bikin error.
- **File permission**: PHP tidak punya izin menulis ke direktori — `file_put_contents` gagal diam-diam.
- **JSON tidak valid akibat karakter khusus**: String dengan kutip ganda atau newline — gunakan `JSON_UNESCAPED_UNICODE` dan `JSON_HEX_TAG`.
- **Race condition**: Dua request simultan menulis file yang sama — data bisa korup. Untuk produksi, gunakan locking (`flock`).
- **File membesar tanpa kendali**: Tidak ada mekanisme kompaksi — data lama menumpuk.
- **Menyimpan data sensitif**: Jangan simpan password di JSON tanpa enkripsi — file bisa dibaca siapa pun.

## Soal Latihan & Jawaban
### Soal
Buat file `anggota.json` dan fungsi `tambahAnggota(string $nama, string $email): array` yang menyimpan data anggota baru ke file JSON. Setiap anggota memiliki `id` (otomatis increment), `nama`, `email`, dan `tanggal_daftar`. Buat juga fungsi `getAnggota(): array` untuk menampilkan semua anggota.

### Jawaban
```php
<?php
define('ANGGOTA_FILE', __DIR__ . '/anggota.json');

function initAnggota(): void {
    if (!file_exists(ANGGOTA_FILE)) {
        file_put_contents(ANGGOTA_FILE, json_encode([]));
    }
}

function getAnggota(): array {
    initAnggota();
    return json_decode(file_get_contents(ANGGOTA_FILE), true) ?: [];
}

function tambahAnggota(string $nama, string $email): array {
    $anggota = getAnggota();
    $idBaru  = count($anggota) > 0 ? max(array_column($anggota, 'id')) + 1 : 1;

    $baru = [
        'id'            => $idBaru,
        'nama'          => $nama,
        'email'         => $email,
        'tanggal_daftar' => date('Y-m-d'),
    ];

    $anggota[] = $baru;
    file_put_contents(ANGGOTA_FILE, json_encode($anggota, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE));

    return $baru;
}

// Test
tambahAnggota('Siti Aminah', 'siti@email.com');
tambahAnggota('Rudi Hartono', 'rudi@email.com');

foreach (getAnggota() as $a) {
    echo "[{$a['id']}] {$a['nama']} — {$a['email']} ({$a['tanggal_daftar']})\n";
}
?>
```
