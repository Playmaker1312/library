# Setup Environment

## Penjelasan
Sebelum menulis kode HTML, kita perlu menyiapkan "meja kerja" yang nyaman. Lingkungan kerja (environment) yang baik akan mempercepat proses belajar dan bekerja. Untuk HTML dasar, kita hanya butuh: **text editor** (VS Code), **browser** (Chrome), dan beberapa ekstensi pendukung.

## Fungsi
- Menulis kode HTML dengan nyaman (syntax highlighting, auto-complete)
- Melihat hasil langsung di browser secara real-time (Live Server)
- Memformat kode agar rapi dan konsisten (Prettier)
- Debugging kode dengan inspeksi elemen (Chrome DevTools)

## Cara Pengimplementasian
```html
<!-- Tidak ada kode HTML untuk setup, ini langkah instalasi -->

1. Download & install VS Code: https://code.visualstudio.com
2. Download & install Chrome: https://google.com/chrome
3. Buka VS Code, install ekstensi:
   - Live Server (Ritwick Dey)
   - Prettier - Code formatter
   - HTML CSS Support
   - Auto Rename Tag
4. Buka folder project, buat file .html, klik kanan → "Open with Live Server"
```

## Analogi
Setup environment adalah **mempersiapkan peralatan tukang sebelum membangun rumah**. Tukang tidak akan mulai tanpa palu, gergaji, meteran, dan helm. VS Code adalah kotak peralatan utama, Live Server adalah alat untuk langsung melihat hasil pasangan bata, Prettier adalah spirit level agar semuanya rapi lurus. Chrome adalah jendela untuk mengintip rumah yang sedang dibangun.

## Dipakai Untuk
- Setiap kali memulai project web baru
- Menulis, mengedit, dan men-debug kode HTML/CSS/JavaScript
- Melihat perubahan kode secara instan tanpa refresh manual
- Menjaga konsistensi format kode dalam tim

## Kesalahan Umum
- Tidak install Live Server → harus refresh manual tiap kaliubah kode
- Menggunakan Notepad atau text editor tanpa fitur → sangat tidak produktif
- Tidak memasang Prettier → kode jadi berantakan dan sulit dibaca
- Lupa mengaktifkan "Auto Save" di VS Code → perubahan tidak tersimpan saat Live Server reload
