## 📝 Format Setiap Materi

Setiap file markdown mengikuti format:

| Bagian | Deskripsi |
|---|---|
| Penjelasan | Konsep inti dalam bahasa sederhana |
| Fungsi | Mengapa ini ada, masalah apa yang diselesaikan |
| Cara Implementasi | Kode langsung yang bisa dijalankan |
| Analogi (Rumah) | Dihubungkan ke tema membangun rumah |
| Dipakai Untuk Apa | Use case di dunia nyata |
| Kesalahan Umum | Trap yang sering menjebak pemula |
| Benang Merah | Hubungan ke materi sebelumnya & sesudahnya |
| Soal + Jawaban | 3 level: mudah, sedang, tantangan |

---

## 🎯 Cara Pakai

1. Mulai dari **Level 1** — jangan loncat
2. Baca materi sesuai **urutan nomor** (1, 2, 3...)
3. Kerjakan **micro-exercise** sebelum lanjut
4. Setiap selesai sub-bab, buat **catatan sendiri**
5. Selesaikan **proyek level** sebelum naik level
