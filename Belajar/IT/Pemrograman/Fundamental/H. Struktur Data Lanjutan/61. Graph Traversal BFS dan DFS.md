Mari kita lengkapi keahlian Anda dalam menguasai struktur data _Graph_. Di materi sebelumnya, kita sudah berhasil membangun "peta jaringan" menggunakan _Adjacency List_. Sekarang pertanyaannya: bagaimana cara komputer menjelajahi peta tersebut dari satu titik ke titik lain secara sistematis?

Karena _Graph_ tidak memiliki "Akar" (_Root_) yang pasti seperti _Tree_, dan jalurnya bisa berputar-putar tanpa ujung (_cycles_), kita membutuhkan dua algoritma penelusuran mutakhir: **BFS** dan **DFS**.

---

## 1. Definisi Singkat

**Graph Traversal (Penelusuran Graf)** adalah proses mengunjungi setiap _Vertex_ (simpul/titik) di dalam sebuah jaringan tepat satu kali.

- **Breadth-First Search / BFS (Pencarian Melebar):** Algoritma ini menjelajahi jaringan lapis demi lapis. Ia akan mengunjungi **semua tetangga terdekat** dari titik awal terlebih dahulu, sebelum melangkah lebih jauh ke tetangganya tetangga.
    
- **Depth-First Search / DFS (Pencarian Mendalam):** Algoritma ini sangat agresif. Ia akan memilih satu jalur dan **terus menyelam sedalam mungkin** sampai menemukan jalan buntu. Jika buntu, ia akan mundur satu langkah (_backtrack_) dan mencoba jalur lain.
    

## 2. Analogi: Mencari Kucing Hilang di Labirin vs Menyebarkan Rumor

- **BFS (Menyebarkan Rumor):** Bayangkan Anda menceritakan sebuah gosip ke 3 sahabat Anda (Jarak 1). Besoknya, ke-3 sahabat Anda itu menceritakannya ke sahabat mereka masing-masing (Jarak 2). Rumor menyebar secara merata seperti gelombang air yang dilempar batu. Ini adalah BFS!
    
- **DFS (Mencari Kucing di Labirin):** Anda masuk ke labirin. Saat bertemu pertigaan, Anda memilih belok kiri dan _terus_ berjalan sejauh mungkin tanpa mempedulikan persimpangan lain yang Anda lewati. Tiba-tiba, jalan buntu! Anda mengeluarkan kapur, menandai tembok dengan tanda silang (X), lalu berjalan mundur ke persimpangan terakhir untuk mencoba lorong yang belum dilewati. Ini adalah DFS!
    

## 3. Poin-Poin Penting

- **Awas Terjebak Lingkaran Setan (Cycles):** Berbeda dengan _Tree_, _Graph_ bisa memiliki jalur yang memutar (A ke B, B ke C, C kembali ke A). Jika Anda tidak berhati-hati, komputer akan menelusurinya selamanya hingga _crash_. Solusinya? **Kita WAJIB membawa "Buku Catatan" (biasanya menggunakan tipe data `Set`)** untuk mencatat titik mana saja yang sudah dikunjungi.
    
- **Senjata Rahasia (Struktur Data Pendukung):**
    
    - **BFS wajib menggunakan _Queue_ (Antrean - FIFO):** Siapa yang dicatat pertama, dia yang dieksplorasi pertama.
        
    - **DFS wajib menggunakan _Stack_ (Tumpukan - LIFO) atau _Rekursi_:** Memori jangka pendek untuk mengingat persimpangan terakhir saat harus mundur (_backtrack_).
        
- **Kompleksitas Waktu:** Keduanya sama-sama memiliki kecepatan O(V+E), di mana V adalah jumlah _Vertices_ (Titik) dan E adalah jumlah _Edges_ (Garis koneksi).
    
- **Kapan Pakai Apa?**
    
    - Gunakan **BFS** jika Anda mencari **Jalur Terpendek** (_Shortest Path_) di jaringan yang jaraknya sama rata.
        
    - Gunakan **DFS** jika Anda ingin memastikan **Apakah ada jalan menuju tujuan?**, memecahkan teka-teki labirin, atau mengurutkan tugas yang saling bergantung (_Topological Sorting_).
        

## 4. Contoh Implementasi

Mari kita siapkan sebuah _Graph_ sederhana menggunakan _Adjacency List_ (seperti materi sebelumnya) di **JavaScript**, lalu kita jelajahi menggunakan BFS dan DFS.

JavaScript

```
// Peta Jaringan kita (Adjacency List)
const petaJaringan = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
};

// ==========================================
// 1. BREADTH-FIRST SEARCH (BFS) - Pakai Antrean (Queue)
// ==========================================
function jelajahBFS(titikAwal) {
    let antrean = [titikAwal]; // Masukkan titik pertama
    let sudahDikunjungi = new Set([titikAwal]); // Buku catatan agar tidak mutar-mutar

    console.log("Mulai BFS:");
    while (antrean.length > 0) {
        // Keluarkan orang pertama dari depan antrean
        let titikSaatIni = antrean.shift(); 
        console.log(titikSaatIni);

        // Panggil semua tetangga dari titik saat ini
        for (let tetangga of petaJaringan[titikSaatIni]) {
            // Jika tetangga belum pernah dikunjungi, catat dan masukkan ke antrean!
            if (!sudahDikunjungi.has(tetangga)) {
                sudahDikunjungi.add(tetangga);
                antrean.push(tetangga);
            }
        }
    }
}

// ==========================================
// 2. DEPTH-FIRST SEARCH (DFS) - Pakai Rekursi
// ==========================================
function jelajahDFS(titikSaatIni, sudahDikunjungi = new Set()) {
    // 1. Langsung catat agar tidak dikunjungi dua kali
    sudahDikunjungi.add(titikSaatIni);
    console.log(titikSaatIni);

    // 2. Selami semua tetangganya satu per satu sedalam mungkin!
    for (let tetangga of petaJaringan[titikSaatIni]) {
        if (!sudahDikunjungi.has(tetangga)) {
            // REKURSI: Panggil fungsi ini lagi untuk tetangga tersebut (menyelam lebih dalam)
            jelajahDFS(tetangga, sudahDikunjungi);
        }
    }
}

// --- MARI KITA UJI ---
jelajahBFS('A'); 
// Output BFS: A, B, C, D, E, F (Melebar lapis demi lapis)

console.log("-------------------");

console.log("Mulai DFS:");
jelajahDFS('A'); 
// Output DFS: A, B, D, E, F, C (Menyelam tajam ke B->D->E->F baru mundur ke C)
```

## 5. Koneksi dengan Web Development

Pemahaman algoritma penelusuran jaringan ini sangat vital dalam arsitektur perangkat lunak skala besar:

1. **"Degrees of Separation" di LinkedIn (BFS):** Saat Anda membuka profil seseorang di LinkedIn, sistem tahu bahwa dia adalah koneksi "2nd" (teman dari teman) Anda. Sistem menggunakan BFS dari profil Anda, meluas 2 lapis, untuk menemukan profil orang tersebut dengan rute terpendek.
    
2. **Web Crawling Googlebot (BFS/DFS):** Google menggunakan _bot_ untuk menelusuri internet. _Bot_ mulai dari satu _website_ (Titik A), lalu menelusuri semua _link_ yang ada di halaman tersebut ke _website_ lain (Titik B, C, D). Menjelajahi triliunan _link_ ini membutuhkan algoritma penelusuran graf tingkat dewa.
    
3. **Resolusi Ketergantungan / Dependency (DFS):** Saat Anda menjalankan perintah `npm install` atau `yarn` di proyek Node.js, sistem seringkali menggunakan variasi DFS (_Topological Sort_) untuk memastikan _package_ yang menjadi fondasi utama di-unduh dan di-_install_ terlebih dahulu sebelum _package_ lain yang bergantung padanya.
