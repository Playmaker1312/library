Mari kita bahas salah satu varian _Tree_ yang memiliki aturan paling unik dan sangat aplikatif di dunia nyata. Jika _Binary Search Tree_ (BST) di materi sebelumnya sangat ahli dalam **mencari** data spesifik, struktur data kali ini sangat ahli dalam **mencari data yang paling ekstrem** (paling besar atau paling kecil) secara instan.

---

## 1. Definisi Singkat

**Heap** adalah struktur data berbasis pohon biner (_Binary Tree_) yang memiliki dua aturan mutlak:

1. **Bentuknya harus komplit (Complete Binary Tree):** Pohon harus diisi dari atas ke bawah, dan dari kiri ke kanan tanpa ada celah kosong.
    
2. **Aturan Nilai (Heap Property):**
    
    - **Max-Heap:** Nilai _Parent_ (Induk) **selalu lebih besar atau sama dengan** anak-anaknya. Akibatnya, angka terbesar di seluruh pohon pasti berada di puncak (_Root_).
        
    - **Min-Heap:** Nilai _Parent_ **selalu lebih kecil atau sama dengan** anak-anaknya. Akibatnya, angka terkecil di seluruh pohon pasti berada di puncak (_Root_).
        

**Priority Queue (Antrean Prioritas)** adalah penerapan dunia nyata (tipe data abstrak) dari _Heap_. Jika antrean biasa memegang prinsip "Siapa datang pertama, dilayani pertama" (FIFO), _Priority Queue_ memegang prinsip "Siapa yang prioritasnya paling tinggi, dia yang dilayani duluan".

## 2. Analogi: IGD Rumah Sakit (Emergency Room)

Bayangkan Anda sedang berada di ruang gawat darurat rumah sakit:

- **Antrean Biasa (Queue):** Seperti di kasir minimarket. Jika Anda datang duluan hanya karena sakit panu, Anda akan dilayani sebelum orang yang datang belakangan. Di IGD, ini bisa memakan korban jiwa.
    
- **Antrean Prioritas (Priority Queue / Max-Heap):** Perawat melakukan _Triage_ (penilaian tingkat keparahan). Setiap pasien diberi skor keparahan dari 1 sampai 10.
    
    - Pasien A datang (Skor 3: Demam). Ia ditaruh di puncak.
        
    - Pasien B datang belakangan (Skor 9: Serangan Jantung). Perawat langsung "menggelembungkan" Pasien B ke puncak antrean (_Root_) menggeser Pasien A.
        
    - Saat dokter siap, ia selalu mengambil pasien dari **puncak antrean** (pasien dengan kondisi paling kritis).
        

## 3. Poin-Poin Penting

- **Keajaiban Matematika (Array di Balik Layar):** Karena bentuk _Heap_ selalu komplit tanpa celah, kita tidak perlu menggunakan _Class Node_ dengan _pointer_ yang rumit seperti BST. _Heap_ bisa disimpan murni di dalam sebuah **Array biasa**!
    
    - Jika sebuah _Parent_ berada di indeks i, maka anak kirinya pasti berada di indeks 2i+1, dan anak kanannya di 2i+2.
        
    - Untuk mencari siapa _Parent_ dari indeks i, rumusnya adalah ⌊2i−1​⌋.
        
- **Waktu Eksekusi (Time Complexity):**
    
    - Melihat siapa yang paling prioritas (_Peek Root_): Sangat instan, O(1).
        
    - Menambahkan pasien baru (_Insert_): Sangat cepat, O(logn).
        
    - Mengeluarkan pasien prioritas tertinggi (_Extract Max/Min_): Sangat cepat, O(logn), karena pohon harus menyusun ulang dirinya (_bubble down_) agar posisinya kembali seimbang.
        

## 4. Contoh Implementasi

Mari kita buat sistem **Min-Heap** sederhana di **JavaScript** untuk menangani nomor antrean prioritas (di mana angka terkecil = prioritas tertinggi, VIP nomor 1 dilayani duluan).

JavaScript

```
class MinHeap {
    constructor() {
        // Heap sebenarnya hanyalah Array biasa!
        this.heap = []; 
    }

    // Mengambil indeks Parent atau Child
    _parent(i) { return Math.floor((i - 1) / 2); }
    _anakKiri(i) { return (2 * i) + 1; }
    _anakKanan(i) { return (2 * i) + 2; }

    // 1. METODE INSERT (Menambahkan antrean baru)
    insert(nilai) {
        this.heap.push(nilai); // Taruh di paling ujung bawah (akhir array)
        this._bubbleUp(this.heap.length - 1); // Gelembungkan ke atas jika dia lebih VIP dari atasannya
    }

    // 2. METODE BUBBLE UP (Mengecek ke atas)
    _bubbleUp(indeks) {
        let saatIni = indeks;
        
        // Selama belum sampai puncak (Root) DAN nilai saat ini LEBIH KECIL dari Parent-nya
        while (saatIni > 0 && this.heap[saatIni] < this.heap[this._parent(saatIni)]) {
            // TUKAR posisi mereka! (Pasien VIP menggeser pasien biasa)
            let indeksParent = this._parent(saatIni);
            let simpanSementara = this.heap[saatIni];
            
            this.heap[saatIni] = this.heap[indeksParent];
            this.heap[indeksParent] = simpanSementara;
            
            // Lanjutkan pengecekan ke tingkat yang lebih tinggi
            saatIni = indeksParent; 
        }
    }

    // Melihat siapa prioritas tertinggi saat ini
    lihatPuncak() {
        return this.heap[0];
    }
}

// --- MARI KITA UJI ANTREAN IGD ---
let antreanIGD = new MinHeap();

antreanIGD.insert(5); // Pasien biasa (Prioritas 5)
antreanIGD.insert(8); // Pasien ringan (Prioritas 8)
antreanIGD.insert(1); // Pasien kritis datang! (Prioritas 1)
antreanIGD.insert(3); // Pasien darurat (Prioritas 3)

// Pasien dengan skor 1 otomatis naik ke pucuk (indeks 0) tanpa perulangan yang lambat!
console.log("Yang harus ditangani dokter sekarang: Skor " + antreanIGD.lihatPuncak()); 
// Output: Yang harus ditangani dokter sekarang: Skor 1
```

## 5. Koneksi dengan Web Development

Meskipun struktur ini jarang ditulis manual oleh _Web Developer_ di proyek sehari-hari, _Priority Queue_ beroperasi secara senyap di banyak teknologi modern:

1. **Manajemen Bandwidth (Download Manager):** Saat Anda mengunduh 5 file sekaligus di _browser_, _browser_ menggunakan _Priority Queue_ untuk memprioritaskan file berukuran kecil atau file yang aktif diklik pengguna agar selesai lebih dulu.
    
2. **Sistem Operasi (Task Scheduling):** Komputer atau _server_ _cloud_ menjalankan ribuan proses secara bersamaan. _CPU Scheduler_ menggunakan _Max-Heap_ untuk memastikan proses sistem operasi (seperti detak _mouse_ atau _keyboard_) mendapat prioritas pemrosesan lebih tinggi daripada aplikasi _browser_ yang sedang terbuka di latar belakang.
    
3. **Algoritma Navigasi (Dijkstra):** Saat Google Maps mencari rute tercepat dari rumah Anda ke kantor, ia menggunakan _Priority Queue_ untuk selalu mengevaluasi dan memilih jalan dengan jarak terpendek berikutnya secara instan, tanpa harus mengecek jalan buntu yang panjang.
