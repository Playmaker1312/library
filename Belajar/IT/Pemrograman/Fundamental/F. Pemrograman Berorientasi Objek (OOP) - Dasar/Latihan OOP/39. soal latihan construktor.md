### **Soal 1: Inisialisasi Karakter RPG (Constructor & Default)**

Kita akan membuat sistem pembuatan karakter game di mana beberapa data diisi oleh user, dan beberapa data sudah disiapkan oleh sistem secara otomatis.

**Tugas di VS Code:**

1. Buat Class bernama `Hero`.
    
2. Buat `constructor` yang menerima dua parameter: `nama` dan `peran` (misal: "Warrior", "Mage").
    
3. Di dalam constructor, set properti `this.nama` dan `this.peran` dari parameter.
    
4. Tambahkan properti internal yang **tidak ada di parameter**:
    
    - `this.level = 1`
        
    - `this.hp = 100`
        
5. Tambahkan `console.log` di dalam constructor: `"Hero ${this.nama} dengan kelas ${this.peran} telah memasuki arena!"`.
    
6. **Instansiasi**: Buat objek `hero1` (Aragon, Warrior). Perhatikan pesan yang muncul di terminal saat Anda menjalankan `node`.

### **Soal 2: Validasi Data pada Constructor (Logic in Init)**

Constructor juga bisa digunakan untuk memastikan data yang dimasukkan masuk akal.

**Tugas di VS Code:**

1. Buat Class `PendaftaranSiswa`.
    
2. Constructor menerima `nama` dan `umur`.
    
3. Di dalam constructor, gunakan **If-Else**:
    
    - Jika `umur` kurang dari 7, tampilkan: `"Maaf ${nama}, umur anda belum cukup untuk SD."`.
        
    - Jika 7 atau lebih, set `this.nama = nama`, `this.umur = umur`, dan tampilkan `"Pendaftaran ${nama} berhasil!"`.
        
4. **Instansiasi**: Cobalah membuat dua objek, satu dengan umur 5 dan satu dengan umur 8. Lihat perbedaannya di terminal.

### **Soal 3: Constructor di Python vs JavaScript (Sintaks)**

Sebagai calon developer serba bisa (Fullstack), Anda harus peka terhadap perbedaan penulisan.

**Tugas di VS Code:**

1. Buat dua file: `latihan.js` dan `latihan.py`.
    
2. Di `latihan.js`, buat class `Mobil` dengan constructor yang menerima `merk`.
    
3. Di `latihan.py`, buat class `Mobil` dengan metode `__init__` yang menerima `merk`.
    
4. Keduanya harus mencetak pesan: `"Mobil [merk] siap dikendarai."` saat objek dibuat.
    
5. Jalankan keduanya dan bandingkan penggunaan `this.` di JS dan `self.` di Python.

### **Pesan dari Mentor IT:**

- **`new` Keyword**: Di JavaScript, jika Anda lupa menulis `new` saat memanggil Class (contoh: `let h = Hero()`), program akan error karena Constructor tidak akan terpicu.
    
- **`this` vs `self`**: Keduanya punya tujuan yang sama, yaitu merujuk pada "diri sendiri". Anggap saja itu seperti menunjuk dada sendiri saat berbicara tentang identitas Anda.
    

Silakan buat file-file tersebut dan jalankan. Jika Anda sudah melihat pesan otomatis muncul tepat saat objek dibuat (tanpa memanggil metode apa pun), berarti Anda sudah menguasai konsep "Inisialisasi Otomatis".
