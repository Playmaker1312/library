Selamat! Anda telah sampai di "pusat kendali". Jika Vue.js adalah wajah dari sebuah aplikasi, maka **Express.js** adalah mesin, pelayan, sekaligus satpam di belakang layar.

Sebagai _framework_ paling populer untuk **Node.js**, Express.js memungkinkan Anda membangun _web server_ yang sangat cepat dan fleksibel hanya dengan beberapa baris kode JavaScript.

---

## 1. Definisi Singkat

**Express.js** adalah _framework_ minimalis untuk Node.js yang dirancang untuk membangun aplikasi web dan **REST API**. Ia bertindak sebagai perantara yang menerima permintaan (_Request_) dari browser, mengolahnya (mungkin mengambil data ke database), dan mengirimkan balasan (_Response_) kembali ke pengguna.

## 2. Analogi: Pos Satpam Perumahan

Bayangkan _server_ Anda adalah sebuah gerbang perumahan:

1. **Client (Tamu):** Datang membawa mobil dan ingin menuju rumah tertentu (URL/Endpoint).
    
2. **Express.js (Pos Satpam):** * Satpam mengecek surat izin tamu (**Middleware/Authentication**).
    
    - Satpam mengarahkan tamu: "Kalau mau ke blok A (Data User), silakan lewat jalan kiri. Kalau mau ke blok B (Data Produk), lewat jalan kanan" (**Routing**).
        
    - Jika rumah yang dicari tidak ada, satpam bilang "Maaf, rumah tidak ditemukan" (**Error 404**).
        

---

## 3. Konsep Inti Express.js

### A. Routing (Pengatur Arah)

Routing menentukan bagaimana aplikasi merespons permintaan _client_ ke alamat tertentu. Express menggunakan metode HTTP yang sudah kita bahas: `app.get()`, `app.post()`, `app.put()`, dan `app.delete()`.

### B. Middleware (Penyaring)

Ini adalah fungsi yang berjalan **sebelum** permintaan sampai ke tujuan akhir. Kegunaannya sangat banyak, mulai dari mengecek apakah pengguna sudah _login_, mencatat aktivitas pengunjung (_logging_), hingga mengubah data JSON dari _client_ agar bisa dibaca oleh JavaScript.

### C. Request & Response (Req & Res)

Dua objek paling penting dalam Express:

- `req` (Request): Berisi semua data yang dikirim _client_ (seperti parameter URL atau isi formulir).
    
- `res` (Response): Alat bagi kita untuk mengirim balik data ke _client_ (seperti `res.send()` atau `res.json()`).
    

---

## 4. Contoh Implementasi: Membuat Server Pertama

Hanya butuh beberapa baris untuk menyalakan "mesin" _backend_ Anda.

**File: `app.js`**

JavaScript

```
const express = require('express'); // Panggil library
const app = express(); // Inisialisasi
const port = 3000;

// Middleware agar Express bisa membaca data JSON dari Client
app.use(express.json());

// ROUTING: Jika ada yang buka alamat utama (/) dengan GET
app.get('/', (req, res) => {
  res.send('Selamat Datang di Server Express Anda!');
});

// ROUTING: Mengambil data pengguna spesifik berdasarkan ID
app.get('/user/:id', (req, res) => {
  const userId = req.params.id; // Mengambil angka dari URL
  res.json({
    id: userId,
    nama: "Budi Programmer",
    status: "Aktif"
  });
});

// Menyalakan Server
app.listen(port, () => {
  console.log(`Server berjalan di http://localhost:${port}`);
});
```

## 5. Koneksi dengan Web Development

Mengapa Express.js menjadi standar industri di dunia _startup_?

1. **Satu Bahasa (JavaScript Everywhere):** Anda bisa menjadi _Full-Stack Developer_ hanya dengan menguasai JavaScript. Vue/React di depan, Express di belakang.
    
2. **Sangat Ringan & Cepat:** Karena bersifat minimalis, Express tidak memaksa Anda menggunakan fitur yang tidak perlu. Ini membuatnya sangat cepat dan efisien untuk aplikasi _Real-Time_ seperti _Chat_ atau _Dashboard_ data.
    
3. **Ekosistem NPM:** Anda butuh fitur _Login_? Pakai `Passport.js`. Butuh koneksi ke MongoDB? Pakai `Mongoose`. Semuanya tinggal "pasang" lewat NPM (_Node Package Manager_).
    

Dengan Express.js, Anda tidak lagi sekadar membuat tampilan yang merespons klik. Anda sekarang memegang kunci untuk **mengelola data**, mengamankan sistem, dan membangun fondasi aplikasi yang bisa diakses oleh jutaan orang.
