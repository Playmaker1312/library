Selamat! Anda telah memahami konsep **REST API** sebagai jembatan data. Sekarang, saatnya kita belajar cara menggunakan "tangan" JavaScript untuk mengambil data tersebut dari dunia internet dan membawanya ke dalam aplikasi Anda.

Di ekosistem JavaScript, ada dua alat utama yang paling sering digunakan untuk "menembak" API: **Fetch API** (bawaan browser) dan **Axios** (pustaka pihak ketiga).

---

## 1. Definisi Singkat

- **Fetch API:** Fitur standar modern yang sudah ada di dalam _browser_ (tidak perlu instalasi). Ia menggunakan konsep _Promise_ untuk menangani proses asinkron.
    
- **Axios:** Pustaka (_library_) eksternal yang sangat populer. Axios menawarkan fitur lebih lengkap, sintaks yang lebih ringkas, dan dukungan otomatis untuk mengubah data menjadi format JSON.
    

## 2. Analogi: Mengambil Air di Sumur Tetangga

Bayangkan API adalah sebuah sumur di rumah tetangga Anda.

- **Fetch API (Mengambil Manual):** Anda membawa ember sendiri. Setelah mengambil air, Anda harus menyaringnya sendiri dari kotoran (mengonversi ke JSON) dan mengecek sendiri apakah airnya bersih atau beracun (mengecek status HTTP _error_ secara manual).
    
- **Axios (Layanan Pengantaran Air):** Anda menelepon layanan profesional. Mereka mengambilkan air, otomatis menyaringnya agar siap minum (otomatis jadi JSON), dan jika ada masalah di jalan, mereka langsung memberi tahu Anda dengan laporan yang jelas.
    

---

## 3. Perbandingan Kode: Fetch vs Axios

Mari kita lihat perbedaan cara mereka mengambil daftar "Tugas" (Todos) dari server publik.

### A. Menggunakan Fetch API (Bawaan)

Fetch membutuhkan dua langkah: pertama memanggil URL, kedua mengubah responnya menjadi JSON.

JavaScript

```
async function ambilDataFetch() {
    try {
        const response = await fetch('https://jsonplaceholder.typicode.com/todos/1');
        
        // Fetch TIDAK menganggap error 404 atau 500 sebagai 'catch' error.
        // Kita harus mengeceknya manual.
        if (!response.ok) {
            throw new Error("Gagal mengambil data: " + response.status);
        }

        const data = await response.json(); // Langkah ekstra: konversi ke JSON
        console.log("Hasil Fetch:", data.title);
    } catch (error) {
        console.error("Terjadi masalah:", error);
    }
}
```

### B. Menggunakan Axios (Modern & Ringkas)

Axios jauh lebih cerdas. Ia langsung memberikan data yang sudah "matang".

JavaScript

```
// Pastikan sudah pasang axios via <script> atau npm install axios
async function ambilDataAxios() {
    try {
        const response = await axios.get('https://jsonplaceholder.typicode.com/todos/1');
        
        // Data otomatis sudah menjadi JSON di dalam properti .data
        console.log("Hasil Axios:", response.data.title);
        
        // Axios otomatis melempar error jika status code 4xx atau 5xx
    } catch (error) {
        console.error("Terjadi masalah:", error.message);
    }
}
```

## 4. Poin-Poin Penting (Kapan Pilih Mana?)

|Fitur|Fetch API|Axios|
|---|---|---|
|**Instalasi**|Tidak perlu (Langsung pakai).|Perlu (via CDN atau NPM).|
|**JSON Data**|Harus panggil `.json()` manual.|Otomatis di dalam `.data`.|
|**Error Handling**|Hanya gagal jika koneksi putus.|Gagal jika status server 400-500.|
|**Fitur Lanjut**|Terbatas.|Punya _Interceptors_ & _Timeout_.|
|**Kecocokan**|Proyek kecil/belajar.|Proyek profesional/skala besar.|

---

## 5. Koneksi dengan Web Development

Mengapa kemampuan mengonsumsi API ini sangat krusial?

1. **Data Real-Time:** Aplikasi seperti portal berita atau kurs saham menggunakan `fetch` atau `axios` di dalam fungsi `setInterval()` untuk terus memperbarui angka di layar tanpa membuat pengguna melakukan _refresh_ halaman.
    
2. **Interceptors (Hanya di Axios):** Di perusahaan besar, kita sering menggunakan Axios _Interceptors_. Ini seperti "petugas keamanan" yang otomatis menempelkan Token Akses (_Bearer Token_) ke setiap permintaan API Anda agar Anda tidak perlu mengetik kode keamanan berulang-ulang di setiap fungsi.
    
3. **Mengirim Data (POST):** Bukan hanya mengambil, Anda menggunakan alat ini untuk mengirim data. Saat pengguna mengisi formulir "Kontak Kami", Anda menggunakan `axios.post('/api/contact', dataFormulir)` untuk mengirimkan pesan tersebut ke _database_ di _server_.
