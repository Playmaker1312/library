Selamat! Anda telah memiliki kerangka _website_ yang kokoh (HTML) dan desain visual yang memukau (CSS). Namun, _website_ Anda saat ini masih diam mematung layaknya manekin di etalase toko.

Untuk membuat _website_ tersebut hidup—bisa merespons klik, menampilkan _pop-up_, atau mengubah warna secara dinamis tanpa harus memuat ulang (_refresh_) halaman—Anda harus memberikan "otak dan otot". Di sinilah keajaiban **JavaScript dan DOM Manipulation** beraksi.

---

## 1. Definisi Singkat

- **DOM (Document Object Model):** Saat _browser_ (seperti Chrome) selesai membaca kode HTML Anda, ia akan mengubah teks HTML tersebut menjadi sebuah model terstruktur yang bentuknya mirip pohon keluarga (_Tree_). Pohon inilah yang disebut DOM.
    
- **DOM Manipulation (Manipulasi DOM):** Proses di mana kita menggunakan bahasa pemrograman **JavaScript** untuk memegang, mengubah, menghapus, atau menambahkan ranting dan daun baru ke dalam Pohon DOM tersebut secara langsung di layar pengguna.
    

## 2. Analogi: Dalang dan Wayang

Bayangkan halaman _website_ Anda adalah sebuah panggung pertunjukan wayang.

- **HTML** adalah **Wayang** kayu yang diam mematung di atas panggung (misalnya: tombol, gambar, teks).
    
- **DOM** adalah **Benang-benang** transparan yang terikat pada setiap sendi pergerakan wayang tersebut.
    
- **JavaScript** adalah sang **Dalang**.
    

Sang Dalang tidak turun langsung ke panggung untuk menggeser wayang. Ia menggunakan benang-benang (DOM) untuk memerintahkan wayang mengangkat tangan, berganti pakaian, atau bahkan mengeluarkan wayang baru dari dalam kotak panggung secara magis.

## 3. Poin-Poin Penting (Tiga Senjata Sang Dalang)

Untuk memanipulasi _website_, JavaScript harus melakukan tiga langkah berurutan: Mencari, Mengubah, atau Membuat. Berikut adalah mantra utamanya:

- **1. Mencari Elemen (Selectors):** JavaScript harus mencari elemen mana yang ingin diubah.
    
    - `document.getElementById('nama-id')`: Mencari satu elemen paling spesifik berdasarkan ID.
        
    - `document.querySelector('.nama-class')`: Mencari elemen pertama yang cocok dengan _class_ atau _tag_ CSS tertentu. Sangat fleksibel!
        
- **2. Mengubah Elemen (Manipulation):** Setelah elemen ditangkap, Anda bisa mengubah wujudnya.
    
    - `.textContent` atau `.innerHTML`: Mengganti teks atau isi HTML di dalam elemen tersebut.
        
    - `.style.warna` / `.style.display`: Mengubah gaya CSS-nya secara langsung (misal: menyembunyikan elemen).
        
    - `.classList.add()` / `.classList.remove()`: Menambah atau mencopot atribut _class_ CSS.
        
- **3. Membuat Elemen Baru (Creation):** Anda bisa menciptakan elemen dari ketiadaan.
    
    - `document.createElement('div')`: Membuat elemen `<div>` baru di dalam memori (belum tampil di layar).
        
    - `.appendChild()`: Menaruh elemen baru tersebut ke dalam panggung HTML agar terlihat oleh pengguna.
        

## 4. Contoh Implementasi

Mari kita lihat bagaimana kode HTML yang statis bisa diubah wujudnya secara drastis menggunakan JavaScript.

**Kode HTML Awal:**

HTML

```
<div id="kotak-profil">
    <h1 id="judul" class="teks-gelap">Halo, Tamu!</h1>
    </div>
```

**Kode JavaScript (Manipulasi DOM):**

JavaScript

```
// 1. MENCARI WAYANG (Selector)
// Menangkap elemen H1 dan bungkus DIV-nya
let elemenJudul = document.getElementById('judul');
let bungkusProfil = document.getElementById('kotak-profil');

// 2. MENGUBAH WAYANG (Manipulation)
// Mengganti teksnya
elemenJudul.textContent = "Selamat Datang, Hacker Muda!";

// Mengubah gaya CSS secara langsung (Ubah warna teks jadi merah)
elemenJudul.style.color = "red";

// Mencopot class lama, dan memasang class baru
elemenJudul.classList.remove('teks-gelap');
elemenJudul.classList.add('teks-terang');

// 3. MEMBUAT WAYANG BARU (Creation)
// Membuat tag <p> baru di memori komputer
let paragrafBaru = document.createElement('p');

// Mengisi teks ke dalam tag <p> tersebut
paragrafBaru.textContent = "Ini adalah pesan rahasia yang dibuat oleh JavaScript.";

// Menaruh tag <p> tersebut ke panggung (ke dalam kotak-profil)
bungkusProfil.appendChild(paragrafBaru);
```

## 5. Koneksi dengan Web Development

DOM Manipulation adalah landasan mutlak dari semua interaktivitas modern di internet:

1. **Fitur Dinamis Tanpa _Refresh_:** Dulu, jika Anda ingin melihat komentar baru di Facebook, Anda harus me-_refresh_ seluruh halaman web. Sekarang, JavaScript menggunakan DOM Manipulation untuk membuat elemen komentar baru dan menyisipkannya langsung ke layar Anda secara _real-time_.
    
2. **Kelahiran Framework Raksasa (React, Vue, Angular):** Melakukan DOM Manipulation secara manual (seperti contoh di atas) menggunakan _Vanilla JavaScript_ akan sangat melelahkan jika _website_ Anda sebesar Tokopedia. Oleh karena itu, _programmer_ menciptakan _framework_ modern seperti **React.js**. React pada dasarnya adalah mesin pemanipulasi DOM otomatis yang luar biasa cepat dan efisien.
    
3. **Animasi dan UI Interaktif:** Fitur seperti _Dark Mode Toggle_, menu _Dropdown_, hingga _Slider_ gambar semuanya bergantung pada JavaScript yang menambah atau menghapus _class_ CSS di dalam DOM secara instan.
