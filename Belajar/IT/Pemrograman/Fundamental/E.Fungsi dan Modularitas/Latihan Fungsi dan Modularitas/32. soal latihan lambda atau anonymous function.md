
### **Soal 1: Konversi Fungsi Tradisional ke Arrow (Refactoring)**

Latihlah "mata" Anda untuk mengubah kode lama yang panjang menjadi kode modern yang elegan.

**Tugas di VS Code:**

1. Anda memiliki fungsi tradisional berikut:
    
    JavaScript
    
    ```
    function hitungKuadrat(n) {
        return n * n;
    }
    ```
    
2. Ubahlah fungsi di atas menjadi sebuah **Arrow Function** yang disimpan dalam variabel `const kuadrat`.
    
3. Gunakan fitur _Implicit Return_ (tulis hanya dalam satu baris tanpa kata `return` dan tanpa kurung kurawal `{}`).
    
4. Panggil `kuadrat(5)` dan tampilkan hasilnya ke terminal.

### **Soal 2: Operasi Array Sederhana (forEach dengan Arrow)**

Mari kita simulasikan pengolahan data daftar belanja menggunakan fungsi anonim yang diselipkan sebagai argumen.

**Tugas di VS Code:**

1. Buat Array: `let barang = ["Laptop", "Mouse", "Keyboard"];`
    
2. Gunakan metode `.forEach()` pada array tersebut.
    
3. Di dalam kurung `.forEach()`, masukkan sebuah **Arrow Function** yang menerima satu parameter (misal: `item`).
    
4. Di dalam fungsi tersebut, tampilkan pesan: `"Barang: [item] tersedia di gudang."`
    
5. Jalankan di terminal dan lihat bagaimana fungsi anonim tersebut bekerja untuk setiap isi array.

### **Soal 3: Filter Data Cepat (The Power of Arrow Function)**

Salah satu kegunaan paling sakti dari Arrow Function adalah untuk menyaring data secara instan.

**Tugas di VS Code:**

1. Buat Array berisi angka: `let nilaiUjian = [60, 85, 90, 50, 75, 100];`
    
2. Gunakan metode `.filter()` untuk membuat array baru berisi nilai yang **lebih besar dari 70**.
    
3. Gunakan Arrow Function di dalam `.filter()` tersebut.
    
    - Contoh: `let lulus = nilaiUjian.filter(skor => skor > 70);`
        
4. Tampilkan variabel `lulus` ke terminal.
    
5. **Analisis:** Bandingkan betapa pendeknya kode ini dibandingkan jika Anda harus menggunakan `for loop` dan `if`.

### **Pesan dari Mentor IT:**

- **Kapan Pakai Arrow Function?** Pakailah untuk fungsi-fungsi pendek yang sifatnya "sekali pakai" atau fungsi pembantu di dalam Array methods (`map`, `filter`, `reduce`).
    
- **Kapan Pakai Fungsi Biasa?** Gunakan fungsi bernama (`function`) untuk logika yang sangat panjang, kompleks, atau jika Anda ingin fungsi tersebut bisa dipanggil dari mana saja di dalam file (karena fitur _hoisting_).
