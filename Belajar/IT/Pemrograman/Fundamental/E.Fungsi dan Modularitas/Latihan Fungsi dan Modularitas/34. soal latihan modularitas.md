### **Soal 1: Membuat "Gudang Alat" (Export)**

Mari kita buat modul yang berisi fungsi-fungsi pembantu untuk mengolah teks.

**Tugas di VS Code:**

1. Buat file bernama `stringHelper.js`.
    
2. Di dalamnya, buat dan **export** dua fungsi:
    
    - `keHurufBesar(teks)`: Mengembalikan teks dalam kapital (`.toUpperCase()`).
        
    - `potongTeks(teks, panjang)`: Mengembalikan potongan teks sesuai panjang yang ditentukan (`.slice(0, panjang)`).
        
3. Tambahkan **export** untuk sebuah konstanta: `export const VERSI_MODUL = "1.0.0";`.
    

---

### **Soal 2: Merakit di File Utama (Import)**

Sekarang, mari kita gunakan alat-alat dari `stringHelper.js` di file utama kita.

**Tugas di VS Code:**

1. Buat file bernama `main.js` di folder yang sama.
    
2. Gunakan perintah `import { ... } from './stringHelper.js';` untuk mengambil semua fungsi dan konstanta dari file sebelah.
    
3. Gunakan fungsi `keHurufBesar` untuk mengubah nama Anda menjadi kapital.
    
4. Gunakan fungsi `potongTeks` untuk memotong kalimat `"Belajar Modularisasi itu Seru"` menjadi hanya 7 karakter.
    
5. Tampilkan `VERSI_MODUL` ke terminal.
    
6. Jalankan dengan: `node main.js`.
    

---

### **Soal 3: Modularisasi Logika Kasir (Studi Kasus)**

Pisahkan logika perhitungan pajak agar bisa digunakan di banyak tempat.

**Tugas di VS Code:**

1. Buat file `pajak.js`. Export fungsi `hitungPPN(harga)` yang mengembalikan `harga * 0.11`.
    
2. Buat file `app.js`. Import fungsi `hitungPPN`.
    
3. Di `app.js`, buat variabel `hargaBarang = 500000`.
    
4. Hitung total yang harus dibayar (harga + pajak) dan tampilkan hasilnya.
    

---

### **Pesan dari Mentor IT:**

- **Gunakan Nama File yang Deskriptif:** Jangan beri nama file `script1.js`, `script2.js`. Gunakan nama seperti `userController.js`, `apiClient.js`, atau `formatters.js`.
    
- **Path File:** Jangan lupa gunakan `./` (titik garis miring) untuk merujuk ke file yang berada di folder yang sama. Tanpa `./`, Node.js akan mengira Anda sedang mencari modul yang diunduh dari internet (NPM).
    

Silakan jalankan `node main.js`. Jika Anda berhasil melihat teks yang terpotong dan hasil perhitungan pajak dari file terpisah, selamat! Anda sudah siap bekerja dalam tim pengembang profesional.
