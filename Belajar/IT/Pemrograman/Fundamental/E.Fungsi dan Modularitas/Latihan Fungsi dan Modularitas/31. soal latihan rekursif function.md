### **Soal 1: Hitung Mundur Rekursif (Basic Recursion)**

Mari kita buat fungsi hitung mundur tanpa menggunakan `for` atau `while` loop.

**Tugas di VS Code:**

1. Buat fungsi bernama `hitungMundur` yang menerima satu parameter `n`.
    
2. Tentukan **Base Case**: Jika `n` kurang dari 0, tampilkan `"Selesai!"` dan gunakan `return;` (untuk menghentikan fungsi).
    
3. Tentukan **Recursive Case**:
    
    - Tampilkan nilai `n` ke terminal.
        
    - Panggil kembali fungsi `hitungMundur` dengan argumen `n - 1`.
        
4. Panggil fungsi tersebut dengan angka `5`.
    
5. **Analisis:** Apa yang terjadi jika Anda lupa menuliskan baris `n - 1` dan hanya menulis `n`? (Jangan dicoba terlalu lama, atau VS Code Anda akan _hang_ karena _Stack Overflow_!).

### **Soal 2: Penjumlahan Beruntun (Recursive Sum)**

Buatlah fungsi yang menjumlahkan semua angka dari `n` sampai 1. (Contoh: jika input 4, hasilnya 4+3+2+1 = 10).

**Tugas di VS Code:**

1. Buat fungsi `totalAngka(n)`.
    
2. **Base Case**: Jika `n === 1`, maka `return 1`.
    
3. **Recursive Case**: Kembalikan `n + totalAngka(n - 1)`.
    
4. Tampilkan hasil dari `totalAngka(10)` ke terminal.
    
5. **Logika:** Bayangkan bagaimana komputer menumpuk (stack) angka 10, lalu 9, lalu 8, sampai menyentuh angka 1, baru kemudian menjumlahkannya saat tumpukan dibongkar kembali.

### **Soal 3: Menelusuri Menu Bersarang (Real-World Case)**

Ini adalah simulasi bagaimana rekursi digunakan untuk membaca data kategori produk yang memiliki sub-kategori (Tree Structure).

**Tugas di VS Code:**

1. Anda memiliki data objek kategori seperti ini:
    
    JavaScript
    
    ```
    const kategori = {
        nama: "Elektronik",
        sub: {
            nama: "Laptop",
            sub: {
                nama: "Gaming",
                sub: null // Base Case: Tidak ada sub-kategori lagi
            }
        }
    };
    ```
    
2. Buat fungsi rekursif `tampilkanKategori(obj)`.
    
3. **Base Case**: Jika `obj === null`, maka berhenti (`return`).
    
4. **Recursive Case**:
    
    - Tampilkan `obj.nama` ke terminal.
        
    - Panggil kembali `tampilkanKategori(obj.sub)`.
        
5. Panggil fungsi tersebut dengan objek `kategori` di atas.

### **Pesan dari Mentor IT:**

Rekursi sangat hebat untuk data yang strukturnya bercabang (seperti folder komputer atau menu navigasi), tetapi untuk tugas sederhana seperti menjumlahkan angka di dalam Array, **Looping biasa (`for/while`)** biasanya lebih cepat dan hemat memori. Gunakan rekursi saat masalahnya memang memiliki pola "masalah yang sama di dalam masalah".

Silakan buat file `rekursif.js` dan jalankan dengan `node rekursif.js`. Jika Anda sudah bisa melihat urutan kategori dari "Elektronik" sampai "Gaming" muncul di terminal, selamat! Anda sudah berhasil menguasai salah satu teknik logika paling tingkat tinggi di pemrograman.
