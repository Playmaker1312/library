Selamat! Jika **Functional Programming** adalah tentang transformasi data, maka **Reactive Programming** adalah tentang **aliran data (streams)** dan bagaimana aplikasi Anda bereaksi terhadap perubahan secara otomatis.

Ini adalah paradigma yang sangat populer untuk membangun aplikasi yang sangat interaktif, seperti _dashboard_ real-time, sistem _chat_, atau media sosial yang kontennya terus mengalir tanpa henti.

---

## 1. Apa itu Reactive Programming?

**"Program yang Bereaksi terhadap Kejadian (Events)."**

Dalam pemrograman tradisional, jika Anda mengubah nilai `A`, maka `B` yang bergantung pada `A` tidak akan berubah sampai Anda memanggilnya lagi. Dalam **Reactive Programming**, begitu `A` berubah, `B` akan otomatis terupdate.

### Analogi: Spreadsheet (Excel)

Bayangkan Anda punya sel `C1` dengan rumus `=A1+B1`.

- Saat Anda mengubah angka di `A1`, angka di `C1` **langsung berubah otomatis**.
    
- Anda tidak perlu menekan tombol "Hitung Ulang". Inilah inti dari sistem yang reaktif.
    

---

## 2. Konsep Utama: Data Streams & Observables

Dalam Reactive Programming, segala sesuatu adalah **Stream** (Aliran). Klik mouse, pesan dari server, hingga input keyboard diperlakukan sebagai aliran data yang bisa kita:

- **Listen (Dengarkan):** Menunggu data lewat.
    
- **Filter (Saring):** Hanya ambil data yang penting.
    
- **Transform (Ubah):** Mengubah bentuk data sebelum dipakai.
    

### Komponen Penting:

1. **Observable (Sumber):** Objek yang memancarkan data.
    
2. **Observer (Pendengar):** Objek yang menunggu dan bereaksi saat data muncul.
    
3. **Operators:** Fungsi-fungsi sakti untuk memanipulasi aliran data (seperti `map`, `filter`, `merge`, `debounce`).
    

---

## 3. Keunggulan: Menangani Kerumitan Asinkron

Bayangkan Anda ingin membuat fitur **"Auto-complete Search"**. Anda harus menangani:

1. User mengetik (Event input).
    
2. Tunggu sebentar agar tidak terlalu banyak request ke server (**Debounce**).
    
3. Batalkan request lama jika user mengetik huruf baru (**SwitchMap**).
    
4. Tampilkan hasil hanya jika datanya berbeda dari sebelumnya (**DistinctUntilChanged**).
    

Dengan kode biasa, ini akan menjadi mimpi buruk _if-else_. Dengan **Reactive Programming**, ini hanya butuh 5-10 baris kode yang elegan.

---

## 4. Library Populer

Paradigma ini biasanya diimplementasikan melalui library **Reactive Extensions (Rx)** yang tersedia di hampir semua bahasa:

- **RxJS:** Standar industri untuk Web Development (sangat kuat di **Angular**).
    
- **RxJava / RxKotlin:** Sangat populer untuk pengembangan aplikasi **Android**.
    
- **RxSwift:** Untuk pengembangan aplikasi **iOS**.
    
- **Project Reactor:** Digunakan di ekosistem **Java Spring Boot** (WebFlux) untuk sistem backend yang sangat cepat (_high throughput_).
    

---

## 5. Hubungan dengan Paradigma Lain

Reactive Programming sering disebut sebagai **Functional Reactive Programming (FRP)** karena ia menggunakan teknik fungsional (seperti _pure functions_ dan _immutability_) untuk mengelola aliran datanya.

|Fitur|Imperatif (Biasa)|Reactive|
|---|---|---|
|**Gaya**|"Tarik" data saat butuh (Pull).|"Dorong" data saat tersedia (Push).|
|**Data**|Variabel tunggal/Array.|Streams (Aliran berkelanjutan).|
|**Waktu**|Berurutan (Sikuen).|Berdasarkan kejadian (Event-based).|

## 6. Contoh Singkat (RxJS)

JavaScript

```
import { fromEvent } from 'rxjs';
import { map, filter } from 'rxjs/operators';

// Membuat stream dari klik mouse
const clicks = fromEvent(document, 'click');

// Hanya bereaksi jika klik dilakukan di sisi kiri layar
const leftClicks = clicks.pipe(
  filter(ev => ev.clientX < window.innerWidth / 2),
  map(ev => `Klik di koordinat X: ${ev.clientX}`)
);

leftClicks.subscribe(msg => console.log(msg));
```
