Sepertinya Anda ingin memastikan data Anda aman tersimpan di _hard drive_ secara permanen sebelum kita bermain-main dengan waktu! Pilihan yang sangat bijak.

Selama ini, setiap kali Anda membuat variabel atau _Array_, data tersebut disimpan di dalam **RAM (Memori Sementara)**. Begitu program dimatikan atau _browser_ di-_refresh_, data itu musnah tanpa sisa. Untuk membuat data bertahan hidup meskipun komputer dimatikan, kita harus menyimpannya ke dalam _Hard Drive/SSD_.

Di sinilah **File I/O** beraksi.

---

## 1. Definisi Singkat

**File I/O (Input / Output)** adalah proses di mana sebuah program komputer berkomunikasi dengan sistem penyimpanan luar (_storage_).

- **Input (Membaca / Read):** Program mengambil data yang sudah ada di dalam sebuah file (seperti `.txt` atau `.csv`) dan memasukkannya ke dalam memori (RAM) agar bisa diproses.
    
- **Output (Menulis / Write):** Program mengambil data dari dalam memori (RAM) dan mencetaknya menjadi sebuah file baru (atau menimpa file lama) di dalam _hard drive_.
    

## 2. Analogi: Membaca Buku dan Menulis Buku Harian

Bayangkan otak Anda adalah RAM (memori program) dan lemari buku Anda adalah _Hard Drive_ (penyimpanan permanen).

- **Membaca (Input):** Saat Anda butuh resep masakan, Anda tidak mungkin mengingat semuanya di otak. Anda mengambil buku resep dari lemari, membukanya, dan membacanya (mentransfer informasi dari buku ke otak Anda).
    
- **Menulis (Output):** Saat Anda memiliki ide cemerlang, ide itu ada di otak Anda. Jika Anda tidur, ide itu mungkin hilang. Maka, Anda mengambil pena dan menuliskannya ke dalam buku harian lalu menyimpannya di lemari agar bisa dibaca lagi besok.
    

## 3. Poin-Poin Penting

- **TXT (Teks Biasa):** Format file paling murni dan ringan. Tidak ada warna, tidak ada _font_ tebal, hanya deretan karakter biasa. Sangat bagus untuk menyimpan catatan atau _log_ (catatan aktivitas program).
    
- **CSV (Comma Separated Values):** Ini adalah "bentuk purba" dari Microsoft Excel. Data yang berbentuk tabel disimpan dalam format teks biasa, di mana setiap kolom dipisahkan oleh tanda koma `,` dan setiap baris dipisahkan oleh _Enter_ (baris baru). Ini adalah format standar untuk ekspor/impor data di dunia teknologi.
    
- **Modul Bawaan:** Di JavaScript (khususnya lingkungan _backend_ Node.js), kita menggunakan modul bawaan bernama `fs` (_File System_) untuk melakukan operasi ini.
    

## 4. Contoh Implementasi

Mari kita lihat bagaimana JavaScript di Node.js membaca dan menulis file teks dan CSV.

_Catatan: Kita akan menggunakan metode `writeFileSync` dan `readFileSync` yang bersifat **Synchronous** (menunggu sampai selesai) agar lebih mudah dipahami._

JavaScript

```
// Memanggil modul File System (fs) bawaan Node.js
const fs = require('fs');

// ==========================================
// 1. MENULIS DAN MEMBACA FILE .TXT
// ==========================================

// Menulis (Output): Membuat file baru bernama 'catatan.txt'
let pesan = "Halo Dunia! Ini adalah pesan rahasia yang tidak akan hilang saat laptop mati.";
fs.writeFileSync('catatan.txt', pesan);
console.log("File TXT berhasil dibuat!");

// Membaca (Input): Mengambil isi file 'catatan.txt'
// (Kita wajib menyertakan 'utf-8' agar komputer tahu ini adalah teks manusia, bukan kode biner mesin)
let isiCatatan = fs.readFileSync('catatan.txt', 'utf-8');
console.log("Isi file TXT:", isiCatatan);


// ==========================================
// 2. MENULIS DAN MEMBACA FILE .CSV
// ==========================================

// Menulis CSV: Ingat, kolom dipisah koma (,), baris dipisah Enter (\n)
let dataKaryawan = "Nama,Jabatan,Gaji\nAndi,Programmer,10000000\nSiti,Desainer,8500000";
fs.writeFileSync('database.csv', dataKaryawan);
console.log("\nFile CSV berhasil dibuat!");

// Membaca dan Memecah CSV: Mengubah teks biasa kembali menjadi Array yang berguna!
let isiCSV = fs.readFileSync('database.csv', 'utf-8');

// Memecah teks berdasarkan baris baru (\n)
let barisData = isiCSV.split('\n'); 

console.log("Data CSV yang sudah di-parsing:");
for (let i = 0; i < barisData.length; i++) {
    // Memecah setiap baris berdasarkan tanda koma
    let kolom = barisData[i].split(','); 
    console.log(`- ${kolom[0]} bekerja sebagai ${kolom[1]}`);
}
/* OUTPUT CSV:
- Nama bekerja sebagai Jabatan (Ini baris judul)
- Andi bekerja sebagai Programmer
- Siti bekerja sebagai Desainer
*/
```

## 5. Koneksi dengan Web Development

Operasi _File I/O_ adalah makanan sehari-hari _Backend Developer_:

1. **Fitur Ekspor Laporan (CSV):** Saat bos Anda menekan tombol "Download Laporan Penjualan Bulan Ini" di _dashboard admin_, _backend_ Anda akan menarik data dari _database_, menyusunnya menjadi _string_ CSV, dan menyimpannya sebagai file `laporan.csv` untuk diunduh.
    
2. **Server Logging (TXT):** Jika _website_ Anda tiba-tiba _error_ jam 3 pagi, Anda tidak mungkin terus menatap layar. Program Anda dirancang untuk secara otomatis melakukan `fs.appendFileSync('error.log', 'Jam 03:00 - Database mati')`. Besok paginya, Anda tinggal membaca file TXT tersebut untuk mengetahui penyebabnya.
    
3. **Konfigurasi Keamanan (.env):** _Password database_ atau kunci API rahasia tidak pernah ditulis langsung di dalam kode. Mereka disimpan di file teks khusus bernama `.env`, dan program akan membaca file tersebut (Input) saat pertama kali dinyalakan.
