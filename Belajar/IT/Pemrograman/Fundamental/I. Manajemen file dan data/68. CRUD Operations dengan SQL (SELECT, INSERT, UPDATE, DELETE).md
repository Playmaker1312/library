Selamat datang di jantung pengelolaan data! Di materi sebelumnya, Anda sudah memahami perbedaan antara lemari arsip (SQL) dan gudang logistik (NoSQL). Sekarang, pertanyaannya adalah: **Bagaimana cara kita memberikan perintah kepada lemari arsip tersebut?**

Untuk berbicara dengan _database_ relasional (seperti MySQL atau PostgreSQL), Anda harus menggunakan bahasa **SQL** (_Structured Query Language_). Di dalam bahasa ini, terdapat empat mantra utama yang menguasai 90% aktivitas aplikasi web di seluruh dunia, yang dikenal dengan singkatan **CRUD**.

---

## 1. Definisi Singkat

**CRUD** adalah akronim dari empat fungsi dasar penyimpanan persisten. Dalam bahasa SQL, keempat fungsi ini dipetakan menjadi perintah-perintah berikut:

- **C**reate (Membuat data baru) ➔ Perintah SQL: `INSERT`
    
- **R**ead (Membaca/Mencari data) ➔ Perintah SQL: `SELECT`
    
- **U**pdate (Mengubah data yang ada) ➔ Perintah SQL: `UPDATE`
    
- **D**elete (Menghapus data) ➔ Perintah SQL: `DELETE`
    

## 2. Analogi: Buku Induk Siswa

Bayangkan Anda adalah seorang staf tata usaha sekolah yang memegang Buku Induk Siswa:

- **CREATE (`INSERT`):** Saat ada siswa baru mendaftar, Anda mengambil pena dan menuliskan nama, kelas, dan tanggal lahirnya di baris yang baru.
    
- **READ (`SELECT`):** Kepala sekolah meminta Anda mencari daftar semua siswa yang berada di "Kelas 10". Anda membuka buku dan membaca baris demi baris untuk memfilter informasi tersebut.
    
- **UPDATE (`UPDATE`):** Seorang siswa pindah rumah. Anda mencari namanya di buku, lalu menghapus alamat lamanya dengan _tipe-x_ dan menuliskan alamat barunya.
    
- **DELETE (`DELETE`):** Seorang siswa lulus atau pindah sekolah. Anda mencoret seluruh baris data siswa tersebut dari buku induk.
    

## 3. Poin-Poin Penting (Aturan Emas SQL)

- **Tanda Bintang (`*`):** Dalam perintah `SELECT`, tanda bintang berarti "Ambil SEMUA kolom". Ini praktis, tetapi boros memori jika tabel Anda punya 50 kolom dan Anda hanya butuh kolom "Nama".
    
- **Klausa `WHERE` (Filter Wajib):** Ini adalah kata yang paling menyelamatkan nyawa di SQL. `WHERE` berfungsi sebagai filter penentu target (Misal: _Ubah data ini DIMANA namanya adalah 'Budi'_).
    
- **Mimpi Buruk Junior Developer:** Melakukan perintah `UPDATE` atau `DELETE` **tanpa** menggunakan klausa `WHERE`. Jika Anda mengetik `DELETE FROM Karyawan;` (tanpa `WHERE`), seluruh data karyawan di perusahaan akan terhapus dalam sekejap! Selalu pastikan Anda menentukan target yang spesifik.
    

## 4. Contoh Implementasi (Sintaks SQL)

Mari kita lihat bagaimana keempat mantra ini ditulis secara nyata. Anggaplah kita memiliki tabel bernama `karyawan` dengan kolom: `id`, `nama`, `posisi`, dan `gaji`.

SQL

```
-- ==========================================
-- 1. CREATE (INSERT) - Memasukkan Data Baru
-- ==========================================
-- Sintaks: INSERT INTO nama_tabel (kolom1, kolom2) VALUES (nilai1, nilai2);
INSERT INTO karyawan (nama, posisi, gaji) 
VALUES ('Andi Saputra', 'Programmer', 10000000);

INSERT INTO karyawan (nama, posisi, gaji) 
VALUES ('Siti Aminah', 'Desainer', 8500000);


-- ==========================================
-- 2. READ (SELECT) - Mengambil / Membaca Data
-- ==========================================
-- Mengambil SEMUA kolom dari seluruh karyawan
SELECT * FROM karyawan;

-- Mengambil HANYA kolom nama dan gaji, KHUSUS untuk Programmer
SELECT nama, gaji FROM karyawan WHERE posisi = 'Programmer';


-- ==========================================
-- 3. UPDATE (UPDATE) - Mengubah Data
-- ==========================================
-- Sintaks: UPDATE nama_tabel SET kolom = nilai_baru WHERE kondisi;
-- Kasus: Andi naik gaji menjadi 12 juta!
UPDATE karyawan 
SET gaji = 12000000 
WHERE nama = 'Andi Saputra'; 
-- AWAS: Jika WHERE lupa ditulis, SEMUA orang akan bergaji 12 juta!


-- ==========================================
-- 4. DELETE (DELETE) - Menghapus Data
-- ==========================================
-- Sintaks: DELETE FROM nama_tabel WHERE kondisi;
-- Kasus: Siti *resign* dari perusahaan.
DELETE FROM karyawan 
WHERE nama = 'Siti Aminah';
```

## 5. Koneksi dengan Web Development

Operasi CRUD di database ini adalah fondasi utama dari **REST API** yang dibangun oleh _Backend Developer_. Ada pemetaan langsung antara metode internet (HTTP) dengan operasi SQL:

1. **Metode POST (Create):** Saat Anda mengisi formulir pendaftaran di sebuah _website_ dan menekan tombol "Daftar", _browser_ mengirimkan _request_ POST. _Server backend_ menerima data tersebut dan menjalankan perintah `INSERT` ke database.
    
2. **Metode GET (Read):** Saat Anda membuka halaman profil Instagram, _browser_ mengirimkan _request_ GET. _Server_ menjalankan perintah `SELECT` untuk mengambil foto-foto Anda dari database dan mengirimkannya ke layar Anda.
    
3. **Metode PUT/PATCH (Update):** Saat Anda mengubah foto profil atau mengganti _password_, _server_ mengeksekusi perintah `UPDATE` berdasarkan _request_ ini.
    
4. **Metode DELETE (Delete):** Saat Anda menekan ikon tempat sampah pada sebuah komentar, _server_ menerima _request_ DELETE dan mengeksekusi perintah `DELETE` di SQL.
    

Dengan menguasai operasi CRUD ini, Anda secara teknis sudah memiliki kemampuan inti untuk membangun hampir semua jenis aplikasi manajemen data di dunia (Aplikasi Kasir, Sistem Rumah Sakit, E-Commerce, dll). Semuanya bermuara pada bagaimana kita membuat, membaca, memperbarui, dan menghapus data.
