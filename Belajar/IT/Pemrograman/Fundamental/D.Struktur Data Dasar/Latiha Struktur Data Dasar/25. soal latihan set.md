### **Soal 1: Pembersih Username Ganda (Auto-Deduplication)**

Bayangkan Anda sedang memproses data pendaftar webinar yang masuk lewat formulir, tapi banyak orang yang mendaftar berkali-kali dengan nama yang sama.

**Tugas di VS Code:**

1. Buat Array: `let pendaftarKotor = ["Andi", "Budi", "Siti", "Andi", "Rani", "Budi"];`
    
2. Buat variabel `setPendaftar` yang mengubah `pendaftarKotor` menjadi sebuah **Set**.
    
3. Tampilkan isi `setPendaftar` ke terminal. Perhatikan berapa nama yang tersisa.
    
4. Tambahkan satu nama baru `"Eko"` ke dalam Set tersebut menggunakan `.add()`.
    
5. Coba tambahkan lagi nama `"Siti"` ke dalam Set. Lihat apakah jumlahnya bertambah atau tetap.

### **Soal 2: Fitur Cek Keanggotaan Cepat (Checking)**

Set sangat efisien untuk mengecek apakah seseorang ada dalam daftar tanpa harus menyisir seluruh isi daftar dari awal sampai akhir.

**Tugas di VS Code:**

1. Buat sebuah Set bernama `blacklist` yang berisi: `"Spammer1"`, `"Penipu2"`, `"UserKasar"`.
    
2. Buat variabel `userBaru` berisi teks `"Spammer1"`.
    
3. Gunakan metode `.has()` untuk mengecek apakah `userBaru` ada di dalam `blacklist`.
    
4. Gunakan **Percabangan (If-Else)**:
    
    - Jika ada (true), tampilkan: `"Maaf, user ini dilarang masuk!"`.
        
    - Jika tidak ada (false), tampilkan: `"Selamat datang di komunitas kami."`.

### **Soal 3: Konversi Balik ke Array (Spread Operator)**

Seringkali setelah data dibersihkan oleh Set, kita perlu mengubahnya kembali menjadi Array agar bisa diolah dengan metode Array lainnya (seperti `.pop()` atau `.push()`).

**Tugas di VS Code:**

1. Buat Set berisi angka-angka unik: `let angkaUnik = new Set([10, 20, 30, 40]);`
    
2. Hapus angka `20` dari Set tersebut menggunakan `.delete()`.
    
3. Ubah Set tersebut kembali menjadi Array menggunakan **Spread Operator** `[...]`.
    
    - Contoh: `let hasilArray = [...angkaUnik];`
        
4. Tampilkan `hasilArray` ke terminal dan cek tipenya (apakah sekarang sudah berbentuk kurung siku `[]`?).
    

---

### **Tips IT Pro: Kapan Pakai Array vs Set?**

- Gunakan **Array** jika urutan itu penting (misal: antrean loket) atau jika Anda memang mengizinkan data ganda (misal: riwayat transaksi).
    
- Gunakan **Set** jika Anda hanya peduli pada **keunikan** (misal: daftar ID kategori, daftar tag blog, atau daftar negara yang pernah dikunjungi).
