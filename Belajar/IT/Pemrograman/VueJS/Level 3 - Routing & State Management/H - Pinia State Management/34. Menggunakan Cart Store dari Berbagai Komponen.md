# 34. Menggunakan Cart Store dari Berbagai Komponen

## Penjelasan

Setelah cart store dibuat (Poin 33), sekarang kita **gunakan** store tersebut di komponen-komponen yang membutuhkan. Keindahan Pinia: `useCartStore()` bisa dipanggil dari komponen **mana saja** — tanpa props, tanpa emit, tanpa event bus.

Komponen yang akan menggunakan cart store:

| Komponen | Akses |
|---|---|
| **AppHeader.vue** | Membaca `totalItems` untuk badge counter |
| **BookCard.vue** | Memanggil `addItem(book)` saat tombol "Tambah" diklik |
| **CartView.vue** | Membaca `items`, `totalPrice`, `isEmpty` untuk halaman cart |

---

## Fungsi

- Menghilangkan **props drilling** — AppHeader tidak perlu terima prop dari App.vue
- Menghilangkan **event emit** — BookCard tidak perlu emit ke parent
- Semua komponen membaca dan menulis ke **sumber data yang SAMA** (single source of truth)
- State tetap konsisten meskipun diubah dari komponen mana pun

---

## Cara Implementasi

### 1. AppHeader.vue — Tampilkan Badge Counter

```vue
<script setup lang="ts">
import { useCartStore } from '@/stores/cart'

const cart = useCartStore()
</script>

<template>
  <header>
    <h1>BookStore</h1>
    <nav>
      <RouterLink to="/">Beranda</RouterLink>
      <RouterLink to="/cart">
        🛒 Cart
        <span v-if="!cart.isEmpty" class="badge">{{ cart.totalItems }}</span>
      </RouterLink>
    </nav>
  </header>
</template>

<style scoped>
.badge {
  background: #e74c3c;
  color: white;
  border-radius: 50%;
  padding: 2px 8px;
  font-size: 0.75rem;
  margin-left: 4px;
}
</style>
```

**Bandingkan dengan Poin 23 (tanpa Pinia):**
```diff
- defineProps<{ cartCount: number }>()  // ← props dari parent
+ const cart = useCartStore()           // ← akses langsung ke store
```

### 2. BookCard.vue — Tambah ke Keranjang

```vue
<script setup lang="ts">
import { useCartStore } from '@/stores/cart'
import type { Book } from '@/types/book'

const props = defineProps<{ book: Book }>()
const cart = useCartStore()
</script>

<template>
  <div class="book-card">
    <h3>{{ book.title }}</h3>
    <p>{{ book.author }}</p>
    <p class="price">Rp{{ book.price.toLocaleString() }}</p>
    <button @click="cart.addItem(props.book)">
      + Tambah ke Keranjang
    </button>
  </div>
</template>
```

**Bandingkan dengan Poin 22 (tanpa Pinia):**
```diff
- const emit = defineEmits<{ 'add-to-cart': [book: Book] }>()
- <button @click="emit('add-to-cart', book)">  // ← emit ke parent
+ const cart = useCartStore()
+ <button @click="cart.addItem(props.book)">    // ← langsung ke store
```

### 3. App.vue — Bersih dari State Management

Tanpa Pinia, `App.vue` jadi perantara yang bengkak:

```diff
<!-- App.vue SEBELUM Pinia (Poin 23) -->
- <script setup lang="ts">
- import { ref, computed } from 'vue'
- const cartItems = ref<Book[]>([])
- const cartCount = computed(() => cartItems.value.length)
- function addToCart(book: Book) { cartItems.value.push(book) }
- </script>
- <template>
-   <AppHeader :cart-count="cartCount" @add-to-cart="addToCart" />
-   <HomeView @add-to-cart="addToCart" />
- </template>
```

Dengan Pinia, `App.vue` kembali bersih:

```vue
<script setup lang="ts">
import AppHeader from '@/components/AppHeader.vue'
import { RouterView } from 'vue-router'
</script>

<template>
  <AppHeader />
  <main>
    <RouterView />
  </main>
</template>
```

## ⚠️ storeToRefs — Jangan Kehilangan Reaktivitas!

**Ini penting!** Jika kamu destructure store di `<script setup>`:

```typescript
// ❌ SALAH — kehilangan reaktivitas!
const { totalItems, isEmpty } = useCartStore()
```

`totalItems` dan `isEmpty` adalah hasil **salinan nilai saat itu** — tidak akan update saat state berubah. **Gunakan `storeToRefs()`:**

```typescript
// ✅ BENAR — reaktif
import { storeToRefs } from 'pinia'

const cart = useCartStore()
const { totalItems, isEmpty } = storeToRefs(cart)

// Actions dan non-ref tetap bisa di-destructure biasa
const { addItem, removeItem } = cart
```

**Aturan praktis:**

| Jenis | Destructure biasa? | Pakai storeToRefs? |
|---|---|---|
| **State** (`items`) | ❌ | ✅ |
| **Getters** (`totalItems`) | ❌ | ✅ |
| **Actions** (`addItem`) | ✅ | ❌ (tetap reaktif) |

Cara paling aman untuk pemula: **jangan destructure**. Akses melalui object:

```typescript
const cart = useCartStore()
// cart.totalItems ✅, cart.addItem(book) ✅
```

## Analogi — Toko Buku

Papan informasi digital sudah terpasang (**Poin 33**). Sekarang kita lihat siapa yang menulis dan membaca:

| Komponen | Peran | Tindakan |
|---|---|---|
| **BookCard** (pegawai etalase) | Menulis di papan | "Clean Code +1" → `cart.addItem(book)` |
| **AppHeader** (kasir) | Membaca papan | Melihat angka counter, update badge |
| **CartView** (lantai kasir) | Membaca detail | Daftar lengkap + total harga |

**Tanpa papan (Poin 22-23):**
Pegawai etalase teriak ke manajer → "Clean Code terjual 1!" → Manajer catat → Manajer teriak ke kasir → "Total sekarang 3!"

**Dengan papan (Poin 33-34):**
Pegawai etalase tulis di papan → "Clean Code +1" → Kasir lihat papan → otomatis tahu. Tidak perlu perantara. Semua akses data yang **sama secara langsung**.

## Dipakai untuk apa

- **E-commerce:** ProductCard → tambah ke cart → header badge update — tanpa props drilling
- **Social media:** Tombol like di setiap post → store update → counter di post dan notifikasi sinkron

## Kesalahan Umum

| Kesalahan | Akibat | Cara Benar |
|---|---|---|
| **Destructure state/getter biasa** | Kehilangan reaktivitas — angka di template tidak pernah update | Pakai `storeToRefs()` atau akses via `cart.totalItems` |
| **Lupa import `useCartStore`** | Error `Cannot find name 'useCartStore'` | Pastikan import: `import { useCartStore } from '@/stores/cart'` |
| **Membuat store baru di tiap komponen** | Boros memori (tapi Pinia cache — hanya 1 instance) | Pinia otomatis singleton; `useCartStore()` di mana saja merujuk ke instance yang sama ✅ |
| **Mutasi state langsung dari komponen** | `items.value.push(...)` — bekerja tapi tidak konsisten | Panggil action: `cart.addItem(book)` |
| **Asumsi store bisa diakses di luar `setup()`** | Error karena Pinia butuh komponen context | Store hanya bisa dipanggil di dalam komponen atau fungsi yang dijalankan dalam konteks Vue app |

## Hubungan dengan Materi Sebelumnya

- **Poin 33:** Store sudah dibuat, sekarang dipakai dari berbagai komponen.
- **Poin 22 (Emit):** BookCard sebelumnya `emit('add-to-cart', book)`. Sekarang langsung `cart.addItem(book)`.
- **Poin 23 (Props Drilling):** `AppHeader` sebelumnya terima prop `cartCount`. Sekarang panggil `useCartStore()` langsung.
- **Poin 18 (Props):** Konsep props masih dipakai untuk data spesifik-komponen (misal `:book="book"`), tapi tidak lagi untuk state global.
- **Poin 28 (Router):** Cart state sekarang global — saat pindah halaman dari `/` ke `/cart`, data cart **tetap ada**. (Masalah ini akan muncul lagi di Poin 35 dan disempurnakan di Poin 36.)

## Soal Latihan

### Soal 1

Di AppHeader, tampilkan badge merah dengan jumlah item hanya jika ada item di cart. Jika cart kosong, badge tidak muncul. Gunakan getter `isEmpty` dari store.

<details>
<summary>Jawaban Soal 1</summary>

```vue
<template>
  <header>
    <nav>
      <RouterLink to="/cart">
        🛒 Cart
        <span v-if="!cart.isEmpty" class="badge">{{ cart.totalItems }}</span>
      </RouterLink>
    </nav>
  </header>
</template>

<script setup lang="ts">
import { useCartStore } from '@/stores/cart'
const cart = useCartStore()
</script>
```

Sudah ada di contoh implementasi di atas. Jika ingin lebih rapi, ekstrak ke computed component sendiri:

```typescript
import { computed } from 'vue'

const showBadge = computed(() => !cart.isEmpty)
```
</details>

### Soal 2

Di BookCard, tambahkan tombol "Hapus dari Keranjang" yang hanya muncul jika buku sudah ada di cart. Gunakan method `items.value.some()` atau buat getter `isInCart` di store.

<details>
<summary>Jawaban Soal 2</summary>

Tambahkan getter di store `cart.ts`:

```typescript
function isInCart(bookId: number): boolean {
  return items.value.some(item => item.book.id === bookId)
}
```

Di BookCard.vue:

```vue
<script setup lang="ts">
const cart = useCartStore()
const adaDiCart = computed(() => cart.isInCart(props.book.id))
</script>

<template>
  <div class="book-card">
    <!-- ... -->
    <button v-if="!adaDiCart" @click="cart.addItem(props.book)">
      + Tambah ke Keranjang
    </button>
    <button v-else class="btn-remove" @click="cart.removeItem(props.book.id)">
      Hapus dari Keranjang
    </button>
  </div>
</template>
```

**Alternatif:** Pakai getter langsung tanpa computed:

```vue
<button v-if="!cart.isInCart(book.id)" @click="cart.addItem(book)">
  + Tambah
</button>
```
</details>
