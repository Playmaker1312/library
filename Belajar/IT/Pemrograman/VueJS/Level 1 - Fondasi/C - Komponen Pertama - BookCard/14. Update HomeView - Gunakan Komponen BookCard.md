# 14. Update HomeView — Gunakan Komponen BookCard

## Penjelasan

Setelah membuat `BookCard` (Poin 12) dan memahami props (Poin 13), sekarang kita gunakan komponen tersebut di **HomeView**. Sebelumnya (di Bagian B), `HomeView` mungkin berisi daftar buku yang ditulis manual satu per satu. Sekarang kita refactor: HomeView cukup **melakukan looping** data buku dan mengirimnya ke `BookCard` melalui `v-for`.

## Fungsi

- **Separation of concerns**: HomeView urus layout halaman dan data; BookCard urus tampilan satu buku
- **DRY (Don't Repeat Yourself)**: Tidak perlu menulis ulang HTML untuk setiap buku
- **Kode lebih bersih**: HomeView jadi pendek, mudah dibaca, dan mudah dimodifikasi
- **Skalabilitas**: Menambah 10 buku = tinggal masukin data ke array, tidak perlu tambah HTML

### 3. Perbandingan kode

| Aspek | Sebelum (tanpa BookCard) | Sesudah (dengan BookCard) |
|-------|--------------------------|---------------------------|
| Jumlah baris template | ~50 baris (untuk 4 buku) | ~12 baris |

## Analogi — Toko Buku

**Seperti punya satu pegawai andalan yang bisa menata etalase dengan pola seragam.**

Bayangkan sebelumnya Anda punya 6 etalase dan setiap etalase ditata manual: "Etalase 1: letakkan buku Laskar Pelangi di sini, tambah label harga, tempel stiker rating. Etalase 2: ulangi proses yang sama untuk Bumi Manusia..." Melelahkan dan rawan salah.

Sekarang Anda punya **satu pegawai (BookCard)** yang terlatih menata etalase dengan pola tetap. Anda tinggal memberinya daftar buku dan berkata: "Tata semua buku ini dengan pola yang sudah kamu tahu." Pegawai akan mengulangi pola yang sama untuk setiap buku — cepat, rapi, konsisten.

| Konsep Vue | Analogi Toko Buku |
|------------|-------------------|
| `v-for` | Perintah: "kerjakan untuk setiap item dalam daftar ini" |
| `books` array | Daftar inventaris buku yang akan dipajang |
| `<BookCard>` | Pegawai andalan yang tahu cara menata etalase |
| `:key` | ID unik buku — biar pegawai tahu buku yang mana yang harus diganti kalau ada perubahan |

## Dipakai untuk Apa di Dunia Nyata

- **Halaman produk e-commerce**: Setiap daftar produk — baik di halaman utama, hasil pencarian, atau kategori — menggunakan pola `v-for` dengan komponen card
- **Dashboard administrasi**: Daftar user, daftar order, daftar transaksi — semuanya looping komponen tabel/card
- **Feed media sosial**: Setiap post, story, atau reels adalah komponen yang di-loop
- **Playlist aplikasi musik**: Daftar lagu — setiap item adalah komponen `TrackRow`

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| **Lupa import BookCard di HomeView** | Error: "Failed to resolve component BookCard" | Import komponen di `<script setup>`: `import BookCard from '@/components/features/BookCard.vue'` |
| **Path import salah** | Error: "Cannot find module" | Pastikan path sesuai struktur folder. Gunakan alias `@` (langsung ke `src/`) |
| **Lupa `:key` di `v-for`** | Vue warning, performa buruk saat data berubah | Selalu tambahkan `:key="book.id"` — gunakan ID unik, bukan index |
| **Props tidak sesuai tipe** | TypeScript error atau data tidak muncul | Cek: apakah `book` di `v-for` punya properti `coverUrl`, `title`, dll? |
| **Data hardcode langsung di HomeView** | Ribet saat data dari API nanti | Gunakan array data, nanti tinggal ganti dengan API call |

## Hubungan dengan Materi Sebelumnya

Di **Poin 13**, kita belajar cara mengirim data via props. Sekarang kita praktikkan: HomeView sebagai parent mengirim data `book` ke BookCard.

Di **Poin 12**, kita membuat BookCard — sekarang kita lihat hasil nyatanya: BookCard dipakai berulang kali dengan data berbeda.

Di **Bagian B** (Poin 10), kita belajar `v-for`. Di sini kita terapkan `v-for` dengan komponen, bukan dengan elemen HTML biasa. Ini adalah pola yang sangat umum di Vue: looping komponen untuk menampilkan daftar data.

**Poin 15 berikutnya**: Setelah halaman HomeView rapi, kita tambahkan layout global — header dan footer yang konsisten di semua halaman.

### Soal 2
Lihat kode di bawah. Ada 2 kesalahan. Temukan dan perbaiki!

```vue
<template>
  <div class="book-list">
    <BookCard v-for="book in books" :book="book" />
  </div>
</template>

<script setup lang="ts">
import BookCard from '@/components/BookCard.vue'

const books = [
  { id: 1, title: 'Atomic Habits', price: 105000 },
]
</script>
```

<details>
<summary>Jawaban</summary>

**Kesalahan 1**: Lupa `:key` di `v-for`. Efek: Vue memberikan warning dan performa update bisa bermasalah. **Perbaikan**: tambahkan `:key="book.id"`.

**Kesalahan 2**: Path import BookCard salah. Di materi, BookCard ada di `@/components/features/BookCard.vue`, bukan `@/components/BookCard.vue`. **Perbaikan**: `import BookCard from '@/components/features/BookCard.vue'`.

Kode yang benar:

```vue
<template>
  <div class="book-list">
    <BookCard v-for="book in books" :key="book.id" :book="book" />
  </div>
</template>

<script setup lang="ts">
import BookCard from '@/components/features/BookCard.vue'

const books = [
  { id: 1, title: 'Atomic Habits', author: 'James Clear', price: 105000, rating: 5, coverUrl: '' },
]
</script>
```

Selain itu, array `books` juga tidak memenuhi kontrak `Book` (kurang `author`, `rating`, `coverUrl`) — tapi ini tergantung strict tidaknya TypeScript config.
</details>
