# 1. Membuat Project Vue.js dengan `create-vue`

## Penjelasan

`create-vue` adalah *scaffolding tool* resmi dari tim Vue untuk membuat project Vue 3 dengan Vite sebagai *build tool*-nya. Vite adalah *bundler* modern yang jauh lebih cepat dari webpack karena menggunakan native ESM dan Hot Module Replacement (HMR) instan.

**Perbedaan Vue 3 vs Vue 2:**
| Aspek | Vue 2 | Vue 3 |
|-------|-------|-------|
| API | Options API | Options API + Composition API |
| TypeScript | Dukungan terbatas | Dukungan first-class |
| Performa | Lebih lambat | 2x lebih cepat (Proxy-based reactivity) |
| Bundle size | ~30kB | ~13kB (tree-shakeable) |
| Suspense | Tidak ada | Ada |
| Fragment | Tidak support | Support |

## Fungsi

`create-vue` menyediakan *project scaffolding* — membuat struktur folder, konfigurasi build, dan boilerplate code sehingga kita tidak perlu setup dari nol.

## Cara Implementasi

```bash
# 1. Buat project baru
npm create vue@latest bookstore-ui

# 2. Akan muncul prompt interaktif, pilih:
# √ Project name: ... bookstore-ui
# √ Add TypeScript? ... YES
# √ Add JSX Support? ... NO
# √ Add Vue Router for Single Page Application? ... YES
# √ Add Pinia for state management? ... YES
# √ Add Vitest for Unit Testing? ... YES
# √ Add an End-to-End Testing Solution? ... NO
# √ Add ESLint for code quality? ... YES
# √ Add Prettier for code formatting? ... YES

# 3. Masuk ke folder project
cd bookstore-ui

# 4. Install dependencies
npm install

# 5. Jalankan dev server
npm run dev

# 6. Buka browser ke http://localhost:5173
```

## Analogi: Toko Buku

Membeli "paket dasar" toko buku — Anda datang ke supplier yang menjual paket toko siap pakai. Di dalamnya sudah ada rak buku (komponen), meja kasir (state management), papan nama (router), dan label harga (styling). Anda tinggal membawa barang dagangan dan mengisi rak-rak tersebut. Tidak perlu bikin rak dari kayu sendiri.

## Dipakai Untuk Apa

- **Startup baru**: Tim ingin prototyping cepat tanpa buang waktu setup build tool.
- **Migrasi Vue 2 ke 3**: Mulai project baru dengan standar terbaru.
- **Open source project**: Kontributor bisa langsung `npm create vue@latest` dan mulai coding tanpa setup manual.
- **Micro-frontend**: Setiap tim bikin *app shell* sendiri dengan konfigurasi minimal.

## Kesalahan Umum

| Kesalahan | Dampak | Cara Hindari |
|-----------|--------|--------------|
| Lupa pilih TypeScript saat setup | Tidak bisa pakai type safety | Pastikan pilih YES saat prompt TypeScript |
| Versi Node < 18 | Error saat `npm install` | Cek Node: `node --version`, upgrade jika perlu |
| Pilih semua opsi tanpa paham | Folder penuh file tidak dikenal | Pilih hanya yang dibutuhkan (TS, Router, Pinia, ESLint cukup) |
| Tidak `cd` ke folder project | File terinstall di folder salah | Perhatikan output: "Scaffolding project in ./bookstore-ui..." |

## Hubungan dengan Materi Sebelumnya

Materi ini adalah **titik awal** dari seluruh pembelajaran Vue.js. Sebelumnya diasumsikan sudah menguasai HTML, CSS, JavaScript (ES6+), dan dasar TypeScript. Tanpa project yang dibuat dengan benar, materi selanjutnya (routing, state management, testing) tidak bisa dijalankan.

## Soal Latihan

**Soal 1:** Sebutkan 3 perbedaan Vue 2 dan Vue 3 yang paling signifikan!

**Jawaban:**
1. **Composition API**: Vue 3 memperkenalkan `setup()` dan `ref()`/`reactive()` sebagai alternatif Options API.
2. **Reactivity berbasis Proxy**: Vue 3 menggunakan `Proxy` (lebih cepat, bisa detect perubahan array/index) vs `Object.defineProperty` di Vue 2.
3. **Tree-shaking**: Vue 3 modular — fitur yang tidak dipakai tidak ikut di-bundle (ukuran final lebih kecil).

**Soal 2:** Apa yang terjadi jika kita menjalankan `npm create vue@latest` tanpa memilih TypeScript? Bagaimana cara menambahkannya setelah project sudah dibuat?

**Jawaban:**
Project akan dibuat tanpa dukungan TypeScript — file berekstensi `.js`, tidak ada `tsconfig.json`, dan IDE tidak memberikan type checking. Untuk menambahkan TypeScript setelah project jadi:
```bash
# 1. Install vue-tsc dan typescript
npm install -D typescript vue-tsc @vue/tsconfig

# 2. Buat tsconfig.json dan tsconfig.app.json manual
# 3. Ubah semua .js menjadi .ts, .vue pakai <script setup lang="ts">
# 4. Update vite.config.ts (ganti dari .js)
```
**Lebih baik create ulang** daripada migrasi manual.
