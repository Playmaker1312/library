# 52. Toast Notification System — Feedback untuk User

## Penjelasan

Toast adalah notifikasi kecil berisi pesan singkat yang muncul temporer di pojok layar, lalu menghilang otomatis setelah beberapa detik. Di Vue 3, kita buat sistem toast dengan **composable `useToast()`** yang menyimpan state global (module-level `ref` array), dan **komponen `ToastContainer.vue`** yang me-render semua toast menggunakan `<Teleport to="body">` agar selalu berada di luar hierarki komponen mana pun.

Setiap toast memiliki interface:

```ts
interface Toast {
  id: number
  type: 'success' | 'error' | 'info' | 'warning'
  message: string
  duration: number // ms
}
```

Animasi masuk/keluar dikelola dengan `<TransitionGroup>`.

## Fungsi

Memberikan feedback non-intrusif untuk aksi user. Setelah user login, logout, menambah buku ke keranjang, atau aksi lain, toast muncul sebagai konfirmasi instan tanpa mengganggu alur kerja.

## Cara Implementasi / Kode

### 1. Composable `useToast`

```ts
// composables/useToast.ts
import { ref } from 'vue'

interface Toast {
  id: number
  type: 'success' | 'error' | 'info' | 'warning'
  message: string
  duration: number
}

const toasts = ref<Toast[]>([])
let nextId = 0

function addToast(type: Toast['type'], message: string, duration = 3000) {
  const id = nextId++
  toasts.value.push({ id, type, message, duration })
  setTimeout(() => {
    removeToast(id)
  }, duration)
}

function removeToast(id: number) {
  toasts.value = toasts.value.filter(t => t.id !== id)
}

export function useToast() {
  return {
    toasts,
    success: (msg: string) => addToast('success', msg),
    error: (msg: string) => addToast('error', msg),
    info: (msg: string) => addToast('info', msg),
    warning: (msg: string) => addToast('warning', msg),
    removeToast,
  }
}
```

### 2. Komponen `ToastContainer`

```vue
<!-- components/ToastContainer.vue -->
<script setup lang="ts">
import { useToast } from '@/composables/useToast'

const { toasts, removeToast } = useToast()
</script>

<template>
  <Teleport to="body">
    <div class="toast-container">
      <TransitionGroup name="toast">
        <div
          v-for="toast in toasts"
          :key="toast.id"
          :class="['toast-item', `toast-${toast.type}`]"
          @click="removeToast(toast.id)"
        >
          {{ toast.message }}
        </div>
      </TransitionGroup>
    </div>
  </Teleport>
</template>
```

### 3. Integrasi — setelah aksi user

```ts
const { success, error } = useToast()

function addItemToCart(book: Book) {

function login() {
```

## Analogi — Toko Buku

Toast seperti **lampu indikator** di toko. Saat pegawai menekan tombol "Tambah ke Keranjang", lampu hijau berkedip sebentar: "Berhasil!". Kalau gagal, lampu merah: "Maaf, stok habis". Lampu ini muncul di pojok kanan bawah dan menghilang sendiri setelah 3 detik — tidak mengganggu aktivitas, tapi memberi tahu status aksi. `Teleport to="body"` memastikan lampu ini selalu muncul di layer teratas, tidak tertutup rak buku.

## Dipakai untuk Apa

- Konfirmasi setelah submit form
- Notifikasi error dari API
- Feedback login/logout
- Indikator sukses simpan/hapus data

## Kesalahan Umum

| Kesalahan | Solusi |
|-----------|--------|
| Dua toast muncul bersamaan, layout bentrok | Pastikan container `flex-direction: column` dan setiap toast punya `min-width` tetap |
| Lupa `clearTimeout` → memory leak | Simpan `setTimeout` dalam variabel, lalu `clearTimeout` saat komponen unmount atau toast di-remove manual |
| Toast tidak accessible (screen reader tidak baca) | Tambahkan `role="alert"` dan `aria-live="polite"` pada container toast |

## Soal Latihan

### Soal 1

Buat fungsi `toast.promise()` yang menerima Promise. Selama Promise pending, tampilkan toast `info("Memproses...")`. Jika resolve → toast `success("Berhasil")`. Jika reject → toast `error("Gagal")`.

<details>
<summary>Jawaban</summary>

```ts
async function promise<T>(
  promise: Promise<T>,
  messages?: { pending?: string; success?: string; error?: string }
) {
  const msg = messages ?? {}
  addToast('info', msg.pending ?? 'Memproses...', 0) // duration 0 = tidak auto dismiss
  try {
    const result = await promise
    // Hapus toast pending, lalu tampilkan success
    toasts.value = toasts.value.filter(t => t.message !== (msg.pending ?? 'Memproses...'))
    addToast('success', msg.success ?? 'Berhasil')
    return result
  } catch (err) {
    toasts.value = toasts.value.filter(t => t.message !== (msg.pending ?? 'Memproses...'))
    addToast('error', msg.error ?? 'Gagal')
    throw err
  }
}
```

</details>

### Soal 2

Tambahkan fitur **undo** pada toast. Saat toast `success("Buku dihapus")` muncul, user bisa klik tombol "Undo" di dalam toast untuk membatalkan penghapusan.

<details>
<summary>Jawaban</summary>

Perluas interface Toast:

```ts
interface Toast {
  // ...
  undo?: () => void
}
```

```ts
function addItemToCart(book: Book) {
  const deletedBook = cartStore.items.find(b => b.id === book.id)
  if (deletedBook) {
    cartStore.removeItem(book.id)
    toast.success('Buku dihapus dari keranjang', {
      undo: () => cartStore.addItem(deletedBook)
    })
  }
}
```

Template:

```vue
<div v-for="toast in toasts" :key="toast.id" :class="...">
  {{ toast.message }}
  <button v-if="toast.undo" @click.stop="toast.undo(); removeToast(toast.id)">
    Undo
  </button>
</div>
```
