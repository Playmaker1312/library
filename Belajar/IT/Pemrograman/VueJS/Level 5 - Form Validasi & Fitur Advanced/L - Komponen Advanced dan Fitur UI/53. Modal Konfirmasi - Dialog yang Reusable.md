# 53. Modal Konfirmasi — Dialog yang Reusable

## Penjelasan

Modal konfirmasi adalah dialog yang muncul di tengah layar dengan backdrop gelap, berisi pesan konfirmasi serta dua tombol: Konfirmasi dan Batal. Di Vue 3, kita buat **composable `useConfirm()`** yang mengembalikan Promise — sehingga pemanggilannya mirip `window.confirm()` tapi dengan UI kustom.

Pattern: `ref` untuk `isOpen`, dan `resolveRef` untuk menyimpan callback resolve Promise.

```ts
const confirmed = await confirm({
  title: 'Hapus Buku',
  message: 'Yakin ingin menghapus "Clean Code"?',
  confirmText: 'Hapus',
  danger: true, // tombol merah
})
```

## Fungsi

Konfirmasi aksi penting sebelum dijalankan: hapus item, checkout, logout. Memberi kesempatan user membatalkan jika terjadi kesalahan.

## Cara Implementasi / Kode

### 1. Composable `useConfirm`

```ts
// composables/useConfirm.ts
import { ref } from 'vue'

interface ConfirmOptions {
  title: string
  message: string
  confirmText?: string
  cancelText?: string
  danger?: boolean
}

const isOpen = ref(false)
const options = ref<ConfirmOptions | null>(null)
let resolveRef: ((value: boolean) => void) | null = null

export function useConfirm() {
  function confirm(opts: ConfirmOptions): Promise<boolean> {
    options.value = opts
    isOpen.value = true
    return new Promise((resolve) => {
      resolveRef = resolve
    })
  }

  function onConfirm() {
    isOpen.value = false
    resolveRef?.(true)
  }

  function onCancel() {
    isOpen.value = false
    resolveRef?.(false)
  }

  return { isOpen, options, confirm, onConfirm, onCancel }
}
```

### 2. Komponen `ConfirmModal`

```vue
<!-- components/ConfirmModal.vue -->
<script setup lang="ts">
import { useConfirm } from '@/composables/useConfirm'
import { onMounted, onUnmounted } from 'vue'

const { isOpen, options, onConfirm, onCancel } = useConfirm()

function onKeydown(e: KeyboardEvent) {
  if (e.key === 'Escape' && isOpen.value) onCancel()
}
onMounted(() => window.addEventListener('keydown', onKeydown))
onUnmounted(() => window.removeEventListener('keydown', onKeydown))

function onBackdropClick() {
  onCancel()
}
</script>

<template>
  <Teleport to="body">
    <Transition name="modal">
      <div v-if="isOpen" class="modal-overlay" @click.self="onBackdropClick">
        <div class="modal-content" role="dialog" aria-modal="true">
          <h3>{{ options?.title }}</h3>
          <p>{{ options?.message }}</p>
          <div class="modal-actions">
            <button class="btn-cancel" @click="onCancel">
              {{ options?.cancelText ?? 'Batal' }}
            </button>
            <button
              :class="['btn-confirm', { 'btn-danger': options?.danger }]"
              @click="onConfirm"
            >
              {{ options?.confirmText ?? 'Konfirmasi' }}
            </button>
          </div>
        </div>
      </div>
    </Transition>
  </Teleport>
</template>

<style scoped>
.modal-overlay {

```

### 3. Penggunaan

```ts
const { confirm } = useConfirm()

async function deleteBook(book: Book) {
  const confirmed = await confirm({
    title: 'Hapus Buku',
    message: `Yakin ingin menghapus "${book.title}" dari perpustakaan?`,
    confirmText: 'Hapus',
    danger: true,
  })
  if (!confirmed) return

  await booksStore.remove(book.id)
  success(`"${book.title}" berhasil dihapus`)
}
```


### 4. Scroll Lock

Agar body tidak bisa di-scroll saat modal terbuka:

```ts
import { watch } from 'vue'

watch(isOpen, (open) => {
  document.body.style.overflow = open ? 'hidden' : ''
})
```

## Analogi — Toko Buku

Modal seperti **pintu konfirmasi** di toko. Saat pegawai mau menghapus item dari keranjang, pintu ini terbuka: "Anda yakin ingin menghapus 'Clean Code' dari keranjang?" dengan dua tombol: "Hapus" (merah, bahaya) dan "Batal" (aman). Di belakang pintu, seluruh toko digelapkan (backdrop) — fokus hanya ke dialog ini. Kalau pegawai pilih "Hapus" → pintu tertutup, aksi dijalankan. Kalau "Batal" → pintu tertutup, tidak terjadi apa-apa. Modal memaksa user berpikir sebelum aksi penting.

## Dipakai untuk Apa

- Konfirmasi hapus data
- Konfirmasi checkout / pembayaran
- Konfirmasi logout
- Peringatan sebelum meninggalkan form yang belum disimpan

## Kesalahan Umum

| Kesalahan | Solusi |
|-----------|--------|
| Body tetap bisa di-scroll saat modal terbuka | Set `document.body.style.overflow = 'hidden'` saat modal open, kembalikan ke `''` saat close |
| Modal tidak bisa ditutup dengan tombol Escape | Pasang event listener `keydown` untuk `Escape` |
| Backdrop tidak bisa diklik untuk tutup | Tambahkan `@click.self="onCancel"` pada overlay |
| Fokus tidak terperangkap di dalam modal | Gunakan `focus-trap` atau pindahkan fokus ke tombol pertama saat modal mount |

## Hubungan dengan Materi Sebelumnya

- **Poin 52 (Toast):** Toast untuk feedback ringan; modal untuk konfirmasi yang butuh keputusan user. Sama-sama pakai `Teleport` dan `Transition`.
- **Bagian K (Poin 51):** Setelah validasi form sukses, jika ada duplikat data, modal muncul minta konfirmasi timpa data.

## Soal Latihan

### Soal 1

Buat fungsi `useConfirm().confirmWithInput(opts)` yang menambahkan input teks. User harus mengetik "HAPUS" untuk mengonfirmasi. Tombol konfirmasi disable sampai input sesuai.

<details>
<summary>Jawaban</summary>

```ts
// composables/useConfirm.ts — tambahkan
interface ConfirmInputOptions extends ConfirmOptions {
  inputLabel?: string
  inputMatch: string
}

let userInput = ref('')

async function confirmWithInput(opts: ConfirmInputOptions): Promise<boolean> {
  options.value = opts
  isOpen.value = true
  userInput.value = ''
  return new Promise((resolve) => {
    resolveRef = resolve
  })
}

// Di template
<input
  v-model="userInput"
  :placeholder="options.inputLabel ?? 'Ketik konfirmasi'"
/>
<button :disabled="userInput !== options.inputMatch" @click="onConfirm">
  {{ options?.confirmText }}
</button>
```

### Soal 2

Buat fitur **stacking modal**. Jika modal A terbuka lalu user memicu modal B, modal B muncul di atas modal A. Saat B ditutup, A muncul kembali.

<details>
<summary>Jawaban</summary>

Gunakan array untuk stack:

```ts
const modalStack = ref<Array<{ options: ConfirmOptions; resolve: (v: boolean) => void }>>([])

function confirm(opts: ConfirmOptions): Promise<boolean> {
  return new Promise((resolve) => {
    modalStack.value.push({ options: opts, resolve })
  })
}

function onConfirm() {
  const top = modalStack.value.pop()
  top?.resolve(true)
}

function onCancel() {
  const top = modalStack.value.pop()
  top?.resolve(false)
}
```

Render modal berdasarkan item teratas stack. Pastikan backdrop tidak menumpuk.
