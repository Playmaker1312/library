# 25. Lifecycle Hooks — onMounted, onUnmounted, onUpdated

## Penjelasan

Lifecycle hooks adalah fungsi bawaan Vue yang dijalankan secara otomatis pada tahap tertentu dalam "siklus hidup" sebuah komponen. Di Composition API + `<script setup>`, hooks ini diimpor dari `vue` dan dipanggil langsung di setup.

| Hook | Waktu Eksekusi |
|------|----------------|
| `onMounted` | Setelah komponen dipasang ke DOM |
| `onUpdated` | Setelah reaktivitas menyebabkan DOM diperbarui |
| `onUnmounted` | Saat komponen dihapus dari DOM |
| `onBeforeMount` | Tepat sebelum komponen dipasang |
| `onBeforeUpdate` | Sebelum DOM diperbarui |
| `onBeforeUnmount` | Sebelum komponen dihapus |

> **Catatan:** `onMounted` dan `onUnmounted` adalah dua hook terpenting untuk pemula. `onBeforeMount` jarang dipakai.

---

## Fungsi

- **onMounted** — aman mengakses DOM, fetch data dari API, membaca localStorage, menambahkan event listener (scroll, resize, klik di luar)
- **onUnmounted** — membersihkan efek samping: hapus event listener, batalkan timer (`setInterval`, `setTimeout`), batalkan subscription, abort fetch
- **onUpdated** — bereaksi setelah data berubah dan DOM diperbarui (hati-hati: bisa menyebabkan infinite loop jika mengubah state di dalamnya)

---

## Cara Implementasi / Kode

```vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'

const books = ref<string[]>([])
const scrollY = ref(0)

// --- onMounted: load initial data & setup listener ---
onMounted(() => {
  const saved = localStorage.getItem('books')
  if (saved) {
    try {
      books.value = JSON.parse(saved)
    } catch {
      books.value = []
    }
  }

  window.addEventListener('scroll', handleScroll)
})

// --- onUnmounted: cleanup ---
onUnmounted(() => {
  window.removeEventListener('scroll', handleScroll)
})

function handleScroll() {
  scrollY.value = window.scrollY
}
</script>

<template>
  <ul>
    <li v-for="book in books" :key="book">{{ book }}</li>
  </ul>
  <p>Scroll position: {{ scrollY }}px</p>
</template>
```

---

## Analogi — Toko Buku

Toko buku memiliki **ritual buka-tutup** setiap hari:

- **Pagi hari (onMounted):** pemilik membuka pintu, menyalakan lampu, mengambil uang kasir dari brankas (load data), memasang papan "BUKA" di pintu (setup listener). Barang tersedia di etalase (DOM ready).

- **Malam hari (onUnmounted):** pemilik menyetor uang ke brankas (save data), mematikan lampu, menurunkan papan "BUKA" (remove listener), mengunci pintu. Toko tidak bisa diakses lagi.

- **Siang hari (onUpdated):** setiap kali ada pelanggan membeli buku, stok di etalase diperbarui — kasir mencatat perubahan.

**Penting:** Kalau lupa cleanup di malam hari — misalnya lupa menyimpan uang ke brankas atau lupa mengunci pintu — bisa terjadi **memory leak** (uang hilang, toko kemalingan). Sama persis dengan lupa `removeEventListener` di `onUnmounted`: event listener tetap berjalan meskipun komponen sudah tidak ada.

---

## Dipakai untuk Apa (Use Case Nyata)

1. **Fetch data dari REST API / GraphQL** — panggil `fetch` di `onMounted`
2. **Integrasi library pihak ketiga** — inisialisasi chart (Chart.js), peta (Leaflet), atau editor teks di `onMounted`, destroy di `onUnmounted`
3. **Lazy loading / infinite scroll** — pasang scroll listener di `onMounted`, lepas di `onUnmounted`
4. **Event tracking / analytics** — kirim event "page_view" di `onMounted`
5. **Timer / interval** — jalankan `setInterval` di `onMounted`, `clearInterval` di `onUnmounted`

---

## Kesalahan Umum

| Kesalahan | Dampak | Cara Menghindari |
|-----------|--------|------------------|
| Lupa cleanup listener | Memory leak, handler tetap jalan walau komponen dihapus | Selalu pasang `removeEventListener` di `onUnmounted` untuk setiap `addEventListener` di `onMounted` |
| Fetch async di `onBeforeMount` | Fetch mungkin belum selesai saat komponen mount — tidak masalah sebenarnya, tapi `onMounted` lebih aman untuk DOM | Gunakan `onMounted` untuk fetch |
| Mengubah state di `onUpdated` tanpa guard | Infinite loop (ubah state → trigger update → panggil `onUpdated` lagi → ubah state lagi) | Gunakan kondisi / flag |
| Memanggil hook di luar `setup()` | Vue warning, hook tidak jalan | Pastikan hook dipanggil langsung di `<script setup>`, bukan di dalam fungsi async biasa |

---

## Hubungan dengan Materi Sebelumnya

- **Level 1 — Vue Dasar:** Di Options API ada `mounted()`, `unmounted()` — ini padanan Composition API-nya.
- **Bagian D (ref, reactive):** `ref` mendefinisikan **apa** datanya; `onMounted` menentukan **kapan** data itu dimuat. Keduanya bekerja bersama.
- **Bagian E (computed, watch):** `computed` / `watch` bereaksi terhadap perubahan data **setelah** mounted. Lifecycle hooks mengatur **kapan efek samping** (fetch, listener) dimulai dan dibersihkan.

> **Inti:** `ref` + `computed` + `watch` adalah **"apa"** (data & logika). Lifecycle hooks adalah **"kapan"** (waktu eksekusi). Keduanya saling melengkapi.

## Soal Latihan + Jawaban

### Soal 1

Buat komponen `TimerTracker` yang:

- Menampilkan angka detik yang berjalan (counter)
- Menggunakan `setInterval` di `onMounted` untuk menambah counter setiap 1 detik
- Membersihkan interval di `onUnmounted`
- Memiliki tombol "Reset" untuk mengatur ulang counter ke 0

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'

const counter = ref(0)
let intervalId: number | undefined

onMounted(() => {
  intervalId = window.setInterval(() => {
    counter.value++
  }, 1000)
})

onUnmounted(() => {
  if (intervalId !== undefined) {
    clearInterval(intervalId)
  }
})

function reset() {
  counter.value = 0
}
</script>

<template>
  <p>Detik: {{ counter }}</p>
  <button @click="reset">Reset</button>
</template>
```

</details>

### Soal 2

Komponen `ScrollToTop` menambahkan tombol yang muncul setelah user scroll > 200px. Saat diklik, halaman scroll ke atas. Pastikan tidak ada memory leak.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'

const showButton = ref(false)

function onScroll() {
  showButton.value = window.scrollY > 200
}

function scrollToTop() {
  window.scrollTo({ top: 0, behavior: 'smooth' })
}

onMounted(() => {
  window.addEventListener('scroll', onScroll)
})

onUnmounted(() => {
  window.removeEventListener('scroll', onScroll)
})
</script>

<template>
  <button
    v-if="showButton"
    @click="scrollToTop"
    style="position: fixed; bottom: 20px; right: 20px"
  >
    ↑ Atas
  </button>
</template>
```

</details>
