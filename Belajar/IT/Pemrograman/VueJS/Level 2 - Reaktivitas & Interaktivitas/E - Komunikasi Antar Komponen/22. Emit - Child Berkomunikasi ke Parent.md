# 22. Emit - Child Berkomunikasi ke Parent

## Penjelasan

**Props** = komunikasi satu arah dari parent ke child. **Emit** = kebalikannya: child memberi tahu parent bahwa sesuatu terjadi. Child tidak bisa mengubah props langsung, tapi bisa "mengirim sinyal" via event.

Di Vue 3 + `<script setup>`, emit dideklarasikan dengan `defineEmits`.

### Deklarasi emit (tipe-safe dengan TypeScript)

```typescript
// Di komponen child (BookCard.vue)
const emit = defineEmits<{
  'add-to-cart': [book: Book]
}>()
```

### Mengirim event

```typescript
emit('add-to-cart', props.book)
```

### Menangkap event di parent

```vue
<template>
  <BookCard @add-to-cart="handleAddToCart" />
</template>

<script setup lang="ts">
function handleAddToCart(book: Book) {
  // lakukan sesuatu
}
</script>
```

---

## Fungsi

- Memberi sinyal dari child ke parent bahwa ada aksi user (klik, submit, dll.)
- Menjaga aliran data tetap satu arah — child tidak mutasi props, cukup notifikasi
- Membuat komponen child bisa **interaktif** tanpa perlu tahu logika bisnis parent

---

## Cara Implementasi

### 1. Definisikan tipe Book

```typescript
// types/book.ts
export interface Book {
  id: number
  title: string
  author: string
  price: number
}
```

### 2. Komponen BookCard — child yang emit event

```vue
<!-- components/BookCard.vue -->
<script setup lang="ts">
import type { Book } from '@/types/book'

const props = defineProps<{ book: Book }>()

const emit = defineEmits<{
  'add-to-cart': [book: Book]
}>()

function handleTambah() {
  emit('add-to-cart', props.book)
}
</script>

<template>
  <div class="book-card">
    <h3>{{ book.title }}</h3>
    <p>{{ book.author }} — Rp{{ book.price.toLocaleString() }}</p>
    <button @click="handleTambah">Tambah ke Keranjang</button>
  </div>
</template>
```

### 3. Komponen HomeView — parent yang menangkap event

```vue
<!-- views/HomeView.vue -->
<script setup lang="ts">
import BookCard from '@/components/BookCard.vue'
import type { Book } from '@/types/book'

const bukuPopuler: Book[] = [
  { id: 1, title: 'Vue.js untuk Pemula', author: 'Rudi', price: 95000 },
  { id: 2, title: 'TypeScript Lanjutan', author: 'Sari', price: 120000 },
]

function handleAddToCart(book: Book) {
  console.log('Buku ditambahkan:', book.title)
}
</script>

<template>
  <div>
    <BookCard
      v-for="buku in bukuPopuler"
      :key="buku.id"
      :book="buku"
      @add-to-cart="handleAddToCart"
    />
  </div>
</template>
```

---

## Analogi — Toko Buku

**Props** seperti papan pengumuman dari pemilik toko ke pegawai: "Harga buku ini Rp50.000." Informasi mengalir satu arah.

**Emit** seperti **bel di meja pegawai**. Saat pelanggan ingin bertanya atau membeli, pegawai tidak bisa langsung mengambil buku dari gudang (mengubah state toko). Pegawai cukup menekan bel → pemilik toko datang menangani.

- **BookCard** = pegawai etalase
- **HomeView** = pemilik toko
- **Event `add-to-cart`** = bunyi bel
- **Data buku** yang dikirim via emit = "Pak, pelanggan ini mau beli *Vue.js untuk Pemula*"

Pegawai (BookCard) tidak perlu tahu cara mengelola uang atau stok — cukup memberi sinyal.

---

## Dipakai untuk apa

| Skenario | Contoh |
|---|---|
| Tombol aksi | Klik "Tambah ke Keranjang", "Like", "Hapus" |
| Form input child | Child kirim data form ke parent |
| Toggle / expand | Child notify parent untuk buka/tutup panel |
| Drag & drop | Child notify posisi baru item |
| Delete confirmation | Child notify "user ingin hapus item ini" |

---

## Kesalahan Umum

| Kesalahan | Akibat | Cara Benar |
|---|---|---|
| Lupa defineEmits | Error TS / runtime warning | Selalu deklarasi: `const emit = defineEmits<{...}>()` |
| Typo nama event | Event tidak terima di parent | Gunakan string literal, konsisten kebab-case |
| Emit dari komponen non-child | Tidak akan sampai ke parent yang dimaksud | Emit hanya naik 1 level, bukan antar saudara |
| Langsung panggil emit tanpa handler | Tidak error tapi tidak terjadi apa-apa | Pastikan parent punya listener: `@event="fn"` |
| Mengubah props langsung | Warning Vue, data tidak sinkron | Gunakan emit, jangan mutate props |

---

## Hubungan dengan Materi Sebelumnya

- **Level 1 (Poin 12-13):** Di Level 1, `BookCard` hanya menampilkan data via props — komponen pasif (read-only). Sekarang dengan emit, `BookCard` menjadi **interaktif**. User bisa klik tombol, child kirim sinyal ke parent.

- **Poin 14 (Template Syntax):** Event listener `@click` di child memicu function yang memanggil emit.

- **Poin 18 (Props):** Props untuk *menerima* data dari parent, emit untuk *mengirim* notifikasi ke parent. Dua sisi dari komunikasi parent-child.

- **Poin 20 (Komponen Fungsional):** Emit membuat komponen tidak hanya menampilkan UI tapi juga bisa berinteraksi dengan pengguna dan memberi feedback ke parent.

## Soal Latihan

### Soal 1

Buat komponen `RatingStars.vue` yang menerima prop `maxStars: number` (default 5) dan emit event `'rate'` dengan payload `rating: number`. Setiap bintang bisa diklik. Di parent, tangkap event tersebut dan tampilkan rating yang dipilih.

<details>
<summary>Jawaban Soal 1</summary>

```vue
<!-- RatingStars.vue -->
<script setup lang="ts">
const props = withDefaults(defineProps<{ maxStars?: number }>(), {
  maxStars: 5,
})

const emit = defineEmits<{
  rate: [rating: number]
}>()

function handleRate(bintang: number) {
  emit('rate', bintang)
}
</script>

<template>
  <div class="stars">
    <span
      v-for="b in maxStars"
      :key="b"
      @click="handleRate(b)"
      style="cursor: pointer; font-size: 1.5rem"
    >
      ☆
    </span>
  </div>
</template>
```

```vue
<!-- Parent.vue -->
<script setup lang="ts">
const ratingDipilih = ref(0)

function onRate(rating: number) {
  ratingDipilih.value = rating
}
</script>

<template>
  <RatingStars @rate="onRate" />
  <p v-if="ratingDipilih">Rating: {{ ratingDipilih }}</p>
</template>
```

</details>

### Soal 2

Komponen `BookCard` di atas memiliki tombol "Tambah ke Keranjang". Tambahkan emit kedua bernama `'remove-from-cart'` yang juga mengirim data book. Di parent, tampilkan dua daftar terpisah: "Daftar Beli" dan "Daftar Hapus".

<details>
<summary>Jawaban Soal 2</summary>

```vue
<!-- BookCard.vue (ditambahkan emit kedua) -->
<script setup lang="ts">
const emit = defineEmits<{
  'add-to-cart': [book: Book]
  'remove-from-cart': [book: Book]
}>()
</script>

<template>
  <div class="book-card">
    <h3>{{ book.title }}</h3>
    <button @click="emit('add-to-cart', book)">Tambah ke Keranjang</button>
    <button @click="emit('remove-from-cart', book)">Hapus</button>
  </div>
</template>
```

```vue
<!-- Parent.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import type { Book } from '@/types/book'

const daftarBeli = ref<Book[]>([])
const daftarHapus = ref<Book[]>([])

function tambah(book: Book) {
  daftarBeli.value.push(book)
}

function hapus(book: Book) {
  daftarHapus.value.push(book)
}
</script>

<template>
  <BookCard
    v-for="buku in bukuPopuler"
    :key="buku.id"
    :book="buku"
    @add-to-cart="tambah"
    @remove-from-cart="hapus"
  />

  <section>
    <h4>Daftar Beli ({{ daftarBeli.length }})</h4>
    <ul><li v-for="b in daftarBeli" :key="b.id">{{ b.title }}</li></ul>
  </section>

  <section>
    <h4>Daftar Hapus ({{ daftarHapus.length }})</h4>
    <ul><li v-for="b in daftarHapus" :key="b.id">{{ b.title }}</li></ul>
  </section>
</template>
```

</details>
