# 20. `watch()` — Bereaksi terhadap Perubahan Data

## Penjelasan

`watch()` menjalankan **side effect** (fungsi) setiap kali data reaktif yang dipantau berubah. Cocok untuk: menyimpan ke localStorage, fetching data, sinkronisasi DOM, reset state.

### `watch()` vs `watchEffect()`

| Fungsi | watch | watchEffect |
|--------|-------|-------------|
| Trigger | Eksplisit: sebut sumbernya | Implisit: otomatis track dependency di dalamnya |
| Eksekusi awal | Tidak jalan saat inisialisasi | **Jalan segera** saat pertama kali |
| Akses nilai lama | ✅ `(newVal, oldVal)` | ❌ Tidak punya `oldVal` |
| cleanup | ✅ `onCleanup` | ✅ `onCleanup` |

```ts
import { watch, watchEffect } from 'vue'

// watch — spesifik, akses old value
watch(searchQuery, (newVal, oldVal) => {
  console.log(`Berubah dari "${oldVal}" ke "${newVal}"`)
  saveToLocalStorage(newVal)
})

// watchEffect — otomatis track dependency
watchEffect(() => {
  console.log(searchQuery.value) // otomatis track searchQuery
  document.title = `Mencari: ${searchQuery.value}`
})
```

## Fungsi

Melakukan **aksi sebagai RESPON** terhadap perubahan data — bukan menghitung ulang nilai (itu tugas `computed`).

## Cara Implementasi

```vue
<script setup lang="ts">
import { ref, reactive, watch, watchEffect } from 'vue'

const searchQuery = ref('')
const filterState = reactive({
  search: '',
  category: 'semua',
  sortBy: 'title',
  page: 1,
})
const books = ref<{ title: string }[]>([])

// 1. watch sumber tunggal
watch(searchQuery, (newVal, oldVal) => {
  console.log(`Search: "${oldVal}" → "${newVal}"`)
  filterState.page = 1 // Reset page saat search berubah
})

// 2. watch multiple source (array)
watch([() => filterState.category, () => filterState.sortBy], ([newCat, newSort], [oldCat, oldSort]) => {
  console.log(`Filter berubah: ${oldCat}→${newCat}, ${oldSort}→${newSort}`)
  filterState.page = 1
})

// 3. watch dengan deep (object)
watch(filterState, (newVal) => {
  localStorage.setItem('bookstore-filter', JSON.stringify(newVal))
}, { deep: true })

// 4. watchEffect — auto track
watchEffect(() => {
  document.title = searchQuery.value
    ? `Toko Buku — mencari "${searchQuery.value}"`
    : 'Toko Buku'
})

// 5. Load localStorage di awal
const saved = localStorage.getItem('bookstore-filter')
if (saved) {
  Object.assign(filterState, JSON.parse(saved))
}
</script>
```

### Opsi Penting

| Opsi | Fungsi |
|------|--------|
| `{ deep: true }` | Pantau perubahan **di dalam** object/array |
| `{ immediate: true }` | Jalankan watch **segera** saat inisialisasi |
| `{ once: true }` (Vue 3.4+) | Hanya jalankan **sekali** |

## Analogi — Toko Buku

Di toko buku, ada **CCTV** yang "mengawasi" rak tertentu. Misalnya, CCTV mengawasi rak "Buku Terlaris". Setiap kali ada buku yang dipindahkan ke rak itu, CCTV mencatatnya dan otomatis menyalakan lampu sorot ke rak itu.

Inilah `watch` — bukan mengubah data, tapi **melakukan aksi sebagai RESPON** terhadap perubahan data.

- `watch` = CCTV yang fokus ke satu rak spesifik
- `watchEffect` = CCTV yang otomatis mengarah ke rak mana pun yang sedang dipantau di dalam kode

## Dipakai untuk apa

- **localStorage** — simpan filter state agar persisten
- **Debounce search** — tunggu user berhenti mengetik baru fetch API
- **Reset state** — reset `page` ke 1 saat filter berubah
- **Sinkronisasi DOM** — update `document.title`, meta tags
- **Fetch data** — panggil API saat parameter berubah
- **Logging / analytics**

## Kesalahan Umum

| ❌ Salah | ✅ Benar |
|----------|----------|
| `watch(books, ...)` tanpa `{ deep: true }` untuk array dalam | Tambahkan `{ deep: true }` atau gunakan getter `() => [...books.value]` |
| `watch(() => filterState.search, ...)` lupa getter syntax `()` | Getter wajib untuk properti dari `reactive` |
| Mengubah dependency di dalam watch (infnite loop) | Gunakan `if` guard atau `{ once: true }` |
| Side effect di dalam `computed` | Pindahkan ke `watch` atau `watchEffect` |
| `watchEffect` async tanpa cleanup | Gunakan `onCleanup` untuk cancel request |

```ts
// Debounce search dengan onCleanup
watch(searchQuery, (newVal, oldVal, onCleanup) => {
  let cancelled = false
  onCleanup(() => { cancelled = true })

  setTimeout(async () => {
    if (!cancelled) {
      books.value = await fetchBooks(newVal)
    }
  }, 300)
})
```

## Hubungan dengan Materi Sebelumnya

**Poin 19**: `watch` bisa memonitor perubahan `filterState` (reactive object) dengan `{ deep: true }` dan melakukan sesuatu seperti save ke localStorage atau reset page.

## Soal Latihan

### Soal 1

Buat `watch` pada ref `cariBuku` yang menyimpan nilai terakhir ke localStorage dengan key `"last-search"`.  Setiap kali komponen dimuat, baca localStorage dan isi `cariBuku` dengan `{ immediate: true }`.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref, watch } from 'vue'

const cariBuku = ref('')

// Load dari localStorage
const saved = localStorage.getItem('last-search')
if (saved) cariBuku.value = saved

// Watch + save
watch(cariBuku, (val) => {
  localStorage.setItem('last-search', val)
})
</script>

<template>
  <input v-model="cariBuku" placeholder="Cari buku..." />
  <p>Pencarian terakhir disimpan: {{ cariBuku }}</p>
</template>
```
</details>

### Soal 2

Buat `watch` pada array `keranjang` yang menampilkan alert "Stok terbatas!" jika panjang array > 5. Gunakan `{ deep: true }`.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref, watch } from 'vue'

const keranjang = ref<string[]>([])

watch(keranjang, (items) => {
  if (items.length > 5) {
    alert('Stok terbatas! Maksimal 5 buku per transaksi.')
  }
}, { deep: true })

function tambahBuku(judul: string) {
  keranjang.value.push(judul)
}
</script>

<template>
  <button @click="tambahBuku('Vue 3')">Tambah Vue 3</button>
  <button @click="tambahBuku('TypeScript')">Tambah TypeScript</button>
  <p>Keranjang: {{ keranjang.length }} item</p>
</template>
```
</details>
