# 18. `computed()` — Nilai yang Dihitung Otomatis

## Penjelasan

`computed()` adalah fungsi yang mengembalikan **nilai turunan reaktif**. Nilainya dihitung ulang otomatis setiap kali **dependency** (ref/reactive di dalamnya) berubah. Hasilnya **di-cache** — hanya re-run jika dependency berubah, bukan setiap render.

```ts
import { computed } from 'vue'

const filteredBooks = computed(() => {
  return books.value.filter(b => b.title.includes(searchQuery.value))
})
```

## Fungsi

Mengolah data mentah menjadi **data siap tampil** secara deklaratif — tanpa perlu method, tanpa perlu manual re-run.

## Cara Implementasi

```vue
<script setup lang="ts">
import { ref, computed } from 'vue'

interface Book {
  title: string
  price: number
  inStock: boolean
  category: string
}

const books = ref<Book[]>([
  { title: 'Vue 3 Dasar', price: 75000, inStock: true, category: 'teknologi' },
  { title: 'Belajar TypeScript', price: 65000, inStock: true, category: 'teknologi' },
  { title: 'Novel Tengah Malam', price: 50000, inStock: false, category: 'fiksi' },
])

const searchQuery = ref('')
const categoryFilter = ref('semua')
const sortBy = ref('title')

const filteredBooks = computed(() => {
  return books.value
    .filter(b => {
      const matchSearch = b.title.toLowerCase().includes(searchQuery.value.toLowerCase())
      const matchCategory = categoryFilter.value === 'semua' || b.category === categoryFilter.value
      return matchSearch && matchCategory
    })
    .sort((a, b) => {
      if (sortBy.value === 'price') return a.price - b.price
      return a.title.localeCompare(b.title)
    })
})

const totalItems = computed(() => filteredBooks.value.length)
const totalPrice = computed(() => filteredBooks.value.reduce((sum, b) => sum + b.price, 0))
</script>

<template>
  <input v-model="searchQuery" placeholder="Cari..." />
  <select v-model="sortBy">
    <option value="title">Judul</option>
    <option value="price">Harga</option>
  </select>

  <p>{{ totalItems }} buku ditemukan — Total Rp{{ totalPrice.toLocaleString() }}</p>

  <div v-for="book in filteredBooks" :key="book.title">
    {{ book.title }} — Rp{{ book.price.toLocaleString() }}
  </div>
</template>
```

### computed vs method

| Aspek | computed | method |
|-------|----------|--------|
| Cache | ✅ Dicache sampai dependency berubah | ❌ Dijalankan ulang setiap render |
| Sintaks | Nilai (`const x = computed(...)`) | Fungsi (`const x = () => ...`) |
| Template | `{{ filteredBooks }}` | `{{ filteredBooks() }}` |
| Cocok | Data turunan / olahan | Event handler / aksi |

## Analogi — Toko Buku

Di toko buku, ada rak **"Hasil Pencarian"** yang isinya berubah otomatis saat pelanggan mengetik di layar pencarian.

Ini bukan rak fisik baru — ini seperti rak **"virtual"** yang isinya dihitung ulang dari rak utama setiap kali kata kunci berubah. Hasilnya langsung muncul tanpa perlu refresh halaman. Inilah **computed**.

## Dipakai untuk apa

- Filter, search, sort data
- Menghitung total / rata-rata / ringkasan
- Transformasi format (misal tanggal, mata uang)
- Validasi form real-time
- Menggabungkan / memproses beberapa state

## Kesalahan Umum

| ❌ Salah | ✅ Benar |
|----------|----------|
| Mengubah nilai computed (tidak punya setter) | Computed readonly — gunakan ref biasa untuk mutable |
| Menaruh side effect di computed (fetch, localStorage) | Computed harus **pure** — side effect pakai `watch` |
| Mengira computed jalan terus | Computed hanya re-run saat dependency berubah |
| `computed(() => { return data })` tanpa akses `.value` | Pastikan dependency diakses via `.value` |

## Hubungan dengan Materi Sebelumnya

**Poin 16-17**: `ref` untuk **data mentah** (`searchQuery`, `books`), `computed` untuk **data olahan** (`filteredBooks`). Search + filter bekerja real-time karena `v-model` mengisi ref, dan `computed` otomatis bereaksi.

**Poin 19 nanti**: `reactive()` bisa menggantikan kumpulan ref dan langsung dipakai sebagai dependency di computed.

## Soal Latihan

### Soal 1

Buat computed `bukuTersedia` yang hanya menampilkan buku dengan `inStock: true`, dan computed `totalStok` yang menghitung jumlahnya.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref, computed } from 'vue'

const books = ref([
  { title: 'Buku A', inStock: true },
  { title: 'Buku B', inStock: false },
  { title: 'Buku C', inStock: true },
])

const bukuTersedia = computed(() => books.value.filter(b => b.inStock))
const totalStok = computed(() => bukuTersedia.value.length)
</script>

<template>
  <p>Tersedia: {{ totalStok }} buku</p>
  <div v-for="b in bukuTersedia" :key="b.title">{{ b.title }}</div>
</template>
```
</details>

### Soal 2

Buat computed `diskonPrice` yang mengembalikan array buku dengan harga diskon 20% (tidak mengubah array asli). Tampilkan harga asli dan harga diskon.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref, computed } from 'vue'

const books = ref([
  { title: 'Vue 3', price: 100000 },
  { title: 'TypeScript', price: 80000 },
])

const diskonPrice = computed(() =>
  books.value.map(b => ({
    ...b,
    diskon: b.price * 0.8,
    hemat: b.price * 0.2,
  }))
)
</script>

<template>
  <div v-for="b in diskonPrice" :key="b.title">
    {{ b.title }} — Rp{{ b.price.toLocaleString() }} → Rp{{ b.diskon.toLocaleString() }}
    (hemat Rp{{ b.hemat.toLocaleString() }})
  </div>
</template>
```
</details>
