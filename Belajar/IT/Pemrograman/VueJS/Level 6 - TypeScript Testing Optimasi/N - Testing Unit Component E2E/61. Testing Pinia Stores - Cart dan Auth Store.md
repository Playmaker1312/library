# 61. Testing Pinia Stores — Cart dan Auth Store

## Penjelasan

**Store test** menguji state management Pinia secara terisolasi menggunakan `setActivePinia(createPinia())`. Store adalah jantung aplikasi — semua data mengalir melaluinya. Dengan menguji store terpisah, kita memverifikasi bahwa state, getters, dan actions bekerja benar tanpa perlu komponen.

## Fungsi

- Memverifikasi state awal store sudah sesuai
- Menguji getters (computed properties) mengembalikan nilai yang benar
- Menguji actions memutasi state dengan tepat
- Memastikan store bisa direset antar test

## Cara Implementasi

### 1. Struktur Store

```typescript
// src/stores/cart.store.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export interface CartItem {
  id: number
  title: string
  price: number
  quantity: number
}

export const useCartStore = defineStore('cart', () => {
  const items = ref<CartItem[]>([])

  const totalItems = computed(() =>
    items.value.reduce((sum, item) => sum + item.quantity, 0)
  )

  const totalPrice = computed(() =>
    items.value.reduce((sum, item) => sum + item.price * item.quantity, 0)
  )

  function addItem(book: { id: number; title: string; price: number }) {
    const existing = items.value.find((i) => i.id === book.id)
    if (existing) {
      existing.quantity++
    } else {
      items.value.push({ ...book, quantity: 1 })
    }
  }

  function removeItem(id: number) {
    items.value = items.value.filter((i) => i.id !== id)
  }

  function clearCart() {
    items.value = []
  }

  return { items, totalItems, totalPrice, addItem, removeItem, clearCart }
})
```

```typescript
// src/stores/auth.store.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export interface User {
  id: number
  name: string
}

export const useAuthStore = defineStore('auth', () => {
  const user = ref<User | null>(null)

  const isAuthenticated = computed(() => user.value !== null)

  function setAuth(u: User) {
    user.value = u
  }

  function clearAuth() {
    user.value = null
  }

  return { user, isAuthenticated, setAuth, clearAuth }
})
```

### 2. Test: `cart.store.spec.ts`

```typescript
// src/stores/__tests__/cart.store.spec.ts
import { describe, it, expect, beforeEach } from 'vitest'
import { createPinia, setActivePinia } from 'pinia'
import { useCartStore } from '../cart.store'

describe('CartStore', () => {
  beforeEach(() => {
    setActivePinia(createPinia())
  })

  it('state awal: items kosong', () => {
    const store = useCartStore()
    expect(store.items).toHaveLength(0)
    expect(store.totalItems).toBe(0)
    expect(store.totalPrice).toBe(0)
  })

  it('addItem — menambah item baru ke cart', () => {
    const store = useCartStore()
    store.addItem({ id: 1, title: 'Vue.js Dasar', price: 75000 })
    expect(store.items).toHaveLength(1)
    expect(store.items[0].quantity).toBe(1)
  })

  it('addItem — menambah quantity jika item sudah ada', () => {
    const store = useCartStore()
    store.addItem({ id: 1, title: 'Vue.js Dasar', price: 75000 })
    store.addItem({ id: 1, title: 'Vue.js Dasar', price: 75000 })
    expect(store.items).toHaveLength(1)
    expect(store.items[0].quantity).toBe(2)
  })

  it('totalItems — menghitung jumlah semua quantity', () => {
    const store = useCartStore()
    store.addItem({ id: 1, title: 'Buku A', price: 50000 })
    store.addItem({ id: 2, title: 'Buku B', price: 60000 })
    store.addItem({ id: 1, title: 'Buku A', price: 50000 }) // quantity jadi 2
    expect(store.totalItems).toBe(3)
  })

  it('totalPrice — menghitung total harga', () => {
    const store = useCartStore()
    store.addItem({ id: 1, title: 'Buku A', price: 50000 })
    store.addItem({ id: 2, title: 'Buku B', price: 60000 })
    expect(store.totalPrice).toBe(110000)
  })

  it('removeItem — menghapus item dari cart', () => {
    const store = useCartStore()
    store.addItem({ id: 1, title: 'Buku A', price: 50000 })
    store.addItem({ id: 2, title: 'Buku B', price: 60000 })
    store.removeItem(1)
    expect(store.items).toHaveLength(1)
    expect(store.items[0].id).toBe(2)
  })

  it('clearCart — mengosongkan semua item', () => {
    const store = useCartStore()
    store.addItem({ id: 1, title: 'Buku A', price: 50000 })
    store.clearCart()
    expect(store.items).toHaveLength(0)
    expect(store.totalItems).toBe(0)
  })
})
```

### 3. Test: `auth.store.spec.ts`

```typescript
// src/stores/__tests__/auth.store.spec.ts
import { describe, it, expect, beforeEach } from 'vitest'
import { createPinia, setActivePinia } from 'pinia'
import { useAuthStore } from '../auth.store'

describe('AuthStore', () => {
  beforeEach(() => {
    setActivePinia(createPinia())
  })

  it('state awal: user null, isAuthenticated false', () => {
    const store = useAuthStore()
    expect(store.user).toBeNull()
    expect(store.isAuthenticated).toBe(false)
  })

  it('setAuth — mengubah state jadi terautentikasi', () => {
    const store = useAuthStore()
    store.setAuth({ id: 1, name: 'Andi' })
    expect(store.user).toEqual({ id: 1, name: 'Andi' })
    expect(store.isAuthenticated).toBe(true)
  })

  it('clearAuth — mengembalikan ke state awal', () => {
    const store = useAuthStore()
    store.setAuth({ id: 1, name: 'Andi' })
    store.clearAuth()
    expect(store.user).toBeNull()
    expect(store.isAuthenticated).toBe(false)
  })
})
```

## Analogi — Toko Buku

Ini adalah uji **"papan informasi digital"** toko — jantung komunikasi semua pegawai.

Kita uji:
- *"Kalau pegawai etalase menulis 'Clean Code +1' (addItem), apakah counter naik (totalItems)?"*
- *"Kalau menulis lagi buku yang sama, apakah quantity jadi 2?"*
- *"Kalau pegawai kasir menulis 'Hapus semua' (clearCart), apakah papan jadi kosong?"*
- *"Kalau admin menulis 'Login: Budi' (setAuth), apakah lampu hijau menyala (isAuthenticated)?"*

Papan ini kritis — **jika rusak, semua pegawai kacau**. Makanya diuji terpisah sebelum dipasang di toko.

## Dipakai untuk Apa

- Validasi logika keranjang belanja (add, update quantity, remove, clear)
- Validasi autentikasi (login/logout, role-based access)
- Validasi data master (daftar buku, kategori, penulis)
- Validasi persistensi state (hydration dari localStorage)

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| Lupa `setActivePinia(createPinia())` di `beforeEach` | Error Pinia tidak aktif atau state bocor antar test | Selalu panggil di `beforeEach`, bukan `beforeAll` |
| Store menggunakan persist plugin | State tetap tersimpan meski Pinia direset | Mock `localStorage.clear()` di `beforeEach`, atau nonaktifkan persist di test |
| Tidak reset state antar test | Test saling memengaruhi | `beforeEach(() => setActivePinia(createPinia()))` otomatis membuat instance baru |
| Test bergantung pada store lain | Coupling test | Test setiap store secara independen; mock store lain jika perlu |

## Hubungan dengan Materi Sebelumnya

- **Poin 59 (Unit Test)**: Store test mirip dengan composable test — keduanya menguji logic tanpa DOM.
- **Poin 60 (Component Test)**: Store sudah diuji terpisah. Jadi, jika component test gagal, kita tahu pasti itu masalah komponen, bukan store. Ini prinsip **isolasi tanggung jawab**.
- **Level 4 (Poin 42-44)**: Store `cart` dan `auth` pertama kali dibuat di level 4. Sekarang logic-nya diamankan dengan test.

### Soal 2

Buat integrasi test antara `AuthStore` dan `CartStore`: hanya user yang sudah login bisa melakukan `clearCart`. Jika belum login, `clearCart` harus menolak.

<details>
<summary>Jawaban</summary>

```typescript
import { describe, it, expect, beforeEach } from 'vitest'
import { createPinia, setActivePinia } from 'pinia'
import { useCartStore } from '../cart.store'
import { useAuthStore } from '../auth.store'

describe('CartStore — otorisasi clearCart', () => {
  beforeEach(() => {
    setActivePinia(createPinia())
  })

  it('clearCart berhasil jika sudah login', () => {
    const auth = useAuthStore()
    const cart = useCartStore()
    auth.setAuth({ id: 1, name: 'Budi' })
    cart.addItem({ id: 1, title: 'Buku', price: 50000 })
    cart.clearCart()
    expect(cart.items).toHaveLength(0)
  })

  it('clearCart tidak mengosongkan cart jika belum login', () => {
    const cart = useCartStore()
    cart.addItem({ id: 1, title: 'Buku', price: 50000 })

    // Simulasi guard: hanya clear jika authenticated
    const auth = useAuthStore()
    if (auth.isAuthenticated) {
      cart.clearCart()
    }

    expect(cart.items).toHaveLength(1)
  })
})
```
