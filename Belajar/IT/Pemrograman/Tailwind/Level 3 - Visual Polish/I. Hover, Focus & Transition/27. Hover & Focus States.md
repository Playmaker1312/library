# Hover & Focus States

## Penjelasan
- `hover:` -- style saat kursor mouse di atas elemen
- `focus:` -- style saat elemen sedang aktif/dipilih (biasanya input atau link)
- `focus-visible:` -- style saat elemen di-focus via keyboard (bukan klik mouse), penting untuk aksesibilitas
- `active:` -- style saat elemen sedang ditekan/diklik
- `disabled:` -- style untuk elemen yang dinonaktifkan (button/input dengan atribut disabled)
- `visited:` -- style untuk link yang sudah pernah dikunjungi
- Semua state dapat dikombinasikan dengan utility apapun: `hover:bg-blue-600`, `focus:ring-2`, `active:scale-95`
- Bisa dikombinasikan dengan multiple states: `hover:focus:ring-4`

## Fungsi
Memberikan feedback visual kepada pengguna saat berinteraksi dengan elemen, meningkatkan user experience dan aksesibilitas.

## Cara Pengimplementasian / Kode

```html
<button class="bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-6 rounded-lg transition-colors">
  Tombol Hover
</button>

<input
  type="text"
  placeholder="Klik di sini..."
  class="border border-gray-300 focus:border-blue-500 focus:ring-2 focus:ring-blue-200 focus:outline-none rounded-lg px-4 py-2"
>

<button class="bg-green-500 hover:bg-green-600 active:bg-green-700 active:scale-95 text-white font-bold py-2 px-6 rounded-lg transition-all">
  Tekan Saya
</button>

<button disabled class="bg-gray-300 text-gray-500 cursor-not-allowed py-2 px-6 rounded-lg">
  Disabled
</button>

<a href="https://example.com" class="text-blue-500 visited:text-purple-600 hover:underline">
  Link dengan visited state
</a>
```

## Analogi
Hover seperti ketika kamu mendekatkan tangan ke sebuah pintu -- pintu itu belum terbuka, tapi kamu sudah bisa melihat bahwa pintu itu bisa didorong (warnanya berubah). Focus seperti ketika kunci sudah masuk ke lubang kunci -- pintu siap untuk dibuka. Active seperti ketika kamu benar-benar mendorong pintu -- aksinya terjadi saat itu juga. Disabled seperti pintu yang sedang digembok dan tidak bisa digunakan sama sekali.

## Dipakai untuk Apa
- Hover: tomol, card, link, menu item, gambar galeri
- Focus: input form, textarea, select, search bar, tombol
- Focus-visible: navigasi keyboard untuk aksesibilitas
- Active: tombol yang perlu feedback tekan, drag handler
- Disabled: form yang belum lengkap, tombol yang butuh syarat tertentu
- Visited: link di artikel, daftar navigasi

## Kesalahan Umum yang Sering Terjadi
- Lupa menambahkan `focus:outline-none` saat menggunakan `focus:ring-*` sehingga muncul double outline
- Hanya menggunakan `focus:` tanpa `focus-visible:` sehingga pengguna keyboard dan mouse dapat efek yang sama (mengganggu pengguna mouse)
- Mengubah ukuran elemen di hover (via padding/margin) tanpa `transition` sehingga layout melompat-lompat
- Warna hover terlalu mirip dengan warna default sehingga perubahannya tidak terlihat
- Tidak memberikan style disabled sama sekali, sehingga tombol disabled masih terlihat bisa diklik

## Koneksi dengan Materi Sebelumnya
Di materi sebelumnya (shadow, filter, gradient) kamu membuat elemen yang terlihat statis dan indah. Hover dan focus adalah jembatan menuju interaktivitas -- elemen-elemen itu kini bisa bereaksi terhadap pengguna. Shadow memberikan ilusi kedalaman statis, hover bisa menggunakan shadow yang lebih besar untuk memberi ilusi elemen terangkat saat disentuh.

## Soal Latihan
Buat sebuah tombol dengan background biru, saat di-hover berubah menjadi biru lebih gelap, saat di-click (active) mengecil (scale-95) dan background menjadi biru paling gelap. Tambahkan transisi yang halus.
