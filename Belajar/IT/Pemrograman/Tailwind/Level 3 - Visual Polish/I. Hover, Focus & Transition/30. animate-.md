# animate-*

## Penjelasan
- `animate-spin` -- rotasi 360 derajat terus-menerus (linear infinite), biasa untuk loading spinner
- `animate-ping` -- efek sonar/radar (skala membesar lalu memudar berulang), biasa untuk indikator notifikasi
- `animate-pulse` -- efek denyut (opacity naik-turun), biasa untuk skeleton loading atau indikator "sedang memproses"
- `animate-bounce` -- efek memantul vertikal, biasa untuk indikasi "scroll ke bawah" atau perhatian
- `animate-none` -- nonaktifkan animasi
- Animasi kustom bisa ditambahkan di file konfigurasi Tailwind (`tailwind.config.js`) dengan keyframes CSS
- Semua animasi Tailwind menggunakan `infinite` secara default (berulang terus), kecuali dikustom

## Fungsi
Memberikan gerakan otomatis pada elemen tanpa perlu interaksi pengguna, berguna untuk feedback status sistem (loading, sukses, perhatian) dan elemen dekoratif.

## Cara Pengimplementasian / Kode

```html
<div class="flex gap-8 p-8 items-center">
  <!-- Loading Spinner -->
  <div class="w-8 h-8 border-4 border-blue-200 border-t-blue-600 rounded-full animate-spin"></div>

  <!-- Notifikasi Ping -->
  <div class="relative">
    <div class="w-4 h-4 bg-red-500 rounded-full"></div>
    <div class="w-4 h-4 bg-red-500 rounded-full absolute inset-0 animate-ping"></div>
  </div>

  <!-- Pulse -->
  <div class="w-24 h-6 bg-gray-200 rounded animate-pulse"></div>

  <!-- Bounce -->
  <div class="text-center">
    <svg class="w-8 h-8 text-gray-600 animate-bounce" fill="none" stroke="currentColor" viewBox="0 0 24 24">
      <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M19 14l-7 7m0 0l-7-7m7 7V3"></path>
    </svg>
    <p class="text-sm text-gray-500">Scroll ke bawah</p>
  </div>
</div>

<!-- Kombinasi: Tombol Loading -->
<button disabled class="bg-blue-500 text-white px-6 py-2 rounded-lg flex items-center gap-2 opacity-75 cursor-not-allowed">
  <div class="w-4 h-4 border-2 border-white border-t-transparent rounded-full animate-spin"></div>
  Memproses...
</button>

<!-- Custom Animation via config -->
<style>
  @keyframes wiggle {
    0%, 100% { transform: rotate(-3deg); }
    50% { transform: rotate(3deg); }
  }
  .animate-wiggle {
    animation: wiggle 1s ease-in-out infinite;
  }
</style>
<button class="bg-yellow-400 text-gray-900 px-6 py-2 rounded-lg font-semibold animate-wiggle">
  Diskon Spesial!
</button>
```

## Analogi
Animasi Tailwind seperti peralatan otomatis di gedung pintar. `animate-spin` seperti kipas angin di langit-langit yang terus berputar. `animate-ping` seperti lampu strobo darurat yang menyala berkala untuk menarik perhatian. `animate-pulse` seperti lampu indikator di panel listrik yang berkedip pelan menandakan sistem aktif. `animate-bounce` seperti bola pantul di papan reklame yang memantul terus menerus. Semua berjalan otomatis tanpa disentuh -- berbeda dengan transition yang butuh trigger interaksi.

## Dipakai untuk Apa
- Spin: loading spinner, tombol loading state, icon processing
- Ping: notifikasi badge, unread indicator, titik lokasi di map
- Pulse: skeleton loader saat data belum tampil, efek "sedang merekam", indikator live
- Bounce: arrow "scroll ke bawah", call-to-action yang ingin diperhatikan, mascot/karakter interaktif
- Custom animation: efek wiggle untuk diskon, efek fade-in untuk elemen yang muncul, efek slide-in untuk notifikasi

## Kesalahan Umum yang Sering Terjadi
- Tidak menambahkan class `border-t-transparent` atau `border-t-current` pada spinner sehingga spin tidak terlihat (semua border warna sama)
- Animasi ping tidak dibungkus di container `relative` sehingga efek membesar keluar dari layout
- Menggunakan animasi di terlalu banyak elemen sekaligus sehingga halaman terasa berat dan mengganggu
- Animasi berjalan terus-menerus (`infinite`) padahal cukup sekali tampil (misal fade-in sekali saja)
- Lupa bahwa animasi default Tailworth berjalan `infinite`, jadi perlu dikustom jika ingin sekali jalan

## Koneksi dengan Materi Sebelumnya
Transition bereaksi terhadap interaksi pengguna (hover, focus, toggle class via JS). Animasi (`animate-*`) berjalan otomatis tanpa interaksi. Bedanya seperti pintu otomatis yang hanya bergerak saat ada orang (transition) vs. lampu kedip yang terus berkedip sepanjang malam (animation). Setelah kamu menguasai hover, focus, group, peer, dan transition, langkah terakhir adalah animasi otomatis untuk feedback sistem yang tidak memerlukan input pengguna.

## Soal Latihan
Buat sebuah container yang menampilkan loading state dengan spinner (animate-spin) di sebelah kiri teks "Sedang memuat data...". Gunakan flex untuk tata letak horizontal, teks abu-abu, dan spinner dengan border biru.
