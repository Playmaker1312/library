# Membuat sidebar layout yang collapsible menggunakan Tailwind
## Analogi: Perpustakaan Digital
Sidebar collapsible seperti rak buku geser di perpustakaan. Saat Anda butuh akses ke buku, Anda tarik raknya keluar. Saat tidak butuh, Anda dorong kembali agar ruang baca lebih luas. Ini memberikan fleksibilitas: pengguna bisa memilih berapa banyak ruang yang ingin dialokasikan untuk navigasi.
## Penjelasan Detail
Sidebar collapsible adalah layout di mana sidebar bisa disembunyikan atau ditampilkan, biasanya dengan tombol toggle. Dengan Tailwind, Anda bisa mencapainya menggunakan state management JavaScript (Vue, React, atau vanilla) untuk toggle class `-translate-x-full` (sembunyikan ke kiri) atau `translate-x-0` (tampilkan). Untuk animasi, tambahkan `transition-transform duration-300`. Pada layar desktop, sidebar bisa tetap terbuka; pada mobile, sidebar bisa menjadi overlay yang menutupi konten. Beberapa variasi: sidebar bisa berupa "push" (mendorong konten) atau "overlay" (menimpa konten). Tailwind memudahkan implementasi kedua variasi dengan utility `absolute`, `fixed`, `relative`, dan `z-index`. Ukuran sidebar bisa ditentukan dengan `w-64` atau `w-[250px]`.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Collapsible Sidebar - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
    <div id="app" class="min-h-screen flex">
        <!-- Sidebar -->
        <aside 
            :class="[
                'fixed md:relative z-40 h-full bg-gray-800 text-white transition-transform duration-300 w-64',
                isOpen ? 'translate-x-0' : '-translate-x-full md:translate-x-0 md:w-0 md:overflow-hidden md:p-0'
            ]"
            class="p-5"
        >
            <div class="flex items-center justify-between mb-8">
                <h2 class="text-lg font-bold">Navigasi</h2>
                <button @click="isOpen = false" class="md:hidden text-gray-400 hover:text-white text-xl">&times;</button>
            </div>
            <nav class="space-y-2">
                <a href="#" class="block px-3 py-2 rounded hover:bg-gray-700 text-sm">Beranda</a>
                <a href="#" class="block px-3 py-2 rounded hover:bg-gray-700 text-sm">Katalog</a>
                <a href="#" class="block px-3 py-2 rounded hover:bg-gray-700 text-sm">Peminjaman</a>
                <a href="#" class="block px-3 py-2 rounded hover:bg-gray-700 text-sm">Pengaturan</a>
            </nav>
        </aside>

        <!-- Overlay mobile -->
        <div 
            v-if="isOpen" 
            @click="isOpen = false"
            class="fixed inset-0 bg-black bg-opacity-50 z-30 md:hidden"
        ></div>

        <!-- Main Content -->
        <div class="flex-1 flex flex-col min-h-screen">
            <!-- Top Bar -->
            <header class="bg-white shadow-sm p-4 flex items-center gap-4">
                <button @click="isOpen = !isOpen" class="p-2 hover:bg-gray-100 rounded-lg transition">
                    <svg class="w-6 h-6 text-gray-600" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M4 6h16M4 12h16M4 18h16"/>
                    </svg>
                </button>
                <h1 class="text-lg font-semibold text-gray-800">Dashboard Perpustakaan</h1>
            </header>

            <!-- Content -->
            <main class="flex-1 p-6 bg-gray-100">
                <div class="bg-white rounded-xl shadow-md p-6">
                    <h2 class="text-xl font-bold text-gray-800 mb-4">Sidebar Collapsible</h2>
                    <p class="text-gray-600">Klik tombol hamburger (☰) di pojok kiri atas untuk toggle sidebar. Di mobile, sidebar muncul sebagai overlay. Di desktop (&ge; 768px), sidebar tetap terlihat.</p>
                </div>
            </main>
        </div>
    </div>

    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <script>
        const { createApp, ref } = Vue;
        createApp({
            setup() {
                const isOpen = ref(false);
                return { isOpen };
            }
        }).mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- Gunakan `translate-x-full` / `-translate-x-full` dengan `transition-transform` untuk animasi slide
- Di mobile: sidebar sebagai overlay dengan backdrop; di desktop: sidebar tetap terbuka
- Tombol toggle (hamburger) mengontrol visibility sidebar melalui state JavaScript
