# Membuat full-bleed layout menggunakan teknik negative margin atau grid dengan Tailwind
## Analogi: Perpustakaan Digital
Full-bleed layout seperti poster besar yang menempel di dinding perpustakaan — ia "berdarah" keluar dari bingkai normalnya, memenuhi seluruh lebar dinding. Ini menciptakan efek dramatis di mana konten tertentu (seperti gambar hero) melampaui batas kontainer yang dibatasi lebar maksimalnya.
## Penjelasan Detail
Full-bleed layout memungkinkan elemen tertentu (seperti gambar hero, section background, atau banner) melampaui batasan `max-width` kontainer dan memenuhi seluruh lebar viewport. Ada dua teknik di Tailwind: (1) Negative margin — beri elemen `-mx-[calc((100vw-100%)/2)]` untuk melebarkan elemen melampaui kontainer, atau (2) CSS Grid — buat grid dengan kolom full-bleed di mana konten normal berada di kolom tengah (dengan max-width) dan elemen full-bleed menggunakan kolom penuh. Teknik Grid lebih modern dan lebih mudah dikelola. Di Tailwind, Anda bisa menggunakan `grid-cols-[1fr_minmax(0,56rem)_1fr]` dengan konten di kolom tengah dan elemen full-bleed membentang dari kolom 1 hingga 3 (`col-span-full`).
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Full-Bleed Layout - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-100">
    <!-- Teknik 1: CSS Grid Full-Bleed -->
    <div class="grid grid-cols-[1fr_minmax(0,56rem)_1fr]">
        
        <!-- Normal content (di kolom tengah) -->
        <div class="col-start-2 col-end-3 p-6">
            <div class="bg-white rounded-xl shadow-md p-6 mb-8">
                <h2 class="text-xl font-bold text-gray-800 mb-4">Teknik Grid Full-Bleed</h2>
                <p class="text-gray-600">Layout ini menggunakan CSS Grid dengan 3 kolom: <code>1fr minmax(0, 56rem) 1fr</code>. Konten normal ditempatkan di kolom tengah (kolom 2). Elemen full-bleed menggunakan <code>col-span-full</code> untuk membentang penuh.</p>
            </div>
        </div>

        <!-- Full-bleed section: gambar hero -->
        <div class="col-span-full bg-gradient-to-r from-blue-600 to-indigo-700 text-white">
            <div class="col-start-2 col-end-3 p-12">
                <h2 class="text-3xl font-bold mb-4">Full-Bleed Hero Section</h2>
                <p class="text-xl opacity-90 max-w-2xl">Section ini membentang dari tepi kiri ke tepi kanan viewport, melampaui batasan konten normal. Efek ini disebut "full-bleed".</p>
            </div>
        </div>

        <!-- Kembali ke konten normal -->
        <div class="col-start-2 col-end-3 p-6">
            <div class="bg-white rounded-xl shadow-md p-6 mb-8">
                <h2 class="text-xl font-bold text-gray-800 mb-3">Kembali ke Konten Normal</h2>
                <p class="text-gray-600">Setelah section full-bleed, konten kembali ke lebar normal (max-width 56rem). Perhatikan bagaimana section biru di atas "berdarah" keluar.</p>
            </div>

            <!-- Teknik 2: Negative margin -->
            <div class="bg-white rounded-xl shadow-md p-6">
                <h2 class="text-xl font-bold text-gray-800 mb-3">Teknik Alternatif: Negative Margin</h2>
                <p class="text-gray-600 mb-4">Teknik menggunakan negative margin untuk full-bleed:</p>
                <pre class="p-3 bg-gray-800 text-green-400 rounded-lg text-xs overflow-x-auto"><code>.full-bleed {
  margin-left: calc(-50vw + 50%);
  margin-right: calc(-50vw + 50%);
  width: 100vw;
  max-width: 100vw;
}

// Atau dengan Tailwind arbitrari:
class="ml-[calc(-50vw+50%)] 
       mr-[calc(-50vw+50%)] 
       w-screen"</code></pre>
            </div>
        </div>

        <!-- Full-bleed kedua dengan latar berbeda -->
        <div class="col-span-full bg-gray-800 text-gray-200">
            <div class="col-start-2 col-end-3 p-12">
                <h2 class="text-2xl font-bold mb-4">Full-Bleed Quote Section</h2>
                <blockquote class="text-xl italic opacity-90 border-l-4 border-blue-400 pl-6">
                    "Pengetahuan adalah kekuatan. Perpustakaan adalah gudangnya."
                </blockquote>
            </div>
        </div>

        <!-- Footer normal -->
        <div class="col-start-2 col-end-3 p-6 text-center text-sm text-gray-500">
            &copy; 2026 Perpustakaan Digital. Full-bleed layout with Tailwind CSS Grid.
        </div>
    </div>

    <!-- Kode struktur -->
    <div class="fixed bottom-4 right-4 p-4 bg-gray-900 text-green-400 rounded-lg text-xs shadow-lg max-w-xs">
        <div class="font-semibold mb-2">Struktur Grid:</div>
        <code>grid-cols-[1fr_minmax(0,56rem)_1fr]</code>
        <div class="mt-2">Konten normal: <code>col-start-2 col-end-3</code></div>
        <div>Full-bleed: <code>col-span-full</code></div>
    </div>
</body>
</html>
```
## Poin Penting
- Teknik Grid: gunakan `grid-cols-[1fr_minmax(0,56rem)_1fr]` dengan `col-span-full` untuk elemen full-bleed
- Teknik negative margin: gunakan kalkulasi `calc(-50vw + 50%)` untuk melebarkan elemen melampaui kontainer
- Full-bleed ideal untuk hero section, banner, background berwarna, dan quote yang ingin menonjol
