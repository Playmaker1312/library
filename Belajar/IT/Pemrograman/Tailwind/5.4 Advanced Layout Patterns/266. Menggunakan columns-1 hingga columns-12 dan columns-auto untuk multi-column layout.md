# Menggunakan columns-1 hingga columns-12 dan columns-auto untuk multi-column layout
## Analogi: Perpustakaan Digital
Bayangkan Anda mengatur koran dinding di perpustakaan. Anda bisa memformatnya menjadi 1 kolom (lebar penuh), 2 kolom (seperti koran), 3 kolom (seperti majalah), atau membiarkan browser menentukan jumlah kolom secara otomatis. Tailwind memberi Anda kendali penuh atas jumlah kolom ini.
## Penjelasan Detail
Tailwind menyediakan utility `columns-{count}` dari `columns-1` hingga `columns-12`, plus `columns-auto`. Ini mengatur properti CSS `column-count`. Setiap nilai menentukan jumlah kolom tetap. `columns-auto` memungkinkan browser menentukan jumlah kolom berdasarkan lebar konten (dikombinasikan dengan `column-width`). Utility ini berguna untuk layout teks seperti koran atau majalah, daftar pendek, galeri, dan pricing table. Untuk responsivitas, kombinasikan dengan breakpoint: `columns-1 md:columns-2 lg:columns-3`. Tidak seperti `grid-cols-*` yang membagi ruang menjadi kolom grid yang kaku, `columns-*` membuat konten mengalir dari satu kolom ke kolom berikutnya secara alami. Kontrol jarak antar kolom dengan `gap-*`.

## Poin Penting
- `columns-{1-12}` mengatur jumlah kolom tetap untuk multi-column layout
- `columns-auto` membiarkan browser menentukan jumlah kolom berdasarkan lebar konten
- Konten mengalir secara vertikal dalam kolom, berbeda dengan grid yang horizontal
