# Membuat centered layout dengan max-width dan auto margin
## Analogi: Perpustakaan Digital
Centered layout seperti aula utama perpustakaan yang selalu memiliki lorong di kedua sisinya. Tidak peduli seberapa lebar ruangannya, area konten utama tetap di tengah dengan lebar yang nyaman dibaca. Ini adalah pola layout paling dasar dan paling penting dalam web design.
## Penjelasan Detail
Centered layout adalah pola di mana konten dibatasi lebar maksimalnya dan secara horizontal berada di tengah viewport. Di Tailwind, ini dicapai dengan dua class: `max-w-{size}` untuk membatasi lebar dan `mx-auto` untuk auto margin kiri dan kanan. Tailwind menyediakan skala `max-w-`: `max-w-sm` (24rem), `max-w-md` (28rem), `max-w-lg` (32rem), `max-w-xl` (36rem), `max-w-2xl` (42rem), hingga `max-w-7xl` (80rem). Juga ada `max-w-screen-sm/md/lg/xl/2xl` yang sesuai dengan breakpoint. Untuk layout yang lebih kompleks, Anda bisa menggabungkan centered layout dengan padding: `px-4` untuk memberikan jarak di layar kecil saat konten mencapai batas max-width. Ini disebut "holy grail of responsive design" — `max-w-6xl mx-auto px-4`. Pola ini sering digunakan sebagai wrapper di seluruh halaman.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Centered Layout - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
    <!-- Wrapper utama dengan centered layout -->
    <div class="max-w-4xl mx-auto px-4">
        <!-- Header -->
        <header class="bg-white border-b py-4 mb-8">
            <div class="flex items-center justify-between">
                <h1 class="text-xl font-bold text-gray-800">
                    <span class="text-blue-600">Centered</span> Layout
                </h1>
                <nav class="flex gap-4 text-sm text-gray-500">
                    <a href="#" class="hover:text-blue-600">Beranda</a>
                    <a href="#" class="hover:text-blue-600">Tentang</a>
                    <a href="#" class="hover:text-blue-600">Kontak</a>
                </nav>
            </div>
        </header>

        <!-- Hero centered -->
        <div class="text-center py-12 mb-8">
            <h2 class="text-3xl font-bold text-gray-800 mb-4">Pola Centered Layout</h2>
            <p class="text-gray-500 max-w-2xl mx-auto">Konten ini dibatasi dengan <code class="text-blue-600">max-w-4xl mx-auto px-4</code>. Resize browser untuk melihat bagaimana konten tetap di tengah dan memiliki padding yang cukup di tepi.</p>
        </div>

        <!-- Demo berbagai max-width -->
        <div class="space-y-6 mb-8">
            <div class="p-6 bg-white rounded-xl shadow-md">
                <h3 class="font-bold text-gray-800 mb-4">Demo Berbagai max-width</h3>
                <p class="text-sm text-gray-500 mb-4">Setiap baris di bawah menggunakan max-width yang berbeda, semuanya dengan mx-auto:</p>
                
                <div class="space-y-4">
                    <div class="max-w-xs mx-auto p-3 bg-blue-100 rounded text-sm text-blue-700 text-center">max-w-xs (20rem)</div>
                    <div class="max-w-sm mx-auto p-3 bg-blue-100 rounded text-sm text-blue-700 text-center">max-w-sm (24rem)</div>
                    <div class="max-w-md mx-auto p-3 bg-blue-100 rounded text-sm text-blue-700 text-center">max-w-md (28rem)</div>
                    <div class="max-w-lg mx-auto p-3 bg-blue-100 rounded text-sm text-blue-700 text-center">max-w-lg (32rem)</div>
                    <div class="max-w-xl mx-auto p-3 bg-blue-100 rounded text-sm text-blue-700 text-center">max-w-xl (36rem)</div>
                    <div class="max-w-2xl mx-auto p-3 bg-blue-100 rounded text-sm text-blue-700 text-center">max-w-2xl (42rem)</div>
                    <div class="max-w-4xl mx-auto p-3 bg-blue-100 rounded text-sm text-blue-700 text-center">max-w-4xl (56rem) — yang digunakan halaman ini</div>
                </div>
            </div>
        </div>

        <!-- Kapan menggunakan ukuran apa -->
        <div class="grid md:grid-cols-3 gap-4 mb-8">
            <div class="p-4 bg-white rounded-xl shadow-md">
                <h4 class="font-semibold text-gray-700">Artikel / Blog</h4>
                <p class="text-sm text-gray-500 mt-1">Gunakan <code>max-w-2xl</code> atau <code>max-w-3xl</code> (42-48rem) untuk kenyamanan membaca. Lebar ini optimal untuk teks.</p>
            </div>
            <div class="p-4 bg-white rounded-xl shadow-md">
                <h4 class="font-semibold text-gray-700">Dashboard / App</h4>
                <p class="text-sm text-gray-500 mt-1">Gunakan <code>max-w-6xl</code> atau <code>max-w-7xl</code> (72-80rem) untuk memanfaatkan ruang layar lebar.</p>
            </div>
            <div class="p-4 bg-white rounded-xl shadow-md">
                <h4 class="font-semibold text-gray-700">Form / Card</h4>
                <p class="text-sm text-gray-500 mt-1">Gunakan <code>max-w-md</code> atau <code>max-w-lg</code> (28-32rem) agar form tidak terlalu lebar.</p>
            </div>
        </div>

        <!-- Footer -->
        <footer class="border-t py-6 text-center text-sm text-gray-400">
            <p>Pola <code class="text-blue-600">max-w-{size} mx-auto px-4</code> adalah fondasi layout responsive Tailwind.</p>
        </footer>
    </div>
</body>
</html>
```
## Poin Penting
- Pola dasar: `max-w-{size} mx-auto px-4` — batasi lebar, tengahkan, beri padding samping
- Pilih ukuran max-w berdasarkan jenis konten: artikel (2xl-3xl), dashboard (6xl-7xl), form (md-lg)
- `px-4` penting untuk layar kecil agar konten tidak menempel ke tepi viewport
