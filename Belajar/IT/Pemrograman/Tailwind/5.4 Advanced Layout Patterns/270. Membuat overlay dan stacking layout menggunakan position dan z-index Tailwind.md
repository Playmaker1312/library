# Membuat overlay dan stacking layout menggunakan position dan z-index Tailwind
## Analogi: Perpustakaan Digital
Overlay seperti peta transparan yang diletakkan di atas meja — Anda masih bisa melihat meja di bawahnya, tetapi informasi di peta lebih prioritas. Stacking layout seperti tumpukan buku di rak: buku yang paling baru diletakkan berada di atas. Tailwind memungkinkan Anda mengontrol "tumpukan" ini dengan position dan z-index.
## Penjelasan Detail
Tailwind menyediakan utility position: `static` (default), `fixed`, `absolute`, `relative`, dan `sticky`. Untuk overlay, Anda biasanya menggunakan `fixed` atau `absolute` dengan `inset-0` (untuk membentang penuh). Z-index dikontrol dengan `z-{n}` dari `z-0` hingga `z-50`, plus `z-auto`. Nilai yang lebih tinggi berarti lebih ke atas (lebih dekat ke pengguna). Pola umum overlay: (1) Modal — `fixed inset-0 z-50` dengan background semi-transparan. (2) Dropdown — `absolute top-full left-0 z-10`. (3) Tooltip — `absolute bottom-full z-20`. (4) Backdrop — `fixed inset-0 bg-black/50 z-40`. Untuk mengelola stacking context yang kompleks, pastikan elemen parent memiliki `position: relative` jika menggunakan anak `absolute`. Hindari z-index yang terlalu tinggi (9999) — gunakan skala Tailwind yang sudah terstruktur.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Overlay dan Stacking - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="app" class="max-w-4xl mx-auto">
        <div class="p-6 bg-white rounded-xl shadow-md mb-8">
            <h2 class="text-xl font-bold text-gray-800 mb-2">Overlay & Stacking Layout</h2>
            <p class="text-gray-500 text-sm mb-6">Klik tombol di bawah untuk mendemonstrasikan berbagai pola overlay.</p>

            <!-- Tombol demo -->
            <div class="flex flex-wrap gap-4">
                <button @click="showModal = true" class="px-5 py-2 bg-blue-500 text-white rounded-lg font-semibold hover:bg-blue-600 transition">
                    Tampilkan Modal
                </button>
                <button @click="showTooltip = !showTooltip" class="px-5 py-2 bg-emerald-500 text-white rounded-lg font-semibold hover:bg-emerald-600 transition">
                    Toggle Tooltip
                </button>
                <button @click="showDropdown = !showDropdown" class="relative px-5 py-2 bg-purple-500 text-white rounded-lg font-semibold hover:bg-purple-600 transition">
                    Dropdown
                    <!-- Dropdown -->
                    <div v-if="showDropdown" class="absolute top-full left-0 mt-1 w-48 bg-white rounded-lg shadow-xl border z-10">
                        <a href="#" class="block px-4 py-2 text-sm text-gray-700 hover:bg-gray-50">Profil</a>
                        <a href="#" class="block px-4 py-2 text-sm text-gray-700 hover:bg-gray-50">Pengaturan</a>
                        <a href="#" class="block px-4 py-2 text-sm text-red-600 hover:bg-red-50">Keluar</a>
                    </div>
                </button>
            </div>
        </div>

        <!-- Demo Z-Index Stacking -->
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h3 class="text-lg font-bold text-gray-800 mb-4">Demo Z-Index Stacking</h3>
            <div class="relative h-64 bg-gray-100 rounded-lg overflow-hidden">
                <div class="absolute top-4 left-4 w-40 h-40 bg-red-400 rounded-lg flex items-center justify-center text-white font-bold z-10">
                    z-10
                </div>
                <div class="absolute top-12 left-12 w-40 h-40 bg-blue-400 rounded-lg flex items-center justify-center text-white font-bold z-20">
                    z-20
                </div>
                <div class="absolute top-20 left-20 w-40 h-40 bg-green-400 rounded-lg flex items-center justify-center text-white font-bold z-30">
                    z-30
                </div>
                <div class="absolute top-28 left-28 w-40 h-40 bg-yellow-400 rounded-lg flex items-center justify-center text-white font-bold z-40">
                    z-40
                </div>
            </div>
            <p class="text-sm text-gray-500 mt-2">Kotak dengan z-index lebih tinggi muncul di atas. z-40 berada paling depan.</p>
        </div>

        <!-- Modal overlay -->
        <div v-if="showModal" class="fixed inset-0 z-50 flex items-center justify-center">
            <!-- Backdrop -->
            <div class="fixed inset-0 bg-black bg-opacity-50" @click="showModal = false"></div>
            <!-- Modal content -->
            <div class="relative bg-white rounded-xl shadow-2xl p-6 max-w-md w-full mx-4 z-10">
                <div class="flex items-center justify-between mb-4">
                    <h3 class="text-lg font-bold text-gray-800">Modal Overlay</h3>
                    <button @click="showModal = false" class="text-gray-400 hover:text-gray-600 text-xl">&times;</button>
                </div>
                <p class="text-gray-600">Modal ini menggunakan <code>fixed inset-0 z-50</code> dengan backdrop semi-transparan. Klik di luar modal atau tombol close untuk menutup.</p>
                <div class="mt-4 flex justify-end gap-3">
                    <button @click="showModal = false" class="px-4 py-2 bg-gray-200 rounded-lg hover:bg-gray-300 transition">Batal</button>
                    <button @click="showModal = false" class="px-4 py-2 bg-blue-500 text-white rounded-lg hover:bg-blue-600 transition">Konfirmasi</button>
                </div>
            </div>
        </div>

        <!-- Tooltip -->
        <div v-if="showTooltip" class="fixed top-4 right-4 z-40">
            <div class="relative bg-gray-800 text-white px-4 py-2 rounded-lg shadow-lg text-sm">
                Ini adalah tooltip dengan z-40
                <div class="absolute -bottom-1 left-1/2 -translate-x-1/2 w-2 h-2 bg-gray-800 rotate-45"></div>
            </div>
        </div>
    </div>

    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <script>
        const { createApp, ref } = Vue;
        createApp({
            setup() {
                const showModal = ref(false);
                const showTooltip = ref(false);
                const showDropdown = ref(false);
                return { showModal, showTooltip, showDropdown };
            }
        }).mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- Modal: `fixed inset-0 z-50` dengan backdrop semi-transparan (`bg-black/50`)
- Dropdown: `absolute top-full left-0 z-10` di dalam parent `relative`
- Z-index Tailwind (0-50) sudah cukup untuk sebagian besar kasus — hindari nilai 9999
