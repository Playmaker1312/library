# Membuat masonry layout menggunakan columns utilities Tailwind
## Analogi: Perpustakaan Digital
Masonry layout seperti papan pengumuman perpustakaan di mana berbagai poster dan pengumuman ditempel dengan ukuran berbeda. Poster yang tinggi tidak mempengaruhi posisi poster di sebelahnya — semuanya mengalir secara alami dalam kolom, menciptakan tampilan yang tidak beraturan namun teratur.
## Penjelasan Detail
Masonry layout adalah pola tata letak di mana elemen-elemen ditempatkan dalam kolom dengan tinggi yang bervariasi, mirip Pinterest. Tailwind menyediakan utility `columns-*` untuk mencapai efek ini tanpa JavaScript. Anda cukup menentukan jumlah kolom: `columns-2`, `columns-3`, `columns-4`, atau `columns-auto`. Untuk mengontrol jarak antar kolom, gunakan `gap-*`. Untuk mencegah elemen terpotong di antara kolom, gunakan `break-inside-avoid` pada setiap item. Penting: `columns` di CSS bersifat "flow" — item mengalir dari atas ke bawah dalam kolom pertama, lalu ke kolom berikutnya. Ini berbeda dengan Grid yang mengalir per baris. Jika Anda ingin urutan left-to-right (horizontal), gunakan library JavaScript seperti Masonry.js. Untuk kasus penggunaan umum (seperti galeri), `columns` CSS sudah cukup.

## Poin Penting
- Gunakan `columns-*` untuk masonry layout yang mudah tanpa JavaScript atau library tambahan
- Selalu tambahkan `break-inside-avoid` pada setiap item agar tidak terpotong antar kolom
- Columns CSS mengalir vertikal (top-to-bottom), berbeda dengan Grid yang horizontal (left-to-right)
