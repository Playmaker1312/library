# Membuat sticky header dan footer menggunakan Tailwind
## Analogi: Perpustakaan Digital
Sticky header seperti papan nama perpustakaan yang selalu terlihat di atas saat Anda berjalan di antara rak-rak buku. Sticky footer seperti denah perpustakaan yang tetap ada di dasar tas Anda — selalu ada saat Anda butuh, tanpa menghalangi saat tidak.
## Penjelasan Detail
Sticky header adalah header yang tetap berada di atas viewport saat pengguna scroll ke bawah. Implementasi Tailwind-nya sederhana: `sticky top-0 z-10`. Elemen dengan `position: sticky` akan berperilaku seperti `relative` sampai scroll melewati batas tertentu, lalu menjadi `fixed`. Sticky footer berbeda — ia menggunakan `sticky bottom-0` dan berguna untuk toolbar aksi yang ingin tetap terlihat. Untuk footer yang selalu di bagian bawah halaman (sticky bottom) tetapi tidak menimpa konten, gunakan flex layout: `min-h-screen flex flex-col` dengan `mt-auto` pada footer. Atau gunakan Grid: `grid-rows-[auto_1fr_auto]`. Untuk sticky header, pastikan z-index cukup tinggi agar tidak tertimpa konten lain. Perhatikan bahwa `position: sticky` tidak berfungsi jika parent-nya memiliki `overflow: hidden`.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sticky Header Footer - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="min-h-screen flex flex-col">
    <!-- Sticky Header -->
    <header class="sticky top-0 z-50 bg-white shadow-md p-4 border-b">
        <div class="max-w-4xl mx-auto flex items-center justify-between">
            <h1 class="text-xl font-bold text-gray-800">
                <span class="text-blue-600">Perpustakaan</span> Digital
            </h1>
            <nav class="flex gap-4 text-sm text-gray-600">
                <a href="#" class="hover:text-blue-600 transition">Beranda</a>
                <a href="#" class="hover:text-blue-600 transition">Katalog</a>
                <a href="#" class="hover:text-blue-600 transition">Kontak</a>
            </nav>
            <div class="text-xs text-gray-400 bg-gray-100 px-2 py-1 rounded">Sticky Header</div>
        </div>
    </header>

    <!-- Main Content (scroll untuk melihat efek sticky) -->
    <main class="flex-1 bg-gray-100">
        <div class="max-w-4xl mx-auto p-6 space-y-6">
            <!-- Info banner -->
            <div class="p-4 bg-blue-50 border border-blue-200 rounded-lg text-sm text-blue-700">
                Scroll ke bawah untuk melihat efek sticky header. Footer menggunakan <code>mt-auto</code> agar tetap di bawah.
            </div>

            <!-- Konten dummy untuk scrolling -->
            <div class="bg-white rounded-xl shadow-md p-6">
                <h2 class="text-xl font-bold text-gray-800 mb-3">Sticky Header</h2>
                <p class="text-gray-600">Header di atas menggunakan <code>sticky top-0 z-50</code>. Saat Anda scroll, header tetap berada di atas viewport.</p>
            </div>

            <div class="bg-white rounded-xl shadow-md p-6">
                <h2 class="text-xl font-bold text-gray-800 mb-3">Cara Kerja Position Sticky</h2>
                <p class="text-gray-600">Elemen dengan <code>position: sticky</code> berperilaku seperti <code>relative</code> sampai scroll melewati threshold (top: 0), lalu berubah menjadi <code>fixed</code>. Tailwind menyediakan utility <code>sticky</code>, <code>top-0</code>, <code>bottom-0</code>, dll.</p>
            </div>

            <div class="bg-white rounded-xl shadow-md p-6">
                <h2 class="text-xl font-bold text-gray-800 mb-3">Konten Dummy 3</h2>
                <p class="text-gray-600">Terus scroll untuk melihat lebih banyak konten.</p>
            </div>

            <div class="bg-white rounded-xl shadow-md p-6">
                <h2 class="text-xl font-bold text-gray-800 mb-3">Konten Dummy 4</h2>
                <p class="text-gray-600">Scroll terus...</p>
            </div>

            <div class="bg-white rounded-xl shadow-md p-6">
                <h2 class="text-xl font-bold text-gray-800 mb-3">Konten Dummy 5</h2>
                <p class="text-gray-600">Hampir sampai footer.</p>
            </div>
        </div>
    </main>

    <!-- Footer (selalu di bawah) -->
    <footer class="bg-gray-800 text-gray-300 p-6 mt-auto">
        <div class="max-w-4xl mx-auto flex flex-col md:flex-row justify-between items-center gap-4">
            <p class="text-sm">&copy; 2026 Perpustakaan Digital</p>
            <div class="flex gap-4 text-sm">
                <a href="#" class="hover:text-white transition">Kebijakan Privasi</a>
                <a href="#" class="hover:text-white transition">Syarat & Ketentuan</a>
            </div>
        </div>
    </footer>

    <!-- CSS code display -->
    <div class="fixed bottom-4 right-4 p-3 bg-gray-900 text-green-400 rounded-lg text-xs shadow-lg max-w-xs">
        <div class="font-semibold mb-1">Kode:</div>
        <code>header: sticky top-0 z-50</code><br>
        <code>body: min-h-screen flex flex-col</code><br>
        <code>footer: mt-auto</code>
    </div>
</body>
</html>
```
## Poin Penting
- Sticky header: `sticky top-0 z-50` — header tetap di atas saat scroll
- Sticky footer: gunakan `min-h-screen flex flex-col` pada body dan `mt-auto` pada footer
- Position sticky tidak berfungsi jika parent memiliki `overflow: hidden`
