# Membuat Holy Grail layout menggunakan CSS grid Tailwind
## Analogi: Perpustakaan Digital
Holy Grail layout seperti tata letak perpustakaan standar: header di atas (nama perpustakaan), footer di bawah (informasi kontak), sidebar kiri (katalog), konten utama di tengah (ruang baca), dan sidebar kanan (pengumuman). Layout ini terkenal "sulit" dicapai dengan CSS tradisional, tetapi Grid membuatnya mudah.
## Penjelasan Detail
Holy Grail layout adalah pola layout web klasik yang terdiri dari header, footer, sidebar kiri, konten utama, dan sidebar kanan — semuanya dengan tinggi yang sama (full height). Dengan Tailwind CSS Grid, Anda bisa mencapainya dengan mudah menggunakan `grid-rows-[auto_1fr_auto]` untuk tiga baris (header, konten, footer) dan `grid-cols-[200px_1fr_200px]` untuk tiga kolom di area konten. Grid secara otomatis menangani tinggi yang sama (equal height) untuk sidebar dan konten — sesuatu yang sangat sulit dicapai dengan Flexbox tanpa trik. Layout ini responsif secara default di Tailwind: Anda bisa mengubah ke single-column pada layar kecil dengan `grid-cols-1 md:grid-cols-[200px_1fr_200px]`. Gunakan `min-h-screen` untuk memastikan layout memenuhi seluruh tinggi viewport.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Holy Grail Layout - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
    <div class="min-h-screen grid grid-rows-[auto_1fr_auto]">
        <!-- Header -->
        <header class="bg-blue-600 text-white p-4">
            <div class="max-w-6xl mx-auto flex items-center justify-between">
                <h1 class="text-xl font-bold">Perpustakaan Digital</h1>
                <nav class="flex gap-4 text-sm">
                    <a href="#" class="hover:underline">Beranda</a>
                    <a href="#" class="hover:underline">Katalog</a>
                    <a href="#" class="hover:underline">Tentang</a>
                </nav>
            </div>
        </header>

        <!-- Main Content: grid 3 kolom -->
        <main class="grid grid-cols-1 md:grid-cols-[200px_1fr_200px] max-w-6xl mx-auto w-full">
            <!-- Sidebar Kiri -->
            <aside class="bg-gray-100 p-4 border-r border-gray-200">
                <h2 class="font-bold text-gray-700 mb-3">Kategori</h2>
                <ul class="space-y-2 text-sm text-gray-600">
                    <li><a href="#" class="hover:text-blue-600">Fiksi</a></li>
                    <li><a href="#" class="hover:text-blue-600">Non-Fiksi</a></li>
                    <li><a href="#" class="hover:text-blue-600">Sains</a></li>
                    <li><a href="#" class="hover:text-blue-600">Sejarah</a></li>
                </ul>
            </aside>

            <!-- Konten Utama -->
            <article class="p-6 bg-white">
                <h2 class="text-2xl font-bold text-gray-800 mb-4">Konten Utama</h2>
                <p class="text-gray-600 mb-4">Holy Grail layout terdiri dari header, footer, sidebar kiri, konten utama, dan sidebar kanan. Dengan CSS Grid, semua kolom memiliki tinggi yang sama secara otomatis.</p>
                <p class="text-gray-600">Pada layar kecil (&lt; 768px), layout berubah menjadi satu kolom. Sidebar pindah ke bawah konten utama.</p>
            </article>

            <!-- Sidebar Kanan -->
            <aside class="bg-gray-50 p-4 border-l border-gray-200">
                <h2 class="font-bold text-gray-700 mb-3">Pengumuman</h2>
                <div class="p-3 bg-yellow-50 rounded-lg text-sm text-yellow-700">
                    <p class="font-medium">Libur</p>
                    <p>Perpustakaan tutup hari Minggu.</p>
                </div>
            </aside>
        </main>

        <!-- Footer -->
        <footer class="bg-gray-800 text-gray-300 p-4 text-center text-sm">
            <p>&copy; 2026 Perpustakaan Digital. All rights reserved.</p>
        </footer>
    </div>

    <!-- Kode grid -->
    <div class="fixed bottom-4 right-4 p-3 bg-gray-900 text-green-400 rounded-lg text-xs shadow-lg max-w-sm">
        <div class="font-semibold mb-1">Grid Template:</div>
        <code>grid-rows-[auto_1fr_auto]</code><br>
        <code>grid-cols-[200px_1fr_200px]</code>
    </div>
</body>
</html>
```
## Poin Penting
- Gunakan `grid-rows-[auto_1fr_auto]` untuk header, konten fleksibel, footer
- `grid-cols-[200px_1fr_200px]` untuk sidebar kiri, konten utama, sidebar kanan
- Grid secara otomatis menyamakan tinggi semua kolom — tidak perlu trik CSS tambahan
