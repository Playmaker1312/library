# Membuat split screen layout menggunakan grid atau flexbox Tailwind
## Analogi: Perpustakaan Digital
Split screen layout seperti dua ruang baca yang bersebelahan di perpustakaan — satu untuk membaca tenang, satu untuk diskusi kelompok. Keduanya berbagi ruang yang sama, dan Anda bisa menyesuaikan proporsi masing-masing sesuai kebutuhan.
## Penjelasan Detail
Split screen layout membagi layar menjadi dua atau lebih bagian yang sejajar. Contoh klasik: halaman login dengan ilustrasi di kiri dan form di kanan. Dengan Tailwind, ada dua pendekatan: (1) Flexbox: `flex` dengan `w-1/2` atau `flex-1` pada setiap panel. (2) Grid: `grid-cols-2` atau `grid-cols-[1fr_1fr]`. Untuk proporsi tidak sama, gunakan `grid-cols-[2fr_1fr]` atau `flex-[2]` dan `flex-[1]`. Split screen sering dikombinasikan dengan `min-h-screen` untuk memenuhi viewport. Untuk responsivitas, ubah ke single column di mobile: `flex-col md:flex-row` atau `grid-cols-1 md:grid-cols-2`. Split screen juga bisa vertikal (atas-bawah) dengan `flex-col` atau `grid-rows-2`. Tambahkan `overflow-hidden` untuk mencegah scroll pada panel tertentu.

## Poin Penting
- Gunakan `flex-col md:flex-row` atau `grid-cols-1 md:grid-cols-2` untuk split screen responsif
- Atur proporsi dengan `flex-[n]` (flexbox) atau `grid-cols-[nfr_mfr]` (grid)
- Split screen ideal untuk halaman login, landing page, profil, dan dashboard
