# Cara menambah custom breakpoint di tailwind.config.js

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang ingin menambahkan ukuran layar khusus untuk perangkat tertentu. Seperti menambah rak buku baru untuk kategori khusus, custom breakpoint memungkinkan Anda mendefinisikan ukuran layar yang tidak tercakup oleh default Tailwind. Misalnya breakpoint untuk tablet besar (900px) atau monitor ultra-wide (1920px). Anda bisa menyesuaikan breakpoints sesuai kebutuhan spesifik proyek Anda.

## Penjelasan Detail
Untuk menambahkan custom breakpoint, buka tailwind.config.js dan tambahkan di bagian theme.extend.screens. Formatnya: 'nama': 'nilai'. Contoh: 'tablet': '900px' akan menghasilkan class tablet: yang berlaku dari 900px ke atas. Anda juga bisa mengganti breakpoints default dengan mendefinisikan theme.screens (bukan extend). Untuk breakpoint dengan max-width, gunakan objek: 'max-md': { 'max': '767px' }. Custom breakpoint bisa diberi nama apapun sesuai kebutuhan proyek Anda, seperti 'xs': '480px' untuk layar sangat kecil. Pastikan nama breakpoint intuitif dan konsisten dengan konvensi tim.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Custom Breakpoint</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script>
        tailwind.config = {
            theme: {
                extend: {
                    screens: {
                        'xs': '480px',
                        'tablet': '900px',
                        'ultra': '1920px',
                    }
                }
            }
        }
    </script>
</head>
<body class="min-h-screen bg-gray-900 p-4 xs:p-6 tablet:p-10">
    <div class="max-w-5xl mx-auto">
        <h2 class="text-white text-lg xs:text-xl tablet:text-2xl ultra:text-4xl font-bold mb-6 text-center">
            Custom Breakpoint
        </h2>
        <div class="grid grid-cols-1 xs:grid-cols-2 tablet:grid-cols-3 ultra:grid-cols-6 gap-4">
            <div class="bg-blue-500 rounded-xl p-6 text-white text-center font-bold">xs: 480px</div>
            <div class="bg-green-500 rounded-xl p-6 text-white text-center font-bold">tablet: 900px</div>
            <div class="bg-purple-500 rounded-xl p-6 text-white text-center font-bold">ultra: 1920px</div>
            <div class="bg-pink-500 rounded-xl p-6 text-white text-center font-bold">Kartu 4</div>
            <div class="bg-yellow-500 rounded-xl p-6 text-white text-center font-bold">Kartu 5</div>
            <div class="bg-cyan-500 rounded-xl p-6 text-white text-center font-bold">Kartu 6</div>
        </div>
        <div class="mt-6 bg-gray-800 rounded-xl p-4 text-center">
            <p class="text-gray-300 text-sm">Custom breakpoint: xs (480px), tablet (900px), ultra (1920px).</p>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Tambahkan custom breakpoint di theme.extend.screens di tailwind.config.js.
- Format: 'nama': 'nilai' (min-width) atau { 'max': 'nilai' } (max-width).
- Custom breakpoint berguna untuk mendukung perangkat spesifik yang tidak tercakup default.
