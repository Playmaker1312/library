# Cara menggunakan prefix breakpoint yaitu sm:, md:, lg:, xl:, dan 2xl:

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang mengatur ulang tampilan bukunya saat layar diperbesar. Prefix breakpoint seperti perintah "saat layar mencapai ukuran tertentu, lakukan ini". sm: seperti aturan untuk layar kecil, md: untuk layar menengah, dan seterusnya. Seperti mengatur ulang furnitur saat ruangan diperluas, setiap breakpoint menyesuaikan layout secara otomatis.

## Penjelasan Detail
Untuk menggunakan responsive prefix, tambahkan prefix breakpoint di depan utility class: sm:flex, md:grid-cols-3, lg:text-2xl, xl:w-1/2, 2xl:p-10. Prefix dapat dikombinasikan dengan variant lain seperti md:hover:scale-105 atau lg:focus:ring-2. Urutan penulisan class sebaiknya dari yang paling umum (tanpa prefix) ke yang paling spesifik (prefix terbesar). Karena Tailwind menggunakan min-width, gaya dengan prefix yang lebih besar akan menimpa gaya yang lebih kecil jika keduanya berlaku. Penting untuk diingat bahwa Anda tidak perlu menggunakan breakpoint untuk setiap properti; gunakan hanya ketika diperlukan perubahan pada ukuran layar tertentu.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Prefix Breakpoint</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-6 p-4 sm:p-6 md:p-8 lg:p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-lg sm:text-xl md:text-2xl lg:text-3xl xl:text-4xl font-bold transition-all">
        Responsive Text
    </h2>
    <div class="flex flex-col sm:flex-row md:flex-row lg:flex-row gap-4 w-full max-w-4xl">
        <div class="flex-1 bg-gradient-to-br from-blue-500 to-purple-600 rounded-xl p-6 text-white text-center">
            <p class="text-sm sm:text-base md:text-lg">Layout berubah dari kolom (mobile) menjadi baris (desktop)</p>
        </div>
        <div class="flex-1 bg-gradient-to-br from-green-400 to-teal-500 rounded-xl p-6 text-white text-center">
            <p class="text-sm sm:text-base md:text-lg">Gunakan sm:flex-row untuk mengubah arah flex</p>
        </div>
    </div>
    <div class="hidden sm:block md:hidden lg:block bg-gray-800 p-4 rounded-xl w-full max-w-4xl text-center">
        <p class="text-gray-300">Elemen ini: hidden di mobile, sm:block, md:hidden, lg:block</p>
    </div>
</body>
</html>
```

## Poin Penting
- Prefix breakpoint ditempatkan sebelum utility class: md:flex, lg:text-2xl, xl:w-1/2.
- Urutan penulisan: tanpa prefix (mobile) &rarr; sm: &rarr; md: &rarr; lg: &rarr; xl: &rarr; 2xl:.
- Kombinasikan dengan variant state: md:hover:scale-105, lg:focus:ring-2.
