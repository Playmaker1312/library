# Cara membuat layout yang berbeda di setiap breakpoint

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang mengatur ulang rak bukunya secara otomatis saat layar berubah. Di ponsel, rak bertumpuk vertikal; di tablet, rak berbaris dua kolom; di desktop, rak berbaris empat kolom. Seperti ruangan yang bisa diatur ulang furniturnya, layout yang responsif memastikan konten selalu optimal di setiap ukuran layar. Tailwind memudahkan ini dengan utility grid dan flex responsif.

## Penjelasan Detail
Untuk membuat layout berbeda di setiap breakpoint, Anda bisa menggunakan kombinasi grid dan flex dengan prefix breakpoint. Contoh: grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 untuk grid yang kolomnya bertambah sesuai layar. Atau flex-col md:flex-row untuk mengubah arah flex. Anda juga bisa mengubah gap, padding, dan properti layout lainnya secara responsif. Teknik umum: (1) Mobile: single column stack, (2) Tablet: 2-3 columns, (3) Desktop: 3-4+ columns. Untuk layout yang lebih kompleks, Anda bisa menyembunyikan/menampilkan elemen atau mengubah order elemen.

## Poin Penting
- Gunakan grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 untuk grid responsif.
- Ubah arah flex dengan flex-col md:flex-row pada container flex.
- Atur properti layout lain (gap, padding, order) secara responsif sesuai kebutuhan.
