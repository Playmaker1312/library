# Memahami breakpoints default Tailwind yaitu sm 640px, md 768px, lg 1024px, xl 1280px, dan 2xl 1536px

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang menyesuaikan tampilan rak bukunya berdasarkan ukuran layar pengunjung. Breakpoints seperti aturan tata letak yang berubah saat layar mencapai lebar tertentu: sm (640px) untuk ponsel kecil, md (768px) untuk tablet, lg (1024px) untuk laptop, xl (1280px) untuk desktop, dan 2xl (1536px) untuk layar lebar. Seperti rak yang bisa diatur ulang, setiap ukuran layar mendapat pengalaman optimal.

## Penjelasan Detail
Tailwind menggunakan pendekatan mobile-first dengan lima breakpoints default. sm: 640px (min-width), md: 768px, lg: 1024px, xl: 1280px, dan 2xl: 1536px. Tanpa prefix berarti gaya berlaku untuk semua ukuran layar (mobile). Setiap prefix breakpoint berarti "pada ukuran layar ini dan di atasnya". Misalnya md:flex berarti flex dimulai dari layar 768px ke atas. Penting untuk memahami bahwa breakpoints bekerja dengan min-width, bukan max-width. Ini berarti Anda mendesain untuk mobile terlebih dahulu, lalu menambahkan breakpoint untuk layar yang lebih besar. Breakpoints dapat dikustomisasi di tailwind.config.js.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Breakpoints Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-6 p-4 min-h-screen bg-gray-900">
    <h2 class="text-white text-xl sm:text-2xl md:text-3xl lg:text-4xl font-bold text-center transition-all">
        Breakpoints Tailwind
    </h2>
    <div class="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 xl:grid-cols-5 gap-4 w-full max-w-5xl">
        <div class="bg-blue-500 rounded-xl h-24 flex items-center justify-center text-white font-bold">1</div>
        <div class="bg-green-500 rounded-xl h-24 flex items-center justify-center text-white font-bold">2</div>
        <div class="bg-purple-500 rounded-xl h-24 flex items-center justify-center text-white font-bold">3</div>
        <div class="bg-pink-500 rounded-xl h-24 flex items-center justify-center text-white font-bold">4</div>
        <div class="bg-yellow-500 rounded-xl h-24 flex items-center justify-center text-white font-bold">5</div>
    </div>
    <div class="bg-gray-800 rounded-xl p-4 w-full max-w-5xl">
        <p class="text-gray-300 text-center">
            Layar saat ini: <span class="text-blue-400 font-bold sm:text-green-400 md:text-purple-400 lg:text-pink-400 xl:text-yellow-400 2xl:text-red-400">resize untuk lihat perubahan</span>
        </p>
    </div>
</body>
</html>
```

## Poin Penting
- Lima breakpoints default: sm (640px), md (768px), lg (1024px), xl (1280px), 2xl (1536px).
- Pendekatan mobile-first: tanpa prefix = semua ukuran, prefix = mulai dari ukuran tersebut ke atas.
- Breakpoints dapat dikustomisasi di tailwind.config.js sesuai kebutuhan proyek.
