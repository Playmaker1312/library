# @layer Directive

## Penjelasan

- `@layer` adalah directive CSS milik Tailwind yang digunakan di dalam file CSS (biasanya `input.css` atau `main.css`) bersama `@tailwind` directives.
- Ada tiga layer yang bisa digunakan: `base`, `components`, dan `utilities`.
- `@layer base` digunakan untuk menulis style dasar seperti reset atau style untuk elemen HTML (body, html, heading, selection, scrollbar).
- `@layer components` digunakan untuk mendefinisikan kelas reusable seperti tombol, card, badge, atau pattern yang dipakai berulang.
- `@layer utilities` digunakan untuk membuat utility class kustom yang tidak ada di Tailwind default.
- Style di setiap layer akan diinjeksi pada urutan yang tepat sesuai specificity system Tailwind, sehingga tidak ada konflik.
- Urutan prioritas: base (terendah) < components < utilities (tertinggi).

## Fungsi

Membuat CSS kustom yang tetap terintegrasi dengan sistem layer Tailwind, menjaga konsistensi specificity, dan memungkinkan utility Tailwind tetap bisa meng-override style kustom.

## Cara Pengimplementasian / Kode

```css
/* main.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer base {
  html {
    scroll-behavior: smooth;
  }
  body {
    @apply bg-white text-gray-900 antialiased;
  }
  ::selection {
    @apply bg-blue-500 text-white;
  }
  h1, h2, h3 {
    @apply font-bold tracking-tight;
  }
}

@layer components {
  .btn-primary {
    @apply inline-block px-6 py-3 bg-blue-600 text-white font-semibold rounded-lg 
           hover:bg-blue-700 transition-colors duration-200;
  }
  .card {
    @apply bg-white rounded-xl shadow-md p-6 border border-gray-200;
  }
  .badge {
    @apply inline-flex items-center px-3 py-1 text-xs font-medium rounded-full;
  }
}

@layer utilities {
  .text-balance {
    text-wrap: balance;
  }
  .scrollbar-hide {
    -ms-overflow-style: none;
    scrollbar-width: none;
  }
  .scrollbar-hide::-webkit-scrollbar {
    display: none;
  }
}
```

```html
<!-- Contoh penggunaan component & utility kustom -->
<nav class="bg-gray-800 p-4">
  <div class="card">
    <span class="badge bg-green-100 text-green-800">Baru</span>
    <h2 class="text-xl font-bold">Judul Card</h2>
    <p class="text-balance mt-2">Teks yang seimbang tanpa orphan words.</p>
    <a href="#" class="btn-primary mt-4 inline-block">Lihat Detail</a>
  </div>
</nav>
```

## Analogi

- `@layer base` = **fondasi rumah**. Beton, pondasi, tiang utama. Elemen dasar yang menopang semuanya: body, html, selection.
- `@layer components` = **ruangan siap pakai**. Kamar tidur, dapur, kamar mandi. Komponen reusable yang tinggal pakai: tombol, card, navbar.
- `@layer utilities` = **alat-alat khusus**. Obeng listrik, bor, palu pneumatik. Utility spesifik yang hanya dipakai saat diperlukan untuk tugas tertentu.

## Dipakai untuk Apa

- Menulis style global untuk elemen HTML dasar (base).
- Mendefinisikan komponen UI yang dipakai di banyak tempat tanpa harus menulis ulang utility setiap kali (components).
- Membuat utility kecil yang tidak tersedia di Tailwind, seperti text-wrap, scrollbar-hide, atau mask gradient (utilities).

## Kesalahan Umum yang Sering Terjadi

1. **Menggunakan @layer di luar file CSS utama**: @layer hanya berfungsi jika ditulis di file yang juga memiliki `@tailwind` directives.
2. **Menempatkan @layer components tapi berisi utility**: Layer components seharusnya berisi kelas komponen, bukan utility tunggal.
3. **Lupa @apply untuk utility Tailwind di dalam component**: Saat menulis komponen, gunakan `@apply` agar utility Tailwind bisa di-override nantinya.
4. **Bingung urutan layer**: Components tidak bisa meng-override utilities, jadi jika ada konflik, utilities menang.
5. **Overuse @layer components**: Terlalu banyak mendefinisikan komponen di CSS padahal bisa menggunakan pendekatan framework component (React/Vue) lebih efektif.

## Koneksi dengan Materi Sebelumnya

Setelah menguasai Extend vs Override (materi 31) untuk mengatur tema di `tailwind.config.js`, sekarang kamu bisa menulis CSS kustom yang terintegrasi dengan Tailwind melalui `@layer`. Config mengatur tema, `@layer` mengatur style tambahan -- keduanya bekerja bersama untuk membangun design system yang lengkap.

## Soal Latihan

Buat file CSS utama yang berisi:
1. Layer base: atur `body` dengan font-sans, bg-gray-50, text-gray-800, dan `::selection` dengan bg-blue-600 text-white.
2. Layer components: buat kelas `.btn-danger` dengan bg merah, hover lebih gelap, padding, rounded, dan transisi.
3. Layer utilities: buat kelas `.rotate-y-180` yang melakukan transform `rotateY(180deg)`.

  .rotate-y-180 {

}
