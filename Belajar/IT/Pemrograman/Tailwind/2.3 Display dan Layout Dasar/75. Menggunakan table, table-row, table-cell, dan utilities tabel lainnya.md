# Menggunakan table, table-row, table-cell, dan utilities tabel lainnya

## Analogi: Perpustakaan Digital

Table utilities seperti mengatur data katalog perpustakaan dalam format tabel. `table` membuat wadah seperti tabel, `table-row` seperti baris, `table-cell` seperti sel. Berguna untuk menata data tabular tanpa menggunakan tag `<table>`. Sama seperti katalog buku yang disusun dalam baris dan kolom informatif.

## Penjelasan Detail

Table utilities meliputi `table`, `table-caption`, `table-cell`, `table-column`, `table-column-group`, `table-footer-group`, `table-header-group`, `table-row`, `table-row-group`. Utility ini mengubah display elemen menjadi varian tabel CSS. Berguna untuk layout yang membutuhkan perilaku tabel (seperti vertical alignment merata) tanpa menggunakan markup tabel HTML. Juga berguna untuk mempertahankan semantik HTML yang lebih baik sambil mendapatkan layout tabel.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Table Utilities Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8">
  <h1 class="text-2xl font-bold mb-4">Table Utilities</h1>
  <div class="table w-full border-collapse">
    <div class="table-header-group bg-blue-500 text-white">
      <div class="table-row">
        <div class="table-cell p-3 font-semibold border">Judul</div>
        <div class="table-cell p-3 font-semibold border">Penulis</div>
        <div class="table-cell p-3 font-semibold border">Tahun</div>
      </div>
    </div>
    <div class="table-row-group">
      <div class="table-row even:bg-gray-100">
        <div class="table-cell p-3 border">Belajar Tailwind</div>
        <div class="table-cell p-3 border">John Doe</div>
        <div class="table-cell p-3 border">2024</div>
      </div>
      <div class="table-row even:bg-gray-100">
        <div class="table-cell p-3 border">CSS Modern</div>
        <div class="table-cell p-3 border">Jane Smith</div>
        <div class="table-cell p-3 border">2023</div>
      </div>
      <div class="table-row even:bg-gray-100">
        <div class="table-cell p-3 border">Web Design</div>
        <div class="table-cell p-3 border">Bob Wilson</div>
        <div class="table-cell p-3 border">2025</div>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Utility `table`, `table-row`, `table-cell` untuk display tabel CSS
- Berguna untuk layout tabular tanpa markup `<table>`
- Mendukung grouping seperti `table-header-group` dan `table-row-group`
