# Menggunakan grid untuk mengaktifkan CSS grid container

## Analogi: Perpustakaan Digital

Grid seperti rak buku berbentuk tabel dengan baris dan kolom yang terdefinisi. Jika flexbox adalah rak linear satu dimensi, grid adalah rak dua dimensi yang mengatur buku dalam baris dan kolom sekaligus. Grid memungkinkan penempatan buku secara presisi di sel-sel tertentu. Seperti catalog perpustakaan digital yang tersusun rapi.

## Penjelasan Detail

Utility `grid` mengubah display menjadi `grid`, mengaktifkan CSS grid container. Grid membutuhkan definisi kolom (`grid-cols-*`) dan/atau baris (`grid-rows-*`). Grid memberikan kontrol dua dimensi penuh atas layout. Child secara otomatis ditempatkan ke dalam sel-sel grid secara berurutan. Grid ideal untuk layout halaman kompleks, gallery, dashboard, dan card grids. Berbeda dengan flexbox yang satu dimensi, grid unggul untuk layout yang membutuhkan kontrol baris dan kolom.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Grid Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Grid Container</h1>
  <div class="grid grid-cols-3 gap-4">
    <div class="bg-blue-500 text-white p-4 rounded">1</div>
    <div class="bg-blue-500 text-white p-4 rounded">2</div>
    <div class="bg-blue-500 text-white p-4 rounded">3</div>
    <div class="bg-blue-500 text-white p-4 rounded">4</div>
    <div class="bg-blue-500 text-white p-4 rounded">5</div>
    <div class="bg-blue-500 text-white p-4 rounded">6</div>
  </div>
  <div>
    <h2 class="font-semibold mb-2">Grid dengan responsive breakpoints</h2>
    <div class="grid grid-cols-1 md:grid-cols-3 gap-4">
      <div class="bg-green-500 text-white p-4 rounded">Responsif 1</div>
      <div class="bg-green-500 text-white p-4 rounded">Responsif 2</div>
      <div class="bg-green-500 text-white p-4 rounded">Responsif 3</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `grid` mengaktifkan CSS grid container
- Membutuhkan definisi kolom/baris via `grid-cols-*` dan `grid-rows-*`
- Ideal untuk layout dua dimensi yang kompleks
