# Menggunakan inline-flex dan inline-grid

## Analogi: Perpustakaan Digital

Jika flex dan grid seperti rak buku yang mengambil satu baris penuh, `inline-flex` dan `inline-grid` seperti rak yang hanya selebar kontennya dan bisa bersebelahan dengan rak lain. Ini seperti rak kecil yang diletakkan di antara buku-buku lain dalam satu baris tanpa memulai baris baru.

## Penjelasan Detail

`inline-flex` dan `inline-grid` adalah versi inline dari flexbox dan grid. Mereka membuat container berperilaku seperti elemen inline (tidak memulai baris baru) namun tetap memiliki kemampuan flexbox/grid di dalamnya. Berguna untuk komponen inline seperti tombol grup, badge, atau elemen navigasi kecil. Perbedaan utama dengan `flex`/`grid` biasa adalah container tidak mengambil lebar penuh parent. Sangat berguna saat ingin menggabungkan beberapa flex/grid container dalam satu baris.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Inline Flex Grid Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Inline-flex & Inline-grid</h1>
  <div class="bg-gray-100 p-4 rounded-lg">
    <span class="text-gray-500">Teks sebelum </span>
    <div class="inline-flex space-x-2 bg-blue-500 text-white p-2 rounded">
      <span>inline-flex</span>
      <span>item</span>
    </div>
    <span class="text-gray-500"> teks setelah (masih dalam baris yang sama)</span>
  </div>
  <div class="bg-gray-100 p-4 rounded-lg">
    <span class="text-gray-500">Teks sebelum </span>
    <div class="inline-grid grid-cols-2 gap-1 bg-green-500 text-white p-2 rounded">
      <span>A</span><span>B</span>
      <span>C</span><span>D</span>
    </div>
    <span class="text-gray-500"> teks setelah</span>
  </div>
  <div>
    <h2 class="font-semibold mb-2">Perbandingan flex vs inline-flex</h2>
    <div class="bg-gray-200 p-4">
      <div class="flex bg-red-400 text-white p-2 mb-2">flex (baris baru)</div>
      <div class="inline-flex bg-red-400 text-white p-2">inline-flex (tidak baris baru)</div>
      <span> bersebelahan</span>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `inline-flex` dan `inline-grid` tidak memulai baris baru
- Container hanya selebar kontennya
- Berguna untuk komponen inline yang membutuhkan layout flexbox/grid
