# Menggunakan flex untuk mengaktifkan flexbox container

## Analogi: Perpustakaan Digital

Flex seperti sistem rak buku yang fleksibel dan adaptif. Saat mengaktifkan flex pada container, semua buku di dalamnya secara otomatis tersusun rapi dalam satu baris. Flexbox memudahkan pengaturan posisi, perataan, dan distribusi ruang antar buku tanpa perlu kalkulasi manual. Seperti rak yang secara cerdas mengatur koleksi bukunya.

## Penjelasan Detail

Utility `flex` mengubah properti display menjadi `flex`, mengaktifkan flexbox pada container. Semua child langsung menjadi flex items yang secara default tersusun dalam baris (horizontal). Flexbox memberikan kontrol atas arah (flex-direction), pembungkusan (flex-wrap), perataan (justify-content, align-items), dan urutan (order). Flex adalah fondasi layout modern di Tailwind. Hampir semua layout web modern menggunakan flexbox untuk distribusi ruang yang dinamis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Flex Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Flex Container</h1>
  <div class="flex bg-gray-100 p-4 rounded-lg space-x-4">
    <div class="bg-blue-500 text-white p-4 rounded">Item 1</div>
    <div class="bg-blue-500 text-white p-4 rounded">Item 2</div>
    <div class="bg-blue-500 text-white p-4 rounded">Item 3</div>
  </div>
  <div>
    <h2 class="font-semibold mb-2">Flex dengan justify-between</h2>
    <nav class="flex justify-between bg-gray-800 text-white p-4 rounded">
      <span>Logo</span>
      <div class="flex space-x-4">
        <a href="#">Home</a>
        <a href="#">About</a>
        <a href="#">Contact</a>
      </div>
    </nav>
  </div>
  <div>
    <h2 class="font-semibold mb-2">Flex center</h2>
    <div class="flex items-center justify-center bg-purple-100 p-8 rounded-lg h-32">
      <div class="bg-purple-500 text-white px-6 py-3 rounded">Tengah</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `flex` mengaktifkan flexbox pada container
- Child otomatis menjadi flex items dalam baris horizontal
- Wajib dipahami sebagai fondasi layout Tailwind
