# Menggunakan container di Tailwind dan perbedaannya dengan Bootstrap container

## Analogi: Perpustakaan Digital

Container seperti ruang baca utama di perpustakaan digital yang membatasi lebar maksimal konten dan menengahkan secara otomatis. Di Tailwind, container bersifat opsional dan lebih fleksibel. Berbeda dengan Bootstrap yang memiliki container fixed dengan breakpoint spesifik, container Tailwind lebih sederhana dan dapat dikustomisasi.

## Penjelasan Detail

Container di Tailwind adalah utility `container` yang membatasi lebar maksimal konten berdasarkan breakpoint dan menengahkan dengan margin auto. Perbedaan dengan Bootstrap: (1) Tailwind container tidak memiliki padding default, (2) Tailwind container hanya mengatur max-width di setiap breakpoint tanpa lebar tetap, (3) Tailwind tidak memiliki container-fluid (gantinya gunakan `w-full`), (4) Tailwind container dapat dikustomisasi di konfigurasi. Container sangat berguna untuk layout halaman yang terpusat dengan lebar maksimal.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Container Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
  <div class="container mx-auto bg-gray-100 p-4">
    <h1 class="text-2xl font-bold text-blue-600">Container Tailwind</h1>
    <p class="mt-2">Container ini terpusat dengan lebar maksimal responsif.</p>
    <p class="text-sm text-gray-500">Coba resize browser untuk melihat perubahan lebar.</p>
  </div>
  <div class="container mx-auto mt-4 grid grid-cols-1 md:grid-cols-2 gap-4">
    <div class="bg-blue-500 text-white p-4 rounded">Kiri</div>
    <div class="bg-green-500 text-white p-4 rounded">Kanan</div>
  </div>
</body>
</html>
```

## Poin Penting
- `container` membatasi lebar maksimal dan menengahkan konten
- Berbeda dengan Bootstrap: tidak ada padding default, tidak ada container-fluid
- Dapat dikustomisasi melalui konfigurasi tailwind.config
