# Menggunakan block, inline-block, inline, hidden, dan contents

## Analogi: Perpustakaan Digital

Display utilities seperti menentukan cara buku ditampilkan di rak. `block` seperti buku yang mengambil satu baris penuh (seperti rak terpisah). `inline` seperti buku yang berdiri bersebelahan dalam satu baris. `inline-block` seperti buku yang bersebelahan tapi tetap punya lebar dan tinggi sendiri. `hidden` menyembunyikan buku dari rak. `contents` membuat buku "tembus pandang" dan hanya anak-anaknya yang terlihat.

## Penjelasan Detail

Display utilities mengubah properti CSS `display`. `block` membuat elemen mengambil lebar penuh dan memulai baris baru. `inline-block` menggabungkan sifat inline (bersebelahan) dengan kemampuan mengatur lebar/tinggi. `inline` membuat elemen mengalir dalam teks tanpa memulai baris baru. `hidden` setara dengan `display: none`. `contents` membuat elemen induk tidak terlihat secara visual, hanya anak-anaknya yang di-render. Sangat penting untuk layout dan responsivitas.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Display Utilities Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Display Utilities</h1>
  <div>
    <h2 class="font-semibold">block</h2>
    <div class="bg-blue-500 text-white p-2 block">block 1</div>
    <div class="bg-blue-500 text-white p-2 block">block 2</div>
  </div>
  <div>
    <h2 class="font-semibold">inline-block</h2>
    <div class="bg-green-500 text-white p-2 inline-block">inline-1</div>
    <div class="bg-green-500 text-white p-2 inline-block">inline-2</div>
  </div>
  <div>
    <h2 class="font-semibold">inline</h2>
    <span class="bg-red-500 text-white p-2 inline">inline 1</span>
    <span class="bg-red-500 text-white p-2 inline">inline 2</span>
  </div>
  <div>
    <h2 class="font-semibold">hidden</h2>
    <div class="bg-purple-500 text-white p-2 hidden">Tidak terlihat</div>
    <p>Elemen di atas hidden.</p>
  </div>
</body>
</html>
```

## Poin Penting
- `block` mengambil lebar penuh, `inline` mengalir dalam teks
- `inline-block` menggabungkan kelebihan keduanya
- `hidden` untuk menyembunyikan elemen, `contents` untuk menghapus parent dari render
