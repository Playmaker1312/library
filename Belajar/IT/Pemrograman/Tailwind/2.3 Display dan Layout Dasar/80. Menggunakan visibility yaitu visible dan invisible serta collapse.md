# Menggunakan visibility yaitu visible dan invisible serta collapse

## Analogi: Perpustakaan Digital

Visibility utilities seperti menentukan apakah buku terlihat di rak atau tidak. `visible` membuat buku tampak normal. `invisible` membuat buku tidak terlihat namun tetap memakan tempat di rak (berbeda dengan hidden yang menghilangkan tempat). `collapse` khusus untuk elemen tabel yang menyembunyikan baris tanpa memengaruhi layout tabel.

## Penjelasan Detail

Visibility utilities: `visible` (visibility: visible), `invisible` (visibility: hidden), `collapse` (visibility: collapse). Perbedaan utama dengan `hidden` (display: none): `invisible` menyembunyikan elemen secara visual namun elemen tetap mempertahankan ruangnya di layout. `collapse` untuk baris/kolom tabel yang menyembunyikan konten tetapi mempertahankan lebar kolom. `invisible` berguna untuk elemen yang perlu tetap di layout tapi disembunyikan (seperti placeholder).

```html
    <div class="bg-red-500 text-white p-4 visible">visible</div>
  </div>
  <p class="text-sm text-gray-500">Elemen invisible tetap mempertahankan ruangnya (ada celah).</p>
  <div class="flex space-x-4 bg-gray-100 p-4">
    <div class="bg-blue-500 text-white p-4">normal</div>
    <div class="bg-blue-500 text-white p-4 hidden">hidden (display none)</div>
    <div class="bg-blue-500 text-white p-4">normal - lihat tidak ada celah</div>
  </div>
  <p class="text-sm text-gray-500">Elemen hidden tidak mempertahankan ruangnya.</p>

```

## Poin Penting
- `invisible` menyembunyikan visual tetapi tetap mempertahankan ruang
- `hidden` (`display: none`) menghilangkan elemen beserta ruangnya
- `collapse` khusus untuk elemen tabel
