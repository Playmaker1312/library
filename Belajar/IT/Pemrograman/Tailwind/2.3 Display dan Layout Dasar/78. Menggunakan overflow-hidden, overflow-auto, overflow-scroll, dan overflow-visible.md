# Menggunakan overflow-hidden, overflow-auto, overflow-scroll, dan overflow-visible

## Analogi: Perpustakaan Digital

Overflow utilities seperti mengatur apa yang terjadi ketika konten buku melebihi batas raknya. `overflow-hidden` memotong kelebihan konten (seperti buku yang dipotong). `overflow-auto` menampilkan scrollbar hanya jika diperlukan. `overflow-scroll` selalu menampilkan scrollbar. `overflow-visible` membiarkan konten meluber keluar rak.

## Penjelasan Detail

Overflow utilities mengatur properti CSS `overflow`. `overflow-hidden` memotong konten yang melampaui batas elemen. `overflow-auto` menambahkan scrollbar secara otomatis saat konten melebihi batas. `overflow-scroll` selalu menampilkan scrollbar. `overflow-visible` adalah default browser, konten tetap terlihat meskipun melampaui batas. Sangat penting untuk layout yang membutuhkan area scroll, cropping gambar, atau mencegah overflow merusak layout.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Overflow Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8">
  <h1 class="text-2xl font-bold mb-4">Overflow Utilities</h1>
  <div class="grid grid-cols-2 gap-4">
    <div class="overflow-hidden bg-blue-100 p-2 h-20">
      <h2 class="font-semibold">overflow-hidden</h2>
      <p>Konten yang sangat panjang ini akan dipotong karena melebihi tinggi container yang dibatasi.</p>
    </div>
    <div class="overflow-auto bg-green-100 p-2 h-20">
      <h2 class="font-semibold">overflow-auto</h2>
      <p>Konten yang sangat panjang ini akan memiliki scrollbar otomatis jika melebihi batas.</p>
    </div>
    <div class="overflow-scroll bg-red-100 p-2 h-20">
      <h2 class="font-semibold">overflow-scroll</h2>
      <p>Scrollbar selalu muncul di sini meskipun konten tidak terpotong.</p>
    </div>
    <div class="overflow-visible bg-purple-100 p-2 h-20">
      <h2 class="font-semibold">overflow-visible</h2>
      <p>Konten yang meluber akan tetap terlihat keluar dari batas container.</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `overflow-hidden` memotong konten berlebih, `overflow-auto` scroll otomatis
- `overflow-scroll` selalu menampilkan scrollbar
- `overflow-visible` membiarkan konten meluber
