# Menggunakan Border Color Utilities di Tailwind

## Analogi: Perpustakaan Digital

Border color seperti bingkai foto di perpustakaan. Bingkai emas untuk foto penting, bingkai perak untuk foto biasa, bingkai merah untuk pengumuman darurat. Warna bingkai membantu pengunjung memahami tingkat kepentingan setiap tampilan.

## Penjelasan Detail

Kelas border color menggunakan format `border-{color}-{shade}`. Contoh: `border-purple-300` untuk border ungu muda, `border-gray-200` untuk border abu-abu terang yang sering digunakan untuk pemisah halus. Border color harus digunakan bersama dengan kelas `border` yang mengatur ketebalan (default 1px). Bisa juga dengan `border-2`, `border-4`, `border-8` untuk ketebalan berbeda. Untuk border hanya di sisi tertentu: `border-t`, `border-b`, `border-l`, `border-r`. Border color sangat berguna untuk kartu, input form, tabel, dan elemen yang perlu batas visual. Warna border yang lebih gelap (400-600) untuk input aktif, lebih terang (100-200) untuk pemisah pasif.

```html
<!DOCTYPE html>
<html lang="en">
<head>

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full space-y-4">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Border Color</h1>
        <div class="border border-gray-200 bg-white p-4 rounded-lg">border-gray-200 - Border halus default</div>
        <div class="border-2 border-purple-300 bg-white p-4 rounded-lg">border-purple-300 - Border ungu muda</div>
        <div class="border-2 border-blue-500 bg-white p-4 rounded-lg">border-blue-500 - Border biru solid</div>
        <div class="border-l-4 border-green-500 bg-white p-4 rounded-lg">border-l-4 border-green-500 - Aksen kiri hijau</div>
        <div class="border-2 border-red-400 bg-red-50 p-4 rounded-lg">border-red-400 - Border merah (error/warning)</div>
        <div class="border border-yellow-400 bg-yellow-50 p-4 rounded-lg">border-yellow-400 - Border kuning (peringatan)</div>
    </div>
</body>
</html>
```

## Poin Penting
- Format: `border-{warna}-{shade}`, butuh kelas `border` untuk ketebalan
- border-100/200 untuk pemisah halus, border-400/600 untuk input aktif
- Bisa spesifik per sisi: border-t, border-b, border-l, border-r
