# Menggunakan Warna Current di Tailwind

## Analogi: Perpustakaan Digital

Warna current seperti bunglon yang bisa berubah warna mengikuti lingkungan. Jika ditempatkan di halaman biru, ia jadi biru. Di halaman merah, ia jadi merah. Ini memungkinkan satu elemen mewarisi warna dari elemen induknya tanpa perlu menentukan warna spesifik.

## Penjelasan Detail

`text-current` dan `bg-current` menggunakan nilai CSS `currentColor` yang mewarisi nilai `color` dari elemen induk. Jika induk memiliki `text-red-500`, maka elemen dengan `bg-current` akan memiliki background merah yang sama. Ini sangat berguna untuk komponen ikon SVG yang ingin mengikuti warna teks di sekitarnya. Contoh: sebuah tombol dengan ikon SVG di dalamnya - saat tombol di-hover dan berubah warna, ikon otomatis ikut berubah tanpa perlu CSS tambahan. `text-current` berguna untuk situasi di mana Anda ingin memaksa sebuah elemen menggunakan warna yang diwarisi. Ini adalah pendekatan yang lebih fleksibel daripada warna kaku.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Current Color</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full space-y-6">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Current Color</h1>
        <div class="text-blue-600 bg-blue-50 p-4 rounded-xl">
            <p class="font-semibold">Induk: text-blue-600</p>
            <div class="mt-2 flex items-center gap-2">
                <svg class="w-6 h-6 text-current" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                    <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M5 13l4 4L19 7"/>
                </svg>
                <span>Ikon menggunakan currentColor, otomatis biru</span>
            </div>
        </div>
        <div class="text-green-600 bg-green-50 p-4 rounded-xl">
            <p class="font-semibold">Induk: text-green-600</p>
            <div class="mt-2 flex items-center gap-2">
                <svg class="w-6 h-6 text-current" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                    <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M5 13l4 4L19 7"/>
                </svg>
                <span>Ikon otomatis hijau mengikuti induk</span>
            </div>
        </div>
        <div class="text-purple-700 bg-purple-50 p-4 rounded-xl">
            <p class="font-semibold">Hover untuk lihat perubahan</p>
            <button class="mt-2 px-4 py-2 bg-purple-500 text-white rounded-lg hover:bg-purple-700 transition-colors group">
                <span class="flex items-center gap-2">
                    <svg class="w-5 h-5 text-current" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M13 10V3L4 14h7v7l9-11h-7z"/>
                    </svg>
                    Ikon mengikuti warna tombol
                </span>
            </button>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- `currentColor` mewarisi nilai color dari elemen induk
- Sangat berguna untuk ikon SVG yang mengikuti warna teks
- text-current dan bg-current menggunakan currentColor CSS
