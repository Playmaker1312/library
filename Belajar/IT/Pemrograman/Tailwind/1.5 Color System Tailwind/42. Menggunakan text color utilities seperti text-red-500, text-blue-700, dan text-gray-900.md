# Menggunakan Text Color Utilities di Tailwind

## Analogi: Perpustakaan Digital

Text color seperti tinta warna-warni di perpustakaan. Ada tinta merah untuk judul penting, tinta biru untuk link, tinta abu-abu untuk catatan kaki, dan tinta hitam untuk teks utama. Setiap warna tinta sudah memiliki gradasi ketebalan dari sangat tipis hingga sangat pekat.

## Penjelasan Detail

Kelas text color menggunakan format `text-{color}-{shade}`. Contoh: `text-red-500` untuk teks merah, `text-blue-700` untuk teks biru gelap, `text-gray-900` untuk teks abu-abu hampir hitam. Warna netral seperti gray, slate, zinc, neutral, stone sangat berguna untuk hierarki tipografi: `text-gray-900` untuk judul, `text-gray-700` untuk teks body, `text-gray-500` untuk teks sekunder, `text-gray-400` untuk placeholder. Warna cerah seperti red, blue, green digunakan untuk penekanan, link, status, atau pesan error/sukses. Bisa juga menggunakan `text-black`, `text-white`, dan `text-transparent`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Color</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-white p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full space-y-4">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Text Color Utilities</h1>
        <p class="text-gray-900 bg-gray-50 p-3 rounded-lg">text-gray-900 - Judul / teks utama</p>
        <p class="text-gray-700 bg-gray-50 p-3 rounded-lg">text-gray-700 - Teks body</p>
        <p class="text-gray-500 bg-gray-50 p-3 rounded-lg">text-gray-500 - Teks sekunder</p>
        <p class="text-gray-400 bg-gray-50 p-3 rounded-lg">text-gray-400 - Placeholder</p>
        <p class="text-blue-600 bg-blue-50 p-3 rounded-lg">text-blue-600 - Link</p>
        <p class="text-red-600 bg-red-50 p-3 rounded-lg">text-red-600 - Error / peringatan</p>
        <p class="text-green-600 bg-green-50 p-3 rounded-lg">text-green-600 - Sukses</p>
        <p class="text-purple-600 bg-purple-50 p-3 rounded-lg">text-purple-600 - Penekanan</p>
    </div>
</body>
</html>
```

## Poin Penting
- Format: `text-{warna}-{shade}` atau `text-{warna}` untuk shade 500
- Hierarki tipografi: 900 (judul) > 700 (body) > 500 (sekunder) > 400 (placeholder)
- Warna cerah untuk link, error, sukses, dan penekanan
