# Memahami Opacity Modifier pada Warna di Tailwind

## Analogi: Perpustakaan Digital

Opacity modifier seperti kaca buram di perpustakaan. Kaca dengan opacity 50% masih tembus pandang, 30% lebih buram, 80% hampir transparan. Ini memungkinkan warna terlihat namun tidak terlalu pekat, seperti menambahkan efek transparansi pada cat tembok.

## Penjelasan Detail

Tailwind mendukung opacity modifier menggunakan format slash: `bg-blue-500/50` berarti background biru dengan opacity 50%. Nilai opacity: /0 (0%), /5 (5%), /10, /20, /25, /30, /40, /50, /60, /70, /75, /80, /90, /95, /100 (100% - solid). Opacity modifier bisa digunakan pada semua utility warna: `text-red-600/75`, `border-green-400/50`, `bg-black/30`, dll. Fitur ini sangat berguna untuk overlay, efek transparansi, layer, dan variasi warna tanpa perlu mengubah shade. Sebelum Tailwind v3, opacity harus diatur dengan kelas terpisah seperti `bg-opacity-50`. Dengan modifier slash, lebih ringkas dan intuitif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Opacity Modifier</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full space-y-4">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Opacity Modifier</h1>
        <div class="space-y-3">
            <div class="h-16 bg-blue-500 rounded-xl flex items-center justify-center text-white font-bold">bg-blue-500 (100%)</div>
            <div class="h-16 bg-blue-500/75 rounded-xl flex items-center justify-center text-white font-bold">bg-blue-500/75 (75%)</div>
            <div class="h-16 bg-blue-500/50 rounded-xl flex items-center justify-center text-white font-bold">bg-blue-500/50 (50%)</div>
            <div class="h-16 bg-blue-500/25 rounded-xl flex items-center justify-center text-white font-bold">bg-blue-500/25 (25%)</div>
            <div class="relative h-16 rounded-xl overflow-hidden">
                <div class="absolute inset-0 bg-gradient-to-r from-purple-500 to-pink-500"></div>
                <div class="absolute inset-0 bg-black/40 flex items-center justify-center text-white font-bold">bg-black/40 overlay</div>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Format: `{utility}-{warna}/{opacity}` seperti bg-blue-500/50
- Nilai opacity: 0, 5, 10, 20, 25, 30, 40, 50, 60, 70, 75, 80, 90, 95, 100
- Berguna untuk overlay, efek layer, dan variasi warna instan
