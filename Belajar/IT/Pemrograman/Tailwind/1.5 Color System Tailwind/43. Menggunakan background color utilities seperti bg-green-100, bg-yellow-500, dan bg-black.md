# Menggunakan Background Color Utilities di Tailwind

## Analogi: Perpustakaan Digital

Background color seperti warna dinding dan lantai perpustakaan. Dinding putih bersih (bg-white) untuk ruang baca utama, dinding biru muda (bg-blue-100) untuk area anak-anak, lantai abu-abu (bg-gray-100) untuk area sirkulasi, dan dinding hitam (bg-black) untuk area multimedia. Setiap area punya suasana berbeda.

## Penjelasan Detail

Kelas background color menggunakan format `bg-{color}-{shade}`. Contoh: `bg-green-100` untuk background hijau sangat muda, `bg-yellow-500` untuk background kuning solid, `bg-black` untuk background hitam. Shade 50-200 sangat cocok untuk background section atau kartu karena lembut dan tidak mengganggu. Shade 300-500 untuk elemen interaktif seperti tombol atau badge. Shade 600-900 untuk header/footer gelap. `bg-transparent` untuk background transparan. `bg-current` untuk mewarisi warna dari text color. Background color bisa dikombinasikan dengan state variants seperti `hover:bg-blue-600` atau dark mode `dark:bg-gray-800`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Background Color</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-100 p-8 min-h-screen">
    <div class="max-w-2xl mx-auto space-y-4">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Background Color</h1>
        <div class="bg-white p-4 rounded-xl shadow-sm">bg-white - Kartu putih bersih</div>
        <div class="bg-blue-50 p-4 rounded-xl">bg-blue-50 - Background sangat muda</div>
        <div class="bg-blue-100 p-4 rounded-xl">bg-blue-100 - Background muda</div>
        <div class="bg-blue-500 text-white p-4 rounded-xl">bg-blue-500 - Tombol / aksi utama</div>
        <div class="bg-gray-900 text-white p-4 rounded-xl">bg-gray-900 - Footer / header gelap</div>
        <div class="bg-gradient-to-r from-purple-500 to-pink-500 text-white p-4 rounded-xl">bg-gradient - Background gradien</div>
    </div>
</body>
</html>
```

## Poin Penting
- Format: `bg-{warna}-{shade}`, shade 50-200 untuk background halus
- shade 300-500 untuk elemen interaktif, 600-900 untuk gelap
- Bisa dikombinasikan dengan state variants dan dark mode
