# Menggunakan Ring Color Utilities di Tailwind

## Analogi: Perpustakaan Digital

Ring color seperti lingkaran cahaya yang muncul di sekitar buku saat pengunjung mendekat. Saat buku dipilih (focus), lingkaran biru menyala di sekelilingnya. Ini membantu pengunjung tahu buku mana yang sedang menjadi perhatian, terutama saat navigasi menggunakan keyboard.

## Penjelasan Detail

Ring adalah utility Tailwind untuk membuat efek outline/focus ring di sekitar elemen. Format: `ring-{color}`, `ring-{width}`, `ring-offset-{color}`, `ring-offset-{width}`. Contoh: `ring-blue-500` dengan default ketebalan 3px. Ring sangat berguna untuk accessibility pada focus state: `focus:ring-2 focus:ring-blue-500 focus:ring-offset-2 focus:outline-none`. Ring berbeda dengan border karena ring ditempatkan di luar elemen menggunakan box-shadow, sehingga tidak mempengaruhi layout. Ring offset memberi jarak antara elemen dan ring. Warna ring biasanya menggunakan warna brand (blue-500) atau warna yang kontras dengan background.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ring Color</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full space-y-6">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Ring Utilities</h1>
        <div class="space-y-4">
            <div class="p-4 bg-white rounded-lg ring-2 ring-blue-500">ring-2 ring-blue-500 - Ring biru 2px</div>
            <div class="p-4 bg-white rounded-lg ring-4 ring-green-400">ring-4 ring-green-400 - Ring hijau 4px</div>
            <div class="p-4 bg-white rounded-lg ring-2 ring-purple-500 ring-offset-2 ring-offset-gray-50">ring-2 ring-purple-500 ring-offset-2 - Dengan offset</div>
            <input type="text" placeholder="Klik untuk focus ring" class="w-full px-4 py-3 bg-white border border-gray-300 rounded-lg focus:ring-2 focus:ring-blue-500 focus:ring-offset-2 focus:outline-none transition-all">
            <button class="w-full py-3 bg-blue-500 text-white rounded-lg focus:outline-none focus:ring-4 focus:ring-blue-300 transition-all">Tombol dengan focus ring</button>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Ring menggunakan box-shadow, tidak mempengaruhi layout elemen
- Sangat penting untuk accessibility focus state
- Ring offset memberi jarak antara elemen dan ring
