# Cara Menambah Warna Kustom ke Konfigurasi Tailwind

## Analogi: Perpustakaan Digital

Kadang perpustakaan perlu koleksi buku dengan warna sampul khusus yang tidak ada di katalog standar. Anda bisa memesan warna baru ke penerbit (menambah kustom warna di konfigurasi) atau menempelkan label warna sendiri langsung di buku (menggunakan arbitrary value).

## Penjelasan Detail

Ada tiga cara menambah warna kustom ke Tailwind. Pertama, menggunakan `theme.extend.colors` di `tailwind.config.js` untuk menambah warna baru tanpa menghapus default. Contoh: tambahkan `primary: '#3B82F6'` dan `secondary: '#8B5CF6'`. Kedua, timpa seluruh palet dengan `theme.colors` jika ingin menggunakan palet kustom sepenuhnya. Ketiga, gunakan arbitrary value langsung di HTML seperti `bg-[#123456]` atau `text-[oklch(0.5_0.2_240)]` tanpa konfigurasi. Pendekatan extend paling disarankan karena tetap mempertahankan palet Tailwind yang kaya sambil menambah warna brand. Nama warna bisa mengikuti pola brand seperti `brand-primary`, `brand-secondary`, dll.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Warna Kustom</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script>
        tailwind.config = {
            theme: {
                extend: {
                    colors: {
                        brand: {
                            50: '#eff6ff',
                            100: '#dbeafe',
                            200: '#bfdbfe',
                            300: '#93c5fd',
                            400: '#60a5fa',
                            500: '#3B82F6',
                            600: '#2563eb',
                            700: '#1d4ed8',
                            800: '#1e40af',
                            900: '#1e3a8a',
                            950: '#172554',
                        },
                        accent: '#F59E0B',
                    }
                }
            }
        }
    </script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8 space-y-4">
        <h1 class="text-2xl font-bold text-center" style="color: #3B82F6;">Warna Kustom</h1>
        <div class="bg-brand-100 text-brand-800 p-4 rounded-xl">bg-brand-100 / text-brand-800 - Warna brand extend</div>
        <div class="bg-brand-500 text-white p-4 rounded-xl">bg-brand-500 - Warna brand utama (#3B82F6)</div>
        <div class="bg-brand-900 text-white p-4 rounded-xl">bg-brand-900 - Warna brand gelap</div>
        <div class="bg-[#F59E0B] text-white p-4 rounded-xl">bg-accent / bg-[#F59E0B] - Warna aksen</div>
        <div class="bg-[#10B981] text-white p-4 rounded-xl">bg-[#10B981] - Arbitrary value tanpa konfigurasi</div>
    </div>
</body>
</html>
```

## Poin Penting
- Gunakan `theme.extend.colors` untuk menambah warna tanpa menghapus default
- Warna kustom bisa menggunakan pola brand seperti brand-50 hingga brand-950
- Arbitrary value `bg-[kode-warna]` untuk warna yang jarang dipakai tanpa konfigurasi
