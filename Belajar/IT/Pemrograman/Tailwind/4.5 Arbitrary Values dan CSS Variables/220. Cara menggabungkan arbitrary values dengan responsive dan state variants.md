# Cara menggabungkan arbitrary values dengan responsive dan state variants

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki rak dengan ukuran berbeda tergantung waktu — rak lebih lebar di pagi hari saat banyak pengunjung, dan lebih sempit di malam hari. Juga tergantung kondisi — rak "sedang dipinjam" akan berwarna merah, rak "tersedia" berwarna hijau. Menggabungkan arbitrary values dengan responsive dan state variants seperti memberi instruksi: "ukuran rak ini 347px saat layar lebar, 200px saat layar kecil, dan berwarna merah saat sedang dipinjam." Semua dalam satu class.

## Penjelasan Detail
Arbitrary values bisa dikombinasikan dengan variant responsive (`sm:`, `md:`, `lg:`, `xl:`, `2xl:`) dan state variants (`hover:`, `focus:`, `active:`, `disabled:`, dll). Formatnya: `lg:w-[347px]` atau `hover:bg-[#ff6b6b]`. Ini memungkinkan styling yang sangat spesifik tanpa perlu menulis CSS kustom. Kombinasi ini berguna untuk: desain responsif dengan ukuran presisi, interaksi hover dengan warna spesifik, dan transisi state dengan nilai kustom. Urutan penulisan: variant diletakkan di depan, diikuti utility class dengan arbitrary values. Contoh: `lg:hover:bg-[#4f46e5]`. Semua aturan variant Tailwind tetap berlaku — variant ditulis dari yang terkecil ke terbesar (mobile-first).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Arbitrary Values + Variants</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-4xl mx-auto space-y-8">
    <h1 class="text-3xl font-bold text-gray-800">Arbitrary Values + Variants</h1>

    <!-- Responsive + Arbitrary -->
    <section class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Responsive + Arbitrary Sizing</h2>
      <div class="w-[200px] md:w-[347px] lg:w-[500px] h-32 bg-gradient-to-r from-indigo-500 to-purple-600 rounded-lg flex items-center justify-center text-white font-bold transition-all">
        w-[200px] → md:w-[347px] → lg:w-[500px]
      </div>
      <p class="text-sm text-gray-500 mt-2">Ubah ukuran layar untuk melihat perubahan lebar</p>
    </section>

    <!-- State + Arbitrary -->
    <section class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">State Variants + Arbitrary Colors</h2>
      <div class="flex gap-4">
        <button class="bg-[#6366f1] hover:bg-[#4f46e5] active:bg-[#3730a3] text-white px-6 py-3 rounded-lg transition-colors">
          Hover → hover:bg-[#4f46e5]
        </button>
        <button class="bg-[#ec4899] hover:bg-[#db2777] active:bg-[#be185d] text-white px-6 py-3 rounded-lg transition-colors">
          Hover → hover:bg-[#db2777]
        </button>
      </div>
    </section>

    <!-- Combined responsive + state + arbitrary -->
    <section class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Kombinasi Lengkap</h2>
      <div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
        <div class="bg-[#f0fdf4] hover:bg-[#dcfce7] dark:bg-[#052e16] dark:hover:bg-[#14532d] p-6 rounded-xl border border-[#bbf7d0] dark:border-[#166534] transition-colors">
          <p class="font-semibold text-[#166534] dark:text-[#bbf7d0]">Kartu 1</p>
          <p class="text-sm text-[#15803d] dark:text-[#86efac]">Responsif + State + Dark + Arbitrary</p>
        </div>
        <div class="bg-[#fef2f2] hover:bg-[#fecaca] dark:bg-[#450a0a] dark:hover:bg-[#7f1d1d] p-6 rounded-xl border border-[#fecaca] dark:border-[#7f1d1d] transition-colors">
          <p class="font-semibold text-[#991b1b] dark:text-[#fca5a5]">Kartu 2</p>
          <p class="text-sm text-[#b91c1c] dark:text-[#fca5a5]">Semua warna menggunakan arbitrary values</p>
        </div>
        <div class="bg-[#fefce8] hover:bg-[#fef08a] dark:bg-[#422006] dark:hover:bg-[#713f12] p-6 rounded-xl border border-[#fde047] dark:border-[#a16207] transition-colors">
          <p class="font-semibold text-[#854d0e] dark:text-[#fde047]">Kartu 3</p>
          <p class="text-sm text-[#a16207] dark:text-[#fef08a]">Dengan dark mode variant juga</p>
        </div>
      </div>
    </section>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// Format: [variant]:[utility]-[nilai]
md:w-[347px]                // responsive + arbitrary width
lg:hover:bg-[#4f46e5]       // responsive + state + arbitrary color
dark:bg-[#1e293b]            // dark + arbitrary background
hover:shadow-[0_0_20px_#000] // state + arbitrary shadow
lg:dark:hover:text-[#fff]   // responsive + dark + state + arbitrary</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Gabungkan arbitrary values dengan variant responsive (`md:w-[347px]`) dan state (`hover:bg-[#ff6b6b]`)
- Urutan penulisan: variant diikuti utility dengan arbitrary value: `lg:hover:bg-[#4f46e5]`
- Kombinasi ini memungkinkan styling presisi tinggi tanpa CSS kustom
