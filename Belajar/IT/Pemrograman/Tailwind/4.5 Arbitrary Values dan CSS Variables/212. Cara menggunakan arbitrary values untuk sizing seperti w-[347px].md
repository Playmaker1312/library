# Cara menggunakan arbitrary values untuk sizing seperti w-[347px]

## Analogi: Perpustakaan Digital
Seperti rak buku yang biasanya memiliki ukuran standar (lebar 100, 200, 300), tetapi Anda menemukan buku setebal 347 halaman yang tidak pas di rak mana pun. Dengan arbitrary values untuk sizing, Anda bisa membuat rak dengan lebar persis 347px, tinggi 812px, atau ukuran spesifik lainnya. Tidak perlu mengubah seluruh sistem ukuran perpustakaan — cukup buat rak khusus untuk buku yang tidak biasa ini.

## Penjelasan Detail
Arbitrary values untuk sizing mencakup properti `w-` (width), `h-` (height), `min-w-`, `min-h-`, `max-w-`, `max-h-`, `inset-`, `top-`, `right-`, `bottom-`, `left-`, `basis-`, dan `size-`. Format penulisan: `w-[nilai]` misalnya `w-[347px]`, `h-[50vh]`, `max-w-[800px]`. Anda bisa menggunakan unit CSS apapun: px, rem, em, vh, vw, %, ch, atau bahkan fungsi CSS seperti `calc()`. Contoh: `w-[calc(100%-2rem)]`, `h-[100dvh]`. Arbitrary values sangat berguna saat mendesain layout yang membutuhkan ukuran spesifik dari desain Figma atau saat menangani kasus tepi (edge case) yang tidak tercakup oleh spacing scale default.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Arbitrary Values Sizing</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-4xl mx-auto space-y-8">
    <h1 class="text-3xl font-bold text-gray-800">Sizing dengan Arbitrary Values</h1>

    <!-- Width examples -->
    <section class="bg-white p-6 rounded-xl shadow space-y-4">
      <h2 class="font-semibold text-gray-700">Width Kustom</h2>
      <div class="w-[200px] bg-indigo-500 text-white px-4 py-2 rounded">w-[200px]</div>
      <div class="w-[347px] bg-indigo-500 text-white px-4 py-2 rounded">w-[347px]</div>
      <div class="w-[50%] bg-indigo-500 text-white px-4 py-2 rounded">w-[50%]</div>
      <div class="w-[calc(100%-100px)] bg-indigo-500 text-white px-4 py-2 rounded">w-[calc(100%-100px)]</div>
    </section>

    <!-- Height examples -->
    <section class="bg-white p-6 rounded-xl shadow space-y-4">
      <h2 class="font-semibold text-gray-700">Height Kustom</h2>
      <div class="flex gap-4 items-end">
        <div class="h-[100px] bg-emerald-500 text-white px-4 py-2 rounded">h-[100px]</div>
        <div class="h-[150px] bg-emerald-500 text-white px-4 py-2 rounded">h-[150px]</div>
        <div class="h-[200px] bg-emerald-500 text-white px-4 py-2 rounded">h-[200px]</div>
        <div class="h-[50vh] bg-emerald-500 text-white px-4 py-2 rounded">h-[50vh]</div>
      </div>
    </section>

    <!-- Max-width -->
    <section class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-3">Max-Width Kustom</h2>
      <div class="max-w-[400px] bg-amber-500 text-white px-4 py-2 rounded mx-auto text-center truncate">
        max-w-[400px] — teks ini akan terpotong jika melebihi 400px
      </div>
    </section>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// Unit CSS yang bisa digunakan:
w-[347px]           // pixel
h-[50vh]            // viewport height
max-w-[800px]       // max-width
w-[calc(100%-2rem)] // fungsi calc()
h-[100dvb]          // dynamic viewport height
w-[33.333%]         // persentase
min-h-[screen]      // min-height screen
max-h-[500px]       // max-height</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Arbitrary values untuk sizing mendukung unit CSS apapun: px, rem, vh, vw, %, calc(), dll
- Gunakan `w-[nilai]`, `h-[nilai]`, `max-w-[nilai]`, `min-h-[nilai]` untuk ukuran spesifik
- Sangat berguna untuk mengimplementasikan desain pixel-perfect dari Figma tanpa mengubah konfigurasi
