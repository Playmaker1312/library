# Cara menggunakan CSS variables sebagai arbitrary values

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki papan pengumuman utama yang berisi informasi penting: "Jam Buka: 08.00", "Denda Keterlambatan: Rp1000/hari", "Ruangan: Lantai 2". Papan ini seperti CSS variables — nilai-nilai yang disimpan di satu tempat dan bisa dirujuk dari mana saja. Ketika Anda ingin mengubah jam buka, cukup ubah di papan pengumuman, semua rak dan jadwal yang merujuk akan otomatis berubah. CSS variables sebagai arbitrary values memungkinkan Anda merujuk nilai dari papan pengumuman ini langsung di class Tailwind.

## Penjelasan Detail
CSS variables (custom properties) bisa digunakan sebagai arbitrary values di Tailwind dengan sintaks `var(--nama-variable)`. Contoh: `bg-[var(--color-primary)]`, `text-[var(--color-text)]`, `w-[var(--sidebar-width)]`. CSS variables didefinisikan di selector `:root` atau elemen tertentu dan bisa diubah secara dinamis via JavaScript. Keuntungan menggunakan CSS variables: (1) Nilai bisa diubah runtime via JavaScript, (2) Mendukung theming yang fleksibel, (3) Nilai bisa diwariskan ke child elements, (4) Mengurangi duplikasi nilai. CSS variables sangat berguna untuk theming dinamis, responsive design, dan interaksi yang membutuhkan perubahan nilai CSS secara real-time.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>CSS Variables di Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <style>
    :root {
      --color-primary: #6366f1;
      --color-secondary: #ec4899;
      --color-accent: #14b8a6;
      --sidebar-width: 280px;
      --card-radius: 16px;
      --spacing-section: 2rem;
    }
  </style>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-4xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">CSS Variables sebagai Arbitrary Values</h1>

    <div class="flex gap-4">
      <button class="bg-[var(--color-primary)] text-white px-6 py-3 rounded-[var(--card-radius)] hover:opacity-90 transition">Primary Variable</button>
      <button class="bg-[var(--color-secondary)] text-white px-6 py-3 rounded-[var(--card-radius)] hover:opacity-90 transition">Secondary Variable</button>
      <button class="bg-[var(--color-accent)] text-white px-6 py-3 rounded-[var(--card-radius)] hover:opacity-90 transition">Accent Variable</button>
    </div>

    <div style="width: var(--sidebar-width)" class="bg-white p-6 rounded-xl shadow border border-gray-200">
      <h2 class="font-semibold text-gray-800">Sidebar dengan Variable Width</h2>
      <p class="text-gray-600 text-sm mt-2">Lebar elemen ini diatur oleh <code>--sidebar-width: 280px</code>. Ubah variable di CSS dan semua elemen yang merujuk akan berubah.</p>
    </div>

    <div class="grid grid-cols-2 gap-6">
      <div class="bg-white p-6 rounded-xl shadow border border-gray-200" style="border-radius: var(--card-radius);">
        <p class="text-gray-700">Border-radius menggunakan <code>var(--card-radius)</code> via <code>style</code> attribute.</p>
      </div>
      <div class="bg-white p-6 rounded-[var(--card-radius)] shadow border border-gray-200">
        <p class="text-gray-700">Border-radius menggunakan <code>rounded-[var(--card-radius)]</code> — arbitrary value Tailwind.</p>
      </div>
    </div>

    <!-- Dynamic variable demo -->
    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-800 mb-3">CSS Variables Dinamis via JavaScript</h2>
      <div class="flex gap-3 mb-4">
        <button onclick="changePrimary('#ef4444')" class="bg-red-500 text-white px-3 py-1 rounded text-sm">Merah</button>
        <button onclick="changePrimary('#3b82f6')" class="bg-blue-500 text-white px-3 py-1 rounded text-sm">Biru</button>
        <button onclick="changePrimary('#10b981')" class="bg-emerald-500 text-white px-3 py-1 rounded text-sm">Hijau</button>
      </div>
      <div class="bg-[var(--color-primary)] text-white p-4 rounded-lg text-center font-semibold">
        Warna ini berubah saat tombol di klik
      </div>
    </div>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// CSS Variables
:root {
  --color-primary: #6366f1;
  --sidebar-width: 280px;
  --card-radius: 16px;
}

// Di Tailwind
bg-[var(--color-primary)]
w-[var(--sidebar-width)]
rounded-[var(--card-radius)]

// Ubah via JavaScript
document.documentElement.style.setProperty('--color-primary', '#ef4444');</pre>
  </div>

  <script>
    function changePrimary(color) {
      document.documentElement.style.setProperty('--color-primary', color);
    }
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan `var(--nama-variable)` di dalam arbitrary values untuk merujuk CSS variables
- CSS variables memungkinkan perubahan nilai secara dinamis via JavaScript tanpa rebuild
- Sangat berguna untuk theming, responsive design, dan nilai yang perlu diubah runtime
