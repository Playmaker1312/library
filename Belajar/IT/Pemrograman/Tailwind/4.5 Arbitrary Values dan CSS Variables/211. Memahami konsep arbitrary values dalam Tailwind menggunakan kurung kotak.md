# Memahami konsep arbitrary values dalam Tailwind menggunakan kurung kotak

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki rak standar dengan ukuran tetap (small, medium, large). Tapi terkadang ada buku dengan ukuran tidak biasa yang tidak muat di rak standar. Arbitrary values seperti rak khusus yang bisa diatur ukurannya secara bebas — Anda bisa membuat rak dengan lebar 347px, tinggi 812px, atau warna latar #1a2b3c, meskipun ukuran tersebut tidak ada dalam sistem standar perpustakaan.

## Penjelasan Detail
Arbitrary values memungkinkan Anda menggunakan nilai CSS apapun langsung di class Tailwind dengan sintaks kurung siku `[nilai]`. Ini adalah "escape hatch" ketika utility class standar tidak menyediakan nilai yang Anda butuhkan. Contoh: `w-[347px]` untuk lebar 347px, `text-[#1a2b3c]` untuk warna teks tertentu, `p-[13px]` untuk padding 13px. Tailwind akan menerjemahkan nilai di dalam kurung siku menjadi CSS langsung. Arbitrary values bisa digunakan untuk hampir semua utility class yang ada. Fitur ini sangat berguna untuk desain pixel-perfect, mengintegrasikan dengan desain dari Figma, atau saat prototyping cepat tanpa perlu mengubah konfigurasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Arbitrary Values</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Arbitrary Values [ ]</h1>
    
    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold mb-4">Sizing: w-[347px] h-[200px]</h2>
      <div class="w-[347px] h-[200px] bg-gradient-to-br from-indigo-500 to-purple-600 rounded-lg flex items-center justify-center text-white font-bold">
        347px × 200px
      </div>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold mb-4">Warna: text-[#ff6b6b] bg-[#ffd93d]</h2>
      <div class="flex gap-4">
        <span class="text-[#ff6b6b] bg-[#ffe0e0] px-4 py-2 rounded font-bold">text-[#ff6b6b]</span>
        <span class="text-[#6c5ce7] bg-[#e8e3ff] px-4 py-2 rounded font-bold">text-[#6c5ce7]</span>
        <span class="text-white bg-[#00b894] px-4 py-2 rounded font-bold">bg-[#00b894]</span>
      </div>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold mb-4">Spacing & Border: p-[13px] rounded-[20px]</h2>
      <div class="p-[13px] rounded-[20px] border-[3px] border-indigo-400 bg-indigo-50 text-indigo-700">
        padding 13px, border-radius 20px, border 3px
      </div>
    </div>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// Sintaks: [nilai] langsung di dalam class
w-[347px]       // width: 347px
text-[#1a2b3c]  // color: #1a2b3c
p-[13px]        // padding: 13px
rounded-[20px]  // border-radius: 20px
gap-[8px]       // gap: 8px
text-[2.5rem]   // font-size: 2.5rem</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan kurung siku `[nilai]` untuk nilai CSS apapun yang tidak ada di utility class standar
- Arbitrary values bekerja untuk sizing, warna, spacing, border, font, dan hampir semua utility
- Fitur ini ideal untuk desain pixel-perfect dari Figma tanpa perlu mengubah konfigurasi
