# Cara menggunakan arbitrary variants untuk selector yang tidak ada variantnya

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki aturan standar untuk rak buku: "buku di rak atas", "buku di rak bawah", "buku di dekat jendela". Tapi suatu hari Anda ingin aturan baru: "buku yang pernah dipinjam lebih dari 5 kali" atau "buku yang sampulnya berwarna merah". Aturan ini tidak tercakup oleh variant standar. Arbitrary variants seperti membuat filter khusus — Anda bisa menargetkan elemen berdasarkan kondisi CSS apapun, bahkan yang tidak ada variant bawaannya.

## Penjelasan Detail
Arbitrary variants memungkinkan Anda membuat variant kustom langsung di class HTML tanpa perlu plugin. Sintaksnya: `[selector]:utility`. Contoh: `[@media(print)]:text-black` untuk gaya saat dicetak, `[&:nth-child(odd)]:bg-gray-100` untuk baris ganjil, `[&::first-letter]:text-4xl` untuk huruf pertama. Anda bisa menggunakan pseudo-class apapun (`:hover`, `:focus`, `:checked`), pseudo-element (`::before`, `::after`, `::first-letter`), media query (`@media`), at-rule (`@supports`), atau selector CSS kustom (`& > *`, `& + &`). Arbitrary variants sangat berguna untuk kasus styling yang tidak tercakup oleh variant bawaan Tailwind. Gunakan `&` untuk merujuk elemen yang sedang ditargetkan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Arbitrary Variants</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Arbitrary Variants</h1>

    <!-- Pseudo-class -->
    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold mb-3">Pseudo-class: [&:nth-child(odd)]</h2>
      <div class="space-y-1">
        <div class="[&:nth-child(odd)]:bg-indigo-100 [&:nth-child(even)]:bg-white p-3 rounded">Item 1 (odd)</div>
        <div class="[&:nth-child(odd)]:bg-indigo-100 [&:nth-child(even)]:bg-white p-3 rounded">Item 2 (even)</div>
        <div class="[&:nth-child(odd)]:bg-indigo-100 [&:nth-child(even)]:bg-white p-3 rounded">Item 3 (odd)</div>
        <div class="[&:nth-child(odd)]:bg-indigo-100 [&:nth-child(even)]:bg-white p-3 rounded">Item 4 (even)</div>
      </div>
    </div>

    <!-- Pseudo-element -->
    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold mb-3">Pseudo-element: [&::first-letter] & [&::first-line]</h2>
      <p class="[&::first-letter]:text-4xl [&::first-letter]:font-bold [&::first-letter]:text-indigo-600 [&::first-letter]:float-left [&::first-letter]:mr-2 [&::first-line]:font-semibold text-gray-700">
        Ini adalah contoh paragraf dengan huruf pertama yang diperbesar (drop cap). Baris pertama juga dibuat tebal menggunakan arbitrary variants. Variant ini memungkinkan styling elemen yang tidak tercakup oleh variant bawaan Tailwind.
      </p>
    </div>

    <!-- Media query -->
    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold mb-3">Media Query: [@media(print)] & [@media(prefers-reduced-motion)]</h2>
      <div class="[@media(prefers-reduced-motion)]:bg-amber-100 [@media(prefers-reduced-motion)]:border-amber-300 bg-gray-100 border border-gray-200 p-4 rounded-lg transition-all">
        <p class="text-gray-700">Elemen ini akan berubah warna jika pengguna mengaktifkan "reduce motion" di OS.</p>
      </div>
    </div>

    <!-- Selector combinators -->
    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold mb-3">Selector: [&>p] — children selector</h2>
      <div class="[&>p]:text-indigo-600 [&>p]:font-semibold space-y-2">
        <p>Paragraf anak langsung — kena gaya</p>
        <div>
          <p>Paragraf di dalam div — tidak kena gaya (bukan anak langsung)</p>
        </div>
        <p>Paragraf anak langsung lainnya — kena gaya</p>
      </div>
    </div>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// Format: [selector]:utility
[&:nth-child(odd)]:bg-gray-100        // nth-child
[&::first-letter]:text-4xl            // first-letter
[&::placeholder]:text-gray-400        // placeholder
[@media(print)]:hidden                // media query
[@supports(display:grid)]:grid        // @supports
[&>p]:text-red-500                   // child selector
[&:focus-within]:ring-2              // focus-within
[&:not(:last-child)]:border-b        // not selector</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Arbitrary variants menggunakan format `[selector]:utility` untuk selector CSS yang tidak ada variantnya
- Mendukung pseudo-class, pseudo-element, media query, @supports, dan selector combinator
- Gunakan `&` untuk merujuk elemen yang sedang ditargetkan dalam selector
