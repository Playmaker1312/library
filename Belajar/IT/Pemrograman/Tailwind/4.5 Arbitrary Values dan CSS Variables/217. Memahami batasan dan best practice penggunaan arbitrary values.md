# Memahami batasan dan best practice penggunaan arbitrary values

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang menggunakan rak kustom untuk setiap buku yang tidak biasa. Pada awalnya ini praktis, tetapi lama-kelamaan rak kustom memenuhi gudang dan sulit diatur. Tidak ada standarisasi, sulit mencari buku, dan perpustakaan terlihat berantakan. Arbitrary values seperti rak kustom — sangat berguna untuk kasus tertentu, tetapi jika digunakan berlebihan akan menghilangkan konsistensi dan manfaat utama Tailwind.

## Penjelasan Detail
Arbitrary values memiliki beberapa batasan. Pertama, nilai di dalam kurung siku tidak bisa menggunakan spasi tanpa underscore, misalnya `shadow-[0_0_10px_#000]`. Kedua, tidak bisa digunakan dengan variant `group-*` atau `peer-*` secara langsung di semua kasus. Ketiga, tidak mendukung properti shorthand CSS tertentu. Keempat, arbitrary values tidak dideteksi oleh fitur IntelliSense/LSP secara optimal. Best practice: (1) Prioritaskan utility class standar — hanya gunakan arbitrary values jika benar-benar diperlukan, (2) Jika nilai yang sama muncul berulang kali, pertimbangkan untuk memperluas konfigurasi theme, (3) Gunakan CSS variables untuk nilai yang digunakan di banyak tempat, (4) Batasi penggunaan arbitrary values untuk prototyping atau edge case, (5) Dokumentasikan arbitrary values yang digunakan dalam codebase.

```html
  <div class="max-w-3xl mx-auto space-y-6">

    <div class="bg-green-50 border border-green-200 p-6 rounded-xl">
      <h2 class="font-semibold text-green-800 mb-3">✅ Best Practice</h2>
      <ul class="space-y-2 text-green-700 text-sm">
        <li>✅ Prioritaskan utility standar: <code>p-4</code> bukan <code>p-[16px]</code></li>
        <li>✅ Gunakan extend di config untuk nilai yang sering dipakai: <code>spacing: { 18: '4.5rem' }</code></li>
        <li>✅ Gunakan CSS variables untuk nilai yang berubah dinamis</li>
        <li>✅ Batasi arbitrary values untuk prototyping dan edge case</li>
      </ul>
    </div>

    <!-- Bad practices -->
    <div class="bg-red-50 border border-red-200 p-6 rounded-xl">
      <h2 class="font-semibold text-red-800 mb-3">❌ Hindari</h2>
      <ul class="space-y-2 text-red-700 text-sm">
        <li>❌ Jangan gunakan untuk nilai yang sudah ada utility-nya: <code>p-[1rem]</code> lebih baik <code>p-4</code></li>
        <li>❌ Jangan gunakan berulang kali untuk nilai yang sama — buat config atau variable</li>
        <li>❌ Jangan gunakan untuk nilai yang kompleks dengan spasi — gunakan CSS variables</li>
        <li>❌ Jangan abaikan IntelliSense — arbitrary values tidak memiliki autocomplete</li>
      </ul>
    </div>

          <pre class="text-xs text-amber-900">// Berulang kali

// Atau CSS variable
&lt;div class="p-4.5 m-2"&gt;

&lt;div class="p-4.5 m-2"&gt;</pre>

// 2. Ekstrak ke config jika muncul &gt; 3 kali
// 3. Gunakan CSS variables untuk nilai dinamis

  </div>
</body>
</html>
```

## Poin Penting
- Prioritaskan utility class standar — arbitrary values untuk edge case dan prototyping saja
- Ekstrak nilai yang sering muncul ke konfigurasi theme atau CSS variables
- Waspadai batasan teknis seperti spasi (gunakan underscore) dan kompatibilitas variant
