# Cara menggunakan arbitrary values untuk properti yang belum ada utilitynya

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki sistem katalog standar untuk buku, majalah, dan DVD. Suatu hari, perpustakaan menerima koleksi baru — piringan hitam, kaset, dan CD-ROM — yang tidak memiliki rak khusus. Arbitrary values untuk properti baru seperti membuat rak darurat untuk koleksi baru ini. Anda bisa mengatur properti CSS apapun meskipun Tailwind tidak memiliki utility class khusus untuknya.

## Penjelasan Detail
Arbitrary values bisa digunakan untuk properti CSS yang tidak memiliki utility class di Tailwind. Sintaksnya adalah `[properti: nilai]`, misalnya `[scrollbar-width:thin]` atau `[object-fit:cover]`. Ini berbeda dengan arbitrary values biasa yang menggunakan format `properti-[nilai]` — untuk properti yang tidak ada utility-nya, Anda harus menulis nama properti lengkap diikuti titik dua dan nilai di dalam kurung siku. Contoh: `[perspective:1000px]`, `[backdrop-filter:blur(4px)]`, `[transform-style:preserve-3d]`. Fitur ini sangat berguna untuk properti CSS modern atau properti spesifik browser yang belum diadopsi oleh Tailwind. Namun, gunakan dengan bijak — jika suatu properti sering digunakan, pertimbangkan untuk membuat plugin atau memperluas konfigurasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Arbitrary Properti Baru</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Properti Tanpa Utility</h1>

    <div class="bg-white p-6 rounded-xl shadow space-y-6">
      <h2 class="font-semibold text-gray-700">CSS Columns</h2>
      <div class="[column-count:3] [column-gap:1rem] text-sm text-gray-700">
        <p>Tailwind CSS adalah framework utility-first. Dengan pendekatan ini, Anda bisa membangun antarmuka dengan cepat. Setiap utility class mewakili satu properti CSS.</p>
        <p>Arbitrary values memungkinkan Anda menggunakan properti CSS yang belum ada utilitynya. Ini memberikan fleksibilitas tanpa batas.</p>
        <p>Cukup gunakan format [properti:nilai] untuk properti apapun. Kreativitas Anda adalah batasnya.</p>
      </div>
    </div>

    <div class="bg-white p-6 rounded-xl shadow space-y-4">
      <h2 class="font-semibold text-gray-700">Perspektif 3D</h2>
      <div class="[perspective:1000px] flex gap-4">
        <div class="[transform:rotateY(10deg)] bg-indigo-500 text-white p-4 rounded-lg">rotateY(10deg)</div>
        <div class="[transform:rotateY(20deg)] bg-indigo-600 text-white p-4 rounded-lg">rotateY(20deg)</div>
        <div class="[transform:rotateY(30deg)] bg-indigo-700 text-white p-4 rounded-lg">rotateY(30deg)</div>
      </div>
    </div>

    <div class="bg-white p-6 rounded-xl shadow space-y-4">
      <h2 class="font-semibold text-gray-700">Properti Lainnya</h2>
      <div class="space-y-2">
        <div class="[scrollbar-width:thin] [scrollbar-color:#6366f1_#e0e7ff] overflow-x-auto p-2 bg-gray-100 rounded">
          <div class="w-[600px] text-sm text-gray-600">scrollbar-width:thin — scrollbar custom dengan warna indigo (Firefox)</div>
        </div>
        <div class="[text-wrap:balance] text-lg font-semibold text-gray-800">text-wrap:balance — Teks ini akan di-wrap secara seimbang agar rata kanan-kiri lebih merata.</div>
        <div class="[font-variant-numeric:tabular-nums] text-gray-700">tabular-nums: 1234567890 — Angka dengan lebar yang seragam.</div>
      </div>
    </div>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// Format: [properti: nilai]
[column-count:3]           // CSS columns
[perspective:1000px]       // 3D perspective
[transform:rotateY(20deg)] // Transform kustom
[scrollbar-width:thin]     // Scrollbar Firefox
[text-wrap:balance]        // Text wrapping
[object-fit:cover]         // Object fit
[accent-color:red]         // Accent color
[content-visibility:auto]  // Content visibility</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan format `[properti:nilai]` untuk properti CSS yang tidak memiliki utility class Tailwind
- Fitur ini mendukung properti CSS modern, vendor-specific, dan eksperimental
- Jika suatu properti sering digunakan, pertimbangkan membuat plugin atau menambahkannya ke konfigurasi
