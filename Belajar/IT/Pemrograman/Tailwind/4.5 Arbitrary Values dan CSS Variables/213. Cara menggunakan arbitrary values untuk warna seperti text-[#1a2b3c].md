# Cara menggunakan arbitrary values untuk warna seperti text-[#1a2b3c]

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki palet warna standar untuk sampul buku (biru, merah, hijau). Tapi tiba-tiba Anda menerima buku dengan sampul warna "tosca pastel #4ECDC4" atau "coral #FF6B6B" yang tidak ada dalam palet. Arbitrary values untuk warna seperti membeli cat khusus di toko — Anda bisa mencampur warna apapun yang diinginkan, tidak terbatas pada palet standar perpustakaan.

## Penjelasan Detail
Arbitrary values untuk warna memungkinkan Anda menggunakan nilai warna CSS apapun langsung di class Tailwind. Format: `text-[#1a2b3c]`, `bg-[#ff6b6b]`, `border-[rgba(0,0,0,0.5)]`, `shadow-[0_0_10px_#6366f1]`. Nilai warna bisa berupa hex (`#ff0000`), RGB (`rgb(255,0,0)`), RGBA (`rgba(255,0,0,0.5)`), HSL (`hsl(0,100%,50%)`), atau nama warna CSS (`red`). Arbitrary values untuk warna mendukung semua properti yang berhubungan dengan warna termasuk `text-`, `bg-`, `border-`, `ring-`, `shadow-`, `outline-`, `accent-`, `caret-`, `placeholder-`, `divide-`, `from-`, `via-`, `to-`, dan `decoration-`. Fitur ini sangat berguna ketika mengintegrasikan desain yang memiliki warna spesifik dari brand.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Arbitrary Values Warna</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Arbitrary Values untuk Warna</h1>

    <!-- Text colors -->
    <div class="bg-white p-6 rounded-xl shadow space-y-3">
      <h2 class="font-semibold text-gray-700">Warna Teks</h2>
      <p class="text-[#FF6B6B] font-bold">text-[#FF6B6B] — Coral Red</p>
      <p class="text-[#4ECDC4] font-bold">text-[#4ECDC4] — Turquoise</p>
      <p class="text-[#FFE66D] font-bold bg-gray-800 px-2">text-[#FFE66D] — Yellow</p>
      <p class="text-[rgba(99,102,241,0.8)] font-bold">text-[rgba(99,102,241,0.8)] — Semi-transparent indigo</p>
    </div>

    <!-- Background colors -->
    <div class="p-6 rounded-xl shadow space-y-3" style="background: #f0f0f0;">
      <h2 class="font-semibold text-gray-700">Warna Background</h2>
      <div class="flex gap-3">
        <div class="bg-[#FF6B6B] text-white px-4 py-2 rounded">bg-[#FF6B6B]</div>
        <div class="bg-[#4ECDC4] text-white px-4 py-2 rounded">bg-[#4ECDC4]</div>
        <div class="bg-[#292F36] text-white px-4 py-2 rounded">bg-[#292F36]</div>
        <div class="bg-[hsl(260,80%,60%)] text-white px-4 py-2 rounded">bg-[hsl(260,80%,60%)]</div>
      </div>
    </div>

    <!-- Border & other -->
    <div class="bg-white p-6 rounded-xl shadow space-y-3">
      <h2 class="font-semibold text-gray-700">Border, Ring, dan Gradient</h2>
      <div class="border-[3px] border-[#FF6B6B] bg-[#FFF0F0] p-4 rounded-lg">border-[#FF6B6B]</div>
      <div class="ring-4 ring-[#4ECDC4] p-4 rounded-lg mt-3">ring-[#4ECDC4]</div>
      <div class="bg-gradient-to-r from-[#FF6B6B] via-[#4ECDC4] to-[#292F36] text-white p-4 rounded-lg mt-3 text-center">
        from-[#FF6B6B] via-[#4ECDC4] to-[#292F36]
      </div>
    </div>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// Format warna yang didukung:
text-[#ff6b6b]           // Hex
bg-[rgb(255,107,107)]    // RGB
border-[rgba(0,0,0,0.5)] // RGBA
from-[hsl(0,80%,60%)]    // HSL
via-[red]                // Nama warna CSS
shadow-[0_0_15px_#6366f1] // Shadow dengan warna</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Arbitrary values untuk warna mendukung format Hex, RGB, RGBA, HSL, dan nama warna CSS
- Berlaku untuk semua properti warna: `text-`, `bg-`, `border-`, `ring-`, `shadow-`, gradient, dll
- Sangat berguna untuk mengintegrasikan warna brand spesifik tanpa perlu memperluas palet di konfigurasi
