# Cara mengukur dan memantau ukuran bundle CSS Tailwind

## Analogi: Perpustakaan Digital
Mengukur bundle CSS Tailwind seperti memeriksa berat buku sebelum dimasukkan ke rak perpustakaan digital. Buku yang terlalu tebal akan memenuhi rak dan memperlambat pengunjung yang ingin mengambilnya. Tailwind dirancang ringan dengan purging, tetapi perlu dipantau agar tetap optimal.

## Penjelasan Detail
Ukuran bundle CSS Tailwind sangat bergantung pada konfigurasi `purge`/`content` dan utility classes yang benar-benar digunakan di project. Tailwind CSS versi 3+ menggunakan JIT (Just-In-Time) engine yang hanya menghasilkan CSS untuk kelas yang terdeteksi di file template. Tools untuk mengukur ukuran CSS: **`purgecss`**, **`source-map-explorer`**, **`webpack-bundle-analyzer`** (jika menggunakan webpack), dan **`css-minimizer-webpack-plugin`** untuk minifikasi. Ukuran bundle tipikal Tailwind setelah purging: 10-30 KB (gzipped) untuk project kecil, 50-100 KB untuk project besar dengan banyak kustomisasi. Faktor yang memperbesar bundle: terlalu banyak color shades kustom, plugin tambahan, dan utility classes yang tidak digunakan. Gunakan `@layer` directives untuk mengorganisir CSS kustom. Monitor ukuran di CI dengan tools seperti `bundlesize` atau `size-limit`. Perbandingan ukuran antar rilis membantu mendeteksi pembengkakan.

## Contoh Kode Implementasi

```bash
# Mengukur ukuran CSS dengan size-limit
npx size-limit

# size-limit configuration di package.json
# "size-limit": [{ "path": "dist/output.css", "limit": "30 KB" }]
```

```javascript
// Analisis bundle CSS di postcss.config.js
module.exports = {
    plugins: {
        tailwindcss: {},
        autoprefixer: {},
        ...(process.env.NODE_ENV === 'production'
            ? { cssnano: { preset: 'default' } }
            : {}),
    },
}
```

```html
<!-- Gunakan only: variant untuk conditional classes -->
<div class="only:block">Only child</div>

<!-- Hindari dynamic classes yang tidak terdeteksi purge -->
<!-- ❌ Buruk: class={`text-${color}-500`} -->
<!-- ✅ Baik: class={color === 'red' ? 'text-red-500' : 'text-blue-500'} -->
```

## Poin Penting
- JIT engine Tailwind hanya menghasilkan CSS untuk kelas yang terdeteksi di template
- Ukuran bundle tipikal setelah purging: 10-30 KB gzipped untuk project kecil
- Monitor ukuran CSS di CI dengan tools seperti size-limit atau bundlesize
- Hindari kelas dinamis yang tidak terdeteksi purge agar bundle tetap optimal
