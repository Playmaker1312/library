# Cara mendokumentasikan komponen dan pola desain dalam project Tailwind

## Analogi: Perpustakaan Digital
Dokumentasi komponen Tailwind seperti katalog perpustakaan digital yang mencatat setiap buku—judul, penulis, sinopsis, dan lokasi rak. Dokumentasi yang baik memudahkan anggota tim menemukan, memahami, dan menggunakan komponen dengan benar. Ini mencegah duplikasi dan inkonsistensi.

## Penjelasan Detail
Dokumentasi komponen Tailwind dapat dilakukan dengan beberapa tools: **Storybook** (standar industri), **Histoire** (untuk Vue), atau dokumentasi markdown sederhana. Setiap komponen didokumentasikan dengan: nama, deskripsi, props/API, contoh kode, varian (size, color, state), dan preview visual. Storybook terintegrasi baik dengan Tailwind karena komponen menggunakan utility classes yang langsung terlihat di preview. Dokumentasi juga mencakup **design guidelines** (kapan menggunakan komponen tertentu), **accessibility notes**, dan **changelog**. Pattern library dapat di-generate secara otomatis dari komponen yang ada. Untuk tim kecil, dokumentasi di README atau folder `docs/` dengan contoh HTML sudah cukup. Konsistensi dokumentasi dijaga dengan template dan code review. Integrasi dengan Chromatic untuk visual regression melengkapi dokumentasi dengan snapshot otomatis.

## Contoh Kode Implementasi

```javascript
// Storybook example untuk komponen Tailwind Button
export default {
    title: 'Components/Button',
    component: Button,
    argTypes: {
        variant: { control: 'select', options: ['primary', 'secondary', 'ghost'] },
        size: { control: 'select', options: ['sm', 'md', 'lg'] },
    },
}

export const Primary = {
    args: { variant: 'primary', size: 'md', children: 'Click Me' },
}

export const Secondary = {
    args: { variant: 'secondary', size: 'md', children: 'Cancel' },
}
```

```markdown
# Button Component

## Usage
Button komponen untuk aksi utama dan sekunder.

## Variants
| Variant    | Classes                                  | Use Case           |
|------------|------------------------------------------|--------------------|
| Primary    | `bg-indigo-600 text-white hover:bg-...`  | Aksi utama         |
| Secondary  | `border border-gray-300 text-gray-700`   | Aksi alternatif    |
| Ghost      | `text-gray-500 hover:bg-gray-100`        | Aksi minimal       |

## Example
```html
<button class="bg-indigo-600 hover:bg-indigo-500 text-white px-4 py-2 rounded-lg font-medium transition">
    Primary Button
</button>
```

## Accessibility
- Gunakan `aria-label` jika tombol hanya berisi icon
- Pastikan focus ring terlihat dengan `focus-visible:ring-2`
```
