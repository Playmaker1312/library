# Cara memastikan tidak ada class Tailwind yang hilang di production build

## Analogi: Perpustakaan Digital
Memastikan kelas Tailwind tidak hilang di production seperti memverifikasi bahwa semua halaman buku tercetak dengan sempurna tanpa ada yang terpotong. Sistem purging Tailwind sangat efektif, tetapi bisa salah memotong kelas yang digunakan secara dinamis. Anda perlu memastikan semua konten terdeteksi.

## Penjelasan Detail
Tailwind JIT engine mendeteksi kelas yang digunakan dengan mencari string yang cocok dengan pola kelas di file template. Masalah terjadi ketika kelas dibangun secara dinamis (concatenation) atau dihasilkan oleh JavaScript runtime. Solusi: gunakan **safelist** di `tailwind.config.js` untuk kelas yang digunakan secara dinamis, atau tulis kelas secara lengkap di template. Contoh pattern aman: gunakan object mapping daripada string concatenation, misal `{ primary: 'bg-blue-500', danger: 'bg-red-500' }[variant]`. Fitur `safelist` dapat menerima array string, regex, atau pattern. Untuk project besar, gunakan script untuk memindai source code dan mengidentifikasi kelas dinamis yang mungkin terlewat. Tools seperti `tailwindcss-jit-cleanup` membantu analisis. Testing E2E dapat memvalidasi tampilan visual semua state komponen. Perhatikan kelas yang digunakan di server-side rendering atau CMS yang menyimpan kelas di database.

## Contoh Kode Implementasi

```javascript
// tailwind.config.js - Safelist pattern
module.exports = {
    content: ['./src/**/*.{html,js,jsx,ts,tsx}'],
    safelist: [
        'bg-red-500',
        'bg-blue-500',
        'bg-green-500',
        { pattern: /^text-(red|blue|green)-(500|600)$/ },
        { pattern: /^bg-(red|blue|green)-(100|200)$/, variants: ['hover', 'dark'] },
    ],
}
```

```javascript
// Object mapping pattern (lebih aman dari string concatenation)
const buttonColors = {
    primary: 'bg-indigo-600 hover:bg-indigo-500 text-white',
    danger: 'bg-red-600 hover:bg-red-500 text-white',
    ghost: 'bg-transparent text-gray-700 hover:bg-gray-100',
}
// ✅ Aman: kelas ditulis lengkap
<button className={buttonColors[variant]}>Click</button>

// ❌ Berbahaya: concatenation tidak terdeteksi
// <button className={`text-${color}-500`}>Click</button>
```

## Poin Penting
- Tailwind JIT mendeteksi kelas dengan mencocokkan string lengkap di file template
- Gunakan safelist untuk kelas yang dibangun secara dinamis atau dari sumber eksternal
- Hindari string concatenation untuk kelas; gunakan object mapping dengan kelas lengkap
- Validasi production build dengan E2E testing untuk memastikan semua state komponen tampil
