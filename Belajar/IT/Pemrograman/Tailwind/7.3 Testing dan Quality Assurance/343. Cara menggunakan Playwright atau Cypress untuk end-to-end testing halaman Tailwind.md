# Cara menggunakan Playwright atau Cypress untuk end-to-end testing halaman Tailwind

## Analogi: Perpustakaan Digital
End-to-end testing seperti menguji seluruh alur pengunjung di perpustakaan digital—dari masuk, mencari buku, meminjam, hingga logout. Playwright dan Cypress adalah robot penguji yang mensimulasikan interaksi pengguna secara otomatis. Mereka memastikan semua fitur berfungsi seperti yang diharapkan.

## Penjelasan Detail
End-to-end (E2E) testing menggunakan Playwright atau Cypress untuk mensimulasikan interaksi pengguna nyata di browser. Untuk project Tailwind, testing mencakup: verifikasi elemen muncul dengan kelas Tailwind yang benar, interaksi tombol (click, hover, focus), navigasi halaman, form submission, dan state changes (dark mode toggle, modal, dropdown). Playwright unggul dengan cross-browser support dan kecepatan, sementara Cypress memiliki debugging experience yang lebih baik. Keduanya dapat memverifikasi kelas Tailwind pada elemen menggunakan selector CSS. Contoh: `await expect(page.locator('button').first()).toHaveClass(/bg-indigo-600/)`. Testing juga mencakup responsivitas dengan mengubah viewport. Integration dengan CI/CD pipeline memungkinkan testing otomatis di setiap pull request. Snapshot testing untuk komponen Tailwind melengkapi E2E.

## Contoh Kode Implementasi

```javascript
// Playwright E2E test untuk halaman Tailwind
import { test, expect } from '@playwright/test';

test('dark mode toggle works', async ({ page }) => {
    await page.goto('/');
    const html = page.locator('html');
    await expect(html).not.toHaveClass(/dark/);
    await page.click('button[aria-label="Toggle dark mode"]');
    await expect(html).toHaveClass(/dark/);
});

test('responsive navigation', async ({ page }) => {
    await page.setViewportSize({ width: 375, height: 812 });
    await page.goto('/');
    await expect(page.locator('nav a')).toHaveCount(0); // hidden on mobile
    await page.click('button[aria-label="Open menu"]');
    await expect(page.locator('nav a')).toHaveCount(4);
});

test('form validation shows error styles', async ({ page }) => {
    await page.goto('/contact');
    await page.click('button[type="submit"]');
    await expect(page.locator('.error-message')).toBeVisible();
    await expect(page.locator('input:invalid')).toHaveCount(2);
});
```

## Poin Penting
- Playwright dan Cypress mensimulasikan interaksi pengguna nyata di berbagai browser
- Verifikasi kelas Tailwind pada elemen menggunakan regex atau class matcher
- Test responsivitas dengan mengubah viewport size di Playwright
- Integrasikan E2E test dengan CI/CD untuk deteksi regresi otomatis
