# Cara melakukan performa audit menggunakan Lighthouse pada project Tailwind

## Analogi: Perpustakaan Digital
Lighthouse audit seperti inspektur kualitas yang memeriksa kecepatan akses perpustakaan digital—seberapa cepat halaman terbuka, seberapa ringan asetnya, dan seberapa mulus navigasinya. Tailwind yang dioptimalkan dengan benar seharusnya mendapat skor tinggi di Lighthouse.

## Penjelasan Detail
Lighthouse adalah tools otomatis dari Chrome DevTools untuk mengaudit performa, aksesibilitas, SEO, dan best practices. Untuk project Tailwind, metrik utama adalah **Performance** (First Contentful Paint, Largest Contentful Paint, Cumulative Layout Shift, Speed Index) dan **Best Practices** (ukuran CSS, penggunaan modern formats). Tailwind JIT menghasilkan CSS minimal yang membantu skor performa. Faktor yang mempengaruhi: ukuran bundle CSS yang sudah dipurge, penggunaan font dengan `font-display: swap`, optimasi gambar dengan `aspect-ratio` untuk mencegah layout shift, dan minimalisasi JavaScript. Lighthouse juga mendeteksi CSS yang tidak digunakan (walaupun Tailwind JIT sudah meminimalkannya). Audit dapat dijalankan di Chrome DevTools, via CLI (`lighthouse`), atau di CI dengan `lhci`. Target skor: Performance > 90, Accessibility > 90, Best Practices > 90. Catatan: Tailwind utility classes tidak menyebabkan performance issues—yang penting adalah cara Anda menggunakannya.

## Contoh Kode Implementasi

```bash
# Lighthouse CLI audit
npx lighthouse http://localhost:3000 --view --preset=desktop

# Lighthouse CI di GitHub Actions
npx lhci autorun --collect.url=http://localhost:3000 --upload.target=temporary-public-storage
```

```html
<!-- Optimasi untuk Lighthouse dengan Tailwind -->
<html lang="en" class="scroll-smooth">
<head>
    <link rel="preconnect" href="https://fonts.googleapis.com" />
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
    <style>
        /* Kritis CSS inline untuk FCP cepat */
        .hero { min-height: 60vh; display: flex; align-items: center; }
    </style>
</head>
<body>
    <!-- Gunakan aspect-ratio untuk mencegah CLS -->
    <div class="aspect-video bg-gray-200 rounded-xl">
        <img src="hero.webp" alt="Hero" class="w-full h-full object-cover rounded-xl" loading="eager" />
    </div>
</body>
</html>
```

## Poin Penting
- Lighthouse mengukur Performance, Accessibility, SEO, dan Best Practices
- Tailwind JIT menghasilkan CSS minimal yang mendukung skor performa tinggi
- Optimasi tambahan: font-display swap, aspect-ratio untuk CLS, dan lazy loading gambar
- Target skor: Performance > 90, Accessibility > 90 untuk project profesional
