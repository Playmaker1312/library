# Cara melakukan aksesibilitas testing otomatis pada project Tailwind

## Analogi: Perpustakaan Digital
Aksesibilitas testing seperti memastikan perpustakaan digital bisa digunakan oleh semua pengunjung—termasuk mereka yang menggunakan pembaca layar, hanya keyboard, atau memiliki keterbatasan penglihatan. Tailwind menyediakan utility untuk aksesibilitas, tetapi perlu diverifikasi dengan tools automatis.

## Penjelasan Detail
Aksesibilitas (a11y) testing otomatis untuk project Tailwind menggunakan tools seperti **axe-core**, **Lighthouse**, dan **Playwright/Cypress a11y plugins**. Tools ini memeriksa kontras warna, ARIA attributes, keyboard navigation, focus management, dan semantic HTML. Tailwind memiliki utility kelas untuk aksesibilitas seperti `sr-only` (screen reader only), `focus:ring`, `focus-visible:`, dan `motion-safe/motion-reduce`. Automated testing dapat diintegrasikan ke CI/CD untuk mencegah regresi aksesibilitas. Contoh pelanggaran umum: kurangnya label pada form, kontras warna tidak mencukupi, heading tidak terstruktur, dan missing alt text pada gambar. Playwright memiliki `@axe-core/playwright` untuk injeksi axe-core. Lighthouse audit menyediakan skor aksesibilitas dan rekomendasi perbaikan. Tailwind dark mode perlu diuji kontrasnya secara terpisah. Test keyboard navigation dengan tab, shift+tab, enter, dan escape.

## Contoh Kode Implementasi

```javascript
// Playwright aksesibilitas test dengan axe-core
import { test, expect } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';

test('homepage should not have accessibility violations', async ({ page }) => {
    await page.goto('/');
    const results = await new AxeBuilder({ page }).analyze();
    expect(results.violations).toEqual([]);
});

test('dark mode accessibility', async ({ page }) => {
    await page.goto('/?dark=1');
    const results = await new AxeBuilder({ page }).analyze();
    expect(results.violations).toEqual([]);
});

test('keyboard navigation works', async ({ page }) => {
    await page.goto('/');
    await page.keyboard.press('Tab');
    await expect(page.locator(':focus-visible')).toBeVisible();
    await page.keyboard.press('Enter');
    await expect(page).toHaveURL(/\/about/);
});
```

## Poin Penting
- Gunakan axe-core untuk automated accessibility testing di Playwright atau Cypress
- Periksa kontras warna, ARIA labels, keyboard navigation, dan heading structure
- Utility Tailwind `sr-only`, `focus-visible`, dan `motion-safe` membantu aksesibilitas
- Test dark mode dan light mode secara terpisah untuk kepatuhan kontras penuh
