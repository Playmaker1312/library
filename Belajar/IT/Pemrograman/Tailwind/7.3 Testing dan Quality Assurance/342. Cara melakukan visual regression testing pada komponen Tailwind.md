# Cara melakukan visual regression testing pada komponen Tailwind

## Analogi: Perpustakaan Digital
Visual regression testing seperti membandingkan edisi baru buku dengan edisi sebelumnya di perpustakaan digital untuk memastikan tidak ada halaman yang berubah secara tidak sengaja. Jika ada perbedaan, Anda bisa langsung tahu bagian mana yang berubah dan apakah perubahan itu sesuai keinginan.

## Penjelasan Detail
Visual regression testing membandingkan screenshot komponen sebelum dan sesudah perubahan untuk mendeteksi perbedaan visual yang tidak diinginkan. Tools seperti **Percy**, **Chromatic**, **Playwright Visual Comparisons**, atau **BackstopJS** mengotomatisasi proses ini. Untuk project Tailwind, perubahan pada utility classes atau konfigurasi theme dapat mempengaruhi tampilan secara global. Setup meliputi: mengambil baseline screenshot, menjalankan test setelah perubahan, membandingkan dengan diff visual, dan menyetujui atau menolak perubahan. Integrasi dengan CI/CD pipeline memastikan regression terdeteksi sebelum deployment. Threshold perbedaan dapat dikonfigurasi untuk toleransi anti-aliasing. Perhatikan bahwa dark mode perlu di-test secara terpisah. Tailwind utility classes yang konsisten membuat diff lebih mudah diinterpretasikan karena perubahan biasanya terlokalisasi.

## Contoh Kode Implementasi

```javascript
// Playwright visual comparison test
import { test, expect } from '@playwright/test';

test('homepage visual regression', async ({ page }) => {
    await page.goto('/');
    await expect(page).toHaveScreenshot('homepage.png', {
        maxDiffPixels: 100,
        threshold: 0.2,
    });
});

test('dark mode visual regression', async ({ page }) => {
    await page.goto('/?dark=1');
    await expect(page).toHaveScreenshot('homepage-dark.png', {
        maxDiffPixels: 100,
    });
});
```

```bash
# BackstopJS configuration for Tailwind project
npx backstop init
# Edit backstop.json with scenarios
npx backstop test
```

## Poin Penting
- Visual regression membandingkan screenshot baseline dengan hasil render terbaru
- Tools populer: Percy, Chromatic, Playwright Visual Comparisons, BackstopJS
- Test dark mode dan light mode secara terpisah untuk coverage penuh
- Integrasikan dengan CI/CD agar regression terdeteksi otomatis sebelum deployment
