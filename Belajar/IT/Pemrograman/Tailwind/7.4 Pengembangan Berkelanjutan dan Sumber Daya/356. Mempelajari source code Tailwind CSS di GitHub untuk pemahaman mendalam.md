# Mempelajari source code Tailwind CSS di GitHub untuk pemahaman mendalam

## Analogi: Perpustakaan Digital
Mempelajari source code Tailwind seperti membaca buku tentang cara kerja mesin cetak di perpustakaan—Anda tidak hanya menggunakan buku, tetapi memahami bagaimana buku dibuat. Ini memberikan pemahaman fundamental tentang bagaimana utility classes diproses, bagaimana JIT engine bekerja, dan bagaimana plugin diintegrasikan.

## Penjelasan Detail
Source code Tailwind CSS di GitHub (github.com/tailwindlabs/tailwindcss) adalah kode sumber terbuka yang dapat dipelajari siapa saja. Struktur utama: **`packages/tailwindcss`** untuk core framework, termasuk JIT engine, parser, dan generator CSS. **`packages/plugin-typography`** untuk plugin resmi. **`packages/oxide`** untuk Rust-based engine (Tailwind v4). Mempelajari source code memberikan pemahaman tentang: bagaimana utility classes diproses menjadi CSS, bagaimana variant modifiers bekerja, bagaimana purge/content detection beroperasi, dan bagaimana custom plugin dieksekusi. File penting: `src/corePlugins.js` berisi definisi semua utility classes bawaan, `src/lib/` untuk logika utama. Tailwind menggunakan PostCSS sebagai plugin untuk transformasi CSS. Kontribusi ke source code dimulai dengan membaca `CONTRIBUTING.md`, mencari issues berlabel "good first issue", dan mengirim pull request. Source code didokumentasikan dengan JSDoc dan tes ekstensif dengan Jest.

```javascript
// Membaca core plugin Tailwind (contoh struktur)

    return {

        '.p-1': { padding: '0.25rem' },
        '.p-2': { padding: '0.5rem' },
        '.p-4': { padding: '1rem' },
        // Responsive variants are added by the framework

// Cara kerja JIT engine (konseptual)

// 4. Output ke file CSS final
```
