# Cara menggunakan prose-headings, prose-p, prose-a, dan element-specific modifiers

## Analogi: Perpustakaan Digital
Bayangkan Anda ingin merapikan perpustakaan tetapi hanya untuk bagian tertentu — sampul buku (headings) dengan warna biru, halaman isi (paragraph) dengan font lebih besar, dan label rak (link) dengan gaya khusus. Element-specific modifiers seperti memberikan instruksi detail untuk setiap jenis elemen: "heading seperti ini, paragraf seperti itu, link seperti ini." Setiap elemen mendapat perlakuan yang sesuai tanpa mengganggu yang lain.

## Penjelasan Detail
Element-specific modifiers adalah class modifier yang menargetkan elemen HTML spesifik di dalam container prose. Modifier yang tersedia meliputi `prose-headings` (semua heading h1-h6), `prose-h1`, `prose-h2`, `prose-h3` (heading spesifik level), `prose-p` (paragraph), `prose-a` (anchor/link), `prose-blockquote`, `prose-code`, `prose-pre`, `prose-ol` (ordered list), `prose-ul` (unordered list), `prose-li` (list item), `prose-img` (image), `prose-hr` (horizontal rule), `prose-table`, `prose-thead`, `prose-tr`, `prose-th`, `prose-td`, dan `prose-figure`. Setiap modifier bisa dikombinasikan dengan utility Tailwind seperti warna, font, margin, dan lainnya. Modifier ini sangat berguna ketika Anda ingin memberikan identitas visual yang unik pada tiap elemen artikel tanpa mengubah konfigurasi global.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Element-Specific Prose Modifiers</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          addBase({
            ".prose": {
              maxWidth: "65ch", fontSize: "1rem", lineHeight: "1.75", color: "#374151",
              "& h1": { fontSize: "2.25em", fontWeight: "800", marginBottom: "0.5em" },
              "& h2": { fontSize: "1.5em", fontWeight: "700", marginBottom: "0.5em", marginTop: "1.5em" },
              "& h3": { fontSize: "1.25em", fontWeight: "600", marginBottom: "0.5em", marginTop: "1.25em" },
              "& p": { marginBottom: "1.25em" },
              "& a": { color: "#2563eb", textDecoration: "underline" },
              "& ul": { listStyle: "disc", paddingLeft: "1.5em", marginBottom: "1.25em" },
              "& ol": { listStyle: "decimal", paddingLeft: "1.5em", marginBottom: "1.25em" },
              "& blockquote": { borderLeft: "4px solid #e5e7eb", paddingLeft: "1em", fontStyle: "italic" },
              "& code": { backgroundColor: "#f3f4f6", padding: "0.2em 0.4em", borderRadius: "0.25rem", fontSize: "0.875em" },
              "& img": { borderRadius: "0.5rem", margin: "1.5em 0" },
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto">
    <article class="prose prose-h1:text-4xl prose-h1:text-indigo-700 prose-h2:text-2xl prose-h2:text-indigo-500 prose-h2:border-b prose-h2:border-indigo-200 prose-h2:pb-2 prose-p:text-gray-600 prose-p:leading-loose prose-a:text-emerald-600 prose-a:font-semibold prose-a:no-underline hover:prose-a:underline prose-blockquote:border-emerald-400 prose-blockquote:bg-emerald-50 prose-blockquote:px-4 prose-blockquote:py-2 prose-blockquote:rounded-r-lg prose-code:text-emerald-800 prose-code:bg-emerald-50 prose-ul:list-disc prose-ul:marker:text-emerald-500 bg-white p-8 rounded-xl shadow">
      <h1>Element-Specific Modifiers</h1>
      <p>Setiap elemen di artikel ini memiliki gaya yang dikustomisasi secara spesifik menggunakan <strong>element-specific modifiers</strong>. Heading h1 berwarna indigo-700, paragraf abu-abu, dan link hijau emerald.</p>
      <h2>Apa Itu Element-Specific Modifiers?</h2>
      <p>Modifier ini memungkinkan Anda menarget elemen HTML spesifik di dalam prose. Contohnya: <code>prose-h1:</code>, <code>prose-p:</code>, <code>prose-a:</code>, dan masih banyak lagi.</p>
      <blockquote>Dengan element-specific modifiers, setiap bagian artikel bisa memiliki gaya unik tanpa menulis CSS kustom.</blockquote>
      <h3>Daftar Elemen yang Didukung</h3>
      <ul>
        <li><code>prose-h1</code> hingga <code>prose-h6</code> — heading spesifik</li>
        <li><code>prose-p</code> — paragraph</li>
        <li><code>prose-a</code> — link</li>
        <li><code>prose-blockquote</code> — kutipan</li>
      </ul>
      <p>Kode seperti <code>npm install @tailwindcss/typography</code> akan ditampilkan dengan gaya emerald.</p>
    </article>
  </div>
</body>
</html>
```

## Poin Penting
- Element-specific modifiers menarget elemen HTML spesifik: `prose-h1`, `prose-p`, `prose-a`, `prose-blockquote`, dll
- Setiap modifier bisa dikombinasikan dengan utility Tailwind untuk kustomisasi mendetail
- Modifier ini memungkinkan kontrol granular atas tampilan setiap elemen artikel
