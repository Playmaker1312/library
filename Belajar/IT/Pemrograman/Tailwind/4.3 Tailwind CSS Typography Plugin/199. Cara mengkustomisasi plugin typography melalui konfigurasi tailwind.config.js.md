# Cara mengkustomisasi plugin typography melalui konfigurasi tailwind.config.js

## Analogi: Perpustakaan Digital
Alih-alih menambahkan instruksi manual setiap kali menata buku, Anda bisa mengubah aturan utama sistem penataan perpustakaan itu sendiri. Mengkustomisasi plugin typography melalui konfigurasi seperti mengubah buku panduan petugas perpustakaan — "mulai sekarang, semua heading menggunakan font ini, semua paragraf menggunakan spasi ini, dan semua kutipan menggunakan gaya ini." Perubahan ini akan berlaku global tanpa perlu modifier tambahan.

## Penjelasan Detail
Plugin Tailwind Typography bisa dikustomisasi secara mendalam melalui properti `theme.extend.typography` di tailwind.config.js. Di sini Anda bisa mendefinisikan kustomisasi untuk setiap elemen HTML yang ada di dalam prose. Struktur konfigurasinya adalah objek dengan key nama elemen (seperti `h1`, `h2`, `p`, `a`, `blockquote`) dan value berupa properti CSS. Anda bisa mengganti font, warna, margin, padding, border, dan properti CSS lainnya. Kustomisasi melalui konfigurasi bersifat global dan akan memengaruhi semua container prose di proyek. Anda juga bisa membuat varian kustom prose seperti `prose-xl` atau `prose-custom` dengan menambahkan key baru di dalam `typography`. Ini adalah pendekatan yang paling terstruktur dan maintainable untuk kustomisasi typography skala besar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Kustomisasi Typography via Config</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          typography: {
            DEFAULT: {
              css: {
                maxWidth: "75ch",
                color: "#374151",
                fontSize: "1rem",
                lineHeight: "1.75",
                h1: {
                  fontSize: "2.5em",
                  fontWeight: "800",
                  color: "#1e40af",
                  marginBottom: "0.5em",
                  letterSpacing: "-0.02em",
                },
                h2: {
                  fontSize: "1.75em",
                  fontWeight: "700",
                  color: "#1e3a8a",
                  marginTop: "1.5em",
                  marginBottom: "0.5em",
                },
                a: {
                  color: "#3b82f6",
                  textDecoration: "none",
                  fontWeight: "500",
                  "&:hover": { color: "#1d4ed8", textDecoration: "underline" },
                },
                blockquote: {
                  borderLeftColor: "#3b82f6",
                  borderLeftWidth: "4px",
                  fontStyle: "italic",
                  paddingLeft: "1.25em",
                  color: "#4b5563",
                },
                code: {
                  backgroundColor: "#eff6ff",
                  color: "#1e40af",
                  padding: "0.2em 0.4em",
                  borderRadius: "0.25rem",
                  fontWeight: "600",
                  fontSize: "0.875em",
                },
              },
            },
          },
        },
      },
      plugins: [
        function ({ addBase, theme }) {
          const typography = theme("typography.DEFAULT.css");
          if (typography) {
            const proseStyles = { ".prose": { ...typography } };
            addBase(proseStyles);
          }
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto">
    <h1 class="text-2xl font-bold text-gray-800 mb-6">Kustomisasi via tailwind.config.js</h1>
    <article class="prose bg-white p-8 rounded-xl shadow">
      <h1>Judul dengan Kustomisasi Global</h1>
      <p>Semua heading h1 di artikel ini berwarna biru tua (indigo-800) dengan font lebih besar karena sudah dikustomisasi di konfigurasi. <a href="#">Link memiliki warna biru</a> dengan hover underline — ini juga dari konfigurasi.</p>
      <h2>Subheading Biru Muda</h2>
      <p>Kustomisasi melalui <code>theme.extend.typography</code> memberikan kontrol global. Kode inline memiliki background biru muda dengan teks biru tua.</p>
      <blockquote>Blockquote memiliki border biru-500 dengan padding dan font italic — semua diatur dari konfigurasi.</blockquote>
      <p>Dengan pendekatan ini, semua artikel di proyek akan konsisten tanpa perlu modifier manual.</p>
    </article>
    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm mt-6">
theme: {
  extend: {
    typography: {
      DEFAULT: {
        css: {
          h1: { color: "#1e40af", fontSize: "2.5em" },
          a: { color: "#3b82f6", "&:hover": { color: "#1d4ed8" } },
          blockquote: { borderLeftColor: "#3b82f6" },
        },
      },
    },
  },
},</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Kustomisasi typography global dilakukan melalui `theme.extend.typography.DEFAULT.css` di tailwind.config.js
- Anda bisa mengubah properti CSS untuk setiap elemen HTML (h1, h2, p, a, blockquote, code, dll)
- Pendekatan ini memberikan konsistensi global tanpa perlu modifier manual di setiap container prose
