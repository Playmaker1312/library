# Cara mengubah warna prose menggunakan prose-gray, prose-slate, dll

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki tema warna berbeda untuk setiap ruangan: ruang baca utama dengan nuansa abu-abu netral (prose-gray), ruang anak dengan nuansa biru keabu-abuan (prose-slate), ruang referensi dengan nuansa hangat (prose-stone), dan ruang diskusi dengan nuansa netral (prose-neutral). Masing-masing memberikan suasana yang berbeda tanpa mengubah tata letak atau struktur ruangan. Inilah yang dilakukan prose color modifiers pada konten artikel.

## Penjelasan Detail
Plugin Tailwind Typography menyediakan modifier warna untuk mengubah skema warna konten prose secara keseluruhan. Modifier tersebut meliputi `prose-gray` (abu-abu netral), `prose-slate` (abu-abu kebiruan), `prose-zinc` (abu-abu keperakan), `prose-neutral` (netral), dan `prose-stone` (abu-abu kehangatan). Masing-masing modifier mengubah warna teks, heading, link, blockquote, kode, border, dan elemen lainnya secara konsisten. Modifier warna ini berguna untuk menyesuaikan tampilan artikel dengan tema situs Anda. Jika tidak ada modifier warna yang ditambahkan, prose akan menggunakan warna default (netral). Modifier warna bisa digabungkan dengan modifier ukuran dan element-specific modifiers.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Warna Prose</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          const proseShared = {
            maxWidth: "65ch", fontSize: "1rem", lineHeight: "1.75",
            "& h1": { fontSize: "2.25em", fontWeight: "800", marginBottom: "0.5em" },
            "& h2": { fontSize: "1.5em", fontWeight: "700", marginBottom: "0.5em", marginTop: "1.5em" },
            "& p": { marginBottom: "1.25em" },
            "& a": { textDecoration: "underline" },
            "& code": { padding: "0.2em 0.4em", borderRadius: "0.25rem", fontSize: "0.875em" },
          };
          addBase({
            ".prose-gray": { ...proseShared, color: "#374151", "& h1, & h2": { color: "#111827" }, "& a": { color: "#2563eb" }, "& code": { backgroundColor: "#f3f4f6", color: "#111827" } },
            ".prose-slate": { ...proseShared, color: "#334155", "& h1, & h2": { color: "#0f172a" }, "& a": { color: "#3b82f6" }, "& code": { backgroundColor: "#f1f5f9", color: "#0f172a" } },
            ".prose-stone": { ...proseShared, color: "#44403c", "& h1, & h2": { color: "#1c1917" }, "& a": { color: "#d97706" }, "& code": { backgroundColor: "#f5f5f4", color: "#1c1917" } },
            ".prose-neutral": { ...proseShared, color: "#404040", "& h1, & h2": { color: "#171717" }, "& a": { color: "#525252" }, "& code": { backgroundColor: "#f5f5f5", color: "#171717" } },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-5xl mx-auto space-y-8">
    <h1 class="text-3xl font-bold text-center">Prose Color Modifiers</h1>
    <div class="grid grid-cols-1 md:grid-cols-2 gap-6">
      <div class="prose-gray bg-white p-6 rounded-xl shadow">
        <h2>prose-gray</h2>
        <p>Warna abu-abu netral. Cocok untuk artikel standar dengan <a href="#">link biru</a> dan tampilan yang profesional.</p>
      </div>
      <div class="prose-slate bg-white p-6 rounded-xl shadow">
        <h2>prose-slate</h2>
        <p>Warna abu-abu kebiruan. Memberikan kesan <a href="#">modern dan teknis</a>, cocok untuk dokumentasi.</p>
      </div>
      <div class="prose-stone bg-white p-6 rounded-xl shadow">
        <h2>prose-stone</h2>
        <p>Warna hangat seperti batu. <a href="#">Cocok untuk blog personal</a> atau situs dengan nuansa earthy.</p>
      </div>
      <div class="prose-neutral bg-white p-6 rounded-xl shadow">
        <h2>prose-neutral</h2>
        <p>Warga netral seimbang. <a href="#">Tampilan minimalis</a> untuk situs dengan fokus pada konten.</p>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Prose color modifiers: `prose-gray`, `prose-slate`, `prose-zinc`, `prose-neutral`, `prose-stone`
- Setiap modifier mengubah palet warna seluruh elemen di dalam container prose secara konsisten
- Modifier warna bisa dikombinasikan dengan modifier ukuran dan element-specific modifier untuk hasil optimal
