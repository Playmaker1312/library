# Cara menggunakan class prose untuk menerapkan typografi otomatis

## Analogi: Perpustakaan Digital
Seperti menekan satu tombol "Rapikan Buku" yang secara otomatis mengatur semua buku di rak berdasarkan genre, ukuran, dan abjad. Class `prose` adalah tombol ajaib itu — cukup tambahkan ke container artikel, dan semua konten HTML di dalamnya akan dirapikan secara otomatis dengan typografi yang indah tanpa perlu mengatur setiap elemen satu per satu.

## Penjelasan Detail
Class `prose` adalah class utama yang disediakan oleh plugin Tailwind Typography. Cara menggunakannya sangat sederhana: tambahkan class `prose` ke elemen container (biasanya `<article>` atau `<div>`) yang membungkus konten HTML. Class ini akan memberikan gaya typografi yang optimal dengan `max-width` sekitar 65 karakter per baris (ideal untuk readability). `prose` menggunakan warna teks netral dan ukuran font yang nyaman untuk dibaca. Konten yang akan diformat bisa berupa HTML statis, hasil render Markdown, konten dari CMS, atau output dari rich text editor. Class `prose` bekerja langsung pada elemen HTML tanpa perlu JavaScript. Pastikan konten di dalam container adalah HTML yang valid untuk hasil terbaik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Menggunakan Class Prose</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          addBase({
            ".prose": {
              maxWidth: "65ch",
              fontSize: "1rem",
              lineHeight: "1.75",
              color: "#374151",
              "& h1": { fontSize: "2.25em", fontWeight: "800", marginBottom: "0.5em", color: "#111827" },
              "& h2": { fontSize: "1.5em", fontWeight: "700", marginBottom: "0.5em", marginTop: "1.5em", color: "#111827" },
              "& p": { marginBottom: "1.25em" },
              "& a": { color: "#2563eb", textDecoration: "underline" },
              "& ul": { listStyle: "disc", paddingLeft: "1.5em", marginBottom: "1.25em" },
              "& ol": { listStyle: "decimal", paddingLeft: "1.5em", marginBottom: "1.25em" },
              "& blockquote": { borderLeft: "4px solid #e5e7eb", paddingLeft: "1em", fontStyle: "italic", color: "#6b7280", margin: "1.5em 0" },
              "& code": { backgroundColor: "#f3f4f6", padding: "0.2em 0.4em", borderRadius: "0.25rem", fontSize: "0.875em" },
              "& pre": { backgroundColor: "#1f2937", color: "#e5e7eb", padding: "1em", borderRadius: "0.5em", overflow: "auto" },
              "& pre code": { background: "none", padding: "0" },
              "& img": { borderRadius: "0.5em", margin: "1.5em 0" },
              "& hr": { border: "0", borderTop: "1px solid #e5e7eb", margin: "2em 0" },
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto">
    <div class="bg-indigo-50 p-4 rounded-lg mb-6">
      <p class="text-sm text-indigo-800">Container dengan class <code class="font-bold">prose</code> → typografi otomatis aktif</p>
    </div>
    <article class="prose bg-white p-8 rounded-xl shadow">
      <h1>Belajar Tailwind CSS</h1>
      <p>Tailwind CSS adalah framework utility-first yang memungkinkan Anda membangun desain kustom dengan cepat. Artikel ini membahas cara menggunakan <a href="#">class prose</a> untuk typografi otomatis.</p>
      <h2>Apa Itu Class Prose?</h2>
      <p>Class <code>prose</code> adalah solusi all-in-one untuk styling konten HTML. Dengan satu class, semua elemen mendapatkan gaya yang optimal:</p>
      <ul>
        <li>Heading dengan ukuran dan weight yang proporsional</li>
        <li>Paragraph dengan line-height ideal untuk readability</li>
        <li>Link dengan warna yang kontras dan underline</li>
      </ul>
      <blockquote>Prose adalah cara termudah untuk membuat konten artikel terlihat profesional.</blockquote>
      <p>Berikut adalah contoh kode Python:</p>
      <pre><code>def hello():
    print("Hello, Tailwind!")</code></pre>
      <hr />
      <p><em>Artikel ini ditulis untuk demonstrasi class prose.</em></p>
    </article>
  </div>
</body>
</html>
```

## Poin Penting
- Tambahkan class `prose` ke container (biasanya `<article>` atau `<div>`) untuk aktivasi typografi otomatis
- Class prose memberikan styling optimal untuk konten HTML termasuk heading, paragraph, list, dan code
- Hasilnya adalah artikel dengan readability tinggi tanpa perlu menulis CSS kustom
