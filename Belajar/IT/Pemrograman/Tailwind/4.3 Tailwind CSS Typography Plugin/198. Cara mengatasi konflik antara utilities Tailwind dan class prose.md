# Cara mengatasi konflik antara utilities Tailwind dan class prose

## Analogi: Perpustakaan Digital
Bayangkan Anda sudah menata perpustakaan dengan sistem rak otomatis (prose), tetapi terkadang ada buku tertentu yang perlu diletakkan di rak yang berbeda dari aturan umum. Di sinilah Anda perlu memberikan instruksi manual (utility class) yang mengesampingkan aturan otomatis. Masalahnya, kadang instruksi manual tidak berfungsi karena aturan otomatis terlalu kuat. Konflik ini perlu diatasi dengan strategi yang tepat.

## Penjelasan Detail
Konflik antara utility Tailwind dan class prose terjadi karena prose menggunakan selektor dengan spesifisitas tinggi (seperti `.prose h1`, `.prose p`), yang bisa meng-override utility class langsung seperti `text-red-500`. Untuk mengatasi konflik ini, ada beberapa strategi. Pertama, gunakan important modifier (`!`) di depan utility class, misalnya `!text-red-500`. Kedua, gunakan inline style untuk override yang paling kuat. Ketiga, kustomisasi konfigurasi typography di tailwind.config.js untuk mengubah nilai default prose. Keempat, gunakan element-specific modifiers untuk override yang lebih spesifik. Kelima, jika konflik terjadi pada elemen tertentu, Anda bisa membungkusnya dalam container terpisah di luar prose. Strategi terbaik adalah menggunakan modifiers prose sebelum menggunakan important modifier.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Konflik Prose vs Utilities</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          addBase({
            ".prose": {
              maxWidth: "65ch", fontSize: "1rem", lineHeight: "1.75", color: "#374151",
              "& h1": { fontSize: "2.25em", fontWeight: "800", color: "#111827" },
              "& p": { marginBottom: "1.25em", color: "#374151" },
              "& a": { color: "#2563eb", textDecoration: "underline" },
              "& strong": { fontWeight: "700" },
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-8">
    <div class="prose bg-white p-8 rounded-xl shadow">
      <h1>Konflik Prose vs Utility</h1>
      
      <p>Paragraf ini menggunakan gaya prose default — warna abu-abu dan margin bawah.</p>
      
      <!-- Strategi 1: Important modifier -->
      <p class="!text-red-600 !font-bold">Strategi 1: Important modifier (<code>!text-red-600</code>) — berhasil override warna prose.</p>
      
      <!-- Strategi 2: Prose modifier (rekomendasi) -->
      <p class="prose-p:text-indigo-600 prose-p:font-semibold">Strategi 2: Prose modifier (<code>prose-p:text-indigo-600</code>) — cara yang lebih bersih.</p>
      
      <!-- Strategi 3: Element spesifik -->
      <p>Paragraf normal. <strong class="!text-emerald-600">Strong dengan important modifier</strong> — berhasil mengubah warna.</p>
      
      <!-- Demonstrasi konflik -->
      <div class="bg-amber-50 border-l-4 border-amber-400 p-4 rounded-r-lg not-prose">
        <p class="text-amber-900"><strong>Catatan:</strong> Container ini menggunakan <code>not-prose</code> untuk keluar dari prose styling. Utility class di sini bekerja normal tanpa konflik.</p>
      </div>
    </div>

    <div class="bg-gray-900 text-green-400 p-6 rounded-xl text-sm">
      <pre>// Strategi mengatasi konflik:
// 1. Prose modifier (lebih disarankan)
&lt;p class="prose-p:text-indigo-600"&gt;...

// 2. Important modifier
&lt;p class="!text-red-600"&gt;...

// 3. not-prose (keluar dari prose)
&lt;div class="not-prose"&gt;...

// 4. Kustomisasi konfigurasi typography</pre>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Konflik terjadi karena prose menggunakan selektor spesifik yang bisa meng-override utility class
- Gunakan prose modifier (`prose-p:text-indigo-600`) sebagai solusi utama untuk override
- Important modifier (`!text-red-600`) dan class `not-prose` adalah alternatif untuk kasus tertentu
