# Memahami prose variants yaitu prose-sm, prose-base, prose-lg, prose-xl, dan prose-2xl

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki buku dengan ukuran font berbeda: buku saku (prose-sm), buku standar (prose-base), buku ukuran besar (prose-lg), buku meja (prose-xl), dan buku atlas raksasa (prose-2xl). Masing-masing cocok untuk konteks yang berbeda — buku saku untuk bacaan cepat, atlas untuk studi detail. Prose variants memungkinkan Anda memilih ukuran typografi yang tepat untuk setiap konteks.

## Penjelasan Detail
Plugin Tailwind Typography menyediakan varian ukuran untuk class `prose` yang mengontrol ukuran font dan spacing secara keseluruhan. Varian tersebut adalah `prose-sm` (0.875rem), `prose-base` (1rem / default), `prose-lg` (1.125rem), `prose-xl` (1.25rem), dan `prose-2xl` (1.5rem). Setiap varian tidak hanya mengubah ukuran font, tetapi juga menyesuaikan margin, padding, line-height, dan ukuran heading secara proporsional. Varian ini bisa digabungkan dengan class `prose` pada elemen yang sama, misalnya `<div class="prose prose-lg">`. Varian ukuran memungkinkan Anda memiliki artikel dengan skala typografi yang berbeda untuk berbagai konteks — artikel utama (lebih besar), sidebar (lebih kecil), atau konten hero (sangat besar).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Prose Variants</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          const proseBase = {
            maxWidth: "65ch", color: "#374151",
            "& h1": { fontWeight: "800", color: "#111827" },
            "& h2": { fontWeight: "700", color: "#111827" },
            "& p": { marginBottom: "1em" },
          };
          addBase({
            ".prose": { ...proseBase, fontSize: "1rem", lineHeight: "1.75" },
            ".prose-sm": { ...proseBase, fontSize: "0.875rem", lineHeight: "1.7142857" },
            ".prose-lg": { ...proseBase, fontSize: "1.125rem", lineHeight: "1.7777778" },
            ".prose-xl": { ...proseBase, fontSize: "1.25rem", lineHeight: "1.8" },
            ".prose-2xl": { ...proseBase, fontSize: "1.5rem", lineHeight: "1.6666667" },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-5xl mx-auto space-y-10">
    <h1 class="text-3xl font-bold text-gray-800 text-center">Prose Variants</h1>
    <div class="grid grid-cols-1 md:grid-cols-2 gap-6">
      <div class="prose-sm bg-white p-6 rounded-xl shadow">
        <h1>prose-sm</h1>
        <p>Ukuran 0.875rem. Cocok untuk sidebar, komentar, atau konten pendamping. Line-height lebih rapat untuk memaksimalkan ruang.</p>
      </div>
      <div class="prose bg-white p-6 rounded-xl shadow">
        <h1>prose-base</h1>
        <p>Ukuran 1rem (default). Standar untuk artikel blog dan konten utama. Memberikan keseimbangan antara readability dan densitas konten.</p>
      </div>
      <div class="prose-lg bg-white p-6 rounded-xl shadow">
        <h1>prose-lg</h1>
        <p>Ukuran 1.125rem. Untuk artikel premium atau konten yang ingin dibaca dengan santai. Spasi lebih lega.</p>
      </div>
      <div class="prose-xl bg-white p-6 rounded-xl shadow">
        <h1>prose-xl</h1>
        <p>Ukuran 1.25rem. Cocok untuk halaman utama, hero content, atau dokumentasi teknis yang ingin menonjol.</p>
      </div>
    </div>
    <div class="prose-2xl bg-white p-8 rounded-xl shadow max-w-3xl mx-auto">
      <h1>prose-2xl</h1>
      <p>Ukuran 1.5rem. Untuk konten premium eksklusif atau artikel feature yang panjang. Sangat nyaman dibaca dengan spacing yang luas.</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Prose variants mengontrol skala ukuran font: prose-sm, prose-base, prose-lg, prose-xl, prose-2xl
- Setiap varian menyesuaikan tidak hanya font size tetapi juga margin, padding, dan line-height
- Pilih varian berdasarkan konteks: sm untuk sidebar, lg/xl untuk artikel utama, 2xl untuk konten premium
