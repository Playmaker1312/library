# Cara menerapkan prose untuk konten yang berasal dari CMS atau markdown

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang menerima koleksi buku dari berbagai penerbit — masing-masing dengan format, font, dan tata letak yang berbeda. Sebelum buku-buku ini dipajang di rak, petugas perpustakaan akan menyeragamkan tampilannya dengan label dan sampul yang konsisten. Konten dari CMS atau Markdown seperti buku dari berbagai penerbit: HTML yang dihasilkan bisa berbeda formatnya. Prose adalah petugas yang menyeragamkan tampilan semua konten tersebut.

## Penjelasan Detail
Konten dari CMS (Content Management System) seperti WordPress, Sanity, Contentful, atau dari Markdown biasanya berupa HTML mentah dengan struktur yang tidak selalu rapi. Untuk menerapkan prose, Anda cukup membungkus konten tersebut dalam elemen dengan class `prose`. Karena prose bekerja pada level CSS, tidak peduli bagaimana HTML dihasilkan — selama HTML tersebut valid, prose akan memberikan gaya yang konsisten. Pada framework JavaScript seperti React atau Vue, Anda tinggal menempatkan HTML mentah ke dalam container prose menggunakan `dangerouslySetInnerHTML` (React) atau `v-html` (Vue). Pada static site generator seperti Eleventy atau Hugo, Anda bisa langsung menambahkan class `prose` ke template artikel. Penting untuk diingat bahwa prose tidak membersihkan HTML dari potensi XSS — pastikan konten sudah di-sanitize sebelumnya.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Prose untuk CMS & Markdown</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          addBase({
            ".prose": {
              maxWidth: "65ch", fontSize: "1rem", lineHeight: "1.75", color: "#374151",
              "& h1": { fontSize: "2.25em", fontWeight: "800", marginBottom: "0.5em", color: "#111827" },
              "& h2": { fontSize: "1.5em", fontWeight: "700", marginBottom: "0.5em", marginTop: "1.5em", color: "#111827" },
              "& h3": { fontSize: "1.25em", fontWeight: "600", marginBottom: "0.5em", marginTop: "1.25em", color: "#111827" },
              "& p": { marginBottom: "1.25em" },
              "& a": { color: "#2563eb", textDecoration: "underline" },
              "& ul, & ol": { paddingLeft: "1.5em", marginBottom: "1.25em" },
              "& li": { marginBottom: "0.25em" },
              "& blockquote": { borderLeft: "4px solid #e5e7eb", paddingLeft: "1em", fontStyle: "italic", color: "#6b7280", margin: "1.5em 0" },
              "& code": { backgroundColor: "#f3f4f6", padding: "0.2em 0.4em", borderRadius: "0.25rem", fontSize: "0.875em", color: "#111827" },
              "& pre": { backgroundColor: "#1f2937", color: "#e5e7eb", padding: "1.25em", borderRadius: "0.5rem", overflow: "auto" },
              "& img": { borderRadius: "0.5rem", margin: "1.5em 0", maxWidth: "100%" },
              "& table": { width: "100%", borderCollapse: "collapse", margin: "1.5em 0" },
              "& th": { backgroundColor: "#f9fafb", padding: "0.75em", border: "1px solid #e5e7eb", fontWeight: "600" },
              "& td": { padding: "0.75em", border: "1px solid #e5e7eb" },
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto">
    <div class="bg-amber-50 border-l-4 border-amber-400 p-4 mb-6 rounded-r-lg">
      <p class="text-sm text-amber-800"><strong>Simulasi:</strong> Konten di bawah ini berasal dari Markdown/CMS dan ditempatkan di dalam container <code>prose</code>.</p>
    </div>

    <div id="article-container" class="prose bg-white p-8 rounded-xl shadow"></div>
  </div>

  <script>
    // Simulasi konten dari CMS/Markdown
    const markdownContent = `
      <h1>Integrasi Prose dengan CMS</h1>
      <p>Artikel ini ditulis di <strong>Markdown</strong> kemudian di-render menjadi HTML. Dengan membungkusnya dalam container <code>prose</code>, tampilannya langsung rapi tanpa perlu styling manual.</p>
      <h2>Mengapa Ini Penting?</h2>
      <p>Konten dari CMS biasanya sudah berupa HTML. Daripada menulis utility class untuk setiap elemen, cukup tambahkan class <code>prose</code> di container.</p>
      <h3>Contoh List dari Markdown</h3>
      <ul>
        <li>Heading otomatis mendapat ukuran proporsional</li>
        <li>Link mendapat warna dan underline yang sesuai</li>
        <li>Kode inline memiliki background yang kontras</li>
      </ul>
      <blockquote>Dengan prose, konten dari CMS atau Markdown langsung terlihat profesional tanpa kerja ekstra.</blockquote>
      <pre><code>// React example
function Article({ html }) {
  return &lt;div className="prose" dangerouslySetInnerHTML={{ __html: html }} /&gt;;
}</code></pre>
    `;

    document.getElementById("article-container").innerHTML = markdownContent;
  </script>
</body>
</html>
```

## Poin Penting
- Prose bisa langsung diterapkan pada konten HTML dari CMS atau Markdown tanpa modifikasi
- Di framework JS, gunakan `dangerouslySetInnerHTML` (React) atau `v-html` (Vue) di dalam container prose
- Pastikan konten sudah di-sanitize untuk mencegah XSS sebelum ditempatkan di container prose
