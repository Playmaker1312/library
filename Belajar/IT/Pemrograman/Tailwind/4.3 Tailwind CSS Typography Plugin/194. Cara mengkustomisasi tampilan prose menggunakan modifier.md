# Cara mengkustomisasi tampilan prose menggunakan modifier

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang secara otomatis menata bukunya rapi, tetapi Anda ingin menyesuaikan beberapa rak — misalnya rak novel remaja dengan font lebih besar dan warna lebih cerah. Modifier pada prose seperti instruksi tambahan: "tetap gunakan tata letak default, tapi untuk bagian ini, ubah ini dan itu." Anda tidak perlu mengubah seluruh sistem, cukup tambahkan modifier spesifik.

## Penjelasan Detail
Plugin Typography Tailwind memungkinkan kustomisasi tampilan prose melalui modifier class yang bisa ditambahkan ke container yang sama. Modifier seperti `prose-headings`, `prose-p`, `prose-a`, `prose-blockquote`, `prose-code`, `prose-pre`, `prose-li`, `prose-img`, `prose-h1`, `prose-h2`, `prose-h3`, dan lainnya memungkinkan Anda mengubah gaya untuk elemen spesifik tanpa memengaruhi elemen lain. Modifier ini bisa dikombinasikan dengan utility Tailwind biasa. Misalnya, Anda bisa menggunakan `prose-headings:text-indigo-600` untuk mengubah warna semua heading, atau `prose-a:text-pink-600` untuk mengubah warna link. Modifier juga bisa digunakan dengan variant responsive seperti `lg:prose-lg`. Pendekatan ini memberikan fleksibilitas tinggi tanpa harus menulis CSS kustom.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Kustomisasi Prose dengan Modifier</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          addBase({
            ".prose": {
              maxWidth: "65ch", fontSize: "1rem", lineHeight: "1.75", color: "#374151",
              "& h1": { fontSize: "2.25em", fontWeight: "800", marginBottom: "0.5em", color: "#111827" },
              "& h2": { fontSize: "1.5em", fontWeight: "700", marginBottom: "0.5em", marginTop: "1.5em", color: "#111827" },
              "& p": { marginBottom: "1.25em" },
              "& a": { color: "#2563eb", textDecoration: "underline" },
              "& blockquote": { borderLeft: "4px solid #e5e7eb", paddingLeft: "1em", fontStyle: "italic", color: "#6b7280" },
              "& code": { backgroundColor: "#f3f4f6", padding: "0.2em 0.4em", borderRadius: "0.25rem", fontSize: "0.875em" },
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-8">
    <div class="prose prose-headings:text-indigo-600 prose-a:text-pink-600 prose-a:no-underline hover:prose-a:underline prose-blockquote:border-indigo-400 prose-blockquote:text-indigo-700 prose-code:text-indigo-800 prose-code:bg-indigo-50 bg-white p-8 rounded-xl shadow">
      <h1>Kustomisasi Prose dengan Modifier</h1>
      <p>Artikel ini menggunakan modifier prose. Heading berwarna <span class="text-indigo-600">indigo</span>, link berwarna <span class="text-pink-600">pink</span>, dan blockquote memiliki border indigo.</p>
      <h2>Heading dengan Indigo</h2>
      <p>Modifier <code>prose-headings:text-indigo-600</code> mengubah semua heading menjadi indigo. Coba lihat <a href="#">link ini berwarna pink</a> karena modifier <code>prose-a:text-pink-600</code>.</p>
      <blockquote>Blockquote ini memiliki border indigo-400 dan teks indigo-700, berbeda dari default.</blockquote>
      <p>Kode seperti <code>console.log("Hello")</code> memiliki background indigo-50 dan teks indigo-800.</p>
    </div>

    <div class="bg-gray-900 text-green-400 p-6 rounded-xl">
      <pre class="text-sm">// Contoh kombinasi modifier
&lt;div class="prose
  prose-headings:text-indigo-600
  prose-a:text-pink-600
  prose-a:no-underline
  hover:prose-a:underline
  prose-blockquote:border-indigo-400
  prose-code:bg-indigo-50
"&gt;
  Konten artikel...
&lt;/div&gt;</pre>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan modifier seperti `prose-headings:`, `prose-a:`, `prose-blockquote:` untuk kustomisasi elemen spesifik
- Modifier bisa dikombinasikan dengan utility Tailwind biasa dan variant responsive
- Pendekatan ini memungkinkan kustomisasi tanpa menulis CSS kustom atau mengubah konfigurasi plugin
