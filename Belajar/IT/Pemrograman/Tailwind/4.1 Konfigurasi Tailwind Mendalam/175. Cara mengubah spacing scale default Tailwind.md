# Cara mengubah spacing scale default Tailwind

## Analogi: Perpustakaan Digital
Seperti perpustakaan yang memiliki ukuran rak standar — 30cm, 60cm, 90cm — Tailwind memiliki spacing scale default dengan kelipatan 4px (0.25rem). Terkadang Anda membutuhkan ukuran rak yang tidak ada dalam standar, misalnya 85cm. Di sinilah Anda perlu menambah atau mengubah spacing scale agar sesuai dengan kebutuhan desain spesifik proyek Anda.

## Penjelasan Detail
Spacing scale di Tailwind mengontrol nilai untuk properti padding (p, px, py, pt, pr, pb, pl), margin (m, mx, my, mt, mr, mb, ml), width (w), height (h), gap, dan lainnya. Default scale menggunakan kelipatan 0.25rem (4px) mulai dari 0 hingga 96. Untuk mengubah scale, gunakan `theme.extend.spacing` untuk menambah nilai baru, atau override `theme.spacing` untuk mengganti seluruh scale. Nilai spacing bisa berupa angka (dalam rem) atau string dengan unit (px, em, %, dll). Menambah spacing berguna ketika desain membutuhkan jarak yang tidak tercakup oleh default seperti `13` (3.25rem) atau `18` (4.5rem). Hati-hati saat mengubah scale default karena akan memengaruhi seluruh utility yang menggunakan spacing.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Spacing Scale Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          spacing: {
            13: "3.25rem",
            15: "3.75rem",
            18: "4.5rem",
            25: "6.25rem",
            30: "7.5rem",
          },
        },
      },
    };
  </script>
</head>
<body class="p-10 bg-slate-50">
  <div class="max-w-4xl mx-auto">
    <h1 class="text-3xl font-bold text-slate-800 mb-8">Spacing Scale Kustom</h1>
    <div class="space-y-6">
      <div class="bg-white border-l-4 border-indigo-500 p-4 rounded shadow-sm">
        <p class="text-slate-700"><span class="font-bold">p-4</span> — spacing default (1rem)</p>
      </div>
      <div class="bg-white border-l-4 border-indigo-500 p-13 rounded shadow-sm">
        <p class="text-slate-700"><span class="font-bold">p-13</span> — spacing kustom (3.25rem)</p>
      </div>
      <div class="bg-white border-l-4 border-indigo-500 p-15 rounded shadow-sm">
        <p class="text-slate-700"><span class="font-bold">p-15</span> — spacing kustom (3.75rem)</p>
      </div>
      <div class="bg-white border-l-4 border-indigo-500 p-18 rounded shadow-sm">
        <p class="text-slate-700"><span class="font-bold">p-18</span> — spacing kustom (4.5rem)</p>
      </div>
      <div class="bg-indigo-100 p-4 rounded-lg">
        <h2 class="font-semibold text-indigo-800 mb-2">Contoh Penggunaan Gap</h2>
        <div class="flex gap-13">
          <div class="bg-indigo-500 text-white w-20 h-20 flex items-center justify-center rounded">1</div>
          <div class="bg-indigo-600 text-white w-20 h-20 flex items-center justify-center rounded">2</div>
          <div class="bg-indigo-700 text-white w-20 h-20 flex items-center justify-center rounded">3</div>
        </div>
        <p class="text-sm text-slate-500 mt-2">gap-13 (3.25rem) antar item</p>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Spacing scale default menggunakan kelipatan 0.25rem (4px) dari 0 hingga 96
- Gunakan `theme.extend.spacing` untuk menambah nilai spacing baru tanpa menghapus default
- Nilai spacing bisa berupa angka (dalam rem) atau string dengan unit (px, em, %)
