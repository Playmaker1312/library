# Perbedaan antara theme extend dan theme override dalam konfigurasi

## Analogi: Perpustakaan Digital
Bayangkan Anda memiliki perpustakaan dengan rak default yang sudah diatur rapi. Theme override seperti mengganti seluruh rak dengan rak baru yang berbeda ukuran dan bentuknya — tidak ada yang tersisa dari rak lama. Theme extend seperti menambahkan rak tambahan di samping rak yang sudah ada — rak lama tetap utuh, Anda hanya menambah kapasitas. Keduanya mengubah perpustakaan, tetapi dengan pendekatan yang sangat berbeda.

## Penjelasan Detail
Tailwind secara default memiliki nilai theme yang lengkap untuk warna, spacing, font, breakpoint, dan lainnya. Ketika Anda menulis properti `theme` secara langsung (tanpa `extend`), Anda menimpa seluruh nilai default untuk kategori tersebut. Misalnya, `theme: { colors: { ... } }` akan menghapus semua warna default Tailwind dan hanya menyisakan warna yang Anda definisikan. Sebaliknya, `theme: { extend: { colors: { ... } } }` akan menambahkan warna baru ke dalam palet default yang sudah ada. Override berguna ketika Anda ingin memulai dari awal atau mengganti sistem desain sepenuhnya. Extend berguna ketika Anda hanya ingin menyesuaikan beberapa nilai sambil tetap mempertahankan default. Keduanya bisa digunakan bersamaan dalam satu file konfigurasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Extend vs Override</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          colors: {
            primary: "#6366f1",
            secondary: "#ec4899",
          },
          spacing: {
            72: "18rem",
          },
        },
      },
    };
  </script>
</head>
<body class="p-10 bg-gray-100">
  <div class="max-w-2xl mx-auto space-y-6">
    <div class="bg-white p-6 rounded-xl shadow">
      <h1 class="text-2xl font-bold text-primary mb-4">Extend vs Override</h1>
      <p class="mb-4">Warna <span class="text-primary font-semibold">primary</span> dan <span class="text-secondary font-semibold">secondary</span> adalah warna extend — warna default Tailwind tetap tersedia.</p>
      <div class="flex gap-4 flex-wrap">
        <div class="bg-blue-500 text-white px-4 py-2 rounded">blue-500 (default)</div>
        <div class="bg-primary text-white px-4 py-2 rounded">primary (extend)</div>
        <div class="bg-emerald-500 text-white px-4 py-2 rounded">emerald-500 (default)</div>
        <div class="bg-secondary text-white px-4 py-2 rounded">secondary (extend)</div>
      </div>
    </div>
    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="text-xl font-bold mb-2">Spacing Extended</h2>
      <p>Spacing <code>p-72</code> adalah hasil extend:</p>
      <div class="bg-purple-500 text-white p-72 rounded-lg mt-4 text-center">p-72 (18rem)</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `theme.extend` untuk menambahkan nilai baru tanpa menghapus default Tailwind
- Gunakan override langsung di `theme` ketika ingin mengganti seluruh sistem desain
- Extend adalah pendekatan yang lebih aman dan paling sering digunakan dalam proyek nyata
