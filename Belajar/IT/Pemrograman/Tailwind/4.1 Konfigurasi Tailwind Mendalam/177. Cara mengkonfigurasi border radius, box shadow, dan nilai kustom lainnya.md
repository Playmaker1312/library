# Cara mengkonfigurasi border radius, box shadow, dan nilai kustom lainnya

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki buku dengan berbagai jenis sudut dan bayangan. Ada buku pojok lancip (sharp), pojok sedikit melengkung (rounded), dan pojok sangat melengkung (rounded-full). Bayangan buku juga berbeda — ada yang tipis (shadow-sm) dan ada yang tebal (shadow-lg). Tailwind memungkinkan Anda menyesuaikan semua properti visual ini agar sesuai dengan identitas desain merek Anda.

## Penjelasan Detail
Properti kustom seperti borderRadius, boxShadow, dan lainnya dikonfigurasi di dalam `theme.extend`. Untuk `borderRadius`, nilai dikonversi ke utility seperti `rounded-sm`, `rounded-md`, `rounded-lg`, dan seterusnya. Untuk `boxShadow`, Anda mendefinisikan objek dengan nama dan nilai CSS shadow. Properti lain yang bisa dikustomisasi termasuk `backgroundImage`, `backgroundSize`, `cursor`, `opacity`, `scale`, `rotate`, `translate`, `skew`, `transitionDuration`, `transitionTimingFunction`, `animation`, `keyframes`, dan masih banyak lagi. Tailwind mengelompokkan properti ini ke dalam kategori theme yang terstruktur. Setiap kategori bisa diextend atau dioverride. Untuk animasi kustom, Anda perlu mendefinisikan keyframes terlebih dahulu, lalu animation yang mengacu pada keyframes tersebut.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Konfigurasi Nilai Kustom</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          borderRadius: {
            xs: "0.125rem",
            "4xl": "2rem",
            "5xl": "3rem",
          },
          boxShadow: {
            soft: "0 2px 15px -3px rgba(0, 0, 0, 0.07), 0 10px 20px -2px rgba(0, 0, 0, 0.04)",
            glow: "0 0 15px rgba(99, 102, 241, 0.4)",
          },
          animation: {
            "bounce-slow": "bounce 3s infinite",
          },
        },
      },
    };
  </script>
</head>
<body class="p-10 bg-gradient-to-br from-slate-50 to-slate-100">
  <div class="max-w-4xl mx-auto space-y-8">
    <h1 class="text-3xl font-bold text-slate-800">Nilai Kustom Border & Shadow</h1>
    <div class="grid grid-cols-3 gap-6">
      <div class="rounded-xs bg-white p-6 shadow-soft text-center">rounded-xs + shadow-soft</div>
      <div class="rounded-lg bg-white p-6 shadow-soft text-center">rounded-lg + shadow-soft</div>
      <div class="rounded-4xl bg-white p-6 shadow-soft text-center">rounded-4xl + shadow-soft</div>
      <div class="rounded-xl bg-white p-6 shadow-glow text-center">rounded-xl + shadow-glow</div>
      <div class="rounded-5xl bg-white p-6 shadow-glow text-center">rounded-5xl + shadow-glow</div>
      <div class="rounded-full bg-white p-6 shadow-glow text-center">rounded-full + shadow-glow</div>
    </div>
    <div class="bg-indigo-500 text-white p-6 rounded-xl animate-bounce-slow text-center">animate-bounce-slow</div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `theme.extend.borderRadius` dan `theme.extend.boxShadow` untuk menambah variasi baru
- Untuk animasi kustom, definisikan keyframes dan animation secara terpisah di konfigurasi
- Nilai kustom bisa diberi nama apa saja dan akan menghasilkan utility class sesuai nama tersebut
