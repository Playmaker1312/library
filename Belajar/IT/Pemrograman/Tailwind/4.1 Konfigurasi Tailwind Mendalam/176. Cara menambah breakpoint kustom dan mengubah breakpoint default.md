# Cara menambah breakpoint kustom dan mengubah breakpoint default

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki area baca dengan ukuran berbeda: sudut kecil untuk 1-2 orang (sm), meja sedang untuk 3-4 orang (md), dan ruang besar untuk kelompok (lg). Ketika Anda membutuhkan area sangat besar untuk seminar (xl) atau area sangat kecil untuk baca privat (xs), Anda perlu menambah atau mengubah ukuran area yang tersedia. Breakpoint Tailwind bekerja persis seperti ini — menentukan tata letak berdasarkan lebar layar.

## Penjelasan Detail
Breakpoint default Tailwind adalah sm (640px), md (768px), lg (1024px), xl (1280px), dan 2xl (1536px). Untuk mengubah breakpoint yang ada, Anda bisa override properti `theme.screens`. Untuk menambah breakpoint baru, gunakan `theme.extend.screens`. Tailwind menggunakan pendekatan mobile-first, artinya breakpoint berlaku sebagai batas minimal (min-width). Anda juga bisa mendefinisikan breakpoint dengan max-width menggunakan sintaks `{ 'max-sm': { 'max': '639px' } }`. Breakpoint kustom memungkinkan desain yang lebih responsif dan sesuai dengan kebutuhan spesifik produk. Pastikan untuk menguji breakpoint di berbagai perangkat nyata, tidak hanya di dev tools browser.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Breakpoint Kustom Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          screens: {
            xs: "480px",
            tablet: "900px",
            desktop: "1440px",
          },
        },
      },
    };
  </script>
</head>
<body class="p-6 bg-slate-50">
  <div class="max-w-7xl mx-auto">
    <h1 class="text-3xl font-bold text-slate-800 mb-6">Breakpoint Kustom</h1>
    <div class="grid grid-cols-1 xs:grid-cols-2 tablet:grid-cols-3 desktop:grid-cols-4 gap-4">
      <div class="bg-white p-6 rounded-xl shadow-sm text-center">
        <div class="text-4xl mb-2">📱</div>
        <p class="font-semibold">xs: 480px</p>
        <p class="text-sm text-slate-500">1 kolom → 2 kolom</p>
      </div>
      <div class="bg-white p-6 rounded-xl shadow-sm text-center">
        <div class="text-4xl mb-2">📋</div>
        <p class="font-semibold">sm: 640px (default)</p>
        <p class="text-sm text-slate-500">Breakpoint standar</p>
      </div>
      <div class="bg-white p-6 rounded-xl shadow-sm text-center">
        <div class="text-4xl mb-2">💻</div>
        <p class="font-semibold">tablet: 900px</p>
        <p class="text-sm text-slate-500">2 kolom → 3 kolom</p>
      </div>
      <div class="bg-white p-6 rounded-xl shadow-sm text-center">
        <div class="text-4xl mb-2">🖥️</div>
        <p class="font-semibold">desktop: 1440px</p>
        <p class="text-sm text-slate-500">3 kolom → 4 kolom</p>
      </div>
    </div>
    <div class="mt-8 bg-indigo-50 p-6 rounded-xl">
      <h2 class="font-semibold text-indigo-800 mb-3">Cara Mengubah Breakpoint Default</h2>
      <pre class="bg-slate-900 text-green-400 p-4 rounded text-sm">
tailwind.config = {
  theme: {
    screens: {
      sm: '640px',
      md: '768px',
      lg: '1024px',
      xl: '1280px',
      '2xl': '1536px',
      // override: ganti lg jadi 1100px
      lg: '1100px',
    },
  },
};</pre>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Breakpoint default bersifat mobile-first (min-width) dan bisa diubah atau ditambah via `theme.screens`
- Gunakan `theme.extend.screens` untuk menambah breakpoint baru tanpa mengubah default
- Breakpoint dengan max-width bisa dibuat menggunakan sintaks objek `{ 'max': 'value' }`
