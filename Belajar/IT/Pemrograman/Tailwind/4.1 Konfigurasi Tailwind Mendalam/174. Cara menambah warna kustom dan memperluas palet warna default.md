# Cara menambah warna kustom dan memperluas palet warna default

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan memiliki sistem kode warna untuk rak buku — biru untuk fiksi, merah untuk non-fiksi, hijau untuk referensi. Ketika kategori buku baru muncul, Anda tidak perlu mengecat ulang seluruh perpustakaan, cukup tambahkan kode warna baru. Di Tailwind, palet warna default seperti kode warna standar perpustakaan, dan Anda bisa memperluasnya dengan warna kustom untuk kebutuhan spesifik proyek.

## Penjelasan Detail
Warna di Tailwind didefinisikan sebagai objek bersarang dengan variasi shade dari 50 hingga 950 (misalnya `blue-500`, `blue-700`). Untuk menambah warna kustom, gunakan `theme.extend.colors` dan definisikan struktur yang sama. Anda bisa membuat warna dengan shade lengkap atau warna flat (tanpa variasi). Tailwind juga mendukung nested object untuk organisasi yang lebih baik, seperti `colors: { brand: { light, DEFAULT, dark } }`. Nilai `DEFAULT` akan digunakan ketika tidak ada shade yang disebutkan. Warna kustom bisa menggunakan format HEX, RGB, HSL, atau nama warna CSS. Best practice adalah menggunakan sistem desain yang konsisten dan mendokumentasikan palet warna untuk kolaborasi tim.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Warna Kustom Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          colors: {
            brand: {
              50: "#eff6ff",
              100: "#dbeafe",
              200: "#bfdbfe",
              300: "#93c5fd",
              400: "#60a5fa",
              500: "#3b82f6",
              600: "#2563eb",
              700: "#1d4ed8",
              DEFAULT: "#2563eb",
            },
            accent: {
              coral: "#ff7f50",
              teal: "#14b8a6",
              gold: "#f59e0b",
            },
          },
        },
      },
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-4xl mx-auto">
    <h1 class="text-3xl font-bold text-brand mb-8">Palet Warna Kustom</h1>
    <div class="grid grid-cols-5 gap-4 mb-8">
      <div class="bg-brand-50 text-brand-700 p-4 rounded text-center text-sm">50</div>
      <div class="bg-brand-100 text-brand-800 p-4 rounded text-center text-sm">100</div>
      <div class="bg-brand-200 text-brand-900 p-4 rounded text-center text-sm">200</div>
      <div class="bg-brand-300 text-white p-4 rounded text-center text-sm">300</div>
      <div class="bg-brand-400 text-white p-4 rounded text-center text-sm">400</div>
      <div class="bg-brand-500 text-white p-4 rounded text-center text-sm">500</div>
      <div class="bg-brand-600 text-white p-4 rounded text-center text-sm">600</div>
      <div class="bg-brand-700 text-white p-4 rounded text-center text-sm">700</div>
      <div class="bg-brand text-white p-4 rounded text-center text-sm">DEFAULT</div>
    </div>
    <h2 class="text-xl font-semibold mb-4">Warna Accent Flat</h2>
    <div class="flex gap-4">
      <div class="bg-accent-coral text-white px-6 py-3 rounded-lg">coral</div>
      <div class="bg-accent-teal text-white px-6 py-3 rounded-lg">teal</div>
      <div class="bg-accent-gold text-white px-6 py-3 rounded-lg">gold</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `theme.extend.colors` untuk menambah warna kustom tanpa kehilangan palet default
- Warna dengan shade (50-950) memberikan fleksibilitas lebih dibanding warna flat
- Properti `DEFAULT` pada objek warna digunakan saat tidak ada angka shade yang dispesifikasikan
