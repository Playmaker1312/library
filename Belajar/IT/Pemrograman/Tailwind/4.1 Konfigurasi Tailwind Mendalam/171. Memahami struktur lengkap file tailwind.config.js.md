# Memahami struktur lengkap file tailwind.config.js

## Analogi: Perpustakaan Digital
Bayangkan tailwind.config.js adalah katalog induk sebuah perpustakaan digital. Katalog ini berisi daftar lengkap semua buku (utility classes), kategori (plugins), aturan peminjaman (theme), dan konfigurasi rak (variants) yang tersedia. Setiap kali pustakawan (Tailwind) ingin mencari sesuatu, ia merujuk pada katalog ini. Jika ingin menambahkan buku baru atau mengubah aturan, katalog inilah yang diedit. Semakin rapi katalognya, semakin efisien pustakawan bekerja.

## Penjelasan Detail
File tailwind.config.js adalah file konfigurasi utama dalam proyek Tailwind CSS. File ini menggunakan format JavaScript module export dan berisi objek besar dengan beberapa properti kunci. Properti `content` (sebelumnya `purge`) mendefinisikan file mana yang akan dipindai untuk class Tailwind. Properti `theme` berisi semua nilai desain seperti warna, font, spacing, breakpoint, dan lainnya. Di dalam `theme`, terdapat sub-properti `extend` untuk menambahkan nilai baru tanpa menimpa default. Properti `plugins` digunakan untuk mendaftarkan plugin eksternal atau kustom. Properti `darkMode` mengontrol strategi dark mode. Properti `variants` (deprecated di v3) mengontrol varian apa yang tersedia untuk setiap utility. Properti `prefix` memungkinkan penambahan awalan pada semua class Tailwind. Properti `important` dapat mengubah selektor menjadi `!important`. Memahami setiap bagian dari struktur ini adalah kunci untuk menguasai Tailwind secara profesional.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Struktur tailwind.config.js</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      content: ["./src/**/*.{html,js}"],
      darkMode: "class",
      theme: {
        screens: {
          sm: "640px",
          md: "768px",
          lg: "1024px",
          xl: "1280px",
        },
        extend: {
          colors: {
            brand: { light: "#3b82f6", DEFAULT: "#2563eb", dark: "#1d4ed8" },
          },
          fontFamily: {
            heading: ["Poppins", "sans-serif"],
          },
          spacing: {
            18: "4.5rem",
          },
        },
      },
      plugins: [],
    };
  </script>
</head>
<body class="bg-gray-50 p-10">
  <div class="max-w-3xl mx-auto">
    <h1 class="font-heading text-3xl text-brand mb-6">Struktur tailwind.config.js</h1>
    <pre class="bg-gray-900 text-green-400 p-6 rounded-lg overflow-x-auto text-sm">
tailwind.config = {
  content: ['./src/**/*.{html,js}'],
  darkMode: 'class',
  theme: {
    screens: { sm: '640px', md: '768px', lg: '1024px', xl: '1280px' },
    extend: {
      colors: { brand: { light: '#3b82f6', DEFAULT: '#2563eb', dark: '#1d4ed8' } },
      fontFamily: { heading: ['Poppins', 'sans-serif'] },
    }
  },
  plugins: [],
}</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Properti `content` wajib diisi agar Tailwind tahu file mana yang perlu dipindai untuk generate class
- Gunakan `theme.extend` untuk menambah nilai kustom tanpa menimpa konfigurasi default Tailwind
- Properti `plugins` memungkinkan penambahan fungsionalitas eksternal seperti typography, forms, dan container-queries
