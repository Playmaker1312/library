# Cara menambah font kustom ke dalam konfigurasi Tailwind

## Analogi: Perpustakaan Digital
Seperti perpustakaan yang memiliki beberapa jenis huruf untuk katalognya — font serif untuk buku klasik, sans-serif untuk buku modern, dan monospace untuk buku teknis — Tailwind memungkinkan Anda mendaftarkan font keluarga yang berbeda. Dengan menambahkan font kustom ke konfigurasi, Anda memberi Tailwind "kosakata" baru untuk digunakan di seluruh proyek melalui class seperti `font-heading` atau `font-body`.

## Penjelasan Detail
Untuk menambahkan font kustom di Tailwind, Anda perlu memperluas properti `fontFamily` di dalam `theme.extend`. Setiap entri font menerima array string yang berisi nama font dan fallback. Font kustom harus diimpor terlebih dahulu melalui Google Fonts, @font-face, atau file lokal sebelum digunakan. Anda bisa membuat beberapa kategori font seperti `heading`, `body`, `display`, atau `mono`. Tailwind akan menghasilkan utility class seperti `font-heading`, `font-body`, dll. Pastikan untuk menyertakan fallback font yang sesuai (seperti `sans-serif`, `serif`, atau `monospace`) agar tampilan tetap baik jika font kustom gagal dimuat. Best practice adalah mendaftarkan font di konfigurasi daripada menggunakan class arbitrer setiap kali.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Font Kustom Tailwind</title>
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&family=Playfair+Display:wght@400;700&family=Fira+Code:wght@400;600&display=swap" rel="stylesheet" />
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      theme: {
        extend: {
          fontFamily: {
            heading: ["Playfair Display", "serif"],
            body: ["Inter", "system-ui", "sans-serif"],
            code: ["Fira Code", "monospace"],
          },
        },
      },
    };
  </script>
</head>
<body class="font-body p-10 bg-stone-50">
  <div class="max-w-3xl mx-auto space-y-8">
    <div>
      <h1 class="font-heading text-4xl text-stone-800">Playfair Display — Heading</h1>
      <p class="text-stone-600 mt-2">Font ini digunakan untuk judul dan subjudul.</p>
    </div>
    <div>
      <h2 class="font-heading text-2xl text-stone-700">Tentang Font Kustom</h2>
      <p class="text-stone-700 leading-relaxed">Ini paragraf menggunakan Inter sebagai font body. Font ini nyaman dibaca untuk teks panjang. Perhatikan bagaimana setiap font memberikan nuansa berbeda pada halaman.</p>
    </div>
    <div>
      <pre class="font-code bg-stone-900 text-lime-400 p-4 rounded-lg text-sm">
const greeting = "Hello, Tailwind!";
console.log(greeting);</pre>
    </div>
    <div class="flex gap-4">
      <span class="font-heading bg-stone-200 px-3 py-1 rounded">font-heading</span>
      <span class="font-body bg-stone-200 px-3 py-1 rounded">font-body</span>
      <span class="font-code bg-stone-200 px-3 py-1 rounded">font-code</span>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Daftarkan font kustom di `theme.extend.fontFamily` dengan array berisi nama font dan fallback
- Import font terlebih dahulu via Google Fonts, @font-face, atau CDN sebelum digunakan
- Buat beberapa kategori font (heading, body, code, display) untuk fleksibilitas maksimal
