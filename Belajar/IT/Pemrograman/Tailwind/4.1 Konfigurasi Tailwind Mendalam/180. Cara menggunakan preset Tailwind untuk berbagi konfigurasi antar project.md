# Cara menggunakan preset Tailwind untuk berbagi konfigurasi antar project

## Analogi: Perpustakaan Digital
Bayangkan Anda mengelola jaringan perpustakaan di beberapa kota. Setiap perpustakaan memiliki aturan dan tata letak yang sama, tetapi beberapa memiliki koleksi tambahan yang unik. Daripada mengatur ulang setiap perpustakaan dari nol, Anda membuat "preset" berupa buku panduan standar yang dikirim ke semua cabang. Setiap cabang kemudian bisa menambahkan penyesuaian lokal. Preset Tailwind bekerja seperti panduan standar ini.

## Penjelasan Detail
Preset di Tailwind adalah objek konfigurasi yang bisa dibagikan ke beberapa project. Anda mendefinisikan preset di properti `preset` dalam array di tailwind.config.js. Preset bisa berisi konfigurasi theme, plugins, darkMode, dan lainnya. Preset memungkinkan tim untuk mempertahankan konsistensi desain di seluruh ekosistem project. Anda bisa membuat preset sebagai package npm terpisah, atau file lokal yang diimport. Preset bisa digabungkan dengan konfigurasi lokal, di mana konfigurasi lokal akan menimpa preset jika ada konflik. Ini mirip dengan konsep inheritance di OOP. Anda bisa memiliki beberapa preset yang digabungkan, dan urutannya menentukan prioritas.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Preset Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    const designPreset = {
      theme: {
        extend: {
          colors: {
            brand: { light: "#818cf8", DEFAULT: "#6366f1", dark: "#4f46e5" },
          },
          fontFamily: {
            sans: ["Inter", "system-ui", "sans-serif"],
          },
        },
      },
    };

    tailwind.config = {
      presets: [designPreset],
      theme: {
        extend: {
          colors: {
            accent: "#f59e0b",
          },
        },
      },
    };
  </script>
</head>
<body class="p-10 bg-gray-50 font-sans">
  <div class="max-w-2xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-brand">Preset Tailwind untuk Berbagi Konfigurasi</h1>
    <p class="text-gray-600">Warna brand berasal dari preset, warna accent dari konfigurasi lokal.</p>
    <div class="flex gap-4">
      <div class="bg-brand text-white px-6 py-3 rounded-lg">brand (dari preset)</div>
      <div class="bg-accent text-white px-6 py-3 rounded-lg">accent (konfigurasi lokal)</div>
    </div>
    <div class="bg-gray-900 text-green-400 p-4 rounded text-sm mt-6">
      <pre>// preset.js (shared)
module.exports = {
  theme: {
    extend: {
      colors: { brand: { light: '#818cf8', DEFAULT: '#6366f1', dark: '#4f46e5' } },
      fontFamily: { sans: ['Inter', 'system-ui', 'sans-serif'] },
    },
  },
};

// tailwind.config.js (lokal)
module.exports = {
  presets: [require('./preset')],
  theme: {
    extend: {
      colors: { accent: '#f59e0b' },
    },
  },
};</pre>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Preset memungkinkan berbagi konfigurasi Tailwind antar project melalui properti `presets`
- Preset bisa berupa package npm atau file lokal, dan bisa digabungkan dengan konfigurasi lokal
- Konfigurasi lokal akan menimpa preset jika ada properti yang sama (override)
