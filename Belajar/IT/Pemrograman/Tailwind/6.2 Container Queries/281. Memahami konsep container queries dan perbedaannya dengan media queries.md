# Memahami konsep container queries dan perbedaannya dengan media queries

## Analogi: Perpustakaan Digital

Media queries seperti aturan yang bergantung pada ukuran ruangan perpustakaan—apakah ruangannya besar atau kecil, semua rak akan mengikuti aturan yang sama. Container queries seperti rak pintar yang menyesuaikan buku di dalamnya berdasarkan ukuran rak itu sendiri. Di ruangan besar, Anda punya rak lebar dan sempit; container queries memungkinkan setiap rak menata bukunya secara optimal terlepas dari ukuran ruangan.

## Penjelasan Detail

Media queries merespons ukuran viewport browser, yang berarti satu set aturan berlaku untuk seluruh halaman pada ukuran layar tertentu. Container queries, sebaliknya, merespons ukuran elemen container tertentu, memungkinkan komponen yang sama memiliki tampilan berbeda tergantung di mana ia ditempatkan. Container queries mengatasi masalah komponen yang tidak portabel—sebuah card yang tampak bagus di sidebar (sempit) mungkin terlalu kecil di main content (lebar) tanpa container queries. Dengan container queries, komponen menjadi "responsif terhadap konteksnya," bukan responsif terhadap layar. Browser modern telah mendukung container queries sejak 2023, dan Tailwind menyediakan utility class yang membuat penggunaannya semudah media queries.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Container vs Media Queries</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans space-y-8">
  <div class="grid grid-cols-1 md:grid-cols-3 gap-4">
    <!-- Ketiga card ini punya container berbeda -->
    <!-- Card di kolom sempit -->
    <div class="@container p-2 bg-gray-50 rounded-xl border">
      <div class="@lg:flex @lg:gap-3">
        <div class="size-12 @lg:size-20 bg-blue-500 rounded-lg mb-2 @lg:mb-0"></div>
        <div>
          <h3 class="font-bold @lg:text-xl">Card di kolom sempit</h3>
          <p class="text-sm @lg:text-base">Teks menyesuaikan ukuran container.</p>
        </div>
      </div>
    </div>
    <!-- Kolom sedang -->
    <div class="@container p-2 bg-gray-50 rounded-xl border">
      <div class="@lg:flex @lg:gap-3">
        <div class="size-12 @lg:size-20 bg-green-500 rounded-lg mb-2 @lg:mb-0"></div>
        <div>
          <h3 class="font-bold @lg:text-xl">Card di kolom sedang</h3>
          <p class="text-sm @lg:text-base">Layout berubah di @lg.</p>
        </div>
      </div>
    </div>
    <!-- Kolom lebar -->
    <div class="@container p-2 bg-gray-50 rounded-xl border">
      <div class="@lg:flex @lg:gap-3">
        <div class="size-12 @lg:size-20 bg-purple-500 rounded-lg mb-2 @lg:mb-0"></div>
        <div>
          <h3 class="font-bold @lg:text-xl">Card di kolom lebar</h3>
          <p class="text-sm @lg:text-base">Semua responsif terhadap container masing-masing.</p>
        </div>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting

- Media queries berdasarkan ukuran viewport; container queries berdasarkan ukuran container
- Container queries membuat komponen portabel dan benar-benar reusable
- Tailwind memudahkan container queries dengan prefix `@` yang intuitif
