# Menggunakan container-name untuk named containers

## Analogi: Perpustakaan Digital

Named containers seperti memberi nama pada setiap rak buku sehingga Anda bisa merujuknya secara spesifik. Tanpa nama, container queries akan mencari rak terdekat yang memiliki `@container`. Dengan nama, Anda bisa berkata "Rak Favorit, atur buku ini dengan gaya A" atau "Rak Referensi, atur buku ini dengan gaya B." Ini penting ketika ada container yang bersarang di dalam container lain dan Anda ingin query pada container tertentu, bukan yang terdekat.

## Penjelasan Detail

`container-name` memungkinkan Anda memberi identitas unik pada container, sehingga query dapat menargetkan container spesifik. Di Tailwind, nama container ditambahkan dengan class `@container-{nama}`. Misalnya, `@container-sidebar` pada elemen akan membuat container bernama "sidebar." Query kemudian bisa menggunakan `@sidebar-md:text-lg` untuk menargetkan container "sidebar" secara spesifik. Named containers sangat berguna dalam komponen bersarang di mana terdapat beberapa containment context. Jika container tidak ditemukan dengan nama yang diminta, query akan diabaikan. `container-name` bisa berisi beberapa nama yang dipisahkan spasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Named Containers</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans space-y-6">
  <!-- Named container: sidebar -->
  <div class="@container-sidebar border-2 border-blue-300 p-4 rounded-xl">
    <h3 class="font-bold mb-2">Container: sidebar</h3>
    <div class="@sidebar-md:bg-blue-100 @sidebar-md:p-4 @sidebar-md:rounded-lg">
      <p class="@sidebar-md:text-lg @sidebar-lg:text-xl">
        Query spesifik ke container "sidebar"
      </p>
    </div>

    <!-- Container bersarang dengan nama berbeda -->
    <div class="@container-card border border-dashed border-gray-400 p-3 mt-3 rounded-lg">
      <p class="@card-md:text-sm @sidebar-md:text-base">
        Bersarang: responsif terhadap "card" dan "sidebar"
      </p>
    </div>
  </div>

  <!-- Named container: main -->
  <div class="@container-main border-2 border-purple-300 p-4 rounded-xl">
    <h3 class="font-bold mb-2">Container: main</h3>
    <div class="@main-md:bg-purple-100 @main-md:p-4 @main-md:rounded-lg">
      <p class="@main-md:text-lg @main-lg:text-2xl">
        Query spesifik ke container "main"
      </p>
    </div>
  </div>

  <div class="text-sm text-gray-500">
    Setiap container merespons secara independen dengan namanya masing-masing.
  </div>
</body>
</html>
```

## Poin Penting

- `@container-{nama}` untuk membuat named container
- Query menggunakan `@{nama}-{ukuran}:{utility}` untuk menarget container spesifik
- Named containers penting dalam komponen bersarang dengan banyak containment context
