# Cara menggunakan plugin container-queries resmi di Tailwind v3

## Analogi: Perpustakaan Digital

Di Tailwind v3, container queries seperti fitur khusus yang memerlukan kunci akses terpisah (plugin). Perpustakaan menyediakan fitur ini di lantai yang berbeda—Anda harus naik lift (menginstall plugin) untuk mengaksesnya. Setelah sampai, sistemnya mirip dengan container queries di v4, tetapi Anda harus selalu ingat membawa kunci akses itu setiap kali ingin menggunakannya.

## Penjelasan Detail

Di Tailwind v3, container queries tersedia melalui plugin resmi `@tailwindcss/container-queries`. Setelah menginstal plugin dan menambahkannya ke `tailwind.config.js`, Anda bisa menggunakan class `@container` pada elemen parent dan prefix `@sm`, `@md`, `@lg`, `@xl`, `@2xl` untuk styling berbasis ukuran container. Ukuran default container queries mengikuti breakpoints Tailwind tetapi bisa dikustomisasi. Plugin ini mendukung `container-type` melalui class `@container-normal` (default, inline-size) dan `@container-size` (both axes). Sayangnya, plugin ini tidak mendukung named containers—semua container queries berdasarkan container terdekat yang memiliki class `@container`.

## Contoh Kode Implementasi

```bash
npm install @tailwindcss/container-queries
```

```js
// tailwind.config.js
module.exports = {
  content: ["./src/**/*.{html,js}"],
  theme: {
    extend: {},
  },
  plugins: [
    require("@tailwindcss/container-queries"),
  ],
};
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link href="/dist/output.css" rel="stylesheet">
  <title>Container Queries di v3</title>
</head>
<body class="p-8 font-sans">
  <div class="@container border-2 border-dashed border-gray-300 p-4 rounded-lg">
    <div class="grid @sm:grid-cols-2 @lg:grid-cols-3 gap-4">
      <div class="bg-blue-100 p-3 rounded">Item 1</div>
      <div class="bg-blue-100 p-3 rounded">Item 2</div>
      <div class="bg-blue-100 p-3 rounded">Item 3</div>
    </div>
    <p class="mt-4 text-sm @lg:text-lg @xl:text-xl">
      Teks ini berubah ukuran berdasarkan container
    </p>
  </div>
</body>
</html>
```

## Poin Penting

- Plugin `@tailwindcss/container-queries` diperlukan di v3 untuk container queries
- Class `@container` mengaktifkan containment; prefix `@sm`, `@lg`, dll. untuk query
- Ukuran container queries mengikuti breakpoints Tailwind dan bisa dikustomisasi
