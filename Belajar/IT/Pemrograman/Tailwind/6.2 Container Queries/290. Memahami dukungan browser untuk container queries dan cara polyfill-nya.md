# Memahami dukungan browser untuk container queries dan cara polyfill-nya

## Analogi: Perpustakaan Digital

Container queries adalah fitur perpustakaan modern yang baru dipasang tahun lalu. Sebagian besar pengunjung (browser modern) sudah bisa menggunakannya tanpa masalah. Tapi beberapa pengunjung dengan kacamata lama (browser lawas) mungkin tidak melihat perubahan ukuran buku secara otomatis. Untuk mereka, Anda perlu menyediakan kaca pembesar (polyfill) agar pengalaman tetap konsisten.

## Penjelasan Detail

Container queries (`container-type`, `container-name`, `@container`) didukung penuh di Chrome 105+, Edge 105+, Safari 16+, dan Firefox 110+. Inti dukungan sudah stabil sejak pertengahan 2023. Untuk browser lama (terutama versi lama Safari dan Firefox), polyfill seperti `container-query-polyfill` bisa digunakan. Polyfill ini bekerja dengan meniru perilaku container queries menggunakan JavaScript dan ResizeObserver, memungkinkan penggunaan container queries di browser yang belum mendukung. Namun polyfill memiliki keterbatasan: tidak bisa mendeteksi perubahan pada pseudo-elements dan mungkin menurunkan performa pada halaman dengan banyak container. Untuk penggunaan production, disarankan memeriksa dukungan dengan `@supports (container-type: inline-size)`.

## Contoh Kode Implementasi

```bash
npm install container-query-polyfill
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dukungan Container Queries</title>
  <style>
    @import "tailwindcss";

    /* Feature query untuk deteksi */
    @supports (container-type: inline-size) {
      .cq-warning { display: none; }
    }

    @supports not (container-type: inline-size) {
      .cq-info { display: none; }
    }
  </style>
</head>
<body class="p-8 font-sans">
  <!-- Deteksi dukungan -->
  <div class="cq-warning bg-yellow-100 border border-yellow-400 text-yellow-800 p-4 rounded-lg mb-4">
    Browser Anda belum mendukung container queries. Polyfill akan diaktifkan.
  </div>
  <div class="cq-info bg-green-100 border border-green-400 text-green-800 p-4 rounded-lg mb-4">
    Browser Anda mendukung container queries. Polyfill tidak diperlukan.
  </div>

  <!-- Container queries tetap berjalan -->
  <div class="@container border-2 border-gray-300 p-4 rounded-xl">
    <div class="@lg:flex @lg:gap-4">
      <div class="size-12 @lg:size-20 bg-blue-500 rounded-lg"></div>
      <p class="@lg:text-xl mt-2 @lg:mt-0">Container queries aktif!</p>
    </div>
  </div>

  <script type="module">
    // Polyfill container queries jika diperlukan
    if (!CSS.supports("container-type: inline-size")) {
      const { polyfill } = await import("container-query-polyfill");
      polyfill();
    }
  </script>
</body>
</html>
```

## Poin Penting

- Didukung penuh di Chrome, Edge, Safari 16+, Firefox 110+ (sejak 2023)
- Gunakan `container-query-polyfill` untuk browser lama
- Deteksi dukungan dengan `@supports (container-type: inline-size)`
