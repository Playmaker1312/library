# Menggunakan container-type yaitu inline-size dan size

## Analogi: Perpustakaan Digital

`container-type` seperti Anda memberi tahu rak buku apakah harus memperhatikan lebar saja atau lebar dan tinggi sekaligus. `inline-size` (default) seperti rak yang hanya peduli pada seberapa lebar buku bisa dijajarkan. `size` seperti rak yang peduli pada volume total buku—lebar dan tinggi. Kebanyakan kasus cukup dengan `inline-size` karena layout web umumnya mengalir secara horizontal. Gunakan `size` hanya jika tinggi container juga memengaruhi tata letak.

## Penjelasan Detail

`container-type` menentukan sumbu mana yang akan dipantau oleh container queries. Nilai `inline-size` (default) hanya memantau perubahan pada lebar container (inline axis dalam mode writing horizontal), yang mencakup sebagian besar use case layout web. Nilai `size` memantau perubahan pada lebar dan tinggi container, tetapi mengubah `contain` menjadi `layout style size` yang bisa memengaruhi performa. Di Tailwind, `@container` secara default menggunakan `container-type: inline-size`. Untuk menggunakan `size`, tambahkan class `@container-size`. Class `@container-normal` secara eksplisit menonaktifkan containment tetapi mempertahankan nama container.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Container Type</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans space-y-8">
  <!-- inline-size (default) - hanya pantau lebar -->
  <div class="@container border-2 border-green-300 p-4 rounded-xl">
    <h3 class="font-bold mb-2">container-type: inline-size (default)</h3>
    <div class="@lg:flex @lg:gap-4">
      <div class="size-16 @lg:size-24 bg-green-400 rounded-lg"></div>
      <p class="@lg:text-xl">Lebar saja yang dipantau.</p>
    </div>
  </div>

  <!-- size - pantau lebar dan tinggi -->
  <div class="@container-size border-2 border-orange-300 p-4 rounded-xl min-h-[200px]">
    <h3 class="font-bold mb-2">container-type: size</h3>
    <div class="@lg:flex @lg:gap-4 @[300px]:bg-orange-100">
      <div class="size-16 @lg:size-24 bg-orange-400 rounded-lg"></div>
      <p class="@lg:text-xl">Lebar dan tinggi dipantau.</p>
      <p class="text-sm text-gray-500 mt-2">Resize vertikal juga memicu perubahan.</p>
    </div>
  </div>

  <!-- Perbandingan -->
  <div class="grid grid-cols-2 gap-4">
    <div class="@container p-4 bg-blue-50 rounded-xl">
      <code class="text-sm">@container</code> (inline-size)
    </div>
    <div class="@container-size p-4 bg-orange-50 rounded-xl">
      <code class="text-sm">@container-size</code> (size)
    </div>
  </div>
</body>
</html>
```

## Poin Penting

- `@container` = `container-type: inline-size` (hanya pantau lebar) — default
- `@container-size` = `container-type: size` (pantau lebar dan tinggi)
- Gunakan `inline-size` untuk sebagian besar kasus; `size` hanya jika tinggi signifikan
