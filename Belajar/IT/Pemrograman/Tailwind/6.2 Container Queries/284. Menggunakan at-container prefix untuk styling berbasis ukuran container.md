# Menggunakan at-container prefix untuk styling berbasis ukuran container

## Analogi: Perpustakaan Digital

Prefix `@` pada class Tailwind seperti label yang berubah tergantung ukuran rak buku. Jika raknya kecil, label menunjukkan judul pendek; jika raknya besar, label menunjukkan judul lengkap plus deskripsi. Anda tidak perlu mengatur ini untuk setiap rak secara manual—cukup tempel aturan `@sm` atau `@lg` pada elemen, dan rak akan menyesuaikan secara otomatis. Ini seperti buku dengan tinta yang berubah ukuran sesuai tempatnya diletakkan.

## Penjelasan Detail

Prefix `@` diikuti ukuran container (misal `@sm`, `@md`, `@lg`) digunakan persis seperti prefix media queries (`sm:`, `md:`, `lg:`) tetapi container queries bekerja berdasarkan ukuran container terdekat yang memiliki `@container`. Sintaksnya adalah `@{ukuran}:{utility}`—contohnya `@lg:text-2xl` yang berarti "ukuran font 2xl ketika container minimal ukuran lg." Semua utility Tailwind bisa dikombinasikan dengan prefix container queries. Yang membedakan dari media queries: jika sebuah komponen berada dalam container 300px, class `@lg:text-2xl` akan aktif jika container tersebut memenuhi syarat ukuran lg, terlepas dari ukuran viewport. Ini memungkinkan komponen beradaptasi secara independen terhadap konteksnya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>At-Container Prefix</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans">
  <!-- Demo berbagai prefix container queries -->
  <div class="@container border-2 border-indigo-200 p-4 rounded-xl space-y-4">
    <!-- Layout grid berubah -->
    <div class="grid @sm:grid-cols-2 @md:grid-cols-3 @lg:grid-cols-4 gap-3">
      <div class="bg-indigo-100 p-3 rounded-lg @md:bg-indigo-200 @lg:bg-indigo-300">1</div>
      <div class="bg-indigo-100 p-3 rounded-lg @md:bg-indigo-200 @lg:bg-indigo-300">2</div>
      <div class="bg-indigo-100 p-3 rounded-lg @md:bg-indigo-200 @lg:bg-indigo-300">3</div>
      <div class="bg-indigo-100 p-3 rounded-lg @md:bg-indigo-200 @lg:bg-indigo-300">4</div>
    </div>

    <!-- Tipografi berubah -->
    <p class="@sm:text-sm @md:text-base @lg:text-lg @xl:text-xl text-gray-600">
      Teks ini berubah ukuran berdasarkan container width.
    </p>

    <!-- Padding dan margin -->
    <div class="@md:p-6 @lg:p-8 bg-white rounded-lg shadow-sm @md:shadow-md @lg:shadow-lg">
      <p class="@md:font-semibold">Shadow dan padding juga responsif terhadap container.</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting

- Prefix `@{ukuran}:{utility}` untuk menulis style berbasis ukuran container
- Bekerja seperti media queries prefix tetapi berdasarkan container terdekat
- Semua utility Tailwind bisa dikombinasikan dengan prefix container queries
