# Cara menggunakan container queries built-in di Tailwind v4

## Analogi: Perpustakaan Digital

Di Tailwind v4, container queries sudah menjadi bagian dari perabotan standar perpustakaan. Setiap rak buku secara default bisa di-query tanpa perlu memasang perangkat tambahan. Cukup tempel stiker `@container` pada rak yang ingin Anda buat "pintar," dan semua buku di dalamnya akan otomatis menyesuaikan diri dengan ukuran rak tersebut. Tidak perlu lagi membawa kunci akses khusus.

## Penjelasan Detail

Di Tailwind v4, container queries terintegrasi penuh tanpa plugin eksternal. Setiap elemen dengan class `@container` menjadi containment context. Ukuran yang tersedia untuk query adalah `@sm` (>= 40ch), `@md` (>= 48ch), `@lg` (>= 64ch), `@xl` (>= 80ch), `@2xl` (>= 96ch). Anda juga bisa menggunakan `@container-{name}` untuk named containers dengan `container-name`. Container-type default adalah `inline-size` (hanya sumbu inline), tetapi bisa diubah dengan `@container-size` untuk kedua sumbu. Keunggulan utama di v4 adalah Anda tidak perlu plugin, tidak perlu konfigurasi, dan container queries bekerja di semua komponen secara out-of-the-box. Dukungan CSS nesting juga memudahkan penulisan style kustom untuk container.

## Contoh Kode Implementasi

```css
@import "tailwindcss";
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Container Queries Built-in v4</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans space-y-6">
  <div class="@container border-2 border-blue-300 p-4 rounded-xl">
    <div class="grid gap-4 @sm:grid-cols-2 @lg:grid-cols-4">
      <div class="bg-gradient-to-br from-blue-400 to-blue-600 p-4 rounded-lg text-white text-center">
        Item A
      </div>
      <div class="bg-gradient-to-br from-green-400 to-green-600 p-4 rounded-lg text-white text-center">
        Item B
      </div>
      <div class="bg-gradient-to-br from-purple-400 to-purple-600 p-4 rounded-lg text-white text-center">
        Item C
      </div>
      <div class="bg-gradient-to-br from-pink-400 to-pink-600 p-4 rounded-lg text-white text-center">
        Item D
      </div>
    </div>
    <p class="mt-4 @sm:text-lg @lg:text-2xl @xl:text-3xl font-bold text-gray-700">
      Teks ini responsif terhadap container
    </p>
  </div>
</body>
</html>
```

## Poin Penting

- Container queries di v4 built-in tanpa plugin—cukup tambahkan `@container` pada parent
- Prefix `@sm`, `@md`, `@lg`, `@xl`, `@2xl` untuk query container
- `@container-size` untuk containment dua sumbu, `@container-{name}` untuk named containers
