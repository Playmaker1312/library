# Kapan sebaiknya menggunakan container queries versus media queries

## Analogi: Perpustakaan Digital

Gunakan media queries untuk mengatur tata letak ruangan perpustakaan secara keseluruhan—apakah rak harus berjajar tiga atau satu baris tergantung ukuran ruangan. Gunakan container queries untuk mengatur isi setiap rak secara independen—buku di rak dekat jendela mungkin perlu tata letak berbeda dari buku di rak sudut. Keduanya diperlukan: ruangan menentukan struktur makro, rak menentukan struktur mikro.

## Penjelasan Detail

Gunakan media queries untuk layout halaman secara keseluruhan: grid columns, sidebar visibility, header/footer layout, dan navigasi. Ini karena elemen-elemen tersebut terkait langsung dengan viewport. Gunakan container queries untuk komponen reusable yang bisa ditempatkan di berbagai konteks: card, widget, panel, form groups, dan komponen yang mungkin muncul di sidebar dan main content secara bersamaan. Container queries unggul ketika komponen yang sama perlu beradaptasi di berbagai tempat. Aturan praktis: jika tata letak tergantung pada halaman, gunakan media queries. Jika tergantung pada ruang yang tersedia untuk komponen itu sendiri, gunakan container queries.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Media vs Container Queries</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans space-y-6">
  <!-- Media queries untuk layout halaman -->
  <header class="flex flex-col md:flex-row md:justify-between bg-gray-800 text-white p-4 rounded-lg">
    <h1 class="text-xl font-bold">My App</h1>
    <nav class="flex gap-4 mt-2 md:mt-0">
      <a href="#" class="hover:underline">Home</a>
      <a href="#" class="hover:underline">About</a>
      <a href="#" class="hover:underline">Contact</a>
    </nav>
  </header>

  <!-- Container queries untuk komponen reusable -->
  <div class="grid grid-cols-1 md:grid-cols-3 gap-4">
    <!-- Card di sidebar -->
    <aside class="@container bg-gray-50 p-3 rounded-xl border">
      <div class="@lg:flex @lg:gap-3">
        <img src="https://placehold.co/100" alt="" class="rounded-lg mb-2 @lg:mb-0">
        <div>
          <h3 class="font-bold @lg:text-lg">Card di Sidebar</h3>
          <p class="text-sm @lg:text-base">Container queries menjaga proporsi.</p>
        </div>
      </div>
    </aside>

    <!-- Card yang sama di main content -->
    <main class="col-span-2 @container bg-gray-50 p-3 rounded-xl border">
      <div class="@lg:flex @lg:gap-4">
        <img src="https://placehold.co/120" alt="" class="rounded-lg mb-2 @lg:mb-0">
        <div>
          <h3 class="font-bold @lg:text-2xl">Card di Main Content</h3>
          <p class="text-sm @lg:text-lg">Container lebih lebar, tampilan menyesuaikan.</p>
        </div>
      </div>
    </main>
  </div>
</body>
</html>
```

## Poin Penting

- Media queries untuk layout halaman global (struktur makro)
- Container queries untuk komponen reusable yang portabel (struktur mikro)
- Gunakan container queries ketika komponen yang sama muncul di berbagai konteks
