# Praktik membuat card component yang menggunakan container queries

## Analogi: Perpustakaan Digital

Card component adalah buku display yang harus terlihat menarik di manapun ia diletakkan—di rak etalase besar atau di tumpukan meja kecil. Container queries memastikan card tetap proporsional: di rak lebar, card menampilkan gambar besar di samping teks; di rak sempit, gambar di atas dan teks di bawah. Card menjadi "smart display" yang tahu cara terbaik menampilkan dirinya.

## Penjelasan Detail

Untuk membuat card dengan container queries, pertama tentukan struktur HTML dengan parent yang memiliki `@container`. Card dimulai dengan layout default (stack vertikal) dan menggunakan `@sm`, `@md`, `@lg` untuk mengubah layout. Gunakan `@container-size` jika tinggi card juga perlu diperhitungkan. Pertimbangkan aspek berikut: gambar bisa berubah dari `w-full` menjadi `size-24` (flex row); teks bisa bertambah dari `line-clamp-2` menjadi `line-clamp-4`; tombol bisa berubah dari `flex-col` menjadi `flex-row`. Container queries memungkinkan semua perubahan ini terjadi berdasarkan ruang yang tersedia untuk card, bukan berdasarkan viewport.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Card Component dengan Container Queries</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans">
  <!-- Grid tempat card-card diletakkan -->
  <div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-4">
    <!-- Card component - setiap instance merespons containernya sendiri -->
    <div class="@container bg-white rounded-2xl shadow-md overflow-hidden">
      <div class="p-4 @lg:flex @lg:gap-4">
        <div class="aspect-video @lg:aspect-square @lg:size-28 bg-gradient-to-br from-violet-400 to-indigo-600 rounded-xl mb-3 @lg:mb-0 flex-shrink-0"></div>
        <div class="flex-1 min-w-0">
          <span class="text-xs @md:text-sm font-semibold text-indigo-500 uppercase tracking-wide">Kategori</span>
          <h3 class="font-bold text-lg @lg:text-xl mt-1 leading-tight">Judul Card yang Panjang</h3>
          <p class="text-gray-600 text-sm @md:text-base mt-1 line-clamp-2 @lg:line-clamp-3">
            Deskripsi card yang akan terpotong atau meluas tergantung ruang yang tersedia untuk komponen ini.
          </p>
          <div class="flex items-center justify-between mt-3 @lg:mt-4">
            <span class="font-bold text-indigo-600 @lg:text-lg">Rp 150.000</span>
            <button class="bg-indigo-600 text-white px-3 @md:px-4 py-1.5 rounded-lg text-sm @md:text-base hover:bg-indigo-700 transition">
              Beli
            </button>
          </div>
        </div>
      </div>
    </div>

    <!-- Card kedua (sama, container akan berbeda) -->
    <div class="@container bg-white rounded-2xl shadow-md overflow-hidden">
      <!-- konten sama -->
    </div>
    <div class="@container bg-white rounded-2xl shadow-md overflow-hidden">
      <!-- konten sama -->
    </div>
    <div class="@container bg-white rounded-2xl shadow-md overflow-hidden">
      <!-- konten sama -->
    </div>
  </div>
</body>
</html>
```

## Poin Penting

- Mulai dengan layout vertikal (default), lalu tambah `@lg:flex` untuk layout horizontal
- Gunakan `@sm`, `@md`, `@lg` secara progresif untuk typography dan spacing
- Setiap instance card merespons containernya sendiri secara independen
