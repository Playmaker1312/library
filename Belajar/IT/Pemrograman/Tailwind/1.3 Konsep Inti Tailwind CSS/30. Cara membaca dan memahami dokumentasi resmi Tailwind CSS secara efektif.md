# Cara Membaca Dokumentasi Resmi Tailwind CSS

## Analogi: Perpustakaan Digital

Dokumentasi Tailwind seperti peta harta karun perpustakaan yang dirancang dengan sangat baik. Ada bagian "pencarian cepat" untuk menemukan class, bagian "contoh" untuk melihat cara pemakaian, dan bagian "API referensi" untuk detail teknis. Peta ini adalah panduan utama menjelajahi perpustakaan Tailwind.

## Penjelasan Detail

Dokumentasi resmi Tailwind di tailwindcss.com/docs adalah sumber referensi terbaik. Cara membaca efektif: navigasi kiri berisi semua kategori (Layout, Flexbox, Grid, Spacing, Typography, dll). Setiap halaman utility memiliki: deskripsi fungsi, daftar class lengkap dengan nilai, contoh visual langsung, dan kode yang bisa dicopy. Fitur "Quick Search" (Ctrl+K) memungkinkan pencarian class instan. Setiap halaman utility juga menampilkan kode CSS yang dihasilkan, cara kustomisasi, dan opsi variant yang didukung. Dokumentasi Tailwind v3+ juga menyertakan integrasi dengan Tailwind Play untuk eksperimen langsung. Untuk belajar efektif, baca halaman Core Concepts terlebih dahulu, lalu jelajahi utility per kategori.
