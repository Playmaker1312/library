# Memahami Konfigurasi Content dalam Tailwind CSS

## Analogi: Perpustakaan Digital

Konfigurasi `content` seperti peta perpustakaan yang memberi tahu petugas rak mana yang harus diperiksa. Jika petugas hanya memeriksa rak A dan B, buku di rak C tidak akan pernah tercatat. Semakin akurat peta, semakin efisien proses pencatatan.

## Penjelasan Detail

`content` adalah array path ke file-file yang berisi class Tailwind. Tailwind akan membaca file-file ini untuk menemukan class yang digunakan dan hanya menghasilkan CSS untuk class tersebut. Path ditulis dalam format glob pattern, seperti `./src/**/*.{html,js}` yang artinya semua file .html dan .js di folder src dan subfoldernya. Jika ada file di luar path content yang menggunakan Tailwind, class-class tersebut tidak akan dihasilkan. Konfigurasi content yang tepat sangat penting untuk menghasilkan CSS yang optimal. Jika terlalu sempit, banyak class hilang. Jika terlalu luas, proses scanning lebih lambat tapi akurat. Untuk project multi-framework, pastikan semua ekstensi file yang relevan tercakup.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Content Configuration</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-2xl w-full">
        <h1 class="text-3xl font-bold text-center text-gray-900 mb-8">Konfigurasi Content</h1>
        <div class="bg-white rounded-2xl shadow-lg p-6">
            <div class="bg-gray-900 rounded-xl p-5 font-mono text-sm">
                <div class="text-gray-400">/** @type {import('tailwindcss').Config} */</div>
                <div class="text-white">module.exports = {</div>
                <div class="pl-4 text-purple-400">content</div><div class="text-white">: [</div>
                <div class="pl-8 text-green-400">"./index.html",</div>
                <div class="pl-8 text-green-400">"./src/**/*.{html,js}",</div>
                <div class="pl-8 text-green-400">"./src/**/*.{vue,jsx,tsx}",</div>
                <div class="pl-8 text-green-400">"./public/**/*.php",</div>
                <div class="pl-4 text-white">],</div>
                <div class="text-white">}</div>
            </div>
            <div class="mt-4 grid grid-cols-2 gap-3 text-sm">
                <div class="p-3 bg-green-50 rounded-lg border border-green-200">
                    <span class="font-semibold text-green-800">Benar:</span>
                    <p class="text-green-600">Mencakup semua file yang menggunakan Tailwind</p>
                </div>
                <div class="p-3 bg-red-50 rounded-lg border border-red-200">
                    <span class="font-semibold text-red-800">Salah:</span>
                    <p class="text-red-600">Path tidak lengkap, class tidak tergenerate</p>
                </div>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- `content` menentukan file mana yang di-scan untuk class Tailwind
- Path ditulis dalam glob pattern untuk mencakup banyak file
- Konfigurasi yang salah menyebabkan class tidak tergenerate
