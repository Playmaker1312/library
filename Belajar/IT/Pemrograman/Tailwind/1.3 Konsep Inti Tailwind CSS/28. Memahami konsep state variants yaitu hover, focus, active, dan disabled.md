# Memahami Konsep State Variants dalam Tailwind

## Analogi: Perpustakaan Digital

State variants seperti perilaku buku yang berubah saat disentuh. Saat jari menyentuh sampul (hover), buku mengeluarkan cahaya. Saat buku dipegang (focus), buku terbuka setengah. Saat ditekan (active), buku terbuka lebar. Perilaku ini tidak permanen, hanya terjadi saat interaksi tertentu.

## Penjelasan Detail

State variants adalah prefix yang memungkinkan gaya berubah berdasarkan keadaan atau interaksi pengguna. Variant utama: `hover:` (saat mouse di atas elemen), `focus:` (saat elemen menerima fokus, seperti input), `active:` (saat elemen sedang diklik), `disabled:` (untuk elemen yang dinonaktifkan), `visited:` (untuk link yang sudah dikunjungi), `focus-within:` (saat elemen di dalam container menerima fokus), `focus-visible:` (fokus yang terlihat secara visual). State variants bisa dikombinasikan dengan responsive prefix, contoh: `hover:md:bg-blue-500` artinya saat hover di ukuran layar md ke atas, background berubah biru. Variant ini membuat interaksi pengguna lebih responsif dan intuitif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>State Variants</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full space-y-6">
        <h1 class="text-3xl font-bold text-center text-gray-900">State Variants</h1>
        <div class="bg-white rounded-2xl p-6 shadow-lg space-y-4">
            <button class="w-full py-3 px-6 bg-blue-500 text-white font-semibold rounded-xl hover:bg-blue-600 focus:ring-4 focus:ring-blue-300 focus:outline-none active:bg-blue-700 transition-all">
                Hover, Focus, Active Saya
            </button>
            <input type="text" placeholder="Klik di sini untuk focus" class="w-full px-4 py-3 border border-gray-300 rounded-xl focus:border-blue-500 focus:ring-2 focus:ring-blue-200 focus:outline-none transition-all">
            <a href="#" class="text-blue-500 hover:text-blue-700 hover:underline visited:text-purple-600 transition-colors">Link dengan visited state</a>
            <div class="flex gap-2">
                <button disabled class="flex-1 py-2 bg-gray-300 text-gray-500 rounded-xl cursor-not-allowed">Disabled</button>
                <button class="flex-1 py-2 bg-green-500 text-white rounded-xl hover:bg-green-600 active:bg-green-700 transition-all">Active</button>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Variant utama: hover, focus, active, disabled, visited
- Bisa dikombinasikan dengan responsive prefix (misal: hover:md:bg-red-500)
- Membuat interaksi pengguna lebih hidup dan responsif
