# Memahami Konsep Dark Mode Variant dalam Tailwind

## Analogi: Perpustakaan Digital

Perpustakaan memiliki dua mode pencahayaan: terang untuk siang hari dan redup untuk malam hari. Saat sensor mendeteksi gelap, semua lampu otomatis beralih ke mode redup. Buku dengan warna cerah tetap bisa dibaca, namun background berubah menjadi gelap agar tidak menyilaukan.

## Penjelasan Detail

Dark mode di Tailwind memungkinkan penerapan gaya berbeda saat dark mode aktif. Gunakan prefix `dark:` di depan class yang ingin diubah saat dark mode. Contoh: `bg-white dark:bg-gray-800` membuat background putih di mode terang dan abu-abu gelap di mode gelap. Secara default, Tailwind menggunakan strategi `media` yang mengikuti preferensi sistem operasi pengguna (prefers-color-scheme). Bisa diubah ke strategi `class` di konfigurasi (`darkMode: 'class'`) untuk mengontrol dark mode secara manual via class di elemen HTML. Strategi class berguna untuk toggle dark mode yang bisa dipilih pengguna. Dark mode bisa diterapkan ke semua utility: warna teks, background, border, shadow, dan lainnya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dark Mode</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-white dark:bg-gray-900 transition-colors duration-300 p-8 min-h-screen">
    <div class="max-w-lg mx-auto">
        <h1 class="text-3xl font-bold text-gray-900 dark:text-white mb-8 text-center">Dark Mode Tailwind</h1>
        <div class="bg-gray-50 dark:bg-gray-800 rounded-2xl p-6 shadow-lg space-y-4">
            <p class="text-gray-700 dark:text-gray-300">Ini adalah teks yang berubah warna di dark mode. Gunakan <code class="text-blue-500 dark:text-blue-400">dark:</code> prefix.</p>
            <div class="grid grid-cols-3 gap-3">
                <div class="p-4 bg-white dark:bg-gray-700 rounded-xl shadow-sm dark:shadow-gray-900/50">
                    <p class="text-sm text-gray-800 dark:text-gray-200">Kartu 1</p>
                </div>
                <div class="p-4 bg-white dark:bg-gray-700 rounded-xl shadow-sm dark:shadow-gray-900/50">
                    <p class="text-sm text-gray-800 dark:text-gray-200">Kartu 2</p>
                </div>
                <div class="p-4 bg-white dark:bg-gray-700 rounded-xl shadow-sm dark:shadow-gray-900/50">
                    <p class="text-sm text-gray-800 dark:text-gray-200">Kartu 3</p>
                </div>
            </div>
            <button class="w-full py-3 bg-blue-500 dark:bg-blue-600 text-white rounded-xl hover:bg-blue-600 dark:hover:bg-blue-700 transition-all">
                Tombol dengan dark mode
            </button>
        </div>
        <p class="text-xs text-gray-400 dark:text-gray-500 text-center mt-4">Ganti tema sistem operasi Anda untuk melihat efeknya</p>
    </div>
</body>
</html>
```

## Poin Penting
- Gunakan prefix `dark:` untuk gaya saat dark mode aktif
- Dua strategi: `media` (ikuti sistem) dan `class` (kontrol manual)
- Dark mode bisa diterapkan ke semua utility class
