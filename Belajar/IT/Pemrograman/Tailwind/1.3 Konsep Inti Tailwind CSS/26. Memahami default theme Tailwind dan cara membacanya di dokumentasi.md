# Memahami Default Theme Tailwind

## Analogi: Perpustakaan Digital

Default theme Tailwind seperti katalog standar perpustakaan pusat. Ada 1000 koleksi buku dasar yang sudah diatur rapi: buku biru di rak A, buku merah di rak B, buku besar di rak C. Setiap perpustakaan cabang bisa memilih buku tambahan, tapi katalog dasar ini selalu tersedia.

## Penjelasan Detail

Default theme Tailwind adalah kumpulan design tokens standar yang disediakan Tailwind tanpa konfigurasi tambahan. Theme ini mencakup semua nilai untuk: colors (22 warna + hitam/putih/transparent), spacing (0-96), fontFamily (sans, serif, mono), fontSize (xs hingga 9xl), fontWeight (thin hingga black), lineHeight (none hingga loose), letterSpacing (tighter hingga widest), borderRadius (none hingga full), borderWidth (0-8), boxShadow (sm hingga 2xl), maxWidth (xs hingga 7xl), breakpoints (sm, md, lg, xl, 2xl), dan masih banyak lagi. Dokumentasi resmi Tailwind di tailwindcss.com/docs menyediakan referensi lengkap semua nilai default. Untuk melihat theme, buka file konfigurasi dengan `npx tailwindcss init --full` yang akan menghasilkan file lengkap berisi semua nilai default.

## Poin Penting
- Default theme mencakup colors, spacing, typography, dan nilai desain lainnya
- Dokumentasi resmi adalah referensi utama untuk semua nilai default
- Gunakan `tailwindcss init --full` untuk melihat semua nilai theme lengkap
