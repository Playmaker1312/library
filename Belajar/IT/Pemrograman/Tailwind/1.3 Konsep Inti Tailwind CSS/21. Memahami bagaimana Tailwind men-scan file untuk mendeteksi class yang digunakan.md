# Memahami Bagaimana Tailwind Men-Scan File untuk Mendeteksi Class

## Analogi: Perpustakaan Digital

Bayangkan petugas perpustakaan yang berkeliling dengan daftar cek, mencatat setiap judul buku yang disebut pengunjung. Petugas tidak membaca seluruh isi buku, cukup melihat sampul dan daftar isi. Begitu pula Tailwind yang tidak menjalankan kode, hanya membaca file teks mencari pattern class.

## Penjelasan Detail

Tailwind menggunakan strategi scanning berbasis regex untuk mendeteksi class yang digunakan dalam file project. Prosesnya: Tailwind membaca seluruh file yang terdaftar di konfigurasi `content`, lalu mencari teks yang cocok dengan pattern class Tailwind seperti `text-`, `bg-`, `p-`, `m-`, dll. Scanning ini bersifat agnostik terhadap bahasa pemrograman - bisa HTML, JSX, Vue template, PHP, atau file apapun. Tailwind hanya mencari string yang mengandung class name yang valid. Jika class dibuat secara dinamis seperti `` `text-${size}-500` ``, Tailwind tidak akan mendeteksinya karena nilai konkritnya tidak ada di file sumber. Solusinya adalah menggunakan safelist di konfigurasi atau memastikan class lengkap ditulis dalam string.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Scanning Files</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-900 text-white p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-2xl w-full">
        <h1 class="text-3xl font-bold text-center mb-8">Bagaimana Tailwind Scan File</h1>
        <div class="bg-slate-800 rounded-xl p-6 space-y-4">
            <div class="p-4 bg-slate-700 rounded-lg">
                <p class="text-sm text-slate-400 mb-2">Class statis (terdeteksi):</p>
                <code class="text-green-400">&lt;div class="p-4 bg-blue-500 text-white"&gt;</code>
            </div>
            <div class="p-4 bg-slate-700 rounded-lg">
                <p class="text-sm text-slate-400 mb-2">Class dinamis (TIDAK terdeteksi):</p>
                <code class="text-red-400">&lt;div class={`text-${size}-500`}&gt;</code>
                <p class="text-xs text-slate-500 mt-1">Tailwind tidak bisa menebak nilai `size` saat runtime</p>
            </div>
            <div class="p-4 bg-slate-700 rounded-lg">
                <p class="text-sm text-slate-400 mb-2">Solusi - tulis lengkap:</p>
                <code class="text-green-400">&lt;div class={`${size === 'lg' ? 'text-lg' : 'text-base'}`}&gt;</code>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Tailwind scan file menggunakan regex untuk mencari pattern class
- Class yang digabung secara dinamis (`text-${size}`) tidak terdeteksi
- Solusi: tulis class secara lengkap dalam string atau gunakan safelist
