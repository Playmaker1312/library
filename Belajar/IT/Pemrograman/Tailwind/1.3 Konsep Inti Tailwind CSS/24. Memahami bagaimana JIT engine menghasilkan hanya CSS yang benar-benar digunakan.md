# Memahami Bagaimana JIT Engine Menghasilkan Hanya CSS yang Digunakan

## Analogi: Perpustakaan Digital

Bayangkan mesin fotokopi pintar yang hanya menggandakan halaman yang benar-benar diminta. Tidak seperti mesin fotokopi biasa yang menggandakan seluruh buku. Saat pengunjung bilang "salin halaman 5, 12, dan 34", mesin hanya menyalin tiga halaman itu, bukan 500 halaman buku.

## Penjelasan Detail

Proses JIT engine dimulai dengan tahap ekstraksi: Tailwind membaca semua file di `content` dan mengekstrak setiap string yang menyerupai class Tailwind menggunakan regex. Tahap kedua adalah resolusi: setiap class yang ditemukan dipecah menjadi bagian-bagiannya - utility name, variant prefix, value, dan modifier. Tahap ketiga adalah generasi: engine mencocokkan setiap class dengan definisi CSS yang sesuai dan menghasilkan aturan CSS spesifik. Tahap keempat adalah deduplikasi: aturan CSS yang identik digabungkan. Hasilnya adalah file CSS yang hanya berisi aturan untuk class yang benar-benar ada di project. Tidak ada class `bg-red-500` jika tidak digunakan, meskipun itu bagian dari default theme Tailwind.


## Poin Penting
- Ekstraksi class dari file, resolusi ke komponen, generasi CSS, lalu output
- Hanya class yang terdeteksi di file yang akan dihasilkan CSS-nya
- Proses deduplikasi menggabungkan aturan CSS yang identik
