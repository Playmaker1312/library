# Memahami Konsep Just-in-Time (JIT) Engine dalam Tailwind

## Analogi: Perpustakaan Digital

JIT engine seperti koki yang hanya memasak saat ada pesanan. Tidak ada makanan siap saji dalam jumlah besar. Ketika pelanggan memesan mie goreng, koki baru memasaknya. Ini berbeda dengan sistem katering (mode klasik) yang memasak semua menu dari pagi, meskipun banyak yang tidak dimakan.

## Penjelasan Detail

JIT (Just-in-Time) engine adalah mesin generasi CSS yang diperkenalkan di Tailwind v3. Alih-alih menghasilkan seluruh library Tailwind (ribuan class) terlebih dahulu, JIT engine menunggu hingga file project di-scan, lalu hanya menghasilkan CSS untuk class yang benar-benar digunakan. Keuntungan utamanya: ukuran file CSS development sangat kecil; waktu build lebih cepat; arbitrary values didukung tanpa konfigurasi tambahan; semua variant langsung tersedia tanpa perlu konfigurasi; dan feedback lebih cepat saat development. JIT engine bekerja dengan membaca file project, mengumpulkan semua class yang digunakan, lalu menghasilkan CSS spesifik untuk class-class tersebut. Engine ini menjadi default sejak Tailwind v3 dan membuat pengalaman development jauh lebih baik.

```html
    <title>JIT Engine</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-2xl w-full">
        <h1 class="text-3xl font-bold text-center text-gray-900 mb-8">JIT Engine</h1>
        <div class="bg-white rounded-2xl shadow-lg overflow-hidden">
            <div class="p-6 border-b border-gray-100">
                <div class="flex items-center gap-4">
                    <div class="w-16 h-16 bg-green-100 rounded-xl flex items-center justify-center">
                        <svg class="w-8 h-8 text-green-600" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                            <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M13 10V3L4 14h7v7l9-11h-7z"/>
                        </svg>
                    </div>
                    <div>
                        <h2 class="text-xl font-bold text-gray-900">Just-in-Time Engine</h2>
                        <p class="text-gray-500">Hanya generate CSS yang benar-benar dipakai</p>
                    </div>
                </div>
            </div>
            <div class="p-6 space-y-4">
                <div class="flex items-center justify-between p-4 bg-green-50 rounded-lg">
                    <span class="text-green-800 font-medium">Tanpa JIT (v2)</span>
                    <span class="text-green-700 font-bold">~3000 KB</span>
                </div>
                <div class="flex items-center justify-between p-4 bg-blue-50 rounded-lg">
                    <span class="text-blue-800 font-medium">Dengan JIT (v3+)</span>
                    <span class="text-blue-700 font-bold">~8 KB</span>
                </div>
                <div class="mt-4 p-4 bg-gray-50 rounded-lg text-sm text-gray-600">
                    JIT engine memungkinkan arbitrary value seperti <code class="text-purple-600">text-[32px]</code> atau <code class="text-purple-600">bg-[#123456]</code> tanpa konfigurasi.
                </div>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- JIT engine hanya menghasilkan CSS untuk class yang terdeteksi di project
- Ukuran file CSS turun drastis dari ribuan KB menjadi puluhan KB
- Arbitrary values bisa digunakan langsung tanpa konfigurasi
