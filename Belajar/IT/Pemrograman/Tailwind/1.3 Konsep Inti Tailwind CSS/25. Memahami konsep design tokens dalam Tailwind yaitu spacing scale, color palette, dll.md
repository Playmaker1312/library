# Memahami Konsep Design Tokens dalam Tailwind

## Analogi: Perpustakaan Digital

Design tokens seperti standar ukuran buku di perpustakaan. Semua buku harus mengikuti ukuran yang sudah ditentukan: S (14x20cm), M (16x24cm), L (20x28cm). Tidak ada yang boleh membuat ukuran 17.5x23.3cm. Ini memastikan semua buku rapi di rak dan konsisten.

## Penjelasan Detail

Design tokens adalah kumpulan nilai-nilai desain yang telah ditentukan dan menjadi dasar seluruh utility Tailwind. Komponen utama design tokens Tailwind meliputi: spacing scale (p-0 hingga p-96, dengan nilai p-4 = 16px, p-8 = 32px), color palette (setiap warna memiliki 11 shade dari 50 hingga 950), font size (text-xs hingga text-9xl), breakpoints (sm: 640px, md: 768px, lg: 1024px, xl: 1280px, 2xl: 1536px), dan border radius (rounded-sm hingga rounded-full). Design tokens ini memastikan konsistensi visual di seluruh project. Semua nilai mengikuti skala yang proporsional, misalnya spacing scale menggunakan kelipatan 4 (0, 1, 2, 3, 4, 5, 6 yang setara dengan 0, 4, 8, 12, 16, 20, 24 piksel).

## Poin Penting
- Design tokens adalah kumpulan nilai terstandarisasi untuk konsistensi
- Komponen utama: spacing, color, typography, breakpoints, radius
- Semua nilai menggunakan skala proporsional (kelipatan 4 untuk spacing)
