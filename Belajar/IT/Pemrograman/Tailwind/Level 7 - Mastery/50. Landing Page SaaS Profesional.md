# 50. Landing Page SaaS Profesional

## Penjelasan

Project ini adalah membangun landing page profesional untuk produk SaaS (Software as a Service) menggunakan Tailwind CSS. Landing page ini mencakup semua section yang dibutuhkan untuk konversi: navbar sticky, hero section dengan CTA, logo marquee, features grid, how it works, testimonials carousel, pricing table dengan toggle monthly/annual, FAQ accordion, CTA akhir, dan footer. Semua section dilengkapi scroll-triggered animations menggunakan Intersection Observer API.

Landing page adalah gerbang utama produk SaaS. Ini adalah halaman yang paling sering dilihat dan harus memberikan kesan pertama yang kuat. Project ini menguji kemampuanmu dalam membangun halaman yang indah, responsif, cepat, dan accessible dengan skor Lighthouse 95+.

## Fungsi

- Membangun landing page SaaS profesional dengan 9+ section lengkap
- Menerapkan scroll animations menggunakan Intersection Observer API
- Membangun pricing table dengan toggle monthly/annual dan highlight best value
- Membuat testimonial carousel dengan auto-play dan manual nav
- Membangun logo marquee dengan infinite scroll animation
- Mengimplementasikan FAQ accordion dengan smooth expand/collapse
- Menerapkan dark mode sempurna di semua section
- Mengoptimalkan performa untuk Lighthouse score 95+

## Struktur Project

```
saas-landing-page/
+-- index.html                  # file utama (semua section inline)
+-- css/
|   +-- style.css              # output Tailwind CSS
```

### 11. Intersection Observer Animations

Semua section menggunakan Intersection Observer API untuk memicu animasi fade-in-up saat elemen masuk viewport.

`javascript
// animations.js
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('animate-fade-in-up');
      observer.unobserve(entry.target);
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.feature-card, .step-card, .testimonial-slide').forEach(el => {
  el.classList.add('opacity-0', 'translate-y-8');
  observer.observe(el);
});

// Sticky Navbar with scroll direction
const navbar = document.getElementById('navbar');
let lastScroll = 0;
window.addEventListener('scroll', () => {
  const current = window.pageYOffset;
  if (current > 50) {
    navbar.classList.add('bg-white/90', 'dark:bg-gray-900/90', 'backdrop-blur-md', 'shadow-sm');
  } else {
    navbar.classList.remove('bg-white/90', 'dark:bg-gray-900/90', 'backdrop-blur-md', 'shadow-sm');
  }
  if (current > lastScroll && current > 200) {
    navbar.style.transform = 'translateY(-100%)';
  } else {
    navbar.style.transform = 'translateY(0)';
  }
  lastScroll = current;
});

// Pricing toggle
let isAnnual = false;
document.getElementById('billingToggle').addEventListener('click', () => {
  isAnnual = !isAnnual;
  document.querySelectorAll('.price').forEach(p => {
    p.textContent = isAnnual ? p.dataset.annual : p.dataset.monthly;
  });
});

// Testimonials carousel
let currentSlide = 0;
const track = document.getElementById('testimonialTrack');
const slides = track.querySelectorAll('.testimonial-slide');
function goToSlide(i) {
  currentSlide = i;
  track.style.transform = 'translateX(-' + (currentSlide * 100) + '%)';
  document.querySelectorAll('.testimonial-dot').forEach((d, idx) => {
    d.className = 'testimonial-dot w-3 h-3 rounded-full transition-all ' + (idx === currentSlide ? 'bg-blue-600 w-6' : 'bg-gray-300 dark:bg-gray-600');
  });
}
document.getElementById('testimonialNext').addEventListener('click', () => goToSlide((currentSlide + 1) % slides.length));
document.getElementById('testimonialPrev').addEventListener('click', () => goToSlide((currentSlide - 1 + slides.length) % slides.length));
setInterval(() => goToSlide((currentSlide + 1) % slides.length), 5000);

// FAQ Accordion
document.querySelectorAll('.faq-question').forEach(btn => {
  btn.addEventListener('click', () => {
    document.querySelectorAll('.faq-answer').forEach(a => a.classList.add('hidden'));
    document.querySelectorAll('.faq-icon').forEach(i => i.classList.remove('rotate-180'));
    btn.nextElementSibling.classList.remove('hidden');
    btn.querySelector('.faq-icon').classList.add('rotate-180');
  });
});
`

## Tantangan Teknis

1. **Scroll animations**: Intersection Observer harus diinisialisasi dengan benar. Animasi hanya triggered sekali (unobserve). Gunakan custom CSS keyframes untuk fade-in-up.
2. **Dark mode konsisten**: Semua section harus memiliki dark: variant. Background, text, border, shadow harus berubah. Gunakan CSS custom properties untuk kemudahan.
3. **Performance**: Target Lighthouse 95+. Lazy loading gambar, hindari layout shift, minimalkan JS, gunakan content-visibility: auto.
4. **Pricing toggle**: Harga disimpan di data-* attribute. Update semua harga saat toggle. Update badge diskon.
5. **Testimonial carousel**: Auto-play dengan pause on hover. Dot indicators sinkron. Transisi menggunakan CSS 	ransition-transform.
6. **Marquee infinite scroll**: CSS animation dengan track di-duplicate. Pause on hover. Gunakan 	ransform untuk smooth animation.
7. **Mobile menu**: Hamburger menu dengan backdrop overlay. Smooth slide-down. Tutup saat link di-click.
