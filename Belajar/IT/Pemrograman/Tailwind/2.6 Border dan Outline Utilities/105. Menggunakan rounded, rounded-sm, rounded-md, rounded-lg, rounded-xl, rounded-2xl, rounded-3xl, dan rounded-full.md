# Menggunakan rounded, rounded-sm, rounded-md, rounded-lg, rounded-xl, rounded-2xl, rounded-3xl, dan rounded-full

## Analogi: Perpustakaan Digital

Rounded utilities seperti membulatkan sudut-sudut buku atau kartu. `rounded-sm` sudut sedikit bulat, `rounded` bulat standar, `rounded-lg` lebih bulat, `rounded-xl` hingga `rounded-3xl` sangat bulat, `rounded-full` membuat sudut sangat bulat hingga membentuk lingkaran/oval. Seperti memilih apakah buku memiliki sudut lancip atau tumpul.

## Penjelasan Detail

Rounded utilities mengatur properti CSS `border-radius`. Skala: `rounded-none` (0px), `rounded-sm` (2px), `rounded` (4px), `rounded-md` (6px), `rounded-lg` (8px), `rounded-xl` (12px), `rounded-2xl` (16px), `rounded-3xl` (24px), `rounded-full` (9999px). `rounded-full` sangat berguna untuk membuat avatar lingkaran atau tombol pill. Radius dapat diterapkan ke sisi dan sudut spesifik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Rounded Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Rounded Utilities</h1>
  <div class="flex flex-wrap gap-4">
    <div class="bg-blue-500 text-white p-4 rounded-none">none</div>
    <div class="bg-blue-500 text-white p-4 rounded-sm">sm</div>
    <div class="bg-blue-500 text-white p-4 rounded">default</div>
    <div class="bg-blue-500 text-white p-4 rounded-md">md</div>
    <div class="bg-blue-500 text-white p-4 rounded-lg">lg</div>
    <div class="bg-blue-500 text-white p-4 rounded-xl">xl</div>
    <div class="bg-blue-500 text-white p-4 rounded-2xl">2xl</div>
    <div class="bg-blue-500 text-white p-4 rounded-3xl">3xl</div>
    <div class="bg-blue-500 text-white p-4 rounded-full">full</div>
  </div>
  <div class="flex items-center space-x-4 mt-4">
    <div class="bg-green-500 text-white size-16 rounded-full flex items-center justify-center font-bold">JD</div>
    <div class="bg-red-500 text-white px-8 py-3 rounded-full">Tombol Pill</div>
  </div>
</body>
</html>
```

## Poin Penting
- Skala radius: `none`, `sm`, `default`, `md`, `lg`, `xl`, `2xl`, `3xl`, `full`
- `rounded-full` untuk lingkaran sempurna dan tombol pill
- Dapat diterapkan ke sisi spesifik seperti `rounded-t-lg`
