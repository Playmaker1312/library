# Menggunakan border-solid, border-dashed, border-dotted, border-double, dan border-hidden

## Analogi: Perpustakaan Digital

Border style utilities seperti memilih gaya garis tepi buku. `border-solid` garis utuh, `border-dashed` garis putus-putus, `border-dotted` garis titik-titik, `border-double` garis ganda, `border-hidden` menyembunyikan border. Seperti memilih jenis bingkai dekoratif untuk sampul buku.

## Penjelasan Detail

Border style utilities mengubah properti CSS `border-style`. `border-solid` (default) garis utuh. `border-dashed` garis dengan strip pendek. `border-dotted` garis dengan titik. `border-double` dua garis paralel. `border-hidden` sama dengan none untuk border tetapi berbeda untuk tabel. Dapat dikombinasikan dengan ketebalan dan warna. border-style memberikan variasi desain tanpa mengubah ukuran atau warna.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Border Style Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Border Style</h1>
  <div class="border-2 border-solid border-blue-500 p-4">border-solid</div>
  <div class="border-2 border-dashed border-green-500 p-4">border-dashed</div>
  <div class="border-2 border-dotted border-red-500 p-4">border-dotted</div>
  <div class="border-4 border-double border-purple-500 p-4">border-double</div>
  <div class="border-2 border-hidden border-gray-500 p-4 bg-gray-100">border-hidden</div>
  <div class="flex space-x-4">
    <div class="border-b-2 border-dashed border-blue-500 pb-2">Garis bawah dashed</div>
    <div class="border-l-4 border-dotted border-green-500 pl-4">Samping dotted</div>
  </div>
</body>
</html>
```

## Poin Penting
- Gaya border: `solid`, `dashed`, `dotted`, `double`, `hidden`
- Dapat dikombinasikan dengan sisi, ketebalan, dan warna
- `border-double` membutuhkan minimal `border-3` agar terlihat
