# Menggunakan border untuk menambahkan border dan border-0 untuk menghapusnya

## Analogi: Perpustakaan Digital

Border utilities seperti menambahkan bingkai di sekeliling buku atau rak. `border` menambahkan garis tepi tipis (1px) di semua sisi. `border-0` menghilangkan border. Seperti memilih apakah buku memiliki bingkai dekoratif atau tidak. Border membantu memisahkan elemen secara visual.

## Penjelasan Detail

Utility `border` menambahkan border solid 1px di keempat sisi elemen. Warna default adalah `gray-200` atau mengikuti warna teks saat ini. `border-0` menghapus semua border. Border dapat dikustomisasi dengan utilities warna (`border-red-500`), ketebalan (`border-2`), dan gaya (`border-dashed`). Border adalah elemen desain fundamental untuk memisahkan konten, membuat kartu, dan mendefinisikan area.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Border Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Border Utilities</h1>
  <div class="border p-4">border (default 1px solid)</div>
  <div class="border-0 p-4 bg-gray-100">border-0 (tanpa border)</div>
  <div class="border-2 border-blue-500 p-4">border-2 border-blue-500</div>
  <div class="border-4 border-green-500 p-4">border-4 border-green-500</div>
  <div class="border border-red-500 p-4">border border-red-500</div>
  <div class="space-y-2">
    <input type="text" class="border p-2 rounded w-64" placeholder="Input dengan border">
    <input type="text" class="border-0 p-2 bg-gray-100 rounded w-64" placeholder="Input tanpa border">
  </div>
</body>
</html>
```

## Poin Penting
- `border` menambahkan border 1px solid di semua sisi
- `border-0` menghapus border
- Dapat dikombinasikan dengan warna dan ketebalan
