# Menggunakan outline, outline-none, outline-dashed, dan outline-offset

## Analogi: Perpustakaan Digital

Outline seperti garis fokus di sekitar buku yang tidak memengaruhi tata letak. Berbeda dengan border, outline tidak menambah ruang dan dapat ditempatkan di luar elemen. `outline` menambahkan garis, `outline-none` menghapusnya, `outline-dashed` membuat garis putus. `outline-offset` memberi jarak antara outline dan elemen.

## Penjelasan Detail

Outline utilities mengatur properti CSS `outline`. `outline` (outline: 1px solid), `outline-none` (outline: 0). `outline-dashed`, `outline-dotted`, `outline-double` untuk gaya. `outline-offset-{nilai}` untuk jarak outline dari tepi elemen. Outline tidak memengaruhi ukuran elemen atau layout. Sangat penting untuk accessibility: jangan hapus outline pada elemen fokus tanpa memberikan alternatif indikator fokus.

```html
<!DOCTYPE html>

  <h1 class="text-2xl font-bold">Outline Utilities</h1>
  <div class="outline outline-2 outline-blue-500 p-4">outline blue</div>
  <div class="outline outline-2 outline-dashed outline-green-500 p-4">outline-dashed</div>
  <div class="outline outline-2 outline-dotted outline-red-500 p-4">outline-dotted</div>
  <div class="outline outline-2 outline-blue-500 outline-offset-4 p-4">outline-offset-4</div>
  <div class="outline outline-2 outline-blue-500 outline-offset-8 p-4">outline-offset-8</div>
  <div class="bg-gray-100 p-4">
    <button class="outline-none bg-blue-500 text-white px-4 py-2 rounded focus:ring-2 focus:ring-blue-500">
      outline-none (fokus: ring)
    </button>
  </div>
</body>
</html>
```

## Poin Penting
- Outline tidak memengaruhi layout atau ukuran elemen
- `outline-offset` memberi jarak antara outline dan elemen
- Hati-hati menghapus outline focus (accessibility)
