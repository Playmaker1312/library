# Cara mendeteksi preferensi sistem operasi menggunakan prefers-color-scheme via JavaScript

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang bisa "membaca" preferensi pengunjung bahkan sebelum mereka masuk. Ketika seseorang mendekati pintu, sistem mengenali apakah mereka lebih suka lingkungan terang atau gelap berdasarkan pengaturan perangkat mereka. Inilah yang dilakukan `prefers-color-scheme` — sebuah media query CSS yang bisa diakses via JavaScript untuk mendeteksi preferensi sistem operasi pengguna sebelum konten ditampilkan.

## Penjelasan Detail
Untuk mendeteksi preferensi OS via JavaScript, gunakan `window.matchMedia('(prefers-color-scheme: dark)')`. Fungsi ini mengembalikan objek `MediaQueryList` dengan properti `matches` (boolean) yang menunjukkan apakah media query cocok. Untuk mendengarkan perubahan (pengguna mengganti preferensi OS saat situs terbuka), gunakan event listener `change` pada objek tersebut. Deteksi ini sangat berguna untuk inisialisasi dark mode sebelum halaman dirender, sehingga tidak ada flash. Kombinasikan dengan localStorage: prioritaskan preferensi yang tersimpan, lalu fallback ke preferensi OS. Pendekatan ini memberikan pengalaman terbaik bagi pengguna yang sering mengganti mode OS mereka.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Deteksi Preferensi OS</title>
  <script>
    // Deteksi preferensi OS sebelum render
    const prefersDark = window.matchMedia('(prefers-color-scheme: dark)');
    if (prefersDark.matches) {
      document.documentElement.classList.add('dark');
    }
  </script>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      darkMode: "class",
    };
  </script>
</head>
<body>
  <div class="min-h-screen bg-white dark:bg-gray-950 p-10 transition-colors">
    <div class="max-w-2xl mx-auto">
      <div class="flex justify-between items-center mb-8">
        <h1 class="text-3xl font-bold text-gray-900 dark:text-white">Deteksi Preferensi OS</h1>
        <button onclick="document.documentElement.classList.toggle('dark')" class="bg-gray-200 dark:bg-gray-700 text-gray-800 dark:text-white px-4 py-2 rounded-lg transition">Toggle</button>
      </div>

      <div class="bg-gray-50 dark:bg-gray-900 p-6 rounded-xl mb-6">
        <p class="text-gray-700 dark:text-gray-300">
          JavaScript mendeteksi preferensi sistem operasi Anda: 
          <span id="osPref" class="font-bold text-indigo-600 dark:text-indigo-400"></span>
        </p>
      </div>

      <div id="statusCards" class="grid grid-cols-2 gap-4 mb-6">
        <div id="lightCard" class="bg-yellow-50 dark:bg-gray-800 border-2 border-transparent dark:border-gray-700 p-4 rounded-xl transition-all">
          <p class="font-semibold text-yellow-800 dark:text-gray-400">☀️ Light Mode</p>
          <p class="text-sm text-yellow-700 dark:text-gray-500">Preferensi: terang</p>
        </div>
        <div id="darkCard" class="bg-gray-800 dark:bg-indigo-950 border-2 border-transparent dark:border-indigo-500 p-4 rounded-xl transition-all">
          <p class="font-semibold text-gray-200 dark:text-indigo-200">🌙 Dark Mode</p>
          <p class="text-sm text-gray-400 dark:text-indigo-300">Preferensi: gelap</p>
        </div>
      </div>

      <div class="bg-white dark:bg-gray-800 p-6 rounded-xl border border-gray-200 dark:border-gray-700">
        <h2 class="font-semibold text-gray-800 dark:text-white mb-2">Live Listener</h2>
        <p class="text-gray-600 dark:text-gray-400 text-sm" id="liveStatus">Mendengarkan perubahan preferensi OS...</p>
      </div>
    </div>
  </div>

  <script>
    const osPref = document.getElementById('osPref');
    const liveStatus = document.getElementById('liveStatus');
    const darkMedia = window.matchMedia('(prefers-color-scheme: dark)');

    function updateStatus() {
      osPref.textContent = darkMedia.matches ? 'DARK' : 'LIGHT';
      liveStatus.textContent = darkMedia.matches ?
        '🔄 Sistem Anda dalam mode gelap. Toggle untuk override.' :
        '🔄 Sistem Anda dalam mode terang. Toggle untuk override.';
    }

    // Listen for OS preference changes
    darkMedia.addEventListener('change', (e) => {
      if (!localStorage.getItem('theme')) {
        if (e.matches) {
          document.documentElement.classList.add('dark');
        } else {
          document.documentElement.classList.remove('dark');
        }
        updateStatus();
      }
    });

    updateStatus();
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan `window.matchMedia('(prefers-color-scheme: dark)')` untuk deteksi preferensi OS via JavaScript
- Tambahkan event listener `change` untuk merespons perubahan preferensi OS secara real-time
- Prioritaskan localStorage jika ada, gunakan preferensi OS sebagai fallback untuk inisialisasi
