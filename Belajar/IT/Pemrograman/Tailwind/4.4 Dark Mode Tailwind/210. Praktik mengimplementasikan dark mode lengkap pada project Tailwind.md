# Praktik mengimplementasikan dark mode lengkap pada project Tailwind

## Analogi: Perpustakaan Digital
Setelah mempelajari berbagai teknik pencahayaan, saatnya menerapkan sistem pencahayaan lengkap untuk seluruh gedung perpustakaan. Implementasi dark mode lengkap bukan sekadar mengganti warna latar — ini tentang menciptakan pengalaman yang mulus: toggle yang responsif, preferensi yang tersimpan, transisi yang halus, dan konsistensi di seluruh halaman. Semua elemen bekerja bersama seperti sistem pencahayaan terpadu.

## Penjelasan Detail
Implementasi dark mode lengkap terdiri dari beberapa komponen: (1) Konfigurasi Tailwind dengan `darkMode: "class"`, (2) Script inline di `<head>` untuk membaca localStorage dan mencegah flash, (3) Toggle button di UI dengan ikon yang berubah, (4) Event listener untuk menyimpan preferensi, (5) Transisi CSS halus untuk semua propersi warna, (6) Testing di berbagai halaman dan komponen. Pastikan semua elemen memiliki pasangan class `dark:` — tidak hanya background dan teks, tetapi juga border, shadow, placeholder, scrollbar, dan elemen form. Gunakan CSS `transition-colors` pada elemen utama untuk animasi yang halus. Jangan lupa gambar dan ikon — mungkin perlu versi berbeda untuk dark mode.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Dark Mode Lengkap</title>
  <!-- Script anti-flash -->
  <script>
    if (localStorage.getItem('theme') === 'dark' || (!localStorage.getItem('theme') && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
      document.documentElement.classList.add('dark');
    }
  </script>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = { darkMode: "class" };
  </script>
  <style>
    html { transition: background-color 0.3s, color 0.3s; }
    html *, html *:before, html *:after { transition: background-color 0.3s, border-color 0.3s, color 0.3s, box-shadow 0.3s; }
  </style>
</head>
<body>
  <div class="min-h-screen bg-white dark:bg-gray-950">
    <!-- Navbar -->
    <nav class="bg-white dark:bg-gray-900 border-b border-gray-200 dark:border-gray-800 sticky top-0 z-50">
      <div class="max-w-5xl mx-auto px-6 py-4 flex justify-between items-center">
        <span class="text-xl font-bold text-indigo-600 dark:text-indigo-400">MyApp</span>
        <div class="flex items-center gap-6">
          <a href="#" class="text-gray-600 dark:text-gray-300 hover:text-indigo-600 dark:hover:text-indigo-400">Home</a>
          <a href="#" class="text-gray-600 dark:text-gray-300 hover:text-indigo-600 dark:hover:text-indigo-400">Features</a>
          <a href="#" class="text-gray-600 dark:text-gray-300 hover:text-indigo-600 dark:hover:text-indigo-400">Pricing</a>
          <button id="themeToggle" class="relative w-14 h-7 bg-gray-200 dark:bg-gray-700 rounded-full transition-colors focus:outline-none focus:ring-2 focus:ring-indigo-500" aria-label="Toggle dark mode">
            <span id="toggleThumb" class="absolute top-0.5 left-0.5 w-6 h-6 bg-white dark:bg-gray-900 rounded-full shadow flex items-center justify-center text-xs transition-transform duration-300" style="transform: translateX(0);">
              🌙
            </span>
          </button>
        </div>
      </div>
    </nav>

    <!-- Hero -->
    <header class="max-w-4xl mx-auto px-6 py-16 text-center">
      <h1 class="text-5xl font-extrabold text-gray-900 dark:text-white mb-4">Dark Mode Lengkap</h1>
      <p class="text-xl text-gray-600 dark:text-gray-400 mb-8">Implementasi dark mode end-to-end dengan persistensi, transisi halus, dan anti-flash.</p>
      <button class="bg-indigo-600 dark:bg-indigo-500 text-white px-8 py-3 rounded-xl font-semibold hover:bg-indigo-700 dark:hover:bg-indigo-400 transition">Mulai Sekarang</button>
    </header>

      <div class="grid grid-cols-1 md:grid-cols-3 gap-6">
        <div class="bg-white dark:bg-gray-800 p-6 rounded-xl shadow-md dark:shadow-gray-900/50 border border-gray-200 dark:border-gray-700">
          <div class="w-12 h-12 bg-indigo-100 dark:bg-indigo-900 rounded-lg flex items-center justify-center mb-4">⚡</div>
          <h3 class="font-semibold text-gray-900 dark:text-white">Cepat & Ringan</h3>
          <p class="text-gray-600 dark:text-gray-400 text-sm mt-2">Dark mode tanpa JavaScript berat. Transisi CSS yang halus.</p>
        </div>
        <div class="bg-white dark:bg-gray-800 p-6 rounded-xl shadow-md dark:shadow-gray-900/50 border border-gray-200 dark:border-gray-700">
          <div class="w-12 h-12 bg-emerald-100 dark:bg-emerald-900 rounded-lg flex items-center justify-center mb-4">💾</div>
          <h3 class="font-semibold text-gray-900 dark:text-white">Persistensi</h3>
          <p class="text-gray-600 dark:text-gray-400 text-sm mt-2">Preferensi tersimpan di localStorage. Tidak perlu atur ulang.</p>
        </div>
        <div class="bg-white dark:bg-gray-800 p-6 rounded-xl shadow-md dark:shadow-gray-900/50 border border-gray-200 dark:border-gray-700">
          <div class="w-12 h-12 bg-amber-100 dark:bg-amber-900 rounded-lg flex items-center justify-center mb-4">🎨</div>
          <h3 class="font-semibold text-gray-900 dark:text-white">Konsisten</h3>
          <p class="text-gray-600 dark:text-gray-400 text-sm mt-2">Semua elemen memiliki pasangan dark: — border, shadow, form.</p>
        </div>
      </div>

    <!-- Footer -->
    <footer class="border-t border-gray-200 dark:border-gray-800 py-8 text-center text-gray-500 dark:text-gray-400 text-sm">
      <p>&copy; 2026 MyApp. Implementasi dark mode lengkap dengan Tailwind CSS.</p>
    </footer>
  </div>

  <script>
    const toggle = document.getElementById('themeToggle');
    const thumb = document.getElementById('toggleThumb');

    function updateUI() {
      const isDark = document.documentElement.classList.contains('dark');
      thumb.style.transform = isDark ? 'translateX(28px)' : 'translateX(0)';
      thumb.textContent = isDark ? '☀️' : '🌙';
    }

    toggle.addEventListener('click', () => {
      const isDark = document.documentElement.classList.toggle('dark');
      localStorage.setItem('theme', isDark ? 'dark' : 'light');
      updateUI();
    });

    updateUI();
  </script>
</body>
</html>
```

## Poin Penting
- Letakkan script anti-flash di `<head>` untuk membaca localStorage sebelum halaman dirender
- Berikan transisi CSS halus (`transition-colors`) pada semua elemen yang berubah warna
- Pastikan setiap komponen memiliki pasangan class `dark:` — background, teks, border, shadow, dan form
