# Cara mengkonfigurasi dark mode menggunakan strategy media

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang terhubung dengan sensor cahaya di luar gedung. Ketika matahari terbenam dan lingkungan sekitar gelap, perpustakaan otomatis menyalakan lampu hangat dan meredupkan layar komputer — tanpa perlu ada pustakawan yang menekan sakelar. Inilah strategi dark mode "media": sistem mendeteksi preferensi pengguna secara otomatis dan menyesuaikan tampilan tanpa interaksi manual.

## Penjelasan Detail
Strategi `media` adalah default dark mode Tailwind. Untuk menggunakannya, set `darkMode: "media"` di tailwind.config.js (atau biarkan tidak diset karena ini default). Tailwind akan menggunakan CSS media query `@media (prefers-color-scheme: dark)` untuk mendeteksi preferensi sistem operasi pengguna. Keuntungannya adalah dark mode bekerja otomatis tanpa JavaScript — jika pengguna sudah mengatur OS ke mode gelap, situs Anda akan otomatis tampil gelap. Kekurangannya adalah pengguna tidak bisa mengubah preferensi di dalam situs jika mereka ingin mode yang berbeda dari OS. Strategi ini cocok untuk situs yang tidak memerlukan toggle dark mode dan ingin mengikuti preferensi sistem secara ketat.

## Poin Penting
- Set `darkMode: "media"` untuk dark mode otomatis berdasarkan preferensi sistem operasi
- Tidak memerlukan JavaScript — CSS media query menangani deteksi secara native
- Pengguna tidak bisa override preferensi di dalam situs; cocok untuk situs yang ingin mengikuti OS secara ketat
