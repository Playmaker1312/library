# Cara mengkonfigurasi dark mode menggunakan strategy class

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki sakelar lampu di setiap meja baca. Setiap pengunjung bisa memilih sendiri apakah ingin meja mereka terang atau gelap, terlepas dari pencahayaan ruangan secara keseluruhan. Strategi dark mode "class" memberikan kendali ini kepada pengguna — mereka bisa memilih mode sesuai preferensi, kapan pun mereka mau.

## Penjelasan Detail
Strategi `class` membutuhkan konfigurasi `darkMode: "class"` di tailwind.config.js. Dengan strategi ini, Tailwind akan mencari class `dark` pada elemen induk (biasanya `<html>` atau `<body>`) untuk mengaktifkan dark mode. Anda bisa menambahkan class `dark` secara statis di HTML, atau secara dinamis menggunakan JavaScript. Strategi ini memberikan fleksibilitas penuh: Anda bisa membuat toggle button, membaca preferensi dari localStorage, mendeteksi OS dengan JavaScript lalu mengaplikasikan class yang sesuai, atau bahkan memberikan tiga opsi (terang, gelap, ikuti sistem). Strategi `class` adalah pilihan paling populer untuk proyek yang membutuhkan user experience yang baik dalam hal dark mode.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Dark Mode Class Strategy</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      darkMode: "class",
    };
  </script>
</head>
<body>
  <div class="min-h-screen bg-white dark:bg-gray-950 p-10 transition-colors">
    <div class="max-w-3xl mx-auto">
      <div class="flex justify-between items-center mb-8">
        <h1 class="text-3xl font-bold text-gray-900 dark:text-white">Dark Mode: Class Strategy</h1>
        <button id="toggleBtn" class="bg-gray-200 dark:bg-gray-700 text-gray-800 dark:text-white px-4 py-2 rounded-lg hover:bg-gray-300 dark:hover:bg-gray-600 transition flex items-center gap-2">
          <span id="toggleIcon">🌙</span>
          <span id="toggleText">Dark Mode</span>
        </button>
      </div>

      <div class="bg-gray-50 dark:bg-gray-900 p-6 rounded-xl mb-6">
        <p class="text-gray-700 dark:text-gray-300">
          Strategi <code class="bg-gray-200 dark:bg-gray-700 px-1 rounded">darkMode: "class"</code> memberikan kontrol penuh.
          Class <code>dark</code> ditambahkan ke elemen &lt;html&gt; saat tombol diklik.
        </p>
      </div>

      <div class="grid grid-cols-1 md:grid-cols-3 gap-4">
        <div class="bg-white dark:bg-gray-800 p-4 rounded-lg shadow dark:shadow-gray-900/50">
          <h3 class="font-semibold text-gray-800 dark:text-white">Fleksibel</h3>
          <p class="text-gray-600 dark:text-gray-400 text-sm">Bisa toggle kapan saja.</p>
        </div>
        <div class="bg-white dark:bg-gray-800 p-4 rounded-lg shadow dark:shadow-gray-900/50">
          <h3 class="font-semibold text-gray-800 dark:text-white">Persistent</h3>
          <p class="text-gray-600 dark:text-gray-400 text-sm">Bisa simpan ke localStorage.</p>
        </div>
        <div class="bg-white dark:bg-gray-800 p-4 rounded-lg shadow dark:shadow-gray-900/50">
          <h3 class="font-semibold text-gray-800 dark:text-white">User Choice</h3>
          <p class="text-gray-600 dark:text-gray-400 text-sm">Pengguna yang memutuskan.</p>
        </div>
      </div>
    </div>
  </div>

  <script>
    const btn = document.getElementById('toggleBtn');
    const icon = document.getElementById('toggleIcon');
    const text = document.getElementById('toggleText');

    btn.addEventListener('click', () => {
      document.documentElement.classList.toggle('dark');
      const isDark = document.documentElement.classList.contains('dark');
      icon.textContent = isDark ? '☀️' : '🌙';
      text.textContent = isDark ? 'Light Mode' : 'Dark Mode';
    });
  </script>
</body>
</html>
```

## Poin Penting
- Set `darkMode: "class"` dan tambahkan/hapus class `dark` pada elemen induk via JavaScript
- Strategi class memberikan fleksibilitas untuk toggle manual, persistensi, dan preferensi pengguna
- Ini adalah strategi paling populer untuk proyek dengan user experience dark mode yang baik
