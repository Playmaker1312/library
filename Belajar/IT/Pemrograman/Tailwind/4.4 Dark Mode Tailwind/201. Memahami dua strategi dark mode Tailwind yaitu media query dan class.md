# Memahami dua strategi dark mode Tailwind yaitu media query dan class

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki dua mode pencahayaan. Mode "media" seperti perpustakaan yang secara otomatis menyesuaikan pencahayaan berdasarkan sensor cahaya di luar gedung — jika di luar gelap, lampu otomatis menyala. Mode "class" seperti sakelar manual yang bisa ditekan pengunjung kapan saja — mereka bisa memilih terang atau gelap sesuai preferensi, terlepas dari kondisi luar. Kedua pendekatan ini adalah dua strategi dark mode di Tailwind.

## Penjelasan Detail
Tailwind mendukung dua strategi dark mode melalui properti `darkMode` di konfigurasi. Strategi `media` (default) menggunakan CSS `prefers-color-scheme` untuk mendeteksi preferensi sistem operasi pengguna. Dark mode akan aktif otomatis jika OS pengguna diatur ke mode gelap, tanpa perlu JavaScript. Strategi `class` memberikan kontrol manual dengan menambahkan class `dark` ke elemen induk (biasanya `<html>` atau `<body>`). Dengan strategi `class`, Anda bisa membuat toggle switch, mendeteksi preferensi dari localStorage, atau memberikan pengguna kendali penuh. Strategi `class` lebih fleksibel dan banyak digunakan dalam proyek modern karena memungkinkan override manual. Tailwind v3 juga mendukung strategi `selector` kustom untuk menggunakan selector arbitrary.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Strategi Dark Mode</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      darkMode: "class",
    };
  </script>
</head>
<body>
  <div class="p-10 min-h-screen bg-white dark:bg-gray-900 transition-colors">
    <div class="max-w-2xl mx-auto space-y-6">
      <h1 class="text-3xl font-bold text-gray-800 dark:text-white">Dua Strategi Dark Mode</h1>
      
      <div class="grid grid-cols-2 gap-6">
        <div class="bg-blue-50 dark:bg-blue-900 p-6 rounded-xl">
          <h2 class="font-bold text-blue-800 dark:text-blue-200">Strategi: media</h2>
          <p class="text-blue-700 dark:text-blue-300 text-sm mt-2">Mengikuti preferensi sistem operasi. <code class="bg-blue-200 dark:bg-blue-800 px-1 rounded">darkMode: "media"</code></p>
        </div>
        <div class="bg-purple-50 dark:bg-purple-900 p-6 rounded-xl">
          <h2 class="font-bold text-purple-800 dark:text-purple-200">Strategi: class</h2>
          <p class="text-purple-700 dark:text-purple-300 text-sm mt-2">Kontrol manual via class "dark". <code class="bg-purple-200 dark:bg-purple-800 px-1 rounded">darkMode: "class"</code></p>
        </div>
      </div>

      <div class="bg-gray-100 dark:bg-gray-800 p-6 rounded-xl">
        <p class="text-gray-700 dark:text-gray-300">Toggle di bawah hanya berfungsi dengan strategi <strong>class</strong>. Klik untuk beralih mode.</p>
        <button onclick="document.documentElement.classList.toggle('dark')" class="mt-4 bg-indigo-600 dark:bg-indigo-500 text-white px-6 py-2 rounded-lg hover:bg-indigo-700 transition">
          Toggle Dark Mode
        </button>
      </div>

      <div class="bg-gray-900 text-green-400 p-4 rounded text-sm">
        <pre>// tailwind.config.js
module.exports = {
  darkMode: 'media', // otomatis berdasarkan OS
  // atau
  darkMode: 'class', // manual via class "dark"
};</pre>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Strategi `media` menggunakan `prefers-color-scheme` OS — otomatis tanpa JavaScript
- Strategi `class` membutuhkan class `dark` pada elemen induk — memungkinkan toggle manual
- Strategi `class` lebih fleksibel untuk implementasi dark mode dengan kontrol pengguna
