# Cara membuat toggle dark mode menggunakan JavaScript sederhana

## Analogi: Perpustakaan Digital
Bayangkan sebuah sakelar lampu di meja resepsionis perpustakaan. Ketika ditekan, semua lampu di perpustakaan berubah — dari terang ke hangat, atau sebaliknya. Toggle dark mode adalah sakelar ini: satu tombol yang mengubah seluruh tampilan situs dari mode terang ke mode gelap dan sebaliknya, memberikan kendali penuh kepada pengunjung.

## Penjelasan Detail
Toggle dark mode adalah implementasi JavaScript yang menambahkan atau menghapus class `dark` pada elemen `<html>`. Langkah-langkahnya: (1) siapkan tombol dengan event listener, (2) di dalam event listener, panggil `document.documentElement.classList.toggle('dark')`, (3) perbarui teks atau ikon tombol sesuai mode aktif. Untuk mempermudah, Anda bisa menggunakan satu fungsi yang menangani toggle dan update UI. Toggle bisa berupa tombol, switch, atau ikon. Pastikan untuk memberikan feedback visual yang jelas tentang mode saat ini. Toggle dark mode biasanya ditempatkan di navbar, header, atau pojok layar. Untuk pengalaman yang lebih baik, kombinasikan toggle dengan penyimpanan preferensi di localStorage.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Toggle Dark Mode</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      darkMode: "class",
    };
  </script>
</head>
<body>
  <div class="min-h-screen bg-white dark:bg-gray-950 p-10 transition-colors duration-300">
    <div class="max-w-2xl mx-auto">
      <!-- Toggle Button -->
      <div class="flex justify-end mb-8">
        <button id="darkModeToggle" class="relative w-16 h-8 bg-gray-200 dark:bg-gray-700 rounded-full transition-colors duration-300 focus:outline-none focus:ring-2 focus:ring-indigo-500">
          <span id="toggleThumb" class="absolute top-1 left-1 w-6 h-6 bg-white dark:bg-gray-900 rounded-full shadow-md transition-transform duration-300 flex items-center justify-center text-sm">
            🌙
          </span>
        </button>
      </div>

      <div class="text-center space-y-6">
        <h1 class="text-4xl font-bold text-gray-900 dark:text-white">Toggle Dark Mode</h1>
        <p class="text-lg text-gray-600 dark:text-gray-400" id="modeText">Saat ini: Light Mode</p>
        
        <div class="bg-gray-50 dark:bg-gray-800 p-8 rounded-2xl shadow-lg border border-gray-200 dark:border-gray-700">
          <p class="text-gray-700 dark:text-gray-300">Klik toggle di pojok kanan atas untuk beralih antara light mode dan dark mode. Toggle ini menggunakan JavaScript sederhana untuk menambahkan atau menghapus class <code>dark</code> pada elemen HTML.</p>
        </div>

        <div class="grid grid-cols-2 gap-4">
          <div class="bg-indigo-50 dark:bg-indigo-950 p-4 rounded-xl">
            <p class="text-indigo-800 dark:text-indigo-200 font-semibold">Light Mode</p>
            <p class="text-indigo-600 dark:text-indigo-400 text-sm">Tampilan cerah untuk siang hari.</p>
          </div>
          <div class="bg-purple-50 dark:bg-purple-950 p-4 rounded-xl">
            <p class="text-purple-800 dark:text-purple-200 font-semibold">Dark Mode</p>
            <p class="text-purple-600 dark:text-purple-400 text-sm">Tampilan gelap untuk malam hari.</p>
          </div>
        </div>
      </div>
    </div>
  </div>

  <script>
    const toggle = document.getElementById('darkModeToggle');
    const thumb = document.getElementById('toggleThumb');
    const modeText = document.getElementById('modeText');

    toggle.addEventListener('click', () => {
      const isDark = document.documentElement.classList.toggle('dark');
      thumb.style.transform = isDark ? 'translateX(32px)' : 'translateX(0)';
      thumb.textContent = isDark ? '☀️' : '🌙';
      modeText.textContent = isDark ? 'Saat ini: Dark Mode' : 'Saat ini: Light Mode';
    });
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan `document.documentElement.classList.toggle('dark')` untuk toggle dark mode
- Update UI tombol (ikon/teks) sesuai mode aktif untuk feedback visual
- Toggle bisa berupa tombol, switch, atau ikon yang ditempatkan di navbar atau header
