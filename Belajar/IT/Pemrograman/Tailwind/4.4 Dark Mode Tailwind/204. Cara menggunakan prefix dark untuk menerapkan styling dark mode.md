# Cara menggunakan prefix dark untuk menerapkan styling dark mode

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki label khusus untuk buku yang bisa dibaca dalam mode gelap — label "D" (dark) ditempel di sampul. Ketika ruangan digelapkan, buku dengan label D akan bersinar. Di Tailwind, prefix `dark:` adalah label ini — Anda menempelkannya di depan utility class untuk mengaktifkan style tersebut hanya saat dark mode aktif. Ini seperti memberi instruksi: "gunakan gaya ini hanya saat mode gelap."

## Penjelasan Detail
Prefix `dark:` adalah cara utama untuk menerapkan dark mode styling di Tailwind. Cara kerjanya sederhana: tambahkan `dark:` di depan utility class apa pun, misalnya `dark:bg-gray-900` atau `dark:text-white`. Ketika dark mode aktif (baik via media query atau class), Tailwind akan mengaktifkan gaya yang diawali `dark:`. Prefix `dark:` bisa dikombinasikan dengan prefix lain seperti `hover:`, `focus:`, dan responsive prefix. Contoh: `dark:hover:bg-gray-700`. Untuk elemen yang ingin Anda sembunyikan di dark mode, gunakan `dark:hidden`. Untuk elemen yang hanya muncul di dark mode, gunakan `hidden dark:block`. Prefix `dark:` bekerja pada semua utility class termasuk layout, typography, background, border, shadow, dan efek lainnya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Prefix Dark Mode</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      darkMode: "class",
    };
  </script>
</head>
<body>
  <div class="min-h-screen bg-white dark:bg-gray-950 p-10 transition-colors">
    <div class="max-w-3xl mx-auto">
      <div class="flex justify-between items-center mb-8">
        <h1 class="text-3xl font-bold text-gray-900 dark:text-white">Prefix <code>dark:</code></h1>
        <button onclick="document.documentElement.classList.toggle('dark')" class="bg-gray-200 dark:bg-gray-700 text-gray-800 dark:text-white px-4 py-2 rounded-lg transition">Toggle</button>
      </div>

      <!-- Dark mode aware cards -->
      <div class="grid grid-cols-1 md:grid-cols-2 gap-4 mb-6">
        <div class="bg-white dark:bg-gray-800 p-6 rounded-xl shadow-md dark:shadow-gray-900/50 border border-gray-200 dark:border-gray-700">
          <h2 class="text-xl font-bold text-gray-800 dark:text-white dark:hover:text-indigo-400 transition-colors">Kartu 1</h2>
          <p class="text-gray-600 dark:text-gray-400 mt-2">Background, teks, border, dan shadow semuanya menggunakan prefix <code>dark:</code>.</p>
          <button class="mt-4 bg-indigo-600 dark:bg-indigo-500 text-white px-4 py-2 rounded-lg hover:bg-indigo-700 dark:hover:bg-indigo-400 transition">Tombol</button>
        </div>
        <div class="bg-white dark:bg-gray-800 p-6 rounded-xl shadow-md dark:shadow-gray-900/50 border border-gray-200 dark:border-gray-700">
          <h2 class="text-xl font-bold text-gray-800 dark:text-white">Kartu 2</h2>
          <p class="text-gray-600 dark:text-gray-400 mt-2">Kombinasi <code>dark:hover:bg-indigo-400</code> pada tombol di atas.</p>
          <div class="mt-4 flex gap-2">
            <span class="bg-gray-100 dark:bg-gray-700 text-gray-800 dark:text-gray-200 px-2 py-1 rounded text-sm">default</span>
            <span class="bg-gray-100 dark:bg-gray-700 text-gray-800 dark:text-gray-200 px-2 py-1 rounded text-sm dark:hidden">hanya light</span>
            <span class="hidden dark:inline-block bg-indigo-900 text-indigo-200 px-2 py-1 rounded text-sm">hanya dark</span>
          </div>
        </div>
      </div>

      <!-- Dark mode toggle indicator -->
      <div class="p-4 rounded-xl text-center text-lg font-semibold bg-yellow-100 text-yellow-800 dark:bg-indigo-900 dark:text-indigo-200 dark:block">
        <span class="dark:hidden">☀️ Light Mode Aktif</span>
        <span class="hidden dark:inline">🌙 Dark Mode Aktif</span>
      </div>

      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm mt-6">
// Prefix dark: bisa dikombinasikan dengan variant lain
dark:bg-gray-900        // background di dark mode
dark:text-white          // teks di dark mode
dark:hover:bg-gray-700   // hover di dark mode
lg:dark:text-xl          // responsive + dark mode
dark:border-gray-600     // border di dark mode
dark:shadow-lg           // shadow di dark mode
dark:hidden              // sembunyi di dark mode
hidden dark:block        // muncul hanya di dark mode</pre>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Tambahkan prefix `dark:` di depan utility class untuk styling yang hanya aktif saat dark mode
- Prefix `dark:` bisa dikombinasikan dengan prefix lain: `hover:`, `focus:`, responsive (`lg:`)
- Gunakan `dark:hidden` untuk menyembunyikan elemen di dark mode dan `hidden dark:block` untuk sebaliknya
