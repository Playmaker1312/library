# Cara menyimpan preferensi dark mode di localStorage

## Analogi: Perpustakaan Digital
Bayangkan seorang pengunjung perpustakaan yang selalu memilih meja dengan pencahayaan hangat. Ketika ia datang lagi keesokan harinya, meja yang sama sudah diatur dengan pencahayaan hangat tanpa perlu meminta lagi. Ini seperti localStorage yang "mengingat" preferensi pengguna. Tidak perlu mengatur ulang setiap kali berkunjung — preferensi tersimpan dan langsung diterapkan saat halaman dimuat.

## Penjelasan Detail
localStorage adalah Web API yang memungkinkan penyimpanan data key-value di browser pengguna secara persisten. Untuk menyimpan preferensi dark mode, simpan status dark mode sebagai string 'dark' atau 'light' di localStorage saat toggle di-click. Saat halaman dimuat, baca localStorage terlebih dahulu sebelum merender. Jika ada preferensi tersimpan, terapkan langsung. Jika tidak ada, deteksi preferensi OS sebagai fallback. Implementasi yang baik memeriksa localStorage saat `DOMContentLoaded` atau bahkan sebelum render (di `<head>` untuk menghindari flash). Contoh kunci penyimpanan: `localStorage.setItem('theme', 'dark')`. Untuk membaca: `localStorage.getItem('theme')`. Hapus dengan `localStorage.removeItem('theme')`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Dark Mode localStorage</title>
  <script>
    // Cek localStorage SEBELUM render untuk mencegah flash
    if (localStorage.getItem('theme') === 'dark' || (!localStorage.getItem('theme') && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
      document.documentElement.classList.add('dark');
    }
  </script>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      darkMode: "class",
    };
  </script>
</head>
<body>
  <div class="min-h-screen bg-white dark:bg-gray-950 p-10 transition-colors duration-300">
    <div class="max-w-2xl mx-auto">
      <div class="flex justify-between items-center mb-8">
        <h1 class="text-3xl font-bold text-gray-900 dark:text-white">Persistensi Dark Mode</h1>
        <button id="themeToggle" class="bg-gray-200 dark:bg-gray-700 text-gray-800 dark:text-white px-4 py-2 rounded-lg hover:bg-gray-300 dark:hover:bg-gray-600 transition flex items-center gap-2">
          <span id="toggleIcon">🌙</span>
          <span id="toggleLabel">Dark Mode</span>
        </button>
      </div>

      <div class="bg-gray-50 dark:bg-gray-900 p-6 rounded-xl mb-6">
        <p class="text-gray-700 dark:text-gray-300">
          Preferensi dark mode Anda <strong>disimpan di localStorage</strong>. Tutup dan buka kembali halaman ini — mode akan tetap sesuai pilihan terakhir Anda. Coba refresh halaman setelah toggle.
        </p>
      </div>

      <div class="bg-white dark:bg-gray-800 p-6 rounded-xl border border-gray-200 dark:border-gray-700">
        <h2 class="text-xl font-semibold text-gray-800 dark:text-white mb-4">Status Penyimpanan</h2>
        <div id="storageStatus" class="font-mono text-sm bg-gray-100 dark:bg-gray-900 p-3 rounded text-gray-700 dark:text-gray-300">
          localStorage.getItem('theme') = <span id="storageValue">null</span>
        </div>
      </div>
    </div>
  </div>

  <script>
    const toggle = document.getElementById('themeToggle');
    const icon = document.getElementById('toggleIcon');
    const label = document.getElementById('toggleLabel');
    const storageValue = document.getElementById('storageValue');

    function updateUI() {
      const isDark = document.documentElement.classList.contains('dark');
      icon.textContent = isDark ? '☀️' : '🌙';
      label.textContent = isDark ? 'Light Mode' : 'Dark Mode';
      storageValue.textContent = `'${localStorage.getItem('theme') || 'null'}'`;
    }

    toggle.addEventListener('click', () => {
      const isDark = document.documentElement.classList.toggle('dark');
      localStorage.setItem('theme', isDark ? 'dark' : 'light');
      updateUI();
    });

    updateUI();
  </script>
</body>
</html>
```

## Poin Penting
- Simpan status dark mode dengan `localStorage.setItem('theme', 'dark')` dan baca saat inisialisasi
- Cek localStorage sebelum render (di `<head>`) untuk mencegah flash (FOUC)
- Gunakan preferensi OS (`matchMedia`) sebagai fallback jika localStorage belum pernah diisi
