# Cara menggunakan data-theme attribute sebagai alternatif pendekatan dark mode

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki tiga setelan pencahayaan: "terang" untuk siang, "gelap" untuk malam, dan "sephia" untuk suasana vintage. Dengan sakelar data-theme, pustakawan bisa memilih mode yang diinginkan dan semua rak, meja, dan lampu akan menyesuaikan. Pendekatan data-theme lebih fleksibel daripada class dark sederhana karena memungkinkan lebih dari dua tema.

## Penjelasan Detail
Pendekatan `data-theme` menggunakan HTML attribute kustom (biasanya `data-theme="dark"` atau `data-theme="light"`) pada elemen `<html>` sebagai pengganti class `dark`. Keuntungannya: Anda bisa memiliki lebih dari dua tema (light, dark, sepia, high-contrast, dll). Untuk menggunakannya di Tailwind, set `darkMode: ['class', '[data-theme="dark"]']` untuk mendukung class dan data-theme. Atau Anda bisa menggunakan CSS murni dengan `[data-theme="dark"]` sebagai selector. Pendekatan ini populer di framework seperti DaisyUI. Data attribute juga lebih semantik dibanding class karena menyimpan nilai (tema apa yang aktif) bukan hanya boolean (ada/tidaknya class dark).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Data-Theme Dark Mode</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      darkMode: ['class', '[data-theme="dark"]'],
    };
  </script>
  <style>
    :root { --bg: #ffffff; --text: #0f172a; --card: #f8fafc; --border: #e2e8f0; }
    [data-theme="dark"] { --bg: #0f172a; --text: #f1f5f9; --card: #1e293b; --border: #334155; }
    [data-theme="sepia"] { --bg: #fbf0d9; --text: #5b4636; --card: #f5e6c8; --border: #d4b896; }
    [data-theme="high-contrast"] { --bg: #000000; --text: #ffffff; --card: #1a1a1a; --border: #ffffff; }
    .theme-aware-bg { background-color: var(--bg); }
    .theme-aware-text { color: var(--text); }
    .theme-aware-card { background-color: var(--card); border-color: var(--border); }
  </style>
</head>
<body class="theme-aware-bg min-h-screen p-10 transition-colors">
  <div class="max-w-2xl mx-auto">
    <div class="flex justify-between items-center mb-8">
      <h1 class="text-3xl font-bold theme-aware-text">Data-Theme Approach</h1>
      <div class="flex gap-2">
        <button onclick="setTheme('light')" class="bg-yellow-100 text-yellow-800 px-3 py-1 rounded text-sm hover:bg-yellow-200 transition">☀️ Light</button>
        <button onclick="setTheme('dark')" class="bg-gray-800 text-gray-200 px-3 py-1 rounded text-sm hover:bg-gray-700 transition">🌙 Dark</button>
        <button onclick="setTheme('sepia')" class="bg-amber-100 text-amber-800 px-3 py-1 rounded text-sm hover:bg-amber-200 transition">📜 Sepia</button>
        <button onclick="setTheme('high-contrast')" class="bg-black text-white px-3 py-1 rounded text-sm hover:bg-gray-900 transition">🔲 High Contrast</button>
      </div>
    </div>

    <div class="theme-aware-card border p-6 rounded-xl shadow mb-6 transition-colors">
      <h2 class="text-xl font-bold theme-aware-text mb-2">Multi-Tema dengan Data Attribute</h2>
      <p class="theme-aware-text opacity-80">Pendekatan data-theme memungkinkan lebih dari dua tema. Setiap tema mendefinisikan variabel CSS-nya sendiri. Klik tombol di atas untuk mengganti tema.</p>
    </div>

    <div class="grid grid-cols-2 gap-4">
      <div class="theme-aware-card border p-4 rounded-lg transition-colors">
        <p class="font-semibold theme-aware-text">Kartu 1</p>
        <p class="text-sm theme-aware-text opacity-70">Konten menyesuaikan tema aktif.</p>
      </div>
      <div class="theme-aware-card border p-4 rounded-lg transition-colors">
        <p class="font-semibold theme-aware-text">Kartu 2</p>
        <p class="text-sm theme-aware-text opacity-70">Tanpa flash, tanpa JavaScript berat.</p>
      </div>
    </div>

    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm mt-6">
// HTML
&lt;html data-theme="dark"&gt;

// CSS Variables
[data-theme="dark"] { --bg: #0f172a; --text: #f1f5f9; }
[data-theme="sepia"] { --bg: #fbf0d9; --text: #5b4636; }

// JavaScript
function setTheme(theme) {
  document.documentElement.setAttribute('data-theme', theme);
  localStorage.setItem('theme', theme);
}</pre>
  </div>

  <script>
    function setTheme(theme) {
      document.documentElement.setAttribute('data-theme', theme);
      localStorage.setItem('theme', theme);
    }
    // Restore on load
    const savedTheme = localStorage.getItem('theme');
    if (savedTheme) {
      document.documentElement.setAttribute('data-theme', savedTheme);
    }
  </script>
</body>
</html>
```

## Poin Penting
- Data attribute `data-theme` memungkinkan lebih dari dua tema (multi-tema) dibanding class `dark` yang hanya boolean
- Kombinasikan dengan CSS variables untuk pengelolaan tema yang lebih terstruktur
- Pendekatan ini lebih semantik dan fleksibel untuk proyek dengan kebutuhan tema yang kompleks
