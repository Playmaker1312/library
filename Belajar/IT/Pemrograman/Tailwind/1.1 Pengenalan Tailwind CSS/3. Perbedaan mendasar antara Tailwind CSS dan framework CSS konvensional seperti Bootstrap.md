# Perbedaan Tailwind CSS dan Framework Konvensional

## Analogi: Perpustakaan Digital

Perpustakaan konvensional seperti Bootstrap menyediakan buku-buku jadi yang langsung bisa dibaca, dengan tema dan format yang sudah ditentukan. Tailwind seperti rak berisi alat tulis kosong, kertas, dan stempel warna yang bisa digunakan untuk membuat buku sendiri sesuai keinginan. Satu perpustakaan memberi solusi instan, yang lain memberi kebebasan kreatif penuh.

## Penjelasan Detail

Framework konvensional seperti Bootstrap menyediakan komponen siap pakai seperti `.btn-primary` atau `.card` yang sudah memiliki gaya default. Pendekatan ini mempercepat prototyping namun menyulitkan kustomisasi karena harus menimpa CSS yang sudah ada. Tailwind tidak menyediakan komponen jadi, melainkan kelas utility kecil yang bisa digabungkan untuk membentuk komponen apapun. Kustomisasi di Tailwind dilakukan langsung di HTML tanpa perlu menulis CSS tambahan. Bootstrap menghasilkan file CSS berukuran besar meskipun banyak class tidak terpakai, sedangkan Tailwind dengan JIT engine menghasilkan CSS yang sangat kecil. Tailwind juga memberikan kontrol lebih besar terhadap desain tanpa terikat gaya default framework.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tailwind vs Bootstrap</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-100 p-8">
    <div class="max-w-4xl mx-auto grid grid-cols-2 gap-8">
        <div class="p-6 bg-white rounded-xl shadow">
            <h2 class="text-xl font-bold text-blue-600 mb-3">Bootstrap Style</h2>
            <div class="p-4 border rounded">
                <button class="px-4 py-2 bg-blue-500 text-white rounded">Tombol</button>
                <div class="mt-3 p-3 border rounded bg-light">Kartu dengan gaya default Bootstrap</div>
            </div>
            <p class="mt-3 text-sm text-gray-500">Sulit dikustomisasi tanpa CSS tambahan</p>
        </div>
        <div class="p-6 bg-white rounded-xl shadow">
            <h2 class="text-xl font-bold text-green-600 mb-3">Tailwind Style</h2>
            <button class="px-6 py-3 bg-gradient-to-r from-purple-500 to-pink-500 text-white font-semibold rounded-lg shadow-md hover:shadow-xl hover:scale-105 transition-all">
                Tombol Kustom
            </button>
            <div class="mt-3 p-4 bg-gray-50 rounded-lg border-l-4 border-green-500 shadow-sm">
                Kartu dengan gaya yang sepenuhnya dapat dikustomisasi
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Bootstrap menyediakan komponen jadi, Tailwind menyediakan blok utility
- Kustomisasi Tailwind dilakukan di HTML, Bootstrap membutuhkan CSS tambahan
- Tailwind menghasilkan CSS lebih kecil melalui JIT engine dibanding Bootstrap
