# Kapan Sebaiknya Menggunakan Tailwind CSS

## Analogi: Perpustakaan Digital

Tidak semua pengunjung butuh blok Lego. Ada yang hanya ingin meminjam novel lengkap, ada yang ingin fotokopi halaman tertentu. Perpustakaan blok Lego sangat ideal untuk yang ingin membangun sesuatu yang unik, tapi merepotkan untuk yang hanya ingin membaca cepat.

## Penjelasan Detail

Gunakan Tailwind CSS ketika: project membutuhkan desain yang sangat kustom dan unik; tim terdiri dari developer yang ingin bergerak cepat; project menggunakan framework JS seperti React, Vue, atau Svelte yang memudahkan component extraction; konsistensi desain adalah prioritas utama; dan ukuran file CSS perlu diminimalkan. Jangan gunakan Tailwind ketika: project adalah website statis sederhana yang bisa menggunakan CSS biasa; tim lebih nyaman dengan CSS semantik tradisional; project membutuhkan banyak gaya dinamis yang harus diubah melalui JavaScript; atau ketika stakeholder menginginkan file HTML yang bersih dan pendek tanpa banyak class. Tailwind juga kurang ideal untuk project yang membutuhkan tema yang sangat kompleks dengan banyak variasi, karena HTML bisa menjadi sangat panjang.

```html
    <title>Kapan Pakai Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gradient-to-br from-cyan-50 to-blue-100 p-8">
    <div class="max-w-4xl mx-auto">
        <div class="grid grid-cols-1 md:grid-cols-2 gap-6">
            <div class="p-6 bg-white rounded-xl shadow-lg border-l-4 border-green-400">
                <h2 class="text-xl font-bold text-green-700 mb-4">Gunakan Tailwind</h2>
                <ul class="space-y-3">
                    <li class="flex gap-2"><span class="text-green-500">+</span> Desain kustom dan unik</li>
                    <li class="flex gap-2"><span class="text-green-500">+</span> Tim ingin bergerak cepat</li>
                    <li class="flex gap-2"><span class="text-green-500">+</span> Framework JS (React/Vue/Svelte)</li>
                    <li class="flex gap-2"><span class="text-green-500">+</span> Konsistensi desain prioritas</li>
                    <li class="flex gap-2"><span class="text-green-500">+</span> Ukuran file CSS minimal</li>
                </ul>
            </div>
            <div class="p-6 bg-white rounded-xl shadow-lg border-l-4 border-red-400">
                <h2 class="text-xl font-bold text-red-700 mb-4">Jangan Gunakan</h2>
                <ul class="space-y-3">
                    <li class="flex gap-2"><span class="text-red-500">-</span> Website statis sederhana</li>
                    <li class="flex gap-2"><span class="text-red-500">-</span> Tim nyaman dengan CSS semantik</li>
                    <li class="flex gap-2"><span class="text-red-500">-</span> Banyak gaya dinamis via JS</li>
                    <li class="flex gap-2"><span class="text-red-500">-</span> HTML perlu bersih dan pendek</li>
                </ul>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Tailwind ideal untuk desain kustom, tim cepat, dan framework JS
- Hindari Tailwind untuk project statis atau tim yang suka CSS semantik
- Pertimbangkan kompromi antara HTML panjang vs kemudahan development
