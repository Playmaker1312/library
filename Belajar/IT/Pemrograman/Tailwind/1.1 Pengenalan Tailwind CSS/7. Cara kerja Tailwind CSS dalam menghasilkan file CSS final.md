# Cara Kerja Tailwind CSS dalam Menghasilkan File CSS

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang memiliki miliaran buku di gudang bawah tanah. Ketika seorang pengunjung datang dengan daftar permintaan, petugas perpustakaan hanya mengambil buku-buku yang ada di daftar itu dan menaruhnya di rak utama. Buku lain tetap tersimpan di gudang, tidak pernah diambil.

## Penjelasan Detail

Tailwind bekerja melalui beberapa tahapan untuk menghasilkan file CSS final. Pertama, Tailwind membaca semua file project yang dikonfigurasi di `content` untuk mencari class yang digunakan. Kedua, engine JIT mencocokkan setiap class yang ditemukan dengan aturan CSS yang telah didefinisikan. Ketiga, Tailwind hanya menghasilkan CSS untuk class yang benar-benar ada di file project, tidak termasuk class yang tidak digunakan. Keempat, CSS yang dihasilkan dioptimalkan dengan menghilangkan duplikasi dan menggabungkan aturan yang identik. Kelima, untuk production, CSS diminifikasi dengan menghapus spasi dan komentar. Hasilnya adalah file CSS final yang sangat kecil karena hanya berisi gaya yang benar-benar dipakai, bisa kurang dari 10KB untuk project sederhana.

## Poin Penting
- Tailwind scan file project untuk mendeteksi class yang digunakan
- Engine JIT menghasilkan CSS hanya untuk class yang terdeteksi
- File CSS final sangat kecil karena tidak menyertakan class yang tidak terpakai
