# Apa itu Tailwind CSS dan Filosofi Utility-First

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital raksasa yang tidak menyediakan buku jadi, melainkan jutaan blok Lego siap pakai. Setiap blok adalah satu kelas CSS kecil yang melakukan satu hal spesifik, seperti memberi warna merah atau mengatur jarak 16 piksel. Pengguna bebas merangkai blok-blok ini langsung di file HTML tanpa perlu menulis CSS kustom. Hasilnya adalah perpustakaan yang memberi kebebasan total tanpa aturan baku.

## Penjelasan Detail

Tailwind CSS adalah framework CSS yang menggunakan pendekatan utility-first, berbeda dengan framework tradisional yang menyediakan komponen siap pakai. Utility-first berarti setiap kelas CSS hanya memiliki satu fungsi spesifik, seperti `text-center` untuk meratakan teks atau `p-4` untuk memberikan padding 16 piksel. Filosofi ini memungkinkan developer membangun antarmuka langsung di HTML tanpa harus menulis CSS kustom. Pendekatan ini menghilangkan konteks switching antara file HTML dan CSS, sehingga mempercepat proses development. Tailwind juga menghasilkan CSS yang sangat kecil karena semua class yang tidak digunakan akan dibuang saat proses build. Dengan utility-first, konsistensi desain lebih terjaga karena semua nilai mengacu pada design tokens yang telah ditentukan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Utility-First Example</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex items-center justify-center min-h-screen bg-gray-100">
    <div class="max-w-sm p-6 bg-white rounded-xl shadow-lg hover:shadow-xl transition-shadow">
        <h1 class="text-2xl font-bold text-gray-900 mb-2">Judul Kartu</h1>
        <p class="text-gray-600 mb-4">Ini adalah contoh bagaimana utility-first bekerja. Setiap kelas melakukan satu hal spesifik.</p>
        <button class="px-4 py-2 bg-blue-500 text-white rounded-lg hover:bg-blue-600 active:bg-blue-700 transition-colors">
            Klik Saya
        </button>
    </div>
</body>
</html>
```

## Poin Penting
- Utility-first menggunakan kelas kecil yang spesifik daripada komponen besar siap pakai
- Pendekatan ini mempercepat development dengan menghilangkan konteks switching file
- File CSS final lebih kecil karena hanya class yang dipakai yang disertakan
