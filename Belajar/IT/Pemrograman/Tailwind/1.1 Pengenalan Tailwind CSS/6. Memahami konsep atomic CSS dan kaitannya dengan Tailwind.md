# Atomic CSS dan Kaitannya dengan Tailwind

## Analogi: Perpustakaan Digital

Atomic CSS seperti perpustakaan yang hanya menyimpan atom-atom: hidrogen, oksigen, karbon. Pengguna tidak bisa meminjam air (H2O) jadi, tapi harus mengambil 2 hidrogen dan 1 oksigen lalu merangkainya sendiri. Ini mirip konsep utility-first Tailwind, hanya saja atomic CSS lebih ekstrem dengan class yang lebih kecil lagi.

## Penjelasan Detail

Atomic CSS adalah pendekatan di mana setiap class CSS mewakili satu deklarasi properti tunggal, seperti `.w-100px { width: 100px; }`. Tailwind mengadopsi filosofi ini namun dalam skala yang lebih besar - class Tailwind seperti `p-4` mewakili satu properti (padding) dengan satu nilai spesifik. Perbedaan utamanya, atomic CSS murni biasanya menggunakan class seperti `.w-100px` atau `.c-red` yang langsung mencerminkan nilai, sedangkan Tailwind menggunakan sistem naming yang lebih terstruktur dengan skala yang telah ditentukan. Tailwind bisa dianggap sebagai implementasi atomic CSS yang lebih matang dan terorganisir. Pendekatan atomic CSS memastikan tidak ada CSS yang redundan dan setiap class memiliki ukuran yang sangat kecil. Tailwind membawa konsep ini ke level produksi dengan design tokens, responsive variants, dan tooling yang lengkap.

## Poin Penting
- Atomic CSS memecah gaya menjadi deklarasi tunggal per class
- Tailwind adalah implementasi atomic CSS yang lebih terstruktur dan matang
- Perbedaan utama: Tailwind menggunakan design tokens, bukan nilai mentah
