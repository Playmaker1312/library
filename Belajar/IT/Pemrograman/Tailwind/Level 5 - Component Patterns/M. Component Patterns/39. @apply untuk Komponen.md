# @apply untuk Komponen

## Penjelasan
- `@apply` adalah direktif Tailwind yang memungkinkan kamu menulis utility class di dalam CSS stylesheet. Ini seperti "inline expansion" — Tailwind akan mengganti `@apply` dengan utility class yang sesuai.
- Prinsip utama: **Gunakan `@apply` hanya jika pola yang sama muncul lebih dari 5 kali** di codebase. Jika hanya sekali atau dua kali, tulis utility class langsung di HTML.
- `@apply` paling efektif untuk komponen yang sangat sering dipakai seperti button, input form, card, badge.
- Gunakan `@layer components` untuk mengelompokkan style komponen. Ini penting agar Tailwind bisa mengatur urutan dan prioritas CSS dengan benar.
- Hindari `@apply` untuk style yang hanya dipakai satu halaman (one-off). Lebih baik tulis inline di HTML — itulah gunanya utility-first.
- `@apply` bisa dikombinasikan dengan variant seperti `hover:`, `focus:`, `dark:`, dll.
- File yang menggunakan `@apply` biasanya diletakkan di direktori `styles/` atau langsung di `src/input.css`.

## Fungsi
- Mengurangi repetisi utility class yang sama di banyak tempat
- Memudahkan refactoring — cukup ubah satu tempat
- Memberikan "nama semantic" pada komponen (`.btn-primary`) tanpa meninggalkan ekosistem Tailwind
- Tetap mempertahankan konsistensi dengan design system yang sudah didefinisikan di tailwind.config

## Cara Pengimplementasian / Kode

```css
/* styles/components.css */
@layer components {
  .btn {
    @apply inline-flex items-center justify-center rounded-md font-medium transition-colors duration-200;
    @apply focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2;
    @apply disabled:opacity-50 disabled:cursor-not-allowed;
  }

  .btn-primary {
    @apply btn; /*重用 .btn */
    @apply bg-blue-600 text-white hover:bg-blue-700;
    @apply focus-visible:ring-blue-600;
  }

  .btn-secondary {
    @apply btn;
    @apply bg-gray-200 text-gray-900 hover:bg-gray-300;
    @apply focus-visible:ring-gray-400;
  }

  .btn-danger {
    @apply btn;
    @apply bg-red-600 text-white hover:bg-red-700;
    @apply focus-visible:ring-red-600;
  }

  .form-input {
    @apply block w-full rounded-md border border-gray-300 px-3 py-2 text-base;
    @apply placeholder:text-gray-400;
    @apply focus:border-blue-600 focus:outline-none focus:ring-1 focus:ring-blue-600;
    @apply disabled:bg-gray-100 disabled:text-gray-500;
  }

  .card {
    @apply rounded-lg border border-gray-200 bg-white p-6 shadow-sm;
  }
}
```

```html
<!-- BOLEH: komponen yang dipakai berkali-kali -->
<button class="btn-primary">Simpan</button>
<button class="btn-primary">Kirim</button>
<button class="btn-primary">Tambah</button>
<input class="form-input" placeholder="Nama lengkap" />
<div class="card">Isi card</div>
```

```html
<!-- TIDAK BOLEH: one-off cukup pakai utility langsung -->
<!-- JANGAN buat class .header-title hanya untuk ini: -->
<h1 class="header-title">Tentang Kami</h1>

<!-- Lebih baik tulis langsung: -->
<h1 class="text-3xl font-bold text-gray-900 tracking-tight">Tentang Kami</h1>
```

## Analogi
`@apply` seperti template cetak kue. Jika kamu membuat 100 kue nastar, kamu tidak akan membentuk setiap kue satu per satu — kamu pakai cetakan. Begitu juga button: jika dipakai di 50 tempat, cetak dengan `@apply`. Tapi untuk satu kue eksperimen, bentuk manual saja — tidak perlu cetakan khusus.

## Dipakai untuk Apa
- Komponen UI yang muncul di banyak tempat: button, input, select, card, badge, alert
- Design system internal perusahaan dengan komponen yang sudah standar
- Project tim besar di mana konsistensi komponen sangat penting
- Migrasi dari framework CSS lain ke Tailwind — `@apply` jadi jembatan

## Kesalahan Umum yang Sering Terjadi
- Membuat `@apply` untuk komponen yang hanya dipakai 1-2 kali — ini melanggar prinsip utility-first Tailwind
- Lupa menempatkan kode di `@layer components`, menyebabkan masalah urutan CSS (style tidak keapply dengan benar)
- `@apply` bersarang terlalu dalam (`.a { @apply b }` dan `.b { @apply c }`) — sulit di-debug
- Mencampur `@apply` dengan CSS kustom yang kompleks — jika butuh CSS kustom, mungkin tailwind.config perlu di-extend
- Tidak konsisten: kadang pakai `@apply`, kadang inline untuk komponen yang sama — pilih salah satu
- Menggunakan `@apply` untuk utility yang sudah ada di config (misal `@apply text-blue-600` sudah diwakili warna brand)

## Koneksi dengan Materi Sebelumnya
Di Level 4 kamu belajar tailwind.config untuk brand tokens. Di materi 38 kamu belajar cn() untuk manage class di komponen JS. `@apply` adalah alternatif untuk project yang ingin approach CSS-file based. Ketiganya bisa dipakai bersamaan: config untuk brand, cn() untuk komponen JS React/Vue, dan `@apply` untuk CSS klasik atau komponen yang sangat sering dipakai di banyak template.

## Soal Latihan
Buat komponen `Alert` dengan `@apply` yang memiliki 3 variant (info, success, error). Alert harus memiliki icon area, teks, dan tombol close. Gunakan `@layer components`.

<details>
<summary>Jawaban</summary>

```css
@layer components {
  .alert {
    @apply relative flex items-start gap-3 rounded-lg border p-4 text-sm;
  }

  .alert-info {
    @apply alert;
    @apply border-blue-200 bg-blue-50 text-blue-800;
  }

  .alert-success {
    @apply alert;
    @apply border-green-200 bg-green-50 text-green-800;
  }

  .alert-error {
    @apply alert;
    @apply border-red-200 bg-red-50 text-red-800;
  }

  .alert-close {
    @apply ml-auto rounded-md p-1 opacity-70 transition-opacity hover:opacity-100;
    @apply focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-1;
  }
}
```

```html
<div class="alert-info" role="alert">
  <span class="alert-icon">i</span>
  <p>Data berhasil disimpan.</p>
  <button class="alert-close">&times;</button>
</div>

<div class="alert-error" role="alert">
  <span class="alert-icon">x</span>
  <p>Gagal menyimpan data.</p>
  <button class="alert-close">&times;</button>
</div>
```
