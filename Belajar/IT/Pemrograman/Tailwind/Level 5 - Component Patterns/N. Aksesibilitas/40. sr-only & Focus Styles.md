# sr-only & Focus Styles

## Penjelasan
- **sr-only** (screen reader only) adalah utility Tailwind untuk menyembunyikan elemen secara visual tapi tetap bisa dibaca oleh screen reader. Cocok untuk label tersembunyi pada icon button, atau teks tambahan untuk konteks aksesibilitas.
- **focus-visible** vs **focus**: `focus-visible` hanya menampilkan focus ring ketika user navigasi dengan keyboard (Tab), bukan saat klik mouse. `focus` selalu aktif meskipun diklik. Gunakan `focus-visible` untuk pengalaman yang lebih baik — tidak mengganggu pengguna mouse.
- **Skip to content link** adalah link tersembunyi di paling atas halaman yang memungkinkan pengguna keyboard langsung melompat ke konten utama, melewati navigasi yang berulang.
- **aria-label** memberikan label pada elemen yang tidak memiliki teks visual. Wajib untuk icon-only button, input tanpa label visual, dan elemen interaktif lainnya.
- **Kontras warna** memastikan teks mudah dibaca oleh pengguna dengan gangguan penglihatan. Tailwind sudah dirancang dengan kontras yang baik, tapi tetap perlu dicek dengan alat seperti WebAIM Contrast Checker. Standar WCAG AA minimal rasio kontras 4.5:1 untuk teks normal.

## Fungsi
- sr-only: menyediakan informasi tambahan untuk screen reader tanpa mengubah tampilan visual
- focus-visible: memberikan indikator fokus hanya saat navigasi keyboard, tidak saat mouse click
- Skip link: mempercepat navigasi keyboard ke konten utama
- aria-label: memberi nama pada elemen tanpa teks visual
- Kontras warna: memastikan semua teks terbaca oleh pengguna dengan keterbatasan penglihatan

## Cara Pengimplementasian / Kode

```html
<!-- Skip to content link — elemen pertama setelah <body> -->
<body>
  <a
    href="#main-content"
    class="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-50
           focus:rounded focus:bg-white focus:px-4 focus:py-2 focus:text-blue-600 focus:shadow-lg"
  >
    Lompat ke konten utama
  </a>

  <!-- Navigasi -->
  <nav>
    <ul>
      <li><a href="/">Beranda</a></li>
      <li><a href="/tentang">Tentang</a></li>
      <li><a href="/kontak">Kontak</a></li>
    </ul>
  </nav>

  <!-- Konten utama -->
  <main id="main-content">
    <h1>Selamat Datang</h1>
  </main>
</body>
```

## Analogi
sr-only seperti papan petunjuk tersembunyi di dalam bangunan yang hanya bisa dilihat oleh petugas khusus — orang biasa tidak melihatnya, tapi informasinya vital untuk navigasi. Focus-visible seperti lampu sensor yang hanya menyala ketika seseorang mendekat dengan gerakan tertentu (keyboard), bukan setiap kali ada orang lewat (mouse). Skip link seperti lift khusus di gedung bertingkat — pengguna biasa naik tangga, tapi pengguna kursi roda langsung naik lift ke lantai tujuan.

## Dipakai untuk Apa
- Icon button tanpa teks: tambahkan sr-only untuk deskripsi
- Form tanpa label visual: aria-label pada input
- Navigasi berulang di setiap halaman: skip link
- Setiap elemen interaktif (link, button, input): focus-visible ring
- Tombol close modal, hamburger menu, tombol edit/hapus: sr-only + aria-label
- Kartu atau panel yang bisa diklik: focus-visible outline

## Kesalahan Umum yang Sering Terjadi
- Menggunakan `focus:` saja tanpa `focus-visible:` — focus ring muncul setiap klik mouse, mengganggu pengalaman
- Lupa menambahkan `aria-label` pada icon-only button — screen reader tidak tahu fungsi tombol
- Skip link tidak muncul saat di-tab — user keyboard tidak bisa menemukannya
- Kontras warna terlalu rendah, terutama pada teks di background berwarna (contoh: teks putih di atas gambar)
- Menggunakan sr-only pada elemen yang penting untuk navigasi visual — sr-only hanya untuk suplemen, bukan pengganti
- Tidak menyediakan `focus-visible:outline-none` saat membuat custom focus ring — outline default tetap muncul

## Koneksi dengan Materi Sebelumnya
Di Level 1-4 kamu fokus ke aspek visual: layout, spacing, typography, warna, responsive. Sekarang kamu melengkapi aspek non-visual yang sama pentingnya. Aksesibilitas memastikan bahwa semua orang — termasuk pengguna screen reader dan keyboard-only — bisa menikmati hasil kerja kerasmu. Ini adalah syarat produksi (production requirement), bukan bonus.

## Soal Latihan
Buat sebuah navigasi sidebar dengan 3 link. Tambahkan skip link yang muncul saat di-tab. Setiap link harus memiliki focus-visible ring yang jelas. Tambahkan juga icon button "Tutup sidebar" yang hanya menampilkan icon (gunakan sr-only untuk label).
