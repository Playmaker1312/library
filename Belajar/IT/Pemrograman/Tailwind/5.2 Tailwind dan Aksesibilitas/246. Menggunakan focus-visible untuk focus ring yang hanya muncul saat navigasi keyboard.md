# Menggunakan focus-visible untuk focus ring yang hanya muncul saat navigasi keyboard
## Analogi: Perpustakaan Digital
Seorang petugas hanya ingin mendengar bel meja saat pengunjung benar-benar memanggil, bukan saat seseorang hanya berjalan melewati meja. `focus-visible` membedakan antara "sengaja memanggil" (navigasi keyboard) dengan "hanya lewat" (klik mouse), sehingga indikator fokus hanya muncul saat benar-benar diperlukan.
## Penjelasan Detail
`focus-visible` adalah utility Tailwind yang memanfaatkan pseudo-class CSS `:focus-visible`. Perilakunya: saat pengguna mengklik elemen dengan mouse, focus ring tidak muncul; saat pengguna menavigasi ke elemen dengan keyboard (Tab), focus ring muncul. Ini memberikan pengalaman visual yang lebih bersih bagi pengguna mouse tanpa mengorbankan aksesibilitas bagi pengguna keyboard. Sebelum `focus-visible`, developer sering harus memilih antara menghilangkan focus ring sama sekali (buruk untuk aksesibilitas) atau selalu menampilkannya (mengganggu pengguna mouse). Dengan Tailwind, Anda cukup menambahkan `focus-visible:ring-2` sebagai pengganti `focus:ring-2`. Browser modern mendukung `:focus-visible` dengan baik. Untuk fallback browser lama, Anda bisa tetap menyertakan `focus:ring-2` sebagai cadangan.

## Poin Penting
- `focus-visible` hanya menampilkan focus ring saat navigasi keyboard (Tab), bukan saat klik mouse
- Memberikan pengalaman visual lebih bersih bagi pengguna mouse tanpa mengorbankan aksesibilitas keyboard
- Untuk fallback browser lama, sertakan `focus:ring` sebagai cadangan di samping `focus-visible:ring`
