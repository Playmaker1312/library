# Menggunakan not-sr-only untuk membalikkan efek sr-only
## Analogi: Perpustakaan Digital
Jika `sr-only` adalah buku Braille yang hanya terlihat oleh pengunjung tunanetra, `not-sr-only` seperti buku yang sengaja diletakkan di rak biasa agar bisa dibaca oleh semua pengunjung. Ini membatalkan status "khusus" dari buku tersebut.
## Penjelasan Detail
`not-sr-only` adalah utility Tailwind yang membalikkan efek `sr-only`. Ketika sebuah elemen disembunyikan dengan `sr-only`, Anda dapat menggunakan `not-sr-only` dalam kondisi tertentu (biasanya dengan `focus:` atau `group-hover:`) untuk membuatnya terlihat kembali. Penggunaan paling umum adalah untuk link "Skip to Content" yang hanya muncul saat difokuskan: defaultnya `sr-only`, dan saat di-tab, ia berubah menjadi `focus:not-sr-only` sehingga link tersebut terlihat. Utility ini juga berguna untuk tooltip yang hanya muncul saat hover, atau panel aksesibilitas yang bisa ditampilkan dengan tombol toggle. `not-sr-only` adalah contoh sempurna bagaimana Tailwind memungkinkan Anda mengelola visibilitas secara deklaratif dengan varian state.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>not-sr-only - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-3xl mx-auto space-y-8">
        <!-- Skip to Content (paling umum) -->
        <div class="relative">
            <!-- Skip link: hanya terlihat saat di-tab -->
            <a href="#main"
                class="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-50
                       focus:px-6 focus:py-3 focus:bg-blue-600 focus:text-white focus:rounded-lg
                       focus:font-semibold focus:shadow-lg focus:outline-none">
            Langsung ke konten utama
            </a>

            <div class="p-6 bg-white rounded-xl shadow-md">
                <h2 class="text-xl font-bold text-gray-800 mb-4">Demo not-sr-only</h2>
                <p class="text-gray-600">Tekan tombol Tab sekarang — link "Langsung ke konten utama" akan muncul di pojok kiri atas. Ini menggunakan <code>sr-only</code> sebagai default dan <code>focus:not-sr-only</code> saat difokuskan.</p>
            </div>
        </div>

        <!-- Tooltip dengan group-hover -->
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Tooltip dengan not-sr-only</h2>
            <div class="group relative inline-block">
                <button class="px-4 py-2 bg-gray-200 rounded-lg font-semibold hover:bg-gray-300 transition">
                    Hover saya
                    <span class="sr-only group-hover:not-sr-only absolute bottom-full left-1/2 -translate-x-1/2 mb-2
                         px-3 py-1 bg-gray-800 text-white text-sm rounded-lg whitespace-nowrap shadow-lg">
                        Tooltip ini muncul saat hover
                        <span class="absolute top-full left-1/2 -translate-x-1/2 border-4 border-transparent border-t-gray-800"></span>
                    </span>
                </button>
            </div>
            <p class="mt-4 text-sm text-gray-500">Tooltip di atas menggunakan <code>sr-only</code> sebagai default dan <code>group-hover:not-sr-only</code> saat container di-hover.</p>
        </div>

        <!-- Panel toggle -->
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Panel Informasi Toggle</h2>
            <div id="panel-container">
                <button id="toggle-btn" class="px-4 py-2 bg-indigo-500 text-white rounded-lg font-semibold hover:bg-indigo-600 transition"
                    onclick="document.getElementById('info-panel').classList.toggle('sr-only')">
                Tampilkan/Sembunyikan Panel
                </button>
                <div id="info-panel" class="sr-only mt-4 p-4 bg-indigo-50 rounded-lg border border-indigo-200">
                    <h3 class="font-bold text-indigo-800">Panel Informasi</h3>
                    <p class="text-indigo-600 text-sm mt-1">Panel ini bisa ditampilkan dan disembunyikan. Secara default tersembunyi (sr-only), tetapi saat tombol diklik, class sr-only dihapus sehingga panel terlihat.</p>
                </div>
            </div>
        </div>

        <div class="p-4 bg-yellow-50 border border-yellow-200 rounded-lg text-sm text-yellow-700">
            <strong>Catatan:</strong> Di production, gunakan JavaScript yang lebih robust (seperti Alpine.js atau Vue) untuk toggle class, bukan onclick langsung.
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- `not-sr-only` membalikkan efek `sr-only`, biasanya digunakan dengan varian state seperti `focus:` atau `group-hover:`
- Penggunaan paling umum adalah link "Skip to Content" yang hanya muncul saat difokuskan keyboard
- Pola ini memungkinkan kontrol visibilitas deklaratif tanpa menulis CSS kustom
