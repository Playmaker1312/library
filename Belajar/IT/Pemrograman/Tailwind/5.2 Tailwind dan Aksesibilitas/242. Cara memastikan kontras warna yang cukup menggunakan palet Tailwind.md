# Cara memastikan kontras warna yang cukup menggunakan palet Tailwind
## Analogi: Perpustakaan Digital
Jika tulisan di rambu perpustakaan berwarna abu-abu muda di atas latar putih, pengunjung akan kesulitan membaca petunjuk. Kontras warna yang cukup seperti memastikan spidol yang digunakan di papan pengumuman cukup gelap dan tebal untuk dibaca dari jarak jauh oleh siapa pun, termasuk mereka dengan penglihatan terbatas.
## Penjelasan Detail
Tailwind menyediakan palet warna yang telah dirancang dengan variasi shade dari 50 hingga 900. Secara umum, shade 900 adalah yang tergelap dan 50 yang paling terang. Untuk memastikan kontras yang cukup, Anda perlu memasangkan warna teks dan latar belakang dengan perbedaan shade yang memadai. Standar WCAG AA membutuhkan rasio kontras minimal 4.5:1 untuk teks normal dan 3:1 untuk teks besar. Sebagai panduan praktis: teks gelap (gray-900, gray-800) di atas latar putih aman. Teks putih di atas latar biru-600 atau lebih gelap juga aman. Hindari kombinasi seperti gray-400 di atas white, atau white di atas blue-300. Gunakan alat seperti WebAIM Contrast Checker untuk memverifikasi rasio kontras pilihan warna Anda.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Kontras Warna Palet Tailwind - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-5xl mx-auto space-y-8">
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Kombinasi Kontras dengan Palet Tailwind</h2>

            <!-- Teks gelap di atas latar terang -->
            <h3 class="text-sm font-semibold text-gray-600 mb-2">Te = Teks, La = Latar</h3>
            <div class="grid grid-cols-2 md:grid-cols-4 gap-4 mb-8">
                <div v-for="item in kontrasBaik" :key="item.label" class="p-4 rounded-lg text-center"
                    :style="{ background: item.bg, color: item.text }">
                    <div class="font-bold">{{ item.label }}</div>
                    <div class="text-sm opacity-80">{{ item.text.replace('#', '') }}</div>
                </div>
            </div>

            <!-- Peringatan kombinasi buruk -->
            <div class="p-4 bg-yellow-50 border border-yellow-200 rounded-lg mb-6">
                <h3 class="font-bold text-yellow-800">Contoh Kombinasi Berisiko (Kontras Rendah)</h3>
                <p class="text-yellow-700 text-sm mt-1">Hindari kombinasi berikut karena rasio kontras di bawah standar WCAG AA:</p>
            </div>

            <div class="grid grid-cols-2 md:grid-cols-4 gap-4">
                <div v-for="item in kontrasBuruk" :key="item.label" class="p-4 rounded-lg text-center"
                    :style="{ background: item.bg, color: item.text }">
                    <div class="font-bold">{{ item.label }}</div>
                    <div class="text-sm opacity-80">{{ item.text.replace('#', '') }}</div>
                </div>
            </div>

            <!-- Rekomendasi Panduan -->
            <div class="mt-8 p-4 bg-blue-50 rounded-lg">
                <h3 class="font-bold text-blue-800">Panduan Cepat</h3>
                <ul class="mt-2 text-sm text-blue-700 space-y-1">
                    <li>✓ Teks gray-900 / gray-800 di atas white → aman</li>
                    <li>✓ Teks white di atas blue-600, blue-700, blue-800 → aman</li>
                    <li>✓ Teks white di atas gray-800 / gray-900 → aman</li>
                    <li>✗ Hindari gray-400 / gray-500 di atas white → terlalu tipis</li>
                    <li>✗ Hindari white di atas blue-300 / blue-400 → kontras tidak cukup</li>
                </ul>
            </div>
        </div>
    </div>

    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <script>
        const { createApp } = Vue;

        // Mapping Tailwind color names to hex
        const colors = {
            'white': '#ffffff',
            'gray-50': '#f9fafb', 'gray-100': '#f3f4f6',
            'gray-200': '#e5e7eb', 'gray-300': '#d1d5db',
            'gray-400': '#9ca3af', 'gray-500': '#6b7280',
            'gray-600': '#4b5563', 'gray-700': '#374151',
            'gray-800': '#1f2937', 'gray-900': '#111827',
            'blue-300': '#93c5fd', 'blue-400': '#60a5fa',
            'blue-500': '#3b82f6', 'blue-600': '#2563eb',
            'blue-700': '#1d4ed8', 'blue-800': '#1e40af',
        };

        const app = createApp({
            setup() {
                const kontrasBaik = [
                    { label: 'gray-900 / white', text: '#111827 / #ffffff', bg: colors['white'], text: colors['gray-900'] },
                    { label: 'gray-800 / white', text: '#1f2937 / #ffffff', bg: colors['white'], text: colors['gray-800'] },
                    { label: 'white / blue-600', text: '#ffffff / #2563eb', bg: colors['blue-600'], text: colors['white'] },
                    { label: 'white / blue-700', text: '#ffffff / #1d4ed8', bg: colors['blue-700'], text: colors['white'] },
                ];
                const kontrasBuruk = [
                    { label: 'gray-400 / white', text: '#9ca3af / #ffffff', bg: colors['white'], text: colors['gray-400'] },
                    { label: 'gray-500 / white', text: '#6b7280 / #ffffff', bg: colors['white'], text: colors['gray-500'] },
                    { label: 'white / blue-300', text: '#ffffff / #93c5fd', bg: colors['blue-300'], text: colors['white'] },
                    { label: 'white / blue-400', text: '#ffffff / #60a5fa', bg: colors['blue-400'], text: colors['white'] },
                ];
                return { kontrasBaik, kontrasBuruk };
            }
        });

        app.mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- Pastikan rasio kontras minimal 4.5:1 untuk teks normal (WCAG AA)
- Palet Tailwind aman jika menggunakan perbedaan shade yang cukup besar antara teks dan latar
- Gunakan alat kontras checker untuk memverifikasi kombinasi warna sebelum digunakan di production
