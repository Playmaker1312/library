# Memahami tanggung jawab developer dalam aksesibilitas saat menggunakan Tailwind
## Analogi: Perpustakaan Digital
Memiliki perpustakaan yang indah tidak berarti apa-apa jika pengunjung kursi roda tidak bisa melewati pintu masuk. Tailwind menyediakan cat dan dekorasi yang cantik, tetapi developer bertanggung jawab memastikan bangunannya dapat diakses oleh semua orang, termasuk yang memiliki keterbatasan fisik atau sensorik.
## Penjelasan Detail
Tailwind CSS hanyalah alat styling — ia tidak secara otomatis membuat aplikasi Anda aksesibel. Tanggung jawab aksesibilitas tetap sepenuhnya di tangan developer. Ini mencakup penggunaan semantic HTML yang benar (seperti `<button>` bukan `<div onclick>`), memastikan kontras warna yang cukup, menyediakan focus indicator yang jelas, mendukung navigasi keyboard, dan menambahkan atribut ARIA yang sesuai. Tailwind memang menyediakan utilities yang membantu aksesibilitas seperti `sr-only`, `focus:ring`, dan `motion-reduce`, tetapi penggunaannya tetap opsional. Jangan pernah mengandalkan class Tailwind semata untuk aksesibilitas; pastikan struktur HTML Anda sudah benar sebelum menambahkan styling. Accessibility tree yang baik dimulai dari markup yang semantik dan terstruktur.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Developer Tanggung Jawab Aksesibilitas - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-4xl mx-auto space-y-8">
        <!-- Buruk: tidak aksesibel -->
        <div class="p-6 bg-white rounded-xl shadow-md border-l-4 border-red-400">
            <h2 class="text-xl font-bold text-red-700 mb-3">Buruk (Tidak Aksesibel)</h2>
            <div class="space-y-3">
                <div onclick="alert('diklik')" class="bg-blue-500 text-white px-4 py-2 rounded text-center cursor-pointer">
                    Saya bukan button
                </div>
                <p class="text-gray-600 text-sm">
                    Masalah: menggunakan <code>&lt;div&gt;</code> sebagai tombol, tidak bisa difokus dengan keyboard, tidak ada role button.
                </p>
            </div>
        </div>

        <!-- Baik: aksesibel -->
        <div class="p-6 bg-white rounded-xl shadow-md border-l-4 border-green-400">
            <h2 class="text-xl font-bold text-green-700 mb-3">Baik (Aksesibel)</h2>
            <div class="space-y-3">
                <button onclick="alert('diklik')"
                    class="bg-blue-500 text-white px-5 py-2 rounded-lg font-semibold
                           hover:bg-blue-600 focus:outline-none focus:ring-2 focus:ring-blue-400 focus:ring-offset-2
                           transition">
            Tombol yang benar
                </button>
                <p class="text-gray-600 text-sm">
                    Menggunakan <code>&lt;button&gt;</code> semantic, bisa di-tab, memiliki focus ring, dan sudah memiliki role bawaan.
                </p>
            </div>
        </div>

        <!-- Checklist -->
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Tanggung Jawab Developer</h2>
            <ul class="space-y-2">
                <li class="flex items-start gap-2">
                    <span class="text-green-500 mt-1">✓</span>
                    <span>Gunakan semantic HTML (<code>&lt;nav&gt;</code>, <code>&lt;main&gt;</code>, <code>&lt;button&gt;</code>, <code>&lt;label&gt;</code>)</span>
                </li>
                <li class="flex items-start gap-2">
                    <span class="text-green-500 mt-1">✓</span>
                    <span>Pastikan kontras warna memenuhi standar WCAG AA</span>
                </li>
                <li class="flex items-start gap-2">
                    <span class="text-green-500 mt-1">✓</span>
                    <span>Sediakan focus indicator yang jelas (gunakan <code>focus:ring</code>)</span>
                </li>
                <li class="flex items-start gap-2">
                    <span class="text-green-500 mt-1">✓</span>
                    <span>Dukung navigasi keyboard (tab index, arrow keys)</span>
                </li>
                <li class="flex items-start gap-2">
                    <span class="text-green-500 mt-1">✓</span>
                    <span>Tambahkan teks alternatif untuk gambar (<code>alt</code>)</span>
                </li>
                <li class="flex items-start gap-2">
                    <span class="text-green-500 mt-1">✓</span>
                    <span>Gunakan <code>sr-only</code> untuk konten screen reader saja</span>
                </li>
                <li class="flex items-start gap-2">
                    <span class="text-green-500 mt-1">✓</span>
                    <span>Hormati preferensi reduced motion dengan <code>motion-reduce</code></span>
                </li>
            </ul>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- Tailwind hanya alat styling, aksesibilitas tetap tanggung jawab penuh developer
- Semantic HTML adalah fondasi aksesibilitas yang paling penting
- Gunakan utility aksesibilitas Tailwind sebagai pelengkap, bukan pengganti praktik aksesibel yang benar
