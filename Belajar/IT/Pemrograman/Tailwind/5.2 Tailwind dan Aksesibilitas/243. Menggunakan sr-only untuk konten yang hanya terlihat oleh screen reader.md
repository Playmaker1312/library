# Menggunakan sr-only untuk konten yang hanya terlihat oleh screen reader
## Analogi: Perpustakaan Digital
`sr-only` seperti buku Braille di perpustakaan — hanya bisa dibaca oleh pengunjung tunanetra, sementara pengunjung lain tidak melihatnya. Ini menyediakan informasi yang diperlukan untuk pengguna screen reader tanpa mengganggu tampilan visual bagi pengguna lain.
## Penjelasan Detail
Utility `sr-only` (screen reader only) di Tailwind menyembunyikan konten secara visual tetapi tetap membuatnya dapat diakses oleh screen reader dan teknologi bantu lainnya. Ini menerapkan teknik CSS: posisi absolut, ukuran 1px, overflow hidden, dan clip path. Situasi umum penggunaan `sr-only` meliputi: tombol ikon tanpa teks (misalnya tombol "Hapus" yang hanya menampilkan ikon tempat sampah), label tersembunyi untuk input form, link "Skip to Content", dan judul tersembunyi untuk memperjelas struktur halaman bagi screen reader. Penting untuk diingat bahwa `sr-only` hanya untuk konten yang benar-benar tidak perlu dilihat secara visual. Jangan gunakan untuk menyembunyikan konten yang seharusnya terlihat — itu akan membingungkan pengguna screen reader yang mendengar konten yang tidak sesuai dengan apa yang mereka lihat di layar.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>sr-only - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-3xl mx-auto space-y-8">
        <!-- Tombol Ikon -->
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Tombol dengan Ikon Saja</h2>
            <div class="flex gap-4 items-center">
                <button class="p-3 bg-red-100 rounded-lg hover:bg-red-200 transition focus:outline-none focus:ring-2 focus:ring-red-400">
                    <!-- Ikon tempat sampah -->
                    <svg class="w-5 h-5 text-red-600" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M19 7l-.867 12.142A2 2 0 0116.138 21H7.862a2 2 0 01-1.995-1.858L5 7m5 4v6m4-6v6m1-10V4a1 1 0 00-1-1h-4a1 1 0 00-1 1v3M4 7h16" />
                    </svg>
                    <span class="sr-only">Hapus item</span>
                </button>
                <span class="text-sm text-gray-500">Tombol di atas menggunakan sr-only untuk teks "Hapus item"</span>
            </div>
            <div class="mt-4 p-3 bg-yellow-50 rounded-lg text-sm text-yellow-700">
                Screen reader akan membacakan "Hapus item" saat tombol difokuskan, meskipun secara visual hanya terlihat ikon.
            </div>
        </div>

        <!-- Label form tersembunyi -->
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Label Form Tersembunyi</h2>
            <div class="space-y-4 max-w-sm">
                <div>
                    <label for="search" class="sr-only">Cari artikel</label>
                    <div class="relative">
                        <input id="search" type="text" placeholder="Cari..."
                            class="w-full pl-10 pr-4 py-2 border rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-400">
                        <svg class="absolute left-3 top-2.5 w-5 h-5 text-gray-400" fill="none" stroke="currentColor" viewBox="0 0 24 24">
                            <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M21 21l-6-6m2-5a7 7 0 11-14 0 7 7 0 0114 0z" />
                        </svg>
                    </div>
                </div>
            </div>
            <div class="mt-4 text-sm text-gray-500">
                Label "Cari artikel" tersembunyi secara visual tapi dibaca oleh screen reader ketika input difokuskan.
            </div>
        </div>

        <!-- Link Skip to Content -->
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Link Skip to Content</h2>
            <a href="#main-content"
                class="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-50 focus:px-4 focus:py-2 focus:bg-blue-600 focus:text-white focus:rounded-lg">
            Langsung ke konten utama
            </a>
            <p class="text-gray-600">Link di atas hanya terlihat saat difokuskan (tekan Tab setelah halaman dimuat). Ini memungkinkan pengguna keyboard langsung menuju konten utama.</p>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- Gunakan `sr-only` untuk konten yang perlu diakses screen reader tetapi tidak perlu dilihat secara visual
- Kasus umum: tombol ikon, label form tersembunyi, link skip-to-content
- Jangan gunakan `sr-only` untuk menyembunyikan konten yang seharusnya terlihat secara visual
