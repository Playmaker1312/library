# Menggunakan Font Weight di Tailwind

## Analogi: Perpustakaan Digital

Font weight seperti ketebalan spidol di perpustakaan. Ada spidol tipis (thin) untuk garis halus, spidol sedang (normal) untuk tulisan biasa, spidol tebal (bold) untuk judul, dan spidol sangat tebal (black) untuk poster besar. Setiap spidol memiliki fungsi yang jelas.

## Penjelasan Detail

Tailwind menyediakan 9 tingkat font weight: `font-thin` (100), `font-extralight` (200), `font-light` (300), `font-normal` (400 - default), `font-medium` (500), `font-semibold` (600), `font-bold` (700), `font-extrabold` (800), dan `font-black` (900). Nilai numerik mengikuti standar CSS font-weight. `font-normal` adalah default untuk sebagian besar elemen teks. `font-bold` biasanya digunakan untuk heading dan penekanan. `font-medium` dan `font-semibold` berguna untuk variasi antara normal dan bold. `font-thin` dan `font-extralight` cocok untuk desain minimalis atau ukuran teks besar. Ketersediaan weight tergantung pada font yang digunakan - tidak semua font memiliki semua weight.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Font Weight</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8">
        <h1 class="text-2xl font-bold text-gray-900 text-center mb-6">Font Weight</h1>
        <div class="space-y-2 text-center">
            <p class="font-thin text-gray-700">font-thin (100) - Paling tipis</p>
            <p class="font-extralight text-gray-700">font-extralight (200)</p>
            <p class="font-light text-gray-700">font-light (300)</p>
            <p class="font-normal text-gray-800">font-normal (400) - Default</p>
            <p class="font-medium text-gray-800">font-medium (500)</p>
            <p class="font-semibold text-gray-900">font-semibold (600)</p>
            <p class="font-bold text-gray-900">font-bold (700) - Tebal</p>
            <p class="font-extrabold text-gray-900">font-extrabold (800)</p>
            <p class="font-black text-gray-900">font-black (900) - Paling tebal</p>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- 9 tingkat weight: thin (100) hingga black (900)
- font-normal (400) adalah default, font-bold (700) untuk heading
- Ketersediaan weight tergantung pada font yang digunakan
