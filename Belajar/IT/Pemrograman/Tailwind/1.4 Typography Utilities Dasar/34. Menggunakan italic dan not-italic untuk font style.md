# Menggunakan Font Style di Tailwind

## Analogi: Perpustakaan Digital

Font style seperti gaya tulisan dalam buku: tegak lurus untuk teks biasa, miring untuk kata asing atau penekanan. Seperti buku yang menggunakan italic untuk menunjukkan dialog dalam pikiran karakter.

## Penjelasan Detail

Tailwind menyediakan dua kelas untuk font style: `italic` untuk teks miring dan `not-italic` untuk teks tegak lurus (utamanya digunakan untuk mematikan italic pada elemen yang secara default italic, seperti `<em>` atau `<cite>`). `italic` setara dengan CSS `font-style: italic`. Kelas ini berguna untuk penekanan, kutipan, judul buku, kata asing, atau istilah teknis. `not-italic` berguna saat menggunakan sistem desain yang mengharuskan elemen tertentu tidak menggunakan italic meskipun secara semantic seharusnya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Font Style</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8 space-y-4">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Font Style</h1>
        <div class="p-4 bg-blue-50 rounded-xl">
            <p class="text-gray-800"><span class="font-semibold">Normal:</span> Teks biasa tanpa miring</p>
        </div>
        <div class="p-4 bg-green-50 rounded-xl">
            <p class="italic text-gray-800"><span class="font-semibold not-italic">Italic:</span> Teks miring untuk penekanan atau kata asing</p>
        </div>
        <div class="p-4 bg-yellow-50 rounded-xl">
            <p class="not-italic text-gray-800"><span class="font-semibold">not-italic:</span> Mematikan italic <em class="italic">(tapi em tetap italic)</em></p>
        </div>
        <div class="p-4 bg-purple-50 rounded-xl text-center">
            <p class="text-sm text-gray-500">Gunakan <code class="text-purple-600">italic</code> untuk kata asing seperti <span class="italic">vis-à-vis</span> atau <span class="italic">déjà vu</span></p>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- `italic` untuk teks miring, `not-italic` untuk mematikan italic
- Cocok untuk penekanan, kata asing, judul buku, kutipan
- `not-italic` berguna untuk override elemen yang defaultnya italic
