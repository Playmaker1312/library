# Menggunakan Font Family di Tailwind

## Analogi: Perpustakaan Digital

Perpustakaan memiliki tiga jenis rak buku: rak buku tulis (serif) untuk novel klasik, rak buku modern (sans) untuk majalah, dan rak buku mesin ketik (mono) untuk naskah kode. Setiap jenis tulisan memiliki rak khusus yang mencerminkan karakternya.

## Penjelasan Detail

Tailwind menyediakan tiga kelas font family utama: `font-sans` untuk font sans-serif (system font stack default seperti Inter, Segoe UI, Roboto), `font-serif` untuk font serif seperti Georgia, Cambria, dan `font-mono` untuk font monospace seperti Menlo, Monaco, Consolas. Default font-sans Tailwind menggunakan system font stack yang dioptimalkan untuk performa dan konsistensi lintas OS. Font family bisa dikustomisasi di `tailwind.config.js` dengan menambah atau mengubah nilai di `theme.fontFamily`. Untuk menggunakan font kustom, daftarkan di CSS dengan `@font-face` atau dari Google Fonts, lalu tambahkan ke konfigurasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Font Family</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8 space-y-6">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Font Family</h1>
        <div class="space-y-4">
            <div class="p-4 bg-blue-50 rounded-xl">
                <p class="font-sans text-lg text-blue-900">font-sans: Sans-serif modern</p>
                <p class="font-sans text-sm text-blue-600">The quick brown fox jumps over the lazy dog</p>
            </div>
            <div class="p-4 bg-green-50 rounded-xl">
                <p class="font-serif text-lg text-green-900">font-serif: Serif klasik</p>
                <p class="font-serif text-sm text-green-600">The quick brown fox jumps over the lazy dog</p>
            </div>
            <div class="p-4 bg-purple-50 rounded-xl">
                <p class="font-mono text-lg text-purple-900">font-mono: Monospace</p>
                <p class="font-mono text-sm text-purple-600">The quick brown fox jumps over the lazy dog</p>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Tiga font family: font-sans (default), font-serif, font-mono
- font-sans menggunakan system font stack yang optimal
- Font kustom bisa ditambahkan melalui konfigurasi tailwind.config.js
