# Menggunakan Text Decoration di Tailwind

## Analogi: Perpustakaan Digital

Text decoration seperti alat stabilo dan coretan di perpustakaan. Garis bawah (underline) untuk judul penting, garis atas (overline) untuk efek dekoratif, garis tengah (line-through) untuk mencoret item yang sudah dihapus, dan tanpa garis (no-underline) untuk link yang tidak ingin digarisbawahi.

## Penjelasan Detail

Tailwind menyediakan kelas text decoration: `underline` (garis bawah), `overline` (garis atas), `line-through` (garis tengah/coret), `no-underline` (tanpa garis). `underline` adalah default untuk tag `<a>` dan sering digunakan untuk penekanan atau judul. `overline` jarang digunakan namun bisa untuk efek dekoratif unik. `line-through` menampilkan teks yang dicoret, berguna untuk menunjukkan item yang sudah dihapus atau tidak tersedia. `no-underline` berguna untuk menghilangkan garis bawah default pada link, misalnya di navigasi atau tombol. Semua kelas bisa dikombinasikan dengan warna dekorasi menggunakan `decoration-{color}` dan ketebalan dengan `decoration-{width}`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Decoration</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8 space-y-5">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Text Decoration</h1>
        <div class="p-4 bg-blue-50 rounded-lg">
            <p class="underline text-lg text-blue-800">underline - Teks dengan garis bawah</p>
        </div>
        <div class="p-4 bg-green-50 rounded-lg">
            <p class="overline text-lg text-green-800">overline - Teks dengan garis atas</p>
        </div>
        <div class="p-4 bg-red-50 rounded-lg">
            <p class="line-through text-lg text-red-800">line-through - Teks dicoret (tidak tersedia)</p>
        </div>
        <div class="p-4 bg-gray-100 rounded-lg">
            <a href="#" class="no-underline text-lg text-gray-800 hover:underline">no-underline - Link tanpa garis bawah (hover untuk lihat)</a>
        </div>
        <div class="p-4 bg-purple-50 rounded-lg">
            <p class="underline decoration-purple-500 decoration-2 text-lg text-purple-800">Dekorasi dengan warna dan ketebalan</p>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Empat dekorasi: underline, overline, line-through, no-underline
- Bisa dikombinasikan dengan warna (decoration-{color}) dan ketebalan (decoration-{width})
- no-underline berguna untuk menghilangkan garis bawah default link
