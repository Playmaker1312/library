# Menggunakan Line Height di Tailwind

## Analogi: Perpustakaan Digital

Line height seperti jarak antar baris dalam buku. Jika terlalu rapat, mata mudah lelah. Jika terlalu renggang, teks terlihat putus-putus. Perpustakaan mengatur jarak baca yang nyaman agar pengunjung bisa membaca berjam-jam tanpa sakit kepala.

## Penjelasan Detail

Tailwind menyediakan kelas line height (leading): `leading-none` (1 - tanpa spasi), `leading-tight` (1.25), `leading-snug` (1.375), `leading-normal` (1.5 - default), `leading-relaxed` (1.625), `leading-loose` (2). Nilai adalah multiplier dari ukuran font. `leading-none` berguna untuk ikon atau teks satu baris agar vertikal center sempurna. `leading-tight` cocok untuk heading agar tidak terlalu renggang. `leading-normal` adalah default untuk teks body dengan kenyamanan baca optimal. `leading-relaxed` dan `leading-loose` untuk teks yang perlu banyak spasi, seperti paragraf pendek atau puisi. Pemilihan line height yang tepat sangat mempengaruhi keterbacaan teks.


## Poin Penting
- Lima tingkat: leading-none (1) hingga leading-loose (2)
- leading-normal (1.5) optimal untuk teks body
- leading-tight cocok untuk heading, leading-loose untuk teks pendek
