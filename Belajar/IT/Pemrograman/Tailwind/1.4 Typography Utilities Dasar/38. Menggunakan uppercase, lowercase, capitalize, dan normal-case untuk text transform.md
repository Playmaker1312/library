# Menggunakan Text Transform di Tailwind

## Analogi: Perpustakaan Digital

Text transform seperti mesin pengubah huruf di perpustakaan. Ada mode yang mengubah semua huruf menjadi besar (kapital), kecil (lowercase), atau hanya huruf pertama setiap kata yang besar (capitalize). Seperti mesin ketik yang bisa mengubah gaya huruf dengan satu tombol.

## Penjelasan Detail

Tailwind menyediakan kelas text transform: `uppercase` (semua huruf kapital), `lowercase` (semua huruf kecil), `capitalize` (huruf pertama setiap kata kapital), `normal-case` (kembali ke default tanpa transformasi). `uppercase` sering digunakan untuk judul, label tombol, header tabel, dan singkatan. `lowercase` jarang digunakan namun berguna untuk efek desain tertentu atau email. `capitalize` berguna untuk judul, nama orang, atau tempat. `normal-case` digunakan untuk mematikan transformasi pada elemen yang mewarisi text-transform dari induknya. Text transform murni visual dan tidak mengubah konten aktual - copy-paste akan tetap menghasilkan teks asli.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Transform</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8 space-y-5">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Text Transform</h1>
        <div class="p-4 bg-blue-50 rounded-lg">
            <p class="text-xs text-gray-400 mb-1">uppercase</p>
            <p class="uppercase text-lg font-bold text-blue-800 tracking-wide">Ini Teks Kapital Semua</p>
        </div>
        <div class="p-4 bg-green-50 rounded-lg">
            <p class="text-xs text-gray-400 mb-1">lowercase</p>
            <p class="lowercase text-lg text-green-800">Ini Teks Kecil Semua</p>
        </div>
        <div class="p-4 bg-yellow-50 rounded-lg">
            <p class="text-xs text-gray-400 mb-1">capitalize</p>
            <p class="capitalize text-lg text-yellow-800">setiap kata diawali huruf kapital</p>
        </div>
        <div class="p-4 bg-gray-100 rounded-lg">
            <p class="text-xs text-gray-400 mb-1">normal-case (default)</p>
            <p class="normal-case text-lg text-gray-800">Teks normal tanpa transformasi</p>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Empat transformasi: uppercase, lowercase, capitalize, normal-case
- uppercase untuk judul dan label, capitalize untuk nama
- Transformasi murni visual, tidak mengubah konten aktual
