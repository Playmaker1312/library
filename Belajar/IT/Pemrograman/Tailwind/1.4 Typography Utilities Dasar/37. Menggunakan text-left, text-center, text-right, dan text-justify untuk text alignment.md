# Menggunakan Text Alignment di Tailwind

## Analogi: Perpustakaan Digital

Text alignment seperti posisi tulisan di papan pengumuman perpustakaan. Ada yang rata kiri seperti daftar isi, rata tengah seperti judul bab, rata kanan seperti tanggal surat, dan rata kiri-kanan seperti paragraf buku cetak. Setiap posisi memiliki fungsi dan estetika tersendiri.

## Penjelasan Detail

Tailwind menyediakan kelas text alignment: `text-left` (rata kiri), `text-center` (rata tengah), `text-right` (rata kanan), `text-justify` (rata kiri-kanan). `text-left` adalah default untuk bahasa yang dibaca dari kiri ke kanan, cocok untuk paragraf panjang dan konten utama. `text-center` digunakan untuk judul, tombol, atau elemen yang ingin ditonjolkan di tengah. `text-right` berguna untuk elemen seperti tanggal, harga, atau bahasa yang dibaca kanan ke kiri. `text-justify` meratakan teks di kedua sisi, memberikan tampilan seperti buku cetak, cocok untuk artikel panjang. Alignment bisa dikombinasikan dengan responsive prefix untuk mengubah alignment di ukuran layar berbeda.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Alignment</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8 space-y-5">
        <h1 class="text-2xl font-bold text-gray-900 text-center">Text Alignment</h1>
        <div>
            <p class="text-xs text-gray-400 mb-1">text-left (default)</p>
            <p class="text-left bg-blue-50 p-3 rounded-lg text-gray-700">Teks rata kiri. Cocok untuk paragraf panjang dan konten utama website.</p>
        </div>
        <div>
            <p class="text-xs text-gray-400 mb-1">text-center</p>
            <p class="text-center bg-green-50 p-3 rounded-lg text-gray-700">Teks rata tengah. Ideal untuk judul dan tombol.</p>
        </div>
        <div>
            <p class="text-xs text-gray-400 mb-1">text-right</p>
            <p class="text-right bg-yellow-50 p-3 rounded-lg text-gray-700">Teks rata kanan. Untuk tanggal atau harga.</p>
        </div>
        <div>
            <p class="text-xs text-gray-400 mb-1">text-justify</p>
            <p class="text-justify bg-purple-50 p-3 rounded-lg text-gray-700">Teks rata kiri dan kanan. Memberikan tampilan seperti buku cetak profesional, sangat cocok untuk artikel panjang dengan banyak paragraf.</p>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Empat alignment: left, center, right, justify
- text-left default untuk konten utama, text-center untuk judul
- text-justify untuk tampilan seperti buku cetak pada artikel panjang
