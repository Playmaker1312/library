# Menggunakan Font Size di Tailwind

## Analogi: Perpustakaan Digital

Ukuran teks di Tailwind seperti ukuran font di buku: dari catatan kaki (xs) hingga judul besar (9xl). Setiap ukuran sudah diatur proporsional, dari 12px untuk teks kecil hingga 128px untuk teks raksasa. Tidak perlu lagi mengingat angka pasti, cukup gunakan nama ukurannya.

## Penjelasan Detail

Tailwind menyediakan skala font size yang konsisten: `text-xs` (12px), `text-sm` (14px), `text-base` (16px - default), `text-lg` (18px), `text-xl` (20px), `text-2xl` (24px), `text-3xl` (30px), `text-4xl` (36px), `text-5xl` (48px), `text-6xl` (60px), `text-7xl` (72px), `text-8xl` (96px), dan `text-9xl` (128px). Setiap ukuran juga memiliki line height default yang sesuai. Class `text-base` adalah ukuran default untuk teks body. Untuk ukuran kustom di luar skala, gunakan arbitrary value seperti `text-[32px]`. Skala ini mengikuti ukuran tipografi standar dan proporsional untuk hierarki visual yang baik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Font Size</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8">
        <h1 class="text-2xl font-bold text-gray-900 text-center mb-6">Font Size Scale</h1>
        <div class="space-y-2">
            <p class="text-xs text-gray-600">text-xs (12px) - Catatan kaki</p>
            <p class="text-sm text-gray-600">text-sm (14px) - Keterangan</p>
            <p class="text-base text-gray-800">text-base (16px) - Teks body default</p>
            <p class="text-lg text-gray-800">text-lg (18px) - Teks lebih besar</p>
            <p class="text-xl font-medium text-gray-900">text-xl (20px) - Sub-heading</p>
            <p class="text-2xl font-bold text-gray-900">text-2xl (24px) - Heading kecil</p>
            <p class="text-3xl font-bold text-gray-900">text-3xl (30px) - Heading</p>
            <p class="text-4xl font-bold text-gray-900">text-4xl (36px) - Heading besar</p>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Skala font: text-xs (12px) hingga text-9xl (128px)
- text-base (16px) adalah ukuran default untuk body text
- Gunakan arbitrary value text-[ukuran] untuk ukuran kustom
