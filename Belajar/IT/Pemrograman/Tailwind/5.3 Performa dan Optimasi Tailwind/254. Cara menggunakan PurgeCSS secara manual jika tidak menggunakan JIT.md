# Cara menggunakan PurgeCSS secara manual jika tidak menggunakan JIT
## Analogi: Perpustakaan Digital
Jika JIT adalah petugas yang hanya menempatkan buku yang dipesan, PurgeCSS adalah petugas yang membersihkan rak dari buku-buku yang tidak pernah dipinjam selama bertahun-tahun. Keduanya bertujuan mengurangi jumlah buku di rak, tetapi dengan pendekatan berbeda: JIT proaktif, PurgeCSS reaktif.
## Penjelasan Detail
Meskipun Tailwind JIT sudah menjadi default sejak v3, beberapa proyek mungkin masih menggunakan mode klasik (AOT) karena alasan kompatibilitas atau workflow tertentu. Untuk mode klasik, Anda perlu menggunakan PurgeCSS (atau `@fullhuman/postcss-purgecss`) secara manual untuk menghapus class Tailwind yang tidak terpakai dari CSS final. PurgeCSS bekerja dengan memindai file HTML/template Anda, mencari class yang digunakan, lalu membandingkannya dengan CSS yang dihasilkan. Class yang tidak ditemukan akan dihapus. Konfigurasi dilakukan di `postcss.config.js` atau sebagai plugin di build tool. Penting untuk dikonfigurasi dengan benar: tentukan paths file yang dipindai, ekstraktor untuk bahasa template yang digunakan (seperti Blade, ERB, atau EJS), dan pastikan class dinamis tetap dipertahankan. Mode JIT sebenarnya sudah mengintegrasikan PurgeCSS secara internal, jadi Anda tidak perlu mengonfigurasinya lagi.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>PurgeCSS Manual - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-3xl mx-auto space-y-8">
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-4">Konfigurasi PurgeCSS</h2>
            
            <h3 class="font-semibold text-gray-700 mb-2">postcss.config.js (mode klasik)</h3>
            <pre class="p-4 bg-gray-800 text-green-400 rounded-lg text-sm overflow-x-auto"><code>module.exports = {
  plugins: [
    require('tailwindcss'),
    require('@fullhuman/postcss-purgecss')({
      content: [
        './src/**/*.html',
        './src/**/*.js',
        './src/**/*.jsx',
        './src/**/*.vue',
      ],
      // Ekstraktor default untuk HTML/JS
      defaultExtractor: content => {
        // Tangkap class yang ditulis di template
        return content.match(/[\w-/:]+(?<!:)/g) || [];
      },
      // Safelist: class yang tidak boleh dihapus
      safelist: ['html', 'body', /^bg-/, /^text-/],
    }),
    require('cssnano')({ preset: 'default' }),
  ],
}</code></pre>

            <!-- Perbandingan -->
            <div class="mt-6 grid md:grid-cols-2 gap-4">
                <div class="p-4 bg-gray-50 rounded-lg">
                    <h4 class="font-semibold text-gray-700">PurgeCSS Manual (Mode Klasik)</h4>
                    <ul class="mt-2 text-sm text-gray-600 space-y-1">
                        <li>• Dijalankan setelah Tailwind generate semua CSS</li>
                        <li>• Menghapus class yang tidak terpakai</li>
                        <li>• Perlu konfigurasi ekstraktor</li>
                        <li>• Rentan kehilangan class dinamis jika tidak hati-hati</li>
                    </ul>
                </div>
                <div class="p-4 bg-green-50 rounded-lg">
                    <h4 class="font-semibold text-green-700">JIT Engine (Mode Baru)</h4>
                    <ul class="mt-2 text-sm text-green-600 space-y-1">
                        <li>• Hanya generate class yang digunakan</li>
                        <li>• Tidak perlu PurgeCSS terpisah</li>
                        <li>• Konfigurasi content yang lebih sederhana</li>
                        <li>• Mendukung arbitrary values</li>
                    </ul>
                </div>
            </div>

            <!-- Safelist Tips -->
            <div class="mt-6 p-4 bg-yellow-50 rounded-lg">
                <h4 class="font-semibold text-yellow-800">Tips Safelist untuk Class Dinamis</h4>
                <div class="mt-2 text-sm text-yellow-700 space-y-2">
                    <p>Jika Anda membuat class secara dinamis di JavaScript:</p>
                    <pre class="p-2 bg-gray-800 text-green-400 rounded text-xs"><code>// ❌ Class tidak akan terdeteksi PurgeCSS
const color = 'red';
element.classList.add(`bg-${color}-500`);

// ✅ Gunakan safelist di konfigurasi
safelist: ['bg-red-500', 'bg-blue-500', 'bg-green-500']</code></pre>
                    <p>Atau gunakan pattern regex:</p>
                    <pre class="p-2 bg-gray-800 text-green-400 rounded text-xs"><code>safelist: [
  { pattern: /^bg-(red|blue|green)-(500|600)$/ },
  { pattern: /^text-(white|gray)-(100|200)$/ },
]</code></pre>
                </div>
            </div>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- PurgeCSS diperlukan jika menggunakan Tailwind mode klasik (non-JIT) untuk menghapus CSS yang tidak terpakai
- Konfigurasi ekstraktor harus sesuai dengan bahasa template yang digunakan
- Gunakan safelist untuk class yang dibangun secara dinamis agar tidak ikut terhapus
