# Cara menggunakan Tailwind dengan module CSS untuk isolasi
## Analogi: Perpustakaan Digital
Module CSS seperti memberikan setiap buku barcode unik yang tidak akan tertukar dengan buku lain. Dengan module CSS, nama class Anda di-scope secara otomatis sehingga tidak ada konflik antara komponen yang berbeda. Ini menggabungkan kecepatan Tailwind dengan keamanan isolasi module CSS.
## Penjelasan Detail
Module CSS adalah teknik di CSS di mana nama class di-scope secara lokal ke file tersebut, mencegah bentrokan nama class. Saat menggunakan Tailwind dengan module CSS, Anda bisa menulis utility class Tailwind di dalam file `.module.css` atau langsung di JSX dengan modul. Ada dua pendekatan: (1) Menulis Tailwind di module CSS menggunakan `@apply` — ini memberi Anda isolasi sambil tetap menggunakan utility class. (2) Menggabungkan string class module dengan class Tailwind di komponen. Pendekatan kedua lebih umum dan lebih fleksibel. Tool seperti Vite dan Next.js mendukung module CSS secara bawaan. Anda tinggal mengimpor file `.module.css` dan menggunakan class yang di-export sebagai objek JavaScript. Untuk proyek React dengan Vite, module CSS + Tailwind adalah kombinasi yang powerful: Tailwind untuk utility, module CSS untuk komponen yang perlu isolasi ketat.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tailwind + Module CSS - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <style>
        /* Simulasi module CSS: class di-scope dengan nama unik */
        ._card_abc123 {
            @apply p-6 bg-white rounded-xl shadow-md border border-gray-100;
        }
        ._card_abc123 h3 {
            @apply text-xl font-bold text-gray-800 mb-3;
        }
        ._card_abc123 p {
            @apply text-gray-600;
        }
        
        ._btn_xyz789 {
            @apply px-5 py-2 rounded-lg font-semibold transition;
        }
        ._btn_xyz789--primary {
            @apply bg-blue-500 text-white hover:bg-blue-600;
        }
        ._btn_xyz789--secondary {
            @apply bg-gray-200 text-gray-700 hover:bg-gray-300;
        }
    </style>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-3xl mx-auto space-y-8">
        <div class="p-6 bg-white rounded-xl shadow-md">
            <h2 class="text-xl font-bold text-gray-800 mb-2">Simulasi Module CSS + Tailwind</h2>
            <p class="text-gray-500 text-sm mb-6">Di bawah ini adalah simulasi bagaimana module CSS bekerja dengan Tailwind. Class memiliki nama unik (hash) untuk isolasi.</p>

            <!-- Card dengan module CSS style -->
            <div class="space-y-4">
                <div class="_card_abc123">
                    <h3>Komponen Card (Terisolasi)</h3>
                    <p>Class pada card ini menggunakan <code>@apply</code> di dalam module CSS. Nama class-nya unik sehingga tidak akan bentrok dengan komponen lain.</p>
                    <div class="mt-4 flex gap-3">
                        <button class="_btn_xyz789 _btn_xyz789--primary">Simpan</button>
                        <button class="_btn_xyz789 _btn_xyz789--secondary">Batal</button>
                    </div>
                </div>
            </div>

            <!-- Kode module CSS -->
            <div class="mt-8 grid md:grid-cols-2 gap-6">
                <div>
                    <h3 class="font-semibold text-gray-700 mb-2">Card.module.css</h3>
                    <pre class="p-3 bg-gray-800 text-green-400 rounded-lg text-xs overflow-x-auto"><code>.card {
  @apply p-6 bg-white rounded-xl
         shadow-md border border-gray-100;
}

.title {
  @apply text-xl font-bold
         text-gray-800 mb-3;
}

.description {
  @apply text-gray-600;
}</code></pre>
                </div>
                <div>
                    <h3 class="font-semibold text-gray-700 mb-2">Card.jsx (React)</h3>
                    <pre class="p-3 bg-gray-800 text-yellow-400 rounded-lg text-xs overflow-x-auto"><code>import styles from './Card.module.css';
import 'tailwindcss/tailwind.css';

export function Card({ title, desc }) {
  return (
    &lt;div className={styles.card}&gt;
      &lt;h3 className={styles.title}&gt;
        {title}
      &lt;/h3&gt;
      &lt;p className={styles.description}&gt;
        {desc}
      &lt;/p&gt;
    &lt;/div&gt;
  );
}</code></pre>
                </div>
            </div>

            <!-- Keuntungan -->
            <div class="mt-6 p-4 bg-green-50 rounded-lg">
                <h4 class="font-semibold text-green-800">Keuntungan Kombinasi Module CSS + Tailwind</h4>
                <ul class="mt-2 text-sm text-green-700 space-y-1">
                    <li>✓ Isolasi class: tidak ada bentrokan nama antar komponen</li>
                    <li>✓ Utility class tetap bisa digunakan via @apply</li>
                    <li>✓ Cocok untuk design system / component library</li>
                    <li>✓ Tree-shaking tetap berfungsi (class yang tidak dipakai dihapus)</li>
                </ul>
            </div>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- Module CSS memberikan isolasi class dengan hashing otomatis, mencegah konflik nama
- Gunakan `@apply` di dalam module CSS untuk menggabungkan utility Tailwind dengan isolasi
- Kombinasi Tailwind + module CSS cocok untuk proyek design system atau component library
