# Cara memastikan konfigurasi content sudah benar untuk menghindari class yang hilang di production
## Analogi: Perpustakaan Digital
Konfigurasi `content` seperti daftar rak yang harus diperiksa petugas perpustakaan saat menentukan buku mana yang akan disusun. Jika petugas lupa memeriksa rak tertentu, buku di rak itu tidak akan tersortir. Akibatnya, pengunjung tidak bisa menemukan buku tersebut.
## Penjelasan Detail
Di Tailwind JIT, konfigurasi `content` di `tailwind.config.js` memberitahu compiler file mana yang harus dipindai untuk menemukan class Tailwind. Jika konfigurasi ini salah atau tidak lengkap, class yang Anda gunakan di file yang tidak terdaftar tidak akan di-generate di CSS production. Akibatnya, style hilang di production meskipun berfungsi di development. Praktik terbaik: gunakan glob pattern yang mencakup semua file yang mungkin mengandung class Tailwind, termasuk file `.html`, `.js`, `.jsx`, `.ts`, `.tsx`, `.vue`, `.php`, `.blade.php`, `.erb`, dan lainnya sesuai proyek Anda. Jika menggunakan monorepo atau package eksternal yang mengekspor komponen Tailwind, pastikan path package tersebut juga tercakup.

```html
    './src/**/*.{js,jsx,ts,tsx}',

                    <p class="text-sm text-red-600 mt-1">Contoh: Anda punya file <code>src/components/Button.tsx</code> tapi content hanya <code>'./src/**/*.js'</code> — file .tsx tidak terdeteksi.</p>

                </div>

                    <p class="text-sm text-green-600 mt-1">Solusi: gunakan class lengkap <code>const classes = { red: 'bg-red-500', blue: 'bg-blue-500' }</code> atau tambahkan class ke daftar safelist.</p>

                <div class="p-4 bg-red-50 rounded-lg">

                    <p class="text-sm text-green-600 mt-1">Solusi: tambahkan path node_modules dari library yang digunakan: <code>'./node_modules/library/dist/*.js'</code>.</p>

                    <span class="text-blue-500 font-bold">1</span>
                    <div>
                        <div class="font-medium text-blue-800">Periksa file CSS output</div>
                        <p class="text-sm text-blue-600">Cari class yang hilang di file CSS production. Jika tidak ada, berarti JIT tidak mendeteksinya.</p>
                    </div>
                </div>
                <div class="flex items-start gap-3 p-3 bg-blue-50 rounded-lg">

```
## Poin Penting
- Konfigurasi `content` harus mencakup semua file yang mengandung class Tailwind dengan glob pattern yang tepat
- Class yang dibangun secara dinamis (string concatenation) tidak terdeteksi JIT — gunakan objek lookup atau safelist
- Gunakan `safelist` untuk class yang tidak bisa dideteksi oleh scanner JIT
