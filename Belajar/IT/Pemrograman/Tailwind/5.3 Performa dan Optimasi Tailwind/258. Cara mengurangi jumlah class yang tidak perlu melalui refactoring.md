# Cara mengurangi jumlah class yang tidak perlu melalui refactoring
## Analogi: Perpustakaan Digital
Seiring waktu, rak perpustakaan bisa dipenuhi buku-buku usang, edisi duplikat, dan buku yang sudah tidak relevan. Refactoring Tailwind seperti proses penyortiran: buku yang sama disatukan, yang tidak perlu dibuang, dan yang tersisa diatur dengan rapi agar mudah ditemukan.
## Penjelasan Detail
Refactoring class Tailwind bertujuan mengurangi pengulangan dan menyederhanakan markup tanpa mengubah hasil visual. Langkah-langkahnya: (1) Identifikasi pola class yang berulang — gunakan pencarian "find in project" untuk melihat frekuensi kemunculan sekelompok class. (2) Ekstrak pola berulang ke komponen (di React/Vue) atau partial (di Blade/Laravel). (3) Gunakan `@apply` untuk pola yang sangat stabil dan muncul di banyak file non-JS. (4) Periksa class yang tidak digunakan — class yang ditambahkan saat eksperimen tapi tidak dihapus. (5) Manfaatkan fitur group untuk menghindari pengulangan variant class pada parent-child. (6) Gunakan `theme()` function di CSS untuk mengambil nilai dari konfigurasi Tailwind jika Anda perlu nilai yang sama di CSS kustom. Refactoring bukan hanya tentang mengurangi jumlah baris, tetapi juga meningkatkan maintainability. Prioritaskan refactoring pada komponen yang paling sering berubah.

```html
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Refactoring Class - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-4xl mx-auto space-y-8">
        <!-- Sebelum Refactoring -->
        <div class="p-6 bg-white rounded-xl shadow-md border-l-4 border-red-400">
            <h2 class="text-xl font-bold text-red-700 mb-4">Sebelum Refactoring</h2>
            <div class="space-y-3">
                <!-- Banyak class berulang -->
                <div class="flex items-center justify-between p-4 bg-white border border-gray-200 rounded-lg hover:shadow-md transition-shadow">
                    <span class="text-sm font-semibold text-gray-800">Item 1</span>
                    <span class="px-2 py-1 text-xs bg-blue-100 text-blue-700 rounded-full">Active</span>
                </div>
                <div class="flex items-center justify-between p-4 bg-white border border-gray-200 rounded-lg hover:shadow-md transition-shadow">
                    <span class="text-sm font-semibold text-gray-800">Item 2</span>
                    <span class="px-2 py-1 text-xs bg-gray-100 text-gray-600 rounded-full">Inactive</span>
                </div>
                <div class="flex items-center justify-between p-4 bg-white border border-gray-200 rounded-lg hover:shadow-md transition-shadow">
                    <span class="text-sm font-semibold text-gray-800">Item 3</span>
                    <span class="px-2 py-1 text-xs bg-green-100 text-green-700 rounded-full">Completed</span>
                </div>
            </div>
            <pre class="mt-4 p-3 bg-gray-800 text-red-400 rounded-lg text-xs overflow-x-auto"><code>&lt;!-- Pola yang sama diulang 3x --&gt;
flex items-center justify-between p-4 
bg-white border border-gray-200 rounded-lg

        </div>

        <!-- Sesudah Refactoring -->
        <div class="p-6 bg-white rounded-xl shadow-md border-l-4 border-green-400">
            <h2 class="text-xl font-bold text-green-700 mb-4">Sesudah Refactoring</h2>
            
            <!-- Definisikan komponen via style (simulasi) -->
            <style>
                .list-item { @apply flex items-center justify-between p-4 bg-white border border-gray-200 rounded-lg hover:shadow-md transition-shadow; }
                .badge { @apply px-2 py-1 text-xs rounded-full font-medium; }
                .badge-blue { @apply bg-blue-100 text-blue-700; }
                .badge-gray { @apply bg-gray-100 text-gray-600; }
                .badge-green { @apply bg-green-100 text-green-700; }
            </style>

            <div class="space-y-3">
                <div class="list-item">
                    <span class="text-sm font-semibold text-gray-800">Item 1</span>
                    <span class="badge badge-blue">Active</span>
                </div>
                <div class="list-item">
                    <span class="text-sm font-semibold text-gray-800">Item 2</span>
                    <span class="badge badge-gray">Inactive</span>
                </div>
                <div class="list-item">
                    <span class="text-sm font-semibold text-gray-800">Item 3</span>
                    <span class="badge badge-green">Completed</span>
                </div>
            </div>

            <pre class="mt-4 p-3 bg-gray-800 text-green-400 rounded-lg text-xs overflow-x-auto"><code>/* CSS: pola diekstrak ke @apply */
.list-item {
  @apply flex items-center justify-between 
         p-4 bg-white border border-gray-200 
         rounded-lg hover:shadow-md transition-shadow;
}
.badge {
  @apply px-2 py-1 text-xs rounded-full font-medium;
}

&lt;!-- HTML jadi lebih bersih --&gt;
&lt;div class="list-item"&gt;
  &lt;span class="badge badge-blue"&gt;Active&lt;/span&gt;
&lt;/div&gt;</code></pre>
        </div>

        <!-- Refactoring Tips -->
        <div class="p-6 bg-indigo-50 border border-indigo-200 rounded-xl">
            <h3 class="font-bold text-indigo-800">Langkah Refactoring</h3>
            <ol class="mt-2 text-sm text-indigo-700 space-y-2 list-decimal list-inside">
                <li>Cari pola class berulang dengan fitur search di editor</li>
                <li>Ekstrak ke komponen (React/Vue) atau partial template</li>
                <li>Jika tidak pakai framework, gunakan @apply di CSS</li>
                <li>Hapus class yang tidak terpakai (hasil eksperimen)</li>
                <li>Gunakan group variant untuk mengurangi pengulangan class pada parent-child</li>
                <li>Dokumentasikan komponen yang sudah di-refactor</li>
            </ol>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- Identifikasi pola class berulang dengan fitur search, lalu ekstrak ke komponen atau @apply
- Prioritaskan refactoring pada komponen yang paling sering berubah atau paling banyak diulang
- Refactoring bukan hanya mengurangi jumlah baris, tetapi juga meningkatkan maintainability
