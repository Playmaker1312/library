# Mengukur performa halaman dengan Tailwind menggunakan Lighthouse
## Analogi: Perpustakaan Digital
Lighthouse seperti lembaga inspeksi perpustakaan yang memberikan skor untuk berbagai aspek: seberapa cepat pengunjung bisa masuk, seberapa mudah menemukan buku, dan seberapa baik perpustakaan melayani semua pengunjung. Skor ini membantu Anda tahu apa yang perlu diperbaiki.
## Penjelasan Detail
Lighthouse adalah alat audit otomatis built-in di Chrome DevTools yang mengukur performa, aksesibilitas, SEO, dan best practices. Untuk project Tailwind, Lighthouse sangat berguna untuk memastikan utility-first approach tidak berdampak negatif pada performa. Metrik utama yang perlu diperhatikan: First Contentful Paint (FCP), Largest Contentful Paint (LCP), Time to Interactive (TTI), Total Blocking Time (TBT), dan Cumulative Layout Shift (CLS). Tailwind yang dikonfigurasi dengan benar (JIT + minify) biasanya tidak menyebabkan masalah performa signifikan — file CSS yang kecil justru membantu. Namun, Lighthouse bisa mengungkap masalah seperti: CSS yang tidak digunakan (jika konfigurasi content salah), render-blocking CSS (bisa diatasi dengan critical CSS), atau layout shift karena font atau gambar yang tidak dimuat dengan benar.
