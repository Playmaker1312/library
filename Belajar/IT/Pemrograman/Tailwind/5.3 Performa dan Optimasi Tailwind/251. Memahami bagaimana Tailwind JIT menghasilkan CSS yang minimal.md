# Memahami bagaimana Tailwind JIT menghasilkan CSS yang minimal
## Analogi: Perpustakaan Digital
Tailwind JIT seperti petugas perpustakaan yang hanya menyalin halaman buku yang benar-benar diperlukan pengunjung, bukan seluruh buku. Daripada menyediakan katalog raksasa yang berisi semua kemungkinan utility class, JIT hanya menghasilkan CSS untuk class yang benar-benar Anda gunakan dalam proyek.
## Penjelasan Detail
Tailwind JIT (Just-In-Time) engine adalah generasi terbaru dari compiler Tailwind yang menghasilkan CSS secara real-time saat pengembangan. Alih-alih menghasilkan file CSS besar yang berisi semua kemungkinan kombinasi utility (bisanya mencapai puluhan MB), JIT memindai file template Anda dan hanya menghasilkan CSS untuk class yang terdeteksi. Hasilnya, file CSS production menjadi sangat kecil — seringkali hanya 5-15 kB setelah kompresi. JIT juga memungkinkan penggunaan varian arbitrari seperti `text-[32px]`, `bg-[#1da1f1]`, atau `grid-cols-[200px_1fr]` yang tidak mungkin dilakukan di mode klasik. Proses generation terjadi per request, sehingga saat development Anda selalu mendapatkan CSS terbaru tanpa perlu build ulang penuh. Kecepatan build juga meningkat drastis karena JIT hanya memproses class yang digunakan.

## Poin Penting
- JIT hanya menghasilkan CSS untuk class yang benar-benar digunakan dalam proyek
- Hasil CSS production sangat kecil (5-15 kB gzip) dibanding mode klasik (MB)
- JIT mendukung arbitrary values dengan sintaks `[nilai]` yang tidak ada di mode klasik
