# Cara mengoptimasi loading Tailwind CSS menggunakan critical CSS
## Analogi: Perpustakaan Digital
Critical CSS seperti menyediakan peta utama perpustakaan di pintu masuk, sementara katalog lengkap disediakan di dalam. Pengunjung langsung tahu tata letak dasar tanpa harus menunggu seluruh katalog di-download. Ini mempercepat waktu yang dibutuhkan pengunjung untuk mulai menggunakan perpustakaan.
## Penjelasan Detail
Critical CSS adalah teknik mengekstrak CSS yang diperlukan untuk merender konten "above the fold" (bagian halaman yang terlihat pertama kali tanpa scroll) dan menyisipkannya langsung di `<head>` sebagai inline `<style>`. Sisanya (non-critical CSS) dimuat secara asinkron. Untuk Tailwind, ini berarti utility class yang digunakan di hero section, navigasi, dan header perlu di-inline. Keuntungan: First Contentful Paint (FCP) dan Largest Contentful Paint (LCP) membaik drastis karena browser tidak perlu menunggu file CSS eksternal selesai di-download. Alat seperti `critical` (Node.js), PurgeCSS Critical, atau `penthouse` dapat mengekstrak critical CSS secara otomatis. Untuk Tailwind, karena class-nya prediktif, Anda bisa menentukan secara manual utility class apa yang termasuk "critical" berdasarkan komponen yang selalu muncul di atas fold.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Critical CSS - Tailwind</title>
    <!-- Critical CSS (inline) -->
    <style>
        /* Critical: utility untuk above-the-fold */
        body { margin: 0; font-family: system-ui, sans-serif; }
        .bg-gradient-to-r { background: linear-gradient(to right, #3b82f6, #1d4ed8); }
        .text-white { color: #fff; }
        .p-6 { padding: 1.5rem; }
        .text-3xl { font-size: 1.875rem; line-height: 2.25rem; }
        .font-bold { font-weight: 700; }
        .mb-4 { margin-bottom: 1rem; }
        .max-w-4xl { max-width: 56rem; }
        .mx-auto { margin-left: auto; margin-right: auto; }
        .rounded-lg { border-radius: 0.5rem; }
        .shadow-md { box-shadow: 0 4px 6px -1px rgb(0 0 0 / 0.1); }
        .bg-white { background-color: #fff; }
        .text-blue-600 { color: #2563eb; }
        .px-4 { padding-left: 1rem; padding-right: 1rem; }
        .py-2 { padding-top: 0.5rem; padding-bottom: 0.5rem; }
        .inline-block { display: inline-block; }
        .mt-8 { margin-top: 2rem; }
    </style>
    <!-- Non-critical CSS dimuat asinkron -->
    <link rel="preload" href="https://cdn.tailwindcss.com" as="script">
    <script>
        // Load Tailwind setelah halaman dimuat
        window.addEventListener('load', function() {
            var script = document.createElement('script');
            script.src = 'https://cdn.tailwindcss.com';
            document.head.appendChild(script);
        });
    </script>
    <noscript>
        <!-- Fallback jika JS nonaktif -->
        <link rel="stylesheet" href="https://cdn.tailwindcss.com">
    </noscript>
</head>
<body>
    <!-- Above the fold: menggunakan critical CSS -->
    <div class="bg-gradient-to-r from-blue-500 to-blue-700 text-white p-6">
        <div class="max-w-4xl mx-auto">
            <h1 class="text-3xl font-bold mb-4">Critical CSS dengan Tailwind</h1>
            <p class="text-lg opacity-90">Bagian ini menggunakan critical CSS yang di-inline. Konten di bawah fold akan menggunakan Tailwind penuh setelah di-load.</p>
        </div>
    </div>

    <!-- Above the fold content -->
    <div class="max-w-4xl mx-auto mt-8 p-6 bg-white rounded-lg shadow-md">
        <h2 class="text-xl font-bold text-blue-600 mb-4">Apa itu Critical CSS?</h2>
        <p class="text-gray-600">Critical CSS mengekstrak style yang diperlukan untuk konten above-the-fold dan menempatkannya langsung di <code>&lt;head&gt;</code>.</p>
        <div class="mt-4 inline-block px-4 py-2 bg-blue-600 text-white rounded-lg font-semibold">Manfaat</div>
    </div>

    <!-- Below the fold: menggunakan Tailwind penuh setelah di-load -->
    <div id="below-fold" class="max-w-4xl mx-auto mt-8 p-6 bg-white rounded-lg shadow-md">
        <h2 class="text-xl font-bold text-blue-600 mb-4">Konten di Bawah Fold</h2>
        <p class="text-gray-600 mb-4">Bagian ini baru akan di-style setelah file Tailwind selesai di-load. Sementara itu, tampilan dasar sudah cukup karena pengguna perlu scroll untuk melihat bagian ini.</p>
        <div class="grid md:grid-cols-3 gap-4">
            <div class="p-4 bg-gray-50 rounded-lg text-center">Fitur 1</div>
            <div class="p-4 bg-gray-50 rounded-lg text-center">Fitur 2</div>
            <div class="p-4 bg-gray-50 rounded-lg text-center">Fitur 3</div>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- Critical CSS mempercepat First Contentful Paint (FCP) dengan inline style untuk konten above-the-fold
- Gunakan Tailwind penuh secara asinkron setelah halaman dimuat untuk konten di bawah fold
- Tanpa JIT, Anda bisa menentukan "critical set" utility class secara manual berdasarkan komponen yang selalu muncul di atas fold
