# Cara menginstal dan mengkonfigurasi Tailwind CSS v4

## Analogi: Perpustakaan Digital

Proses instalasi Tailwind v4 seperti memindahkan koleksi buku ke apartemen baru yang sudah memiliki rak built-in. Di v3, Anda harus membeli rak (konfigurasi), mengatur label (plugin), dan menyusun buku satu per satu. Di v4, rak sudah terpasang dan tinggal ditempeli stiker sesuai preferensi Anda. Anda cukup membawa buku (memasang package) dan mulai menata dengan aturan CSS.

## Penjelasan Detail

Instalasi Tailwind v4 dimulai dengan package `tailwindcss` melalui npm atau pnpm tanpa perlu plugin PostCSS terpisah karena semuanya sudah terintegrasi. CLI Tailwind v4 dapat dijalankan langsung dengan perintah `npx @tailwindcss/cli` untuk project sederhana, atau diintegrasikan dengan Vite, Next.js, dan framework lain melalui adapter resmi. Konfigurasi dilakukan langsung di file CSS utama dengan `@import "tailwindcss"` sebagai titik awal, lalu mendefinisikan tema menggunakan `@theme`. Tidak ada lagi file `tailwind.config.js` yang terpisah—semua pengaturan dilakukan dengan CSS at-rules. Untuk project yang membutuhkan kustomisasi kompleks, Anda masih bisa menggunakan opsi `@config` untuk merujuk ke file konfigurasi eksternal jika diperlukan.

## Contoh Kode Implementasi

```css
/* styles.css - Cara baru Tailwind v4 */
@import "tailwindcss";

/* Override tema langsung di CSS */
@theme {
  --color-brand: #ff5733;
  --color-brand-dark: #c13e1f;
  --font-display: "Poppins", sans-serif;
  --breakpoint-xs: 20rem;
  --spacing-section: 5rem;
}

/* Custom variant dengan at-rule */
@custom-variant dark (&:where(.dark, .dark *));
@custom-variant hocus (&:hover, &:focus);
```

```bash
# Instalasi via npm
npm install tailwindcss @tailwindcss/cli

# Build dengan CLI
npx @tailwindcss/cli -i styles.css -o output.css --watch
```

## Poin Penting

- Cukup install `tailwindcss` tanpa plugin PostCSS terpisah
- Konfigurasi tema dilakukan dengan at-rule `@theme` di file CSS
- CLI baru `@tailwindcss/cli` menyederhanakan proses build
