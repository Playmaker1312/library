# Menggunakan fitur container queries yang built-in di Tailwind v4

## Analogi: Perpustakaan Digital

Container queries seperti rak buku pintar yang menyesuaikan tampilan bukunya berdasarkan ukuran rak itu sendiri, bukan berdasarkan ukuran ruangan (viewport). Di v3, Anda perlu memasang plugin tambahan agar rak bisa pintar. Di v4, semua rak sudah pintar secara bawaan. Buku akan otomatis mengubah ukuran font, layout, dan warna tergantung pada seberapa besar ruang yang tersedia di rak tempat ia berada.

## Penjelasan Detail

Tailwind v4 mengintegrasikan container queries langsung ke inti framework tanpa plugin tambahan. Semua elemen secara default adalah container yang bisa di-query menggunakan prefix `@` diikuti ukuran (misal `@sm`, `@md`, `@lg`). Untuk mengaktifkan containment, cukup tambahkan class `@container` pada elemen parent. Anda bisa menentukan `container-type` dengan `@container` (inline-size) atau `@container-size` (both axes). Container juga bisa diberi nama dengan `@container-{name}` untuk query spesifik. Fitur ini memungkinkan komponen yang benar-benar portabel karena responsivitasnya berdasarkan kontainer terdekat, bukan viewport.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Container Queries v4</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans">
  <!-- Container queries built-in -->
  <div class="grid grid-cols-2 gap-6">
    <!-- Card dalam container sempit -->
    <div class="@container border-2 border-dashed border-gray-300 p-2 rounded-lg">
      <div class="p-4 @lg:flex @lg:gap-4">
        <div class="size-16 @lg:size-24 bg-gradient-to-br from-purple-400 to-pink-500 rounded-lg"></div>
        <div>
          <h3 class="font-bold @lg:text-2xl">Judul Card</h3>
          <p class="text-gray-600 @lg:text-lg">Deskripsi yang merespons ukuran container.</p>
        </div>
      </div>
    </div>

    <!-- Card dalam container lebar -->
    <div class="@container border-2 border-dashed border-blue-300 p-2 rounded-lg">
      <div class="p-4 @lg:flex @lg:gap-4">
        <div class="size-16 @lg:size-24 bg-gradient-to-br from-emerald-400 to-cyan-500 rounded-lg"></div>
        <div>
          <h3 class="font-bold @lg:text-2xl">Judul Card</h3>
          <p class="text-gray-600 @lg:text-lg">Container ini lebih lebar, tapi tetap konsisten.</p>
        </div>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting

- Container queries built-in tanpa plugin—cukup gunakan prefix `@` seperti `@lg:text-2xl`
- Aktifkan containment dengan class `@container` pada elemen parent
- Komponen menjadi portabel karena responsivitas berdasarkan container, bukan viewport
