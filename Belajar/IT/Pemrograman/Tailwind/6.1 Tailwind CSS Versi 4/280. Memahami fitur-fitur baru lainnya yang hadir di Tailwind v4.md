# Memahami fitur-fitur baru lainnya yang hadir di Tailwind v4

## Analogi: Perpustakaan Digital

Jika v3 adalah perpustakaan standar dengan katalog kartu, v4 adalah perpustakaan digital modern dengan pencarian suara, rak otomatis, dan buku yang bisa berbicara. Fitur-fitur baru lainnya seperti `@layer`, persen pada utility, varian `group-*` yang lebih baik, dan dukungan CSS nesting native membuat pengalaman coding lebih mulus. Setiap fitur baru dirancang untuk mengurangi boilerplate dan meningkatkan ekspresivitas.

## Penjelasan Detail

Tailwind v4 membawa sejumlah fitur tambahan yang meningkatkan produktivitas. CSS nesting native kini didukung langsung tanpa plugin PostCSS—Anda bisa menulis `&:hover` di dalam aturan CSS. Utility class baru untuk `field-sizing`, `scrollbar`, `overscroll`, dan `content-visibility` menambahkan kontrol lebih pada browser modern. Varian `group-*` sekarang mendukung nesting dan kombinasi yang lebih kompleks. Utility `persen` seperti `w-1/2` tetap ada tetapi v4 menambahkan `w-1/7`, `w-1/9`, dll. untuk fleksibilitas lebih. Fitur `@layer` memungkinkan pengorganisasian CSS kustom dalam layer yang sama dengan Tailwind. Engine berbasis Rust juga menghasilkan source map yang lebih akurat dan waktu build yang drastis lebih cepat.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Fitur Baru Tailwind v4</title>
  <style>
    @import "tailwindcss";

    @layer components {
      .btn {
        @apply px-4 py-2 rounded-lg font-medium transition-all;
      }
    }

    @utility field-sizing-content {
      field-sizing: content;
    }
  </style>
</head>
<body class="p-8 font-sans space-y-6">
  <!-- Field sizing -->
  <textarea class="field-sizing-content w-full border p-2 rounded-lg" rows="1" placeholder="Ketik sesuatu..."></textarea>

  <!-- Pecahan baru -->
  <div class="grid grid-cols-5 gap-2">
    <div class="bg-blue-500 text-white p-2 rounded text-center">1/5</div>
    <div class="bg-blue-500 text-white p-2 rounded text-center">2/5</div>
    <div class="bg-blue-500 text-white p-2 rounded text-center">3/5</div>
    <div class="bg-blue-500 text-white p-2 rounded text-center">4/5</div>
    <div class="bg-blue-500 text-white p-2 rounded text-center">5/5</div>
  </div>

  <!-- CSS nesting native -->
  <div class="card p-4 bg-gray-100 rounded-xl [&:hover]:bg-gray-200 [&_p]:text-gray-700">
    <h3 class="font-bold text-lg">CSS Nesting</h3>
    <p>Nesting native tanpa plugin.</p>
  </div>
</body>
</html>
```

## Poin Penting

- CSS nesting native didukung langsung—tidak perlu plugin PostCSS
- Utility baru seperti `field-sizing-content` dan pecahan tambahan (1/7, 1/9, dll.)
- `@layer` untuk mengorganisasi CSS kustom dalam layer Tailwind
