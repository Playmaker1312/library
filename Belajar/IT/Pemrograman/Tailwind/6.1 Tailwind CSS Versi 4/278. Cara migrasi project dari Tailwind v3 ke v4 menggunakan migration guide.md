# Cara migrasi project dari Tailwind v3 ke v4 menggunakan migration guide

## Analogi: Perpustakaan Digital

Migrasi dari v3 ke v4 seperti merenovasi rumah sambil tetap tinggal di dalamnya. Anda tidak bisa merobohkan semuanya sekaligus—perubahan dilakukan secara sistematis. Beberapa buku (class) mungkin pindah rak, beberapa label (utility) berganti nama, dan sistem katalog (konfigurasi) berubah total. Panduan migrasi adalah cetak biru renovasi yang menunjukkan apa yang harus dipindahkan, apa yang bisa dipertahankan, dan apa yang harus dibuang.

## Penjelasan Detail

Migrasi dari v3 ke v4 dimulai dengan memperbarui package `tailwindcss` dan menghapus plugin PostCSS yang tidak diperlukan lagi karena engine v4 sudah mandiri. Langkah kedua adalah memindahkan konfigurasi dari `tailwind.config.js` ke file CSS menggunakan `@theme`, `@custom-variant`, dan `@utility`. Beberapa class berubah nama atau dihapus—periksa daftar breaking changes di dokumentasi resmi. Class berbasis `ring` dan `shadow` mungkin memerlukan penyesuaian karena sistem baru. Container queries yang sebelumnya plugin `@tailwindcss/container-queries` kini built-in dan menggunakan prefix `@` bukan `@container`. Tool migrasi otomatis (`@tailwindcss/upgrade`) dapat membantu mengidentifikasi dan memperbaiki perubahan sintaks secara massal.

## Contoh Kode Implementasi

```bash
# 1. Upgrade package
npm install tailwindcss@latest @tailwindcss/cli@latest

# 2. Jalankan upgrade tool otomatis
npx @tailwindcss/upgrade

# 3. Hapus konfigurasi dan plugin yang tidak diperlukan
npm uninstall tailwindcss @tailwindcss/container-queries
```

```diff
- /* tailwind.config.js */
- module.exports = {
-   content: ["./src/**/*.{html,js}"],
-   theme: {
-     extend: {
-       colors: { primary: "#3b82f6" },
-       fontFamily: { display: ["Poppins", "sans-serif"] },
-     },
-   },
-   plugins: [require("@tailwindcss/container-queries")],
- };

+ /* styles.css */
+ @import "tailwindcss";
+ @theme {
+   --color-primary: #3b82f6;
+   --font-display: "Poppins", sans-serif;
+ }
```

## Poin Penting

- Gunakan `npx @tailwindcss/upgrade` untuk migrasi otomatis
- Pindahkan konfigurasi dari JS ke CSS dengan `@theme`, `@custom-variant`, `@utility`
- Container queries sekarang built-in, hapus plugin eksternal
