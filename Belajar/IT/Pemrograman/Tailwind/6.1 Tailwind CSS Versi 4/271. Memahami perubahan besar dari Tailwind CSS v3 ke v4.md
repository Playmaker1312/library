# Memahami perubahan besar dari Tailwind CSS v3 ke v4

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang tiba-tiba mengganti seluruh sistem katalognya. Di v3, Anda harus mengisi formulir konfigurasi terpisah (tailwind.config.js) sebelum meminjam buku. Di v4, formulir itu dihapus—Anda cukup menulis aturan langsung di buku catatan CSS Anda. Semua buku juga diatur ulang ke rak yang lebih intuitif dengan nama yang lebih singkat. Hasilnya, Anda menghabiskan lebih sedikit waktu mengurus administrasi dan lebih banyak waktu membaca.

## Penjelasan Detail

Tailwind CSS v4 memperkenalkan arsitektur yang sepenuhnya baru dengan mesin berbasis Rust yang jauh lebih cepat dari pendahulunya. Perubahan paling mendasar adalah pergeseran dari konfigurasi berbasis JavaScript (tailwind.config.js) ke konfigurasi berbasis CSS murni menggunakan at-rules seperti `@theme`. Sistem warna dirombak total dengan palet yang lebih konsisten dan penamaan yang lebih intuitif, menggantikan skema numerik 50-950 yang lama. Container queries kini menjadi fitur bawaan tanpa perlu plugin tambahan, menandakan komitmen Tailwind pada desain yang benar-benar responsif. Gradien juga mengalami revisi sintaks dengan pendekatan yang lebih deklaratif dan fleksibel. Selain itu, file output CSS yang dihasilkan jauh lebih kecil berkat peningkatan tree-shaking dan optimasi berbasis Rust.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tailwind v4 vs v3</title>
  <style>
    /* v4: konfigurasi langsung di CSS */
    @import "tailwindcss";
    @theme {
      --color-primary: #3b82f6;
      --color-secondary: #8b5cf6;
      --font-heading: "Inter", sans-serif;
    }
  </style>
</head>
<body class="p-8 font-sans">
  <div class="space-y-6">
    <div class="bg-primary text-white p-4 rounded-xl">
      ✅ v4: Warna didefinisikan dengan @theme
    </div>
    <div class="bg-gradient-to-r from-cyan-400 to-blue-600 p-4 rounded-xl text-white">
      ✅ v4: Gradien dengan sintaks baru
    </div>
    <div class="@container p-4 border-2 border-dashed border-gray-300 rounded-xl">
      <div class="@lg:text-2xl @lg:font-bold text-sm">
        ✅ v4: Container queries built-in
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting

- Konfigurasi v4 menggunakan CSS murni dengan @theme, bukan tailwind.config.js
- Engine berbasis Rust menghasilkan build 10x lebih cepat dari v3
- Container queries dan gradient syntax yang lebih baik adalah fitur bawaan, bukan plugin
