# Menggunakan at-rules baru dalam Tailwind v4 seperti theme dan custom-variant

## Analogi: Perpustakaan Digital

At-rules di Tailwind v4 seperti sistem label stiker yang bisa Anda tempel di rak buku. `@theme` adalah stiker untuk kategori buku (warna, ukuran font, spasi). `@custom-variant` adalah stiker untuk situasi khusus ("buku ini hanya dibaca saat malam hari"). `@utility` adalah stiker untuk fungsi spesifik ("buku ini bisa dipinjam selama 30 hari"). Anda membuat stiker sendiri sesuai kebutuhan tanpa harus memanggil petugas perpustakaan (developer tools).

## Penjelasan Detail

Tailwind v4 memperkenalkan tiga at-rules utama untuk kustomisasi tanpa JavaScript. `@theme` mendefinisikan nilai-nilai desain global seperti warna, font, spacing, breakpoints, dan radius—semuanya ditulis sebagai properti CSS dengan prefix `--`. `@custom-variant` memungkinkan Anda membuat varian seperti `hover`, `focus`, atau kondisi kustom yang bisa dikombinasikan dengan utility class. Sintaksnya menggunakan `&` sebagai placeholder untuk elemen yang ditargetkan. `@utility` menciptakan utility class yang sepenuhnya baru dengan logika CSS sendiri, bukan hanya mengganti nilai tema. At-rules ini diproses oleh engine Tailwind pada saat build dan menghasilkan class yang siap pakai di HTML.

## Contoh Kode Implementasi

```css
@import "tailwindcss";

@theme {
  --color-primary: #2563eb;
  --color-primary-light: #60a5fa;
  --spacing-gutter: 1.5rem;
  --radius-card: 1rem;
}

@custom-variant pointer (&:not([disabled]):hover);
@custom-variant landscape (@media (orientation: landscape));
@custom-variant in-card (&:is(.card *));

@utility text-gradient {
  background-clip: text;
  -webkit-background-clip: text;
  color: transparent;
  background-image: linear-gradient(to right, var(--color-primary), var(--color-primary-light));
}

@utility center {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

```html
<div class="text-gradient pointer:scale-105 landscape:flex-row in-card:text-sm">
  Teks gradien dengan varian kustom
</div>
<div class="center size-16 bg-primary text-white rounded-card">
  Center
</div>
```

## Poin Penting

- `@theme` menggantikan `theme` di konfigurasi JavaScript untuk design tokens
- `@custom-variant` membuat varian kondisi dengan sintaks `&:`
- `@utility` mendefinisikan utility class baru yang bisa langsung dipakai di HTML
