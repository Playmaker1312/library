# Memahami perubahan pada default container behavior di Tailwind v4

## Analogi: Perpustakaan Digital

Di v3, container seperti kotak buku yang selalu berada di tengah rak dengan lebar maksimum tetap, terlepas dari apakah Anda ingin memindahkannya atau tidak. Di v4, container seperti kotak yang bisa Anda atur sendiri—tidak ada maksimum default, tidak ada centering otomatis. Anda bebas menentukan apakah kotak harus 100%, di-tengahkan, atau dibatasi lebarnya. Container kini lebih merupakan kanvas kosong daripada alat layout yang kaku.

## Penjelasan Detail

Tailwind v3 memiliki class `container` yang secara default memberikan lebar maksimum responsif (sm: 640px, md: 768px, dll.) dan harus di-centering dengan `mx-auto`. Di v4, class `container` tidak lagi memiliki maksimum default—class ini hanya memberikan `width: 100%` pada setiap breakpoint. Ini memberikan kontrol lebih kepada developer untuk menentukan lebar maksimum sesuai kebutuhan. Jika ingin mempertahankan perilaku v3, Anda harus secara eksplisit mendefinisikan `max-width` melalui `@theme`. Perubahan ini mengurangi asumsi implisit dan membuat container lebih fleksibel dalam berbagai konteks layout seperti grid dan flexbox.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Container di v4</title>
  <style>
    @import "tailwindcss";
    @theme {
      --container-md: 48rem;
      --container-lg: 64rem;
    }
  </style>
</head>
<body>
  <!-- v4: container tanpa max-width, perlu mx-auto untuk centering -->
  <div class="container mx-auto p-4">
    <p>Container v4: width 100% di semua breakpoint</p>
  </div>

  <!-- v4: mensimulasikan container v3 dengan max-width kustom -->
  <div class="container max-w-container-md mx-auto p-4 bg-gray-100 rounded-lg">
    <p>Container dengan max-width: 768px seperti v3</p>
  </div>

  <!-- v4: container dalam flex -->
  <div class="flex gap-4">
    <div class="container flex-1 bg-blue-100 p-4 rounded">Flex item 1</div>
    <div class="container flex-1 bg-green-100 p-4 rounded">Flex item 2</div>
  </div>
</body>
</html>
```

## Poin Penting

- Container di v4 tidak memiliki max-width default, hanya width 100%
- Centering harus dilakukan eksplisit dengan `mx-auto`
- Perilaku v3 bisa disimulasikan dengan mendefinisikan `--container-*` di `@theme`
