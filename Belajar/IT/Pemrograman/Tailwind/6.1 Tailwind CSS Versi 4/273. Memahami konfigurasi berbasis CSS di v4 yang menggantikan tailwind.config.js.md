# Memahami konfigurasi berbasis CSS di v4 yang menggantikan tailwind.config.js

## Analogi: Perpustakaan Digital

Di v3, menata buku seperti mengisi formulir online sebelum masuk ke perpustakaan—Anda harus mendaftar di meja depan (tailwind.config.js) sebelum bisa menyentuh buku. Di v4, Anda langsung masuk dan mulai menulis catatan tempel di setiap rak buku (langsung di CSS). Aturannya sederhana: apa yang Anda tulis di CSS adalah konfigurasi Anda, tanpa perantara file JavaScript. Ini mengurangi gesekan dan membuat eksperimen lebih cepat.

## Penjelasan Detail

Pendekatan berbasis CSS di v4 menggunakan at-rules baru seperti `@theme`, `@custom-variant`, dan `@utility` untuk menggantikan fungsi-fungsi yang sebelumnya ada di tailwind.config.js. At-rule `@theme` mendefinisikan design tokens seperti warna, font, spacing, dan breakpoints dengan sintaks properti CSS khusus. At-rule `@custom-variant` memungkinkan pembuatan varian kustom seperti `dark` atau `hocus` tanpa plugin JavaScript. At-rule `@utility` digunakan untuk membuat utility class baru yang tidak ada di bawaan Tailwind. Semua ini diproses langsung oleh engine Tailwind v4 tanpa perlu transpilasi JavaScript terlebih dahulu, membuat iterasi lebih cepat dan lebih dekat dengan bahasa asli web.

## Contoh Kode Implementasi

```css
/* tailwind.config.js sudah tidak diperlukan lagi */
@import "tailwindcss";

@theme {
  /* Design tokens langsung di CSS */
  --color-ocean: #0077be;
  --color-sunset: #ff6b6b;
  --font-mono: "JetBrains Mono", monospace;
  --spacing-18: 4.5rem;
  --breakpoint-3xl: 120rem;
}

@custom-variant pointer (&:not([disabled]):hover);

@utility text-balance {
  text-wrap: balance;
}

@utility scrollbar-hide {
  scrollbar-width: none;
  &::-webkit-scrollbar {
    display: none;
  }
}
```

## Poin Penting

- `@theme` menggantikan `theme.extend` dan `theme` di tailwind.config.js
- `@custom-variant` menggantikan plugin kustom untuk varian
- `@utility` membuat utility class baru tanpa JavaScript
