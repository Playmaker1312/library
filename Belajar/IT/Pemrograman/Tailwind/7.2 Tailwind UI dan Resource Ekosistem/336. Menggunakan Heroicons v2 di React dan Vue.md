# Menggunakan Heroicons v2 di React dan Vue

## Analogi: Perpustakaan Digital
Heroicons v2 di React dan Vue seperti buku stiker digital yang sudah terpotong dan siap tempel—setiap icon sudah dalam format komponen siap pakai. Anda tinggal mengimpor dan menggunakannya tanpa perlu menulis SVG manual. Ini mempercepat pengembangan dan menjaga konsistensi kode.

## Penjelasan Detail
Heroicons v2 menyediakan paket npm untuk React (`@heroicons/react`) dan Vue (`@heroicons/vue`). Setiap icon diekspor sebagai komponen dengan props yang menerima className Tailwind. Varian outline (24x24) dan solid (20x20) dapat diimpor sesuai kebutuhan. Tree-shaking memastikan hanya icon yang digunakan yang masuk ke production bundle. Komponen icon secara default menggunakan `currentColor` untuk stroke/fill, sehingga mudah diwarnai via kelas teks. Props seperti `className` dapat ditambahkan langsung untuk styling lanjutan. Di React, icon diimpor dengan nama PascalCase; di Vue menggunakan kebab-case atau PascalCase sesuai preferensi. Contoh pattern: `import { HomeIcon } from '@heroicons/react/24/outline'`. Penggunaan di komponen lain seperti tombol, input, atau navigasi dilakukan dengan nesting dalam elemen.

## Contoh Kode Implementasi

```jsx
// React: Menggunakan Heroicons v2
import { HomeIcon, UserIcon, Cog6ToothIcon } from '@heroicons/react/24/outline'
import { HeartIcon } from '@heroicons/react/24/solid'

export default function Navigation() {
    return (
        <nav className="flex items-center gap-6 p-4 bg-white dark:bg-gray-900 rounded-xl shadow-sm">
            <button className="flex items-center gap-2 text-gray-500 hover:text-indigo-600 transition">
                <HomeIcon className="w-5 h-5" />
                <span className="text-sm font-medium">Home</span>
            </button>
            <button className="flex items-center gap-2 text-gray-500 hover:text-indigo-600 transition">
                <UserIcon className="w-5 h-5" />
                <span className="text-sm font-medium">Profile</span>
            </button>
            <button className="flex items-center gap-2 text-gray-500 hover:text-indigo-600 transition">
                <Cog6ToothIcon className="w-5 h-5" />
                <span className="text-sm font-medium">Settings</span>
            </button>
            <button className="ml-auto flex items-center gap-2 text-red-500 hover:text-red-400 transition">
                <HeartIcon className="w-5 h-5" />
                <span className="text-sm font-medium">Liked</span>
            </button>
        </nav>
    )
}
```

```vue
</script>
```

## Poin Penting
- Heroicons v2 tersedia sebagai paket npm `@heroicons/react` dan `@heroicons/vue`
- Setiap icon adalah komponen dengan props className untuk styling Tailwind
- Tree-shaking otomatis hanya menyertakan icon yang digunakan di production bundle
- Varian outline (`/24/outline`) dan solid (`/24/solid`) bisa digunakan bersamaan
