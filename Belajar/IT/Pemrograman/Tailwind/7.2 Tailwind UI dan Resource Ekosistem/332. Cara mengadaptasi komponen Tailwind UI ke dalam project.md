# Cara mengadaptasi komponen Tailwind UI ke dalam project

## Analogi: Perpustakaan Digital
Mengadaptasi komponen Tailwind UI ke dalam project seperti mengambil buku dari rak perpustakaan lalu menyesuaikannya dengan sistem katalog Anda sendiri. Anda bisa mengubah sampul, menyesuaikan kategori, atau menambahkan anotasi. Intinya, Anda memiliki kendali penuh atas konten setelah mengambilnya.

## Penjelasan Detail
Adaptasi komponen Tailwind UI dimulai dengan meng-copy HTML komponen yang diinginkan, lalu menyesuaikan konten, warna, dan spacing agar sesuai dengan brand project. Karena semua kelas adalah utility Tailwind standar, modifikasi cukup dengan mengganti nilai kelas seperti `text-2xl` menjadi `text-3xl` atau `bg-indigo-600` menjadi `bg-emerald-600`. Untuk integrasi dengan framework, komponen vanilla HTML perlu dipecah menjadi komponen reusable di React/Vue dengan props untuk data dinamis. Warna dalam komponen Tailwind UI menggunakan palet default Tailwind; jika project menggunakan warna kustom, ganti dengan kelas kustom yang sudah didefinisikan di `tailwind.config.js`. Responsivitas komponen dapat disesuaikan dengan menambahkan atau mengubah breakpoint variants. Aksesibilitas seperti `aria-label` dan `role` dapat ditambahkan tanpa mengubah struktur visual.

## Contoh Kode Implementasi

```html
<!-- Komponen asli dari Tailwind UI (hero section) -->
<div class="bg-white dark:bg-gray-900">
    <div class="max-w-7xl mx-auto py-16 px-4 sm:py-24 sm:px-6 lg:px-8">
        <h1 class="text-4xl font-extrabold text-gray-900 dark:text-white sm:text-5xl sm:tracking-tight lg:text-6xl">Get started in minutes</h1>
        <p class="max-w-xl mt-5 text-xl text-gray-500 dark:text-gray-400">Deploy your project with a single command and scale as you grow.</p>
    </div>
</div>

<!-- Adaptasi dengan brand warna kustom -->
<div class="bg-gradient-to-br from-emerald-50 to-teal-50 dark:from-gray-950 dark:to-gray-900">
    <div class="max-w-7xl mx-auto py-20 px-4 sm:py-28 sm:px-6 lg:px-8 text-center">
        <h1 class="text-5xl font-extrabold text-emerald-900 dark:text-emerald-100 sm:text-6xl lg:text-7xl">Mulai dalam hitungan menit</h1>
        <p class="max-w-2xl mx-auto mt-5 text-lg text-emerald-700 dark:text-emerald-300">Deploy project Anda dengan satu perintah dan scaling otomatis sesuai kebutuhan.</p>
    </div>
</div>
```

## Poin Penting
- Copy-paste HTML komponen lalu sesuaikan konten dan kelas utilitas untuk brand project
- Ubah warna dengan mengganti kelas palet default (indigo, blue) ke warna kustom project
- Pecah komponen menjadi komponen reusable di framework (React/Vue) untuk data dinamis
- Tambahkan aksesibilitas tanpa mengubah struktur visual komponen yang sudah ada
