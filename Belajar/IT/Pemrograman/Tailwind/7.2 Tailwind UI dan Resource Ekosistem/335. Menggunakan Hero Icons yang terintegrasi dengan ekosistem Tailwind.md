# Menggunakan Hero Icons yang terintegrasi dengan ekosistem Tailwind

## Analogi: Perpustakaan Digital
Hero Icons seperti koleksi stiker dan penanda buku siap pakai di perpustakaan digital yang dirancang dengan gaya seragam. Setiap icon memiliki bobot visual yang konsisten, sehingga rak buku (antarmuka) terlihat rapi dan profesional. Anda tinggal memilih dan menempelkannya tanpa perlu mendesain dari nol.

## Penjelasan Detail
Hero Icons adalah kumpulan icon SVG gratis yang dikembangkan oleh tim Tailwind CSS. Icon-icon ini dirancang dengan gaya konsisten (outline dan solid) dalam ukuran 24x24 dan 20x20 piksel. Integrasi dengan Tailwind sangat alami karena icon dapat langsung di-styling menggunakan kelas Tailwind seperti `w-5 h-5`, `text-gray-500`, `hover:text-indigo-600`. Icons tersedia dalam format SVG inline, React components (`@heroicons/react`), dan Vue components (`@heroicons/vue`). Penggunaan SVG inline memberikan fleksibilitas penuh untuk mengubah warna, ukuran, dan animasi via Tailwind classes. Hero Icons dapat dikombinasikan dengan komponen Tailwind UI untuk elemen navigasi, tombol, form inputs, dan notifikasi. Library ini ringan karena hanya mengimpor icon yang digunakan (tree-shaking). Icon juga bisa diunduh sebagai file SVG individual.

## Poin Penting
- Hero Icons adalah library icon gratis dari tim Tailwind dengan gaya outline dan solid yang konsisten
- Icon SVG inline dapat di-styling langsung dengan kelas Tailwind (ukuran, warna, animasi)
- Tersedia dalam format React (`@heroicons/react`) dan Vue (`@heroicons/vue`) dengan tree-shaking
- Ukuran icon menggunakan `w-5 h-5` (solid 20px) atau `w-6 h-6` (outline 24px) sesuai konteks
