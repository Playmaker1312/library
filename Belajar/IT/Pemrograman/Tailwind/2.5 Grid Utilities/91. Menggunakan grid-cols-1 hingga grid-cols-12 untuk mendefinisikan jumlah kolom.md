# Menggunakan grid-cols-1 hingga grid-cols-12 untuk mendefinisikan jumlah kolom

## Analogi: Perpustakaan Digital

Grid-cols seperti menentukan jumlah rak buku dalam satu baris. `grid-cols-1` satu kolom, `grid-cols-2` dua kolom, hingga `grid-cols-12` dua belas kolom. Seperti memilih apakah koleksi buku ditampilkan dalam 1, 2, 3, atau lebih kolom. Fleksibel untuk berbagai tata letak.

## Penjelasan Detail

Grid-cols utilities (`grid-cols-{jumlah}`) mendefinisikan jumlah kolom dalam grid container. Nilai dari 1 hingga 12, dengan `grid-cols-none` untuk menggunakan grid implisit. Tailwind menggunakan satuan `fr` (fraction) untuk membagi ruang secara proporsional. Grid-cols dapat dikombinasikan dengan responsive breakpoints: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`. Ini adalah fondasi layout grid di Tailwind dan paling sering digunakan untuk card grids, gallery, dan dashboard.

## Poin Penting
- `grid-cols-1` hingga `grid-cols-12` untuk jumlah kolom
- Menggunakan satuan `fr` (fraction unit) secara otomatis
- Dapat dikombinasikan dengan responsive breakpoints
