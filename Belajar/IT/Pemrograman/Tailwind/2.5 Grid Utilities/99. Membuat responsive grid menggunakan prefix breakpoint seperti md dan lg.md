# Membuat responsive grid menggunakan prefix breakpoint seperti md dan lg

## Analogi: Perpustakaan Digital

Responsive grid seperti rak buku yang secara otomatis menyesuaikan jumlah kolom berdasarkan lebar layar. Di layar kecil (mobile) 1 kolom, layar sedang (tablet) 2 kolom, layar besar (desktop) 3 kolom. Seperti rak yang secara cerdas mengatur ulang koleksi bukunya agar selalu terlihat rapi.

## Penjelasan Detail

Tailwind menggunakan prefix breakpoint: `sm` (640px), `md` (768px), `lg` (1024px), `xl` (1280px), `2xl` (1536px). Syntax: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`. Tanpa prefix berlaku sebagai default (mobile). Setiap breakpoint adalah min-width query. Responsive grid memungkinkan layout yang adaptif tanpa media queries manual. Sangat penting untuk pengalaman mobile-first dan desain yang responsif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Responsive Grid Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8">
  <h1 class="text-2xl font-bold mb-4">Responsive Grid</h1>
  <div class="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-4">
    <div class="bg-blue-500 text-white p-6 rounded-lg shadow">
      <h3 class="font-bold">Kartu 1</h3>
      <p class="text-sm mt-2">Responsif: 1 → 2 → 3 → 4 kolom</p>
    </div>
    <div class="bg-green-500 text-white p-6 rounded-lg shadow">
      <h3 class="font-bold">Kartu 2</h3>
      <p class="text-sm mt-2">Coba resize browser</p>
    </div>
    <div class="bg-red-500 text-white p-6 rounded-lg shadow">
      <h3 class="font-bold">Kartu 3</h3>
      <p class="text-sm mt-2">Lihat perubahan jumlah kolom</p>
    </div>
    <div class="bg-purple-500 text-white p-6 rounded-lg shadow">
      <h3 class="font-bold">Kartu 4</h3>
      <p class="text-sm mt-2">Tailwind membuatnya mudah</p>
    </div>
    <div class="bg-yellow-500 text-white p-6 rounded-lg shadow">
      <h3 class="font-bold">Kartu 5</h3>
      <p class="text-sm mt-2">Mobile-first approach</p>
    </div>
    <div class="bg-indigo-500 text-white p-6 rounded-lg shadow">
      <h3 class="font-bold">Kartu 6</h3>
      <p class="text-sm mt-2">6 kartu total</p>
    </div>
  </div>
  <p class="mt-4 text-sm text-gray-500">Breakpoints: sm:640px, md:768px, lg:1024px</p>
</body>
</html>
```

## Poin Penting
- Default (tanpa prefix) untuk mobile, `sm:`, `md:`, `lg:`, `xl:`, `2xl:` untuk layar lebih besar
- Mobile-first: mulai dengan kolom sedikit, tambah dengan breakpoint
- Responsive grid penting untuk UX di berbagai perangkat
