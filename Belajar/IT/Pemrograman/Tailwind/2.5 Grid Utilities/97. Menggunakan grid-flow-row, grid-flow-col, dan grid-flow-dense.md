# Menggunakan grid-flow-row, grid-flow-col, dan grid-flow-dense

## Analogi: Perpustakaan Digital

Grid-flow seperti menentukan arah pengisian item ke dalam grid. `grid-flow-row` mengisi baris per baris (kiri ke kanan, lalu turun). `grid-flow-col` mengisi kolom per kolom (atas ke bawah, lalu ke kanan). `grid-flow-dense` mengisi celah kosong secara otomatis. Seperti petugas perpustakaan yang menempatkan buku ke rak dengan pola tertentu.

## Penjelasan Detail

Grid-flow utilities mengatur properti CSS `grid-auto-flow`. `grid-flow-row` (default) menempatkan item secara berurutan dalam baris. `grid-flow-col` menempatkan item dalam kolom. `grid-flow-dense` mengisi celah kosong yang ditinggalkan oleh item dengan ukuran berbeda. Dense flow memungkinkan algoritma untuk mengisi "lubang" dengan item yang lebih kecil. Sangat berguna untuk masonry-style layouts atau galeri dengan item berbagai ukuran.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Grid Flow Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Grid Flow</h1>
  <div>
    <h2 class="font-semibold">grid-flow-row (default)</h2>
    <div class="grid grid-cols-3 grid-flow-row gap-2">
      <div class="bg-blue-500 text-white p-4 rounded col-span-2">lebar 2 kolom</div>
      <div class="bg-blue-500 text-white p-4 rounded">3</div>
      <div class="bg-blue-500 text-white p-4 rounded">4</div>
      <div class="bg-blue-500 text-white p-4 rounded">5</div>
    </div>
  </div>
  <div>
    <h2 class="font-semibold">grid-flow-dense (isi celah)</h2>
    <div class="grid grid-cols-3 grid-flow-dense gap-2">
      <div class="bg-green-500 text-white p-4 rounded col-span-2">lebar 2 kolom</div>
      <div class="bg-green-500 text-white p-4 rounded">3</div>
      <div class="bg-green-500 text-white p-4 rounded">4</div>
      <div class="bg-green-500 text-white p-4 rounded">5</div>
    </div>
    <p class="text-sm text-gray-500">Item 4 dan 5 mengisi celah di samping item 3.</p>
  </div>
  <div>
    <h2 class="font-semibold">grid-flow-col</h2>
    <div class="grid grid-rows-3 grid-flow-col gap-2 h-48">
      <div class="bg-red-500 text-white p-4 rounded">A</div>
      <div class="bg-red-500 text-white p-4 rounded">B</div>
      <div class="bg-red-500 text-white p-4 rounded">C</div>
      <div class="bg-red-500 text-white p-4 rounded">D</div>
      <div class="bg-red-500 text-white p-4 rounded">E</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `grid-flow-row` isi per baris, `grid-flow-col` isi per kolom
- `grid-flow-dense` mengisi celah kosong secara otomatis
- Dense flow ideal untuk galeri dengan item berbagai ukuran
