# Menggunakan grid-rows-1 hingga grid-rows-6 untuk mendefinisikan jumlah baris

## Analogi: Perpustakaan Digital

Grid-rows seperti menentukan jumlah baris rak buku secara vertikal. `grid-rows-2` berarti 2 baris, `grid-rows-3` berarti 3 baris. Berbeda dengan grid-cols yang mengatur kolom horizontal, grid-rows mengatur baris vertikal. Seperti menentukan tinggi rak dalam jumlah baris.

## Penjelasan Detail

Grid-rows utilities (`grid-rows-{jumlah}`) mendefinisikan jumlah baris eksplisit dalam grid container. Nilai dari 1 hingga 6. Grid-rows dapat dikombinasikan dengan grid-cols untuk layout dua dimensi yang lengkap. Grid-rows menggunakan satuan `fr` secara default. Berguna untuk layout yang membutuhkan kontrol baris eksplisit, seperti kalender, timetable, atau dashboard dengan baris tetap. Tanpa grid-rows, baris dibuat secara implisit sesuai kebutuhan.

## Poin Penting
- `grid-rows-{n}` untuk jumlah baris eksplisit
- Dikombinasikan dengan grid-cols untuk grid dua dimensi
- Berguna untuk layout dengan baris tetap
