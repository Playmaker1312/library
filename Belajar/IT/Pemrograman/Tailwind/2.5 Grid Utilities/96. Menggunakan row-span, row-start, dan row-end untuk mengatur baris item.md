# Menggunakan row-span, row-start, dan row-end untuk mengatur baris item

## Analogi: Perpustakaan Digital

Row-span, row-start, dan row-end seperti mengatur tinggi vertikal dan posisi buku dalam grid. `row-span-2` membuat buku setinggi 2 baris. `row-start-3` menempatkan buku mulai dari baris ke-3. `row-end-5` berakhir di baris ke-5. Seperti buku tinggi yang melintasi beberapa rak vertikal.

## Penjelasan Detail

Row utilities: `row-span-{jumlah}` mengatur `grid-row: span {jumlah}`. `row-start-{nomor}` mengatur `grid-row-start`. `row-end-{nomor}` mengatur `grid-row-end`. Nilai row-span dari 1 hingga 6, row-start/row-end dari 1 hingga 7. Dapat dikombinasikan dengan col utilities untuk kontrol dua dimensi penuh. Sangat berguna untuk layout dashboard, grid feature, atau tampilan dengan item yang memiliki tinggi berbeda.

## Poin Penting
- `row-span-{n}` untuk tinggi item melintasi n baris
- `row-start` dan `row-end` untuk posisi vertikal presisi
- Dikombinasikan dengan col utilities untuk layout dua dimensi
