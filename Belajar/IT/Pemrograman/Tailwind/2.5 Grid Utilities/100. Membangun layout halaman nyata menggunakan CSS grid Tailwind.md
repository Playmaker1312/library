# Membangun layout halaman nyata menggunakan CSS grid Tailwind

## Analogi: Perpustakaan Digital

Layout halaman nyata dengan CSS grid adalah seperti merancang seluruh denah perpustakaan digital: header di atas, sidebar navigasi di kiri, area konten utama di tengah, dan footer di bawah. Grid memberikan kontrol dua dimensi penuh untuk membagi halaman menjadi zona-zona fungsional.

## Penjelasan Detail

Layout halaman nyata menggunakan grid menggabungkan grid-cols, grid-rows, dan span utilities. Contoh layout umum: header (full width), sidebar (lebar tetap), main content (flexibel), footer (full width). Menggunakan `grid-cols-1 lg:grid-cols-[250px_1fr]` untuk layout dengan sidebar di desktop. Grid rows dapat ditentukan dengan `grid-rows-[auto_1fr_auto]` untuk header-konten-footer. CSS grid sangat ideal untuk layout halaman penuh (page layout) karena kontrol dua dimensinya.

```html
<body class="min-h-screen">
  <div class="grid grid-cols-1 lg:grid-cols-[250px_1fr] grid-rows-[auto_1fr_auto] min-h-screen">

        <li class="p-2 bg-white rounded shadow-sm hover:bg-blue-50 cursor-pointer">Sains</li>
        <li class="p-2 bg-white rounded shadow-sm hover:bg-blue-50 cursor-pointer">Teknologi</li>
        <li class="p-2 bg-white rounded shadow-sm hover:bg-blue-50 cursor-pointer">Sejarah</li>
      </ul>

    <main class="p-6 bg-white">

      <div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">

      &copy; 2025 Perpustakaan Digital - Dibangun dengan Tailwind CSS Grid
    </footer>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `grid-rows-[auto_1fr_auto]` untuk header-konten-footer
- Gunakan `grid-cols-[250px_1fr]` untuk sidebar dan konten utama
- CSS grid ideal untuk layout halaman penuh dua dimensi
