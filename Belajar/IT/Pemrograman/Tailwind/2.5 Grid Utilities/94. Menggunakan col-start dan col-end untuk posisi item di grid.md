# Menggunakan col-start dan col-end untuk posisi item di grid

## Analogi: Perpustakaan Digital

Col-start dan col-end seperti menentukan di kolom mana sebuah buku mulai dan berakhir. `col-start-2` berarti buku mulai di kolom ke-2, `col-end-4` berarti berakhir di kolom ke-4. Ini memungkinkan penempatan buku secara presisi di lokasi tertentu dalam grid. Seperti menempatkan buku di rak tertentu berdasarkan nomor kolom.

## Penjelasan Detail

Col-start utilities (`col-start-{nomor}`) mengatur `grid-column-start`, col-end (`col-end-{nomor}`) mengatur `grid-column-end`. Grid line dimulai dari 1. `col-start-auto` menggunakan penempatan otomatis. Dapat digabungkan dengan `col-span` untuk kontrol yang lebih presisi. Berguna untuk layout asimetris atau dashboard dengan widget di posisi spesifik. Kombinasi col-start dan col-end memberikan kontrol penuh atas posisi item.

```html
    <div class="bg-green-500 text-white p-4 rounded col-start-3 col-end-5">col-start-3 col-end-5</div>

    <div class="bg-purple-500 text-white p-4 rounded col-start-2 col-end-5">col-start-2 col-end-5</div>
    <div class="bg-yellow-500 text-white p-4 rounded col-span-4">col-span-4 (normal)</div>
  </div>
  <p class="mt-2 text-sm text-gray-500">Grid line dimulai dari 1. col-start-1 artinya mulai dari garis vertikal pertama.</p>
</body>
</html>
```

## Poin Penting
- `col-start-{n}` dan `col-end-{n}` untuk posisi presisi
- Grid line dimulai dari angka 1
- Berguna untuk layout dashboard dan asimetris
