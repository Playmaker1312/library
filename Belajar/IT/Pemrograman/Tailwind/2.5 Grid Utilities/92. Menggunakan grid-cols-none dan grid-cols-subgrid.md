# Menggunakan grid-cols-none dan grid-cols-subgrid

## Analogi: Perpustakaan Digital

`grid-cols-none` seperti menghapus definisi kolom dan membiarkan item mengalir alami. `grid-cols-subgrid` seperti rak anak yang mengikuti pola kolom rak induknya. Jika rak utama memiliki 3 kolom, rak anak juga mengikuti 3 kolom yang sama. Ini menciptakan konsistensi kolom antar level grid.

## Penjelasan Detail

`grid-cols-none` mengatur `grid-template-columns: none`, yang berarti tidak ada grid eksplisit. Item akan ditempatkan dalam grid implisit. `grid-cols-subgrid` membuat grid anak mewarisi definisi kolom dari grid induknya, memungkinkan penyelarasan sempurna antar elemen di berbagai level. Subgrid membutuhkan grid induk yang sudah memiliki definisi kolom eksplisit. Subgrid sangat berguna untuk layout card yang kompleks atau tabel.

## Poin Penting
- `grid-cols-none` untuk grid tanpa template kolom eksplisit
- `grid-cols-subgrid` mewarisi kolom dari grid parent
- Subgrid memastikan penyelarasan antar level grid
