# Cara membuat komponen reusable di React menggunakan Tailwind
## Analogi: Perpustakaan Digital
Bayangkan perpustakaan memiliki formulir standar untuk peminjaman buku yang bisa digunakan di berbagai meja layanan. Formulir ini memiliki tata letak dan gaya yang sama, tetapi judul dan fungsinya bisa berbeda. Inilah esensi komponen reusable — cetak biru yang bisa diisi dengan konten berbeda tanpa mengubah struktur dasarnya.
## Penjelasan Detail
Di React, membuat komponen reusable dengan Tailwind sangatlah alami. Anda membuat fungsi komponen yang menerima `props` dan mengembalikan elemen JSX dengan utility class Tailwind. Untuk fleksibilitas, Anda dapat menggunakan prop seperti `className` untuk menambahkan class eksternal, `variant` untuk mengubah gaya, dan `as` untuk mengubah elemen HTML yang dirender. Penggunaan `forwardRef` memastikan komponen dapat menerima ref dari parent. Komponen seperti `Button`, `Card`, `Input`, dan `Badge` adalah kandidat sempurna untuk reusable component. Anda bisa mengombinasikan Tailwind dengan TypeScript untuk mendapatkan type safety pada props. Gunakan `clsx` atau `tailwind-merge` untuk menggabungkan class internal dengan class dari prop `className` tanpa konflik.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>React + Tailwind Reusable - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="root"></div>
    <script type="text/babel">
        const { useState } = React;

        // Komponen Button reusable
        function Button({ variant = 'primary', size = 'md', children, ...props }) {
            const base = 'rounded-lg font-semibold transition duration-200 focus:outline-none focus:ring-2';
            const variants = {
                primary: 'bg-blue-500 text-white hover:bg-blue-600 focus:ring-blue-300',
                secondary: 'bg-gray-200 text-gray-800 hover:bg-gray-300 focus:ring-gray-400',
                danger: 'bg-red-500 text-white hover:bg-red-600 focus:ring-red-300',
            };
            const sizes = {
                sm: 'px-3 py-1 text-sm',
                md: 'px-5 py-2',
                lg: 'px-8 py-3 text-lg',
            };
            return <button className={`${base} ${variants[variant]} ${sizes[size]}`} {...props}>{children}</button>;
        }

        // Komponen Card reusable
        function Card({ title, children, className = '' }) {
            return (
                <div className={`p-6 bg-white rounded-xl shadow-md border border-gray-100 ${className}`}>
                    {title && <h3 className="text-xl font-bold text-gray-800 mb-3">{title}</h3>}
                    <div className="text-gray-600">{children}</div>
                </div>
            );
        }

        function App() {
            return (
                <div className="max-w-2xl mx-auto space-y-6">
                    <Card title="Komponen Reusable dengan Tailwind + React">
                        <p className="mb-4">Komponen Button di bawah menggunakan prop variant dan size untuk mengubah tampilannya.</p>
                        <div className="flex flex-wrap gap-3 items-center">
                            <Button variant="primary" size="sm">Small Primary</Button>
                            <Button variant="primary">Default Primary</Button>
                            <Button variant="secondary">Secondary</Button>
                            <Button variant="danger">Danger</Button>
                            <Button variant="primary" size="lg">Large Primary</Button>
                        </div>
                    </Card>
                    <Card title="Prinsip Reusable" className="border-l-4 border-l-blue-500">
                        <ul className="list-disc list-inside space-y-1">
                            <li>Gunakan prop untuk fleksibilitas</li>
                            <li>Pisahkan base styles dengan variant styles</li>
                            <li>Terima className eksternal untuk kustomisasi</li>
                        </ul>
                    </Card>
                </div>
            );
        }

        ReactDOM.createRoot(document.getElementById('root')).render(<App />);
    </script>
</body>
</html>
```
## Poin Penting
- Buat komponen dengan prop seperti `variant`, `size`, `className` untuk fleksibilitas maksimal
- Gunakan `tailwind-merge` atau `clsx` untuk menggabungkan class internal dan eksternal tanpa konflik
- Komponen seperti Button, Card, Input, dan Badge adalah kandidat utama untuk direusable-kan
