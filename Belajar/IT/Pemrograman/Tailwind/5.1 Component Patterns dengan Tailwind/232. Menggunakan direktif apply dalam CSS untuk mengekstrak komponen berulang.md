# Menggunakan direktif apply dalam CSS untuk mengekstrak komponen berulang
## Analogi: Perpustakaan Digital
Direktif `@apply` seperti membuat "kartu referensi cepat" di perpustakaan. Alih-alih menulis ulang daftar lengkap nomor rak setiap kali, Anda cukup menulis nama singkat kartu tersebut. Saat tata letak perpustakaan berubah, Anda hanya perlu memperbarui kartu referensi, dan semua yang menggunakannya akan otomatis mengikuti perubahan itu tanpa perlu diedit satu per satu.
## Penjelasan Detail
Direktif `@apply` di Tailwind memungkinkan Anda menggabungkan beberapa utility class ke dalam satu class CSS kustom. Anda mendefinisikannya di file CSS (biasanya di PostCSS) seperti `.btn-primary { @apply py-2 px-4 bg-blue-500 text-white rounded; }`. Ini sangat berguna ketika Anda memiliki pola class yang sangat berulang dan tidak menggunakan framework JavaScript. Namun, perlu diingat bahwa `@apply` bukanlah solusi ajaib — ia menonaktifkan fitur tree-shaking Tailwind jika tidak hati-hati karena Tailwind tidak bisa melihat class apa yang digunakan di dalam CSS. Pastikan file CSS Anda termasuk dalam konfigurasi `content` Tailwind. Direktif ini paling cocok untuk komponen yang benar-benar stabil dan tidak memiliki varian. Untuk komponen dengan banyak varian, pendekatan berbasis JavaScript seperti CVA mungkin lebih tepat.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Direktif Apply - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <style>
        /* Simulasi @apply menggunakan Tailwind CSS via CDN */
        .btn {
            @apply py-2 px-6 font-semibold rounded-lg shadow-md transition duration-200;
        }
        .btn-primary {
            @apply bg-blue-500 text-white hover:bg-blue-600;
        }
        .btn-secondary {
            @apply bg-gray-200 text-gray-800 hover:bg-gray-300;
        }
        .card {
            @apply p-6 bg-white rounded-xl shadow-lg border border-gray-100;
        }
        .card-title {
            @apply text-xl font-bold text-gray-800 mb-2;
        }
        .card-body {
            @apply text-gray-600;
        }
    </style>
</head>
<body class="p-8 bg-gradient-to-br from-blue-50 to-indigo-100 min-h-screen">
    <div class="max-w-2xl mx-auto space-y-8">
        <div class="card">
            <h2 class="card-title">Apa itu @apply?</h2>
            <p class="card-body">@apply memungkinkan Anda mengekstrak utility class ke dalam class CSS kustom. Ini seperti membuat komponen tanpa framework JavaScript.</p>
            <div class="mt-4 flex gap-3">
                <button class="btn btn-primary">Simpan</button>
                <button class="btn btn-secondary">Batal</button>
            </div>
        </div>
        <div class="card">
            <h2 class="card-title">Keuntungan</h2>
            <p class="card-body">Mengurangi pengulangan, mempermudah rebranding, dan membuat HTML lebih bersih. Cocok untuk proyek tanpa framework frontend.</p>
            <div class="mt-4 flex gap-3">
                <button class="btn btn-primary">Pelajari</button>
                <button class="btn btn-secondary">Nanti</button>
            </div>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- Gunakan `@apply` untuk pola class yang benar-benar stabil dan sangat berulang
- Pastikan file CSS yang berisi `@apply` terdaftar di konfigurasi `content` Tailwind
- Hindari `@apply` untuk komponen dengan banyak varian dinamis — lebih baik gunakan CVA atau komponen framework
