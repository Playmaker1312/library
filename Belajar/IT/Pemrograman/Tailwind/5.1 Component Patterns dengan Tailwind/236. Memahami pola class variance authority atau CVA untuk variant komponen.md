# Memahami pola class variance authority atau CVA untuk variant komponen
## Analogi: Perpustakaan Digital
CVA (Class Variance Authority) seperti katalog yang berisi berbagai varian seragam petugas perpustakaan. Ada seragam untuk petugas sirkulasi, petugas referensi, dan petugas anak-anak. Masing-masing memiliki warna dan aksesori berbeda, tetapi semuanya adalah seragam. CVA memungkinkan Anda mendefinisikan "seragam" komponen dengan berbagai varian secara terstruktur.
## Penjelasan Detail
CVA adalah library yang mempopulerkan pola pengelolaan varian komponen dengan Tailwind. Intinya, Anda mendefinisikan sebuah objek konfigurasi yang berisi base styles, varian (seperti `variant: { primary: "...", secondary: "..." }`), dan default varian. CVA kemudian menghasilkan fungsi yang menerima objek varian dan mengembalikan string class Tailwind yang sesuai. Pola ini sangat berguna untuk komponen yang memiliki banyak varian, ukuran, dan state (seperti disabled, focus). CVA juga mendukung compound variants — kombinasi varian yang menghasilkan class tertentu. Di ekosistem React, CVA telah menjadi standar de facto untuk pengelolaan varian komponen Tailwind. Library ini sering digunakan bersama `tailwind-merge` dan `clsx` untuk hasil optimal.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CVA Pattern - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="app">
        <div class="max-w-3xl mx-auto space-y-6">
            <!-- Simulasi CVA dengan fungsi helper -->
            <div class="p-6 bg-white rounded-xl shadow-md">
                <h3 class="text-xl font-bold text-gray-800 mb-4">Pola CVA untuk Button</h3>
                <div class="flex flex-wrap gap-3 mb-6">
                    <button v-for="btn in buttons" :key="btn.label"
                        :class="buttonCVA({ variant: btn.variant, size: btn.size })"
                        :disabled="btn.disabled">
                        {{ btn.label }}
                    </button>
                </div>
                <div class="flex gap-4 items-center">
                    <label class="text-sm font-medium text-gray-700">Variant:</label>
                    <select v-model="selectedVariant" class="border rounded px-3 py-1 text-sm">
                        <option value="primary">Primary</option>
                        <option value="secondary">Secondary</option>
                        <option value="outline">Outline</option>
                        <option value="ghost">Ghost</option>
                    </select>
                    <label class="text-sm font-medium text-gray-700">Size:</label>
                    <select v-model="selectedSize" class="border rounded px-3 py-1 text-sm">
                        <option value="sm">Small</option>
                        <option value="md">Medium</option>
                        <option value="lg">Large</option>
                    </select>
                    <button :class="buttonCVA({ variant: selectedVariant, size: selectedSize })">
                        Preview
                    </button>
                </div>
            </div>
        </div>
    </div>

    <script>
        const { createApp, ref, reactive } = Vue;

        // Implementasi sederhana pola CVA
        function cva(base, variants, defaultVariants = {}) {
            return function (props = {}) {
                const resolved = { ...defaultVariants, ...props };
                let classes = base;

                for (const [key, value] of Object.entries(variants)) {
                    const variantValue = resolved[key] || defaultVariants[key];
                    if (variantValue && value[variantValue]) {
                        classes += ' ' + value[variantValue];
                    }
                }

                return classes;
            };
        }

        const buttonCVA = cva(
            'inline-flex items-center justify-center rounded-lg font-semibold transition duration-200 focus:outline-none focus:ring-2 focus:ring-offset-2 disabled:opacity-50 disabled:cursor-not-allowed',
            {
                variant: {
                    primary: 'bg-blue-500 text-white hover:bg-blue-600 focus:ring-blue-300',
                    secondary: 'bg-gray-200 text-gray-800 hover:bg-gray-300 focus:ring-gray-400',
                    outline: 'border-2 border-blue-500 text-blue-500 hover:bg-blue-50 focus:ring-blue-300',
                    ghost: 'text-gray-600 hover:bg-gray-100 focus:ring-gray-300',
                },
                size: {
                    sm: 'px-3 py-1 text-sm',
                    md: 'px-5 py-2 text-base',
                    lg: 'px-8 py-3 text-lg',
                },
            },
            { variant: 'primary', size: 'md' }
        );

        const app = createApp({
            setup() {
                const selectedVariant = ref('primary');
                const selectedSize = ref('md');
                const buttons = reactive([
                    { label: 'Primary', variant: 'primary', size: 'md' },
                    { label: 'Secondary', variant: 'secondary', size: 'md' },
                    { label: 'Outline', variant: 'outline', size: 'md' },
                    { label: 'Ghost', variant: 'ghost', size: 'md' },
                    { label: 'Small', variant: 'primary', size: 'sm' },
                    { label: 'Large', variant: 'primary', size: 'lg' },
                    { label: 'Disabled', variant: 'primary', size: 'md', disabled: true },
                ]);

                return { buttonCVA, buttons, selectedVariant, selectedSize };
            }
        });

        app.mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- CVA mendefinisikan base styles, varian, dan default varian dalam satu objek konfigurasi
- Pola ini ideal untuk komponen dengan banyak varian, ukuran, dan state
- CVA sering digunakan bersama tailwind-merge dan clsx untuk penggabungan class yang aman
