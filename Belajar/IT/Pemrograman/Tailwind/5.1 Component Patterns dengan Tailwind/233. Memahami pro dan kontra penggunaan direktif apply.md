# Memahami pro dan kontra penggunaan direktif apply
## Analogi: Perpustakaan Digital
Membuat kartu referensi untuk rak buku memang praktis, tetapi jika Anda membuat terlalu banyak kartu, Anda malah membutuhkan sistem pengelolaan kartu itu sendiri. Yang awalnya bertujuan menyederhanakan justru bisa menjadi lapisan abstraksi baru yang harus dirawat. Inilah dilema utama dari setiap alat abstraksi — termasuk `@apply`.
## Penjelasan Detail
Penggunaan `@apply` memiliki sisi positif dan negatif. Dari sisi positif, `@apply` mengurangi pengulangan utility class di HTML, membuat markup lebih bersih dan lebih mudah dibaca. Ini juga memudahkan perubahan desain global karena Anda cukup mengubah satu definisi di CSS. Namun, dari sisi negatif, `@apply` menyembunyikan utility class yang digunakan dari Tailwind JIT engine, yang dapat menyebabkan hilangnya class yang tidak terdeteksi. Selain itu, `@apply` memperkenalkan kembali masalah penamaan class CSS tradisional yang justru ingin dipecahkan Tailwind. Overhead kognitif untuk memikirkan nama class (seperti `.btn-primary`, `.card-title`) bisa memperlambat produktivitas. Banyak developer berpengalaman menyarankan untuk menghindari `@apply` di awal proyek dan hanya menggunakannya jika pola pengulangan sudah sangat jelas dan stabil.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Pro Kontra Apply - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <style>
        /* Pro: HTML lebih bersih */
        .pro-card {
            @apply p-4 bg-green-50 border border-green-200 rounded-lg;
        }
        .pro-title {
            @apply text-lg font-bold text-green-800;
        }
        /* Kontra: Butuh penamaan, overhead kognitif */
        .kontra-card {
            @apply p-4 bg-red-50 border border-red-200 rounded-lg;
        }
        .kontra-title {
            @apply text-lg font-bold text-red-800;
        }
    </style>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div class="max-w-4xl mx-auto grid md:grid-cols-2 gap-6">
        <div class="pro-card">
            <h2 class="pro-title">Pro</h2>
            <ul class="mt-2 text-green-700 space-y-1 text-sm">
                <li>+ HTML lebih bersih dan mudah dibaca</li>
                <li>+ Perubahan global lebih mudah</li>
                <li>+ Mengurangi pengulangan class</li>
                <li>+ Cocok untuk tim non-JS</li>
            </ul>
        </div>
        <div class="kontra-card">
            <h2 class="kontra-title">Kontra</h2>
            <ul class="mt-2 text-red-700 space-y-1 text-sm">
                <li>- Butuh penamaan class manual</li>
                <li>- Overhead kognitif bertambah</li>
                <li>- Risiko class tidak terdeteksi JIT</li>
                <li>- Mengembalikan masalah CSS tradisional</li>
            </ul>
        </div>
    </div>
</body>
</html>
```
## Poin Penting
- `@apply` membersihkan HTML tetapi menambah kompleksitas penamaan
- Tailwind JIT bisa kehilangan jejak class yang digunakan dalam `@apply`
- Sebaiknya hindari `@apply` di awal proyek; gunakan hanya saat pola pengulangan sudah jelas dan stabil
