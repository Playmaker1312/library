# Menggunakan library clsx atau classnames untuk conditional class
## Analogi: Perpustakaan Digital
Petugas perpustakaan memiliki lencana yang berbeda tergantung situasi: lencana "Sedang Bertugas" saat bekerja, lencana "Istirahat" saat istirahat, dan tidak memakai lencana sama sekali di hari libur. `clsx` dan `classnames` adalah alat yang memudahkan Anda memilih lencana mana yang akan dipakai berdasarkan kondisi tertentu, tanpa harus menulis logika if-else yang berantakan.
## Penjelasan Detail
`clsx` (dan versi lebih besarnya `classnames`) adalah library JavaScript kecil untuk menggabungkan nama class secara kondisional. Sintaksnya sederhana: Anda bisa memberikan string, array, atau objek di mana key adalah nama class dan value adalah kondisi boolean. Jika value truthy, class akan dimasukkan. Library ini sangat berguna dalam komponen React atau Vue yang menggunakan Tailwind, di mana Anda sering perlu menambahkan class berdasarkan prop seperti `disabled`, `active`, atau `variant`. `clsx` juga menangani falsy values dengan baik — nilai `null`, `undefined`, `false`, atau `0` akan diabaikan. Untuk proyek kecil, Anda bisa menggunakan `clsx` (1.2 kB) daripada `classnames` (2.3 kB) karena ukurannya lebih kecil dengan API yang mirip.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>clsx Conditional Class - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="app">
        <div class="max-w-2xl mx-auto space-y-6">
            <div class="p-6 bg-white rounded-xl shadow-md">
                <h3 class="text-xl font-bold text-gray-800 mb-4">Demo clsx untuk Conditional Class</h3>

                <!-- Controls -->
                <div class="flex flex-wrap gap-4 mb-6">
                    <label class="flex items-center gap-2">
                        <input type="checkbox" v-model="isActive" class="rounded">
                        <span class="text-sm">Active</span>
                    </label>
                    <label class="flex items-center gap-2">
                        <input type="checkbox" v-model="isDisabled" class="rounded">
                        <span class="text-sm">Disabled</span>
                    </label>
                    <label class="flex items-center gap-2">
                        <input type="checkbox" v-model="isLoading" class="rounded">
                        <span class="text-sm">Loading</span>
                    </label>
                    <select v-model="selectedVariant" class="border rounded px-3 py-1 text-sm">
                        <option value="primary">Primary</option>
                        <option value="secondary">Secondary</option>
                        <option value="danger">Danger</option>
                    </select>
                </div>

                <!-- Button dengan clsx-style logic -->
                <button :class="btnClasses">
                    <span v-if="isLoading" class="mr-2 inline-block w-4 h-4 border-2 border-white border-t-transparent rounded-full animate-spin"></span>
                    {{ isLoading ? 'Memuat...' : isActive ? 'Aktif' : 'Nonaktif' }}
                </button>

                <!-- Logika clsx ditampilkan -->
                <div class="mt-6 p-4 bg-gray-50 rounded-lg text-sm font-mono">
                    <div>clsx(</div>
                    <div class="ml-4">'inline-flex items-center gap-2 rounded-lg font-semibold transition px-5 py-2',</div>
                    <div class="ml-4">{{ isActive ? "'bg-green-500 text-white hover:bg-green-600'" : "'bg-gray-400 text-white'" }},</div>
                    <div class="ml-4">{{ isDisabled ? "'opacity-50 cursor-not-allowed'" : "''" }},</div>
                    <div class="ml-4">{{ isLoading ? "'pointer-events-none'" : "''" }}</div>
                    <div>)</div>
                </div>
            </div>
        </div>
    </div>

    <script>
        const { createApp, ref, computed } = Vue;

        // Implementasi clsx sederhana
        function clsx(...args) {
            const classes = [];
            for (const arg of args) {
                if (!arg) continue;
                if (typeof arg === 'string') {
                    classes.push(arg);
                } else if (Array.isArray(arg)) {
                    classes.push(clsx(...arg));
                } else if (typeof arg === 'object') {
                    for (const [key, value] of Object.entries(arg)) {
                        if (value) classes.push(key);
                    }
                }
            }
            return classes.join(' ');
        }

        const app = createApp({
            setup() {
                const isActive = ref(false);
                const isDisabled = ref(false);
                const isLoading = ref(false);
                const selectedVariant = ref('primary');

                const btnClasses = computed(() => {
                    return clsx(
                        'inline-flex items-center gap-2 rounded-lg font-semibold transition px-5 py-2',
                        {
                            'bg-green-500 text-white hover:bg-green-600': isActive.value && !isDisabled.value,
                            'bg-gray-400 text-white': !isActive.value || isDisabled.value,
                            'opacity-50 cursor-not-allowed': isDisabled.value,
                            'pointer-events-none': isLoading.value,
                        }
                    );
                });

                return { isActive, isDisabled, isLoading, selectedVariant, btnClasses };
            }
        });

        app.mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- `clsx` dan `classnames` menyederhanakan penggabungan class berdasarkan kondisi boolean
- Sintaks objek memungkinkan Anda menulis `{ 'bg-red-500': isError, 'text-lg': isLarge }` secara intuitif
- `clsx` lebih ringan (1.2 kB) dibanding `classnames` (2.3 kB) dengan fungsi yang hampir identik
