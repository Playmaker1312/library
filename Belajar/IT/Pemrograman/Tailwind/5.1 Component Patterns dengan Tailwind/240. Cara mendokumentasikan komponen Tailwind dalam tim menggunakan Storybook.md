# Cara mendokumentasikan komponen Tailwind dalam tim menggunakan Storybook
## Analogi: Perpustakaan Digital
Storybook seperti katalog perpustakaan yang menampilkan setiap buku dengan sampul, sinopsis, dan informasi detailnya. Developer dapat melihat semua komponen yang tersedia, variannya, dan cara penggunaannya — persis seperti pengunjung yang mencari buku di katalog sebelum pergi ke rak.
## Penjelasan Detail
Storybook adalah alat pengembangan yang memungkinkan Anda mengembangkan dan mendokumentasikan komponen UI secara terisolasi. Untuk proyek Tailwind, Storybook memungkinkan Anda menampilkan komponen dengan semua varian, state, dan ukuran yang didukung. Anda dapat menulis "stories" yang mendemonstrasikan setiap varian komponen, lengkap dengan kontrol interaktif untuk mengubah props. Integrasi Tailwind dengan Storybook cukup mudah: Anda hanya perlu mengimpor file CSS Tailwind di file preview.js Storybook. Dengan fitur Docs, Anda bisa menghasilkan dokumentasi otomatis yang menunjukkan kode sumber komponen, props table, dan contoh penggunaan. Ini sangat berharga untuk tim yang ingin menjaga konsistensi desain dan mempercepat onboarding developer baru.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Storybook Tailwind - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="app">
        <div class="max-w-4xl mx-auto space-y-6">
            <!-- Simulasi Storybook UI -->
            <div class="bg-white rounded-xl shadow-md overflow-hidden">
                <!-- Toolbar -->
                <div class="flex items-center gap-2 px-4 py-2 bg-gray-50 border-b border-gray-200">
                    <span class="w-3 h-3 rounded-full bg-red-400"></span>
                    <span class="w-3 h-3 rounded-full bg-yellow-400"></span>
                    <span class="w-3 h-3 rounded-full bg-green-400"></span>
                    <span class="ml-4 text-sm font-mono text-gray-500">Button.stories.js</span>
                </div>
                <!-- Canvas -->
                <div class="p-8">
                    <h3 class="text-lg font-bold text-gray-800 mb-4">Button Component Stories</h3>

                    <!-- Controls -->
                    <div class="flex flex-wrap gap-4 mb-6 p-4 bg-gray-50 rounded-lg">
                        <div>
                            <label class="block text-xs font-medium text-gray-600 mb-1">Variant</label>
                            <select v-model="variant" class="border rounded px-3 py-1 text-sm">
                                <option value="primary">Primary</option>
                                <option value="secondary">Secondary</option>
                                <option value="danger">Danger</option>
                                <option value="ghost">Ghost</option>
                            </select>
                        </div>
                        <div>
                            <label class="block text-xs font-medium text-gray-600 mb-1">Size</label>
                            <select v-model="size" class="border rounded px-3 py-1 text-sm">
                                <option value="sm">Small</option>
                                <option value="md">Medium</option>
                                <option value="lg">Large</option>
                            </select>
                        </div>
                        <div>
                            <label class="block text-xs font-medium text-gray-600 mb-1">State</label>
                            <div class="flex gap-2 mt-1">
                                <label class="flex items-center gap-1 text-sm"><input type="checkbox" v-model="disabled"> Disabled</label>
                                <label class="flex items-center gap-1 text-sm"><input type="checkbox" v-model="loading"> Loading</label>
                            </div>
                        </div>
                    </div>

                    <!-- Component Preview -->
                    <button :class="btnClasses" :disabled="disabled">
                        <span v-if="loading" class="w-4 h-4 border-2 border-white border-t-transparent rounded-full animate-spin mr-2"></span>
                        {{ loading ? 'Loading...' : 'Button' }}
                    </button>

                    <!-- Stories Grid -->
                    <h4 class="text-sm font-semibold text-gray-700 mt-8 mb-3">All Variants</h4>
                    <div class="grid grid-cols-2 md:grid-cols-4 gap-4">
                        <div v-for="story in stories" :key="story.label" class="p-4 border rounded-lg text-center">
                            <div class="text-xs text-gray-500 mb-2">{{ story.label }}</div>
                            <button :class="story.classes">{{ story.text }}</button>
                        </div>
                    </div>

                    <!-- Code Snippet -->
                    <h4 class="text-sm font-semibold text-gray-700 mt-8 mb-3">Source Code</h4>
                    <pre class="p-4 bg-gray-900 text-green-400 rounded-lg text-sm overflow-x-auto"><code>&lt;Button
  variant="{{ variant }}"
  size="{{ size }}"
  {{ disabled ? ':disabled=\"true\"' : '' }}
  {{ loading ? ':loading=\"true\"' : '' }}
&gt;
  {{ loading ? 'Loading...' : 'Button' }}
&lt;/Button&gt;</code></pre>
                </div>
            </div>
        </div>
    </div>

    <script>
        const { createApp, ref, computed } = Vue;

        const app = createApp({
            setup() {
                const variant = ref('primary');
                const size = ref('md');
                const disabled = ref(false);
                const loading = ref(false);

                const baseClasses = 'inline-flex items-center justify-center gap-2 rounded-lg font-semibold transition focus:outline-none focus:ring-2 focus:ring-offset-2';

                const variantClasses = computed(() => ({
                    primary: 'bg-blue-500 text-white hover:bg-blue-600 focus:ring-blue-300',
                    secondary: 'bg-gray-200 text-gray-800 hover:bg-gray-300 focus:ring-gray-400',
                    danger: 'bg-red-500 text-white hover:bg-red-600 focus:ring-red-300',
                    ghost: 'text-gray-600 hover:bg-gray-100 focus:ring-gray-300',
                }[variant.value]));

                const sizeClasses = computed(() => ({
                    sm: 'px-3 py-1 text-sm',
                    md: 'px-5 py-2',
                    lg: 'px-8 py-3 text-lg',
                }[size.value]));

                const btnClasses = computed(() => {
                    return `${baseClasses} ${variantClasses.value} ${sizeClasses.value} ${disabled.value ? 'opacity-50 cursor-not-allowed' : ''}`;
                });

                const stories = [
                    { label: 'Primary', classes: `${baseClasses} bg-blue-500 text-white px-4 py-2 text-sm`, text: 'Primary' },
                    { label: 'Secondary', classes: `${baseClasses} bg-gray-200 text-gray-800 px-4 py-2 text-sm`, text: 'Secondary' },
                    { label: 'Danger', classes: `${baseClasses} bg-red-500 text-white px-4 py-2 text-sm`, text: 'Danger' },
                    { label: 'Ghost', classes: `${baseClasses} text-gray-600 hover:bg-gray-100 px-4 py-2 text-sm`, text: 'Ghost' },
                ];

                return { variant, size, disabled, loading, btnClasses, stories };
            }
        });

        app.mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- Storybook memungkinkan pengembangan dan dokumentasi komponen Tailwind secara terisolasi
- Fitur Docs menghasilkan dokumentasi otomatis termasuk props table dan source code
- Storybook sangat berguna untuk menjaga konsistensi desain dan onboarding developer baru dalam tim
