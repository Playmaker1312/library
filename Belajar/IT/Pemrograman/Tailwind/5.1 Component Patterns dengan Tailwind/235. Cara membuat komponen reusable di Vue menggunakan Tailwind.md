# Cara membuat komponen reusable di Vue menggunakan Tailwind
## Analogi: Perpustakaan Digital
Seperti halnya template surat yang bisa diisi dengan nama peminjam berbeda, komponen Vue dengan props memungkinkan Anda membuat kerangka tampilan yang bisa diisi dengan data berbeda. Setiap instance komponen akan mewarisi struktur yang sama tetapi dengan konten yang unik.
## Penjelasan Detail
Di Vue, Anda dapat membuat komponen reusable Tailwind melalui Single File Component (SFC) dengan template, script, dan style. Props digunakan untuk meneruskan data dan konfigurasi dari komponen parent. Anda bisa mendefinisikan prop seperti `variant`, `size`, atau `disabled` untuk mengontrol tampilan dan perilaku. Vue juga mendukung `slots` yang memungkinkan Anda menyuntikkan konten kustom ke dalam komponen. Untuk menggabungkan class secara kondisional, Anda dapat menggunakan sintaks array dan object di `:class`. Jika ingin meneruskan class dari parent, gunakan `$attrs.class` bersama dengan `inheritAttrs: false` untuk kontrol yang lebih baik. Vue's reactivity system membuat komponen Tailwind Anda menjadi dinamis dan interaktif secara alami.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Vue + Tailwind Reusable - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="app">
        <div class="max-w-3xl mx-auto space-y-6">
            <card-component title="Komponen Reusable Vue + Tailwind" variant="primary">
                <p class="mb-4">Komponen ini dibuat dengan Vue 3 Composition API dan Tailwind CSS.</p>
                <div class="flex flex-wrap gap-3">
                    <button-component
                        v-for="btn in buttons"
                        :key="btn.label"
                        :variant="btn.variant"
                        :size="btn.size"
                        @click="handleClick(btn.label)"
                    >
                        {{ btn.label }}
                    </button-component>
                </div>
            </card-component>

            <card-component title="Keuntungan Vue + Tailwind" variant="secondary">
                <ul class="list-disc list-inside space-y-1">
                    <li>Props untuk variasi tampilan</li>
                    <li>Slots untuk injeksi konten</li>
                    <li>Reaktivitas otomatis</li>
                    <li class="text-gray-800 font-semibold" v-if="lastClicked">Terakhir diklik: {{ lastClicked }}</li>
                </ul>
            </card-component>
        </div>
    </div>

    <script>
        const { createApp, ref, reactive } = Vue;

        const ButtonComponent = {
            template: `
                <button
                    :class="classes"
                    @click="$emit('click')"
                >
                    <slot />
                </button>
            `,
            props: {
                variant: { type: String, default: 'primary' },
                size: { type: String, default: 'md' },
            },
            emits: ['click'],
            computed: {
                classes() {
                    const base = 'rounded-lg font-semibold transition duration-200 focus:outline-none focus:ring-2';
                    const variants = {
                        primary: 'bg-indigo-500 text-white hover:bg-indigo-600 focus:ring-indigo-300',
                        secondary: 'bg-gray-200 text-gray-800 hover:bg-gray-300 focus:ring-gray-400',
                        success: 'bg-emerald-500 text-white hover:bg-emerald-600 focus:ring-emerald-300',
                    };
                    const sizes = {
                        sm: 'px-3 py-1 text-sm',
                        md: 'px-5 py-2',
                        lg: 'px-8 py-3 text-lg',
                    };
                    return `${base} ${variants[this.variant]} ${sizes[this.size]}`;
                }
            }
        };

        const CardComponent = {
            template: `
                <div :class="cardClasses">
                    <h3 v-if="title" class="text-xl font-bold mb-3" :class="titleClasses">{{ title }}</h3>
                    <div class="text-gray-600"><slot /></div>
                </div>
            `,
            props: {
                title: String,
                variant: { type: String, default: 'primary' },
            },
            computed: {
                cardClasses() {
                    const base = 'p-6 bg-white rounded-xl shadow-md border';
                    const borders = {
                        primary: 'border-l-4 border-l-indigo-500',
                        secondary: 'border-l-4 border-l-gray-400',
                    };
                    return `${base} ${borders[this.variant] || borders.primary}`;
                },
                titleClasses() {
                    return this.variant === 'primary' ? 'text-indigo-800' : 'text-gray-700';
                }
            }
        };

        const app = createApp({
            components: { ButtonComponent, CardComponent },
            setup() {
                const lastClicked = ref('');
                const buttons = reactive([
                    { label: 'Simpan', variant: 'primary', size: 'md' },
                    { label: 'Hapus', variant: 'secondary', size: 'md' },
                    { label: 'Konfirmasi', variant: 'success', size: 'lg' },
                    { label: 'Kecil', variant: 'primary', size: 'sm' },
                ]);

                function handleClick(label) {
                    lastClicked.value = label;
                }

                return { buttons, handleClick, lastClicked };
            }
        });

        app.mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- Gunakan props untuk variant, size, dan konfigurasi tampilan lainnya di Vue
- Manfaatkan slots untuk menyuntikkan konten kustom ke dalam komponen
- Gunakan `:class` dengan sintaks array/object untuk penggabungan class kondisional
