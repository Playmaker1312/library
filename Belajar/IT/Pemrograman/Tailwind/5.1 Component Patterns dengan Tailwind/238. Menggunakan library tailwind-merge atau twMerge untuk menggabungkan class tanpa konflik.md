# Menggunakan library tailwind-merge atau twMerge untuk menggabungkan class tanpa konflik
## Analogi: Perpustakaan Digital
Saat dua petugas perpustakaan memberikan instruksi berbeda untuk mengatur rak buku, Anda butuh aturan siapa yang didengar. `tailwind-merge` seperti pengawas yang tahu bahwa instruksi terakhir yang harus diikuti. Jika ada dua class yang mengatur property CSS yang sama (misalnya `bg-red-500` dan `bg-blue-500`), tailwind-merge akan mempertahankan class yang disebut terakhir.
## Penjelasan Detail
`tailwind-merge` adalah library yang secara cerdas menggabungkan string class Tailwind dan menyelesaikan konflik di antara mereka. Masalah yang dipecahkan: ketika komponen Anda memiliki class default (misal `bg-blue-500 text-white px-4 py-2`) dan pengguna memberikan class tambahan melalui prop `className` (misal `bg-red-500`), penggabungan string biasa akan menghasilkan kedua class tersebut. Tailwind akan menggunakan yang terakhir di stylesheet, yang mungkin bukan yang diinginkan. `tailwind-merge` memahami spesifisitas class Tailwind dan akan memastikan class yang disebut di akhir (biasanya dari pengguna) yang menang. Library ini sangat penting untuk pembuatan library komponen atau komponen reusable yang menerima prop `className` dari pengguna. `tailwind-merge` juga bekerja dengan class kustom dan varian seperti `hover:`, `dark:`, `lg:`.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>tailwind-merge - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="app">
        <div class="max-w-3xl mx-auto space-y-6">
            <div class="p-6 bg-white rounded-xl shadow-md">
                <h3 class="text-xl font-bold text-gray-800 mb-4">Demo tailwind-merge</h3>

                <!-- Input untuk class kustom -->
                <div class="mb-4">
                    <label class="block text-sm font-medium text-gray-700 mb-1">Custom className untuk button:</label>
                    <div class="flex gap-2">
                        <input v-model="customClass" placeholder="Contoh: bg-red-500 text-white text-xl"
                            class="flex-1 border rounded-lg px-4 py-2 text-sm font-mono">
                        <button @click="customClass = ''" class="px-3 py-2 bg-gray-200 rounded-lg text-sm hover:bg-gray-300">Reset</button>
                    </div>
                </div>

                <!-- Button tanpa twMerge -->
                <div class="p-4 bg-red-50 rounded-lg mb-4">
                    <div class="text-sm font-semibold text-red-700 mb-2">Tanpa tailwind-merge (concat biasa):</div>
                    <button :class="`bg-blue-500 text-white px-5 py-2 rounded-lg font-semibold ${customClass}`">
                        Button
                    </button>
                    <div class="text-xs text-red-600 mt-1">Class terakhir mungkin tidak menang karena urutan CSS</div>
                </div>

                <!-- Button dengan twMerge -->
                <div class="p-4 bg-green-50 rounded-lg">
                    <div class="text-sm font-semibold text-green-700 mb-2">Dengan tailwind-merge:</div>
                    <button :class="twMerge('bg-blue-500 text-white px-5 py-2 rounded-lg font-semibold', customClass)">
                        Button
                    </button>
                    <div class="text-xs text-green-600 mt-1">Class pengguna akan selalu menimpa class default dengan benar</div>
                </div>

                <!-- Info current classes -->
                <div class="mt-6 p-4 bg-gray-50 rounded-lg text-sm font-mono">
                    <div>Default: bg-blue-500 text-white px-5 py-2 rounded-lg font-semibold</div>
                    <div>Custom:  {{ customClass || '(kosong)' }}</div>
                    <div>Result:  {{ twMerge('bg-blue-500 text-white px-5 py-2 rounded-lg font-semibold', customClass) }}</div>
                </div>
            </div>
        </div>
    </div>

    <script>
        const { createApp, ref } = Vue;

        // Implementasi sederhana tailwind-merge
        // Property CSS yang sering bentrok di Tailwind
        const CONFLICTING = {
            'bg': true, 'text': true, 'p': true, 'px': true, 'py': true,
            'm': true, 'mx': true, 'my': true, 'rounded': true,
            'border': true, 'shadow': true, 'font': true,
        };

        function getTailwindProperty(cls) {
            // Ekstrak property dari class Tailwind (misal: bg-red-500 -> bg, hover:bg-red-500 -> bg)
            const clean = cls.replace(/^(hover|focus|active|dark|lg|md|sm|xl):/, '');
            const parts = clean.split('-');
            if (parts.length >= 2 && CONFLICTING[parts[0]]) return parts[0];
            if (parts.length >= 3 && CONFLICTING[parts[0] + '-' + parts[1]]) return parts[0] + '-' + parts[1];
            return null;
        }

        function twMerge(...classLists) {
            const allClasses = classLists.filter(Boolean).join(' ').split(/\s+/);
            const merged = {};
            const result = [];

            for (const cls of allClasses) {
                if (!cls) continue;
                const prop = getTailwindProperty(cls);
                if (prop) {
                    merged[prop] = cls; // Timpa dengan yang terakhir
                } else {
                    result.push(cls);
                }
            }

            // Tambahkan yang sudah di-resolve konflik
            const resolved = new Set();
            for (const cls of allClasses) {
                const prop = getTailwindProperty(cls);
                if (prop && !resolved.has(prop)) {
                    result.push(merged[prop]);
                    resolved.add(prop);
                }
            }

            return [...new Set(result)].join(' ');
        }

        const app = createApp({
            setup() {
                const customClass = ref('');
                return { customClass, twMerge };
            }
        });

        app.mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- `tailwind-merge` menyelesaikan konflik class Tailwind dengan aturan "yang terakhir dipanggil yang menang"
- Sangat penting untuk komponen reusable yang menerima prop `className` dari pengguna
- Library ini memahami varian Tailwind, class kustom, dan property CSS yang saling bertentangan
