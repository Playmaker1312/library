# Memahami pola compound component dengan Tailwind
## Analogi: Perpustakaan Digital
Sebuah meja peminjaman perpustakaan terdiri dari beberapa bagian: formulir, tempat stempel, dan laci penyimpanan. Masing-masing bagian bisa digunakan sendiri, tetapi jika digabungkan membentuk satu kesatuan yang utuh. Compound component memungkinkan Anda membuat komponen yang terdiri dari sub-komponen yang bekerja bersama secara implisit.
## Penjelasan Detail
Compound component adalah pola di React/Vue di mana sebuah komponen "parent" menyediakan beberapa sub-komponen yang saling berbagi state secara internal tanpa perlu prop drilling. Contoh klasik adalah komponen `Select` dengan `Select.Option`, atau `Tabs` dengan `Tabs.Tab` dan `Tabs.Panel`. Pola ini sangat cocok dengan Tailwind karena setiap sub-komponen bisa memiliki utility class sendiri. State bersama (seperti tab mana yang aktif) dikelola oleh komponen parent melalui React Context atau Vue provide/inject. Sub-komponen kemudian mengonsumsi state tersebut untuk menyesuaikan tampilannya. Pola ini menghasilkan API yang ekspresif dan deklaratif. Dengan Tailwind, setiap sub-komponen bisa di-styling secara independen tanpa khawatir tentang konflik class.
## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Compound Component - Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body class="p-8 bg-gray-100 min-h-screen">
    <div id="app">
        <div class="max-w-2xl mx-auto">
            <tabs>
                <tab-panel name="deskripsi" :selected="true">
                    <template #title>Deskripsi</template>
                    <p class="text-gray-600">Compound component memungkinkan sub-komponen berbagi state secara implisit. Setiap sub-komponen dapat di-styling dengan Tailwind secara independen.</p>
                </tab-panel>
                <tab-panel name="fitur">
                    <template #title>Fitur</template>
                    <ul class="list-disc list-inside text-gray-600 space-y-1">
                        <li>State management terpusat</li>
                        <li>API deklaratif dan ekspresif</li>
                        <li>Setiap sub-komponen punya styling sendiri</li>
                    </ul>
                </tab-panel>
                <tab-panel name="contoh">
                    <template #title>Contoh</template>
                    <div class="flex gap-2">
                        <span class="px-3 py-1 bg-blue-100 text-blue-700 rounded-full text-sm">Tailwind</span>
                        <span class="px-3 py-1 bg-green-100 text-green-700 rounded-full text-sm">Vue</span>
                        <span class="px-3 py-1 bg-purple-100 text-purple-700 rounded-full text-sm">Compound</span>
                    </div>
                </tab-panel>
            </tabs>
        </div>
    </div>

    <script>
        const { createApp, ref, provide, inject, computed } = Vue;

        // Provide key
        const TABS_KEY = Symbol('tabs');

        // Tabs component (parent)
        const Tabs = {
            template: `
                <div class="bg-white rounded-xl shadow-md overflow-hidden">
                    <!-- Tab navigation -->
                    <div class="flex border-b border-gray-200 bg-gray-50">
                        <button
                            v-for="tab in tabs"
                            :key="tab.name"
                            @click="activeTab = tab.name"
                            :class="[
                                'px-5 py-3 text-sm font-medium transition',
                                activeTab === tab.name
                                    ? 'text-blue-600 border-b-2 border-blue-600 bg-white'
                                    : 'text-gray-500 hover:text-gray-700 hover:bg-gray-100'
                            ]"
                        >
                            <component :is="tab.titleComponent" v-if="tab.titleComponent" />
                            <template v-else>{{ tab.name }}</template>
                        </button>
                    </div>
                    <!-- Tab content -->
                    <div class="p-6">
                        <slot />
                    </div>
                </div>
            `,
            setup() {
                const activeTab = ref('');
                const tabs = ref([]);

                provide(TABS_KEY, { activeTab, tabs, registerTab: (tab) => {
                    tabs.value.push(tab);
                    if (tab.selected && !activeTab.value) {
                        activeTab.value = tab.name;
                    }
                    if (tabs.value.length === 1 && !activeTab.value) {
                        activeTab.value = tab.name;
                    }
                }});

                return { tabs, activeTab };
            }
        };

        // TabPanel component (child)
        const TabPanel = {
            template: `
                <div v-show="isActive">
                    <slot />
                </div>
            `,
            props: {
                name: String,
                selected: { type: Boolean, default: false },
            },
            setup(props, { slots }) {
                const { activeTab, registerTab } = inject(TABS_KEY);
                const titleComponent = slots.title ? computed(() => slots.title) : null;

                registerTab({
                    name: props.name,
                    selected: props.selected,
                    titleComponent: titleComponent ? { render: titleComponent.value } : null,
                });

                const isActive = computed(() => activeTab.value === props.name);

                return { isActive };
            }
        };

        const app = createApp({
            components: { Tabs, TabPanel }
        });

        app.mount('#app');
    </script>
</body>
</html>
```
## Poin Penting
- Compound component memungkinkan sub-komponen berbagi state melalui context/provider tanpa prop drilling
- Pola ini ideal untuk komponen kompleks seperti Tabs, Select, atau Accordion
- Tailwind memungkinkan styling independen untuk setiap sub-komponen dalam compound component
