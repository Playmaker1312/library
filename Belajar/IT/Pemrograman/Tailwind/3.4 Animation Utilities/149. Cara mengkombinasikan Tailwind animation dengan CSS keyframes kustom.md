# Cara mengkombinasikan Tailwind animation dengan CSS keyframes kustom

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang memiliki buku dengan ilustrasi bergerak yang kompleks. Seperti menggabungkan halaman buku dengan ilustrasi animasi kustom, Anda bisa menggunakan animasi Tailwind default sebagai dasar kemudian menambahkan keyframes kustom untuk efek yang lebih spesifik. Ini memberikan keseimbangan antara kemudahan utility classes dan fleksibilitas CSS murni. Hasilnya adalah animasi yang unik dan sesuai kebutuhan spesifik proyek.

## Penjelasan Detail
Anda bisa menggabungkan animasi Tailwind dengan CSS keyframes kustom melalui beberapa pendekatan: (1) Mendefinisikan keyframes kustom di tailwind.config.js dan menggunakannya dengan animate-{nama}, (2) Menggunakan arbitrary animation dengan format animate-[namaKustom_1s_ease_infinite] di HTML, (3) Menulis CSS keyframes di stylesheet dan merujuknya dengan arbitrary value animate-[slideIn_1s_ease-in-out], (4) Mengombinasikan utility Tailwind dengan CSS inline untuk properti yang tidak tercakup. Pendekatan ketiga sangat berguna ketika Anda ingin menggunakan animasi yang kompleks tanpa perlu mengubah konfigurasi Tailwind. Anda bisa mendefinisikan keyframes di tag style dan langsung menggunakannya di class dengan format animate-[namaKeyframes_durasi_easing].

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Kombinasi Animasi</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <style>
        @keyframes float {
            0%, 100% { transform: translateY(0px) rotate(0deg); }
            33% { transform: translateY(-15px) rotate(3deg); }
            66% { transform: translateY(-8px) rotate(-2deg); }
        }
        @keyframes glow {
            0%, 100% { box-shadow: 0 0 5px rgba(59,130,246,0.5); }
            50% { box-shadow: 0 0 30px rgba(59,130,246,0.8), 0 0 60px rgba(59,130,246,0.3); }
        }
    </style>
</head>
<body class="flex flex-col items-center justify-center gap-8 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">Animasi Kombinasi</h2>
    <div class="animate-[float_3s_ease-in-out_infinite] bg-gradient-to-br from-blue-500 to-purple-600 w-32 h-32 rounded-xl flex items-center justify-center text-white font-bold shadow-lg">
        float
    </div>
    <div class="animate-[glow_2s_ease-in-out_infinite] bg-gradient-to-br from-green-400 to-emerald-500 w-32 h-32 rounded-xl flex items-center justify-center text-white font-bold">
        glow
    </div>
    <div class="animate-[float_4s_ease-in-out_infinite,glow_2s_ease-in-out_infinite] bg-gradient-to-br from-pink-500 to-rose-500 w-32 h-32 rounded-xl flex items-center justify-center text-white font-bold">
        float + glow
    </div>
    <div class="animate-spin [animation-duration:3s] bg-gradient-to-r from-yellow-400 to-orange-500 w-24 h-24 rounded-full flex items-center justify-center text-white font-bold text-sm">
        lambat
    </div>
    <p class="text-gray-400 text-sm">Kombinasikan animasi Tailwind default dengan keyframes kustom untuk efek unik</p>
</body>
</html>
```

## Poin Penting
- Definisikan CSS keyframes di stylesheet, lalu gunakan dengan format animate-[nama_durasi_easing].
- Beberapa animasi bisa digabungkan dengan memisahkannya dengan koma dalam satu class.
- Gunakan arbitrary value untuk menyesuaikan duration, easing, atau delay animasi Tailwind bawaan.
