# Menggunakan prefers-reduced-motion untuk aksesibilitas animasi

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang memiliki sensor untuk mendeteksi pengunjung yang sensitif terhadap gerakan. prefers-reduced-motion seperti sensor yang membaca preferensi pengunjung dan secara otomatis mengatur lingkungan perpustakaan. Jika pengunjung membutuhkan lingkungan tenang, semua elemen bergerak akan dimatikan. Ini memastikan perpustakaan nyaman untuk semua pengunjung tanpa terkecuali.

## Penjelasan Detail
prefers-reduced-motion adalah media query CSS yang mendeteksi preferensi pengguna terhadap animasi dan efek gerakan di sistem operasi mereka. Pengguna dapat mengaktifkan pengaturan ini di Windows (Settings > Ease of Access > Display > Show animations), macOS (System Preferences > Accessibility > Display > Reduce motion), atau perangkat mobile. Tailwind menyediakan variant motion-reduce yang secara langsung memetakan ke media query ini. Praktik terbaik adalah selalu menyediakan fallback statis untuk setiap animasi, misalnya motion-reduce:animate-none untuk mematikan animasi, atau motion-reduce:transition-none untuk transisi. Jangan hanya menyembunyikan animasi, tetapi pastikan konten tetap dapat diakses dan dipahami tanpa efek gerakan.

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Preferensi Reduced Motion</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <style>
        @media (prefers-reduced-motion: reduce) {
            .custom-info { border-left: 4px solid #3B82F6; }
        }
    </style>
</head>
<body class="flex flex-col items-center justify-center gap-8 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">Aksesibilitas Animasi</h2>
    <div class="motion-reduce:animate-none animate-spin w-16 h-16 border-4 border-blue-500 border-t-transparent rounded-full"></div>
    <div class="flex gap-4 motion-reduce:gap-3">
        <div class="motion-reduce:scale-100 motion-safe:hover:scale-110 motion-reduce:hover:opacity-80 transition-all bg-gradient-to-br from-purple-500 to-pink-500 w-24 h-24 rounded-xl flex items-center justify-center text-white text-sm font-bold cursor-pointer">
            Kartu 1
        </div>
        <div class="motion-reduce:scale-100 motion-safe:hover:scale-110 motion-reduce:hover:opacity-80 transition-all bg-gradient-to-br from-cyan-500 to-blue-600 w-24 h-24 rounded-xl flex items-center justify-center text-white text-sm font-bold cursor-pointer">
            Kartu 2
        </div>
        <div class="motion-reduce:scale-100 motion-safe:hover:scale-110 motion-reduce:hover:opacity-80 transition-all bg-gradient-to-br from-green-400 to-teal-500 w-24 h-24 rounded-xl flex items-center justify-center text-white text-sm font-bold cursor-pointer">
            Kartu 3
        </div>
    </div>
    <div class="custom-info bg-gray-800 p-5 rounded-xl max-w-lg">
        <p class="text-gray-300">Aktifkan <strong class="text-white">Reduce motion</strong> di sistem operasi Anda untuk melihat perbedaan. Animasi akan dimatikan dan diganti dengan efek statis.</p>
    </div>
</body>
</html>
```

## Poin Penting
- prefers-reduced-motion adalah media query CSS yang mendeteksi preferensi aksesibilitas pengguna.
- Tailwind menyediakan variant motion-reduce yang langsung memetakan ke media query ini.
- Selalu sediakan fallback statis untuk setiap animasi agar konten tetap dapat diakses.
