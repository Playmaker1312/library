# Cara membuat custom animation menggunakan konfigurasi Tailwind

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang ingin menambahkan jenis animasi baru yang tidak ada di katalog default. Seperti membuat aturan peminjaman baru di perpustakaan, Anda bisa mendefinisikan animasi kustom di file konfigurasi Tailwind. Ini memberikan fleksibilitas penuh untuk menciptakan efek gerakan yang unik sesuai kebutuhan desain. Setiap animasi baru bisa digunakan dengan utility animate-{nama}.

## Penjelasan Detail
Untuk membuat custom animation, Anda menambahkan konfigurasi di bagian theme.extend.animation dan theme.extend.keyframes di tailwind.config.js. Di animation, Anda mendefinisikan nama animasi dan properti CSS animation shorthand-nya (duration, timing, repeat, dll). Di keyframes, Anda mendefinisikan langkah-langkah animasi menggunakan persentase atau from/to. Setelah dikonfigurasi, Anda bisa menggunakan animate-{nama} langsung di HTML. Custom animation memungkinkan Anda membuat efek yang tidak tersedia secara default seperti fade-in, slide-up, shake, typing effect, dan sebagainya.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Custom Animation Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
    <script>
        tailwind.config = {
            theme: {
                extend: {
                    animation: {
                        'fade-in': 'fadeIn 0.5s ease-out',
                        'slide-up': 'slideUp 0.6s ease-out',
                        'shake': 'shake 0.5s ease-in-out',
                    },
                    keyframes: {
                        fadeIn: {
                            '0%': { opacity: '0', transform: 'translateY(20px)' },
                            '100%': { opacity: '1', transform: 'translateY(0)' },
                        },
                        slideUp: {
                            '0%': { transform: 'translateY(100%)', opacity: '0' },
                            '100%': { transform: 'translateY(0)', opacity: '1' },
                        },
                        shake: {
                            '0%, 100%': { transform: 'translateX(0)' },
                            '10%, 30%, 50%, 70%, 90%': { transform: 'translateX(-5px)' },
                            '20%, 40%, 60%, 80%': { transform: 'translateX(5px)' },
                        },
                    }
                }
            }
        }
    </script>
</head>
<body class="flex flex-col items-center justify-center gap-8 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">Custom Animation</h2>
    <div class="animate-fade-in bg-gradient-to-r from-blue-500 to-purple-600 w-48 h-32 rounded-xl flex items-center justify-center text-white font-bold">
        animate-fade-in
    </div>
    <div class="animate-slide-up bg-gradient-to-r from-green-400 to-teal-500 w-48 h-32 rounded-xl flex items-center justify-center text-white font-bold">
        animate-slide-up
    </div>
    <button class="animate-shake hover:animate-none bg-gradient-to-r from-red-500 to-pink-500 text-white font-bold px-8 py-3 rounded-xl" onclick="this.classList.add('animate-shake')">
        Klik untuk shake
    </button>
    <p class="text-gray-400 text-sm">Animasi didefinisikan di tailwind.config via script CDN</p>
</body>
</html>
```

## Poin Penting
- Tambahkan animasi di theme.extend.animation dan keyframes di tailwind.config.js.
- Gunakan CSS keyframes standar dengan format persentase atau from/to.
- Custom animation bisa langsung digunakan dengan utility animate-{nama} di HTML.
