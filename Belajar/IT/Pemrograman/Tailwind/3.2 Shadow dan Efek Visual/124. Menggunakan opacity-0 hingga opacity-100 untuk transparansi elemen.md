# Menggunakan opacity-0 hingga opacity-100 untuk transparansi elemen

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang memiliki jendela kaca dengan berbagai tingkat transparansi. opacity-0 seperti jendela yang benar-benar buram, opacity-100 seperti jendela bening sempurna, dan opacity-50 seperti kaca setengah transparan. Seperti mengatur tingkat visibilitas ruangan di perpustakaan, Anda bisa mengontrol seberapa tembus pandang suatu elemen. Ini penting untuk menciptakan efek layering dan kedalaman visual.

## Penjelasan Detail
Utility opacity di Tailwind menggunakan skala dari 0 hingga 100 dengan kelipatan 5, memberikan 21 tingkat transparansi yang berbeda. opacity-0 membuat elemen sepenuhnya transparan (tidak terlihat tetapi tetap ada di layout), opacity-100 membuat elemen sepenuhnya opak. Tingkatan seperti opacity-25, opacity-50, opacity-75 memberikan kontrol granular atas transparansi. Opacity sangat berguna untuk efek hover, overlay, elemen disabled, atau menciptakan hierarki visual. Berbeda dengan display:none atau visibility:hidden, elemen dengan opacity-0 tetap mempertahankan ruangnya di layout dan masih bisa berinteraksi.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Opacity Utilities</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-8 p-10 min-h-screen bg-gradient-to-br from-indigo-500 to-purple-700">
    <div class="flex flex-wrap items-center justify-center gap-4">
        <div class="opacity-100 bg-white w-20 h-20 rounded-lg shadow-lg"></div>
        <div class="opacity-75 bg-white w-20 h-20 rounded-lg shadow-lg"></div>
        <div class="opacity-50 bg-white w-20 h-20 rounded-lg shadow-lg"></div>
        <div class="opacity-25 bg-white w-20 h-20 rounded-lg shadow-lg"></div>
        <div class="opacity-10 bg-white w-20 h-20 rounded-lg shadow-lg"></div>
        <div class="opacity-0 bg-white w-20 h-20 rounded-lg shadow-lg border-2 border-white/30"></div>
    </div>
    <div class="flex gap-4">
        <span class="opacity-100 text-white text-lg font-bold">100%</span>
        <span class="opacity-75 text-white text-lg font-bold">75%</span>
        <span class="opacity-50 text-white text-lg font-bold">50%</span>
        <span class="opacity-25 text-white text-lg font-bold">25%</span>
    </div>
    <button class="opacity-100 hover:opacity-70 bg-white text-indigo-700 font-bold px-8 py-3 rounded-full transition-opacity">
        Hover untuk fade
    </button>
</body>
</html>
```

## Poin Penting
- Opacity diatur dalam skala 0-100 dengan kelipatan 5 (0, 5, 10, 15, ... 95, 100).
- opacity-0 membuat elemen transparan tetapi tetap mempertahankan ruang dan interaktivitas.
- Gunakan transition-opacity untuk animasi fade yang halus saat hover atau state change.
