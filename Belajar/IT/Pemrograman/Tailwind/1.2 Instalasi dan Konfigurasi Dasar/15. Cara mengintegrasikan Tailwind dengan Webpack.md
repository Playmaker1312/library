# Cara Mengintegrasikan Tailwind dengan Webpack

## Analogi: Perpustakaan Digital

Webpack seperti sistem manajemen perpustakaan enterprise yang sangat konfigurabel. Ada banyak pengaturan, plugin, dan loader yang bisa dipasang. Butuh waktu untuk menyiapkannya, tapi setelah jadi, sistem ini sangat kuat dan bisa menangani proyek besar dengan banyak cabang.

## Penjelasan Detail

Webpack adalah module bundler yang sudah mapan dan banyak digunakan di project production. Integrasi Tailwind dengan Webpack membutuhkan PostCSS loader. Install dependencies: `npm install -D tailwindcss postcss postcss-loader`. Buat file `postcss.config.js` di root project dengan konten `module.exports = { plugins: { tailwindcss: {}, autoprefixer: {} } }`. Pastikan `css-loader` dan `style-loader` atau `MiniCssExtractPlugin` sudah terkonfigurasi di Webpack. Tambahkan direktif Tailwind di file CSS entry. Kelebihan Webpack adalah ekosistem plugin yang luas dan dukungan untuk berbagai fitur seperti code splitting, asset modules, dan environment-specific configuration. Namun, konfigurasinya lebih kompleks dibanding Vite.

## Poin Penting
- Membutuhkan PostCSS loader untuk integrasi dengan Webpack
- Konfigurasi lebih kompleks namun ekosistem plugin sangat luas
- Cocok untuk project enterprise yang sudah menggunakan Webpack
