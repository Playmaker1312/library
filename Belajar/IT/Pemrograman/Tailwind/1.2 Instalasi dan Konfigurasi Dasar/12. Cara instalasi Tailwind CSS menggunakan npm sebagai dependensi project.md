# Cara Instalasi Tailwind CSS Menggunakan NPM

## Analogi: Perpustakaan Digital

Ini seperti membeli kit perpustakaan pribadi yang dikirim ke rumah. Anda perlu mendaftar (npm init), memesan paket (npm install), dan mengatur rak buku (konfigurasi). Prosesnya lebih panjang, tapi setelahnya Anda memiliki perpustakaan permanen yang bisa diakses kapan saja tanpa koneksi internet.

## Penjelasan Detail

Instalasi Tailwind via npm adalah metode standar untuk project produksi. Langkahnya: inisialisasi project dengan `npm init -y`, install Tailwind dengan `npm install -D tailwindcss`, buat file konfigurasi dengan `npx tailwindcss init`, dan atur path konten di `tailwind.config.js`. Selanjutnya, buat file CSS utama dengan direktif Tailwind `@tailwind base; @tailwind components; @tailwind utilities;`. Terakhir, jalankan `npx tailwindcss -i input.css -o output.css --watch` untuk memulai development. Metode ini memberikan kontrol penuh atas konfigurasi, ukuran file optimal untuk production, dan integrasi dengan build tool modern.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Instalasi NPM</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-900 text-white p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-2xl w-full">
        <h1 class="text-3xl font-bold mb-8 text-center">Instalasi via NPM</h1>
        <div class="bg-slate-800 rounded-xl p-6 font-mono text-sm space-y-2">
            <div class="text-green-400">$ npm init -y</div>
            <div class="text-green-400">$ npm install -D tailwindcss</div>
            <div class="text-green-400">$ npx tailwindcss init</div>
            <div class="text-yellow-400 mt-4">// tailwind.config.js</div>
            <div class="text-gray-300">module.exports = {</div>
            <div class="text-gray-300 pl-4">content: ["./src/**/*.{html,js}"],</div>
            <div class="text-gray-300">}</div>
            <div class="text-yellow-400 mt-4">// input.css</div>
            <div class="text-gray-300">@tailwind base;</div>
            <div class="text-gray-300">@tailwind components;</div>
            <div class="text-gray-300">@tailwind utilities;</div>
            <div class="text-green-400 mt-4">$ npx tailwindcss -i input.css -o output.css --watch</div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Metode standar untuk project produksi dengan kontrol penuh
- Membutuhkan inisialisasi npm, instalasi, dan konfigurasi
- File CSS final optimal dan bisa diintegrasikan dengan build tool
