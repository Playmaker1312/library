# Cara Instalasi Tailwind CSS Menggunakan CDN Play CDN

## Analogi: Perpustakaan Digital

Ini seperti perpustakaan keliling yang datang ke rumah Anda. Tanpa perlu mendaftar atau membangun gedung, Anda bisa langsung meminjam buku dengan menunjukkan kartu identitas. Cukup tempel satu baris kode di HTML, dan seluruh koleksi Tailwind siap digunakan.

## Penjelasan Detail

Play CDN adalah cara termudah untuk mulai menggunakan Tailwind CSS tanpa instalasi apapun. Cukup tambahkan tag `<script src="https://cdn.tailwindcss.com">` di bagian `<head>` file HTML, dan semua class Tailwind siap digunakan. Metode ini sangat cocok untuk prototyping cepat, membuat demo, atau belajar Tailwind. Play CDN menggunakan JIT engine yang berjalan di browser, sehingga class yang tidak digunakan tidak akan menghasilkan CSS. Namun, metode ini tidak cocok untuk production karena file Tailwind harus di-download setiap kali halaman dimuat. Untuk production, gunakan instalasi npm atau Tailwind CLI.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Play CDN Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 min-h-screen flex items-center justify-center">
    <div class="text-center max-w-md mx-auto p-8 bg-white rounded-2xl shadow-lg">
        <div class="w-20 h-20 bg-gradient-to-br from-purple-500 to-pink-500 rounded-full mx-auto mb-4 flex items-center justify-center">
            <span class="text-3xl text-white font-bold">&lt;/&gt;</span>
        </div>
        <h1 class="text-2xl font-bold text-gray-900 mb-2">Play CDN Active</h1>
        <p class="text-gray-600 mb-4">Tailwind sudah siap digunakan hanya dengan satu baris script tag!</p>
        <div class="flex gap-2 justify-center">
            <span class="px-3 py-1 bg-purple-100 text-purple-700 text-sm rounded-full">Cepat</span>
            <span class="px-3 py-1 bg-green-100 text-green-700 text-sm rounded-full">Mudah</span>
            <span class="px-3 py-1 bg-blue-100 text-blue-700 text-sm rounded-full">Prototype</span>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Cukup tambahkan satu script tag untuk mulai menggunakan Tailwind
- Metode terbaik untuk prototyping, demo, dan belajar
- Tidak cocok untuk production karena load time tidak optimal
