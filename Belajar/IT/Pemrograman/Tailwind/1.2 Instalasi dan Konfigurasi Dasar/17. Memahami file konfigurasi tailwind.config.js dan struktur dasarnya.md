# Memahami File Konfigurasi Tailwind CSS

## Analogi: Perpustakaan Digital

File konfigurasi Tailwind seperti katalog utama perpustakaan yang bisa dimodifikasi. Anda bisa menambahkan genre buku baru, mengubah kategori yang ada, atau menghapus bagian yang tidak diperlukan. Katalog ini adalah pusat kendali yang menentukan bagaimana seluruh perpustakaan beroperasi.

## Penjelasan Detail

`tailwind.config.js` adalah file JavaScript yang mengekspor objek konfigurasi untuk Tailwind. Struktur dasarnya terdiri dari beberapa bagian utama. `content` (dulu `purge`) menentukan file mana yang di-scan untuk class Tailwind. `theme` berisi semua design tokens seperti warna, font, spacing, breakpoints, dan lainnya. `theme.extend` digunakan untuk menambah nilai baru tanpa menimpa default. `plugins` untuk menambahkan plugin Tailwind kustom. `prefix` untuk menambahkan prefix pada semua class. `important` untuk menambahkan `!important` pada semua utility. Konfigurasi ini memungkinkan kustomisasi penuh Tailwind sesuai kebutuhan project. File ini bisa dibuat dengan `npx tailwindcss init` atau manual.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Konfigurasi Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-2xl w-full">
        <h1 class="text-3xl font-bold text-center text-gray-900 mb-8">tailwind.config.js</h1>
        <div class="bg-white rounded-2xl shadow-lg overflow-hidden">
            <div class="bg-gray-900 p-6 font-mono text-sm leading-relaxed">
                <div class="text-gray-400">/** @type {import('tailwindcss').Config} */</div>
                <div class="text-blue-400">module</div><span class="text-white">.</span><span class="text-yellow-400">exports</span><span class="text-white"> = {</span>
                <div class="pl-4"><span class="text-purple-400">content</span><span class="text-white">: [</span><span class="text-green-400">"./src/**/*.{html,js}"</span><span class="text-white">],</span></div>
                <div class="pl-4"><span class="text-purple-400">theme</span><span class="text-white">: {</span></div>
                <div class="pl-8"><span class="text-purple-400">extend</span><span class="text-white">: {</span></div>
                <div class="pl-12"><span class="text-purple-400">colors</span><span class="text-white">: {</span></div>
                <div class="pl-16"><span class="text-purple-400">primary</span><span class="text-white">: </span><span class="text-green-400">'#3B82F6'</span><span class="text-white">,</span></div>
                <div class="pl-16"><span class="text-purple-400">secondary</span><span class="text-white">: </span><span class="text-green-400">'#8B5CF6'</span><span class="text-white">,</span></div>
                <div class="pl-12"><span class="text-white">},</span></div>
                <div class="pl-12"><span class="text-purple-400">fontFamily</span><span class="text-white">: {</span></div>
                <div class="pl-16"><span class="text-purple-400">heading</span><span class="text-white">: [</span><span class="text-green-400">'Poppins'</span><span class="text-white">, </span><span class="text-green-400">'sans-serif'</span><span class="text-white">],</span></div>
                <div class="pl-12"><span class="text-white">},</span></div>
                <div class="pl-8"><span class="text-white">},</span></div>
                <div class="pl-4"><span class="text-white">},</span></div>
                <div class="pl-4"><span class="text-purple-400">plugins</span><span class="text-white">: [],</span></div>
                <div class="text-white">}</div>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- `content` menentukan file yang di-scan untuk class Tailwind
- `theme.extend` menambah nilai baru tanpa menimpa konfigurasi default
- File konfigurasi adalah pusat kendali kustomisasi Tailwind
