# Memahami Direktif Tailwind CSS

## Analogi: Perpustakaan Digital

Direktif Tailwind seperti perintah khusus yang diberikan ke petugas perpustakaan. `@tailwind base` adalah perintah untuk menyiapkan rak dasar. `@tailwind components` untuk mengatur buku-buku komponen. `@tailwind utilities` untuk menyusun alat-alat utility di bagian paling atas agar mudah dijangkau.

## Penjelasan Detail

Direktif Tailwind adalah at-rules khusus yang digunakan dalam file CSS untuk mengontrol output Tailwind. `@tailwind base` menyuntikkan gaya dasar (normalize/reset) seperti menghilangkan margin default browser. `@tailwind components` menyuntikkan class komponen dari plugin (seperti container, forms, typography). `@tailwind utilities` menyuntikkan semua class utility Tailwind. Urutan direktif penting karena menentukan spesifisitas CSS - utilities harus setelah components agar bisa menimpa. `@layer` digunakan untuk mengelompokkan CSS kustom ke dalam layer yang sama. `@apply` memungkinkan penggunaan utility class di dalam CSS kustom. `@config` menentukan file konfigurasi Tailwind yang digunakan (khusus Tailwind v3+).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Direktif Tailwind</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-slate-900 text-white p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-2xl w-full">
        <h1 class="text-3xl font-bold text-center mb-8">Direktif Tailwind</h1>
        <div class="grid grid-cols-1 gap-4">
            <div class="bg-slate-800 rounded-xl p-5 border-l-4 border-blue-500">
                <code class="text-blue-400 font-mono text-lg">@tailwind base;</code>
                <p class="text-slate-300 mt-1">Menyuntikkan gaya dasar (reset/normalize) untuk konsistensi lintas browser</p>
            </div>
            <div class="bg-slate-800 rounded-xl p-5 border-l-4 border-green-500">
                <code class="text-green-400 font-mono text-lg">@tailwind components;</code>
                <p class="text-slate-300 mt-1">Menyuntikkan class komponen dari plugin eksternal</p>
            </div>
            <div class="bg-slate-800 rounded-xl p-5 border-l-4 border-purple-500">
                <code class="text-purple-400 font-mono text-lg">@tailwind utilities;</code>
                <p class="text-slate-300 mt-1">Menyuntikkan semua class utility yang menjadi inti Tailwind</p>
            </div>
            <div class="bg-slate-800 rounded-xl p-5 border-l-4 border-yellow-500">
                <code class="text-yellow-400 font-mono text-lg">@apply bg-blue-500 text-white;</code>
                <p class="text-slate-300 mt-1">Menggabungkan utility class ke dalam CSS kustom</p>
            </div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- `@tailwind base` untuk reset CSS, `components` untuk plugin, `utilities` untuk class utama
- Urutan direktif penting: utilities harus setelah components
- `@apply` memungkinkan penggunaan utility class di dalam CSS kustom
