# Cara Mengintegrasikan Tailwind dengan Parcel

## Analogi: Perpustakaan Digital

Parcel seperti sistem perpustakaan otomatis yang bisa langsung digunakan tanpa konfigurasi. Begitu buku dimasukkan, sistem langsung mengkatalogkannya dengan sendirinya. Tidak perlu mengatur rak atau menulis aturan khusus - semuanya berjalan otomatis.

## Penjelasan Detail

Parcel adalah build tool zero-configuration yang sangat mudah digunakan. Integrasi Tailwind dengan Parcel sangat sederhana karena Parcel memiliki dukungan PostCSS bawaan. Cukup install Tailwind dan buat file `postcss.config.js` di root project. Install dengan `npm install -D tailwindcss postcss`, buat file konfigurasi Tailwind, lalu buat file `postcss.config.js` dengan plugin tailwindcss. Parcel akan otomatis mendeteksi PostCSS config dan memproses CSS melalui Tailwind. Kelebihan Parcel adalah kemudahan penggunaan - tidak perlu webpack.config.js atau vite.config.js yang rumit. Parcel juga memiliki fitur HMR, code splitting, dan image optimization yang terintegrasi. Sangat cocok untuk developer yang ingin setup cepat tanpa ribet.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tailwind + Parcel</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gradient-to-br from-emerald-50 to-teal-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8">
        <div class="flex items-center gap-3 mb-6">
            <div class="w-10 h-10 bg-emerald-600 rounded-lg flex items-center justify-center text-white font-bold text-lg">P</div>
            <h1 class="text-2xl font-bold text-gray-900">Tailwind + Parcel</h1>
        </div>
        <div class="bg-gray-900 rounded-xl p-4 font-mono text-sm space-y-1">
            <div class="text-green-400">$ npm init -y</div>
            <div class="text-green-400">$ npm install -D tailwindcss postcss</div>
            <div class="text-green-400">$ npx tailwindcss init</div>
            <div class="text-yellow-400 mt-2">// postcss.config.js</div>
            <div class="text-white">module.exports = {</div>
            <div class="text-white pl-4">plugins: {</div>
            <div class="text-white pl-8">tailwindcss: {},</div>
            <div class="text-white pl-8">autoprefixer: {},</div>
            <div class="text-white pl-4">},</div>
            <div class="text-white">}</div>
            <div class="text-green-400 mt-2">$ parcel src/index.html</div>
        </div>
        <p class="mt-4 text-sm text-gray-500">Zero config, Parcel otomatis mendeteksi PostCSS dan Tailwind.</p>
    </div>
</body>
</html>
```

## Poin Penting
- Parcel zero-config, otomatis mendeteksi PostCSS dan Tailwind
- Setup sangat sederhana: cukup install dan buat postcss.config.js
- Cocok untuk developer yang ingin memulai project dengan cepat
