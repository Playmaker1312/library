# Cara Menginstal Tailwind CLI untuk Digunakan Tanpa Bundler

## Analogi: Perpustakaan Digital

Tailwind CLI seperti petugas perpustakaan mandiri yang bisa bekerja tanpa perlu tim manajemen gedung (bundler). Anda cukup memberi perintah, dan dia akan menyusun buku-buku yang diperlukan tanpa perlu sistem katalog yang rumit.

## Penjelasan Detail

Tailwind CLI adalah standalone executable yang memungkinkan penggunaan Tailwind tanpa Node.js atau bundler sama sekali. Unduh binary dari GitHub releases sesuai sistem operasi, lalu jalankan langsung dari terminal. CLI mendukung perintah build dan watch dengan opsi kustomisasi. Contoh: `./tailwindcss -i input.css -o output.css --watch` untuk development mode. Keuntungan Tailwind CLI adalah kemandiriannya - tidak perlu package.json, node_modules, atau konfigurasi build tool. Cocok untuk project sederhana, static site generator, atau ketika ingin mengurangi kompleksitas toolchain. CLI juga mendukung file konfigurasi `tailwind.config.js` untuk kustomisasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tailwind CLI</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-lg p-8">
        <div class="flex items-center gap-3 mb-6">
            <div class="w-10 h-10 bg-blue-600 rounded-lg flex items-center justify-center">
                <span class="text-white font-bold text-lg">&gt;_</span>
            </div>
            <h1 class="text-2xl font-bold text-gray-900">Tailwind CLI</h1>
        </div>
        <div class="bg-gray-900 rounded-xl p-4 font-mono text-sm">
            <div class="text-green-400"># Download binary terbaru</div>
            <div class="text-white">$ curl -sLO https://github.com/tailwindlabs/tailwindcss/releases/latest/download/tailwindcss-x.x.x</div>
            <div class="text-green-400 mt-2"># Build CSS</div>
            <div class="text-white">$ ./tailwindcss -i input.css -o output.css</div>
            <div class="text-green-400 mt-2"># Watch mode</div>
            <div class="text-white">$ ./tailwindcss -i input.css -o output.css --watch</div>
        </div>
        <p class="mt-4 text-sm text-gray-500">Tidak perlu Node.js atau bundler. Satu file binary, langsung jalan.</p>
    </div>
</body>
</html>
```

## Poin Penting
- Binary standalone yang bisa jalan tanpa Node.js atau bundler
- Cocok untuk project sederhana dan static site generator
- Mendukung watch mode dan konfigurasi kustom
