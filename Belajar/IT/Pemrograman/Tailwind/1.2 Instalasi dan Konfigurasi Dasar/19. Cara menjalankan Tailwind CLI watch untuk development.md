# Cara Menjalankan Tailwind CLI Watch untuk Development

## Analogi: Perpustakaan Digital

Mode watch seperti memiliki petugas perpustakaan yang selalu berjaga 24 jam. Setiap kali ada buku baru yang ditambahkan atau diubah, petugas langsung memperbarui katalog dan menata ulang rak. Pengunjung selalu melihat versi terbaru tanpa perlu meminta pembaruan manual.

## Penjelasan Detail

`--watch` flag pada Tailwind CLI membuat Tailwind terus memantau file project untuk perubahan. Setiap kali file diubah, Tailwind langsung memproses ulang CSS dan menghasilkan output terbaru. Cara menjalankannya: `npx tailwindcss -i input.css -o output.css --watch` untuk project berbasis npm, atau `./tailwindcss -i input.css -o output.css --watch` untuk standalone CLI. Mode ini sangat penting untuk development karena memberikan feedback instan. Tailwind watch akan memantau file yang terdaftar di `content` dalam konfigurasi. Jika ada file baru yang perlu dipantau, tambahkan path-nya ke `content`. Mode ini juga mendukung `--poll` untuk filesystem yang tidak mendengar perubahan file secara native, seperti di beberapa Docker container.

## Poin Penting
- Mode watch memantau file dan membangun ulang CSS secara otomatis
- Feedback instan untuk development tanpa build manual
- Gunakan `--poll` untuk environment yang tidak mendukung file watching native
