# Cara Mengintegrasikan Tailwind dengan Vite

## Analogi: Perpustakaan Digital

Vite seperti sistem manajemen perpustakaan super cepat yang menggunakan teknologi modern. Saat pengunjung datang, buku langsung tersaji dalam hitungan detik. Saat ada perubahan, hanya halaman yang berubah yang diperbarui, bukan seluruh perpustakaan.

## Penjelasan Detail

Vite adalah build tool modern yang sangat cepat berkat native ESM dan Hot Module Replacement (HMR). Integrasi Tailwind dengan Vite sangat mudah. Buat project Vite dengan `npm create vite@latest`, install Tailwind dengan `npm install -D tailwindcss @tailwindcss/vite`, tambahkan plugin Tailwind di `vite.config.js`, lalu import Tailwind di file CSS utama. Vite akan otomatis memproses CSS dan melakukan HMR saat ada perubahan. Keunggulan integrasi ini: build time sangat cepat, HMR instan, konfigurasi minimal, dan dukungan penuh untuk PostCSS. Vite adalah pilihan utama untuk project baru yang menggunakan framework seperti React, Vue, atau Svelte dengan Tailwind.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tailwind + Vite</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gradient-to-br from-violet-50 to-fuchsia-50 p-8 min-h-screen flex items-center justify-center">
    <div class="max-w-lg w-full bg-white rounded-2xl shadow-xl p-8">
        <div class="flex items-center gap-3 mb-6">
            <div class="w-10 h-10 bg-purple-600 rounded-lg flex items-center justify-center text-white font-bold text-lg">V</div>
            <h1 class="text-2xl font-bold text-gray-900">Tailwind + Vite</h1>
        </div>
        <div class="bg-gray-900 rounded-xl p-4 font-mono text-sm space-y-1">
            <div class="text-green-400">$ npm create vite@latest my-project -- --template vanilla</div>
            <div class="text-green-400">$ cd my-project</div>
            <div class="text-green-400">$ npm install -D tailwindcss @tailwindcss/vite</div>
            <div class="text-yellow-400 mt-2">// vite.config.js</div>
            <div class="text-white">import { defineConfig } from 'vite'</div>
            <div class="text-white">import tailwindcss from '@tailwindcss/vite'</div>
            <div class="text-white">export default defineConfig({</div>
            <div class="text-white pl-4">plugins: [tailwindcss()],</div>
            <div class="text-white">})</div>
            <div class="text-yellow-400 mt-2">// style.css</div>
            <div class="text-white">@import "tailwindcss";</div>
        </div>
    </div>
</body>
</html>
```

## Poin Penting
- Integrasi sederhana dengan plugin `@tailwindcss/vite`
- Build super cepat dan HMR instan berkat teknologi Vite
- Pilihan utama untuk project baru dengan framework modern
