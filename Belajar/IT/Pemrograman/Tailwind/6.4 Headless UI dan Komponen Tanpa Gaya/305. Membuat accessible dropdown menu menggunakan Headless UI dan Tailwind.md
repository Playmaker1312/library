# Membuat accessible dropdown menu menggunakan Headless UI dan Tailwind

## Analogi: Perpustakaan Digital

Dropdown menu seperti rak buku tarik yang menyembunyikan kategori-kategori spesifik. Biasanya hanya label "Genre" yang terlihat. Saat diklik, rak menarik keluar dan menampilkan: Fiksi, Non-Fiksi, Referensi, Biografi. Pengguna bisa memilih dengan mouse, keyboard panah (↑ ↓), atau menekan Enter. Headless UI `Menu` menangani semua interaksi ini; Tailwind membuat rak tarik terlihat menarik dengan bayangan dan animasi.

## Penjelasan Detail

Headless UI `Menu` adalah komponen untuk dropdown menu yang accessible. Struktur: `Menu` (wrapper), `MenuButton` (trigger), `MenuItems` (container item), `MenuItem` (setiap opsi). `MenuButton` secara otomatis memiliki `aria-haspopup` dan `aria-expanded`. `MenuItems` memiliki `role="menu"` dan item-itemnya memiliki `role="menuitem"`. Keyboard navigation: Arrow Up/Down untuk navigasi, Enter/Space untuk memilih, Escape untuk menutup. Fokus kembali ke `MenuButton` setelah menu ditutup. Gunakan `Transition` untuk animasi. Styling item bisa bervariasi berdasarkan state `active` (hover/keyboard focus) dan `disabled`.

## Contoh Kode Implementasi

```jsx
import { Menu, Transition } from "@headlessui/react";
import { Fragment } from "react";

const menuItems = [
  { label: "Profile", icon: "👤" },
  { label: "Settings", icon: "⚙️" },
  { label: "Billing", icon: "💳" },
  { label: "Logout", icon: "🚪", disabled: false },
];

export default function DropdownMenu() {
  return (
    <Menu as="div" className="relative inline-block text-left">
      <MenuButton className="flex items-center gap-2 rounded-xl bg-white px-4 py-2.5 text-sm font-medium text-gray-700 shadow-sm ring-1 ring-gray-200 hover:bg-gray-50 focus:outline-none focus:ring-2 focus:ring-indigo-500">
        Akun Saya
        <svg className="size-4" fill="none" viewBox="0 0 24 24" stroke="currentColor">
          <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M19 9l-7 7-7-7" />
        </svg>
      </MenuButton>

      <Transition as={Fragment} enter="transition ease-out duration-150" enterFrom="transform opacity-0 scale-95" enterTo="transform opacity-100 scale-100" leave="transition ease-in duration-100" leaveFrom="transform opacity-100 scale-100" leaveTo="transform opacity-0 scale-95">
        <MenuItems className="absolute right-0 mt-2 w-56 origin-top-right rounded-xl bg-white shadow-xl ring-1 ring-black/5 focus:outline-none p-1.5">
          {menuItems.map((item) => (
            <MenuItem key={item.label} disabled={item.disabled}>
              {({ active }) => (
                <button className={`${active ? "bg-indigo-50 text-indigo-600" : "text-gray-700"} ${item.disabled ? "opacity-50 cursor-not-allowed" : ""} group flex w-full items-center gap-3 rounded-lg px-3 py-2 text-sm transition`}>
                  <span>{item.icon}</span>
                  {item.label}
                </button>
              )}
            </MenuItem>
          ))}
        </MenuItems>
      </Transition>
    </Menu>
  );
}
```

## Poin Penting

- `Menu` menyediakan keyboard navigation (panah, Enter, Escape) secara otomatis
- State `active` untuk styling hover/keyboard focus, `disabled` untuk item non-aktif
- Fokus kembali ke `MenuButton` setelah menu ditutup
