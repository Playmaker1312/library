# Membuat accessible modal menggunakan Headless UI dan Tailwind

## Analogi: Perpustakaan Digital

Modal seperti kotak khusus di perpustakaan yang muncul saat Anda membutuhkan informasi penting—seperti buku langka yang hanya dikeluarkan jika diminta. Kotak ini memiliki mekanisme keamanan (tidak bisa dibuka jika kondisi tidak tepat), fokus otomatis (cahaya menyorot ke kotak), dan bisa ditutup dengan tombol escape (seperti menekan tombol "kembalikan buku"). Headless UI `Dialog` menangani semua mekanisme ini; Tailwind membuat kotak itu terlihat indah.

## Penjelasan Detail

Headless UI `Dialog` menyediakan modal yang sepenuhnya accessible: focus trapping (fokus tidak bisa keluar dari modal), keyboard interaction (Escape untuk menutup), dan ARIA attributes (`role="dialog"`, `aria-modal`). Struktur dasar: `Dialog` (wrapper dengan open/close state), `DialogPanel` (konten modal), `DialogTitle` dan `DialogDescription` untuk screen reader. Gunakan `Transition` untuk animasi masuk/keluar. Backdrop (overlay) bisa dibuat dengan `div` terpisah yang dikontrol oleh `Transition`. Pastikan modal tidak memblokir konten penting selamanya—sertakan cara mudah untuk menutupnya (tombol close, klik backdrop, tekan Escape).

## Contoh Kode Implementasi

```jsx
import { Dialog, Transition } from "@headlessui/react";
import { Fragment, useState } from "react";

export default function Modal() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)} className="rounded-lg bg-indigo-600 px-4 py-2 text-white hover:bg-indigo-700">
        Buka Modal
      </button>

      <Transition appear show={isOpen} as={Fragment}>
        <Dialog as="div" className="relative z-50" onClose={() => setIsOpen(false)}>
          <Transition.Child as={Fragment} enter="ease-out duration-300" enterFrom="opacity-0" enterTo="opacity-100" leave="ease-in duration-200" leaveFrom="opacity-100" leaveTo="opacity-0">
            <div className="fixed inset-0 bg-black/40" />
          </Transition.Child>

          <div className="fixed inset-0 overflow-y-auto">
            <div className="flex min-h-full items-center justify-center p-4">
              <Transition.Child as={Fragment} enter="ease-out duration-300" enterFrom="opacity-0 scale-95" enterTo="opacity-100 scale-100" leave="ease-in duration-200" leaveFrom="opacity-100 scale-100" leaveTo="opacity-0 scale-95">
                <DialogPanel className="w-full max-w-md transform overflow-hidden rounded-2xl bg-white p-6 shadow-xl transition-all">
                  <DialogTitle as="h3" className="text-lg font-bold text-gray-900">
                    Konfirmasi
                  </DialogTitle>
                  <DialogDescription as="p" className="mt-2 text-sm text-gray-500">
                    Apakah Anda yakin ingin melanjutkan?
                  </DialogDescription>

                  <div className="mt-6 flex gap-3 justify-end">
                    <button onClick={() => setIsOpen(false)} className="rounded-lg border px-4 py-2 text-sm font-medium text-gray-700 hover:bg-gray-50">
                      Batal
                    </button>
                    <button onClick={() => setIsOpen(false)} className="rounded-lg bg-indigo-600 px-4 py-2 text-sm font-medium text-white hover:bg-indigo-700">
                      Konfirmasi
                    </button>
                  </div>
                </DialogPanel>
              </Transition.Child>
            </div>
          </div>
        </Dialog>
      </Transition>
    </>
  );
}
```

## Poin Penting

- `Dialog` Headless UI menangani focus trapping, Escape key, dan ARIA otomatis
- Gunakan `Transition` untuk animasi masuk/keluar yang halus
- `DialogTitle` dan `DialogDescription` penting untuk aksesibilitas screen reader
