# Memahami konsep headless component dan kegunaannya dengan Tailwind

## Analogi: Perpustakaan Digital

Headless component seperti kerangka rak buku tanpa cat dan label—ia memiliki struktur yang kokoh, mekanisme buka-tutup yang tepat, dan sistem pengunci yang aman, tetapi tidak memiliki warna atau dekorasi. Anda (developer) yang menentukan apakah rak itu akan berwarna biru, merah, atau kayu alami menggunakan Tailwind. Headless component menangani logika, aksesibilitas, dan perilaku; Tailwind menangani tampilan visual.

## Penjelasan Detail

Headless component adalah komponen yang menyediakan logika, state management, aksesibilitas (ARIA), dan perilaku keyboard navigation tanpa memberikan styling apapun. Contohnya: modal, dropdown, tabs, combobox, radio group. Dengan headless component, Anda mendapatkan perilaku yang benar secara aksesibilitas tanpa harus menulis logika kompleks dari nol. Tailwind kemudian digunakan untuk memberi styling pada struktur yang sudah disediakan oleh headless component. Kombinasi ini ideal karena headless component menangani hal-hal yang sulit (focus management, keyboard interaction, ARIA attributes) sementara Tailwind memberi fleksibilitas penuh dalam desain.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Konsep Headless Component</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans">
  <div class="max-w-md mx-auto space-y-4">
    <h1 class="text-2xl font-bold">Konsep Headless + Tailwind</h1>
    
    <!-- Ilustrasi: struktur tanpa style vs dengan style -->
    <div class="grid grid-cols-2 gap-4">
      <div class="border-2 border-dashed border-red-300 p-4 rounded-lg">
        <p class="text-sm font-semibold text-red-500">Headless (tanpa style)</p>
        <div class="space-y-2 mt-2 text-gray-400">
          <div class="p-2">Menu Item 1</div>
          <div class="p-2">Menu Item 2</div>
          <div class="p-2">Menu Item 3</div>
        </div>
      </div>

      <div class="border-2 border-solid border-green-300 p-4 rounded-lg">
        <p class="text-sm font-semibold text-green-500">+ Tailwind (dengan style)</p>
        <div class="space-y-1 mt-2">
          <div class="p-2 bg-blue-50 hover:bg-blue-100 rounded-lg cursor-pointer transition">Menu Item 1</div>
          <div class="p-2 bg-blue-50 hover:bg-blue-100 rounded-lg cursor-pointer transition">Menu Item 2</div>
          <div class="p-2 bg-blue-50 hover:bg-blue-100 rounded-lg cursor-pointer transition">Menu Item 3</div>
        </div>
      </div>
    </div>

    <!-- Contoh sederhana: disclosure (expand/collapse) tanpa JS -->
    <details class="group bg-white border rounded-xl overflow-hidden">
      <summary class="flex items-center justify-between p-4 cursor-pointer hover:bg-gray-50">
        <span class="font-medium">Klik untuk expand — logika HTML native</span>
        <span class="group-open:rotate-180 transition">▼</span>
      </summary>
      <div class="p-4 border-t bg-gray-50">
        <p class="text-gray-600">Ini adalah konten yang tersembunyi. Logika buka-tutup sudah native.</p>
      </div>
    </details>
  </div>
</body>
</html>
```

## Poin Penting

- Headless component menangani logika, aksesibilitas, dan keyboard navigation
- Tailwind menangani 100% tampilan visual tanpa mengganggu logika
- Kombinasi ideal: Headless UI untuk "otak," Tailwind untuk "wajah"
