# Membuat accessible combobox atau autocomplete menggunakan Headless UI dan Tailwind

## Analogi: Perpustakaan Digital

Combobox seperti mesin pencari buku di perpustakaan digital. Saat Anda mengetik "fik," mesin menampilkan saran: "Fiksi," "Fiksi Ilmiah," "Fiksi Fantasi." Anda bisa memilih dengan mouse, atau navigasi dengan keyboard, atau mengetik kata kunci yang lebih spesifik. Headless UI `Combobox` menangani logika pencarian dan aksesibilitas; Tailwind membuat kotak pencarian dan dropdown saran terlihat elegan.

## Penjelasan Detail

Headless UI `Combobox` menggabungkan fungsi input teks dengan listbox untuk autocomplete. Struktur: `Combobox` (wrapper dengan value dan onChange), `ComboboxInput` (input teks), `ComboboxButton` (tombol buka/tutup), `ComboboxOptions` (dropdown), `ComboboxOption` (setiap saran). Fitur: filter otomatis berdasarkan input, keyboard navigation, ARIA `combobox` pattern. State `active` untuk item yang difokus, `selected` untuk item yang dipilih. Mendukung multiple selection dengan prop `multiple`. Bisa dikombinasikan dengan `Transition` untuk animasi dropdown.

## Contoh Kode Implementasi

```jsx
import { Combobox, Transition } from "@headlessui/react";
import { Fragment, useState } from "react";

const books = [
  "Fiksi", "Fiksi Ilmiah", "Fiksi Fantasi", "Non-Fiksi",
  "Biografi", "Sejarah", "Sains", "Teknologi", "Seni",
];

export default function ComboboxExample() {
  const [selected, setSelected] = useState("");
  const [query, setQuery] = useState("");

  const filtered = query === "" ? books : books.filter((b) =>
    b.toLowerCase().includes(query.toLowerCase())
  );

  return (
    <Combobox value={selected} onChange={setSelected}>
      <div className="relative w-72">
        <div className="flex items-center rounded-xl bg-white shadow-sm ring-1 ring-gray-200 focus-within:ring-2 focus-within:ring-indigo-500">
          <ComboboxInput
            className="w-full rounded-xl bg-transparent px-4 py-2.5 text-sm focus:outline-none"
            placeholder="Cari kategori..."
            onChange={(e) => setQuery(e.target.value)}
            displayValue={(book) => book}
          />
          <ComboboxButton className="px-2 text-gray-400 hover:text-gray-600">
            ▼
          </ComboboxButton>
        </div>

        <Transition as={Fragment} leave="transition ease-in duration-100" leaveFrom="opacity-100" leaveTo="opacity-0" afterLeave={() => setQuery("")}>
          <ComboboxOptions className="absolute mt-1 w-full rounded-xl bg-white p-1.5 shadow-xl ring-1 ring-black/5 focus:outline-none z-10">
            {filtered.length === 0 && query !== "" ? (
              <div className="px-3 py-2 text-sm text-gray-500">Tidak ditemukan</div>
            ) : (
              filtered.map((book) => (
                <ComboboxOption key={book} value={book} className={({ active }) =>
                  `${active ? "bg-indigo-50 text-indigo-600" : "text-gray-700"} cursor-pointer select-none rounded-lg px-3 py-2 text-sm`
                }>
                  {({ selected, active }) => (
                    <span className="flex items-center gap-2">
                      {selected && <span className="text-indigo-600">✓</span>}
                      {book}
                    </span>
                  )}
                </ComboboxOption>
              ))
            )}
          </ComboboxOptions>
        </Transition>
      </div>
    </Combobox>
  );
}
```

## Poin Penting

- `Combobox` menggabungkan input teks dengan listbox untuk autocomplete
- Filter saran bisa dilakukan secara client-side atau server-side
- Keyboard navigation (Arrow, Enter, Escape) dan ARIA pattern otomatis
