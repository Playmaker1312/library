# Memahami alternatif Headless UI seperti Radix UI dan Ark UI bersama Tailwind

## Analogi: Perpustakaan Digital

Headless UI, Radix UI, dan Ark UI seperti tiga merek alat pustakawan yang berbeda. Headless UI sederhana dan mudah digunakan—cocok untuk perpustakaan kecil. Radix UI lebih komprehensif dengan banyak varian dan opsi kustomisasi—seperti peralatan profesional untuk perpustakaan besar. Ark UI adalah yang terbaru dengan pendekatan yang lebih modern dan fleksibel—seperti peralatan pintar dengan fitur AI. Semuanya bekerja dengan Tailwind yang sama—cat dan stiker yang Anda gunakan untuk menghias alat-alat tersebut.

## Penjelasan Detail

Radix UI (Primitives) adalah library headless component untuk React yang lebih ekstensif daripada Headless UI. Radix menyediakan komponen seperti `Dialog`, `Popover`, `Tooltip`, `DropdownMenu`, `Select`, `Slider`, `Toast`, dan banyak lagi dengan fokus kuat pada aksesibilitas dan keyboard navigation. Keunggulan Radix adalah dukungan untuk "as child" pattern dan styling yang sangat fleksibel. Ark UI adalah alternatif yang lebih baru dengan dukungan multi-framework (React, Vue, Solid) dan pendekatan "headless" yang menggunakan machine-state pattern. Ark UI menawarkan komponen yang sama dengan API yang lebih deklaratif. Pilihan antara Headless UI, Radix, atau Ark UI tergantung pada kebutuhan framework, kompleksitas komponen, dan preferensi API.

## Contoh Kode Implementasi

```jsx
// Radix UI — Dialog
import * as Dialog from "@radix-ui/react-dialog";

function RadixModal() {
  return (
    <Dialog.Root>
      <Dialog.Trigger className="rounded-lg bg-indigo-600 px-4 py-2 text-white">
        Buka Modal (Radix)
      </Dialog.Trigger>
      <Dialog.Portal>
        <Dialog.Overlay className="fixed inset-0 bg-black/40 data-[state=open]:animate-in" />
        <Dialog.Content className="fixed left-1/2 top-1/2 w-full max-w-md -translate-x-1/2 -translate-y-1/2 rounded-2xl bg-white p-6 shadow-xl data-[state=open]:animate-in">
          <Dialog.Title className="text-lg font-bold">Konfirmasi</Dialog.Title>
          <Dialog.Description className="mt-2 text-sm text-gray-500">
            Apakah Anda yakin?
          </Dialog.Description>
          <div className="mt-6 flex justify-end gap-3">
            <Dialog.Close className="rounded-lg border px-4 py-2 text-sm">Batal</Dialog.Close>
            <Dialog.Close className="rounded-lg bg-indigo-600 px-4 py-2 text-sm text-white">Ya</Dialog.Close>
          </div>
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
}
```

      <DialogDescription class="mt-2 text-sm text-gray-500">Apakah Anda yakin?</DialogDescription>

## Poin Penting

- Headless UI: sederhana, cocok untuk React/Vue, API mudah
- Radix UI: lebih komprehensif, React-only, ekosistem besar
- Ark UI: multi-framework, state machine pattern, modern dan fleksibel
