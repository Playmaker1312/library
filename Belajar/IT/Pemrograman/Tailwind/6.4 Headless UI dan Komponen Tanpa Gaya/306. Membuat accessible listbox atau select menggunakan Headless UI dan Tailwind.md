# Membuat accessible listbox atau select menggunakan Headless UI dan Tailwind

## Analogi: Perpustakaan Digital

Listbox seperti formulir pemilihan kategori buku yang lebih canggih dari select biasa. Bayangkan memilih genre buku dari daftar yang bisa difilter: Anda bisa mengetik "fik" dan daftar langsung menyaring ke "Fiksi" dan "Fiksi Ilmiah." Pengguna juga bisa menggunakan keyboard untuk navigasi. Headless UI `Listbox` menyediakan ini dengan aksesibilitas penuh; Tailwind membuat tampilannya konsisten dengan desain perpustakaan lainnya.

## Penjelasan Detail

Headless UI `Listbox` adalah komponen select yang dapat dikustomisasi sepenuhnya. Struktur: `Listbox` (wrapper dengan value dan onChange), `ListboxButton` (trigger), `ListboxOptions` (dropdown), `ListboxOption` (setiap opsi). Komponen ini secara otomatis memiliki ARIA attributes seperti `role="listbox"`, `aria-activedescendant`, dan `aria-selected`. Keyboard navigation: Arrow Up/Down, Home/End, Enter untuk memilih. Value yang dipilih bisa berupa string, number, atau object. Multiple selection didukung dengan `multiple` prop. `ListboxOptions` mendukung pencarian dengan keyboard (ketik huruf untuk lompat ke opsi).

## Contoh Kode Implementasi

```jsx
import { Listbox, Transition } from "@headlessui/react";
import { Fragment, useState } from "react";

const categories = [
  { id: 1, name: "Fiksi" },
  { id: 2, name: "Non-Fiksi" },
  { id: 3, name: "Referensi" },
  { id: 4, name: "Biografi" },
  { id: 5, name: "Sains" },
];

export default function ListboxSelect() {
  const [selected, setSelected] = useState(categories[0]);

  return (
    <Listbox value={selected} onChange={setSelected}>
      <div className="relative w-64">
        <ListboxButton className="flex w-full items-center justify-between rounded-xl bg-white px-4 py-2.5 text-sm shadow-sm ring-1 ring-gray-200 hover:ring-gray-300 focus:outline-none focus:ring-2 focus:ring-indigo-500">
          <span>{selected.name}</span>
          <svg className="size-4" fill="none" viewBox="0 0 24 24" stroke="currentColor">
            <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M19 9l-7 7-7-7" />
          </svg>
        </ListboxButton>

        <Transition as={Fragment} leave="transition ease-in duration-100" leaveFrom="opacity-100" leaveTo="opacity-0">
          <ListboxOptions className="absolute mt-1 w-full rounded-xl bg-white p-1.5 shadow-xl ring-1 ring-black/5 focus:outline-none z-10">
            {categories.map((category) => (
              <ListboxOption key={category.id} value={category} className={({ active, selected }) =>
                `${active ? "bg-indigo-50 text-indigo-600" : "text-gray-700"} ${selected ? "font-medium" : ""} cursor-pointer select-none rounded-lg px-3 py-2 text-sm`
              }>
                {({ selected }) => (
                  <span className="flex items-center gap-2">
                    {selected && <span className="text-indigo-600">✓</span>}
                    {category.name}
                  </span>
                )}
              </ListboxOption>
            ))}
          </ListboxOptions>
        </Transition>
      </div>
    </Listbox>
  );
}
```

## Poin Penting

- `Listbox` mendukung navigasi keyboard dan ARIA attributes otomatis
- Value bisa berupa string, number, atau object (tidak terbatas pada string)
- Dukung multiple selection dengan prop `multiple`
