# Membuat accessible radio group menggunakan Headless UI dan Tailwind

## Analogi: Perpustakaan Digital

Radio group seperti pilihan jenis keanggotaan perpustakaan: "Reguler," "Premium," atau "VIP." Pengguna hanya bisa memilih satu. Dengan radio group, setiap pilihan terlihat seperti kartu yang bisa diklik, bukan lingkaran kecil membosankan. Headless UI `RadioGroup` mengelola state pemilihan dan aksesibilitas (ARIA role "radiogroup"); Tailwind membuat setiap opsi tampak seperti kartu membership yang menarik.

## Penjelasan Detail

Headless UI `RadioGroup` menyediakan pilihan grup dengan single selection yang accessible. Struktur: `RadioGroup` (wrapper dengan value dan onChange), `RadioGroupLabel` (label grup), `RadioGroupOption` (setiap opsi). Komponen ini secara otomatis menambahkan `role="radiogroup"` dan `role="radio"`. Keyboard navigation: Arrow Up/Down atau Arrow Left/Right untuk berpindah opsi. State yang tersedia di setiap option: `checked`, `active` (focus), `disabled`. RadioGroup sangat cocok untuk form dengan opsi terbatas (3-7 pilihan) di mana setiap opsi perlu ditampilkan secara visual.

## Contoh Kode Implementasi

```jsx
import { RadioGroup } from "@headlessui/react";
import { useState } from "react";

const plans = [
  { name: "Reguler", desc: "Akses 10 buku/bulan", price: "Gratis" },
  { name: "Premium", desc: "Akses 50 buku/bulan", price: "Rp50.000" },
  { name: "VIP", desc: "Akses tak terbatas", price: "Rp150.000" },
];

export default function RadioGroupExample() {
  const [selected, setSelected] = useState(plans[0]);

  return (
    <RadioGroup value={selected} onChange={setSelected} className="space-y-3">
      <RadioGroupLabel className="text-lg font-bold text-gray-900">Pilih Paket</RadioGroupLabel>
      {plans.map((plan) => (
        <RadioGroupOption key={plan.name} value={plan} className={({ active, checked }) =>
          `${active ? "ring-2 ring-indigo-500" : ""} ${checked ? "bg-indigo-50 border-indigo-500" : "bg-white border-gray-200"} relative flex cursor-pointer rounded-xl border p-4 shadow-sm hover:border-indigo-300 focus:outline-none transition`
        }>
          {({ checked }) => (
            <div className="flex w-full items-center justify-between">
              <div className="flex items-center gap-3">
                <div className={`${checked ? "bg-indigo-600 border-indigo-600" : "border-gray-300"} flex size-5 items-center justify-center rounded-full border transition`}>
                  {checked && <div className="size-2 rounded-full bg-white" />}
                </div>
                <div>
                  <RadioGroup.Label as="p" className={`${checked ? "text-indigo-600" : "text-gray-900"} font-medium`}>
                    {plan.name}
                  </RadioGroup.Label>
                  <RadioGroup.Description as="span" className="text-sm text-gray-500">
                    {plan.desc}
                  </RadioGroup.Description>
                </div>
              </div>
              <span className="text-sm font-semibold text-gray-700">{plan.price}</span>
            </div>
          )}
        </RadioGroupOption>
      ))}
    </RadioGroup>
  );
}
```

## Poin Penting

- `RadioGroup` untuk single selection dengan tampilan yang bisa dikustomisasi
- Navigasi keyboard (Arrow Up/Down) dan ARIA attributes otomatis
- Setiap option memiliki state `checked`, `active`, `disabled` untuk styling
