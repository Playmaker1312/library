# Membuat accessible tabs menggunakan Headless UI dan Tailwind

## Analogi: Perpustakaan Digital

Tabs seperti rak buku dengan pembatas yang bisa digeser: "Semua Buku," "Fiksi," "Non-Fiksi," "Terbaru." Setiap tab menampilkan koleksi yang berbeda tanpa meninggalkan halaman. Headless UI `Tab` memastikan navigasi tab berfungsi dengan keyboard (Arrow Keys) dan memiliki label yang benar untuk screen reader. Tailwind membuat setiap tab terlihat seperti stiker kategori yang rapi.

## Penjelasan Detail

Headless UI `TabGroup` menyediakan tabs yang accessible dengan `role="tablist"`, `role="tab"`, dan `role="tabpanel"` secara otomatis. Struktur: `TabGroup` (wrapper), `TabList` (container tab), `Tab` (setiap tab trigger), `TabPanels` (container panel), `TabPanel` (konten setiap tab). Keyboard navigation: Arrow Left/Right untuk navigasi tab, Home/End untuk ke tab pertama/terakhir. Tab yang aktif memiliki `aria-selected="true"`. Panel yang sesuai memiliki `aria-labelledby` yang merujuk ke tab-nya. `TabGroup` mendukung `manual` keyboard activation (pengguna harus tekan Enter/Space untuk mengaktifkan) atau `automatic` default.

## Contoh Kode Implementasi

```jsx
import { Tab } from "@headlessui/react";

const categories = [
  { name: "Semua", content: "Semua buku dalam koleksi..." },
  { name: "Fiksi", content: "Novel, cerpen, dan karya fiksi..." },
  { name: "Non-Fiksi", content: "Biografi, sejarah, dan sains..." },
  { name: "Terbaru", content: "Buku-buku yang baru ditambahkan..." },
];

function classNames(...classes) {
  return classes.filter(Boolean).join(" ");
}

export default function TabsExample() {
  return (
    <TabGroup>
      <TabList className="flex gap-1 rounded-xl bg-gray-100 p-1">
        {categories.map(({ name }) => (
          <Tab key={name} className={({ selected }) =>
            classNames(
              "w-full rounded-lg py-2.5 text-sm font-medium leading-5 transition",
              selected
                ? "bg-white text-indigo-600 shadow-sm"
                : "text-gray-600 hover:bg-white/60 hover:text-gray-800"
            )
          }>
            {name}
          </Tab>
        ))}
      </TabList>
      <TabPanels className="mt-4">
        {categories.map(({ name, content }) => (
          <TabPanel key={name} className="rounded-xl bg-white p-6 shadow-sm ring-1 ring-gray-200">
            <h3 className="text-lg font-bold text-gray-900 mb-2">{name}</h3>
            <p className="text-gray-600">{content}</p>
          </TabPanel>
        ))}
      </TabPanels>
    </TabGroup>
  );
}
```

## Poin Penting

- `TabGroup` mengelola role ARIA (`tablist`, `tab`, `tabpanel`) secara otomatis
- Keyboard navigation: Arrow Left/Right untuk pindah tab
- Gunakan `manual` prop jika tab perlu diklik/di-Enter untuk aktivasi
