# Cara menginstal dan menggunakan Headless UI untuk React

## Analogi: Perpustakaan Digital

Memasang Headless UI untuk React seperti mendapatkan kotak peralatan pustakawan yang sudah berisi alat-alat penting: pencapit buku (dropdown), kaca pembesar (combobox), dan pembatas rak (tabs). Alat-alat ini sudah memiliki mekanisme yang tepat—Anda tinggal menghiasnya dengan stiker dan cat (Tailwind) sesuai selera perpustakaan Anda. Tidak perlu membuat alat dari nol, cukup gunakan yang sudah ada dan bungkus dengan tampilan yang Anda inginkan.

## Penjelasan Detail

Headless UI untuk React diinstal melalui npm: `npm install @headlessui/react @heroicons/react`. Library ini menyediakan komponen seperti `Menu` (dropdown), `Listbox` (select), `Combobox` (autocomplete), `Dialog` (modal), `Disclosure` (accordion), `Popover`, `RadioGroup`, `Switch`, `Tabs`, dan `Transition`. Setiap komponen menggunakan pattern "render props" atau "compound components" —Anda mendapatkan akses ke state (open, selected, active) dan kontrol penuh atas tampilan. Komponen Headless UI sudah memenuhi standar aksesibilitas WAI-ARIA secara otomatis: keyboard navigation, focus management, screen reader announcements. Cukup tambahkan class Tailwind untuk styling.

## Contoh Kode Implementasi

```jsx
import { Menu, Transition } from "@headlessui/react";
import { Fragment } from "react";

export default function MyDropdown() {
  return (
    <Menu as="div" className="relative inline-block text-left">
      <Menu.Button className="inline-flex items-center gap-2 rounded-lg bg-indigo-600 px-4 py-2 text-sm font-medium text-white hover:bg-indigo-700 focus:outline-none focus:ring-2 focus:ring-indigo-500">
        Options
        <svg className="size-4" fill="none" viewBox="0 0 24 24" stroke="currentColor">
          <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M19 9l-7 7-7-7" />
        </svg>
      </Menu.Button>

      <Transition
        as={Fragment}
        enter="transition ease-out duration-100"
        enterFrom="transform opacity-0 scale-95"
        enterTo="transform opacity-100 scale-100"
        leave="transition ease-in duration-75"
        leaveFrom="transform opacity-100 scale-100"
        leaveTo="transform opacity-0 scale-95"
      >
        <Menu.Items className="absolute right-0 mt-2 w-56 origin-top-right rounded-xl bg-white shadow-lg ring-1 ring-black/5 focus:outline-none p-1">
          <Menu.Item>
            {({ active }) => (
              <button className={`${active ? "bg-indigo-50 text-indigo-600" : "text-gray-700"} group flex w-full items-center gap-2 rounded-lg px-3 py-2 text-sm`}>
                Edit
              </button>
            )}
          </Menu.Item>
          <Menu.Item>
            {({ active }) => (
              <button className={`${active ? "bg-indigo-50 text-indigo-600" : "text-gray-700"} group flex w-full items-center gap-2 rounded-lg px-3 py-2 text-sm`}>
                Duplicate
              </button>
            )}
          </Menu.Item>
        </Menu.Items>
      </Transition>
    </Menu>
  );
}
```

## Poin Penting

- Install dengan `npm install @headlessui/react`
- Komponen menggunakan compound component pattern untuk kontrol penuh styling
- Aksesibilitas (WAI-ARIA) sudah terhandle otomatis oleh Headless UI
