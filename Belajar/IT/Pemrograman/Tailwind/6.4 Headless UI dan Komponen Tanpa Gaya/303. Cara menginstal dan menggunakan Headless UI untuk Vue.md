# Cara menginstal dan menggunakan Headless UI untuk Vue

## Analogi: Perpustakaan Digital

Headless UI untuk Vue seperti versi alat pustakawan yang dirancang khusus untuk sistem katalog Eropa (Vue). Alat-alatnya sama—pencapit buku, kaca pembesar, pembatas rak—tetapi cara menggunakannya sedikit berbeda karena sistem katalognya menggunakan slot dan directive ala Vue. Anda tetap menghias alat-alat ini dengan stiker Tailwind yang sama, tetapi logika penanganannya mengikuti filosofi Vue.

## Penjelasan Detail

Headless UI untuk Vue diinstal dengan `npm install @headlessui/vue`. Komponen-komponen yang tersedia sama dengan versi React: `Menu`, `Listbox`, `Combobox`, `Dialog`, `Disclosure`, `Popover`, `RadioGroup`, `Switch`, `Tabs`. Di Vue, komponen menggunakan slot scoped (v-slot) untuk memberikan akses ke state. Anda bisa menggunakan `v-model` untuk two-way binding pada komponen yang memiliki state seperti `Listbox` dan `Switch`. `Transition` dan `TransitionRoot` disediakan untuk animasi. Semua komponen sudah ARIA-compliant secara default. Vue 3 dengan Composition API didukung penuh.

## Contoh Kode Implementasi

```vue
<script setup>
import { ref } from "vue";
import { Menu, MenuButton, MenuItems, MenuItem } from "@headlessui/vue";

const items = ["Edit", "Duplicate", "Archive", "Delete"];
</script>

<template>
  <Menu as="div" class="relative inline-block text-left">
    <MenuButton class="inline-flex items-center gap-2 rounded-lg bg-indigo-600 px-4 py-2 text-sm font-medium text-white hover:bg-indigo-700 focus:outline-none focus:ring-2 focus:ring-indigo-500">
      Options
      <svg class="size-4" fill="none" viewBox="0 0 24 24" stroke="currentColor">
        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M19 9l-7 7-7-7" />
      </svg>
    </MenuButton>

    <transition enter-active-class="transition ease-out duration-100" enter-from-class="transform opacity-0 scale-95" enter-to-class="transform opacity-100 scale-100" leave-active-class="transition ease-in duration-75" leave-from-class="transform opacity-100 scale-100" leave-to-class="transform opacity-0 scale-95">
      <MenuItems class="absolute right-0 mt-2 w-56 origin-top-right rounded-xl bg-white shadow-lg ring-1 ring-black/5 focus:outline-none p-1">
        <MenuItem v-for="item in items" :key="item" v-slot="{ active }">
          <button :class="[active ? 'bg-indigo-50 text-indigo-600' : 'text-gray-700', 'group flex w-full items-center gap-2 rounded-lg px-3 py-2 text-sm']">
            {{ item }}
          </button>
        </MenuItem>
      </MenuItems>
    </transition>
  </Menu>
</template>
```

## Poin Penting

- Install dengan `npm install @headlessui/vue`
- Gunakan slot scoped (v-slot) untuk akses state komponen
- `v-model` untuk two-way binding pada Listbox, Switch, dll.
