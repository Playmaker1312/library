# Cara mendefinisikan design tokens dalam konfigurasi Tailwind

## Analogi: Perpustakaan Digital

Design tokens seperti daftar isi katalog perpustakaan yang baku. Setiap token adalah entri yang mendefinisikan satu aspek visual: "warna sampul adalah biru #3b82f6", "font judul adalah Inter", "jarak antar buku adalah 8px". Dengan Tailwind, daftar isi ini ditulis langsung di CSS menggunakan `@theme`. Begitu didefinisikan, Anda tinggal menyebut nama token-nya di HTML dan sistem akan menerapkannya secara konsisten.

## Penjelasan Detail

Di Tailwind v4, design tokens didefinisikan di dalam at-rule `@theme` sebagai properti CSS kustom. Formatnya adalah `--kategori-nama: nilai`. Kategori meliputi `color`, `font`, `spacing`, `radius`, `shadow`, `breakpoint`, dan `container`. Setiap token yang didefinisikan akan menghasilkan utility class yang sesuai: `--color-primary` menghasilkan `bg-primary`, `text-primary`, `border-primary`, dll. Token bisa merujuk ke token lain menggunakan `var()`. Untuk nilai yang bersifat tematik (misal light/dark mode), gunakan logical properties. Hindari mendefinisikan terlalu banyak variasi—cukup yang benar-benar dibutuhkan oleh desain.

## Contoh Kode Implementasi

```css
@import "tailwindcss";

@theme {
  /* Warna dengan semantik jelas */
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-danger: #dc2626;
  --color-success: #16a34a;
  --color-warning: #d97706;

  /* Warna netral untuk UI */
  --color-neutral-50: #f8fafc;
  --color-neutral-100: #f1f5f9;
  --color-neutral-200: #e2e8f0;
  --color-neutral-700: #334155;
  --color-neutral-800: #1e293b;
  --color-neutral-900: #0f172a;

  /* Spacing sistematis */
  --spacing-0: 0px;
  --spacing-1: 0.25rem;
  --spacing-2: 0.5rem;
  --spacing-3: 0.75rem;
  --spacing-4: 1rem;
  --spacing-6: 1.5rem;
  --spacing-8: 2rem;
  --spacing-12: 3rem;
  --spacing-16: 4rem;

  /* Typography scale */
  --font-sans: "Inter", ui-sans-serif, system-ui;
  --font-mono: "JetBrains Mono", monospace;

  /* Border radius sistematis */
  --radius-none: 0px;
  --radius-sm: 0.125rem;
  --radius-md: 0.375rem;
  --radius-lg: 0.5rem;
  --radius-xl: 0.75rem;
  --radius-2xl: 1rem;
  --radius-full: 9999px;

  /* Shadows */
  --shadow-sm: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1);
  --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1);
}
```

```html
<div class="bg-primary text-white px-4 py-2 rounded-lg shadow-md">
  Tombol dengan design tokens
</div>
```

## Poin Penting

- Tokens didefinisikan dengan `--kategori-nama: nilai` di dalam `@theme`
- Utility class (bg-*, text-*, dll.) otomatis tersedia dari tokens yang didefinisikan
- Batasi jumlah tokens pada nilai yang benar-benar dibutuhkan oleh desain
