# Cara membuat shadow dan border radius system yang konsisten

## Analogi: Perpustakaan Digital

Shadow dan border radius seperti desain fisik rak buku: sudut rak bisa tajam (radius kecil) atau tumpul (radius besar), dan bayangan bisa tipis atau tebal tergantung seberapa menonjol rak tersebut. Di perpustakaan yang terdesain baik, semua rak dengan fungsi yang sama memiliki sudut dan bayangan yang seragam. Ini membantu pengunjung (user) memahami hierarki visual—mana yang mengambang (card dengan shadow), mana yang menyatu dengan dinding (tanpa shadow).

## Penjelasan Detail

Border radius system biasanya memiliki 4-6 level: `none` (0), `sm` (2px), `md` (4px), `lg` (8px), `xl` (12px), `full` (lingkaran). Setiap level digunakan untuk konteks spesifik: `sm` untuk input fields, `md` untuk buttons, `lg` untuk cards, `xl` untuk modals. Shadow system memiliki 3-5 level: `sm` untuk elemen yang diangkat sedikit (tombol), `md` untuk card, `lg` untuk dropdown, `xl` untuk modal/dialog. Penting untuk tidak mencampur level secara acak—semua tombol harus punya radius yang sama, semua card harus punya level shadow yang sama. Dokumentasikan panduan penggunaan untuk setiap level.

## Contoh Kode Implementasi

```css
@import "tailwindcss";

@theme {
  /* Border Radius System */
  --radius-none: 0px;
  --radius-sm: 0.25rem;    /* 4px — input, badge */
  --radius-md: 0.375rem;   /* 6px — button */
  --radius-lg: 0.5rem;     /* 8px — card, alert */
  --radius-xl: 0.75rem;    /* 12px — modal, drawer */
  --radius-2xl: 1rem;      /* 16px — hero, special */
  --radius-full: 9999px;   /* circular — avatar, pill */

  /* Shadow System */
  --shadow-sm: 0 1px 2px 0 rgb(0 0 0 / 0.05);
  --shadow-md: 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1);
  --shadow-lg: 0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1);
  --shadow-xl: 0 20px 25px -5px rgb(0 0 0 / 0.1), 0 8px 10px -6px rgb(0 0 0 / 0.1);
  --shadow-2xl: 0 25px 50px -12px rgb(0 0 0 / 0.25);
}
```

## Poin Penting

- Batasi radius pada 4-6 level dengan konteks penggunaan yang jelas
- Shadow memiliki 3-5 level dari ringan (sm) hingga berat (2xl)
- Dokumentasikan konteks penggunaan setiap level untuk konsistensi tim
