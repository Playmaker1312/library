# Cara membuat spacing system yang konsisten menggunakan Tailwind

## Analogi: Perpustakaan Digital

Spacing system seperti grid lantai perpustakaan—setiap rak buku, lorong, dan meja baca memiliki jarak yang konsisten. Tidak ada celah 7px di satu tempat dan 12px di tempat lain. Tailwind menyediakan skala spacing matematis (biasanya kelipatan 4px) yang menjamin harmoni visual. Jika Anda memutuskan jarak antar rak adalah 16px, maka semua jarak—dari padding tombol hingga margin antar kartu—akan mengikuti aturan yang sama.

## Penjelasan Detail

Tailwind menggunakan skala spacing berbasis `rem` dengan faktor 4 secara default (0, 0.25rem/4px, 0.5rem/8px, 1rem/16px, dst). Untuk design system, Anda bisa mempertahankan skala ini atau menyesuaikannya. Prinsipnya: gunakan base unit yang konsisten (misal 4px) dan hanya gunakan nilai dalam skala tersebut. Jangan menambahkan nilai "satu-off" seperti `p-[13px]`—ini merusak konsistensi. Dalam konteks design system, spacing meliputi margin, padding, gap, dan dimensi (width/height). Tentukan skala maksimal yang diperlukan (biasanya 0-16 pada skala 4px) dan patuhi. Untuk layout yang kompleks, tambahkan nilai spesifik seperti `section` (padding antar section besar).

## Contoh Kode Implementasi

```css
@import "tailwindcss";

@theme {
  /* Base spacing scale: kelipatan 4px (0.25rem) */
  --spacing-0: 0px;
  --spacing-px: 1px;
  --spacing-0\.5: 0.125rem;  /* 2px */
  --spacing-1: 0.25rem;      /* 4px */
  --spacing-2: 0.5rem;       /* 8px */
  --spacing-3: 0.75rem;      /* 12px */
  --spacing-4: 1rem;         /* 16px */
  --spacing-5: 1.25rem;      /* 20px */
  --spacing-6: 1.5rem;       /* 24px */
  --spacing-8: 2rem;         /* 32px */
  --spacing-10: 2.5rem;      /* 40px */
  --spacing-12: 3rem;        /* 48px */
  --spacing-16: 4rem;        /* 64px */
  --spacing-20: 5rem;        /* 80px */
  --spacing-24: 6rem;        /* 96px */

  /* Semantic spacing tokens */
  --spacing-section: 5rem;
  --spacing-card-padding: 1.5rem;
  --spacing-element-gap: 0.75rem;
}
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Spacing System</title>
  <style>
    @import "tailwindcss";
    @theme {
      --spacing-card: 1.5rem;
      --spacing-section: 5rem;
    }
  </style>
</head>
<body class="font-sans">
  <section class="p-section space-y-6">
    <h1 class="text-2xl font-bold">Spacing System Konsisten</h1>
    <div class="flex gap-4">
      <div class="bg-blue-100 p-card rounded-lg flex-1">Card 1</div>
      <div class="bg-blue-100 p-card rounded-lg flex-1">Card 2</div>
    </div>
    <div class="flex flex-wrap gap-3">
      <button class="bg-primary text-white px-4 py-2 rounded-lg">Tombol</button>
      <button class="bg-primary text-white px-4 py-2 rounded-lg">Tombol</button>
    </div>
  </section>
</body>
</html>
```

## Poin Penting

- Gunakan skala spacing matematis (kelipatan 4px) untuk konsistensi visual
- Jangan gunakan nilai arbitrer seperti `p-[13px]` dalam design system
- Tambahkan semantic spacing tokens untuk nilai yang sering digunakan bersama
