# Cara mengintegrasikan design system Tailwind dengan tools desain seperti Figma

## Analogi: Perpustakaan Digital

Integrasi Tailwind dengan Figma seperti membuat peta perpustakaan digital yang langsung terhubung dengan rak fisik. Desainer menggambar tata letak di Figma menggunakan warna "Primary Blue" dan spacing "16px." Developer kemudian membangunnya di kode dengan `bg-primary` dan `p-4`—tanpa perlu konversi manual. Keduanya berbicara dalam bahasa yang sama: design tokens.

## Penjelasan Detail

Integrasi dimulai dengan mendefinisikan design tokens yang sama di Figma dan Tailwind. Gunakan plugin Figma seperti "Tailwind CSS" atau "Design Tokens" untuk menyinkronkan warna, spacing, typography, dan shadow. Alternatifnya, gunakan tools seperti Style Dictionary untuk mengelola tokens dari satu sumber (misal JSON) dan menghasilkan output untuk Figma (via plugin) dan Tailwind (via CSS). Pendekatan "single source of truth" memastikan ketika tokens berubah, baik desain maupun kode sinkron. Beberapa tim menggunakan Git-based workflow di mana perubahan di Figma menghasilkan PR ke repository kode, atau sebaliknya.

## Contoh Kode Implementasi

```json
/* tokens.json — single source of truth via Style Dictionary */
{
  "color": {
    "primary": { "value": "#6366f1" },
    "primary-hover": { "value": "#4f46e5" },
    "neutral-50": { "value": "#f8fafc" },
    "neutral-900": { "value": "#0f172a" }
  },
  "spacing": {
    "4": { "value": "1rem" },
    "card": { "value": "1.5rem" },
    "section": { "value": "5rem" }
  },
  "font": {
    "sans": { "value": "'Inter', sans-serif" }
  },
  "radius": {
    "button": { "value": "0.375rem" },
    "card": { "value": "0.5rem" }
  }
}
```

```css
/* Generated dari Style Dictionary — tailwind.css */
@import "tailwindcss";
@theme {
  --color-primary: #6366f1;
  --color-primary-hover: #4f46e5;
  --color-neutral-50: #f8fafc;
  --color-neutral-900: #0f172a;
  --spacing-4: 1rem;
  --spacing-card: 1.5rem;
  --spacing-section: 5rem;
  --font-sans: 'Inter', sans-serif;
  --radius-button: 0.375rem;
  --radius-card: 0.5rem;
}
```

```bash
# Install Style Dictionary
npm install -g style-dictionary

# Build tokens ke berbagai format (CSS, JS, Figma plugin)
style-dictionary build
```

## Poin Penting

- Gunakan "single source of truth" (Style Dictionary) untuk tokens yang sama di Figma dan kode
- Plugin Figma "Tailwind CSS" atau "Design Tokens" membantu sinkronisasi
- Workflow Git-based memastikan perubahan desain dan kode tetap sinkron
