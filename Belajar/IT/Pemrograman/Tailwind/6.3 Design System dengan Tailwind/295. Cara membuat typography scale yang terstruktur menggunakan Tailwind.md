# Cara membuat typography scale yang terstruktur menggunakan Tailwind

## Analogi: Perpustakaan Digital

Typography scale seperti hierarki ukuran buku di perpustakaan: ensiklopedia (heading 1) berukuran besar, buku referensi (heading 2) sedikit lebih kecil, buku saku (body text) standar, dan catatan kaki (small text) mungil. Tailwind menyediakan skala tipografi yang terstruktur sehingga setiap level teks memiliki ukuran, line-height, dan font-weight yang konsisten. Pembaca (user) bisa langsung mengenali mana yang penting hanya dari ukuran teksnya.

## Penjelasan Detail

Mulailah dengan menentukan type scale, biasanya menggunakan rasio modular seperti 1.25 (major third) atau 1.333 (perfect fourth). Tailwind menggunakan skala default berbasis rem yang mencakup dari `text-xs` (0.75rem) hingga `text-6xl` (3.75rem). Dalam design system, Anda bisa menambahkan level yang hilang atau menyesuaikan nilai yang ada. Setiap level harus memiliki definisi `font-size`, `line-height`, dan mungkin `letter-spacing` dan `font-weight`. Buat juga semantic tokens seperti `text-heading`, `text-body`, `text-caption` untuk penggunaan yang lebih intuitif. Pertimbangkan juga responsive typography—ukuran font yang berubah di breakpoint tertentu.

## Contoh Kode Implementasi

```css
@import "tailwindcss";

@theme {
  /* Type scale modular */
  --text-xs: 0.75rem;
  --text-xs--line-height: 1rem;
  --text-sm: 0.875rem;
  --text-sm--line-height: 1.25rem;
  --text-base: 1rem;
  --text-base--line-height: 1.5rem;
  --text-lg: 1.125rem;
  --text-lg--line-height: 1.75rem;
  --text-xl: 1.25rem;
  --text-xl--line-height: 1.75rem;
  --text-2xl: 1.5rem;
  --text-2xl--line-height: 2rem;
  --text-3xl: 1.875rem;
  --text-3xl--line-height: 2.25rem;
  --text-4xl: 2.25rem;
  --text-4xl--line-height: 2.5rem;
  --text-5xl: 3rem;
  --text-5xl--line-height: 1;
  --text-6xl: 3.75rem;
  --text-6xl--line-height: 1;

  /* Semantic typography tokens */
  --font-heading: "Inter", sans-serif;
  --font-body: "Inter", sans-serif;
  --font-mono: "JetBrains Mono", monospace;
}
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Typography Scale</title>
  <style>
    @import "tailwindcss";
  </style>
</head>
<body class="p-8 font-sans space-y-2">
  <h1 class="text-4xl font-bold tracking-tight">Heading 1 — Display</h1>
  <h2 class="text-3xl font-semibold">Heading 2 — Section Title</h2>
  <h3 class="text-2xl font-semibold">Heading 3 — Card Title</h3>
  <h4 class="text-xl font-medium">Heading 4 — Subsection</h4>
  <p class="text-base leading-relaxed">Body text — Paragraf standar untuk konten utama.</p>
  <p class="text-sm text-gray-500">Caption — Teks kecil untuk keterangan.</p>
  <p class="text-xs text-gray-400">Small — Detail teknis atau footnote.</p>
</body>
</html>
```

## Poin Penting

- Gunakan type scale dengan rasio modular (1.25 atau 1.333) untuk harmoni visual
- Setiap level harus memiliki font-size dan line-height yang konsisten
- Tambahkan semantic typography tokens untuk penggunaan yang lebih intuitif
