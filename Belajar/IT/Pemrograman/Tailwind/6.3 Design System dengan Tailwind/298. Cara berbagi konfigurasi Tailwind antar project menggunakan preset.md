# Cara berbagi konfigurasi Tailwind antar project menggunakan preset

## Analogi: Perpustakaan Digital

Preset Tailwind seperti cetak biru perpustakaan standar yang bisa digunakan di banyak cabang perpustakaan. Setiap cabang (project) mungkin punya sedikit perbedaan—rak khusus untuk koleksi lokal—tetapi struktur dasarnya sama: warna katalog, ukuran rak, dan font label seragam di semua cabang. Dengan preset, Anda mendefinisikan cetak biru sekali dan semua cabang tinggal mengimpornya.

## Penjelasan Detail

Di Tailwind v4, preset diimplementasikan sebagai package npm yang berisi file CSS dengan at-rule `@theme` dan kustomisasi lainnya. Buat package terpisah (misal `@company/tailwind-preset`) yang mengekspor konfigurasi CSS dasar. Di setiap project, Anda tinggal mengimpor preset tersebut di file CSS utama sebelum kustomisasi lokal. Preset bisa dirantai—preset global untuk semua project, lalu preset spesifik per produk. Pendekatan ini memastikan konsistensi di seluruh organisasi sambil tetap memberi fleksibilitas per project untuk menambahkan tokens spesifik. Perubahan pada preset akan otomatis tersedia di semua project setelah update package.

## Contoh Kode Implementasi

```css
/* @company/tailwind-preset/index.css */
@import "tailwindcss";

@theme {
  /* Brand global */
  --color-primary: #6366f1;
  --color-primary-hover: #4f46e5;
  --color-secondary: #f59e0b;
  --color-neutral-50: #f8fafc;
  --color-neutral-900: #0f172a;

  /* Typography global */
  --font-sans: "Inter", sans-serif;
  --font-mono: "JetBrains Mono", monospace;

  /* Spacing global */
  --spacing-section: 5rem;
  --spacing-card: 1.5rem;

  /* Radius global */
  --radius-button: 0.375rem;
  --radius-card: 0.5rem;
}
```

```css
/* Project A: styles.css — menggunakan preset */
@import "@company/tailwind-preset";

/* Override atau tambahan untuk Project A */
@theme {
  --color-primary: #2563eb; /* Project A menggunakan biru */
  --color-brand-accent: #7c3aed;
  --font-heading: "Poppins", sans-serif;
}
```

```bash
# Publikasi preset
cd packages/tailwind-preset
npm publish --access public

# Install di project
npm install @company/tailwind-preset
```

```css
/* Atau menggunakan npm package lokal */
@import "../packages/tailwind-preset/index.css";
```

## Poin Penting

- Preset adalah package npm berisi CSS dengan `@theme` yang bisa diimpor antar project
- Preset bisa dirantai (global → produk → project) untuk fleksibilitas
- Update preset otomatis tersinkronisasi ke semua project via update package
