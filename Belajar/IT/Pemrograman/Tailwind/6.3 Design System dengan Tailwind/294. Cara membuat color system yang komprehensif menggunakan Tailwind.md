# Cara membuat color system yang komprehensif menggunakan Tailwind

## Analogi: Perpustakaan Digital

Color system seperti kode warna pada sistem kategorisasi buku: merah untuk fiksi, biru untuk non-fiksi, hijau untuk referensi. Setiap warna memiliki variant lebih terang (subkategori) dan lebih gelap (edisi khusus). Tailwind memungkinkan Anda mendefinisikan palet warna lengkap dengan varian-variannya, memastikan bahwa setiap kali Anda menggunakan "biru" di perpustakaan, warnanya akan seragam—tidak ada biru yang sedikit berbeda di rak berbeda.

## Penjelasan Detail

Color system yang baik memiliki warna brand (primer, sekunder, aksen), warna netral (untuk teks, background, border), dan warna semantik (success, warning, danger, info). Setiap warna sebaiknya memiliki beberapa varian intensitas, biasanya 3-5 level (light, default, dark, darker). Tailwind memungkinkan definisi warna dengan format `--color-{nama}-{varian}`. Untuk konsistensi, gunakan pendekatan HSL atau oklch agar variasi intensitas lebih terkontrol. Pertimbangkan aksesibilitas: pastikan kontras antara teks dan background memenuhi standar WCAG 2.1 AA. Dokumentasikan juga penggunaan semantik dari setiap warna (misal: "primary digunakan untuk tombol aksi utama").

## Contoh Kode Implementasi

```css
@import "tailwindcss";

@theme {
  /* Brand colors */
  --color-brand-50: #eef2ff;
  --color-brand-100: #e0e7ff;
  --color-brand-200: #c7d2fe;
  --color-brand-500: #6366f1;
  --color-brand-600: #4f46e5;
  --color-brand-700: #4338ca;
  --color-brand-900: #312e81;

  /* Neutral palette */
  --color-neutral-50: #f8fafc;
  --color-neutral-100: #f1f5f9;
  --color-neutral-200: #e2e8f0;
  --color-neutral-400: #94a3b8;
  --color-neutral-600: #475569;
  --color-neutral-800: #1e293b;
  --color-neutral-900: #0f172a;

  /* Semantic colors */
  --color-success: #22c55e;
  --color-success-light: #bbf7d0;
  --color-warning: #f59e0b;
  --color-warning-light: #fde68a;
  --color-danger: #ef4444;
  --color-danger-light: #fecaca;
  --color-info: #3b82f6;
  --color-info-light: #bfdbfe;
}
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Color System</title>
  <style>
    @import "tailwindcss";
    @theme {
      --color-primary: #6366f1;
      --color-primary-light: #a5b4fc;
      --color-primary-dark: #4f46e5;
      --color-danger: #ef4444;
      --color-success: #22c55e;
    }
  </style>
</head>
<body class="p-8 font-sans space-y-4">
  <div class="bg-primary text-white p-4 rounded-lg">Primary Brand</div>
  <div class="bg-primary-light text-primary-dark p-4 rounded-lg">Primary Light</div>
  <div class="bg-success text-white p-4 rounded-lg">Success</div>
  <div class="bg-danger text-white p-4 rounded-lg">Danger</div>
  <button class="bg-primary hover:bg-primary-dark text-white px-4 py-2 rounded-lg transition">
    Tombol dengan state
  </button>
</body>
</html>
```

## Poin Penting

- Definisikan warna brand, netral, dan semantik dengan varian intensitas yang konsisten
- Pastikan kontras warna memenuhi standar aksesibilitas WCAG AA
- Dokumentasikan penggunaan semantik setiap warna untuk konsistensi tim
