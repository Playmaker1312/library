# Cara mendokumentasikan design system berbasis Tailwind

## Analogi: Perpustakaan Digital

Dokumentasi design system seperti peta perpustakaan dan buku panduan untuk pustakawan baru. Peta menunjukkan di mana setiap kategori buku ditempatkan (layout), sementara panduan menjelaskan aturan katalogisasi (design tokens). Tanpa dokumentasi, setiap pustakawan mungkin mengatur ulang buku sesuai seleranya masing-masing—kekacauan pun terjadi. Dokumentasi memastikan semua orang mengikuti aturan yang sama.

## Penjelasan Detail

Dokumentasi design system berbasis Tailwind bisa dimulai dengan membuat halaman referensi yang menampilkan semua design tokens: warna, typography, spacing, shadow, border radius. Gunakan Storybook, PatternLab, atau alat serupa untuk menampilkan komponen secara interaktif. Setiap token dan komponen harus memiliki: nama, nilai CSS, contoh visual, dan panduan penggunaan. Dokumentasi juga harus mencakup aturan penggunaan—kapan menggunakan `primary` vs `secondary`, kapan menggunakan `shadow-md` vs `shadow-lg`. Integrasikan dokumentasi dengan workflow development: buat halaman dokumentasi statis dalam project itu sendiri atau gunakan tools seperti Fractal. Pastikan dokumentasi selalu sinkron dengan kode—gunakan pendekatan "docs as code."

```html
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Design System Documentation</title>
  <style>

    @theme {
      --color-primary: #6366f1;
      --color-secondary: #f59e0b;
    }
  </style>
</head>
<body class="p-8 font-sans max-w-4xl mx-auto">
  <header class="mb-8">
    <h1 class="text-3xl font-bold">Design System — Tailwind</h1>
    <p class="text-gray-600">Versi 1.0 — Diperbarui 24 Mei 2026</p>
  </header>

  <!-- Color Tokens -->
  <section class="mb-8">
    <h2 class="text-2xl font-bold mb-4">Color Tokens</h2>
    <div class="grid grid-cols-3 gap-4">
      <div class="bg-primary text-white p-4 rounded-lg">
        <div class="font-bold">Primary</div>
        <div class="text-sm opacity-80">#6366f1</div>
        <div class="text-xs mt-1">Tombol CTA, Link aktif</div>
      </div>
      <div class="bg-secondary text-white p-4 rounded-lg">

        <div class="text-sm opacity-80">#f59e0b</div>

      </div>
    </div>

  <!-- Spacing Tokens -->

  </section>

  <!-- Component Preview -->
  <section>
    <h2 class="text-2xl font-bold mb-4">Components</h2>
    <div class="flex gap-4">
      <button class="bg-primary text-white px-4 py-2 rounded-lg">Button Primary</button>
      <button class="border border-primary text-primary px-4 py-2 rounded-lg">Button Outline</button>
    </div>
  </section>

```

## Poin Penting

- Dokumentasikan setiap token dengan nama, nilai, contoh visual, dan panduan penggunaan
- Gunakan Storybook atau halaman dokumentasi statis dalam project
- Jaga agar dokumentasi selalu sinkron dengan kode ("docs as code")
