# Width, Height & Sizing

## Penjelasan
- `w-*`: lebar tetap (w-4 = 16px, w-64 = 256px), persen (w-1/2 = 50%, w-full = 100%), viewport (w-screen = 100vw)
- `h-*`: tinggi tetap (h-4, h-64), persen (h-1/2, h-full), viewport (h-screen = 100vh)
- `min-w-*`: lebar minimal (`min-w-0`, `min-w-full`, `min-w-max`, `min-w-min`)
- `max-w-*`: lebar maksimal (`max-w-md`, `max-w-4xl`, `max-w-7xl`)
- `min-h-*`: tinggi minimal (`min-h-screen` sangat umum untuk layout full page)
- `max-h-*`: tinggi maksimal (`max-h-64`, `max-h-screen`)
- `aspect-*`: rasio aspek (`aspect-square` = 1:1, `aspect-video` = 16:9, `aspect-auto`)
- `object-fit`: cara gambar menyesuaikan container (`object-contain`, `object-cover`, `object-fill`, `object-none`, `object-scale-down`)
- `object-position`: posisi gambar dalam container (`object-center`, `object-top`, `object-left`, dll)
- `size-*`: shorthand untuk width + height sekaligus (`size-6` = w-6 + h-6), tersedia Tailwind v3.4+

## Fungsi
Mengontrol dimensi elemen (lebar, tinggi, rasio aspek, dan bagaimana konten visual mengisi ruang) untuk menciptakan layout yang presisi.

## Cara Pengimplementasian / Kode

```html
<!-- Berbagai cara mengatur lebar -->
<div class="bg-gray-100 p-6 rounded-lg space-y-4">
  <!-- w-1/2: setengah lebar parent -->
  <div class="w-1/2 bg-blue-500 text-white p-3 rounded">w-1/2 (50%)</div>
  <!-- w-64: lebar tetap 256px -->
  <div class="w-64 bg-blue-500 text-white p-3 rounded">w-64 (256px)</div>
  <!-- w-full: lebar penuh -->
  <div class="w-full bg-blue-500 text-white p-3 rounded">w-full (100%)</div>
  <!-- w-3/4: tiga perempat -->
  <div class="w-3/4 bg-blue-500 text-white p-3 rounded">w-3/4 (75%)</div>
</div>

<!-- min-h-screen: full page layout -->
<div class="min-h-screen bg-gray-50 flex flex-col">
  <header class="bg-blue-600 text-white p-4">Header</header>
  <main class="flex-1 p-6">Konten utama mengisi sisa ruang</main>
  <footer class="bg-gray-800 text-white p-4">Footer selalu di bawah</footer>
</div>

<!-- aspect-*: menjaga rasio gambar -->
<div class="max-w-6xl mx-auto p-6 space-y-8">
  <!-- aspect-video: 16:9 -->
  <div class="aspect-video bg-gray-300 rounded-lg flex items-center justify-center text-gray-600">
    Video Placeholder (16:9)
  </div>

  <!-- aspect-square: 1:1 -->
  <div class="w-48 aspect-square bg-purple-500 rounded-lg flex items-center justify-center text-white">
    Kotak
  </div>

  <!-- Grid dengan aspect-3/4 -->
  <div class="grid grid-cols-4 gap-4">
    <div class="aspect-[3/4] bg-green-400 rounded-lg"></div>
    <div class="aspect-[3/4] bg-green-400 rounded-lg"></div>
    <div class="aspect-[3/4] bg-green-400 rounded-lg"></div>
    <div class="aspect-[3/4] bg-green-400 rounded-lg"></div>
  </div>
</div>

<!-- object-cover: gambar memotong mengisi container -->
<div class="flex gap-6 p-6 bg-gray-100 rounded-lg">
  <div class="w-48 h-48 overflow-hidden rounded-lg">
    <img src="https://placehold.co/600x400" alt="object-cover"
         class="w-full h-full object-cover object-center">
  </div>
  <div class="w-48 h-48 overflow-hidden rounded-lg">
    <img src="https://placehold.co/600x400" alt="object-contain"
         class="w-full h-full object-contain bg-gray-200">
  </div>
  <div class="w-48 h-48 overflow-hidden rounded-lg bg-gray-200">
    <img src="https://placehold.co/600x400" alt="object-cover-top"
         class="w-full h-full object-cover object-top">
  </div>
</div>

<!-- size-*: shortcut width + height -->
<div class="flex gap-4 p-6">
  <div class="size-16 bg-red-500 rounded-full flex items-center justify-center text-white">64px</div>
  <div class="size-24 bg-red-500 rounded-full flex items-center justify-center text-white">96px</div>
  <div class="size-12 bg-red-500 rounded-full flex items-center justify-center text-white">48px</div>
</div>
```

## Analogi
`w-*` dan `h-*` seperti **ukuran denah bangunan** -- seberapa lebar dan tinggi suatu ruangan. `min-h-screen` seperti **aturan tinggi minimal bangunan** -- halaman harus setinggi minimal satu layar. `aspect-video` seperti **TV dengan rasio layar 16:9** -- berapapun ukurannya, proporsinya tetap. `object-cover` seperti **memotong foto agar pas di bingkai** -- sebagian foto mungkin terpotong tapi bingkai terisi penuh. `object-contain` seperti **meletakkan foto utuh di dalam bingkai** -- Foto utuh terlihat tapi mungkin ada ruang kosong.

## Dipakai untuk Apa
- Full-height layout (`min-h-screen`)
- Thumbnail gambar dengan rasio konsisten (`aspect-square`, `aspect-video`)
- Avatar profil (`size-10`, `size-16`)
- Banner hero dengan gambar full width
- Gallery dengan ukuran seragam
- Card dengan tinggi yang bervariasi tetap rapi (pakai `h-full` atau grid)

## Kesalahan Umum yang Sering Terjadi
- Tidak memberi `overflow-hidden` pada parent saat menggunakan `object-cover`, menyebabkan gambar keluar dari container
- Mengira `h-screen` sama dengan `min-h-screen` (`h-screen` memaksa setinggi viewport, `min-h-screen` minimal setinggi viewport)
- Menggunakan `w-full` dan `h-full` tanpa parent yang memiliki ukuran pasti
- Tidak menggunakan `aspect-*` untuk gambar, sehingga gambar pecah saat container di-resize
- Mengatur `w-1/2` pada flex item yang juga punya `flex-1`, terjadi konflik
- Lupa bahwa `size-*` baru ada di Tailwind v3.4+, tidak kompatibel dengan versi lama

## Koneksi dengan Materi Sebelumnya
Sebelumnya kita belajar container dan max-width untuk lebar halaman. Sekarang kita belajar mengatur lebar dan tinggi elemen individual, termasuk rasio aspek. Ini penting untuk gambar, video, avatar, dan elemen visual lainnya. Kombinasi sizing + flexbox/grid + container adalah fondasi layout profesional.

## Soal Latihan
Buat sebuah card profil dengan:
1. Avatar berbentuk lingkaran menggunakan `size-*` (atau w + h)
2. Foto cover dengan aspect-video dan object-cover
3. Card dengan lebar tetap `max-w-sm`
4. Gunakan `min-h-screen` untuk layout full page
5. Grid gallery 3 kolom dengan aspect-square dan object-cover
