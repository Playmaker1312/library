# Container & Max-Width

## Penjelasan
- `container` class: elemen yang lebarnya menyesuaikan breakpoint Tailwind secara otomatis
  - sm: 640px, md: 768px, lg: 1024px, xl: 1280px, 2xl: 1536px
  - Di bawah breakpoint, `container` melebar penuh (100%)
  - Di breakpoint tertentu, `container` berhenti di lebar tetap
- `container-center`: `container` + `mx-auto` (terpusat), tersedia di Tailwind v3.4+
- `max-w-*`: batas lebar maksimum elemen
  - `max-w-sm` (384px), `max-w-md` (448px), `max-w-lg` (512px), `max-w-xl` (576px)
  - `max-w-2xl` (672px), `max-w-4xl` (896px), `max-w-6xl` (1152px), `max-w-7xl` (1280px)
  - `max-w-full`, `max-w-max`, `max-w-min`, `max-w-fit`
- `mx-auto` + `max-w-*`: pola standar **section wrapper** yang konsisten
- `w-full`: lebar 100% untuk memastikan elemen mengisi parent

## Fungsi
Membatasi lebar konten pada layar lebar agar tetap terbaca dan tidak melar terlalu jauh, serta menciptakan struktur layout yang konsisten di seluruh halaman.

## Cara Pengimplementasian / Kode

```html
<!-- Container class -->
<div class="container mx-auto bg-gray-100 p-4 rounded-lg">
  <p class="text-gray-700">
    Container ini akan melebar penuh di layar kecil, lalu berhenti di lebar
    640px (sm), 768px (md), 1024px (lg), dst.
  </p>
</div>

<!-- max-w-* dengan mx-auto: pola paling umum -->
<div class="max-w-6xl mx-auto bg-white p-6 rounded-lg shadow-md mt-8">
  <h1 class="text-3xl font-bold text-gray-800">Artikel Utama</h1>
  <p class="text-gray-600 mt-4">
    Konten artikel dengan lebar maksimal 1152px. Di layar kecil, konten
    tetap penuh karena kita tidak memberi padding horizontal di parent.
  </p>
</div>

<!-- max-w-* + padding agar tidak menempel di tepi -->
<div class="max-w-4xl mx-auto px-4 sm:px-6 lg:px-8 mt-8">
  <div class="bg-white p-6 rounded-lg shadow-md">
    <h2 class="text-xl font-bold">Section dengan Padding Responsif</h2>
    <p class="text-gray-600 mt-2">
      Padding kiri-kanan menyesuaikan layar: kecil 16px, sedang 24px, besar 32px.
    </p>
  </div>
</div>

<!-- Container dengan child grid -->
<div class="container mx-auto px-4 mt-8">
  <h2 class="text-2xl font-bold mb-6">Produk Terbaru</h2>
  <div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-6">
    <div class="bg-white p-4 rounded-lg shadow">Produk 1</div>
    <div class="bg-white p-4 rounded-lg shadow">Produk 2</div>
    <div class="bg-white p-4 rounded-lg shadow">Produk 3</div>
    <div class="bg-white p-4 rounded-lg shadow">Produk 4</div>
  </div>
</div>

<!-- max-w berbeda untuk tiap section -->
<div class="mt-8">
  <!-- Hero section: lebar penuh dengan background -->
  <section class="bg-blue-600 text-white">
    <div class="max-w-6xl mx-auto px-4 py-16 text-center">
      <h1 class="text-4xl font-bold">Hero Section</h1>
      <p class="mt-4">Lebar konten dibatasi 6xl, background penuh</p>
    </div>
  </section>

  <!-- Konten sempit untuk readability -->
  <section class="bg-white">
    <div class="max-w-2xl mx-auto px-4 py-12">
      <h2 class="text-2xl font-bold">Artikel Bacaan</h2>
      <p class="text-gray-600 mt-4 leading-relaxed">
        Konten teks dibatasi max-w-2xl agar mudah dibaca. Ideal untuk artikel
        karena lebar baris tidak terlalu panjang.
      </p>
    </div>
  </section>
</div>
```

## Analogi
`max-w-*` seperti **menentukan seberapa lebar bangunan yang dibangun**. Di lahan sempit (HP), bangunan memenuhi seluruh lahan. Di lahan luas (desktop), Anda batasi bangunan agar tidak terlalu melebar dan tetap nyaman dilihat. `mx-auto` seperti **menempatkan bangunan di tengah-tengah lahan**. `container` seperti **aturan pemerintah yang menentukan lebar maksimal bangunan** untuk setiap tipe zona (sm, md, lg, xl, 2xl). Pola `max-w-6xl mx-auto px-4` adalah **pondasi standar** untuk setiap section.

## Dipakai untuk Apa
- Layout halaman penuh dengan konten terpusat
- Artikel blog dengan lebar baca optimal (max-w-2xl)
- Halaman dashboard dengan lebar penuh
- Landing page dengan berbagai section yang konsisten
- Auth page (login/register) dengan form sempit (max-w-md)
- Memastikan website tidak terlihat terlalu melar di monitor lebar

## Kesalahan Umum yang Sering Terjadi
- Menggunakan `container` tanpa `mx-auto`, sehingga tidak terpusat
- Lupa menambah `px-4` pada container, sehingga konten menempel di tepi layar saat < breakpoint
- Menggunakan `container` di dalam `max-w-*` (nested), menyebabkan konflik lebar
- Tidak konsisten menggunakan `max-w-*` antar section, menyebabkan layout terlihat tidak rapi
- Mengira `container` otomatis memberikan padding (tidak, hanya mengatur lebar)
- Menggunakan `w-full` yang tidak perlu karena `max-w-*` + `mx-auto` sudah cukup

## Koneksi dengan Materi Sebelumnya
Sebelumnya kita belajar grid yang bisa membuat layout kolom. Container adalah "pembungkus" yang memastikan grid dan konten lain tidak melar terlalu lebar. Pola `max-w-* mx-auto px-4` akan menjadi pattern yang dipakai di **setiap section** website setelah ini. Ini juga persiapan untuk responsive design yang akan dipelajari selanjutnya.

## Soal Latihan
Buat halaman sederhana dengan:
1. Header dengan `container mx-auto px-4`, background biru, teks putih
2. Hero section dengan `max-w-4xl mx-auto px-4`, teks di tengah
3. Section produk dengan grid 3 kolom, `max-w-6xl mx-auto px-4`
4. Footer dengan `container mx-auto px-4`, background gelap
5. Pastikan setiap section memiliki padding vertikal yang konsisten (py-12 atau py-16)
