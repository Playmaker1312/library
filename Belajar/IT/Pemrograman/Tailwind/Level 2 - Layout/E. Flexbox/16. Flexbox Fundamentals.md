# Flexbox Fundamentals

## Penjelasan
- `flex`: mengubah elemen menjadi flex container, child secara default berjejer horizontal
- `flex-row` (default): child berjejer kiri ke kanan
- `flex-col`: child bertumpuk vertikal (atas ke bawah)
- `flex-row-reverse`: child berjejer kanan ke kiri
- `flex-col-reverse`: child bertumpuk bawah ke atas
- `flex-wrap`: child turun ke baris baru jika tidak cukup ruang
- `flex-nowrap` (default): child dipaksa dalam satu baris, bisa overflow
- `flex-wrap-reverse`: child wrap ke baris baru di arah sebaliknya
- Property penting: child dalam flex container otomatis menjadi flex items

## Fungsi
Membuat layout satu dimensi (baris atau kolom) yang fleksibel, di mana child dapat mengatur posisi, ukuran, dan wrapping secara otomatis.

## Cara Pengimplementasian / Kode

```html
<!-- flex-row (default): berjejer horizontal -->
<div class="flex bg-gray-100 p-4 rounded-lg space-x-4">
  <div class="bg-blue-500 text-white p-4 rounded">Item 1</div>
  <div class="bg-blue-500 text-white p-4 rounded">Item 2</div>
  <div class="bg-blue-500 text-white p-4 rounded">Item 3</div>
</div>

<!-- flex-col: bertumpuk vertikal -->
<div class="flex flex-col bg-gray-100 p-4 rounded-lg space-y-4 mt-8">
  <div class="bg-green-500 text-white p-4 rounded">Item Atas</div>
  <div class="bg-green-500 text-white p-4 rounded">Item Tengah</div>
  <div class="bg-green-500 text-white p-4 rounded">Item Bawah</div>
</div>

<!-- flex-wrap: item turun baris jika penuh -->
<div class="flex flex-wrap bg-gray-100 p-4 rounded-lg gap-4 mt-8">
  <div class="bg-purple-500 text-white p-4 rounded w-40">Item 1</div>
  <div class="bg-purple-500 text-white p-4 rounded w-40">Item 2</div>
  <div class="bg-purple-500 text-white p-4 rounded w-40">Item 3</div>
  <div class="bg-purple-500 text-white p-4 rounded w-40">Item 4</div>
  <div class="bg-purple-500 text-white p-4 rounded w-40">Item 5</div>
</div>

<!-- flex-row-reverse: urutan kebalik -->
<div class="flex flex-row-reverse bg-gray-100 p-4 rounded-lg space-x-4 space-x-reverse mt-8">
  <div class="bg-red-500 text-white p-4 rounded">Pertama (tampil paling kanan)</div>
  <div class="bg-red-500 text-white p-4 rounded">Kedua</div>
  <div class="bg-red-500 text-white p-4 rounded">Ketiga (tampil paling kiri)</div>
</div>

<!-- Kombinasi flex-col + h-screen untuk full page layout -->
<div class="flex flex-col h-screen">
  <header class="bg-blue-600 text-white p-4">Header</header>
  <main class="flex-1 bg-gray-50 p-6">Konten Utama</main>
  <footer class="bg-gray-800 text-white p-4">Footer</footer>
</div>
```

## Analogi
Flexbox seperti **rak buku yang bisa diatur**. Anda bisa memilih apakah buku-buku diletakkan **mendatar** (`flex-row`) atau **ditumpuk vertikal** (`flex-col`). Jika rak tidak cukup panjang, Anda bisa mengaktifkan mode **wrap** sehingga buku turun ke rak baris berikutnya (`flex-wrap`). `flex-reverse` seperti meletakkan buku dari kanan ke kiri.

## Dipakai untuk Apa
- Navigasi bar horizontal
- Layout header-content-footer
- Gallery gambar dengan wrapping otomatis
- Kartu produk yang rapi dalam satu baris
- Form dengan label di atas dan input di bawah (flex-col)
- Sidebar + konten utama

## Kesalahan Umum yang Sering Terjadi
- Lupa menambahkan `flex` di parent, lalu bingung kenapa `flex-col` tidak bekerja
- Tidak menggunakan `flex-wrap` untuk konten dinamis, menyebabkan item overflow atau mengecil sendiri
- Mengira `flex-row-reverse` hanya membalik visual tapi tidak mengubah arah margin/space (perlu `space-x-reverse`)
- Menaruh `space-*` di parent tapi lupa menambahkan `flex` pada parent
- Menggunakan flex untuk layout 2 dimensi yang kompleks (lebih cocok grid)

## Koneksi dengan Materi Sebelumnya
Sebelumnya kita belajar spacing system (padding, margin, space-x/y). Flexbox adalah cara untuk mengatur **posisi** elemen dalam satu baris atau kolom -- bukan hanya jaraknya. Kombinasi antara spacing dan flexbox sudah cukup untuk membuat sebagian besar layout website modern. Ini adalah gerbang menuju pemahaman layout yang lebih kompleks, termasuk grid.

## Soal Latihan
Buat sebuah kartu profil yang terdiri dari:
1. Flex container horizontal dengan foto (lingkaran) di kiri dan teks di kanan
2. Di dalam bagian teks, gunakan flex-col agar nama, jabatan, dan deskripsi bertumpuk
3. Tambahkan 3 tombol aksi yang menggunakan flex dengan wrap
4. Gunakan gap atau space untuk jarak
