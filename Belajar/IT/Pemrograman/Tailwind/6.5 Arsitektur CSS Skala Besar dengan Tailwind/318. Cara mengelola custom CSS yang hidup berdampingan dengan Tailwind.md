# Cara mengelola custom CSS yang hidup berdampingan dengan Tailwind

## Analogi: Perpustakaan Digital

Kadang-kadang perpustakaan membutuhkan rak khusus yang tidak bisa dibeli dari toko—rak bundar untuk majalah, rak miring untuk koran. Ini adalah "custom CSS" Anda. Tailwind menyediakan 99% kebutuhan styling, tetapi untuk 1% sisanya, Anda perlu menulis CSS manual. Kuncinya adalah mengintegrasikan rak khusus ini tanpa mengganggu sistem rak standar yang sudah ada—mereka harus hidup berdampingan secara harmonis.

## Penjelasan Detail

Custom CSS dalam project Tailwind sebaiknya diminimalkan dan ditempatkan di layer yang tepat. Tailwind v4 mendukung `@layer` untuk mengatur urutan spesifisitas: `tailwind utilities` (paling tinggi), `components`, dan `base`. Tempatkan custom CSS di layer yang sesuai: style komponen di `@layer components`, style dasar di `@layer base`. Gunakan CSS nesting native untuk organisasi yang lebih baik. Hindari `!important`—andalkan urutan layer untuk mengontrol prioritas. Jika ada gaya yang tidak bisa dicapai dengan Tailwind (misal animasi kompleks, mask, filter), ekstrak ke file CSS terpisah dan import di file utama.

## Contoh Kode Implementasi

```css
@import "tailwindcss";

/* Layer base: style dasar untuk elemen HTML */
@layer base {
  html {
    scroll-behavior: smooth;
  }
  body {
    @apply antialiased;
  }
  *::selection {
    @apply bg-indigo-200 text-indigo-900;
  }
}

/* Layer components: pola yang reusable */
@layer components {
  .prose-custom {
    @apply max-w-none text-gray-700 leading-relaxed;
    p { @apply mb-4; }
    a { @apply text-indigo-600 underline decoration-indigo-300 underline-offset-2; }
  }

  .card-hover-effect {
    transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
    &:hover {
      @apply -translate-y-1 shadow-xl;
    }
  }
}

/* Utility kustom dengan @utility di v4 */
@utility text-balance {
  text-wrap: balance;
}

@utility mask-fade-bottom {
  mask-image: linear-gradient(to bottom, black 60%, transparent 100%);
}
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Custom CSS + Tailwind</title>
  <link href="/dist/output.css" rel="stylesheet">
</head>
<body class="font-sans p-8">
  <article class="prose-custom">
    <h1 class="text-3xl font-bold text-gray-900">Judul Artikel</h1>
    <p>Ini adalah paragraf dengan <a href="#">tautan kustom</a> yang menggunakan styling dari layer components.</p>
  </article>

  <div class="card-hover-effect mt-6 rounded-xl bg-white p-6 shadow-md">
    Card dengan efek hover kustom
  </div>

  <p class="text-balance mt-6 max-w-sm text-lg">
    Teks ini akan balance secara otomatis dengan utility kustom.
  </p>
</body>
</html>
```

## Poin Penting

- Tempatkan custom CSS di `@layer base`, `@layer components`, atau `@layer utilities`
- Minimalisir custom CSS—gunakan Tailwind utility class sebisa mungkin
- Hindari `!important`; andalkan layer dan spesifisitas untuk prioritas
