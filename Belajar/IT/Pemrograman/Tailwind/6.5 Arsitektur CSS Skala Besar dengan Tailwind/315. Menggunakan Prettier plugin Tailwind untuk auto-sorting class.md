# Menggunakan Prettier plugin Tailwind untuk auto-sorting class

## Analogi: Perpustakaan Digital

Prettier plugin Tailwind seperti mesin otomatis yang merapikan buku di rak setiap malam. Anda mungkin meninggalkan buku dalam keadaan berantakan setelah membaca, tetapi mesin akan mengembalikannya ke urutan yang benar: berdasarkan kategori, ukuran, dan warna. Anda tidak perlu berpikir tentang urutan—cukup tulis class, dan Prettier akan mengaturnya setiap kali Anda menyimpan file.

## Penjelasan Detail

`prettier-plugin-tailwindcss` adalah plugin Prettier yang secara otomatis mengurutkan class Tailwind dalam atribut `class`, `className`, atau fungsi utility seperti `cn()`, `clsx()`, `twMerge()`. Plugin ini bekerja berdasarkan urutan yang ditentukan oleh konfigurasi Tailwind Anda. Urutan default: layout, flexbox/grid, spacing, sizing, typography, backgrounds, borders, effects, transitions, dan lainnya. Plugin ini juga mendeteksi class yang duplikat dan menghapusnya secara otomatis. Integrasi semudah menambahkan plugin ke konfigurasi Prettier—setiap format/save akan merapikan class secara otomatis.

## Contoh Kode Implementasi

```bash
npm install -D prettier prettier-plugin-tailwindcss
```

```json
// .prettierrc
{
  "semi": true,
  "singleQuote": false,
  "tabWidth": 2,
  "printWidth": 100,
  "plugins": ["prettier-plugin-tailwindcss"],
  "tailwindFunctions": ["cn", "clsx", "twMerge", "classnames"],
  "tailwindPreserveWhitespace": false
}
```

```tsx
// SEBELUM format — class acak
export function Card() {
  return (
    <div className="shadow-lg flex p-6 items-center bg-white gap-4 mt-4 rounded-xl">
      <div className="rounded-full bg-gradient-to-br from-indigo-400 size-12 to-purple-600"></div>
      <div>
        <h3 className="text-gray-900 text-lg font-bold">Judul</h3>
        <p className="text-sm text-gray-600">Deskripsi</p>
      </div>
    </div>
  );
}

// SESUDAH format — class terurut otomatis
export function Card() {
  return (
    <div className="mt-4 flex items-center gap-4 rounded-xl bg-white p-6 shadow-lg">
      <div className="size-12 rounded-full bg-gradient-to-br from-indigo-400 to-purple-600"></div>
      <div>
        <h3 className="text-lg font-bold text-gray-900">Judul</h3>
        <p className="text-sm text-gray-600">Deskripsi</p>
      </div>
    </div>
  );
}
```

## Poin Penting

- Plugin Prettier mengurutkan class Tailwind otomatis saat format/save
- Urutan: layout → spacing → sizing → typography → visual → effects
- Dukung fungsi utility `cn()`, `clsx()`, `twMerge()` secara built-in
