# Cara menangani third-party component libraries yang tidak menggunakan Tailwind

## Analogi: Perpustakaan Digital

Third-party library seperti buku dari penerbit lain yang sudah memiliki sampul dan label sendiri. Anda tidak bisa menempelkan stiker perpustakaan di atas sampul bukunya tanpa merusaknya. Sebagai gantinya, Anda bisa membuat "jaket buku" khusus—pembungkus transparan yang menampilkan label perpustakaan tanpa menutupi desain asli. Di kode, ini berarti membungkus komponen pihak ketiga dengan wrapper Tailwind atau menggunakan CSS override yang selektif.

## Penjelasan Detail

Ada beberapa strategi untuk mengintegrasikan komponen pihak ketiga dengan Tailwind. First, gunakan wrapper component: buat komponen React/Vue yang membungkus komponen library dan menambahkan class Tailwind via `className` prop. Second, gunakan CSS injection: beberapa library menyediakan cara untuk meng-inject CSS kustom (MUI's `sx` prop, Ant Design's `style`). Third, gunakan `@layer` untuk override: tempatkan override CSS di `@layer components` untuk memastikan spesifisitas yang cukup. Keempat, gunakan `!important` secara bijak jika benar-benar diperlukan, tetapi lebih baik hindari. Kelima, untuk library yang menggunakan CSS-in-JS, Anda bisa melewati styling mereka dan memberikan class Tailwind Anda sendiri.

## Contoh Kode Implementasi

```tsx
// Strategi 1: Wrapper component
import { DatePicker } from "antd";

interface TailwindDatePickerProps {
  value?: string;
  onChange?: (date: any) => void;
  className?: string;
}

export function TailwindDatePicker({ className = "", ...props }: TailwindDatePickerProps) {
  return (
    <div className={className}>
      <DatePicker
        {...props}
        className="w-full rounded-lg border-gray-200 shadow-sm focus:border-indigo-500 focus:ring-indigo-500"
        popupClassName="custom-popup" // untuk styling dropdown
      />
    </div>
  );
}
```

```css
/* Override CSS untuk komponen Ant Design */
@layer components {
  /* Target class Ant Design yang spesifik */
  .ant-picker {
    @apply w-full rounded-lg border-gray-200 shadow-sm;
  }
  .ant-picker:hover {
    @apply border-indigo-300;
  }
  .ant-picker-focused {
    @apply border-indigo-500 ring-1 ring-indigo-500;
  }

  /* Dropdown kalender */
  .ant-picker-dropdown .ant-picker-cell-inner {
    @apply rounded-lg;
  }
  .ant-picker-dropdown .ant-picker-cell-today .ant-picker-cell-inner {
    @apply text-indigo-600 font-medium;
  }
  .ant-picker-dropdown .ant-picker-cell-selected .ant-picker-cell-inner {
    @apply bg-indigo-600 text-white;
  }
}
```

```tsx
// Strategi 2: Override via className di library yang mendukung
import { Button as MuiButton } from "@mui/material";

function MyButton() {
  return (
    <MuiButton
      className="rounded-lg bg-indigo-600 text-white hover:bg-indigo-700 normal-case"
      disableRipple
    >
      Tombol MUI + Tailwind
    </MuiButton>
  );
}
```

## Poin Penting

- Buat wrapper component untuk membungkus library dengan styling Tailwind
- Gunakan CSS override di `@layer components` untuk menarget class library
- Beberapa library mendukung className langsung untuk Tailwind
