# Cara menggunakan linting untuk memastikan konsistensi penggunaan Tailwind

## Analogi: Perpustakaan Digital

Linting seperti sistem keamanan perpustakaan yang memeriksa setiap buku yang masuk. Jika ada buku yang tidak sesuai aturan—sampul robek, label salah, halaman terbalik—sistem akan menolaknya sebelum masuk ke rak. ESLint untuk Tailwind bekerja seperti ini: ia memeriksa class-class Tailwind di kode Anda dan melaporkan yang tidak sesuai aturan, sebelum kode masuk ke production.

## Penjelasan Detail

`eslint-plugin-tailwindcss` adalah plugin ESLint resmi untuk Tailwind yang menyediakan aturan untuk memvalidasi penggunaan class. Aturan penting: `classnames-order` (urutkan class berdasarkan kategori), `no-custom-classname` (peringatkan jika ada class yang tidak dikenal), `no-contradicting-classname` (deteksi class yang bertentangan seperti `flex` dan `hidden`), `no-unnecessary-arbitrary-value` (peringatkan jika arbitrary value bisa diganti dengan nilai tema yang sudah ada), `enforces-negative-arbitrary-values` (pastikan prefix `-` digunakan dengan benar). Integrasikan dengan pre-commit hook menggunakan husky dan lint-staged untuk memeriksa hanya file yang diubah.

## Contoh Kode Implementasi

```js
// eslint.config.js
import tailwind from "eslint-plugin-tailwindcss";

export default [
  ...tailwind.configs["flat/recommended"],
  {
    rules: {
      "tailwindcss/classnames-order": "error",
      "tailwindcss/no-contradicting-classname": "error",
      "tailwindcss/no-unnecessary-arbitrary-value": "warn",
      "tailwindcss/no-custom-classname": [
        "warn",
        {
          whitelist: [
            "btn-.+",
            "card-.+",
            "section-.+",
          ],
        },
      ],
      "tailwindcss/enforces-negative-arbitrary-values": "error",
      "tailwindcss/enforces-shorthand": "warn",
    },
  },
];
```

```bash
# Install
npm install -D eslint eslint-plugin-tailwindcss prettier prettier-plugin-tailwindcss

# Integrasi dengan husky dan lint-staged
npx husky init
```

```json
// package.json (sebagian)
{
  "lint-staged": {
    "*.{js,jsx,ts,tsx}": ["eslint --fix", "prettier --write"],
    "*.css": ["prettier --write"],
    "*.html": ["prettier --write"]
  }
}
```

```bash
# .husky/pre-commit
npx lint-staged
```

## Poin Penting

- `eslint-plugin-tailwindcss` untuk validasi otomatis class Tailwind
- Aturan kunci: `no-contradicting-classname`, `no-unnecessary-arbitrary-value`, `classnames-order`
- Integrasikan dengan pre-commit hook untuk mencegah kode tidak konsisten masuk
