# Menggunakan eslint-plugin-tailwindcss untuk sorting dan validasi class

## Analogi: Perpustakaan Digital

ESLint plugin Tailwind seperti asisten pustakawan yang selalu mengatur ulang buku yang berantakan. Anda mungkin meletakkan buku dengan label "Sejarah - 2024 - Hardcover - Rp150.000" di rak. Asisten akan mengaturnya menjadi: label "Sejarah," tahun "2024," jenis "Hardcover," harga "Rp150.000"—format yang konsisten. Plugin ini mengurutkan class Tailwind Anda ke dalam urutan yang logis: layout dulu, lalu spacing, typography, visual, dan lainnya.

## Penjelasan Detail

`eslint-plugin-tailwindcss` menyediakan aturan `classnames-order` yang mengurutkan class Tailwind secara otomatis berdasarkan kategori. Urutan default: layout (flex, grid, dll.), positioning, sizing, spacing, typography, backgrounds, borders, effects, transitions, dan lainnya. Aturan `no-custom-classname` memvalidasi bahwa setiap class adalah class Tailwind yang valid—class yang tidak dikenal akan diperingatkan. Aturan `no-contradicting-classname` mendeteksi kombinasi class yang tidak masuk akal seperti `flex` dengan `hidden` atau `text-sm` dengan `text-lg`. Aturan `enforces-shorthand` mendorong penggunaan class singkat seperti `p-4` daripada `px-4 py-4` jika nilainya sama.

## Contoh Kode Implementasi

```js
// eslint.config.js
import tailwindPlugin from "eslint-plugin-tailwindcss";

export default [
  {
    plugins: { tailwindcss: tailwindPlugin },
    rules: {
      "tailwindcss/classnames-order": [
        "error",
        {
          "callees": ["cn", "clsx", "twMerge", "classnames"],
          "config": "./tailwind.config.js",
          "removeDuplicates": true,
        },
      ],
      "tailwindcss/no-contradicting-classname": "error",
      "tailwindcss/enforces-shorthand": "warn",
      "tailwindcss/no-unnecessary-arbitrary-value": "warn",
    },
  },
];
```

```tsx
// Sebelum — class tidak terurut dan ada yang kontradiktif
<div className="text-lg p-4 flex hidden bg-white text-sm mt-4">
  Konten
</div>

// Sesudah — otomatis diurutkan, kontradiksi terdeteksi (flex + hidden)
// ESLint akan error: "flex" dan "hidden" bertentangan
<div className="mt-4 flex p-4 text-sm text-lg bg-white">
  Konten
</div>
// ESLint juga error: "text-sm" dan "text-lg" bertentangan
```

```bash
# Auto-fix sorting
npx eslint . --fix

# Atau integrate dengan editor (VS Code: Cmd+S akan auto-fix)
```

## Poin Penting

- `classnames-order` mengurutkan class berdasarkan kategori (layout, spacing, dll.)
- `no-contradicting-classname` mendeteksi class yang bertentangan
- `enforces-shorthand` mendorong penggunaan class singkat untuk nilai yang sama
