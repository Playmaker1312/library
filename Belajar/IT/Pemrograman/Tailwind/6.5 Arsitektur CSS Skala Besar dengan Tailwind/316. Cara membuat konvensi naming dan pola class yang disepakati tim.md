# Cara membuat konvensi naming dan pola class yang disepakati tim

## Analogi: Perpustakaan Digital

Konvensi naming seperti aturan penulisan label buku di perpustakaan. Semua buku fiksi diberi label merah dengan format "Fiksi - [Subgenre] - [Judul]." Semua buku referensi diberi label biru dengan format "REF - [Kode]." Tanpa konvensi, satu buku mungkin ditulis "Fiksi - Ilmiah" sementara yang lain "Fiksi Ilmiah." Di tim development, konvensi class memastikan semua anggota tim menulis kode yang terlihat seperti ditulis oleh satu orang.

## Penjelasan Detail

Buat dan dokumentasikan konvensi naming untuk komponen, file, dan pola class Tailwind. Contoh: komponen React menggunakan PascalCase (`Button`, `ProductCard`), file menggunakan kebab-case (`button.tsx`, `product-card.tsx`). Untuk class Tailwind, sepakati urutan penulisan (layout, spacing, typography, visual) yang akan dijamin oleh Prettier. Tentukan kapan menggunakan `@apply` (hanya untuk pola 3+ kali) dan kapan menggunakan komponen React/Vue. Sepakati penggunaan warna semantik (`bg-primary`) daripada warna literal (`bg-indigo-600`). Dokumentasikan keputusan ini di README atau CONTRIBUTING.md project.

## Contoh Kode Implementasi

```md
// CONTRIBUTING.md — Konvensi Tim

## Konvensi Tailwind

### Urutan Class
Gunakan urutan berikut (dijamin oleh Prettier plugin):
1. Layout: flex, grid, block, hidden
2. Positioning: absolute, relative, z-*
3. Sizing: w-*, h-*, size-*
4. Spacing: p-*, m-*, gap-*, space-*
5. Typography: text-*, font-*, leading-*
6. Visual: bg-*, border-*, rounded-*, shadow-*
7. Effects: opacity, transition, transform

### Aturan @apply
- Hanya gunakan @apply untuk pola yang muncul 3+ kali
- Tempatkan @apply di file `components.css` dalam `@layer components`
- Jangan gunakan @apply untuk komponen yang sudah dibungkus React/Vue

### Design Tokens
- Gunakan warna semantik: bg-primary, bukan bg-indigo-600
- Gunakan spacing scale: p-4, bukan p-[16px]
- Gunakan font theme: font-sans, bukan font-['Inter']

### Naming Komponen
- React: PascalCase, satu komponen per file
- File: kebab-case (.tsx)
- Folder: kebab-case
- Props: camelCase
```

```tsx
// ✅ Baik: menggunakan design tokens dan urutan class yang konsisten
<button className="flex items-center gap-2 rounded-lg bg-primary px-4 py-2 text-sm font-medium text-white transition hover:bg-primary-dark">
  Simpan
</button>

// ❌ Buruk: arbitrary value, warna literal, tidak terurut
<button className="hover:bg-blue-800 bg-blue-600 flex font-medium gap-2 items-center p-[10px] text-sm text-white transition-[colors]">
  Simpan
</button>
```

## Poin Penting

- Dokumentasikan konvensi di CONTRIBUTING.md atau README
- Gunakan design tokens semantik daripada nilai literal
- Prettier plugin menjamin urutan class tanpa diskusi manual
