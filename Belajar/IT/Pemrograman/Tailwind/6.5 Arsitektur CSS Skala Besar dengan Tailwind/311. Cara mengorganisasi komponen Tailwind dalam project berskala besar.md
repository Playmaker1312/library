# Cara mengorganisasi komponen Tailwind dalam project berskala besar

## Analogi: Perpustakaan Digital

Project berskala besar seperti perpustakaan nasional dengan jutaan buku. Tanpa organisasi yang baik, buku akan tersebar di mana-mana—sama seperti komponen tanpa struktur folder yang jelas. Di perpustakaan, ada bagian khusus: fiksi di lantai 2, referensi di lantai 1, anak-anak di basement. Di project Tailwind, Anda perlu membagi komponen ke dalam folder berdasarkan fungsinya: UI dasar, modul fitur, layout, dan halaman.

## Penjelasan Detail

Di project besar, organisasi komponen yang baik sangat penting. Buat struktur folder yang konsisten, misalnya: `components/ui/` (tombol, input, badge), `components/layout/` (header, sidebar, footer), `components/modules/` (komponen spesifik fitur), `pages/` atau `app/` (halaman). Setiap komponen sebaiknya memiliki file sendiri (single file component) dengan styling Tailwind inline. Gunakan `@apply` dengan hati-hati dan hanya untuk pola yang benar-benar berulang. Hindari file CSS kustom yang besar—lebih baik gunakan utility class langsung di template. Komponen yang kompleks bisa dipecah menjadi sub-komponen yang lebih kecil.

```tsx
// components/ui/Button.tsx — contoh komponen terorganisir
import { cn } from "@/utils/cn";

interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: "primary" | "secondary" | "outline";
  size?: "sm" | "md" | "lg";
}

export function Button({ variant = "primary", size = "md", className, ...props }: ButtonProps) {
  return (
    <button
      className={cn(
        "rounded-lg font-medium transition-colors focus:outline-none focus:ring-2 focus:ring-indigo-500",
        variant === "primary" && "bg-indigo-600 text-white hover:bg-indigo-700",
        variant === "secondary" && "bg-gray-100 text-gray-700 hover:bg-gray-200",
        variant === "outline" && "border border-gray-300 text-gray-700 hover:bg-gray-50",
        size === "sm" && "px-3 py-1.5 text-sm",
        size === "md" && "px-4 py-2 text-sm",
        size === "lg" && "px-6 py-3 text-base",
        className
      )}
      {...props}
    />
  );
}
```

## Poin Penting

- Organisasi folder: `ui/`, `layout/`, `modules/`, `pages/`
- Hindari `@apply` berlebihan—utility class langsung di template lebih baik
- Gunakan pattern `cn()` utility untuk menggabungkan class secara kondisional
