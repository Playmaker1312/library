# Cara mengintegrasikan Tailwind dengan Astro

## Analogi: Perpustakaan Digital
Astro adalah perpustakaan generasi baru yang mengirimkan "hanya buku yang benar-benar dibaca pengunjung" — zero JavaScript ke client jika tidak diperlukan. Mengintegrasikan Tailwind dengan Astro seperti menggabungkan sistem rak yang efisien dengan framework yang mengutamakan performa. Hasilnya adalah situs yang cepat, styling yang konsisten, dan bundle size yang minimal. Astro memiliki integrasi resmi untuk Tailwind yang membuat setup sangat mudah.

## Penjelasan Detail
Astro menyediakan integrasi resmi untuk Tailwind. Cara termudah: saat membuat project Astro, pilih Tailwind dari template. Atau tambahkan secara manual: (1) Buat project Astro: `npm create astro@latest`, (2) Tambahkan integrasi Tailwind: `npx astro add tailwind`. Perintah ini secara otomatis menginstal `@astrojs/tailwind` dan dependencies, mengonfigurasi `astro.config.mjs`, dan membuat `tailwind.config.js`. Astro mendukung Tailwind di semua jenis komponen — `.astro`, `.mdx`, `.html`, dan framework components (React, Vue, Svelte) yang digunakan di dalam Astro. Dengan Astro + Tailwind, Anda bisa membangun content-focused websites seperti blog, dokumentasi, dan landing pages dengan performa luar biasa.

## Poin Penting
- Gunakan `npx astro add tailwind` untuk integrasi otomatis — ini adalah cara termudah
- Atau install manual: `npm install -D @astrojs/tailwind tailwindcss` dan tambahkan ke `astro.config.mjs`
- Tailwind berfungsi di semua jenis file Astro: .astro, .mdx, .html, dan komponen framework
