# Cara mengintegrasikan Tailwind dengan Next.js

## Analogi: Perpustakaan Digital
Next.js seperti perpustakaan digital canggih yang sudah memiliki sistem routing, rendering server, dan optimasi gambar built-in. Mengintegrasikan Tailwind dengan Next.js seperti memasang sistem desain yang seragam ke dalam gedung bertingkat — Tailwind akan bekerja di semua lantai (halaman), baik yang di-render di server (SSR) maupun di client (CSR). Next.js bahkan menyediakan template dengan Tailwind pre-installed.

## Penjelasan Detail
Next.js memiliki dukungan first-class untuk Tailwind CSS. Mulai dari instalasi: (1) Buat project Next.js: `npx create-next-app@latest my-app` — pilih "Yes" saat ditanya tentang Tailwind, atau (2) Install manual: `npm install -D tailwindcss postcss autoprefixer && npx tailwindcss init`. Konfigurasi `content` di tailwind.config.js harus mencakup `./pages/**/*.{js,ts,jsx,tsx}` dan `./components/**/*.{js,ts,jsx,tsx}` (App Router: `./app/**/*.{js,ts,jsx,tsx}`). Di Next.js 13+ dengan App Router, Tailwind sudah pre-configured. Tambahkan direktif Tailwind di `app/globals.css`. Tailwind bekerja sempurna dengan SSR Next.js — utility class di-render di server tanpa masalah.

## Poin Penting
- Next.js memiliki dukungan first-class untuk Tailwind — pilih "Yes" saat `create-next-app` untuk konfigurasi otomatis
- Set `content` di tailwind.config.js sesuai router yang digunakan (App Router atau Pages Router)
- Tailwind bekerja sempurna dengan SSR — utility class di-render server-side tanpa masalah
