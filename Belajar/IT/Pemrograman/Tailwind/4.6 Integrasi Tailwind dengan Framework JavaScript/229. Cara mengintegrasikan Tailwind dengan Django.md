# Cara mengintegrasikan Tailwind dengan Django

## Analogi: Perpustakaan Digital
Django adalah backend python yang "batteries-included" — memiliki segalanya dari admin panel hingga ORM. Mengintegrasikan Tailwind dengan Django seperti memasang sistem rak modern ke perpustakaan klasik yang sudah mapan. Django mengurus data dan logika di belakang layar, Tailwind mengurus tampilan depan. Integrasi dilakukan melalui django-tailwind-cli atau django-compressor, memungkinkan workflow development yang mulus.

## Penjelasan Detail
Ada beberapa cara integrasi Tailwind dengan Django. Metode yang paling direkomendasikan adalah menggunakan `django-tailwind-cli` atau ekstensi VS Code. Langkah-langkah: (1) Buat project Django dan virtual environment, (2) Install `django-tailwind-cli`: `pip install django-tailwind-cli`, (3) Tambahkan ke `INSTALLED_APPS`, (4) Jalankan `python manage.py tailwind init`, (5) Install npm dependencies: `npm install`, (6) Gunakan template tag `{% tailwind_css %}` di template Django. Alternatif lain adalah menggunakan `django-compressor` untuk memproses CSS Tailwind, atau menggunakan CDN Tailwind untuk prototyping cepat. Untuk production, Tailwind CSS perlu di-build dan file statis dikumpulkan dengan `python manage.py collectstatic`.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Tailwind + Django</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Integrasi Tailwind + Django</h1>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Metode 1: django-tailwind-cli (Direkomendasikan)</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
# 1. Install django-tailwind-cli
pip install django-tailwind-cli

# 2. settings.py
INSTALLED_APPS = [
  'django_tailwind_cli',
  # ...
]

# 3. Init Tailwind
python manage.py tailwind init

# 4. Jalankan development
python manage.py tailwind start</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Metode 2: Tailwind CDN (Prototyping Cepat)</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
&lt;!-- base.html --&gt;
&lt;!DOCTYPE html&gt;
&lt;html&gt;
&lt;head&gt;
  &lt;script src="https://cdn.tailwindcss.com"&gt;&lt;/script&gt;
&lt;/head&gt;
&lt;body&gt;
  {% block content %}{% endblock %}
&lt;/body&gt;
&lt;/html&gt;</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Contoh Template Django</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
&lt;!-- templates/home.html --&gt;
{% extends "base.html" %}
{% load tailwind_tags %}

{% block content %}
&lt;div class="min-h-screen
  bg-gray-50 p-8"&gt;
  &lt;h1 class="text-4xl font-bold
    text-gray-900 mb-4"&gt;
    Django + Tailwind
  &lt;/h1&gt;
  
  &lt;div class="grid
    grid-cols-1 md:grid-cols-2
    gap-4"&gt;
    {% for item in items %}
    &lt;div class="bg-white p-6
      rounded-xl shadow"&gt;
      &lt;h2 class="text-xl
        font-semibold text-gray-800"&gt;
        {{ item.title }}
      &lt;/h2&gt;
      &lt;p class="text-gray-600
        mt-2"&gt;{{ item.description }}&lt;/p&gt;
    &lt;/div&gt;
    {% endfor %}
  &lt;/div&gt;
&lt;/div&gt;
{% endblock %}</pre>
    </div>

    <div class="bg-green-50 p-6 rounded-xl">
      <p class="text-green-800"><strong>Tips:</strong> Untuk production, build CSS dengan <code>python manage.py tailwind build</code> lalu <code>python manage.py collectstatic</code>. Pastikan direktori static Tailwind terdaftar di STATICFILES_DIRS.</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `django-tailwind-cli` untuk workflow Tailwind yang terintegrasi dengan Django
- Untuk prototyping cepat, gunakan CDN Tailwind via `<script>` tag di template base
- Untuk production, build CSS dengan `tailwind build` dan kumpulkan static files Django
