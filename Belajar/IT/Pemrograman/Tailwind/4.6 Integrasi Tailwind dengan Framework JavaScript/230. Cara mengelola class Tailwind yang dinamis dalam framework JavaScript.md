# Cara mengelola class Tailwind yang dinamis dalam framework JavaScript

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang secara dinamis mengubah tampilan rak berdasarkan siapa yang melihat — pengguna premium melihat rak emas, pengguna biasa melihat rak kayu. Class Tailwind yang dinamis memungkinkan Anda mengubah styling berdasarkan state aplikasi, data, atau interaksi pengguna. Namun, mengelola class dinamis di framework JavaScript membutuhkan strategi yang tepat karena Tailwind menggunakan JIT (Just-In-Time) yang hanya menghasilkan class yang terdeteksi di source code.

## Penjelasan Detail
Ada beberapa strategi untuk mengelola class Tailwind dinamis. Pertama, **conditional class** menggunakan operator ternary atau logical AND: `className={isActive ? 'bg-indigo-600' : 'bg-gray-300'}`. Kedua, **array class** menggunakan library seperti `clsx` atau `classnames` untuk menggabungkan class secara kondisional. Ketiga, **object class** di React: `className={cn('px-4 py-2 rounded', { 'bg-indigo-600 text-white': isActive, 'bg-gray-200': !isActive })}`. Keempat, **concatenation** dengan template literal. PENTING: Jangan membuat class secara dinamis dengan concatenation string seperti `bg-${color}-500` karena Tailwind JIT tidak akan mendeteksi class tersebut. Gunakan class lengkap atau gunakan `safeList` di konfigurasi. Library seperti `clsx` dan `tailwind-merge` sangat membantu untuk menggabungkan class Tailwind dan menyelesaikan konflik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Class Dinamis Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      safelist: [
        'bg-red-500', 'bg-blue-500', 'bg-green-500',
        'bg-yellow-500', 'bg-purple-500',
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Class Tailwind Dinamis</h1>

    <!-- Demo interaktif -->
    <div id="demo" class="bg-white p-6 rounded-xl shadow space-y-4">
      <h2 class="font-semibold text-gray-700">Demo: Dynamic Color Picker</h2>
      <div class="flex gap-2">
        <button onclick="setColor('red')" class="bg-red-500 text-white px-4 py-2 rounded">Merah</button>
        <button onclick="setColor('blue')" class="bg-blue-500 text-white px-4 py-2 rounded">Biru</button>
        <button onclick="setColor('green')" class="bg-green-500 text-white px-4 py-2 rounded">Hijau</button>
        <button onclick="setColor('purple')" class="bg-purple-500 text-white px-4 py-2 rounded">Ungu</button>
      </div>
      <div id="colorBox" class="bg-indigo-500 text-white p-6 rounded-lg text-center text-lg font-bold transition-colors">
        Warna akan berubah
      </div>
      <pre class="bg-gray-100 p-3 rounded text-sm text-gray-700">
// ✅ BENAR: class lengkap di safelist
// ❌ SALAH: className={`bg-${color}-500`}
// Gunakan safelist di config
safelist: ['bg-red-500', 'bg-blue-500', ...]</pre>
    </div>

    <!-- Pattern yang benar -->
    <div class="bg-white p-6 rounded-xl shadow space-y-4">
      <h2 class="font-semibold text-gray-700">Pattern yang Direkomendasikan</h2>
      
      <div class="bg-green-50 border border-green-200 p-4 rounded-lg">
        <p class="font-semibold text-green-800">✅ Object/Map-based</p>
        <pre class="text-sm text-green-700 mt-1">const variants = {
  primary: 'bg-indigo-600 text-white',
  danger: 'bg-red-500 text-white',
  ghost: 'bg-transparent text-gray-600',
};
&lt;button className={variants[variant]} /&gt;</pre>
      </div>

      <div class="bg-green-50 border border-green-200 p-4 rounded-lg">
        <p class="font-semibold text-green-800">✅ clsx / tailwind-merge</p>
        <pre class="text-sm text-green-700 mt-1">import { clsx } from 'clsx';
import { twMerge } from 'tailwind-merge';

function cn(...inputs) {
  return twMerge(clsx(inputs));
}

&lt;div className={cn(
  'px-4 py-2 rounded',
  isActive && 'bg-indigo-600 text-white',
  size === 'lg' && 'text-lg p-4'
)} /&gt;</pre>
      </div>

      <div class="bg-red-50 border border-red-200 p-4 rounded-lg">
        <p class="font-semibold text-red-800">❌ Hindari Concatenation</p>
        <pre class="text-sm text-red-700 mt-1">// ❌ Tidak akan terdeteksi JIT:
className={`bg-${color}-500`}

// ✅ Gunakan mapping:
const colors = { red: 'bg-red-500', blue: 'bg-blue-500' };
className={colors[color]}</pre>
      </div>
    </div>
  </div>

  <script>
    function setColor(color) {
      const box = document.getElementById('colorBox');
      const colors = { red: 'bg-red-500', blue: 'bg-blue-500', green: 'bg-green-500', purple: 'bg-purple-500' };
      // Hapus semua class warna, tambah yang baru
      Object.values(colors).forEach(c => box.classList.remove(c));
      box.classList.add(colors[color]);
      box.textContent = `Warna: ${color}`;
    }
  </script>
</body>
</html>
```

## Poin Penting
- Hindari concatenation string untuk class dinamis (`bg-${color}-500`) — gunakan mapping object atau conditional
- Gunakan library `clsx` dan `tailwind-merge` untuk menggabungkan class secara kondisional
- Tambahkan class yang mungkin digunakan secara dinamis ke `safelist` di tailwind.config.js
- Gunakan object mapping untuk variant (primary, danger, ghost) daripada string dinamis
