# Cara mengintegrasikan Tailwind dengan React menggunakan Create React App

## Analogi: Perpustakaan Digital
Bayangkan Anda membangun perpustakaan digital baru menggunakan "paket konstruksi" React CRA yang sudah menyediakan kerangka dasar. Mengintegrasikan Tailwind seperti memasang sistem rak buku standar ke dalam gedung yang sudah jadi — Anda perlu mengikuti prosedur tertentu agar rak (utility class) bisa dipasang dengan benar dan berfungsi di seluruh ruangan (komponen).

## Penjelasan Detail
Untuk mengintegrasikan Tailwind dengan Create React App (CRA), langkah-langkahnya: (1) Buat project CRA dengan `npx create-react-app my-app`, (2) Install Tailwind dan PostCSS CLI: `npm install -D tailwindcss postcss-cli autoprefixer`, (3) Inisialisasi konfigurasi: `npx tailwindcss init`, (4) Konfigurasi `content` di tailwind.config.js untuk memindai file JS dan JSX, (5) Tambahkan direktif Tailwind di `src/index.css`: `@tailwind base; @tailwind components; @tailwind utilities;`, (6) Jalankan project dengan `npm start`. Di CRA versi lama, Anda mungkin perlu menggunakan CRACO untuk override konfigurasi PostCSS. Mulai CRA versi 5, Tailwind bisa digunakan langsung tanpa CRACO. Setelah terintegrasi, utility class Tailwind bisa langsung digunakan di komponen React.

## Poin Penting
- Install Tailwind dengan `npm install -D tailwindcss postcss autoprefixer`, inisialisasi dengan `npx tailwindcss init`
- Set `content` di tailwind.config.js untuk memindai file `./src/**/*.{js,jsx,ts,tsx}`
- Tambahkan direktif `@tailwind base; @tailwind components; @tailwind utilities;` di index.css
