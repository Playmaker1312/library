# Cara mengintegrasikan Tailwind dengan SvelteKit

## Analogi: Perpustakaan Digital
SvelteKit seperti perpustakaan yang "menghilangkan kerumitan" — kode Anda dikompilasi menjadi JavaScript murni yang sangat cepat. Tidak ada virtual DOM, tidak ada overhead runtime. Mengintegrasikan Tailwind dengan SvelteKit seperti menggabungkan dua teknologi yang sama-sama efisien: Svelte menangani logika dengan ringan, Tailwind menangani styling dengan presisi. Hasilnya adalah aplikasi yang sangat cepat dan mudah dirawat.

## Penjelasan Detail
Integrasi Tailwind dengan SvelteKit: (1) Buat project SvelteKit: `npx sv create my-app` lalu pilih template, (2) Install Tailwind: `npm install -D tailwindcss @tailwindcss/vite`, (3) Tambahkan `tailwindcss()` di `vite.config.js`, (4) Tambahkan `@import "tailwindcss"` di `src/app.css`. SvelteKit menggunakan Vite secara internal, jadi integrasi Tailwind via plugin Vite adalah pendekatan yang tepat. Svelte component files (.svelte) bisa langsung menggunakan Tailwind di bagian `<style>` dan template. Dengan SvelteKit, Tailwind bisa digunakan di server-side rendering, prerendering, dan client-side rendering. SvelteKit juga mendukung Tailwind dengan baik karena menggunakan PostCSS secara default.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Tailwind + SvelteKit</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Integrasi Tailwind + SvelteKit</h1>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Langkah Instalasi</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
# 1. Buat project SvelteKit
npx sv create my-app
cd my-app
npm install

# 2. Install Tailwind v4
npm install -D tailwindcss @tailwindcss/vite</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">vite.config.js</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
import { sveltekit } from '@sveltejs/kit/vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
    sveltekit(),
  ],
})</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">src/app.css</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
@import "tailwindcss";</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Contoh Komponen Svelte</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
&lt;script&gt;
  let count = $state(0);
&lt;/script&gt;

&lt;div class="min-h-screen
  bg-gray-50 p-8"&gt;
  &lt;h1 class="text-4xl font-bold
    text-gray-800 mb-4"&gt;
    SvelteKit + Tailwind
  &lt;/h1&gt;
  
  &lt;button
    onclick={() => count++}
    class="bg-indigo-600 text-white
    px-6 py-3 rounded-lg
    hover:bg-indigo-700
    transition"&gt;
    Count: {count}
  &lt;/button&gt;
&lt;/div&gt;</pre>
    </div>

    <div class="bg-orange-50 p-6 rounded-xl">
      <p class="text-orange-800"><strong>Catatan:</strong> SvelteKit menggunakan Vite secara default. Integrasi Tailwind dilakukan melalui plugin Vite <code>@tailwindcss/vite</code>. Pastikan plugin tailwindcss ditambahkan sebelum plugin sveltekit di vite.config.js.</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- SvelteKit menggunakan Vite, jadi integrasi via plugin `@tailwindcss/vite` adalah pendekatan standar
- Tambahkan `@import "tailwindcss"` di `src/app.css` untuk mengimpor direktif Tailwind
- Svelte component (.svelte) bisa langsung menggunakan Tailwind di template dan style
