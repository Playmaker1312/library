# Cara mengintegrasikan Tailwind dengan React menggunakan Vite

## Analogi: Perpustakaan Digital
Jika CRA seperti membangun perpustakaan dengan crane standar, Vite adalah crane balap yang super cepat. Vite menawarkan kecepatan development yang jauh lebih tinggi dengan Hot Module Replacement (HMR) instan. Mengintegrasikan Tailwind dengan Vite adalah cara modern dan paling direkomendasikan saat ini untuk memulai project React. Prosesnya lebih mulus dan hasilnya lebih cepat.

## Penjelasan Detail
Untuk integrasi Tailwind dengan React menggunakan Vite: (1) Buat project Vite: `npm create vite@latest my-app -- --template react`, (2) Masuk ke direktori dan install dependencies: `npm install`, (3) Install Tailwind: `npm install -D tailwindcss @tailwindcss/vite`, (4) Tambahkan plugin `@tailwindcss/vite` di `vite.config.js`, (5) Tambahkan `@import "tailwindcss"` di file CSS utama. Di Vite, integrasi Tailwind sangat mulus karena Vite sudah mendukung PostCSS secara native. Vite juga memberikan development experience yang lebih cepat dibanding CRA. Vite cocok untuk project baru karena performa build dan development yang superior.

## Poin Penting
- Buat project dengan `npm create vite@latest`, install `tailwindcss` dan `@tailwindcss/vite`
- Tambahkan plugin `tailwindcss()` di `vite.config.js` dan `@import "tailwindcss"` di CSS utama
- Vite memberikan development experience lebih cepat dibanding CRA — pilihan utama untuk project baru
