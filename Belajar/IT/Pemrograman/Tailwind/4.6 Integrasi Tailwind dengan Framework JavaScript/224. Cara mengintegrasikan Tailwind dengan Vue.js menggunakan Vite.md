# Cara mengintegrasikan Tailwind dengan Vue.js menggunakan Vite

## Analogi: Perpustakaan Digital
Vue.js seperti sistem perpustakaan yang reaktif dan intuitif — ketika ada buku baru ditambahkan, rak langsung menyesuaikan. Mengintegrasikan Tailwind dengan Vue.js via Vite seperti menyatukan dua sistem yang saling melengkapi: Vue mengurus logika dan reaktivitas, Tailwind mengurus tampilan. Hasilnya adalah aplikasi yang responsif, cepat, dan mudah dikembangkan.

## Penjelasan Detail
Langkah integrasi Tailwind dengan Vue.js menggunakan Vite: (1) Buat project Vite + Vue: `npm create vite@latest my-app -- --template vue`, (2) Masuk direktori dan install dependencies, (3) Install Tailwind: `npm install -D tailwindcss @tailwindcss/vite`, (4) Tambahkan `tailwindcss()` di `vite.config.js`, (5) Tambahkan `@import "tailwindcss"` di `src/style.css`. Vue single-file components (SFC) bisa langsung menggunakan Tailwind di bagian `<template>`. Utility class juga bisa digunakan dengan class binding Vue (`:class`). Integrasi Tailwind dengan Vue sangat mulus dan banyak digunakan dalam ekosistem Vue modern, terutama dengan Vue 3 dan Composition API.

```html
<body class="p-10 bg-gray-50">
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Integrasi Tailwind + Vue.js + Vite</h1>

npm create vite@latest my-app -- --template vue
cd my-app
npm install

# 2. Install Tailwind v4
npm install -D tailwindcss @tailwindcss/vite</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">vite.config.js</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    vue(),
    tailwindcss(),
  ],
})</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">src/style.css</h2>
      <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
@import "tailwindcss";</pre>
    </div>

    <div class="bg-white p-6 rounded-xl shadow">
      <h2 class="font-semibold text-gray-700 mb-4">Contoh Komponen Vue (SFC)</h2>

import { ref } from 'vue'

&lt;/script&gt;

&lt;template&gt;
  &lt;div class="min-h-screen
    bg-gray-50 p-8 flex
    flex-col items-center"&gt;

    &lt;/p&gt;
    &lt;button @click="count++"

      px-6 py-3 rounded-lg

    &lt;/button&gt;
  &lt;/div&gt;
&lt;/template&gt;</pre>
    </div>

    <div class="bg-emerald-50 p-6 rounded-xl">
      <p class="text-emerald-800"><strong>Tips:</strong> Gunakan class binding Vue (<code>:class="[isActive ? 'bg-indigo-600' : 'bg-gray-300']"</code>) untuk dynamic class dengan Tailwind. Vue 3 + Vite + Tailwind adalah stack modern yang sangat populer.</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Buat project dengan `npm create vite@latest -- --template vue`, install `tailwindcss` dan `@tailwindcss/vite`
- Tambahkan plugin `tailwindcss()` di vite.config.js dan `@import "tailwindcss"` di style.css
- Vue SFC bisa langsung menggunakan Tailwind di template dan mendukung class binding dinamis
