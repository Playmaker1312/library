# Cara mengintegrasikan Tailwind dengan Nuxt.js

## Analogi: Perpustakaan Digital
Nuxt.js adalah framework Vue yang sudah memiliki segalanya — routing, SSR, module system, dan auto-import. Jika Vue adalah sistem perpustakaan, Nuxt adalah "perpustakaan lengkap dengan manajemen otomatis". Mengintegrasikan Tailwind dengan Nuxt semudah menginstal modul resmi — Nuxt memiliki ekosistem modul yang membuat integrasi Tailwind menjadi satu perintah saja. Sisanya berjalan otomatis.

## Penjelasan Detail
Nuxt.js memiliki modul resmi `@nuxtjs/tailwindcss` yang menyederhanakan integrasi Tailwind. Langkah-langkah: (1) Buat project Nuxt: `npx nuxi@latest init my-app`, (2) Install modul Tailwind: `npm install -D @nuxtjs/tailwindcss`, (3) Tambahkan `@nuxtjs/tailwindcss` ke modul di `nuxt.config.ts`. Modul ini secara otomatis mengonfigurasi PostCSS, membuat file `tailwind.config.js`, dan menyediakan file `app/assets/css/tailwind.css` dengan direktif Tailwind. Nuxt juga mendukung auto-import komponen yang menggunakan Tailwind. Dengan Nuxt 3, kamu bisa menggunakan Tailwind di server-side rendered pages, static generated pages, dan client-side rendered pages tanpa konfigurasi tambahan.

## Poin Penting
- Gunakan modul resmi `@nuxtjs/tailwindcss` — integrasi instan dengan satu baris di `nuxt.config.ts`
- Modul ini otomatis mengonfigurasi PostCSS, content paths, dan direktif Tailwind
- Tailwind bekerja di semua mode rendering Nuxt: SSR, SSG, dan CSR tanpa konfigurasi tambahan
