# Cara mengintegrasikan Tailwind dengan Laravel menggunakan Vite

## Analogi: Perpustakaan Digital
Laravel adalah backend perpustakaan yang kuat — mengurus database, autentikasi, dan logika bisnis. Vite adalah kurir cepat yang mengirimkan CSS dan JavaScript ke frontend. Mengintegrasikan Tailwind dengan Laravel via Vite seperti menyatukan sistem manajemen perpustakaan (Laravel) dengan sistem display rak yang indah (Tailwind). Hasilnya adalah aplikasi full-stack yang rapi dan cepat.

## Penjelasan Detail
Laravel 9+ secara default menggunakan Vite sebagai bundler (menggantikan Laravel Mix). Langkah integrasi: (1) Buat project Laravel: `composer create-project laravel/laravel my-app`, (2) Install Tailwind: `npm install -D tailwindcss @tailwindcss/vite`, (3) Tambahkan `tailwindcss()` di `vite.config.js`, (4) Tambahkan `@import "tailwindcss"` di `resources/css/app.css`. Laravel Vite plugin sudah terkonfigurasi secara default. Jalankan `npm run dev` untuk development atau `npm run build` untuk production. Tailwind akan memindai file blade (.blade.php) di direktori resources/views. Integrasi Laravel + Tailwind sangat populer untuk aplikasi web full-stack karena Tailwind memungkinkan styling cepat tanpa meninggalkan file blade.

```html
  <div class="max-w-3xl mx-auto space-y-6">
    <h1 class="text-3xl font-bold text-gray-800">Integrasi Tailwind + Laravel + Vite</h1>

    <div class="bg-white p-6 rounded-xl shadow">

import laravel from 'laravel-vite-plugin';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [
    tailwindcss(),
    laravel({
      input: ['resources/css/app.css',
              'resources/js/app.js'],
      refresh: true,
    }),
  ],
});</pre>
    </div>

    </div>

    <div class="bg-white p-6 rounded-xl shadow">

  app()->getLocale()) }}"&gt;

  @vite(['resources/css/app.css',

  &lt;h1 class="text-4xl font-bold

  &lt;/h1&gt;

```

## Poin Penting
- Laravel 9+ menggunakan Vite — install `tailwindcss` dan `@tailwindcss/vite`, tambahkan ke `vite.config.js`
- Tambahkan `@import "tailwindcss"` di `resources/css/app.css` dan gunakan direktif `@vite()` di blade
- Tailwind akan memindai file `.blade.php` di `resources/views` secara otomatis
