# Membangun halaman blog dengan konten markdown menggunakan Tailwind Typography

## Analogi: Perpustakaan Digital
Halaman blog dengan konten markdown bagaikan ruang baca utama perpustakaan digital tempat pengunjung menikmati artikel panjang dengan nyaman. Layaknya rak yang menata buku berdasarkan genre dan ukuran, Tailwind Typography secara otomatis memformat elemen markdown—heading, paragraf, daftar, blockquote—menjadi tipografi yang indah dan konsisten. Pembaca bisa fokus pada konten tanpa terganggu oleh styling yang tidak rapi. Pengalaman membaca yang menyenangkan adalah prioritas utama.

## Penjelasan Detail
Membangun halaman blog dengan Tailwind Typography memanfaatkan plugin `@tailwindcss/typography` yang menyediakan class `prose` untuk memformat konten HTML yang dihasilkan dari markdown. Plugin ini mengatur styling untuk heading, paragraf, link, code blocks, blockquote, daftar, tabel, dan gambar secara otomatis. Prose dapat dikustomisasi melalui modifier seperti `prose-sm`, `prose-lg`, `prose-invert` untuk dark mode, serta kustomisasi warna melalui `prose-{color}`. Integrasi dengan markdown parser seperti marked, remark, atau markdown-it memungkinkan konversi file `.md` ke HTML yang langsung diformat oleh prose. Layout blog mencakup header dengan metadata (judul, penulis, tanggal, tag), konten utama dengan prose, sidebar dengan daftar isi, dan footer. Code highlighting via Prism.js atau highlight.js dapat ditambahkan dengan gaya yang selaras dengan prose. Tailwind Typography memastikan konsistensi tipografi di seluruh artikel tanpa perlu menulis CSS kustom untuk setiap elemen.

## Poin Penting
- Plugin `@tailwindcss/typography` dengan class `prose` memformat konten markdown secara otomatis tanpa CSS manual
- Modifier `prose-invert` menangani dark mode untuk seluruh elemen tipografi sekaligus
- Ukuran prose dapat disesuaikan dengan `prose-sm`, `prose-base`, `prose-lg` secara responsif
- Kustomisasi warna dan spacing prose dilakukan melalui `tailwind.config.js` di `theme.typography`
