# Membangun komponen email template yang responsif dengan prinsip Tailwind

## Analogi: Perpustakaan Digital
Email template responsif seperti kartu pos digital dari perpustakaan yang harus terbaca sempurna di berbagai ukuran kertas—dari layar ponsel hingga monitor desktop. Tailwind membantu merancang tata letak email yang fleksibel menggunakan tabel dan inline styles. Setiap elemen harus tertata rapi dan konsisten di semua klien email. Prinsip utility-first Tailwind memastikan setiap detail proporsional.

## Penjelasan Detail
Membangun email template menggunakan prinsip Tailwind memerlukan pendekatan khusus karena klien email (Gmail, Outlook) memiliki dukungan CSS terbatas. Tailwind tidak bisa digunakan langsung via CDN di email; sebagai gantinya, gunakan CSS inlining dengan tools seperti Maizzle atau Foundation for Emails. Prinsip utility-first Tailwind tetap diterapkan: spacing, typography, dan warna didefinisikan secara eksplisit. Layout menggunakan tabel HTML (<table>, <tr>, <td>) dengan ole="presentation" untuk kompatibilitas lintas klien. Media queries untuk responsivitas di mobile menggunakan <style> di head dengan max-width. Tombol CTA menggunakan padding dan border-radius dengan fallback. Gambar menggunakan max-width: 100% dan height: auto untuk responsivitas. Pre-header text tersembunyi untuk preview di inbox. Fallback font stack (Arial, sans-serif) memastikan keterbacaan. Testing di berbagai klien email menggunakan tools seperti Litmus atau Email on Acid.

## Poin Penting
- Email template menggunakan tabel HTML untuk kompatibilitas lintas klien email (Gmail, Outlook, Apple Mail)
- Media queries untuk responsivitas mobile dengan max-width 480px dan penyesuaian padding
- Tombol CTA menggunakan inline styles dan fallback untuk klien yang tidak mendukung CSS
- Warna dan spacing mengikuti prinsip utility Tailwind untuk konsistensi dengan brand
