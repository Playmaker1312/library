# Menggunakan padding utilities yaitu p, pt, pr, pb, pl, px, dan py

## Analogi: Perpustakaan Digital

Bayangkan sebuah bingkai foto digital di perpustakaan. Padding adalah jarak antara isi bingkai (foto) dengan tepi bingkainya. `p` memberi jarak di semua sisi foto. `pt` jarak ke tepi atas, `pb` ke tepi bawah, `pl` ke kiri, `pr` ke kanan. `px` untuk jarak kiri-kanan, `py` untuk atas-bawah.

## Penjelasan Detail

Padding utilities di Tailwind menggunakan format `{p|pt|pr|pb|pl|px|py}-{nilai}` dengan nilai dari spacing scale. Padding menciptakan ruang di dalam elemen, antara konten dan border. `px` mempengaruhi padding kiri dan kanan sekaligus, sedangkan `py` mempengaruhi atas dan bawah. Padding sangat penting untuk memberikan "ruang bernapas" pada konten. Berbeda dengan margin yang mendorong elemen lain, padding memperluas area klik elemen. Padding tidak bisa bernilai negatif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Padding Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Padding Utilities</h1>
  <div class="bg-blue-200">
    <div class="bg-blue-500 text-white p-4">p-4 (semua sisi)</div>
  </div>
  <div class="bg-green-200">
    <div class="bg-green-500 text-white px-8 py-2">px-8 py-2</div>
  </div>
  <div class="bg-red-200">
    <div class="bg-red-500 text-white pt-6 pb-2 pl-4 pr-2">pt-6 pb-2 pl-4 pr-2</div>
  </div>
  <div class="bg-purple-200">
    <div class="bg-purple-500 text-white py-4">py-4 (atas-bawah)</div>
  </div>
</body>
</html>
```

## Poin Penting
- Padding memberi jarak di dalam elemen, bukan di luar
- `px` untuk horizontal, `py` untuk vertikal
- Padding tidak mendukung nilai negatif
