# Menggunakan scroll margin yaitu scroll-mt dan scroll-mb untuk scroll behavior

## Analogi: Perpustakaan Digital

Saat menggulir halaman perpustakaan digital ke sebuah bagian tertentu, scroll margin seperti memberi jarak ekstra sebelum bagian tersebut mencapai tepi layar. Ini seperti menandai bab dalam buku digital dengan jarak pandang tertentu agar judul bab tidak tertutup navbar. Scroll margin memastikan target scroll memiliki ruang di atasnya.

## Penjelasan Detail

Scroll margin utilities (`scroll-mt-{nilai}`, `scroll-mb-{nilai}`, `scroll-ml-{nilai}`, `scroll-mr-{nilai}`, `scroll-mx-{nilai}`, `scroll-my-{nilai}`) mengatur jarak margin saat elemen menjadi target scroll, terutama saat menggunakan scroll smooth atau scroll snap. `scroll-mt` berguna untuk mengompensasi navbar fixed yang menutupi konten saat navigasi anchor. Nilai mengikuti spacing scale Tailwind. Fitur ini menggunakan properti CSS `scroll-margin`. Sangat berguna pada halaman dengan anchor links.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Scroll Margin Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <style>html { scroll-behavior: smooth; }</style>
</head>
<body>
  <nav class="fixed top-0 left-0 right-0 bg-gray-800 text-white p-4 z-10">
    <a href="#section1" class="mr-4 hover:underline">Section 1</a>
    <a href="#section2" class="mr-4 hover:underline">Section 2</a>
    <a href="#section3" class="hover:underline">Section 3</a>
  </nav>
  <main class="mt-16 space-y-4">
    <section id="section1" class="scroll-mt-20 bg-blue-100 p-8 h-screen">
      <h2 class="text-2xl font-bold">Section 1</h2>
      <p class="mt-4">scroll-mt-20 memberi jarak 80px di atas saat scroll ke sini.</p>
    </section>
    <section id="section2" class="scroll-mt-20 bg-green-100 p-8 h-screen">
      <h2 class="text-2xl font-bold">Section 2</h2>
      <p class="mt-4">Navbar tidak akan menutupi konten berkat scroll margin.</p>
    </section>
    <section id="section3" class="scroll-mt-20 bg-purple-100 p-8 h-screen">
      <h2 class="text-2xl font-bold">Section 3</h2>
      <p class="mt-4">Coba klik link navigasi di atas.</p>
    </section>
  </main>
</body>
</html>
```

## Poin Penting
- scroll-mt mengompensasi navbar fixed pada anchor scrolling
- Berguna untuk scroll snap dan smooth scroll behavior
- Menggunakan properti CSS scroll-margin
