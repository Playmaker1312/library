# Menggunakan scroll padding yaitu scroll-pt dan scroll-pb

## Analogi: Perpustakaan Digital

Jika scroll margin memberi jarak di luar elemen, scroll padding memberi jarak di dalam container scroll. Ini seperti memberi bantalan di tepi area gulir perpustakaan digital sehingga konten tidak menyentuh tepi viewport saat discroll. Scroll padding memastikan konten memiliki ruang bernapas di area scroll.

## Penjelasan Detail

Scroll padding utilities (`scroll-pt-{nilai}`, `scroll-pb-{nilai}`, `scroll-pl-{nilai}`, `scroll-pr-{nilai}`, `scroll-px-{nilai}`, `scroll-py-{nilai}`) mengatur padding pada scroll container. Berbeda dengan scroll margin yang diterapkan pada target, scroll padding diterapkan pada container scroll. Nilai menggunakan spacing scale Tailwind. Scroll padding sangat berguna pada scroll snap containers untuk memberi jarak sebelum snap terjadi. Properti CSS yang digunakan adalah `scroll-padding`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Scroll Padding Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8">
  <h1 class="text-2xl font-bold mb-4">Scroll Padding</h1>
  <div class="scroll-pt-8 flex overflow-x-auto space-x-4 p-4 bg-gray-100 rounded-lg">
    <div class="min-w-[300px] bg-blue-500 text-white p-8 rounded-lg h-48 flex items-center justify-center text-xl">Kartu 1</div>
    <div class="min-w-[300px] bg-green-500 text-white p-8 rounded-lg h-48 flex items-center justify-center text-xl">Kartu 2</div>
    <div class="min-w-[300px] bg-red-500 text-white p-8 rounded-lg h-48 flex items-center justify-center text-xl">Kartu 3</div>
    <div class="min-w-[300px] bg-purple-500 text-white p-8 rounded-lg h-48 flex items-center justify-center text-xl">Kartu 4</div>
  </div>
  <p class="mt-4 text-gray-600">scroll-pt-8 memberi padding scroll di atas container.</p>
</body>
</html>
```

## Poin Penting
- Scroll padding diterapkan pada container scroll, bukan target
- Berguna untuk scroll snap containers
- Menggunakan properti CSS scroll-padding
