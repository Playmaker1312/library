# Menggunakan gap, gap-x, dan gap-y untuk jarak di dalam flex dan grid container

## Analogi: Perpustakaan Digital

Jika koleksi buku disusun dalam rak grid (baris dan kolom), gap adalah jarak antar rak buku. `gap` mengatur jarak antara baris dan kolom sekaligus. `gap-x` khusus jarak antar kolom, `gap-y` khusus jarak antar baris. Ini seperti menentukan lebar lorong antar rak buku secara konsisten.

## Penjelasan Detail

Gap utilities (`gap-{nilai}`, `gap-x-{nilai}`, `gap-y-{nilai}`) digunakan pada flexbox dan grid container. Gap menggantikan margin pada child untuk memberi jarak yang konsisten. Berbeda dengan space utilities yang hanya memberi jarak antar sibling, gap bekerja di kedua arah pada grid. Gap mengikuti spacing scale standar Tailwind. Pada flexbox, gap-x memengaruhi jarak antar item dalam satu baris, gap-y jarak antar baris. Gap lebih modern dan lebih mudah digunakan dibanding margin manual.

## Poin Penting
- `gap` untuk baris dan kolom sekaligus, `gap-x` dan `gap-y` untuk masing-masing arah
- Berfungsi di flexbox dan grid container
- Lebih praktis daripada margin manual pada child
