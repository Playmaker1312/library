# Menggunakan flex-1, flex-auto, flex-initial, dan flex-none untuk flex grow dan shrink

## Analogi: Perpustakaan Digital

Flex grow dan shrink seperti mengatur bagaimana buku membagi ruang kosong di rak. `flex-1` membuat buku tumbuh merata mengisi ruang (seperti buku yang melebar). `flex-auto` tumbuh tapi berdasarkan ukuran konten. `flex-initial` tumbuh hanya jika perlu. `flex-none` tidak mau tumbuh atau menyusut. Seperti buku yang bersedia menyesuaikan ukuran untuk mengisi rak.

## Penjelasan Detail

Flex utilities adalah shorthand untuk `flex-grow`, `flex-shrink`, dan `flex-basis`. `flex-1` setara dengan `flex: 1 1 0%` (tumbuh merata). `flex-auto` setara dengan `flex: 1 1 auto` (tumbuh berdasarkan konten). `flex-initial` setara dengan `flex: 0 1 auto` (default, tidak tumbuh). `flex-none` setara dengan `flex: 0 0 auto` (tidak tumbuh atau menyusut). Sangat penting untuk layout sidebar dan konten utama, navigasi, dan distribusi ruang dinamis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Flex Grow Shrink Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Flex Grow & Shrink</h1>
  <div class="flex bg-gray-100 p-2 space-x-2">
    <div class="bg-blue-500 text-white p-3 flex-1">flex-1</div>
    <div class="bg-blue-500 text-white p-3 flex-1">flex-1</div>
    <div class="bg-blue-500 text-white p-3 flex-1">flex-1</div>
  </div>
  <div class="flex bg-gray-100 p-2 space-x-2">
    <div class="bg-green-500 text-white p-3 flex-1">flex-1</div>
    <div class="bg-green-500 text-white p-3 flex-auto">flex-auto</div>
    <div class="bg-green-500 text-white p-3 flex-none">flex-none</div>
  </div>
  <div class="flex bg-gray-100 p-2 space-x-2">
    <div class="bg-red-500 text-white p-3 w-32 flex-none">flex-none w-32</div>
    <div class="bg-red-500 text-white p-3 flex-1">flex-1 (sisa ruang)</div>
  </div>
  <div class="flex bg-gray-100 p-2 space-x-2">
    <div class="bg-purple-500 text-white p-3 flex-initial">flex-initial</div>
    <div class="bg-purple-500 text-white p-3 flex-initial w-48">flex-initial w-48</div>
  </div>
</body>
</html>
```

## Poin Penting
- `flex-1` untuk distribusi merata (grow: 1, shrink: 1, basis: 0%)
- `flex-none` mencegah pertumbuhan dan penyusutan
- `flex-auto` grow berdasarkan ukuran konten
