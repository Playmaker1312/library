# Menggunakan flex-row, flex-row-reverse, flex-col, dan flex-col-reverse

## Analogi: Perpustakaan Digital

Flex-direction seperti menentukan arah susunan buku di rak. `flex-row` menyusun buku dari kiri ke kanan (default). `flex-row-reverse` dari kanan ke kiri. `flex-col` menyusun buku dari atas ke bawah. `flex-col-reverse` dari bawah ke atas. Seperti memilih apakah koleksi buku disusun horizontal atau vertikal.

## Penjelasan Detail

Flex direction utilities mengatur properti CSS `flex-direction`. `flex-row` (default) menyusun item secara horizontal, sumbu utama dari kiri ke kanan. `flex-row-reverse` membalik urutan horizontal. `flex-col` menyusun item secara vertikal, sumbu utama dari atas ke bawah. `flex-col-reverse` membalik urutan vertikal. Mengubah flex direction juga mengubah arah justify-content dan align-items. Flex-col sangat berguna untuk layout mobile-first yang kemudian berubah ke flex-row di layar lebih besar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Flex Direction Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Flex Direction</h1>
  <div>
    <h2 class="font-semibold">flex-row</h2>
    <div class="flex flex-row bg-gray-100 p-2 space-x-2">
      <div class="bg-blue-500 text-white p-3">1</div>
      <div class="bg-blue-500 text-white p-3">2</div>
      <div class="bg-blue-500 text-white p-3">3</div>
    </div>
  </div>
  <div>
    <h2 class="font-semibold">flex-row-reverse</h2>
    <div class="flex flex-row-reverse bg-gray-100 p-2 space-x-2 space-x-reverse">
      <div class="bg-green-500 text-white p-3">1</div>
      <div class="bg-green-500 text-white p-3">2</div>
      <div class="bg-green-500 text-white p-3">3</div>
    </div>
  </div>
  <div>
    <h2 class="font-semibold">flex-col</h2>
    <div class="flex flex-col bg-gray-100 p-2 space-y-2">
      <div class="bg-red-500 text-white p-3">1</div>
      <div class="bg-red-500 text-white p-3">2</div>
      <div class="bg-red-500 text-white p-3">3</div>
    </div>
  </div>
  <div>
    <h2 class="font-semibold">flex-col-reverse</h2>
    <div class="flex flex-col-reverse bg-gray-100 p-2 space-y-2">
      <div class="bg-purple-500 text-white p-3">1</div>
      <div class="bg-purple-500 text-white p-3">2</div>
      <div class="bg-purple-500 text-white p-3">3</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `flex-row` horizontal (default), `flex-col` vertikal
- Versi reverse membalik urutan item
- Sering digunakan untuk layout responsive mobile-first
