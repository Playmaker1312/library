# Membangun layout praktis menggunakan kombinasi flexbox utilities Tailwind

## Analogi: Perpustakaan Digital

Saat membangun tata letak lengkap perpustakaan digital, kita menggabungkan berbagai flexbox utilities: flex container, arah, pembungkusan, perataan, dan distribusi. Seperti merancang seluruh ruangan perpustakaan dengan berbagai jenis rak yang ditata rapi dan fungsional.

## Penjelasan Detail

Layout praktis dengan flexbox menggabungkan multiple utilities: `<div class="flex flex-wrap items-center justify-between">` untuk navbar, `<div class="flex flex-col md:flex-row">` untuk layout sidebar, `<div class="flex items-center justify-center">` untuk centering. Kombinasi dengan gap, padding, dan responsive breakpoints menciptakan layout yang adaptif. Praktik terbaik: gunakan flex-col pada mobile, flex-row pada layar lebih besar. Manfaatkan flex-1 untuk distribusi ruang dinamis.

```html

<body class="min-h-screen flex flex-col">

        <li><a href="#" class="hover:text-yellow-300">Kontak</a></li>
      </ul>
    </nav>
  </header>
  <main class="flex-1 flex flex-col md:flex-row p-4 gap-4">
    <aside class="bg-gray-100 p-4 rounded md:w-48 flex-none">
      <h2 class="font-bold mb-2">Kategori</h2>

        <li>Fiksi</li>
        <li>Non-fiksi</li>

        <li>Teknologi</li>
      </ul>
    </aside>

      <h1 class="text-2xl font-bold mb-4">Koleksi Buku</h1>

        <div class="bg-white shadow rounded p-4 w-full sm:w-[calc(50%-8px)] lg:w-[calc(33.33%-11px)]">
          <h3 class="font-semibold">Buku 1</h3>

        </div>

        <div class="bg-white shadow rounded p-4 w-full sm:w-[calc(50%-8px)] lg:w-[calc(33.33%-11px)]">

```

## Poin Penting
- Kombinasikan flex-col (mobile) dengan flex-row (desktop)
- Gunakan flex-1 untuk area konten utama
- flex-wrap untuk grid card yang responsif
