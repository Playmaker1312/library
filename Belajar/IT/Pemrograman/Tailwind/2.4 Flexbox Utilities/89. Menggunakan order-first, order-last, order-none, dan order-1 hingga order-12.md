# Menggunakan order-first, order-last, order-none, dan order-1 hingga order-12

## Analogi: Perpustakaan Digital

Order utilities seperti mengatur ulang urutan buku di rak tanpa mengubah urutan di HTML. `order-first` memindahkan buku ke posisi pertama, `order-last` ke posisi terakhir, `order-none` kembali ke urutan default. `order-1` hingga `order-12` untuk urutan spesifik. Seperti menata ulang koleksi tanpa memindahkan fisik buku.

## Penjelasan Detail

Order utilities mengatur properti CSS `order`. Nilai default adalah 0. `order-first` (order: -9999) memindahkan ke awal. `order-last` (order: 9999) ke akhir. `order-none` (order: 0) default. `order-1` hingga `order-12` untuk urutan spesifik dengan nilai 1 hingga 12. Semakin kecil nilai order, semakin awal posisinya. Berguna untuk mengubah urutan visual tanpa mengubah markup HTML, terutama penting untuk layout responsif dan accessibility.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Order Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Order Utilities</h1>
  <div class="flex bg-gray-100 p-2 space-x-2">
    <div class="bg-blue-500 text-white p-4 order-last">1 (order-last)</div>
    <div class="bg-blue-500 text-white p-4 order-first">2 (order-first)</div>
    <div class="bg-blue-500 text-white p-4 order-2">3 (order-2)</div>
    <div class="bg-blue-500 text-white p-4">4 (default)</div>
  </div>
  <p class="text-sm text-gray-500">Urutan visual: 2 (first), 3 (order-2), 4 (default), 1 (last)</p>
  <div class="flex bg-gray-100 p-2 space-x-2">
    <div class="bg-green-500 text-white p-4 order-3">A (order-3)</div>
    <div class="bg-green-500 text-white p-4 order-1">B (order-1)</div>
    <div class="bg-green-500 text-white p-4 order-2">C (order-2)</div>
  </div>
  <p class="text-sm text-gray-500">B, C, A (urutan berdasarkan nilai order: 1, 2, 3)</p>
</body>
</html>
```

## Poin Penting
- `order-first` (-9999) dan `order-last` (9999) untuk posisi ekstrem
- `order-1` hingga `order-12` untuk urutan spesifik
- Mengubah urutan visual tanpa mengubah markup HTML
