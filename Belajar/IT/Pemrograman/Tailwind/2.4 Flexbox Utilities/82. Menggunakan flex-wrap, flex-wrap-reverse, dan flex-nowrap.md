# Menggunakan flex-wrap, flex-wrap-reverse, dan flex-nowrap

## Analogi: Perpustakaan Digital

Flex-wrap seperti mengatur apakah buku yang tidak muat dalam satu baris akan turun ke baris berikutnya atau tetap dipaksakan dalam satu baris. `flex-wrap` mengizinkan buku turun ke baris baru jika tidak muat. `flex-wrap-reverse` turun ke baris baru dengan urutan terbalik. `flex-nowrap` memaksa semua buku tetap dalam satu baris (default).

## Penjelasan Detail

Flex-wrap utilities mengatur properti CSS `flex-wrap`. `flex-wrap` (flex-wrap: wrap) mengizinkan item flex untuk membungkus ke baris baru jika tidak cukup ruang. `flex-wrap-reverse` sama tetapi baris baru muncul di atas. `flex-nowrap` (default) memaksa semua item tetap dalam satu baris, yang dapat menyebabkan overflow. Flex-wrap sangat penting untuk layout responsif, memastikan item tidak overflow dan tetap terlihat di semua ukuran layar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Flex Wrap Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-6">
  <h1 class="text-2xl font-bold">Flex Wrap</h1>
  <div>
    <h2 class="font-semibold">flex-nowrap (default - overflow)</h2>
    <div class="flex flex-nowrap bg-gray-100 p-2 w-64 overflow-x-auto">
      <div class="bg-blue-500 text-white p-4 w-32 shrink-0">Item 1</div>
      <div class="bg-blue-500 text-white p-4 w-32 shrink-0">Item 2</div>
      <div class="bg-blue-500 text-white p-4 w-32 shrink-0">Item 3</div>
      <div class="bg-blue-500 text-white p-4 w-32 shrink-0">Item 4</div>
    </div>
  </div>
  <div>
    <h2 class="font-semibold">flex-wrap (turun ke baris baru)</h2>
    <div class="flex flex-wrap bg-gray-100 p-2 w-64 gap-2">
      <div class="bg-green-500 text-white p-4">Item 1</div>
      <div class="bg-green-500 text-white p-4">Item 2</div>
      <div class="bg-green-500 text-white p-4">Item 3</div>
      <div class="bg-green-500 text-white p-4">Item 4</div>
      <div class="bg-green-500 text-white p-4">Item 5</div>
    </div>
  </div>
  <div>
    <h2 class="font-semibold">flex-wrap-reverse</h2>
    <div class="flex flex-wrap-reverse bg-gray-100 p-2 w-64 gap-2">
      <div class="bg-red-500 text-white p-4">Item 1</div>
      <div class="bg-red-500 text-white p-4">Item 2</div>
      <div class="bg-red-500 text-white p-4">Item 3</div>
      <div class="bg-red-500 text-white p-4">Item 4</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `flex-wrap` mengizinkan item turun ke baris baru
- `flex-nowrap` (default) memaksa satu baris
- `flex-wrap-reverse` wrap dengan urutan terbalik
