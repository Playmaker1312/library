# Menggunakan justify-content yaitu justify-start, justify-end, justify-center, justify-between, justify-around, dan justify-evenly

## Analogi: Perpustakaan Digital

Justify-content seperti mengatur distribusi buku dalam satu baris rak. `justify-start` mengumpulkan buku di awal, `justify-end` di akhir, `justify-center` di tengah. `justify-between` memberi jarak merata antar buku (tanpa jarak di tepi), `justify-around` dengan jarak setengah di tepi, `justify-evenly` dengan jarak sama di semua sisi.

## Penjelasan Detail

Justify-content utilities mengatur perataan item pada sumbu utama (main axis). Pada `flex-row`, sumbu utama adalah horizontal. `justify-start` (default) merapat ke kiri/atas. `justify-end` ke kanan/bawah. `justify-center` ke tengah. `justify-between` distribusi merata dengan item pertama di awal dan terakhir di akhir. `justify-around` distribusi dengan ruang setengah di tepi. `justify-evenly` distribusi dengan jarak identik. Sangat penting untuk tata letak navigasi, header, dan distribusi konten.

```html
  <h1 class="text-2xl font-bold">Justify Content</h1>
  <div class="flex justify-start bg-gray-100 p-2 space-x-2">

    <div class="bg-blue-500 text-white p-3">start</div>
  </div>
  <div class="flex justify-end bg-gray-100 p-2 space-x-2">
    <div class="bg-green-500 text-white p-3">end</div>
    <div class="bg-green-500 text-white p-3">end</div>
  </div>
  <div class="flex justify-center bg-gray-100 p-2 space-x-2">
    <div class="bg-red-500 text-white p-3">center</div>
    <div class="bg-red-500 text-white p-3">center</div>
  </div>
  <div class="flex justify-between bg-gray-100 p-2">
    <div class="bg-purple-500 text-white p-3">kiri</div>
    <div class="bg-purple-500 text-white p-3">kanan</div>
  </div>
  <div class="flex justify-around bg-gray-100 p-2">
    <div class="bg-yellow-500 text-white p-3">A</div>
    <div class="bg-yellow-500 text-white p-3">B</div>
    <div class="bg-yellow-500 text-white p-3">C</div>
  </div>
  <div class="flex justify-evenly bg-gray-100 p-2">
    <div class="bg-indigo-500 text-white p-3">1</div>
    <div class="bg-indigo-500 text-white p-3">2</div>
    <div class="bg-indigo-500 text-white p-3">3</div>
    <div class="bg-indigo-500 text-white p-3">4</div>
  </div>
</body>
</html>
```

## Poin Penting
- Mengatur perataan item pada sumbu utama flexbox
- `justify-between`, `around`, `evenly` untuk distribusi ruang
- `justify-center` untuk menengahkan item secara horizontal
