# Menggunakan focus-visible prefix untuk styling fokus yang terlihat

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang membedakan antara navigasi keyboard dan klik mouse. focus-visible seperti menyorot elemen hanya saat pengguna menggunakan keyboard (Tab), bukan saat mengklik dengan mouse. Ini memungkinkan Anda menampilkan ring fokus hanya saat diperlukan untuk navigasi keyboard. Seperti memberikan petunjuk jalan hanya untuk pejalan kaki, bukan untuk pengemudi mobil.

## Penjelasan Detail
focus-visible: menerapkan gaya hanya ketika elemen menerima fokus melalui navigasi keyboard (biasanya tombol Tab), bukan melalui klik mouse. Utility ini menggunakan CSS pseudo-class :focus-visible. Ini menyelesaikan masalah umum di mana ring fokus muncul saat tombol diklik, yang dianggap tidak estetis oleh banyak desainer. Dengan focus-visible, ring fokus hanya muncul untuk pengguna keyboard, memberikan pengalaman bersih untuk pengguna mouse sekaligus tetap aksesibel untuk pengguna keyboard. Tailwind merekomendasikan penggunaan focus-visible:ring-2 sebagai pengganti focus:ring untuk menghindari ring yang muncul saat klik. Ini adalah praktik terbaik untuk aksesibilitas modern.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Focus Visible</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-10 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">focus-visible vs focus</h2>
    <div class="flex gap-8">
        <div class="flex flex-col items-center gap-4">
            <button class="focus:ring-2 focus:ring-blue-500 focus:outline-none bg-blue-500 text-white font-bold px-8 py-4 rounded-xl">
                focus:ring
            </button>
            <p class="text-gray-400 text-xs text-center">Ring muncul saat klik<br>dan keyboard</p>
        </div>
        <div class="flex flex-col items-center gap-4">
            <button class="focus-visible:ring-2 focus-visible:ring-green-500 focus:outline-none bg-green-500 text-white font-bold px-8 py-4 rounded-xl">
                focus-visible:ring
            </button>
            <p class="text-gray-400 text-xs text-center">Ring hanya saat<br>navigasi keyboard</p>
        </div>
    </div>
    <div class="flex gap-6">
        <a href="#" class="focus-visible:ring-2 focus-visible:ring-purple-500 focus:outline-none text-purple-400 hover:text-purple-300 text-lg font-semibold px-4 py-2 rounded">
            Tautan 1
        </a>
        <a href="#" class="focus-visible:ring-2 focus-visible:ring-purple-500 focus:outline-none text-purple-400 hover:text-purple-300 text-lg font-semibold px-4 py-2 rounded">
            Tautan 2
        </a>
    </div>
    <div class="bg-gray-800 p-6 rounded-xl max-w-lg text-center">
        <p class="text-gray-300">Klik tombol dengan mouse tidak akan menampilkan ring pada <code class="text-green-400">focus-visible</code>. Gunakan Tab untuk navigasi keyboard.</p>
    </div>
</body>
</html>
```

## Poin Penting
- focus-visible: menampilkan fokus hanya untuk navigasi keyboard, bukan klik mouse.
- Mencegah ring fokus muncul saat tombol diklik, memberikan tampilan yang lebih bersih.
- Praktik terbaik aksesibilitas modern: gunakan focus-visible:ring sebagai pengganti focus:ring.
