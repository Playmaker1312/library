# Menggunakan focus-within prefix untuk styling parent saat child difokus

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang memiliki grup formulir yang menyala saat salah satu input di dalamnya difokuskan. focus-within seperti lampu di ruang baca yang menyala saat ada orang di dalamnya. Ini memungkinkan Anda memberi gaya pada elemen parent ketika salah satu anaknya menerima fokus. Seperti ruangan yang terang saat ada aktivitas, focus-within menandai grup yang sedang aktif.

## Penjelasan Detail
focus-within: menerapkan gaya pada elemen parent ketika salah satu turunannya (child) memiliki fokus. Utility ini menggunakan CSS pseudo-class :focus-within. Tidak seperti focus yang hanya berlaku pada elemen itu sendiri, focus-within merambat ke parent. Sangat berguna untuk styling grup formulir, kartu dengan input, atau container pencarian. Efek umum termasuk mengubah border parent, menambahkan shadow, atau mengubah warna label. focus-within juga bisa digunakan untuk menampilkan elemen yang sebelumnya tersembunyi saat child difokuskan. Ini meningkatkan UX dengan memberikan konteks visual yang lebih luas.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Focus Within</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-8 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">focus-within</h2>
    <div class="focus-within:ring-2 focus-within:ring-blue-500 focus-within:border-blue-500 transition-all bg-gray-800 border border-gray-600 rounded-xl p-1 w-80">
        <input type="text" placeholder="Cari di sini..." class="bg-transparent text-white px-4 py-3 w-full outline-none">
    </div>
    <div class="focus-within:border-green-500 focus-within:shadow-lg focus-within:shadow-green-500/10 transition-all bg-gray-800 border border-gray-600 rounded-xl p-6 w-80 space-y-4">
        <label class="text-gray-300 text-sm font-semibold">Formulir Pendaftaran</label>
        <input type="text" placeholder="Nama" class="focus:ring-2 focus:ring-green-500 focus:outline-none bg-gray-700 border border-gray-600 text-white px-4 py-3 rounded-lg w-full transition-all">
        <input type="email" placeholder="Email" class="focus:ring-2 focus:ring-green-500 focus:outline-none bg-gray-700 border border-gray-600 text-white px-4 py-3 rounded-lg w-full transition-all">
    </div>
    <div class="focus-within:bg-gray-800/80 transition-all bg-gray-800 border border-gray-700 rounded-xl p-6 w-80">
        <p class="text-gray-400 text-sm mb-3">Klik di dalam area ini</p>
        <input type="text" placeholder="Input di sini..." class="focus:ring-2 focus:ring-purple-500 focus:outline-none bg-gray-700 border border-gray-600 text-white px-4 py-3 rounded-lg w-full transition-all">
    </div>
    <p class="text-gray-400 text-sm">Parent akan berubah saat input di dalamnya difokuskan</p>
</body>
</html>
```

## Poin Penting
- focus-within: memberi gaya pada parent ketika salah satu child-nya menerima fokus.
- Ideal untuk grup formulir, kotak pencarian, atau kartu yang mengandung input.
- Meningkatkan UX dengan memberikan konteks visual yang lebih luas dari sekadar elemen input.
