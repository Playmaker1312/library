# Menggunakan hover prefix untuk styling saat elemen dihover

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang mengubah tampilan buku saat kursor mouse mendekatinya. hover: seperti menyorot buku dengan senter saat Anda mendekatkannya, buku tersebut berubah warna, membesar sedikit, atau menampilkan informasi tambahan. Ini memberikan feedback visual bahwa elemen tersebut interaktif. Seperti rak buku yang bereaksi saat Anda mendekat, hover meningkatkan pengalaman eksplorasi.

## Penjelasan Detail
hover: adalah variant paling umum di Tailwind yang menerapkan gaya hanya ketika pengguna mengarahkan kursor ke elemen. Anda bisa menambahkan hover: di depan utility apa pun: hover:bg-blue-600, hover:scale-105, hover:shadow-lg, hover:text-white, dll. hover bekerja dengan CSS pseudo-class :hover. Penting untuk diingat bahwa hover tidak berfungsi dengan baik di perangkat sentuh karena tidak ada konsep "hover" pada layar sentuh. Untuk perangkat mobile, gunakan active: atau focus: sebagai alternatif. hover sering dikombinasikan dengan transition untuk efek yang halus.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hover State</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-wrap items-center justify-center gap-6 p-10 min-h-screen bg-gray-900">
    <button class="hover:bg-blue-600 hover:scale-105 hover:shadow-lg transition-all bg-blue-500 text-white font-bold px-8 py-4 rounded-xl">
        Hover Saya
    </button>
    <button class="hover:bg-green-600 hover:-translate-y-1 hover:shadow-lg transition-all bg-green-500 text-white font-bold px-8 py-4 rounded-xl">
        Angkat Hover
    </button>
    <button class="hover:border-blue-400 hover:text-blue-300 transition-all bg-transparent border-2 border-gray-500 text-gray-300 font-bold px-8 py-4 rounded-xl">
        Border Hover
    </button>
    <div class="group cursor-pointer">
        <div class="hover:rotate-6 hover:scale-105 transition-transform bg-gradient-to-br from-purple-500 to-pink-500 w-36 h-28 rounded-xl flex items-center justify-center text-white font-bold">
            Putar
        </div>
        <p class="text-gray-400 text-sm text-center mt-2 opacity-0 group-hover:opacity-100 transition-opacity">Teks muncul saat hover</p>
    </div>
    <a href="#" class="hover:text-yellow-300 hover:underline transition-all text-white text-lg font-semibold">
        Tautan dengan hover
    </a>
</body>
</html>
```

## Poin Penting
- hover: menerapkan gaya saat kursor berada di atas elemen, menggunakan CSS :hover.
- Kombinasikan dengan transition untuk animasi yang halus dan profesional.
- hover tidak berfungsi di perangkat sentuh, sediakan alternatif active: atau focus: untuk mobile.
