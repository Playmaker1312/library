# Menggunakan checked prefix untuk styling checkbox atau radio yang dicentang

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang memiliki daftar buku yang bisa ditandai sebagai "sedang dibaca". checked: seperti mencentang buku di daftar bacaan Anda, yang mengubah tampilannya menjadi berbeda. Ini memberikan feedback visual bahwa opsi telah dipilih atau diaktifkan. Seperti memberi stempel pada kartu perpustakaan, checked menandai status terpilih.

## Penjelasan Detail
checked: menerapkan gaya pada elemen input seperti checkbox atau radio yang memiliki status checked (dicontreng/dipilih). Utility ini menggunakan CSS pseudo-class :checked. checked dapat mengubah warna background, border, atau menambahkan efek visual lainnya pada elemen saat dicentang. Karena browser memiliki style default untuk checkbox dan radio, Tailwind menyediakan utility appearance-none untuk menghilangkan style default dan memungkinkan kustomisasi penuh. checked sering digunakan bersama peer variant untuk menyebarkan efek ke sibling elemen. Untuk aksesibilitas, pastikan status checked tetap jelas terlihat bahkan tanpa warna.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Checked State</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-8 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">Checked State</h2>
    <div class="space-y-4">
        <label class="flex items-center gap-3 cursor-pointer">
            <input type="checkbox" class="checked:bg-blue-500 checked:border-blue-500 appearance-none w-6 h-6 border-2 border-gray-500 rounded bg-gray-800 transition-all cursor-pointer">
            <span class="text-white">Opsi 1</span>
        </label>
        <label class="flex items-center gap-3 cursor-pointer">
            <input type="checkbox" class="checked:bg-green-500 checked:border-green-500 appearance-none w-6 h-6 border-2 border-gray-500 rounded bg-gray-800 transition-all cursor-pointer">
            <span class="text-white">Opsi 2</span>
        </label>
        <label class="flex items-center gap-3 cursor-pointer">
            <input type="checkbox" class="checked:bg-purple-500 checked:border-purple-500 appearance-none w-6 h-6 border-2 border-gray-500 rounded bg-gray-800 transition-all cursor-pointer" checked>
            <span class="text-white">Opsi 3 (default checked)</span>
        </label>
    </div>
    <div class="space-y-4">
        <label class="flex items-center gap-3 cursor-pointer">
            <input type="radio" name="radio" class="checked:bg-pink-500 checked:border-pink-500 appearance-none w-6 h-6 border-2 border-gray-500 rounded-full bg-gray-800 transition-all cursor-pointer">
            <span class="text-white">Radio 1</span>
        </label>
        <label class="flex items-center gap-3 cursor-pointer">
            <input type="radio" name="radio" class="checked:bg-pink-500 checked:border-pink-500 appearance-none w-6 h-6 border-2 border-gray-500 rounded-full bg-gray-800 transition-all cursor-pointer">
            <span class="text-white">Radio 2</span>
        </label>
    </div>
</body>
</html>
```

## Poin Penting
- checked: untuk styling checkbox/radio yang dicentang, sering dengan appearance-none untuk kustomisasi penuh.
- checked mengubah tampilan saat opsi dipilih, memberikan feedback status yang jelas.
- Kombinasikan dengan peer variant untuk mempengaruhi elemen lain saat dicentang.
