# Menggunakan focus prefix untuk styling saat elemen difokus

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang menyorot kotak pencarian saat Anda mulai mengetik. focus: seperti lampu yang menyala di meja baca saat Anda duduk dan mulai membaca. Ini menunjukkan elemen mana yang sedang aktif dan siap menerima input. Seperti menyorot halaman yang sedang dibaca, focus membantu pengguna mengetahui posisi mereka dalam formulir.

## Penjelasan Detail
focus: menerapkan gaya ketika elemen menerima fokus, biasanya melalui klik atau navigasi keyboard (Tab). Utility ini sangat penting untuk aksesibilitas karena membantu pengguna keyboard mengetahui elemen mana yang aktif. Contoh penggunaan: focus:ring-2 focus:ring-blue-500 focus:outline-none untuk memberikan ring fokus yang terlihat, focus:border-blue-500 untuk mengubah warna border, focus:bg-gray-100 untuk mengubah latar belakang. focus:ring sangat direkomendasikan untuk menggantikan outline default browser yang tidak konsisten. Selalu pastikan elemen fokus memiliki indikator visual yang jelas untuk kepatuhan WCAG.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Focus State</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-8 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">Focus State</h2>
    <input type="text" placeholder="Klik di sini..." class="focus:ring-2 focus:ring-blue-500 focus:outline-none focus:border-blue-500 transition-all bg-gray-800 border border-gray-600 text-white px-6 py-4 rounded-xl w-80">
    <input type="email" placeholder="Email..." class="focus:ring-2 focus:ring-green-500 focus:outline-none focus:border-green-500 transition-all bg-gray-800 border border-gray-600 text-white px-6 py-4 rounded-xl w-80">
    <button class="focus:ring-2 focus:ring-purple-500 focus:outline-none focus:scale-105 transition-all bg-purple-500 text-white font-bold px-8 py-4 rounded-xl">
        Tombol Focus
    </button>
    <textarea placeholder="Teks area..." class="focus:ring-2 focus:ring-pink-500 focus:outline-none transition-all bg-gray-800 border border-gray-600 text-white px-6 py-4 rounded-xl w-80 h-32 resize-none"></textarea>
    <p class="text-gray-400 text-sm">Tekan Tab untuk navigasi keyboard dan lihat efek focus</p>
</body>
</html>
```

## Poin Penting
- focus: menerapkan gaya saat elemen aktif (klik atau Tab), penting untuk aksesibilitas keyboard.
- Gunakan focus:ring-2 dan focus:outline-none untuk indikator fokus kustom yang konsisten.
- Indikator fokus wajib untuk kepatuhan WCAG, jangan menghapus outline tanpa pengganti.
