# Menggunakan peer dan peer-checked untuk styling sibling berdasarkan state elemen lain

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan digital yang memiliki dua rak buku bersebelahan. Saat satu rak dikunjungi, rak di sebelahnya ikut terang. peer dan peer-checked seperti hubungan antara dua elemen yang bersebelahan di mana state satu memengaruhi yang lain. Ini memungkinkan Anda memberi gaya pada elemen berdasarkan state elemen saudara (sibling) sebelumnya. Seperti efek domino antar tetangga di perpustakaan.

## Penjelasan Detail
peer adalah teknik yang mirip dengan group, tetapi bekerja pada elemen saudara (sibling) bukan parent-child. Anda menambahkan class peer ke elemen pertama, lalu menggunakan variant seperti peer-hover:, peer-focus:, peer-checked:, atau peer-disabled: pada elemen saudara setelahnya. peer sangat berguna untuk input checkbox atau radio kustom di mana label elemen berubah saat input dicentang. peer hanya memengaruhi elemen saudara yang muncul SETELAH elemen peer (dalam urutan DOM). peer-invalid dan peer-valid juga tersedia untuk validasi formulir. Teknik ini mengurangi kebutuhan akan JavaScript untuk interaksi sederhana antar elemen.

## Contoh Kode Implementasi
```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Peer State</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="flex flex-col items-center justify-center gap-10 p-10 min-h-screen bg-gray-900">
    <h2 class="text-white text-2xl font-bold">peer & peer-checked</h2>
    <div class="space-y-4 w-80">
        <label class="flex items-center gap-4 cursor-pointer">
            <input type="checkbox" class="peer appearance-none w-6 h-6 border-2 border-gray-500 rounded bg-gray-800 cursor-pointer">
            <span class="peer-checked:text-green-400 peer-checked:font-bold text-gray-400 transition-all">Aktifkan notifikasi</span>
        </label>
        <label class="flex items-center gap-4 cursor-pointer">
            <input type="checkbox" class="peer appearance-none w-6 h-6 border-2 border-gray-500 rounded bg-gray-800 cursor-pointer">
            <span class="peer-checked:text-blue-400 peer-checked:font-bold text-gray-400 transition-all">Mode gelap</span>
        </label>
        <label class="flex items-center gap-4 cursor-pointer">
            <input type="checkbox" class="peer appearance-none w-6 h-6 border-2 border-gray-500 rounded bg-gray-800 cursor-pointer">
            <span class="peer-checked:text-purple-400 peer-checked:font-bold text-gray-400 transition-all">Terima syarat & ketentuan</span>
        </label>
    </div>
    <div class="flex items-center gap-6">
        <input type="text" placeholder="Ketik sesuatu..." class="peer bg-gray-800 border border-gray-600 text-white px-4 py-3 rounded-xl w-64 outline-none focus:border-blue-500 transition-all">
        <span class="peer-invisible:text-gray-500 peer-valid:text-green-400 text-sm font-semibold transition-all">&#10003; Valid</span>
    </div>
    <div class="bg-gray-800 p-6 rounded-xl max-w-md text-center">
        <p class="text-gray-300">Centang checkbox di atas untuk melihat efek <code class="text-blue-400">peer-checked</code> pada teks di sebelahnya.</p>
    </div>
</body>
</html>
```

## Poin Penting
- peer: memungkinkan elemen saudara (sibling) bereaksi terhadap state elemen sebelumnya.
- peer-checked:, peer-hover:, peer-focus:, peer-invalid:, dll. tersedia untuk berbagai state.
- peer hanya memengaruhi elemen yang muncul SETELAH elemen peer dalam urutan DOM.
