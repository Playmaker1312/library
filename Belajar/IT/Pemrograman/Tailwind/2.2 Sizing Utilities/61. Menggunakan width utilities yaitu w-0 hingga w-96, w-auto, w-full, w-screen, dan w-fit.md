# Menggunakan width utilities yaitu w-0 hingga w-96, w-auto, w-full, w-screen, dan w-fit

## Analogi: Perpustakaan Digital

Width utilities seperti mengatur lebar rak buku digital. `w-0` seperti rak yang tidak terlihat, `w-96` seperti rak besar, `w-auto` membiarkan buku menentukan lebarnya sendiri, `w-full` mengisi seluruh ruang yang tersedia, `w-screen` selebar layar penuh, dan `w-fit` hanya selebar kontennya.

## Penjelasan Detail

Width utilities (`w-{nilai}`) menggunakan skala 0 hingga 96 (0px hingga 384px). `w-auto` membiarkan browser menghitung lebar berdasarkan konten. `w-full` setara dengan lebar 100% parent. `w-screen` setara dengan 100vw (lebar viewport). `w-fit` menggunakan `fit-content` sehingga lebar mengikuti konten. Semua width utilities dapat dikombinasikan dengan responsive breakpoints. Untuk lebar persentase pecahan, gunakan fractional width seperti `w-1/2`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Width Utilities Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Width Utilities</h1>
  <div class="bg-blue-500 text-white p-3 w-0 overflow-hidden">w-0</div>
  <div class="bg-blue-500 text-white p-3 w-24">w-24</div>
  <div class="bg-blue-500 text-white p-3 w-64">w-64</div>
  <div class="bg-blue-500 text-white p-3 w-96">w-96</div>
  <div class="bg-green-500 text-white p-3 w-auto">w-auto (ikut konten)</div>
  <div class="bg-red-500 text-white p-3 w-full">w-full</div>
  <div class="bg-purple-500 text-white p-3 w-fit">w-fit (fit content)</div>
  <div class="bg-yellow-500 text-white p-3 w-screen">w-screen (layar penuh)</div>
</body>
</html>
```

## Poin Penting
- Skala lebar dari 0 hingga 96 (kelipatan 4px)
- `w-full` = 100%, `w-screen` = 100vw, `w-fit` = fit-content
- Dapat dikombinasikan dengan breakpoint responsive
