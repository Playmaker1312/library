# Menggunakan min-height utilities yaitu min-h-0, min-h-full, dan min-h-screen

## Analogi: Perpustakaan Digital

Min-height seperti menentukan tinggi minimum sebuah rak buku. Meskipun hanya ada sedikit buku, rak harus memiliki tinggi minimal tertentu. `min-h-0` menghapus batas minimal, `min-h-full` memastikan setinggi container, `min-h-screen` memastikan setinggi layar. Berguna untuk layout yang harus memenuhi tinggi viewport.

## Penjelasan Detail

Min-height utilities (`min-h-{nilai}`) mengatur properti CSS `min-height`. Nilai meliputi `min-h-0`, `min-h-full`, `min-h-screen`, `min-h-min`, `min-h-max`, `min-h-fit`, dan nilai skala seperti `min-h-64`. `min-h-screen` sangat umum digunakan pada elemen utama halaman untuk memastikan konten minimal setinggi layar, sehingga footer tetap di bawah meskipun konten sedikit. `min-h-0` berguna pada flexbox untuk mengatasi default minimum height.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Min-Height Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body>
  <div class="min-h-screen bg-gradient-to-b from-blue-400 to-purple-500 p-8">
    <h1 class="text-2xl font-bold text-white">min-h-screen</h1>
    <p class="text-white mt-4">Halaman ini minimal setinggi viewport.</p>
    <div class="mt-8 bg-white/20 p-4 rounded">
      <div class="bg-white/30 p-4 min-h-full rounded">
        <p class="text-white">min-h-full di dalam container</p>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `min-h-screen` memastikan elemen setinggi viewport minimal
- `min-h-full` mengisi tinggi parent minimal
- `min-h-0` mengatasi overflow di flex/grid
