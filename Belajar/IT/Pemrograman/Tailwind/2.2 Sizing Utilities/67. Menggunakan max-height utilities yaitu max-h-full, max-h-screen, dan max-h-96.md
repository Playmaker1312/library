# Menggunakan max-height utilities yaitu max-h-full, max-h-screen, dan max-h-96

## Analogi: Perpustakaan Digital

Max-height seperti membatasi tinggi maksimal rak buku agar tidak terlalu tinggi. `max-h-96` membatasi hingga 384px, `max-h-screen` setinggi layar maksimal, `max-h-full` setinggi parent maksimal. Seperti rak yang dirancang tidak boleh melebihi tinggi langit-langit ruangan.

## Penjelasan Detail

Max-height utilities (`max-h-{nilai}`) mengatur properti CSS `max-height`. Nilai meliputi skala standar (`max-h-0` hingga `max-h-96`), `max-h-full` (100%), `max-h-screen` (100vh), `max-h-min` (min-content), `max-h-max` (max-content), `max-h-fit` (fit-content). Max-height sangat berguna untuk panel scrollable, modal, dropdown, dan elemen yang perlu dibatasi tingginya. Kombinasi `max-h-96` dengan `overflow-y-auto` sangat umum untuk membuat area scroll terbatas.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Max-Height Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Max-Height Utilities</h1>
  <div class="bg-blue-500 text-white p-4 max-h-32 overflow-y-auto w-64">
    <p>Item 1</p><p>Item 2</p><p>Item 3</p><p>Item 4</p>
    <p>Item 5</p><p>Item 6</p><p>Item 7</p><p>Item 8</p>
    <p class="text-yellow-300">Scroll ke bawah...</p>
  </div>
  <div class="bg-green-200" style="height: 100px;">
    <div class="bg-green-500 text-white p-4 max-h-full w-64">max-h-full</div>
  </div>
  <div class="bg-purple-500 text-white p-4 max-h-screen w-64">max-h-screen</div>
</body>
</html>
```

## Poin Penting
- `max-h-96` dengan `overflow-y-auto` untuk panel scrollable
- `max-h-screen` membatasi setinggi viewport
- Berguna untuk modal, dropdown, dan panel navigasi
