# Memahami arbitrary sizing values menggunakan kurung kotak

## Analogi: Perpustakaan Digital

Ketika ukuran rak standar tidak sesuai dengan buku khusus, arbitrary sizing memungkinkan pembuatan ukuran kustom. Seperti memesan rak dengan ukuran spesifik untuk koleksi buku antik yang tidak biasa. Tailwind mengizinkan nilai kapan pun melalui syntax kurung kotak untuk semua utility sizing.

## Penjelasan Detail

Arbitrary sizing values ditulis dengan format `w-[nilai]`, `h-[nilai]`, `min-w-[nilai]`, `max-h-[nilai]`, `size-[nilai]`, dan seterusnya. Nilai dapat berupa unit CSS apa pun: `w-[320px]`, `h-[50%]`, `min-w-[40vw]`, `max-h-[75vh]`, `size-[4.5rem]`. Arbitrary values juga mendukung fungsi CSS seperti `min-w-[calc(100%-2rem)]`. Fitur ini memberikan fleksibilitas penuh ketika nilai skala standar tidak mencukupi, tanpa harus menulis CSS kustom.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Arbitrary Sizing Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Arbitrary Sizing Values</h1>
  <div class="bg-blue-500 text-white p-4 w-[250px]">w-[250px]</div>
  <div class="bg-green-500 text-white p-4 max-w-[80%]">max-w-[80%]</div>
  <div class="flex space-x-4 items-end">
    <div class="bg-red-500 text-white size-[60px] flex items-center justify-center">size-[60px]</div>
    <div class="bg-purple-500 text-white w-[10rem] h-[4rem] flex items-center justify-center">w-[10rem]</div>
    <div class="bg-yellow-500 text-white p-4 h-[30vh]">h-[30vh]</div>
  </div>
  <div class="bg-indigo-500 text-white p-4 w-[calc(100%-4rem)]">w-[calc(100%-4rem)]</div>
</body>
</html>
```

## Poin Penting
- Syntax: `w-[nilai]`, `h-[nilai]`, `size-[nilai]` untuk nilai kustom
- Mendukung semua unit CSS dan fungsi calc()
- Memberikan fleksibilitas tanpa CSS kustom terpisah
