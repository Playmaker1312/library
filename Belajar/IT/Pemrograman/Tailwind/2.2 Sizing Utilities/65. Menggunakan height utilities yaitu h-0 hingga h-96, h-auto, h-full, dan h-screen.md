# Menggunakan height utilities yaitu h-0 hingga h-96, h-auto, h-full, dan h-screen

## Analogi: Perpustakaan Digital

Height utilities seperti mengatur tinggi rak buku digital. `h-0` rak tanpa tinggi, `h-96` rak tinggi, `h-auto` menyesuaikan tinggi konten, `h-full` mengisi tinggi container, `h-screen` setinggi layar penuh. Sama seperti memilih tinggi rak yang sesuai dengan koleksi buku.

## Penjelasan Detail

Height utilities (`h-{nilai}`) menggunakan skala yang sama dengan width: 0 hingga 96 (0px hingga 384px). `h-auto` membiarkan browser menghitung tinggi berdasarkan konten. `h-full` setara dengan 100% dari tinggi parent. `h-screen` setara dengan 100vh. Ada juga `h-min`, `h-max`, dan `h-fit` untuk min-content, max-content, dan fit-content. Height utilities penting untuk membuat layout full-height, hero sections, dan elemen dengan tinggi proporsional.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Height Utilities Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Height Utilities</h1>
  <div class="flex space-x-4 items-end">
    <div class="bg-blue-500 text-white p-2 w-16 h-16 flex items-center justify-center">h-16</div>
    <div class="bg-blue-500 text-white p-2 w-16 h-24 flex items-center justify-center">h-24</div>
    <div class="bg-blue-500 text-white p-2 w-16 h-48 flex items-center justify-center">h-48</div>
    <div class="bg-blue-500 text-white p-2 w-16 h-96 flex items-center justify-center">h-96</div>
  </div>
  <div class="bg-green-500 text-white p-4 h-auto w-64">h-auto (sesuai konten)</div>
  <div class="bg-red-200" style="height: 150px;">
    <div class="bg-red-500 text-white p-4 h-full">h-full (100% parent)</div>
  </div>
  <div class="bg-purple-500 text-white p-4 h-screen w-64">h-screen (100vh)</div>
</body>
</html>
```

## Poin Penting
- Skala tinggi dari 0 hingga 96 (kelipatan 4px)
- `h-full` = 100%, `h-screen` = 100vh
- `h-auto` menyesuaikan dengan konten secara otomatis
