# Menggunakan min-width utilities yaitu min-w-0, min-w-full, dan min-w-min

## Analogi: Perpustakaan Digital

Min-width seperti menentukan lebar minimal sebuah rak buku. Rak tidak boleh lebih kecil dari ukuran tertentu, meskipun kontennya sedikit. `min-w-0` menghapus batas minimal (seperti rak yang bisa menyempit), `min-w-full` memastikan lebar setidaknya 100% parent, `min-w-min` memastikan lebar minimal selebar konten terkecil.

## Penjelasan Detail

Min-width utilities (`min-w-{nilai}`) mengatur properti CSS `min-width`. Nilai meliputi `min-w-0` (0px), `min-w-full` (100%), `min-w-min` (min-content), `min-w-max` (max-content), `min-w-fit` (fit-content), dan nilai skala seperti `min-w-64`. `min-w-0` penting untuk mengatasi overflow pada flexbox dan grid. Berguna untuk memastikan elemen tidak mengecil melebihi batas tertentu dalam layout responsif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Min-Width Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Min-Width Utilities</h1>
  <div class="flex">
    <div class="bg-blue-500 text-white p-4 min-w-0 flex-1">min-w-0 flex-1 (bisa menyusut)</div>
    <div class="bg-green-500 text-white p-4 min-w-64">min-w-64 (min 256px)</div>
  </div>
  <div class="bg-red-200 p-4">
    <div class="bg-red-500 text-white p-4 min-w-full">min-w-full (setidaknya 100%)</div>
  </div>
  <div class="bg-purple-200 p-4">
    <div class="bg-purple-500 text-white p-4 min-w-min inline-block">min-w-min (min-content)</div>
  </div>
</body>
</html>
```

## Poin Penting
- `min-w-0` penting untuk mencegah overflow di flexbox
- `min-w-full` memastikan lebar minimal 100% parent
- `min-w-min` menggunakan min-content CSS
