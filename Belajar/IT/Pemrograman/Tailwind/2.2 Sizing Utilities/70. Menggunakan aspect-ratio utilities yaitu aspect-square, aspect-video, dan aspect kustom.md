# Menggunakan aspect-ratio utilities yaitu aspect-square, aspect-video, dan aspect kustom

## Analogi: Perpustakaan Digital

Aspect-ratio seperti menentukan proporsi bingkai foto di perpustakaan digital. `aspect-square` membuat kotak sempurna (1:1), `aspect-video` membuat rasio layar lebar (16:9). Seperti memastikan semua thumbnail buku memiliki proporsi yang konsisten tanpa menghitung manual.

## Penjelasan Detail

Aspect-ratio utilities (`aspect-{nilai}`) mengatur properti CSS `aspect-ratio`. Nilai bawaan: `aspect-auto` (default), `aspect-square` (1:1), `aspect-video` (16:9). Untuk rasio kustom, gunakan arbitrary values: `aspect-[4/3]`, `aspect-[3/2]`, `aspect-[21/9]`. Aspect-ratio sangat berguna untuk gambar, video, card, dan konten media agar memiliki proporsi yang konsisten. Elemen akan mempertahankan rasionya meskipun ukuran viewport berubah.

```html
      aspect-[4/3]

      aspect-[3/2]
    </div>
    <div class="aspect-[2/1] bg-yellow-500 text-white flex items-center justify-center rounded">
      aspect-[2/1]
    </div>

      aspect-[1/2]
    </div>
  </div>
  <div class="max-w-md mx-auto">
    <img src="https://placehold.co/600x400" alt="Demo" class="aspect-video rounded-lg w-full object-cover">
    <p class="text-sm text-gray-500 mt-1">Gambar dengan aspect-video (16:9)</p>
  </div>

```

## Poin Penting
- `aspect-square` = 1:1, `aspect-video` = 16:9
- Rasio kustom: `aspect-[4/3]`, `aspect-[3/2]`, dll
- Mempertahankan proporsi elemen di berbagai ukuran viewport
