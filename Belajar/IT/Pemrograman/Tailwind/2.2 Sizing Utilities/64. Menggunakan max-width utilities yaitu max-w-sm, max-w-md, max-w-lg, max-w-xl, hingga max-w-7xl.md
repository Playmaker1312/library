# Menggunakan max-width utilities yaitu max-w-sm, max-w-md, max-w-lg, max-w-xl, hingga max-w-7xl

## Analogi: Perpustakaan Digital

Max-width seperti batas maksimal lebar rak buku. `max-w-sm` seperti rak kecil, `max-w-lg` rak medium, `max-w-7xl` rak sangat besar. Ini berguna untuk container konten agar tidak terlalu lebar dan tetap mudah dibaca. Seperti buku yang tidak boleh terlalu lebar agar nyaman dibaca.

## Penjelasan Detail

Max-width utilities (`max-w-{size}`) menggunakan skala yang telah ditentukan: `max-w-xs` (320px), `sm` (384px), `md` (448px), `lg` (512px), `xl` (576px), `2xl` (672px), `3xl` (768px), `4xl` (896px), `5xl` (1024px), `6xl` (1152px), `7xl` (1280px). Ada juga `max-w-full` (100%), `max-w-min` (min-content), `max-w-max` (max-content), `max-w-fit` (fit-content), dan `max-w-prose` (65ch untuk readability). Max-width paling sering digunakan pada kontainer utama halaman untuk membatasi lebar konten dan meningkatkan readability.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Max-Width Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Max-Width Utilities</h1>
  <div class="bg-blue-500 text-white p-4 mx-auto max-w-sm rounded">max-w-sm (320px)</div>
  <div class="bg-green-500 text-white p-4 mx-auto max-w-md rounded">max-w-md (448px)</div>
  <div class="bg-red-500 text-white p-4 mx-auto max-w-lg rounded">max-w-lg (512px)</div>
  <div class="bg-purple-500 text-white p-4 mx-auto max-w-xl rounded">max-w-xl (576px)</div>
  <div class="bg-yellow-500 text-white p-4 mx-auto max-w-4xl rounded">max-w-4xl (896px)</div>
  <div class="bg-indigo-500 text-white p-4 mx-auto max-w-full rounded">max-w-full</div>
</body>
</html>
```

## Poin Penting
- Skala max-width dari xs hingga 7xl
- `max-w-prose` (65ch) optimal untuk readability artikel
- Sangat umum dikombinasikan dengan `mx-auto` untuk layout konten
