# Menggunakan fractional width yaitu w-1/2, w-1/3, w-2/3, w-1/4, dll

## Analogi: Perpustakaan Digital

Bayangkan rak buku yang dibagi menjadi beberapa bagian proporsional. `w-1/2` berarti setengah rak, `w-1/3` sepertiga rak, `w-2/3` dua pertiga rak. Ini seperti membagi koleksi buku ke dalam seksi yang proporsional tanpa harus menghitung pixel. Pecahan memudahkan pembagian ruang secara visual.

## Penjelasan Detail

Fractional width menggunakan notasi `w-{angka}/{penyebut}` seperti `w-1/2`, `w-1/3`, `w-2/3`, `w-1/4`, `w-3/4`, `w-1/5`, `w-2/5`, `w-3/5`, `w-4/5`, `w-1/6`, `w-5/6`, `w-1/12`, dan seterusnya. Nilai ini setara dengan persentase CSS (`width: 50%`, `width: 33.333%`, dll). Fractional width sangat berguna untuk layout grid kustom dan pembagian kolom. Dapat dikombinasikan dengan flexbox dan grid untuk layout yang responsif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Fractional Width Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Fractional Width</h1>
  <div class="flex space-x-2">
    <div class="bg-blue-500 text-white p-4 w-1/2">w-1/2</div>
    <div class="bg-green-500 text-white p-4 w-1/2">w-1/2</div>
  </div>
  <div class="flex space-x-2">
    <div class="bg-red-500 text-white p-4 w-1/3">w-1/3</div>
    <div class="bg-yellow-500 text-white p-4 w-1/3">w-1/3</div>
    <div class="bg-purple-500 text-white p-4 w-1/3">w-1/3</div>
  </div>
  <div class="flex space-x-2">
    <div class="bg-indigo-500 text-white p-4 w-1/4">w-1/4</div>
    <div class="bg-pink-500 text-white p-4 w-3/4">w-3/4</div>
  </div>
  <div class="flex space-x-2">
    <div class="bg-teal-500 text-white p-4 w-2/5">w-2/5</div>
    <div class="bg-orange-500 text-white p-4 w-3/5">w-3/5</div>
  </div>
</body>
</html>
```

## Poin Penting
- Format: `w-{pembilang}/{penyebut}` seperti `w-1/2`, `w-2/3`
- Berguna untuk layout proporsional tanpa CSS kustom
- Dapat digunakan dengan flexbox, grid, atau elemen block biasa
