# Menggunakan size utilities yaitu size-4, size-8, size-full sebagai shorthand width dan height

## Analogi: Perpustakaan Digital

Size utilities seperti menentukan ukuran kotak buku secara instan dengan satu perintah. Alih-alih mengatur lebar dan tinggi secara terpisah, `size-4` langsung membuat kotak dengan lebar dan tinggi 16px. Ini seperti memilih wadah buku yang sudah memiliki ukuran seragam tanpa perlu mengukur dua dimensi terpisah.

## Penjelasan Detail

Size utilities (`size-{nilai}`) adalah shorthand untuk mengatur `width` dan `height` sekaligus dengan nilai yang sama. Mengikuti skala spacing Tailwind dari 0 hingga 96, termasuk `size-px`, `size-auto`, `size-full`, `size-min`, `size-max`, `size-fit`, dan `size-screen`. Size utilities sangat berguna untuk icon, avatar, tombol icon-only, dan elemen persegi lainnya. Fitur ini diperkenalkan di Tailwind CSS v3.4 untuk menyederhanakan pembuatan elemen dengan dimensi sama.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Size Utilities Demo</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="p-8 space-y-4">
  <h1 class="text-2xl font-bold">Size Utilities</h1>
  <div class="flex items-end space-x-4">
    <div class="bg-blue-500 text-white size-8 flex items-center justify-center text-xs">8</div>
    <div class="bg-green-500 text-white size-12 flex items-center justify-center text-sm">12</div>
    <div class="bg-red-500 text-white size-16 flex items-center justify-center">16</div>
    <div class="bg-purple-500 text-white size-20 flex items-center justify-center">20</div>
    <div class="bg-yellow-500 text-white size-24 flex items-center justify-center">24</div>
  </div>
  <div class="flex items-center space-x-4">
    <div class="w-12 h-12 bg-gray-300 rounded-full flex items-center justify-center text-lg font-bold">JD</div>
    <div>
      <p class="font-semibold">Avatar dengan size utilities</p>
      <div class="bg-indigo-500 text-white size-10 rounded-full flex items-center justify-center text-sm font-bold">JD</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `size-{nilai}` mengatur width dan height sekaligus
- Berguna untuk avatar, icon, dan tombol berbentuk persegi/bulat
- Mendukung semua nilai di spacing scale termasuk `size-full` dan `size-screen`
