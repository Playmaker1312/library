# Cara menambahkan custom components melalui plugin

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki "paket bacaan siap pakai" — satu set buku yang sudah dipilih, diatur, dan dibundel menjadi satu kesatuan. Di Tailwind, components adalah bundel utility class yang menjadi satu kesatuan. Daripada menulis 10 class yang sama berulang kali, Anda membuat satu component class yang mewakili semuanya. Plugin memungkinkan Anda mendaftarkan component ini secara global.

## Penjelasan Detail
`addComponents` adalah fungsi API plugin yang mirip dengan `addUtilities`, tetapi component ditambahkan ke layer `components` yang memiliki prioritas di atas base styles tapi di bawah utilities. Ini berarti utility class tetap bisa meng-override component style. Component biasanya digunakan untuk reusable UI pattern seperti button, card, badge, atau alert. Dalam `addComponents`, Anda mendefinisikan class dengan properti CSS lengkap. Component bisa menggunakan nilai dari theme melalui fungsi `theme()`. Component juga bisa menggunakan pseudo-class seperti `:hover`, `:focus`, dan `::before`/`::after`. Component yang baik bersifat fleksibel, bisa dikustomisasi via utility class, dan mengikuti prinsip DRY.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Custom Components via Plugin</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addComponents, theme }) {
          addComponents({
            ".card": {
              backgroundColor: theme("colors.white"),
              borderRadius: theme("borderRadius.xl"),
              padding: theme("spacing.6"),
              boxShadow: "0 4px 6px -1px rgba(0,0,0,0.1)",
              border: `1px solid ${theme("colors.gray.200")}`,
            },
            ".badge": {
              display: "inline-flex",
              alignItems: "center",
              padding: `${theme("spacing.1")} ${theme("spacing.3")}`,
              borderRadius: theme("borderRadius.full"),
              fontSize: theme("fontSize.sm")[0],
              fontWeight: theme("fontWeight.semibold"),
              lineHeight: "1",
            },
            ".badge-success": {
              backgroundColor: theme("colors.emerald.100"),
              color: theme("colors.emerald.800"),
            },
            ".badge-warning": {
              backgroundColor: theme("colors.amber.100"),
              color: theme("colors.amber.800"),
            },
            ".badge-error": {
              backgroundColor: theme("colors.red.100"),
              color: theme("colors.red.800"),
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-2xl mx-auto space-y-4">
    <h1 class="text-2xl font-bold text-gray-800">Custom Components dari Plugin</h1>
    <div class="card space-y-4">
      <div class="flex gap-2">
        <span class="badge badge-success">Active</span>
        <span class="badge badge-warning">Pending</span>
        <span class="badge badge-error">Failed</span>
      </div>
      <h2 class="text-xl font-semibold text-gray-800">Judul Card</h2>
      <p class="text-gray-600">Ini adalah contoh component card yang dibuat melalui plugin <code>addComponents</code>. Component ini bisa digunakan di mana saja tanpa perlu menulis ulang utility class.</p>
      <button class="bg-indigo-600 text-white px-4 py-2 rounded-lg hover:bg-indigo-700 transition">Tombol Aksi</button>
    </div>
    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
addComponents({
  ".card": {
    backgroundColor: theme("colors.white"),
    borderRadius: theme("borderRadius.xl"),
    padding: theme("spacing.6"),
    boxShadow: "0 4px 6px -1px rgba(0,0,0,0.1)",
  },
});</pre>
  </div>
</body>
</html>
```

## Poin Penting
- `addComponents` menambahkan ke layer components yang prioritasnya di antara base dan utilities
- Components berguna untuk reusable UI pattern seperti card, badge, button, dan alert
- Component bisa mengakses nilai theme melalui fungsi `theme()` untuk konsistensi desain
