# Menggunakan plugin resmi yaitu typography, forms, aspect-ratio, dan container-queries

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang menyediakan "paket ekstensi resmi" yang dikembangkan oleh tim perpustakaan pusat. Ada paket untuk menata buku puisi (typography), paket untuk formulir pendaftaran anggota baru (forms), paket untuk mengatur rasio bingkai foto (aspect-ratio), dan paket untuk rak yang bisa menyesuaikan ukuran (container-queries). Ekstensi resmi ini dijamin kompatibel dan terawat dengan baik.

## Penjelasan Detail
Plugin resmi Tailwind adalah plugin yang dikembangkan dan dipelihara langsung oleh tim inti Tailwind CSS. Plugin `@tailwindcss/typography` menyediakan class `prose` untuk styling konten kaya seperti artikel blog. Plugin `@tailwindcss/forms` memberikan reset style untuk elemen form yang konsisten di semua browser. Plugin `@tailwindcss/aspect-ratio` menyediakan utility untuk mengatur rasio aspek elemen (sudah menjadi bawaan di Tailwind v3.3+). Plugin `@tailwindcss/container-queries` memungkinkan styling berdasarkan ukuran container (bukan viewport). Masing-masing plugin diinstal via npm dengan `npm install -D @tailwindcss/xxx` dan didaftarkan di `plugins` pada tailwind.config.js. Plugin resmi mengikuti versi Tailwind dan diuji secara ekstensif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Plugin Resmi Tailwind</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addUtilities }) {
          addUtilities({
            ".aspect-video": { aspectRatio: "16 / 9" },
            ".aspect-square": { aspectRatio: "1 / 1" },
            ".aspect-portrait": { aspectRatio: "3 / 4" },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-4xl mx-auto space-y-8">
    <h1 class="text-3xl font-bold text-gray-800">Plugin Resmi Tailwind</h1>
    <div class="grid grid-cols-3 gap-6">
      <div class="bg-white rounded-xl overflow-hidden shadow">
        <div class="aspect-video bg-gradient-to-br from-indigo-400 to-purple-500 flex items-center justify-center text-white text-2xl">16:9</div>
        <div class="p-4">
          <h3 class="font-semibold">Typografi</h3>
          <p class="text-sm text-gray-500">Plugin typography untuk konten artikel.</p>
        </div>
      </div>
      <div class="bg-white rounded-xl overflow-hidden shadow">
        <div class="aspect-square bg-gradient-to-br from-emerald-400 to-teal-500 flex items-center justify-center text-white text-2xl">1:1</div>
        <div class="p-4">
          <h3 class="font-semibold">Forms</h3>
          <p class="text-sm text-gray-500">Reset style form konsisten.</p>
        </div>
      </div>
      <div class="bg-white rounded-xl overflow-hidden shadow">
        <div class="aspect-portrait bg-gradient-to-br from-amber-400 to-orange-500 flex items-center justify-center text-white text-2xl">3:4</div>
        <div class="p-4">
          <h3 class="font-semibold">Container Queries</h3>
          <p class="text-sm text-gray-500">Style berdasarkan ukuran container.</p>
        </div>
      </div>
    </div>
    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
// Install via npm
npm install -D @tailwindcss/typography @tailwindcss/forms @tailwindcss/container-queries

// tailwind.config.js
plugins: [
  require('@tailwindcss/typography'),
  require('@tailwindcss/forms'),
  require('@tailwindcss/container-queries'),
],</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Plugin resmi Tailwind (typography, forms, aspect-ratio, container-queries) dipelihara langsung oleh tim inti
- Plugin `@tailwindcss/typography` menggunakan class `prose` untuk styling konten HTML kaya
- Plugin diinstal via npm dan didaftarkan di array `plugins` pada tailwind.config.js
