# Cara menambahkan custom variants melalui plugin

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki aturan khusus: "buku ini hanya bisa dibaca di tempat" (read-only) atau "buku ini hanya untuk anggota premium" (premium-only). Tailwind variants seperti selector khusus yang mengaktifkan utility hanya dalam kondisi tertentu — saat elemen di-hover, saat layar lebar, saat elemen dalam keadaan disabled, dan sebagainya. Custom variants memungkinkan Anda menambahkan kondisi baru yang spesifik untuk kebutuhan proyek.

## Penjelasan Detail
`addVariant` adalah fungsi API plugin yang digunakan untuk menambahkan variant kustom ke Tailwind. Variant adalah prefix yang mengubah utility class berdasarkan kondisi tertentu, seperti `hover:`, `focus:`, `lg:`. Untuk menambahkan variant, panggil `addVariant('nama', 'selector')` di mana selector bisa berupa string CSS selector atau fungsi yang menerima selector dan mengembalikan selector yang dimodifikasi. Contoh: `addVariant('optional', '&:optional')` akan menghasilkan class `optional:border-red-500`. Variant juga bisa menggunakan pseudo-element seperti `&::placeholder`, `&::marker`. Untuk variant yang lebih kompleks, Anda bisa menggunakan fungsi sebagai parameter kedua yang menerima `{ modifySelectors, separator }`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Custom Variants</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addVariant }) {
          addVariant("optional", "&:optional");
          addVariant("read-only", "&:read-only");
          addVariant("target", "&:target");
          addVariant("children", "& > *");
          addVariant("sibling", "& ~ &");
          addVariant("before", "&::before");
          addVariant("after", "&::after");
          addVariant("number-input", '&[type="number"]');
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-2xl mx-auto space-y-6">
    <h1 class="text-2xl font-bold">Custom Variants via Plugin</h1>
    <div class="bg-white p-6 rounded-xl space-y-4">
      <div>
        <label class="block text-sm font-medium mb-1">Field Optional</label>
        <input type="text" class="border p-2 rounded w-full optional:border-yellow-400 optional:ring-1 optional:ring-yellow-400" />
        <p class="text-xs text-gray-400 mt-1">Field dengan variant <code>optional</code></p>
      </div>
      <div>
        <label class="block text-sm font-medium mb-1">Field Read-only</label>
        <input type="text" value="Tidak bisa diedit" readonly class="border p-2 rounded w-full read-only:bg-gray-100 read-only:cursor-not-allowed" />
        <p class="text-xs text-gray-400 mt-1">Variant <code>read-only</code></p>
      </div>
      <div class="children:bg-indigo-50 children:p-2 children:rounded">
        <p>Item 1 — children:bg-indigo-50</p>
        <p>Item 2 — children:bg-indigo-50</p>
        <p>Item 3 — children:bg-indigo-50</p>
      </div>
    </div>
    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm">
addVariant("children", "& > *");
addVariant("optional", "&:optional");
addVariant("read-only", "&:read-only");
// Gunakan: children:bg-red-500, optional:border-yellow-400</pre>
  </div>
</body>
</html>
```

## Poin Penting
- `addVariant` menambahkan variant kustom yang bisa digunakan sebagai prefix utility class
- Variant bisa menargetkan pseudo-class, pseudo-element, atau selector CSS kustom
- Custom variants memungkinkan logika styling yang tidak tersedia di variant bawaan Tailwind
