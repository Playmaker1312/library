# Cara menambahkan custom base styles melalui plugin

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki aturan dasar: semua buku harus memiliki label di punggung, semua rak harus memiliki nomor, dan semua pintu harus terbuka ke luar. Aturan dasar ini adalah "base styles" dari perpustakaan — aturan yang berlaku untuk semua elemen tanpa terkecuali. Di Tailwind, base styles adalah CSS yang berlaku global untuk elemen HTML dasar. Plugin bisa menambahkan atau memodifikasi base styles ini.

## Penjelasan Detail
`addBase` adalah fungsi API plugin yang menambahkan CSS ke layer `base` Tailwind. Layer base adalah layer dengan prioritas terendah, digunakan untuk reset CSS dan style default elemen HTML. Fungsi ini menerima object CSS dengan selector sebagai key. Anda bisa menargetkan elemen HTML seperti `h1`, `p`, `a`, atau selector kustom seperti `*` untuk box-sizing reset. `addBase` sangat berguna untuk menambahkan style global seperti font family default, warna link, style heading, atau utility reset kustom. Tidak seperti `addUtilities` dan `addComponents`, style yang ditambahkan via `addBase` bisa dengan mudah di-override oleh class lain. Hati-hati menggunakan `addBase` karena perubahannya bersifat global.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Custom Base Styles</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase, theme }) {
          addBase({
            "h1, h2, h3, h4": {
              fontWeight: theme("fontWeight.bold"),
              lineHeight: "1.2",
              letterSpacing: theme("letterSpacing.tight"),
            },
            a: {
              color: theme("colors.indigo.600"),
              textDecoration: "none",
              "&:hover": {
                color: theme("colors.indigo.800"),
                textDecoration: "underline",
              },
            },
            "::selection": {
              backgroundColor: theme("colors.indigo.200"),
              color: theme("colors.indigo.900"),
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-2xl mx-auto space-y-6">
    <h1>Custom Base Styles via Plugin</h1>
    <h2>Heading 2 — Bold dengan letter-spacing ketat</h2>
    <p>Paragraf biasa. <a href="#">Ini adalah contoh link</a> yang memiliki warna indigo-600 dan hover underline. Base styles ini ditambahkan melalui plugin menggunakan <code>addBase</code>.</p>
    <h3>Heading 3 — Seleksi teks</h3>
    <p>Coba seleksi teks ini — warna seleksinya sudah dikustomisasi menjadi indigo-200 dengan teks indigo-900.</p>
    <pre class="bg-gray-900 text-green-400 p-4 rounded text-sm mt-6">
addBase({
  "h1, h2, h3, h4": {
    fontWeight: theme("fontWeight.bold"),
    lineHeight: "1.2",
  },
  a: {
    color: theme("colors.indigo.600"),
    "&:hover": { color: theme("colors.indigo.800") },
  },
  "::selection": {
    backgroundColor: theme("colors.indigo.200"),
  },
});</pre>
  </div>
</body>
</html>
```

## Poin Penting
- `addBase` menambahkan CSS ke layer base Tailwind yang berlaku secara global
- Base styles memiliki prioritas terendah dan mudah di-override oleh utility atau component class
- Gunakan `addBase` untuk reset CSS kustom, style elemen HTML global, dan font family default
