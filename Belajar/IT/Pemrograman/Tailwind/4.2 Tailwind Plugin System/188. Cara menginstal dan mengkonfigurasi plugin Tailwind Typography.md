# Cara menginstal dan mengkonfigurasi plugin Tailwind Typography

## Analogi: Perpustakaan Digital
Seperti perpustakaan yang membeli paket "pemformatan buku otomatis" — sekali dipasang, semua buku akan diatur dengan margin, font, dan spasi yang konsisten. Plugin Tailwind Typography adalah alat yang secara otomatis memberikan gaya typografi yang indah pada konten HTML mentah, seperti artikel blog atau halaman dokumentasi.

## Penjelasan Detail
Untuk menginstal plugin Tailwind Typography, jalankan `npm install -D @tailwindcss/typography` di terminal proyek Anda. Setelah terinstal, daftarkan plugin di `plugins` pada tailwind.config.js dengan `require('@tailwindcss/typography')`. Plugin ini menambahkan class `prose` yang memberikan gaya typografi optimal untuk konten HTML. Anda tidak perlu mengkonfigurasi apa pun untuk penggunaan dasar — cukup tambahkan class `prose` ke container artikel. Plugin ini juga mendukung kustomisasi melalui `theme.extend.typography` di konfigurasi. Anda bisa mengubah warna, font, spacing, dan lainnya untuk setiap elemen HTML di dalam konten prose. Plugin juga menyediakan berbagai varian ukuran dan warna.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Instalasi Typography Plugin</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addUtilities, addBase }) {
          addBase({
            ".prose": {
              maxWidth: "65ch",
              fontSize: "1rem",
              lineHeight: "1.75",
              color: "#374151",
              "& h1": { fontSize: "2.25rem", fontWeight: "800", marginTop: "2rem", marginBottom: "1rem", color: "#111827" },
              "& h2": { fontSize: "1.5rem", fontWeight: "700", marginTop: "1.75rem", marginBottom: "0.75rem", color: "#111827" },
              "& p": { marginBottom: "1.25rem" },
              "& a": { color: "#4f46e5", textDecoration: "underline" },
              "& ul": { listStyleType: "disc", paddingLeft: "1.5rem", marginBottom: "1.25rem" },
              "& li": { marginBottom: "0.25rem" },
              "& blockquote": { borderLeft: "4px solid #e5e7eb", paddingLeft: "1rem", fontStyle: "italic", color: "#6b7280" },
              "& code": { backgroundColor: "#f3f4f6", padding: "0.125rem 0.375rem", borderRadius: "0.25rem", fontSize: "0.875rem" },
              "& pre code": { backgroundColor: "transparent", padding: "0" },
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="prose mx-auto bg-white p-8 rounded-xl shadow">
    <h1>Cara Instalasi Typography Plugin</h1>
    <p>Plugin Tailwind Typography memberikan gaya typografi otomatis untuk konten HTML. Berikut langkah instalasinya:</p>
    <h2>Langkah 1: Install via NPM</h2>
    <pre><code>npm install -D @tailwindcss/typography</code></pre>
    <h2>Langkah 2: Daftarkan di Konfigurasi</h2>
    <pre><code>// tailwind.config.js
module.exports = {
  plugins: [
    require('@tailwindcss/typography'),
  ],
}</code></pre>
    <h2>Langkah 3: Gunakan Class Prose</h2>
    <p>Tambahkan class <code>prose</code> ke container artikel Anda.</p>
    <blockquote>Plugin ini secara otomatis menata semua elemen HTML di dalam container prose.</blockquote>
    <p>Keuntungan menggunakan plugin ini:</p>
    <ul>
      <li>Styling konsisten untuk semua konten HTML</li>
      <li>Mendukung berbagai varian ukuran (prose-sm hingga prose-2xl)</li>
      <li>Dapat dikustomisasi melalui konfigurasi theme</li>
    </ul>
  </div>
</body>
</html>
```

## Poin Penting
- Install plugin dengan `npm install -D @tailwindcss/typography` lalu daftarkan di `plugins`
- Gunakan class `prose` pada container untuk mendapatkan gaya typografi otomatis
- Plugin bisa dikustomisasi melalui `theme.extend.typography` di tailwind.config.js
