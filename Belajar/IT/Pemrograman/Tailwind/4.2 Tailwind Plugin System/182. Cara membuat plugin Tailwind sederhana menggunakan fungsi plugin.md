# Cara membuat plugin Tailwind sederhana menggunakan fungsi plugin

## Analogi: Perpustakaan Digital
Seperti menulis resep masakan baru untuk kafetaria perpustakaan — Anda mendaftarkan bahan-bahan (CSS) dan langkah-langkah (fungsi) yang dibutuhkan. Plugin Tailwind sederhana ibarat resep satu halaman yang langsung bisa dipraktikkan tanpa perlu peralatan khusus. Cukup dengan fungsi JavaScript, plugin bisa langsung didaftarkan dan digunakan.

## Penjelasan Detail
Cara paling sederhana membuat plugin Tailwind adalah dengan menulis fungsi anonim langsung di dalam array `plugins` di tailwind.config.js. Fungsi ini menerima parameter yang didestructuring dari object plugin API. Anda bisa menggunakan `addUtilities` untuk menambahkan utility class, `addComponents` untuk component class, dan seterusnya. Plugin sederhana bisa hanya berisi beberapa baris kode. Untuk plugin yang lebih kompleks, Anda bisa memisahkan ke file terpisah dan menggunakan `module.exports`. Fungsi plugin juga bisa menerima opsi kustom jika plugin tersebut adalah higher-order function. Plugin yang baik harus memberi nama utility yang konsisten dengan konvensi Tailwind dan tidak bentrok dengan class yang sudah ada.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Plugin Sederhana</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addUtilities }) {
          addUtilities({
            ".content-auto": { "content-visibility": "auto" },
            ".content-hidden": { "content-visibility": "hidden" },
            ".content-visible": { "content-visibility": "visible" },
            ".scrollbar-hide": {
              "-ms-overflow-style": "none",
              "scrollbar-width": "none",
              "&::-webkit-scrollbar": { display: "none" },
            },
            ".bg-dots": {
              backgroundImage: "radial-gradient(circle, #000 1px, transparent 1px)",
              backgroundSize: "20px 20px",
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-2xl mx-auto space-y-6">
    <h1 class="text-2xl font-bold text-gray-800">Plugin Sederhana</h1>
    <div class="bg-dots bg-white border rounded-xl p-6">
      <p class="font-semibold mb-2">bg-dots — background pattern dari plugin</p>
      <div class="h-32 scrollbar-hide overflow-x-auto bg-white rounded-lg p-4 border">
        <div class="w-96 flex gap-4">
          <div class="bg-indigo-500 text-white p-4 rounded shrink-0">Konten 1</div>
          <div class="bg-indigo-600 text-white p-4 rounded shrink-0">Konten 2</div>
          <div class="bg-indigo-700 text-white p-4 rounded shrink-0">Konten 3</div>
          <div class="bg-indigo-800 text-white p-4 rounded shrink-0">Konten 4</div>
        </div>
        <p class="text-sm text-gray-400 mt-2">scrollbar-hide menyembunyikan scrollbar</p>
      </div>
    </div>
    <pre class="bg-gray-900 text-green-400 p-4 rounded-lg text-sm">
// Plugin 5 baris — addUtilities kustom
function({ addUtilities }) {
  addUtilities({
    ".scrollbar-hide": {
      "-ms-overflow-style": "none",
      "scrollbar-width": "none",
      "&::-webkit-scrollbar": { display: "none" },
    },
  });
}</pre>
  </div>
</body>
</html>
```

## Poin Penting
- Plugin sederhana dibuat dengan fungsi anonim langsung di array `plugins` menggunakan `addUtilities`
- Gunakan `addUtilities` untuk utility class, `addComponents` untuk reusable component
- Pastikan nama utility class tidak bentrok dengan class bawaan Tailwind
