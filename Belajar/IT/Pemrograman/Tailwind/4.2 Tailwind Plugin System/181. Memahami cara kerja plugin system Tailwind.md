# Memahami cara kerja plugin system Tailwind

## Analogi: Perpustakaan Digital
Bayangkan perpustakaan yang memiliki sistem operasi dengan API (Application Programming Interface). API ini memungkinkan pengembang eksternal untuk membuat "aplikasi" kecil yang bisa berjalan di dalam perpustakaan — menambahkan rak baru, sistem pencarian baru, atau tampilan baru. Plugin system Tailwind seperti API ini: memberikan akses ke fungsi-fungsi inti Tailwind sehingga pengembang bisa memperluas kemampuannya tanpa harus mengubah kode sumber Tailwind itu sendiri.

## Penjelasan Detail
Plugin system Tailwind bekerja dengan menyediakan object yang berisi fungsi-fungsi seperti `addUtilities`, `addComponents`, `addBase`, `addVariant`, `matchUtilities`, `matchComponents`, `theme`, `config`, `e` (escape selector), dan `prefix`. Ketika plugin dipanggil, Tailwind melewatkan object ini sebagai parameter. Plugin bisa berupa fungsi anonim atau modul yang di-require. Tailwind memproses plugin setelah konfigurasi theme di-resolve, sehingga plugin bisa mengakses nilai theme yang sudah lengkap. Plugin dieksekusi dalam urutan tertentu: base styles, kemudian components, lalu utilities. Setiap plugin bisa menambahkan CSS ke masing-masing layer tersebut. Plugin juga bisa mendaftarkan variant baru yang bisa digunakan dengan utility class.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Cara Kerja Plugin System</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addUtilities, addVariant, theme, e }) {
          addUtilities({
            ".bg-gradient-brand": {
              background: `linear-gradient(135deg, ${theme("colors.indigo.500")}, ${theme("colors.purple.600")})`,
            },
            ".text-gradient": {
              background: `linear-gradient(135deg, ${theme("colors.indigo.400")}, ${theme("colors.pink.500")})`,
              "-webkit-background-clip": "text",
              "-webkit-text-fill-color": "transparent",
            },
          });
          addVariant("optional", "&:optional");
          addVariant("read-only", "&:read-only");
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-2xl mx-auto space-y-6">
    <h1 class="text-4xl font-bold text-gradient">Plugin System Tailwind</h1>
    <div class="bg-gradient-brand text-white p-6 rounded-xl shadow-lg">
      <h2 class="text-xl font-semibold mb-2">Utility dari Plugin</h2>
      <p>Class <code>bg-gradient-brand</code> dibuat oleh plugin menggunakan fungsi addUtilities.</p>
    </div>
    <div class="bg-white p-6 rounded-xl shadow space-y-3">
      <h3 class="font-semibold text-gray-700">Variant Kustom: optional & read-only</h3>
      <input type="text" placeholder="Field biasa" class="border p-2 rounded w-full" />
      <input type="text" placeholder="Field readonly" value="read-only" readonly class="border p-2 rounded w-full read-only:bg-gray-100 read-only:cursor-not-allowed" />
      <p class="text-sm text-gray-500">Variant <code>read-only</code> diterapkan pada input readonly — plugin menambahkan variant baru.</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Plugin system Tailwind menyediakan API seperti `addUtilities`, `addComponents`, `addBase`, dan `addVariant`
- Plugin dapat mengakses nilai theme dan konfigurasi melalui parameter `theme` dan `config`
- Plugin dieksekusi dalam urutan layer: base → components → utilities
