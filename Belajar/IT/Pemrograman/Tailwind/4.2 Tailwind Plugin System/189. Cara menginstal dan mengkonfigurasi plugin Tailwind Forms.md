# Cara menginstal dan mengkonfigurasi plugin Tailwind Forms

## Analogi: Perpustakaan Digital
Bayangkan setiap kali anggota baru mendaftar di perpustakaan, formulir pendaftaran terlihat berbeda tergantung browser yang digunakan — di Chrome rapi, di Firefox berantakan. Plugin Tailwind Forms seperti template formulir standar yang memastikan semua input, select, checkbox, dan radio button terlihat konsisten di browser mana pun. Cukup pasang sekali, semua formulir akan memiliki tampilan seragam.

## Penjelasan Detail
Plugin Tailwind Forms (`@tailwindcss/forms`) memberikan reset CSS untuk elemen form yang konsisten di semua browser. Instalasi dilakukan dengan `npm install -D @tailwindcss/forms`, lalu daftarkan di `plugins` di tailwind.config.js. Plugin ini menambahkan style dasar untuk `input`, `textarea`, `select`, `checkbox`, dan `radio`. Setelah plugin terpasang, Anda bisa menggunakan utility Tailwind seperti biasa untuk mengkustomisasi tampilan form. Plugin ini menyediakan dua strategy: `base` (default) yang memberikan style minimal, dan `class` yang memungkinkan styling per elemen. Strategy `class` berguna jika Anda ingin form tertentu menggunakan style default browser. Plugin Forms sangat berguna untuk proyek yang banyak menggunakan form seperti dashboard admin atau halaman pendaftaran.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Plugin Tailwind Forms</title>
  <script src="https://cdn.tailwindcss.com"></script>
  <script>
    tailwind.config = {
      plugins: [
        function ({ addBase }) {
          addBase({
            'input[type="text"], input[type="email"], input[type="password"], textarea, select': {
              borderWidth: "1px",
              borderColor: "#d1d5db",
              borderRadius: "0.375rem",
              padding: "0.5rem 0.75rem",
              fontSize: "0.875rem",
              lineHeight: "1.25rem",
              backgroundColor: "#ffffff",
              "&:focus": {
                outline: "none",
                borderColor: "#6366f1",
                boxShadow: "0 0 0 3px rgba(99,102,241,0.15)",
              },
            },
            'input[type="checkbox"]': {
              borderRadius: "0.25rem",
              borderColor: "#d1d5db",
              accentColor: "#6366f1",
            },
            'input[type="radio"]': {
              borderColor: "#d1d5db",
              accentColor: "#6366f1",
            },
          });
        },
      ],
    };
  </script>
</head>
<body class="p-10 bg-gray-50">
  <div class="max-w-lg mx-auto bg-white p-8 rounded-xl shadow">
    <h1 class="text-2xl font-bold text-gray-800 mb-6">Formulir dengan Tailwind Forms</h1>
    <form class="space-y-4">
      <div>
        <label class="block text-sm font-medium text-gray-700 mb-1">Nama Lengkap</label>
        <input type="text" placeholder="John Doe" class="w-full" />
      </div>
      <div>
        <label class="block text-sm font-medium text-gray-700 mb-1">Email</label>
        <input type="email" placeholder="john@example.com" class="w-full" />
      </div>
      <div>
        <label class="block text-sm font-medium text-gray-700 mb-1">Kota</label>
        <select class="w-full">
          <option>Jakarta</option>
          <option>Bandung</option>
          <option>Surabaya</option>
        </select>
      </div>
      <div>
        <label class="block text-sm font-medium text-gray-700 mb-1">Pesan</label>
        <textarea rows="3" class="w-full" placeholder="Tulis pesan..."></textarea>
      </div>
      <div class="flex items-center gap-4">
        <label class="flex items-center gap-2">
          <input type="checkbox" checked />
          <span class="text-sm text-gray-700">Setuju dengan syarat & ketentuan</span>
        </label>
        <label class="flex items-center gap-2">
          <input type="radio" name="gender" />
          <span class="text-sm text-gray-700">Pria</span>
        </label>
        <label class="flex items-center gap-2">
          <input type="radio" name="gender" />
          <span class="text-sm text-gray-700">Wanita</span>
        </label>
      </div>
      <button type="submit" class="bg-indigo-600 text-white py-2 px-4 rounded-lg hover:bg-indigo-700 transition w-full">Kirim</button>
    </form>
  </div>
</body>
</html>
```

## Poin Penting
- Install plugin Forms dengan `npm install -D @tailwindcss/forms` untuk reset style form yang konsisten
- Plugin menyediakan strategy `base` (default) dan `class` untuk fleksibilitas styling
- Setelah plugin terpasang, utility Tailwind tetap bisa digunakan untuk kustomisasi lebih lanjut
