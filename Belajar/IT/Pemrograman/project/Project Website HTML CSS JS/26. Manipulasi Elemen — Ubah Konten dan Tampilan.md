# 26. Manipulasi Elemen — Ubah Konten dan Tampilan

Materi ini mengajarkan cara mengubah isi dan penampilan elemen yang sudah ditemukan: menulis teks lewat `textContent`, menyuntik HTML lewat `innerHTML` (beserta bahaya XSS-nya), mengelola atribut, `data-*` attributes, class (CSS), dan style inline. Setelah mampu menemukan elemen (materi 25), sekarang kamu belajar mengendalikannya.

## 1. Penjelasan Singkat & Konsep Dasar

Materi 25 mengajarkan cara **menemukan** elemen di DOM — penyelesaian "petanya" untuk menjangkau bagian halaman. Namun menemukan saja belum cukup; tujuan utama pemrograman DOM adalah **mengubah** sesuatu yang terlihat oleh user. Tanpa manipulasi, `document.querySelector` hanyalah cara menatap elemen dari dekat. Level 5 menjadi bermakna ketika kamu mulai membaca nilai dari sebuah input dan menuliskannya kembali ke halaman, atau menandai buku yang sedang dipinjam, atau menyembunyikan konten yang sudah tidak relevan.

Inti perbedaannya terletak pada _properti_ yang kamu ubah. Setiap elemen punya beberapa "pintu" untuk konten: **`textContent`** mengambil/menulis teks polos (truthy untuk semua node teks, tanpa interpretasi HTML), **`innerText`** mirip tapi menghormati CSS (misal `display:none` membuat teksnya tak terhitung; hasilnya bisa berbeda dengan `textContent`), dan **`innerHTML`** membaca/menulis string HTML yang akan di-parse menjadi elemen. Perbedaan inilah yang menjadi keputusan keamanan paling penting dalam materi ini: `innerHTML` dengan input user adalah jalur **XSS (Cross-Site Scripting)**, sementara `textContent` selalu aman karena memperlakukan segala sesuatu sebagai teks semata.

Untuk atribut, ada dua cara akses. API generik `getAttribute` / `setAttribute` / `removeAttribute` / `hasAttribute` bekerja pada atribut apa pun. Sebagian atribut juga tersedia sebagai **property langsung**: `input.value`, `input.checked`, `input.disabled`, `a.href`, `img.src`, `img.alt`, dan lain-lain — penulisan property ini lebih ringkas dan biasanya yang kamu pakai sehari-hari. Ada juga **`dataset`** yang membaca atribut `data-*` (`data-id`, `data-kategori`) menjadi `element.dataset.id`, `element.dataset.kategori` — sangat berguna untuk menyimpan data kecil pada kartu dinamis.

Yang tak kalah penting adalah **class**: `classList` menyediakan `add`, `remove`, `toggle`, `contains`, dan `replace` sehingga kamu bisa mengubah tampilan elemen dengan menggeser class, bukan menulis ulang style. Ini pola terbaik karena tampilannya tetap diurus CSS, sedangkan JS hanya memilih class mana yang aktif. Adapun `element.style.color = "red"` (mencatat: property CSS ber-`-kebab-case` menjadi **camelCase** `backgroundColor`) tetap tersedia untuk perubahan yang benar-benar ad hoc, tetapi jarang diinginkan karena mencampur tampilan ke dalam logika dan menumpuknya di atas CSS.

**Benang merah**: materi 25 memberi pegangan ke elemen; materi 26 menjadikan pegangan itu aktif — membaca nilai, menulis ulang, mengubah status dan penampilan. Semua fitur interaktif "tanpa reload" di perpustakaan digital, mulai dari memberi tahu user bahwa buku habis sampai menandai input agar tak bisa diubah, bergantung pada teknik manipulasi di sini. Materi 27 dan 28 akan memakainya terus-menerus saat membuat, menghapus, dan merespons event.

## 2. Fungsi & Kegunaan Utama dalam Web

Dalam **Perpustakaan Digital Kota**, hampir setiap interaksi user menghasilkan perubahan tampilan. Satu fungsi tunggal — misalnya "tandai buku sebagai sedang dipinjam" — membutuhkan: membaca judul dari `textContent` kartu, menyimpan id buku ke `dataset` kartu, menambah class `kartu--terpinjam` lewat `classList`, dan mengubah label tombol pinjam dari `textContent` "Pinjam" menjadi "Dikembalikan". Semuanya tanpa satu pun reload halaman.

Untuk **pencarian**, nilai input dibaca dari `input.value`, dan jika user memberlakukan filter yang tidak menghasilkan buku, pesan "Tidak ada hasil" ditulis lewat `textContent`. Untuk **form tambah buku** dan **modal notifikasi**, pesan status sukses/gagal disusun dengan `textContent` (data user/API) sementara bagian struktur yang kamu kendalikan sendiri boleh memakai `innerHTML`. `classList` menjadi tuas utama untuk membuka/menutup modal (menambah/menghapus class `modal--aktif`), menandai kategori terpilih pada filter, dan menampilkan/hilangkan notifikasi.

`dataset` berperan diam-diam tapi krusial: setiap kartu buku menyimpan `data-id` dan `data-stok` sehingga ketika user mengeklik tombol hapus atau pinjam, JS langsung tahu buku mana yang dimaksud — tanpa harus mencari-cari lagi. Itu sebabnya kartu-kartu selanjutnya (materi 27) selalu dibekali `dataset`.

```javascript
// js/main.js

// ─── 1. textContent vs innerText vs innerHTML ────────────────────────────
const infoStatus = document.querySelector("#info-status");

infoStatus.textContent = "2 buku ditemukan di katalog."; // aman, tulis sebagai teks polos
console.log(infoStatus.textContent);                      // baca teks (tanpa tag)

// innerText: menghormati CSS. Jika elemen display:none, textContent tetap
// menghitung, innerText tidak. Bandingkan sendiri di DevTools.
console.log("textContent hanya teks:", infoStatus.innerText.includes("<") === false);

// innerHTML: string di-parse sebagai HTML. HATI-HATI!
const judul = document.querySelector(".judul-buku");
judul.innerHTML = "<em>Clean Code</em>: Revisi"; // em jadi benar-benar italic
// Bahaya XSS: jangan pernah masukkan input USER ke innerHTML!
const inputUserId = "User <img src=x onerror=alert(1)>"; // contoh payload
// judul.innerHTML = inputUserId; // ❌ SCRIPT JALAN! JANGAN!
judul.textContent = inputUserId; // ✅ aman: ditampilkan sebagai teks biasa

// ─── 2. Mencari/mengubah class lewat classList (yang utama dipakai) ─────
const kartuPertama = document.querySelector(".kartu-buku");

kartuPertama.classList.add("terpinjam");        // tambah class
kartuPertama.classList.remove("terpinjam");     // hapus class
kartuPertama.classList.toggle("terpinjam");     // nyalakan jika belum, matikan jika sudah
console.log(kartuPertama.classList.contains("terpinjam")); // true

// Mengganti class badge utk mencerminkan stok
const badgePertama = kartuPertama.querySelector(".badge");
badgePertama.classList.replace("baik", "habis");   // punya kedua class di CSS
console.log(badgePertama.classList.contains("habis")); // true

// ─── 3. Property langsung dan API atribut ────────────────────────────────
const inputAnggota = document.querySelector("#kartu-anggota");
console.log(inputAnggota.value);        // "ANG-2024-001"
inputAnggota.value = "ANG-2025-001";    // property langsung (TERSERING dipakai)
inputAnggota.disabled = true;           // field jadi nonaktif

// API generik utk atribut apa pun:
const link = document.querySelector("a"); // contoh saja; tidak ada di HTML ini
// link.getAttribute("href") / link.setAttribute("href", "#katalog")
// link.removeAttribute("href") / link.hasAttribute("href")

const gambar = document.querySelector("img"); // tidak ada di HTML ini
// gambar.src = "images/buku.jpg";    ← property langsung
// gambar.alt = "Sampul buku";        ← property langsung

// ─── 4. dataset untuk atribut data-* ─────────────────────────────────────
// Dari HTML: data-id="1", data-stok="3"
console.log(kartuPertama.dataset.id);     // "1"
console.log(kartuPertama.dataset.stok);   // "3"

kartuPertama.dataset.kategori = "teknologi"; // setara menambah data-kategori

// Cek berapa buku yang datanya bisa dibaca:
const semuaKartu = document.querySelectorAll(".kartu-buku");
semuaKartu.forEach(kartu => {
    console.log(`Buku #${kartu.dataset.id}: stok ${kartu.dataset.stok}`);
});

// ─── 5. style inline: ada tujuan terbatas, tapi utamakan classList ──────
const judulHalaman = document.querySelector("h1");
judulHalaman.style.color = "#2563eb";       // camelCase, bukan color-color
judulHalaman.style.marginBottom = "8px";    // ganti background-color → backgroundColor

// Menutup/menampilkan elemen ad hoc via display (jarang, prefer class):
inputAnggota.style.display = "none";
inputAnggota.style.display = ""; // kembalikan ke default CSS
```

## 4. Analogi Sederhana — Membangun Rumah

Di rumah analogi kita, **HTML** adalah kerangka dan tata ruang, **CSS** adalah cat serta dekorasi, dan **JavaScript** adalah instalasi listrik. Di materi 25 kamu belajar membaca denah di panel kontrol listrik. Materi 26 ini tentang **mengendalikan** apa yang sudah ada di rumah: mengganti saklar, menandai ruangan, dan mengubah suasana tanpa merombak tembok.

`classList` paling pas dianalogikan sebagai **mengganti mode saklar**. Sebuah lampu biasa hanya punya "nyala/mati". Tapi kalau kamu memasang **saklar pintar** (satu lapisan tambahan di atasnya), satu saklar yang sama bisa punya beberapa mode: "terang", "redup", "nyala otomatis saat senja". Menambah class `terpinjam` ke kartu buku persis seperti menekan saklar pintar menuju mode "tandai". Kamu tidak menulis ulang warna di setiap ruangan — cukup memindahkan tombol mode, dan cat yang sudah siap di CSS bekerja menyesuaikan suasana. Memakai `.style.backgroundColor = "..."` sebaliknya sama dengan melukis ulang sebuah sudut dengan kuas kecil setiap kali ruangan diganti suasana: mungkin tampak cepat, tetapi cepat menjadi rawan konsistensi dan sulit dirawat — itulah alasan kita **mendahulukan classList** dan meninggalkan style inline hanya untuk perubahan yang sifatnya sangat khusus.

`textContent` vs `innerHTML` bisa diibaratkan dua cara menindahkan tulisan ke dinding rumah. `textContent` adalah menempelkan **teks polos** — apa pun yang kamu tempel, seberapa pun liciknya, tetap jadi tulisan biasa di dinding. Sedangkan `innerHTML` adalah menempelkan **papan tulis dengan perintah isian**: jika tulisan yang kamu tempel ternyata bukan tulisan biasa, melainkan perintah mencabut kabel listrik, dinding pun ikut mencabut kabel sesuai perintah (itulah XSS). Selama kamu sendiri yang menulis perintahnya (template yang kamu kontrol penuh) dan tidak ada konten asing di dalamnya, aman saja; begitu konten user masuk ke `innerHTML`, kamu memasang kabel dari luar tanpa isolasi — dan itulah bahaya XSS yang harus dihindari.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Menandai status kartu** — `classList.toggle("terpinjam")` saat user mengeklik tombol pinjam; warna kartu langsung berubah tanpa kode CSS menumpuk di JS.
- **Menampilkan umpan balik** — menulis pesan "Buku berhasil dipinjam" ke elemen notifikasi memakai `textContent` karena pesan mengandung data user/API yang tidak boleh di-parse.
- **Menyimpan identitas elemen dinamis** — setiap kartu dibuat dengan `dataset.id = buku.id` sehingga nanti (materi 28) satu klik langsung tahu buku mana yang dituju.
- **Membaca dan menulis nilai form** — `input.value`, `input.checked`, `input.disabled` untuk membaca pencarian dan mengunci field yang tidak boleh diubah.
- **Membuka/menutup UI sekunder** — modal dan dropdown dikendalikan dengan `classList.add/remove("modal--aktif")`, jauh lebih bersih daripada merangakai `style.display` di banyak tempat.

## 6. Poin-poin Penting & Best Practices

- Utamakan membangun tampilan di **CSS**; biarkan JavaScript cukup menambah/menghapus **class** lewat `classList` (`add`, `remove`, `toggle`, `contains`, `replace`).
- Hindari `innerHTML` untuk data yang tidak kamu kontrol (input user, respons API, nilai dari `localStorage`). Untuk itu gunakan **`textContent`** — aman secara bawaan.
- Jika tetap memakai `innerHTML` untuk template yang kamu kontrol sendiri, pastikan tidak ada data user yang diselipkan di dalam string tersebut.
- Pahami perbedaan ketiga properti konten: `textContent` (teks polos), `innerText` (teks yang "terlihat" per CSS), `innerHTML` (parsing HTML). Jangan menukar fungsinya gegabah.
- Untuk atribut: gunakan **property langsung** (`value`, `checked`, `disabled`, `src`, `href`) karena ringkas dan aman dari typo; API `get/set/remove/hasAttribute` dipakai untuk atribut generik atau atribut kustom.
- Manfaatkan **`dataset`** untuk data kecil ber-`data-*`. Nama key otomatis diubah: `data-stok-buku` → `dataset.stokBuku`.
- Set `checked`/`disabled` sebagai nilai boolean (`input.disabled = true`), bukan string `"true"`.
- `element.style` menulis gaya terpisah dari stylesheet dan punya prioritas tinggi; gunakan hanya untuk nilai yang benar-benar dinamis per-elemen.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **XSS via `innerHTML` dengan input user.** `judul.innerHTML = inputUser` memungkinkan payload `<img onerror=...>` dieksekusi. Perbaikan: selalu `textContent` untuk data user/API; simpan `innerHTML` hanya untuk template statis yang kamu tulis sendiri.
- **Typo pada nama property style.** `el.style.backgroundcolor` tidak menghasilkan error (property tidak dikenal) tapi tidak berfungsi; CSS `background-color` ditulis `backgroundColor` dalam JS. Perbaikan: konsisten camelCase, atau hindari sama sekali dengan classList.
- **Menulis class lewat `className` dan menghapus class lain.** `el.className = "terpinjam"` mengganti **seluruh** class elemen. Perbaikan: pakai `classList.add`/`remove`/`toggle` yang mempertahankan class lain.
- **NodeList diproses seperti array untuk assignment.** Mengubah `.innerHTML` pada elemen hasil `querySelectorAll` (yang berisi banyak elemen) tidak masuk akal; `querySelectorAll` mengembalikan koleksi. Perbaikan: loop dengan `forEach`, atau pilih satu elemen jika yang kamu mau tautannya ke satu saja.
- **property vs atribut untuk `checked`/`value`.** `input.setAttribute("value", ...)` tidak selalu menyinkronkan `input.value` dan sebaliknya. Untuk form, pakai property (`input.value`, `input.checked`).

```javascript
// js/main.js

const info      = document.querySelector("#info");
const kartuSemua = document.querySelectorAll(".kartu-buku");

// (a) + (d) Menulis info dan membaca dataset
kartuSemua.forEach(kartu => {
    const judul = kartu.querySelector("h3").textContent;
    info.textContent = `Sekarang membaca: ${judul}`;
    console.log(`${judul} (kategori: ${kartu.dataset.kategori})`);

    // (b) Tandai stok 0 sejak awal via classList.add
    if (Number(kartu.dataset.stok) === 0) {
        kartu.classList.add("habis");
    }
});

// (c) Tombol: tandai SEMUA kartu habis — querySelectorAll kembali dipakai
const tombolTandai = document.querySelector("#tombol-tandai");
tombolTandai.addEventListener("click", () => {
    kartuSemua.forEach(kartu => kartu.classList.add("habis"));
    info.textContent = "Semua buku saat ini tidak tersedia.";
});

// Bonus: ganti teks tombol Pinjam pada kartu pertama
const kartuPertama = document.querySelector(".kartu-buku");
kartuPertama.querySelector(".btn-pinjam").textContent = "Dipinjam";

// (2) Nonaktifkan input anggota setelah 3 karakter
const inputAnggota = document.querySelector("#kartu-anggota");
inputAnggota.addEventListener("input", () => {
    inputAnggota.disabled = inputAnggota.value.trim().length >= 3;
});
```

**Pembahasan**: Latihan ini mengulang semua teknik manipulasi inti. Kardu pertama dibaca lewat `querySelector` di dalam loop `querySelectorAll`, lalu dibandingkan `Number(dataset.stok)`, karena `dataset` selalu mengembalikan **string** — `"0" === 0` akan `false`. `classList.add("habis")` menyalakan warna merah lewat CSS tanpa kita menulis style di JS. Teks tombol berubah hanya dengan `textContent` yang aman. Terakhir, event `input` (akan dibahas tuntas di materi 28) menjalankan manipulasi `disabled` — contoh alur "baca input → ubah property → halaman bereaksi".

**Ide lanjutan**: barang latihan 2 ingin pasangan bidang yang ketikannya tidak boleh diubah setelah lengkap: cukup ganti kondisi — misal cek `inputAnggota.value.includes(" ")` — dan samakan pola di atas. Latihan 27 akan memakai seluruh teknik ini saat membuat dan menghapus kartu secara dinamis.
