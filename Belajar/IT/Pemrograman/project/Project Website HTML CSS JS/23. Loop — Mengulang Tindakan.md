# Loop — Mengulang Tindakan

Setelah bisa mengambil keputusan (materi 22), kini kita belajar mengulang: memproses sekumpulan data — ratusan buku di katalog — dengan kode yang ditulis sekali saja. Materi ini memakai variabel, array, dan object dari materi 20-21, dan hasilnya (koleksi terfilter, terurut, terhitung) akan langsung dirender ke halaman di Level 5.

## 1. Penjelasan Singkat & Konsep Dasar

Bayangkan kamu harus menampilkan 100 buku ke halaman. Menulis 100 baris `console.log` satu per satu adalah kegilaan. Loop memecahkan ini: tulis **satu** instruksi, dan biarkan komputer mengulanginya untuk setiap elemen. Katalog perpustakaan yang besar, daftar peminjaman, laporan denda — semuanya butuh pengulangan. Tanpa loop, aplikasi web yang menangani data apa pun hampir tidak mungkin.

JavaScript modern menawarkan dua keluarga besar iterasi. Yang pertama adalah **array methods**: `forEach`, `map`, `filter`, `find`, `some`, `every`, `reduce`, `sort`. Ini adalah cara yang disarankan (idiomatic) untuk 95% kasus, karena tiap method menyatakan **tujuan** dengan jelas: `filter` berarti "ambil yang memenuhi syarat", `map` berarti "ubah tiap elemen", `reduce` berarti "kumpulkan jadi satu nilai". Kode jadi ekspresif dan jarang kena bug index seperti loop manual klasik. Yang kedua adalah **loop klasik** `for...of` (untuk urutan yang butuh `break`/`continue`) dan `for...in` (untuk property object — meski `Object.entries` biasanya lebih baik).

Kunci penting yang sering membingungkan pemula: **`forEach` vs `map`**. `forEach` hanya *melakukan* sesuatu terhadap setiap elemen dan **tidak mengembalikan nilai** — ia untuk efek samping seperti `console.log` atau mengubah tampilan. `map` **mengembalikan array baru** yang berisi hasil transformasi tiap elemen — ia untuk mengubah data, bukan sekadar memproses. Kalau kamu butuh hasil untuk dipakai lagi, pakai `map`; kalau hanya ingin melakukan aksi, pakai `forEach`. Memilih yang salah adalah salah satu kesalahan paling umum di awal belajar.

Benang merah menuju Level 5: di Level 5 kamu akan mengubah array buku menjadi potongan HTML. `map` yang mengubah satu buku menjadi satu string kartu HTML lalu di-`join` — persis pola yang dipakai untuk merender katalog — akan menjadi jembatan dari data (Level 4) ke tampilan (Level 5). Sementara `filter`, `find`, `some`, `every`, dan `reduce` adalah otak dari fitur pencarian, pengecekan ketersediaan, dan statistik koleksi yang akan dibangun setelahnya.

## 2. Fungsi & Kegunaan Utama dalam Web

Di **Perpustakaan Digital Kota**, setiap halaman yang menampilkan lebih dari satu item pasti melibatkan loop:

- **Render katalog** — `map` mengubah setiap object buku menjadi kartu HTML; hasilnya digabung lalu disisipkan ke halaman (dibahas lebih dalam di Level 5).
- **Pencarian & filter** — `filter` menyaring buku yang cocok dengan keyword atau kategori; `find` mengambil satu buku berdasarkan id saat user membuka detail.
- **Sortir harga & judul** — `sort` mengurutkan koleksi (murah→mahal, A→Z) untuk pengalaman belanja/eksplorasi yang lebih baik.
- **Statistik koleksi** — `reduce` menjumlahkan total nilai koleksi (harga × stok) atau total stok seluruh perpustakaan untuk dashboard.
- **Validasi** — `some`/`every` menjawab "apakah ada buku yang stoknya habis?" atau "apakah semua buku sudah dicek?" sebelum memproses peminjaman.
- **Notifikasi & update** — `forEach` menandai semua notifikasi terbaca, atau mengirim pesan ke semua anggota yang buku pinjamannya jatuh tempo.

Intinya: dari katalog sampai dashboard admin, hampir tidak ada fitur yang tidak menyentuh iterasi. Menguasai array methods sama artinya dengan menguasai pengolahan data di web.

## 3. Contoh Kode & Implementasi Real-World

```javascript
// Data koleksi perpustakaan — semua contoh memakai data ini
const katalog = [
    { id: 1, judul: "Clean Code",       stok: 5,  harga: 150000, kategori: "Teknologi" },
    { id: 2, judul: "Laskar Pelangi",   stok: 3,  harga: 95000,  kategori: "Fiksi" },
    { id: 3, judul: "The Great Gatsby", stok: 0,  harga: 120000, kategori: "Fiksi" },
    { id: 4, judul: "Cosmos",           stok: 8,  harga: 200000, kategori: "Sains" },
];

// ─── forEach — untuk efek samping, TIDAK return apa pun ─────────────────
// Cocok saat kamu "melakukan sesuatu" per elemen, tanpa butuh hasil kembali
katalog.forEach((buku, index) => {
    console.log(`${index + 1}. ${buku.judul} (stok ${buku.stok})`);
});

// ─── map — TRANSFORMASI, return array baru dengan hasil tiap elemen ─────
// Beda kunci dari forEach: map memberi nilai balik untuk dipakai lagi
const daftarJudul = katalog.map(buku => buku.judul);
console.log(daftarJudul); // ["Clean Code", "Laskar Pelangi", "The Great Gatsby", "Cosmos"]

// Contoh paling nyata di web: ubah data → HTML (dipakai terus di Level 5)
const kartuHTML = katalog.map(buku => `
    <article class="kartu-buku">
        <h3>${buku.judul}</h3>
        <p>${buku.stok > 0 ? `Tersedia (${buku.stok})` : "Habis"}</p>
    </article>
`).join("");
// Hasilnya satu string panjang berisi semua kartu, siap disisipkan ke DOM

// ─── filter — AMBIL elemen yang memenuhi kondisi, return array baru ─────
const bukuTersedia = katalog.filter(buku => buku.stok > 0);
const bukuFiksi    = katalog.filter(buku => buku.kategori === "Fiksi");
const bukuDiBawah100k = katalog.filter(buku => buku.harga <= 100000);
console.log(bukuFiksi.map(b => b.judul)); // ["Laskar Pelangi", "The Great Gatsby"]

// ─── find — ambil SATU elemen pertama yang cocok (atau undefined) ───────
const bukuClean = katalog.find(buku => buku.judul.includes("Clean"));
console.log(bukuClean); // { id: 1, judul: "Clean Code", ... }

// findIndex — seperti find, tapi mengembalikan posisinya
const indexGatsby = katalog.findIndex(buku => buku.id === 3);
console.log(indexGatsby); // 2

// ─── some / every — cek kondisi pada koleksi, return boolean ─────────────
const adaYangHabis = katalog.some(buku => buku.stok === 0);   // true (Gatsby)
const semuaTersedia = katalog.every(buku => buku.stok > 0);   // false
const semuaDiAtas50k = katalog.every(buku => buku.harga > 50000); // true
console.log(adaYangHabis, semuaTersedia, semuaDiAtas50k); // true false true

// ─── reduce — akumulasi SEMUA elemen menjadi satu nilai ─────────────────
// Parameter kedua (0) adalah nilai awal — WAJIB untuk penjumlahan
const totalStok = katalog.reduce((total, buku) => total + buku.stok, 0);
console.log(totalStok); // 5 + 3 + 0 + 8 = 16

// Total nilai koleksi = jumlah (harga × stok) untuk semua buku
const totalNilaiKoleksi = katalog.reduce(
    (total, buku) => total + buku.harga * buku.stok,
    0
);
console.log(totalNilaiKoleksi); // 150000*5 + 95000*3 + 120000*0 + 200000*8 = 2.635.000

// ─── sort — urutkan; HATI-HATI ini MENGUBAH array asli! ─────────────────
// Default sort membandingkan sebagai STRING → hasil mengejutkan:
console.log([10, 2, 1].sort());           // [1, 10, 2] ← bukan urutan angka!
// Selalu beri fungsi pembanding, dan salin dulu agar array asli aman:
const diurutHarga = [...katalog].sort((a, b) => a.harga - b.harga);      // murah → mahal
const diurutJudul = [...katalog].sort((a, b) => a.judul.localeCompare(b.judul));
console.log(diurutHarga.map(b => b.harga)); // [95000, 120000, 150000, 200000]
console.log(katalog.length);                 // 4 — array asli TIDAK berubah

// ─── Chaining — gabungkan beberapa method dalam satu pipa ───────────────
// Pola yang sangat kuat: filter → sort → map
const hasilCari = katalog
    .filter(buku => buku.kategori === "Fiksi")        // ambil fiksi
    .filter(buku => buku.stok > 0)                    // yang tersedia saja
    .sort((a, b) => a.judul.localeCompare(b.judul))   // urutkan A→Z
    .map(buku => buku.judul);                         // ambil judulnya
console.log(hasilCari); // ["Laskar Pelangi"]

// ─── for...of — saat butuh break / continue ─────────────────────────────
// Array methods tidak punya break/continue; for...of hadir untuk ini
const peminjamanHariIni = [];
for (const buku of katalog) {
    if (buku.stok === 0) continue;    // lewati yang habis
    if (buku.harga > 150000) break;   // berhenti di buku yang terlalu mahal
    peminjamanHariIni.push(buku.judul);
}
console.log(peminjamanHariIni); // ["Clean Code", "Laskar Pelangi"]

// ─── for...in — untuk property object; sering diganti Object.entries ────
const bukuDetail = { judul: "Cosmos", pengarang: "Carl Sagan", tahun: 1980 };
for (const key in bukuDetail) {
    console.log(`${key}: ${bukuDetail[key]}`);
}
// Rekomendasi modern: Object.entries memberi pasangan [kunci, nilai]
Object.entries(bukuDetail).forEach(([key, value]) => {
    console.log(`${key}: ${value}`);
});
```

## 4. Analogi Sederhana — Membangun Rumah

Loop adalah **mesin yang berkeliling rumah** dan listrik yang menyusuri tiap terminal untuk bekerja berulang.

- **forEach** = petugas keamanan yang berjalan mengelilingi seluruh ruangan, mengecek setiap lampu satu per satu, lalu pindah ke lampu berikutnya. Ia melakukan aksi (memeriksa) tapi tidak mengumpulkan apa pun — jika lampu menyala, ia mencatatnya (efek samping), selesai.
- **map** = listrik yang menyusuri tiap terminal dan **mengubah** apa yang dilewatinya — setiap stopkontak diberi kabel adapter baru, dan hasilnya adalah daftar terminal yang sudah terpasang adapter (array baru).
- **filter** = saat memeriksa, menyaring **terminal yang bermasalah** — hanya yang aman yang dilaporkan. Hasilnya daftar baru yang lebih pendek dari daftar awal.
- **reduce** = tukang listrik yang menghitung **total konsumsi daya** seluruh rumah: mulai dari nol, menjumlahkan beban tiap ruangan satu per satu, dan pulang dengan satu angka final.
- **sort** = menyusun ulang urutan ruangan berdasarkan ukuran; ingat, ia menyusun ulang di rumah yang sama (mutasi), jadi kalau mau denah asli tetap utuh, salin denahnya dulu.
- **for...of dengan break/continue** = petugas yang sedang berkeliling tapi diberi aturan: *continue* = "lewati saja ruangan ini", *break* = "berhenti total, sudah cukup, pulang".

Di Level 5, mesin-mesin ini akan "mengisi ruangan" — setiap hasil loop akan menyalakan lampu kartu buku di halaman nyata.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

1. **Merender daftar kartu buku** — `map` + `join` mengubah array katalog menjadi HTML. Gunakan `map` (bukan `forEach`) karena kamu butuh hasil berupa string/template untuk ditampilkan.
2. **Pencarian real-time di katalog** — setiap ketikan user memanggil pipa `filter` (keyword/kategori/ketersediaan) → `sort` → `map`. Chaining membuat logika ini terbaca seperti kalimat.
3. **Halaman detail buku** — `find` berdasarkan `id` mengambil satu buku; jika hasilnya `undefined` (buku tidak ada), tampilkan pesan "Buku tidak ditemukan".
4. **Statistik dashboard admin** — `reduce` menghitung total nilai koleksi, total stok, dan rata-rata harga; `some`/`every` memberi tanda bahaya "ada stok habis" untuk seluruh rak.
5. **Berhenti lebih awal saat ketemu** — `find`/`some` berhenti di elemen pertama yang cocok (efisien untuk data besar); `for...of` dengan `break` saat iterasi perlu logika lompat yang kompleks.

## 6. Poin-poin Penting & Best Practices

- **Modern JavaScript ES6+:** gunakan array methods (`map`, `filter`, `reduce`) daripada loop manual `for` klasik. Loop manual lebih panjang, lebih lambat dibaca, dan rentan bug index off-by-one.
- **`forEach` vs `map`:** butuh hasil → `map`; hanya melakukan aksi → `forEach`. Ini perbedaan konseptual yang paling sering diuji.
- **Jangan mutasi array asli.** `sort` (dan `reverse`, `splice`) mengubah array pemanggilnya. Salin dulu dengan spread `[...arr]` sebelum mengubah, agar data sumber tetap bersih.
- **`sort` butuh fungsi pembanding untuk angka**: `(a, b) => a - b`. Sort default mengurutkan sebagai string dan menghasilkan `[1, 10, 2]`.
- **Selalu beri nilai awal pada `reduce`** (`0` untuk penjumlahan). Tanpa nilai awal, array kosong akan error, dan hasil untuk array berisi object bisa jadi `undefined`.
- **Gunakan `localeCompare` untuk mengurutkan teks berbahasa Indonesia** agar huruf dan karakter khusus diurutkan dengan benar.
- **Perhatikan bahwa `map`/`filter`/`reduce` tidak mengubah array asli** — mereka mengembalikan array/nilai baru. Ini membuat kode lebih mudah diprediksi.
- Catatan **Type Safety**: TypeScript akan menangkap callback yang salah tipe (misal `reduce` yang return-nya bukan number), dan memberi tahu jika kamu memanggil property yang tidak ada di object array — bug yang biasanya baru kelihatan saat runtime.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

1. **Sort default mengurutkan sebagai string.** `[10, 2, 1].sort()` menghasilkan `[1, 10, 2]`. **Perbaikan:** selalu fungsi pembanding `(a, b) => a - b` untuk number, `localeCompare` untuk teks.

```javascript
// ❌ Salah
katalog.sort(); // mengurutkan "judul" sebagai string berbahaya & salah
// ✅ Benar
[...katalog].sort((a, b) => a.judul.localeCompare(b.judul));
```

2. **Sort bermutasi array asli.** Karena `sort` mengubah array yang dipanggil, data katalog jadi kacau saat user sortir berulang. **Perbaikan:** salin dengan `[...arr]` atau `Array.from` sebelum sort.
3. **Lupa `return` di `map` → array berisi `undefined`.** Kurung kurawal di arrow function tanpa `return` menghasilkan `undefined` untuk tiap elemen. **Perbaikan:** gunakan ekspresi singkat tanpa `{}`, atau tulis `return` secara eksplisit.

```javascript
// ❌ Salah — semua elemen jadi undefined
const hargaSalah = katalog.map(buku => { buku.harga; });
// ✅ Benar
const hargaBenar = katalog.map(buku => buku.harga);
```

4. **`reduce` tanpa nilai awal.** Untuk array kosong ini melempar `TypeError`; untuk array berisi object, hasil pertama menjadi object itu sendiri. **Perbaikan:** selalu berikan nilai awal yang sesuai tipe hasil (`0` untuk angka, `""` untuk string, `[]` untuk array).
5. **Closure dalam loop menghitung index yang sama** (jumpa juga di materi fungsi) — saat memakai `for...of` dengan `let`, tiap iterasi mendapat `buku` baru sehingga aman, tapi hati-hati jika memakai callback yang menangkap index dari loop `for` dengan `var`.

## 8. Mini Project / Soal Latihan & Kunci Jawaban

**Tantangan:** Dengan data `katalog`, selesaikan empat tugas: (a) Hitung **total nilai koleksi per kategori** memakai `reduce`. (b) Buat pipa data: **filter buku tersedia → sort harga termurah → map format** menjadi array string seperti `"Rp 95.000 — Laskar Pelangi"`. (c) Tampilkan judul buku dengan `forEach` (efek samping: log ke konsol). (d) Cek dengan `every` apakah semua buku berharga di bawah Rp 250.000.

```javascript
const katalog = [
    { id: 1, judul: "Clean Code",       stok: 5,  harga: 150000, kategori: "Teknologi" },
    { id: 2, judul: "Laskar Pelangi",   stok: 3,  harga: 95000,  kategori: "Fiksi" },
    { id: 3, judul: "The Great Gatsby", stok: 0,  harga: 120000, kategori: "Fiksi" },
    { id: 4, judul: "Cosmos",           stok: 8,  harga: 200000, kategori: "Sains" },
];
```

**Solusi & Pembahasan:**

```javascript
// (a) Total nilai koleksi per kategori — reduce mengakumulasi ke dalam object
const nilaiPerKategori = katalog.reduce((hasil, buku) => {
    const nilai = buku.harga * buku.stok;
    hasil[buku.kategori] = (hasil[buku.kategori] || 0) + nilai;
    return hasil;
}, {});
console.log(nilaiPerKategori);
// { Teknologi: 750000, Fiksi: 285000, Sains: 1600000 }

// (b) Pipa data: filter tersedia → sort harga termurah → map format
const daftarTermurah = katalog
    .filter(buku => buku.stok > 0)                      // hanya yang tersedia
    .sort((a, b) => a.harga - b.harga)                  // termurah di depan
    .map(buku => `Rp ${buku.harga.toLocaleString("id-ID")} — ${buku.judul}`);
console.log(daftarTermurah);
// ["Rp 95.000 — Laskar Pelangi", "Rp 150.000 — Clean Code", "Rp 200.000 — Cosmos"]

// (c) forEach — efek samping, tidak return apa pun
katalog.forEach(buku => console.log(`Menyiapkan: ${buku.judul}`));

// (d) every — cek seluruh koleksi, hasil boolean
const semuaMurah = katalog.every(buku => buku.harga < 250000);
console.log(semuaMurah); // true — semua di bawah 250 ribu
```

**Pembahasan:** Bagian (a) memakai `reduce` dengan nilai awal object `{}`; trik `hasil[buku.kategori] || 0` menghindari `NaN` saat kategori pertama kali ditemui (nilai awalnya belum ada = `undefined`, lalu `|| 0` menjadikannya 0). Bagian (b) menunjukkan kekuatan chaining: urutan filter→sort→map penting — filter dulu agar sort tidak membuang waktu, sort memakai `[...]`? di sini tidak perlu karena `filter` sudah menghasilkan array baru, jadi aman di-sort. Bagian (c) menegaskan `forEach` dipakai murni untuk efek samping. Bagian (d) membuktikan `every` mengembalikan `true` hanya jika semua elemen lolos. Coba ubah angka 250000 menjadi 200000 dan perhatikan hasil `(d)` berubah menjadi `false` karena Cosmos tepat 200.000 (bukan di bawahnya).
