# Fungsi — Kode yang Reusable

Ini materi pamungkas JavaScript dasar Level 4. Fungsi adalah cara membungkus logika (kondisi dari materi 22 dan loop dari materi 23) menjadi satu blok yang bisa dipanggil berulang — dan inilah fondasi untuk semua arsitektur aplikasi, termasuk DOM manipulation di Level 5.

## 1. Penjelasan Singkat & Konsep Dasar

Saat aplikasi tumbuh, kode yang sama akan dipakai berkali-kali: format harga muncul di kartu buku, di halaman detail, di laporan denda. Menyalin-tempel kode itu ke mana-mana melanggar prinsip **DRY (Don't Repeat Yourself)** — dan mengundang bug, karena perbaikan harus dilakukan di banyak tempat dan mudah terlewat. Fungsi memecahkan ini: tulis logika **sekali**, beri nama yang jelas, lalu panggil dari mana saja. Fungsi adalah unit reusable terkecil dari sebuah program.

JavaScript punya dua cara utama mendefinisikan fungsi. **Function declaration** (`function nama() {}`) bersifat *hoisted* — bisa dipanggil sebelum baris deklarasinya, karena seluruh deklarasi diangkat ke atas scope saat eksekusi. **Arrow function** (`const nama = () => {}`) tidak di-hoisted (harus didefinisikan dulu sebelum dipanggil) dan yang lebih penting: ia **tidak punya `this` sendiri** — ia mewarisi `this` dari scope sekitarnya. Perbedaan `this` ini baru terasa di event handling (Level 5) dan method object; untuk sekarang cukup tahu bahwa arrow function adalah pilihan utama untuk callback dan fungsi singkat.

Dua konsep yang membuat fungsi JavaScript "hidup": **higher-order function** dan **closure**. Higher-order function adalah fungsi yang menerima fungsi lain sebagai argumen (kamu sudah memakainya — callback di `map`, `filter`, `reduce`) atau mengembalikan fungsi. Memahaminya berarti kamu bisa membuat "pabrik" fungsi seperti `buatFilter(kategori)` yang mengembalikan fungsi filter spesifik. **Closure** adalah fungsi yang "mengingat" variabel dari scope tempat ia dilahirkan, bahkan setelah scope itu selesai — inilah mesin di balik counter yang menyimpan state, dan salah satu konsep yang paling membedakan JavaScript dari bahasa lain.

Benang merah menuju Level 5: di Level 5, hampir semua kode ditulis dalam fungsi — `renderKatalog(buku)`, `buatKartuBuku(buku)`, handler event. Fungsi yang kamu tulis di sini (misal `formatHarga`, `hitungDenda`, `buatFilter`) akan dipanggil dari event listener dan dari dalam fungsi render. Semakin kecil dan murni fungsi kamu, semakin mudah diuji dan dipakai ulang — ini juga persiapan untuk Level 6 (async/await memakai fungsi `async`) dan Level 7 (arsitektur aplikasi).

## 2. Fungsi & Kegunaan Utama dalam Web

Di **Perpustakaan Digital Kota**, fungsi ada di balik setiap fitur yang bisa dipanggil berulang:

- **Format harga & angka** — `formatHarga(150000)` → `"Rp 150.000"`. Dipakai di kartu buku, halaman detail, dan laporan, jadi cukup ditulis sekali.
- **Aturan peminjaman & denda** — `hitungDenda(hariTerlambat, tarif)` mengembalikan jumlah denda; `bolehPinjam(anggota, jumlah)` mengecek batas pinjam. Logika bisnis tersentralisasi di satu tempat.
- **Filter dan pencarian katalog** — `buatFilter(kategori)` (higher-order) menghasilkan fungsi filter spesifik; `cariBuku(keyword)` memakai `filter` + `includes` untuk pencarian.
- **Render data ke tampilan** — `buatKartuBuku(buku)` mengubah satu object buku menjadi HTML (jembatan ke Level 5); `renderKatalog(list)` memanggilnya untuk semua buku.
- **Counter kunjungan / statistik** — closure `buatCounter()` mengingat jumlah kunjungan halaman tanpa variabel global yang berantakan.
- **Operasi async (teaser Level 6)** — `async function ambilDataBuku()` menandai fungsi agar bisa `await` fetch dari API.

Fungsi membuat aplikasi modular: setiap bagian punya tanggung jawab jelas, bisa diuji sendiri, dan perubahan aturan bisnis (misal denda naik) hanya perlu diedit di satu fungsi.

## 3. Contoh Kode & Implementasi Real-World

```javascript
// Data koleksi perpustakaan — dipakai semua contoh
const katalog = [
    { id: 1, judul: "Clean Code",       stok: 5,  harga: 150000, kategori: "Teknologi" },
    { id: 2, judul: "Laskar Pelangi",   stok: 3,  harga: 95000,  kategori: "Fiksi" },
    { id: 3, judul: "The Great Gatsby", stok: 0,  harga: 120000, kategori: "Fiksi" },
    { id: 4, judul: "Cosmos",           stok: 8,  harga: 200000, kategori: "Sains" },
];

// ─── Function Declaration — hoisted, boleh dipanggil sebelum definisinya ──
// Cara klasik, cocok untuk fungsi utama aplikasi
function formatHarga(angka) {
    return angka.toLocaleString("id-ID", {
        style: "currency",
        currency: "IDR",
        minimumFractionDigits: 0,
    });
}
console.log(formatHarga(150000)); // "Rp 150.000"

// Hoisting: fungsi ini dipanggil SEBELUM baris deklarasinya — tetap jalan
console.log(cekStok(katalog[1])); // "Stok terbatas (3)"
function cekStok(buku) {
    if (buku.stok > 10) return "Stok banyak";
    if (buku.stok > 0)  return `Stok terbatas (${buku.stok})`;
    return "Stok habis";
}

// ─── Arrow Function — tidak hoisted, this berbeda, gaya modern ──────────
// Untuk callback dan fungsi singkat. Perhatikan: tidak punya `this` sendiri
const formatJudul = (buku) => `${buku.judul} — ${buku.kategori}`;
console.log(formatJudul(katalog[0])); // "Clean Code — Teknologi"

// Satu parameter: bisa tanpa kurung. Satu ekspresi: bisa tanpa return
const kuadrat = n => n * n;
const naikStok = buku => ({ ...buku, stok: buku.stok + 1 }); // return object → perlu kurung

// Arrow + higher-order dipakai setiap hari: callback map/filter
const daftarJudul = katalog.map(buku => buku.judul);

// ─── Default Parameter — nilai awal jika argumen tidak dikirim ──────────
function hitungDenda(hariTerlambat, dendaPerHari = 1000) {
    if (hariTerlambat < 0) throw new Error("Hari terlambat tidak boleh negatif");
    return hariTerlambat * dendaPerHari;
}
console.log(hitungDenda(7));       // 7000  → pakai default 1000
console.log(hitungDenda(7, 2000)); // 14000 → tarif khusus

// ─── Higher-Order Function — menerima / mengembalikan fungsi ────────────
// "Pabrik filter": satu fungsi menghasilkan banyak filter spesifik
function buatFilter(field, nilai) {
    // Closure: fungsi dalam ini "mengingat" field dan nilai
    return buku => buku[field] === nilai;
}
const filterFiksi     = buatFilter("kategori", "Fiksi");
const filterTeknologi = buatFilter("kategori", "Teknologi");
const bukuFiksi       = katalog.filter(filterFiksi);
const bukuTeknologi   = katalog.filter(filterTeknologi);
console.log(bukuFiksi.map(b => b.judul));     // ["Laskar Pelangi", "The Great Gatsby"]
console.log(bukuTeknologi.map(b => b.judul)); // ["Clean Code"]

// Fungsi yang menerima fungsi (callback) — pola wajib untuk transformasi
function terapkanPerItem(list, transformasi) {
    return list.map(transformasi);
}
const kartuRingkas = terapkanPerItem(katalog, b => `${b.judul}: ${cekStok(b)}`);
console.log(kartuRingkas);
// ["Clean Code: Stok terbatas (5)", "Laskar Pelangi: Stok terbatas (3)", ...]

// ─── Closure — fungsi yang mengingat scope tempat ia lahir ──────────────
// Mesin counter: `count` tersembunyi, tidak bocor ke scope global
function buatCounter(awal = 0) {
    let count = awal; // variabel ini "ditangkap" oleh closure di bawah
    return {
        increment: () => ++count,
        decrement: () => --count,
        reset:     () => { count = awal; },
        nilai:     () => count,
    };
}
const counterKunjungan = buatCounter(0);
counterKunjungan.increment();   // 1
counterKunjungan.increment();   // 2
counterKunjungan.decrement();   // 1
console.log(counterKunjungan.nilai()); // 1

// Pre-bound value: closure yang selalu mengingat konteks
function buatPesanBuku(judul) {
    return () => `Buku "${judul}" siap dipinjam`;
}
const pesanCosmos = buatPesanBuku("Cosmos");
console.log(pesanCosmos()); // 'Buku "Cosmos" siap dipinjam'

// ─── Pure Function & Side Effect ────────────────────────────────────────
// Pure: input sama → output sama, tidak mengubah apa pun di luar
function hitungNilaiKoleksi(buku) {
    return buku.harga * buku.stok;
}
console.log(hitungNilaiKoleksi(katalog[0])); // 750000 — selalu sama, aman

// Side effect: mengubah state di luar fungsi (misal array asli)
// ❌ Ini fungsi yang MENGUBAH inputnya (impure) — hindari untuk fungsi kecil
function tambahStokImpure(buku, jumlah) {
    buku.stok += jumlah;  // memutasi object yang dikirim!
    return buku.stok;
}
// ✅ Lebih baik: kembalikan nilai baru, biarkan array asli bersih
function tambahStokPure(buku, jumlah) {
    return { ...buku, stok: buku.stok + jumlah };
}

// ─── Async Function — TEASER, dibahas penuh di Level 6 ──────────────────
// `async` menandai fungsi agar bisa menunggu operasi yang butuh waktu
async function ambilDataBuku() {
    try {
        const response = await fetch("/api/buku");
        if (!response.ok) throw new Error("Gagal memuat data");
        return await response.json();
    } catch (error) {
        console.error("Terjadi kesalahan:", error);
        return []; // kembalikan array kosong sebagai fallback yang aman
    }
}
// Belum dipanggil di sini — cukup pahami polanya untuk sekarang
```

## 4. Analogi Sederhana — Membangun Rumah

Fungsi adalah **rangkaian otomatisasi reusable** di dalam rumah. Sama seperti satu prosedur "saklar utama" yang bisa dipanggil dari ruangan mana pun, satu fungsi dipanggil dari banyak tempat tanpa menyalin kabelnya.

- **Function declaration** = prosedur standar rumah yang dipasang permanen dan bisa dipakai siapa pun, kapan pun — termasuk sebelum "dipasang" secara tertulis (hoisting), seperti resep yang sudah hafal di luar kepala.
- **Arrow function** = alat portable yang ringkas, dipegang di tangan (callback) dan tidak membawa "identitas ruangan" sendiri (`this` tidak mengikat) — pas untuk tugas singkat yang didelegasikan.
- **Default parameter** = saklar dengan pengaturan bawaan: jika tidak diubah, otomatis memakai setelan pabrik (denda default Rp 1.000/hari), tapi tetap bisa dikustomisasi per pemakaian.
- **Higher-order function** = pabrik prosedur: satu mesin "buat saklar otomatis" yang menerima spesifikasi (field, nilai) dan mengeluarkan saklar siap pakai untuk tiap kebutuhan (filter Fiksi, filter Teknologi).
- **Closure** = otomatisasi yang **mengingat pengaturan khusus dari ruang asalnya**: meski dipindah ke ruangan lain, ia tetap ingat kelembapan target dari ruang tempat ia dikonfigurasi (variabel `count`/`field`/`nilai`).
- **Pure function** = prosedur yang hanya bekerja di atas data yang dikirim dan tidak menyentuh barang-barang ruangan lain (tidak memutasi state global) — mudah ditebak dan aman dipanggil berkali-kali.

Di Level 5, seluruh saklar ini dihubungkan ke tombol di dinding — event listener yang memanggil fungsi saat user mengklik, mengetik, atau mengirim form.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

1. **Format ulang data untuk tampilan** — `formatHarga(150000)` dipakai di kartu buku, detail buku, dan keranjang. Satu definisi, banyak pemanggilan → DRY.
2. **Logika bisnis peminjaman** — `hitungDenda(hari, tarif)` dan `bolehPinjam(anggota, judulBuku)` menampung aturan yang berubah (tarif baru, batas pinjam). Perubahan aturan cukup di satu tempat.
3. **Callback untuk array methods** — arrow function sebagai argumen `map`/`filter`/`reduce`; `buatFilter("kategori", "Fiksi")` (higher-order) menghasilkan filter yang bisa disimpan dan dipakai ulang.
4. **Event handler (Level 5)** — fungsi bernama seperti `saatTombolPinjamDiklik(event)` dipanggil oleh `addEventListener`; memakai fungsi bernama lebih mudah dibaca dan dilepas daripada fungsi anonim.
5. **State yang tersembunyi** — `buatCounter()` (closure) menghitung jumlah klik "Pinjam" per sesi tanpa variabel global; `buatPesanBuku(judul)` membungkus pesan dengan nilai yang sudah terikat.
6. **Data dari server (teaser Level 6)** — `async function ambilDataBuku()` akan menjadi pintu masuk semua fetch di aplikasi.

## 6. Poin-poin Penting & Best Practices

- **Nama fungsi deskriptif, berawalan kata kerja**: `formatHarga`, `hitungDenda`, `renderKatalog`, `cariBuku`. Fungsi yang namanya "melakukan" akan terbaca seperti kalimat.
- **Jaga fungsi kecil dan murni (small pure functions).** Input sama → output sama, tanpa memutasi argumen atau state global. Ini membuat fungsi mudah diuji dan dipakai ulang.
- **Satu fungsi, satu tanggung jawab.** Jika fungsi melakukan tiga hal, pecah. Ini menyederhanakan debugging dan tes.
- **DRY (Don't Repeat Yourself):** jika kode yang sama muncul dua kali atau lebih, ekstrak jadi fungsi. Tapi jangan over-abstract — ekstrak saat benar-benar diulang, bukan karena "mungkin nanti dipakai".
- **Hati-hati memutasi argumen.** Mengubah object/array yang dikirim bisa mengejutkan pemanggil. Lebih aman mengembalikan nilai baru (misal spread `{...buku}`).
- **Arrow function untuk callback, function declaration untuk fungsi utama.** Gunakan keduanya dengan sadar: arrow singkat untuk callback, declaration (hoisted) untuk fungsi yang dipanggil dari banyak tempat.
- **Default parameter untuk argumen opsional**, bukan melakukan manipulasi di dalam fungsi.
- **Hindari callback hell** dengan `async/await` (dibahas penuh di Level 6) — untuk sekarang, jangan membuat nesting callback terlalu dalam.
- Catatan **Type Safety**: TypeScript akan memeriksa tipe parameter dan nilai balik fungsi (`function hitungDenda(hari: number): number`), menangkap kesalahan tipe di argumen **sebelum** kode berjalan.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

1. **Lupa `return` di arrow function ber-kurung kurawal** → hasilnya `undefined`. **Perbaikan:** tanpa `{}` untuk ekspresi singkat, atau tulis `return` eksplisit.

```javascript
// ❌ Salah — mengembalikan undefined
const hargaSalah = katalog.map(buku => { buku.harga * 2 });
// ✅ Benar
const hargaBenar = katalog.map(buku => buku.harga * 2);
```

2. **Sort (dan mutasi lain) mengubah array asli.** Ini juga soal fungsi: method seperti `sort` bermutasi argumennya. **Perbaikan:** salin dulu dengan `[...arr].sort(...)` sebelum memanggil method mutasi.
3. **Mengubah parameter (object) tanpa sadar.** Fungsi yang mengubah `buku.stok` memengaruhi data asli di tempat lain. **Perbaikan:** kembalikan object baru dengan spread, dan simpan `buku` asli tetap utuh.

```javascript
// ❌ Fungsi yang memutasi data pemanggil
function pinjam(buku) { buku.stok--; }
// ✅ Mengembalikan nilai baru
function pinjam(buku) { return { ...buku, stok: buku.stok - 1 }; }
```

4. **Closure dalam loop yang menangkap index sama.** Masalah klasik: memanggil fungsi yang menangkap variabel loop setelah loop selesai — semua memakai nilai terakhir. **Perbaikan:** gunakan `let` di `for...of` (setiap iterasi punya binding baru) atau `const` di array methods.

```javascript
// ❌ Semua mencetak 3 (nilai terakhir loop) karena var + closure
const fns = [];
for (var i = 0; i < 3; i++) { fns.push(() => i); }
console.log(fns.map(f => f())); // [3, 3, 3]
// ✅ let memberi binding per iterasi
const fns2 = [];
for (let i = 0; i < 3; i++) { fns2.push(() => i); }
console.log(fns2.map(f => f())); // [0, 1, 2]
```

5. **Menggunakan arrow function saat `this` diperlukan.** Arrow tidak punya `this` sendiri; di method object atau event handler yang butuh `this`, bisa menghasilkan perilaku tak terduga. Untuk sekarang: di event handler (Level 5), perhatikan apakah kamu butuh `this` dari elemen atau dari scope luar.

## 8. Mini Project / Soal Latihan & Kunci Jawaban

**Tantangan:** Dengan data `katalog`, kerjakan: (a) Buat fungsi `cariBuku(keyword)` yang mengembalikan array buku yang judulnya mengandung keyword (abaikan huruf besar/kecil). (b) Buat fungsi `hitungDenda(hariTerlambat, tarifPerHari = 1000)` memakai default parameter; jika hari negatif, lempar error. (c) Buat higher-order `buatFilter(field, nilai)` lalu pakai untuk mengambil semua buku kategori "Fiksi" yang tersedia. (d) Buat closure `buatCounter` untuk menghitung berapa kali tombol "Pinjam" diklik, dan jalankan beberapa kali.

```javascript
const katalog = [
    { id: 1, judul: "Clean Code",       stok: 5,  harga: 150000, kategori: "Teknologi" },
    { id: 2, judul: "Laskar Pelangi",   stok: 3,  harga: 95000,  kategori: "Fiksi" },
    { id: 3, judul: "The Great Gatsby", stok: 0,  harga: 120000, kategori: "Fiksi" },
    { id: 4, judul: "Cosmos",           stok: 8,  harga: 200000, kategori: "Sains" },
];
```

**Solusi & Pembahasan:**

```javascript
// (a) Pencarian keyword — case-insensitive, pakai array methods
function cariBuku(keyword) {
    const kata = keyword.toLowerCase();
    return katalog.filter(buku =>
        buku.judul.toLowerCase().includes(kata)
    );
}
console.log(cariBuku("laskar").map(b => b.judul)); // ["Laskar Pelangi"]
console.log(cariBuku("CODE").map(b => b.judul));   // ["Clean Code"] (case tidak masalah)

// (b) Default parameter + validasi input
function hitungDenda(hariTerlambat, tarifPerHari = 1000) {
    if (hariTerlambat < 0) throw new Error("Hari terlambat tidak boleh negatif");
    return hariTerlambat * tarifPerHari;
}
console.log(hitungDenda(7));       // 7000  (default tarif 1000)
console.log(hitungDenda(7, 2000)); // 14000 (tarif khusus)

// (c) Higher-order function → filter spesifik, lalu digabung dengan filter
function buatFilter(field, nilai) {
    return buku => buku[field] === nilai;
}
const filterFiksi = buatFilter("kategori", "Fiksi");
const fiksiTersedia = katalog.filter(filterFiksi).filter(buku => buku.stok > 0);
console.log(fiksiTersedia.map(b => b.judul)); // ["Laskar Pelangi"]

// (d) Closure untuk counter klik
function buatCounter(awal = 0) {
    let count = awal;
    return {
        klik:    () => ++count,
        total:   () => count,
        reset:   () => { count = awal; },
    };
}
const klikPinjam = buatCounter(0);
klikPinjam.klik();                 // 1 — user klik "Pinjam" di kartu Cosmos
klikPinjam.klik();                 // 2 — klik lagi di kartu lain
console.log(`Total klik pinjam: ${klikPinjam.total()}`); // 2
klikPinjam.reset();
console.log(klikPinjam.total());   // 0
```

**Pembahasan:** (a) `toLowerCase()` di kedua sisi membuat pencarian case-insensitive — user mengetik "CODE" tetap menemukan "Clean Code". (b) Default parameter menangani tarif yang tidak dikirim, dan `throw` memvalidasi input negatif — ini contoh pure function dengan penjaga input. (c) `buatFilter` mengembalikan closure yang mengingat `field` dan `nilai`; hasilnya langsung dipakai sebagai callback `filter`, lalu dirantai dengan `filter` kedua — pabrik fungsi + chaining array methods. (d) Closure menyembunyikan `count` sehingga tidak bisa diubah dari luar; satu-satunya jalan adalah lewat method `klik`, `total`, `reset`. Coba tantangan lanjutan: gabungkan (c) dan `reduce` untuk menghitung total nilai koleksi buku Fiksi yang tersedia, atau jadikan `cariBuku` menerima objek kriteria (`{ kategori, hanyaTersedia }`) agar makin fleksibel.
