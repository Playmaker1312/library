# 2. Setup Environment — VS Code dan Browser

Materi ini menyiapkan "dapur mengoding" kamu: menginstal VS Code, memasang ekstensi wajib, membuka folder project, dan menjalankan Live Server. Tujuannya satu — lingkaran kerja yang cepat: tulis → simpan → langsung lihat hasil di browser.

## 1. Penjelasan Singkat & Konsep Dasar

Environment adalah kumpulan alat yang kamu pakai untuk menulis dan menjalankan kode. Untuk Level 1-3 kita butuh tiga alat pokok: **text editor** (VS Code), **browser** (Chrome atau Firefox), dan **beberapa ekstensi** yang mempercepat kerja.

**VS Code (Visual Studio Code)** adalah text editor gratis buatan Microsoft, dan praktis menjadi standar industri karena ringan, ekstensibel, dan didukung ekosistem ekstensi yang sangat besar. Tiga ekstensi wajib kita pasang sejak awal: **Live Server** (browser otomatis refresh setiap file disimpan), **Prettier** (merapikan format kode secara otomatis), dan **Auto Rename Tag** (mengganti tag pembuka dan penutup sekaligus supaya tidak saling lupa).

Lalu bagian terpenting: **struktur folder**. Sejak awal biasakan project web punya folder yang rapih dan terpisah per tipe file. Dengan begini, ketika project Perpustakaan Digital Kota tumbuh, kamu tidak akan tersesat mencari file yang mana.

```
perpustakaan-web/          ← folder utama project (root)
├── index.html             ← beranda
├── katalog.html           ← daftar buku
├── tentang.html           ← profil perpustakaan
├── kontak.html            ← halaman kontak
├── css/
│   └── style.css          ← style sheet (Level 2)
├── js/
│   └── main.js            ← JavaScript (Level 4)
└── images/
    ├── logo.png
    └── buku/              ← sampul buku-buku
```

**Benang merah**: materi sebelumnya menjelaskan *bagaimana browser membaca file* (konsep). Materi ini menjelaskan *alat dan tempat untuk menulis file tersebut* (lingkungan kerja). Setelah ini barulah kita menulis isi HTML itu sendiri (materi 3 dan 4). Cara browser bekerja tidak berubah apa pun tool yang kamu pakai — tetapi environment yang benar membuat debugging dan eksperimen jauh lebih cepat.

## 2. Fungsi & Kegunaan Utama dalam Web

Environment yang benar memangkas waktu antara "menulis kode" dan "melihat hasil". Ini bukan kemewahan, melainkan kebutuhan: kecepatan siklus *tulis → lihat hasil → perbaiki* menentukan seberapa cepat kamu menyerap materi. Semakin pendek jedanya, semakin banyak eksperimen yang bisa kamu lakukan dalam satu sesi belajar — dan eksperimen adalah cara terbaik menguatkan ingatan tentang cara kerja HTML.

**Tanpa Live Server**, alur kerja kamu adalah: tulis kode → simpan file → pindah ke browser → tekan F5 refresh → kembali ke editor. Satu langkah ekstra ini, diulang ratusan kali dalam sehari, terasa sangat menguras. Dengan Live Server, langkah terakhir hilang. Kebiasaan ini adalah fondasi ideal untuk proses belajar yang efektif di tahap HTML murni.

## 3. Contoh Kode & Implementasi Real-World

Karena materi ini menyiapkan alat, contoh implementasinya berupa instruksi nyata. Mari siapkan project perpustakaan.

**Langkah 1 — Instal VS Code**: unduh dari [code.visualstudio.com](https://code.visualstudio.com), jalankan penginstal, dan pastikan di Langkah "Select Additional Tasks" mencentang **"Add 'Open with Code' action to Windows Explorer file."** Ini mempermudah membuka folder nanti.

**Langkah 2 — Instal ekstensi**: buka VS Code, klik ikon Extensions di sidebar kiri (atau tekan `Ctrl+Shift+X`), lalu cari dan instal sesuai nama persisnya:
- `Live Server` (oleh Ritwick Dey) — menjalankan server lokal dan auto-reload browser setiap file disimpan. Preview terbuka otomatis di browser begitu kamu memilih "Open with Live Server".
- `Prettier - Code formatter` — merapikan format kode.
- `Auto Rename Tag` — mengganti nama tag pembuka dan penutup sekaligus.

**Langkah 3 — Buat folder project dan buka**: buat folder bernama `perpustakaan-web/` di tempat yang mudah ditemukan (misal `Dokumen`). Di VS Code pilih `File → Open Folder...` lalu pilih folder itu. Sidebar VS Code kini menampilkan isi folder project.

**Langkah 4 — Buat file `index.html`**: klik ikon New File lalu beri nama `index.html`. Isi dengan kerangka boilerplate sederhana:

```html
<!-- index.html — halaman awal project Perpustakaan Digital Kota -->
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Perpustakaan Digital Kota</title>
</head>
<body>
    <h1>Halo, ini project Perpustakaan Digital Kota!</h1>
</body>
</html>
```

**Langkah 5 — Jalankan Live Server**: klik kanan pada file `index.html` di sidebar VS Code, lalu pilih **"Open with Live Server"**. Browser otomatis terbuka ke `http://127.0.0.1:5500`. Sekarang ubah teks `<h1>` pada file, simpan, dan lihat halaman browser langsung berubah tanpa menekan F5 — inilah kerja Live Server. Sekali lagi, jangan lupa buka F12 → tab Elements untuk melihat struktur DOM yang sedang ditampilkan.

**Catatan**: port `5500` adalah default Live Server. Jika tertutup oleh aplikasi lain, klik ikon Live Server di status bar dan pilih port lain — tidak perlu khawatir soal ini lebih lanjut.

## 4. Analogi Sederhana — Membangun Rumah

Sebelum membangun rumah, kamu perlu **lokasi dan alat kerja**: lahan yang rapi, gambar kerja, dan peralatan yang lengkap. Folder `perpustakaan-web/` adalah **lahan** rumahmu — disiapkan sejak dini supaya semua bahan (file) punya tempat masing-masing (`css/`, `js/`, `images/`). VS Code adalah **meja kerja** tempat menyusun bahan-bahan itu; tanpa meja ini, kamu akan menyusun material di lantai yang berantakan.

Live Server adalah jendela kepo ke rumah yang sedang dibangun — setiap kamu "menyimpan" gambar kerja, jendela itu langsung memperlihatkan kondisi terkini tanpa kamu harus membukanya secara manual.

Jangan lupa peta besarnya:
- **HTML** = pondasi dan kerangka rumah (Level 1, sedang kita bangun).
- **CSS** = cat dan interior (Level 2).
- **JavaScript** = instalasi listrik dan otomatisasi (Level 4).

Environment yang benar memastikan kamu punya lahan, meja kerja, dan alat inspeksi yang memadai sebelum menuang fondasi.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Mulai project baru** — selalu buat folder project sendiri (`perpustakaan-web/`), bukan menyebar file di folder sistem atau Desktop.
- **Ketika menulis banyak file terkait** — struktur folder dengan subfolder `css/` dan `js/` membuat file saling terhubung tanpa kebingungan.
- **Saat kamu bingung kenapa kode tidak berubah** — cek dulu apakah file yang kamu edit benar-benar file yang sedang dibuka Live Server; kesalahan paling umum adalah mengedit file di lokasi lain.
- **Sebelum mengelola lebih dari satu halaman** — dengan struktur folder rapi, menambah `katalog.html` menjadi sangat sederhana.
- **Saat debugging berulang-ulang** — akses cepat F12 + Elements + Live Server menggabungkan inspeksi dan refresh instan.

## 6. Poin-poin Penting & Best Practices

- Instal **Live Server**, **Prettier**, dan **Auto Rename Tag** — ketiganya wajib untuk alur kerja yang nyaman.
- Selalu buka **folder project**, bukan file satu per satu, supaya sidebar VS Code mencerminkan struktur project.
- Buat subfolder sejak awal: `css/`, `js/`, `images/`. Ini mencegah "kekacauan file" saat project besar.
- Konvensi nama file: huruf kecil, tanpa spasi (`katalog.html`, bukan `Katalog Buku.html`).
- Mulai setiap project dengan file `index.html` — browser dan server otomatis mengenalinya sebagai halaman utama.
- Gunakan Auto Rename Tag supaya tag penutup tidak pernah tertinggal saat mengganti nama tag — ini melatih kebiasaan "tag selalu sepasang".
- Untuk Level 1-3 **tidak perlu Node.js atau terminal** — tahan keinginan menginstal hal yang belum dibutuhkan; fokus dulu pada HTML.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Mengedit file yang salah.** Kamu mengubah `index.html` di folder lain, sementara Live Server membaca file di `perpustakaan-web/`. Solusi: selalu cek judul file di tab VS Code dan path di sidebar.
- **Lupa menekan Save.** Prettier atau Live Server tidak akan berjalan jika file tidak disimpan. Solusi: biasakan `Ctrl+S` setelah setiap perubahan.
- **Live Server tidak muncul.** Penyebab umum: ekstensi belum aktif, atau kamu klik kanan di tempat kosong, bukan pada file `index.html`. Solusi: klik kanan *pada file* lalu pilih Open with Live Server.
- **Memasang ekstensi secara berlebihan.** Semakin banyak ekstensi, semakin berat VS Code dan bingung mana yang dipakai. Solusi: pasang hanya yang dibutuhkan di tahap ini (tiga ekstensi di atas sudah cukup).

## 8. Mini Project / Soal Latihan & Kunci Jawaban

### Tantangan

1. Buat folder `perpustakaan-web/`, buka dengan VS Code, dan susun struktur folder: `index.html`, `css/`, `js/`, `images/` (folder kosong boleh dibuat dengan klik kanan → New Folder).
2. Isi `index.html` dengan boilerplate sederhana (judul tab: "Perpustakaan Digital Kota"), jalankan Live Server, lalu ubah teks `<h1>` dan pastikan browser otomatis refresh tanpa menekan F5.

### Solusi & Pembahasan

**Langkah 1** — Buat folder `perpustakaan-web/` lalu di VS Code `File → Open Folder...`. Klik ikon New Folder di sidebar, buat `css`, `js`, `images`. Buat file `index.html` dan isi:

```html
<!-- index.html — awal project Perpustakaan Digital Kota -->
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Perpustakaan Digital Kota</title>
</head>
<body>
    <h1>Perpustakaan Digital Kota</h1>
    <p>Mulai dari halaman sederhana, menuju aplikasi yang utuh.</p>
</body>
</html>
```

**Langkah 2** — Klik kanan file `index.html` → **Open with Live Server**. Browser terbuka di `http://127.0.0.1:5500`. Ubah teks `<p>` menjadi apa saja, simpan, dan perhatikan browser langsung memperbarui halaman.

**Pembahasan**: folder kosong `css/`, `js/`, dan `images/` sengaja dibuat sejak awal supaya kamu terbiasa dengan struktur yang akan dipakai di Level 2 dan seterusnya — folder kosong adalah "tempat kosong" yang menunggu diisi. Uji keberhasilan latihan ini: halaman dimuat oleh Live Server, dan setiap kali `Ctrl+S`, perubahan langsung terlihat di browser.
