# 30. Modal dan Notifikasi — UI Pattern yang Penting

Materi ini membahas dua **UI pattern** yang hampir selalu ada di aplikasi web: **modal** (jendela di atas halaman untuk detail/konfirmasi/form) dan **notifikasi toast** (pesan kecil yang muncul sebentar lalu hilang sendiri) — dibungkus rapi sebagai `class Modal` dan `class Notifikasi` yang bisa dipakai ulang.

## 1. Penjelasan Singkat & Konsep Dasar

Modal dan toast bukan elemen HTML khusus — keduanya adalah **div biasa yang diatur perilakunya oleh CSS + JavaScript**. Modal memakai `position: fixed` untuk melayang di atas halaman: ada lapisan **overlay** gelap di belakangnya untuk menutup konteks, dan **kotak konten** di tengah. Ia tidak selalu tampil; ada class penanda seperti `modal--aktif` yang mengontrol visibilitas. Toast memakai `position: fixed` juga, biasanya menumpuk di pojok kanan bawah, dengan transisi masuk/keluar yang halus dan **dihapus sendiri** setelah beberapa detik.

Yang membuat keduanya layak disebut "pattern" adalah **perilaku standar** yang selalu diulang. Modal harus bisa dibuka dan ditutup, harus tertutup saat user mengklik overlay, menekan tombol X, atau menekan **Escape**, dan saat terbuka halaman di belakangnya tidak boleh ikut di-scroll (`body.no-scroll` → `overflow: hidden`). Untuk aksesibilitas, modal memakai `aria-hidden`, `role="dialog"`, dan **focus dipindahkan** ke dalam modal saat dibuka, lalu dikembalikan saat ditutup. Toast wajib memakai `role="status"`/`aria-live="polite"` pada containernya agar screen reader mengumumkan perubahan, dan setiap notif punya `role="alert"`.

Cara paling rapi mengemas pola ini adalah **class**. `class Modal` menyimpan referensi elemen modal dan menyediakan `buka()`, `tutup()`, `sedangBuka()`. `class Notifikasi` dibuat `static` karena ia bersifat global: container dibuat sekali (`setup()`), lalu dipanggil dari mana saja tanpa perlu instans. Kata kunci `static` (ES2022) berarti properti/fungsi itu melekat pada class, bukan pada instance, sehingga cukup `Notifikasi.sukses("...")` tanpa `new Notifikasi()`. Variasi pesan disederhanakan jadi metode: `sukses`, `error`, `peringatan`, `info`.

Toast perlu animasi keluar yang elegan: saat `setTimeout` habis, class `notifikasi--tampil` dilepas (opacity turun), dan elemen baru benar-benar dihapus setelah transisi selesai — memakai event **`transitionend`** (dengan `{ once: true }` agar listenernya tidak menumpuk). Tanpa ini, `remove()` terlalu cepat dan animasi keluar tidak terlihat, atau sebaliknya toast menumpuk dan menetap selamanya.

**Benang merah**: modal adalah hasil langsung dari materi 25-29 — seleksi elemen (25), manipulasi `classList`/atribut (26), `createElement` untuk toast (27), dan event `click`/`keydown`/`submit` (28), ditambah pola state dari materi 29. Modal dan toast juga memakai **event delegation** saat tombol di dalamnya dibuat dinamis. Ke arah **Level 6**, notifikasi menjadi jembatan penting: status `loading`, `sukses`, dan `error` dari `fetch`/`async` hampir selalu disampaikan lewat toast — pola yang sama persis, hanya dipicu oleh hasil Promise.

## 2. Fungsi & Kegunaan Utama dalam Web

Di **Perpustakaan Digital Kota**, modal dipakai untuk **detail buku**: saat kartu diklik, muncul overlay berisi judul, pengarang, kategori, harga, stok, dan tombol "Pinjam". Modal yang sama bisa dipakai untuk **form tambah/edit buku** (CRUD materi 27) dan **konfirmasi hapus** ("Yakin hapus buku ini?"). Karena pola ditulis sekali sebagai class, semua varian ini tinggal melempar data yang berbeda ke `modal.buka(data)`.

Toast menyampaikan umpan balik setelah setiap aksi: "Buku berhasil dipinjam!" (hijau), "Stok buku habis." (merah), "Batas pinjaman hampir tercapai." (kuning), atau "Data tersimpan." (biru). Toast juga akan menampilkan hasil request async di Level 6 — misalnya error dari server ditangkap di `catch`, lalu ditampilkan sebagai toast error. Kombinasi modal + toast adalah pola yang dipakai hampir semua aplikasi: dashboard admin, aplikasi e-commerce, sistem antrian, sampai form login.

```javascript
// js/ui.js

// ─── DATA (Level 6 nanti diganti fetch dari API) ──────────────────────────
let katalog = [
    { id: 1, judul: "Clean Code",     pengarang: "Robert C. Martin", kategori: "Teknologi", harga: 150000, stok: 2 },
    { id: 2, judul: "Laskar Pelangi", pengarang: "Andrea Hirata",     kategori: "Fiksi",     harga: 95000,  stok: 0 },
    { id: 3, judul: "Cosmos",         pengarang: "Carl Sagan",        kategori: "Sains",      harga: 120000, stok: 4 },
];

const grid = document.querySelector("#katalog-grid");
let bukuAktif = null;   // buku yang sedang tampil di modal

// ─── 1. CLASS MODAL ────────────────────────────────────────────────────────
class Modal {
    constructor(selector) {
        this.modal    = document.querySelector(selector);
        this.overlay  = this.modal.querySelector(".modal__overlay");
        this.btnTutup = this.modal.querySelector(".modal__tutup");

        this.setupListener();
    }

    setupListener() {
        // Tutup saat klik overlay
        this.overlay.addEventListener("click", () => this.tutup());
        // Tutup saat klik tombol X (opsional chaining: aman jika tidak ada)
        this.btnTutup?.addEventListener("click", () => this.tutup());
        // Tutup saat tekan Escape — hanya jika modal sedang terbuka
        document.addEventListener("keydown", (e) => {
            if (e.key === "Escape" && this.sedangBuka()) this.tutup();
        });
    }

    buka(data = {}) {
        // Isi konten jika data diberikan
        if (data.judul) {
            this.modal.querySelector(".modal__judul").textContent = data.judul;
        }
        if (data.konten) {
            this.modal.querySelector(".modal__konten-teks").textContent = data.konten;
        }

        this.modal.classList.add("modal--aktif");
        this.modal.setAttribute("aria-hidden", "false");
        document.body.classList.add("no-scroll");   // kunci scroll halaman

        // Aksesibilitas: pindahkan fokus ke tombol tutup
        this.btnTutup?.focus();

        return this;    // memungkinkan chaining: modal.buka(...).buka(...)
    }

    tutup() {
        this.modal.classList.remove("modal--aktif");
        this.modal.setAttribute("aria-hidden", "true");
        document.body.classList.remove("no-scroll");
        return this;
    }

    sedangBuka() {
        return this.modal.classList.contains("modal--aktif");
    }
}

const modalDetail = new Modal("#modal-detail");

// ─── 2. CLASS NOTIFIKASI (static — dipakai tanpa instance) ─────────────────
class Notifikasi {
    static container = null;

    // Buat container global sekali, tandai untuk screen reader
    static setup() {
        this.container = document.createElement("div");
        this.container.id = "notifikasi-container";
        this.container.setAttribute("role", "status");        // region pengumuman
        this.container.setAttribute("aria-live", "polite");   // diumumkan saat berubah
        document.body.appendChild(this.container);
    }

    static tampilkan(pesan, tipe = "info", durasi = 3000) {
        const notif = document.createElement("div");
        notif.className = `notifikasi notifikasi--${tipe}`;
        notif.textContent = pesan;
        notif.setAttribute("role", "alert");   // setiap toast diumumkan

        this.container.appendChild(notif);

        // Animasi masuk: butuh elemen sudah ada di DOM → tunggu 1 frame
        requestAnimationFrame(() => {
            notif.classList.add("notifikasi--tampil");
        });

        // Auto-hapus: sembunyikan dulu, baru HAPUS saat transisi kelar
        setTimeout(() => {
            notif.classList.remove("notifikasi--tampil");
            notif.addEventListener("transitionend", () => notif.remove(), { once: true });
        }, durasi);
    }

    static sukses(pesan)     { this.tampilkan(pesan, "sukses"); }
    static error(pesan)      { this.tampilkan(pesan, "error"); }
    static peringatan(pesan) { this.tampilkan(pesan, "peringatan"); }
    static info(pesan)       { this.tampilkan(pesan, "info"); }
}

// ─── 3. RENDER KATALOG ─────────────────────────────────────────────────────
function buatKartu(buku) {
    const kartu = document.createElement("article");
    kartu.className = "kartu-buku";
    kartu.dataset.id = buku.id;

    const judul = document.createElement("h3");
    judul.textContent = buku.judul;

    const meta = document.createElement("p");
    meta.textContent = `${buku.pengarang} · ${buku.stok > 0 ? `Stok ${buku.stok}` : "Habis"}`;

    const btnDetail = document.createElement("button");
    btnDetail.className = "btn btn--sekunder";
    btnDetail.textContent = "Detail";
    btnDetail.dataset.aksi = "detail";
    btnDetail.dataset.id = buku.id;

    const btnPinjam = document.createElement("button");
    btnPinjam.className = "btn btn--primary";
    btnPinjam.textContent = "Pinjam";
    btnPinjam.dataset.aksi = "pinjam";
    btnPinjam.dataset.id = buku.id;
    btnPinjam.disabled = buku.stok === 0;   // habis → tidak bisa diklik

    const aksi = document.createElement("div");
    aksi.className = "aksi";
    aksi.append(btnDetail, btnPinjam);

    kartu.append(judul, meta, aksi);
    return kartu;
}

function renderKatalog() {
    grid.innerHTML = "";
    const frag = document.createDocumentFragment();
    katalog.forEach(b => frag.appendChild(buatKartu(b)));
    grid.appendChild(frag);
}

// ─── 4. EVENT DELEGATION — satu listener untuk semua tombol dinamis ────────
grid.addEventListener("click", (e) => {
    const btnDetail = e.target.closest("[data-aksi='detail']");
    const btnPinjam = e.target.closest("[data-aksi='pinjam']");

    if (btnDetail) {
        const buku = katalog.find(b => b.id === Number(btnDetail.dataset.id));
        if (!buku) return;

        bukuAktif = buku;
        modalDetail.buka({
            judul: buku.judul,
            konten: `${buku.pengarang} — ${buku.kategori}\nHarga: Rp ${buku.harga.toLocaleString("id-ID")}\nStok: ${buku.stok} eksemplar`,
        });
    }

    if (btnPinjam) {
        const buku = katalog.find(b => b.id === Number(btnPinjam.dataset.id));
        if (!buku || buku.stok <= 0) {
            Notifikasi.error("Stok buku habis, tidak bisa dipinjam.");
            return;
        }
        buku.stok -= 1;              // ubah data dulu
        renderKatalog();             // tampilan mengikuti data
        Notifikasi.sukses(`"${buku.judul}" berhasil dipinjam.`);
    }
});

// Tombol "Pinjam" di dalam modal — aksi yang sama dengan di kartu
document.querySelector("#btn-pinjam-modal").addEventListener("click", () => {
    if (!bukuAktif || bukuAktif.stok <= 0) {
        Notifikasi.peringatan("Buku ini sedang tidak tersedia.");
        modalDetail.tutup();
        return;
    }
    bukuAktif.stok -= 1;
    renderKatalog();
    modalDetail.tutup();
    Notifikasi.sukses(`"${bukuAktif.judul}" berhasil dipinjam dari modal.`);
});

// ─── 5. JALANKAN ───────────────────────────────────────────────────────────
Notifikasi.setup();
renderKatalog();
```

## 4. Analogi Sederhana — Membangun Rumah

Di rumah analogi kita, **HTML** adalah kerangka dan tata ruang, **CSS** adalah cat dan dekorasi interior, sedangkan **JavaScript** adalah instalasi listrik dan otomatisasi. Materi 30 bicara soal **pintu rahasia dan lampu indikator**.

**Modal** adalah kotak kendali/pintu rahasia di dalam rumah. Ia tidak terlihat sampai dipanggil — ketika tombol "Detail" ditekan, listrik (JS) membuka pintu tersembunyi itu, dan ruang kecil berisi informasi buku muncul di atas semua ruangan lain. Selama pintu terbuka, lorong utama rumah dikunci (`body.no-scroll`) agar orang tidak berjalan saat ruang kendali sedang dipakai. Pintu menutup lewat tiga cara: ditekan tombol di sisinya (tombol X), disentuh di luar pintu (klik overlay), atau perintah "Escape" dari pengelola. Desainnya (kerangka pintu + warna catnya) ditulis sekali di satu tempat, lalu semua ruangan bisa memakai pintu yang sama dengan isi yang berbeda — itulah nilai **pattern**: satu blueprint, banyak pemakaian.

**Toast** adalah lampu indikator kecil di panel pengatur rumah. Lampu menyala memberikan status — "Buku dipinjam!" (hijau), "Stok habis!" (merah), "Hampir melebihi batas!" (kuning) — lalu **padam sendiri** setelah beberapa saat, tanpa ada yang menekannya. Lampu ini tidak membutuhkan ruangan khusus atau pintu; ia diletakkan di pojok panel (container fixed di kanan bawah) dan bisa muncul kapan pun. Karena ia "menyala lalu padam", notifikasi tidak mengganggu pekerjaan utama penghuni — persis seperti toast yang auto-hapus dengan `setTimeout` + `transitionend`.

Keduanya menunjukkan pola pikir aplikasi nyata: komponen yang bisa dipakai ulang (`class Modal`, `class Notifikasi`) lebih baik daripada menulis ulang kode modal di setiap halaman.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Detail / info lengkap suatu item** — klik kartu buku → modal menampilkan deskripsi lengkap tanpa pindah halaman (juga produk di toko online, data di dashboard).
- **Form dalam jendela** — tambah/edit buku, isi data anggota, atau login; modal menjaga konteks user tetap di halaman yang sama.
- **Konfirmasi tindakan penting** — "Yakin hapus buku ini?" dengan tombol Batal/Konfirmasi; modal menahan aksi destruktif sebelum dieksekusi.
- **Umpan balik singkat setelah aksi** — toast "Buku berhasil dipinjam", "Perubahan tersimpan", atau "Gagal terhubung ke server"; cocok untuk sesuatu yang tidak butuh interaksi lanjutan.
- **Pemberitahuan status async (Level 6)** — saat `fetch` berjalan muncul toast/indikator loading, lalu toast sukses atau error tergantung hasil Promise.

## 6. Poin-poin Penting & Best Practices

- **Bungkus pola jadi class** — `class Modal` dengan `buka()`, `tutup()`, `sedangBuka()`, dan `class Notifikasi` static dengan `tampilkan()`; ini membuat UI pattern bisa dipakai di seluruh aplikasi tanpa menyalin kode.
- **Modal: kelola visibilitas lewat class** — `modal--aktif` mengatur `visibility` + `opacity` (transisi), bukan `display: none` yang mematikan animasi masuk/keluar.
- **Modal: kunci scroll body** — tambah `body.no-scroll` (CSS `overflow: hidden`) saat terbuka, lepas saat ditutup. Tanpa ini halaman belakang bisa ikut tergulir.
- **Modal: aksesibilitas** — `aria-hidden="true"` saat tertutup (false saat terbuka), `role="dialog"` + `aria-modal` pada konten, dan pindahkan fokus (`this.btnTutup.focus()`) saat dibuka; dukung penutupan dengan **Escape**.
- **Modal: jangan hanya andalkan mouse** — tutup via overlay, tombol X, dan keyboard Escape; pastikan fokus tidak tersangkut di dalam modal (focus management).
- **Toast: container global dengan `role="status"` + `aria-live="polite"`** — screen reader akan mengumumkan notif baru tanpa membacakan semua yang sudah lewat.
- **Toast: auto-hapus dengan benar** — `setTimeout` melepas class tampil (mulai animasi keluar), lalu **`transitionend` dengan `{ once: true }`** untuk `remove()`; tanpa `{ once: true }` listener bisa menumpuk.
- **Gunakan `textContent`** untuk pesan notif dan isi modal, bukan `innerHTML`, karena data bisa berasal dari user/API (materi 26 — mencegah XSS).
- **Event delegation** (materi 28) untuk tombol yang dibuat dinamis: satu listener di `#katalog-grid` memakai `event.target.closest("[data-aksi='...']")`.
- **Cleanup bila perlu** — kalau modal dibuat dan dibuang berulang (SPA), simpan referensi listener `keydown` dan buang dengan `removeEventListener` saat komponen dihancurkan agar tidak terjadi dobel binding.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Modal tidak bisa ditutup / fokus tidak masuk.** Hanya `display: none` tanpa focus management dan tanpa handler Escape — keyboard user tidak bisa menutup modal dan fokus hilang ke balik overlay. Perbaikan: `modal--aktif` + `visibility`/`opacity`, pasang `keydown` Escape di `document`, dan panggil `.focus()` pada tombol tutup saat `buka()`.
- **Scroll halaman ikut bergulir di belakang modal.** Saat konten modal lebih panjang dari layar, `body` ikut scroll. Perbaikan: tambah `body.no-scroll` (`overflow: hidden`) saat `buka()`, lepas di `tutup()`.
- **Toast menumpuk tanpa auto-remove.** `remove()` dipanggil terlalu cepat (animasi keluar tidak pernah terlihat) atau terlalu lambat/tidak sama sekali. Perbaikan: lepas class tampil di `setTimeout`, hapus elemen di event **`transitionend`**, dengan `{ once: true }` agar listener tidak ganda.
- **`aria-hidden` dan `aria-live` dilupakan.** Modal tetap "terbaca" oleh screen reader saat tertutup, atau notifikasi tidak diumumkan. Perbaikan: toggle `aria-hidden` bersamaan dengan class `modal--aktif`, dan pasang `role="status"` + `aria-live="polite"` pada container toast.
- **Tombol dinamis tidak merespons.** Listener dipasang per tombol saat render pertama — tombol yang dibuat belakangan mati. Perbaikan: event delegation di container yang permanen (`#katalog-grid`).
- **`transitionend` tidak pernah terpicu.** Jika CSS tidak punya transisi pada property yang berubah, event `transitionend` tidak muncul dan elemen tak pernah dihapus. Perbaikan: pastikan `.notifikasi` punya `transition` pada `opacity`/`transform`, atau tambah fallback `setTimeout(() => notif.remove(), 400)`.

    <h1>Perpustakaan Digital Kota</h1>

        <div class="modal-overlay"></div>

    <script>
    // ─── Data ──────────────────────────────────────────────────────────────
    let katalog = [
        { id: 1, judul: "Clean Code",     pengarang: "Robert C. Martin", kategori: "Teknologi", harga: 150000, stok: 1 },
        { id: 2, judul: "Laskar Pelangi", pengarang: "Andrea Hirata",     kategori: "Fiksi",     harga: 95000,  stok: 0 },
        { id: 3, judul: "Cosmos",         pengarang: "Carl Sagan",        kategori: "Sains",      harga: 120000, stok: 3 },
    ];
    const grid = document.querySelector("#katalog");
    let bukuAktif = null;

    // ─── Modal ─────────────────────────────────────────────────────────────
    class Modal {
        constructor(selector) {
            this.modal    = document.querySelector(selector);
            this.overlay  = this.modal.querySelector(".modal-overlay");
            this.btnTutup = this.modal.querySelector(".modal-tutup");
            this.overlay.addEventListener("click", () => this.tutup());
            this.btnTutup.addEventListener("click", () => this.tutup());
            document.addEventListener("keydown", (e) => {
                if (e.key === "Escape" && this.sedangBuka()) this.tutup();
            });
        }
        buka(judul, teks) {
            this.modal.querySelector("#modal-judul").textContent = judul;
            this.modal.querySelector("#modal-teks").textContent = teks;
            this.modal.classList.add("aktif");
            this.modal.setAttribute("aria-hidden", "false");
            document.body.classList.add("no-scroll");
            this.btnTutup.focus();
            return this;
        }
        tutup() {
            this.modal.classList.remove("aktif");
            this.modal.setAttribute("aria-hidden", "true");
            document.body.classList.remove("no-scroll");
            return this;
        }
        sedangBuka() {
            return this.modal.classList.contains("aktif");
        }
    }
    const modal = new Modal("#modal-detail");

    // ─── Notifikasi ─────────────────────────────────────────────────────────
    class Notifikasi {
        static setup() {
            this.container = document.createElement("div");
            this.container.id = "notif-container";
            this.container.setAttribute("role", "status");
            this.container.setAttribute("aria-live", "polite");
            document.body.appendChild(this.container);
        }
        static tampilkan(pesan, tipe, durasi = 3000) {
            const el = document.createElement("div");
            el.className = `notif ${tipe}`;
            el.textContent = pesan;
            this.container.appendChild(el);
            requestAnimationFrame(() => el.classList.add("tampil"));
            setTimeout(() => {
                el.classList.remove("tampil");
                el.addEventListener("transitionend", () => el.remove(), { once: true });
            }, durasi);
        }
        static sukses(p)     { this.tampilkan(p, "sukses"); }
        static peringatan(p) { this.tampilkan(p, "peringatan"); }
        static error(p)      { this.tampilkan(p, "error"); }
    }

    // ─── Render + event delegation ──────────────────────────────────────────
    function render() {
        grid.innerHTML = "";
        const frag = document.createDocumentFragment();
        katalog.forEach(b => {
            const kartu = document.createElement("article");
            kartu.className = "kartu";
            kartu.dataset.id = b.id;

            const judul = document.createElement("h3");
            judul.textContent = b.judul;
            const meta = document.createElement("p");
            meta.textContent = `${b.pengarang} · ${b.stok > 0 ? `Stok ${b.stok}` : "Habis"}`;

            const btnDetail = document.createElement("button");
            btnDetail.className = "btn btn-detail";
            btnDetail.textContent = "Detail";
            btnDetail.dataset.aksi = "detail";
            btnDetail.dataset.id = b.id;

            const btnPinjam = document.createElement("button");
            btnPinjam.className = "btn btn-pinjam";
            btnPinjam.textContent = "Pinjam";
            btnPinjam.dataset.aksi = "pinjam";
            btnPinjam.dataset.id = b.id;
            btnPinjam.disabled = b.stok === 0;

            kartu.append(judul, meta, btnDetail, btnPinjam);
            frag.appendChild(kartu);
        });
        grid.appendChild(frag);
    }

    function kurangiStok(id) {
        const buku = katalog.find(b => b.id === id);
        if (!buku || buku.stok <= 0) {
            Notifikasi.error("Stok buku habis, tidak bisa dipinjam.");
            return false;
        }
        buku.stok -= 1;
        render();
        Notifikasi.sukses(`"${buku.judul}" berhasil dipinjam.`);
        return true;
    }

    grid.addEventListener("click", (e) => {
        const btnDetail = e.target.closest("[data-aksi='detail']");
        const btnPinjam = e.target.closest("[data-aksi='pinjam']");

        if (btnDetail) {
            const b = katalog.find(x => x.id === Number(btnDetail.dataset.id));
            bukuAktif = b;
            modal.buka(
                b.judul,
                `${b.pengarang} — ${b.kategori}\nRp ${b.harga.toLocaleString("id-ID")} · Stok ${b.stok}`
            );
        }
        if (btnPinjam) kurangiStok(Number(btnPinjam.dataset.id));
    });

    // Pinjam dari dalam modal
    document.querySelector("#btn-modal-pinjam").addEventListener("click", () => {
        if (bukuAktif && bukuAktif.stok <= 0) {
            Notifikasi.peringatan("Buku ini sedang tidak tersedia.");
            modal.tutup();
            return;
        }
        if (bukuAktif) {
            kurangiStok(bukuAktif.id);
            modal.tutup();
        }
    });

    Notifikasi.setup();
    render();
    </script>
</body>

**Pembahasan**: `class Modal` menyimpan semua perilaku pembukaan/penutupan — overlay, tombol X, dan Escape semuanya memanggil `tutup()`, sedangkan `buka(judul, teks)` mengisi konten, menambah `aktif`, mengunci scroll (`no-scroll`), dan memindahkan fokus. `class Notifikasi` dibuat `static` sehingga cukup `Notifikasi.sukses(...)` dari mana saja; container dibuat sekali di `setup()` dengan `role="status"` dan `aria-live="polite"`. Setiap toast di-`appendChild`, masuk lewat `requestAnimationFrame` (agar transisi `opacity`/`transform` terpicu), lalu dihapus lewat `setTimeout` + `transitionend` (animasi keluar terlihat dulu, baru `remove()`). Aksi "Pinjam" dipakai bersama lewat fungsi `kurangiStok()`: dari kartu (via event delegation) maupun dari tombol dalam modal — data diubah dulu (`buku.stok -= 1`), baru `render()` dan toast sukses. Stok 0 memicu toast error/peringatan, dan tombol kartu otomatis `disabled`. Ini pola yang sama yang nanti dipakai menampilkan hasil fetch di Level 6: toast sukses/error mengikuti hasil Promise, dan modal tetap menjadi tempat interaksi detail.
