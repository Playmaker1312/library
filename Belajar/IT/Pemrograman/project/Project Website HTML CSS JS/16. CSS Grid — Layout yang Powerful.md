# 16. CSS Grid — Layout yang Powerful

CSS Grid adalah sistem layout dua dimensi (2D): ia mengatur posisi elemen dalam baris **dan** kolom sekaligus. Sementara Flexbox adalah pisau untuk komponen satu dimensi, Grid adalah denah untuk seluruh halaman — katalog, dan layout bertemplat seperti sidebar dan footer.

## 1. Penjelasan Singkat & Konsep Dasar

Flexbox (materi 15) sudah mengajarkanmu menata komponen dalam satu arah: sumbu utama dan sumbu silang. Masalah muncul saat kamu butuh menata baris dan kolom *bersamaan* — misal tiga kolom katalog yang tiap barisnya juga harus rapi, atau layout halaman dengan header, sidebar, main, dan footer. Memaksanya dengan Flexbox berarti membuat struktur bersarang (baris di dalam kolom) yang rapuh. Grid lahir untuk kasus ini: kamu mendefinisikan **kedua arah sekaligus** di satu container.

Konsep kunci Grid adalah **grid lines**, garis imajiner bernomor yang membagi container. Garis vertikal memisahkan kolom, garis horizontal memisahkan baris. Di antara dua garis berurutan ada **grid track** (kolom atau baris). Pertemuan satu kolom dan satu baris membentuk **grid cell** — satu "kotak". Saat sebuah item menggabungkan beberapa cell, jadilah **grid area**. Semua properti penempatan (placement) sebenarnya berbicara dalam bahasa garis: "mulai dari line 1 sampai line 3".

Definisi track lewat `grid-template-columns` dan `grid-template-rows` adalah jantung Grid. Unit **`fr`** (fraction) membagi ruang tersisa secara proporsional — `1fr 2fr` berarti kolom kedua dua kali lebih lebar dari kolom pertama. `repeat(3, 1fr)` menulis "tiga kolom sama rata" tanpa mengulang. Yang paling dahsyat untuk katalog adalah `repeat(auto-fill, minmax(250px, 1fr))`: browser menghitung sendiri berapa kolom yang muat, tiap kolom minimal 250px dan memanjang mengisi ruang — **responsif tanpa satu pun media query**.

Penempatan item dilakukan dengan `grid-column` dan `grid-row`, masing-masing dalam format `mulai / akhir` (berdasarkan nomor garis) atau `span n` (menempati n track dari posisi alaminya). Saat pola layout perlu mudah dibaca, gunakan **named grid areas**: `grid-template-areas` menggambar "petagram" dengan nama area, lalu setiap child diarahkan via `grid-area: nama`. Layout halaman utuh bisa digambar sekali dan dibaca seperti denah.

Properti pendukung yang sering dipakai: `gap` (jarak antar track, sama seperti Flexbox), `align-items`/`justify-items` (perataan item di dalam cell), serta `auto-fit` sebagai saudara `auto-fill` yang menyusutkan kolom kosong agar mengisi penuh baris.

**Benang merah**: box model (14) menentukan ukuran kotak, Flexbox (15) menata kotak dalam satu arah, dan Grid melengkapinya dengan dua arah. Di materi 17 kamu akan melihat kombinasi ungkapannya: Grid membangun kerangka halaman, media queries menyesuaikan templatnya di tiap ukuran layar, dan Flexbox menata isi di dalam cell.

## 2. Fungsi & Kegunaan Utama dalam Web

Bagian halaman "Perpustakaan Digital Kota" yang paling terasa adalah **katalog grid**: ribuan buku ditampilkan dalam kartu-kartu yang rapi, otomatis bertambah kolomnya saat layar melebar. Dengan `repeat(auto-fill, minmax(280px, 1fr))`, satu baris kode menggantikan ulasan media query yang membosankan.

- **Katalog grid**: kartu buku responsif otomatis — di ponsel satu kolom penuh, di tablet dua, di desktop tiga-empat, tanpa menulis breakpoint.
- **Layout halaman (Holy Grail)**: header di atas, footer di bawah, sidebar di kiri, konten utama di tengah, dan area tambahan di kanan. `grid-template-areas` menggambarnya seperti peta dan sulit salah dibaca.
- **Tampilan berita / majalah**: artikel utama besar mengambil dua kolom dan dua baris, artikel kecil mengisi sisa — penempatan dengan `span`.
- **Hero statistik**: baris angka-angka (koleksi, anggota, peminjaman) dibagi dalam kolom yang sama lebarnya dan otomatis turun saat layar sempit.
- **Sidebar + konten halaman detail buku**: kolom samping untuk info (penulis, penerbit, ISBN) tetap 260px, kolom konten mengambil sisa (`1fr`).

## 3. Contoh Kode & Implementasi Real-World

HTML minimal berikut memuat tiga skenario grid: katalog kartu, layout halaman penuh, dan grid kartu dengan item *featured* yang membentang.

```html
<!-- index.html -->
<!-- (1) Grid katalog: kartu-kartu responsif otomatis -->
<section class="katalog">
    <h2>Koleksi Pilihan</h2>

    <div class="katalog__grid">
        <article class="kartu">
            <h3>Clean Code</h3>
            <p>Robert C. Martin</p>
        </article>
        <article class="kartu">
            <h3>Laskar Pelangi</h3>
            <p>Andrea Hirata</p>
        </article>
        <article class="kartu">
            <h3>Cosmos</h3>
            <p>Carl Sagan</p>
        </article>
        <!-- kartu berikutnya ditambahkan dst. -->
    </div>
</section>

<!-- (2) Holy Grail: layout halaman lengkap -->
<div class="halaman">
    <header class="halaman__header">Perpustakaan Digital Kota</header>
    <aside class="halaman__sidebar">Menu / Informasi</aside>
    <main class="halaman__main">Daftar buku dan konten utama</main>
    <aside class="halaman__info">Promo dan pengumuman</aside>
    <footer class="halaman__footer">© 2024 Perpustakaan Digital Kota</footer>
</div>
```

```css
/* css/style.css */
* { box-sizing: border-box; }
body { margin: 0; font-family: sans-serif; }

/* ── (1) Katalog grid — responsif otomatis tanpa media query ─────────── */
.katalog__grid {
    display: grid;

    /* auto-fill: isi sebanyak mungkin kolom.
       minmax(280px, 1fr): tiap kolom min 280px, sisanya membagi rata.
       Hasil: 1 kolom di ponsel, 2-3 di tablet, 4+ di desktop. */
    grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
    gap: 24px;
}

.kartu {
    padding: 24px;
    background: #ffffff;
    border: 1px solid #e2e8f0;
    border-radius: 8px;
}

/* ── (2) Holy Grail dengan named grid areas ───────────────────────────── */
.halaman {
    display: grid;

    /* 2 kolom: sidebar 220px + main 1fr (sisa).
       3 baris: header, isi (tumbuh mengisi), footer. */
    grid-template-columns: 220px 1fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header  header"
        "sidebar main  "
        "footer  footer";
    min-height: 100vh;
}

/* Arahkan setiap anak ke area bernama */
.halaman__header  { grid-area: header; }
.halaman__sidebar { grid-area: sidebar; }
.halaman__main    { grid-area: main; }
.halaman__info    { grid-area: sidebar; }  /* surat peringatan: tidak unik --
                                              sebaiknya area berbeda (lihat bawah) */
.halaman__footer  { grid-area: footer; }

/* Peta yang benar untuk 3 kolom (header/footer membentang penuh):
   grid-template-columns: 1fr 2fr 1fr;
   grid-template-areas:
       "header  header  header "
       "sidebar main    info   "
       "footer  footer  footer "; */

/* ── (3) Item yang membentang beberapa track ──────────────────────────── */
.grid-pilihan {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 16px;
}

.kartu--utama {
    grid-column: span 2;   /* menempati 2 kolom dari posisi alaminya */
    grid-row: span 2;      /* dan 2 baris — jadi persegi besar */
    background: #2563eb;
    color: #ffffff;
}

/* Kolom contoh dengan unit fr */
.kolom-profil {
    display: grid;
    grid-template-columns: 200px 1fr 1fr; /* satu kolom tetap, dua membagi sisa */
    gap: 16px;
}
```

Perhatikan tiga hal: (a) katalog responsif ditulis *sekali* tanpa media query; (b) Holy Grail digambar sebagai peta bernama yang mudah dibaca — dan komentar menunjukkan versi 3 kolom yang benar; (c) `grid-column: span 2` dipakai untuk kartu unggulan yang besar.

## 4. Analogi Sederhana — Membangun Rumah

Kalau Flexbox menata perabot di **satu dinding**, maka Grid adalah **memetakan seluruh denah rumah atau kompleks** sekaligus.

- `display: grid` = kamu membuka denah kosong dan memutuskan berapa ruangan yang dibutuhkan.
- `grid-template-columns` dan `grid-template-rows` = **menarik garis lurus di denah** untuk membuat kamar-kamar: "kompleks ini punya 3 baris dan 4 kolom".
- `fr` = ruangan yang saling berbagi lahan: `1fr 2fr` berarti satu kamar mengambil sepertiga lahan, kamar lain dua pertiga.
- `gap` = lebar koridor antar kamar: jarak bersih yang menjaga ruangan tidak menempel.
- `grid-column: span 2` = **satu ruangan memanjang dua kolom** — misal ruang keluarga yang menyerap dua kamar kecil agar lebih lega.
- `grid-template-areas / grid-area` = menempel nama di tiap kamar di denah: "dapur", "kamar tidur", "ruang tamu" — lalu kamu cukup menempelkan nama itu di perabot (elemen) yang bersangkutan. Denahnya jadi jelas sekali dipandang.

Perbedaan dengan Flexbox dalam bahasa rumah: Flexbox menjawab "bagaimana mengatur sofa, meja, lampu di satu dinding", Grid menjawab "berapa kamar denah ini punya dan di mana ruangannya". Kamu akan memakai keduanya: Grid untuk membagi rumah menjadi ruangan, Flexbox untuk mengisi tiap ruangan dengan perabot.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

- **Seluruh layout halaman**: header, sidebar, main, footer yang stabil — Holy Grail dengan `grid-template-areas`. Ini "kapan Grid" yang paling khas.
- **Katalog / galeri / daftar kartu responsif**: grid dengan `auto-fill` + `minmax` membuat kolom menyesuaikan lebar otomatis tanpa script atau breakpoint.
- **Item unggulan dengan ukuran tidak seragam**: artikel pertama lebih besar (membentang 2 kolom), sisanya standar — penempatan eksplisit dengan `grid-column/grid-row`.
- **Kolom asimetris yang proporsional**: halaman detail buku (kolom info tetap 260px + kolom konten `1fr`) atau dashboard statistik.
- **Tata letak berbentuk tabel tanpa elemen `<table>`**: daftar pengumuman atau jadwal yang butuh kolom sejajar.

Aturan sederhananya: butuh baris **dan** kolom sekaligus → Grid; satu baris/kolom saja → Flexbox. "Grid untuk halaman, Flexbox untuk komponen" — kedua-duanya saling melengkapi, bukan bersaing.

## 6. Poin-poin Penting & Best Practices

- **`fr` vs `%`**: `1fr` memakai *ruang tersisa* setelah item berukuran tetap diposisikan — lebih fleksibel dan tidak meluap seperti kombinasi persen. Gunakan `fr` untuk ruang yang fleksibel, `px` untuk kolom yang memang kaku (sidebar).
- **`gap` selalu dipakai** — jarak antar track tanpa margin collapsing, dan bisa `gap: 16px 24px` (baris | kolom).
- **`minmax()` dengan `auto-fill` untuk katalog** — satu baris mengulang semua breakpoint. Gunakan `auto-fit` bila kamu ingin kolom kosong diisi penuh.
- **Baca peta `grid-template-areas` sebagai denah**: tiap baris string mewakili satu baris grid, dan nama yang sama berarti satu area. Pastikan bentuknya persegi panjang — nama yang "menjendol" akan membuat parse error.
- **Hindari menaruh sembarang child tanpa area di container yang sudah punya `grid-template-areas`** — item tak terpetakan akan terlempar ke posisi alami dan tampak "tersesat". Beri `grid-area` untuk semua child atau jangan campur.
- **`min-height: 100vh`** pada layout halaman agar footer menempel di bawah viewport walau isi pendek — pola Holy Grail.
- **Semantik dulu, div belakangan**: `<header>`, `<aside>`, `<main>`, `<footer>` masuk langsung sebagai grid items — tidak perlu div pembungkus.

## 7. Kesalahan Umum (Common Pitfalls & Bugs)

- **Item keluar dari alur akibat placement salah.** Kamu menulis `grid-column: 1 / 3` di dua item yang tumpang tindih, atau memakai nomor garis tanpa tahu jumlah kolom, sehingga item menimpa satu sama lain. Perbaikan: gambarkan line numbers dulu (atau pakai `span`) — hitung dari 1 untuk garis paling kiri/atas, negatif untuk dari kanan/bawah.
- **Item yang belum diberi area tersesat di layout bernama.** Container memakai `grid-template-areas`, tapi salah satu child tidak diarahkan ke area — ia mengalir ke cell kosong yang tidak kamu maksud. Perbaikan: beri `grid-area` untuk setiap child, atau pastikan semua item punya posisi eksplisit.
- **`auto-fill` vs `auto-fit` rancu.** Keduanya menghitung jumlah kolom, tapi `auto-fill` mempertahankan track kosong dan `auto-fit` menyusut-kannya jadi nol sehingga isi melebar. Perbaikan: katalog pakai `auto-fill`, konten yang ingin merata sampai penuh pakai `auto-fit`.
- **Hanya menghafal `1fr` tanpa `minmax`.** `repeat(3, 1fr)` di layar sempit memaksa tiga kolom menipis dan teksnya kelaparan. Perbaikan: kombinasikan dengan `minmax(280px, 1fr)` dan (untuk kontrol penuh) media query.
- **Menempatkan item di grid yang bukan container.** `grid-column` dan `grid-row` hanya berlaku pada *direct children* dari grid container — sama seperti properti flex.

## 8. Mini Project / Soal Latihan & Kunci Jawaban

### Tantangan

1. **Katalog responsif otomatis**: buat grid kartu buku yang menampilkan minimal 4 kartu. Gunakan `repeat(auto-fill, minmax(280px, 1fr))` dengan `gap` 24px — tanpa satu media query pun. Di ponsel harus satu kolom penuh; di layar lebar 4+ kolom.
2. **Holy Grail**: buat layout halaman lengkap (header, sidebar kiri, main, sidebar kanan/info, footer) dengan `grid-template-areas`. Header dan footer membentang penuh, dua kolom isi — sidebar 220px + main `1fr` (+ info 220px bila memakai 3 kolom). `min-height: 100vh`, dan berikan `grid-area` yang benar.

### Solusi & Pembahasan

```html
<!-- index.html -->
<body class="halaman">
    <header class="halaman__header">
        <h1>Perpustakaan Digital Kota</h1>
    </header>

    <aside class="halaman__sidebar">
        <ul>
            <li><a href="#">Koleksi</a></li>
            <li><a href="#">Keanggotaan</a></li>
            <li><a href="#">Tentang</a></li>
        </ul>
    </aside>

    <main class="halaman__main">
        <h2>Katalog Responsif</h2>
        <div class="katalog">
            <article class="kartu"><h3>Clean Code</h3><p>Robert C. Martin</p></article>
            <article class="kartu"><h3>Laskar Pelangi</h3><p>Andrea Hirata</p></article>
            <article class="kartu"><h3>Cosmos</h3><p>Carl Sagan</p></article>
            <article class="kartu"><h3>The Hobbit</h3><p>J.R.R. Tolkien</p></article>
            <article class="kartu"><h3>Atomic Habits</h3><p>James Clear</p></article>
        </div>
    </main>

    <aside class="halaman__info"><p>Promo bulan ini</p></aside>

    <footer class="halaman__footer">© 2024 Perpustakaan Digital Kota</footer>
</body>
```

```css
/* css/style.css */
* { box-sizing: border-box; }
body { margin: 0; font-family: sans-serif; }

/* ── Holy Grail (tantangan 2) ────────────────────────────────────────── */
.halaman {
    display: grid;
    grid-template-columns: 220px 1fr 220px;  /* sidebar | main | info */
    grid-template-rows: auto 1fr auto;       /* header | isi (tumbuh) | footer */
    grid-template-areas:
        "header  header  header"
        "sidebar main    info  "
        "footer  footer  footer";
    min-height: 100vh;
}

.halaman__header  { grid-area: header; background: #1e293b; color: #fff;
                    padding: 16px 24px; }
.halaman__sidebar { grid-area: sidebar; background: #f1f5f9; padding: 16px; }
.halaman__main    { grid-area: main;    padding: 24px; }
.halaman__info    { grid-area: info;    background: #f1f5f9; padding: 16px; }
.halaman__footer  { grid-area: footer;  background: #1e293b; color: #fff;
                    padding: 16px 24px; text-align: center; }

/* ── Katalog responsif (tantangan 1) ─────────────────────────────────── */
.katalog {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
    gap: 24px;
}

.kartu {
    padding: 20px;
    background: #ffffff;
    border: 1px solid #e2e8f0;
    border-radius: 8px;
}

.kartu h3 { margin: 0 0 8px; }
.kartu p  { margin: 0; color: #64748b; }
```

**Pembahasan**: tantangan 2 menghasilkan Holy Grail — baca peta `grid-template-areas` dan setiap elemen semantik menunjuk ke area dengan `grid-area`. `1fr` pada baris kedua membuat `main` menggelepang mengisi tinggi viewport sehingga footer menempel di bawah. Tantangan 1 selesai dengan satu baris `grid-template-columns`: browser menghitung kolom berdasar lebar, `minmax(280px, 1fr)` menjamin kartu tak pernah lebih sempit dari 280px dan selalu memakai sisa ruang merata. Uji di DevTools dengan device toolbar: geser lebar dari 360px ke 1280px dan saksikan jumlah kolom berubah 1 → 2 → 3 → 4 tanpa menulis media query. Itulah kekuatan Grid yang akan kamu gabungkan dengan media queries di materi 17 untuk kontrol breakpoint yang lebih halus.
