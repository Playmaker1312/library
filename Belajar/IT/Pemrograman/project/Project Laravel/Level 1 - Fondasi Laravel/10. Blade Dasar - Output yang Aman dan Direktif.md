# 10. Blade Dasar — Output yang Aman dan Direktif

Blade adalah template engine bawaan Laravel yang memungkinkan kamu menulis tampilan (view) dengan sintaks yang ringkas namun tetap merupakan PHP asli. Materi ini akan mengajarkan cara menampilkan data dengan aman (perlindungan XSS) dan cara mengontrol logika tampilan lewat direktif seperti `@if`, `@foreach`, hingga `@auth`.

## 1. Penjelasan Singkat & Konsep Dasar

Pada materi Routing sebelumnya, kita belajar bahwa sebuah route memanggil callback/controller, lalu controller mengembalikan sebuah view. Nah, view itulah yang ditulis dengan Blade. Jadi alurnya:

```
Route (pelayan menerima pesanan) -> Controller (koki menyiapkan data) -> View Blade (piring yang menyajikan)
```

Blade mengubah file `.blade.php` menjadi PHP murni saat di-render, lalu hasilnya disimpan di cache. Karena itu Blade sangat cepat. Yang penting dikuasai pertama kali: **bagaimana data dari controller sampai ke view** dan **bagaimana menampilkannya dengan aman**.

Materi ini menjadi fondasi untuk materi berikutnya (Layout dengan `@extends` dan Komponen Blade), karena layout dan komponen juga ditulis dengan sintaks Blade yang sama.

## 2. Fungsi & Kegunaan Utama dalam Laravel

Blade menyelesaikan masalah besar dalam pengembangan web: **memisahkan logika aplikasi dari tampilan (presentation)**. Tanpa Blade, kamu akan menulis HTML dengan `<?php echo $buku['judul']; ?>` yang berantakan dan rawan kesalahan.

Kegunaan utama Blade:

- **Keamanan output**: `{{ $buku->judul }}` otomatis melewati `htmlspecialchars()`, sehingga teks seperti `<script>alert('x')</script>` tidak akan dieksekusi oleh browser. Ini pertahanan utama melawan serangan XSS.
- **Sintaks ringkas**: kondisi, perulangan, otentikasi, dan otorisasi ditulis dengan direktif yang mudah dibaca.
- **Komposisi tampilan**: layout, partial, dan komponen (dibahas di materi berikutnya).
- **Cache otomatis**: file yang sudah di-compile tidak di-proses ulang jika tidak berubah.

## 3. Contoh Kode & Implementasi (Real-world Example)

Kita akan menampilkan katalog buku di halaman `buku/index.blade.php`. Data buku dikirim dari controller lewat dua cara: `compact()` dan array asosiatif.

### 3.1 Mengirim data dari Controller

Lokasi standar: `app/Http/Controllers/BukuController.php`

```php
<?php

namespace App\Http\Controllers;

use App\Models\Buku;

class BukuController extends Controller
{
    public function index()
    {
        // Cara 1: compact() - variabel 'buku' jadi tersedia di view
        $buku = Buku::all();

        return view('buku.index', compact('buku'));

        // Cara 2: array asosiatif - hasilnya sama saja
        // return view('buku.index', ['buku' => $buku]);
    }
}
```

Lokasi route: `routes/web.php`

```php
use App\Http\Controllers\BukuController;

// Controller mengembalikan view 'buku.index'
Route::get('/buku', [BukuController::class, 'index'])->name('buku.index');
```

### 3.2 View katalog buku

Lokasi standar: `resources/views/buku/index.blade.php`

```blade
{{-- Judul halaman --}}
<h1>Katalog Buku</h1>

{{-- @forelse: cek dulu apakah data ada; kalau kosong jalankan @empty --}}
@forelse ($buku as $item)
    <div class="grid">
        @foreach ($item as $key => $b)
            {{-- Menampilkan properti satu per satu dengan aman --}}
            <div class="kartu">
                <h2>{{ $b->judul }}</h2>
                <p>{{ $b->pengarang }}</p>

                {{-- Harga: {{ }} otomatis htmlspecialchars, aman dari XSS --}}
                <p>Harga: Rp {{ number_format($b->harga, 0, ',', '.') }}</p>

                {{-- Direktif kondisional: badge stok --}}
                @if ($b->stok > 10)
                    <span class="badge badge-hijau">Stok: {{ $b->stok }} (tersedia)</span>
                @elseif ($b->stok > 0)
                    <span class="badge badge-kuning">Stok: {{ $b->stok }} (tinggal sedikit)</span>
                @else
                    <span class="badge badge-merah">Stok habis</span>
                @endif

                {{-- Menampilkan nomor urut perulangan lewat variabel $loop --}}
                <small>Item ke-{{ $loop->iteration }} dari {{ $loop->count }}</small>
            </div>
        @endforeach
    </div>
@empty
    {{-- Pesan saat tidak ada buku sama sekali --}}
    <p>Belum ada buku. Silakan tambahkan buku terlebih dahulu.</p>
@endforelse

{{-- @unless: jalankan jika kondisi TIDAK terpenuhi --}}
@unless (auth()->check())
    <p>Login untuk melihat detail harga khusus anggota.</p>
@endunless
```

### 3.3 Direktif auth, isset, dan otorisasi

```blade
{{-- @auth: hanya tampil untuk pengguna yang login --}}
@auth
    <p>Selamat datang, {{ auth()->user()->name }}</p>
@endauth

{{-- @guest: hanya tampil untuk pengunjung yang belum login --}}
@guest
    <a href="{{ route('login') }}">Masuk</a>
@endauth

{{-- @isset: tampil hanya jika variabel ada dan tidak null --}}
@isset($halamanDeskripsi)
    <p>{{ $halamanDeskripsi }}</p>
@endisset

{{-- @empty: tampil jika variabel ada tapi isinya kosong/null --}}
@empty($buku)
    <p>Katalog masih kosong.</p>
@endempty

{{-- @can: tampil hanya jika user punya izin (dibahas di materi Otorisasi) --}}
@can('hapus-buku', $buku)
    <form method="POST" action="{{ route('buku.destroy', $buku) }}">
        @csrf
        @method('DELETE')
        <button type="submit">Hapus Buku</button>
    </form>
@endcan

@cannot('hapus-buku', $buku)
    <p>Kamu tidak berhak menghapus buku ini.</p>
@endcannot
```

## 4. Analogi Sederhana

**Blade/View = Penyajian makanan di piring.**

- Bahan mentah data = bahan makanan dari gudang (Model `Buku`).
- Route = pelayan yang menerima pesanan dari pelanggan (browser).
- Controller = koki yang mengambil bahan dari gudang lalu menyiapkan hidangan.
- View Blade = piring yang menyajikan hidangan dengan rapi ke pelanggan.

`{{ }}` itu seperti **piring yang hanya menyajikan makanan yang sudah dipastikan aman** — tidak ada pisau tersembunyi. `{!! !!}` adalah piring biasa tanpa pengaman; hanya boleh digunakan jika kamu benar-benar yakin isinya aman (misalnya konten yang kamu tulis sendiri, bukan input user).

Direktif `@if`/`@foreach` ibarat **porsi dan tatanan penyajian**: pelayan memutuskan apakah menu habis (stok kosong) atau menawarkan porsi khusus, dan meletakkan tiap piring sesuai meja. Variabel `$loop` seperti urutan piring yang disajikan — tahu ini piring keberapa dan berapa totalnya.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

Gunakan direktif ini pada skenario nyata berikut:

- **`@if/@elseif/@else`**: menampilkan badge stok berbeda (hijau/kuning/merah), menampilkan status peminjaman ("Sedang dipinjam" / "Tersedia"), atau pesan selamat datang vs pesan ajakan login.
- **`@unless`**: tombol "Pinjam" hanya tampil jika user **belum** meminjam buku tersebut — logika "kecuali" yang lebih mudah dibaca daripada `@if (bukan)`.
- **`@forelse`**: daftar peminjaman user; kalau belum pernah meminjam tampilkan teks "Kamu belum pernah meminjam buku". Ini sangat umum di halaman profil.
- **`@auth`/`@guest`**: menu "Login"/"Daftar" untuk tamu, dan menu "Profil"/"Logout" untuk anggota.
- **`@isset`**: bagian deskripsi buku yang bersifat opsional; hindari error karena variabel belum di-set.
- **`@can`/`@cannot`**: tombol hapus/edit yang hanya tampil untuk admin, tombol verifikasi anggota untuk pustakawan.

## 6. Poin-poin Penting & Best Practices

- **Selalu gunakan `{{ }}`** untuk menampilkan data dari user atau database. `htmlspecialchars` di dalamnya memblokir XSS.
- **Gunakan `{!! !!}` hanya untuk konten yang benar-benar terpercaya** dan sengaja berupa HTML (contoh: body artikel yang kamu tulis). Untuk input user, hindari — atau sanitasi dulu.
- **Komentar rahasia pakai `{{-- --}}`**, bukan `<!-- -->`, karena komentar HTML terlihat di browser.
- **Utamakan `@forelse`** daripada `@foreach` + cek kosong manual; lebih pendek dan lebih aman.
- **Konvensi penamaan file view**: huruf kecil (lowercase) dan kebab-case, misalnya `buku/index.blade.php`, bukan `Buku/Index.blade.php`. Nama folder biasanya jamak mengikuti resource (`buku`, `peminjaman`).
- **Pisahkan logika dari view**: jangan query database di dalam Blade (`Buku::where(...)` di view adalah anti-pattern). Data harus disiapkan di controller.
- **Format angka/tanggal di view** (misal `number_format` untuk harga) agar tampilan konsisten, bukan menambah logika bisnis ke controller.
- **`$loop`** tersedia di dalam `@foreach` dan berisi `iteration` (mulai 1), `index` (mulai 0), `first`, `last`, `count`, `remaining`. Gunakan untuk memberi class CSS berbeda pada baris ganjil/genap.
- **`@yield` vs direktif lain**: `@yield` dipakai di layout (materi berikutnya). Di materi ini fokus pada output dan logika perulangan.
- **Selalu sertakan `@csrf`** di form `POST` (dibahas di materi Form). Form tanpa `@csrf` akan ditolak Laravel (419).
- **Blade otomatis di-cache**; setelah mengubah file `.blade.php`, biasanya tidak perlu `php artisan view:clear` karena Laravel mendeteksi perubahan, kecuali ada masalah caching aneh di production.

## 7. Kesalahan Umum (Common Pitfalls & Anti-patterns)

- **Lupa `@csrf` di form POST** → muncul error `419 Page Expired`. Solusi: tambahkan `@csrf` tepat setelah tag `<form>`.
- **Pakai `{!! !!}` untuk data user** → rentan XSS. Contoh salah: `{!! $b->deskripsi !!}` saat deskripsi bisa berisi script. Solusi: ganti ke `{{ $b->deskripsi }}`.
- **Nama file view salah** → error `View [buku.index] not found`. Solusi: cek huruf kecil, ekstensi `.blade.php`, dan path folder. `buku/index.blade.php` dipanggil dengan `view('buku.index')`.
- **`@yield` vs `@section` tertukar** → `@yield` dipakai di layout (menentukan "lubang" yang diisi), `@section`/`@endsection` dipakai di child view (mengisi lubang). Memakai `@yield` di child tidak akan mengisi apa pun.
- **Variabel tidak ada** → error seperti `Undefined variable $buku` (atau blank). Solusi: pastikan controller mengirimnya (`compact('buku')`), atau cek dengan `@isset`/`@empty` bila opsional.
- **Menulis query di dalam view** → lambat dan susah dirawat. Semua data harus datang dari controller.
- **Komentar `<!-- -->` menyimpan rahasia** → misalnya credential muncul di source code browser. Gunakan `{{-- --}}`.
- **Bercampur tag penutup** → `@endif` tanpa `@if`, atau `@endforeach` dobel. Periksa pasangan direktif; indentasi dengan rapi membantu.
- **Masalah cache view di production** → tampilan tidak berubah padahal file sudah diedit. Solusi: `php artisan view:clear` lalu jalankan ulang.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan

1. **Badge status peminjaman**: Di halaman detail buku `buku/show.blade.php`, tampilkan badge:
   - "Tersedia untuk dipinjam" (hijau) jika stok > 0,
   - "Menunggu restok" (kuning) jika stok == 0,
   - "Dalam masa perawatan" (merah) jika stok < 0 (buku rusak/hilang).
   Gunakan `@if/@elseif/@else`. Tampilkan juga "Kamu sudah meminjam buku ini" jika variabel `$sudahDipinjam` bernilai `true`.

2. **Daftar peminjaman dengan nomor urut**: Di halaman `peminjaman/index.blade.php`, tampilkan daftar peminjaman user yang dikirim dari controller sebagai `$peminjaman`. Tampilkan nomor urut (1, 2, 3...), judul buku, tanggal pinjam, dan status. Jika belum pernah meminjam, tampilkan pesan ramah. Gunakan `@forelse`, variabel `$loop`, dan `@if`.

### Jawaban & Pembahasan

**Jawaban 1** — lokasi `resources/views/buku/show.blade.php`:

```blade
<h1>{{ $buku->judul }}</h1>

{{-- Badge status berdasarkan stok --}}
@if ($buku->stok > 0)
    <span class="badge badge-hijau">Tersedia untuk dipinjam</span>
@elseif ($buku->stok == 0)
    <span class="badge badge-kuning">Menunggu restok</span>
@else
    <span class="badge badge-merah">Dalam masa perawatan</span>
@endif

{{-- Pesan bila user sudah meminjam buku ini --}}
@if ($sudahDipinjam)
    <p class="catatan">Kamu sudah meminjam buku ini.</p>
@endif
```

Alur: `@if` mengecek stok > 0 (terbanyak dulu). `@elseif` menangkap kasus stok == 0. `@else` menangkap sisanya (stok negatif). Variabel `$sudahDipinjam` bernilai `true`/`false` dari controller; `@if` cukup membaca nilai aslinya tanpa perbandingan. Ingat, semua variabel ini (`$buku`, `$sudahDipinjam`) dikirim controller lewat `compact()`.

**Jawaban 2** — lokasi `resources/views/peminjaman/index.blade.php`:

```blade
<h1>Riwayat Peminjaman Saya</h1>

@forelse ($peminjaman as $pinjam)
    <div class="baris">
        {{-- $loop->iteration mulai dari 1 --}}
        <strong>{{ $loop->iteration }}.</strong>
        <span>{{ $pinjam->buku->judul }}</span>
        <span>{{ $pinjam->tanggal_pinjam->format('d M Y') }}</span>

        {{-- Status pinjaman --}}
        @if ($pinjam->status === 'dikembalikan')
            <span class="badge badge-hijau">Selesai</span>
        @else
            <span class="badge badge-kuning">Sedang dipinjam</span>
        @endif

        {{-- Info tambahan: baris terakhir dalam daftar --}}
        @if ($loop->last)
            <p><small>Ini adalah peminjaman terakhirmu (total {{ $loop->count }}).</small></p>
        @endif
    </div>
@empty
    <p>Kamu belum pernah meminjam buku apa pun. Yuk, jelajahi katalog!</p>
@endempty
```

Alur: `@forelse` otomatis menangani dua kasus — data ada (loop berjalan) dan data kosong (blok `@empty` dijalankan, tidak perlu `@if (count(...))` manual). `$loop->iteration` menghasilkan nomor urut mulai 1, `$loop->count` memberi total item, dan `$loop->last` bernilai `true` hanya pada iterasi terakhir. Format tanggal dilakukan di view memakai helper Carbon bawaan (`->format()`), sehingga tampilan konsisten dan logic tetap bersih.
