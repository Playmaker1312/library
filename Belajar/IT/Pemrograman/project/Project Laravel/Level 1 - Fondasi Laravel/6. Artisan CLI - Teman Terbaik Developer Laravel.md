# 6. Artisan CLI — Teman Terbaik Developer Laravel

Artisan adalah command-line tool bawaan Laravel yang bekerja lewat file `artisan` di root project. Kalau `.env` adalah otak konfigurasi, maka Artisan adalah **tangan kanan** kamu — hampir semua tugas scaffolding (membuat Controller, Model, Migration), migrasi database, cache, dan informasi project dilakukan lewat sini. Sebagian besar perintah di roadmap ini akan memakai Artisan, jadi kuasai materi ini baik-baik.

## 1. Penjelasan Singkat & Konsep Dasar

Artisan adalah **CLI (Command Line Interface)** yang mengikuti filosofi *Convention over Configuration*: ia otomatis menempatkan file di folder yang benar, memberi nama class sesuai konvensi, dan membangun namespace yang tepat. Kamu tidak perlu menghafal lokasi dan struktur — cukup jalankan satu perintah.

Konsep ini nyambung langsung dengan materi sebelumnya:
- **Materi 3 (Instalasi)**: `laravel new`, `php artisan serve`, dan `php artisan --version` adalah perkenalan pertama kamu dengan Artisan.
- **Materi 4 (Struktur Direktori)**: Artisan lah yang menciptakan file di folder-folder yang tadi kita pelajari.
- **Materi 5 (.env)**: `php artisan key:generate`, `config:cache`, `config:clear` berhubungan dengan `.env`.
- **Materi berikutnya (Routing)**: `php artisan route:list` akan jadi alat utama untuk memeriksa route.

## 2. Fungsi & Kegunaan Utama dalam Laravel

1. **Scaffolding otomatis** — membuat file (Model, Controller, Migration, Request, dsb.) dengan struktur dan namespace yang benar, sehingga minim typo dan salah lokasi.
2. **Manajemen database** — menjalankan dan membatalkan migration, mengisi data awal (seeder).
3. **Informasi project** — melihat daftar route, konfigurasi, versi, dan status aplikasi.
4. **Optimasi performa** — me-cache config, route, dan view untuk produksi.
5. **Interaksi langsung dengan data** — `tinker` memberi REPL interaktif untuk menguji Eloquent dan kode Laravel tanpa halaman web.
6. **Menulis command custom** — kamu bisa membuat command sendiri untuk tugas berulang project perpustakaan (mis. laporan peminjaman overdue).

## 3. Contoh Kode & Implementasi (Real-world Example)

### 3.1 Melihat semua perintah yang tersedia

```bash
# Daftar lengkap command + deskripsi
php artisan list

# Cari perintah tertentu
php artisan list make
```

### 3.2 Kelompok perintah yang wajib kamu hafal

**a) Server**

```bash
php artisan serve                # jalan di http://127.0.0.1:8000
php artisan serve --port=9000    # ganti port jika 8000 dipakai
```

**b) Scaffolding (`make:*`) — paling sering dipakai**

```bash
# Model + migration + factory + seeder sekaligus (flag -mfs)
php artisan make:model Buku -mfs

# Controller resource (CRUD: index, create, store, edit, update, destroy)
php artisan make:controller BukuController --resource

# Middleware (mis. cek role pustakawan)
php artisan make:middleware EnsureUserIsPustakawan

# Form Request untuk validasi
php artisan make:request StoreBukuRequest

# Policy (otorisasi per model)
php artisan make:policy BukuPolicy --model=Buku

# Event & Listener (mis. PeminjamanTerbuat)
php artisan make:event PeminjamanTerbuat
php artisan make:listener KirimNotifikasiPeminjaman --event=PeminjamanTerbuat

# Job (mis. proses antrian pengembalian massal)
php artisan make:job ProsesPengembalianBuku

# Mail dengan template markdown
php artisan make:mail NotifikasiOverdue --markdown=emails.notifikasi-overdue

# Test
php artisan make:test PeminjamanTest
```

**c) Database**

```bash
php artisan migrate                # jalankan migration (buat tabel)
php artisan migrate:status         # lihat status tiap migration
php artisan migrate:rollback       # batalkan migration terakhir
php artisan migrate:fresh --seed   # reset semua tabel + isi seeder (hati-hati, data hilang!)
php artisan db:seed                # jalankan seeder
```

**d) Informasi**

```bash
php artisan route:list             # daftar semua route (belajar di materi Routing)
php artisan route:list --path=buku # filter route yang mengandung "buku"
php artisan about                  # ringkasan environment & folder
php artisan config:show database   # tampilkan konfigurasi database saat ini
```

**e) Cache & Optimasi**

```bash
php artisan optimize:clear         # bersihkan semua cache sekaligus (config, route, view, dll)
php artisan cache:clear            # bersihkan cache aplikasi
php artisan config:clear           # bersihkan cache konfigurasi
php artisan route:clear            # bersihkan cache route
php artisan view:clear             # bersihkan cache view/Blade

# Untuk produksi — cache semua agar cepat
php artisan optimize
```

**f) Tinker (REPL interaktif)**

```bash
php artisan tinker

# Contoh interaksi dengan data — di dalam prompt tinker:
```

```php
<?php
// Di dalam prompt php artisan tinker
use App\Models\Buku;
use App\Models\Anggota;

// Buat data uji lewat Eloquent
$buku = Buku::create([
    'judul'  => 'Laravel untuk Pemula',
    'penulis'=> 'Budi Santoso',
    'stok'   => 5,
]);

// Query data
$buku = Buku::where('stok', '>', 0)->get();

// Hitung total anggota aktif
$total = Anggota::where('status', 'aktif')->count();

// Simulasikan logika peminjaman
$anggota = Anggota::first();
$anggota->nama; // baca properti hasil query
```

### 3.3 Contoh skenario nyata di perpustakaan

Saat kita mau membangun fitur CRUD Buku di materi selanjutnya, urutan artisan-nya kira-kira begini:

```bash
# 1. Buat model + migration + factory + seeder
php artisan make:model Buku -mfs

# 2. Buat controller resource
php artisan make:controller BukuController --resource

# 3. Buat form request untuk validasi
php artisan make:request StoreBukuRequest

# 4. Jalankan migration (tabel bukus terbuat)
php artisan migrate

# 5. Isi data awal
php artisan db:seed

# 6. Cek route yang sudah dibuat
php artisan route:list
```

## 4. Analogi Sederhana

Artisan seperti **koki kepala yang serba tahu di dapur restoran** — tetapi lebih tepatnya: ia adalah **katalog resep & peralatan dapur yang tinggal dipanggil namanya**.

Kamu tidak perlu mencari-cari di mana wajan (folder), atau bagaimana menyusun alatnya (namespace). Cukup ucapkan: "buatkan saya pisau khusus" → `php artisan make:model Buku -mfs` — dan pisau (model lengkap dengan migration, factory, seeder) langsung muncul di tempat yang benar sesuai konvensi.

`php artisan tinker` adalah **dapur percobaan** — kamu bisa mencicipi bahan (query data) langsung sebelum dimasak (ditulis ke halaman web). `php artisan route:list` adalah **daftar menu** — lihat semua pesanan (URL) yang tersedia di restoran. `migrate:fresh --seed` adalah **membersihkan dapur & mengisi stok ulang** dari nol — hati-hati, semua yang lama hilang.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

| Situasi | Perintah Artisan |
|---|---|
| Membuat Model Buku beserta pendukungnya | `php artisan make:model Buku -mfs` |
| Membuat Controller CRUD buku | `php artisan make:controller BukuController --resource` |
| Membuat tabel di database | `php artisan migrate` |
| Mengisi data awal (contoh buku, anggota) | `php artisan db:seed` |
| Melihat semua route aplikasi | `php artisan route:list` |
| Menguji query tanpa halaman web | `php artisan tinker` |
| Menambah validasi form | `php artisan make:request StoreBukuRequest` |
| Menambah aturan akses role | `php artisan make:policy BukuPolicy --model=Buku` |
| Bersih-bersih cache setelah ubah `.env` | `php artisan optimize:clear` |
| Menyiapkan produksi | `php artisan optimize` |

## 6. Poin-poin Penting & Best Practices

- **Selalu gunakan `php artisan make:*` untuk membuat file** — lokasi, namespace, dan nama class dijamin benar sesuai konvensi. Ini menyelamatkanmu dari error `Class not found`.
- **`-mfs` pada `make:model`** = buat sekaligus Migration, Factory, dan Seeder: `php artisan make:model Buku -mfs`.
- **`--resource` pada `make:controller`** = langsung buat 7 method CRUD standar (`index`, `create`, `store`, `show`, `edit`, `update`, `destroy`).
- **Baca output perintah.** Artisan memberi tahu file mana yang dibuat dan command apa yang dijalankan — jangan di-skip.
- **Hati-hati `migrate:fresh`** — menghapus semua data. Hanya untuk development, bukan produksi.
- **Gunakan `optimize:clear`** saat bingung kenapa perubahan tidak muncul — ini membersihkan semua cache sekaligus.
- **`route:list` adalah sahabat routing** — biasakan mengecek route setelah menulis route baru.
- **Custom command** untuk tugas berulang: `php artisan make:command LaporkanBukuTerlambat`, lalu daftarkan lewat `signature` dan logika di `handle()`.
- **Tinker aman untuk development**, jangan jalankan di server produksi yang menangani traffic nyata.

## 7. Kesalahan Umum (Common Pitfalls & Anti-patterns)

| Gejala | Penyebab | Solusi |
|---|---|---|
| `Command "make:model" is not defined` | Dijalankan di folder bukan project Laravel | Pastikan berada di root project (`perpustakaan/`), lihat `artisan` file |
| `Not Found Exception` saat akses route | Route belum dibuat / salah nama | `php artisan route:list` untuk cek |
| Perubahan kode/`.env` tidak berefek | Cache masih aktif | `php artisan optimize:clear` |
| `migrate:fresh --seed` di produksi (data hilang!) | Salah environment | Jangan pernah menjalankan di produksi; cek `APP_ENV` |
| `Class "Database\Seeders\XSeeder" not found` | Seeder belum terdaftar | Daftarkan di `DatabaseSeeder::run()` dengan `$this->call([...])` |
| Menjalankan artisan tapi error "file not found" | Ada di subfolder / file `artisan` terhapus | Jalankan dari root project |
| Tinker query tidak mengubah data | Lupa `->save()` / atribut salah | Pastikan kolom sudah ada di migration & mass assignment diizinkan |
| Salah mengetik nama command | — | `php artisan list` untuk cek nama persisnya |

## 8. Soal Latihan & Kunci Jawaban

### Tantangan

1. Buat fondasi fitur Buku di project `perpustakaan` dengan menjalankan Artisan: buat Model `Buku` lengkap dengan migration, factory, dan seeder; buat Controller `BukuController` bertipe resource; buat Form Request `StoreBukuRequest`. Lalu jalankan migration dan verifikasi hasilnya.
2. Kamu menambahkan route baru di `routes/web.php`, tetapi muncul error 404 saat diakses. Sebutkan tiga langkah diagnosis dengan Artisan.

### Jawaban & Pembahasan

**Soal 1**

```bash
# 1. Model + migration + factory + seeder (flag -mfs)
php artisan make:model Buku -mfs
# Output: INFO Model [app/Models/Buku.php] created successfully. (dll)

# 2. Controller resource
php artisan make:controller BukuController --resource

# 3. Form Request validasi
php artisan make:request StoreBukuRequest

# 4. Jalankan migration untuk membuat tabel bukus
php artisan migrate

# 5. Verifikasi tabel sudah dibuat
php artisan migrate:status
```

**Alur pembahasan:** `make:model Buku -mfs` menciptakan 4 file sekaligus di lokasi konvensional: `app/Models/Buku.php`, migration di `database/migrations/`, factory di `database/factories/`, dan seeder di `database/seeders/`. Controller resource dibuat dengan 7 method CRUD standar. Form Request ditempatkan di `app/Http/Requests/`. Semua ini mengikuti peta struktur direktori (materi 4). Setelah `migrate`, tabel `bukus` muncul di database `perpustakaan_db` — verifikasi lewat `migrate:status`.

**Soal 2**

```bash
# 1. Pastikan route terdaftar
php artisan route:list

# 2. Filter route yang berkaitan, mis. yang mengandung "buku"
php artisan route:list --path=buku

# 3. Bersihkan cache route jika route sudah benar tapi tetap 404
php artisan route:clear

# (Opsional) cek konfigurasi & versi aplikasi
php artisan about
```

**Alur pembahasan:** `route:list` menunjukkan seluruh route yang dikenali framework — jika route baru tidak muncul, berarti penulisannya salah di `routes/web.php`. Jika muncul tapi tetap 404, kemungkinan cache route lama masih aktif, jadi `route:clear` menyegarkannya. Pola diagnosis "lihat → filter → bersihkan cache" adalah cara standar menyelesaikan masalah routing, dan akan jadi modal utama di materi Routing berikutnya.
