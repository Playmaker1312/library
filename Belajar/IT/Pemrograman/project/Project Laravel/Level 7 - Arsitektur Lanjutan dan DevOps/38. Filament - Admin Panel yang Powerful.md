# 38. Filament — Admin Panel yang Powerful

Filament adalah admin panel modern yang dibangun di atas TALL stack (Tailwind + Alpine + Livewire + Laravel). Dengan Filament, kamu tidak perlu membangun dashboard admin dari nol — cukup definisikan resource-nya, dan panel siap pakai dengan CRUD, form, tabel, filter, dan otorisasi. Materi ini adalah puncak dari materi Livewire (39) dan erat kaitannya dengan policy dari materi 24.

## 1. Penjelasan Singkat & Konsep Dasar

Filament itu "boilerplate destroyer": ia menyediakan seluruh kerangka UI admin (sidebar, layout, form, tabel, modal, notifikasi) yang siap diisi oleh definisi resource milikmu. Konsep intinya adalah **Resource** — satu file PHP yang mendeskripsikan bagaimana sebuah model (misal `Buku`) ditampilkan di form dan tabel panel admin. Karena Filament dibangun di atas Livewire (materi 39), semua interaksinya reaktif tanpa reload halaman, dan karena ia menjunjung tinggi prinsip Laravel, otorisasinya tetap lewat Policy (materi 24).

Alur sederhananya: `composer require filament` -> `php artisan filament:install --panels` -> `php artisan make:filament-resource Buku --generate` -> sesuaikan form & tabel di `app/Filament/Resources/BukuResource.php`.

## 2. Fungsi & Kegunaan Utama dalam Laravel

Masalah yang dipecahkan Filament: **membangun UI admin internal itu mahal dan membosankan**. Setiap aplikasi butuh cara mengelola data — buku, anggota, peminjaman — tapi menulis CRUD penuh (list, search, pagination, create form, edit form, delete, validasi) untuk tiap model memakan waktu berhari-hari dan rawan tidak konsisten.

Filament menyelesaikan ini dengan:
- **Panel admin siap pakai** di `/admin` dengan autentikasi bawaan.
- **Resource generator** yang membaca kolom migrasi dan langsung membuat form + tabel.
- **Form & table builder** yang deklaratif (schema array), jadi UI dihasilkan konsisten dan mudah diubah.
- **Terintegrasi dengan ekosistem Laravel**: Policy untuk otorisasi, Filament dibangun di atas Livewire sehingga skill yang kamu pelajari di materi 39 tetap relevan.

## 3. Contoh Kode & Implementasi (Real-world Example)

Lokasi file standar:
- `app/Filament/Resources/BukuResource.php` — definisi resource.
- `app/Filament/Resources/BukuResource/Pages/` — halaman List, Create, Edit.

### 3.1 Install Filament

```bash
# 1. Install package
composer require filament/filament:"^3.0"

# 2. Jalankan installer, pilih opsi panel (biasanya "Panels")
php artisan filament:install --panels

# 3. Generate resource Buku dengan --generate
#     flag ini otomatis membaca kolom migrasi Buku
php artisan make:filament-resource Buku --generate
```

### 3.2 Akses Panel

```bash
# Buka browser
# http://localhost:8000/admin

# Buat user admin
php artisan make:filament-user
```

### 3.3 Contoh Lengkap BukuResource

```php
<?php

namespace App\Filament\Resources;

use App\Filament\Resources\BukuResource\Pages;
use App\Models\Buku;
use Filament\Forms;
use Filament\Forms\Form;
use Filament\Resources\Resource;
use Filament\Tables;
use Filament\Tables\Table;

class BukuResource extends Resource
{
    protected static ?string $model = Buku::class;

    // Ikon & label di sidebar panel
    protected static ?string $navigationIcon = 'heroicon-o-book-open';
    protected static ?string $navigationLabel = 'Katalog Buku';

    public static function form(Form $form): Form
    {
        return $form->schema([
            Forms\Components\TextInput::make('judul')
                ->required()
                ->maxLength(255),
            Forms\Components\TextInput::make('pengarang')
                ->required()
                ->maxLength(255),
            Forms\Components\TextInput::make('isbn')
                ->unique(ignoreRecord: true)
                ->maxLength(13),
            Forms\Components\Select::make('kategori')
                ->options([
                    'fiksi'   => 'Fiksi',
                    'nonfiksi' => 'Non-fiksi',
                    'teknologi' => 'Teknologi',
                    'anak'    => 'Anak-anak',
                ])
                ->required(),
            Forms\Components\TextInput::make('harga')
                ->numeric()
                ->prefix('Rp')
                ->required(),
            Forms\Components\TextInput::make('stok')
                ->integer()
                ->minValue(0)
                ->required(),
            Forms\Components\Textarea::make('deskripsi')
                ->columnSpanFull(),
            Forms\Components\FileUpload::make('sampul')
                ->image()
                ->imageResizeWidth(400)
                ->directory('sampul-buku'),
        ]);
    }

    public static function table(Table $table): Table
    {
        return $table
            ->columns([
                Tables\Columns\TextColumn::make('judul')
                    ->searchable()
                    ->sortable(),
                Tables\Columns\TextColumn::make('pengarang')
                    ->searchable(),
                Tables\Columns\TextColumn::make('kategori')
                    ->badge()
                    ->color(fn (string $state): string => match ($state) {
                        'teknologi' => 'info',
                        'fiksi'     => 'success',
                        'anak'      => 'warning',
                        default     => 'gray',
                    }),
                Tables\Columns\TextColumn::make('harga')
                    ->money('IDR')
                    ->sortable(),
                Tables\Columns\TextColumn::make('stok')
                    ->badge()
                    ->color(fn (int $state): string => $state > 0 ? 'success' : 'danger')
                    ->label('Stok'),
                Tables\Columns\TextColumn::make('created_at')
                    ->dateTime(),
            ])
            ->filters([
                Tables\Filters\SelectFilter::make('kategori'),
            ])
            ->actions([
                Tables\Actions\EditAction::make(),
                Tables\Actions\DeleteAction::make(),
            ]);
    }

    public static function getPages(): array
    {
        return [
            'index'  => Pages\ListBukus::route('/'),
            'create' => Pages\CreateBuku::route('/create'),
            'edit'   => Pages\EditBuku::route('/{record}/edit'),
        ];
    }
}
```

### 3.4 Hubungkan ke Policy (materi 24)

```php
// app/Models/Buku.php — override otorisasi default
class Buku extends Model
{
    // Laravel 11: otomatis memakai BukuPolicy dari app/Policies
    // Filament otomatis mengecek Policy saat user membuka panel
}

// app/Policies/BukuPolicy.php (contoh sederhana)
class BukuPolicy
{
    public function viewAny(User $user): bool
    {
        return $user->isAdmin(); // hanya admin yang lihat panel
    }

    public function delete(User $user, Buku $buku): bool
    {
        return $user->isAdmin(); // hanya admin boleh hapus buku
    }
}
```

## 4. Analogi Sederhana

Bayangkan Filament sebagai **panel manajemen / meja kasir restoran**. Sebagai pemilik restoran, kamu tidak perlu membangun meja kasir dari kayu sendiri — kamu beli sistem kasir jadi yang tinggal dikonfigurasi. Filament memberi dashboard siap pakai untuk mengelola **stok (buku)**, **karyawan (anggota)**, dan **laporan (peminjaman)** — semua lewat UI yang sudah jadi, tinggal kamu definisikan kolom dan formnya. Kamu fokus pada "apa yang dikelola" (resource), bukan "bagaimana UI-nya dibuat".

Sementara itu, **Livewire (39) adalah pelayan yang responsif** — saat pelanggan bertanya apakah menu X masih ada, pelayan cek dari meja tanpa harus lari ke dapur (reload halaman). Filament justru memakai Livewire di dalamnya: setiap klik di panel itu request AJAX-reaktif, bukan reload penuh.

## 5. Kapan Harus Digunakan & Kasus Penggunaan (Use Cases)

| Situasi | Rekomendasi | Alasan |
|---|---|---|
| Butuh panel admin internal cepat (kelola buku, anggota, peminjaman) | **Filament** | Semua CRUD siap pakai, tinggal definisi resource |
| Admin panel sangat custom, UI unik, banyak interaksi aneh | **Build sendiri** (Blade + Livewire) | Filament punya konvensi yang kadang sulit dipaksa |
| Hanya butuh 1-2 halaman CRUD kecil | Livewire/Blade biasa | Filament bisa berlebihan untuk skala sekecil itu |
| Butuh dashboard dengan banyak widget, chart, notifikasi | **Filament** | Punya widget system bawaan (Stats, Chart) |

Aturan praktis untuk sistemmu (perpustakaan): pakai Filament untuk **area admin** (staff mengelola katalog, stok, laporan), dan Livewire (39) untuk **area publik** (katalog yang dilihat anggota dengan pencarian real-time).

## 6. Poin-poin Penting & Best Practices

- **Install bertahap**: `composer require filament/filament:"^3.0"` lalu `php artisan filament:install --panels`. Generate resource dengan `php artisan make:filament-resource Buku --generate` agar kolom form/tabel langsung terbaca dari migrasi.
- **Form schema**: gunakan `TextInput` (dengan `->required()`, `->maxLength()`, `->numeric()`, `->prefix('Rp')`, `->minValue(0)`), `Select` untuk pilihan kategori, `Textarea` untuk deskripsi (atur `->columnSpanFull()` agar tampil penuh), dan `FileUpload` untuk sampul (`->image()`, `->imageResizeWidth(400)`, `->directory(...)`).
- **Table**: `TextColumn` dengan `->searchable()` dan `->sortable()` untuk judul; `->badge()` untuk kategori dan stok (warnai dengan closure `->color()`); `->money('IDR')` untuk harga.
- **Filter & aksi**: `SelectFilter` untuk memfilter kategori; `EditAction` dan `DeleteAction` di `->actions()`.
- **Navigation**: set `$navigationIcon` dan `$navigationLabel` agar sidebar rapi.
- **Otorisasi**: jangan biarkan panel terbuka tanpa proteksi — pastikan Policy (materi 24) menutup akses, minimal `viewAny` untuk admin.
- **Environment**: di produksi set `APP_ENV=production` dan `APP_DEBUG=false`, jangan expose debug. Jalankan `php artisan filament:optimize` setelah deploy.
- **Data terkait**: jangan langsung tampilkan semua kolom; tampilkan kolom yang berguna saja agar tabel tidak padat.

## 7. Kesalahan Umum (Common Pitfalls & Anti-patterns)

| Gejala | Penyebab | Solusi |
|---|---|---|
| UI Filament aneh / tidak stylish | Lupa publish assets atau asset belum dibuild | `php artisan filament:assets`; pastikan `npm run build` dijalankan bila memakai tema custom |
| Panel bisa diakses semua orang | Panel dibuka tanpa autentikasi | Pastikan konfigurasi panel memakai provider auth; proteksi lewat Policy |
| Akses ditolak padahal user valid | Policy belum dibuat / belum disinkron dengan resource | Generate policy (`php artisan make:policy BukuPolicy --model=Buku`) dan pastikan method-nya mengembalikan `true` untuk peran yang berhak |
| Form create edit tidak jalan | Resource tidak sync dengan kolom migrasi | Jalankan ulang `--generate` atau cek kolom di form schema cocok dengan migrasi |
| FileUpload gagal di produksi | Storage link belum dibuat | `php artisan storage:link` |
| Panel lambat dengan banyak data | Query default mengambil semua | Atur `->paginate()` di halaman List, atau gunakan `ModifyQueryUsing` |
| Membangun semua UI custom di Filament | Memaksakan design non-konvensional | Pilih membangun sendiri bila kebutuhan custom-nya lebih besar daripada default Filament |

**Troubleshooting cepat**: kalau resource tidak muncul di sidebar, cek `$navigationGroup` / label; kalau error 403, cek Policy; kalau gambar tidak tampil, cek `storage:link`; selalu lihat `php artisan route:list` untuk memastikan route `/admin` ada.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan

1. Buat resource `Anggota` dengan Filament: form berisi `nama` (required), `email` (required, format email, unique), `no_hp` (optional), `alamat` (textarea). Tabel menampilkan `nama` (searchable) dan `email` (searchable), dengan filter `SelectFilter` berdasarkan status keanggotaan (`aktif`/`nonaktif`). Buat field `status` di form sebagai `Select`. Pastikan hanya admin yang bisa menghapus anggota.
2. Tambahkan aksi di tabel `BukuResource` untuk menampilkan stok dengan warna: hijau bila stok lebih dari 5, kuning bila 1-5, merah bila 0. Jelaskan cara kerjanya.

### Jawaban & Pembahasan

**Jawaban 1**

```bash
php artisan make:filament-resource Anggota --generate
```

```php
// app/Filament/Resources/AnggotaResource.php (potongan utama)
public static function form(Form $form): Form
{
    return $form->schema([
        Forms\Components\TextInput::make('nama')
            ->required()
            ->maxLength(255),
        Forms\Components\TextInput::make('email')
            ->email()
            ->required()
            ->unique(ignoreRecord: true),
        Forms\Components\TextInput::make('no_hp')
            ->tel()
            ->maxLength(20),
        Forms\Components\Select::make('status')
            ->options([
                'aktif'   => 'Aktif',
                'nonaktif' => 'Non-aktif',
            ])
            ->default('aktif')
            ->required(),
        Forms\Components\Textarea::make('alamat'),
    ]);
}

public static function table(Table $table): Table
{
    return $table
        ->columns([
            Tables\Columns\TextColumn::make('nama')->searchable(),
            Tables\Columns\TextColumn::make('email')->searchable(),
            Tables\Columns\TextColumn::make('status')->badge(),
        ])
        ->filters([
            Tables\Filters\SelectFilter::make('status'),
        ])
        ->actions([
            Tables\Actions\EditAction::make(),
            Tables\Actions\DeleteAction::make()
                ->authorize(fn () => auth()->user()->isAdmin()),
        ]);
}
```

**Pembahasan**: `--generate` membaca migrasi dan membuat halaman List/Create/Edit otomatis. `unique(ignoreRecord: true)` penting agar saat edit, email milik record itu sendiri tidak dianggap duplikat. `->badge()` pada status membuatnya tampil sebagai label berwarna. Aksi Delete dibatasi dengan `->authorize()` sehingga hanya admin yang melihat tombol hapus (ini menyederhanakan kontrol di level UI; pastikan Policy tetap ada sebagai lapisan keamanan utama).

**Jawaban 2**

```php
Tables\Columns\TextColumn::make('stok')
    ->badge()
    ->color(fn (int $state): string => match (true) {
        $state > 5   => 'success',
        $state >= 1  => 'warning',
        default      => 'danger',
    }),
```

**Pembahasan**: Closure `->color()` menerima nilai kolom (di sini `$state` adalah nilai `stok`). Menggunakan `match(true)` membuat kita bisa mengevaluasi beberapa kondisi secara berurutan: di atas 5 hijau (`success`), 1-5 kuning (`warning`), dan 0 merah (`danger`). Filament menjalankan closure ini saat merender tabel, jadi warnanya otomatis mengikuti data terbaru tanpa reload.
