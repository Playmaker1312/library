# 26. Router dan Front Controller

> **Level 6 · Arsitektur MVC dan REST API** — Satu pintu masuk untuk semua request, dan satu "petugas lalu lintas" yang mengarahkannya.

---

## 1. Penjelasan Singkat & Konsep Dasar

**Front Controller** = pola arsitektur: **semua** request HTTP masuk ke **satu file** (`public/index.php`). Di sana request diparsing, dan **Router** memutuskan controller/method mana yang menanganinya.

Sebelum (Level 1-5): setiap halaman = satu file (`buku.php`, `login.php`). URL = file. **Masalah**: sulit memisahkan logika (controller) & tampilan, sulit menambah middleware, sulit security headers terpusat, duplikasi tinggi.

Sesudah (MVC): URL = rute, bukan file.

```
URL: /buku/{id}
     │
public/index.php (front controller)
     │  parse method & path
     ▼
Router: /buku/{id} → 'BukuController@show', params ['id' => 5]
     │
     ▼
BukuController->show($request, ['id' => 5])
     ├─ ambil data via BukuRepository
     └─ render View
```

**Bagaimana request sampai ke `index.php` tanpa nama file?** — via **URL rewriting** (Apache `.htaccess` atau nginx `try_files`): semua request yang bukan file/direktori asli diarahkan ke `index.php`.

**Benang Merah:** autoloading (25) memberi struktur file; router memberi *kontrol alur*: URL bersih, controller tipis, view terpisah. Ini juga pola persis framework (Laravel/Symfony router). API (27) memakai router yang sama untuk endpoint JSON.

---

## 2. Fungsi & Kegunaan Utama

- **URL yang bermakna** — `/buku/5` bukan `/buku.php?id=5`; mudah dibaca, dibookmark, SEO friendly.
- **Satu titik masuk** — middleware (auth, CSRF, headers) dipasang di front controller, bukan di tiap halaman.
- **Pemisahan concern (MVC)** — Controller tipis (koordinasi), Model/Repository (data), View (tampilan) — menggantikan "spaghetti" file.
- **Method routing** — GET (baca), POST/PUT/DELETE (mutasi) → menjalankan middleware sesuai jenis request.
- **Parameter dinamis** — `{id}` ditangkap & diserahkan ke controller — tidak manual parse query.
- **Error handling terpusat** — 404/403/500 ditangani sekali di front controller.

---

## 3. Contoh Kode & Implementasi Real-World

Struktur:

```
public/
├── index.php          ← front controller
└── .htaccess          ← URL rewriting
src/
├── Core/  Router.php  Request.php
└── Controllers/  BukuController.php
```

**`.htaccess` (Apache) — arahkan semua request ke index.php:**

```apache
Options -MultiViews -Indexes
RewriteEngine On

RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.php [QSA,L]
```

**`src/Core/Request.php` — bungkus data request:**

```php
<?php
// File: src/Core/Request.php
declare(strict_types=1);

namespace App\Core;

class Request {
    public function getMethod(): string {
        $method = $_SERVER['REQUEST_METHOD'] ?? 'GET';
        // Method spoofing untuk form HTML (PUT/DELETE)
        if ($method === 'POST' && isset($_POST['_method'])) {
            return strtoupper($_POST['_method']);
        }
        return $method;
    }

    public function getPath(): string {
        $path = parse_url($_SERVER['REQUEST_URI'] ?? '/', PHP_URL_PATH);
        return $path !== false ? $path : '/';
    }

    public function getQuery(string $key, mixed $default = null): mixed {
        return $_GET[$key] ?? $default;
    }

    public function getBody(string $key, mixed $default = null): mixed {
        return $_POST[$key] ?? $default;
    }
}
```

**`src/Core/Router.php`:**

```php
<?php
// File: src/Core/Router.php
declare(strict_types=1);

namespace App\Core;

use App\Exceptions\NotFoundException;

class Router {
    private array $routes = [];

    public function get(string $path, string $handler): void    { $this->add('GET', $path, $handler); }
    public function post(string $path, string $handler): void   { $this->add('POST', $path, $handler); }
    public function put(string $path, string $handler): void    { $this->add('PUT', $path, $handler); $this->add('POST', $path, $handler); }
    public function delete(string $path, string $handler): void { $this->add('DELETE', $path, $handler); $this->add('POST', $path, $handler); }

    private function add(string $method, string $path, string $handler): void {
        // Ubah {id} → named group regex, contoh: /buku/{id} → @^/buku/(?P<id>[^/]+)$@
        $pattern = preg_replace('/\{([a-z_]+)\}/', '(?P<$1>[^/]+)', $path);
        $this->routes[] = [
            'method'  => $method,
            'pattern' => "@^{$pattern}$@",
            'handler' => $handler,
        ];
    }

    public function dispatch(Request $request): void {
        $method = $request->getMethod();
        $path   = $request->getPath();

        foreach ($this->routes as $route) {
            if ($route['method'] !== $method) continue;

            if (preg_match($route['pattern'], $path, $matches)) {
                // Ambil named captures (parameter)
                $params = array_filter($matches, fn($k) => !is_int($k), ARRAY_FILTER_USE_KEY);

                [$controllerName, $action] = explode('@', $route['handler']);
                $controllerClass = "App\\Controllers\\{$controllerName}";

                if (!class_exists($controllerClass)) {
                    throw new \RuntimeException("Controller {$controllerClass} tidak ditemukan.");
                }

                $controller = new $controllerClass();
                if (!method_exists($controller, $action)) {
                    throw new \RuntimeException("Method {$action} tidak ada di {$controllerClass}.");
                }

                $controller->$action($request, $params);
                return;
            }
        }

        throw new NotFoundException("Rute tidak ditemukan: {$method} {$path}");
    }
}
```

**`public/index.php` — front controller:**

```php
<?php
// File: public/index.php
declare(strict_types=1);

define('ROOT_PATH', dirname(__DIR__));

require ROOT_PATH . '/vendor/autoload.php';

$dotenv = Dotenv\Dotenv::createImmutable(ROOT_PATH);
$dotenv->safeLoad();

if (($_ENV['APP_ENV'] ?? 'development') === 'production') {
    error_reporting(0);
    ini_set('display_errors', '0');
} else {
    error_reporting(E_ALL);
    ini_set('display_errors', '1');
}

use App\Core\Router;
use App\Core\Request;

$router = new Router();

// ─── Definisi rute ───
$router->get('/', 'HomeController@index');

$router->get('/buku', 'BukuController@index');
$router->get('/buku/tambah', 'BukuController@create');
$router->post('/buku', 'BukuController@store');
$router->get('/buku/{id}', 'BukuController@show');
$router->get('/buku/{id}/edit', 'BukuController@edit');
$router->put('/buku/{id}', 'BukuController@update');
$router->delete('/buku/{id}', 'BukuController@destroy');

$router->get('/login', 'AuthController@showLogin');
$router->post('/login', 'AuthController@login');

// ─── Dispatch ───
try {
    $router->dispatch(new Request());
} catch (\App\Exceptions\NotFoundException $e) {
    http_response_code(404);
    include ROOT_PATH . '/src/Views/errors/404.php';
} catch (\App\Exceptions\ForbiddenException $e) {
    http_response_code(403);
    include ROOT_PATH . '/src/Views/errors/403.php';
} catch (\Throwable $e) {
    error_log($e->getMessage() . "\n" . $e->getTraceAsString());
    http_response_code(500);
    if (($_ENV['APP_ENV'] ?? 'development') !== 'production') {
        throw $e;
    }
    include ROOT_PATH . '/src/Views/errors/500.php';
}
```

**`src/Controllers/BukuController.php` (controller tipis):**

```php
<?php
// File: src/Controllers/BukuController.php
declare(strict_types=1);

namespace App\Controllers;

use App\Core\Request;
use App\Repositories\BukuRepository;
use App\Core\View;

class BukuController {
    public function __construct(private BukuRepository $bukuRepo = new BukuRepository()) {}

    public function show(Request $request, array $params): void {
        $id   = (int) ($params['id'] ?? 0);
        $buku = $this->bukuRepo->findById($id);

        if ($buku === null) {
            http_response_code(404);
            View::render('errors/404', ['pesan' => 'Buku tidak ditemukan']);
            return;
        }

        View::render('buku/show', ['buku' => $buku]);
    }
}
```

> **Catatan**: `new BukuRepository()` sebagai default di property promotion adalah contoh sederhana; di arsitektur besar kamu akan menyuntikkan via Container/DI (materi pengembangan).

**`src/Core/View.php` (rendering template sederhana):**

```php
<?php
// File: src/Core/View.php
declare(strict_types=1);

namespace App\Core;

class View {
    public static function render(string $template, array $data = []): void {
        extract($data, EXTR_SKIP);   // $buku dsb. tersedia di template
        require ROOT_PATH . "/src/Views/{$template}.php";
    }
}
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**:

- **Front controller** = **pintu masuk tunggal** kantor + meja resepsionis. Semua tamu (request) masuk lewat pintu yang sama, dicek sekali (auth, headers), lalu diarahkan ke ruang yang sesuai.
- **Router** = **petugas penunjuk jalan**: membaca papan "saya mau ke `/buku/5`" dan menunjuk ke ruang `BukuController@show` dengan data `id=5`. Tidak ada dua pintu yang membingungkan.
- **Rute (`{id}`)** = petunjuk bernomor: "ruang buku dengan label nomor 5".
- **URL rewriting** = *papan nama depan*: alamat `/buku/5` dipasang sehingga semua pengunjung otomatis diarahkan ke pintu utama (front controller) — seolah-olah ada ruangan di depan, padahal proses lewat satu pintu.
- **Controller tipis** = *staf penghubung* yang hanya memanggil unit (repository, view) — dia tidak menulis surat sendiri dan tidak membuka lemari arsip secara langsung; semuanya diatur dari tempatnya.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Aplikasi dengan > 2-3 halaman** yang butuh konsistensi middleware (auth, headers) → front controller + router.
- **URL yang perlu "bersih"** (`/buku/5` vs `/buku.php?id=5`).
- **API (materi 27)** — satu router, endpoint JSON dengan method GET/POST/PUT/DELETE.
- **Middleware (level lanjutan)** — `AuthMiddleware`, `CsrfMiddleware` dipasang per-group rute (misal semua `/buku/{id}/edit` butuh admin) — di front controller, bukan di controller.
- **Kapan tidak perlu:** aplikasi kecil/tutorial — tapi pola ini adalah *gateway* menuju framework; begitu rutin dipakai, pindah ke router produksi (FastRoute/Symfony Routing) juga mudah.

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **Whitelist nama controller & action** — jangan pernah membangun controller class dari input user mentah (`$_GET['controller']`); mapping hanya dari daftar rute (seperti di `Router`).
- **Cast parameter dari route** — `{id}` dari URL adalah string; cast `(int)` sebelum dipakai (materi 6/21).
- **Method mutasi hanya POST/PUT/DELETE** — jangan hapus/ubah data lewat GET (CSRF & cache). Router `put`/`delete` juga mendaftarkan POST (method spoofing) — tapi tetap jangan GET.
- **Front controller = satu tempat security headers** — pasang `setSecurityHeaders()` (materi 22) sebelum dispatch, sekali untuk semua halaman.
- **Error handling terpusat** — jangan `die()` di controller; lempar exception → ditangkap front controller (404/403/500 yang konsisten, tanpa detail di production).
- **`index.php` sesedikit mungkin logika** — define env & bootstrap, lalu delegasi; jangan taruh logika bisnis di sini.

---

## 7. Kesalahan Umum & Debugging

- **`404` terus padahal rute ada** — urutan rute: `/buku/{id}` harus *setelah* `/buku/tambah` (regex `/buku/{id}` juga mencocokkan `tambah`!). Letakkan rute yang lebih spesifik dulu.
- **`.htaccess` tidak berfungsi (Apache)** — `mod_rewrite` belum aktif / `AllowOverride All` belum di-set. Aktifkan di `httpd.conf` virtual host.
- **`RewriteRule` di Nginx** — nginx tidak memakai `.htaccess`; gunakan `try_files $uri $uri/ /index.php?$query_string;` (materi 30).
- **Class controller tidak ditemukan** — namespace salah / autoload belum dump (materi 25); pastikan `namespace App\Controllers;` dan `composer dump-autoload`.
- **`{id}` regex rakus** — `/buku/{id}` cocok `tambah`; batasi dengan type pattern atau urutan rute. Bisa juga `{id:\d+}`.
- **`headers already sent`** — output sebelum `header()`/dispatch; pastikan semua `echo` di view, bukan di controller/bootstrap.
- **Debug**: aktifkan `APP_ENV=development` → lihat exception langsung; atau cek `.htaccess`/`try_files`. Gunakan `var_dump($request->getPath())` untuk melihat path yang benar-benar tiba.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Perluas router: tambahkan rute group `/api` yang **tanpa auth web** tapi **memakai token** (nanti di 27), dan rute `/buku/{id}/edit` dengan metode GET yang **hanya admin** (gunakan `requireRole`). Letakkan rute yang lebih spesifik lebih dulu. Verifikasi bahwa `/buku/tambah` tidak tertangkap `/buku/{id}`.

### Tantangan 2
Jelaskan alur lengkap saat browser meminta `GET /buku/5` pada aplikasi MVC ini — mulai dari request sampai halaman tampil. Sebutkan file-file yang terlibat.

### Jawaban & Pembahasan

**Tantangan 1** — Urutan rute yang benar (spesifik dulu):

```php
// Spesifik lebih dulu:
$router->get('/buku/tambah', 'BukuController@create');        // sebelum /buku/{id}
$router->get('/buku/{id}/edit', 'BukuController@edit');        // (pola lebih panjang, aman)
$router->get('/buku/{id}', 'BukuController@show');

// Group API (dalam project besar: mount + middleware token)
$router->get('/api/buku', 'Api\\BukuApiController@index');
$router->get('/api/buku/{id}', 'Api\\BukuApiController@show');
```

Untuk proteksi edit-admin, di `BukuController@edit` panggil `requireRole('admin')` (materi 16) atau (lebih bersih) pasang middleware di front controller untuk group `/buku/{id}/edit`. Karena `/buku/tambah` terdaftar *sebelum* `/buku/{id}`, saat path `/buku/tambah` diminta, router mencocokkan pola `/buku/tambah` terlebih dahulu dan berhenti di sana — `/buku/{id}` tidak pernah tercapai.

> **Pembahasan:** Order routing adalah gotcha paling umum; menaruh pola spesifik di depan pola `{param}` adalah aturan standar di semua framework.

**Tantangan 2** — Alur `GET /buku/5`:

1. Browser kirim `GET /buku/5` → Apache/Nginx.
2. `.htaccess` (`!-f !-d`) → semua request non-file diarahkan ke `public/index.php` (front controller).
3. `index.php`: load `vendor/autoload.php`, muat `.env`, set error mode (dev/prod).
4. Buat `Request` (method `GET`, path `/buku/5`), daftarkan rute di `Router`, panggil `dispatch($request)`.
5. Router iterasi rute; cocok pola `@^/buku/(?P<id>[^/]+)$@` → controller `App\Controllers\BukuController`, action `show`, param `['id' => '5']`.
6. `BukuController->show($request, ['id' => '5'])` → `(int) 5` → `BukuRepository->findById(5)` (PDO prepared) → dapat array/data buku.
7. `View::render('buku/show', ['buku' => ...])` → template `src/Views/buku/show.php` menghasilkan HTML.
8. HTML dikirim sebagai respons ke browser.

File yang terlibat: `public/index.php`, `.htaccess`, `src/Core/Router.php`, `src/Core/Request.php`, `src/Controllers/BukuController.php`, `src/Repositories/BukuRepository.php`, `src/Views/buku/show.php`, `src/Database/Connection.php`, `vendor/autoload.php`.

> **Pembahasan:** Ini "satu pintu" yang menyatukan seluruh roadmap: dari request browser sampai hasil HTML, semua jalur bisa diikuti — dan middleware/error handling hidup di front controller (titik 3-4) sehingga tidak terduplikasi di halaman.
