# 12. Fungsi — Definisi, Parameter, Return, Type Hints

> **Level 2 · String, Array, dan Fungsi** — Penutup Level 2: kode yang bisa dipanggil ulang dan diuji.

---

## 1. Penjelasan Singkat & Konsep Dasar

**Fungsi** adalah blok kode bernama yang bisa dipanggil kapan pun, menerima input (parameter), dan mengembalikan output (return). Prinsipnya: *tulis sekali, pakai berkali-kali* — inilah implementasi paling mendasar dari **DRY** (Don't Repeat Yourself).

```php
function hitungDenda(int $hariTerlambat, int $dendaPerHari = 1000): int {
    if ($hariTerlambat < 0) {
        throw new InvalidArgumentException('Hari terlambat tidak boleh negatif');
    }
    return $hariTerlambat * $dendaPerHari;
}
```

Fitur penting PHP 8:

| Fitur | Contoh |
|---|---|
| **Type hints** | `function f(int $a): string` — parameter & return dijamin tipenya |
| **Default value** | `int $dendaPerHari = 1000` |
| **Nullable** | `?array` — boleh `null` |
| **Union type** | `int\|string` |
| **Named arguments** | `hitungDenda(hariTerlambat: 5, dendaPerHari: 2000)` |
| **Variadic** | `function gabungkan(string $sep, string ...$tags)` |
| **Closure / Arrow fn** | `fn($x) => $x * 2` (PHP 7.4+) |
| **Strict types** | `declare(strict_types=1);` di atas file |

**Benang Merah:** materi 9-11 memakai callback (`array_filter`, `usort`) yang *berupa fungsi*. Sekarang kamu membuat fungsi sendiri secara penuh: dengan type hints, default, named args, closure. Fungsi-fungsi ini akan menjadi *method* di dalam class (materi 18-19) dan di-refactor menjadi Repository (materi 21).

## 2. Fungsi & Kegunaan Utama

- **Reusability** — `formatHarga()` dipakai di katalog, detail, keranjang. Ubah format sekali, semua ter-update.
- **Mengurangi duplikasi & bug** — logika kompleks (hitung denda, validasi, cari buku) ditulis sekali, diuji sekali.
- **Keterbacaan** — nama fungsi seperti kalimat: `cariBuku($katalog, 'clean')` terbaca langsung maksudnya.
- **Isolasi** — variabel di dalam fungsi *tidak bocor* ke luar; ini awal dari konsep *scope* yang juga berlaku di OOP.
- **Type hints sebagai kontrak** — PHP memvalidasi tipe parameter & return; salah tipe → `TypeError` yang jelas, bukan bug diam-diam.

## 3. Contoh Kode & Implementasi Real-World

`functions/perhitungan.php` — library fungsi dengan type hints penuh:

```php
<?php
// File: functions/perhitungan.php
declare(strict_types=1);

/**
 * Hitung denda keterlambatan peminjaman.
 * @throws InvalidArgumentException jika argumen tidak valid
 */
function hitungDenda(int $hariTerlambat, int $dendaPerHari = 1000): int {
    if ($hariTerlambat < 0) {
        throw new InvalidArgumentException('Hari terlambat tidak boleh negatif');
    }
    return $hariTerlambat * $dendaPerHari;
}

/**
 * Ambil statistik katalog: total, tersedia, habis, rata-rata harga.
 */
function statistikKatalog(array $katalog): array {
    $tersedia = array_filter($katalog, fn($b) => $b['stok'] > 0);
    $habis    = array_filter($katalog, fn($b) => $b['stok'] === 0);

    $rerata = count($katalog) > 0
        ? array_sum(array_column($katalog, 'harga')) / count($katalog)
        : 0;

    return [
        'total'    => count($katalog),
        'tersedia' => count($tersedia),
        'habis'    => count($habis),
        'rerata_harga' => $rerata,
    ];
}

/**
 * Cari buku by id; return null jika tidak ditemukan.
 */
function cariBukuById(array $katalog, int $id): ?array {
    foreach ($katalog as $buku) {
        if ($buku['id'] === $id) return $buku;
    }
    return null;
}
```

`index.php` — penggunaan nyata:

```php
<?php
require_once 'data/katalog.php';
require_once 'functions/perhitungan.php';

$stats = statistikKatalog($katalog);
$buku  = cariBukuById($katalog, 2);

echo "Total buku: {$stats['total']}, tersedia: {$stats['tersedia']}, habis: {$stats['habis']}<br>";
echo "Rata-rata harga: " . formatHarga((int) round($stats['rerata_harga']));

if ($buku !== null) {
    echo "Buku ditemukan: {$buku['judul']}";
}
```

**Fitur lanjutan yang sangat berguna:**

```php
// Named arguments (PHP 8) — baca & aman dari urutan
echo hitungDenda(dendaPerHari: 2000, hariTerlambat: 5); // 10000

// Union type — terima int ATAU string
function prosesId(int|string $id): string {
    return is_int($id) ? sprintf("ID-%05d", $id) : strtoupper(trim($id));
}

// Variadic — parameter bebas
function gabungkanTag(string $separator, string ...$tags): string {
    return implode($separator, $tags);
}
echo gabungkanTag(', ', 'PHP', 'MySQL', 'HTML'); // PHP, MySQL, HTML

// Closure + arrow function
$formatHarga = fn(int $harga): string => 'Rp ' . number_format($harga, 0, ',', '.');
echo $formatHarga(150000); // Rp 150.000

// Closure dengan use (untuk callback yang butuh variabel luar)
$batas = 200000;
$terjangkau = array_filter($katalog, function ($buku) use ($batas) {
    return $buku['harga'] <= $batas;
});
// Arrow function otomatis menangkap variabel luar — lebih ringkas:
$terjangkau = array_filter($katalog, fn($b) => $b['harga'] <= $batas);
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**:

- **Fungsi** = **prosedur/instruksi kerja standar (SOP)**. Ada SOP "hitung denda", "cari buku", "format harga" — siapa pun stafnya cukup membuka SOP itu, mengisi parameternya, dan menerima hasilnya. Tidak perlu menulis ulang langkah-langkahnya di setiap meja.
- **Parameter** = *isi formulir* yang kamu serahkan ke SOP (berapa hari terlambat, berapa denda per hari).
- **Return** = *hasil surat jawaban* dari SOP.
- **Type hints** = SOP menolak formulir yang salah tipe — "kolom ini harus angka, beri saya angka!".
- **Default value** = SOP punya nilai bawaan ("kalau tidak ditulis, denda per hari = 1000").
- **Scope** = staf bekerja di meja masing-masing; catatan di meja A tidak mengganggu meja B. Variabel dalam fungsi privat bagi dunia luar.

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Segala logika yang dipakai > 1 kali** → fungsikan. Katalog, denda, validasi, format — semua jadi fungsi.
- **Pemisahan *logika* dari *tampilan*** — fungsi di `functions/`, dipanggil dari halaman. Ini anti-spaghetti.
- **Callback untuk array functions** — `array_filter`/`array_map`/`usort` selalu butuh fungsi (closure/arrow).
- **Kapan memakai `declare(strict_types=1);`** — di semua file aplikasi modern. Efek: PHP *menolak* mengubah tipe argument diam-diam (juggling materi 6 tidak berlaku di sini) — misal `hitungDenda("5")` akan `TypeError`, bukan otomatis int. Lebih aman, sedikit lebih ketat.
- **Kasus nyata:** fungsi `cariBukuById` akan menjadi *method* `findById` di class `BukuRepository` (materi 21) — pola yang sama, hanya dibungkus class.

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **Validasi di dalam fungsi** — jangan biarkan fungsi "memercayai" pemanggilnya. `hitungDenda(-1)` harus *error* (throw), bukan hasil negatif aneh. Ini menjaga invariant data.
- **Jangan pernah menggabungkan string SQL / output HTML dengan input user di dalam fungsi** — itu tugas *sanitasi & prepared statement* (materi 14, 21). Fungsi harus tetap bersih.
- **Best practices:**
  - Selalu **type hints** untuk parameter & return (PHP 8 style — wajib roadmap).
  - `declare(strict_types=1)` di atas tiap file.
  - Satu fungsi = satu tanggung jawab (Single Responsibility, pendahulu OOP).
  - Nama fungsi deskriptif: `cariBukuById`, bukan `find()`, `getb()`, `x()`.
  - Jangan mengubah parameter input (immutable) — kalau butuh versi baru, return array baru.
  - Simpan fungsi terkait dalam satu file (helpers) dan `require_once` sekali.

## 7. Kesalahan Umum & Debugging

- **`Call to undefined function` (Fatal)** — file belum di-`require`, salah nama, atau salah path. Debug: cek `require_once` & penulisan nama.
- **`TypeError: Argument #1 ($x) must be of type int, string given`** — PHP 8 menolak `hitungDenda("5")` (apalagi dengan `strict_types`). Solusi: cast di pemanggil (`(int)`), atau perbaiki sumber datanya.
- **Variabel tidak terlihat di dalam fungsi** — *scope*: variabel luar tidak otomatis masuk. Butuh `use ($var)` (closure) atau parameter. Ini sumber kebingungan #1 pemula.
- **`undefined variable` di dalam closure** — lupa `use`, padahal closure tidak menangkap otomatis seperti arrow function.
- **Return yang tertelan** — fungsi `echo` isi sendiri (bukan return) membuat hasil tak bisa dipakai ulang. Aturan: **return, bukan echo**, di dalam fungsi utilitas.
- **Nama fungsi bentrok** — dua library mendefinisikan `formatHarga` → *Cannot redeclare function* (Fatal). Solusi: prefix namespace (misal `Perpus\formatHarga`) — akan dibahas di autoloading (materi 25).
- **`require` vs `require_once`** — `require` file yang sama dua kali → *Cannot redeclare function*. Selalu `require_once` untuk fungsi/class.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Buat library `functions/peminjaman.php` berisi:
- `hitungBatasKembali(string $tglPinjam, int $hari = 14): string` — kembalikan tanggal batas (format `Y-m-d`), validasi format input.
- `hitungDendaSekarang(int $hariTerlambat): int` — pakai `DENDA_PER_HARI` dari konstanta (materi 7).
- `statusPeminjaman(array $pinjam): string` — return `'dipinjam' | 'dikembalikan' | 'terlambat'` dengan pengecekan tanggal.

### Tantangan 2
Jelaskan perbedaan hasil kedua blok ini:

```php
$a = fn($x) => $x * 2;
echo $a(5);                       // ?

$b = function ($x) use ($kali) { return $x * $kali; };
echo $b(5);                       // jika $kali = 3 → ?
```

Lalu, apa yang terjadi jika `$kali` diubah setelah closure `$b` didefinisikan, dan apakah arrow function `$a` bisa membaca `$kali` di dalam dirinya?

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
// functions/peminjaman.php
declare(strict_types=1);

function hitungBatasKembali(string $tglPinjam, int $hari = 14): string {
    $d = DateTimeImmutable::createFromFormat('Y-m-d', $tglPinjam);
    if ($d === false) {
        throw new InvalidArgumentException("Format tanggal harus Y-m-d");
    }
    return $d->modify("+{$hari} days")->format('Y-m-d');
}

function hitungDendaSekarang(int $hariTerlambat): int {
    return hitungDenda($hariTerlambat, DENDA_PER_HARI);
}

function statusPeminjaman(array $pinjam): string {
    $batas = new DateTimeImmutable($pinjam['batas_kembali']);
    $sekarang = new DateTimeImmutable('today');

    if (!empty($pinjam['tanggal_kembali'])) {
        return 'dikembalikan';
    }
    return $sekarang > $batas ? 'terlambat' : 'dipinjam';
}

echo hitungBatasKembali('2026-08-01');        // 2026-08-15
echo statusPeminjaman(['batas_kembali' => '2026-08-10']); // tergantung tanggal hari ini
```

> **Pembahasan alur:** `hitungBatasKembali` menggunakan `DateTimeImmutable` (tidak bisa diubah in-place → aman untuk chain) dan **memvalidasi format** sebelum `modify` — prinsip "fungsi tidak percaya pemanggil". `hitungDendaSekarang` me-reuse fungsi sebelumnya (DRY). `statusPeminjaman` menentukan status lewat perbandingan tanggal, `!empty` untuk tanggal kembali.

**Tantangan 2**

- `$a(5)` → `10` — arrow function `fn($x) => $x * 2` mengalikan langsung.
- `$b(5)` → `15` jika `$kali = 3` — closure menangkap `$kali` melalui `use` saat didefinisikan.

Perbedaan kunci:
- **Arrow function menangkap variabel luar *otomatis* dan *by-value*** — tapi dia membaca nilai pada *saat pemanggilan*? Tidak: arrow function menangkap by-value saat dibuat. Sedangkan closure `use ($kali)` juga by-value, menangkap nilai `$kali` **pada saat closure dibuat**. Jika `$kali` diubah *setelah* definisi, nilai di dalam closure **tidak berubah** (karena by-value; jika ingin by-reference, gunakan `use (&$kali)`).
- `$a` **tidak bisa membaca `$kali`** untuk dipakai di dalamnya — arrow function hanya otomatis menangkap variabel yang muncul di *body*-nya. Karena `$a` tidak memakai `$kali`, ia tidak menangkap apa pun.

```php
$kali = 3;
$b = fn() => $kali * 2;   // arrow function MENANGKAP $kali (karena dipakai)
echo $b();                // 6
```

> **Pembahasan:** Pemahaman *waktu penangkapan* (capture by-value) ini sering membingungkan. Kalau kamu butuh nilai terbaru setiap pemanggilan, gunakan parameter (`fn($x, $kali) => $x * $kali`) atau by-reference `use (&$kali)`.
