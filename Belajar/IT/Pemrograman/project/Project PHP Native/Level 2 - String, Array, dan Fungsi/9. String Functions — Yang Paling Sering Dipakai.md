# 9. String Functions — Yang Paling Sering Dipakai

> **Level 2 · String, Array, dan Fungsi** — Level 1 menyimpan teks dalam variabel; sekarang kita *mengolah* teks itu.

---

## 1. Penjelasan Singkat & Konsep Dasar

Hampir semua data yang masuk ke aplikasi web — nama, judul buku, ISBN, email, pencarian — adalah **string**. Karena itu, menguasai fungsi string = menguasai 40% pekerjaan harian PHP.

PHP menyediakan **ratusan fungsi string** bawaan. Kamu tidak perlu hafal semuanya; yang penting memahami *kategori* dan fungsi inti:

| Kategori | Fungsi kunci |
|---|---|
| Pembersihan | `trim`, `ltrim`, `rtrim` |
| Perubahan huruf | `strtolower`, `strtoupper`, `ucfirst`, `ucwords` |
| Pencarian | `strpos`, `strrpos`, `str_contains`, `str_starts_with`, `str_ends_with` (PHP 8) |
| Penggantian | `str_replace`, `preg_replace` |
| Pemotongan/gabung | `substr`, `explode`, `implode` |
| Ukuran | `strlen`, `mb_strlen` (multi-byte) |
| Format | `number_format`, `sprintf` |

**Benang Merah:** Di Level 1, string adalah "wadah data pasif" (`$nama = "Perpustakaan"`). Sekarang string menjadi *bahan kerja*: dibersihkan dari whitespace, dicari kata kuncinya, dipotong, digabung, diformat. Ini adalah jembatan menuju array (materi 10) — karena `explode`/`implode` adalah gerbang antara string dan array.

---

## 2. Fungsi & Kegunaan Utama

Mengapa fitur ini ada? Karena **input dari user tidak pernah rapi**:

- User mengetik `"  Clean Code  "` (spasi berlebih) → butuh `trim()`.
- User mencari dengan huruf campur `"cLeAn"` → butuh `strtolower()` agar bisa dibandingkan case-insensitive.
- ISBN datang sebagai `"978-0-13-235088-4"` → butuh `str_replace`/`preg_replace` untuk normalisasi.
- Data ditampilkan ke user → butuh `number_format`, `htmlspecialchars`.

Tiga fungsi PHP 8 yang *wajib* kamu gunakan menggantikan pola lama `strpos(...) !== false`:

```php
$adaKata   = str_contains("Clean Code", "Code");      // true
$mulaiDengan = str_starts_with("Clean Code", "Clean"); // true
$akhirDengan = str_ends_with("Clean Code", "Code");    // true
```

> `strpos()` masih valid untuk mencari *posisi*, tapi untuk sekadar "apakah ada/tidak", fungsi `str_*` di atas jauh lebih mudah dibaca.

## 3. Contoh Kode & Implementasi Real-World

`functions/helpers.php` — mulai mengumpulkan fungsi reusable (awal dari DRY & library):

```php
<?php
// File: functions/helpers.php

/**
 * Format harga ke format Rupiah Indonesia.
 */
function formatHarga(int $harga): string {
    return 'Rp ' . number_format($harga, 0, ',', '.');
}

/**
 * Normalisasi ISBN: hapus semua non-digit, lalu format standar.
 */
function formatISBN(string $isbn): string {
    $digits = preg_replace('/[^0-9]/', '', $isbn);
    if (strlen($digits) === 13) {
        return substr($digits, 0, 3) . '-' .
               substr($digits, 3, 1) . '-' .
               substr($digits, 4, 2) . '-' .
               substr($digits, 6, 6) . '-' .
               substr($digits, 12, 1);
    }
    return $isbn;
}

/**
 * Slice teks panjang untuk preview di halaman daftar.
 */
function ringkas(string $teks, int $panjang = 100): string {
    $teks = trim($teks);
    if (mb_strlen($teks) <= $panjang) return $teks;
    return mb_substr($teks, 0, $panjang) . '…';
}
```

`katalog.php` — pemakaian nyata pada pencarian:

```php
<?php
require_once 'functions/helpers.php';

function cariDiJudul(string $judul, string $keyword): bool {
    $judul   = strtolower(trim($judul));
    $keyword = strtolower(trim($keyword));
    return str_contains($judul, $keyword);   // case-insensitive
}

$keyword = 'clean';
var_dump(cariDiJudul('Clean Code', $keyword));       // true
var_dump(cariDiJudul('Laskar Pelangi', $keyword));   // false
```

**Snippet fungsi string lainnya yang sering dipakai:**

```php
$judul  = "  Clean Code  ";
$isbn   = "978-0-13-235088-4";

echo trim($judul);                       // Clean Code
echo strtoupper("clean code");           // CLEAN CODE
echo ucwords("clean code book");         // Clean Code Book

echo str_replace(["-", " "], "", $isbn); // 9780132350884
echo preg_replace('/[^0-9]/', '', $isbn); // 9780132350884

// explode → array, implode → string
$parts = explode("-", $isbn);            // ["978","0","13","235088","4"]
echo implode(" ", $parts);               // 978 0 13 235088 4

echo mb_strlen("Buku Bäru");             // 10 (multi-byte safe!)
echo number_format(4.567, 2, ',', '.');  // 4,57

// sprintf — format konsisten untuk laporan
echo sprintf("%-20s | Rp %10s", "Clean Code", "150.000");
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**, string adalah **surat/dokumen**, dan fungsi string adalah **staf yang menangani dokumen**:

- **`trim`** = staf merapikan kertas yang penuh spasi di tepinya sebelum diarsipkan.
- **`strtolower`** = menormalkan semua huruf jadi kecil agar pencarian mudah (sama-sama pakai huruf kecil untuk membandingkan).
- **`str_contains`** = staf memeriksa "apakah kata 'Code' ada di dalam dokumen ini?"
- **`str_replace`** = staf mengganti semua tanda hubung dengan kosong di kolom ISBN.
- **`explode`** = staf *memisah* satu kalimat menjadi kata-kata; **`implode`** = staf *menjajarkan* kata-kata jadi satu kalimat.
- **`number_format`** = staf menulis angka 1500000 menjadi "1.500.000" agar mudah dibaca manusia.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Sebelum menyimpan & membandingkan data teks**: selalu `trim()` + `strtolower()` (misal email, nama). Ini praktik normalisasi data yang akan sangat membantu saat validasi (materi 14).
- **Pencarian & filter**: `str_contains` untuk kata kunci; `str_starts_with` untuk awalan (misal autocomplete nomor anggota).
- **Sanitasi karakter**: `str_replace`/`preg_replace` untuk menghapus karakter berbahaya atau format tidak seragam.
- **Tampilan**: `number_format` untuk harga, `mb_substr` untuk preview, `sprintf` untuk laporan sejajar kolom.
- **Parsing data**: `explode` untuk memecah CSV/query string, `implode` untuk menyusun koma-separated list dari array.

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **Gunakan `mb_*` untuk teks multi-byte** — `strlen`, `substr` bekerja per-byte; untuk teks UTF-8 (judul buku bahasa Indonesia/dengan aksen, emoji) bisa salah potong. Selalu `mb_strlen`, `mb_substr` untuk data berpotensi non-ASCII.
- **Jangan gunakan string function untuk *mencegah* XSS/SQLi** — membersihkan input dengan `str_replace` **tidak cukup** dan sering salah. Perlindungan yang benar: `htmlspecialchars()` pada *output*, dan prepared statement pada *query* (Level 3-5). `preg_replace` untuk "sanitasi" input hanya sebagai lapisan tambahan, bukan pengganti.
- **Best practices:**
  - Normalisasi (trim + lowercase) di *satu* tempat (helper), bukan tersebar.
  - Gunakan fungsi PHP 8 `str_contains`/`str_starts_with`/`str_ends_with` daripada `strpos() !== false`.
  - Nama fungsi helper deskriptif & reusable (`formatHarga`, `ringkas`) — DRY.
  - Dokumentasi fungsi dengan docblock singkat.

---

## 7. Kesalahan Umum & Debugging

- **`strpos` return `0` untuk posisi pertama** → `strpos("Clean Code", "Clean")` menghasilkan `0` (int), dan `0 == false` bernilai `true` jika memakai `==`! Inilah bug klasik. Solusi: gunakan `str_contains`, atau tulis `strpos(...) !== false`.
- **`Undefined array key` setelah `explode`** — `explode` bisa menghasilkan array lebih pendek dari yang diduga (input tanpa delimiter). Solusi: cek `count()` atau gunakan `?? ''`.
- **`mb_substr` tidak ada** — ekstensi `mbstring` belum aktif. Aktifkan di `php.ini` (materi 2, `php -m`).
- **Case yang "tidak ketemu"** — pencarian gagal karena perbedaan huruf besar/kecil; normalisasi `strtolower` di kedua sisi sebelum `str_contains`.
- **UTF-8 rusak** — `strlen`/`substr` memotong di tengah byte multi-byte → karakter jadi `�`. Solusi: `mb_strlen`/`mb_substr`, dan pastikan koneksi DB `utf8mb4` (materi 20).
- **`trim` tidak menghapus karakter yang diinginkan** — `trim` default hanya whitespace (` `, `\t`, `\n`, `\r`). Untuk menghapus karakter lain (misal `"."` atau `"0"`), kirimkan *character mask*: `trim("...abc...", '.')`.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Buat fungsi `normalizeJudul(string $judul): string` yang: menghapus whitespace berlebih di awal/akhir, mengubah jadi huruf kecil, menghapus tanda baca ganda (`.`, `,`) dan mengganti *multiple spaces* menjadi satu spasi. Lalu fungsi `isJudulMatch(string $judul, string $keyword): bool` yang mengecek kecocokan case-insensitive memakai `str_contains`.

### Tantangan 2
Apa output & jelaskan kenapa:

```php
$teks = "ABCDEF";
echo strpos($teks, "A") . "\n";      // ?
var_dump(strpos($teks, "A") == false); // ?
echo str_contains($teks, "A");       // ?
echo substr($teks, 2, 3);            // ?
echo mb_substr("Héllo", 0, 3);       // ?
```

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
function normalizeJudul(string $judul): string {
    $judul = trim($judul);
    $judul = strtolower($judul);
    $judul = str_replace(['.', ','], '', $judul);
    $judul = preg_replace('/\s+/', ' ', $judul);  // banyak spasi → satu spasi
    return $judul;
}

function isJudulMatch(string $judul, string $keyword): bool {
    return str_contains(normalizeJudul($judul), normalizeJudul($keyword));
}

var_dump(isJudulMatch("  Clean Code,  ", "clean code")); // true
var_dump(isJudulMatch("The Great Gatsby", "laskar"));     // false
```

> **Pembahasan alur:** Fungsi normalisasi menjadi *pintu tunggal* untuk semua pencarian — input apapun dibersihkan, di-lowercase, lalu dihapus tanda baca. `isJudulMatch` memanggil normalisasi di kedua sisi, sehingga `"Clean Code,"` cocok dengan `"clean code"`. Ini pola yang sama yang nanti kamu terapkan ke query `WHERE judul LIKE :keyword` di database (materi 21).

**Tantangan 2**

```php
echo strpos($teks, "A");               // int(0)  — posisi huruf A adalah 0
var_dump(strpos($teks, "A") == false); // bool(true) — BUG KLASIK!
echo str_contains($teks, "A");         // bool(true)
echo substr($teks, 2, 3);              // "CDE"
echo mb_substr("Héllo", 0, 3);         // "Hél"  (aman untuk multi-byte)
```

> **Pembahasan:** `strpos` mengembalikan `0` karena "A" berada di index 0 — dan `0 == false` bernilai `true` (loose comparison, materi 6). Ini persis bug "ketemu tapi dianggap tidak ketemu". `str_contains` mengembalikan boolean murni sehingga aman. `substr` dengan offset 2 dan panjang 3 mengambil 3 karakter dari posisi ke-2 ("CDE"). `mb_substr` menghitung karakter (bukan byte) sehingga "é" (2 byte) tetap dihitung satu karakter dan potongan aman.
