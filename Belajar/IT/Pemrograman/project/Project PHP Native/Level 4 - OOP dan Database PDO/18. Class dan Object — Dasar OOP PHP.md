# 18. Class dan Object — Dasar OOP PHP

> **Level 4 · OOP dan Database PDO** — Dari fungsi terpencar (Level 2-3) ke *paket* data + perilaku dalam satu unit.

---

## 1. Penjelasan Singkat & Konsep Dasar

**OOP (Object-Oriented Programming)** mengelompokkan dua hal yang secara alami berpasangan — **data** (property) dan **perilaku** (method) — dalam satu cetakan bernama **class**:

```php
class Buku {
    public string $judul;        // property = data
    public int $stok;

    public function tersedia(): bool {   // method = perilaku
        return $this->stok > 0;
    }
}

$buku1 = new Buku();             // object = instance dari class
$buku1->judul = 'Clean Code';
$buku1->stok  = 5;

echo $buku1->tersedia() ? 'Ada' : 'Habis';   // Ada
```

**Istilah inti:**

| Istilah | Arti |
|---|---|
| **Class** | cetakan/template (didefinisikan sekali) |
| **Object / instance** | hasil jadi dari class (`new Buku`) |
| **Property** | variabel milik object (`public string $judul`) |
| **Method** | fungsi milik object (`terda();` / `pinjam()`) |
| **`$this`** | referensi ke object yang sedang berjalan |
| **Constructor** | method `__construct()` — dijalankan saat `new` |
| **Encapsulation** | menyembunyikan data (`private`) — akses via method |

**Benang Merah:** materi 12 membuat *fungsi standalone*; OOP *membungkus* fungsi + variabel ke dalam class. `JsonStorage` (materi 17) sudah class — sekarang kita bangun model bisnis (Buku, User) dan nanti Repository DB (materi 21). Semua framework PHP modern adalah OOP — ini fondasinya.

---

## 2. Fungsi & Kegunaan Utama

- **Kohesi data + perilaku** — `$stok` dan method `pinjam()` ada di satu tempat; tidak mungkin memanggil `pinjam()` untuk object yang tidak punya stok.
- **Encapsulation** — property `private` + getter/setter: data tidak bisa dibikin tidak valid dari luar (misal stok negatif) — validasi hidup *di* class.
- **Reusability & abstraksi** — panggil `$buku->formatHarga()` tanpa tahu rumusnya; `new` banyak instance dari satu class.
- **Konsistensi & maintainability** — pertumbuhan project memakai pola yang sama (Model → Repository → Controller) yang nanti dipakai framework.
- **`readonly` property (PHP 8.1+)** — nilai hanya di-set sekali di constructor; aman karena immutable.

## 3. Contoh Kode & Implementasi Real-World

Struktur file Model (akan dipakai di MVC, materi 25):

```
perspustakaan/
└── src/
    └── Models/
        └── Buku.php
```

```php
<?php
// File: src/Models/Buku.php
declare(strict_types=1);

class Buku {
    // Property: readonly = hanya bisa di-set di constructor
    public readonly int $id;
    public string $judul;
    public string $pengarang;
    public ?string $isbn;
    public int $tahun;
    public float $harga;
    public string $kategori;
    public readonly \DateTimeImmutable $createdAt;

    // PRIVATE: tidak bisa diakses dari luar, hanya lewat method khusus
    private int $stok;

    public function __construct(
        string $judul,
        string $pengarang,
        int $tahun,
        float $harga,
        int $stok,
        string $kategori,
        ?string $isbn = null,
        int $id = 0,
    ) {
        // Validasi di constructor — "harga negatif" tidak pernah bisa lahir
        if ($harga < 0 || $stok < 0) {
            throw new \InvalidArgumentException('Harga dan stok tidak boleh negatif.');
        }
        $this->judul     = $judul;
        $this->pengarang = $pengarang;
        $this->isbn      = $isbn;
        $this->tahun     = $tahun;
        $this->harga     = $harga;
        $this->stok      = $stok;
        $this->kategori  = $kategori;
        $this->id        = $id;
        $this->createdAt = new \DateTimeImmutable();
    }

    // ─── Getter & Setter (jembatan ke property private) ───
    public function getStok(): int {
        return $this->stok;
    }

    public function setStok(int $stok): void {
        if ($stok < 0) {
            throw new \InvalidArgumentException('Stok tidak boleh negatif.');
        }
        $this->stok = $stok;
    }

    // ─── Method bisnis (perilaku) ───
    public function tersedia(): bool {
        return $this->stok > 0;
    }

    public function pinjam(): void {
        if (!$this->tersedia()) {
            throw new \RuntimeException("Buku '{$this->judul}' tidak tersedia.");
        }
        $this->stok--;
    }

    public function kembalikan(): void {
        $this->stok++;
    }

    public function formatHarga(): string {
        return 'Rp ' . number_format($this->harga, 0, ',', '.');
    }

    // ─── Factory: dari data array (hasil DB/JSON) jadi object ───
    public static function fromArray(array $data): self {
        return new self(
            judul:     $data['judul'],
            pengarang: $data['pengarang'],
            tahun:     (int) $data['tahun'],
            harga:     (float) $data['harga'],
            stok:      (int) $data['stok'],
            kategori:  $data['kategori'],
            isbn:      $data['isbn'] ?? null,
            id:        (int) ($data['id'] ?? 0),
        );
    }

    // ─── Reverse: object jadi array (untuk API/JSON) ───
    public function toArray(): array {
        return [
            'id'        => $this->id,
            'judul'     => $this->judul,
            'pengarang' => $this->pengarang,
            'isbn'      => $this->isbn,
            'tahun'     => $this->tahun,
            'harga'     => $this->harga,
            'stok'      => $this->getStok(),
            'kategori'  => $this->kategori,
        ];
    }
}
```

Pemakaian:

```php
require_once 'src/Models/Buku.php';

$buku = Buku::fromArray(['id' => 1, 'judul' => 'Clean Code', 'pengarang' => 'Robert Martin',
                         'tahun' => 2008, 'harga' => 150000, 'stok' => 5, 'kategori' => 'Teknologi']);

echo $buku->formatHarga();          // Rp 150.000
echo $buku->getStok();              // 5
$buku->pinjam();                    // stok → 4
echo $buku->tetapTersedia ? 'y' : 'n'; // (contoh salah tulis di sini tidak akan pernah valid)
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**:

- **Class `Buku`** = **template/cetakan formulir buku** yang dicetak di percetakan. Semua formulir punya kolom yang sama (judul, pengarang, stok) dan aturan yang sama (misal "stok tidak boleh negatif").
- **Object** = **satu lembar formulir yang sudah diisi** — `new Buku()` mencetak & mengisi lembar baru. Banyak lembar (object) dari satu template.
- **Constructor** = petugas *menerima lembar kosong dan mengisinya sekaligus* saat cetak — data wajib datang saat `new`.
- **`private $stok`** = angka stok ditulis **di bagian dalam arsip** — tidak semua orang bisa mencoret; perubahan hanya lewat prosedur resmi (`setStok`, `pinjam`).
- **Method `pinjam()`** = SOP "meminjam buku": periksa apakah ada, kurangi stok, laporkan error jika tidak ada. Tidak ada staf yang memotong angka stok seenaknya.
- **`$this`** = "formulir yang sedang saya kerjakan ini".
- **Instance method statik `fromArray()`** = layanan pembuat formulir dari data arsip lama.

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Model bisnis** — Buku, Anggota, Peminjaman: setiap entitas punya data + aturan sendiri.
- **Class yang menampung logika kompleks** — Validator (materi 14), JsonStorage (17), Repository (21).
- **Kapan pindah dari fungsi ke class:** ketika fungsi saling memakai state & validasi secara berkelompok, atau ketika kamu ingin *menjamin* data tidak pernah invalid.
- **Kasus nyata:** `Buku::fromArray($row)` dari hasil query PDO (fetch assoc) → seluruh bisnis logic jalan di object → `toArray()` untuk dikirim ke view/JSON. Inilah jembatan DB→model→tampilan.

---

## 6. Aspek Keamanan & Best Practices (Critical)

- **Validasi di constructor / setter** — kelas yang memvalidasi membunuh data invalid sejak lahir. Ini kekuatan Encapsulation untuk keamanan data (misal stok negatif atau harga minus tidak pernah masuk DB).
- **Jangan pernah menampilkan property sensitif lewat `__toString` / `toArray`** — simpan `passwordHash` sebagai private, jangan ekspos di `toArray()` (bocor ke API!). 
- **`readonly`** untuk nilai yang immutable (id, createdAt) — mencegah perubahan setelah pembuatan.
- **Best practices:**
  - **Satu class = satu tanggung jawab** (pola `Buku` tidak merangkap query DB — itu tugas `BukuRepository`) — pendahulu arsitektur MVC (materi 25).
  - Property private + getter/setter (atau readonly) — bukan public licin.
  - `declare(strict_types=1)` dan type hints di semua anggota.
  - Gunakan **named arguments** & promotion di constructor (PHP 8).
  - `fromArray`/`toArray` factory — jembatan rapi ke array/DB/JSON.

## 7. Kesalahan Umum & Debugging

- **`Uncaught Error: Call to a member function formatHarga() on null`** — memanggil method pada object yang `null` (biasanya hasil cari/temukan gagal). Cek `if ($buku !== null)` sebelum memanggil method — nanti dipakai di repository.
- **Property private diakses dari luar** → `Fatal error: Cannot access private property Buku::$stok`. Solusi: gunakan getter (`getStok()`).
- **`Fatal error: Class 'Buku' not found`** — file belum di-`require` (Level 4 manual; di Level 6 otomatis via Composer/autoload, materi 25).
- **Property tidak terdefinisi** — typo nama property (`$this->tahunn`) menghasilkan *dynamic property deprecated* (PHP 8.2) atau *undefined*. Solusi: deklarasi eksplisit semua property.
- **`readonly` di-set dua kali** → `Cannot modify readonly property`. Ingat: hanya sekali di constructor.
- **Clone vs referensi** — object PHP selalu *by-reference*; `$b = $a;` tidak menyalin. Untuk salinan, gunakan `clone` (`$b = clone $a;`). (Berbeda dengan array yang *copy-on-write* — sumber banyak bug "data berubah sendiri").
- **Constructor tidak dipanggil jika tidak ada `new`** — memanggil `Buku::fromArray()` (static) yang salah implement bisa membuat object tanpa validasi — perhatikan static methods hanya membangun lewat constructor resmi.

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Buat class `Anggota` dengan: property `readonly id`, `nama`, `email`, `role`; private `batasPinjam`; method `pinjamBuku(Buku $buku): bool` yang melempar `RuntimeException` jika jumlah pinjaman sudah mencapai batas, dan mencatat pinjaman; getter untuk jumlah pinjaman aktif.

### Tantangan 2
Apa yang salah dengan kode di bawah, dan bagaimana memperbaikinya?

```php
class Penjaga {
    public string $nama;
    private int $jumlahBuku = 0;
    public function tambah(): void { $this->jumlahBuku++; }
}

$p = new Penjaga('Andi');
$p->jumlahBuku = 5;         // ?
echo $p->jumlahBuku;        // ?
```

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
declare(strict_types=1);

class Anggota {
    public readonly int $id;
    private array $pinjaman = [];     // daftar Buku yang sedang dipinjam

    public function __construct(
        int $id,
        public string $nama,
        public string $email,
        public string $role = 'anggota',
        private int $batasPinjam = 5,
    ) {
        $this->id = $id;
    }

    public function pinjamBuku(Buku $buku): bool {
        if (count($this->pinjaman) >= $this->batasPinjam) {
            throw new \RuntimeException(
                "Batas pinjam ({$this->batasPinjam}) tercapai untuk {$this->nama}."
            );
        }
        $buku->pinjam();                    // delegasi ke object Buku
        $this->pinjaman[] = $buku;
        return true;
    }

    public function jumlahPinjaman(): int {
        return count($this->pinjaman);
    }

    public function getBatasPinjam(): int {
        return $this->batasPinjam;
    }
}
```

> **Pembahasan alur:** Property promotion (`public string $nama`, `private int $batasPinjam`) membuat constructor ringkas. `pinjamBuku()` memeriksa batas, lalu mendelegasikan pengurangan stok ke method `pinjam()` milik `Buku` — object bekerja sama, tidak saling merogoh state. Invariant (batas) dijaga di kelas (encapsulation) — tidak bisa dijebol dari luar.

**Tantangan 2** — Dua masalah:
1. Constructor `Penjaga` menerima `$nama` tapi PHP tidak otomatis membuat property `$nama` dari itu (kamu menulis `public string $nama` — itu benar, tapi argumen `'Andi'` tidak ter-assign). Seharusnya `$p = new Penjaga('Andi')` membutuhkan `$this->nama = $nama` di constructor, atau memakai promotion (`__construct(public string $nama)`).
2. `$p->jumlahBuku = 5;` dan `echo $p->jumlahBuku;` akan **Fatal error: Cannot access private property** — `$jumlahBuku` private tidak bisa diakses dari luar.

```php
class Penjaga {
    public function __construct(public string $nama) {}
    private int $jumlahBuku = 0;
    public function tambah(): void { $this->jumlahBuku++; }
    public function getJumlah(): int { return $this->jumlahBuku; }
}

$p = new Penjaga('Andi');
$p->tambah();             // via method
echo $p->getJumlah();     // 1
```

> **Pembahasan:** Ini inti encapsulation: *data diubah lewat method*, bukan akses langsung. Kegagalan "private" adalah error yang paling sering muncul saat permenata OOP pertama — dan cara membacanya justru *menguatkan* alasan kenapa private itu ada.
