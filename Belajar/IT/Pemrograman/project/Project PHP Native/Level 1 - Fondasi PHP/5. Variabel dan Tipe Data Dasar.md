# 5. Variabel dan Tipe Data Dasar

> **Level 1 · Fondasi PHP** — PHP sudah berjalan dan error sudah terkendali. Sekarang kita menyimpan data.

---

## 1. Penjelasan Singkat & Konsep Dasar

**Variabel** adalah wadah bernama untuk menyimpan sebuah nilai. Di PHP, semua variabel diawali tanda `$`, nilainya **bebas berubah**, dan **nama variabel case-sensitive** (`$nama` ≠ `$Nama`).

Kekhasan PHP: ini bahasa **dynamically typed** — tipe data sebuah variabel **tidak ditulis saat deklarasi**; PHP menentukan dan bisa mengubah tipe secara otomatis saat runtime.

Tipe data dasar:

```php
$judul  = "Clean Code";      // string  — teks
$harga  = 150000;            // int     — bilangan bulat
$rating = 4.8;               // float   — bilangan desimal
$tersedia = true;            // bool    — true/false
$isbn   = null;              // null    — "tidak ada nilai"
```

**Benang Merah:** materi 1-4 membangun saluran *kode → server → output*. Variabel adalah langkah pertama untuk membuat output itu *berarti* — data yang disimpan lalu ditampilkan. Seluruh Level 2 (string & array) adalah pengembangan dari pemahaman variabel ini.

---

## 2. Fungsi & Kegunaan Utama

- **Menyimpan nilai** yang akan dipakai beberapa kali — ini awal dari prinsip **DRY** (Don't Repeat Yourself). Tulis sekali `$jamBuka`, pakai di banyak tempat, ubah sekali saja.
- **Membuat kode terbaca** — nama variabel deskriptif (`$jumlahKoleksi`) berfungsi sebagai dokumentasi diri.
- **Single vs double quote** — ini bukan hanya selera: double quote memproses variabel & escape; single quote literal & sedikit lebih cepat.

```php
$nama = "Perpustakaan";
echo "Selamat datang di $nama";   // Selamat datang di Perpustakaan
echo 'Selamat datang di $nama';   // Selamat datang di $nama  ← literal!
```

- **`var_dump()` / `print_r()`** — teman paling setia saat debugging. `var_dump` menampilkan tipe + nilai lengkap; `print_r` lebih ringkas untuk array & object.

---

## 3. Contoh Kode & Implementasi Real-World

`profil.php` — variabel dipakai untuk "memprogram" halaman sekali, isi berubah tanpa menyentuh HTML:

```php
<?php
// File: perpustakaan/profil.php
$namaPerpustakaan = "Perpustakaan Digital Kota";
$tahunBerdiri     = 1995;                 // int
$jumlahKoleksi    = 12500;                // int
$ratingLayanan    = 4.8;                  // float
$bukaHariMinggu   = true;                 // bool
$alamat           = "Jl. Merdeka No. 1";  // string
$website          = null;                 // null — belum punya website
?>
<!DOCTYPE html>
<html lang="id">
<body>
    <h1><?= htmlspecialchars($namaPerpustakaan) ?></h1>
    <p>Tahun berdiri: <?= $tahunBerdiri ?></p>
    <p>Koleksi: <?= number_format($jumlahKoleksi, 0, ',', '.') ?></p>
    <p>Rating layanan: <?= $ratingLayanan ?>/5</p>
    <p>Buka hari Minggu: <?= $bukaHariMinggu ? 'Ya' : 'Tidak' ?></p>
    <p>Website: <?= $website ?? 'Belum tersedia' ?></p>
</body>
</html>
```

**Sedikit catatan penting tentang nilai-boolean & falsy:**

```php
// Nilai yang dianggap FALSE oleh PHP (jika dalam konteks boolean):
// false, 0, 0.0, "", "0", [], null
if ($stok) { }          // ia akan dianggap false jika $stok = 0 / "" / null

// Cara memeriksa tipe dengan tegas:
is_string($judul);      // true
is_int($harga);         // true
is_float($rating);      // true
is_bool($tersedia);     // true
is_null($website);      // true
```

**Debug type & value:**

```php
var_dump($harga);                       // int(150000)
var_dump($rating);                      // float(4.8)
var_dump($tersedia);                    // bool(true)
print_r(["Clean Code", "Laskar Pelangi"]);
```

## 4. Analogi Sederhana

Dalam **Sistem Administrasi Kantor**:

- **Variabel** = **berkas/label penyimpanan** di meja staf. Label `$namaPerpustakaan` tertempel pada map yang berisi "Perpustakaan Digital Kota". Staf bisa membuka map kapan pun dan mengganti isinya.
- **Tipe data** = jenis isi berkas. Map `$harga` berisi angka (int), map `$nama` berisi teks (string), map `$tersedia` berisi tanda centang/mencoret (bool), map `$website` kosong (null).
- **Dynamic typing** = staf tidak diwajibkan menulis "INI BERISI ANGKA" di sampul — dia membaca dan menyesuaikan sendiri. Fleksibel, tapi kadang salah tebak (dibahas di materi 6).
- **`var_dump()`** = staf membuka map dan *melaporkan isi + jenis isi* secara detail — cara paling jujur untuk tahu apa yang sebenarnya tersimpan.

---

## 5. Kapan Harus Digunakan & Kasus Penggunaan

- **Segala saat** — setiap data yang dipakai lebih dari sekali disimpan dalam variabel.
- **Kapan memakai double vs single quote:**
  - Double quote: ketika kamu *ingin* interpolasi variabel (`"Halo $nama"`) atau karakter escape (`"\n"`, `"\t"`).
  - Single quote: string literal tanpa variabel (`'email'`, `'admin123'`) — sedikit lebih cepat dan tidak ada kejutan interpolasi.
- **Kasus nyata:** data profil perpustakaan disimpan di variabel → tampil di `index.php` dan `profil.php` tanpa duplikasi. Di materi 9-12, variabel ini akan berubah menjadi array & fungsi, tapi prinsip wadah-bernama tetap sama.

## 6. Aspek Keamanan & Best Practices (Critical)

- **Output selalu di-escape** — nilai variabel yang ditampilkan ke HTML lewat `htmlspecialchars()` (terutama yang nanti berasal dari user). `$website ?? 'Belum tersedia'` menunjukkan pola aman memakai null coalescing; kombinasi dengan `esc()` adalah standar.
- **Jangan percaya nilai dari user** — variabel itu sendiri aman; bahaya muncul ketika *isinya* bisa berasal dari input user (Level 3+). Disiplin menulis variabel dari sumber yang sudah divalidasi adalah fondasi keamanan.
- **Best practices:**
  - Nama variabel deskriptif: `$jumlahKoleksi`, bukan `$jk` atau `$x`.
  - `$camelCase` adalah konvensi penamaan variabel PHP (rantai roda: coba konsisten).
  - Selalu deklarasikan dengan nilai awal — menghindari *Undefined variable* (materi 4).
  - Gunakan `var_dump()` bukan `echo` saat ragu tipe data.

---

## 7. Kesalahan Umum & Debugging

- **`Undefined variable: $x` (Notice)** — variabel dipakai sebelum didefinisikan. Penyebab: typo nama (`$jumlahStok` vs `$jmlStok`), atau pindah scope. Solusi: deklarasikan dulu, atau pakai `??` untuk default.
- **`Undefined array key`** — mirip, tapi untuk array (akan sering muncul di Level 2+). Solusi: `??` / `isset()`.
- **"Variabel tidak berubah walau sudah saya ubah"** — cek apakah kamu mengubah **file yang benar** dan apakah **area HTML yang menampilkan** ikut diubah.
- **Interpolasi aneh** — `echo "$namaPerpustakaan Digital"` error/tidak sesuai karena `$namaPerpustakaanDigital` dibaca sebagai satu nama variabel. Solusi: gunakan kurung kurawal `${...}`.

```php
$nama = "Perpustakaan";
echo "Selamat datang di ${nama} Digital";  // ✅ jelas
echo "Selamat datang di $nama Digital";    // ❌ $namaDigital tidak ada
```

- **Angka vs string** — `$harga` dari form selalu *string* `"150000"`. Ini dibahas tuntas di materi 6 (type juggling) dan 13 (superglobal).

## 8. Soal Latihan & Kunci Jawaban

### Tantangan 1
Tulis script yang mendefinisikan data perpustakaan berikut: nama (string), tahun berdiri (int), luas bangunan dalam `m²` (float), status "aktif" (bool), dan lokasi file koran lama (null). Gunakan `var_dump()` untuk masing-masing dan jelaskan output tipe datanya. Tampilkan juga info ke HTML menggunakan `<?= ?>` dan `htmlspecialchars()`.

### Tantangan 2
Apa output dari kode berikut, dan kenapa?

```php
$kota = "Bandung";
echo 'Kami berpusat di $kota, ' . "tepat di $kota.";
```

### Jawaban & Pembahasan

**Tantangan 1**

```php
<?php
$nama             = "Perpustakaan Kota";
$tahunBerdiri     = 1995;
$luasBangunan     = 1250.75;
$statusAktif      = true;
$lokasiArsipLama  = null;

var_dump($nama);            // string(17) "Perpustakaan Kota"
var_dump($tahunBerdiri);    // int(1995)
var_dump($luasBangunan);    // float(1250.75)
var_dump($statusAktif);     // bool(true)
var_dump($lokasiArsipLama); // NULL

echo "<p>" . htmlspecialchars($nama) . " berdiri sejak $tahunBerdiri, " .
     "luas $luasBangunan m&sup2;.</p>";
?>
```

> **Pembahasan:** `var_dump` menunjukkan (tipe+nilai) secara eksplisit — cara terbaik mengonfirmasi bahwa PHP menyimpan "Bandung" sebagai string 7 huruf, `1995` sebagai int, dst. Cable notice `var_dump(NULL)` menampilkan `NULL`. Untuk HTML, gunakan `htmlspecialchars()` pada teks yang mungkin mengandung karakter HTML.

**Tantangan 2** — Output: `Kami berpusat di $kota, tepat di Bandung.`

> **Pembahasan:** Bagian pertama memakai **single quote** → `$kota` diperlakukan *literal* (tidak di-interpolasi). Bagian kedua memakai **double quote** (setelah concatenation `.`) → variabel `$kota` diproses menjadi `Bandung`. Ini adalah contoh paling langsung perbedaan single vs double quote, dan alasan kenapa pemilihan kutip penting saat menulis string.
