# 73. Unit Test Guards — Mock ExecutionContext

## Penjelasan

Guards di NestJS adalah komponen yang menentukan apakah suatu request boleh dilanjutkan ke route handler atau tidak. Dua guard yang paling umum adalah `JwtAuthGuard` (memeriksa apakah request menyertakan token JWT yang valid) dan `RolesGuard` (memeriksa apakah user memiliki role yang diizinkan untuk mengakses resource). Kedua guard ini beroperasi pada level `ExecutionContext`, yang merupakan abstraksi dari request yang masuk. Untuk menguji guard secara unit, kita perlu membuat mock `ExecutionContext` yang mensimulasikan berbagai skenario request.

`ExecutionContext` menyediakan akses ke request handler, class controller, dan argumen request. Untuk `JwtAuthGuard`, kita perlu memastikan bahwa guard melewati request jika route memiliki decorator `@Public()`, dan memblokir request jika token tidak valid. Untuk `RolesGuard`, kita perlu memeriksa apakah user memiliki role yang sesuai dengan yang didefinisikan di decorator `@Roles()`. Kedua guard ini menggunakan `Reflector` untuk membaca metadata dari handler dan class.

Mocking `ExecutionContext` membutuhkan pembuatan object `switchToHttp()` palsu yang mengembalikan `getRequest()` palsu. Request palsu ini berisi properti seperti `headers` (untuk token), `user` (setelah JWT diverifikasi), dan `route` (untuk metadata). Kita juga perlu mock `Reflector` untuk mengembalikan metadata yang sesuai dengan skenario test. Dengan pendekatan ini, kita bisa menguji guard dalam isolasi penuh tanpa harus menjalankan server HTTP.

## Fungsi

- Memvalidasi `JwtAuthGuard` melewati request dengan token valid dan memblokir tanpa token
- Memvalidasi `RolesGuard` mengizinkan akses untuk role yang sesuai dan menolak yang tidak sesuai
- Memastikan decorator `@Public()` benar-benar melewati autentikasi
- Memverifikasi error response guard sesuai dengan format yang diharapkan (401 vs 403)
- Menguji kombinasi guard: endpoint yang butuh autentikasi DAN role tertentu
- Mendokumentasikan behavior keamanan aplikasi secara eksplisit

### 1. Utility untuk Mock ExecutionContext

```typescript
// test/mocks/execution-context.mock.ts
import { ExecutionContext, Type } from '@nestjs/common';
import { ROUTE_ARGS_METADATA } from '@nestjs/common/constants';
import { HttpArgumentsHost } from '@nestjs/common/interfaces';

export function createMockExecutionContext(options?: {
  user?: any;
  headers?: Record<string, string>;
  handler?: any;
  class?: Type<any>;
}): ExecutionContext {
  const handler = options?.handler ?? (() => {});
  handler.name = handler.name || 'testHandler';

  const request = {
    headers: options?.headers ?? {},
    user: options?.user,
    url: '/api/test',
    method: 'GET',
  };

  const httpArgumentsHost: HttpArgumentsHost = {
    getRequest: () => request,
    getResponse: () => ({ status: jest.fn().mockReturnThis(), json: jest.fn() }),
    getNext: () => jest.fn(),
  };

  return {
    switchToHttp: () => httpArgumentsHost,
    getHandler: () => handler,
    getClass: () => options?.class ?? class TestController {},
    getArgs: jest.fn(),
    getArgByIndex: jest.fn(),
    switchToRpc: jest.fn(),
    switchToWs: jest.fn(),
    getType: () => 'http',
  } as unknown as ExecutionContext;
}
```

### 3. `jwt-auth.guard.spec.ts`

```typescript
// src/auth/guards/jwt-auth.guard.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { Reflector } from '@nestjs/core';
import { UnauthorizedException } from '@nestjs/common';
import { JwtAuthGuard } from './jwt-auth.guard';
import { IS_PUBLIC_KEY } from '../decorators/public.decorator';
import { createMockExecutionContext } from '../../../test/mocks/execution-context.mock';

describe('JwtAuthGuard', () => {
  let guard: JwtAuthGuard;
  let reflector: jest.Mocked<Reflector>;

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        JwtAuthGuard,
        { provide: Reflector, useValue: createMockReflector() },
      ],
    }).compile();

    guard = module.get<JwtAuthGuard>(JwtAuthGuard);
    reflector = module.get(Reflector) as jest.Mocked<Reflector>;

    jest.clearAllMocks();
  });

  describe('canActivate', () => {
    it('should allow access if route is marked as @Public', () => {
      const handler = () => {};
      Reflect.defineMetadata(IS_PUBLIC_KEY, true, handler);

      const context = createMockExecutionContext({ handler });

      const result = guard.canActivate(context);

      expect(result).toBe(true);
    });

    it('should call super.canActivate if route is not public', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        headers: { authorization: 'Bearer valid-token' },
      });

      // Mock super.canActivate untuk return true
      const canActivateSpy = jest
        .spyOn(JwtAuthGuard.prototype as any, 'canActivate')
        .mockReturnValue(true);

      const result = guard.canActivate(context);

      expect(result).toBe(true);
      canActivateSpy.mockRestore();
    });

    it('should throw UnauthorizedException if token is missing and not public', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        headers: {},
      });

      try {
        guard.canActivate(context);
      } catch (e) {
        expect(e).toBeInstanceOf(UnauthorizedException);
        expect(e.message).toBe('Authentication required');
      }
    });

    it('should handle error when super.canActivate throws', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        headers: { authorization: 'Bearer invalid-token' },
      });

      jest.spyOn(JwtAuthGuard.prototype as any, 'canActivate').mockImplementation(() => {
        throw new UnauthorizedException('Invalid token');
      });

      expect(() => guard.canActivate(context)).toThrow(UnauthorizedException);
    });
  });
});
```

### 4. `roles.guard.spec.ts`

```typescript
// src/auth/guards/roles.guard.spec.ts
import { Test, TestingModule } from '@nestjs/testing';
import { Reflector } from '@nestjs/core';
import { ForbiddenException } from '@nestjs/common';
import { RolesGuard } from './roles.guard';
import { Role } from '../enums/role.enum';
import { ROLES_KEY } from '../decorators/roles.decorator';
import { createMockExecutionContext } from '../../../test/mocks/execution-context.mock';
import { createMockReflector } from '../../../test/mocks/reflector.mock';

describe('RolesGuard', () => {
  let guard: RolesGuard;
  let reflector: jest.Mocked<Reflector>;

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      providers: [
        RolesGuard,
        { provide: Reflector, useValue: createMockReflector() },
      ],
    }).compile();

    guard = module.get<RolesGuard>(RolesGuard);
    reflector = module.get(Reflector) as jest.Mocked<Reflector>;

    jest.clearAllMocks();
  });

  describe('canActivate', () => {
    it('should allow access if no roles are required', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        user: { role: Role.USER },
      });

      reflector.get.mockReturnValue(undefined);

      const result = guard.canActivate(context);

      expect(result).toBe(true);
    });

    it('should allow access if user has the required role', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        user: { role: Role.ADMIN },
      });

      reflector.get.mockReturnValue([Role.ADMIN]);

      const result = guard.canActivate(context);

      expect(result).toBe(true);
    });

    it('should allow access if user has one of multiple required roles', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        user: { role: Role.EDITOR },
      });

      reflector.get.mockReturnValue([Role.ADMIN, Role.EDITOR]);

      const result = guard.canActivate(context);

      expect(result).toBe(true);
    });

    it('should throw ForbiddenException if user does not have the required role', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        user: { role: Role.USER },
      });

      reflector.get.mockReturnValue([Role.ADMIN]);

      expect(() => guard.canActivate(context)).toThrow(ForbiddenException);
    });

    it('should throw ForbiddenException if user has no role property', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        user: {},
      });

      reflector.get.mockReturnValue([Role.USER]);

      expect(() => guard.canActivate(context)).toThrow(ForbiddenException);
    });

    it('should handle roles defined at class level', () => {
      class TestController {}
      const handler = () => {};

      const context = createMockExecutionContext({
        handler,
        class: TestController,
        user: { role: Role.ADMIN },
      });

      reflector.get.mockReturnValue([Role.ADMIN]);

      const result = guard.canActivate(context);

      expect(result).toBe(true);
      // Reflector.get dipanggil dua kali: handler dan class
      expect(reflector.get).toHaveBeenCalledTimes(2);
    });

    it('should prioritize handler-level roles over class-level roles', () => {
      const handler = () => {};
      const context = createMockExecutionContext({
        handler,
        user: { role: Role.USER },
      });

      // Class-level: [ADMIN], Handler-level: [USER]
      reflector.get
        .mockReturnValueOnce([Role.USER])    // handler
        .mockReturnValueOnce([Role.ADMIN]);  // class (fallback)

      const result = guard.canActivate(context);

      expect(result).toBe(true);
    });

    it('should check class-level roles if handler has none', () => {
      const handler = () => {};
      class AdminController {}

      const context = createMockExecutionContext({
        handler,
        class: AdminController,
        user: { role: Role.ADMIN },
      });

      reflector.get
        .mockReturnValueOnce(undefined)           // handler no roles
        .mockReturnValueOnce([Role.ADMIN]);        // class has roles

      const result = guard.canActivate(context);

      expect(result).toBe(true);
    });
  });
});
```

## Analogi

Bayangkan perpustakaan memiliki **pintu masuk dengan dua lapis keamanan**. Lapis pertama (JwtAuthGuard) adalah **pintu gesek kartu anggota** — hanya anggota yang memiliki kartu aktif yang bisa masuk. Lapis kedua (RolesGuard) adalah **pintu akses ke ruangan khusus** — hanya anggota dengan status "staf" atau "peneliti" yang bisa masuk ke ruang koleksi langka. Untuk menguji kedua sistem keamanan ini, kita membuat **pengunjung palsu** (mock ExecutionContext) yang membawa kartu palsu (mock token) dan status palsu (mock role). Kita juga membuat **papan aturan palsu** (mock Reflector) yang memberi tahu siapa saja yang diizinkan masuk ke ruangan tertentu. Dengan pengunjung palsu ini, kita bisa menguji apakah pintu gesek menolak kartu yang sudah kadaluarsa, apakah pintu ruangan khusus menolak anggota biasa, dan apakah pintu utama tetap terbuka untuk tamu undangan (@Public).

## Penggunaan

- Memvalidasi keamanan endpoint sebelum deployment
- Menguji kombinasi guard yang kompleks (JwtAuth + Roles secara bersamaan)
- Memastikan decorator @Public berfungsi untuk route yang tidak perlu autentikasi
- Regression test saat mengubah logika otorisasi
- Dokumentasi eksplisit tentang siapa yang bisa mengakses apa

## Kesalahan Umum yang Sering Terjadi

1. **ExecutionContext tidak lengkap**: Mock hanya menyediakan `switchToHttp().getRequest()` tapi lupa method lain seperti `getClass()`. Akibatnya, guard yang membaca metadata dari class level gagal. Solusi: gunakan utility `createMockExecutionContext` yang lengkap.

2. **Reflector.get tidak di-mock dengan benar**: Guard memanggil `reflector.get(key, handler)` lalu `reflector.get(key, class)`. Jika urutan mock tidak sesuai, test bisa memberikan hasil yang salah. Solusi: gunakan `mockReturnValueOnce` dengan urutan yang benar.

3. **Lupa test untuk @Public decorator**: Banyak developer hanya menguji guard untuk route yang butuh autentikasi, lupa bahwa route publik harus tetap bisa diakses. Solusi: tambahkan test case untuk handler dengan metadata `IS_PUBLIC_KEY = true`.

4. **Error handling tidak di-test**: Guard melempar exception, tapi test tidak memverifikasi tipe exceptionnya. Solusi: gunakan `expect(() => guard.canActivate(...)).toThrow(ForbiddenException)`.

5. **RolesGuard tidak mengecek inheritance role**: Misalnya, ADMIN seharusnya bisa mengakses route yang membutuhkan USER, tapi implementasi tidak memperhitungkan hierarki. Solusi: test case untuk skenario inheritance jika ada.
