# 84. Health Check Endpoint - @nestjs/terminus

## Penjelasan
Health check endpoint adalah endpoint khusus (biasanya `GET /api/health` atau `GET /health`) yang digunakan untuk memantau status kesehatan aplikasi dan seluruh dependensinya — database, Redis, microservice, email service, dan lain-lain. Di NestJS, kita menggunakan package `@nestjs/terminus` untuk membuat health check secara terstruktur. Terminus menyediakan berbagai HealthIndicator bawaan seperti `PrismaHealthIndicator` (untuk mengecek koneksi Prisma/PostgreSQL), `DNSHealthIndicator`, `MemoryHealthIndicator`, `DiskHealthIndicator`, dan `MicroserviceHealthIndicator`.

Fungsi health check sangat krusial di production: (1) **Orchestrator** seperti Kubernetes atau Docker menggunakan health check untuk menentukan kapan harus me-restart container yang gagal; (2) **Load balancer** (seperti Nginx atau AWS ALB) menggunakan health check untuk menghentikan pengiriman traffic ke instance yang bermasalah; (3) **Monitoring tools** seperti Prometheus atau Datadog mengumpulkan metrik uptime dari health check endpoint; (4) **Developer** bisa dengan cepat mendiagnosis masalah dengan melihat status setiap dependensi.

## Fungsi
- Menyediakan endpoint terpusat untuk mengecek status aplikasi dan semua dependensinya
- Membantu orchestrator (Kubernetes, Docker) memutuskan kapan perlu me-restart container
- Memberikan visibilitas real-time tentang kesehatan sistem secara keseluruhan

## Cara Implementasi / Code

**Install package:**
```bash
npm install @nestjs/terminus @prisma/client
```

**Health Module:**
```typescript
import { Module } from '@nestjs/common';
import { TerminusModule } from '@nestjs/terminus';
import { PrismaModule } from '../prisma/prisma.module';
import { HealthController } from './health.controller';
import { PrismaHealthIndicator } from './prisma-health.indicator';

@Module({
  imports: [
    TerminusModule.forRoot({
      errorLogStyle: 'json',
      gracefulShutdownTimeoutMs: 1000,
    }),
    PrismaModule,
  ],
  controllers: [HealthController],
  providers: [PrismaHealthIndicator],
})
export class HealthModule {}
```

**Prisma Health Indicator:**
```typescript
import { Injectable } from '@nestjs/common';
import { HealthIndicator, HealthIndicatorResult, HealthCheckError } from '@nestjs/terminus';
import { PrismaService } from '../prisma/prisma.service';

@Injectable()
export class PrismaHealthIndicator extends HealthIndicator {
  constructor(private readonly prisma: PrismaService) {
    super();
  }

  async isHealthy(key: string): Promise<HealthIndicatorResult> {
    try {
      await this.prisma.$queryRaw`SELECT 1`;
      return this.getStatus(key, true);
    } catch (error) {
      throw new HealthCheckError('Prisma check failed', this.getStatus(key, false, { message: error.message }));
    }
  }
}
```

**Health Controller:**
```typescript
import { Controller, Get } from '@nestjs/common';
import { HealthCheck, HealthCheckService, MemoryHealthIndicator, DiskHealthIndicator } from '@nestjs/terminus';
import { PrismaHealthIndicator } from './prisma-health.indicator';

@Controller('api/health')
export class HealthController {
  constructor(
    private health: HealthCheckService,
    private prismaHealth: PrismaHealthIndicator,
    private memory: MemoryHealthIndicator,
    private disk: DiskHealthIndicator,
  ) {}

  @Get()
  @HealthCheck()
  check() {
    return this.health.check([
      () => this.prismaHealth.isHealthy('database'),
      () => this.memory.checkHeap('memory_heap', 200 * 1024 * 1024),
      () => this.memory.checkRSS('memory_rss', 300 * 1024 * 1024),
      () => this.disk.checkStorage('disk', { path: '/', thresholdPercent: 0.9 }),
    ]);
  }
}
```

## Analogi
Bayangkan perpustakaan memiliki **panel kontrol** di ruang petugas yang menunjukkan status semua fasilitas: lampu hijau jika rak buku (database) tersusun rapi, lampu hijau jika sistem katalog (Redis) berfungsi, dan lampu merah jika ada kerusakan. Health check endpoint adalah panel kontrol tersebut — memberikan informasi real-time apakah semua "fasilitas perpustakaan" berfungsi normal atau ada yang perlu diperbaiki.

## Penggunaan
- Dipakai oleh **Docker** sebagai `HEALTHCHECK` instruction di Dockerfile (file 81) untuk memutuskan kapan container perlu di-restart
- Dipakai oleh **Kubernetes** sebagai `livenessProbe` dan `readinessProbe`
- Dipakai oleh **load balancer** untuk menghentikan traffic ke instance yang tidak sehat
- Dipakai oleh **monitoring dashboard** (Grafana, Datadog) untuk menampilkan uptime dan alerting

## Kesalahan Umum yang Sering Terjadi
1. **Health check terlalu berat** — Menjalankan query kompleks atau query yang memakan waktu lama. Health check harus cepat (idealnya < 500ms). Query cukup `SELECT 1`.
2. **Tidak mengecek dependensi eksternal** — Health check hanya return 200 OK tanpa mengecek database, Redis, atau API eksternal. Ini berbahaya karena aplikasi bisa dianggap sehat padahal database mati.
3. **Meletakkan health check di route yang sama dengan API bisnis** — Health check harus di endpoint terpisah (misal `/api/health`) dan tidak perlu autentikasi.
4. **Response terlalu besar** — Hindari mengembalikan terlalu banyak data dalam health check response. Cukup status up/down dan pesan error singkat.
5. **Lupa setup di Dockerfile** — Docker `HEALTHCHECK` di file 81 memanggil endpoint ini. Jika endpoint tidak ada, container akan dianggap tidak sehat terus-menerus.

## Hubungan dengan Materi Sebelumnya
Di file 81, kita menambahkan `HEALTHCHECK` di Dockerfile yang memanggil `http://localhost:3000/api/health`. Di file 82, kita setup `healthcheck` untuk PostgreSQL di docker-compose. Sekarang kita implementasikan endpoint health check di kode NestJS menggunakan @nestjs/terminus. Ketiganya bekerja bersama: Docker → panggil health endpoint → @nestjs/terminus cek database → return status.

## Soal Latihan

**Soal:** Kamu ingin menambahkan health check untuk Redis di HealthController. Lengkapi kode berikut dengan menggunakan `MicroserviceHealthIndicator` dari `@nestjs/terminus` (asumsikan Redis terhubung via TCP di `localhost:6379`):

```typescript
import { MicroserviceHealthIndicator } from '@nestjs/terminus';

// tambahkan di constructor:
constructor(
  private microservice: MicroserviceHealthIndicator,
  // ... lainnya
)

// tambahkan di array health.check:
```

**Jawaban:**

```typescript
import { MicroserviceHealthIndicator, HealthIndicatorFunction } from '@nestjs/terminus';
import { RedisOptions, Transport } from '@nestjs/microservices';

// Di constructor:
constructor(
  private microservice: MicroserviceHealthIndicator,
  private health: HealthCheckService,
  private prismaHealth: PrismaHealthIndicator,
  private memory: MemoryHealthIndicator,
  private disk: DiskHealthIndicator,
) {}

// Di method check:
@Get()
@HealthCheck()
check() {
  return this.health.check([
    () => this.prismaHealth.isHealthy('database'),
    () => this.microservice.pingCheck('redis', {
      transport: Transport.REDIS,
      options: { host: 'localhost', port: 6379 },
    }),
    () => this.memory.checkHeap('memory_heap', 200 * 1024 * 1024),
    () => this.disk.checkStorage('disk', { path: '/', thresholdPercent: 0.9 }),
  ]);
}
```
