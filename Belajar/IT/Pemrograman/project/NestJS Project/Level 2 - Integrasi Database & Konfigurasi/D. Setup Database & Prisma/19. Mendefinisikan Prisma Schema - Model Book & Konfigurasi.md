# Mendefinisikan Prisma Schema — Model Book & Konfigurasi

## Penjelasan

Prisma Schema adalah file konfigurasi utama (`prisma/schema.prisma`) yang menjadi single source of truth untuk struktur database. Di dalamnya kita mendefinisikan tiga hal utama: datasource (koneksi database), generator (pembuat Prisma Client), dan models (representasi tabel database). Model dalam Prisma menggunakan sintaksis deklaratif yang mirip dengan TypeScript, di mana setiap properti merepresentasikan kolom tabel dengan tipe data yang sesuai seperti `String`, `Int`, `DateTime`, atau `Boolean`.

Untuk project perpustakaan, kita akan membuat model `Book` yang memiliki field-field seperti `id` (UUID), `title`, `author`, `isbn`, `publishedYear`, `genre`, `stock`, `isDeleted`, `createdAt`, dan `updatedAt`. Prisma menyediakan decorator seperti `@id` untuk primary key, `@default` untuk nilai default, `@unique` untuk unique constraint, `@map` untuk mapping nama kolom di database, dan `@updatedAt` untuk timestamp otomatis. Kita juga bisa mendefinisikan enum untuk field dengan nilai tetap seperti genre buku.

Relasi antar model juga bisa didefinisikan langsung di schema. Misalnya, jika nanti kita punya model `Member` dan `Loan`, kita bisa membuat relasi one-to-many atau many-to-many langsung di Prisma Schema. Prisma akan secara otomatis menghasilkan foreign key dan join table yang diperlukan. Ini memudahkan kita melakukan query dengan nested include tanpa menulis JOIN secara manual.

## Fungsi

Mendefinisikan struktur tabel database secara deklaratif dan type-safe menggunakan Prisma Schema, termasuk tipe data, constraint, relasi, enum, dan mapping ke database PostgreSQL.

## Cara Implementasi / Code

Berikut adalah `prisma/schema.prisma` lengkap untuk project perpustakaan:

```prisma
// prisma/schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// Enum untuk genre buku
enum BookGenre {
  FIKSI
  NON_FIKSI
  SAINS
  TEKNOLOGI
  SEJARAH
  BIOGRAFI
  FILSAFAT
  PSIKOLOGI
  EKONOMI
  SENI
  AGAMA
  PENDIDIKAN
  KESEHATAN
  HUKUM
  @map("book_genre")
}

// Model utama untuk buku
model Book {
  id            String    @id @default(uuid()) @map("id")
  title         String    @map("title")
  author        String    @map("author")
  isbn          String    @unique @map("isbn")
  publishedYear Int       @map("published_year")
  genre         BookGenre @map("genre")
  description   String?   @map("description")
  stock         Int       @default(1) @map("stock")
  isDeleted     Boolean   @default(false) @map("is_deleted")
  createdAt     DateTime  @default(now()) @map("created_at")
  updatedAt     DateTime  @updatedAt @map("updated_at")

  // Relasi (akan dikembangkan di level selanjutnya)
  // loans Loan[]

  @@map("books")
}
```

Penjelasan field:

| Field | Tipe | Keterangan |
|-------|------|-----------|
| `id` | `String @id @default(uuid())` | Primary key menggunakan UUID v4 |
| `title` | `String` | Judul buku (required) |
| `author` | `String` | Penulis buku (required) |
| `isbn` | `String @unique` | ISBN unik, tidak boleh ada duplikat |
| `publishedYear` | `Int` | Tahun terbit |
| `genre` | `BookGenre` | Enum genre buku |
| `description` | `String?` | Deskripsi opsional (nullable) |
| `stock` | `Int @default(1)` | Jumlah stok, default 1 |
| `isDeleted` | `Boolean @default(false)` | Soft delete flag |
| `createdAt` | `DateTime @default(now())` | Auto-set saat create |
| `updatedAt` | `DateTime @updatedAt` | Auto-update saat update |

Setelah schema selesai, generate Prisma Client:

```bash
npx prisma generate
```

## Analogi

Prisma Schema adalah **cetak biru perpustakaan** yang digambar oleh arsitek. Cetak biru ini menentukan: di mana letak rak buku (tabel), berapa lebar rak (tipe data), rak mana yang hanya bisa diisi buku dengan ISBN unik (`@unique`), dan rak mana yang wajib diisi (`String` vs `String?`). Ada juga bagian khusus yang memberi label pada setiap rak (`@map`) agar petugas perpustakaan (database) mudah memahami, meskipun nama di cetak biru berbeda dari label di rak sungguhan. Cetak biru ini juga mencakup kotak-kotak kecil (enum) yang berisi daftar genre yang sudah ditentukan — petugas tidak bisa seenaknya menaruh buku genre "Misteri" jika tidak ada di kotak tersebut. Dengan cetak biru ini, tukang bangunan (Prisma Migrate) bisa membangun perpustakaan yang persis sesuai rencana.

## Penggunaan

Dipakai untuk mendefinisikan seluruh model data aplikasi. Schema ini menjadi dasar untuk migrasi database, Prisma Client (type-safe query), Prisma Studio (GUI), dan dokumentasi struktur data. Setiap perubahan struktur database harus diawali dengan perubahan di Prisma Schema, bukan langsung di database.

## Kesalahan Umum yang Sering Terjadi

1. **Lupa generate setelah ubah schema**: Prisma Client tidak update, autocompletion tetap pakai model lama.
2. **Tidak pakai `@map`**: Nama kolom di database menggunakan camelCase alih-alih snake_case, yang kurang konsisten dengan konvensi database.
3. **Nullable tanpa `?`**: Field yang seharusnya boleh kosong tidak ditandai `?`, menyebabkan error saat insert data tanpa field tersebut.
4. **Duplikat ISBN**: Lupa pasang `@unique` di field `isbn`, sehingga dua buku bisa punya ISBN sama.
5. **Enum typo**: Nilai enum ditulis sembarangan, tidak konsisten.
6. **Lupa `@updatedAt`**: Field `updatedAt` tidak auto-update saat record diubah.

## Soal Latihan

**Soal 1:** Buat Prisma Schema untuk model `Member` dengan field: id (UUID), name, email (unique), phone (nullable), address (nullable), isActive (default true), createdAt, updatedAt.

<details>
<summary>Jawaban</summary>

```prisma
model Member {
  id        String   @id @default(uuid()) @map("id")
  name      String   @map("name")
  email     String   @unique @map("email")
  phone     String?  @map("phone")
  address   String?  @map("address")
  isActive  Boolean  @default(true) @map("is_active")
  createdAt DateTime @default(now()) @map("created_at")
  updatedAt DateTime @updatedAt @map("updated_at")

  @@map("members")
}
```

</details>

**Soal 2:** Apa perbedaan `@default(now())` dengan `@updatedAt`?

<details>
<summary>Jawaban</summary>

`@default(now())` mengisi nilai default dengan waktu saat record dibuat, dan tidak berubah setelahnya. `@updatedAt` secara otomatis memperbarui nilai field setiap kali record di-update. Jadi `createdAt` pakai `@default(now())`, sedangkan `updatedAt` pakai `@updatedAt`.

</details>

**Soal 3:** Mengapa kita menggunakan `@map("is_deleted")` dan `@@map("books")`?

<details>
<summary>Jawaban</summary>

`@map("is_deleted")` mengubah nama kolom di database menjadi snake_case (`is_deleted`) meskipun di Prisma kita pakai camelCase (`isDeleted`). `@@map("books")` mengubah nama tabel di database menjadi `books` (plural) sementara model di Prisma tetap `Book` (singular). Ini menjaga konvensi database (snake_case, plural) tanpa mengorbankan gaya penulisan TypeScript.

</details>
