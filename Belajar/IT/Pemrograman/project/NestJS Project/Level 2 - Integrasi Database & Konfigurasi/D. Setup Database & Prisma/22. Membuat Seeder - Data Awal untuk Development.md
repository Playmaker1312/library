# Membuat Seeder — Data Awal untuk Development

## Penjelasan

Seeder adalah script yang digunakan untuk mengisi database dengan data dummy atau data awal yang diperlukan untuk development dan testing. Dalam project NestJS dengan Prisma, seeder biasanya ditempatkan di file `prisma/seed.ts` dan menggunakan library `@faker-js/faker` untuk menghasilkan data yang realistis. Dengan seeder, setiap developer yang baru bergabung bisa langsung memiliki data yang cukup untuk menguji fitur-fitur aplikasi tanpa harus memasukkan data satu per satu secara manual.

Seeder sangat berguna dalam skenario pengembangan karena memungkinkan kita menguji pagination, filter, search, dan sorting dengan data yang bervariasi. Misalnya, kita bisa membuat 20 buku dummy dengan judul, penulis, ISBN, genre, dan tahun terbit yang berbeda-beda. Dengan faker, data yang dihasilkan tampak realistis — nama penulis terdengar seperti nama asli, ISBN mengikuti format yang valid, dan genre terdistribusi secara acak.

Untuk menjalankan seeder, kita perlu mengkonfigurasi `package.json` dengan menambahkan key `"prisma": { "seed": "ts-node prisma/seed.ts" }` atau menggunakan `tsx` yang lebih cepat. Perintah `npx prisma db seed` akan membaca konfigurasi ini dan menjalankan file seed. Prisma juga memastikan bahwa seed hanya dijalankan jika database sudah memiliki tabel (migrasi sudah dilakukan). Jika ingin mengisi ulang data, kita bisa menjalankan `npx prisma migrate reset` yang akan menghapus data, menjalankan migrasi ulang, lalu otomatis menjalankan seed.

## Fungsi

Mengisi database development dengan data dummy yang realistis untuk keperluan pengembangan dan testing, sehingga developer tidak perlu memasukkan data manual.

## Cara Implementasi / Code

Install faker:

```bash
npm install @faker-js/faker --save-dev
npm install tsx --save-dev
```

Buat file `prisma/seed.ts`:

```typescript
import { PrismaClient, BookGenre } from '@prisma/client';
import { faker } from '@faker-js/faker';

const prisma = new PrismaClient();

const genres = Object.values(BookGenre);

async function main() {
  console.log('Seeding database...');

  // Hapus data existing
  await prisma.book.deleteMany();

  const books = Array.from({ length: 20 }, (_, i) => ({
    title: `${faker.lorem.words({ min: 2, max: 5 })}`,
    author: faker.person.fullName(),
    isbn: faker.string.numeric(13),
    publishedYear: faker.number.int({ min: 1900, max: 2024 }),
    genre: genres[Math.floor(Math.random() * genres.length)],
    description: faker.lorem.sentences({ min: 1, max: 3 }),
    stock: faker.number.int({ min: 1, max: 10 }),
  }));

  for (const book of books) {
    await prisma.book.create({ data: book });
  }

  console.log(`Successfully seeded ${books.length} books`);
}

main()
  .catch((e) => {
    console.error('Error seeding database:', e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

Update `package.json`:

```json
{
  "prisma": {
    "seed": "tsx prisma/seed.ts"
  }
}
```

Jalankan seeder:

```bash
# Menjalankan seed
npx prisma db seed

# Atau reset + seed (hapus semua data, migrate ulang, seed ulang)
npx prisma migrate reset
```

Verifikasi data di Prisma Studio:

```bash
npx prisma studio
```

## Analogi

Seeder adalah **petugas magang yang ditugaskan mengisi rak buku** dengan 20 buku baru di perpustakaan yang baru dibangun. Bos perpustakaan memberi daftar: "Buat 20 buku dengan judul, penulis, ISBN, dan genre yang berbeda-beda." Petugas magang ini punya buku panduan ajaib (faker) yang bisa menghasilkan judul buku seperti "Senja di Atas Sajadah" atau "Teknologi Nano untuk Pemula", lengkap dengan nama penulis seperti "Dr. Sarah Wijaya" dan ISBN 13 digit. Setelah selesai, rak buku tidak lagi kosong dan pengunjung (developer) bisa langsung meminjam buku untuk diuji coba. Jika suatu saat rak perlu dikosongkan dan diisi ulang, petugas magang tinggal menjalankan ritual "reset" dan semua buku baru akan muncul kembali secara ajaib.

## Penggunaan

Dipakai di environment development dan staging untuk menyediakan data awal yang konsisten. Juga digunakan dalam integration test untuk menyiapkan data test sebelum test dijalankan. Tidak digunakan di production karena data dummy tidak boleh tercampur dengan data asli.

## Kesalahan Umum yang Sering Terjadi

1. **Lupa install `tsx` atau `ts-node`**: Script seed gagal dijalankan karena tidak bisa mengeksekusi TypeScript.
2. **Lupa konfigurasi `package.json`**: Prisma tidak tahu file seed mana yang harus dijalankan.
3. **Tidak hapus data existing sebelum seed**: Data duplikat atau error unique constraint (ISBN duplikat).
4. **Faker menghasilkan data yang tidak sesuai**: Misalnya ISBN tidak numeric atau tahun terbit di masa depan.
5. **Lupa `$disconnect()`**: Koneksi database tetap terbuka setelah seed selesai, menyebabkan warning.
6. **Seeder terlalu lambat**: Insert satu per satu dalam loop untuk 1000+ data. Gunakan `createMany` jika memungkinkan.

## Hubungan dengan Materi Sebelumnya

Setelah migrasi (materi 20) membuat tabel `books` yang masih kosong, seeder ini mengisinya dengan 20 buku dummy. Data inilah yang nantinya akan kita akses melalui repository pattern (materi 24) dan service (materi 26). Seeder memastikan kita memiliki data yang cukup untuk menguji pagination, filter, dan search di materi-materi selanjutnya.

```typescript
import { PrismaClient } from '@prisma/client';
import { faker } from '@faker-js/faker';

const prisma = new PrismaClient();

async function main() {
  await prisma.member.deleteMany();

  const members = Array.from({ length: 5 }, () => ({
    name: faker.person.fullName(),
    email: faker.internet.email(),
    phone: faker.phone.number(),
    address: faker.location.streetAddress(),
  }));

  for (const member of members) {
    await prisma.member.create({ data: member });
  }

  console.log(`Seeded ${members.length} members`);
}

main()
  .catch(console.error)
  .finally(() => prisma.$disconnect());
```
