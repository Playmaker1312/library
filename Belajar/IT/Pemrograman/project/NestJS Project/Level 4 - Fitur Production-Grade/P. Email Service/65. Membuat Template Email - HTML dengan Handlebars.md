# 65. Membuat Template Email — HTML dengan Handlebars

## Penjelasan

Email mentah berupa string HTML yang di-hardcode di dalam kode adalah praktik yang buruk. Selain sulit dibaca dan di-maintain, juga tidak fleksibel ketika desain email berubah. Solusinya adalah menggunakan **template engine** yang memisahkan kode (logic) dari tampilan (presentation). **Handlebars** adalah template engine yang populer untuk email karena sintaksnya sederhana (double curly braces `{{variable}}`) dan mendukung helper kondisional (`{{#if}}`) serta iterasi (`{{#each}}`).

Template email disimpan sebagai file `.hbs` di folder `templates/`. Setiap tipe email memiliki template sendiri: `loan-confirmation.hbs` untuk konfirmasi peminjaman, `welcome.hbs` untuk selamat datang anggota baru, `overdue-notice.hbs` untuk notifikasi keterlambatan. Template ini dirender dengan data yang diberikan (seperti nama user, judul buku, due date) menjadi HTML utuh yang siap dikirim.

## Fungsi

Template email berfungsi sebagai kerangka (skeleton) HTML yang akan diisi dengan data dinamis. Mereka memisahkan desain visual dari logika pengiriman, memudahkan desainer untuk mengubah tampilan email tanpa menyentuh kode TypeScript, dan memastikan konsistensi format di semua jenis email.

### 5. Helper Handlebars

```typescript
// src/email/helpers/handlebars.helpers.ts
import * as Handlebars from 'handlebars';

// Format tanggal Indonesia
Handlebars.registerHelper('formatDate', (date: string) => {
  return new Date(date).toLocaleDateString('id-ID', {
    year: 'numeric',
    month: 'long',
    day: 'numeric',
  });
});

// Format currency (untuk denda)
Handlebars.registerHelper('formatCurrency', (value: number) => {
  return new Intl.NumberFormat('id-ID', {
    style: 'currency',
    currency: 'IDR',
  }).format(value);
});

// Conditional untuk overdue
Handlebars.registerHelper('isOverdue', (status, options) => {
  return status === 'OVERDUE' ? options.fn(this) : options.inverse(this);
});
```

## Analogi

Bayangkan perpustakaan memiliki **cetakan surat standar** (template) yang tinggal diisi nama dan detail peminjaman. Ada cetakan berbeda untuk: surat selamat datang anggota baru, surat konfirmasi peminjaman, surat pengingat pengembalian, dan surat peringatan keterlambatan. Petugas cukup mengambil cetakan yang sesuai, mengisi bagian yang kosong ({{variable}}), dan surat siap dikirim. Tanpa cetakan, petugas harus menulis surat dari nol setiap kali — tidak efisien dan rawan inkonsistensi format.

## Penggunaan

Template email digunakan di semua method `EmailService` untuk menghasilkan body HTML:
- `sendLoanConfirmation()` → `loan-confirmation.hbs`
- `sendWelcomeEmail()` → `welcome.hbs`
- `sendReturnReminder()` → `return-reminder.hbs`
- `sendOverdueNotice()` → `overdue-notice.hbs`
- `sendDailyReport()` → `daily-report.hbs`

## Kesalahan Umum yang Sering Terjadi

1. **Template tidak di-deploy** — file `.hbs` tidak ikut terbundle saat build. Pastikan di `nest-cli.json` ada konfigurasi `assets` untuk menyalin folder template.
2. **Variable typo** — `{{userName}}` berbeda dengan `{{username}}`. Error tidak akan throw, hanya menampilkan string kosong.
3. **HTML email tidak responsif** — banyak email client (terutama Outlook) tidak support CSS modern. Gunakan table-based layout untuk kompatibilitas maksimal.
4. **Partial path salah** — `{{#> layouts/main}}` butuh path yang benar. Handlebars partial harus didaftarkan dengan nama yang sesuai.
5. **Lupa escape HTML** — Handlebars auto-escapes dengan `{{variable}}`. Gunakan triple curly `{{{variable}}}` jika ingin HTML raw (hati-hati XSS).

## Hubungan dengan Materi Sebelumnya

Di **#64**, `EmailService` memiliki method `sendMail()` yang menerima parameter `html: string`. Template Handlebars ini adalah **sumber dari string HTML** tersebut. Di **#66**, kita akan menghubungkan semuanya: EmailService akan merender template dengan data, lalu mengirim hasilnya via Nodemailer. Template adalah komponen "View" dalam arsitektur MVC email.
