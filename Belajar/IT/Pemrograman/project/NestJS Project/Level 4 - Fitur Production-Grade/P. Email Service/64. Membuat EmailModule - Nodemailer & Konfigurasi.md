# 64. Membuat EmailModule — Nodemailer & Konfigurasi

## Penjelasan

**Nodemailer** adalah library Node.js yang paling populer untuk mengirim email. Ia mendukung berbagai transport: SMTP (paling umum), Sendmail, ses transport untuk AWS SES, dan lainnya. Di NestJS, kita akan membungkus Nodemailer dalam sebuah `EmailModule` yang menyediakan `EmailService` sebagai provider global. Service ini akan bertanggung jawab untuk membuat koneksi transport, mengirim email, dan merender template.

Konfigurasi email diambil dari environment variables menggunakan `@nestjs/config` dan `registerAs` untuk membuat namespace `email`. Pendekatan ini memisahkan konfigurasi dari implementasi, memudahkan switching antara Mailhog (development) dan SMTP riil (production). Transport dibuat sekali saat module diinisialisasi (singleton) dan digunakan ulang untuk setiap pengiriman.

## Fungsi

`EmailModule` berfungsi sebagai modul infrastruktur yang menyediakan kemampuan mengirim email ke seluruh aplikasi. Ia mengelola koneksi SMTP, konfigurasi pengirim, dan menyediakan method untuk mengirim berbagai tipe email.

### 2. Konfigurasi Email

```typescript
// src/config/email.config.ts
import { registerAs } from '@nestjs/config';

export default registerAs('email', () => ({
  host: process.env.MAIL_HOST || 'localhost',
  port: parseInt(process.env.MAIL_PORT, 10) || 1025,
  user: process.env.MAIL_USER || '',
  pass: process.env.MAIL_PASS || '',
  from: process.env.MAIL_FROM || 'noreply@library.com',
  fromName: process.env.MAIL_FROM_NAME || 'Perpustakaan Digital',
  secure: process.env.MAIL_SECURE === 'true',
  ignoreTLS: process.env.MAIL_IGNORE_TLS === 'true',
}));
```

### 3. EmailService

```typescript
// src/email/services/email.service.ts
import { Injectable, Logger } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import * as nodemailer from 'nodemailer';
import * as fs from 'fs';
import * as path from 'path';
import * as Handlebars from 'handlebars';

@Injectable()
export class EmailService {
  private readonly logger = new Logger(EmailService.name);
  private transporter: nodemailer.Transporter;
  private readonly from: string;
  private readonly fromName: string;

  constructor(private readonly configService: ConfigService) {
    this.from = this.configService.get<string>('email.from');
    this.fromName = this.configService.get<string>('email.fromName');
    this.initializeTransporter();
  }

  private initializeTransporter() {
    const host = this.configService.get<string>('email.host');
    const port = this.configService.get<number>('email.port');
    const user = this.configService.get<string>('email.user');
    const pass = this.configService.get<string>('email.pass');
    const secure = this.configService.get<boolean>('email.secure');
    const ignoreTLS = this.configService.get<boolean>('email.ignoreTLS');

    const config: nodemailer.TransportOptions = {
      host,
      port,
      secure,
      ignoreTLS,
    };

    // Hanya set auth jika user dan pass disediakan
    if (user && pass) {
      config.auth = { user, pass };
    }

    this.transporter = nodemailer.createTransport(config);

    // Verifikasi koneksi (hanya di development)
    this.transporter.verify((error) => {
      if (error) {
        this.logger.warn(`Email transporter verification failed: ${error.message}`);
      } else {
        this.logger.log('Email transporter is ready');
      }
    });
  }

  async sendMail(options: {
    to: string;
    subject: string;
    html: string;
    text?: string;
  }): Promise<void> {
    try {
      await this.transporter.sendMail({
        from: `"${this.fromName}" <${this.from}>`,
        to: options.to,
        subject: options.subject,
        html: options.html,
        text: options.text || this.stripHtml(options.html),
      });
      this.logger.log(`Email sent to ${options.to}: ${options.subject}`);
    } catch (error) {
      this.logger.error(`Failed to send email to ${options.to}: ${error.message}`);
      throw error;
    }
  }

  private stripHtml(html: string): string {
    return html.replace(/<[^>]*>/g, '').replace(/\s+/g, ' ').trim();
  }

  // Akan diimplementasi di #66
  async sendLoanConfirmation(data: any): Promise<void> { /* ... */ }
  async sendWelcomeEmail(data: any): Promise<void> { /* ... */ }
}
```

### 4. EmailModule

```typescript
// src/email/email.module.ts
import { Module, Global } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { EmailService } from './services/email.service';
import emailConfig from '../config/email.config';

@Global() // Global agar bisa di-inject di mana saja tanpa import
@Module({
  imports: [
    ConfigModule.forFeature(emailConfig),
  ],
  providers: [EmailService],
  exports: [EmailService],
})
export class EmailModule {}
```

## Analogi

Bayangkan perpustakaan memiliki **meja pengiriman surat** yang terhubung langsung ke kantor pos. Di meja ini ada prangko, amplop, dan buku alamat. Petugas tinggal menulis surat, memasukkan ke amplop, menempel prangko, dan menyerahkan ke petugas pos (SMTP). `EmailService` adalah meja ini — ia menyediakan semua perlengkapan (transporter) dan tahu cara mengirim surat. `EmailModule` adalah ruangan tempat meja itu berada — ruangan ini bisa diakses oleh semua pegawai perpustakaan (global module).

## Penggunaan

EmailService digunakan oleh berbagai module:
- **AuthModule**: kirim email verifikasi registrasi, reset password
- **LoansModule**: kirim konfirmasi peminjaman, reminder, overdue notice
- **Schedule tasks**: kirim laporan harian ke admin
- **Admin panel**: kirim notifikasi ke anggota

## Kesalahan Umum yang Sering Terjadi

1. **Tidak handle error verify** — initialisasi transport gagal tapi aplikasi tetap jalan. Nantinya saat sendMail dipanggil, error baru muncul. Lebih baik handle sejak awal.
2. **Auth hardcoded** — username/password SMTP ditulis langsung di kode. Gunakan environment variables dan ConfigService.
3. **HTML tanpa fallback text** — beberapa email client hanya menampilkan plain text. Selalu sertakan `text` version.
4. **Transporter dibuat ulang setiap request** — Nodemailer transporter mahal untuk dibuat. Pastikan singleton (NestJS sudah menjamin ini dengan @Injectable()).
5. **Lupa set from name** — email masuk sebagai "noreply@library.com" tanpa nama, terlihat tidak profesional. Gunakan format `"Nama" <email>`.

## Hubungan dengan Materi Sebelumnya

Di **#59 (Email Processor)** kita telah menggunakan `EmailService` di processor. Sekarang kita implementasikan `EmailService` itu sendiri. Ini adalah **dependency inversion** yang baik: processor (high-level) bergantung pada abstraksi EmailService, bukan pada implementasi Nodemailer secara langsung. Di **#65** kita akan menambahkan template rendering, dan di **#66** kita akan membuat method-method spesifik untuk berbagai tipe email.

## Soal Latihan

**Soal:**
Konfigurasikan EmailService untuk menggunakan **AWS SES** sebagai transport (bukan SMTP biasa) ketika `MAIL_TRANSPORT=ses`. Gunakan `nodemailer.createTransport` dengan SES transport.

**Jawaban:**

```typescript
import * as nodemailer from 'nodemailer';

private initializeTransporter() {
  const transport = this.configService.get<string>('MAIL_TRANSPORT');

  if (transport === 'ses') {
    const ses = new (require('@aws-sdk/client-ses').SESClient)({
      region: this.configService.get<string>('AWS_REGION'),
      credentials: {
        accessKeyId: this.configService.get<string>('AWS_ACCESS_KEY_ID'),
        secretAccessKey: this.configService.get<string>('AWS_SECRET_ACCESS_KEY'),
      },
    });
    this.transporter = nodemailer.createTransport({
      SES: { ses, aws: require('@aws-sdk/client-ses') },
    });
  } else {
    // Default SMTP
    this.transporter = nodemailer.createTransport({
      host: this.configService.get<string>('email.host'),
      port: this.configService.get<number>('email.port'),
      secure: this.configService.get<boolean>('email.secure'),
      auth: { user, pass },
    });
  }
}
```
