# 99. Membuat Book Type & Resolver - Query dan Mutation

## Penjelasan
Di GraphQL, **Type** mendefinisikan bentuk data yang bisa di-query, **Query** adalah operasi baca (setara GET di REST), dan **Mutation** adalah operasi tulis (setara POST/PUT/DELETE). Di NestJS Code-First, kita membuat Type dengan decorator `@ObjectType()` dan `@Field()`, Query dengan decorator `@Query()` di Resolver, dan Mutation dengan `@Mutation()`. Resolver adalah class yang mirip dengan Controller di REST — tempat handler query/mutation ditulis.

**BookType** akan mendefinisikan field-field buku yang bisa di-query client: `id`, `title`, `author`, `isbn`, `category`, `createdAt`. Client bisa meminta subset field ini — misal hanya `{ title, author }` — dan GraphQL hanya akan mengembalikan itu. **BooksResolver** akan memiliki `@Query(() => [BookType])` untuk daftar buku, `@Query(() => BookType)` untuk detail buku, dan `@Mutation(() => BookType)` untuk create/update/delete. Kita juga bisa menggunakan **Guards** (dari Level 3) di GraphQL — baik di level resolver maupun per query/mutation — untuk melindungi operasi yang memerlukan autentikasi atau role tertentu. Bedanya, di GraphQL kita menggunakan `@UseGuards()` di method resolver, dan context GraphQL berisi `req` object yang sama dengan REST.

## Fungsi
- Mendefinisikan schema GraphQL untuk entity Book — client tahu persis data apa yang tersedia
- Menyediakan query untuk membaca data buku dengan fleksibilitas tinggi
- Menyediakan mutation untuk membuat, memperbarui, dan menghapus buku
- Mengintegrasikan autentikasi (Guards) ke dalam resolver GraphQL

import { ObjectType, Field, ID, Int, registerEnumType } from '@nestjs/graphql';
import { BookStatus } from '@prisma/client';

// Register enum dari Prisma ke GraphQL
registerEnumType(BookStatus, {
  name: 'BookStatus',
  description: 'Status ketersediaan buku',
});

@ObjectType({ description: 'Data buku perpustakaan' })
export class BookType {
  @Field(() => ID)
  id: string;

  @Field({ description: 'Judul buku' })
  title: string;

  @Field({ description: 'Nama penulis' })
  author: string;

  @Field({ nullable: true, description: 'ISBN buku (jika tersedia)' })
  isbn?: string;

  @Field(() => Int, { nullable: true, description: 'Tahun terbit' })
  publishedYear?: number;

  @Field(() => BookStatus, {
    defaultValue: 'AVAILABLE',
    description: 'Status ketersediaan',
  })
  status: BookStatus;

  @Field(() => CategoryType, { description: 'Kategori buku' })
  category: CategoryType;

  @Field({ description: 'Waktu dibuat' })
  createdAt: Date;

  @Field({ description: 'Waktu terakhir diperbarui' })
  updatedAt: Date;
}

@ObjectType({ description: 'Kategori buku' })
export class CategoryType {
  @Field(() => ID)
  id: string;

  @Field({ description: 'Nama kategori' })
  name: string;

  @Field(() => [BookType], { nullable: 'items' })
  books?: BookType[];
}

**4. Books Resolver — books.resolver.ts:**
```typescript
import { Resolver, Query, Mutation, Args, Int, Context } from '@nestjs/graphql';
import { UseGuards } from '@nestjs/common';
import { BooksService } from './books.service';
import { BookType, BookPaginationResult } from './book.type';
import { CreateBookInput, UpdateBookInput } from './book.input';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { RolesGuard } from '../auth/guards/roles.guard';
import { Roles } from '../auth/decorators/roles.decorator';
import { Role } from '@prisma/client';

@Resolver(() => BookType)
export class BooksResolver {
  constructor(private readonly booksService: BooksService) {}

  // ============ QUERIES ============

  @Query(() => BookPaginationResult, {
    name: 'books',
    description: 'Mendapatkan daftar buku dengan pagination',
  })
  async getBooks(
    @Args('page', { type: () => Int, nullable: true, defaultValue: 1 }) page: number,
    @Args('limit', { type: () => Int, nullable: true, defaultValue: 20 }) limit: number,
    @Args('categoryId', { nullable: true }) categoryId?: string,
  ) {
    return this.booksService.findAll({ page, limit, categoryId });
  }

  @Query(() => BookType, {
    name: 'book',
    nullable: true,
    description: 'Mendapatkan detail buku berdasarkan ID',
  })
  async getBook(@Args('id', { type: () => String }) id: string) {
    return this.booksService.findById(id);
  }

  @Query(() => [BookType], {
    name: 'searchBooks',
    description: 'Mencari buku berdasarkan judul atau penulis',
  })
  async searchBooks(@Args('query') query: string) {
    return this.booksService.search(query);
  }

  // ============ MUTATIONS ============

  @Mutation(() => BookType, {
    name: 'createBook',
    description: 'Membuat buku baru (Admin & Staff only)',
  })
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles(Role.ADMIN, Role.STAFF)
  async createBook(
    @Args('input') input: CreateBookInput,
    @Context() context: any,
  ) {
    // context.req.user tersedia karena JwtAuthGuard
    console.log(`Book created by user: ${context.req.user?.email}`);
    return this.booksService.create(input);
  }

  @Mutation(() => BookType, {
    name: 'updateBook',
    description: 'Memperbarui data buku (Admin only)',
  })
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles(Role.ADMIN)
  async updateBook(
    @Args('id') id: string,
    @Args('input') input: UpdateBookInput,
  ) {
    return this.booksService.update(id, input);
  }

  @Mutation(() => Boolean, {
    name: 'deleteBook',
    description: 'Menghapus buku (Admin only)',
  })
  @UseGuards(JwtAuthGuard, RolesGuard)
  @Roles(Role.ADMIN)
  async deleteBook(@Args('id') id: string) {
    await this.booksService.delete(id);
    return true;
  }
}
```

**5. Books Service — books.service.ts (sama seperti REST):**
```typescript
import { Injectable, NotFoundException } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';
import { CreateBookInput, UpdateBookInput } from './book.input';

@Injectable()
export class BooksService {
  constructor(private readonly prisma: PrismaService) {}

  async findAll(params: { page: number; limit: number; categoryId?: string }) {
    const { page, limit, categoryId } = params;
    const skip = (page - 1) * limit;
    const where = categoryId ? { categoryId } : {};

    const [data, total] = await Promise.all([
      this.prisma.book.findMany({
        where,
        skip,
        take: limit,
        include: { category: true },
        orderBy: { createdAt: 'desc' },
      }),
      this.prisma.book.count({ where }),
    ]);

    return {
      data,
      meta: {
        page,
        limit,
        total,
        totalPages: Math.ceil(total / limit),
      },
    };
  }

  async findById(id: string) {
    const book = await this.prisma.book.findUnique({
      where: { id },
      include: { category: true },
    });
    if (!book) throw new NotFoundException(`Book ${id} not found`);
    return book;
  }

  async search(query: string) {
    return this.prisma.book.findMany({
      where: {
        OR: [
          { title: { contains: query, mode: 'insensitive' } },
          { author: { contains: query, mode: 'insensitive' } },
        ],
      },
      include: { category: true },
    });
  }

  async create(input: CreateBookInput) {
    return this.prisma.book.create({
      data: {
        title: input.title,
        author: input.author,
        isbn: input.isbn,
        publishedYear: input.publishedYear,
        categoryId: input.categoryId,
      },
      include: { category: true },
    });
  }

  async update(id: string, input: UpdateBookInput) {
    await this.findById(id);
    return this.prisma.book.update({
      where: { id },
      data: input,
      include: { category: true },
    });
  }

  async delete(id: string) {
    await this.findById(id);
    await this.prisma.book.delete({ where: { id } });
  }
}
```

## Analogi
Bayangkan perpustakaan memiliki **katalog digital interaktif** (GraphQL Playground). Type adalah **formulir data buku** yang sudah dicetak: ada kolom ID, Judul, Penulis, Kategori, dll. Query adalah **permintaan pengunjung**: "saya ingin daftar buku fiksi, cukup judul dan penulisnya saja" — petugas cukup mengisi kolom yang diminta Mutation adalah **formulir perubahan** — pengunjung yang juga staf perpustakaan bisa mengisi formulir "Tambah Buku Baru" (createBook) atau "Hapus Buku Rusak" (deleteBook). Tapi formulir ini hanya boleh diakses oleh staf dengan **lencana khusus** (@UseGuards + @Roles) — pengunjung biasa tidak bisa mengaksesnya. Resolver adalah **petugas katalog** yang menerima formulir, memprosesnya ke database (BooksService), dan mengembalikan hasilnya.

## Penggunaan
- API publik untuk aplikasi mobile perpustakaan — aplikasi hanya request data yang ditampilkan di layar
- Admin dashboard untuk mengelola katalog buku — mutation create/update/delete
- Front-end React/Vue yang ingin fetching data kompleks dalam satu request (book + category + loans)
- Integrasi third-party yang membutuhkan fleksibilitas query

## Kesalahan Umum yang Sering Terjadi
1. **Lupa dekorator @Field()** — Property tanpa `@Field()` tidak akan muncul di schema GraphQL. Jika properti ada di TypeScript class tapi tidak di-export, graphql akan skip.
2. **Resolver tidak di-register di module** — Setiap resolver harus masuk ke `providers` di module, bukan `controllers`.
3. **Circular dependency** — BookType reference CategoryType, CategoryType reference [BookType]. Jika terjadi error, gunakan `@Field(() => [BookType], { nullable: 'items' })` atau `() => BookType` (lazy).
4. **Guard tidak jalan** — Guards di GraphQL sama seperti di REST, tapi perlu memastikan `context.req` tersedia. Di konfigurasi GraphQL, `context: ({ req }) => ({ req })`.
5. **N+1 problem** — Query `books { category { name } }` memanggil resolver category untuk setiap buku. Solusi: DataLoader (materi 100).

## Hubungan dengan Materi Sebelumnya
Resolver di sini menggantikan Controller dari REST API di Level 1. Service, Prisma, Guards, dan decorator @Roles dari Level 3 tetap digunakan. Perbedaan utama: input validation menggunakan `@Args()` dan `@InputType()` menggantikan `@Body()` DTO. Setelah resolver berfungsi, masalah N+1 di GraphQL harus diselesaikan dengan DataLoader (materi 100).

## Soal Latihan

**Soal:** Buatlah resolver method baru `@Query(() => [BookType])` bernama `recentBooks` yang menerima argumen `@Args('days', { type: () => Int })` dan mengembalikan buku yang dibuat dalam jumlah hari terakhir. Implementasikan juga di service.

**Jawaban:**
```typescript
// books.resolver.ts
@Query(() => [BookType], {
  name: 'recentBooks',
  description: 'Mendapatkan buku yang baru ditambahkan dalam N hari terakhir',
})
async getRecentBooks(
  @Args('days', { type: () => Int }) days: number,
) {
  return this.booksService.findRecent(days);
}
```

```typescript
// books.service.ts
async findRecent(days: number) {
  const since = new Date();
  since.setDate(since.getDate() - days);

  return this.prisma.book.findMany({
    where: {
      createdAt: { gte: since },
    },
    include: { category: true },
    orderBy: { createdAt: 'desc' },
  });
}
```
