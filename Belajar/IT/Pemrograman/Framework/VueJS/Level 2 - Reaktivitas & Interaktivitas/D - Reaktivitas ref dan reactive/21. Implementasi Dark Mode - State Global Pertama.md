# 21. Implementasi Dark Mode — State Global Pertama

## Penjelasan

Dark mode adalah **state global** yang pertama kita buat. Implementasinya menggunakan:

- **Tailwind CSS** dengan strategi `darkMode: 'class'`
- Toggle class `dark` di elemen `<html>`
- **Composable** `useDarkMode` untuk reusable logic
- **localStorage** untuk persistensi preferensi user

```ts
// tailwind.config.js
module.exports = {
  darkMode: 'class', // <-- penting!
}
```

```css
/* CSS Tailwind — cukup pakai class dark: */
<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100">
```

## Fungsi

Membuat state global (`isDark`) yang bisa diakses dari komponen mana pun, dengan persistensi dan sinkronisasi otomatis ke DOM.

## Cara Implementasi

### 1. Buat `src/composables/useDarkMode.ts`

```ts
import { ref, watchEffect } from 'vue'

const isDark = ref(false)

// Load dari localStorage saat inisialisasi
const saved = localStorage.getItem('bookstore-dark-mode')
if (saved !== null) {
  isDark.value = JSON.parse(saved)
} else {
  // Default: preferensi sistem
  isDark.value = window.matchMedia('(prefers-color-scheme: dark)').matches
}

export function useDarkMode() {
  // Sinkronisasi isDark → class <html> + localStorage
  watchEffect(() => {
    const html = document.documentElement
    if (isDark.value) {
      html.classList.add('dark')
    } else {
      html.classList.remove('dark')
    }
    localStorage.setItem('bookstore-dark-mode', JSON.stringify(isDark.value))
  })

  function toggleDark() {
    isDark.value = !isDark.value
  }

  return {
    isDark: isDark,       // readonly di luar
    toggleDark,
  }
}
```

### 2. Gunakan di Komponen

```vue
<!-- src/components/Header.vue -->
<script setup lang="ts">
import { useDarkMode } from '../composables/useDarkMode'

const { isDark, toggleDark } = useDarkMode()
</script>

<template>
  <header
    class="bg-white dark:bg-gray-800 border-b dark:border-gray-700 p-4"
  >
    <div class="flex items-center justify-between">
      <h1 class="text-xl font-bold dark:text-white">📚 Toko Buku</h1>

      <button
        @click="toggleDark"
        class="px-4 py-2 rounded bg-gray-200 dark:bg-gray-600
               text-gray-800 dark:text-gray-200"
      >
        {{ isDark ? '☀️ Terang' : '🌙 Gelap' }}
      </button>
    </div>
  </header>
</template>
```

### 3. Contoh Halaman dengan Dark Mode

```vue
<!-- src/views/Home.vue -->
<script setup lang="ts">
import { ref, computed } from 'vue'
import { useDarkMode } from '../composables/useDarkMode'

const { isDark } = useDarkMode()
const searchQuery = ref('')

const books = ref([
  { title: 'Vue 3 Dasar', price: 75000 },
  { title: 'TypeScript Handbook', price: 85000 },
])

const filteredBooks = computed(() =>
  books.value.filter(b =>
    b.title.toLowerCase().includes(searchQuery.value.toLowerCase())
  )
)
</script>

<template>
  <main
    class="min-h-screen bg-gray-50 dark:bg-gray-900
           text-gray-900 dark:text-gray-100 p-6"
  >
    <input
      v-model="searchQuery"
      placeholder="Cari buku..."
      class="w-full p-3 rounded border dark:border-gray-600
             bg-white dark:bg-gray-800 dark:text-white"
    />

    <div
      v-for="book in filteredBooks"
      :key="book.title"
      class="mt-4 p-4 rounded bg-white dark:bg-gray-800
             shadow dark:shadow-gray-700"
    >
      <h3 class="dark:text-white">{{ book.title }}</h3>
      <p class="dark:text-gray-300">
        Rp{{ book.price.toLocaleString() }}
      </p>
    </div>
  </main>
</template>
```

## Analogi — Toko Buku

Dark mode seperti **"mode malam"** toko buku — lampu utama dimatikan, lampu baca lembut dinyalakan, warna dinding berubah dari putih ke gelap.

Satu tombol mengubah **SUASANA SELURUH TOKO**. Ini adalah **state global pertama** kita — diakses dari mana saja (header, halaman manapun), cukup dengan memanggil `useDarkMode()`.

## Dipakai untuk apa

- **Dark mode / theme toggle** di seluruh aplikasi
- State global sederhana (preferensi user)
- Sinkronisasi preferensi ke DOM + localStorage
- Dasar pola **composable + state singleton** untuk global state

## Kesalahan Umum

| ❌ Salah | ✅ Benar |
|----------|----------|
| `darkMode: 'media'` (ikuti sistem — user tidak bisa toggle) | `darkMode: 'class'` |
| Class dark di `<body>` atau komponen | Class dark harus di **`<html>`** karena Tailwind membaca parent |
| Membuat `isDark` lokal di setiap komponen | Gunakan composable dengan **state singleton** (luar fungsi) |
| Lupa import Tailwind directives di CSS | Pastikan `@tailwind base; @tailwind components; @tailwind utilities;` |
| Toggle manual tanpa simpan preferensi | Simpan ke localStorage agar persisten saat reload |

```ts
// ❌ State lokal — setiap komponen punya state sendiri
export function useDarkMode() {
  const isDark = ref(false) // <- BURUK: setiap komponen bikin baru
  // ...
}

// ✅ State singleton — semua komponen pakai state yang sama
const isDark = ref(false) // <- BAIK: di luar fungsi, hanya 1 instance
export function useDarkMode() {
  // ...
}
```

## Hubungan dengan Materi Sebelumnya

**Poin 20**: `watchEffect` digunakan di dalam `useDarkMode` untuk **sinkronisasi otomatis** — setiap kali `isDark` berubah, class `<html>` dan localStorage ikut berubah tanpa perlu manual.

**Point 16-19**: Semua komponen yang sudah kita buat (filter, search, computed) akan otomatis menyesuaikan tema karena Tailwind CSS class `dark:` merespon class di `<html>`.

**Level 1 → Level 2**: Di Level 1 UI statis, dark mode tidak mungkin karena tidak ada reaktivitas. Sekarang, dengan ref + watchEffect + composable, kita punya sistem tema yang responsif dan persisten.

## Soal Latihan

### Soal 1

Buat composable `useFontSize` yang menyimpan state global `fontSize` ('kecil', 'sedang', 'besar') ke localStorage dan menambahkan class `text-sm`, `text-base`, atau `text-lg` ke `<html>`.

<details>
<summary>Jawaban</summary>

```ts
// src/composables/useFontSize.ts
import { ref, watchEffect } from 'vue'

type FontSize = 'kecil' | 'sedang' | 'besar'

const fontSize = ref<FontSize>('sedang')

const saved = localStorage.getItem('bookstore-font-size')
if (saved && ['kecil', 'sedang', 'besar'].includes(saved)) {
  fontSize.value = saved as FontSize
}

export function useFontSize() {
  watchEffect(() => {
    const html = document.documentElement
    html.classList.remove('text-sm', 'text-base', 'text-lg')

    const map: Record<FontSize, string> = {
      kecil: 'text-sm',
      sedang: 'text-base',
      besar: 'text-lg',
    }
    html.classList.add(map[fontSize.value])
    localStorage.setItem('bookstore-font-size', fontSize.value)
  })

  function setFontSize(size: FontSize) {
    fontSize.value = size
  }

  return { fontSize, setFontSize }
}
```
</details>
