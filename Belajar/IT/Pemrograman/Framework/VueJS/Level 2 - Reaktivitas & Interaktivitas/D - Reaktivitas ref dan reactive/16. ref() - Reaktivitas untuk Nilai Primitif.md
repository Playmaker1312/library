# 16. `ref()` — Reaktivitas untuk Nilai Primitif

## Penjelasan

`ref()` adalah fungsi Vue 3 yang membungkus nilai primitif (string, number, boolean, dsb.) menjadi **reaktif**. Di dalam `<script>`, data ref diakses melalui **`.value`**. Di dalam **template**, Vue secara otomatis melakukan **auto-unwrap** — kamu bisa menulis `searchQuery` saja tanpa `.value`.

```ts
import { ref } from 'vue'

const searchQuery = ref('')   // Ref<string>
const count = ref(0)          // Ref<number>
const isOpen = ref(true)      // Ref<boolean>
```

## Fungsi

Membuat data yang perubahannya **memicu re-render** komponen. Tanpa `ref`, perubahan data tidak akan terlihat di layar.

## Cara Implementasi

```vue
<script setup lang="ts">
import { ref } from 'vue'

const searchQuery = ref('')
const count = ref(0)

function increment() {
  count.value++
}

function clearSearch() {
  searchQuery.value = ''
}
</script>

<template>
  <div>
    <input v-model="searchQuery" placeholder="Cari buku..." />

    <p>Kamu mencari: {{ searchQuery }}</p>

    <button @click="increment">
      Dicari {{ count }} kali
    </button>

    <button @click="clearSearch">Hapus pencarian</button>
  </div>
</template>
```

## Analogi — Toko Buku

`ref()` seperti **sensor di rak buku**. Dulu di Level 1, rak buku itu statis — kalau buku dipindah, tidak ada yang tahu. Sekarang, setiap rak (ref) punya sensor — saat buku ditaruh atau diambil, sensor berbunyi dan sistem (Vue) langsung memperbarui katalog di layar.

- `.value` di script seperti "cek sensor secara manual"
- Auto-unwrap di template seperti Vue otomatis membaca sensor tanpa kamu sentuh

## Dipakai untuk apa

- Input search / filter
- Counter, toggle (boolean)
- Nilai form: nama, email, password
- State loading, error, status

## Kesalahan Umum

| ❌ Salah | ✅ Benar |
|----------|----------|
| `searchQuery = 'buku'` (di script) | `searchQuery.value = 'buku'` |
| Lupa `import { ref } from 'vue'` | Import ref dari Vue |
| Menulis `.value` di template | Langsung `{{ searchQuery }}` |

## Hubungan dengan Materi Sebelumnya

**Level 1**: Data buku adalah `const books: Book[] = [...]` — array biasa. Kalau diubah, tampilan **tidak berubah**.

**Sekarang**: Dengan `ref`, Vue akan **otomatis update tampilan** saat data berubah. Inilah fondasi reaktivitas Vue.

**Poin 17 nanti**: `v-model` adalah cara paling umum mengisi nilai ref dari input user.

## Soal Latihan

### Soal 1

Buat sebuah komponen dengan `ref` untuk menyimpan `judulBuku` (string) dan `harga` (number). Tampilkan keduanya di template dan buat tombol yang menaikkan harga sebesar 5000.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref } from 'vue'

const judulBuku = ref('Pemrograman Vue 3')
const harga = ref(85000)

function naikkanHarga() {
  harga.value += 5000
}
</script>

<template>
  <div>
    <h2>{{ judulBuku }}</h2>
    <p>Harga: Rp{{ harga.toLocaleString() }}</p>
    <button @click="naikkanHarga">Naikkan harga Rp5.000</button>
  </div>
</template>
```
</details>

### Soal 2

Buat komponen dengan `ref` boolean `isStockReady`. Tampilkan teks "Stok Siap" jika `true`, dan "Stok Belum Siap" jika `false`. Ada tombol untuk toggle.

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { ref } from 'vue'

const isStockReady = ref(false)

function toggleStock() {
  isStockReady.value = !isStockReady.value
}
</script>

<template>
  <div>
    <p>{{ isStockReady ? 'Stok Siap' : 'Stok Belum Siap' }}</p>
    <button @click="toggleStock">Toggle Status Stok</button>
  </div>
</template>
```
</details>
