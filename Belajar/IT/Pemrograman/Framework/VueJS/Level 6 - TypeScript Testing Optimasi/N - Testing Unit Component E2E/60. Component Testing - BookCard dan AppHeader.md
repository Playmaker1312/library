# 60. Component Testing — `BookCard` dan `AppHeader`

## Penjelasan

**Component test** menguji komponen Vue yang sudah dimount di lingkungan headless (jsdom) dengan `@vue/test-utils`. Berbeda dengan unit test yang hanya menguji logic, component test memverifikasi **render, props, event, dan interaksi user** pada komponen nyata.

## Fungsi

- Memastikan komponen merender data dengan benar (title, price, badge)
- Memverifikasi event emission saat user berinteraksi (klik, input)
- Mendeteksi visual regression dari segi logic (stok habis, harga diskon)
- Menguji komponen dalam kondisi berbeda (loading, empty, error state)

### 3. Komponen: `BookCard.vue`

```vue
<!-- src/components/features/BookCard.vue -->
<script setup lang="ts">
defineProps<{
  id: number
  title: string
  author: string
  price: number
  stock: number
}>()

const emit = defineEmits<{
  (e: 'add-to-cart', id: number): void
}>()
</script>

<template>
  <div class="book-card" data-testid="book-card">
    <h3 data-testid="title">{{ title }}</h3>
    <p data-testid="author">{{ author }}</p>
    <p data-testid="price">Rp {{ price.toLocaleString('id-ID') }}</p>
    <span v-if="stock === 0" class="badge badge--out" data-testid="badge">
      Stok Habis
    </span>
    <span v-else class="badge badge--avail" data-testid="badge">
      Tersedia ({{ stock }})
    </span>
    <button
      :disabled="stock === 0"
      data-testid="add-btn"
      @click="emit('add-to-cart', id)"
    >
      {{ stock === 0 ? 'Habis' : 'Tambah ke Keranjang' }}
    </button>
  </div>
</template>
```

### 4. Test: `BookCard`

```typescript
// src/components/features/__tests__/BookCard.spec.ts
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import BookCard from '../BookCard.vue'

describe('BookCard', () => {
  const props = {
    id: 1,
    title: 'Vue.js untuk Pemula',
    author: 'Andi Pratama',
    price: 85000,
    stock: 5,
  }

  it('merender title dan author dengan benar', () => {
    const wrapper = mount(BookCard, { props })
    expect(wrapper.find('[data-testid="title"]').text()).toBe('Vue.js untuk Pemula')
    expect(wrapper.find('[data-testid="author"]').text()).toBe('Andi Pratama')
  })

  it('menampilkan harga dalam format Rupiah', () => {
    const wrapper = mount(BookCard, { props })
    expect(wrapper.find('[data-testid="price"]').text()).toContain('85.000')
  })

  it('menampilkan badge "Stok Habis" jika stock = 0', () => {
    const wrapper = mount(BookCard, { ...props, props: { ...props, stock: 0 } })
    expect(wrapper.find('[data-testid="badge"]').text()).toBe('Stok Habis')
  })

  it('tombol disabled jika stok habis', () => {
    const wrapper = mount(BookCard, { ...props, props: { ...props, stock: 0 } })
    expect(wrapper.find('[data-testid="add-btn"]').attributes('disabled')).toBeDefined()
  })

  it('emit "add-to-cart" dengan id saat tombol diklik', () => {
    const wrapper = mount(BookCard, { props })
    wrapper.find('[data-testid="add-btn"]').trigger('click')
    expect(wrapper.emitted('add-to-cart')).toBeTruthy()
    expect(wrapper.emitted('add-to-cart')![0]).toEqual([1])
  })

  it('tidak emit "add-to-cart" jika stok habis', () => {
    const wrapper = mount(BookCard, { ...props, props: { ...props, stock: 0 } })
    wrapper.find('[data-testid="add-btn"]').trigger('click')
    expect(wrapper.emitted('add-to-cart')).toBeFalsy()
  })
})
```

### 5. Test: `AppHeader` (dengan Pinia)

```vue
<!-- src/components/layout/AppHeader.vue -->
<script setup lang="ts">
import { useCartStore } from '@/stores/cart.store'
import { useAuthStore } from '@/stores/auth.store'

const cart = useCartStore()
const auth = useAuthStore()
</script>

<template>
  <header>
    <span data-testid="logo">BookStore</span>
    <span data-testid="cart-count">Cart: {{ cart.totalItems }}</span>
    <span v-if="auth.isAuthenticated" data-testid="username">
      {{ auth.user?.name }}
    </span>
    <button v-else data-testid="login-btn">Login</button>
  </header>
</template>
```

```typescript
// src/components/layout/__tests__/AppHeader.spec.ts
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import { createPinia, setActivePinia } from 'pinia'
import { useCartStore } from '@/stores/cart.store'
import { useAuthStore } from '@/stores/auth.store'
import AppHeader from '../AppHeader.vue'

describe('AppHeader', () => {
  beforeEach(() => {
    setActivePinia(createPinia())
  })

  it('menampilkan cart count 0 saat belum ada item', () => {
    const wrapper = mount(AppHeader, {
      global: { plugins: [createPinia()] },
    })
    expect(wrapper.find('[data-testid="cart-count"]').text()).toContain('0')
  })

  it('menampilkan cart count sesuai jumlah item di store', () => {
    const cart = useCartStore()
    cart.addItem({ id: 1, title: 'Vue', price: 50000, quantity: 1 })
    const wrapper = mount(AppHeader, {
      global: { plugins: [createPinia()] },
    })
    expect(wrapper.find('[data-testid="cart-count"]').text()).toContain('1')
  })

  it('menampilkan username jika sudah login', () => {
    const auth = useAuthStore()
    auth.setAuth({ id: 1, name: 'Budi' })
    const wrapper = mount(AppHeader, {
      global: { plugins: [createPinia()] },
    })
    expect(wrapper.find('[data-testid="username"]').text()).toBe('Budi')
  })

  it('menampilkan tombol Login jika belum login', () => {
    const wrapper = mount(AppHeader, {
      global: { plugins: [createPinia()] },
    })
    expect(wrapper.find('[data-testid="login-btn"]').exists()).toBe(true)
  })
})
```

## Analogi — Toko Buku

Kalau composable test adalah **uji mesin kasir di bengkel**, component test adalah **uji mesin kasir yang SUDAH DIPASANG di toko** — lengkap dengan layar, tombol, dan koneksi ke papan informasi (store).

Kita cek:
- *"Apakah tampilan harga muncul?"* → render prop price
- *"Kalau tombol diskon ditekan, apakah layar berubah?"* → event → state
- *"Apakah lampu indikator 'Stok Habis' menyala?"* → conditional rendering
- *"Kalau tidak ada stok, apakah tombol mati?"* → disabled attribute

Semua komponen toko diuji dalam lingkungan yang **mirip toko asli** tapi tanpa pelanggan sungguhan.

## Dipakai untuk Apa

- Validasi render setiap komponen UI (card, form, modal, table)
- Test interaksi user (klik, hover, type, drag)
- Test conditional rendering (loading/empty/error state)
- Test komponen yang bergantung pada store, router, atau plugin

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| Lupa setup Pinia | `getActivePinia() was called but there was no active Pinia` | Gunakan `global.plugins: [createPinia()]` |
| Test terlalu detail (class CSS) | Patah saat styling berubah | Gunakan `data-testid` untuk binding test |
| Tidak `await` trigger async | Event belum selesai diproses | `await wrapper.find('button').trigger('click')` |
| Mock reactive ref secara manual | Kompleks dan rawan error | Isi store langsung, jangan mock komponen |

## Hubungan dengan Materi Sebelumnya

- **Poin 59 (Unit Test Composables)**: Composable test hanya verifikasi logic. Component test melangkah lebih jauh — memverifikasi bahwa logic tersebut **terintegrasi dengan template dan DOM**.
- **Level 2 (Komponen)**: Komponen `BookCard` dan `AppHeader` dibuat di level tersebut. Sekarang kita pastikan mereka bekerja dalam berbagai skenario.
- **Level 4 (State Management)**: Store Pinia yang terhubung ke komponen (via `useCartStore`) diuji interaksinya — apakah komponen merespons perubahan store dengan benar.

### Soal 1

Buat component test untuk `SearchBar.vue` yang memiliki:
- `input[type="text"]` dengan `v-model` terikat ke ref `query`
- Emit `search(query: string)` saat tombol diklik
- Tombol disabled jika query kosong

<details>
<summary>Jawaban</summary>

```typescript
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import SearchBar from '../SearchBar.vue'

describe('SearchBar', () => {
  it('tombol disabled jika input kosong', async () => {
    const wrapper = mount(SearchBar)
    const btn = wrapper.find('[data-testid="search-btn"]')
    expect(btn.attributes('disabled')).toBeDefined()
  })

  it('tombol enabled jika input terisi', async () => {
    const wrapper = mount(SearchBar)
    await wrapper.find('input').setValue('Vue')
    const btn = wrapper.find('[data-testid="search-btn"]')
    expect(btn.attributes('disabled')).toBeUndefined()
  })

  it('emit search dengan query saat submit', async () => {
    const wrapper = mount(SearchBar)
    await wrapper.find('input').setValue('Vue.js')
    await wrapper.find('[data-testid="search-btn"]').trigger('click')
    expect(wrapper.emitted('search')).toBeTruthy()
    expect(wrapper.emitted('search')![0]).toEqual(['Vue.js'])
  })
})
```

### Soal 2

Buat component test untuk `BookCard` yang menguji: badge berubah dari "Stok Habis" menjadi "Tersedia (3)" saat prop `stock` berubah dari 0 menjadi 3.

<details>
<summary>Jawaban</summary>

```typescript
import { describe, it, expect } from 'vitest'
import { mount } from '@vue/test-utils'
import BookCard from '../BookCard.vue'

describe('BookCard — reaktivitas stock', () => {
  it('badge berubah saat stock diupdate', async () => {
    const wrapper = mount(BookCard, {
      props: {
        id: 1,
        title: 'Test',
        author: 'Penulis',
        price: 50000,
        stock: 0,
      },
    })

    // Awal: stok habis
    expect(wrapper.find('[data-testid="badge"]').text()).toBe('Stok Habis')
    expect(wrapper.find('[data-testid="add-btn"]').attributes('disabled')).toBeDefined()

    // Update stok jadi 3
    await wrapper.setProps({ stock: 3 })
    expect(wrapper.find('[data-testid="badge"]').text()).toContain('Tersedia')
    expect(wrapper.find('[data-testid="badge"]').text()).toContain('3')
    expect(wrapper.find('[data-testid="add-btn"]').attributes('disabled')).toBeUndefined()
  })
})
```
</details>
