# 62. E2E Testing dengan Playwright — User Journey Lengkap

## Penjelasan

**E2E (End-to-End) test** mensimulasikan pengalaman **user nyata** — membuka browser sungguhan (Chromium/Firefox/WebKit), mengetik, mengklik, dan memverifikasi halaman. Berbeda dengan unit/component test yang berjalan di Node.js, E2E test menggunakan **Playwright** untuk mengotomatisasi browser.

Hirarki testing:

```
Unit Test ──► Component Test ──► E2E Test
(korek api)     (kaca pembesar)     (teropong)
```

## Fungsi

- Mensimulasikan user journey dari awal sampai akhir (smoke test)
- Memverifikasi integrasi antar halaman, API, dan database
- Mendeteksi regression yang tidak tertangkap unit/component test
- Validasi deployment/production environment

## Cara Implementasi

### 1. Install Playwright

```bash
npm install -D @playwright/test
npx playwright install           # download browser
npx playwright install-deps      # dependencies system (Linux)
```

### 2. Konfigurasi


### 4. E2E Test: Shopping Flow Lengkap

```typescript
// e2e/shopping.spec.ts
import { test, expect } from '@playwright/test'

test.describe('Shopping Flow — Toko Buku', () => {
  test('user dapat browsing, mencari, menambah ke cart, dan checkout', async ({ page }) => {
    // 1. Buka halaman utama
    await page.goto('/')
    await expect(page.locator('h1')).toContainText('BookStore')

    // 2. Cari buku via search bar
    await page.fill('[data-testid="search-input"]', 'Vue')
    await page.click('[data-testid="search-btn"]')
    await expect(page.locator('[data-testid="book-card"]').first()).toBeVisible()

    // 3. Klik buku untuk lihat detail
    await page.click('[data-testid="book-card"] >> nth=0')
    await expect(page.locator('[data-testid="book-title"]')).toContainText('Vue')

    // 4. Tambah ke keranjang
    await page.click('[data-testid="add-to-cart-btn"]')
    await expect(page.locator('[data-testid="cart-count"]')).toContainText('1')

    // 5. Buka halaman cart
    await page.click('[data-testid="cart-link"]')
    await expect(page).toHaveURL(/\/cart/)
    await expect(page.locator('[data-testid="cart-item"]')).toHaveCount(1)

    // 6. Lanjut ke checkout
    await page.click('[data-testid="checkout-btn"]')
    await expect(page).toHaveURL(/\/checkout/)

    // 7. Isi form checkout
    await page.fill('[data-testid="name-input"]', 'Budi')
    await page.fill('[data-testid="address-input"]', 'Jl. Merdeka No.1')
    await page.click('[data-testid="submit-order-btn"]')

    // 8. Konfirmasi
    await expect(page.locator('[data-testid="order-success"]')).toBeVisible()
    await expect(page.locator('[data-testid="order-success"]')).toContainText('Pesanan Berhasil')
  })
})
```

### 5. E2E Test: Auth Flow

```typescript
// e2e/auth.spec.ts
import { test, expect } from '@playwright/test'

test.describe('Auth Flow', () => {
  test('user dapat login dan melihat profil', async ({ page }) => {
    await page.goto('/login')

    await page.fill('[data-testid="email-input"]', 'user@tokobuku.com')
    await page.fill('[data-testid="password-input"]', 'password123')
    await page.click('[data-testid="login-submit"]')

    // Redirect ke halaman utama
    await expect(page).toHaveURL('/')
    await expect(page.locator('[data-testid="username"]')).toContainText('Budi')
  })

  test('user yang belum login diarahkan ke login saat akses /cart', async ({ page }) => {
    await page.goto('/cart')
    await expect(page).toHaveURL(/\/login/)
  })

  test('user dapat logout', async ({ page }) => {
    // Login dulu
    await page.goto('/login')
    await page.fill('[data-testid="email-input"]', 'user@tokobuku.com')
    await page.fill('[data-testid="password-input"]', 'password123')
    await page.click('[data-testid="login-submit"]')

    // Logout
    await page.click('[data-testid="logout-btn"]')
    await expect(page.locator('[data-testid="username"]')).not.toBeVisible()
    await expect(page.locator('[data-testid="login-btn"]')).toBeVisible()
  })
})
```

## Analogi — Toko Buku

- **Unit test** = uji mesin kasir di bengkel
- **Component test** = uji mesin kasir yang sudah dipasang di toko
- **E2E test** = **SURVEY PELANGGAN**

Seseorang masuk toko, cari buku di rak, baca deskripsi, tambah ke keranjang, pergi ke kasir, bayar, dan keluar. Ini test **PALING NYATA** — apakah seluruh flow toko berfungsi dari awal sampai akhir?

Playwright adalah **"pengunjung robot"** yang melakukan semua langkah secara otomatis dan melaporkan jika ada yang rusak. Jika pintu masuk macet (halaman tidak load) atau kasir error (tombol checkout tidak bekerja), robot akan berteriak: **"FLOW RUSAK!"**

## Dipakai untuk Apa

- **Smoke test** — memastikan fitur utama aplikasi berfungsi setelah deploy
- **Regression test** — deteksi otomatis saat perubahan kode merusak flow yang sudah ada
- **Cross-browser testing** — verifikasi di Chrome, Firefox, Safari
- **User acceptance test (UAT)** — validasi persyaratan bisnis dari sudut pandang user
- **Performance sanity** — memastikan halaman tidak lambat secara ekstrem

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| **Flaky test** (kadang lolos, kadang tidak) | Test tidak bisa diandalkan | Gunakan auto-wait (`toHaveText`, `waitForSelector`), jangan `setTimeout` |
| Test terlalu panjang (>50 langkah) | Sulit debug saat gagal | Pisahkan per flow kecil (browse, cart, checkout) |
| Hardcoded selector (`div > button`) | Patah saat struktur DOM berubah | Gunakan `data-testid` |
| Tidak isolasi test | Satu test gagal = yang lain ikut gagal | Setiap test harus bisa jalan sendiri |
| Lupa setup/teardown data | Test bergantung pada data dari test sebelumnya | Gunakan `page.route()` untuk mock API, atau seed data di `beforeEach` |
| Test dependen pada API eksternal | Gagal jika server API down | Mock API dengan `page.route()` atau gunakan test environment sendiri |

### Tips Menghindari Flaky Test

```typescript
// ❌ Buruk — timeout manual
await page.waitForTimeout(2000)
await page.locator('.cart-count')

// ✅ Baik — auto-wait
await expect(page.locator('[data-testid="cart-count"]')).toContainText('1')

// ✅ Baik — waitForSelector
await page.waitForSelector('[data-testid="cart-count"]', { state: 'visible' })
```

## Hubungan dengan Materi Sebelumnya

- **Poin 59-61 (Unit, Component, Store Test)**: Tiga level sebelumnya memverifikasi bagian-bagian aplikasi secara terisolasi. E2E test adalah **lapisan terluar** yang memverifikasi semuanya bekerja bersama.
- **Level 1-5**: Semua fitur (daftar buku, search, cart, auth, checkout, routing, state management) — yang sudah dibangun dari Level 1 sampai 5 — sekarang diuji dalam satu kesatuan flow.
- **Covernote**: Unit test → "apakah fungsi hitung benar?" E2E test → "apakah user bisa beli buku sampai selesai?". Keduanya penting dan saling melengkapi.

## Soal Latihan

### Soal 1

Buat E2E test untuk skenario: user membuka halaman utama, memfilter buku berdasarkan kategori "Programming", dan memverifikasi hanya buku Programming yang tampil.

<details>
<summary>Jawaban</summary>

```typescript
import { test, expect } from '@playwright/test'

test.describe('Filter Kategori', () => {
  test('user dapat memfilter buku berdasarkan kategori', async ({ page }) => {
    await page.goto('/')

    // Pilih kategori
    await page.selectOption('[data-testid="category-select"]', 'Programming')

    // Tunggu hasil filter
    await expect(page.locator('[data-testid="book-card"]').first()).toBeVisible()

    // Verifikasi semua buku yang tampil adalah Programming
    const categories = await page.locator('[data-testid="book-category"]').allTextContents()
    for (const cat of categories) {
      expect(cat).toBe('Programming')
    }
  })

  test('filter kategori "Semua" menampilkan semua buku', async ({ page }) => {
    await page.goto('/')
    await page.selectOption('[data-testid="category-select"]', 'all')
    const count = await page.locator('[data-testid="book-card"]').count()
    expect(count).toBeGreaterThan(0)
  })
})
```

### Soal 2

Buat E2E test untuk validasi form checkout: jika nama kosong, tombol submit harus disabled dan pesan error muncul.

<details>
<summary>Jawaban</summary>

```typescript
import { test, expect } from '@playwright/test'

test.describe('Validasi Form Checkout', () => {
  test('tombol submit disabled jika nama kosong', async ({ page }) => {
    await page.goto('/checkout')

    // Field nama kosong
    await page.fill('[data-testid="name-input"]', '')
    await page.fill('[data-testid="address-input"]', 'Jl. Test')

    const submitBtn = page.locator('[data-testid="submit-order-btn"]')
    await expect(submitBtn).toBeDisabled()
  })

  test('pesan error muncul jika form tidak lengkap', async ({ page }) => {
    await page.goto('/checkout')
    await page.click('[data-testid="submit-order-btn"]')
    await expect(page.locator('[data-testid="error-name"]')).toBeVisible()
    await expect(page.locator('[data-testid="error-name"]')).toContainText('Nama wajib diisi')
  })

  test('form dapat disubmit jika semua field terisi', async ({ page }) => {
    await page.goto('/checkout')
    await page.fill('[data-testid="name-input"]', 'Budi')
    await page.fill('[data-testid="address-input"]', 'Jl. Merdeka No.1')
    await expect(page.locator('[data-testid="submit-order-btn"]')).toBeEnabled()
  })
})
```
