# 11. Class dan Style Binding Dinamis

## Penjelasan

Di dunia nyata, tampilan elemen sering berubah berdasarkan data. Vue menyediakan cara deklaratif untuk mengikat class CSS dan inline style ke data:

1. **`:class` dengan Object Syntax** — class aktif berdasarkan kondisi
2. **`:class` dengan Array Syntax** — beberapa class digabung secara dinamis
3. **`:style`** — inline style langsung dari data

Ini memungkinkan kita mengubah tampilan tanpa menyentuh DOM secara manual.

## Fungsi

| Teknik | Sintaks | Fungsi |
|--------|---------|--------|
| Object Syntax | `:class="{ 'active': isActive }"` | Tambahkan class `active` jika `isActive` bernilai `true` |
| Array Syntax | `:class="['base', condition ? 'extra' : '']"` | Gabungkan beberapa class, beberapa bersifat kondisional |
| Inline Style | `:style="{ color: textColor, fontSize: size + 'px' }"` | Terapkan style langsung dari data, gunakan camelCase |

### Object Syntax vs Array Syntax

| Aspek | Object Syntax | Array Syntax |
|-------|--------------|--------------|
| Struktur | `{ 'nama-class': boolean }` | `['class1', 'class2']` |
| Kondisional | Langsung di nilai boolean | Pakai ternary `? :` |
| Kelebihan | Lebih bersih untuk 1-2 class kondisional | Fleksibel untuk kombinasi banyak class |
| Contoh | `{ 'discounted': book.price < 50000 }` | `['card', book.isPopular ? 'popular' : '']` |

## Cara Implementasi / Kode

```vue
<template>
  <div class="catalog">
    <h1>{{ storeName }}</h1>

    <div class="book-list">
      <div
        v-for="book in books"
        :key="book.id"
        class="book-card"
        :class="{
          'card-gold': book.rating >= 4.5,
          'card-dim': !book.inStock,
          'card-sale': book.discounted
        }"
      >
        <img :src="book.cover" :alt="book.title" class="cover" />
        <h3>{{ book.title }}</h3>
        <p class="author">— {{ book.author }}</p>

        <!-- Inline style: warna teks harga berdasarkan stok -->
        <p
          class="price"
          :style="{
            color: book.inStock ? '#2e7d32' : '#c62828',
            opacity: book.inStock ? 1 : 0.5,
            textDecoration: !book.inStock ? 'line-through' : 'none'
          }"
        >
          Rp{{ book.price.toLocaleString('id-ID') }}
        </p>

        <!-- Array syntax class -->
        <span
          :class="[
            'badge',
            book.rating >= 4.5 ? 'badge-top' : 'badge-normal',
            book.discounted ? 'badge-sale' : ''
          ]"
        >
          {{ book.rating >= 4.5 ? '★ Best Seller' : 'Tersedia' }}
        </span>

  </div>
</template>

<script setup lang="ts">

  },
  {
    id: 3, title: 'Ronggeng Dukuh Paruk', author: 'Ahmad Tohari',

</script>

<style scoped>
```

### Langkah-langkah
1. Tentukan kondisi dari data (misal: `book.rating >= 4.5`)
2. Untuk **object syntax**, buat objek dengan key = nama class, value = kondisi boolean
3. Untuk **array syntax**, buat array berisi string class, gunakan ternary untuk yang kondisional
4. Untuk **inline style**, buat objek dengan properti CSS camelCase

## Analogi — Toko Buku

| Teknik | Analogi Toko Buku |
|--------|-------------------|
| `:class` object syntax | **Memberikan stiker diskon (stiker kuning)** hanya untuk buku rating di atas 4.5. Stiker menempel otomatis — saat rating berubah, stiker ikut terpasang atau terlepas. |
| `:class` array syntax | **Papan nama rak** yang bisa punya beberapa label sekaligus: "BEST SELLER" + "DISKON 20%" — setiap label diatur oleh kondisi berbeda. |
| `:style` | **Lampu sorot** yang warnanya berubah: merah untuk stok habis, hijau untuk tersedia. Langsung diatur propertinya tanpa harus membuat class CSS terpisah. |

Intinya: `:class` seperti menempel dan melepas stiker, `:style` seperti mengatur properti fisik elemen secara langsung.

## Dipakai untuk Apa di Dunia Nyata

- **Highlight produk best seller** — border emas untuk rating tinggi
- **Produk tidak aktif / habis** — opacity turun, teks dicoret
- **Tombol disabled** — ubah warna dan cursor
- **Selected state** — class aktif pada menu atau tab
- **Tema gelap/terang** — toggle class `dark-mode` di root element
- **Progress bar** — ubah lebar dan warna berdasarkan persentase
- **Form validation** — border merah untuk input error

## Kesalahan Umum

| Kesalahan | Salah | Benar |
|-----------|-------|-------|
| **Bingung object vs array syntax** | `:class="{ 'a', 'b' }"` (salah — pakai koma tanpa nilai) | `:class="{ a: true, b: false }"` (object) atau `:class="['a', 'b']"` (array) |
| **Pake koma di object untuk pemisah class** | `:class="{ 'a': cond1 'b': cond2 }"` (lupa koma) | `:class="{ 'a': cond1, 'b': cond2 }"` |
| **Property CSS pakai kebab-case di `:style`** | `:style="{ font-size: '12px' }"` (error) | `:style="{ fontSize: '12px' }"` (camelCase) |
| **Mencampur class statis dan dinamis tanpa array** | `<div class="base" :class="{ dyn: cond }">` — ini sebenarnya sudah benar, jadi bukan error | Tapi untuk kombinasi kompleks, array syntax lebih expressif |

### Contoh confusion yang sering terjadi

```vue
<!-- ❌ SALAH: Ini object syntax yang ditulis seperti array -->
<div :class="{ 'red', 'bold' }">...</div>

<!-- ✅ BENAR: Object syntax dengan kondisi -->
<div :class="{ red: isError, bold: isImportant }">...</div>

<!-- ✅ BENAR: Array syntax -->
<div :class="['base', isError ? 'red' : 'blue']">...</div>
```

## Hubungan dengan Materi Sebelumnya

Di **Poin 10**, kita menggunakan `v-if`/`v-show` untuk menampilkan/menyembunyikan elemen. Sekarang kita **tidak hanya menyembunyikan, tapi mengubah tampilan** secara dinamis — buku dengan rating tinggi dapat border emas, stok habis jadi redup, dan seterusnya.

Ini melengkapi kemampuan template Vue: dari menampilkan data (Poin 8), mengulang (Poin 9), kondisional (Poin 10), hingga styling dinamis (Poin 11).

## Soal Latihan + Jawaban

### Soal 1
Apa perbedaan antara object syntax dan array syntax pada `:class`? Berikan contoh masing-masing.

<details>
<summary>Jawaban</summary>

**Object syntax** menggunakan objek dengan key = nama class, value = kondisi boolean:
```ts
:class="{ 'active': isActive, 'disabled': !isEnabled }"
```
Class `active` akan ditambahkan jika `isActive === true`.

**Array syntax** menggunakan array berisi nama class (bisa string langsung atau ternary):
```ts
:class="['base-class', isPopular ? 'popular' : 'regular']"
```
Array memungkinkan penggabungan class statis dan dinamis.
</details>

### Soal 2
Buat komponen yang menampilkan buku dengan:
- Jika `isPremium === true`, tambahkan class `premium-border` (border emas)
- Jika stok <= 0, tambahkan class `out-of-stock` (opacity 0.5) dan inline style `color: red`
- Gunakan kombinasi `:class` object syntax dan `:style`

<details>
<summary>Jawaban</summary>

```vue
<template>
  <div>
    <div
      v-for="book in books"
      :key="book.id"
      class="book-card"
      :class="{ 'premium-border': book.isPremium, 'out-of-stock': book.stock <= 0 }"
      :style="{ borderColor: book.isPremium ? '#ffd700' : '#ddd' }"
    >
      <h3>{{ book.title }}</h3>
      <p>Stok: {{ book.stock }}</p>
      <span :style="{ color: book.stock <= 0 ? 'red' : 'green' }">
        {{ book.stock <= 0 ? 'Habis' : 'Tersedia' }}
      </span>
    </div>
  </div>
</template>

<script setup lang="ts">
interface Book {
  id: number
  title: string
  stock: number
  isPremium: boolean
}

const books: Book[] = [
  { id: 1, title: 'Laskar Pelangi', stock: 5, isPremium: true },
  { id: 2, title: 'Bumi Manusia', stock: 0, isPremium: false }
]
</script>

<style scoped>
.book-card {
  padding: 1rem;
  margin-bottom: 0.5rem;
  border: 2px solid #ddd;
  border-radius: 6px;
}

.premium-border {
  box-shadow: 0 0 10px rgba(255, 215, 0, 0.5);
}

.out-of-stock {
  opacity: 0.5;
}
</style>
```
</details>
