# 4. Setup Tailwind CSS

## Penjelasan

Tailwind CSS adalah *utility-first CSS framework* yang menyediakan class-class kecil (seperti `flex`, `text-center`, `p-4`, `bg-blue-500`) yang bisa dikombinasikan langsung di HTML/Vue template. Berbeda dengan Bootstrap yang menyediakan komponen siap pakai (`.btn`, `.card`), Tailwind memberikan *building blocks* terkecil sehingga desain lebih fleksibel dan tidak ada CSS yang tidak terpakai.

Vue 3 + Tailwind CSS adalah kombinasi populer karena:
- **Scoped styles** milik Vue tidak bertabrakan dengan utility Tailwind.
- **Vite** memproses PostCSS dengan cepat, Hot Reload tetap instan.
- **PurgeCSS** sudah built-in di Tailwind → hanya CSS yang dipakai yang di-bundle.

## Fungsi

- Menulis CSS tanpa perlu ganti file — cukup tambah class di template.
- Ukuran CSS final sangat kecil karena hanya utility yang dipakai yang ikut.
- Konsistensi desain — semua spacing, warna, font mengikuti *design system* Tailwind.

## Cara Implementasi

### 1. Install Tailwind dan Dependencies

```bash
npm install -D tailwindcss @tailwindcss/vite
```

> **Catatan**: Tailwind CSS v4 menggunakan pendekatan berbeda dengan v3. Untuk v4, kita pakai plugin Vite langsung. Jika menggunakan Tailwind v3, install `tailwindcss postcss autoprefixer` dan gunakan file config.

### 2. Konfigurasi `vite.config.ts`

```typescript
import { fileURLToPath, URL } from 'node:url'
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    vue(),
    tailwindcss(),
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
    },
  },
})
```

### 3. Import Tailwind di `src/assets/main.css`

```css
@import "tailwindcss";
```

### 4. Pastikan `main.css` Sudah Di-import di `main.ts`

```typescript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import router from './router'
import App from './App.vue'
import './assets/main.css'  // ← Pastikan baris ini ada

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.mount('#app')
```

### 5. Test di `src/views/HomeView.vue`

```vue
<script setup lang="ts">
</script>

<template>
  <main class="min-h-screen bg-gray-50 flex items-center justify-center">
    <div class="text-center space-y-4">
      <h1 class="text-4xl font-bold text-gray-800">
        Selamat Datang di BookStore
      </h1>
      <p class="text-lg text-gray-600">
        Toko buku online favorit Anda.
      </p>
      <button class="bg-blue-600 text-white px-6 py-2 rounded-lg hover:bg-blue-700 transition">
        Jelajahi Buku
      </button>
    </div>
  </main>
</template>
```

### 6. Jalankan

```bash
npm run dev
```

Buka http://localhost:5173 — teks dan tombol harus sudah ter-styling dengan Tailwind.

## Analogi: Toko Buku

Tailwind seperti memiliki katalog standar untuk semua perlengkapan toko buku. Daripada membuat lemari dari kayu dan mengecatnya sendiri (CSS manual), Anda tinggal pilih dari katalog: rak ukuran `w-64` (lebar 256px), warna cat `bg-white`, jarak antar rak `gap-4`. Semua sudah distandarisasi — Anda tidak perlu mikir "berapa px sih padding yang pas?" karena Tailwind sudah menyediakan skala `p-1` sampai `p-96`.

Sebaliknya, Bootstrap seperti membeli rak buku jadi dengan merek tertentu — cepat, tapi semua toko jadi terlihat sama. Tailwind memberi Anda fleksibilitas "toko unik" tanpa harus jadi tukang kayu.

## Dipakai Untuk Apa

- **Startup / MVP**: Desain cepat tanpa setup CSS framework kompleks.
- **Design system kustom**: Tim desain menentukan warna, spacing → tinggal mapping ke Tailwind config.
- **Prototyping**: Bikin halaman dalam hitungan menit hanya dengan class.
- **Project dengan tim Frontend kecil**: Satu orang handle styling + logic tanpa ganti konteks.

## Kesalahan Umum

| Kesalahan | Dampak | Cara Hindari |
|-----------|--------|--------------|
| Lupa `import './assets/main.css'` di `main.ts` | Tailwind tidak bekerja sama sekali | Cek `main.ts` — baris import CSS harus ada |
| Content paths tidak mencakup `.vue` | CSS utility tiba-tiba hilang di production | Tailwind v4 via Vite plugin otomatis scan semua file |
| Install Tailwind v3 tapi ikut panduan v4 (atau sebaliknya) | Error konfigurasi | Cek versi Tailwind: `npx tailwindcss --help` lalu ikuti panduan yang sesuai |
| Menambahkan Tailwind tapi Bootstrap juga diinstall | CSS conflict, ukuran file membengkak | Pilih salah satu — campur keduanya tidak disarankan |
| Mengedit class sintaks Tailwind | Class tidak dikenali | Gunakan class valid: `text-center` (bukan `text-centre`), `bg-gray-100` (bukan `bg-grey-100`) |

## Hubungan dengan Materi Sebelumnya

**Poin 3** kita membersihkan project dan menyiapkan `src/assets/main.css`. Sekarang kita isi file `main.css` tersebut dengan import Tailwind. Struktur folder dari poin 3 tetap utuh — kita hanya menambahkan styling.

## Soal Latihan

**Soal 1:** Apa perbedaan pendekatan Tailwind CSS (utility-first) dengan Bootstrap (component-first)? Berikan contoh!

**Jawaban:**
- **Tailwind**: Utility class — kita kombinasikan class kecil untuk membuat tombol:
  ```html
  <button class="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600">Klik</button>
  ```
- **Bootstrap**: Component class — kita pakai class siap pakai:
  ```html
  <button class="btn btn-primary">Klik</button>
  ```

Dengan Tailwind, kita kendali penuh setiap aspek visual. Dengan Bootstrap, kita terikat dengan desain default Bootstrap (warna, radius, ukuran).

**Soal 2:** Setelah install Tailwind, styling tidak berubah sama sekali — halaman tetap putih polos. Sebutkan 3 kemungkinan penyebab dan solusinya!

**Jawaban:**
1. **Penyebab**: `main.css` tidak di-import di `main.ts`.
   - **Solusi**: Tambahkan `import './assets/main.css'` di `src/main.ts`.

2. **Penyebab**: Isi `main.css` salah — mungkin masih berisi CSS lama, bukan `@import "tailwindcss"`.
   - **Solusi**: Hapus semua isi `main.css`, ganti dengan `@import "tailwindcss";` (Tailwind v4).

3. **Penyebab**: Tailwind v3 terinstall, tapi konfigurasi v4 yang dipakai (atau plugin tidak ditambahkan di `vite.config.ts`).
   - **Solusi**: Untuk Tailwind v3, butuh `postcss.config.js`:
     ```javascript
     export default {
       plugins: {
         tailwindcss: {},
         autoprefixer: {},
       },
     }
     ```
     Lalu di `main.css`: `@tailwind base; @tailwind components; @tailwind utilities;`
