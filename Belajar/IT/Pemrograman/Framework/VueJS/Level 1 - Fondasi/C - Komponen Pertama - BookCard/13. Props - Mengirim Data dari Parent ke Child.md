# 13. Props — Mengirim Data dari Parent ke Child

## Penjelasan

**Props** (singkatan dari *properties*) adalah mekanisme utama untuk mengirim data dari komponen induk (parent) ke komponen anak (child) di Vue. Props bersifat **read-only** di child — child tidak boleh mengubah nilai props yang diterima.

Di Vue 3 dengan TypeScript, kita mendefinisikan props menggunakan macro `defineProps()`:

```vue
<!-- Child component menerima props -->
<script setup lang="ts">
defineProps<{ book: Book }>()
</script>
```

Untuk memberikan **default value**, kita gunakan `withDefaults()`:

```vue
<script setup lang="ts">
interface Props {
  book: Book
  showDiscount?: boolean   // opsional
}

const props = withDefaults(defineProps<Props>(), {
  showDiscount: false,     // default: diskon tidak ditampilkan
})
</script>
```

### Aliran Data Satu Arah (One-Way Data Flow)

```
┌──────────────┐     props (read-only)     ┌──────────────┐
│  Parent      │ ─────────────────────────→ │  Child       │
│  (HomeView)  │                            │  (BookCard)  │
└──────────────┘                            └──────────────┘
       ↑ tidak boleh mengubah props              ↓
       │                                   hanya boleh baca
       └──────────────────────────────────────────┘
            Kalau ada perubahan data, parent
            yang harus mengubah sumber datanya
```

## Fungsi

- **Komunikasi parent → child**: Satu-satunya cara standar untuk memberikan data ke komponen anak
- **Reusability**: Komponen yang sama bisa menerima data berbeda melalui props
- **Type safety**: TypeScript memvalidasi tipe data props di compile-time
- **Immutability terjamin**: Child tidak bisa mengubah data milik parent secara tidak sengaja

## Cara Implementasi / Kode

### 1. Terima props di BookCard

Buka `src/components/features/BookCard.vue` dan pastikan sudah menggunakan `defineProps`:

```vue
<script setup lang="ts">
import type { Book } from '@/types/book.types'
import { formatPrice } from '@/utils/format'

const props = defineProps<{
  book: Book
}>()
</script>
```

Dengan `const props = ...`, kita bisa mengakses `props.book` di dalam script. Di template, cukup panggil `book` langsung — Vue secara otomatis membuka destructuring untuk template.

### 2. Gunakan `withDefaults` untuk props opsional

Kita tambahkan properti opsional `showDiscount`:

```vue
<script setup lang="ts">
import type { Book } from '@/types/book.types'
import { formatPrice } from '@/utils/format'

export interface BookCardProps {
  book: Book
  showDiscount?: boolean
}

const props = withDefaults(defineProps<BookCardProps>(), {
  showDiscount: false,
})
</script>
```

Update template untuk menampilkan diskon jika `showDiscount` true:

```vue
<template>
  <div class="card">
    <img :src="book.coverUrl" :alt="book.title" class="cover" />
    <div class="info">
      <h3 class="title">{{ book.title }}</h3>
      <p class="author">{{ book.author }}</p>
      <p class="price">
        {{ formatPrice(book.price) }}
        <span v-if="props.showDiscount" class="discount-badge">Diskon!</span>
      </p>
      <div class="rating">
        <span
          v-for="star in 5"
          :key="star"
          class="star"
          :class="{ filled: star <= book.rating }"
        >★</span>
        <span class="rating-text">({{ book.rating }}/5)</span>
      </div>
    </div>
  </div>
</template>
```

### 3. Kirim data dari parent

Di parent (contoh `HomeView.vue`), kirim data melalui atribut:

```vue
<template>
  <BookCard :book="bookData" :show-discount="true" />
</template>

<script setup lang="ts">
import BookCard from '@/components/features/BookCard.vue'
import type { Book } from '@/types/book.types'

const bookData: Book = {
  id: 1,
  title: 'Laskar Pelangi',
  author: 'Andrea Hirata',
  price: 95000,
  rating: 5,
  coverUrl: 'https://via.placeholder.com/100x150?text=Laskar+Pelangi',
}
</script>
```

Perhatikan: `:show-discount="true"` di template otomatis dikonversi ke `showDiscount` di script (Vue mengubah kebab-case ke camelCase).

### Props bersifat read-only

Kode berikut **salah** dan akan menghasilkan warning Vue:

```vue
<!-- ⛔ SALAH: jangan lakukan ini di dalam BookCard -->
<script setup lang="ts">
const props = defineProps<{ book: Book }>()

function ubahJudul() {
  props.book.title = 'Judul Baru'   // ⛔ Error: Cannot assign to read-only property
}
</script>
```

Jika perlu mengubah data, **emit event** ke parent (dibahas di level selanjutnya).

## Analogi — Toko Buku

**Props seperti "kertas pesanan" yang diberikan pemilik toko kepada pegawai.**

Pemilik toko (parent component) menulis pesanan di selembar kertas: "Tolong tampilkan buku Laskar Pelangi dengan harga Rp95.000, stiker diskon dipasang." Kertas ini diberikan ke pegawai (child component).

| Konsep Vue | Analogi Toko Buku |
|------------|-------------------|
| `defineProps` | Pegawai menerima kertas pesanan dan membaca isinya |
| `withDefaults` | Instruksi bawaan: "Jika tidak disebut, anggap tidak pakai stiker diskon" |
| Props read-only | Pegawai **hanya boleh membaca** kertas, tidak boleh menulis ulang pesanan |
| Parent mengubah props | Pemilik toko mengambil kertas lama, menulis ulang, kasih lagi ke pegawai |
| Kebab-case di template | Pemilik toko menulis "stiker-diskon" (dengan tanda hubung) — pegawai paham itu `stikerDiskon` |

Pegawai yang baik hanya menjalankan apa yang tertulis — tidak mengubah pesanan seenaknya.

## Dipakai untuk Apa di Dunia Nyata

- **Setiap komponen reusable** pasti menerima props: `BookCard`, `UserAvatar`, `ProductCard`, `Modal`
- **Layout components**: `AppHeader` menerima props `title` atau `showSearch`
- **Form components**: `BaseInput` menerima props `label`, `placeholder`, `type`, `modelValue`
- **Data display**: `DataTable` menerima props `columns` dan `rows`

## Kesalahan Umum

| Kesalahan | Dampak | Solusi |
|-----------|--------|--------|
| **Mengubah props dari child** | Warning Vue: "Attempt to mutate prop" | Jangan ubah props. Gunakan emit atau local copy (`const localBook = computed(() => props.book)`) |
| **Lupa `:` di template** | Props dikirim sebagai string literal, bukan JavaScript | `book="data"` mengirim string "data", bukan variable. Gunakan `:book="data"` |
| **Bingung props vs local state** | Data yang seharusnya milik child malah dikirim via props | Gunakan `ref()` untuk data internal child, props untuk data dari parent |
| **Props terlalu dalam** | Component jadi rapuh terhadap perubahan struktur data | Gunakan props yang flat untuk komponen sederhana, atau gunakan composable |
| **CamelCase vs kebab-case bingung** | Props tidak terkirim dengan benar | Di template gunakan kebab-case (`show-discount`), di script gunakan camelCase (`showDiscount`) |

## Hubungan dengan Materi Sebelumnya

Di **Poin 12**, kita membuat `BookCard.vue` yang di dalamnya sudah ada `defineProps`. Sekarang kita pahami **apa** yang terjadi di balik `defineProps` — mekanisme pengiriman data, aliran satu arah, dan default values.

Props adalah fondasi dari **komunikasi komponen di Vue**. Setelah ini, kita akan:
1. **Poin 14**: Mengirim data dari `HomeView` ke `BookCard` menggunakan v-for
2. **Level 2 nanti**: Mempelajari emit (komunikasi child → parent) dan provide/inject (komunikasi ke komponen yang lebih dalam)

## Soal Latihan + Jawaban

### Soal 1
Jelaskan apa yang terjadi jika kamu menulis kode berikut di dalam komponen BookCard:

```vue
<script setup lang="ts">
const props = defineProps<{ book: Book }>()

function ubahHarga() {
  props.book.price = 50000
}
</script>
```

<details>
<summary>Jawaban</summary>

Vue akan mengeluarkan **warning** di console: *"Attempt to mutate prop 'book.price'"* atau error terkait read-only. Props adalah **read-only** — child tidak boleh mengubah nilai props.

Solusi yang benar: Jika ingin harga berbeda, **parent** yang harus mengubah data sumbernya, lalu Vue akan re-render komponen dengan nilai baru. Atau, buat **local copy** menggunakan `computed` atau `ref` jika memang perlu modifikasi lokal.
</details>

### Soal 2
Apa perbedaan antara `:book="bookData"` dan `book="bookData"` di template?

<details>
<summary>Jawaban</summary>

- **`:book="bookData"`** (dengan `:`) : Vue mengevaluasi `bookData` sebagai **JavaScript expression**. Nilai yang dikirim adalah nilai dari variabel `bookData` (misal object Book).
- **`book="bookData"`** (tanpa `:`) : Vue mengirim string literal **"bookData"** sebagai nilai props. Bukan variabel, melainkan teks biasa.

Jadi tanpa `:`, komponen child akan menerima string `"bookData"`, bukan object buku yang dimaksud. Ini adalah salah satu kesalahan paling umum pada pemula Vue.
</details>
