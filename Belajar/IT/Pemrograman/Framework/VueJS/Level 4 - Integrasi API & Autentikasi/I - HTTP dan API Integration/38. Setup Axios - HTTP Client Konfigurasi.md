# 38. Setup Axios - HTTP Client Konfigurasi

## Penjelasan

Axios adalah HTTP client berbasis Promise untuk melakukan request ke API dari browser. Di Vue 3, Axios menjadi pilihan utama karena ringan, support interceptor, dan integrasi mudah dengan TypeScript.

Dengan `axios.create()` kita bisa membuat instance Axios dengan konfigurasi default — seperti baseURL, timeout, dan headers — sehingga semua komponen cukup menggunakan instance yang sama tanpa perlu mengulang konfigurasi setiap kali.

## Fungsi

- Abstraction layer untuk semua komunikasi HTTP ke backend
- Menyediakan konfigurasi terpusat (base URL, timeout, headers)
- Interceptor untuk otomatis menyisipkan token autentikasi
- Interceptor untuk transform response (misal langsung ambil `response.data`)
- Memudahkan penanganan error global (seperti 401 → redirect login)

## Cara Implementasi

### 1. Install Axios

```bash
npm install axios
```

### 2. File Environment (`src/.env`)

```env
VITE_API_BASE_URL=http://localhost:3000/api
```

### 3. Axios Instance (`src/api/axios.instance.ts`)

```typescript
import axios from 'axios'

const apiClient = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
})

apiClient.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('access_token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error),
)

apiClient.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('access_token')
      window.location.href = '/login'
    }
    return Promise.reject(error)
  },
)

export default apiClient
```

## Analogi — Toko Buku

Axios instance seperti **"saluran telepon khusus"** toko ke gudang pusat. Dulu semua barang (data) ada di toko (hardcode). Sekarang toko punya hotline ke gudang pusat (backend NestJS). Setiap kali butuh data, pegawai tinggal angkat telepon (axios call) — data dikirim dari gudang.

**Interceptor request** seperti **"resepsionis"** yang otomatis menyebutkan identitas toko (token) setiap kali menelepon — "Halo, ini Toko Buku Jaya, nomor pelanggan 12345".

**Interceptor response** seperti **"resepsionis"** yang menyortir surat — ia membuka amplop (response) dan langsung mengambil isinya (`response.data`) sebelum diberikan ke pegawai.

## Dipakai untuk Apa

- Setiap komunikasi HTTP ke backend NestJS dalam satu aplikasi
- Autentikasi: menyisipkan token JWT secara otomatis
- Global error handling: 401 redirect ke login
- Timeout dan retry logic
- Logging request/response di development

## Kesalahan Umum

| Kesalahan | Akibat | Solusi |
|---|---|---|
| Tidak pakai instance, langsung `axios.get()` di tiap komponen | Base URL hardcode di banyak tempat, susah maintenance | Buat satu instance dengan `axios.create()` |
| Token disimpan di memory, bukan localStorage | Hilang saat refresh, user harus login lagi | Simpan token di localStorage, baca dari interceptor |
| Lupa handle error global | Setiap komponen harus handle error sendiri | Interceptor response untuk tangani error umum |
| Timeout tidak disetel | Request menggantung tanpa batas | Set `timeout: 10000` di instance |
| Tidak pakai env variable | Base URL beda-beda antar environment | Gunakan `import.meta.env.VITE_API_BASE_URL` |

## Hubungan dengan Materi Sebelumnya

Selama ini di Level 1-3, semua data *hardcode* di file:

```typescript
// Level 3 - data masih palsu
const books = ref<Book[]>([
  { id: 1, title: 'Buku A', price: 50000 },
  { id: 2, title: 'Buku B', price: 75000 },
])
```

Sekarang data berasal dari server via Axios:

```typescript
// Level 4 - panggil API
const books = ref<Book[]>([])
const response = await apiClient.get('/books')
books.value = response.data
```

Semua data di Level 1-3 (books, users, authors, genres) akan diganti dengan data asli dari backend NestJS.

## Soal Latihan + Jawaban

### Soal 1

Buat sebuah Axios instance dengan konfigurasi:
- baseURL dari env variable `VITE_API_URL`
- timeout 15 detik
- Request interceptor yang menambahkan header `X-Request-Id` berisi UUID random setiap request

<details>
<summary>Jawaban</summary>

```typescript
import axios from 'axios'
import { v4 as uuidv4 } from 'uuid'

const apiClient = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
  timeout: 15000,
})

apiClient.interceptors.request.use((config) => {
  config.headers['X-Request-Id'] = uuidv4()
  return config
})

export default apiClient
```

### Soal 2

Buat interceptor response yang otomatis mengubah error network menjadi pesan yang lebih ramah: "Gagal terhubung ke server. Periksa koneksi internet Anda."

<details>
<summary>Jawaban</summary>

```typescript
apiClient.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (!error.response) {
      // Network error — tidak ada response dari server
      console.error('Network Error:', error.message)
      return Promise.reject(
        new Error('Gagal terhubung ke server. Periksa koneksi internet Anda.'),
      )
    }
    return Promise.reject(error)
  },
)
```
