# 41. Update HomeView — Fetch Buku dari API

## Penjelasan

HomeView adalah halaman utama aplikasi yang menampilkan daftar buku. Sebelumnya, data buku masih berupa array hardcode di file. Sekarang kita ganti dengan fetch data dari API menggunakan `useApi` + `booksApi`.

Selain mengganti sumber data, kita juga perlu menangani tiga kondisi yang mungkin terjadi:
- **Loading**: tampilkan skeleton sementara data dimuat
- **Error**: tampilkan pesan error dan tombol "Coba Lagi"
- **Empty**: tampilkan pesan "Tidak ada buku ditemukan"

## Fungsi

- Aplikasi menampilkan data **nyata** dari server, bukan data palsu
- Memberikan user experience yang baik selama fetching (loading animation)
- Memberikan feedback yang jelas jika terjadi error
- Filter dan search bekerja langsung terhadap data real-time

### 2. HomeView Sesudah (fetch dari API)

```vue
<script setup lang="ts">
import { ref, watch, onMounted } from 'vue'
import { useApi } from '@/composables/useApi'
import { booksApi } from '@/api/books.api'
import type { PaginatedResult, Book } from '@/types/book'
import BookCard from '@/components/BookCard.vue'
import SkeletonCard from '@/components/SkeletonCard.vue'

const searchQuery = ref('')
const currentPage = ref(1)

const { data, isLoading, error, execute } = useApi<PaginatedResult<Book>>()

async function fetchBooks() {
  await execute(() =>
    booksApi.getAll({
      page: currentPage.value,
      limit: 12,
      search: searchQuery.value || undefined,
    }),
  )
}

onMounted(fetchBooks)

watch(searchQuery, () => {
  currentPage.value = 1
  fetchBooks()
})

watch(currentPage, fetchBooks)

function retry() {
  fetchBooks()
}
</script>

<template>
  <div class="home-view">
    <header>
      <h1>Katalog Buku</h1>
      <input
        v-model="searchQuery"
        type="text"
        placeholder="Cari judul buku..."
        class="search-input"
      />
    </header>

    <!-- Loading State -->
    <div v-if="isLoading" class="book-grid">
      <SkeletonCard v-for="n in 8" :key="n" />
    </div>

    <!-- Error State -->
    <div v-else-if="error" class="error-state">
      <p class="error-message">⚠️ {{ error }}</p>
      <button @click="retry" class="retry-btn">Coba Lagi</button>
    </div>

    <!-- Empty State -->
    <div v-else-if="data && data.data.length === 0" class="empty-state">
      <p>Tidak ada buku ditemukan.</p>
    </div>

    <!-- Data Tersedia -->
    <div v-else-if="data" class="book-grid">
      <BookCard
        v-for="book in data.data"
        :key="book.id"
        :book="book"
      />
    </div>
  </div>
</template>

<style scoped>
.book-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 1.5rem;
}

.error-state,
.empty-state {
  text-align: center;
  padding: 3rem;
}

.retry-btn {
  padding: 0.5rem 1.5rem;
  background: #4f46e5;
  color: white;
  border: none;
  border-radius: 6px;
  cursor: pointer;
}
</style>
```

## Analogi — Toko Buku

Akhirnya! Dulu toko punya **katalog cetak** (hardcode) yang isinya sudah kadaluarsa — buku yang sudah terjual masih tercantum, harga tidak update.

Sekarang **etalase terhubung LANGSUNG** ke database gudang pusat. Setiap kali pelanggan mencari buku, pegawai cukup lihat di layar — **data real-time** dari server.

- **Loading**: seperti pegawai sedang menunggu sambungan telepon — layar menampilkan "Memuat..." (skeleton)
- **Error**: "Maaf, sedang gangguan — coba lagi" (error + retry button)
- **Empty**: "Tidak ada buku yang cocok dengan pencarian Anda"
- **Filter/Search**: seperti pelanggan bertanya "Ada buku Vue.js?" — pegawai langsung Tanya ke gudang, jawaban real-time

## Dipakai untuk Apa

- Halaman utama toko buku online (marketplace)
- Halaman pencarian produk
- Dashboard admin dengan data real-time
- Halaman kategori/filter produk
- Aplikasi yang memerlukan data terkini dari server

## Kesalahan Umum

| Kesalahan | Akibat | Solusi |
|---|---|---|
| Lupa handle loading state | Tampilan kosong sementara data dimuat | Tampilkan skeleton atau spinner |
| Fetch di `<script setup>` (sync) | Promise tidak di-trigger, data kosong | Panggil fetch di `onMounted` |
| Tidak watch filter → refetch | Filter berubah tapi data tidak berubah | `watch(searchQuery, fetchBooks)` |
| Lupa handle empty state | Grid kosong tanpa pesan | Cek `data.data.length === 0` |
| Multiple request saat filter cepat berubah | Request ke-1 timpa data dari request ke-3 | Gunakan AbortController atau debounce |

## Hubungan dengan Materi Sebelumnya

Di **Level 3**, HomeView hanya menampilkan data statis:

```typescript
const books = ref<Book[]>(MOCK_BOOKS)
// Tidak ada loading, error, atau empty state
```

Sekarang **perubahan besar** terjadi:
- Data tidak lagi dari file, tapi dari server
- Ada 4 state: loading, error, empty, success
- Filter memicu fetch ulang
- Setiap render bisa menampilkan data berbeda

Ini adalah **transisi fundamental** dari aplikasi statis menjadi aplikasi dinamis yang terhubung ke backend.

### Soal 1

Implementasikan infinite scroll di HomeView — ketika user scroll ke bawah halaman, muat halaman berikutnya dan tambahkan ke daftar buku yang sudah ada (append, bukan replace).

<details>
<summary>Jawaban</summary>

```vue
<script setup lang="ts">
import { onMounted, onUnmounted } from 'vue'

const books = ref<Book[]>([])
const currentPage = ref(1)
const { isLoading, execute } = useApi<PaginatedResult<Book>>()

async function loadMore() {
  await execute(() =>
    booksApi.getAll({ page: currentPage.value, limit: 12 }),
  )
  if (data.value) {
    books.value.push(...data.value.data)
    currentPage.value++
  }
}

function handleScroll() {
  const nearBottom =
    window.innerHeight + window.scrollY >=
    document.body.offsetHeight - 200

  if (nearBottom && !isLoading.value) {
    loadMore()
  }
}

onMounted(() => {
  loadMore()
  window.addEventListener('scroll', handleScroll)
})

onUnmounted(() => {
  window.removeEventListener('scroll', handleScroll)
})
</script>
```

### Soal 2

Buat debounce 300ms pada search input agar tidak memicu fetch API setiap kali user mengetik satu huruf.

<details>
<summary>Jawaban</summary>

```typescript
import { ref, watch, onMounted } from 'vue'

const searchQuery = ref('')
const debouncedSearch = ref('')

// Debounce manual
let timeoutId: ReturnType<typeof setTimeout>
watch(searchQuery, (val) => {
  clearTimeout(timeoutId)
  timeoutId = setTimeout(() => {
    debouncedSearch.value = val
  }, 300)
})

// Fetch ketika debouncedSearch berubah
watch(debouncedSearch, () => {
  currentPage.value = 1
  fetchBooks()
})
```

Atau gunakan `useDebounce` dari VueUse:

```typescript
import { useDebounce } from '@vueuse/core'

const searchQuery = ref('')
const debouncedSearch = useDebounce(searchQuery, 300)

watch(debouncedSearch, () => {
  currentPage.value = 1
  fetchBooks()
})
```
