# 28. Review dan Konfigurasi Router

## Penjelasan

Vue Router sudah disertakan sejak setup awal `create-vue` (Poin 1). Sekarang kita **review** struktur yang sudah ada dan **tambah semua route** yang dibutuhkan aplikasi BookStore.

Route yang akan dibuat:
| Path | Nama Route | Halaman |
|---|---|---|
| `/` | `home` | Beranda (daftar buku) |
| `/books/:id` | `book-detail` | Detail buku |
| `/cart` | `cart` | Keranjang belanja |
| `/wishlist` | `wishlist` | Wishlist |
| `/profile` | `profile` | Profil user |
| `/:pathMatch(.*)*` | `not-found` | 404 |

## Fungsi

Memetakan setiap **URL** ke **komponen halaman** tertentu. Saat user mengklik link atau mengetik URL, Vue Router tahu komponen mana yang harus ditampilkan tanpa reload halaman.

## Cara Implementasi

### 1. Setup dasar `src/router/index.ts`

```typescript
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  scrollBehavior(to, from, savedPosition) {
    // Kembali ke posisi scroll sebelumnya jika user tekan back
    if (savedPosition) {
      return savedPosition
    }
    // Scroll ke anchor jika ada hash
    if (to.hash) {
      return { el: to.hash, behavior: 'smooth' }
    }
    // Default: scroll ke atas
    return { top: 0, behavior: 'smooth' }
  },
  routes: [
    {
      path: '/',
      name: 'home',
      component: () => import('../views/HomeView.vue')
    },
    {
      path: '/books/:id',
      name: 'book-detail',
      component: () => import('../views/BookDetailView.vue')
    },
    {
      path: '/cart',
      name: 'cart',
      component: () => import('../views/CartView.vue')
    },
    {
      path: '/wishlist',
      name: 'wishlist',
      component: () => import('../views/WishlistView.vue')
    },
    {
      path: '/profile',
      name: 'profile',
      component: () => import('../views/ProfileView.vue')
    },
    {
      path: '/:pathMatch(.*)*',
      name: 'not-found',
      component: () => import('../views/NotFoundView.vue')
    }
  ]
})

export default router
```

### 2. `main.ts` — pasang router ke app

```typescript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'

const app = createApp(App)
app.use(createPinia())
app.use(router)
app.mount('#app')
```

### 3. `App.vue` — tempat RouterView

```vue
<script setup lang="ts">
import { RouterView } from 'vue-router'
</script>

<template>
  <RouterView />
</template>
```

## Lazy Loading

`() => import(...)` membuat **lazy loading** — komponen hanya di-download saat route itu dikunjungi. Ini bikin bundle awal lebih kecil dan halaman pertama loading lebih cepat.

**Tanpa lazy loading** (semua di-load sekali):
```typescript
import HomeView from '../views/HomeView.vue'  // buruk untuk bundle size
```

**Dengan lazy loading** (di-load per route):
```typescript
component: () => import('../views/HomeView.vue')  // bagus ✅
```

## scrollBehavior

Mengatur posisi scroll tiap pindah halaman:
- **Back/forward**: `savedPosition` mengembalikan posisi terakhir
- **Anchor**: scroll ke elemen dengan `id` tertentu
- **Default**: scroll ke `top: 0` (paling atas) dengan animasi smooth

## Analogi — Papan Penunjuk Arah di Toko Buku

Bayangkan toko buku besar dengan 6 bagian:

| Route | Bagian Toko |
|---|---|
| `/` → Beranda | Pintu utama masuk toko |
| `/books/:id` → Detail | Setiap rak punya nomor unik |
| `/cart` → Keranjang | Meja kasir |
| `/wishlist` → Wishlist | Meja daftar keinginan |
| `/profile` → Profil | Meja anggota |
| `/:pathMatch(.)*` → 404 | Lorong buntu (tidak ada rak) |

**Papan penunjuk arah** (Router) dipasang di setiap sudut toko. Saat pengunjung mau ke kasir, papan bilang "belok kiri". Saat mau cari rak buku, papan bilang "lantai 2, rak 5".

**ScrollBehavior** seperti instruksi "setelah sampai, lihat ke atas (scroll to top)" atau saat kembali dari rak 5 ke beranda, pandangan otomatis kembali ke posisi sebelumnya.

## Dipakai untuk Apa

- **Single Page Application (SPA)**: Navigasi tanpa reload — seperti Google Maps, Gmail
- **Multi-role app**: Route berbeda untuk admin, user, guest
- **Deep linking**: URL bisa di-share — `https://toko-buku.com/books/42` langsung ke detail buku
- **Code splitting**: Hanya load kode yang diperlukan per halaman

## Kesalahan Umum

1. **Lupa pasang `app.use(router)`** → `RouterView` kosong, tidak ada yang tampil
2. **Urutan route 404 salah** → Catch-all route (`/:pathMatch(.*)*`) HARUS di **akhir** array routes. Kalau ditaruh di tengah, route lain di bawahnya tidak akan pernah terpanggil
3. **Lazy loading typo** → `() => { import() }` (pakai kurung kurawal) tidak return, harus `() => import()`
4. **Lupa `import.meta.env.BASE_URL`** di `createWebHistory` — path bisa salah saat deploy ke subfolder

## Hubungan dengan Materi Sebelumnya

- **Level 1 (Poin 1)**: `create-vue` sudah include Vue Router. Sekarang kita review dan perluas.
- **Level 2 (Poin 23)**: Cart state ada di `HomeView.vue`. Masalah: saat pindah dari halaman home ke `/books/:id` lalu back, cart **hilang** karena state di-reset. **Solusi**: Router tidak menyelesaikan ini sendirian — perlu **Pinia** (akan dibahas di Level 3 bagian State Management) untuk menyimpan cart secara global agar tidak hilang antar halaman.
- **Level 2 (Poin 17)**: `v-for` untuk render daftar buku akan diklik menuju `book-detail` (Poin 29).
