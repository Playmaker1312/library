# 49. Membuat FormField Component — Reusable Input dengan Error

## Penjelasan

**FormField** adalah komponen Vue reusable yang membungkus elemen `<input>` (atau `<textarea>`, `<select>`) dengan:

- **Label** yang konsisten
- **Error message** di bawah input
- **Dynamic styling** — border merah jika error, normal jika valid
- **Unique ID** — menghubungkan `label` dan `input` via `for` / `id` (aksesibilitas)

Komponen ini menggunakan `defineOptions({ inheritAttrs: false })` agar atribut seperti `type`, `placeholder`, `maxlength` bisa langsung dioper ke elemen `<input>` tanpa mendeklarasikannya satu per satu sebagai props.

## Fungsi

- **Konsistensi** — semua input di aplikasi punya tampilan dan perilaku yang sama
- **DRY** — tidak perlu menulis ulang label, error message, dan styling di setiap form
- **Aksesibilitas** — label terhubung ke input via id unik (menggunakan `useId()`)
- **Mudah dipelihara** — perubahan styling cukup di satu file

## Cara Implementasi

```vue
<!-- src/components/common/FormField.vue -->
<script setup lang="ts">
defineOptions({ inheritAttrs: false })

const props = defineProps<{
  label: string
  modelValue: string
  errorMessage?: string
  required?: boolean
}>()

const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()

const inputId = useId()
</script>

<template>
  <div class="form-field" :class="{ 'form-field--error': errorMessage }">
    <label :for="inputId" class="form-field__label">
      {{ label }}
      <span v-if="required" class="form-field__required">*</span>
    </label>
    <input
      :id="inputId"
      :value="modelValue"
      :class="['form-field__input', { 'form-field__input--error': errorMessage }]"
      v-bind="$attrs"
      @input="emit('update:modelValue', ($event.target as HTMLInputElement).value)"
    />
    <Transition name="fade">
      <p v-if="errorMessage" class="form-field__error">{{ errorMessage }}</p>
    </Transition>
  </div>
</template>

<style scoped>

```

### Cara pakai komponen

```vue
<FormField
  v-model="email"
  label="Email"
  type="email"
  placeholder="contoh@email.com"
  :error-message="errors.email"
  required
/>
```

Atribut `type="email"` dan `placeholder="..."` otomatis sampai ke `<input>` karena `inheritAttrs: false` + `v-bind="$attrs"`.

## Analogi — Toko Buku

**FormField** adalah **formulir standar** toko buku — semua kolom punya tampilan yang seragam:

- **Label** di atas (nama field): "Nama Lengkap", "Email", "Password"
- **Kotak isian** di tengah
- **Tempat pesan error** di bawah

Kalau ada kesalahan, border jadi merah dan pesan error muncul — konsisten untuk kolom **nama**, **email**, **password**, **alamat**, semuanya.

Tidak ada kolom yang tampil beda. Pelanggan (developer) tinggal pakai tanpa perlu mikir styling ulang setiap kali buat form baru.

## Dipakai untuk Apa

- Semua form input di aplikasi — login, register, checkout, profil, pengaturan
- Textarea, select, dan input type lain (dengan sedikit modifikasi)
- Form dengan banyak field — konsistensi terjamin

## Kesalahan Umum

| Kesalahan | Solusi |
|-----------|--------|
| Lupa `inheritAttrs: false` | Atribut tambahan tidak sampai ke `<input>` |
| ID tidak unique jika komponen dipakai berkali-kali | Gunakan `useId()` (Vue 3.5+) |
| Error message muncul tanpa transisi | Tambahkan `<Transition>` untuk UX lebih baik |
| `required` di prop tapi tidak ditampilkan di label | Tampilkan asterisk (`*`) jika `required` true |

## Hubungan dengan Materi Sebelumnya (Poin 48)

Di poin 48 kita:
- Membuat schema Zod untuk validasi
- Mendefinisikan tipe data (`LoginForm`, `RegisterForm`)

Sekarang **FormField** adalah komponen yang **menampilkan hasil validasi** tersebut di UI. Tanpa FormField, pesan error hanya ada di console atau object `errors` — tidak terlihat oleh user. FormField menjembatani antara **schema** (logika validasi) dan **tampilan** (UI).

## Soal Latihan

### Soal 1

Buat komponen `FormTextarea` yang mirip FormField tetapi menggunakan elemen `<textarea>` sebagai ganti `<input>`. Tambahkan prop `rows` (default 3) yang dioper ke textarea.

<details>
<summary>Jawaban</summary>

```vue
<!-- src/components/common/FormTextarea.vue -->
<script setup lang="ts">
defineOptions({ inheritAttrs: false })

const props = defineProps<{
  label: string
  modelValue: string
  errorMessage?: string
  required?: boolean
  rows?: number
}>()

const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()

const inputId = useId()
</script>

<template>
  <div class="form-field" :class="{ 'form-field--error': errorMessage }">
    <label :for="inputId" class="form-field__label">
      {{ label }}
      <span v-if="required" class="form-field__required">*</span>
    </label>
    <textarea
      :id="inputId"
      :value="modelValue"
      :rows="rows ?? 3"
      :class="['form-field__input', { 'form-field__input--error': errorMessage }]"
      v-bind="$attrs"
      @input="emit('update:modelValue', ($event.target as HTMLTextAreaElement).value)"
    ></textarea>
    <p v-if="errorMessage" class="form-field__error">{{ errorMessage }}</p>
  </div>
</template>
```

### Soal 2

Buat komponen `FormSelect` yang mirip FormField tetapi menampilkan `<select>` dengan opsi dari prop `options: { value: string; label: string }[]`.

<details>
<summary>Jawaban</summary>

```vue
<!-- src/components/common/FormSelect.vue -->
<script setup lang="ts">
defineOptions({ inheritAttrs: false })

const props = defineProps<{
  label: string
  modelValue: string
  options: { value: string; label: string }[]
  errorMessage?: string
  required?: boolean
}>()

const emit = defineEmits<{
  'update:modelValue': [value: string]
}>()

const inputId = useId()
</script>

<template>
  <div class="form-field" :class="{ 'form-field--error': errorMessage }">
    <label :for="inputId" class="form-field__label">
      {{ label }}
      <span v-if="required" class="form-field__required">*</span>
    </label>
    <select
      :id="inputId"
      :value="modelValue"
      :class="['form-field__input', { 'form-field__input--error': errorMessage }]"
      v-bind="$attrs"
      @change="emit('update:modelValue', ($event.target as HTMLSelectElement).value)"
    >
      <option value="" disabled>Pilih {{ label.toLowerCase() }}</option>
      <option
        v-for="opt in options"
        :key="opt.value"
        :value="opt.value"
      >
        {{ opt.label }}
      </option>
    </select>
    <p v-if="errorMessage" class="form-field__error">{{ errorMessage }}</p>
  </div>
</template>
```

</details>
