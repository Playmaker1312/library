# 72. File-Based Routing di Nuxt

## Penjelasan

Nuxt menggunakan **file-based routing** — struktur folder `pages/` secara otomatis menjadi struktur URL. Tidak perlu mendefinisikan route secara manual di `router/index.ts` seperti Vue SPA.

**Pemetaan folder ke URL:**

| File di `pages/` | URL yang dihasilkan |
|---|---|
| `pages/index.vue` | `/` |
| `pages/books.vue` | `/books` |
| `pages/books/[id].vue` | `/books/:id` |
| `pages/cart.vue` | `/cart` |
| `pages/about.vue` | `/about` |

Navigasi menggunakan `<NuxtLink>` (pengganti `<RouterLink>`) dan `navigateTo()` (pengganti `router.push()`). Keduanya auto-imported.

---

## Fungsi

- Routing otomatis berdasarkan file — tidak ada konfigurasi router terpisah
- Struktur URL selalu sinkron dengan folder — mudah diprediksi
- Mendukung dynamic routes dengan `[param].vue`
- Mendukung nested routes dengan subfolder

---

## Cara Implementasi

### 1. Halaman Beranda — `pages/index.vue`

```vue
<template>
  <div>
    <h1>BookStore — Nuxt</h1>
    <BookList />
  </div>
</template>

<script setup lang="ts">
// BookList dari components/BookList.vue — auto-imported
</script>
```

### 2. Halaman Detail Buku — `pages/books/[id].vue`

```vue
<template>
  <div v-if="book">
    <h1>{{ book.title }}</h1>
    <p>{{ book.author }}</p>
    <p>{{ book.description }}</p>
    <NuxtLink to="/books">← Kembali</NuxtLink>
  </div>
  <div v-else>
    <p>Buku tidak ditemukan</p>
  </div>
</template>

<script setup lang="ts">
const route = useRoute()
const id = route.params.id as string

// Simulasi data — nanti diganti useFetch
const books = [
  { id: '1', title: 'Clean Code', author: 'Robert Martin', description: 'Panduan menulis kode bersih.' },
  { id: '2', title: 'Design Patterns', author: 'Gang of Four', description: 'Pola desain OOP.' }
]
const book = books.find(b => b.id === id)
</script>
```

### 3. Halaman Cart — `pages/cart.vue`

```vue
<template>
  <div>
    <h1>Keranjang Belanja</h1>
    <CartItems />
    <NuxtLink to="/books">Lanjut Belanja</NuxtLink>
  </div>
</template>
```

### 4. Navigasi programatik — `navigateTo()`

```vue
<script setup lang="ts">
const goToDetail = (id: string) => {
  navigateTo(`/books/${id}`)
}
</script>
```

### 5. Nested route dengan layout

Buat `pages/category/index.vue` → `/category` dan `pages/category/[slug].vue` → `/category/:slug`

```vue
<!-- pages/category/index.vue -->
<template>
  <h1>Semua Kategori</h1>
</template>
```

```vue
<!-- pages/category/[slug].vue -->
<template>
  <h1>Kategori: {{ route.params.slug }}</h1>
</template>
```

---

## Analogi — Toko Buku

Di toko SPA (Vue), kita perlu **papan petunjuk manual** (`router/index.ts`) — seperti menempelkan kertas bertuliskan "Rak Fiksi — belok kiri", "Rak Non-Fiksi — lantai 2". Setiap kali menambah rak, kertas harus ditulis ulang.

Nuxt bekerja seperti **toko IKEA** — lorong mengikuti jalur yang sudah ditentukan. Jika ada folder `pages/books/` dengan file `[id].vue`, maka secara otomatis alamatnya `/books/:id`. Tidak perlu papan petunjuk tambahan. Cukup taruh file di tempat yang benar, alamatnya sudah jadi.

`<NuxtLink>` adalah pegawai toko yang mengantar pengunjung ke rak yang diminta. `navigateTo()` adalah sistem interkom yang memanggil pegawai untuk mengantar.

---

## Dipakai untuk Apa

- Semua aplikasi Nuxt — file-based routing adalah fondasi utama
- Situs dengan banyak halaman (toko online, blog, portal berita)
- Aplikasi dengan dynamic routes (detail produk, profil user, artikel)

---

## Kesalahan Umum

| Kesalahan | Akibat | Solusi |
|---|---|---|
| Masih pakai `<RouterLink>` | Error komponen tidak dikenal | Ganti dengan `<NuxtLink>` (auto-import) |
| Masih pakai `router.push()` | Error — `router` tidak dikenal | Ganti dengan `navigateTo()` (auto-import) |
| Lupa membuat `index.vue` di folder | Folder tanpa `index.vue` tidak menghasilkan route | Pastikan setiap folder punya `index.vue` |
| Nama file mengandung spasi | URL tidak valid | Gunakan `[param].vue`, hindari spasi |
| Mengira nama file bisa sembarang | Route tidak cocok | Sesuaikan dengan struktur folder yang diinginkan |

## Hubungan dengan Materi Sebelumnya

**Poin 71:** Project Nuxt sudah dibuat. Sekarang saatnya memindahkan halaman dari Vue SPA ke Nuxt.

**Level 4 (Vue Router):** Di SPA, routing didefinisikan manual di `router/index.ts`:

```ts
// Vue SPA — manual routing
const routes = [
  { path: '/', component: Home },
  { path: '/books/:id', component: BookDetail }
]
```

Di Nuxt, cukup letakkan file di `pages/`. Tidak perlu file router sama sekali. Proses migrasi: copy template dari `src/views/*.vue` ke `pages/*.vue`, ganti `<RouterLink>` dengan `<NuxtLink>`, ganti `router.push()` dengan `navigateTo()`.

### Soal 2

Apa perbedaan `<RouterLink>` (Vue Router) dengan `<NuxtLink>` (Nuxt)? Sebutkan minimal 2 perbedaan.

<details>
<summary>Jawaban</summary>

1. `<RouterLink>` butuh import dari `vue-router` — `<NuxtLink>` auto-imported
2. `<NuxtLink>` mendukung prefetching otomatis (saat link terlihat di viewport, Nuxt pre-fetch halaman tujuan)
3. `<NuxtLink>` kompatibel dengan SSR dan routing Nuxt — `<RouterLink>` tidak bisa digunakan langsung di Nuxt tanpa konfigurasi tambahan
</details>
