# 75. SEO dengan useHead dan useSeoMeta

## Penjelasan

SEO (Search Engine Optimization) adalah proses membuat halaman web mudah ditemukan dan dipahami oleh mesin pencari seperti Google. Nuxt menyediakan composable `useHead()` dan `useSeoMeta()` untuk mengatur meta tags per halaman — title, description, Open Graph tags, Twitter cards, dan lainnya.

```ts
// Di setiap halaman pages/
useSeoMeta({
  title: 'BookStore — Beli Buku Teknologi',
  description: 'Toko buku online untuk程序员. Buku pemrograman, software engineering, dan IT.',
  ogTitle: 'BookStore',
  ogDescription: 'Toko buku online untuk programmer.',
  ogImage: 'https://bookstore.com/og-image.jpg'
})
```

Meta tags ini akan muncul di HTML yang dikirim server. Googlebot, Facebook crawler, dan Twitter card semuanya bisa membaca konten tanpa perlu JavaScript.

---

## Fungsi

- Halaman muncul di Google dengan title dan deskripsi yang benar
- Kontrol tampilan saat link dibagikan di sosial media (OG tags)
- Perbaiki CTR (Click Through Rate) di hasil pencarian
- Dynamic meta tags — title berubah sesuai data buku, bukan hardcoded

---

## Cara Implementasi

### 1. Static SEO — Halaman Beranda

```vue
<!-- pages/index.vue -->
<template>
  <h1>Selamat datang di BookStore</h1>
  <BookList />
</template>

<script setup lang="ts">
useSeoMeta({
  title: 'BookStore — Toko Buku Teknologi No. 1',
  description: 'Jual buku pemrograman, software engineering, database, dan IT. Clean Code, Design Patterns, Refactoring, dan lainnya.',
  ogTitle: 'BookStore',
  ogDescription: 'Toko buku teknologi terlengkap. Belanja aman dan mudah.',
  ogImage: 'https://bookstore.com/images/og-default.jpg',
  ogType: 'website',
  twitterCard: 'summary_large_image'
})
</script>
```

### 2. Dynamic SEO — Halaman Detail Buku

```vue
<!-- pages/books/[id].vue -->
<template>
  <div v-if="book">
    <h1>{{ book.title }}</h1>
    <p>{{ book.author }}</p>
    <img :src="book.coverUrl" :alt="book.title" />
  </div>
</template>

<script setup lang="ts">
const route = useRoute()

const { data: book } = await useFetch<Book>(`/api/books/${route.params.id}`)

if (book.value) {
  useSeoMeta({
    title: `${book.value.title} — BookStore`,
    description: `Beli ${book.value.title} karya ${book.value.author}. ${book.value.description?.slice(0, 150)}`,
    ogTitle: `${book.value.title} — BookStore`,
    ogDescription: book.value.description?.slice(0, 200),
    ogImage: book.value.coverUrl,
    ogType: 'product'
  })
}
</script>
```

### 3. Menggunakan `useHead` untuk lebih banyak kontrol

```vue
<script setup lang="ts">
useHead({
  title: 'BookStore',
  meta: [
    { name: 'description', content: 'Toko buku online untuk programmer.' },
    { property: 'og:image', content: 'https://bookstore.com/og.jpg' },
    { name: 'keywords', content: 'buku, pemrograman, IT, teknologi' }
  ],
  link: [
    { rel: 'canonical', href: 'https://bookstore.com/books/1' }
  ]
})
</script>
```

### 4. SEO untuk halaman kategori

```vue
<!-- pages/category/[slug].vue -->
<script setup lang="ts">
const route = useRoute()
const slug = route.params.slug as string

const categoryNames: Record<string, string> = {
  'pemrograman': 'Buku Pemrograman',
  'database': 'Buku Database',
  'infrastruktur': 'Buku Infrastruktur IT'
}

const categoryName = categoryNames[slug] || slug

useSeoMeta({
  title: `${categoryName} — BookStore`,
  description: `Koleksi ${categoryName} terlengkap. Beli sekarang dan dapatkan diskon!`,
  ogTitle: `${categoryName} — BookStore`
})
</script>
```

### 5. Global SEO di `app.vue` atau layout

```vue
<!-- layouts/default.vue -->
<script setup lang="ts">
useSeoMeta({
  ogSiteName: 'BookStore',
  twitterCard: 'summary_large_image'
})
</script>
```

## Analogi — Toko Buku

SEO di Nuxt seperti **papan nama toko** yang terlihat dari jalan raya (Google).

Dulu (**SPA**), papan nama toko kosong — hanya title "BookStore" saja. Google yang lewat di jalan tidak tahu apa isi toko. Saat dibagikan ke teman di Facebook, hanya muncul URL mentah tanpa gambar atau deskripsi.

Sekarang (**Nuxt SSR**), setiap rak buku (halaman) punya **papan nama sendiri**:
- "Clean Code — BookStore" (title)
- "Beli Clean Code karya Robert Martin..." (description)
- Foto sampul buku (ogImage)

Saat dibagikan di Facebook, muncul **card** dengan gambar, judul, dan deskripsi. Semua ini sudah tercetak di HTML dari server — tidak perlu JavaScript untuk menampilkannya.

Google seperti **pembaca papan nama** yang berjalan kaki. Dengan papan nama jelas di setiap halaman, Google bisa mengindex SEMUA buku yang dijual. Tanpa papan nama, Google hanya melihat bangunan toko tanpa tahu barang dagangannya.

---

## Dipakai untuk Apa

- Semua halaman web yang ingin muncul di hasil pencarian Google
- Halaman produk — title + description dari nama produk
- Blog — title artikel, excerpt sebagai description
- Landing page — meta tags untuk meningkatkan CTR
- Social sharing — Open Graph tags untuk Facebook, LinkedIn, Twitter

---

## Kesalahan Umum

| Kesalahan | Akibat | Solusi |
|---|---|---|
| Lupa set meta tags per halaman | Semua halaman punya title "BookStore" saja | Set `useSeoMeta` di setiap halaman |
| `ogImage` pakai relative path | Gambar tidak muncul di sosial media | Gunakan **URL absolut** (`https://bookstore.com/image.jpg`) |
| Description terlalu panjang | Terpotong di hasil pencarian (max ~160 chars) | Ringkas deskripsi, maksimal 155–160 karakter |
| Title tidak unik per halaman | Google bingung halaman mana yang relevan | Gunakan `${judul} — BookStore` format |
| Meta tags di-set setelah fetch (tanpa guard) | Error saat data null | Bungkus dengan `if (book.value)` sebelum set meta |

---

## Hubungan dengan Materi Sebelumnya

**Poin 73:** Konten (data buku) sudah di-render server menggunakan `useFetch`. Sekarang **meta tags** juga di-render server — SEO lengkap.

**Poin 72:** Setiap file di `pages/` adalah halaman unik. Dengan `useSeoMeta` di setiap halaman, masing-masing punya title dan deskripsi sendiri. Ini penting karena Google mengindex **per URL**, bukan per aplikasi.

**Level 1–6 (SPA):** Di SPA murni, `<title>` hanya di-set sekali di `index.html`. Google tidak bisa membedakan halaman `/books/1` dengan `/books/2`. Nuxt memperbaiki ini dengan SSR + per-halaman meta tags.

### Soal 2

Mengapa `ogImage` harus menggunakan URL absolut (bukan `/images/cover.jpg`)?

<details>
<summary>Jawaban</summary>

Karena Open Graph tags dibaca oleh crawler sosial media (Facebook, Twitter, LinkedIn) yang tidak mengunjungi halaman secara langsung. Mereka membaca HTML dan mengambil URL gambar. Jika URL relatif seperti `/images/cover.jpg`, crawler tidak tahu domain asal dan tidak bisa menampilkan gambar. URL absolut seperti `https://bookstore.com/images/cover.jpg` memastikan gambar selalu bisa diakses.

</details>
