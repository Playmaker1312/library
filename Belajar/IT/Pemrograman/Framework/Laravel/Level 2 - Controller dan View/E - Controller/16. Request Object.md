# 16. Request Object — Data dari HTTP Request

## Penjelasan

**Request object** (`Illuminate\Http\Request`) merepresentasikan HTTP request yang masuk. Melalui object ini, kamu bisa mengakses semua data dari request:
- Input (form data, query string)
- File upload
- Header, IP address, URL
- HTTP method

Request di-inject otomatis ke controller method melalui Dependency Injection.

## Fungsi

- Mengakses data dari pengguna (form, query string, file)
- Validasi input di controller
- Mendapatkan informasi request (URL, method, IP, headers)
- Upload file

## Cara Pengimplementasian

```php
<?php
class BukuController extends Controller
{
    public function index(Request $request): View
    {
        // ─── QUERY STRING ─────────────────────────────────
        // URL: /buku?kategori=Teknologi&halaman=2

        $kategori = $request->query('kategori');          // 'Teknologi'
        $halaman  = $request->query('halaman', 1);        // 2 (default: 1)
        $semua    = $request->query();                     // ['kategori' => 'Teknologi', ...]

        // Cek keberadaan
        if ($request->has('kategori')) { /* ada */ }
        if ($request->filled('kategori')) { /* ada dan tidak kosong */ }

        // ─── INPUT (POST / PUT / PATCH) ────────────────────
        $judul     = $request->input('judul');
        $pengarang = $request->input('pengarang', 'Tidak Diketahui');
        $semua     = $request->all();
        $hanya     = $request->only(['judul', 'pengarang']);
        $kecuali   = $request->except(['_token', '_method']);

        // ─── INFORMASI REQUEST ───────────────────────────
        $url    = $request->url();         // http://localhost/buku
        $path   = $request->path();        // buku
        $method = $request->method();      // GET
        $ip     = $request->ip();          // 127.0.0.1
        $ajax   = $request->ajax();        // true jika request via AJAX

        // ─── FILE UPLOAD ─────────────────────────────────
        if ($request->hasFile('sampul')) {
            $file   = $request->file('sampul');
            $path   = $file->store('sampul-buku', 'public');
            $nama   = $file->getClientOriginalName();
            $ukuran = $file->getSize();
        }

        return view('buku.index', compact('buku', 'kategori'));
    }

    // ─── EXPECTS JSON ────────────────────────────────────
    public function api(Request $request)
    {
        if ($request->expectsJson()) {
            return response()->json(['data' => $buku]);
        }
        return view('buku.index', compact('buku'));
    }
}
```

## Analogi

Request object seperti **formulir yang diisi pengunjung perpustakaan**:

- `$request->input('judul')` = "Isi kolom 'Judul Buku' di formulir"
- `$request->query('kategori')` = "Lihat catatan di amplop (query string)"
- `$request->hasFile('sampul')` = "Apakah ada lampiran gambar sampul?"
- `$request->method()` = "Apa jenis permintaannya? (mau pinjam/mau balikin?)"
- `$request->ip()` = "Dari alamat mana pengunjung ini datang?"

Setiap pengunjung (HTTP request) membawa amplop yang berisi:
1. **Data di dalam amplop (POST body)** — `$request->input()` — formulir yang diisi
2. **Data di luar amplop (query string)** — `$request->query()` — catatan di amplop
3. **Informasi pengirim** — `$request->ip()`, `$request->header()` — alamat dan identitas

Pustakawan (controller) tinggal membaca amplop tersebut tanpa perlu membongkar sendiri.

## Dipakai untuk Apa

- **Setiap method `store` dan `update`** — mengambil data dari form
- **Filter dan pencarian** — mengambil parameter query string
- **Upload file** — menangani file dari form
- **API** — mengecek apakah request menginginkan JSON

## Kesalahan Umum

1. **Menggunakan `$_GET` atau `$_POST` langsung** — jangan! Gunakan `$request->input()` — lebih aman dan konsisten
2. **Tidak membedakan `input()` dan `query()`** — `input()` ambil dari manapun, `query()` hanya dari query string
3. **Lupa validasi** — jangan percaya input user. Validasi dulu sebelum pakai
4. **Mengakses file tanpa cek `hasFile()`** — error jika file tidak ada
5. **Salah method** — form dengan method POST harus diakses dengan route POST, bukan GET

## Koneksi dengan Materi Sebelumnya

Poin 15 memperkenalkan DI — Request adalah dependency yang paling sering di-inject. Poin 14 membuat controller — dan di dalam controller, Request digunakan untuk mengambil data.

**Benang merah ke depan:**
- Poin 17 (Passing Data ke View): Data dari request disaring, lalu dikirim ke view
- Poin 24 (Validasi): Request divalidasi sebelum diproses

## Soal Latihan

1. **Praktik**: Inject `Request` ke method `index`, ambil parameter `cari` dari query string, lalu kirim ke view!
2. **Praktik**: Buat form pencarian buku yang mengirim query string `?cari=clean` ke route `buku.index`!
3. **Analisis**: Apa perbedaan `$request->input('nama')` dengan `$request->query('nama')`? Kapan pakai yang mana?

<details>
<summary>Jawaban</summary>

1. **Kode:**
   ```php
   public function index(Request $request): View
   {
       $cari = $request->query('cari');
       // Filter data berdasarkan $cari
       return view('buku.index', compact('cari'));
   }
   ```

2. **Form pencarian:**
   ```blade
   <form action="{{ route('buku.index') }}" method="GET">
       <input type="text" name="cari" placeholder="Cari judul buku..."
              value="{{ request('cari') }}">
       <button type="submit">Cari</button>
   </form>
   ```
   Method GET agar parameter muncul di URL: `/buku?cari=clean`

3. **Perbedaan `input()` vs `query()`:**
   - `$request->input('nama')` — mengambil dari **semua sumber** (query string + POST body)
   - `$request->query('nama')` — hanya dari **query string** (URL bagian `?nama=...`)
   - **Gunakan `input()`** untuk form submission (POST)
   - **Gunakan `query()`** untuk filter/pencarian di URL (GET)
