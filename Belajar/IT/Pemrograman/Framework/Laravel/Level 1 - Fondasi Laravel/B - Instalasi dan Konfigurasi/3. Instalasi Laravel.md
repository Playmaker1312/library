# 3. Instalasi Laravel — Setup Project Perpustakaan

## Penjelasan

Ada dua cara utama untuk membuat project Laravel baru:
1. **Laravel Installer** (rekomendasi) — lebih cepat, fitur lebih lengkap
2. **Composer create-project** — cara standar

Setelah project dibuat, Laravel menyediakan `php artisan serve` untuk menjalankan server development lokal.

**Prasyarat Sistem:**
- PHP >= 8.2
- Composer
- Node.js (untuk asset bundling)
- Database (MySQL, PostgreSQL, SQLite, atau lainnya)

## Fungsi

- Membuat project Laravel baru dengan struktur direktori lengkap
- Mengunduh semua dependency yang dibutuhkan
- Menyediakan environment development lokal

## Cara Pengimplementasian

```bash
# Cek prasyarat
php --version
composer --version
node --version

# Cara 1: Laravel Installer (rekomendasi)
composer global require laravel/installer
laravel new perpustakaan

# Cara 2: Composer create-project
composer create-project laravel/laravel perpustakaan

# Saat diminta stack, pilih:
# - Starter kit: None (belajar manual dulu)
# - Testing framework: Pest
# - Database: MySQL (sesuai kebutuhan)

# Masuk ke project
cd perpustakaan

# Jalankan server development
php artisan serve
# Buka di browser: http://localhost:8000
```

**Setup dengan Laragon (Windows):**
```bash
# 1. Install Laragon dari https://laragon.org
# 2. Buat folder project di: C:\laragon\www\perpustakaan\
# 3. Akses: http://perpustakaan.test (Laragon auto-configure)
```

**Setup dengan Laravel Sail (Docker):**
```bash
# Untuk tim yang butuh environment seragam
php artisan sail:install
./vendor/bin/sail up
```

## Analogi

Membuat project Laravel seperti membeli **paket perpustakaan siap rakit**:

- **Laravel Installer** = Membeli paket lengkap dengan layanan antar-jemput — tinggal buka kotaknya, semua komponen sudah tersedia
- **Composer create-project** = Membeli dari toko online — harus menunggu paket dikirim (download) lalu dirakit
- **`php artisan serve`** = Menyalakan lampu perpustakaan — tandanya perpustakaan sudah siap dibuka

Setelah perpustakaan dibangun (`laravel new`), kamu menyalakan lampu (`php artisan serve`) dan melihat tampilan depan (halaman welcome).

## Dipakai untuk Apa

Setiap project Laravel dimulai dengan proses ini. Tanpa instalasi, tidak ada project yang bisa dikerjakan. Kamu akan melakukan ini setiap kali memulai project baru.

## Kesalahan Umum

1. **PHP atau Composer tidak terinstal** — selalu cek versi sebelum `laravel new`
2. **Gagal karena ekstensi PHP kurang** — pastikan ekstensi `mbstring`, `xml`, `curl`, `zip` aktif
3. **Node.js tidak terinstal** — Laravel 11 butuh Node.js untuk Vite
4. **Lupa `cd perpustakaan`** — perintah `php artisan serve` harus dijalankan di dalam folder project
5. **Port 8000 sudah dipakai** — gunakan `php artisan serve --port=8080`
6. **Error "Composer out of memory"** — jalankan `COMPOSER_MEMORY_LIMIT=-1 composer create-project laravel/laravel perpustakaan`

## Koneksi dengan Materi Sebelumnya

Di poin 1 kamu paham bagaimana Laravel bekerja, di poin 2 kamu paham filosofinya. Sekarang kamu siap membuat project pertama yang akan digunakan untuk semua pembelajaran selanjutnya.

**Benang merah ke depan:**
- Poin 4 (Struktur Direktori): Setelah project jadi, kamu perlu tahu arti setiap folder
- Poin 5 (.env): Database perlu dikonfigurasi agar aplikasi bisa menyimpan data

## Soal Latihan

1. **Praktik**: Buat project Laravel baru bernama `perpustakaan`, lalu jalankan `php artisan serve`. Tampilkan screenshot halaman welcome!
2. **Analisis**: Apa perbedaan `laravel new` dengan `composer create-project`? Mana yang lebih cepat dan mengapa?
3. **Pemecahan Masalah**: Jika `php artisan serve` menghasilkan error "Address already in use", apa yang harus dilakukan?

<details>
<summary>Jawaban</summary>

1. Jalankan perintah:
   ```bash
   laravel new perpustakaan
   cd perpustakaan
   php artisan serve
   ```
   Buka `http://localhost:8000` — akan tampil halaman welcome Laravel.

2. **Perbedaan:**
   - `laravel new` lebih cepat karena menggunakan cache lokal dari installer
   - `composer create-project` mendownload dari repository Composer — lebih lambat
   - Installer juga memberikan opsi interaktif (stack, database, dll) sebelum membuat project

3. **Solusi:**
   - Ganti port: `php artisan serve --port=8080`
   - Atau hentikan proses yang memakai port 8000:
     - Windows: `netstat -ano | findstr :8000` lalu `taskkill /PID <pid> /F`
     - Mac/Linux: `lsof -i :8000` lalu `kill -9 <pid>`
</details>
