# 8. Named Route — URL yang Fleksibel

## Penjelasan

**Named Route** adalah route yang diberi nama unik. Nama ini digunakan untuk merujuk ke route di seluruh aplikasi — bukan URL-nya. Ini adalah praktik terbaik (best practice) karena:

- Jika URL berubah, kamu hanya perlu edit di satu tempat (`routes/web.php`)
- Semua link di view dan redirect di controller menggunakan nama, bukan URL hardcode

```php
Route::get('/buku', [BukuController::class, 'index'])->name('buku.index');
// Nama: 'buku.index'
// URL: /buku
// Cara panggil: route('buku.index')
```

## Fungsi

- Memisahkan URL dari referensi kode — URL bisa berubah tanpa mengubah kode di tempat lain
- Menghasilkan URL secara konsisten (termasuk base URL)
- Memudahkan refactoring URL

## Cara Pengimplementasian

```php
<?php
// routes/web.php

// Beri nama dengan chain method ->name()
Route::get('/buku', [BukuController::class, 'index'])->name('buku.index');
Route::get('/buku/{id}', [BukuController::class, 'show'])->name('buku.show');
Route::get('/buku/tambah', [BukuController::class, 'create'])->name('buku.create');

// Cara generate URL dari nama route:
$urlIndex = route('buku.index');           // http://localhost:8000/buku
$urlShow  = route('buku.show', ['id' => 5]); // http://localhost:8000/buku/5
$urlShow  = route('buku.show', 5);           // shortcut
```

```php
{{-- Di Blade — SELALU gunakan route() bukan hardcode --}}
<a href="{{ route('buku.index') }}">Katalog Buku</a>
<a href="{{ route('buku.show', $buku->id) }}">{{ $buku->judul }}</a>

{{-- JANGAN begini --}}
<a href="/buku">Katalog</a>  {{-- Jika URL berubah, link ini rusak! --}}
```

```php
<?php
// Redirect ke named route — di controller
return redirect()->route('buku.index');
return redirect()->route('buku.show', ['id' => $buku->id]);
```

```php
<?php
// Route group dengan prefix nama
Route::name('admin.')->prefix('admin')->group(function () {
    Route::get('/dashboard', ...)->name('dashboard');
    // Nama lengkap: 'admin.dashboard'
    // URL: /admin/dashboard
});
```

## Analogi

Named route seperti **nama orang** vs **alamat rumah**:

- URL `/buku/show/5` adalah alamat: "Jalan Merdeka No. 5, RT 02 RW 03"
- Nama route `buku.show` adalah nama orang: "Pak Budi"

Kalau Pak Budi pindah rumah, kamu tetap bisa menghubungi "Pak Budi" — alamat barunya otomatis dicari. Tapi jika kamu menyimpan alamat lamanya, kamu akan tersesat.

**Di kode:**
```php
// Kamu menyimpan "nama orang" (route name)
route('buku.show', 5)

// BUKAN "alamat rumah" (URL hardcode)
/buku/show/5
```

Jika URL diubah dari `/buku/{id}` menjadi `/koleksi/{id}`, semua `route('buku.show', ...)` tetap berfungsi. Tapi `/buku/5` di view akan rusak.

## Dipakai untuk Apa

- **Setiap link di Blade** — `href="{{ route('...') }}"`
- **Setiap redirect di Controller** — `redirect()->route('...')`
- **Setiap URL di API response** — `route('api.buku.show', $buku)`
- **Setiap form action** — `<form action="{{ route('buku.store') }}">`

## Kesalahan Umum

1. **Tidak memberi nama pada route** — masih bisa dipakai, tapi merepotkan saat URL berubah
2. **Hardcode URL di view** — `href="/buku"` bukan `href="{{ route('buku.index') }}"`
3. **Nama route tidak unik** — error duplikasi nama
4. **Lupa parameter** — `route('buku.show')` tanpa `$id` → error
5. **Salah nama** — `route('buku.list')` padahal namanya `'buku.index'`
6. **Nama tidak konsisten** — campur-campur `buku-index`, `buku_index`, `buku.index`

## Koneksi dengan Materi Sebelumnya

Poin 7 memperkenalkan route dasar. Sekarang route tersebut diberi nama agar mudah dirujuk. Named route adalah jembatan menuju praktik yang lebih baik di poin berikutnya.

**Benang merah ke depan:**
- Poin 9 (Resource Route): Resource route otomatis memberi nama pada 7 route sekaligus
- Poin 12 (Blade Layout): `route()` dipakai di layout untuk navigasi

## Soal Latihan

1. **Praktik**: Beri nama `buku.store` pada route POST `/buku`, lalu buat form di Blade dengan action `route('buku.store')`!
2. **Analisis**: Jika URL berubah dari `/buku` menjadi `/katalog`, apa yang perlu diubah jika kita menggunakan named route? Apa yang perlu diubah jika tidak?
3. **Praktik**: Jalankan `php artisan route:list` dan perhatikan kolom "Name" — berapa banyak route yang sudah memiliki nama?
