# 24. Validasi di Controller dan Form Request

## Penjelasan

**Validasi** adalah proses memeriksa data input sebelum diproses. Laravel menyediakan dua cara:

1. **Validasi di Controller** — untuk form sederhana (2-3 field)
2. **Form Request** — class validasi terpisah (rekomendasi untuk form kompleks)

Aturan validasi ditulis sebagai array — ada ~60+ aturan bawaan seperti `required`, `email`, `unique`, `min`, `max`, `image`, dll.

**Alur Validasi:**
```
User submit form
    ↓
Validasi gagal → redirect back → tampilkan error di form
Validasi lolos → lanjut ke proses (create/update)
```

## Fungsi

- Memastikan data yang masuk sesuai format yang diharapkan
- Mencegah SQL injection, XSS, dan data kotor
- Memberikan feedback error yang jelas ke pengguna
- Memisahkan logika validasi dari logika bisnis (Form Request)

## Cara Pengimplementasian

```php
<?php
// Cara 1: Validasi di Controller (form sederhana)
public function store(Request $request): RedirectResponse
{
    $validated = $request->validate([
        'judul'     => ['required', 'string', 'max:200'],
        'pengarang' => ['required', 'string', 'max:100'],
        'isbn'      => ['nullable', 'digits:13', 'unique:buku,isbn'],
        'tahun'     => ['required', 'integer', 'min:1000', 'max:' . date('Y')],
        'harga'     => ['required', 'numeric', 'min:0'],
        'stok'      => ['required', 'integer', 'min:0'],
        'kategori'  => ['required', 'in:Teknologi,Fiksi,Sains,Sejarah'],
        'sampul'    => ['nullable', 'image', 'mimes:jpg,png', 'max:2048'],
    ]);

    $buku = Buku::create($validated);
    return redirect()->route('buku.show', $buku)->with('sukses', 'Buku ditambahkan!');
}
```

```php
<?php
// app/Http/Requests/StoreBukuRequest.php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Validation\Rule;

class StoreBukuRequest extends FormRequest
{
    // ✅ Siapa yang boleh submit form ini?
    public function authorize(): bool
    {
        return auth()->check() && auth()->user()->isAdmin();
    }

    // ✅ Aturan validasi
    public function rules(): array
    {
        return [
            'judul'     => ['required', 'string', 'max:200'],
            'pengarang' => ['required', 'string', 'max:100'],
            'isbn'      => ['nullable', 'digits:13', Rule::unique('buku', 'isbn')],
            'tahun'     => ['required', 'integer', 'min:1000', 'max:' . date('Y')],
            'harga'     => ['required', 'numeric', 'min:0'],
            'stok'      => ['required', 'integer', 'min:0'],
            'kategori'  => ['required', Rule::in(['Teknologi', 'Fiksi', 'Sains', 'Sejarah'])],
            'deskripsi' => ['nullable', 'string', 'max:2000'],
        ];
    }

    // ✅ Pesan error kustom (default: English)
    public function messages(): array
    {
        return [
            'judul.required'    => 'Judul buku wajib diisi.',
            'judul.max'         => 'Judul maksimal :max karakter.',
            'isbn.digits'       => 'ISBN harus 13 digit angka.',
            'isbn.unique'       => 'ISBN ini sudah terdaftar.',
            'sampul.image'      => 'File harus berupa gambar.',
        ];
    }

    // ✅ Modifikasi input sebelum validasi
    protected function prepareForValidation(): void
    {
        $this->merge([
            'judul' => trim($this->judul ?? ''),
            'isbn'  => preg_replace('/[^0-9]/', '', $this->isbn ?? ''),
        ]);
    }
}

// UpdateBukuRequest — unique kecuali record yang diedit
class UpdateBukuRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'isbn' => [
                'nullable',
                'digits:13',
                Rule::unique('buku', 'isbn')->ignore($this->route('buku')),
            ],
            // ... rules lainnya
        ];
    }
}
```

## Analogi

Validasi seperti **pustakawan yang memeriksa kartu anggota**:

- **`required`** = "Kolom nama wajib diisi" — tidak boleh kosong
- **`email`** = "Format harus email valid" — bukan "nama saya" tapi "nama@email.com"
- **`min:3`** = "Nama minimal 3 karakter" — bukan "A" tapi "Ali"
- **`unique:buku,isbn`** = "ISBN ini sudah ada" — buku duplikat ditolak
- **`image|max:2048`** = "Foto harus gambar, maks 2MB" — bukan file PDF 10MB

**Form Request** seperti **formulir standar perpustakaan**:
- Daripada setiap petugas membuat aturan sendiri (validasi di controller), perpustakaan menyediakan formulir baku (Form Request) yang sudah tercetak aturannya
- Setiap kali ada pengunjung yang mau daftar, tinggal ambil formulir itu

Tanpa validasi: "Buku dengan harga -50000 dan tahun 3000" masuk database. Validasi mencegah data aneh seperti itu.

## Dipakai untuk Apa

- **Setiap form submission** — tambah buku, edit buku, daftar anggota, peminjaman
- **File upload** — validasi ukuran, tipe file
- **Unik check** — ISBN, email, nomor anggota tidak boleh duplikat
- **Authorization** — Form Request juga bisa cek siapa yang boleh akses

## Kesalahan Umum

1. **Lupa validasi** — data masuk tanpa diperiksa → database kotor, rawan serangan
2. **Aturan validasi terlalu longgar** — `max:255` untuk judul padahal judul maximal 100 karakter
3. **Pesan error default (English)** — user bingung. Kustom pesan dengan `messages()`
4. **Lupa `Rule::unique()->ignore()` di update** — validasi gagal karena ISBN dianggap duplikat dengan dirinya sendiri
5. **Tidak menggunakan `old()` di input** — setelah validasi gagal, form kosong — user harus ngetik ulang
6. **Validasi di controller untuk form kompleks** — gunakan Form Request agar controller tetap bersih

## Koneksi dengan Materi Sebelumnya

Poin 22 (CRUD) belum ada validasi — data langsung disimpan. Sekarang dengan validasi, data diperiksa dulu sebelum masuk database. Ini meningkatkan keamanan dan kualitas data.

**Benang merah ke depan:**
- Poin 25 (Breeze): Breeze menyertakan validasi untuk form login/register
- Poin 28 (Policy): Form Request juga mengatur otorisasi (siapa yang boleh submit)
