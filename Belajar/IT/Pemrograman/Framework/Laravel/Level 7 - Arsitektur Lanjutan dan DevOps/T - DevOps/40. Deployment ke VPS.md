# 40. Deployment ke VPS — Langkah Demi Langkah

## Penjelasan

**Deployment** adalah proses memindahkan aplikasi dari lingkungan development ke production (server nyata). VPS (Virtual Private Server) adalah server pribadi yang bisa diakses publik.

**Komponen Deployment:**
- **Web Server** (Nginx) — menerima request dari browser
- **PHP-FPM** — menjalankan PHP
- **Database** (MySQL) — menyimpan data
- **Redis** — cache dan queue
- **Supervisor** — menjaga queue worker tetap hidup
- **SSL** (Let's Encrypt) — HTTPS

## Fungsi

- Membuat aplikasi bisa diakses publik (bukan hanya localhost)
- Performa optimal dengan cache dan optimasi
- Aman dengan HTTPS dan konfigurasi server yang benar
- Proses background berjalan terus (queue, scheduler)

## Cara Pengimplementasian

```bash
# ─── DI SERVER (Ubuntu 22.04) ──────────────────────────

# 1. Update sistem
sudo apt update && sudo apt upgrade -y

# 2. Install dependencies
sudo apt install -y nginx mysql-server php8.3-fpm php8.3-mysql \
    php8.3-mbstring php8.3-xml php8.3-curl php8.3-zip php8.3-redis \
    composer git supervisor redis-server certbot python3-certbot-nginx

# 3. Clone project
cd /var/www
sudo git clone https://github.com/username/perpustakaan.git
sudo chown -R www-data:www-data perpustakaan/
cd perpustakaan

# 4. Install dependencies
composer install --optimize-autoloader --no-dev

# 5. Setup environment
cp .env.example .env
php artisan key:generate
# Edit .env: APP_ENV=production, APP_DEBUG=false, DB_*, dll

# 6. Database
php artisan migrate --force
php artisan db:seed --force

# 7. Optimasi Laravel
php artisan optimize          # cache config, route, view
php artisan storage:link      # symlink storage → public

# 8. Permission
sudo chown -R www-data:www-data storage/ bootstrap/cache/
sudo chmod -R 775 storage/ bootstrap/cache/
```

```nginx
# /etc/nginx/sites-available/perpustakaan

server {
    listen 80;
    server_name perpustakaan.kota.id www.perpustakaan.kota.id;
    root /var/www/perpustakaan/public;
    index index.php;

    server_tokens off;

    # Security headers
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # Laravel routing
    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # PHP processing
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # Sembunyikan file sensitif
    location ~ /\.(env|git|htaccess) {
        deny all;
    }

    # Cache static files
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

```bash
# Aktifkan site dan SSL
sudo ln -s /etc/nginx/sites-available/perpustakaan /etc/nginx/sites-enabled/
sudo nginx -t  # test config
sudo systemctl reload nginx

# SSL dengan Let's Encrypt
sudo certbot --nginx -d perpustakaan.kota.id
```

```ini
# /etc/supervisor/conf.d/perpustakaan-worker.conf

[program:perpustakaan-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/perpustakaan/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/perpustakaan/storage/logs/worker.log
stopwaitsecs=3600
```

```bash
# Jalankan supervisor
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start all
```


## Analogi

Deployment seperti **meresmikan perpustakaan cabang baru**:

- **Development (local)** = Perpustakaan model di ruang belakang — hanya staf yang lihat
- **Production (VPS)** = Perpustakaan yang buka untuk umum — semua orang bisa masuk

**Proses:**
1. **Siapkan bangunan (VPS)** — instal Ubuntu, Nginx, MySQL, PHP
2. **Kirim buku (git clone)** — pindahkan kode dari repository
3. **Atur rak (migration)** — buat struktur database
4. **Optimasi (artisan optimize)** — cache agar halaman cepat
5. **Pasang CCTV (Supervisor)** — pastikan worker tetap jalan
6. **Buka pintu (SSL)** — akses via HTTPS aman

**Laravel Optimize untuk Production:**
```bash
php artisan optimize
# = config:cache + route:cache + view:cache + event:cache
# Semua konfigurasi digabung jadi 1 file — lebih cepat
```

## Dipakai untuk Apa

- **Setiap aplikasi yang siap production** — harus melalui proses deployment
- **Aplikasi publik** — bisa diakses user nyata
- **Tim** — staging server untuk testing, production untuk publik

## Kesalahan Umum

1. **`APP_DEBUG=true` di production** — error detail bocor ke user
2. **Lupa `php artisan migrate`** — aplikasi error karena tabel tidak ada
3. **Permission salah** — storage tidak bisa ditulis → error 500
4. **Queue worker tidak jalan** — email tidak terkirim, job menumpuk
5. **Lupa `composer install --no-dev`** — package development ikut terinstall (berat)
6. **SSL tidak aktif** — browser warning "Not Secure"
7. **Tidak backup database** — jika error migration, data bisa hilang

<details>
<summary>Jawaban</summary>

1. **Nginx config:**
   - Buat file `/etc/nginx/sites-available/perpustakaan` dengan konfigurasi di atas
   - `root` arahkan ke `/var/www/perpustakaan/public`
   - `sudo nginx -t` untuk test, `sudo systemctl reload nginx`

2. **Supervisor:**
   - Buat file config di `/etc/supervisor/conf.d/laravel-worker.conf`
   - `sudo supervisorctl reread && sudo supervisorctl update`
   - `sudo supervisorctl status` — pastikan running

3. **`APP_DEBUG=false` di production:**
   - **Risiko jika `true`**: stack trace error, path file absolut, query SQL, environment variables bisa bocor
   - Attacker bisa mendapatkan informasi sensitif (path file `/var/www/...`, versi package, kredensial database)
   - Ini adalah celah keamanan serius — jangan pernah `true` di production
</details>
