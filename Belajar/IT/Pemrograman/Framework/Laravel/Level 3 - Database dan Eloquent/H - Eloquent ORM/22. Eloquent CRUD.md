# 22. Eloquent CRUD — Create, Update, Delete

## Penjelasan

CRUD (Create, Read, Update, Delete) adalah operasi dasar pada data. Eloquent menyediakan method yang intuitif untuk setiap operasi.

**Create:**
```php
Buku::create($data);  // mass assignment (butuh $fillable)
// atau
$buku = new Buku(); $buku->judul = '...'; $buku->save();
```

**Read:**
```php
Buku::all(); Buku::findOrFail($id); Buku::where(...)->get();
```

**Update:**
```php
$buku->update($data);  // mass assignment
// atau
$buku->judul = '...'; $buku->save();
```

**Delete:**
```php
$buku->delete();     // soft delete (isi deleted_at)
$buku->forceDelete(); // hard delete (hapus permanen)
```

## Fungsi

- Create: menyimpan data baru ke database
- Read: mengambil data (dibahas detail di poin 21)
- Update: mengubah data yang sudah ada
- Delete: menghapus data (soft atau hard)

## Cara Pengimplementasian

```php
<?php
class BukuController extends Controller
{
    // ─── CREATE ──────────────────────────────────────────
    public function store(StoreBukuRequest $request): RedirectResponse
    {
        // Cara 1: mass assignment (rekomendasi — butuh $fillable)
        $buku = Buku::create($request->validated());

        // Cara 2: instance + save
        $buku = new Buku();
        $buku->judul     = $request->judul;
        $buku->pengarang = $request->pengarang;
        $buku->save();

        return redirect()
            ->route('buku.show', $buku)
            ->with('sukses', "Buku '{$buku->judul}' berhasil ditambahkan!");
    }

    // ─── UPDATE ──────────────────────────────────────────
    public function update(UpdateBukuRequest $request, Buku $buku): RedirectResponse
    {
        // Cara 1: mass assignment
        $buku->update($request->validated());

        // Cara 2: satu per satu
        $buku->judul = $request->judul;
        $buku->save();

        // Update increment/decrement
        $buku->increment('stok');       // stok + 1
        $buku->increment('stok', 5);    // stok + 5
        $buku->decrement('stok', 2);    // stok - 2

        // Batch update (tanpa fetch model)
        Buku::where('kategori', 'Lama')->update(['kategori' => 'Umum']);

        return redirect()
            ->route('buku.show', $buku)
            ->with('sukses', 'Buku berhasil diperbarui!');
    }

    // ─── DELETE ──────────────────────────────────────────
    public function destroy(Buku $buku): RedirectResponse
    {
        // Soft delete: isi deleted_at, data masih di database
        // Query normal tidak termasuk soft-deleted records
        $buku->delete();

        // Ambil data yang sudah soft-deleted
        Buku::withTrashed()->find($id);
        Buku::onlyTrashed()->get();

        // Restore
        $buku->restore();

        // Hard delete: benaran hapus
        // $buku->forceDelete();

        return redirect()
            ->route('buku.index')
            ->with('sukses', "Buku '{$buku->judul}' berhasil dihapus.");
    }
}
```

## Analogi

CRUD Eloquent seperti **proses peminjaman buku**:

**Create** = Mendaftarkan **buku baru** ke katalog:
- Mass assignment: Petugas input data di komputer — judul, pengarang, ISBN — dalam satu formulir, langsung masuk database
- Instance + save: Petugas input satu per satu — "Judulnya apa? Pengarangnya siapa?" — lebih aman untuk input bertahap

**Read** = Melihat data buku di katalog (dibahas di poin 21)

**Update** = Memperbaiki **data buku** yang salah:
- Misal: tahun terbit salah ketik — petugas edit di sistem
- `increment('stok')` = "Buku ini baru dikembalikan 1 eksemplar, tambah stok"

**Delete** = Menghapus buku dari katalog:
- **Soft delete** (default) = Buku dipindahkan ke **gudang bawah tanah** — tidak terlihat di rak, tapi masih ada catatannya. Kalau perlu, bisa diambil lagi (restore).
- **Hard delete** = Buku **dibakar** — hilang selamanya. Hanya dilakukan jika benar-benar yakin.

Laravel menganjurkan soft delete: data tidak benar-benar hilang, masih bisa diaudit.

## Dipakai untuk Apa

- **Setiap form submission** — tambah/edit data
- **Setiap tombol hapus** — dengan konfirmasi
- **Operasi batch** — update banyak record sekaligus
- **Increment/decrement** — stok barang, jumlah pinjaman

## Kesalahan Umum

1. **Form lupa `@csrf`** — error 419 Page Expired. CSRF token wajib di semua form POST/PUT/DELETE
2. **Method spoofing lupa** — form PUT harus pakai `@method('PUT')` karena HTML hanya support GET dan POST
3. **`update()` tanpa validasi** — data kotor masuk ke database. Selalu validasi dulu dengan Form Request
4. **Hard delete tanpa backup** — data hilang permanen. Gunakan soft delete default
5. **Lupa `$fillable`** — mass assignment error. `create()` dan `update()` butuh `$fillable`
6. **Tidak pakai `findOrFail`** — jika ID tidak ada, program lanjut dengan data null → error
