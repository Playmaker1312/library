# 19. Seeder dan Factory — Data Awal dan Data Palsu

## Penjelasan

**Seeder** dan **Factory** adalah dua alat untuk mengisi database dengan data.

- **Seeder**: Data spesifik yang ditentukan manual (data awal yang pasti, seperti admin user, kategori default)
- **Factory**: Generator data palsu (fake data) untuk development dan testing, menggunakan library **Faker**

```bash
php artisan make:factory BukuFactory --model=Buku
php artisan make:seeder BukuSeeder
php artisan make:seeder DatabaseSeeder  # sudah ada
```

**Alur:**
```
Migration → buat tabel kosong
    ↓
Seeder → isi data awal (fixed data)
Factory → generate data palsu untuk development/testing
    ↓
Database siap digunakan aplikasi
```

## Fungsi

- **Seeder**: Mengisi data yang pasti dibutuhkan aplikasi (admin, kategori default)
- **Factory**: Membuat data palsu untuk development — tampilan aplikasi lebih realistis
- Mempercepat setup development — `php artisan migrate:fresh --seed` langsung siap

## Cara Pengimplementasian

```php
<?php
// database/factories/BukuFactory.php

namespace Database\Factories;

use App\Models\Buku;
use Illuminate\Database\Eloquent\Factories\Factory;

class BukuFactory extends Factory
{
    protected $model = Buku::class;

    public function definition(): array
    {
        return [
            'judul'     => fake()->sentence(3, true),     // 3 kata
            'pengarang' => fake()->name(),
            'isbn'      => fake()->numerify('#############'), // 13 digit
            'penerbit'  => fake()->company(),
            'tahun'     => fake()->year(),
            'harga'     => fake()->numberBetween(50000, 500000),
            'stok'      => fake()->numberBetween(0, 20),
            'kategori'  => fake()->randomElement(['Teknologi', 'Fiksi', 'Sains', 'Sejarah']),
            'deskripsi' => fake()->paragraphs(2, true),
        ];
    }

    // Factory state — variasi data
    public function habis(): static
    {
        return $this->state(['stok' => 0]);
    }

    public function teknologi(): static
    {
        return $this->state(['kategori' => 'Teknologi']);
    }
}
```

```php
<?php
// database/seeders/BukuSeeder.php

namespace Database\Seeders;

use App\Models\Buku;
use Illuminate\Database\Seeder;

class BukuSeeder extends Seeder
{
    public function run(): void
    {
        // Fixed data — buku nyata
        Buku::create([
            'judul'     => 'Clean Code',
            'pengarang' => 'Robert C. Martin',
            'isbn'      => '9780132350884',
            'penerbit'  => 'Prentice Hall',
            'tahun'     => 2008,
            'harga'     => 150000,
            'stok'      => 5,
            'kategori'  => 'Teknologi',
        ]);

        Buku::create([
            'judul'     => 'Laskar Pelangi',
            'pengarang' => 'Andrea Hirata',
            'isbn'      => '9789793062792',
            'penerbit'  => 'Bentang Pustaka',
            'tahun'     => 2005,
            'harga'     => 95000,
            'stok'      => 8,
            'kategori'  => 'Fiksi',
        ]);

        // Fake data — 40 buku palsu
        Buku::factory()->count(40)->create();

        // Factory dengan state
        Buku::factory()->count(5)->habis()->create();
        Buku::factory()->count(5)->teknologi()->create();
    }
}
```

```php
<?php
// database/seeders/DatabaseSeeder.php

class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        // Urutan penting: pastikan FK terpenuhi
        $this->call([
            KategoriSeeder::class,  // seed kategori dulu

            PeminjamanSeeder::class,

```

```bash
# Jalankan
php artisan db:seed                    # jalankan DatabaseSeeder
php artisan db:seed --class=BukuSeeder  # seeder spesifik
php artisan migrate:fresh --seed        # reset + seed (paling sering dipakai)
```

## Analogi

Seeder dan Factory seperti **staf perpustakaan yang mengisi rak buku**:

**Seeder** = Pustakawan senior yang menempatkan **buku-buku khusus**:
- Buku referensi (kategori "Referensi")
- Buku langka (koleksi pertama)
- Buku dengan data yang pasti (admin user)
- Buku-buku ini harus ada — aplikasi butuh data ini untuk berfungsi

**Factory** = Asisten yang mengisi rak dengan **buku-buku umum**:
- Ambil buku dari gudang (Faker) — judul random, pengarang random
- Isi semua rak yang kosong
- Biar perpustakaan kelihatan penuh dan realistis saat development
- Buku-buku ini bisa dihapus kapan saja

Tanpa seeder: setiap migration fresh, database kosong. Harus input data manual lewat form. Tanpa factory: cuma 2-3 data, tampilan aplikasi sepi.

## Dipakai untuk Apa

- **Seeder**: Admin user pertama, kategori default, data master yang tetap
- **Factory**: Data uji coba untuk development, data untuk testing
- **`migrate:fresh --seed`**: Reset database dan isi ulang — sering dilakukan saat development

## Kesalahan Umum

1. **Seeder tergantung urutan** — jika BukuSeeder butuh kategori, KategoriSeeder harus jalan duluan
2. **Factory tanpa model** — `--model=Buku` harus sesuai
3. **Data seeder tidak lengkap** — aplikasi error karena butuh data tertentu yang tidak di-seed
4. **Hardcode data di factory** — factory harusnya generate random, bukan fixed
5. **Lupa panggil seeder di DatabaseSeeder** — seeder tidak akan jalan jika tidak dipanggil
6. **Factory state tidak terpakai** — buat state `habis()` tapi tidak dipanggil

## Koneksi dengan Materi Sebelumnya

Poin 18 membuat tabel kosong. Sekarang tabel diisi data. Migration + Seeder + Factory = database siap pakai.

**Benang merah ke depan:**
- Poin 20 (Eloquent Model): Model digunakan untuk mengakses data yang sudah di-seed
- Poin 35 (Testing): Factory sering dipakai di test untuk membuat data
