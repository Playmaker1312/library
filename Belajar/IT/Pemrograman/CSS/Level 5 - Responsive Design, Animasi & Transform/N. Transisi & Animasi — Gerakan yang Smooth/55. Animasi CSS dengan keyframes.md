# 55. Animasi CSS dengan @keyframes

## Penjelasan

`@keyframes` mendefinisikan **animasi multi-step** — perubahan dari state ke state dalam durasi tertentu.

```css
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.element {
  animation: fadeInUp 0.6s ease-out;
}
```

## Fungsi

- Animasi kompleks yang tidak bisa dilakukan dengan transisi biasa
- Animasi berulang (loading spinner, pulse)
- Animasi saat halaman dimuat

## Cara Pengimplementasian

```css
/* 1. Definisi keyframes */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

@keyframes fadeInUp {
  0%   { opacity: 0; transform: translateY(20px); }
  100% { opacity: 1; transform: translateY(0); }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.05); }
}

@keyframes slideInLeft {
  0%   { transform: translateX(-100%); opacity: 0; }
  100% { transform: translateX(0); opacity: 1; }
}

/* 2. Implementasi */
.loading-spinner {
  width: 40px;
  height: 40px;
  border: 3px solid var(--color-border);
  border-top-color: var(--color-primary);
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}

.hero-content {
  animation: fadeInUp 0.6s ease-out both;
}

.cta-button {
  animation: pulse 2s ease-in-out infinite;
}

/* Animation shorthand */
.element {
  animation: name duration timing-function delay iteration-count direction fill-mode play-state;
}

/* Contoh lengkap */
.modal {
  animation: fadeInUp 0.3s ease-out 0s 1 normal both;
}

/* Animation dengan delay berbeda untuk staggered effect */
.item:nth-child(1) { animation: fadeInUp 0.5s ease-out 0s both; }
.item:nth-child(2) { animation: fadeInUp 0.5s ease-out 0.1s both; }
.item:nth-child(3) { animation: fadeInUp 0.5s ease-out 0.2s both; }
```

## Analogi

Transisi seperti **pintu soft-close** — dari A ke B, sederhana. Keyframes seperti **tarian yang sudah dikoreografi** — ada gerakan 1 (angkat tangan), gerakan 2 (putar), gerakan 3 (duduk) — setiap langkah diatur waktunya.

Animasi `fadeInUp`: elemen mulai transparan & di bawah (opacity 0, translateY 20px) → berakhir terlihat & di posisi normal (opacity 1, translateY 0). Seperti orang yang muncul dari bawah panggung.

## Dipakai Untuk Apa

- Loading spinner
- Fade in saat halaman dimuat
- Pulse/attention seeker pada tombol CTA
- Slide in menu
- Shake pada input error
- Typing effect

## Kesalahan Umum

- **Lupa animation-fill-mode: both**: elemen loncat ke posisi awal sebelum animasi dimulai
- **Animasi terlalu panjang**: 3+ detik membuat user menunggu
- **Animasi di setiap elemen**: terlalu banyak gerakan — pilih elemen penting saja
- **Tidak hormati prefers-reduced-motion**: animasi panjang tanpa alternatif

## Hubungan dengan Materi Sebelumnya

Poin 54: transition untuk perubahan sederhana (A → B). **Keyframes** untuk animasi multi-step (A → B → C) atau berulang (spin, pulse). Loading spinner, fade-in hero, pulse CTA — membuat website lebih hidup.

## Soal Latihan

### Soal 1
Tulis keyframes untuk animasi fadeIn (dari transparan ke terlihat).

**Jawaban:**
```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}
```

### Soal 2
Apa fungsi `animation-fill-mode: both`?

**Jawaban:**
Elemen mengambil posisi awal animasi (from) sebelum dimulai, dan mempertahankan posisi akhir (to) setelah selesai. Mencegah "loncat" sebelum/sesudah animasi.

### Soal 3
Tulis CSS untuk loading spinner berputar terus.

**Jawaban:**
```css
.spinner {
  width: 40px; height: 40px;
  border: 4px solid #e5e7eb;
  border-top-color: #2563eb;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
@keyframes spin {
  to { transform: rotate(360deg); }
}
```
