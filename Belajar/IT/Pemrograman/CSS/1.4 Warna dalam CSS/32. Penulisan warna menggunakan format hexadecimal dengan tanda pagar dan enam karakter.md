# Penulisan warna menggunakan format hexadecimal dengan tanda pagar dan enam karakter

## Analogi: Perpustakaan Digital

Format hexadecimal seperti kode unik rak buku di perpustakaan digital — `#2A5B8C` adalah koordinat spesifik yang menunjuk ke warna eksak. Setiap dua karakter mewakili intensitas komponen merah, hijau, dan biru (dalam heksadesimal). Ini memberikan kontrol presisi seperti menentukan posisi buku di rak dengan koordinat X, Y, Z.

## Penjelasan Detail

Format warna hex (#RRGGBB) menggunakan tanda pagar (`#`) diikuti enam karakter heksadesimal (0-9, a-f). Dua digit pertama mewakili intensitas merah (RR), dua digit tengah untuk hijau (GG), dan dua digit terakhir untuk biru (BB). Setiap pasangan bernilai dari `00` (0, tanpa warna) hingga `FF` (255, intensitas penuh). Misalnya `#FF0000` adalah merah murni, `#00FF00` hijau murni, `#0000FF` biru murni, `#000000` hitam, dan `#FFFFFF` putih. Format ini memungkinkan lebih dari 16 juta variasi warna.

## Contoh Kode Implementasi

```css
/* Format hex #RRGGBB — 6 karakter */
.primary {
  background-color: #3498db; /* biru terang */
  color: #ffffff;            /* putih */
}

.dark {
  background-color: #2c3e50; /* biru gelap */
  color: #ecf0f1;            /* putih keabu-abuan */
}

.success {
  background-color: #27ae60; /* hijau */
  border: 2px solid #1e8449; /* hijau lebih gelap */
}

.card {
  background-color: #ffffff;
  border: 1px solid #e0e0e0;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

.text-primary {
  color: #3498db;
}

.error {
  color: #e74c3c; /* merah */
}
```

## Poin Penting
- Format hex: `#` + 6 digit heksadesimal (RRGGBB)
- Setiap pasangan digit mewakili intensitas merah, hijau, biru (0-255)
- Memberikan lebih dari 16 juta pilihan warna dengan presisi tinggi
