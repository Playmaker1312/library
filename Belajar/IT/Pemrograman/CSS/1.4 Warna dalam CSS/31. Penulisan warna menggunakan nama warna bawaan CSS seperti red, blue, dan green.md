# Penulisan warna menggunakan nama warna bawaan CSS seperti red, blue, dan green

## Analogi: Perpustakaan Digital

Nama warna CSS seperti label warna standar di perpustakaan digital — "Merah", "Biru", "Hijau" — yang mudah diingat dan langsung dikenali. Seperti pustakawan yang langsung tahu warna "Merah" tanpa perlu melihat kode warna, browser langsung memahami nama warna ini tanpa penjelasan tambahan.

## Penjelasan Detail

CSS mendefinisikan 148 nama warna standar (color keywords) yang bisa digunakan langsung dalam kode. Nama-nama ini mencakup warna dasar seperti `red`, `blue`, `green`, `black`, `white`, serta variasi seperti `darkblue`, `lightgreen`, `tomato`, `coral`, `steelblue`, dan `gold`. Nama warna bersifat case-insensitive, sehingga `RED`, `red`, dan `Red` sama-sama valid. Warna `transparent` dan `currentColor` juga termasuk color keywords. Meskipun mudah diingat, nama warna terbatas dalam variasi dan tidak memberikan kontrol presisi seperti format warna lainnya.

## Contoh Kode Implementasi

```css
/* Nama warna bawaan CSS */
.header {
  background-color: steelblue;
  color: white;
}

.alert {
  background-color: tomato;
  color: white;
  padding: 15px;
  border-radius: 4px;
}

.success {
  background-color: mediumseagreen;
}

.warning {
  background-color: gold;
  color: #333;
}

.info {
  background-color: skyblue;
  color: navy;
}

.text-muted {
  color: gray;
}

.divider {
  border-color: currentColor; /* menggunakan nilai color elemen */
}
```

## Poin Penting
- Ada 148 nama warna standar CSS yang case-insensitive
- Mudah diingat tetapi terbatas dalam variasi
- `transparent` dan `currentColor` adalah color keywords khusus
