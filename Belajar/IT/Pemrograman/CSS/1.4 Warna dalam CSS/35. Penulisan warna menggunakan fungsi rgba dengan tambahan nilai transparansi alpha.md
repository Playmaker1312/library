# Penulisan warna menggunakan fungsi rgba dengan tambahan nilai transparansi alpha

## Analogi: Perpustakaan Digital

Fungsi `rgba()` seperti kaca patri di perpustakaan digital — selain menentukan warna, Anda juga bisa mengatur tingkat transparansinya. Nilai alpha (a) seperti tingkat kejernihan kaca: 1 berarti buram penuh, 0 berarti transparan total, dan 0.5 berarti setengah tembus pandang.

## Penjelasan Detail

`rgba()` adalah ekstensi dari `rgb()` dengan tambahan parameter alpha (opacity). Sintaks: `rgba(merah, hijau, biru, alpha)`. Nilai alpha berkisar 0.0 (transparan penuh) hingga 1.0 (buram penuh). Nilai alpha bisa ditulis dalam persentase: 0% = 0, 100% = 1. CSS Color Module Level 4 mendefinisikan bahwa `rgb()` kini juga menerima parameter alpha opsional: `rgb(255 0 0 / 0.5)`. RGBA memungkinkan elemen latar belakang terlihat di belakang elemen yang diberi warna, menciptakan efek layering dan kedalaman.

## Contoh Kode Implementasi

```css
/* Fungsi rgba() — dengan alpha channel */
.overlay {
  background-color: rgba(0, 0, 0, 0.5); /* hitam semi-transparan */
  color: white;
  padding: 20px;
}

.card {
  background-color: rgba(255, 255, 255, 0.9); /* putih dengan transparansi */
  backdrop-filter: blur(10px);
}

.badge {
  background-color: rgba(231, 76, 60, 0.15); /* merah sangat transparan */
  color: #c0392b;
  padding: 4px 8px;
  border-radius: 4px;
}

/* Sintaks modern: rgb dengan alpha */
.button {
  background-color: rgb(52 152 219 / 0.8);
}

/* Efek glass morphism */
.glass {
  background: rgba(255, 255, 255, 0.25);
  border: 1px solid rgba(255, 255, 255, 0.3);
}
```

## Poin Penting
- `rgba()` = `rgb()` + alpha (transparansi)
- Nilai alpha: 0.0 (transparan) hingga 1.0 (buram)
- Berguna untuk overlay, efek glass, dan layering
