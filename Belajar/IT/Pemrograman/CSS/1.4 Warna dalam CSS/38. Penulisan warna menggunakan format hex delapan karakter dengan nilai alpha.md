# Penulisan warna menggunakan format hex delapan karakter dengan nilai alpha

## Analogi: Perpustakaan Digital

Format hex 8 karakter seperti kode rak yang juga menyertakan informasi apakah buku itu tersedia untuk umum atau terbatas. Selain koordinat warna (RRGGBB), ada kode tambahan (AA) yang menunjukkan tingkat visibilitas — dari 00 (tidak terlihat) hingga FF (terlihat penuh), seperti tirai yang bisa dibuka atau ditutup.

## Penjelasan Detail

Format hex 8 karakter (`#RRGGBBAA`) adalah ekstensi dari format hex 6 karakter dengan tambahan dua digit alpha. Dua digit terakhir (AA) mewakili tingkat opacity dalam heksadesimal: `00` = transparan penuh, `FF` = buram penuh, `80` = 50% transparan. Format ini juga memiliki versi singkat 4 karakter (`#RGBA`) di mana setiap digit digandakan. Format hex 8 karakter didukung di CSS Color Level 4, memberikan cara ringkas untuk menyertakan transparansi langsung dalam nilai hex.

## Contoh Kode Implementasi

```css
/* Format hex 8 karakter #RRGGBBAA */
.overlay {
  background-color: #00000080; /* hitam 50% transparan */
  color: #FFFFFFFF;            /* putih buram penuh */
}

.primary-transparent {
  background-color: #3498DB33; /* biru dengan 20% opacity */
}

.card-glass {
  background-color: #FFFFFF40; /* putih 25% transparan */
  border: 1px solid #FFFFFF80; /* border putih 50% transparan */
}

/* Format singkat 4 karakter #RGBA */
.short {
  background-color: #F008; /* #FF000088 — merah 53% transparan */
  color: #FFF;              /* #FFFFFF — putih buram */
}

/* Panel transparan */
.panel {
  background-color: #2C3E50CC; /* biru gelap 80% buram */
  color: #ECF0F1;
  padding: 20px;
  border-radius: 8px;
}
```

## Poin Penting
- Format hex 8 digit: `#RRGGBBAA` — RR, GG, BB, Alpha (00-FF)
- AA = 00 (transparan) hingga FF (buram)
- Ada juga format singkat 4 digit: `#RGBA`
- Didukung di CSS Color Level 4
