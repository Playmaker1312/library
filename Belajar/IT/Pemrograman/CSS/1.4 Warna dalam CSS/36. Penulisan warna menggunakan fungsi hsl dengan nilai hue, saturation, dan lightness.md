# Penulisan warna menggunakan fungsi hsl dengan nilai hue, saturation, dan lightness

## Analogi: Perpustakaan Digital

Fungsi `hsl()` seperti memilih warna cat untuk perpustakaan digital dengan cara yang lebih alami: pertama pilih warna dasar (hue) misalnya biru atau merah, lalu atur seberapa terang/vibrant warnanya (saturation), dan seberapa terang/gelap warnanya (lightness). Ini lebih intuitif daripada RGB karena mendekati cara manusia berpikir tentang warna.

## Penjelasan Detail

`hsl()` menggunakan tiga parameter: Hue (0-360 derajat pada roda warna), Saturation (0%-100%), dan Lightness (0%-100%). Hue 0/360 = merah, 120 = hijau, 240 = biru. Saturation 0% = abu-abu, 100% = warna penuh. Lightness 0% = hitam, 100% = putih, 50% = warna normal. HSL lebih mudah digunakan saat ingin membuat variasi warna — cukup ubah lightness atau saturation tanpa mengubah hue. Ini sangat berguna untuk tema warna yang konsisten.

## Contoh Kode Implementasi

```css
/* Fungsi hsl() — hue, saturation, lightness */
.primary {
  background-color: hsl(204, 64%, 44%);   /* biru (#3498db) */
  color: hsl(0, 0%, 100%);                 /* putih */
}

.danger {
  background-color: hsl(6, 78%, 57%);      /* merah (#e74c3c) */
}

.success {
  background-color: hsl(145, 63%, 49%);    /* hijau (#27ae60) */
}

/* Variasi warna dengan hue yang sama */
/* Warna dasar biru (hue: 204) */
.blue-100 { background-color: hsl(204, 70%, 90%); }
.blue-300 { background-color: hsl(204, 70%, 70%); }
.blue-500 { background-color: hsl(204, 70%, 50%); }
.blue-700 { background-color: hsl(204, 70%, 30%); }
.blue-900 { background-color: hsl(204, 70%, 10%); color: white; }

/* Desaturasi */
.muted { background-color: hsl(204, 20%, 50%); }
```

## Poin Penting
- Hue (0-360): posisi pada roda warna, 0=merah, 120=hijau, 240=biru
- Saturation (0%-100%): intensitas warna, 0%=abu-abu
- Lightness (0%-100%): 0%=hitam, 50%=normal, 100%=putih
- HSL lebih intuitif untuk membuat variasi dan tema warna
