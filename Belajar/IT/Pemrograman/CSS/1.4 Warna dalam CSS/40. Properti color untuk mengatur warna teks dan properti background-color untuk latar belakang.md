# Properti color untuk mengatur warna teks dan properti background-color untuk latar belakang

## Analogi: Perpustakaan Digital

Di perpustakaan digital, properti `color` seperti memilih warna tinta untuk mencetak teks di halaman buku. Properti `background-color` seperti memilih warna kertas atau dinding rak. Kombinasi keduanya menentukan kontras dan keterbacaan — teks gelap di latar terang atau sebaliknya, memastikan pengunjung bisa membaca dengan nyaman.

## Penjelasan Detail

`color` mengatur warna teks depan (foreground) dari suatu elemen. Properti ini diwariskan ke elemen turunan, sehingga mengubah `color` pada `body` akan mempengaruhi sebagian besar teks di halaman. `background-color` mengatur warna latar belakang elemen, mencakup area konten hingga batas padding (tidak termasuk margin dan border). Kombinasi warna teks dan latar harus memiliki kontras yang cukup untuk aksesibilitas — rasio kontras minimal 4.5:1 untuk teks normal. Kedua properti menerima semua format warna CSS.

## Contoh Kode Implementasi

```css
/* Properti color dan background-color */
body {
  color: #333;               /* teks abu-abu gelap */
  background-color: #fafafa; /* latar putih keabu-abuan */
}

.header {
  background-color: #2c3e50; /* latar biru gelap */
  color: #ffffff;             /* teks putih */
  padding: 20px;
}

.section-highlight {
  background-color: #fff3cd; /* latar kuning lembut */
  color: #856404;             /* teks coklat gelap */
  border: 1px solid #ffc107;
  padding: 15px;
  border-radius: 4px;
}

.link {
  color: #3498db;            /* teks biru */
  background-color: transparent; /* latar transparan */
}

.link:hover {
  color: #2980b9;            /* biru lebih gelap saat hover */
}

/* Aksesibilitas: kontras yang baik */
body {
  color: #1a1a1a;
  background-color: #ffffff;
}
```

## Poin Penting
- `color` mengatur warna teks (foreground), diwariskan ke elemen anak
- `background-color` mengatur warna latar belakang elemen
- Jaga rasio kontras minimal 4.5:1 untuk aksesibilitas
