# Penulisan warna menggunakan format hex singkat dengan tiga karakter

## Analogi: Perpustakaan Digital

Format hex singkat (3 karakter) seperti kode rak yang disingkat — alih-alih menulis "RAK-05-B-03", Anda cukup menulis "R5B3". Ini adalah cara cepat dan ringkas untuk warna-warna tertentu, mirip dengan singkatan yang digunakan pustakawan untuk menandai kategori buku secara cepat.

## Penjelasan Detail

Format hex singkat menggunakan tanda pagar diikuti tiga karakter heksadesimal: `#RGB`. Setiap karakter mewakili komponen merah, hijau, dan biru, tetapi nilai digandakan secara otomatis oleh browser. Jadi `#F00` sama dengan `#FF0000` (merah), `#0F0` sama dengan `#00FF00` (hijau), `#00F` sama dengan `#0000FF` (biru), `#FFF` sama dengan `#FFFFFF` (putih), dan `#000` sama dengan `#000000` (hitam). Format ini hanya mencakup 4.096 variasi warna (16^3) — lebih sedikit dari format 6 karakter (16^6). Tidak semua warna bisa direpresentasikan dalam format singkat.

## Contoh Kode Implementasi

```css
/* Format hex singkat #RGB — 3 karakter */
/* #F00 = #FF0000 (merah) */
.error { background-color: #F00; }

/* #0F0 = #00FF00 (hijau) */
.success { background-color: #0F0; }

/* #00F = #0000FF (biru) */
.link { color: #00F; }

/* #FFF = #FFFFFF (putih) */
.card { background-color: #FFF; }

/* #000 = #000000 (hitam) */
.footer { background-color: #000; color: #FFF; }

/* #888 = #888888 (abu-abu) */
.border { border: 1px solid #888; }

/* #FA0 = #FFAA00 (oranye) */
.warning { background-color: #FA0; }

/* Perbandingan: #ABC = #AABBCC */
.example { color: #ABC; }  /* sama dengan #AABBCC */
```

## Poin Penting
- Format singkat: `#` + 3 digit heksadesimal (RGB)
- Setiap digit digandakan: `#F00` = `#FF0000`
- Hanya 4.096 variasi warna — lebih hemat tetapi terbatas
