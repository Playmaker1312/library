# Penulisan warna menggunakan fungsi hsla dengan tambahan nilai transparansi alpha

## Analogi: Perpustakaan Digital

`hsla()` seperti memilih kaca berwarna untuk jendela perpustakaan digital — Anda tidak hanya memilih warna (hue, saturation, lightness) tetapi juga tingkat transparansinya. Anda bisa memiliki jendela biru yang tembus pandang atau buram, tergantung kebutuhan pencahayaan ruangan.

## Penjelasan Detail

`hsla()` adalah ekstensi dari `hsl()` dengan parameter alpha. Sintaks: `hsla(hue, saturation, lightness, alpha)`. Nilai alpha berkisar 0.0 (transparan penuh) hingga 1.0 (buram penuh). CSS Color Level 4 memungkinkan `hsl()` langsung menerima alpha: `hsl(204 64% 44% / 0.5)`. Kombinasi HSL dengan alpha sangat berguna untuk efek seperti backdrop overlay, bayangan berwarna, atau elemen UI dengan transparansi yang tetap mempertahankan hue yang konsisten.

## Contoh Kode Implementasi

```css
/* Fungsi hsla() — dengan alpha channel */
.overlay {
  background-color: hsla(0, 0%, 0%, 0.6); /* hitam 60% opaque */
  color: white;
  position: fixed;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;
}

.card {
  background-color: hsla(204, 70%, 50%, 0.1); /* biru sangat transparan */
  border: 1px solid hsla(204, 70%, 50%, 0.3);
  border-radius: 8px;
  padding: 20px;
}

.badge-warning {
  background-color: hsla(36, 100%, 50%, 0.15); /* oranye transparan */
  color: hsl(36, 100%, 35%);
}

/* Sintaks modern CSS Color Level 4 */
.modern {
  background-color: hsl(204 64% 44% / 0.8);
  border: 1px solid hsl(204 64% 44% / 0.4);
}

/* Bayangan dengan hue */
.shadow {
  box-shadow: 0 4px 20px hsla(204, 70%, 30%, 0.3);
}
```

## Poin Penting
- `hsla()` = `hsl()` + alpha channel untuk transparansi
- Nilai alpha: 0.0 (transparan) hingga 1.0 (buram)
- CSS Color Level 4: `hsl(hue saturation lightness / alpha)`
