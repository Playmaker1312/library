# Penulisan warna menggunakan fungsi rgb dengan nilai merah, hijau, dan biru

## Analogi: Perpustakaan Digital

Fungsi `rgb()` seperti mencampur cat di perpustakaan digital — Anda menentukan berapa banyak tetes cat merah, hijau, dan biru yang akan dicampur. Dengan mengatur intensitas masing-masing dari 0 hingga 255, Anda bisa menciptakan warna apa pun, persis seperti pustakawan yang mencampur warna cat untuk mengecat rak buku.

## Penjelasan Detail

Fungsi `rgb()` mendefinisikan warna menggunakan model warna aditif RGB (Red, Green, Blue). Sintaksnya: `rgb(merah, hijau, biru)` di mana setiap nilai berupa angka 0-255. `rgb(0, 0, 0)` adalah hitam, `rgb(255, 255, 255)` adalah putih, `rgb(255, 0, 0)` adalah merah murni. Format ini intuitif bagi yang terbiasa dengan nilai numerik, dan memberikan kontrol presisi yang sama dengan hex. CSS Color Module Level 4 juga mendukung sintaks dengan spasi: `rgb(255 0 0)` dan nilai persentase `rgb(100% 0% 0%)`.

## Contoh Kode Implementasi

```css
/* Fungsi rgb() — nilai 0-255 */
.merah {
  background-color: rgb(255, 0, 0);    /* merah murni */
  color: rgb(255, 255, 255);            /* putih */
}

.hijau {
  background-color: rgb(46, 204, 113);  /* hijau toska */
}

.biru {
  background-color: rgb(52, 152, 219);  /* biru muda */
}

.abu-abu {
  background-color: rgb(240, 240, 240); /* abu-abu terang */
  color: rgb(51, 51, 51);               /* abu-abu gelap */
}

/* Sintaks modern CSS Color Level 4 */
.modern {
  background-color: rgb(52 73 94);      /* spasi sebagai pemisah */
}

/* Nilai persentase */
.persen {
  background-color: rgb(20% 40% 80%);
}
```

## Poin Penting
- `rgb(merah, hijau, biru)` — setiap nilai 0-255
- Model warna aditif: kombinasi merah, hijau, biru
- Mendukung sintaks koma dan spasi (CSS Color Level 4)
