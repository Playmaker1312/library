# CSS Custom Properties atau variabel CSS untuk menyimpan nilai warna yang konsisten

## Analogi: Perpustakaan Digital

CSS Custom Properties seperti buku referensi warna pusat di perpustakaan digital. Alih-alih menulis kode warna di setiap rak buku, Anda cukup merujuk ke "Warna Utama" atau "Warna Aksen" yang sudah ditentukan. Jika ingin mengubah tema perpustakaan, cukup ubah satu entri di buku referensi, dan semua rak akan berubah secara otomatis.

## Penjelasan Detail

CSS Custom Properties (variabel CSS) didefinisikan dengan awalan dua tanda hubung (`--`), seperti `--primary: #3498db;`. Variabel biasanya dideklarasikan dalam selector `:root` agar tersedia secara global. Untuk menggunakan nilai variabel, gunakan fungsi `var()` — misalnya `color: var(--primary);`. Variabel CSS bersifat kaskade dan bisa diubah nilainya pada selector tertentu — mirip seperti scope dalam bahasa pemrograman. Ini sangat berguna untuk tema warna, konsistensi desain, dan kemudahan pemeliharaan.

## Contoh Kode Implementasi

```css
/* Deklarasi variabel CSS dalam :root */
:root {
  --primary: #3498db;
  --primary-dark: #2980b9;
  --secondary: #2ecc71;
  --danger: #e74c3c;
  --warning: #f39c12;
  --dark: #2c3e50;
  --light: #ecf0f1;
  --text: #333333;
  --text-light: #7f8c8d;
  --border-radius: 6px;
  --shadow: 0 2px 8px rgba(0,0,0,0.1);
}

/* Menggunakan variabel */
.button {
  background-color: var(--primary);
  color: white;
  border: none;
  border-radius: var(--border-radius);
  padding: 12px 24px;
  box-shadow: var(--shadow);
  transition: background-color 0.3s ease;
}

.button:hover {
  background-color: var(--primary-dark);
}

/* Tema berbeda — override variabel */
.dark-theme {
  --primary: #5dade2;
  --dark: #1a1a2e;
  --light: #16213e;
  --text: #e0e0e0;
  background-color: var(--dark);
}
```

## Poin Penting
- Variabel CSS dideklarasikan dengan `--nama` dan dipanggil dengan `var(--nama)`
- `:root` adalah tempat umum untuk variabel global
- Variabel CSS bersifat kaskade dan bisa dioverride untuk theming
