# Membangun Halaman Web yang Sepenuhnya Responsif dari Mobile hingga Desktop

## Analogi: Perpustakaan Digital

Halaman responsif seperti perpustakaan yang menata ulang raknya secara otomatis tergantung ukuran ruangan. Di layar kecil (ponsel), rak disusun vertikal. Di layar sedang (tablet), rak bisa dua kolom. Di layar besar (desktop), rak penuh dengan sidebar. Semua konten tetap bisa diakses tanpa harus scroll horizontal.

## Penjelasan Detail

Desain responsif menggunakan pendekatan mobile-first: mulai dari layout terkecil lalu tambahkan media query untuk layar lebih besar. Teknik utama: fluid grid (gunakan %, fr, auto), flexible images (max-width: 100%), media queries untuk breakpoint, dan relative units. Breakpoint umum: 576px (sm), 768px (md), 992px (lg), 1200px (xl). CSS Grid dan Flexbox sangat penting untuk layout responsif modern. Jangan lupa viewport meta tag di HTML dan testing pada berbagai ukuran layar.

## Contoh Kode Implementasi

```css
/* ==================== */
/* VIEWPORT — WAJIB di HTML */
/* ==================== */
/* <meta name="viewport" content="width=device-width, initial-scale=1"> */

/* ==================== */
/* MOBILE-FIRST LAYOUT */
/* ==================== */

/* Base (mobile) — 0px ke atas */
* { box-sizing: border-box; margin: 0; padding: 0; }

body {
  font-family: system-ui, -apple-system, sans-serif;
  line-height: 1.6;
  color: #1a1a2e;
}

.container {
  width: 100%;
  padding: 0 16px;
}

/* Mobile: 1 kolom, stacked */
.page-layout {
  display: grid;
  grid-template-columns: 1fr;
  gap: 24px;
  padding: 16px 0;
}

/* Header mobile */
.header {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  justify-content: space-between;
  padding: 12px 0;
}

.nav-links {
  display: flex;
  flex-direction: column;
  width: 100%;
  gap: 4px;
  margin-top: 12px;
}

.nav-links a {
  display: block;
  padding: 10px 0;
  text-decoration: none;
  color: #475569;
  border-bottom: 1px solid #e2e8f0;
}

/* Hero section mobile */
.hero {
  display: flex;
  flex-direction: column;
  gap: 24px;
  padding: 32px 0;
}

.hero-content h1 {
  font-size: 1.75rem;
  line-height: 1.2;
  margin-bottom: 12px;
}

.hero-image img {
  width: 100%;
  height: auto;
}

/* Card grid mobile */
.card-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

.card {
  padding: 20px;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
}

/* Sidebar mobile — muncul setelah konten */
.sidebar {
  order: 2;
}

.main-content {
  order: 1;
}

/* Footer mobile */
.footer {
  padding: 24px 0;
  text-align: center;
}

.footer-links {
  display: flex;
  flex-direction: column;
  gap: 8px;
  margin-bottom: 16px;
}

/* ==================== */
/* TABLET — 768px ke atas */
/* ==================== */
@media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }

  .page-layout {
    grid-template-columns: 2fr 1fr;
  }

  .nav-links {
    flex-direction: row;
    width: auto;
    gap: 16px;
    margin-top: 0;
  }

  .nav-links a {
    border-bottom: none;
    padding: 8px 12px;
  }

  .hero {
    flex-direction: row;
    align-items: center;
  }

  .hero-content {
    flex: 1;
  }

  .hero-content h1 {
    font-size: 2rem;
  }

  .hero-image {
    flex: 1;
  }

  .card-grid {
    grid-template-columns: repeat(2, 1fr);
  }

  .footer-links {
    flex-direction: row;
    justify-content: center;
  }
}

/* ==================== */
/* DESKTOP — 1024px ke atas */
/* ==================== */
@media (min-width: 1024px) {
  .container {
    max-width: 960px;
  }

  .page-layout {
    grid-template-columns: 3fr 1fr;
    gap: 32px;
  }

  .hero-content h1 {
    font-size: 2.5rem;
  }

  .card-grid {
    grid-template-columns: repeat(3, 1fr);
  }

  .header {
    padding: 16px 0;
  }
}

/* ==================== */
/* WIDE DESKTOP — 1280px ke atas */
/* ==================== */
@media (min-width: 1280px) {
  .container {
    max-width: 1200px;
  }

  .card-grid {
    grid-template-columns: repeat(4, 1fr);
  }
}

/* ==================== */
/* FLEXIBLE MEDIA */
/* ==================== */
img, video, iframe {
  max-width: 100%;
  height: auto;
}

/* ==================== */
/* RESPONSIVE TYPOGRAPHY */
/* ==================== */
h1 { font-size: clamp(1.5rem, 3vw + 0.5rem, 2.5rem); }
h2 { font-size: clamp(1.25rem, 2vw + 0.5rem, 2rem); }
p { font-size: clamp(0.875rem, 1vw + 0.5rem, 1rem); }

/* ==================== */
/* RESPONSIVE TABLES */
/* ==================== */
@media (max-width: 768px) {
  .responsive-table {
    overflow-x: auto;
    -webkit-overflow-scrolling: touch;
  }
}

/* ==================== */
/* HIDE/SHOW RESPONSIVE */
/* ==================== */
.hide-mobile { display: none; }
.show-mobile { display: block; }

@media (min-width: 768px) {
  .hide-mobile { display: block; }
  .show-mobile { display: none; }
  .hide-tablet { display: none; }
}
```

## Poin Penting
- Gunakan pendekatan mobile-first: layout dasar untuk mobile, media query untuk layar lebih besar
- CSS Grid dan Flexbox adalah fondasi layout responsif modern
- Gunakan relative units (%, fr, rem, clamp()) untuk fluiditas
- Breakpoint umum: 768px (tablet), 1024px (desktop), 1280px (wide)
