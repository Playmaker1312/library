# Membangun Dark Mode Toggle Menggunakan Variabel CSS dan JavaScript Minimal

## Analogi: Perpustakaan Digital

Dark mode seperti perpustakaan yang bisa beralih antara mode terang (dengan pencahayaan penuh) dan mode gelap (dengan pencahayaan redup) untuk kenyamanan membaca. Pengunjung bisa memilih mode sesuai preferensi, dan perpustakaan juga bisa otomatis menyesuaikan dengan waktu (siang/malam).

## Penjelasan Detail

Dark mode diimplementasikan dengan CSS custom properties yang berubah nilainya saat kelas atau atribut tertentu ditambahkan ke elemen root. JavaScript minimal digunakan untuk toggle, menyimpan preferensi di localStorage, dan mendeteksi preferensi sistem (prefers-color-scheme). Pendekatan ini memastikan dark mode tetap bertahan saat halaman direfresh. Variabel CSS memungkinkan seluruh tema berubah hanya dengan mengganti nilai variabel, tanpa mengubah kode CSS komponen satu per satu.

```javascript
// JavaScript minimal untuk dark mode toggle

// 1. Ambil elemen toggle
const themeToggle = document.getElementById('theme-toggle');

// 2. Deteksi preferensi sistem
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)');

// 3. Ambil tema tersimpan atau gunakan preferensi sistem
function getTheme() {
  const stored = localStorage.getItem('theme');
  if (stored) return stored;
  return prefersDark.matches ? 'dark' : 'light';
}

// 4. Terapkan tema
function setTheme(theme) {
  document.documentElement.setAttribute('data-theme', theme);
  localStorage.setItem('theme', theme);
}

// 5. Inisialisasi tema
setTheme(getTheme());

// 6. Toggle tema
themeToggle.addEventListener('click', () => {
  const current = document.documentElement.getAttribute('data-theme');
  const next = current === 'dark' ? 'light' : 'dark';
  setTheme(next);
});

// 7. Dengarkan perubahan preferensi sistem
prefersDark.addEventListener('change', (e) => {
  if (!localStorage.getItem('theme')) {
    setTheme(e.matches ? 'dark' : 'light');
  }
});
```

```css
  background: var(--bg-secondary);
}

  background: var(--text-muted);
  border-radius: 6px;
}
```

## Poin Penting
- Gunakan CSS custom properties untuk semua nilai yang berubah antar tema
- JavaScript menyimpan preferensi di localStorage dan mendeteksi prefers-color-scheme
- Terapkan transisi smooth pada properti yang berubah saat toggle tema
- Dark mode harus menghormati prefers-reduced-motion
