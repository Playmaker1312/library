# Membangun Komponen UI Interaktif seperti Dropdown, Accordion, dan Tab Hanya dengan CSS

## Analogi: Perpustakaan Digital

Komponen interaktif CSS murni seperti rak buku yang bisa diperluas, label yang bisa diklik untuk menampilkan detail, atau tab yang membagi koleksi buku berdasarkan kategori. Semua interaksi ini terjadi tanpa JavaScript — cukup menggunakan :hover, :focus, :target, dan checkbox hack.

## Penjelasan Detail

CSS dapat menciptakan komponen interaktif menggunakan pseudo-class seperti :hover, :focus-within, :target, dan :checked. Teknik umum: checkbox hack (sembunyikan checkbox, gunakan label untuk toggle), :target untuk navigasi berbasis anchor, dan :focus-within untuk dropdown. Keterbatasan: CSS murni tidak bisa mengelola state kompleks atau aksesibilitas penuh (ARIA). Untuk produksi, JavaScript tetap diperlukan untuk aksesibilitas optimal. Namun komponen CSS murni sangat berguna untuk prototipe cepat dan situasi di mana JavaScript terbatas.

## Contoh Kode Implementasi

```css
/* ==================== */
/* 1. DROPDOWN — dengan :focus-within */
/* ==================== */

.dropdown {
  position: relative;
  display: inline-block;
}

.dropdown-trigger {
  display: inline-flex;
  align-items: center;
  gap: 8px;
  padding: 10px 16px;
  background: #6366f1;
  color: white;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  font-size: 0.9rem;
}

.dropdown-menu {
  position: absolute;
  top: 100%;
  left: 0;
  min-width: 200px;
  margin-top: 4px;
  padding: 4px 0;
  background: white;
  border: 1px solid #e2e8f0;
  border-radius: 8px;
  box-shadow: 0 10px 15px -3px rgba(0,0,0,0.1);
  opacity: 0;
  visibility: hidden;
  transform: translateY(-8px);
  transition: all 200ms ease;
  z-index: 10;
}

.dropdown:focus-within .dropdown-menu,
.dropdown:hover .dropdown-menu {
  opacity: 1;
  visibility: visible;
  transform: translateY(0);
}

.dropdown-item {
  display: block;
  padding: 8px 16px;
  text-decoration: none;
  color: #334155;
  font-size: 0.9rem;
  transition: background 150ms;
}

.dropdown-item:hover {
  background: #f1f5f9;
}

/* ==================== */
/* 2. ACCORDION — dengan checkbox hack */
/* ==================== */

.accordion {
  border: 1px solid #e2e8f0;
  border-radius: 8px;
  overflow: hidden;
}

.accordion-item {
  border-bottom: 1px solid #e2e8f0;
}

.accordion-item:last-child {
  border-bottom: none;
}

/* Sembunyikan checkbox */
.accordion-toggle {
  display: none;
}

.accordion-header {
  display: block;
  padding: 16px 20px;
  background: #f8fafc;
  font-weight: 600;
  cursor: pointer;
  user-select: none;
  position: relative;
}

.accordion-header::after {
  content: "+";
  position: absolute;
  right: 20px;
  transition: transform 200ms;
}

/* Saat checkbox checked, ubah ikon dan tampilkan konten */
.accordion-toggle:checked + .accordion-header::after {
  content: "-";
}

.accordion-content {
  max-height: 0;
  overflow: hidden;
  transition: max-height 300ms ease;
  padding: 0 20px;
}

.accordion-toggle:checked ~ .accordion-content {
  max-height: 300px;
  padding: 16px 20px;
}

/* ==================== */
/* 3. TABS — dengan :target */
/* ==================== */

.tabs {
  display: flex;
  gap: 0;
  border-bottom: 2px solid #e2e8f0;
}

.tab-label {
  padding: 12px 24px;
  cursor: pointer;
  color: #64748b;
  font-weight: 500;
  border-bottom: 2px solid transparent;
  margin-bottom: -2px;
  transition: all 200ms;
  text-decoration: none;
}

.tab-label:hover {
  color: #6366f1;
}

/* Saat tab menjadi target, ubah styling */
.tab-label:target,
.tab-panel:target ~ .tabs .tab-label[href="#tab1"] {
  color: #6366f1;
  border-bottom-color: #6366f1;
}

.tab-panel {
  display: none;
  padding: 24px 0;
}

.tab-panel:target {
  display: block;
}

/* Default tab (tab1) */
#tab1:target ~ .tab-panel#tab1,
/* Jika tidak ada target, tampilkan tab1 */
body:not(:has(:target)) .tab-panel#tab1 {
  display: block;
}

/* ==================== */
/* 4. TOOLTIP — dengan :hover */
/* ==================== */

.tooltip-trigger {
  position: relative;
  cursor: help;
  border-bottom: 1px dashed #94a3b8;
}

.tooltip-trigger::after {
  content: attr(data-tooltip);
  position: absolute;
  bottom: 100%;
  left: 50%;
  transform: translateX(-50%) translateY(4px);
  padding: 6px 10px;
  background: #1e293b;
  color: white;
  font-size: 0.8rem;
  border-radius: 4px;
  white-space: nowrap;
  opacity: 0;
  visibility: hidden;
  transition: all 200ms;
  pointer-events: none;
}

.tooltip-trigger:hover::after {
  opacity: 1;
  visibility: visible;
  transform: translateX(-50%) translateY(-4px);
}

/* ==================== */
/* 5. MODAL — dengan :target */
/* ==================== */

.modal-overlay {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: rgba(0,0,0,0.5);
  display: flex;
  align-items: center;
  justify-content: center;
  opacity: 0;
  visibility: hidden;
  transition: all 300ms;
  z-index: 100;
}

.modal-overlay:target {
  opacity: 1;
  visibility: visible;
}

.modal {
  background: white;
  padding: 32px;
  border-radius: 12px;
  max-width: 500px;
  width: 90%;
  position: relative;
}

.modal-close {
  position: absolute;
  top: 16px;
  right: 16px;
  text-decoration: none;
  font-size: 1.5rem;
  color: #94a3b8;
}
```

## Poin Penting
- CSS dapat membuat interaksi UI menggunakan :hover, :focus-within, :target, dan checkbox hack
- Dropdown menggunakan :focus-within untuk menu yang muncul saat fokus
- Accordion menggunakan checkbox hack (:checked) untuk toggle konten
- Tabs dapat dibuat dengan :target atau radio button hack untuk state eksklusif
