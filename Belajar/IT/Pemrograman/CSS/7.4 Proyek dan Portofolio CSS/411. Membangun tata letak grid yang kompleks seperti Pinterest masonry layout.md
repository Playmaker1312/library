# Membangun Tata Letak Grid yang Kompleks seperti Pinterest Masonry Layout

## Analogi: Perpustakaan Digital

Masonry layout seperti papan pajangan buku di perpustakaan di mana buku-buku dengan tinggi berbeda ditempel di papan tanpa harus sejajar secara horizontal. Setiap kolom memiliki buku yang ditumpuk secara vertikal, menciptakan tata letak yang dinamis dan menarik tanpa celah putih yang besar.

## Penjelasan Detail

Masonry layout adalah tata letak grid di mana elemen memiliki lebar sama tetapi tinggi berbeda, membentuk kolom yang rapat tanpa celah vertikal besar. Ada tiga pendekatan utama: CSS multi-column, CSS Grid dengan dense packing, dan JavaScript library (Masonry, Isotope). Pendekatan CSS murni terbatas untuk masonry sejati karena CSS tidak bisa mengatur urutan elemen lintas kolom. CSS multi-column adalah solusi termudah tetapi mengalirkan konten vertikal (column-first). CSS Grid dengan grid-auto-rows dan span dapat mendekati masonry. Untuk masonry sejati seperti Pinterest, JavaScript library atau pendekatan JavaScript diperlukan.

## Contoh Kode Implementasi

```css
/* ==================== */
/* 1. CSS MULTI-COLUMN — termudah */
/* ==================== */

.masonry-columns {
  column-count: 3;
  column-gap: 16px;
}

.masonry-columns > * {
  break-inside: avoid;
  margin-bottom: 16px;
}

/* Responsive columns */
@media (max-width: 1024px) {
  .masonry-columns { column-count: 2; }
}

@media (max-width: 640px) {
  .masonry-columns { column-count: 1; }
}

/* Item dalam masonry */
.masonry-item {
  display: inline-block;
  width: 100%;
  background: white;
  border-radius: 12px;
  overflow: hidden;
  box-shadow: 0 2px 8px rgba(0,0,0,0.08);
}

.masonry-item img {
  width: 100%;
  display: block;
}

.masonry-item-content {
  padding: 16px;
}

/* ==================== */
/* 2. CSS GRID DENSE — pendekatan alternatif */
/* ==================== */

.masonry-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  grid-auto-rows: 10px; /* Basis baris kecil */
  gap: 16px;
}

/* Item dengan tinggi bervariasi */
.masonry-grid-item {
  grid-row: span var(--span, 30); /* Default span */
  /* Atur --span inline di HTML untuk setiap item */
}

/*
 * HTML:
 * <div class="masonry-grid-item" style="--span: 25">...</div>
 * <div class="masonry-grid-item" style="--span: 40">...</div>
 * <div class="masonry-grid-item" style="--span: 35">...</div>
 */

/* ==================== */
/* 3. MASONRY DENGAN CSS GRID + span (fixed) */
/* ==================== */

.grid-masonry {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: 200px;
  gap: 16px;
}

.grid-masonry .tall {
  grid-row: span 2;
}

.grid-masonry .wide {
  grid-column: span 2;
}

.grid-masonry .large {
  grid-column: span 2;
  grid-row: span 2;
}

/* Item styles */
.grid-item {
  border-radius: 12px;
  overflow: hidden;
  background: #f1f5f9;
  position: relative;
}

.grid-item img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.grid-item-content {
  position: absolute;
  bottom: 0;
  left: 0;
  right: 0;
  padding: 16px;
  background: linear-gradient(transparent, rgba(0,0,0,0.7));
  color: white;
}

/* ==================== */
/* 4. RESPONSIVE MASONRY */
/* ==================== */

@media (max-width: 1024px) {
  .masonry-columns { column-count: 2; }
  .grid-masonry { grid-template-columns: repeat(2, 1fr); }
}

@media (max-width: 640px) {
  .masonry-columns { column-count: 1; }
  .grid-masonry { grid-template-columns: 1fr; }
  .grid-masonry .wide,
  .grid-masonry .large { grid-column: span 1; }
}

/* ==================== */
/* 5. TRANSITION / ANIMASI */
/* ==================== */

.masonry-item {
  transition: transform 300ms ease, box-shadow 300ms ease;
}

.masonry-item:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 25px rgba(0,0,0,0.15);
}

/* ==================== */
/* 6. GAP / SPACING UTILITIES */
/* ==================== */

.masonry-gap-sm { gap: 8px; column-gap: 8px; }
.masonry-gap-md { gap: 16px; column-gap: 16px; }
.masonry-gap-lg { gap: 24px; column-gap: 24px; }
```

```javascript
// JavaScript untuk masonry sejati (opsional)
// Gunakan jika CSS murni tidak mencukupi

function createMasonry(containerSelector, columnCount = 3) {
  const container = document.querySelector(containerSelector);
  if (!container) return;

  const items = [...container.children];
  const columns = Array.from({ length: columnCount }, () => []);

  // Distribusi item ke kolom
  items.forEach((item, index) => {
    columns[index % columnCount].push(item);
  });

  // Render ulang dalam kolom
  container.innerHTML = '';
  container.style.display = 'flex';
  container.style.gap = '16px';
  container.style.alignItems = 'start';

  columns.forEach(col => {
    const colDiv = document.createElement('div');
    colDiv.style.flex = '1';
    colDiv.style.display = 'flex';
    colDiv.style.flexDirection = 'column';
    colDiv.style.gap = '16px';
    col.forEach(item => colDiv.appendChild(item.cloneNode(true)));
    container.appendChild(colDiv);
  });
}
```

## Poin Penting
- CSS multi-column (column-count) adalah cara termudah untuk masonry layout
- CSS Grid dengan auto-rows dan span membutuhkan perhitungan manual tinggi
- Untuk masonry sejati ala Pinterest, JavaScript masih diperlukan
- Selalu buat masonry responsif dengan media query
