# Membangun Efek Paralaks Murni Menggunakan CSS Tanpa JavaScript

## Analogi: Perpustakaan Digital

Efek paralaks seperti melihat pemandangan dari jendela perpustakaan yang sedang bergerak — pohon di dekat jendela bergerak cepat, gunung di kejauhan bergerak lambat. Ilusi kedalaman ini menciptakan pengalaman visual yang kaya. Di web, paralaks membuat latar belakang bergerak lebih lambat dari konten depan saat scroll.

## Penjelasan Detail

Paralaks murni CSS dapat dicapai dengan beberapa teknik. Teknik paling modern adalah menggunakan CSS Scroll-Driven Animations (scroll-timeline) yang masih baru. Teknik yang sudah mapan: perspective + transform: translateZ dengan scale untuk menciptakan ilusi paralaks (parallax transform). Teknik lain: background-attachment: fixed untuk efek paralaks pada background, dan position: sticky untuk elemen yang tetap di tempat saat scroll. Untuk efek paralaks paling halus tanpa JavaScript, gunakan kombinasi CSS perspective dan transform.

## Contoh Kode Implementasi

```css
/* ==================== */
/* 1. PARALLAX TRANSFORM — teknik perspective */
/* ==================== */

/* Container dengan perspective */
.parallax-container {
  perspective: 1px;
  height: 100vh;
  overflow-x: hidden;
  overflow-y: auto;
}

/* Grup paralaks */
.parallax-group {
  position: relative;
  transform-style: preserve-3d;
}

/* Background — bergerak lebih lambat */
.parallax-background {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  transform: translateZ(-1px) scale(2);
  /* translateZ negatif = lebih jauh = gerak lebih lambat */
  z-index: -1;
}

/* Foreground — bergerak normal */
.parallax-foreground {
  position: relative;
  z-index: 1;
}

/* ==================== */
/* 2. CONTOH LENGKAP */
/* ==================== */

.parallax-scroll {
  perspective: 1px;
  height: 100vh;
  overflow-x: hidden;
  overflow-y: auto;
  scroll-behavior: smooth;
}

.parallax-layer {
  position: relative;
  display: flex;
  align-items: center;
  justify-content: center;
  min-height: 60vh;
  padding: 20vh 10%;
  color: white;
  font-size: 2rem;
  font-weight: bold;
  text-shadow: 0 2px 8px rgba(0,0,0,0.3);
}

.parallax-layer--bg {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  transform: translateZ(-2px) scale(3);
  z-index: -1;
}

.parallax-layer--bg img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

/* ==================== */
/* 3. background-attachment: fixed */
/* ==================== */

.parallax-section {
  min-height: 60vh;
  display: flex;
  align-items: center;
  justify-content: center;
  padding: 80px 20px;
  position: relative;
  overflow: hidden;
}

.parallax-bg-fixed {
  background-image: url('https://picsum.photos/1920/1080');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  /* background-attachment: fixed menciptakan efek paralaks */
}

.parallax-bg-fixed .content {
  background: rgba(0, 0, 0, 0.5);
  padding: 40px;
  border-radius: 16px;
  color: white;
  text-align: center;
  max-width: 600px;
}

/* ==================== */
/* 4. STICKY PARALLAX — multiple layers */
/* ==================== */

.sticky-parallax {
  position: relative;
}

.sticky-parallax-layer {
  position: sticky;
  top: 0;
  height: 100vh;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 3rem;
  color: white;
  overflow: hidden;
}

.sticky-parallax-layer:nth-child(1) {
  z-index: 3;
  background: #6366f1;
}

.sticky-parallax-layer:nth-child(2) {
  z-index: 2;
  background: #8b5cf6;
  margin-top: -100vh;
}

.sticky-parallax-layer:nth-child(3) {
  z-index: 1;
  background: #a855f7;
  margin-top: -100vh;
}

/* Konten di dalam sticky layer */
.sticky-content {
  max-width: 800px;
  padding: 40px;
  text-align: center;
}

/* ==================== */
/* 5. SMOOTH SCROLL + PARALLAX */
/* ==================== */

html {
  scroll-behavior: smooth;
}

/* ==================== */
/* 6. RESPONSIVE PARALLAX */
/* ==================== */

@media (max-width: 768px) {
  /* Nonaktifkan paralaks di mobile untuk performa */
  .parallax-bg-fixed {
    background-attachment: scroll;
  }

  .parallax-layer--bg {
    transform: none !important;
  }

  .sticky-parallax-layer {
    position: relative;
    height: auto;
    margin-top: 0 !important;
  }
}

/* ==================== */
/* 7. REDUCED MOTION */
/* ==================== */

@media (prefers-reduced-motion: reduce) {
  .parallax-bg-fixed {
    background-attachment: scroll;
  }

  .parallax-scroll {
    perspective: none;
  }

  .parallax-layer--bg {
    transform: none !important;
  }

  /* Posisikan elemen paralaks sebagai normal */
  [class*="parallax"] {
    transform: none !important;
    background-attachment: scroll !important;
  }
}

/* ==================== */
/* 8. CONTOH PENGGUNAAN */
/* ==================== */

/* 
<div class="parallax-scroll">
  <section class="parallax-section parallax-bg-fixed">
    <div class="content">
      <h1>Selamat Datang</h1>
      <p>Paralaks dengan background-attachment: fixed</p>
    </div>
  </section>
  
  <section class="parallax-section" style="background: #1a1a2e;">
    <div class="content" style="background: rgba(255,255,255,0.1);">
      <h2>Bagian Normal</h2>
      <p>Scroll untuk efek paralaks</p>
    </div>
  </section>
</div>
*/

/* ==================== */
/* 9. FALLBACK UNTUK iOS */
/* ==================== */

/* iOS Safari tidak mendukung background-attachment: fixed dengan baik */
@supports (-webkit-touch-callout: none) {
  .parallax-bg-fixed {
    background-attachment: scroll;
  }
}
```

## Poin Penting
- Paralaks CSS murni menggunakan perspective + translateZ untuk ilusi kedalaman
- background-attachment: fixed adalah teknik sederhana untuk efek paralaks dasar
- Sticky positioning dapat menciptakan efek paralaks multi-layer
- Nonaktifkan paralaks di mobile dan saat prefers-reduced-motion untuk aksesibilitas dan performa
