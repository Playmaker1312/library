# Melakukan Refactoring Kode CSS yang Berantakan Menjadi Arsitektur yang Terorganisir

## Analogi: Perpustakaan Digital

Refactoring CSS seperti merapikan perpustakaan yang berantakan — buku berserakan (selector acak), label salah (nama class tidak konsisten), buku duplikat di banyak rak (CSS berulang), dan tidak ada sistem katalog (tidak ada struktur). Tujuan: menciptakan sistem yang teratur sehingga siapa pun bisa menemukan dan menata buku dengan mudah.

## Penjelasan Detail

Refactoring CSS adalah proses merestrukturisasi kode tanpa mengubah tampilan visual. Langkah-langkah: audit kode (identifikasi masalah seperti duplikasi, specificity tinggi, !important berlebihan), kategorisasi (base, layout, components, utilities), konsolidasi (hapus duplikasi, gabungkan aturan yang sama), adopsi metodologi (BEM, ITCSS, SMACSS), implementasi CSS custom properties, dan dokumentasi. Tools seperti PurgeCSS untuk menghapus CSS tidak terpakai, Stylelint untuk linting, dan browser DevTools untuk profiling.

## Contoh Kode Implementasi

```css
/* ==================== */
/* SEBELUM — kode berantakan */
/* ==================== */

/*
 * Masalah:
 * - Inconsistent naming: .btn, .button, .my-button
 * - Specificity tinggi: #header .nav ul li a
 * - !important berlebihan
 * - Duplikasi kode
 * - Tidak ada variabel
 * - Global style tanpa namespace
 */

#header .nav ul li a {
  color: blue !important;
  text-decoration: none;
}

.button {
  background: #6366f1;
  color: white;
  padding: 10px 20px;
  border: none;
}

  background: #6366f1;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
}

.btn {
  background: #6366f1;
  color: #fff;
  padding: 8px 16px;
  border: none;
  border-radius: 4px;
  font-size: 14px;
}

  border: 1px solid #ccc;
  padding: 20px;
  background: #fff;

  font-size: 18px;
```

```css
/* ==================== */
/* SESUDAH — terorganisir */
/* ==================== */

/* 1. DESIGN TOKENS */
:root {
  --clr-primary: #6366f1;
  --clr-dark: #1a1a2e;
  --clr-white: #ffffff;
  --clr-border: #e2e8f0;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 20px;
  --radius-sm: 4px;
  --radius-md: 8px;
  --fs-sm: 0.875rem;
}

/* 2. BASE */
* { box-sizing: border-box; margin: 0; padding: 0; }

/* 3. COMPONENTS — BEM naming */

/* Button */
.btn {
  display: inline-flex;
  align-items: center;
  padding: var(--spacing-sm) var(--spacing-md);
  font-size: var(--fs-sm);
  font-weight: 500;
  border: none;
  border-radius: var(--radius-sm);
  cursor: pointer;
  transition: background 200ms ease;
}

.btn--primary {
  background: var(--clr-primary);
  color: var(--clr-white);
}

.btn--primary:hover {
  background: #4f46e5;
}

/* Card */
.card {
  border: 1px solid var(--clr-border);
  padding: var(--spacing-lg);
  background: var(--clr-white);
  border-radius: var(--radius-md);
}

.card__title {
  font-size: 1.125rem;
  font-weight: 700;
  margin-bottom: var(--spacing-sm);
  color: var(--clr-dark);
}

.card__title--highlight {
  color: var(--clr-primary);
}

/* 4. LAYOUT — utility classes */
.u-bg-dark { background: var(--clr-dark); }
```

```css
/* ==================== */
/* PROSES REFACTORING */
/* ==================== */

/*
 * Langkah 1: Audit
 * - Hitung total CSS (size, jumlah selector, properti)
 * - Identifikasi unused CSS (gunakan Chrome Coverage)
 * - Cari duplikasi properti dan selector
 * - Catat penggunaan !important dan specificity tinggi
 * 
 * Langkah 2: Buat sistem
 * - Tentukan metodologi (BEM, ITCSS)
 * - Buat folder structure:
 *   styles/
 *   ├── base/
 *   │   ├── _reset.scss
 *   │   └── _typography.scss
 *   ├── components/
 *   │   ├── _button.scss
 *   │   ├── _card.scss
 *   │   └── _form.scss
 *   ├── layout/
 *   │   ├── _header.scss
 *   │   └── _grid.scss
 *   ├── utils/
 *   │   └── _variables.scss
 *   └── main.scss
 * 
 * Langkah 3: Ekstrak variabel
 * - Warna, font, spacing, breakpoint
 * 
 * Langkah 4: Refactor selector
 * - Ganti selector descendant (#header .nav ul li a)
 * - dengan class BEM (.header__nav-link)
 * 
 * Langkah 5: Hapus !important
 * - Gunakan specificity yang tepat atau CSS layers
 */

/* Contoh refactoring specificity tinggi */

/* Sebelum */
#sidebar .widget .title { color: blue; }

/* Sesudah — gunakan class dengan specificity tepat */
.widget__title { color: blue; }

/* Atau gunakan CSS layers */
@layer base, components, utilities;

@layer components {
  .widget__title { color: blue; }
}

/* ==================== */
/* TOOLS REFACTORING */
/* ==================== */

/* PurgeCSS config */
/*

  output: './dist/css/'
};
*/

    "max-nesting-depth": 3

```

## Poin Penting
- Audit kode untuk identifikasi masalah: duplikasi, !important, specificity tinggi
- Terapkan metodologi penamaan seperti BEM untuk konsistensi
- Ekstrak nilai berulang ke CSS custom properties
- Gunakan CSS layers untuk mengelola specificity
- Hapus CSS tidak terpakai dengan PurgeCSS
