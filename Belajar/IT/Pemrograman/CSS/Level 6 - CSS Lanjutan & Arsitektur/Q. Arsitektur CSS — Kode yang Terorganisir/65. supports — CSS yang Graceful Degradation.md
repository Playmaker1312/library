# 65. @supports — CSS yang Graceful Degradation

## Penjelasan

`@supports` (feature queries) memungkinkan CSS diterapkan **hanya jika browser mendukung** properti tertentu.

```css
/* Semua browser: fallback dasar */
.element {
  background-color: var(--color-primary);
}

/* Browser yang support backdrop-filter: efek kaca */
@supports (backdrop-filter: blur(10px)) {
  .element {
    background-color: rgba(255, 255, 255, 0.7);
    backdrop-filter: blur(10px);
  }
}
```

## Fungsi

- Menggunakan fitur CSS modern tanpa merusak pengalaman di browser lama
- Progressive enhancement: mulai dari dasar, tambah fitur jika didukung

## Cara Pengimplementasian

```css
/* 1. Backdrop-filter dengan fallback */
header {
  background-color: white; /* fallback */
}

@supports (backdrop-filter: blur(10px)) or (-webkit-backdrop-filter: blur(10px)) {
  header {
    background-color: rgba(255, 255, 255, 0.8);
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px);
  }
}

/* 2. Grid dengan fallback ke flexbox */
@supports not (display: grid) {
  .projects-grid {
    display: flex;
    flex-wrap: wrap;
    gap: var(--space-6);
  }
  .project-card {
    width: calc(33.33% - var(--space-6));
  }
}

/* 3. Aspect-ratio fallback */
.card-image {
  width: 100%;
  padding-bottom: 56.25%;  /* 16:9 fallback */
  position: relative;
}

@supports (aspect-ratio: 16 / 9) {
  .card-image {
    aspect-ratio: 16 / 9;
    padding-bottom: 0;
  }
}

/* 4. Scroll behavior */
html {
  scroll-behavior: smooth;
}

@supports not (scroll-behavior: smooth) {
  html { scroll-behavior: auto; }
  /* Browser lama: scroll instan — tetap functional */
}

/* 5. Kombinasi dengan media query */
@supports (display: grid) {
  @media (min-width: 768px) {
    .grid {
      display: grid;
      grid-template-columns: repeat(2, 1fr);
    }
  }
}
```

## Analogi

Seperti **rencana cadangan di rumah**:
- Listrik mati → siapkan lilin (grid fallback ke flexbox)
- Pipa bocor → siapkan ember (backdrop-filter fallback ke solid color)
- Pintu macet → siapkan tangga darurat

`@supports` memastikan rumah (website) tetap berfungsi dalam kondisi apa pun — fitur modern adalah bonus, bukan keharusan.

- **Progressive enhancement**: semua user dapat basic functionality. User dengan browser modern dapat enhanced experience.

## Dipakai Untuk Apa

- Fitur CSS baru yang belum didukung semua browser
- Backdrop-filter, clip-path, grid (di IE), aspect-ratio (di browser lama)
- Graceful degradation untuk fitur dekoratif

## Kesalahan Umum

- **@supports untuk properti yang sudah universal**: grid, flexbox, css variables sudah didukung di semua browser modern — tidak perlu @supports
- **Fallback tidak di-test**: pastikan fallback benar-benar berfungsi, bukan sekadar ada
- **@supports untuk properti yang tidak bisa di-detect**: beberapa properti didukung secara parsial — @supports deteksi ada/tidak, bukan kualitas dukungan

## Hubungan dengan Materi Sebelumnya

Poin 60-62: fitur modern (aspect-ratio, backdrop-filter, clip-path). Tapi tidak semua browser mendukung. **@supports** memungkinkan kita menggunakan fitur tersebut sambil tetap memberikan pengalaman yang baik di browser lama — profesional dan user-friendly.

## Soal Latihan

### Soal 1
Tulis @supports untuk backdrop-filter dengan fallback background solid.

**Jawaban:**
```css
.element { background-color: white; }
@supports (backdrop-filter: blur(10px)) {
  .element { background-color: rgba(255,255,255,0.8); backdrop-filter: blur(10px); }
}
```

### Soal 2
Apa perbedaan progressive enhancement dan graceful degradation?

**Jawaban:**
Progressive enhancement: mulai dari dasar yang berfungsi di semua browser, lalu tambah fitur untuk browser modern. Graceful degradation: mulai dari fitur lengkap (modern), lalu siapkan fallback untuk browser lama.

### Soal 3
Kapan @supports TIDAK diperlukan?

**Jawaban:**
Untuk properti yang sudah didukung secara universal oleh semua browser target — flexbox, grid, css variables, border-radius, dll.
