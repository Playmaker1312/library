# 60. Fitur CSS Modern — aspect-ratio, object-fit & scroll-behavior

## Penjelasan

Tiga fitur CSS modern yang menyederhanakan tugas umum:

- **`aspect-ratio`**: menjaga rasio aspek elemen tanpa padding hack
- **`object-fit`**: mengontrol bagaimana gambar/video mengisi kontainernya
- **`scroll-behavior`**: scroll halus untuk anchor links

```css
.video { aspect-ratio: 16 / 9; }
img { object-fit: cover; }
html { scroll-behavior: smooth; }
```

## Fungsi

- **aspect-ratio**: kotak/video dengan rasio tetap — tanpa padding hack 56.25%
- **object-fit**: gambar proporsional tanpa distorsi
- **scroll-behavior**: navigasi anchor link yang smooth

## Cara Pengimplementasian

```css
/* aspect-ratio — menggantikan padding-bottom hack */
.video-wrapper {
  aspect-ratio: 16 / 9;      /* 16:9 — widescreen */
  width: 100%;
}

.avatar {
  aspect-ratio: 1;           /* 1:1 — persegi sempurna */
  width: 64px;
  border-radius: 50%;
}

.card-image {
  aspect-ratio: 4 / 3;      /* 4:3 */
  width: 100%;
}

/* object-fit — untuk gambar dalam container */
.gallery-image {
  width: 100%;
  height: 250px;
  object-fit: cover;          /* potong proporsional, penuhi container */
  object-position: center;    /* fokus di tengah */
}

.contain-image {
  object-fit: contain;        /* gambar utuh, mungkin ada ruang kosong */
  object-position: top;
}

.profile-photo {
  width: 200px;
  height: 200px;
  object-fit: cover;
  border-radius: 50%;
}

/* scroll-behavior */
html {
  scroll-behavior: smooth;
  /* Sekarang semua anchor link scroll halus */
}

/* Matikan jika user prefer reduced motion */
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
}
```

## Analogi

- **aspect-ratio** = **bingkai foto dengan rasio tetap**. Kamu beli bingkai 4R (4:6) — tidak peduli seberapa besar, bentuknya tetap proporsional. Dulu, untuk buat video 16:9 di CSS, perlu padding-bottom: 56.25% — rumit. Sekarang `aspect-ratio: 16/9`.
- **object-fit** = **bagaimana foto dimasukkan ke bingkai**. `cover` = potong foto agar penuhi bingkai (mungkin ada bagian terpotong). `contain` = perkecil foto agar utuh dalam bingkai (mungkin ada ruang putih). Dulu untuk effect ini butuh background-image.
- **scroll-behavior** = **eskalator di mal, bukan tangga**. Anchor link biasanya langsung loncat (tangga). Smooth scroll seperti eskalator — halus dan nyaman.

## Dipakai Untuk Apa

- **aspect-ratio**: video embed, avatar, card image, hero image
- **object-fit**: gallery, product image, profile photo, banner
- **scroll-behavior**: navigasi halaman satu halaman (single page)

## Kesalahan Umum

- **aspect-ratio tanpa width/height**: butuh setidaknya satu dimensi — aspect-ratio bekerja dengan dimensi yang tersedia
- **object-fit tidak berfungsi tanpa width & height**: gambar perlu dimensi container agar object-fit bekerja
- **scroll-behavior di body, bukan html**: taruh di `html`, bukan `body`
- **Lupa reduced motion**: user dengan gangguan vestibular bisa mual

## Hubungan dengan Materi Sebelumnya

Poin 21-25: background dan border untuk visual. Tapi **gambar** perlu penanganan khusus — rasio aspek, cropping proporsional. **aspect-ratio, object-fit, dan scroll-behavior** adalah fitur modern yang membuat tugas-tugas umum jadi lebih sederhana.

## Soal Latihan

### Soal 1
Tulis CSS untuk video wrapper 16:9 yang responsif.

**Jawaban:**
```css
.video-wrapper {
  aspect-ratio: 16 / 9;
  width: 100%;
}
```

### Soal 2
Apa perbedaan `object-fit: cover` dan `object-fit: contain`?

**Jawaban:**
`cover` — gambar memenuhi container, proporsi terjaga, bagian mungkin terpotong. `contain` — gambar utuh dalam container, proporsi terjaga, mungkin ada ruang kosong.

### Soal 3
Di selector mana `scroll-behavior: smooth` ditempatkan?

**Jawaban:**
Di `html` (bukan `body`): `html { scroll-behavior: smooth; }`
