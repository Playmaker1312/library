# Nesting dalam SASS untuk Menulis Selector Bersarang yang Mencerminkan Struktur HTML

## Analogi: Perpustakaan Digital

Dalam perpustakaan digital, struktur kategori buku bersarang seperti "Sains > Komputer > Pemrograman Web > CSS". Setiap subkategori berada di dalam kategori induknya, menciptakan hierarki yang jelas. Nesting dalam SASS bekerja seperti ini — selector anak ditulis di dalam selector induk, mencerminkan struktur HTML.

## Penjelasan Detail

Nesting adalah fitur SASS yang memungkinkan penulisan selector CSS secara bersarang di dalam selector lainnya, mengikuti hierarki HTML. Ini menghilangkan kebutuhan untuk mengulang nama selector induk dan membuat kode lebih mudah dibaca serta dipelihara. Operator & (ampersand) digunakan untuk merujuk pada selector induk, memungkinkan pembuatan pseudo-class, modifier BEM, dan kombinasi selector lainnya. Nesting juga dapat digunakan untuk properti CSS seperti font, background, dan border yang memiliki sub-properti. Meskipun nesting sangat berguna, terlalu dalam bersarang (lebih dari 3-4 level) justru dapat mengurangi readability dan menghasilkan specificity yang tinggi.

## Contoh Kode Implementasi

```scss
// Struktur HTML:
// <nav class="navbar">
//   <div class="navbar-brand">Logo</div>
//   <ul class="navbar-nav">
//     <li class="nav-item active">
//       <a class="nav-link" href="#">Home</a>
//     </li>
//     <li class="nav-item">
//       <a class="nav-link" href="#">About</a>
//     </li>
//   </ul>
// </nav>

.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  background: #2c3e50;
  padding: 1rem 2rem;

  // Nesting brand
  &-brand {
    font-size: 1.5rem;
    font-weight: bold;
    color: white;
  }

  // Nesting nav
  &-nav {
    display: flex;
    list-style: none;
    margin: 0;
    padding: 0;
    gap: 1rem;
  }

  // Nesting item
  .nav-item {
    position: relative;

    // Pseudo-class dengan &
    &:hover {
      .nav-link {
        color: #3498db;
      }
    }

    // Modifier dengan &
    &.active {
      .nav-link {
        color: #3498db;
        font-weight: bold;
      }
    }
  }

  // Nesting link
  .nav-link {
    color: white;
    text-decoration: none;
    padding: 0.5rem 0;
    transition: color 0.3s ease;
  }
}

// Property nesting
.card {
  font: {
    family: 'Roboto', sans-serif;
    size: 1rem;
    weight: 400;
  }
  border: {
    style: solid;
    width: 1px;
    color: #ddd;
    radius: 8px;
  }
  background: {
    color: white;
    image: url('bg.png');
    repeat: no-repeat;
    position: center;
  }
}

// Nesting dengan @at-root untuk menghindari inheritance
.wrapper {
  color: black;

  @at-root {
    .global-alert {
      color: red;
      border: 1px solid red;
    }
  }
}
```

## Poin Penting
- Nesting memungkinkan penulisan selector bersarang yang mencerminkan struktur HTML
- Operator & (ampersand) merujuk pada selector induk untuk pseudo-class dan modifier
- Hindari nesting lebih dari 3-4 level untuk menjaga readability dan specificity rendah
- @at-root digunakan untuk mengeluarkan selector dari hierarki nesting
