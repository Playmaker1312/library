# Mixin dalam SASS untuk Mendefinisikan Blok Aturan yang Dapat Digunakan Ulang

## Analogi: Perpustakaan Digital

Dalam perpustakaan digital, ada templat cetak standar untuk label buku, kartu anggota, dan formulir peminjaman. Templat ini bisa digunakan berulang kali dengan parameter yang berbeda seperti nama peminjam atau nomor buku. Mixin dalam SASS seperti templat cetak ini — cetak biru aturan CSS yang bisa digunakan ulang dengan nilai yang berbeda.

## Penjelasan Detail

Mixin adalah fitur SASS yang memungkinkan pendefinisian blok aturan CSS yang dapat digunakan kembali di seluruh stylesheet. Mixin dideklarasikan dengan @mixin dan dipanggil dengan @include. Keunggulan utama mixin adalah kemampuannya menerima argumen, memungkinkan fleksibilitas tinggi dengan nilai yang berbeda setiap kali dipanggil. Mixin juga dapat berisi aturan CSS lengkap, selector, properti, atau bahkan direktif kontrol seperti @if dan @for. Berbeda dengan extend yang menggabungkan selector, mixin menduplikasi kode setiap kali dipanggil — ini adalah trade-off yang perlu dipertimbangkan. Mixin sangat ideal untuk vendor prefix, animasi kompleks, pola desain yang sering digunakan, dan grup properti yang saling terkait.

## Contoh Kode Implementasi

```scss
// Mixin dasar tanpa parameter
@mixin clearfix {
  &::after {
    content: '';
    display: table;
    clear: both;
  }
}

// Mixin dengan parameter
@mixin flex-center($direction: row) {
  display: flex;
  align-items: center;
  justify-content: center;
  flex-direction: $direction;
}

// Mixin untuk responsive breakpoints
@mixin respond-to($breakpoint) {
  @if $breakpoint == 'phone' {
    @media (max-width: 600px) { @content; }
  } @else if $breakpoint == 'tablet' {
    @media (max-width: 900px) { @content; }
  } @else if $breakpoint == 'desktop' {
    @media (min-width: 901px) { @content; }
  }
}

// Mixin dengan argumen opsional dan default
@mixin button-variant($bg, $color: white, $border: $bg) {
  background-color: $bg;
  color: $color;
  border: 1px solid $border;
  padding: 10px 20px;
  border-radius: 4px;
  font-size: 1rem;
  cursor: pointer;
  transition: all 0.3s ease;

  &:hover {
    background-color: darken($bg, 10%);
    border-color: darken($border, 10%);
  }
}

// Mixin dengan @content (block content)
@mixin card($shadow: true) {
  background: white;
  border-radius: 8px;
  padding: 20px;

  @if $shadow {
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  }

  @content; // Tempat untuk konten kustom
}

// Penggunaan mixin
.container {
  @include clearfix;
}

.hero {
  @include flex-center(column);
  min-height: 100vh;
}

.sidebar {
  @include respond-to('phone') {
    display: none;
  }
  @include respond-to('tablet') {
    width: 250px;
  }
}

.btn-primary {
  @include button-variant(#3498db);
}

.btn-success {
  @include button-variant(#2ecc71, #333);
}

.featured-card {
  @include card(true) {
    border-left: 4px solid #3498db;
  }
}
```

## Poin Penting
- Mixin memungkinkan penggunaan ulang blok aturan CSS dengan @mixin dan @include
- Mixin dapat menerima argumen dengan nilai default untuk fleksibilitas maksimal
- @content memungkinkan penyisipan konten kustom saat memanggil mixin
- Mixin menduplikasi kode, berbeda dengan extend yang menggabungkan selector
