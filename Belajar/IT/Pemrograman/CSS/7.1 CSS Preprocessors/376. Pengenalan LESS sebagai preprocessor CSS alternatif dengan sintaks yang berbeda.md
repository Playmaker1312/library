# Pengenalan LESS sebagai Preprocessor CSS Alternatif dengan Sintaks yang Berbeda

## Analogi: Perpustakaan Digital

LESS seperti sistem katalog perpustakaan yang berbeda dari SASS. Jika SASS menggunakan dolar ($) untuk variabel, LESS menggunakan at (@). Keduanya bertujuan sama — membuat CSS lebih terstruktur — tetapi dengan aturan sintaks dan filosofi yang sedikit berbeda. Seperti dua merek sistem manajemen perpustakaan yang populer.

## Penjelasan Detail

LESS adalah preprocessor CSS yang dikembangkan oleh Alexis Sellier pada tahun 2009. Sintaks LESS mirip dengan CSS dan menggunakan @ (at sign) untuk variabel, bukan $ seperti SASS. LESS tidak memiliki fitur kontrol direktif (@if, @each) seperti SASS karena LESS mengandalkan JavaScript untuk logika pemrosesan. LESS menyediakan fitur seperti variabel, nesting, mixin (tanpa kata kunci khusus — cukup class biasa), extend, fungsi, dan operasi matematika. Kelebihan LESS adalah sintaksnya yang sederhana dan kemudahan integrasi dengan JavaScript. LESS populer terutama di ekosistem Bootstrap versi 3 dan 4 sebelumnya.

## Contoh Kode Implementasi

```less
// Variabel menggunakan @
@primary: #3498db;
@secondary: #2ecc71;
@danger: #e74c3c;
@font-family: 'Helvetica Neue', sans-serif;
@base-padding: 16px;

// Mixin (cukup class biasa)
.border-radius(@radius: 4px) {
  -webkit-border-radius: @radius;
  -moz-border-radius: @radius;
  border-radius: @radius;
}

.box-shadow(@x: 0, @y: 2px, @blur: 4px, @color: rgba(0,0,0,0.1)) {
  -webkit-box-shadow: @arguments;
  box-shadow: @arguments;
}

// Nesting
.navbar {
  background: @primary;
  padding: @base-padding;
  color: white;

  ul {
    list-style: none;
    margin: 0;
    padding: 0;

    li {
      display: inline-block;
      margin-right: 16px;

      a {
        color: white;
        text-decoration: none;
        .border-radius(4px);

        &:hover {
          text-decoration: underline;
        }
      }
    }
  }
}

// Extend
.message {
  padding: 12px 20px;
  border: 1px solid transparent;
  border-radius: 4px;
  font-size: 0.95rem;
}

.message-success {
  &:extend(.message);
  color: #155724;
  background: #d4edda;
  border-color: #c3e6cb;
}

.message-error {
  &:extend(.message);
  color: #721c24;
  background: #f8d7da;
  border-color: #f5c6cb;
}

// Operasi matematika
@grid-columns: 12;
@grid-gutter: 30px;

.col(@span: 1) {
  width: (@span / @grid-columns) * 100%;
  padding-left: (@grid-gutter / 2);
  padding-right: (@grid-gutter / 2);
}

.col-4 {
  .col(4);
}

.col-6 {
  .col(6);
}

// Fungsi warna
.button {
  background: @primary;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
  cursor: pointer;

  &:hover {
    background: darken(@primary, 10%);
  }

  &:active {
    background: darken(@primary, 20%);
  }
}

// Looping (menggunakan recursive mixin)
.loop(@i) when (@i > 0) {
  .loop(@i - 1);
  .col-@{i} {
    width: (@i / @grid-columns) * 100%;
  }
}

.loop(@grid-columns);
```

## Poin Penting
- LESS menggunakan @ untuk variabel, berbeda dengan SASS yang menggunakan $
- LESS tidak memiliki kontrol direktif seperti @if dan @each; mengandalkan JavaScript
- Mixin dalam LESS didefinisikan seperti class biasa dengan tanda kurung parameter
- LESS populer di ekosistem Bootstrap dan dikenal dengan sintaks yang sederhana
