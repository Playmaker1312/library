# Fungsi dan Operasi Matematika dalam SASS untuk Perhitungan Nilai Dinamis

## Analogi: Perpustakaan Digital

Bayangkan sistem perpustakaan yang dapat secara otomatis menghitung denda keterlambatan berdasarkan jumlah hari, atau menentukan posisi rak buku berdasarkan nomor klasifikasi desimal. SASS menyediakan fungsi dan operasi matematika seperti kalkulator bawaan yang dapat menghitung nilai secara dinamis.

## Penjelasan Detail

SASS menyediakan dukungan operasi matematika lengkap termasuk penjumlahan (+), pengurangan (-), perkalian (*), pembagian (/), dan modulo (%). SASS juga dilengkapi dengan banyak fungsi built-in untuk manipulasi warna, string, angka, dan daftar. Fungsi built-in seperti lighten(), darken(), mix(), rgba(), dan hsl() sangat berguna untuk menghasilkan variasi warna secara dinamis. SASS juga mendukung fungsi kustom dengan @function. Operasi matematika memungkinkan perhitungan nilai secara otomatis seperti lebar kolom berbasis grid, ukuran font responsif, dan spacing yang konsisten.

## Contoh Kode Implementasi

```scss
// Operasi matematika dasar
$base-size: 16px;
$gutter: 30px;

.container {
  width: 100% - $gutter; // 100% - 30px
  padding: $base-size * 1.5; // 24px
  margin-bottom: $gutter / 2; // 15px
}

// Perhitungan grid
$columns: 12;
$column-width: 100% / $columns;

.col-1 { width: $column-width * 1; }
.col-2 { width: $column-width * 2; }
.col-3 { width: $column-width * 3; }
.col-4 { width: $column-width * 4; }
.col-6 { width: $column-width * 6; }
.col-12 { width: $column-width * 12; }

// Fungsi built-in warna
$primary: #3498db;

.element {
  // Lighten dan darken
  background: lighten($primary, 20%); // #7fbff0
  border-color: darken($primary, 10%); // #217dbb

  // Saturate dan desaturate
  color: saturate($primary, 30%); // Lebih jenuh
  outline: desaturate($primary, 20%); // Kurang jenuh

  // Mix dua warna
  box-shadow: mix($primary, #e74c3c, 50%); // Campuran 50%

  // RGBA / opacity
  background: rgba($primary, 0.5);
  border: 1px solid transparentize($primary, 0.3);

  // HSL functions
  $hue: hue($primary); // 204 derajat
  $saturation: saturation($primary); // 62%
  $lightness: lightness($primary); // 53%
  $adjusted: adjust-hue($primary, 180deg); // Rotasi hue 180 derajat
}

// Fungsi untuk typography
@function calculate-rem($size) {
  @return $size / 16px * 1rem;
}

@function fluid-type($min, $max, $min-vw: 320px, $max-vw: 1200px) {
  @return calc(#{$min} + (#{$max} - #{$min}) * ((100vw - #{$min-vw}) / (#{$max-vw} - #{$min-vw})));
}

h1 {
  font-size: calculate-rem(32px); // 2rem
  line-height: fluid-type(1.2, 1.5);
}

p {
  font-size: calculate-rem(16px); // 1rem
}

// Fungsi kustom untuk spacing scale
$base-spacing: 8px;

@function spacing($multiplier) {
  @return $base-spacing * $multiplier;
}

.card {
  padding: spacing(3); // 24px
  margin-bottom: spacing(4); // 32px
  gap: spacing(1); // 8px
}

// Fungsi untuk konversi
@function to-em($px, $base: 16px) {
  @return $px / $base * 1em;
}

.quote {
  font-size: to-em(18px); // 1.125em
  padding: to-em(16px, 18px); // 0.889em dengan base 18px
}

// Map functions
$breakpoints: (
  'sm': 576px,
  'md': 768px,
  'lg': 992px,
  'xl': 1200px
);

@function bp($key) {
  @return map-get($breakpoints, $key);
}

@mixin respond($bp) {
  @media (min-width: bp($bp)) {
    @content;
  }
}

.sidebar {
  @include respond('md') {
    width: 250px;
  }
}
```

## Poin Penting
- SASS mendukung operasi matematika (+, -, *, /, %) untuk perhitungan nilai dinamis
- Fungsi built-in untuk warna seperti lighten(), darken(), mix() sangat berguna
- Fungsi kustom dengan @function memungkinkan logika perhitungan yang dapat digunakan ulang
- SASS functions dan operasi matematika menghasilkan kode yang lebih dinamis dan mudah dipelihara
