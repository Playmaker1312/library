# Variabel dalam SASS dengan Tanda Dolar sebagai Awalan Nama Variabel

## Analogi: Perpustakaan Digital

Dalam perpustakaan digital, ada label dan kategori standar yang digunakan di seluruh sistem. Misalnya label "Fiksi" atau "Non-Fiksi" yang konsisten di setiap rak buku. Variabel dalam SASS seperti label standar ini — Anda tetapkan sekali di satu tempat, lalu gunakan di mana saja tanpa perlu mengulang nilainya.

## Penjelasan Detail

Variabel dalam SASS dideklarasikan menggunakan tanda dolar ($) diikuti dengan nama variabel, lalu nilai yang ditetapkan. Variabel dapat menyimpan nilai seperti warna, font, ukuran, dan nilai CSS lainnya. Keuntungan utama variabel adalah konsistensi dan kemudahan pemeliharaan — cukup ubah nilai di satu tempat untuk memperbarui seluruh stylesheet. Variabel SASS berbeda dengan variabel CSS murni (custom properties) karena SASS variabel bersifat compile-time, artinya nilainya sudah tetap setelah kompilasi. Variabel SASS juga mendukung scoping, di mana variabel yang dideklarasikan di dalam blok selector hanya dapat diakses di dalam blok tersebut. SASS menyediakan fungsi untuk memanipulasi nilai variabel seperti lighten(), darken(), dan mix().

## Contoh Kode Implementasi

```scss
// Deklarasi variabel global
$primary-color: #3498db;
$secondary-color: #2ecc71;
$danger-color: #e74c3c;
$warning-color: #f39c12;
$info-color: #1abc9c;

// Variabel untuk tipografi
$font-family-sans: 'Open Sans', 'Helvetica Neue', Arial, sans-serif;
$font-family-serif: 'Merriweather', Georgia, 'Times New Roman', serif;
$font-family-mono: 'Fira Code', 'Consolas', monospace;
$font-size-base: 16px;
$line-height-base: 1.5;

// Variabel untuk spacing
$spacing-unit: 8px;
$spacing-xs: $spacing-unit * 0.5;
$spacing-sm: $spacing-unit;
$spacing-md: $spacing-unit * 2;
$spacing-lg: $spacing-unit * 4;
$spacing-xl: $spacing-unit * 8;

// Variabel untuk layout
$container-max-width: 1200px;
$grid-columns: 12;
$grid-gutter: 30px;

// Penggunaan variabel
.container {
  max-width: $container-max-width;
  margin: 0 auto;
  padding: 0 $grid-gutter / 2;
}

.button {
  display: inline-block;
  padding: $spacing-sm $spacing-md;
  font-size: $font-size-base;
  font-family: $font-family-sans;
  line-height: $line-height-base;
  border: none;
  border-radius: 4px;
  cursor: pointer;
  transition: background-color 0.3s ease;

  &--primary {
    background-color: $primary-color;
    color: white;

    &:hover {
      background-color: darken($primary-color, 10%);
    }
  }

  &--danger {
    background-color: $danger-color;
    color: white;

    &:hover {
      background-color: darken($danger-color, 10%);
    }
  }
}

// Local scoping
.alert {
  $padding: 15px;
  padding: $padding;
  margin-bottom: $spacing-md;
  border: 1px solid transparent;
  border-radius: 4px;

  &--success {
    color: darken($secondary-color, 30%);
    background-color: lighten($secondary-color, 40%);
    border-color: $secondary-color;
  }
}

// Default flag
$theme-color: $primary-color !default;
```

## Poin Penting
- Variabel SASS menggunakan tanda dolar ($) sebagai awalan dan dapat menyimpan berbagai jenis nilai CSS
- Variabel bersifat compile-time, nilainya tetap setelah kompilasi, berbeda dengan CSS custom properties
- SASS mendukung scoping lokal dan global untuk variabel
- Variabel sangat penting untuk konsistensi dan kemudahan pemeliharaan dalam proyek besar
