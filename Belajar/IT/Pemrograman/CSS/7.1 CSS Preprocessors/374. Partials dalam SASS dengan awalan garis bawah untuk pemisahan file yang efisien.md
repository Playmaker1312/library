# Partials dalam SASS dengan Awalan Garis Bawah untuk Pemisahan File yang Efisien

## Analogi: Perpustakaan Digital

Perpustakaan digital yang baik memisahkan buku-buku ke dalam bagian yang berbeda: fiksi, non-fiksi, referensi, dan majalah. Setiap bagian memiliki raknya sendiri namun tetap merupakan bagian dari perpustakaan yang sama. Partials dalam SASS seperti bagian-bagian perpustakaan ini — file terpisah yang diorganisir berdasarkan fungsinya dan digabungkan menjadi satu stylesheet utuh.

## Penjelasan Detail

Partials adalah file SASS terpisah yang diawali dengan garis bawah (_) pada nama filenya, misalnya _variables.scss atau _mixins.scss. Awalan garis bawah memberi tahu kompiler SASS bahwa file tersebut adalah partial dan tidak perlu dikompilasi menjadi file CSS terpisah. Partials memungkinkan pemisahan kode CSS ke dalam file-file kecil yang terfokus berdasarkan fungsinya: variabel, mixin, komponen, layout, atau halaman. File-file ini kemudian digabungkan menggunakan @use atau @import ke dalam file utama (main.scss). Penggunaan partials sangat penting untuk proyek besar karena memudahkan kolaborasi tim, navigasi kode, dan pemeliharaan.

## Contoh Kode Implementasi

```scss
// _variables.scss
$primary: #3498db;
$secondary: #2ecc71;
$danger: #e74c3c;
$dark: #2c3e50;
$light: #ecf0f1;

$font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
$font-size-base: 16px;

$spacing-unit: 8px;
$container-max: 1200px;

// _reset.scss
*,
*::before,
*::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

html {
  font-size: $font-size-base;
  scroll-behavior: smooth;
}

body {
  font-family: $font-family;
  line-height: 1.6;
  color: $dark;
  background: $light;
}

// _mixins.scss
@mixin flex-center($direction: row) {
  display: flex;
  align-items: center;
  justify-content: center;
  flex-direction: $direction;
}

@mixin respond-to($breakpoint) {
  @if $breakpoint == 'sm' { @media (min-width: 576px) { @content; } }
  @if $breakpoint == 'md' { @media (min-width: 768px) { @content; } }
  @if $breakpoint == 'lg' { @media (min-width: 992px) { @content; } }
  @if $breakpoint == 'xl' { @media (min-width: 1200px) { @content; } }
}

// _buttons.scss
.btn {
  display: inline-block;
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
  cursor: pointer;
  font-size: 1rem;
  transition: all 0.3s ease;

  &--primary {
    background: $primary;
    color: white;
    &:hover { background: darken($primary, 10%); }
  }

  &--secondary {
    background: $secondary;
    color: white;
    &:hover { background: darken($secondary, 10%); }
  }

  &--danger {
    background: $danger;
    color: white;
    &:hover { background: darken($danger, 10%); }
  }
}

// _cards.scss
.card {
  background: white;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  overflow: hidden;

  &__image {
    width: 100%;
    height: 200px;
    object-fit: cover;
  }

  &__body {
    padding: 20px;
  }

  &__title {
    font-size: 1.25rem;
    margin-bottom: 8px;
    color: $dark;
  }

  &__text {
    font-size: 0.95rem;
    color: #666;
    line-height: 1.6;
  }
}

// _layout.scss
.container {
  width: 100%;
  max-width: $container-max;
  margin: 0 auto;
  padding: 0 15px;
}

.grid {
  display: grid;
  gap: 20px;
  grid-template-columns: repeat(12, 1fr);

  &__col {
    &--4 { grid-column: span 4; }
    &--6 { grid-column: span 6; }
    &--8 { grid-column: span 8; }
    &--12 { grid-column: span 12; }
  }
}

// main.scss — file utama yang menggabungkan semua partials
// @use 'variables';
// @use 'reset';
// @use 'mixins';
// @use 'buttons';
// @use 'cards';
// @use 'layout';
```

## Poin Penting
- Partials adalah file SASS dengan awalan garis bawah (_) yang tidak dikompilasi menjadi file CSS terpisah
- Partials memungkinkan pemisahan kode ke dalam file kecil berdasarkan fungsi untuk organisasi yang lebih baik
- Partials digabungkan menggunakan @use atau @import ke dalam file utama
- Penggunaan partials sangat penting untuk proyek besar, kolaborasi tim, dan kemudahan pemeliharaan
