# Perbandingan SASS, LESS, dan Stylus dalam Hal Fitur dan Ekosistem

## Analogi: Perpustakaan Digital

SASS, LESS, dan Stylus seperti tiga sistem manajemen perpustakaan yang berbeda. SASS seperti sistem enterprise yang lengkap dengan semua fitur. LESS seperti sistem yang sederhana dan mudah dipelajari. Stylus seperti sistem yang sangat fleksibel dengan banyak kebebasan. Ketiganya bisa mengelola koleksi buku, tetapi dengan pendekatan dan fitur yang berbeda.

## Penjelasan Detail

SASS, LESS, dan Stylus adalah tiga preprocessor CSS utama dengan pendekatan dan ekosistem yang berbeda. SASS adalah yang paling matang dengan fitur terlengkap termasuk variabel ($), nesting, mixin, extend, fungsi built-in, dan kontrol direktif. SASS memiliki komunitas terbesar, dokumentasi terbanyak, dan didukung oleh framework seperti Bootstrap 5. LESS menggunakan sintaks mirip CSS dengan @ untuk variabel, mixin seperti class biasa, dan populer di era Bootstrap 3/4. Stylus menawarkan fleksibilitas sintaks tertinggi dengan opsi menghilangkan tanda baca. SASS berbasis Dart (sebelumnya Ruby), LESS berbasis JavaScript, dan Stylus berbasis Node.js.

## Contoh Kode Implementasi

```scss
// ====================
// SASS/SCSS
// ====================
// Variabel: $
$primary: #3498db;

// Mixin
@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

// Extend
%btn {
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
}

.btn-primary {
  @extend %btn;
  background: $primary;
}

// Kontrol direktif
@for $i from 1 through 3 {
  .col-#{$i} { width: $i * 33.33%; }
}
```

```less
// ====================
// LESS
// ====================
// Variabel: @
@primary: #3498db;

// Mixin
.flex-center() {
  display: flex;
  align-items: center;
  justify-content: center;
}

.btn-primary {
  .flex-center();
  background: @primary;
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
}

// Looping via recursive mixin
.loop(@i) when (@i > 0) {
  .loop(@i - 1);
  .col-@{i} { width: @i * 33.33%; }
}
.loop(3);
```

```stylus
// ====================
// Stylus
// ====================
// Variabel: tanpa prefix
primary = #3498db

// Mixin
flex-center()
  display flex
  align-items center
  justify-content center

.btn-primary
  flex-center()
  background primary
  padding 10px 20px
  border none
  border-radius 4px

// Looping
for i in (1..3)
  .col-{i}
    width i * 33.33%
```

```scss
// ====================
// Perbandingan Ekosistem
// ====================
// Tools pendukung:

// SASS: Dart SASS, Node SASS, Webpack (sass-loader), Gulp (gulp-sass)
// LESS: Less.js, Webpack (less-loader), Gulp (gulp-less)
// Stylus: Stylus, Webpack (stylus-loader), Gulp (gulp-stylus)

// Adopsi framework:
// SASS: Bootstrap 5, Bulma, Foundation, Materialize
// LESS: Bootstrap 3 & 4 (sebelum migrasi ke SASS)
// Stylus: Digunakan oleh beberapa proyek Node.js

// Pilihan berdasarkan kebutuhan:
// - Butuh fitur lengkap & komunitas besar? → SASS
// - Sintaks sederhana & integrasi JS? → LESS
// - Fleksibilitas sintaks tinggi? → Stylus
```

## Poin Penting
- SASS adalah preprocessor paling populer dengan fitur terlengkap dan ekosistem terbesar
- LESS menawarkan sintaks mirip CSS dengan kurva belajar rendah dan integrasi JavaScript
- Stylus memberikan fleksibilitas sintaks tertinggi dengan opsi menghilangkan tanda baca
- Pilihan preprocessor tergantung kebutuhan proyek, tim, dan ekosistem yang digunakan
