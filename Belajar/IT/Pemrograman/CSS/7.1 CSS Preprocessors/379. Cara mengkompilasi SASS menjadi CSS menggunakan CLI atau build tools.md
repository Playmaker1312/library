# Cara Mengkompilasi SASS Menjadi CSS Menggunakan CLI atau Build Tools

## Analogi: Perpustakaan Digital

Setelah pustakawan menulis katalog dalam format digital mentah, data tersebut perlu dikonversi ke format standar yang bisa dibaca oleh sistem perpustakaan. Kompilasi SASS adalah proses konversi ini — mengubah kode SASS/SCSS menjadi CSS standar yang dapat dipahami browser.

## Penjelasan Detail

Kompilasi SASS dapat dilakukan melalui berbagai metode. SASS CLI (Command Line Interface) adalah cara paling langsung menggunakan perintah sass. Opsi kompilasi meliputi mode watch (pemantauan otomatis), compressed output (produksi), expanded (pengembangan), dan source maps. Build tools modern seperti Webpack dengan sass-loader, Vite dengan dukungan bawaan SASS, dan Gulp dengan gulp-sass menawarkan integrasi otomatis dalam workflow. Pemilihan metode kompilasi tergantung pada skala proyek dan workflow tim.

## Contoh Kode Implementasi

```bash
# ====================
# SASS CLI
# ====================

# Install SASS global
npm install -g sass

# Kompilasi satu file
sass input.scss output.css

# Kompilasi dengan watch (otomatis)
sass --watch input.scss output.css

# Kompilasi seluruh folder
sass --watch scss/:css/

# Mode compressed (produksi)
sass input.scss output.css --style=compressed

# Mode expanded (pengembangan)
sass input.scss output.css --style=expanded

# Dengan source maps
sass input.scss output.css --source-map

# Load path untuk partials
sass --load-path=node_modules input.scss output.css
```

```javascript
// ====================
// Dengan Webpack
// ====================

// webpack.config.js
module.exports = {
  module: {
    rules: [
      {
        test: /\.scss$/,
        use: [
          'style-loader',  // Inject CSS ke DOM
          'css-loader',    // Resolve CSS imports
          'sass-loader'    // Kompilasi SASS ke CSS
        ]
      }
    ]
  }
};
```

```javascript
// ====================
// Dengan Vite
// ====================

// vite.config.js
import { defineConfig } from 'vite';

export default defineConfig({
  css: {
    preprocessorOptions: {
      scss: {
        additionalData: `@use "src/styles/variables" as *;`,
        api: 'modern-compiler' // atau 'modern'
      }
    }
  }
});
```

```javascript
// ====================
// Dengan Gulp
// ====================

// gulpfile.js
const gulp = require('gulp');
const sass = require('gulp-sass')(require('sass'));

function styles() {
  return gulp.src('./src/scss/**/*.scss')
    .pipe(sass({ outputStyle: 'compressed' }).on('error', sass.logError))
    .pipe(gulp.dest('./dist/css'));
}

function watch() {
  gulp.watch('./src/scss/**/*.scss', styles);
}

exports.default = gulp.series(styles, watch);
```

```json
// ====================
// Dengan npm scripts
// ====================

// package.json
{
  "scripts": {
    "sass:dev": "sass --watch src/scss:dist/css --style=expanded",
    "sass:build": "sass src/scss:dist/css --style=compressed --no-source-map",
    "sass:lint": "sass-lint src/scss/**/*.scss"
  },
  "devDependencies": {
    "sass": "^1.70.0"
  }
}
```

## Poin Penting
- SASS CLI adalah cara langsung untuk kompilasi dengan opsi watch, compressed, dan source maps
- Webpack menggunakan sass-loader dalam pipeline build untuk kompilasi otomatis
- Vite memiliki dukungan SASS bawaan dengan konfigurasi preprocessorOptions
- Gulp dan npm scripts adalah alternatif populer untuk otomatisasi kompilasi SASS
