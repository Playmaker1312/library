# Integrasi SASS dalam Workflow Modern Menggunakan Webpack, Vite, atau Gulp

## Analogi: Perpustakaan Digital

Integrasi SASS dalam workflow modern seperti menghubungkan sistem katalog perpustakaan dengan sistem digital lainnya — peminjaman otomatis, pembaruan stok real-time, dan sinkronisasi antar cabang. Setiap alat (Webpack, Vite, Gulp) adalah seperti jembatan yang menghubungkan SASS ke ekosistem yang lebih luas.

## Penjelasan Detail

Integrasi SASS dalam workflow modern memungkinkan kompilasi otomatis, autoprefixing, minifikasi, source maps, dan hot module replacement. Webpack menggunakan sass-loader dalam rule modul dengan css-loader dan style-loader. Vite memiliki dukungan SASS bawaan tanpa plugin terpisah. Gulp adalah task runner yang menggunakan gulp-sass untuk kompilasi SASS. Semua alat ini mendukung autoprefixer, CSS nano, dan post-processing lainnya. Workflow modern juga mengintegrasikan linting SASS dengan stylelint, dan optimasi produksi seperti purging CSS.

## Contoh Kode Implementasi

```javascript
// ====================
// Webpack (Lengkap)
// ====================

// webpack.config.js
const MiniCssExtractPlugin = require('mini-css-extract-plugin');
const CssMinimizerPlugin = require('css-minimizer-webpack-plugin');

module.exports = {
  module: {
    rules: [
      {
        test: /\.scss$/,
        use: [
          process.env.NODE_ENV === 'production'
            ? MiniCssExtractPlugin.loader // Extract ke file CSS
            : 'style-loader',             // Inject ke DOM
          {
            loader: 'css-loader',
            options: {
              modules: false,
              sourceMap: true,
              importLoaders: 2
            }
          },
          {
            loader: 'postcss-loader',
            options: {
              postcssOptions: {
                plugins: [
                  require('autoprefixer')(),
                  require('cssnano')()
                ]
              }
            }
          },
          {
            loader: 'sass-loader',
            options: {
              implementation: require('sass'),
              sassOptions: {
                outputStyle: 'compressed'
              },
              additionalData: '$env: ' + process.env.NODE_ENV + ';'
            }
          }
        ]
      }
    ]
  },
  plugins: [
    new MiniCssExtractPlugin({
      filename: 'css/[name].[contenthash].css'
    })
  ],
  optimization: {
    minimizer: [new CssMinimizerPlugin()]
  }
};
```

```javascript
// ====================
// Vite (Modern & Cepat)
// ====================

// vite.config.js
import { defineConfig } from 'vite';
import autoprefixer from 'autoprefixer';

export default defineConfig({
  css: {
    modules: {
      localsConvention: 'camelCase'
    },
    postcss: {
      plugins: [autoprefixer()]
    },
    preprocessorOptions: {
      scss: {
        additionalData: `
          @use "src/styles/variables" as *;
          @use "src/styles/mixins" as *;
        `,
        api: 'modern-compiler',
        silenceDeprecations: ['mixed-decls']
      }
    }
  },
  build: {
    cssMinify: 'esbuild',
    rollupOptions: {
      output: {
        assetFileNames: 'assets/css/[name].[hash][extname]'
      }
    }
  }
});
```

```javascript
// ====================
// Gulp (Workflow Lengkap)
// ====================

// gulpfile.js
const { src, dest, watch, series, parallel } = require('gulp');
const sass = require('gulp-sass')(require('sass'));
const postcss = require('gulp-postcss');
const autoprefixer = require('autoprefixer');
const cssnano = require('cssnano');
const sourcemaps = require('gulp-sourcemaps');
const browserSync = require('browser-sync').create();

function styles() {
  return src('src/scss/**/*.scss')
    .pipe(sourcemaps.init())
    .pipe(sass({ outputStyle: 'expanded' }).on('error', sass.logError))
    .pipe(postcss([autoprefixer(), cssnano()]))
    .pipe(sourcemaps.write('.'))
    .pipe(dest('dist/css'))
    .pipe(browserSync.stream());
}

function serve() {
  browserSync.init({
    server: { baseDir: './dist' }
  });

  watch('src/scss/**/*.scss', styles);
  watch('dist/*.html').on('change', browserSync.reload);
}

exports.default = series(styles, serve);
exports.build = series(styles);
```

## Poin Penting
- Webpack menawarkan pipeline build lengkap dengan sass-loader, postcss, dan ekstraksi CSS
- Vite memiliki dukungan SASS bawaan dengan konfigurasi minimal dan performa cepat
- Gulp memberikan kontrol granular atas workflow kompilasi SASS
- Workflow modern mengintegrasikan autoprefixer, minifikasi, source maps, dan hot reload
