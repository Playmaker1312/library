# Extend dalam SASS untuk Berbagi Aturan Gaya antara Beberapa Selector

## Analogi: Perpustakaan Digital

Di perpustakaan, semua buku fiksi mendapatkan stiker "Fiksi" yang sama tanpa harus mencetak ulang setiap stiker. Stiker tersebut cukup dibuat sekali dan ditempelkan ke semua buku yang relevan. Extend dalam SASS bekerja seperti ini — aturan CSS didefinisikan sekali, lalu selector lain mewarisi aturan tersebut tanpa duplikasi.

## Penjelasan Detail

@extend adalah direktif SASS yang memungkinkan suatu selector mewarisi aturan dari selector lain. Tidak seperti mixin yang menduplikasi kode, @extend menggabungkan selector dengan aturan yang sama menggunakan koma dalam CSS yang dikompilasi. Ini menghasilkan CSS yang lebih kecil dan lebih efisien. Extend paling berguna ketika ada beberapa selector yang secara logis terkait dan berbagi gaya dasar yang sama. Namun, @extend harus digunakan dengan hati-hati karena dapat menyebabkan selector grouping yang tidak terduga jika digunakan secara berlebihan. Best practice adalah menggunakan @extend untuk hubungan yang benar-benar hierarkis, seperti variant dari komponen yang sama.

## Contoh Kode Implementasi

```scss
// Placeholder selector (tidak muncul di CSS)
%button-base {
  display: inline-block;
  padding: 10px 20px;
  font-size: 1rem;
  font-family: inherit;
  border: 1px solid transparent;
  border-radius: 4px;
  cursor: pointer;
  text-align: center;
  text-decoration: none;
  transition: all 0.3s ease;
}

%message-base {
  padding: 12px 20px;
  margin-bottom: 16px;
  border: 1px solid transparent;
  border-radius: 4px;
  font-size: 0.95rem;
  line-height: 1.5;
}

// Extend placeholder
.btn-primary {
  @extend %button-base;
  background-color: #3498db;
  color: white;

  &:hover {
    background-color: darken(#3498db, 10%);
  }
}

.btn-secondary {
  @extend %button-base;
  background-color: #95a5a6;
  color: white;

  &:hover {
    background-color: darken(#95a5a6, 10%);
  }
}

.btn-danger {
  @extend %button-base;
  background-color: #e74c3c;
  color: white;

  &:hover {
    background-color: darken(#e74c3c, 10%);
  }
}

// Extend regular class
.alert-success {
  @extend %message-base;
  color: #155724;
  background-color: #d4edda;
  border-color: #c3e6cb;
}

.alert-error {
  @extend %message-base;
  color: #721c24;
  background-color: #f8d7da;
  border-color: #f5c6cb;
}

.alert-warning {
  @extend %message-base;
  color: #856404;
  background-color: #fff3cd;
  border-color: #ffeeba;
}

// Chaining extend
%badge {
  display: inline-block;
  padding: 4px 8px;
  font-size: 0.75rem;
  font-weight: 600;
  border-radius: 10px;
  text-transform: uppercase;
}

.badge-primary {
  @extend %badge;
  background-color: #3498db;
  color: white;
}

.badge-success {
  @extend %badge;
  background-color: #2ecc71;
  color: white;
}

// Multiple extend
%font-smooth {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

%text-truncate {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

.card-title {
  @extend %font-smooth;
  @extend %text-truncate;
  font-size: 1.25rem;
  font-weight: 600;
  color: #333;
}
```

## Poin Penting
- @extend menghindari duplikasi kode dengan menggabungkan selector menggunakan koma
- Placeholder selector (%) tidak muncul di CSS output, ideal untuk pola extend saja
- Extend paling cocok untuk variant komponen yang berbagi gaya dasar yang sama
- Gunakan @extend dengan hati-hati karena dapat menyebabkan selector grouping yang tidak terduga
