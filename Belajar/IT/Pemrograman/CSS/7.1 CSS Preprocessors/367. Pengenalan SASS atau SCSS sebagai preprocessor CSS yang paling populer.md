# Pengenalan SASS atau SCSS sebagai Preprocessor CSS yang Paling Populer

## Analogi: Perpustakaan Digital

SASS adalah seperti sistem katalog perpustakaan digital yang canggih, di mana setiap buku tidak hanya memiliki lokasi tetap tetapi juga dapat dikelompokkan, diberi label, dan dihubungkan satu sama lain. SCSS adalah dialek SASS yang menggunakan kurung kurawal dan titik koma seperti CSS biasa, membuatnya lebih mudah dipelajari oleh pengembang yang sudah terbiasa dengan CSS.

## Penjelasan Detail

SASS (Syntactically Awesome Style Sheets) adalah preprocessor CSS yang paling matang dan banyak digunakan di industri. SASS memiliki dua sintaks: SCSS (.scss) yang menggunakan kurung kurawal dan titik koma mirip CSS standar, dan SASS (.sass) yang menggunakan indentasi tanpa kurung kurawal. SCSS adalah superset dari CSS, artinya semua kode CSS yang valid juga merupakan kode SCSS yang valid. SASS diperkenalkan pada tahun 2006 oleh Hampton Catlin dan dikembangkan oleh Natalie Weizenbaum. SASS menawarkan fitur-fitur canggih seperti variabel, nesting, mixin, extend, fungsi, dan kontrol direktif seperti @if, @each, dan @while. Ekosistem SASS sangat luas dengan dukungan dari berbagai build tools, framework, dan editor kode.

## Contoh Kode Implementasi

```scss
// SCSS syntax (dengan kurung kurawal)
$primary: #3498db;
$danger: #e74c3c;
$font-size-base: 16px;

.card {
  background: white;
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 20px;
  font-size: $font-size-base;

  &__title {
    font-size: 1.5em;
    color: $primary;
    margin-bottom: 10px;
  }

  &__body {
    line-height: 1.6;
    color: #333;
  }

  &--danger {
    border-color: $danger;

    .card__title {
      color: $danger;
    }
  }
}

// BEM naming dengan nesting
.block {
  &__element {
    &--modifier {
      background: lighten($primary, 30%);
    }
  }
}

// @each directive
$sizes: 40px, 50px, 80px;

@each $size in $sizes {
  .icon-#{$size} {
    width: $size;
    height: $size;
  }
}
```

## Poin Penting
- SASS adalah preprocessor CSS paling populer yang tersedia dalam dua sintaks: SCSS dan SASS
- SCSS menggunakan kurung kurawal dan titik koma, menjadikannya superset dari CSS
- SASS mendukung fitur canggih seperti variabel, nesting, mixin, extend, dan kontrol direktif
- SCSS lebih direkomendasikan untuk pemula karena sintaksnya mirip dengan CSS biasa
