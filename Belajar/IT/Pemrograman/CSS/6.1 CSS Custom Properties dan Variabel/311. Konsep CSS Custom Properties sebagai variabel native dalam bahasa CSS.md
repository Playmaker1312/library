# CSS Custom Properties

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang memiliki papan pengumuman pusat. Setiap kali pustakawan ingin mengubah informasi jam buka, cukup mengubah papan pusat tersebut, dan semua pengunjung akan melihat informasi terbaru. Tanpa papan pusat, pustakawan harus memberi tahu setiap pengunjung satu per satu. CSS Custom Properties berfungsi seperti papan pengumuman pusat ini—sebuah tempat penyimpanan nilai yang bisa diakses dan diubah dari satu lokasi, mempengaruhi seluruh elemen yang merujuk padanya.

## Penjelasan Detail

CSS Custom Properties, juga dikenal sebagai CSS Variables, adalah entitas yang didefinisikan oleh pengembang untuk menyimpan nilai tertentu yang dapat digunakan kembali di seluruh dokumen. Berbeda dengan variabel dalam preprocessor seperti SASS yang diproses saat kompilasi, CSS Custom Properties bersifat live dan dapat dimanipulasi saat runtime oleh browser. Mereka didefinisikan dengan awalan dua tanda hubung (`--`) dan diakses menggunakan fungsi `var()`. Keunggulan utama mereka adalah kemampuan untuk diwariskan melalui pohon DOM, diubah melalui media queries, dan dimodifikasi menggunakan JavaScript. CSS Custom Properties mengikuti aturan cascade yang sama seperti properti CSS lainnya, sehingga nilai dapat ditimpa berdasarkan spesifisitas selector. Ini membuka pintu untuk berbagai teknik seperti theming dinamis, desain responsif yang lebih bersih, dan pengelolaan kode yang lebih terpusat.

## Contoh Kode Implementasi

```css
:root {
  --warna-utama: #3498db;
  --warna-teks: #2c3e50;
  --padding-default: 1rem;
}

.card {
  color: var(--warna-teks);
  padding: var(--padding-default);
  border: 2px solid var(--warna-utama);
}

.card-title {
  color: var(--warna-utama);
  font-size: 1.25rem;
}
```

## Poin Penting
- CSS Custom Properties bersifat live dan dapat diubah saat runtime, tidak seperti variabel preprocessor yang statis.
- Mereka mengikuti aturan cascade dan dapat ditimpa berdasarkan spesifisitas selector.
- Nilai variabel diwariskan dari elemen induk ke elemen anak dalam pohon DOM.
- CSS Custom Properties dapat dimanipulasi menggunakan JavaScript melalui `getPropertyValue` dan `setProperty`.
- Berbeda dengan properti CSS biasa, custom properties tidak memiliki makna semantik bawaan.
