# Manipulasi Variabel CSS dengan JavaScript

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang memiliki panel kontrol pusat. Pustakawan dapat mengubah pengaturan seperti warna tema, ukuran font, atau mode tampilan melalui panel ini, dan perubahan langsung terlihat di seluruh sistem. Panel kontrol ini adalah JavaScript, yang dapat membaca dan mengubah nilai variabel CSS secara dinamis, memberikan kemampuan untuk memanipulasi gaya secara real-time tanpa memuat ulang halaman.

## Penjelasan Detail

JavaScript dapat berinteraksi dengan CSS Custom Properties melalui CSS Object Model (CSSOM). Metode utama yang digunakan adalah `getPropertyValue()` untuk membaca nilai variabel dan `setProperty()` untuk mengubahnya, keduanya dipanggil pada properti `style` dari suatu elemen. Sintaksnya adalah `element.style.getPropertyValue('--nama-variabel')` dan `element.style.setProperty('--nama-variabel', 'nilai-baru')`. Karena CSS Custom Properties mengikuti aturan cascade, nilai yang dibaca dengan `getPropertyValue` hanya mengembalikan nilai dari inline style. Untuk mendapatkan nilai yang dihitung (computed value), gunakan `getComputedStyle(element).getPropertyValue('--nama-variabel')`. Kemampuan ini membuka pintu untuk berbagai aplikasi seperti theme switcher, pengaturan preferensi pengguna, animasi berbasis data, dan dashboard interaktif yang merespons input secara real-time.

## Contoh Kode Implementasi

```css
:root {
  --warna-primer: #3498db;
  --warna-sekunder: #2ecc71;
  --ukuran-font: 16px;
  --spasi: 1rem;
}

body {
  background-color: var(--warna-primer);
  font-size: var(--ukuran-font);
  padding: var(--spasi);
}
```

```javascript
// Membaca nilai variabel computed
const root = document.documentElement;
const warnaPrimer = getComputedStyle(root).getPropertyValue('--warna-primer').trim();
console.log(warnaPrimer); // #3498db

// Mengubah nilai variabel
root.style.setProperty('--warna-primer', '#e74c3c');

// Mengubah beberapa variabel sekaligus
function ubahTema(warnaBaru) {
  root.style.setProperty('--warna-primer', warnaBaru.primer);
  root.style.setProperty('--warna-sekunder', warnaBaru.sekunder);
  root.style.setProperty('--ukuran-font', warnaBaru.ukuranFont);
}

// Reset ke nilai default
root.style.removeProperty('--warna-primer');
```

## Poin Penting
- Gunakan `element.style.setProperty('--nama', 'nilai')` untuk mengubah variabel CSS dari JavaScript.
- Gunakan `getComputedStyle(element).getPropertyValue('--nama')` untuk membaca nilai variabel yang sedang aktif.
- `element.style.getPropertyValue('--nama')` hanya membaca inline style, bukan nilai dari stylesheet.
- Perubahan variabel melalui JavaScript langsung mempengaruhi rendering tanpa perlu reflow penuh.
- `removeProperty()` dapat digunakan untuk menghapus variabel inline, mengembalikan ke nilai cascade semula.
