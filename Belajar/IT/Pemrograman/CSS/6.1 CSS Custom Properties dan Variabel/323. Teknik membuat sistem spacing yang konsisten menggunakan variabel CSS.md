# Sistem Spacing Konsisten dengan Variabel CSS

## Analogi: Perpustakaan Digital

Perpustakaan digital menggunakan sistem grid untuk menata buku di rak. Setiap buku memiliki jarak yang sama dengan buku di sebelahnya—tidak ada yang terlalu rapat atau terlalu renggang. Petugas perpustakaan menggunakan pengukur standar untuk menentukan jarak ini. Jika suatu saat perpustakaan memutuskan untuk memperlebar jarak antar buku, cukup ubah ukuran pengukur standar dan semua rak akan menyesuaikan. Inilah prinsip sistem spacing dalam CSS.

## Penjelasan Detail

Sistem spacing yang konsisten menciptakan ritme visual dan hierarki yang jelas dalam desain. CSS Custom Properties memungkinkan pembuatan skala spacing yang terstandarisasi, biasanya berdasarkan satuan `rem` atau `px`. Skala spacing umumnya mengikuti urutan geometris atau linear, misalnya: 0.25rem, 0.5rem, 0.75rem, 1rem, 1.5rem, 2rem, 3rem, 4rem. Setiap tingkat dalam skala diberi nama berdasarkan fungsinya (seperti `--sp-xs`, `--sp-sm`, `--sp-md`, `--sp-lg`) atau berdasarkan angka (`--sp-1`, `--sp-2`, `--sp-3`). Dengan menggunakan variabel spacing di seluruh proyek, kita memastikan bahwa padding, margin, gap, dan ukuran elemen mengikuti pola yang konsisten. Ini juga memudahkan penyesuaian skalabilitas—misalnya, memperbesar semua spacing untuk tampilan mobile yang lebih ramah jari.

## Contoh Kode Implementasi

```css
:root {
  --sp-1: 0.25rem;
  --sp-2: 0.5rem;
  --sp-3: 0.75rem;
  --sp-4: 1rem;
  --sp-5: 1.5rem;
  --sp-6: 2rem;
  --sp-7: 2.5rem;
  --sp-8: 3rem;
  --sp-9: 4rem;
  --sp-10: 5rem;
}

.card {
  padding: var(--sp-5);
  margin-bottom: var(--sp-6);
  border-radius: var(--sp-2);
}

.card-header {
  padding-bottom: var(--sp-4);
  margin-bottom: var(--sp-4);
  border-bottom: 1px solid #eee;
}

.card-footer {
  padding-top: var(--sp-4);
  margin-top: var(--sp-4);
  border-top: 1px solid #eee;
}

.layout-grid {
  display: grid;
  gap: var(--sp-5);
  grid-template-columns: repeat(3, 1fr);
}

.section {
  padding: var(--sp-8) var(--sp-6);
  margin-bottom: var(--sp-8);
}

@media (max-width: 640px) {
  :root {
    --sp-5: 1rem;
    --sp-6: 1.25rem;
    --sp-8: 2rem;
  }
}
```

## Poin Penting
- Gunakan skala spacing yang terstandarisasi untuk menciptakan ritme visual yang konsisten.
- Beri nama variabel spacing berdasarkan ukuran relatif (sp-1 hingga sp-10) atau fungsi (xs, sm, md, lg).
- Konsistensi spacing meningkatkan hierarki visual dan pengalaman pengguna.
- Ubah skala spacing di media queries untuk adaptasi responsif yang cepat.
- Terapkan variabel spacing pada margin, padding, gap, dan properti dimensi lainnya.
