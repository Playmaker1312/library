# Perbandingan Variabel CSS dengan SASS dan LESS

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki dua jenis catatan: catatan tempel yang bisa diubah kapan saja dan buku cetak yang isinya tetap setelah dicetak. Catatan tempel bisa diganti, ditulis ulang, dan dihapus kapan saja oleh siapa pun—ini seperti CSS Custom Properties yang dinamis. Buku cetak, setelah dicetak, isinya tidak bisa berubah kecuali dicetak ulang—ini seperti variabel SASS/LESS yang statis setelah kompilasi.

## Penjelasan Detail

Perbedaan mendasar antara CSS Custom Properties dan variabel preprocessor (SASS, LESS) terletak pada waktu eksekusi. Variabel preprocessor diproses saat kompilasi dan menghasilkan output CSS statis—nilai variabel sudah tetap setelah stylesheet dihasilkan. CSS Custom Properties dievaluasi oleh browser saat runtime, sehingga nilainya bisa berubah berdasarkan interaksi pengguna, JavaScript, media queries, atau pseudo-class. Variabel preprocessor memiliki keunggulan: bisa digunakan dalam selector, media queries, operasi matematika langsung, dan looping. CSS Custom Properties unggul dalam dinamisme dan integrasi dengan DOM. SASS memiliki fitur seperti `lighten()`, `darken()`, dan struktur data seperti map dan list yang tidak dimiliki CSS murni. CSS Custom Properties dapat dikombinasikan dengan preprocessor untuk mendapatkan yang terbaik dari kedua dunia—menggunakan preprocessor untuk logika kompilasi dan variabel CSS untuk dinamisme runtime.

## Contoh Kode Implementasi

```scss
// SASS: variabel statis
$warna-primer: #3498db;
$spasi-base: 16px;
$breakpoint-md: 768px;

.container {
  color: $warna-primer;
  padding: $spasi-base * 2;
}

@media (min-width: $breakpoint-md) {
  .container { width: 80%; }
}
```

```css
/* CSS Custom Properties: variabel dinamis */
:root {
  --warna-primer: #3498db;
  --spasi-base: 16px;
}

.container {
  color: var(--warna-primer);
  padding: calc(var(--spasi-base) * 2);
}

/* CSS: variabel dinamis, media query manual */
@media (min-width: 768px) {
  :root {
    --lebar-container: 80%;
  }
  .container { width: var(--lebar-container); }
}
```

## Poin Penting
- Variabel preprocessor bersifat statis (dikompilasi sebelum runtime), CSS Custom Properties bersifat dinamis (dievaluasi saat runtime).
- Preprocessor mendukung operasi matematika langsung, looping, dan fungsi manipulasi warna.
- CSS Custom Properties dapat diubah dengan JavaScript, media queries, dan pseudo-class.
- Kombinasi keduanya memberikan fleksibilitas maksimal: preprocessor untuk tooling, variabel CSS untuk dinamisme.
- Preprocessor dapat digunakan di mana saja dalam syntax (selector, media query), sedangkan CSS Custom Properties hanya dalam nilai properti.
