# Variabel Lokal dalam Selector Tertentu

## Analogi: Perpustakaan Digital

Setiap ruang baca di perpustakaan digital memiliki papan pengumuman kecilnya sendiri yang hanya relevan untuk ruangan tersebut. Di ruang baca anak-anak, papan mungkin berisi peraturan tentang volume suara dan denda buku bergambar. Informasi ini tidak perlu diketahui pengunjung ruang lainnya. Variabel CSS lokal bekerja dengan cara yang sama—didefinisikan dalam selector tertentu dan hanya mempengaruhi elemen dalam cakupan tersebut.

## Penjelasan Detail

CSS Custom Properties dapat didefinisikan dalam selector apa pun, tidak hanya `:root`. Ketika didefinisikan dalam selector tertentu, variabel hanya tersedia untuk elemen yang sesuai dengan selector tersebut beserta elemen turunannya. Ini menciptakan cakupan (scope) lokal yang berguna untuk mengisolasi nilai dalam komponen atau bagian tertentu dari halaman. Variabel lokal dapat menimpa variabel global dengan nama yang sama karena aturan cascade—selector yang lebih spesifik akan menang. Teknik ini sangat berguna dalam pengembangan berbasis komponen, di mana setiap komponen memiliki variabel internal yang tidak bocor ke komponen lain. Variabel lokal juga memungkinkan penggunaan nama variabel yang sama dengan nilai berbeda di berbagai konteks.

## Contoh Kode Implementasi

```css
.card {
  --warna-latar: #ffffff;
  --warna-border: #ddd;
  --padding-card: 20px;
  --radius-card: 8px;
  
  background-color: var(--warna-latar);
  border: 1px solid var(--warna-border);
  padding: var(--padding-card);
  border-radius: var(--radius-card);
}

.card-featured {
  --warna-latar: #fff3cd;
  --warna-border: #ffc107;
  --radius-card: 12px;
}

.card-featured .card-title {
  color: #856404;
  font-weight: bold;
}

.card-title {
  font-size: 1.25rem;
  margin-bottom: 10px;
}
```

## Poin Penting
- Variabel lokal memiliki cakupan terbatas pada elemen selector dan turunannya.
- Variabel lokal dapat menimpa variabel global dengan nama yang sama.
- Berguna untuk mengisolasi nilai dalam komponen dan mencegah kebocoran gaya.
- Setiap komponen dapat memiliki variabel internal tanpa risiko konflik nama.
- Variabel lokal mendukung pembuatan variasi komponen dengan mengubah nilai variabel yang sama.
