# Sistem Warna Konsisten dengan Variabel CSS

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki pedoman merek yang ketat: warna biru tertentu untuk judul, hijau untuk tombol sukses, merah untuk peringatan, dan abu-abu untuk teks biasa. Alih-alih mengingat kode heksadesimal setiap kali menulis halaman baru, pustakawan menyimpan semua warna ini dalam satu palet referensi. Setiap kali ingin menggunakan warna, mereka cukup merujuk ke nama paletnya. Ini memastikan konsistensi warna di seluruh halaman perpustakaan.

## Penjelasan Detail

Sistem warna yang konsisten adalah fondasi desain yang profesional. CSS Custom Properties memungkinkan pembuatan palet warna terpusat yang dapat digunakan di seluruh proyek. Dengan menamai warna berdasarkan fungsi (misalnya `--warna-primer`, `--warna-danger`) bukan berdasarkan nilai fisik (`--biru`, `--merah`), kita dapat mengubah seluruh tema tanpa mengubah kode CSS. Sistem warna biasanya terdiri dari warna primer, sekunder, aksen, netral (abu-abu), dan warna semantik (sukses, peringatan, error, info). Setiap kategori bisa memiliki variasi shade (gelap, terang) untuk memberikan fleksibilitas desain. Dengan pendekatan ini, perubahan branding atau tema cukup dilakukan di satu tempat dan seluruh aplikasi akan menyesuaikan. Sistem ini juga memudahkan kolaborasi tim karena semua orang menggunakan referensi warna yang sama.

## Contoh Kode Implementasi

```css
:root {
  --primer: #3498db;
  --primer-gelap: #2980b9;
  --primer-terang: #ebf5fb;
  --sekunder: #2ecc71;
  --sekunder-gelap: #27ae60;
  --sekunder-terang: #eafaf1;
  --danger: #e74c3c;
  --danger-gelap: #c0392b;
  --danger-terang: #fdedec;
  --warning: #f39c12;
  --warning-gelap: #d68910;
  --warning-terang: #fef9e7;
  --info: #3498db;
  --info-gelap: #2980b9;
  --info-terang: #d6eaf8;
  --netral-100: #f8f9fa;
  --netral-200: #e9ecef;
  --netral-300: #dee2e6;
  --netral-400: #ced4da;
  --netral-500: #adb5bd;
  --netral-600: #6c757d;
  --netral-700: #495057;
  --netral-800: #343a40;
  --netral-900: #212529;
}

.btn-success {
  background-color: var(--sekunder);
  color: white;
}
.btn-success:hover {
  background-color: var(--sekunder-gelap);
}

.alert-error {
  background-color: var(--danger-terang);
  border: 1px solid var(--danger);
  color: var(--danger-gelap);
}
```

## Poin Penting
- Beri nama variabel berdasarkan fungsi warna, bukan nama fisik warna itu sendiri.
- Sediakan variasi shade (gelap, terang) untuk setiap warna kunci.
- Satu perubahan pada definisi variabel akan memperbarui seluruh aplikasi.
- Sistem warna terpusat memastikan konsistensi visual di seluruh proyek.
- Pisahkan warna semantik (sukses, error) dari warna dekoratif untuk kejelasan penggunaan.
