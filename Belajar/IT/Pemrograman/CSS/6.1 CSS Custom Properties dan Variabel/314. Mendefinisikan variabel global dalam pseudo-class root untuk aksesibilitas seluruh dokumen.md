# Variabel Global dalam Pseudo-class :root

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki papan informasi utama di lobi yang bisa dilihat semua pengunjung dari mana pun mereka berada. Informasi di papan ini—seperti jam operasional, peraturan, dan pengumuman—bersifat global dan dapat diakses oleh semua orang. Pseudo-class `:root` dalam CSS berfungsi seperti papan informasi utama ini, menjadi tempat mendefinisikan variabel yang tersedia untuk seluruh elemen dalam dokumen.

## Penjelasan Detail

Pseudo-class `:root` merepresentasikan elemen akar dari dokumen, yaitu elemen `<html>` dalam dokumen HTML, tetapi dengan spesifisitas yang lebih tinggi. Mendefinisikan CSS Custom Properties di dalam `:root` membuat variabel tersebut bersifat global dan dapat diakses oleh semua elemen di halaman. Karena CSS Properties mengikuti aturan pewarisan, variabel yang didefinisikan di `:root` akan diwarisi ke seluruh elemen turunannya. Ini adalah pendekatan yang paling umum dan direkomendasikan untuk variabel yang digunakan secara luas di seluruh proyek. Variabel global biasanya mencakup warna tema, ukuran font dasar, spacing, dan nilai-nilai desain sistem lainnya yang konsisten di seluruh komponen.

## Contoh Kode Implementasi

```css
:root {
  --biru-utama: #3498db;
  --biru-gelap: #2980b9;
  --hijau: #2ecc71;
  --merah: #e74c3c;
  --kuning: #f1c40f;
  --abu-terang: #ecf0f1;
  --abu-gelap: #34495e;
  --font-sans: 'Open Sans', sans-serif;
  --font-mono: 'Fira Code', monospace;
  --ukuran-h1: 2.5rem;
  --ukuran-h2: 2rem;
  --ukuran-body: 1rem;
  --lebar-konten: 1200px;
  --radius-button: 6px;
}

body {
  font-family: var(--font-sans);
  font-size: var(--ukuran-body);
  color: var(--abu-gelap);
  background-color: var(--abu-terang);
}
```

## Poin Penting
- `:root` memiliki spesifisitas lebih tinggi daripada elemen `<html>` biasa.
- Variabel di `:root` diwarisi ke seluruh elemen turunan melalui mekanisme cascade.
- Praktik terbaik untuk menyimpan token desain sistem yang digunakan secara global.
- Variabel global memudahkan rebranding dan perubahan tema secara menyeluruh.
- Hindari menempatkan terlalu banyak variabel di `:root` agar tidak mencemari namespace global.
