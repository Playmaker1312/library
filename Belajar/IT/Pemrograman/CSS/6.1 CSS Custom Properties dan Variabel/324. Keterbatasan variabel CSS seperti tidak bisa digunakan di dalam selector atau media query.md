# Keterbatasan CSS Custom Properties

## Analogi: Perpustakaan Digital

Di perpustakaan digital, papan pengumuman pusat sangat berguna untuk menyimpan informasi yang bisa ditampilkan di halaman. Namun, papan ini tidak bisa digunakan untuk mengubah struktur rak buku itu sendiri atau menentukan aturan tentang siapa yang boleh meminjam buku. Papan hanya menyimpan nilai untuk ditampilkan—bukan untuk mengubah kebijakan atau infrastruktur perpustakaan. CSS Custom Properties memiliki batasan yang serupa.

## Penjelasan Detail

CSS Custom Properties memiliki beberapa keterbatasan penting yang perlu dipahami. Pertama, variabel CSS tidak bisa digunakan di luar nilai properti—misalnya, tidak bisa digunakan dalam nama selector, nama properti, atau aturan `@media`. Kedua, nilai fallback dalam `var()` tidak berfungsi jika variabel terdefinisi tetapi nilainya tidak valid untuk properti tersebut; dalam kasus ini, browser menggunakan nilai inherited atau initial. Ketiga, variabel CSS tidak bisa digunakan dalam `@keyframes` untuk nama animasi atau sebagai nama property yang dianimasikan. Keempat, variabel CSS tidak bisa digunakan dalam `@import` untuk URL stylesheet. Kelima, meskipun dapat diubah dalam media queries, mereka sendiri tidak bisa menjadi kondisi dalam media queries. Keenam, tidak seperti variabel preprocessor, CSS Custom Properties tidak bisa digunakan dalam operasi matematika langsung tanpa fungsi `calc()`. Memahami batasan ini penting untuk menghindari frustrasi dan memilih alat yang tepat untuk setiap kebutuhan.

## Contoh Kode Implementasi

```css
:root {
  --lebar: 800px;
  --warna: #3498db;
  --nama-animasi: fadeIn;
  --ukuran: 16px;
}

/* TIDAK BISA: variabel dalam media query */
/* @media (min-width: var(--lebar)) { } */

/* TIDAK BISA: variabel sebagai nama properti */
/* .element { var(--properti): nilai; } */

/* TIDAK BISA: variabel dalam @keyframes untuk nama animasi */
/* @keyframes var(--nama-animasi) { } */

/* TIDAK BISA: variabel dalam @import */
/* @import url(var(--stylesheet)); */

/* BISA: variabel dalam nilai properti */
.container {
  max-width: var(--lebar);
  color: var(--warna);
}

/* BISA: variabel dalam calc untuk operasi matematika */
.element {
  font-size: calc(var(--ukuran) * 1.5);
  width: calc(var(--lebar) - 40px);
}
```

## Poin Penting
- Variabel CSS tidak bisa digunakan dalam nama selector, nama properti, atau aturan @media.
- Nilai fallback tidak aktif jika variabel terdefinisi tapi nilainya tidak valid untuk properti.
- Variabel CSS tidak bisa digunakan dalam @keyframes untuk nama animasi atau nama properti.
- Operasi matematika langsung tidak didukung—harus menggunakan fungsi `calc()`.
- Variabel CSS tidak bisa menjadi parameter dalam aturan @import atau @supports.
