# Fungsi var() untuk Mengakses Variabel CSS

## Analogi: Perpustakaan Digital

Di perpustakaan, ketika seorang pengunjung ingin mengambil buku tertentu, mereka menggunakan nomor panggil yang merujuk ke lokasi buku di rak. Nomor panggil ini seperti fungsi `var()` dalam CSS—cara untuk merujuk dan mengambil nilai yang sudah disimpan sebelumnya. Tanpa nomor panggil, pengunjung tidak akan tahu harus mencari di mana. Begitu pula tanpa `var()`, browser tidak akan tahu nilai mana yang harus digunakan dari custom property yang telah didefinisikan.

## Penjelasan Detail

Fungsi `var()` adalah mekanisme utama untuk mengakses nilai dari CSS Custom Properties. Sintaks dasarnya adalah `var(--nama-variabel)`, yang akan mengambil nilai dari variabel yang paling relevan berdasarkan aturan cascade. Fungsi `var()` juga menerima parameter kedua sebagai nilai fallback: `var(--nama-variabel, nilai-fallback)`. Nilai fallback ini akan digunakan jika variabel yang dirujuk tidak terdefinisi atau tidak valid untuk properti tersebut. Fungsi `var()` dapat digunakan di mana pun nilai properti CSS diterima—baik sebagai nilai tunggal maupun sebagai bagian dari nilai yang lebih kompleks seperti dalam fungsi `calc()`, `rgb()`, atau nilai shorthand. Penggunaan `var()` di luar nilai properti (misalnya dalam nama selector atau media query) tidak diperbolehkan.

## Contoh Kode Implementasi

```css
:root {
  --warna-primer: #2ecc71;
  --warna-teks: #333;
  --ukuran-font: 1rem;
}

.button {
  background-color: var(--warna-primer, #27ae60);
  color: var(--warna-teks, #000);
  font-size: var(--ukuran-font, 16px);
  padding: calc(var(--spasi, 1rem) * 1.5);
  border: 2px solid var(--warna-primer);
}

.button-secondary {
  background-color: transparent;
  color: var(--warna-primer);
  border-color: var(--warna-primer);
}
```

## Poin Penting
- Fungsi `var()` mengambil nilai custom property berdasarkan aturan cascade.
- Parameter kedua opsional berfungsi sebagai fallback jika variabel tidak terdefinisi.
- `var()` bisa digunakan dalam fungsi CSS lain seperti `calc()`, `rgb()`, dan `hsl()`.
- Nilai fallback hanya digunakan saat variabel tidak terdefinisi, bukan saat nilainya tidak valid untuk properti.
- `var()` tidak bisa digunakan di luar nilai properti, misalnya dalam nama selector.
