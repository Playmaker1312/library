# Nilai Fallback dalam Fungsi var()

## Analogi: Perpustakaan Digital

Di perpustakaan, jika seorang pengunjung meminta buku yang sudah dipinjam orang lain, pustakawan biasanya menawarkan buku alternatif yang serupa. Buku alternatif ini adalah rencana cadangan jika buku utama tidak tersedia. Dalam CSS, nilai fallback pada fungsi `var()` berfungsi persis seperti ini—menyediakan nilai alternatif jika variabel yang dirujuk tidak terdefinisi atau tidak dapat digunakan.

## Penjelasan Detail

Fungsi `var()` menerima dua parameter: nama variabel dan nilai fallback opsional. Sintaksnya adalah `var(--nama-variabel, nilai-fallback)`. Nilai fallback akan digunakan ketika variabel belum didefinisikan di mana pun dalam cascade. Penting untuk dipahami bahwa fallback hanya aktif jika variabel tidak terdefinisi sama sekali—bukan ketika nilai variabel tidak valid untuk properti yang digunakan. Jika variabel terdefinisi dengan nilai yang tidak valid, browser justru menggunakan nilai inherited atau initial, bukan fallback. Fallback bisa berupa nilai CSS apa pun, termasuk nilai yang mengandung spasi atau koma. Untuk fallback kompleks yang mengandung koma, fallback harus dibungkus dalam fungsi CSS lain atau tidak memiliki koma di level atas.

## Contoh Kode Implementasi

```css
.button {
  background-color: var(--warna-utama, #3498db);
  color: var(--warna-teks, white);
  padding: var(--padding-button, 10px 20px);
  border: var(--border-button, 2px solid currentColor);
  font-family: var(--font-button, 'Segoe UI', sans-serif);
}

.button-danger {
  background-color: var(--warna-danger, #e74c3c);
}

.card {
  background: var(
    --latar-card,
    linear-gradient(135deg, #667eea 0%, #764ba2 100%)
  );
  gap: var(--gap-card, 1rem);
}
```

## Poin Penting
- Nilai fallback digunakan hanya jika variabel tidak terdefinisi dalam cascade.
- Fallback tidak aktif jika variabel terdefinisi tapi nilainya tidak valid—browser akan menggunakan nilai inherited/initial.
- Fallback bisa berupa nilai kompleks seperti gradient, shadow, atau font stack.
- Gunakan fallback untuk memastikan komponen tetap berfungsi meskipun variabel belum didefinisikan.
- Untuk fallback dengan koma, pastikan parser CSS tidak salah mengartikan koma sebagai pemisah fungsi `var()`.
