# Pewarisan Variabel CSS dari Induk ke Anak

## Analogi: Perpustakaan Digital

Dalam perpustakaan digital, jika seorang pustakawan kepala menetapkan aturan bahwa semua buku harus dikembalikan dalam 14 hari, aturan ini otomatis berlaku untuk semua anggota staf di bawahnya tanpa perlu diperintahkan satu per satu. Anak buah pustakawan kepala mewarisi kebijakan ini. Demikian pula dalam CSS, variabel yang didefinisikan pada elemen induk secara otomatis diwarisi oleh semua elemen anaknya.

## Penjelasan Detail

Salah satu karakteristik paling kuat dari CSS Custom Properties adalah pewarisan (inheritance). Ketika sebuah variabel didefinisikan pada suatu elemen, nilai tersebut tersedia untuk elemen itu sendiri dan semua elemen turunannya di pohon DOM. Ini berbeda dengan properti CSS biasa yang mungkin tidak diwarisi (seperti `margin` atau `border`). Pewarisan variabel mengikuti struktur hierarki DOM, bukan struktur visual. Jika elemen anak mendefinisikan ulang variabel dengan nama yang sama, nilai lokal anak akan menimpa nilai yang diwarisi dari induk. Mekanisme ini memungkinkan pembuatan tema kontekstual—di mana komponen yang sama dapat memiliki tampilan berbeda tergantung di mana ia ditempatkan dalam hierarki halaman. Pewarisan juga memungkinkan pengelompokan nilai dalam satu container untuk mempengaruhi semua child elements secara seragam.

## Contoh Kode Implementasi

```css
:root {
  --warna-teks: #333;
  --ukuran-font: 16px;
}

.container-dark {
  --warna-teks: #eee;
  --ukuran-font: 18px;
  background-color: #222;
  padding: 20px;
}

.container-dark p {
  color: var(--warna-teks);
  font-size: var(--ukuran-font);
}

p {
  color: var(--warna-teks);
  font-size: var(--ukuran-font);
}

.sidebar {
  --warna-teks: #555;
  --ukuran-font: 14px;
}

.main-content {
  --ukuran-font: 18px;
}
```

## Poin Penting
- Variabel CSS diwarisi dari elemen induk ke elemen anak secara otomatis.
- Pewarisan mengikuti hierarki DOM, bukan hierarki visual atau tata letak.
- Nilai lokal pada anak menimpa nilai yang diwarisi dari induk (shadowing).
- Mekanisme ini memungkinkan tematisasi kontekstual berdasarkan posisi elemen.
- Tidak seperti properti biasa yang perlu diatur `inherit`, variabel selalu diwarisi secara default.
