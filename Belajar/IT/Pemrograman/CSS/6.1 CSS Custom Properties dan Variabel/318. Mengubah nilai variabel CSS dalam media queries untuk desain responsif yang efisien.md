# Mengubah Variabel dalam Media Queries

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki pengaturan tampilan yang berbeda untuk berbagai perangkat. Di layar komputer, navigasi ditampilkan sebagai sidebar lebar; di tablet, navigasi menyusut; di ponsel, navigasi berubah menjadi menu hamburger. Alih-alih menulis ulang setiap aturan untuk setiap ukuran layar, perpustakaan cukup mengubah variabel tata letak di setiap konfigurasi perangkat. Inilah cara kerja variabel CSS dalam media queries.

## Penjelasan Detail

Salah satu keunggulan utama CSS Custom Properties adalah kemampuannya diubah dalam media queries. Dengan mengubah nilai variabel di dalam aturan `@media`, kita dapat menyesuaikan tampilan elemen secara responsif tanpa perlu menulis ulang setiap deklarasi properti. Ini menghasilkan kode yang lebih bersih, lebih mudah dipelihara, dan lebih efisien. Alih-alih mengubah setiap properti secara individual untuk setiap breakpoint, cukup ubah beberapa variabel kunci dan semua elemen yang menggunakan variabel tersebut akan menyesuaikan secara otomatis. Teknik ini sangat berguna untuk properti seperti ukuran font, spacing, padding, ukuran komponen, dan bahkan warna yang perlu beradaptasi dengan konteks perangkat. Namun perlu diingat bahwa variabel CSS tidak bisa digunakan di dalam syntax media query itu sendiri—hanya nilainya yang bisa diubah.

## Contoh Kode Implementasi

```css
:root {
  --spasi-konten: 2rem;
  --ukuran-judul: 2.5rem;
  --ukuran-teks: 1rem;
  --lebar-sidebar: 300px;
  --padding-card: 1.5rem;
  --grid-kolom: repeat(3, 1fr);
}

@media (max-width: 1024px) {
  :root {
    --spasi-konten: 1.5rem;
    --ukuran-judul: 2rem;
    --lebar-sidebar: 240px;
    --grid-kolom: repeat(2, 1fr);
  }
}

@media (max-width: 640px) {
  :root {
    --spasi-konten: 1rem;
    --ukuran-judul: 1.5rem;
    --ukuran-teks: 0.875rem;
    --lebar-sidebar: 0px;
    --padding-card: 1rem;
    --grid-kolom: 1fr;
  }
}

.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: var(--spasi-konten);
}

.card-grid {
  display: grid;
  grid-template-columns: var(--grid-kolom);
  gap: var(--spasi-konten);
}
```

## Poin Penting
- Ubah nilai variabel dalam media queries untuk desain responsif yang efisien tanpa menulis ulang banyak deklarasi.
- Tidak perlu mengubah setiap properti secara individual—cukup ubah variabel kunci.
- Variabel yang diubah dalam media queries mempengaruhi semua elemen yang merujuk padanya.
- Sangat efektif untuk properti ukuran, spacing, layout, dan tipografi responsif.
- Variabel CSS tidak bisa digunakan untuk mendefinisikan kondisi media query itu sendiri.
