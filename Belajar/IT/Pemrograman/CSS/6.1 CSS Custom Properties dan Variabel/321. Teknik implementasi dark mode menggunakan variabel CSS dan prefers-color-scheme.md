# Dark Mode dengan Variabel CSS dan prefers-color-scheme

## Analogi: Perpustakaan Digital

Perpustakaan digital modern memiliki mode siang dan malam yang otomatis menyesuaikan dengan preferensi pengguna. Di siang hari, latar terang dengan teks gelap memberikan kenyamanan membaca. Saat malam tiba, tampilan berubah menjadi latar gelap dengan teks terang untuk mengurangi ketegangan mata. Alih-alih mendesain dua tema terpisah, perpustakaan cukup mengubah palet warna variabelnya berdasarkan deteksi preferensi sistem pengguna.

## Penjelasan Detail

Implementasi dark mode yang efektif menggunakan CSS Custom Properties bersama dengan media query `prefers-color-scheme`. Media query ini mendeteksi preferensi tema sistem operasi pengguna (light, dark, atau no-preference). Dengan mendefinisikan nilai variabel warna dalam dua konteks berbeda—satu di luar media query (default light) dan satu di dalam `@media (prefers-color-scheme: dark)`—seluruh tema dapat berubah hanya dengan mengganti nilai beberapa variabel kunci. Pendekatan ini jauh lebih bersih daripada menulis ulang setiap selector untuk dark mode. Untuk memberikan kontrol lebih kepada pengguna, kita juga bisa mengabaikan preferensi sistem dengan toggle manual menggunakan JavaScript yang mengubah variabel pada `:root` atau menambahkan class pada elemen HTML. Teknik ini memastikan aksesibilitas dan kenyamanan pengguna dalam berbagai kondisi pencahayaan.

## Contoh Kode Implementasi

```css
:root {
  --warna-latar: #ffffff;
  --warna-teks: #1a1a2e;
  --warna-kartu: #f8f9fa;
  --warna-border: #dee2e6;
  --warna-primer: #4361ee;
  --warna-tautan: #3a0ca3;
  --bayangan: 0 2px 8px rgba(0,0,0,0.1);
}

@media (prefers-color-scheme: dark) {
  :root {
    --warna-latar: #1a1a2e;
    --warna-teks: #e8e8e8;
    --warna-kartu: #16213e;
    --warna-border: #2a2a4a;
    --warna-primer: #4cc9f0;
    --warna-tautan: #7209b7;
    --bayangan: 0 2px 8px rgba(0,0,0,0.4);
  }
}

[data-tema="light"] {
  --warna-latar: #ffffff;
  --warna-teks: #1a1a2e;
  --warna-kartu: #f8f9fa;
}

[data-tema="dark"] {
  --warna-latar: #1a1a2e;
  --warna-teks: #e8e8e8;
  --warna-kartu: #16213e;
}

body {
  background-color: var(--warna-latar);
  color: var(--warna-teks);
  transition: background-color 0.3s ease, color 0.3s ease;
}
```

## Poin Penting
- Gunakan `prefers-color-scheme` untuk mendeteksi preferensi tema sistem pengguna secara otomatis.
- Dark mode yang efektif hanya perlu mengubah nilai variabel, bukan menulis ulang seluruh stylesheet.
- Sediakan toggle manual untuk memberi pengguna kontrol lebih, mengabaikan preferensi sistem.
- Gunakan transisi CSS untuk animasi halus saat beralih antar tema.
- Pastikan kontras warna tetap memenuhi standar aksesibilitas WCAG di kedua mode.
