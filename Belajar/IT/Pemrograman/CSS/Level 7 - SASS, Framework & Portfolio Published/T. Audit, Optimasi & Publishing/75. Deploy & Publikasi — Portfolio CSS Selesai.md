# 75. Deploy & Publikasi — Portfolio CSS Selesai

## Penjelasan

Setelah 74 poin — dari reset CSS hingga SASS, dari warna hingga animasi — saatnya **deploy** website portofolio ke internet.

Platform deploy gratis untuk website statis:
- **Vercel** — deploy dari GitHub, auto HTTPS, drag-and-drop
- **Netlify** — drag-and-drop folder, form handling
- **GitHub Pages** — gratis dari repo GitHub

## Fungsi

- Website bisa diakses publik — portofolio untuk dicantumkan di CV
- Uji coba di environment production — tidak selalu sama dengan localhost
- Evaluasi akhir — Lighthouse di production

## Cara Pengimplementasian

**Final checklist sebelum deploy:**
```
[ ] Semua file CSS terorganisir di folder css/
[ ] Tidak ada !important yang tidak perlu
[ ] Tidak ada selector yang tidak dipakai (cek Coverage)
[ ] Semua animasi respek prefers-reduced-motion
[ ] Dark mode berfungsi (toggle + OS preference)
[ ] Mobile responsive (320px - 1920px)
[ ] Lighthouse score ≥ 90 di semua kategori
[ ] HTML divalidasi (validator.w3.org)
[ ] Alt text di semua gambar
[ ] Meta tags: viewport, description, OG tags
[ ] 404 page kustom
```

**Deploy ke Vercel:**
```bash
# 1. Install Vercel CLI
npm install -g vercel

# 2. Deploy dari folder
vercel --prod

# Atau:
# Hubungkan GitHub repo ke Vercel.com → auto-deploy setiap push
```

**Deploy ke GitHub Pages:**
```bash
# 1. Push ke GitHub
git add .
git commit -m "feat: portfolio CSS selesai"
git push

# 2. GitHub → Settings → Pages → Source: main branch /docs folder
# Website live di: username.github.io/repo-name
```

**Deploy ke Netlify:**
```bash
# Drag-and-drop folder (dist/ atau ./) ke netlify.com
# Atau: hubungkan GitHub → auto-deploy
```

**Setelah deploy — final audit:**
```bash
npx lighthouse https://portfolio-kamu.vercel.app --view
```

## Analogi

**Rumah selesai dibangun** — dinding dicat (Level 1), furnitur ditata (Level 2-4), taman dibuat (Level 5-6), dan gerbang dipasang (Level 7).

Sekarang saatnya **open house** — undang orang (deploy) untuk melihat rumah yang sudah dibangun dari awal. Ada rasa bangga melihat hasil kerja — "Ini rumah yang saya bangun dari pondasi hingga atap, dengan tangan saya sendiri."

**CSS Roadmap selesai. Portfolio sekarang live.**

## Kesalahan Umum

- **Lupa final check**: deploy, lalu CSS berantakan — selalu test di production
- **File tidak di-minify**: deploy file development — besar dan lambat
- **Absolute path error**: path gambar/CSS pake `./` relatif — pastikan benar di production
- **Dark mode tidak di-test di production**: bisa berbeda dengan localhost
- **Tidak ada README**: dokumentasi cara run dan build
