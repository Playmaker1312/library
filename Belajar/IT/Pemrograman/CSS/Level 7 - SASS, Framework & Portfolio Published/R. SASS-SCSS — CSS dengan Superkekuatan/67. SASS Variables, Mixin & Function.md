# 67. SASS Variables, Mixin & Function

## Penjelasan

Tiga fitur SASS yang membuat CSS lebih **reusable**:

- **`$variable`**: nilai yang di-compile (berbeda dengan CSS Variables `--var` yang runtime)
- **`@mixin`**: blok CSS reusable yang bisa menerima argumen
- **`@function`**: fungsi yang mengembalikan nilai (bukan blok CSS)

```scss
// SASS variables — di-compile menjadi nilai statis
$color-primary: #2563eb;
$breakpoint-md: 768px;

// Mixin — reusable block
@mixin flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
}

// Function — return value
@function rem($px) {
  @return $px / 16 + rem;
}
```

## Fungsi

- **$variable**: untuk nilai yang tidak perlu berubah runtime (breakpoints, konfigurasi)
- **@mixin**: menghindari duplikasi kode — flex-center, responsive, button variants
- **@function**: kalkulasi nilai — px ke rem, color manipulation

## Cara Pengimplementasian

```scss
// === SASS VARIABLES ===
$font-primary: 'Inter', sans-serif;
$breakpoint-sm: 640px;
$breakpoint-md: 768px;
$breakpoint-lg: 1024px;

// === MIXIN ===
@mixin flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
}

@mixin responsive($bp) {
  @media (min-width: $bp) {
    @content; // placeholder untuk konten
  }
}

@mixin button-variant($bg, $color: white) {
  background-color: $bg;
  color: $color;
  padding: 12px 24px;
  border: none;
  border-radius: 8px;
  cursor: pointer;
  
  &:hover {
    background-color: darken($bg, 10%);
  }
}

// === FUNCTION ===
@function rem($px) {
  @return $px / 16 * 1rem;
}

@function em($px, $base: 16) {
  @return $px / $base * 1em;
}

// === PENGGUNAAN ===
.hero {
  @include flex-center;
  min-height: 100vh;
  
  @include responsive($breakpoint-md) {
    min-height: 80vh;
  }
}

.btn-primary {
  @include button-variant(#2563eb);
}

.btn-success {
  @include button-variant(#10b981);
}

.element {
  padding: rem(24); // → 1.5rem
  font-size: em(18); // → 1.125em
}
```

## Analogi

- **$variable** = **resep dasar di buku** — "gunakan gula 200g" ($sugar: 200g). Dicetak di buku, tidak bisa diubah saat memasak (compile-time, bukan runtime).
- **@mixin** = **cetakan kue** — masukkan adonan, keluar bentuk kue yang sama. Cetakan bisa punya variasi (argumen): "cetakan bintang" vs "cetakan hati" ($shape).
- **@function** = **timbangan digital** — masukkan gram (px), keluar kilogram (rem). Kalkulasi, bukan blok CSS.

## Dipakai Untuk Apa

- **$variable**: breakpoints, font stacks, konfigurasi
- **@mixin**: responsive queries, flex-center, button variants, card variants
- **@function**: unit conversion, color manipulation (lighten, darken)

## Kesalahan Umum

- **SASS $ vs CSS -- bingung**: SASS variable di-compile ke nilai statis. CSS variable tetap sebagai variable di browser. Pilih berdasarkan kebutuhan: runtime = CSS var, compile-time = SASS var
- **Mixin untuk satu penggunaan**: jika hanya dipakai sekali, lebih baik tulis langsung
- **Terlalu banyak argumen mixin**: mixin dengan 10 argumen sulit digunakan
- **Function untuk hal sederhana**: `rem(24)` vs tulis `1.5rem` — mana yang lebih mudah dibaca?

## Hubungan dengan Materi Sebelumnya

Poin 66: SASS nesting. **Variables, mixin, function** adalah fitur yang membuat SASS powerful — kode yang reusable dan terorganisir. Ini adalah langkah dari "menulis CSS" ke "memproduksi CSS".

## Soal Latihan

### Soal 1
Buat mixin untuk responsive query dengan breakpoint parameter.

**Jawaban:**
```scss
@mixin respond($bp) {
  @media (min-width: $bp) { @content; }
}
// Pakai: @include respond(768px) { ... }
```

### Soal 2
Apa perbedaan SASS variable (`$`) dan CSS variable (`--`)?

**Jawaban:**
SASS variable di-compile menjadi nilai statis di CSS — tidak bisa diubah runtime. CSS variable tetap sebagai variable — bisa diubah via JavaScript, media query, atau selector.

### Soal 3
Buat function SASS yang mengubah px ke rem (asumsi base 16px).

**Jawaban:**
```scss
@function rem($px) {
  @return $px / 16 * 1rem;
}
```
