# Nilai margin auto untuk memusatkan elemen secara horizontal

## Analogi: Perpustakaan Digital

Seperti buku yang ditempatkan tepat di tengah rak agar terlihat seimbang, margin auto memusatkan elemen secara horizontal dalam wadahnya. Bayangkan petugas perpustakaan yang menggeser buku sehingga jarak kiri dan kanannya sama persis. Margin auto melakukan hal yang sama: mendorong elemen ke tengah dengan membagi ruang kosong secara merata di kedua sisi.

## Penjelasan Detail

Nilai auto pada margin-left dan margin-right menyuruh browser untuk menghitung margin secara otomatis. Ketika diterapkan bersama pada elemen block yang memiliki lebar tertentu, margin auto akan membagi ruang kosong yang tersisa secara merata di kiri dan kanan, sehingga elemen menjadi terpusat. Syaratnya elemen harus memiliki lebar yang ditentukan (width atau max-width) dan bersifat block level. auto pada margin-top dan margin-bottom biasanya bernilai 0, kecuali dalam konteks flexbox atau grid. Dalam flexbox, margin auto dapat digunakan untuk mendorong item ke posisi tertentu. auto pada satu sisi juga dapat digunakan untuk mendorong elemen ke sisi berlawanan. Teknik ini merupakan metode standar untuk memusatkan elemen block secara horizontal sebelum era flexbox.

## Contoh Kode Implementasi

```css
/* Sentrasi horizontal klasik */
.centered-block {
  width: 300px;
  margin-left: auto;
  margin-right: auto;
  background: #3498db;
  color: white;
  padding: 20px;
}

/* Menggunakan shorthand margin */
.centered-shorthand {
  width: 50%;
  margin: 0 auto;
  background: #e74c3c;
  color: white;
  padding: 20px;
}

/* Auto dengan max-width untuk responsif */
.responsive-centered {
  max-width: 800px;
  margin: 0 auto;
  padding: 20px;
}

/* Margin auto dalam flexbox memusatkan item */
.flex-container {
  display: flex;
  height: 200px;
  border: 1px solid #333;
}

.flex-item {
  margin: auto; /* memusatkan vertikal dan horizontal */
  background: #2ecc71;
  padding: 20px;
}

/* Auto untuk mendorong ke kanan */
.push-right {
  width: 200px;
  margin-left: auto;
  margin-right: 0;
  background: #f39c12;
  color: white;
  padding: 10px;
}

/* Multiple items dengan auto spacing */
.nav {
  display: flex;
}

.nav-item:last-child {
  margin-left: auto; /* mendorong item terakhir ke kanan */
}

/* Auto tidak bekerja pada elemen inline */
span {
  margin: 0 auto; /* tidak akan memusatkan span */
  display: block; /* harus diubah ke block */
  width: 200px;
}
```

## Poin Penting
- margin: 0 auto memusatkan elemen block secara horizontal dengan syarat elemen memiliki lebar tertentu
- margin auto membagi ruang kosong secara merata di antara sisi kiri dan kanan
- Dalam flexbox, margin auto dapat memusatkan item secara vertikal dan horizontal
- Elemen inline tidak dapat dipusatkan dengan margin auto; ubah display ke block atau gunakan text-align
