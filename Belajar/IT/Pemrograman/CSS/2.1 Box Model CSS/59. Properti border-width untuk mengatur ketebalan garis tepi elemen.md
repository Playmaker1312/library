# Properti border-width untuk mengatur ketebalan garis tepi elemen

## Analogi: Perpustakaan Digital

Seperti ketebalan sampul buku yang bervariasi dari tipis hingga tebal, border-width menentukan seberapa tebal garis tepi elemen. Buku saku mungkin memiliki sampul tipis, sedangkan ensiklopedia memiliki sampul tebal. Dalam CSS, kita dapat memilih ketebalan border dari yang sangat tipis hingga sangat tebal sesuai kebutuhan desain.

## Penjelasan Detail

Properti border-width mengatur ketebalan garis border elemen. Nilai dapat ditentukan menggunakan satuan panjang seperti px, em, rem, atau menggunakan kata kunci thin (tipis), medium (sedang), dan thick (tebal) yang masing-masing setara dengan 1px, 3px, dan 5px pada kebanyakan browser. Nilai default border-width adalah medium. border-width dapat diatur secara terpisah untuk setiap sisi menggunakan border-top-width, border-right-width, border-bottom-width, dan border-left-width, atau menggunakan shorthand border-width dengan satu hingga empat nilai. Ketebalan border mempengaruhi ukuran total elemen dan visual desain. border-width yang terlalu tipis mungkin sulit terlihat, sedangkan yang terlalu tebal dapat mendominasi elemen.

## Contoh Kode Implementasi

```css
/* Kata kunci border-width */
.thin-border {
  border-style: solid;
  border-width: thin; /* sekitar 1px */
  border-color: #333;
}

.medium-border {
  border-style: solid;
  border-width: medium; /* sekitar 3px */
  border-color: #666;
}

.thick-border {
  border-style: solid;
  border-width: thick; /* sekitar 5px */
  border-color: #999;
}

/* border-width dengan satuan piksel */
.pixel-border {
  border-style: solid;
  border-width: 4px;
  border-color: #e74c3c;
}

/* border-width berbeda per sisi dengan shorthand */
.asymmetric-border {
  border-style: solid;
  border-color: #3498db;
  border-width: 1px 3px 5px 2px;
}

/* border-width individual per sisi */
.individual-widths {
  border-style: solid;
  border-color: #2ecc71;
  border-top-width: 1px;
  border-right-width: 4px;
  border-bottom-width: 8px;
  border-left-width: 2px;
}

/* border-width dalam shorthand border */
.shorthand-border {
  border: 4px dashed #e67e22;
}

/* border-width menggunakan em */
.em-border {
  border-style: solid;
  border-width: 0.2em;
  border-color: #9b59b6;
  font-size: 20px;
}
```

## Poin Penting
- border-width menggunakan satuan panjang (px, em) atau kata kunci thin, medium (default), dan thick
- border-width dapat diatur per sisi menggunakan properti individual atau shorthand dengan 1-4 nilai
- border-style harus ditentukan agar border-width memiliki efek karena default border-style adalah none
- Ketebalan border mempengaruhi ukuran total elemen dan harus dipertimbangkan dalam perhitungan tata letak
