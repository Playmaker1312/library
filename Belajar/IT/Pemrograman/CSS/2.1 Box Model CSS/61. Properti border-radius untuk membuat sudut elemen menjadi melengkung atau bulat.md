# Properti border-radius untuk membuat sudut elemen menjadi melengkung atau bulat

## Analogi: Perpustakaan Digital

Bayangkan buku yang sudut halamannya sengaja dilipat atau dibulatkan agar tidak melukai pembaca. Border-radius dalam CSS melakukan hal yang sama pada elemen web. Sudut yang melengkung memberikan kesan yang lebih lembut, modern, dan ramah dibandingkan sudut yang tajam. Seperti perpustakaan anak-anak yang menggunakan buku dengan sudut rounded untuk keamanan.

## Penjelasan Detail

Properti border-radius memungkinkan sudut elemen menjadi melengkung dengan radius tertentu. Nilai dapat berupa satuan panjang (px, em) atau persentase. Satu nilai akan diterapkan ke semua sudut. Dua nilai: nilai pertama untuk sudut kiri-atas dan kanan-bawah, nilai kedua untuk kanan-atas dan kiri-bawah. Tiga nilai: kiri-atas, kanan-atas dan kiri-bawah, kanan-bawah. Empat nilai: kiri-atas, kanan-atas, kanan-bawah, kiri-bawah (searah jarum jam). Nilai persentase dihitung relatif terhadap dimensi elemen, 50% akan membuat elemen persegi menjadi lingkaran sempurna. border-radius juga memiliki varian individual: border-top-left-radius, border-top-right-radius, border-bottom-right-radius, dan border-bottom-left-radius. Properti ini bekerja dengan baik pada elemen yang memiliki border, background, atau box-shadow.

## Contoh Kode Implementasi

```css
/* Sudut melengkung seragam */
.rounded-box {
  border: 2px solid #333;
  border-radius: 10px;
  padding: 20px;
}

/* Lingkaran sempurna dengan border-radius 50% */
.circle {
  width: 150px;
  height: 150px;
  background: #3498db;
  border-radius: 50%;
}

/* Sudut melengkung berbeda per sisi */
.asymmetric-radius {
  border-radius: 10px 30px 50px 70px;
  background: #e74c3c;
  padding: 20px;
  color: white;
}

/* Tombol dengan border-radius */
.btn {
  background: #2ecc71;
  color: white;
  border: none;
  border-radius: 5px;
  padding: 12px 24px;
  cursor: pointer;
}

/* Tombol pill shape */
.pill-btn {
  background: #9b59b6;
  color: white;
  border: none;
  border-radius: 50px;
  padding: 12px 40px;
}

/* Hanya rounded di atas */
.top-rounded {
  border-radius: 20px 20px 0 0;
  background: #f39c12;
  padding: 15px;
  color: white;
}

/* border-radius individual */
.individual-corners {
  border-top-left-radius: 10px;
  border-top-right-radius: 20px;
  border-bottom-right-radius: 30px;
  border-bottom-left-radius: 40px;
  background: #1abc9c;
  padding: 15px;
  color: white;
}

/* border-radius dengan nilai yang besar */
.pill-shape {
  width: 300px;
  height: 60px;
  background: #e67e22;
  border-radius: 30px;
}
```

## Poin Penting
- border-radius membuat sudut elemen melengkung dengan nilai radius yang ditentukan dalam px atau persentase
- Nilai 50% pada elemen persegi akan menghasilkan lingkaran, pada persegi panjang akan menghasilkan oval
- Gunakan border-radius individual untuk mengatur sudut tertentu secara spesifik
- border-radius tetap berfungsi tanpa border, mempengaruhi background dan box-shadow elemen
