# Shorthand padding dengan satu, dua, tiga, dan empat nilai sekaligus

## Analogi: Perpustakaan Digital

Seperti mengatur jarak buku dari tepi rak, shorthand padding memungkinkan kita menentukan jarak secara efisien. Jika semua sisi sama, cukup satu perintah. Jika berbeda, kita bisa mengatur setiap sisi dengan urutan tertentu. Ini seperti memberi instruksi pada petugas perpustakaan untuk mengatur jarak buku dari tepi atas, kanan, bawah, dan kiri rak dalam satu kalimat.

## Penjelasan Detail

Shorthand padding memungkinkan pengaturan padding untuk semua sisi elemen dalam satu deklarasi. Dengan satu nilai, padding diterapkan secara merata ke semua sisi. Dengan dua nilai, nilai pertama untuk padding atas dan bawah, nilai kedua untuk padding kanan dan kiri. Dengan tiga nilai, nilai pertama untuk atas, nilai kedua untuk kanan dan kiri, nilai ketiga untuk bawah. Dengan empat nilai, urutannya adalah atas, kanan, bawah, kiri (searah jarum jam). Shorthand ini mengikuti pola yang sama dengan margin dan properti lainnya. Penggunaan shorthand membuat kode lebih ringkas dan mudah dibaca, namun perlu diingat urutan nilainya. Nilai dapat menggunakan satuan apa pun yang valid untuk padding, termasuk px, em, rem, dan persentase.

## Contoh Kode Implementasi

```css
/* Satu nilai: padding 20px di semua sisi */
.equal-padding {
  padding: 20px;
}

/* Dua nilai: atas-bawah 10px, kanan-kiri 30px */
.vertical-horizontal {
  padding: 10px 30px;
}

/* Tiga nilai: atas 5px, kanan-kiri 15px, bawah 25px */
.three-values {
  padding: 5px 15px 25px;
}

/* Empat nilai: atas 10px, kanan 20px, bawah 30px, kiri 40px */
.four-values {
  padding: 10px 20px 30px 40px;
}

/* Contoh praktis pada tombol */
.btn {
  padding: 12px 24px; /* atas-bawah 12px, kanan-kiri 24px */
  background: #4CAF50;
  color: white;
  border: none;
  border-radius: 4px;
}

/* Konten artikel */
.article-content {
  padding: 20px 40px 30px; /* atas 20px, kanan-kiri 40px, bawah 30px */
}

/* Kartu dengan padding asimetris */
.card {
  padding: 16px 16px 24px; /* lebih banyak padding di bawah */
  border: 1px solid #ddd;
  border-radius: 8px;
}

/* Navigasi dengan padding horizontal lebih besar */
.nav-item {
  padding: 8px 20px;
  display: inline-block;
}
```

## Poin Penting
- Satu nilai: semua sisi sama; dua nilai: vertikal dan horizontal; tiga nilai: atas, horizontal, bawah; empat nilai: atas, kanan, bawah, kiri
- Shorthand padding mengikuti urutan searah jarum jam dimulai dari atas
- Gunakan shorthand untuk kode yang lebih bersih, tetapi pastikan memahami urutan nilai dengan benar
- Shorthand dapat dikombinasikan dengan properti padding individual untuk kasus tertentu
