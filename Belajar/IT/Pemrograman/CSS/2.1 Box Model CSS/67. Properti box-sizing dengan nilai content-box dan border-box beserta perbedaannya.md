# Properti box-sizing dengan nilai content-box dan border-box beserta perbedaannya

## Analogi: Perpustakaan Digital

Bayangkan dua cara mengukur ukuran buku: content-box mengukur hanya ukuran halaman isi buku, sedangkan border-box mengukur dari sampul luar buku. Jika Anda memesan rak buku, Anda perlu tahu apakah ukuran yang disebutkan termasuk sampul atau hanya halaman isinya. Box-sizing menentukan cara browser menghitung ukuran total elemen, apakah termasuk padding dan border atau tidak.

## Penjelasan Detail

Properti box-sizing mengubah cara browser menghitung lebar dan tinggi total elemen. Nilai content-box (default) membuat width dan height hanya mengukur area konten, sehingga padding dan border ditambahkan di luar ukuran tersebut. Nilai border-box membuat width dan height mencakup konten, padding, dan border, sehingga ukuran total elemen tetap sesuai yang ditentukan. Perbedaan utama: dengan content-box, menambah padding akan memperbesar elemen; dengan border-box, padding dan border mengurangi ruang konten tanpa mengubah ukuran total. border-box sangat memudahkan pembuatan layout responsif karena ukuran elemen lebih dapat diprediksi. Saat ini border-box banyak digunakan secara global dengan universal selector karena menghilangkan perhitungan manual.

## Contoh Kode Implementasi

```css
/* content-box (default) */
.content-box-demo {
  box-sizing: content-box;
  width: 300px;
  padding: 20px;
  border: 5px solid #333;
  /* Total lebar = 300 + 20 + 20 + 5 + 5 = 350px */
  background: #f0f0f0;
}

/* border-box */
.border-box-demo {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
  border: 5px solid #333;
  /* Total lebar = 300px (padding dan border di dalam) */
  background: #e0f7fa;
}

/* Perbandingan langsung */
.comparison {
  display: flex;
  gap: 20px;
}

.comparison > div {
  width: 200px;
  padding: 15px;
  border: 3px solid black;
}

.content-box {
  box-sizing: content-box;
  /* Total = 200 + 15 + 15 + 3 + 3 = 236px */
}

.border-box {
  box-sizing: border-box;
  /* Total = 200px */
}

/* Grid layout dengan border-box */
.grid-container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 10px;
}

.grid-item {
  box-sizing: border-box;
  padding: 15px;
  border: 1px solid #ddd;
}

/* Kolom dengan persentase menggunakan border-box */
.column {
  box-sizing: border-box;
  width: 50%;
  padding: 20px;
  float: left;
}
```

## Poin Penting
- content-box (default): width/height hanya untuk konten, padding dan border ditambahkan di luar
- border-box: width/height mencakup konten + padding + border, memudahkan perhitungan ukuran
- border-box sangat direkomendasikan untuk layout responsif karena ukuran total lebih mudah diprediksi
- border-box dapat diterapkan secara global dengan universal selector (*) untuk konsistensi di seluruh proyek
