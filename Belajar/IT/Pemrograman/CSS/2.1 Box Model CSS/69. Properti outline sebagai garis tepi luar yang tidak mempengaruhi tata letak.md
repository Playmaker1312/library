# Properti outline sebagai garis tepi luar yang tidak mempengaruhi tata letak

## Analogi: Perpustakaan Digital

Bayangkan stabilo atau highlighter yang digunakan untuk menandai buku tanpa merusak halamannya. Outline dalam CSS bekerja seperti stabilo: menandai elemen dengan garis di sekelilingnya tanpa mengubah ukuran atau posisi elemen tersebut. Seperti menandai buku penting di rak tanpa memindahkannya, outline memberi penekanan visual tanpa mengganggu tata letak.

## Penjelasan Detail

Outline adalah garis yang digambar di sekitar elemen, di luar border, tetapi tidak mempengaruhi ukuran atau posisi elemen. Berbeda dengan border, outline tidak termasuk dalam perhitungan box model dan tidak mempengaruhi tata letak elemen di sekitarnya. Outline dapat digunakan untuk indikasi fokus, debugging tata letak, atau efek visual tanpa mengubah dimensi elemen. Outline dapat memiliki style, width, dan color yang mirip dengan border, tetapi tidak dapat diatur per sisi (selalu mengelilingi seluruh elemen). Outline juga dapat di-offset menggunakan outline-offset untuk menggeser posisinya ke luar atau ke dalam. Browser sering menggunakan outline untuk menunjukkan elemen yang sedang fokus, terutama pada elemen yang dapat difokuskan seperti input dan tombol.

## Contoh Kode Implementasi

```css
/* Outline sederhana */
.focus-outline {
  outline: 2px solid #007bff;
}

/* Outline dengan offset */
.offset-outline {
  outline: 3px dashed #e74c3c;
  outline-offset: 5px; /* menggeser outline ke luar */
  margin: 20px;
  padding: 15px;
}

/* Outline offset negatif (ke dalam) */
.inner-outline {
  outline: 2px solid #3498db;
  outline-offset: -5px;
  padding: 15px;
}

/* Outline pada fokus - aksesibilitas */
input:focus {
  outline: 3px solid #4A90D9;
  outline-offset: 2px;
}

/* Menghilangkan outline default (hati-hati untuk aksesibilitas) */
.remove-outline {
  outline: none; /* atau outline: 0 */
}

/* Custom focus outline yang lebih baik */
.custom-focus:focus {
  outline: none;
  box-shadow: 0 0 0 3px rgba(52, 152, 219, 0.5);
}

/* Outline untuk debugging layout */
.debug {
  outline: 1px solid red; /* tidak mengubah layout */
}

/* Outline dengan gaya dotted */
.dotted-outline {
  outline: 2px dotted #9b59b6;
  padding: 10px;
}

/* Perbandingan border vs outline */
.border-example {
  border: 3px solid #e74c3c; /* mempengaruhi ukuran */
  padding: 10px;
}

.outline-example {
  outline: 3px solid #3498db; /* tidak mempengaruhi ukuran */
  padding: 10px;
}
```

## Poin Penting
- Outline adalah garis di luar border yang tidak mempengaruhi ukuran atau tata letak elemen
- Outline tidak dapat diatur per sisi, selalu mengelilingi seluruh elemen
- outline-offset menggeser posisi outline ke luar (positif) atau ke dalam (negatif) dari border
- Outline penting untuk aksesibilitas sebagai indikator fokus, jangan dihapus tanpa alternatif yang baik
