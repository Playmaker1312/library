# Perbedaan border dan outline serta kapan menggunakan masing-masing

## Analogi: Perpustakaan Digital

Border seperti sampul buku yang menjadi bagian dari buku itu sendiri, mempengaruhi ukuran dan posisinya di rak. Outline seperti pita penanda yang ditempelkan di sampul tanpa mengubah buku itu sendiri. Jika Anda ingin buku terlihat lebih besar dengan sampul tebal, gunakan border. Jika hanya ingin menandai buku tanpa mengubah ukurannya, gunakan outline. Keduanya memiliki tujuan yang berbeda dalam perpustakaan digital.

## Penjelasan Detail

Border dan outline sama-sama menggambar garis di sekitar elemen, tetapi memiliki perbedaan fundamental. Border termasuk dalam box model dan mempengaruhi ukuran total serta tata letak elemen. Outline tidak termasuk dalam box model dan digambar di atas elemen tanpa mempengaruhi ukuran atau posisi. Border dapat diatur per sisi (top, right, bottom, left) dengan gaya dan warna berbeda. Outline selalu seragam di semua sisi dan tidak dapat diatur per sisi. Border mengikuti border-radius, sedangkan outline tidak selalu mengikuti border-radius di semua browser. Border lebih cocok untuk dekorasi permanen elemen, sedangkan outline lebih cocok untuk indikasi fokus sementara atau debugging. Outline memiliki properti outline-offset yang tidak dimiliki border. Keduanya memiliki properti width, style, dan color yang serupa.

## Contoh Kode Implementasi

```css
/* Border mempengaruhi layout */
.with-border {
  border: 5px solid #e74c3c;
  width: 200px;
  padding: 10px;
  /* Total lebar: 200 + 5 + 5 + 10 + 10 = 230px */
}

/* Outline tidak mempengaruhi layout */
.with-outline {
  outline: 5px solid #3498db;
  width: 200px;
  padding: 10px;
  /* Total lebar: 200 + 10 + 10 = 220px (outline tidak dihitung) */
}

/* Border per sisi */
.border-sides {
  border-top: 3px solid #e74c3c;
  border-bottom: 3px solid #3498db;
  border-left: 3px solid #2ecc71;
  border-right: 3px solid #f39c12;
  padding: 10px;
}

/* Outline tidak bisa per sisi */
.outline-uniform {
  outline: 3px solid #9b59b6;
  padding: 10px;
}

/* Border mengikuti border-radius */
.rounded-border {
  border: 3px solid #e74c3c;
  border-radius: 10px;
  padding: 15px;
}

/* Outline tidak selalu mengikuti border-radius */
.rounded-outline {
  outline: 3px solid #3498db;
  border-radius: 10px;
  padding: 15px;
}

/* Kapan menggunakan border */
.card {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 20px;
}

/* Kapan menggunakan outline */
input:focus-visible {
  outline: 2px solid #007bff;
  outline-offset: 2px;
}

/* Debugging dengan outline */
.debug-layout {
  outline: 1px solid rgba(255, 0, 0, 0.3);
}
```

## Poin Penting
- Border mempengaruhi ukuran dan tata letak elemen; outline tidak mempengaruhi sama sekali
- Border dapat diatur per sisi; outline hanya seragam di semua sisi
- Border mengikuti border-radius; outline belum tentu mengikuti border-radius
- Gunakan border untuk dekorasi permanen dan outline untuk indikator fokus sementara atau debugging
