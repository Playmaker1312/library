# Shorthand border dan penulisannya secara ringkas dalam satu deklarasi

## Analogi: Perpustakaan Digital

Seperti memesan sampul buku dengan spesifikasi lengkap dalam satu kalimat, shorthand border memungkinkan kita menetapkan lebar, gaya, dan warna border sekaligus. Daripada mengatakan "sampul buku setebal 2mm, bertekstur halus, dan berwarna biru", kita cukup mengatakan "sampul 2mm halus biru". Ini menghemat waktu dan membuat instruksi lebih jelas.

## Penjelasan Detail

Shorthand border menggabungkan border-width, border-style, dan border-color dalam satu deklarasi. Urutan penulisan tidak kaku, tetapi konvensi yang umum adalah width style color. Jika salah satu nilai tidak ditentukan, nilai default akan digunakan. border-style wajib ada, jika tidak, border tidak akan ditampilkan meskipun width dan color ditentukan. Shorthand border juga memiliki varian per sisi seperti border-top, border-right, border-bottom, dan border-left. Shorthand ini sangat berguna untuk menulis kode yang ringkas dan mudah dipelihara. Selain itu, terdapat properti border-width, border-style, dan border-color yang dapat digunakan sebagai shorthand untuk ketiga aspek tersebut secara terpisah.

## Contoh Kode Implementasi

```css
/* Shorthand border lengkap */
.card {
  border: 2px solid #333;
}

/* Shorthand per sisi */
.header {
  border-bottom: 3px solid #3498db;
}

.sidebar {
  border-right: 1px solid #ddd;
}

.notification {
  border-left: 4px solid #e74c3c;
}

/* Hanya style dan color, width default */
.light-border {
  border: solid #ccc; /* width akan menggunakan nilai default medium */
}

/* Shorthand border-width terpisah */
.thick-border {
  border-width: 4px;
  border-style: dashed;
  border-color: #e67e22;
}

/* Border dengan warna transparan */
.transparent-border {
  border: 2px solid transparent;
}

/* Mengganti hanya warna border */
.success-box {
  border: 1px solid #2ecc71;
}

.success-box.error {
  border-color: #e74c3c; /* hanya mengganti warna */
}

/* Tanpa border-style, border tidak tampak */
.invisible-border {
  border: 2px #333; /* tidak muncul karena style tidak ditentukan */
}
```

## Poin Penting
- Shorthand border ditulis dengan urutan width style color, dan border-style wajib ada agar border muncul
- Gunakan shorthand per sisi seperti border-bottom untuk border hanya pada satu sisi tertentu
- Shorthand border-width, border-style, dan border-color dapat digunakan untuk mengatur ketiga aspek secara kolektif
- Border tanpa border-style tidak akan ditampilkan meskipun width dan color sudah ditentukan
