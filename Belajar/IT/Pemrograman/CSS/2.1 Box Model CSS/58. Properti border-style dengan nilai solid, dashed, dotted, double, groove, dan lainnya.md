# Properti border-style dengan nilai solid, dashed, dotted, double, groove, dan lainnya

## Analogi: Perpustakaan Digital

Border-style seperti memilih jenis jilid buku: solid seperti jilid hardcover yang kokoh, dashed seperti jilid spiral dengan celah, dotted seperti jahitan benang, double seperti dua lapis sampul, groove seperti jilid timbul, dan ridge seperti jilid tenggelam. Setiap jenis memberikan tampilan dan kesan yang berbeda pada elemen.

## Penjelasan Detail

Properti border-style menentukan tampilan visual garis tepi elemen. Nilai yang tersedia meliputi solid (garis padat), dashed (garis putus-putus dengan segmen pendek), dotted (garis titik-titik), double (dua garis paralel), groove (efek timbul ke dalam), ridge (efek timbul ke luar), inset (efek tenggelam), outset (efek menonjol), none (tanpa border), dan hidden (border tersembunyi). Beberapa gaya seperti groove, ridge, inset, dan outset bergantung pada warna border untuk menciptakan efek tiga dimensi. Setiap sisi elemen dapat memiliki gaya border yang berbeda. border-style adalah properti yang wajib ada agar border muncul, karena nilai default-nya adalah none. Pemilihan gaya border mempengaruhi estetika dan keseluruhan desain halaman web.

## Contoh Kode Implementasi

```css
/* Berbagai jenis border-style */
.solid {
  border: 3px solid #333;
}

.dashed {
  border: 3px dashed #e74c3c;
}

.dotted {
  border: 3px dotted #3498db;
}

.double {
  border: 6px double #2ecc71;
}

.groove {
  border: 6px groove #8e44ad;
}

.ridge {
  border: 6px ridge #f39c12;
}

.inset {
  border: 6px inset #1abc9c;
}

.outset {
  border: 6px outset #e67e22;
}

/* Gaya berbeda per sisi */
.mixed-styles {
  border-top-style: solid;
  border-right-style: dashed;
  border-bottom-style: dotted;
  border-left-style: double;
  border-width: 3px;
  border-color: #333;
}

/* None vs hidden */
.no-border {
  border-style: none;
}

.hidden-border {
  border-style: hidden;
}

/* Demo table dengan border-style */
table {
  border-collapse: collapse;
}

td {
  border: 2px solid #333;
  padding: 8px;
}
```

## Poin Penting
- border-style memiliki nilai solid, dashed, dotted, double, groove, ridge, inset, outset, none, dan hidden
- border-style wajib ditentukan agar border muncul karena nilai default-nya adalah none
- Gaya groove, ridge, inset, dan outset menciptakan efek tiga dimensi berdasarkan warna border
- Setiap sisi elemen dapat memiliki border-style yang berbeda untuk efek kreatif
