# Properti width dan height untuk mengatur lebar dan tinggi elemen

## Analogi: Perpustakaan Digital

Seperti rak buku yang memiliki lebar dan tinggi tertentu untuk menampung buku-buku, setiap elemen HTML juga memiliki dimensi yang dapat diatur menggunakan properti width dan height. Rak buku yang terlalu sempit akan membuat buku terjepit, sedangkan rak yang terlalu longgar akan membuang ruang. Dalam perpustakaan digital, kita dapat menentukan secara presisi berapa besar ruang yang ditempati setiap elemen.

## Penjelasan Detail

Properti width dan height digunakan untuk mengatur dimensi elemen dalam CSS. Width menentukan lebar area konten elemen, sedangkan height menentukan tingginya. Kedua properti ini dapat menggunakan berbagai satuan seperti piksel (px), persentase (%), em, rem, viewport unit (vw, vh), atau nilai auto. Nilai auto membuat browser menghitung dimensi secara otomatis berdasarkan konten. Untuk elemen block level, width default adalah auto yang berarti memenuhi lebar induknya, sedangkan height default auto menyesuaikan konten. Elemen inline tidak terpengaruh oleh width dan height. Persentase pada width dihitung relatif terhadap lebar elemen induk, sedangkan persentase pada height memerlukan tinggi induk yang definitif. Properti ini juga mendukung nilai min-width, max-width, min-height, dan max-height untuk membatasi dimensi elemen.

## Contoh Kode Implementasi

```css
/* Dimensi dasar dengan piksel */
.card {
  width: 400px;
  height: 250px;
}

/* Dimensi responsif dengan persentase */
.responsive-box {
  width: 80%;
  max-width: 1200px;
  height: auto;
}

/* Menggunakan viewport units */
.full-screen {
  width: 100vw;
  height: 100vh;
}

/* Min dan max dimensions */
.flexible-box {
  width: 50%;
  min-width: 300px;
  max-width: 800px;
  height: auto;
  min-height: 200px;
}

/* Elemen inline tidak terpengaruh width/height */
span {
  width: 200px; /* Tidak berpengaruh */
  height: 100px; /* Tidak berpengaruh */
  display: inline-block; /* Solusi: ubah display */
}

/* height berdasarkan konten */
.auto-height {
  width: 500px;
  height: auto;
  padding: 20px;
}
```

## Poin Penting
- width dan height mengatur dimensi area konten, bukan total elemen termasuk padding dan border
- Elemen inline tidak dapat diatur width dan height-nya kecuali display diubah menjadi inline-block atau block
- Nilai persentase pada height memerlukan tinggi definitif pada elemen induk agar berfungsi
- Gunakan min-width/max-width dan min-height/max-height untuk membuat desain yang responsif dan fleksibel
