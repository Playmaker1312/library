# Properti border-color untuk mengatur warna garis tepi elemen

## Analogi: Perpustakaan Digital

Seperti buku di perpustakaan yang dikelompokkan berdasarkan warna sampul, border-color menentukan warna garis tepi elemen. Buku bergenre fiksi mungkin bersampul biru, sedangkan non-fiksi bersampul merah. Warna border dalam CSS membantu mengkategorikan, menonjolkan, atau memperindah tampilan elemen sesuai dengan skema desain.

## Penjelasan Detail

Properti border-color mengatur warna dari garis border elemen. Nilai warna dapat menggunakan berbagai format CSS seperti nama warna (red, blue), hexadecimal (#ff0000), RGB (rgb(255, 0, 0)), RGBA (rgba(255, 0, 0, 0.5)), HSL (hsl(0, 100%, 50%)), HSLA, atau nilai transparent. Nilai default border-color adalah warna teks elemen (color). border-color dapat diatur secara terpisah untuk setiap sisi menggunakan border-top-color, border-right-color, border-bottom-color, dan border-left-color, atau menggunakan shorthand border-color dengan satu hingga empat nilai. border-color yang menggunakan RGBA atau HSLA memungkinkan border dengan efek transparan. Warna border juga mempengaruhi efek visual dari border-style seperti groove, ridge, inset, dan outset yang menggunakan variasi warna untuk menciptakan efek tiga dimensi.

## Contoh Kode Implementasi

```css
/* border-color dengan nama warna */
.red-border {
  border: 2px solid red;
}

/* border-color dengan hexadecimal */
.hex-border {
  border: 3px solid #3498db;
}

/* border-color dengan RGB */
.rgb-border {
  border: 2px solid rgb(231, 76, 60);
}

/* border-color dengan RGBA transparan */
.rgba-border {
  border: 4px solid rgba(46, 204, 113, 0.5);
}

/* border-color dengan HSL */
.hsl-border {
  border: 2px solid hsl(39, 100%, 50%);
}

/* border-color berbeda per sisi */
.colored-sides {
  border-style: solid;
  border-width: 3px;
  border-color: #e74c3c #3498db #2ecc71 #f39c12;
}

/* border-color individual per sisi */
.individual-colors {
  border-style: solid;
  border-width: 3px;
  border-top-color: #e74c3c;
  border-right-color: #3498db;
  border-bottom-color: #2ecc71;
  border-left-color: #f39c12;
}

/* Menggunakan currentColor */
.current-color-border {
  border: 2px solid currentColor;
}

/* border-color transparent */
.transparent-border {
  border: 3px solid transparent;
}

/* border-color inherited */
.parent {
  color: #8e44ad;
}
.child {
  border: 2px solid;
  border-color: inherit;
}
```

## Poin Penting
- border-color mendukung semua format warna CSS: nama, hex, RGB, RGBA, HSL, HSLA, dan transparent
- Nilai default border-color adalah warna teks elemen (color property)
- border-color dapat diatur per sisi menggunakan properti individual atau shorthand dengan 1-4 nilai
- Warna mempengaruhi efek tiga dimensi pada border-style groove, ridge, inset, dan outset
