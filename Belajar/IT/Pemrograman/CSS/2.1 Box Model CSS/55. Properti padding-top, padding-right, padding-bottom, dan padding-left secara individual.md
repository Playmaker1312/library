# Properti padding-top, padding-right, padding-bottom, dan padding-left secara individual

## Analogi: Perpustakaan Digital

Seperti mengatur jarak setiap sisi buku dari tepi rak secara terpisah, properti padding individual memungkinkan kontrol presisi pada setiap sisi elemen. Mungkin sisi kiri buku perlu jarak lebih karena adanya jilid, atau sisi bawah perlu jarak ekstra untuk catatan kaki. Dalam perpustakaan digital, kita dapat mengatur setiap sisi dengan kebutuhan spesifiknya masing-masing.

## Penjelasan Detail

Properti padding individual terdiri dari padding-top, padding-right, padding-bottom, dan padding-left yang masing-masing mengatur padding pada satu sisi tertentu. Properti ini memberikan kontrol yang lebih spesifik dibandingkan shorthand ketika hanya satu atau beberapa sisi yang perlu diubah. Nilai yang digunakan sama dengan properti padding pada umumnya, termasuk px, em, rem, dan persentase. padding-bottom dan padding-top yang menggunakan persentase tetap dihitung berdasarkan lebar elemen induk. Properti individual sangat berguna dalam komponen yang memerlukan asimetri, seperti kartu dengan padding bawah lebih besar untuk tombol aksi, atau artikel dengan padding kiri untuk indentasi.

## Contoh Kode Implementasi

```css
/* Mengatur padding setiap sisi secara terpisah */
.custom-card {
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 30px;
  padding-left: 15px;
  border: 1px solid #333;
}

/* Kartu dengan padding bawah lebih besar untuk tombol */
.card-with-button {
  padding-top: 20px;
  padding-right: 20px;
  padding-bottom: 40px;
  padding-left: 20px;
  background: #fff;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

/* Indentasi paragraf dengan padding kiri */
.indented-paragraph {
  padding-left: 2em;
}

/* Navigasi dengan padding kanan tambahan */
.nav-item {
  padding-top: 10px;
  padding-right: 25px;
  padding-bottom: 10px;
  padding-left: 15px;
}

/* Hanya mengubah padding kiri, sisanya menggunakan nilai default */
.sidebar-item {
  padding-left: 24px;
}

/* Footer dengan padding atas untuk pemisah */
.footer {
  padding-top: 30px;
  padding-bottom: 20px;
  border-top: 2px solid #eee;
}
```

## Poin Penting
- padding-top, padding-right, padding-bottom, padding-left mengontrol padding pada masing-masing sisi secara terpisah
- Gunakan properti individual ketika hanya satu atau beberapa sisi yang perlu dimodifikasi untuk menghindari penimpaan
- Persentase pada padding-top dan padding-bottom tetap dihitung berdasarkan lebar elemen induk
- Kombinasikan dengan shorthand untuk nilai default dan properti individual untuk pengecualian sisi tertentu
