# Menggunakan box-sizing border-box secara global dengan universal selector

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang memutuskan untuk mengubah cara pengukuran semua bukunya. Daripada mengukur ukuran halaman isi, mereka sekarang mengukur dari sampul luar untuk semua koleksi. Dengan menerapkan border-box secara global menggunakan universal selector, kita mengubah cara semua elemen dihitung ukurannya sekaligus. Ini seperti kebijakan standar baru di seluruh perpustakaan yang membuat segalanya lebih konsisten.

## Penjelasan Detail

Penerapan box-sizing: border-box secara global menggunakan universal selector (*) adalah praktik umum yang merekomendasikan untuk mengubah model box default semua elemen. Tanpa ini, setiap kali menambahkan padding atau border pada elemen dengan lebar persentase, kita harus melakukan perhitungan manual untuk menghindari overflow. Dengan border-box, padding dan border termasuk dalam lebar yang ditentukan. Seringkali pola ini juga menyertakan pseudo-elements ::before dan ::after. Penerapan global menghilangkan kejutan dari perhitungan ukuran elemen dan membuat kode CSS lebih mudah diprediksi. Banyak kerangka kerja CSS seperti Bootstrap telah mengadopsi ini sebagai default. Penerapan ini biasanya ditempatkan di awal file CSS atau sebagai bagian dari CSS reset.

## Contoh Kode Implementasi

```css
/* Penerapan global border-box */
*,
*::before,
*::after {
  box-sizing: border-box;
}

/* CSS reset lengkap dengan border-box */
*,
*::before,
*::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

/* Contoh manfaat - kolom 50% dengan padding */
.column-half {
  width: 50%;
  padding: 20px;
  float: left;
  /* Tanpa border-box akan overflow, dengan border-box pas 50% */
}

/* Form elements konsisten */
input,
textarea,
select {
  width: 100%;
  padding: 10px;
  border: 1px solid #ccc;
  /* border-box membuat input tidak overflow */
}

/* Card grid yang responsif */
.card {
  width: 33.33%;
  padding: 15px;
  border: 1px solid #ddd;
  float: left;
  /* border-box membuat 3 card muat dalam satu baris */
}

/* Parent container */
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 20px;
}

/* Tanpa border-box global - perhitungan manual */
.container-old {
  width: 100%;
  padding: 20px;
  /* Harus menggunakan: width: calc(100% - 40px) */
}

/* Exception jika perlu content-box */
.special-element {
  box-sizing: content-box; /* override global */
}
```

## Poin Penting
- Gunakan `*, *::before, *::after { box-sizing: border-box; }` untuk menerapkan border-box secara global
- Penerapan global menghilangkan perhitungan manual saat menambahkan padding/border pada elemen dengan lebar persentase
- Semua elemen termasuk form inputs akan memiliki perilaku ukuran yang konsisten
- Elemen tertentu dapat di-override kembali ke content-box jika diperlukan secara spesifik
