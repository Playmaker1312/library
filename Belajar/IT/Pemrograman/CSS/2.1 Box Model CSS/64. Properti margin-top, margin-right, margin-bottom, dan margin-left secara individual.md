# Properti margin-top, margin-right, margin-bottom, dan margin-left secara individual

## Analogi: Perpustakaan Digital

Seperti mengatur jarak setiap sisi buku secara terpisah di rak, properti margin individual memberikan kontrol presisi pada setiap sisi elemen. Mungkin sisi kiri buku perlu jarak lebih karena dekat dengan sekat rak, atau sisi bawah perlu jarak ekstra untuk label. Dalam perpustakaan digital, kita dapat mengatur margin setiap sisi sesuai kebutuhan spesifik.

## Penjelasan Detail

Properti margin individual terdiri dari margin-top, margin-right, margin-bottom, dan margin-left yang masing-masing mengatur margin pada satu sisi tertentu. Properti ini berguna ketika hanya satu atau beberapa sisi yang perlu dimodifikasi, menghindari penimpaan nilai dari shorthand. Nilai yang dapat digunakan meliputi satuan panjang (px, em, rem), persentase, auto, dan nilai negatif. margin-top dan margin-bottom adalah properti yang terlibat dalam fenomena margin collapsing. margin-left dan margin-right dengan nilai auto digunakan untuk distribusi ruang dalam flexbox dan sentrasi horizontal. Properti individual sangat berguna dalam komponen yang memerlukan margin asimetris, seperti sidebar yang membutuhkan margin kiri untuk indentasi.

## Contoh Kode Implementasi

```css
/* Margin individual */
.custom-spacing {
  margin-top: 20px;
  margin-right: 15px;
  margin-bottom: 25px;
  margin-left: 10px;
  border: 1px solid #333;
}

/* Heading dengan margin bawah untuk jarak */
h1 {
  margin-top: 0;
  margin-bottom: 0.5em;
}

h2 {
  margin-top: 1.5em;
  margin-bottom: 0.5em;
}

/* Paragraf dengan margin */
p {
  margin-top: 0;
  margin-bottom: 1em;
}

/* Sentrasi horizontal dengan margin-left dan margin-right */
.centered-item {
  width: 200px;
  margin-left: auto;
  margin-right: auto;
}

/* Margin kiri untuk indentasi */
.indented {
  margin-left: 2em;
}

/* Margin negatif per sisi */
.overlap-left {
  margin-left: -20px;
}

/* Mengganti hanya margin-top */
.component {
  margin: 20px;
}

.component.featured {
  margin-top: 40px; /* override hanya margin atas */
}

/* Sidebar dengan margin */
.sidebar {
  margin-right: 30px;
  margin-bottom: 20px;
}

/* Reset margin */
.no-margin {
  margin-top: 0;
  margin-right: 0;
  margin-bottom: 0;
  margin-left: 0;
}
```

## Poin Penting
- margin-top, margin-right, margin-bottom, margin-left mengontrol margin pada masing-masing sisi secara terpisah
- margin-top dan margin-bottom terlibat dalam fenomena margin collapsing antar elemen vertikal
- margin-left dan margin-right auto berguna untuk sentrasi horizontal dan distribusi ruang pada flexbox
- Gunakan properti individual untuk menghindari penimpaan saat hanya satu sisi yang perlu diubah
