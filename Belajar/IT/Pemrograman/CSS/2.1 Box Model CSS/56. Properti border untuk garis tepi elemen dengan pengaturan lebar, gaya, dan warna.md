# Properti border untuk garis tepi elemen dengan pengaturan lebar, gaya, dan warna

## Analogi: Perpustakaan Digital

Border seperti bingkai foto atau sampul buku yang membungkus isi sebuah elemen. Sama seperti buku yang memiliki sampul dengan ketebalan, tekstur, dan warna tertentu, elemen web juga dapat diberi garis tepi yang bervariasi. Sebuah buku dengan sampul tebal dan berwarna akan menonjol di rak, sama seperti border yang menarik perhatian pada elemen tertentu.

## Penjelasan Detail

Border adalah garis yang mengelilingi padding dan konten elemen. Setiap border memiliki tiga aspek yang dapat diatur: lebar (width), gaya (style), dan warna (color). Lebar border menentukan ketebalan garis, gaya border menentukan tampilan garis seperti solid atau dashed, dan warna border menentukan warna garis tersebut. Border dapat diatur secara individual untuk setiap sisi atau menggunakan shorthand. Border mempengaruhi ukuran total elemen dalam box model. Border juga dapat dikombinasikan dengan border-radius untuk membuat sudut melengkung. Berbeda dengan outline, border termasuk dalam perhitungan box model dan mempengaruhi tata letak elemen di sekitarnya. Border dapat digunakan untuk berbagai tujuan seperti dekorasi, pemisah, indikasi status, atau fokus pada elemen.

## Contoh Kode Implementasi

```css
/* Border sederhana */
.box {
  border: 2px solid #333;
}

/* Border dengan ketebalan berbeda per sisi */
.custom-border {
  border-top-width: 1px;
  border-right-width: 3px;
  border-bottom-width: 5px;
  border-left-width: 1px;
  border-style: solid;
  border-color: #007bff;
}

/* Border bawah saja untuk efek garis bawah */
.underline-effect {
  border-bottom: 3px solid #e74c3c;
  padding-bottom: 5px;
}

/* Border dengan gaya dashed */
.dashed-border {
  border: 2px dashed #95a5a6;
  padding: 15px;
}

/* Border ganda */
.double-border {
  border: 4px double #2c3e50;
  padding: 10px;
}

/* Border dekoratif */
.fancy-border {
  border: 1px solid #ddd;
  border-left: 5px solid #3498db;
  padding: 15px;
}

/* Border dengan warna berbeda per sisi */
.colored-border {
  border-style: solid;
  border-width: 2px;
  border-color: #e74c3c #3498db #2ecc71 #f39c12;
}
```

## Poin Penting
- Border memiliki tiga properti utama: border-width, border-style, dan border-color yang dapat diatur bersama atau terpisah
- Border termasuk dalam perhitungan box model dan mempengaruhi ukuran total serta tata letak elemen
- Setiap sisi border dapat diatur secara independen dengan properti seperti border-top, border-right, dll.
- Border berbeda dengan outline karena border mempengaruhi tata letak dan termasuk dalam area klik elemen
