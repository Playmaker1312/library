# Shorthand margin dengan satu, dua, tiga, dan empat nilai sekaligus

## Analogi: Perpustakaan Digital

Shorthand margin seperti memberikan instruksi jarak antar buku dalam satu kalimat lengkap. Daripada mengatakan "beri jarak 10px di atas, 20px di kanan, 30px di bawah, dan 15px di kiri", kita cukup mengatakan "margin 10px 20px 30px 15px". Ini menghemat waktu dan mengurangi kemungkinan kesalahan seperti halnya instruksi singkat pada petugas perpustakaan.

## Penjelasan Detail

Shorthand margin menggabungkan margin-top, margin-right, margin-bottom, dan margin-left dalam satu deklarasi. Dengan satu nilai, margin diterapkan ke semua sisi. Dengan dua nilai, nilai pertama untuk margin atas dan bawah, nilai kedua untuk margin kanan dan kiri. Dengan tiga nilai, nilai pertama untuk atas, nilai kedua untuk kanan dan kiri, nilai ketiga untuk bawah. Dengan empat nilai, urutannya adalah atas, kanan, bawah, kiri (searah jarum jam). Shorthand margin dapat menggunakan berbagai satuan termasuk px, em, rem, persentase, dan auto. Nilai negatif juga diperbolehkan. Shorthand ini sangat berguna untuk menulis kode yang lebih bersih dan mengurangi pengulangan. Pola yang sama berlaku untuk shorthand padding.

## Contoh Kode Implementasi

```css
/* Satu nilai: margin 20px di semua sisi */
.equal-margin {
  margin: 20px;
}

/* Dua nilai: atas-bawah 10px, kanan-kiri 30px */
.vertical-horizontal-margin {
  margin: 10px 30px;
}

/* Tiga nilai: atas 5px, kanan-kiri 15px, bawah 25px */
.three-value-margin {
  margin: 5px 15px 25px;
}

/* Empat nilai: atas 10px, kanan 20px, bawah 30px, kiri 40px */
.four-value-margin {
  margin: 10px 20px 30px 40px;
}

/* Margin auto untuk sentrasi horizontal */
.centered {
  width: 60%;
  margin: 20px auto;
}

/* Margin dengan campuran auto dan nilai tetap */
.header {
  margin: 0 auto 20px;
  width: 80%;
}

/* Margin negatif */
.overlap-element {
  margin: -10px -20px -10px -20px;
}

/* Margin untuk layout */
.container > .item {
  margin: 0 10px 20px;
}

/* Reset margin pada heading */
h1, h2, h3 {
  margin: 0 0 1em;
}

/* Margin dengan satuan em */
.text-margin {
  margin: 1em 0 1.5em;
}
```

## Poin Penting
- Satu nilai: semua sisi; dua nilai: vertikal dan horizontal; tiga nilai: atas, horizontal, bawah; empat nilai: atas, kanan, bawah, kiri
- Shorthand margin mengikuti pola searah jarum jam yang sama dengan shorthand padding dan border-width
- Nilai auto dapat digunakan dalam shorthand untuk sentrasi horizontal pada elemen block
- Margin negatif diperbolehkan dan berguna untuk efek overlap atau koreksi posisi
