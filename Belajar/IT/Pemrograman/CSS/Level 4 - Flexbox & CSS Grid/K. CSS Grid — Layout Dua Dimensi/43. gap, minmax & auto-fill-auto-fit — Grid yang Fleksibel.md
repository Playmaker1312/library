# 43. gap, minmax & auto-fill/auto-fit — Grid yang Fleksibel

## Penjelasan

- **`gap`**: jarak antar grid items (sama seperti di flexbox)
- **`minmax()`**: ukuran kolom antara minimum dan maksimum
- **`auto-fill`/`auto-fit`**: buat kolom sebanyak mungkin dalam container

```css
/* GRID SANGAT RESPONSIF — tanpa media query! */
.projects-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: var(--space-6);
}
```

## Fungsi

- **minmax**: kolom tidak lebih kecil dari X, tidak lebih besar dari Y
- **auto-fill/auto-fit**: grid yang otomatis menyesuaikan jumlah kolom dengan lebar container

## Cara Pengimplementasian

```css
/* Responsif otomatis — magic! */
.projects-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: var(--space-6);
}
/* 280px = minimum lebar card. Jika layar 1200px → 4 kolom. 900px → 3 kolom. 600px → 2 kolom. 300px → 1 kolom. */

/* auto-fill vs auto-fit */
.auto-fill {
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  /* Tetap buat kolom kosong jika item sedikit */
}

.auto-fit {
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  /* Collapse kolom kosong, item melebar */
}

/* minmax dengan fixed dan fr */
.mixed-grid {
  grid-template-columns: minmax(200px, 250px) minmax(0, 1fr);
  /* sidebar 200-250px, konten mengisi sisa */
}

/* Gap shorthand */
.grid {
  display: grid;
  gap: var(--space-4);          /* row & column sama */
  gap: var(--space-6) var(--space-4);  /* row | column */
  row-gap: var(--space-6);
  column-gap: var(--space-4);
}
```

## Analogi

Seperti **etalase toko dengan rak yang bisa menyesuaikan diri**:
- **minmax(280px, 1fr)** = setiap rak minimal 280px, tapi bisa melebar jika ada ruang
- **auto-fill** = etalase dipasang rak sebanyak mungkin — meskipun barang hanya 3, rak tetap terpasang 5 (ada rak kosong)
- **auto-fit** = rak menyesuaikan dengan jumlah barang — jika hanya 3 barang, 3 rak yang melebar mengisi etalase

## Dipakai Untuk Apa

- Gallery/card grid responsif tanpa media query
- Sidebar dengan lebar minimal
- Layout yang butuh ukuran kolom adaptif

## Kesalahan Umum

- **minmax(280px, 1fr) lupa repeat**: harus `repeat(auto-fill, minmax(...))`, bukan `grid-template-columns: minmax(280px, 1fr)`
- **auto-fill vs auto-fit membingungkan**: auto-fill buat kolom kosong, auto-fit collapse kolom kosong
- **Gap di IE11**: tidak didukung — butuh fallback margin

## Hubungan dengan Materi Sebelumnya

Poin 42: grid dengan kolom fixed (repeat(3, 1fr)). Tapi kurang responsif — di layar kecil tetap 3 kolom. **minmax + auto-fill** membuat grid yang otomatis menyesuaikan dengan lebar layar. Ini adalah teknik CSS favorit — responsif tanpa satu baris media query.

## Soal Latihan

### Soal 1
Tulis CSS untuk grid card yang responsif otomatis dengan minimum 280px per card.

**Jawaban:**
```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
}
```

### Soal 2
Apa perbedaan `auto-fill` dan `auto-fit`?

**Jawaban:**
`auto-fill` — grid tetap membuat kolom (track) sebanyak mungkin, termasuk kolom kosong. `auto-fit` — kolom kosong di-collapse (dihapus), item yang ada melebar mengisi ruang.

### Soal 3
Apa fungsi `minmax(250px, 1fr)`?

**Jawaban:**
Kolom memiliki lebar minimum 250px dan maksimum 1fr (mengisi sisa ruang). Jadi kolom tidak akan lebih sempit dari 250px, tapi bisa melebar jika ada ruang.
