# 39. align-items & gap — Penyelarasan & Jarak

## Penjelasan

- **`align-items`**: menyelaraskan item di **cross axis** (sumbu silang — tegak lurus main axis)
- **`gap`**: jarak antar item (pengganti margin individu)

```css
.container {
  display: flex;
  align-items: stretch;     /* default: item setinggi container */
  align-items: flex-start;  /* ke atas */
  align-items: flex-end;    /* ke bawah */
  align-items: center;      /* ke tengah (vertikal) */
  align-items: baseline;    /* sejajar berdasarkan baseline teks */
  
  gap: var(--space-4);      /* jarak antar item */
}
```

## Fungsi

- **align-items**: menyelaraskan item di sumbu silang — penting untuk centering vertikal
- **gap**: jarak konsisten antar flex items — tanpa margin manual

## Cara Pengimplementasian

```css
/* Centering vertikal + horizontal */
.hero {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

/* Nav — semua item center vertikal */
.main-nav {
  display: flex;
  align-items: center;
  gap: var(--space-6);
}

/* Card row — semua card sama tinggi */
.card-row {
  display: flex;
  gap: var(--space-6);
}

.card-row > * {
  flex: 1;
  display: flex;
  flex-direction: column;
}

/* Gap — lebih bersih dari margin */
/* ❌ Lama: .item + .item { margin-left: 16px; } */
/* ✅ Baru: .container { gap: 16px; } */

/* Gap di grid juga berfungsi */
.grid {
  display: grid;
  gap: var(--space-6);
}
```

## Analogi

- **align-items: center** = buku-buku di rak diatur **rata tengah** secara vertikal — tidak ada yang lebih tinggi atau lebih rendah, semuanya center
- **align-items: stretch** = buku dipaksa **meregang** setinggi rak — seperti buku besar dan kecil dipaksa sama tinggi
- **gap** = **sekat antar buku** di rak — jarak yang konsisten tanpa harus atur margin setiap buku

## Dipakai Untuk Apa

- **align-items: center** — centering vertikal (hero, nav items, tombol)
- **align-items: stretch** — card dengan tinggi sama di row
- **gap** — semua layout flex/grid — jarak konsisten

## Kesalahan Umum

- **align-items dan justify-content tertukar**: justify = main axis, align = cross axis
- **align-items dengan flex-direction: column**: cross axis jadi horizontal — center berarti horizontal
- **Gap tidak didukung di browser lama**: fallback dengan margin untuk IE — tapi sudah aman di 2024+

## Hubungan dengan Materi Sebelumnya

Poin 38: justify-content mendistribusi item di **main axis**. **align-items** melengkapinya di **cross axis**. Bersama-sama, mereka memberikan kontrol penuh atas posisi item. **gap** adalah modern addition yang membersihkan kode dari margin-item-pertama/last-child trick.

## Soal Latihan

### Soal 1
Tulis CSS untuk menengahkan konten secara vertikal dan horizontal.

**Jawaban:**
```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

### Soal 2
Apa fungsi `gap` di flexbox?

**Jawaban:**
Memberi jarak antar flex items tanpa perlu margin manual. Sama dengan `gap` di grid. Tidak perlu `margin-left` atau `:not(:last-child)` hack.

### Soal 3
Jika `flex-direction: column`, ke mana arah `align-items`?

**Jawaban:**
Cross axis jadi horizontal — `align-items` mengontrol perataan **horizontal** (kiri-tengah-kanan).
