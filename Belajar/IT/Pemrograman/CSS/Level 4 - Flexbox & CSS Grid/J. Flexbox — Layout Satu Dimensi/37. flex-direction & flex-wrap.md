# 37. flex-direction & flex-wrap

## Penjelasan

- **`flex-direction`**: menentukan arah sumbu utama — baris atau kolom
- **`flex-wrap`**: apakah item boleh pindah ke baris berikutnya jika tidak muat

```css
.flex-container {
  display: flex;
  flex-direction: row;        /* default: kiri ke kanan */
  flex-direction: column;     /* atas ke bawah */
  flex-direction: row-reverse;    /* kanan ke kiri */
  flex-direction: column-reverse; /* bawah ke atas */
  
  flex-wrap: nowrap;    /* default: semua di satu baris */
  flex-wrap: wrap;      /* pindah baris jika tidak muat */
}
```

## Fungsi

- **flex-direction**: mengubah arah layout — horizontal atau vertikal
- **flex-wrap**: mencegah overflow dengan membungkus item ke baris baru

## Cara Pengimplementasian

```css
/* Navigasi horizontal */
.main-nav {
  display: flex;
  flex-direction: row;
  align-items: center;
  justify-content: space-between;
}

/* Card column layout */
.card {
  display: flex;
  flex-direction: column;
  height: 100%;
}

.card-content {
  flex: 1; /* isi mengembang ke bawah */
}

.card-footer {
  margin-top: auto; /* footer di bawah */
}

/* Gallery dengan wrap */
.gallery {
  display: flex;
  flex-wrap: wrap;
  gap: var(--space-4);
}

.gallery-item {
  flex: 1 1 250px; /* tumbuh, menyusut, basis 250px */
}

/* Responsive tanpa media query */
.card-row {
  display: flex;
  flex-wrap: wrap;
  gap: var(--space-6);
}

.card-row > * {
  flex: 1 1 var(--card-min-width, 280px);
}
```

## Analogi

- **flex-direction: row** = rak piring biasa — piring berjajar horizontal
- **flex-direction: column** = rak gelas — gelas bertumpuk vertikal
- **flex-wrap: nowrap** = rak piring super panjang — semua piring dipaksa dalam satu baris, bisa tumpah (overflow)
- **flex-wrap: wrap** = rak dengan pembatas — jika piring sudah penuh, piring baru turun ke baris berikutnya

Di rumah, kamu pasti pilih rak yang bisa wrap — daripada piring bertumpuk tak karuan.

## Dipakai Untuk Apa

- **row**: navigasi, tombol sejajar, badge row
- **column**: card (image atas, judul tengah, footer bawah), form vertikal
- **wrap**: gallery, card grid, tag list

## Kesalahan Umum

- **flex-direction: column + align-items: center**: align-items di column mengontrol horizontal (cross axis jadi horizontal) — sering terbalik
- **Flex-wrap: nowrap default**: item bisa menyusut di luar keinginan — set `flex-wrap: wrap` untuk gallery
- **flex-direction: column tanpa height**: item tidak tahu harus ke mana — tidak ada scroll vertikal otomatis

## Hubungan dengan Materi Sebelumnya

Poin 36: flexbox diaktifkan. Tapi kemanakah arah item? **flex-direction** menjawab — horizontal (row) atau vertikal (column). Dan **flex-wrap** mengontrol apakah item stay di satu baris atau turun ke bawah.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat card dengan layout vertikal (image, title, description, footer di bawah).

**Jawaban:**
```css
.card {
  display: flex;
  flex-direction: column;
  height: 100%;
}
```

### Soal 2
Apa perbedaan `nowrap` dan `wrap`?

**Jawaban:**
`nowrap` — semua item di satu baris, item bisa menyusut atau overflow. `wrap` — item pindah ke baris berikutnya jika tidak muat.

### Soal 3
Jika `flex-direction: column`, ke mana arah `justify-content`?

**Jawaban:**
`justify-content` mengikuti main axis. Jika `flex-direction: column`, main axis adalah vertikal — `justify-content` mengontrol distribusi vertikal (atas-bawah).
