# GPU Compositing Layer untuk Animasi

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki papan tulis transparan yang bisa digeser di atas halaman. Menggeser papan ini terasa mulus karena papan berada di "lapisan" sendiri, terpisah dari halaman di belakangnya. Saat papan digeser, hanya papan itu yang bergerak—halaman di belakang tetap diam tanpa perlu digambar ulang. Inilah prinsip GPU compositing layer: elemen ditempatkan di lapisan terpisah yang bisa dimanipulasi secara independen, menghasilkan animasi yang jauh lebih mulus.

## Penjelasan Detail

GPU compositing layer adalah teknik rendering di mana browser memisahkan elemen tertentu ke lapisan (layer) terpisah yang dirender dan dikomposisikan oleh GPU. Properti tertentu, terutama `transform` dan `opacity`, dapat dianimasikan hanya dengan mengomposisi ulang layer yang sudah dirender tanpa perlu menggambar ulang atau menghitung tata letak ulang. Ini sangat efisien karena operasi komposisi GPU sangat cepat. Properti yang memicu compositing layer antara lain `transform: translateZ(0)`, `will-change: transform`, `opacity`, `filter`, `backface-visibility: hidden`, dan `position: fixed`. Membuat terlalu banyak layer juga bisa menghabiskan memori GPU—ada trade-off antara kelancaran animasi dan penggunaan memori. Memahami compositing layer membantu pengembang memilih properti yang tepat untuk animasi performa tinggi.

## Contoh Kode Implementasi

```css
/* Memicu GPU compositing layer */
.card {
  transform: translateZ(0);
  /* atau */
  /* will-change: transform; */
}

/* Animasi transform — hanya komposisi, tidak ada layout/paint */
.smooth-animation {
  transition: transform 0.3s ease;
  will-change: transform;
}

.smooth-animation:hover {
  transform: translateX(100px) scale(1.1);
}

/* Animasi opacity — juga hanya komposisi */
.fade-layer {
  transition: opacity 0.5s ease;
  will-change: opacity;
}

/* Hindari animasi properti layout */
/* JANGAN: animasi margin, padding, width, height */
/* JANGAN: animasi top, left, right, bottom */

/* Bandingkan: properti layout vs compositing */
.bad-animation {
  transition: margin-left 0.3s;
  /* Memicu layout → mahal */
}

.good-animation {
  transition: transform 0.3s;
  /* Hanya komposisi → murah */
}

/* Fallback untuk hardware acceleration */
.hw-accelerated {
  transform: translateZ(0);
  backface-visibility: hidden;
  perspective: 1000px;
}
```

## Poin Penting
- GPU compositing layer memisahkan elemen ke lapisan yang dirender dan dikomposisi secara independen.
- Properti `transform` dan `opacity` hanya memicu komposisi, bukan layout atau paint.
- Hindari menganimasi properti layout (margin, padding, width, height, top, left) untuk performa lebih baik.
- `transform: translateZ(0)` atau `will-change` memicu pembuatan compositing layer.
- Terlalu banyak layer menghabiskan memori GPU—gunakan secara bijak.
