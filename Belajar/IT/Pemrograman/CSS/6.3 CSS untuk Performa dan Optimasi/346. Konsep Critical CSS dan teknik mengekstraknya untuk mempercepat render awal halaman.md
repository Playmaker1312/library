# Critical CSS untuk Render Awal

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang memuat ribuan buku sebelum menampilkan halaman utama. Pengunjung akan menunggu lama hanya untuk melihat judul dan logo. Solusinya: tampilkan dulu elemen paling penting—logo, judul, navigasi utama—sementara buku lainnya dimuat di latar belakang. Inilah prinsip Critical CSS: hanya memuat gaya yang diperlukan untuk merender bagian atas halaman (above the fold) terlebih dahulu.

## Penjelasan Detail

Critical CSS adalah teknik optimasi yang mengekstrak dan menyematkan gaya CSS yang diperlukan untuk merender konten "above the fold" (bagian halaman yang terlihat tanpa scroll) langsung di dalam `<head>` HTML. Gaya ini dimuat secara inline dalam tag `<style>`, sehingga browser tidak perlu menunggu file CSS eksternal yang besar untuk mulai merender halaman. Sisa CSS (non-critical) dimuat secara asinkron setelah konten utama selesai dirender. Manfaat utama Critical CSS adalah mengurangi waktu render awal (First Contentful Paint) dan meningkatkan pengalaman pengguna, terutama di koneksi lambat. Tools seperti Critical, PurgeCSS, atau WordPress plugin dapat membantu mengekstrak Critical CSS secara otomatis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html>
<head>
  <style>
    /* Critical CSS — inline di head */
    * { box-sizing: border-box; margin: 0; padding: 0; }
    body { font-family: system-ui, sans-serif; color: #333; }
    .header { 
      display: flex; 
      justify-content: space-between; 
      padding: 1rem; 
      background: #2c3e50; 
      color: white; 
    }
    .hero { 
      padding: 4rem 2rem; 
      text-align: center; 
      background: linear-gradient(135deg, #667eea, #764ba2); 
      color: white; 
    }
    .hero h1 { font-size: 2.5rem; margin-bottom: 1rem; }
    .hero p { font-size: 1.25rem; }
  </style>
  <!-- Non-critical CSS dimuat asinkron -->
  <link rel="preload" href="styles.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
  <noscript><link rel="stylesheet" href="styles.css"></noscript>
</head>
<body>
  <header class="header"><!-- konten header --></header>
  <section class="hero"><!-- konten hero --></section>
</body>
</html>
```

## Poin Penting
- Critical CSS hanya mencakup gaya untuk konten "above the fold" yang terlihat tanpa scroll.
- Sematkan Critical CSS inline di `<head>` untuk render instan tanpa blocking.
- Muat CSS non-critical secara asinkron agar tidak memblokir render awal.
- Tools seperti Critical dan PurgeCSS dapat mengekstrak Critical CSS secara otomatis.
- Teknik ini secara signifikan meningkatkan First Contentful Paint (FCP) dan pengalaman pengguna.
