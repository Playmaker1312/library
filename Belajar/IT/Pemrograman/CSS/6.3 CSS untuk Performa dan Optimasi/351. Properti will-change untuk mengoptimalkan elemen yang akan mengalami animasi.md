# Properti will-change untuk Optimasi Animasi

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki rak buku yang bisa digeser oleh pengunjung. Tanpa persiapan, saat pengunjung mulai menggeser, sistem harus menyiapkan semua sumber daya yang diperlukan secara mendadak, menyebabkan tersendat. Dengan memberi tahu sistem sebelumnya "rak ini akan digeser", sistem dapat mempersiapkan sumber daya terlebih dahulu sehingga perpindahan terasa mulus. `will-change` dalam CSS memberi tahu browser tentang properti yang akan berubah, memungkinkan browser melakukan optimasi sebelum perubahan terjadi.

## Penjelasan Detail

Properti `will-change` memberi petunjuk kepada browser bahwa suatu elemen akan mengalami perubahan pada properti tertentu, sehingga browser dapat melakukan optimasi yang diperlukan sebelumnya. Nilai yang umum: `transform`, `opacity`, `top`, `left`, `right`, `bottom`, `filter`, `clip-path`, atau kata kunci `auto` (default). Browser dapat mempersiapkan GPU acceleration atau membuat layer komposisi baru untuk elemen tersebut, menghasilkan animasi yang lebih mulus. Namun, penggunaan `will-change` yang berlebihan justru dapat menurunkan performa karena membuat terlalu banyak layer. Gunakan secara selektif hanya untuk elemen yang benar-benar akan dianimasikan, dan idealnya atur nilainya sebelum animasi dimulai dan hapus setelah selesai menggunakan JavaScript.

## Contoh Kode Implementasi

```css
/* Optimasi untuk elemen yang akan ditransformasi */
.animated-element {
  will-change: transform;
  transition: transform 0.3s ease;
}

.animated-element:hover {
  transform: scale(1.1);
}

/* Optimasi untuk opacity */
.fade-element {
  will-change: opacity;
  transition: opacity 0.5s ease;
}

/* Beberapa properti */
.complex-animation {
  will-change: transform, opacity;
  transition: transform 0.3s, opacity 0.3s;
}

/* Penggunaan dengan JavaScript */
const element = document.querySelector('.modal');
element.addEventListener('mouseenter', () => {
  element.style.willChange = 'transform';
});
element.addEventListener('animationend', () => {
  element.style.willChange = 'auto';
});

/* Scroll-linked animation */
.scroll-fade {
  will-change: transform, opacity;
}

/* Hanya untuk GPU-accelerated properties */
.gpu-accelerated {
  will-change: transform;
  opacity: 0.9;
}
```

## Poin Penting
- `will-change` memberi tahu browser untuk mengoptimasi properti yang akan berubah.
- Paling efektif untuk properti `transform` dan `opacity` yang bisa di-akselerasi GPU.
- Gunakan secara selektif—terlalu banyak `will-change` justru menurunkan performa.
- Setel `will-change` sebelum animasi dimulai, hapus setelah animasi selesai.
- Hindari menggunakan pada terlalu banyak elemen sekaligus.
