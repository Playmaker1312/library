# Memuat CSS Non-Kritis Secara Asinkron

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin menampilkan halaman utama secepat mungkin. Daripada menunggu semua buku di rak belakang dimuat, perpustakaan menampilkan dulu buku-buku di rak depan yang terlihat oleh pengunjung. Buku di rak belakang (yang belum terlihat) dimuat secara diam-diam di latar belakang. CSS non-kritis adalah "buku di rak belakang"—gaya untuk konten yang tidak langsung terlihat, yang bisa dimuat tanpa memblokir render halaman.

## Penjelasan Detail

Secara default, file CSS eksternal yang dimuat dengan `<link rel="stylesheet">` bersifat render-blocking—browser akan menunggu file CSS selesai diunduh sebelum merender halaman. Untuk CSS non-kritis, kita bisa menggunakan teknik asinkron dengan memanfaatkan atribut `media="print"` dan `onload`, atau menggunakan `rel="preload"` dengan `onload` untuk mengubahnya menjadi stylesheet. Teknik yang paling umum adalah menggunakan `rel="preload"` dengan `as="style"` dan event `onload` untuk mengubahnya menjadi stylesheet biasa. Alternatif lain adalah menggunakan JavaScript untuk menyisipkan tag `<link>` secara dinamis setelah halaman dimuat. Pendekatan ini memastikan CSS non-kritis tidak memblokir render awal, meningkatkan performa yang dirasakan.

## Contoh Kode Implementasi

```html
<!-- Teknik 1: preload dengan onload -->
<link rel="preload" href="styles-non-critical.css" as="style" 
      onload="this.onload=null;this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="styles-non-critical.css"></noscript>

<!-- Teknik 2: media="print" (hanya untuk printer) lalu diubah -->
<link rel="stylesheet" href="styles-non-critical.css" media="print" 
      onload="this.media='all'">
<noscript><link rel="stylesheet" href="styles-non-critical.css"></noscript>

<!-- Teknik 3: JavaScript dinamis -->
<script>
  var link = document.createElement('link');
  link.rel = 'stylesheet';
  link.href = 'styles-non-critical.css';
  document.head.appendChild(link);
</script>

<!-- Teknik 4: loadCSS library untuk dukungan browser lama -->
<script>
  loadCSS('styles-non-critical.css');
</script>
```

## Poin Penting
- CSS non-kritis adalah gaya untuk konten di bawah lipatan atau yang tidak segera terlihat.
- Gunakan `rel="preload"` dengan `onload` untuk memuat stylesheet secara asinkron.
- Sediakan fallback `<noscript>` untuk pengguna dengan JavaScript nonaktif.
- Teknik ini mengurangi waktu render blocking dan meningkatkan First Contentful Paint.
- Pastikan hanya CSS non-kritis yang dimuat secara asinkron—Critical CSS harus tetap sinkron.
