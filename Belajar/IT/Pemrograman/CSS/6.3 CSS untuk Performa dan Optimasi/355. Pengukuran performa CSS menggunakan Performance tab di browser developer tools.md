# Mengukur Performa CSS dengan Browser DevTools

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin tahu mengapa halamannya lambat. Apakah karena terlalu banyak buku yang dimuat? Atau karena raknya terlalu rumit? Dengan alat pemantau kinerja, pustakawan bisa merekam aktivitas halaman dan melihat persis apa yang memakan waktu—berapa lama rendering, berapa lama layout, dan elemen mana yang paling lambat. Performance tab di browser DevTools adalah alat pemantau kinerja untuk halaman web.

## Penjelasan Detail

Performance tab di browser developer tools (Chrome DevTools, Firefox DevTools) memungkinkan kita merekam dan menganalisis aktivitas rendering halaman. Untuk mengukur performa CSS, kita bisa merekam sesi interaksi (scroll, klik, animasi) dan menganalisis flame chart yang dihasilkan. Metrik kunci yang perlu diperhatikan: waktu yang dihabiskan untuk Layout (perhitungan posisi/ukuran), Paint (penggambaran piksel), dan Composite (penggabungan layer). Kita juga bisa menggunakan fitur "Rendering" tab untuk menampilkan Layout Shift Regions, Paint Flashing, dan Layer Borders untuk debugging visual. Tools khusus CSS seperti CSS Overview (di Chrome) memberikan ringkasan statistik CSS seperti jumlah selector, warna yang digunakan, dan media queries. Audit dengan Lighthouse juga memberikan rekomendasi performa CSS spesifik.

## Contoh Kode Implementasi

```css
/* Tidak ada kode khusus — ini tentang penggunaan tools browser */

/*
Langkah-langkah mengukur performa CSS:

1. Buka DevTools → Performance tab
2. Klik tombol Record (lingkaran merah)
3. Lakukan interaksi: scroll halaman, klik tombol, jalankan animasi
4. Stop recording
5. Analisis flame chart:
   - Cari "Layout" event — perhatikan durasi dan pemicunya
   - Cari "Paint" event — perhatikan area yang dicat ulang
   - Cari "Composite Layers" — perhatikan penggabungan layer

6. Buka Rendering tab (More tools → Rendering):
   - Paint Flashing: lihat area yang sering dicat ulang
   - Layer Borders: lihat compositing layer yang dibuat
   - Layout Shift Regions: lihat pergeseran tata letak (CLS)

7. Gunakan CSS Overview (Chrome):
   - Lihat jumlah total stylesheet dan aturan CSS
   - Identifikasi warna dan font yang tidak konsisten
   - Temukan media queries yang mungkin tidak diperlukan
*/
```

## Poin Penting
- Performance tab merekam aktivitas rendering: Layout, Paint, Composite.
- Paint Flashing menunjukkan area yang sering digambar ulang (perlu optimasi).
- Layer Borders menunjukkan compositing layer yang aktif.
- CSS Overview memberikan ringkasan statistik CSS untuk audit dan pembersihan.
- Lighthouse memberikan rekomendasi performa CSS otomatis seperti eliminasi CSS tidak terpakai.
