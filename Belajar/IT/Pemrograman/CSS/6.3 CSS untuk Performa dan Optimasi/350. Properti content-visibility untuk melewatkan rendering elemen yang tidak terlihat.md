# Properti content-visibility untuk Render Efisien

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki ribuan buku dalam katalog. Daripada merender sampul semua buku sekaligus—yang akan menghabiskan memori dan waktu—perpustakaan hanya merender sampul buku yang saat ini terlihat di layar. Buku di luar layar baru akan dirender ketika pengguna menggulir ke posisinya. `content-visibility` memungkinkan browser melakukan hal ini pada elemen HTML, melewatkan rendering elemen yang tidak terlihat.

## Penjelasan Detail

Properti `content-visibility` memungkinkan browser melewatkan rendering elemen yang berada di luar viewport, secara dramatis meningkatkan performa halaman dengan banyak konten. Nilai `auto` membuat browser secara otomatis melewatkan rendering elemen yang tidak terlihat—elemen masih mempengaruhi tata letak (ukuran dan ruangnya dihitung), tetapi anak-anaknya tidak dirender hingga elemen mendekati viewport. Nilai `visible` membuat elemen dirender normal. Nilai `hidden` menyembunyikan elemen dan melewatkan renderingnya sepenuhnya. Properti ini paling efektif untuk halaman panjang dengan konten berulang, daftar item, komentar, artikel blog, hasil pencarian, dan feed sosial. `content-visibility` bekerja baik dengan `contain-intrinsic-size` untuk menentukan perkiraan ukuran elemen sebelum dirender.

## Contoh Kode Implementasi

```css
/* Terapkan pada item daftar panjang */
.long-list-item {
  content-visibility: auto;
  contain-intrinsic-size: 100px;
}

/* Artikel dalam feed */
.article-item {
  content-visibility: auto;
  contain-intrinsic-size: 200px;
  /* Ukuran perkiraan agar scrollbar akurat */
}

/* Komentar dalam thread */
.comment {
  content-visibility: auto;
  contain-intrinsic-size: 80px;
}

/* Hasil pencarian */
.search-result {
  content-visibility: auto;
  contain-intrinsic-size: 120px;
}

/* Produk dalam katalog */
.product-card {
  content-visibility: auto;
  contain-intrinsic-size: 350px;
}

/* Sembunyikan konten sepenuhnya */
.hidden-content {
  content-visibility: hidden;
}

/* Fallback untuk browser lama */
.post-content {
  content-visibility: auto;
  contain-intrinsic-size: 500px;
}

@media print {
  .post-content {
    content-visibility: visible;
  }
}
```

## Poin Penting
- `content-visibility: auto` melewatkan rendering elemen di luar viewport.
- Gunakan `contain-intrinsic-size` untuk menentukan perkiraan ukuran agar scrollbar akurat.
- Efektif untuk halaman panjang dengan konten berulang seperti daftar, feed, dan komentar.
- Dapat meningkatkan performa render secara signifikan, terutama di perangkat mobile.
- `content-visibility: hidden` menyembunyikan elemen sepenuhnya tanpa ruang yang terpakai.
