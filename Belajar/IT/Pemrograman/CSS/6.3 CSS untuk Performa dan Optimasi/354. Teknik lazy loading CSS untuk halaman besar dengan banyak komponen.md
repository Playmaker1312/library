# Lazy Loading CSS untuk Halaman Besar

## Analogi: Perpustakaan Digital

Perpustakaan digital yang besar tidak memuat semua buku dari semua lantai saat pengunjung membuka pintu. Sebagai gantinya, buku-buku di lantai dasar dimuat dulu; saat pengunjung naik ke lantai dua, buku-buku di sana baru dimuat. Ini menghemat waktu dan bandwidth awal. Lazy loading CSS menerapkan prinsip yang sama—memuat gaya hanya ketika komponen atau bagian halaman benar-benar diperlukan.

## Penjelasan Detail

Lazy loading CSS adalah teknik memuat file stylesheet hanya ketika komponen terkait diperlukan atau memasuki viewport. Ini sangat berguna untuk halaman besar dengan banyak komponen yang tidak semuanya terlihat sekaligus, seperti dashboard, halaman aplikasi SPA, atau halaman dengan tab/section. Teknik implementasi meliputi: memuat CSS berdasarkan rute (route-based splitting), memuat CSS saat komponen mendekati viewport menggunakan Intersection Observer, atau memuat CSS sebagai respons terhadap interaksi pengguna (misalnya saat membuka modal). Bundler modern seperti webpack dengan Code Splitting dan React.lazy memungkinkan pemisahan CSS per komponen secara otomatis. Teknik ini melengkapi Critical CSS—Critical CSS untuk muatan awal, lazy loading untuk komponen yang tidak langsung terlihat.

## Contoh Kode Implementasi

```html
<!-- Lazy loading manual dengan Intersection Observer -->
<link rel="stylesheet" href="base.css">

<script>
  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        const link = document.createElement('link');
        link.rel = 'stylesheet';
        link.href = entry.target.dataset.css;
        document.head.appendChild(link);
        observer.unobserve(entry.target);
      }
    });
  });

  document.querySelectorAll('[data-css]').forEach(el => observer.observe(el));
</script>

<div data-css="gallery.css">
  <!-- Komponen galeri yang tidak langsung terlihat -->
</div>

<div data-css="comments.css">
  <!-- Bagian komentar di bawah halaman -->
</div>
```

```javascript
// Lazy loading berbasis interaksi
function loadCSS(href) {
  const link = document.createElement('link');
  link.rel = 'stylesheet';
  link.href = href;
  document.head.appendChild(link);
}

document.getElementById('openModal').addEventListener('click', () => {
  loadCSS('modal.css');
  // buka modal
});

// Route-based dengan dynamic import (webpack/Vite)
// import('./Component').then(module => { ... })
// CSS akan dimuat otomatis bersama komponen
```

## Poin Penting
- Lazy loading CSS memuat stylesheet hanya saat komponen diperlukan atau terlihat.
- Gunakan Intersection Observer untuk memuat CSS saat elemen mendekati viewport.
- Load CSS berdasarkan interaksi pengguna (klik, scroll, navigasi tab).
- Bundler modern mendukung code splitting CSS per komponen secara otomatis.
- Kombinasikan dengan Critical CSS untuk hasil optimal: Critical CSS untuk konten awal, lazy loading untuk sisanya.
