# Properti contain untuk Batas Rendering

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki bagian "Anak-Anak" yang terisolasi dari bagian lain. Jika ada perubahan di bagian Anak-Anak—misalnya buku baru ditambahkan—hanya bagian itu yang perlu diperbarui, bukan seluruh halaman perpustakaan. Isolasi ini menghemat sumber daya karena browser tidak perlu menghitung ulang tata letak seluruh halaman. `contain` dalam CSS memberi tahu browser bahwa sebuah elemen dan kontennya independen dari bagian halaman lainnya.

## Penjelasan Detail

Properti `contain` memberi petunjuk kepada browser bahwa subpohon DOM tertentu independen dari halaman lainnya. Ini memungkinkan browser mengoptimalkan rendering dengan membatasi perhitungan ulang hanya pada elemen tersebut. Nilai `layout` mengisolasi tata letak—perubahan dalam elemen tidak mempengaruhi luar. Nilai `paint` mengisolasi area rendering—elemen tidak akan meluap secara visual ke luar batasnya. Nilai `size` membuat elemen tidak bergantung pada ukuran kontennya untuk perhitungan ukuran. Nilai `style` mengisolasi style—perubahan properti yang dapat meluap (seperti counter) tidak memengaruhi luar. Nilai `strict` menggabungkan semua nilai (`layout paint size style`). Nilai `content` menggabungkan `layout paint style` (tanpa `size`). Properti ini penting untuk komponen widget, kartu, sidebar, dan komponen lain yang mandiri.

## Contoh Kode Implementasi

```css
/* Isolasi penuh — tidak ada efek ke luar */
.widget {
  contain: strict;
}

/* Isolasi layout dan paint — ukuran masih tergantung konten */
.card {
  contain: layout paint style;
  /* Sama dengan contain: content */
}

/* Hanya isolasi layout — paling ringan */
.isolated-section {
  contain: layout;
}

/* Isolasi size — ukuran tidak dipengaruhi konten */
.fixed-size-widget {
  contain: size;
  width: 300px;
  height: 200px;
}

/* Komponen yang sering berubah */
.live-update-widget {
  contain: layout paint;
}

/* Aplikasi praktis untuk komponen */
.sidebar {
  contain: layout paint;
}

.modal {
  contain: content;
}

.chat-message {
  contain: layout style;
}

/* Gunakan contain untuk virtual scrolling */
.virtual-list-item {
  contain: layout paint;
  height: 50px;
}
```

## Poin Penting
- `contain` memberi tahu browser bahwa subpohon elemen independen, memungkinkan optimasi rendering.
- Nilai: `layout`, `paint`, `size`, `style`, `strict` (semua), `content` (layout + paint + style).
- `contain: strict` mengisolasi sepenuhnya; `contain: content` tanpa isolasi ukuran.
- Meningkatkan performa pada halaman dengan banyak komponen independen.
- Ideal untuk widget, kartu, daftar virtual, dan komponen yang sering diperbarui.
