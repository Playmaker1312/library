# Gambar responsif menggunakan properti max-width 100 persen pada elemen img

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki koleksi gambar sampul buku dengan berbagai ukuran. Aturan utamanya: gambar tidak boleh lebih lebar dari tempatnya berada. Sebuah gambar sampul akan otomatis mengecil jika rak buku menyempit, tetapi tidak akan pernah melampaui batas raknya. Dengan aturan ini, gambar tetap proporsional dan tidak pernah tumpang tindih dengan elemen lain.

## Penjelasan Detail

Teknik dasar membuat gambar responsif adalah dengan menerapkan `max-width: 100%` dan `height: auto` pada elemen `img`. `max-width: 100%` memastikan gambar tidak pernah melebihi lebar kontainernya. `height: auto` mempertahankan rasio aspek asli gambar ketika lebarnya berubah. Tanpa properti ini, gambar dengan ukuran tetap akan meluber keluar kontainernya di layar kecil dan merusak tata letak. Teknik ini sederhana namun sangat efektif dan merupakan fondasi dari semua teknik gambar responsif lainnya. Untuk gambar latar, properti `background-size: cover` atau `background-size: contain` memberikan efek serupa.

## Contoh Kode Implementasi

```css
/* Teknik dasar gambar responsif */
img {
  max-width: 100%;
  height: auto;
  display: block;
}

/* Untuk gambar dalam container tertentu */
.responsive-image {
  max-width: 100%;
  height: auto;
  display: block;
}

/* Gambar dengan border-radius yang responsif */
.card-image {
  max-width: 100%;
  height: auto;
  display: block;
  border-radius: 8px;
}

/* Gambar full-width (selalu selebar kontainer) */
.full-width-image {
  width: 100%;
  height: auto;
  display: block;
}

/* Gambar dengan rasio aspek tetap */
.aspect-ratio-image {
  max-width: 100%;
  height: auto;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  display: block;
}

/* Gambar responsif dalam grid */
.image-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 1rem;
}

.image-grid img {
  width: 100%;
  height: 200px;
  object-fit: cover;
  border-radius: 4px;
}

/* Gambar latar responsif */
.hero-background {
  width: 100%;
  min-height: 300px;
  background-image: url('hero.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* Media query untuk gambar latar yang berbeda */
@media (min-width: 768px) {
  .hero-background {
    min-height: 500px;
    background-image: url('hero-desktop.jpg');
  }
}

/* Figure dengan caption */
figure {
  margin: 0;
  max-width: 100%;
}

figure img {
  max-width: 100%;
  height: auto;
  display: block;
}

figcaption {
  font-size: 0.875rem;
  color: #666;
  margin-top: 0.5rem;
  text-align: center;
}
```

## Poin Penting
- max-width: 100% mencegah gambar melampaui lebar kontainernya
- height: auto mempertahankan rasio aspek gambar saat lebar berubah
- display: block menghilangkan jarak putih di bawah gambar (inline gap)
- Kombinasikan dengan object-fit untuk kontrol yang lebih baik atas pemotongan gambar
