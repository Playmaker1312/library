# Teknik membuat tabel yang responsif di perangkat mobile

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki katalog buku dalam bentuk tabel dengan kolom: judul, penulis, tahun, rak, dan status. Di layar lebar, tabel ditampilkan normal dengan semua kolom. Di layar ponsel, tabel berubah menjadi kartu per baris, di mana setiap sel menjadi baris dalam kartu dengan label di sampingnya. Pengguna tetap bisa melihat semua informasi, hanya tampilannya yang berbeda.

## Penjelasan Detail

Tabel HTML standar sering menjadi masalah di perangkat mobile karena kolom yang banyak membutuhkan lebar layar yang besar. Ada beberapa teknik untuk membuat tabel responsif. Teknik pertama adalah horizontal scroll di mana tabel tetap utuh tetapi dapat digulir secara horizontal. Teknik kedua adalah mengubah setiap baris tabel menjadi kartu vertikal di layar kecil, di mana setiap sel menjadi baris dengan label. Teknik ketiga adalah menyembunyikan kolom yang kurang penting dan menampilkan yang penting saja. Teknik keempat adalah menggunakan grid CSS untuk mengatur ulang tata letak tabel. Pemilihan teknik tergantung pada jenis data dan kebutuhan pengguna.

## Contoh Kode Implementasi

```css
/* Teknik 1: Horizontal scroll */
.table-wrapper {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  margin: 1rem 0;
  border: 1px solid #e0e0e0;
  border-radius: 8px;
}

.table-wrapper table {
  width: 100%;
  border-collapse: collapse;
  white-space: nowrap;
}

.table-wrapper th,
.table-wrapper td {
  padding: 0.75rem 1rem;
  text-align: left;
  border-bottom: 1px solid #e0e0e0;
}

.table-wrapper th {
  background-color: #f5f5f5;
  font-weight: 600;
  position: sticky;
  top: 0;
}

/* Teknik 2: Mengubah tabel menjadi kartu */
@media (max-width: 768px) {
  /* Sembunyikan header tabel */
  .responsive-table thead {
    display: none;
  }

  .responsive-table tr {
    display: block;
    margin-bottom: 1rem;
    border: 1px solid #e0e0e0;
    border-radius: 8px;
    padding: 0.75rem;
    background: #ffffff;
  }

  .responsive-table td {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 0.5rem 0;
    border-bottom: 1px solid #f0f0f0;
    white-space: normal;
  }

  .responsive-table td:last-child {
    border-bottom: none;
  }

  /* Tambahkan label menggunakan atribut data */
  .responsive-table td::before {
    content: attr(data-label);
    font-weight: 600;
    color: #333;
    margin-right: 1rem;
    flex-shrink: 0;
  }

  .responsive-table td:first-child {
    font-weight: 600;
    font-size: 1.1rem;
  }
}

/* Teknik 3: Grid CSS untuk tabel */
@media (max-width: 768px) {
  .grid-table {
    display: grid;
    grid-template-columns: 1fr;
    gap: 1rem;
  }

  .grid-table .row {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 0.5rem;
    padding: 0.75rem;
    border: 1px solid #e0e0e0;
    border-radius: 8px;
  }

  .grid-table .cell {
    display: flex;
    flex-direction: column;
  }

  .grid-table .cell-label {
    font-weight: 600;
    font-size: 0.75rem;
    text-transform: uppercase;
    color: #666;
    margin-bottom: 0.25rem;
  }
}

/* Teknik 4: Prioritas kolom */
@media (max-width: 600px) {
  .priority-table th:nth-child(4),
  .priority-table td:nth-child(4),
  .priority-table th:nth-child(5),
  .priority-table td:nth-child(5) {
    display: none;
  }
}

@media (max-width: 480px) {
  .priority-table th:nth-child(3),
  .priority-table td:nth-child(3) {
    display: none;
  }
}
```

## Poin Penting
- Horizontal scroll adalah solusi cepat untuk tabel dengan banyak kolom
- Teknik kartu (card) memberikan keterbacaan terbaik di layar kecil
- Gunakan atribut data-label untuk menampilkan label sel di mode kartu
- Pertimbangkan prioritas kolom: tampilkan kolom terpenting, sembunyikan yang kurang penting
