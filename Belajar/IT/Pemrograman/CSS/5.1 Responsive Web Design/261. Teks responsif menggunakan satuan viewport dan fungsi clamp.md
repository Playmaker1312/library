# Teks responsif menggunakan satuan viewport dan fungsi clamp

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin judul buku selalu terbaca dengan nyaman di semua perangkat. Di layar lebar, judul berukuran besar dan megah. Di layar kecil, judul mengecil secara proporsional tetapi tidak boleh terlalu kecil hingga sulit dibaca. Ukuran huruf bergerak secara dinamis mengikuti lebar layar, tetapi tetap dalam batas minimal dan maksimal yang nyaman.

## Penjelasan Detail

Teks responsif adalah teknik mengatur ukuran font agar beradaptasi dengan ukuran viewport. Satuan viewport seperti `vw` (viewport width) memungkinkan ukuran font berubah secara proporsional dengan lebar layar. Namun, menggunakan `vw` saja berisiko: teks bisa terlalu kecil di layar ponsel atau terlalu besar di layar lebar. Fungsi `clamp()` mengatasi masalah ini dengan mendefinisikan tiga nilai: nilai minimal, nilai ideal (yang bisa berupa rumus), dan nilai maksimal. `clamp(1rem, 2.5vw, 3rem)` berarti font tidak akan lebih kecil dari 1rem, tidak akan lebih besar dari 3rem, dan akan mengikuti 2.5vw di antaranya. Kombinasi `clamp()` dengan satuan viewport dan satuan relatif menghasilkan fluid typography yang sempurna.

## Contoh Kode Implementasi

```css
/* Fluid typography dengan clamp() */
h1 {
  font-size: clamp(1.75rem, 4vw + 1rem, 3.5rem);
  line-height: 1.2;
}

h2 {
  font-size: clamp(1.5rem, 3vw + 0.75rem, 2.5rem);
  line-height: 1.3;
}

h3 {
  font-size: clamp(1.25rem, 2vw + 0.5rem, 2rem);
  line-height: 1.4;
}

p {
  font-size: clamp(1rem, 1vw + 0.5rem, 1.25rem);
  line-height: 1.6;
}

/* Alternatif: hanya menggunakan vw (kurang aman) */
.hero-title {
  font-size: 5vw;
  /* Berisiko: 5vw di layar 320px = 16px,
     di layar 1920px = 96px (terlalu besar) */
}

/* Lebih aman dengan clamp */
.hero-title {
  font-size: clamp(2rem, 5vw, 5rem);
}

/* Rumus fluid typography yang presisi */
/* target: 16px - 24px, viewport: 320px - 1200px */
/* slope = (24 - 16) / (1200 - 320) = 8 / 880 = 0.00909 */
/* intercept = 16 - 0.00909 * 320 = 13.09 */
/* font-size: clamp(1rem, 0.909vw + 0.818rem, 1.5rem); */

.fluid-text {
  font-size: clamp(1rem, 0.909vw + 0.818rem, 1.5rem);
}

/* Ukuran font responsif untuk berbagai elemen */
.small-text {
  font-size: clamp(0.75rem, 0.5vw + 0.5rem, 0.875rem);
}

.meta-text {
  font-size: clamp(0.8rem, 0.8vw + 0.4rem, 0.9rem);
  color: #666;
}

/* Line-height juga bisa responsif */
.article-body {
  font-size: clamp(1rem, 1vw + 0.5rem, 1.25rem);
  line-height: clamp(1.5, 0.5vw + 1.3, 1.8);
}

/* Padding responsif dengan clamp */
.section {
  padding: clamp(2rem, 5vw, 5rem) clamp(1rem, 3vw, 3rem);
}
```

## Poin Penting
- clamp(min, ideal, max) membatasi ukuran font dalam rentang aman
- Satuan vw membuat ukuran font proporsional dengan lebar viewport
- Kombinasi vw dengan rem dalam rumus clamp menghasilkan transisi yang halus
- Fluid typography menghilangkan kebutuhan breakpoint untuk perubahan ukuran font
