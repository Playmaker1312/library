# Media feature width dan height untuk kondisi berdasarkan ukuran viewport

## Analogi: Perpustakaan Digital

Perpustakaan digital menyesuaikan tampilan rak buku berdasarkan lebar dan tinggi jendela tampilan. Jika jendela sempit, rak ditampilkan vertikal. Jika jendela pendek, jumlah baris buku dikurangi. Perpustakaan terus memantau dimensi jendela dan menyesuaikan tata letak secara real-time. Fitur media width dan height di CSS memungkinkan deteksi dimensi viewport yang sama.

## Penjelasan Detail

Media feature `width` dan `height` memungkinkan CSS merespons berdasarkan dimensi viewport perangkat. Fitur `width` mendeteksi lebar viewport, sementara `height` mendeteksi tinggi viewport. Nilai yang diuji bisa berupa panjang absolut (seperti `600px`) atau relatif terhadap viewport. Dalam praktiknya, `min-width` dan `max-width` lebih sering digunakan daripada `width` karena mendukung pendekatan rentang. Fitur `height` jarang digunakan untuk tata letak utama karena tinggi halaman web cenderung bervariasi, tetapi berguna untuk situasi spesifik seperti menyesuaikan tata letak di layar yang sangat pendek (seperti smartphone landscape) atau sangat tinggi.

## Contoh Kode Implementasi

```css
/* Gaya default */
body {
  font-size: 16px;
  padding: 1rem;
}

/* Berdasarkan lebar viewport tepat 768px */
@media (width: 768px) {
  body {
    padding: 2rem;
    background-color: #f0f8ff;
  }
}

/* Berdasarkan tinggi viewport */
@media (min-height: 800px) {
  .hero {
    min-height: 70vh;
    display: flex;
    align-items: center;
  }
  .hero-content {
    padding: 4rem 0;
  }
}

@media (max-height: 500px) {
  .hero {
    min-height: auto;
    padding: 1rem 0;
  }
  .hero-content h1 {
    font-size: 1.5rem;
  }
  .navbar {
    position: relative;
  }
}

/* Kombinasi lebar dan tinggi */
@media (min-width: 1024px) and (min-height: 768px) {
  .layout {
    display: grid;
    grid-template-columns: 300px 1fr;
    grid-template-rows: auto 1fr auto;
    min-height: 100vh;
  }
}

/* Layar lebar namun pendek (misal: landscape di ponsel) */
@media (min-width: 640px) and (max-height: 480px) {
  .sidebar {
    width: 200px;
    overflow-y: auto;
  }
  .content {
    padding: 0.5rem;
  }
}

/* Fitur width dengan satuan viewport */
@media (min-width: 50em) {
  .container {
    display: grid;
    grid-template-columns: 2fr 1fr;
    gap: 2rem;
  }
}
```

## Poin Penting
- width dan height mendeteksi dimensi viewport, bukan dimensi layar fisik perangkat
- min-width dan max-width lebih praktis digunakan daripada width untuk rentang ukuran
- height berguna untuk skenario khusus seperti layar pendek (landscape) atau tata letak full-height
- Kombinasi width dan height memungkinkan kontrol tata letak yang lebih presisi
