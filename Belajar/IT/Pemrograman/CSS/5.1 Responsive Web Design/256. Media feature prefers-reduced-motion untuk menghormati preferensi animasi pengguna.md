# Media feature prefers-reduced-motion untuk menghormati preferensi animasi pengguna

## Analogi: Perpustakaan Digital

Beberapa pengunjung perpustakaan digital merasa pusing saat melihat animasi buku yang berputar atau transisi halaman yang cepat. Perpustakaan menyediakan pengaturan "mode tenang" di mana semua gerakan dan animasi diminimalkan atau dimatikan. Dengan mendeteksi preferensi sistem operasi pengunjung, perpustakaan secara otomatis mengaktifkan mode tenang ini tanpa perlu konfigurasi manual.

## Penjelasan Detail

Media feature `prefers-reduced-motion` memungkinkan CSS mendeteksi apakah pengguna telah mengatur sistem operasi mereka untuk mengurangi pergerakan animasi. Fitur ini sangat penting untuk aksesibilitas karena animasi dapat menyebabkan mual, pusing, atau ketidaknyamanan pada pengguna dengan gangguan vestibular. Nilai `no-preference` berarti pengguna tidak memiliki preferensi khusus, sementara `reduce` berarti pengguna meminta untuk meminimalkan animasi. Penerapan yang baik melibatkan penghentian animasi yang tidak esensial, mengurangi durasi animasi, atau mengganti efek animasi dengan transisi yang lebih halus dan singkat.

## Contoh Kode Implementasi

```css
/* Gaya default dengan animasi */
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
}

@keyframes pulse {
  0%, 100% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.05);
  }
}

.notification-badge {
  animation: pulse 2s infinite;
}

@keyframes slideIn {
  from {
    transform: translateX(100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

.modal {
  animation: slideIn 0.3s ease-out;
}

/* Preferensi mengurangi gerakan */
@media (prefers-reduced-motion: reduce) {
  /* Hentikan semua animasi */
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }

  /* Alternatif: animasi yang lebih halus */
  .card:hover {
    transform: none;
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  }

  .notification-badge {
    animation: none;
  }

  .modal {
    animation: none;
    opacity: 1;
  }

  /* Efek parallax dimatikan */
  .parallax {
    background-attachment: scroll;
  }

  /* Loading spinner jadi statis */
  .spinner {
    animation: none;
  }
  .spinner::after {
    content: 'Loading...';
  }
}

/* Pendekatan sebaliknya: animasi hanya aktif jika diizinkan */
@media (prefers-reduced-motion: no-preference) {
  .fade-in {
    animation: fadeIn 0.5s ease forwards;
  }
  
  @keyframes fadeIn {
    from {
      opacity: 0;
      transform: translateY(20px);
    }
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
}
```

## Poin Penting
- prefers-reduced-motion mendeteksi preferensi pengguna untuk mengurangi animasi
- Penting untuk aksesibilitas pengguna dengan gangguan vestibular (mual/pusing karena gerakan)
- Nilai reduce: matikan atau minimalisir animasi; no-preference: animasi boleh berjalan normal
- Gunakan pendekatan animasi progresif: default tanpa animasi, tambah animasi hanya jika diizinkan
