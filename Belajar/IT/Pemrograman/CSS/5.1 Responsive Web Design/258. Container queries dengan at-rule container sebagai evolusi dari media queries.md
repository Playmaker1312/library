# Container queries dengan at-rule container sebagai evolusi dari media queries

## Analogi: Perpustakaan Digital

Media queries seperti aturan perpustakaan yang melihat ukuran ruangan secara keseluruhan. Container queries lebih cerdas: setiap rak buku dapat menyesuaikan tampilannya berdasarkan ukuran rak itu sendiri, bukan ukuran ruangan. Sebuah kartu buku akan terlihat berbeda ketika ditempatkan di rak utama yang lebar versus di rak sidebar yang sempit, meskipun keduanya berada di ruangan yang sama.

## Penjelasan Detail

Container queries adalah fitur CSS yang memungkinkan elemen merespons ukuran kontainer induknya, bukan ukuran viewport seperti media queries. Ini adalah evolusi besar dalam desain responsif karena komponen dapat menjadi benar-benar mandiri dan kontekstual. Dengan at-rule `@container`, pengembang dapat mendefinisikan gaya yang bergantung pada ukuran kontainer tempat elemen berada. Untuk menggunakan container queries, kontainer induk harus didefinisikan dengan properti `container-type` atau `container`. Fitur ini sangat berguna untuk komponen reusable yang mungkin ditempatkan di berbagai posisi dalam layout yang berbeda.

## Contoh Kode Implementasi

```css
/* Mendefinisikan container */
.card-grid {
  container-type: inline-size;
  container-name: card-container;
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: 1rem;
}

.sidebar {
  container-type: inline-size;
  container-name: sidebar;
}

/* Container query berdasarkan ukuran kontainer */
@container card-container (min-width: 300px) {
  .card {
    display: grid;
    grid-template-columns: 120px 1fr;
    gap: 1rem;
  }
  
  .card-image {
    width: 120px;
    height: 120px;
    object-fit: cover;
    border-radius: 8px;
  }
  
  .card-title {
    font-size: 1.25rem;
  }
  
  .card-description {
    display: block;
  }
}

@container card-container (max-width: 299px) {
  .card {
    display: block;
  }
  
  .card-image {
    width: 100%;
    height: 200px;
    object-fit: cover;
    border-radius: 8px;
  }
  
  .card-title {
    font-size: 1rem;
  }
  
  .card-description {
    display: none;
  }
}

/* Container dengan nama spesifik */
@container sidebar (min-width: 200px) {
  .widget {
    padding: 1rem;
  }
  
  .widget-title {
    font-size: 0.875rem;
    text-transform: uppercase;
    letter-spacing: 0.05em;
  }
}

/* Container query tanpa nama (mencari container terdekat) */
@container (min-width: 400px) {
  .profile-card {
    display: flex;
    align-items: center;
    gap: 1.5rem;
  }
  
  .profile-avatar {
    width: 80px;
    height: 80px;
  }
  
  .profile-info {
    flex: 1;
  }
}

/* Fallback untuk browser yang belum mendukung container queries */
.card {
  display: block;
}

@supports (container-type: inline-size) {
  .card-grid {
    container-type: inline-size;
  }
}
```

## Poin Penting
- Container queries memungkinkan komponen merespons ukuran kontainer induk, bukan viewport
- Gunakan container-type untuk mendefinisikan elemen sebagai container query
- Container queries membuat komponen lebih portabel dan reusable di berbagai konteks
- Fitur ini merupakan evolusi dari media queries untuk desain berbasis komponen
