# Sintaks media queries dengan kata kunci and, or, dan not untuk kondisi gabungan

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki aturan akses yang kompleks: "Jika pengguna adalah anggota premium DAN perangkatnya adalah tablet, tampilkan konten eksklusif." Atau "Jika hari libur ATAU akhir pekan, aktifkan mode santai." Aturan logika seperti ini memungkinkan perpustakaan merespon kombinasi kondisi secara tepat. Media queries di CSS memiliki kemampuan logika yang serupa.

## Penjelasan Detail

Media queries mendukung operator logika `and`, `or` (menggunakan koma), dan `not` untuk menggabungkan beberapa kondisi. Operator `and` mensyaratkan semua kondisi terpenuhi agar query bernilai true. Operator `or` menggunakan koma sebagai pemisah, di mana salah satu kondisi terpenuhi sudah cukup. Operator `not` membalikkan hasil evaluasi kondisi. Urutan evaluasi mengikuti aturan logika standar tanpa prioritas implisit, sehingga penggunaan tanda kurung sangat disarankan untuk kondisi kompleks. Selain itu, fitur media `only` dapat digunakan untuk mencegah browser lama yang tidak mendukung media queries menerapkan gaya.

## Contoh Kode Implementasi

```css
/* Operator AND: semua kondisi harus terpenuhi */
@media screen and (min-width: 768px) and (max-width: 1024px) {
  .container {
    padding: 2rem;
    max-width: 960px;
  }
  .card {
    flex: 1 1 50%;
  }
}

/* Operator OR (koma): salah satu kondisi terpenuhi */
@media (max-width: 480px), (orientation: portrait) {
  .sidebar {
    display: none;
  }
  .main-content {
    width: 100%;
  }
}

/* Operator NOT: membalikkan kondisi */
@media not screen and (color) {
  body {
    background-color: #ffffff;
    color: #000000;
  }
  img {
    display: none;
  }
}

/* Kombinasi kompleks dengan tanda kurung */
@media screen and (min-width: 768px) and (max-width: 1200px), 
       screen and (orientation: landscape) {
  .gallery {
    grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  }
}

/* Operator ONLY untuk mencegah browser lama */
@media only screen and (min-width: 768px) {
  .header {
    position: fixed;
    top: 0;
    width: 100%;
  }
}
```

## Poin Penting
- Operator and mensyaratkan semua kondisi bernilai true untuk mengaktifkan gaya
- Operator or menggunakan koma sebagai pemisah antar kondisi
- Operator not membalikkan hasil evaluasi media query
- Penggunaan tanda kurung penting untuk memperjelas prioritas logika pada kondisi kompleks
