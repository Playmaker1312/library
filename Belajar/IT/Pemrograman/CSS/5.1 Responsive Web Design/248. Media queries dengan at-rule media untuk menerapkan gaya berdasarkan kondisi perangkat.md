# Media queries dengan at-rule media untuk menerapkan gaya berdasarkan kondisi perangkat

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki aturan pencahayaan yang berbeda tergantung waktu: lampu terang saat siang, redup saat malam, dan otomatis menyesuaikan dengan sensor cahaya ruangan. Aturan ini memastikan kenyamanan membaca di berbagai kondisi. Media queries dalam CSS bekerja seperti sensor yang mendeteksi karakteristik perangkat pengunjung, lalu menerapkan aturan gaya yang sesuai secara otomatis.

## Penjelasan Detail

Media queries adalah fitur CSS3 yang memungkinkan penerapan gaya berdasarkan hasil evaluasi kondisi perangkat pengguna. At-rule `@media` digunakan untuk mendefinisikan blok CSS yang hanya aktif ketika kondisi tertentu terpenuhi. Sintaks dasarnya terdiri dari kata kunci `@media` diikuti tipe media (seperti `screen` atau `print`) dan ekspresi fitur media dalam tanda kurung. Media queries dapat memeriksa berbagai karakteristik perangkat seperti lebar layar, tinggi layar, orientasi, resolusi, dan preferensi sistem. Ketika kondisi terpenuhi, semua gaya di dalam blok media query akan diterapkan. Media queries adalah fondasi dari responsive web design karena memungkinkan satu stylesheet melayani berbagai perangkat.

## Contoh Kode Implementasi

```css
/* Gaya default untuk semua perangkat */
body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  color: #333333;
  background-color: #f5f5f5;
  line-height: 1.6;
}

/* Tipe media: print */
@media print {
  body {
    background-color: #ffffff;
    color: #000000;
    font-size: 12pt;
  }
  .no-print {
    display: none;
  }
}

/* Tipe media: screen dengan kondisi lebar minimal */
@media screen and (min-width: 768px) {
  .container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 2rem;
  }
}

/* Multiple conditions */
@media screen and (min-width: 1024px) and (orientation: landscape) {
  .container {
    grid-template-columns: repeat(3, 1fr);
  }
  .hero h1 {
    font-size: 3rem;
  }
}

/* Tipe media all (default) */
@media (max-width: 480px) {
  .nav-links {
    flex-direction: column;
  }
  .btn {
    width: 100%;
  }
}
```

## Poin Penting
- @media memungkinkan CSS diterapkan secara kondisional berdasarkan karakteristik perangkat
- Tipe media yang umum digunakan: screen (layar), print (cetakan), all (semua perangkat)
- Media queries dievaluasi oleh browser dan gaya hanya diterapkan jika kondisi terpenuhi
- Media queries dapat digabungkan dengan operator and, or (koma), dan not untuk kondisi kompleks
