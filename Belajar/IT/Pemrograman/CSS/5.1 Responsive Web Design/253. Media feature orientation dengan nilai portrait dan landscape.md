# Media feature orientation dengan nilai portrait dan landscape

## Analogi: Perpustakaan Digital

Perpustakaan digital mendeteksi bagaimana pengguna memegang perangkat mereka. Saat perangkat dipegang tegak (portrait), konten ditampilkan dalam satu kolom yang mudah digulir ke bawah. Saat perangkat diputar menyamping (landscape), konten diatur dalam dua kolom untuk memanfaatkan lebar layar. Perpustakaan secara otomatis menyesuaikan tata letak setiap kali pengguna memutar perangkat mereka.

## Penjelasan Detail

Media feature `orientation` mendeteksi apakah viewport perangkat sedang dalam mode portrait (tinggi lebih besar dari lebar) atau landscape (lebar lebih besar dari tinggi). Fitur ini sangat berguna untuk menyesuaikan tata letak ketika pengguna memutar perangkat mobile. Pada mode portrait, konten biasanya ditampilkan dalam satu kolom dengan navigasi di atas. Pada mode landscape, tersedia lebih banyak ruang horizontal yang bisa dimanfaatkan untuk tata letak multi-kolom, sidebar, atau elemen yang lebih lebar. Orientation sangat relevan untuk perangkat mobile, tetapi juga berguna di desktop ketika pengguna mengubah ukuran jendela menjadi sangat lebar atau sangat tinggi.

## Contoh Kode Implementasi

```css
/* Gaya default */
.container {
  display: flex;
  flex-direction: column;
  gap: 1rem;
  padding: 1rem;
}

.sidebar {
  width: 100%;
}

.content {
  flex: 1;
}

.gallery {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 1rem;
}

/* Mode portrait */
@media (orientation: portrait) {
  .container {
    max-width: 100%;
  }
  
  .sidebar {
    order: -1;
  }
  
  .hero h1 {
    font-size: 2rem;
  }
  
  .hero p {
    font-size: 1rem;
  }
  
  .nav {
    position: sticky;
    top: 0;
    background: white;
    z-index: 100;
  }
}

/* Mode landscape */
@media (orientation: landscape) {
  .container {
    flex-direction: row;
    align-items: flex-start;
  }
  
  .sidebar {
    width: 280px;
    position: sticky;
    top: 1rem;
  }
  
  .hero {
    display: grid;
    grid-template-columns: 1fr 1fr;
    align-items: center;
    min-height: 60vh;
  }
  
  .hero h1 {
    font-size: 3rem;
  }
  
  .gallery {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Kombinasi orientation dengan width */
@media (orientation: landscape) and (max-height: 500px) {
  .header {
    padding: 0.25rem 0;
  }
  .hero {
    min-height: auto;
    padding: 1rem 0;
  }
}
```

## Poin Penting
- Portrait: tinggi viewport lebih besar dari lebar, umumnya perangkat dipegang tegak
- Landscape: lebar viewport lebih besar dari tinggi, umumnya perangkat diputar menyamping
- Perubahan orientation paling sering terjadi pada perangkat mobile saat diputar
- Kombinasikan orientation dengan min-width untuk kontrol yang lebih presisi
