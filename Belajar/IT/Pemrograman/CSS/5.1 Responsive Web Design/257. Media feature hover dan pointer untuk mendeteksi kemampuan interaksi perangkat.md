# Media feature hover dan pointer untuk mendeteksi kemampuan interaksi perangkat

## Analogi: Perpustakaan Digital

Perpustakaan digital mendeteksi alat yang digunakan pengunjung untuk berinteraksi. Ada yang menggunakan kursor mouse yang bisa melayang (hover) di atas buku, ada yang menggunakan jari di layar sentuh yang hanya bisa mengetuk, dan ada yang menggunakan stylus untuk presisi tinggi. Perpustakaan menyesuaikan pengalaman berdasarkan alat interaksi ini: menampilkan tooltip untuk mouse, memperbesar area ketuk untuk sentuhan.

## Penjelasan Detail

Media feature `hover` dan `pointer` memungkinkan CSS mendeteksi kemampuan interaksi perangkat pengguna. `hover` mengecek apakah perangkat memiliki kemampuan hover (kursor bisa melayang di atas elemen). Nilainya `hover` (perangkat mendukung hover) atau `none` (tidak mendukung, seperti layar sentuh). `pointer` mengecek ketepatan alat interaksi: `fine` untuk pointer presisi tinggi (mouse, stylus), `coarse` untuk pointer presisi rendah (jari), dan `none` jika tidak ada pointer. Informasi ini memungkinkan pengoptimalan UX seperti memperbesar target sentuhan di perangkat touch dan menyediakan efek hover yang lebih kompleks di perangkat mouse.

## Contoh Kode Implementasi

```css
/* Default: untuk semua perangkat */
.button {
  padding: 0.5rem 1rem;
  border: 2px solid #1a73e8;
  background: transparent;
  color: #1a73e8;
  border-radius: 4px;
  cursor: pointer;
  font-size: 1rem;
  
  /* Area target minimum untuk touch */
  min-width: 44px;
  min-height: 44px;
}

/* Perangkat dengan hover (mouse) */
@media (hover: hover) {
  .button:hover {
    background: #1a73e8;
    color: white;
    transition: all 0.2s ease;
  }
  
  .card {
    transition: transform 0.3s ease;
  }
  
  .card:hover {
    transform: translateY(-4px);
  }
  
  .tooltip {
    display: block;
    opacity: 0;
    transition: opacity 0.2s ease;
    position: absolute;
    bottom: 100%;
    left: 50%;
    transform: translateX(-50%);
  }
  
  .tooltip-trigger:hover .tooltip {
    opacity: 1;
  }
}

/* Perangkat tanpa hover (touch) */
@media (hover: none) {
  .button {
    padding: 0.75rem 1.5rem;
  }
  
  .button:active {
    background: #e8f0fe;
  }
  
  .card:active {
    transform: scale(0.98);
  }
}

/* Pointer presisi tinggi (mouse/stylus) */
@media (pointer: fine) {
  .menu-item {
    padding: 0.25rem 0.5rem;
  }
  .slider-thumb {
    width: 16px;
    height: 16px;
  }
}

/* Pointer presisi rendah (jari) */
@media (pointer: coarse) {
  .menu-item {
    padding: 0.75rem 1rem;
    margin-bottom: 0.25rem;
  }
  .slider-thumb {
    width: 32px;
    height: 32px;
  }
  .nav-link {
    min-width: 48px;
    min-height: 48px;
    display: flex;
    align-items: center;
    justify-content: center;
  }
}

/* Kombinasi hover dan pointer */
@media (hover: hover) and (pointer: fine) {
  .drag-handle {
    cursor: grab;
  }
  .resize-handle {
    cursor: se-resize;
  }
}
```

## Poin Penting
- hover mengecek kemampuan melayang kursor, pointer mengecek ketepatan alat interaksi
- Perangkat touch tidak memiliki hover, gunakan :active sebagai alternatif feedback
- pointer: coarse (jari) membutuhkan target sentuh minimal 44x44 piksel
- Kombinasi hover dan pointer memungkinkan pengalaman yang dioptimalkan untuk setiap perangkat
