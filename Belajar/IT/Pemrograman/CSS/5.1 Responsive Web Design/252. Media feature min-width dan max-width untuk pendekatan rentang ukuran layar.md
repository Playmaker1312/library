# Media feature min-width dan max-width untuk pendekatan rentang ukuran layar

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki aturan: "Jika lebar jendela minimal 768 piksel, tampilkan navigasi samping." Aturan ini menggunakan pendekatan batas minimal. Aturan lain: "Jika lebar jendela maksimal 480 piksel, sembunyikan gambar besar." Ini menggunakan pendekatan batas maksimal. Keduanya memungkinkan perpustakaan merespons secara bertahap seiring perubahan ukuran jendela.

## Penjelasan Detail

`min-width` dan `max-width` adalah media feature yang mendefinisikan rentang ukuran viewport. `min-width: 768px` berarti kondisi terpenuhi jika viewport lebih besar atau sama dengan 768 piksel. `max-width: 767px` berarti kondisi terpenuhi jika viewport lebih kecil atau sama dengan 767 piksel. `min-width` sangat cocok untuk pendekatan mobile-first karena gaya default ditulis untuk layar kecil, kemudian ditambahkan gaya untuk layar yang lebih besar. `max-width` cocok untuk pendekatan desktop-first, di mana gaya default ditulis untuk layar besar, kemudian ditimpa untuk layar yang lebih kecil. Kedua pendekatan bisa dikombinasikan untuk menargetkan rentang spesifik, misalnya `min-width: 768px` dan `max-width: 1024px` untuk perangkat tablet.

## Contoh Kode Implementasi

```css
/* Mobile-first dengan min-width */

/* Gaya default: ponsel (< 480px) */
.nav {
  display: block;
}
.nav-item {
  display: block;
  padding: 0.5rem 0;
}
.grid {
  display: block;
}

/* Tablet (>= 480px) */
@media (min-width: 480px) {
  .nav {
    display: flex;
    gap: 1rem;
  }
  .grid {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 1rem;
  }
}

/* Desktop (>= 768px) */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: 1fr 1fr 1fr;
    gap: 1.5rem;
  }
  .container {
    max-width: 720px;
  }
}

/* Layar lebar (>= 1024px) */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(4, 1fr);
  }
  .container {
    max-width: 960px;
  }
}

/* Rentang spesifik: tablet saja (480px - 767px) */
@media (min-width: 480px) and (max-width: 767px) {
  .tablet-only {
    display: block;
  }
  .sidebar {
    display: none;
  }
  .card {
    padding: 1rem;
  }
}

/* Desktop-first dengan max-width */
/* Gaya default: desktop */
/* @media (max-width: 1023px) { ... tablet }
   @media (max-width: 767px) { ... ponsel } */
```

## Poin Penting
- min-width digunakan dalam pendekatan mobile-first, gaya default untuk layar terkecil
- max-width digunakan dalam pendekatan desktop-first, gaya default untuk layar terbesar
- Kombinasi min-width dan max-width dapat menargetkan rentang perangkat spesifik
- Saat menggunakan min-width, urutan media queries harus dari kecil ke besar untuk menghindari konflik
