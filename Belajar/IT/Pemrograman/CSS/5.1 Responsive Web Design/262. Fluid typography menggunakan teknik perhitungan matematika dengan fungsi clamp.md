# Fluid typography menggunakan teknik perhitungan matematika dengan fungsi clamp

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin ukuran font judul berubah secara mulus dari 24 piksel di ponsel menjadi 48 piksel di desktop. Alih-alih berubah secara tiba-tiba di breakpoint tertentu, ukuran font mengalir secara linear mengikuti lebar layar. Ini seperti air yang mengalir menyesuaikan bentuk wadahnya, bukan melompat-lompat seperti air dalam ember yang dipindah-pindah.

## Penjelasan Detail

Fluid typography menggunakan perhitungan matematika untuk membuat ukuran font berubah secara linear antara dua nilai berdasarkan lebar viewport. Rumus dasarnya melibatkan perhitungan slope (kemiringan) dan intercept (titik potong) berdasarkan dua titik: ukuran font minimum pada viewport minimum, dan ukuran font maksimum pada viewport maksimum. Hasil perhitungan ini kemudian digunakan dalam fungsi `clamp()`. Rumus umum: `clamp(minSize, slope * 100vw + intercept, maxSize)`. Teknik ini menghilangkan kebutuhan breakpoint untuk perubahan ukuran font dan memberikan pengalaman tipografi yang mulus di semua ukuran layar.

## Contoh Kode Implementasi

```css
/* Rumus fluid typography */
/* 
  Langkah-langkah:
  1. Tentukan ukuran min (16px) pada viewport min (320px)
  2. Tentukan ukuran max (24px) pada viewport max (1200px)
  3. Hitung slope = (24 - 16) / (1200 - 320) = 0.00909
  4. Hitung intercept = 16 - 0.00909 * 320 = 13.09
  5. Ubah ke rem: min = 1rem, max = 1.5rem
  6. Hasil: font-size: clamp(1rem, 0.909vw + 0.818rem, 1.5rem)
*/

body {
  font-size: clamp(1rem, 0.909vw + 0.818rem, 1.5rem);
}

/* Heading dengan fluid scale */
/* 28px - 56px (1.75rem - 3.5rem) */
h1 {
  font-size: clamp(1.75rem, 2.273vw + 1.273rem, 3.5rem);
}

/* 21px - 40px (1.3125rem - 2.5rem) */
h2 {
  font-size: clamp(1.3125rem, 1.591vw + 0.977rem, 2.5rem);
}

/* 18px - 32px (1.125rem - 2rem) */
h3 {
  font-size: clamp(1.125rem, 1.136vw + 0.864rem, 2rem);
}

/* Fluid typography untuk berbagai skala */
:root {
  --fluid-min-width: 320;
  --fluid-max-width: 1200;
  
  --fluid-min-size: 16;
  --fluid-max-size: 24;
  
  /* Slope = (max - min) / (max-width - min-width) */
  --fluid-slope: calc(
    (var(--fluid-max-size) - var(--fluid-min-size)) /
    (var(--fluid-max-width) - var(--fluid-min-width))
  );
}

/* Pendekatan custom property (CSS variables) */
:root {
  --step-0: clamp(1rem, 0.909vw + 0.818rem, 1.5rem);
  --step-1: clamp(1.125rem, 1.136vw + 0.864rem, 2rem);
  --step-2: clamp(1.3125rem, 1.591vw + 0.977rem, 2.5rem);
  --step-3: clamp(1.75rem, 2.273vw + 1.273rem, 3.5rem);
  --step-4: clamp(2.5rem, 3.409vw + 1.727rem, 5rem);
}

h1 { font-size: var(--step-4); }
h2 { font-size: var(--step-3); }
h3 { font-size: var(--step-2); }
h4 { font-size: var(--step-1); }
p { font-size: var(--step-0); }

/* Utility classes untuk fluid text */
.text-sm {
  font-size: clamp(0.75rem, 0.455vw + 0.659rem, 1rem);
}

.text-base {
  font-size: clamp(1rem, 0.909vw + 0.818rem, 1.5rem);
}

.text-lg {
  font-size: clamp(1.125rem, 1.136vw + 0.864rem, 2rem);
}

.text-xl {
  font-size: clamp(1.3125rem, 1.591vw + 0.977rem, 2.5rem);
}
```

## Poin Penting
- Fluid typography menggunakan perhitungan matematika linear antara dua titik ukuran
- Rumus dasar: clamp(min, slope * 100vw + intercept, max)
- Slope dihitung dari selisih ukuran dibagi selisih lebar viewport
- Gunakan custom properties untuk mendefinisikan skala tipografi yang konsisten
