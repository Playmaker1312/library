# Properti container-type dan container-name untuk mendefinisikan kontainer query

## Analogi: Perpustakaan Digital

Untuk membuat rak buku yang cerdas menyesuaikan tampilan, kita perlu memberi label pada rak tersebut. `container-type` memberi tahu rak bahwa ia harus melacak ukurannya sendiri. `container-name` memberi nama unik pada rak sehingga aturan container query tahu rak mana yang harus diperhatikan. Tanpa kedua properti ini, container queries tidak akan berfungsi.

## Penjelasan Detail

`container-type` dan `container-name` adalah properti CSS yang digunakan untuk mendefinisikan elemen sebagai kontainer query. `container-type` menentukan dimensi apa yang akan dilacak. Nilai `inline-size` melacak lebar kontainer (paling umum digunakan). Nilai `size` melacak lebar dan tinggi, tetapi membutuhkan elemen untuk memiliki ukuran yang eksplisit. Nilai `normal` membuat elemen menjadi kontainer query tanpa melacak ukuran (berguna untuk style queries). `container-name` memberikan nama unik pada kontainer sehingga dapat ditarget secara spesifik dalam at-rule `@container`. Kedua properti ini dapat digabungkan menggunakan shorthand `container`.

## Contoh Kode Implementasi

```css
/* container-type: melacak ukuran inline (lebar) */
.main-content {
  container-type: inline-size;
}

/* container-type: melacak lebar dan tinggi */
.fullscreen-panel {
  container-type: size;
  height: 100vh;
}

/* container-type: normal (untuk style queries) */
.theme-provider {
  container-type: normal;
  container-name: theme;
}

/* container-name: memberi nama pada kontainer */
.sidebar-widgets {
  container-type: inline-size;
  container-name: sidebar;
}

.content-area {
  container-type: inline-size;
  container-name: content;
}

/* Shorthand container */
.card-wrapper {
  container: card-container / inline-size;
}

.header-section {
  container: header / size;
}

/* Multiple nama container */
.grid-item {
  container-type: inline-size;
  container-name: grid-item card-component;
}

/* Container queries yang menarget container spesifik */
@container card-container (min-width: 350px) {
  .card-inner {
    display: flex;
    gap: 1rem;
  }
}

@container sidebar (min-width: 200px) {
  .widget-list {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
  }
}

@container content (min-width: 500px) {
  .article {
    column-count: 2;
    column-gap: 2rem;
  }
}

/* Fallback untuk browser lama */
.component {
  display: block;
}

@supports (container-type: inline-size) {
  .component-wrapper {
    container-type: inline-size;
  }
  
  @container (min-width: 400px) {
    .component {
      display: flex;
    }
  }
}
```

## Poin Penting
- container-type: inline-size melacak lebar, size melacak lebar dan tinggi, normal untuk style queries
- container-name memberikan identitas unik untuk ditarget dalam at-rule @container
- Shorthand container menggabungkan container-name dan container-type
- Gunakan @supports untuk fallcheck browser yang belum mendukung container queries
