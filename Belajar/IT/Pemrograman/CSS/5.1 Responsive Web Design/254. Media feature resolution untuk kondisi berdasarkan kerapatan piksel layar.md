# Media feature resolution untuk kondisi berdasarkan kerapatan piksel layar

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki dua versi gambar sampul buku: resolusi standar untuk layar biasa dan resolusi tinggi untuk layar Retina. Saat pengguna membuka perpustakaan di ponsel dengan layar kerapatan tinggi, sistem secara otomatis memilih gambar versi HD. Deteksi kerapatan piksel ini memastikan gambar selalu tajam tanpa membebani perangkat dengan file yang tidak perlu.

## Penjelasan Detail

Media feature `resolution` memungkinkan CSS mendeteksi kerapatan piksel layar perangkat, yang diukur dalam satuan dpi (dots per inch) atau dpcm (dots per centimeter). Layar dengan kerapatan tinggi seperti layar Retina Apple memiliki nilai 2x atau 3x dari layar standar. Fitur ini sangat penting untuk menyediakan gambar dengan resolusi yang sesuai, mencegah gambar tampak buram di layar berkerapatan tinggi atau mengunduh file terlalu besar di layar standar. Nilai `min-resolution` dan `max-resolution` dapat digunakan untuk menentukan rentang. Satuan `dppx` (dots per pixel unit) sering digunakan sebagai alternatif yang lebih intuitif, di mana 1dppx setara dengan 96dpi.

## Contoh Kode Implementasi

```css
/* Gaya default untuk layar resolusi standar (1x) */
.logo {
  background-image: url('logo.png');
  background-size: 200px 50px;
  width: 200px;
  height: 50px;
}

.hero-image {
  background-image: url('hero-standard.jpg');
  background-size: cover;
}

/* Layar dengan resolusi tinggi (2x) */
@media (min-resolution: 192dpi) {
  .logo {
    background-image: url('logo@2x.png');
  }
  .hero-image {
    background-image: url('hero-hd.jpg');
  }
}

/* Layar dengan resolusi sangat tinggi (3x) */
@media (min-resolution: 288dpi) {
  .logo {
    background-image: url('logo@3x.png');
  }
  .icon {
    background-image: url('icon@3x.png');
  }
}

/* Menggunakan satuan dppx (lebih intuitif) */
@media (min-resolution: 2dppx) {
  .profile-pic {
    background-image: url('profile@2x.jpg');
  }
  .border-thin {
    border-width: 0.5px;
  }
}

@media (min-resolution: 3dppx) {
  .profile-pic {
    background-image: url('profile@3x.jpg');
  }
}

/* Gambar responsif dengan <picture> dan srcset (pendekatan HTML) */
/*
<picture>
  <source srcset="hero-hd.jpg" media="(min-resolution: 192dpi)">
  <img src="hero-standard.jpg" alt="Hero">
</picture>
*/

/* Kombinasi dengan ukuran viewport */
@media (min-resolution: 2dppx) and (min-width: 768px) {
  .card {
    box-shadow: 0 1px 2px rgba(0, 0, 0, 0.1);
  }
}
```

## Poin Penting
- resolution mendeteksi kerapatan piksel layar dalam dpi, dpcm, atau dppx
- 1dppx = 96dpi, merupakan kerapatan layar standar
- min-resolution digunakan untuk menargetkan layar berkerapatan tinggi (Retina/HiDPI)
- Penting untuk performa dan ketajaman visual, terutama untuk gambar dan ikon
