# Pendekatan mobile-first versus desktop-first dalam pengembangan CSS responsif

## Analogi: Perpustakaan Digital

Perpustakaan digital bisa dirancang dengan dua cara: mulai dari tampilan ponsel lalu memperluas untuk layar besar, atau mulai dari tampilan desktop lalu menyederhanakan untuk ponsel. Pendekatan pertama seperti membangun kursi yang nyaman lalu menambahkan sandaran tangan. Pendekatan kedua seperti membangun sofa lalu memotongnya menjadi kursi kecil. Hasil akhir mungkin mirip, tetapi proses dan prioritasnya sangat berbeda.

## Penjelasan Detail

Mobile-first adalah pendekatan di mana pengembang memulai desain dari ukuran layar terkecil terlebih dahulu, kemudian menambahkan gaya untuk layar yang lebih besar menggunakan media queries min-width. Desktop-first sebaliknya: memulai dari layar besar lalu menambahkan gaya untuk layar kecil menggunakan media queries max-width. Mobile-first mendorong pengembang untuk fokus pada konten esensial dan performa karena keterbatasan perangkat mobile. Pendekatan ini juga lebih selaras dengan tren penggunaan internet di mana mayoritas trafik berasal dari perangkat mobile. Desktop-first sering kali menghasilkan kode CSS yang lebih panjang karena harus menimpa properti yang sudah didefinisikan. Mobile-first umumnya menghasilkan stylesheet yang lebih bersih dan lebih mudah dipelihara.

## Contoh Kode Implementasi

```css
/* MOBILE-FIRST: Mulai dari layar kecil */
.layout {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
  padding: 1rem;
}

.sidebar {
  display: none;
}

.content {
  padding: 1rem;
}

/* Tablet: 768px ke atas */
@media (min-width: 768px) {
  .layout {
    grid-template-columns: 250px 1fr;
  }
  .sidebar {
    display: block;
  }
}

/* Desktop: 1024px ke atas */
@media (min-width: 1024px) {
  .layout {
    grid-template-columns: 300px 1fr 200px;
  }
}
```

## Poin Penting
- Mobile-first menggunakan min-width, desktop-first menggunakan max-width dalam media queries
- Mobile-first menghasilkan kode lebih bersih karena tidak perlu banyak menimpa properti sebelumnya
- Mobile-first memaksa prioritisasi konten esensial karena keterbatasan ruang layar
- Sebagian besar tim pengembang modern merekomendasikan pendekatan mobile-first
