# Media feature prefers-color-scheme untuk mendeteksi preferensi tema gelap atau terang

## Analogi: Perpustakaan Digital

Perpustakaan digital mendeteksi preferensi pencahayaan pengunjung: ada yang nyaman membaca di latar putih terang seperti siang hari, ada yang lebih suka latar gelap seperti membaca di malam hari. Perpustakaan secara otomatis mengubah skema warna sesuai preferensi sistem operasi pengunjung, tanpa perlu meminta mereka memilih secara manual.

## Penjelasan Detail

Media feature `prefers-color-scheme` memungkinkan CSS mendeteksi apakah pengguna telah mengatur sistem operasi mereka ke mode terang (`light`) atau gelap (`dark`). Fitur ini merupakan bagian dari spesifikasi Media Queries Level 5 yang mendukung preferensi pengguna. Dengan fitur ini, website dapat secara otomatis menyediakan tema gelap tanpa memerlukan JavaScript atau toggle manual. Penerapan yang baik melibatkan pendefinisian variabel CSS untuk warna-warna utama, sehingga peralihan tema hanya membutuhkan perubahan nilai variabel. Tema gelap tidak hanya soal estetika, tetapi juga mengurangi ketegangan mata dalam kondisi pencahayaan redup dan menghemat baterai pada perangkat dengan layar OLED.

## Contoh Kode Implementasi

```css
/* Variabel CSS untuk tema terang (default) */
:root {
  --color-bg: #ffffff;
  --color-text: #222222;
  --color-primary: #1a73e8;
  --color-secondary: #5f6368;
  --color-border: #dadce0;
  --color-card-bg: #f8f9fa;
  --color-shadow: rgba(0, 0, 0, 0.1);
  --color-link: #1a73e8;
  --color-link-hover: #1557b0;
  --color-code-bg: #f1f3f4;
}

/* Tema gelap */
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #1a1a2e;
    --color-text: #e0e0e0;
    --color-primary: #8ab4f8;
    --color-secondary: #9aa0a6;
    --color-border: #3c4043;
    --color-card-bg: #16213e;
    --color-shadow: rgba(0, 0, 0, 0.3);
    --color-link: #8ab4f8;
    --color-link-hover: #aecbfa;
    --color-code-bg: #2d2d44;
  }
}

/* Penggunaan variabel dalam komponen */
body {
  background-color: var(--color-bg);
  color: var(--color-text);
  transition: background-color 0.3s ease, color 0.3s ease;
}

.card {
  background-color: var(--color-card-bg);
  border: 1px solid var(--color-border);
  box-shadow: 0 2px 8px var(--color-shadow);
}

a {
  color: var(--color-link);
}

a:hover {
  color: var(--color-link-hover);
}

code {
  background-color: var(--color-code-bg);
  padding: 0.2em 0.4em;
  border-radius: 3px;
}

/* Gambar dengan opacity lebih rendah di mode gelap */
@media (prefers-color-scheme: dark) {
  img {
    opacity: 0.85;
    transition: opacity 0.3s ease;
  }
  img:hover {
    opacity: 1;
  }
}
```

## Poin Penting
- prefers-color-scheme mendeteksi preferensi tema dari sistem operasi pengguna
- Nilai yang tersedia: light (default) dan dark
- Gunakan variabel CSS untuk memudahkan peralihan antara tema terang dan gelap
- Tema gelap meningkatkan kenyamanan mata di lingkungan redup dan menghemat baterai OLED
