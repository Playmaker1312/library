# Breakpoint umum yang digunakan dalam desain responsif untuk berbagai ukuran layar

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki tiga mode tampilan yang berubah pada ukuran tertentu. Saat lebar layar di atas 1024 piksel, semua rak dan koleksi ditampilkan lengkap. Saat layar antara 768 hingga 1024 piksel, navigasi samping disembunyikan dan konten diatur ulang. Saat di bawah 768 piksel, tampilan berubah menjadi daftar vertikal yang mudah digulir. Titik-titik perubahan ini disebut breakpoint.

## Penjelasan Detail

Breakpoint adalah titik lebar layar di mana tata letak website berubah untuk menyesuaikan dengan ukuran perangkat. Tidak ada standar baku untuk breakpoint karena setiap desain memiliki kebutuhan unik. Namun, beberapa breakpoint umum telah diadopsi oleh komunitas pengembang berdasarkan ukuran perangkat populer. Breakpoint 480px untuk ponsel kecil, 768px untuk tablet, 1024px untuk desktop kecil, dan 1200px untuk layar lebar. Praktik terbaik menyarankan menggunakan breakpoint berbasis konten, bukan berbasis perangkat tertentu. Artinya, breakpoint ditentukan oleh kapan desain mulai terlihat jelek atau tidak nyaman, bukan oleh ukuran perangkat tertentu.

## Contoh Kode Implementasi

```css
/* Breakpoint umum dalam pendekatan mobile-first */
.container {
  max-width: 100%;
  padding: 0 1rem;
}

/* Ponsel kecil: < 480px - gaya default */

/* Ponsel besar: >= 480px */
@media (min-width: 480px) {
  .container {
    max-width: 440px;
    margin: 0 auto;
  }
  .col {
    flex: 1 1 100%;
  }
}

/* Tablet: >= 768px */
@media (min-width: 768px) {
  .container {
    max-width: 720px;
  }
  .col {
    flex: 1 1 50%;
  }
  .sidebar {
    display: block;
    width: 250px;
  }
}

/* Desktop: >= 1024px */
@media (min-width: 1024px) {
  .container {
    max-width: 960px;
  }
  .col {
    flex: 1 1 33.333%;
  }
  .header {
    padding: 2rem 0;
  }
}

/* Layar lebar: >= 1200px */
@media (min-width: 1200px) {
  .container {
    max-width: 1140px;
  }
  .col {
    flex: 1 1 25%;
  }
}

/* Custom breakpoint berbasis konten */
@media (min-width: 850px) {
  .testimonial-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1100px) {
  .testimonial-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}
```

## Poin Penting
- Breakpoint umum: 480px (ponsel), 768px (tablet), 1024px (desktop), 1200px (layar lebar)
- Breakpoint harus berbasis konten, bukan berbasis perangkat tertentu
- Gunakan pendekatan mobile-first dengan min-width untuk breakpoint yang lebih mudah dikelola
- Dokumentasikan breakpoint dalam satu tempat untuk konsistensi di seluruh stylesheet
