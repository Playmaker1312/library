# Gradien conic menggunakan fungsi conic-gradient untuk gradien melingkar

## Analogi: Perpustakaan Digital

Bayangkan roda warna atau diagram lingkaran di perpustakaan yang menunjukkan kategori buku. Gradien conic adalah gradien yang berputar di sekitar titik pusat seperti potongan kue atau roda warna. Berbeda dengan radial yang menyebar ke luar, conic gradient berputar melingkar seperti jarum jam, menciptakan transisi warna melingkar di sekitar titik pusat.

## Penjelasan Detail

Fungsi conic-gradient() menghasilkan transisi warna yang berputar di sekitar titik pusat, bukan menyebar ke luar. Gradien ini dimulai dari atas (0 derajat) dan berputar searah jarum jam. Posisi pusat dapat ditentukan dengan at the. Sudut awal dapat ditentukan dengan from. Warna ditentukan dengan color stops yang dapat diberi sudut atau persentase. conic-gradient sangat berguna untuk membuat roda warna, diagram lingkaran, efek berputar, dan pola dekoratif melingkar. Properti ini relatif lebih baru dibanding linear-gradient dan radial-gradient, tetapi didukung oleh semua browser modern.

## Contoh Kode Implementasi

```css
/* Gradien conic dasar */
.basic-conic {
  background: conic-gradient(#e74c3c, #f39c12, #2ecc71, #3498db, #9b59b6, #e74c3c);
  width: 300px;
  height: 300px;
  border-radius: 50%;
}

/* Dengan sudut awal */
.from-angle {
  background: conic-gradient(from 90deg, #3498db, #e74c3c, #f39c12, #2ecc71);
  width: 300px;
  height: 300px;
  border-radius: 50%;
}

/* Dengan posisi pusat */
.positioned-conic {
  background: conic-gradient(at 30% 40%, #e74c3c, #3498db, #2ecc71);
  width: 300px;
  height: 300px;
}

/* Color stops dengan sudut */
.stops-conic {
  background: conic-gradient(
    #e74c3c 0deg,
    #f39c12 90deg,
    #2ecc71 180deg,
    #3498db 270deg,
    #e74c3c 360deg
  );
  width: 300px;
  height: 300px;
  border-radius: 50%;
}

/* Hard stop - seperti diagram lingkaran */
.pie-chart {
  background: conic-gradient(
    #3498db 0% 25%,
    #e74c3c 25% 50%,
    #2ecc71 50% 75%,
    #f39c12 75% 100%
  );
  width: 250px;
  height: 250px;
  border-radius: 50%;
}

/* Roda warna */
.color-wheel {
  background: conic-gradient(
    red, yellow, lime, aqua, blue, magenta, red
  );
  width: 200px;
  height: 200px;
  border-radius: 50%;
}

/* Conic untuk efek border gradient */
.conic-border {
  background: conic-gradient(#667eea, #764ba2, #667eea);
  width: 300px;
  height: 300px;
  border-radius: 50%;
  padding: 10px;
}

/* Multiple conic */
.multiple-conic {
  background:
    conic-gradient(from 0deg at 30% 50%, rgba(231,76,60,0.3), transparent),
    conic-gradient(from 180deg at 70% 50%, rgba(52,152,219,0.3), transparent);
  width: 400px;
  height: 300px;
}
```

## Poin Penting
- conic-gradient berputar di sekitar titik pusat, dimulai dari atas (0 derajat) searah jarum jam
- Gunakan from untuk mengatur sudut awal dan at untuk posisi pusat gradien
- Color stops dapat menggunakan sudut (deg) atau persentase untuk mengontrol posisi transisi
- conic-gradient cocok untuk roda warna, diagram lingkaran, dan efek dekoratif melingkar
