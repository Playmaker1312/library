# Latar belakang dengan beberapa gambar menggunakan multiple background values

## Analogi: Perpustakaan Digital

Seperti menumpuk beberapa dekorasi di dinding yang sama, multiple background values memungkinkan elemen memiliki lebih dari satu gambar latar. Bayangkan perpustakaan yang memiliki wallpaper sebagai lapisan dasar, kemudian di atasnya ditempelkan pola geometris, dan di atasnya lagi ditempatkan logo. Setiap lapisan dapat diatur posisi, ukuran, dan pengulangannya secara independen.

## Penjelasan Detail

CSS memungkinkan sebuah elemen memiliki beberapa gambar latar belakang yang ditumpuk. Gambar-gambar dipisahkan dengan koma pada properti background-image. Gambar pertama dalam daftar berada di lapisan paling atas, gambar terakhir di lapisan paling bawah. Properti background lainnya seperti background-repeat, background-position, background-size juga dapat memiliki beberapa nilai yang dipisahkan koma, sesuai dengan urutan gambar. Jika jumlah nilai lebih sedikit dari jumlah gambar, nilai akan diulang. Multiple backgrounds sangat berguna untuk efek visual kompleks seperti overlay, tekstur, dan dekorasi berlapis tanpa memerlukan elemen HTML tambahan. Teknik ini juga meningkatkan performa karena mengurangi jumlah elemen dan HTTP request.

## Contoh Kode Implementasi

```css
/* Dua gambar latar */
.two-layers {
  background-image: url('overlay.png'), url('background.jpg');
  background-repeat: no-repeat, repeat;
  background-position: center, top left;
  background-size: contain, auto;
  height: 400px;
}

/* Tiga lapisan */
.three-layers {
  background-image: url('stars.png'), url('gradient-overlay.png'), url('sky.jpg');
  background-repeat: no-repeat, no-repeat, repeat;
  background-position: center, center, top left;
  background-size: 200px, cover, auto;
  height: 500px;
}

/* Efek vignette dengan gradien dan gambar */
.vignette {
  background-image:
    radial-gradient(ellipse at center, transparent 50%, rgba(0,0,0,0.6) 100%),
    url('photo.jpg');
  background-size: cover, cover;
  background-position: center, center;
  height: 500px;
}

/* Overlay warna di atas gambar */
.overlay-bg {
  background-image:
    linear-gradient(rgba(52, 152, 219, 0.7), rgba(44, 62, 80, 0.8)),
    url('hero-image.jpg');
  background-size: cover, cover;
  background-position: center, center;
  background-blend-mode: multiply;
  height: 450px;
  color: white;
}

/* Pattern dengan gradien */
.pattern-overlay {
  background-image:
    repeating-linear-gradient(45deg, transparent, transparent 10px, rgba(255,255,255,0.1) 10px, rgba(255,255,255,0.1) 20px),
    linear-gradient(to bottom, #667eea, #764ba2);
  height: 300px;
}

/* Ikon dengan warna latar */
.icon-card {
  background-image:
    url('icon-check.svg'),
    linear-gradient(135deg, #2ecc71, #27ae60);
  background-repeat: no-repeat, repeat;
  background-position: center, top left;
  background-size: 48px, cover;
  width: 120px;
  height: 120px;
  border-radius: 16px;
}
```

## Poin Penting
- Multiple backgrounds ditulis dengan memisahkan nilai menggunakan koma pada properti background
- Gambar pertama berada di lapisan paling atas, gambar terakhir di lapisan paling bawah
- Setiap gambar dapat memiliki properti repeat, position, dan size yang diatur secara terpisah
- Gunakan multiple backgrounds untuk mengurangi elemen HTML tambahan dan meningkatkan performa
