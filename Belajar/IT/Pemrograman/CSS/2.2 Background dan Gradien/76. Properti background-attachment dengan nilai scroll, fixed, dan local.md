# Properti background-attachment dengan nilai scroll, fixed, dan local

## Analogi: Perpustakaan Digital

Bayangkan sebuah mural besar di dinding perpustakaan. Apakah mural ikut bergerak saat Anda menggeser pandangan (scroll), tetap diam seperti lukisan yang dipaku di dinding (fixed), atau bergerak bersama halaman buku yang Anda baca (local)? background-attachment mengontrol perilaku gambar latar saat pengguna menggulir halaman web.

## Penjelasan Detail

Properti background-attachment menentukan apakah gambar latar bergulir bersama konten atau tetap diam. Nilai scroll (default) membuat gambar latar bergulir bersama halaman. Nilai fixed membuat gambar latar tetap diam di viewport saat halaman digulir, menciptakan efek parallax sederhana. Nilai local membuat gambar latar bergulir bersama konten elemen jika elemen tersebut memiliki scroll sendiri. Fixed sering digunakan untuk menciptakan efek dramatis pada hero section atau latar yang sticky. Local berguna untuk elemen dengan overflow scroll seperti panel atau kotak teks yang panjang. Kombinasi fixed dengan background-size cover dan background-position center menghasilkan efek latar penuh yang populer.

## Contoh Kode Implementasi

```css
/* Default - scroll bersama konten */
.scroll-attachment {
  background-image: url('pattern.png');
  background-attachment: scroll;
  height: 300px;
}

/* Fixed - tetap diam saat discroll */
.fixed-bg {
  background-image: url('mountains.jpg');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  height: 100vh;
}

/* Parallax sederhana dengan fixed */
.parallax-section {
  background-image: url('parallax-bg.jpg');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  height: 500px;
  display: flex;
  align-items: center;
  justify-content: center;
}

/* Local - bergulir dengan konten elemen */
.local-attachment {
  background-image: url('scroll-pattern.png');
  background-attachment: local;
  height: 300px;
  overflow-y: scroll;
}

/* Konten di atas fixed background */
.content-overlay {
  background-color: rgba(255, 255, 255, 0.8);
  padding: 40px;
  position: relative;
  z-index: 1;
}

/* Multiple backgrounds dengan attachment berbeda */
.multiple-attachment {
  background-image: url('stars.png'), url('sky.jpg');
  background-size: auto, cover;
  background-attachment: fixed, scroll;
  height: 600px;
}

/* Hero section dengan fixed */
.hero-fixed {
  background-image: url('hero-bg.jpg');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  min-height: 80vh;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
}
```

## Poin Penting
- scroll (default): gambar latar bergerak bersama konten saat digulir
- fixed: gambar latar tetap diam di viewport saat halaman digulir (efek parallax)
- local: gambar latar bergulir bersama konten elemen jika elemen memiliki scroll sendiri
- background-attachment fixed membutuhkan background-size cover untuk efek latar penuh yang optimal
