# Properti background-size dengan nilai auto, cover, contain, dan ukuran spesifik

## Analogi: Perpustakaan Digital

Seperti mencetak foto untuk pigura, background-size menentukan bagaimana gambar latar disesuaikan ukurannya. Apakah foto dicetak sesuai ukuran asli (auto), diperbesar untuk memenuhi seluruh pigura (cover), atau diperkecil agar seluruh foto terlihat (contain)? Dalam perpustakaan digital, properti ini memastikan gambar latar tampil proporsional dan sesuai dengan desain yang diinginkan.

## Penjelasan Detail

Properti background-size mengontrol ukuran gambar latar belakang. Nilai auto menggunakan ukuran asli gambar. cover memperbesar atau memperkecil gambar untuk menutupi seluruh area elemen, bagian gambar yang melampaui akan terpotong. contain memperbesar atau memperkecil gambar agar seluruh gambar terlihat dalam area elemen, mungkin menyisakan ruang kosong. Nilai dapat juga berupa satuan panjang (px, em) atau persentase. Satu nilai akan diterapkan untuk lebar, tinggi otomatis proporsional. Dua nilai menentukan lebar dan tinggi secara terpisah. Properti ini sangat penting untuk membuat gambar latar yang responsif. cover biasanya digunakan untuk hero section, contain untuk logo atau ikon latar.

## Contoh Kode Implementasi

```css
/* Ukuran asli gambar */
.auto-size {
  background-image: url('pattern.png');
  background-size: auto;
  height: 300px;
}

/* Cover - memenuhi area, terpotong jika perlu */
.cover-bg {
  background-image: url('hero.jpg');
  background-size: cover;
  background-position: center;
  height: 500px;
}

/* Contain - seluruh gambar terlihat */
.contain-bg {
  background-image: url('logo.svg');
  background-repeat: no-repeat;
  background-size: contain;
  background-position: center;
  height: 200px;
}

/* Ukuran spesifik dengan px */
.fixed-size {
  background-image: url('icon.png');
  background-repeat: no-repeat;
  background-size: 50px 50px;
  padding-left: 60px;
}

/* Ukuran dengan persentase */
.percentage-size {
  background-image: url('bg.jpg');
  background-size: 80% auto;
  background-repeat: no-repeat;
  background-position: center;
  height: 300px;
}

/* Cover untuk full-screen hero */
.full-hero {
  background-image: url('hero-large.jpg');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
  height: 100vh;
}

/* Multiple backgrounds dengan size berbeda */
.multiple-size {
  background-image: url('icon.svg'), url('bg.jpg');
  background-repeat: no-repeat, no-repeat;
  background-size: 50px, cover;
  background-position: 20px 20px, center;
  height: 400px;
}

/* Responsive background */
.hero-section {
  background-image: url('hero.jpg');
  background-size: cover;
  background-position: center;
  height: 60vh;
}

@media (max-width: 600px) {
  .hero-section {
    background-size: contain;
    background-color: #333;
  }
}
```

## Poin Penting
- cover memperbesar gambar hingga menutupi seluruh area (mungkin terpotong); contain memastikan seluruh gambar terlihat
- auto menggunakan ukuran asli gambar; satuan spesifik memberikan kontrol penuh atas dimensi
- background-size sangat penting untuk membuat gambar latar yang responsif
- Kombinasikan dengan background-position untuk mengontrol area fokus saat menggunakan cover
