# Properti background-repeat dengan nilai repeat, no-repeat, repeat-x, dan repeat-y

## Analogi: Perpustakaan Digital

Seperti ubin lantai perpustakaan yang dipasang berulang, properti background-repeat mengontrol bagaimana gambar latar belakang diulang. Apakah ubin dipasang di seluruh lantai (repeat), hanya satu baris (repeat-x), hanya satu kolom (repeat-y), atau cukup satu ubin saja (no-repeat). Setiap pola memberikan tampilan yang berbeda pada ruangan perpustakaan digital.

## Penjelasan Detail

Properti background-repeat menentukan bagaimana gambar latar belakang diulang jika ukurannya lebih kecil dari elemen. Nilai repeat (default) mengulang gambar baik secara horizontal maupun vertikal hingga memenuhi elemen. no-repeat menampilkan gambar hanya sekali. repeat-x mengulang hanya secara horizontal. repeat-y mengulang hanya secara vertikal. Nilai lain seperti space menambahkan ruang antar gambar yang diulang, round menyesuaikan ukuran gambar agar pas tanpa terpotong. Properti ini sangat penting untuk mengontrol tampilan pola, tekstur, dan gambar latar yang tidak ingin diulang. Kombinasi dengan background-position dan background-size memberikan kontrol penuh atas penempatan gambar latar.

## Contoh Kode Implementasi

```css
/* Repeat default - diulang di kedua arah */
.repeat-all {
  background-image: url('pattern.png');
  background-repeat: repeat;
}

/* Tidak diulang */
.no-repeat {
  background-image: url('logo-large.png');
  background-repeat: no-repeat;
  height: 300px;
}

/* Diulang horizontal saja */
.repeat-x {
  background-image: url('divider.png');
  background-repeat: repeat-x;
  height: 50px;
}

/* Diulang vertikal saja */
.repeat-y {
  background-image: url('stripes.png');
  background-repeat: repeat-y;
  width: 100px;
  height: 400px;
}

/* Space - menambah ruang agar gambar pas */
.space-repeat {
  background-image: url('dot.png');
  background-repeat: space;
  height: 200px;
}

/* Round - menyesuaikan ukuran gambar */
.round-repeat {
  background-image: url('tile.png');
  background-repeat: round;
  height: 200px;
}

/* Kombinasi no-repeat dengan posisi */
.positioned-bg {
  background-image: url('icon.png');
  background-repeat: no-repeat;
  background-position: right center;
  padding-right: 50px;
}

/* Header dengan garis bawah berulang */
.header-divider {
  background-image: url('line.png');
  background-repeat: repeat-x;
  background-position: bottom;
  padding-bottom: 10px;
}

/* Nilai default untuk elemen baru */
.default-repeat {
  background-image: url('default-pattern.png');
  /* background-repeat: repeat; default */
}
```

## Poin Penting
- repeat (default) mengulang gambar di kedua sumbu; no-repeat menampilkan sekali saja
- repeat-x mengulang horizontal; repeat-y mengulang vertikal
- Nilai space dan round memberikan kontrol lebih untuk pola yang presisi
- Kombinasikan dengan background-position untuk mengontrol titik awal pengulangan
