# Shorthand background untuk menuliskan semua properti latar belakang sekaligus

## Analogi: Perpustakaan Digital

Seperti memesan dekorasi ruangan lengkap dalam satu formulir, shorthand background menggabungkan semua properti latar belakang dalam satu deklarasi. Daripada mengisi formulir terpisah untuk warna dinding, wallpaper, posisi, ukuran, dan pengulangan, kita cukup menulis semuanya dalam satu baris. Ini menghemat waktu dan membuat kode lebih rapi seperti katalog perpustakaan yang terorganisir.

## Penjelasan Detail

Shorthand background memungkinkan pengaturan background-color, background-image, background-repeat, background-attachment, background-position, dan background-size dalam satu deklarasi. Urutan penulisan yang umum adalah color image repeat attachment position/size. background-size harus ditulis setelah background-position dan dipisahkan dengan garis miring (/). Jika ada nilai yang tidak ditentukan, nilai default-nya akan digunakan. Shorthand ini dapat digunakan untuk multiple backgrounds dengan memisahkan每组 menggunakan koma. Menggunakan shorthand membuat kode lebih bersih, tetapi urutan dan sintaksnya harus tepat. Shorthand background tidak mencakup background-origin dan background-clip yang harus ditulis terpisah.

## Contoh Kode Implementasi

```css
/* Shorthand background lengkap */
.hero {
  background: #333 url('hero.jpg') no-repeat fixed center / cover;
  height: 500px;
}

/* Urutan: color image repeat attachment position / size */
.card {
  background: #f8f9fa url('pattern.png') repeat-x scroll left top / auto;
  padding: 20px;
}

/* Tanpa gambar - hanya warna */
.bg-color-only {
  background: #3498db;
  color: white;
  padding: 20px;
}

/* Dengan gradien */
.gradient-box {
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  padding: 40px;
  color: white;
}

/* Multiple backgrounds dengan shorthand */
.multiple-bg {
  background:
    url('overlay.png') no-repeat center / contain,
    #2c3e50 url('bg.jpg') repeat-x scroll left top / cover;
  height: 400px;
}

/* Shorthand minimal */
.minimal-bg {
  background: url('icon.svg') no-repeat;
  padding-left: 40px;
}

/* Shorthand untuk button */
.btn-primary {
  background: #007bff url('arrow.svg') no-repeat right 10px center / 16px;
  padding: 10px 35px 10px 15px;
  color: white;
  border: none;
}

/* Shorthand tanpa attachment */
.simple-bg {
  background: #ecf0f1 url('pattern.png') repeat;
}
```

## Poin Penting
- Urutan shorthand background: color image repeat attachment position / size
- background-size harus didahului background-position dengan pemisah garis miring (/)
- Setiap properti yang tidak disebut akan menggunakan nilai default-nya
- Shorthand mendukung multiple backgrounds dengan memisahkan每组 menggunakan koma
