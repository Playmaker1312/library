# Gradien radial menggunakan fungsi radial-gradient dengan bentuk dan warna

## Analogi: Perpustakaan Digital

Seperti lampu sorot di perpustakaan yang menyebar melingkar dari titik fokus, gradien radial menyebar dari satu titik pusat ke segala arah. Bayangkan cahaya lampu baca yang menerangi area melingkar di sekitar meja, semakin jauh dari pusat semakin redup. Gradien radial menciptakan transisi warna yang menyebar secara radial dari pusat atau titik tertentu.

## Penjelasan Detail

Fungsi radial-gradient() menghasilkan transisi warna yang menyebar dari satu titik pusat ke luar secara melingkar atau elips. Bentuk dapat berupa circle (lingkaran) atau ellipse (elips, default). Ukuran dapat ditentukan dengan kata kunci (closest-side, farthest-side, closest-corner, farthest-corner) atau satuan panjang. Posisi pusat ditentukan dengan at the diikuti posisi (center, top left, 50% 50%, dll.). Warna dan color stops bekerja seperti pada linear-gradient. Ellipse adalah default dan akan menyesuaikan dengan dimensi elemen. Gradien radial sering digunakan untuk efek sorotan, cahaya, tombol dengan efek 3D, dan latar belakang yang dramatis.

## Contoh Kode Implementasi

```css
/* Gradien radial dasar dari pusat */
.basic-radial {
  background: radial-gradient(circle, #3498db, #2c3e50);
  height: 300px;
}

/* Ellipse default */
.ellipse-gradient {
  background: radial-gradient(#e74c3c, #c0392b);
  height: 200px;
  width: 400px;
}

/* Posisi pusat ditentukan */
.positioned-radial {
  background: radial-gradient(circle at top left, #f39c12, #e67e22);
  height: 300px;
}

/* Ukuran dengan closest-side */
.closest-side {
  background: radial-gradient(circle closest-side, #2ecc71, #27ae60, #1abc9c);
  height: 300px;
}

/* farthest-corner */
.farthest-corner {
  background: radial-gradient(ellipse farthest-corner at 30% 40%, #9b59b6, #8e44ad);
  height: 300px;
}

/* Tiga warna */
.three-color-radial {
  background: radial-gradient(circle, #3498db 0%, #9b59b6 50%, #e74c3c 100%);
  height: 300px;
}

/* Efek spotlight */
.spotlight {
  background: radial-gradient(circle at 50% 30%, rgba(255,255,255,0.8) 0%, rgba(0,0,0,0.6) 100%);
  height: 400px;
}

/* Ukuran dengan satuan */
sized-radial {
  background: radial-gradient(100px 50px at center, #f1c40f, #e67e22);
  height: 300px;
}

/* Multiple radial gradients */
.multiple-radial {
  background:
    radial-gradient(circle at 20% 80%, rgba(231,76,60,0.3) 0%, transparent 50%),
    radial-gradient(circle at 80% 20%, rgba(52,152,219,0.3) 0%, transparent 50%);
  height: 400px;
}
```

## Poin Penting
- radial-gradient menyebar dari titik pusat ke luar dalam bentuk lingkaran atau elips
- Bentuk default adalah ellipse yang menyesuaikan dengan dimensi elemen
- Posisi pusat diatur dengan at the (default center); ukuran dengan closest-side, farthest-corner, dll.
- Gradien radial cocok untuk efek sorotan, tombol 3D, dan latar belakang dramatis
