# Properti background-position untuk mengatur posisi gambar latar belakang

## Analogi: Perpustakaan Digital

Seperti menggantung lukisan di dinding perpustakaan, properti background-position menentukan di mana gambar latar ditempatkan. Apakah lukisan dipasang di tengah dinding, di pojok kiri atas, atau di sisi kanan? Dalam perpustakaan digital, kita dapat memposisikan gambar latar dengan presisi menggunakan kata kunci, persentase, atau satuan panjang.

## Penjelasan Detail

Properti background-position mengatur posisi awal gambar latar belakang relatif terhadap area elemen. Nilai dapat berupa kata kunci (top, right, bottom, left, center), persentase, atau satuan panjang (px, em). Dengan dua nilai, nilai pertama menentukan posisi horizontal dan nilai kedua vertikal. Satu nilai akan digunakan untuk kedua sumbu jika nilai kedua tidak ditentukan. Persentase 0% 0% berarti pojok kiri atas, 100% 100% berarti pojok kanan bawah, 50% 50% berarti tengah. Satuan panjang menggeser gambar dari pojok kiri atas. Properti ini bekerja bersama background-repeat untuk mengontrol bagaimana gambar diposisikan. background-position sangat berguna untuk memfokuskan bagian tertentu dari gambar latar, seperti memusatkan wajah pada foto profil.

## Contoh Kode Implementasi

```css
/* Kata kunci posisi */
.center-center {
  background-image: url('photo.jpg');
  background-repeat: no-repeat;
  background-position: center center;
  height: 400px;
}

/* Pojok kanan bawah */
.right-bottom {
  background-image: url('watermark.png');
  background-repeat: no-repeat;
  background-position: right bottom;
  height: 300px;
}

/* Posisi dengan persentase */
.percentage-position {
  background-image: url('bg.jpg');
  background-repeat: no-repeat;
  background-position: 25% 75%;
  height: 300px;
}

/* Posisi dengan satuan panjang */
.pixel-position {
  background-image: url('icon.png');
  background-repeat: no-repeat;
  background-position: 20px 30px;
  padding-left: 60px;
}

/* Posisi tengah untuk hero section */
.hero {
  background-image: url('hero-image.jpg');
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
  height: 500px;
}

/* Multiple background dengan posisi berbeda */
.multiple-position {
  background-image: url('overlay.png'), url('bg.jpg');
  background-repeat: no-repeat, no-repeat;
  background-position: center, top left;
  background-size: contain, cover;
  height: 400px;
}

/* Posisi dengan offset dari tepi */
.offset-position {
  background-image: url('badge.svg');
  background-repeat: no-repeat;
  background-position: right 20px top 20px;
  height: 200px;
}

/* Background pada tombol dengan ikon */
.btn-icon {
  background-image: url('arrow-right.svg');
  background-repeat: no-repeat;
  background-position: right 10px center;
  padding-right: 35px;
}
```

## Poin Penting
- background-position menggunakan dua nilai: horizontal lalu vertikal (kata kunci, persentase, atau satuan)
- Persentase 0% 0% = kiri atas, 50% 50% = tengah, 100% 100% = kanan bawah
- Kombinasikan dengan background-repeat: no-repeat untuk hasil yang paling terkontrol
- background-position penting untuk memfokuskan area tertentu dari gambar latar yang besar
