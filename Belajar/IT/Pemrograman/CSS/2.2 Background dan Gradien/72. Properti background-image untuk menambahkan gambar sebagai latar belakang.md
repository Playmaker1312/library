# Properti background-image untuk menambahkan gambar sebagai latar belakang

## Analogi: Perpustakaan Digital

Seperti wallpaper atau mural di dinding perpustakaan, background-image menambahkan gambar sebagai latar belakang elemen. Gambar ini bisa menjadi hiasan dinding yang indah, tekstur kayu, atau pola geometris. Dalam perpustakaan digital, background-image memberikan dimensi visual tambahan yang membuat halaman web lebih menarik dan ekspresif.

## Penjelasan Detail

Properti background-image menetapkan satu atau lebih gambar sebagai latar belakang elemen. Gambar ditentukan menggunakan fungsi url() dengan path ke file gambar. Secara default, gambar akan ditempatkan di pojok kiri atas elemen dan diulang (repeat) untuk memenuhi seluruh area. background-image dapat dikombinasikan dengan properti background-repeat, background-position, dan background-size untuk mengontrol perilaku gambar. Beberapa gambar dapat ditumpuk dengan memisahkan nilai menggunakan koma, gambar pertama berada di lapisan paling atas. Jika gambar gagal dimuat, background-color akan ditampilkan sebagai fallback. Selain gambar raster, background-image juga dapat menggunakan fungsi gradien CSS.

## Contoh Kode Implementasi

```css
/* Gambar latar belakang sederhana */
.hero {
  background-image: url('hero-bg.jpg');
  height: 400px;
  color: white;
}

/* Gambar dengan fallback color */
.card {
  background-color: #f8f9fa;
  background-image: url('pattern.png');
  padding: 20px;
}

/* Mengontrol pengulangan gambar */
.no-repeat {
  background-image: url('logo.png');
  background-repeat: no-repeat;
  padding: 20px;
}

/* Beberapa gambar latar belakang */
.multiple-bg {
  background-image: url('overlay.png'), url('background.jpg');
  background-repeat: no-repeat, repeat;
  background-position: center, top left;
  min-height: 300px;
}

/* Menggunakan gradien sebagai background-image */
.gradient-bg {
  background-image: linear-gradient(to bottom, #3498db, #2c3e50);
  height: 200px;
  color: white;
}

/* Background dengan ikon */
.icon-bg {
  background-image: url('icon-search.svg');
  background-repeat: no-repeat;
  background-position: 10px center;
  padding-left: 40px;
}

/* Responsive background */
.responsive-hero {
  background-image: url('hero-desktop.jpg');
  background-size: cover;
  background-position: center;
  height: 500px;
}

@media (max-width: 768px) {
  .responsive-hero {
    background-image: url('hero-mobile.jpg');
  }
}

/* Background transparan menggunakan PNG */
.transparent-overlay {
  background-image: url('transparent-pattern.png');
  background-repeat: repeat;
}
```

## Poin Penting
- background-image menggunakan fungsi url() untuk merujuk file gambar sebagai latar belakang
- Gambar latar belakang secara default diulang (repeat) untuk memenuhi area elemen
- Beberapa gambar dapat ditumpuk dengan memisahkan menggunakan koma
- Selalu berikan background-color sebagai fallback jika gambar gagal dimuat
