# Properti background-color untuk mengatur warna latar belakang elemen

## Analogi: Perpustakaan Digital

Seperti warna dinding perpustakaan yang menentukan suasana ruangan, background-color mengatur warna latar belakang elemen. Dinding berwarna cerah membuat ruangan terasa terang dan luas, sedangkan warna gelap memberikan kesan hangat dan intim. Dalam perpustakaan digital, background-color menjadi kanvas dasar yang membentuk mood dan keterbacaan halaman web.

## Penjelasan Detail

Properti background-color mengisi latar belakang elemen dengan warna solid. Nilai dapat menggunakan semua format warna CSS: nama warna (red, blue), hexadecimal (#ff0000), RGB (rgb(255,0,0)), RGBA (rgba(255,0,0,0.5)), HSL, HSLA, atau kata kunci transparent. Nilai defaultnya adalah transparent. Warna latar belakang akan mengisi area konten, padding, dan border (jika border memiliki celah). background-color dapat diwarisi secara visual melalui opacity, tetapi tidak diwarisi secara properti. Properti ini sering digunakan bersama properti background lainnya. RGBA dan HSLA memungkinkan latar belakang dengan efek transparan yang berbeda dari opacity karena hanya mempengaruhi latar belakang, bukan konten elemen.

## Contoh Kode Implementasi

```css
/* Warna dasar dengan nama */
.box-red {
  background-color: red;
  padding: 20px;
  color: white;
}

/* Hexadecimal */
.box-hex {
  background-color: #3498db;
  padding: 20px;
  color: white;
}

/* RGB */
.box-rgb {
  background-color: rgb(46, 204, 113);
  padding: 20px;
  color: white;
}

/* RGBA dengan transparansi */
.box-rgba {
  background-color: rgba(231, 76, 60, 0.7);
  padding: 20px;
  color: white;
}

/* HSL */
.box-hsl {
  background-color: hsl(204, 64%, 44%);
  padding: 20px;
  color: white;
}

/* HSLA */
.box-hsla {
  background-color: hsla(39, 100%, 50%, 0.8);
  padding: 20px;
  color: white;
}

/* Transparan */
.box-transparent {
  background-color: transparent;
  padding: 20px;
  border: 2px solid #333;
}

/* Background pada body */
body {
  background-color: #f5f5f5;
}

/* Background pada section */
section {
  background-color: #ffffff;
  padding: 40px;
  margin: 20px 0;
}

/* Header dengan background */
header {
  background-color: #2c3e50;
  color: white;
  padding: 20px;
}

/* Footer */
footer {
  background-color: #34495e;
  color: #ecf0f1;
  padding: 30px;
}
```

## Poin Penting
- background-color mengisi latar belakang elemen termasuk area konten dan padding
- Gunakan RGBA atau HSLA untuk latar belakang transparan tanpa mempengaruhi konten elemen
- Nilai default background-color adalah transparent, bukan putih
- background-color sering digunakan sebagai fallback ketika background-image gagal dimuat
