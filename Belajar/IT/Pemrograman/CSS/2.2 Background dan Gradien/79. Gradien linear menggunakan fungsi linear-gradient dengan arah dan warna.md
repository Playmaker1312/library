# Gradien linear menggunakan fungsi linear-gradient dengan arah dan warna

## Analogi: Perpustakaan Digital

Bayangkan langit senja di jendela perpustakaan yang berubah warna dari biru di atas menjadi jingga di bawah. Gradien linear adalah transisi warna yang mulus dalam satu arah, seperti warna buku di rak yang berangsur berubah dari kiri ke kanan. Dalam perpustakaan digital, gradien linear menciptakan transisi warna yang halus tanpa perlu file gambar.

## Penjelasan Detail

Fungsi linear-gradient() menghasilkan transisi warna yang mulus sepanjang garis lurus. Arah gradien ditentukan oleh kata kunci (to top, to right, to bottom, to left, to top right, dll.) atau sudut dalam derajat (0deg = ke atas, 90deg = ke kanan, 180deg = ke bawah, 270deg = ke kiri). Warna didefinisikan sebagai parameter dengan minimal dua warna. Color stops dapat ditambahkan dengan posisi dalam persentase atau satuan panjang untuk menentukan di mana transisi warna terjadi. Tanpa posisi, warna akan didistribusikan secara merata. Gradien adalah tipe data gambar CSS sehingga dapat digunakan di mana pun background-image diterima. Gradien dapat dikombinasikan dengan properti background lainnya termasuk multiple backgrounds.

## Contoh Kode Implementasi

```css
/* Gradien dasar atas ke bawah */
.basic-gradient {
  background: linear-gradient(to bottom, #3498db, #2c3e50);
  height: 200px;
  color: white;
}

/* Gradien kiri ke kanan */
.left-right {
  background: linear-gradient(to right, #e74c3c, #f39c12);
  height: 200px;
}

/* Gradien diagonal */
.diagonal {
  background: linear-gradient(135deg, #667eea, #764ba2);
  height: 200px;
  color: white;
}

/* Gradien dengan sudut dalam deg */
.angle-gradient {
  background: linear-gradient(45deg, #2ecc71, #3498db);
  height: 200px;
}

/* Tiga warna */
.three-colors {
  background: linear-gradient(to right, #e74c3c, #f39c12, #2ecc71);
  height: 150px;
}

/* Color stops dengan posisi */
.position-stops {
  background: linear-gradient(to right, #3498db 0%, #9b59b6 50%, #e74c3c 100%);
  height: 200px;
}

/* Hard stop - tanpa transisi */
.hard-stop {
  background: linear-gradient(to right, #3498db 50%, #e74c3c 50%);
  height: 150px;
}

/* Gradien transparan */
.transparent-gradient {
  background: linear-gradient(to bottom, rgba(0,0,0,0), rgba(0,0,0,0.8));
  height: 300px;
}

/* Gradien untuk teks overlay */
.hero-overlay {
  background: linear-gradient(to top, rgba(0,0,0,0.7) 0%, transparent 50%);
  height: 400px;
}
```

## Poin Penting
- Arah gradien ditentukan dengan kata kunci (to bottom, to right) atau sudut dalam derajat (0-360)
- Minimal dua warna diperlukan, dapat ditambahkan lebih banyak dengan color stops
- Color stops dapat diberi posisi dalam persentase untuk mengontrol titik transisi
- Gradien adalah tipe data gambar sehingga dapat digunakan di properti background dan sumber gambar lainnya
