# Properti background-origin untuk menentukan area asal posisi latar belakang

## Analogi: Perpustakaan Digital

Seperti menentukan apakah wallpaper dimulai dari tepi dinding (border), dari tepi cat (padding), atau dari tepi ruangan display (konten), background-origin menentukan titik awal referensi untuk gambar latar belakang. Bayangkan memasang stiker di buku: apakah stiker ditempel di sampul (border), di halaman depan (padding), atau di tengah halaman isi (content)?

## Penjelasan Detail

Properti background-origin menentukan area posisi awal background-image relatif terhadap border-box, padding-box, atau content-box. Nilai border-box memulai gambar dari tepi luar border. Nilai padding-box (default) memulai gambar dari tepi luar padding. Nilai content-box memulai gambar dari tepi area konten. Properti ini mempengaruhi bagaimana background-position menghitung posisi awal. background-origin tidak berpengaruh jika background-attachment bernilai fixed. Properti ini bekerja bersama background-clip yang menentukan area pemotongan latar belakang. background-origin berguna ketika ingin gambar latar dimulai dari area tertentu tanpa terpotong oleh border atau padding.

## Contoh Kode Implementasi

```css
/* Default - padding-box */
.default-origin {
  background-image: url('pattern.png');
  background-origin: padding-box;
  border: 10px solid rgba(0,0,0,0.3);
  padding: 20px;
  height: 200px;
}

/* border-box - gambar dari tepi border */
.border-origin {
  background-image: url('pattern.png');
  background-origin: border-box;
  border: 10px solid rgba(0,0,0,0.3);
  padding: 20px;
  height: 200px;
}

/* content-box - gambar dari tepi konten */
.content-origin {
  background-image: url('pattern.png');
  background-origin: content-box;
  border: 10px solid rgba(0,0,0,0.3);
  padding: 20px;
  height: 200px;
}

/* Membandingkan ketiganya */
.comparison {
  display: flex;
  gap: 20px;
}

.comparison > div {
  width: 200px;
  height: 200px;
  border: 15px solid rgba(231,76,60,0.5);
  padding: 25px;
  background-image: url('logo.png');
  background-repeat: no-repeat;
}

.border-box {
  background-origin: border-box;
}

.padding-box {
  background-origin: padding-box;
}

.content-box {
  background-origin: content-box;
}

/* Tidak berpengaruh jika background-attachment fixed */
.fixed-bg {
  background-image: url('hero.jpg');
  background-attachment: fixed;
  background-origin: content-box; /* tidak berpengaruh */
  height: 300px;
}
```

## Poin Penting
- background-origin menentukan area referensi posisi awal background-image: border-box, padding-box (default), atau content-box
- background-origin mempengaruhi bagaimana background-position menghitung posisi awal gambar
- background-origin tidak berpengaruh jika background-attachment bernilai fixed
- Properti ini berbeda dengan background-clip yang menentukan area pemotongan, bukan area awal
