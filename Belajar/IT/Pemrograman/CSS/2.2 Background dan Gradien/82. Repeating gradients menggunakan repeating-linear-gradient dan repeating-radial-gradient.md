# Repeating gradients menggunakan repeating-linear-gradient dan repeating-radial-gradient

## Analogi: Perpustakaan Digital

Bayangkan pola lantai perpustakaan dengan ubin yang polanya berulang terus-menerus. Repeating gradients melakukan hal yang sama untuk gradien: mengulang pola gradien secara terus-menerus. Jika gradien biasa berhenti setelah satu siklus warna, repeating gradients akan terus mengulang pola yang sama seperti wallpaper dengan motif berulang di dinding perpustakaan.

## Penjelasan Detail

Fungsi repeating-linear-gradient() dan repeating-radial-gradient() bekerja seperti linear-gradient dan radial-gradient, tetapi pola warnanya akan diulang secara terus-menerus untuk memenuhi area elemen. Kunci dari repeating gradients adalah menentukan color stops terakhir sehingga pola dapat diulang dengan mulus. Jika color stops tidak mencakup 100%, pola akan diulang dari awal. Repeating gradients berguna untuk membuat pola garis-garis, kotak-kotak, zebra stripe, dan tekstur berulang tanpa gambar eksternal. Penggunaan yang umum termasuk membuat progress bar, tabel dengan baris bergantian, dan latar belakang pola.

## Contoh Kode Implementasi

```css
/* Stripe horizontal berulang */
.horizontal-stripes {
  background: repeating-linear-gradient(
    to bottom,
    #3498db 0px,
    #3498db 20px,
    #2c3e50 20px,
    #2c3e50 40px
  );
  height: 300px;
}

/* Stripe vertikal */
.vertical-stripes {
  background: repeating-linear-gradient(
    to right,
    #e74c3c 0px,
    #e74c3c 15px,
    #c0392b 15px,
    #c0392b 30px
  );
  height: 200px;
}

/* Stripe diagonal */
.diagonal-stripes {
  background: repeating-linear-gradient(
    45deg,
    #f39c12 0px,
    #f39c12 10px,
    #e67e22 10px,
    #e67e22 20px
  );
  height: 200px;
}

/* Zebra stripe untuk tabel */
.zebra-background {
  background: repeating-linear-gradient(
    to bottom,
    #f8f9fa 0px,
    #f8f9fa 40px,
    #e9ecef 40px,
    #e9ecef 80px
  );
}

/* Repeating radial gradient */
.repeating-radial {
  background: repeating-radial-gradient(
    circle,
    #2ecc71 0px,
    #2ecc71 10px,
    #27ae60 10px,
    #27ae60 20px
  );
  height: 300px;
}

/* Target pattern */
.target-pattern {
  background: repeating-radial-gradient(
    circle,
    #3498db 0px,
    #3498db 5px,
    transparent 5px,
    transparent 15px
  );
  height: 300px;
}

/* Checkerboard pattern */
.checkerboard {
  background:
    repeating-linear-gradient(45deg, transparent, transparent 10px, rgba(0,0,0,0.05) 10px, rgba(0,0,0,0.05) 20px),
    repeating-linear-gradient(-45deg, transparent, transparent 10px, rgba(0,0,0,0.05) 10px, rgba(0,0,0,0.05) 20px);
  height: 300px;
}

/* Progress bar pattern */
.progress-striped {
  background: repeating-linear-gradient(
    45deg,
    transparent 0px,
    transparent 5px,
    rgba(255,255,255,0.2) 5px,
    rgba(255,255,255,0.2) 10px
  );
}
```

## Poin Penting
- repeating-linear-gradient dan repeating-radial-gradient mengulang pola warna secara terus-menerus
- Color stops harus mencakup satu siklus penuh agar pola dapat diulang dengan mulus
- Berguna untuk membuat pola garis, kotak, zebra stripe, dan tekstur tanpa file gambar
- Kombinasikan dengan multiple backgrounds untuk pola yang lebih kompleks
