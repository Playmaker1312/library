# Properti align-content untuk mengatur penyelarasan baris flex saat ada beberapa baris

## Analogi: Perpustakaan Digital

Ketika buku-buku dalam rak terlalu banyak sehingga harus dilanjutkan ke baris-baris baru, kamu bisa mengatur bagaimana baris-baris tersebut didistribusikan secara vertikal. Apakah semua baris dikumpulkan di atas, di tengah, di bawah, atau diberi jarak merata. Properti ini hanya aktif ketika ada lebih dari satu baris flex items—mirip seperti mengatur spasi antar baris paragraf dalam dokumen.

## Penjelasan Detail

`align-content` adalah properti pada flex container yang mengatur distribusi ruang antar baris flex pada cross axis, tetapi hanya ketika ada beberapa baris (yaitu `flex-wrap` diatur ke `wrap` atau `wrap-reverse`). Jika hanya ada satu baris, properti ini tidak berpengaruh. Nilai-nilainya mirip dengan `justify-content`: `flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`, dan `stretch` (default). `stretch` membuat baris meregang untuk mengisi ruang kosong. `space-between` dan `space-around` berguna untuk mendistribusikan baris secara merata. Properti ini berbeda dari `align-items` yang mengatur posisi item dalam satu baris, sementara `align-content` mengatur posisi antar baris.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  flex-flow: row wrap;
  align-content: center;
  height: 300px;
  border: 2px solid #333;
  padding: 8px;
  margin-bottom: 12px;
}

.stretch     { align-content: stretch; }
.flex-start  { align-content: flex-start; }
.flex-end    { align-content: flex-end; }
.center      { align-content: center; }
.space-between { align-content: space-between; }
.space-around  { align-content: space-around; }

.item {
  background: #FF5722;
  color: white;
  padding: 16px 24px;
  margin: 4px;
  width: 120px;
}
```

## Poin Penting
- `align-content` hanya berfungsi jika ada beberapa baris flex items
- Memerlukan `flex-wrap: wrap` atau `wrap-reverse` untuk aktif
- Nilai `stretch` adalah default, meregangkan baris mengisi container
- Mirip dengan `justify-content` tetapi pada cross axis antar baris
- Berbeda dengan `align-items` yang mengatur dalam satu baris
