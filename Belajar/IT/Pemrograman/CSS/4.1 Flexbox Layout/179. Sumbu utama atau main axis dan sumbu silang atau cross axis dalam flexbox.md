# Sumbu utama atau main axis dan sumbu silang atau cross axis dalam flexbox

## Analogi: Perpustakaan Digital

Bayangkan sebuah rak buku yang memiliki dua arah pengaturan: arah utama tempat buku-buku berjejer (misalnya ke samping) dan arah silang yang tegak lurus (misalnya ke atas-bawah). Jika rak diatur agar buku berjejer horizontal, maka sumbu utama adalah horizontal dan sumbu silang adalah vertikal. Jika rak diputar agar buku bertumpuk vertikal, maka sumbu utama menjadi vertikal dan sumbu silang menjadi horizontal. Konsep dua sumbu ini menjadi dasar bagaimana semua properti Flexbox bekerja.

## Penjelasan Detail

Flexbox memiliki dua sumbu: main axis (sumbu utama) dan cross axis (sumbu silang), yang selalu saling tegak lurus. Arah main axis ditentukan oleh properti `flex-direction`. Jika `flex-direction` bernilai `row` atau `row-reverse`, main axis adalah horizontal (inline axis) dan cross axis adalah vertikal (block axis). Jika bernilai `column` atau `column-reverse`, main axis adalah vertikal dan cross axis adalah horizontal. Pemahaman ini krusial karena properti `justify-content` selalu bekerja pada main axis, sementara `align-items` dan `align-self` bekerja pada cross axis. Mengetahui sumbu mana yang sedang aktif membantu kamu memilih properti yang tepat untuk menyelaraskan item.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  flex-direction: row; /* Main axis: horizontal, Cross axis: vertical */
  justify-content: center; /* Bekerja pada main axis */
  align-items: center;     /* Bekerja pada cross axis */
  height: 200px;
  border: 2px solid #333;
}

.container-column {
  display: flex;
  flex-direction: column; /* Main axis: vertical, Cross axis: horizontal */
  justify-content: center; /* Bekerja pada main axis (vertikal) */
  align-items: center;     /* Bekerja pada cross axis (horizontal) */
  height: 200px;
  border: 2px solid #666;
  margin-top: 12px;
}

.item {
  background: #E91E63;
  color: white;
  padding: 12px;
  margin: 4px;
}
```

## Poin Penting
- Main axis ditentukan oleh `flex-direction`—bisa horizontal (row) atau vertikal (column)
- Cross axis selalu tegak lurus dengan main axis
- `justify-content` mengatur penyelarasan pada main axis
- `align-items` dan `align-self` mengatur penyelarasan pada cross axis
- Memahami kedua sumbu ini adalah kunci untuk menguasai Flexbox
