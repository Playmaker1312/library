# Properti flex-direction dengan nilai row, row-reverse, column, dan column-reverse

## Analogi: Perpustakaan Digital

Di perpustakaan digital, kamu bisa memilih bagaimana buku-buku ditata dalam rak: berjejer dari kiri ke kanan seperti rak biasa, dari kanan ke kiri seperti rak bahasa Arab, bertumpuk ke bawah seperti lemari arsip, atau dari bawah ke atas seperti tumpukan buku terbalik. Setiap mode ini mengubah arah utama rak, dan semua buku akan menyesuaikan posisinya sesuai arah yang dipilih.

## Penjelasan Detail

`flex-direction` adalah properti pada flex container yang menentukan arah main axis, yaitu arah di mana flex items ditempatkan. Nilai `row` (default) menempatkan item dari kiri ke kanan. `row-reverse` membalik urutan dari kanan ke kiri, dan konten juga dibalik secara visual. `column` menempatkan item dari atas ke bawah. `column-reverse` membalik urutan dari bawah ke atas. Selain mengubah arah, nilai `*-reverse` juga membalik urutan item, yang berbeda dengan sekadar mengubah posisi. Perubahan `flex-direction` juga memengaruhi bagaimana properti `justify-content` dan `align-items` bekerja karena main axis dan cross axis ikut berubah.

## Contoh Kode Implementasi

```css
.row {
  display: flex;
  flex-direction: row;
}

.row-reverse {
  display: flex;
  flex-direction: row-reverse;
}

.column {
  display: flex;
  flex-direction: column;
}

.column-reverse {
  display: flex;
  flex-direction: column-reverse;
}

.item {
  background: #3F51B5;
  color: white;
  padding: 12px 20px;
  margin: 4px;
  border-radius: 4px;
}
```

## Poin Penting
- `flex-direction` menentukan arah main axis dalam flexbox
- Nilai `row` (default): kiri ke kanan; `row-reverse`: kanan ke kiri
- Nilai `column`: atas ke bawah; `column-reverse`: bawah ke atas
- Nilai `*-reverse` membalik urutan tampilan item
- Mengubah `flex-direction` juga mengubah hubungan main axis dan cross axis
