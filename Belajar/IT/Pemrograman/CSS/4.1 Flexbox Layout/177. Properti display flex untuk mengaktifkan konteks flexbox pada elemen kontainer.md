# Properti display flex untuk mengaktifkan konteks flexbox pada elemen kontainer

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada mode tampilan khusus yang disebut "mode rak fleksibel" yang bisa diaktifkan untuk mengubah rak biasa menjadi rak pintar. Begitu mode ini diaktifkan, semua buku di dalamnya langsung mengikuti aturan tata letak yang fleksibel. Tanpa mengaktifkan mode ini, buku-buku akan ditampilkan secara statis seperti tumpukan biasa.

## Penjelasan Detail

Properti `display: flex` adalah langkah pertama untuk menggunakan Flexbox. Ketika nilai `flex` diterapkan pada sebuah elemen, elemen tersebut menjadi flex container dan semua anak langsungnya menjadi flex items. Container ini membentuk Block Formatting Context (BFC) baru, yang berarti margin anak tidak akan collapse dengan margin container. Semua flex items akan diatur dalam satu baris (secara default) dan properti Flexbox lainnya mulai berlaku. Nilai `inline-flex` juga tersedia untuk membuat container flex yang bersifat inline, sehingga container berperilaku seperti elemen inline namun tetap mempertahankan kemampuan flex di dalamnya. Tanpa `display: flex`, properti Flexbox lain seperti `justify-content` atau `align-items` tidak akan berpengaruh.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  background: #f0f0f0;
  padding: 12px;
  border-radius: 8px;
}

.container-inline {
  display: inline-flex;
  background: #e0e0e0;
  padding: 8px;
  margin-top: 12px;
}

.item {
  padding: 12px 20px;
  background: #6200EE;
  color: white;
  margin: 4px;
  border-radius: 4px;
}
```

## Poin Penting
- `display: flex` mengubah elemen menjadi flex container dan anak-anaknya menjadi flex items
- Container membentuk Block Formatting Context baru yang mencegah margin collapse
- Tanpa `display: flex`, semua properti Flexbox lainnya tidak akan berfungsi
- `display: inline-flex` membuat container flex yang bersifat inline
- Semua anak langsung (bukan cucu) menjadi flex items dan tunduk pada aturan flexbox
