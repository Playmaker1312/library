# Nilai flex umum yaitu flex auto, flex none, dan flex 1

## Analogi: Perpustakaan Digital

Tiga resep umum untuk mengatur ukuran buku di rak: `flex: 1` membuat semua buku tumbuh sama besar mengisi rak; `flex: auto` membuat buku tumbuh sesuai kebutuhan tetapi mempertahankan ukuran dasarnya; `flex: none` membuat buku tetap pada ukuran aslinya tanpa peduli ruang yang tersedia. Masing-masing cocok untuk situasi desain yang berbeda.

## Penjelasan Detail

Tiga nilai shorthand `flex` yang paling sering digunakan memiliki perilaku berbeda. `flex: 1` setara dengan `1 1 0`—item tumbuh dan menyusut secara proporsional dengan basis 0, sehingga semua item dengan `flex: 1` mendapat ukuran yang sama persis. `flex: auto` setara dengan `1 1 auto`—item tumbuh dan menyusut tetapi basisnya mengikuti ukuran konten, sehingga item yang lebih besar tetap lebih besar. `flex: none` setara dengan `0 0 auto`—item tidak tumbuh atau menyusut, ukurannya tetap sesuai konten. Nilai `flex: 1` paling sering digunakan untuk membuat kolom fleksibel yang sama besar. `flex: none` berguna untuk elemen seperti ikon atau tombol yang ukurannya harus tetap.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  border: 2px solid #333;
  padding: 4px;
  width: 500px;
}

.flex-1 { flex: 1; }   /* tumbuh merata, basis 0 */
.flex-auto { flex: auto; } /* tumbuh, basis auto */
.flex-none { flex: none; } /* tidak berubah */

.item {
  padding: 16px;
  margin: 4px;
  border-radius: 4px;
  color: white;
  text-align: center;
}

.item:nth-child(1) { background: #E91E63; flex: 1; }
.item:nth-child(2) { background: #9C27B0; flex: auto; }
.item:nth-child(3) { background: #3F51B5; flex: none; }
```

## Poin Penting
- `flex: 1` = `flex-grow: 1; flex-shrink: 1; flex-basis: 0`—distribusi merata
- `flex: auto` = `1 1 auto`—tumbuh tetapi basis mengikuti konten
- `flex: none` = `0 0 auto`—ukuran tetap, tidak fleksibel
- Pilih `flex: 1` untuk kolom sama besar, `flex: auto` untuk item proporsional
- Pilih `flex: none` untuk elemen yang ukurannya tidak boleh berubah
