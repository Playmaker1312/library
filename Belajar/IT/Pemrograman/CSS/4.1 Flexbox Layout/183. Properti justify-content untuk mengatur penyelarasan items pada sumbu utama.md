# Properti justify-content untuk mengatur penyelarasan items pada sumbu utama

## Analogi: Perpustakaan Digital

Bayangkan rak buku dengan ruang kosong di dalamnya. Kamu bisa memilih bagaimana buku-buku ditempatkan di sepanjang rak: rata kiri, rata kanan, di tengah, atau dengan jarak yang sama antara satu buku dengan buku lainnya. Ini seperti mengatur paragraf dalam dokumen—apakah rata kiri, rata kanan, rata tengah, atau justified.

## Penjelasan Detail

`justify-content` adalah properti pada flex container yang mengatur penyelarasan flex items di sepanjang main axis. Properti ini bekerja ketika ada ruang kosong di container setelah semua item ditempatkan. Nilai `flex-start` (default) menempatkan item di awal main axis. `flex-end` menempatkan di akhir. `center` menempatkan di tengah. `space-between` mendistribusikan item dengan jarak yang sama, item pertama di awal dan terakhir di akhir. `space-around` memberi jarak yang sama di sekitar setiap item. `space-evenly` memberi jarak yang benar-benar sama antara semua item dan tepi container. Nilai-nilai ini memberikan kontrol presisi atas distribusi ruang dalam tata letak.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  padding: 12px;
  background: #f9f9f9;
  border: 2px solid #ddd;
  margin-bottom: 12px;
}

.flex-start { justify-content: flex-start; }
.flex-end { justify-content: flex-end; }
.center { justify-content: center; }
.space-between { justify-content: space-between; }
.space-around { justify-content: space-around; }
.space-evenly { justify-content: space-evenly; }

.item {
  background: #673AB7;
  color: white;
  padding: 12px 20px;
  border-radius: 4px;
}
```

## Poin Penting
- `justify-content` mengatur penyelarasan item pada main axis
- Nilai `flex-start` dan `flex-end` menempatkan item di awal/akhir main axis
- `center` memusatkan item pada main axis
- `space-between`, `space-around`, dan `space-evenly` mendistribusikan ruang kosong
- Hanya berpengaruh jika ada ruang kosong setelah item ditempatkan
