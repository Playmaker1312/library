# Properti flex-basis untuk menentukan ukuran awal item sebelum ruang didistribusikan

## Analogi: Perpustakaan Digital

Setiap buku di rak memiliki ukuran dasar sebelum proses pengaturan ruang dimulai. Ukuran dasar ini adalah "titik awal"—seberapa besar buku tersebut idealnya ditampilkan. Setelah itu, sistem akan menambahkan atau mengurangi ukuran berdasarkan `flex-grow` dan `flex-shrink`. Jika buku memiliki ukuran dasar 200px, ia akan meminta ruang 200px terlebih dahulu, baru kelebihannya dibagikan.

## Penjelasan Detail

`flex-basis` adalah properti pada flex item yang menentukan ukuran awal item sebelum ruang kosong didistribusikan oleh `flex-grow` atau `flex-shrink`. Nilai default adalah `auto`, yang berarti ukuran basis diambil dari properti `width` atau `height` item (tergantung `flex-direction`). Jika tidak ada ukuran yang ditentukan, basis menggunakan ukuran konten. Nilai bisa berupa panjang (`px`, `em`, `%`), konten (`content`), atau `auto`. Ketika `flex-basis` diatur ke nilai tertentu (misal 150px), item akan memiliki ukuran dasar 150px sebelum `flex-grow` dan `flex-shrink` bekerja. Properti ini menggantikan `width` pada flex item ketika arahnya `row`. Nilai `0` membuat semua item memulai dari ukuran nol, sehingga distribusi `flex-grow` benar-benar proporsional.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  border: 2px solid #333;
  padding: 4px;
  width: 500px;
}

.item {
  padding: 16px;
  margin: 4px;
  border-radius: 4px;
  color: white;
  text-align: center;
}

.item:nth-child(1) { background: #9C27B0; flex-basis: 100px; flex-grow: 1; }
.item:nth-child(2) { background: #FF9800; flex-basis: 200px; flex-grow: 1; }
.item:nth-child(3) { background: #607D8B; flex-basis: auto; flex-grow: 1; }
```

## Poin Penting
- `flex-basis` menentukan ukuran awal item sebelum distribusi ruang
- Nilai default `auto` menggunakan `width` atau ukuran konten sebagai basis
- Nilai tetap (px, em, %) menggantikan `width` pada flex item saat `flex-direction: row`
- Nilai `0` membuat item mulai dari ukuran nol untuk distribusi proporsional
- Bekerja bersama `flex-grow` dan `flex-shrink` dalam proses distribusi ruang
