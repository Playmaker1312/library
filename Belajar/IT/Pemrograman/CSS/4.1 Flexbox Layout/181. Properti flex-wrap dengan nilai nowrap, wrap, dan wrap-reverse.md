# Properti flex-wrap dengan nilai nowrap, wrap, dan wrap-reverse

## Analogi: Perpustakaan Digital

Bayangkan sebuah rak buku yang terbatas panjangnya. Jika buku terlalu banyak, kamu bisa memilih: memaksa semua buku tetap dalam satu baris meski berdesakan (nowrap), atau membiarkan buku melanjutkan ke baris baru di bawahnya (wrap), atau bahkan melanjutkan ke baris baru di atasnya (wrap-reverse). Ini seperti memilih apakah teks dalam paragraf dipotong, dibungkus ke baris baru, atau dibungkus ke arah sebaliknya.

## Penjelasan Detail

`flex-wrap` menentukan apakah flex items dipaksa berada dalam satu baris atau bisa dilanjutkan ke baris baru jika tidak cukup ruang. Nilai `nowrap` (default) memaksa semua item dalam satu baris, item akan menyusut (shrink) jika perlu. Nilai `wrap` memungkinkan item melanjutkan ke baris baru dari atas ke bawah ketika ruang tidak mencukupi. Nilai `wrap-reverse` juga membungkus, tetapi baris baru muncul di atas (arah cross axis terbalik). Ketika `flex-wrap` aktif dan item membentuk beberapa baris, properti `align-content` mulai berfungsi untuk mengatur distribusi baris-baris tersebut.

## Contoh Kode Implementasi

```css
.nowrap {
  display: flex;
  flex-wrap: nowrap;
  width: 300px;
  border: 2px solid #333;
}

.wrap {
  display: flex;
  flex-wrap: wrap;
  width: 300px;
  border: 2px solid #333;
  margin-top: 12px;
}

.wrap-reverse {
  display: flex;
  flex-wrap: wrap-reverse;
  width: 300px;
  border: 2px solid #333;
  margin-top: 12px;
}

.item {
  background: #009688;
  color: white;
  padding: 12px 24px;
  margin: 4px;
  width: 100px;
  flex-shrink: 0;
}
```

## Poin Penting
- `nowrap` (default): semua item dalam satu baris, item bisa menyusut
- `wrap`: item pindah ke baris baru jika ruang tidak cukup
- `wrap-reverse`: sama seperti wrap tetapi baris baru muncul di atas
- `flex-wrap` memungkinkan `align-content` untuk mengatur distribusi beberapa baris
- Nilai `wrap` sangat berguna untuk tata letak responsif
