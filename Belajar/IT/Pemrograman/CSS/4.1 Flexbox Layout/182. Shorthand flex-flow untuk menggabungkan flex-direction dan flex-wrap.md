# Shorthand flex-flow untuk menggabungkan flex-direction dan flex-wrap

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada satu perintah yang bisa mengatur dua hal sekaligus: arah rak buku (ke samping atau ke bawah) dan apakah buku boleh pindah ke baris baru jika penuh. Daripada mengatur dua properti secara terpisah, perintah gabungan ini membuat konfigurasi lebih ringkas dan mudah dibaca, seperti perintah "samping-bungkus" yang langsung dipahami oleh sistem.

## Penjelasan Detail

`flex-flow` adalah shorthand untuk menggabungkan `flex-direction` dan `flex-wrap` dalam satu deklarasi. Nilai pertama adalah `flex-direction` dan nilai kedua adalah `flex-wrap`. Jika hanya satu nilai yang diberikan, nilai lainnya akan menggunakan default masing-masing (`row` untuk `flex-direction`, `nowrap` untuk `flex-wrap`). Shorthand ini mengurangi jumlah baris kode dan membuat kode lebih bersih. Kombinasi yang umum digunakan adalah `row wrap` untuk tata letak responsif, `column nowrap` untuk kolom vertikal, atau `row-reverse wrap` untuk urutan terbalik yang tetap responsif.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  flex-flow: row wrap;
  width: 400px;
  border: 2px solid #333;
  padding: 8px;
}

.container-column {
  display: flex;
  flex-flow: column nowrap;
  height: 200px;
  border: 2px solid #666;
  margin-top: 12px;
  padding: 8px;
}

.container-responsive {
  display: flex;
  flex-flow: row wrap;
  justify-content: center;
  gap: 8px;
}

.item {
  background: #FF9800;
  color: white;
  padding: 12px 20px;
  border-radius: 4px;
}
```

## Poin Penting
- `flex-flow` menggabungkan `flex-direction` dan `flex-wrap` dalam satu properti
- Urutan: `flex-flow: <flex-direction> <flex-wrap>`
- Jika satu nilai dihilangkan, nilai default (`row nowrap`) digunakan
- Membuat kode lebih ringkas dan mudah dipelihara
- Kombinasi `row wrap` paling umum digunakan untuk layout responsif
