# Properti order untuk mengubah urutan tampilan flex items tanpa mengubah HTML

## Analogi: Perpustakaan Digital

Bayangkan kamu memiliki tiga buku di rak: Merah, Biru, dan Hijau. Kamu ingin menampilkan Biru di posisi pertama tanpa memindahkan buku fisiknya. Dengan properti ini, kamu bisa memberi nomor urut khusus pada setiap buku sehingga tampilannya berubah tanpa menyentuh urutan asli di HTML. Ini seperti memberikan label prioritas pada setiap buku yang menentukan posisinya di rak.

## Penjelasan Detail

`order` adalah properti pada flex item yang menentukan urutan tampilan item dalam flex container. Nilai default-nya adalah `0`. Item diurutkan berdasarkan nilai `order` dari yang terkecil ke terbesar. Jika dua item memiliki nilai `order` yang sama, urutan mereka mengikuti urutan dalam HTML. Nilai negatif diperbolehkan, sehingga item bisa ditempatkan sebelum item yang memiliki `order` 0. Properti `order` tidak mengubah urutan di DOM, hanya tampilan visual. Ini penting untuk aksesibilitas dan SEO—pembaca layar tetap mengikuti urutan DOM, bukan urutan visual. Penggunaan `order` yang berlebihan bisa membingungkan, terutama jika dikombinasikan dengan navigasi keyboard.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  padding: 16px 24px;
  margin: 4px;
  border-radius: 4px;
  color: white;
  font-weight: bold;
}

.item:nth-child(1) { background: #E91E63; order: 3; }
.item:nth-child(2) { background: #2196F3; order: 1; }
.item:nth-child(3) { background: #4CAF50; order: 2; }
/* Tampilan: Biru (index 2), Hijau (index 3), Merah (index 1) */
```

## Poin Penting
- `order` mengubah urutan visual item tanpa mengubah urutan DOM
- Nilai default adalah `0`, item diurutkan dari kecil ke besar
- Nilai negatif memungkinkan item tampil sebelum item default
- Urutan DOM tetap terjaga untuk aksesibilitas dan pembaca layar
- Gunakan secara bijak untuk menghindari kebingungan navigasi
