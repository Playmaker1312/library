# Teknik membuat holy grail layout dengan header, sidebar, konten, dan footer menggunakan flexbox

## Analogi: Perpustakaan Digital

Holy Grail Layout adalah tata letak klasik perpustakaan digital: header di atas, footer di bawah, sidebar navigasi di kiri, dan konten utama di tengah. Dengan rak pintar flexbox, tata letak ini bisa dibuat dengan mudah—header dan footer memenuhi lebar penuh, sementara sidebar dan konten utama membagi ruang di tengah secara fleksibel.

## Penjelasan Detail

Holy Grail Layout terdiri dari empat area utama: header (atas), sidebar (kiri atau kanan), konten utama (tengah), dan footer (bawah). Dengan Flexbox, struktur ini bisa dicapai dengan membuat container utama menggunakan `flex-direction: column` dan `min-height: 100vh` untuk memenuhi seluruh viewport. Area tengah (sidebar + konten) adalah flex container horizontal dengan `flex: 1` untuk mengisi ruang yang tersisa. Sidebar diberi lebar tetap (misal 250px), sementara konten utama menggunakan `flex: 1` untuk mengisi sisa ruang. Header dan footer memiliki tinggi tetap. Pendekatan ini menghasilkan footer yang selalu berada di bawah meskipun konten sedikit (sticky footer).

## Contoh Kode Implementasi

```css
body {
  margin: 0;
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}

.header {
  background: #2c3e50;
  color: white;
  padding: 20px 24px;
  text-align: center;
}

.middle-area {
  display: flex;
  flex: 1;
}

.sidebar {
  width: 250px;
  background: #34495e;
  color: white;
  padding: 20px;
}

.main-content {
  flex: 1;
  padding: 24px;
  background: #ecf0f1;
}

.footer {
  background: #2c3e50;
  color: white;
  padding: 16px 24px;
  text-align: center;
}
```

## Poin Penting
- Container utama menggunakan `flex-direction: column` dan `min-height: 100vh`
- Area tengah adalah flex container horizontal dengan `flex: 1` untuk mengisi ruang
- Sidebar memiliki lebar tetap, konten utama menggunakan `flex: 1`
- Sticky footer tercapai secara alami karena footer berada di akhir kolom
- Layout ini responsif dan bisa diubah menjadi tumpuk vertikal di layar kecil
