# Teknik membuat kartu atau card layout menggunakan flexbox

## Analogi: Perpustakaan Digital

Kartu-kartu informasi di perpustakaan digital seperti koleksi buku yang ditampilkan dalam kotak-kotak. Setiap kotak memiliki gambar sampul, judul, deskripsi, dan tombol. Dengan rak pintar, kotak-kotak ini bisa diatur dalam baris-baris yang rapi, dengan tinggi yang sama secara otomatis, dan langsung menyesuaikan jumlah kolom sesuai lebar layar.

## Penjelasan Detail

Card layout dengan Flexbox memanfaatkan `display: flex` dan `flex-wrap: wrap` untuk membuat grid kartu yang responsif. Setiap kartu adalah flex item dengan `flex` tertentu agar memiliki lebar yang konsisten. Untuk membuat kartu setinggi dalam satu baris, gunakan `align-items: stretch` (default) sehingga semua kartu dalam satu baris memiliki tinggi yang sama. Struktur internal kartu juga bisa menggunakan flexbox dengan `flex-direction: column` dan `margin-top: auto` pada tombol di bagian bawah untuk mendorongnya ke bawah kartu. Dengan `flex: 1 1 300px`, setiap kartu memiliki lebar minimal 300px dan akan mengisi ruang yang tersedia.

## Contoh Kode Implementasi

```css
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
  padding: 20px;
}

.card {
  flex: 1 1 280px;
  display: flex;
  flex-direction: column;
  background: white;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
  overflow: hidden;
}

.card-image {
  width: 100%;
  height: 180px;
  background: #e0e0e0;
}

.card-content {
  flex: 1;
  padding: 16px;
}

.card-content h3 {
  margin: 0 0 8px;
  font-size: 18px;
}

.card-content p {
  color: #666;
  line-height: 1.5;
}

.card-button {
  margin-top: auto;
  padding: 12px 16px;
  background: #1976D2;
  color: white;
  text-align: center;
  border: none;
  cursor: pointer;
}
```

## Poin Penting
- Gunakan `flex-wrap: wrap` dan `flex: 1 1 <min-width>` untuk grid kartu responsif
- `align-items: stretch` (default) memastikan kartu setinggi dalam satu baris
- Struktur internal kartu menggunakan `flex-direction: column` untuk tata letak vertikal
- `margin-top: auto` pada tombol mendorongnya ke bagian bawah kartu
- `gap` memberikan jarak konsisten antar kartu tanpa margin manual
