# Nilai justify-content yaitu flex-start, flex-end, center, space-between, space-around, dan space-evenly

## Analogi: Perpustakaan Digital

Enam mode pengaturan rak buku menawarkan cara berbeda untuk mendistribusikan buku. `flex-start` seperti mendorong semua buku ke sisi kiri rak. `flex-end` mendorong ke sisi kanan. `center` memusatkannya. `space-between` memberi jarak sama antar buku, buku pertama dan terakhir menempel tepi. `space-around` memberi jarak yang sama di kiri dan kanan setiap buku. `space-evenly` memberi jarak yang identik antara semua elemen termasuk ke tepi. Masing-masing cocok untuk konteks desain yang berbeda.

## Penjelasan Detail

Keenam nilai `justify-content` memberikan perilaku distribusi ruang yang berbeda. `flex-start` (default) mengelompokkan item di awal main axis. `flex-end` mengelompokkan di akhir. `center` memusatkan grup item. `space-between` mendistribusikan ruang secara merata antar item; item pertama dan terakhir menempel ke tepi container. `space-around` memberi setengah jarak di tepi dan jarak penuh di tengah. `space-evenly` memberi jarak yang identik antara semua item dan antara item dengan tepi. Nilai `space-evenly` adalah yang paling konsisten secara visual karena semua spasi benar-benar sama, namun dukungan browser lawas perlu dipertimbangkan.

## Contoh Kode Implementasi

```css
.demo {
  display: flex;
  flex-direction: row;
  padding: 8px;
  background: #eee;
  margin-bottom: 8px;
  border-radius: 4px;
}

.flex-start   { justify-content: flex-start; }
.flex-end     { justify-content: flex-end; }
.center       { justify-content: center; }
.space-between { justify-content: space-between; }
.space-around  { justify-content: space-around; }
.space-evenly  { justify-content: space-evenly; }

.item {
  background: #E91E63;
  color: white;
  padding: 8px 16px;
  border-radius: 3px;
  font-size: 14px;
}
```

## Poin Penting
- `flex-start`: item dikelompokkan di awal main axis (default)
- `flex-end`: item dikelompokkan di akhir main axis
- `center`: item dikelompokkan di tengah main axis
- `space-between`: ruang merata antar item, tepi tanpa spasi
- `space-around`: ruang merata di sekitar setiap item
- `space-evenly`: ruang identik antara semua elemen termasuk ke tepi
