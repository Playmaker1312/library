# Properti flex-grow untuk mengatur seberapa besar item tumbuh mengisi ruang kosong

## Analogi: Perpustakaan Digital

Bayangkan rak buku dengan ruang kosong di ujungnya. Kamu bisa memberikan "izin tumbuh" pada setiap buku untuk mengembang mengisi ruang kosong tersebut. Buku dengan izin tumbuh lebih besar akan mengambil porsi ruang kosong yang lebih besar dibanding buku lain. Jika hanya satu buku yang memiliki izin tumbuh, buku itu akan mengambil semua ruang kosong yang tersisa.

## Penjelasan Detail

`flex-grow` adalah properti pada flex item yang menentukan seberapa besar item akan tumbuh (bertambah ukuran) relatif terhadap item lain ketika ada ruang positif yang tersisa di container. Nilai default adalah `0`, yang berarti item tidak akan tumbuh. Nilai berupa angka positif (biasanya integer, tapi float juga valid). Jika semua item memiliki `flex-grow: 1`, mereka akan membagi ruang kosong secara merata. Jika satu item memiliki `flex-grow: 2` dan lainnya `1`, item tersebut mendapat porsi dua kali lipat. Properti ini hanya memengaruhi distribusi ruang positif—jika tidak ada ruang kosong, `flex-grow` tidak berpengaruh. Nilai yang sangat besar (seperti 999) tidak masalah karena distribusi bersifat proporsional.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  border: 2px solid #333;
  padding: 4px;
  width: 500px;
}

.item {
  padding: 16px;
  margin: 4px;
  border-radius: 4px;
  color: white;
  text-align: center;
}

.item:nth-child(1) { background: #F44336; flex-grow: 1; }
.item:nth-child(2) { background: #2196F3; flex-grow: 2; }
.item:nth-child(3) { background: #4CAF50; flex-grow: 1; }
/* Item 2 mendapat ruang 2x lebih besar dari item 1 dan 3 */
```

## Poin Penting
- `flex-grow` mengontrol seberapa besar item tumbuh mengisi ruang kosong
- Nilai default `0` berarti item tidak tumbuh
- Distribusi bersifat proporsional berdasarkan perbandingan nilai
- Hanya berpengaruh jika ada ruang positif (sisa) di container
- Item dengan `flex-grow: 1` akan tumbuh sama besar jika semua item bernilai sama
