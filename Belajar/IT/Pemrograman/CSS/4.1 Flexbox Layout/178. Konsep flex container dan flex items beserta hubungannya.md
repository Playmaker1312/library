# Konsep flex container dan flex items beserta hubungannya

## Analogi: Perpustakaan Digital

Dalam perpustakaan digital, terdapat rak utama (flex container) yang menjadi wadah bagi buku-buku (flex items). Rak ini memiliki aturan tentang bagaimana buku-buku di dalamnya harus diatur—apakah berjejer ke samping, ke bawah, atau bagaimana jarak antar buku. Setiap buku yang diletakkan langsung di dalam rak akan mengikuti aturan rak tersebut, sementara buku di dalam kotak khusus di dalam rak tidak terpengaruh. Hubungan ini bersifat hierarkis: aturan rak hanya berlaku untuk anak langsung, bukan cucu.

## Penjelasan Detail

Flex container adalah elemen yang diberi properti `display: flex` atau `display: inline-flex`. Semua elemen yang menjadi anak langsung (first-level children) dari container tersebut secara otomatis menjadi flex items. Hubungan antara container dan items bersifat satu-tingkat (one-level): hanya anak langsung yang terpengaruh, bukan turunan yang lebih dalam. Container dapat memiliki properti seperti `flex-direction`, `flex-wrap`, `justify-content`, `align-items`, dan `align-content` yang memengaruhi tata letak semua flex items di dalamnya. Setiap flex item juga memiliki properti individual seperti `flex`, `order`, dan `align-self` yang dapat menimpa pengaturan container. Elemen pseudo seperti `::before` dan `::after` pada container juga menjadi flex items jika ada kontennya.

## Contoh Kode Implementasi

```css
.flex-container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  padding: 16px;
  background: #f5f5f5;
  border: 2px dashed #999;
  min-height: 150px;
}

.flex-item {
  background: #FF5722;
  color: white;
  padding: 16px 24px;
  border-radius: 4px;
  font-weight: bold;
}

.flex-item.special {
  align-self: flex-end;
  background: #9C27B0;
}
```

## Poin Penting
- Flex container adalah elemen dengan `display: flex` atau `display: inline-flex`
- Flex items hanyalah anak langsung (first-level children) dari container
- Hubungan bersifat satu tingkat—cucu tidak menjadi flex items secara otomatis
- Properti container memengaruhi semua flex items di dalamnya
- Setiap flex item bisa menimpa pengaturan container melalui properti individualnya
