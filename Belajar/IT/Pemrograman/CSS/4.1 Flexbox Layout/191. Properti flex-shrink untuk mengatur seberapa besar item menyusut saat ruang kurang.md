# Properti flex-shrink untuk mengatur seberapa besar item menyusut saat ruang kurang

## Analogi: Perpustakaan Digital

Ketika rak buku terlalu penuh dan buku-buku mulai berdesakan, beberapa buku bisa "menyusut" untuk memberi ruang. Buku dengan "ketahanan susut" rendah akan menyusut lebih banyak dibanding buku dengan ketahanan tinggi. Jika sebuah buku memiliki ketahanan susut nol, ia tidak akan menyusut sama sekali meski buku lain harus berdesakan. Ini seperti buku dengan sampul keras yang tidak bisa ditekan.

## Penjelasan Detail

`flex-shrink` adalah properti pada flex item yang menentukan seberapa besar item akan menyusut ketika ruang container tidak mencukupi untuk menampung semua item. Nilai default adalah `1`, yang berarti semua item menyusut secara proporsional. Nilai `0` berarti item tidak akan menyusut sama sekali—ia mempertahankan ukuran aslinya meskipun container kekurangan ruang. Nilai lebih besar dari 1 (misalnya 2) menyebabkan item menyusut dua kali lipat dari item lain. Properti ini adalah kebalikan dari `flex-grow` dalam konteks ruang negatif. `flex-shrink` hanya berpengaruh ketika total ukuran item melebihi ukuran container dan `flex-wrap` bernilai `nowrap`.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  flex-wrap: nowrap;
  width: 300px;
  border: 2px solid #333;
  padding: 4px;
}

.item {
  padding: 16px 24px;
  margin: 4px;
  border-radius: 4px;
  color: white;
  text-align: center;
  width: 120px;
}

.item:nth-child(1) { background: #F44336; flex-shrink: 1; }
.item:nth-child(2) { background: #2196F3; flex-shrink: 2; }
.item:nth-child(3) { background: #4CAF50; flex-shrink: 0; }
/* Item 3 tidak menyusut, item 2 menyusut 2x lebih banyak dari item 1 */
```

## Poin Penting
- `flex-shrink` mengontrol seberapa besar item menyusut saat ruang kurang
- Nilai default `1`—item menyusut secara proporsional
- Nilai `0` mencegah item menyusut sama sekali
- Hanya berpengaruh jika `flex-wrap: nowrap` dan total ukuran item > container
- Berlawanan dengan `flex-grow` yang mengatur pertumbuhan pada ruang positif
