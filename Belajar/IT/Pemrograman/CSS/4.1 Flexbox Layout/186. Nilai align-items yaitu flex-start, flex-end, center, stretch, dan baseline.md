# Nilai align-items yaitu flex-start, flex-end, center, stretch, dan baseline

## Analogi: Perpustakaan Digital

Lima cara untuk menyejajarkan buku dalam rak secara vertikal: `stretch` meregangkan semua buku setinggi rak; `flex-start` menempelkan buku ke atas rak; `flex-end` ke bawah rak; `center` di tengah rak; dan `baseline` menyelaraskan berdasarkan posisi teks pada setiap buku. Metode baseline berguna ketika isi buku memiliki tinggi font yang berbeda-beda namun ingin terlihat rapi secara visual.

## Penjelasan Detail

Lima nilai `align-items` memberikan kontrol berbeda terhadap posisi item pada cross axis. `stretch` adalah default, membuat setiap item meregang untuk mengisi seluruh ukuran cross axis container (jika item tidak memiliki ukuran tetap pada arah tersebut). `flex-start` menempatkan item di awal cross axis—jika `flex-direction: row`, item menempel ke atas. `flex-end` menempel ke bawah. `center` memusatkan item secara vertikal (untuk `row`). `baseline` menyelaraskan item berdasarkan garis dasar (baseline) teks dari setiap item, bukan berdasarkan tepi elemen. `baseline` sangat berguna ketika item memiliki ukuran padding berbeda atau teks dalam berbagai ukuran font.

## Contoh Kode Implementasi

```css
.demo {
  display: flex;
  flex-direction: row;
  height: 120px;
  border: 2px solid #888;
  margin-bottom: 8px;
  padding: 4px;
}

.stretch  { align-items: stretch; }
.flex-start { align-items: flex-start; }
.flex-end   { align-items: flex-end; }
.center     { align-items: center; }
.baseline   { align-items: baseline; }

.item {
  background: #00BCD4;
  color: white;
  padding: 8px 16px;
  border-radius: 3px;
  margin: 2px;
}

.item-lg { padding: 20px 16px; font-size: 20px; }
.item-sm { padding: 4px 16px; font-size: 12px; }
```

## Poin Penting
- `stretch` (default): item meregang memenuhi cross axis container
- `flex-start`: item menempel di awal cross axis
- `flex-end`: item menempel di akhir cross axis
- `center`: item di tengah cross axis
- `baseline`: item diselaraskan berdasarkan garis dasar teks
