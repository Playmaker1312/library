# Teknik membuat navigasi horizontal menggunakan flexbox

## Analogi: Perpustakaan Digital

Navigasi horizontal seperti rak buku yang berisi daftar kategori perpustakaan. Setiap kategori (Beranda, Katalog, Tentang, Kontak) ditempatkan berjejer dari kiri ke kanan. Dengan rak pintar, kamu bisa mengatur agar kategori-kategori ini rata kiri, rata kanan, atau tersebar merata. Jika layar menyempit, kategori bisa otomatis turun ke baris baru.

## Penjelasan Detail

Flexbox adalah pilihan sempurna untuk navigasi horizontal karena sifatnya yang satu dimensi. Dengan `display: flex` pada elemen `<nav>` atau `<ul>`, setiap tautan navigasi menjadi flex items yang bisa diatur. Gunakan `justify-content: center` untuk navigasi terpusat, `space-between` untuk tautan yang tersebar, atau `flex-end` untuk navigasi rata kanan. Dengan `flex-wrap: wrap`, navigasi akan responsif—tautan turun ke baris baru ketika layar tidak cukup lebar. Setiap item bisa diberi `padding` yang konsisten dan `gap` untuk jarak. Flexbox juga memudahkan pembuatan navigasi dengan logo di kiri dan tautan di kanan menggunakan `margin-left: auto` pada item tertentu.

## Contoh Kode Implementasi

```css
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  background: #2c3e50;
  padding: 0 24px;
  border-radius: 8px;
}

.nav-links {
  display: flex;
  gap: 8px;
  list-style: none;
  margin: 0;
  padding: 0;
}

.nav-links a {
  display: block;
  padding: 16px 20px;
  color: white;
  text-decoration: none;
  border-radius: 4px;
  transition: background 0.2s;
}

.nav-links a:hover {
  background: #34495e;
}

.logo {
  color: white;
  font-size: 20px;
  font-weight: bold;
}
```

## Poin Penting
- Gunakan `display: flex` pada container navigasi untuk tata letak horizontal
- Atur penyelarasan dengan `justify-content` (center, space-between, flex-end)
- `flex-wrap: wrap` membuat navigasi responsif terhadap ukuran layar
- `gap` memberikan jarak konsisten antar tautan navigasi
- `margin-left: auto` pada item memisahkan grup navigasi ke kanan
