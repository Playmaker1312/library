# Shorthand flex untuk menggabungkan flex-grow, flex-shrink, dan flex-basis

## Analogi: Perpustakaan Digital

Daripada mengatur tiga properti terpisah untuk setiap buku—seberapa besar bisa tumbuh, seberapa besar bisa menyusut, dan ukuran dasarnya—kamu bisa menggunakan satu perintah gabungan. Ini seperti memberikan resep lengkap untuk perilaku ukuran buku dalam satu frasa: "tumbuh 1, susut 1, basis 0" atau "tumbuh 0, susut 0, basis auto".

## Penjelasan Detail

`flex` adalah shorthand yang menggabungkan `flex-grow`, `flex-shrink`, dan `flex-basis` dalam satu deklarasi. Formatnya: `flex: <flex-grow> <flex-shrink> <flex-basis>`. Jika hanya satu nilai angka diberikan (misal `flex: 1`), itu menjadi nilai `flex-grow`, sementara `flex-shrink` menjadi `1` dan `flex-basis` menjadi `0`. Nilai `flex: none` setara dengan `0 0 auto`. Nilai `flex: auto` setara dengan `1 1 auto`. Nilai `flex: initial` (default) setara dengan `0 1 auto`. Menggunakan shorthand ini sangat disarankan karena lebih ringkas dan menghindari kebingungan tentang nilai default masing-masing properti.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  border: 2px solid #333;
  padding: 4px;
  width: 500px;
}

.item {
  padding: 16px;
  margin: 4px;
  border-radius: 4px;
  color: white;
  text-align: center;
}

/* flex-grow: 1, flex-shrink: 1, flex-basis: 0 */
.item:nth-child(1) { background: #F44336; flex: 1 1 0; }
/* flex-grow: 2, flex-shrink: 1, flex-basis: 0 */
.item:nth-child(2) { background: #2196F3; flex: 2 1 0; }
/* flex: none — tidak tumbuh, tidak menyusut, basis auto */
.item:nth-child(3) { background: #4CAF50; flex: none; }
```

## Poin Penting
- `flex` menggabungkan `flex-grow`, `flex-shrink`, dan `flex-basis` dalam satu properti
- Nilai tunggal `flex: 1` berarti `flex-grow: 1; flex-shrink: 1; flex-basis: 0`
- `flex: none` = `0 0 auto`; `flex: auto` = `1 1 auto`; `flex: initial` = `0 1 auto`
- Shorthand lebih ringkas dan disarankan dibanding properti individual
- Nilai default browser adalah `0 1 auto` (sama dengan `flex: initial`)
