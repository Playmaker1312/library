# Properti align-self pada flex item untuk menimpa align-items pada item tertentu

## Analogi: Perpustakaan Digital

Dalam sebuah rak yang semua buku biasanya disejajarkan rata tengah secara vertikal, kamu bisa memilih satu buku khusus untuk diletakkan di posisi berbeda—misalnya ditempelkan ke dasar rak. Ini seperti memberikan perintah khusus pada satu buku untuk mengabaikan aturan umum rak. Tanpa mengubah aturan untuk buku lainnya, satu buku tersebut bisa memiliki posisi yang unik.

## Penjelasan Detail

`align-self` adalah properti yang diterapkan pada flex item (bukan container) untuk menimpa nilai `align-items` dari container untuk item tersebut. Nilai yang tersedia sama dengan `align-items`: `auto`, `flex-start`, `flex-end`, `center`, `stretch`, dan `baseline`. Nilai `auto` (default) berarti item mengikuti pengaturan `align-items` dari container. Dengan `align-self`, kamu bisa memberikan pengecualian pada satu atau beberapa item tanpa memengaruhi item lainnya. Ini sangat berguna dalam desain di mana sebagian besar item mengikuti pola yang sama, tetapi beberapa item membutuhkan penyelarasan berbeda, seperti tombol aksi yang perlu berada di bagian bawah kartu.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  align-items: center;
  height: 150px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #9C27B0;
  color: white;
  padding: 12px 20px;
  margin: 4px;
  border-radius: 4px;
}

.item.push-top {
  align-self: flex-start;
  background: #E91E63;
}

.item.push-bottom {
  align-self: flex-end;
  background: #4CAF50;
}

.item.stretch-self {
  align-self: stretch;
  background: #FF9800;
}
```

## Poin Penting
- `align-self` diterapkan pada flex item, bukan container
- Menimpa nilai `align-items` dari container untuk item tersebut
- Nilai `auto` (default) membuat item mengikuti aturan container
- Nilai yang tersedia sama dengan `align-items`
- Berguna untuk membuat pengecualian individual dalam tata letak
