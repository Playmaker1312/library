# Properti align-items untuk mengatur penyelarasan items pada sumbu silang

## Analogi: Perpustakaan Digital

Jika `justify-content` mengatur posisi buku di sepanjang rak, `align-items` mengatur posisi buku pada arah tegak lurus rak—apakah buku diletakkan di atas rak, di bawah, di tengah, atau diregangkan memenuhi tinggi rak. Ini seperti menyesuaikan bagaimana buku-buku dengan tinggi berbeda disejajarkan secara vertikal dalam satu baris rak.

## Penjelasan Detail

`align-items` adalah properti pada flex container yang mengatur penyelarasan flex items pada cross axis (sumbu silang). Properti ini bekerja pada semua item dalam container secara sekaligus. Nilai `stretch` (default) meregangkan item memenuhi ukuran cross axis container. `flex-start` menempatkan item di awal cross axis. `flex-end` menempatkan di akhir. `center` memusatkan item pada cross axis. `baseline` menyelaraskan item berdasarkan garis dasar teks, berguna ketika item memiliki ukuran font berbeda. `align-items` berbeda dengan `justify-content` karena bekerja pada sumbu silang, bukan sumbu utama. Properti ini bisa ditimpa pada item individual menggunakan `align-self`.

## Contoh Kode Implementasi

```css
.container {
  display: flex;
  flex-direction: row;
  align-items: center;
  height: 150px;
  border: 2px solid #333;
  padding: 8px;
  margin-bottom: 12px;
}

.stretch  { align-items: stretch; }
.flex-start { align-items: flex-start; }
.flex-end   { align-items: flex-end; }
.center     { align-items: center; }
.baseline   { align-items: baseline; }

.item {
  background: #4CAF50;
  color: white;
  padding: 8px 16px;
  border-radius: 4px;
}

.item.tall { padding: 24px 16px; }
.item.short { padding: 4px 16px; }
```

## Poin Penting
- `align-items` mengatur penyelarasan item pada cross axis
- Nilai default adalah `stretch` yang meregangkan item memenuhi container
- `baseline` menyelaraskan item berdasarkan garis dasar teks
- Berlaku untuk semua flex items dalam container
- Dapat ditimpa per-item menggunakan properti `align-self`
