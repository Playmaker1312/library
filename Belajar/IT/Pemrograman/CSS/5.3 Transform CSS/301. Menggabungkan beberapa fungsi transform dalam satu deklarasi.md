# Menggabungkan beberapa fungsi transform dalam satu deklarasi

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin buku bergerak kompleks: geser ke kanan, perbesar, lalu miringkan secara bersamaan. Seperti koreografi tari, beberapa gerakan digabungkan dalam satu urutan. Fungsi transform dapat digabungkan dalam satu deklarasi `transform`, dipisah spasi. Gerakan diterapkan dari kanan ke kiri, sehingga urutan penulisan mempengaruhi hasil akhir.

## Penjelasan Detail

Beberapa fungsi transform dapat digabungkan dalam satu properti `transform` dengan memisahnya menggunakan spasi. Urutan penulisan penting karena transformasi diterapkan dari kanan ke kiri (fungsi paling kanan diterapkan pertama). `transform: translateX(100px) rotate(45deg)` berbeda hasilnya dengan `transform: rotate(45deg) translateX(100px)`. Pada yang pertama, elemen bergeser dulu lalu diputar. Pada yang kedua, elemen diputar dulu lalu bergeser (arah geser mengikuti rotasi). Memahami urutan ini penting untuk mencapai efek yang diinginkan. Untuk kemudahan, fungsi `translate3d`, `scale3d`, dan `rotate3d` menggabungkan sumbu dalam satu fungsi.

## Contoh Kode Implementasi

```css
/* Urutan transform: dari kanan ke kiri */
/* translate dulu, lalu rotate */
.transform-order-1 {
  transform: translateX(100px) rotate(45deg);
  /* Geser 100px ke kanan, lalu putar 45 deg */
}

/* rotate dulu, lalu translate */
.transform-order-2 {
  transform: rotate(45deg) translateX(100px);
  /* Putar 45 deg dulu, lalu geser 100px ke arah yang sudah diputar */
}

/* Multiple transform umum */
.card-hover {
  transition: transform 0.3s ease;
}

.card-hover:hover {
  transform: translateY(-8px) scale(1.02);
}

/* Transform kompleks */
.complex-transform {
  transform: 
    perspective(800px)
    rotateX(10deg)
    rotateY(20deg)
    scale(1.1)
    translateZ(30px);
}

/* Entrance animation dengan multiple transform */
@keyframes cardEntrance {
  from {
    opacity: 0;
    transform: 
      translateY(40px)
      scale(0.95)
      rotate(-5deg);
  }
  to {
    opacity: 1;
    transform: 
      translateY(0)
      scale(1)
      rotate(0deg);
  }
}

.card-entrance {
  animation: cardEntrance 0.5s ease-out forwards;
}

/* Efek hover yang kompleks */
.image-overlay {
  transition: transform 0.4s ease;
}

.image-overlay:hover {
  transform: 
    scale(1.1)
    rotate(3deg)
    translateY(-5px);
}

/* Button dengan efek pressed dan bounce */
.button-transform {
  transition: transform 0.2s cubic-bezier(0.68, -0.55, 0.27, 1.55);
}

.button-transform:hover {
  transform: scale(1.05) translateY(-2px);
}

.button-transform:active {
  transform: scale(0.95) translateY(1px);
}

/* Skew dan rotate */
.text-skew {
  transform: 
    skewX(-10deg)
    rotate(-5deg);
}

/* 3D card tilt mengikuti mouse (CSS saja, statis) */
.card-3d-tilt {
  transform: 
    perspective(600px)
    rotateX(5deg)
    rotateY(10deg);
}

/* Loading spinner dengan multiple transform */
@keyframes spinAndScale {
  0% {
    transform: rotate(0deg) scale(1);
  }
  50% {
    transform: rotate(180deg) scale(1.2);
  }
  100% {
    transform: rotate(360deg) scale(1);
  }
}

.spinner-fancy {
  animation: spinAndScale 2s ease-in-out infinite;
}

/* Nav link dengan underline slide */
.nav-link-underline {
  position: relative;
}

.nav-link-underline::after {
  content: '';
  position: absolute;
  bottom: -2px;
  left: 0;
  width: 100%;
  height: 2px;
  background: currentColor;
  transform: scaleX(0) translateX(-100%);
  transform-origin: left;
  transition: transform 0.3s ease;
}

.nav-link-underline:hover::after {
  transform: scaleX(1) translateX(0);
}
```

## Poin Penting
- Fungsi transform ditulis dalam satu deklarasi dipisah spasi
- Urutan penting: diterapkan dari kanan ke kiri
- translate + scale: geser lalu perbesar
- rotate + translate: putar dulu mempengaruhi arah geser
- perspective sebaiknya ditempatkan paling kiri (diterapkan paling akhir)
