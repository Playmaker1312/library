# Fungsi scale untuk memperbesar atau memperkecil elemen secara proporsional

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur "zoom" pada sampul buku. Saat pengguna mengarahkan kursor ke buku, buku membesar secara proporsional (scale > 1). Saat melihat galeri, gambar kecil diperbesar saat diklik. Fungsi scale seperti kaca pembesar yang memperbesar atau memperkecil tampilan buku tanpa mengubah ukuran aslinya.

## Penjelasan Detail

Fungsi `scale()` memperbesar atau memperkecil ukuran visual elemen berdasarkan faktor skala. Nilai 1 adalah ukuran asli. Nilai antara 0 dan 1 memperkecil (misal: 0.5 = setengah ukuran). Nilai lebih dari 1 memperbesar (misal: 2 = dua kali ukuran). Nilai negatif membalikkan elemen (mirror). Scale dapat memiliki satu parameter (sama untuk X dan Y) atau dua parameter (X dan Y berbeda). Scale mempengaruhi tampilan visual saja, bukan ukuran layout elemen. Elemen tetap mempertahankan ruang aslinya dalam aliran dokumen.

## Contoh Kode Implementasi

```css
/* Scale seragam: satu nilai untuk X dan Y */
.scale-up {
  transform: scale(1.5);
  /* 1.5x ukuran asli */
}

.scale-down {
  transform: scale(0.5);
  /* Setengah ukuran asli */
}

/* Scale berbeda untuk X dan Y */
.scale-stretch {
  transform: scale(2, 1);
  /* Dua kali lebar, tinggi tetap */
}

.scale-squash {
  transform: scale(1, 1.5);
  /* Lebar tetap, 1.5x tinggi */
}

/* Scale negatif: mirror */
.scale-mirror-x {
  transform: scale(-1, 1);
  /* Mirror horizontal */
}

.scale-mirror-y {
  transform: scale(1, -1);
  /* Mirror vertikal */
}

/* Hover effect: scale */
.card {
  transition: transform 0.3s ease;
}

.card:hover {
  transform: scale(1.05);
}

/* Active effect: pressed */
.button {
  transition: transform 0.1s ease;
}

.button:active {
  transform: scale(0.95);
}

/* Animasi pulse dengan scale */
@keyframes pulse {
  0%, 100% {
    transform: scale(1);
  }
  50% {
    transform: scale(1.1);
  }
}

.pulse-element {
  animation: pulse 1s ease-in-out infinite;
}

/* Scale untuk entrance effect */
@keyframes scaleIn {
  from {
    transform: scale(0);
    opacity: 0;
  }
  to {
    transform: scale(1);
    opacity: 1;
  }
}

.scale-in {
  animation: scaleIn 0.4s ease-out forwards;
}

/* Scale dengan origin berbeda */
.scale-from-top {
  transform-origin: top center;
  transform: scale(0);
  transition: transform 0.3s ease;
}

.scale-from-top.active {
  transform: scale(1);
}

/* Scale untuk galeri gambar */
.gallery img {
  transition: transform 0.3s ease;
}

.gallery img:hover {
  transform: scale(1.1);
  z-index: 10;
}

/* Scale untuk loading skeleton */
@keyframes shimmer {
  0% { transform: scaleX(0); transform-origin: left; }
  50% { transform: scaleX(1); transform-origin: left; }
  100% { transform: scaleX(1); transform-origin: right; }
}

.skeleton-loading::after {
  content: '';
  position: absolute;
  inset: 0;
  background: linear-gradient(90deg, transparent, rgba(255,255,255,0.4), transparent);
  animation: shimmer 1.5s infinite;
}

/* Scale untuk zoom image modal */
.modal-image {
  transition: transform 0.3s ease;
  cursor: zoom-in;
}

.modal-image.zoomed {
  transform: scale(2);
  cursor: zoom-out;
}
```

## Poin Penting
- scale(1) = ukuran asli, scale(2) = 2x lebih besar, scale(0.5) = setengahnya
- Satu parameter untuk skala seragam, dua parameter untuk X dan Y berbeda
- Scale negatif menciptakan efek mirror
- Scale hanya mengubah tampilan visual, bukan layout
