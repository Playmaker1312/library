# Fungsi rotate untuk memutar elemen berdasarkan sudut yang ditentukan

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur memutar sampul buku. Buku bisa diputar searah jarum jam atau berlawanan, seperti memutar foto di galeri. Fungsi rotate seperti memutar buku di atas meja: buku berputar pada porosnya tanpa berpindah tempat. Sudut putaran diukur dalam derajat, radian, atau putaran penuh.

## Penjelasan Detail

Fungsi `rotate()` memutar elemen pada bidang 2D berdasarkan sudut yang ditentukan. Nilai positif memutar searah jarum jam, nilai negatif berlawanan arah jarum jam. Satuan yang didukung: `deg` (derajat, 360 = satu putaran), `rad` (radian, 2π = satu putaran), `grad` (gradian, 400 = satu putaran), `turn` (putaran, 1 = satu putaran). Titik pusat rotasi ditentukan oleh `transform-origin` (default: center). Rotasi hanya mempengaruhi tampilan visual, elemen tetap di posisi layout aslinya.

## Contoh Kode Implementasi

```css
/* Rotasi dasar */
.rotate-45 {
  transform: rotate(45deg);
  /* 45 derajat searah jarum jam */
}

.rotate-negative {
  transform: rotate(-45deg);
  /* 45 derajat berlawanan jarum jam */
}

/* Berbagai satuan sudut */
.rotate-deg {
  transform: rotate(90deg);
}

.rotate-rad {
  transform: rotate(1.5708rad);
  /* 90 derajat dalam radian */
}

.rotate-turn {
  transform: rotate(0.25turn);
  /* Seperempat putaran = 90 derajat */
}

.rotate-grad {
  transform: rotate(100grad);
  /* 100 gradian = 90 derajat */
}

/* Rotasi penuh */
.rotate-full {
  transform: rotate(360deg);
}

/* Hover effect: rotate */
.icon-rotate {
  display: inline-block;
  transition: transform 0.3s ease;
}

.icon-rotate:hover {
  transform: rotate(180deg);
}

/* Animasi rotasi kontinu */
@keyframes spin {
  from {
    transform: rotate(0deg);
  }
  to {
    transform: rotate(360deg);
  }
}

.spinner {
  animation: spin 1s linear infinite;
}

/* Rotasi dengan origin berbeda */
.rotate-from-corner {
  transform-origin: top left;
  transition: transform 0.3s ease;
}

.rotate-from-corner:hover {
  transform: rotate(10deg);
}

/* Kartu yang miring saat hover */
.card-tilt {
  transition: transform 0.3s ease;
}

.card-tilt:hover {
  transform: rotate(2deg) scale(1.02);
}

/* Animasi swing (ayunan) */
@keyframes swing {
  0%, 100% {
    transform: rotate(-10deg);
  }
  50% {
    transform: rotate(10deg);
  }
}

.swing-element {
  animation: swing 2s ease-in-out infinite;
  transform-origin: top center;
}

/* Tombol dengan aksen */
.button-rotate {
  display: inline-flex;
  align-items: center;
  gap: 0.5rem;
  transition: transform 0.2s ease;
}

.button-rotate:hover .arrow {
  transform: rotate(90deg);
}

.arrow {
  display: inline-block;
  transition: transform 0.2s ease;
}

/* Ikon loading */
@keyframes loadSpin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

.loading-icon {
  animation: loadSpin 1s linear infinite;
}

/* Rotate untuk efek shuffle */
@keyframes shuffle {
  0% { transform: rotate(0deg); }
  25% { transform: rotate(90deg); }
  50% { transform: rotate(180deg); }
  75% { transform: rotate(270deg); }
  100% { transform: rotate(360deg); }
}

/* Chevron rotation */
.chevron {
  transition: transform 0.2s ease;
}

.accordion.open .chevron {
  transform: rotate(180deg);
}
```

## Poin Penting
- rotate(angle) memutar elemen pada bidang 2D
- Nilai positif = searah jarum jam, negatif = berlawanan
- Satuan: deg (derajat), rad (radian), turn (putaran), grad (gradian)
- transform-origin menentukan titik pusat rotasi
