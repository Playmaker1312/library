# Teknik membuat efek parallax sederhana menggunakan transform dan perspective

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin menciptakan ilusi kedalaman saat pengguna menggulir halaman. Bayangkan melihat rak buku dari samping saat berjalan: buku yang dekat bergerak cepat, buku yang jauh bergerak lambat. Efek parallax menggunakan prinsip yang sama: beberapa lapisan konten bergerak dengan kecepatan berbeda saat scroll, menciptakan ilusi tiga dimensi yang memukau.

## Penjelasan Detail

Efek parallax adalah teknik di mana latar belakang bergerak lebih lambat daripada latar depan saat pengguna menggulir halaman, menciptakan ilusi kedalaman. Pendekatan CSS sederhana menggunakan `perspective` dan `translateZ` pada elemen anak. Dengan mengatur `perspective` pada kontainer dan memberikan `translateZ` negatif pada elemen latar belakang, elemen tersebut akan bergerak lebih lambat secara alami. Namun, karena elemen dengan translateZ negatif menjadi lebih kecil, perlu dikompensasi dengan `scale()` agar tetap terlihat normal. Rumus: `scale = 1 + (translateZ / perspective)`. Pendekatan lain menggunakan `background-attachment: fixed` untuk efek parallax pada gambar latar.

## Contoh Kode Implementasi

```css
/* Parallax sederhana dengan perspective */
.parallax-container {
  perspective: 1px;
  height: 100vh;
  overflow-x: hidden;
  overflow-y: auto;
  transform-style: preserve-3d;
}

.parallax-layer {
  position: absolute;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;
}

.parallax-back {
  transform: translateZ(-1px) scale(2);
  /* Bergerak lebih lambat */
  z-index: 1;
}

.parallax-mid {
  transform: translateZ(-0.5px) scale(1.5);
  /* Bergerak sedikit lebih lambat */
  z-index: 2;
}

.parallax-front {
  transform: translateZ(0);
  /* Bergerak normal */
  z-index: 3;
}

/* Parallax dengan background-attachment */
.parallax-bg {
  min-height: 400px;
  background-image: url('mountains.jpg');
  background-attachment: fixed;
  background-position: center;
  background-repeat: no-repeat;
  background-size: cover;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
}

.parallax-bg h2 {
  font-size: 3rem;
  text-shadow: 0 2px 8px rgba(0, 0, 0, 0.5);
}

/* Multiple parallax sections */
.parallax-section {
  position: relative;
  overflow: hidden;
}

.parallax-section .bg {
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 120%;
  background-image: url('bg.jpg');
  background-size: cover;
  background-position: center;
  transform: translateY(-10%);
  z-index: -1;
}

/* Parallax dengan pseudo-elemen */
.hero-parallax {
  position: relative;
  height: 100vh;
  overflow: hidden;
  display: flex;
  align-items: center;
  justify-content: center;
}

.hero-parallax::before {
  content: '';
  position: absolute;
  inset: -20%;
  background-image: url('hero-bg.jpg');
  background-size: cover;
  background-position: center;
  transform: translateZ(-1px) scale(1.2);
  z-index: -1;
}

/* Rumus scale untuk kompensasi translateZ */
/* scale = 1 + (translateZ / perspective) */
/* translateZ(-1px) pada perspective(1px) => scale(2) */
/* translateZ(-2px) pada perspective(1px) => scale(3) */

.parallax-deep {
  transform: translateZ(-2px) scale(3);
}

.parallax-shallow {
  transform: translateZ(-0.3px) scale(1.3);
}

/* Content section normal */
.content-section {
  position: relative;
  min-height: 60vh;
  background: white;
  padding: 4rem 2rem;
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 10;
}

/* Parallax dengan gradien overlay */
.parallax-overlay {
  position: relative;
}

.parallax-overlay::after {
  content: '';
  position: absolute;
  inset: 0;
  background: linear-gradient(
    rgba(0, 0, 0, 0.3),
    rgba(0, 0, 0, 0.5)
  );
}

/* Fallback untuk prefers-reduced-motion */
@media (prefers-reduced-motion: reduce) {
  .parallax-bg {
    background-attachment: scroll;
  }
  
  .parallax-layer {
    transform: none !important;
  }
}
```

## Poin Penting
- Parallax dengan perspective: latar belakang diberi translateZ negatif + scale kompensasi
- background-attachment: fixed untuk parallax sederhana pada gambar latar
- Rumus scale: 1 + (translateZ / perspective)
- Selalu sediakan fallback untuk prefers-reduced-motion
- Perhatikan performa: parallax bisa berat di perangkat mobile
