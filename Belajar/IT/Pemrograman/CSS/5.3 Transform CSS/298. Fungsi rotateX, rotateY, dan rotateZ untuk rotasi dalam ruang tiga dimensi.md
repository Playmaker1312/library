# Fungsi rotateX, rotateY, dan rotateZ untuk rotasi dalam ruang tiga dimensi

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki buku yang bisa diputar dalam tiga dimensi. rotateX memutar buku pada sumbu horizontal (seperti halaman buku yang dibalik). rotateY memutar pada sumbu vertikal (seperti pintu yang membuka). rotateZ memutar pada sumbu kedalaman (sama seperti rotate 2D). Ketiganya memungkinkan efek 3D yang realistis seperti buku yang terbuka, kartu yang membalik, atau kubus yang berputar.

## Penjelasan Detail

`rotateX()`, `rotateY()`, dan `rotateZ()` adalah fungsi transform yang memutar elemen dalam ruang tiga dimensi. `rotateX(angle)` memutar di sekitar sumbu X (horizontal), menciptakan efek seperti halaman buku dibalik. `rotateY(angle)` memutar di sekitar sumbu Y (vertikal), menciptakan efek seperti pintu terbuka. `rotateZ(angle)` memutar di sekitar sumbu Z, setara dengan rotate() 2D. Untuk melihat efek 3D, diperlukan properti `perspective` pada parent. Nilai positif mengikuti aturan tangan kanan. Kombinasi ketiga fungsi memungkinkan orientasi elemen dalam ruang 3D penuh.

## Contoh Kode Implementasi

```js
/* Setup perspective */
.scene {
  perspective: 800px;
  perspective-origin: center;
}

/* rotateX: sumbu horizontal */
.rotate-x {
  transform: rotateX(45deg);
  /* Miring ke depan/belakang */
}

.rotate-x-full {
  transform: rotateX(180deg);
  /* Terbalik */
}

/* rotateY: sumbu vertikal */
.rotate-y {
  transform: rotateY(45deg);
  /* Miring ke kiri/kanan */
}

.rotate-y-full {
  transform: rotateY(180deg);
  /* Membalik seperti kartu */
}

/* rotateZ: sumbu kedalaman (sama dengan rotate 2D) */
.rotate-z {
  transform: rotateZ(45deg);
  /* Sama dengan rotate(45deg) */
}

/* Flip card dengan rotateY */
.flip-card {
  perspective: 1000px;
  width: 300px;
  height: 200px;
}

.flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.6s ease;
  transform-style: preserve-3d;
}

.flip-card:hover .flip-card-inner {
  transform: rotateY(180deg);
}

.flip-card-front,
.flip-card-back {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
  border-radius: 8px;
  padding: 1.5rem;
  display: flex;
  align-items: center;
  justify-content: center;
}

.flip-card-front {
  background: #1a73e8;
  color: white;
}

.flip-card-back {
  background: #34a853;
  color: white;
  transform: rotateY(180deg);
}

/* Animasi 3D cube */
@keyframes cubeSpin {
  from {
    transform: rotateX(0deg) rotateY(0deg);
  }
  to {
    transform: rotateX(360deg) rotateY(360deg);
  }
}

.cube-container {
  perspective: 600px;
}

.cube {
  position: relative;
  width: 200px;
  height: 200px;
  transform-style: preserve-3d;
  animation: cubeSpin 6s linear infinite;
}

/* Hover effect dengan rotateX */
.card-hover-3d {
  transition: transform 0.3s ease;
}

.card-hover-3d:hover {
  transform: rotateX(10deg) rotateY(10deg);
}

/* Page flip effect */
@keyframes pageFlip {
  from {
    transform: rotateY(0deg);
    transform-origin: left center;
  }
  to {
    transform: rotateY(-180deg);
    transform-origin: left center;
  }
}

.page {
  animation: pageFlip 0.6s ease-in-out forwards;
}

/* Door swing effect */
.door {
  transform-origin: left center;
  transition: transform 0.5s ease;
  transform-style: preserve-3d;
}

.door.open {
  transform: rotateY(-90deg);
}

/* Multiple rotations */
.element-3d {
  transform: rotateX(20deg) rotateY(40deg) rotateZ(10deg);
}
```

## Poin Penting
- rotateX memutar pada sumbu horizontal (efek balik halaman)
- rotateY memutar pada sumbu vertikal (efek buka pintu)
- rotateZ setara dengan rotate 2D pada sumbu kedalaman
- Perspective dan transform-style: preserve-3d diperlukan untuk efek 3D
