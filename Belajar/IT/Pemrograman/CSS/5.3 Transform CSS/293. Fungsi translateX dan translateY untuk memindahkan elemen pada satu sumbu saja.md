# Fungsi translateX dan translateY untuk memindahkan elemen pada satu sumbu saja

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki dua jenis gerakan untuk buku: geser horizontal seperti buku digeser sepanjang rak, dan geser vertikal seperti buku diangkat ke atas atau ke bawah. translateX untuk gerakan horizontal, translateY untuk gerakan vertikal. Keduanya adalah gerakan satu sumbu yang lebih spesifik dibandingkan fungsi translate dua sumbu.

## Penjelasan Detail

`translateX()` dan `translateY()` adalah fungsi transform yang memindahkan elemen hanya pada satu sumbu. `translateX(n)` setara dengan `translate(n, 0)`. `translateY(n)` setara dengan `translate(0, n)`. Fungsi satu sumbu lebih ekspresif secara semantik ketika hanya satu arah pergerakan yang diperlukan. Nilai positif pada translateX menggeser ke kanan, negatif ke kiri. Nilai positif pada translateY menggeser ke bawah, negatif ke atas. Satuan yang didukung sama dengan translate: px, em, rem, persen, vw, vh.

## Contoh Kode Implementasi

```css
/* translateX horizontal */
.move-right {
  transform: translateX(50px);
  /* Geser 50px ke kanan */
}

.move-left {
  transform: translateX(-50px);
  /* Geser 50px ke kiri */
}

/* translateY vertikal */
.move-down {
  transform: translateY(30px);
  /* Geser 30px ke bawah */
}

.move-up {
  transform: translateY(-30px);
  /* Geser 30px ke atas */
}

/* Penggunaan dalam interaksi */
.sidebar {
  transform: translateX(-100%);
  transition: transform 0.3s ease-out;
}

.sidebar.open {
  transform: translateX(0);
}

/* Animasi naik turun */
@keyframes float {
  0%, 100% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-20px);
  }
}

.floating-element {
  animation: float 2s ease-in-out infinite;
}

/* Animasi geser kanan-kiri */
@keyframes shake {
  0%, 100% {
    transform: translateX(0);
  }
  25% {
    transform: translateX(-10px);
  }
  75% {
    transform: translateX(10px);
  }
}

.shake-element {
  animation: shake 0.5s ease-in-out;
}

/* Hover effect khusus sumbu */
.card-hover-x {
  transition: transform 0.3s ease;
}

.card-hover-x:hover {
  transform: translateX(10px);
}

.card-hover-y {
  transition: transform 0.3s ease;
}

.card-hover-y:hover {
  transform: translateY(-5px);
}

/* Menu dropdown yang muncul dari atas */
.dropdown-menu {
  transform: translateY(-10px);
  opacity: 0;
  transition: transform 0.2s ease-out, opacity 0.2s ease;
}

.dropdown-menu.open {
  transform: translateY(0);
  opacity: 1;
}

/* Tooltip positioning */
.tooltip {
  position: absolute;
  top: calc(100% + 8px);
  left: 50%;
  transform: translateX(-50%);
  /* Tengah horizontal relatif terhadap parent */
}

/* Badge notification */
.badge {
  position: absolute;
  top: -8px;
  right: -8px;
  transform: translateX(50%) translateY(-50%);
}

/* Scroll indicator horizontal */
.scroll-indicator {
  transform: translateX(var(--scroll-position, 0%));
}

/* Loading bar animasi */
@keyframes loadingProgress {
  from {
    transform: translateX(-100%);
  }
  to {
    transform: translateX(0);
  }
}

.loading-bar::after {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: #1a73e8;
  animation: loadingProgress 2s ease-in-out infinite;
}
```

## Poin Penting
- translateX untuk pergerakan horizontal saja, translateY untuk vertikal saja
- Fungsi satu sumbu lebih spesifik dan ekspresif secara semantik
- translateX(-100%) berguna untuk menyembunyikan elemen di luar viewport kiri
- translateY(-50%) dengan position absolute membantu vertikal centering
