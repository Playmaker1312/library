# Fungsi translate untuk memindahkan elemen secara horizontal dan vertikal

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur "drag" untuk memindahkan buku dari satu posisi ke posisi lain. Buku dapat digeser ke kanan, kiri, atas, atau bawah tanpa mempengaruhi buku lain di sekitarnya. Fungsi translate seperti menarik buku secara visual: bukunya berpindah tempat, tetapi tempat duduk aslinya tetap kosong, menunggu buku itu kembali.

## Penjelasan Detail

Fungsi `translate()` memindahkan elemen dari posisi aslinya berdasarkan sumbu X (horizontal) dan Y (vertikal). Nilai positif X menggeser ke kanan, negatif ke kiri. Nilai positif Y menggeser ke bawah, negatif ke atas. Satuan dapat berupa piksel, persen (dari ukuran elemen sendiri), em, atau viewport. Keunggulan translate dibanding properti `top`/`left` adalah performa: translate hanya memicu Composite, sementara `top`/`left` memicu Layout. Translate juga memungkinkan pemosisian relatif terhadap ukuran elemen sendiri menggunakan persen.

## Contoh Kode Implementasi

```css
/* Translate dasar */
.translate-basic {
  transform: translate(50px, 100px);
  /* Pindah 50px ke kanan, 100px ke bawah */
}

/* Translate dengan satuan berbeda */
.translate-px {
  transform: translate(20px, 30px);
}

.translate-percent {
  /* 50% dari lebar elemen sendiri, 25% dari tinggi sendiri */
  transform: translate(50%, 25%);
}

.translate-em {
  transform: translate(2em, 1em);
}

/* Translate sumbu tunggal */
.translate-x-only {
  transform: translateX(100px);
  /* Hanya horizontal */
}

.translate-y-only {
  transform: translateY(-50px);
  /* Hanya vertikal, ke atas */
}

/* Translate untuk animasi hover */
.card {
  transition: transform 0.3s ease;
}

.card:hover {
  transform: translateY(-8px);
  /* Naik 8px saat hover */
}

/* Translate untuk efek pressed */
.button:active {
  transform: translateY(2px);
  /* Turun 2px saat diklik */
}

/* Translate dari luar viewport */
.slide-in {
  transform: translateX(-100%);
  transition: transform 0.3s ease-out;
}

.slide-in.active {
  transform: translateX(0);
}

/* Centering dengan translate */
.center-absolute {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  /* Pusat tepat di tengah, tanpa tahu ukuran elemen */
}

/* Translate untuk efek parallax */
.parallax-layer {
  transition: transform 0.1s linear;
}

.parallax-layer.slow {
  transform: translateY(20px);
}

.parallax-layer.fast {
  transform: translateY(-10px);
}

/* Beberapa translate dalam animasi */
@keyframes moveAround {
  0% {
    transform: translate(0, 0);
  }
  25% {
    transform: translate(100px, 0);
  }
  50% {
    transform: translate(100px, 100px);
  }
  75% {
    transform: translate(0, 100px);
  }
  100% {
    transform: translate(0, 0);
  }
}

.moving-box {
  animation: moveAround 4s ease-in-out infinite;
}
```

## Poin Penting
- translate(x, y) memindahkan elemen secara horizontal dan vertikal
- translateX untuk horizontal saja, translateY untuk vertikal saja
- Nilai persen dihitung relatif terhadap ukuran elemen itu sendiri
- Gunakan translate(-50%, -50%) untuk centering yang tidak bergantung ukuran
