# Properti perspective untuk memberikan kedalaman pada transformasi tiga dimensi

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin menciptakan ilusi kedalaman, seperti melihat buku melalui lensa kamera. perspective menentukan seberapa kuat efek 3D terlihat. Nilai perspective yang kecil (misal 200px) seperti lensa sudut lebar: efek 3D sangat kuat dan dramatis. Nilai besar (misal 1000px) seperti lensa telefoto: efek 3D lebih halus dan realistis. Seperti melihat dunia melalui kacamata yang berbeda.

## Penjelasan Detail

Properti `perspective` dan fungsi `perspective()` menentukan jarak antara pengamat dan bidang z=0, menciptakan ilusi kedalaman dalam transformasi 3D. Nilai yang lebih kecil menghasilkan efek 3D yang lebih dramatis (seperti lensa sudut lebar). Nilai yang lebih besar menghasilkan efek 3D yang lebih halus (seperti lensa telefoto). Properti `perspective` diterapkan pada parent dan mempengaruhi semua anak. Fungsi `perspective()` diterapkan langsung pada elemen dalam transform. `perspective-origin` mengubah posisi titik hilang (vanishing point).

## Contoh Kode Implementasi

```css
/* Perspective pada parent (semua anak terpengaruh) */
.scene {
  perspective: 800px;
  perspective-origin: center;
}

.scene .card {
  transition: transform 0.3s ease;
}

.scene .card:hover {
  transform: rotateY(15deg);
}

/* Perbedaan nilai perspective */
.perspective-close {
  perspective: 200px;
  /* Efek 3D sangat kuat */
}

.perspective-normal {
  perspective: 600px;
  /* Efek 3D sedang */
}

.perspective-far {
  perspective: 1200px;
  /* Efek 3D halus */
}

/* Perspective-origin: titik hilang */
.origin-center {
  perspective-origin: center;
}

.origin-left {
  perspective-origin: left center;
}

.origin-top-right {
  perspective-origin: top right;
}

/* Perspective sebagai fungsi transform */
.perspective-function {
  transform: perspective(800px) rotateY(15deg);
  /* Hanya mempengaruhi elemen ini */
}

/* Tumpukan kartu dengan perspective */
.card-stack-3d {
  perspective: 600px;
  perspective-origin: center top;
}

.card-stack-3d .card {
  position: absolute;
  transition: transform 0.3s ease;
  transform-style: preserve-3d;
}

.card-stack-3d .card:nth-child(1) { transform: rotateX(5deg) translateZ(0); }
.card-stack-3d .card:nth-child(2) { transform: rotateX(5deg) translateZ(10px); }
.card-stack-3d .card:nth-child(3) { transform: rotateX(5deg) translateZ(20px); }
.card-stack-3d .card:nth-child(4) { transform: rotateX(5deg) translateZ(30px); }

/* Hover 3D pada card grid */
.card-grid-3d {
  perspective: 800px;
}

.card-grid-3d .card {
  transition: transform 0.3s ease;
}

.card-grid-3d .card:hover {
  transform: rotateY(10deg) translateZ(20px);
}

/* Efek parallax 3D */
.parallax-container {
  perspective: 600px;
  overflow-x: hidden;
  overflow-y: auto;
}

.parallax-layer {
  position: absolute;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;
}

.parallax-layer-0 { transform: translateZ(0px); }
.parallax-layer-1 { transform: translateZ(50px) scale(0.9); }
.parallax-layer-2 { transform: translateZ(100px) scale(0.8); }

/* Animasi dengan perspective */
@keyframes float3d {
  0%, 100% {
    transform: perspective(800px) rotateX(5deg) rotateY(0deg);
  }
  50% {
    transform: perspective(800px) rotateX(5deg) rotateY(10deg);
  }
}

.float-3d-element {
  animation: float3d 3s ease-in-out infinite;
  transform-style: preserve-3d;
}

/* Custom perspective berdasarkan viewport */
:root {
  --perspective: min(800px, 80vw);
}

.element-3d {
  perspective: var(--perspective);
}
```

## Poin Penting
- perspective menentukan jarak pengamat ke bidang z=0
- Nilai kecil (< 400px) = efek 3D dramatis, nilai besar (> 1000px) = efek halus
- perspective-origin mengubah posisi titik hilang
- Properti perspective pada parent vs fungsi perspective() pada elemen
