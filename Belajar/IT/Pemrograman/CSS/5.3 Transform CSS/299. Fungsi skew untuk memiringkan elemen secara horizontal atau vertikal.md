# Fungsi skew untuk memiringkan elemen secara horizontal atau vertikal

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur untuk memiringkan tampilan buku. Bayangkan buku yang didorong dari samping sehingga bentuknya menjadi jajar genjang, bukan persegi panjang. Fungsi skew seperti mendorong sisi atas buku ke kanan atau kiri, menciptakan ilusi kemiringan dan perspektif.

## Penjelasan Detail

Fungsi `skew()` memiringkan elemen dengan menggeser sisi-sisinya sepanjang sumbu X dan Y. Nilai `skew(ax)` hanya memiringkan sumbu X. `skew(ax, ay)` memiringkan kedua sumbu. `skewX(angle)` memiringkan secara horizontal (sisi atas/bawah bergeser). `skewY(angle)` memiringkan secara vertikal (sisi kiri/kanan bergeser). Sudut diukur dalam derajat. Skew positif pada X menggeser sisi atas ke kanan, sisi bawah ke kiri. Skew positif pada Y menggeser sisi kiri ke bawah, sisi kanan ke atas. Skew berguna untuk efek perspektif, badge miring, atau elemen desain dengan sudut dinamis.

## Contoh Kode Implementasi

```css
/* Skew horizontal */
.skew-x {
  transform: skewX(10deg);
  /* Miring 10 derajat ke kanan */
}

.skew-x-negative {
  transform: skewX(-10deg);
  /* Miring 10 derajat ke kiri */
}

/* Skew vertikal */
.skew-y {
  transform: skewY(10deg);
  /* Miring vertikal */
}

/* Skew kedua sumbu */
.skew-both {
  transform: skew(10deg, 5deg);
}

/* Skew untuk badge miring */
.badge-skew {
  display: inline-block;
  background: #ea4335;
  color: white;
  padding: 0.25rem 1rem;
  transform: skewX(-15deg);
  font-weight: bold;
}

.badge-skew span {
  display: inline-block;
  transform: skewX(15deg);
  /* Membalik kemiringan agar teks tetap lurus */
}

/* Efek parallax dengan skew */
.parallax-skew {
  transform: skewY(5deg);
  transform-origin: top left;
}

.parallax-skew > * {
  transform: skewY(-5deg);
  /* Membalik untuk konten di dalamnya */
}

/* Hero section dengan skew */
.hero-skew {
  position: relative;
  background: #1a73e8;
  color: white;
  padding: 4rem 2rem;
  margin-top: -50px;
}

.hero-skew::after {
  content: '';
  position: absolute;
  bottom: -50px;
  left: 0;
  width: 100%;
  height: 50px;
  background: #1a73e8;
  transform: skewY(2deg);
  transform-origin: top right;
}

/* Hover effect dengan skew */
.card-skew {
  transition: transform 0.3s ease;
}

.card-skew:hover {
  transform: skewX(-2deg);
}

/* Animasi skew */
@keyframes skewPulse {
  0%, 100% {
    transform: skewX(0deg);
  }
  50% {
    transform: skewX(5deg);
  }
}

.skew-animation {
  animation: skewPulse 2s ease-in-out infinite;
}

/* Skew untuk efek "tearing" */
@keyframes tearEffect {
  0% { transform: skewX(0deg); }
  20% { transform: skewX(5deg); }
  40% { transform: skewX(-5deg); }
  60% { transform: skewX(3deg); }
  80% { transform: skewX(-3deg); }
  100% { transform: skewX(0deg); }
}

/* Strip miring dengan skew */
.stripes {
  background: repeating-linear-gradient(
    45deg,
    #1a73e8,
    #1a73e8 20px,
    transparent 20px,
    transparent 40px
  );
}

/* Skew untuk efek 3D palsu */
.pseudo-3d {
  transform: skewX(-5deg) scaleX(0.9);
  /* Menciptakan ilusi perspektif */
}

/* Navigasi miring */
.nav-skew {
  display: flex;
  gap: 0;
}

.nav-skew a {
  display: block;
  padding: 0.5rem 1.5rem;
  background: #f0f0f0;
  transform: skewX(-20deg);
  margin-right: -10px;
  transition: background 0.2s ease;
}

.nav-skew a span {
  display: block;
  transform: skewX(20deg);
}

.nav-skew a:hover {
  background: #1a73e8;
  color: white;
}
```

## Poin Penting
- skewX(angle) memiringkan horizontal, skewY(angle) memiringkan vertikal
- Untuk membalikkan kemiringan pada konten anak, gunakan skew negatif yang sama
- Skew berguna untuk efek desain seperti badge, hero section, dan navigasi
- Kombinasikan dengan scale untuk efek 3D palsu
