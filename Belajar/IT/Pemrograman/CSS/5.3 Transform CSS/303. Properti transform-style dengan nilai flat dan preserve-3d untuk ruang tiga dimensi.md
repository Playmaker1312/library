# Properti transform-style dengan nilai flat dan preserve-3d untuk ruang tiga dimensi

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki grup buku yang ditumpuk. Jika grup diputar, apakah setiap buku mempertahankan posisi 3D-nya relatif satu sama lain, atau semuanya rata seperti gambar datar? `transform-style: flat` membuat grup rata, sementara `preserve-3d` mempertahankan kedalaman masing-masing buku. Seperti perbedaan antara memutar foto grup (flat) dan memutar patung 3D (preserve-3d).

## Penjelasan Detail

`transform-style` menentukan apakah elemen anak mempertahankan posisi 3D-nya dalam ruang tiga dimensi. `flat` (default): semua anak diratakan ke bidang parent, tidak ada efek 3D yang dipertahankan. `preserve-3d`: anak-anak mempertahankan transformasi 3D mereka relatif terhadap parent. `preserve-3d` diperlukan untuk efek seperti kubus 3D, flip card, dan galeri 3D. Namun, `preserve-3d` tidak kompatibel dengan `overflow: hidden` karena browser tidak dapat menghitung batas clipping dalam ruang 3D.

## Contoh Kode Implementasi

```css
/* flat (default): anak diratakan */
.container-flat {
  transform-style: flat;
  perspective: 800px;
}

.container-flat .child {
  transform: translateZ(50px);
  /* Tidak akan terlihat efek kedalaman karena parent flat */
}

/* preserve-3d: anak mempertahankan posisi 3D */
.container-3d {
  transform-style: preserve-3d;
  perspective: 800px;
}

.container-3d .child {
  transform: translateZ(50px);
  /* Akan terlihat lebih dekat karena parent preserve-3d */
}

/* Flip card dengan preserve-3d */
.flip-card {
  perspective: 1000px;
  width: 300px;
  height: 200px;
}

.flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.6s ease;
  transform-style: preserve-3d;
}

.flip-card:hover .flip-card-inner {
  transform: rotateY(180deg);
}

.flip-card-front,
.flip-card-back {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
  display: flex;
  align-items: center;
  justify-content: center;
  padding: 1.5rem;
  border-radius: 8px;
}

.flip-card-front {
  background: #1a73e8;
  color: white;
}

.flip-card-back {
  background: #34a853;
  color: white;
  transform: rotateY(180deg);
}

/* Kubus 3D */
.cube {
  position: relative;
  width: 200px;
  height: 200px;
  transform-style: preserve-3d;
  transform: rotateX(-30deg) rotateY(30deg);
}

.cube-face {
  position: absolute;
  width: 200px;
  height: 200px;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 2rem;
  font-weight: bold;
  color: white;
  border: 2px solid rgba(255, 255, 255, 0.5);
}

.cube-front  { transform: translateZ(100px); background: rgba(66, 133, 244, 0.8); }
.cube-back   { transform: rotateY(180deg) translateZ(100px); background: rgba(52, 168, 83, 0.8); }
.cube-right  { transform: rotateY(90deg) translateZ(100px); background: rgba(251, 188, 5, 0.8); }
.cube-left   { transform: rotateY(-90deg) translateZ(100px); background: rgba(234, 67, 53, 0.8); }
.cube-top    { transform: rotateX(90deg) translateZ(100px); background: rgba(142, 68, 173, 0.8); }
.cube-bottom { transform: rotateX(-90deg) translateZ(100px); background: rgba(0, 150, 136, 0.8); }

/* Carousel 3D */
.carousel-3d {
  perspective: 1200px;
  transform-style: preserve-3d;
}

.carousel-item {
  position: absolute;
  width: 200px;
  height: 300px;
  backface-visibility: hidden;
  transform-style: preserve-3d;
}

/* Galeri 3D */
.gallery-3d {
  transform-style: preserve-3d;
  perspective: 800px;
}

.gallery-3d img {
  transition: transform 0.3s ease;
}

.gallery-3d img:hover {
  transform: translateZ(50px);
}

/* Catatan: preserve-3d tidak kompak dengan overflow: hidden */
/* Ini TIDAK akan bekerja: */
/* .broken-3d {
  transform-style: preserve-3d;
  overflow: hidden;
} */
```

## Poin Penting
- flat (default): anak diratakan ke bidang parent
- preserve-3d: anak mempertahankan posisi 3D dalam ruang
- preserve-3d diperlukan untuk flip card, kubus, dan efek 3D kompleks
- preserve-3d tidak kompatibel dengan overflow: hidden
