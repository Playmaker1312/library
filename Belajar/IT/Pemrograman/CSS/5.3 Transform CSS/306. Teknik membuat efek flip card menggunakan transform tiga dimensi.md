# Teknik membuat efek flip card menggunakan transform tiga dimensi

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki koleksi kartu yang bisa dibalik. Di satu sisi, ada sampul buku. Di sisi lain, ada sinopsis dan informasi detail. Saat pengguna mengarahkan kursor ke kartu, kartu berputar secara realistis seperti membalik kartu fisik. Efek ini menggabungkan perspective, rotateY, backface-visibility, dan preserve-3d untuk menciptakan ilusi kartu tiga dimensi yang nyata.

## Penjelasan Detail

Flip card adalah efek populer yang menampilkan dua sisi konten dalam satu elemen. Teknik ini menggabungkan beberapa properti CSS: `perspective` untuk kedalaman, `transform-style: preserve-3d` untuk mempertahankan ruang 3D, `backface-visibility: hidden` untuk menyembunyikan sisi belakang saat tidak menghadap, dan `rotateY(180deg)` untuk membalik kartu. Dua elemen anak (depan dan belakang) diposisikan absolut di dalam kontainer yang sama. Sisi depan berada di posisi default, sisi belakang diputar 180 derajat. Saat hover, kontainer diputar 180 derajat sehingga sisi belakang yang terlihat.

## Contoh Kode Implementasi

```css
/* Struktur dasar flip card */
.flip-card {
  perspective: 1000px;
  width: 300px;
  height: 400px;
}

.flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.6s ease;
  transform-style: preserve-3d;
  cursor: pointer;
}

.flip-card:hover .flip-card-inner {
  transform: rotateY(180deg);
}

.flip-card-front,
.flip-card-back {
  position: absolute;
  width: 100%;
  height: 100%;
  backface-visibility: hidden;
  border-radius: 12px;
  overflow: hidden;
  box-shadow: 0 4px 16px rgba(0, 0, 0, 0.15);
}

.flip-card-front {
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: white;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  padding: 2rem;
}

.flip-card-back {
  background: white;
  color: #333;
  transform: rotateY(180deg);
  display: flex;
  flex-direction: column;
  padding: 2rem;
}

/* Flip card dengan gambar */
.flip-card-image .flip-card-front {
  padding: 0;
}

.flip-card-image .flip-card-front img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

/* Flip card vertikal (sumbu X) */
.flip-card-vertical .flip-card-inner:hover {
  transform: rotateX(180deg);
}

.flip-card-vertical .flip-card-back {
  transform: rotateX(180deg);
}

/* Flip card 3D dengan depth */
.flip-card-depth .flip-card-inner {
  transform: rotateY(0deg) translateZ(0);
}

.flip-card-depth:hover .flip-card-inner {
  transform: rotateY(180deg) translateZ(20px);
}

/* Flip card dengan tombol close */
.flip-card-toggle {
  perspective: 1000px;
  width: 300px;
  height: 400px;
}

.flip-card-toggle .flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;
  transition: transform 0.6s ease;
  transform-style: preserve-3d;
}

.flip-card-toggle.active .flip-card-inner {
  transform: rotateY(180deg);
}

/* Multiple flip cards dengan staggered delay */
.flip-card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 2rem;
  perspective: 1000px;
}

/* Flip card dengan shadow 3D */
.flip-card-shadow .flip-card-front {
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.2);
}

.flip-card-shadow:hover .flip-card-front {
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}

/* Flip card aksesibel: tetap responsif tanpa hover */
@media (hover: none) {
  .flip-card .flip-card-inner {
    transform: none !important;
  }
  
  .flip-card .flip-card-back {
    display: none;
  }
  
  .flip-card.active .flip-card-back {
    display: flex;
  }
}

/* Animasi flip lebih halus */
.flip-card-smooth .flip-card-inner {
  transition: transform 0.8s cubic-bezier(0.4, 0, 0.2, 1);
}

/* Flip card dengan glas morphism */
.flip-card-glass .flip-card-front {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.2);
}
```

## Poin Penting
- Flip card menggabungkan perspective, preserve-3d, rotateY, dan backface-visibility
- Sisi depan di posisi default, sisi belakang di rotateY(180deg)
- Hover memutar inner container 180 derajat
- Untuk perangkat touch, gunakan toggle class dengan JavaScript
- Aksesibilitas: pastikan konten di kedua sisi tetap dapat diakses
