# Properti transform-origin untuk mengubah titik acuan transformasi elemen

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki pintu yang bisa berputar. Jika pintu berputar pada engsel di samping, ia membuka seperti pintu normal. Jika berputar pada titik tengah, ia berputar seperti pintu putar. Titik acuan transformasi menentukan bagaimana elemen bergerak. Fungsi transform-origin seperti menentukan di mana engsel dipasang pada buku atau pintu.

## Penjelasan Detail

`transform-origin` menentukan titik pusat (origin) dari transformasi elemen. Secara default, origin berada di pusat elemen (`50% 50%` atau `center`). Dengan mengubah origin, efek transformasi berubah secara dramatis. Nilai dapat berupa kata kunci (`top`, `bottom`, `left`, `right`, `center`), persen (dari ukuran elemen), atau panjang piksel. Untuk `rotate`, origin menentukan poros putaran. Untuk `scale`, origin menentukan titik yang tetap saat elemen membesar/mengecil. Untuk `skew`, origin mempengaruhi arah kemiringan. Tiga nilai dapat digunakan untuk origin 3D (`transform-origin: x y z`).

## Contoh Kode Implementasi

```css
/* Default: center */
.default-origin {
  transform-origin: 50% 50%;
  transform: rotate(45deg);
  /* Berputar pada pusat */
}

/* Kata kunci */
.origin-top-left {
  transform-origin: top left;
  transform: scale(1.5);
  /* Membesar dari pojok kiri atas */
}

.origin-top-right {
  transform-origin: top right;
}

.origin-bottom-left {
  transform-origin: bottom left;
}

.origin-bottom-right {
  transform-origin: bottom right;
}

.origin-center {
  transform-origin: center;
}

/* Nilai persen */
.origin-percent {
  transform-origin: 100% 0%;
  /* Pojok kanan atas */
}

.origin-custom {
  transform-origin: 30% 70%;
}

/* Nilai panjang */
.origin-px {
  transform-origin: 20px 30px;
}

/* Efek pintu dengan origin di kiri */
.door {
  transform-origin: left center;
  transition: transform 0.5s ease;
}

.door.open {
  transform: rotateY(-90deg);
}

/* Efek accordion dengan origin di atas */
.accordion-content {
  transform-origin: top center;
  transform: scaleY(0);
  transition: transform 0.3s ease;
}

.accordion-content.open {
  transform: scaleY(1);
}

/* Efek card flip dengan origin berbeda */
.card-flip {
  perspective: 1000px;
}

.card-flip-inner {
  transition: transform 0.6s ease;
  transform-origin: center right;
  transform-style: preserve-3d;
}

.card-flip:hover .card-flip-inner {
  transform: rotateY(-180deg);
}

/* Animasi pendulum dengan origin di atas */
.pendulum {
  transform-origin: top center;
  animation: swing 2s ease-in-out infinite;
}

@keyframes swing {
  0%, 100% { transform: rotate(-15deg); }
  50% { transform: rotate(15deg); }
}

/* Progress bar yang mengisi dari kiri */
.progress-fill {
  transform-origin: left center;
  transform: scaleX(0);
  transition: transform 0.5s ease;
}

.progress-fill.filled {
  transform: scaleX(1);
}

/* Efek grow dari pojok */
.grow-from-corner {
  transform-origin: bottom right;
  transform: scale(0);
  transition: transform 0.3s ease;
}

.grow-from-corner.active {
  transform: scale(1);
}

/* Transform origin 3D */
.origin-3d {
  transform-origin: 50% 50% 50px;
  transform: rotateY(45deg);
}

/* Multiple origin untuk elemen berbeda */
.origin-demo {
  transition: transform 0.3s ease;
}

.origin-demo.top { transform-origin: top center; }
.origin-demo.bottom { transform-origin: bottom center; }
.origin-demo.left { transform-origin: left center; }
.origin-demo.right { transform-origin: right center; }
```

## Poin Penting
- transform-origin menentukan titik acuan transformasi (default: center)
- Kata kunci: top, bottom, left, right, center
- Untuk rotate: origin adalah poros putaran
- Untuk scale: origin adalah titik yang tetap saat elemen berubah ukuran
- Tiga nilai untuk origin 3D: x, y, z
