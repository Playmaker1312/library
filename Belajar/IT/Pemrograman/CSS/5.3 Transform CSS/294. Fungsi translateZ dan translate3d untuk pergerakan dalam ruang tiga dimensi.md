# Fungsi translateZ dan translate3d untuk pergerakan dalam ruang tiga dimensi

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki rak buku dalam ruang 3D. Buku tidak hanya bisa digeser ke kiri-kanan dan atas-bawah, tetapi juga maju-mundur mendekati atau menjauhi pengguna. translateZ menggerakkan buku mendekati (positif) atau menjauhi (negatif) layar, menciptakan ilusi kedalaman. translate3d menggabungkan semua gerakan dalam satu fungsi untuk efisiensi.

## Penjelasan Detail

`translateZ()` dan `translate3d()` adalah fungsi transform yang bekerja dalam ruang tiga dimensi. `translateZ(n)` memindahkan elemen sepanjang sumbu Z (mendekati atau menjauhi pengguna). `translate3d(x, y, z)` menggabungkan translateX, translateY, dan translateZ dalam satu fungsi. Untuk melihat efek translateZ, diperlukan properti `perspective` pada parent atau fungsi `perspective()` dalam transform. translateZ positif membuat elemen tampak lebih besar (mendekat), negatif tampak lebih kecil (menjauh). translate3d lebih efisien daripada tiga fungsi translate terpisah karena browser dapat mengoptimalkan matriks transformasi.

## Contoh Kode Implementasi

```css
/* Setup perspective untuk efek 3D */
.scene {
  perspective: 800px;
  perspective-origin: center;
}

/* translateZ dasar */
.move-closer {
  transform: translateZ(100px);
  /* Tampak lebih dekat ke pengguna */
}

.move-farther {
  transform: translateZ(-100px);
  /* Tampak lebih jauh dari pengguna */
}

/* translate3d: x, y, z */
.move-3d {
  transform: translate3d(50px, 30px, 100px);
  /* 50px kanan, 30px bawah, 100px lebih dekat */
}

/* Kartu dengan efek 3D */
.card-3d {
  transition: transform 0.3s ease;
}

.card-3d:hover {
  transform: translateZ(50px);
  /* Kartu mendekat saat hover */
}

/* Parallax 3D layers */
.layer {
  position: absolute;
  width: 200px;
  height: 200px;
  border-radius: 8px;
  transition: transform 0.1s ease;
}

.layer-0 { transform: translateZ(0px); }
.layer-1 { transform: translateZ(50px); }
.layer-2 { transform: translateZ(100px); }
.layer-3 { transform: translateZ(150px); }

/* Animasi 3D */
@keyframes float3d {
  0%, 100% {
    transform: translate3d(0, 0, 0);
  }
  50% {
    transform: translate3d(20px, -30px, 50px);
  }
}

.float-3d {
  animation: float3d 3s ease-in-out infinite;
}

/* Perspective sebagai fungsi transform */
.perspective-transform {
  transform: perspective(800px) translateZ(100px);
}

/* Card stack dengan depth */
.card-stack {
  perspective: 600px;
}

.card-stack .card {
  position: absolute;
  transition: transform 0.3s ease;
}

.card-stack .card:nth-child(1) { transform: translateZ(0px); }
.card-stack .card:nth-child(2) { transform: translateZ(10px); }
.card-stack .card:nth-child(3) { transform: translateZ(20px); }
.card-stack .card:nth-child(4) { transform: translateZ(30px); }

/* Hover untuk menarik card */
.card-stack .card:hover {
  transform: translateZ(60px);
}

/* Animasi masuk dari dalam layar */
@keyframes zoomIn3d {
  from {
    opacity: 0;
    transform: translate3d(0, 0, -500px);
  }
  to {
    opacity: 1;
    transform: translate3d(0, 0, 0);
  }
}

.zoom-in-3d {
  animation: zoomIn3d 0.6s ease-out forwards;
}

/* translate3d untuk performa lebih baik */
/* BAIK: translate3d mengaktifkan akselerasi GPU */
.gpu-accelerated {
  transform: translate3d(0, 0, 0);
  /* Memicu GPU tanpa mengubah posisi */
}

/* Hindari: z-index manual jika bisa pakai translateZ */
.elements-3d {
  transform-style: preserve-3d;
}
```

## Poin Penting
- translateZ menggerakkan elemen mendekati/menjauhi pengguna pada sumbu Z
- translate3d(x, y, z) menggabungkan semua sumbu dalam satu fungsi
- Perspective diperlukan untuk melihat efek translateZ
- translate3d(0, 0, 0) dapat mengaktifkan akselerasi GPU untuk performa lebih baik
