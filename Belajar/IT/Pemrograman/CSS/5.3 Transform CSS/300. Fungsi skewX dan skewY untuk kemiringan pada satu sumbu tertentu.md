# Fungsi skewX dan skewY untuk kemiringan pada satu sumbu tertentu

## Analogi: Perpustakaan Digital

Perpustakaan digital dapat memiringkan buku hanya secara horizontal (skewX) atau hanya secara vertikal (skewY). skewX seperti mendorong buku dari samping sehingga bentuknya menjadi jajar genjang horizontal. skewY seperti menarik buku dari atas sehingga bentuknya menjadi jajar genjang vertikal. Keduanya adalah kemiringan satu sumbu yang lebih spesifik dibandingkan fungsi skew dua sumbu.

## Penjelasan Detail

`skewX()` dan `skewY()` adalah fungsi transform yang memiringkan elemen hanya pada satu sumbu. `skewX(angle)` menggeser sumbu X, mengubah sudut vertikal elemen. `skewY(angle)` menggeser sumbu Y, mengubah sudut horizontal elemen. Nilai positif skewX memiringkan ke kanan, negatif ke kiri. Nilai positif skewY memiringkan ke bawah, negatif ke atas. Fungsi satu sumbu lebih ekspresif secara semantik dan mudah diprediksi perilakunya. Skew mempertahankan ukuran layout elemen, hanya tampilan visual yang berubah.

## Contoh Kode Implementasi

```css
/* skewX: horizontal */
.skew-x-right {
  transform: skewX(15deg);
  /* Miring 15 derajat ke kanan */
}

.skew-x-left {
  transform: skewX(-15deg);
  /* Miring 15 derajat ke kiri */
}

/* skewY: vertikal */
.skew-y-down {
  transform: skewY(10deg);
  /* Miring vertikal ke bawah */
}

.skew-y-up {
  transform: skewY(-10deg);
  /* Miring vertikal ke atas */
}

/* Badge dengan skewX */
.badge {
  display: inline-block;
  background: #ea4335;
  color: white;
  padding: 0.2em 0.8em;
  font-size: 0.75rem;
  font-weight: bold;
  transform: skewX(-12deg);
}

.badge-content {
  display: inline-block;
  transform: skewX(12deg);
}

/* Section diagonal dengan skewY */
.diagonal-section {
  position: relative;
  background: #1a73e8;
  color: white;
  padding: 4rem 2rem;
  overflow: hidden;
}

.diagonal-section::before {
  content: '';
  position: absolute;
  top: -50px;
  left: 0;
  width: 100%;
  height: 100px;
  background: inherit;
  transform: skewY(3deg);
  transform-origin: top left;
}

/* Kartu dengan efek miring saat hover */
.card-tilt {
  transition: transform 0.3s ease;
}

.card-tilt:hover {
  transform: skewX(-2deg) scale(1.02);
}

/* Animasi dengan skewX */
@keyframes wobble {
  0%, 100% {
    transform: skewX(0deg);
  }
  25% {
    transform: skewX(5deg);
  }
  75% {
    transform: skewX(-5deg);
  }
}

.wobble-element {
  animation: wobble 0.5s ease-in-out;
}

/* Efek "shake" horizontal */
@keyframes shakeX {
  0%, 100% {
    transform: skewX(0deg) translateX(0);
  }
  20% {
    transform: skewX(3deg) translateX(-5px);
  }
  40% {
    transform: skewX(-3deg) translateX(5px);
  }
  60% {
    transform: skewX(2deg) translateX(-3px);
  }
  80% {
    transform: skewX(-2deg) translateX(3px);
  }
}

.shake-x {
  animation: shakeX 0.5s ease-in-out;
}

/* Efek "shake" vertikal */
@keyframes shakeY {
  0%, 100% {
    transform: skewY(0deg) translateY(0);
  }
  20% {
    transform: skewY(3deg) translateY(-5px);
  }
  40% {
    transform: skewY(-3deg) translateY(5px);
  }
  60% {
    transform: skewY(2deg) translateY(-3px);
  }
  80% {
    transform: skewY(-2deg) translateY(3px);
  }
}

.shake-y {
  animation: shakeY 0.5s ease-in-out;
}

/* Hero section dengan skewX */
.hero-slant {
  position: relative;
  overflow: hidden;
}

.hero-slant::after {
  content: '';
  position: absolute;
  bottom: -5%;
  left: -5%;
  width: 110%;
  height: 15%;
  background: white;
  transform: skewX(-3deg);
  transform-origin: left bottom;
}

/* Navigasi miring horizontal */
.nav-skew-x {
  display: flex;
}

.nav-skew-x a {
  display: block;
  padding: 0.5rem 1.5rem;
  background: #f0f0f0;
  transform: skewX(-15deg);
  margin-right: -8px;
  transition: background 0.2s;
}

.nav-skew-x a span {
  display: block;
  transform: skewX(15deg);
}

/* Custom checkbox dengan skew */
.checkbox-custom:checked + .checkbox-label::before {
  transform: skewX(0deg) scale(1);
}
```

## Poin Penting
- skewX(angle) untuk kemiringan horizontal saja
- skewY(angle) untuk kemiringan vertikal saja
- Untuk konten teks di dalam elemen skew, balik dengan skew negatif yang sama
- Kombinasikan skew dengan translate dan scale untuk efek yang lebih kompleks
