# Fungsi scaleX dan scaleY untuk mengubah skala pada satu sumbu tertentu

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur unik: buku bisa dilebarkan tanpa meninggikan (scaleX), atau ditinggikan tanpa melebarkan (scaleY). Seperti peregangan gambar yang tidak proporsional, scaleX meregangkan elemen secara horizontal, scaleY secara vertikal. Ini berguna untuk efek khusus seperti pintu yang terbuka, atau progress bar yang mengisi.

## Penjelasan Detail

`scaleX()` dan `scaleY()` adalah fungsi transform yang mengubah skala hanya pada satu sumbu. `scaleX(n)` mengubah skala horizontal, `scaleY(n)` mengubah skala vertikal. Nilai 1 adalah ukuran asli. Nilai 0 membuat elemen tidak terlihat pada sumbu tersebut. Nilai antara 0 dan 1 mempersempit, lebih dari 1 melebarkan. Nilai negatif membalikkan pada sumbu tersebut. Fungsi satu sumbu berguna untuk efek seperti progress bar animasi, menu yang "tumbuh" secara horizontal, atau efek squash dan stretch pada animasi.

## Contoh Kode Implementasi

```css
/* scaleX: horizontal */
.widen {
  transform: scaleX(2);
  /* Dua kali lebar asli, tinggi tetap */
}

.squeeze-x {
  transform: scaleX(0.5);
  /* Setengah lebar asli */
}

/* scaleY: vertikal */
.heighten {
  transform: scaleY(1.5);
  /* 1.5x tinggi asli, lebar tetap */
}

.squeeze-y {
  transform: scaleY(0.5);
  /* Setengah tinggi asli */
}

/* Mirror horizontal dengan scaleX */
.mirror-horizontal {
  transform: scaleX(-1);
}

/* Progress bar animasi */
.progress-bar {
  width: 100%;
  height: 8px;
  background: #e0e0e0;
  border-radius: 4px;
  overflow: hidden;
}

.progress-bar-fill {
  height: 100%;
  background: #1a73e8;
  border-radius: 4px;
  transform-origin: left center;
  animation: fillProgress 1s ease-out forwards;
}

@keyframes fillProgress {
  from {
    transform: scaleX(0);
  }
  to {
    transform: scaleX(1);
  }
}

/* Efek squash (tekan saat membentur) */
@keyframes squash {
  0%, 100% {
    transform: scaleY(1);
  }
  50% {
    transform: scaleY(0.6);
  }
}

.squash-element {
  animation: squash 0.5s ease-in-out;
}

/* Efek stretch (regang saat jatuh) */
@keyframes stretch {
  0%, 100% {
    transform: scaleX(1) scaleY(1);
  }
  50% {
    transform: scaleX(1.2) scaleY(0.8);
  }
}

.stretch-element {
  animation: stretch 0.5s ease-in-out;
}

/* Menu horizontal yang melebar */
.menu-item {
  overflow: hidden;
}

.menu-item::after {
  content: '';
  position: absolute;
  bottom: 0;
  left: 0;
  width: 100%;
  height: 2px;
  background: #1a73e8;
  transform: scaleX(0);
  transform-origin: left center;
  transition: transform 0.3s ease;
}

.menu-item:hover::after {
  transform: scaleX(1);
}

/* Reveal animasi dari tengah */
.reveal {
  transform: scaleX(0);
  transform-origin: left center;
  animation: reveal 0.5s ease-out forwards;
}

@keyframes reveal {
  from {
    transform: scaleX(0);
  }
  to {
    transform: scaleX(1);
  }
}

/* Modal muncul dengan scaleY */
.modal-content {
  transform: scaleY(0);
  transform-origin: top center;
  transition: transform 0.3s ease;
}

.modal-content.open {
  transform: scaleY(1);
}

/* Garis bawah yang meluas */
.underline-hover {
  display: inline-block;
  position: relative;
}

.underline-hover::after {
  content: '';
  position: absolute;
  bottom: -2px;
  left: 0;
  width: 100%;
  height: 2px;
  background: currentColor;
  transform: scaleX(0);
  transform-origin: right center;
  transition: transform 0.3s ease;
}

.underline-hover:hover::after {
  transform: scaleX(1);
  transform-origin: left center;
}
```

## Poin Penting
- scaleX untuk skala horizontal, scaleY untuk skala vertikal
- Nilai 0 pada sumbu membuat elemen tidak terlihat pada sumbu tersebut
- scaleX(-1) untuk mirror horizontal, scaleY(-1) untuk mirror vertikal
- Kombinasikan dengan transform-origin untuk kontrol titik skala
