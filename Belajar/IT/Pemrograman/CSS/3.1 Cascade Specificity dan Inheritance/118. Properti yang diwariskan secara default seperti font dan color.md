# Properti yang Diwariskan Secara Default

## Analogi: Perpustakaan Digital

Di perpustakaan digital, kebijakan bahasa dan jenis font yang digunakan dalam katalog akan secara otomatis diwarisi oleh semua halaman dan subkatalog. Petugas di setiap bagian tidak perlu mengatur ulang bahasa atau jenis font untuk setiap halaman yang mereka buat. Ini mirip dengan properti CSS seperti font dan color yang otomatis diwariskan dari induk ke anak.

## Penjelasan Detail

Properti CSS yang diwariskan secara default sebagian besar adalah properti yang berhubungan dengan tipografi, teks, dan beberapa properti visual lainnya. Properti-properti ini meliputi color, font-family, font-size, font-style, font-variant, font-weight, font (shorthand), letter-spacing, line-height, text-align, text-indent, text-shadow, text-transform, visibility, white-space, word-spacing, cursor, dan direction. Properti list-style juga diwariskan untuk elemen daftar. Inheritance properti ini masuk akal karena jika Anda mengubah warna teks pada body, Anda mengharapkan semua teks di dalamnya berubah menjadi warna tersebut tanpa harus menulis ulang. Properti visibility diwariskan secara visual: jika induk memiliki visibility: hidden, anak juga akan tersembunyi, meskipun anak yang secara eksplisit memiliki visibility: visible akan muncul kembali.

## Contoh Kode Implementasi

```css
body {
  /* Semua properti ini akan diwariskan ke elemen anak */
  color: #2d3748;
  font-family: 'Inter', system-ui, -apple-system, sans-serif;
  font-size: 16px;
  line-height: 1.7;
  text-align: left;
  text-rendering: optimizeLegibility;
}

.container {
  /* Anak container mewarisi semua properti dari body */
  /* Kemudian kita timpa sebagian */
  color: #1a202c; /* Menimpa color yang diwariskan */
}

.container h2 {
  font-size: 1.5rem; /* font-size tetap diwariskan tapi ditimpa */
  font-weight: 600;
}

.container p {
  /* Mewarisi color dari .container (#1a202c) */
  /* Mewarisi font-family, line-height, dll dari body */
  margin-bottom: 1rem; /* margin TIDAK diwariskan */
}

.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  overflow: hidden;
}
```

## Poin Penting
- Properti font (family, size, weight, style), color, dan line-height diwariskan
- Properti text-align, text-indent, text-transform, letter-spacing, word-spacing juga diwariskan
- Visibility diwariskan, begitu juga cursor dan direction
- Memahami properti yang diwariskan membantu menulis CSS yang lebih efisien dan bersih
