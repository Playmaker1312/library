# Nilai Revert

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada opsi "kembali ke kebijakan standar sistem" yang menghapus semua modifikasi yang dilakukan oleh administrator cabang, tetapi tetap mempertahankan kebijakan dasar yang ditetapkan oleh pengembang platform. Ini berbeda dengan "reset pabrik" yang menghilangkan semuanya. Dalam CSS, revert mengembalikan properti ke gaya yang akan diterapkan oleh browser jika tidak ada author stylesheet — yaitu ke user-agent stylesheet.

## Penjelasan Detail

Kata kunci revert mengembalikan properti CSS ke nilai yang akan dimiliki elemen tersebut berdasarkan cascade pada origin yang lebih rendah. Dalam praktiknya, revert menghapus deklarasi dari author stylesheet dan mengembalikan properti ke nilai dari user-agent stylesheet (dan user stylesheet jika ada). Ini berbeda dengan initial yang mengembalikan ke nilai spesifikasi CSS, dan unset yang berperilaku berdasarkan inheritance. Misalnya, elemen heading h1 memiliki font-weight: bold dari browser. Jika author stylesheet menetapkan font-weight: normal, menggunakan font-weight: revert akan mengembalikannya ke bold. revert lebih alami daripada initial dalam banyak kasus karena mempertahankan gaya default browser yang sudah dikenal pengguna.

## Contoh Kode Implementasi

```css
/* Mengembalikan heading ke gaya browser default */
h1, h2, h3 {
  font-size: revert; /* Kembali ke ukuran browser default */
  font-weight: revert; /* Kembali ke bold */
  margin: revert; /* Kembali ke margin default browser */
}

/* Mengembalikan link ke gaya default */
a {
  color: revert; /* Kembali ke biru */
  text-decoration: revert; /* Kembali ke underline */
}

/* all: revert */
.article {
  all: revert; /* Semua properti kembali ke gaya browser */
}

/* Perbandingan */
.compare {
  /* initial: color -> canvastext (biasanya hitam) */
  color: initial;
  
  /* revert: color -> warna dari browser (biasanya hitam untuk teks) */
  color: revert;
  
  /* Untuk h1: */
  /* initial: font-size -> medium (16px) */
  /* revert: font-size -> 2em (default browser untuk h1) */
}
```

## Poin Penting
- revert mengembalikan properti ke gaya yang ditentukan oleh user-agent/browser
- Berbeda dari initial yang mengembalikan ke nilai spesifikasi CSS
- revert mempertahankan default browser seperti ukuran heading, margin, dan warna link
- Gunakan all: revert untuk mengembalikan semua properti elemen ke gaya browser
