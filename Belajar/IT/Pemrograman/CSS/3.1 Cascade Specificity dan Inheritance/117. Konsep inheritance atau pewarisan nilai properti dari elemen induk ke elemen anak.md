# Konsep Inheritance

## Analogi: Perpustakaan Digital

Di perpustakaan digital, aturan umum dari perpustakaan pusat secara otomatis berlaku ke semua cabang di daerah. Cabang-cabang tidak perlu mendefinisikan ulang aturan tersebut kecuali ingin menyesuaikannya. Misalnya, aturan "jam buka 08.00-20.00" akan diwarisi oleh semua cabang, tetapi cabang tertentu bisa mengubahnya menjadi "09.00-21.00" sesuai kebutuhan lokal. Dalam CSS, inheritance bekerja persis seperti ini: properti dari induk diwariskan ke anak secara otomatis.

## Penjelasan Detail

Inheritance adalah mekanisme di CSS di mana beberapa properti dari elemen induk secara otomatis diturunkan ke elemen anaknya. Ini memungkinkan Anda mengatur gaya pada elemen tingkat atas dan secara otomatis diterapkan ke semua elemen di dalamnya, tanpa perlu mendeklarasikannya ulang. Tidak semua properti CSS diwariskan; hanya properti yang berkaitan dengan tipografi dan teks seperti color, font-family, font-size, line-height, dan visibility yang diwariskan secara default. Properti yang berkaitan dengan tata letak seperti margin, padding, border, width, height, dan background tidak diwariskan. Inheritance sangat berguna untuk menjaga konsistensi desain dan mengurangi duplikasi kode. Ketika sebuah properti tidak diwariskan, Anda dapat memaksa pewarisan menggunakan nilai inherit.

## Contoh Kode Implementasi

```css
/* Induk: nilai akan diwariskan ke elemen anak */
body {
  color: #333;
  font-family: 'Segoe UI', system-ui, sans-serif;
  font-size: 16px;
  line-height: 1.5;
}

/* Semua elemen di dalam body akan mewarisi properti di atas */
/* Kecuali elemen yang memiliki aturan sendiri */

/* Anak: menimpa nilai yang diwariskan */
h1 {
  font-size: 2rem; /* Menimpa font-size yang diwariskan */
  color: #1a365d; /* Menimpa color yang diwariskan */
}

p {
  font-size: 1rem; /* Tetap menggunakan font-size dari body secara implisit */
}

/* Properti yang tidak diwariskan harus dideklarasikan ulang */
section {
  padding: 2rem;
  margin-bottom: 1rem;
  background: #f7fafc;
}

/* Anak tidak akan mewarisi padding, margin, atau background dari section */
```

## Poin Penting
- Properti terkait teks (color, font, line-height) diwariskan secara default
- Properti tata letak (margin, padding, border, background) tidak diwariskan
- Inheritance mengurangi duplikasi dan memudahkan pemeliharaan kode CSS
- Gunakan nilai inherit untuk memaksa pewarisan properti yang tidak diwariskan secara default
