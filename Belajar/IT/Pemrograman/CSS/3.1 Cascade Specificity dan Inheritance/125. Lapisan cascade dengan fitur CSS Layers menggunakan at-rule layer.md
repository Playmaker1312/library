# Lapisan Cascade dengan CSS Layers

## Analogi: Perpustakaan Digital

Di perpustakaan digital, aturan dikelompokkan ke dalam lapisan berdasarkan fungsi dan prioritasnya. Lapisan pertama berisi aturan dasar yang jarang berubah, lapisan kedua berisi aturan tema, dan lapisan ketiga berisi aturan komponen. Jika ada konflik antara lapisan yang berbeda, aturan dari lapisan dengan prioritas lebih tinggi yang menang, tanpa peduli specificity. Ini memungkinkan pengelolaan aturan yang lebih terstruktur dibandingkan mencampur semuanya dalam satu ruang.

## Penjelasan Detail

CSS Layers, diperkenalkan dengan at-rule @layer, memungkinkan developer untuk mengelompokkan stylesheet ke dalam lapisan bernama yang memiliki urutan prioritas tertentu. Lapisan yang didefinisikan lebih awal memiliki prioritas lebih rendah daripada lapisan yang didefinisikan kemudian. Ini memberikan kontrol eksplisit atas cascade tanpa bergantung pada specificity atau source order yang rumit. Anda bisa mendefinisikan urutan lapisan di awal dengan @layer dan kemudian mendistribusikan aturan ke lapisan-lapisan tersebut. CSS Layers sangat berguna dalam proyek besar yang menggunakan CSS dari berbagai sumber: framework, reset, komponen, utility classes. Dengan layers, Anda bisa memastikan bahwa reset selalu memiliki prioritas terendah, diikuti framework, lalu komponen, lalu utility.

## Contoh Kode Implementasi

```css
/* Mendefinisikan urutan lapisan */
@layer reset, base, components, utilities;

/* Lapisan reset */
@layer reset {
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
}

/* Lapisan base */
@layer base {
  body {
    font-family: system-ui, sans-serif;
    color: #333;
    line-height: 1.6;
  }
  
  a {
    color: #0066cc;
  }
}

/* Lapisan components */
@layer components {
  .card {
    padding: 1.5rem;
    border: 1px solid #e2e8f0;
    border-radius: 8px;
    background: white;
  }
  
  .btn {
    display: inline-block;
    padding: 0.5rem 1rem;
    background: #0066cc;
    color: white;
    border: none;
    border-radius: 4px;
  }
}

/* Lapisan utilities (prioritas tertinggi) */
@layer utilities {
  .text-center {
    text-align: center;
  }
  
  .mt-4 {
    margin-top: 1rem;
  }
}

/* Aturan tanpa lapisan memiliki prioritas di atas semua lapisan */
.fallback {
  color: red;
}
```

## Poin Penting
- @layer memungkinkan pengelompokan CSS ke dalam lapisan dengan prioritas yang bisa diatur
- Lapisan yang muncul lebih awal dalam deklarasi memiliki prioritas lebih rendah
- Aturan di luar lapisan memiliki prioritas tertinggi, mengalahkan aturan dalam lapisan mana pun
- CSS Layers sangat membantu dalam proyek besar dengan banyak sumber stylesheet
