# Cara Menghitung Nilai Specificity

## Analogi: Perpustakaan Digital

Perpustakaan digital menggunakan sistem skor untuk menentukan prioritas aturan peminjaman. Setiap aturan diberi bobot berdasarkan tingkat kekhususannya. Aturan dengan judul buku spesifik mendapat skor lebih tinggi daripada aturan kategori umum, dan aturan kategori lebih tinggi daripada aturan jenis bahan pustaka. Demikian pula CSS memberikan skor pada setiap selector untuk menentukan prioritasnya dalam cascade.

## Penjelasan Detail

Specificity dihitung dengan sistem empat kolom (a, b, c, d) atau sering ditulis sebagai tiga angka (b, c, d) karena inline styles dianggap terpisah. Kolom a mewakili inline styles (nilai 1 jika ada, 0 jika tidak). Kolom b mewakili jumlah ID selector. Kolom c mewakili jumlah class selector, attribute selector ([type="text"]), dan pseudo-class selector (:hover, :focus). Kolom d mewakili jumlah type selector (p, h1, div) dan pseudo-element selector (::before, ::after). Universal selector (*) dan combinator (>, +, ~, spasi) tidak berkontribusi pada specificity. Nilai specificity tidak dihitung sebagai angka desimal, melainkan sebagai perbandingan kolom per kolom dari kiri ke kanan. Misalnya, specificity 0-1-0-0 selalu menang atas 0-0-10-0 meskipun 10 secara numerik lebih besar.

## Contoh Kode Implementasi

```css
/* Specificity: 0-0-0-1 (satu type selector) */
div { color: black; }

/* Specificity: 0-0-1-0 (satu class selector) */
.warning { color: orange; }

/* Specificity: 0-1-0-0 (satu ID selector) */
#header { color: blue; }

/* Specificity: 1-0-0-0 (inline style) */
/* <p style="color: red;"> */

/* Specificity: 0-0-2-1 (dua class + satu type) */
nav .menu .active a { color: green; }

/* Specificity: 0-0-1-2 (satu class + dua type) */
ul li.active { color: yellow; }

/* Specificity: 0-0-0-0 (hanya universal) */
* { box-sizing: border-box; }

/* Specificity: 0-0-1-1 (satu attribute + satu type) */
[type="text"] input { border: 1px solid gray; }
```

## Poin Penting
- Specificity dihitung berdasarkan: inline style > ID > class/attribute/pseudo-class > type/pseudo-element
- Universal selector (*) dan combinator tidak menambah specificity
- Perbandingan dilakukan kolom per kolom, bukan sebagai angka desimal
- Mengetahui cara menghitung specificity membantu debugging konflik CSS dan menulis aturan yang efisien
