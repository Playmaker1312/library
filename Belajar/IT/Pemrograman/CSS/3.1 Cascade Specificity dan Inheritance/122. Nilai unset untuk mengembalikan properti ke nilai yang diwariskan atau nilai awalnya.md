# Nilai Unset

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada kebijakan "ikuti aturan induk jika ada, jika tidak gunakan aturan standar". Misalnya, jika perpustakaan pusat memiliki aturan tentang batas peminjaman, cabang akan mengikutinya. Jika tidak ada aturan dari pusat, cabang menggunakan aturan baku yang sudah ditentukan sistem. Dalam CSS, nilai unset berperilaku seperti ini: jika properti biasanya diwariskan, unset akan berfungsi seperti inherit; jika tidak, unset akan berfungsi seperti initial.

## Penjelasan Detail

Kata kunci unset adalah nilai CSS yang berperilaku berbeda tergantung pada apakah properti yang diterapkan adalah properti yang diwariskan (inherited) atau tidak. Untuk properti yang diwariskan secara default seperti color atau font-family, unset bertindak seperti inherit, mengambil nilai dari elemen induk. Untuk properti yang tidak diwariskan seperti margin atau padding, unset bertindak seperti initial, mengembalikan properti ke nilai awalnya. Ini membuat unset menjadi nilai yang berguna ketika Anda ingin "menyetel ulang" sebuah properti ke keadaan naturalnya tanpa perlu mengingat apakah properti tersebut diwariskan atau tidak. unset sangat sering digunakan dengan properti all untuk mereset semua properti elemen sekaligus, yang berguna dalam pembuatan komponen yang terisolasi.

## Contoh Kode Implementasi

```css
/* Unset pada properti yang diwariskan */
.parent {
  color: blue;
  font-size: 20px;
}

.child {
  color: unset; /* Sama dengan inherit -> menjadi biru */
  font-size: unset; /* Sama dengan inherit -> menjadi 20px */
}

/* Unset pada properti yang tidak diwariskan */
.box {
  margin: unset; /* Sama dengan initial -> margin: 0 */
  padding: unset; /* Sama dengan initial -> padding: 0 */
  border: unset; /* Sama dengan initial -> border: none */
}

/* all: unset - reset semua properti */
.isolated-component {
  all: unset; /* Semua properti direset ke natural state */
  /* Properti diwariskan: mengikuti induk */
  /* Properti tidak diwariskan: nilai awal */
}

/* Perbandingan */
.example {
  /* inherit - selalu ambil dari induk */
  margin: inherit;
  
  /* initial - selalu nilai awal */
  margin: initial;
  
  /* unset - tergantung jenis properti */
  margin: unset; /* Tidak diwariskan -> 0 */
  color: unset; /* Diwariskan -> dari induk */
}
```

## Poin Penting
- unset bertindak seperti inherit untuk properti yang diwariskan
- unset bertindak seperti initial untuk properti yang tidak diwariskan
- all: unset sering digunakan untuk mengisolasi komponen dari gaya global
- unset lebih intuitif daripada harus memilih antara inherit dan initial secara manual
