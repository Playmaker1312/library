# Properti All

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada tombol master yang bisa menerapkan satu kebijakan ke semua aspek operasional cabang sekaligus. Daripada mengatur kebijakan peminjaman, kebijakan denda, kebijakan jam buka, dan kebijakan katalog satu per satu, administrator cukup memilih satu opsi yang mereset semuanya ke mode tertentu. Dalam CSS, properti all melakukan hal yang sama: menerapkan satu nilai ke semua properti elemen sekaligus.

## Penjelasan Detail

Properti all adalah shorthand CSS yang mereset semua properti (kecuali direction dan unicode-bidi) ke nilai tertentu. Properti ini menerima salah satu dari empat kata kunci: initial, inherit, unset, atau revert. all: initial mengembalikan semua properti ke nilai awal spesifikasi; all: inherit membuat semua properti mewarisi dari induk (meskipun ini jarang berguna); all: unset mengembalikan properti yang diwariskan ke nilai induk dan yang tidak ke nilai awal; all: revert mengembalikan ke gaya browser. Properti all sangat berguna ketika Anda ingin mengisolasi sebuah komponen dari gaya global halaman. Dengan all: unset atau all: initial, komponen memulai dari kanvas yang bersih. Namun, perhatikan bahwa properti yang menggunakan all tetap bisa ditimpa oleh aturan setelahnya.

## Contoh Kode Implementasi

```css
/* Reset komponen secara total */
.widget {
  all: initial; /* Semua properti kembali ke nilai awal */
  /* Kemudian tetapkan gaya yang diinginkan */
  display: block;
  color: #333;
  font-size: 14px;
}

/* Isolasi komponen */
.modal-content {
  all: unset; /* Reset total */
  /* Secara eksplisit atur ulang yang diperlukan */
  display: block;
  padding: 2rem;
  background: white;
  border-radius: 8px;
  font-family: system-ui, sans-serif;
  line-height: 1.5;
}

.modal-content p {
  margin-bottom: 1rem;
}

/* Perbandingan */
.all-initial {
  all: initial;
  /* Semua properti direset: color -> hitam, font-size -> medium, dll */
}

.all-unset {
  all: unset;
  /* Inherited -> dari induk, Non-inherited -> nilai awal */
}

.all-revert {
  all: revert;
  /* Semua properti kembali ke gaya browser default */
}
```

## Poin Penting
- all: initial/unset/revert mereset semua properti elemen sekaligus
- Berguna untuk mengisolasi komponen dari gaya global yang tidak diinginkan
- Setelah all, Anda harus mendeklarasikan ulang properti yang diperlukan
- Properti direction dan unicode-bidi tidak terpengaruh oleh all
