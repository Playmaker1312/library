# Konsep Cascade dalam CSS

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan digital yang memiliki banyak aturan peminjaman. Setiap kali seorang anggota meminjam buku, sistem memeriksa berbagai lapisan aturan mulai dari kebijakan nasional, kebijakan perpustakaan pusat, hingga kebijakan cabang lokal. Aturan yang lebih spesifik akan menimpa aturan yang lebih umum. Demikian pula cascade dalam CSS bekerja dengan menumpuk aturan gaya dari berbagai sumber dan menerapkan yang paling relevan.

## Penjelasan Detail

Cascade adalah mekanisme inti dalam CSS yang menentukan aturan gaya mana yang akan diterapkan ketika terdapat konflik antara beberapa deklarasi. Proses ini melibatkan tiga tahap utama: asal stylesheet (origin), specificity, dan urutan source order. Browser pertama-tama mengumpulkan semua deklarasi CSS yang cocok dengan elemen tertentu, lalu mengurutkannya berdasarkan prioritas. Deklarasi dari author stylesheet memiliki prioritas lebih tinggi daripada user stylesheet, yang pada gilirannya lebih tinggi daripada browser default. Jika dua deklarasi berasal dari sumber yang sama, specificity akan menjadi penentu. Jika specificity juga sama, deklarasi yang ditulis terakhir dalam source order akan menang. Cascade memastikan bahwa setiap elemen mendapatkan gaya yang paling tepat tanpa konflik yang ambigu.

## Contoh Kode Implementasi

```css
/* Browser default: teks hitam */
body {
  margin: 0;
  padding: 0;
}

/* User stylesheet bisa menimpa */
body {
  font-size: 16px;
}

/* Author stylesheet memiliki prioritas tertinggi */
body {
  font-family: 'Segoe UI', Tahoma, sans-serif;
  color: #333;
  line-height: 1.6;
}

/* Cascade: aturan ini menimpa color sebelumnya karena source order */
body {
  color: #1a1a1a;
}

/* Specificity lebih tinggi akan menang */
.container p {
  color: #2c3e50;
}

p {
  color: #7f8c8d; /* Tidak akan menang karena specificity lebih rendah */
}
```

## Poin Penting
- Cascade adalah algoritma yang menyelesaikan konflik deklarasi CSS dengan mempertimbangkan origin, specificity, dan source order
- Browser stylesheet memiliki prioritas terendah, diikuti user stylesheet, dan author stylesheet memiliki prioritas tertinggi
- Memahami cascade membantu developer menulis CSS yang lebih terprediksi dan mudah dipelihara
- Source order menjadi penentu terakhir ketika semua faktor lain sama
