# Nilai Initial

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada tombol "reset" yang mengembalikan pengaturan cabang ke pengaturan pabrik awal, menghilangkan semua penyesuaian yang telah dilakukan sebelumnya. Ini berguna ketika cabang telah mengubah terlalu banyak pengaturan dan ingin memulai lagi dari awal yang bersih. Dalam CSS, nilai initial berfungsi seperti tombol reset untuk properti, mengembalikannya ke nilai awal yang ditentukan oleh spesifikasi CSS.

## Penjelasan Detail

Kata kunci initial mengembalikan properti CSS ke nilai awalnya (initial value) sebagaimana didefinisikan dalam spesifikasi CSS. Nilai initial adalah nilai default yang dimiliki properti sebelum stylesheet apa pun diterapkan. Setiap properti CSS memiliki nilai initial yang berbeda; misalnya, display memiliki initial value inline, position memiliki initial value static, color memiliki initial value canvastext (biasanya hitam), dan visibility memiliki initial value visible. Penting untuk dipahami bahwa initial tidak mengembalikan properti ke gaya browser default (seperti yang dilakukan revert), melainkan ke nilai spesifikasi CSS. Misalnya, nilai initial dari display pada semua elemen adalah inline, meskipun browser menetapkan display: block untuk elemen div secara default. initial berguna untuk mengatur ulang properti yang telah diubah oleh stylesheet sebelumnya.

## Contoh Kode Implementasi

```css
/* Reset umum dengan initial */
* {
  margin: initial; /* margin: 0 */
  padding: initial; /* padding: 0 */
  box-sizing: initial; /* box-sizing: content-box */
}

/* Mengembalikan heading ke ukuran awal */
h1 {
  font-size: 2rem;
}

.article h1 {
  font-size: initial; /* Kembali ke medium (~16px) */
}

/* Mengembalikan display ke inline */
.custom-element {
  display: block; /* Diubah jadi block */
}

.custom-element .reset {
  display: initial; /* Kembali ke inline */
}

/* color initial */
.warning {
  color: red;
}

.warning .normal-text {
  color: initial; /* Kembali ke hitam (canvastext) */
}

/* all: initial - reset semua properti */
.reset-all {
  all: initial; /* Semua properti kembali ke nilai awal */
}
```

## Poin Penting
- initial mengembalikan properti ke nilai awal dari spesifikasi CSS, bukan dari browser
- Setiap properti memiliki nilai initial yang berbeda menurut spesifikasi
- initial berbeda dari revert yang mengembalikan ke gaya browser default
- Gunakan all: initial untuk mereset semua properti sekaligus
