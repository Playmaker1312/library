# Konsep Specificity

## Analogi: Perpustakaan Digital

Di perpustakaan digital, aturan yang lebih spesifik selalu didahulukan daripada aturan umum. Misalnya, aturan "buku referensi tidak boleh dipinjam" lebih spesifik daripada aturan umum "semua buku boleh dipinjam". Jika ada anggota yang mencoba meminjam buku referensi, aturan spesifik itulah yang berlaku. Dalam CSS, specificity adalah sistem pembobotan yang menentukan aturan mana yang menang ketika beberapa aturan menargetkan elemen yang sama.

## Penjelasan Detail

Specificity adalah mekanisme yang digunakan browser untuk menentukan deklarasi CSS mana yang paling relevan terhadap suatu elemen. Setiap selector memiliki nilai specificity yang dihitung berdasarkan komponen-komponennya: inline styles, ID selector, class/attribute/pseudo-class selector, dan type/pseudo-element selector. Specificity biasanya direpresentasikan sebagai skor empat bagian (a, b, c, d) atau tiga bagian tergantung jenis selectornya. Selector dengan specificity lebih tinggi akan menimpa selector dengan specificity lebih rendah, regardless of source order. Jika dua selector memiliki specificity yang sama, maka source order yang menjadi penentu. Konsep ini mencegah kekacauan dan memberikan cara yang terstruktur untuk menentukan gaya mana yang berlaku ketika ada konflik.

## Contoh Kode Implementasi

```css
/* Specificity: 0,0,0,1 (type selector) */
p {
  color: blue;
}

/* Specificity: 0,0,1,0 (class selector) */
.text {
  color: green;
}

/* Specificity: 0,1,0,0 (ID selector) */
#main-text {
  color: red;
}

/* Specificity: 1,0,0,0 (inline style) */
/* <p style="color: purple;"> akan menang atas semua di atas */

/* Specificity: 0,0,2,1 (dua class + satu type) */
.container .highlight p {
  color: orange;
}

/* Specificity: 0,0,1,1 (satu class + satu type) */
.highlight p {
  color: pink; /* Kalah dari specificity di atas */
}
```

## Poin Penting
- Specificity dihitung dari inline styles, ID, class/attribute/pseudo-class, dan type selector
- Inline styles memiliki specificity tertinggi, diikuti ID, lalu class, lalu type selector
- Universal selector (*) dan combinators (>, +, ~) tidak menambah specificity
- Pahami specificity untuk menghindari !important yang berlebihan dan menjaga CSS tetap terstruktur
