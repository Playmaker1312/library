# Nilai Inherit

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada fitur yang memungkinkan sebuah cabang untuk secara eksplisit menyatakan "saya ingin mengikuti kebijakan perpustakaan pusat" untuk aturan tertentu. Meskipun secara default kebijakan tertentu tidak diwariskan, cabang bisa secara sukarela mengadopsi kebijakan pusat dengan mencentang opsi "warisi dari pusat". Di CSS, nilai inherit berfungsi persis seperti ini: memaksa elemen untuk mewarisi nilai properti dari induknya.

## Penjelasan Detail

Kata kunci inherit dalam CSS memerintahkan elemen untuk menggunakan nilai komputasi dari properti yang sama pada elemen induknya. Ini sangat berguna untuk properti yang secara default tidak diwariskan. Misalnya, border secara default tidak diwariskan, tetapi Anda bisa membuat semua elemen di dalam kontainer mewarisi border kontainer tersebut. inherit juga berguna dalam komponen yang membutuhkan konsistensi visual dengan lingkungan sekitarnya. Nilai inherit dapat diterapkan pada properti apa pun, termasuk properti kustom (custom properties). Perlu diingat bahwa jika tidak ada elemen induk yang memiliki nilai eksplisit untuk properti tersebut, inherit akan mencari ke atas hingga ke elemen root. Jika root juga tidak memiliki nilai, nilai awal (initial value) akan digunakan.

## Contoh Kode Implementasi

```css
.container {
  color: #2c5282;
  border: 2px solid #2c5282;
  font-family: Georgia, serif;
  padding: 1rem;
}

.container p {
  /* color dan font-family diwariskan secara default - tidak perlu inherit */
  /* border TIDAK diwariskan - kita paksa dengan inherit */
  border: inherit;
  
  /* padding juga tidak diwariskan */
  padding: inherit; /* Akan menjadi 1rem (nilai dari .container) */
}

/* inherit pada link di dalam navigasi */
.nav {
  color: #333;
}

.nav a {
  color: inherit; /* Link menggunakan warna dari .nav */
  text-decoration: none;
}

/* inherit pada input */
.form-group {
  color: #4a5568;
  font-size: 14px;
}

.form-group input {
  color: inherit;
  font-size: inherit;
}
```

## Poin Penting
- inherit memaksa elemen menggunakan nilai komputasi dari elemen induknya
- Berguna untuk properti yang tidak diwariskan secara default seperti border, margin, padding
- inherit mencari ke atas hingga elemen root jika induk tidak memiliki nilai eksplisit
- Nilai inherit sangat berguna dalam pembuatan komponen yang adaptif terhadap lingkungannya
