# Urutan Prioritas Cascade Berdasarkan Asal Stylesheet

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki tiga tingkat kebijakan: kebijakan nasional sebagai dasar, kebijakan institusi sebagai penyesuai, dan kebijakan pribadi pengguna yang dapat menimpa keduanya. Kebijakan pribadi selalu didahulukan karena paling relevan dengan kebutuhan individu. Dalam CSS, tiga asal stylesheet ini analog dengan browser default, user stylesheet, dan author stylesheet — masing-masing memiliki bobot prioritas yang berbeda.

## Penjelasan Detail

CSS mengenal tiga asal stylesheet (origins) yang membentuk hierarki prioritas dalam cascade. Pertama, browser default (user-agent stylesheet) adalah gaya bawaan yang diterapkan browser ke setiap elemen HTML, seperti margin pada body atau warna tautan biru. Kedua, user stylesheet adalah gaya yang ditentukan oleh pengguna melalui pengaturan browser atau ekstensi, misalnya memperbesar ukuran font default untuk aksesibilitas. Ketiga, author stylesheet adalah gaya yang ditulis oleh developer situs web. Dalam urutan prioritas, author stylesheet menang atas user stylesheet, dan user stylesheet menang atas browser default. Namun, deklarasi !important membalikkan urutan ini: !important dalam user stylesheet akan mengalahkan !important dalam author stylesheet. Normal declarations (tanpa !important) dari author tetap mendahului user.

## Contoh Kode Implementasi

```css
/* Browser default (prioritas terendah) */
/* Contoh: <h1> memiliki font-size: 2em dan font-weight: bold secara default */

/* User stylesheet (prioritas menengah) */
/* Pengguna mungkin menambahkan di browser:
   body { font-size: 18px; }
*/

/* Author stylesheet (prioritas tertinggi untuk deklarasi normal) */
h1 {
  font-size: 2.5rem;
  font-weight: 700;
  color: #1a365d;
  margin-bottom: 0.5em;
}

/* Author !important */
.alert {
  color: #e53e3e !important;
}

/* User !important akan mengalahkan author !important */
/* User: .alert { color: #000 !important; } -> teks akan hitam */
```

## Poin Penting
- Tiga asal stylesheet: browser (default), user (pengguna), dan author (pengembang)
- Author stylesheet mendominasi deklarasi normal, tetapi user !important mendominasi author !important
- Memahami hierarki origin penting untuk debugging dan menulis CSS yang dapat diprediksi
- Gunakan cascading origin untuk memisahkan concerns: tema dasar, personalisasi pengguna, dan gaya aplikasi
