# Pseudo-Class Link

## Analogi: Perpustakaan Digital

Di perpustakaan digital, tautan ke artikel yang belum pernah dibaca ditandai dengan warna biru terang dan garis bawah. Ini memberi sinyal kepada pengguna bahwa konten tersebut masih baru dan belum diakses. Ketika pengguna telah membacanya, tautan akan berubah warna. Dalam CSS, pseudo-class :link digunakan untuk menargetkan tautan yang belum pernah dikunjungi oleh pengguna.

## Penjelasan Detail

Pseudo-class :link secara khusus menargetkan elemen <a> yang memiliki atribut href dan belum pernah dikunjungi oleh pengguna. Pseudo-class ini hanya berlaku untuk elemen <a> — tidak untuk elemen lain yang mungkin memiliki href seperti <link> atau <area>. :link bersama dengan :visited membedakan state kunjungan tautan. Keduanya harus ditempatkan sebelum :hover dan :active dalam stylesheet untuk memastikan cascade bekerja dengan benar (urutan LVHA). Perlu dicatat bahwa :link memiliki specificity yang sama dengan pseudo-class lain, yaitu 0,0,1,0 (class selector level). Dalam praktiknya, :link jarang digunakan secara eksplisit karena selector a tanpa pseudo-class sudah menargetkan semua tautan, tetapi menggunakan :link lebih eksplisit dan tepat.

## Contoh Kode Implementasi

```css
/* Semua tautan yang belum dikunjungi */
a:link {
  color: #3182ce;
  text-decoration: none;
  font-weight: 500;
}

/* Tautan yang sudah dikunjungi */
a:visited {
  color: #805ad5;
}

/* Hover pada tautan */
a:hover {
  color: #2c5282;
  text-decoration: underline;
}

/* Active press */
a:active {
  color: #c53030;
}

/* Daftar artikel blog */
.blog-post a:link {
  color: #2b6cb0;
  border-bottom: 2px solid transparent;
  transition: border-color 0.2s;
}

.blog-post a:visited {
  color: #718096;
}

.blog-post a:hover {
  border-bottom-color: #2b6cb0;
}

/* Tombol yang tampil seperti tautan */
.button-link:link {
  display: inline-block;
  padding: 0.5rem 1rem;
  background: #4299e1;
  color: white;
  border-radius: 4px;
  text-decoration: none;
}

.button-link:visited {
  background: #805ad5;
  color: white;
}
```

## Poin Penting
- :link menargetkan <a> dengan href yang belum pernah dikunjungi
- Hanya berlaku untuk elemen anchor (<a>) dengan atribut href
- Ikuti urutan LVHA: :link, :visited, :hover, :active
- Gunakan :link untuk membedakan secara eksplisit dari semua state tautan
