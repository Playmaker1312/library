# Pseudo-Class Empty

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada rak yang kosong tanpa buku. Rak ini mungkin perlu ditandai dengan pesan "Rak kosong" atau disembunyikan agar tidak membingungkan pengunjung. Dalam CSS, pseudo-class :empty memungkinkan Anda menargetkan elemen yang tidak memiliki konten sama sekali — tidak ada teks, tidak ada elemen anak, bahkan tidak ada spasi.

## Penjelasan Detail

Pseudo-class :empty menargetkan elemen yang tidak memiliki anak sama sekali, termasuk elemen anak, text node (bahkan spasi atau whitespace), atau komentar HTML. Sebuah elemen dianggap empty hanya jika tag pembuka dan penutupnya berdekatan tanpa konten di antaranya. Misalnya, <div></div> adalah empty, tetapi <div> </div> (dengan spasi) bukan. :empty berguna untuk menyembunyikan elemen kosong, menampilkan placeholder atau pesan default, atau memberikan gaya khusus pada kontainer yang belum memiliki konten. Ini sangat berguna dalam komponen dinamis di mana konten dimuat secara asinkron.

## Contoh Kode Implementasi

```css
/* Sembunyikan elemen kosong */
div:empty {
  display: none;
}

/* Tampilkan pesan default pada list kosong */
ul:empty::after {
  content: "Belum ada item";
  display: block;
  color: #a0aec0;
  font-style: italic;
  padding: 1rem;
}

/* Beri gaya pada sel tabel kosong */
td:empty {
  background-color: #f7fafc;
}

/* Card tanpa konten */
.card:empty {
  min-height: 100px;
  border: 2px dashed #cbd5e0;
  border-radius: 8px;
}

/* Notifikasi kosong */
.alert:empty {
  padding: 0;
  margin: 0;
  border: none;
}

/* Sidebar widget tanpa konten */
.widget:empty {
  display: none;
}

/* Tooltip kosong */
.tooltip:empty {
  visibility: hidden;
}
```

## Poin Penting
- :empty menargetkan elemen tanpa anak atau konten teks sama sekali
- Spasi atau whitespace membuat elemen TIDAK dianggap empty
- Berguna untuk menyembunyikan atau menandai kontainer kosong
- Sering digunakan dengan pseudo-element ::after untuk menampilkan pesan default
