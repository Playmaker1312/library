# Pseudo-Class Root

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada satu aturan master yang mengatur seluruh sistem — seperti pengaturan dasar arsitektur perpustakaan yang mempengaruhi semua halaman dan fitur. Aturan ini berada di level tertinggi dan menjadi fondasi untuk semua aturan lainnya. Dalam CSS, pseudo-class :root mewakili elemen akar dokumen, yaitu elemen <html>, dan sering digunakan untuk mendefinisikan variabel global dan pengaturan dasar.

## Penjelasan Detail

Pseudo-class :root menargetkan elemen akar dari dokumen. Dalam dokumen HTML, :root setara dengan elemen <html>, tetapi dengan specificity yang lebih tinggi (pseudo-class memiliki bobot class selector, sementara html hanya type selector). Dalam dokumen SVG, :root menargetkan elemen <svg>. :root paling sering digunakan untuk mendefinisikan custom properties (CSS variables) global yang dapat diakses oleh semua elemen dalam dokumen. Ini menjadikan :root sebagai tempat yang ideal untuk menyimpan nilai-nilai desain seperti warna tema, ukuran font, spacing, dan breakpoint. Pendekatan ini memudahkan pemeliharaan tema dan konsistensi desain di seluruh situs.

## Contoh Kode Implementasi

```css
/* Definisi variabel global di :root */
:root {
  /* Warna tema */
  --color-primary: #4299e1;
  --color-secondary: #3182ce;
  --color-accent: #ed8936;
  --color-success: #38a169;
  --color-danger: #e53e3e;
  --color-warning: #d69e2e;
  
  /* Warna netral */
  --color-white: #ffffff;
  --color-gray-100: #f7fafc;
  --color-gray-200: #edf2f7;
  --color-gray-700: #4a5568;
  --color-gray-900: #1a202c;
  
  /* Tipografi */
  --font-sans: 'Inter', system-ui, -apple-system, sans-serif;
  --font-serif: 'Georgia', 'Times New Roman', serif;
  --font-mono: 'Fira Code', monospace;
  
  /* Spacing */
  --spacing-xs: 0.25rem;
  --spacing-sm: 0.5rem;
  --spacing-md: 1rem;
  --spacing-lg: 2rem;
  --spacing-xl: 4rem;
  
  /* Border radius */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 16px;
  
  /* Shadow */
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.05);
  --shadow-md: 0 4px 6px rgba(0, 0, 0, 0.1);
  --shadow-lg: 0 10px 15px rgba(0, 0, 0, 0.1);
  
  /* Layout */
  --max-width: 1200px;
  --header-height: 64px;
}

/* Menggunakan variabel */
body {
  font-family: var(--font-sans);
  color: var(--color-gray-900);
  background: var(--color-gray-100);
}

.btn-primary {
  background: var(--color-primary);
  color: var(--color-white);
  border-radius: var(--radius-md);
  padding: var(--spacing-sm) var(--spacing-md);
}
```

## Poin Penting
- :root menargetkan elemen akar dokumen (<html> di HTML)
- Specificity lebih tinggi dari selector elemen html
- Tempat ideal untuk mendefinisikan CSS custom properties global
- Memudahkan pengelolaan tema, konsistensi desain, dan pemeliharaan kode
