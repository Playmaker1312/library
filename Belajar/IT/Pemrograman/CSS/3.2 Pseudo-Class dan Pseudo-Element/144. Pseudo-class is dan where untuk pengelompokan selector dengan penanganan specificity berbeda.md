# Pseudo-Class Is dan Where

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada dua cara untuk mengelompokkan aturan. Pertama, mengelompokkan beberapa kategori menjadi satu aturan yang mewarisi prioritas kategori tertinggi di dalamnya. Kedua, mengelompokkan kategori tetapi semua aturan dianggap memiliki prioritas yang sama tanpa peduli kategori asalnya. Dalam CSS, :is() dan :where() adalah dua pseudo-class yang melakukan hal ini dengan perbedaan penting pada specificity.

## Penjelasan Detail

Pseudo-class :is() dan :where() keduanya menerima daftar selector yang dipisahkan koma. :is(header, main, footer) p akan memilih <p> di dalam header, main, atau footer. Perbedaan kritisnya adalah cara mereka menangani specificity. :is() mengambil nilai specificity tertinggi dari selector dalam daftar argumennya. :where() selalu memiliki specificity 0 (nol), tanpa peduli selector apa yang ada di dalamnya. Ini membuat :where() ideal untuk reset CSS atau styling dasar yang harus mudah ditimpa. :is() berguna untuk mengurangi pengulangan selector tanpa mengorbankan specificity yang diperlukan. Keduanya meningkatkan keterbacaan kode dengan menggabungkan selector yang panjang.

## Contoh Kode Implementasi

```css
/* Menggunakan :is() - specificity diambil dari tertinggi */
:is(.header, .footer, .sidebar) p {
  color: #4a5568;
  line-height: 1.6;
}

/* Sama dengan menulis:
   .header p, .footer p, .sidebar p { ... }
   Specificity: 0,0,2,1 */

/* Menggunakan :where() - specificity selalu 0 */
:where(.header, .footer) h2 {
  font-size: 1.25rem;
  border-bottom: 1px solid #e2e8f0;
}

/* Mudah ditimpa: */
h2 {
  font-size: 1.5rem; /* Akan menang karena specificity 0,0,0,1 > 0,0,0,0 */
}

/* :is() untuk nested selector */
article :is(h1, h2, h3) {
  color: #1a202c;
  font-weight: 700;
}

/* :where() untuk reset */
:where(h1, h2, h3, h4, h5, h6) {
  margin: 0;
  padding: 0;
  line-height: 1.2;
}

/* Kombinasi */
.card :is(.title, .subtitle) {
  font-family: 'Georgia', serif;
}

:where(.card) :where(.title, .subtitle) {
  font-weight: 400;
}
```

## Poin Penting
- :is() dan :where() mengelompokkan selector untuk mengurangi pengulangan
- :is() mengambil specificity tertinggi dari selector argumennya
- :where() selalu memiliki specificity 0, ideal untuk reset yang mudah ditimpa
- Keduanya meningkatkan keterbacaan dan pemeliharaan kode CSS
