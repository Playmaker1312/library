# Pseudo-Class Last-Child

## Analogi: Perpustakaan Digital

Di perpustakaan digital, dalam daftar hasil pencarian, buku terakhir sering kali memiliki gaya yang berbeda — misalnya tidak memiliki garis pemisah di bawahnya. Ini memberikan tampilan yang lebih bersih dan rapi pada akhir daftar. Dalam CSS, pseudo-class :last-child memungkinkan Anda menargetkan elemen yang merupakan anak terakhir dari induknya.

## Penjelasan Detail

Pseudo-class :last-child menargetkan elemen yang merupakan anak terakhir dari elemen induknya. Ini adalah kebalikan dari :first-child. Sama seperti :first-child, seleksi ini berdasarkan posisi dalam DOM dan akan cocok hanya jika elemen tersebut benar-benar merupakan anak terakhir. :last-child sangat berguna untuk menghilangkan border-bottom atau margin-bottom pada item terakhir dalam daftar, menghindari jarak atau garis yang tidak perlu. Pseudo-class ini juga sering digunakan dalam navigasi breadcrumb, daftar menu, dan kartu dalam grid. Jika elemen yang ditargetkan bukan anak terakhir, :last-child tidak akan cocok, jadi pastikan struktur HTML Anda sesuai.

## Contoh Kode Implementasi

```css
/* Item terakhir tanpa border-bottom */
li:last-child {
  border-bottom: none;
  margin-bottom: 0;
}

/* Paragraf terakhir tanpa margin */
article p:last-child {
  margin-bottom: 0;
}

/* List item terakhir dengan gaya berbeda */
.nav-item:last-child {
  margin-right: 0;
}

/* Breadcrumb: tambah separator */
.breadcrumb-item:not(:last-child)::after {
  content: "›";
  margin: 0 0.5rem;
  color: #a0aec0;
}

/* Card terakhir dalam grid */
.card:last-child {
  margin-bottom: 0;
}

/* Hapus border-bottom pada item terakhir */
.menu > .menu-item:last-child {
  border-bottom: none;
}

/* Container anak terakhir tanpa padding-bottom */
.section > :last-child {
  margin-bottom: 0;
}

/* Form: tombol submit terakhir */
.form-actions :last-child {
  margin-right: 0;
}
```

## Poin Penting
- :last-child menargetkan elemen yang merupakan anak terakhir dari induknya
- Kebalikan dari :first-child
- Sering digunakan untuk menghilangkan border-bottom atau margin-bottom pada item terakhir
- Kombinasikan dengan :not(:last-child) untuk menambahkan separator di antara item
