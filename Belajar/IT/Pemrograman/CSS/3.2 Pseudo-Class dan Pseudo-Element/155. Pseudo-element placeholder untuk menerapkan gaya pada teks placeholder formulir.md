# Pseudo-Element Placeholder

## Analogi: Perpustakaan Digital

Di perpustakaan digital, kolom pencarian menampilkan teks abu-abu "Cari judul buku..." yang memberi petunjuk kepada pengguna tentang apa yang harus diketik. Teks ini menghilang ketika pengguna mulai mengetik. Dalam CSS, pseudo-element ::placeholder memungkinkan Anda menyesuaikan tampilan teks petunjuk ini agar sesuai dengan desain keseluruhan.

## Penjelasan Detail

Pseudo-element ::placeholder menargetkan teks placeholder dalam elemen input dan textarea. Placeholder adalah teks petunjuk yang muncul di dalam elemen formulir ketika belum memiliki nilai. Properti yang didukung untuk ::placeholder terbatas pada yang berkaitan dengan font (font-family, font-size, font-weight, font-style, font-variant), color, background, text-decoration, text-transform, letter-spacing, word-spacing, line-height, text-align, text-indent, vertical-align, white-space, word-break, overflow-wrap, opacity, dan text-overflow. Browser dulu menggunakan prefiks vendor seperti ::-webkit-input-placeholder, ::-moz-placeholder, dan :-ms-input-placeholder, tetapi ::placeholder kini sudah standar di semua browser modern. Placeholder bukanlah pengganti label — gunakan elemen <label> untuk aksesibilitas.

## Contoh Kode Implementasi

```css
/* Gaya placeholder standar */
input::placeholder {
  color: #a0aec0;
  font-size: 0.95rem;
  font-style: italic;
}

/* Textarea placeholder */
textarea::placeholder {
  color: #a0aec0;
  font-family: inherit;
  font-size: 0.9rem;
  line-height: 1.5;
}

/* Placeholder dengan opacity */
.search-input::placeholder {
  color: #718096;
  opacity: 0.7;
}

/* Placeholder tebal */
.important-input::placeholder {
  font-weight: 600;
  color: #a0aec0;
  text-transform: uppercase;
  letter-spacing: 0.05em;
}

/* Focus: placeholder berubah */
input:focus::placeholder {
  color: #cbd5e0;
  transform: translateY(-2px);
  transition: all 0.2s;
}

/* Dark mode placeholder */
@media (prefers-color-scheme: dark) {
  input::placeholder {
    color: #4a5568;
  }
}

/* Text-align center */
input.center-placeholder::placeholder {
  text-align: center;
}
```

## Poin Penting
- ::placeholder menata teks petunjuk dalam input dan textarea
- Mendukung properti font, color, background, text, dan opacity
- Gunakan <label> untuk aksesibilitas, placeholder hanya sebagai petunjuk tambahan
- ::placeholder sudah menjadi standar, dukungan prefiks vendor tidak diperlukan lagi
