# Pseudo-Element Selection

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna menyorot teks dengan mouse untuk menyalinnya, teks yang disorot berubah warna menjadi biru dengan latar putih — atau sesuai preferensi pengguna. Dalam CSS, pseudo-element ::selection memungkinkan Anda menyesuaikan tampilan teks yang dipilih oleh pengguna, memberikan identitas merek yang unik bahkan pada level interaksi dasar ini.

## Penjelasan Detail

Pseudo-element ::selection menargetkan bagian dari dokumen yang sedang dipilih (disorot) oleh pengguna. Hanya beberapa properti CSS yang dapat diterapkan pada ::selection: color, background-color, text-decoration dan properti terkait (text-decoration-color, text-decoration-style), text-shadow, stroke-color, fill-color, dan stroke-width. Penggunaan yang paling umum adalah mengubah warna teks dan latar belakang teks yang dipilih. ::selection dapat diterapkan secara global (::selection) atau pada elemen spesifik (p::selection). Penting untuk memastikan kontras yang cukup antara warna teks dan latar belakang selection agar tetap mudah dibaca.

## Contoh Kode Implementasi

```css
/* Selection global */
::selection {
  background-color: #4299e1;
  color: white;
}

/* Selection spesifik per elemen */
p::selection {
  background-color: #ebf8ff;
  color: #2b6cb0;
}

h1::selection {
  background-color: #2b6cb0;
  color: #ebf8ff;
}

/* Dark mode selection */
@media (prefers-color-scheme: dark) {
  ::selection {
    background-color: #63b3ed;
    color: #1a202c;
  }
}

/* Selection dengan text-shadow */
.highlight-text::selection {
  background-color: #fefcbf;
  color: #744210;
  text-shadow: 1px 1px 2px rgba(0, 0, 0, 0.1);
}

/* Code block selection */
code::selection {
  background-color: #2d3748;
  color: #a0aec0;
}

/* Link selection */
a::selection {
  background-color: #3182ce;
  color: white;
  text-decoration-color: white;
}
```

## Poin Penting
- ::selection mengatur gaya teks yang dipilih oleh pengguna
- Hanya properti color, background-color, text-decoration, text-shadow yang didukung
- Pastikan kontras cukup antara warna teks dan background selection
- Dapat diterapkan secara global atau per elemen untuk pengalaman yang berbeda
