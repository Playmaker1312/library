# Pseudo-Element First-Letter

## Analogi: Perpustakaan Digital

Di perpustakaan digital, bab pertama dari sebuah buku digital sering dimulai dengan huruf pertama yang sangat besar dan dekoratif — disebut drop cap. Huruf raksasa ini menarik mata pembaca dan menandai awal dari sebuah bab baru. Dalam CSS, pseudo-element ::first-letter memungkinkan Anda menerapkan efek serupa pada huruf pertama dari sebuah elemen blok.

## Penjelasan Detail

Pseudo-element ::first-letter menargetkan karakter pertama dari teks dalam elemen blok. Properti yang didukung untuk ::first-letter mirip dengan ::first-line: font, color, background, margin, padding, border, text-decoration, text-transform, line-height, float, dan vertical-align. Ini memungkinkan efek tipografi klasik seperti drop cap (huruf pertama besar yang mengapung). ::first-letter hanya bekerja pada elemen blok. Karakter pertama dihitung setelah tanda baca pembuka seperti kutipan, tanda kurung, atau tanda guillemet. Properti float: left atau right sering digunakan bersama ::first-letter untuk membuat huruf pertama mengapung dan teks mengalir di sekitarnya.

## Contoh Kode Implementasi

```css
/* Drop cap klasik */
p::first-letter {
  font-size: 3.5em;
  float: left;
  margin-right: 0.5rem;
  margin-top: 0.15em;
  line-height: 0.8;
  color: #4299e1;
  font-weight: bold;
  font-family: 'Georgia', serif;
}

/* Drop cap dengan border */
.article p:first-child::first-letter {
  font-size: 4em;
  float: left;
  padding: 0.25rem;
  margin-right: 0.5rem;
  border: 2px solid #4299e1;
  border-radius: 4px;
  color: #2b6cb0;
  line-height: 0.9;
}

/* Warna khusus untuk huruf pertama */
.story::first-letter {
  color: #e53e3e;
  font-size: 2em;
  font-weight: bold;
}

/* Initial dengan background */
.intro::first-letter {
  font-size: 3em;
  float: left;
  padding: 0.25rem 0.5rem;
  background: #2b6cb0;
  color: white;
  margin-right: 0.5rem;
  font-family: serif;
}

/* Efek outline */
.headline::first-letter {
  font-size: 4em;
  float: left;
  color: transparent;
  -webkit-text-stroke: 2px #4299e1;
  margin-right: 0.5rem;
}
```

## Poin Penting
- ::first-letter menargetkan karakter pertama dari elemen blok
- Mendukung properti font, color, float, margin, padding, border, dan background
- Sering digunakan untuk efek drop cap dalam tipografi
- Hanya bekerja pada elemen blok, bukan inline
