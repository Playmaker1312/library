# Pseudo-Class Visited

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna telah membaca sebuah artikel, tautan artikel tersebut berubah warna menjadi lebih redup. Ini membantu pengguna mengingat konten mana yang sudah mereka akses dan mana yang belum, sehingga mereka tidak membuang waktu membaca ulang. Dalam CSS, pseudo-class :visited memungkinkan Anda menerapkan gaya pada tautan yang sudah pernah dikunjungi oleh pengguna.

## Penjelasan Detail

Pseudo-class :visited secara khusus menargetkan elemen <a> yang atribut href-nya telah dikunjungi oleh pengguna (tercatat di history browser). Karena alasan privasi dan keamanan, browser membatasi properti CSS yang bisa diterapkan pada :visited. Properti yang diizinkan umumnya terbatas pada color, background-color, border-color, outline-color, dan column-rule-color. Bahkan untuk properti yang diizinkan, nilai yang digunakan oleh :visited tidak bisa dibaca oleh JavaScript melalui computed style untuk mencegah pelacakan. Ini adalah batasan privasi yang penting. Meskipun terbatas, :visited tetap berguna untuk memberikan indikasi visual yang jelas tentang tautan yang sudah dan belum dikunjungi.

## Contoh Kode Implementasi

```css
/* Tautan belum dikunjungi */
a:link {
  color: #3182ce;
  text-decoration: none;
}

/* Tautan sudah dikunjungi */
a:visited {
  color: #805ad5;
}

/* Interaksi */
a:hover {
  color: #2c5282;
  text-decoration: underline;
}

a:active {
  color: #c53030;
}

/* Penerapan pada navigasi */
.nav-link:link {
  color: #4a5568;
  font-weight: 500;
}

.nav-link:visited {
  color: #4a5568; /* Sama agar navigasi tidak berubah */
}

/* Daftar artikel */
.article-list a:link {
  color: #2b6cb0;
  border-bottom: 1px solid transparent;
}

.article-list a:visited {
  color: #718096;
}

.article-list a:hover {
  border-bottom-color: currentColor;
}
```

## Poin Penting
- :visited hanya untuk elemen <a> dengan href yang ada di history browser
- Browser membatasi properti yang bisa digunakan untuk privasi (terutama color)
- Kombinasikan dengan :link, :hover, :active dalam urutan LVHA yang benar
- Untuk navigasi, pertimbangkan untuk tidak membedakan visited agar konsisten
