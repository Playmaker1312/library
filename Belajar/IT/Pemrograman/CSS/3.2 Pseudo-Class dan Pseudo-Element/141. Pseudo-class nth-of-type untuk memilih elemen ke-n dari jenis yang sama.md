# Pseudo-Class Nth-of-Type

## Analogi: Perpustakaan Digital

Di perpustakaan digital, dalam sebuah halaman hasil pencarian yang menampilkan campuran buku, artikel, dan video, Anda mungkin ingin memberikan gaya khusus pada setiap video ke-2 yang muncul. Anda hanya peduli pada posisi video di antara video lainnya, bukan posisinya di antara semua elemen. Dalam CSS, pseudo-class :nth-of-type melayani kebutuhan ini dengan memilih elemen berdasarkan urutannya di antara saudara dengan jenis yang sama.

## Penjelasan Detail

Pseudo-class :nth-of-type menggunakan pola an+b yang sama dengan :nth-child, tetapi hanya mempertimbangkan elemen dengan jenis yang sama. Misalnya, div p:nth-of-type(2) akan memilih paragraf kedua dalam div, mengabaikan heading, gambar, atau elemen lain yang mungkin ada di antaranya. Ini sangat berguna dalam situasi di mana struktur HTML berisi campuran elemen dan Anda hanya ingin menargetkan elemen tertentu berdasarkan urutannya di antara jenisnya sendiri. :nth-of-type lebih fleksibel daripada :nth-child dalam konten yang tidak seragam, karena :nth-child bisa gagal jika ada elemen lain yang mengubah urutan absolut.

## Contoh Kode Implementasi

```css
/* Paragraf kedua dalam artikel */
.post p:nth-of-type(2) {
  font-style: italic;
  color: #4a5568;
}

/* Setiap gambar ke-3 */
.gallery img:nth-of-type(3n) {
  margin-right: 0;
}

/* Heading level 2 genap */
article h2:nth-of-type(even) {
  color: #2b6cb0;
}

/* Paragraf ganjil */
section p:nth-of-type(odd) {
  background: #f7fafc;
  padding: 0.5rem;
}

/* List item ke-n dalam container campuran */
.mixed-container li:nth-of-type(2n+1) {
  background: #ebf8ff;
}

/* 3 gambar pertama */
.container img:nth-of-type(-n+3) {
  border: 2px solid #4299e1;
}

/* Blockquote pertama dan kedua */
article blockquote:nth-of-type(-n+2) {
  border-left: 3px solid #4299e1;
}
```

## Poin Penting
- :nth-of-type memilih elemen ke-n dari jenis yang sama dalam induk
- Mengabaikan elemen jenis lain saat menghitung urutan
- Gunakan pola an+b, even, odd seperti :nth-child
- Lebih fleksibel daripada :nth-child dalam konten campuran
