# Pseudo-Class Required dan Optional

## Analogi: Perpustakaan Digital

Di perpustakaan digital, saat mengisi formulir pendaftaran anggota baru, beberapa kolom seperti "Nama Lengkap" dan "Email" diberi tanda bintang merah karena wajib diisi. Kolom lain seperti "Nomor Telepon" bersifat opsional. Perbedaan visual ini membantu pengguna mengetahui informasi mana yang esensial. Dalam CSS, pseudo-class :required dan :optional memungkinkan Anda menata elemen berdasarkan atribut required.

## Penjelasan Detail

Pseudo-class :required menargetkan elemen formulir yang memiliki atribut required, yang menandakan bahwa elemen tersebut harus diisi sebelum form dapat disubmit. Sebaliknya, :optional menargetkan elemen formulir yang tidak memiliki atribut required. Kedua pseudo-class ini dapat diterapkan pada elemen input, select, dan textarea. Dengan menggunakan :required dan :optional, Anda dapat memberikan petunjuk visual yang jelas tentang kolom mana yang wajib diisi tanpa harus menambahkan kelas CSS tambahan di HTML. Ini membuat kode lebih bersih dan lebih mudah dipelihara. Anda juga bisa menggabungkannya dengan pseudo-class validitas seperti :valid dan :invalid untuk memberikan umpan balik real-time.

## Contoh Kode Implementasi

```css
/* Kolom wajib diisi */
input:required {
  border-left: 3px solid #e53e3e;
}

/* Kolom opsional */
input:optional {
  border-left: 3px solid #a0aec0;
}

/* Label untuk kolom wajib */
input:required + label::after {
  content: " *";
  color: #e53e3e;
  font-weight: bold;
}

/* Select wajib */
select:required {
  background-color: #fff5f5;
}

/* Textarea opsional */
textarea:optional {
  background-color: white;
}

/* Kombinasi dengan validitas */
input:required:valid {
  border-left-color: #38a169;
}

input:required:invalid {
  border-left-color: #e53e3e;
}

/* Fieldset dengan semua kolom wajib */
fieldset:required {
  border-color: #e53e3e;
}

/* Pesan bantuan untuk kolom */
input:optional ~ .hint {
  display: block;
  color: #718096;
  font-size: 0.875rem;
}
```

## Poin Penting
- :required untuk elemen dengan atribut required, :optional untuk yang tanpa
- Berguna untuk memberikan indikasi visual kolom wajib dan opsional
- Dapat dikombinasikan dengan :valid dan :invalid untuk umpan balik real-time
- Mengurangi penggunaan class CSS tambahan di HTML untuk status required
