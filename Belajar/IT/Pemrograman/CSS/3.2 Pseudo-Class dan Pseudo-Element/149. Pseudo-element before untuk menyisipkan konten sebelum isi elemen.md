# Pseudo-Element Before

## Analogi: Perpustakaan Digital

Di perpustakaan digital, setiap kali sebuah buku ditampilkan dalam daftar hasil pencarian, secara otomatis muncul ikon kecil di sebelah kiri judul buku yang menandakan jenis buku (novel, referensi, atau majalah). Ikon ini tidak ada di dalam data HTML tetapi muncul secara visual. Dalam CSS, pseudo-element ::before bekerja seperti ini: menyisipkan konten dekoratif sebelum konten utama elemen.

## Penjelasan Detail

Pseudo-element ::before membuat elemen virtual sebagai anak pertama dari elemen yang dipilih, sebelum konten elemen tersebut. Properti content wajib ada agar ::before berfungsi — tanpa content, pseudo-element tidak akan muncul. ::before dapat digunakan untuk berbagai tujuan: menambahkan ikon, label, quote marks, indikator visual, atau dekorasi lainnya. Secara default, ::before adalah elemen inline. Anda bisa mengubah display menjadi block atau inline-block untuk kebutuhan layout. Pseudo-element ini tidak dapat diterapkan pada elemen void seperti <img>, <br>, atau <input> karena elemen-elemen tersebut tidak memiliki konten.

## Contoh Kode Implementasi

```css
/* Tanda kutip pada blockquote */
blockquote::before {
  content: "\201C";
  font-size: 3em;
  color: #4299e1;
  line-height: 0;
  vertical-align: -0.4em;
  margin-right: 0.25rem;
}

/* Ikon pada link eksternal */
a[target="_blank"]::before {
  content: "↗";
  margin-right: 0.25rem;
}

/* Label pada required field */
input:required::before {
  content: "*";
  color: #e53e3e;
}

/* Nomor pada heading */
section h2::before {
  counter-increment: section;
  content: counter(section) ". ";
  color: #4299e1;
}

/* Clearfix */
.clearfix::before {
  content: "";
  display: table;
}

/* Breadcrumb separator */
.breadcrumb-item + .breadcrumb-item::before {
  content: "›";
  margin: 0 0.5rem;
  color: #a0aec0;
}

/* Icon file berdasarkan ekstensi */
a[href$=".pdf"]::before {
  content: "📄";
  margin-right: 0.25rem;
}
```

## Poin Penting
- ::before menyisipkan konten virtual sebelum konten elemen
- Properti content WAJIB ada, bisa berupa string, image, atau empty string
- ::before adalah inline element secara default, bisa diubah display-nya
- Tidak bisa digunakan pada elemen void seperti <img>, <br>, <input>
