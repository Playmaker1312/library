# Pseudo-Class Hover

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna mengarahkan kursor ke judul buku, muncul pratinjau singkat tentang buku tersebut. Ini memberikan umpan balik visual bahwa elemen tersebut dapat diklik atau memiliki informasi tambahan. Dalam CSS, pseudo-class :hover bekerja dengan cara yang sama: menerapkan gaya ketika kursor mouse berada di atas elemen, memberikan indikasi interaktivitas kepada pengguna.

## Penjelasan Detail

Pseudo-class :hover diterapkan ketika pengguna mengarahkan kursor (pointer) ke atas suatu elemen, tetapi belum mengkliknya. Ini adalah salah satu pseudo-class yang paling sering digunakan dalam CSS, terutama untuk tautan, tombol, kartu, dan elemen interaktif lainnya. :hover biasanya digunakan untuk memberikan umpan balik visual seperti perubahan warna, underline, elevasi (shadow), atau transformasi skala. Dalam konteks tautan, :hover sering dikombinasikan dengan :link, :visited, dan :active untuk menciptakan pengalaman yang lengkap. Pada perangkat layar sentuh, :hover bersifat sementara dan hanya aktif saat pengguna menyentuh elemen. Penting untuk tidak menggantungkan fungsi penting hanya pada :hover karena tidak berfungsi dengan baik di perangkat sentuh dan dapat mengurangi aksesibilitas.

## Contoh Kode Implementasi

```css
/* Tautan */
a {
  color: #3182ce;
  text-decoration: none;
  transition: color 0.2s ease;
}

a:hover {
  color: #2c5282;
  text-decoration: underline;
}

/* Tombol */
.btn {
  display: inline-block;
  padding: 0.75rem 1.5rem;
  background: #4299e1;
  color: white;
  border: none;
  border-radius: 6px;
  font-size: 1rem;
  cursor: pointer;
  transition: all 0.2s ease;
}

.btn:hover {
  background: #3182ce;
  transform: translateY(-1px);
  box-shadow: 0 4px 8px rgba(0, 0, 0, 0.15);
}

/* Kartu */
.card {
  transition: box-shadow 0.3s ease;
}

.card:hover {
  box-shadow: 0 8px 16px rgba(0, 0, 0, 0.1);
}

/* Baris tabel */
tr:hover {
  background-color: #ebf8ff;
}

/* Gambar */
img:hover {
  opacity: 0.9;
}
```

## Poin Penting
- :hover aktif saat pointer (mouse) berada di atas elemen
- Sering digunakan untuk umpan balik visual pada tautan, tombol, dan elemen interaktif
- Tidak persisten di perangkat sentuh, jadikan sebagai peningkatan saja
- Gunakan transisi untuk animasi yang halus saat masuk dan keluar hover
