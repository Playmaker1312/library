# Pseudo-Class Nth-Last-Child

## Analogi: Perpustakaan Digital

Di perpustakaan digital, kadang Anda ingin menandai beberapa buku terakhir yang baru ditambahkan ke koleksi. Anda ingin memberikan gaya khusus pada 3 buku terakhir dalam daftar tanpa harus tahu berapa total jumlah buku. Dalam CSS, pseudo-class :nth-last-child memungkinkan Anda menghitung posisi elemen dari akhir daftar, bukan dari awal.

## Penjelasan Detail

Pseudo-class :nth-last-child bekerja seperti :nth-child, tetapi menghitung dari elemen terakhir mundur ke awal. Sintaksnya sama menggunakan pola an+b. Misalnya, :nth-last-child(1) memilih elemen terakhir (sama dengan :last-child), :nth-last-child(2n) memilih elemen genap dari bawah, dan :nth-last-child(-n+3) memilih 3 elemen terakhir. Ini sangat berguna ketika Anda ingin memberikan gaya pada elemen di akhir daftar tanpa mengetahui jumlah total elemen. Misalnya, Anda ingin menambahkan border-top pada 3 item terakhir dalam daftar, atau ingin memberikan gaya khusus pada item yang baru ditambahkan (yang biasanya muncul di akhir).

## Contoh Kode Implementasi

```css
/* Elemen terakhir */
li:nth-last-child(1) {
  border-bottom: none;
}

/* 3 elemen terakhir */
li:nth-last-child(-n+3) {
  background: #fffff0;
  font-weight: 500;
}

/* Elemen kedua dari akhir */
li:nth-last-child(2) {
  border-bottom: 2px dashed #cbd5e0;
}

/* Elemen genap dari bawah */
li:nth-last-child(2n) {
  background: #f7fafc;
}

/* 5 item terakhir dengan margin */
.item:nth-last-child(-n+5) {
  margin-bottom: 0.5rem;
}

/* Gabungan: pilih jika setidaknya ada 4 item */
li:nth-last-child(n+4) {
  /* Gaya hanya jika total >= 4 */
}

/* Log: item terakhir yang baru ditambahkan */
.log-entry:nth-last-child(-n+2) {
  border-left: 3px solid #4299e1;
  padding-left: 0.5rem;
}
```

## Poin Penting
- :nth-last-child menghitung posisi dari akhir daftar (mundur)
- Sintaks an+b sama dengan :nth-child
- Berguna untuk menargetkan sejumlah item terakhir tanpa tahu totalnya
- :nth-last-child(1) sama dengan :last-child
