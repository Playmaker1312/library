# Pseudo-Class Has

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda mungkin ingin memberikan gaya khusus pada kategori yang memiliki setidaknya satu buku dengan status "best seller". Atau ingin menyorot rak yang berisi buku yang sudah habis masa pinjamnya. Dalam CSS, pseudo-class :has() — yang dikenal sebagai "parent selector" — memungkinkan Anda memilih elemen berdasarkan konten yang dikandungnya, sesuatu yang sebelumnya tidak mungkin dilakukan dengan CSS murni.

## Penjelasan Detail

Pseudo-class :has() adalah relational pseudo-class yang memilih elemen jika argumen selector yang diberikan cocok dengan setidaknya satu elemen di dalamnya. Fungsi ini membalikkan arah seleksi CSS tradisional — dari anak ke induk, atau dari saudara ke saudara. Contohnya, div:has(img) akan memilih div yang mengandung setidaknya satu elemen <img>. :has() juga bisa digunakan untuk memilih saudara sebelumnya: h2:has(+ p) memilih h2 yang diikuti oleh paragraf. Pseudo-class ini membuka banyak kemungkinan baru dalam CSS, seperti styling form berdasarkan validitas, menandai kartu yang memiliki konten tertentu, atau membuat navigasi kontekstual tanpa JavaScript.

## Contoh Kode Implementasi

```css
/* Pilih card yang memiliki gambar */
.card:has(img) {
  padding: 0;
  overflow: hidden;
}

/* Form group yang berisi input invalid */
.form-group:has(input:invalid) {
  border-color: #e53e3e;
}

.form-group:has(input:valid) {
  border-color: #38a169;
}

/* Section yang memiliki heading */
section:has(h2) {
  margin-top: 2rem;
}

/* Link yang memiliki icon */
a:has(svg) {
  display: inline-flex;
  align-items: center;
  gap: 0.5rem;
}

/* Pilih li yang berisi sublist */
li:has(ul, ol) {
  list-style-type: disc;
  font-weight: bold;
}

/* Pilih paragraf yang diikuti oleh blockquote */
p:has(+ blockquote) {
  margin-bottom: 0;
}

/* Highlight baris yang memiliki checkbox checked */
tr:has(input:checked) {
  background-color: #ebf8ff;
}
```

## Poin Penting
- :has() memilih elemen berdasarkan elemen yang dikandungnya ("parent selector")
- Membalikkan arah seleksi CSS dari anak ke induk atau saudara sebelumnya
- Membuka kemungkinan styling kontekstual baru tanpa JavaScript
- Didukung di browser modern, berguna untuk form, kartu, dan navigasi
