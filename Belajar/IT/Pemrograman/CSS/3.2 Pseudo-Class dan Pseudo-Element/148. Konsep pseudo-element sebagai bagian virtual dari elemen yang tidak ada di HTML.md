# Konsep Pseudo-Element

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada elemen antarmuka yang tidak tercatat secara eksplisit dalam database buku tetapi tetap muncul di layar — seperti garis pemisah antar kategori, ikon kecil di samping judul, atau bayangan di bawah kartu buku. Elemen-elemen ini ada secara visual tetapi tidak ada dalam struktur data. Dalam CSS, pseudo-element bekerja dengan cara yang sama: memungkinkan Anda menata bagian virtual dari elemen yang tidak ada di markup HTML.

## Penjelasan Detail

Pseudo-element adalah kata kunci yang ditambahkan ke selector untuk menata bagian tertentu dari elemen yang tidak direpresentasikan secara eksplisit di DOM. Berbeda dengan pseudo-class yang menandai state, pseudo-element menciptakan atau menargetkan bagian virtual dari elemen. Pseudo-element ditulis dengan dua titik dua (::) untuk membedakannya dari pseudo-class (:). Contoh pseudo-element termasuk ::before dan ::after untuk menyisipkan konten, ::first-line untuk baris pertama, ::first-letter untuk huruf pertama, ::selection untuk teks yang dipilih, dan ::placeholder untuk teks placeholder. Pseudo-element memungkinkan dekorasi dan penataan konten yang lebih kaya tanpa memodifikasi HTML, menjaga markup tetap bersih dan semantik.

## Contoh Kode Implementasi

```css
/* ::before - sisipkan konten sebelum elemen */
.note::before {
  content: "ℹ️ ";
  font-size: 1.2em;
}

/* ::after - sisipkan konten setelah elemen */
.external-link::after {
  content: " ↗";
  font-size: 0.8em;
}

/* ::first-line - baris pertama paragraf */
p::first-line {
  font-weight: 600;
  color: #2d3748;
}

/* ::first-letter - huruf pertama */
p::first-letter {
  font-size: 2.5em;
  float: left;
  margin-right: 0.5rem;
  color: #4299e1;
  font-weight: bold;
}

/* ::selection - teks yang dipilih */
::selection {
  background: #4299e1;
  color: white;
}

/* ::placeholder - placeholder input */
input::placeholder {
  color: #a0aec0;
  font-style: italic;
}

/* ::marker - bullet list */
li::marker {
  color: #4299e1;
  font-weight: bold;
}
```

## Poin Penting
- Pseudo-element menggunakan notasi :: (dua titik dua) untuk membedakan dari pseudo-class
- Membuat atau menargetkan bagian elemen yang tidak ada di HTML
- ::before dan ::after membutuhkan properti content untuk berfungsi
- Pseudo-element memperkaya tampilan tanpa memodifikasi markup HTML
