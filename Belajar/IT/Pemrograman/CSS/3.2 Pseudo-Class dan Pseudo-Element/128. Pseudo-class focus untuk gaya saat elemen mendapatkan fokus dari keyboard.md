# Pseudo-Class Focus

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna menavigasi menggunakan keyboard (misalnya tombol Tab), satu elemen pada halaman akan "disorot" sebagai yang aktif. Ini membantu pengguna mengetahui posisi mereka saat ini, terutama penting bagi pengguna dengan keterbatasan motorik yang tidak bisa menggunakan mouse. Dalam CSS, pseudo-class :focus menangani keadaan ini.

## Penjelasan Detail

Pseudo-class :focus diterapkan pada elemen yang saat ini menjadi fokus, baik melalui navigasi keyboard (Tab), klik mouse, atau aktivasi programatik via JavaScript. Elemen yang umum menerima fokus adalah elemen interaktif seperti input, textarea, select, button, dan tautan. Elemen non-interaktif seperti div atau span bisa diberi fokus dengan menambahkan atribut tabindex. :focus sangat penting untuk aksesibilitas karena menyediakan indikator visual bagi pengguna keyboard untuk mengetahui elemen mana yang aktif. Praktik terbaik adalah selalu menyertakan gaya :focus yang jelas, biasanya berupa outline, dan jangan pernah menghapus outline tanpa menyediakan alternatif visual.

## Contoh Kode Implementasi

```css
/* Gaya fokus default yang jelas */
input:focus {
  outline: 2px solid #4299e1;
  outline-offset: 2px;
  border-color: #4299e1;
  box-shadow: 0 0 0 3px rgba(66, 153, 225, 0.15);
}

/* Focus pada tombol */
button:focus {
  outline: 2px solid #2b6cb0;
  outline-offset: 2px;
}

/* Focus pada tautan */
a:focus {
  outline: 2px solid #3182ce;
  outline-offset: 2px;
  text-decoration: underline;
}

/* Jangan hapus outline tanpa alternatif */
/* BURUK: outline: none tanpa alternatif */
/* BAIK: custom focus style */
.custom-focus:focus {
  outline: none;
  box-shadow: 0 0 0 3px rgba(66, 153, 225, 0.5);
  border-radius: 4px;
}

/* Focus-visible (hanya untuk keyboard) */
button:focus-visible {
  outline: 3px solid #4299e1;
  outline-offset: 2px;
}

button:focus:not(:focus-visible) {
  outline: none; /* Mouse click tanpa outline */
}
```

## Poin Penting
- :focus aktif ketika elemen menjadi target fokus keyboard atau klik
- Sangat penting untuk aksesibilitas pengguna keyboard
- Jangan hapus outline focus tanpa menyediakan alternatif visual
- Gunakan :focus-visible untuk membedakan fokus keyboard dan mouse
