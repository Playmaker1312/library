# Pseudo-Class First-of-Type dan Last-of-Type

## Analogi: Perpustakaan Digital

Di perpustakaan digital, dalam sebuah halaman yang berisi campuran berbagai jenis konten (teks, gambar, tabel), Anda mungkin ingin memberikan gaya khusus pada paragraf pertama yang muncul, tanpa peduli apakah ada gambar atau heading sebelumnya. Ini berbeda dengan memilih "anak pertama" yang mengharuskan elemen tersebut menjadi anak pertama secara keseluruhan. Dalam CSS, pseudo-class :first-of-type dan :last-of-type memungkinkan seleksi berdasarkan jenis elemen, bukan posisi absolut.

## Penjelasan Detail

Pseudo-class :first-of-type menargetkan elemen yang merupakan pertama dari jenisnya di antara saudara-saudaranya. Berbeda dengan :first-child yang hanya cocok jika elemen adalah anak pertama secara keseluruhan, :first-of-type akan cocok untuk elemen pertama dari jenis tertentu meskipun ada elemen jenis lain sebelumnya. Misalnya, dalam div yang berisi <h1>, <p>, <p>, maka p:first-of-type akan menargetkan <p> pertama meskipun <h1> adalah anak pertama secara keseluruhan. :last-of-type adalah kebalikannya, menargetkan elemen terakhir dari jenisnya. Pseudo-class ini sangat berguna untuk memberikan gaya pada heading, paragraf, atau elemen pertama/terakhir dalam konten campuran.

## Contoh Kode Implementasi

```css
/* Paragraf pertama dari jenisnya */
article p:first-of-type {
  font-size: 1.125rem;
  font-weight: 500;
  color: #2d3748;
}

/* Heading pertama */
section h2:first-of-type {
  margin-top: 0;
}

/* Gambar terakhir */
.gallery img:last-of-type {
  margin-right: 0;
}

/* List item pertama dari jenisnya */
.container li:first-of-type {
  font-weight: bold;
}

/* Kombinasi untuk konten campuran */
.blog-post p:first-of-type::first-letter {
  font-size: 2.5em;
  float: left;
  margin-right: 0.5rem;
  color: #4299e1;
}

/* Hapus margin pada heading terakhir */
.blog-post h2:last-of-type {
  margin-bottom: 0.5rem;
}

/* Setiap gambar pertama dalam section */
section img:first-of-type {
  border-radius: 8px 8px 0 0;
}

/* Blockquote pertama */
article blockquote:first-of-type {
  border-left: 4px solid #4299e1;
  margin-left: 0;
  padding-left: 1rem;
}
```

## Poin Penting
- :first-of-type memilih elemen pertama dari jenisnya, bukan anak pertama mutlak
- :last-of-type memilih elemen terakhir dari jenisnya
- Berguna dalam konten campuran dengan berbagai jenis elemen
- Berbeda dengan :first-child/:last-child yang berdasarkan posisi absolut dalam DOM
