# Konsep Pseudo-Class

## Analogi: Perpustakaan Digital

Di perpustakaan digital, buku dapat memiliki status yang berubah-ubah: tersedia, dipinjam, dalam perbaikan, atau hilang. Setiap status memungkinkan tindakan yang berbeda terhadap buku tersebut. Pengguna hanya bisa meminjam buku yang berstatus tersedia, dan hanya bisa memperpanjang buku yang sedang dipinjam oleh mereka. Dalam CSS, pseudo-class bekerja seperti status ini: memungkinkan Anda menerapkan gaya berdasarkan kondisi atau status elemen, bukan berdasarkan nama atau kelas di HTML.

## Penjelasan Detail

Pseudo-class adalah kata kunci yang ditambahkan ke selector untuk menentukan keadaan khusus dari elemen yang dipilih. Pseudo-class diawali dengan titik dua (:) dan dapat diterapkan pada elemen berdasarkan interaksi pengguna (:hover, :focus, :active), posisi elemen dalam dokumen (:first-child, :last-child, :nth-child), status formulir (:checked, :disabled, :valid, :invalid), atau kondisi lainnya seperti :empty dan :root. Tidak seperti kelas biasa yang ditambahkan secara eksplisit di HTML, pseudo-class secara dinamis mencerminkan state elemen. Ini memungkinkan pembuatan antarmuka yang responsif terhadap tindakan pengguna tanpa perlu JavaScript. Pseudo-class dapat digabungkan dengan selector lain untuk menargetkan elemen secara lebih spesifik.

## Contoh Kode Implementasi

```css
/* Pseudo-class berdasarkan interaksi pengguna */
button:hover {
  background: #2b6cb0;
  cursor: pointer;
}

input:focus {
  outline: 2px solid #4299e1;
  border-color: #4299e1;
}

a:active {
  color: #c53030;
}

/* Pseudo-class berdasarkan posisi */
li:first-child {
  font-weight: bold;
}

li:last-child {
  border-bottom: none;
}

li:nth-child(even) {
  background: #f7fafc;
}

/* Pseudo-class berdasarkan status formulir */
input:checked + label {
  color: #38a169;
  font-weight: bold;
}

input:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

input:valid {
  border-color: #38a169;
}

input:invalid {
  border-color: #fc8181;
}
```

## Poin Penting
- Pseudo-class diawali dengan satu titik dua (:) dan merepresentasikan state dinamis
- Dapat dikombinasikan dengan selector lain untuk target yang lebih spesifik
- Pseudo-class memungkinkan responsivitas UI tanpa JavaScript
- Kategori utama: interaksi, posisi, status formulir, dan kondisi struktural
