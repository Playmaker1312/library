# Pseudo-Class Checked

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna mencentang kategori buku yang ingin dicari, kotak centang berubah warna dan muncul tanda centang. Umpan balik visual ini mengkonfirmasi bahwa opsi telah dipilih. Dalam CSS, pseudo-class :checked memungkinkan Anda menerapkan gaya pada elemen yang sedang dalam keadaan terpilih (checked).

## Penjelasan Detail

Pseudo-class :checked diterapkan pada elemen input tipe checkbox, radio, dan opsi dalam elemen <select> (khususnya <option>) yang sedang dalam keadaan dipilih. Untuk checkbox, :checked aktif ketika kotak dicentang. Untuk radio, :checked aktif ketika tombol radio dalam grup yang sama dipilih. Pseudo-class ini sangat berguna untuk membuat komponen kustom yang stylish tanpa JavaScript. Dengan menggabungkan :checked dengan sibling selector (+ atau ~), Anda bisa membuat efek seperti toggle switch, accordion, tab panel, dan komponen interaktif lainnya murni dengan CSS. Perubahan state :checked dapat dianimasikan dengan transition.

## Contoh Kode Implementasi

```css
/* Checkbox kustom */
input[type="checkbox"] {
  appearance: none;
  width: 20px;
  height: 20px;
  border: 2px solid #cbd5e0;
  border-radius: 4px;
  cursor: pointer;
  transition: all 0.2s;
}

input[type="checkbox"]:checked {
  background-color: #4299e1;
  border-color: #4299e1;
  background-image: url("data:image/svg+xml,...");
  background-position: center;
  background-repeat: no-repeat;
}

/* Radio button kustom */
input[type="radio"] {
  appearance: none;
  width: 20px;
  height: 20px;
  border: 2px solid #cbd5e0;
  border-radius: 50%;
  cursor: pointer;
}

input[type="radio"]:checked {
  border-color: #4299e1;
  background-color: #4299e1;
  box-shadow: inset 0 0 0 4px white;
}

/* Label berubah saat checkbox dicentang */
input[type="checkbox"]:checked + label {
  color: #38a169;
  text-decoration: line-through;
}

/* Toggle switch */
.toggle:checked + .toggle-label::after {
  transform: translateX(24px);
  background: #4299e1;
}

/* Highlight baris tabel */
tr:has(input:checked) {
  background-color: #ebf8ff;
}
```

## Poin Penting
- :checked untuk input[type="checkbox"], input[type="radio"], dan <option>
- Dapat dikombinasikan dengan sibling selector untuk efek interaktif murni CSS
- Gunakan appearance: none untuk styling checkbox/radio kustom
- State :checked dapat dianimasikan dengan properti transition
