# Pseudo-Element First-Line

## Analogi: Perpustakaan Digital

Di perpustakaan digital, baris pertama dari ringkasan buku ditampilkan dengan font yang lebih tebal dan sedikit lebih besar untuk menarik perhatian pembaca. Ini membantu pembaca memutuskan apakah mereka tertarik untuk membaca lebih lanjut. Dalam CSS, pseudo-element ::first-line memungkinkan Anda menerapkan gaya khusus hanya pada baris pertama dari sebuah elemen blok.

## Penjelasan Detail

Pseudo-element ::first-line menargetkan baris pertama teks dalam elemen blok seperti paragraf, heading, atau div. Properti apa yang bisa diterapkan pada ::first-line terbatas. Hanya properti yang berkaitan dengan font (font-family, font-size, font-weight, font-style, font-variant), color, background, text-decoration, text-transform, letter-spacing, word-spacing, line-height, dan vertical-align yang didukung. Properti layout seperti float, margin, padding, dan width tidak berfungsi. ::first-line bersifat responsif — jika lebar viewport berubah, baris pertama yang ditargetkan juga berubah, karena pseudo-element ini mengikuti rendering visual, bukan struktur DOM.

## Contoh Kode Implementasi

```css
/* Drop cap effect pada baris pertama */
p::first-line {
  font-weight: 600;
  color: #2d3748;
  font-size: 1.1em;
}

/* Baris pertama artikel */
.article-lead::first-line {
  font-variant: small-caps;
  letter-spacing: 0.05em;
  color: #2b6cb0;
}

/* Heading dengan baris pertama berbeda */
h2::first-line {
  color: #4299e1;
}

/* Quote dengan baris pertama tebal */
blockquote p::first-line {
  font-style: italic;
  font-weight: 600;
}

/* Background pada baris pertama */
.highlight-first::first-line {
  background-color: #fffff0;
  padding: 0.25rem 0;
}

/* Surat: salam pembuka */
.letter p::first-line {
  font-size: 1.1em;
  color: #4a5568;
}

/* Kombinasi dengan first-letter */
p::first-line {
  font-weight: 600;
  color: #2d3748;
}

p::first-letter {
  font-size: 2.5em;
  float: left;
  margin-right: 0.5rem;
  color: #4299e1;
}
```

## Poin Penting
- ::first-line menargetkan baris pertama teks dalam elemen blok
- Hanya properti terkait font, color, background, dan teks yang didukung
- Bersifat responsif terhadap perubahan lebar viewport
- Dapat dikombinasikan dengan ::first-letter untuk efek tipografi yang kaya
