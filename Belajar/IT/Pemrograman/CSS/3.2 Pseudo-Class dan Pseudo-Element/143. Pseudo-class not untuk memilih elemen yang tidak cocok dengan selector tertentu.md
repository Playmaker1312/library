# Pseudo-Class Not

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda mungkin ingin menerapkan aturan ke semua buku kecuali buku referensi. Atau memberikan diskon peminjaman ke semua anggota kecuali anggota VIP. Dalam CSS, pseudo-class :not() — disebut negation pseudo-class — memungkinkan Anda mengecualikan elemen yang cocok dengan selector tertentu dari aturan yang diterapkan.

## Penjelasan Detail

Pseudo-class :not() menerima selector sebagai argumen dan menargetkan elemen yang tidak cocok dengan selector tersebut. Misalnya, input:not([type="submit"]) akan menargetkan semua input kecuali yang bertipe submit. Pseudo-class :not() dapat meningkatkan keterbacaan kode secara signifikan dengan menghindari penulisan beberapa selector atau override. Dalam CSS3, :not() hanya menerima selector sederhana (type, class, ID, attribute, pseudo-class). CSS Selector Level 4 memperluasnya untuk menerima selector kompleks. :not() dapat ditumpuk dan digabungkan dengan pseudo-class lain. Perlu diingat bahwa specificity dari :not() dihitung dari argumen selectornya, bukan dari pseudo-class itu sendiri.

## Contoh Kode Implementasi

```css
/* Semua input kecuali submit */
input:not([type="submit"]) {
  border: 1px solid #cbd5e0;
  padding: 0.5rem;
}

/* List item kecuali yang terakhir */
li:not(:last-child) {
  border-bottom: 1px solid #e2e8f0;
  margin-bottom: 0.5rem;
}

/* Paragraf tanpa class .lead */
p:not(.lead) {
  color: #4a5568;
  font-size: 0.95rem;
}

/* Semua elemen kecuali yang disabled */
button:not(:disabled) {
  cursor: pointer;
}

button:not(:disabled):hover {
  background: #3182ce;
}

/* Link yang bukan di navigasi */
a:not(nav a) {
  color: #3182ce;
}

/* Semua anak kecuali yang ke-3 */
li:not(:nth-child(3)) {
  opacity: 0.8;
}

/* Gabungan: semua checkbox kecuali yang disabled */
input[type="checkbox"]:not(:disabled) {
  cursor: pointer;
}
```

## Poin Penting
- :not() menargetkan elemen yang tidak cocok dengan selector argumen
- Meningkatkan keterbacaan dengan menghindari multiple selector atau override
- Specificity :not() dihitung dari argumen selector, bukan pseudo-class-nya
- Di CSS3, :not() hanya menerima selector sederhana; CSS4 menerima selector kompleks
