# Pseudo-Class Active

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna menekan tombol "Pinjam" dan sebelum melepaskannya, tombol tersebut sedikit terbenam untuk memberikan sensasi fisik bahwa tombol sedang ditekan. Umpan balik ini sangat singkat tetapi penting untuk memberikan keyakinan bahwa aksi telah terdaftar. Dalam CSS, pseudo-class :active mewakili momen antara ditekan dan dilepaskan ini.

## Penjelasan Detail

Pseudo-class :active diterapkan pada elemen pada saat elemen sedang diaktifkan oleh pengguna — biasanya antara saat mouse ditekan (mousedown) dan saat dilepaskan (mouseup). :active bersifat sementara dan hanya berlangsung selama interaksi berlangsung. Pseudo-class ini paling sering digunakan pada tautan dan tombol untuk memberikan umpan balik instan. Pada tautan, :active biasanya terjadi setelah :hover dan sebelum pelepasan klik. Urutan yang tepat untuk styling tautan adalah :link — :visited — :hover — :active (dikenal dengan LVHA order). Selain pada elemen interaktif, :active juga dapat diterapkan pada elemen lain yang memiliki event klik.

## Contoh Kode Implementasi

```css
/* Tautan */
a {
  color: #3182ce;
}

a:link {
  color: #3182ce;
}

a:visited {
  color: #805ad5;
}

a:hover {
  color: #2c5282;
}

a:active {
  color: #c53030;
}

/* Tombol */
.btn {
  padding: 0.75rem 1.5rem;
  background: #4299e1;
  color: white;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  transition: transform 0.1s ease;
}

.btn:active {
  transform: scale(0.97);
  background: #3182ce;
}

/* Efek pressed pada kartu */
.card:active {
  transform: scale(0.98);
  opacity: 0.9;
}

/* LVHA order penting */
/* :link — :visited — :hover — :active */
.link-example:link {
  color: blue;
}
.link-example:visited {
  color: purple;
}
.link-example:hover {
  color: red;
}
.link-example:active {
  color: orange;
}
```

## Poin Penting
- :active aktif selama elemen sedang ditekan (mousedown hingga mouseup)
- Bersifat sementara dan sangat singkat durasinya
- Ikuti urutan LVHA (:link, :visited, :hover, :active) untuk tautan
- Cocok untuk efek tekan seperti scale(0.97) pada tombol
