# Pseudo-Class Nth-Child

## Analogi: Perpustakaan Digital

Di perpustakaan digital, dalam daftar buku yang panjang, Anda mungkin ingin memberi warna latar yang berselang-seling pada baris tabel agar lebih mudah dibaca. Atau Anda mungkin ingin menandai setiap buku ke-3 yang muncul. Dalam CSS, pseudo-class :nth-child memberikan kemampuan untuk memilih elemen berdasarkan pola matematika, seperti setiap elemen genap, ganjil, atau setiap elemen ke-n.

## Penjelasan Detail

Pseudo-class :nth-child menggunakan pola an+b untuk memilih elemen berdasarkan posisinya di antara saudara-saudaranya. Parameter 'a' adalah faktor pengali, 'n' adalah counter yang dimulai dari 0, dan 'b' adalah offset. Misalnya, :nth-child(2n) memilih elemen genap (2, 4, 6, ...), :nth-child(2n+1) memilih elemen ganjil (1, 3, 5, ...). Anda juga bisa menggunakan kata kunci even (sama dengan 2n) dan odd (sama dengan 2n+1). Pola seperti :nth-child(3n+1) akan memilih elemen ke-1, 4, 7, 10, ... Pola :nth-child(n+5) memilih semua elemen mulai dari ke-5, dan :nth-child(-n+3) memilih 3 elemen pertama. Ini memberikan fleksibilitas luar biasa dalam menata elemen berdasarkan pola tertentu.

## Contoh Kode Implementasi

```css
/* Baris genap dan ganjil */
tr:nth-child(even) {
  background-color: #f7fafc;
}

tr:nth-child(odd) {
  background-color: white;
}

/* Setiap elemen ke-3 */
li:nth-child(3n) {
  color: #e53e3e;
}

/* 3 elemen pertama */
li:nth-child(-n+3) {
  font-weight: bold;
}

/* Mulai dari elemen ke-5 */
li:nth-child(n+5) {
  opacity: 0.7;
}

/* Pola 2n+1 (sama dengan odd) */
.item:nth-child(2n+1) {
  background: #ebf8ff;
}

/* Setiap elemen ke-4 mulai dari ke-2 */
.item:nth-child(4n+2) {
  border-left: 3px solid #4299e1;
}

/* Grid: 3 kolom, setiap kolom ke-3 */
.grid-item:nth-child(3n) {
  margin-right: 0;
}

/* Tabel: highlight kolom tertentu */
td:nth-child(2) {
  font-weight: 600;
}
```

## Poin Penting
- :nth-child(an+b) memilih elemen berdasarkan pola matematika
- Gunakan even dan odd untuk baris genap/ganjil dalam tabel
- Pola an+b memberikan fleksibilitas untuk seleksi yang kompleks
- Ingat bahwa n dimulai dari 0, sehingga 2n menghasilkan 0, 2, 4, 6...
