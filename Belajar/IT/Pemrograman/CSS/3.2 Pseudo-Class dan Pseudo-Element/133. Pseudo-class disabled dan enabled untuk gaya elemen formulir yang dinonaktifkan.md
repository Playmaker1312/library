# Pseudo-Class Disabled dan Enabled

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika stok buku habis, tombol "Pinjam" menjadi abu-abu dan tidak bisa diklik. Ini memberi tahu pengguna bahwa aksi tersebut tidak tersedia saat ini tanpa harus mengklik dan mendapatkan pesan error. Dalam CSS, pseudo-class :disabled dan :enabled memungkinkan Anda menata elemen formulir berdasarkan status aktif atau non-aktifnya.

## Penjelasan Detail

Pseudo-class :disabled diterapkan pada elemen formulir yang memiliki atribut disabled, yang membuat elemen tersebut tidak dapat diinteraksi oleh pengguna. Elemen disabled biasanya tidak dapat menerima fokus, tidak dapat diklik, dan nilainya tidak dikirimkan saat form disubmit. Sebaliknya, :enabled diterapkan pada elemen yang dapat diinteraksi (default state). Hampir semua elemen formulir seperti input, select, button, dan textarea mendukung kedua pseudo-class ini. Dengan memberikan gaya yang jelas pada elemen disabled (seperti opacity lebih rendah, warna pudar, atau cursor not-allowed), Anda meningkatkan usability dengan mengkomunikasikan status elemen secara visual.

## Contoh Kode Implementasi

```css
/* Input yang dinonaktifkan */
input:disabled {
  background-color: #f7fafc;
  color: #a0aec0;
  border-color: #e2e8f0;
  cursor: not-allowed;
  opacity: 0.7;
}

/* Input yang aktif */
input:enabled {
  background-color: white;
  color: #2d3748;
  border-color: #cbd5e0;
}

/* Tombol disabled */
button:disabled {
  background-color: #cbd5e0;
  color: #a0aec0;
  cursor: not-allowed;
  transform: none;
  box-shadow: none;
}

button:enabled {
  background-color: #4299e1;
  color: white;
  cursor: pointer;
}

button:enabled:hover {
  background-color: #3182ce;
}

/* Select disabled */
select:disabled {
  background-color: #f7fafc;
  color: #a0aec0;
}

/* Textarea disabled */
textarea:disabled {
  resize: none;
  background-color: #f7fafc;
}

/* Fieldset disabled */
fieldset:disabled {
  opacity: 0.6;
}
```

## Poin Penting
- :disabled untuk elemen dengan atribut disabled, :enabled untuk elemen aktif (default)
- Elemen disabled tidak bisa difokus, diklik, atau dikirim nilainya
- Gunakan cursor: not-allowed untuk indikasi visual yang jelas
- Turunkan opacity dan kontras untuk elemen disabled agar terlihat tidak aktif
