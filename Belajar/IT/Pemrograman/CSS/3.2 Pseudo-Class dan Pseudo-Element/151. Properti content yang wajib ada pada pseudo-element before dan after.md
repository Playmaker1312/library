# Properti Content

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada slot kosong di samping setiap judul buku yang bisa diisi dengan berbagai jenis informasi: ikon, teks, atau gambar. Namun, slot ini hanya akan muncul jika Anda mengisinya dengan sesuatu. Jika slot dibiarkan kosong, slot itu sendiri tidak akan terlihat. Dalam CSS, properti content adalah "isi" slot tersebut pada pseudo-element ::before dan ::after — tanpanya, pseudo-element tidak akan muncul.

## Penjelasan Detail

Properti content digunakan pada pseudo-element ::before dan ::after untuk menentukan konten apa yang akan ditampilkan. Tanpa properti content, pseudo-element tidak akan dirender sama sekali, meskipun properti lain seperti width, height, atau background telah ditentukan. Properti content dapat menerima berbagai nilai: string teks (content: "teks"), atribut HTML (content: attr(data-tooltip)), counter CSS (content: counter(section)), gambar (content: url("icon.svg")), atau kombinasi nilai (content: "(" attr(href) ")"). content juga bisa berupa string kosong (content: "") yang berguna saat pseudo-element digunakan murni untuk dekorasi visual seperti ikon latar atau elemen shape.

## Contoh Kode Implementasi

```css
/* String */
.note::before {
  content: "Catatan: ";
  font-weight: bold;
  color: #4299e1;
}

/* Atribut HTML */
a::after {
  content: " (" attr(href) ")";
  font-size: 0.8em;
  color: #a0aec0;
}

/* Empty string untuk dekorasi */
.icon-star::before {
  content: "";
  display: inline-block;
  width: 16px;
  height: 16px;
  background: url('star.svg') no-repeat center;
  margin-right: 0.25rem;
}

/* Counter */
body {
  counter-reset: chapter;
}

h2::before {
  counter-increment: chapter;
  content: "Bab " counter(chapter) ": ";
}

/* Quote marks */
blockquote::before {
  content: open-quote;
}

blockquote::after {
  content: close-quote;
}

/* Gambar */
.external::after {
  content: url('external-link-icon.svg');
  margin-left: 0.25rem;
}

/* Kombinasi */
.tooltip::after {
  content: "ℹ️ " attr(data-info);
  font-size: 0.8rem;
}
```

## Poin Penting
- content WAJIB ada pada ::before dan ::after, tanpa itu pseudo-element tidak tampil
- content bisa berupa string, attr(), url(), counter(), open-quote/close-quote
- content: "" berguna untuk dekorasi visual murni (shape, ikon background)
- Konten dari properti content tidak dapat dipilih atau diakses screen reader
