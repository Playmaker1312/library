# Pseudo-Class First-Child

## Analogi: Perpustakaan Digital

Di perpustakaan digital, dalam daftar buku hasil pencarian, buku pertama selalu ditampilkan dengan gaya yang sedikit berbeda — mungkin dengan ikon khusus atau latar belakang yang disorot. Ini membantu pengguna mengenali item pertama dalam urutan. Dalam CSS, pseudo-class :first-child memungkinkan Anda menargetkan elemen pertama di antara saudara-saudaranya dalam induk yang sama.

## Penjelasan Detail

Pseudo-class :first-child menargetkan elemen yang merupakan anak pertama dari induknya. Seleksi ini berdasarkan posisi dalam struktur DOM, bukan jenis elemennya. Jika elemen yang ditargetkan bukan anak pertama (misalnya ada elemen lain sebelumnya), pseudo-class ini tidak akan cocok. :first-child sangat berguna untuk memberikan gaya khusus pada item pertama dalam daftar, seperti menghilangkan border-top atau menambahkan margin-top. Pseudo-class ini dapat dikombinasikan dengan selector lain, misalnya p:first-child untuk menargetkan paragraf yang merupakan anak pertama. Jika Anda ingin menargetkan elemen pertama dari jenis tertentu (bukan pertama secara umum), gunakan :first-of-type.

## Contoh Kode Implementasi

```css
/* Item pertama dalam daftar */
li:first-child {
  font-weight: bold;
  color: #2b6cb0;
}

/* Paragraf pertama dalam artikel */
article p:first-child {
  font-size: 1.125rem;
  font-weight: 500;
  color: #2d3748;
}

/* Anak pertama dari setiap daftar */
ul :first-child {
  border-top: none;
  padding-top: 0;
}

/* Card pertama dalam grid */
.card:first-child {
  margin-left: 0;
}

/* Item pertama tanpa border-top */
.menu-item:first-child {
  border-top: none;
}

/* Hanya jika <p> adalah anak pertama */
.container > p:first-child {
  margin-top: 0;
}

/* Efek drop cap pada paragraf pertama */
.post > p:first-child::first-letter {
  font-size: 3em;
  float: left;
  margin-right: 0.5rem;
  color: #4299e1;
}
```

## Poin Penting
- :first-child menargetkan elemen yang merupakan anak pertama dari induknya
- Berdasarkan posisi absolut dalam DOM, bukan jenis elemen
- Berbeda dengan :first-of-type yang melihat jenis elemen
- Berguna untuk menyesuaikan gaya tepi seperti margin, padding, dan border
