# Pseudo-Class Valid dan Invalid

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna memasukkan nomor anggota yang tidak valid, kolom input langsung berubah menjadi merah dan muncul pesan "Nomor anggota tidak ditemukan". Sebaliknya, ketika nomor valid dimasukkan, kolom berubah menjadi hijau. Umpan balik instan ini membantu pengguna memperbaiki kesalahan dengan cepat. Dalam CSS, pseudo-class :valid dan :invalid menyediakan kemampuan ini berdasarkan validasi HTML5.

## Penjelasan Detail

Pseudo-class :valid dan :invalid menargetkan elemen formulir berdasarkan validitas nilainya menurut constraint validation API HTML5. Elemen dianggap valid jika nilainya memenuhi semua batasan yang ditetapkan oleh atribut seperti type, pattern, min, max, minlength, maxlength, dan required. Sebagai contoh, input[type="email"] akan :invalid jika teks yang dimasukkan tidak mengandung @, dan input[type="number"] dengan min="18" akan :invalid jika nilainya kurang dari 18. Pseudo-class ini sangat berguna untuk menciptakan umpan balik visual real-time tanpa JavaScript. Namun, perlu diingat bahwa :invalid juga akan aktif pada elemen required yang kosong sebelum pengguna berinteraksi dengannya.

## Contoh Kode Implementasi

```css
/* Input valid */
input:valid {
  border-color: #38a169;
  background-color: #f0fff4;
}

/* Input invalid */
input:invalid {
  border-color: #e53e3e;
  background-color: #fff5f5;
}

/* Dengan pesan error */
input:invalid ~ .error-message {
  display: block;
  color: #e53e3e;
  font-size: 0.8rem;
}

input:valid ~ .error-message {
  display: none;
}

/* Input email spesifik */
input[type="email"]:valid {
  border-color: #38a169;
}

input[type="email"]:invalid {
  border-color: #e53e3e;
}

/* Number dengan range */
input[type="number"]:in-range {
  border-color: #38a169;
}

input[type="number"]:out-of-range {
  border-color: #e53e3e;
}

/* Pattern validation */
input[pattern="[0-9]{10}"]:valid {
  border-color: #38a169;
}

input[pattern="[0-9]{10}"]:invalid {
  border-color: #e53e3e;
}

/* Kombinasi required */
input:required:invalid {
  border-color: #e53e3e;
  box-shadow: 0 0 0 3px rgba(229, 62, 62, 0.1);
}
```

## Poin Penting
- :valid dan :invalid berdasarkan constraint validation API HTML5
- Bekerja dengan atribut type, pattern, required, min, max, dll
- Berikan umpan balik visual real-time tanpa JavaScript
- Hati-hati dengan :invalid pada form kosong, gunakan :not(:focus):invalid atau JavaScript untuk perilaku yang lebih baik
