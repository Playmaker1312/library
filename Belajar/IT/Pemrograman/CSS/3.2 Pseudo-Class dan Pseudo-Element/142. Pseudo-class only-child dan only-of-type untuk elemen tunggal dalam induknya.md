# Pseudo-Class Only-Child dan Only-of-Type

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada kalanya sebuah kategori hanya memiliki satu buku. Buku tunggal ini mungkin perlu ditampilkan secara istimewa, misalnya dengan ukuran lebih besar atau latar khusus. Dalam CSS, pseudo-class :only-child dan :only-of-type memungkinkan Anda menargetkan elemen yang merupakan satu-satunya anak dalam induknya, atau satu-satunya dari jenisnya.

## Penjelasan Detail

:only-child menargetkan elemen yang merupakan satu-satunya anak dari elemen induknya. Induk hanya memiliki tepat satu elemen anak, tidak ada saudara lain. :only-of-type menargetkan elemen yang merupakan satu-satunya dari jenisnya dalam induk, meskipun mungkin ada elemen jenis lain sebagai saudara. Misalnya, jika sebuah div berisi satu <p> dan beberapa <span>, maka <p> adalah :only-of-type (karena hanya satu <p>) tetapi bukan :only-child (karena ada <span> lain). Pseudo-class ini berguna untuk memberikan gaya khusus pada elemen yang sendirian, seperti teks yang terisolasi dalam kontainer, ikon tunggal, atau elemen yang mungkin menjadi satu-satunya dalam tata letak responsif.

## Contoh Kode Implementasi

```css
/* Satu-satunya anak dalam induk */
p:only-child {
  font-size: 1.25rem;
  color: #2b6cb0;
  text-align: center;
  padding: 2rem;
}

/* Satu-satunya gambar dalam kontainer */
img:only-of-type {
  width: 100%;
  height: auto;
  border-radius: 8px;
}

/* Satu-satunya list item */
li:only-child {
  list-style: none;
  font-weight: bold;
}

/* Satu-satunya heading */
h2:only-of-type {
  text-align: center;
  font-size: 2rem;
  border-bottom: 2px solid #4299e1;
  padding-bottom: 0.5rem;
}

/* Card dengan satu tombol */
.card button:only-child {
  width: 100%;
  padding: 1rem;
}

/* Navigasi dengan satu link */
nav a:only-child {
  display: block;
  text-align: center;
}

/* Form dengan satu input */
.form-group input:only-of-type {
  width: 100%;
}
```

## Poin Penting
- :only-child untuk elemen yang merupakan satu-satunya anak dalam induk
- :only-of-type untuk elemen yang satu-satunya dari jenisnya dalam induk
- :only-of-type memungkinkan adanya elemen jenis lain sebagai saudara
- Berguna untuk penanganan kasus tepi (edge case) dalam tata letak
