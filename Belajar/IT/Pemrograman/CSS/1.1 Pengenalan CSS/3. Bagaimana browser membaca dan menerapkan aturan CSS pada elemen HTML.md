# Bagaimana browser membaca dan menerapkan aturan CSS pada elemen HTML

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna mencari buku, sistem membaca aturan katalog (CSS) untuk menampilkan hasil dengan format yang sesuai. Browser bertindak seperti sistem perpustakaan yang memproses setiap permintaan — ia membaca aturan CSS, mencocokkan dengan elemen HTML (seperti buku di rak), lalu menerapkan gaya yang sesuai sebelum menampilkannya ke layar.

## Penjelasan Detail

Browser memproses CSS melalui beberapa tahap: parsing HTML menjadi DOM (Document Object Model), parsing CSS menjadi CSSOM (CSS Object Model), lalu menggabungkan keduanya menjadi render tree. Browser kemudian melakukan layout (menghitung posisi dan ukuran) dan painting (menggambar piksel ke layar). Aturan CSS dibaca dari kanan ke kiri oleh engine browser untuk efisiensi pencocokan selector. Ketika ada konflik, browser menggunakan kaskade dan spesifisitas untuk menentukan aturan mana yang menang.

## Contoh Kode Implementasi

```css
/* Browser akan mencocokkan selector ini dengan elemen HTML */
article p.intro {
  font-size: 1.1em;
  color: #444;
  line-height: 1.8;
}

/* Browser membaca: cari elemen p dengan class "intro" yang ada di dalam article */
/* Lalu terapkan deklarasi di atas */
```

## Poin Penting
- Browser membangun DOM tree dari HTML dan CSSOM tree dari CSS
- Render tree menggabungkan DOM dan CSSOM untuk elemen yang terlihat
- Pencocokan selector dilakukan dari kanan ke kiri untuk efisiensi
