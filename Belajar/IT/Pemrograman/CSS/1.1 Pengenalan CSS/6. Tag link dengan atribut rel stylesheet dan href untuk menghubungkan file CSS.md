# Tag link dengan atribut rel stylesheet dan href untuk menghubungkan file CSS

## Analogi: Perpustakaan Digital

Tag `<link>` seperti papan petunjuk di pintu masuk perpustakaan digital yang mengarahkan pengunjung ke buku panduan desain. Atribut `rel="stylesheet"` memberi tahu bahwa petunjuk ini mengarah ke buku panduan gaya, sementara `href` adalah alamat rak tempat buku panduan itu disimpan.

## Penjelasan Detail

Tag `<link>` adalah elemen HTML yang digunakan untuk menghubungkan dokumen HTML dengan sumber daya eksternal. Untuk CSS, atribut `rel` diisi dengan nilai `"stylesheet"` yang mendefinisikan hubungan antara HTML dan file yang ditautkan sebagai lembar gaya. Atribut `href` berisi path atau URL menuju file CSS. Tag `<link>` juga dapat menyertakan atribut `type="text/css"` (opsional di HTML5) dan `media` untuk stylesheet spesifik perangkat. Penggunaan tag `<link>` lebih disukai dibandingkan `@import` karena memungkinkan rendering paralel oleh browser.

## Contoh Kode Implementasi

```css
/* File: css/theme.css */
:root {
  --primary: #3498db;
  --secondary: #2ecc71;
  --dark: #2c3e50;
}

.btn {
  display: inline-block;
  padding: 10px 20px;
  background-color: var(--primary);
  color: white;
  text-decoration: none;
  border-radius: 4px;
}
```

```html
<!-- Menghubungkan multiple stylesheets -->
<head>
  <link rel="stylesheet" href="css/reset.css">
  <link rel="stylesheet" href="css/theme.css">
  <link rel="stylesheet" href="css/print.css" media="print">
</head>
```

## Poin Penting
- `rel="stylesheet"` memberi tahu browser bahwa file yang ditautkan adalah CSS
- `href` berisi path atau URL menuju file CSS
- Tag `<link>` memungkinkan multiple stylesheets dan media-specific CSS
