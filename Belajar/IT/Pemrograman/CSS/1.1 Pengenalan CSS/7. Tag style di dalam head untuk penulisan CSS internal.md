# Tag style di dalam head untuk penulisan CSS internal

## Analogi: Perpustakaan Digital

Menulis CSS internal menggunakan tag `<style>` seperti membuat catatan desain yang ditempel di dinding ruangan perpustakaan. Catatan ini hanya berlaku untuk ruangan tersebut, tidak untuk ruangan lain. Ini berguna ketika Anda ingin memberikan gaya khusus pada satu ruangan tanpa mempengaruhi seluruh perpustakaan.

## Penjelasan Detail

Tag `<style>` ditempatkan di dalam elemen `<head>` pada dokumen HTML. Di dalam tag ini, Anda menulis aturan CSS langsung tanpa perlu file terpisah. CSS internal berguna untuk halaman tunggal yang membutuhkan gaya unik, prototipe cepat, atau ketika Anda ingin menghindari permintaan HTTP tambahan. Meskipun demikian, CSS internal tidak dapat di-cache oleh browser dan tidak bisa digunakan bersama antar halaman, sehingga kurang efisien untuk situs multi-halaman.

## Contoh Kode Implementasi

```css
/* CSS internal ditulis dalam tag <style> di head HTML */
/* <head>
  <style>
    body {
      font-family: Georgia, serif;
      background-color: #f9f9f9;
      color: #222;
      line-height: 1.7;
    }

    .article-title {
      font-size: 2em;
      color: #8b4513;
      border-bottom: 2px solid #8b4513;
      padding-bottom: 10px;
    }

    .article-meta {
      color: #666;
      font-style: italic;
      font-size: 0.9em;
    }
  </style>
</head> */
```

## Poin Penting
- Tag `<style>` ditempatkan di dalam `<head>` dokumen HTML
- CSS internal hanya berlaku untuk satu halaman HTML
- Cocok untuk halaman tunggal tetapi tidak bisa di-cache oleh browser
