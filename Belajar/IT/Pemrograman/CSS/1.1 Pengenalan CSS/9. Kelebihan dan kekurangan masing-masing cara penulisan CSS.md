# Kelebihan dan kekurangan masing-masing cara penulisan CSS

## Analogi: Perpustakaan Digital

Seperti memilih metode pengelolaan perpustakaan digital, setiap cara penulisan CSS memiliki trade-off. Catatan tempel (inline) cepat tetapi berantakan. Panduan per ruangan (internal) rapi tetapi terbatas. Buku panduan pusat (external) profesional tetapi butuh persiapan awal. Pilihan terbaik tergantung skala perpustakaan Anda.

## Penjelasan Detail

External stylesheet unggul dalam pemisahan konten dan presentasi, reusabilitas, caching browser, dan kemudahan pemeliharaan — ideal untuk situs multi-halaman. Internal style cocok untuk halaman tunggal atau prototipe, tetapi tidak bisa digunakan kembali dan menambah ukuran HTML. Inline style berguna untuk override cepat atau konten dinamis, namun mencampur struktur dan gaya, sulit di-debug, dan tidak efisien. Dari segi performa, external stylesheet memungkinkan caching, internal mempercepat load awal untuk satu halaman, sementara inline menunda rendering karena browser harus memproses atribut satu per satu.

## Contoh Kode Implementasi

```css
/* External stylesheet — terpusat, bisa di-cache, reusable */
/* style.css */
.btn-primary {
  background-color: #3498db;
  color: white;
  padding: 12px 24px;
  border: none;
  border-radius: 4px;
}

/* Internal style — dalam halaman, tidak reusable */
/* <style>
  .page-specific { border-left: 3px solid #e67e22; }
</style> */

/* Inline style — spesifik untuk satu elemen, prioritas tinggi */
/* <button style="background-color: #e74c3c;">Hapus</button> */
```

## Poin Penting
- External stylesheet: kelebihan reusabilitas dan caching, kekurangan HTTP request tambahan
- Internal style: kelebihan tanpa request tambahan, kekurangan tidak bisa di-cache
- Inline style: kelebihan prioritas tinggi, kekurangan sulit dipelihara dan tidak reusable
