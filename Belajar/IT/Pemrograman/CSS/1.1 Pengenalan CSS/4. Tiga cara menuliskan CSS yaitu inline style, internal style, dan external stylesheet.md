# Tiga cara menuliskan CSS yaitu inline style, internal style, dan external stylesheet

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda bisa menata buku dengan tiga cara: menempel catatan langsung di buku (inline), membuat panduan rak di setiap ruangan (internal), atau memiliki buku panduan pusat yang mengatur seluruh perpustakaan (external). Masing-masing memiliki kegunaan tergantung skala dan kebutuhan perpustakaan Anda.

## Penjelasan Detail

Tiga metode penulisan CSS memberikan fleksibilitas dalam mengelola gaya halaman web. Inline style ditulis langsung dalam atribut `style` elemen HTML, berguna untuk override cepat tapi sulit dipelihara. Internal style ditulis dalam tag `<style>` di bagian `<head>`, cocok untuk halaman tunggal. External stylesheet menyimpan CSS di file terpisah dengan ekstensi `.css` dan dihubungkan via tag `<link>`, merupakan praktik terbaik karena memisahkan konten dan presentasi serta memungkinkan caching browser.

## Contoh Kode Implementasi

```css
/* --- External stylesheet (style.css) --- */
body { font-family: 'Segoe UI', Tahoma, sans-serif; }
.container { max-width: 1200px; margin: 0 auto; }

/* --- Internal style (di HTML dalam tag <style>) --- */
/* <style>
  .highlight { background-color: yellow; }
</style> */

/* --- Inline style (langsung di elemen HTML) --- */
/* <p style="color: red; font-weight: bold;">Teks merah tebal</p> */
```

## Poin Penting
- External stylesheet adalah metode terbaik untuk proyek multi-halaman
- Internal style cocok untuk halaman tunggal atau prototipe cepat
- Inline style memiliki prioritas tertinggi namun sulit dipelihara
