# Apa itu CSS dan peran pentingnya dalam mendesain tampilan halaman web

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan digital yang menyimpan ribuan buku. HTML adalah kerangka rak buku, lantai, dan dindingnya. CSS adalah cat dinding, desain rak, pencahayaan, dan papan petunjuk yang membuat perpustakaan nyaman dipandang dan mudah dinavigasi. Tanpa CSS, perpustakaan digital hanya berupa tumpukan buku tanpa estetika.

## Penjelasan Detail

CSS (Cascading Style Sheets) adalah bahasa stylesheet yang digunakan untuk mengontrol tampilan dan layout elemen HTML di halaman web. CSS memisahkan konten (HTML) dari presentasi (tampilan), sehingga pengembang dapat mengubah desain secara terpusat tanpa mengubah struktur halaman. Dengan CSS, Anda dapat mengatur warna, font, jarak, ukuran, posisi, animasi, dan responsivitas halaman. Peran CSS sangat penting dalam menciptakan pengalaman pengguna yang konsisten dan menarik, serta memungkinkan desain yang adaptif di berbagai perangkat.

## Contoh Kode Implementasi

```css
body {
  background-color: #f4f4f4;
  font-family: Arial, sans-serif;
  margin: 0;
  padding: 20px;
}

h1 {
  color: #2c3e50;
  text-align: center;
}

p {
  color: #333;
  line-height: 1.6;
}
```

## Poin Penting
- CSS memisahkan konten dari presentasi sehingga desain lebih mudah dikelola
- CSS memungkinkan desain yang konsisten di seluruh halaman web
- CSS mendukung desain responsif untuk berbagai ukuran layar
