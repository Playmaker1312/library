# Cara membuat file CSS eksternal dengan ekstensi .css dan menghubungkannya ke HTML

## Analogi: Perpustakaan Digital

Membuat file CSS eksternal seperti menulis buku panduan desain terpisah untuk perpustakaan digital. Buku panduan ini bisa digunakan oleh semua ruangan di perpustakaan. Cukup dengan merujuk buku panduan yang sama, setiap ruangan akan memiliki tampilan yang seragam tanpa harus menulis ulang aturan desain.

## Penjelasan Detail

File CSS eksternal adalah file teks biasa dengan ekstensi `.css` yang berisi aturan-aturan gaya. Untuk menghubungkannya ke halaman HTML, gunakan tag `<link>` di dalam elemen `<head>`. Tag `<link>` membutuhkan atribut `rel="stylesheet"` untuk memberi tahu browser bahwa file tersebut adalah stylesheet, dan atribut `href` untuk menentukan lokasi file CSS. File CSS dapat ditempatkan di folder yang sama atau subfolder terpisah. Keuntungan utama metode ini adalah pemisahan konten dan gaya, caching oleh browser, dan kemudahan pemeliharaan.

## Contoh Kode Implementasi

```css
/* File: styles/main.css */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  background-color: #fafafa;
  color: #333;
  font-family: 'Helvetica Neue', Arial, sans-serif;
}

header {
  background-color: #2c3e50;
  color: white;
  padding: 1rem 2rem;
}
```

```html
<!-- Di file HTML, hubungkan file CSS -->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Contoh</title>
  <link rel="stylesheet" href="styles/main.css">
</head>
<body>
  <header>
    <h1>Selamat Datang</h1>
  </header>
</body>
</html>
```

## Poin Penting
- File CSS eksternal menggunakan ekstensi `.css` dan berisi aturan gaya murni
- Tag `<link>` dengan `rel="stylesheet"` dan `href` menghubungkan CSS ke HTML
- Metode eksternal memungkinkan caching browser dan pemeliharaan terpusat
