# Sejarah perkembangan CSS dari CSS1 hingga CSS3 dan fitur-fitur yang ditambahkan

## Analogi: Perpustakaan Digital

Seperti halnya perpustakaan digital yang terus diperbarui dengan sistem katalog baru dan fitur pencarian yang lebih canggih, CSS pun berkembang dari versi ke versi. CSS1 adalah katalog kartu sederhana, CSS2 menambahkan navigasi bertingkat, dan CSS3 menghadirkan pencarian suara serta rekomendasi cerdas. Setiap versi membawa kemampuan baru yang memperkaya pengalaman pengguna.

## Penjelasan Detail

CSS pertama kali diusulkan oleh Håkon Wium Lie pada tahun 1994 dan resmi menjadi rekomendasi W3C sebagai CSS1 pada tahun 1996. CSS1 memperkenalkan dasar-dasar seperti properti font, warna, teks, margin, dan padding. CSS2 dirilis pada tahun 1998 dengan tambahan fitur positioning, z-index, media types, dan tabel. CSS3 hadir dalam bentuk modul-modul terpisah sejak 1999, memungkinkan adopsi bertahap. Fitur utama CSS3 meliputi border-radius, box-shadow, gradient, transformasi, animasi, transisi, flexbox, grid, dan media queries.

## Contoh Kode Implementasi

```css
/* CSS1 - basic styling */
h1 { color: navy; font-size: 24px; }

/* CSS2 - positioning */
#sidebar { position: absolute; left: 0; top: 0; width: 250px; }

/* CSS3 - modern features */
.card {
  border-radius: 8px;
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);
  transition: transform 0.3s ease;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}
.card:hover { transform: translateY(-5px); }
```

## Poin Penting
- CSS1 memperkenalkan fondasi dasar styling teks dan elemen
- CSS2 menambahkan positioning dan layout yang lebih kompleks
- CSS3 hadir secara modular dengan fitur visual modern dan responsif
