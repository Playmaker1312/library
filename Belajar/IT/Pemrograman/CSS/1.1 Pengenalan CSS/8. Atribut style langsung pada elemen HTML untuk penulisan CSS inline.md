# Atribut style langsung pada elemen HTML untuk penulisan CSS inline

## Analogi: Perpustakaan Digital

Inline style seperti menempelkan stiker keterangan langsung pada buku di perpustakaan digital. Stiker ini hanya mempengaruhi buku tersebut, bukan buku lain. Ini berguna untuk koreksi cepat, tetapi jika Anda ingin mengubah gaya semua buku, Anda harus mengganti stiker satu per satu.

## Penjelasan Detail

CSS inline ditulis langsung dalam atribut `style` pada elemen HTML. Nilai atribut `style` berisi deklarasi CSS yang dipisahkan oleh titik koma, tanpa selector karena sudah terikat pada elemen itu sendiri. Inline style memiliki spesifisitas tertinggi dibanding metode lain, sehingga dapat menimpa aturan dari external atau internal stylesheet. Namun, metode ini mencampur konten dengan presentasi, sulit dipelihara, tidak bisa digunakan kembali, dan tidak dapat menerapkan pseudo-class atau media queries.

## Contoh Kode Implementasi

```css
/* CSS inline ditulis langsung di atribut style HTML */
/* <div style="background-color: #e74c3c; 
              color: white; 
              padding: 20px; 
              border-radius: 8px; 
              font-size: 18px;">
  <p style="margin: 0; font-weight: bold;">Peringatan Penting!</p>
  <p style="margin: 5px 0 0 0; opacity: 0.9;">Silakan periksa kembali data Anda.</p>
</div> */
```

## Poin Penting
- Inline style ditulis dalam atribut `style` langsung di elemen HTML
- Memiliki spesifisitas tertinggi dibanding internal dan external CSS
- Tidak mendukung pseudo-class, media queries, atau reusabilitas
