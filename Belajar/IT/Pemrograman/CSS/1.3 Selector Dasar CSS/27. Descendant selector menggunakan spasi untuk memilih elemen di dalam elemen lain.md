# Descendant selector menggunakan spasi untuk memilih elemen di dalam elemen lain

## Analogi: Perpustakaan Digital

Descendant selector seperti perintah "cari semua buku di ruang baca utama, baik di rak atas, rak bawah, maupun di meja." Spasi dalam CSS berarti "yang berada di dalam" — menargetkan elemen di level hierarki manapun di dalam elemen yang ditentukan, tidak harus anak langsung.

## Penjelasan Detail

Descendant selector menggunakan spasi antara dua selector (atau lebih). Selector pertama adalah induk/leluhur, selector kedua adalah keturunan yang ditargetkan. Berbeda dengan child selector (`>`), descendant selector menargetkan elemen pada level kedalaman berapapun — anak langsung, cucu, cicit, dan seterusnya. Ini berguna ketika Anda ingin menargetkan semua elemen tertentu di dalam sebuah kontainer, tanpa peduli seberapa dalam nesting-nya. Perhatikan bahwa spasi adalah descendant selector, jangan tertukar dengan selector lain.

## Contoh Kode Implementasi

```css
/* Descendant selector — spasi = "yang berada di dalam" */
article p {
  line-height: 1.8;
  color: #333;
  margin-bottom: 1em;
}

/* Semua link di dalam navbar */
.navbar a {
  color: white;
  text-decoration: none;
  padding: 10px 15px;
  display: inline-block;
}

/* Multi-level descendant */
.sidebar ul li a {
  font-size: 0.9rem;
  color: #555;
  border-left: 3px solid transparent;
  padding-left: 10px;
}

.sidebar ul li a:hover {
  border-left-color: #3498db;
  color: #3498db;
}
```

```html
<!-- Semua <a> di dalam .navbar akan kena style -->
<nav class="navbar">
  <a href="#">Home</a>
  <a href="#">About</a>
  <div>
    <a href="#">Submenu</a> <!-- Juga kena -->
  </div>
</nav>
```

## Poin Penting
- Spasi antar selector berarti "yang berada di dalam"
- Menargetkan semua level keturunan, bukan hanya anak langsung
- Berguna untuk styling elemen dalam kontainer tertentu
