# Class selector menggunakan tanda titik untuk memilih elemen berdasarkan kelas

## Analogi: Perpustakaan Digital

Class selector seperti label "Buku Best Seller" yang bisa ditempel pada berbagai buku di perpustakaan digital — baik novel, biografi, maupun buku sains. Semua buku yang memiliki label yang sama akan diperlakukan seragam, tanpa peduli jenis atau lokasi aslinya.

## Penjelasan Detail

Class selector menggunakan tanda titik (`.`) diikuti nama kelas yang diberikan pada atribut `class` elemen HTML. Satu elemen bisa memiliki banyak kelas (dipisah spasi) dan satu kelas bisa digunakan oleh banyak elemen. Class selector memiliki spesifisitas 0,1,0 — lebih tinggi dari type selector. Class adalah cara paling umum dan fleksibel untuk menargetkan elemen karena dapat digunakan berulang kali di seluruh halaman. Konvensi penamaan seperti BEM (Block Element Modifier) membantu menjaga konsistensi.

## Contoh Kode Implementasi

```css
/* Class selector dengan tanda titik */
.button {
  display: inline-block;
  padding: 12px 24px;
  border: none;
  border-radius: 4px;
  font-size: 1rem;
  cursor: pointer;
}

.button-primary {
  background-color: #3498db;
  color: white;
}

.button-danger {
  background-color: #e74c3c;
  color: white;
}

.card {
  background: white;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
  padding: 20px;
}
```

```html
<!-- Penggunaan class di HTML -->
<button class="button button-primary">Simpan</button>
<button class="button button-danger">Hapus</button>
<div class="card">
  <p>Ini adalah kartu dengan gaya CSS class selector.</p>
</div>
```

## Poin Penting
- Class selector menggunakan `.` diikuti nama kelas
- Satu kelas bisa digunakan oleh banyak elemen, satu elemen bisa punya banyak kelas
- Spesifisitas 0,1,0 — lebih tinggi dari type selector
