# General sibling selector menggunakan tanda tilde untuk memilih semua saudara setelahnya

## Analogi: Perpustakaan Digital

General sibling selector (`~`) seperti perintah "cari semua buku yang terletak di sebelah kanan buku 'Harry Potter' di rak yang sama, tidak harus tepat di sebelahnya." Tanda `~` berarti "semua saudara setelah" — menargetkan semua elemen yang menjadi saudara sejajar setelah elemen yang ditentukan.

## Penjelasan Detail

General sibling selector menggunakan tanda `~` (tilde) antara dua selector. Selector pertama adalah elemen acuan, selector kedua adalah semua elemen yang berada setelahnya dan memiliki induk yang sama. Berbeda dengan adjacent sibling selector (`+`) yang hanya menargetkan satu elemen tepat setelahnya, general sibling selector menargetkan semua elemen yang cocok setelah elemen acuan, tidak peduli apakah ada elemen lain di antaranya. Ini berguna untuk memberikan efek pada semua elemen setelah checkbox dicentang atau setelah suatu state berubah.

## Contoh Kode Implementasi

```css
/* General sibling selector — semua saudara setelah */
h2 ~ p {
  padding-left: 20px;
  border-left: 3px solid #3498db;
  margin-left: 10px;
}

/* Semua elemen setelah .active dalam .menu */
.menu .active ~ li {
  opacity: 0.5;
}

/* Semua field setelah checkbox dicentang */
.toggle:checked ~ .content {
  display: block;
}

/* Semua saudara setelah error message */
.error-message ~ .field {
  border-color: #e74c3c;
}
```

```html
<h2>Judul</h2>
<p>Paragraf 1 — kena style (setelah h2)</p>
<div>Div penyela — tidak kena (bukan p)</div>
<p>Paragraf 2 — kena style (setelah h2, meskipun ada div)</p>

<!-- General sibling vs Adjacent sibling -->
<!-- ~ : semua p setelah h2       -->
<!-- + : hanya p pertama setelah h2 -->
```

## Poin Penting
- Tanda `~` berarti "semua saudara sejajar setelahnya"
- Menargetkan semua elemen yang cocok, tidak harus langsung berurutan
- Berguna untuk efek berdasarkan state elemen sebelumnya
