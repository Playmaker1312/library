# Type selector atau element selector untuk memilih elemen berdasarkan nama tagnya

## Analogi: Perpustakaan Digital

Type selector seperti memilih semua buku berdasarkan kategori — misalnya, "semua novel" atau "semua buku referensi." Di CSS, Anda menulis `p` untuk memilih semua paragraf, atau `h1` untuk semua judul utama. Semua elemen dengan tag HTML yang sama akan menerapkan gaya yang sama.

## Penjelasan Detail

Type selector (juga disebut element selector) menargetkan elemen HTML berdasarkan nama tag-nya, seperti `div`, `p`, `h1`, `a`, `img`, `section`, `nav`, dan sebagainya. Selector ini adalah selector paling sederhana dan memiliki spesifisitas 0,0,1 (satu elemen). Type selector menerapkan gaya ke semua elemen dengan tag tersebut di halaman. Untuk membatasi cakupan, type selector sering dikombinasikan dengan class, ID, atau selector lainnya.

## Contoh Kode Implementasi

```css
/* Type selector berdasarkan nama tag */
h1 {
  font-size: 2.5rem;
  color: #2c3e50;
  text-align: center;
}

h2 {
  font-size: 1.8rem;
  color: #34495e;
  border-bottom: 2px solid #3498db;
}

p {
  font-size: 1rem;
  line-height: 1.7;
  color: #444;
  margin-bottom: 1rem;
}

a {
  color: #3498db;
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}

img {
  max-width: 100%;
  height: auto;
}
```

## Poin Penting
- Type selector menggunakan nama tag HTML tanpa tanda kurung sudut
- Memilih semua elemen dengan tag yang sama di halaman
- Spesifisitas: 0,0,1 (rendah)
