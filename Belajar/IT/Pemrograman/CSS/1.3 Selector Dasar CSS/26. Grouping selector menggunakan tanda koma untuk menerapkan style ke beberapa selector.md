# Grouping selector menggunakan tanda koma untuk menerapkan style ke beberapa selector

## Analogi: Perpustakaan Digital

Grouping selector seperti perintah "Semua buku fiksi, buku referensi, dan majalah harus memiliki label rak hijau." Alih-alih menulis aturan yang sama tiga kali, Anda cukup menulisnya sekali dengan memisahkan kategori menggunakan koma. Ini menghemat waktu dan membuat katalog lebih bersih.

## Penjelasan Detail

Grouping selector memungkinkan Anda menerapkan deklarasi yang sama ke beberapa selector sekaligus dengan memisahkannya menggunakan tanda koma (`,`). Tanpa grouping, Anda harus menulis ulang blok deklarasi yang sama untuk setiap selector — melanggar prinsip DRY (Don't Repeat Yourself). Grouping selector tidak mengubah spesifisitas; setiap selector dalam grup mempertahankan spesifisitasnya sendiri. Pastikan setiap selector dipisahkan koma dengan benar, dan perhatikan bahwa selector kompleks (seperti `div > p`) juga bisa di-group.

## Contoh Kode Implementasi

```css
/* Tanpa grouping — kode berulang */
h1 { color: #2c3e50; font-family: Arial, sans-serif; }
h2 { color: #2c3e50; font-family: Arial, sans-serif; }
h3 { color: #2c3e50; font-family: Arial, sans-serif; }

/* Dengan grouping selector — lebih ringkas */
h1, h2, h3 {
  color: #2c3e50;
  font-family: Arial, sans-serif;
  margin-top: 1.5em;
  margin-bottom: 0.5em;
}

/* Grouping dengan selector kompleks */
.nav-link, .footer-link, .sidebar a {
  text-decoration: none;
  color: #3498db;
  transition: color 0.3s ease;
}

.nav-link:hover, .footer-link:hover, .sidebar a:hover {
  color: #2980b9;
}
```

## Poin Penting
- Grouping selector menggunakan koma untuk memisahkan selector
- Menerapkan deklarasi yang sama ke beberapa elemen tanpa mengulang kode
- Menerapkan prinsip DRY dan membuat kode lebih bersih
