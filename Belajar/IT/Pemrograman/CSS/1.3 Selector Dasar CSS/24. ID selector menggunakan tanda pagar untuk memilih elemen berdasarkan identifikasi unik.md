# ID selector menggunakan tanda pagar untuk memilih elemen berdasarkan identifikasi unik

## Analogi: Perpustakaan Digital

ID selector seperti nomor ISBN unik yang diberikan pada setiap buku di perpustakaan digital. Tidak ada dua buku yang memiliki ISBN yang sama. ID bersifat eksklusif — hanya satu elemen di halaman yang boleh memiliki ID tertentu. Ini berguna untuk menargetkan elemen spesifik seperti header utama atau form login.

## Penjelasan Detail

ID selector menggunakan tanda pagar (`#`) diikuti nama ID yang diberikan pada atribut `id` elemen HTML. Berbeda dengan class, ID harus unik dalam satu halaman HTML — hanya satu elemen yang boleh memiliki ID tertentu. ID selector memiliki spesifisitas 1,0,0 — jauh lebih tinggi dari class (0,1,0) dan type selector (0,0,1). Karena tingginya spesifisitas, ID sulit ditimpa dan kurang fleksibel untuk digunakan kembali, sehingga banyak developer modern lebih memilih class selector untuk styling dan menggunakan ID untuk fragment identifier atau JavaScript hooks.

## Contoh Kode Implementasi

```css
/* ID selector dengan tanda pagar */
#header {
  background-color: #2c3e50;
  color: white;
  padding: 20px 0;
  position: fixed;
  top: 0;
  width: 100%;
  z-index: 1000;
}

#main-content {
  margin-top: 80px;
  padding: 20px;
  min-height: 60vh;
}

#footer {
  background-color: #34495e;
  color: #ccc;
  text-align: center;
  padding: 15px;
}
```

```html
<!-- Penggunaan ID di HTML (hanya satu per halaman) -->
<div id="header">
  <h1>Situs Saya</h1>
</div>
<main id="main-content">
  <p>Konten utama halaman.</p>
</main>
<div id="footer">
  <p>Hak Cipta 2024</p>
</div>
```

## Poin Penting
- ID selector menggunakan `#` diikuti nama ID yang unik
- Satu halaman HTML hanya boleh memiliki satu elemen dengan ID tertentu
- Spesifisitas 1,0,0 — sangat tinggi, sulit ditimpa
