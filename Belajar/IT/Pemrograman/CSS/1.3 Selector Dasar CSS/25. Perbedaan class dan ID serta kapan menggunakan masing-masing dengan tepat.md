# Perbedaan class dan ID serta kapan menggunakan masing-masing dengan tepat

## Analogi: Perpustakaan Digital

Di perpustakaan digital, class seperti label kategori yang bisa ditempel ke banyak buku ("Fiksi", "Non-Fiksi"). ID seperti nomor akses unik yang hanya dimiliki satu buku. Label kategori bisa dipakai di banyak tempat, nomor akses bersifat eksklusif. Masing-masing punya fungsi yang berbeda dan digunakan untuk tujuan yang berbeda.

## Penjelasan Detail

Perbedaan utama: class bisa digunakan berulang kali pada banyak elemen, ID harus unik per halaman. Spesifisitas ID (1,0,0) jauh lebih tinggi dari class (0,1,0). Gunakan class ketika Anda ingin menerapkan gaya yang sama ke beberapa elemen, untuk komponen yang reusable, dan untuk styling umum. Gunakan ID untuk anchor link, target form label, JavaScript hooks, atau elemen yang benar-benar unik seperti header/footer utama. Praktik terbaik modern cenderung menggunakan class untuk styling dan ID untuk fungsionalitas, karena class lebih fleksibel dan tidak menyebabkan masalah spesifisitas.

## Contoh Kode Implementasi

```css
/* Class — untuk styling reusable */
.btn {
  padding: 10px 20px;
  border-radius: 4px;
  font-size: 1rem;
}
.btn-primary { background-color: #3498db; color: white; }
.btn-danger { background-color: #e74c3c; color: white; }

/* ID — untuk elemen unik dan JavaScript */
#sidebar {
  width: 300px;
  background-color: #f8f9fa;
  position: sticky;
  top: 20px;
}

/* Kombinasi class dan ID */
#header .nav-link {
  color: white;
  padding: 10px 15px;
}
```

```html
<!-- Class digunakan berulang -->
<button class="btn btn-primary">Simpan</button>
<button class="btn btn-danger">Hapus</button>

<!-- ID hanya satu kali per halaman -->
<aside id="sidebar">...</aside>
```

## Poin Penting
- Class: reusable, bisa banyak elemen, spesifisitas 0,1,0 — untuk styling
- ID: unik, satu elemen per halaman, spesifisitas 1,0,0 — untuk fungsionalitas
- Prioritaskan class untuk styling, ID untuk JavaScript dan anchor
