# Child selector menggunakan tanda lebih besar untuk memilih elemen anak langsung

## Analogi: Perpustakaan Digital

Child selector (`>`) seperti perintah "hanya buku yang langsung diletakkan di rak utama, bukan yang ada di dalam kotak di dalam rak." Tanda `>` berarti "anak langsung dari" — hanya menargetkan elemen yang menjadi anak pertama (direct child) dari elemen tertentu, bukan cucu atau cicit.

## Penjelasan Detail

Child selector menggunakan tanda `>` antara dua selector. Selector pertama menunjuk elemen induk, selector kedua menunjuk elemen anak langsung. Berbeda dengan descendant selector (spasi) yang menargetkan semua level keturunan, child selector hanya menargetkan satu level ke bawah. Ini berguna ketika Anda ingin membedakan styling antara anak langsung dan elemen yang lebih dalam. Misalnya, Anda ingin list di level pertama berbeda dengan nested list.

## Contoh Kode Implementasi

```css
/* Child selector — hanya anak langsung */
.menu > li {
  display: inline-block;
  padding: 10px 20px;
  background-color: #2c3e50;
  color: white;
  position: relative;
}

/* Anak langsung dari article */
article > h2 {
  font-size: 1.5rem;
  color: #e74c3c;
  border-bottom: 2px solid #e74c3c;
  padding-bottom: 5px;
}

/* Hanya paragraf yang jadi anak langsung .content */
.content > p {
  margin-bottom: 1.2em;
  font-size: 1.1rem;
}
```

```html
<ul class="menu">
  <li>Home           <!-- Anak langsung — kena style -->
    <ul>
      <li>Submenu    <!-- Bukan anak langsung — tidak kena -->
    </ul>
  </li>
  <li>About          <!-- Anak langsung — kena style --></li>
</ul>

<article>
  <h2>Judul</h2>        <!-- Anak langsung — kena -->
  <div>
    <h2>Sub Judul</h2>  <!-- Bukan anak langsung — tidak kena -->
  </div>
</article>
```

## Poin Penting
- Child selector (`>`) menargetkan elemen anak langsung (satu level ke bawah)
- Berbeda dengan descendant selector yang menargetkan semua level keturunan
- Berguna untuk membedakan styling berdasarkan level hierarki
