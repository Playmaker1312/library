# Universal selector menggunakan tanda bintang untuk memilih semua elemen

## Analogi: Perpustakaan Digital

Universal selector (`*`) seperti perintah "berlaku untuk semua buku di perpustakaan digital." Apapun jenisnya — fiksi, non-fiksi, referensi — semua buku akan menerapkan aturan yang sama. Ini berguna untuk memberikan gaya dasar yang seragam, seperti memberi sampul plastik pada setiap buku.

## Penjelasan Detail

Universal selector (`*`) memilih semua elemen HTML dalam dokumen. Ini sering digunakan dalam CSS reset untuk menghilangkan margin dan padding default browser. Selektor ini dapat dikombinasikan dengan selector lain, misalnya `*.class` yang sama dengan `.class`, atau `div *` yang memilih semua elemen di dalam div. Universal selector memiliki spesifisitas 0 (nol), sehingga mudah ditimpa oleh selector lain. Meskipun berguna, penggunaan berlebihan dapat mempengaruhi performa karena browser harus mencocokkan semua elemen.

## Contoh Kode Implementasi

```css
/* CSS reset menggunakan universal selector */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* Universal selector dalam kombinasi */
.container * {
  font-family: Arial, sans-serif;
  color: #333;
}

/* Semua elemen di dalam form */
.form-wrapper * {
  display: block;
  margin-bottom: 10px;
}
```

## Poin Penting
- Universal selector `*` memilih SEMUA elemen HTML
- Sering digunakan untuk CSS reset (menghilangkan margin/padding default)
- Spesifisitas 0 — mudah ditimpa selector lain
