# 13. font-size — Skala Tipografi yang Harmonis

## Penjelasan

`font-size` mengatur ukuran teks. Tiga satuan utama:

| Satuan | Relatif ke | Contoh | Karakter |
|--------|-----------|--------|----------|
| `px` | absolut (pixel) | `16px` | Tidak responsif, abaikan preferensi user |
| `rem` | root (`<html>`) | `1rem` = 16px | Responsif, ikuti setting browser user |
| `em` | parent element | `1.5em` = 1.5x parent | Skalabel per komponen |

```css
:root {
  /* Skala tipografi — Major Third ratio 1.25 */
  --text-xs:   0.75rem;   /* 12px */
  --text-sm:   0.875rem;  /* 14px */
  --text-base: 1rem;      /* 16px (default browser) */
  --text-lg:   1.125rem;  /* 18px */
  --text-xl:   1.25rem;   /* 20px */
  --text-2xl:  1.5rem;    /* 24px */
  --text-3xl:  1.875rem;  /* 30px */
  --text-4xl:  2.25rem;   /* 36px */
  --text-5xl:  3rem;      /* 48px */
}
```

## Fungsi

- Membuat hierarki visual — pembaca bisa bedakan judul, sub-judul, dan body
- Skala yang harmonis membuat desain terasa profesional dan konsisten

## Cara Pengimplementasian

```css
:root {
  --text-xs:   0.75rem;
  --text-sm:   0.875rem;
  --text-base: 1rem;
  --text-lg:   1.125rem;
  --text-xl:   1.25rem;
  --text-2xl:  1.5rem;
  --text-3xl:  1.875rem;
  --text-4xl:  2.25rem;
  --text-5xl:  3rem;
}

h1 { font-size: var(--text-5xl); }
h2 { font-size: var(--text-3xl); }
h3 { font-size: var(--text-2xl); }
h4 { font-size: var(--text-xl); }
p  { font-size: var(--text-base); }
small, .caption { font-size: var(--text-sm); }
```

## Analogi

Skala tipografi seperti **ukuran papan nama di rumah**:
- **`--text-5xl`** = papan nama besar di depan rumah (heading 1) — terlihat dari jauh
- **`--text-3xl`** = papan nama kamar (heading 2) — terlihat dari pintu
- **`--text-base`** = tulisan di buku tamu (body) — ukuran nyaman untuk dibaca dekat

Jika semua papan nama ukurannya sama, tidak ada hierarki — pengunjung bingung mana informasi utama. Skala tipografi menciptakan **hierarki visual** alami.

## Dipakai Untuk Apa

- Heading 1-6: ukuran paling besar ke paling kecil
- Body text: ukuran nyaman baca (16px / 1rem)
- Caption, footnote, label: ukuran kecil
- Menciptakan hierarki informasi di halaman

## Kesalahan Umum

- **Gunakan `px` untuk body text**: user tidak bisa memperbesar teks via setting browser — masalah aksesibilitas
- **Ukuran heading tidak proporsional**: h1 64px, h2 18px — lompatan terlalu besar, hierarki tidak jelas
- **Tidak konsisten**: kadang pakai `1.2rem`, kadang `20px` — campuran satuan
- **Semua teks ukuran sama**: tidak ada pembeda antara judul dan konten

## Hubungan dengan Materi Sebelumnya

Poin 12: font-family sudah dipilih. Sekarang kita atur **ukurannya**. `rem` adalah satuan pilihan karena menghormati preferensi ukuran font browser user — aksesibilitas yang baik. Skala tipografi (xs sampai 5xl) memastikan semua ukuran konsisten.

## Soal Latihan

### Soal 1
Apa perbedaan `rem` dan `em`?

**Jawaban:**
`rem` relatif terhadap ukuran font root (`<html>`), biasanya 16px. `em` relatif terhadap ukuran font elemen parent. `em` bisa bertumpuk (nested em → semakin besar), `rem` selalu konsisten.

### Soal 2
Jika root font-size adalah 16px, berapa pixel `2.5rem`?

**Jawaban:**
2.5 × 16px = **40px**.

### Soal 3
Mengapa `px` tidak disarankan untuk `font-size` body text?

**Jawaban:**
Karena `px` bersifat absolut dan tidak mengikuti preferensi ukuran font browser user. Pengguna yang membutuhkan teks lebih besar (gangguan penglihatan, layar kecil) tidak bisa memperbesar teks. `rem` menghormati setting tersebut.
