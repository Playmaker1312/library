# 8. Grouping Selector — Satu Aturan untuk Beberapa Elemen

## Penjelasan

Grouping selector memungkinkan satu aturan CSS diterapkan ke **beberapa selector sekaligus** dengan memisahkannya menggunakan **koma**.

```css
/* Tanpa grouping — berulang: */
h1 { color: #1e40af; font-weight: 700; }
h2 { color: #1e40af; font-weight: 700; }
h3 { color: #1e40af; font-weight: 700; }

/* Dengan grouping — efisien: */
h1, h2, h3 {
  color: #1e40af;
  font-weight: 700;
}
```

## Fungsi

- Mengurangi duplikasi kode
- Memudahkan pemeliharaan — ubah satu tempat, semua berubah
- Membuat stylesheet lebih bersih dan singkat

## Cara Pengimplementasian

```css
/* Grouping berbagai jenis selector */
h1, h2, h3, h4 {
  line-height: 1.2;
  font-family: var(--font-sans);
}

/* Class dan type dalam satu grup */
.btn, button, input[type="submit"] {
  display: inline-block;
  padding: 8px 16px;
  border-radius: 4px;
  cursor: pointer;
}

/* Selector kompleks bisa digabung */
nav a, .footer a, .breadcrumb a {
  text-decoration: none;
  color: inherit;
}

/* Dengan koma di baris terpisah — lebih rapi */
.project-card,
.blog-card,
.testimonial-card {
  background-color: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: var(--radius-lg);
  padding: var(--space-6);
}
```

## Analogi

Seperti **daftar belanja** — "Beli susu, roti, dan telur" lebih efisien daripada "Beli susu. Beli roti. Beli telur." Kamu pergi ke toko sekali untuk semua barang. Grouping selector adalah "pergi ke toko sekali" untuk beberapa elemen sekaligus.

## Dipakai Untuk Apa

- Heading: semua heading punya `line-height` dan `font-family` yang sama
- Komponen: semua varian card punya border dan padding yang sama
- Global: semua link di navigasi dan footer punya style yang seragam

## Kesalahan Umum

- **Lupa koma**: `h1 h2 h3` (tanpa koma) berarti "h2 di dalam h1, dan h3" — berbeda dengan `h1, h2, h3`
- **Kelebihan grouping**: jika nanti satu selector perlu style berbeda, lebih baik pisahkan dari awal
- **Typo di satu selector**: seluruh grup gagal jika browser tidak kenali selector (`:invalid-pseudo` misalnya) — hati-hati di browser lama

## Hubungan dengan Materi Sebelumnya

Poin 5-7: kita tahu berbagai cara memilih elemen. Sekarang kita hemat waktu dengan **mengelompokkan selector yang punya style sama**. Ini adalah praktik menulis CSS yang efisien — DRY (Don't Repeat Yourself).

## Soal Latihan

### Soal 1
Tulis ulang kode berikut menggunakan grouping selector:
```css
.card { border-radius: 8px; }
.card-header { border-radius: 8px; }
.card-footer { border-radius: 8px; }
```

**Jawaban:**
```css
.card, .card-header, .card-footer {
  border-radius: 8px;
}
```

### Soal 2
Apa bahaya lupa koma di grouping selector `h1 h2 h3`?

**Jawaban:**
`h1 h2 h3` (tanpa koma) berarti "h3 yang berada di dalam h2 yang berada di dalam h1" — descendant selector, bukan grouping. Ini mungkin tidak memilih elemen yang dimaksud sama sekali.

### Soal 3
Kapan sebaiknya TIDAK menggunakan grouping selector?

**Jawaban:**
Ketika di masa depan salah satu selector mungkin butuh style berbeda. Misal semua button punya padding sama, tapi button `submit` nanti perlu padding lebih besar. Lebih baik tulis terpisah dari awal jika ada indikasi akan berbeda.
