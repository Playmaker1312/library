# 9. Format Warna CSS — Hex, RGB & HSL

## Penjelasan

Tiga format warna utama di CSS:

| Format | Sintaks | Contoh | Kelebihan |
|--------|---------|--------|-----------|
| **Hex** | `#RRGGBB` | `#1e40af` | Paling umum, mudah copy dari design tool |
| **RGB** | `rgb(R, G, B)` | `rgb(30, 64, 175)` | Mudah untuk transparansi (rgba) |
| **HSL** | `hsl(H, S%, L%)` | `hsl(224, 72%, 40%)` | Intuitif buat variasi warna |

```css
.hex-example { color: #1e40af; }        /* biru */
.rgb-example { color: rgb(30, 64, 175); } /* biru yang sama */
.hsl-example { color: hsl(224, 72%, 40%); } /* biru yang sama */

/* Dengan transparansi */
.rgba-example { color: rgba(30, 64, 175, 0.5); }  /* 50% transparan */
.hsla-example { color: hsla(224, 72%, 40%, 0.5); }
```

## Fungsi

- Menentukan warna elemen CSS — teks, background, border
- Memberi kontrol atas transparansi (RGBA/HSLA)

## Cara Pengimplementasian

```css
:root {
  /* Hex — paling sering digunakan */
  --blue-600: #2563eb;
  --green-500: #10b981;
  --red-500: #ef4444;
  
  /* RGB — untuk transparansi */
  --blue-600-rgb: 37, 99, 235;
  
  /* HSL — untuk variasi warna */
  --blue-h: 224;
  --blue-s: 72%;
}
```

**HSL** paling intuitif: `H` (0-360, posisi roda warna), `S` (0-100%, intensitas warna), `L` (0-100%, gelap/terang). Jika ingin versi lebih gelap dari warna yang sama, cukup turunkan nilai L (Lightness).
```
hsl(224, 72%, 40%) → warna dasar
hsl(224, 72%, 30%) → lebih gelap
hsl(224, 72%, 60%) → lebih terang
```

## Analogi

Warna seperti **cat rumah**:
- **Hex** seperti kode katalog cat "Biru Samudra #1e40af" — kamu tunjukkan kode ini ke toko cat, mereka kasih warna yang tepat
- **RGB** seperti resep "campur 30ml merah, 64ml hijau, 175ml biru"
- **HSL** seperti deskripsi "biru dengan jenuh 72% dan terang 40%"

HSL paling intuitif untuk membuat variasi: "Buat biru ini 10% lebih gelap" = turunkan Lightness.

## Dipakai Untuk Apa

- Menentukan warna teks, background, border, shadow
- Sistem warna yang konsisten di seluruh website

## Kesalahan Umum

- **Format campur aduk tanpa sistem**: kadang hex, kadang rgb, kadang hsl — sulit konsisten
- **Transparansi tidak disadari**: jika pakai `rgba(0,0,0,0.5)` di atas teks putih, hasilnya abu-abu, bukan hitam
- **Lupa `#` di hex**: `1e40af` tanpa `#` tidak valid

## Hubungan dengan Materi Sebelumnya

Poin 5-8: kita sudah bisa memilih elemen dengan selector. Sekarang kita tentukan **apa yang akan diubah** — dimulai dari warna. Warna adalah properti yang paling langsung terlihat dampaknya.

## Soal Latihan

### Soal 1
Tulis warna merah murni dalam format Hex, RGB, dan HSL.

**Jawaban:**
- Hex: `#ff0000`
- RGB: `rgb(255, 0, 0)`
- HSL: `hsl(0, 100%, 50%)`

### Soal 2
Dari warna dasar `hsl(224, 72%, 40%)`, bagaimana cara membuat versi yang lebih terang?

**Jawaban:**
Naikkan nilai Lightness: `hsl(224, 72%, 60%)` — warna lebih terang, hue tetap biru yang sama.

### Soal 3
Format mana yang paling cocok jika perlu menambahkan transparansi?

**Jawaban:**
RGBA (`rgba(30, 64, 175, 0.5)`) atau HSLA (`hsla(224, 72%, 40%, 0.5)`). Hex tidak mendukung transparansi secara langsung.
