# 1. Apa itu CSS & Cara Browser Memprosesnya

## Penjelasan

CSS (Cascading Style Sheets) adalah bahasa yang memisahkan **tampilan** dari **struktur** (HTML). Browser memproses CSS dalam urutan:

1. **HTML** diunduh dan diurai menjadi DOM (Document Object Model)
2. **CSS** diunduh dan diurai menjadi CSSOM (CSS Object Model)
3. DOM + CSSOM digabungkan menjadi **Render Tree**
4. Browser melakukan **Layout** (menghitung posisi/ukuran)
5. Browser melakukan **Paint** (menggambar ke layar)

## Fungsi

- Memberikan gaya visual pada elemen HTML (warna, font, ukuran, layout)
- Memisahkan konten (HTML) dari presentasi (CSS)
- Satu file CSS bisa dipakai untuk banyak halaman (reusable)

## Cara Pengimplementasian

```css
/* styles.css */
h1 {
  color: blue;
  font-size: 2rem;
}
```

Hubungkan ke HTML:

```html
<link rel="stylesheet" href="styles.css">
```

## Analogi

Bayangkan rumah. HTML adalah **kerangka dan struktur** (dinding, atap, pintu). CSS adalah **cat, wallpaper, furnitur, dan dekorasi**. Tanpa CSS, website seperti rumah tanpa cat — tetap berfungsi sebagai tempat tinggal, tapi tidak nyaman dipandang. Browser adalah **kontraktor** yang membaca blueprint (HTML), lalu menerapkan semua sentuhan akhir (CSS) sesuai instruksi.

## Dipakai Untuk Apa

- Mewarnai teks dan latar belakang
- Mengatur ukuran, jenis, dan gaya font
- Membuat layout halaman (tata letak)
- Menambahkan animasi dan interaksi visual
- Membuat website responsif di berbagai ukuran layar

## Kesalahan Umum

- **Lupa menghubungkan file CSS** ke HTML — tidak ada style yang muncul
- **Typo pada nama properti** — browser mengabaikan properti yang salah ketik
- **Tidak memahami urutan proses** — sering bingung kenapa style "tidak jalan" atau muncul setengah-setengah saat halaman loading

## Hubungan dengan Materi Sebelumnya

Ini adalah **pintu gerbang** ke seluruh roadmap. Sebelum belajar properti CSS apapun, kita harus paham bagaimana CSS bekerja di browser. Tanpa ini, semua gaya yang kita tulis terasa seperti "trial and error" — kita tidak tahu mengapa sesuatu berhasil atau gagal.

## Soal Latihan

### Soal 1
Apa kepanjangan CSS dan apa fungsi utamanya?

**Jawaban:**
CSS = Cascading Style Sheets. Fungsi utamanya adalah mengatur tampilan/visual dari elemen HTML — memisahkan konten dari presentasi.

### Soal 2
Jelaskan urutan singkat bagaimana browser memproses CSS hingga sebuah halaman tampil.

**Jawaban:**
HTML → DOM → CSS → CSSOM → Render Tree → Layout → Paint

### Soal 3
Mengapa penting memisahkan CSS dari HTML?

**Jawaban:**
1. Satu file CSS bisa dipakai di banyak halaman (efisien)
2. Kode lebih mudah dipelihara
3. File CSS bisa di-cache browser untuk loading lebih cepat
4. Pemisahan tanggung jawab (separation of concerns)
