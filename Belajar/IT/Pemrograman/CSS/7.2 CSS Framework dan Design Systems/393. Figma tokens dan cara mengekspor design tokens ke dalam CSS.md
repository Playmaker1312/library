# Figma Tokens dan Cara Mengekspor Design Tokens ke dalam CSS

## Analogi: Perpustakaan Digital

Figma tokens seperti katalog pusat perpustakaan yang mendefinisikan standar secara visual — warna dinding, jenis kertas label, ukuran font papan nama. Ketika standar ini diperbarui di katalog pusat (Figma), sistem digital perpustakaan (CSS) harus disinkronkan secara otomatis. Tokens menjadi jembatan antara desainer dan developer.

## Penjelasan Detail

Design tokens adalah unit terkecil dari keputusan desain — warna, spacing, font size, shadow, dan lainnya. Figma tokens (menggunakan plugin seperti Tokens Studio / Figma Tokens) memungkinkan desainer mendefinisikan tokens langsung di file Figma. Tokens ini dapat diekspor dalam format JSON dan dikonversi ke CSS menggunakan tools seperti Style Dictionary (Amazon) atau Theo. Workflow ini memastikan konsistensi antara desain di Figma dan implementasi di kode. Setiap perubahan desain di Figma dapat langsung diterjemahkan ke tokens tanpa perlu manual copy-paste.

```javascript
// Style Dictionary — konversi JSON tokens ke CSS
// style-dictionary.config.js
const StyleDictionary = require('style-dictionary');

module.exports = {
  source: ['tokens.json'],
  platforms: {
    css: {
      transformGroup: 'css',
      buildPath: 'src/styles/',
      files: [{
        destination: 'tokens.css',
        format: 'css/variables',
        options: {
          outputReferences: true,
          selector: ':root'
        }
      }]
    },
    scss: {
      transformGroup: 'scss',
      buildPath: 'src/styles/',
      files: [{
        destination: '_tokens.scss',
        format: 'scss/variables'
      }]
    },
    js: {
      transformGroup: 'js',
      buildPath: 'src/styles/',
      files: [{
        destination: 'tokens.js',
        format: 'javascript/es6'
      }]
    }
  }
};
```

## Poin Penting
- Design tokens adalah unit terkecil keputusan desain yang dijadikan jembatan antara desainer dan developer
- Figma tokens plugin memungkinkan definisi tokens langsung di file Figma
- Style Dictionary (Amazon) mengkonversi tokens JSON ke berbagai format (CSS, SCSS, JS)
- Workflow tokens memastikan konsistensi desain-ke-kode secara otomatis
