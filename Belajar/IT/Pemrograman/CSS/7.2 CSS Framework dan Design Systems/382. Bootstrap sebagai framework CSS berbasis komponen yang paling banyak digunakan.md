# Bootstrap sebagai Framework CSS Berbasis Komponen yang Paling Banyak Digunakan

## Analogi: Perpustakaan Digital

Bootstrap seperti perpustakaan digital yang sudah memiliki semua rak, label, meja baca, dan sistem pencarian yang terstandarisasi. Anda tinggal mengisi kontennya. Ini adalah sistem yang paling banyak digunakan di dunia, dengan dokumentasi lengkap dan komunitas besar yang siap membantu.

## Penjelasan Detail

Bootstrap adalah framework CSS open-source yang dikembangkan oleh Twitter pada tahun 2011. Bootstrap menyediakan komponen UI siap pakai seperti navbar, modal, carousel, form, card, badges, dan alerts. Fitur utama Bootstrap meliputi grid system 12 kolom yang responsif, utility classes yang luas, komponen JavaScript (seperti dropdown dan tooltip), serta tema kustomisasi melalui SASS variabel. Bootstrap 5 menggunakan CSS Grid dan Flexbox murni (tanpa jQuery). Bootstrap mendukung aksesibilitas dengan atribut ARIA dan fokus manajemen. Dengan dokumentasi ekstensif, contoh kode, dan template, Bootstrap adalah pilihan utama untuk rapid prototyping dan proyek dengan tim besar.

```css
  padding-right: calc(var(--bs-gutter-x) * 0.5);

```

## Poin Penting
- Bootstrap adalah framework CSS paling populer, dikembangkan oleh Twitter sejak 2011
- Fitur utama: grid system 12 kolom, komponen UI siap pakai, utility classes
- Bootstrap 5 menggunakan CSS Flexbox/Grid murni tanpa ketergantungan jQuery
- Cocok untuk rapid prototyping dan proyek dengan tim besar berkat dokumentasi lengkap
