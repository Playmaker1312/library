# Konsep Design System dan Perbedaannya dengan Framework CSS Biasa

## Analogi: Perpustakaan Digital

Design system seperti manual branding komprehensif untuk seluruh jaringan perpustakaan — menentukan warna logo, jenis font untuk semua papan nama, ukuran rak standar, dan bahkan nada suara petugas. Framework CSS seperti set furnitur standar yang bisa dibeli. Design system lebih dari sekadar kode — ini adalah bahasa desain terpadu.

## Penjelasan Detail

Design system adalah kumpulan standar, prinsip, dan komponen yang digunakan bersama untuk membangun produk digital secara konsisten. Design system mencakup design tokens (warna, tipografi, spacing), komponen UI, pattern library, guidelines, dan dokumentasi. Perbedaan utama dengan framework CSS: framework adalah solusi teknis siap pakai, sedangkan design system adalah pendekatan holistik yang mencakup desain, kode, dan proses. Design system dapat menggunakan framework CSS sebagai fondasi teknis, atau dibangun dari kustom. Design system lebih fleksibel dan dapat disesuaikan dengan brand, sedangkan framework memiliki batasan tertentu.

## Poin Penting
- Design system adalah kumpulan standar, prinsip, dan komponen untuk konsistensi produk digital
- Framework CSS adalah solusi teknis siap pakai; design system lebih holistik (desain + kode + proses)
- Design tokens (variabel desain) adalah fondasi design system
- Design system dapat dibangun di atas framework CSS atau dari kustom sepenuhnya
