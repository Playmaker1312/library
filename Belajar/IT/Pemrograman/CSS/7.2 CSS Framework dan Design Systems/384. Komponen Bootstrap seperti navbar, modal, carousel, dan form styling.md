# Komponen Bootstrap seperti Navbar, Modal, Carousel, dan Form Styling

## Analogi: Perpustakaan Digital

Bootstrap menyediakan berbagai komponen seperti furnitur standar perpustakaan: rak buku (navbar), meja baca (card), kotak saran (modal), pajangan buku bergilir (carousel), dan formulir pendaftaran (form). Semua sudah didesain dan siap pakai, tinggal diisi kontennya.

## Penjelasan Detail

Bootstrap menyediakan berbagai komponen UI yang siap pakai. Navbar adalah navigasi responsif dengan brand, menu, dan toggler. Modal adalah dialog overlay dengan backdrop, header, body, dan footer. Carousel adalah slider konten dengan kontrol navigasi. Form memiliki styling untuk input, select, checkbox, radio, file input, dan validation states. Setiap komponen memiliki variasi (seperti warna, ukuran) melalui modifier classes. Bootstrap 5 menggunakan JavaScript murni tanpa jQuery untuk interaktivitas komponen seperti dropdown, modal, dan carousel.

## Poin Penting
- Bootstrap menyediakan komponen siap pakai: navbar, modal, carousel, form, card, alert, badges
- Setiap komponen memiliki variasi melalui modifier classes seperti warna dan ukuran
- Bootstrap 5 menggunakan JavaScript murni tanpa jQuery untuk interaktivitas komponen
- Komponen Bootstrap didesain dengan aksesibilitas dan responsivitas sebagai prioritas
