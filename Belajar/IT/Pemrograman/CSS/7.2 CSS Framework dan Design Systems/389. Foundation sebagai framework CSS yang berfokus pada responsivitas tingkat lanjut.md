# Foundation sebagai Framework CSS yang Berfokus pada Responsivitas Tingkat Lanjut

## Analogi: Perpustakaan Digital

Foundation seperti sistem perpustakaan enterprise yang dirancang untuk skala besar dengan fitur responsivitas canggih. Jika perpustakaan harus melayani pengguna dari berbagai perangkat (kios, tablet, ponsel), Foundation menyediakan alat untuk memastikan pengalaman optimal di setiap ukuran layar.

## Penjelasan Detail

Foundation adalah framework CSS enterprise yang dikembangkan oleh Zurb. Fokus utama Foundation adalah responsivitas tingkat lanjut dengan fitur seperti XY Grid (berbasis Flexbox dan CSS Grid), visibility classes untuk kontrol tampilan perangkat, responsive navigation (top bar, drilldown, accordion menu), dan komponen canggih seperti interchange (responsive images) dan responsive tables. Foundation menggunakan SASS sebagai preprocessor dan menyediakan sistem build dengan customizer. Foundation cocok untuk proyek skala besar dan enterprise yang membutuhkan kontrol responsif yang presisi.

## Contoh Kode Implementasi

```css
/* Foundation-style XY Grid */

/* Grid container */
.grid-container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 0.625rem;
}

.grid-container.fluid {
  max-width: 100%;
}

/* Grid X (horizontal) */
.grid-x {
  display: flex;
  flex-flow: row wrap;
}

.grid-x > .cell {
  flex: 0 0 auto;
  min-width: 0;
}

/* Cell widths */
.cell { flex: 1 1 0%; }
.shrink { flex: 0 0 auto; }
.auto { flex: 1 1 0%; }

.small-1 { flex-basis: 8.3333%; max-width: 8.3333%; }
.small-2 { flex-basis: 16.6667%; max-width: 16.6667%; }
.small-3 { flex-basis: 25%; max-width: 25%; }
.small-4 { flex-basis: 33.3333%; max-width: 33.3333%; }
.small-6 { flex-basis: 50%; max-width: 50%; }
.small-12 { flex-basis: 100%; max-width: 100%; }

@media (min-width: 640px) {
  .medium-3 { flex-basis: 25%; max-width: 25%; }
  .medium-4 { flex-basis: 33.3333%; max-width: 33.3333%; }
  .medium-6 { flex-basis: 50%; max-width: 50%; }
  .medium-8 { flex-basis: 66.6667%; max-width: 66.6667%; }
}

@media (min-width: 1024px) {
  .large-2 { flex-basis: 16.6667%; max-width: 16.6667%; }
  .large-3 { flex-basis: 25%; max-width: 25%; }
  .large-4 { flex-basis: 33.3333%; max-width: 33.3333%; }
  .large-6 { flex-basis: 50%; max-width: 50%; }
}

/* Grid margin */
.grid-margin-x {
  margin: 0 -0.625rem;
}

.grid-margin-x > .cell {
  padding: 0 0.625rem;
}

/* Grid Y (vertical) */
.grid-y {
  display: flex;
  flex-flow: column nowrap;
}

/* Visibility classes */
.show-for-small-only { display: block; }
.hide-for-small-only { display: none; }

@media (min-width: 640px) {
  .show-for-medium { display: block; }
  .hide-for-medium { display: none; }
  .show-for-small-only { display: none; }
}

@media (min-width: 1024px) {
  .show-for-large { display: block; }
  .hide-for-large { display: none; }
}

/* Responsive navigation — Top Bar */
.top-bar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 0.5rem;
  background: #333;
  color: white;
}

.top-bar-title {
  font-weight: bold;
  font-size: 1.25rem;
}

.top-bar-left, .top-bar-right {
  display: flex;
  align-items: center;
  gap: 1rem;
}

.top-bar ul {
  list-style: none;
  margin: 0;
  padding: 0;
  display: flex;
  gap: 0.5rem;
}

.top-bar a {
  color: white;
  text-decoration: none;
  padding: 0.5rem 0.75rem;
}

/* Callout (alert) */
.callout {
  padding: 1rem;
  margin-bottom: 1rem;
  border: 1px solid #e6e6e6;
  border-radius: 3px;
  background: #fefefe;
  color: #0a0a0a;
}

.callout.primary { background: #def0fc; border-color: #b5d8f5; }
.callout.success { background: #e1faea; border-color: #b8f0cc; }
.callout.alert { background: #fce6e6; border-color: #f8bfbf; }

/* Responsive table */
.responsive-table {
  overflow-x: auto;
}

.responsive-table table {
  min-width: 600px;
}

/* Interchange (responsive images) */
.responsive-img img {
  width: 100%;
  height: auto;
}

/* Flexbox utilities */
.align-center { justify-content: center; }
.align-right { justify-content: flex-end; }
.align-justify { justify-content: space-between; }
.align-middle { align-items: center; }
.align-bottom { align-items: flex-end; }
.align-center-middle {
  display: flex;
  align-items: center;
  justify-content: center;
}
```

## Poin Penting
- Foundation dikembangkan oleh Zurb untuk proyek enterprise dengan fokus responsivitas
- XY Grid menggunakan grid-x dan grid-y dengan cell yang responsif per breakpoint
- Visibility classes mengontrol tampilan elemen berdasarkan ukuran layar
- Foundation menyediakan komponen canggih seperti responsive navigation, interchange, dan responsive tables
