# Cara Membuat Design System Sederhana Menggunakan Variabel CSS dan Komponen

## Analogi: Perpustakaan Digital

Membangun design system sendiri seperti merancang perpustakaan dari awal. Anda menentukan skema warna untuk rak dan label, memilih font untuk papan petunjuk, menetapkan jarak antar rak, dan mendesain formulir peminjaman yang konsisten. Semua keputusan ini dicatat sebagai "standar" di buku panduan.

## Penjelasan Detail

Membangun design system sederhana dimulai dengan mendefinisikan design tokens menggunakan CSS custom properties (variabel CSS). Tokens mencakup warna, tipografi, spacing, shadows, dan border-radius. Selanjutnya, bangun komponen dasar (button, card, input, badge) yang menggunakan tokens ini. Komponen harus memiliki variasi melalui modifier classes. Dokumentasikan setiap komponen dengan nama, deskripsi, dan contoh kode. Pendekatan ini memastikan konsistensi visual di seluruh produk dan memudahkan scaling tim.

## Contoh Kode Implementasi

```css
/* ==================== */
/* 1. DESIGN TOKENS */
/* ==================== */
:root {
  /* Warna */
  --clr-primary: #6366f1;
  --clr-primary-hover: #4f46e5;
  --clr-primary-light: #eef2ff;
  --clr-success: #22c55e;
  --clr-danger: #ef4444;
  --clr-warning: #f59e0b;

  --clr-text: #1e293b;
  --clr-text-secondary: #64748b;
  --clr-bg: #ffffff;
  --clr-bg-secondary: #f8fafc;
  --clr-border: #e2e8f0;

  /* Tipografi */
  --ff-sans: 'Inter', system-ui, -apple-system, sans-serif;
  --ff-mono: 'JetBrains Mono', monospace;
  --fs-sm: 0.875rem;
  --fs-base: 1rem;
  --fs-lg: 1.125rem;
  --fs-xl: 1.5rem;
  --fs-2xl: 2rem;
  --fw-normal: 400;
  --fw-medium: 500;
  --fw-bold: 700;

  /* Spacing */
  --sp-1: 0.25rem;
  --sp-2: 0.5rem;
  --sp-3: 0.75rem;
  --sp-4: 1rem;
  --sp-6: 1.5rem;
  --sp-8: 2rem;
  --sp-12: 3rem;

  /* Radius */
  --radius-sm: 0.25rem;
  --radius-md: 0.5rem;
  --radius-lg: 0.75rem;
  --radius-full: 9999px;

  /* Shadow */
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.05);
  --shadow-md: 0 4px 6px -1px rgba(0,0,0,0.1);

  /* Transition */
  --tr-fast: 150ms ease;
}

/* ==================== */
/* 2. RESET / BASE */
/* ==================== */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: var(--ff-sans);
  font-size: var(--fs-base);
  color: var(--clr-text);
  background: var(--clr-bg);
  line-height: 1.6;
}

/* ==================== */
/* 3. KOMPONEN */
/* ==================== */

/* Button */
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: var(--sp-2);
  padding: var(--sp-2) var(--sp-4);
  font-family: var(--ff-sans);
  font-size: var(--fs-sm);
  font-weight: var(--fw-medium);
  line-height: 1.5;
  border: 1px solid transparent;
  border-radius: var(--radius-md);
  cursor: pointer;
  transition: all var(--tr-fast);
  text-decoration: none;
}

.btn-primary {
  background: var(--clr-primary);
  color: white;
}

.btn-primary:hover {
  background: var(--clr-primary-hover);
}

.btn-outline {
  background: transparent;
  color: var(--clr-primary);
  border-color: var(--clr-primary);
}

.btn-outline:hover {
  background: var(--clr-primary-light);
}

.btn-sm { padding: var(--sp-1) var(--sp-3); font-size: var(--fs-sm); }
.btn-lg { padding: var(--sp-3) var(--sp-6); font-size: var(--fs-base); }

/* Card */
.card {
  background: var(--clr-bg);
  border: 1px solid var(--clr-border);
  border-radius: var(--radius-lg);
  padding: var(--sp-6);
  box-shadow: var(--shadow-sm);
}

.card-header {
  margin-bottom: var(--sp-4);
  padding-bottom: var(--sp-4);
  border-bottom: 1px solid var(--clr-border);
}

.card-title {
  font-size: var(--fs-lg);
  font-weight: var(--fw-bold);
}

.card-body {
  color: var(--clr-text-secondary);
  line-height: 1.6;
}

/* Badge */
.badge {
  display: inline-flex;
  align-items: center;
  padding: var(--sp-1) var(--sp-3);
  font-size: var(--fs-sm);
  font-weight: var(--fw-medium);
  border-radius: var(--radius-full);
  line-height: 1.4;
}

.badge-primary {
  background: var(--clr-primary-light);
  color: var(--clr-primary);
}

.badge-success {
  background: #dcfce7;
  color: #166534;
}

.badge-danger {
  background: #fef2f2;
  color: #991b1b;
}

/* Input */
.input {
  display: block;
  width: 100%;
  padding: var(--sp-2) var(--sp-3);
  font-family: var(--ff-sans);
  font-size: var(--fs-base);
  color: var(--clr-text);
  background: var(--clr-bg);
  border: 1px solid var(--clr-border);
  border-radius: var(--radius-md);
  transition: border-color var(--tr-fast);
}

.input:focus {
  outline: none;
  border-color: var(--clr-primary);
  box-shadow: 0 0 0 3px var(--clr-primary-light);
}

.input-error {
  border-color: var(--clr-danger);
}

.input-error:focus {
  box-shadow: 0 0 0 3px #fef2f2;
}

/* Alert */
.alert {
  padding: var(--sp-4);
  border-radius: var(--radius-md);
  border: 1px solid transparent;
  font-size: var(--fs-sm);
  line-height: 1.5;
}

.alert-info {
  background: var(--clr-primary-light);
  color: var(--clr-primary);
  border-color: var(--clr-primary);
}

.alert-success {
  background: #dcfce7;
  color: #166534;
  border-color: #bbf7d0;
}

.alert-danger {
  background: #fef2f2;
  color: #991b1b;
  border-color: #fecaca;
}

/* ==================== */
/* 4. LAYOUT */
/* ==================== */
.container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 var(--sp-6);
}

.flex { display: flex; }
.flex-col { flex-direction: column; }
.items-center { align-items: center; }
.justify-between { justify-content: space-between; }
.gap-2 { gap: var(--sp-2); }
.gap-4 { gap: var(--sp-4); }
.gap-6 { gap: var(--sp-6); }
```

## Poin Penting
- Design system dimulai dari design tokens: warna, tipografi, spacing, shadow, radius
- Komponen dibangun menggunakan tokens untuk konsistensi visual
- Gunakan modifier classes untuk variasi komponen (btn-primary, btn-outline, btn-sm)
- Dokumentasi dan konsistensi adalah kunci keberhasilan design system
