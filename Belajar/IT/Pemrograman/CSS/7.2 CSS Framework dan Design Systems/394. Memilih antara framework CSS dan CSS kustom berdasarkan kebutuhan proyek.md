# Memilih antara Framework CSS dan CSS Kustom Berdasarkan Kebutuhan Proyek

## Analogi: Perpustakaan Digital

Memilih antara framework CSS atau CSS kustom seperti memutuskan apakah akan membeli perabot perpustakaan yang sudah jadi (IKEA) atau membuatnya dari awal oleh tukang kayu. Perabot jadi lebih cepat dan murah, tetapi mungkin tidak pas dengan ruangan unik. Perabot kustom lebih mahal dan lama, tetapi sesuai persis dengan kebutuhan.

## Penjelasan Detail

Keputusan menggunakan framework CSS atau CSS kustom tergantung pada beberapa faktor. Framework (Bootstrap, Tailwind) unggul dalam kecepatan development, konsistensi tim, dan dokumentasi lengkap. CSS kustom unggul dalam performa (file lebih kecil), fleksibilitas desain unik, dan kontrol penuh. Pertimbangan utama: ukuran tim (tim besar lebih cocok framework), kebutuhan desain (unik vs konvensional), deadline (ketat → framework), ukuran proyek (kecil → kustom, besar → tergantung), dan maintenance jangka panjang. Banyak proyek menggunakan pendekatan hybrid: framework sebagai fondasi dengan CSS kustom untuk komponen spesifik.

## Contoh Kode Implementasi

```css
/* Pendekatan Hybrid: Framework + CSS Kustom */

/** 
 * Variabel mendefinisikan fondasi visual
 * Bisa dari framework atau kustom
 */
:root {
  /* Framework-style grid */
  --grid-columns: 12;
  --grid-gap: 1.5rem;
  --container-max: 1200px;

  /* Brand colors */
  --brand-primary: #7c3aed;
  --brand-secondary: #ec4899;
  --brand-accent: #f59e0b;

  /* Typography scale */
  --text-base: 1rem;
  --text-scale-ratio: 1.25;
}

/* Hybrid grid */
.container {
  width: 100%;
  max-width: var(--container-max);
  margin: 0 auto;
  padding: 0 1rem;
}

/* Grid dari framework */
.row {
  display: grid;
  grid-template-columns: repeat(var(--grid-columns), 1fr);
  gap: var(--grid-gap);
}

[class*="col-"] { min-width: 0; }

/* Tapi dengan kustomisasi */
.col-4 { grid-column: span 4; }
.col-6 { grid-column: span 6; }
.col-8 { grid-column: span 8; }

/* Kustom component */
.hero-section {
  background: linear-gradient(135deg, var(--brand-primary), var(--brand-secondary));
  color: white;
  padding: 6rem 2rem;
  border-radius: 1.5rem;
  /* Framework tidak punya gradient section seperti ini */
}

.hero-section h1 {
  font-size: clamp(2rem, 5vw, 4rem);
  font-weight: 800;
  line-height: 1.1;
  max-width: 800px;
}

/* Framework button dengan kustom variant */
.btn-kustom {
  background: var(--brand-accent);
  color: #1a1a2e;
  padding: 0.75rem 2rem;
  border-radius: 9999px;
  font-weight: 700;
  text-transform: uppercase;
  letter-spacing: 0.05em;
  transition: transform 0.2s, box-shadow 0.2s;
}

.btn-kustom:hover {
  transform: translateY(-2px);
  box-shadow: 0 8px 25px rgba(245, 158, 11, 0.4);
}

/* Kustom responsive utilities */
@media (max-width: 768px) {
  .hide-mobile { display: none; }
  .col-4, .col-6, .col-8 { grid-column: span 12; }
}

@media (min-width: 769px) {
  .hide-desktop { display: none; }
}
```

## Poin Penting
- Framework unggul dalam kecepatan development dan konsistensi tim
- CSS kustom unggul dalam fleksibilitas desain unik dan performa file
- Pendekatan hybrid (framework + kustom) sering menjadi solusi terbaik
- Faktor keputusan: ukuran tim, deadline, keunikan desain, dan skala proyek
