# Storybook untuk Dokumentasi dan Pengembangan Komponen dalam Design System

## Analogi: Perpustakaan Digital

Storybook seperti etalase perpustakaan digital di mana setiap komponen (buku, rak, formulir) dipajang secara terpisah dengan dokumentasi lengkap. Pengunjung bisa melihat, menguji, dan memahami setiap komponen tanpa harus menjelajahi seluruh sistem. Ini adalah showroom untuk komponen UI.

## Penjelasan Detail

Storybook adalah tool open-source untuk mengembangkan, mendokumentasikan, dan menguji komponen UI secara terisolasi. Storybook mendukung berbagai framework (React, Vue, Angular, Svelte) dan menyediakan fitur seperti stories (dokumentasi per komponen), controls (properti interaktif), addons (aksesibilitas, docs, viewport), dan visual testing. Storybook sangat berguna untuk design system karena memungkinkan tim melihat semua komponen dalam satu tempat, menguji variasi properti, dan memastikan konsistensi visual. Integrasi Storybook dengan design system memungkinkan dokumentasi hidup yang selalu sinkron dengan kode.

## Contoh Kode Implementasi

```javascript
// Button.stories.js — Storybook story untuk komponen Button
import React from 'react';
import { Button } from './Button';

// Konfigurasi story
export default {
  title: 'Components/Button',
  component: Button,
  argTypes: {
    variant: {
      control: { type: 'select' },
      options: ['primary', 'secondary', 'outline', 'ghost', 'danger'],
      description: 'Varian visual button'
    },
    size: {
      control: { type: 'select' },
      options: ['sm', 'md', 'lg'],
      description: 'Ukuran button'
    },
    disabled: {
      control: 'boolean',
      description: 'Apakah button dalam keadaan disabled'
    },
    children: {
      control: 'text',
      description: 'Teks atau konten button'
    }
  }
};

// Stories
export const Primary = {
  args: {
    variant: 'primary',
    size: 'md',
    children: 'Button Primary'
  }
};

export const Secondary = {
  args: {
    variant: 'secondary',
    size: 'md',
    children: 'Button Secondary'
  }
};

export const Outline = {
  args: {
    variant: 'outline',
    size: 'md',
    children: 'Button Outline'
  }
};

export const Small = {
  args: {
    variant: 'primary',
    size: 'sm',
    children: 'Small Button'
  }
};

export const Large = {
  args: {
    variant: 'primary',
    size: 'lg',
    children: 'Large Button'
  }
};

export const Disabled = {
  args: {
    variant: 'primary',
    size: 'md',
    disabled: true,
    children: 'Disabled Button'
  }
};

// Story dengan komposisi
export const ButtonGroup = {
  render: () => (
    <div style={{ display: 'flex', gap: '8px' }}>
      <Button variant="primary">Save</Button>
      <Button variant="outline">Cancel</Button>
      <Button variant="danger">Delete</Button>
    </div>
  )
};
```

## Poin Penting
- Storybook adalah tool untuk mengembangkan dan mendokumentasikan komponen UI secara terisolasi
- Stories mendokumentasikan setiap komponen dengan kontrol properti interaktif
- Addons menyediakan fitur tambahan seperti aksesibilitas, viewport testing, dan dokumentasi
- Storybook sangat penting untuk design system karena menyediakan dokumentasi hidup yang sinkron dengan kode
