# Konsep JIT atau Just In Time Compiler dalam Tailwind CSS

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang hanya mencetak label buku saat dibutuhkan, bukan mencetak semua label yang mungkin diperlukan sebelumnya. JIT compiler Tailwind seperti ini — hanya menghasilkan utility classes yang benar-benar digunakan dalam proyek, bukan seluruh perpustakaan class yang mungkin berguna.

## Penjelasan Detail

JIT (Just-In-Time) compiler adalah mode kompilasi Tailwind CSS yang diperkenalkan di Tailwind v3. Sebelum JIT, Tailwind menggunakan mode AOT (Ahead-of-Time) yang menghasilkan semua kombinasi utility class yang mungkin, menghasilkan file CSS besar. JIT hanya menghasilkan class yang terdeteksi dalam file proyek secara real-time. Keuntungan JIT termasuk ukuran file CSS yang sangat kecil, kecepatan build yang lebih cepat, kemampuan menggunakan nilai kustom tanpa konfigurasi (seperti w-[123px]), dan source maps yang lebih akurat. JIT menjadi mode default di Tailwind CSS v3.

## Contoh Kode Implementasi

```javascript
// tailwind.config.js — JIT sudah default di v3
module.exports = {
  content: [
    './src/**/*.{html,js,jsx,ts,tsx,vue}',
  ],
  theme: {
    extend: {}
  }
};
```

```css
/* @tailwind directives sudah cukup untuk JIT */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* JIT memungkinkan arbitrary values */
/* Di HTML: 
   <div class="w-[320px] h-[200px] bg-[#ff6600] text-[14px]"></div>
   <div class="grid-cols-[1fr_2fr] gap-[15px]"></div>
   <div class="bg-[url('/images/hero.jpg')]"></div>
*/
```

```html
<!-- Contoh arbitrary values yang hanya mungkin dengan JIT -->
<div class="
  w-[calc(100%-2rem)]
  h-[300px]
  bg-[#1da1f2]
  text-[15px]
  leading-[1.6]
  p-[18px]
  m-[10px_20px]
  rounded-[12px_4px]
  shadow-[0_5px_15px_rgba(0,0,0,0.3)]
  grid-cols-[repeat(auto-fill,minmax(250px,1fr))]
  bg-gradient-to-r from-[#ff6b6b] to-[#4ecdc4]
">
  Arbitrary values dengan JIT
</div>
```

```css
/* JIT juga mendukung variants dengan arbitrary values */
/* 
  @media (min-width: 750px) {
    .md\:w-[50%] { width: 50%; }
  }

  @media (prefers-color-scheme: dark) {
    .dark\:bg-[#1a1a2e] { background-color: #1a1a2e; }
  }

  .hover\:bg-[#eee]:hover { background-color: #eee; }
  .focus\:ring-[3px]:focus { ... }
*/

/* Penting: arbitrary values hanya untuk nilai unik */
/* Untuk nilai yang sering digunakan, tetap gunakan konfigurasi theme */

/* Performance JIT — file output sangat kecil */
/* 
  Sebelum JIT (AOT): 3000-4000 KB (semua kemungkinan class)
  Setelah JIT: 5-20 KB (hanya class yang digunakan)
*/

/* JIT watch mode — rebuild instan */
/* 
  npx tailwindcss -i src/input.css -o dist/output.css --watch
*/

/* JIT dengan import CSS */
@import 'tailwindcss/base';
@import 'tailwindcss/components';
@import 'tailwindcss/utilities';
```

```javascript
// Custom content detection untuk JIT
module.exports = {
  content: [
    './src/**/*.{html,js}',
    // Deteksi class dalam string
    { raw: '<div class="bg-red-500 text-white">', extension: 'html' },
    // Template engine
    './templates/**/*.twig'
  ],
  // Safety: pastikan class tertentu tidak terhapus
  safelist: [
    'bg-red-500',
    'text-center',
    { pattern: /bg-(red|green|blue)-(100|200|300)/ }
  ]
};
```

## Poin Penting
- JIT hanya menghasilkan utility class yang terdeteksi digunakan dalam proyek
- JIT menjadi mode default di Tailwind CSS v3, menggantikan AOT
- Keuntungan JIT: ukuran file kecil, build cepat, arbitrary values, akurat
- Class tidak terdeteksi harus ditambahkan ke safelist dalam konfigurasi
