# Tailwind CSS sebagai Framework Utility-First yang Berbeda dari Framework Konvensional

## Analogi: Perpustakaan Digital

Tailwind CSS seperti perpustakaan yang tidak menyediakan rak buku jadi, tetapi menyediakan batu bata, papan kayu, dan alat untuk Anda membangun rak sendiri. Pendekatan utility-first memberi Anda komponen desain terkecil (seperti padding, margin, warna) untuk dikombinasikan langsung di HTML, bukan class komponen siap pakai.

## Penjelasan Detail

Tailwind CSS adalah framework utility-first yang menyediakan class kecil dan spesifik seperti p-4 (padding: 1rem), text-center, bg-blue-500, flex, items-center. Berbeda dengan Bootstrap yang menyediakan komponen siap pakai (seperti .card, .navbar), Tailwind memberikan blok bangunan terkecil untuk dibangun langsung di HTML. Keuntungan Tailwind termasuk ukuran CSS final yang sangat kecil (purged), konsistensi desain melalui design tokens, tidak perlu menulis CSS kustom, dan fleksibilitas penuh. Pendekatan ini memerlukan perubahan mindset — desain dibangun di HTML dengan menggabungkan banyak utility classes, bukan di file CSS terpisah.

## Poin Penting
- Tailwind adalah framework utility-first dengan class kecil dan spesifik, bukan komponen siap pakai

- Ukuran CSS final sangat kecil berkat purging unused styles
- Pendekatan ini memberikan fleksibilitas penuh dan konsistensi desain melalui design tokens
