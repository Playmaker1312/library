# Konfigurasi Tailwind CSS dan Cara Menyesuaikan Tema Desain

## Analogi: Perpustakaan Digital

Tailwind CSS seperti sistem manajemen perpustakaan yang bisa dikonfigurasi sepenuhnya. Anda dapat menentukan warna dinding (warna tema), ukuran rak (spacing), jenis font (tipografi), dan aturan peminjaman (breakpoint). Semua pengaturan ini ada di satu file konfigurasi pusat.

## Penjelasan Detail

Tailwind CSS dikonfigurasi melalui file tailwind.config.js yang berisi tema desain, plugins, dan opsi kustomisasi. Tema mencakup colors, spacing, fontFamily, fontSize, breakpoints, borderRadius, boxShadow, dan lainnya. Kustomisasi tema dapat dilakukan dengan mengganti nilai default (override), menambah nilai baru (extend), atau membuat tema khusus sepenuhnya. Tailwind juga mendukung dark mode, custom variants, dan plugins. Dengan konfigurasi yang tepat, Tailwind dapat disesuaikan dengan design system proyek apa pun.

```css
/* Menggunakan konfigurasi kustom di CSS */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* Membuat component classes dengan @apply */
@layer components {
  .btn {
    @apply inline-flex items-center justify-center px-4 py-2 
           font-medium rounded-lg transition-colors duration-200
           focus:outline-none focus:ring-2 focus:ring-offset-2;
  }

  .btn-primary {
    @apply btn bg-primary-500 text-white 
           hover:bg-primary-600 
           focus:ring-primary-500;
  }

  .btn-secondary {
    @apply btn bg-neutral-200 text-neutral-800 
           hover:bg-neutral-300 
           focus:ring-neutral-400;
  }

  .card {
    @apply bg-white rounded-xl shadow-md overflow-hidden 
           border border-neutral-200;
  }

  .card-body {
    @apply p-6;
  }

  .input {
    @apply w-full px-3 py-2 border border-neutral-300 
           rounded-lg text-neutral-900 placeholder-neutral-400
           focus:outline-none focus:ring-2 focus:ring-primary-500 
           focus:border-transparent transition-colors duration-200;
  }
}

@layer base {
  h1 {
    @apply text-3xl font-bold text-neutral-900;
  }
  h2 {
    @apply text-2xl font-semibold text-neutral-800;
  }
  body {
    @apply text-neutral-700 bg-neutral-50 font-sans antialiased;
  }
}

/* Dark mode */
.dark .card {
  @apply bg-neutral-800 border-neutral-700;
}

.dark .card-body {
  @apply text-neutral-200;
}
```

```javascript
// Dengan custom plugin
const plugin = require('tailwindcss/plugin');

module.exports = {
  theme: {
    extend: {
      textShadow: {
        'sm': '0 1px 2px rgba(0, 0, 0, 0.5)',
        'lg': '0 2px 4px rgba(0, 0, 0, 0.5)'
      }
    }
  },
  plugins: [
    plugin(function({ addUtilities, addComponents, addBase, theme }) {
      addUtilities({
        '.text-shadow-sm': {
          textShadow: theme('textShadow.sm')
        },
        '.text-shadow-lg': {
          textShadow: theme('textShadow.lg')
        }
      });
    })
  ]
};
```

## Poin Penting
- Konfigurasi Tailwind dilakukan melalui tailwind.config.js dengan tema global
- theme.extend menambah nilai tanpa mengganti default; theme langsung mengganti sepenuhnya
- @layer directives (base, components, utilities) digunakan untuk mengorganisir CSS kustom
- Plugins seperti @tailwindcss/forms menambah utility classes tambahan
