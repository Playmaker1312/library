# Migrasi dari Framework CSS ke Pendekatan CSS Kustom atau Sebaliknya

## Analogi: Perpustakaan Digital

Migrasi framework seperti merenovasi perpustakaan yang sudah ada — mengganti sistem rak standar dengan rak kustom yang lebih sesuai, atau sebaliknya. Proses ini memerlukan perencanaan matang agar pengunjung (pengguna) tidak terganggu selama renovasi, dan buku (konten) tetap dapat diakses.

## Penjelasan Detail

Migrasi dari framework ke kustom atau sebaliknya adalah proses yang memerlukan strategi hati-hati. Migrasi ke CSS kustom memberikan kebebasan desain dan performa lebih baik, tetapi membutuhkan waktu dan pengujian ulang. Migrasi ke framework mempercepat development tetapi memerlukan adaptasi kode. Strategi terbaik adalah migrasi bertahap (incremental) menggunakan pendekatan side-by-side atau component-by-component. Tools seperti PurgeCSS dapat membantu saat beralih dari framework ke kustom dengan menghapus CSS yang tidak terpakai. Penting juga memiliki sistem CSS yang teruji (visual regression testing) sebelum dan sesudah migrasi.

```css
/* ==================== */
/* Strategi Migrasi: Side-by-side */
/* ==================== */

/* Selama transisi, kedua sistem berjalan bersama */
.old-card { /* Bootstrap old */ }
.new-card { /* Kustom baru */ }

/* Kelas transisi */
.card {
  /* Gunakan initial di new, fallback ke old */
  background: var(--card-bg, #fff);
  border: var(--card-border, 1px solid rgba(0,0,0,.125));
  border-radius: var(--card-radius, .25rem);
}

/* Feature detection dengan @supports */
@supports (display: grid) {
  .grid-layout {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
    gap: 1.5rem;
  }
}

@supports not (display: grid) {
  .grid-layout {
    display: flex;
    flex-wrap: wrap;
  }
  .grid-layout > * {
    width: calc(33.333% - 1rem);
    margin: 0.5rem;
  }
}
```

## Poin Penting
- Migrasi framework ke kustom atau sebaliknya harus dilakukan bertahap (incremental)
- Strategi side-by-side memungkinkan kedua sistem berjalan bersama selama transisi
- Gunakan CSS custom properties sebagai jembatan antara sistem lama dan baru
- Tools seperti PurgeCSS dan visual regression testing membantu memastikan migrasi aman
