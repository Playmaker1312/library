# Grid System Bootstrap dan Cara Menggunakannya untuk Tata Letak Responsif

## Analogi: Perpustakaan Digital

Grid system Bootstrap seperti sistem rak buku modular yang dapat diatur ulang sesuai kebutuhan. Rak dapat memiliki lebar berbeda untuk menampung buku besar atau kecil, dan dapat ditata ulang saat ruang terbatas (layar kecil). Grid memberikan struktur yang konsisten namun fleksibel untuk menampilkan konten.

## Penjelasan Detail

Grid system Bootstrap menggunakan 12 kolom sebagai dasar yang dapat dikombinasikan untuk membuat lebar elemen yang berbeda. Grid menggunakan container, row, dan column classes. Bootstrap mendefinisikan breakpoint responsif: xs (<576px), sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px), xxl (≥1400px). Column classes menggunakan format col-{breakpoint}-{size}. Grid juga mendukung nesting (grid di dalam grid), offset, alignment, dan reordering. Pendekatan mobile-first berarti gaya dasar untuk layar kecil, lalu ditingkatkan untuk layar lebih besar.

## Contoh Kode Implementasi

```css
/* Container */
.container {
  width: 100%;
  max-width: 1320px;
  margin: 0 auto;
  padding: 0 12px;
}

.container-fluid {
  width: 100%;
  padding: 0 12px;
}

/* Responsive containers */
@media (min-width: 576px) {
  .container { max-width: 540px; }
}
@media (min-width: 768px) {
  .container { max-width: 720px; }
}
@media (min-width: 992px) {
  .container { max-width: 960px; }
}
@media (min-width: 1200px) {
  .container { max-width: 1140px; }
}
@media (min-width: 1400px) {
  .container { max-width: 1320px; }
}

/* Row */
.row {
  display: flex;
  flex-wrap: wrap;
  margin: 0 -12px;
}

[class*="col-"] {
  padding: 0 12px;
  box-sizing: border-box;
}

/* Equal-width columns */
.col {
  flex: 1 0 0%;
}

/* Specific column widths */
.col-1 { flex: 0 0 8.333333%; max-width: 8.333333%; }
.col-2 { flex: 0 0 16.666667%; max-width: 16.666667%; }
.col-3 { flex: 0 0 25%; max-width: 25%; }
.col-4 { flex: 0 0 33.333333%; max-width: 33.333333%; }
.col-5 { flex: 0 0 41.666667%; max-width: 41.666667%; }
.col-6 { flex: 0 0 50%; max-width: 50%; }
.col-7 { flex: 0 0 58.333333%; max-width: 58.333333%; }
.col-8 { flex: 0 0 66.666667%; max-width: 66.666667%; }
.col-9 { flex: 0 0 75%; max-width: 75%; }
.col-10 { flex: 0 0 83.333333%; max-width: 83.333333%; }
.col-12 { flex: 0 0 100%; max-width: 100%; }

/* Responsive breakpoint classes */
/* Small (≥576px) */
@media (min-width: 576px) {
  .col-sm-6 { flex: 0 0 50%; max-width: 50%; }
  .col-sm-12 { flex: 0 0 100%; max-width: 100%; }
}

/* Medium (≥768px) */
@media (min-width: 768px) {
  .col-md-3 { flex: 0 0 25%; max-width: 25%; }
  .col-md-4 { flex: 0 0 33.333333%; max-width: 33.333333%; }
  .col-md-6 { flex: 0 0 50%; max-width: 50%; }
  .col-md-8 { flex: 0 0 66.666667%; max-width: 66.666667%; }
}

/* Large (≥992px) */
@media (min-width: 992px) {
  .col-lg-2 { flex: 0 0 16.666667%; max-width: 16.666667%; }
  .col-lg-3 { flex: 0 0 25%; max-width: 25%; }
  .col-lg-4 { flex: 0 0 33.333333%; max-width: 33.333333%; }
  .col-lg-6 { flex: 0 0 50%; max-width: 50%; }
}

/* Extra Large (≥1200px) */
@media (min-width: 1200px) {
  .col-xl-2 { flex: 0 0 16.666667%; max-width: 16.666667%; }
  .col-xl-3 { flex: 0 0 25%; max-width: 25%; }
  .col-xl-4 { flex: 0 0 33.333333%; max-width: 33.333333%; }
}

/* Grid dengan nested row */
.row .row {
  margin: 0 -12px;
}

/* Offset */
.offset-1 { margin-left: 8.333333%; }
.offset-2 { margin-left: 16.666667%; }
.offset-3 { margin-left: 25%; }
.offset-4 { margin-left: 33.333333%; }

/* Alignment */
.align-items-start { align-items: flex-start; }
.align-items-center { align-items: center; }
.align-items-end { align-items: flex-end; }
.justify-content-center { justify-content: center; }
.justify-content-between { justify-content: space-between; }

/* Grid gap utilities */
.g-0 { gap: 0; }
.g-1 { gap: 0.25rem; }
.g-2 { gap: 0.5rem; }
.g-3 { gap: 1rem; }
.g-4 { gap: 1.5rem; }
.g-5 { gap: 3rem; }
```

## Poin Penting
- Grid Bootstrap berbasis 12 kolom dengan container, row, dan column classes
- Breakpoint responsif: xs, sm, md, lg, xl, xxl dengan pendekatan mobile-first
- Column classes: col-{breakpoint}-{size} untuk kontrol responsif yang presisi
- Grid mendukung offset, alignment, nesting, ordering, dan gap utilities
