# Properti text-align untuk mengatur perataan teks kiri, kanan, tengah, dan justify

## Analogi: Perpustakaan Digital

Properti `text-align` seperti mengatur posisi buku di rak perpustakaan digital. Apakah buku-buku rata kiri (seperti kebanyakan rak), rata tengah (untuk display khusus), rata kanan (untuk bahasa yang dibaca kanan-ke-kiri), atau rata kanan-kiri (seperti buku cetak yang rapi di kedua sisi). Setiap metode perataan memberikan tampilan yang berbeda.

## Penjelasan Detail

`text-align` mengatur perataan horizontal teks dalam elemen blok. Nilai: `left` (rata kiri — default untuk bahasa LTR), `right` (rata kanan), `center` (rata tengah), `justify` (rata kanan-kiri dengan spasi antar kata diatur). `justify` memberikan tampilan rapi di kedua sisi, tetapi bisa menyebabkan spasi yang tidak merata pada teks dengan lebar baris sempit. Properti ini juga mempengaruhi elemen inline anak. `text-align: center` sering digunakan untuk judul, `justify` untuk artikel panjang, `left` untuk paragraf biasa.

## Contoh Kode Implementasi

```css
/* text-align values */
.left {
  text-align: left; /* rata kiri — default */
}

.right {
  text-align: right; /* rata kanan */
}

.center {
  text-align: center; /* rata tengah */
}

.justify {
  text-align: justify; /* rata kanan-kiri */
}

/* Penggunaan umum */
body {
  text-align: left;
}

h1, h2, h3 {
  text-align: center;
}

.article-body {
  text-align: justify;
  hyphens: auto; /* tambah tanda hubung untuk justify lebih rapi */
}

.footer-text {
  text-align: center;
  color: #666;
}

.navbar {
  text-align: right;
}

.caption {
  text-align: center;
  font-style: italic;
  font-size: 0.9rem;
}

/* Untuk elemen dengan arah teks berbeda */
.rtl-text {
  text-align: right;
  direction: rtl;
}
```

## Poin Penting
- `left`: rata kiri, `right`: rata kanan, `center`: rata tengah, `justify`: rata kanan-kiri
- Default untuk bahasa LTR (Indonesia/Inggris) adalah `left`
- `justify` bisa menyebabkan spasi tidak merata pada baris pendek
