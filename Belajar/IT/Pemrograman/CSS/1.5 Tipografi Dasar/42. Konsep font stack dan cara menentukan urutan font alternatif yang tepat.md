# Konsep font stack dan cara menentukan urutan font alternatif yang tepat

## Analogi: Perpustakaan Digital

Font stack seperti daftar prioritas pustakawan yang bisa membaca buku: "Coba panggil Budi dulu, jika Budi tidak ada panggil Siti, jika Siti tidak ada panggil Andi, terakhir minta bantuan siapa saja yang bisa membaca." Browser akan mencoba font pertama; jika font tersebut tidak tersedia di sistem pengguna, beralih ke font berikutnya dalam daftar.

## Penjelasan Detail

Font stack adalah daftar font yang dipisahkan koma, diurutkan berdasarkan prioritas. Browser mencoba font pertama; jika tidak terinstall, lanjut ke font kedua, dan seterusnya. Urutan harus logis: font spesifik dan modern di awal, font umum di tengah, dan generic family (serif, sans-serif, monospace) di akhir sebagai fallback terakhir. Pertimbangkan sistem operasi: font yang tersedia di Windows mungkin berbeda dengan macOS atau Linux. Font stack yang baik memastikan teks tetap terbaca di semua perangkat.

## Contoh Kode Implementasi

```css
/* Font stack yang baik — urutan prioritas */
body {
  /* Font modern untuk OS modern, fallback ke font umum */
  font-family: 
    -apple-system,           /* macOS */
    BlinkMacSystemFont,      /* macOS Chrome */
    'Segoe UI',              /* Windows */
    Roboto,                  /* Android */
    Oxygen-Sans,             /* Linux KDE */
    Ubuntu,                  /* Linux Ubuntu */
    Cantarell,               /* Linux GNOME */
    'Helvetica Neue',        /* macOS fallback */
    Arial,                   /* Windows fallback */
    sans-serif;              /* Fallback generic */
}

/* Heading dengan font stack serif */
h1, h2, h3 {
  font-family: Georgia, 'Times New Roman', Times, serif;
}

/* Code dengan font stack monospace */
code, pre {
  font-family: 'Fira Code', 'Cascadia Code', 'JetBrains Mono',
               'Source Code Pro', 'Consolas', 'Courier New', monospace;
}
```

## Poin Penting
- Font stack adalah daftar font prioritas yang dipisah koma
- Browser mencoba font pertama, lalu fallback ke berikutnya
- Akhiri dengan generic family (serif, sans-serif, monospace)
- Pertimbangkan ketersediaan font di berbagai sistem operasi
