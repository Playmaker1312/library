# Properti text-transform untuk mengubah kapitalisasi teks secara otomatis

## Analogi: Perpustakaan Digital

Properti `text-transform` seperti sistem katalog otomatis di perpustakaan digital yang mengubah format teks label secara konsisten. Judul buku bisa otomatis dikapitalisasi, label rak bisa dibuat huruf besar semua, atau catatan kecil dibuat huruf kecil semua. Ini memastikan konsistensi tanpa harus mengubah teks asli di HTML.

## Penjelasan Detail

`text-transform` mengubah kapitalisasi teks tanpa mengubah konten HTML asli. Nilai: `uppercase` (SEMUA HURUF BESAR), `lowercase` (semua huruf kecil), `capitalize` (Huruf Pertama Setiap Kata Kapital), dan `none` (default — tidak ada perubahan). `capitalize` hanya mengubah huruf pertama setiap kata, bukan setiap kata menjadi Title Case sempurna (misalnya kata seperti "dan" atau "di" juga dikapitalisasi). Properti ini berguna untuk konsistensi tipografi — judul, tombol, label — dan menghemat waktu dibanding mengubah teks manual di HTML.

## Contoh Kode Implementasi

```css
/* text-transform values */
.all-caps {
  text-transform: uppercase; /* SEMUA HURUF BESAR */
}

.all-lower {
  text-transform: lowercase; /* semua huruf kecil */
}

.capitalize {
  text-transform: capitalize; /* Setiap Kata Diawali Huruf Besar */
}

.none {
  text-transform: none; /* sesuai teks asli */
}

/* Penggunaan umum */
.nav-link {
  text-transform: uppercase;
  letter-spacing: 1px;
  font-size: 0.85rem;
  font-weight: 600;
}

.button {
  text-transform: uppercase;
  font-weight: bold;
}

.section-title {
  text-transform: capitalize;
}

.form-label {
  text-transform: uppercase;
  font-size: 0.8rem;
  color: #666;
}

/* Untuk konten dinamis yang perlu konsistensi */
.user-name {
  text-transform: capitalize; /* pastikan nama selalu capital */
}
```

## Poin Penting
- `uppercase`, `lowercase`, `capitalize`, `none`
- Mengubah tampilan tanpa mengubah HTML asli
- Berguna untuk konsistensi judul, tombol, dan label navigasi
- `capitalize` mengubah huruf pertama setiap kata tanpa pengecualian
