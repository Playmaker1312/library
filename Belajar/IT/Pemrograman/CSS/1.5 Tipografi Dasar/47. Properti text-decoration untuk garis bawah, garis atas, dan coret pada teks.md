# Properti text-decoration untuk garis bawah, garis atas, dan coret pada teks

## Analogi: Perpustakaan Digital

Properti `text-decoration` seperti memberikan tanda pada buku di perpustakaan digital. Garis bawah untuk menandai judul penting, garis coret untuk buku yang sudah tidak tersedia, dan garis atas untuk anotasi khusus. Setiap tanda memberikan informasi visual tambahan tentang teks tersebut.

## Penjelasan Detail

`text-decoration` adalah shorthand yang menggabungkan `text-decoration-line`, `text-decoration-color`, `text-decoration-style`, dan `text-decoration-thickness`. `text-decoration-line` menentukan jenis garis: `underline` (garis bawah), `overline` (garis atas), `line-through` (coret), atau kombinasi. `text-decoration-style`: `solid`, `double`, `dotted`, `dashed`, `wavy`. Properti ini sering digunakan untuk link (underline default), menunjukkan teks yang dihapus (line-through), atau dekorasi khusus. Shortcut `text-decoration: underline wavy red 2px` memungkinkan dekorasi yang kaya.

## Contoh Kode Implementasi

```css
/* text-decoration dasar */
.underline {
  text-decoration: underline;
}

.overline {
  text-decoration: overline;
}

.strikethrough {
  text-decoration: line-through;
}

/* Kombinasi */
.combo {
  text-decoration: underline overline line-through;
}

/* Dengan gaya dan warna */
.wavy-underline {
  text-decoration: underline wavy #3498db;
}

.double-overline {
  text-decoration: overline double #e74c3c;
}

.dashed-strike {
  text-decoration: line-through dashed #999;
}

/* Shorthand lengkap */
.fancy {
  text-decoration: underline wavy #e74c3c 2px;
}

/* Untuk link */
a {
  text-decoration: none; /* hilangkan underline default */
}

a:hover {
  text-decoration: underline;
}

/* Styling untuk konten yang dihapus */
del {
  text-decoration: line-through;
  color: #999;
}
```

## Poin Penting
- `underline`: garis bawah, `overline`: garis atas, `line-through`: coret tengah
- Bisa dikombinasikan dengan warna, gaya (solid, wavy, dotted), dan ketebalan
- Link memiliki `text-decoration: underline` secara default
