# Generic font families seperti serif, sans-serif, monospace, cursive, dan fantasy

## Analogi: Perpustakaan Digital

Generic font families seperti kategori umum buku di perpustakaan digital — "Fiksi", "Non-Fiksi", "Referensi". Anda tidak tahu judul spesifiknya, tapi Anda tahu karakteristik umumnya. Serif seperti buku klasik dengan hiasan, sans-serif seperti buku modern yang bersih, monospace seperti buku kode pemrograman, cursive seperti buku tulisan tangan, dan fantasy seperti buku ilustrasi dekoratif.

## Penjelasan Detail

CSS mendefinisikan lima generic font families: `serif` (dengan kait dekoratif di ujung huruf — Times New Roman, Georgia), `sans-serif` (tanpa kait, bersih — Arial, Helvetica), `monospace` (setiap huruf lebar sama — Courier New, Consolas), `cursive` (meniru tulisan tangan — Comic Sans, Brush Script), dan `fantasy` (dekoratif, artistik — Impact, Papyrus). Setiap browser dan sistem operasi memiliki font default untuk setiap generic family. Generic family harus menjadi fallback terakhir dalam font stack.

## Contoh Kode Implementasi

```css
/* Generic font families */
.serif-text {
  font-family: serif;
  /* Browser akan memilih font serif default */
}

.sans-serif-text {
  font-family: sans-serif;
  /* Browser akan memilih font sans-serif default */
}

.monospace-text {
  font-family: monospace;
  /* Browser akan memilih font monospace default */
}

.cursive-text {
  font-family: cursive;
  /* Browser akan memilih font cursive default */
}

.fantasy-text {
  font-family: fantasy;
  /* Browser akan memilih font fantasy default */
}

/* Contoh penggunaan dengan font stack */
.article {
  font-family: Georgia, 'Times New Roman', serif;
}

.navigation {
  font-family: 'Helvetica Neue', Arial, sans-serif;
}

.code-block {
  font-family: 'Fira Code', 'Courier New', monospace;
}

.caption {
  font-family: 'Brush Script MT', cursive;
}
```

## Poin Penting
- Lima generic families: serif, sans-serif, monospace, cursive, fantasy
- Setiap OS/browser memiliki font default untuk masing-masing kategori
- Generic family digunakan sebagai fallback terakhir dalam font stack
