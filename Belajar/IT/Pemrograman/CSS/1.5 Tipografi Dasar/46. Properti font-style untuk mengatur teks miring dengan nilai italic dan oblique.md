# Properti font-style untuk mengatur teks miring dengan nilai italic dan oblique

## Analogi: Perpustakaan Digital

Properti `font-style` seperti memiringkan buku di rak perpustakaan digital untuk menunjukkan bahwa buku tersebut memiliki penekanan khusus — mungkin catatan penting, kata serapan asing, atau judul karya. Teks miring memberikan nuansa berbeda yang menarik perhatian tanpa harus berteriak seperti huruf tebal.

## Penjelasan Detail

`font-style` memiliki tiga nilai: `normal` (tegak/default), `italic` (huruf miring dengan gaya kursif khusus), dan `oblique` (huruf yang dimiringkan secara mekanis dari versi normal). Perbedaan `italic` dan `oblique`: italic adalah gaya font terpisah yang dirancang khusus dengan bentuk huruf berbeda, sedangkan oblique hanya memiringkan versi normal. Banyak font modern tidak memiliki perbedaan signifikan antara keduanya. Jika font tidak memiliki varian italic, browser akan mensimulasikan dengan oblique. Properti ini penting untuk penekanan dalam teks.

## Contoh Kode Implementasi

```css
/* font-style values */
.normal-text {
  font-style: normal; /* default — teks tegak */
}

.italic-text {
  font-style: italic; /* huruf miring */
}

.oblique-text {
  font-style: oblique; /* versi miring mekanis */
}

.oblique-angled {
  font-style: oblique 15deg; /* miring dengan sudut tertentu */
}

/* Penggunaan umum */
blockquote {
  font-style: italic;
  color: #555;
  border-left: 3px solid #ccc;
  padding-left: 20px;
}

.foreign-word {
  font-style: italic; /* untuk kata serapan */
}

.book-title {
  font-style: italic; /* untuk judul buku/karya */
}

.citation {
  font-style: italic;
  font-size: 0.9em;
}

/* Reset italic */
.no-italic {
  font-style: normal;
}
```

## Poin Penting
- `normal`: teks tegak, `italic`: huruf miring bergaya kursif, `oblique`: miring mekanis
- Italic menggunakan varian font khusus, oblique memiringkan versi normal
- Digunakan untuk penekanan, judul karya, dan kata asing
