# Properti font-weight untuk mengatur ketebalan teks dari 100 hingga 900

## Analogi: Perpustakaan Digital

Properti `font-weight` seperti ketebalan spidol yang digunakan untuk menulis label di perpustakaan digital. Spidol tipis (100-300) untuk catatan kecil, spidol sedang (400-500) untuk label standar, spidol tebal (600-700) untuk judul rak, dan spidol sangat tebal (800-900) untuk papan nama perpustakaan. Semakin tebal semakin menonjol.

## Penjelasan Detail

`font-weight` mengatur ketebalan atau berat visual huruf. Nilai numerik dari 100 hingga 900, kelipatan 100. Nilai umum: 100 (Thin), 200 (Extra Light), 300 (Light), 400 (Normal/Regular), 500 (Medium), 600 (Semi Bold), 700 (Bold), 800 (Extra Bold), 900 (Black/Heavy). Nilai keyword juga tersedia: `normal` (400) dan `bold` (700). Tidak semua font memiliki semua varian weight; jika weight tertentu tidak tersedia, browser akan memilih yang terdekat. `font-weight` mempengaruhi hierarki visual dan keterbacaan.

## Contoh Kode Implementasi

```css
/* font-weight dengan nilai numerik */
.thin {
  font-weight: 100;
}

.light {
  font-weight: 300;
}

.normal {
  font-weight: 400; /* default */
}

.medium {
  font-weight: 500;
}

.semi-bold {
  font-weight: 600;
}

.bold {
  font-weight: 700;
}

.extra-bold {
  font-weight: 800;
}

.black {
  font-weight: 900;
}

/* Keyword values */
.keyword-normal {
  font-weight: normal; /* 400 */
}

.keyword-bold {
  font-weight: bold; /* 700 */
}

/* Penggunaan dalam tipografi hierarki */
h1 { font-weight: 700; }
h2 { font-weight: 600; }
h3 { font-weight: 500; }
p  { font-weight: 400; }
small { font-weight: 300; }
```

## Poin Penting
- Nilai numerik 100-900, kelipatan 100
- `normal` = 400, `bold` = 700
- Tidak semua font menyediakan semua varian weight
- Weight mempengaruhi hierarki visual dan penekanan teks
