# Properti font-family untuk menentukan jenis huruf yang digunakan pada teks

## Analogi: Perpustakaan Digital

Properti `font-family` seperti memilih jenis huruf yang digunakan di rak buku perpustakaan digital. Apakah Anda ingin judul buku tercetak dalam huruf Times New Roman yang klasik, Arial yang modern, atau Comic Sans yang santai? Pemilihan jenis huruf mempengaruhi suasana dan keterbacaan seluruh perpustakaan.

## Penjelasan Detail

`font-family` menentukan jenis huruf (typeface) yang digunakan untuk teks elemen. Nilai bisa berupa nama font spesifik (seperti `Arial`, `Georgia`, `Times New Roman`) atau generic family (seperti `serif`, `sans-serif`, `monospace`). Nama font dengan spasi harus diapit tanda kutip. Properti ini menerima fallback stack — daftar font yang dipisah koma. Browser akan mencoba font pertama; jika tidak tersedia, beralih ke font berikutnya. Selalu akhiri stack dengan generic family sebagai fallback terakhir.

## Contoh Kode Implementasi

```css
/* font-family dengan font stack */
body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
}

.heading {
  font-family: Georgia, 'Times New Roman', Times, serif;
}

.code {
  font-family: 'Courier New', Courier, monospace;
}

.quote {
  font-family: 'Georgia', 'Palatino Linotype', 'Book Antiqua', Palatino, serif;
}

/* Font dengan spasa dalam nama */
.brand {
  font-family: 'Fira Sans', 'Helvetica Neue', Arial, sans-serif;
}

/* Generic family saja */
.monospace-text {
  font-family: monospace;
}
```

## Poin Penting
- `font-family` menentukan jenis huruf untuk teks elemen
- Gunakan font stack dengan fallback untuk kompatibilitas
- Nama font dengan spasi harus diapit tanda kutip
- Akhiri stack dengan generic family (serif, sans-serif, monospace)
