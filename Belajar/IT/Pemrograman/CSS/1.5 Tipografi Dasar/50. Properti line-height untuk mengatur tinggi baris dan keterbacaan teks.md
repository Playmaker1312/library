# Properti line-height untuk mengatur tinggi baris dan keterbacaan teks

## Analogi: Perpustakaan Digital

Properti `line-height` seperti mengatur jarak antar baris buku di rak perpustakaan digital. Jika baris terlalu rapat, teks sulit dibaca seperti buku yang ditumpuk. Jika terlalu renggang, halaman terlihat kosong dan tidak efisien. Jarak yang ideal membuat mata pembaca mudah mengikuti baris tanpa tersesat ke baris berikutnya.

## Penjelasan Detail

`line-height` mengatur tinggi minimum setiap baris teks, diukur dari baseline ke baseline. Nilai bisa berupa: angka (tanpa satuan — dikalikan dengan font-size, rekomendasi terbaik), `em` (relatif terhadap font-size), `px` (absolut), `%` (persentase dari font-size), atau keyword `normal` (biasanya 1.2). Nilai tanpa satuan adalah praktik terbaik karena dihitung relatif terhadap font-size dan diwariskan dengan benar ke elemen anak. Untuk teks paragraf, `line-height: 1.5-1.8` umumnya dianggap paling terbaca. Untuk heading, `line-height: 1.1-1.3` lebih cocok.

## Contoh Kode Implementasi

```css
/* line-height — praktik terbaik dengan nilai tanpa satuan */
body {
  font-size: 16px;
  line-height: 1.6; /* 1.6 x 16px = 25.6px — nilai tanpa satuan */
}

/* Untuk paragraf — jarak longgar untuk keterbacaan */
p {
  line-height: 1.7;
  margin-bottom: 1.5em;
}

/* Untuk heading — jarak lebih rapat */
h1, h2, h3 {
  line-height: 1.2;
  margin-bottom: 0.5em;
}

/* Teks kecil perlu line-height lebih besar */
small, .caption {
  font-size: 0.8rem;
  line-height: 1.8;
}

/* Komponen dengan ukuran tetap — gunakan px */
.button {
  line-height: 40px; /* membantu vertical centering */
  padding: 0 20px;
}

/* line-height dengan em */
.article {
  font-size: 1.125rem;
  line-height: 1.75em; /* 1.75 x 1.125rem */
}

/* Nilai normal */
.normal-line-height {
  line-height: normal; /* sekitar 1.2 tergantung font */
}
```

## Poin Penting
- Gunakan nilai tanpa satuan (misal `1.6`) untuk warisan yang tepat
- Paragraf: `1.5-1.8` untuk keterbacaan optimal
- Heading: `1.1-1.3` untuk tampilan yang proporsional
- `line-height` mempengaruhi aksesibilitas dan kenyamanan membaca
