# Properti font-size untuk mengatur ukuran teks dengan berbagai satuan

## Analogi: Perpustakaan Digital

Properti `font-size` seperti mengatur ukuran huruf di papan petunjuk perpustakaan digital. Judul utama harus besar agar terlihat dari jauh, teks deskripsi sedang agar nyaman dibaca, dan catatan kaki kecil agar tidak mengganggu. Ukuran yang tepat membuat perpustakaan mudah dinavigasi.

## Penjelasan Detail

`font-size` menentukan ukuran teks. Satuan yang umum digunakan: `px` (piksel — ukuran absolut tetap), `em` (relatif terhadap font-size elemen induk), `rem` (relatif terhadap font-size root/html), `%` (persentase dari font-size induk), dan viewport units `vw`/`vh` (relatif terhadap lebar/tinggi viewport). Untuk aksesibilitas dan responsivitas, `rem` adalah pilihan terbaik karena menghormati pengaturan ukuran font browser pengguna. Satuan viewport berguna untuk tipografi responsif yang skalanya berubah sesuai layar.

## Contoh Kode Implementasi

```css
/* Ukuran tetap absolut */
html {
  font-size: 16px; /* ukuran dasar root */
}

/* font-size dengan berbagai satuan */
h1 {
  font-size: 2.5rem;  /* 40px — relatif terhadap root */
}

h2 {
  font-size: 2rem;    /* 32px */
}

h3 {
  font-size: 1.5rem;  /* 24px */
}

p {
  font-size: 1rem;    /* 16px — ukuran default */
}

.small-text {
  font-size: 0.875rem; /* 14px */
}

.caption {
  font-size: 0.75rem;  /* 12px */
}

/* Ukuran responsif dengan viewport units */
.responsive-heading {
  font-size: calc(1.5rem + 2vw); /* antara 24px + skala viewport */
}

/* Ukuran em — kontekstual */
.card {
  font-size: 14px;
}
.card .title {
  font-size: 1.5em;  /* 21px — 1.5 x 14px */
}
```

## Poin Penting
- `px`: absolut dan tetap, tidak responsif terhadap preferensi pengguna
- `rem`: relatif terhadap root, aksesibel dan konsisten
- `em`: relatif terhadap induk, berguna untuk komponen yang skalabel
- `vw/vh`: responsif terhadap ukuran viewport
