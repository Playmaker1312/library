# Metodologi SMACSS

## Analogi: Perpustakaan Digital

Perpustakaan digital mengkategorikan buku-bukunya ke dalam bagian yang terorganisir: Fiksi, Non-Fiksi, Referensi, dan Periodikal. Setiap bagian memiliki aturan penempatan dan penanganan sendiri. Kategorisasi ini memudahkan pustakawan menemukan dan mengelola buku. SMACSS menerapkan kategorisasi serupa untuk aturan CSS, membaginya ke dalam kategori fungsional yang memudahkan organisasi dan pemeliharaan.

## Penjelasan Detail

SMACSS (Scalable and Modular Architecture for CSS) adalah metodologi oleh Jonathan Snook yang mengkategorikan aturan CSS ke dalam lima tipe: Base (gaya dasar elemen HTML seperti reset dan tipografi), Layout (gaya untuk elemen struktural besar seperti header, footer, sidebar), Module (komponen reusable seperti card, button, navigasi), State (gaya untuk keadaan tertentu seperti active, disabled, hidden), dan Theme (gaya untuk variasi tampilan/tema). Setiap kategori memiliki aturan penamaan dan organisasi sendiri. SMACSS juga memberikan pedoman tentang profunditas selector (hindari selector dalam, maksimal 3-4 level). Pendekatan ini membantu tim mengelola CSS dalam proyek besar dengan memisahkan tanggung jawab dan membuat kode lebih mudah diprediksi.

## Contoh Kode Implementasi

```css
/* ===== BASE ===== */
body {
  font-family: system-ui, sans-serif;
  line-height: 1.6;
  color: #333;
}

a {
  color: #3498db;
  text-decoration: none;
}

/* ===== LAYOUT ===== */
.l-header {
  position: fixed;
  top: 0;
  width: 100%;
  z-index: 100;
}

.l-sidebar {
  width: 280px;
  float: left;
}

.l-main {
  margin-left: 280px;
}

.l-footer {
  clear: both;
  padding: 2rem;
  text-align: center;
}

/* ===== MODULE ===== */
.card {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 1rem;
}

.card > .card-title {
  font-size: 1.25rem;
  margin-bottom: 0.5rem;
}

/* ===== STATE ===== */
.is-hidden {
  display: none !important;
}

.is-active {
  background-color: #3498db;
  color: white;
}

.is-disabled {
  opacity: 0.5;
  pointer-events: none;
}

/* ===== THEME ===== */
.theme-dark {
  --warna-latar: #222;
  --warna-teks: #eee;
}

.theme-colorful {
  --warna-primer: #e74c3c;
  --warna-sekunder: #f1c40f;
}
```

## Poin Penting
- Lima kategori SMACSS: Base, Layout, Module, State, Theme.
- Base: gaya dasar elemen HTML (reset, font dasar, warna tautan).
- Layout: elemen struktural besar dengan prefiks `l-`.
- Module: komponen reusable, harus independen dan tidak bergantung konteks.
- State: keadaan elemen dengan prefiks `is-` (is-active, is-hidden).
- Theme: variasi tampilan menggunakan CSS Custom Properties.
