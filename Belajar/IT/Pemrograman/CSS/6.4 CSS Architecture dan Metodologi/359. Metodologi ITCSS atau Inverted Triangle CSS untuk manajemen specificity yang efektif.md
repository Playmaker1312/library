# Metodologi ITCSS (Inverted Triangle CSS)

## Analogi: Perpustakaan Digital

Perpustakaan digital menyusun buku dari konsep paling umum ke paling spesifik. Di lantai dasar, ada buku tentang "Pengetahuan Umum" yang mencakup banyak topik. Semakin naik ke lantai atas, buku semakin spesifik—misalnya "Sejarah Perpustakaan Digital di Asia Tenggara Abad 21". Urutan ini memudahkan navigasi. ITCSS menerapkan prinsip yang sama pada CSS: dari aturan paling umum (spesifisitas rendah) ke aturan paling spesifik (spesifisitas tinggi).

## Penjelasan Detail

ITCSS (Inverted Triangle CSS) adalah metodologi oleh Harry Roberts yang mengatur proyek CSS berdasarkan tingkat spesifisitas dan lingkup. Struktur ITCSS berbentuk segitiga terbalik: bagian atas (lebar) berisi aturan paling umum dengan spesifisitas rendah—reset, elemen dasar. Semakin ke bawah, aturan semakin spesifik dengan spesifisitas lebih tinggi—komponen, utilitas. Lapisan ITCSS meliputi: Settings (variabel, konfigurasi), Tools (mixin, fungsi), Generic (reset, normalize), Elements (gaya elemen HTML dasar), Objects (pola layout reusable), Components (komponen UI spesifik), dan Utilities (helper dengan !important). Pendekatan ini mengelola spesifisitas secara progresif, mengurangi konflik, dan membuat CSS lebih mudah diprediksi dan dipelihara.

## Contoh Kode Implementasi

```css
/* 1. SETTINGS — variabel dan konfigurasi */
$warna-primer: #3498db;
$spasi-base: 16px;

/* 2. TOOLS — mixin dan fungsi */
@mixin respond($breakpoint) {
  @media (min-width: $breakpoint) { @content; }
}

/* 3. GENERIC — reset dan normalize */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

/* 4. ELEMENTS — gaya elemen HTML tanpa kelas */
body {
  font-family: system-ui, sans-serif;
  color: #333;
  line-height: 1.6;
}

h1, h2, h3 { margin-bottom: 0.5em; }

a { color: $warna-primer; }

/* 5. OBJECTS — pola layout reusable */
.o-container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 1rem;
}

.o-grid {
  display: grid;
  gap: 1rem;
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
}

/* 6. COMPONENTS — komponen UI spesifik */
.card {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 1rem;
}

.card__title {
  font-size: 1.25rem;
  font-weight: 600;
}

/* 7. UTILITIES — helper dengan !important */
.u-hidden { display: none !important; }
.u-mt-4 { margin-top: 1rem !important; }
.u-text-center { text-align: center !important; }
```

## Poin Penting
- ITCSS mengatur CSS dari umum ke spesifik, dari spesifisitas rendah ke tinggi.
- Tujuh lapisan: Settings, Tools, Generic, Elements, Objects, Components, Utilities.
- Lapisan atas (Settings, Tools) — paling umum, tanpa output CSS langsung.
- Lapisan bawah (Utilities) — paling spesifik, menggunakan !important.
- Mengurangi konflik spesifisitas dan membuat CSS lebih mudah diprediksi.
