# CSS Modules untuk Enkapsulasi Gaya

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki sistem penomoran buku yang unik secara global—setiap buku memiliki ISBN yang tidak mungkin sama dengan buku lain di mana pun di dunia. Ini memastikan tidak ada kebingungan antara buku yang sama dari cabang berbeda. CSS Modules melakukan hal yang sama untuk kelas CSS—secara otomatis menghasilkan nama kelas yang unik sehingga gaya komponen tidak bocor atau bertabrakan dengan komponen lain.

## Penjelasan Detail

CSS Modules adalah pendekatan di mana file CSS dianggap sebagai modul dengan cakupan lokal secara default. Setiap nama kelas yang ditulis dalam file CSS akan diubah menjadi nama unik (biasanya dengan hash) saat proses build, mencegah konflik antar komponen. Kelas diimpor ke dalam komponen JavaScript dan digunakan sebagai properti objek, bukan string literal. Ini memberikan enkapsulasi gaya yang kuat tanpa perlu metodologi penamaan seperti BEM. CSS Modules bekerja dengan bundler seperti webpack, Vite, atau Parcel. Fitur tambahan: komposisi kelas dengan `composes`, nilai variabel lokal, dan integrasi dengan preprocessor. Pendekatan ini sangat populer dalam ekosistem React, Vue, dan framework komponen modern lainnya.

## Contoh Kode Implementasi

```css
/* Card.module.css — cakupan lokal secara default */
.card {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 1rem;
  background: white;
}

.title {
  font-size: 1.25rem;
  color: #333;
  margin-bottom: 0.5rem;
}

.button {
  background: #3498db;
  color: white;
  padding: 0.5rem 1rem;
  border: none;
  border-radius: 4px;
}

.button:hover {
  background: #2980b9;
}

/* Komposisi kelas */
.featured {
  composes: card;
  border-color: #f1c40f;
  box-shadow: 0 4px 12px rgba(241,196,15,0.3);
}
```

```javascript
// React component menggunakan CSS Modules
import styles from './Card.module.css';

function Card({ title, children, featured }) {
  return (
    <div className={featured ? styles.featured : styles.card}>
      <h2 className={styles.title}>{title}</h2>
      <div>{children}</div>
      <button className={styles.button}>Klik</button>
    </div>
  );
}

// Hasil: kelas akan menjadi unik seperti "Card_card_abc123"
// Tidak ada konflik dengan komponen lain yang memiliki kelas "title"
```

## Poin Penting
- CSS Modules menghasilkan nama kelas unik secara otomatis, mencegah konflik global.
- Kelas diimpor sebagai properti objek JavaScript, bukan string literal.
- Memberikan enkapsulasi gaya yang kuat tanpa metodologi penamaan manual.
- Mendukung komposisi kelas dengan kata kunci `composes`.
- Integrasi dengan bundler modern (webpack, Vite, Parcel) untuk build time.
