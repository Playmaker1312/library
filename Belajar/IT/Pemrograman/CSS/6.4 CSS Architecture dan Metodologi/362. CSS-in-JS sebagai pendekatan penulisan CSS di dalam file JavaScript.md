# CSS-in-JS untuk Styling dalam JavaScript

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital di mana setiap buku memiliki instruksi perawatan yang ditempel langsung di sampulnya, bukan di buku panduan terpisah. Petugas bisa langsung merawat buku tanpa mencari buku panduan. CSS-in-JS melakukan hal yang sama—gaya ditulis langsung di dalam komponen JavaScript, bukan di file CSS terpisah. Ini membuat gaya dan logika komponen berada dalam satu konteks.

## Penjelasan Detail

CSS-in-JS adalah pendekatan di mana gaya CSS ditulis menggunakan JavaScript, biasanya sebagai template literal atau objek gaya, dan disuntikkan ke dalam DOM saat runtime atau dikompilasi saat build. Library populer: styled-components, Emotion, JSS, Aphrodite, dan CSS Modules (yang juga dianggap sebagai turunan CSS-in-JS). Keuntungan: gaya memiliki cakupan komponen secara otomatis, akses ke props dan state JavaScript untuk gaya dinamis, eliminasi gaya tidak terpakai, dan tidak ada konflik nama kelas. Kerugian: runtime overhead, ukuran bundle JavaScript lebih besar, dan beberapa pengembang lebih suka pemisahan concern (HTML, CSS, JavaScript terpisah). CSS-in-JS sangat populer di ekosistem React dan framework komponen modern.

## Contoh Kode Implementasi

```javascript
// styled-components (React)
import styled from 'styled-components';

const Button = styled.button`
  background: ${props => props.primary ? '#3498db' : '#95a5a6'};
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
  font-size: 1rem;
  cursor: pointer;
  
  &:hover {
    background: ${props => props.primary ? '#2980b9' : '#7f8c8d'};
  }
  
  ${props => props.large && css`
    padding: 15px 30px;
    font-size: 1.25rem;
  `}
`;

// Menggunakan komponen
function App() {
  return (
    <div>
      <Button primary>Tombol Utama</Button>
      <Button>Tombol Sekunder</Button>
      <Button large primary>Tombol Besar</Button>
    </div>
  );
}
```

```javascript
// Emotion — CSS prop
/** @jsxImportSource @emotion/react */
import { css } from '@emotion/react';

const cardStyle = css`
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 1rem;
  background: white;
  
  h2 {
    font-size: 1.25rem;
    color: #333;
  }
`;

function Card({ title, children }) {
  return (
    <div css={cardStyle}>
      <h2>{title}</h2>
      {children}
    </div>
  );
}
```

## Poin Penting
- CSS-in-JS menulis gaya dalam file JavaScript, terintegrasi dengan logika komponen.
- Akses ke props dan state memungkinkan gaya dinamis berbasis data.
- Cakupan otomatis (scoped styles) tanpa konflik nama kelas.
- Library populer: styled-components, Emotion, JSS.
- Trade-off: runtime overhead vs kenyamanan development dan kemampuan dinamis.
