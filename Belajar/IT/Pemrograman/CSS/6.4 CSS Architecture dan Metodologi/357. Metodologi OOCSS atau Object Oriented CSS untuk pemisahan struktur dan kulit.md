# Metodologi OOCSS (Object Oriented CSS)

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki konsep "template rak" yang bisa digunakan kembali. Ada template untuk rak buku besar, rak buku kecil, dan rak buku display. Struktur rak (ukuran, jumlah rak) dipisahkan dari tampilannya (warna, bahan). Dengan cara ini, rak buku besar bisa diwarnai biru atau hijau tanpa perlu mendesain ulang strukturnya. OOCSS menerapkan prinsip yang sama—memisahkan struktur dari visual.

## Penjelasan Detail

OOCSS (Object Oriented CSS) adalah metodologi yang dikembangkan oleh Nicole Sullivan dengan dua prinsip utama: (1) pisahkan struktur dari kulit (separate structure from skin), dan (2) pisahkan konten dari container (separate content from container). Prinsip pertama berarti properti struktural (layout, spacing, ukuran) dipisahkan dari properti visual (warna, background, border, font). Prinsip kedua berarti komponen tidak boleh bergantung pada container tertentu—komponen yang sama harus bisa ditempatkan di mana saja. OOCSS mendorong penggunaan kelas yang dapat digunakan kembali dan menghindari penulisan gaya yang terikat pada konteks. Pendekatan ini menghasilkan CSS yang lebih DRY, mudah dipelihara, dan komponen yang benar-benar reusable.

## Contoh Kode Implementasi

```css
/* === STRUKTUR (terpisah dari kulit) === */
.box {
  padding: 1rem;
  margin-bottom: 1rem;
  border-radius: 8px;
}

/* === KULIT (warna, font, efek visual) === */
.skin-light {
  background-color: #f8f9fa;
  color: #333;
  border: 1px solid #dee2e6;
}

.skin-dark {
  background-color: #343a40;
  color: #fff;
  border: 1px solid #23272b;
}

.skin-primary {
  background-color: #3498db;
  color: #fff;
}

.skin-danger {
  background-color: #e74c3c;
  color: #fff;
}

/* === KONTEN (tidak tergantung container) === */
.media {
  display: flex;
  gap: 1rem;
  align-items: flex-start;
}

.media__image {
  flex-shrink: 0;
}

.media__body {
  flex: 1;
}
```

```html
<!-- Box dengan berbagai kulit, struktur tetap sama -->
<div class="box skin-primary">Pesan sukses</div>
<div class="box skin-danger">Pesan error</div>
<div class="box skin-light">Informasi umum</div>

<!-- Media object — bisa ditempatkan di container mana pun -->
<div class="media">
  <img class="media__image" src="avatar.jpg" alt="">
  <div class="media__body">
    <h3>Judul</h3>
    <p>Deskripsi</p>
  </div>
</div>
```

## Poin Penting
- Prinsip 1: Pisahkan struktur (layout, spacing) dari kulit (warna, font, border).
- Prinsip 2: Pisahkan konten dari container — komponen harus bisa ditempatkan di mana saja.
- OOCSS mendorong penggunaan kembali kelas yang dapat dikombinasikan.
- Hasilnya: CSS lebih DRY, reusable, dan mudah dipelihara.
- OOCSS menjadi fondasi bagi metodologi utility-first CSS modern seperti Tailwind.
