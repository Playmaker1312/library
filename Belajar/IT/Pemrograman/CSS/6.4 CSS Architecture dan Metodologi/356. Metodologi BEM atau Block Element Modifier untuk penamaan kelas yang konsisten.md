# Metodologi BEM (Block Element Modifier)

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki sistem penamaan rak yang terstruktur: "Rak-Fiksi-Populer" dan "Rak-Fiksi-Klasik" adalah bagian dari blok "Fiksi", dengan elemen seperti "Label" dan "Pintu", serta modifier seperti "Terbuka" atau "Terkunci". Setiap orang yang bekerja di perpustakaan langsung memahami struktur dari namanya. BEM adalah sistem penamaan kelas CSS yang mengikuti prinsip serupa—nama kelas langsung mengungkapkan struktur komponen.

## Penjelasan Detail

BEM (Block Element Modifier) adalah metodologi penamaan kelas CSS yang dikembangkan oleh Yandex. Tujuannya adalah membuat nama kelas yang intuitif, konsisten, dan mudah dipahami. Blok (Block) adalah komponen mandiri seperti `.card`, `.header`, `.button`. Elemen (Element) adalah bagian dari blok yang tidak berdiri sendiri, ditandai dengan dua underscore: `.card__title`, `.card__image`. Modifier (Modifier) adalah variasi dari blok atau elemen, ditandai dengan dua tanda hubung: `.card--featured`, `.card__title--large`. Keuntungan BEM: tidak ada konflik nama kelas, struktur HTML langsung terbaca dari kelas CSS, specificity rendah dan konsisten, serta mudah dipelihara dalam proyek besar. BEM juga mudah diintegrasikan dengan CSS preprocessor untuk penulisan yang lebih efisien.

## Contoh Kode Implementasi

```css
/* Block */
.card {
  border: 1px solid #ddd;
  border-radius: 8px;
  overflow: hidden;
}

/* Element — bagian dari block */
.card__image {
  width: 100%;
  height: 200px;
  object-fit: cover;
}

.card__title {
  font-size: 1.25rem;
  margin: 0.5rem 1rem;
}

.card__body {
  padding: 1rem;
  color: #555;
}

.card__button {
  display: block;
  width: 100%;
  padding: 0.75rem;
  background: #3498db;
  color: white;
  border: none;
}

/* Modifier — variasi dari block atau element */
.card--featured {
  border-color: #f1c40f;
  box-shadow: 0 4px 12px rgba(241,196,15,0.3);
}

.card__title--large {
  font-size: 1.5rem;
}

.card__button--secondary {
  background: #95a5a6;
}
```

```html
<div class="card card--featured">
  <img class="card__image" src="photo.jpg" alt="">
  <h2 class="card__title card__title--large">Judul Card</h2>
  <div class="card__body">Deskripsi card</div>
  <button class="card__button">Aksi</button>
</div>
```

## Poin Penting
- BEM: Block (komponen), Element (bagian blok, `__`), Modifier (variasi, `--`).
- Nama kelas langsung mengungkapkan struktur komponen dan hubungannya.
- Specificity rendah dan konsisten (semua kelas level 0,1,0).
- Mencegah konflik nama kelas dalam proyek besar dengan banyak komponen.
- Mudah diintegrasikan dengan preprocessor untuk penulisan nested yang efisien.
