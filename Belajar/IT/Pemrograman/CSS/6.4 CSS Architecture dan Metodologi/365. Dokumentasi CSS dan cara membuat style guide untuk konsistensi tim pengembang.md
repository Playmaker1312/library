# Dokumentasi CSS dan Style Guide

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki buku panduan resmi yang menjelaskan aturan penulisan: bagaimana mengkategorikan buku, format nomor ISBN, cara menulis deskripsi, dan pedoman tata letak rak. Setiap pustakawan baru membaca panduan ini untuk bekerja dengan standar yang sama. Tanpa panduan, setiap pustakawan akan bekerja dengan caranya sendiri, menciptakan kekacauan. Style guide CSS berfungsi sebagai buku panduan ini untuk tim pengembang.

## Penjelasan Detail

Dokumentasi CSS dan style guide adalah praktik penting untuk menjaga konsistensi kode dalam tim. Style guide mencakup: aturan penamaan (BEM, camelCase, kebab-case), urutan properti (misalnya positioning → box model → tipografi → visual), pedoman format (indentasi, spasi, komentar), penggunaan unit (px vs rem vs em), pola komponen reusable, dan contoh kode. Tools untuk membuat style guide: KSS (Knyle Style Sheets) untuk dokumentasi otomatis dari komentar CSS, Styleguidist atau Storybook untuk dokumentasi komponen interaktif, dan Fractal untuk sistem desain. Dokumentasi yang baik mempercepat onboarding anggota tim baru, mengurangi inkonsistensi, dan menjadi sumber kebenaran tunggal untuk keputusan desain dan implementasi. Style guide hidup (living style guide) diperbarui seiring evolusi proyek.

## Contoh Kode Implementasi

```css
/* ==========================================
   STYLE GUIDE — Komponen Button
   ========================================== */

/*
 * Button — Tombol interaktif untuk aksi pengguna.
 *
 * .btn — Tombol dasar
 * .btn--primary — Tombol utama (biru)
 * .btn--secondary — Tombol sekunder (abu-abu)
 * .btn--large — Tombol ukuran besar
 * .btn--small — Tombol ukuran kecil
 * .btn--disabled — Tombol nonaktif
 *
 * Markup:
 * <button class="btn btn--primary">Tombol</button>
 * <button class="btn btn--secondary">Batal</button>
 * <a class="btn btn--primary btn--large" href="#">Link Tombol</a>
 *
 * Weight: 1
 */

/* Base button structure */
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  padding: 0.5rem 1rem;
  font-size: 1rem;
  font-weight: 500;
  line-height: 1.5;
  border: 1px solid transparent;
  border-radius: 6px;
  cursor: pointer;
  transition: all 0.2s ease;
  text-decoration: none;
}

/* Sizes */
.btn--small { padding: 0.25rem 0.5rem; font-size: 0.875rem; }
.btn--large { padding: 0.75rem 1.5rem; font-size: 1.125rem; }

/* Visual variants */
.btn--primary {
  background: #3498db;
  color: white;
  border-color: #3498db;
}
.btn--primary:hover { background: #2980b9; }

.btn--secondary {
  background: #95a5a6;
  color: white;
  border-color: #95a5a6;
}
.btn--secondary:hover { background: #7f8c8d; }

/* States */
.btn--disabled,
.btn[disabled] {
  opacity: 0.6;
  pointer-events: none;
}

/* ==========================================
   PEDOMAN PENULISAN
   ==========================================
   - Gunakan 2 spasi untuk indentasi
   - Urutan properti: posisi → display → box model → tipografi → visual → misc
   - Satu baris per selector dalam grouping
   - Beri komentar untuk setiap section
   ========================================== */
```

## Poin Penting
- Style guide CSS mendokumentasikan aturan penamaan, format, dan pola komponen untuk konsistensi tim.
- Tools: KSS, Storybook, Styleguidist, Fractal untuk dokumentasi interaktif.
- Dokumentasi mempercepat onboarding dan mengurangi inkonsistensi kode.
- Style guide hidup (living style guide) diperbarui seiring evolusi proyek.
- Sertakan contoh kode nyata, pedoman format, dan aturan penggunaan komponen.
