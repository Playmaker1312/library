# Shorthand grid-area dengan empat nilai untuk menentukan posisi item secara lengkap

## Analogi: Perpustakaan Digital

Jika `grid-area` dengan nama seperti label ruangan, `grid-area` dengan empat nilai adalah seperti memberikan koordinat lengkap: "mulai dari garis baris 2, garis kolom 1, akhiri di garis baris 4, garis kolom 3". Ini mendefinisikan posisi item secara eksplisit dalam satu baris kode, mencakup awal dan akhir untuk kedua sumbu—baris dan kolom—sekaligus.

## Penjelasan Detail

`grid-area` dengan empat nilai adalah shorthand untuk `grid-row-start`, `grid-column-start`, `grid-row-end`, dan `grid-column-end` secara berurutan. Formatnya: `grid-area: row-start / column-start / row-end / column-end`. Urutan ini berbeda dari intuisi umum (row, column, row, column). Nilai bisa berupa nomor garis, nama garis, atau `span`. Jika hanya satu nilai yang diberikan, `grid-area` berfungsi sebagai penetapan nama area. Shorthand ini sangat berguna ketika kamu perlu menempatkan item secara presisi tanpa menggunakan `grid-template-areas`, terutama untuk item yang tidak mengikuti tata letak grid yang rapi.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-template-rows: repeat(3, 100px);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #607D8B;
  color: white;
  padding: 20px;
  border-radius: 4px;
}

.item-pos {
  grid-area: 2 / 1 / 4 / 3;
  background: #F44336;
}

.item-overlay {
  grid-area: 1 / 2 / 3 / 4;
  background: rgba(156, 39, 176, 0.8);
}
```

## Poin Penting
- Format: `grid-area: row-start / column-start / row-end / column-end`
- Urutan: row-start, column-start, row-end, column-end (ingat: row-column-row-column)
- Bisa menggunakan nomor garis, nama garis, atau span
- Jika satu nilai diberikan, berfungsi sebagai penetapan nama area
- Shorthand paling ringkas untuk penempatan eksplisit lengkap
