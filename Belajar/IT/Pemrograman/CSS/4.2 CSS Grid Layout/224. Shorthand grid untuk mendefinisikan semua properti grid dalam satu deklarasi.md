# Shorthand grid untuk mendefinisikan semua properti grid dalam satu deklarasi

## Analogi: Perpustakaan Digital

Daripada mengatur banyak pengaturan secara terpisah—kolom, baris, area, aliran, ukuran implisit—kamu bisa menggunakan satu perintah komprehensif yang merangkum semuanya. Shorthand `grid` adalah seperti cetak biru lengkap untuk perpustakaan digital: ukuran ruangan, jumlah rak, bagaimana rak diisi, dan bagaimana menangani buku tambahan, semuanya dalam satu deklarasi.

## Penjelasan Detail

Shorthand `grid` menggabungkan properti `grid-template-rows`, `grid-template-columns`, `grid-template-areas`, `grid-auto-rows`, `grid-auto-columns`, dan `grid-auto-flow` dalam satu deklarasi. Formatnya kompleks: bisa menerima nilai untuk explicit grid (seperti `grid-template`) dan auto grid. Contoh: `grid: auto 1fr auto / 1fr 3fr` setara dengan `grid-template-rows: auto 1fr auto; grid-template-columns: 1fr 3fr`. `grid: flow dense / auto-flow 1fr` mengatur auto flow dan auto columns. Karena kompleksitasnya, shorthand `grid` jarang digunakan untuk kode produksi—lebih umum menggunakan `grid-template` atau properti individual.

## Contoh Kode Implementasi

```css
/* grid: <grid-template-rows> / <grid-template-columns> */
.grid-layout {
  display: grid;
  grid: auto 1fr auto / 200px 1fr;
  gap: 12px;
  min-height: 300px;
  border: 2px solid #333;
  padding: 8px;
}

/* grid: <grid-auto-flow> / <grid-auto-columns> */
.grid-auto {
  display: grid;
  grid: dense / auto-flow 150px;
  gap: 10px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #E91E63;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- Shorthand `grid` menggabungkan properti grid template dan auto
- Format: `grid: <rows> / <columns>` untuk grid eksplisit
- Format: `grid: <auto-flow> / <auto-columns>` untuk grid implisit
- Sangat ringkas tetapi bisa sulit dibaca karena formatnya kompleks
- `grid-template` shorthand lebih sering digunakan untuk definisi template
