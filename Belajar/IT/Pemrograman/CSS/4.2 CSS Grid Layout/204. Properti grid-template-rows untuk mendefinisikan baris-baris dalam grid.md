# Properti grid-template-rows untuk mendefinisikan baris-baris dalam grid

## Analogi: Perpustakaan Digital

Jika `grid-template-columns` membagi ruang secara vertikal, `grid-template-rows` membagi ruang secara horizontal. Ini seperti menentukan berapa banyak rak vertikal yang ada di perpustakaan: rak atas untuk buku referensi, rak tengah untuk fiksi, dan rak bawah untuk non-fiksi. Kamu bisa mengatur tinggi masing-masing rak sesuai kebutuhan.

## Penjelasan Detail

`grid-template-rows` mendefinisikan jumlah dan ukuran baris dalam grid. Mirip dengan `grid-template-columns`, setiap nilai mewakili satu baris. Nilai bisa `auto` (menyesuaikan konten), panjang tetap (`px`), persentase, unit `fr`, `minmax()`, atau `repeat()`. Jika jumlah item melebihi baris yang didefinisikan, baris implisit akan dibuat secara otomatis dengan ukuran default (bisa diatur dengan `grid-auto-rows`). Properti ini sering digunakan bersama `grid-template-columns` untuk membuat grid yang lengkap. Untuk tata letak halaman, biasanya `grid-template-rows` digunakan dengan kombinasi `auto` untuk header/footer dan `1fr` untuk konten utama.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: 1fr 3fr;
  grid-template-rows: auto 1fr auto;
  gap: 12px;
  min-height: 300px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #FF9800;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}

.item.header {
  grid-column: 1 / -1;
  background: #3F51B5;
}

.item.footer {
  grid-column: 1 / -1;
  background: #607D8B;
}
```

## Poin Penting
- `grid-template-rows` mendefinisikan jumlah dan ukuran baris grid
- Nilai bisa berupa auto, px, fr, minmax(), atau repeat()
- Baris implisit dibuat otomatis jika item melebihi baris yang didefinisikan
- Sering digunakan bersama `grid-template-columns` untuk grid lengkap
- Kombinasi `auto` dan `1fr` berguna untuk layout halaman standar
