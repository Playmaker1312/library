# Properti justify-self dan align-self pada item untuk menimpa penyelarasan individual

## Analogi: Perpustakaan Digital

Meskipun semua buku dalam grid biasanya mengikuti aturan alignment yang sama dari container, kamu bisa memberikan pengecualian pada satu atau dua buku. `justify-self` dan `align-self` adalah perintah individual yang memungkinkan sebuah buku diposisikan berbeda dari yang lain—misalnya, semua buku rata tengah, tetapi satu buku khusus rata kanan.

## Penjelasan Detail

`justify-self` dan `align-self` diterapkan pada grid item (bukan container) untuk menimpa nilai `justify-items` dan `align-items` dari container untuk item tertentu. `justify-self` mengatur penyelarasan horizontal item dalam selnya, dengan nilai `stretch`, `start`, `end`, `center`. `align-self` mengatur penyelarasan vertikal dengan nilai yang sama. Nilai default `auto` membuat item mengikuti pengaturan container. Properti ini memberikan fleksibilitas untuk menyesuaikan posisi item individual tanpa memengaruhi item lain, berguna untuk tombol aksi, badge, atau elemen yang membutuhkan posisi khusus dalam selnya.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
  border: 2px solid #333;
  padding: 8px;
  height: 200px;
  justify-items: center;
  align-items: center;
}

.item {
  background: #4CAF50;
  color: white;
  padding: 12px 20px;
  border-radius: 4px;
}

.item-right {
  justify-self: end;
  align-self: start;
  background: #F44336;
}

.item-left-bottom {
  justify-self: start;
  align-self: end;
  background: #2196F3;
}

.item-stretch {
  justify-self: stretch;
  align-self: stretch;
  background: #9C27B0;
}
```

## Poin Penting
- `justify-self` menimpa `justify-items` untuk satu item (horizontal)
- `align-self` menimpa `align-items` untuk satu item (vertikal)
- Nilai `auto` (default) mengikuti pengaturan container
- Nilai tersedia: stretch, start, end, center
- Memberikan fleksibilitas posisi individual dalam tata letak grid
