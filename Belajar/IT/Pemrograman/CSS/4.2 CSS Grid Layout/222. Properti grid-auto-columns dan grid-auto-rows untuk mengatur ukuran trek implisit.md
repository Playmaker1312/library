# Properti grid-auto-columns dan grid-auto-rows untuk mengatur ukuran trek implisit

## Analogi: Perpustakaan Digital

Ketika rak tambahan muncul secara otomatis (grid implisit), kamu bisa menentukan ukuran standar untuk rak-rak baru tersebut. `grid-auto-rows` seperti menentukan tinggi standar untuk rak baru yang muncul di bawah, sementara `grid-auto-columns` menentukan lebar standar untuk kolom baru di samping. Tanpa pengaturan ini, rak baru akan menyesuaikan ukuran kontennya secara default.

## Penjelasan Detail

`grid-auto-columns` dan `grid-auto-rows` mengatur ukuran trek yang dibuat secara implisit—yaitu trek yang tidak didefinisikan dalam `grid-template-columns` atau `grid-template-rows`. Nilai default adalah `auto`, yang berarti ukuran trek menyesuaikan konten. Kamu bisa menggunakan nilai panjang (px, em), `fr`, `minmax()`, atau kombinasi. Misalnya, `grid-auto-rows: minmax(100px, auto)` membuat setiap baris implisit minimal 100px tetapi bisa meregang sesuai konten. Properti ini sangat berguna untuk tata letak dengan konten dinamis di mana jumlah item tidak diketahui sebelumnya, seperti galeri gambar atau daftar produk.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 100px;
  grid-auto-rows: minmax(80px, auto);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-columns-auto {
  display: grid;
  grid-auto-columns: 150px;
  grid-auto-flow: column;
  gap: 10px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #9C27B0;
  color: white;
  padding: 16px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `grid-auto-rows` mengatur tinggi baris implisit (default: auto)
- `grid-auto-columns` mengatur lebar kolom implisit (default: auto)
- Nilai bisa berupa px, fr, minmax(), atau kombinasi
- Berguna untuk konten dinamis dengan jumlah item yang tidak diketahui
- `minmax(100px, auto)` memastikan tinggi minimal namun tetap fleksibel
