# Nilai span dalam penempatan grid untuk membuat item mencakup beberapa trek

## Analogi: Perpustakaan Digital

Bayangkan sebuah meja besar di perpustakaan yang membutuhkan ruang tiga kolom. Daripada menentukan garis akhir secara spesifik (yang mungkin berubah jika layout dimodifikasi), kamu cukup bilang "meja ini membutuhkan 3 kolom" menggunakan kata kunci `span`. Ini seperti mengatakan "bentang 3 rak" tanpa perlu tahu di mana ujung rak tersebut.

## Penjelasan Detail

Nilai `span` dalam penempatan grid menentukan berapa banyak trek (kolom atau baris) yang harus dicakup oleh item, tanpa perlu menentukan garis akhir yang spesifik. `span` bisa digunakan di properti `grid-column-start`, `grid-column-end`, `grid-row-start`, `grid-row-end`, atau dalam shorthand. Contoh: `grid-column: 2 / span 3` berarti mulai dari garis kolom 2 dan mencakup 3 kolom (berakhir di garis 5). `grid-column: span 2 / 4` berarti mencakup 2 kolom sebelum garis 4 (mulai dari garis 2). `span` lebih fleksibel daripada garis absolut karena secara otomatis menyesuaikan jika grid template berubah.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #00BCD4;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}

.item-span-3 {
  grid-column: span 3;
  background: #FF5722;
}

.item-span-2-row {
  grid-row: span 2;
  background: #4CAF50;
}

.item-specific {
  grid-column: 2 / span 2;
  grid-row: 1 / span 2;
  background: #9C27B0;
}
```

## Poin Penting
- `span N` membuat item mencakup N trek tanpa menentukan garis akhir
- Bisa digunakan di start atau end, pada kolom maupun baris
- Lebih fleksibel daripada garis absolut karena menyesuaikan dengan template
- Contoh: `grid-column: span 2 / 4` = mulai 2 trek sebelum garis 4
- `span` sangat berguna dalam tata letak responsif dan dinamis
