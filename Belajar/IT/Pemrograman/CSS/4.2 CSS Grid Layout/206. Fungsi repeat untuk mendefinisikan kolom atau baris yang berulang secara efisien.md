# Fungsi repeat untuk mendefinisikan kolom atau baris yang berulang secara efisien

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan dengan 12 rak yang identik. Daripada menulis "rak, rak, rak, rak..." dua belas kali, kamu cukup bilang "ulangi rak sebanyak 12 kali". Fungsi `repeat()` dalam CSS Grid melakukan hal yang sama—memungkinkan kamu mendefinisikan pola kolom atau baris yang berulang tanpa menulis nilai yang sama berkali-kali.

## Penjelasan Detail

Fungsi `repeat()` digunakan dalam `grid-template-columns` dan `grid-template-rows` untuk mendefinisikan pola trek yang berulang. Formatnya: `repeat(count, value)`. Contoh: `repeat(3, 1fr)` setara dengan `1fr 1fr 1fr`, dan `repeat(4, 100px)` setara dengan `100px 100px 100px 100px`. `repeat()` juga bisa menerima beberapa nilai: `repeat(2, 1fr 2fr)` setara dengan `1fr 2fr 1fr 2fr`. Kata kunci khusus `auto-fill` dan `auto-fit` bisa digunakan sebagai pengganti count untuk membuat grid yang responsif secara otomatis. Fungsi ini juga bisa digunakan bersama nilai non-repeat dalam deklarasi yang sama.

## Contoh Kode Implementasi

```css
.grid-repeat {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-repeat-multi {
  display: grid;
  grid-template-columns: repeat(2, 100px 1fr);
  gap: 8px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.grid-mixed {
  display: grid;
  grid-template-columns: 200px repeat(2, 1fr);
  gap: 12px;
  border: 2px solid #999;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #9C27B0;
  color: white;
  padding: 16px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `repeat(count, value)` menghindari pengulangan nilai yang sama
- Bisa menerima beberapa nilai: `repeat(2, 1fr 2fr)`
- Bisa dikombinasikan dengan nilai non-repeat dalam deklarasi yang sama
- Kata kunci `auto-fill` dan `auto-fit` membuat grid responsif otomatis
- Fungsi ini membuat kode lebih bersih dan mudah dipelihara
