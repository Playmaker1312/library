# Properti display grid untuk mengaktifkan konteks grid pada elemen kontainer

## Analogi: Perpustakaan Digital

Seperti Flexbox, CSS Grid juga memulai dengan mengaktifkan "mode grid" pada sebuah wadah. Begitu mode ini diaktifkan, semua anak langsung dari wadah tersebut menjadi grid items yang siap diatur dalam baris dan kolom. Tanpa mode ini, properti grid lainnya seperti `grid-template-columns` tidak akan berpengaruh.

## Penjelasan Detail

`display: grid` mengubah elemen menjadi grid container, dan semua anak langsungnya menjadi grid items. Container membentuk Grid Formatting Context (GFC), yang berbeda dari Block Formatting Context. Dengan nilai `grid`, container bersifat block-level (mengisi lebar penuh). Nilai `inline-grid` juga tersedia untuk membuat container grid yang bersifat inline. Setelah `display: grid` diterapkan, kamu bisa mendefinisikan kolom dan baris, mengatur jarak (gap), dan menempatkan item. Salah satu efek langsung dari `display: grid` adalah bahwa grid items secara default akan menempati satu sel grid dan tidak lagi mengikuti aturan layout normal.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
  padding: 12px;
  background: #f0f0f0;
  border-radius: 8px;
}

.inline-grid-container {
  display: inline-grid;
  grid-template-columns: 80px 80px 80px;
  gap: 6px;
  padding: 8px;
  background: #e0e0e0;
  border-radius: 8px;
}

.grid-item {
  background: #00BCD4;
  color: white;
  padding: 16px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `display: grid` mengubah elemen menjadi grid container (block-level)
- `display: inline-grid` membuat container grid yang bersifat inline
- Semua anak langsung menjadi grid items secara otomatis
- Tanpa `display: grid`, properti grid lainnya tidak berfungsi
- Grid items default ke satu sel grid dan tidak saling tumpang tindih
