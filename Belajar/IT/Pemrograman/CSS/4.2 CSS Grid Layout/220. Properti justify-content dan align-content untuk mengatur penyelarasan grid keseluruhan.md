# Properti justify-content dan align-content untuk mengatur penyelarasan grid keseluruhan

## Analogi: Perpustakaan Digital

Bayangkan sebuah papan grid yang lebih kecil dari ruangan yang tersedia. Seluruh papan grid bisa digeser ke kiri, ke kanan, ke tengah, atau diregangkan memenuhi ruangan. `justify-content` mengatur posisi horizontal seluruh grid dalam containernya, sementara `align-content` mengatur posisi vertikalnya. Ini berguna ketika ukuran total grid lebih kecil dari ukuran container.

## Penjelasan Detail

`justify-content` dan `align-content` pada grid container mengatur penyelarasan seluruh grid tracks ketika ukuran total grid lebih kecil dari ukuran container (dalam arah inline untuk `justify-content` dan block untuk `align-content`). Nilai yang tersedia: `start`, `end`, `center`, `stretch`, `space-between`, `space-around`, `space-evenly`. `stretch` (default) meregangkan tracks untuk mengisi container. `space-between` mendistribusikan ruang kosong secara merata antar tracks. Properti ini mirip dengan `align-content` di Flexbox, tetapi untuk grid, properti ini bisa diterapkan pada kedua sumbu secara independen.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 100px);
  grid-template-rows: repeat(2, 80px);
  gap: 12px;
  border: 2px solid #333;
  padding: 8px;
  height: 300px;
  justify-content: center;
  align-content: center;
}

.jc-start  { justify-content: start; }
.jc-end    { justify-content: end; }
.jc-center { justify-content: center; }
.jc-between { justify-content: space-between; }
.jc-evenly { justify-content: space-evenly; }

.item {
  background: #00BCD4;
  color: white;
  padding: 16px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `justify-content` mengatur posisi horizontal seluruh grid dalam container
- `align-content` mengatur posisi vertikal seluruh grid dalam container
- Berguna ketika ukuran total grid lebih kecil dari container
- Nilai: start, end, center, stretch, space-between, space-around, space-evenly
- `stretch` adalah default, meregangkan tracks mengisi container
