# Kapan menggunakan CSS Grid dan kapan menggunakan Flexbox secara tepat

## Analogi: Perpustakaan Digital

CSS Grid seperti denah seluruh lantai perpustakaan—membagi ruangan menjadi area-area (ruang baca, rak buku, meja sirkulasi) dalam dua dimensi. Flexbox seperti rak buku individual—mengatur buku dalam satu baris atau kolom dalam rak tersebut. Grid untuk tata letak halaman secara keseluruhan, Flexbox untuk komponen di dalamnya. Keduanya saling melengkapi, bukan bersaing.

## Penjelasan Detail

CSS Grid dan Flexbox memiliki kekuatan masing-masing. Gunakan CSS Grid ketika: (1) kamu perlu mengontrol tata letak dalam dua dimensi (baris dan kolom), (2) kamu membuat tata letak halaman secara keseluruhan, (3) kamu perlu menempatkan item secara presisi dalam grid, (4) item harus selaras dalam kedua sumbu. Gunakan Flexbox ketika: (1) tata letak hanya dalam satu dimensi (baris ATAU kolom), (2) kamu perlu mendistribusikan ruang secara dinamis antar item, (3) ukuran item bersifat fleksibel dan tidak diketahui, (4) kamu membuat komponen UI kecil seperti navigasi, tombol, atau kartu. Praktik terbaik adalah menggabungkan keduanya: Grid untuk layout makro (struktur halaman), Flexbox untuk layout mikro (komponen di dalam area grid).

## Contoh Kode Implementasi

```css
/* Grid untuk tata letak halaman (makro) */
.page-layout {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  min-height: 100vh;
}

/* Flexbox untuk komponen di dalamnya (mikro) */
.nav-links {
  display: flex;
  gap: 16px;
  justify-content: flex-end;
  align-items: center;
}

.card-row {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
```

## Poin Penting
- Grid untuk tata letak dua dimensi (halaman keseluruhan)
- Flexbox untuk tata letak satu dimensi (komponen dan item)
- Grid unggul untuk penempatan presisi dan alignment dua sumbu
- Flexbox unggul untuk distribusi ruang dinamis dan urutan item
- Praktik terbaik: Grid untuk makro (layout halaman), Flexbox untuk mikro (komponen)
