# Shorthand grid-column dan grid-row untuk penempatan item yang lebih ringkas

## Analogi: Perpustakaan Digital

Daripada menulis "mulai dari garis 1, akhiri di garis 4" sebagai dua perintah terpisah, kamu bisa menulis satu perintah ringkas: "1 / 4". Shorthand `grid-column` dan `grid-row` menggabungkan nilai start dan end dalam satu deklarasi, membuat kode lebih bersih dan mudah ditulis. Ini seperti menggunakan singkatan dalam catatan perpustakaan.

## Penjelasan Detail

`grid-column` adalah shorthand untuk `grid-column-start` dan `grid-column-end`, dengan format: `grid-column: start / end`. `grid-row` adalah shorthand untuk `grid-row-start` dan `grid-row-end`. Jika hanya satu nilai yang diberikan, itu menjadi nilai start dan end menggunakan default (span 1). Nilai `span` bisa ditempatkan di posisi start atau end. Contoh: `grid-column: 2 / 4` berarti mulai dari garis 2, berakhir di garis 4. `grid-column: 2 / span 3` berarti mulai dari garis 2, mencakup 3 kolom. `grid-column: 1 / -1` mencakup semua kolom dari awal hingga akhir.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #9C27B0;
  color: white;
  padding: 20px;
  border-radius: 4px;
}

.item-wide {
  grid-column: 1 / 4;
  background: #E91E63;
}

.item-full {
  grid-column: 1 / -1;
  background: #3F51B5;
}

.item-offset {
  grid-column: 2 / span 2;
  grid-row: 2 / span 2;
  background: #FF9800;
}
```

## Poin Penting
- `grid-column: start / end` menggabungkan `grid-column-start` dan `grid-column-end`
- `grid-row: start / end` menggabungkan `grid-row-start` dan `grid-row-end`
- Nilai tunggal hanya mengatur start, end menggunakan default (span 1)
- `span N` bisa digunakan di kedua posisi start atau end
- `1 / -1` mencakup semua trek dari awal hingga akhir
