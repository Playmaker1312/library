# Properti grid-area pada item untuk menempatkan item dalam area yang sudah dinamai

## Analogi: Perpustakaan Digital

Setelah membuat denah ruangan dengan nama-nama seperti "header", "sidebar", dan "konten", kamu perlu memberi label pada setiap kotak atau rak agar ditempatkan di ruangan yang sesuai. Properti `grid-area` pada item seperti menempelkan label "ini adalah header" pada elemen header, sehingga ia secara otomatis menempati area yang telah ditentukan dalam denah.

## Penjelasan Detail

`grid-area` pada grid item digunakan bersama `grid-template-areas` untuk menempatkan item ke dalam area yang sudah dinamai. Nilai `grid-area` pada item harus cocok dengan nama area yang didefinisikan di `grid-template-areas`. Satu nama area bisa ditempati oleh satu item saja—jika ada dua item dengan nama yang sama, mereka akan saling tumpang tindih. Properti ini membuat kode sangat deklaratif: cukup beri nama pada item, lalu atur posisinya di template areas. Jika ingin mengubah layout, cukup ubah `grid-template-areas` tanpa menyentuh item-itemnya. `grid-area` juga bisa digunakan sebagai shorthand untuk `grid-row-start`, `grid-column-start`, `grid-row-end`, `grid-column-end`.

## Contoh Kode Implementasi

```css
.grid-layout {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header  header"
    "sidebar main    aside"
    "footer  footer  footer";
  gap: 10px;
  min-height: 350px;
  border: 2px solid #333;
  padding: 8px;
}

header { grid-area: header;  background: #2c3e50; }
nav    { grid-area: sidebar; background: #34495e; }
main   { grid-area: main;    background: #ecf0f1; color: #333; }
aside  { grid-area: aside;   background: #bdc3c7; }
footer { grid-area: footer;  background: #2c3e50; }

.item {
  color: white;
  padding: 20px;
  border-radius: 4px;
}
```

## Poin Penting
- `grid-area` pada item mencocokkan nama area di `grid-template-areas`
- Membuat kode sangat deklaratif—nama area menjelaskan fungsi item
- Mengubah layout cukup dengan mengubah `grid-template-areas`
- Dua item tidak bisa berbagi nama area yang sama dalam satu grid
- `grid-area` juga bisa digunakan sebagai shorthand 4-nilai untuk posisi eksplisit
