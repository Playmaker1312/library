# Subgrid sebagai fitur untuk mewarisi trek grid dari kontainer induknya

## Analogi: Perpustakaan Digital

Bayangkan sebuah laci besar dalam rak yang terbagi menjadi kompartemen-kompartemen kecil. Daripada mendefinisikan ulang ukuran kompartemen dari awal, laci tersebut bisa mewarisi pembagian dari rak utamanya. `subgrid` memungkinkan grid anak untuk "menyambung" ke grid induknya, sehingga kolom atau baris di grid anak selaras sempurna dengan grid induk. Ini seperti kompartemen yang mengikuti garis-garis rak utama.

## Penjelasan Detail

`subgrid` adalah nilai untuk `grid-template-columns` dan `grid-template-rows` pada grid item yang juga merupakan grid container. Alih-alih mendefinisikan trek sendiri, subgrid mewarisi definisi trek dari grid induknya. Ini memastikan bahwa item di dalam subgrid selaras dengan grid induk. Subgrid hanya bisa digunakan jika elemen adalah grid item (anak langsung dari grid container) dan juga grid container. Subgrid sangat berguna untuk tata letak tabel atau kartu di mana konten di dalamnya harus selaras dengan elemen di baris atau kolom yang sama.

## Contoh Kode Implementasi

```css
.parent-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 12px;
  border: 2px solid #333;
  padding: 8px;
}

.subgrid-item {
  grid-column: span 2;
  display: grid;
  grid-template-columns: subgrid;
  background: #f0f0f0;
  border-radius: 4px;
  padding: 8px;
}

.subgrid-item > * {
  background: #4CAF50;
  color: white;
  padding: 12px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `subgrid` mewarisi definisi trek dari grid induk
- Hanya bisa digunakan pada item yang juga merupakan grid container
- Memastikan konten di dalam subgrid selaras dengan grid induk
- Ideal untuk tata letak tabel atau kartu yang kompleks
- Didukung di browser modern, periksa kompatibilitas sebelum digunakan
