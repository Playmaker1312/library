# Satuan fr atau fraction unit untuk mendistribusikan ruang yang tersisa secara proporsional

## Analogi: Perpustakaan Digital

Satuan `fr` seperti memesan ruang di perpustakaan secara proporsional. Jika kamu berkata "bagi ruang kosong menjadi 4 bagian, beri 1 bagian untuk rak majalah, 3 bagian untuk rak buku", maka rak buku akan mendapat ruang tiga kali lebih besar dari rak majalah. Ini jauh lebih fleksibel daripada menggunakan ukuran tetap seperti piksel atau persentase.

## Penjelasan Detail

`fr` adalah unit khusus dalam CSS Grid yang mewakili sebagian (fraction) dari ruang yang tersisa di grid container. Setelah semua ukuran tetap (px, em) dan konten (auto) dihitung, ruang yang tersisa didistribusikan secara proporsional berdasarkan nilai `fr`. Misalnya, `grid-template-columns: 1fr 2fr 1fr` membagi ruang menjadi 4 bagian: kolom 1 mendapat 1/4, kolom 2 mendapat 2/4 (1/2), kolom 3 mendapat 1/4. `fr` hanya menghitung ruang yang tersisa, bukan total lebar container, sehingga bisa dikombinasikan dengan ukuran tetap. Unit ini tidak setara dengan persentase karena persentase dihitung dari total container, sedangkan `fr` dari ruang yang tersisa.

## Contoh Kode Implementasi

```css
.grid-fr {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 12px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-mixed {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
  gap: 12px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #2196F3;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}

.item:nth-child(2) { background: #F44336; }
```

## Poin Penting
- `fr` (fraction) mendistribusikan ruang yang tersisa secara proporsional
- Bisa dikombinasikan dengan ukuran tetap seperti px dan em
- Tidak sama dengan persentase—fr dihitung dari sisa ruang, bukan total container
- Nilai total fr menentukan rasio pembagian (1fr+2fr+1fr = 4 bagian)
- Unit paling fleksibel untuk tata letak grid yang responsif
