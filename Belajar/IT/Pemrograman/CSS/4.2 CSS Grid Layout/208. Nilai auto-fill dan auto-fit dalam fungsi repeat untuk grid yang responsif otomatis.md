# Nilai auto-fill dan auto-fit dalam fungsi repeat untuk grid yang responsif otomatis

## Analogi: Perpustakaan Digital

Bayangkan rak buku yang secara otomatis menyesuaikan jumlah kolom tergantung lebar layar. `auto-fill` akan mengisi rak dengan kolom-kolom kosong yang siap diisi, sementara `auto-fit` akan meruntuhkan kolom kosong dan meregangkan kolom yang ada. Jika ada 3 buku dengan lebar minimal 200px di layar 1000px, `auto-fill` akan membuat 5 kolom (3 terisi + 2 kosong), sedangkan `auto-fit` akan membuat 3 kolom yang meregang.

## Penjelasan Detail

`auto-fill` dan `auto-fit` adalah kata kunci yang digunakan dalam fungsi `repeat()` untuk membuat grid yang responsif secara otomatis. Keduanya bekerja dengan `minmax()` untuk menentukan jumlah trek berdasarkan ruang yang tersedia. `auto-fill` membuat sebanyak mungkin trek yang muat, termasuk trek kosong yang tidak terisi item. `auto-fit` juga membuat sebanyak mungkin trek, tetapi trek kosong akan memiliki ukuran 0 dan di-collapse, sehingga trek yang terisi bisa meregang. Perbedaan ini terlihat ketika jumlah item lebih sedikit dari kapasitas maksimum: `auto-fill` meninggalkan ruang kosong, `auto-fit` meruntuhkannya.

## Contoh Kode Implementasi

```css
.grid-auto-fill {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
  gap: 12px;
  border: 2px solid #333;
  padding: 8px;
  margin-bottom: 16px;
}

.grid-auto-fit {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
  gap: 12px;
  border: 2px solid #666;
  padding: 8px;
}

.item {
  background: #4CAF50;
  color: white;
  padding: 24px;
  border-radius: 4px;
  text-align: center;
  font-weight: bold;
}
```

## Poin Penting
- `auto-fill` membuat trek sebanyak mungkin termasuk yang kosong
- `auto-fit` meruntuhkan trek kosong sehingga trek terisi bisa meregang
- Keduanya memerlukan `minmax()` untuk menentukan ukuran minimum trek
- `auto-fit` lebih sering digunakan karena memanfaatkan ruang secara optimal
- Perbedaan terlihat ketika jumlah item < kapasitas maksimum trek
