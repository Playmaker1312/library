# Properti justify-items untuk mengatur penyelarasan semua item dalam sel secara horizontal

## Analogi: Perpustakaan Digital

Bayangkan setiap sel grid adalah kotak kecil, dan di dalamnya ada sebuah buku. `justify-items` mengatur bagaimana buku-buku tersebut disejajarkan secara horizontal di dalam kotaknya masing-masing. Apakah buku ditempelkan ke kiri kotak, ke kanan, di tengah, atau diregangkan memenuhi lebar kotak. Ini seperti mengatur alignment horizontal untuk semua item sekaligus.

## Penjelasan Detail

`justify-items` adalah properti pada grid container yang mengatur penyelarasan horizontal (inline axis) dari semua grid items di dalam sel grid mereka. Nilai `stretch` (default) membuat item meregang memenuhi lebar sel. `start` menempatkan item di tepi kiri sel. `end` menempatkan di tepi kanan. `center` memusatkan item secara horizontal. Nilai-nilai ini bekerja dalam konteks grid cell, bukan grid container secara keseluruhan. Properti ini bisa ditimpa untuk item individual menggunakan `justify-self`. Perhatikan bahwa `justify-items` di Grid mirip dengan `align-items` di Flexbox, tetapi untuk arah inline.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 100px);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
  justify-items: center;
}

.grid-start  { justify-items: start; }
.grid-end    { justify-items: end; }
.grid-center { justify-items: center; }
.grid-stretch { justify-items: stretch; }

.item {
  background: #FF9800;
  color: white;
  padding: 8px 16px;
  border-radius: 4px;
}
```

## Poin Penting
- `justify-items` mengatur penyelarasan horizontal item dalam sel grid
- Nilai `stretch` (default) meregangkan item memenuhi lebar sel
- Nilai `start`, `end`, `center` untuk posisi kiri, kanan, tengah
- Berlaku untuk semua grid items dalam container
- Bisa ditimpa per-item menggunakan `justify-self`
