# Properti grid-column-start dan grid-column-end untuk penempatan item secara eksplisit

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin menempatkan sebuah rak buku besar yang membentang dari kolom pertama hingga kolom ketiga. Kamu perlu menentukan di garis kolom mana rak dimulai dan di garis kolom mana berakhir. `grid-column-start` dan `grid-column-end` adalah perintah untuk menentukan batas awal dan akhir item pada sumbu kolom—seperti menentukan "mulai dari garis 1, akhiri di garis 4".

## Penjelasan Detail

`grid-column-start` dan `grid-column-end` menentukan posisi item grid berdasarkan nomor garis (grid lines). Grid lines diberi nomor dari 1 di awal. `grid-column-start: 2` berarti item mulai dari garis kolom ke-2, dan `grid-column-end: 4` berarti item berakhir di garis kolom ke-4 (mencakup kolom 2 dan 3). Nilai negatif menghitung dari akhir: `-1` adalah garis terakhir. Nilai `span N` membuat item mencakup N kolom: `grid-column-end: span 2` berarti item membentang 2 kolom dari posisi start. Jika `grid-column-end` tidak ditentukan, item mencakup 1 kolom secara default.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #2196F3;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}

.item-wide {
  grid-column-start: 1;
  grid-column-end: 4;
  background: #F44336;
}

.item-full {
  grid-column-start: 1;
  grid-column-end: -1;
  background: #9C27B0;
}
```

## Poin Penting
- `grid-column-start` dan `grid-column-end` menggunakan nomor grid lines
- Grid lines diberi nomor dari 1 di awal hingga N+1 di akhir
- Nilai negatif menghitung dari garis terakhir
- Nilai `span N` membuat item mencakup N trek
- Jika `grid-column-end` tidak ditentukan, item mencakup 1 kolom
