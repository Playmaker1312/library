# Menggabungkan CSS Grid dan Flexbox untuk tata letak yang kompleks dan fleksibel

## Analogi: Perpustakaan Digital

Dalam perpustakaan digital yang ideal, denah ruangan (Grid) dan rak buku pintar (Flexbox) bekerja bersama. Denah ruangan membagi area menjadi ruang baca, rak buku, dan meja sirkulasi. Di dalam setiap area, rak buku pintar mengatur buku-buku secara fleksibel. Kombinasi keduanya menciptakan perpustakaan yang tertata secara struktural namun fleksibel dalam detailnya.

## Penjelasan Detail

Menggabungkan CSS Grid dan Flexbox adalah praktik terbaik untuk tata letak web modern. Grid digunakan untuk struktur halaman secara keseluruhan (makro), sementara Flexbox digunakan untuk komponen di dalam area grid (mikro). Contoh umum: halaman dengan header, sidebar, konten utama, dan footer menggunakan Grid. Di dalam header, navigasi menggunakan Flexbox. Di dalam konten utama, daftar kartu menggunakan Flexbox dengan wrap. Di dalam sidebar, daftar tautan menggunakan Flexbox dengan arah kolom. Pendekatan ini memanfaatkan kekuatan masing-masing—Grid untuk alignment dua dimensi dan penempatan presisi, Flexbox untuk distribusi ruang dinamis dalam satu dimensi.

## Contoh Kode Implementasi

```css
/* Grid untuk struktur halaman */
.page {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
  gap: 0;
}

.header  { grid-area: header; background: #2c3e50; padding: 0 24px; }
.sidebar { grid-area: sidebar; background: #34495e; padding: 20px; }
.main    { grid-area: main; background: #ecf0f1; padding: 24px; }
.footer  { grid-area: footer; background: #2c3e50; padding: 16px; }

/* Flexbox untuk komponen di dalam grid */
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  height: 60px;
}

.nav-links {
  display: flex;
  gap: 20px;
  list-style: none;
}

.sidebar-menu {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

.card-list {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

.card {
  flex: 1 1 280px;
  background: white;
  border-radius: 8px;
  padding: 20px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}
```

## Poin Penting
- Grid untuk struktur halaman keseluruhan (makro layout)
- Flexbox untuk komponen di dalam area grid (mikro layout)
- Kombinasi ini memanfaatkan kekuatan terbaik dari kedua sistem
- Contoh: Grid untuk layout halaman, Flexbox untuk navigasi, kartu, sidebar
- Pendekatan paling fleksibel dan banyak digunakan dalam web modern
