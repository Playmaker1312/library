# Teknik membuat tata letak majalah atau magazine layout menggunakan CSS Grid

## Analogi: Perpustakaan Digital

Tata letak majalah adalah seperti halaman koran atau majalah digital dengan berbagai ukuran artikel: judul besar di atas, artikel utama lebar di tengah, sidebar dengan berita terkait, gambar yang membentang beberapa kolom. CSS Grid memungkinkan pembuatan tata letak kompleks ini dengan mudah, di mana setiap artikel menempati area yang berbeda dalam grid—beberapa lebih lebar, beberapa lebih tinggi.

## Penjelasan Detail

Magazine layout memanfaatkan kemampuan CSS Grid untuk membuat grid dengan kolom dan baris yang tidak seragam. Dengan mendefinisikan beberapa kolom (misal 4-6 kolom) dan menempatkan item secara eksplisit menggunakan `grid-column` dan `grid-row`, kamu bisa membuat tata letak majalah yang dinamis. Item utama (featured article) bisa membentang beberapa kolom dan baris, sementara item kecil hanya satu sel. Fungsi `repeat(auto-fill, minmax())` bisa digunakan untuk tata letak yang responsif. Kombinasi penempatan eksplisit dan implisit memungkinkan beberapa artikel diatur secara manual sementara sisanya mengalir otomatis.

## Contoh Kode Implementasi

```css
.magazine {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: minmax(120px, auto);
  gap: 16px;
  max-width: 1000px;
  margin: 0 auto;
  padding: 16px;
}

.featured {
  grid-column: 1 / 4;
  grid-row: 1 / 3;
  background: #2c3e50;
  color: white;
  padding: 24px;
  border-radius: 8px;
}

.sidebar {
  grid-column: 4 / 5;
  grid-row: 1 / 4;
  background: #ecf0f1;
  padding: 16px;
  border-radius: 8px;
}

.article {
  background: white;
  padding: 16px;
  border-radius: 8px;
  box-shadow: 0 1px 4px rgba(0,0,0,0.1);
}

.article-wide {
  grid-column: span 2;
}

.article-tall {
  grid-row: span 2;
}
```

## Poin Penting
- Gunakan beberapa kolom (4-6) untuk fleksibilitas tata letak
- Tempatkan item secara eksplisit dengan `grid-column` dan `grid-row`
- Item utama bisa membentang beberapa baris dan kolom
- Kombinasikan penempatan eksplisit dengan auto-placement
- `grid-auto-rows: minmax()` memastikan tinggi minimum yang konsisten
