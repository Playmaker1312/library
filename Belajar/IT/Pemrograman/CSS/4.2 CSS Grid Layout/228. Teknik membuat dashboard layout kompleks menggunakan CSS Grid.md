# Teknik membuat dashboard layout kompleks menggunakan CSS Grid

## Analogi: Perpustakaan Digital

Dashboard adalah seperti papan kontrol perpustakaan digital yang menampilkan berbagai informasi sekaligus: statistik pengunjung, daftar buku terpopuler, grafik peminjaman, dan notifikasi. CSS Grid memungkinkan semua elemen ini diatur dalam tata letak grid yang kompleks, dengan setiap panel menempati posisi dan ukuran yang berbeda, namun tetap rapi dan terstruktur.

## Penjelasan Detail

Dashboard layout kompleks memanfaatkan kemampuan CSS Grid untuk membuat grid dengan area-area yang tidak seragam. Pendekatan terbaik adalah menggunakan `grid-template-areas` untuk mendefinisikan denah dashboard secara visual. Setiap panel (statistics, chart, table, notifications, calendar) ditempatkan dalam area spesifik. Panel bisa membentang beberapa baris atau kolom sesuai kebutuhan. Dengan media queries, tata letak dashboard bisa diubah total untuk layar kecil—dari grid multi-kolom menjadi tumpukan vertikal. Penggunaan `minmax()` dan `fr` memastikan panel-panel mengisi ruang yang tersedia secara proporsional.

## Contoh Kode Implementasi

```css
.dashboard {
  display: grid;
  grid-template-columns: 250px 1fr 1fr;
  grid-template-rows: auto 1fr 1fr auto;
  grid-template-areas:
    "sidebar  header  header"
    "sidebar  stats   chart"
    "sidebar  table   notifications"
    "sidebar  footer  footer";
  gap: 16px;
  min-height: 100vh;
  padding: 16px;
}

.sidebar { grid-area: sidebar; background: #2c3e50; color: white; padding: 20px; }
.header { grid-area: header; background: white; padding: 20px; border-radius: 8px; }
.stats { grid-area: stats; background: white; padding: 20px; border-radius: 8px; }
.chart { grid-area: chart; background: white; padding: 20px; border-radius: 8px; }
.table { grid-area: table; background: white; padding: 20px; border-radius: 8px; }
.notifications { grid-area: notifications; background: white; padding: 20px; border-radius: 8px; }
.footer { grid-area: footer; background: #ecf0f1; padding: 16px; border-radius: 8px; text-align: center; }

@media (max-width: 768px) {
  .dashboard {
    grid-template-columns: 1fr;
    grid-template-areas:
      "header"
      "stats"
      "chart"
      "table"
      "notifications"
      "footer";
  }
  .sidebar { display: none; }
}
```

## Poin Penting
- Gunakan `grid-template-areas` untuk mendefinisikan denah dashboard secara visual
- Panel dashboard bisa membentang beberapa baris/kolom sesuai kebutuhan
- Kombinasi `fr` dan `minmax()` untuk panel yang responsif
- Media queries mengubah tata letak menjadi vertikal di layar kecil
- Setiap panel adalah container independen yang bisa diisi dengan konten sendiri
