# Konsep CSS Grid sebagai sistem tata letak dua dimensi dalam CSS

## Analogi: Perpustakaan Digital

CSS Grid seperti papan catur raksasa di perpustakaan digital yang bisa membagi ruang menjadi baris dan kolom secara bersamaan. Berbeda dengan rak buku satu dimensi (Flexbox), Grid memungkinkan kamu mengatur buku-buku dalam grid dua dimensi—baik horizontal maupun vertikal dalam satu waktu. Ini seperti membuat denah ruangan perpustakaan dengan sekat-sekat yang bisa digabungkan atau dipisahkan.

## Penjelasan Detail

CSS Grid adalah modul tata letak dua dimensi yang dirancang untuk mengatur elemen dalam baris dan kolom secara simultan. Tidak seperti Flexbox yang hanya bekerja pada satu sumbu, Grid memberikan kontrol penuh atas kedua dimensi. Konsep utamanya terdiri dari grid container (induk) dan grid items (anak). Container mendefinisikan grid tracks (baris dan kolom) melalui properti seperti `grid-template-columns` dan `grid-template-rows`. Setiap item bisa ditempatkan secara eksplisit di sel-sel grid menggunakan nomor garis (grid lines), nama area, atau span. Grid juga mendukung penempatan otomatis (auto-placement) untuk item yang tidak diberi posisi eksplisit.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows: auto 1fr auto;
  gap: 12px;
  min-height: 300px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-item {
  background: #9C27B0;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}

.grid-item.header {
  grid-column: 1 / -1;
  background: #3F51B5;
}
```

## Poin Penting
- CSS Grid adalah sistem tata letak dua dimensi (baris dan kolom sekaligus)
- Berbeda dengan Flexbox yang satu dimensi (baris ATAU kolom)
- Grid tracks didefinisikan dengan `grid-template-columns` dan `grid-template-rows`
- Item bisa ditempatkan secara eksplisit atau otomatis
- Ideal untuk tata letak halaman secara keseluruhan dan layout kompleks
