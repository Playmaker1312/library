# Properti align-items untuk mengatur penyelarasan semua item dalam sel secara vertikal

## Analogi: Perpustakaan Digital

Jika `justify-items` mengatur posisi horizontal buku dalam kotak, `align-items` mengatur posisi vertikalnya. Apakah buku ditempelkan ke atas kotak, ke bawah, di tengah secara vertikal, atau diregangkan memenuhi tinggi kotak. Ini seperti menyesuaikan bagaimana buku dengan ukuran berbeda diposisikan secara vertikal dalam setiap sel grid.

## Penjelasan Detail

`align-items` pada grid container mengatur penyelarasan vertikal (block axis atau cross axis) dari semua grid items di dalam sel grid mereka. Nilai `stretch` (default) membuat item meregang memenuhi tinggi sel. `start` menempatkan item di tepi atas sel. `end` menempatkan di tepi bawah. `center` memusatkan item secara vertikal. `baseline` menyelaraskan item berdasarkan garis dasar teks. Properti ini mirip dengan `align-items` di Flexbox tetapi bekerja dalam konteks sel grid. Bisa ditimpa per-item dengan `align-self`. Perbedaan dengan `justify-items` adalah sumbu yang digunakan: `justify-items` untuk horizontal (inline), `align-items` untuk vertikal (block).

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 120px);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
  align-items: center;
}

.grid-start  { align-items: start; }
.grid-end    { align-items: end; }
.grid-center { align-items: center; }
.grid-stretch { align-items: stretch; }
.grid-baseline { align-items: baseline; }

.item {
  background: #E91E63;
  color: white;
  padding: 8px 16px;
  border-radius: 4px;
}
```

## Poin Penting
- `align-items` mengatur penyelarasan vertikal item dalam sel grid
- Nilai `stretch` (default) meregangkan item memenuhi tinggi sel
- Nilai `start`, `end`, `center` untuk posisi atas, bawah, tengah
- Nilai `baseline` menyelaraskan berdasarkan garis dasar teks
- Bisa ditimpa per-item menggunakan `align-self`
