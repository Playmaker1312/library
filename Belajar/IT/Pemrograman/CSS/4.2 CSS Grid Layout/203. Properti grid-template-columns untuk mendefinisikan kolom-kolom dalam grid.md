# Properti grid-template-columns untuk mendefinisikan kolom-kolom dalam grid

## Analogi: Perpustakaan Digital

Bayangkan kamu ingin membagi ruangan perpustakaan menjadi beberapa bagian vertikal: rak buku utama di kiri, area baca di tengah, dan meja sirkulasi di kanan. `grid-template-columns` adalah alat untuk menentukan berapa banyak bagian vertikal yang ada dan seberapa lebar masing-masing bagian. Kamu bisa menggunakan ukuran tetap, fleksibel, atau proporsional.

## Penjelasan Detail

`grid-template-columns` mendefinisikan jumlah dan ukuran kolom dalam grid. Setiap nilai dalam deklarasi mewakili satu kolom. Nilai bisa berupa panjang tetap (`px`, `em`), persentase, unit `fr` (fraction), fungsi `repeat()`, atau fungsi `minmax()`. Jumlah nilai menentukan jumlah kolom. Misalnya, `grid-template-columns: 200px 1fr 200px` membuat tiga kolom: dua kolom samping selebar 200px dan kolom tengah yang mengisi sisa ruang. `grid-template-columns: 1fr 1fr 1fr` membuat tiga kolom dengan lebar yang sama. Kolom-kolom ini membentuk grid lines (garis) yang diberi nomor secara otomatis dari 1 hingga N+1.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  gap: 12px;
  min-height: 200px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-container-equal {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #4CAF50;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `grid-template-columns` mendefinisikan jumlah dan ukuran kolom grid
- Setiap nilai mewakili satu kolom—jumlah nilai = jumlah kolom
- Unit `fr` mendistribusikan ruang secara proporsional
- Fungsi `repeat()` dan `minmax()` membuat definisi kolom lebih fleksibel
- Grid lines diberi nomor otomatis dari 1 hingga (jumlah kolom + 1)
