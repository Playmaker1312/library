# Fungsi minmax untuk mendefinisikan ukuran minimum dan maksimum trek grid

## Analogi: Perpustakaan Digital

Bayangkan rak buku yang bisa meregang tetapi tidak boleh lebih kecil dari 200px dan tidak lebih besar dari 400px. Ini seperti rak yang fleksibel namun memiliki batasan ukuran. Fungsi `minmax()` memberikan kemampuan untuk menentukan rentang ukuran—sebuah minimum yang harus dipenuhi dan maksimum yang tidak boleh dilewati, memberikan fleksibilitas dalam batasan yang terkontrol.

## Penjelasan Detail

Fungsi `minmax(min, max)` mendefinisikan batas ukuran minimum dan maksimum untuk grid track. Track akan tumbuh sesuai kebutuhan antara nilai minimum dan maksimum. Ini sangat berguna untuk desain responsif di mana kolom harus memiliki ukuran minimal tertentu tetapi bisa meregang jika ada ruang. Contoh umum: `grid-template-columns: repeat(auto-fill, minmax(250px, 1fr))` membuat kolom yang minimal 250px dan maksimal 1fr (mengisi ruang). Nilai minimum bisa berupa panjang tetap, auto, atau persentase. Nilai maksimum bisa berupa 1fr, panjang tetap, atau `auto`. Jika nilai minimum lebih besar dari maksimum, nilai minimum yang digunakan.

## Contoh Kode Implementasi

```css
.grid-minmax {
  display: grid;
  grid-template-columns: repeat(3, minmax(150px, 1fr));
  gap: 12px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-minmax-auto {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 12px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #E91E63;
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `minmax(min, max)` menetapkan rentang ukuran minimum dan maksimum
- Track akan berada di antara nilai min dan max tergantung ruang yang ada
- Sering dikombinasikan dengan `repeat()` dan `auto-fill` untuk responsivitas
- Nilai minimum mencegah kolom terlalu kecil, maksimum mencegah terlalu besar
- Jika min > max, nilai min yang digunakan
