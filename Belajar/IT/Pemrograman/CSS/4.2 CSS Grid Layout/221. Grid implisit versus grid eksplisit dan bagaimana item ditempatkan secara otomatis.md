# Grid implisit versus grid eksplisit dan bagaimana item ditempatkan secara otomatis

## Analogi: Perpustakaan Digital

Grid eksplisit adalah rak yang sudah kamu rencanakan dan bangun dengan ukuran tertentu. Grid implisit adalah rak tambahan yang muncul secara otomatis ketika buku yang masuk lebih banyak dari yang direncanakan. Jika kamu mendefinisikan 6 sel tetapi ada 8 item, 2 item tambahan akan membuat baris atau kolom baru secara implisit. Sistem ini memastikan tidak ada item yang tertinggal.

## Penjelasan Detail

Grid eksplisit adalah grid yang didefinisikan secara sengaja melalui properti `grid-template-columns`, `grid-template-rows`, dan `grid-template-areas`. Grid implisit adalah trek tambahan yang dibuat secara otomatis ketika item ditempatkan di luar grid eksplisit—misalnya, karena jumlah item melebihi kapasitas grid. Secara default, item implisit akan membuat baris baru (`grid-auto-flow: row`). Ukuran trek implisit diatur oleh `grid-auto-rows` (default: `auto`) dan `grid-auto-columns`. Algoritma penempatan otomatis mengisi sel secara berurutan: kiri ke kanan, atas ke bawah. Memahami perbedaan ini penting untuk mengontrol bagaimana item ekstra ditangani.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 80px 80px;
  grid-auto-rows: 60px;
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #3F51B5;
  color: white;
  padding: 16px;
  border-radius: 4px;
  text-align: center;
}

.item:nth-child(n+7) {
  background: #FF5722;
  /* Item 7+ masuk ke grid implisit */
}
```

## Poin Penting
- Grid eksplisit didefinisikan dengan `grid-template-columns/rows/areas`
- Grid implisit dibuat otomatis untuk item di luar grid eksplisit
- Ukuran trek implisit diatur dengan `grid-auto-rows` dan `grid-auto-columns`
- Algoritma auto-placement mengisi sel secara berurutan
- Memahami grid implisit penting untuk menangani konten dinamis
