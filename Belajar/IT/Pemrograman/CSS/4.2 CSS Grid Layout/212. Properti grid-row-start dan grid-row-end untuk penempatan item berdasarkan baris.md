# Properti grid-row-start dan grid-row-end untuk penempatan item berdasarkan baris

## Analogi: Perpustakaan Digital

Sama seperti kolom, kamu juga bisa mengatur posisi item berdasarkan baris. Misalnya, sebuah rak informasi penting yang harus membentang dari baris pertama hingga baris ketiga (secara vertikal). `grid-row-start` dan `grid-row-end` menentukan di garis baris mana item dimulai dan berakhir, memberikan kontrol penuh atas posisi vertikal item dalam grid.

## Penjelasan Detail

`grid-row-start` dan `grid-row-end` bekerja persis seperti `grid-column-start` dan `grid-column-end`, tetapi pada sumbu baris. Mereka menentukan posisi item berdasarkan nomor garis baris. Nomor garis baris dihitung dari 1 di tepi atas container. Nilai negatif menghitung dari bawah. Nilai `span` juga didukung untuk menentukan berapa banyak baris yang dicakup. Kombinasi properti kolom dan baris memungkinkan penempatan item di sel grid mana pun secara presisi. Item bisa tumpang tindih jika beberapa item ditempatkan di area yang sama, berbeda dengan aliran normal grid yang mencegah tumpang tindih.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(3, 100px);
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #4CAF50;
  color: white;
  padding: 20px;
  border-radius: 4px;
}

.item-tall {
  grid-row-start: 1;
  grid-row-end: 3;
  background: #FF5722;
}

.item-bottom {
  grid-row-start: 2;
  grid-row-end: 4;
  grid-column-start: 3;
  background: #3F51B5;
}
```

## Poin Penting
- `grid-row-start` dan `grid-row-end` menggunakan nomor grid lines baris
- Grid lines baris diberi nomor dari 1 di tepi atas container
- Nilai negatif dan `span` juga didukung untuk baris
- Dikombinasikan dengan properti kolom untuk penempatan presisi
- Item bisa tumpang tindih jika ditempatkan di area grid yang sama
