# Properti grid-auto-flow untuk mengontrol algoritma penempatan otomatis item

## Analogi: Perpustakaan Digital

Ketika buku baru masuk ke perpustakaan tanpa posisi yang ditentukan, sistem harus memutuskan bagaimana menempatkannya: apakah mengisi rak dari kiri ke kanan dulu baru ke bawah (row), atau dari atas ke bawah dulu baru ke samping (column). `grid-auto-flow` adalah pengaturan yang menentukan arah pengisian ini, seperti memilih apakah rak diisi secara horizontal atau vertikal terlebih dahulu.

## Penjelasan Detail

`grid-auto-flow` mengontrol algoritma yang digunakan untuk menempatkan item yang tidak diberi posisi eksplisit. Nilai `row` (default) mengisi grid baris per baris—item ditempatkan dari kiri ke kanan, lalu pindah ke baris berikutnya. Nilai `column` mengisi kolom per kolom—item ditempatkan dari atas ke bawah, lalu pindah ke kolom berikutnya. Kata kunci `dense` bisa ditambahkan (misal `row dense`) untuk mengisi celah yang ditinggalkan oleh item yang lebih besar. Mode `dense` membuat grid terisi lebih rapat tetapi mengubah urutan visual item.

## Contoh Kode Implementasi

```css
.grid-row {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-flow: row;
  gap: 10px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-column {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-flow: column;
  gap: 10px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.grid-dense {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-flow: dense;
  gap: 10px;
  border: 2px solid #999;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #4CAF50;
  color: white;
  padding: 16px;
  border-radius: 4px;
  text-align: center;
}

.item-wide { grid-column: span 2; }
.tall { grid-row: span 2; }
```

## Poin Penting
- `grid-auto-flow: row` (default) mengisi baris per baris
- `grid-auto-flow: column` mengisi kolom per kolom
- Kata kunci `dense` mengisi celah dengan item berikutnya
- Mode `dense` menghasilkan tata letak lebih rapat tapi mengubah urutan
- Pilih sesuai dengan arah baca dan urutan konten yang diinginkan
