# Properti gap, row-gap, dan column-gap untuk mengatur jarak antar sel grid

## Analogi: Perpustakaan Digital

Bayangkan lantai perpustakaan dengan ubin-ubin persegi. `gap` adalah nat atau celah antar ubin yang konsisten. Daripada memberi margin pada setiap ubin satu per satu, kamu cukup menentukan jarak antar ubin langsung pada lantainya. `column-gap` mengatur jarak vertikal antar kolom, `row-gap` mengatur jarak horizontal antar baris, dan `gap` mengatur keduanya sekaligus.

## Penjelasan Detail

`gap`, `row-gap`, dan `column-gap` di CSS Grid berfungsi sama seperti di Flexbox—mengatur jarak antar grid tracks. `gap` adalah shorthand untuk `row-gap` dan `column-gap`. Jika hanya satu nilai diberikan, itu berlaku untuk kedua arah. `row-gap` mengatur jarak antar baris, `column-gap` mengatur jarak antar kolom. Nilai bisa dalam px, em, atau persentase. `gap` tidak menambahkan jarak di tepi container—hanya di antara sel. Properti ini menggantikan properti lama `grid-gap`, `grid-row-gap`, dan `grid-column-gap` yang sekarang dianggap usang.

## Contoh Kode Implementasi

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
  row-gap: 30px;
  column-gap: 15px;
  border: 2px solid #333;
  padding: 8px;
}

.grid-gap-single {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 12px;
  border: 2px solid #666;
  padding: 8px;
  margin-top: 12px;
}

.item {
  background: #3F51B5;
  color: white;
  padding: 24px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `gap` adalah shorthand untuk `row-gap` dan `column-gap`
- `row-gap` untuk jarak antar baris, `column-gap` untuk jarak antar kolom
- Nilai bisa panjang (px, em) atau persentase
- Tidak menambahkan jarak di tepi container—hanya antar sel
- Menggantikan properti usang `grid-gap`, `grid-row-gap`, `grid-column-gap`
