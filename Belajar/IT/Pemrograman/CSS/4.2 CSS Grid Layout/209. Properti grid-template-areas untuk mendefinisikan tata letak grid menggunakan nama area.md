# Properti grid-template-areas untuk mendefinisikan tata letak grid menggunakan nama area

## Analogi: Perpustakaan Digital

Daripada menggunakan angka garis, kamu bisa menggambar denah perpustakaan dengan nama ruangan: "header" di atas, "sidebar" di kiri, "konten" di tengah, "footer" di bawah. `grid-template-areas` memungkinkan kamu mendefinisikan tata letak grid menggunakan nama-nama yang mudah diingat, membuat kode lebih intuitif dan mudah dibaca seperti melihat denah.

## Penjelasan Detail

`grid-template-areas` mendefinisikan grid template dengan mereferensikan nama area yang ditentukan dengan properti `grid-area` pada item. Setiap string dalam deklarasi mewakili satu baris grid, dan setiap nama dalam string mewakili satu sel. Titik (`.`) digunakan untuk sel kosong. Nama yang sama yang berdekatan akan digabung menjadi satu area (harus berbentuk persegi panjang). Properti ini membuat tata letak sangat mudah dipahami dan diubah—cukup dengan mengatur ulang nama area dalam string, seluruh layout berubah tanpa perlu mengubah properti item individual.

## Contoh Kode Implementasi

```css
.grid-layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 12px;
  min-height: 300px;
  border: 2px solid #333;
  padding: 8px;
}

.header  { grid-area: header;  background: #3F51B5; }
.sidebar { grid-area: sidebar; background: #FF9800; }
.main    { grid-area: main;    background: #4CAF50; }
.footer  { grid-area: footer;  background: #607D8B; }

.item {
  color: white;
  padding: 20px;
  border-radius: 4px;
  text-align: center;
}
```

## Poin Penting
- `grid-template-areas` menggunakan nama string untuk mendefinisikan layout
- Setiap string adalah satu baris, setiap nama dalam string adalah satu kolom
- Titik (.) mewakili sel kosong dalam grid
- Nama area yang sama dan berdekatan membentuk area persegi panjang
- Sangat intuitif dan mudah dimodifikasi—ubah string saja untuk mengubah layout
