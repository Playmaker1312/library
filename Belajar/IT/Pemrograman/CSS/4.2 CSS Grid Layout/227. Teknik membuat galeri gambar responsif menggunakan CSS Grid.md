# Teknik membuat galeri gambar responsif menggunakan CSS Grid

## Analogi: Perpustakaan Digital

Galeri gambar adalah seperti dinding perpustakaan yang dipenuhi bingkai foto berbagai ukuran. CSS Grid memungkinkan kamu mengatur gambar-gambar ini dalam grid yang rapi, dengan jumlah kolom yang otomatis menyesuaikan lebar layar. Beberapa gambar bisa lebih besar (featured) sementara yang lain ukuran standar, semuanya tertata rapi tanpa celah yang tidak diinginkan.

## Penjelasan Detail

Galeri gambar responsif dengan CSS Grid menggunakan `repeat(auto-fill, minmax())` untuk membuat kolom yang otomatis menyesuaikan dengan lebar container. Setiap gambar ditempatkan dalam grid items. Dengan properti `object-fit: cover`, gambar bisa mengisi sel secara proporsional tanpa distorsi. Untuk galeri yang lebih menarik, beberapa gambar bisa diberi ukuran lebih besar menggunakan `grid-column: span 2` atau `grid-row: span 2`. Kombinasi `grid-auto-flow: dense` membuat galeri terisi rapat tanpa celah, meskipun mengubah urutan gambar. `gap` memberikan jarak konsisten antar gambar.

## Contoh Kode Implementasi

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  grid-auto-rows: 200px;
  gap: 10px;
  padding: 10px;
}

.gallery-item {
  overflow: hidden;
  border-radius: 8px;
}

.gallery-item img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
  transition: transform 0.3s;
}

.gallery-item:hover img {
  transform: scale(1.05);
}

.gallery-item.featured {
  grid-column: span 2;
  grid-row: span 2;
}

.gallery-item.wide {
  grid-column: span 2;
}

.gallery-item.tall {
  grid-row: span 2;
}
```

## Poin Penting
- `repeat(auto-fill, minmax(200px, 1fr))` untuk kolom responsif otomatis
- `object-fit: cover` pada gambar menjaga proporsi tanpa distorsi
- `grid-auto-flow: dense` mengisi celah untuk tampilan lebih rapat
- Beberapa gambar bisa diberi ukuran lebih besar dengan span
- `gap` memberikan jarak konsisten antar gambar
