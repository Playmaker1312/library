# Properti user-select untuk Kontrol Seleksi Teks

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki beberapa jenis konten: buku yang bisa disorot dan disalin, judul halaman yang sebaiknya tidak bisa dipilih secara tidak sengaja, dan kode program yang mudah dipilih untuk disalin. Mengontrol bagian mana yang bisa dipilih oleh pengguna meningkatkan pengalaman dan mencegah frustrasi. `user-select` memberikan kontrol ini dalam CSS.

## Penjelasan Detail

Properti `user-select` mengontrol apakah teks dalam elemen dapat dipilih oleh pengguna. Nilai `auto` (default) membiarkan browser menentukan selektabilitas berdasarkan konteks—teks biasanya bisa dipilih, konten dari elemen dengan `contenteditable` bisa dipilih. Nilai `none` mencegah seleksi teks sama sekali. Nilai `text` memungkinkan seleksi teks pada elemen tersebut. Nilai `all` memungkinkan satu klik untuk memilih seluruh konten elemen. Nilai `contain` memungkinkan seleksi dimulai dalam elemen tetapi tidak keluar dari batasnya. Properti ini berguna untuk UI seperti tombol, ikon, navigasi, panel kontrol, dan konten yang tidak boleh disalin. Namun, properti ini tidak menggantikan langkah keamanan—pengguna tetap bisa menyalin konten melalui DevTools.

## Contoh Kode Implementasi

```css
/* Cegah seleksi pada UI interaktif */
button, nav, .toolbar, .icon {
  user-select: none;
  -webkit-user-select: none;
  -moz-user-select: none;
  -ms-user-select: none;
}

/* Pilih seluruh konten dengan satu klik */
.code-block {
  user-select: all;
}

/* Batasi seleksi dalam elemen */
.modal-content {
  user-select: contain;
}

/* Izinkan seleksi teks secara eksplisit */
.editable-text {
  user-select: text;
}

/* Cegah seleksi pada sidebar, izinkan pada konten utama */
.sidebar {
  user-select: none;
}

.sidebar a {
  user-select: text;
}

/* Proteksi konten premium */
.premium-content {
  user-select: none;
}

/* Peringatan: seleksi hanya pada area tertentu */
.selectable-only {
  user-select: text;
}
```

## Poin Penting
- `user-select: none` mencegah seleksi teks pada elemen.
- `user-select: all` memilih seluruh konten dengan satu klik.
- `user-select: contain` membatasi seleksi dalam batas elemen.
- Gunakan prefiks vendor (`-webkit-`, `-moz-`, `-ms-`) untuk dukungan browser yang lebih luas.
- `user-select` bukan fitur keamanan—hanya untuk kenyamanan pengguna.
