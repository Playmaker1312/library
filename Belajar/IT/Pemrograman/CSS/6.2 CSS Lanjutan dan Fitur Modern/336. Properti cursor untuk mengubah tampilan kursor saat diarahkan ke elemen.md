# Properti cursor untuk Tampilan Kursor

## Analogi: Perpustakaan Digital

Perpustakaan digital mengubah bentuk pointer mouse tergantung konteksnya. Di atas tautan, pointer berubah menjadi tangan yang menunjuk. Di atas area teks, berubah menjadi kursor teks. Saat menyeret item, berubah menjadi tanda silang. Perubahan ini memberi pengguna petunjuk visual tentang interaksi apa yang tersedia. `cursor` dalam CSS menyediakan kontrol penuh atas tampilan kursor.

## Penjelasan Detail

Properti `cursor` menentukan bentuk kursor mouse saat diarahkan ke elemen. CSS menyediakan banyak nilai bawaan: `pointer` untuk tautan, `text` untuk teks yang bisa dipilih, `move` untuk elemen yang bisa dipindah, `grab`/`grabbing` untuk elemen yang bisa diseret, `not-allowed` untuk elemen yang tidak bisa diinteraksi, `wait` untuk proses loading, `crosshair` untuk presisi, dan banyak lagi. Kita juga bisa menggunakan URL gambar kustom dengan `cursor: url('path-to-cursor'), auto;`. Fallback harus disediakan setelah URL. Properti ini penting untuk memberikan umpan balik visual yang intuitif kepada pengguna tentang interaksi yang mungkin dilakukan pada setiap elemen.

## Contoh Kode Implementasi

```css
a, button, [role="button"] {
  cursor: pointer;
}

input[type="text"], textarea {
  cursor: text;
}

.draggable {
  cursor: grab;
}

.draggable:active {
  cursor: grabbing;
}

.disabled-button {
  cursor: not-allowed;
  opacity: 0.6;
}

.loading-overlay {
  cursor: wait;
}

.precision-target {
  cursor: crosshair;
}

.help-tooltip {
  cursor: help;
}

.movable-panel {
  cursor: move;
}

.custom-cursor {
  cursor: url('pointer.svg') 4 12, auto;
}

.no-cursor {
  cursor: none;
}
```

## Poin Penting
- `cursor` memberikan petunjuk visual tentang interaksi yang tersedia pada elemen.
- Nilai umum: `pointer`, `text`, `move`, `grab`, `grabbing`, `not-allowed`, `wait`, `help`.
- Kursor kustom dapat digunakan dengan `url()` dengan fallback wajib.
- Kursor kustom memerlukan format gambar yang didukung browser (PNG, SVG, CUR).
- Gunakan `cursor: none` untuk menyembunyikan kursor (misalnya pada video player).
