# At-rule @supports untuk Deteksi Fitur Browser

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur pemindai buku otomatis, tetapi tidak semua perangkat pengunjung mendukung pemindai ini. Untuk mengatasinya, perpustakaan memeriksa kemampuan perangkat sebelum mengaktifkan fitur tersebut. Jika perangkat mendukung, tampilkan pemindai canggih; jika tidak, tampilkan formulir manual. Inilah cara kerja `@supports` dalam CSS—memeriksa apakah browser mendukung properti CSS tertentu sebelum menerapkan gaya.

## Penjelasan Detail

At-rule `@supports` memungkinkan kita menerapkan gaya CSS hanya jika browser mendukung fitur atau properti tertentu. Ini dikenal sebagai feature query. Sintaks dasarnya adalah `@supports (properti: nilai) { ... }`. Browser akan mengevaluasi kondisi dalam tanda kurung; jika properti dan nilai didukung, blok gaya akan diterapkan. Kita juga bisa menggunakan operator `not`, `and`, dan `or` untuk kondisi yang lebih kompleks, seperti `@supports not (display: grid)` atau `@supports (display: grid) and (gap: 1rem)`. Berbeda dengan pendekatan Modernizr berbasis JavaScript, `@supports` adalah solusi CSS murni yang tidak memerlukan beban tambahan. Fitur ini sangat berguna untuk progressive enhancement—menyediakan gaya dasar untuk semua browser dan gaya lanjutan hanya untuk browser yang mendukung fitur modern.

## Contoh Kode Implementasi

```css
/* Gaya dasar untuk semua browser */
.card-container {
  display: flex;
  flex-wrap: wrap;
}

/* Gaya lanjutan hanya jika browser mendukung CSS Grid */
@supports (display: grid) {
  .card-container {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
    gap: 20px;
  }
}

/* Gaya untuk browser yang mendukung backdrop-filter */
@supports (backdrop-filter: blur(10px)) or (-webkit-backdrop-filter: blur(10px)) {
  .navbar-translucent {
    background-color: rgba(255, 255, 255, 0.7);
    backdrop-filter: blur(10px);
    -webkit-backdrop-filter: blur(10px);
  }
}

/* Gaya jika tidak mendukung CSS Grid */
@supports not (display: grid) {
  .card {
    margin-bottom: 20px;
  }
}
```

## Poin Penting
- `@supports` memeriksa dukungan browser terhadap properti dan nilai CSS tertentu.
- Gunakan `not`, `and`, dan `or` untuk kondisi feature query yang kompleks.
- Ideal untuk progressive enhancement—gaya dasar untuk semua browser, gaya lanjutan untuk yang mendukung.
- Tidak memerlukan JavaScript library seperti Modernizr.
- Browser lama yang tidak mendukung `@supports` akan mengabaikan blok tersebut, jadi pastikan gaya dasar tetap berfungsi.
