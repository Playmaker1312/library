# Properti overscroll-behavior

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki peta interaktif di dalam halaman. Saat pengguna mencapai tepi peta dan terus menggulir, halaman utama di belakangnya ikut tergulir—ini mengganggu pengalaman. Idealnya, ketika pengguna mencapai batas peta, guliran harus berhenti atau memberikan efek "bounce" lokal tanpa mempengaruhi halaman di luarnya. `overscroll-behavior` memberikan kontrol atas perilaku ini.

## Penjelasan Detail

Properti `overscroll-behavior` mengontrol apa yang terjadi ketika pengguna menggulir melebihi batas scroll suatu elemen. Nilai default `auto` memungkinkan efek overscroll normal (seperti bounce pada mobile atau scroll chain ke elemen induk). Nilai `contain` mencegah scroll chain—guliran berlebih hanya mempengaruhi elemen itu sendiri tanpa menggulirkan elemen induk. Nilai `none` mencegah semua efek overscroll, termasuk bounce. Properti ini memiliki sub-properti `overscroll-behavior-x` dan `overscroll-behavior-y` untuk kontrol per sumbu. Sangat berguna untuk mencegah perilaku scroll yang tidak diinginkan pada komponen seperti sidebar, modal, peta interaktif, carousel, atau chat box yang memiliki scroll internalnya sendiri.

## Contoh Kode Implementasi

```css
.sidebar {
  overscroll-behavior: contain;
  overflow-y: auto;
  height: 100vh;
}

.modal-content {
  overscroll-behavior: none;
  overflow-y: auto;
  max-height: 80vh;
}

.map-container {
  overscroll-behavior: contain;
  overflow: scroll;
  width: 100%;
  height: 500px;
}

.chat-box {
  overscroll-behavior-y: contain;
  overflow-y: scroll;
  height: 400px;
}

.horizontal-scroll {
  overscroll-behavior-x: none;
  overflow-x: auto;
}

/* Cegah pull-to-refresh pada mobile */
body {
  overscroll-behavior-y: none;
}
```

## Poin Penting
- `contain`: cegah scroll chain ke elemen induk, izinkan efek bounce lokal.
- `none`: cegah semua efek overscroll termasuk bounce.
- `auto`: perilaku default browser (scroll chain dan bounce diizinkan).
- Gunakan sub-properti `overscroll-behavior-x` dan `overscroll-behavior-y` untuk kontrol per sumbu.
- Sangat berguna untuk komponen dengan scroll internal seperti sidebar, modal, dan peta.
