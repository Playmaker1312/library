# Properti clip-path untuk Memotong Elemen

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur pemotong foto yang memungkinkan pustakawan memotong sampul buku menjadi berbagai bentuk—lingkaran, segitiga, bintang, atau bentuk kustom lainnya. Alih-alih menggunakan editor gambar, pemotongan bisa dilakukan langsung di CSS. `clip-path` adalah gunting digital yang memotong elemen HTML menjadi bentuk geometris atau bentuk kustom apa pun.

## Penjelasan Detail

Properti `clip-path` memotong elemen ke dalam bentuk tertentu, menyembunyikan bagian yang berada di luar jalur yang ditentukan. Fungsi bentuk dasar (basic shapes) yang tersedia: `circle()` untuk lingkaran, `ellipse()` untuk elips, `inset()` untuk persegi panjang dengan sudut membulat, `polygon()` untuk poligon kustom, dan `path()` untuk jalur SVG kustom. Bentuk didefinisikan dengan koordinat relatif terhadap kotak referensi elemen. Properti ini sangat berguna untuk membuat avatar bulat, gambar dengan bentuk unik, efek transisi kreatif, slider berbentuk geometris, galeri foto artistik, dan efek pengungkapan konten. `clip-path` berbeda dengan `mask`—clip-path memotong elemen, sedangkan mask mengontrol transparansi.

## Contoh Kode Implementasi

```css
.avatar {
  width: 150px;
  height: 150px;
  clip-path: circle(50%);
  object-fit: cover;
}

.hexagon {
  width: 200px;
  height: 200px;
  clip-path: polygon(50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25%);
  object-fit: cover;
}

.rounded-card {
  clip-path: inset(0 round 16px);
  padding: 1rem;
}

.arrow-shape {
  clip-path: polygon(0% 0%, 75% 0%, 100% 50%, 75% 100%, 0% 100%);
  background: #3498db;
  padding: 2rem;
}

.star {
  width: 200px;
  height: 200px;
  background: #f1c40f;
  clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%);
}

.parallax-clip {
  clip-path: polygon(0 0, 100% 0, 100% 85%, 0 100%);
}

.diamond {
  clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
}

/* Animasi clip-path */
.element-reveal {
  clip-path: circle(0%);
  transition: clip-path 0.5s;
}

.element-reveal:hover {
  clip-path: circle(100%);
}

/* Path kustom menggunakan SVG */
.custom-path {
  clip-path: path('M0,0 L100,0 L100,80 L50,100 L0,80 Z');
}
```

## Poin Penting
- `clip-path` memotong elemen ke bentuk yang ditentukan, menyembunyikan area di luar jalur.
- Fungsi bentuk: `circle()`, `ellipse()`, `inset()`, `polygon()`, `path()`.
- `polygon()` memungkinkan bentuk kustom dengan koordinat titik-titik.
- Dapat dianimasikan dengan `transition` atau `@keyframes` untuk efek pengungkapan kreatif.
- Berbeda dengan `mask` yang mengontrol transparansi berdasarkan gambar grayscale.
