# Properti resize untuk Elemen yang Dapat Diubah Ukurannya

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki panel catatan yang bisa diperbesar atau diperkecil oleh pengguna sesuai kebutuhan. Beberapa pengguna ingin catatan yang lebar untuk menulis panjang lebar, sementara yang lain lebih suka catatan yang sempit. Dengan menyediakan gagang resize di sudut panel, pengguna dapat menyesuaikan ukuran panel sesuai preferensi mereka. `resize` dalam CSS menyediakan fungsionalitas ini untuk elemen HTML.

## Penjelasan Detail

Properti `resize` mengontrol apakah pengguna dapat mengubah ukuran elemen, dan ke arah mana. Nilai `both` mengizinkan resize horizontal dan vertikal. Nilai `horizontal` hanya mengizinkan perubahan lebar. Nilai `vertical` hanya mengizinkan perubahan tinggi. Nilai `none` (default) menonaktifkan resize. Elemen harus memiliki properti `overflow` yang tidak bernilai `visible` agar resize berfungsi—biasanya `overflow: auto` atau `overflow: hidden`. Browser akan menampilkan gagang resize di sudut kanan bawah elemen. Properti ini sangat berguna untuk `<textarea>`, panel teks, editor kode, sidebar, dan komponen yang memerlukan fleksibilitas ukuran oleh pengguna.

## Contoh Kode Implementasi

```css
textarea {
  resize: vertical;
  width: 100%;
  min-height: 100px;
  max-height: 400px;
  padding: 0.5rem;
}

.note-panel {
  resize: both;
  overflow: auto;
  width: 300px;
  height: 200px;
  min-width: 200px;
  min-height: 150px;
  max-width: 600px;
  max-height: 500px;
  border: 1px solid #ccc;
  padding: 1rem;
}

.code-editor {
  resize: vertical;
  overflow: auto;
  min-height: 200px;
  font-family: monospace;
}

.sidebar-resizable {
  resize: horizontal;
  overflow: auto;
  width: 300px;
  min-width: 200px;
  max-width: 500px;
  height: 100vh;
}

/* Nonaktifkan resize default textarea */
textarea.no-resize {
  resize: none;
}
```

## Poin Penting
- `resize` memerlukan `overflow` yang tidak bernilai `visible` untuk berfungsi.
- Nilai: `both`, `horizontal`, `vertical`, `none`.
- Gunakan `min-width`, `max-width`, `min-height`, `max-height` untuk membatasi ukuran.
- Gagang resize muncul di sudut kanan bawah elemen.
- Sangat berguna untuk textarea, panel, dan komponen yang memerlukan fleksibilitas pengguna.
