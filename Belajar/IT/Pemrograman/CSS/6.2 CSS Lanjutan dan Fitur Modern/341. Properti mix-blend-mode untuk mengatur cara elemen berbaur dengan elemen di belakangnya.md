# Properti mix-blend-mode untuk Efek Perbauran

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur stempel digital yang dapat ditempatkan di atas foto buku. Alih-alih stempel buram yang menutupi foto, stempel bisa dibuat "menyatu" dengan foto di bawahnya—warna stempel berinteraksi dengan warna foto untuk menciptakan efek artistik. `mix-blend-mode` memungkinkan efek ini dalam CSS, mengontrol bagaimana konten elemen berbaur dengan konten di belakangnya.

## Penjelasan Detail

Properti `mix-blend-mode` menentukan bagaimana konten elemen (termasuk teks, gambar, dan latar belakang) berbaur dengan konten elemen di belakangnya. Nilai-nilai mode perbauran diadopsi dari grafis dan pengeditan foto: `multiply` menggelapkan, `screen` menerangkan, `overlay` menggabungkan keduanya, `darken` dan `lighten` memilih yang lebih gelap/terang, `color-dodge` dan `color-burn` untuk efek kontras tinggi, `difference` menciptakan efek negatif, `exclusion` mirip difference tetapi lebih lembut, `hue`, `saturation`, `color`, dan `luminosity` bekerja dengan komponen warna HSL. Nilai default adalah `normal` (tanpa perbauran). Properti ini membuka kemungkinan efek visual yang kaya, seperti teks yang terukir di gambar, overlay bertekstur, efek duotone, dan komposisi artistik.

## Contoh Kode Implementasi

```css
.hero-section {
  position: relative;
  background-image: url('hero.jpg');
  background-size: cover;
}

.hero-overlay {
  position: absolute;
  inset: 0;
  background: linear-gradient(45deg, #667eea, #764ba2);
  mix-blend-mode: multiply;
  opacity: 0.8;
}

.hero-title {
  color: white;
  mix-blend-mode: overlay;
  font-size: 3rem;
}

.image-duotone {
  mix-blend-mode: screen;
  background-color: #3498db;
}

.image-duotone img {
  mix-blend-mode: multiply;
  width: 100%;
}

.texture-overlay {
  mix-blend-mode: multiply;
  opacity: 0.3;
  background-image: url('noise.png');
}

.highlight-text {
  background-color: #f1c40f;
  mix-blend-mode: multiply;
}

.difference-effect {
  mix-blend-mode: difference;
  color: white;
}

.photo-gallery img {
  transition: mix-blend-mode 0.3s;
}

.photo-gallery img:hover {
  mix-blend-mode: overlay;
}
```

## Poin Penting
- `mix-blend-mode` mengontrol perbauran elemen dengan konten di belakangnya.
- Nilai umum: `multiply`, `screen`, `overlay`, `difference`, `color`, `luminosity`.
- Efek visual tergantung pada konten di belakang elemen (background dan elemen saudara).
- Kombinasikan dengan opacity untuk efek yang lebih halus.
- Gunakan `isolation: isolate` untuk membatasi efek perbauran dalam container tertentu.
