# At-rule @layer untuk Mengelola Cascade

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki beberapa sumber aturan: kebijakan nasional, peraturan perpustakaan pusat, dan pedoman cabang lokal. Ketika terjadi konflik antara aturan dari sumber berbeda, aturan dari cabang lokal biasanya lebih diutamakan daripada kebijakan nasional karena lebih spesifik untuk konteks setempat. `@layer` dalam CSS memungkinkan kita mengelompokkan gaya ke dalam lapisan dengan prioritas yang jelas, sehingga kita bisa menentukan sumber mana yang "didengar" lebih dulu.

## Penjelasan Detail

At-rule `@layer` adalah fitur CSS yang memungkinkan pengembang mendefinisikan lapisan cascade (cascade layers) untuk mengontrol urutan prioritas gaya. Gaya dalam lapisan yang dideklarasikan lebih awal akan memiliki prioritas lebih rendah daripada gaya dalam lapisan yang dideklarasikan kemudian, terlepas dari spesifisitas selectornya. Ini memberikan kontrol yang lebih baik dibandingkan mengandalkan spesifisitas atau urutan sumber saja. Lapisan dapat didefinisikan dengan pernyataan `@layer nama { ... }` atau dengan `@layer nama;` diikuti aturan yang ditambahkan ke lapisan tersebut. Kita juga bisa mendefinisikan urutan prioritas lapisan dalam satu baris: `@layer reset, base, komponen, utilitas;`. Fitur ini sangat berguna untuk mengelola gaya dari berbagai sumber seperti library CSS (Bootstrap, Tailwind), gaya komponen, dan gaya utilitas tanpa konflik prioritas.

## Contoh Kode Implementasi

```css
/* Mendefinisikan urutan prioritas lapisan */
@layer reset, base, komponen, utilitas;

/* Gaya dalam lapisan reset */
@layer reset {
  * {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
  }
}

/* Gaya dalam lapisan base */
@layer base {
  body {
    font-family: system-ui, sans-serif;
    line-height: 1.6;
    color: #333;
  }
  
  h1, h2, h3 {
    margin-bottom: 0.5em;
    font-weight: 600;
  }
}

/* Gaya dalam lapisan komponen */
@layer komponen {
  .card {
    padding: 1rem;
    border: 1px solid #ddd;
    border-radius: 8px;
  }
}

/* Gaya dalam lapisan utilitas */
@layer utilitas {
  .text-center { text-align: center; }
  .mt-4 { margin-top: 1rem; }
}
```

## Poin Penting
- Cascade layers memberi kontrol prioritas yang independen dari spesifisitas selector.
- Lapisan yang dideklarasikan kemudian memiliki prioritas lebih tinggi.
- Berguna untuk mengelola konflik antara CSS library, komponen, dan utilitas.
- Urutan prioritas dapat didefinisikan di awal dengan pernyataan `@layer` tunggal.
- Gaya tanpa lapisan memiliki prioritas lebih tinggi daripada semua lapisan yang bernama.
