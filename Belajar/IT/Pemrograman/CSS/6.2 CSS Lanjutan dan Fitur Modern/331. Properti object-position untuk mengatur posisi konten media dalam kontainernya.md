# Properti object-position untuk Posisi Media

## Analogi: Perpustakaan Digital

Bayangkan memajang foto di bingkai dinding. Jika fotonya lebih besar dari bingkai, kita bisa memilih bagian mana yang akan terlihat—apakah wajah di tengah, pemandangan di kiri, atau bangunan di kanan. Menggeser foto dalam bingkai tanpa mengubah ukuran bingkai adalah apa yang dilakukan `object-position` pada konten media. Ini menentukan titik fokus mana yang tetap terlihat saat `object-fit: cover` memotong bagian lain.

## Penjelasan Detail

Properti `object-position` bekerja bersama `object-fit` untuk menentukan posisi konten media dalam kotak kontainernya. Nilai defaultnya adalah `50% 50%` (pusat). Nilai bisa ditentukan dalam persentase, panjang (px, em, rem), atau kata kunci seperti `top`, `bottom`, `left`, `right`, `center`. Nilai pertama mengontrol posisi horizontal, nilai kedua mengontrol posisi vertikal. Ketika `object-fit: cover` digunakan, `object-position` menentukan area mana dari gambar yang tetap terlihat saat bagian lain terpotong. Ketika `object-fit: contain`, properti ini mengontrol posisi konten dalam area yang tersedia. Properti ini sangat berguna untuk gambar dengan komposisi penting, seperti foto produk, potret wajah, atau gambar hero yang perlu mempertahankan titik fokus tertentu di berbagai ukuran layar.

## Contoh Kode Implementasi

```css
.hero-image {
  width: 100%;
  height: 400px;
  object-fit: cover;
  object-position: center 30%;
  /* Fokus pada 30% dari atas — bagus untuk foto dengan langit luas */
}

.product-image {
  width: 300px;
  height: 300px;
  object-fit: cover;
  object-position: center center;
  /* Fokus pada pusat — ideal untuk foto produk */
}

.portrait-photo {
  width: 200px;
  height: 250px;
  object-fit: cover;
  object-position: 30% top;
  /* Fokus pada wajah yang posisinya 30% dari kiri */
}

.card-thumbnail {
  width: 100%;
  height: 200px;
  object-fit: cover;
  object-position: left top;
  /* Fokus pada sudut kiri atas */
}

@media (max-width: 640px) {
  .hero-image {
    object-position: 60% center;
    /* Geser fokus untuk layar kecil */
  }
}
```

## Poin Penting
- Gunakan `object-position` bersama `object-fit` untuk kontrol posisi konten media.
- Nilai default adalah `50% 50%` (pusat).
- Nilai bisa berupa persentase, panjang, atau kata kunci (top, bottom, left, right, center).
- Sangat berguna untuk menentukan titik fokus gambar saat `object-fit: cover` memotong bagian gambar.
- Sesuaikan `object-position` di media queries untuk fokus yang optimal di berbagai perangkat.
