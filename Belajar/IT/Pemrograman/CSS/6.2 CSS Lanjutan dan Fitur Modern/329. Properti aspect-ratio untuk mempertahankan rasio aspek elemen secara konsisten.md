# Properti aspect-ratio untuk Rasio Aspek Konsisten

## Analogi: Perpustakaan Digital

Perpustakaan digital menampilkan sampul buku dalam ukuran thumbnail yang seragam. Tanpa pedoman, beberapa sampul akan terlihat gepeng atau memanjang tergantung dimensi aslinya. Dengan menetapkan rasio aspek—misalnya 3:4 untuk buku—semua sampul akan mempertahankan proporsi yang konsisten meskipun ukurannya berbeda-beda. Inilah fungsi properti `aspect-ratio` dalam CSS.

## Penjelasan Detail

Properti `aspect-ratio` diperkenalkan untuk mengatasi masalah umum dalam CSS: mempertahankan rasio aspek elemen secara konsisten tanpa menggunakan teknik hack seperti `padding-bottom` berbasis persentase. Nilai properti ini didefinisikan sebagai rasio lebar terhadap tinggi, misalnya `16 / 9` atau `1 / 1` untuk persegi. Browser akan menghitung dimensi elemen berdasarkan rasio yang ditentukan dan dimensi yang tersedia. Jika salah satu dimensi (lebar atau tinggi) sudah ditentukan, browser akan menghitung dimensi lainnya secara otomatis. Properti ini sangat berguna untuk gambar, video, iframe, card, dan container media lainnya yang memerlukan proporsi konsisten. `aspect-ratio` bekerja dengan baik dalam tata letak responsif dan grid, memastikan elemen tetap proporsional di berbagai ukuran layar.

## Contoh Kode Implementasi

```css
.video-container {
  aspect-ratio: 16 / 9;
  width: 100%;
  background: #000;
}

.video-container iframe {
  width: 100%;
  height: 100%;
}

.card-square {
  aspect-ratio: 1 / 1;
  width: 200px;
  overflow: hidden;
}

.card-square img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}

.portrait {
  aspect-ratio: 3 / 4;
  max-height: 400px;
}

.gallery-item {
  aspect-ratio: 4 / 3;
  flex: 1 1 250px;
}

.hero-section {
  aspect-ratio: 21 / 9;
  width: 100%;
  background-size: cover;
}

.circle {
  aspect-ratio: 1 / 1;
  width: 100px;
  border-radius: 50%;
}
```

## Poin Penting
- `aspect-ratio` menggantikan teknik padding-bottom hack untuk mempertahankan rasio aspek.
- Nilai ditulis sebagai rasio lebar terhadap tinggi, misalnya `16 / 9` atau `1 / 1`.
- Browser menghitung dimensi otomatis berdasarkan rasio dan dimensi yang tersedia.
- Sangat berguna untuk media containers (video, gambar, iframe) dalam tata letak responsif.
- Dikombinasikan dengan `object-fit` untuk kontrol yang lebih baik atas konten media.
