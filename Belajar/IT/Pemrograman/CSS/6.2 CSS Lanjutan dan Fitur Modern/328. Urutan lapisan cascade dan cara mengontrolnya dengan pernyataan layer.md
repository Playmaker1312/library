# Urutan dan Kontrol Cascade Layers

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki hierarki otoritas yang ketat: aturan pemerintah pusat, aturan yayasan perpustakaan, aturan manajemen cabang, dan aturan harian petugas. Aturan yang lebih rendah dalam hierarki tidak bisa mengalahkan aturan yang lebih tinggi. Namun, dalam CSS, lapisan yang dideklarasikan lebih akhir justru memiliki prioritas lebih tinggi. Memahami urutan ini adalah kunci untuk mengelola cascade layers secara efektif.

## Penjelasan Detail

Urutan prioritas dalam cascade layers ditentukan oleh urutan deklarasi lapisan. Lapisan yang muncul pertama dalam daftar `@layer` memiliki prioritas terendah, dan lapisan yang muncul terakhir memiliki prioritas tertinggi. Gaya yang tidak termasuk dalam lapisan mana pun (unlayered styles) memiliki prioritas lebih tinggi dari semua lapisan. Dalam satu lapisan, aturan cascade normal tetap berlaku: urutan sumber dan spesifisitas masih penting. Jika dua aturan dalam lapisan berbeda memiliki spesifisitas yang sama, aturan dari lapisan dengan prioritas lebih tinggi yang menang. Pernyataan `@layer` dapat digunakan untuk mendefinisikan ulang urutan lapisan, menambahkan gaya ke lapisan yang sudah ada, atau membuat lapisan baru. Kita juga bisa menggunakan lapisan bersarang (nested layers) untuk organisasi yang lebih terperinci.

## Contoh Kode Implementasi

```css
/* Mendefinisikan urutan: reset (prioritas terendah), base, komponen (tertinggi) */
@layer reset, base, komponen;

@layer reset {
  h1 { margin: 0; font-size: 2em; }
}

@layer base {
  h1 { font-size: 2.5rem; color: #333; }
}

@layer komponen {
  .title { font-size: 2rem; color: #0066cc; }
}

/* Gaya tanpa lapisan (prioritas tertinggi) */
h1 {
  font-size: 1.8rem;
}

/* Menambahkan gaya ke lapisan yang sudah ada di lain tempat */
@layer komponen {
  .title-large { font-size: 3rem; }
}

/* Nested layers */
@layer tema {
  @layer gelap {
    body { background: #111; color: #eee; }
  }
  @layer terang {
    body { background: #fff; color: #222; }
  }
}
```

## Poin Penting
- Urutan deklarasi `@layer` menentukan prioritas: yang pertama = prioritas terendah.
- Gaya tanpa lapisan (unlayered) selalu menang atas gaya dalam lapisan mana pun.
- Dalam satu lapisan, spesifisitas dan urutan sumber tetap berfungsi normal.
- Gunakan nested layers untuk organisasi prioritas yang lebih terperinci.
- Lapisan dapat dideklarasikan di berbagai file dan ditambahkan secara bertahap.
