# Properti background-blend-mode untuk Layer Latar Belakang

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki sampul buku yang terdiri dari beberapa lapisan: foto latar, gradien warna, dan teks judul. Tanpa perbauran, lapisan-lapisan ini hanya bertumpuk buram. Dengan mengatur cara lapisan latar berbaur, pustakawan dapat menciptakan efek visual yang kaya—misalnya, gradien biru yang menyatu dengan foto hitam-putih untuk efek duotone yang dramatis. `background-blend-mode` memungkinkan ini terjadi antar lapisan latar belakang.

## Penjelasan Detail

Properti `background-blend-mode` mengontrol cara beberapa gambar atau warna latar belakang pada elemen yang sama berbaur satu sama lain. Ketika sebuah elemen memiliki beberapa lapisan latar belakang (dideklarasikan dalam properti `background` dengan nilai yang dipisahkan koma), `background-blend-mode` menentukan mode perbauran antar lapisan tersebut. Nilai-nilai yang tersedia sama dengan `mix-blend-mode`: `multiply`, `screen`, `overlay`, `darken`, `lighten`, `color-dodge`, `color-burn`, `difference`, `exclusion`, `hue`, `saturation`, `color`, `luminosity`, dan `normal`. Properti ini sangat berguna untuk menciptakan efek duotone, overlay berwarna pada gambar, tekstur pada latar belakang, dan efek visual kreatif lainnya tanpa memerlukan elemen HTML tambahan atau JavaScript.

## Contoh Kode Implementasi

```css
/* Efek duotone dengan gambar dan gradien */
.duotone-card {
  background:
    linear-gradient(135deg, #667eea 0%, #764ba2 100%),
    url('photo.jpg') center/cover;
  background-blend-mode: multiply;
  width: 300px;
  height: 200px;
}

/* Overlay warna pada tekstur */
.textured-bg {
  background:
    linear-gradient(rgba(52,152,219,0.8), rgba(52,152,219,0.8)),
    url('texture.png');
  background-blend-mode: multiply;
}

/* Efek vintage */
.vintage-bg {
  background:
    radial-gradient(circle, #f5d6a8, #c4956a),
    url('old-photo.jpg') center/cover;
  background-blend-mode: overlay;
}

/* Efek screen untuk tampilan cerah */
.bright-bg {
  background:
    linear-gradient(45deg, #ff6b6b, #ffd93d),
    url('dark-bg.jpg') center/cover;
  background-blend-mode: screen;
}

/* Gradien berbaur dengan gambar */
.hero-banner {
  background:
    linear-gradient(to right, #000, transparent, transparent, #000),
    radial-gradient(circle at 20% 50%, #ff6b6b44, transparent),
    url('banner.jpg') center/cover;
  background-blend-mode: multiply, normal;
  height: 500px;
}
```

## Poin Penting
- `background-blend-mode` mengontrol perbauran antar lapisan dalam properti `background` yang sama.
- Bekerja dengan beberapa gambar latar dan gradien yang dideklarasikan dalam satu properti `background`.
- Nilai mode perbauran sama dengan `mix-blend-mode`, termasuk `multiply`, `screen`, `overlay`.
- Tidak memerlukan elemen HTML tambahan—semua efek dalam satu elemen.
- Kombinasikan dengan `background-size`, `background-position`, dan `background-repeat` untuk kontrol penuh.
