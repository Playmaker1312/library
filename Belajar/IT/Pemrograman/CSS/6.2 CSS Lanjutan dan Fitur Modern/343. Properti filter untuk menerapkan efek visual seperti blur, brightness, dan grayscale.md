# Properti filter untuk Efek Visual

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur pengeditan foto untuk sampul buku. Pustakawan dapat mengaburkan bagian sensitif, mencerahkan foto yang gelap, mengubah ke hitam-putih, atau menambahkan bayangan. Alih-alih menggunakan software terpisah, semua efek ini bisa diterapkan langsung melalui CSS pada elemen HTML. `filter` adalah properti yang menyediakan fungsi-fungsi efek visual seperti blur, brightness, contrast, grayscale, dan lainnya.

## Penjelasan Detail

Properti `filter` menerapkan efek grafis seperti yang ada di software pengeditan foto ke elemen HTML. Efek diterapkan setelah elemen dan anak-anaknya di-render, mempengaruhi output visual akhir. Fungsi-fungsi yang tersedia: `blur()` untuk keburaman, `brightness()` untuk kecerahan, `contrast()` untuk kontras, `grayscale()` untuk hitam-putih, `sepia()` untuk efek sepia, `hue-rotate()` untuk perputaran warna, `saturate()` untuk saturasi, `invert()` untuk pembalikan warna, `opacity()` untuk transparansi, `drop-shadow()` untuk bayangan, dan `url()` untuk filter SVG kustom. Nilai dapat digabungkan dengan spasi. Properti ini sangat berguna untuk efek hover, transisi gambar, efek loading, dark mode, dan efek visual kreatif lainnya.

## Contoh Kode Implementasi

```css
.image-blur {
  filter: blur(4px);
  transition: filter 0.3s;
}

.image-blur:hover {
  filter: blur(0);
}

.grayscale-image {
  filter: grayscale(100%);
  transition: filter 0.3s;
}

.grayscale-image:hover {
  filter: grayscale(0%);
}

.brightness-adjust {
  filter: brightness(1.2) contrast(1.1);
}

.hero-overlay {
  filter: brightness(0.7) saturate(1.2);
}

.sepia-effect {
  filter: sepia(80%) hue-rotate(-15deg);
}

.drop-shadow-card {
  filter: drop-shadow(0 4px 8px rgba(0,0,0,0.2));
}

.dark-mode-img {
  filter: brightness(0.8) contrast(1.2);
}

/* Efek loading skeleton */
.skeleton {
  filter: blur(2px);
  animation: pulse 1.5s infinite;
}

@keyframes pulse {
  0%, 100% { filter: blur(2px); }
  50% { filter: blur(4px); }
}

/* Multiple filters */
.artistic-effect {
  filter: contrast(1.2) saturate(1.5) sepia(0.3) hue-rotate(10deg);
}
```

## Poin Penting
- `filter` menerapkan efek grafis ke elemen setelah rendering, seperti software pengeditan foto.
- Fungsi tersedia: `blur()`, `brightness()`, `contrast()`, `grayscale()`, `sepia()`, `hue-rotate()`, `saturate()`, `invert()`, `opacity()`, `drop-shadow()`.
- Beberapa filter dapat digabungkan dalam satu deklarasi dengan spasi.
- `filter` memicu GPU acceleration untuk performa yang lebih baik.
- Gunakan transisi CSS untuk animasi filter yang halus saat interaksi pengguna.
