# Properti object-fit untuk Kontrol Media

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki bingkai foto yang ukurannya tetap, tetapi foto yang diunggah pengguna memiliki ukuran dan rasio berbeda. Beberapa foto perlu dipotong agar pas, yang lain perlu diperkecil agar muat, dan yang lainnya bisa diregangkan. Pustakawan dapat memilih bagaimana foto harus disesuaikan dengan bingkai—ini adalah fungsi `object-fit` dalam CSS untuk elemen media seperti `<img>` dan `<video>`.

## Penjelasan Detail

Properti `object-fit` mengontrol bagaimana konten elemen media (seperti gambar atau video) disesuaikan dengan ukuran kotak kontainernya. Nilai `cover` akan memotong konten untuk memenuhi container sambil mempertahankan rasio aspek. Nilai `contain` akan menskalakan konten agar muat dalam container tanpa terpotong, meninggalkan ruang kosong. Nilai `fill` akan meregangkan konten untuk memenuhi container, mengabaikan rasio aspek. Nilai `none` akan menampilkan konten dalam ukuran aslinya tanpa penskalaan. Nilai `scale-down` akan memilih ukuran terkecil antara `none` dan `contain`. Properti ini sangat penting untuk desain responsif dengan gambar, terutama dalam grid dan card yang memerlukan ukuran seragam tetapi menerima konten dengan rasio aspek beragam.

## Contoh Kode Implementasi

```css
.image-gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

.gallery-img {
  width: 100%;
  height: 250px;
}

.gallery-img.cover {
  object-fit: cover; /* Gambar dipotong untuk memenuhi container */
}

.gallery-img.contain {
  object-fit: contain; /* Gambar muat dalam container tanpa potong */
  background: #f0f0f0; /* Background terlihat di area kosong */
}

.gallery-img.fill {
  object-fit: fill; /* Gambar distorsi untuk memenuhi container */
}

.gallery-img.none {
  object-fit: none; /* Ukuran asli, bisa overflow */
}

.gallery-img.scale-down {
  object-fit: scale-down; /* Ukuran terkecil dari none dan contain */
}

.hero-banner {
  width: 100%;
  height: 400px;
  object-fit: cover;
  object-position: center 20%;
}
```

## Poin Penting
- `object-fit` hanya berlaku untuk elemen media yang diganti (replaced elements) seperti `<img>`, `<video>`, `<canvas>`.
- `cover`: potong untuk memenuhi container, `contain`: muat tanpa potong, `fill`: regangkan tanpa peduli rasio.
- `none`: ukuran asli, `scale-down`: pilih yang paling kecil antara none dan contain.
- Kombinasikan dengan `object-position` untuk mengontrol area fokus konten yang dipotong.
- Gunakan `cover` untuk thumbnail dan hero images, `contain` untuk logo dan ikon.
