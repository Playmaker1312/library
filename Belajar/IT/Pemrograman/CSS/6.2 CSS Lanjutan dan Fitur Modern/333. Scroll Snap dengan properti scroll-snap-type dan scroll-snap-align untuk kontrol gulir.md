# Scroll Snap untuk Kontrol Gulir

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki galeri buku yang bisa digulir secara horizontal. Agar setiap buku terlihat rapi, guliran harus "menempel" pada setiap item—berhenti tepat di tepi buku berikutnya, bukan di antara dua buku. Ini seperti slide presentasi yang selalu berhenti di posisi yang tepat. Scroll Snap menyediakan mekanisme ini dalam CSS, memastikan konten berhenti pada posisi yang telah ditentukan saat pengguna selesai menggulir.

## Penjelasan Detail

Scroll Snap memungkinkan kita mengontrol posisi berhenti saat pengguna menggulir kontainer scroll. Dua properti utama: `scroll-snap-type` pada kontainer dan `scroll-snap-align` pada elemen anak. `scroll-snap-type` menentukan sumbu dan tingkat keketatan snap—nilainya bisa `x`, `y`, `both`, `block`, `inline`, dikombinasikan dengan `mandatory` (wajib snap) atau `proximity` (snap hanya jika dekat). `scroll-snap-align` pada elemen anak menentukan posisi snap: `start`, `center`, atau `end`. Dengan `mandatory`, browser akan selalu menghentikan scroll pada posisi snap, sedangkan `proximity` hanya akan snap jika posisi scroll sudah cukup dekat. Scroll Snap sangat berguna untuk carousel, galeri gambar, slider, daftar horizontal, dan konten yang dibagi menjadi halaman-halaman.

## Contoh Kode Implementasi

```css
.horizontal-gallery {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  gap: 1rem;
  padding: 1rem;
}

.horizontal-gallery img {
  scroll-snap-align: center;
  flex: 0 0 300px;
  height: 200px;
  object-fit: cover;
}

.vertical-sections {
  height: 100vh;
  overflow-y: scroll;
  scroll-snap-type: y proximity;
}

.section {
  height: 100vh;
  scroll-snap-align: start;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 2rem;
}

.card-carousel {
  display: grid;
  grid-auto-flow: column;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  gap: 20px;
}

.carousel-item {
  scroll-snap-align: start;
  width: 350px;
}
```

## Poin Penting
- `scroll-snap-type` pada kontainer: tentukan sumbu (`x`, `y`, `both`) dan keketatan (`mandatory` atau `proximity`).
- `scroll-snap-align` pada anak: tentukan posisi snap (`start`, `center`, `end`).
- `mandatory` memastikan snap selalu terjadi; `proximity` hanya snap jika dekat.
- Scroll Snap bekerja dengan overflow scroll pada kontainer.
- Ideal untuk carousel, galeri, slider, dan navigasi berbasis halaman.
