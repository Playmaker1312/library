# Properti pointer-events untuk Kontrol Interaksi Mouse

## Analogi: Perpustakaan Digital

Di perpustakaan digital, beberapa area bersifat "read-only"—pengunjung bisa melihatnya tetapi tidak bisa mengklik atau berinteraksi. Misalnya, overlay transparan di atas formulir yang sedang tidak aktif. Area ini menerima tatapan (lihat) tetapi tidak menerima sentuhan (klik). `pointer-events` dalam CSS memungkinkan kita mengontrol apakah suatu elemen menjadi target peristiwa pointer atau tidak.

## Penjelasan Detail

Properti `pointer-events` mengontrol bagaimana elemen merespons peristiwa pointer seperti klik, hover, dan sentuhan. Nilai `auto` (default) membuat elemen berperilaku normal sebagai target peristiwa pointer. Nilai `none` membuat elemen tidak pernah menjadi target peristiwa pointer—klik dan hover akan menembus elemen ke elemen di bawahnya. Elemen dengan `pointer-events: none` tetap terlihat tetapi tidak bisa diinteraksi. Properti ini juga memiliki nilai spesifik untuk SVG seperti `visiblePainted`, `fill`, `stroke`, dll. `pointer-events` sangat berguna untuk membuat overlay non-interaktif, tombol yang dinonaktifkan secara visual, memperbaiki masalah klik pada elemen yang saling tumpang tindih, dan meningkatkan aksesibilitas interaksi.

## Contoh Kode Implementasi

```css
.overlay {
  position: fixed;
  inset: 0;
  background: rgba(0,0,0,0.5);
  pointer-events: none; /* Klik tembus ke elemen di bawah */
}

.modal-active .overlay {
  pointer-events: auto; /* Aktifkan overlay hanya saat modal terbuka */
}

.disabled-button {
  opacity: 0.5;
  pointer-events: none; /* Tombol tidak bisa diklik */
}

.icon-over-text {
  pointer-events: none; /* Ikon tidak menghalangi klik pada teks */
}

.click-through-wrapper {
  pointer-events: none;
}

.click-through-wrapper > * {
  pointer-events: auto; /* Anak-anak bisa diklik */
}

.tooltip-trigger:hover + .tooltip {
  pointer-events: auto;
}

.tooltip {
  pointer-events: none; /* Tooltip tidak menghalangi hover */
}

/* SVG pointer-events */
svg .interactive-path {
  pointer-events: fill; /* Hanya area fill yang merespons klik */
}
```

## Poin Penting
- `pointer-events: none` membuat elemen tidak merespons klik, hover, atau sentuhan.
- Klik akan "menembus" elemen dengan `pointer-events: none` ke elemen di bawahnya.
- Berguna untuk overlay non-interaktif, tombol disabled, dan memperbaiki konflik klik.
- Kombinasikan dengan `:hover` atau class untuk mengaktifkan/menonaktifkan interaksi secara dinamis.
- Nilai SVG seperti `fill`, `stroke`, `visiblePainted` memberikan kontrol presisi untuk grafik vektor.
