# Properti isolation untuk Stacking Context Baru

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki beberapa panel yang saling bertumpuk: panel notifikasi di atas konten utama, modal di atas notifikasi, dan tooltip di atas modal. Mengelola urutan tumpukan ini bisa rumit, terutama ketika elemen dari berbagai bagian halaman bercampur. `isolation` menyediakan cara untuk mengelompokkan elemen dalam "ruang tumpuk" mereka sendiri, seperti meletakkan sekelompok dokumen dalam map terpisah agar tidak tercampur dengan dokumen lain.

## Penjelasan Detail

Properti `isolation` adalah cara untuk membuat stacking context baru tanpa perlu properti `z-index`, `transform`, atau `opacity`. Nilai `isolate` memastikan bahwa elemen membuat stacking context baru, mengisolasi tumpukan anak-anaknya dari elemen di luar. Ini berarti anak-anak dari elemen yang di-isolate tidak akan bercampur dengan elemen lain di luar dalam hal urutan tumpukan. `isolation: auto` adalah nilai default, yang membiarkan stacking context dibuat hanya jika properti lain memicunya. Properti ini sangat berguna untuk komponen seperti dropdown, tooltip, modal, dan overlay, di mana kita ingin memastikan komponen tersebut dan anak-anaknya ditumpuk secara independen dari konten halaman lainnya.

## Contoh Kode Implementasi

```css
.dropdown-container {
  isolation: isolate;
  position: relative;
}

.dropdown-menu {
  position: absolute;
  top: 100%;
  left: 0;
  z-index: 10;
}

.tooltip-wrapper {
  isolation: isolate;
}

.tooltip {
  position: absolute;
  z-index: 100;
}

.modal-backdrop {
  isolation: isolate;
  position: fixed;
  inset: 0;
}

.modal-content {
  position: relative;
  z-index: 1;
}

/* Tanpa isolation, z-index pada elemen di dalam komponen
   bisa berinteraksi dengan z-index dari komponen lain */
.card-stack {
  isolation: isolate;
}

.card-stack .card {
  position: relative;
  z-index: 1;
}

.card-stack .card:hover {
  z-index: 2;
}

/* Mencegah mix-blend-mode bocor */
.isolated-blend {
  isolation: isolate;
  mix-blend-mode: multiply;
}
```

## Poin Penting
- `isolation: isolate` membuat stacking context baru tanpa properti pemicu lainnya.
- Mencegah elemen anak bercampur dalam urutan tumpukan dengan elemen luar.
- Sangat berguna untuk komponen yang mengandung elemen dengan z-index.
- Juga mencegah `mix-blend-mode` bocor ke elemen di luar container.
- Lebih eksplisit dan aman daripada mengandalkan z-index atau opacity untuk membuat stacking context.
