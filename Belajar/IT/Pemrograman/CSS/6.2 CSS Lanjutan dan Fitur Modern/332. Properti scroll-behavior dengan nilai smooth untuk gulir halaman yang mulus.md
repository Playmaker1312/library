# Properti scroll-behavior untuk Gulir Mulus

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki fitur "loncat ke halaman" yang memungkinkan pengguna berpindah dari daftar isi langsung ke bab tertentu. Tanpa animasi, layar akan berkedip dan pengguna kehilangan orientasi. Dengan animasi gulir yang mulus, pengguna merasa seperti meluncur dari satu bagian ke bagian lain, mempertahankan konteks visual. Inilah yang disediakan `scroll-behavior: smooth` dalam CSS.

## Penjelasan Detail

Properti `scroll-behavior` mengontrol perilaku gulir untuk elemen yang dapat di-scroll, terutama untuk navigasi anchor (`<a href="#target">`) dan metode JavaScript seperti `scrollIntoView()`. Nilai defaultnya adalah `auto`, yang menyebabkan lompatan instan. Nilai `smooth` menghasilkan animasi gulir yang mulus antara posisi saat ini dan target. Properti ini diterapkan pada elemen kontainer scroll (biasanya `html` atau `body`), bukan pada elemen target itu sendiri. `scroll-behavior` bersifat deklaratif—tidak memerlukan JavaScript atau library tambahan untuk efek gulir mulus. Namun, properti ini tidak mempengaruhi gulir manual oleh pengguna (scrolling dengan mouse wheel atau touch). Browser akan memutuskan durasi dan easing animasi secara internal.

## Contoh Kode Implementasi

```css
html {
  scroll-behavior: smooth;
}

/* Untuk container scroll tertentu */
.sidebar-nav {
  scroll-behavior: smooth;
  overflow-y: auto;
  max-height: 500px;
}

/* Nonaktifkan smooth scroll untuk pengguna yang lebih suka gerakan minimal */
@media (prefers-reduced-motion: reduce) {
  html {
    scroll-behavior: auto;
  }
}
```

```html
<nav>
  <a href="#section-1">Bagian 1</a>
  <a href="#section-2">Bagian 2</a>
  <a href="#section-3">Bagian 3</a>
</nav>
<section id="section-1"><h2>Bagian 1</h2></section>
<section id="section-2"><h2>Bagian 2</h2></section>
<section id="section-3"><h2>Bagian 3</h2></section>
```

## Poin Penting
- `scroll-behavior: smooth` diterapkan pada kontainer scroll, biasanya `html` atau `body`.
- Hanya mempengaruhi navigasi anchor dan `scrollIntoView()`, bukan gulir manual pengguna.
- Durasi dan easing animasi ditentukan oleh browser, tidak bisa dikustomisasi.
- Hormati preferensi pengguna dengan `prefers-reduced-motion: reduce`.
- Alternatif JavaScript memberikan kontrol lebih atas durasi dan easing animation.
