# Ukuran Target Interaksi yang Memadai Sesuai Rekomendasi WCAG untuk Layar Sentuh

## Analogi: Perpustakaan Digital

Bayangkan menekan tombol lift di perpustakaan — jika tombol terlalu kecil, Anda bisa salah tekan. WCAG merekomendasikan target sentuh minimal seperti tombol lift yang cukup besar untuk ditekan dengan nyaman, baik oleh jari orang dewasa maupun mereka dengan keterbatasan motorik.

## Penjelasan Detail

WCAG 2.2 Success Criterion 2.5.8 (Target Size) merekomendasikan ukuran target interaksi minimal 24x24 pixel, dengan rekomendasi yang lebih kuat di 44x44 pixel. Target interaksi mencakup tombol, link, input, kontrol form, dan elemen yang dapat diklik. Target yang terlalu kecil menyulitkan pengguna dengan tremor, gangguan motorik, atau yang menggunakan perangkat layar sentuh kecil. Prinsip penting: hitung ukuran target total (termasuk padding), bukan hanya ukuran konten visual. Jarak antar target juga penting — target yang berdekatan harus memiliki jarak yang cukup untuk menghindari salah sentuh.

## Contoh Kode Implementasi

```css
/* ==================== */
/* UKURAN TARGET DASAR */
/* ==================== */

/* Semua elemen interaktif */
button,
a,
input,
select,
textarea,
[role="button"],
[tabindex="0"] {
  /* Minimum 44x44px untuk aksesibilitas sentuh optimal */
  min-width: 44px;
  min-height: 44px;
}

/* Tombol dengan padding yang memadai */
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  min-width: 44px;
  min-height: 44px;
  padding: 12px 20px;
  /* Total height: 12px(atas) + 20px(konten) + 12px(bawah) = 44px+ */
  font-size: 1rem;
  line-height: 1.2;
  border: none;
  border-radius: 8px;
  cursor: pointer;
  -webkit-tap-highlight-color: transparent;
}

/* Tombol ikon saja — pastikan ukuran memadai */
.icon-btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 44px;
  height: 44px;
  padding: 0;
  border: none;
  border-radius: 8px;
  background: transparent;
  cursor: pointer;
}

.icon-btn svg {
  width: 24px;
  height: 24px;
}

/* Link dalam teks — perbesar area klik */
.content a {
  /* Padding ekstra untuk area klik */
  padding: 4px 2px;
  /* Jangan gunakan display: inline untuk padding vertikal */
}

/* Alternatif: gunakan inline-block */
.content a {
  display: inline-block;
  padding: 4px 4px;
  margin: -4px; /* Kompensasi layout */
}

/* ==================== */
/* FORM ELEMENTS */
/* ==================== */

/* Checkbox dan Radio — perlu area klik besar */
.checkbox-wrapper {
  display: flex;
  align-items: center;
  min-height: 44px;
  gap: 12px;
  cursor: pointer;
}

.checkbox-wrapper input[type="checkbox"],
.checkbox-wrapper input[type="radio"] {
  width: 24px;
  height: 24px;
  min-width: 44px;
  min-height: 44px;
  /* Perbesar area klik dengan -webkit-appearance */
  -webkit-appearance: none;
  appearance: none;
}

/* Toggle switch */
.toggle {
  position: relative;
  display: inline-flex;
  align-items: center;
  min-height: 44px;
  cursor: pointer;
  gap: 12px;
}

/* Range slider */
input[type="range"] {
  min-height: 44px;
  /* Thumb harus ≥ 44x44px */
}

input[type="range"]::-webkit-slider-thumb {
  width: 24px;
  height: 24px;
  /* Plus padding visual */
  -webkit-appearance: none;
}

/* ==================== */
/* NAVIGASI — menu items */
/* ==================== */

.nav-link {
  display: flex;
  align-items: center;
  min-height: 44px;
  padding: 8px 16px;
  text-decoration: none;
  color: inherit;
}

/* Dropdown items */
.dropdown-item {
  display: flex;
  align-items: center;
  min-height: 44px;
  padding: 8px 16px;
  cursor: pointer;
}

/* ==================== */
/* JARAK ANTAR TARGET */
/* ==================== */

/* Beri jarak antar elemen yang berdekatan */
.button-group {
  display: flex;
  gap: 12px; /* Jarak minimal antar tombol */
}

/* Atau margin */
.btn + .btn {
  margin-left: 12px;
}

/* Link berurutan dalam teks */
.nav-links {
  display: flex;
  gap: 8px;
}

/* ==================== */
/* RESPONSIVE — perbesar di mobile */
/* ==================== */

@media (hover: none) and (pointer: coarse) {
  /* Layar sentuh — perbesar target */
  .btn {
    min-height: 52px;
    padding: 14px 24px;
    font-size: 1.1rem;
  }

  .nav-link {
    min-height: 52px;
    padding: 12px 20px;
  }

  .icon-btn {
    width: 52px;
    height: 52px;
  }

  .form-input {
    min-height: 52px;
    padding: 14px 16px;
    font-size: 16px; /* Prevent zoom on iOS */
  }
}

/* ==================== */
/* WCAG 2.2 — pengecualian */
/* ==================== */

/*
 * Pengecualian ukuran target 24x24px:
 * - Inline links dalam paragraf (tapi tetap beri padding)
 * - Kontrol yang ada di dalam teks (seperti footnotes)
 * - Peta interaktif (tapi harus ada alternatif)
 * - Kontrol yang memiliki setara yang lebih besar
 */

/* ==================== */
/* TESTING */
/* ==================== */

/* Gunakan outline untuk visualisasi target saat development */
/* 
 * [aria-pressed],
 * [aria-expanded],
 * button,
 * a[href],
 * input:not([type="hidden"]) {
 *   outline: 2px dashed rgba(255, 0, 0, 0.3);
 * }
 */
```

## Poin Penting
- Target interaksi minimal 24x24px (WCAG 2.2 AA), rekomendasi kuat 44x44px
- Hitung ukuran total termasuk padding, bukan hanya konten visual
- Beri jarak antar target untuk menghindari salah sentuh
- Perbesar target di layar sentuh (hover: none, pointer: coarse)
