# Desain Responsif yang Mempertimbangkan Pengguna yang Memperbesar Teks Browser

## Analogi: Perpustakaan Digital

Beberapa pengunjung perpustakaan menggunakan kaca pembesar untuk membaca buku. Di web, banyak pengguna memperbesar teks browser hingga 200% karena gangguan penglihatan. Desain harus tetap berfungsi sempurna pada zoom 200% tanpa teks terpotong, tumpang tindih, atau hilang.

## Penjelasan Detail

WCAG Success Criterion 1.4.4 (Resize Text) mensyaratkan teks dapat diperbesar hingga 200% tanpa kehilangan konten atau fungsionalitas. Kuncinya adalah menggunakan unit relatif (rem, em, %, vw) daripada unit absolut (px) untuk ukuran font dan dimensi layout. Saat pengguna memperbesar teks (zoom), layout harus tetap utuh — teks tidak boleh tumpang tindih, terpotong, atau mendorong elemen keluar halaman. Teknik penting: gunakan media query berdasarkan lebar viewport (bukan zoom level), gunakan flexbox/grid yang fleksibel, hindari fixed height, dan pastikan container dapat menampung teks yang diperbesar.

## Contoh Kode Implementasi

```css
/* ==================== */
/* UNIT RELATIF — fondasi */
/* ==================== */

/* Gunakan rem untuk font size */
html {
  font-size: 100%; /* 16px default — hormati preferensi browser */
}

body {
  font-size: 1rem; /* 16px — relatif terhadap root */
}

/* Heading dalam rem */
h1 { font-size: 2rem; }  /* 32px */
h2 { font-size: 1.5rem; } /* 24px */
h3 { font-size: 1.25rem; } /* 20px */

/* Padding/margin dalam rem — ikut skala zoom */
.container {
  padding: 1rem;
  max-width: 75rem; /* 1200px — tapi tetap membesar */
}

/* ==================== */
/* LAYOUT FLEKSIBEL */
/* ==================== */

/* Hindari fixed height */
.card {
  /* Jangan: height: 300px */
  min-height: auto;
  /* Biarkan konten menentukan tinggi */
  display: flex;
  flex-direction: column;
}

/* Gunakan min-height untuk minimum, bukan fixed */
.hero-section {
  min-height: 60vh;
  padding: 2rem;
}

/* Grid yang fleksibel */
.grid-layout {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 1rem;
  /* Kolom akan menyesuaikan saat teks membesar */
}

/* Flexbox wrapping */
.nav-links {
  display: flex;
  flex-wrap: wrap;
  gap: 0.5rem;
  /* Link akan wrap ke baris baru jika perlu */
}

/* ==================== */
*/
/* TEKS TIDAK BOLEH TERPOTONG */
/* ==================== */

/* Jangan: overflow: hidden dengan text-overflow: ellipsis untuk teks penting */
/*
.card-title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
*/

/* Alternatif: biarkan teks wrap */
.card-title {
  overflow-wrap: break-word;
  word-break: break-word;
}

/* ==================== */
/* MEDIA QUERY RESPONSIF */
/* ==================== */

/* Media query tetap berdasarkan lebar viewport, bukan zoom */
@media (max-width: 768px) {
  .sidebar {
    display: none;
  }

  .content {
    width: 100%;
  }

  h1 {
    font-size: 1.5rem;
  }
}

/* ==================== */
/* CONTAINER YANG AMAN */
/* ==================== */

/* Pastikan container cukup lebar */
.content-area {
  max-width: 70rem;
  margin: 0 auto;
  padding: 1rem;
  overflow-wrap: break-word;
}

/* Form elements yang fleksibel */
.form-input {
  width: 100%;
  max-width: 100%;
  box-sizing: border-box;
  min-height: 2.5rem;
  padding: 0.5rem 0.75rem;
  font-size: inherit; /* Ikuti ukuran teks */
}

/* Tombol yang fleksibel */
.btn {
  display: inline-flex;
  align-items: center;
  padding: 0.5rem 1rem;
  font-size: inherit;
  white-space: normal; /* Teks bisa wrap jika perlu */
  min-height: 2.75rem;
}

/* ==================== */
/* IMAGE & MEDIA */
/* ==================== */

img {
  max-width: 100%;
  height: auto;
}

/* ==================== */
/* TESTING ZOOM 200% */
/* ==================== */

/*
 * Cara testing:
 * 1. Browser > View > Zoom > Zoom In (Ctrl/Cmd +)
 * 2. Zoom hingga 200%
 * 3. Periksa:
 *    - Semua teks terbaca tanpa terpotong
 *    - Layout tidak rusak
 *    - Tidak ada horizontal scroll pada elemen utama
 *    - Tombol dan form masih bisa digunakan
 *    - Navigasi masih berfungsi
 */

/* ==================== */
/* ACCESSIBLE ZOOM SAFE PATTERNS */
/* ==================== */

/* Card yang aman saat di-zoom */
.safe-card {
  display: flex;
  flex-direction: column;
  padding: 1rem;
  border: 1px solid #e2e8f0;
  border-radius: 0.5rem;
}

.safe-card h3 {
  font-size: 1.125rem;
  margin-bottom: 0.5rem;
  line-height: 1.3;
}

.safe-card p {
  font-size: 0.875rem;
  line-height: 1.5;
}

/* Navigasi horizontal yang aman */
.safe-nav {
  display: flex;
  flex-wrap: wrap;
  gap: 0.25rem;
}

.safe-nav a {
  display: flex;
  align-items: center;
  padding: 0.5rem 0.75rem;
  min-height: 2.75rem;
}

/* Hero section yang aman */
.safe-hero {
  padding: 2rem 1rem;
  min-height: auto;
}

.safe-hero h1 {
  font-size: clamp(1.5rem, 4vw, 2.5rem);
  line-height: 1.2;
}

.safe-hero p {
  font-size: clamp(0.875rem, 2vw, 1.125rem);
  max-width: 40rem;
}
```

## Poin Penting
- Gunakan unit relatif (rem, em) untuk semua ukuran font dan dimensi layout
- Hindari fixed height; gunakan min-height atau biarkan konten menentukan tinggi
- Pastikan layout menggunakan flex-wrap dan grid responsive yang adaptif
- Test dengan zoom browser hingga 200% untuk memverifikasi tidak ada konten terpotong
