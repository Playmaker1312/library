# Desain untuk Pengguna dengan Gangguan Penglihatan Warna Menggunakan Pola dan Ikon

## Analogi: Perpustakaan Digital

Di perpustakaan, buku tidak hanya dibedakan berdasarkan warna sampul — ada label nomor, strip kode, dan teks judul. Jika seseorang tidak bisa membedakan merah-hijau, mereka masih bisa menemukan buku dari informasi lain. Desain web juga harus menyediakan lebih dari sekadar warna untuk menyampaikan informasi.

## Penjelasan Detail

Sekitar 8% pria dan 0.5% wanita memiliki gangguan penglihatan warna (color blindness). Jenis yang paling umum adalah deuteranopia (kesulitan membedakan merah-hijau). Prinsip desain inklusif: jangan gunakan warna sebagai satu-satunya cara menyampaikan informasi. Gunakan kombinasi warna + ikon, warna + teks, warna + pola, atau warna + tekstur. Tools seperti Color Oracle atau Sim Daltonism membantu developer melihat tampilan website dengan berbagai jenis buta warna. Gunakan pola (pattern) dengan CSS background-image untuk grafik dan chart, tambahkan ikon pada status messages, dan gunakan label teks yang jelas.

## Poin Penting
- Jangan gunakan warna sebagai satu-satunya cara menyampaikan informasi
- Kombinasikan warna dengan ikon, teks, pola, atau underline
- Gunakan pola CSS (repeating-linear-gradient) untuk grafik dan chart
- Selalu sertakan label teks dan indikator non-warna untuk setiap status
