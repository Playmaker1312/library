# Animasi yang Bertanggung Jawab Menggunakan prefers-reduced-motion dalam CSS

## Analogi: Perpustakaan Digital

Beberapa pengunjung perpustakaan merasa pusing melihat rak buku yang bergerak atau lampu berkedip. prefers-reduced-motion adalah seperti pengaturan "mode tenang" yang bisa diaktifkan pengunjung — semua animasi menjadi pelan atau berhenti, menciptakan lingkungan yang nyaman bagi semua orang.

## Penjelasan Detail

prefers-reduced-motion adalah media query CSS yang mendeteksi preferensi pengguna terhadap animasi berkurang. Banyak pengguna dengan gangguan vestibular (seperti vertigo atau mabuk gerak) merasa tidak nyaman dengan animasi dan transisi yang berlebihan. Media query ini memungkinkan developer menyediakan alternatif tanpa animasi atau dengan gerakan minimal. Prinsipnya: animasi harus meningkatkan pengalaman, bukan menjadi penghalang. Animasi dekoratif (parallax, particle effects) harus dimatikan sepenuhnya. Animasi fungsional (loading, progress) bisa diganti dengan alternatif non-gerak.

## Contoh Kode Implementasi

```css
/* ==================== */
/* prefers-reduced-motion — pendekatan global */
/* ==================== */

/* Matikan semua animasi dan transisi yang tidak penting */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* ==================== */
/* Pendekatan selektif — lebih baik */
/* ==================== */

/* Animasi yang aman (loading spinner) — tetap berjalan */
@media (prefers-reduced-motion: reduce) {
  .spinner {
    animation: spin 2s linear infinite;
    /* Lebih lambat */
  }
}

/* Animasi dekoratif — matikan */
@media (prefers-reduced-motion: reduce) {
  .parallax-bg,
  .floating-element,
  .particle-effect,
  .animated-gradient,
  .shake-on-hover {
    animation: none !important;
    transition: none !important;
    transform: none !important;
  }
}

/* Animasi fungsional — alternatif non-gerak */
@media (prefers-reduced-motion: reduce) {
  .skeleton-loader {
    animation: none;
    background: #e5e7eb;
  }

  .progress-bar-animated {
    animation: none;
    background: linear-gradient(90deg, #6366f1 0%, #6366f1 100%);
  }
}

/* ==================== */
/* Contoh spesifik per komponen */
/* ==================== */

/* Fade in animation */
.fade-in {
  opacity: 0;
  animation: fadeIn 0.5s ease forwards;
}

@keyframes fadeIn {
  to { opacity: 1; }
}

@media (prefers-reduced-motion: reduce) {
  .fade-in {
    opacity: 1;
    animation: none;
  }
}

/* Slide up animation */
.slide-up {
  opacity: 0;
  transform: translateY(20px);
  animation: slideUp 0.6s ease forwards;
}

@keyframes slideUp {
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@media (prefers-reduced-motion: reduce) {
  .slide-up {
    opacity: 1;
    transform: none;
    animation: none;
  }
}

/* Pulse notification */
.notification-dot {
  animation: pulse 2s ease-in-out infinite;
}

@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}

@media (prefers-reduced-motion: reduce) {
  .notification-dot {
    animation: none;
    opacity: 1;
  }
}

/* Shake on error */
.shake {
  animation: shake 0.3s ease;
}

@keyframes shake {
  25% { transform: translateX(-4px); }
  75% { transform: translateX(4px); }
}

@media (prefers-reduced-motion: reduce) {
  .shake {
    animation: none;
    /* Ganti dengan highlight visual */
    outline: 3px solid #dc2626;
    outline-offset: 2px;
  }
}

/* ==================== */
/* Transisi halaman */
/* ==================== */

.page-enter {
  opacity: 0;
  transition: opacity 0.3s ease;
}

.page-enter-active {
  opacity: 1;
}

@media (prefers-reduced-motion: reduce) {
  .page-enter,
  .page-enter-active {
    transition: none;
    opacity: 1;
  }
}

/* ==================== */
/* Hover effects yang aman */
/* ==================== */

.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 24px rgba(0,0,0,0.1);
}

@media (prefers-reduced-motion: reduce) {
  .card {
    transition: none;
  }

  .card:hover {
    transform: none;
    box-shadow: 0 4px 8px rgba(0,0,0,0.1);
  }
}

/* ==================== */
/* Scroll behavior */
/* ==================== */

html {
  scroll-behavior: smooth;
}

@media (prefers-reduced-motion: reduce) {
  html {
    scroll-behavior: auto;
  }
}

/* ==================== */
/* Test prefers-reduced-motion in browser */
/* ==================== */

/*
 * Testing di Chrome DevTools:
 * 1. Buka DevTools (F12)
 * 2. Klik tiga titik ⋮ > More tools > Rendering
 * 3. Cari "Emulate CSS media feature prefers-reduced-motion"
 * 4. Pilih "prefers-reduced-motion: reduce"
 */
```

## Poin Penting
- prefers-reduced-motion mendeteksi preferensi pengguna untuk animasi minimal
- Jangan matikan semua animasi secara global — gunakan pendekatan selektif
- Animasi dekoratif dimatikan; animasi fungsional diberikan alternatif non-gerak
- Selalu test dengan browser DevTools untuk memastikan preferensi dihormati
