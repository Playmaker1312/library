# Prinsip Aksesibilitas Visual seperti Kontras Warna, Ukuran Teks, dan Area Interaksi

## Analogi: Perpustakaan Digital

Seperti perpustakaan yang harus memastikan rambu-rambu cukup jelas dibaca oleh semua pengunjung — termasuk mereka dengan gangguan penglihatan — website harus memastikan teks, tombol, dan elemen visual dapat diakses oleh semua pengguna, termasuk penyandang disabilitas visual.

## Penjelasan Detail

Aksesibilitas visual dalam CSS mencakup tiga prinsip utama: kontras warna, ukuran teks, dan area interaksi. WCAG (Web Content Accessibility Guidelines) menetapkan rasio kontras minimum 4.5:1 untuk teks normal dan 3:1 untuk teks besar. Ukuran teks harus minimal 16px sebagai ukuran dasar, dan pengguna harus bisa memperbesar hingga 200% tanpa kehilangan fungsi. Area interaksi (tombol, link) harus memiliki ukuran minimal 44x44 pixel untuk memudahkan pengguna dengan keterbatasan motorik. Warna tidak boleh menjadi satu-satunya cara menyampaikan informasi — gunakan ikon, pola, atau teks pendamping.

## Contoh Kode Implementasi

```css
/* Prinsip aksesibilitas visual dalam CSS */

/* 1. Kontras warna yang memadai */
:root {
  /* Rasio kontras minimal 4.5:1 untuk teks normal */
  --text-primary: #1a1a2e;        /* Kontras tinggi terhadap putih */
  --text-secondary: #4a4a6a;      /* Pastikan kontras ≥ 4.5:1 */
  --text-on-primary: #ffffff;     /* Teks putih di background gelap */
  --bg-primary: #ffffff;
  --bg-secondary: #f5f5fa;
}

body {
  color: var(--text-primary);
  background: var(--bg-primary);
}

/* Jangan gunakan warna sebagai satu-satunya indikator */
.error-message {
  color: #dc2626;              /* Warna merah */
  /* TAMBAHKAN ikon atau pola */
}

.error-message::before {
  content: "⚠ ";
  /* Ikon universal untuk error */
}

.success-message {
  color: #16a34a;
}

.success-message::before {
  content: "✓ ";
}

/* 2. Ukuran teks yang memadai */
html {
  font-size: 16px; /* Ukuran dasar minimal */
  /* Pengguna dapat memperbesar hingga 200% */
}

body {
  font-size: 1rem;
  line-height: 1.5;
}

/* Gunakan rem agar ukuran mengikuti preferensi pengguna */
h1 { font-size: 2rem; }
h2 { font-size: 1.5rem; }
h3 { font-size: 1.25rem; }
p { font-size: 1rem; }
small { font-size: 0.875rem; } /* Minimal 14px */

/* 3. Ukuran target interaksi */
button, 
a, 
input[type="checkbox"],
input[type="radio"],
select {
  min-width: 44px;   /* WCAG rekomendasi */
  min-height: 44px;  /* Target sentuh minimal */
}

/* Tombol dengan area klik yang memadai */
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  min-width: 44px;
  min-height: 44px;
  padding: 0.5rem 1rem;
  /* Jangan hanya padding — pastikan total area ≥ 44x44 */
}

/* Link dalam teks — perbesar area klik */
.content a {
  display: inline-block;
  padding: 4px 2px; /* Perbesar area klik */
  /* Fallback jika padding tidak cukup */
}

/* 4. Focus indicator */
:focus-visible {
  outline: 3px solid #6366f1;
  outline-offset: 2px;
  /* Jangan gunakan outline: none tanpa fallback */
}

/* 5. Jangan sembunyikan informasi dalam pseudo-element saja */
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}

/* Gunakan sr-only untuk informasi penting yang hanya untuk screen reader */
```

## Poin Penting
- Kontras warna minimal 4.5:1 untuk teks normal (WCAG AA)
- Ukuran teks minimal 16px; gunakan rem agar pengguna bisa memperbesar
- Target interaksi minimal 44x44 pixel untuk aksesibilitas sentuh
- Jangan gunakan warna sebagai satu-satunya indikator informasi
