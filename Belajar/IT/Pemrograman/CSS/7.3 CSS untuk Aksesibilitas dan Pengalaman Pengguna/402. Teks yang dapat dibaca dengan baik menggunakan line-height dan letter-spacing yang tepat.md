# Teks yang Dapat Dibaca dengan Baik Menggunakan Line-height dan Letter-spacing yang Tepat

## Analogi: Perpustakaan Digital

Seperti buku cetak yang memiliki jarak antar baris dan spasi antar huruf yang nyaman dibaca, teks di web juga memerlukan pengaturan tipografi yang tepat. Terlalu rapat membuat mata lelah, terlalu renggang membuat teks terputus-putus. Line-height dan letter-spacing adalah "napas" dari tipografi.

## Penjelasan Detail

Line-height (jarak antar baris) yang optimal untuk readability adalah 1.5-1.8 untuk teks paragraf dan 1.2-1.4 untuk heading. Letter-spacing (spasi antar huruf) yang normal adalah 0, tetapi untuk teks kecil atau kapital, sedikit tambahan spasi (0.02-0.05em) meningkatkan keterbacaan. Word-spacing juga penting — terlalu rapat atau renggang mengganggu reading flow. Prinsip penting lainnya: panjang baris ideal 45-75 karakter (termasuk spasi), gunakan unit rem untuk ukuran teks, dan pastikan warna teks memiliki kontras yang memadai terhadap background.

## Contoh Kode Implementasi

```css
/* ==================== */
/* TIPOGRAFI DASAR */
/* ==================== */

:root {
  /* Ukuran font */
  --fs-body: 1rem;         /* 16px */
  --fs-small: 0.875rem;    /* 14px */
  --fs-large: 1.125rem;    /* 18px */

  /* Line height */
  --lh-tight: 1.2;
  --lh-normal: 1.5;
  --lh-relaxed: 1.7;
  --lh-loose: 1.8;

  /* Letter spacing */
  --ls-normal: 0;
  --ls-wide: 0.05em;
  --ls-wider: 0.1em;

  /* Font */
  --ff-body: 'Inter', system-ui, -apple-system, sans-serif;
  --ff-heading: 'Inter', system-ui, -apple-system, sans-serif;
}

body {
  font-family: var(--ff-body);
  font-size: var(--fs-body);
  line-height: var(--lh-relaxed); /* 1.7 — optimal untuk body text */
  color: #1a1a2e;
  background: #ffffff;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

/* ==================== */
/* PARAGRAPH */
/* ==================== */

p {
  line-height: var(--lh-relaxed);
  margin-bottom: 1.5rem;
  max-width: 70ch; /* Batasi lebar untuk readability */
  /* 1 ch ≈ lebar karakter; 70ch ideal untuk body text */
}

/* ==================== */
/* HEADINGS */
/* ==================== */

h1, h2, h3, h4, h5, h6 {
  font-family: var(--ff-heading);
  font-weight: 700;
  line-height: 1.2; /* Tight untuk heading */
  color: #0f172a;
  margin-bottom: 0.5em;
}

h1 {
  font-size: 2.5rem;
  line-height: 1.1;
  letter-spacing: -0.02em; /* Heading besar — sedikit rapat */
}

h2 {
  font-size: 2rem;
  letter-spacing: -0.01em;
}

h3 {
  font-size: 1.5rem;
}

/* ==================== */
/* SMALL TEXT */
/* ==================== */

small, .text-small {
  font-size: var(--fs-small);
  line-height: 1.5;
  /* letter-spacing sedikit lebih longgar untuk ukuran kecil */
  letter-spacing: var(--ls-wide);
}

/* ==================== */
/* CAPS TEXT */
/* ==================== */

.text-uppercase {
  text-transform: uppercase;
  letter-spacing: var(--ls-wider); /* 0.1em — perlu spasi ekstra */
  font-weight: 600;
}

/* ==================== */
/* LINK IN TEXT */
/* ==================== */

.content a {
  color: #2563eb;
  text-decoration: underline;
  text-decoration-thickness: 1px;
  text-underline-offset: 2px;
  font-weight: 500;
}

/* ==================== */
/* LIST */
/* ==================== */

ul, ol {
  line-height: var(--lh-relaxed);
  padding-left: 1.5rem;
  margin-bottom: 1.5rem;
}

li {
  margin-bottom: 0.25rem;
}

/* ==================== */
/* BLOCKQUOTE */
/* ==================== */

blockquote {
  font-style: italic;
  line-height: var(--lh-relaxed);
  padding: 1rem 1.5rem;
  margin: 1.5rem 0;
  border-left: 4px solid #e2e8f0;
  color: #475569;
}

/* ==================== */
/* CODE */
/* ==================== */

code {
  font-family: 'JetBrains Mono', 'Fira Code', monospace;
  font-size: 0.875em;
  line-height: 1.5;
  padding: 0.125rem 0.25rem;
  background: #f1f5f9;
  border-radius: 3px;
}

pre {
  font-size: 0.875rem;
  line-height: 1.6;
  padding: 1.25rem;
  background: #1e293b;
  color: #e2e8f0;
  border-radius: 0.5rem;
  overflow-x: auto;
  max-width: 100%;
}

pre code {
  background: none;
  padding: 0;
  font-size: inherit;
  color: inherit;
}

/* ==================== */
/* RESPONSIVE TYPOGRAPHY */
/* ==================== */

/* Fluid typography dengan clamp() */
h1 {
  font-size: clamp(1.75rem, 3vw + 1rem, 3rem);
}

p {
  font-size: clamp(0.95rem, 1vw + 0.5rem, 1.125rem);
}

/* Adjust line-height untuk layar kecil */
@media (max-width: 640px) {
  body {
    line-height: 1.6;
  }

  p {
    line-height: 1.6;
  }
}

/* ==================== */
/* PRINT STYLES */
/* ==================== */

@media print {
  body {
    font-size: 12pt;
    line-height: 1.5;
    color: #000;
    background: #fff;
  }
}

/* ==================== */
/* ACCESSIBILITY — jangan fixed line-height */
/* ==================== */

/* 
 * Jangan gunakan unit px untuk line-height
 * Gunakan unitless (angka) agar proporsional terhadap ukuran font
 */

/* Buruk */
.bad { line-height: 24px; }

/* Baik */
.good { line-height: 1.6; }
```

## Poin Penting
- Line-height ideal: 1.5-1.8 untuk body text, 1.2-1.4 untuk heading
- Letter-spacing: 0 untuk normal, 0.05em untuk small/caps text
- Panjang baris ideal 45-75 karakter; gunakan max-width: 70ch
- Gunakan unitless line-height (angka) agar proporsional terhadap ukuran font
