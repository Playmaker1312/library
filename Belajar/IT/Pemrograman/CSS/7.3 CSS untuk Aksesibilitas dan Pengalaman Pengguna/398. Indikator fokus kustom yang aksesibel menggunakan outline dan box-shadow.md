# Indikator Fokus Kustom yang Aksesibel Menggunakan Outline dan Box-shadow

## Analogi: Perpustakaan Digital

Indikator fokus kustom seperti sistem sorot buku di perpustakaan digital yang bisa disesuaikan — tidak hanya outline standar, tetapi bisa berupa efek glow, border berwarna, atau animasi ringan. Namun tetap harus jelas terlihat oleh semua pengunjung, termasuk yang menggunakan kaca pembesar (screen reader).

## Penjelasan Detail

Indikator fokus kustom memberikan kontrol penuh atas tampilan fokus tanpa mengorbankan aksesibilitas. Teknik utama meliputi outline (yang paling aman dan tidak mempengaruhi layout), box-shadow (untuk efek glow atau ring), border (untuk perubahan batas), dan background (untuk perubahan latar). Penting untuk memastikan indikator fokus memiliki kontras minimal 3:1 terhadap background dan tidak terpotong oleh overflow: hidden. Beberapa teknik menggabungkan multiple shadows untuk efek fokus yang lebih menarik. Untuk browser legacy yang tidak mendukung :focus-visible, gunakan polyfill atau fallback.

## Contoh Kode Implementasi

```css
/* ==================== */
/* TEKNIK OUTLINE */
/* ==================== */

/* Outline sederhana dan aman */
.focus-ring:focus-visible {
  outline: 3px solid #6366f1;
  outline-offset: 2px;
}

/* Double outline */
.focus-double:focus-visible {
  outline: 2px solid white;
  box-shadow: 0 0 0 4px #6366f1;
}

/* ==================== */
/* TEKNIK BOX-SHADOW */
/* ==================== */

/* Glow effect */
.focus-glow:focus-visible {
  outline: none;
  box-shadow: 0 0 0 4px rgba(99, 102, 241, 0.4);
}

/* Ring effect */
.focus-ring-large:focus-visible {
  outline: none;
  box-shadow:
    0 0 0 2px #ffffff,
    0 0 0 5px #6366f1;
}

/* Inset shadow untuk compact layout */
.focus-inset:focus-visible {
  outline: none;
  box-shadow: inset 0 0 0 3px #6366f1;
}

/* Offset shadow dengan warna kontras */
.focus-offset:focus-visible {
  outline: none;
  box-shadow:
    0 0 0 2px #fff,
    0 0 0 5px #4f46e5;
  border-radius: 4px;
}

/* ==================== */
/* TEKNIK BORDER */
/* ==================== */

/* Border perubahan — hati-hati dengan layout shift */
.focus-border:focus-visible {
  outline: none;
  border: 3px solid #6366f1;
}

/* Border dengan transparent default — aman */
.focus-border-safe {
  border: 2px solid transparent;
  transition: border-color 200ms ease;
}

.focus-border-safe:focus-visible {
  border-color: #6366f1;
}

/* ==================== */
/* TEKNIK BACKGROUND */
/* ==================== */

/* Background change */
.focus-bg:focus-visible {
  outline: 2px solid #6366f1;
  background: #eef2ff;
}

/* ==================== */
/* KOMBINASI UNTUK BRANDING */
/* ==================== */

/* Focus ring dengan brand color */
.brand-focus:focus-visible {
  outline: none;
  box-shadow:
    0 0 0 2px var(--bg, white),
    0 0 0 4px var(--brand, #6366f1);
  border-radius: 6px;
}

/* Focus ring dengan gradient */
.gradient-focus:focus-visible {
  outline: none;
  box-shadow:
    0 0 0 3px white,
    0 0 0 5px #6366f1, /* Dari brand */
    0 0 15px rgba(99, 102, 241, 0.3);
}

/* ==================== */
/* RESPONSIVE FOCUS */
/* ==================== */

/* Fokus lebih besar di layar sentuh */
@media (hover: none) and (pointer: coarse) {
  .touch-focus:focus-visible {
    outline-width: 4px;
    outline-offset: 3px;
  }
}

/* ==================== */
/* REDUCED MOTION SAFE */
/* ==================== */

@media (prefers-reduced-motion: reduce) {
  .animated-focus:focus-visible {
    transition: none;
    animation: none;
  }
}

/* ==================== */
/* POLYFILL :focus-visible */
/* ==================== */

/*
 * Untuk browser yang belum mendukung :focus-visible,
 * gunakan class .focus-visible (polyfill)
 */
.js-focus-visible :focus:not(.focus-visible) {
  outline: none;
}

/* ==================== */
/* HIGH CONTRAST MODE */
/* ==================== */

@media (forced-colors: active) {
  .custom-focus:focus-visible {
    outline: 3px solid Highlight;
    outline-offset: 2px;
  }
}
```

## Poin Penting
- Outline adalah teknik paling aman karena tidak mempengaruhi layout
- Box-shadow dengan multiple layers menciptakan efek fokus yang menarik
- Pastikan indikator fokus tidak terpotong overflow: hidden
- Gunakan forced-colors media query untuk dukungan High Contrast Mode Windows
