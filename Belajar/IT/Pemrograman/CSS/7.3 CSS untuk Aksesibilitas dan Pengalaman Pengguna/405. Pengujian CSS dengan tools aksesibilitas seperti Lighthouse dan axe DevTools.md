# Pengujian CSS dengan Tools Aksesibilitas seperti Lighthouse dan axe DevTools

## Analogi: Perpustakaan Digital

Seperti inspektur perpustakaan yang memeriksa apakah rambu jelas, lorong cukup lebar, dan pencahayaan memadai untuk semua pengunjung, tools aksesibilitas mengaudit website untuk memastikan CSS dan desain memenuhi standar aksesibilitas bagi semua pengguna.

## Penjelasan Detail

Lighthouse adalah tool otomatis bawaan Chrome DevTools yang mengaudit performa, aksesibilitas, SEO, dan best practices. axe DevTools adalah ekstensi browser yang menyediakan pengujian aksesibilitas lebih mendalam dengan aturan deteksi yang komprehensif. Kedua tool ini dapat mendeteksi masalah CSS terkait aksesibilitas seperti kontras warna tidak memadai, elemen focus tidak terlihat, heading tidak berurutan, dan teks terlalu kecil. Pengujian sebaiknya dilakukan secara rutin dan terintegrasi dalam CI/CD pipeline untuk memastikan kualitas aksesibilitas terjaga.

## Contoh Kode Implementasi

```css
/* ==================== */
/* MASALAH YANG DIDETEKSI TOOLS */
/* ==================== */

/* 1. Kontras warna tidak memadai */
/* Lighthouse akan melaporkan jika rasio kontras < 4.5:1 */
.bad-contrast {
  color: #999999;        /* Terlalu terang */
  background: #ffffff;   /* Kontras tidak cukup */
}

.good-contrast {
  color: #4a5568;        /* Kontras 7.2:1 terhadap putih */
  background: #ffffff;
}

/* 2. Elemen focus tidak terlihat */
.bad-focus:focus {
  outline: none;         /* Akan terdeteksi sebagai error */
}

.good-focus:focus-visible {
  outline: 3px solid #6366f1;
  outline-offset: 2px;
}

/* 3. Heading tidak berurutan */
/* Lighthouse periksa struktur heading — jangan loncat h1 ke h4 */

/* 4. Target size terlalu kecil */
.bad-button {
  padding: 2px 4px;      /* Target terlalu kecil */
  font-size: 10px;
}

.good-button {
  min-width: 44px;
  min-height: 44px;
  padding: 12px 16px;
}

/* 5. Teks terlalu kecil */
.bad-text {
  font-size: 10px;       /* Lighthouse anggap terlalu kecil */
}

.good-text {
  font-size: 16px;       /* Ukuran minimal yang disarankan */
}

/* ==================== */
/* LIGHTHOUSE CI INTEGRATION — CSS */
/* ==================== */

/* Konfigurasi Lighthouse CI di .lighthouserc.js */

/* ==================== */
/* axe DevTools — aturan terkait CSS */
/* ==================== */

/*
 * Aturan axe yang relevan dengan CSS:
 *
 * color-contrast: Kontras warna teks dan background
 * focus-order-no-missing: Elemen focus tidak tersembunyi
 * heading-order: Urutan heading benar
 * label-content-name-mismatch: Label aksesibel
 * link-in-text-block: Link bisa dibedakan dari teks biasa
 * meta-viewport: Viewport tidak menonaktifkan zoom
 * target-size: Ukuran target interaksi memadai
 */

/* ==================== */
/* TESTING KONTRAS WARNA DI CSS */
/* ==================== */

/* Fungsi untuk cek kontras */
:root {
  /* Gunakan tools online untuk verifikasi rasio kontras */
  /* WebAIM Contrast Checker: https://webaim.org/resources/contrastchecker/ */

  /* Contoh palet yang sudah terverifikasi kontrasnya */
  --text-primary: #1a202c;      /* 15.3:1 terhadap putih */
  --text-secondary: #4a5568;   /* 7.2:1 terhadap putih */
  --text-muted: #718096;        /* 5.2:1 terhadap putih — masih AA */
  --text-on-dark: #ffffff;      /* 15.3:1 terhadap #1a202c */

  --bg-primary: #ffffff;
  --bg-secondary: #f7fafc;
  --bg-dark: #1a202c;
}

/* ==================== */
/* LIGHTHOUSE REPORT — CSS FIXES */
/* ==================== */

/* Setelah audit Lighthouse, perbaiki masalah yang ditemukan */

/* Masalah: "Background and foreground colors do not have a sufficient contrast ratio." */
/* Fix: */
.error-text {
  color: #b91c1c;   /* Ganti dari #dc2626 — lebih gelap, kontras lebih baik */
  background: #fef2f2;
}

/* Masalah: "The heading structure is not logically nested." */
/* Fix: Pastikan urutan heading: h1 → h2 → h3 → h4 */

/* Masalah: "Links do not have a discernible name." */
/* Fix: Gunakan aria-label atau teks yang jelas */
/* 
 * <a href="#" aria-label="Baca selengkapnya tentang CSS Grid">Selengkapnya</a>
 */

/* Masalah: "Document doesn't use legible font sizes." */
/* Fix: */
html {
  font-size: 100%;
}

body {
  font-size: 1rem;
}

/* ==================== */
/* axe CORE — programmatic testing */
/* ==================== */

/*
 * Integrasi axe-core dalam test suite:
 *
 * npm install axe-core --save-dev
 *
 * Cypress: cypress-axe
 * Jest: jest-axe
 * Playwright: @axe-core/playwright
 */

/* ==================== */
/* MANUAL TESTING CHECKLIST */
/* ==================== */

/*
 * 1. Zoom browser ke 200% — cek tidak ada konten terpotong
 * 2. Navigasi keyboard (Tab) — cek fokus terlihat
 * 3. Matikan CSS — cek konten masih terbaca
 * 4. Gunakan screen reader (NVDA, VoiceOver) — cek navigasi
 * 5. Cek kontras warna dengan Color Contrast Analyzer
 * 6. Cek target size dengan ruler overlay
 */
```

## Poin Penting
- Lighthouse dan axe DevTools mendeteksi masalah CSS terkait aksesibilitas secara otomatis
- Masalah umum: kontras warna, fokus tidak terlihat, heading salah urut, target terlalu kecil
- Integrasikan pengujian aksesibilitas dalam CI/CD untuk deteksi dini
- Lakukan pengujian manual (keyboard, zoom 200%, screen reader) sebagai pelengkap
