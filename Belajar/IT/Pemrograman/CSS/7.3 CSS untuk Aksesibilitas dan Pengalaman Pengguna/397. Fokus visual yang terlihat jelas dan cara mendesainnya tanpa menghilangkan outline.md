# Fokus Visual yang Terlihat Jelas dan Cara Mendesainnya Tanpa Menghilangkan Outline

## Analogi: Perpustakaan Digital

Bayangkan mencari buku di perpustakaan dengan senter — fokus visual adalah senter yang menandai elemen aktif di layar. Jika senter terlalu redup atau tidak ada, pengguna keyboard (yang tidak bisa menggunakan mouse) akan kesulitan menavigasi. Fokus visual adalah panduan bagi pengguna yang bernavigasi dengan keyboard.

## Penjelasan Detail

Fokus visual adalah indikator yang menunjukkan elemen mana yang sedang aktif/terpilih di halaman web. Indikator ini sangat penting bagi pengguna yang bernavigasi menggunakan keyboard (Tab, Shift+Tab). Praktik buruk yang umum adalah menghilangkan outline dengan `outline: none` tanpa memberikan alternatif. Praktik baik menggunakan `:focus-visible` untuk menampilkan fokus hanya saat navigasi keyboard (bukan saat klik mouse). Indikator fokus harus memiliki kontras yang cukup terhadap background dan terlihat jelas. Desain fokus kustom dapat menggunakan outline, box-shadow, border, atau kombinasi.

## Contoh Kode Implementasi

```css
/* ==================== */
/* PRAKTIK BURUK — JANGAN DITIRU */
/* ==================== */

/* Jangan lakukan ini: */
/*
*:focus {
  outline: none; /* Menghilangkan fokus sepenuhnya */
}
*/

/* ==================== */
/* PRAKTIK BAIK */
/* ==================== */

/* 1. Gunakan :focus-visible (modern) */
/* :focus-visible hanya aktif saat navigasi keyboard */
:focus-visible {
  outline: 3px solid #6366f1;
  outline-offset: 2px;
  border-radius: 2px;
}

/* 2. Fallback untuk browser yang belum mendukung :focus-visible */
:focus:not(:focus-visible) {
  outline: none;
  /* Browser modern: fokus mouse tidak menampilkan outline */
  /* Browser lama: outline tetap muncul (fallback aman) */
}

/* 3. Fokus kustom yang menarik secara visual */
.custom-focus:focus-visible {
  outline: none;
  box-shadow:
    0 0 0 3px #ffffff,    /* Ruang putih */
    0 0 0 6px #6366f1;    /* Ring fokus */
  border-radius: 4px;
}

/* 4. Focus ring untuk berbagai komponen */

/* Tombol */
.btn:focus-visible {
  outline: 2px solid #4f46e5;
  outline-offset: 2px;
}

/* Link dalam paragraf */
a:focus-visible {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
  text-decoration: underline;
  border-radius: 2px;
}

/* Input form */
input:focus-visible,
textarea:focus-visible,
select:focus-visible {
  outline: 2px solid #6366f1;
  outline-offset: -1px;
  /* Atau gunakan box-shadow */
  box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.4);
}

/* Card yang bisa di-focus */
.card:focus-visible {
  outline: 3px solid #6366f1;
  outline-offset: 2px;
}

/* Menu dropdown / listbox */
[role="menuitem"]:focus-visible,
[role="option"]:focus-visible {
  background: #eef2ff;
  outline: 2px solid #6366f1;
  outline-offset: -2px;
}

/* ==================== */
/* SKIP LINK — untuk keyboard users */
/* ==================== */

.skip-link {
  position: absolute;
  top: -40px;
  left: 0;
  background: #6366f1;
  color: white;
  padding: 8px 16px;
  z-index: 100;
  text-decoration: none;
}

.skip-link:focus {
  top: 0;
}

/* ==================== */
/* HIGH CONTRAST MODE — Windows */
/* ==================== */

@media (forced-colors: active) {
  *:focus-visible {
    outline: 3px solid CanvasText;
    outline-offset: 2px;
  }
}

/* ==================== */
/* REDUCED MOTION — untuk fokus */
/* ==================== */

@media (prefers-reduced-motion: reduce) {
  *:focus-visible {
    transition: none;
    animation: none;
  }
}
```

## Poin Penting
- Jangan pernah menghilangkan outline fokus tanpa memberikan alternatif yang jelas
- Gunakan :focus-visible untuk menampilkan fokus hanya saat navigasi keyboard
- Indikator fokus harus memiliki kontras cukup dan terlihat jelas terhadap background
- Tambahkan skip link untuk membantu pengguna keyboard melewati navigasi
