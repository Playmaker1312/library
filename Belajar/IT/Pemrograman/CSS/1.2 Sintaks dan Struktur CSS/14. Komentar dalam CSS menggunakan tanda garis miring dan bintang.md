# Komentar dalam CSS menggunakan tanda garis miring dan bintang

## Analogi: Perpustakaan Digital

Komentar dalam CSS seperti catatan tempel di perpustakaan digital — memberikan penjelasan kepada pustakawan tentang mengapa suatu aturan diterapkan, apa fungsi kode tertentu, atau peringatan tentang bagian yang kompleks. Catatan ini tidak terlihat oleh pengunjung (pengguna web) tetapi sangat membantu bagi tim yang mengelola perpustakaan.

## Penjelasan Detail

Komentar CSS diawali dengan `/*` dan diakhiri dengan `*/`. Teks di antara tanda tersebut sepenuhnya diabaikan oleh browser saat merender halaman. Komentar bisa terdiri dari satu baris atau multi-baris. Komentar berguna untuk mendokumentasikan kode, memberikan konteks tentang keputusan desain, menandai bagian yang perlu diperbaiki (TODO), atau sementara menonaktifkan aturan CSS tertentu selama debugging. Berbeda dengan HTML, CSS tidak memiliki komentar satu baris seperti `//` (walaupun beberapa preprocessor mendukungnya).

## Contoh Kode Implementasi

```css
/* ========== Reset Dasar ========== */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* Komentar multi-baris:
   Bagian ini mengatur layout utama halaman
   Menggunakan flexbox untuk tata letak responsif */
.main-layout {
  display: flex;
  gap: 2rem;
  /* background-color: lightgray; — dinonaktifkan sementara */
  padding: 20px;
}

/* TODO: Ganti warna ini dengan variable CSS nanti */
.sidebar {
  background-color: #f0f0f0;
}
```

## Poin Penting
- Komentar CSS ditulis dengan `/* ... */` dan diabaikan browser
- Berguna untuk dokumentasi, debugging, dan menandai area kode
- CSS murni tidak mendukung komentar satu baris dengan `//`
