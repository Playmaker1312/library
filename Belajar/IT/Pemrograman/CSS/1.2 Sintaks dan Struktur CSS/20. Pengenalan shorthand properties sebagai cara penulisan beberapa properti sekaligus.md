# Pengenalan shorthand properties sebagai cara penulisan beberapa properti sekaligus

## Analogi: Perpustakaan Digital

Shorthand properties CSS seperti paket bundel buku di perpustakaan digital — alih-alih mengambil buku satu per satu Anda bisa mengambil satu paket yang berisi beberapa buku sekaligus. Daripada menulis `margin-top`, `margin-right`, `margin-bottom`, `margin-left` secara terpisah, Anda cukup menulis `margin` dengan beberapa nilai yang dipisahkan spasi.

## Penjelasan Detail

Shorthand properties memungkinkan Anda mengatur beberapa properti terkait dalam satu deklarasi. Contoh umum: `margin` dan `padding` (4 sisi), `border` (width, style, color), `background` (color, image, position, repeat, size), `font` (style, weight, size, family), dan `flex` (grow, shrink, basis). Aturan penulisan nilai biasanya mengikuti arah jarum jam: atas, kanan, bawah, kiri. Jika satu nilai dihilangkan, shorthand menggunakan nilai yang diberikan untuk sisi yang berlawanan. Shorthand membuat kode lebih ringkas, tetapi hati-hati karena nilai yang tidak ditulis akan di-reset ke nilai default.

## Contoh Kode Implementasi

```css
/* Tanpa shorthand */
.element {
  margin-top: 10px;
  margin-right: 20px;
  margin-bottom: 10px;
  margin-left: 20px;
  border-width: 2px;
  border-style: solid;
  border-color: #333;
  background-color: #f0f0f0;
  background-image: none;
  background-repeat: no-repeat;
}

/* Dengan shorthand — lebih ringkas */
.element {
  margin: 10px 20px;        /* atas/bawah 10px, kiri/kanan 20px */
  border: 2px solid #333;   /* width style color */
  background: #f0f0f0;      /* nilai lain di-reset ke default */
  font: italic bold 1.2rem/1.6 'Georgia', serif;
}

/* shorthand: 4 nilai = atas kanan bawah kiri */
.example {
  padding: 10px 20px 15px 25px;
}
```

## Poin Penting
- Shorthand menggabungkan beberapa properti dalam satu deklarasi
- Urutan nilai umumnya: atas, kanan, bawah, kiri (searah jarum jam)
- Nilai yang tidak disebutkan di-reset ke nilai default — gunakan dengan hati-hati
