# Penulisan CSS yang rapi dan konsisten untuk kemudahan pemeliharaan kode

## Analogi: Perpustakaan Digital

CSS yang rapi seperti katalog perpustakaan digital yang terorganisir dengan baik. Setiap buku (aturan) ditempatkan di rak yang tepat, diberi label jelas, dan diurutkan secara logis. Ketika pustakawan baru bergabung, mereka bisa langsung memahami dan mengelola koleksi tanpa kebingungan. Kode yang berantakan seperti buku yang berserakan — sulit ditemukan dan diperbaiki.

## Penjelasan Detail

Praktik penulisan CSS yang baik mencakup: konsistensi dalam indentasi (spasi 2 atau 4), pengelompokan aturan berdasarkan fungsi (layout, tipografi, warna), penamaan kelas yang bermakna dan konsisten (misal BEM), urutan properti yang logis (positioning, box model, tipografi, visual), penggunaan komentar untuk memisahkan bagian, dan menghindari pengulangan dengan memanfaatkan shorthand. CSS yang bersih lebih mudah di-debug, diperbarui, dan diskalakan, terutama saat bekerja dalam tim atau pada proyek besar.

## Contoh Kode Implementasi

```css
/* === Penulisan CSS yang rapi dan konsisten === */

/* Variables */
:root {
  --primary: #3498db;
  --text-color: #333;
  --spacing-unit: 8px;
}

/* Layout */
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: calc(var(--spacing-unit) * 3);
}

/* Components */
.card {
  background: #fff;
  border: 1px solid #e0e0e0;
  border-radius: 4px;
  padding: calc(var(--spacing-unit) * 2);
  margin-bottom: calc(var(--spacing-unit) * 2);
}

.card__title {
  font-size: 1.25rem;
  color: var(--primary);
  margin-bottom: var(--spacing-unit);
}

.card__content {
  font-size: 0.9rem;
  color: var(--text-color);
  line-height: 1.6;
}
```

## Poin Penting
- Gunakan indentasi konsisten dan beri komentar pada bagian penting
- Kelompokkan properti secara logis untuk kemudahan pembacaan
- Gunakan konvensi penamaan seperti BEM untuk skala proyek besar
