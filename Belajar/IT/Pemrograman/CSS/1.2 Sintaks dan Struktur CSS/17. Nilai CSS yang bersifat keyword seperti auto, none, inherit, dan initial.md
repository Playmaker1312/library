# Nilai CSS yang bersifat keyword seperti auto, none, inherit, dan initial

## Analogi: Perpustakaan Digital

Keyword dalam CSS seperti perintah khusus di perpustakaan digital. `auto` berarti "atur secara otomatis", seperti rak yang menyesuaikan ukurannya dengan buku. `none` berarti "hapus/tidak ada", seperti menghilangkan label tertentu. `inherit` berarti "ikuti aturan induk", seperti anak rak yang mengikuti gaya rak utama. `initial` berarti "kembali ke default", seperti mengembalikan pengaturan ke setelan pabrik.

## Penjelasan Detail

Keyword CSS adalah nilai yang sudah ditentukan (predefined) dengan makna khusus. `auto` umumnya digunakan pada properti seperti `width`, `height`, `margin`, `overflow` untuk memberikan kontrol otomatis pada browser. `none` menghilangkan atau menonaktifkan properti seperti `border: none` atau `display: none`. `inherit` memaksa elemen untuk mewarisi nilai properti dari elemen induknya. `initial` mengembalikan properti ke nilai default-nya sesuai spesifikasi CSS. `unset` adalah kombinasi — berperilaku seperti `inherit` jika properti bisa diwarisi, atau `initial` jika tidak.

## Contoh Kode Implementasi

```css
.container {
  width: auto;              /* menyesuaikan lebar secara otomatis */
  margin: 0 auto;           /* margin kiri-kanan otomatis untuk centering */
}

.hidden {
  display: none;            /* elemen tidak ditampilkan */
  border: none;             /* tanpa border */
}

.child {
  color: inherit;           /* mewarisi warna dari induk */
  font-size: initial;       /* menggunakan ukuran font default browser */
  margin: unset;            /* menghapus margin, kembali ke perilaku default */
}
```

## Poin Penting
- Keyword CSS adalah nilai predefined dengan makna khusus
- `auto` untuk kontrol otomatis, `none` untuk menghilangkan properti
- `inherit` mewarisi dari induk, `initial` kembali ke nilai default CSS
