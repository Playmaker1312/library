# Anatomi aturan CSS yang terdiri dari selector, property, dan value

## Analogi: Perpustakaan Digital

Di perpustakaan digital, aturan CSS seperti instruksi katalog: "Semua buku fiksi (selector) harus memiliki label (property) berwarna merah (value)." Selector menentukan elemen mana yang diatur, property adalah aspek yang diubah, dan value adalah nilai yang diterapkan. Ketiganya membentuk satu aturan lengkap.

## Penjelasan Detail

Aturan CSS terdiri dari tiga komponen utama. Selector menargetkan elemen HTML yang akan diberi gaya — bisa berupa nama tag, class, ID, atau kombinasi kompleks. Property adalah aspek visual yang ingin diubah seperti `color`, `font-size`, atau `margin`. Value adalah nilai spesifik yang diterapkan pada property tersebut, misalnya `red`, `16px`, atau `10px`. Selector diikuti oleh blok deklarasi yang diapit kurung kurawal, berisi satu atau lebih deklarasi yang masing-masing terdiri dari pasangan property: value yang dipisahkan titik koma.

## Contoh Kode Implementasi

```css
/* Anatomi: selector { property: value; } */
h1 {
  color: darkblue;
  font-size: 32px;
  text-align: center;
}

.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 20px;
}

#main-title {
  border-bottom: 3px solid #3498db;
  padding-bottom: 10px;
}
```

## Poin Penting
- Selector menargetkan elemen HTML yang akan diubah gayanya
- Property adalah aspek visual yang dimodifikasi
- Value adalah nilai spesifik yang diberikan pada property
