# Cara penulisan blok deklarasi menggunakan tanda kurung kurawal

## Analogi: Perpustakaan Digital

Kurung kurawal dalam CSS seperti kotak penyimpanan di perpustakaan digital yang mengelompokkan semua instruksi untuk satu kategori buku. Setiap kotak memiliki label (selector) di luarnya, dan di dalamnya berisi kumpulan aturan (deklarasi) yang rapi. Kurung kurawal memastikan aturan-aturan untuk selector tertentu tidak tercampur dengan selector lain.

## Penjelasan Detail

Blok deklarasi diapit oleh tanda kurung kurawal buka `{` dan kurung kurawal tutup `}`. Kurung kurawal buka ditempatkan setelah selector — bisa di baris yang sama atau baris baru tergantung gaya penulisan. Semua deklarasi untuk selector tersebut ditulis di antara kedua kurung kurawal. Kurung kurawal tutup menandai akhir dari blok deklarasi. Tanpa kurung kurawal, browser tidak akan bisa membedakan di mana aturan untuk suatu selector dimulai dan berakhir, menyebabkan CSS tidak berfungsi dengan benar.

## Contoh Kode Implementasi

```css
/* Blok deklarasi diapit kurung kurawal { } */
.navbar {                          /* kurung kurawal buka */
  display: flex;
  justify-content: space-between;
  align-items: center;
  background-color: #2c3e50;
  padding: 1rem 2rem;
}                                  /* kurung kurawal tutup */

/* Style alternatif dengan kurung kurawal di baris baru */
.navbar
{
  display: flex;
  justify-content: space-between;
  align-items: center;
  background-color: #2c3e50;
  padding: 1rem 2rem;
}
```

## Poin Penting
- Kurung kurawal `{ }` membungkus semua deklarasi untuk satu selector
- Kurung kurawal buka setelah selector, kurung kurawal tutup di akhir blok
- Tanpa kurung kurawal, CSS tidak akan berfungsi dengan benar
