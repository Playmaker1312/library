# Nilai CSS yang bersifat numerik dengan berbagai satuan pengukuran

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ukuran rak buku diukur dalam berbagai satuan — sentimeter untuk dimensi fisik, inci untuk layar besar, atau "unit rak" yang relatif terhadap ukuran buku. CSS juga memiliki beragam satuan: absolut seperti cm dan piksel, atau relatif seperti persentase dan em yang menyesuaikan dengan lingkungan sekitar.

## Penjelasan Detail

Satuan numerik CSS terbagi menjadi absolut dan relatif. Satuan absolut meliputi `px` (piksel), `pt` (points), `cm`, `mm`, dan `in` (inci) — nilainya tetap. Satuan relatif lebih fleksibel: `%` (persentase dari induk), `em` (relatif terhadap font-size elemen), `rem` (relatif terhadap font-size root), `vw`/`vh` (1% dari lebar/tinggi viewport), `vmin`/`vmax` (persentase dari dimensi viewport min/max). Untuk responsivitas, satuan relatif seperti `rem`, `em`, `%`, dan `vw`/`vh` lebih disukai karena menyesuaikan dengan konteks pengguna.

## Contoh Kode Implementasi

```css
/* Satuan absolut */
.box-fixed {
  width: 300px;
  height: 200px;
  font-size: 16px;
  border: 1pt solid #000;
  margin: 0.5in;
}

/* Satuan relatif */
.box-fluid {
  width: 80%;               /* 80% dari lebar induk */
  font-size: 1.2rem;        /* 1.2x ukuran font root */
  padding: 1.5em;           /* 1.5x ukuran font elemen */
  margin: 2vw 1vh;          /* 2% lebar viewport, 1% tinggi viewport */
  min-height: 100vh;        /* minimal setinggi viewport */
}
```

## Poin Penting
- Satuan absolut (px, pt, cm) nilainya tetap dan tidak responsif
- Satuan relatif (%, em, rem, vw, vh) menyesuaikan dengan konteks
- Gunakan satuan relatif untuk desain responsif dan aksesibilitas
