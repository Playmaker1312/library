# Perbedaan antara property dan value dalam deklarasi CSS

## Analogi: Perpustakaan Digital

Dalam deklarasi CSS, property dan value seperti label kategori dan isinya di perpustakaan digital. "Property" adalah label kategori seperti "Genre" atau "Pengarang", sedangkan "value" adalah isi spesifik seperti "Fiksi" atau "J.K. Rowling". Label menentukan aspek apa yang diatur, dan value menentukan bagaimana aspek itu diterapkan.

## Penjelasan Detail

Property adalah aspek visual atau perilaku elemen yang ingin diubah, seperti `color`, `font-size`, `margin`, `display`, atau `position`. Property bersifat tetap dan ditentukan oleh spesifikasi CSS — Anda tidak bisa membuat property sendiri. Value adalah nilai spesifik yang diberikan kepada property tersebut, seperti `red`, `16px`, `10px`, `flex`, atau `absolute`. Value bisa berupa keyword, angka dengan satuan, warna, fungsi CSS, atau string. Tidak semua value valid untuk semua property; setiap property memiliki value yang didukungnya.

## Contoh Kode Implementasi

```css
/* Property (kiri) : Value (kanan) */
.element {
  color: #333;              /* property: color; value: #333 */
  font-size: 1.2rem;        /* property: font-size; value: 1.2rem */
  font-family: Arial, sans-serif; /* property: font-family; value: Arial, sans-serif */
  background: linear-gradient(to right, red, blue); /* property: background; value: fungsi gradient */
  display: grid;            /* property: display; value: grid */
  grid-template-columns: repeat(3, 1fr); /* property: grid-template-columns; value: repeat(3, 1fr) */
  transition: all 0.3s ease; /* property: transition; value: shorthand dengan multiple value */
}
```

## Poin Penting
- Property adalah aspek elemen yang diatur, ditentukan oleh spesifikasi CSS
- Value adalah nilai spesifik yang diterapkan pada property
- Setiap property memiliki kumpulan value valid yang didukungnya
