# Nilai CSS yang bersifat teks seperti nama warna dan URL

## Analogi: Perpustakaan Digital

Nilai teks dalam CSS seperti label dan alamat di perpustakaan digital. Nama warna seperti "merah" atau "biru" adalah label yang mudah diingat, seperti "Rak Fiksi" atau "Rak Referensi". URL adalah alamat lengkap seperti "Gedung A, Lantai 3, Rak 5" yang menunjuk ke sumber daya spesifik — dalam CSS, URL mengarah ke file seperti gambar atau font.

## Penjelasan Detail

Nilai teks dalam CSS meliputi string dan identifier. Nama warna (color keywords) adalah identifier predefined seperti `red`, `blue`, `green`, `transparent`, `currentColor`. CSS mendukung 148 nama warna standar. Nilai URL ditulis dengan fungsi `url()` yang berisi path ke file, seperti `url('images/bg.jpg')`. Nilai string menggunakan tanda kutip (bisa tunggal atau ganda) untuk properti seperti `content` pada pseudo-elements. Nilai identifier tanpa kutip seperti `auto`, `block`, `inline` juga termasuk nilai teks.

## Contoh Kode Implementasi

```css
/* Nama warna */
.header {
  color: white;
  background-color: steelblue;
  border-color: currentColor; /* menggunakan nilai color saat ini */
}

/* URL */
.hero {
  background-image: url('https://example.com/images/hero-bg.jpg');
  background-size: cover;
}

/* String dengan content */
.badge::before {
  content: "★ ";
  color: gold;
}

.logo::after {
  content: " (Beta)";
  font-size: 0.8em;
  color: #666;
}
```

## Poin Penting
- Nama warna adalah 148 keyword warna standar CSS
- Fungsi `url()` digunakan untuk merujuk file eksternal
- Nilai string menggunakan tanda kutip tunggal atau ganda
