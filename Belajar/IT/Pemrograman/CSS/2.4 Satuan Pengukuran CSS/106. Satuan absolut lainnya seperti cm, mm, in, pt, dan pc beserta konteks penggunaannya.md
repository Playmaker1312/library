# Satuan absolut lainnya seperti cm, mm, in, pt, dan pc beserta konteks penggunaannya

## Analogi: Perpustakaan Digital

Selain piksel, CSS mendukung satuan fisik dunia nyata seperti sentimeter (cm), milimeter (mm), inci (in), point (pt), dan pica (pc). Ini seperti menggunakan penggaris sungguhan untuk mengukur buku di perpustakaan digital. Meskipun jarang digunakan di layar, satuan ini berguna untuk output cetak di mana ukuran fisik benar-benar berarti.

## Penjelasan Detail

CSS mendukung beberapa satuan absolut fisik: cm (sentimeter), mm (milimeter), in (inci, 1in = 2.54cm = 96px), pt (point, 1pt = 1/72 inci = 1.333px), pc (pica, 1pc = 12pt = 16px). Satuan-satuan ini didefinisikan berdasarkan hubungan dengan inci dan piksel. Pada layar, satuan ini mungkin tidak selalu akurat secara fisik karena variasi resolusi dan ukuran layar. Satuan absolut fisik lebih berguna untuk media cetak (print stylesheets) di mana ukuran fisik memiliki arti. pt sering digunakan dalam tipografi cetak tradisional. cm dan mm berguna untuk layout cetak seperti brosur atau kartu. Dalam desain web modern, px, rem, dan em hampir selalu lebih praktis untuk penggunaan layar.

## Contoh Kode Implementasi

```css
/* Satuan untuk print */
@media print {
  body {
    font-size: 12pt;
    line-height: 1.4;
  }

  .page {
    width: 21cm; /* A4 width */
    min-height: 29.7cm; /* A4 height */
    padding: 2cm;
    margin: 0 auto;
  }

  h1 {
    font-size: 24pt;
    margin-bottom: 12pt;
  }

  h2 {
    font-size: 18pt;
  }

  p {
    font-size: 11pt;
    margin-bottom: 6pt;
  }

  .print-margin {
    margin: 2.5cm 2cm 2cm 2.5cm;
  }

  .indent {
    text-indent: 1.5cm;
  }

  .signature {
    margin-top: 3cm;
  }
}

/* Penggunaan di layar (kurang umum) */
.physical-size {
  width: 5cm;
  height: 5cm;
  background: #3498db;
  margin: 10px;
}

.inch-box {
  width: 2in;
  height: 2in;
  background: #e74c3c;
}

.point-text {
  font-size: 14pt;
}

/* Print-specific layout */
.print-card {
  width: 3.5in; /* business card width */
  height: 2in; /* business card height */
  padding: 0.25in;
  border: 1pt solid #333;
}

/* Margin untuk print */
.print-job {
  margin: 1in;
}

/* Pica unit */
.pica-width {
  width: 10pc;
  background: #2ecc71;
  height: 100px;
}

/* Konversi satuan */
.conversion-info {
  /* 1in = 96px */
  /* 1cm = 37.8px */
  /* 1mm = 3.78px */
  /* 1pt = 1.333px */
  /* 1pc = 16px */
}
```

## Poin Penting
- Satuan fisik CSS: cm, mm, in, pt (point), pc (pica) berdasarkan konversi ke inci dan piksel
- Paling berguna untuk print stylesheets; jarang digunakan untuk desain web layar
- pt adalah satuan tradisional tipografi; cm/mm berguna untuk layout cetak fisik
- Pada layar, akurasi fisik tidak terjamin; preferensikan px, rem, atau em untuk web
