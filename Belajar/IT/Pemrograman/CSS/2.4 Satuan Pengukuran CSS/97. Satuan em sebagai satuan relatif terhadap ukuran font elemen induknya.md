# Satuan em sebagai satuan relatif terhadap ukuran font elemen induknya

## Analogi: Perpustakaan Digital

Bayangkan ukuran buku di perpustakaan yang dinyatakan dalam "kali ukuran standar". Jika ukuran standar adalah 16pt, maka 2em berarti 32pt. Em adalah satuan yang relatif terhadap ukuran font elemen induk, seperti mengatakan "dua kali lebih besar dari ukuran buku di rak ini". Dalam perpustakaan digital, em memungkinkan ukuran yang proporsional dan mudah diskalakan.

## Penjelasan Detail

Satuan em adalah satuan relatif dalam CSS yang dihitung berdasarkan ukuran font (font-size) elemen saat ini. Jika elemen memiliki font-size 16px, maka 1em = 16px, 2em = 32px, 0.5em = 8px. Untuk properti selain font-size (seperti margin, padding, width), em dihitung berdasarkan font-size elemen itu sendiri. Untuk properti font-size, em dihitung berdasarkan font-size elemen induk. Em bersifat kumulatif: jika induk memiliki 1.5em dan anak memiliki 1.5em, hasilnya adalah 2.25em dari ukuran asli. Karena sifat kumulatif ini, em bisa sulit diprediksi dalam struktur bersarang yang dalam. Em berguna untuk membuat komponen yang skalanya proporsional terhadap ukuran font-nya.

## Contoh Kode Implementasi

```css
/* Dasar em */
.parent {
  font-size: 16px;
}

.child-em {
  font-size: 1.5em; /* = 24px */
  margin-bottom: 1em; /* = 24px (berdasarkan font-size child sendiri) */
}

/* Padding dan margin dengan em */
.button {
  font-size: 16px;
  padding: 0.75em 1.5em; /* 12px 24px */
  border-radius: 0.25em; /* 4px */
}

.button-large {
  font-size: 20px;
  padding: 0.75em 1.5em; /* 15px 30px - proporsional */
}

/* Komponen yang proporsional */
.card {
  font-size: 16px;
  padding: 1em;
  border-radius: 0.5em;
}

.card-title {
  font-size: 1.25em; /* 20px */
  margin-bottom: 0.5em;
}

.card-text {
  font-size: 0.875em; /* 14px */
  line-height: 1.5em;
}

/* Efek kumulatif em */
.grandparent {
  font-size: 20px;
}

.parent-em {
  font-size: 1.2em; /* 24px */
}

.child-em {
  font-size: 1.2em; /* 28.8px (bukan 24px) */
}

/* Border-radius dengan em */
.avatar {
  width: 3em;
  height: 3em;
  border-radius: 50%;
  font-size: 40px; /* avatar = 120px */
}

/* Width dengan em */
.text-input {
  font-size: 16px;
  width: 20em; /* 320px */
  padding: 0.5em;
}

/* Line-height dengan em */
p {
  font-size: 16px;
  line-height: 1.6em; /* 25.6px */
}
```

## Poin Penting
- 1em = ukuran font elemen saat ini; untuk font-size, em mengacu pada ukuran font induk
- Em bersifat kumulatif dalam struktur bersarang, yang bisa menyulitkan prediksi
- Em sangat berguna untuk membuat komponen yang skalanya proporsional terhadap ukuran font
- Gunakan em untuk padding, margin, border-radius pada komponen agar ukurannya proporsional terhadap teks
