# Fungsi max untuk memilih nilai terbesar dari beberapa nilai yang diberikan

## Analogi: Perpustakaan Digital

Max seperti memilih ukuran rak yang paling besar dari beberapa pilihan. Jika rak harus setidaknya 300px tetapi juga setidaknya 50% dari ruangan, kita memilih yang terbesar. Dalam perpustakaan digital, max() memastikan elemen tidak lebih kecil dari batas tertentu dengan memilih nilai terbesar dari daftar nilai yang diberikan.

## Penjelasan Detail

Fungsi max() menerima satu atau lebih nilai yang dipisahkan koma dan mengembalikan nilai terbesar di antaranya. Fungsi ini kebalikan dari min() dan berguna untuk menetapkan ukuran minimum responsif. Misalnya, width: max(300px, 50%) akan memilih 300px jika 50% kurang dari 300px, atau 50% jika lebih besar. Max sering digunakan untuk memastikan elemen memiliki ukuran minimum yang dapat diterima, terutama pada layout responsif. Max dapat mencampur berbagai satuan dan dikombinasikan dengan fungsi CSS lainnya. Bersama min() dan clamp(), max() memberikan kontrol yang presisi atas ukuran elemen dalam desain responsif.

## Contoh Kode Implementasi

```css
/* Minimum width responsif */
.element {
  width: max(300px, 50%);
  background: #3498db;
  color: white;
  padding: 20px;
}

/* Container dengan minimum */
.container {
  width: max(70%, 960px);
  margin: 0 auto;
}

/* Font size minimum */
h1 {
  font-size: max(3.2rem, 4vw);
}

/* Padding minimum */
.padding {
  padding: max(20px, 3vw);
}

/* Height minimum */
.hero {
  height: max(400px, 60vh);
  background: linear-gradient(135deg, #667eea, #764ba2);
}

/* Gap minimum */
.gap {
  gap: max(16px, 2vw);
}

/* Grid dengan minimum */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(max(200px, 20%), 1fr));
  gap: 20px;
}

/* Button minimum */
button {
  width: max(120px, 30%);
  padding: 12px 24px;
}

/* Sidebar minimum */
.sidebar {
  width: max(200px, 20%);
}

/* Card dengan minimum */
.card {
  width: max(280px, 30%);
  padding: 20px;
  margin: 10px;
}

/* Multiple values */
.multiple-max {
  width: max(50%, 400px, 50vw);
}

/* Combined dengan calc */
.combined-max {
  width: max(calc(50% - 20px), 300px);
}

/* min dan max bersama */
.bounded {
  width: min(max(300px, 50%), 1200px);
  /* setidaknya 300px, setidaknya 50%, tetapi tidak lebih dari 1200px */
}

/* Typography */
p {
  font-size: max(1.4rem, 1.5vw);
}
```

## Poin Penting
- max() mengembalikan nilai terbesar dari daftar nilai yang diberikan
- Ideal untuk memastikan elemen memiliki ukuran minimum dalam desain responsif
- Dapat mencampur berbagai satuan yang kompatibel
- Sering dikombinasikan dengan min() untuk membuat rentang ukuran yang terkontrol
