# Satuan viewport height atau vh sebagai persentase dari tinggi viewport

## Analogi: Perpustakaan Digital

Vh seperti mengukur elemen berdasarkan tinggi jendela perpustakaan. Jika tinggi jendela 800px, maka 50vh berarti 400px. Ini seperti mengatakan "elemen ini akan selalu setinggi setengah dari jendela". Dalam perpustakaan digital, vh memungkinkan elemen menyesuaikan tinggi dengan viewport, sangat berguna untuk membuat section yang memenuhi layar.

## Penjelasan Detail

Satuan vh (viewport height) adalah satuan relatif terhadap tinggi viewport browser. 1vh sama dengan 1% dari tinggi viewport. Jika viewport setinggi 900px, maka 1vh = 9px, 50vh = 450px, 100vh = 900px. Vh sering digunakan untuk membuat hero section yang memenuhi layar (100vh), layout vertikal, dan elemen yang proporsional terhadap tinggi layar. Vh sangat berguna untuk halaman one-page, landing page, dan aplikasi mobile. Perlu diperhatikan bahwa pada mobile, vh mungkin tidak akurat karena toolbar browser yang muncul/sembunyi. CSS telah memperkenalkan svh (small viewport height), lvh (large viewport height), dan dvh (dynamic viewport height) untuk mengatasi masalah ini.

## Contoh Kode Implementasi

```css
/* Hero section full screen */
.hero {
  height: 100vh;
  background: linear-gradient(135deg, #667eea, #764ba2);
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
}

/* Section dengan tinggi setengah layar */
.half-screen {
  height: 50vh;
  background: #3498db;
  color: white;
  padding: 40px;
}

/* Card grid yang menyesuaikan tinggi */
.card {
  height: 30vh;
  min-height: 200px;
  max-height: 400px;
}

/* Vertical centering dengan vh */
.center-vertically {
  margin-top: 50vh;
  transform: translateY(-50%);
}

/* Layout dengan vh */
.sidebar {
  height: 100vh;
  width: 250px;
  position: fixed;
  top: 0;
  left: 0;
}

.main-content {
  margin-left: 250px;
  min-height: 100vh;
}

/* Responsive square */
.square {
  width: 20vw;
  height: 20vw;
}

/* Background attachment fix dengan vh */
.bg-section {
  background-image: url('parallax.jpg');
  background-size: cover;
  background-attachment: fixed;
  height: 60vh;
}

/* Mobile-friendly vh */
.mobile-hero {
  height: 100dvh; /* dynamic viewport height */
  background: #2c3e50;
  color: white;
}

/* Alternatif untuk masalah vh mobile */
.fallback-hero {
  height: 100vh;
  height: -webkit-fill-available;
}

/* Scroll-based spacing */
.section-spacing {
  padding: 10vh 0;
}

/* Text alignment vertical */
.vertical-text {
  writing-mode: vertical-rl;
  height: 80vh;
}
```

## Poin Penting
- 1vh = 1% dari tinggi viewport; 100vh = tinggi penuh viewport
- Vh ideal untuk hero section full-screen, sidebar tetap, dan layout vertikal
- Pada mobile, vh mungkin tidak akurat karena toolbar browser; pertimbangkan dvh atau svh
- Kombinasikan dengan min-height untuk memastikan konten tidak terpotong
