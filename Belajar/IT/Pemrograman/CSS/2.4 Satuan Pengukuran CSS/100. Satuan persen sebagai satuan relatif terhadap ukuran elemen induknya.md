# Satuan persen sebagai satuan relatif terhadap ukuran elemen induknya

## Analogi: Perpustakaan Digital

Persen seperti mengatakan "rak ini mengisi setengah dari lebar dinding" atau "kolom ini lebarnya sepertiga dari halaman". Dalam perpustakaan digital, persentase selalu mengacu pada ukuran elemen induk. Jika induk selebar 1000px, maka 50% berarti 500px. Ini membuat persentase sangat berguna untuk layout yang responsif dan proporsional.

## Penjelasan Detail

Satuan persen (%) dalam CSS adalah satuan relatif yang dihitung berdasarkan nilai properti tertentu dari elemen induk. Untuk width, persentase dihitung dari lebar elemen induk. Untuk height, persentase dihitung dari tinggi elemen induk (jika tinggi induk definitif). Untuk padding dan margin, persentase dihitung dari lebar elemen induk (termasuk padding-top/bottom). Untuk font-size, persentase dihitung dari font-size induk. Persentase sangat penting untuk desain responsif karena elemen secara otomatis menyesuaikan dengan perubahan ukuran induk. Persentase juga digunakan dalam banyak properti lain seperti background-position, background-size, border-radius, dan transform.

## Contoh Kode Implementasi

```css
/* Width dengan persentase */
.container {
  width: 80%;
  max-width: 1200px;
  margin: 0 auto;
}

.column-half {
  width: 50%;
  float: left;
}

.column-third {
  width: 33.33%;
  float: left;
}

/* Height dengan persentase */
.parent-height {
  height: 500px;
  background: #f0f0f0;
}

.child-height {
  height: 50%; /* 250px */
  background: #3498db;
}

/* Padding dengan persentase */
.responsive-padding {
  width: 80%;
  padding: 5%; /* berdasarkan lebar */
  background: #e74c3c;
  color: white;
}

/* Margin dengan persentase */
.margin-percent {
  width: 60%;
  margin: 2% auto; /* margin kiri/kanan auto, atas/bawah 2% dari lebar */
}

/* Font-size dengan persentase */
.parent-text {
  font-size: 20px;
}

.child-text {
  font-size: 150%; /* 30px */
}

/* Border-radius dengan persentase */
.circle {
  width: 200px;
  height: 200px;
  background: #2ecc71;
  border-radius: 50%; /* membuat lingkaran */
}

/* Background-position dengan persentase */
.bg-position {
  background-image: url('photo.jpg');
  background-position: 50% 50%; /* tengah */
  height: 300px;
}

/* Transform dengan persentase */
.center-self {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

/* Responsif dengan persentase */
.responsive-grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 2%;
}
```

## Poin Penting
- Persentase width dihitung dari lebar induk; persentase height dari tinggi induk (jika definitif)
- Persentase padding dan margin selalu dihitung dari lebar induk (termasuk padding vertikal)
- Persentase sangat penting untuk desain responsif karena ukuran menyesuaikan induk
- Border-radius 50% pada elemen persegi menghasilkan lingkaran sempurna
