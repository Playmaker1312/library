# Satuan viewport width atau vw sebagai persentase dari lebar viewport

## Analogi: Perpustakaan Digital

Vw seperti mengukur elemen berdasarkan lebar jendela perpustakaan. Jika jendela selebar 1000px, maka 50vw berarti 500px, tidak peduli berapa pun ukuran elemen induknya. Ini seperti mengatakan "elemen ini akan selalu selebar setengah dari jendela". Dalam perpustakaan digital, vw memungkinkan elemen menyesuaikan ukuran dengan viewport secara langsung.

## Penjelasan Detail

Satuan vw (viewport width) adalah satuan relatif terhadap lebar viewport browser. 1vw sama dengan 1% dari lebar viewport. Jika viewport selebar 1200px, maka 1vw = 12px, 50vw = 600px, 100vw = 1200px. Vw tidak terpengaruh oleh ukuran elemen induk atau font. Vw sangat berguna untuk membuat elemen yang skalanya berdasarkan viewport, seperti hero section full-width, tipografi responsif, dan layout yang menyesuaikan lebar layar. Vw sering dikombinasikan dengan calc() untuk mengurangi scrollbar horizontal yang disebabkan oleh 100vw. Perhatikan bahwa vw termasuk lebar scrollbar, sehingga 100vw mungkin sedikit lebih lebar dari 100% pada beberapa browser.

## Contoh Kode Implementasi

```css
/* Full width hero */
.hero {
  width: 100vw;
  height: 60vh;
  background: linear-gradient(135deg, #667eea, #764ba2);
  color: white;
  display: flex;
  align-items: center;
  justify-content: center;
}

/* Responsive font size */
h1 {
  font-size: 5vw; /* 5% dari lebar viewport */
}

h2 {
  font-size: 3.5vw;
}

p {
  font-size: 1.5vw;
}

/* Full width container */
.full-width {
  width: 100vw;
  margin-left: calc(-50vw + 50%);
  /* Menempatkan elemen full-width di luar container */
}

/* Ukuran berdasarkan viewport */
.square {
  width: 20vw;
  height: 20vw; /* persegi yang menyesuaikan lebar */
  background: #3498db;
}

/* Mengatasi scrollbar dengan calc */
.safe-full-width {
  width: calc(100vw - (100vw - 100%));
  /* Lebar viewport minus scrollbar */
}

/* Padding responsif */
.responsive-padding {
  padding: 2vw 4vw;
}

/* Gap responsif */
.flex-responsive {
  display: flex;
  gap: 2vw;
}

/* Font responsif dengan clamp */
.responsive-text {
  font-size: clamp(1.6rem, 2.5vw, 3.2rem);
}

/* Media query dengan vw */
@media (min-width: 1200px) {
  .hero-title {
    font-size: 4rem; /* batasi ukuran maksimal */
  }
}

/* Margin berdasarkan viewport */
.section {
  margin: 5vw 0;
}

/* Border radius responsif */
.responsive-radius {
  border-radius: 2vw;
}
```

## Poin Penting
- 1vw = 1% dari lebar viewport; 100vw = lebar penuh viewport
- Vw independen dari ukuran induk, berguna untuk layout yang berbasis viewport
- Hati-hati dengan scrollbar: 100vw termasuk lebar scrollbar, gunakan calc() untuk kompensasi
- Vw sangat berguna untuk tipografi responsif dan elemen full-width
