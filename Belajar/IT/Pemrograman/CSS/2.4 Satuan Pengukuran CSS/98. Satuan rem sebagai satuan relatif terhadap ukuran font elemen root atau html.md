# Satuan rem sebagai satuan relatif terhadap ukuran font elemen root atau html

## Analogi: Perpustakaan Digital

Rem seperti ukuran buku yang dinyatakan dalam "kali ukuran standar utama perpustakaan". Jika ukuran standar utama adalah 16pt, maka 2rem berarti 32pt di mana pun dalam perpustakaan. Tidak peduli berapa pun ukuran buku di rak tertentu, 2rem selalu sama di seluruh perpustakaan digital. Ini membuat rem lebih mudah diprediksi dibandingkan em.

## Penjelasan Detail

Satuan rem (root em) adalah satuan relatif yang dihitung berdasarkan ukuran font elemen root (html), bukan elemen induk. Dengan demikian, 1rem selalu sama di seluruh dokumen, tidak terpengaruh oleh struktur bersarang. Ukuran default font browser biasanya 16px, jadi 1rem = 16px secara default. Rem sangat populer untuk desain responsif karena dengan mengubah font-size pada root, seluruh ukuran berbasis rem akan berubah secara proporsional. Ini memudahkan implementasi tema ukuran dan aksesibilitas. Rem lebih mudah diprediksi daripada em karena tidak kumulatif. Banyak kerangka kerja CSS menggunakan rem untuk spacing dan tipografi.

## Contoh Kode Implementasi

```css
/* Root font size */
html {
  font-size: 16px; /* default browser */
}

/* Mengubah skala global */
html {
  font-size: 62.5%; /* 10px - memudahkan konversi: 1rem = 10px */
}

/* Heading dengan rem */
h1 {
  font-size: 3.2rem; /* 32px */
}

h2 {
  font-size: 2.4rem; /* 24px */
}

h3 {
  font-size: 1.8rem; /* 18px */
}

/* Body text */
body {
  font-size: 1.6rem; /* 16px */
  line-height: 1.5;
}

/* Spacing dengan rem */
.container {
  max-width: 120rem; /* 1200px */
  margin: 0 auto;
  padding: 2rem;
}

/* Komponen dengan rem */
.card {
  padding: 2rem;
  margin-bottom: 1.5rem;
  border-radius: 0.5rem;
  box-shadow: 0 0.2rem 0.4rem rgba(0,0,0,0.1);
}

.card-title {
  font-size: 2rem;
  margin-bottom: 1rem;
}

.card-text {
  font-size: 1.4rem;
  line-height: 1.6;
}

/* Rem tidak terpengaruh struktur bersarang */
.level-1 { font-size: 1.5rem; }
.level-2 { font-size: 1.5rem; } /* tetap 1.5rem */
.level-3 { font-size: 1.5rem; } /* tetap 1.5rem, tidak kumulatif */

/* Aksesibilitas - user dapat mengubah font-size */
html {
  font-size: 100%; /* menghormati preferensi user */
}

/* Media query dengan rem */
@media (max-width: 48rem) { /* 768px */
  .container {
    padding: 1rem;
  }
}

/* Gap dengan rem */
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 2rem;
}
```

## Poin Penting
- 1rem = ukuran font elemen root (html), default 16px di browser
- Rem tidak kumulatif seperti em, sehingga lebih mudah diprediksi di seluruh dokumen
- Rem sangat cocok untuk desain responsif dan aksesibilitas karena skala global dapat diubah dari satu titik
- Mengubah font-size root (misal 62.5%) memudahkan konversi: 1rem = 10px
