# Satuan ch berdasarkan lebar karakter nol pada font yang sedang digunakan

## Analogi: Perpustakaan Digital

Ch seperti mengukur lebar berdasarkan lebar huruf "0" (nol) dalam font tertentu. Jika dalam font yang digunakan, huruf "0" selebar 10px, maka 20ch berarti 200px. Ini seperti mengatakan "ruang untuk 20 karakter". Dalam perpustakaan digital, ch sangat berguna untuk mengatur lebar elemen yang berisi teks agar terbaca dengan nyaman.

## Penjelasan Detail

Satuan ch (character unit) adalah satuan relatif yang sama dengan lebar karakter "0" (nol) dari font yang digunakan. Karena sebagian besar font memiliki lebar karakter yang bervariasi (proportional font), ch memberikan estimasi lebar karakter yang lebih akurat daripada em. Ch sangat berguna untuk mengatur lebar elemen teks seperti paragraf, input, atau textarea agar memiliki lebar optimal untuk keterbacaan (biasanya 60-75 karakter per baris). Dalam monospace font, ch sangat akurat karena setiap karakter memiliki lebar yang sama. Ch juga berguna untuk mengatur indentasi, membuat grid berbasis karakter, dan elemen yang berhubungan dengan konten teks.

## Contoh Kode Implementasi

```css
/* Lebar optimal untuk paragraf */
.article-body {
  max-width: 65ch; /* 65 karakter per baris - optimal readability */
  font-size: 1.6rem;
  line-height: 1.6;
}

/* Input dengan lebar berdasarkan karakter */
input[type="text"] {
  width: 30ch;
  padding: 0.5em;
  font-size: 1.6rem;
}

/* Textarea */
textarea {
  width: 70ch;
  max-width: 100%;
  height: 20em;
}

/* Code block */
code {
  font-family: 'Courier New', monospace;
  font-size: 1.4rem;
}

pre {
  max-width: 80ch;
  overflow-x: auto;
  background: #f4f4f4;
  padding: 1.5em;
  border-radius: 4px;
}

/* Indentasi berbasis karakter */
.indent-2ch {
  padding-left: 2ch;
}

.indent-4ch {
  padding-left: 4ch;
}

/* Monospace grid */
.mono-grid {
  font-family: 'Courier New', monospace;
  font-size: 14px;
}

.mono-grid .cell {
  width: 10ch;
  display: inline-block;
}

/* Input untuk kode pos */
.zip-input {
  width: 10ch; /* cukup untuk 5 digit + padding */
  letter-spacing: 0.2ch;
}

/* Card dengan width berdasarkan konten */
.text-card {
  width: min(65ch, 90vw);
  margin: 0 auto;
  padding: 2rem;
}

/* Measurement */
.measure {
  max-width: 60ch;
  margin-left: auto;
  margin-right: auto;
}

/* Label dengan lebar tetap */
.form-label {
  display: inline-block;
  width: 15ch;
  text-align: right;
  margin-right: 1ch;
}
```

## Poin Penting
- 1ch = lebar karakter "0" (nol) dari font yang digunakan pada elemen tersebut
- Sangat berguna untuk mengatur lebar teks optimal (60-75ch) untuk keterbacaan
- Paling akurat dengan monospace font; dengan proportional font, ch adalah estimasi
- Gunakan ch untuk input, textarea, code block, dan elemen teks lainnya
