# Fungsi min untuk memilih nilai terkecil dari beberapa nilai yang diberikan

## Analogi: Perpustakaan Digital

Min seperti memilih ukuran rak yang paling kecil dari beberapa pilihan. Jika rak harus muat di ruangan yang lebarnya 800px tetapi juga tidak boleh lebih dari 90% ruangan, kita memilih yang terkecil. Dalam perpustakaan digital, min() memastikan elemen tidak melebihi batas tertentu dengan memilih nilai terkecil dari daftar nilai yang diberikan.

## Penjelasan Detail

Fungsi min() menerima satu atau lebih nilai yang dipisahkan koma dan mengembalikan nilai terkecil di antaranya. Fungsi ini sangat berguna untuk membuat elemen yang responsif dengan batasan maksimal. Misalnya, width: min(100%, 1200px) akan memilih 100% jika viewport kurang dari 1200px, atau 1200px jika viewport lebih besar. Min dapat mencampur berbagai satuan yang kompatibel. Min sering digunakan sebagai alternatif yang lebih bersih daripada max-width. Fungsi ini juga dapat dikombinasikan dengan calc() dan fungsi CSS lainnya. Min didukung oleh semua browser modern dan merupakan bagian dari CSS Values and Units Module.

## Contoh Kode Implementasi

```css
/* Container responsif dengan batas maksimal */
.container {
  width: min(100%, 1200px);
  margin: 0 auto;
  padding: 20px;
}

/* Grid columns */
.grid-columns {
  display: grid;
  grid-template-columns: repeat(3, min(100%, 400px));
  gap: 20px;
}

/* Responsive padding */
.padding {
  padding: min(5vw, 40px);
}

/* Font size responsif */
h1 {
  font-size: min(5vw, 48px);
}

/* Card width */
.card {
  width: min(90vw, 350px);
  padding: 20px;
}

/* Image dengan batas */
img {
  width: min(100%, 800px);
  height: auto;
}

/* Gap responsif */
.gap {
  gap: min(3vw, 30px);
}

/* Height dengan batas */
.section {
  height: min(60vh, 500px);
}

/* Multiple values */
.element {
  width: min(80%, 600px, 90vw);
}

/* Button min width */
button {
  width: min(200px, 100%);
  padding: 12px 24px;
}

/* Combined dengan calc */
.combined {
  width: min(calc(100% - 40px), 1140px);
  margin: 0 auto;
}

/* Typography clamp alternative */
p {
  font-size: min(2.5vw, 18px); /* tumbuh hingga 18px */
}

/* Sidebar */
.sidebar {
  width: min(30%, 300px);
}

/* Hero text */
.hero-title {
  font-size: min(8vw, 72px);
  line-height: 1.1;
}
```

## Poin Penting
- min() mengembalikan nilai terkecil dari daftar nilai yang diberikan
- Ideal untuk membuat ukuran responsif dengan batas maksimal (seperti max-width alternatif)
- Dapat mencampur berbagai satuan yang kompatibel (%, vw, px, rem, dll.)
- Kombinasikan dengan calc() untuk perhitungan yang lebih kompleks
