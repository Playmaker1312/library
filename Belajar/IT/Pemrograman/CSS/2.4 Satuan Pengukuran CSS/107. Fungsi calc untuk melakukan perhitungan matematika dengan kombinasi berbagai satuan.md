# Fungsi calc untuk melakukan perhitungan matematika dengan kombinasi berbagai satuan

## Analogi: Perpustakaan Digital

Calc seperti kalkulator di perpustakaan yang bisa menghitung ukuran dengan mencampur berbagai satuan. Misalnya, "lebar rak ini adalah 100% dari dinding dikurangi 40px untuk bingkai". Dalam perpustakaan digital, calc() memungkinkan kita melakukan operasi matematika dengan satuan campuran, memberikan fleksibilitas yang tidak mungkin dilakukan dengan satuan statis.

## Penjelasan Detail

Fungsi calc() memungkinkan operasi matematika dalam nilai CSS. Kalkulasi dapat melibatkan penjumlahan (+), pengurangan (-), perkalian (*), dan pembagian (/). Kelebihan utama calc adalah kemampuannya mencampur satuan yang berbeda, seperti persentase dengan piksel. Calc sangat berguna untuk membuat layout yang responsif namun tetap mempertahankan ukuran tetap tertentu. Contoh umum: lebar kolom = 100% - 20px untuk margin, atau height = 100vh - 60px untuk header. Spasi diperlukan di sekitar operator + dan - tetapi tidak untuk * dan /. Calc dapat digunakan untuk nilai panjang, angle, time, frequency, dan lainnya.

## Contoh Kode Implementasi

```css
/* Full width minus sidebar */
.main-content {
  width: calc(100% - 250px);
  margin-left: 250px;
}

/* Full viewport minus header */
.page-content {
  min-height: calc(100vh - 60px);
  padding-top: 60px;
}

/* Column with fixed gutters */
.column {
  width: calc(33.33% - 20px);
  margin: 0 10px;
  float: left;
}

/* Responsive font size */
h1 {
  font-size: calc(1.8rem + 1.5vw);
}

/* Card height */
.card {
  height: calc(100% - 40px);
  margin: 20px;
}

/* Centered element with offset */
.centered-offset {
  position: absolute;
  left: calc(50% - 150px);
  width: 300px;
}

/* Kalkulasi kompleks */
.complex-calc {
  width: calc((100% - 40px) / 3 - 20px);
  margin: 10px;
}

/* Background position */
.bg-calc {
  background-position: calc(100% - 20px) calc(100% - 20px);
}

/* Clamp with calc */
.responsive {
  font-size: clamp(1.6rem, calc(1.2rem + 1.5vw), 3.2rem);
}

/* Grid dengan calc */
.grid-calc {
  display: grid;
  grid-template-columns: 1fr calc(300px + 2rem) 1fr;
  gap: 2rem;
}

/* Spacing dengan calc */
.spaced-item {
  margin: calc(1rem + 0.5vw) 0;
}

/* Aspect ratio dengan calc */
.video-container {
  width: 100%;
  height: calc(width * 9 / 16); /* aspect ratio 16:9 */
}

/* Multiple calc */
.multiple {
  padding: calc(1rem + 1vw) calc(2rem + 2vw);
  border-radius: calc(0.5rem + 0.5vw);
}
```

## Poin Penting
- calc() memungkinkan operasi +, -, *, / dengan campuran satuan berbeda
- Spasi wajib di sekitar operator + dan -; opsional untuk * dan /
- Calc sangat berguna untuk layout responsif yang membutuhkan ukuran tetap dan relatif
- Calc dapat digunakan di hampir semua properti yang menerima angka atau panjang
