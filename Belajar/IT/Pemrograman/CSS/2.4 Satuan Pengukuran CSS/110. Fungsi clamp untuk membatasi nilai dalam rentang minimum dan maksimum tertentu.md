# Fungsi clamp untuk membatasi nilai dalam rentang minimum dan maksimum tertentu

## Analogi: Perpustakaan Digital

Clamp seperti mengatur suhu ruangan perpustakaan dengan termostat: tidak boleh kurang dari 18°C, tidak boleh lebih dari 26°C, dan idealnya 22°C. Dalam perpustakaan digital, clamp() membatasi nilai dalam rentang antara minimum dan maksimum, dengan nilai ideal (preferred) di tengah. Ini memberikan fluiditas responsif dengan batasan yang aman.

## Penjelasan Detail

Fungsi clamp() menerima tiga nilai: MIN, PREFERRED, dan MAX. Fungsi ini akan memilih nilai PREFERRED selama berada di antara MIN dan MAX. Jika PREFERRED lebih kecil dari MIN, clamp mengembalikan MIN. Jika PREFERRED lebih besar dari MAX, clamp mengembalikan MAX. Clamp sangat populer untuk tipografi responsif, memungkinkan font-size yang fluid (berubah dengan viewport) tetapi tidak lebih kecil atau lebih besar dari batas tertentu. Clamp juga berguna untuk spacing, ukuran elemen, dan apa pun yang membutuhkan responsivitas terkontrol. Fungsi ini menggabungkan min() dan max() dalam satu fungsi yang lebih bersih.

## Contoh Kode Implementasi

```css
/* Fluid typography */
h1 {
  font-size: clamp(2.4rem, 5vw, 4.8rem);
  line-height: 1.1;
}

h2 {
  font-size: clamp(2rem, 4vw, 3.2rem);
}

p {
  font-size: clamp(1.4rem, 2vw, 1.8rem);
  line-height: 1.6;
}

/* Container width */
.container {
  width: clamp(320px, 90%, 1200px);
  margin: 0 auto;
  padding: 20px;
}

/* Responsive padding */
.padding {
  padding: clamp(16px, 3vw, 40px);
}

/* Card width */
.card {
  width: clamp(280px, 30%, 400px);
  padding: clamp(16px, 2vw, 30px);
  margin: clamp(10px, 1.5vw, 20px);
}

/* Hero section */
.hero {
  height: clamp(300px, 50vh, 600px);
  background: linear-gradient(135deg, #667eea, #764ba2);
}

/* Gap responsif */
.gap {
  gap: clamp(12px, 2vw, 32px);
}

/* Border radius */
.radius {
  border-radius: clamp(4px, 1vw, 16px);
}

/* Button sizing */
button {
  padding: clamp(8px, 1.5vw, 16px) clamp(16px, 3vw, 32px);
  font-size: clamp(1.4rem, 1.5vw, 1.8rem);
}

/* Grid dengan clamp */
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(clamp(200px, 30%, 400px), 1fr));
  gap: clamp(16px, 2vw, 32px);
}

/* Margin section */
.section {
  margin: clamp(40px, 8vw, 100px) 0;
}

/* Image sizing */
img {
  width: clamp(200px, 50%, 800px);
  height: auto;
}

/* Combined dengan calc */
.complex-clamp {
  width: clamp(300px, calc(50% + 100px), 800px);
}

/* Line height */
.text {
  line-height: clamp(1.4, calc(1.4 + 0.2 * ((100vw - 320px) / 960)), 1.8);
}
```

## Poin Penting
- clamp(MIN, PREFERRED, MAX) membatasi nilai antara minimum dan maksimum
- Ideal untuk tipografi fluid: ukuran font yang berubah dengan viewport tetapi tidak melampaui batas
- Clamp menggabungkan fungsi min() dan max() dalam satu deklarasi yang lebih bersih
- Sangat berguna untuk padding, gap, width, height, dan properti lain yang membutuhkan responsivitas terkontrol
