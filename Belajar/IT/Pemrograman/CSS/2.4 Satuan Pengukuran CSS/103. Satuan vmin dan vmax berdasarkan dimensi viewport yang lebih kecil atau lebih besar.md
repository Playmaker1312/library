# Satuan vmin dan vmax berdasarkan dimensi viewport yang lebih kecil atau lebih besar

## Analogi: Perpustakaan Digital

Vmin seperti mengukur berdasarkan sisi terpendek dari jendela perpustakaan, vmax berdasarkan sisi terpanjang. Jika jendela memiliki lebar 1000px dan tinggi 600px, maka 10vmin = 60px (berdasarkan tinggi yang lebih kecil) dan 10vmax = 100px (berdasarkan lebar yang lebih besar). Dalam perpustakaan digital, vmin dan vmax memastikan ukuran proporsional terhadap dimensi viewport tertentu.

## Penjelasan Detail

Satuan vmin dan vmax adalah satuan viewport yang mengambil dimensi minimum atau maksimum dari viewport. vmin mengambil nilai dari dimensi yang lebih kecil (min(width, height)). vmax mengambil nilai dari dimensi yang lebih besar (max(width, height)). Pada layar landscape, vmin berdasarkan tinggi (yang lebih kecil) dan vmax berdasarkan lebar (yang lebih besar). Pada layar portrait, sebaliknya. Vmin sangat berguna untuk membuat elemen yang selalu proporsional terhadap sisi terpendek, memastikan elemen tidak terpotong. Vmax berguna untuk elemen yang ingin memaksimalkan penggunaan ruang. Kedua satuan ini berguna untuk tipografi responsif, elemen persegi, dan komponen yang harus terlihat baik di berbagai orientasi.

## Contoh Kode Implementasi

```css
/* Square yang menyesuaikan sisi terpendek */
.square-vmin {
  width: 50vmin;
  height: 50vmin;
  background: #3498db;
  border-radius: 10%;
}

/* Font size berdasarkan vmin */
.responsive-font {
  font-size: 5vmin; /* selalu proporsional terhadap sisi terpendek */
}

/* Full screen dengan vmax */
.full-vmax {
  width: 100vmax;
  height: 100vmin; /* mengambil seluruh viewport */
  background: linear-gradient(135deg, #667eea, #764ba2);
}

/* Elemen yang menggunakan vmax untuk lebar */
.wide-element {
  width: 80vmax;
  height: 200px;
  background: #e74c3c;
}

/* Avatar yang proporsional */
.avatar {
  width: 10vmin;
  height: 10vmin;
  border-radius: 50%;
  object-fit: cover;
}

/* Hero section dengan vmin */
.hero-vmin {
  height: 60vmin;
  min-height: 300px;
  background: #2c3e50;
  color: white;
  display: flex;
  align-items: center;
  padding: 4vmin;
}

/* Grid dengan vmin gap */
.grid-vmin {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 2vmin;
}

/* Card yang responsif */
.card-vmin {
  padding: 3vmin;
  border-radius: 2vmin;
  margin: 2vmin;
}

/* Landscape vs portrait considerations */
@media (orientation: landscape) {
  .landscape-text {
    font-size: 4vmin; /* berdasarkan tinggi di landscape */
  }
}

@media (orientation: portrait) {
  .portrait-text {
    font-size: 4vmin; /* berdasarkan lebar di portrait */
  }
}

/* Membatasi ukuran dengan clamp */
.bounded-element {
  width: clamp(200px, 40vmin, 500px);
  height: clamp(200px, 40vmin, 500px);
}
```

## Poin Penting
- vmin berdasarkan dimensi viewport yang lebih kecil; vmax berdasarkan dimensi yang lebih besar
- Vmin ideal untuk elemen yang harus muat di kedua orientasi landscape dan portrait
- Vmax berguna untuk memaksimalkan penggunaan ruang viewport
- Kombinasikan dengan clamp() atau media queries untuk kontrol ukuran yang lebih baik
