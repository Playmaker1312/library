# Perbedaan em dan rem serta kapan menggunakan masing-masing dengan tepat

## Analogi: Perpustakaan Digital

Em seperti ukuran yang mengikuti skala rak buku tertentu: 2em di rak anak berbeda ukurannya dengan 2em di rak dewasa. Rem seperti ukuran standar perpustakaan: 2rem selalu sama di mana pun, mengacu pada standar utama. Dalam perpustakaan digital, pilih em ketika ingin ukuran proporsional dalam komponen, pilih rem untuk konsistensi global.

## Penjelasan Detail

Perbedaan utama antara em dan rem adalah apa yang menjadi referensi perhitungan. Em merujuk pada ukuran font elemen induk (untuk font-size) atau elemen itu sendiri (untuk properti lain). Rem merujuk pada ukuran font elemen root (html). Em bersifat kumulatif dalam struktur bersarang, sedangkan rem tidak. Gunakan em ketika: ingin komponen yang skalanya proporsional terhadap ukuran font-nya, seperti tombol yang padding-nya mengikuti ukuran teks. Gunakan rem ketika: ingin konsistensi global, aksesibilitas, dan kemudahan penskalaan di seluruh halaman. Banyak developer menggunakan kombinasi: rem untuk spacing dan layout, em untuk komponen lokal. Praktik umum: html font-size 62.5% (10px), lalu gunakan rem untuk sebagian besar ukuran, dan em untuk elemen yang perlu proporsional dalam komponen.

## Contoh Kode Implementasi

```css
/* Setup root */
html {
  font-size: 62.5%; /* 1rem = 10px */
}

/* REM untuk layout global */
.container {
  max-width: 120rem;
  margin: 0 auto;
  padding: 2rem;
}

.header {
  padding: 1.5rem 2rem;
  font-size: 1.8rem;
}

/* EM untuk komponen proporsional */
.button {
  font-size: 1.6rem;
  padding: 0.75em 1.5em; /* proporsional terhadap font-size */
  border-radius: 0.25em;
}

.button-small {
  font-size: 1.2rem;
  padding: 0.75em 1.5em; /* lebih kecil secara proporsional */
}

.button-large {
  font-size: 2rem;
  padding: 0.75em 1.5em; /* lebih besar secara proporsional */
}

/* Mix rem dan em dalam komponen */
.card {
  padding: 2rem;
  margin-bottom: 2rem;
  border-radius: 0.5rem;
}

.card-title {
  font-size: 2rem;
  margin-bottom: 0.5em; /* berdasarkan font-size card-title */
  padding-bottom: 0.3em;
  border-bottom: 0.2rem solid #eee;
}

.card-text {
  font-size: 1.4rem;
  line-height: 1.6em; /* berdasarkan font-size 1.4rem */
}

/* Em untuk media queries tidak disarankan */
/* Gunakan rem untuk konsistensi */
@media (max-width: 48rem) {
  .container {
    padding: 1rem;
  }
  .card {
    padding: 1.5rem;
  }
}

/* Em untuk nesting yang disengaja */
.nested-component {
  font-size: 1.4rem;
}

.nested-component .item {
  font-size: 0.9em; /* 1.26rem */
}

.nested-component .item .sub-item {
  font-size: 0.9em; /* 1.134rem - kumulatif */
}
```

## Poin Penting
- Em berdasarkan ukuran font induk/lokal; rem berdasarkan ukuran font root (html)
- Em kumulatif dalam nesting; rem tidak kumulatif
- Gunakan rem untuk layout global, spacing, dan tipografi; gunakan em untuk komponen yang perlu proporsional
- Kombinasi em dan rem memberikan fleksibilitas: konsistensi global + proporsionalitas lokal
