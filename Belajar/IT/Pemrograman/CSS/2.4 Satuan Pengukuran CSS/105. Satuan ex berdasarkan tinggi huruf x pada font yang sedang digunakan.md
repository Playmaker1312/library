# Satuan ex berdasarkan tinggi huruf x pada font yang sedang digunakan

## Analogi: Perpustakaan Digital

Ex seperti mengukur berdasarkan tinggi huruf "x" kecil dalam font tertentu. Jika tinggi huruf "x" adalah 8px, maka 2ex berarti 16px. Dalam perpustakaan digital, ex mengacu pada x-height font, yaitu tinggi huruf kecil tanpa ascender dan descender. Ini berguna untuk ukuran yang berhubungan dengan tipografi dan keterbacaan.

## Penjelasan Detail

Satuan ex (x-height) adalah satuan relatif yang sama dengan tinggi huruf "x" kecil dari font yang digunakan. x-height adalah jarak dari baseline ke meanline (tinggi huruf kecil tanpa ascender seperti pada "x", "a", "e"). Font yang berbeda memiliki x-height yang berbeda meskipun ukuran font-nya sama. Ex berguna untuk ukuran yang berhubungan dengan tipografi vertikal, seperti mengatur jarak antar baris, ukuran subscript/superscript, atau elemen yang harus proporsional terhadap tinggi huruf kecil. Ex kurang umum digunakan dibandingkan em atau rem karena variasi x-height antar font cukup signifikan. Namun, ex sangat berguna untuk pengaturan tipografi yang presisi.

## Contoh Kode Implementasi

```css
/* Indentasi baris pertama berdasarkan x-height */
p {
  text-indent: 2ex;
}

/* Line height berdasarkan x-height */
.tight-text {
  line-height: 2ex;
}

/* Vertical alignment */
.subscript {
  vertical-align: sub;
  font-size: 0.75em;
}

.superscript {
  vertical-align: super;
  font-size: 0.75em;
}

/* Margin bottom proporsional terhadap x-height */
.heading {
  margin-bottom: 1ex;
}

/* Initial letter dropcap */
.dropcap::first-letter {
  font-size: 3em;
  float: left;
  line-height: 1ex;
  margin-right: 0.5ex;
}

/* Border-bottom based on x-height */
.underline-custom {
  border-bottom: 0.2ex solid currentColor;
  padding-bottom: 0.5ex;
}

/* Icon sizing based on ex */
.icon-inline {
  width: 1.5ex;
  height: 1.5ex;
  vertical-align: middle;
}

/* Padding vertikal proporsional */
.text-block {
  padding: 1ex 2em;
}

/* Font-relative spacing */
.ex-spacing > * + * {
  margin-top: 1.5ex;
}

/* Perbandingan ex antar font */
.serif-text {
  font-family: 'Times New Roman', serif;
  font-size: 16px;
  /* ex mungkin berbeda dengan sans-serif */
}

.sans-text {
  font-family: Arial, sans-serif;
  font-size: 16px;
  /* ex mungkin lebih besar dari Times */
}

/* Custom underline position */
.custom-underline {
  text-decoration: none;
  background-image: linear-gradient(currentColor, currentColor);
  background-size: 1px 0.1ex;
  background-repeat: repeat-x;
  background-position: 0 1.2ex;
}
```

## Poin Penting
- 1ex = tinggi huruf "x" kecil (x-height) dari font yang digunakan
- Ex berguna untuk ukuran yang berhubungan dengan tipografi vertikal
- x-height bervariasi antar font, sehingga ex tidak konsisten antar font berbeda
- Ex kurang umum digunakan dibandingkan em/rem, tetapi berguna untuk presisi tipografi
