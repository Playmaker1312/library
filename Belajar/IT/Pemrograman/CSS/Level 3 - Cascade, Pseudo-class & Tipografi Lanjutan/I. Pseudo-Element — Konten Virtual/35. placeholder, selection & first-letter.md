# 35. ::placeholder, ::selection & ::first-letter

## Penjelasan

Pseudo-element untuk bagian spesifik dari elemen:

| Pseudo-element | Target |
|---------------|--------|
| `::placeholder` | Teks placeholder di input |
| `::selection` | Teks yang diseleksi (di-highlight) user |
| `::first-letter` | Huruf pertama dari elemen block |
| `::first-line` | Baris pertama dari elemen block |

```css
::selection {
  background-color: var(--color-primary);
  color: white;
}

input::placeholder {
  color: var(--color-text-muted);
  font-style: italic;
}
```

## Fungsi

- Kustomisasi pengalaman user — selection, placeholder
- Dropcap (huruf pertama besar) untuk artikel
- Detail kecil yang membuat website terasa polished

## Cara Pengimplementasian

```css
/* Custom selection color */
::selection {
  background-color: var(--color-primary);
  color: white;
}

/* Placeholder style */
input::placeholder {
  color: var(--color-text-muted);
  font-style: italic;
  opacity: 0.7;
}

/* Dropcap — huruf pertama besar */
.article-content > p:first-child::first-letter {
  font-size: 3.5rem;
  font-weight: var(--font-weight-bold);
  color: var(--color-primary);
  float: left;
  line-height: 1;
  margin-right: var(--space-2);
  margin-top: var(--space-1);
}

/* First-line — semua teks di baris pertama */
.article-content p::first-line {
  font-weight: var(--font-weight-semibold);
  color: var(--color-text);
}
```

## Analogi

- **::selection** = **stabilo** warna biru — saat kamu blok teks, stabilo ini yang muncul, bukan stabilo abu-abu default Windows
- **::placeholder** = **tulisan "Isi di sini" di formulir** — petunjuk yang hilang saat mulai menulis
- **::first-letter** = **huruf kapital besar di awal bab buku** — seperti di buku dongeng, huruf "P" besar penuh hiasan

Semuanya tentang **sentuhan kecil** yang bikin rumah (website) terasa lebih personal dan diperhatikan.

## Dipakai Untuk Apa

- **::selection**: warna brand saat user menyeleksi teks
- **::placeholder**: instruksi input yang lebih stylish
- **::first-letter**: dropcast di artikel blog
- **::first-line**: bold baris pertama paragraf untuk penekanan

## Kesalahan Umum

- **Hanya properti tertentu di ::selection**: color, background, text-shadow, dan beberapa lainnya — tidak semua properti berlaku
- **::first-letter hanya untuk block element**: tidak berfungsi di inline element
- **Lupa prefix di browser lama**: beberapa pseudo-element butuh `:` tunggal (IE), standar modern `::`
- **::placeholder didukung semua browser modern**: tapi tidak semua properti CSS berlaku (hanya font, color, background, text, opacity)

## Hubungan dengan Materi Sebelumnya

Poin 34: ::before/::after untuk konten virtual. Sekarang **::placeholder, ::selection, ::first-letter** — pseudo-element untuk bagian spesifik dari elemen yang sudah ada. Ini adalah **sentuhan akhir** level 3 — detail yang membuat website terasa profesional dan diperhatikan.

## Soal Latihan

### Soal 1
Tulis CSS untuk membuat teks yang diseleksi memiliki background biru dan teks putih.

**Jawaban:**
```css
::selection {
  background-color: #2563eb;
  color: white;
}
```

### Soal 2
Tulis CSS untuk membuat placeholder berwarna abu-abu dan miring.

**Jawaban:**
```css
input::placeholder {
  color: #9ca3af;
  font-style: italic;
}
```

### Soal 3
Apa yang dimaksud dengan dropcap di CSS?

**Jawaban:**
Dropcap adalah huruf pertama paragraf yang diperbesar secara signifikan (biasanya 3-4x ukuran normal) dan diletakkan mengambang (float) di kiri paragraf — seperti di novel atau buku cerita.
