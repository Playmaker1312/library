# 28. !important & Strategi Menghindarinya

## Penjelasan

`!important` adalah deklarasi yang **meng-override specificity** dan order. Semua aturan normal (bahkan inline style) bisa dikalahkan oleh `!important`.

```css
p { color: red !important; }   /* !important — override semua */
#main p { color: blue; }      /* kalah — walaupun specificity tinggi */
```

## Fungsi

- **Override darurat**: utility class yang harus selalu menang
- **Override third-party library**: CSS library yang tidak bisa diubah
- **Hanya untuk situasi spesifik**: bukan solusi untuk specificity buruk

## Cara Pengimplementasian

```css
/* Kapan BOLEH pakai !important */
.utility-hidden { 
  display: none !important;  /* utility class — harus selalu menang */
}

/* Bootstrap override — tidak bisa ubah source */
.btn-special {
  background-color: var(--color-primary) !important;
}

/* Print styles */
@media print {
  nav { display: none !important; }
}

/* Kapan TIDAK BOLEH pakai !important */
/* ❌ Untuk "malas" menulis selector yang tepat */
.card .title { color: red !important; }  /* seharusnya specificity cukup */

/* ❌ Untuk "sementara" — !important bersifat permanen dan menular */
```

## Analogi

`!important` seperti **kunci utama rumah**. Dengan kunci ini, kamu bisa buka pintu mana pun — bahkan pintu yang sudah dikunci (specificity tinggi). Tapi jika semua orang punya kunci utama, pintu jadi tidak berguna.

Begitu banyak `!important` di CSS, sistem specificity jadi tidak berfungsi — tidak ada lagi "prediksi" siapa yang menang. Semua jadi pertarungan !important.

## Dipakai Untuk Apa

- Utility classes (`.hidden`, `.sr-only`)
- Override CSS pihak ketiga (Bootstrap, Tailwind)
- Print stylesheet
- Situasi di mana kita tidak bisa mengubah source (library)

## Kesalahan Umum

- **!important untuk "gampang"**: malas memperbaiki specificity — menambah hutang teknis
- **!important menular**: developer berikutnya juga pakai !important untuk override !important
- **!important di inline style**: inline + !important = sangat sulit di-override
- **!important di komponen reusable**: komponen jadi tidak fleksibel

## Hubungan dengan Materi Sebelumnya

Poin 26-27: cascade dan specificity adalah aturan main CSS. Tapi ada **"kartu truf"** — `!important` — yang bisa mengabaikan aturan. Ini adalah alat yang kuat tapi berbahaya. Paham kapan (tidak) menggunakannya adalah tanda developer CSS yang matang.

## Soal Latihan

### Soal 1
Apa fungsi `!important` di CSS?

**Jawaban:**
`!important` memberikan prioritas tertinggi pada suatu deklarasi — meng-override specificity, order, dan bahkan inline style (kecuali inline !important).

### Soal 2
Sebutkan satu situasi di mana `!important` boleh digunakan.

**Jawaban:**
Utility class seperti `display: none !important` yang harus selalu bekerja terlepas dari apapun CSS lainnya.

### Soal 3
Mengapa `!important` berbahaya jika digunakan berlebihan?

**Jawaban:**
Merusak mekanisme cascade dan specificity. Developer jadi harus pakai !important untuk override !important sebelumnya — menciptakan "perang !important". CSS jadi tidak terprediksi dan sulit dimaintain.
