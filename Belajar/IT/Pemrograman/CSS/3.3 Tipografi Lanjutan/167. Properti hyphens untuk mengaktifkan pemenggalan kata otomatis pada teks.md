# Properti Hyphens

## Analogi: Perpustakaan Digital

Dalam buku cetak, teks yang diratakan kiri-kanan (justify) sering menggunakan tanda hubung di akhir baris untuk memotong kata secara rapi, menciptakan tepi yang bersih. Di perpustakaan digital, efek yang sama bisa dicapai dengan pemenggalan kata otomatis. Dalam CSS, properti hyphens mengontrol apakah browser boleh menambahkan tanda hubung saat memotong kata di akhir baris.

## Penjelasan Detail

Properti hyphens mengontrol pemenggalan kata otomatis (hyphenation) dalam teks. Nilai none mencegah pemenggalan sama sekali. manual (default) hanya memotong di titik yang ditandai dengan karakter &shy; (soft hyphen) atau &#8203; (zero-width space) di HTML. auto memungkinkan browser memutuskan sendiri di mana memotong kata berdasarkan kamus hyphenation bahasa yang dideteksi dari atribut lang pada HTML. Hyphenation sangat berguna untuk teks justify dan kontainer sempit untuk menciptakan tepi yang lebih rapi. Namun, hyphens: auto dapat menghasilkan pemotongan yang tidak konsisten antar browser dan membutuhkan atribut lang yang benar.

## Contoh Kode Implementasi

```css
/* Nonaktifkan hyphenation */
.no-hyphens {
  hyphens: none;
}

/* Manual: hanya dengan soft hyphen */
.manual-hyphens {
  hyphens: manual;
}
/* HTML: <span class="manual-hyphens">super&shy;cali&shy;fragilistic</span> */

/* Auto: browser menentukan sendiri */
.auto-hyphens {
  hyphens: auto;
}

/* Aplikasi: teks justify dengan hyphenation */
article p {
  text-align: justify;
  hyphens: auto;
}

/* Aplikasi: kontainer sempit */
.sidebar {
  hyphens: auto;
  overflow-wrap: break-word;
}

/* Aplikasi: kartu produk */
.product-description {
  hyphens: auto;
  font-size: 0.875rem;
  line-height: 1.5;
}

/* Kombinasi optimal */
.text-content {
  text-align: justify;
  hyphens: auto;
  overflow-wrap: break-word;
  word-break: normal;
}

/* Penting: atribut lang di HTML */
/* <html lang="id"> atau <div lang="en"> */
[lang="en"] {
  hyphens: auto;
}

[lang="id"] {
  hyphens: auto;
}
```

## Poin Penting
- hyphens: none (tanpa pemenggalan), manual (hanya &shy;), auto (otomatis oleh browser)
- hyphens: auto membutuhkan atribut lang yang benar di HTML untuk kamus bahasa
- Cocok untuk teks justify dan kontainer sempit
- Kombinasikan dengan overflow-wrap: break-word untuk hasil terbaik
