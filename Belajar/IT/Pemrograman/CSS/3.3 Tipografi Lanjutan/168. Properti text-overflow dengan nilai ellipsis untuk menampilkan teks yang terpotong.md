# Properti Text-Overflow

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika judul buku terlalu panjang untuk ditampilkan dalam satu baris di daftar hasil pencarian, teks dipotong dan tiga titik (...) ditampilkan di akhir untuk menandakan bahwa masih ada teks yang tersembunyi. Ini memberikan indikasi visual yang jelas tanpa memecah tata letak. Dalam CSS, properti text-overflow dengan nilai ellipsis memberikan efek ini.

## Penjelasan Detail

Properti text-overflow menentukan bagaimana konten teks yang meluap dari kontainer ditampilkan ketika overflow: hidden dan white-space: nowrap diterapkan. Nilai clip memotong teks di batas kontainer tanpa indikasi. Nilai ellipsis menambahkan tiga titik (...) di akhir untuk menandakan teks terpotong. Nilai string khusus (seperti "→" atau "[...]") juga didukung di beberapa browser untuk indikator kustom. text-overflow hanya bekerja ketika ketiga kondisi terpenuhi: overflow memiliki nilai selain visible (biasanya hidden), white-space: nowrap (atau metode lain yang mencegah wrap), dan kontainer memiliki lebar yang terbatas. Untuk multi-line truncation dengan ellipsis, gunakan teknik WebKit line-clamp.

## Contoh Kode Implementasi

```css
/* Single-line ellipsis */
.truncate {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Aplikasi: judul artikel */
.article-title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  max-width: 300px;
  font-weight: 600;
}

/* Aplikasi: tabel dengan sel panjang */
td {
  max-width: 200px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Aplikasi: breadcrumb */
.breadcrumb-item {
  max-width: 150px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Aplikasi: dropdown item */
.dropdown-item {
  max-width: 250px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Clip: potong tanpa indikasi */
.clip-text {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: clip;
}

/* Multi-line truncation (WebKit) */
.multiline-ellipsis {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Kustom string (browser tertentu) */
.custom-ellipsis {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: " →";
}
```

## Poin Penting
- text-overflow: ellipsis menampilkan "..." untuk teks yang terpotong
- Membutuhkan overflow: hidden dan white-space: nowrap (atau kontainer dengan lebar tetap)
- Single-line truncation menggunakan white-space: nowrap + overflow: hidden + text-overflow: ellipsis
- Multi-line truncation membutuhkan -webkit-line-clamp untuk efek ellipsis lebih dari satu baris
