# Properti Font-Kerning

## Analogi: Perpustakaan Digital

Dalam tipografi profesional, huruf-huruf tertentu seperti "AV" atau "To" memiliki jarak yang disesuaikan secara khusus agar terlihat proporsional — huruf "A" dan "V" bisa saling "bertumpuk" sebagian. Penyesuaian ini disebut kerning dan merupakan data yang tertanam dalam font. Dalam CSS, properti font-kerning mengontrol apakah data kerning ini digunakan atau tidak.

## Penjelasan Detail

Properti font-kerning mengontrol penggunaan data kerning yang ada dalam file font. Kerning adalah penyesuaian jarak antara pasangan huruf tertentu untuk menciptakan tipografi yang lebih seimbang secara visual. Nilai auto membiarkan browser memutuskan apakah akan menggunakan kerning (biasanya diaktifkan untuk font ukuran besar). Nilai normal selalu mengaktifkan kerning. Nilai none menonaktifkan kerning. Kerning sangat penting untuk teks judul dan ukuran besar di mana ketidakseimbangan jarak antar huruf lebih terlihat. Untuk teks tubuh ukuran kecil, kerning mungkin tidak terlalu berpengaruh. Properti font-kerning adalah bagian dari pendekatan modern yang lebih semantik dibandingkan font-feature-settings: "kern".

## Contoh Kode Implementasi

```css
/* Kerning otomatis (default) */
.auto-kerning {
  font-kerning: auto;
}

/* Kerning selalu aktif */
.normal-kerning {
  font-kerning: normal;
}

/* Kerning nonaktif */
.no-kerning {
  font-kerning: none;
}

/* Aplikasi: heading dengan kerning */
h1 {
  font-kerning: normal;
  font-size: 2.5rem;
  letter-spacing: -0.01em; /* Fine-tune setelah kerning */
}

/* Aplikasi: logo */
.logo {
  font-kerning: normal;
  font-family: 'Playfair Display', Georgia, serif;
  font-size: 2rem;
}

/* Aplikasi: body text */
body {
  font-kerning: normal;
  font-size: 1rem;
  line-height: 1.6;
}

/* Aplikasi: teks kapital */
.caps-text {
  font-kerning: normal;
  text-transform: uppercase;
  letter-spacing: 0.05em;
}

/* Perbandingan visual */
.comparison {
  display: flex;
  gap: 2rem;
}

.with-kerning {
  font-kerning: normal;
}

.without-kerning {
  font-kerning: none;
}
```

## Poin Penting
- font-kerning mengontrol penggunaan data kerning dalam font untuk jarak antar huruf yang proporsional
- normal mengaktifkan kerning, none menonaktifkan, auto membiarkan browser memutuskan
- Kerning paling terlihat pada heading dan teks ukuran besar
- font-kerning adalah alternatif semantik yang lebih baik daripada font-feature-settings: "kern"
