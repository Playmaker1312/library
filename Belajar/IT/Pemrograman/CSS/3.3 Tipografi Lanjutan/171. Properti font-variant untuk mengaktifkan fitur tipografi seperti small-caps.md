# Properti Font-Variant

## Analogi: Perpustakaan Digital

Di perpustakaan digital, beberapa judul buku ditampilkan dengan huruf kapital kecil yang elegan — disebut small caps — untuk memberikan kesan formal dan klasik. Alih-alih menulis ulang teks di HTML dengan huruf kapital, CSS dapat mengubah tampilan ini secara otomatis. Dalam CSS, properti font-variant menyediakan akses ke berbagai fitur tipografi termasuk small-caps.

## Penjelasan Detail

Properti font-variant adalah properti shorthand yang mengontrol berbagai fitur tipografi font. Nilai yang paling umum adalah small-caps, yang menampilkan teks dalam huruf kapital kecil (huruf besar diperkecil ukurannya). Properti ini juga memiliki sub-properti individual seperti font-variant-caps (small-caps, all-small-caps, petite-caps, unicase, titling-caps), font-variant-numeric (lining-nums, oldstyle-nums, proportional-nums, tabular-nums, fractions, ordinal, slashed-zero), font-variant-ligatures (common-ligatures, discretionary-ligatures, historical-ligatures, contextual), font-variant-east-asian (jis78, jis83, jis90, jis04, simplified, traditional), dan font-variant-alternates. font-variant memungkinkan akses ke fitur tipografi OpenType yang kaya tanpa perlu menggunakan font-feature-settings yang lebih rendah levelnya.

## Contoh Kode Implementasi

```css
/* Small caps */
.small-caps {
  font-variant: small-caps;
}

/* All small caps (semua teks dalam kapital kecil) */
.all-small-caps {
  font-variant-caps: all-small-caps;
}

/* Nomor tabel (tabular numbers) */
.price-table {
  font-variant-numeric: tabular-nums lining-nums;
}

/* Pecahan */
.fraction {
  font-variant-numeric: diagonal-fractions;
}

/* Ordinal (1st, 2nd, 3rd) */
.ordinal {
  font-variant-numeric: ordinal;
}

/* Ligatures */
.with-ligatures {
  font-variant-ligatures: common-ligatures contextual;
}

.without-ligatures {
  font-variant-ligatures: no-common-ligatures;
}

/* East Asian */
.east-asian {
  font-variant-east-asian: proportional-width;
}

/* Shorthand */
.comprehensive {
  font-variant: small-caps tabular-nums common-ligatures;
}

/* Aplikasi: teks formal */
.formal-text {
  font-variant: small-caps;
  letter-spacing: 0.05em;
  font-size: 1.125rem;
}

/* Aplikasi: data tabel */
table.data td {
  font-variant-numeric: tabular-nums;
}
```

## Poin Penting
- font-variant menyediakan akses ke fitur tipografi seperti small-caps dan variant numerik
- Sub-properti mencakup font-variant-caps, font-variant-numeric, font-variant-ligatures, dll.
- Small-caps menampilkan huruf kapital dalam ukuran lebih kecil
- font-variant-numeric mengontrol tampilan angka (tabular, lama, pecahan)
