# Properti Overflow-Wrap

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika judul buku yang sangat panjang (misalnya "Ensiklopedia Pengetahuan Umum dan Ilmu Pengetahuan Alam") tidak muat dalam kontainer kartu, sistem akan memotong kata tersebut hanya jika benar-benar diperlukan untuk mencegah luapan. Dalam CSS, properti overflow-wrap mengontrol apakah browser boleh memotong kata panjang yang tidak bisa muat dalam satu baris.

## Penjelasan Detail

Properti overflow-wrap (sebelumnya dikenal sebagai word-wrap) menentukan apakah browser boleh memutuskan kata di tengah saat kata tersebut terlalu panjang untuk muat dalam satu baris. Nilai normal hanya mengizinkan pemutusan di titik pemutusan normal (spasi, hyphen). break-word mengizinkan pemutusan di sembarang titik jika kata tidak dapat muat dalam kontainer tanpa meluap. Berbeda dengan word-break: break-all yang memotong di mana pun untuk membuat semua baris sama panjang, overflow-wrap: break-word hanya memotong ketika benar-benar diperlukan untuk mencegah luapan. overflow-wrap lebih "cerdas" dan merupakan pilihan yang lebih baik untuk teks umum yang mungkin mengandung URL atau kata panjang sesekali.

## Contoh Kode Implementasi

```css
/* Normal: tidak ada pemutusan paksa */
.no-wrap {
  overflow-wrap: normal;
}

/* Break-word: putus hanya jika perlu */
.break-word {
  overflow-wrap: break-word;
}

/* Aplikasi: teks umum dengan kata panjang */
.content p {
  overflow-wrap: break-word;
  max-width: 100%;
}

/* Aplikasi: card dengan judul */
.card-title {
  overflow-wrap: break-word;
  font-size: 1.125rem;
  font-weight: 600;
  line-height: 1.3;
}

/* Aplikasi: komentar pengguna */
.user-comment {
  overflow-wrap: break-word;
  word-break: break-word; /* Fallback untuk browser lama */
}

/* Aplikasi: sidebar */
.sidebar-text {
  overflow-wrap: break-word;
  hyphens: auto;
}

/* Perbandingan dengan word-break */
.compare {
  overflow-wrap: break-word;
  /* Lebih baik untuk teks umum */
  
  word-break: break-all;
  /* Lebih agresif, cocok untuk URL */
}

/* Kombinasi optimal untuk konten pengguna */
.user-content {
  overflow-wrap: break-word;
  word-wrap: break-word; /* Nama lama untuk kompatibilitas */
  hyphens: auto;
}
```

## Poin Penting
- overflow-wrap: break-word memotong kata panjang hanya jika perlu mencegah luapan
- Lebih "cerdas" daripada word-break: break-all untuk teks umum
- Nama lama word-wrap masih didukung untuk kompatibilitas mundur
- Kombinasikan dengan hyphens: auto untuk hasil pemotongan yang lebih baik
