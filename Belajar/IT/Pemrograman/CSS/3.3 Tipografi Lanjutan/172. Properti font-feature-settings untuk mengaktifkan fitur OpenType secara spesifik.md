# Properti Font-Feature-Settings

## Analogi: Perpustakaan Digital

Di perpustakaan digital, font premium memiliki fitur tersembunyi seperti ligatur artistik, angka proporsional, atau alternatif kaligrafi yang tidak aktif secara default. Untuk mengakses fitur ini, Anda perlu "mengunci" kode khusus yang mengaktifkannya. Dalam CSS, properti font-feature-settings memberi Anda akses langsung ke fitur OpenType font melalui kode empat karakter.

## Penjelasan Detail

Properti font-feature-settings memungkinkan akses tingkat rendah ke fitur OpenType font menggunakan tag fitur empat karakter. Setiap fitur memiliki kode seperti "liga" (standard ligatures), "kern" (kerning), "frac" (diagonal fractions), "zero" (slashed zero), "ss01" hingga "ss20" (stylistic sets), "calt" (contextual alternates), "dlig" (discretionary ligatures), dan "smcp" (small caps). Nilai 1 mengaktifkan fitur, 0 menonaktifkan. Meskipun font-feature-settings memberikan kontrol yang sangat presisi, properti yang lebih semantik seperti font-variant sebaiknya digunakan terlebih dahulu karena lebih mudah dibaca dan dipelihara. Gunakan font-feature-settings hanya untuk fitur yang belum memiliki properti CSS standar.

## Contoh Kode Implementasi

```css
/* Mengaktifkan ligatur standar */
.ligatures {
  font-feature-settings: "liga" 1, "clig" 1;
}

/* Kerning */
.kerned {
  font-feature-settings: "kern" 1;
}

/* Fraction */
.fractions {
  font-feature-settings: "frac" 1;
}

/* Slashed zero */
.slashed-zero {
  font-feature-settings: "zero" 1;
}

/* Stylistic set */
.stylistic-alt {
  font-family: 'MyFont', serif;
  font-feature-settings: "ss01" 1, "ss02" 1;
}

/* Tabular figures */
.tabular-figs {
  font-feature-settings: "tnum" 1, "lnum" 1;
}

/* Contextual alternates */
.contextual {
  font-feature-settings: "calt" 1;
}

/* Small caps via feature settings */
.smcp {
  font-feature-settings: "smcp" 1;
}

/* Kombinasi beberapa fitur */
.complex {
  font-feature-settings: "liga" 1, "dlig" 1, "calt" 1, "kern" 1;
}

/* Nonaktifkan fitur tertentu */
.no-ligatures {
  font-feature-settings: "liga" 0;
}

/* Aplikasi: kode programming dengan ligatur */
.code-font {
  font-family: 'Fira Code', 'Cascadia Code', monospace;
  font-feature-settings: "calt" 1, "liga" 1;
}
```

## Poin Penting
- font-feature-settings menggunakan tag OpenType 4 karakter seperti "liga", "kern", "smcp"
- Nilai 1 = aktif, 0 = nonaktifkan fitur
- Gunakan properti font-variant yang lebih semantik jika tersedia
- Berguna untuk mengakses stylistic sets (ss01-ss20) dan fitur OpenType spesifik lainnya
