# Properti Word-Break

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika judul buku yang sangat panjang tidak muat dalam satu baris, sistem harus memutuskan bagaimana memotongnya. Apakah dipotong di tengah kata, atau seluruh kata dipindahkan ke baris berikutnya? Dalam CSS, properti word-break memberikan kontrol atas perilaku pemutusan kata ketika teks meluap dari kontainernya.

## Penjelasan Detail

Properti word-break mengontrol bagaimana browser memutuskan kata saat teks mencapai batas kontainer. Nilai normal menggunakan aturan default bahasa (biasanya hanya memotong di spasi atau tanda hubung). break-all memungkinkan pemutusan di titik mana pun dalam kata, bahkan di tengah karakter, untuk mencegah luapan. keep-all mencegah pemutusan untuk teks CJK (Chinese/Japanese/Korean) dan memperlakukan teks non-CJK seperti normal. word-break berbeda dari overflow-wrap (sebelumnya word-wrap), yang lebih "cerdas" dalam memutus kata panjang dengan mempertimbangkan konten yang tidak dapat diputus secara normal. Untuk teks seperti URL panjang atau kode, word-break: break-all sering menjadi solusi untuk mencegah luapan horizontal.

## Contoh Kode Implementasi

```css
/* Normal: hanya putus di spasi/hyphen */
.normal-break {
  word-break: normal;
}

/* Break-all: putus di mana pun perlu */
.break-all {
  word-break: break-all;
}

/* Keep-all: cegah pemutusan (khusus CJK) */
.keep-all {
  word-break: keep-all;
}

/* Aplikasi: URL dalam paragraf */
.url-container {
  word-break: break-all;
  background: #f7fafc;
  padding: 0.5rem;
  border-radius: 4px;
  font-family: 'Fira Code', monospace;
  font-size: 0.875rem;
}

/* Aplikasi: email */
.email-text {
  word-break: break-all;
  color: #3182ce;
}

/* Aplikasi: kode program */
.code-block {
  word-break: break-all;
  white-space: pre-wrap;
  font-family: 'Fira Code', monospace;
  font-size: 0.85rem;
  line-height: 1.5;
}

/* Tabel dengan konten panjang */
.table-cell {
  word-break: break-all;
  max-width: 200px;
}

/* Perbandingan dengan overflow-wrap */
.compare-overflow {
  overflow-wrap: break-word; /* Lebih cerdas: putus hanya jika perlu */
  word-break: break-all; /* Paksa putus di mana pun */
}
```

## Poin Penting
- word-break: normal (default) hanya memotong di spasi atau tanda hubung
- word-break: break-all memotong di titik mana pun, bahkan di tengah kata
- word-break: keep-all mencegah pemotongan untuk teks CJK
- Untuk URL panjang, word-break: break-all lebih agresif daripada overflow-wrap
