# Properti Writing-Mode

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada buku yang ditulis dari kiri ke kanan (seperti bahasa Indonesia), dari kanan ke kiri (seperti bahasa Arab), atau dari atas ke bawah (seperti bahasa Jepang tradisional). Properti writing-mode dalam CSS memungkinkan Anda mengubah orientasi penulisan teks, membuka kemungkinan untuk desain multibahasa dan efek tipografi kreatif.

## Penjelasan Detail

Properti writing-mode menentukan apakah teks ditulis secara horizontal atau vertikal, serta arah penulisan blok. Nilai horizontal-tb (default) menulis teks dari kiri ke kanan, dengan baris dari atas ke bawah (top-to-bottom). vertical-rl menulis teks secara vertikal dari atas ke bawah, dengan baris dari kanan ke kiri. vertical-lr menulis teks secara vertikal dari atas ke bawah, dengan baris dari kiri ke kanan. Properti ini mempengaruhi tidak hanya teks tetapi juga tata letak elemen anak, arah float, dan margin. writing-mode sangat berguna untuk desain yang terinspirasi tipografi Asia Timur, judul samping (sidebar titles), dan efek kreatif lainnya.

## Contoh Kode Implementasi

```css
/* Default: horizontal, baris atas ke bawah */
.horizontal {
  writing-mode: horizontal-tb;
}

/* Vertikal: dari kanan ke kiri */
.vertical-rl {
  writing-mode: vertical-rl;
}

/* Vertikal: dari kiri ke kanan */
.vertical-lr {
  writing-mode: vertical-lr;
}

/* Aplikasi: judul sidebar vertikal */
.sidebar-title {
  writing-mode: vertical-rl;
  text-orientation: mixed;
  font-size: 1.5rem;
  letter-spacing: 0.1em;
  padding: 1rem 0.5rem;
}

/* Aplikasi: label vertikal pada tabel */
.table-label {
  writing-mode: vertical-lr;
  text-orientation: upright;
  padding: 0.5rem;
  background: #f7fafc;
  font-weight: 600;
}

/* Aplikasi: navigasi vertikal */
.nav-vertical a {
  writing-mode: vertical-rl;
  text-decoration: none;
  padding: 0.5rem;
  margin: 0.25rem 0;
}

/* Text-orientation untuk kontrol karakter */
.mixed {
  text-orientation: mixed; /* Default: karakter tegak, angka miring */
}

.upright {
  text-orientation: upright; /* Semua karakter tegak */
}

.sideways {
  text-orientation: sideways; /* Semua karakter miring */
}

/* Kombinasi */
.vertical-text {
  writing-mode: vertical-rl;
  text-orientation: mixed;
  font-family: 'Noto Sans JP', sans-serif;
  line-height: 1.5;
}
```

## Poin Penting
- writing-mode mengubah arah penulisan: horizontal-tb (default), vertical-rl, vertical-lr
- vertical-rl menulis dari atas ke bawah, baris dari kanan ke kiri
- text-orientation mengontrol orientasi karakter dalam teks vertikal
- Berguna untuk desain multibahasa, judul samping, dan efek tipografi kreatif
