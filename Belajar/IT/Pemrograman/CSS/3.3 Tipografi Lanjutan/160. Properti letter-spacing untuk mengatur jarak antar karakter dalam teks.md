# Properti Letter-Spacing

## Analogi: Perpustakaan Digital

Di perpustakaan digital, judul buku di rak terkadang ditulis dengan jarak antar huruf yang lebar untuk memberikan kesan elegan dan formal. Sementara untuk teks biasa, jarak huruf diatur standar agar mudah dibaca. Dalam CSS, properti letter-spacing memberikan kontrol presisi atas jarak antar karakter dalam teks, mempengaruhi keterbacaan dan estetika.

## Penjelasan Detail

Properti letter-spacing mengatur jarak tambahan (atau pengurangan) antara setiap karakter dalam teks. Nilai dapat berupa panjang positif (untuk menambah jarak), negatif (untuk merapatkan), atau normal (nilai default 0). Satuan yang umum digunakan adalah em, px, atau rem. letter-spacing sangat sensitif — perubahan kecil sekalipun (0.01em) dapat terlihat. Nilai positif kecil (0.02em hingga 0.1em) sering digunakan pada heading dan teks kapital untuk meningkatkan keterbacaan. Nilai negatif dapat digunakan untuk efek tertentu tetapi hati-hati karena dapat mengurangi keterbacaan. letter-spacing diwariskan ke elemen anak dan dapat dianimasikan.

## Contoh Kode Implementasi

```css
/* Heading dengan spacing longgar */
h1 {
  letter-spacing: 0.05em;
  font-weight: 700;
}

/* Teks kapital */
.uppercase-text {
  text-transform: uppercase;
  letter-spacing: 0.1em;
}

/* Small caps */
.small-caps {
  font-variant: small-caps;
  letter-spacing: 0.08em;
}

/* Navigasi */
.nav-link {
  letter-spacing: 0.05em;
  text-transform: uppercase;
  font-size: 0.875rem;
}

/* Label dan tombol */
button {
  letter-spacing: 0.02em;
}

.label {
  letter-spacing: 0.03em;
  font-weight: 600;
}

/* Tracking negatif untuk compact text */
.compact {
  letter-spacing: -0.01em;
}

/* Teks normal (default) */
body {
  letter-spacing: normal; /* Sama dengan 0 */
}

/* Animasi letter-spacing */
@keyframes widen {
  from { letter-spacing: 0; }
  to { letter-spacing: 0.2em; }
}

.animate-spacing:hover {
  animation: widen 0.3s ease forwards;
}
```

## Poin Penting
- letter-spacing mengatur jarak antar karakter, dalam satuan panjang (em, px, rem)
- Nilai positif memperlebar, nilai negatif merapatkan, normal/nol adalah default
- Heading dan teks kapital sering menggunakan letter-spacing positif
- Perubahan kecil (0.01-0.05em) sudah memberikan efek yang signifikan
