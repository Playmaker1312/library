# Properti Direction

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada katalog yang ditulis dalam bahasa Arab atau Ibrani yang dibaca dari kanan ke kiri. Sistem harus bisa mengakomodasi arah baca yang berbeda ini tanpa mengubah struktur HTML. Dalam CSS, properti direction memberikan kontrol atas arah aliran teks dalam elemen, mendukung konten multibahasa dengan benar.

## Penjelasan Detail

Properti direction mengatur arah teks dasar dalam elemen. Nilai ltr (left-to-right) adalah default untuk bahasa seperti Indonesia, Inggris, dan kebanyakan bahasa Eropa. Nilai rtl (right-to-left) digunakan untuk bahasa seperti Arab, Ibrani, dan Urdu. direction mempengaruhi urutan penulisan karakter, arah teks, arah float default, dan posisi awal elemen inline. Namun, untuk kontrol yang lebih komprehensif, gunakan atribut HTML dir pada elemen (dir="ltr" atau dir="rtl") yang juga mempengaruhi arah kolom tabel, scrollbar, dan elemen lainnya. direction paling berguna ketika Anda perlu mengubah arah teks untuk sebagian kecil halaman tanpa mengubah atribut HTML.

## Contoh Kode Implementasi

```css
/* Arah teks kiri ke kanan (default) */
.ltr-text {
  direction: ltr;
}

/* Arah teks kanan ke kiri */
.rtl-text {
  direction: rtl;
}

/* Aplikasi: elemen dengan teks Arab */
.arabic-quote {
  direction: rtl;
  font-family: 'Amiri', 'Traditional Arabic', serif;
  font-size: 1.25rem;
  line-height: 1.8;
}

/* Aplikasi: UI mix */
.mixed-ui {
  /* Kontainer RTL */
  direction: rtl;
}

.mixed-ui .english-text {
  /* Inner LTR override */
  direction: ltr;
  unicode-bidi: embed;
}

/* Unicide-bidi untuk kontrol lebih */
.override {
  direction: rtl;
  unicode-bidi: bidi-override; /* Memaksa urutan karakter */
}

.embed {
  direction: ltr;
  unicode-bidi: embed; /* Mempertahankan konteks */
}

/* Aplikasi: ikon panah yang berubah arah */
.arrow {
  direction: ltr;
}

[dir="rtl"] .arrow {
  direction: rtl;
}

/* Unicide-bidi isolate untuk mencegah kebocoran */
.isolate {
  unicode-bidi: isolate;
  direction: ltr;
}
```

## Poin Penting
- direction: ltr (default) atau rtl untuk mengontrol arah teks
- Untuk dukungan multibahasa penuh, gunakan atribut HTML dir sebagai preferensi
- unicode-bidi mengontrol bagaimana teks dengan arah berbeda berinteraksi
- direction mempengaruhi float, alignment, dan properti layout lainnya
