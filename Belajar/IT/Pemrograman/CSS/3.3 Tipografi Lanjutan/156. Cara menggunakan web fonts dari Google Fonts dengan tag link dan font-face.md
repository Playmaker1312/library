# Cara Menggunakan Web Fonts dari Google Fonts

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda tidak harus menulis semua buku sendiri. Anda bisa meminjam buku dari perpustakaan lain melalui sistem antar-perpustakaan. Google Fonts adalah seperti perpustakaan font raksasa yang memungkinkan Anda "meminjam" font untuk digunakan di situs web Anda. Anda bisa mengambilnya melalui tautan (link) atau mengunduhnya (font-face).

## Penjelasan Detail

Google Fonts menyediakan dua cara untuk memuat font ke dalam proyek web. Pertama, melalui tag <link> di HTML — Anda cukup menambahkan link stylesheet yang disediakan oleh Google Fonts ke dalam <head> dokumen HTML. Kedua, melalui at-rule @import di file CSS — Anda menambahkan @import url() di awal stylesheet. Kedua metode ini memuat font dari server Google. Alternatif ketiga adalah mengunduh file font dan menyimpannya secara lokal, lalu mendefinisikannya dengan @font-face. Pendekatan lokal memberikan kontrol lebih besar dan tidak bergantung pada ketersediaan server pihak ketiga. Saat memilih font, perhatikan performa — terlalu banyak variasi font berat akan memperlambat waktu muat halaman.

## Contoh Kode Implementasi

```css
/* Metode 1: HTML <link> (di file HTML, bukan CSS) */
/* <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Merriweather:wght@400;700&display=swap" rel="stylesheet"> */

/* Metode 2: @import di CSS */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Merriweather:wght@400;700&display=swap');

/* Metode 3: @font-face lokal (setelah download) */
@font-face {
  font-family: 'Inter';
  src: url('fonts/Inter-Regular.woff2') format('woff2'),
       url('fonts/Inter-Regular.woff') format('woff');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: 'Inter';
  src: url('fonts/Inter-Bold.woff2') format('woff2'),
       url('fonts/Inter-Bold.woff') format('woff');
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}

/* Penggunaan font */
body {
  font-family: 'Inter', system-ui, -apple-system, sans-serif;
  font-weight: 400;
}

h1, h2, h3 {
  font-family: 'Merriweather', Georgia, serif;
  font-weight: 700;
}
```

## Poin Penting
- Google Fonts bisa dimuat via <link> di HTML atau @import di CSS
- @font-face digunakan untuk font lokal dengan mendefinisikan src, format, dan font-weight
- Pilih hanya variasi font yang diperlukan untuk performa optimal
- font-display: swap mencegah FOIT (Flash of Invisible Text)
