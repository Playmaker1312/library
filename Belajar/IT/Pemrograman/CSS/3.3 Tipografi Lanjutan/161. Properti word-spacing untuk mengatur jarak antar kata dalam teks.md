# Properti Word-Spacing

## Analogi: Perpustakaan Digital

Di perpustakaan digital, teks dalam ringkasan buku bisa diatur jarak antar katanya. Jarak yang terlalu rapat membuat teks sulit dibaca, sementara jarak yang terlalu lebar membuat teks terlihat tidak padu. Dalam CSS, properti word-spacing memberi Anda kontrol atas jarak horizontal antar kata dalam teks.

## Penjelasan Detail

Properti word-spacing mengatur jarak tambahan antara setiap kata dalam teks. Nilainya bisa berupa panjang positif (menambah jarak), negatif (mengurangi jarak), atau normal (default 0). Seperti letter-spacing, satuan yang umum adalah em, px, atau rem. word-spacing mempengaruhi spasi antar kata yang dihasilkan oleh karakter spasi di HTML. Nilai normal berarti tidak ada tambahan jarak dari default font. Nilai positif membuat teks lebih "airy" tetapi bisa membuat teks terlihat terputus-putus jika terlalu besar. Nilai negatif merapatkan kata tetapi dapat menyebabkan kata-kata saling bertabrakan. word-spacing berguna untuk tipografi yang lebih baik pada teks justify atau untuk gaya desain tertentu.

## Contoh Kode Implementasi

```css
/* Teks justify dengan word-spacing */
.text-justify {
  text-align: justify;
  word-spacing: 0.05em;
}

/* Teks longgar untuk efek desain */
.loose-text {
  word-spacing: 0.2em;
}

/* Teks rapat */
.tight-text {
  word-spacing: -0.05em;
}

/* Normal */
body {
  word-spacing: normal;
}

/* Kombinasi letter-spacing dan word-spacing */
.hero-title {
  font-size: 2.5rem;
  letter-spacing: 0.02em;
  word-spacing: 0.1em;
  font-weight: 300;
}

/* Paragraf dengan word-spacing meningkat */
p {
  word-spacing: 0.03em;
  line-height: 1.7;
}

/* Heading kapital */
.section-title {
  text-transform: uppercase;
  word-spacing: 0.15em;
  letter-spacing: 0.08em;
}

/* Animasi */
@keyframes space-out {
  from { word-spacing: 0; }
  to { word-spacing: 0.5em; }
}

.spacer:hover {
  animation: space-out 0.5s ease forwards;
}
```

## Poin Penting
- word-spacing mengatur jarak tambahan antar kata dalam teks
- Nilai positif memperlebar jarak, negatif merapatkan, normal/default adalah 0
- Berguna untuk fine-tuning tipografi terutama pada teks justify
- Kombinasikan dengan letter-spacing untuk kontrol tipografi yang presisi
