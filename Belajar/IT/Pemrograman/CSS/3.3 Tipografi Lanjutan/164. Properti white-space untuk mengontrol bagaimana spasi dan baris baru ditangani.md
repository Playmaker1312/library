# Properti White-Space

## Analogi: Perpustakaan Digital

Di perpustakaan digital, teks dalam katalog buku bisa ditampilkan dalam berbagai cara: bisa dipotong otomatis agar muat dalam satu baris, bisa mempertahankan format asli termasuk baris baru, atau bisa menggabungkan spasi berlebih menjadi satu spasi. Dalam CSS, properti white-space mengontrol bagaimana spasi, tab, dan baris baru dalam HTML ditampilkan.

## Penjelasan Detail

Properti white-space mengontrol tiga aspek penanganan spasi: collapsing (penggabungan spasi berurutan), wrapping (pemotongan baris), dan preservasi spasi. Nilai normal (default) menggabungkan spasi berurutan dan memotong baris secara otomatis. nowrap mencegah pemotongan baris. pre mempertahankan spasi dan baris baru seperti di HTML (mirip tag <pre>). pre-wrap mempertahankan spasi tetapi tetap membungkus baris saat meluap. pre-line menggabungkan spasi berurutan tetapi mempertahankan baris baru. Nilai-nilai ini berguna untuk menampilkan kode, alamat, puisi, data tabular, atau teks dari sumber eksternal di mana format spasi penting.

## Contoh Kode Implementasi

```css
/* Normal: spasi digabung, baris dipotong otomatis */
.normal {
  white-space: normal;
}

/* Nowrap: spasi digabung, baris TIDAK dipotong */
.nowrap {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Pre: spasi dan baris baru dipertahankan */
.pre {
  white-space: pre;
  font-family: 'Courier New', monospace;
}

/* Pre-wrap: spasi dipertahankan, baris dipotong otomatis */
.pre-wrap {
  white-space: pre-wrap;
  word-wrap: break-word;
}

/* Pre-line: spasi digabung, baris baru dipertahankan */
.pre-line {
  white-space: pre-line;
}

/* Aplikasi: kode program */
code {
  white-space: pre;
  background: #f7fafc;
  padding: 0.5rem;
  border-radius: 4px;
  display: block;
  overflow-x: auto;
}

/* Aplikasi: alamat */
.address {
  white-space: pre-line;
  font-style: normal;
}

/* Aplikasi: teks puisi */
.poem {
  white-space: pre-wrap;
  font-style: italic;
  line-height: 2;
}
```

## Poin Penting
- white-space mengontrol collapsing, wrapping, dan preservasi spasi
- nowrap mencegah wrap baris, berguna dengan text-overflow: ellipsis
- pre mempertahankan format asli seperti tag <pre>
- pre-wrap dan pre-line memberikan fleksibilitas antara preservasi dan wrapping
