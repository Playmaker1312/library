# Properti Text-Shadow

## Analogi: Perpustakaan Digital

Di perpustakaan digital, judul buku utama bisa diberi efek bayangan halus di belakangnya sehingga tampak seperti timbul atau melayang di atas halaman. Efek ini memberikan kedalaman visual dan membuat teks lebih menonjol. Dalam CSS, properti text-shadow memungkinkan Anda menambahkan satu atau lebih bayangan pada teks.

## Penjelasan Detail

Properti text-shadow menerima daftar bayangan yang dipisahkan koma, masing-masing dengan offset-x, offset-y, blur-radius (opsional), dan color. offset-x dan offset-y menentukan pergeseran bayangan horizontal dan vertikal (nilai positif ke kanan/bawah, negatif ke kiri/atas). blur-radius menentukan seberapa kabur bayangan (nilai 0 = tajam). color menentukan warna bayangan. Anda dapat menambahkan beberapa bayangan sekaligus untuk efek yang lebih kompleks seperti efek neon, 3D, atau emboss. text-shadow berbeda dari box-shadow yang diterapkan pada kotak elemen, bukan pada teks itu sendiri.

## Contoh Kode Implementasi

```css
/* Bayangan sederhana */
h1 {
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.2);
}

/* Bayangan halus */
.subtle {
  text-shadow: 0 1px 2px rgba(0, 0, 0, 0.1);
}

/* Bayangan tanpa blur (tajam) */
.sharp-shadow {
  text-shadow: 3px 3px 0 #cbd5e0;
}

/* Efek neon */
.neon {
  color: #00ff00;
  text-shadow: 0 0 5px #00ff00,
               0 0 10px #00ff00,
               0 0 20px #00ff00,
               0 0 40px #00ff00;
}

/* Efek emboss (timbul) */
.emboss {
  color: #2d3748;
  text-shadow: 0 1px 0 white,
               0 -1px 0 #a0aec0;
}

/* Efek fire */
.fire {
  color: #e53e3e;
  text-shadow: 0 0 5px #ed8936,
               0 -5px 10px #dd6b20,
               0 -10px 20px #c05621;
}

/* Multiple bayangan untuk efek 3D */
.text-3d {
  color: #4299e1;
  text-shadow: 1px 1px 0 #3182ce,
               2px 2px 0 #2b6cb0,
               3px 3px 0 #2c5282;
}

/* Bayangan pada link hover */
a:hover {
  text-shadow: 0 0 3px rgba(66, 153, 225, 0.5);
}
```

## Poin Penting
- text-shadow: offset-x offset-y blur-radius color
- Multiple bayangan dipisahkan koma untuk efek kompleks (neon, 3D)
- blur-radius opsional, 0 menghasilkan bayangan tajam
- text-shadow mempengaruhi teks, bukan kotak elemen (box-shadow untuk kotak)
