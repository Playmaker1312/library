# Properti Font-Display

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika gambar sampul buku sedang dimuat dari server, Anda memiliki pilihan: menampilkan placeholder abu-abu sampai gambar siap, atau membiarkan area kosong dan tiba-tiba menampilkan gambar. Masing-masing memiliki dampak pengalaman pengguna yang berbeda. Dalam CSS, properti font-display mengontrol bagaimana browser menampilkan teks sementara font kustom sedang dimuat.

## Penjelasan Detail

Properti font-display digunakan dalam at-rule @font-face untuk mengontrol strategi rendering teks selama font kustom dimuat. Ada lima nilai yang tersedia: auto (default browser, biasanya mirip block), block (FOIT — Flash of Invisible Text — browser menyembunyikan teks hingga 3 detik sambil menunggu font), swap (FOUT — Flash of Unstyled Text — browser menampilkan teks dengan font fallback segera, lalu menukar ke font kustom saat siap), fallback (kompromi — periode blok singkat ~100ms, lalu swap, dan jika font tidak dimuat dalam ~3 detik, font fallback akan digunakan seterusnya), dan optional (periode blok sangat singkat, font kustom hanya digunakan jika sudah dimuat sebelumnya dari cache). Nilai swap paling umum digunakan untuk menyeimbangkan antara performa dan estetika.

## Contoh Kode Implementasi

```css
/* swap - tampilkan font fallback segera, tukar saat font siap */
@font-face {
  font-family: 'BodyFont';
  src: url('fonts/body.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}

/* block - FOIT, sembunyikan teks sampai font siap (maks 3 detik) */
@font-face {
  font-family: 'HeroFont';
  src: url('fonts/hero.woff2') format('woff2');
  font-weight: 700;
  font-display: block;
}

/* fallback - blok singkat lalu swap, jika timeout pakai fallback permanen */
@font-face {
  font-family: 'DecorativeFont';
  src: url('fonts/decorative.woff2') format('woff2');
  font-weight: 400;
  font-display: fallback;
}

/* optional - hanya pakai font kustom jika sudah di-cache */
@font-face {
  font-family: 'OptionalFont';
  src: url('fonts/optional.woff2') format('woff2');
  font-weight: 400;
  font-display: optional;
}

/* Penggunaan font */
body {
  font-family: 'BodyFont', 'Segoe UI', system-ui, sans-serif;
}

h1 {
  font-family: 'HeroFont', Georgia, serif;
}
```

## Poin Penting
- font-display mengontrol perilaku rendering selama font kustom dimuat
- swap adalah nilai paling umum — menampilkan fallback segera, swap saat font siap
- block menyebabkan FOIT (teks tidak terlihat) hingga 3 detik
- optional hanya menggunakan font kustom jika sudah ada di cache browser
- Pilih strategi berdasarkan prioritas: kecepatan tampil (swap) vs presisi desain (block)
