# Format File Font

## Analogi: Perpustakaan Digital

Di perpustakaan digital, buku bisa hadir dalam berbagai format: PDF, EPUB, MOBI. Masing-masing memiliki kelebihan dalam ukuran file, kompatibilitas, dan fitur. Pembaca digital harus mendukung format tertentu untuk menampilkan buku. Dalam CSS, file font juga hadir dalam berbagai format seperti WOFF2, WOFF, TTF, dan EOT — masing-masing dengan tingkat kompresi dan dukungan browser yang berbeda.

## Penjelasan Detail

Format font web yang paling umum meliputi WOFF2 (Web Open Font Format 2) yang menawarkan kompresi terbaik (30-50% lebih kecil dari WOFF) dan didukung oleh semua browser modern. WOFF (Web Open Font Format) adalah standar sebelumnya dengan kompresi yang baik dan dukungan browser yang luas termasuk browser lama. TTF (TrueType Font) adalah format standar yang telah ada sejak lama, dengan ukuran file lebih besar tanpa kompresi khusus web. EOT (Embedded OpenType) adalah format proprietary Microsoft yang hanya didukung oleh Internet Explorer. Praktik terbaik saat ini adalah menyediakan WOFF2 sebagai format utama dengan WOFF sebagai fallback, dan mengabaikan TTF serta EOT untuk proyek modern yang tidak perlu mendukung browser very old.

## Contoh Kode Implementasi

```css
/* Prioritas format: WOFF2 > WOFF > TTF > EOT */
@font-face {
  font-family: 'ModernFont';
  
  /* WOFF2 - prioritas utama, browser modern */
  src: url('fonts/modern.woff2') format('woff2'),
  
       /* WOFF - fallback untuk browser yang lebih lama */
       url('fonts/modern.woff') format('woff'),
  
       /* TTF - fallback terakhir */
       url('fonts/modern.ttf') format('truetype'),
  
       /* EOT - hanya untuk IE lama */
       url('fonts/modern.eot') format('embedded-opentype');
  
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

/* Konversi ukuran file (estimasi) */
/* Regular 400: TTF ~150KB, WOFF ~80KB, WOFF2 ~45KB */
/* Bold 700: TTF ~150KB, WOFF ~85KB, WOFF2 ~48KB */

/* Strategi modern: hanya WOFF2 */
@font-face {
  font-family: 'EfficientFont';
  src: url('fonts/efficient.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

## Poin Penting
- WOFF2 adalah format terbaik dengan kompresi tertinggi dan dukungan browser modern
- WOFF adalah fallback yang baik untuk browser yang tidak mendukung WOFF2
- TTF tidak terkompresi dan lebih besar, tetapi didukung hampir di mana-mana
- EOT hanya diperlukan untuk Internet Explorer lama, bisa diabaikan untuk proyek modern
