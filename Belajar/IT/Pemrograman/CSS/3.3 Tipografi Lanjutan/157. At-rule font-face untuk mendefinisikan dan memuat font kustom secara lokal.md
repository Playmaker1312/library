# At-Rule Font-Face

## Analogi: Perpustakaan Digital

Di perpustakaan digital, kadang Anda perlu menambahkan buku langka yang tidak tersedia di perpustakaan lain. Anda harus mendaftarkan buku tersebut ke dalam sistem katalog dengan informasi detail seperti judul, penulis, dan lokasi penyimpanan. Dalam CSS, @font-face adalah proses pendaftaran font kustom ke dalam sistem, menentukan nama font, lokasi file, dan karakteristiknya.

## Penjelasan Detail

At-rule @font-face memungkinkan Anda mendefinisikan font kustom yang akan digunakan dalam stylesheet. Dengan @font-face, Anda dapat memuat file font dari server lokal atau eksternal dan memberikan nama keluarga (font-family) untuk digunakan nanti dalam deklarasi font. @font-face membutuhkan setidaknya dua properti: font-family (nama yang akan digunakan) dan src (lokasi file font). Anda dapat mendefinisikan beberapa variasi font (regular, bold, italic, dll) dengan @font-face terpisah. Properti tambahan seperti font-weight, font-style, font-stretch, font-display, dan unicode-range membantu browser memilih variasi font yang tepat untuk setiap penggunaan.

## Contoh Kode Implementasi

```css
/* Definisi font regular */
@font-face {
  font-family: 'MyCustomFont';
  src: url('fonts/custom-font-regular.woff2') format('woff2'),
       url('fonts/custom-font-regular.woff') format('woff'),
       url('fonts/custom-font-regular.ttf') format('truetype');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

/* Definisi font bold */
@font-face {
  font-family: 'MyCustomFont';
  src: url('fonts/custom-font-bold.woff2') format('woff2'),
       url('fonts/custom-font-bold.woff') format('woff');
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}

/* Definisi font italic */
@font-face {
  font-family: 'MyCustomFont';
  src: url('fonts/custom-font-italic.woff2') format('woff2');
  font-weight: 400;
  font-style: italic;
  font-display: swap;
}

/* Definisi dengan unicode-range */
@font-face {
  font-family: 'MyCustomFont';
  src: url('fonts/custom-font-latin.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  unicode-range: U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC;
  font-display: swap;
}

/* Penggunaan */
body {
  font-family: 'MyCustomFont', 'Segoe UI', sans-serif;
}

strong {
  font-weight: 700; /* Akan menggunakan variasi bold */
}

em {
  font-style: italic; /* Akan menggunakan variasi italic */
}
```

## Poin Penting
- @font-face mendaftarkan font kustom dengan nama font-family dan lokasi file src
- Definisi terpisah diperlukan untuk setiap variasi weight dan style
- Gunakan format woff2 sebagai prioritas utama untuk performa terbaik
- font-display: swap mencegah teks tidak terlihat saat font dimuat
