# Properti Text-Indent

## Analogi: Perpustakaan Digital

Dalam buku cetak tradisional, baris pertama setiap paragraf biasanya menjorok masuk (indentasi) untuk menandai awal paragraf baru. Di perpustakaan digital, efek ini juga bisa diterapkan pada teks digital. Dalam CSS, properti text-indent memberikan kemampuan untuk mengatur indentasi baris pertama dari sebuah elemen blok.

## Penjelasan Detail

Properti text-indent mengatur seberapa jauh baris pertama teks dalam elemen blok harus menjorok ke dalam (atau ke luar jika nilai negatif). Nilai dapat berupa panjang absolut (px, pt), panjang relatif (em, rem), atau persentase (dari lebar kontainer). text-indent hanya mempengaruhi baris pertama dari elemen blok, bukan baris-baris berikutnya. Nilai positif membuat baris pertama menjorok ke kanan, nilai negatif membuatnya menjorok ke kiri (biasanya digunakan dengan padding-left untuk efek hanging indent). Properti ini berguna untuk tipografi paragraf tradisional, daftar pustaka, dan efek desain tertentu.

## Contoh Kode Implementasi

```css
/* Indentasi standar paragraf */
p {
  text-indent: 2em;
  margin-bottom: 0.5em;
}

/* Paragraf tanpa indentasi */
p.no-indent {
  text-indent: 0;
}

/* Indentasi dengan satuan px */
.article p {
  text-indent: 40px;
}

/* Hanging indent (untuk daftar pustaka) */
.reference {
  text-indent: -2em;
  padding-left: 2em;
}

/* Indentasi persentase */
.indent-percent {
  text-indent: 10%;
}

/* Paragraf pertama tanpa indentasi */
.article p:first-of-type {
  text-indent: 0;
}

/* Indentasi negatif */
.negative-indent {
  text-indent: -1em;
  padding-left: 1.5em;
}

/* Efek khusus: baris pertama menjorok keluar */
.pull-quote {
  text-indent: -0.5em;
  font-size: 1.25rem;
  font-weight: 600;
  color: #2b6cb0;
}

/* Drop cap dengan text-indent */
.dropcap {
  text-indent: 0;
}

.dropcap::first-letter {
  font-size: 3em;
  float: left;
  margin-right: 0.25em;
  line-height: 0.8;
}
```

## Poin Penting
- text-indent mengatur indentasi baris pertama elemen blok
- Nilai positif menjorok ke kanan, negatif menjorok ke kiri
- Satuan em atau rem lebih responsif daripada px
- Hanging indent: text-indent negatif + padding-left positif untuk efek menjorok keluar
