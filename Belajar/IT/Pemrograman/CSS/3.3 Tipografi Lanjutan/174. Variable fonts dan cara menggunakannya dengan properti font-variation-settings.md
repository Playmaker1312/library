# Variable Fonts

## Analogi: Perpustakaan Digital

Bayangkan satu file font yang bisa menghasilkan gaya tak terbatas — dari tipis hingga tebal, dari sempit hingga lebar, dari miring hingga tegak — hanya dengan menyesuaikan slider. Ini seperti memiliki satu buku yang bisa berubah menjadi novel, kamus, atau ensiklopedia tergantung bagaimana Anda membacanya. Inilah yang ditawarkan variable fonts: satu file font yang berisi seluruh spektrum variasi desain font.

## Penjelasan Detail

Variable fonts adalah format font OpenType yang memungkinkan satu file font berisi banyak variasi (weight, width, slant, italic, optical size, dll.) dalam satu paket. Alih-alih memuat file terpisah untuk Regular, Bold, Light, Black, Condensed, Expanded, Anda cukup memuat satu file yang berisi semua variasi tersebut. Sumbu variasi (axes) utama meliputi wght (weight), wdth (width), slnt (slant), ital (italic), dan opsz (optical size). Properti font-variation-settings digunakan untuk mengontrol sumbu-sumbu ini dengan pasangan tag dan nilai. CSS juga mendukung properti standar seperti font-weight dan font-stretch untuk sumbu yang sesuai. Variable fonts menghemat bandwidth, memberikan fleksibilitas desain yang lebih besar, dan memungkinkan animasi font yang mulus.

## Contoh Kode Implementasi

```css
/* Memuat variable font */
@font-face {
  font-family: 'MyVariableFont';
  src: url('fonts/MyVariableFont.woff2') format('woff2-variations');
  font-weight: 100 900;
  font-stretch: 75% 125%;
}

/* Menggunakan properti standar */
.variable-demo {
  font-family: 'MyVariableFont', sans-serif;
  font-weight: 400;
  font-stretch: 100%;
}

/* Berat berbeda */
.light { font-weight: 300; }
.regular { font-weight: 400; }
.medium { font-weight: 500; }
.semibold { font-weight: 600; }
.bold { font-weight: 700; }
.black { font-weight: 900; }

/* font-variation-settings untuk kontrol penuh */
.custom-variation {
  font-family: 'MyVariableFont', sans-serif;
  font-variation-settings: "wght" 650, "wdth" 110, "slnt" -5;
}

/* Optical size */
.optical-size {
  font-family: 'MyVariableFont', sans-serif;
  font-variation-settings: "opsz" 36;
}

/* Animasi variable font */
@keyframes weight-animation {
  0% { font-variation-settings: "wght" 100; }
  50% { font-variation-settings: "wght" 900; }
  100% { font-variation-settings: "wght" 100; }
}

.animated-font {
  font-family: 'MyVariableFont', sans-serif;
  animation: weight-animation 3s ease infinite;
}

/* Mendeteksi dukungan variable font */
@supports (font-variation-settings: normal) {
  body {
    font-family: 'MyVariableFont', sans-serif;
  }
}
```

## Poin Penting
- Variable fonts menyimpan banyak variasi dalam satu file, menghemat bandwidth
- Sumbu utama: wght (weight), wdth (width), slnt (slant), ital (italic), opsz (optical size)
- Gunakan properti CSS standar (font-weight) atau font-variation-settings untuk kontrol
- Variable fonts memungkinkan animasi font yang mulus antar variasi
