# Nilai timing function bawaan yaitu ease, linear, ease-in, ease-out, dan ease-in-out

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki lima pola gerakan rak buku yang berbeda. ease seperti petugas yang mendorong rak dengan lembut, kecepatan berubah secara alami. linear seperti konveyor otomatis yang bergerak konstan. ease-in seperti kereta yang baru berangkat, lambat lalu cepat. ease-out seperti kereta yang akan berhenti, cepat lalu lambat. ease-in-out seperti lift, lambat saat mulai dan berhenti, cepat di tengah.

## Penjelasan Detail

CSS menyediakan lima nilai built-in untuk `transition-timing-function` yang mewakili kurva percepatan berbeda. `ease` adalah nilai default dengan kurva yang mirip cubic-bezier(0.25, 0.1, 0.25, 1.0). `linear` setara dengan cubic-bezier(0.0, 0.0, 1.0, 1.0). `ease-in` setara dengan cubic-bezier(0.42, 0.0, 1.0, 1.0). `ease-out` setara dengan cubic-bezier(0.0, 0.0, 0.58, 1.0). `ease-in-out` setara dengan cubic-bezier(0.42, 0.0, 0.58, 1.0). Setiap nilai menciptakan sensasi gerakan yang berbeda dan cocok untuk konteks yang berbeda. Pemahaman tentang kelima nilai ini penting sebelum beralih ke fungsi cubic-bezier kustom.

## Contoh Kode Implementasi

```css
/* Kelima timing function dibandingkan */
.timing-demo {
  display: flex;
  flex-direction: column;
  gap: 1rem;
  padding: 2rem;
}

.timing-item {
  display: flex;
  align-items: center;
  gap: 1rem;
}

.timing-label {
  width: 120px;
  font-size: 0.875rem;
  font-family: monospace;
  color: #666;
}

.timing-box {
  width: 80px;
  height: 80px;
  border-radius: 8px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
  font-size: 0.75rem;
  font-weight: bold;
  cursor: pointer;
  transition-property: transform;
  transition-duration: 1s;
}

.timing-box:hover {
  transform: translateX(200px);
}

.ease-box {
  background: #4285f4;
  transition-timing-function: ease;
}

.linear-box {
  background: #34a853;
  transition-timing-function: linear;
}

.ease-in-box {
  background: #ea4335;
  transition-timing-function: ease-in;
}

.ease-out-box {
  background: #fbbc05;
  transition-timing-function: ease-out;
}

.ease-in-out-box {
  background: #8e44ad;
  transition-timing-function: ease-in-out;
}

/* Penerapan pada komponen nyata */
.modal {
  transition-property: opacity, transform;
  transition-duration: 0.3s;
  transition-timing-function: ease-out;
}

.modal.closing {
  transition-timing-function: ease-in;
}

.notification {
  transition-property: transform, opacity;
  transition-duration: 0.4s;
  transition-timing-function: ease-out;
}

/* Rekomendasi penggunaan */
.button {
  transition-property: background-color, transform;
  transition-duration: 0.2s;
  transition-timing-function: ease-out;
}

.slide-in {
  transition-property: transform;
  transition-duration: 0.3s;
  transition-timing-function: ease-out;
}

.slide-out {
  transition-property: transform;
  transition-duration: 0.3s;
  transition-timing-function: ease-in;
}

.fade {
  transition-property: opacity;
  transition-duration: 0.2s;
  transition-timing-function: linear;
}
```

## Poin Penting
- ease: default, cocok untuk sebagian besar transisi
- linear: gerakan konstan, cocok untuk opacity dan warna
- ease-out: paling alami untuk interaksi pengguna (hover, klik)
- ease-in: cocok untuk elemen yang menghilang atau meninggalkan layar
- ease-in-out: cocok untuk transisi bolak-balik antara dua keadaan
