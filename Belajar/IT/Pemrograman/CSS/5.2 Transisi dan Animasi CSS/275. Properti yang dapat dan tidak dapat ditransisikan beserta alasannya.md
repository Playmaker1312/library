# Properti yang dapat dan tidak dapat ditransisikan beserta alasannya

## Analogi: Perpustakaan Digital

Perpustakaan digital mengetahui properti mana yang bisa dianimasikan dan mana yang tidak. Ukuran buku bisa diperbesar secara halus. Posisi buku bisa digerakkan mulus. Tapi judul buku tidak bisa berubah secara bertahap dari "Sejarah" menjadi "Geografi" karena teks adalah nilai diskrit. Warna sampul bisa berubah perlahan, tetapi jenis bahan sampul (keras/lunak) tidak bisa bertransisi karena bersifat kategoris.

## Penjelasan Detail

Properti CSS yang dapat ditransisikan adalah properti yang nilainya berada dalam rentang numerik atau gradien yang dapat diinterpolasi. Properti numerik seperti `opacity` (0-1), `transform` (matrix), `width`, `height`, `font-size`, `margin`, `padding`, `border-width` dapat ditransisikan karena browser dapat menghitung nilai di antara dua keadaan. Properti warna seperti `color`, `background-color`, `border-color` juga dapat ditransisikan karena warna adalah spektrum yang kontinu. Properti yang tidak dapat ditransisikan adalah properti dengan nilai diskrit seperti `display` (none, block), `visibility` (collapse tidak bisa), `font-family`, `text-align`, `overflow`. Properti `visibility` dapat ditransisikan meskipun diskrit karena browser menginterpolasinya secara khusus.

## Contoh Kode Implementasi

```css
/* PROSES YANG DAPAT DITRANSISIKAN */

/* Numerik */
.transition-width {
  width: 200px;
  transition: width 0.3s ease;
}

.transition-width:hover {
  width: 300px;
}

/* Warna */
.transition-color {
  color: #333;
  background-color: #fff;
  transition: color 0.3s, background-color 0.3s;
}

.transition-color:hover {
  color: #1a73e8;
  background-color: #e8f0fe;
}

/* Transform */
.transition-transform {
  transition: transform 0.3s ease-out;
}

.transition-transform:hover {
  transform: translateX(50px) scale(1.1) rotate(5deg);
}

/* Opacity */
.transition-opacity {
  opacity: 1;
  transition: opacity 0.3s ease;
}

.transition-opacity:hover {
  opacity: 0.7;
}

/* Filter */
.transition-filter {
  transition: filter 0.3s ease;
}

.transition-filter:hover {
  filter: brightness(1.2) saturate(1.1);
}

/* Box shadow */
.transition-shadow {
  transition: box-shadow 0.3s ease;
}

.transition-shadow:hover {
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
}

/* PROSES YANG TIDAK DAPAT DITRANSISIKAN */

/* display: berubah instan */
.display-none {
  /* display: none ke block tidak bisa ditransisikan */
  display: block;
}

/* overflow: tidak bisa ditransisikan */
.overflow-transition {
  /* overflow: hidden ke visible tidak bisa */
  overflow: hidden;
}

/* font-family: tidak bisa */
.font-transition {
  /* font-family: serif ke sans-serif tidak bisa */
  font-family: serif;
}

/* Solusi alternatif untuk display none */
.alternative {
  opacity: 0;
  max-height: 0;
  overflow: hidden;
  transition: opacity 0.3s ease, max-height 0.5s ease;
}

.alternative.active {
  opacity: 1;
  max-height: 500px;
}

/* visibility: dapat ditransisikan dengan durasi */
.visibility-demo {
  visibility: hidden;
  opacity: 0;
  transition: visibility 0s linear 0.3s, opacity 0.3s ease;
}

.visibility-demo.active {
  visibility: visible;
  opacity: 1;
  transition-delay: 0s;
}
```

## Poin Penting
- Properti numerik, warna, transform, opacity, filter dapat ditransisikan
- Properti diskrit seperti display, font-family, overflow tidak dapat ditransisikan
- visibility dapat ditransisikan secara khusus (delay saat hide)
- Gunakan opacity + max-height sebagai alternatif untuk efek show/hide
