# Properti animation-iteration-count dengan nilai angka atau infinite untuk pengulangan

## Analogi: Perpustakaan Digital

Perpustakaan digital menentukan berapa kali sebuah gerakan diulang. Buku yang muncul cukup sekali (1 iterasi). Loading spinner berputar terus-menerus (infinite). Notifikasi yang berkedip tiga kali lalu berhenti (3 iterasi). Efek pulsa pada tombol yang berdenyut lima kali saat diklik (5 iterasi). Setiap animasi memiliki jumlah pengulangan yang sesuai dengan tujuannya.

## Penjelasan Detail

`animation-iteration-count` menentukan berapa kali animasi dijalankan. Nilai numerik (1, 2, 3, dst.) membatasi jumlah siklus. Nilai `infinite` membuat animasi berulang terus-menerus. Nilai desimal seperti `1.5` diperbolehkan, di mana animasi akan berhenti di tengah siklus. Nilai `0` menyebabkan animasi tidak berjalan. Nilai negatif tidak valid. Untuk animasi entrance, biasanya digunakan 1 iterasi. Untuk animasi perhatian (attention seeker) seperti pulse atau shake, 2-5 iterasi sudah cukup. Untuk loading indicator, infinite adalah pilihan yang tepat.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}

@keyframes shake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-5px); }
  75% { transform: translateX(5px); }
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}

/* Satu kali iterasi (default) */
.entrance {
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-iteration-count: 1;
  animation-fill-mode: backwards;
}

/* Infinite: berulang terus */
.spinner {
  animation-name: spin;
  animation-duration: 1s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

.loading-dots {
  animation-name: bounce;
  animation-duration: 0.5s;
  animation-iteration-count: infinite;
}

/* Iterasi terbatas: 3 kali */
.attention-pulse {
  animation-name: pulse;
  animation-duration: 0.3s;
  animation-iteration-count: 3;
}

.shake-error {
  animation-name: shake;
  animation-duration: 0.4s;
  animation-iteration-count: 2;
}

/* Iterasi desimal: 1.5 */
.partial-bounce {
  animation-name: bounce;
  animation-duration: 1s;
  animation-iteration-count: 1.5;
  /* Berhenti di tengah siklus */
}

/* Multiple animasi dengan iterasi berbeda */
.element {
  animation-name: fadeIn, pulse;
  animation-duration: 0.5s, 0.3s;
  animation-iteration-count: 1, 3;
  /* fadeIn sekali, pulse 3 kali */
}

/* Animasi infinite dengan timing function linear untuk efek konsisten */
@keyframes rotate {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

.continuous-rotate {
  animation-name: rotate;
  animation-duration: 3s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

/* Animasi infinite untuk background */
@keyframes gradientShift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

.animated-gradient {
  background: linear-gradient(45deg, #4285f4, #34a853, #fbbc05, #ea4335);
  background-size: 400% 400%;
  animation-name: gradientShift;
  animation-duration: 10s;
  animation-iteration-count: infinite;
}

/* Animasi entrance diikuti animasi kontinu */
.card {
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-iteration-count: 1;
  animation-timing-function: ease;
}

.card:hover .card-icon {
  animation-name: pulse;
  animation-duration: 0.5s;
  animation-iteration-count: infinite;
}
```

## Poin Penting
- 1 (default): animasi berjalan sekali, cocok untuk entrance
- infinite: animasi berulang terus, cocok untuk loading atau dekorasi
- Nilai desimal seperti 1.5 menghentikan animasi di tengah siklus
- Untuk animasi infinite yang berulang mulus, gunakan timing function linear
