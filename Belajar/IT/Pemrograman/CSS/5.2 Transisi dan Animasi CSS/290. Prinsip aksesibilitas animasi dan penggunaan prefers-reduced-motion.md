# Prinsip aksesibilitas animasi dan penggunaan prefers-reduced-motion

## Analogi: Perpustakaan Digital

Perpustakaan digital menyadari bahwa tidak semua pengunjung nyaman dengan animasi. Beberapa pengunjung merasa pusing saat melihat gerakan cepat. Perpustakaan menyediakan "mode tenang" yang menghormati preferensi sistem operasi pengunjung. Dengan mendeteksi pengaturan `prefers-reduced-motion`, perpustakaan secara otomatis mengurangi atau mematikan animasi yang tidak perlu, memastikan semua pengunjung dapat menggunakan perpustakaan dengan nyaman.

## Penjelasan Detail

Aksesibilitas animasi adalah prinsip penting dalam pengembangan web inklusif. Banyak pengguna dengan gangguan vestibular (keseimbangan) mengalami mual, pusing, atau sakit kepala saat melihat animasi tertentu. Media query `prefers-reduced-motion` memungkinkan website mendeteksi preferensi pengguna untuk mengurangi gerakan. Implementasi yang baik: matikan semua animasi yang tidak esensial, ganti animasi kompleks dengan transisi sederhana, dan pastikan tidak ada konten yang bergantung pada animasi untuk dipahami. Prinsipnya: animasi harus meningkatkan pengalaman, bukan menjadi penghalang.

## Contoh Kode Implementasi

```css
/* Strategi 1: Matikan semua animasi jika pengguna meminta reduced motion */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

/* Strategi 2: Animasi hanya aktif jika diizinkan (progressive enhancement) */
.animate-on-scroll {
  opacity: 1;
  transform: none;
}

@media (prefers-reduced-motion: no-preference) {
  .animate-on-scroll {
    opacity: 0;
    transform: translateY(30px);
    transition: opacity 0.6s ease-out, transform 0.6s ease-out;
  }
  
  .animate-on-scroll.visible {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Strategi 3: Animasi alternatif yang lebih tenang */
.hero-animation {
  /* Default: tanpa animasi */
  background: #1a73e8;
}

@media (prefers-reduced-motion: no-preference) {
  .hero-animation {
    animation: gradientShift 10s ease infinite;
    background: linear-gradient(45deg, #1a73e8, #34a853);
    background-size: 400% 400%;
  }
}

@keyframes gradientShift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

/* Strategi 4: Kontrol per elemen */
.parallax-section {
  background-attachment: scroll;
}

@media (prefers-reduced-motion: no-preference) {
  .parallax-section {
    background-attachment: fixed;
  }
}

.loading-spinner {
  /* Default: spinner statis */
  width: 40px;
  height: 40px;
  border: 4px solid #e0e0e0;
  border-radius: 50%;
}

@media (prefers-reduced-motion: no-preference) {
  .loading-spinner {
    border-top-color: #1a73e8;
    animation: spin 0.8s linear infinite;
  }
}

@keyframes spin {
  to { transform: rotate(360deg); }
}

/* Strategi 5: Tombol toggle animasi */
.animation-toggle {
  display: flex;
  align-items: center;
  gap: 0.5rem;
  cursor: pointer;
}

.animations-disabled .animated {
  animation: none !important;
  transition: none !important;
}

/* Contoh komponen yang aman untuk aksesibilitas */
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
}

@media (prefers-reduced-motion: reduce) {
  .card {
    transition: none;
  }
  
  .card:hover {
    transform: none;
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  }
}

/* Pastikan konten tetap dapat diakses tanpa animasi */
.notification {
  animation: fadeIn 0.3s ease forwards;
}

@media (prefers-reduced-motion: reduce) {
  .notification {
    animation: none;
    opacity: 1;
  }
}
```

## Poin Penting
- prefers-reduced-motion mendeteksi preferensi pengguna untuk mengurangi animasi
- Gangguan vestibular mempengaruhi sebagian populasi, animasi dapat memicu mual/pusing
- Strategi progressive enhancement: default tanpa animasi, tambah jika diizinkan
- Jangan pernah menyembunyikan konten penting hanya dengan animasi
- Animasi harus meningkatkan aksesibilitas, bukan menghalanginya
