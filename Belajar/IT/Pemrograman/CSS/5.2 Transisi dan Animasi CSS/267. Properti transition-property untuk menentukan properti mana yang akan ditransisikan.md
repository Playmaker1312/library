# Properti transition-property untuk menentukan properti mana yang akan ditransisikan

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin beberapa elemen berubah secara halus saat interaksi, tetapi tidak semua. Warna tombol berubah perlahan, ukuran font berubah instan. Dengan menentukan properti mana yang akan ditransisikan, perpustakaan mengontrol aspek mana yang bergerak mulus dan mana yang berubah seketika, seperti memilih rak mana yang akan digerakkan perlahan dan mana yang tetap diam.

## Penjelasan Detail

`transition-property` menentukan properti CSS mana yang akan mengalami efek transisi ketika nilainya berubah. Nilai `all` akan menerapkan transisi ke semua properti yang berubah, sementara mendaftar properti spesifik memberikan kontrol yang lebih presisi. Memilih properti secara spesifik penting untuk performa dan perilaku yang diharapkan. Beberapa properti seperti `display` tidak dapat ditransisikan karena nilainya bersifat diskrit (ada/tidak ada). Properti yang dapat ditransisikan umumnya memiliki nilai numerik atau gradien warna. Mendaftar properti secara eksplisit juga mencegah transisi yang tidak diinginkan pada properti yang tidak perlu.

## Contoh Kode Implementasi

```css
/* Transition: all (semua properti) */
.element-all {
  background-color: #1a73e8;
  color: #ffffff;
  padding: 1rem;
  border-radius: 4px;
  transition: all 0.3s ease;
}

.element-all:hover {
  background-color: #34a853;
  color: #000000;
  padding: 1.5rem;
  border-radius: 8px;
}

/* Transition: properti spesifik */
.element-specific {
  background-color: #1a73e8;
  color: #ffffff;
  padding: 1rem;
  border-radius: 4px;
  /* Hanya background-color yang ditransisikan */
  transition-property: background-color;
  transition-duration: 0.3s;
  transition-timing-function: ease;
}

.element-specific:hover {
  background-color: #34a853;
  color: #000000; /* Berubah instan */
  padding: 1.5rem; /* Berubah instan */
}

/* Multiple properti dengan durasi berbeda */
.element-multiple {
  background-color: #1a73e8;
  transform: scale(1);
  opacity: 1;
  transition-property: background-color, transform, opacity;
  transition-duration: 0.3s, 0.5s, 0.2s;
  transition-timing-function: ease, ease-out, linear;
}

.element-multiple:hover {
  background-color: #34a853;
  transform: scale(1.05);
  opacity: 0.9;
}

/* Kombinasi all dengan override spesifik */
.element {
  transition: all 0.3s ease;
  /* Override untuk transform dengan timing function berbeda */
  transition-property: transform; /* Ini akan mengoverride all */
}

/* Properti yang tidak dapat ditransisikan */
/* display: none ke block -> instan */
/* height: auto ke 100px -> tidak mulus (kecuali numeric) */

.card {
  transition-property: opacity, transform, background-color, box-shadow;
  transition-duration: 0.3s;
  transition-timing-function: ease;
}

.card:hover {
  opacity: 0.9;
  transform: translateY(-4px);
  background-color: #f8f9fa;
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
}
```

## Poin Penting
- transition-property: all untuk semua properti, atau daftar properti spesifik
- Mendaftar properti secara spesifik memberikan performa lebih baik dan kontrol lebih presisi
- Properti diskrit seperti display tidak dapat ditransisikan
- Gunakan daftar nilai yang dipisah koma untuk pengaturan per-properti
