# Properti transition-timing-function untuk mengatur kecepatan perubahan transisi

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur bagaimana rak buku bergerak saat dibuka. Rak bisa bergerak dengan kecepatan konstan dari awal hingga akhir. Atau bergerak cepat di awal lalu melambat di akhir seperti rak fisik yang didorong lalu berhenti perlahan. Atau bergerak lambat di awal lalu cepat di akhir seperti benda yang baru mulai bergerak. Setiap pola kecepatan menciptakan sensasi yang berbeda bagi pengunjung.

## Penjelasan Detail

`transition-timing-function` mengatur bagaimana kecepatan perubahan properti selama durasi transisi. Fungsi ini mendefinisikan kurva kecepatan dari awal hingga akhir. Nilai `ease` (default) mulai cepat, melambat di tengah, lalu cepat lagi di akhir. `linear` bergerak dengan kecepatan konstan. `ease-in` mulai lambat lalu cepat di akhir. `ease-out` mulai cepat lalu lambat di akhir. `ease-in-out` mulai lambat, cepat di tengah, lambat di akhir. Fungsi `cubic-bezier()` memungkinkan kurva kustom. Pemilihan timing function mempengaruhi bagaimana pengguna merasakan kualitas dan responsivitas interaksi.

## Contoh Kode Implementasi

```css
/* Timing function bawaan */

/* ease (default) - mulai cepat, melambat di tengah, cepat lagi */
.ease {
  transition-property: transform;
  transition-duration: 0.5s;
  transition-timing-function: ease;
}

.ease:hover {
  transform: translateX(100px);
}

/* linear - kecepatan konstan */
.linear {
  transition-property: transform;
  transition-duration: 0.5s;
  transition-timing-function: linear;
}

.linear:hover {
  transform: translateX(100px);
}

/* ease-in - mulai lambat, semakin cepat */
.ease-in {
  transition-property: transform;
  transition-duration: 0.5s;
  transition-timing-function: ease-in;
}

.ease-in:hover {
  transform: translateX(100px);
}

/* ease-out - mulai cepat, melambat */
.ease-out {
  transition-property: transform;
  transition-duration: 0.5s;
  transition-timing-function: ease-out;
}

.ease-out:hover {
  transform: translateX(100px);
}

/* ease-in-out - lambat di awal dan akhir */
.ease-in-out {
  transition-property: transform;
  transition-duration: 0.5s;
  transition-timing-function: ease-in-out;
}

.ease-in-out:hover {
  transform: translateX(100px);
}

/* Perbandingan dalam satu container */
.demo-box {
  width: 100px;
  height: 100px;
  margin: 10px 0;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
  font-size: 0.75rem;
  border-radius: 4px;
  cursor: pointer;
}

/* Penerapan pada properti berbeda */
.card-enter {
  opacity: 0;
  transform: translateY(20px);
  transition-property: opacity, transform;
  transition-duration: 0.4s;
  transition-timing-function: ease-out;
}

.card-enter.active {
  opacity: 1;
  transform: translateY(0);
}

/* Timing function untuk elemen yang berbeda */
.sidebar {
  transition-property: transform;
  transition-duration: 0.3s;
  transition-timing-function: ease-out;
}

.sidebar.open {
  transform: translateX(0);
}

.modal-overlay {
  transition-property: opacity;
  transition-duration: 0.2s;
  transition-timing-function: linear;
}

.modal-overlay.active {
  opacity: 1;
}
```

## Poin Penting
- ease: standar, mulai cepat lalu melambat (default)
- linear: kecepatan konstan dari awal hingga akhir
- ease-out: paling alami untuk interaksi hover (mulai cepat, melambat)
- ease-in: cocok untuk elemen yang meninggalkan layar (mulai lambat, cepat)
- ease-in-out: cocok untuk transisi antara dua keadaan yang setara
