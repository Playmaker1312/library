# Properti animation-name untuk menghubungkan elemen dengan keyframes yang didefinisikan

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki berbagai macam gerakan yang sudah didefinisikan: fadeIn, slideIn, bounce, spin, pulse. Untuk membuat sebuah elemen bergerak, perpustakaan cukup menyebutkan nama gerakan yang diinginkan. Seperti memilih sebuah tarian dari daftar koreografi yang sudah ada, properti animation-name menghubungkan elemen dengan gerakan yang sudah didefinisikan.

## Penjelasan Detail

`animation-name` adalah properti yang menghubungkan elemen HTML dengan at-rule `@keyframes` yang telah didefinisikan. Nilainya adalah nama kustom yang dibuat saat mendefinisikan keyframes. Nama keyframes bersifat case-sensitive, dapat mengandung huruf, angka, underscore, dan hyphen, tetapi tidak boleh diawali angka. Beberapa keyframes dapat diterapkan pada satu elemen dengan mendaftar nama yang dipisah koma. Jika nama keyframes tidak ditemukan, animasi tidak akan berjalan. Praktik terbaik adalah menggunakan nama yang deskriptif dan konsisten dengan konvensi penamaan yang digunakan dalam proyek.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(40px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes rotate360 {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}

/* Menggunakan animation-name */
.fade-in {
  animation-name: fadeIn;
  animation-duration: 0.5s;
}

.slide-up {
  animation-name: slideUp;
  animation-duration: 0.6s;
  animation-timing-function: ease-out;
}

.rotating {
  animation-name: rotate360;
  animation-duration: 2s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

/* Multiple keyframes pada satu elemen */
.multiple-animations {
  animation-name: slideUp, fadeIn;
  animation-duration: 0.6s, 0.4s;
  animation-timing-function: ease-out, ease;
}

/* Menggunakan none untuk menonaktifkan */
.no-animation {
  animation-name: none;
}

/* Nama keyframes yang valid dan tidak valid */
/* Valid: fadeIn, slide-up, _bounce, anim2, my-animation_3 */
/* Tidak Valid: 123anim, my animation, @fade */

/* Animation-name dengan fallback */
.element {
  animation-name: fadeIn;
}

/* Animation-name dalam shorthand */
.element {
  animation: fadeIn 0.5s ease forwards;
}

/* Berganti animasi berdasarkan kelas */
.element.slide-in {
  animation-name: slideIn;
  animation-duration: 0.5s;
}

.element.fade-out {
  animation-name: fadeOut;
  animation-duration: 0.3s;
  animation-fill-mode: forwards;
}

@keyframes slideIn {
  from { transform: translateX(-100%); opacity: 0; }
  to { transform: translateX(0); opacity: 1; }
}

@keyframes fadeOut {
  from { opacity: 1; }
  to { opacity: 0; }
}

/* Animasi bersarang */
.card {
  animation-name: slideUp;
  animation-duration: 0.5s;
  animation-fill-mode: backwards;
}

.card:hover .card-icon {
  animation-name: pulse;
  animation-duration: 0.3s;
}
```

## Poin Penting
- animation-name merujuk ke nama @keyframes yang telah didefinisikan
- Nama bersifat case-sensitive dan harus unik dalam stylesheet
- Beberapa animasi bisa diterapkan dengan daftar nama dipisah koma
- Nilai none menonaktifkan animasi pada elemen
