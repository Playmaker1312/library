# Shorthand transition untuk mendefinisikan semua properti transisi sekaligus

## Analogi: Perpustakaan Digital

Daripadamenulis aturan panjang untuk setiap aspek gerakan rak buku secara terpisah, perpustakaan digital menyediakan formulir ringkas yang mencakup semua informasi: properti mana yang bergerak, berapa lama, pola kecepatannya, dan kapan mulai. Formulir ringkas ini membuat kode lebih bersih dan mudah dibaca.

## Penjelasan Detail

Shorthand `transition` menggabungkan `transition-property`, `transition-duration`, `transition-timing-function`, dan `transition-delay` dalam satu deklarasi. Urutannya adalah: property, duration, timing-function, delay. Jika hanya dua nilai yang diberikan, nilai pertama dianggap duration dan kedua dianggap delay. Timing function bersifat opsional dan akan menggunakan default `ease` jika tidak ditentukan. Untuk transisi pada beberapa properti dengan nilai berbeda, gunakan daftar yang dipisah koma. Shorthand membuat kode lebih ringkas dan lebih mudah dipelihara dibandingkan menulis properti individual.

## Contoh Kode Implementasi

```css
/* Shorthand dasar: property duration */
.element {
  transition: opacity 0.3s;
}

/* Shorthand: property duration timing-function */
.element {
  transition: transform 0.3s ease-out;
}

/* Shorthand lengkap: property duration timing-function delay */
.element {
  transition: background-color 0.3s ease 0.1s;
}

/* Transisi pada beberapa properti dengan daftar koma */
.card {
  transition:
    transform 0.3s ease-out,
    opacity 0.2s linear,
    background-color 0.3s ease 0.1s;
}

.card:hover {
  transform: translateY(-4px);
  opacity: 0.9;
  background-color: #f8f9fa;
}

/* Shorthand untuk all */
.element {
  transition: all 0.3s ease;
}

/* Berbagai contoh shorthand */
.button {
  transition: background-color 0.2s ease, transform 0.1s ease;
}

.button:hover {
  background-color: #1557b0;
  transform: scale(0.98);
}

.nav-link {
  transition: color 0.2s, border-bottom-color 0.2s;
}

.nav-link:hover {
  color: #1a73e8;
  border-bottom-color: #1a73e8;
}

/* Hover dan focus dengan transisi berbeda */
.input {
  border: 2px solid #ddd;
  padding: 0.5rem;
  transition: border-color 0.3s ease, box-shadow 0.3s ease;
}

.input:focus {
  border-color: #1a73e8;
  box-shadow: 0 0 0 3px rgba(26, 115, 232, 0.2);
}

/* Multiple properti dengan timing function berbeda */
.animated-element {
  opacity: 1;
  transform: scale(1);
  background-color: #1a73e8;
  transition:
    opacity 0.2s linear,
    transform 0.4s ease-out,
    background-color 0.3s ease;
}

.animated-element:hover {
  opacity: 0.8;
  transform: scale(1.05);
  background-color: #34a853;
}

/* Transition dengan delay berbeda per properti */
.staggered {
  transition:
    opacity 0.3s ease,
    transform 0.3s ease 0.1s;
}
```

## Poin Penting
- Urutan shorthand: property, duration, timing-function, delay
- Dua nilai pertama: nilai pertama adalah duration, kedua adalah delay
- Gunakan daftar koma untuk transisi multi-properti dengan nilai berbeda
- Shorthand membuat kode lebih ringkas dan mudah dipelihara
