# Teknik membuat animasi slide dan bounce menggunakan transform dan keyframes

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki rak buku yang meluncur masuk dari samping (slide) dan bola yang memantul (bounce). Slide seperti laci yang dibuka perlahan, bergerak lurus dari satu titik ke titik lain. Bounce seperti bola karet yang dijatuhkan, memantul beberapa kali dengan ketinggian yang semakin berkurang. Kedua efek ini membuat interaksi terasa lebih hidup dan nyata.

## Penjelasan Detail

Slide animation menggunakan `transform: translateX()` atau `translateY()` untuk menggerakkan elemen secara linear. Bounce animation menggunakan kombinasi `translateY` dengan timing function yang berbeda di setiap keyframe untuk mensimulasi efek gravitasi. Perbedaan utama: slide bergerak dari satu titik ke titik lain dan berhenti, sementara bounce memiliki efek overshoot yang menciptakan ilusi fisik. Kedua animasi dapat dikombinasikan dengan `opacity` untuk hasil yang lebih halus. Pemilihan durasi dan jarak pergerakan sangat mempengaruhi persepsi kualitas animasi.

## Contoh Kode Implementasi

```css
/* Slide from left */
.slide-in-left {
  animation: slideInLeft 0.4s ease-out forwards;
}

@keyframes slideInLeft {
  from {
    transform: translateX(-100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

/* Slide from right */
.slide-in-right {
  animation: slideInRight 0.4s ease-out forwards;
}

@keyframes slideInRight {
  from {
    transform: translateX(100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

/* Slide from bottom */
.slide-in-up {
  animation: slideInUp 0.4s ease-out forwards;
}

@keyframes slideInUp {
  from {
    transform: translateY(100%);
    opacity: 0;
  }
  to {
    transform: translateY(0);
    opacity: 1;
  }
}

/* Slide out to right */
.slide-out-right {
  animation: slideOutRight 0.3s ease-in forwards;
}

@keyframes slideOutRight {
  from {
    transform: translateX(0);
    opacity: 1;
  }
  to {
    transform: translateX(100%);
    opacity: 0;
  }
}

/* Bounce sederhana */
.bounce {
  animation: bounce 1s ease infinite;
}

@keyframes bounce {
  0%, 100% {
    transform: translateY(0);
    animation-timing-function: ease-out;
  }
  30% {
    transform: translateY(-30px);
    animation-timing-function: ease-in;
  }
  50% {
    transform: translateY(0);
    animation-timing-function: ease-out;
  }
  70% {
    transform: translateY(-15px);
    animation-timing-function: ease-in;
  }
  90% {
    transform: translateY(-5px);
    animation-timing-function: ease-in;
  }
}

/* Bounce untuk entrance */
.bounce-in {
  animation: bounceIn 0.6s ease-out forwards;
}

@keyframes bounceIn {
  0% {
    transform: scale(0);
    opacity: 0;
  }
  50% {
    transform: scale(1.15);
  }
  70% {
    transform: scale(0.95);
  }
  100% {
    transform: scale(1);
    opacity: 1;
  }
}

/* Slide dengan bounce di akhir */
.slide-bounce {
  animation: slideBounce 0.5s cubic-bezier(0.68, -0.55, 0.27, 1.55) forwards;
}

@keyframes slideBounce {
  from {
    transform: translateX(-100px);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

/* Slide untuk menu sidebar */
.sidebar {
  transform: translateX(-100%);
  transition: transform 0.3s ease-out;
}

.sidebar.open {
  transform: translateX(0);
}

/* Slide untuk notification toast */
.toast {
  animation: slideInRight 0.3s ease-out, slideOutRight 0.3s ease-in 3s forwards;
}

/* Utility classes */
.slide-left { animation: slideInLeft 0.3s ease-out forwards; }
.slide-right { animation: slideInRight 0.3s ease-out forwards; }
.slide-up { animation: slideInUp 0.3s ease-out forwards; }
.bounce-effect { animation: bounce 1s ease infinite; }
.bounce-in-effect { animation: bounceIn 0.5s ease-out forwards; }
```

## Poin Penting
- Slide menggunakan translateX/Y untuk gerakan linear
- Bounce mensimulasi gravitasi dengan beberapa keyframe dan timing function berbeda
- Bounce-in menggunakan efek overshoot scale untuk entrance yang dramatis
- Kombinasikan slide dengan opacity untuk hasil yang lebih halus
