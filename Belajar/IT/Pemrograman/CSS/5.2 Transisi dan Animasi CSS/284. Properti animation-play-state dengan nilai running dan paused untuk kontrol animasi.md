# Properti animation-play-state dengan nilai running dan paused untuk kontrol animasi

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki tombol pause dan play untuk setiap animasi. Saat pengguna mengarahkan kursor ke buku yang sedang bergerak, buku itu berhenti (paused). Saat kursor meninggalkan buku, gerakan dilanjutkan (running). Seperti remote control yang bisa menjeda dan melanjutkan film kapan saja, animation-play-state memberikan kontrol atas eksekusi animasi.

## Penjelasan Detail

`animation-play-state` mengontrol apakah animasi sedang berjalan atau dijeda. Nilai `running` (default) menjalankan animasi normal. Nilai `paused` menjeda animasi di posisinya saat itu. Ketika diubah kembali ke `running`, animasi melanjutkan dari posisi di mana ia dijeda, bukan dari awal. Properti ini sangat berguna untuk interaksi pengguna seperti hover untuk menjeda animasi karusel, atau toggle play/pause untuk video animasi. Kombinasi dengan JavaScript memberikan kontrol yang lebih fleksibel.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

@keyframes slide {
  0% { transform: translateX(0); }
  50% { transform: translateX(200px); }
  100% { transform: translateX(0); }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.2); }
}

/* Pause on hover */
.spinner {
  animation-name: spin;
  animation-duration: 2s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
  animation-play-state: running;
}

.spinner:hover {
  animation-play-state: paused;
}

/* Karusel yang bisa dijeda */
.carousel {
  animation-name: slide;
  animation-duration: 4s;
  animation-iteration-count: infinite;
  animation-timing-function: ease-in-out;
  animation-play-state: running;
}

.carousel-wrapper:hover .carousel {
  animation-play-state: paused;
}

/* Tombol play/pause dengan checkbox hack */
.play-toggle {
  display: none;
}

.play-toggle-label {
  cursor: pointer;
  padding: 0.5rem 1rem;
  background: #1a73e8;
  color: white;
  border-radius: 4px;
  user-select: none;
}

.play-toggle-label::before {
  content: 'Pause';
}

.play-toggle:checked ~ .animated-element {
  animation-play-state: paused;
}

.play-toggle:checked ~ .play-toggle-label::before {
  content: 'Play';
}

.animated-element {
  animation-name: pulse;
  animation-duration: 0.5s;
  animation-iteration-count: infinite;
  animation-play-state: running;
}

/* Multiple animasi dengan play-state berbeda */
.element {
  animation-name: spin, pulse;
  animation-duration: 2s, 0.5s;
  animation-iteration-count: infinite, infinite;
  animation-play-state: running, paused;
}

.element.active {
  animation-play-state: running, running;
}

/* Efek reduce motion dengan play-state */
@media (prefers-reduced-motion: reduce) {
  .animated {
    animation-play-state: paused !important;
  }
}

/* Animasi yang dijeda saat elemen tidak terlihat */
.in-view {
  animation-name: spin;
  animation-duration: 3s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

.in-view.out-of-view {
  animation-play-state: paused;
}

/* Hero section dengan background animasi yang bisa dijeda */
.hero:hover .animated-bg {
  animation-play-state: paused;
}

.animated-bg {
  animation-name: gradientShift;
  animation-duration: 10s;
  animation-iteration-count: infinite;
  animation-play-state: running;
  background-size: 400% 400%;
}

@keyframes gradientShift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}
```

## Poin Penting
- running: animasi berjalan normal (default)
- paused: animasi dijeda di posisi saat itu
- Sangat berguna untuk interaksi hover dan kontrol pengguna
- Animasi melanjutkan dari posisi terakhir setelah diubah kembali ke running
