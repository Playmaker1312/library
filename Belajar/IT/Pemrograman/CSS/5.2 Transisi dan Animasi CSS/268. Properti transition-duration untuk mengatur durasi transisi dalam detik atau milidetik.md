# Properti transition-duration untuk mengatur durasi transisi dalam detik atau milidetik

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur kecepatan animasi setiap elemen. Buku yang melayang saat hover bergerak selama 0,3 detik, terasa cepat dan responsif. Panel informasi yang muncul bergerak selama 0,5 detik, terasa lebih santai. Pintu perpustakaan yang terbuka membutuhkan 1 detik penuh untuk memberikan kesan megah. Setiap durasi dipilih untuk menciptakan pengalaman yang tepat.

## Penjelasan Detail

`transition-duration` menentukan berapa lama efek transisi berlangsung dari keadaan awal ke keadaan akhir. Nilai dapat ditulis dalam detik (`s`) atau milidetik (`ms`). Durasi pendek (0.1s-0.2s) memberikan respons cepat yang terasa langsung. Durasi sedang (0.3s-0.5s) paling umum untuk interaksi hover dan focus. Durasi panjang (0.6s-1s) cocok untuk transisi halaman atau elemen yang ingin ditonjolkan. Pemilihan durasi mempengaruhi persepsi pengguna terhadap kecepatan dan kualitas website. Durasi yang terlalu cepat terasa kasar, terlalu lambat terasa mengganggu.

## Contoh Kode Implementasi

```css
/* Berbagai durasi transisi */

/* Sangat cepat (100ms) - untuk feedback instan */
.btn-active {
  transition-property: transform;
  transition-duration: 100ms;
  transition-timing-function: ease;
}

.btn-active:active {
  transform: scale(0.95);
}

/* Cepat (200ms) - untuk hover effects */
.nav-link {
  color: #666;
  text-decoration: none;
  transition-property: color;
  transition-duration: 200ms;
}

.nav-link:hover {
  color: #1a73e8;
}

/* Sedang (300ms) - standar untuk interaksi */
.button {
  background: #1a73e8;
  color: white;
  border: none;
  padding: 0.75rem 1.5rem;
  border-radius: 4px;
  cursor: pointer;
  transition-property: background-color, transform;
  transition-duration: 300ms, 300ms;
  transition-timing-function: ease;
}

.button:hover {
  background-color: #1557b0;
  transform: translateY(-1px);
}

/* Lambat (500ms) - untuk elemen dekoratif */
.card {
  transition-property: box-shadow;
  transition-duration: 500ms;
}

.card:hover {
  box-shadow: 0 12px 32px rgba(0, 0, 0, 0.15);
}

/* Sangat lambat (1000ms) - untuk transisi halaman */
.page-enter {
  opacity: 0;
  transform: translateY(20px);
  transition-property: opacity, transform;
  transition-duration: 1000ms;
  transition-timing-function: ease-out;
}

.page-enter.active {
  opacity: 1;
  transform: translateY(0);
}

/* Multiple properti dengan durasi berbeda */
.element {
  background-color: #1a73e8;
  transform: scale(1);
  opacity: 1;
  transition-property: background-color, transform, opacity;
  transition-duration: 200ms, 400ms, 300ms;
  transition-timing-function: ease, ease-out, linear;
}

.element:hover {
  background-color: #34a853;
  transform: scale(1.1);
  opacity: 0.9;
}

/* Menggunakan milidetik */
.fast-fade {
  opacity: 1;
  transition-property: opacity;
  transition-duration: 150ms;
}

.fast-fade:hover {
  opacity: 0.7;
}
```

## Poin Penting
- Gunakan detik (0.3s) atau milidetik (300ms) untuk menentukan durasi
- Durasi 200ms-300ms paling umum untuk interaksi hover
- Durasi lebih dari 500ms sebaiknya hanya untuk elemen dekoratif
- Konsistensi durasi antar elemen serupa menciptakan pengalaman yang kohesif
