# Properti animation-direction dengan nilai normal, reverse, alternate, dan alternate-reverse

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur arah gerakan animasi. normal: buku bergerak dari kiri ke kanan lalu kembali ke awal. reverse: buku bergerak dari kanan ke kiri. alternate: buku bergerak dari kiri ke kanan lalu kembali lagi, bolak-balik seperti pendulum. alternate-reverse: buku bergerak dari kanan ke kiri lalu kembali, kebalikan dari alternate. Setiap arah menciptakan pengalaman visual yang berbeda.

## Penjelasan Detail

`animation-direction` mengontrol arah perjalanan animasi dalam setiap siklus. `normal` (default) menjalankan animasi dari 0% ke 100% setiap siklus. `reverse` menjalankan animasi dari 100% ke 0%. `alternate` bergantian normal dan reverse. `alternate-reverse` bergantian reverse dan normal. Untuk animasi dengan `iteration-count` ganjil menggunakan alternate, animasi berakhir di posisi 100%. Untuk genap, berakhir di 0%. `alternate` sangat berguna untuk efek bolak-balik seperti pendulum, naik-turun, atau buka-tutup.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes slide {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(200px);
  }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.2); }
}

@keyframes fadeInOut {
  0% { opacity: 0; }
  50% { opacity: 1; }
  100% { opacity: 0; }
}

/* normal (default): 0% -> 100% setiap siklus */
.normal-direction {
  animation-name: slide;
  animation-duration: 1s;
  animation-iteration-count: 3;
  animation-direction: normal;
}

/* reverse: 100% -> 0% setiap siklus */
.reverse-direction {
  animation-name: slide;
  animation-duration: 1s;
  animation-iteration-count: 3;
  animation-direction: reverse;
}

/* alternate: 0%->100%, 100%->0%, 0%->100% */
.alternate-direction {
  animation-name: slide;
  animation-duration: 1s;
  animation-iteration-count: 3;
  animation-direction: alternate;
}

/* alternate-reverse: 100%->0%, 0%->100%, 100%->0% */
.alternate-reverse-direction {
  animation-name: slide;
  animation-duration: 1s;
  animation-iteration-count: 3;
  animation-direction: alternate-reverse;
}

/* Efek pendulum dengan alternate */
@keyframes swing {
  from { transform: rotate(-15deg); }
  to { transform: rotate(15deg); }
}

.pendulum {
  animation-name: swing;
  animation-duration: 1s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
  animation-timing-function: ease-in-out;
  transform-origin: top center;
}

/* Naik turun dengan alternate */
@keyframes float {
  from { transform: translateY(0); }
  to { transform: translateY(-20px); }
}

.floating-element {
  animation-name: float;
  animation-duration: 2s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
  animation-timing-function: ease-in-out;
}

/* Fade in-out dengan alternate */
.blinking-cursor {
  animation-name: fadeInOut;
  animation-duration: 1s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}

/* Multiple animasi dengan arah berbeda */
.element {
  animation-name: slide, pulse;
  animation-duration: 2s, 1s;
  animation-iteration-count: infinite, 3;
  animation-direction: alternate, normal;
}

/* Hamburger menu animasi */
@keyframes menuOpen {
  from { transform: rotate(0deg); }
  to { transform: rotate(90deg); }
}

.menu-icon.active {
  animation-name: menuOpen;
  animation-duration: 0.3s;
  animation-iteration-count: 1;
  animation-fill-mode: forwards;
}
```

## Poin Penting
- normal: 0% ke 100% (default)
- reverse: 100% ke 0%
- alternate: bergantian normal dan reverse, ideal untuk efek bolak-balik
- alternate-reverse: bergantian reverse dan normal
- Gunakan alternate dengan ease-in-out untuk gerakan bolak-balik yang alami
