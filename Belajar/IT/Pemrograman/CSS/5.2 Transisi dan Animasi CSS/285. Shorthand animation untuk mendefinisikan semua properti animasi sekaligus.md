# Shorthand animation untuk mendefinisikan semua properti animasi sekaligus

## Analogi: Perpustakaan Digital

Daripada menulis aturan panjang untuk setiap aspek gerakan secara terpisah, perpustakaan digital menyediakan formulir ringkas: nama gerakan, durasi, pola kecepatan, jeda, jumlah ulangan, arah, dan fill mode dalam satu baris. Formulir ringkas ini seperti resep masakan yang mencakup semua instruksi dalam satu paragraf, membuat kode lebih bersih dan mudah ditulis.

## Penjelasan Detail

Shorthand `animation` menggabungkan semua properti animasi dalam satu deklarasi: `animation-name`, `animation-duration`, `animation-timing-function`, `animation-delay`, `animation-iteration-count`, `animation-direction`, `animation-fill-mode`, dan `animation-play-state`. Urutan yang disarankan: name, duration, timing-function, delay, iteration-count, direction, fill-mode, play-state. Dua nilai waktu: nilai pertama dianggap duration, kedua dianggap delay. Properti yang tidak disebut akan menggunakan nilai default. Untuk beberapa animasi pada satu elemen, gunakan daftar yang dipisah koma.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(30px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.1); }
}

/* Shorthand minimal: name duration */
.fade-in {
  animation: fadeIn 0.5s;
}

/* Shorthand: name duration timing-function */
.slide-up {
  animation: slideUp 0.6s ease-out;
}

/* Shorthand: name duration timing-function delay */
.delayed-fade {
  animation: fadeIn 0.5s ease 0.3s;
}

/* Shorthand lengkap */
.spinner {
  animation: spin 1s linear 0s infinite normal none running;
}

/* Shorthand dengan iteration-count dan fill-mode */
.entrance {
  animation: slideUp 0.5s ease-out 0s 1 forwards;
}

/* Shorthand dengan direction */
.swing {
  animation: swing 1s ease-in-out 0s infinite alternate;
}

@keyframes swing {
  from { transform: rotate(-10deg); }
  to { transform: rotate(10deg); }
}

/* Multiple animations dengan shorthand */
.element {
  animation:
    slideUp 0.5s ease-out forwards,
    fadeIn 0.3s ease forwards;
}

/* Shorthand dengan play-state */
.pausable {
  animation: spin 2s linear infinite;
}

.pausable:hover {
  animation: spin 2s linear infinite paused;
}

/* Berbagai contoh shorthand umum */
.fade-in-fast {
  animation: fadeIn 0.3s ease forwards;
}

.slide-up-slow {
  animation: slideUp 0.8s cubic-bezier(0.22, 1, 0.36, 1) 0.2s both;
}

.bounce-infinite {
  animation: bounce 1s ease-in-out infinite;
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}

/* Animation shorthand dengan fallback */
.card {
  animation: slideUp 0.5s ease-out both;
}

@media (prefers-reduced-motion: reduce) {
  .card {
    animation: none;
  }
}
```

## Poin Penting
- Urutan: name, duration, timing-function, delay, iteration-count, direction, fill-mode, play-state
- Dua nilai waktu: pertama duration, kedua delay
- Properti yang tidak disebut menggunakan nilai default
- Multiple animations dipisah koma dalam satu deklarasi
