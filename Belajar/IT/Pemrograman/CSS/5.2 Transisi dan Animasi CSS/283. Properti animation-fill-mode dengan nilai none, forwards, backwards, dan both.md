# Properti animation-fill-mode dengan nilai none, forwards, backwards, dan both

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur posisi buku sebelum dan sesudah animasi. forwards: setelah animasi selesai, buku tetap di posisi akhir. backwards: sebelum animasi dimulai (selama delay), buku sudah di posisi awal animasi. both: kombinasi keduanya. none: buku kembali ke posisi awal setelah animasi selesai. Seperti aktor yang tetap dalam pose terakhir setelah adegan selesai, atau bersiap di pose pertama sebelum adegan dimulai.

## Penjelasan Detail

`animation-fill-mode` menentukan gaya elemen di luar waktu eksekusi animasi. `none` (default): elemen tidak memiliki gaya di luar animasi, kembali ke gaya asli. `forwards`: setelah animasi selesai, elemen mempertahankan gaya dari keyframe terakhir. `backwards`: sebelum animasi dimulai (termasuk selama delay), elemen menggunakan gaya dari keyframe pertama. `both`: kombinasi backwards dan forwards. Nilai ini sangat penting untuk entrance animation agar elemen tidak tampil sebelum animasi dimulai (backwards) dan tetap di posisi akhir setelah animasi selesai (forwards).

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes slideIn {
  from {
    opacity: 0;
    transform: translateX(-100%);
  }
  to {
    opacity: 1;
    transform: translateX(0);
  }
}

@keyframes fadeOut {
  from { opacity: 1; }
  to { opacity: 0; }
}

/* none (default): kembali ke gaya awal setelah animasi */
.none-fill {
  animation-name: slideIn;
  animation-duration: 1s;
  animation-delay: 0.5s;
  animation-fill-mode: none;
  /* Selama delay: elemen tampil normal */
  /* Setelah animasi: kembali ke posisi awal */
}

/* forwards: bertahan di posisi akhir */
.forwards-fill {
  animation-name: slideIn;
  animation-duration: 0.5s;
  animation-fill-mode: forwards;
  /* Setelah animasi: tetap di posisi translateX(0) */
}

/* backwards: mengambil posisi awal selama delay */
.backwards-fill {
  animation-name: slideIn;
  animation-duration: 0.5s;
  animation-delay: 1s;
  animation-fill-mode: backwards;
  /* Selama delay: opacity 0, translateX(-100%) */
  /* Setelah animasi: kembali ke gaya asli */
}

/* both: kombinasi backwards dan forwards */
.both-fill {
  animation-name: slideIn;
  animation-duration: 0.5s;
  animation-delay: 0.3s;
  animation-fill-mode: both;
  /* Selama delay: opacity 0, translateX(-100%) */
  /* Setelah animasi: tetap di posisi akhir */
}

/* Fade out dengan forwards */
.hidden {
  animation-name: fadeOut;
  animation-duration: 0.3s;
  animation-fill-mode: forwards;
  /* Setelah fadeOut, elemen tetap opacity 0 */
}

/* Multiple animasi dengan fill mode */
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.1); }
}

.element {
  animation-name: slideIn, pulse;
  animation-duration: 0.5s, 1s;
  animation-delay: 0s, 0.5s;
  animation-fill-mode: both, none;
  animation-iteration-count: 1, infinite;
}

/* Entrance animation yang aman */
.entrance-safe {
  opacity: 0; /* Fallback */
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-fill-mode: forwards;
}

@keyframes fadeIn {
  from { opacity: 0; transform: translateY(10px); }
  to { opacity: 1; transform: translateY(0); }
}

/* Staggered items dengan both */
.stagger-item {
  animation-name: slideIn;
  animation-duration: 0.4s;
  animation-fill-mode: both;
  animation-timing-function: ease-out;
}

.stagger-item:nth-child(1) { animation-delay: 0.1s; }
.stagger-item:nth-child(2) { animation-delay: 0.2s; }
.stagger-item:nth-child(3) { animation-delay: 0.3s; }
```

## Poin Penting
- forwards: simpan gaya keyframe terakhir setelah animasi selesai
- backwards: terapkan gaya keyframe pertama selama animation-delay
- both: kombinasi backwards dan forwards (paling umum untuk entrance)
- none: default, tidak ada gaya yang dipertahankan di luar animasi
