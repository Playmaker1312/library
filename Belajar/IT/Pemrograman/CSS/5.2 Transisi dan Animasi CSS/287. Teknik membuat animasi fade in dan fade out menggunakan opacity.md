# Teknik membuat animasi fade in dan fade out menggunakan opacity

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki efek muncul dan menghilang secara perlahan. Buku baru muncul dengan transparan menjadi jelas (fade in). Notifikasi yang tidak penting menghilang dengan menjadi transparan (fade out). Efek ini lebih lembut dan profesional dibandingkan muncul atau hilang secara tiba-tiba, seperti hantu yang perlahan muncul dan menghilang.

## Penjelasan Detail

Fade in dan fade out adalah animasi paling dasar yang mengubah properti `opacity` dari 0 (transparan) menjadi 1 (terlihat) atau sebaliknya. Fade in biasanya dikombinasikan dengan `transform: translateY()` untuk efek muncul dari bawah yang lebih natural. Fade out sering digunakan untuk menutup modal, notifikasi, atau tooltip. Teknik ini ringan secara performa karena `opacity` adalah properti yang dapat dianimasikan dengan efisien oleh GPU. Penting untuk menggunakan `animation-fill-mode: forwards` pada fade out agar elemen tetap tidak terlihat setelah animasi selesai.

## Contoh Kode Implementasi

```css
/* Fade in sederhana */
.fade-in {
  animation: fadeIn 0.5s ease forwards;
}

@keyframes fadeIn {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

/* Fade in dengan slide dari bawah */
.fade-in-up {
  animation: fadeInUp 0.5s ease-out forwards;
}

@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Fade in dengan slide dari atas */
.fade-in-down {
  animation: fadeInDown 0.5s ease-out forwards;
}

@keyframes fadeInDown {
  from {
    opacity: 0;
    transform: translateY(-20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Fade in dengan scale */
.fade-in-scale {
  animation: fadeInScale 0.4s ease-out forwards;
}

@keyframes fadeInScale {
  from {
    opacity: 0;
    transform: scale(0.9);
  }
  to {
    opacity: 1;
    transform: scale(1);
  }
}

/* Fade out sederhana */
.fade-out {
  animation: fadeOut 0.3s ease forwards;
}

@keyframes fadeOut {
  from {
    opacity: 1;
  }
  to {
    opacity: 0;
  }
}

/* Fade out dengan slide ke bawah */
.fade-out-down {
  animation: fadeOutDown 0.3s ease-in forwards;
}

@keyframes fadeOutDown {
  from {
    opacity: 1;
    transform: translateY(0);
  }
  to {
    opacity: 0;
    transform: translateY(20px);
  }
}

/* Modal overlay fade */
.modal-overlay {
  position: fixed;
  inset: 0;
  background: rgba(0, 0, 0, 0.5);
  animation: fadeIn 0.2s ease forwards;
}

.modal-overlay.closing {
  animation: fadeOut 0.2s ease forwards;
}

.modal-content {
  animation: fadeInUp 0.3s ease-out forwards;
}

/* Staggered fade in untuk list */
.stagger-fade li {
  opacity: 0;
  animation: fadeInUp 0.4s ease-out forwards;
}

.stagger-fade li:nth-child(1) { animation-delay: 0ms; }
.stagger-fade li:nth-child(2) { animation-delay: 100ms; }
.stagger-fade li:nth-child(3) { animation-delay: 200ms; }
.stagger-fade li:nth-child(4) { animation-delay: 300ms; }
.stagger-fade li:nth-child(5) { animation-delay: 400ms; }

/* Fade in saat hover */
.hover-fade {
  opacity: 0.7;
  transition: opacity 0.3s ease;
  cursor: pointer;
}

.hover-fade:hover {
  opacity: 1;
}

/* Notifikasi auto fade out */
.notification {
  animation: fadeInUp 0.3s ease-out, fadeOut 0.5s ease-in 3s forwards;
}

/* Utility classes */
.animate-fade-in {
  animation: fadeIn 0.3s ease forwards;
}

.animate-fade-out {
  animation: fadeOut 0.3s ease forwards;
}
```

## Poin Penting
- opacity 0 ke 1 untuk fade in, 1 ke 0 untuk fade out
- Kombinasikan dengan transform translate untuk efek yang lebih dinamis
- Gunakan animation-fill-mode: forwards pada fade out agar elemen tetap tersembunyi
- Staggered fade in menciptakan efek berantai yang elegan
