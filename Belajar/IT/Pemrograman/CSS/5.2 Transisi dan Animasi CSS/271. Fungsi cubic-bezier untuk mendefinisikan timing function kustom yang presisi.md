# Fungsi cubic-bezier untuk mendefinisikan timing function kustom yang presisi

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin gerakan rak buku yang tidak bisa dicapai dengan timing function standar. Misalnya, rak yang bergerak sedikit mundur terlebih dahulu sebelum maju (seperti karet gelang yang ditarik). Atau rak yang sedikit melampaui target lalu kembali (efek bounce). Fungsi cubic-bezier memungkinkan pembuatan kurva kecepatan kustom dengan presisi penuh, seperti konduktor yang menentukan tempo musik secara detail.

## Penjelasan Detail

Fungsi `cubic-bezier()` memungkinkan pembuatan timing function kustom dengan mendefinisikan kurva Bézier kubik melalui empat titik kontrol: P1 (x1, y1) dan P2 (x2, y2). Kurva ini menentukan kecepatan perubahan dari awal (0,0) hingga akhir (1,1). Parameter x1 dan x2 harus berada dalam rentang 0 hingga 1 (untuk fungsi timing standar), sementara y1 dan y2 bisa melampaui rentang 0-1 untuk menciptakan efek seperti bounce atau overshoot. Nilai `cubic-bezier(0.68, -0.55, 0.27, 1.55)` misalnya, menciptakan efek bounce karena nilai y negatif pada P1 dan lebih dari 1 pada P2.

## Contoh Kode Implementasi

```css
/* Fungsi cubic-bezier untuk berbagai efek */

/* Ease-out kustom: lebih halus dari ease-out bawaan */
.smooth-ease-out {
  transition-property: transform;
  transition-duration: 0.4s;
  transition-timing-function: cubic-bezier(0.0, 0.0, 0.2, 1.0);
}

.smooth-ease-out:hover {
  transform: scale(1.05);
}

/* Efek bounce: sedikit overshoot lalu kembali */
.bounce {
  transition-property: transform;
  transition-duration: 0.5s;
  transition-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55);
}

.bounce:hover {
  transform: scale(1.2);
}

/* Efek elastic: mundur dulu baru maju */
.elastic {
  transition-property: transform;
  transition-duration: 0.6s;
  transition-timing-function: cubic-bezier(0.5, -0.5, 0.5, 1.5);
}

.elastic:hover {
  transform: translateX(100px);
}

/* Overshoot: melewati target lalu kembali */
.overshoot {
  transition-property: transform;
  transition-duration: 0.5s;
  transition-timing-function: cubic-bezier(0.175, 0.885, 0.32, 1.275);
}

.overshoot:hover {
  transform: scale(1.1);
}

/* Antarmuka yang responsif */
.snap-back {
  transition-property: transform;
  transition-duration: 0.3s;
  transition-timing-function: cubic-bezier(0.34, 1.56, 0.64, 1);
}

/* Timing function untuk berbagai konteks */
:root {
  --ease-in-out-cubic: cubic-bezier(0.65, 0.0, 0.35, 1.0);
  --ease-out-quart: cubic-bezier(0.25, 1.0, 0.5, 1.0);
  --ease-in-quart: cubic-bezier(0.5, 0.0, 0.75, 0.0);
  --ease-out-back: cubic-bezier(0.34, 1.56, 0.64, 1);
  --ease-in-out-back: cubic-bezier(0.68, -0.6, 0.32, 1.6);
}

.card {
  transition-property: transform, box-shadow;
  transition-duration: 0.4s;
  transition-timing-function: var(--ease-out-quart);
}

.card:hover {
  transform: translateY(-8px);
  box-shadow: 0 12px 32px rgba(0, 0, 0, 0.15);
}

/* Efek entrance dramatis */
.hero-title {
  opacity: 0;
  transform: translateY(40px);
  transition-property: opacity, transform;
  transition-duration: 0.8s;
  transition-timing-function: cubic-bezier(0.22, 1, 0.36, 1);
}

.hero-title.active {
  opacity: 1;
  transform: translateY(0);
}

/* Bounce untuk notifikasi */
.notification {
  transition-property: transform, opacity;
  transition-duration: 0.5s;
  transition-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55);
}
```

## Poin Penting
- cubic-bezier(x1, y1, x2, y2) mendefinisikan kurva kecepatan kustom
- Nilai x harus antara 0 dan 1, nilai y bisa melampaui 0-1 untuk efek bounce/overshoot
- Gunakan custom properties untuk menyimpan dan menggunakan ulang timing function
- Efek bounce dan overshoot memberikan kesan yang lebih hidup dan alami
