# At-rule keyframes untuk mendefinisikan tahapan animasi CSS yang kompleks

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin membuat buku "menari" dengan gerakan kompleks: muncul dari bawah, berputar, membesar, lalu mengecil kembali. Gerakan ini memiliki beberapa tahapan yang harus didefinisikan secara berurutan. Seperti storyboard film, keyframes menentukan pose-pose kunci pada waktu-waktu tertentu, dan browser mengisi gerakan di antaranya secara otomatis.

## Penjelasan Detail

At-rule `@keyframes` adalah fondasi animasi CSS yang memungkinkan pendefinisian serangkaian tahapan (keyframes) dalam suatu animasi. Setiap keyframe ditandai dengan persentase waktu (0% hingga 100%) atau kata kunci `from` (setara 0%) dan `to` (setara 100%). Di setiap tahapan, pengembang mendefinisikan properti CSS yang akan diterapkan pada saat tersebut. Browser kemudian menginterpolasi nilai di antara keyframes untuk menciptakan animasi yang mulus. Keyframes dapat berisi properti apa pun yang dapat dianimasikan. Nama keyframes bersifat kustom dan akan dirujuk oleh properti `animation-name`.

## Contoh Kode Implementasi

```css
/* Keyframes sederhana: fade in */
@keyframes fadeIn {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

/* Keyframes dengan beberapa tahapan */
@keyframes slideIn {
  0% {
    opacity: 0;
    transform: translateX(-100%);
  }
  50% {
    opacity: 0.5;
    transform: translateX(20px);
  }
  100% {
    opacity: 1;
    transform: translateX(0);
  }
}

/* Keyframes kompleks: bounce */
@keyframes bounce {
  0%, 100% {
    transform: translateY(0);
    animation-timing-function: ease-out;
  }
  30% {
    transform: translateY(-50px);
    animation-timing-function: ease-in;
  }
  50% {
    transform: translateY(0);
    animation-timing-function: ease-out;
  }
  70% {
    transform: translateY(-25px);
    animation-timing-function: ease-in;
  }
  90% {
    transform: translateY(-5px);
    animation-timing-function: ease-in;
  }
}

/* Keyframes: spin loading */
@keyframes spin {
  0% {
    transform: rotate(0deg);
  }
  100% {
    transform: rotate(360deg);
  }
}

/* Keyframes: pulse */
@keyframes pulse {
  0%, 100% {
    transform: scale(1);
    opacity: 1;
  }
  50% {
    transform: scale(1.1);
    opacity: 0.8;
  }
}

/* Keyframes: shimmer untuk skeleton loading */
@keyframes shimmer {
  0% {
    background-position: -200% 0;
  }
  100% {
    background-position: 200% 0;
  }
}

/* Multiple properti dalam satu keyframes */
@keyframes slideAndFade {
  0% {
    opacity: 0;
    transform: translateY(40px) scale(0.95);
  }
  60% {
    opacity: 1;
    transform: translateY(-5px) scale(1.02);
  }
  100% {
    opacity: 1;
    transform: translateY(0) scale(1);
  }
}

/* Keyframes dengan warna */
@keyframes colorCycle {
  0% {
    background-color: #4285f4;
  }
  25% {
    background-color: #34a853;
  }
  50% {
    background-color: #fbbc05;
  }
  75% {
    background-color: #ea4335;
  }
  100% {
    background-color: #4285f4;
  }
}

/* Menggunakan keyframes */
.fade-in-element {
  animation-name: fadeIn;
  animation-duration: 1s;
  animation-fill-mode: forwards;
}

.bounce-element {
  animation-name: bounce;
  animation-duration: 1s;
  animation-iteration-count: infinite;
}

.spinner {
  animation-name: spin;
  animation-duration: 1s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}
```

## Poin Penting
- @keyframes mendefinisikan tahapan animasi menggunakan persentase (0%-100%)
- from setara dengan 0%, to setara dengan 100%
- Setiap keyframes dapat berisi banyak properti CSS yang berubah secara bersamaan
- Nama keyframes bersifat kustom dan case-sensitive
