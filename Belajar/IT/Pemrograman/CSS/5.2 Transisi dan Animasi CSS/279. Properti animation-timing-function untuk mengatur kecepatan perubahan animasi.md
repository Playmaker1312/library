# Properti animation-timing-function untuk mengatur kecepatan perubahan animasi

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur pola gerakan setiap animasi. Buku yang muncul dari bawah bergerak cepat di awal lalu melambat (ease-out). Loading spinner berputar dengan kecepatan konstan (linear). Bola yang memantul bergerak lambat di puncak dan cepat saat jatuh. Setiap animasi memiliki karakter gerakan yang berbeda, ditentukan oleh timing function.

## Penjelasan Detail

`animation-timing-function` mengatur kurva kecepatan animasi di dalam satu siklus keyframes. Nilainya sama dengan `transition-timing-function`: `ease`, `linear`, `ease-in`, `ease-out`, `ease-in-out`, dan `cubic-bezier()`. Perbedaan penting: timing function dapat didefinisikan di dalam keyframes individual untuk mengontrol kecepatan antar tahapan tertentu. Jika timing function diterapkan pada elemen, ia mempengaruhi seluruh animasi. Jika diterapkan di dalam keyframes, ia mempengaruhi segmen antara keyframe tersebut dan keyframe berikutnya.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(40px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes bounce {
  0% {
    transform: translateY(0);
    animation-timing-function: ease-out;
  }
  50% {
    transform: translateY(-50px);
    animation-timing-function: ease-in;
  }
  100% {
    transform: translateY(0);
    animation-timing-function: ease-out;
  }
}

@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

/* Timing function pada elemen */
.slide-up-ease-out {
  animation-name: slideUp;
  animation-duration: 0.6s;
  animation-timing-function: ease-out;
  animation-fill-mode: backwards;
}

.slide-up-linear {
  animation-name: slideUp;
  animation-duration: 0.6s;
  animation-timing-function: linear;
  animation-fill-mode: backwards;
}

/* Timing function untuk animasi berulang */
.spinner-linear {
  animation-name: spin;
  animation-duration: 1s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

/* Bounce dengan timing function di keyframes */
.bouncing-ball {
  animation-name: bounce;
  animation-duration: 1s;
  animation-iteration-count: infinite;
}

/* Timing function kustom dengan cubic-bezier */
.custom-bounce {
  animation-name: slideUp;
  animation-duration: 0.6s;
  animation-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55);
}

/* Multiple animasi dengan timing function berbeda */
.element {
  animation-name: fadeIn, slideUp;
  animation-duration: 0.3s, 0.6s;
  animation-timing-function: ease, ease-out;
}

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

/* Timing function dalam keyframes untuk kontrol granular */
@keyframes pulse {
  0% {
    transform: scale(1);
    animation-timing-function: ease-out;
  }
  50% {
    transform: scale(1.1);
    animation-timing-function: ease-in;
  }
  100% {
    transform: scale(1);
    animation-timing-function: ease-out;
  }
}

.pulse-element {
  animation-name: pulse;
  animation-duration: 0.5s;
  animation-iteration-count: infinite;
}

/* Rekomendasi timing function per jenis animasi */
:root {
  --entrance-timing: ease-out;
  --exit-timing: ease-in;
  --continuous-timing: linear;
  --bounce-timing: cubic-bezier(0.68, -0.55, 0.27, 1.55);
}

.entrance {
  animation-name: slideUp;
  animation-duration: 0.5s;
  animation-timing-function: var(--entrance-timing);
}
```

## Poin Penting
- animation-timing-function mengatur kurva kecepatan dalam satu siklus animasi
- Timing function di dalam @keyframes mengontrol kecepatan antar keyframe spesifik
- ease-out paling alami untuk entrance animation
- linear wajib untuk animasi rotasi (spinner) agar terlihat konsisten
