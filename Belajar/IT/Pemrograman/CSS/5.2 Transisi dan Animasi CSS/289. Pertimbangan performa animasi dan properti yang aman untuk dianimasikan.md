# Pertimbangan performa animasi dan properti yang aman untuk dianimasikan

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin animasi berjalan mulus seperti air mengalir, bukan tersendat-sendat seperti film dengan frame rendah. Beberapa properti seperti posisi dan ukuran membutuhkan perhitungan ulang tata letak yang berat. Properti lain seperti opacity dan transform hanya mempengaruhi komposisi dan dapat diproses oleh GPU. Memilih properti yang tepat untuk dianimasikan sama pentingnya dengan memilih buku yang tepat untuk dibaca.

## Penjelasan Detail

Performa animasi CSS sangat dipengaruhi oleh properti yang dianimasikan. Tiga tahap rendering pipeline: Layout (perhitungan posisi/ukuran), Paint (penggambaran piksel), dan Composite (penggabungan layer). Properti seperti `width`, `height`, `top`, `left`, `margin`, `padding` memicu Layout yang paling berat. Properti seperti `color`, `background-color` memicu Paint yang lebih ringan. Properti `opacity` dan `transform` hanya memicu Composite yang paling ringan dan dapat diakselerasi GPU. Untuk animasi 60fps yang mulus, prioritaskan `transform` dan `opacity`. Gunakan `will-change` untuk memberi petunjuk browser tentang properti yang akan berubah. Hindari menganimasikan properti yang memicu Layout.

## Contoh Kode Implementasi

```css
/* PROSES YANG AMAN (hanya Composite) */

/* Transform: aman untuk animasi */
.safe-transform {
  transition: transform 0.3s ease;
}

.safe-transform:hover {
  transform: translateX(50px) scale(1.05);
}

/* Opacity: aman untuk animasi */
.safe-opacity {
  transition: opacity 0.3s ease;
}

.safe-opacity:hover {
  opacity: 0.8;
}

/* Filter: cukup aman, bisa diakselerasi GPU */
.safe-filter {
  transition: filter 0.3s ease;
}

.safe-filter:hover {
  filter: brightness(1.1) blur(2px);
}

/* PROSES YANG KURANG AMAN (memicu Paint) */

/* Color changes: memicu Paint */
.less-safe-color {
  transition: color 0.3s ease, background-color 0.3s ease;
}

.less-safe-color:hover {
  color: #1a73e8;
  background-color: #f0f6ff;
}

/* PROSES YANG TIDAK AMAN (memicu Layout) */

/* Hindari: width, height, top, left, margin, padding */
.avoid-layout {
  /* JANGAN lakukan ini:
  transition: width 0.3s ease, height 0.3s ease;
  */
  transition: transform 0.3s ease;
}

/* Alternatif: gunakan transform */
.box {
  width: 200px;
  height: 200px;
  background: #1a73e8;
  transition: transform 0.3s ease;
}

.box:hover {
  transform: scale(1.1);
  /* Alternatif dari width: 220px */
}

/* Gunakan will-change untuk optimalisasi */
.optimized-element {
  will-change: transform, opacity;
  transition: transform 0.3s ease, opacity 0.3s ease;
}

/* Hindari animasi properti yang tidak perlu */
/* BURUK: menganimasikan semua properti */
.bad-practice {
  transition: all 0.3s ease;
}

/* BAIK: hanya animasikan properti yang diperlukan */
.good-practice {
  transition: transform 0.3s ease, opacity 0.3s ease;
}

/* Rekomendasi properti untuk animasi */
:root {
  /* Aman: */
  --animate-transform: transform 0.3s ease;
  --animate-opacity: opacity 0.3s ease;
  --animate-filter: filter 0.3s ease;
  
  /* Cukup aman: */
  --animate-color: color 0.3s ease;
  --animate-bg: background-color 0.3s ease;
  --animate-shadow: box-shadow 0.3s ease;
}

/* Test performa: prefer transform dibanding properti posisi */
/* BURUK */
.element-bad {
  position: relative;
  left: 0;
  transition: left 0.3s ease;
}
.element-bad.active {
  left: 100px;
}

/* BAIK */
.element-good {
  transition: transform 0.3s ease;
}
.element-good.active {
  transform: translateX(100px);
}
```

## Poin Penting
- Prioritaskan transform dan opacity untuk animasi (hanya Composite)
- Hindari width, height, top, left yang memicu Layout (paling berat)
- Gunakan will-change secara bijak, jangan berlebihan
- Transform sebagai alternatif untuk animasi posisi dan ukuran
