# Properti transition-delay untuk mengatur jeda sebelum transisi dimulai

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki efek berantai: saat pengguna mengarahkan kursor ke rak buku, rak pertama bergerak segera, rak kedua bergerak 100ms kemudian, rak ketiga 200ms kemudian. Jeda ini menciptakan efek gelombang yang menarik. Sebaliknya, saat kursor meninggalkan rak, semua rak kembali dengan jeda yang sama, menciptakan ritme yang konsisten.

## Penjelasan Detail

`transition-delay` menentukan waktu tunggu sebelum transisi dimulai. Nilai positif menyebabkan transisi dimulai setelah jeda tertentu. Nilai negatif menyebabkan transisi dimulai segera, tetapi seolah-olah sudah berjalan selama durasi delay tersebut. Delay sangat berguna untuk efek berantai (staggered animation) di mana elemen bergerak bergantian. Delay juga berguna untuk menghindari transisi yang tidak diinginkan saat halaman dimuat, atau untuk menciptakan efek masuk yang bertahap. Kombinasi delay dengan durasi yang berbeda pada properti yang sama dapat menciptakan efek yang kompleks.

## Contoh Kode Implementasi

```css
/* Delay positif: transisi dimulai setelah jeda */
.button {
  background-color: #1a73e8;
  color: white;
  padding: 0.75rem 1.5rem;
  border: none;
  border-radius: 4px;
  cursor: pointer;
  transition-property: background-color;
  transition-duration: 0.3s;
  transition-delay: 0.1s;
}

.button:hover {
  background-color: #1557b0;
}

/* Staggered animation: efek berantai */
.stagger-item {
  opacity: 0;
  transform: translateY(20px);
  transition-property: opacity, transform;
  transition-duration: 0.4s;
  transition-timing-function: ease-out;
}

.stagger-item:nth-child(1) { transition-delay: 0ms; }
.stagger-item:nth-child(2) { transition-delay: 100ms; }
.stagger-item:nth-child(3) { transition-delay: 200ms; }
.stagger-item:nth-child(4) { transition-delay: 300ms; }
.stagger-item:nth-child(5) { transition-delay: 400ms; }

.stagger-item.active {
  opacity: 1;
  transform: translateY(0);
}

/* Delay negatif: transisi seolah sudah dimulai */
.negative-delay {
  opacity: 0;
  transition-property: opacity;
  transition-duration: 2s;
  /* Transisi seolah sudah berjalan 1s */
  transition-delay: -1s;
}

.negative-delay.active {
  opacity: 1;
}

/* Delay berbeda untuk hover dan leave */
.toggle-element {
  background-color: #1a73e8;
  transition-property: background-color;
  transition-duration: 0.3s;
  /* Saat hover: delay 0s, saat leave: delay 0.2s */
  transition-delay: 0s;
}

.toggle-element:hover {
  background-color: #34a853;
  transition-delay: 0.2s;
}

/* Delay pada menu dropdown */
.menu-item {
  transition-property: opacity, transform;
  transition-duration: 0.2s;
  transition-timing-function: ease-out;
}

.menu-item:nth-child(1) { transition-delay: 0ms; }
.menu-item:nth-child(2) { transition-delay: 50ms; }
.menu-item:nth-child(3) { transition-delay: 100ms; }
.menu-item:nth-child(4) { transition-delay: 150ms; }

.menu-item.hidden {
  opacity: 0;
  transform: translateY(-10px);
}

/* Delay untuk tooltip */
.tooltip {
  opacity: 0;
  transition-property: opacity;
  transition-duration: 0.2s;
  transition-delay: 0s;
}

.tooltip-trigger:hover .tooltip {
  opacity: 1;
  transition-delay: 0.5s;
}
```

## Poin Penting
- transition-delay positif menunda awal transisi, negatif membuat transisi seolah sudah berjalan
- Staggered animation menggunakan delay bervariasi untuk efek berantai
- Delay berbeda untuk masuk dan keluar menciptakan interaksi yang lebih natural
- Gunakan milidetik untuk delay yang presisi pada efek berantai
