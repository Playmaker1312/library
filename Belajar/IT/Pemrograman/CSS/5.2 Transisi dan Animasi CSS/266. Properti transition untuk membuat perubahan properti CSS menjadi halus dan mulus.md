# Properti transition untuk membuat perubahan properti CSS menjadi halus dan mulus

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika pengguna mengarahkan kursor ke sampul buku, sampul itu tidak langsung membesar secara instan. Sebaliknya, ia membesar secara perlahan dan mulus selama sepersekian detik, memberikan kesan alami dan menyenangkan. Transisi ini membuat interaksi terasa lebih hidup dan profesional, seperti buku fisik yang perlahan ditarik ke arah pembaca.

## Penjelasan Detail

Properti `transition` di CSS memungkinkan perubahan nilai properti dari satu keadaan ke keadaan lain terjadi secara bertahap selama periode waktu tertentu. Tanpa transisi, perubahan properti terjadi secara instan yang terlihat kasar dan tiba-tiba. Transisi bekerja antara dua keadaan: keadaan awal (biasanya gaya default) dan keadaan akhir (biasanya saat hover, focus, atau perubahan kelas). Properti yang dapat ditransisikan umumnya adalah properti numerik seperti `opacity`, `transform`, `color`, `background-color`, dan `width`. Shorthand `transition` menggabungkan `transition-property`, `transition-duration`, `transition-timing-function`, dan `transition-delay`.

## Contoh Kode Implementasi

```css
/* Transisi sederhana pada hover */
.button {
  background-color: #1a73e8;
  color: #ffffff;
  padding: 0.75rem 1.5rem;
  border: none;
  border-radius: 4px;
  cursor: pointer;
  font-size: 1rem;
  transition: background-color 0.3s ease;
}

.button:hover {
  background-color: #1557b0;
}

/* Transisi pada beberapa properti */
.card {
  background: #ffffff;
  padding: 1.5rem;
  border-radius: 8px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
  cursor: pointer;
  transition: 
    transform 0.3s ease,
    box-shadow 0.3s ease,
    background-color 0.3s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 24px rgba(0, 0, 0, 0.15);
  background-color: #f8f9fa;
}

/* Transisi pada link */
a {
  color: #1a73e8;
  text-decoration: none;
  transition: color 0.2s ease, text-decoration-color 0.2s ease;
  text-decoration-color: transparent;
  text-decoration-line: underline;
}

a:hover {
  color: #1557b0;
  text-decoration-color: currentColor;
}

/* Transisi pada gambar */
.gallery img {
  width: 100%;
  height: 200px;
  object-fit: cover;
  border-radius: 4px;
  transition: transform 0.4s ease, filter 0.4s ease;
  cursor: pointer;
}

.gallery img:hover {
  transform: scale(1.05);
  filter: brightness(1.1);
}

/* Transisi dengan nilai berbeda per properti */
.element {
  opacity: 1;
  transform: scale(1);
  background-color: #1a73e8;
  transition:
    opacity 0.3s ease,
    transform 0.5s ease-out,
    background-color 1s linear;
}

.element:hover {
  opacity: 0.8;
  transform: scale(1.1);
  background-color: #34a853;
}
```

## Poin Penting
- Transition membuat perubahan properti CSS menjadi mulus dan tidak instan
- Properti numerik dan warna dapat ditransisikan, properti diskrit (seperti display) tidak
- Shorthand transition menggabungkan property, duration, timing-function, dan delay
- Waktu transisi yang umum: 0.2s-0.3s untuk hover, 0.3s-0.5s untuk layout changes
