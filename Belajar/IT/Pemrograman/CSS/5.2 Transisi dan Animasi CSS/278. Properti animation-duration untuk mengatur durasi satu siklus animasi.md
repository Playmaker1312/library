# Properti animation-duration untuk mengatur durasi satu siklus animasi

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur durasi setiap gerakan: fade in membutuhkan 0,5 detik, slide up 0,6 detik, bounce 1 detik, dan rotasi penuh 2 detik. Seperti konduktor yang menentukan tempo setiap bagian orkestra, animation-duration menentukan berapa lama satu siklus animasi berlangsung. Durasi yang tepat membuat animasi terasa alami dan tidak mengganggu.

## Penjelasan Detail

`animation-duration` menentukan berapa lama satu siklus penuh animasi berlangsung, diukur dari awal hingga akhir keyframes. Nilai dapat ditulis dalam detik (`s`) atau milidetik (`ms`). Animasi dengan durasi pendek (0.3s-0.5s) cocok untuk feedback interaksi. Durasi sedang (0.6s-1s) cocok untuk entrance animation. Durasi panjang (2s-5s) cocok untuk animasi dekoratif yang terus berulang. Untuk animasi dengan `animation-iteration-count: infinite`, durasi menentukan kecepatan setiap siklus. Multiple animasi dapat memiliki durasi berbeda dengan menggunakan daftar nilai dipisah koma.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes slideIn {
  from {
    opacity: 0;
    transform: translateY(30px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-30px); }
}

/* Durasi pendek (0.3s) - feedback instan */
.button-feedback {
  animation-name: fadeIn;
  animation-duration: 0.3s;
}

/* Durasi sedang (0.6s) - entrance animation */
.card-entrance {
  animation-name: slideIn;
  animation-duration: 0.6s;
  animation-timing-function: ease-out;
  animation-fill-mode: backwards;
}

/* Durasi panjang (2s) - animasi dekoratif */
.loading-spinner {
  animation-name: spin;
  animation-duration: 2s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

/* Durasi sangat pendek (100ms) - micro-interaction */
.micro-feedback {
  animation-name: pulse;
  animation-duration: 100ms;
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(0.95); }
}

/* Multiple animasi dengan durasi berbeda */
.element {
  animation-name: slideIn, fadeIn;
  animation-duration: 0.6s, 0.4s;
  animation-timing-function: ease-out, ease;
}

/* Durasi dalam milidetik */
.fast-spinner {
  animation-name: spin;
  animation-duration: 500ms;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

.slow-spinner {
  animation-name: spin;
  animation-duration: 3000ms;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

/* Durasi diakses melalui custom property */
:root {
  --duration-fast: 150ms;
  --duration-normal: 300ms;
  --duration-slow: 600ms;
  --duration-very-slow: 2000ms;
}

.element {
  animation-name: fadeIn;
  animation-duration: var(--duration-normal);
}

/* Stagger duration */
.stagger-item {
  animation-name: slideIn;
  animation-duration: 0.4s;
  animation-fill-mode: backwards;
}

.stagger-item:nth-child(1) { animation-delay: 0s; }
.stagger-item:nth-child(2) { animation-delay: 0.1s; animation-duration: 0.5s; }
.stagger-item:nth-child(3) { animation-delay: 0.2s; animation-duration: 0.6s; }
```

## Poin Penting
- animation-duration dalam detik (0.5s) atau milidetik (500ms)
- Durasi pendek (< 0.5s) untuk feedback, sedang (0.5s-1s) untuk entrance, panjang (> 1s) untuk dekoratif
- Multiple animasi dapat memiliki durasi berbeda dengan daftar koma
- Durasi 0s atau nilai negatif menyebabkan animasi tidak berjalan
