# Properti animation-delay untuk mengatur jeda sebelum animasi dimulai

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur waktu mulai setiap animasi. Buku pertama mulai bergerak segera, buku kedua menunggu 200ms, buku ketiga menunggu 400ms. Jeda ini menciptakan efek gelombang yang menarik. Saat tombol dipencet, animasi loading mulai setelah jeda 300ms untuk memastikan bahwa aksi benar-benar dimaksudkan oleh pengguna, bukan karena kesalahan klik.

## Penjelasan Detail

`animation-delay` menentukan waktu tunggu sebelum animasi dimulai setelah diterapkan pada elemen. Nilai positif menyebabkan animasi memulai setelah jeda. Nilai negatif menyebabkan animasi dimulai segera tetapi seolah-olah sudah berjalan selama durasi delay tersebut. Delay sangat berguna untuk efek staggered (berantai), di mana elemen-elemen yang berurutan memulai animasi dengan jeda tertentu. Delay negatif berguna untuk memulai animasi di tengah siklus, yang sangat berguna untuk animasi yang tampaknya berjalan acak pada elemen yang identik.

## Contoh Kode Implementasi

```css
/* Definisi keyframes */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(40px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}

/* Delay positif: animasi dimulai setelah jeda */
.delayed-fade {
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-delay: 0.3s;
  animation-fill-mode: backwards;
}

/* Staggered animation dengan delay */
.stagger-item {
  animation-name: slideUp;
  animation-duration: 0.4s;
  animation-timing-function: ease-out;
  animation-fill-mode: backwards;
}

.stagger-item:nth-child(1) { animation-delay: 0ms; }
.stagger-item:nth-child(2) { animation-delay: 100ms; }
.stagger-item:nth-child(3) { animation-delay: 200ms; }
.stagger-item:nth-child(4) { animation-delay: 300ms; }
.stagger-item:nth-child(5) { animation-delay: 400ms; }
.stagger-item:nth-child(6) { animation-delay: 500ms; }

/* Delay negatif: memulai di tengah animasi */
.random-spinner {
  animation-name: spin;
  animation-duration: 2s;
  animation-iteration-count: infinite;
  animation-timing-function: linear;
}

.random-spinner:nth-child(1) { animation-delay: 0s; }
.random-spinner:nth-child(2) { animation-delay: -0.5s; }
.random-spinner:nth-child(3) { animation-delay: -1s; }
.random-spinner:nth-child(4) { animation-delay: -1.5s; }

/* Delay untuk animasi entrance halaman */
.page-header {
  animation-name: slideUp;
  animation-duration: 0.6s;
  animation-delay: 0.2s;
  animation-fill-mode: backwards;
}

.page-content {
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-delay: 0.4s;
  animation-fill-mode: backwards;
}

.page-footer {
  animation-name: fadeIn;
  animation-duration: 0.5s;
  animation-delay: 0.6s;
  animation-fill-mode: backwards;
}

/* Delay dengan nilai negatif untuk efek kontinu */
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.1); }
}

.pulse-stagger {
  animation-name: pulse;
  animation-duration: 1s;
  animation-iteration-count: infinite;
}

.pulse-stagger:nth-child(1) { animation-delay: 0s; }
.pulse-stagger:nth-child(2) { animation-delay: -0.33s; }
.pulse-stagger:nth-child(3) { animation-delay: -0.66s; }

/* Delay dalam milidetik */
.notification {
  animation-name: slideUp;
  animation-duration: 400ms;
  animation-delay: 300ms;
  animation-fill-mode: backwards;
  animation-timing-function: ease-out;
}
```

## Poin Penting
- animation-delay positif menunda awal animasi, delay negatif memulai di tengah siklus
- Staggered animation menggunakan delay bervariasi untuk efek berantai
- Delay negatif berguna untuk membuat elemen identik tampak berjalan acak
- Selalu gunakan animation-fill-mode: backwards dengan delay positif untuk mencegah flash
