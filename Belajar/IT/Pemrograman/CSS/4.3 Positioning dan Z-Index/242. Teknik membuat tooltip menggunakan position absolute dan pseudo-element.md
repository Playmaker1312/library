# Teknik membuat tooltip menggunakan position absolute dan pseudo-element

## Analogi: Perpustakaan Digital

Bayangkan saat kamu mengarahkan kursor ke sebuah buku di perpustakaan digital, muncul kotak kecil berisi informasi tambahan (sinopsis, tahun terbit, penulis) di atas buku tersebut. Tooltip ini muncul di luar aliran normal halaman, melayang di atas konten lain, dan menghilang saat kursor menjauh. Ini adalah implementasi umum dari `position: absolute` yang dikombinasikan dengan pseudo-element untuk membuat panah indikator.

## Penjelasan Detail

Tooltip dibuat dengan menempatkan elemen secara absolute relatif terhadap induknya (yang diberi `position: relative`). Tooltip tersembunyi secara default (`display: none` atau `opacity: 0`) dan muncul saat hover (`:hover`). Pseudo-element `::after` atau `::before` digunakan untuk membuat panah kecil di bawah tooltip menggunakan border trik. Posisi tooltip bisa di atas, bawah, kiri, atau kanan elemen. Properti `white-space: nowrap` mencegah tooltip terputus menjadi beberapa baris. `z-index` yang tinggi memastikan tooltip berada di atas elemen lain.

## Contoh Kode Implementasi

```css
.tooltip-container {
  position: relative;
  display: inline-block;
  cursor: pointer;
  border-bottom: 1px dotted #333;
}

.tooltip-container .tooltip-text {
  position: absolute;
  bottom: calc(100% + 10px);
  left: 50%;
  transform: translateX(-50%);
  background: #333;
  color: white;
  padding: 8px 14px;
  border-radius: 6px;
  font-size: 14px;
  white-space: nowrap;
  z-index: 100;
  display: none;
}

.tooltip-container .tooltip-text::after {
  content: '';
  position: absolute;
  top: 100%;
  left: 50%;
  transform: translateX(-50%);
  border: 6px solid transparent;
  border-top-color: #333;
}

.tooltip-container:hover .tooltip-text {
  display: block;
}

/* Tooltip posisi bawah */
.tooltip-bottom .tooltip-text {
  bottom: auto;
  top: calc(100% + 10px);
}

.tooltip-bottom .tooltip-text::after {
  top: auto;
  bottom: 100%;
  border-top-color: transparent;
  border-bottom-color: #333;
}
```

## Poin Penting
- Gunakan `position: relative` pada container dan `position: absolute` pada tooltip
- Sembunyikan tooltip dengan `display: none`, tampilkan dengan `:hover`
- Pseudo-element `::after` membuat panah menggunakan border trik
- `white-space: nowrap` mencegah tooltip terputus
- `z-index` tinggi memastikan tooltip di atas elemen lain
