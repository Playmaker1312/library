# Masalah umum z-index yang tidak berfungsi dan cara mengatasinya

## Analogi: Perpustakaan Digital

Bayangkan kamu sudah memberi label "prioritas tinggi" pada sebuah catatan, tetapi catatan itu tetap tertutup oleh catatan lain. Masalahnya mungkin karena catatan tersebut berada di laci yang berbeda—dalam stacking context yang berbeda. Atau mungkin label "prioritas" tidak berlaku karena catatan tersebut tidak diposisikan secara khusus (position: static). Inilah dua masalah paling umum mengapa z-index sering tidak berfungsi seperti yang diharapkan.

## Penjelasan Detail

Ada beberapa penyebab umum z-index tidak berfungsi: (1) Elemen tidak memiliki `position` yang ditentukan (z-index hanya bekerja pada elemen dengan `position` selain `static`). (2) Elemen berada dalam stacking context yang berbeda—z-index tidak bisa membandingkan elemen dari context yang berbeda. (3) Elemen induk memiliki `overflow: hidden` yang memotong elemen child. (4) Elemen memiliki `opacity` < 1 yang membentuk stacking context baru. (5) Urutan HTML—elemen yang muncul belakangan secara default berada di atas elemen sebelumnya. Solusinya: pastikan `position` diatur, periksa stacking context induk, dan hindari properti yang tidak sengaja membuat stacking context baru.

## Contoh Kode Implementasi

```css
/* Masalah: z-index tidak berfungsi */
.problem-child {
  position: absolute;
  z-index: 999;
  background: #F44336;
  color: white;
  padding: 16px;
}

/* Solusi: pastikan induk tidak membatasi stacking context */
.solution-parent {
  position: relative;
  z-index: auto;
  overflow: visible;
}

/* Alternatif: pastikan elemen dalam stacking context yang sama */
.same-context {
  position: relative;
  z-index: 1;
}

.higher-element {
  position: relative;
  z-index: 10;
  background: #4CAF50;
  color: white;
  padding: 12px;
}

/* Hindari opacity yang tidak sengaja membuat context */
.no-opacity-context {
  position: relative;
  z-index: 5;
  background: rgba(33, 150, 243, 0.9);
}
```

## Poin Penting
- Pastikan elemen memiliki `position` yang ditentukan (bukan static)
- Periksa stacking context—z-index hanya bekerja dalam context yang sama
- Properti seperti opacity, transform, filter membuat stacking context baru
- Hindari `overflow: hidden` pada induk jika elemen absolute perlu melampaui
- Gunakan browser dev tools untuk memeriksa stacking context
