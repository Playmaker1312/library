# Teknik membuat modal atau overlay menggunakan position fixed

## Analogi: Perpustakaan Digital

Bayangkan sebuah pop-up konfirmasi yang muncul di tengah layar saat kamu ingin meminjam buku. Latar belakang menjadi gelap (overlay) dan kotak konfirmasi melayang di atasnya, tidak peduli bagaimana posisi scroll halaman. Ini adalah modal—elemen yang menutupi seluruh halaman dan membutuhkan interaksi pengguna sebelum bisa melanjutkan. Modal menggunakan `position: fixed` untuk menutupi viewport.

## Penjelasan Detail

Modal terdiri dari dua elemen utama: overlay (latar belakang gelap) dan modal content (kotak dialog). Keduanya menggunakan `position: fixed` agar tetap di tempat meskipun halaman di-scroll. Overlay mencakup seluruh viewport dengan `inset: 0` (shorthand untuk top, right, bottom, left = 0) dan latar belakang semi-transparan. Modal content dipusatkan menggunakan kombinasi `top: 50%; left: 50%; transform: translate(-50%, -50%)`. `z-index` yang sangat tinggi memastikan modal berada di atas semua konten. Saat modal aktif, scroll pada body biasanya dicegah dengan `overflow: hidden` pada body.

## Contoh Kode Implementasi

```css
.modal-overlay {
  position: fixed;
  inset: 0;
  background: rgba(0, 0, 0, 0.5);
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 1000;
  opacity: 0;
  visibility: hidden;
  transition: opacity 0.3s, visibility 0.3s;
}

.modal-overlay.active {
  opacity: 1;
  visibility: visible;
}

.modal-content {
  background: white;
  border-radius: 12px;
  padding: 32px;
  max-width: 500px;
  width: 90%;
  max-height: 80vh;
  overflow-y: auto;
  box-shadow: 0 20px 60px rgba(0,0,0,0.3);
  position: relative;
}

.modal-close {
  position: absolute;
  top: 12px;
  right: 16px;
  cursor: pointer;
  font-size: 24px;
  color: #999;
  border: none;
  background: none;
}

body.no-scroll {
  overflow: hidden;
}
```

## Poin Penting
- Overlay dan modal menggunakan `position: fixed` dengan `inset: 0`
- Pusatkan modal dengan `display: flex` pada overlay atau dengan transform
- `z-index` tinggi (1000+) memastikan modal di atas konten lain
- Cegah scroll body dengan `overflow: hidden` saat modal aktif
- Gunakan transisi untuk animasi muncul/hilang yang halus
