# Properti z-index untuk mengontrol urutan tumpukan elemen dalam stacking context

## Analogi: Perpustakaan Digital

Bayangkan beberapa catatan tempel yang saling tumpang tindih di papan pengumuman. Catatan dengan nomor `z-index` lebih tinggi akan berada di atas catatan dengan nomor lebih rendah. Jika dua catatan memiliki nomor yang sama, catatan yang muncul belakangan dalam HTML akan berada di atas. Properti `z-index` memberikan kontrol atas urutan vertikal elemen-elemen yang bertumpukan.

## Penjelasan Detail

`z-index` adalah properti yang mengontrol urutan tumpukan (stacking order) elemen dalam stacking context yang sama. Nilai berupa integer (bisa negatif). Elemen dengan `z-index` lebih tinggi muncul di atas elemen dengan nilai lebih rendah. Nilai default adalah `auto` (sama dengan 0 tetapi tidak membentuk stacking context baru). `z-index` hanya berfungsi pada elemen dengan `position` selain `static`. Nilai negatif menempatkan elemen di belakang elemen in-flow normal. Nilai besar (9999) menempatkan elemen di atas yang lain, tetapi tetap terbatas dalam stacking context-nya. `z-index` tidak bersifat global—hanya membandingkan dalam stacking context yang sama.

## Contoh Kode Implementasi

```css
.container {
  position: relative;
  background: #f0f0f0;
  padding: 40px;
  border: 2px solid #333;
  min-height: 150px;
}

.box {
  position: absolute;
  width: 120px;
  height: 120px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
  font-weight: bold;
  border-radius: 8px;
}

.box-1 { top: 20px; left: 20px; background: #F44336; z-index: 1; }
.box-2 { top: 50px; left: 60px; background: #2196F3; z-index: 3; }
.box-3 { top: 80px; left: 100px; background: #4CAF50; z-index: 2; }

/* Box-2 (z-index: 3) akan berada di atas */
```

## Poin Penting
- `z-index` mengontrol urutan tumpukan dalam stacking context yang sama
- Nilai integer: lebih tinggi = lebih atas, lebih rendah = lebih bawah
- Hanya berfungsi pada elemen dengan position non-static
- Nilai negatif menempatkan elemen di belakang elemen normal
- `z-index` bersifat lokal dalam stacking context—tidak global
