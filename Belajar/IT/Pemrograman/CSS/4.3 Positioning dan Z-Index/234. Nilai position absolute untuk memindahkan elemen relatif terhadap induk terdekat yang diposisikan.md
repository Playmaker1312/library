# Nilai position absolute untuk memindahkan elemen relatif terhadap induk terdekat yang diposisikan

## Analogi: Perpustakaan Digital

Bayangkan sebuah catatan tempel yang ditempelkan di papan pengumuman. Catatan ini tidak mengikuti aliran normal dokumen—ia ditempatkan secara presisi di koordinat tertentu pada papan. Papan pengumuman adalah "induk yang diposisikan". Jika tidak ada papan, catatan akan menempel pada dinding (viewport). Catatan ini juga tidak memengaruhi posisi elemen lain di sekitarnya.

## Penjelasan Detail

`position: absolute` mengeluarkan elemen dari aliran dokumen normal, sehingga elemen lain berperilaku seolah elemen tersebut tidak ada. Elemen kemudian diposisikan relatif terhadap ancestor terdekat yang memiliki `position` selain `static` (biasanya `relative`). Jika tidak ada ancestor yang diposisikan, elemen akan diposisikan relatif terhadap `body` atau viewport (tergantung pada konteks). Properti `top`, `right`, `bottom`, `left` menentukan offset dari tepi ancestor. Ukuran elemen absolute ditentukan oleh kontennya kecuali jika properti offset atau `width`/`height` ditentukan secara eksplisit.

## Contoh Kode Implementasi

```css
.card {
  position: relative;
  background: white;
  border: 2px solid #ddd;
  border-radius: 8px;
  padding: 24px;
  min-height: 120px;
  margin: 20px 0;
}

.badge {
  position: absolute;
  top: -10px;
  right: -10px;
  background: #F44336;
  color: white;
  padding: 4px 12px;
  border-radius: 12px;
  font-size: 12px;
  font-weight: bold;
}

.tooltip {
  position: absolute;
  bottom: calc(100% + 8px);
  left: 50%;
  transform: translateX(-50%);
  background: #333;
  color: white;
  padding: 6px 12px;
  border-radius: 4px;
  white-space: nowrap;
  display: none;
}

.card:hover .tooltip {
  display: block;
}
```

## Poin Penting
- `position: absolute` mengeluarkan elemen dari aliran dokumen normal
- Diposisikan relatif terhadap ancestor terdekat yang diposisikan (non-static)
- Jika tidak ada ancestor yang diposisikan, relatif terhadap body
- Elemen lain mengabaikan elemen absolute (ruang tidak dipertahankan)
- Ukuran elemen mengikuti konten, kecuali ditentukan secara eksplisit
