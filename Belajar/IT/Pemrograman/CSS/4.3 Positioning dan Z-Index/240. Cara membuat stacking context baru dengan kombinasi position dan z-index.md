# Cara membuat stacking context baru dengan kombinasi position dan z-index

## Analogi: Perpustakaan Digital

Bayangkan dua tumpukan kertas terpisah di meja yang berbeda. Setiap tumpukan memiliki urutan internal sendiri (kertas 1, 2, 3). Kertas di tumpukan A tidak bisa disisipkan di antara kertas di tumpukan B—seluruh tumpukan A bisa di atas atau di bawah tumpukan B. Ini adalah analogi stacking context: elemen dengan stacking context sendiri membentuk "tumpukan" independen yang tidak bisa dicampur z-index-nya dengan tumpukan lain.

## Penjelasan Detail

Stacking context baru dapat dibuat oleh beberapa properti CSS, antara lain: (1) elemen dengan `position: relative` atau `absolute` dan `z-index` selain `auto`, (2) elemen dengan `position: fixed` atau `sticky`, (3) elemen dengan `opacity` kurang dari 1, (4) elemen dengan `transform` selain `none`, (5) elemen dengan `filter` selain `none`, (6) elemen dengan `will-change` yang sesuai. Saat stacking context baru terbentuk, semua anak elemen tersebut terisolasi dalam tumpukannya sendiri. Ini penting karena z-index tidak bisa membandingkan elemen dari stacking context yang berbeda.

## Contoh Kode Implementasi

```css
.context-a {
  position: relative;
  z-index: 1;
  background: #e3f2fd;
  padding: 20px;
  border: 2px solid #2196F3;
}

.context-b {
  position: relative;
  z-index: 2;
  background: #fce4ec;
  padding: 20px;
  border: 2px solid #F44336;
  margin-top: -20px;
}

.child-high {
  position: relative;
  z-index: 9999;
  background: #4CAF50;
  color: white;
  padding: 8px 12px;
}

.context-c {
  position: fixed;
  top: 100px;
  right: 20px;
  background: rgba(156, 39, 176, 0.9);
  color: white;
  padding: 16px;
  border-radius: 8px;
}
```

## Poin Penting
- Stacking context baru dibuat dengan position + z-index, opacity, transform, dll
- Elemen dalam stacking context terisolasi—z-index tidak bisa membandingkan lintas context
- `position: fixed` selalu membentuk stacking context baru
- `opacity` < 1, `transform`, dan `filter` juga membentuk stacking context
- Memahami pembentukan stacking context penting untuk debugging z-index
