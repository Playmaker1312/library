# Nilai position sticky untuk membuat elemen menempel saat melewati titik scroll tertentu

## Analogi: Perpustakaan Digital

Bayangkan label kategori di rak buku yang biasanya mengikuti aliran normal saat di-scroll, tetapi ketika label tersebut mencapai tepi atas layar, ia "menempel" di sana dan tidak ikut tergulung. Label akan tetap menempel sampai seluruh bagian raknya selesai dilewati. Ini adalah perilaku `position: sticky`—gabungan antara relative dan fixed, menempel hanya dalam batas container tertentu.

## Penjelasan Detail

`position: sticky` adalah hybrid antara `relative` dan `fixed`. Elemen berperilaku seperti `relative` dalam aliran normal sampai titik scroll tertentu tercapai, lalu "menempel" (menjadi `fixed`) pada posisi yang ditentukan. Elemen sticky tetap berada dalam aliran dokumen—ruangnya dipertahankan. Properti `top` (atau `bottom`, `left`, `right`) menentukan titik di mana elemen mulai menempel. Elemen hanya menempel selama masih berada dalam container induknya—begitu container meninggalkan viewport, elemen ikut tergulung. Sticky memerlukan `top` atau `bottom` yang ditentukan untuk berfungsi.

## Contoh Kode Implementasi

```css
.sticky-header {
  position: sticky;
  top: 0;
  background: #3F51B5;
  color: white;
  padding: 12px 20px;
  z-index: 10;
  font-weight: bold;
}

.sticky-sidebar {
  position: sticky;
  top: 20px;
  background: #f5f5f5;
  padding: 16px;
  border-radius: 8px;
  border: 1px solid #ddd;
}

.section {
  min-height: 200px;
  border: 1px solid #ccc;
  margin-bottom: 16px;
  padding: 16px;
}

.content-area {
  display: flex;
  gap: 24px;
}

.main-content {
  flex: 1;
}

.sidebar {
  width: 250px;
  align-self: flex-start;
}
```

## Poin Penting
- `position: sticky` adalah hybrid relative + fixed, menempel saat scroll
- Elemen tetap dalam aliran dokumen (ruang dipertahankan)
- Memerlukan properti `top`, `bottom`, `left`, atau `right` untuk aktif
- Hanya menempel dalam batas container induknya
- Cocok untuk header tabel, judul section, dan sidebar yang mengikuti scroll
