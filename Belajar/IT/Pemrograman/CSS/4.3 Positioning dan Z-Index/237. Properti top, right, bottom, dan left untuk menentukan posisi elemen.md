# Properti top, right, bottom, dan left untuk menentukan posisi elemen

## Analogi: Perpustakaan Digital

Properti `top`, `right`, `bottom`, dan `left` adalah seperti koordinat untuk menempatkan buku atau rak pada posisi tertentu. Jika kamu ingin menempatkan catatan di sudut kanan atas papan, kamu perlu menentukan jarak dari tepi kanan dan tepi atas. Properti ini menentukan offset elemen dari tepi-tapi reference-nya (viewport, ancestor, atau posisi normal) tergantung pada nilai `position` yang digunakan.

## Penjelasan Detail

Properti `top`, `right`, `bottom`, dan `left` menentukan offset posisi elemen dari tepi-tapi reference. Untuk `position: relative`, offset dihitung dari posisi normal elemen. Untuk `position: absolute`, offset dihitung dari tepi ancestor yang diposisikan. Untuk `position: fixed`, offset dihitung dari viewport. Untuk `position: sticky`, offset menentukan titik aktivasinya. Nilai bisa berupa panjang (px, em, %), auto, atau inherit. Nilai `auto` mengembalikan posisi ke posisi default. Persentase dihitung dari ukuran container (lebar untuk left/right, tinggi untuk top/bottom). Kombinasi keempat properti ini bisa digunakan untuk menentukan ukuran elemen secara implisit.

## Contoh Kode Implementasi

```css
.container {
  position: relative;
  width: 400px;
  height: 250px;
  border: 2px solid #333;
  margin: 20px 0;
}

.absolute-item {
  position: absolute;
  top: 20px;
  right: 30px;
  bottom: auto;
  left: auto;
  background: #9C27B0;
  color: white;
  padding: 12px 20px;
  border-radius: 4px;
}

.absolute-stretch {
  position: absolute;
  top: 10px;
  right: 10px;
  bottom: 10px;
  left: 10px;
  background: rgba(76, 175, 80, 0.2);
  border: 2px dashed #4CAF50;
  border-radius: 4px;
}

.relative-item {
  position: relative;
  top: -10px;
  left: 20px;
  background: #FF9800;
  color: white;
  padding: 12px;
}
```

## Poin Penting
- Offsets dihitung dari reference yang berbeda tergantung nilai position
- `top` dan `left` menggeser ke bawah/kanan (nilai positif)
- `right` dan `bottom` menggeser ke kiri/atas (nilai positif)
- Persentase dihitung dari ukuran container (lebar/tinggi)
- Kombinasi keempat properti bisa menentukan ukuran elemen secara implisit
