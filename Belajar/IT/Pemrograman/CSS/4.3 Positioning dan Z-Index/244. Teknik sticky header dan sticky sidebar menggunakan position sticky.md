# Teknik sticky header dan sticky sidebar menggunakan position sticky

## Analogi: Perpustakaan Digital

Bayangkan saat kamu scroll daftar buku, judul kategori (misalnya "Fiksi", "Non-Fiksi") menempel di bagian atas layar sehingga kamu selalu tahu sedang membaca kategori apa. Atau sidebar dengan menu navigasi yang tetap terlihat saat kamu scroll konten utama. Ini adalah sticky header dan sticky sidebar—elemen yang awalnya mengalir normal tetapi menjadi "menempel" saat mencapai posisi tertentu.

## Penjelasan Detail

`position: sticky` adalah solusi sempurna untuk header yang menempel dan sidebar yang mengikuti scroll. Untuk sticky header, atur `position: sticky; top: 0` pada elemen header. Header akan mengalir normal sampai mencapai bagian atas viewport, lalu menempel. Untuk sticky sidebar, atur `position: sticky; top: 20px` (atau nilai lain untuk jarak dari atas). Sidebar akan mengikuti scroll sampai container induknya habis. Penting untuk diketahui bahwa sticky hanya bekerja dalam batas container induknya. Sticky sidebar sering digunakan dalam layout dengan flexbox atau grid untuk memastikan sidebar dan konten utama memiliki tinggi yang berbeda.

## Contoh Kode Implementasi

```css
.section-header {
  position: sticky;
  top: 0;
  background: #3F51B5;
  color: white;
  padding: 12px 20px;
  font-weight: bold;
  z-index: 10;
  border-radius: 4px;
}

.page-layout {
  display: flex;
  gap: 24px;
  align-items: flex-start;
}

.main-content {
  flex: 1;
}

.sidebar {
  width: 280px;
  align-self: flex-start;
}

.sticky-sidebar {
  position: sticky;
  top: 24px;
  background: #f5f5f5;
  padding: 20px;
  border-radius: 8px;
  border: 1px solid #e0e0e0;
}

.sticky-sidebar ul {
  list-style: none;
  padding: 0;
  margin: 0;
}

.sticky-sidebar li {
  padding: 10px 12px;
  border-bottom: 1px solid #e0e0e0;
  cursor: pointer;
}

.sticky-sidebar li:hover {
  background: #e0e0e0;
}
```

## Poin Penting
- `position: sticky; top: 0` untuk header yang menempel di atas
- `position: sticky; top: 20px` untuk sidebar yang mengikuti scroll
- Sticky hanya bekerja dalam batas container induknya
- Untuk sidebar sticky, gunakan `align-items: flex-start` pada flex container
- Sticky tidak perlu JavaScript—solusi CSS murni
