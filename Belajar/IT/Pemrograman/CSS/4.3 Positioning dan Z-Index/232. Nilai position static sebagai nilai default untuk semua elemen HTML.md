# Nilai position static sebagai nilai default untuk semua elemen HTML

## Analogi: Perpustakaan Digital

`position: static` adalah cara default buku ditempatkan di rak—mengikuti aliran normal dari kiri ke kanan, atas ke bawah, tanpa ada perilaku khusus. Sebagian besar buku di perpustakaan berada dalam mode ini: mereka mengikuti urutan normal, saling mendorong, dan tidak bisa diatur posisinya secara manual. Ini adalah keadaan alami setiap elemen HTML sebelum kamu mengubahnya.

## Penjelasan Detail

`position: static` adalah nilai default untuk semua elemen HTML. Elemen dengan `position: static` mengikuti aliran dokumen normal (normal flow). Properti offset `top`, `right`, `bottom`, `left` tidak berpengaruh pada elemen static. Demikian juga `z-index` tidak berfungsi. Elemen static tidak bisa menjadi reference point untuk elemen absolute child. Sebagian besar elemen di halaman web menggunakan `position: static` dan tidak memerlukan perubahan. Kamu hanya perlu mengubah position ketika membutuhkan perilaku penempatan khusus seperti relative, absolute, fixed, atau sticky.

## Contoh Kode Implementasi

```css
.static-element {
  position: static;
  background: #f5f5f5;
  padding: 16px;
  margin: 8px 0;
  border: 1px solid #ddd;
  border-radius: 4px;
}

/* top: 20px tidak akan berpengaruh karena position: static */
.static-element {
  top: 20px;
  left: 30px;
}

.container {
  border: 2px solid #333;
  padding: 8px;
}

.item {
  background: #9E9E9E;
  color: white;
  padding: 12px;
  margin: 4px;
}
```

## Poin Penting
- `static` adalah nilai default position untuk semua elemen HTML
- Elemen static mengikuti aliran dokumen normal
- Properti offset (top, right, bottom, left) tidak berpengaruh
- `z-index` tidak berfungsi pada elemen static
- Tidak bisa menjadi reference point untuk elemen absolute child
