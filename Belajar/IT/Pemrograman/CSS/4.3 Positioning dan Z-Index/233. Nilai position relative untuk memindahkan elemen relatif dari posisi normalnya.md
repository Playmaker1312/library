# Nilai position relative untuk memindahkan elemen relatif dari posisi normalnya

## Analogi: Perpustakaan Digital

Bayangkan sebuah buku yang digeser sedikit ke kanan dari posisi aslinya di rak, tetapi tempat aslinya tetap dianggap "ditempati" sehingga buku lain tidak bisa mengambilnya. Buku tersebut bergerak relatif terhadap posisi normalnya, dan ruang kosong yang ditinggalkannya tetap ada. Inilah cara kerja `position: relative`—elemen bergeser dari posisi normalnya tanpa memengaruhi elemen di sekitarnya.

## Penjelasan Detail

`position: relative` memindahkan elemen relatif terhadap posisi normalnya dalam aliran dokumen. Elemen tetap berada dalam aliran dokumen—ruang aslinya tetap dipertahankan (tidak collapse). Properti `top`, `right`, `bottom`, `left` kemudian menggeser elemen dari posisi normalnya. Nilai positif `top` menggeser ke bawah, `left` menggeser ke kanan, dst. Selain untuk menggeser elemen, `position: relative` juga berfungsi sebagai reference point untuk elemen child dengan `position: absolute`. Ini adalah penggunaan paling umum: mengatur `position: relative` pada container agar anak absolute diposisikan relatif terhadap container tersebut.

## Contoh Kode Implementasi

```css
.container {
  position: relative;
  border: 2px solid #333;
  padding: 24px;
  min-height: 100px;
  margin-top: 20px;
}

.normal-box {
  background: #e0e0e0;
  padding: 12px;
  margin: 4px 0;
}

.shifted-box {
  position: relative;
  top: 16px;
  left: 24px;
  background: #FF9800;
  color: white;
  padding: 12px;
}

.absolute-child {
  position: absolute;
  top: 0;
  right: 0;
  background: #F44336;
  color: white;
  padding: 8px 12px;
  font-size: 12px;
}
```

## Poin Penting
- `position: relative` menggeser elemen dari posisi normalnya
- Ruang asli elemen tetap dipertahankan dalam aliran dokumen
- Properti offset (top, right, bottom, left) mengontrol pergeseran
- Berfungsi sebagai reference point untuk elemen absolute child
- Penggunaan paling umum: sebagai container untuk positioning absolute
