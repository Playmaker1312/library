# Nilai position fixed untuk menempelkan elemen pada posisi tetap di viewport

## Analogi: Perpustakaan Digital

Bayangkan peta perpustakaan yang selalu terlihat di pojok kanan bawah layar, tidak peduli seberapa jauh kamu scroll atau halaman mana yang kamu buka. Peta ini "menempel" pada jendela browser (viewport) dan tidak bergerak saat halaman di-scroll. Ini adalah perilaku `position: fixed`—elemen tetap pada posisi yang sama di layar meskipun dokumen di-scroll.

## Penjelasan Detail

`position: fixed` mirip dengan `absolute` dalam hal elemen dikeluarkan dari aliran dokumen, tetapi perbedaan utamanya adalah elemen diposisikan relatif terhadap viewport (jendela browser), bukan relatif terhadap ancestor. Elemen fixed tetap berada di posisi yang sama ketika halaman di-scroll. Ini sangat berguna untuk header navigasi tetap, tombol kembali ke atas, cookie consent bar, atau overlay modal. Karena elemen fixed tidak bergerak saat scroll, perlu diperhatikan agar tidak menutupi konten penting. Properti `top`, `right`, `bottom`, `left` menentukan posisi relatif terhadap viewport.

## Contoh Kode Implementasi

```css
.fixed-header {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  height: 60px;
  background: #2c3e50;
  color: white;
  display: flex;
  align-items: center;
  padding: 0 24px;
  z-index: 100;
  box-shadow: 0 2px 8px rgba(0,0,0,0.15);
}

.fixed-back-to-top {
  position: fixed;
  bottom: 24px;
  right: 24px;
  width: 48px;
  height: 48px;
  background: #2196F3;
  color: white;
  border-radius: 50%;
  display: flex;
  align-items: center;
  justify-content: center;
  cursor: pointer;
  box-shadow: 0 2px 8px rgba(0,0,0,0.2);
  z-index: 50;
}

.fixed-footer-bar {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  background: #4CAF50;
  color: white;
  padding: 12px 24px;
  text-align: center;
  z-index: 100;
}

body {
  padding-top: 60px;
  padding-bottom: 60px;
}
```

## Poin Penting
- `position: fixed` menempelkan elemen pada posisi tetap di viewport
- Elemen tidak bergerak saat halaman di-scroll
- Dikeluarkan dari aliran dokumen (seperti absolute)
- Diposisikan relatif terhadap viewport, bukan ancestor
- Tambahkan padding pada body agar konten tidak tertutup elemen fixed
