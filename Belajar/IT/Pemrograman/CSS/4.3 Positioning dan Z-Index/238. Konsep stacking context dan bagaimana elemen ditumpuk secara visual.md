# Konsep stacking context dan bagaimana elemen ditumpuk secara visual

## Analogi: Perpustakaan Digital

Bayangkan berbagai lapisan kertas transparan yang ditumpuk di atas meja. Setiap lapisan bisa berisi catatan, gambar, atau informasi. Lapisan yang lebih atas akan menutupi lapisan di bawahnya. Dalam CSS, setiap tumpukan lapisan ini disebut "stacking context". Elemen-elemen dalam stacking context yang sama ditumpuk berdasarkan aturan tertentu: latar belakang, elemen dengan z-index negatif, elemen dalam aliran normal, elemen float, dan terakhir elemen dengan z-index positif.

## Penjelasan Detail

Stacking context adalah konsep tiga dimensi dalam CSS yang menentukan bagaimana elemen-elemen ditumpuk secara visual di atas satu sama lain. Setiap stacking context memiliki akar (root element atau elemen yang memicunya). Di dalam setiap stacking context, anak-anak ditumpuk dalam urutan tertentu: (1) background dan border dari elemen yang membentuk context, (2) stacking context dengan z-index negatif, (3) elemen in-flow, inline, dan float, (4) elemen dengan z-index 0 atau auto, (5) elemen dengan z-index positif. Elemen dengan stacking context yang berbeda tidak bisa dicampur z-index-nya—z-index hanya berarti dalam stacking context yang sama.

## Contoh Kode Implementasi

```css
.card {
  position: relative;
  background: white;
  border: 2px solid #ddd;
  border-radius: 8px;
  padding: 20px;
  margin: 20px 0;
}

.card-badge {
  position: absolute;
  top: -8px;
  left: -8px;
  background: #F44336;
  color: white;
  padding: 4px 12px;
  border-radius: 12px;
  font-size: 12px;
  z-index: 2;
}

.card-overlay {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background: rgba(0,0,0,0.5);
  color: white;
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: 1;
  border-radius: 8px;
}
```

## Poin Penting
- Stacking context menentukan urutan tumpukan elemen secara visual
- Setiap stacking context memiliki urutan tumpukan internal sendiri
- z-index hanya bermakna dalam stacking context yang sama
- Elemen dari stacking context berbeda tidak bisa diatur tumpukannya dengan z-index
- Berbagai properti bisa memicu stacking context baru (position, opacity, transform, dll)
