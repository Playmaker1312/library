# 25. visibility & opacity — Tersembunyi Tapi Tetap Ada

## Penjelasan

Tiga cara "menyembunyikan" elemen:

| Properti | Efek | Layout | Interaksi |
|----------|------|--------|-----------|
| `display: none` | Hilang total | Dihapus | Tidak bisa |
| `visibility: hidden` | Tidak terlihat | Tetap ada | Tidak bisa |
| `opacity: 0` | Transparan | Tetap ada | **Bisa** (diklik!) |

```css
.hidden-display { display: none; }        /* hilang + layout hilang */
.hidden-visibility { visibility: hidden; } /* hilang + layout tetap */
.hidden-opacity { opacity: 0; }            /* transparan + layout tetap + bisa diklik */
```

## Fungsi

- Menampilkan/menyembunyikan elemen berdasarkan interaksi
- Animasi transisi (opacity untuk fade in/out)
- Menu dropdown, modal, tooltip

## Cara Pengimplementasian

```css
/* Display none — untuk hide/show dengan JS atau checkbox trick */
.mobile-menu { display: none; }
.menu-open .mobile-menu { display: block; }

/* Visibility — jarang digunakan sendiri */
.loading-text {
  visibility: hidden; /* placeholder tetap di layout */
}

/* Opacity — untuk animasi */
.fade-in {
  opacity: 0;
  transition: opacity 0.3s ease;
}

.fade-in.visible {
  opacity: 1;
}

/* Opacity untuk efek hover */
.card:hover .card-overlay {
  opacity: 1; /* dari 0 ke 1 */
}

/* Transition untuk smooth hide/show */
.element {
  opacity: 1;
  transition: opacity 0.3s ease;
}

.element.hidden {
  opacity: 0;
  pointer-events: none; /* matikan interaksi saat transparan */
}
```

## Analogi

- **`display: none`** = lemari dipindahkan ke ruangan lain — tidak ada di ruangan ini, tidak memakan tempat
- **`visibility: hidden`** = lemari ditutup kain putih — tetap di tempatnya, tapi tidak terlihat
- **`opacity:0`** = lemari kaca bening — terlihat transparan, masih bisa disentuh (dan nabrak jika tidak hati-hati)

## Dipakai Untuk Apa

- **display: none** — menu mobile (hidden/shown), tab content
- **visibility: hidden** — menjaga layout tetap stabil saat konten belum siap
- **opacity** — animasi fade in/out, overlay hover, modal backdrop

## Kesalahan Umum

- **Opacity 0 tapi masih interaktif**: elemen transparan masih bisa diklik — tambah `pointer-events: none`
- **Display none untuk animasi**: tidak bisa di-animasi (dari none ke block instan) — gunakan opacity + visibility
- **Visibility hidden untuk layout**: lebih baik gunakan opacity untuk transisi yang smooth

## Hubungan dengan Materi Sebelumnya

Poin 24: display mengontrol **aliran** elemen. Tapi kadang kita perlu **menyembunyikan** elemen — bukan mengubah aliran. `display:none` vs `visibility:hidden` vs `opacity:0` adalah tiga tingkat "sembunyi" dengan efek berbeda. Ini penting untuk komponen interaktif seperti menu dan modal.

## Soal Latihan

### Soal 1
Apa perbedaan `display: none` dan `visibility: hidden`?

**Jawaban:**
`display: none` menghilangkan elemen dari layout — tidak ada ruang, seolah tidak ada. `visibility: hidden` menyembunyikan elemen secara visual tapi ruangnya tetap dipertahankan.

### Soal 2
Mengapa `opacity: 0` bisa bermasalah untuk interaktivitas?

**Jawaban:** Elemen dengan `opacity: 0` tetap bisa diklik/diinteraksi karena masih ada di layout. Untuk mencegahnya, tambahkan `pointer-events: none`.

### Soal 3
Properti mana yang paling cocok untuk animasi fade?

**Jawaban:**
`opacity` — karena bisa di-transition/di-animasi dengan mulus. `display` tidak bisa di-animasi. `visibility` hanya transisi instan.
