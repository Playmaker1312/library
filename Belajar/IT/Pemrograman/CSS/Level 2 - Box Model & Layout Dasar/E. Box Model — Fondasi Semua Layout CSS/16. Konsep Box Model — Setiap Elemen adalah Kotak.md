# 16. Konsep Box Model — Setiap Elemen adalah Kotak

## Penjelasan

Setiap elemen HTML adalah kotak dengan 4 lapisan (dari dalam ke luar):

```
┌─────────────────────────────────┐
│          MARGIN (luar)          │
│  ┌─────────────────────────┐    │
│  │     BORDER (tepi)       │    │
│  │  ┌───────────────────┐  │    │
│  │  │   PADDING (dalam) │  │    │
│  │  │ ┌───────────────┐ │  │    │
│  │  │ │   CONTENT     │ │  │    │
│  │  │ │ (teks/gambar) │ │  │    │
│  │  │ └───────────────┘ │  │    │
│  │  └───────────────────┘  │    │
│  └─────────────────────────┘    │
└─────────────────────────────────┘
```

- **Content**: area konten (teks, gambar)
- **Padding**: ruang antara konten dan border (di dalam elemen)
- **Border**: garis tepi elemen
- **Margin**: ruang di luar border (jarak antar elemen)

## Fungsi

- Memahami bagaimana ukuran dan jarak elemen dihitung
- Dasar dari semua layout CSS — tanpa paham ini, spacing selalu trial-and-error
- Debugging layout di DevTools (lihat box model diagram)

## Cara Pengimplementasian

```css
.card {
  /* Content: 300px lebar */
  width: 300px;
  
  /* Padding: 20px di semua sisi — ruang antara konten dan border */
  padding: 20px;
  
  /* Border: garis 1px solid */
  border: 1px solid var(--color-border);
  
  /* Margin: 16px — jarak antar card */
  margin: 16px;
}
```

Visualisasikan di DevTools:
1. Klik kanan elemen → Inspect
2. Tab **Computed** atau **Styles**
3. Lihat **Box Model** diagram (biasanya di pojok kanan bawah panel Styles)

## Analogi

Box model seperti **bingkai foto di dinding rumah**:
- **Content** = foto itu sendiri
- **Padding** = jarak antara foto dengan tepi bingkai (matte/alas dalam)
- **Border** = bingkai kayu/plastik di sekeliling foto
- **Margin** = jarak antara bingkai foto dengan bingkai foto lain di dinding yang sama

Jika ingin foto lebih dekat ke bingkai → kurangi padding. Jika ingin jarak antar foto lebih jauh → tambah margin.

## Dipakai Untuk Apa

- Semua elemen HTML — setiap elemen adalah box model
- Mengatur jarak internal (padding) dan eksternal (margin)
- Mendefinisikan ukuran elemen (width/height + padding + border)

## Kesalahan Umum

- **Tidak paham box model → layout "ngaco"**: menambah padding 20px ke elemen 300px → total jadi 340px (tanpa border-box)
- **Padding vs margin tertukar**: padding untuk ruang di dalam (dorong border menjauh dari konten), margin untuk ruang di luar (dorong elemen lain)
- **Margin collapsing tidak disadari**: margin antar dua elemen vertikal tidak dijumlah, tapi diambil yang terbesar

## Hubungan dengan Materi Sebelumnya

Level 1: kita mengatur **warna dan teks** di dalam elemen. Tapi elemen tidak punya "ruang" yang terkontrol — padding, border, margin belum diatur. Box Model adalah **fondasi layout** — memahami ini membuat semua spacing ke depannya intuitif, bukan trial-and-error.

## Soal Latihan

### Soal 1
Sebutkan 4 lapisan box model dari dalam ke luar.

**Jawaban:**
Content → Padding → Border → Margin

### Soal 2
Jika sebuah elemen punya `width: 200px`, `padding: 20px`, `border: 2px`, berapa total lebar elemen dengan `box-sizing: content-box`?

**Jawaban:**
200 + 20×2 + 2×2 = **244px** (content 200 + padding kiri 20 + padding kanan 20 + border kiri 2 + border kanan 2).

### Soal 3
Di panel DevTools mana kita bisa melihat visualisasi box model?

**Jawaban:**
Di panel **Styles** (biasanya di bagian bawah, ada diagram Box Model) atau di **Computed** tab, ada juga diagram box model interaktif.
