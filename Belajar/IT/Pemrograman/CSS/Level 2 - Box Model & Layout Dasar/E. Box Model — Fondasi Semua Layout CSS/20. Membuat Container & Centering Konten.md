# 20. Membuat Container & Centering Konten

## Penjelasan

Container adalah elemen yang **membatasi lebar konten** agar tidak terlalu lebar di layar besar (monitor 27"). Tanpa container, teks akan membentang dari ujung kiri ke kanan — sangat tidak nyaman dibaca.

```css
/* Container klasik */
.container {
  width: 100%;
  max-width: 1200px;   /* tidak lebih lebar dari 1200px */
  margin-left: auto;    /* dorong ke kanan */
  margin-right: auto;   /* dorong ke kiri */
  /* Keduanya auto → elemen di tengah */
  padding-inline: 24px; /* ruang di kiri-kanan saat layar kecil */
}

/* Container modern dengan CSS min() */
.container {
  width: min(100% - 48px, 1200px);
  /* Lebar = 1200px max, tapi jika layar kecil = 100% - 48px */
  margin-inline: auto;
}
```

## Fungsi

- Membatasi lebar konten agar nyaman dibaca
- Memusatkan konten di tengah halaman
- Memberi padding konsisten di kiri-kanan

## Cara Pengimplementasian

```css
/* Di CSS */
:root {
  --container-max-width: 1200px;
  --container-padding: var(--space-6);
}

.container {
  width: 100%;
  max-width: var(--container-max-width);
  margin-inline: auto;
  padding-inline: var(--container-padding);
}

/* Variasi: container kecil untuk artikel */
.container--narrow {
  max-width: 720px;
}

/* Variasi: container penuh (full width) */
.container--fluid {
  max-width: none;
}
```

```html
<!-- Di HTML -->
<main>
  <div class="container">
    <h1>Selamat Datang</h1>
    <p>Ini konten yang terpusat dan terbaca nyaman.</p>
  </div>
</main>

<!-- Container kecil untuk artikel -->
<article class="container container--narrow">
  <h2>Judul Artikel</h2>
  <p>Artikel panjang dengan lebar terbatas untuk kenyamanan baca.</p>
</article>
```

## Analogi

Container seperti **pagar pembatas di lorong rumah**. Tanpa pagar (container), orang bisa berjalan ke mana saja — lorong terasa terlalu lebar dan tidak terarah. Dengan pagar di kiri-kanan (max-width + margin auto), orang berjalan di tengah dengan nyaman.

Di rumah yang sangat lebar (layar 27"), pagar mencegah orang berjalan terlalu jauh ke kiri/kanan. Di lorong sempit (layar HP), pagar menyempit mengikuti dinding.

## Dipakai Untuk Apa

- **Setiap halaman**: bungkus konten utama dengan `.container`
- **Artikel**: `.container--narrow` dengan max-width lebih kecil (720px)
- **Hero section**: kadang full-width tanpa container, tapi teks di dalamnya pakai container

## Kesalahan Umum

- **Tidak pakai container**: konten membentang penuh di layar lebar — tidak nyaman dibaca
- **Container di dalam container**: container bersarang — tidak masalah asal tidak double padding
- **Padding container tidak responsif**: di mobile padding harus cukup (16-24px) agar konten tidak nempel tepi
- **Container tanpa max-width**: `width: 100%` + `margin: auto` tidak akan centering tanpa max-width

## Hubungan dengan Materi Sebelumnya

Poin 18-19: padding dan margin sudah dipahami. Container menggunakan keduanya: `padding-inline` (padding) untuk ruang kiri-kanan, `margin-inline: auto` (margin) untuk centering. Container adalah **fondasi layout** — semua konten akan dibungkus dengan ini.

## Soal Latihan

### Soal 1
Tulis CSS untuk container dengan max-width 1200px, centered, dan padding 24px di kiri-kanan.

**Jawaban:**
```css
.container {
  max-width: 1200px;
  margin-inline: auto;
  padding-inline: 24px;
}
```

### Soal 2
Apa fungsi `margin-inline: auto` pada container?

**Jawaban:**
Membagi sisa ruang secara merata di kiri dan kanan elemen — elemen berada di tengah secara horizontal. Sama dengan `margin-left: auto; margin-right: auto`.

### Soal 3
Mengapa artikel lebih nyaman dibaca dengan container narrow (max-width 720px)?

**Jawaban:**
Garis teks yang terlalu panjang (100+ karakter per baris) melelahkan mata. 720px menghasilkan sekitar 60-75 karakter per baris — panjang ideal untuk kenyamanan baca menurut riset tipografi.
