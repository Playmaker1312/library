# Nilai display block untuk elemen yang mengambil seluruh lebar baris

## Analogi: Perpustakaan Digital

Bayangkan sebuah buku besar di perpustakaan yang ditempatkan di rak tersendiri, mengambil seluruh lebar rak. Elemen block seperti buku yang memonopoli satu baris penuh, tidak ada buku lain yang bisa ditempatkan di sampingnya dalam baris yang sama. Setiap elemen block memulai baris baru dan meregang dari kiri ke kanan selebar mungkin.

## Penjelasan Detail

Elemen dengan display block memiliki karakteristik: memulai baris baru, mengambil seluruh lebar yang tersedia (lebar 100% dari induknya), dan dapat diatur width dan height-nya. Elemen block default meliputi div, p, h1-h6, section, article, header, footer, ul, ol, li, dan form. Ketika display diubah ke block, elemen akan berperilaku seperti elemen block meskipun awalnya inline. Elemen block dapat memiliki margin dan padding yang berfungsi penuh di semua sisi. Elemen block juga mengalami margin collapsing vertikal. Block adalah nilai display yang paling umum untuk komponen layout halaman web.

## Contoh Kode Implementasi

```css
/* Elemen block default */
.block-default {
  background: #3498db;
  color: white;
  padding: 15px;
  margin-bottom: 10px;
}

/* Mengubah inline menjadi block */
span {
  display: block;
  background: #e74c3c;
  color: white;
  padding: 10px;
  margin: 5px 0;
}

/* Link sebagai block */
a.block-link {
  display: block;
  padding: 12px 20px;
  background: #2ecc71;
  color: white;
  text-decoration: none;
  margin-bottom: 5px;
}

a.block-link:hover {
  background: #27ae60;
}

/* Block dengan width terbatas */
.block-fixed {
  display: block;
  width: 400px;
  margin: 0 auto 10px;
  background: #f39c12;
  color: white;
  padding: 15px;
}

/* Block memenuhi induk */
.parent {
  width: 600px;
  background: #f0f0f0;
  padding: 10px;
}

.child-block {
  display: block; /* default untuk div */
  background: #9b59b6;
  color: white;
  padding: 10px;
  margin: 5px 0;
}

/* Heading adalah block */
h1, h2, h3 {
  display: block;
  margin-bottom: 0.5em;
}

/* Button sebagai block */
button.block-btn {
  display: block;
  width: 100%;
  padding: 15px;
  margin-bottom: 10px;
}
```

## Poin Penting
- Elemen block memulai baris baru dan mengambil seluruh lebar yang tersedia dari elemen induk
- Elemen block dapat diatur width dan height serta memiliki margin dan padding yang berfungsi penuh
- Elemen inline dapat diubah menjadi block dengan display: block
- Elemen block default termasuk div, p, heading, section, dan elemen struktural lainnya
