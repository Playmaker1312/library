# Nilai display none untuk menyembunyikan elemen sepenuhnya dari halaman

## Analogi: Perpustakaan Digital

Seperti buku yang dikeluarkan dari rak dan disimpan di gudang, display none menghilangkan elemen sepenuhnya dari halaman web. Elemen tidak terlihat dan tidak mempengaruhi tata letak sama sekali, seolah-olah tidak pernah ada dalam dokumen. Berbeda dengan buku yang hanya ditutupi kain, display none benar-benar menghapus elemen dari aliran visual.

## Penjelasan Detail

Display none menyembunyikan elemen sepenuhnya dari halaman. Elemen tidak dirender, tidak terlihat, dan tidak mempengaruhi tata letak elemen lain. Ruang yang sebelumnya ditempati elemen akan diisi oleh elemen lain. Elemen dengan display none tidak dapat difokuskan, tidak dapat diklik, dan tidak dapat diakses oleh pembaca layar (screen reader). Untuk menyembunyikan elemen secara visual tetapi tetap mempertahankan ruangnya, gunakan visibility: hidden. Untuk menyembunyikan elemen secara visual tetapi tetap dapat diakses oleh screen reader, gunakan teknik accessible hiding. Display none sering digunakan dalam tab panel, dropdown menu, modal, dan komponen yang membutuhkan toggle visibility.

## Contoh Kode Implementasi

```css
/* Menyembunyikan elemen */
.hidden {
  display: none;
}

/* Toggle visibility dengan class */
.modal {
  display: none;
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: rgba(0,0,0,0.5);
}

.modal.active {
  display: block;
}

/* Dropdown menu */
.dropdown-menu {
  display: none;
  position: absolute;
  top: 100%;
  left: 0;
  background: white;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

.dropdown:hover .dropdown-menu {
  display: block;
}

/* Tab panel */
.tab-content {
  display: none;
}

.tab-content.active {
  display: block;
}

/* Mobile navigation */
.mobile-nav {
  display: none;
}

@media (max-width: 768px) {
  .mobile-nav {
    display: block;
  }
  .desktop-nav {
    display: none;
  }
}

/* Loading state */
.loading-spinner {
  display: none;
}

.loading .loading-spinner {
  display: inline-block;
}

/* Accessible hiding (visually hidden but accessible) */
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}
```

## Poin Penting
- display: none menghilangkan elemen sepenuhnya dari halaman dan aliran dokumen
- Elemen dengan display none tidak dapat diakses oleh screen reader
- Gunakan visibility: hidden jika ingin menyembunyikan elemen tetapi mempertahankan ruangnya
- Untuk aksesibilitas, gunakan teknik sr-only jika ingin menyembunyikan secara visual tetapi tetap dapat dibaca screen reader
