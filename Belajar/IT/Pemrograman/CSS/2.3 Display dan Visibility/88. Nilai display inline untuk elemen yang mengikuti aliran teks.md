# Nilai display inline untuk elemen yang mengikuti aliran teks

## Analogi: Perpustakaan Digital

Bayangkan kata-kata dalam kalimat di halaman buku. Setiap kata mengalir dari kiri ke kanan, dan ketika sampai di ujung halaman, kata berlanjut ke baris berikutnya. Elemen inline seperti kata-kata dalam buku: mereka tidak memulai baris baru, hanya mengambil ruang sesuai kontennya, dan mengalir bersama teks di sekitarnya.

## Penjelasan Detail

Elemen dengan display inline memiliki karakteristik: tidak memulai baris baru, hanya mengambil lebar dan tinggi sesuai kontennya, tidak dapat diatur width dan height (diabaikan), margin dan padding hanya berfungsi horizontal (kiri/kanan), dan mengalir dalam aliran teks. Elemen inline default meliputi span, a, strong, em, b, i, u, label, dan img (meskipun img adalah replaced inline element). Elemen inline cocok untuk memformat bagian dari teks tanpa mengganggu aliran. Elemen inline dapat diubah menjadi block atau inline-block jika perlu akses ke properti dimensi. Inline-block sering menjadi solusi ketika ingin elemen mengalir seperti inline tetapi dapat diatur dimensinya.

## Contoh Kode Implementasi

```css
/* Elemen inline default */
span {
  color: #e74c3c;
  font-weight: bold;
}

/* Link inline */
a {
  color: #3498db;
  text-decoration: underline;
  padding: 2px 4px; /* padding horizontal berfungsi */
}

/* Padding horizontal berfungsi, vertikal tidak */
.inline-padding {
  padding: 20px; /* hanya kiri/kanan yang mempengaruhi layout */
  background: #f0f0f0; /* background terlihat di padding */
}

/* Elemen inline tidak terpengaruh width/height */
.inline-dimension {
  display: inline;
  width: 300px; /* diabaikan */
  height: 100px; /* diabaikan */
  background: #3498db;
  color: white;
}

/* Multiple inline elements dalam satu baris */
.inline-group {
  background: #f8f9fa;
  padding: 10px;
}

.inline-group span {
  background: #3498db;
  color: white;
  padding: 5px 10px;
  margin: 0 5px; /* margin horizontal berfungsi */
}

/* Inline dengan vertical-align */
.inline-align {
  vertical-align: middle;
  display: inline;
}

/* Strong dan em adalah inline */
strong {
  color: #2c3e50;
}

em {
  color: #7f8c8d;
  font-style: italic;
}

/* Label inline dengan input */
label {
  display: inline;
  margin-right: 10px;
}
```

## Poin Penting
- Elemen inline tidak memulai baris baru dan hanya mengambil ruang sesuai kontennya
- width dan height tidak berpengaruh pada elemen inline; gunakan inline-block jika perlu dimensi
- Margin dan padding horizontal berfungsi; vertikal tidak mempengaruhi layout
- Elemen inline default termasuk span, a, strong, em, dan label
