# Nilai display list-item untuk menampilkan elemen seperti item daftar

## Analogi: Perpustakaan Digital

Bayangkan daftar buku di katalog perpustakaan, di mana setiap entri memiliki bullet point atau nomor di depannya. Display list-item membuat elemen berperilaku seperti item dalam daftar, lengkap dengan marker di sampingnya. Ini seperti mengubah bagian mana pun dari halaman web menjadi entri katalog yang terstruktur.

## Penjelasan Detail

Display list-item membuat elemen berperilaku seperti elemen li dalam daftar HTML. Elemen akan menampilkan marker (bullet, angka, atau simbol) di depannya, dan secara default akan menjorok ke dalam. list-item adalah nilai display default untuk elemen li. Properti terkait termasuk list-style-type (mengatur jenis marker), list-style-position (posisi marker), dan list-style-image (gambar sebagai marker). Elemen dengan display list-item juga berperilaku seperti block dalam hal tata letak. Nilai ini jarang digunakan secara eksplisit karena biasanya elemen li sudah memiliki nilai ini secara default. Namun, berguna ketika ingin menambahkan perilaku daftar pada elemen non-li.

## Contoh Kode Implementasi

```css
/* Elemen div sebagai list-item */
.div-as-list-item {
  display: list-item;
  list-style-type: disc;
  margin-left: 20px;
  padding: 5px;
}

/* List-style-type berbeda */
.list-circle {
  display: list-item;
  list-style-type: circle;
  margin-left: 30px;
}

.list-square {
  display: list-item;
  list-style-type: square;
  margin-left: 30px;
}

.list-decimal {
  display: list-item;
  list-style-type: decimal;
  margin-left: 30px;
}

.list-roman {
  display: list-item;
  list-style-type: upper-roman;
  margin-left: 30px;
}

.list-alpha {
  display: list-item;
  list-style-type: lower-alpha;
  margin-left: 30px;
}

/* List-style-position */
.list-inside {
  display: list-item;
  list-style-type: disc;
  list-style-position: inside;
  background: #f0f0f0;
  margin: 5px 0;
  padding: 10px;
}

.list-outside {
  display: list-item;
  list-style-type: disc;
  list-style-position: outside;
  background: #f0f0f0;
  margin: 5px 0;
  padding: 10px;
  margin-left: 20px;
}

/* List-style-image */
.custom-list {
  display: list-item;
  list-style-image: url('bullet.png');
  margin-left: 25px;
}

/* Reset list */
.no-marker {
  display: list-item;
  list-style: none;
  /* marker dihilangkan tapi indentasi tetap */
}

/* Mengubah li default */
li {
  display: list-item; /* default */
  list-style-type: square;
  margin-bottom: 5px;
}

/* Span sebagai list-item */
span.list-item {
  display: list-item;
  list-style-type: disc;
  margin-left: 20px;
}

/* Daftar dengan ikon custom */
.custom-bullet {
  display: list-item;
  list-style: none;
  position: relative;
  padding-left: 25px;
}

.custom-bullet::marker {
  content: "\2605"; /* bintang */
  color: #f39c12;
}
```

## Poin Penting
- Display list-item menampilkan elemen dengan marker di depan, seperti elemen li dalam daftar
- Properti list-style-type, list-style-position, dan list-style-image mengontrol tampilan marker
- list-item berguna untuk memberikan perilaku daftar pada elemen non-li
- list-style: none dapat digunakan untuk menghilangkan marker sambil mempertahankan indentasi
