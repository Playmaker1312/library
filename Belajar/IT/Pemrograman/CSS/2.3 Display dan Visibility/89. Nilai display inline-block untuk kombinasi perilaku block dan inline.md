# Nilai display inline-block untuk kombinasi perilaku block dan inline

## Analogi: Perpustakaan Digital

Bayangkan rak display buku kecil yang bisa ditempatkan bersebelahan dalam satu baris (seperti inline), tetapi setiap rak memiliki lebar dan tinggi tetap yang bisa diatur (seperti block). Inline-block adalah hybrid: elemen mengalir dalam baris seperti inline, tetapi dapat diatur dimensi dan margin/padding vertikal seperti block. Ini seperti buku-buku pajangan yang diletakkan berjajar namun setiap buku memiliki ukuran yang tetap.

## Penjelasan Detail

Display inline-block menggabungkan kelebihan inline dan block. Seperti inline, elemen tidak memulai baris baru dan mengalir bersama elemen lain dalam baris yang sama. Seperti block, elemen dapat diatur width, height, margin (termasuk vertikal), dan padding (termasuk vertikal). Inline-block sangat berguna untuk membuat grid navigasi horizontal, tombol, kartu dalam baris, dan komponen yang memerlukan kedua sifat tersebut. Berbeda dengan float, inline-block tidak mengeluarkan elemen dari aliran dokumen. Inline-block memiliki gap spasi antar elemen karena whitespace dalam HTML, yang dapat diatasi dengan menghapus spasi atau menggunakan font-size 0 pada induk.

## Contoh Kode Implementasi

```css
/* Inline-block dasar */
.inline-block-item {
  display: inline-block;
  width: 150px;
  height: 100px;
  background: #3498db;
  color: white;
  margin: 10px;
  padding: 15px;
  text-align: center;
}

/* Navigasi horizontal dengan inline-block */
.nav-item {
  display: inline-block;
  padding: 12px 24px;
  background: #2c3e50;
  color: white;
  text-decoration: none;
}

.nav-item:hover {
  background: #34495e;
}

/* Grid sederhana dengan inline-block */
.grid-box {
  display: inline-block;
  width: 30%;
  margin: 1.5%;
  padding: 20px;
  background: #f8f9fa;
  border: 1px solid #ddd;
  vertical-align: top;
}

/* Button grup */
.btn-group {
  font-size: 0; /* menghilangkan gap */
}

.btn {
  display: inline-block;
  padding: 12px 24px;
  background: #3498db;
  color: white;
  border: none;
  font-size: 16px;
}

.btn + .btn {
  margin-left: -1px; /* mengatasi border ganda */
}

/* Kartu produk */
.product-card {
  display: inline-block;
  width: 220px;
  margin: 10px;
  padding: 15px;
  border: 1px solid #ddd;
  border-radius: 8px;
  vertical-align: top;
}

/* Form elements inline */
.form-group {
  display: inline-block;
  margin-right: 15px;
}

.form-group label {
  display: block;
  margin-bottom: 5px;
}

/* Inline-block dengan text-align center pada parent */
.parent-center {
  text-align: center;
}

.center-item {
  display: inline-block;
  text-align: left;
}
```

## Poin Penting
- Inline-block mengalir seperti inline (tidak memulai baris baru) tetapi dapat diatur dimensi seperti block
- Margin dan padding vertikal berfungsi penuh pada inline-block, berbeda dengan inline
- Terdapat whitespace gap antar elemen inline-block yang perlu diatasi secara khusus
- Gunakan vertical-align untuk mengatur perataan vertikal elemen inline-block
