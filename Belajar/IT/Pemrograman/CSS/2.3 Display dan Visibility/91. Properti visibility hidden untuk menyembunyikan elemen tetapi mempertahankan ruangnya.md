# Properti visibility hidden untuk menyembunyikan elemen tetapi mempertahankan ruangnya

## Analogi: Perpustakaan Digital

Bayangkan buku yang ditutupi dengan kain transparan di rak: buku tersebut tidak terlihat, tetapi tempatnya tetap ada dan buku lain tidak bisa mengambil posisinya. Visibility hidden melakukan hal yang sama pada elemen web: elemen menjadi tidak terlihat tetapi ruang yang ditempatinya tetap dipertahankan dalam tata letak. Ini berbeda dengan display none yang benar-benar menghapus elemen.

## Penjelasan Detail

Properti visibility mengontrol visibilitas elemen. Nilai hidden membuat elemen tidak terlihat tetapi tetap mempertahankan ruang dan posisinya dalam tata letak. Area elemen tetap kosong dan mempengaruhi elemen di sekitarnya. Elemen dengan visibility hidden masih dapat difokuskan (dengan tabindex) dan masih ada dalam DOM. visibility hidden tidak memicu event mouse atau klik pada elemen itu sendiri, tetapi dapat ditarget oleh JavaScript. Berbeda dengan display none, visibility hidden tetap dirender oleh browser tetapi tidak ditampilkan. Properti ini dapat diwarisi oleh elemen anak, tetapi anak dapat di-override dengan visibility: visible.

## Contoh Kode Implementasi

```css
/* Menyembunyikan elemen tetapi mempertahankan ruang */
.invisible {
  visibility: hidden;
  border: 2px dashed #ccc; /* border tetap terlihat sebagai indikasi ruang */
}

/* Perbandingan display none vs visibility hidden */
.compare-container {
  display: flex;
  gap: 20px;
}

.none-example {
  display: none;
  background: #e74c3c;
  padding: 20px;
  color: white;
}

.hidden-example {
  visibility: hidden;
  background: #3498db;
  padding: 20px;
  color: white;
}

/* Toggle visibility */
.content {
  visibility: visible;
}

.content.collapsed {
  visibility: hidden;
}

/* Override visibility pada anak */
.parent-hidden {
  visibility: hidden;
}

.parent-hidden .child-visible {
  visibility: visible; /* anak tetap terlihat */
  background: #2ecc71;
  padding: 10px;
  color: white;
}

/* Loading placeholder */
.placeholder {
  visibility: hidden;
  width: 200px;
  height: 200px;
  background: #f0f0f0;
}

/* Spacing preservation - layout tidak berubah */
.layout-demo {
  width: 300px;
}

.layout-demo .box {
  padding: 20px;
  margin: 10px 0;
  background: #f39c12;
  color: white;
}

.layout-demo .box.hidden-visibility {
  visibility: hidden;
  /* Ruang 20px padding + 10px margin tetap ada */
}

/* Hanya menyembunyikan teks */
.hide-text {
  visibility: hidden;
}
```

## Poin Penting
- visibility: hidden menyembunyikan elemen secara visual tetapi mempertahankan ruang dan posisinya
- Berbeda dengan display: none yang menghapus elemen dari aliran dokumen
- Elemen visibility hidden masih mempengaruhi tata letak dan dapat diakses oleh JavaScript
- Anak dari elemen visibility hidden dapat diatur menjadi visibility: visible untuk ditampilkan
