# Properti opacity untuk mengatur transparansi elemen dari 0 hingga 1

## Analogi: Perpustakaan Digital

Seperti kaca buram di perpustakaan yang bisa diatur tingkat transparansinya, opacity mengontrol seberapa tembus pandang suatu elemen. Kaca yang jernih (opacity 1) memperlihatkan buku di belakangnya dengan jelas, sedangkan kaca yang buram (opacity mendekati 0) hampir tidak terlihat. Dalam perpustakaan digital, opacity memungkinkan kita membuat elemen tampak memudar atau menyatu dengan latar belakang.

## Penjelasan Detail

Properti opacity mengatur tingkat transparansi elemen. Nilai berkisar dari 0 (sepenuhnya transparan) hingga 1 (sepenuhnya buram). Nilai seperti 0.5 berarti 50% transparan. Opacity mempengaruhi seluruh elemen termasuk konten dan anak-anaknya. Ketika opacity diterapkan, semua elemen anak juga menjadi transparan, dan tidak dapat di-override. Berbeda dengan rgba() yang hanya mempengaruhi warna latar belakang, opacity mempengaruhi seluruh elemen termasuk teks, border, dan gambar. Opacity dapat dianimasikan dan sering digunakan untuk efek fade in/out, hover effects, dan overlay. Opacity juga mempengaruhi stack context elemen.

## Contoh Kode Implementasi

```css
/* Opacity penuh */
.fully-opaque {
  opacity: 1;
  background: #3498db;
  color: white;
  padding: 20px;
}

/* Setengah transparan */
.half-transparent {
  opacity: 0.5;
  background: #e74c3c;
  color: white;
  padding: 20px;
}

/* Hampir tidak terlihat */
.faint {
  opacity: 0.1;
  background: #2ecc71;
  color: white;
  padding: 20px;
}

/* Hover effect */
.fade-hover {
  background: #3498db;
  color: white;
  padding: 20px;
  transition: opacity 0.3s ease;
}

.fade-hover:hover {
  opacity: 0.7;
}

/* Opacity mempengaruhi anak */
.parent-opacity {
  opacity: 0.6;
  background: #f39c12;
  padding: 20px;
  color: white;
}

.child-try-override {
  opacity: 1; /* tetap 0.6 karena terwarisi dari parent */
  background: #9b59b6;
  padding: 10px;
  margin: 5px 0;
}

/* Animasi fade in */
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

.fade-in {
  animation: fadeIn 0.5s ease-in;
}

/* Overlay dengan opacity */
.overlay {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  background: rgba(0, 0, 0, 0.5);
  opacity: 0;
  visibility: hidden;
  transition: opacity 0.3s;
}

.overlay.active {
  opacity: 1;
  visibility: visible;
}

/* Disabled state */
button:disabled {
  opacity: 0.6;
  cursor: not-allowed;
}
```

## Poin Penting
- Nilai opacity dari 0 (transparan) hingga 1 (buram), dengan 0.5 sebagai setengah transparan
- Opacity mempengaruhi seluruh elemen termasuk konten dan anak-anaknya, tidak bisa di-override per anak
- Opacity dapat dianimasikan untuk efek fade in/fade out
- Berbeda dengan rgba/alpha channel yang hanya mempengaruhi satu properti, opacity mempengaruhi semua aspek elemen
