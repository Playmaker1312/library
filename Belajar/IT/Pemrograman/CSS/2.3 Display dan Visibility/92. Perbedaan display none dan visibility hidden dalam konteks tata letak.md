# Perbedaan display none dan visibility hidden dalam konteks tata letak

## Analogi: Perpustakaan Digital

Display none seperti buku yang dikeluarkan dari rak dan dibawa ke ruang penyimpanan: tidak terlihat dan raknya kosong untuk diisi buku lain. Visibility hidden seperti buku yang ditutupi kain: tidak terlihat tetapi posisinya di rak tetap ditempati. Dalam perpustakaan digital, memilih antara keduanya tergantung pada apakah kita ingin ruang elemen tetap dipertahankan atau tidak.

## Penjelasan Detail

Display none dan visibility hidden sama-sama menyembunyikan elemen, tetapi memiliki perbedaan fundamental. Display none menghapus elemen dari aliran dokumen: elemen tidak dirender, tidak mempengaruhi tata letak, dan ruangnya diisi elemen lain. Visibility hidden menyembunyikan elemen secara visual tetapi tetap mempertahankan ruangnya dalam tata letak. Display none tidak dapat di-override pada elemen anak, sedangkan visibility dapat. Display none menghemat resource rendering karena elemen tidak dirender sama sekali. Visibility hidden masih merender elemen tetapi tidak menampilkannya. Untuk animasi, visibility hidden dapat dianimasikan, display none tidak. Keduanya mempengaruhi aksesibilitas secara berbeda.

## Contoh Kode Implementasi

```css
/* Perbandingan visual */
.demo-container {
  display: flex;
  gap: 10px;
  align-items: flex-start;
}

.demo-box {
  padding: 20px;
  background: #3498db;
  color: white;
  margin: 5px;
}

.display-none {
  display: none;
  /* Elemen tidak ada, box lain akan mengisi ruangnya */
}

.visibility-hidden {
  visibility: hidden;
  /* Ruang tetap dipertahankan */
}

/* Efek pada tata letak */
.layout-parent {
  border: 2px solid #333;
  padding: 10px;
}

.layout-item {
  background: #e74c3c;
  color: white;
  padding: 15px;
  margin: 5px 0;
}

.layout-item.none {
  display: none;
  /* Item berikutnya naik menggantikan posisi */
}

.layout-item.hidden {
  visibility: hidden;
  /* Ruang kosong tetap ada */
}

/* Aksesibilitas */
.screen-reader-only {
  display: none;
  /* Tidak dibaca screen reader */
}

.visually-hidden {
  visibility: hidden;
  /* Mungkin masih dibaca tergantung implementasi */
}

/* Animasi */
@keyframes fadeIn {
  from { opacity: 0; visibility: hidden; }
  to { opacity: 1; visibility: visible; }
}

.fade-element {
  animation: fadeIn 0.3s ease;
}

/* Trigger events */
.event-none {
  display: none;
  /* Tidak dapat menerima focus/click */
}

.event-hidden {
  visibility: hidden;
  /* Tidak menerima event, tetapi ruangnya ada */
}

/* Penggunaan umum */
.dropdown-menu {
  display: none; /* default hidden */
}

.dropdown-menu.open {
  display: block; /* show */
}

.off-canvas {
  visibility: hidden; /* space preserved */
  transform: translateX(-100%);
  transition: all 0.3s;
}

.off-canvas.open {
  visibility: visible;
  transform: translateX(0);
}
```

## Poin Penting
- display none: elemen dihapus dari aliran dokumen, ruang tidak dipertahankan
- visibility hidden: elemen tidak terlihat tetapi ruangnya tetap dipertahankan
- display none menghemat resource rendering; visibility hidden tetap merender elemen
- Pilih display none untuk toggle container, visibility hidden untuk efek yang mempertahankan layout
