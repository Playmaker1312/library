# 232. Reusing Asset Flip Rotasi Modifikasi

## Definisi Singkat
Teknik menghemat waktu dan resource dengan menggunakan kembali asset yang sudah ada melalui flipping, rotasi, perubahan warna, atau modifikasi minor untuk menciptakan variasi baru.

## Analogi
Seperti lemari baju — Anda punya beberapa baju dasar yang bisa dikombinasikan dengan aksesoris berbeda untuk tampil beda setiap hari. Asset reuse adalah "mix and match" untuk pixel art.

## Poin-Poin Penting
- **Flip horizontal**: ubah arah karakter/enemy tanpa gambar ulang — cocok untuk walk cycle bolak-balik
- **Flip vertical**: jarang digunakan (bikin terlihat terbalik), kecuali untuk efek pantulan air
- **Rotasi 90°/180°**: untuk objek top-down, tileset, atau item pickup
- **Color swap / palette swap**: variasi enemy dengan warna berbeda — kekuatan api, es, cahaya
- **Size variation**: scale sprite dengan menjaga resolusi — tambah/sedikit modifikasi
- **Partial reuse**: ambil bagian tubuh, senjata, atau aksesoris dari karakter lain
- **Symmetry**: gambar setengah karakter, mirror untuk sisi lain — hemat 50% waktu

## Shortcut & Fitur Aseprite
- `Edit → Flip Horizontal` (`Ctrl+H`): flip sprite
- `Edit → Rotate 90° CW` (`Ctrl+R`): rotasi seleksi
- `Edit → Tint` (`Ctrl+Shift+T`): recolor cepat dengan tint
- Palette swap: buat palette alternatif → `Sprite → Replace Color`
- Symmetry tool: `View → Symmetry Options` — gambar otomatis mirror
- `Alt+C` copy cel → `Alt+V` paste ke frame lain

## Contoh Kasus Nyata (Step-by-Step)

### Variasi Enemy dengan Palette Swap
1. **Base enemy**: Goblin hijau (32x32, 4 frame walk cycle)
2. **Variant 1 (Fire)**: Palette swap — ubah hijau ke orange/merah, mata kuning
3. **Variant 2 (Ice)**: Palette swap — hijau ke cyan/biru, efek shard di belakang
4. **Variant 3 (Elite)**: Base goblin + tambah armor (partial reuse) + palette emas
5. **Hasil**: 4 enemy dari 1 base asset — hemat 75% waktu

### Flip Horizontal untuk Walk Cycle
1. Gambar karakter berjalan ke kanan (8 frame)
2. Duplikat semua frame → flip horizontal → dapat walk ke kiri
3. Jika ada asimetri (tameng di tangan kanan), perlu modifikasi minor

### Rotasi Tileset Top-Down
1. Gambar 1 tile jalan lurus (32x32)
2. Rotasi 90° untuk jalan horizontal
3. Rotasi 180° untuk jalan dari arah berlawanan
4. Kombinasikan untuk persimpangan — hanya 4 tile dari 1 base
