# 234. Draw Call Optimization Atlasing Texture Packing

## Definisi Singkat
Teknik mengoptimasi performa game dengan mengurangi jumlah draw call melalui atlasing (menggabungkan banyak sprite ke satu texture) dan texture packing (menyusun sprite efisien dalam atlas).

## Analogi
Bayangkan Anda harus mengirim 100 paket — akan lebih cepat jika 100 paket dimasukkan ke 1 kontainer besar (1x antar) daripada 100 paket dikirim satu-satu (100x antar). Draw call optimization adalah "satu kontainer" untuk GPU.

## Poin-Poin Penting
- **Draw call**: perintah dari CPU ke GPU untuk render objek — terlalu banyak = lag
- **Satu draw call per texture switch** — semua sprite dalam 1 texture = 1 draw call
- **Texture atlas**: satu gambar besar berisi semua sprite yang dibutuhkan
- **POT (Power of Two)**: 512x512, 1024x1024, 2048x2048 — GPU optimal dengan ukuran ini
- **Padding**: 1-4px antar sprite di atlas untuk mencegah texture bleeding
- **Group by usage**: sprite yang sering muncul bersamaan (level 1) dalam satu atlas
- **Separate atlas per scene**: jangan campur sprite level 1 dan level boss dalam 1 atlas
- **Sprite sheet vs atlas**: sheet untuk animasi, atlas untuk kumpulan sprite statis

## Shortcut & Fitur Aseprite
- `Ctrl+Shift+E` (Export Sprite Sheet): atur padding, trim, output size
- "Texture Packer" output: otomatis atur sprite ke grid
- "Best fit" algorithm: susun sprite otomatis minim ruang kosong
- "Rotate sprite" di export: putar sprite untuk fit lebih baik
- Export JSON data: Aseprite bisa export JSON dengan koordinat sprite di atlas

## Contoh Kasus Nyata (Step-by-Step)

### Texture Packing untuk Platformer
1. **Inventory**: 30 item sprite @16x16 = 256x256 atlas (dengan padding 2px)
2. **Level 1 assets**: player (64x64 x8 frame), enemy (32x32 x4 frame x3 varian), tile set (16x16 x20 tile), particle (8x8 x10) = 1024x1024 atlas
3. **Level 2 assets**: atlas terpisah (biarkan level 1 di-unload setelah selesai)
4. **Result**: 3 draw call per frame (player + tilemap, items, UI) — bukan 50+ draw call

### Tools Texture Packing Eksternal
1. Ekspor sprite individual dari Aseprite
2. Gunakan TexturePacker (tool) untuk otomatis pack
3. Import JSON + PNG ke game engine
4. Keuntungan: algoritma packing lebih canggih, padding otomatis, output multiple format

### Draw Call Budget per Platform
- Mobile: target <50 draw call per frame
- Desktop: target <200 draw call per frame
- Dengan atlasing: 1 atlas = 1 draw call (dengan batching)
