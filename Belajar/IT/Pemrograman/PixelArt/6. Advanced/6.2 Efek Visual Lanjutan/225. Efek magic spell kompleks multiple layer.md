# 225. Efek Magic Spell Kompleks Multiple Layer

## Definisi Singkat
Pembuatan efek sihir (magic spell) dengan multiple layer visual — aura, particle, beam, rune, glow — yang bekerja bersama membentuk satu serangan atau skill magis.

## Analogi
Seperti kembang api: ada percikan awal (cast), lintasan naik (projectile), ledakan (impact), dan percikan sisa (aftermath). Magic spell adalah kembang api yang bisa dikontrol karakter.

## Poin-Poin Penting
- **Layer composition**: cast effect → projectile/travel → hit/impact → aftermath/dissipate
- Setiap layer punya fungsi berbeda: glow (ambient), garis (arah), particle (detail), rune (tema)
- Warna konsisten per elemen/tema: api (merah-orange), es (biru-cyan), petir (kuning-putih), gelap (ungu-hitam)
- **Additive blending** penting untuk efek glow dan cahaya
- Multiple frame per fase: cast (4-6 frame), travel (8-12 frame), impact (6-8 frame), aftermath (8-12 frame)
- Gunakan **sparkle/star particle** untuk kilauan

## Shortcut & Fitur Aseprite
- Blending mode: set layer ke "Screen" atau "Add" untuk efek cahaya
- Gunakan layer glow: buat layer terpisah dengan opacity rendah
- `Ctrl+B` untuk bucket fill dengan warna glow transparan
- `Alt+R` untuk rotate selection — buat rune simetris
- Timeline tagging: tag fase "Cast", "Travel", "Impact", "Fade"
- Gunakan frame properties untuk atur durasi tiap frame (jika animasi per frame berbeda)

## Contoh Kasus Nyata (Step-by-Step)

### Fireball Spell (24 frame total)
1. **Cast (Frame 1-6)**: Tangan karakter mengumpulkan energi — lingkaran api kecil di telapak, 2 layer: rune (screen blending) dan glow (opacity 50%)
2. **Travel (Frame 7-14)**: Fireball terbang — 3 layer: inti putih terang, tengah orange, luar merah redup; tambah trailing particle
3. **Impact (Frame 15-20)**: Fireball meledak — lingkaran ekspansi, debris api, flash putih di frame 15-16 saja
4. **Aftermath (Frame 21-24)**: Sisa api mengecil, asap hitam naik, semua fade out

### Ice Magic Shield (16 frame)
1. Layer 1: Outline biru solid (kristal es)
2. Layer 2: Inner glow cyan (additive blending)
3. Layer 3: Snow particle di sekitar shield
4. Layer 4: Rune purba berputar perlahan
5. Animasi: shield expand → stabil → minor pulse
