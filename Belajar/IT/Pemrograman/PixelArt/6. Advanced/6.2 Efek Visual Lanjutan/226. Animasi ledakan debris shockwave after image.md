# 226. Animasi Ledakan Debris Shockwave After Image

## Definisi Singkat
Pembuatan animasi ledakan kompleks yang terdiri dari beberapa elemen: bola api pusat, debris (pecahan material), shockwave (gelombang kejut), dan after image (bayangan gerak).

## Analogi
Ledakan seperti bom di film slow-motion: pertama ada flash cahaya, lalu bola api membesar, kemudian gelombang kejut mendorong udara keluar, dan debris beterbangan ke segala arah. Semua terjadi dalam sepersekian detik.

## Poin-Poin Penting
- **Urutan ledakan**: flash → ekspansi bola api → shockwave → debris → aftermath (asap + sisa api)
- **Flash**: 1-3 frame putih terang, lalu fade ke warna api
- **Shockwave**: lingkaran konsentris yang cepat membesar dan memudar
- **Debris**: pecahan acak dengan rotasi — ukuran bervariasi, lintasan parabola
- **After image**: salinan transparan objek/karakter yang tertinggal dari gerakan cepat
- Skala ledakan menentukan jumlah debris dan radius shockwave
- Gunakan **particle physics sederhana**: debris melambat karena gravitasi, shockwave melambat karena jarak

## Shortcut & Fitur Aseprite
- Multiple layer untuk tiap elemen: Flash, Fireball, Shockwave, Debris, Smoke
- Screen/Add blending untuk flash dan shockwave
- `Alt+R` rotasi debris untuk variasi orientasi
- Gunakan selection tool select-by-color untuk copy debris
- Timeline tagging untuk fase ledakan

## Contoh Kasus Nyata (Step-by-Step)

### Ledakan Bom Besar (32 frame @30fps / ~1 detik)
1. **Frame 1-2 (Flash)**: Putih penuh, tambah layer screen, opacity 100%
2. **Frame 3-6 (Ekspansi)**: Bola api membesar — inti putih, tengah kuning, tepi merah
3. **Frame 4-10 (Shockwave)**: Lingkaran putih tipis membesar dari pusat, opacity turun dari 80% ke 20%
4. **Frame 5-20 (Debris)**: 8-12 debris muncul di frame 5, masing-masing lintasan parabola sendiri, rotasi tiap frame
5. **Frame 8-14 (After image)**: Jika ada karakter di dekat ledakan, gambar siluet transparan bergeser
6. **Frame 12-32 (Aftermath)**: Api mengecil, asap abu-abu membesar dan memudar

### Debris Physics Sederhana
1. Buat 6 debris: 3 besar (4x4 px), 3 kecil (2x2 px)
2. Setiap debris: posisi X bergerak ke luar, posisi Y naik dulu lalu turun (parabola)
3. Rotasi: debris besar rotasi 45°/frame, kecil rotasi 90°/frame
4. Debris besar bertahan 12 frame, kecil 8 frame sebelum fade
