# 271. Lospec Palette List

## Definisi Singkat
Lospec Palette List adalah database ribuan palet warna untuk pixel art yang bisa difilter berdasarkan ukuran, warna, popularitas, dan gaya, dapat diunduh dalam berbagai format.

## Analogi
Seperti toko cat—ada ribuan warna yang sudah dikelompokkan: cat pastel, cat gelap, cat vintage. Tinggal pilih yang cocok untuk proyek, download, dan langsung pakai.

## Poin-Poin Penting
- 3000+ palet dari komunitas pixel art global
- Filter: number of colors (2-256), color hue, year, popularity
- Palet terkenal: PICO-8 (16 colors), DB32 (32 colors), Sweetie 16, NES, Gameboy, APEX
- Setiap palet punya preview contoh penggunaan
- Format download: .png swatch, .hex text, .aseprite, .gpl, .txt
- Rating dan favorites dari pengguna
- Bisa submit palet sendiri setelah daftar akun
- Palet bisa di-embed langsung ke Aseprite via Pocket Palette extension

## Shortcut & Fitur Aseprite
- **Palette > Load Palette** — Muat palet .aseprite dari Lospec
- **Palette > New Palette** — Buat palet dari daftar warna manual
- **Palette > Palette Editor** — Edit warna langsung di Aseprite
- **Windows > Palettes** — Drag-drop palet dari folder ke Aseprite
- **Ctrl+Shift+P** — Preferences, atur default palette folder

## Contoh Kasus Nyata (Step-by-Step)
1. Buka lospec.com/palette-list
2. Filter: "16 colors" + "Blue" + "Highly rated"
3. Cari palet "PICO-8" — klik untuk lihat detail
4. Copy warna dalam format HEX: #000000, #1D2B53, #7E2553, #008751, ...
5. Buka Aseprite → Windows > Palettes → + (New Palette)
6. Klik "+ Add Color" → paste HEX tiap warna
7. Atau langsung download: klik "Download" → pilih .aseprite
8. Di Aseprite: Windows > Palettes → Import → pilih file
9. Buat sprite baru, palet otomatis terpakai
10. Coba buat sprite 32x32 menggunakan palet PICO-8
11. Kunci palet (Lock) agar tidak terganti saat menggambar
12. Export sprite dan tag #PICO-8 #palette di postingan
13. Jika mau kontribusi: daftar akun Lospec → submit palet sendiri
