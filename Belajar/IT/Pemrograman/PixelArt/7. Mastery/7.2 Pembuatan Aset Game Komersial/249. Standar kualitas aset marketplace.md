# 249. Standar Kualitas Aset Marketplace

## Definisi Singkat
Standar kualitas aset marketplace adalah kriteria minimum yang harus dipenuhi pixel art agar layak dijual di platform seperti itch.io, Unity Asset Store, atau GameDev Market.

## Analogi
Seperti standar kelayakan rumah—tidak cukup hanya berdiri, harus ada listrik, air, dan atap. Aset yang baik tidak hanya cantik, tapi juga siap pakai dan terdokumentasi.

## Poin-Poin Penting
- Resolusi konsisten: semua sprite dalam pack harus ukuran yang sama
- Palet warna terbatas dan harmonis (max 16-32 warna per sheet)
- Anti-aliasing minimal untuk tampilan pixel art autentik
- Setiap aset harus collision-ready: bounding box jelas
- File naming: jelas, huruf kecil, underscore, no spasi (contoh: grass_tile_01.png)
- Dokumentasi minimal: readme.txt berisi informasi teknis dan lisensi
- Preview asset harus HD (1920x1080 minimal) dengan latar belakang kontras
- Aset harus bebas dari watermark atau text promo di dalam file

## Shortcut & Fitur Aseprite
- **Ctrl+Shift+X** — Crop ke konten, buang padding tidak perlu
- **File > Export > PNG 32-bit** — Transparansi dengan alpha channel
- **Sprite > Color Mode > Indexed** — Batasi palet ke warna spesifik
- **Windows > Palette** — Cek jumlah warna; refer ke Lospec palette
- **File > Save As** — Beri nama sesuai standar: kategori_tipe_ukuran_variasi

## Contoh Kasus Nyata (Step-by-Step)
1. Buka semua file .aseprite yang akan dijual
2. Cek konsistensi: Sprite > Sprite Size — pastikan semua 32x32
3. Batasi palet: Windows > Palette — pastikan ≤32 warna
4. Rename file sesuai standar:
   - character_knight_idle_32x32.png
   - character_knight_walk_32x32.png
5. Cek bounding box: aktifkan View > Show > Layer Edges
6. Export spritesheet: File > Export > Sprite Sheet
7. Buat readme.txt:
   ```
   Knight Character Pack
   Resolution: 32x32 per frame
   Total Frames: 24 (idle 4, walk 8, attack 6, hurt 2, death 4)
   Color Palette: 16 colors
   License: Commercial Use
   ```
8. Buat screenshot HD: atur canvas 1920x1080, paste aset dengan background gelap-putih
9. ZIP semua file dengan folder struktur rapi
10. Sebelum upload, review checklist: naming OK? dokumentasi OK? preview OK? transparansi OK?
