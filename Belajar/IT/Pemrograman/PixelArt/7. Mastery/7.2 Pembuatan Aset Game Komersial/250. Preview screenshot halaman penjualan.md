# 250. Preview Screenshot Halaman Penjualan

## Definisi Singkat
Preview screenshot adalah gambar atau GIF yang menampilkan aset pixel art dalam konteks penggunaan nyata, berfungsi sebagai media promosi utama di halaman penjualan marketplace.

## Analogi
Seperti foto makanan di menu restoran—tidak cukup menulis "nasi goreng", harus ada foto nasi goreng yang menggugah selera agar orang mau pesan.

## Poin-Poin Penting
- Screenshot pertama harus paling menarik (hero image) — ini yang dilihat pertama
- Gunakan resolusi HD (1920x1080 atau 1280x720) meski aset kecil
- Tampilkan aset dalam konteks game: tileset dipasang, karakter di arena
- Sertakan sebelum-sesudah: tileset kosong vs tileset terpasang
- GIF animasi lebih efektif daripada gambar statis
- Variasi background: gelap untuk aset terang, terang untuk aset gelap
- Tambahkan text overlay minimal (judul, ukuran, jumlah aset)
- Jangan gunakan font terlalu besar atau mengganggu visual aset

## Shortcut & Fitur Aseprite
- **Ctrl+R** — Resize canvas ke 1920x1080 untuk screenshot HD
- **Ctrl+Shift+E** — Export frame sebagai PNG untuk screenshot
- **File > Export > Export as GIF** — Animasi preview
- **Layer > New Layer** — Layer terpisah untuk background preview
- **View > Show > Pixel Grid** — Tampilkan grid untuk kesan teknis

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite, buat file baru 1920x1080
2. Layer 1 (Background): fill dengan warna abu-abu #808080
3. Import tileset: File > Open, copy-paste tile ke layer 2
4. Susun tile membentuk scene game sederhana (rumput, jalan, pohon, karakter)
5. Layer 3: tambahkan border putih 2px di sekitar area tileset
6. Layer 4 (text): tulis "Fantasy Village Tileset — 64 tiles — 32x32"
7. Export PNG: File > Export > PNG 32-bit
8. Export GIF animasi: File > Export > GIF — tapi hanya bagian karakter bergerak
9. Cek hasil: zoom ke 33% agar kelihatan preview realistis
10. Simpan file aseprite sebagai master preview untuk edit di masa depan
