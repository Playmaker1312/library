# 251. Strategi Pricing Lisensi Aset

## Definisi Singkat
Strategi pricing lisensi aset adalah penentuan harga jual dan jenis lisensi (personal, commercial, exclusive) untuk melindungi hak cipta sekaligus memaksimalkan pendapatan pixel artist.

## Analogi
Seperti sewa mobil—ada harga harian (personal license), harga mingguan (commercial license), dan harga beli mobil (exclusive license). Semakin lama dan luas penggunaan, semakin mahal biayanya.

## Poin-Poin Penting
- Personal License: $5-15 — untuk proyek non-komersial, kredit wajib
- Commercial License: $15-50 — untuk game komersial, revenue <$10k
- Extended License: $50-200 — revenue >$10k, tanpa batas
- Exclusive License: $200-1000+ — hak penuh, aset dihapus dari marketplace
- Royalty-free: pembeli bayar sekali, pakai selamanya (model standar marketplace)
- Royalty-based: % dari revenue game (jarang dipakai, susah dilacak)
- Bundle pricing: diskon 20-30% untuk pembelian multipack
- Selalu cantumkan terms of use di halaman produk

## Shortcut & Fitur Aseprite
- **File > Save As** — Simpan file source (.aseprite) hanya untuk exclusive
- **File > Export > PNG** — Aset tanpa source untuk lisensi dasar
- **Ctrl+Shift+T** — Cek frame count untuk perhitungan harga
- **Sprite > Properties** — Catat ukuran dan palet untuk dokumentasi lisensi
- **Windows > Layers** — Kelola layer: base layer untuk semua lisensi, premium layer untuk extended

## Contoh Kasus Nyata (Step-by-Step)
1. Tentukan aset: "Knight Character Pack — 24 frame animasi, 16 warna, 32x32"
2. Hitung harga dasar: $0.50/frame = $12 + $5 (spritesheet) = $17
3. Buat tier lisensi:
   - Personal: $10 (PNG only, no source, credit required)
   - Commercial: $25 (PNG + .aseprite, no credit needed, rev share <$10k)
   - Extended: $60 (source + commercial + rev share unlimited)
   - Exclusive: $300 (full rights, removed from store)
4. Buka itch.io → Edit Project → Add multiple files per tier
5. Gunakan fitur "Pay What You Want" dengan suggested price $25
6. Tulis halaman lisensi: "You may not resell these assets as your own. You may modify for your game project."
7. Aktifkan "File Access" — pembeli bisa download file setelah bayar
8. Update secara berkala: tambah animasi baru, naikkan harga secara gradual
