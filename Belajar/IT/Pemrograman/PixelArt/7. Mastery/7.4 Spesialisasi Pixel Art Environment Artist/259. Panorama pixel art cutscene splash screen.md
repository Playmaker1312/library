# 259. Panorama Pixel Art Cutscene Splash Screen

## Definisi Singkat
Panorama pixel art adalah ilustrasi horizontal lebar untuk cutscene, splash screen, atau background layar judul game yang menampilkan pemandangan epik dalam resolusi tinggi.

## Analogi
Seperti lukisan pemandangan di museum—dari kiri ke kanan ada cerita visual: gunung, hutan, sungai, desa. Mata penonton diajak berjalan menikmati setiap detail.

## Poin-Poin Penting
- Rasio lebar:tinggi minimal 2:1 hingga 4:1 (contoh: 1920x480 atau 2560x640)
- Komposisi horizontal: bagi menjadi 3-4 section visual yang berbeda
- Gunakan paralax layer: background (langit), midground (gunung), foreground (karakter/pepohonan)
- Detail menurun dari foreground ke background (foreground paling detail)
- Palet warna harmonis: pilih 1-2 warna dominan, 2 warna aksen
- Dithering untuk transisi gradien di resolusi rendah
- Splash screen: tambahkan logo game + "Press Start" dalam komposisi
- Cutscene: siapkan animasi minimal (awan bergerak, air mengalir)

## Shortcut & Fitur Aseprite
- **Ctrl+N** — File baru 2560x640 untuk panorama lebar
- **Layer > New Layer** — Buat parallax layers: Sky, Mountains, Forest, Ground
- **Ctrl+T** — Transform untuk scaling elemen per layer
- **Ctrl+R** — Resize canvas jika perlu tambah lebar
- **View > Symmetry Mode** — Untuk elemen simetris di splash screen

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 2560x640, palet 16 warna
2. Layer Sky (Background): gradien 4 warna, dari biru tua ke oranye
3. Layer Mountains (Midground 1): 3 gunung dengan siluet gelap, dithering untuk tekstur
4. Layer Forest (Midground 2): pepohonan berlapis, ukuran mengecil ke belakang
5. Layer Ground (Foreground): rumput + jalan setapak dari kiri ke kanan
6. Layer Details: tambahkan 2-3 karakter kecil di foreground untuk skala
7. Layer Effects: awan (beberapa titik putih, transparan), burung (2-3px)
8. Jika untuk splash screen: tambahkan logo game di center, teks "Press ENTER" di bawah
9. Export sebagai PNG: File > Export > PNG 32-bit
10. Untuk cutscene animasi: duplikasi layer awan, geser 2px tiap frame, export GIF

Animasi minimal untuk cutscene:
- Awan: 4 frame, geser 2px per frame
- Air: 4 frame, berganti warna biru terang-gelap
- Karakter: idle breathing 4 frame
