# 245. Platform Jual Aset Pixel Art Itch.io

## Definisi Singkat
Itch.io adalah platform distribusi digital untuk game dan aset kreatif, tempat pixel artist dapat menjual asset packs, tilesets, sprites, dan tools ke komunitas gamedev.

## Analogi
Seperti toko kelontong online—kita tinggal display barang (aset), kasih harga, dan pembeli datang sendiri karena platform sudah punya pengunjung tetap.

## Poin-Poin Penting
- Itch.io mengambil potongan 10% dari penjualan (salah satu yang terkecil)
- Format aset: .png spritesheet, .aseprite, .gif preview, dokumentasi PDF
- Kategori populer: Tilesets, Character Sprites, UI Packs, Sound Effects
- Fitur "Pay What You Want" (PWYW) efektif untuk exposure
- Gunakan tag yang tepat: pixel-art, game-assets, tileset, 2d, retro
- Preview asset harus GIF animasi untuk menarik perhatian
- Review pengguna dan rating meningkatkan visibilitas
- Bundle sale (discount 50-70%) bisa boosting penjualan signifikan

## Shortcut & Fitur Aseprite
- **File > Export Sprite Sheet** — Siapkan aset dalam format spritesheet
- **Ctrl+R** — Resize canvas untuk thumbnail itch.io (preferably 16:9)
- **File > Export > Export as GIF** — Buat animated preview
- **Ctrl+Shift+X** — Auto-crop padding berlebih
- **Windows > Color** — Cek palet warna untuk dokumentasi

## Contoh Kasus Nyata (Step-by-Step)
1. Buka itch.io → Login → Create New Project
2. Pilih kategori "Assets" dan subkategori "Pixel Art"
3. Upload file:
   - Main file: .zip berisi spritesheet PNG + .aseprite source
   - Preview image: GIF animasi (max 5MB)
   - Dokumentasi: PDF penggunaan aset
4. Tulis deskripsi: "16x16 Fantasy Tileset - 64 tiles, 16 colors, includes walkable terrain, water, and dungeon tiles"
5. Set price: $5.99 (atau PWYW dengan minimum $1)
6. Tag: pixel-art, tileset, fantasy, rpg, 2d, game-assets
7. Atur lisensi: "Standard Itch.io License" atau buat custom license
8. Publish → Share di Twitter dengan gambar preview + link itch.io
9. Update assets setiap bulan untuk maintain relevance di search
