# 241. Portofolio Pixel Art Profesional

## Definisi Singkat
Portofolio pixel art profesional adalah kumpulan karya terkurasi yang menunjukkan kemampuan teknis, gaya artistik, dan pengalaman seorang pixel artist untuk menarik klien atau studio game.

## Analogi
Seperti etalase toko—orang tidak akan masuk jika tampilannya berantakan. Portofolio adalah etalase digitalmu; karya terbaik di depan, variasi di tengah, dan proyek besar sebagai penutup.

## Poin-Poin Penting
- Kualitas > Kuantitas: pilih 10-15 karya terbaik, bukan 50 karya biasa
- Tunjukkan spesialisasi (environments, character, UI, animasi)
- Sertakan proses work-in-progress (WIP) untuk bukti orisinalitas
- Tambahkan konteks: tools yang digunakan, ukuran canvas, jumlah frame
- Update portofolio setiap 3-6 bulan dengan karya terbaru
- Buat versi PDF untuk email dan versi web (site/Carrd/itch.io)
- Landing page harus dimuat <3 detik untuk retensi recruiter

## Shortcut & Fitur Aseprite
- **Ctrl+T** — Transform sprite untuk resize canvas preview
- **Ctrl+Shift+X** — Crop ke konten untuk export bersih
- **File > Export Sprite Sheet** — Buat spritesheet sekaligus GIF
- **View > Grid** — Tampilkan grid untuk menunjukkan presisi
- **File > Save As > .png** — Export transparan untuk web

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite dan kumpulkan 15 file .aseprite terbaik
2. Untuk setiap file, tekan Ctrl+R untuk resize canvas ke ukuran konsisten
3. Gunakan File > Export > PNG (32-bit RGBA) untuk hasil transparan
4. Buka Itch.io → Create New Project → Upload PNG sebagai gallery
5. Tulis deskripsi: tools, ukuran canvas, jumlah warna, waktu pengerjaan
6. Atur urutan: karya paling impresif di slide pertama
7. Generate PDF melalui File > Print > Save as PDF untuk versi offline
8. Share link di Twitter/LinkedIn dengan tag #pixelart #portofolio
