# 264. Game Jam Aset Pixel Art Sendiri

## Definisi Singkat
Game jam adalah kompetisi pengembangan game dalam waktu singkat (24-72 jam) di mana pixel artist membuat aset sendiri atau berkolaborasi dengan tim untuk menyelesaikan game berdasarkan tema tertentu.

## Analogi
Seperti lomba masak 1 jam—tidak bisa masak rendang yang butuh 4 jam. Harus cepat, kreatif dengan bahan terbatas, dan hasilnya tetap enak (playable game).

## Poin-Poin Penting
- Game jam populer: GMTK Game Jam, Ludum Dare, Brackeys, itch.io themed jam
- Pixel artist di tim: fokus bikin aset minimum viable (tileset, character, UI)
- Batasi palet: 8-16 warna untuk konsistensi cepat
- Gunakan template/empty tileset yang sudah ada untuk akselerasi
- Tileset modular: 4-6 tile sudah cukup untuk prototype
- Karakter: 1 karakter + 2 animasi (idle + walk) — jangan over-animasi
- Komunikasi tim: real-time via Discord voice chat
- Export aset ke engine setiap 2-3 jam untuk test integrasi

## Shortcut & Fitur Aseprite
- **Ctrl+N** — File baru cepat, ukuran standar (16x16, 32x32)
- **Ctrl+Shift+T** — Timeline untuk animasi dasar (idle 4 frame, walk 6 frame)
- **File > Export Sprite Sheet** — Export cepat ke format engine
- **Palette > Load Palette** — Muat palet Lospec yang sudah jadi
- **Ctrl+Shift+X** — Crop cepat untuk tile individual

## Contoh Kasus Nyata (Step-by-Step)
1. Daftar di itch.io → Game Jams → cari "GMTK Game Jam 2025"
2. Tema diumumkan: "Growing" — kamu punya 48 jam
3. Jam 0-2: Brainstorm + buat tileset minimal 16x16 (6 tile: ground, wall, water, plant_stage1, plant_stage2, plant_stage3)
4. Jam 2-4: Buat karakter utama 16x16 (idle 4 frame, walk 6 frame)
5. Jam 4-6: Export spritesheet + .png ke folder project Unity/Godot
6. Jam 6-8: Bantu programmer testing — fix tile alignment
7. Jam 8-10: Buat UI sederhana (health bar, score, button) 3 item
8. Jam 10-12: Tambah particle effects (grow sparkle, dust)
9. Jam 12-18: Tidur — istirahat penting!
10. Jam 18-36: Polish: animasi tambahan, efek transisi, screen shake
11. Jam 36-42: Buat icon game + screenshot + cover itch.io
12. Jam 42-48: Final testing + submit game ke game jam page
13. Submit: upload game + tulis deskripsi + screenshot + credit tim
14. Post-mortem: evaluasi apa yang bisa diperbaiki untuk jam berikutnya
