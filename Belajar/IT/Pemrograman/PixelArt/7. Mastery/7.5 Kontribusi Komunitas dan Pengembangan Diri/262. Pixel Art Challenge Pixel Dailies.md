# 262. Pixel Art Challenge Pixel Dailies

## Definisi Singkat
Pixel Art Challenge adalah latihan harian/mingguan dengan tema tertentu yang diikuti pixel artist untuk mengasah skill, membangun kebiasaan, dan mendapatkan exposure di komunitas.

## Analogi
Seperti olahraga pagi—tidak perlu lama, 30 menit sehari sudah cukup untuk menjaga kebugaran (skill) tetap prima. Lama-lama jadi kebiasaan yang sulit ditinggalkan.

## Poin-Poin Penting
- Pixel Dailies (@Pixel_Dailies di Twitter): tema harian, setiap hari berbeda
- Pixel Logic Challenges: fokus ke teknik spesifik (dithering, lighting)
- Weekly Pixel Art Challenge di subreddit r/PixelArt
- Manfaat: melatih kecepatan, kreativitas terbatas, portofolio isi
- Batasi waktu: 30 menit - 2 jam per challenge
- Tidak perlu sempurna—fokus pada selesai dan belajar
- Interaksi dengan peserta lain: comment, like, belajar dari karya orang
- Post hasil dengan hashtag resmi challenge

## Shortcut & Fitur Aseprite
- **Ctrl+N** — Cepat buat file baru ukuran kecil (16x16, 32x32)
- **Ctrl+Shift+E** — Export cepat ke PNG/GIF untuk upload
- **Palette preset** — Load palet Lospec untuk hemat waktu
- **Ctrl+Shift+Z** — Redo untuk trial and error cepat
- **Tab** — Timeline untuk animasi sederhana

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Twitter/X, cek akun @Pixel_Dailies untuk tema hari ini
2. Tema: "Dragon" — kamu punya 1 jam
3. Buka Aseprite, buat 32x32, load palet "Nintendo Gameboy" (4 warna)
4. 0-10 mnt: sketch dasar bentuk naga (kepala, sayap, ekor)
5. 10-25 mnt: tambah bayangan dengan 2 warna gelap
6. 25-40 mnt: detail (mata, sisik, api dari mulut)
7. 40-50 mnt: animasi 4 frame (sayap mengepak)
8. 50-55 mnt: export GIF + cek hasil
9. 55-60 mnt: post di Twitter dengan caption "Day 142: Dragon! #PixelDailies #pixelart #dragon"
10. Reply ke tweet @Pixel_Dailies, tag akun resmi
11. Cek karya orang lain, like dan comment yang membangun
12. Simpan file di folder "Challenges" untuk portofolio
