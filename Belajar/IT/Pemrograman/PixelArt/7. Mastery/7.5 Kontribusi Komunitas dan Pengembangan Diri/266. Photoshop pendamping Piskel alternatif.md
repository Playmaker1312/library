# 266. Photoshop Pendamping Piskel Alternatif

## Definisi Singkat
Photoshop berfungsi sebagai pendamping Aseprite untuk manipulasi gambar kompleks, sementara Piskel adalah alternatif gratis berbasis web untuk pixel art ketika Aseprite tidak tersedia.

## Analogi
Seperti pisau dapur dan blender—Aseprite/Piskel adalah pisau untuk memotong detail (pixel), Photoshop adalah blender untuk menghaluskan dan mencampur (efek, filter, manipulasi besar).

## Poin-Poin Penting
- **Photoshop**: untuk resize, batch processing, color correction, efek glitch
- **Piskel** (piskelapp.com): gratis, web-based, bisa animasi, export GIF/PNG
- Piskel cocok untuk: pixel art sederhana, edukasi, atau ketika di komputer orang lain
- Photoshop: Indexed Color Mode untuk palet terbatas, Nearest Neighbor untuk resize
- Aseprite tetap #1 untuk dedicated pixel art workflow
- Photoshop script: batch convert gambar ke pixel art style
- Piskel limitations: no layer grouping, no tilemap, output terbatas
- Kombinasi optimal: sketch di Piskel/Photoshop → refine di Aseprite

## Shortcut & Fitur Aseprite vs Photoshop vs Piskel
- **Aseprite**: Alt+N (new frame), Onion Skin, timeline terintegrasi
- **Photoshop**: Ctrl+Alt+I (Image Size), Filter > Pixelate > Mosaic, Timeline panel
- **Piskel**: S (draw), D (paint bucket), E (eraser), frame timeline di kanan
- **Ekspor**: Aseprite (Sprite Sheet), Photoshop (PNG sequence), Piskel (GIF)

## Contoh Kasus Nyata (Step-by-Step)
Menggunakan Piskel (Alternatif):
1. Buka browser → piskelapp.com → klik "Create a new sprite"
2. Set ukuran 32x32, palet default
3. Gambar karakter dengan tools: Pen (S), Eraser (E), Paint Bucket (D)
4. Tambah frame: klik "+" di frame panel kanan
5. Animasi: gambar tiap frame dengan onion skin aktif
6. Preview: klik tombol play di atas canvas
7. Export: klik "Export" → pilih GIF atau PNG spritesheet
8. Download file .piskel untuk edit nanti atau PNG/GIF untuk sharing

Menggunakan Photoshop (Pendamping):
1. Buka pixel art di Photoshop
2. Image > Mode > Indexed Color untuk batasi palet
3. Image > Image Size: set Resample ke "Nearest Neighbor" agar tetap tajam
4. Filter > Pixelate > Mosaic untuk efek pixel art dari gambar biasa
5. Export: File > Export > Save for Web (PNG-8 dengan palette terbatas)
6. Gunakan action/batch: Window > Actions untuk automate resize banyak file
