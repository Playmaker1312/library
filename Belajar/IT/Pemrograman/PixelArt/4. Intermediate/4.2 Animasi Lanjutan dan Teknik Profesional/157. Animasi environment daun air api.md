# 157. Animasi Environment Daun Air Api

## Definisi Singkat
Teknik menganimasi elemen environment organik — dedaunan bergoyang, air mengalir, api menyala — untuk menghidupkan latar dan atmosfer game.

## Analogi
Seperti lukisan hidup di film Disney: pohon tidak diam, air tidak statis, api selalu bergerak. Lingkungan yang "hidup" membuat dunia game terasa nyata.

## Poin-Poin Penting
- Daun: gerakan loop 4-8 frame, osilasi perlahan dari pangkal
- Air: flow direction konsisten, gunakan 4-6 frame loop untuk riak
- Api: 6-8 frame, tidak pernah sama tiap loop (variasi kecil)
- Asap: 8-12 frame, membesar dan memudar
- Partikel: daun jatuh, percikan air, abu api
- Jangan animasi semua elemen — cukup fokus 2-3 layer foreground

## Shortcut & Fitur Aseprite
- **Loop tag** — tandai animasi looping environment
- **Onion Skin** (Shift+O) — trace posisi sebelumnya
- **Pencil tool** (B) — detail per piksel
- **Cel opacity** — fade in/out asap dan partikel
- **Duplikat frame** (Alt+D) — buat variasi cepat

## Contoh Kasus Nyata (Step-by-Step)

### Daun bergoyang:
1. Gambar pohon dengan daun di latar belakang
2. Buat 4 frame: frame 1 posisi normal, frame 2 miring kiri, frame 3 normal, frame 4 miring kanan
3. Atur durasi 150-200ms per frame → loop
4. Tambah daun jatuh: 1-2 partikel dengan path meliuk

### Air mengalir:
1. Gambar sungai dengan base warna biru
2. Buat 6 frame flow: garis putih bergerak diagonal dari kiri ke kanan
3. Tambah ripple (lingkaran kecil) muncul dan hilang
4. Air terjun: partikel putih vertikal dengan variasi panjang

### Api menyala:
1. Buat 8 frame: frame 1 api kecil → frame 4 membesar → frame 8 mengecil
2. Warna: putih (inti), kuning, jingga, merah, merah gelap (luar)
3. Variasi: jangan identik tiap loop — selipkan frame random
