# 160. Pose to Pose vs Straight Ahead

## Definisi Singkat
Dua pendekatan fundamental dalam animasi: **Pose to Pose** — menentukan keypose utama dulu, lalu mengisi in-between; **Straight Ahead** — menggambar frame berurutan dari awal hingga akhir tanpa perencanaan keypose.

## Analogi
- Pose to Pose: seperti membangun rumah dengan cetak biru — bingkai dulu, baru detail.
- Straight Ahead: seperti melukis bebas — spontan dan organik, tapi riskan proporsi meleset.

## Poin-Poin Penting

### Pose to Pose:
- Tentukan 2-4 keypose (pose paling penting)
- Interval antar keypose: gambar in-between
- Kelebihan: timing terkontrol, konsistensi proporsi
- Kekurangan: gerakan bisa kaku jika in-between kurang

### Straight Ahead:
- Frame 1 → Frame 2 → Frame 3... tanpa planning
- Kelebihan: gerakan organik, cair, surprising
- Kekurangan: mudah meleset volume, timing tidak presisi

## Shortcut & Fitur Aseprite
- **Onion Skin** (Shift+O) — vital untuk kedua teknik
- **Tag** — tandai keypose (K) dan in-between (I/B)
- **Cel duration adjustment** — atur timing antar keypose
- **Layer: Reference** — tempat sketsa keypose
- **Copy Cel** (Ctrl+C / Ctrl+V) — duplikat frame sebagai base in-between

## Contoh Kasus Nyata (Step-by-Step)

### Pose to Pose untuk karakter melompat:
1. Keypose 1: Squat (frame 1)
2. Keypose 2: Jump apex (frame 5)
3. Keypose 3: Landing (frame 9)
4. In-between frame 1-5: 3 frame transisi (2,3,4)
5. In-between frame 5-9: 3 frame turun (6,7,8)
6. Evaluasi dan adjust timing
7. Tambah smear di frame 1-2 jika perlu

### Straight Ahead untuk api/efek:
1. Frame 1: bentuk api awal
2. Frame 2: api naik sedikit berubah
3. Frame 3: api miring kiri
4. Frame 4: api membesar
5. Lanjutkan sampai 12 frame tanpa planning
6. Review setelah selesai, hapus frame yang tidak perlu

### Hybrid:
1. Tentukan 3 keypose dengan Pose to Pose
2. Isi in-between dengan Straight Ahead (spontan)
3. Koreksi ketidaksesuaian volume
