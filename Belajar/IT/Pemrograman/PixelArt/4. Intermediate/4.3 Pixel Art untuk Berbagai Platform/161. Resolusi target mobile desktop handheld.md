# 161. Resolusi Target Mobile Desktop Handheld

## Definisi Singkat
Panduan memilih dan mengoptimalkan resolusi pixel art berdasarkan target platform — mobile, desktop, atau handheld (Nintendo Switch, Steam Deck) — dengan mempertimbangkan performa, readability, dan estetika.

## Analogi
Sepatu: Anda tidak pakai sepatu seluncur es untuk mendaki gunung. Setiap platform punya "sepatu" ideal — resolusi yang pas untuk layar dan kontrolnya.

## Poin-Poin Penting

### Mobile (iOS/Android):
- Resolusi ideal: 320x180 atau 480x270 (scale 3x-4x)
- Karakter: 16x16 hingga 32x32
- UI harus besar — minimal 24x24 piksel per tombol
- Pertimbangkan notch dan safe area

### Desktop (PC/Mac):
- Resolusi ideal: 640x360 atau 960x540 (scale 2x-3x)
- Karakter: 32x32 hingga 64x64
- Lebih banyak detail diperbolehkan
- Resolusi monitor tinggi: integer scaling penting

### Handheld (Switch/Steam Deck):
- Resolusi ideal: 384x216 atau 640x360
- Karakter: 24x24 hingga 48x48
- Layar kecil → kontras tinggi, siluet jelas
- Performa baterai: palet terbatas, frame rendah

## Shortcut & Fitur Aseprite
- **Sprite > Sprite Size** — sesuaikan resolusi
- **Resize > Nearest Neighbor** — integer scaling, jangan bilinear
- **View > Pixel Grid** — cek tiap piksel
- **Export > Scale** — atur export scale per platform
- **Palette > Reduce Palette** — optimasi warna

## Contoh Kasus Nyata (Step-by-Step)

1. Tentukan platform utama: Mobile (iOS/Android)
2. Pilih resolusi internal: 320x180 (16:9)
3. Karakter utama: 24x24 piksel — cukup detail, tetap efisien
4. UI tombol: minimal 32x32 agar jari tidak salah tap
5. Tes di layar sungguhan: render ukuran asli
6. Jika karakter tidak terbaca → scale up ke 480x270
7. Export: sertakan varian untuk tablet (scale 4x)
8. Dokumentasi resolusi di README proyek
