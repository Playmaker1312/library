# 163. Scaling Pixel Art untuk Resolusi Tinggi

## Definisi Singkat
Teknik memperbesar (scaling up) pixel art dari resolusi rendah ke resolusi tinggi untuk monitor 4K/5K/Retina tanpa kehilangan ketajaman dan estetika khas pixel art.

## Analogi
Foto digital diperbesar: jika pakai bilinear interpolation, hasilnya buram. Jika pakai nearest neighbor (integer scaling), piksel tetap tajam — seperti melihat mozaik dari dekat.

## Poin-Poin Penting
- **Integer scaling** wajib: scale 2x, 3x, 4x, dst — bukan 1.5x atau 2.5x
- Scale 3x adalah sweet spot untuk 1080p (320x180 → 960x540)
- Scale 6x untuk 4K (320x180 → 1920x1080)
- Jika integer scaling tidak mungkin: gunakan Scale2x, Scale3x, atau xBR filter
- Hindari bilinear, bicubic, atau lanczos — merusak pixel art
- Pertimbangkan hybrid: lingkungan 2.5D (pixel art characters di background 3D)

## Shortcut & Fitur Aseprite
- **Sprite > Sprite Size** → resize dengan **Nearest Neighbor**
- **Resize > Percentage** — pastikan integer multiplier
- **Export > Scale** — export langsung dengan scale tertentu
- **Filter > Scale2x / Scale3x** — smart scaling (jika perlu)
- **Sprite > Export Sprite Sheet** — tentukan output size

## Contoh Kasus Nyata (Step-by-Step)

1. Game internal resolusi: 320x180
2. Target monitor: 1920x1080 (Full HD)
3. Hitung scale: 1920/320 = 6, 1080/180 = 6 → integer scale 6x
4. Di Aseprite: File > Export > Scale: 6 → Sprite Size: 1920x1080
5. Jika ada UI: gunakan resolusi UI terpisah (scale 3x untuk UI)
6. Untuk 4K (3840x2160): scale 12x
7. Alternatif non-integer: render 320x180 di 640x360 (scale 2x) → display di 1920x1080 dengan black bars
8. Tes di monitor target: pastikan tidak ada blur
