# 179. Aseprite CLI Command Line

## Definisi Singkat
Aseprite CLI (Command Line Interface) adalah mode non-GUI di Aseprite yang memungkinkan eksekusi perintah langsung dari terminal/command prompt untuk batch processing, konversi, export, dan rendering tanpa membuka aplikasi.

## Analogi
Seperti oven dengan timer — Anda setting suhu dan waktu, lalu oven bekerja sendiri tanpa perlu diawasi. CLI memproses file secara otomatis tanpa GUI.

## Poin-Poin Penting
- Jalankan: `aseprite [options] [files]` dari terminal
- Format umum: `aseprite --batch file.ase --export-as output.png`
- Flag penting: `--batch` (mode tanpa GUI), `--layer`, `--frame`, `--scale`
- Bisa export sprite sheet, GIF animasi, frame individual
- Mendukung wildcard `*.aseprite` untuk batch semua file
- Combine flag: `--data` (JSON data), `--sheet` (sprite sheet), `--list-layers`

## Shortcut & Fitur Aseprite
- **Add Aseprite to PATH**: Pastikan folder install Aseprite ada di PATH sistem
- **--help**: Lihat semua opsi CLI: `aseprite --help`
- **--batch**: Mode batch tanpa GUI (harus ada untuk CLI processing)
- **--list-layers**: Lihat daftar layer tanpa export
- **--list-tags**: Lihat tag animasi untuk frame selection

## Contoh Kasus Nyata (Step-by-Step)

1. **Buka terminal** — PowerShell/CMD di folder project
2. **Cek instalasi** — `aseprite --version` untuk verifikasi CLI tersedia
3. **Export satu frame** — `aseprite --batch char.ase --frame 1 --export-as char_frame1.png`
4. **Export semua layer** — `aseprite --batch char.ase --layer "*" --export-as {layer}.png`
5. **Export sprite sheet** — `aseprite --batch char.ase --sheet char_sheet.png --data char.json --sheet-type packed`
6. **Resize batch export** — `aseprite --batch *.aseprite --scale 2 --export-as {name}@2x.png`
7. **Export animasi GIF** — `aseprite --batch anim.ase --export-as anim.gif`
8. **List layer tanpa export** — `aseprite --batch project.ase --list-layers`
9. **Export range frame** — `aseprite --batch walk.ase --from 1 --to 4 --export-as walk_{frame}.png`
10. **Buat batch script Windows** — Simpan command di file .bat/ps1 untuk reuse
