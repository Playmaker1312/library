# 185. Reference Window

## Definisi Singkat
Reference Window adalah jendela terpisah di Aseprite yang menampilkan gambar referensi (ref sheet, konsep, foto) di samping canvas utama, membantu seniman menggambar dengan akurat tanpa harus alt-tab.

## Analogi
Seperti membuka buku resep di samping kompor — Anda bisa melihat langkah-langkah sambil memasak tanpa harus menghafal atau berhenti.

## Poin-Poin Penting
- Buka via View > Reference (Ctrl+Shift+R)
- Bisa load gambar dari file atau drag & drop langsung
- Window bisa di-resize dan dipindah ke monitor kedua
- Tidak mempengaruhi canvas utama — murni sebagai panduan visual
- Bisa pin beberapa reference sekaligus dengan multiple windows

## Shortcut & Fitur Aseprite
- **View > Reference (Ctrl+Shift+R)**: Buka/tutup Reference Window
- **Load Image**: Klik folder icon di Reference Window untuk pilih file
- **Drag & Drop**: Tarik gambar dari file explorer langsung ke Reference Window
- **Zoom**: Scroll di Reference Window untuk zoom in/out referensi
- **Opacity Slider**: Atur transparansi referensi agar tidak terlalu dominan

## Contoh Kasus Nyata (Step-by-Step)

1. **Siapkan gambar referensi** — File PNG/JPG dari konsep karakter
2. **Buka Reference Window** — View > Reference (Ctrl+Shift+R)
3. **Load referensi** — Klik folder icon, pilih file referensi
4. **Atur posisi** — Drag Reference Window ke samping canvas (atau monitor 2)
5. **Zoom referensi** — Scroll untuk perbesar bagian detail (misal mata)
6. **Opacity 70%** — Kurangi opacity agar tidak mengganggu fokus
7. **Gambar di canvas utama** — Gunakan referensi sebagai panduan proporsi
8. **Multiple referensi** — Buka Reference Window kedua untuk angle berbeda
9. **Pin palette referensi** — Buka palette dari referensi di Color Palette
10. **Tutup referensi** — Ctrl+Shift+R setelah selesai
