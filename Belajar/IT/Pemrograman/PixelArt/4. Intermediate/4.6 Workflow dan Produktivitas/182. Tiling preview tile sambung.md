# 182. Tiling Preview Tile Sambung

## Definisi Singkat
Tiling preview adalah teknik melihat bagaimana tile/gambar menyambung secara seamless saat di-repeat, memastikan tepi tile cocok sempurna tanpa celah atau garis putus.

## Analogi
Seperti memasang keramik lantai — setiap ubin harus sama persis tepinya agar pola lantai mulus tanpa cela.

## Poin-Poin Penting
- Tile seamless: tepi kiri cocok dengan tepi kanan, tepi atas cocok dengan tepi bawah
- Gunakan offset editing: geser canvas lalu edit garis sambung
- Aseprite punya fitur Tile Mode untuk live preview repeat
- Pastikan warna di tepi tile identik (pixel ke pixel)
- Test dengan offset 50% canvas untuk lihat sambungan paling kritis

## Shortcut & Fitur Aseprite
- **View > Tile Mode (Ctrl+Shift+T)**: Live preview tile berulang
- **Tile Mode Options**: Set repeat horizontal, vertikal, atau keduanya
- **Grid Settings**: Atur grid sesuai ukuran tile untuk panduan
- **Edit > Preferences > Tiled Screen Mode**: Setting default tile mode
- **Offset Editing**: Buat tile baru, geser selection, edit sambungan di tengah

## Contoh Kasus Nyata (Step-by-Step)

1. **Buat canvas 32x32 px** — Ukuran tile standar
2. **Aktifkan Tile Mode** — View > Tile Mode (Ctrl+Shift+T), repeat both
3. **Gambar motif di tengah tile** — Jangan sentuh tepi dulu
4. **Matikan Tile Mode** — Ctrl+Shift+T matikan
5. **Offset canvas** — Seleksi semua (Ctrl+A), geser 16 px ke kanan
6. **Edit sambungan vertikal** — Perbaiki garis di tengah canvas (yang jadi tepi)
7. **Offset lagi 16 px ke bawah** — Edit sambungan horizontal
8. **Aktifkan Tile Mode lagi** — Verifikasi tile seamless
9. **Test dengan tile lain** — Copy paste tile, atur bersebelahan
10. **Simpan sebagai .aseprite** — Untuk reuse di project mapping
