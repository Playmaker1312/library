# 181. Custom Brush Elemen Berulang

## Definisi Singkat
Custom brush adalah pola atau bentuk yang disimpan sebagai brush khusus di Aseprite, digunakan untuk mengecat elemen berulang (ubin, rantai, daun, pola dekoratif) secara cepat dan konsisten.

## Analogi
Seperti stempel — Anda tidak perlu menggambar ulang tanda tangan setiap kali, cukup stempel. Custom brush adalah stempel digital untuk pixel art.

## Poin-Poin Penting
- Brush kustom bisa dari seleksi (Ctrl+Shift+B) atau gambar manual
- Brush disimpan di panel Brush (F5) sebagai tile/pola
- Tipe brush: single pixel, pattern, image stamp
- Pattern brush: gambar berulang saat brush digeser
- Image stamp: brush sekali klik, cocok untuk dekorasi (batu, daun, bintang)

## Shortcut & Fitur Aseprite
- **Brush Panel (F5)**: Kelola brush, buat baru, hapus
- **New Brush from Selection (Ctrl+Shift+B)**: Buat brush dari area terpilih
- **Brush Type**: Pilih Image Stamp atau Pattern di dropdown
- **Spacing**: Atur jarak antar stamp saat brush digerakkan
- **Preferences > Brushes**: Lokasi file brush .png atau .aseprite

## Contoh Kasus Nyata (Step-by-Step)

1. **Gambar elemen kecil 8x8 px** — Misal bintang 4 pixel
2. **Seleksi elemen** — Select All (Ctrl+A) atau seleksi manual
3. **Buat brush** — Ctrl+Shift+B atau via Brush Panel > New Brush
4. **Beri nama** — "bintang_emas" di dialog
5. **Set tipe Image Stamp** — Brush Panel, pilih Image Stamp
6. **Test brush** — Klik sekali di canvas, bintang muncul di posisi kursor
7. **Set spacing** — Atur spacing 20 px agar bintang tidak bertumpuk
8. **Buat pattern brush** — Gambar tile 16x16, buat brush, set tipe Pattern
9. **Gunakan pattern untuk border** — Pattern brush untuk batas dekoratif
10. **Simpan brush collection** — Export brush via Brush Panel > Save
