# 173. Efek Bayangan Tile Isometric

## Definisi Singkat
Efek bayangan tile isometric adalah teknik menambahkan proyeksi bayangan objek ke tile ground di sekitarnya, memberikan kesan kedalaman dan dimensi yang lebih realistis.

## Analogi
Seperti bayangan tiang listrik di trotoar — bentuk bayangan mengikuti kontur tanah, bukan bentuk objek aslinya.

## Poin-Poin Penting
- Bayangan diproyeksikan ke ground plane, bukan digambar di objek
- Arah bayangan mengikuti arah cahaya (biasanya ke SE)
- Bayangan tile berbentuk diamond atau persegi panjang miring
- Gunakan layer terpisah dengan blending mode Multiply
- Jarak bayangan = tinggi objek (semakin tinggi objek, semakin jauh bayangan)

## Shortcut & Fitur Aseprite
- **New Layer (Ctrl+Shift+N)**: Buat layer "shadow" di atas ground layer
- **Blending Mode**: Set layer shadow ke Multiply
- **Opacity (Shift+M)**: Atur transparansi bayangan (30-50% ideal)
- **Fill Tool (G)**: Isi area bayangan dengan warna hitam solid
- **Eraser (E)**: Hapus bagian bayangan yang overlap dengan objek lain

## Contoh Kasus Nyata (Step-by-Step)

1. **Siapkan scene isometric** — Ground tile + 1 objek (misal tiang/totem)
2. **Tentukan arah bayangan** — Cahaya dari NW, bayangan jatuh ke SE
3. **Buat layer Shadow** — Layer baru di atas ground, nama "Shadow"
4. **Gambar base shadow** — Diamond gelap di posisi kaki objek, warna hitam
5. **Proyeksikan shadow** — Geser diamond ke SE sejauh 16 px (tinggi objek / 2)
6. **Transform shadow** — Stretch horizontal sesuai sudut cahaya (skew 45°)
7. **Set opacity 40%** — Bayangan tidak boleh full hitam
8. **Blur tepi** — Haluskan tepi bayangan dengan anti-alias manual
9. **Uji dengan objek kedua** — Buat objek lebih tinggi, bayangan lebih jauh
10. **Final** — Group semua shadow layer untuk kontrol opacity global
