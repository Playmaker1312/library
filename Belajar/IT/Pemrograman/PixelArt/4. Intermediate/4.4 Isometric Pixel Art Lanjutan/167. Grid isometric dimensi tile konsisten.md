# 167. Grid Isometric Dimensi Tile Konsisten

## Definisi Singkat
Grid isometric dengan dimensi tile konsisten adalah sistem grid 2.5D di mana setiap tile memiliki ukuran tetap (lebar, tinggi, depth) yang seragam, menciptakan ilusi kedalaman 3D dalam ruang 2D.

## Analogi
Seperti paving block di taman — setiap batu memiliki ukuran sama sehingga pola lantai rapi dan mudah diprediksi saat diperluas.

## Poin-Poin Penting
- Dimensi tile isometric umum: lebar 2x tinggi (misal 64x32 px) untuk ratio 2:1
- Tinggi vertikal (Z-axis) harus konsisten antar tile agar tidak terlihat melayang
- Gunakan snapping grid dengan angle 26.565° (atan(0.5)) untuk garis isometric
- Tilemap isometric menggunakan koordinat Cartesian yang dikonversi ke screen space
- Rumus konversi: screenX = (tileX - tileY) * tileW/2, screenY = (tileX + tileY) * tileH/2

## Shortcut & Fitur Aseprite
- **Grid Settings (Ctrl+Shift+G)**: Atur grid size dengan lebar 2x tinggi (misal 32x16) untuk panduan isometric
- **Pixel Grid (View > Grid)**: Aktifkan grid overlay untuk presisi pixel
- **Symmetry Mode**: Gunakan untuk mirror objek isometric secara horizontal
- **Tool: Shading (Shift+D)**: Membantu gradasi bayangan di permukaan tile

## Contoh Kasus Nyata (Step-by-Step)

1. **Setup dokumen 128x128 px** — Buat canvas baru dengan resolusi cukup untuk 2x2 tile
2. **Grid Settings (Ctrl+Shift+G)** — Set grid width 32, height 16 untuk tile 2:1
3. **Gambar diamond tile pertama** — Buat selection diamond (32x16) di tengah grid
4. **Fill base color** — Isi dengan warna abu-abu terang (misal #B0B0B0)
5. **Buat edge tile** — Tambah garis tepi kiri dan kanan dengan warna lebih gelap (#808080)
6. **Clone tile ke posisi lain** — Copy tile ke grid tetangga (offset 32px horizontal, 16px vertikal)
7. **Verifikasi konsistensi** — Pastikan tidak ada gap atau overlap antar tile
8. **Simpan sebagai tile template** — Export tile sebagai file .aseprite untuk reuse
