# 54. Group Layer

## Definisi Singkat
Group layer adalah folder yang menampung beberapa layer sekaligus, memudahkan pengorganisasian proyek kompleks.

## Analogi
Seperti map folder di komputer — kamu bisa mengelompokkan semua layer karakter dalam satu grup, semua layer latar di grup lain.

## Poin-Poin Penting
- Grup bisa di-*collapse* (ciutkan) untuk menghemat ruang panel
- Opacity dan blending mode grup memengaruhi semua layer di dalamnya
- Grup bisa bersarang (grup di dalam grup)

## Shortcut & Fitur Aseprite
- **New Group**: klik folder icon di panel Layers
- **Collapse/Expand**: klik segitiga di samping nama grup

## Contoh Kasus Nyata (Step-by-Step)
1. Buat grup bernama "Karakter" — klik ikon **New Group**.
2. Di dalam grup, buat layer "Body", "Baju", "Rambut".
3. Buat grup lain "Latar" — buat layer "Langit", "Tanah", "Pohon".
4. Klik segitiga di samping grup untuk menciutkan/memperluas.
5. Pindahkan seluruh grup "Karakter" ke atas grup "Latar" untuk mengatur urutan.
6. Atur opacity grup "Latar" ke 80% untuk efek kabur.
