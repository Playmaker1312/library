# 50. Membuat, Mengganti Nama, Menghapus Layer

## Definisi Singkat
Operasi dasar mengelola layer: membuat layer baru, memberi nama yang deskriptif, dan menghapus layer yang tidak diperlukan.

## Analogi
Seperti menambahkan, memberi label, atau membuang lembar kertas transparan di tumpukan gambar.

## Poin-Poin Penting
- Nama layer yang jelas membantu navigasi proyek kompleks
- Layer yang dihapus tidak bisa dikembalikan (kecuali Undo)
- Bisa mengatur warna label layer untuk kategorisasi visual

## Shortcut & Fitur Aseprite
- **New Layer**: Shift+N
- **Rename**: klik dua kali nama layer di panel Layers
- **Delete Layer**: Shift+Delete
- **Layer Color Tag**: klik kanan layer > Layer Color > pilih warna

## Contoh Kasus Nyata (Step-by-Step)
1. Buat proyek baru. Panel Layers ada di kanan bawah.
2. Klik **New Layer** (atau Shift+N) tiga kali untuk membuat tiga layer.
3. Klik dua kali nama "Layer 1", ketik "Latar".
4. Klik dua kali "Layer 2", ketik "Karakter".
5. Klik dua kali "Layer 3", ketik "Efek".
6. Untuk menghapus layer "Efek", klik kanan > **Delete Layer** (atau Shift+Delete).
