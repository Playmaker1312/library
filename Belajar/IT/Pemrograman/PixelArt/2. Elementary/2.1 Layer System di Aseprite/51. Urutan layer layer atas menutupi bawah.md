# 51. Urutan Layer — Layer Atas Menutupi Bawah

## Definisi Singkat
Layer yang berada di posisi atas dalam panel Layers akan tampil di depan (menutupi) layer di bawahnya. Urutan ini menentukan komposisi visual akhir.

## Analogi
Seperti tumpukan kertas gambar: kertas paling atas terlihat penuh, kertas di bawahnya hanya terlihat di bagian yang tidak tertutup.

## Poin-Poin Penting
- Layer paling atas dalam daftar = paling depan secara visual
- Area transparan pada layer atas tetap memperlihatkan layer bawah
- Urutan bisa diubah kapan saja dengan drag-and-drop

## Shortcut & Fitur Aseprite
- **Move Layer Up**: Ctrl+Shift+Page Up
- **Move Layer Down**: Ctrl+Shift+Page Down
- **Drag-and-drop** langsung di panel Layers

## Contoh Kasus Nyata (Step-by-Step)
1. Buat tiga layer: "Langit" (bawah), "Gunung" (tengah), "Awan" (atas).
2. Gambar persegi panjang biru di layer Langit.
3. Gambar segitiga hijau di layer Gunung.
4. Gambar lingkaran putih di layer Awan.
5. Hasil: awan paling depan, gunung di tengah, langit di belakang.
6. Seret "Gunung" ke atas "Awan" — sekarang gunung menutupi awan.
