# 96. Padding Spacing Hindari Bleeding

## Definisi Singkat
Bleeding adalah artefak visual di mana pixel dari frame/sprite tetangga merembes ke tepi frame saat dirender di game engine, menyebabkan garis atau warna asing di pinggir sprite. Padding dan spacing adalah solusi untuk mencegahnya.

## Analogi
Seperti spidol yang bleed ke kertas tetangga saat mewarnai—kamu perlu jarak antar gambar agar tidak saling ternoda.

## Poin-Penting
- **Bleeding cause**: GPU menggunakan bilinear filtering (interpolasi warna) di tepi texture. Pixel frame A tercampur dengan pixel frame B yang bersebelahan.
- **Spacing**: jarak kosong (transparan) antar frame di sprite sheet. Minimal 1 pixel, ideal 2-4 pixel. Kosong = tidak ada pixel, jadi GPU tidak punya data untuk blend.
- **Padding**: ruang di dalam frame (bukan antar frame). Trim padding menambah pixel transparan di sekeliling sprite di setiap frame.
- **Extrude**: mode di Aseprite yang meng-copy pixel tepi sprite ke area padding (mencegah outline tipis saat filter). Lebih baik pakai spacing kosong.
- **Saat Trim diaktifkan**: Aseprite memotong area transparan, lalu menambah padding otomatis—ini yang paling aman.
- **Fix di engine**: matikan bilinear filter di engine jika kamu suka pixel art sharp (point filtering). Tapi bleeding masih bisa terjadi di mipmap.

## Shortcut & Fitur Aseprite
- **Export Sprite Sheet > Spacing**: atur jarak antar frame di tab Advanced
- **Border**: atur border (jarak dari tepi sheet ke frame pertama)
- **Extrude**: opsi di Export Sprite Sheet > Advanced > Extrude (copy pixel tepi)
- **Trim padding**: di Export Sprite Sheet > Trim > "Trim padding" berapa pixel yang dipertahankan setelah trim

## Contoh Kasus Nyata (Step-by-Step)

### Atur Spacing di Export
1. **Buka Export Sprite Sheet** (Ctrl+Shift+X).
2. Tab **Advanced**:
   - **Spacing**: isi **2** (2 pixel jarak antar frame).
   - **Border**: **0**.
   - **Extrude**: **unchecked** (kita pakai spacing saja).
3. Tab **Sprite**:
   - Layout: "Horizontal Strip".
4. **Export**: hasil sprite sheet 128x32 untuk 4 frame 32x32 menjadi:
   - Frame 1: pixel 0-31.
   - Gap 2: pixel 32-33 (transparan).
   - Frame 2: pixel 34-65.
   - Dan seterusnya.

### Solusi Alternatif: Trim + Padding
1. Di Export Sprite Sheet, centang **Trim**.
2. Set **Trim padding**: **1** (tambah 1 pixel transparan di tiap sisi sprite).
3. **Spacing**: **0** (padding sudah cukup).
4. Export: setiap sprite sekarang punya 1 pixel transparan di semua sisinya, mencegah bleeding tanpa spacing antar frame.
5. **Keunggulan**: lebih hemat ruang daripada spacing, tapi pastikan game engine menghormati padding ini.

### Testing Bleeding
1. Export sprite sheet dengan spacing 0.
2. Import ke game engine dengan bilinear filter.
3. Jika ada garis berwarna di tepi sprite: kamu kena bleeding. Tambah spacing jadi 2 pixel atau set texture filter ke "Nearest" (point filtering).
