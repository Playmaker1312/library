# 73. Jenis Dithering — Checkerboard, Ordered, Freehand

## Definisi Singkat
Tiga pendekatan dithering: checkerboard (pola kotak-kotak teratur), ordered (pola matriks terstruktur), dan freehand (manual artistik).

## Analogi
- Checkerboard: seperti papan catur mini
- Ordered: seperti pola ubin lantai dengan variasi
- Freehand: seperti titik-titik abstrak yang diletakkan artistik

## Poin-Poin Penting
- **Checkerboard**: pola 50% — pixel A dan B berselang seling (paling sederhana)
- **Ordered**: pola matriks (2x2, 4x4) dengan rasio tertentu 25%, 50%, 75%
- **Freehand**: pixel ditempatkan secara manual, tidak mengikuti pola kaku — hasil lebih organik
- Pilih jenis dithering berdasarkan efek visual yang diinginkan

## Shortcut & Fitur Aseprite
- **Dithering presets**: di brush dropdown, pilih "Dithering" lalu pilih pola
- **Freehand**: Pencil Tool (B) dengan size 1px, gambar manual
- **Ordered dithering**: bisa menggunakan script atau manual pattern

## Contoh Kasus Nyata (Step-by-Step)
1. Buat 3 kotak 16x16 pixel.
2. **Kotak 1 (Checkerboard)**: isi dengan pola selang-seling warna A dan B (pola catur).
3. **Kotak 2 (Ordered 25%)**: buat pola 2x2 — 1 pixel A, 3 pixel B, ulang.
4. **Kotak 3 (Freehand)**: letakkan pixel A secara acak di area kotak B, distribusi tidak merata.
5. Bandingkan tekstur ketiganya.
6. Checkerboard terlihat paling teratur, freehand paling organik.
