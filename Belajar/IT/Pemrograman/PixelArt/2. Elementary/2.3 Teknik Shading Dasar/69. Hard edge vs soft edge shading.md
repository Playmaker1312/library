# 69. Hard Edge vs Soft Edge Shading

## Definisi Singkat
Hard edge shading menggunakan batas tegas antar warna bayangan, sedangkan soft edge menggunakan transisi bertahap (dithering atau banding).

## Analogi
- Hard edge: seperti poster art — potongan warna tajam
- Soft edge: seperti lukisan cat minyak — tepi bayangan kabur dan menyatu

## Poin-Poin Penting
- Hard edge cocok: resolusi kecil, pixel art retro, cel shading
- Soft edge cocok: resolusi besar, gaya realistis, lingkungan atmosferik
- Pilih teknik berdasarkan resolusi sprite dan gaya artistik
- Bisa menggabungkan keduanya: hard edge untuk bayangan utama, soft edge untuk transisi halus

## Shortcut & Fitur Aseprite
- **Hard edge**: cukup Pencil Tool (B) dengan warna solid
- **Soft edge**: manual dithering atau filter blur sederhana
- **Opacity slider**: untuk transisi lembut di layer terpisah

## Contoh Kasus Nyata (Step-by-Step)
1. Buat sprite wajah karakter.
2. **Hard edge**: gambar bayangan dengan batas tegas — shadow satu warna solid bertemu midtone langsung tanpa transisi.
3. **Soft edge**: di layer terpisah, tambah 1-2 warna transisi antara shadow dan midtone.
4. Bandingkan tampilan keduanya.
5. Hard edge terlihat retro/tegas, soft edge terlihat lebih halus/realistis.
6. Pilih sesuai gaya yang diinginkan.
