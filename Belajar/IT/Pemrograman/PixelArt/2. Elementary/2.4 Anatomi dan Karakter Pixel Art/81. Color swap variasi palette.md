# 81. Color Swap Variasi Palet

## Definisi Singkat
Color swap adalah teknik mengganti palet warna karakter secara cepat untuk membuat variasi (misal: karakter merah jadi biru, musuh ungu jadi hijau) tanpa menggambar ulang. Ini penting untuk penghematan waktu dan konsistensi ukuran file.

## Analogi
Seperti mewarnai ulang gambar yang sama dengan pensil warna berbeda—sketsa tetap, hanya paletnya yang diganti.

## Poin-Poin Penting
- **Indexed Color mode**: mode warna yang memungkinkan color swapping mudah karena tiap warna memiliki index palet tetap.
- **Palet sharing**: satu palet global untuk semua karakter memudahkan color swapping.
- **Mapping color**: catat index warna mana yang diganti (misal: index 3 = rambut hitam diganti index 3 versi coklat).
- **Jangan gunakan Replace Color sembarangan** jika beberapa karakter sharing palet—bisa kena unintended.
- **Variasi umum**: palet musuh (merah/ungu), palet ally (biru/hijau), palet NPC (kuning/coklat).
- **Hue shifting**: saat swap, jaga kontras—jangan ganti shadow dengan warna yang sama terangnya dengan base.

## Shortcut & Fitur Aseprite
- **Replace Color**: ganti satu warna dengan warna lain, **Shortcut:** Shift+R (default) atau via Sprite > Color > Replace Color
- **Remap Palette**: ganti urutan/re-map seluruh palet, via Sprite > Color > Remap Palette
- **Palette Slider**: geser hue/saturation seluruh palet, via Sprite > Color > Palette Sliders (cepat untuk variasi massal)
- **Export Palette**: simpan palet untuk digunakan di sprite lain, **File > Export > Save Palette**

## Contoh Kasus Nyata (Step-by-Step)

### Color Swap Karakter Petualang
1. Buka file karakter dengan sprite selesai.
2. **Cek mode warna**: pastikan sprite dalam Indexed Color (Sprite > Color Mode > Indexed).
3. **Buka Palet**: Windows > Palette. Lihat daftar warna terbatas.
4. **Identifikasi index**:
   - Index 0: Transparan
   - Index 1: Outline hitam
   - Index 2: Kulit
   - Index 3: Rambut coklat
   - Index 4: Baju biru
   - Index 5: Celana abu-abu
5. **Swap baju** (biru jadi merah):
   - Buka Replace Color (Sprite > Color > Replace Color).
   - Pilih "From" = warna biru (index 4).
   - Pilih "To" = warna merah baru.
   - Klik OK. Semua pixel baju biru jadi merah.
6. **Swap rambut** (coklat jadi pirang):
   - Replace color index 3 dengan kuning pirang.
7. **Efek samping**: periksa apakah ada bagian kulit yang kena replace—jika tidak sengaja, undo (Ctrl+Z).
8. **Simpan variasi**: File > Save As dengan nama baru ("karakter_merah.aseprite").

### Tips Palette Slider untuk Variasi Cepat
- Buka Palette Sliders (Sprite > Color > Palette Sliders).
- Geser Hue slider untuk mengubah warna seluruh sprite secara instan.
- Geser Saturation untuk membuat versi desaturasi (karakter bayangan/undead).
- Kombinasikan dengan Replace Color untuk kendali lebih.
