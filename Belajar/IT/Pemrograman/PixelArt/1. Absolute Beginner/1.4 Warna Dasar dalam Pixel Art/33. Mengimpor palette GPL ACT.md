# 33. Mengimpor Palette (GPL, ACT)

## Definisi Singkat
Mengimpor palette berarti memuat file palette dari format eksternal seperti .gpl (GIMP) atau .act (Adobe Color Table) ke dalam Aseprite. Ini memungkinkan Anda menggunakan palette dari komunitas atau software lain.

## Analogi
Seperti meminjam set pensil warna punya teman. Teman menyimpannya di kotak merek A, Anda buka kotaknya dan pindahkan ke kotak merek B — isinya tetap sama, hanya kemasannya yang berbeda.

## Poin-Poin Penting
- **.gpl**: format teks GIMP, bisa dibuka dengan notepad, berisi nama dan hex warna.
- **.act**: format biner Adobe, digunakan di Photoshop, maksimal 256 warna.
- **.ase**: format native Aseprite, menyimpan metadata tambahan.
- Palette komunitas tersedia gratis di Lospec, Pixilart, dan itch.io.
- Pastikan format palette kompatibel — Aseprite mendukung .gpl, .act, .ase, .png, .bmp, .col, .hex.

## Shortcut & Fitur Aseprite
- **Import Palette**: Palette panel → Import Palette → pilih file
- **Drag & Drop**: seret file .gpl/.act langsung ke jendela Aseprite
- **Palette dari Gambar**: File → Open → buka PNG → lalu Palette → From Sprite

## Contoh Kasus Nyata (Step-by-Step)
1. Buka browser, kunjungi lospec.com/palettes.
2. Pilih palette gratis seperti "Bubblegum 16" — unduh dalam format .gpl atau .png.
3. Buka Aseprite, buka Window → Palette (`F4`).
4. Klik kanan Palette panel → **Import Palette**.
5. Cari file .gpl yang diunduh, pilih, klik Open.
6. Palette akan langsung menggantikan palette aktif.
7. Buat sprite baru dan gambar dengan palette impor tersebut.
8. Alternatif: seret file PNG palette langsung ke canvas Aseprite, lalu Palette → From Sprite.
