# 29. Color Palette (Kumpulan Warna Terbatas)

## Definisi Singkat
Color palette adalah kumpulan warna tetap yang digunakan dalam sebuah pixel art. Alih-alih memilih dari 16 juta warna, palette membatasi jumlah warna — bisa 4, 8, 16, 32, atau 256 — untuk menciptakan konsistensi visual.

## Analogi
Seperti satu set pensil warna dengan 16 warna tertentu. Berapa pun gambar yang dibuat, Anda hanya bisa mewarnai dengan 16 pensil itu. Ini memaksa kreativitas dan memastikan semua warna dalam gambar saling cocok.

## Poin-Poin Penting
- Palette memaksa pemilihan warna secara sengaja, tidak asal pilih.
- Konsistensi warna: semua sprite dalam satu game terlihat harmonis.
- File palette berekstensi .ase (Aseprite), .gpl (GIMP), .act (Adobe Color Table).
- Palette yang baik memiliki transisi value (terang-gelap) untuk setiap hue.
- Ukuran ideal pixel art retro: 8, 16, 32, atau 256 warna.

## Shortcut & Fitur Aseprite
- **Palette Panel**: Window → Palette, **Shortcut:** `F4`
- **New Palette**: klik kanan di Palette panel → New Palette
- **Sort Palette**: di Palette panel → sort icon → pilih sort by Hue, Lightness, dll
- **Edit Color**: double-click swatch warna di Palette untuk edit

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite, buka Window → Palette (atau tekan `F4`).
2. Palette default akan muncul dengan deretan warna standar.
3. Klik kanan area kosong di Palette panel → **New Palette**.
4. Beri nama "My First Palette" dan atur jumlah warna ke 16.
5. Double-click setiap swatch untuk mengganti warna sesuka hati.
6. Gunakan palette ini saat menggambar — jangan pakai warna di luar palette.
