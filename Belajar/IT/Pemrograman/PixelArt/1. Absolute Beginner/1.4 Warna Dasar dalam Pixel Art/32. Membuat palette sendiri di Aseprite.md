# 32. Membuat Palette Sendiri di Aseprite

## Definisi Singkat
Membuat palette sendiri berarti menyusun kumpulan warna kustom di Aseprite untuk digunakan dalam proyek pixel art. Palette pribadi mencerminkan gaya artistik Anda dan memastikan konsistensi di seluruh sprite.

## Analogi
Seperti menyusun set pensil gambar pribadi. Anda pilih 12 pensil warna favorit, bukan asal beli paket. Semua gambar yang Anda buat dengan set ini akan memiliki "tanda tangan" warna khas Anda.

## Poin-Poin Penting
- Pilih warna-warna yang saling melengkapi — jangan asal memilih.
- Sertakan ramping value (terang ke gelap) untuk setiap hue utama.
- Palette ideal: 8-32 warna untuk pixel art modern.
- Simpan palette sebagai file .ase (native Aseprite) agar mudah dibagikan.
- Gunakan monokrom, komplementer, atau triad sebagai skema warna dasar.

## Shortcut & Fitur Aseprite
- **Add Color**: di Palette panel → klik **+** (Add Color)
- **Remove Color**: drag warna ke ikon tempat sampah atau klik kanan → Delete
- **Move Color**: drag-drop swatch untuk mengurutkan
- **Save Palette**: klik kanan Palette panel → Save Palette → pilih format .ase
- **Palette from Current Sprite**: Palette panel → Palette → **From Sprite**

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite, buat file baru 16x16.
2. Buka Window → Palette (`F4`). Palette default akan muncul.
3. Kosongkan palette: pilih semua swatch → klik kanan → Delete.
4. Pilih warna utama (misal: biru laut #1a434b) — double-click swatch kosong pertama, masukkan hex.
5. Buat 4 variasi value biru: #1a434b (paling gelap), #245b5e, #3c7873, #5b9a8a, #8ec1ad (paling terang).
6. Tambahkan warna aksen: emas #f5c542 dan #e89f2e.
7. Klik kanan Palette panel → **Save Palette** → simpan sebagai "Palette Laut.ase".
8. Palette siap digunakan kapan saja — muat ulang via **Import Palette**.
