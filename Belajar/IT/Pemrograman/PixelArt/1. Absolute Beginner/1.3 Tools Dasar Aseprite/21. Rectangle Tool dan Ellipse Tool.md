# 21. Rectangle Tool dan Ellipse Tool

## Definisi Singkat
Rectangle Tool menggambar kotak atau persegi panjang, Ellipse Tool menggambar lingkaran atau elips. Dalam pixel art, alat ini membuat bentuk geometris dasar dengan cepat tanpa menggambar manual piksel per piksel.

## Analogi
Seperti cetakan kue — Anda tinggal tekan, bentuk jadi. Tapi setelah jadi, tetap perlu sentuhan tangan untuk memperhalus.

## Poin-Poin Penting
- Hanya gunakan untuk bentuk dasar — hasil akhir tetap perlu diedit manual
- Tahan Shift untuk proporsi sempurna: persegi (Rectangle) atau lingkaran (Ellipse)
- Mode "Filled" langsung mengisi bentuk dengan warna; mode "Empty" hanya outline
- Hasil Ellipse Tool sering perlu diperbaiki manual agar terlihat lebih organik
- Tools ini menghasilkan anti-aliasing jika tidak diatur — nonaktifkan di options bar

## Shortcut & Fitur Aseprite
- **Rectangle Tool**: pilih alat kotak, **Shortcut:** U
- **Ellipse Tool**: pilih alat lingkaran, **Shortcut:** Shift+U
- **Toggle Filled/Empty**: atur di options bar sebelum menggambar

## Contoh Kasus Nyata (Step-by-Step)
1. Pilih Rectangle Tool (U), atur ke mode Empty (outline)
2. Klik dan drag di canvas — kotak 10×10 piksel
3. Tahan Shift, drag lagi — kotak menjadi persegi sempurna
4. Pilih Ellipse Tool (Shift+U), mode Filled
5. Gambar lingkaran diameter 10 piksel
6. Zoom 1600%, perbaiki tepi lingkaran dengan Pencil Tool agar lebih rapi
