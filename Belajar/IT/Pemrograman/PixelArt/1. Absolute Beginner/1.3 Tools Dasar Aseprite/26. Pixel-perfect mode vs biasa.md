# 26. Pixel-perfect Mode vs Biasa

## Definisi Singkat
Pixel-perfect mode adalah fitur di Aseprite yang secara otomatis mencegah celah (gap) saat menggambar garis diagonal atau kurva. Mode biasa menggambar persis seperti input mouse tanpa koreksi, yang bisa menghasilkan garis diagonal dengan celah tidak rapi.

## Analogi
Pixel-perfect seperti berjalan di atas batu pijakan — setiap langkah otomatis mendarat di batu berikutnya tanpa celah. Mode biasa seperti berjalan tanpa melihat — bisa ada langkah yang kelebihan atau kekurangan.

## Poin-Poin Penting
- Pixel-perfect mencegah "double pixels" dan celah pada garis diagonal 45°
- Wajib diaktifkan saat membuat outline karakter miring atau kurva
- Mode biasa berguna untuk membuat tekstur atau efek kasar (jagged) sengaja
- Pixel-perfect bisa diaktifkan di Pencil, Line, Rectangle, dan Ellipse Tools
- Tidak ada shortcut default — aktifkan via options bar (tombol ikon magnet)

## Shortcut & Fitur Aseprite
- **Pixel-perfect toggle**: tombol ikon magnet di options bar (tidak ada shortcut default)
- **Bisa dibuat shortcut**: Edit → Keyboard Shortcuts → cari "Pixel-perfect" → assign shortcut sendiri

## Contoh Kasus Nyata (Step-by-Step)
1. Pilih Pencil Tool, pastikan Pixel-perfect **nonaktif**
2. Gambar garis diagonal kiri bawah ke kanan atas — perhatikan celah/cabang
3. Aktifkan Pixel-perfect (klik ikon magnet di options bar)
4. Gambar garis diagonal yang sama — hasilnya mulus, 1 piksel rapi tanpa celah
5. Gambar lingkaran 10×10 dengan Ellipse Tool di kedua mode
6. Bandingkan: Pixel-perfect menghasilkan lingkaran lebih rapi dan konsisten
