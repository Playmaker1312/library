# 4. Mengenal Berbagai Gaya Pixel Art 8-bit, 16-bit, 32-bit

## Definisi Singkat
8-bit, 16-bit, dan 32-bit merujuk pada era konsol game yang memengaruhi resolusi sprite, kedalaman warna, dan jumlah piksel. Istilah ini telah menjadi gaya artistik yang bisa dipilih sesuai kebutuhan.

## Analogi
Seperti perbedaan antara kamera VGA (8-bit) vs kamera 4K (32-bit) — makin tinggi bit, makin detail dan warna yang bisa ditampung.

## Poin-Poin Penting
- **8-bit (Nintendo NES)**: resolusi 16×16 – 32×32, palet maksimal 256 warna (4 palet × 4 warna), detail minimal
- **16-bit (SNES, Sega Genesis)**: resolusi 32×32 – 64×64, palet lebih kaya (32.768 warna), shading lebih halus
- **32-bit (PlayStation, GBA)**: resolusi 64×64 – 128×128, warna penuh (16,7 juta), detail tinggi, mulai menggunakan efek transparansi

## Shortcut & Fitur Aseprite
- **Sprite Size**: ubah resolusi sprite, **Shortcut:** Ctrl+R
- **Color Mode**: pilih Indexed untuk meniru palet terbatas 8-bit, **Shortcut:** ada di menu New File

## Contoh Kasus Nyata (Step-by-Step)
1. Buat tiga file baru: 16×16 (8-bit), 48×48 (16-bit), 96×96 (32-bit)
2. Gambar karakter sederhana (misal kotak dengan dua mata) di masing-masing file
3. Di file 16×16: hanya gunakan 4 warna
4. Di file 48×48: gunakan 16 warna dengan bayangan sederhana
5. Di file 96×96: gunakan warna tak terbatas dengan highlight dan shadow detail
6. Bandingkan ketiganya secara berdampingan
