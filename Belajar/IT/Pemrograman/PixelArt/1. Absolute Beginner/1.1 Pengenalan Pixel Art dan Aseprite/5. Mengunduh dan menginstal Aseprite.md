# 5. Mengunduh dan Menginstal Aseprite

## Definisi Singkat
Aseprite adalah editor pixel art dan animasi 2D berbayar yang bisa dibeli dari situs resmi atau dikompilasi sendiri dari source code di GitHub. Aseprite tersedia untuk Windows, macOS, dan Linux.

## Analogi
Seperti membeli satu set pensil khusus pixel art — Anda bisa mendapatkannya secara legal dari toko resmi atau merakitnya sendiri dari bahan mentah.

## Poin-Poin Penting
- Harga lisensi sekitar $19.99 USD (sekali bayar)
- Bisa dikompilasi gratis dari GitHub jika mau (dengan proses build sendiri)
- Tersedia juga di Steam (sering diskon)
- Versi demo gratis bisa di-download dengan batasan (tidak bisa menyimpan, tidak bisa ekspor)

## Shortcut & Fitur Aseprite
- **Command Palette**: akses cepat semua perintah, **Shortcut:** Ctrl+Shift+P
- **Preferences**: pengaturan tema dan shortcut, **Shortcut:** Ctrl+K

## Contoh Kasus Nyata (Step-by-Step)
1. Buka browser dan kunjungi https://aseprite.org
2. Klik tombol "Download" atau "Buy Now"
3. Pilih versi sesuai OS (Windows → .exe installer atau .zip portable)
4. Jalankan installer atau ekstrak ZIP
5. Buka Aseprite, masukkan lisensi jika dibeli (File → Preferences → License)
6. Pastikan versi terbaru (cek menu Help → About)
