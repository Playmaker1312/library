# 3. Perbedaan Pixel Art dengan Seni Digital Biasa

## Definisi Singkat
Pixel art dibangun piksel per piksel secara manual pada resolusi rendah, sedangkan seni digital biasa menggunakan kanvas resolusi tinggi dengan goresan kuas bebas. Perbedaan utama ada pada kontrol manual setiap piksel vs penggunaan alat brush dan filter.

## Analogi
Pixel art seperti merangkai batu bata satu per satu — seni digital biasa seperti melukis dengan kuas lebar di atas kanvas raksasa.

## Poin-Poin Penting
- Pixel art sengaja membatasi resolusi; seni digital biasa menggunakan resolusi setinggi mungkin
- Pixel art tidak menggunakan anti-aliasing otomatis; bayangan dan gradasi dibuat manual via dithering
- Pixel art menggunakan palet warna terbatas dan eksplisit; seni digital bebas menggunakan jutaan warna
- Pixel art mengandalkan garis lurus 45° atau 90°; seni digital bebas melengkung

## Shortcut & Fitur Aseprite
- **Pencil Tool**: satu-satunya alat utama untuk pixel art murni, **Shortcut:** B
- **Brush Tool**: tidak disarankan untuk pixel art karena menghasilkan anti-aliasing otomatis, **Shortcut:** Shift+B

## Contoh Kasus Nyata (Step-by-Step)
1. Buat dua file: satu 32×32 px, satu lagi 512×512 px
2. Gambar lingkaran di file besar menggunakan Brush Tool biasa
3. Gambar lingkaran di file kecil menggunakan Pencil Tool
4. Zoom 1600% pada kedua file
5. Amati: file kecil akan menunjukkan tepi kotak-kotak (piksel), file besar menunjukkan gradasi halus (anti-aliasing)
