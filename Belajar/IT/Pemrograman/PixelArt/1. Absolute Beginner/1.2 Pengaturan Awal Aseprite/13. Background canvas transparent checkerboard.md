# 13. Background Canvas: Transparent & Checkerboard

## Definisi Singkat
Canvas transparan memungkinkan sprite berdiri sendiri tanpa latar belakang. Aseprite menampilkan area transparan sebagai pola checkerboard (kotak abu-abu-putih) agar mudah dibedakan dari area yang sudah digambar.

## Analogi
Seperti kertas kalkir — area kosong tembus pandang, dan checkerboard adalah alas meja yang membantu Anda melihat bagian mana yang masih kosong.

## Poin-Poin Penting
- Checkerboard hanya tampilan editor; tidak ikut tersimpan saat ekspor PNG/GIF
- Warna checkerboard bisa diubah di Preferences (biru, abu-abu, dll.)
- File dengan background Transparent memiliki channel Alpha
- File dengan background White/Black langsung solid tanpa transparansi
- Gunakan transparan untuk sprite; gunakan solid untuk ilustrasi berdiri sendiri

## Shortcut & Fitur Aseprite
- **New File > Background**: pilih Transparent untuk sprite
- **Preferences > Editor > Checkered Background**: ubah warna checkerboard
- **Layer Properties**: atur opacity dan blend mode layer

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru dengan Background: Transparent (32×32 px)
2. Gambar lingkaran merah di tengah (biarkan tepi area kosong)
3. Area kosong akan menunjukkan checkerboard abu-abu-putih
4. Simpan sebagai PNG — buka di viewer foto
5. Lingkaran merah akan tampil tanpa latar belakang (transparan)
6. Coba buat file dengan Background: White — area putih tidak transparan saat diekspor
