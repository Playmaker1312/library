# 12. Grid dan Cara Mengaktifkannya

## Definisi Singkat
Grid adalah garis bantu yang menampilkan batas antar piksel pada canvas. Grid sangat penting dalam pixel art untuk memastikan setiap piksel berada di posisi yang tepat, terutama saat zoom rendah.

## Analogi
Seperti kertas milimeter blok — garis bantu membuat Anda bisa menempatkan titik dengan presisi.

## Poin-Poin Penting
- Grid membagi canvas menjadi kotak-kotak piksel
- Aktifkan grid saat zoom rendah (400% ke bawah) untuk melihat batas piksel
- Grid bisa dikustomisasi warna dan opacity-nya
- Pixel grid (garis antar setiap piksel) aktif otomatis di zoom tinggi
- Nonaktifkan grid saat preview untuk melihat hasil tanpa gangguan

## Shortcut & Fitur Aseprite
- **Toggle Grid**: aktifkan/nonaktifkan grid, **Shortcut:** Ctrl+Shift+G
- **Grid Settings**: atur warna dan opacity grid, **Shortcut:** tersedia di menu View → Grid Settings
- **Pixel Grid**: selalu aktif di zoom tinggi (tidak bisa dimatikan)

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file 16×16 px, zoom ke 800%
2. Tekan Ctrl+Shift+G untuk mengaktifkan grid
3. Perhatikan garis tipis yang membatasi setiap piksel
4. Zoom out ke 200% — grid mungkin hilang; tekan Ctrl+Shift+G lagi
5. Buka View → Grid Settings, ubah warna grid menjadi merah terang
6. Nonaktifkan grid (Ctrl+Shift+G) untuk melihat hasil mulus
