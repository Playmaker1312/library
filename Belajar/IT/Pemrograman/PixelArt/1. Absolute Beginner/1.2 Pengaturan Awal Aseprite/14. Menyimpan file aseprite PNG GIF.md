# 14. Menyimpan File: Aseprite, PNG, GIF

## Definisi Singkat
Aseprite memiliki format native (.aseprite atau .ase) yang menyimpan semua layer, frame, dan palet. Untuk publikasi, ekspor ke PNG (gambar statis dengan transparansi) atau GIF (animasi sederhana).

## Analogi
Seperti file Photoshop (.psd) untuk editing vs JPEG untuk publikasi — simpan di format native untuk diedit lagi, ekspor ke format standar untuk dibagikan.

## Poin-Poin Penting
- **.ase/.aseprite**: format native — simpan selalu untuk backup editing
- **PNG**: gambar statis, mendukung transparansi, lossless, ukuran kecil
- **GIF**: animasi, maksimal 256 warna, ukuran lebih besar, mendukung transparansi
- Jangan gunakan JPG untuk pixel art — kompresi merusak tepi piksel
- GIF hanya disarankan untuk animasi pendek dengan palet terbatas

## Shortcut & Fitur Aseprite
- **Save**: simpan sebagai .aseprite, **Shortcut:** Ctrl+S
- **Save As**: simpan dengan format berbeda, **Shortcut:** Ctrl+Shift+S
- **Export**: ekspor ke PNG/GIF/Sprite Sheet, **Shortcut:** Ctrl+E

## Contoh Kasus Nyata (Step-by-Step)
1. Gambar sprite sederhana dengan 2 frame animasi
2. Tekan Ctrl+S, pilih format .aseprite, simpan
3. Tekan Ctrl+E, pilih PNG — hanya frame aktif yang tersimpan
4. Tekan Ctrl+E lagi, pilih GIF — centang "Loop" agar animasi berulang
5. Buka PNG (statis) dan GIF (animasi) di viewer
6. Tutup Aseprite, buka file .aseprite lagi — semua layer dan frame masih utuh
