# 9. Membuat File Baru: Ukuran Canvas, Color Mode

## Definisi Singkat
Membuat file baru adalah langkah awal setiap proyek pixel art. Anda harus memilih ukuran canvas (lebar × tinggi dalam piksel) dan color mode (RGB, Indexed, atau Grayscale) yang sesuai dengan kebutuhan.

## Analogi
Seperti memilih ukuran buku sketsa dan jenis kertas sebelum mulai menggambar — ukuran menentukan detail, jenis kertas menentukan alat yang bisa dipakai.

## Poin-Poin Penting
- Ukuran pixel art umum: 16×16 (icon), 32×32 (sprite kecil), 64×64 (karakter), 128×128 (detail)
- Pilih ukuran yang TEPAT sejak awal — memperbesar sprite nanti akan merusak ketajaman
- Color mode RGB untuk fleksibilitas penuh warna
- Color mode Indexed untuk palet terbatas (seperti gaya 8-bit)
- Background: pilih Transparent untuk sprite, White/Black untuk preview cepat

## Shortcut & Fitur Aseprite
- **New File**: dialog pembuatan file baru, **Shortcut:** Ctrl+N
- **Sprite Size**: ubah ukuran setelah file dibuat, **Shortcut:** Ctrl+R

## Contoh Kasus Nyata (Step-by-Step)
1. Tekan Ctrl+N untuk membuka dialog New File
2. Atur Width: 32, Height: 32
3. Color Mode: RGB, Background: Transparent
4. Pixel Ratio: 1:1 (default untuk pixel art murni)
5. Klik OK
6. Canvas 32×32 transparan akan muncul — siap digambar
