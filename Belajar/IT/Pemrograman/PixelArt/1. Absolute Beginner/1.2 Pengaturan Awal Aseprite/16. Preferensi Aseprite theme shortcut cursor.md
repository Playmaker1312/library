# 16. Preferensi Aseprite: Theme, Shortcut, Cursor

## Definisi Singkat
Preferensi Aseprite memungkinkan Anda menyesuaikan tampilan (theme), pintasan keyboard (shortcut), dan perilaku kursor. Ini penting untuk kenyamanan kerja jangka panjang.

## Analogi
Seperti mengatur kursi dan meja kerja — posisi yang nyaman membuat Anda bisa bekerja lebih lama tanpa pegal.

## Poin-Poin Penting
- **Theme**: Aseprite memiliki tema terang (Light) dan gelap (Dark). Bisa juga custom
- **Shortcut**: semua shortcut bisa diubah sesuai keinginan (termasuk shortcut custom)
- **Cursor**: bisa diubah bentuk dan ukurannya (crosshair, circle, atau panah biasa)
- **Onion Skin**: pengaturan transparansi untuk animasi
- **Auto-save**: aktifkan untuk mencegah kehilangan pekerjaan

## Shortcut & Fitur Aseprite
- **Preferences**: buka jendela preferensi, **Shortcut:** Ctrl+K
- **Theme**: Edit → Preferences → Theme — pilih Light/Dark/System
- **Shortcut Editor**: Edit → Keyboard Shortcuts — cari dan ubah shortcut
- **Reset Default**: tombol Reset di Preferences untuk kembali ke pengaturan awal

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Preferences (Ctrl+K)
2. Di tab Theme, pilih "Dark" — klik OK, antarmuka berubah menjadi gelap
3. Buka lagi Preferences → Editor, ubah Cursor Style menjadi "Crosshair"
4. Buka Keyboard Shortcuts, cari "Pencil Tool", ubah shortcut dari B ke P
5. Aktifkan Auto-Save setiap 5 menit di tab Files
6. Klik OK, rasakan perbedaan kenyamanan — jika bingung, Reset ke default
