# 48. Memperbesar Pixel Art: Nearest Neighbor

## Definisi Singkat
Nearest Neighbor (NN) adalah algoritma interpolasi yang memperbesar gambar dengan menggandakan pixel tanpa menghaluskan tepi. Ini adalah satu-satunya cara yang benar untuk memperbesar pixel art — menjaga tepi tetap tajam dan kotak-kotak, tidak blur.

## Analogi
Seperti memperbesar foto mozaik. Setiap ubin (pixel) digandakan ukurannya — ubin merah jadi 4 ubin merah, ubin biru jadi 4 ubin biru. Hasilnya tetap kotak-kotak, tidak berubah menjadi gradasi blur.

## Poin-Poin Penting
- Nearest Neighbor menggandakan pixel dalam blok — tidak ada anti-aliasing.
- Algoritma lain (Bilinear, Bicubic, Lanczos) membuat gambar pixel art terlihat blur — JANGAN digunakan.
- Di Aseprite, export dengan scale integer (200%, 400%, 800%) agar pixel tetap kotak sempurna.
- Untuk posting media sosial: export minimal 400% (setiap pixel jadi 4x4).
- Jika scale non-integer (misal 350%), pixel akan terdistorsi — selalu gunakan scale bulat.

## Shortcut & Fitur Aseprite
- **Export Scale**: File → Export → Scale: 100%, 200%, 400%, 800%
- **Resize**: Sprite → Sprite Size → pilih **Nearest Neighbor** di dropdown Resampling
- **Resize Canvas**: Sprite → Canvas Size — tidak mengubah ukuran pixel, hanya area

## Contoh Kasus Nyata (Step-by-Step)
1. Buka sprite 16x16 yang sudah dibuat.
2. File → Export (**`Ctrl+E`**).
3. Atur **Scale** ke **400%** (1 pixel → 4x4 = 16 pixel).
4. Centang **Transparent Background**.
5. Export sebagai "sprite_400.png".
6. Bandingkan: buka file hasil export — pixel terlihat kotak-kotak besar, tajam.
7. Sekarang coba **Resize** dalam Aseprite:
   - Sprite → Sprite Size.
   - Set Width 64, Height 64.
   - Di dropdown Resampling, pilih **Nearest Neighbor** — hasilnya tajam.
   - Ulangi dengan **Bilinear** — hasilnya blur, jangan dipakai untuk pixel art.
8. Selalu gunakan Nearest Neighbor untuk memperbesar pixel art.
