# 47. Export Sprite ke PNG

## Definisi Singkat
Export sprite ke PNG adalah proses menyimpan karya pixel art ke format gambar standar yang bisa digunakan di game engine, web, atau media sosial. PNG adalah format terbaik untuk pixel art karena kompresi lossless dan dukungan transparansi.

## Analogi
Seperti mencetak foto dari kamera digital. File mentah di software (Aseprite) adalah "negatif digital" Anda — bisa diedit kapan saja. File PNG hasil export adalah "cetakan jadi" yang bisa dipajang atau dikirim ke orang lain.

## Poin-Poin Penting
- PNG: lossless, mendukung transparansi alpha, ukuran file kecil untuk pixel art.
- JPG: tidak mendukung transparansi, kompresi lossy merusak tepi pixel — HINDARI untuk pixel art.
- GIF: mendukung transparansi (1-bit: transparan/tidak), tapi terbatas 256 warna.
- Export dengan **scale 100%** untuk sprite asli, atau skala besar (400%, 800%) untuk posting ke media sosial.
- Pastikan **Transparent Background** dicentang jika ingin latar tembus pandang.

## Shortcut & Fitur Aseprite
- **Export**: File → Export atau **Shortcut:** `Ctrl+E`
- **Export Sprite Sheet**: File → Export Sprite Sheet — untuk kumpulan sprite dalam 1 file
- **Preview Export**: di dialog export, centang **Preview** untuk lihat hasil sebelum simpan

## Contoh Kasus Nyata (Step-by-Step)
1. Buka sprite yang sudah dibuat (misal: karakter 16x16).
2. File → Export (**`Ctrl+E`**).
3. Di dialog Export:
   - Pilih format **PNG**.
   - **Scale**: 100% (simpan ukuran asli) atau 400% (untuk post Instagram/Twitter).
   - Centang **Transparent Background**.
   - **Name**: "karakter_16x16.png".
4. Klik **Export**.
5. Buka file PNG di Windows Photos atau browser — periksa apakah transparansi berfungsi.
6. Untuk export banyak sprite dalam satu file: File → Export Sprite Sheet → atur tile grid.
7. Selalu simpan file .ase asli — PNG adalah hasil akhir, .ase adalah sumber yang bisa diedit ulang.
