# 128. Icon item 16x16 32x32

## Definisi Singkat
Icon item adalah representasi visual objek dalam game pada resolusi sangat kecil (16x16 atau 32x32 pixel). Setiap pixel harus bermakna karena ruang sangat terbatas.

## Analogi
Emoji 16x16 pixel di layar ponsel — bentuk kecil yang harus langsung dikenali tanpa teks, mengandalkan siluet dan warna khas.

## Poin-Poin Penting
- Mulai dengan siluet hitam pekat untuk menentukan bentuk dasar.
- Gunakan 3-5 warna per icon: base, shadow, highlight, outline.
- Hindari detail kecil — jika tidak terlihat di 100%, hapus.
- Konsistensi sudut pandang (isometrik/top-down/samping) dalam satu set.
- Outline 1px membantu icon menonjol dari background.

## Shortcut & Fitur Aseprite
- **New File**: 16x16 atau 32x32 px, **Shortcut:** Ctrl+N
- **Pencil Tool**: pixel level editing, **Shortcut:** B
- **Color Palette Bar**: akses cepat ke palet terbatas, **Shortcut:** Klik kanan pada warna
- **Onion Skin**: untuk konsistensi posisi antar icon, **Shortcut:** Alt+Shift+O

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 16x16 px, transparent background.
2. Sketsa siluet icon (misal: pedang) dengan warna gelap — jangan pikirin detail dulu.
3. Isi warna dasar item (misal: abu-abu untuk metal).
4. Tambahkan 1px shadow di kiri bawah untuk kesan 3D.
5. Tambahkan 1px highlight di kanan atas.
6. Outline hitam 1px di pinggir (opsional, sesuaikan gaya game).
7. Duplikat layer untuk variasi item lain, ubah warna dan bentuk kecil.
