# 126. Prinsip desain UI pixel art

## Definisi Singkat
Prinsip desain UI pixel art adalah panduan mendesain antarmuka game yang fungsional, konsisten, dan terbaca jelas dalam resolusi rendah. Fokus utamanya adalah hierarki visual, readability, dan efisiensi ruang pixel.

## Analogi
Seperti papan rambu di jalan raya — harus langsung terbaca dalam sekejap, menggunakan simbol universal, dan tidak mengganggu pengemudi (pemain) dari jalan utama (gameplay).

## Poin-Poin Penting
- Gunakan kontras tinggi antara teks/ikon dan background UI.
- Batasi resolusi UI (misal 320x180) agar konsisten dengan pixel art game.
- Jaga padding minimal 1-2 pixel antar elemen.
- Palet warna UI harus terpisah dari palet gameplay.
- Hindari elemen dekoratif berlebihan yang mengganggu fungsionalitas.

## Shortcut & Fitur Aseprite
- **New File > UI Template**: buka preset resolusi UI, **Shortcut:** Ctrl+N
- **Grid Settings**: aktifkan grid untuk alignment sempurna, **Shortcut:** Ctrl+Shift+G
- **Slice Tool**: potong area UI untuk nine-patch, **Shortcut:** Shift+S

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 320x180 px — resolusi umum UI pixel art.
2. Set palet terbatas (8-16 warna) khusus UI agar konsisten.
3. Buat background panel solid dengan border 1px kontras.
4. Tempatkan tombol di area tepi agar tidak menutupi area gameplay.
5. Gunakan grid 8x8 untuk snap posisi setiap elemen UI.
6. Uji readability dengan memperkecil tampilan ke 100% dan lihat apakah masih terbaca.
