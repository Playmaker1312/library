# 130. Cursor pointer kustom

## Definisi Singkat
Cursor pointer kustom adalah ikon mouse buatan sendiri yang menggantikan kursor sistem default, dirancang dalam resolusi kecil (16x16 atau 32x32) dengan hot spot yang presisi.

## Analogi
Seperti ujung pensil — kamu harus tahu persis di mana ujungnya menyentuh kertas (hot spot), bukan batang pensilnya.

## Poin-Poin Penting
- Resolusi standar: 16x16 atau 32x32 px.
- Hot spot adalah 1 pixel titik aktual interaksi — biasanya 0,0 atau 8,8.
- Gunakan outline kontras (gelap+terang) agar terlihat di background gelap/terang.
- Batasi 3-4 warna agar tetap terbaca.
- Animasi kursor (pulse) boleh tapi jangan mengganggu.

## Shortcut & Fitur Aseprite
- **New File**: 16x16 px, transparent bg, **Shortcut:** Ctrl+N
- **Pencil Tool**: gambar pixel presisi, **Shortcut:** B
- **Onion Skin**: untuk animasi kursor state, **Shortcut:** Alt+Shift+O
- **Export**: ekspor sebagai PNG untuk di-load engine, **Shortcut:** Ctrl+Shift+X

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file 16x16 px, transparent background.
2. Gambar bentuk pointer panah klasik (miring kiri atas) ukuran 11x11 px.
3. Tandai hot spot di ujung panah (pixel 0,0).
4. Buat outline 1px putih + 1px hitam (double outline) agar terbaca di semua background.
5. Isi bagian dalam dengan warna solid (misal putih).
6. Simpan file, lalu export sebagai PNG 16x16.
7. Buat variasi: pointer untuk interact, pointer untuk drag, pointer untuk text.
8. Load ke engine game dan set hot spot sesuai koordinat.
