# 132. Button state normal hover pressed

## Definisi Singkat
Button state adalah tiga kondisi visual tombol UI: Normal (default), Hover (mouse di atas), dan Pressed (sedang diklik). Masing-masing punya variasi warna, bayangan, atau offset pixel.

## Analogi
Saklar lampu di dinding: posisi default (normal), jari menyentuh (hover), jari menekan (pressed). Setiap posisi terasa berbeda secara fisik — di UI, perbedaan itu dibuat secara visual.

## Poin-Pending Penting
- Normal: warna flat, bayangan di kanan bawah (kesan timbul).
- Hover: warna lebih terang atau border glow, sebagai feedback mouse.
- Pressed: warna lebih gelap, shadow hilang, offset 1px ke kanan+bawah.
- Ukuran tombol minimal 16px height agar mudah diklik.
- 1 set tombol terdiri dari 3 frame/fase dalam sprite sheet yang sama.

## Shortcut & Fitur Aseprite
- **Frame Animation**: buat 3 frame untuk 3 state, **Shortcut:** Shift+N
- **Replace Color**: ganti warna cepat antar state, **Shortcut:** Shift+R
- **Offset Layer**: geser layer Pressed 1px, **Shortcut:** Panah pada keyboard dengan Move Tool
- **Export Sprite Sheet**: ekspor sebagai strip horizontal, **Shortcut:** Ctrl+Shift+X

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file 64x32 px, 3 frame.
2. Frame 1 (Normal): gambar panel tombol 48x16 px, isi warna biru tua, bayangan 1px di kanan bawah.
3. Frame 2 (Hover): duplikat frame 1, ubah warna biru lebih terang, tambah outline putih 1px.
4. Frame 3 (Pressed): duplikat frame 1, hilangkan shadow, offset layer konten 1px kanan+bawah, gelapkan warna.
5. Rapikan posisi: 3 frame bersebelahan dalam 1 sheet (64x48 px total).
6. Ekspor sebagai sprite sheet. Di engine, set frame 0 = Normal, frame 1 = Hover, frame 2 = Pressed.
