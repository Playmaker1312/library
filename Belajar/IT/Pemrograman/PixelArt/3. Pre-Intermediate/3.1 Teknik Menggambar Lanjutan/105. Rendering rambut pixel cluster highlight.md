# 105. Rendering Rambut Pixel Cluster Highlight

## Definisi Singkat
Teknik merender rambut menggunakan pixel cluster yang dikelompokkan dalam bentuk helaian, dengan highlight dan shadow mengikuti arah aliran rambut, bukan asal-asalan.

## Analogi
Seperti menyisir rambut: highlight mengikuti arah sisiran, membentuk helaian mengkilap yang memantulkan cahaya di permukaan atas.

## Poin-Poin Penting
- Rambut digambar sebagai cluster helai (2-4 pixel lebar), bukan garis-garis terpisah
- Highlight ditempatkan di bagian atas/tepi luar rambut, mengikuti bentuk kepala
- Gunakan 3-4 tingkat warna: base, shadow, highlight utama, highlight kedua
- Highlight berbentuk cluster memanjang, bukan titik-titik terisolasi
- Rambut anime: highlight besar dan bergelombang; rambut realistis: highlight lebih pecah

## Shortcut & Fitur Aseprite
- **Pencil Tool**: gambar cluster rambut, **Shortcut:** B
- **Contiguous Fill**: mewarnai area rambut setelah outline, **Shortcut:** G
- **Symmetry Tool**: untuk rambut kiri-kanan simetris (tampak depan), **Shortcut:** M, aktifkan Horizontal Symmetry

## Contoh Kasus Nyata (Step-by-Step)
1. Buat canvas 32×32, gambar garis kepala dan leher sederhana
2. Gambar massa rambut (siluet) dengan base color cokelat
3. Tentukan arah cahaya dari kiri atas
4. Tambahkan shadow di helai rambut bagian bawah dengan warna cokelat gelap — bentuk cluster 3×1 pixel
5. Tambahkan highlight kuning-cokelat di bagian atas rambut — cluster memanjang mengikuti aliran
6. Untuk highlight kedua, gunakan warna lebih terang di tengah cluster highlight utama
7. Hasil: rambut tampak mengkilap dan bervolume, bukan blok datar
