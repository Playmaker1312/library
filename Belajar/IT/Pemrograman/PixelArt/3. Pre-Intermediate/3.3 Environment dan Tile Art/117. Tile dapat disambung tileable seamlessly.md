# 117. Tile Dapat Disambung Tileable Seamlessly

## Definisi Singkat
Tileable (seamless) adalah teknik membuat tile yang tepi kanan/kiri dan atas/bawah saling bersambung tanpa celah atau putus saat ditempel berulang. Ujung tile adalah awal tile berikutnya.

## Analogi
Seperti ubin lantai bermotif: setiap ubin punya pola yang lanjutan dari ubin sebelahnya, sehingga seluruh lantai tampak seperti satu gambar utuh tanpa sambungan terlihat.

## Poin-Poin Penting
- Pixel di tepi kanan (x=15) harus identik dengan pixel di tepi kiri (x=0) pada tile 16×16
- Begitu juga tepi bawah (y=15) dengan tepi atas (y=0)
- Pojok tile (0,0) muncul di 4 pojok sekaligus — pastikan konsisten
- Gunakan fitur Tile Mode atau preview tilesheet untuk cek seam
- Seam burst: polakan yang berulang horizontal dan vertikal

## Shortcut & Fitur Aseprite
- **Tile Mode** di Tool Options: gambar otomatis terhubung ke sisi seberang tile, **Shortcut:** tombol ikon tile di toolbar
- **Preview → Tile Preview**: lihat hasil tile berulang di canvas, **Shortcut:** Ctrl+Shift+P
- **New Brush → Tile Brush**: buat brush tileable untuk painting cepat

## Contoh Kasus Nyata (Step-by-Step)
1. Buat canvas baru 16×16
2. Aktifkan Tile Mode (ikon kotak di toolbar Tool Options)
3. Gambar pola sederhana: garis diagonal dari kiri bawah ke kanan atas
4. Saat pixel menyentuh tepi kanan, lihat pixel otomatis muncul di tepi kiri
5. Nonaktifkan Tile Mode, gambar pola bebas di tengah (tidak perlu seamless)
6. Aktifkan Tile Preview (Ctrl+Shift+P) untuk melihat hasil 3×3 tile
7. Periksa: tidak ada garis sambungan yang patah antar tile
8. Simpan sebagai tilesheet untuk digunakan di game engine
