# 122. Prop Environment Pohon Batu Bangunan

## Definisi Singkat
Environment prop adalah objek dekoratif yang ditempatkan di dalam scene game — seperti pohon, batu, dan bangunan — untuk mengisi ruang dan menciptakan atmosfer dunia.

## Analogi
Seperti properti panggung teater: pohon kardas, batu busa, dan rumah latar — semuanya dibuat untuk memperkaya latar cerita tanpa harus interaktif.

## Poin-Poin Penting
- **Pohon**: batang cokelat vertikal, dedaunan berbentuk cluster bulat/kerucut, shading 3 tingkat
- **Batu**: bentuk tidak beraturan, cluster kasar, highlight di sisi kiri atas, bayangan di sisi kanan bawah
- **Bangunan**: dinding dengan jendela dan pintu, atap segitiga/datar, proporsi konsisten dengan karakter
- Semua prop harus konsisten dengan palet dan skala game
- Prop yang baik punya silhouette jelas agar mudah dikenali

## Shortcut & Fitur Aseprite
- **Symmetry Tool**: untuk pohon dan bangunan simetris, **Shortcut:** M, pilih Horizontal Symmetry
- **Pencil Tool**: detail daun dan tekstur batu, **Shortcut:** B
- **Layers**: pisahkan layer untuk batang-daun-pohon, atau dinding-atap-bangunan
- **Blur Tool**: untuk bayangan di bawah prop, **Shortcut:** R

## Contoh Kasus Nyata (Step-by-Step)
1. **Pohon** (canvas 24×32):
   - Batang: 4px lebar, 12px tinggi, cokelat gelap
   - Daun: cluster 12×12 lingkaran, hijau 3 level (gelap-mid-terang)
   - Tambah shadow di bawah pohon (ellips hitam 8×3, opacity 50%)
2. **Batu** (canvas 16×12):
   - Base abu-abu bentuk oval tidak sempurna
   - Highlight abu-abu terang di kiri atas, shadow di kanan bawah
   - Tambah retakan 1px dengan warna lebih gelap
3. **Bangunan** (canvas 48×48):
   - Dinding persegi dengan outline, jendela 2×4 di tengah
   - Atap segitiga dengan warna lebih gelap dari dinding
   - Pintu 4×8 di bagian bawah tengah
4. Tempatkan ketiganya di satu scene sebagai prop lingkungan
