# 124. Background Sky Mountain Horizon Parallax

## Definisi Singkat
Background set untuk scrolling horizontal meliputi 4 komponen utama: sky (langit) sebagai lapisan paling jauh, mountain (gunung) sebagai siluet horizon, dan horizon line sebagai batas pandang.

## Analogi
Seperti lukisan lanskap klasik: langit di bagian atas, gunung di cakrawala, dan daratan di bawah — semua lapisan menciptakan kedalaman dari depan ke belakang.

## Poin-Poin Penting
- **Sky**: gradasi vertikal, warna lebih terang di horizon, lebih gelap di atas
- **Mountain range**: 2-3 lapis gunung dengan warna semakin biru dan pudar untuk lapisan jauh
- **Horizon**: garis tipis sebagai batas langit dan daratan, biasanya 1/3 dari tinggi canvas
- **Ground/trees**: detail di depan horizon untuk transisi natural
- Semua layer harus seamless secara horizontal agar bisa di-scroll tanpa batas

## Shortcut & Fitur Aseprite
- **Gradient Tool**: untuk gradasi sky vertikal, **Shortcut:** G
- **Tile Mode Horizontal**: buat background seamless horizontal saja, tanpa tile vertikal
- **Layer Blending**: ganti blend mode layer gunung untuk efek transparansi
- **Repeat Mode**: di View → Repeat Mode untuk preview scrolling, **Shortcut:** Ctrl+Shift+R

## Contoh Kasus Nyata (Step-by-Step)
1. Buat canvas 256×144 dengan latar belakang transparan
2. **Sky**: gradasi dari biru tua (#1a237e) di atas ke biru muda (#90caf9) di horizon
3. **Gunung Jauh (Layer 3)**: siluet biru-keabuan (#5c6bc0), bentuk puncak bergelombang, scroll 0.2x
4. **Gunung Dekat (Layer 2)**: siluet hijau-keabuan (#4e6e4e), lebih detail, scroll 0.4x
5. **Horizon/Trees (Layer 1)**: pepohonan hitam-hijau (#2e4e2e), scroll 0.7x
6. Gunakan Tile Mode Horizontal agar seamless — pastikan ujung kiri dan kanan sambung
7. Hasil: sky gradasi + 3 layer gunung + pohon horizon = kedalaman penuh
8. Siap digunakan untuk game side-scrolling
