# 125. Atmospheric Perspective Warna Environment

## Definisi Singkat
Atmospheric perspective adalah efek di mana objek yang semakin jauh semakin pudar warnanya, cenderung kebiruan, dan kontrasnya menurun karena partikel udara di antara mata dan objek.

## Analogi
Saat mendaki gunung, lihat pegunungan di kejauhan: warnanya biru keabu-abuan, tidak sejelas pohon di dekatmu. Udara di antaranya membuat warna memudar.

## Poin-Poin Penting
- Jarak 0-50px (layer 1): warna jenuh penuh, kontras tinggi, detail jelas
- Jarak 50-150px (layer 2): warna berkurang 30%, tambah sedikit biru
- Jarak 150-300px (layer 3): warna berkurang 60%, lebih biru, kontras rendah
- Jarak 300+px (layer 4): hampir monokrom biru-abu, kontras sangat rendah
- Gunakan palet dengan saturasi menurun dan hue bergeser ke biru per layer

## Shortcut & Fitur Aseprite
- **Color Palette**: buat palet gradient untuk tiap layer jarak
- **Hue/Saturation** adjustment: turunkan saturasi layer jauh, **Shortcut:** Ctrl+Shift+U
- **Opacity**: kurangi opacity layer untuk efek kabur jauh
- **Blur Tool**: untuk mengaburkan detail layer belakang

## Contoh Kasus Nyata (Step-by-Step)
1. Siapkan 3 layer pohon: depan, tengah, belakang
2. **Pohon Depan**: hijau jenuh (#2e7d32), outline hitam jelas, detail daun terlihat
3. **Pohon Tengah**: hijau biru (#4a7c6f), outline biru gelap, kontras turun, detail berkurang
4. **Pohon Belakang**: biru-abu (#7a8c9e), tanpa outline, hampir tanpa detail
5. Bandingkan ketiganya: pohon depan "maju", pohon belakang "mundur" secara visual
6. Terapkan pada background 3 layer: tanah→hutan→gunung→langit
7. Efek atmosfer membuat environment terasa memiliki kedalaman puluhan kilometer
8. Tips: jangan gunakan outline hitam untuk objek jauh — outline akan merusak ilusi jarak
