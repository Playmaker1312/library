# 108. Run Cycle Animasi Berlari

## Definisi Singkat
Run cycle adalah animasi berlari dengan karakteristik: kedua kaki bisa sama-sama tidak menyentuh tanah (airborne), gerakan lebih cepat, dan badan lebih condong ke depan.

## Analogi
Seperti atlet sprint di foto gerak — tubuh condong, lutut terangkat tinggi, dan ada momen melayang di udara antara langkah-langkah.

## Poin-Poin Penting
- 6-8 frame cukup untuk run cycle; jumlah frame lebih sedikit dari walk cycle
- Badan condong ke depan 15-30° (sekitar 3-5 pixel miring)
- Ada minimal 1 frame airborne di mana kedua kaki tidak menyentuh tanah
- Kontak tanah lebih singkat: kaki menapak hanya 1-2 frame lalu lepas
- Lengan ditekuk 90° dan bergerak lebih cepat dari walk cycle

## Shortcut & Fitur Aseprite
- **Rotate Tool**: memiringkan badan dengan rotasi seleksi, **Shortcut:** Q
- **Pivot Point**: atur titik rotasi di sudut kiri bawah badan untuk kemiringan konsisten
- **Animation Speed**: atur frame delay di timeline untuk kecepatan lari, biasanya 50-80ms per frame

## Contoh Kasus Nyata (Step-by-Step)
1. Buat canvas 32×48, 8 frame, frame delay 60ms
2. **Frame 1 (Contact)**: kaki kanan di depan, badan condong kiri 3px
3. **Frame 2 (Down)**: kaki kanan menapak, badan sedikit turun
4. **Frame 3 (Airborne Start)**: kedua kaki di udara, kaki kanan di belakang, kiri di depan
5. **Frame 4 (Airborne Peak)**: kaki kiri maksimal di depan, kaki kanan maksimal di belakang
6. Frame 5-8: ulang dengan posisi kaki tertukar
7. Pastikan setiap siklus ada 2 frame airborne
8. Preview loop: lari terlihat lebih cepat dan dinamis dibanding walk cycle
