# 137. Color grouping berdasarkan fungsi

## Definisi Singkat
Color grouping adalah praktik mengelompokkan slot warna dalam palette berdasarkan peran/fungsinya (kulit, rambut, baju, metal, UI, dll) untuk memudahkan editing dan palette swapping.

## Analogi
Kotak alat mekanik: obeng dikelompokkan dengan obeng, kunci pas dengan kunci pas. Ketika butuh obeng, kamu tidak perlu mencari di tumpukan kunci pas — semuanya rapi per kategori.

## Poin-Poin Penting
- Kelompokkan warna per elemen: 3-5 slot per elemen (base, shadow, highlight, outline).
- Beri jarak 1 slot kosong antar grup sebagai pemisah.
- Gunakan komentar di palette (Aseprite) untuk menamai grup.
- Urutan konsisten: paling terang ke paling gelap dalam satu grup.
- Grouping memudahkan palette swapping — cukup ganti range index tertentu.

## Shortcut & Fitur Aseprite
- **Palette Editor**: F4 untuk buka panel
- **Add Empty Slot**: sisipkan slot kosong sebagai pemisah grup
- **Palette Comment**: tulis nama grup/keterangan di slot, **Shortcut:** Klik kanan > Comment
- **Drag & Drop**: pindahkan warna ke grup yang benar
- **Sort by Function**: gunakan Sort Palette lalu manual adjust

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Palette Editor (F4) pada sprite karakter.
2. Kelompokkan: index 0-4 untuk outline dan bayangan global.
3. Index 5-8 untuk warna kulit (base, shadow, highlight, blush).
4. Index 9-13 untuk rambut (base, 2 shadow, 2 highlight).
5. Index 14-18 untuk baju (base, shadow, highlight, outline).
6. Index 19-22 untuk aksesoris.
7. Beri komentar di index pertama tiap grup: "Kulit", "Rambut", "Baju".
8. Sisipkan 1 slot kosong antar grup untuk pemisah visual.
9. Simpan palette. Saut mau swap baju, tinggal ganti range index 14-18.
