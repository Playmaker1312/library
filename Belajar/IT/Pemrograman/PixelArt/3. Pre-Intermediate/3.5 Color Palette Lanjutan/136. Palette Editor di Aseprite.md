# 136. Palette Editor di Aseprite

## Definisi Singkat
Palette Editor adalah panel di Aseprite untuk mengelola, mengurutkan, mengedit, dan menyimpan kumpulan warna (palette) yang digunakan dalam file aktif atau sebagai referensi global.

## Analogi
Kotak cat lukis: setiap palet memiliki lubang-lubang (slot) untuk warna tertentu. Kamu bisa mengatur urutan warna, mengganti cat, atau menyimpan kotak cat favorit untuk proyek lain.

## Poin-Poin Penting
- Bisa diakses via menu Window > Palette Editor atau shortcut F4.
- Urutan warna sangat penting — urutkan dari paling terang ke gelap atau berdasarkan fungsi (kulit, rambut, baju).
- Drag & drop untuk memindahkan slot warna.
- Klik ganda pada slot untuk mengedit warna HTML/RGB/HSV.
- Palette bisa disimpan (.ase, .png, .gpl, .hex, .pal, .txt).

## Shortcut & Fitur Aseprite
- **Palette Editor**: Window > Palette Editor, **Shortcut:** F4
- **Edit Color**: klik ganda slot warna, **Shortcut:** Klik ganda
- **Add Color**: tambah warna baru ke palette, **Shortcut:** Shift+C (atau ikon +)
- **Delete Color**: hapus slot, **Shortcut:** Alt+Klik pada slot
- **Sort Palette**: urutkan berdasarkan hue, lightness, atau saturasi, **Shortcut:** Klik kanan > Sort
- **Load Palette**: File > Open dengan file palette

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite, buka Palette Editor (F4).
2. Perhatikan semua warna yang ada di sprite aktif muncul di panel.
3. Klik ganda warna merah (#FF0000) — ubah menjadi merah gelap (#CC0000).
4. Urutkan palette dengan klik kanan > Sort by Lightness.
5. Tambah warna baru dengan ikon + atau Shift+C.
6. Kelompokkan warna: drag warna kulit berdekatan, warna rambut berdekatan.
7. Simpan palette: File > Export > Export Palette — simpan sebagai .ase.
8. Buka file lain, load palette yang tadi disimpan untuk konsistensi.
