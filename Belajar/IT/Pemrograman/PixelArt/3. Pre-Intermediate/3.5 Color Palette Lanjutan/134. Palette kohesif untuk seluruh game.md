# 134. Palette kohesif untuk seluruh game

## Definisi Singkat
Palette kohesif adalah satu set warna terbatas yang dipakai konsisten di semua aspek visual game — karakter, background, UI, efek — sehingga game terasa harmonis dan profesional.

## Analogi
Seperti kode berpakaian di acara formal: semua tamu (elemen game) memakai palet warna yang selaras — tidak ada yang memakai neon terang di pesta hitam-putih.

## Poin-Poin Penting
- Batasi total warna 16-64 untuk seluruh game (tergantung gaya).
- Pilih 2-3 warna dominan (primary), 2-3 aksen, dan sisanya netral.
- Warna UI sebaiknya subset dari palette utama agar tidak kontras berlebihan.
- Uji palette: semua warna harus harmonis jika dipasangkan secara acak.
- Dokumentasikan palette di file referensi agar semua tim pakai palette sama.

## Shortcut & Fitur Aseprite
- **Palette Editor**: atur dan urutkan palette global, **Shortcut:** F4
- **Palette > New Palette**: buat palette game baru
- **Color Wheel**: pilih warna yang harmonis, **Shortcut:** F3
- **Export Palette**: simpan sebagai .aseprite atau .png, **Shortcut:** File > Export Palette

## Contoh Kasus Nyata (Step-by-Step)
1. Tentukan mood game: "fantasi hangat" → warna earthy, coklat, hijau, gold.
2. Pilih 2 warna primer: coklat tua (#4A3B32) dan hijau olive (#5A7A4A).
3. Pilih 2 aksen: gold (#D4A84B) untuk item penting, merah (#8B3A3A) untuk darah/peringatan.
4. Pilih 4 warna netral: putih, abu terang, abu gelap, hitam.
5. Buat palette total 16-24 warna di Palette Editor Aseprite.
6. Uji palette: gambar 1 tile background, 1 karakter, 1 UI element dengan warna dari palette saja.
7. Jika semua terlihat harmonis, simpan sebagai palette master game.
