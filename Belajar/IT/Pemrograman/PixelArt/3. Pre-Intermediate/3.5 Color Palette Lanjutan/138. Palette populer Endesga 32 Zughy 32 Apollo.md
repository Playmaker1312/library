# 138. Palette populer Endesga 32 Zughy 32 Apollo

## Definisi Singkat
Palette populer adalah kumpulan warna siap pakai yang dibuat oleh seniman pixel art terkenal — seperti ENDESGA 32, Zughy 32, dan Apollo — masing-masing dengan karakteristik dan mood yang berbeda.

## Analogi
Seperti set cat akrilik premium dari merek terkenal: palet ENDESGA seperti set 32 warna serbaguna, Zughy 32 seperti set warm earthy, dan Apollo seperti set sci-fi cold.

## Poin-Poin Penting
- **ENDESGA 32**: palette serbaguna 32 warna, sangat populer untuk game retro, coverage warna luas dari hangat ke dingin.
- **Zughy 32** (by Zughy): palette 32 warna dengan warna earthy/warm, ideal untuk game fantasy atau pixel art landscape.
- **Apollo** (by Max): palette 32 warna bernuansa cool/blue, cocok untuk game sci-fi, ice, atau malam hari.
- Palette ini gratis digunakan untuk game komersial (cek lisensi masing-masing).
- Bisa di-download dan di-load langsung ke Aseprite.

## Shortcut & Fitur Aseprite
- **Load Palette**: File > Open > pilih file .ase/.png palette, **Shortcut:** Ctrl+O
- **Palette Editor**: F4 untuk lihat dan edit palette yang di-load
- **New Palette from File**: Palette > New Palette > From File
- **Preset Palette**: Aseprite kadang menyertakan palette populer di folder extensions

## Contoh Kasus Nyata (Step-by-Step)
1. Download file palette ENDESGA 32 (.ase atau .png) dari lospec.com.
2. Di Aseprite, buka File > Open, pilih file ENDESGA 32.
3. Palette akan muncul di Palette Editor (F4) dengan 32 warna.
4. Buat file baru 64x64 px, gambar karakter menggunakan palette ENDESGA 32.
5. Coba load Zughy 32 palette — lihat bagaimana mood berubah drastis.
6. Coba load Apollo palette untuk karakter sci-fi.
7. Eksperimen: mix base shape dengan ENDESGA, lalu ganti palette ke Zughy untuk variasi.
8. Simpan palette favorit ke folder proyek untuk penggunaan konsisten.
