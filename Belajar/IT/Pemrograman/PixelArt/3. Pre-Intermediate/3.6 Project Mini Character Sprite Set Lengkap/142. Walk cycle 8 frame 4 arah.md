# 142. Walk cycle 8 frame 4 arah

## Definisi Singkat
Walk cycle adalah animasi berjalan karakter dalam 8 frame per arah, mencakup 4 arah (bawah, kiri, atas, kanan) untuk game top-down atau side-view. Setiap arah membutuhkan posisi kaki dan badan yang berbeda.

## Analogi
Fotografi gerak berjalan (muybridge): 8 foto berurutan saat manusia berjalan. Kiri-kanan bergantian, badan naik-turun, tangan mengayun natural.

## Poin-Poin Penting
- Walk cycle 8 frame = 1 langkah penuh (kiri maju → kanan maju).
- Contact point (frame 1 & 5): satu kaki di depan, satu di belakang.
- Passing point (frame 3 & 7): kedua kaki berdekatan.
- Badan naik di passing, turun di contact.
- 4 arah: bottom (menghadap), side (kiri/kanan mirror), top (belakang) — total 32 frame.
- Side view bisa di-mirror untuk kiri/kanan cukup buat 1 arah.

## Shortcut & Fitur Aseprite
- **Timeline**: 8 frame x 4 tag = 32 frame total, **Shortcut:** Alt+T
- **Tag**: tiap arah punya tag loop sendiri, **Shortcut:** F7 (New Tag)
- **Onion Skin**: untuk referensi posisi kaki, **Shortcut:** Alt+Shift+O
- **Flip Horizontal**: mirror sprite untuk arah kiri dari kanan, **Shortcut:** Ctrl+H
- **Copy Cel**: duplikat frame, **Shortcut:** Alt+Drag frame

## Contoh Kasus Nyata (Step-by-Step)
1. Buka file karakter 32x64 px, duplikat sebagai "WalkCycle".
2. Buat 8 frame untuk arah bawah (facing player):
   - Frame 1: kaki kiri di depan, kanan di belakang, badan turun.
   - Frame 3: kaki kiri passing, kanan passing, badan naik.
   - Frame 5: kaki kanan di depan, kiri di belakang, badan turun.
   - Frame 7: sama dengan frame 3.
   - Frame 2,4,6,8: frame transisi antar contact/passing.
3. Tag 8 frame sebagai "Walk_Down", loop animation.
4. Duplikat semua frame untuk arah samping kanan (rotasikan sprite).
5. Untuk arah atas: gambar dari belakang (tampak punggung).
6. Mirror arah kanan untuk arah kiri.
7. Atur durasi tiap frame: 150ms.
8. Simpan sebagai "KsatriaApi_Walk.aseprite".
