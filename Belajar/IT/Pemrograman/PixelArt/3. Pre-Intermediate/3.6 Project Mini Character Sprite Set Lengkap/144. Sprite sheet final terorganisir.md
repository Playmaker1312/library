# 144. Sprite sheet final terorganisir

## Definisi Singkat
Sprite sheet final adalah file tunggal yang berisi semua frame animasi karakter yang ditata rapi dalam grid, siap di-export ke game engine. Organisasi yang baik memudahkan programming dan mencegah error slicing.

## Analogi
Lembaran stiker tokoh kartun: setiap pose (idle, jalan, lari, serang) ada di baris sendiri-sendiri. Gunting (engine) tinggal potong per kotak — tidak perlu cari-cari.

## Poin-Poin Penting
- Setiap animasi punya baris sendiri: Row 1 = Idle, Row 2 = Walk, Row 3 = Run, dll.
- Setiap frame dalam satu animasi punya lebar & tinggi yang seragam.
- Beri jarak 1-2 px antar frame (padding) untuk mencegah bleed di engine.
- Gunakan nama tag yang sama dengan nama animasi di engine.
- Pastikan anchor point karakter konsisten (biasanya di tengah bawah).

## Shortcut & Fitur Aseprite
- **Sprite Sheet Export**: File > Export > Sprite Sheet, **Shortcut:** Ctrl+Shift+X
- **Tag**: nama tag menjadi nama animasi di engine, **Shortcut:** F7
- **Slice Tool**: tandai area per frame untuk ekspor presisi, **Shortcut:** Shift+S
- **Output Settings**: atur padding, rotation, layout di dialog export

## Contoh Kasus Nyata (Step-by-Step)
1. Buka file karakter yang berisi semua animasi (idle, walk, run, attack, death) dengan tag masing-masing.
2. Buka File > Export > Sprite Sheet (Ctrl+Shift+X).
3. Di opsi Layout: pilih "By Rows" agar tiap tag berurutan horizontal.
4. Set padding: 2px antar frame untuk mencegah edge bleeding.
5. Centang "Save Tags" agar informasi tag ikut di-export.
6. Pilih output: PNG file, ukuran canvas otomatis atau manual.
7. Klik OK — sprite sheet PNG siap.
8. Buka hasil export untuk verifikasi: semua frame rapi dalam 1 file.
9. Simpan juga file .json/.xml metadata jika engine butuh data slicing.
