# 140. Merancang konsep karakter

## Definisi Singkat
Merancang konsep karakter adalah tahap awal sebelum pixel art — menentukan identitas visual karakter melalui siluet, palet warna, proporsi, dan kepribadian yang akan direalisasikan dalam bentuk sprite.

## Analogi
Seperti mendesain kostum tokoh untuk pertunjukan teater: kamu tentukan dulu perannya (pahlawan/penjahat), bentuk badan, warna kostum, dan properti sebelum menjahit kostumnya.

## Poin-Poin Penting
- Tentukan resolusi sprite: 16x16 (sederhana), 32x32 (standar), atau 64x64 (detail).
- Buat silhouette test: karakter harus dikenali hanya dari bentuk hitamnya.
- Batasi palet: 8-16 warna per karakter untuk konsistensi.
- Tentukan arah hadap utama: biasanya facing right (side-view) atau front-facing.
- Dokumentasikan referensi dan sketsa awal sebelum pixel.

## Shortcut & Fitur Aseprite
- **Pencil Tool**: sketsa awal bentuk, **Shortcut:** B
- **Eraser Tool**: hapus koreksi bentuk, **Shortcut:** E
- **Symmetry Mode**: gambar setengah karakter, mirror otomatis, **Shortcut:** H (Horizontal Symmetry)
- **Reference Layer**: layer khusus untuk sketsa referensi yang tidak ikut export, **Shortcut:** Shift+Layer Icon

## Contoh Kasus Nyata (Step-by-Step)
1. Tentukan karakter: "Ksatria Api" — hero dengan armor merah, pedang api, tinggi 32px.
2. Buka Aseprite, buat file 32x64 px (lebar x tinggi).
3. Buat sketsa siluet di layer pertama dengan warna hitam: kepala, badan, tangan, kaki.
4. Nyalakan Symmetry Mode (H) agar tubuh kiri-kanan simetris.
5. Tentukan palet 12 warna: merah (armor), coklat (kulit), emas (aksesoris), abu (metal), hitam (outline).
6. Cat dasar base color setiap bagian: armor merah, kulit coklat, rambut hitam.
7. Tambahkan shadow dan highlight pada masing-masing bagian.
8. Simpan file sebagai "KsatriaApi_Konsep.aseprite".
