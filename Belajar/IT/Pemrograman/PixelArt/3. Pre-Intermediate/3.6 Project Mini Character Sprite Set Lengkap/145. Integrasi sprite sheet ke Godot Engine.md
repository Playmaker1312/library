# 145. Integrasi sprite sheet ke Godot Engine

## Definisi Singkat
Integrasi sprite sheet adalah proses membawa sprite sheet yang sudah di-export dari Aseprite ke dalam Godot Engine — mengatur slice, animasi, dan parameter karakter agar siap dipakai dalam game.

## Analogi
Memindahkan koleksi stiker ke buku scrapbook digital: stiker (sprite sheet) sudah jadi, tinggal kamu atur posisi, urutan, dan cara menggunakannya sesuai halaman (scene) yang kamu buat.

## Poin-Poin Penting
- Godot mendukung import .aseprite langsung (native) atau via .png + .json.
- Siapkan AnimatedSprite2D (2D) atau Sprite3D + AnimationPlayer untuk karakter.
- Buat AnimationPlayer dengan nama animasi yang sama dengan tag di Aseprite.
- Set Animation: loop = true/false sesuai jenis animasi (idle loop, death no-loop).
- Atur offset sprite agar anchor karakter di tengah bawah posisi (0,0).

## Shortcut & Fitur Godot
- **Import Aseprite**: drag .aseprite langsung ke FileSystem Godot 4.x - built-in support
- **AnimatedSprite2D**: node utama untuk sprite animasi, **Shortcut:** Ctrl+A (add node)
- **SpriteFrames Panel**: drag sprite sheet ke sini, atur grid otomatis, **Shortcut:** di Inspector
- **AnimationPlayer**: alternatif untuk kontrol frame presisi
- **Set Animation**: panggil $AnimatedSprite2D.play("idle") di script

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Godot Engine, buat project 2D baru.
2. Drag file sprite sheet (.png) ke panel FileSystem.
3. Jika pakai .aseprite langsung: drag file ke FileSystem (Godot 4.x support).
4. Buat node AnimatedSprite2D sebagai child dari CharacterBody2D.
5. Di Inspector, buka SpriteFrames > New SpriteFrames.
6. Buka panel SpriteFrames: tambah animasi "idle", "walk", "run", "attack", "death".
7. Drag frame dari sprite sheet ke masing-masing animasi.
8. Atur FPS per animasi: idle=4, walk=8, run=10, attack=6, death=4.
9. Atur looping: idle & walk & run = looping, attack & death = no-loop.
10. Tulis script: $AnimatedSprite2D.play("idle") di _ready().
11. Test scene: karakter muncul dan ber-animasi idle.
