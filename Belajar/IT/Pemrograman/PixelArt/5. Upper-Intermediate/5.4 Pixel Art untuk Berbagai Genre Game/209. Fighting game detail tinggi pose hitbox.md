# 209. Fighting Game — Detail Tinggi, Pose, Hitbox

## Definisi Singkat
Teknik mendesain pixel art untuk game fighting — sprite resolusi lebih tinggi dengan detail ekspresif, pose dinamis, dan kejelasan hitbox untuk gameplay kompetitif.

## Analogi
Fighting game adalah balet berdarah: setiap gerakan harus terlihat indah dan ekspresif, tapi juga presisi — pemain perlu tahu persis di mana area serangan (hitbox) dan area tubuh yang bisa kena (hurtbox).

## Poin-Poin Penting
- Resolusi lebih tinggi: karakter fighting biasanya 64x64 hingga 128x128 untuk detail
- Animasi: idle, walk, dash, jump, crouch, 3-4 basic attack, 1-2 special, hitstun, knockdown, win pose — bisa 50-200+ frame per karakter
- Setiap frame harus jelas: tidak ada frame "kotor" — pemain fighting sangat sensitif terhadap animasi
- Hitbox visual: walaupun tidak digambar, desain pose harus mempertimbangkan area serangan
- Kontras warna: pemain 1 vs pemain 2 harus sangat beda (biasanya palet 1 vs palet 2)
- Siluet poses: setiap pose harus terbaca — pemain harus tahu dari pose apakah karakter sedang attack, block, atau hurt

## Shortcut & Fitur Aseprite
- Window > Timeline (Ctrl+Tab) untuk animasi kompleks
- Layer Groups per anggota tubuh (kepala, badan, lengan kiri, lengan kanan, kaki kiri, kaki kanan)
- Onion Skin (Alt+Shift+O) untuk konsistensi antar frame
- Edit > Duplicate (Ctrl+D) untuk duplikasi frame lalu modifikasi
- Window > Color Palette (F9) untuk palet karakter + palet alternatif (costume)

## Contoh Kasus Nyata (Step-by-Step)
Buat 3 pose karakter fighting 48x64:

1. Pose idle: stance siap — kaki selebar bahu, tangan di depan, badan sedikit condong ke depan
2. Pose heavy punch: tangan kanan ditarik ke belakang (windup) lalu diayun ke depan — bikin 2 frame (windup + hit)
3. Pose knockdown: karakter jatuh ke belakang, tangan terbuka, kaki terangkat
4. Untuk setiap pose, perhatikan siluet: apakah pose ini bisa dikenali dalam 0.1 detik?
5. Tambah frame intermediate: gunakan Onion Skin untuk smooth transisi
6. Visual hitbox: gambar kotak merah transparan di layer terpisah (tidak untuk final, hanya panduan)
7. Konsistensi ukuran: kepala tetap 12x12 di semua pose, badan 24x20, dll
8. Review: apakah pose terasa powerful? Cek referensi fighting game favorit
