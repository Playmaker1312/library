# 212. Pipeline Export Aseprite ke Godot

## Definisi Singkat
Proses workflow mengekspor sprite dan animasi dari Aseprite ke engine game Godot — memastikan sprite sheet, animasi, dan metadata terintegrasi dengan benar.

## Analogi
Seperti juru masak yang menyiapkan bahan di dapur lalu mengirim ke restoran: bahan harus sudah dipotong (export), diberi label (naming), dan dikemas (format) agar koki (Godot) bisa langsung memasak tanpa perlu repot.

## Poin-Poin Penting
- Export format: PNG sprite sheet (disarankan) atau GIF/APNG
- Sprite sheet vs individual files: sheet lebih efisien untuk banyak animasi, individual files lebih mudah untuk manajemen
- Pastikan pivot point konsisten: set pivot di Aseprite di posisi yang sama untuk semua sprite
- Resolusi: pastikan konsisten dengan import scale factor Godot (biasanya 1 game unit = 16px atau 32px)
- Naming: nama file dan layer harus jelas agar mudah diimport di Godot
- Aseprite memiliki export option untuk JSON data (frame coordinates, duration, tags)

## Shortcut & Fitur Aseprite
- File > Export > Export Sprite Sheet (Ctrl+E) — setup layout, spacing, format
- Window > Timeline — tag animasi (loop, once, ping-pong) — diexport sebagai JSON metadata
- File > Export > Advanced Options — pilih output format (PNG, GIF), trim, padding
- Layer Groups — grouping animasi per state (idle, walk, jump)
- Tag animation: klik kanan frame number > Add Tag untuk memberi nama animasi

## Contoh Kasus Nyata (Step-by-Step)
Export karakter dari Aseprite ke Godot:

1. Di Aseprite, tag animasi: "idle" (frame 1-4), "walk" (frame 5-10), "jump" (frame 11-13)
2. File > Export > Export Sprite Sheet
3. Atur Layout: horizontal (row), padding 2px antar frame
4. Atur Output: PNG + JSON data
5. Output File: "player_sheet.png" dan "player_sheet.json"
6. Di Godot: import PNG sebagai SpriteFrames (drag ke AnimationPlayer)
7. Atau gunakan plugin Aseprite Wizard (Godot Asset Library) untuk import .aseprite langsung
8. Atur scale: jika sprite 16x16, set scale 4 di Godot untuk tampil 64x64
9. Test: jalankan scene — apakah animasi idle, walk, jump berfungsi sesuai tag?
10. Jika ada offset, perbaiki pivot point di Aseprite dan re-export
