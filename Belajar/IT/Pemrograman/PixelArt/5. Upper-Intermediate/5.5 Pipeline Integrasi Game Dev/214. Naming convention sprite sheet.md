# 214. Naming Convention Sprite Sheet

## Definisi Singkat
Sistem penamaan file dan sprite yang konsisten dan terstruktur untuk memudahkan organisasi aset, pencarian, dan integrasi dengan game engine.

## Analogi
Seperti perpustakaan: tanpa sistem katalog, buku akan sulit ditemukan. Naming convention adalah sistem katalog untuk aset game — memastikan siapa pun di tim bisa menemukan dan menggunakan aset dengan benar.

## Poin-Poin Penting
- Format umum: `[kategori]_[nama]_[state]_[angle].[ext]`
  - Contoh: `char_player_idle_0.png`, `env_tree_large_0.png`
- Gunakan snake_case atau kebab-case — konsisten, jangan campur
- Sertakan resolusi di nama jika variatif: `char_player_32x32_idle.png`
- Untuk sprite sheet: `[character]_[action]_sheet.png` + JSON dengan nama sama
- Versi: `_v1`, `_v2` atau gunakan folder per versi
- Hindari spasi, karakter spesial, huruf kapital (kecuali konsisten)

## Shortcut & Fitur Aseprite
- Sprite > Sprite Properties — cek/reset nama file
- File > Export > Output File — set nama file sesuai convention
- Layer Groups — gunakan nama grup sebagai prefix layer
- Window > Timeline — Tag name menjadi animasi name di export JSON
- Edit > Duplicate (Ctrl+D) — duplicate file dengan rename

## Contoh Kasus Nyata (Step-by-Step)
Organisir aset game RPG:

1. Struktur folder:
   ```
   assets/
     characters/
       player/
         player_idle_sheet.png + player_idle.json
         player_walk_sheet.png + player_walk.json
       enemy/
         enemy_goblin_idle_sheet.png
         enemy_goblin_walk_sheet.png
     environment/
       tiles/
         tile_grass_16x16.png
         tile_water_16x16.png
       props/
         prop_tree_large_32x48.png
     ui/
       ui_button_play.png
       ui_button_settings.png
   ```
2. Contoh naming: `char_player_walk_32x32_v2.png`
   - `char` = kategori character
   - `player` = nama aset
   - `walk` = state/animasi
   - `32x32` = resolusi
   - `v2` = versi
3. Di Aseprite: set export name sesuai convention
4. Dokumentasi naming convention di art bible
5. Review: apakah semua file di folder mengikuti pattern yang sama?
