# 213. Aseprite Godot Plugin — Import Langsung

## Definisi Singkat
Menggunakan plugin atau tool yang memungkinkan Godot mengimpor file .aseprite secara langsung tanpa perlu export manual ke PNG/JSON.

## Analogi
Biasanya kamu harus memasak makanan (export), lalu menyajikannya di piring (import). Plugin ini seperti makanan yang langsung bisa dimakan dari kulkas — .aseprite file langsung terbaca oleh Godot tanpa proses perantara.

## Poin-Poin Penting
- Plugin populer: "Aseprite Wizard" (Asset Library) atau "Godot Aseprite Plugin" (GitHub)
- Keuntungan: edit sprite di Aseprite, save, langsung auto-update di Godot — no export step
- Plugin membaca layer, frame, tags, loop settings langsung dari .aseprite
- Beberapa plugin mendukung tilemap dan tileset dari Aseprite langsung ke Godot
- Pastikan versi plugin kompatibel dengan versi Godot (4.x vs 3.x)
- Resource: simpan file .aseprite di folder project Godot (biasanya di assets/ atau sprites/)

## Shortcut & Fitur Aseprite
- Simpan file .aseprite langsung di folder Godot project — plugin akan auto-detect
- Window > Timeline untuk tag animasi — pastikan tag benar (nama, range, repeat)
- File > Save (Ctrl+S) — setelah save, Godot auto-reimport jika plugin terinstall
- Layer Groups untuk organisasi — plugin bisa membaca grup sebagai state
- Window > Color Palette (F9) — palet terbawa ke Godot

## Contoh Kasus Nyata (Step-by-Step)
Setup Aseprite + Godot plugin:

1. Install plugin: buka Godot > AssetLib > cari "Aseprite Wizard" > Download > Install
2. Enable plugin: Project > Project Settings > Plugins > centang AsepriteWizard
3. Buat folder "assets/sprites/" di Godot project
4. Di Aseprite, buat karakter 16x16 dengan animasi: idle 4 frame, walk 6 frame (tag dengan nama)
5. Simpan file .aseprite langsung ke "assets/sprites/player.aseprite"
6. Di Godot, file akan muncul di FileSystem panel sebagai .aseprite
7. Drag .aseprite ke scene — plugin otomatis bikin AnimatedSprite2D dengan animasi dari tags
8. Double-click .aseprite di Godot untuk edit — langsung terbuka di Aseprite
9. Edit di Aseprite, save (Ctrl+S) — balik ke Godot, changes auto-update
10. Test: play scene, animasi berjalan sesuai tag — tanpa export manual!
