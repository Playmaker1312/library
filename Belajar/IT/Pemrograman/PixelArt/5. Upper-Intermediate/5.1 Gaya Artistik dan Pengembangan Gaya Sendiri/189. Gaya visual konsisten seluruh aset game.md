# 189. Gaya Visual Konsisten Seluruh Aset Game

## Definisi Singkat
Prinsip menjaga keseragaman gaya artistik di semua aset game — karakter, environment, props, UI — sehingga terlihat seperti satu kesatuan yang utuh.

## Analogi
Seperti orkestra: setiap pemain alat musik berbeda (karakter, background, UI), tapi semua mengikuti partitur dan tempo yang sama sehingga menghasilkan harmoni.

## Poin-Poin Penting
- Tentukan art bible di awal: resolusi, palet, teknik shading, proporsi, outline
- Gunakan palet warna bersama (shared palette) untuk semua aset
- Konsisten dengan ketebalan outline: 1px untuk semua atau tanpa outline
- Samakan resolusi per-tile (misal: 16x16) agar seamless di grid
- Proporsi karakter vs environment harus tetap sama di setiap scene
- Teknik shading seragam: semua aset pakai cel-shading atau semuanya gradient
- Detail level konsisten: jika karakter punya 5 warna, tree juga ~5 warna

## Shortcut & Fitur Aseprite
- File > Export > Export Sprite Sheet untuk mengekspor semua aset
- Colors > Palette > Save Palette untuk menyimpan palet bersama (.gpl atau .aseprite)
- Window > Color Palette (F9) untuk mengakses palet global
- Sprite > Sprite Properties untuk cek konsistensi resolusi
- Layer > Layer dari... untuk mengimpor aset ke file palet bersama

## Contoh Kasus Nyata (Step-by-Step)
Membangun konsistensi untuk game RPG mini:

1. Buat shared palette (.gpl) berisi 20 warna: 5 skin tone, 5 hijau alam, 5 biru langit/air, 5 abu/netral
2. Buat tile rumput 16x16 menggunakan 3 warna dari palet hijau
3. Buat karakter 16x16 dengan outline 1px hitam — gunakan warna skin dan abu dari palet
4. Buat pohon 24x32 — tetap gunakan palet yang sama, outline 1px hitam
5. Verifikasi: buka semua aset bersamaan di Aseprite (File > Open each)
6. Tempel semua aset dalam satu canvas untuk perbandingan visual
7. Sesuaikan warna yang terlihat "nyeleneh" dengan eyedropper dari aset lain
8. Konfirmasi: apakah outline semua aset sama tebal? Apakah jumlah warna per aset seimbang?
