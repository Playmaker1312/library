# 190. Master Copy Karya Pixel Artist

## Definisi Singkat
Teknik belajar dengan mereplikasi secara langsung karya pixel artist profesional (dengan izin) untuk memahami proses, teknik shading, dan pengambilan keputusan artistik mereka.

## Analogi
Seperti siswa musik yang memainkan ulang lagu Beethoven — bukan untuk mengklaim sebagai karya sendiri, tapi untuk merasakan bagaimana komponis menyusun melodi dan harmoni.

## Poin-Poin Penting
- Pilih karya dari artist terkenal: e.g. Pedro Medeiros, Cyangmou, Fool, Slynyrd
- Jangan upload hasil master copy sebagai karya original — hormati hak cipta
- Fokus pada teknik: bagaimana mereka membuat bentuk 3D dengan pixel terbatas
- Perhatikan edge placement: pixel mana yang "menonjol" untuk memberi ilusi bentuk
- Catat rasio highlight : midtone : shadow (biasanya 1:2:1 atau 1:3:1)
- Ulangi proses: setelah selesai, gambar ulang dari ingatan untuk menguji pemahaman

## Shortcut & Fitur Aseprite
- Window > Reference (Ctrl+Shift+R) untuk menampilkan gambar referensi di panel terpisah
- Sprite > Sprite Size untuk menyamakan resolusi canvas dengan karya asli
- View > Grid (Shift+G) untuk melihat grid pixel
- Layer > New Layer (bikin layer tracing jika perlu, lalu hapus)
- Onion Skin (tombol bawang di Timeline) untuk animasi master copy

## Contoh Kasus Nyata (Step-by-Step)
Master copy karakter 16x16 dari Pedro Medeiros (sprite open-source):

1. Buka referensi di Window > Reference
2. Atur ukuran canvas 16x16 (Sprite > Sprite Size)
3. Buat layer baru "sketch", blok bentuk dasar karakter dengan warna solid
4. Buat layer baru "shading", tambah highlight putih di area atas/kiri
5. Buat layer baru "shadow", tambah bayangan di area bawah/kanan
6. Buat layer baru "outline", gambar outline 1px dengan warna gelap (bukan hitam absolut)
7. Layer "refinement": haluskan tepi, tambah anti-aliasing tipis
8. Bandingkan dengan referensi — catat perbedaan dan perbaiki
9. Tulis 3 insight yang kamu dapatkan di panel Notes
10. Ulangi tanpa referensi di canvas baru untuk menguji pemahaman
