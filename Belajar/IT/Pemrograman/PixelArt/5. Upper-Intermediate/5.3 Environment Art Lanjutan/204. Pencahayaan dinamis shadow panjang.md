# 204. Pencahayaan Dinamis & Shadow Panjang

## Definisi Singkat
Teknik mensimulasikan pencahayaan real-time dan bayangan dinamis dalam pixel art — termasuk shadow panjang dari sumber cahaya directional dan efek cahaya yang berubah seiring pergerakan.

## Analogi
Bayangan pohon di sore hari lebih panjang dari bayangan di siang hari. Pencahayaan dinamis berarti bayangan berubah sesuai posisi matahari atau sumber cahaya — membuat scene terasa lebih hidup dan realistis.

## Poin-Poin Penting
- Arah cahaya menentukan arah bayangan: matahari di kiri = bayangan ke kanan
- Panjang bayangan tergantung sudut: matahari rendah (sore) = bayangan panjang, tengah hari = bayangan pendek
- Bayangan tidak harus hitam — gunakan warna lebih gelap dari area yang terkena bayangan
- Cahaya dinamis: api unggun memancarkan cahaya oranye yang flicker — efeknya berubah tiap frame
- Gunakan Multiply layer untuk bayangan, Screen/Add layer untuk area terkena cahaya
- Soft shadow: bayangan dengan transisi (anti-aliasing) vs hard shadow: bayangan tegas

## Shortcut & Fitur Aseprite
- Layer > New Layer dengan Blend Mode Multiply untuk shadow
- Layer > New Layer dengan Blend Mode Screen untuk highlight cahaya
- Filter > RGB > Curves untuk adjustment exposure bayangan
- Onion Skin untuk melihat perubahan shadow antar frame animasi
- Selection (M) + Fill (G) untuk membuat bentuk bayangan; Transform (Q) untuk memiringkan

## Contoh Kasus Nyata (Step-by-Step)
Buat scene tiang lampu dengan bayangan dinamis:

1. Canvas 48x48: tiang lampu di kiri, karakter di tengah, tanah
2. Layer tiang: lampu menyala (#ffdd44) dengan glow oranye
3. Layer shadow (Multiply): bayangan tiang ke kanan — panjang, diagonal
4. Layer shadow karakter: bayangan karakter ke kanan, mengikuti arah cahaya lampu
5. Buat 3 frame untuk animasi flicker:
   - Frame 1: cahaya terang, bayangan tegas
   - Frame 2: cahaya redup, bayangan lebih tipis (opacity turun)
   - Frame 3: kembali terang
6. Gunakan Onion Skin untuk memastikan transisi smooth
7. Animasi loop 3 frame — lampu berkedip, bayangan bergerak
8. Tambah efek glow: layer Screen dengan lingkaran kuning di sekitar lampu
9. Review: apakah bayangan konsisten dengan arah cahaya?
