# 196. Karakter — Tipe Tubuh & Proporsi Berbeda

## Definisi Singkat
Teknik mendesain karakter dengan variasi tipe tubuh dan proporsi (tinggi-pendek, gemuk-kurus, besar-kecil) untuk membuat cast yang lebih hidup dan believable.

## Analogi
Dalam kelompok teman, pasti ada yang tinggi kerempeng, pendek gempal, atletis, dan mungil. Karakter game juga harus punya variasi ini — tidak boleh semua karakter pakai template tubuh yang sama.

## Poin-Poin Penting
- Variasi tinggi: gunakan skala berbeda (16px anak kecil, 24px remaja, 32px dewasa)
- Variasi lebar: karakter kurus 12px lebar, karakter gemuk 20px lebar
- Proporsi kepala:tubuh — chibi 1:1, kartun 1:2, semi-realistis 1:4
- Bentuk dasar: persegi panjang vertikal (kurus), horizontal (gemuk), kotak (atletis)
- Penyesuaian animasi: karakter gemuk butuh gerakan lebih berat, karakter kurus lebih lincah
- Jangan lupa proporsi anggota gerak: lengan gemuk vs lengan kurus, langkah lebar vs pendek

## Shortcut & Fitur Aseprite
- Transform tool (Q) untuk resize seleksi (gunakan Nearest Neighbor)
- Sprite > Sprite Size untuk canvas per karakter
- Layer > New Layer untuk sketsa proporsi
- Selection > Resize Selection untuk ubah ukuran bagian tubuh
- Edit > Duplicate (Ctrl+D) sebagai base lalu modifikasi proporsi

## Contoh Kasus Nyata (Step-by-Step)
Buat 3 karakter dengan tipe tubuh berbeda dalam resolusi 32x32:

1. Karakter A — "Brutus": lebar 20px, tinggi 28px, leher pendek, tangan besar, kaki kokoh
   - Bentuk dasar: kotak horizontal, shading datar untuk kesan kokoh
2. Karakter B — "Lina": lebar 12px, tinggi 32px, leher panjang, tangan ramping, kaki jenjang
   - Bentuk dasar: persegi panjang vertikal, shading tipis
3. Karakter C — "Pip": lebar 14px, tinggi 18px (anak kecil), kepala besar 10x10
   - Proporsi chibi: kepala setengah badan
4. Letakkan 3 karakter dalam satu canvas untuk perbandingan
5. Pastikan outline dan palet konsisten di semua karakter
6. Perhatikan: apakah perbedaan proporsi cukup jelas? Jika semua terlihat sama, perbesar kontrasnya
