# Menggunakan Class fw-bold, fw-normal, dan fw-light untuk Font Weight

## Analogi: Perpustakaan Digital

Font weight seperti ketebalan sampul buku. fw-bold adalah sampul hardcover yang tebal dan kokoh, fw-normal adalah sampul softcover standar, fw-light adalah sampul kertas tipis yang ringan. Bootstrap menyediakan class utilitas untuk mengatur ketebalan font tanpa harus menulis CSS kustom, memudahkan perubahan gaya teks secara cepat.

## Penjelasan Detail

Bootstrap menyediakan class font-weight: `.fw-bold` (weight 700), `.fw-semibold` (weight 600), `.fw-normal` (weight 400), `.fw-light` (weight 300), `.fw-lighter` (weight 100). Juga tersedia `.fw-medium` (500) di Bootstrap 5. Kelas ini menggunakan properti CSS `font-weight`. Class `fw-bold` berguna untuk menekankan teks penting, `fw-normal` untuk teks biasa, dan `fw-light` untuk teks dengan penekanan rendah atau desain yang lebih elegan. Class ini bisa dikombinasikan dengan class tipografi lain seperti `lead`, heading, atau display. Bootstrap juga menyediakan class italic dan normal untuk font-style.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Font Weight</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Font Weight Classes</h1>
        <p class="fw-bold">fw-bold (font-weight: 700) — Teks tebal</p>
        <p class="fw-semibold">fw-semibold (font-weight: 600) — Semi tebal</p>
        <p class="fw-normal">fw-normal (font-weight: 400) — Normal</p>
        <p class="fw-light">fw-light (font-weight: 300) — Ringan</p>
        <p class="fw-lighter">fw-lighter (font-weight: 100) — Paling ringan</p>
        <hr>
        <h5>Kombinasi dengan class lain:</h5>
        <p class="lead fw-bold">Lead dengan fw-bold — teks pengantar tebal</p>
        <h2 class="display-6 fw-light">Display-6 dengan fw-light — judul elegan</h2>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- fw-bold (700), fw-semibold (600), fw-normal (400), fw-light (300), fw-lighter (100)
- Gunakan fw-bold untuk penekanan kuat, fw-light untuk desain elegan
- Bisa dikombinasikan dengan heading, display, dan lead
- Font weight mempengaruhi hirarki visual dan keterbacaan
