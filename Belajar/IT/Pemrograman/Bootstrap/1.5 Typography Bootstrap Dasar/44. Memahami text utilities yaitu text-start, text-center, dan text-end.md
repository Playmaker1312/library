# Memahami Text Utilities yaitu text-start, text-center, dan text-end

## Analogi: Perpustakaan Digital

Text utilities seperti pengaturan posisi teks di sampul buku. text-start seperti judul di pojok kiri sampul, text-center seperti judul di tengah sampul, text-end seperti judul di pojok kanan sampul. Bootstrap menyediakan class utilitas untuk mengatur perataan teks dengan mudah, termasuk varian responsive untuk setiap breakpoint.

## Penjelasan Detail

Bootstrap menyediakan class perataan teks: `.text-start` (rata kiri), `.text-center` (rata tengah), `.text-end` (rata kanan). Kelas ini bisa diterapkan ke elemen blok seperti div, p, atau heading. Bootstrap juga mendukung perataan responsive: `.text-sm-start`, `.text-md-center`, `.text-lg-end`, `.text-xl-start`, `.text-xxl-center`. Ini memungkinkan perataan berbeda di setiap ukuran layar. Contoh: `text-center text-md-start` berarti teks rata tengah di mobile dan rata kiri di layar md ke atas. Utility ini menggunakan properti CSS `text-align` dengan nilai `left`, `center`, `right` yang disesuaikan dengan arah teks (LTR/RTL).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1 class="text-center">Text Utilities</h1>
        <p class="text-start bg-light p-3 rounded">text-start: Rata kiri (default).</p>
        <p class="text-center bg-primary text-white p-3 rounded">text-center: Rata tengah.</p>
        <p class="text-end bg-success text-white p-3 rounded">text-end: Rata kanan.</p>
        <hr>
        <h5>Responsive text alignment:</h5>
        <p class="text-center text-md-start bg-warning p-3 rounded">
            text-center text-md-start: Tengah di mobile, kiri di md ke atas.
        </p>
        <p class="text-end text-lg-center bg-info p-3 rounded">
            text-end text-lg-center: Kanan di mobile, tengah di lg ke atas.
        </p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `text-start` (kiri), `text-center` (tengah), `text-end` (kanan)
- Mendukung varian responsive: `text-md-center`, `text-lg-end`, dll
- Gunakan kombinasi: `text-center text-md-start` untuk perbedaan perangkat
- Berbasis CSS `text-align` dengan dukungan RTL
