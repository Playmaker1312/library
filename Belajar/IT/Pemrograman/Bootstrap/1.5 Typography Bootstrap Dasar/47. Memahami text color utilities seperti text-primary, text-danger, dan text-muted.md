# Memahami Text Color Utilities seperti text-primary, text-danger, dan text-muted

## Analogi: Perpustakaan Digital

Text color utilities seperti sistem warna kode buku di perpustakaan. text-primary (biru) untuk buku referensi utama, text-success (hijau) untuk buku yang tersedia, text-danger (merah) untuk buku yang hilang, text-warning (kuning) untuk buku yang perlu perbaikan, text-muted (abu-abu) untuk catatan kecil. Warna membantu pengunjung memahami status dan kategori informasi secara visual.

## Penjelasan Detail

Bootstrap menyediakan class warna teks yang sesuai dengan tema warna Bootstrap: `.text-primary` (#0d6efd/biru), `.text-secondary` (#6c757d/abu), `.text-success` (#198754/hijau), `.text-danger` (#dc3545/merah), `.text-warning` (#ffc107/kuning), `.text-info` (#0dcaf0/biru muda), `.text-light` (#f8f9fa/putih), `.text-dark` (#212529/hitam), `.text-muted` (#6c757d/abu pudar), `.text-white` (#fff/putih), `.text-body` (warna teks default). Juga ada `.text-black-50` dan `.text-white-50` untuk opacity 50%. Bootstrap 5 mendukung varian responsive untuk warna teks. Warna teks bisa dikombinasikan dengan background color classes seperti `.bg-primary`, `.bg-dark`, dll.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Colors</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Text Color Utilities</h1>
        <p class="text-primary">text-primary — Biru (informasi utama)</p>
        <p class="text-success">text-success — Hijau (sukses/berhasil)</p>
        <p class="text-danger">text-danger — Merah (error/bahaya)</p>
        <p class="text-warning bg-dark p-2">text-warning — Kuning (peringatan)</p>
        <p class="text-info">text-info — Biru muda (informasi)</p>
        <p class="text-muted">text-muted — Abu pudar (catatan tambahan)</p>
        <p class="text-dark">text-dark — Hitam (teks default)</p>
        <div class="bg-dark p-3 rounded">
            <p class="text-white mb-0">text-white — Putih (di background gelap)</p>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Warna teks sesuai tema Bootstrap: primary, secondary, success, danger, warning, info
- text-muted untuk teks sekunder/keterangan
- text-white untuk background gelap
- Bisa dikombinasikan dengan background color classes
