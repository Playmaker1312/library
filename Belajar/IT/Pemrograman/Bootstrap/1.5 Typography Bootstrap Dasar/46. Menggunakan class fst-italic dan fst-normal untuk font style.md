# Menggunakan Class fst-italic dan fst-normal untuk Font Style

## Analogi: Perpustakaan Digital

Font style seperti gaya tulisan di sampul buku. fst-italic adalah tulisan miring seperti catatan tangan, fst-normal adalah tulisan tegak standar seperti cetakan mesin. Bootstrap menyediakan class utilitas sederhana untuk mengubah gaya font antara normal dan italic, berguna untuk penekanan atau gaya penulisan tertentu seperti kutipan dan istilah asing.

## Penjelasan Detail

Bootstrap menyediakan dua class font-style: `.fst-italic` (font-style: italic) dan `.fst-normal` (font-style: normal). Class ini menggunakan properti CSS `font-style`. Italic biasanya digunakan untuk judul buku, istilah asing, kutipan, atau penekanan dalam teks. Bootstrap juga memiliki class `.text-decoration-underline` dan `.text-decoration-line-through` untuk dekorasi teks. Font-style bisa dikombinasikan dengan font-weight untuk berbagai variasi tipografi. Misalnya `fw-bold fst-italic` untuk teks tebal miring. Class ini bekerja pada elemen inline maupun block.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Font Style</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Font Style Classes</h1>
        <p class="fst-normal">fst-normal — Gaya font normal.</p>
        <p class="fst-italic">fst-italic — Gaya font miring/italic.</p>
        <p class="fw-bold fst-italic">Kombinasi fw-bold + fst-italic — Tebal miring.</p>
        <p class="fw-light fst-italic">Kombinasi fw-light + fst-italic — Ringan miring.</p>
        <hr>
        <blockquote class="blockquote">
            <p class="fst-italic mb-0">"Hidup adalah apa yang terjadi saat Anda sibuk membuat rencana lain."</p>
            <footer class="blockquote-footer">John Lennon</footer>
        </blockquote>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- fst-italic untuk teks miring, fst-normal untuk teks tegak
- Kombinasikan dengan font-weight: `fw-bold fst-italic`
- Cocok untuk kutipan, istilah asing, dan penekanan
- Italic meningkatkan keterbacaan pada teks panjang tertentu
