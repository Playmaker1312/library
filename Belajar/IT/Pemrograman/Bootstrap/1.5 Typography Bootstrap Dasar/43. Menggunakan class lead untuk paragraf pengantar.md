# Menggunakan Class Lead untuk Paragraf Pengantar

## Analogi: Perpustakaan Digital

Class lead seperti sinopsis atau ringkasan di sampul belakang buku. Ini adalah paragraf pertama yang memberi gambaran umum tentang isi buku, ditulis dengan font yang sedikit lebih besar dan lebih menonjol dari teks biasa. Class lead membantu pembaca memahami esensi konten sebelum membaca detailnya.

## Penjelasan Detail

Class `.lead` adalah utility Bootstrap untuk membuat paragraf pengantar yang lebih menonjol. CSS yang diterapkan: font-size 1.25rem (20px), font-weight 300 (light), dan line-height 1.5. Efeknya, teks lead terlihat lebih besar dan lebih ringan dari paragraf biasa (16px, weight 400). Lead digunakan untuk memperkenalkan bagian atau halaman, memberikan ringkasan, atau menarik perhatian ke teks penting. Biasanya ditempatkan setelah heading utama atau di awal section. Class lead bisa diterapkan ke elemen `<p>` atau elemen lain yang membutuhkan penekanan. Lead bekerja dengan baik dikombinasikan dengan heading dan display.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Class Lead</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Class Lead</h1>
        <p class="lead">Ini adalah paragraf dengan class "lead". Teksnya lebih besar (1.25rem) dan lebih ringan (font-weight 300), cocok untuk pengantar atau ringkasan.</p>
        <p>Ini adalah paragraf biasa tanpa class lead. Ukuran font default Bootstrap adalah 1rem (16px) dengan font-weight 400 (normal). Perbedaan ukuran dan ketebalan terlihat jelas.</p>
        <hr>
        <div class="bg-light p-4 rounded">
            <h2 class="display-6">Tentang Kami</h2>
            <p class="lead">Kami adalah tim pengembang yang berfokus pada teknologi web modern dan pengalaman pengguna yang optimal.</p>
            <p>Didirikan pada tahun 2020, kami telah mengerjakan berbagai proyek dari skala kecil hingga enterprise, membantu klien mewujudkan visi digital mereka dengan solusi inovatif dan tepat waktu.</p>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `.lead` membuat teks lebih besar (1.25rem) dengan weight 300
- Cocok untuk paragraf pengantar atau ringkasan
- Biasanya ditempatkan setelah heading utama
- Bisa dikombinasikan dengan display dan heading
