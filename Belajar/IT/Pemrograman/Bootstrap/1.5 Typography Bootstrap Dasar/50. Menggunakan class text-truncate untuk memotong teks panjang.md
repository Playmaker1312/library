# Menggunakan Class text-truncate untuk Memotong Teks Panjang

## Analogi: Perpustakaan Digital

Text-truncate seperti judul buku yang terlalu panjang dan harus dipotong di sampul dengan tanda "..." di akhir. Di rak perpustakaan yang sempit, judul lengkap tidak muat, jadi hanya ditampilkan seperlunya dengan elipsis. Bootstrap menyediakan class utilitas untuk memotong teks panjang dan menambahkan elipsis secara otomatis, menjaga tata letak tetap rapi tanpa teks yang meluber.

## Penjelasan Detail

Class `.text-truncate` Bootstrap memotong teks yang terlalu panjang dan menambahkan elipsis (...) di akhir. Class ini bekerja dengan kombinasi properti CSS: `overflow: hidden`, `text-overflow: ellipsis`, `white-space: nowrap`. Teks akan dipotong jika melebihi lebar container. Class ini memerlukan elemen dengan lebar tetap (block atau inline-block). Sangat berguna untuk: judul panjang di card, nama file, tautan, teks di tabel, atau deskripsi di kartu produk. Text-truncate bisa diterapkan ke elemen `<p>`, `<span>`, `<div>`, `<a>`, `<td>`, dan lainnya. Pastikan elemen memiliki lebar terbatas agar truncate berfungsi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Truncate</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Text Truncate</h1>
        <p class="lead">Memotong teks panjang dengan elipsis (...).</p>
        <div class="row">
            <div class="col-md-6">
                <div class="card mb-3">
                    <div class="card-body">
                        <h5 class="card-title text-truncate">Ini adalah judul artikel yang sangat panjang sehingga perlu dipotong dengan elipsis</h5>
                        <p class="card-text text-truncate">Deskripsi produk yang sangat panjang sehingga tidak muat dalam satu baris dan akan dipotong secara otomatis menggunakan class text-truncate dari Bootstrap.</p>
                        <a href="#" class="text-truncate d-block">https://www.contoh-website-sangat-panjang.com/artikel/ini-adalah-url-panjang</a>
                    </div>
                </div>
            </div>
            <div class="col-md-6">
                <table class="table table-bordered">
                    <thead><tr><th>Nama File</th><th>Status</th></tr></thead>
                    <tbody>
                        <tr><td class="text-truncate" style="max-width: 200px;">laporan-keuangan-tahunan-perusahaan-tahun-2025.pdf</td><td>Selesai</td></tr>
                        <tr><td class="text-truncate" style="max-width: 200px;">dokumen-pendaftaran-peserta-seminar-teknologi-informasi.pdf</td><td>Proses</td></tr>
                    </tbody>
                </table>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `.text-truncate` memotong teks dengan elipsis (...) di akhir
- Membutuhkan elemen block atau inline-block dengan lebar terbatas
- Berguna untuk judul, tautan, deskripsi, dan teks tabel
- Kombinasi CSS: overflow hidden + text-overflow ellipsis + nowrap
