# Memahami Heading Default Bootstrap dari h1 hingga h6

## Analogi: Perpustakaan Digital

Heading h1 hingga h6 seperti sistem penomoran rak buku di perpustakaan. h1 adalah label rak utama (contoh: "Fiksi"), h2 adalah sub-rak ("Fiksi Ilmiah"), h3 adalah sub-sub-rak ("Cyberpunk"), dan seterusnya. Semakin kecil angka, semakin besar dan penting judulnya. Bootstrap memberikan ukuran font dan margin yang konsisten untuk setiap level heading.

## Penjelasan Detail

Bootstrap memberikan styling khusus untuk elemen heading `<h1>` hingga `<h6>`. h1 (40px/2.5rem), h2 (32px/2rem), h3 (28px/1.75rem), h4 (24px/1.5rem), h5 (20px/1.25rem), h6 (16px/1rem). Setiap heading memiliki font-weight bold (700) dan margin-bottom default. Bootstrap juga menyediakan class `.h1` hingga `.h6` untuk menerapkan gaya heading ke elemen non-heading seperti `<p>` atau `<div>`. Ini berguna saat Anda ingin tampilan heading tetapi tetap mempertahankan aksesibilitas struktur HTML. Class heading juga memiliki varian responsive yang bisa dikustomisasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Heading Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Heading Default Bootstrap</h1>
        <h1>h1. Heading (2.5rem / 40px)</h1>
        <h2>h2. Heading (2rem / 32px)</h2>
        <h3>h3. Heading (1.75rem / 28px)</h3>
        <h4>h4. Heading (1.5rem / 24px)</h4>
        <h5>h5. Heading (1.25rem / 20px)</h5>
        <h6>h6. Heading (1rem / 16px)</h6>
        <hr>
        <p class="h3">Ini paragraf dengan class h3</p>
        <p class="h5">Ini paragraf dengan class h5</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- h1 terbesar (2.5rem), h6 terkecil (1rem)
- Class `.h1` hingga `.h6` untuk memberi gaya heading ke elemen lain
- Heading memiliki font-weight bold (700) secara default
- Gunakan heading sesuai hierarki konten untuk aksesibilitas dan SEO
