# Menggunakan Class text-decoration-none, text-decoration-underline

## Analogi: Perpustakaan Digital

Text decoration seperti garis bawah atau coretan pada teks di perpustakaan. text-decoration-underline seperti garis bawah pada judul bab, text-decoration-none seperti menghapus garis bawah dari tautan yang biasanya ada secara default, text-decoration-line-through seperti coretan pada buku yang sudah tidak digunakan. Bootstrap menyediakan class utilitas untuk mengontrol dekorasi teks dengan mudah.

## Penjelasan Detail

Bootstrap menyediakan class dekorasi teks: `.text-decoration-underline` (menambahkan garis bawah), `.text-decoration-none` (menghapus dekorasi), dan `.text-decoration-line-through` (menambahkan garis coret). Class ini menggunakan properti CSS `text-decoration`. `text-decoration-none` sangat berguna untuk tautan (`<a>`) yang ingin Anda hilangkan garis bawah defaultnya. `text-decoration-underline` berguna untuk menekankan teks tanpa mengubah struktur HTML. `text-decoration-line-through` berguna untuk menunjukkan teks yang sudah tidak berlaku atau dihapus. Class ini bisa dikombinasikan dengan warna teks dan utility tipografi lainnya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Decoration</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Text Decoration Classes</h1>
        <p><a href="#" class="text-decoration-none">text-decoration-none — Tautan tanpa garis bawah</a></p>
        <p><a href="#">Tautan biasa (dengan garis bawah)</a></p>
        <p class="text-decoration-underline">text-decoration-underline — Teks dengan garis bawah</p>
        <p class="text-decoration-line-through">text-decoration-line-through — Teks dengan coretan</p>
        <hr>
        <p><span class="text-decoration-line-through text-muted">Harga lama: Rp 200.000</span> <strong class="text-danger">Harga baru: Rp 150.000</strong></p>
        <p class="text-primary text-decoration-underline fw-bold">Teks berwarna biru, underline, tebal</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `text-decoration-none` untuk menghapus garis bawah (terutama pada link)
- `text-decoration-underline` untuk menambahkan garis bawah
- `text-decoration-line-through` untuk teks coret
- Bisa dikombinasikan dengan warna teks dan font weight
