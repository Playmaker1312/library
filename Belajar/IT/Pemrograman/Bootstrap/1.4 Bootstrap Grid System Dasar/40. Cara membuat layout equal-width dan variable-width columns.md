# Cara Membuat Layout Equal-Width dan Variable-Width Columns

## Analogi: Perpustakaan Digital

Equal-width columns seperti buku dengan ukuran sama yang berjejer rapi di rak — setiap buku mendapat ruang yang sama persis. Variable-width columns seperti buku dengan ukuran berbeda — buku besar mendapat lebih banyak ruang, buku kecil mendapat ruang sesuai ukurannya. Bootstrap menyediakan kedua opsi ini: auto-layout untuk lebar sama, dan col-{number} untuk lebar berbeda.

## Penjelasan Detail

Equal-width columns dibuat menggunakan class `col` tanpa angka, atau dengan breakpoint seperti `col-sm`. Semua kolom akan memiliki lebar yang sama secara otomatis. Variable-width columns menggunakan dua pendekatan: (1) `col-{number}` untuk lebar spesifik (col-4, col-6, col-8), (2) `col-{breakpoint}-auto` untuk lebar sesuai konten. Class `col-auto` membuat kolom selebar kontennya, sisanya dibagi ke kolom lain. Kombinasi keduanya memungkinkan layout fleksibel: beberapa kolom fixed-width dan sisanya auto. Contoh: col-auto + col + col-auto membuat kolom kiri dan kanan selebar konten, kolom tengah mengisi sisa.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Equal vs Variable Width</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Equal-Width vs Variable-Width</h1>
        <h5>Equal-width: class col (sama rata)</h5>
        <div class="row mb-3 text-center">
            <div class="col bg-primary text-white p-3 border">col</div>
            <div class="col bg-success text-white p-3 border">col</div>
            <div class="col bg-warning p-3 border">col</div>
        </div>
        <h5>Variable-width: col-{number}</h5>
        <div class="row mb-3 text-center">
            <div class="col-2 bg-danger text-white p-3 border">col-2</div>
            <div class="col-8 bg-info p-3 border">col-8</div>
            <div class="col-2 bg-secondary text-white p-3 border">col-2</div>
        </div>
        <h5>Variable-width: col-auto (sesuai konten)</h5>
        <div class="row text-center">
            <div class="col-auto bg-primary text-white p-3 border">Auto (pendek)</div>
            <div class="col bg-success text-white p-3 border">Sisa ruang</div>
            <div class="col-auto bg-warning p-3 border">Auto (sedang)</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `col` = equal-width, semua kolom sama lebar
- `col-{number}` = variable-width, lebar ditentukan angka
- `col-auto` = lebar sesuai konten
- Kombinasikan col-auto + col + col-auto untuk layout fleksibel
