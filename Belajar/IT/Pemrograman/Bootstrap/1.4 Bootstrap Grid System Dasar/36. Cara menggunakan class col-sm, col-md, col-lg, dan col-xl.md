# Cara Menggunakan Class col-sm, col-md, col-lg, dan col-xl

## Analogi: Perpustakaan Digital

Class col-sm, col-md, col-lg, dan col-xl seperti instruksi penataan rak buku untuk berbagai ukuran ruangan. Untuk ruang sempit (sm), buku disusun 2 baris. Untuk ruang sedang (md), 3 baris. Untuk ruang luas (lg), 4 baris. Setiap class memberitahu rak buku bagaimana harus berperilaku ketika ruangan mencapai ukuran tertentu. Anda bisa memberikan instruksi berbeda untuk setiap ukuran ruangan.

## Penjelasan Detail

Class kolom dengan breakpoint memungkinkan Anda menentukan lebar kolom yang berbeda untuk setiap ukuran layar. Format: `col-{breakpoint}-{jumlah}`. Contoh: `col-sm-6` berarti kolom mengambil 6/12 (50%) pada layar sm ke atas. Di bawah sm, kolom akan 100%. Anda bisa menggabungkan multiple classes: `col-12 col-sm-6 col-md-4 col-lg-3` — 100% di xs, 50% di sm, 33% di md, 25% di lg. Jika tidak menentukan jumlah (`col-sm`), Bootstrap akan membagi rata kolom di breakpoint tersebut. Prinsipnya: class dengan breakpoint lebih besar berlaku untuk ukuran itu ke atas, class dengan breakpoint lebih kecil bisa ditimpa.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Class col-sm md lg xl</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Class col-{breakpoint}-{jumlah}</h1>
        <p class="lead">col-12 col-sm-6 col-md-4 col-lg-3</p>
        <div class="row text-center">
            <div class="col-12 col-sm-6 col-md-4 col-lg-3 mb-3">
                <div class="card"><div class="card-body"><h5>Item 1</h5><p>XS:12, SM:6, MD:4, LG:3</p></div></div>
            </div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-3 mb-3">
                <div class="card"><div class="card-body"><h5>Item 2</h5><p>Responsive grid</p></div></div>
            </div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-3 mb-3">
                <div class="card"><div class="card-body"><h5>Item 3</h5><p>Bekerja otomatis</p></div></div>
            </div>
            <div class="col-12 col-sm-6 col-md-4 col-lg-3 mb-3">
                <div class="card"><div class="card-body"><h5>Item 4</h5><p>Tanpa JavaScript</p></div></div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `col-sm-6` = 50% lebar pada layar ≥576px, 100% di bawahnya
- Gabungkan classes: `col-12 col-md-6 col-lg-4`
- Class breakpoint lebih besar menimpa class breakpoint lebih kecil
- Tanpa jumlah (`col-md`), kolom dibagi rata
