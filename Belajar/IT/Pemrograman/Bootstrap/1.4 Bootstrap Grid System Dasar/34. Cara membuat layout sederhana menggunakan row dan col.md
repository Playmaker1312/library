# Cara Membuat Layout Sederhana Menggunakan Row dan Col

## Analogi: Perpustakaan Digital

Membuat layout dengan row dan col seperti mengatur tata letak rak buku di perpustakaan. Anda menentukan berapa banyak rak (row) yang dibutuhkan, dan berapa bagian setiap rak (col). Layout sederhana seperti header, sidebar, konten utama, dan footer bisa dibuat dengan mudah menggunakan kombinasi row dan col. Setiap komponen ditempatkan dalam col yang proporsional.

## Penjelasan Detail

Untuk membuat layout sederhana, mulailah dengan container, lalu tambahkan row, dan tempatkan col di dalam row. Layout umum: header full-width (col-12), diikuti row dengan sidebar (col-3 atau col-4) dan konten utama (col-9 atau col-8), lalu footer full-width (col-12). Setiap row membentuk baris horizontal baru. Kolom dalam satu row akan berjejer horizontal. Jika ingin kolom di baris berbeda, buat row baru. Bootstrap juga mendukung nesting (col di dalam col) untuk layout yang lebih kompleks. Gunakan class col-{number} untuk lebar spesifik, atau class col untuk auto-layout.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Layout Sederhana</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-3">
        <div class="row">
            <div class="col-12 bg-dark text-white p-4 text-center">
                <h1>Header Website</h1>
            </div>
        </div>
        <div class="row mt-3">
            <div class="col-12 col-md-3 bg-light p-3">
                <h5>Sidebar</h5>
                <p>Menu navigasi atau widget.</p>
            </div>
            <div class="col-12 col-md-9 bg-white p-3">
                <h2>Konten Utama</h2>
                <p>Ini adalah area konten utama halaman. Layout ini menggunakan col-12 (mobile) dan col-md-3 + col-md-9 (desktop).</p>
            </div>
        </div>
        <div class="row mt-3">
            <div class="col-12 bg-dark text-white text-center p-3">
                <p class="mb-0">Footer - Hak Cipta &copy; 2025</p>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Setiap row adalah baris horizontal baru
- Kombinasikan col-{breakpoint}-{number} untuk layout responsive
- Layout umum: header (12), sidebar+konten (3+9), footer (12)
- Gunakan row baru untuk baris baru
