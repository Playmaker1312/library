# Konsep Grid System 12 Kolom dalam Bootstrap

## Analogi: Perpustakaan Digital

Grid system 12 kolom Bootstrap seperti rak buku modular yang bisa dibagi menjadi 12 bagian sama lebar. Anda bisa menggabungkan beberapa bagian untuk membuat ruang yang lebih besar: 4 bagian untuk satu rak besar, 3 bagian untuk rak sedang, dan sisanya 5 bagian untuk rak lainnya. Angka 12 dipilih karena mudah dibagi: 2, 3, 4, 6 — memberikan fleksibilitas layout maksimal.

## Penjelasan Detail

Bootstrap menggunakan grid system berbasis 12 kolom yang fleksibel. Angka 12 dipilih karena memiliki banyak faktor (1, 2, 3, 4, 6, 12), memungkinkan berbagai kombinasi layout. Setiap baris (row) dibagi menjadi 12 unit kolom. Jika Anda ingin dua kolom sama lebar, masing-masing mendapat 6 unit (col-6). Tiga kolom sama lebar: masing-masing 4 unit (col-4). Empat kolom: masing-masing 3 unit (col-3). Enam kolom: masing-masing 2 unit (col-2). Jika total kolom melebihi 12, kolom akan turun ke baris berikutnya. Grid system ini responsive — Anda bisa menentukan jumlah kolom berbeda untuk setiap breakpoint. Grid Bootstrap menggunakan Flexbox, yang memungkinkan kolom memiliki lebar yang sama secara otomatis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Grid System 12 Kolom</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Grid 12 Kolom Bootstrap</h1>
        <p class="lead">12 kolom = maksimal fleksibilitas layout.</p>
        <div class="row mb-2">
            <div class="col-6 bg-primary text-white p-3 border">col-6</div>
            <div class="col-6 bg-success text-white p-3 border">col-6</div>
        </div>
        <div class="row mb-2">
            <div class="col-4 bg-warning p-3 border">col-4</div>
            <div class="col-4 bg-info p-3 border">col-4</div>
            <div class="col-4 bg-secondary text-white p-3 border">col-4</div>
        </div>
        <div class="row mb-2">
            <div class="col-3 bg-danger text-white p-3 border">col-3</div>
            <div class="col-3 bg-primary text-white p-3 border">col-3</div>
            <div class="col-3 bg-success text-white p-3 border">col-3</div>
            <div class="col-3 bg-warning p-3 border">col-3</div>
        </div>
        <div class="row">
            <div class="col-2 bg-info p-3 border">col-2</div>
            <div class="col-2 bg-secondary text-white p-3 border">col-2</div>
            <div class="col-2 bg-danger text-white p-3 border">col-2</div>
            <div class="col-2 bg-primary text-white p-3 border">col-2</div>
            <div class="col-2 bg-success text-white p-3 border">col-2</div>
            <div class="col-2 bg-warning p-3 border">col-2</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Grid Bootstrap terdiri dari 12 kolom dalam satu baris
- Angka 12 dipilih karena banyak faktor pembagi (2, 3, 4, 6)
- Total kolom dalam satu baris harus ≤ 12, sisanya turun ke baris baru
- Kombinasi umum: 6+6, 4+4+4, 3+3+3+3, 8+4, 9+3
