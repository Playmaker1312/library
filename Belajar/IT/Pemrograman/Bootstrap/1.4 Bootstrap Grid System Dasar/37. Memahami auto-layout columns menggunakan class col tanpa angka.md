# Memahami Auto-Layout Columns Menggunakan Class col Tanpa Angka

## Analogi: Perpustakaan Digital

Auto-layout columns seperti rak buku yang secara otomatis membagi ruang sama rata untuk semua buku. Jika Anda menempatkan 3 buku, masing-masing mendapat 1/3 rak. Jika 6 buku, masing-masing mendapat 1/6 rak. Anda tidak perlu mengukur atau menentukan lebar — rak akan menyesuaikan secara otomatis. Class `col` tanpa angka melakukan hal yang sama untuk kolom Bootstrap.

## Penjelasan Detail

Class `col` (tanpa angka) membuat setiap kolom memiliki lebar yang sama secara otomatis. Jumlah kolom dalam row menentukan lebar masing-masing: 2 kolom = masing-masing 6/12, 3 kolom = masing-masing 4/12, 4 kolom = masing-masing 3/12, 6 kolom = masing-masing 2/12. Class `col` bisa dikombinasikan dengan col berangka dalam satu row. Kolom dengan `col` akan menyesuaikan mengisi sisa ruang. Contoh: `col-8` + `col` akan membuat kolom pertama 8/12 dan kolom kedua otomatis 4/12. Auto-layout juga bisa responsive: `col-sm` akan membuat kolom sama lebar hanya pada layar sm ke atas. Ini sangat berguna untuk jumlah kolom yang dinamis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Auto Layout Columns</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Auto-Layout dengan class col</h1>
        <p class="lead">3 kolom auto: masing-masing sama lebar.</p>
        <div class="row mb-3 text-center">
            <div class="col bg-primary text-white p-3 border">col (auto)</div>
            <div class="col bg-success text-white p-3 border">col (auto)</div>
            <div class="col bg-warning p-3 border">col (auto)</div>
        </div>
        <p class="lead">Kombinasi col-8 + col (auto sisa).</p>
        <div class="row mb-3 text-center">
            <div class="col-8 bg-danger text-white p-3 border">col-8</div>
            <div class="col bg-info p-3 border">col (otomatis 4/12)</div>
        </div>
        <p class="lead">5 kolom auto.</p>
        <div class="row text-center">
            <div class="col bg-primary text-white p-2 border">col</div>
            <div class="col bg-success text-white p-2 border">col</div>
            <div class="col bg-warning p-2 border">col</div>
            <div class="col bg-info p-2 border">col</div>
            <div class="col bg-secondary text-white p-2 border">col</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Class `col` membagi lebar sama rata ke semua kolom
- Auto-layout fleksibel untuk jumlah kolom yang dinamis
- Bisa dikombinasikan dengan col berangka: col-8 + col = 8 + 4
- Juga bisa responsive: `col-sm`, `col-md`, dll
