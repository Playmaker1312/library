# Memahami Container, Row, dan Col sebagai Tiga Elemen Utama Grid

## Analogi: Perpustakaan Digital

Container, row, dan col adalah tiga lapisan rak buku di perpustakaan. Container adalah ruangan perpustakaan yang membatasi area buku. Row adalah rak buku horizontal di dalam ruangan. Col adalah bagian-bagian rak yang memisahkan buku dalam kelompok. Ketiganya harus ada dalam urutan yang benar: container > row > col. Jika salah satu hilang, tata letak tidak akan berfungsi dengan baik.

## Penjelasan Detail

Tiga elemen utama grid Bootstrap harus digunakan dalam hierarki yang tepat. Container (`.container`) adalah elemen terluar yang memberikan lebar maksimum dan padding horizontal. Row (`.row`) adalah elemen yang membungkus kolom dan memberikan gutter (jarak antar kolom) negatif untuk mengimbangi padding kolom. Col (`.col-*`) adalah elemen tempat konten ditempatkan, dengan padding untuk gutter. Aturan: container hanya berisi row, row hanya berisi col, dan col berisi konten. Row berfungsi sebagai flex container yang mengatur kolom-kolom di dalamnya. Tanpa container, konten akan melebar penuh tanpa batas. Tanpa row, kolom tidak akan memiliki gutter yang benar. Tanpa col, grid tidak akan membagi ruang.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Container Row Col</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Container -> Row -> Col</h1>
        <p class="lead">Tiga elemen utama grid Bootstrap.</p>
        <div class="container bg-light p-3 rounded border mb-3">
            <strong>Container:</strong> Membatasi lebar
            <div class="row bg-primary text-white p-2 rounded mt-2">
                <strong>Row:</strong> Flex container
                <div class="col bg-warning text-dark p-3 rounded mt-2">Col: tempat konten</div>
                <div class="col bg-success text-white p-3 rounded mt-2">Col: tempat konten</div>
            </div>
        </div>
        <div class="alert alert-info">
            Hierarki wajib: <code>.container</code> &gt; <code>.row</code> &gt; <code>.col</code>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Tiga elemen utama: container (pembatas), row (pembungkus kolom), col (tempat konten)
- Hierarki wajib: container > row > col
- Row adalah flex container, col adalah flex item
- Tanpa row, gutter tidak akan berfungsi dengan benar
