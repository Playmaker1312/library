# Memahami offcanvas-start, offcanvas-end, offcanvas-top, dan offcanvas-bottom

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang memiliki empat jenis laci: laci kiri untuk katalog penulis, laci kanan untuk kategori buku, laci atas untuk pengumuman, dan laci bawah untuk arsip lama. Setiap offcanvas muncul dari arah yang berbeda, memberikan fleksibilitas tata letak sesuai kebutuhan konten dan konteks pengguna.

## Penjelasan Detail

Bootstrap menyediakan empat class posisi untuk offcanvas: `.offcanvas-start` (muncul dari tepi kiri, default), `.offcanvas-end` (dari tepi kanan), `.offcanvas-top` (dari tepi atas — tingginya tetap, body scrollable), `.offcanvas-bottom` (dari tepi bawah). Setiap posisi memiliki dimensi default: start/end memiliki lebar 400px, top/bottom memiliki tinggi 30vh. Anda bisa mengubah dimensi dengan CSS kustom. Pilih posisi berdasarkan UX: start untuk menu navigasi, end untuk panel detail, top untuk banner notifikasi, bottom untuk mobile menu. Backdrop dan perilaku scroll dapat dikonfigurasi independen untuk setiap offcanvas.

## Contoh Kode Implementasi

```html
<!-- Tombol pemicu -->
<button data-bs-toggle="offcanvas" data-bs-target="#leftPanel">Kiri</button>
<button data-bs-toggle="offcanvas" data-bs-target="#rightPanel">Kanan</button>
<button data-bs-toggle="offcanvas" data-bs-target="#topPanel">Atas</button>
<button data-bs-toggle="offcanvas" data-bs-target="#bottomPanel">Bawah</button>

<!-- Offcanvas dari kiri (navigasi) -->
<div class="offcanvas offcanvas-start" tabindex="-1" id="leftPanel">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title">Navigasi</h5>
    <button class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  <div class="offcanvas-body">
    <nav class="nav flex-column">...</nav>
  </div>
</div>

<!-- Offcanvas dari kanan (panel detail) -->
<div class="offcanvas offcanvas-end" tabindex="-1" id="rightPanel">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title">Detail Buku</h5>
    <button class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  <div class="offcanvas-body">...</div>
</div>

<!-- Offcanvas dari atas (notifikasi) -->
<div class="offcanvas offcanvas-top" tabindex="-1" id="topPanel" style="height: 200px;">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title">Pengumuman</h5>
    <button class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  <div class="offcanvas-body">...</div>
</div>

<!-- Offcanvas dari bawah (mobile menu) -->
<div class="offcanvas offcanvas-bottom" tabindex="-1" id="bottomPanel" style="height: 40vh;">
  <div class="offcanvas-header">
    <h5 class="offcanvas-title">Menu Cepat</h5>
    <button class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  <div class="offcanvas-body">...</div>
</div>
```

## Poin Penting
- `offcanvas-start`: muncul dari kiri (default), lebar 400px
- `offcanvas-end`: muncul dari kanan, lebar 400px
- `offcanvas-top`: muncul dari atas, tinggi 30vh
- `offcanvas-bottom`: muncul dari bawah, tinggi 30vh
- Dimensi dapat disesuaikan dengan CSS kustom
