# Membuat collapse section menggunakan data-bs-toggle collapse

## Analogi: Perpustakaan Digital

Seperti rak buku yang bisa dilipat — saat tertutup, rak menyembunyikan koleksi buku untuk menghemat ruang; saat dibuka, menampilkan semua buku dengan rapi. Collapse Bootstrap adalah mekanisme show/hide dengan animasi yang sempurna untuk FAQ, panel aksordeon, menu expandable, dan konten yang bisa disembunyikan.

## Penjelasan Detail

Collapse Bootstrap menggunakan data attributes untuk mengontrol visibilitas elemen. Atur `data-bs-toggle="collapse"` pada tombol pemicu, dan `data-bs-target="#idElemen"` untuk menunjuk konten yang akan ditampilkan/sembunyikan. Untuk tautan (`<a>`), gunakan `href` sebagai pengganti `data-bs-target`. Elemen target membutuhkan class `.collapse` (tersembunyi) atau `.collapse.show` (terlihat). Untuk efek accordion (hanya satu panel terbuka), bungkus dalam parent dengan class `.accordion` dan tambahkan `data-bs-parent="#accordionId"` pada setiap collapse. Class `.collapsing` ditambahkan selama animasi transisi. Multi-target dapat menggunakan selector dengan koma di `data-bs-target`.

## Contoh Kode Implementasi

```html
<!-- FAQ sederhana dengan collapse -->
<div class="mb-3">
  <!-- Trigger -->
  <button class="btn btn-primary" 
          type="button" 
          data-bs-toggle="collapse" 
          data-bs-target="#faq1">
    Apa itu Bootstrap?
  </button>

  <!-- Collapsible content -->
  <div id="faq1" class="collapse mt-2">
    <div class="card card-body">
      Bootstrap adalah framework CSS open-source yang digunakan untuk 
      mengembangkan website responsif dan mobile-first. Dikembangkan oleh 
      Twitter, Bootstrap menyediakan komponen UI, sistem grid, dan utilitas 
      yang mempercepat pengembangan web.
    </div>
  </div>
</div>

<!-- Accordion group -->
<div class="accordion" id="bookAccordion">
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button" type="button" 
              data-bs-toggle="collapse" 
              data-bs-target="#book1" 
              data-bs-parent="#bookAccordion">
        Buku Fiksi
      </button>
    </h2>
    <div id="book1" class="accordion-collapse collapse show">
      <div class="accordion-body">Daftar buku fiksi...</div>
    </div>
  </div>

  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button collapsed" type="button" 
              data-bs-toggle="collapse" 
              data-bs-target="#book2" 
              data-bs-parent="#bookAccordion">
        Buku Non-Fiksi
      </button>
    </h2>
    <div id="book2" class="accordion-collapse collapse">
      <div class="accordion-body">Daftar buku non-fiksi...</div>
    </div>
  </div>
</div>
```

## Poin Penting
- Tombol pemicu: `data-bs-toggle="collapse"` + `data-bs-target="#targetId"`
- Elemen target: class `.collapse` (tersembunyi) atau `.collapse.show` (terlihat)
- Untuk accordion, tambahkan `data-bs-parent="#parentId"` pada setiap collapse
- Class `.collapsing` ditambahkan otomatis selama animasi transisi
