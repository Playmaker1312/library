# Membuat offcanvas sidebar menggunakan class offcanvas

## Analogi: Perpustakaan Digital

Seperti laci arsip yang bisa ditarik keluar dari meja pustakawan — saat terbuka, menampilkan file-file penting; saat tertutup, menyembunyikannya dan tidak memakan ruang meja. Offcanvas Bootstrap adalah panel yang muncul dari tepi layar (kiri, kanan, atas, atau bawah) untuk menampilkan konten tambahan tanpa meninggalkan halaman saat ini.

## Penjelasan Detail

Offcanvas adalah komponen Bootstrap untuk membuat sidebar, menu, atau panel yang muncul dari tepi viewport. Struktur dasar: `.offcanvas` (container utama), `.offcanvas-header` (bagian atas dengan judul dan tombol tutup), `.offcanvas-body` (konten scrollable). Posisi diatur dengan class `.offcanvas-start` (kiri, default), `.offcanvas-end` (kanan), `.offcanvas-top` (atas), `.offcanvas-bottom` (bawah). Gunakan `data-bs-toggle="offcanvas"` untuk tombol pemicu dan `data-bs-target` untuk menunjuk ke ID offcanvas. Backdrop gelap muncul di belakang offcanvas dan dapat diklik untuk menutupnya. Offcanvas dapat berisi navigasi, form, daftar, atau komponen apa pun.

## Contoh Kode Implementasi

```html
<!-- Tombol untuk membuka offcanvas -->
<button class="btn btn-primary" type="button" 
        data-bs-toggle="offcanvas" 
        data-bs-target="#sidebarMenu">
  &#9776; Buka Menu
</button>

<!-- Offcanvas sidebar kiri -->
<div class="offcanvas offcanvas-start" tabindex="-1" id="sidebarMenu" 
     data-bs-backdrop="true" data-bs-scroll="true">
  
  <!-- Header -->
  <div class="offcanvas-header">
    <h5 class="offcanvas-title">Menu Perpustakaan</h5>
    <button type="button" class="btn-close" data-bs-dismiss="offcanvas"></button>
  </div>
  
  <!-- Body konten -->
  <div class="offcanvas-body">
    <ul class="nav flex-column">
      <li class="nav-item">
        <a class="nav-link active" href="#">Beranda</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Koleksi Buku</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Anggota</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Peminjaman</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Pengaturan</a>
      </li>
    </ul>
    
    <hr>
    <p class="text-muted small">Panel ini dapat berisi navigasi, form, atau konten lainnya.</p>
  </div>
</div>
```

## Poin Penting
- Class posisi: `.offcanvas-start` (kiri), `.offcanvas-end` (kanan), `.offcanvas-top` (atas), `.offcanvas-bottom` (bawah)
- Struktur: `.offcanvas-header` (judul + tombol tutup) dan `.offcanvas-body` (konten scrollable)
- `data-bs-backdrop="true"` menampilkan backdrop gelap
- `data-bs-scroll="true"` mengizinkan scroll halaman utama saat offcanvas terbuka
