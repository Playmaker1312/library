# Membuat tooltip menggunakan data-bs-toggle dan data-bs-placement

## Analogi: Perpustakaan Digital

Seperti label kecil yang muncul saat Anda mengarahkan kursor ke nomor rak buku — "Rak A12: Fiksi Ilmiah" — tooltip Bootstrap menampilkan teks bantuan singkat saat pengguna berinteraksi (hover, focus, atau click) dengan elemen. Tooltip membantu pengguna memahami fungsi elemen tanpa memenuhi halaman dengan teks penjelasan.

## Penjelasan Detail

Tooltip Bootstrap menggunakan class dan data attributes untuk inisialisasi. Atribut `data-bs-toggle="tooltip""` menandai elemen sebagai tooltip. `data-bs-title` berisi teks yang ditampilkan (menggantikan atribut `title`). `data-bs-placement` mengatur posisi: `top`, `bottom`, `left`, `right`, atau `auto`. Secara default, tooltip muncul saat hover (desktop) dan focus (mobile/tab). Tooltip membutuhkan inisialisasi JavaScript — `new bootstrap.Tooltip(element)` — tidak aktif hanya dengan data attributes. Gunakan opsi `html: true` untuk tooltip dengan HTML. Tooltip didesain untuk teks pendek; untuk konten lebih panjang, gunakan Popover. Tooltip otomatis diposisikan ulang jika tidak muat di viewport.

## Contoh Kode Implementasi

```html
<p>
  <!-- Tooltip di atas -->
  <button class="btn btn-secondary" 
          data-bs-toggle="tooltip" 
          data-bs-placement="top" 
          data-bs-title="Tooltip di atas">
    Hover Atas
  </button>

  <!-- Tooltip di kanan -->
  <button class="btn btn-secondary" 
          data-bs-toggle="tooltip" 
          data-bs-placement="right" 
          data-bs-title="Tooltip di kanan">
    Hover Kanan
  </button>

  <!-- Tooltip di bawah -->
  <button class="btn btn-secondary" 
          data-bs-toggle="tooltip" 
          data-bs-placement="bottom" 
          data-bs-title="Tooltip di bawah">
    Hover Bawah
  </button>

  <!-- Tooltip di kiri -->
  <button class="btn btn-secondary" 
          data-bs-toggle="tooltip" 
          data-bs-placement="left" 
          data-bs-title="Tooltip di kiri">
    Hover Kiri
  </button>

  <!-- Tooltip dengan HTML -->
  <button class="btn btn-info" 
          data-bs-toggle="tooltip" 
          data-bs-placement="top" 
          data-bs-html="true" 
          data-bs-title="<strong>Perhatian!</strong> <em>Baca panduan</em>">
    Tooltip HTML
  </button>
</p>

<script>
  // Inisialisasi semua tooltip di halaman
  document.addEventListener('DOMContentLoaded', function() {
    const tooltipTriggerList = document.querySelectorAll('[data-bs-toggle="tooltip"]');
    tooltipTriggerList.forEach(function(el) {
      new bootstrap.Tooltip(el);
    });
  });
</script>
```

## Poin Penting
- Tooltip membutuhkan inisialisasi JavaScript: `new bootstrap.Tooltip(element)`
- `data-bs-title` untuk konten, `data-bs-placement` untuk posisi
- Posisi: top, bottom, left, right, auto (default: top)
- Inisialisasi massal dengan `querySelectorAll('[data-bs-toggle="tooltip"]')`
