# Membuat carousel atau slider menggunakan class carousel

## Analogi: Perpustakaan Digital

Seperti etalase buku bergulir di perpustakaan yang menampilkan sampul buku terbaru secara bergantian — carousel Bootstrap adalah slider yang menampilkan serangkaian konten (gambar, teks, kartu) secara berurutan. Pengguna dapat menavigasi manual melalui tombol atau menontonnya bergulir otomatis.

## Penjelasan Detail

Carousel Bootstrap adalah komponen slideshow untuk menampilkan konten secara siklis. Struktur dasarnya terdiri dari container `.carousel` yang membungkus `.carousel-inner` (berisi `.carousel-item`) dan elemen navigasi. Setiap `.carousel-item` mewakili satu slide. Gunakan `.active` pada item pertama untuk menentukan slide awal. Atribut `data-bs-ride="carousel"` memulai animasi otomatis. Carousel mendukung gambar, video, teks, atau kombinasi. Teks overlay bisa ditambahkan dengan `.carousel-caption`. Navigasi disediakan melalui `.carousel-control-prev`/`.carousel-control-next` (tombol panah) dan `.carousel-indicators` (indikator titik). Carousel juga mendukung crossfade transition dengan menambahkan class `.carousel-fade`.

## Contoh Kode Implementasi

```html
<div id="heroCarousel" class="carousel slide" data-bs-ride="carousel">
  <!-- Indikator -->
  <div class="carousel-indicators">
    <button type="button" data-bs-target="#heroCarousel" data-bs-slide-to="0" class="active"></button>
    <button type="button" data-bs-target="#heroCarousel" data-bs-slide-to="1"></button>
    <button type="button" data-bs-target="#heroCarousel" data-bs-slide-to="2"></button>
  </div>

  <!-- Slide -->
  <div class="carousel-inner">
    <div class="carousel-item active">
      <img src="slide1.jpg" class="d-block w-100" alt="Slide 1">
      <div class="carousel-caption d-none d-md-block">
        <h5>Selamat Datang di Perpustakaan</h5>
        <p>Temukan ribuan buku menarik</p>
      </div>
    </div>
    <div class="carousel-item">
      <img src="slide2.jpg" class="d-block w-100" alt="Slide 2">
      <div class="carousel-caption d-none d-md-block">
        <h5>Koleksi Terbaru</h5>
        <p>Buku-buku best seller 2024</p>
      </div>
    </div>
    <div class="carousel-item">
      <img src="slide3.jpg" class="d-block w-100" alt="Slide 3">
      <div class="carousel-caption d-none d-md-block">
        <h5>Diskon Anggota Baru</h5>
        <p>Daftar sekarang dan dapatkan promo</p>
      </div>
    </div>
  </div>

  <!-- Kontrol navigasi -->
  <button class="carousel-control-prev" type="button" data-bs-target="#heroCarousel" data-bs-slide="prev">
    <span class="carousel-control-prev-icon"></span>
  </button>
  <button class="carousel-control-next" type="button" data-bs-target="#heroCarousel" data-bs-slide="next">
    <span class="carousel-control-next-icon"></span>
  </button>
</div>
```

## Poin Penting
- Struktur: `.carousel` → `.carousel-inner` → `.carousel-item`
- Gunakan `.active` pada item pertama untuk menentukan slide awal
- `data-bs-ride="carousel"` memulai animasi otomatis
- Tambahkan `.carousel-fade` untuk efek transisi fade, bukan slide
