# Membuat tab content yang berkaitan dengan nav tabs menggunakan tab-content dan tab-pane

## Analogi: Perpustakaan Digital

Seperti binder dengan tab per kategori — tab "Fiksi", "Non-Fiksi", "Majalah" — setiap tab saat diklik memperlihatkan isi kategori yang berbeda. Bootstrap Tabs memungkinkan pembuatan antarmuka tab yang terorganisir, di mana konten ditukar tanpa memuat ulang halaman.

## Penjelasan Detail

Bootstrap Tabs bekerja dengan memasangkan navigasi (`.nav` dengan `.nav-tabs`) dengan konten (`.tab-content` berisi `.tab-pane`). Setiap tautan di navigasi memiliki atribut `data-bs-toggle="tab"` dan `href` atau `data-bs-target` yang menunjuk ke ID `.tab-pane` terkait. `.nav-link` dengan `.active` menandai tab yang aktif. `.tab-pane` dengan `.active` menandai konten yang ditampilkan. Class `.fade` pada `.tab-pane` menambahkan efek animasi transisi. Anda juga bisa menggunakan `.nav-pills` sebagai pengganti `.nav-tabs` untuk tampilan pil. Tabs dapat diinisialisasi via JavaScript API `new bootstrap.Tab(element)` untuk kontrol programatik. Tab juga dapat diaktifkan melalui event `shown.bs.tab`.

## Contoh Kode Implementasi

```html
<!-- Navigasi Tabs -->
<ul class="nav nav-tabs" id="bookTabs" role="tablist">
  <li class="nav-item" role="presentation">
    <button class="nav-link active" id="fiction-tab" 
            data-bs-toggle="tab" 
            data-bs-target="#fiction" 
            type="button" role="tab">
      Fiksi
    </button>
  </li>
  <li class="nav-item" role="presentation">
    <button class="nav-link" id="nonfiction-tab" 
            data-bs-toggle="tab" 
            data-bs-target="#nonfiction" 
            type="button" role="tab">
      Non-Fiksi
    </button>
  </li>
  <li class="nav-item" role="presentation">
    <button class="nav-link" id="magazine-tab" 
            data-bs-toggle="tab" 
            data-bs-target="#magazine" 
            type="button" role="tab">
      Majalah
    </button>
  </li>
</ul>

<!-- Konten Tabs -->
<div class="tab-content" id="bookTabsContent">
  <div class="tab-pane fade show active" id="fiction" role="tabpanel">
    <div class="p-3">
      <h4>Koleksi Fiksi</h4>
      <ul>
        <li>Laskar Pelangi - Andrea Hirata</li>
        <li>Bumi Manusia - Pramoedya A. Toer</li>
        <li>Harry Potter - J.K. Rowling</li>
      </ul>
    </div>
  </div>
  
  <div class="tab-pane fade" id="nonfiction" role="tabpanel">
    <div class="p-3">
      <h4>Koleksi Non-Fiksi</h4>
      <ul>
        <li>Sapiens - Yuval Noah Harari</li>
        <li>Atomic Habits - James Clear</li>
        <li>The Psychology of Money - Morgan Housel</li>
      </ul>
    </div>
  </div>
  
  <div class="tab-pane fade" id="magazine" role="tabpanel">
    <div class="p-3">
      <h4>Koleksi Majalah</h4>
      <ul>
        <li>National Geographic</li>
        <li>Tempo</li>
        <li>Time Magazine</li>
      </ul>
    </div>
  </div>
</div>

<!-- JavaScript API untuk kontrol tab -->
<script>
  // Aktifkan tab via JavaScript
  const tabTrigger = document.querySelector('#nonfiction-tab');
  const tab = new bootstrap.Tab(tabTrigger);
  
  // Event saat tab berubah
  document.querySelectorAll('[data-bs-toggle="tab"]').forEach(tabEl => {
    tabEl.addEventListener('shown.bs.tab', event => {
      console.log('Tab aktif:', event.target.id);
    });
  });
  
  // Buka tab non-fiksi setelah 3 detik
  setTimeout(() => tab.show(), 3000);
</script>
```

## Poin Penting
- Gunakan `.nav-tabs` dengan `data-bs-toggle="tab"` untuk navigasi
- Konten menggunakan `.tab-content` dengan `.tab-pane` untuk setiap panel
- `.tab-pane.active` menandai konten yang ditampilkan; tambahkan `.fade` untuk animasi
- JavaScript API: `new bootstrap.Tab(element).show()` untuk kontrol programatik
