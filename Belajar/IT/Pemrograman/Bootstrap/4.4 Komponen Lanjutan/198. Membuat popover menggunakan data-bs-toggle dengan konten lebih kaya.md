# Membuat popover menggunakan data-bs-toggle dengan konten lebih kaya

## Analogi: Perpustakaan Digital

Jika tooltip adalah label kecil, popover adalah kartu informasi yang bisa menampung lebih banyak detail — seperti brosur mini yang muncul saat pengunjung mengklik rak buku, berisi sinopsis buku, rating, dan stok tersedia. Popover dapat menampilkan teks, gambar, tautan, bahkan form sederhana.

## Penjelasan Detail

Popover Bootstrap mirip dengan tooltip tetapi dengan konten yang lebih kaya. Atribut `data-bs-toggle="popover"` mengaktifkan popover. `data-bs-title` untuk judul, `data-bs-content` untuk konten utama, `data-bs-placement` untuk posisi. Atribut khusus: `data-bs-html="true"` untuk mengizinkan HTML dalam konten, `data-bs-trigger="focus"` agar popover tertutup saat klik di luar, `data-bs-custom-class` untuk styling kustom. Secara default, popover muncul saat diklik (bukan hover) untuk UX yang lebih baik. Popover membutuhkan inisialisasi JavaScript seperti tooltip. Konten bisa berupa string, fungsi, atau elemen DOM. Popover mendukung sanitasi HTML untuk keamanan.

## Contoh Kode Implementasi

```html
<button type="button" 
        class="btn btn-lg btn-danger" 
        data-bs-toggle="popover" 
        data-bs-title="<i class='bi bi-info-circle'></i> Detail Buku" 
        data-bs-content="
          <div class='popover-body-custom'>
            <p><strong>Judul:</strong> Bootstrap 5 untuk Semua</p>
            <p><strong>Penulis:</strong> Tim Developer</p>
            <p><strong>Rating:</strong> ⭐⭐⭐⭐</p>
            <p><strong>Stok:</strong> 12 tersedia</p>
            <button class='btn btn-sm btn-primary'>Pinjam Buku</button>
          </div>
        " 
        data-bs-html="true" 
        data-bs-placement="right"
        data-bs-trigger="click">
  Klik untuk Detail Buku
</button>

<!-- Popover dengan gambar -->
<button class="btn btn-success"
        data-bs-toggle="popover"
        data-bs-title="Profil Penulis"
        data-bs-content='
          <div class="text-center">
            <img src="https://via.placeholder.com/80" 
                 class="rounded-circle mb-2" 
                 alt="Author">
            <p class="mb-1"><strong>Dr. John Doe</strong></p>
            <p class="text-muted small">Penulis 50+ buku programming</p>
          </div>
        '
        data-bs-html="true"
        data-bs-placement="bottom">
  Profil Penulis
</button>

<script>
  document.addEventListener('DOMContentLoaded', function() {
    const popoverList = document.querySelectorAll('[data-bs-toggle="popover"]');
    popoverList.forEach(function(el) {
      new bootstrap.Popover(el);
    });
  });
</script>
```

## Poin Penting
- Gunakan `data-bs-toggle="popover"`, `data-bs-title`, dan `data-bs-content`
- Atur `data-bs-html="true"` untuk konten HTML
- Trigger default adalah `click`, bukan hover
- Inisialisasi popover dengan `new bootstrap.Popover(element)`
