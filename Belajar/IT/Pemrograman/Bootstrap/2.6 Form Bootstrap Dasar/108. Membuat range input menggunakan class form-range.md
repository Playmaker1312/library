# Membuat range input menggunakan class form-range

## Analogi: Perpustakaan Digital

Pengatur volume atau kecerahan lampu baca di perpustakaan yang bisa digeser dari minimum ke maksimum. Range slider memungkinkan pengunjung memilih nilai dalam rentang tertentu dengan menggeser thumb. Bootstrap menyediakan class form-range untuk styling range input.

## Penjelasan Detail

Class `form-range` mengubah `<input type="range">` menjadi slider horizontal yang stylish. Atribut `min` dan `max` menentukan rentang nilai, `step` mengatur increment, dan `value` untuk nilai default. Range mendukung state `disabled`. CSS kustom dapat mengubah warna thumb dan track. Range slider berguna untuk pengaturan volume, harga, ukuran, rating, atau nilai numerik dalam rentang tertentu.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Range Input</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Range Input</h1>
        <div class="row">
            <div class="col-md-6">
                <h5>Range Dasar:</h5>
                <div class="mb-3">
                    <label for="range1" class="form-label">Volume: <span id="volLabel">50</span></label>
                    <input type="range" class="form-range" id="range1" min="0" max="100" step="1" value="50" oninput="document.getElementById('volLabel').textContent=this.value">
                </div>
                <div class="mb-3">
                    <label for="range2" class="form-label">Kecerahan: <span id="brightLabel">80</span></label>
                    <input type="range" class="form-range" id="range2" min="0" max="100" value="80" oninput="document.getElementById('brightLabel').textContent=this.value">
                </div>
                <div class="mb-3">
                    <label for="range3" class="form-label">Range step 10: <span id="stepLabel">30</span></label>
                    <input type="range" class="form-range" id="range3" min="0" max="100" step="10" value="30" oninput="document.getElementById('stepLabel').textContent=this.value">
                </div>
            </div>
            <div class="col-md-6">
                <h5>Range Disabled:</h5>
                <div class="mb-3">
                    <label for="range4" class="form-label">Range Non-aktif</label>
                    <input type="range" class="form-range" id="range4" disabled>
                </div>
                <h5>Contoh Penggunaan Range:</h5>
                <div class="border p-3 rounded bg-light">
                    <div class="mb-3">
                        <label class="form-label">Rating Buku: <span id="ratingLabel">3</span>/5</label>
                        <input type="range" class="form-range" min="1" max="5" step="1" value="3" oninput="document.getElementById('ratingLabel').textContent=this.value">
                    </div>
                    <div class="mb-3">
                        <label class="form-label">Harga Maks: Rp <span id="priceLabel">500</span>rb</label>
                        <input type="range" class="form-range" min="50" max="1000" step="50" value="500" oninput="document.getElementById('priceLabel').textContent=this.value">
                    </div>
                    <div class="mb-3">
                        <label class="form-label">Jumlah Buku Dipinjam: <span id="qtyLabel">2</span></label>
                        <input type="range" class="form-range" min="0" max="10" step="1" value="2" oninput="document.getElementById('qtyLabel').textContent=this.value">
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- form-range untuk styling input type="range"
- Atribut min, max, step untuk mengontrol rentang dan increment
- Gunakan JavaScript untuk menampilkan nilai range secara real-time
