# Membuat form input dasar menggunakan class form-control

## Analogi: Perpustakaan Digital

Formulir pendaftaran anggota perpustakaan memiliki kotak isian untuk nama, alamat, dan nomor telepon. Setiap kotak isian (input) memiliki gaya yang seragam: border abu-abu, padding yang nyaman, dan sudut membulat. Bootstrap menyediakan class form-control untuk menyeragamkan semua input teks dalam form.

## Penjelasan Detail

Class `form-control` mengubah elemen input `<input>` dan `<textarea>` menjadi input Bootstrap yang stylish. Class ini mengatur properti seperti `display: block`, `width: 100%`, padding, border, border-radius, dan shadow saat focus. form-control bekerja untuk berbagai tipe input: text, email, password, number, date, file, dan lainnya. Ukuran: `form-control-sm` untuk kecil, `form-control-lg` untuk besar. form-control juga memiliki state validasi dengan `is-valid` dan `is-invalid`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Form Control</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Form Control</h1>
        <div class="row">
            <div class="col-md-6">
                <div class="mb-3">
                    <label class="form-label">Nama Lengkap</label>
                    <input type="text" class="form-control" placeholder="Masukkan nama">
                </div>
                <div class="mb-3">
                    <label class="form-label">Email</label>
                    <input type="email" class="form-control" placeholder="nama@email.com">
                </div>
                <div class="mb-3">
                    <label class="form-label">Password</label>
                    <input type="password" class="form-control">
                </div>
                <div class="mb-3">
                    <label class="form-label">Tanggal Lahir</label>
                    <input type="date" class="form-control">
                </div>
                <div class="mb-3">
                    <label class="form-label">Ukuran form-control</label>
                    <input class="form-control form-control-sm mb-2" placeholder="form-control-sm">
                    <input class="form-control mb-2" placeholder="Default">
                    <input class="form-control form-control-lg" placeholder="form-control-lg">
                </div>
            </div>
            <div class="col-md-6">
                <div class="mb-3">
                    <label class="form-label">Upload File</label>
                    <input type="file" class="form-control">
                </div>
                <div class="mb-3">
                    <label class="form-label">Nomor Telepon</label>
                    <input type="tel" class="form-control" placeholder="08xx-xxxx-xxxx">
                </div>
                <div class="mb-3">
                    <label class="form-label">Warna Favorit</label>
                    <input type="color" class="form-control form-control-color" style="width:100px;">
                </div>
                <div class="mb-3">
                    <label class="form-label">Input Readonly</label>
                    <input class="form-control" value="Tidak bisa diubah" readonly>
                </div>
                <div class="mb-3">
                    <label class="form-label">Input Disabled</label>
                    <input class="form-control" value="Non-aktif" disabled>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- form-control untuk styling input dan textarea secara konsisten
- Tersedia ukuran: form-control-sm, default, form-control-lg
- Mendukung berbagai tipe input dan state readonly/disabled
