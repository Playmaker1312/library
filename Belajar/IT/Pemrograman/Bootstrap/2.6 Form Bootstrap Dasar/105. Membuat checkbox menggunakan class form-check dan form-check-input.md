# Membuat checkbox menggunakan class form-check dan form-check-input

## Analogi: Perpustakaan Digital

Daftar periksa (checklist) di perpustakaan untuk memilih buku yang akan dipinjam. Pengunjung bisa mencentang satu atau beberapa buku sekaligus. Checkbox Bootstrap menyediakan kotak centang yang konsisten dengan styling yang rapi dan label yang terhubung.

## Penjelasan Detail

Class `form-check` adalah container untuk checkbox, `form-check-input` untuk elemen `<input type="checkbox">`, dan `form-check-label` untuk label. Checkbox bisa dicek secara default dengan atribut `checked`. Checkbox inline menggunakan `form-check-inline`. Checkbox bisa disabled dengan atribut `disabled`. Untuk switch toggle, gunakan `form-switch`. Checkbox standar untuk pilihan ganda di mana pengguna bisa memilih lebih dari satu opsi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Checkbox Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Checkbox</h1>
        <div class="row">
            <div class="col-md-6">
                <h5>Checkbox Vertikal:</h5>
                <div class="form-check">
                    <input class="form-check-input" type="checkbox" id="buku1">
                    <label class="form-check-label" for="buku1">Buku Fiksi</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="checkbox" id="buku2" checked>
                    <label class="form-check-label" for="buku2">Buku Non-fiksi (tercentang)</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="checkbox" id="buku3" disabled>
                    <label class="form-check-label" for="buku3">Buku Rusak (disabled)</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="checkbox" id="buku4" checked disabled>
                    <label class="form-check-label" for="buku4">Tercentang & Disabled</label>
                </div>
            </div>
            <div class="col-md-6">
                <h5>Checkbox Inline:</h5>
                <div class="form-check form-check-inline">
                    <input class="form-check-input" type="checkbox" id="inline1" value="option1">
                    <label class="form-check-label" for="inline1">Fiksi</label>
                </div>
                <div class="form-check form-check-inline">
                    <input class="form-check-input" type="checkbox" id="inline2" value="option2">
                    <label class="form-check-label" for="inline2">Non-fiksi</label>
                </div>
                <div class="form-check form-check-inline">
                    <input class="form-check-input" type="checkbox" id="inline3" value="option3" disabled>
                    <label class="form-check-label" for="inline3">Majalah</label>
                </div>
                <h5 class="mt-3">Contoh Penggunaan:</h5>
                <div class="border p-3 rounded">
                    <p><strong>Pilih kategori yang diminati:</strong></p>
                    <div class="form-check">
                        <input class="form-check-input" type="checkbox" id="kat1">
                        <label class="form-check-label" for="kat1">Sains</label>
                    </div>
                    <div class="form-check">
                        <input class="form-check-input" type="checkbox" id="kat2">
                        <label class="form-check-label" for="kat2">Teknologi</label>
                    </div>
                    <div class="form-check">
                        <input class="form-check-input" type="checkbox" id="kat3">
                        <label class="form-check-label" for="kat3">Sejarah</label>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- form-check sebagai container, form-check-input untuk checkbox, form-check-label untuk label
- Gunakan form-check-inline untuk checkbox sebaris
- Atribut checked untuk default tercentang, disabled untuk non-aktif
