# Memahami form-text untuk helper text di bawah input

## Analogi: Perpustakaan Digital

Petunjuk kecil di bawah setiap kotak isian formulir perpustakaan yang membantu pengunjung mengisi dengan benar: "Minimal 8 karakter", "Format: 08xx-xxxx-xxxx", atau "Tidak wajib diisi". Helper text ini memberikan panduan tambahan tanpa memenuhi halaman. Bootstrap menyediakan class form-text untuk teks bantuan ini.

## Penjelasan Detail

Class `form-text` membuat teks bantuan kecil di bawah input dengan font-size lebih kecil (0.875em) dan warna muted. form-text harus ditempatkan setelah input atau di dalam `div` setelah input. Gunakan atribut `aria-describedby` pada input untuk menghubungkan input dengan helper text (aksesibilitas). form-text bisa disembunyikan dengan class `d-none` dan dimunculkan sesuai kondisi. Helper text penting untuk memberikan instruksi, format, atau persyaratan input.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Form Text</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Form Text (Helper Text)</h1>
        <div class="row">
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="password" class="form-label">Password</label>
                    <input type="password" class="form-control" id="password" aria-describedby="passwordHelp">
                    <div id="passwordHelp" class="form-text">Password minimal 8 karakter, mengandung huruf dan angka.</div>
                </div>
                <div class="mb-3">
                    <label for="email" class="form-label">Email</label>
                    <input type="email" class="form-control" id="email" aria-describedby="emailHelp">
                    <div id="emailHelp" class="form-text">Kami tidak akan membagikan email Anda ke pihak lain.</div>
                </div>
                <div class="mb-3">
                    <label for="telpon" class="form-label">Nomor Telepon</label>
                    <input type="tel" class="form-control" id="telpon" aria-describedby="telponHelp">
                    <div id="telponHelp" class="form-text">Format: 08xx-xxxx-xxxx atau +628xx-xxxx-xxxx</div>
                </div>
            </div>
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="bio" class="form-label">Biografi</label>
                    <textarea class="form-control" id="bio" rows="3" aria-describedby="bioHelp"></textarea>
                    <div id="bioHelp" class="form-text">Ceritakan tentang diri Anda dalam 2-3 kalimat.</div>
                </div>
                <div class="mb-3">
                    <label for="file" class="form-label">Upload Foto</label>
                    <input type="file" class="form-control" id="file" aria-describedby="fileHelp">
                    <div id="fileHelp" class="form-text">File: JPG atau PNG, maksimal 2MB.</div>
                </div>
                <div class="mb-3">
                    <label for="selectHelp" class="form-label">Kategori</label>
                    <select class="form-select" id="selectHelp" aria-describedby="selectHelpBlock">
                        <option>Pilih kategori</option>
                        <option>Fiksi</option>
                        <option>Non-fiksi</option>
                    </select>
                    <div id="selectHelpBlock" class="form-text">Pilih satu kategori yang sesuai dengan buku.</div>
                </div>
                <div class="mb-3">
                    <div class="form-text">form-text juga bisa berdiri sendiri tanpa input.</div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- form-text untuk teks bantuan di bawah input
- Gunakan aria-describedby untuk aksesibilitas
- form-text memiliki font lebih kecil dan warna muted
