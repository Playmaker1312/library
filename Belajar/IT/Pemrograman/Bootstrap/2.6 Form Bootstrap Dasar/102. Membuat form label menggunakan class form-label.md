# Membuat form label menggunakan class form-label

## Analogi: Perpustakaan Digital

Setiap kotak isian di formulir perpustakaan memiliki label yang menjelaskan informasi apa yang harus diisi: "Nama:", "Alamat:", "No. Anggota:". Label yang baik membantu pengunjung mengisi formulir dengan benar. Bootstrap menyediakan class form-label untuk styling label yang konsisten.

## Penjelasan Detail

Class `form-label` memberikan styling pada elemen `<label>` dalam form. Class ini mengatur margin-bottom, font-weight, dan alignment. Label harus dihubungkan dengan input menggunakan atribut `for` (pada label) dan `id` (pada input) untuk aksesibilitas. Label dapat disembunyikan secara visual dengan class `visually-hidden` tetapi tetap tersedia untuk screen reader. form-label dapat dikombinasikan dengan class text color dan spacing. Label yang baik meningkatkan UX dan aksesibilitas form.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Form Label</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Form Label</h1>
        <div class="row">
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="nama" class="form-label">Nama Lengkap</label>
                    <input type="text" class="form-control" id="nama" placeholder="Masukkan nama">
                </div>
                <div class="mb-3">
                    <label for="email" class="form-label">Alamat Email <span class="text-danger">*</span></label>
                    <input type="email" class="form-control" id="email" placeholder="nama@email.com">
                </div>
                <div class="mb-3">
                    <label for="phone" class="form-label">Nomor Telepon</label>
                    <div class="input-group">
                        <span class="input-group-text">+62</span>
                        <input type="tel" class="form-control" id="phone" placeholder="8xx-xxxx-xxxx">
                    </div>
                </div>
            </div>
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="alamat" class="form-label">Alamat Lengkap</label>
                    <textarea class="form-control" id="alamat" rows="2"></textarea>
                    <div class="form-text">Tulis alamat lengkap Anda.</div>
                </div>
                <div class="mb-3">
                    <label for="negara" class="form-label">Negara</label>
                    <select class="form-select" id="negara">
                        <option>Pilih negara</option>
                        <option>Indonesia</option>
                        <option>Malaysia</option>
                    </select>
                </div>
                <div class="mb-3">
                    <label class="form-label visually-hidden">Label Tersembunyi</label>
                    <input class="form-control" placeholder="Label hanya untuk screen reader">
                </div>
            </div>
        </div>
        <div class="mb-3 form-check">
            <input type="checkbox" class="form-check-input" id="setuju">
            <label class="form-check-label" for="setuju">Saya setuju dengan syarat dan ketentuan</label>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- form-label untuk styling label form yang konsisten
- Gunakan atribut for dan id untuk menghubungkan label dengan input
- Gunakan visually-hidden untuk label yang hanya untuk screen reader
