# Membuat select dropdown menggunakan class form-select

## Analogi: Perpustakaan Digital

Daftar pilihan kategori buku dalam menu dropdown: Fiksi, Non-fiksi, Majalah, Referensi. Pengunjung cukup memilih satu dari daftar yang tersedia tanpa perlu mengetik. Bootstrap menyediakan class form-select untuk styling dropdown select yang konsisten.

## Penjelasan Detail

Class `form-select` mengubah elemen `<select>` menjadi dropdown Bootstrap dengan styling yang seragam. Tersedia ukuran: `form-select-sm` dan `form-select-lg`. Select bisa memiliki multiple pilihan dengan atribut `multiple`. Gunakan elemen `<optgroup>` untuk mengelompokkan opsi. form-select mendukung state disabled dan readonly. Untuk select dengan banyak opsi, pertimbangkan menggunakan form-select dengan ukuran yang sesuai.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Form Select</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Form Select</h1>
        <div class="row">
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="kategori" class="form-label">Kategori Buku</label>
                    <select class="form-select" id="kategori">
                        <option selected>Pilih kategori</option>
                        <option value="fiksi">Fiksi</option>
                        <option value="nonfiksi">Non-fiksi</option>
                        <option value="majalah">Majalah</option>
                        <option value="referensi">Referensi</option>
                    </select>
                </div>
                <div class="mb-3">
                    <label for="ukuranSelect" class="form-label">Ukuran Select</label>
                    <select class="form-select form-select-sm mb-2" id="ukuranSelect">
                        <option>form-select-sm</option>
                        <option>Opsi 1</option>
                        <option>Opsi 2</option>
                    </select>
                    <select class="form-select mb-2">
                        <option>Default</option>
                        <option>Opsi 1</option>
                    </select>
                    <select class="form-select form-select-lg">
                        <option>form-select-lg</option>
                        <option>Opsi 1</option>
                    </select>
                </div>
            </div>
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="disabledSelect" class="form-label">Select Disabled</label>
                    <select class="form-select" id="disabledSelect" disabled>
                        <option>Non-aktif</option>
                    </select>
                </div>
                <div class="mb-3">
                    <label for="multiSelect" class="form-label">Multiple Select</label>
                    <select class="form-select" id="multiSelect" multiple size="3">
                        <option>Fiksi</option>
                        <option>Non-fiksi</option>
                        <option>Majalah</option>
                        <option>Referensi</option>
                        <option>Komik</option>
                    </select>
                    <div class="form-text">Tahan Ctrl untuk memilih lebih dari satu.</div>
                </div>
                <div class="mb-3">
                    <label for="groupSelect" class="form-label">Select dengan Group</label>
                    <select class="form-select" id="groupSelect">
                        <optgroup label="Sastra">
                            <option>Novel</option>
                            <option>Puisi</option>
                        </optgroup>
                        <optgroup label="Ilmiah">
                            <option>Sains</option>
                            <option>Teknologi</option>
                        </optgroup>
                    </select>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- form-select untuk styling dropdown select
- Tersedia ukuran: form-select-sm, default, form-select-lg
- Dukung multiple select dan optgroup untuk pengelompokan opsi
