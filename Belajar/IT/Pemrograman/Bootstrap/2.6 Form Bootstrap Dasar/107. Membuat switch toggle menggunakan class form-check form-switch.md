# Membuat switch toggle menggunakan class form-check form-switch

## Analogi: Perpustakaan Digital

Saklar on/off di perpustakaan untuk mengaktifkan atau menonaktifkan fitur tertentu: "Mode Tenang", "Notifikasi", atau "Lampu Baca". Switch toggle adalah variasi checkbox yang tampil seperti saklar. Bootstrap menyediakan class form-switch untuk mengubah checkbox menjadi toggle switch.

## Penjelasan Detail

Class `form-switch` ditambahkan ke `form-check` untuk mengubah checkbox menjadi toggle switch. Switch menggunakan struktur yang sama: `form-check-input` dan `form-check-label`. Switch mendukung `checked` (aktif) dan `disabled`. Switch bisa inline dengan `form-check-inline`. Switch toggle lebih intuitif untuk pengaturan biner (on/off) dibandingkan checkbox biasa. Cocok untuk pengaturan, preferensi, atau fitur toggle dalam aplikasi.

## Poin Penting
- Tambahkan form-switch pada form-check untuk tampilan toggle
- Switch menggunakan struktur yang sama dengan checkbox
- Cocok untuk pengaturan biner on/off
