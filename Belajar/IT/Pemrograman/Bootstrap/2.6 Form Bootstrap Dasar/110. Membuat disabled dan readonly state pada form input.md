# Membuat disabled dan readonly state pada form input

## Analogi: Perpustakaan Digital

Di perpustakaan, beberapa formulir memiliki kolom yang tidak bisa diubah: kolom "Nomor Anggota" yang sudah ditentukan sistem (readonly), atau kolom "Buku Rusak" yang tidak bisa diisi karena buku sudah diperbaiki (disabled). Readonly memungkinkan teks dilihat dan disalin, disabled membuat elemen tidak bisa diakses sama sekali.

## Penjelasan Detail

State `disabled` menggunakan atribut `disabled` pada elemen input, membuatnya tidak bisa diinteraksikan, tidak bisa di-focus, tidak dikirim dalam form, dan tampil redup. State `readonly` menggunakan atribut `readonly`, membuat input tidak bisa diedit tetapi tetap bisa di-focus, teks bisa disalin, dan nilainya tetap dikirim dalam form. readonly hanya berlaku untuk input teks, select, dan textarea (tidak untuk checkbox/radio). keduanya bisa diterapkan pada form-control, form-select, textarea, checkbox, dan radio.

                    <textarea class="form-control" rows="2" disabled>Konten tidak bisa diedit.</textarea>

## Poin Penting
- disabled: elemen tidak bisa diinteraksikan, tidak dikirim ke server
- readonly: elemen tidak bisa diedit tetapi bisa disalin dan dikirim ke server
- readonly hanya untuk input teks, select, textarea (bukan checkbox/radio)
