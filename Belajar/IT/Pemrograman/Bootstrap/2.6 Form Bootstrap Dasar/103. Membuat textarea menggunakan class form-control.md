# Membuat textarea menggunakan class form-control

## Analogi: Perpustakaan Digital

Kotak komentar atau formulir saran di perpustakaan yang memungkinkan pengunjung menulis beberapa baris teks. textarea adalah versi input yang lebih besar untuk teks panjang. Seperti halaman kosong di buku tamu perpustakaan yang bisa diisi dengan pesan panjang lebar.

## Penjelasan Detail

Textarea menggunakan class `form-control` yang sama dengan input teks. Atribut `rows` mengatur jumlah baris yang terlihat (default 2). Textarea bisa di-resize secara vertikal oleh pengguna (default CSS `resize: vertical`). Gunakan `style="resize: none"` untuk menonaktifkan resize. Ukuran: `form-control-sm` dan `form-control-lg`. Textarea juga mendukung state readonly dan disabled. Untuk teks yang sangat panjang, kombinasi dengan overflow-auto bisa digunakan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Textarea</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Textarea</h1>
        <div class="row">
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="saran" class="form-label">Saran untuk Perpustakaan</label>
                    <textarea class="form-control" id="saran" rows="3" placeholder="Tulis saran Anda..."></textarea>
                </div>
                <div class="mb-3">
                    <label for="bio" class="form-label">Biografi (rows=5)</label>
                    <textarea class="form-control" id="bio" rows="5">Teks default di sini.</textarea>
                </div>
                <div class="mb-3">
                    <label for="note" class="form-label">Textarea Small</label>
                    <textarea class="form-control form-control-sm" id="note" rows="2" placeholder="form-control-sm"></textarea>
                </div>
            </div>
            <div class="col-md-6">
                <div class="mb-3">
                    <label for="largeText" class="form-label">Textarea Large</label>
                    <textarea class="form-control form-control-lg" id="largeText" rows="3" placeholder="form-control-lg"></textarea>
                </div>
                <div class="mb-3">
                    <label for="resizeNone" class="form-label">Tanpa resize</label>
                    <textarea class="form-control" id="resizeNone" rows="3" style="resize:none;">Resize dinonaktifkan.</textarea>
                </div>
                <div class="mb-3">
                    <label for="readonlyText" class="form-label">Readonly</label>
                    <textarea class="form-control" id="readonlyText" rows="2" readonly>Konten hanya bisa dibaca.</textarea>
                </div>
                <div class="mb-3">
                    <label for="disabledText" class="form-label">Disabled</label>
                    <textarea class="form-control" id="disabledText" rows="2" disabled>Non-aktif.</textarea>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Textarea menggunakan class form-control seperti input
- Atribut rows mengatur jumlah baris yang terlihat
- Gunakan style="resize:none" untuk menonaktifkan resize
