# Membuat radio button menggunakan class form-check

## Analogi: Perpustakaan Digital

Radio button seperti tombol pilihan di mesin peminjaman buku di mana pengunjung hanya bisa memilih satu opsi: "Pinjam", "Kembalikan", atau "Perpanjang". Berbeda dengan checkbox, radio button hanya mengizinkan satu pilihan dalam satu grup. Bootstrap menyediakan styling radio button yang konsisten.

## Penjelasan Detail

Radio button menggunakan struktur yang sama dengan checkbox: `form-check`, `form-check-input`, `form-check-label`. Perbedaan: input bertipe `radio` dan semua radio dalam grup harus memiliki atribut `name` yang sama. Hanya satu radio dalam satu grup yang bisa dipilih. Radio juga mendukung `checked` dan `disabled`. Radio inline menggunakan `form-check-inline`. Radio button berguna untuk pilihan tunggal seperti jenis kelamin, status, atau opsi eksklusif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Radio Button</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Radio Button</h1>
        <div class="row">
            <div class="col-md-6">
                <h5>Pilih Jenis Peminjaman:</h5>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="jenisPinjam" id="pinjam1" checked>
                    <label class="form-check-label" for="pinjam1">Peminjaman Baru</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="jenisPinjam" id="pinjam2">
                    <label class="form-check-label" for="pinjam2">Perpanjangan</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="jenisPinjam" id="pinjam3" disabled>
                    <label class="form-check-label" for="pinjam3">Pengembalian (disabled)</label>
                </div>
            </div>
            <div class="col-md-6">
                <h5>Radio Inline:</h5>
                <div class="form-check form-check-inline">
                    <input class="form-check-input" type="radio" name="inlineRadio" id="radio1" value="1" checked>
                    <label class="form-check-label" for="radio1">Pria</label>
                </div>
                <div class="form-check form-check-inline">
                    <input class="form-check-input" type="radio" name="inlineRadio" id="radio2" value="2">
                    <label class="form-check-label" for="radio2">Wanita</label>
                </div>
                <h5 class="mt-3">Status Keanggotaan:</h5>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="status" id="status1">
                    <label class="form-check-label" for="status1">Aktif</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="status" id="status2">
                    <label class="form-check-label" for="status2">Tidak Aktif</label>
                </div>
                <div class="form-check">
                    <input class="form-check-input" type="radio" name="status" id="status3" disabled>
                    <label class="form-check-label" for="status3">Diblokir</label>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Radio type="radio" dengan atribut name yang sama untuk grup
- Hanya satu radio dalam satu grup yang bisa dipilih
- form-check-inline untuk radio sebaris
