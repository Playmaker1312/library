# Menggunakan Table-striped, Table-hover, Table-bordered, dan Table-borderless

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki berbagai cara untuk menyajikan tabel koleksi bukunya. Terkadang tabel diberi warna bergantian (striped) agar lebih mudah dibaca baris per baris. Kadang baris berubah warna saat mouse melintas (hover). Ada tabel dengan garis pembatas (bordered) dan ada yang tanpa garis (borderless) untuk tampilan yang lebih modern. Bootstrap menyediakan class-class ini sebagai opsi styling yang bisa dikombinasikan dengan class `table`.

## Penjelasan Detail

`table-striped` menambahkan warna latar bergantian pada baris ganjil dan genap di `<tbody>`, meningkatkan readability untuk tabel dengan banyak baris. `table-hover` menambahkan efek hover yang mengubah warna latar baris saat mouse melewatinya, memberikan interaktivitas. `table-bordered` menambahkan border di semua sisi sel dan sekeliling tabel, sementara `table-borderless` menghilangkan semua border untuk tampilan minimalis. Semua class ini ditambahkan langsung ke elemen `<table>` bersama dengan class `table`. Anda juga bisa menggabungkannya, misalnya `table table-striped table-hover` untuk tabel dengan striped dan efek hover sekaligus.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Table Variasi</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h2>table-striped</h2>
        <table class="table table-striped">
            <thead><tr><th>Judul</th><th>Penulis</th></tr></thead>
            <tbody>
                <tr><td>Buku A</td><td>Penulis 1</td></tr>
                <tr><td>Buku B</td><td>Penulis 2</td></tr>
                <tr><td>Buku C</td><td>Penulis 3</td></tr>
            </tbody>
        </table>
        <h2>table-hover</h2>
        <table class="table table-hover">
            <thead><tr><th>Judul</th><th>Penulis</th></tr></thead>
            <tbody>
                <tr><td>Buku A</td><td>Penulis 1</td></tr>
                <tr><td>Buku B</td><td>Penulis 2</td></tr>
                <tr><td>Buku C</td><td>Penulis 3</td></tr>
            </tbody>
        </table>
        <h2>table-bordered</h2>
        <table class="table table-bordered">
            <thead><tr><th>Judul</th><th>Penulis</th></tr></thead>
            <tbody>
                <tr><td>Buku A</td><td>Penulis 1</td></tr>
                <tr><td>Buku B</td><td>Penulis 2</td></tr>
            </tbody>
        </table>
        <h2>table-borderless</h2>
        <table class="table table-borderless">
            <thead><tr><th>Judul</th><th>Penulis</th></tr></thead>
            <tbody>
                <tr><td>Buku A</td><td>Penulis 1</td></tr>
                <tr><td>Buku B</td><td>Penulis 2</td></tr>
            </tbody>
        </table>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `table-striped` memberi warna bergantian pada baris di tbody.
- `table-hover` menambahkan efek highlight saat hover.
- `table-bordered` menampilkan border di semua sisi sel.
- `table-borderless` menghilangkan semua border tabel.
