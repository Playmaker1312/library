# Membuat Table Bootstrap Menggunakan Class Table

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada tabel inventaris yang mencatat semua koleksi buku dengan informasi seperti judul, penulis, tahun terbit, dan status peminjaman. Tabel ini harus mudah dibaca dan terstruktur dengan rapi. Bootstrap menyediakan class `table` yang mengubah tabel HTML biasa menjadi tabel yang elegan dengan styling yang konsisten, termasuk border, padding, dan tipografi yang optimal. Seperti meja sirkulasi perpustakaan yang terorganisir, tabel Bootstrap membantu menyajikan data secara terstruktur.

## Penjelasan Detail

Class `table` ditambahkan pada elemen `<table>` dan memberikan styling dasar seperti `width: 100%`, `margin-bottom: 1rem`, `border-collapse: collapse`, serta padding yang konsisten pada sel tabel (`<td>` dan `<th>`). Class ini juga mengatur warna border, background header yang lebih gelap, dan `vertical-align: top` pada sel. Tabel Bootstrap menggunakan pendekatan light-weight dengan hanya menambahkan class `table` — semua styling tambahan seperti striped, hover, bordered adalah class opsional yang bisa ditambahkan. Tabel juga mendukung elemen `<thead>`, `<tbody>`, dan `<tfoot>` untuk struktur semantik yang baik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Table Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Tabel Koleksi Buku</h1>
        <table class="table">
            <thead>
                <tr>
                    <th>#</th>
                    <th>Judul</th>
                    <th>Penulis</th>
                    <th>Tahun</th>
                    <th>Status</th>
                </tr>
            </thead>
            <tbody>
                <tr>
                    <td>1</td>
                    <td>Pemrograman Web Modern</td>
                    <td>Andi Pratama</td>
                    <td>2024</td>
                    <td>Tersedia</td>
                </tr>
                <tr>
                    <td>2</td>
                    <td>Machine Learning Dasar</td>
                    <td>Budi Santoso</td>
                    <td>2023</td>
                    <td>Dipinjam</td>
                </tr>
                <tr>
                    <td>3</td>
                    <td>Database SQL Lanjutan</td>
                    <td>Citra Dewi</td>
                    <td>2024</td>
                    <td>Tersedia</td>
                </tr>
            </tbody>
        </table>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Class `table` adalah class dasar untuk men-styling tabel di Bootstrap.
- Tabel menjadi full-width secara default dengan `width: 100%`.
- Struktur tabel menggunakan `<thead>`, `<tbody>`, dan `<tfoot>` untuk semantik.
- Class `table` dapat dikombinasikan dengan class tabel lainnya untuk efek tambahan.
