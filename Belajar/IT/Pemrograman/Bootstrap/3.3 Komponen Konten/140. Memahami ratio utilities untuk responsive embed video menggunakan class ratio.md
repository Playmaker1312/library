# Memahami Ratio Utilities untuk Responsive Embed Video Menggunakan Class Ratio

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda mungkin ingin menampilkan video tutorial atau seminar yang di-embed dari YouTube. Video harus ditampilkan dengan rasio aspek yang benar (misalnya 16:9) dan responsif terhadap ukuran layar. Bootstrap menyediakan class `ratio` yang mempertahankan rasio aspek tertentu pada elemen yang di-embed, seperti video atau iframe. Ini seperti bingkai foto yang selalu mempertahankan proporsi yang benar meskipun diletakkan di dinding yang berbeda ukurannya.

## Penjelasan Detail

Class `ratio` bekerja dengan menerapkan teknik CSS `aspect-ratio` atau `padding-bottom` trick untuk mempertahankan rasio aspek tertentu. Penggunaannya: bungkus elemen `<iframe>`, `<video>`, atau `<embed>` dalam `<div>` dengan class `ratio` dan class rasio yang diinginkan. Class rasio yang tersedia: `ratio-1x1` (persegi), `ratio-4x3` (TV lama), `ratio-16x9` (HD), `ratio-21x9` (ultrawide), dan `ratio-4x3` sebagai default. Elemen di dalamnya akan mengisi seluruh ruang yang tersedia sambil mempertahankan rasio yang ditentukan. Class ini menggantikan pendekatan lama `embed-responsive` yang sudah dihapus di Bootstrap 5.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ratio Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Ratio Utilities untuk Video</h1>
        <div class="row">
            <div class="col-md-6 mb-4">
                <h5>ratio-16x9</h5>
                <div class="ratio ratio-16x9">
                    <iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="YouTube video" allowfullscreen></iframe>
                </div>
            </div>
            <div class="col-md-6 mb-4">
                <h5>ratio-4x3</h5>
                <div class="ratio ratio-4x3">
                    <iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="YouTube video" allowfullscreen></iframe>
                </div>
            </div>
        </div>
        <div class="row">
            <div class="col-md-6 mb-4">
                <h5>ratio-1x1 (persegi)</h5>
                <div class="ratio ratio-1x1">
                    <iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="YouTube video" allowfullscreen></iframe>
                </div>
            </div>
            <div class="col-md-6 mb-4">
                <h5>ratio-21x9 (ultrawide)</h5>
                <div class="ratio ratio-21x9">
                    <iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="YouTube video" allowfullscreen></iframe>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan `<div class="ratio ratio-16x9">` untuk membungkus elemen yang di-embed.
- Class rasio: `ratio-1x1`, `ratio-4x3`, `ratio-16x9`, `ratio-21x9`.
- Elemen di dalamnya (iframe, video, embed) akan mengisi ruang dengan rasio tepat.
- Video dan konten responsive siap pakai tanpa CSS tambahan.
