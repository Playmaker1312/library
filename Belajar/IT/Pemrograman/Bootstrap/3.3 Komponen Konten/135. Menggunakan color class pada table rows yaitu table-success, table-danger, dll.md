# Menggunakan Color Class pada Table Rows yaitu Table-success, Table-danger, dll

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda mungkin ingin menandai baris-baris tertentu dalam tabel inventaris dengan warna: hijau untuk buku yang tersedia, merah untuk buku yang hilang, kuning untuk buku yang sedang dipinjam, dan biru untuk buku baru. Warna-warna ini membantu pengelola perpustakaan dengan cepat mengidentifikasi status koleksi. Bootstrap menyediakan class contextual seperti `table-success`, `table-danger`, `table-warning`, `table-info`, dan lainnya untuk menandai baris atau sel tabel dengan warna yang bermakna.

## Penjelasan Detail

Class contextual untuk tabel dapat diterapkan pada elemen `<tr>`, `<td>`, atau `<th>`. Class yang tersedia antara lain: `table-primary` (biru), `table-secondary` (abu-abu), `table-success` (hijau), `table-danger` (merah), `table-warning` (kuning), `table-info` (biru muda), `table-light` (putih), dan `table-dark` (gelap). Class-class ini mengubah warna latar belakang dan secara otomatis menyesuaikan warna teks untuk kontras yang baik. Penggunaan warna ini membantu pengguna dengan cepat mengidentifikasi pola atau status dalam tabel tanpa harus membaca setiap sel secara detail.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Table Contextual</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Warna Contextual pada Tabel</h1>
        <table class="table">
            <thead>
                <tr>
                    <th>Judul Buku</th>
                    <th>Status</th>
                    <th>Keterangan</th>
                </tr>
            </thead>
            <tbody>
                <tr class="table-success">
                    <td>Pemrograman Web Modern</td>
                    <td>Tersedia</td>
                    <td>Buku siap dipinjam</td>
                </tr>
                <tr class="table-warning">
                    <td>Machine Learning Dasar</td>
                    <td>Dipinjam</td>
                    <td>Kembali 30 Mei 2024</td>
                </tr>
                <tr class="table-danger">
                    <td>Database SQL Lanjutan</td>
                    <td>Hilang</td>
                    <td>Dalam proses pencarian</td>
                </tr>
                <tr class="table-info">
                    <td>Algoritma dan Struktur Data</td>
                    <td>Buku Baru</td>
                    <td>Ditambahkan 20 Mei 2024</td>
                </tr>
                <tr class="table-secondary">
                    <td>Jaringan Komputer</td>
                    <td>Dalam Perbaikan</td>
                    <td>Sedang direstorasi</td>
                </tr>
            </tbody>
        </table>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan `table-success`, `table-danger`, `table-warning`, dll. pada `<tr>` atau `<td>`.
- Warna membantu mengidentifikasi status atau kategori data dengan cepat.
- Bootstrap secara otomatis menyesuaikan kontras teks untuk readability.
- Class ini dapat dikombinasikan dengan `table-striped` dan `table-hover`.
