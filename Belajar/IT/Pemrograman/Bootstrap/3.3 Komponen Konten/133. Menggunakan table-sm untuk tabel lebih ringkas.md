# Menggunakan Table-sm untuk Tabel Lebih Ringkas

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada kalanya Anda perlu menampilkan banyak data dalam ruang yang terbatas, seperti daftar pengunjung harian atau log peminjaman. Tabel dengan padding standar mungkin terlalu boros ruang. Bootstrap menyediakan class `table-sm` yang mengurangi padding sel menjadi setengahnya, membuat tabel lebih ringkas dan padat. Ini seperti mencetak daftar katalog dengan font yang lebih kecil agar lebih banyak informasi muat dalam satu halaman.

## Penjelasan Detail

Class `table-sm` mengurangi padding sel tabel dari default `0.75rem` menjadi `0.25rem` pada sel `<td>` dan `<th>`. Hasilnya adalah tabel yang lebih rapat secara vertikal, memungkinkan lebih banyak baris untuk ditampilkan dalam ruang yang sama. Class ini sangat berguna untuk dashboard, laporan data, atau tabel dengan jumlah baris yang banyak. `table-sm` dapat dikombinasikan dengan class tabel lainnya seperti `table-striped`, `table-hover`, atau `table-bordered`. Penggunaan `table-sm` juga baik untuk tabel yang ditampilkan di sidebar atau area terbatas lainnya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Table Ringkas</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h2>Tabel Standar</h2>
        <table class="table mb-5">
            <thead><tr><th>#</th><th>Judul</th><th>Penulis</th><th>Tahun</th></tr></thead>
            <tbody>
                <tr><td>1</td><td>Pemrograman Web Modern</td><td>Andi Pratama</td><td>2024</td></tr>
                <tr><td>2</td><td>Machine Learning Dasar</td><td>Budi Santoso</td><td>2023</td></tr>
                <tr><td>3</td><td>Database SQL Lanjutan</td><td>Citra Dewi</td><td>2024</td></tr>
            </tbody>
        </table>
        <h2>Tabel dengan table-sm (lebih ringkas)</h2>
        <table class="table table-sm">
            <thead><tr><th>#</th><th>Judul</th><th>Penulis</th><th>Tahun</th></tr></thead>
            <tbody>
                <tr><td>1</td><td>Pemrograman Web Modern</td><td>Andi Pratama</td><td>2024</td></tr>
                <tr><td>2</td><td>Machine Learning Dasar</td><td>Budi Santoso</td><td>2023</td></tr>
                <tr><td>3</td><td>Database SQL Lanjutan</td><td>Citra Dewi</td><td>2024</td></tr>
                <tr><td>4</td><td>Algoritma dan Struktur Data</td><td>Dian Kurniawan</td><td>2023</td></tr>
                <tr><td>5</td><td>Jaringan Komputer</td><td>Eko Prasetyo</td><td>2024</td></tr>
            </tbody>
        </table>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `table-sm` mengurangi padding sel untuk tampilan yang lebih ringkas.
- Digunakan bersama dengan class `table` pada elemen `<table>`.
- Cocok untuk dashboard dan tabel dengan banyak data.
- Dapat dikombinasikan dengan class tabel lainnya (striped, hover, bordered).
