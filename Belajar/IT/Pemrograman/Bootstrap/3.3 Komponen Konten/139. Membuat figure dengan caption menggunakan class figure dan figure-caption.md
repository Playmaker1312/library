# Membuat Figure dengan Caption Menggunakan Class Figure dan Figure-caption

## Analogi: Perpustakaan Digital

Di perpustakaan digital, gambar ilustrasi atau foto sampul buku sering disertai dengan keterangan atau caption yang menjelaskan isinya. Caption ini ditempatkan langsung di bawah gambar, seperti label pada rak buku yang menjelaskan isi rak tersebut. Bootstrap menyediakan komponen `figure` yang merupakan wrapper semantik untuk gambar beserta caption-nya, menggunakan class `figure` dan `figure-caption` untuk styling yang konsisten dan rapi.

## Penjelasan Detail

Komponen figure Bootstrap terdiri dari elemen `<figure>` dengan class `figure` sebagai pembungkus. Di dalamnya, gambar menggunakan class `figure-img` (yang sudah includes `img-fluid` dan `margin-bottom: 0`). Caption menggunakan `<figcaption>` dengan class `figure-caption` yang memberikan teks berwarna abu-abu (`text-muted`) dan ukuran font yang lebih kecil. Class `figure-caption` juga dapat menerima alignment utilities seperti `text-end` untuk rata kanan. Komponen ini berguna untuk galeri gambar, dokumentasi, artikel blog, dan halaman katalog buku.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Figure dan Caption</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Figure dengan Caption</h1>
        <div class="row">
            <div class="col-md-6">
                <figure class="figure">
                    <img src="https://via.placeholder.com/500x300/0066CC/FFFFFF" class="figure-img img-fluid rounded" alt="Gambar ilustrasi">
                    <figcaption class="figure-caption">Gambar 1: Ilustrasi perpustakaan digital modern dengan berbagai koleksi buku elektronik.</figcaption>
                </figure>
            </div>
            <div class="col-md-6">
                <figure class="figure">
                    <img src="https://via.placeholder.com/500x300/28A745/FFFFFF" class="figure-img img-fluid rounded" alt="Gambar buku">
                    <figcaption class="figure-caption text-end">Gambar 2: Sampul buku terbaru koleksi perpustakaan digital tahun 2024.</figcaption>
                </figure>
            </div>
        </div>
        <div class="row">
            <div class="col-md-4">
                <figure class="figure">
                    <img src="https://via.placeholder.com/300x400/CC0000/FFFFFF" class="figure-img img-fluid rounded" alt="Buku 1">
                    <figcaption class="figure-caption">Buku fiksi populer bulan ini.</figcaption>
                </figure>
            </div>
            <div class="col-md-4">
                <figure class="figure">
                    <img src="https://via.placeholder.com/300x400/FFC107/000000" class="figure-img img-fluid rounded" alt="Buku 2">
                    <figcaption class="figure-caption">Koleksi sains dan teknologi.</figcaption>
                </figure>
            </div>
            <div class="col-md-4">
                <figure class="figure">
                    <img src="https://via.placeholder.com/300x400/6F42C1/FFFFFF" class="figure-img img-fluid rounded" alt="Buku 3">
                    <figcaption class="figure-caption">Buku referensi akademik.</figcaption>
                </figure>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan `<figure>` dengan class `figure` sebagai wadah gambar.
- Gambar menggunakan class `figure-img` (termasuk `img-fluid` otomatis).
- Caption menggunakan `<figcaption>` dengan class `figure-caption`.
- `figure-caption` dapat diubah alignment-nya dengan utilities `text-*`.
