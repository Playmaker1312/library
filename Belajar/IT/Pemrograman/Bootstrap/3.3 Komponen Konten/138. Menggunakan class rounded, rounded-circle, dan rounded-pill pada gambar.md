# Menggunakan Class Rounded, Rounded-circle, dan Rounded-pill pada Gambar

## Analogi: Perpustakaan Digital

Foto profil pengguna perpustakaan digital sering ditampilkan dalam bentuk lingkaran sempurna, seperti pin atau badge. Sementara sampul buku mungkin memiliki sudut yang sedikit membulat seperti buku sungguhan. Bootstrap menyediakan class utilities `rounded`, `rounded-circle`, dan `rounded-pill` yang dapat diterapkan pada gambar untuk mengubah bentuk sudut dan tampilannya. Ini seperti memilih bingkai yang berbeda untuk foto di galeri perpustakaan.

## Penjelasan Detail

Class `rounded` memberikan sudut membulat standar (0.375rem). `rounded-circle` mengubah gambar menjadi bentuk lingkaran sempurna dengan menerapkan `border-radius: 50%`. `rounded-pill` membuat sudut sangat membulat hingga membentuk seperti pil atau kapsul. Bootstrap juga menyediakan variasi ukuran: `rounded-0` (tanpa rounding), `rounded-1` (kecil), `rounded-2` (sedang), `rounded-3` (besar), dan `rounded-4` hingga `rounded-5` (lebih besar). Class ini dapat dikombinasikan dengan `img-fluid` atau `img-thumbnail` untuk hasil yang optimal.

## Poin Penting
- `rounded` memberikan sudut membulat standar pada gambar.
- `rounded-circle` membuat gambar menjadi lingkaran sempurna.
- `rounded-pill` membuat sudut sangat membulat seperti kapsul.
- Tersedia variasi `rounded-0` hingga `rounded-5` untuk kontrol ukuran yang lebih presisi.
