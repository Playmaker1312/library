# Membuat Image Thumbnail Menggunakan Class Img-thumbnail

## Analogi: Perpustakaan Digital

Di perpustakaan digital, gambar sampul buku sering ditampilkan dalam bingkai kecil dengan border tipis dan sudut membulat, mirip seperti foto polaroid atau kartu katalog. Efek ini memberikan tampilan yang rapi dan profesional. Bootstrap menyediakan class `img-thumbnail` yang menambahkan border tipis, padding, dan sudut membulat pada gambar, membuatnya terlihat seperti thumbnail yang siap dipajang di galeri perpustakaan digital.

## Penjelasan Detail

Class `img-thumbnail` memberikan gambar efek seperti kartu dengan menambahkan `padding: 0.25rem`, `border: 1px solid` (warna border abu-abu), `border-radius: 0.375rem`, dan `max-width: 100%`. Efek ini membuat gambar terlihat seperti memiliki bingkai tipis di sekelilingnya. Seperti `img-fluid`, class ini juga responsif karena menyertakan `max-width: 100%` dan `height: auto`. `img-thumbnail` sangat cocok untuk galeri gambar, daftar buku dengan sampul, atau grid foto. Anda bisa mengatur ulang border-radius jika ingin sudut yang lebih atau kurang membulat menggunakan utilities `rounded-*`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Image Thumbnail</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Image Thumbnail</h1>
        <div class="row">
            <div class="col-4">
                <img src="https://via.placeholder.com/300x300/CC0000/FFFFFF" alt="Thumbnail 1" class="img-thumbnail">
            </div>
            <div class="col-4">
                <img src="https://via.placeholder.com/300x300/0066CC/FFFFFF" alt="Thumbnail 2" class="img-thumbnail">
            </div>
            <div class="col-4">
                <img src="https://via.placeholder.com/300x300/28A745/FFFFFF" alt="Thumbnail 3" class="img-thumbnail">
            </div>
        </div>
        <h2 class="mt-4">Perbandingan img-fluid vs img-thumbnail</h2>
        <div class="row">
            <div class="col-6">
                <h5>img-fluid</h5>
                <img src="https://via.placeholder.com/400x400/FFC107/000000" alt="Fluid" class="img-fluid">
            </div>
            <div class="col-6">
                <h5>img-thumbnail</h5>
                <img src="https://via.placeholder.com/400x400/FFC107/000000" alt="Thumbnail" class="img-thumbnail">
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `img-thumbnail` menambahkan border, padding, dan border-radius pada gambar.
- Responsif secara default dengan `max-width: 100%` dan `height: auto`.
- Cocok untuk galeri gambar dan sampul buku.
- Dapat dikombinasikan dengan utilities `rounded-*` untuk variasi sudut.
