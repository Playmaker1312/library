# Membuat Responsive Table Menggunakan Class Table-responsive

## Analogi: Perpustakaan Digital

Bayangkan Anda membuka laporan inventaris perpustakaan digital di ponsel. Tabel dengan banyak kolom mungkin terlalu lebar untuk layar yang sempit. Solusinya adalah dengan membuat tabel dapat di-scroll secara horizontal. Bootstrap menyediakan class `table-responsive` yang membungkus tabel dalam kontainer dengan `overflow-x: auto`, sehingga pengguna bisa menggeser tabel ke kiri-kanan pada layar kecil. Ini seperti meja katalog yang bisa digeser untuk melihat kolom yang tersembunyi.

## Penjelasan Detail

Class `table-responsive` diterapkan pada elemen pembungkus `<div>` di sekitar tabel, bukan pada tabel itu sendiri. Pembungkus ini akan memiliki `overflow-x: auto` sehingga scrollbar horizontal muncul ketika tabel melebihi lebar viewport. Bootstrap juga menyediakan variant breakpoint: `table-responsive-sm`, `table-responsive-md`, `table-responsive-lg`, `table-responsive-xl`, dan `table-responsive-xxl`. Ini berarti tabel hanya menjadi scrollable pada ukuran layar di bawah breakpoint yang ditentukan. Misalnya `table-responsive-md` berarti tabel bisa di-scroll pada layar < 768px, dan pada layar lebih besar tabel akan ditampilkan normal.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Table</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Responsive Table</h1>
        <p>Geser tabel ke kanan jika kolom terpotong.</p>
        <div class="table-responsive">
            <table class="table table-bordered">
                <thead>
                    <tr>
                        <th>#</th>
                        <th>Judul Buku</th>
                        <th>Penulis</th>
                        <th>Penerbit</th>
                        <th>Tahun</th>
                        <th>ISBN</th>
                        <th>Kategori</th>
                        <th>Rak</th>
                        <th>Status</th>
                        <th>Harga</th>
                    </tr>
                </thead>
                <tbody>
                    <tr>
                        <td>1</td>
                        <td>Pemrograman Web Modern dengan Bootstrap</td>
                        <td>Andi Pratama</td>
                        <td>Penerbit Digital</td>
                        <td>2024</td>
                        <td>978-123-456-789</td>
                        <td>Teknologi</td>
                        <td>Rak A-12</td>
                        <td>Tersedia</td>
                        <td>Rp 120.000</td>
                    </tr>
                    <tr>
                        <td>2</td>
                        <td>Machine Learning untuk Pemula</td>
                        <td>Budi Santoso</td>
                        <td>Penerbit Sains</td>
                        <td>2023</td>
                        <td>978-987-654-321</td>
                        <td>Sains</td>
                        <td>Rak B-05</td>
                        <td>Dipinjam</td>
                        <td>Rp 150.000</td>
                    </tr>
                </tbody>
            </table>
        </div>
        <h2 class="mt-4">table-responsive-md (scroll hanya di layar &lt; md)</h2>
        <div class="table-responsive-md">
            <table class="table">
                <thead><tr><th>Kolom 1</th><th>Kolom 2</th><th>Kolom 3</th><th>Kolom 4</th><th>Kolom 5</th></tr></thead>
                <tbody><tr><td>Data 1</td><td>Data 2</td><td>Data 3</td><td>Data 4</td><td>Data 5</td></tr></tbody>
            </table>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `table-responsive` adalah pembungkus `<div>`, bukan class pada tabel.
- Tabel akan memiliki scrollbar horizontal saat melebihi lebar layar.
- Gunakan variant breakpoint seperti `table-responsive-md` untuk kontrol responsif.
- Sangat penting untuk tabel dengan banyak kolom agar tetap accessible di mobile.
