# Membuat Progress Bar Menggunakan Class Progress dan Progress-bar

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika Anda mengunggah dokumen atau memproses permintaan peminjaman, Anda mungkin ingin melihat seberapa jauh proses tersebut telah berjalan. Progress bar adalah indikator visual yang menunjukkan persentase penyelesaian suatu tugas. Bootstrap menyediakan class `progress` sebagai wadah dan `progress-bar` sebagai indikator yang mengisi wadah tersebut. Ini seperti gelas ukur yang menunjukkan seberapa penuh air di dalamnya.

## Penjelasan Detail

Progress bar Bootstrap terdiri dari dua elemen: `<div>` dengan class `progress` sebagai wadah luar yang memberikan latar belakang abu-abu dan border-radius, dan `<div>` di dalamnya dengan class `progress-bar` yang menunjukkan progress sebenarnya. Lebar `progress-bar` diatur dengan inline style `width: X%` atau menggunakan class width utilities. Secara default, `progress-bar` berwarna biru (primary). Anda bisa menambahkan teks di dalam `progress-bar` untuk menampilkan persentase numerik. Ketinggian default progress bar adalah 1rem, bisa diubah dengan utilities `h-*` atau style kustom.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Progress Bar</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Progress Bar</h1>
        <p>Status pemrosesan permintaan peminjaman:</p>
        <div class="progress mb-3">
            <div class="progress-bar" style="width: 25%;">25%</div>
        </div>
        <div class="progress mb-3">
            <div class="progress-bar" style="width: 50%;">50%</div>
        </div>
        <div class="progress mb-3">
            <div class="progress-bar" style="width: 75%;">75%</div>
        </div>
        <div class="progress">
            <div class="progress-bar" style="width: 100%;">100% Selesai</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `progress` adalah wadah dengan latar abu-abu, `progress-bar` adalah indikator.
- Atur lebar `progress-bar` dengan inline style `width: X%`.
- Teks di dalam `progress-bar` menampilkan persentase secara otomatis.
- Progress bar dapat dikombinasikan dengan warna dan efek lainnya.
