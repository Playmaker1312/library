# Membuat Spinner Loading Menggunakan Class Spinner-border

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika Anda mencari buku atau memuat halaman, mungkin ada lingkaran berputar yang menandakan bahwa sistem sedang bekerja. Ini adalah spinner loading. Bootstrap menyediakan class `spinner-border` untuk membuat indikator loading berbentuk lingkaran berputar yang ringan dan elegan. Spinner ini seperti jam pasir digital yang memberi tahu pengguna bahwa permintaan mereka sedang diproses.

## Penjelasan Detail

`spinner-border` adalah elemen HTML (biasanya `<div>` atau `<span>`) yang menampilkan animasi lingkaran berputar menggunakan CSS murni. Spinner menggunakan border tipis yang salah satu sisinya transparan, lalu diputar dengan animasi CSS. Anda bisa mengubah warna spinner menggunakan class text color utilities seperti `text-primary`, `text-success`, `text-danger`, dll. Ukuran spinner default adalah 2rem (32px). Untuk mengubah ukuran, gunakan utilities `width` dan `height` CSS atau class `spinner-border-sm` untuk versi kecil.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Spinner Border</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Spinner Loading</h1>
        <p class="text-muted">Sedang memuat data perpustakaan...</p>
        <div class="d-flex gap-3 align-items-center">
            <div class="spinner-border text-primary" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-border text-success" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-border text-danger" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-border text-warning" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-border text-info" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-border text-dark" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
        </div>
        <h2 class="mt-4">Spinner dengan Teks</h2>
        <button class="btn btn-primary" disabled>
            <span class="spinner-border spinner-border-sm" role="status"></span>
            Memuat...
        </button>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `spinner-border` membuat indikator loading lingkaran berputar.
- Gunakan utilities `text-*` untuk mengubah warna spinner.
- Tambahkan `role="status"` dan `visually-hidden` text untuk aksesibilitas.
- Cocok digunakan di dalam tombol untuk menunjukkan proses loading.
