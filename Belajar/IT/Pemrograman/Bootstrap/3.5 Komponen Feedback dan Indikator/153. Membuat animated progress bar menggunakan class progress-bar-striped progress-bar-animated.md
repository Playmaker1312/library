# Membuat Animated Progress Bar Menggunakan Class Progress-bar-striped Progress-bar-animated

## Analogi: Perpustakaan Digital

Bayangkan Anda sedang mengunduh buku digital dari perpustakaan. Progress bar yang bergerak dengan animasi garis-garis yang berjalan memberikan kesan bahwa proses masih aktif dan belum berhenti. Bootstrap menyediakan class `progress-bar-animated` yang menganimasikan efek striped pada progress bar, membuat garis-garisnya bergerak dari atas ke bawah. Animasi ini memberikan feedback visual yang menenangkan pengguna bahwa proses sedang berlangsung.

## Penjelasan Detail

Class `progress-bar-animated` bekerja bersama `progress-bar-striped` untuk menambahkan animasi CSS pada background striped. Animasi ini menggunakan CSS `animation` yang menggeser posisi striped secara linear dan terus-menerus, menciptakan efek garis berjalan. Animasi dapat dihentikan dengan menghapus class `progress-bar-animated` atau dengan menambahkan CSS `animation-play-state: paused`. Penting untuk dicatat bahwa animasi ini membutuhkan `progress-bar-striped` agar terlihat efeknya. Tanpa striped, `progress-bar-animated` tidak akan memiliki efek visual.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Animated Progress Bar</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Animated Progress Bar</h1>
        <p class="text-muted">Sedang mengunduh buku digital...</p>
        <div class="progress mb-4">
            <div class="progress-bar progress-bar-striped progress-bar-animated" style="width: 45%;">
                Mengunduh... 45%
            </div>
        </div>
        <div class="progress mb-4" style="height: 30px;">
            <div class="progress-bar progress-bar-striped progress-bar-animated bg-success" style="width: 70%;">
                Memproses... 70%
            </div>
        </div>
        <div class="progress mb-4">
            <div class="progress-bar progress-bar-striped progress-bar-animated bg-warning" style="width: 90%;">
                Hampir selesai... 90%
            </div>
        </div>
        <h2 class="mt-4">Tanpa Animasi (selesai)</h2>
        <div class="progress">
            <div class="progress-bar bg-success" style="width: 100%;">
                Selesai!
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `progress-bar-animated` menambahkan animasi pada efek striped.
- Membutuhkan `progress-bar-striped` agar efek terlihat.
- Animasi bersifat terus-menerus (infinite) secara default.
- Cocok untuk indikasi proses loading yang sedang berlangsung.
