# Membuat Spinner Grow Menggunakan Class Spinner-grow

## Analogi: Perpustakaan Digital

Selain spinner yang berputar, Bootstrap juga menyediakan spinner yang tumbuh dan menyusut (pulse effect) menggunakan class `spinner-grow`. Spinner ini tidak berputar, melainkan berdenyut seperti detak jantung atau seperti bola yang mengembang dan mengempis secara bergantian. Efek ini memberikan variasi visual dari spinner biasa dan bisa digunakan untuk menarik perhatian pengguna ke elemen tertentu yang sedang memuat.

## Penjelasan Detail

`spinner-grow` menggunakan CSS `animation` dengan `scale` transform untuk menciptakan efek tumbuh dan menyusut. Sama seperti `spinner-border`, spinner ini dapat diubah warnanya menggunakan utilities `text-*`. Ukuran defaultnya juga 2rem, dengan varian `spinner-grow-sm` untuk ukuran kecil. Perbedaan utama antara `spinner-border` dan `spinner-grow` adalah gerakannya: border berputar, grow berdenyut. Pilihan antara keduanya tergantung pada preferensi desain. Spinner grow terkadang lebih cocok untuk konteks yang lebih lembut atau modern.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Spinner Grow</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Spinner Grow</h1>
        <p class="text-muted">Memproses permintaan Anda...</p>
        <div class="d-flex gap-3 align-items-center">
            <div class="spinner-grow text-primary" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-grow text-success" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-grow text-danger" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-grow text-warning" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-grow text-info" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
            <div class="spinner-grow text-dark" role="status">
                <span class="visually-hidden">Loading...</span>
            </div>
        </div>
        <h2 class="mt-4">Perbandingan: Border vs Grow</h2>
        <div class="d-flex gap-4 align-items-center">
            <div>
                <p><code>spinner-border</code></p>
                <div class="spinner-border text-primary"></div>
            </div>
            <div>
                <p><code>spinner-grow</code></p>
                <div class="spinner-grow text-primary"></div>
            </div>
        </div>
        <h2 class="mt-4">Dalam Tombol</h2>
        <button class="btn btn-success" disabled>
            <span class="spinner-grow spinner-grow-sm"></span>
            Menyimpan...
        </button>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `spinner-grow` menampilkan efek berdenyut (tumbuh dan menyusut).
- Berbeda dengan `spinner-border` yang berputar.
- Warna diatur dengan utilities `text-*`.
- Tersedia varian kecil `spinner-grow-sm`.
