# Menggunakan JavaScript Bootstrap API untuk Menampilkan dan Menyembunyikan Toast

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda mungkin ingin mengontrol kapan toast notification muncul — misalnya setelah pengguna berhasil meminjam buku, atau saat terjadi error. Bootstrap menyediakan JavaScript API untuk mengontrol toast secara programatis, termasuk menampilkan, menyembunyikan, dan menangani event saat toast muncul atau menghilang. Ini seperti remote control untuk sistem notifikasi perpustakaan yang memungkinkan Anda mengatur kapan dan bagaimana pesan ditampilkan.

## Penjelasan Detail

Bootstrap Toast API dapat diakses melalui `new bootstrap.Toast(element, options)` di mana `element` adalah DOM element toast dan `options` adalah konfigurasi opsional. Opsi yang tersedia antara lain: `animation` (default true), `autohide` (default true, toast otomatis hilang), dan `delay` (default 5000ms, waktu delay sebelum auto-hide). Method utama: `.show()` untuk menampilkan, `.hide()` untuk menyembunyikan, dan `.dispose()` untuk menghapus instance. Events: `show.bs.toast` (saat akan ditampilkan), `shown.bs.toast` (setelah tampil), `hide.bs.toast` (saat akan disembunyikan), `hidden.bs.toast` (setelah disembunyikan). API ini memungkinkan integrasi toast dengan logika aplikasi yang lebih kompleks.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Toast JavaScript API</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Toast JavaScript API</h1>
        <div class="d-flex gap-2 mb-3">
            <button class="btn btn-success" onclick="showSuccessToast()">Sukses</button>
            <button class="btn btn-danger" onclick="showErrorToast()">Error</button>
            <button class="btn btn-info" onclick="showCustomToast()">Kustom (10 detik)</button>
        </div>
        <div class="toast-container position-fixed top-0 end-0 p-3">
            <div class="toast" id="successToast" role="alert">
                <div class="toast-header bg-success text-white">
                    <strong class="me-auto">Sukses</strong>
                    <button class="btn-close btn-close-white" data-bs-dismiss="toast"></button>
                </div>
                <div class="toast-body">✅ Buku berhasil dipinjam!</div>
            </div>
            <div class="toast" id="errorToast" role="alert">
                <div class="toast-header bg-danger text-white">
                    <strong class="me-auto">Error</strong>
                    <button class="btn-close btn-close-white" data-bs-dismiss="toast"></button>
                </div>
                <div class="toast-body">❌ Gagal memproses permintaan. Coba lagi.</div>
            </div>
            <div class="toast" id="customToast" role="alert">
                <div class="toast-header bg-warning">
                    <strong class="me-auto">Peringatan</strong>
                    <button class="btn-close" data-bs-dismiss="toast"></button>
                </div>
                <div class="toast-body">⏰ Peminjaman akan berakhir dalam 2 hari!</div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
    <script>
        function showSuccessToast() {
            const toast = new bootstrap.Toast(document.getElementById('successToast'));
            toast.show();
        }
        function showErrorToast() {
            const toast = new bootstrap.Toast(document.getElementById('errorToast'), { autohide: false });
            toast.show();
        }
        function showCustomToast() {
            const toast = new bootstrap.Toast(document.getElementById('customToast'), { delay: 10000 });
            toast.show();
        }
    </script>
</body>
</html>
```

## Poin Penting
- Gunakan `new bootstrap.Toast(element, options)` untuk membuat instance toast.
- Opsi `autohide` (default true) mengontrol apakah toast otomatis hilang.
- Opsi `delay` mengatur waktu dalam ms sebelum auto-hide.
- Events `show.bs.toast`, `shown.bs.toast`, `hide.bs.toast`, `hidden.bs.toast` untuk hook.
