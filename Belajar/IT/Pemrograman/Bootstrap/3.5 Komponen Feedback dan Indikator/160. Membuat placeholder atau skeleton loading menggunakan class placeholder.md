# Membuat Placeholder atau Skeleton Loading Menggunakan Class Placeholder

## Analogi: Perpustakaan Digital

Saat halaman perpustakaan digital sedang memuat konten, alih-alih menampilkan halaman kosong yang membingungkan, Anda bisa menampilkan placeholder atau skeleton loading — blok abu-abu yang berbentuk seperti konten asli tetapi dalam keadaan "kerangka". Ini memberi kesan kepada pengguna bahwa halaman sedang dimuat dan konten akan segera muncul. Bootstrap menyediakan class `placeholder` untuk membuat efek skeleton loading yang mudah dan cepat.

## Penjelasan Detail

Class `placeholder` digunakan pada elemen inline atau block untuk menampilkan efek loading skeleton. Class ini memberikan latar belakang abu-abu dengan animasi glowing (pulse). Anda bisa mengatur lebar placeholder dengan class width utilities seperti `w-25`, `w-50`, `w-75`, `col-*`, atau persentase kustom. Placeholder dapat diterapkan pada berbagai elemen: `placeholder` untuk inline, `placeholder-glow` pada wadah untuk efek glowing, `placeholder-wave` pada wadah untuk efek wave. Anda juga bisa mengkombinasikan placeholder dengan class `bg-*` untuk warna yang berbeda. Placeholder sangat berguna untuk meningkatkan perceived performance dan user experience saat konten masih dimuat.

## Poin Penting
- `placeholder` menampilkan efek skeleton loading abu-abu.
- `placeholder-glow` untuk efek animasi glowing, `placeholder-wave` untuk efek wave.
- Atur lebar placeholder dengan utilities `w-*` atau `col-*`.
- Placeholder bisa diterapkan pada berbagai elemen termasuk teks, tombol, dan gambar.
