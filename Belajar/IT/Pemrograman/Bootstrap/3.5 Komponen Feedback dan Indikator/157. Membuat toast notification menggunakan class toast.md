# Membuat Toast Notification Menggunakan Class Toast

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ketika Anda berhasil meminjam buku, sebuah pemberitahuan kecil muncul di sudut layar yang memberi tahu "Peminjaman berhasil!" dan menghilang setelah beberapa detik. Ini adalah toast notification — pesan non-intrusif yang muncul sementara dan tidak memerlukan interaksi pengguna. Bootstrap menyediakan komponen `toast` untuk membuat notifikasi semacam ini. Toast seperti catatan tempel yang muncul dan menghilang dengan sendirinya.

## Penjelasan Detail

Toast Bootstrap terdiri dari elemen dengan class `toast` yang berisi `toast-header` (untuk judul dan tombol tutup) dan `toast-body` (untuk pesan). Toast secara default tersembunyi dan perlu ditampilkan dengan JavaScript Bootstrap atau atribut data. Toast ditempatkan di dalam kontainer `toast-container` yang bisa diposisikan di mana saja menggunakan utilities `position-*`. Fitur utama toast adalah bahwa toast tidak memblokir interaksi pengguna (non-modal) dan biasanya memiliki waktu tampil otomatis (auto-hide). Toast sangat cocok untuk notifikasi operasi sukses, error, atau informasi singkat.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Toast Notification</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Toast Notification</h1>
        <button class="btn btn-primary" onclick="showToast()">Tampilkan Toast</button>
        <div class="toast-container position-fixed bottom-0 end-0 p-3">
            <div class="toast" id="liveToast" role="alert">
                <div class="toast-header">
                    <strong class="me-auto">Perpustakaan Digital</strong>
                    <small>baru saja</small>
                    <button class="btn-close" data-bs-dismiss="toast"></button>
                </div>
                <div class="toast-body">
                    ✅ Buku berhasil dipinjam! Selamat membaca.
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
    <script>
        function showToast() {
            const toast = new bootstrap.Toast(document.getElementById('liveToast'));
            toast.show();
        }
    </script>
</body>
</html>
```

## Poin Penting
- `toast` adalah wadah notifikasi yang muncul sementara.
- Toast memiliki `toast-header` dan `toast-body`.
- Gunakan `toast-container` untuk memposisikan toast di area tertentu.
- Toast ditampilkan dengan JavaScript API `bootstrap.Toast` atau atribut data.
