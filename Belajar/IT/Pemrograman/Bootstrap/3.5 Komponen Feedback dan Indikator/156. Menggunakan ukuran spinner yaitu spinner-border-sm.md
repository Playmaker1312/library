# Menggunakan Ukuran Spinner yaitu Spinner-border-sm

## Analogi: Perpustakaan Digital

Tidak semua spinner di perpustakaan digital harus berukuran besar. Di dalam tombol "Simpan" atau "Cari", spinner perlu lebih kecil agar tidak mendominasi tampilan. Bootstrap menyediakan varian `spinner-border-sm` (dan `spinner-grow-sm`) untuk spinner berukuran kecil. Seperti lampu indikator kecil pada panel kontrol perpustakaan, spinner kecil memberi tahu pengguna bahwa ada proses berjalan tanpa mengganggu tata letak halaman.

## Penjelasan Detail

Spinner kecil (small) dibuat dengan menambahkan class `spinner-border-sm` pada elemen yang sudah memiliki class `spinner-border`. Class ini mengurangi ukuran spinner dari 2rem (32px) menjadi 1rem (16px) dengan mengatur ulang `width`, `height`, dan `border-width`. Anda juga bisa mengatur ukuran spinner secara kustom menggunakan utilities `width` dan `height` atau style inline untuk mendapatkan ukuran yang benar-benar spesifik. Spinner kecil sangat berguna di dalam tombol, input group, atau area terbatas lainnya di mana spinner ukuran penuh akan terlalu besar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ukuran Spinner</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Ukuran Spinner</h1>
        <div class="d-flex gap-4 align-items-center mb-4">
            <div>
                <p><strong>spinner-border-sm</strong></p>
                <div class="spinner-border spinner-border-sm text-primary" role="status"></div>
            </div>
            <div>
                <p><strong>spinner-border (default)</strong></p>
                <div class="spinner-border text-primary" role="status"></div>
            </div>
            <div>
                <p><strong>Custom (3rem)</strong></p>
                <div class="spinner-border text-primary" style="width: 3rem; height: 3rem;" role="status"></div>
            </div>
        </div>
        <h2>spinner-grow-sm</h2>
        <div class="d-flex gap-4 align-items-center mb-4">
            <div>
                <div class="spinner-grow spinner-grow-sm text-success" role="status"></div>
                <p><code>spinner-grow-sm</code></p>
            </div>
            <div>
                <div class="spinner-grow text-success" role="status"></div>
                <p><code>spinner-grow</code></p>
            </div>
        </div>
        <h2>Dalam Tombol</h2>
        <button class="btn btn-primary me-2" disabled>
            <span class="spinner-border spinner-border-sm"></span> Loading
        </button>
        <button class="btn btn-success" disabled>
            <span class="spinner-grow spinner-grow-sm"></span> Processing
        </button>
        <h2 class="mt-4">Ukuran Kustom</h2>
        <div class="spinner-border text-warning" style="width: 4rem; height: 4rem; border-width: 6px;" role="status"></div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `spinner-border-sm` mengurangi ukuran spinner menjadi setengahnya (16px).
- `spinner-grow-sm` untuk varian grow ukuran kecil.
- Spinner kecil cocok ditempatkan di dalam tombol atau area terbatas.
- Ukuran spinner bisa disesuaikan secara kustom dengan CSS.
