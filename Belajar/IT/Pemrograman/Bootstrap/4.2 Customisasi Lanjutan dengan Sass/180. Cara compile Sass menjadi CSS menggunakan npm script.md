# Cara compile Sass menjadi CSS menggunakan npm script

## Analogi: Perpustakaan Digital

Seperti mencetak katalog dari file master digital — seluruh pengaturan font, warna, dan tata letak diubah menjadi dokumen cetak yang siap digunakan — kompilasi Sass mengubah file `.scss` menjadi file `.css` yang dapat dibaca oleh browser. npm scripts adalah tombol "cetak" yang menjalankan proses ini secara otomatis.

## Penjelasan Detail

Setelah menulis file Sass kustom yang mengimpor Bootstrap, Anda perlu mengompilasinya menjadi CSS. Sass CLI menyediakan perintah `sass` untuk tujuan ini. Anda bisa menambahkan script ke `package.json` untuk memudahkan kompilasi. Opsi `--watch` memungkinkan kompilasi otomatis setiap kali file `.scss` berubah. Opsi `--style` mengontrol format output: `expanded` (default, terbaca) atau `compressed` (minified, produksi). Opsi `--load-path` memudahkan impor dari `node_modules`. Untuk CSS production, minifikasi menghasilkan file berukuran jauh lebih kecil. Anda juga bisa menggunakan tools seperti PostCSS dengan Autoprefixer untuk menambah vendor prefixes.

## Contoh Kode Implementasi

```json
{
  "name": "bootstrap-custom",
  "version": "1.0.0",
  "scripts": {
    "sass:dev": "sass --watch --load-path=node_modules scss/custom.scss css/styles.css",
    "sass:build": "sass --load-path=node_modules --style=compressed scss/custom.scss css/styles.min.css",
    "build": "npm run sass:build && postcss css/styles.min.css --use autoprefixer -o css/styles.min.css"
  },
  "devDependencies": {
    "autoprefixer": "^10.4.0",
    "postcss": "^8.4.0",
    "postcss-cli": "^10.0.0",
    "sass": "^1.70.0"
  },
  "dependencies": {
    "bootstrap": "^5.3.0"
  }
}
```

```bash
# Compile untuk development (watch mode)
npm run sass:dev

# Compile untuk production (minified + autoprefixer)
npm run build
```

## Poin Penting
- Tambahkan script ke `package.json` untuk memudahkan kompilasi Sass
- Gunakan `--watch` untuk kompilasi otomatis saat pengembangan
- Gunakan `--style=compressed` untuk file CSS production yang lebih kecil
- Kombinasikan dengan Autoprefixer untuk kompatibilitas browser yang lebih luas
