# Memahami utility API Bootstrap untuk menambah utilitas baru

## Analogi: Perpustakaan Digital

Bayangkan memiliki mesin stempel otomatis yang bisa memproduksi berbagai macam stempel — stempel "Denda", "Tersedia", "Dipinjam" — dengan hanya mengatur parameter di panel kontrol. Utility API Bootstrap adalah mesin stempel ini: Anda cukup mendefinisikan konfigurasi, dan API akan menghasilkan semua utility classes yang Anda butuhkan secara otomatis.

## Penjelasan Detail

Utility API adalah fitur canggih Bootstrap 5 yang memungkinkan Anda menambah, mengubah, atau menghapus utility classes melalui Sass map `$utilities`. Setiap utility didefinisikan dengan properti seperti `property` (CSS property yang diatur), `values` (nilai-nilai yang tersedia), `class` (prefix class), `responsive` (apakah mendukung breakpoints), dan `print` (apakah berlaku untuk print). API secara otomatis menghasilkan class seperti `.class-value` dan `.class-breakpoint-value`. Untuk menambah utility baru, tambahkan entry baru ke map `$utilities` menggunakan `map-merge`. Anda juga bisa memodifikasi utility yang sudah ada menggunakan fungsi `map-get` dan `map-merge`.

## Contoh Kode Implementasi

```scss
// custom.scss — menambah utility baru melalui Utility API

// Tambah utility cursor
$utilities: map-merge(
  $utilities,
  (
    "cursor": (
      property: cursor,
      values: auto pointer grab zoom-in default,
    ),
  )
);

// Utility opacity kustom
$utilities: map-merge(
  $utilities,
  (
    "opacity-custom": (
      property: opacity,
      values: (
        0: 0,
        25: 0.25,
        50: 0.5,
        75: 0.75,
        100: 1,
      ),
    ),
  )
);

// Utility height dengan responsive
$utilities: map-merge(
  $utilities,
  (
    "viewport-height": (
      property: height,
      class: vh,
      values: (
        25: 25vh,
        50: 50vh,
        75: 75vh,
        100: 100vh,
      ),
      responsive: true,
    ),
  )
);

@import "../node_modules/bootstrap/scss/bootstrap";
```

## Poin Penting
- Utility API menggunakan map `$utilities` untuk konfigurasi
- Setiap utility didefinisikan dengan property, values, class prefix, dan opsi responsive
- Gunakan `map-merge` untuk menambah atau memodifikasi utility
- Utility API secara otomatis menghasilkan class untuk setiap value dan breakpoint
