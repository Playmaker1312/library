# Membuat custom component menggunakan Sass dan Bootstrap variables

## Analogi: Perpustakaan Digital

Seperti merancang rak buku khusus dengan dimensi dan warna yang sesuai standar perpustakaan, membuat custom component menggunakan Sass dan Bootstrap variables memungkinkan Anda membangun elemen UI baru yang secara visual konsisten dengan komponen Bootstrap lainnya. Komponen kustom Anda akan menggunakan palet warna, tipografi, spacing, dan sistem grid yang sama.

## Penjelasan Detail

Untuk membuat custom component yang terintegrasi dengan Bootstrap, gunakan variabel-variabel Bootstrap yang sudah ada. Referensikan `$primary`, `$font-family-base`, `$border-radius`, `$spacer`, dan variabel lainnya di file Sass kustom Anda. Gunakan mixins Bootstrap seperti `border-radius()`, `box-shadow()`, `media-breakpoint-up()`, dan `make-container()`. Komponen kustom akan secara otomatis menyesuaikan jika tema Bootstrap diubah di kemudian hari. Pendekatan ini memastikan konsistensi desain tanpa harus mendefinisikan ulang nilai-nilai dasar. Struktur file yang baik adalah memisahkan komponen kustom ke file partial `_custom-components.scss` sendiri.

## Contoh Kode Implementasi

```scss
// _custom-components.scss

// Komponen: Profile Card
.profile-card {
  background-color: $white;
  border: $border-width solid $border-color;
  @include border-radius($border-radius-lg);
  @include box-shadow($box-shadow-sm);
  padding: $spacer * 1.5;
  text-align: center;
  
  .profile-avatar {
    width: 80px;
    height: 80px;
    @include border-radius(50%);
    object-fit: cover;
    border: 3px solid $primary;
    margin-bottom: $spacer;
  }
  
  .profile-name {
    font-family: $headings-font-family;
    font-size: $h5-font-size;
    font-weight: $headings-font-weight;
    color: $dark;
    margin-bottom: $spacer * 0.25;
  }
  
  .profile-bio {
    color: $secondary;
    font-size: $font-size-sm;
    margin-bottom: $spacer;
  }
  
  .profile-stats {
    @include make-row();
    border-top: $border-width solid $border-color;
    padding-top: $spacer;
    
    .stat-item {
      @include make-col-ready();
      @include make-col(4);
      text-align: center;
      
      .stat-value {
        font-weight: $font-weight-bold;
        color: $primary;
      }
      
      .stat-label {
        font-size: $font-size-sm;
        color: $secondary;
      }
    }
  }
}
```

## Poin Penting
- Gunakan variabel Bootstrap (`$primary`, `$spacer`, `$border-radius`) untuk konsistensi
- Gunakan mixins Bootstrap untuk border-radius, box-shadow, grid, dan responsive
- Komponen kustom akan otomatis menyesuaikan saat tema Bootstrap diubah
- Simpan komponen kustom di file partial terpisah untuk organisasi yang rapi
