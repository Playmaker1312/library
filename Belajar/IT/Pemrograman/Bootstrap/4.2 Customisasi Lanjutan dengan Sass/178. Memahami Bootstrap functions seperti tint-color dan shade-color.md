# Memahami Bootstrap functions seperti tint-color dan shade-color

## Analogi: Perpustakaan Digital

Seperti mencampur cat putih untuk membuat warna lebih terang (tint) atau cat hitam untuk membuat lebih gelap (shade), fungsi `tint-color` dan `shade-color` di Bootstrap memungkinkan Anda menghasilkan variasi warna secara otomatis. Ini seperti memiliki mesin pencampur cat digital yang konsisten dan presisi.

## Penjelasan Detail

Bootstrap menyediakan beberapa fungsi Sass yang berguna untuk manipulasi warna dan nilai. `tint-color($color, $percentage)` mencampur warna dengan putih untuk membuat versi lebih terang. `shade-color($color, $percentage)` mencampur warna dengan hitam untuk membuat versi lebih gelap. `shift-color($color, $percentage)` menggabungkan keduanya — nilai positif menghasilkan shade, nilai negatif menghasilkan tint. Ada juga `color-contrast($color)` untuk menentukan warna teks kontras (hitam atau putih) berdasarkan latar belakang, dan `rgba-to-css($rgba)` untuk konversi format. Fungsi-fungsi ini digunakan secara internal Bootstrap untuk menghasilkan variasi tombol, alert, dan komponen lainnya. Anda juga dapat menggunakannya dalam kode Sass kustom.

## Contoh Kode Implementasi

```scss
// custom.scss — menggunakan fungsi Bootstrap

// Tint: menambah putih (warna lebih terang)
$primary-light: tint-color($primary, 60%);
// shade-color: menambah hitam (warna lebih gelap)
$primary-dark: shade-color($primary, 40%);

// shift-color: positif = shade, negatif = tint
$primary-darker: shift-color($primary, 20%);
$primary-lighter: shift-color($primary, -30%);

// color-contrast: dapatkan warna teks kontras
$btn-bg: $primary;
$btn-color: color-contrast($btn-bg); // putih atau hitam

// Penggunaan dalam komponen kustom
.custom-card {
  background-color: tint-color($primary, 80%);
  border: 1px solid tint-color($primary, 50%);
  color: color-contrast(tint-color($primary, 80%));
  
  .custom-card-header {
    background-color: $primary;
    color: color-contrast($primary);
  }
}
```

## Poin Penting
- `tint-color()` mencampur warna dengan putih (lebih terang)
- `shade-color()` mencampur warna dengan hitam (lebih gelap)
- `shift-color()` menggabungkan tint dan shade berdasarkan nilai persentase
- `color-contrast()` mengembalikan #fff atau #000 untuk keterbacaan optimal
