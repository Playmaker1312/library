# Cara menambah custom color ke dalam theme Bootstrap

## Analogi: Perpustakaan Digital

Seperti menambahkan kategori buku baru — misalnya "Graphic Novel" dengan label warna ungu — menambah warna kustom ke tema Bootstrap memungkinkan Anda memperluas palet warna di luar warna default. Warna baru ini akan secara otomatis tersedia untuk semua komponen Bootstrap: tombol, badge, alert, background, dan teks.

## Penjelasan Detail

Untuk menambah warna kustom ke tema Bootstrap, Anda perlu memodifikasi map `$theme-colors` menggunakan fungsi `map-merge()`. Warna baru yang ditambahkan akan secara otomatis menghasilkan class-class seperti `btn-{nama}`, `bg-{nama}`, `text-{nama}`, `alert-{nama}`, dan `badge-{nama}`. Bootstrap juga secara otomatis membuat variasi warna (lebih terang, lebih gelap) menggunakan fungsi Sass `tint-color()` dan `shade-color()`. Pastikan nama warna kustom tidak bertabrakan dengan warna default, atau Anda bisa sengaja override warna default. Untuk kontrol yang lebih baik, Anda juga bisa menambahkan warna ke map `$colors` yang lebih luas cakupannya.

## Contoh Kode Implementasi

```scss
// custom.scss — menambah custom color

// 1. Definisikan warna kustom
$purple: #6f42c1;
$orange: #fd7e14;
$teal: #20c997;

// 2. Merge ke theme-colors
$theme-colors: map-merge(
  $theme-colors,
  (
    "purple": $purple,
    "orange": $orange,
    "teal": $teal,
  )
);

// 3. Tambah juga ke $colors untuk cakupan lebih luas
$colors: map-merge(
  $colors,
  (
    "purple": $purple,
    "orange": $orange,
    "teal": $teal,
  )
);

@import "../node_modules/bootstrap/scss/bootstrap";

// Di HTML, warna baru bisa langsung digunakan:
// <button class="btn btn-purple">Tombol Ungu</button>
// <div class="bg-teal text-white">Konten Teal</div>
// <span class="badge bg-orange">Label Orange</span>
```

## Poin Penting
- Gunakan `map-merge()` untuk menambah warna ke `$theme-colors`
- Warna baru otomatis tersedia untuk button, badge, alert, bg, text, dan utility lainnya
- Bootstrap menghasilkan variasi warna (light/dark) secara otomatis
- Hindari tabrakan nama dengan warna default Bootstrap
