# Menggunakan Bootstrap mixin make-container dan make-row

## Analogi: Perpustakaan Digital

Seperti kerangka rak buku yang memiliki bingkai utama (container) dan sekat-sekat horizontal (row), mixin `make-container` dan `make-row` adalah cetakan untuk membuat struktur grid Bootstrap. Anda bisa membuat elemen layout kustom yang memiliki perilaku grid yang sama dengan container dan row Bootstrap, tanpa harus menggunakan class `.container` atau `.row` di HTML.

## Penjelasan Detail

`make-container()` adalah mixin yang menghasilkan properti CSS untuk elemen container — termasuk `width`, `max-width`, `padding-left`, `padding-right`, dan `margin-left: auto; margin-right: auto` untuk centering. Mixin ini juga menerima parameter opsional untuk `$gutter` (jarak antar kolom). `make-row()` menghasilkan properti untuk row — terutama `display: flex`, `flex-wrap: wrap`, dan margin negatif untuk mengompensasi padding kolom. Kedua mixin ini berguna ketika Anda ingin membuat elemen layout kustom yang tetap mengikuti sistem grid Bootstrap. Anda bisa menggunakannya di dalam component class atau utility class kustom Anda.

## Contoh Kode Implementasi

```scss
// custom.scss — menggunakan make-container dan make-row

// Membuat container kustom
.custom-container {
  @include make-container();
  max-width: 1400px; // override max-width
}

// Membuat row kustom
.custom-row {
  @include make-row();
  gap: 0.5rem; // tambahan gap
}

// Penggunaan dalam component
.hero-section {
  @include make-container();
  
  .hero-grid {
    @include make-row();
  }
  
  .hero-column {
    @include make-col-ready();
    @include make-col(6);
    
    @include media-breakpoint-up(lg) {
      @include make-col(4);
    }
  }
}
```

## Poin Penting
- `make-container()` menghasilkan properti container dengan max-width responsif
- `make-row()` menghasilkan flex row dengan margin negatif untuk gutter
- Mixins ini berguna untuk membuat elemen layout kustom tanpa class Bootstrap di HTML
- Kombinasikan dengan `make-col-ready()` dan `make-col()` untuk kolom kustom
