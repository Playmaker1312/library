# Menggunakan Bootstrap mixin respond-to untuk custom media queries

## Analogi: Perpustakaan Digital

Seperti aturan "jika ruangan sempit, gunakan rak yang lebih kecil", media queries mengubah tampilan berdasarkan lebar layar. Mixin `media-breakpoint-up` dan `media-breakpoint-down` di Bootstrap adalah seperti saklar otomatis yang mengatur ulang tata letak perpustakaan digital Anda saat pengguna beralih dari desktop ke tablet ke ponsel.

## Penjelasan Detail

Bootstrap menyediakan mixins untuk membuat media queries berdasarkan breakpoints yang telah didefinisikan. Mixin `media-breakpoint-up($breakpoint)` membuat aturan `@media (min-width: ...)`, sedangkan `media-breakpoint-down($breakpoint)` membuat `@media (max-width: ...)`. Ada juga `media-breakpoint-only($breakpoint)` untuk range spesifik satu breakpoint, dan `media-breakpoint-between($lower, $upper)` untuk range antara dua breakpoint. Mixins ini menggunakan nilai dari map `$grid-breakpoints`, sehingga jika Anda mengubah breakpoints, media queries kustom Anda juga akan menyesuaikan secara otomatis. Ini lebih baik daripada menulis nilai hardcoded di media queries manual.

## Contoh Kode Implementasi

```scss
// custom.scss — menggunakan mixin respond-to

// media-breakpoint-up: ukuran layar ≥ breakpoint tertentu
.sidebar {
  width: 100%;
  
  @include media-breakpoint-up(md) {
    width: 250px;
  }
  
  @include media-breakpoint-up(lg) {
    width: 300px;
  }
}

// media-breakpoint-down: ukuran layar < breakpoint
@include media-breakpoint-down(sm) {
  .mobile-only {
    display: block;
  }
}

// media-breakpoint-only: spesifik satu breakpoint
@include media-breakpoint-only(md) {
  .tablet-layout {
    grid-template-columns: 1fr 1fr;
  }
}

// media-breakpoint-between: rentang breakpoint
@include media-breakpoint-between(md, xl) {
  .medium-to-large {
    font-size: 1.25rem;
  }
}
```

## Poin Penting
- Mixin `media-breakpoint-up($bp)` menghasilkan `min-width`, `media-breakpoint-down($bp)` menghasilkan `max-width`
- Mixins secara otomatis merujuk ke map `$grid-breakpoints`
- Jangan menulis nilai hardcoded — gunakan mixins agar konsisten dengan breakpoints proyek
- Mixins ini memudahkan pemeliharaan saat breakpoints diubah
