# Cara menonaktifkan komponen Bootstrap yang tidak digunakan untuk optimasi

## Analogi: Perpustakaan Digital

Seperti menyingkirkan rak-rak kosong dan buku-buku yang tidak relevan untuk menghemat ruang, menonaktifkan komponen Bootstrap yang tidak digunakan mengurangi ukuran file CSS yang harus diunduh pengguna. Hasilnya adalah website yang lebih cepat dimuat dan pengalaman pengguna yang lebih baik.

## Penjelasan Detail

Bootstrap menyediakan variabel boolean `$enable-*` yang mengontrol apakah suatu komponen atau fitur diikutsertakan dalam kompilasi. Contohnya: `$enable-caret` (panah dropdown), `$enable-rounded` (border radius), `$enable-shadows` (bayangan), `$enable-gradients` (gradien), `$enable-transitions` (transisi), `$enable-reduced-motion` (preferensi reduced motion), `$enable-smooth-scroll` (scroll halus), `$enable-validation-icons` (ikon validasi form), dan `$enable-dark-mode` (mode gelap). Selain melalui variabel boolean, Anda juga bisa mengomentari komponen yang tidak diinginkan di file impor. Pendekatan terbaik adalah menggabungkan keduanya: nonaktifkan fitur melalui `$enable-*` dan impor hanya komponen yang diperlukan.

## Contoh Kode Implementasi

```scss
// custom.scss — optimasi dengan menonaktifkan komponen

// Nonaktifkan fitur yang tidak diperlukan
$enable-caret: false;
$enable-rounded: false;
$enable-shadows: false;
$enable-gradients: false;
$enable-transitions: false;
$enable-reduced-motion: true;
$enable-smooth-scroll: false;
$enable-validation-icons: false;
$enable-dark-mode: false;

// Impor hanya komponen yang diperlukan
@import "../node_modules/bootstrap/scss/functions";
@import "../node_modules/bootstrap/scss/variables";
@import "../node_modules/bootstrap/scss/mixins";
@import "../node_modules/bootstrap/scss/root";
@import "../node_modules/bootstrap/scss/reboot";
@import "../node_modules/bootstrap/scss/type";
@import "../node_modules/bootstrap/scss/grid";
@import "../node_modules/bootstrap/scss/buttons";
@import "../node_modules/bootstrap/scss/forms";
@import "../node_modules/bootstrap/scss/utilities";
@import "../node_modules/bootstrap/scss/utilities/api";
```

## Poin Penting
- Variabel `$enable-*` mengontrol fitur CSS tertentu di Bootstrap
- Setel ke `false` untuk mengecualikan kode yang tidak diperlukan
- Kombinasikan dengan impor parsial untuk optimasi maksimal
- File CSS yang lebih kecil menghasilkan waktu muat halaman yang lebih cepat
