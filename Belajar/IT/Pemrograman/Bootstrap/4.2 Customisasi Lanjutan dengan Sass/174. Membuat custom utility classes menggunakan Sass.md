# Membuat custom utility classes menggunakan Sass

## Analogi: Perpustakaan Digital

Seperti membuat stempel khusus untuk "Buku Langka" atau "Koleksi Khusus" yang bisa digunakan di berbagai buku, custom utility classes memungkinkan Anda membuat class serbaguna yang bisa diterapkan di mana saja di HTML. Ini adalah alat serba guna yang mempercepat pengembangan dengan menghindari penulisan CSS berulang.

## Penjelasan Detail

Bootstrap memiliki Utility API yang kuat, tetapi Anda juga bisa membuat utility classes manual menggunakan perulangan Sass (`@each`) dan map. Pendekatan manual memberikan fleksibilitas penuh. Anda bisa membuat utility untuk warna teks kustom, background, ukuran font, border, shadow, dan properti lainnya. Caranya adalah dengan mendefinisikan map nilai, lalu menggunakan `@each` untuk menghasilkan class. Bootstrap juga menyediakan fungsi `important()` yang secara otomatis menambahkan `!important` pada utility. Anda bisa menggabungkan utility kustom dengan Bootstrap Utility API untuk hasil yang lebih terintegrasi.

## Contoh Kode Implementasi

```scss
// custom.scss — membuat custom utility classes

// 1. Utility warna teks kustom
$custom-colors: (
  "primary-light": #6ea8fe,
  "primary-dark": #0a58ca
);

@each $name, $color in $custom-colors {
  .text-#{$name} {
    color: $color !important;
  }
  .bg-#{$name} {
    background-color: $color !important;
  }
}

// 2. Utility font size kustom
$font-sizes-custom: (
  7: 0.75rem,
  8: 0.625rem
);

@each $size, $value in $font-sizes-custom {
  .fs-#{$size} {
    font-size: $value !important;
  }
}

// 3. Utility border width kustom
$border-widths: (
  3: 3px,
  4: 4px,
  5: 5px
);

@each $width, $value in $border-widths {
  .border-#{$width} {
    border-width: $value !important;
  }
}
```

## Poin Penting
- Gunakan `@each` untuk menghasilkan utility classes secara dinamis dari map
- Tambahkan `!important` pada utility classes untuk memastikan prioritas tinggi
- Nama class harus konsisten dengan konvensi Bootstrap (contoh: `text-*`, `bg-*`, `fs-*`)
- Kustom utility dapat dikombinasikan dengan Bootstrap Utility API untuk proyek besar
