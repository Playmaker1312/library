# Breakpoints

## Penjelasan
Breakpoints adalah titik-titik lebar layar di mana layout berubah menyesuaikan ukuran perangkat. Bootstrap memiliki 6 breakpoint dengan pendekatan **mobile-first** — artinya gaya default untuk layar kecil, kemudian di-override untuk layar lebih besar.

## Fungsi
Membuat website responsif yang tampil optimal di semua perangkat: HP, tablet, laptop, dan monitor besar.

## 6 Breakpoint Bootstrap

| Breakpoint | Class Prefix | Ukuran Minimal |
|------------|-------------|----------------|
| Extra small (xs) | (default) | < 576px |
| Small (sm) | `col-sm-*` | ≥ 576px |
| Medium (md) | `col-md-*` | ≥ 768px |
| Large (lg) | `col-lg-*` | ≥ 992px |
| Extra large (xl) | `col-xl-*` | ≥ 1200px |
| XXL (xxl) | `col-xxl-*` | ≥ 1400px |

## Cara Pengimplementasian

```html
<!-- Di HP: 2 kolom, di tablet: 3 kolom, di laptop: 4 kolom -->
<div class="container">
  <div class="row">
    <div class="col-6 col-md-4 col-lg-3">Item 1</div>
    <div class="col-6 col-md-4 col-lg-3">Item 2</div>
    <div class="col-6 col-md-4 col-lg-3">Item 3</div>
    <div class="col-6 col-md-4 col-lg-3">Item 4</div>
  </div>
</div>
```

```css
/* Yang terjadi di belakang layar — mobile-first */
.col-6 { width: 50%; }
@media (min-width: 768px) {
  .col-md-4 { width: 33.333%; }
}
@media (min-width: 992px) {
  .col-lg-3 { width: 25%; }
}
```

## Analogi
Breakpoints = **ukuran kavling tanah** tempat rumah dibangun.
- **xs** = kavling sempit (HP) — hanya cukup untuk 2 ruangan per lantai
- **md** = kavling sedang (tablet) — muat 3 ruangan per lantai
- **lg** = kavling luas (laptop) — bisa 4 ruangan per lantai
- **xl/xxl** = kavling sangat luas (monitor besar) — ruangan bisa lebih lega

Prinsip **mobile-first**: desain dulu untuk kavling tersempit, lalu perluas ruangan saat kavling lebih besar.

## Dipakai untuk apa
Membuat halaman yang nyaman dilihat di HP maupun desktop tanpa harus membuat dua versi website.

## Kesalahan umum yang sering terjadi
- Menggunakan `col-lg-*` saja tanpa kelas default — di layar kecil jadinya satu kolom penuh (mungkin itu yang diinginkan, atau tidak)
- Lupa bahwa Bootstrap mobile-first: `col-6 col-lg-4` berarti 2 kolom di HP, 3 kolom di lg ke atas
- Menambahkan breakpoint tidak berurutan dari kecil ke besar

## Koneksi dengan materi sebelumnya
Setelah memahami grid dasar (materi 5) dan container (materi 6), breakpoints memungkinkan denah rumah berubah otomatis tergantung ukuran kavling.

## Soal latihan & jawaban

**1. Ada berapa breakpoint dalam Bootstrap 5? Sebutkan!**
6: xs (<576px), sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px), xxl (≥1400px).

**2. Buat class column yang menampilkan 1 kolom di HP, 2 kolom di tablet, 3 kolom di laptop!**
```html
<div class="col-12 col-md-6 col-lg-4">Konten</div>
```

**3. Apa maksud pendekatan "mobile-first" dalam Bootstrap?**
Gaya default ditulis untuk layar kecil (tanpa media query), kemudian ditimpa dengan media query min-width untuk layar lebih besar. Prioritaskan pengalaman mobile terlebih dahulu.
