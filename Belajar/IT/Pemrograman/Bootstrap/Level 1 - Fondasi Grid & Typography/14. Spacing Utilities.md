# Spacing Utilities

## Penjelasan
Bootstrap memiliki sistem utilitas spacing yang lengkap untuk mengatur margin dan padding. Formatnya: `{property}{sides}-{size}`.

## Fungsi
Memberi jarak di sekitar dan di dalam elemen tanpa menulis CSS manual — mempercepat tata letak dan menjaga konsistensi.

## Cara Pengimplementasian

### Format
```
{property}{sides}-{size}
```

### Property
| Kode | Arti |
|------|------|
| `m` | margin (jarak luar) |
| `p` | padding (jarak dalam) |

### Sides
| Kode | Arti |
|------|------|
| `t` | top (atas) |
| `b` | bottom (bawah) |
| `s` | start (kiri — logical property) |
| `e` | end (kanan — logical property) |
| `x` | kiri + kanan (sumbu X) |
| `y` | atas + bawah (sumbu Y) |
| (kosong) | semua sisi |

### Size
| Kode | Ukuran |
|------|--------|
| `0` | 0 |
| `1` | 0.25rem (~4px) |
| `2` | 0.5rem (~8px) |
| `3` | 1rem (~16px) |
| `4` | 1.5rem (~24px) |
| `5` | 3rem (~48px) |
| `auto` | otomatis |

```html
<!-- Margin -->
<div class="mb-3">Bottom margin 1rem</div>
<div class="mt-4">Top margin 1.5rem</div>
<div class="mx-auto">Centered horizontal</div>
<div class="my-5">Top & bottom margin 3rem</div>
<div class="ms-2">Margin start (kiri) 0.5rem</div>

<!-- Padding -->
<div class="p-3">Padding semua sisi 1rem</div>
<div class="pt-2">Padding top 0.5rem</div>
<div class="px-4">Padding kiri-kanan 1.5rem</div>
<div class="pb-5">Padding bottom 3rem</div>
<div class="pe-1">Padding end (kanan) 0.25rem</div>

<!-- Responsive spacing -->
<div class="p-3 p-md-5 p-lg-4">
  Padding 1rem di HP, 3rem di tablet, 1.5rem di laptop
</div>
<div class="mt-0 mt-md-3">
  Tanpa margin atas di HP, margin 1rem di tablet+
</div>
```

## Analogi
Spacing utilities = **alat ukur jarak antar ruangan dan furnitur**:
- **Margin (m-*)** = **jarak antara furnitur dengan dinding** — misal: sofa (elemen) berjarak 1 meter (`m-3`) dari dinding
- **Padding (p-*)** = **jarak dari dinding ke isi ruangan** — misal: bingkai foto (`p-3`) menyisakan ruang antara pinggiran bingkai dan foto di dalamnya
- **`mx-auto`** = **meja yang dipaksa di tengah ruangan** — margin kiri-kanan otomatis
- **`mt-5`** = **jarak 3 meter dari langit-langit ke lampu gantung**

## Dipakai untuk apa
Memberi jarak antar komponen, memusatkan elemen, membuat section lebih lega, spacing tombol, card, form, dan hampir semua aspek layout.

## Kesalahan umum yang sering terjadi
- Menggunakan `<br>` berkali-kali untuk spasi vertikal — seharusnya `mb-*` atau `my-*`
- Mencampur margin dan padding untuk fungsi yang sama — padding untuk di dalam elemen, margin untuk di luar
- Lupa bahwa `mt-*` tidak bekerja pada elemen inline — perlu `d-block` atau `d-inline-block`
- Menggunakan `mx-auto` tanpa `display: block` dan lebar tertentu

## Koneksi dengan materi sebelumnya
Spacing adalah materi terakhir yang menyatukan semuanya. Jika grid (materi 5-10) adalah denah, typography (materi 11-12) adalah dekorasi dinding, warna (materi 13) adalah cat, maka spacing utilities adalah **jarak antar ruangan dan furnitur** yang membuat rumah terasa lapang dan teratur. Spacing melengkapi gutter (materi 9) yang khusus untuk jarak antar kolom grid.

## Soal latihan & jawaban

**1. Buat div dengan padding 2rem di semua sisi dan margin bottom 1.5rem!**
```html
<div class="p-4 mb-4">Konten</div>
```

**2. Class apa yang digunakan untuk memusatkan elemen block secara horizontal?**
`mx-auto` — margin kiri dan kanan diatur otomatis.

**3. Dalam analogi rumah, bedakan `p-3` dan `m-3`!**
`p-3` adalah jarak antara dinding dengan isi ruangan (padding). `m-3` adalah jarak antara furnitur dengan dinding (margin).
