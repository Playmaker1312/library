# Apa itu Bootstrap & Mengapa Digunakan

## Penjelasan
Bootstrap adalah framework CSS open-source yang dikembangkan oleh Twitter untuk mempermudah pembuatan tampilan website responsif dan mobile-first. Menyediakan kumpulan komponen siap pakai seperti grid, tombol, form, navbar, dan utilitas styling.

## Fungsi
- Mempercepat pengembangan front-end tanpa menulis CSS dari nol
- Menjamin konsistensi tampilan antar browser
- Membantu menciptakan layout responsif dengan mudah
- Menyediakan komponen UI yang sudah teruji

## Cara Pengimplementasian
Bootstrap bisa dipasang melalui CDN (langsung di HTML) atau via package manager (npm) untuk project yang lebih kompleks.

```html
<!-- CDN -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3/dist/css/bootstrap.min.css" rel="stylesheet">
```

## Analogi
Bayangkan Bootstrap sebagai **kotak alat tukang bangunan** yang sudah berisi palu, gergaji, obeng, dan meteran. Tanpa Bootstrap, kamu harus membuat sendiri setiap alat dari bahan mentah — butuh waktu lama. Dengan Bootstrap, kamu tinggal ambil alat yang sudah jadi dan langsung pakai. Tukang bangunan bisa langsung fokus mendesain rumah, bukan membuat alat.

## Dipakai untuk apa
Bootstrap dipakai untuk membangun antarmuka website dengan cepat — mulai dari halaman profil sederhana hingga dashboard aplikasi kompleks. Cocok untuk prototyping maupun production.

## Kesalahan umum yang sering terjadi
- Mencampur Bootstrap 4 dan 5 dalam satu project (class berbeda)
- Tidak menyertakan tag `<meta name="viewport">` sehingga tampilan tidak responsif
- Override CSS tanpa memahami spesifisitas Bootstrap
- Menganggap semua website harus menggunakan Bootstrap

## Koneksi dengan materi sebelumnya
Ini adalah fondasi awal. Materi-materi selanjutnya akan membahas satu per satu "alat" dalam kotak alat Bootstrap: container (pondasi), row (lantai), col (ruangan), grid (denah), typography (dekorasi), dan seterusnya.

## Soal latihan & jawaban

**1. Apa perbedaan utama Bootstrap 4 dengan Bootstrap 5?**
Bootstrap 5 menggunakan vanilla JavaScript (tidak perlu jQuery), sedangkan Bootstrap 4 masih bergantung pada jQuery. Bootstrap 5 juga menghapus dukungan untuk Internet Explorer 10/11.

**2. Sebutkan 3 kelebihan menggunakan Bootstrap dibandingkan CSS murni!**
- Grid system responsif yang siap pakai
- Komponen UI yang konsisten dan teruji
- Dokumentasi lengkap dan komunitas besar

**3. Dalam analogi membangun rumah, apa yang diwakili oleh Bootstrap?**
Kotak alat tukang bangunan yang berisi berbagai alat siap pakai.
