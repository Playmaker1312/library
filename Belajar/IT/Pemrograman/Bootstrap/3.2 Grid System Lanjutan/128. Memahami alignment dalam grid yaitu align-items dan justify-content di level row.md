# Memahami Alignment dalam Grid yaitu Align-items dan Justify-content di Level Row

## Analogi: Perpustakaan Digital

Bayangkan rak buku di perpustakaan digital yang memiliki beberapa baris buku dengan tinggi berbeda. Anda bisa meratakan buku-buku tersebut di bagian atas rak, bawah rak, atau di tengah-tengah. Bootstrap menyediakan class `align-items-*` dan `justify-content-*` di level row untuk mengatur posisi kolom secara vertikal dan horizontal. Ini seperti mengatur bagaimana buku-buku disejajarkan dalam rak, baik secara vertikal (atas-bawah) maupun horizontal (kiri-kanan).

## Penjelasan Detail

Row di Bootstrap menggunakan Flexbox, sehingga semua properti Flexbox alignment dapat digunakan. `align-items-*` mengatur alignment vertikal kolom dalam satu baris: `align-items-start` (ke atas), `align-items-center` (ke tengah), `align-items-end` (ke bawah), dan `align-items-stretch` (default, memenuhi tinggi baris). `justify-content-*` mengatur alignment horizontal: `justify-content-start` (kiri), `justify-content-center` (tengah), `justify-content-end` (kanan), `justify-content-between` (rata kiri-kanan dengan jarak), `justify-content-around` (jarak merata di sekeliling), dan `justify-content-evenly` (jarak benar-benar merata). Class-class ini bisa dikombinasikan dengan breakpoint seperti `align-items-md-center`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Grid Alignment</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Alignment dalam Grid</h1>
        <h5>align-items-center (vertikal tengah)</h5>
        <div class="row align-items-center border mb-4" style="height: 150px;">
            <div class="col"><div class="bg-primary text-white p-2">Kolom 1</div></div>
            <div class="col"><div class="bg-success text-white p-4">Kolom 2 (lebih tinggi)</div></div>
            <div class="col"><div class="bg-warning p-3">Kolom 3</div></div>
        </div>
        <h5>justify-content-center (horizontal tengah)</h5>
        <div class="row justify-content-center border mb-4">
            <div class="col-3"><div class="bg-info p-3">Kolom 1</div></div>
            <div class="col-3"><div class="bg-info p-3">Kolom 2</div></div>
        </div>
        <h5>justify-content-between (kiri dan kanan)</h5>
        <div class="row justify-content-between border mb-4">
            <div class="col-3"><div class="bg-danger text-white p-3">Kiri</div></div>
            <div class="col-3"><div class="bg-danger text-white p-3">Kanan</div></div>
        </div>
        <h5>align-items-end (vertikal bawah)</h5>
        <div class="row align-items-end border" style="height: 120px;">
            <div class="col"><div class="bg-secondary text-white p-2">Bawah 1</div></div>
            <div class="col"><div class="bg-secondary text-white p-2">Bawah 2</div></div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `align-items-*` mengatur alignment vertikal kolom dalam row.
- `justify-content-*` mengatur alignment horizontal kolom dalam row.
- Default `align-items` adalah `stretch` (kolom memenuhi tinggi row).
- Class alignment bisa dikombinasikan dengan breakpoint untuk responsivitas.
