# Praktik Membuat Layout Halaman Nyata Menggunakan Grid System

## Analogi: Perpustakaan Digital

Setelah mempelajari berbagai teknik grid, saatnya merancang halaman perpustakaan digital yang sesungguhnya. Seperti arsitek yang menggambar denah perpustakaan — menentukan di mana pintu masuk, rak buku, area baca, dan meja sirkulasi — kita akan menggunakan grid Bootstrap untuk membuat layout halaman yang lengkap. Halaman ini akan memiliki header, navbar, konten utama, sidebar, dan footer yang semuanya responsif.

## Penjelasan Detail

Layout halaman nyata menggabungkan semua konsep grid yang telah dipelajari: container, row, col dengan berbagai breakpoint, gutter, alignment, dan full-width section. Halaman ini akan meniru struktur perpustakaan digital dengan bagian hero (pengumuman), daftar buku dalam grid, sidebar untuk filter atau kategori, serta footer. Dengan menggunakan class seperti `col-lg-8` untuk konten utama dan `col-lg-4` untuk sidebar di desktop, serta `col-12` untuk stacking di mobile, kita dapat memastikan halaman terlihat baik di semua perangkat. Penggunaan `g-*` untuk jarak dan `row-cols-*` untuk grid buku juga akan diterapkan.

## Poin Penting
- Layout halaman nyata menggabungkan navbar, hero, konten, sidebar, dan footer.
- Gunakan `col-lg-8` dan `col-lg-4` untuk layout utama + sidebar di desktop.
- `row-cols-*` memudahkan pembuatan grid buku yang seragam.
- Pastikan setiap section memiliki padding yang konsisten dengan utilities Bootstrap.
