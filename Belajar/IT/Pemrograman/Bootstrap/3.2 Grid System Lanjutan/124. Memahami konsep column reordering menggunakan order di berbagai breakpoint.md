# Memahami Konsep Column Reordering Menggunakan Order di Berbagai Breakpoint

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan digital yang menampilkan daftar buku: judul, penulis, dan tahun terbit. Di layar lebar, informasi ini ditampilkan dalam satu baris horizontal. Namun di ponsel, Anda mungkin ingin menampilkan judul terlebih dahulu, baru penulis dan tahun di bawahnya. Bootstrap menyediakan class `order-*` untuk mengatur ulang urutan kolom tanpa mengubah struktur HTML, seperti memindahkan kartu katalog di rak tanpa harus mengeluarkan dan memasukkan kembali semua kartu.

## Penjelasan Detail

Class `order-*` pada Bootstrap memanfaatkan CSS `order` property dari Flexbox untuk mengatur urutan visual kolom. Anda bisa menggunakan `order-1` hingga `order-5`, serta `order-first` dan `order-last`. Yang lebih powerful, Anda bisa menggunakan breakpoint seperti `order-md-2` untuk mengatur urutan hanya pada ukuran layar tertentu. Nilai default order adalah 0, sehingga kolom dengan `order-1` akan muncul setelah semua kolom dengan order 0. Fitur ini sangat berguna untuk mobile-first design di mana urutan konten di layar kecil mungkin berbeda dengan di layar besar tanpa menduplikasi HTML.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Column Reordering</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Column Reordering</h1>
        <div class="row">
            <div class="col-12 col-md-4 order-md-2">
                <div class="bg-primary text-white p-3 mb-2">
                    <h4>Sidebar (order-md-2)</h4>
                    <p>Muncul kedua di desktop, pertama di mobile.</p>
                </div>
            </div>
            <div class="col-12 col-md-8 order-md-1">
                <div class="bg-success text-white p-3 mb-2">
                    <h4>Konten Utama (order-md-1)</h4>
                    <p>Muncul pertama di desktop, kedua di mobile.</p>
                </div>
            </div>
        </div>
        <h4 class="mt-4">Contoh dengan order-first dan order-last</h4>
        <div class="row">
            <div class="col bg-info p-3">Kolom 1 (order 0)</div>
            <div class="col bg-warning p-3 order-last">Kolom 2 (order-last)</div>
            <div class="col bg-info p-3">Kolom 3 (order 0)</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan `order-{breakpoint}-{nilai}` untuk mengatur urutan per breakpoint.
- `order-first` setara dengan `order: -1`, `order-last` setara dengan `order: 6`.
- Default order semua kolom adalah 0 (urutan sesuai HTML).
- Sangat berguna untuk mengubah prioritas konten antara mobile dan desktop.
