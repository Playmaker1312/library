# Membuat Layout Kompleks dengan Kombinasi Berbagai Breakpoint

## Analogi: Perpustakaan Digital

Perpustakaan digital perlu menampilkan koleksi bukunya secara optimal di berbagai perangkat. Di layar lebar (desktop), mungkin ditampilkan 4 kolom buku bersebelahan. Di tablet, 2 kolom. Di ponsel, hanya 1 kolom. Layout ini bisa diatur dengan menggunakan kombinasi breakpoint pada class grid Bootstrap. Anda dapat menentukan berapa lebar kolom pada setiap ukuran layar, sehingga tata letak selalu terlihat sempurna tanpa harus menulis CSS media queries manual.

## Penjelasan Detail

Bootstrap menyediakan 6 breakpoint: xs (<576px, default), sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px), dan xxl (≥1400px). Dalam grid system, Anda bisa mengombinasikan class seperti `col-12 col-sm-6 col-md-4 col-lg-3` untuk membuat kolom yang lebarnya berubah sesuai layar. Angka di belakang breakpoint menunjukkan jumlah unit kolom (dari 12). Misalnya `col-lg-3` berarti kolom selebar 3 unit (25%) pada layar lg ke atas. Layout kompleks bisa dibuat dengan memberikan ukuran berbeda pada setiap kolom di breakpoint berbeda, seperti kolom sidebar yang berubah ukuran relatif terhadap konten utama saat layar berubah.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Layout Kompleks</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Layout dengan Multi Breakpoint</h1>
        <div class="row">
            <div class="col-12 col-md-8">
                <div class="bg-primary text-white p-4 mb-2">
                    <h3>Konten Utama</h3>
                    <p>col-12 col-md-8 — Lebar penuh di mobile, 8 unit di desktop.</p>
                </div>
            </div>
            <div class="col-6 col-md-4">
                <div class="bg-success text-white p-4 mb-2">
                    <h3>Sidebar</h3>
                    <p>col-6 col-md-4 — Setengah lebar di mobile.</p>
                </div>
            </div>
            <div class="col-6 col-md-4 col-lg-3">
                <div class="bg-warning p-4 mb-2">
                    <h3>Widget 1</h3>
                    <p>Kecil di lg, sedang di md.</p>
                </div>
            </div>
            <div class="col-6 col-md-4 col-lg-3">
                <div class="bg-info p-4 mb-2">
                    <h3>Widget 2</h3>
                </div>
            </div>
            <div class="col-6 col-md-4 col-lg-3">
                <div class="bg-secondary text-white p-4 mb-2">
                    <h3>Widget 3</h3>
                </div>
            </div>
            <div class="col-12 col-lg-3">
                <div class="bg-dark text-white p-4 mb-2">
                    <h3>Widget 4</h3>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Kombinasikan class `col-{breakpoint}-{size}` untuk responsivitas multi-level.
- Urutan breakpoint dalam class tidak penting, yang penting adalah nilai minimumnya.
- Gunakan `col-12` sebagai default mobile sebelum breakpoint yang lebih besar.
- Layout kompleks membutuhkan perencanaan bagaimana kolom berperilaku di setiap breakpoint.
