# Membangun Form Wizard atau Multi-Step Form Menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Multi-step form adalah seperti proses peminjaman buku di perpustakaan yang terdiri dari beberapa langkah: mencari buku di katalog, mengisi formulir peminjaman, verifikasi anggota, dan konfirmasi. Setiap langkah ditampilkan satu per satu dengan indikator kemajuan, sehingga pemustaka tidak kewalahan dengan semua formulir sekaligus. Bootstrap menyediakan komponen progress bar, tab, dan button untuk membangun wizard yang intuitif.

## Penjelasan Detail

Form wizard memecah form panjang menjadi langkah-langkah kecil, masing-masing dalam satu card atau panel. Gunakan progress bar Bootstrap untuk menunjukkan kemajuan, tombol "Previous" dan "Next" untuk navigasi, dan validasi form per langkah sebelum melanjutkan. Setiap langkah bisa berupa komponen collapsible atau tab. JavaScript diperlukan untuk mengontrol tampilan langkah aktif, memvalidasi input, dan mengupdate progress bar. Simpan data setiap langkah dalam objek JavaScript untuk dikirim ke server di langkah terakhir.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Form Wizard Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    .step { display: none; }
    .step.active { display: block; }
    .step-indicator { display: flex; justify-content: center; gap: 2rem; margin-bottom: 2rem; }
    .step-indicator .dot { width: 36px; height: 36px; border-radius: 50%; background: #dee2e6; display: flex; align-items: center; justify-content: center; font-weight: bold; color: #6c757d; }
    .step-indicator .dot.active { background: #0d6efd; color: white; }
    .step-indicator .dot.completed { background: #198754; color: white; }
  </style>
</head>
<body>
  <div class="container my-5">
    <h2 class="text-center mb-4">Pendaftaran Akun</h2>

    <!-- Step Indicator -->
    <div class="step-indicator">
      <div class="dot active" id="step1-indicator">1</div>
      <div class="dot" id="step2-indicator">2</div>
      <div class="dot" id="step3-indicator">3</div>
    </div>

    <!-- Progress Bar -->
    <div class="progress mb-4" style="height: 8px;">
      <div class="progress-bar" id="progressBar" style="width: 33%"></div>
    </div>

    <!-- Step 1 -->
    <div class="step active" id="step1">
      <div class="card">
        <div class="card-header"><h5 class="mb-0">Informasi Akun</h5></div>
        <div class="card-body">
          <div class="mb-3">
            <label class="form-label">Nama Lengkap</label>
            <input type="text" class="form-control" id="fullName" required>
          </div>
          <div class="mb-3">
            <label class="form-label">Email</label>
            <input type="email" class="form-control" id="email" required>
          </div>
          <div class="mb-3">
            <label class="form-label">Password</label>
            <input type="password" class="form-control" id="password" required>
          </div>
        </div>
      </div>
    </div>

    <!-- Step 2 -->
    <div class="step" id="step2">
      <div class="card">
        <div class="card-header"><h5 class="mb-0">Informasi Profil</h5></div>
        <div class="card-body">
          <div class="mb-3">
            <label class="form-label">Nomor Telepon</label>
            <input type="tel" class="form-control" id="phone">
          </div>
          <div class="mb-3">
            <label class="form-label">Alamat</label>
            <textarea class="form-control" id="address" rows="2"></textarea>
          </div>
          <div class="mb-3">
            <label class="form-label">Tanggal Lahir</label>
            <input type="date" class="form-control" id="birthdate">
          </div>
        </div>
      </div>
    </div>

    <!-- Step 3 -->
    <div class="step" id="step3">
      <div class="card">
        <div class="card-header"><h5 class="mb-0">Konfirmasi & Submit</h5></div>
        <div class="card-body">
          <div class="mb-3">
            <div class="form-check">
              <input class="form-check-input" type="checkbox" id="agreement" required>
              <label class="form-check-label" for="agreement">Saya setuju dengan syarat dan ketentuan</label>
            </div>
          </div>
          <div class="mb-3">
            <div class="form-check">
              <input class="form-check-input" type="checkbox" id="newsletter">
              <label class="form-check-label" for="newsletter">Langganan newsletter</label>
            </div>
          </div>
          <div class="alert alert-info">
            Pastikan semua data yang Anda masukkan sudah benar sebelum menekan tombol Submit.
          </div>
        </div>
      </div>
    </div>

    <!-- Navigation Buttons -->
    <div class="d-flex justify-content-between mt-3">
      <button class="btn btn-secondary" id="prevBtn" onclick="changeStep(-1)" disabled>Previous</button>
      <button class="btn btn-primary" id="nextBtn" onclick="changeStep(1)">Next</button>
    </div>
  </div>

  <script>
    let currentStep = 1;
    const totalSteps = 3;

    function changeStep(direction) {
      const newStep = currentStep + direction;
      if (newStep < 1 || newStep > totalSteps) return;

      document.getElementById(`step${currentStep}`).classList.remove('active');
      document.getElementById(`step${currentStep}-indicator`).classList.remove('active');
      if (direction === 1) {
        document.getElementById(`step${currentStep}-indicator`).classList.add('completed');
      }

      currentStep = newStep;
      document.getElementById(`step${currentStep}`).classList.add('active');
      document.getElementById(`step${currentStep}-indicator`).classList.add('active');

      document.getElementById('progressBar').style.width = `${(currentStep / totalSteps) * 100}%`;
      document.getElementById('prevBtn').disabled = currentStep === 1;
      document.getElementById('nextBtn').textContent = currentStep === totalSteps ? 'Submit' : 'Next';
    }
  </script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Progress bar dan indikator langkah membantu pengguna melihat kemajuan dan posisi mereka dalam wizard.
- JavaScript sederhana dapat mengontrol navigasi antar langkah, mengupdate progress, dan memvalidasi input.
- Simpan data antar langkah dalam variabel JavaScript untuk dikirim ke server di langkah terakhir.
