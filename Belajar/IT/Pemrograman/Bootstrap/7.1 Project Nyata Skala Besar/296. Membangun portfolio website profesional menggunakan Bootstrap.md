# Membangun Portfolio Website Profesional Menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Portfolio website adalah seperti katalog pribadi seorang penulis di perpustakaan—berisi daftar karya terbaik, biografi singkat, dan testimonial dari pembaca. Tujuannya adalah meyakinkan pengunjung bahwa penulis tersebut kompeten dan layak diajak bekerja sama. Bootstrap membantu menyusun katalog ini dengan tata letak yang bersih, profesional, dan responsif di semua perangkat.

## Penjelasan Detail

Portfolio website profesional biasanya memiliki halaman utama dengan hero section yang memorable, tentang saya, galeri karya, layanan, testimonial, dan kontak. Gunakan navbar Bootstrap yang elegan dengan link smooth-scroll ke setiap seksi. Hero section bisa berisi foto profil, nama, dan tagline. Galeri karya menggunakan card grid dengan efek hover dan modal Bootstrap untuk menampilkan detail proyek. Bagian tentang saya menggunakan layout dua kolom (foto di kiri, teks di kanan). Gunakan progress bar untuk menampilkan skill. Testimonial menggunakan carousel. Pastikan desain minimalis dengan whitespace yang cukup.
