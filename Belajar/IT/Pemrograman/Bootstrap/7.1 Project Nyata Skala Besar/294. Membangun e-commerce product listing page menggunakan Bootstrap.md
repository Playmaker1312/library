# Membangun E-Commerce Product Listing Page Menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Halaman daftar produk e-commerce seperti rak buku di perpustakaan yang menampilkan sampul buku, judul, penulis, dan rating. Pengunjung bisa menyortir berdasarkan genre, mencari judul tertentu, atau memfilter berdasarkan tahun terbit. Bootstrap menyediakan sistem grid untuk menata produk-produk dalam baris dan kolom yang rapi, serta komponen card untuk menampilkan informasi setiap produk secara konsisten.

## Penjelasan Detail

Product listing page membutuhkan tata letak yang menampilkan banyak produk secara efisien. Gunakan card Bootstrap dengan gambar produk di atas, judul, harga, rating, dan tombol "Add to Cart". Atur produk dalam grid responsif—4 kolom di desktop, 2 kolom di tablet, 1 kolom di mobile menggunakan class col-lg-3 col-md-6 col-12. Tambahkan sidebar filter dengan accordion atau offcanvas untuk kategori, rentang harga, dan rating. Sertakan juga fitur sorting (dropdown) dan pagination (pagination Bootstrap) untuk navigasi halaman. Gunakan badge untuk menandai diskon atau produk baru.

- Kombinasi badge, pagination, dan dropdown sorting melengkapi fungsionalitas e-commerce.
