# Membangun Responsive Email Template Menggunakan Prinsip Bootstrap

## Analogi: Perpustakaan Digital

Responsive email template adalah seperti surat edaran perpustakaan yang harus terbaca dengan baik baik dicetak di kertas A4 maupun dilihat di ponsel. Isi surat—judul, paragraf, gambar, dan tombol—harus tetap rapi dan mudah dibaca di berbagai ukuran kertas. Prinsip grid dan komponen Bootstrap menginspirasi teknik membangun email yang responsif menggunakan tabel HTML dan inline CSS.

## Penjelasan Detail

Email template memiliki keterbatasan: banyak klien email tidak mendukung CSS modern atau framework JavaScript. Oleh karena itu, pembuatan email responsive menggunakan tabel HTML dengan inline CSS, mengadaptasi prinsip grid Bootstrap seperti kolom yang membungkus pada layar kecil. Gunakan media query dalam tag style untuk membuat layout responsif. Komponen Bootstrap seperti button, alert, dan card bisa ditiru dengan inline CSS. Struktur email umumnya terdiri dari header (logo), hero, konten utama, tombol CTA, dan footer. Uji email di berbagai klien seperti Gmail, Outlook, dan Apple Mail.

## Poin Penting
- Email responsive menggunakan tabel HTML dan inline CSS karena keterbatasan dukungan CSS di klien email.
- Prinsip grid Bootstrap diadaptasi dengan tabel bersarang dan media query untuk layout stack pada mobile.
- Tombol, card, dan komponen lain harus menggunakan inline CSS karena banyak klien email menghapus tag style.
