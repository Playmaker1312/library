# Membangun Halaman Login dan Register yang Profesional Menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Halaman login dan register adalah seperti meja keanggotaan di perpustakaan. Pengunjung baru perlu mendaftar dengan mengisi data diri (register), sementara anggota yang sudah terdaftar cukup menunjukkan kartu anggota (login). Kedua proses ini harus sederhana, aman, dan cepat. Bootstrap menyediakan komponen form, card, alert, dan button untuk membangun halaman autentikasi yang profesional.

## Penjelasan Detail

Halaman login dan register sebaiknya memiliki desain minimalis dengan fokus pada form. Gunakan card Bootstrap yang ditempatkan di tengah halaman menggunakan flexbox alignment (min-height 100vh, justify-content-center, align-items-center). Sertakan logo atau brand di bagian atas card. Form login cukup dengan email dan password, sedangkan register membutuhkan nama, email, password, dan konfirmasi password. Tambahkan link "Lupa Password?" dan opsi "Ingat Saya" (checkbox). Validasi client-side menggunakan class was-validated Bootstrap. Untuk keamanan, form harus menggunakan metode POST dan CSRF protection di sisi server.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Login - Aplikasi</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    body { background: #f0f2f5; }
    .auth-container { min-height: 100vh; display: flex; align-items: center; justify-content: center; }
    .auth-card { max-width: 420px; width: 100%; }
  </style>
</head>
<body>
  <div class="auth-container">
    <div class="auth-card">
      <div class="card shadow">
        <div class="card-body p-4">
          <!-- Logo & Title -->
          <div class="text-center mb-4">
            <h3 class="fw-bold">AplikasiKu</h3>
            <p class="text-muted">Masuk ke akun Anda</p>
          </div>

          <!-- Tab Login/Register -->
          <ul class="nav nav-pills nav-justified mb-4" role="tablist">
            <li class="nav-item"><button class="nav-link active" data-bs-toggle="tab" data-bs-target="#loginTab">Login</button></li>
            <li class="nav-item"><button class="nav-link" data-bs-toggle="tab" data-bs-target="#registerTab">Register</button></li>
          </ul>

          <div class="tab-content">
            <!-- Login Form -->
            <div class="tab-pane fade show active" id="loginTab">
              <form class="needs-validation" novalidate>
                <div class="mb-3">
                  <label class="form-label">Email</label>
                  <input type="email" class="form-control" placeholder="nama@email.com" required>
                  <div class="invalid-feedback">Masukkan email yang valid.</div>
                </div>
                <div class="mb-3">
                  <label class="form-label">Password</label>
                  <input type="password" class="form-control" placeholder="Password" required>
                  <div class="invalid-feedback">Password harus diisi.</div>
                </div>
                <div class="mb-3 form-check">
                  <input type="checkbox" class="form-check-input" id="remember">
                  <label class="form-check-label" for="remember">Ingat saya</label>
                </div>
                <button type="submit" class="btn btn-primary w-100 mb-2">Masuk</button>
                <div class="text-center">
                  <a href="#" class="text-decoration-none small">Lupa password?</a>
                </div>
              </form>
            </div>

            <!-- Register Form -->
            <div class="tab-pane fade" id="registerTab">
              <form class="needs-validation" novalidate>
                <div class="mb-3">
                  <label class="form-label">Nama Lengkap</label>
                  <input type="text" class="form-control" placeholder="Nama Anda" required>
                  <div class="invalid-feedback">Nama harus diisi.</div>
                </div>
                <div class="mb-3">
                  <label class="form-label">Email</label>
                  <input type="email" class="form-control" placeholder="nama@email.com" required>
                  <div class="invalid-feedback">Masukkan email yang valid.</div>
                </div>
                <div class="mb-3">
                  <label class="form-label">Password</label>
                  <input type="password" class="form-control" placeholder="Min 6 karakter" minlength="6" required>
                  <div class="invalid-feedback">Password minimal 6 karakter.</div>
                </div>
                <div class="mb-3">
                  <label class="form-label">Konfirmasi Password</label>
                  <input type="password" class="form-control" placeholder="Ulangi password" required>
                  <div class="invalid-feedback">Konfirmasi password harus sama.</div>
                </div>
                <button type="submit" class="btn btn-success w-100">Daftar</button>
              </form>
            </div>
          </div>

          <hr class="my-4">
          <p class="text-center text-muted small mb-0">
            Dengan mendaftar, Anda menyetujui <a href="#">Syarat & Ketentuan</a>
          </p>
        </div>
      </div>
    </div>
  </div>

  <script>
    // Validasi form Bootstrap
    (function() {
      'use strict';
      var forms = document.querySelectorAll('.needs-validation');
      Array.prototype.slice.call(forms).forEach(function(form) {
        form.addEventListener('submit', function(event) {
          if (!form.checkValidity()) {
            event.preventDefault();
            event.stopPropagation();
          }
          form.classList.add('was-validated');
        }, false);
      });
    })();
  </script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Tempatkan form autentikasi di tengah halaman menggunakan flexbox untuk tampilan yang fokus.
- Gunakan tab Bootstrap untuk menggabungkan halaman login dan register dalam satu halaman.
- Validasi form menggunakan class was-validated Bootstrap memberikan feedback real-time ke pengguna.
