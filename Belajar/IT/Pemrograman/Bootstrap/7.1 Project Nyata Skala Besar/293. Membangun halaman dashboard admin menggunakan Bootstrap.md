# Membangun Halaman Dashboard Admin Menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Dashboard admin adalah seperti ruang kontrol perpustakaan digital—layar monitor yang menampilkan jumlah pengunjung, buku paling populer, denda yang tertunda, dan jadwal petugas. Semua informasi penting tersaji dalam satu tampilan dengan grafik dan angka ringkas. Bootstrap membantu menata panel-panel informasi ini dalam grid yang rapi, konsisten, dan responsif untuk petugas perpustakaan.

## Penjelasan Detail

Dashboard admin Bootstrap biasanya terdiri dari sidebar navigasi, topbar, dan area konten utama yang berisi kartu statistik, grafik, dan tabel data. Mulailah dengan layout menggunakan grid Bootstrap—sidebar di kiri (col-md-3 atau col-md-2) dan konten di kanan (col-md-9 atau col-md-10). Gunakan card Bootstrap untuk menampilkan metrik seperti total pengguna, pendapatan, atau pesanan baru. Integrasikan Chart.js untuk grafik garis atau batang. Data tables bisa menggunakan tabel Bootstrap dengan kelas table-striped dan table-hover. Pastikan sidebar bisa diciutkan (collapsible) pada layar kecil menggunakan offcanvas atau collapse Bootstrap.

## Poin Penting
- Gunakan layout sidebar + konten utama dengan grid Bootstrap untuk struktur dashboard yang konsisten.
- Card dengan border warna berbeda membantu membedakan metrik secara visual.
- Integrasi Chart.js mudah dilakukan dalam elemen canvas di dalam card Bootstrap.
