# Membangun Multi-Page Website dengan Navigasi Kompleks Menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Multi-page website dengan navigasi kompleks adalah seperti perpustakaan besar dengan banyak lantai, sayap, dan ruangan khusus. Pengunjung membutuhkan peta navigasi yang jelas—rambu di setiap lorong, denah lantai, dan petunjuk arah—agar tidak tersesat. Bootstrap navbar dengan dropdown, breadcrumb, dan mega menu adalah seperti papan petunjuk dan rambu-rambu yang memandu pengunjung ke tujuan mereka.

## Penjelasan Detail

Navigasi kompleks mencakup menu bertingkat (nested dropdown), mega menu, breadcrumb trail, navigasi tab, dan navbar ganda (topbar + primary navbar). Bootstrap mendukung nesting dropdown tak terbatas, namun praktik terbaik membatasi maksimal 2-3 level. Gunakan navbar-expand-lg untuk membuat navbar horizontal di desktop dan hamburger menu di mobile. Mega menu bisa dibuat dengan dropdown yang berisi grid dan card untuk menampilkan banyak link dalam kategori. Breadcrumb membantu pengguna mengetahui posisi mereka dalam hierarki situs. Sertakan juga active state pada link berdasarkan halaman aktif.

## Poin Penting
- Gunakan navbar dengan dropdown bertingkat untuk navigasi utama dan topbar terpisah untuk informasi sekunder.
- Mega menu memungkinkan navigasi kompleks dengan banyak link dalam satu dropdown menggunakan grid.
- Breadcrumb dan tab navigation membantu pengguna memahami posisi dan berpindah antar halaman.
