# Memahami sistem dark mode Bootstrap 5.3 secara mendalam

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki dua mode tampilan: siang (latar putih, teks hitam) dan malam (latar gelap, teks terang). Pengunjung bisa memilih mode sesuai preferensi atau mengikuti pengaturan sistem operasi. Bootstrap 5.3 menyediakan sistem dark mode built-in yang berfungsi persis seperti saklar tema global.

## Penjelasan Detail

Bootstrap 5.3 memperkenalkan dukungan dark mode resmi melalui CSS custom properties. Alih-alih mengandalkan sepenuhnya pada Sass variables, Bootstrap kini mendefinisikan warna komponen sebagai CSS custom properties di `:root` dan `[data-bs-theme="dark"]`. Setiap komponen Bootstrap secara otomatis menyesuaikan dengan tema aktif. Sistem ini memungkinkan perpindahan tema tanpa rekompilasi Sass. Bootstrap menggunakan `color-scheme` CSS property untuk memberi tahu browser tentang tema yang didukung. Dark mode Bootstrap tidak hanya mengubah warna latar, tapi juga menyesuaikan shadow, border, dan warna teks secara holistik — mempertahankan kontras yang memadai.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dark Mode Bootstrap 5.3</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    body { transition: background-color 0.3s, color 0.3s; }
    .theme-switcher {
      position: fixed;
      top: 1rem;
      right: 1rem;
      z-index: 1060;
    }
    .component-demo > * { margin-bottom: 0.75rem; }
  </style>
</head>
<body>
  <div class="theme-switcher">
    <div class="btn-group btn-group-sm">
      <button class="btn btn-outline-secondary" onclick="setTheme('light')">Light</button>
      <button class="btn btn-outline-secondary" onclick="setTheme('dark')">Dark</button>
      <button class="btn btn-outline-secondary" onclick="setTheme('auto')">Auto</button>
    </div>
  </div>

  <div class="container py-5">
    <h1 class="mb-4">Dark Mode Bootstrap 5.3</h1>

    <div class="component-demo">
      <!-- Cards -->
      <div class="row g-3">
        <div class="col-md-4">
          <div class="card">
            <div class="card-body">
              <h5 class="card-title">Card Title</h5>
              <p class="card-text">Card content yang menyesuaikan tema.</p>
              <button class="btn btn-primary">Tombol Primary</button>
            </div>
          </div>
        </div>
        <div class="col-md-4">
          <div class="card">
            <div class="card-body">
              <h5 class="card-title">Alert Demo</h5>
              <div class="alert alert-success">Sukses: Data tersimpan.</div>
              <div class="alert alert-warning">Warning: Periksa kembali.</div>
              <div class="alert alert-danger">Error: Gagal menyimpan.</div>
            </div>
          </div>
        </div>
        <div class="col-md-4">
          <div class="card">
            <div class="card-body">
              <h5 class="card-title">Form Demo</h5>
              <input type="text" class="form-control mb-2" placeholder="Input text">
              <select class="form-select mb-2"><option>Pilih opsi</option></select>
              <div class="form-check"><input class="form-check-input" type="checkbox"><label class="form-check-label">Checkbox</label></div>
            </div>
          </div>
        </div>
      </div>

      <!-- Table -->
      <table class="table">
        <thead><tr><th>#</th><th>Nama</th><th>Status</th></tr></thead>
        <tbody>
          <tr><td>1</td><td>Buku A</td><td><span class="badge bg-success">Aktif</span></td></tr>
          <tr><td>2</td><td>Buku B</td><td><span class="badge bg-secondary">Nonaktif</span></td></tr>
        </tbody>
      </table>

      <!-- Navs -->
      <ul class="nav nav-tabs">
        <li class="nav-item"><a class="nav-link active" href="#">Tab 1</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Tab 2</a></li>
        <li class="nav-item"><a class="nav-link" href="#">Tab 3</a></li>
      </ul>
    </div>
  </div>

  <script>
    function setTheme(theme) {
      const html = document.documentElement;
      if (theme === 'auto') {
        html.removeAttribute('data-bs-theme');
      } else {
        html.setAttribute('data-bs-theme', theme);
      }
    }

    // Deteksi preferensi sistem
    if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
      document.documentElement.setAttribute('data-bs-theme', 'dark');
    }
  </script>
</body>
</html>
```

## Poin Penting
- Bootstrap 5.3 menggunakan CSS custom properties dan `data-bs-theme` attribute untuk dark mode
- Dark mode mengubah warna latar, teks, shadow, dan border secara holistik
- Mode "auto" mengikuti preferensi sistem operasi via `prefers-color-scheme`
- Semua komponen Bootstrap secara otomatis kompatibel tanpa perlu kustomisasi tambahan
