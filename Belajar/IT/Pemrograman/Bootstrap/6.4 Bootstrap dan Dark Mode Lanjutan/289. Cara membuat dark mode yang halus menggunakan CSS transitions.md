# Cara membuat dark mode yang halus menggunakan CSS transitions

## Analogi: Perpustakaan Digital

Saat pengunjung menekan tombol mode gelap, perpustakaan tidak berubah secara instan — lampu meredup perlahan, latar berubah gradien, dan teks beradaptasi dengan lembut dalam sepersekian detik. CSS transitions menciptakan efek peralihan yang halus dan nyaman dipandang.

## Penjelasan Detail

CSS transitions memungkinkan perubahan properti CSS terjadi secara gradual, bukan instan. Untuk dark mode, terapkan `transition` pada properti yang berubah: `background-color`, `color`, `border-color`, `box-shadow`, dan `fill` (untuk SVG). Transisi yang baik berdurasi 0.3 hingga 0.5 detik dengan timing function `ease` atau `ease-in-out`. Jangan mentransisikan `all` karena bisa menyebabkan performa buruk — pilih properti spesifik. Untuk performa optimal, preferensikan properti yang hanya memicu compositing (transform, opacity) daripada layout atau paint. Gunakan `will-change` untuk properti yang sering berubah. Pastikan transisi juga halus di komponen kustom dengan CSS custom properties.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Smooth Dark Mode</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    /* Terapkan transisi ke properti yang berubah */
    :root {
      --transition-duration: 0.35s;
    }

    *,
    *::before,
    *::after {
      transition:
        background-color var(--transition-duration) ease,
        color var(--transition-duration) ease,
        border-color var(--transition-duration) ease,
        box-shadow var(--transition-duration) ease,
        fill var(--transition-duration) ease;
    }

    /* Jangan transisikan semua properti untuk performa */
    .no-transition * {
      transition: none !important;
    }

    body {
      min-height: 100vh;
    }

    .theme-toggle-btn {
      position: fixed;
      bottom: 1.5rem;
      right: 1.5rem;
      z-index: 1050;
      width: 56px;
      height: 56px;
      border-radius: 50%;
      border: none;
      cursor: pointer;
      display: flex;
      align-items: center;
      justify-content: center;
      font-size: 1.5rem;
      background: var(--bs-primary);
      color: white;
      box-shadow: 0 4px 20px rgba(0,0,0,0.15);
      transition: transform 0.3s cubic-bezier(0.34, 1.56, 0.64, 1), background 0.35s ease;
    }

    .theme-toggle-btn:hover {
      transform: scale(1.1) rotate(15deg);
    }

    .theme-toggle-btn:active {
      transform: scale(0.9);
    }

    /* Ikon berotasi saat berganti */
    .theme-toggle-btn .icon {
      display: inline-block;
      transition: transform 0.5s cubic-bezier(0.34, 1.56, 0.64, 1);
    }

    .theme-toggle-btn .icon.rotate {
      transform: rotate(360deg);
    }

    /* Card dan komponen kustom */
    .card, .alert, .btn, .form-control, .form-select, .table, .navbar {
      transition:
        background-color 0.35s ease,
        color 0.35s ease,
        border-color 0.35s ease,
        box-shadow 0.35s ease;
    }
  </style>
</head>
<body>
  <nav class="navbar navbar-expand-lg navbar-light bg-light mb-4">
    <div class="container"><a class="navbar-brand fw-bold" href="#">Smooth Dark Mode</a></div>
  </nav>

  <div class="container">
    <div class="row g-3 mb-4">
      <div class="col-md-4">
        <div class="card"><div class="card-body">
          <h5>Card 1</h5>
          <p>Card dengan transisi halus saat tema berubah.</p>
          <button class="btn btn-primary">Primary</button>
        </div></div>
      </div>
      <div class="col-md-4">
        <div class="card"><div class="card-body">
          <h5>Card 2</h5>
          <div class="alert alert-success mb-0">Alert sukses!</div>
        </div></div>
      </div>
      <div class="col-md-4">
        <div class="card"><div class="card-body">
          <h5>Form</h5>
          <input class="form-control mb-2" placeholder="Input...">
          <select class="form-select"><option>Option</option></select>
        </div></div>
      </div>
    </div>

    <table class="table">
      <thead><tr><th>Buku</th><th>Status</th><th>Aksi</th></tr></thead>
      <tbody>
        <tr><td>Bootstrap 5</td><td><span class="badge bg-success">Tersedia</span></td><td><button class="btn btn-sm btn-outline-primary">Pinjam</button></td></tr>
        <tr><td>CSS Modern</td><td><span class="badge bg-warning text-dark">Dipinjam</span></td><td><button class="btn btn-sm btn-outline-secondary">Tunggu</button></td></tr>
      </tbody>
    </table>
  </div>

  <button class="theme-toggle-btn" id="toggleBtn" aria-label="Toggle theme">
    <span class="icon" id="toggleIcon">☀️</span>
  </button>

  <script>
    const html = document.documentElement;
    const toggleBtn = document.getElementById('toggleBtn');
    const toggleIcon = document.getElementById('toggleIcon');

    // Set initial theme
    if (localStorage.getItem('theme') === 'dark' ||
        (!localStorage.getItem('theme') && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
      html.setAttribute('data-bs-theme', 'dark');
      toggleIcon.textContent = '🌙';
    }

    toggleBtn.addEventListener('click', () => {
      // Animasi ikon
      toggleIcon.classList.add('rotate');
      setTimeout(() => toggleIcon.classList.remove('rotate'), 500);

      const isDark = html.getAttribute('data-bs-theme') === 'dark';
      if (isDark) {
        html.removeAttribute('data-bs-theme');
        localStorage.setItem('theme', 'light');
        toggleIcon.textContent = '☀️';
      } else {
        html.setAttribute('data-bs-theme', 'dark');
        localStorage.setItem('theme', 'dark');
        toggleIcon.textContent = '🌙';
      }
    });
  </script>
</body>
</html>
```

## Poin Penting
- Terapkan `transition` pada properti spesifik (`background-color`, `color`, `border-color`, `box-shadow`) bukan `all`
- Durasi 0.3–0.5 detik dengan `ease` atau `cubic-bezier` memberikan transisi yang natural
- Hindari mentransisikan properti yang memicu layout/repaint mahal (seperti `width`, `height`, `margin`)
- Tambahkan efek rotasi ikon untuk feedback visual yang lebih engaging saat toggle
