# Cara mengimplementasikan toggle dark mode dan light mode dengan JavaScript

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki tombol saklar di pojok layar — lampu icon matahari untuk mode terang, bulan untuk mode gelap. Saat diklik, seluruh tampilan berubah dalam sekejap. Toggle dark mode adalah saklar yang dengan JavaScript mengubah tema dari light ke dark dan sebaliknya secara instan.

## Penjelasan Detail

Implementasi toggle dark mode dengan JavaScript cukup sederhana: ubah nilai `data-bs-theme` attribute di elemen `<html>` antara `"light"` dan `"dark"`. Bootstrap 5.3 akan merespon secara otomatis. Buat tombol toggle dengan ikon yang berubah (matahari/bulan) sesuai tema aktif. Gunakan event listener `click` untuk toggle. Untuk UX yang lebih baik, tambahkan transisi CSS yang halus, animasi ikon (rotasi/fade), dan tooltip yang menjelaskan aksi. Pastikan toggle juga bisa diakses via keyboard. Untuk aplikasi yang lebih kompleks, gunakan state management (global state atau context) agar semua komponen tahu tema yang aktif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dark Mode Toggle</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    * { transition: background-color 0.3s ease, color 0.3s ease, border-color 0.3s ease; }
    .theme-toggle {
      position: fixed;
      bottom: 1.5rem;
      right: 1.5rem;
      z-index: 1050;
      width: 52px;
      height: 52px;
      border-radius: 50%;
      border: none;
      background: var(--bs-primary);
      color: white;
      font-size: 1.5rem;
      cursor: pointer;
      box-shadow: 0 4px 15px rgba(0,0,0,0.2);
      display: flex;
      align-items: center;
      justify-content: center;
      transition: transform 0.3s, background 0.3s;
    }
    .theme-toggle:hover { transform: scale(1.1); }
    .theme-toggle .icon { line-height: 1; }
    .theme-toggle .icon-sun { display: inline-block; }
    .theme-toggle .icon-moon { display: none; }
    [data-bs-theme="dark"] .theme-toggle .icon-sun { display: none; }
    [data-bs-theme="dark"] .theme-toggle .icon-moon { display: inline-block; }
    [data-bs-theme="dark"] .theme-toggle { background: #ffc107; color: #212529; }
  </style>
</head>
<body>
  <div class="container py-5">
    <h1 class="mb-4">Toggle Dark Mode</h1>
    <p class="lead">Klik tombol saklar di pojok kanan bawah untuk mengganti tema.</p>
    <div class="row g-3">
      <div class="col-md-6">
        <div class="card"><div class="card-body">
          <h5>Komponen Card</h5>
          <p>Card ini otomatis berubah tema saat toggle diklik.</p>
          <button class="btn btn-primary">Primary</button>
          <button class="btn btn-outline-secondary">Secondary</button>
        </div></div>
      </div>
      <div class="col-md-6">
        <div class="card"><div class="card-body">
          <h5>Form Elements</h5>
          <input class="form-control mb-2" placeholder="Input...">
          <select class="form-select mb-2"><option>Option 1</option></select>
          <div class="form-check"><input class="form-check-input" type="checkbox"><label class="form-check-label">Check me</label></div>
        </div></div>
      </div>
    </div>
  </div>

  <button class="theme-toggle" id="themeToggle" aria-label="Toggle theme">
    <span class="icon icon-sun">☀️</span>
    <span class="icon icon-moon">🌙</span>
  </button>

  <script>
    const toggleBtn = document.getElementById('themeToggle');
    const html = document.documentElement;

    // Set initial theme dari localStorage atau system preference
    const savedTheme = localStorage.getItem('theme');
    if (savedTheme) {
      html.setAttribute('data-bs-theme', savedTheme);
    } else if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
      html.setAttribute('data-bs-theme', 'dark');
    }

    toggleBtn.addEventListener('click', () => {
      const current = html.getAttribute('data-bs-theme');
      const next = current === 'dark' ? 'light' : 'dark';
      html.setAttribute('data-bs-theme', next);
      localStorage.setItem('theme', next);
    });

    // Keyboard accessibility
    toggleBtn.addEventListener('keydown', (e) => {
      if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); toggleBtn.click(); }
    });
  </script>
</body>
</html>
```

## Poin Penting
- Toggle cukup mengubah `data-bs-theme` attribute di `<html>` — Bootstrap menangani sisanya
- Ikon tombol berubah antara matahari (☀️) untuk light dan bulan (🌙) untuk dark
- Simpan preferensi tema di `localStorage` agar bertahan antar kunjungan
- Tambahkan transisi CSS `0.3s ease` untuk perubahan tema yang halus
