# Memastikan semua custom component kompatibel dengan dark mode Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki rak buku kustom yang dibuat sendiri oleh staf. Rak ini harus tetap terlihat bagus baik di mode terang maupun mode gelap — tidak boleh ada tulisan yang hilang atau warna yang bertabrakan. Setiap komponen kustom perlu diuji dan disesuaikan untuk kedua tema.

## Penjelasan Detail

Ketika Anda membuat komponen kustom, komponen tersebut tidak otomatis kompatibel dengan dark mode Bootstrap. Anda harus secara eksplisit mendefinisikan gaya untuk `[data-bs-theme="dark"]`. Strategi terbaik adalah menggunakan CSS custom properties yang nilainya berubah berdasarkan tema. Hindari hardcode warna — gunakan `var(--bs-*)` untuk warna Bootstrap. Jika komponen kustom memiliki warna spesifik, daftarkan CSS custom properties sendiri di `:root` dan `[data-bs-theme="dark"]`. Uji semua state (hover, active, disabled) di kedua tema. Perhatikan juga gambar/ikon — pastikan ada filter atau versi berbeda untuk dark mode jika diperlukan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Custom Component Dark Mode</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    /* Definisikan CSS custom properties untuk komponen kustom */
    :root {
      --custom-card-bg: #ffffff;
      --custom-card-text: #212529;
      --custom-card-border: #dee2e6;
      --custom-card-shadow: 0 2px 8px rgba(0,0,0,0.08);
      --custom-badge-bg: #e9ecef;
      --custom-badge-text: #495057;
      --custom-star-color: #ffc107;
      --custom-star-empty: #dee2e6;
      --custom-avatar-border: #ffffff;
    }

    [data-bs-theme="dark"] {
      --custom-card-bg: #1a1d3e;
      --custom-card-text: #e0e0ff;
      --custom-card-border: #2d2b55;
      --custom-card-shadow: 0 2px 8px rgba(0,0,0,0.3);
      --custom-badge-bg: #2d2b55;
      --custom-badge-text: #a5b4fc;
      --custom-star-color: #fbbf24;
      --custom-star-empty: #374151;
      --custom-avatar-border: #1a1d3e;
    }

    /* Custom card component */
    .c-card {
      background: var(--custom-card-bg);
      color: var(--custom-card-text);
      border: 1px solid var(--custom-card-border);
      border-radius: 0.75rem;
      box-shadow: var(--custom-card-shadow);
      padding: 1.25rem;
      transition: background 0.3s, color 0.3s, border-color 0.3s;
    }

    /* Custom badge */
    .c-badge {
      display: inline-block;
      padding: 0.25rem 0.75rem;
      border-radius: 50rem;
      background: var(--custom-badge-bg);
      color: var(--custom-badge-text);
      font-size: 0.75rem;
      font-weight: 600;
    }

    /* Custom star rating */
    .c-stars {
      color: var(--custom-star-empty);
    }
    .c-stars .filled {
      color: var(--custom-star-color);
    }

    /* Custom avatar */
    .c-avatar {
      width: 40px;
      height: 40px;
      border-radius: 50%;
      border: 2px solid var(--custom-avatar-border);
      object-fit: cover;
      transition: border-color 0.3s;
    }

    /* Custom progress */
    .c-progress {
      height: 6px;
      border-radius: 3px;
      background: var(--custom-star-empty);
      overflow: hidden;
    }
    .c-progress-bar {
      height: 100%;
      background: var(--bs-primary);
      border-radius: 3px;
    }

    body { transition: background-color 0.3s, color 0.3s; }
  </style>
</head>
<body>
  <div class="container py-5">
    <button class="btn btn-outline-secondary mb-4" onclick="toggleDark()">🌙 Toggle Dark Mode</button>

    <div class="c-card mb-3">
      <div class="d-flex align-items-center gap-3 mb-3">
        <img class="c-avatar" src="https://i.pravatar.cc/80?img=3" alt="Avatar">
        <div>
          <h5 class="mb-0">User Profile</h5>
          <div class="c-stars">
            <span class="filled">★</span><span class="filled">★</span><span class="filled">★</span><span class="filled">★</span><span>★</span>
            <small class="text-muted">(4.0)</small>
          </div>
        </div>
      </div>
      <p>Komponen kustom ini menggunakan CSS custom properties yang berubah di dark mode.</p>
      <div class="d-flex gap-2 align-items-center">
        <span class="c-badge">Premium</span>
        <span class="c-badge">Aktif</span>
        <div class="ms-auto small text-muted">Progress: 60%</div>
      </div>
      <div class="c-progress mt-2"><div class="c-progress-bar" style="width: 60%"></div></div>
    </div>

    <div class="c-card">
      <h5>Testing Checklist</h5>
      <ul class="mb-0">
        <li>✅ Latar belakang berubah gelap</li>
        <li>✅ Teks tetap terbaca</li>
        <li>✅ Border dan shadow menyesuaikan</li>
        <li>✅ Avatar border menyatu dengan background</li>
        <li>✅ Star rating tetap kontras</li>
      </ul>
    </div>
  </div>

  <script>
    function toggleDark() {
      const html = document.documentElement;
      if (html.getAttribute('data-bs-theme') === 'dark') {
        html.removeAttribute('data-bs-theme');
      } else {
        html.setAttribute('data-bs-theme', 'dark');
      }
    }
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan CSS custom properties (`var(--custom-*)`) untuk komponen kustom agar mudah di-theming
- Deklarasikan nilai dark mode di `[data-bs-theme="dark"]` selector
- Hindari hardcode warna — gunakan `var(--bs-*)` atau custom properties yang terdefinisi
- Uji semua state (hover, active, disabled) dan elemen (avatar, badge, progress) di kedua tema
