# Cara mendeteksi preferensi sistem operasi menggunakan prefers-color-scheme

## Analogi: Perpustakaan Digital

Perpustakaan digital bisa "membaca" pengaturan perangkat pengunjung — jika laptop sedang dalam mode malam, perpustakaan otomatis menampilkan tema gelap tanpa diminta. prefers-color-scheme adalah sensor yang membaca preferensi tema dari sistem operasi pengguna.

## Penjelasan Detail

`prefers-color-scheme` adalah CSS media query yang mendeteksi apakah sistem operasi pengguna menggunakan tema terang (`light`) atau gelap (`dark`). Bootstrap 5.3 menggunakannya sebagai fallback ketika `data-bs-theme` tidak diset. Anda bisa mengaksesnya dari CSS: `@media (prefers-color-scheme: dark) { ... }` atau dari JavaScript: `window.matchMedia('(prefers-color-scheme: dark)')`. Keuntungannya adalah pengguna tidak perlu memilih tema — aplikasi otomatis menyesuaikan. Dengarkan perubahan preferensi (misal, pengguna mengubah tema OS saat aplikasi sedang terbuka) dengan `matchMedia.addEventListener('change', handler)`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>prefers-color-scheme Detection</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    body { transition: background 0.3s, color 0.3s; }
    /* CSS-only dark mode (tanpa JS) */
    @media (prefers-color-scheme: dark) {
      .system-info { background: rgba(13,110,253,0.15); border-left: 4px solid var(--bs-primary); }
    }
    @media (prefers-color-scheme: light) {
      .system-info { background: rgba(25,135,84,0.1); border-left: 4px solid var(--bs-success); }
    }
    .indicator {
      display: inline-block;
      width: 12px;
      height: 12px;
      border-radius: 50%;
      margin-right: 0.5rem;
    }
    .indicator.light { background: #ffc107; }
    .indicator.dark { background: #6610f2; }
    .indicator.not-supported { background: #dc3545; }
  </style>
</head>
<body>
  <div class="container py-5">
    <h1 class="mb-4">Deteksi prefers-color-scheme</h1>

    <div class="system-info p-3 rounded mb-4">
      <strong>Info:</strong> Panel ini berubah warna berdasarkan preferensi sistem (CSS media query).
    </div>

    <div class="card mb-3">
      <div class="card-body">
        <h5>Status Deteksi (JavaScript)</h5>
        <p id="detectionResult" class="mb-0">Mendeteksi...</p>
      </div>
    </div>

    <div class="card mb-3">
      <div class="card-body">
        <h5>Perubahan Real-time</h5>
        <p id="changeLog" class="mb-0">Ubah tema sistem operasi Anda untuk melihat perubahan real-time.</p>
      </div>
    </div>

    <div class="row g-3">
      <div class="col-md-6">
        <div class="card"><div class="card-body">
          <h6>CSS Menangani Tema</h6>
          <p class="small text-muted">Dengan CSS @media, konten bisa menyesuaikan tanpa JavaScript.</p>
          <div class="alert alert-info">Alert dengan <code>prefers-color-scheme</code></div>
        </div></div>
      </div>
      <div class="col-md-6">
        <div class="card"><div class="card-body">
          <h6>JavaScript Fallback</h6>
          <p class="small text-muted">Gunakan JS untuk fallback atau integrasi dengan Bootstrap dark mode.</p>
          <button class="btn btn-primary" id="detectBtn">Deteksi Sekarang</button>
        </div></div>
      </div>
    </div>
  </div>

  <script>
    const darkModeMedia = window.matchMedia('(prefers-color-scheme: dark)');
    const resultEl = document.getElementById('detectionResult');
    const changeLogEl = document.getElementById('changeLog');

    function updateDetection() {
      const isDark = darkModeMedia.matches;
      const isSupported = darkModeMedia.media !== 'not all';
      const scheme = isDark ? 'dark' : 'light';
      const icon = `<span class="indicator ${scheme}"></span>`;

      if (!isSupported) {
        resultEl.innerHTML = `${icon} prefers-color-scheme <strong>tidak didukung</strong> di browser ini.`;
      } else {
        resultEl.innerHTML = `${icon} Sistem Anda menggunakan tema <strong>${scheme}</strong>.`;
      }

      // Sync dengan Bootstrap
      if (!localStorage.getItem('theme')) {
        document.documentElement.setAttribute('data-bs-theme', scheme);
      }
    }

    // Dengarkan perubahan real-time
    darkModeMedia.addEventListener('change', (e) => {
      const theme = e.matches ? 'dark' : 'light';
      changeLogEl.innerHTML = `⏱ Tema sistem berubah menjadi <strong>${theme}</strong> pada ${new Date().toLocaleTimeString()}.`;
      updateDetection();
    });

    document.getElementById('detectBtn').addEventListener('click', updateDetection);
    updateDetection();
  </script>
</body>
</html>
```

## Poin Penting
- `prefers-color-scheme` mendeteksi tema OS — bisa digunakan di CSS dan JavaScript
- Gunakan `window.matchMedia('(prefers-color-scheme: dark)')` untuk akses JavaScript
- Dengarkan event `change` untuk merespon perubahan tema OS secara real-time
- Kombinasikan dengan localStorage override: sistem sebagai default, localStorage sebagai pilihan pengguna
