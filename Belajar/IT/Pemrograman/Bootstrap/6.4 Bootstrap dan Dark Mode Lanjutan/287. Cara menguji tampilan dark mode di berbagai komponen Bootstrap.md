# Cara menguji tampilan dark mode di berbagai komponen Bootstrap

## Analogi: Perpustakaan Digital

Sebelum meluncurkan mode gelap, staf perpustakaan memeriksa setiap halaman: apakah judul buku terbaca? Apakah tombol pinjam terlihat? Apakah tabel peminjaman kontrasnya cukup? Pengujian dark mode adalah pemeriksaan sistematis untuk memastikan semua komponen berfungsi dan terlihat baik dalam tema gelap.

## Penjelasan Detail

Pengujian dark mode harus mencakup semua komponen Bootstrap yang digunakan dalam aplikasi. Buat halaman test case yang menampilkan grid, cards, forms, tables, alerts, modals, dropdowns, navs, badges, dan komponen lainnya dalam kedua tema. Periksa: (1) kontras warna antara teks dan latar memenuhi standar WCAG AA, (2) tidak ada teks atau ikon yang "hilang" (invisible), (3) gambar dengan background transparan tetap terlihat, (4) shadow dan border memberikan kedalaman yang cukup. Gunakan browser DevTools untuk simulasi, dan alat otomatis seperti Lighthouse atau axe-core untuk audit aksesibilitas. Lakukan juga pengujian di berbagai browser dan perangkat.

```html
    <!-- Test Cards -->
    <div class="test-section">
      <h5>Cards</h5>
      <div class="row g-3">

      </div>
    </div>

    <div class="test-section">

        <div class="col-md-4">
          <div class="input-group"><input class="form-control" placeholder="Search..."><button class="btn btn-primary">Cari</button></div>

        </div>
      </div>
    </div>

    <!-- Test Alerts -->
    <div class="test-section">
      <h5>Alerts</h5>
      <div class="alert alert-primary">Alert Primary — <a href="#" class="alert-link">link example</a></div>

    <!-- Test Table -->

          <tr><td>1</td><td>Buku A</td><td>Programming</td><td><span class="badge bg-success">Aktif</span></td></tr>
          <tr><td>2</td><td>Buku B</td><td>Design</td><td><span class="badge bg-warning text-dark">Pending</span></td></tr>
          <tr class="table-active"><td>3</td><td>Buku C</td><td>Bisnis</td><td><span class="badge bg-secondary">Nonaktif</span></td></tr>

    </div>

    <!-- Test Navs & Dropdowns -->
    <div class="test-section">

      <ul class="nav nav-tabs mb-3">

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
  <script>
    function setTheme(theme) {
      const html = document.documentElement;
      if (theme === 'auto') html.removeAttribute('data-bs-theme');
      else html.setAttribute('data-bs-theme', theme);
    }
  </script>
</body>
</html>
```

## Poin Penting
- Buat halaman test case yang mencakup semua komponen Bootstrap yang digunakan
- Periksa kontras warna sesuai WCAG AA — teks harus terbaca di latar gelap
- Uji komponen inverse (bg-primary text-white) — mereka harus tetap terlihat di dark mode
- Gunakan browser DevTools, Lighthouse, dan axe-core untuk audit aksesibilitas dark mode
