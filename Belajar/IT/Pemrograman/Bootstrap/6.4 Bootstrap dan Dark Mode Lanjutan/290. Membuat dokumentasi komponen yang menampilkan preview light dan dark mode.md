# Membuat dokumentasi komponen yang menampilkan preview light dan dark mode

## Analogi: Perpustakaan Digital

Katalog buku di perpustakaan digital menampilkan sampul dalam dua versi: tema terang untuk siang dan tema gelap untuk malam — pengunjung bisa melihat bagaimana tampilan buku di kedua mode sebelum meminjam. Dokumentasi komponen dengan preview dual-mode membantu pengembang memahami bagaimana komponen akan terlihat di setiap tema.

## Penjelasan Detail

Dokumentasi komponen yang baik menampilkan komponen dalam kedua tema secara berdampingan (side-by-side) atau dengan toggle. Gunakan Bootstrap `data-bs-theme` di container terisolasi untuk menampilkan tema berbeda tanpa mempengaruhi halaman dokumentasi utama. Buat layout split-view: kiri light, kanan dark, dengan label yang jelas. Setiap contoh komponen harus menunjukkan berbagai state (default, hover, active, disabled). Sertakan cuplikan kode yang bisa dicopy. Untuk dokumentasi statis (seperti Storybook), gunakan decorator yang membungkus komponen dengan kedua tema. Pendekatan ini membantu tim memvalidasi komponen di kedua tema sekaligus.

    function toggleGlobal() {
      const html = document.documentElement;
      if (html.getAttribute('data-bs-theme') === 'dark') {
        html.removeAttribute('data-bs-theme');
      } else {
        html.setAttribute('data-bs-theme', 'dark');
      }
    }
  </script>

## Poin Penting
- Gunakan split-view (grid 2 kolom) untuk menampilkan light dan dark mode secara berdampingan
- Set `data-bs-theme` pada container individual tanpa mempengaruhi halaman dokumentasi
- Sertakan cuplikan kode yang bisa dicopy untuk memudahkan implementasi
- Tampilkan berbagai state komponen (default, hover, active, disabled) di kedua tema
