# Cara menyimpan preferensi dark mode pengguna di localStorage

## Analogi: Perpustakaan Digital

Perpustakaan digital mengingat preferensi setiap pengunjung: "Pengunjung ini suka mode gelap". Saat pengunjung login lagi dari perangkat yang sama, tampilan otomatis gelap tanpa perlu memilih ulang. localStorage adalah memori browser yang menyimpan preferensi pengguna secara lokal.

## Penjelasan Detail

localStorage adalah web storage API yang memungkinkan penyimpanan data key-value di browser pengguna. Data tetap ada meskipun tab ditutup atau browser direstart. Untuk dark mode, simpan tema yang dipilih (`"light"` atau `"dark"`) dengan key seperti `"theme"` atau `"preferred-theme"`. Saat halaman dimuat, baca localStorage dan terapkan tema yang tersimpan. Jika tidak ada data, gunakan `prefers-color-scheme` sebagai fallback. Strategi yang baik: simpan tema saat toggle diklik, dan baca di awal load sebelum halaman dirender (gunakan `script` di `<head>` atau blocking script) untuk menghindari flash of unstyled content (FOUC).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>localStorage Theme</title>
  <!-- Script blocking sebelum render untuk mencegah FOUC -->
  <script>
    (function() {
      const theme = localStorage.getItem('theme');
      if (theme === 'dark') {
        document.documentElement.setAttribute('data-bs-theme', 'dark');
      } else if (theme === 'light') {
        document.documentElement.setAttribute('data-bs-theme', 'light');
      } else if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
        document.documentElement.setAttribute('data-bs-theme', 'dark');
        localStorage.setItem('theme', 'dark');
      }
    })();
  </script>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    body { transition: background-color 0.3s, color 0.3s; }
    .toast-notification {
      position: fixed; top: 1rem; right: 1rem; z-index: 1060;
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <h1 class="mb-4">Preferensi Tema via localStorage</h1>
    <p class="lead">Tema yang dipilih akan tersimpan dan diterapkan otomatis saat kunjungan berikutnya.</p>

    <div class="d-flex gap-3 mb-4">
      <button class="btn btn-outline-primary" id="lightBtn">☀️ Light</button>
      <button class="btn btn-outline-primary" id="darkBtn">🌙 Dark</button>
      <button class="btn btn-outline-secondary" id="resetBtn">↺ Reset (ikuti sistem)</button>
    </div>

    <div class="card">
      <div class="card-body">
        <h5>Status</h5>
        <p id="themeStatus" class="mb-0">Tema saat ini: <strong id="currentTheme">-</strong></p>
        <p id="storageStatus" class="mb-0 mt-1">localStorage: <code id="storageValue">-</code></p>
      </div>
    </div>
  </div>

  <script>
    const html = document.documentElement;

    function updateUI() {
      const current = html.getAttribute('data-bs-theme') || 'light';
      document.getElementById('currentTheme').textContent = current;
      document.getElementById('storageValue').textContent = localStorage.getItem('theme') || '(tidak ada)';
    }

    function setTheme(theme) {
      if (theme === 'auto') {
        html.removeAttribute('data-bs-theme');
        localStorage.removeItem('theme');
        // Ikuti preferensi sistem
        if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
          html.setAttribute('data-bs-theme', 'dark');
        }
      } else {
        html.setAttribute('data-bs-theme', theme);
        localStorage.setItem('theme', theme);
      }
      updateUI();
    }

    document.getElementById('lightBtn').addEventListener('click', () => setTheme('light'));
    document.getElementById('darkBtn').addEventListener('click', () => setTheme('dark'));
    document.getElementById('resetBtn').addEventListener('click', () => setTheme('auto'));

    updateUI();
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan script blocking di `<head>` sebelum CSS untuk mencegah FOUC (flash of unstyled content)
- localStorage menyimpan data secara persisten di browser pengguna
- Fallback: jika localStorage kosong, gunakan `prefers-color-scheme` dari sistem operasi
- Tombol reset menghapus localStorage dan kembali ke preferensi sistem
