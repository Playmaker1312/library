# Memahami color-scheme CSS property dan kaitannya dengan Bootstrap dark mode

## Analogi: Perpustakaan Digital

Perpustakaan digital memberi tahu browser: "Saya mendukung mode terang dan gelap, silakan pilih yang sesuai". color-scheme adalah properti CSS yang memberi sinyal ke browser tentang tema apa yang didukung halaman, sehingga browser bisa menyesuaikan elemen native seperti scrollbar, form controls, dan input kalender.

## Penjelasan Detail

CSS `color-scheme` property memberi tahu browser bahwa halaman mendukung skema warna tertentu (`light`, `dark`, atau `light dark`). Browser kemudian akan menyesuaikan elemen UI native seperti scrollbar, input fields, select dropdowns, dan button default agar sesuai dengan tema yang dipilih. Bootstrap 5.3 secara otomatis menyetel `color-scheme` saat `data-bs-theme` diubah: `light` untuk tema terang dan `dark` untuk tema gelap. Properti ini juga mempengaruhi bagaimana user-agent stylesheet browser merender elemen form. Tanpa `color-scheme`, scrollbar di dark mode mungkin tetap putih.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>color-scheme Demo</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    :root { color-scheme: light dark; }
    [data-bs-theme="light"] { color-scheme: light; }
    [data-bs-theme="dark"] { color-scheme: dark; }
    body { transition: background-color 0.3s, color 0.3s; }
    .demo-box { padding: 1rem; border-radius: 0.5rem; margin-bottom: 1rem; }
    .native-elements {
      display: flex;
      flex-direction: column;
      gap: 0.75rem;
      max-width: 400px;
    }
    .native-elements input,
    .native-elements select,
    .native-elements button {
      padding: 0.5rem;
      border: 1px solid var(--bs-border-color);
      border-radius: 0.25rem;
      background: var(--bs-body-bg);
      color: var(--bs-body-color);
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <div class="d-flex justify-content-between mb-4">
      <h1>color-scheme CSS Property</h1>
      <button class="btn btn-outline-secondary" onclick="toggleTheme()">Toggle</button>
    </div>

    <div class="row g-4">
      <div class="col-md-6">
        <div class="card">
          <div class="card-body">
            <h5>Tanpa color-scheme</h5>
            <p class="text-muted small">Scrollbar dan elemen native mungkin tetap putih di dark mode.</p>
            <div class="demo-box bg-light">
              <div class="native-elements">
                <input type="text" value="Input field">
                <select><option>Pilih opsi</option></select>
                <progress value="60" max="100"></progress>
                <button type="button">Native Button</button>
              </div>
            </div>
          </div>
        </div>
      </div>
      <div class="col-md-6">
        <div class="card">
          <div class="card-body">
            <h5>Dengan color-scheme</h5>
            <p class="text-muted small">Scrollbar dan elemen native menyesuaikan tema (set via CSS).</p>
            <div class="demo-box" style="color-scheme: inherit;">
              <div class="native-elements">
                <input type="text" value="Input field">
                <select><option>Pilih opsi</option></select>
                <progress value="60" max="100"></progress>
                <button type="button">Native Button</button>
              </div>
            </div>
          </div>
        </div>
      </div>
    </div>

    <div class="card mt-3">
      <div class="card-body">
        <h5>Informasi</h5>
        <p id="schemeInfo" class="mb-0">color-scheme saat ini: <code id="currentScheme">-</code></p>
        <p class="mb-0 mt-1">Scrollbar di sebelah kanan akan berubah warna sesuai tema.</p>
      </div>
    </div>
  </div>

  <script>
    function getScheme() {
      const html = document.documentElement;
      const theme = html.getAttribute('data-bs-theme') || 'light';
      return theme === 'dark' ? 'dark' : 'light';
    }

    function updateInfo() {
      document.getElementById('currentScheme').textContent = getScheme();
    }

    function toggleTheme() {
      const html = document.documentElement;
      if (html.getAttribute('data-bs-theme') === 'dark') {
        html.removeAttribute('data-bs-theme');
      } else {
        html.setAttribute('data-bs-theme', 'dark');
      }
      updateInfo();
    }

    updateInfo();
  </script>
</body>
</html>
```

## Poin Penting
- `color-scheme` memberi sinyal ke browser tentang tema yang didukung — mempengaruhi scrollbar dan elemen form native
- Bootstrap 5.3 otomatis menyetel `color-scheme` saat `data-bs-theme` berubah
- Tanpa `color-scheme`, scrollbar di dark mode mungkin tetap putih dan tidak konsisten
- Deklarasikan `color-scheme: light dark` di `:root` untuk dukungan kedua tema
