# Cara mengkustomisasi warna dark mode Bootstrap menggunakan Sass variables

## Analogi: Perpustakaan Digital

Perpustakaan digital mengizinkan setiap cabang untuk menyesuaikan tema gelapnya sendiri — cabang Jakarta mungkin menggunakan biru tua, cabang Surabaya menggunakan hijau tua. Bootstrap Sass variables memungkinkan Anda mengkustomisasi palet warna dark mode sesuai brand perusahaan.

## Penjelasan Detail

Bootstrap 5.3 menyediakan Sass variables khusus untuk dark mode yang diawali dengan prefix `$dark-`. Anda bisa menimpa variabel seperti `$body-bg-dark`, `$body-color-dark`, `$primary-text-dark`, dan lainnya. Variables ini digunakan saat `data-bs-theme="dark"` aktif. Untuk kustomisasi, impor Bootstrap functions dulu, timpa variabel dark, lalu impor Bootstrap sisanya. Jika tidak ingin rekompilasi, Anda juga bisa menimpa CSS custom properties di `[data-bs-theme="dark"]` secara langsung. Pendekatan hybrid: gunakan Sass variables untuk kustomisasi global dan CSS custom properties untuk tweak spesifik per komponen.

## Contoh Kode Implementasi

```scss
// custom-dark-mode.scss
// 1. Functions (wajib)
@import "bootstrap/scss/functions";

// 2. Override dark mode variables
// Warna latar dark mode: navy gelap
$body-bg-dark: #0a0e27;
$body-color-dark: #e0e0ff;
$primary-text-dark: #818cf8;
$secondary-text-dark: #a5b4fc;
$border-color-dark: #1e1b4b;
$card-bg-dark: #131638;
$card-cap-bg-dark: #1a1d45;
$table-bg-dark: #131638;
$table-color-dark: #e0e0ff;
$dropdown-bg-dark: #131638;
$dropdown-link-hover-bg-dark: #1a1d45;
$navbar-dark-color: #a5b4fc;

// 3. Custom component dark variables
$custom-card-dark-bg: #131638;
$custom-card-dark-border: #1e1b4b;
$custom-card-dark-shadow: 0 4px 20px rgba(0,0,0,0.4);

// 4. Impor Bootstrap
@import "bootstrap/scss/variables";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
@import "bootstrap/scss/type";
@import "bootstrap/scss/images";
@import "bootstrap/scss/containers";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/helpers";
@import "bootstrap/scss/utilities";
@import "bootstrap/scss/utilities/api";

// 5. Komponen
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/card";
@import "bootstrap/scss/forms";
@import "bootstrap/scss/modal";
@import "bootstrap/scss/nav";
@import "bootstrap/scss/navbar";
@import "bootstrap/scss/alert";
@import "bootstrap/scss/tables";
@import "bootstrap/scss/dropdown";

// 6. Custom component dark mode
[data-bs-theme="dark"] {
  .custom-card {
    background-color: $custom-card-dark-bg;
    border-color: $custom-card-dark-border;
    box-shadow: $custom-card-dark-shadow;
  }
}
```

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Custom Dark Mode</title>
  <link href="dist/custom-dark-mode.css" rel="stylesheet">
</head>
<body>
  <div class="container py-5">
    <div class="d-flex justify-content-between mb-4">
      <h1>Dark Mode Kustom</h1>
      <button class="btn btn-outline-primary" onclick="toggleTheme()">Toggle</button>
    </div>
    <div class="card">
      <div class="card-body">
        <h5>Card dengan Dark Mode Kustom</h5>
        <p>Warna latar navy gelap (#0a0e27) dengan teks biru muda (#e0e0ff).</p>
        <button class="btn btn-primary">Primary</button>
        <button class="btn btn-outline-light">Outline</button>
      </div>
    </div>
    <table class="table mt-3">
      <thead><tr><th>Kolom 1</th><th>Kolom 2</th></tr></thead>
      <tbody><tr><td>Data 1</td><td>Data 2</td></tr></tbody>
    </table>
  </div>
  <script>
    function toggleTheme() {
      const html = document.documentElement;
      const next = html.getAttribute('data-bs-theme') === 'dark' ? 'light' : 'dark';
      html.setAttribute('data-bs-theme', next);
    }
  </script>
</body>
</html>
```

## Poin Penting
- Bootstrap 5.3 menyediakan variabel Sass khusus dark mode dengan prefix `$*-dark`
- Timpa variabel dark sebelum impor Bootstrap untuk tema kustom yang konsisten
- CSS custom properties di `[data-bs-theme="dark"]` bisa digunakan untuk tweak tambahan
- Pastikan kontras warna tetap memadai (AA/AAA) saat mengkustomisasi dark mode
