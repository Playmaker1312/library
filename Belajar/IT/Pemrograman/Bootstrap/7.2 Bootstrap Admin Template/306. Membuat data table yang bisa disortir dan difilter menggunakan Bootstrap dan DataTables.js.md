# Membuat Data Table yang Bisa Disortir dan Difilter Menggunakan Bootstrap dan DataTables.js

## Analogi: Perpustakaan Digital

Data table adalah seperti katalog kartu perpustakaan yang bisa diatur ulang berdasarkan judul, penulis, atau tahun terbit. Pengunjung bisa mencari buku tertentu, menyortir berdasarkan kolom, atau memfilter berdasarkan genre. DataTables.js adalah alat yang membuat katalog digital ini menjadi interaktif—dengan sekali klik, data bisa diurutkan, dicari, atau difilter tanpa memuat ulang halaman.

## Penjelasan Detail

DataTables.js adalah plugin jQuery yang memperkaya tabel HTML dengan fitur sorting, searching, pagination, dan filtering. Integrasinya dengan Bootstrap sudah didukung melalui class Bootstrap untuk styling. Cukup tambahkan class `table table-striped table-hover` pada elemen table dan panggil `$('#myTable').DataTable()`. DataTables juga mendukung export ke CSV/Excel, kolom visibility toggle, dan server-side processing untuk data besar. Gunakan opsi seperti `pageLength`, `order`, dan `searching` untuk mengontrol perilaku tabel.
