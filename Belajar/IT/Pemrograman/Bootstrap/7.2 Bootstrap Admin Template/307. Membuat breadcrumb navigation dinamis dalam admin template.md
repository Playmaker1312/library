# Membuat Breadcrumb Navigation Dinamis dalam Admin Template

## Analogi: Perpustakaan Digital

Breadcrumb adalah seperti jejak remah roti di lantai perpustakaan—setiap persimpangan meninggalkan tanda yang menunjukkan dari mana pengunjung berasal dan bagaimana kembali ke pintu masuk. Di perpustakaan besar, breadcrumb membantu pengunjung tidak tersesat di antara rak-rak buku. Di admin template, breadcrumb menunjukkan posisi pengguna dalam hierarki halaman dan memungkinkan navigasi mundur dengan mudah.

## Penjelasan Detail

Breadcrumb Bootstrap adalah komponen navigasi sekunder yang menampilkan hierarki halaman saat ini. Gunakan class `breadcrumb` pada `<ol>` dan `breadcrumb-item` pada setiap `<li>`. Item terakhir diberi class `active` dan `aria-current="page"` untuk menandai halaman saat ini. Breadcrumb bisa dibuat statis di HTML atau dinamis dengan JavaScript berdasarkan state aplikasi. Breadcrumb dinamis berguna untuk halaman dengan parameter atau routing kompleks. Pastikan breadcrumb konsisten dengan navbar dan judul halaman.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Breadcrumb Dinamis</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="d-flex" style="min-height: 100vh;">
    <!-- Sidebar -->
    <div class="bg-dark text-white p-3" style="width: 250px;">
      <h5>Admin Panel</h5>
      <ul class="nav flex-column mt-3">
        <li class="nav-item"><a href="#" class="nav-link text-white" onclick="navigateTo(['Dashboard'])">📊 Dashboard</a></li>
        <li class="nav-item"><a href="#" class="nav-link text-white" onclick="navigateTo(['Dashboard', 'Users'])">👥 Users</a></li>
        <li class="nav-item"><a href="#" class="nav-link text-white" onclick="navigateTo(['Dashboard', 'Products'])">📦 Products</a></li>
        <li class="nav-item"><a href="#" class="nav-link text-white" onclick="navigateTo(['Dashboard', 'Settings'])">⚙️ Settings</a></li>
      </ul>
    </div>

    <!-- Main -->
    <div class="flex-grow-1 d-flex flex-column">
      <nav class="navbar navbar-light bg-light px-4 shadow-sm">
        <span class="navbar-brand">Admin</span>
      </nav>

      <div class="p-4">
        <!-- Breadcrumb -->
        <nav aria-label="breadcrumb" id="breadcrumbNav">
          <ol class="breadcrumb" id="breadcrumbList">
            <li class="breadcrumb-item active" aria-current="page">Dashboard</li>
          </ol>
        </nav>

        <h4 id="pageTitle">Dashboard</h4>
        <p id="pageContent">Selamat datang di halaman Dashboard.</p>
      </div>
    </div>
  </div>

  <script>
    function navigateTo(path) {
      const breadcrumbList = document.getElementById('breadcrumbList');
      breadcrumbList.innerHTML = '';

      path.forEach((item, index) => {
        const li = document.createElement('li');
        li.className = 'breadcrumb-item';
        if (index === path.length - 1) {
          li.classList.add('active');
          li.setAttribute('aria-current', 'page');
          li.textContent = item;
        } else {
          const a = document.createElement('a');
          a.href = '#';
          a.textContent = item;
          li.appendChild(a);
        }
        breadcrumbList.appendChild(li);
      });

      document.getElementById('pageTitle').textContent = path[path.length - 1];
      document.getElementById('pageContent').textContent = 'Anda sedang berada di halaman ' + path[path.length - 1] + '.';
    }
  </script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Breadcrumb menunjukkan hierarki halaman dan memungkinkan navigasi mundur ke halaman sebelumnya.
- Breadcrumb dinamis dapat diperbarui dengan JavaScript berdasarkan state atau routing aplikasi.
- Item breadcrumb terakhir harus memiliki class active dan atribut aria-current="page" untuk aksesibilitas.
