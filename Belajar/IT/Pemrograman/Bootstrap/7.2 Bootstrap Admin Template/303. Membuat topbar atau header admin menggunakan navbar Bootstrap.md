# Membuat Topbar atau Header Admin Menggunakan Navbar Bootstrap

## Analogi: Perpustakaan Digital

Topbar admin adalah seperti meja resepsionis di perpustakaan—tempat pertama yang dilihat pengunjung saat masuk. Resepsionis menyambut, memberikan informasi, dan mengarahkan pengunjung ke tempat yang tepat. Topbar admin berfungsi serupa: menampilkan brand, notifikasi, pencarian cepat, dan profil pengguna. Navbar Bootstrap adalah komponen sempurna untuk membangun topbar ini.

## Penjelasan Detail

Topbar admin biasanya berisi logo atau brand di kiri, pencarian global di tengah, dan notifikasi serta profil pengguna di kanan. Gunakan navbar Bootstrap dengan kelas `navbar navbar-light bg-white shadow-sm` agar terlihat modern. Sertakan dropdown untuk notifikasi (dengan badge jumlah) dan dropdown untuk profil pengguna (dengan menu dropdown). Topbar harus sticky agar tetap terlihat saat halaman di-scroll. Gunakan container-fluid agar topbar memenuhi lebar halaman. Pada layout dengan sidebar, topbar berada di area konten utama, terpisah dari sidebar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Topbar Admin</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="d-flex" style="min-height: 100vh;">
    <!-- Sidebar -->
    <div class="bg-dark text-white" style="width: 250px; padding: 1rem;">
      <h5>Admin Panel</h5>
    </div>

    <!-- Main Area -->
    <div class="flex-grow-1 d-flex flex-column">
      <!-- Topbar -->
      <nav class="navbar navbar-expand navbar-light bg-white shadow-sm px-4 sticky-top">
        <!-- Search -->
        <form class="d-flex me-auto" role="search">
          <input class="form-control form-control-sm me-2" type="search" placeholder="Cari sesuatu..." style="width: 300px;">
          <button class="btn btn-outline-primary btn-sm" type="submit">Cari</button>
        </form>

        <!-- Right Side -->
        <div class="d-flex align-items-center gap-3">
          <!-- Notifications -->
          <div class="dropdown">
            <button class="btn btn-light position-relative dropdown-toggle" data-bs-toggle="dropdown">
              🔔
              <span class="position-absolute top-0 start-100 translate-middle badge rounded-pill bg-danger">5</span>
            </button>
            <ul class="dropdown-menu dropdown-menu-end" style="width: 300px;">
              <li><h6 class="dropdown-header">Notifikasi</h6></li>
              <li><a class="dropdown-item" href="#">📩 Pesan baru dari Andi</a></li>
              <li><a class="dropdown-item" href="#">✅ Order #123 selesai</a></li>
              <li><a class="dropdown-item" href="#">⚠️ Stok menipis</a></li>
              <li><hr class="dropdown-divider"></li>
              <li><a class="dropdown-item text-center small" href="#">Lihat semua</a></li>
            </ul>
          </div>

          <!-- Profile -->
          <div class="dropdown">
            <button class="btn btn-light dropdown-toggle d-flex align-items-center gap-2" data-bs-toggle="dropdown">
              <img src="https://via.placeholder.com/32" class="rounded-circle" width="32" height="32" alt="User">
              <span>Admin</span>
            </button>
            <ul class="dropdown-menu dropdown-menu-end">
              <li><a class="dropdown-item" href="#">Profile</a></li>
              <li><a class="dropdown-item" href="#">Settings</a></li>
              <li><hr class="dropdown-divider"></li>
              <li><a class="dropdown-item" href="#">Logout</a></li>
            </ul>
          </div>
        </div>
      </nav>

      <!-- Content -->
      <div class="p-4 bg-light flex-grow-1">
        <h4>Dashboard Overview</h4>
        <p>Konten halaman admin ditempatkan di sini.</p>
      </div>
    </div>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Topbar admin berisi pencarian, notifikasi (dengan badge), dan dropdown profil pengguna.
- Gunakan sticky-top agar topbar tetap terlihat saat halaman di-scroll.
- Navbar Bootstrap dengan kelas navbar-light dan shadow-sm memberikan tampilan profesional.
