# Mengintegrasikan Chart.js dengan Bootstrap untuk Visualisasi Data

## Analogi: Perpustakaan Digital

Chart.js adalah seperti papan grafik di perpustakaan yang menampilkan data statistik dalam bentuk visual—diagram batang untuk jumlah pengunjung per bulan, diagram garis untuk tren peminjaman buku, atau diagram lingkaran untuk kategori buku favorit. Grafik membuat data lebih mudah dipahami daripada tabel angka. Bootstrap menyediakan card dan grid yang rapi untuk menempatkan grafik-grafik ini.

## Penjelasan Detail

Chart.js adalah library JavaScript ringan untuk membuat grafik responsif. Integrasinya dengan Bootstrap sangat mudah: tempatkan elemen canvas HTML di dalam card Bootstrap, lalu inisialisasi grafik dengan JavaScript. Chart.js mendukung berbagai jenis grafik: line, bar, radar, doughnut, polar area, dan scatter. Atur beberapa grafik dalam grid Bootstrap untuk dashboard yang informatif. Gunakan opsi responsif Chart.js agar grafik menyesuaikan ukuran container. Warna grafik bisa disesuaikan dengan tema Bootstrap.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Chart.js + Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
  <script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
</head>
<body>
  <div class="container py-5">
    <h2 class="mb-4">Dashboard Visualisasi Data</h2>
    <div class="row g-4">
      <!-- Line Chart -->
      <div class="col-md-6">
        <div class="card shadow-sm">
          <div class="card-header">Revenue Bulanan</div>
          <div class="card-body">
            <canvas id="lineChart" height="200"></canvas>
          </div>
        </div>
      </div>
      <!-- Bar Chart -->
      <div class="col-md-6">
        <div class="card shadow-sm">
          <div class="card-header">Pengguna Baru per Bulan</div>
          <div class="card-body">
            <canvas id="barChart" height="200"></canvas>
          </div>
        </div>
      </div>
      <!-- Doughnut Chart -->
      <div class="col-md-4">
        <div class="card shadow-sm">
          <div class="card-header">Kategori Produk</div>
          <div class="card-body">
            <canvas id="doughnutChart" height="200"></canvas>
          </div>
        </div>
      </div>
      <!-- Polar Chart -->
      <div class="col-md-4">
        <div class="card shadow-sm">
          <div class="card-header">Skor Kepuasan</div>
          <div class="card-body">
            <canvas id="polarChart" height="200"></canvas>
          </div>
        </div>
      </div>
      <!-- Radar Chart -->
      <div class="col-md-4">
        <div class="card shadow-sm">
          <div class="card-header">Performa Tim</div>
          <div class="card-body">
            <canvas id="radarChart" height="200"></canvas>
          </div>
        </div>
      </div>
    </div>
  </div>

  <script>
    // Line Chart
    new Chart(document.getElementById('lineChart'), {
      type: 'line',
      data: {
        labels: ['Jan','Feb','Mar','Apr','May','Jun'],
        datasets: [{
          label: 'Revenue 2026',
          data: [3000, 4500, 3800, 5200, 4800, 6000],
          borderColor: '#0d6efd',
          backgroundColor: 'rgba(13,110,253,0.1)',
          tension: 0.3,
          fill: true
        }]
      },
      options: { responsive: true, maintainAspectRatio: false }
    });

    // Bar Chart
    new Chart(document.getElementById('barChart'), {
      type: 'bar',
      data: {
        labels: ['Jan','Feb','Mar','Apr','May','Jun'],
        datasets: [{
          label: 'Pengguna Baru',
          data: [120, 200, 150, 180, 220, 250],
          backgroundColor: '#198754'
        }]
      },
      options: { responsive: true, maintainAspectRatio: false }
    });

    // Doughnut Chart
    new Chart(document.getElementById('doughnutChart'), {
      type: 'doughnut',
      data: {
        labels: ['Elektronik', 'Fashion', 'Makanan', 'Lainnya'],
        datasets: [{
          data: [35, 25, 20, 20],
          backgroundColor: ['#0d6efd', '#198754', '#ffc107', '#dc3545']
        }]
      }
    });

    // Polar Chart
    new Chart(document.getElementById('polarChart'), {
      type: 'polarArea',
      data: {
        labels: ['Pelayanan', 'Kualitas', 'Harga', 'Pengiriman'],
        datasets: [{
          data: [90, 85, 75, 80],
          backgroundColor: ['rgba(13,110,253,0.6)', 'rgba(25,135,84,0.6)', 'rgba(255,193,7,0.6)', 'rgba(220,53,69,0.6)']
        }]
      }
    });

    // Radar Chart
    new Chart(document.getElementById('radarChart'), {
      type: 'radar',
      data: {
        labels: ['Kecepatan', 'Kualitas', 'Komunikasi', 'Inovasi', 'Ketepatan'],
        datasets: [{
          label: 'Tim A',
          data: [90, 85, 80, 75, 95],
          borderColor: '#0d6efd',
          backgroundColor: 'rgba(13,110,253,0.2)'
        }]
      }
    });
  </script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Chart.js diintegrasikan dengan Bootstrap dengan menempatkan elemen canvas di dalam card.
- Berbagai jenis grafik (line, bar, doughnut, polar, radar) bisa dikombinasikan dalam grid Bootstrap.
- Atur responsive: true agar grafik menyesuaikan ukuran container card secara otomatis.
