# Membuat User Profile Page dalam Admin Template Bootstrap

## Analogi: Perpustakaan Digital

Halaman profil pengguna adalah seperti kartu anggota perpustakaan yang diperbesar—menampilkan foto, nama lengkap, jenis keanggotaan, riwayat peminjaman, dan pengaturan preferensi. Petugas perpustakaan bisa melihat data diri anggota, mengedit informasi, atau melihat aktivitas terbaru. Bootstrap card, form, tabel, dan grid sangat cocok untuk menyusun halaman profil yang informatif dan rapi.

## Penjelasan Detail

User profile page biasanya terdiri dari beberapa seksi: header profil (foto, nama, role), informasi pribadi (form), aktivitas terbaru (tabel/list), dan pengaturan. Layout umum menggunakan grid dua kolom: kolom kiri untuk foto dan ringkasan, kolom kanan untuk detail. Gunakan card Bootstrap untuk setiap seksi. Foto profil bisa menggunakan img rounded-circle. Form informasi bisa menggunakan layout horizontal dengan label di kiri. Tambahkan tab untuk memisahkan "Profile", "Activity", dan "Settings". Button edit memungkinkan pengguna mengubah data.

## Poin Penting
- Halaman profil terdiri dari header (foto + info ringkas) dan tab untuk informasi detail, aktivitas, dan pengaturan.
- Layout dua kolom atau grid dengan card dan form horizontal menciptakan tampilan yang rapi.
- Tab Bootstrap memisahkan konten profil ke dalam kategori yang mudah dinavigasi.
