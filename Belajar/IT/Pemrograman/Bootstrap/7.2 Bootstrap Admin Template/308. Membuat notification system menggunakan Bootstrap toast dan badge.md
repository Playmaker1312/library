# Membuat Notification System Menggunakan Bootstrap Toast dan Badge

## Analogi: Perpustakaan Digital

Sistem notifikasi di perpustakaan adalah seperti papan pengumuman kecil yang muncul saat ada pesan baru—buku yang dipinjam akan segera jatuh tempo, ada buku baru yang tiba, atau jadwal petugas berubah. Toast adalah notifikasi pop-up yang muncul sebentar lalu menghilang, seperti petugas yang mendekat dan berbisik memberi informasi. Badge adalah angka merah di ikon lonceng yang menunjukkan jumlah notifikasi belum dibaca.

## Penjelasan Detail

Bootstrap Toast adalah komponen notifikasi ringan yang muncul di sudut layar dan bisa otomatis menghilang setelah beberapa detik. Gunakan class `toast` dengan container `toast-container` untuk mengelompokkan notifikasi. Badge Bootstrap (`badge bg-danger rounded-pill`) ditempelkan pada ikon atau tombol untuk menunjukkan jumlah notifikasi. Kombinasikan keduanya: badge pada ikon bel di topbar, dan toast notification yang muncul saat ada event baru. Toast bisa diprogram dengan JavaScript untuk ditampilkan secara real-time.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Notification System</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <nav class="navbar navbar-dark bg-dark px-4">
    <a class="navbar-brand" href="#">MyApp</a>
    <div class="d-flex align-items-center gap-3">
      <!-- Notification Bell with Badge -->
      <div class="position-relative" style="cursor: pointer;" onclick="addNotification()">
        🔔
        <span class="position-absolute top-0 start-100 translate-middle badge rounded-pill bg-danger" id="notifBadge">0</span>
      </div>
      <button class="btn btn-sm btn-outline-light" onclick="showToast()">Test Toast</button>
    </div>
  </nav>

  <div class="container my-5">
    <h4>Notification System</h4>
    <p>Klik ikon lonceng untuk simulasi notifikasi baru. Klik "Test Toast" untuk menampilkan toast manual.</p>
  </div>

  <!-- Toast Container -->
  <div class="toast-container position-fixed bottom-0 end-0 p-3" id="toastContainer">
    <div class="toast" role="alert" aria-live="assertive" aria-atomic="true" id="liveToast">
      <div class="toast-header">
        <strong class="me-auto">Notifikasi</strong>
        <small>Baru saja</small>
        <button type="button" class="btn-close" data-bs-dismiss="toast"></button>
      </div>
      <div class="toast-body" id="toastMessage">
        Pesan notifikasi akan muncul di sini.
      </div>
    </div>
  </div>

  <script>
    let notifCount = 0;

    function showToast(message) {
      const toastEl = document.getElementById('liveToast');
      document.getElementById('toastMessage').textContent = message || 'Ini adalah notifikasi toast!';
      const toast = new bootstrap.Toast(toastEl, { autohide: true, delay: 3000 });
      toast.show();
    }

    function addNotification() {
      notifCount++;
      document.getElementById('notifBadge').textContent = notifCount;
      const messages = [
        '📩 Pesan baru dari Andi',
        '✅ Order #123 telah dikonfirmasi',
        '⚠️ Stok produk menipis',
        '📊 Laporan bulanan siap',
        '🔔 Pengguna baru mendaftar'
      ];
      const randomMsg = messages[Math.floor(Math.random() * messages.length)];
      showToast(randomMsg);
    }
  </script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Bootstrap Toast menampilkan notifikasi pop-up yang bisa otomatis menghilang (autohide).
- Badge pada ikon bel menunjukkan jumlah notifikasi yang belum dibaca.
- Kombinasi toast dan badge menciptakan sistem notifikasi real-time yang interaktif.
