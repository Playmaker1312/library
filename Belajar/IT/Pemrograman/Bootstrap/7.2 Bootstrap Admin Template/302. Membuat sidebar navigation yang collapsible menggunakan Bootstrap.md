# Membuat Sidebar Navigation yang Collapsible Menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Sidebar collapsible adalah seperti lemari arsip di perpustakaan yang bisa dibuka dan ditutup. Saat petugas membutuhkan dokumen, mereka membuka laci; setelah selesai, laci ditutup kembali untuk menghemat ruang. Di layar kecil (ponsel), sidebar yang selalu terbuka akan memakan terlalu banyak tempat. Oleh karena itu, sidebar perlu bisa disembunyikan dan dimunculkan dengan tombol toggler.

## Penjelasan Detail

Sidebar collapsible dapat dibuat menggunakan komponen offcanvas Bootstrap atau collapse. Offcanvas adalah panel yang muncul dari sisi layar, cocok untuk sidebar mobile. Untuk sidebar desktop yang bisa diciutkan, gunakan CSS class `collapse` horizontal atau JavaScript untuk mengubah lebar sidebar. Tombol hamburger di topbar berfungsi sebagai toggler. Sidebar bisa berisi menu utama, submenu (accordion), dan divider. Pastikan transisi animasi halus saat sidebar membuka/menutup. Pada layar kecil, sidebar bisa berubah menjadi offcanvas yang menimpa konten.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Sidebar Collapsible</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    .sidebar { width: 250px; transition: width 0.3s, margin-left 0.3s; }
    .sidebar.collapsed { width: 0; overflow: hidden; }
    .main-content { flex-grow: 1; transition: margin-left 0.3s; }
  </style>
</head>
<body>
  <div class="d-flex" style="min-height: 100vh;">
    <!-- Sidebar -->
    <div class="sidebar bg-dark text-white d-flex flex-column" id="sidebar">
      <div class="p-3 border-bottom">
        <h5>Menu</h5>
      </div>
      <ul class="nav flex-column p-3 flex-grow-1">
        <li class="nav-item"><a href="#" class="nav-link text-white">📊 Dashboard</a></li>
        <li class="nav-item"><a href="#" class="nav-link text-white">👥 Users</a></li>
        <li class="nav-item"><a href="#" class="nav-link text-white">📦 Products</a></li>
        <li class="nav-item"><a href="#" class="nav-link text-white">📝 Orders</a></li>
      </ul>
    </div>

    <!-- Main -->
    <div class="main-content d-flex flex-column">
      <!-- Topbar -->
      <nav class="navbar navbar-light bg-light shadow-sm px-3">
        <button class="btn btn-outline-secondary" id="toggleSidebar">☰</button>
        <span>Admin Panel</span>
      </nav>
      <div class="p-4">
        <h4>Dashboard</h4>
        <p>Klik tombol ☰ untuk menyembunyikan/menampilkan sidebar.</p>
      </div>
    </div>
  </div>

  <script>
    document.getElementById('toggleSidebar').addEventListener('click', function() {
      document.getElementById('sidebar').classList.toggle('collapsed');
    });
  </script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Sidebar collapsible dapat dibuat dengan toggle class CSS yang mengatur lebar sidebar.
- Gunakan offcanvas Bootstrap untuk sidebar yang menimpa konten pada layar kecil.
- Tombol toggler di topbar memudahkan pengguna untuk menyembunyikan/menampilkan sidebar.
