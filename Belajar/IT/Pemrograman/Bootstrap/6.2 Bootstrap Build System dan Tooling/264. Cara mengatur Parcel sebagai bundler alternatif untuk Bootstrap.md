# Cara mengatur Parcel sebagai bundler alternatif untuk Bootstrap

## Analogi: Perpustakaan Digital

Sebagian perpustakaan digital menggunakan sistem otomatis yang langsung memproses buku tanpa perlu konfigurasi rumit — cukup masukkan naskah, dan sistem akan mengurus sisanya. Parcel adalah bundler zero-configuration seperti itu. Ia langsung mendukung Sass, JavaScript modern, dan berbagai aset lain tanpa perlu menulis file konfigurasi yang panjang.

## Penjelasan Detail

Parcel adalah web application bundler yang terkenal karena pengalaman zero-config. Untuk menggunakan Bootstrap dengan Parcel, cukup instal Parcel bersama Sass, buat file HTML yang merujuk ke entry JavaScript, dan Parcel akan menangani sisanya. Parcel mendukung Sass, PostCSS, dan Babel secara built-in. Anda bisa mengimpor Bootstrap dari node_modules langsung di file JavaScript atau CSS. Parcel juga mendukung tree shaking, code splitting, dan hot module replacement. Untuk production, jalankan `parcel build` yang akan menghasilkan output optimal dengan cache hashing dan minifikasi otomatis. Parcel versi 2 juga mendukung pemisahan CSS per halaman.

## Contoh Kode Implementasi

```json
{
  "name": "parcel-bootstrap",
  "version": "1.0.0",
  "source": "src/index.html",
  "scripts": {
    "start": "parcel",
    "build": "parcel build --dist-dir dist --public-url ./",
    "clean": "rm -rf dist .parcel-cache"
  },
  "dependencies": {
    "bootstrap": "^5.3.2",
    "@popperjs/core": "^2.11.8"
  },
  "devDependencies": {
    "parcel": "^2.10.0",
    "sass": "^1.69.0",
    "@parcel/transformer-sass": "^2.10.0"
  }
}
```

```html
<!-- src/index.html -->
<!DOCTYPE html>
<html lang="en">
```

## Poin Penting
- Parcel adalah zero-config bundler — tidak perlu webpack.config.js atau vite.config.js
- Gunakan `@parcel/transformer-sass` untuk dukungan Sass penuh
- Parcel secara otomatis menangani tree shaking, minifikasi, dan cache hashing
- Cocok untuk project kecil-menengah yang ingin Bootstrap cepat jalan tanpa setup rumit
