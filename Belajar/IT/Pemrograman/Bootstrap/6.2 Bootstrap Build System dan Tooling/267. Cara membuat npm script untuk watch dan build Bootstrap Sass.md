# Cara membuat npm script untuk watch dan build Bootstrap Sass

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki sistem yang secara otomatis memindai folder input setiap kali ada file baru ditambahkan — jika ada naskah baru masuk, sistem langsung memprosesnya tanpa perlu diminta. npm script watch bekerja seperti itu: ia memantau perubahan file dan secara otomatis menjalankan kompilasi Sass, memberikan feedback instan saat Anda mengedit.

## Penjelasan Detail

npm scripts adalah task runner bawaan npm yang sangat fleksibel. Untuk Bootstrap Sass, Anda perlu script untuk development (watch) dan production (build). Script `build` mengkompilasi Sass ke CSS, menambahkan autoprefixer, dan meminify. Script `watch` menggunakan flag `--watch` dari Sass CLI atau nodemon untuk memantau perubahan. Anda juga bisa menggunakan `npm-run-all` untuk menjalankan watch CSS dan watch JS secara paralel. Untuk production, sertakan minifikasi, source maps (untuk debugging), dan copy file ke direktori dist. Struktur skrip yang baik memisahkan build CSS, build JS, dan clean task agar mudah dipelihara.

## Contoh Kode Implementasi

```json
{
  "name": "bootstrap-custom",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "build": "npm-run-all --sequential clean build:css build:js",
    "build:css": "npm-run-all --sequential build:css:compile build:css:prefix build:css:minify",
    "build:css:compile": "sass src/scss/main.scss:dist/css/main.css --style=expanded",
    "build:css:prefix": "postcss dist/css/main.css --use autoprefixer --replace",
    "build:css:minify": "sass src/scss/main.scss:dist/css/main.min.css --style=compressed",
    "build:js": "rollup src/js/main.js --file dist/js/main.js --format iife",
    "build:js:min": "terser dist/js/main.js --output dist/js/main.min.js --compress --mangle",
    "watch": "npm-run-all --parallel watch:css watch:js",
    "watch:css": "sass --watch src/scss:dist/css --style=expanded",
    "watch:js": "rollup src/js/main.js --file dist/js/main.js --format iife --watch",
    "clean": "rimraf dist",
    "serve": "lite-server --baseDir=\"dist\"",
    "dev": "npm-run-all --parallel watch serve",
    "lint:css": "stylelint \"src/scss/**/*.scss\"",
    "lint:js": "eslint \"src/js/**/*.js\""
  },
  "devDependencies": {
    "sass": "^1.69.0",
    "postcss": "^8.4.32",
    "postcss-cli": "^10.1.0",
    "autoprefixer": "^10.4.16",
    "rollup": "^4.0.0",
    "terser": "^5.24.0",
    "npm-run-all": "^4.1.5",
    "rimraf": "^5.0.0",
    "lite-server": "^2.6.1",
    "stylelint": "^15.10.0",
    "eslint": "^8.50.0"
  },
  "browserslist": [
    "last 2 versions",
    "> 0.5%",
    "not dead"
  ]
}
```

```bat
:: Jalankan di terminal:
:: npm run dev    -> Watch + live server untuk development
:: npm run build  -> Build production ke folder dist/
:: npm run watch  -> Watch saja (CSS + JS)
```

## Poin Penting
- Gunakan `npm-run-all` untuk menjalankan task paralel (`--parallel`) dan sekuensial (`--sequential`)
- Script `build` memiliki tahapan terpisah: compile → prefix → minify untuk kontrol yang granular
- Script `watch` menggunakan `sass --watch` yang memonitor perubahan file secara real-time
- Script `dev` menggabungkan watch dan live server untuk produktivitas maksimal saat development
