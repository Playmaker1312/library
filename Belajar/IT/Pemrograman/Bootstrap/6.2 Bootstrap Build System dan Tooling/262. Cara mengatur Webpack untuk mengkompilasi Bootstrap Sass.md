# Cara mengatur Webpack untuk mengkompilasi Bootstrap Sass

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki pusat pengolahan buku yang mengubah naskah mentah (file .doc, .pdf) menjadi format yang siap ditampilkan di browser. Pusat pengolahan ini memiliki mesin yang bisa menangani berbagai format secara otomatis. Webpack adalah pusat pengolahan untuk project web — ia menerima berbagai aset (Sass, JS, gambar) dan mengubahnya menjadi bundle yang dioptimalkan.

## Penjelasan Detail

Webpack adalah module bundler yang sangat konfigurabel. Untuk mengkompilasi Bootstrap Sass, Anda perlu mengatur loader: `sass-loader` untuk kompilasi Sass, `css-loader` untuk memproses CSS, dan `style-loader` atau `MiniCssExtractPlugin` untuk menyuntikkan CSS ke halaman. Bootstrap membutuhkan `@popperjs/core` sebagai dependency untuk komponen dropdown, tooltip, dan popover. Konfigurasi Webpack modern menggunakan `webpack.config.js` dengan entry point utama yang mengimpor Bootstrap Sass dan JavaScript. Keuntungan menggunakan Webpack adalah code splitting, tree shaking, dan integrasi dengan berbagai loader lain. Anda juga bisa mengatur hot module replacement (HMR) untuk pengembangan yang lebih cepat.

## Contoh Kode Implementasi

```js
// webpack.config.js — Konfigurasi Webpack untuk Bootstrap Sass
const path = require('path');
const MiniCssExtractPlugin = require('mini-css-extract-plugin');

module.exports = {
  mode: process.env.NODE_ENV === 'production' ? 'production' : 'development',
  entry: './src/main.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
    clean: true,
  },
  module: {
    rules: [
      {
        test: /\.scss$/,
        use: [
          MiniCssExtractPlugin.loader,
          'css-loader',
          {
            loader: 'postcss-loader',
            options: {
              postcssOptions: {
                plugins: [
                  ['autoprefixer'],
                ],
              },
            },
          },
          'sass-loader',
        ],
      },
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: 'babel-loader',
      },
    ],
  },
  plugins: [
    new MiniCssExtractPlugin({
      filename: 'styles.css',
    }),
  ],
  devServer: {
    static: './dist',
    hot: true,
    port: 3000,
  },
};
```

## Poin Penting
- Gunakan `sass-loader` untuk kompilasi Sass dan `MiniCssExtractPlugin` untuk ekstrak CSS ke file terpisah
- Urutan loader penting: sass-loader → postcss-loader → css-loader → MiniCssExtractPlugin.loader
- Impor Bootstrap secara selektif (`bootstrap/js/dist/modal`) untuk mengurangi ukuran bundle
- Aktifkan source maps di development untuk debugging Sass yang lebih mudah
