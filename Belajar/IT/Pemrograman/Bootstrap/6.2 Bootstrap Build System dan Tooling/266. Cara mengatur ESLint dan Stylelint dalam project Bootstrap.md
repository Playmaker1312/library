# Cara mengatur ESLint dan Stylelint dalam project Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki tim proofreader yang memeriksa setiap buku sebelum dipublikasikan — memastikan tidak ada typo, format konsisten, dan struktur sesuai standar. ESLint dan Stylelint adalah proofreader untuk kode JavaScript dan CSS/Sass. Mereka secara otomatis mendeteksi kesalahan, pelanggaran gaya, dan potensi bug sebelum kode masuk ke production.

## Penjelasan Detail

ESLint adalah linter untuk JavaScript yang mendeteksi error dan pelanggaran gaya kode. Stylelint adalah linter untuk CSS, Sass, dan PostCSS. Untuk project Bootstrap, Anda perlu mengkonfigurasi keduanya dengan aturan yang sesuai. ESLint membutuhkan file `.eslintrc.json` atau `eslint.config.js` (flat config). Stylelint menggunakan `.stylelintrc.json`. Bootstrap resmi menggunakan Stylelint dengan `stylelint-config-twbs-bootstrap` yang sudah mengakomodasi pola khas Bootstrap. Integrasikan kedua linter ke npm scripts dan pre-commit hook menggunakan husky dan lint-staged. Pastikan juga linter dijalankan di CI pipeline. Penggunaan aturan yang konsisten meningkatkan kualitas kode, mengurangi bug, dan memudahkan code review.

## Contoh Kode Implementasi

```json
// .eslintrc.json
{
  "env": {
    "browser": true,
    "es2021": true,
    "jquery": true
  },
  "extends": [
    "eslint:recommended",
    "airbnb-base"
  ],
  "parserOptions": {
    "ecmaVersion": "latest",
    "sourceType": "module"
  },
  "rules": {
    "no-unused-vars": ["warn", { "argsIgnorePattern": "^_" }],
    "no-console": "off",
    "import/no-unresolved": "off",
    "max-len": ["warn", { "code": 120 }]
  },
  "globals": {
    "bootstrap": "readonly"
  }
}
```

```json
// .stylelintrc.json — Untuk Bootstrap dan Sass kustom
{
  "extends": [
    "stylelint-config-standard-scss",
    "stylelint-config-twbs-bootstrap"
  ],
  "rules": {
    "scss/dollar-variable-pattern": null,
    "selector-class-pattern": [
      "^(custom-|c-)[a-z0-9]+(?:-[a-z0-9]+)*(?:__[a-z0-9]+(?:-[a-z0-9]+)*)?(?:--[a-z0-9]+(?:-[a-z0-9]+)*)?$",
      {
        "message": "Class kustom harus mengikuti pola custom-* atau c-* dengan BEM"
      }
    ],
    "max-nesting-depth": 3,
    "color-no-hex": null,
    "declaration-no-important": [true, {
      "severity": "warning"
    }]
  },
  "ignoreFiles": [
    "dist/**/*.css",
    "node_modules/**/*.scss"
  ]
}
```

```json
// package.json — Script dan husky/lint-staged
{
  "scripts": {
    "lint": "npm-run-all --parallel lint:js lint:css",
    "lint:js": "eslint 'src/js/**/*.js'",
    "lint:css": "stylelint 'src/scss/**/*.scss'",
    "lint:fix": "npm-run-all --parallel lint:js:fix lint:css:fix",
    "lint:js:fix": "eslint 'src/js/**/*.js' --fix",
    "lint:css:fix": "stylelint 'src/scss/**/*.scss' --fix"
  },
  "devDependencies": {
    "eslint": "^8.50.0",
    "eslint-config-airbnb-base": "^15.0.0",
    "stylelint": "^15.10.0",
    "stylelint-config-standard-scss": "^11.0.0",
    "stylelint-config-twbs-bootstrap": "^12.0.0",
    "husky": "^8.0.0",
    "lint-staged": "^15.0.0"
  },
  "lint-staged": {
    "*.js": "eslint --fix",
    "*.scss": "stylelint --fix"
  }
}
```

## Poin Penting
- ESLint untuk JavaScript, Stylelint untuk CSS/Sass — dua alat yang saling melengkapi
- Gunakan `stylelint-config-twbs-bootstrap` untuk aturan yang selaras dengan Bootstrap resmi
- Integrasikan dengan husky + lint-staged agar linter otomatis berjalan sebelum commit
- Jalankan linter di CI untuk mencegah kode berkualitas rendah masuk ke production
