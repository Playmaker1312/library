# Cara mengatur Vite untuk mengkompilasi Bootstrap Sass dengan cepat

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki layanan kilat untuk buku-buku yang paling sering dipinjam — buku-buku itu disimpan di rak depan dan bisa diambil dalam hitungan detik, bukan menit. Vite adalah layanan kilat untuk pengembangan web: ia menggunakan esbuild untuk preprocessing dan native ESM untuk serving, membuat kompilasi Sass terasa instan dibandingkan Webpack yang lebih lambat.

## Penjelasan Detail

Vite adalah build tool yang sangat cepat berkat pendekatan dev server yang menggunakan native ESM dan esbuild untuk pre-bundling. Untuk mengatur Bootstrap Sass dengan Vite, Anda hanya perlu menginstal `sass` sebagai devDependency dan konfigurasi entry point di `vite.config.js`. Vite secara otomatis mendeteksi file `.scss` dan mengkompilasinya. Untuk kustomisasi Bootstrap, buat file `custom.scss` yang mengimpor Bootstrap dan menimpa variabel Sass sebelumnya. Vite juga mendukung PostCSS melalui file `postcss.config.js`. Build untuk production menggunakan Rollup di bawah hood, menghasilkan output yang optimal. Keunggulan utama Vite adalah HMR (Hot Module Replacement) yang hampir instan saat mengubah file Sass.

## Contoh Kode Implementasi

```js
// vite.config.js
import { defineConfig } from 'vite';

export default defineConfig({
  css: {
    devSourcemap: true,
    preprocessorOptions: {
      scss: {
        additionalData: `@import "src/scss/variables-overrides";`,
      },
    },
  },
  build: {
    cssMinify: 'lightningcss',
    rollupOptions: {
      output: {
        manualChunks: {
          bootstrap: ['bootstrap'],
        },
      },
    },
  },
});
```

```scss
// src/scss/custom-bootstrap.scss
// 1. Impor functions Bootstrap (wajib pertama)
@import "bootstrap/scss/functions";

// 2. Override variabel Bootstrap
$primary: #7c3aed;
$enable-shadows: true;
$enable-gradients: true;

// 3. Impor Bootstrap
@import "bootstrap/scss/variables";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/utilities";
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
@import "bootstrap/scss/type";
@import "bootstrap/scss/images";
@import "bootstrap/scss/containers";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/helpers";
@import "bootstrap/scss/utilities/api";

// 4. Komponen Bootstrap yang dibutuhkan
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/card";
@import "bootstrap/scss/forms";
@import "bootstrap/scss/modal";
@import "bootstrap/scss/nav";
@import "bootstrap/scss/navbar";
```

## Poin Penting
- Vite menggunakan esbuild untuk preprocessing Sass yang sangat cepat saat development
- Hot Module Replacement (HMR) di Vite hampir instan untuk perubahan Sass
- Gunakan `additionalData` di `vite.config.js` untuk menyuntikkan shared variables ke setiap file SCSS
- Build production Vite menggunakan Rollup — hasilnya optimal dengan tree shaking dan code splitting
