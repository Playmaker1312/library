# Cara mengatur PostCSS bersama Bootstrap untuk autoprefixer

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki penerjemah otomatis yang mengubah buku ke dalam berbagai bahasa daerah sehingga bisa dibaca di seluruh wilayah. PostCSS dengan autoprefixer adalah penerjemah untuk CSS — ia menambahkan prefix vendor seperti `-webkit-`, `-moz-`, `-ms-` secara otomatis sehingga kode CSS modern bisa berjalan di semua browser.

## Penjelasan Detail

PostCSS adalah tool yang memproses CSS dengan plugin JavaScript. Autoprefixer adalah plugin paling umum yang menambahkan vendor prefix berdasarkan data dari Can I Use. Bootstrap sendiri menggunakan PostCSS dalam build system-nya. Untuk mengatur PostCSS bersama Bootstrap, instal `postcss` dan `autoprefixer`, lalu buat file konfigurasi `postcss.config.js`. Jika menggunakan Vite atau Webpack, postcss-loader akan otomatis menjalankan plugin PostCSS. Anda juga bisa menggunakan plugin PostCSS lain seperti `cssnano` untuk minifikasi, `postcss-preset-env` untuk fitur CSS masa depan, atau `postcss-rtl` untuk dukungan Right-to-Left. Autoprefixer membaca browserlist dari `package.json` atau file `.browserslistrc` untuk menentukan browser mana yang perlu diprefix.

## Contoh Kode Implementasi

```js
// postcss.config.js
module.exports = {
  plugins: [
    require('autoprefixer'),
    require('cssnano')({
      preset: ['default', {
        discardComments: {
          removeAll: true,
        },
      }],
    }),
  ],
};
```

```json
{
  "browserslist": [
    "last 2 versions",
    "> 0.5%",
    "not dead",
    "not op_mini all"
  ]
}
```

```json
{
  "name": "bootstrap-postcss",
  "scripts": {
    "build": "sass src/scss/main.scss dist/main.css --style=expanded && postcss dist/main.css --replace",
    "build:prod": "sass src/scss/main.scss dist/main.css --style=compressed && postcss dist/main.css --replace"
  },
  "dependencies": {
    "bootstrap": "^5.3.2"
  },
  "devDependencies": {
    "sass": "^1.69.0",
    "postcss": "^8.4.32",
    "postcss-cli": "^10.1.0",
    "autoprefixer": "^10.4.16",
    "cssnano": "^6.0.1"
  }
}
```

```scss

@import "bootstrap/scss/functions";
```

## Poin Penting
- Autoprefixer menambahkan prefix vendor berdasarkan data Can I Use dan konfigurasi browserslist
- Bootstrap sendiri menggunakan PostCSS + autoprefixer dalam build system resminya
- Kombinasikan autoprefixer dengan cssnano untuk minifikasi CSS production
- Tentukan browserslist di `package.json` atau `.browserslistrc` untuk kontrol target browser yang presisi
