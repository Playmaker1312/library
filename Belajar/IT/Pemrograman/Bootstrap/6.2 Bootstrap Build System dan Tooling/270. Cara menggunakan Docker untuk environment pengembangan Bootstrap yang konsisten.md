# Cara menggunakan Docker untuk environment pengembangan Bootstrap yang konsisten

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki ruang baca standar di setiap cabang — meja, kursi, pencahayaan, dan komputer yang identik. Pengunjung di mana pun mendapat pengalaman yang sama. Docker adalah ruang baca standar untuk development: container yang identik dengan semua tools dan dependency sudah terinstal, memastikan setiap anggota tim memiliki environment yang sama persis.

## Penjelasan Detail

Docker menyediakan environment terisolasi (container) yang berisi semua yang dibutuhkan project Bootstrap: Node.js, npm, Sass, PostCSS, dan tools lainnya. Dengan Docker, Anda menghindari masalah "works on my machine" karena setiap developer, tester, dan server CI menggunakan image yang sama. Buat `Dockerfile` yang mendefinisikan image, dan `docker-compose.yml` untuk mengatur multi-service (misalnya, web server + SASS watcher). Docker Compose bisa menjalankan development server dengan hot reload menggunakan volume mount. Untuk production, hasil build bisa disalin ke image Nginx atau langsung di-deploy.

## Contoh Kode Implementasi

```dockerfile
# Dockerfile — Image development untuk project Bootstrap
FROM node:20-alpine AS development

WORKDIR /app

# Copy package files
COPY package*.json ./

# Install dependencies
RUN npm ci --only=production && \
    npm cache clean --force

# Copy source code
COPY . .

# Ekspose port untuk dev server
EXPOSE 3000

# Default command
CMD ["npm", "run", "dev"]
```

```yaml
# docker-compose.yml — Multi-service environment
version: '3.8'

services:
  bootstrap-app:
    build:
      context: .
      target: development
    container_name: bootstrap-dev
    ports:
      - "3000:3000"
    volumes:
      - .:/app
      - /app/node_modules
    command: npm run dev
    environment:
      NODE_ENV: development
      CHOKIDAR_USEPOLLING: "true"  # Untuk hot reload di Docker

  bootstrap-build:
    build:
      context: .
      target: development
    container_name: bootstrap-build
    volumes:
      - .:/app
      - /app/node_modules
      - ./dist:/app/dist
    command: npm run build
    environment:
      NODE_ENV: production

  # Server Nginx untuk production preview
  nginx:
    image: nginx:alpine
    container_name: bootstrap-nginx
    ports:
      - "8080:80"
    volumes:
      - ./dist:/usr/share/nginx/html:ro
      - ./nginx/default.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      - bootstrap-build
```

```yaml
# docker-compose.ci.yml — Untuk CI pipeline yang lebih ringan
version: '3.8'
services:
  bootstrap-ci:
    image: node:20-alpine
    working_dir: /app
    volumes:
      - .:/app
    command: >
      sh -c "npm ci && npm run lint && npm run build"
```

```bash
# Perintah yang berguna untuk development dengan Docker

# Build image dan jalankan development
docker compose up bootstrap-app

# Build production
docker compose up bootstrap-build

# Preview production di Nginx
docker compose up nginx

# Hanya build
docker compose run --rm bootstrap-build

# Jalankan lint di container
docker compose run --rm bootstrap-app npm run lint

# Bersihkan container dan volume
docker compose down -v
```

```json
{
  "scripts": {
    "docker:dev": "docker compose up bootstrap-app",
    "docker:build": "docker compose up bootstrap-build",
    "docker:preview": "docker compose up nginx",
    "docker:lint": "docker compose run --rm bootstrap-app npm run lint",
    "docker:clean": "docker compose down -v"
  }
}
```

## Poin Penting
- Docker container memastikan environment pengembangan identik di semua mesin tim
- Gunakan volume mount untuk hot reload — perubahan file lokal langsung tercermin di container
- Multi-stage build di Dockerfile memisahkan development dan production
- Docker Compose memudahkan orkestrasi multi-service seperti app server + Nginx
