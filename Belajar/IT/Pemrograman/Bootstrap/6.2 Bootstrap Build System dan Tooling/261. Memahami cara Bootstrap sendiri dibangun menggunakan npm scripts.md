# Memahami cara Bootstrap sendiri dibangun menggunakan npm scripts

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki proses penerbitan buku yang terorganisir — dari naskah mentah, melewati editing, layout, proofreading, hingga cetak. Setiap tahap memiliki alat dan aturan sendiri. Bootstrap dibangun dengan cara yang sama: serangkaian npm scripts yang menjalankan berbagai tools secara berurutan untuk mengubah kode sumber Sass dan JavaScript menjadi file CSS dan JS yang siap pakai.

## Penjelasan Detail

Bootstrap menggunakan npm scripts yang didefinisikan di `package.json` sebagai pipeline build-nya. Proses dimulai dengan `npm run dist` yang memicu serangkaian task: clean direktori dist, kompilasi Sass ke CSS (dengan autoprefixer), minify CSS, bundle JavaScript dengan Rollup, minify JS, lalu generate source maps. Bootstrap juga menggunakan `npm-run-all` untuk menjalankan task paralel dan `hugo` untuk dokumentasi. Script `npm run watch` memantau perubahan file dan menjalankan ulang task terkait secara otomatis. Memahami pipeline ini membantu Anda mengadaptasi atau meniru proses build untuk project sendiri. Bootstrap menggunakan PostCSS dengan autoprefixer, cssnano untuk minifikasi, dan Rollup sebagai module bundler untuk JavaScript.

## Contoh Kode Implementasi

```json
{
  "scripts": {
    "dist": "npm-run-all --parallel dist-css dist-js",
    "dist-css": "npm-run-all --sequential css css-min css-rtl css-rtl-min",
    "dist-js": "npm-run-all --sequential js js-min js-bundle js-bundle-min",
    "css": "npm-run-all css-swap css-main css-print",
    "css-main": "sass src/scss/bootstrap.scss dist/css/bootstrap.css --style=expanded",
    "css-min": "sass src/scss/bootstrap.scss dist/css/bootstrap.min.css --style=compressed",
    "css-rtl": "postcss dist/css/bootstrap.css --dir dist/css --config build/postcss-rtl.config.js",
    "js": "rollup --config build/rollup.config.js --sourcemap",
    "js-min": "terser dist/js/bootstrap.js --output dist/js/bootstrap.min.js --compress --mangle --source-map",
    "css-autoprefixer": "postcss dist/css/*.css --use autoprefixer --replace",
    "watch": "nodemon --watch src/scss/ --ext scss --exec \"npm run css\"",
    "docs": "hugo --source docs/",
    "serve": "hugo server --source docs/",
    "lint": "npm-run-all --parallel lint-css lint-js",
    "lint-css": "stylelint \"src/scss/**/*.scss\"",
    "lint-js": "eslint \"src/js/**/*.js\""
  },
  "devDependencies": {
    "sass": "^1.69.0",
    "rollup": "^4.0.0",
    "postcss": "^8.4.0",
    "autoprefixer": "^10.4.0",
    "cssnano": "^6.0.0",
    "terser": "^5.24.0",
    "npm-run-all": "^4.1.5",
    "stylelint": "^15.10.0",
    "eslint": "^8.50.0"
  }
}
```

## Poin Penting
- Bootstrap menggunakan npm scripts sebagai task runner utama, bukan Gulp atau Webpack
- Pipeline CSS: Sass → PostCSS (autoprefixer) → cssnano (minify) → RTL
- Pipeline JS: Rollup (bundle) → Terser (minify)
- Script `dist` menjalankan semua task paralel dengan `npm-run-all` untuk efisiensi
