# Cara menggunakan source maps untuk debugging Bootstrap Sass

## Analogi: Perpustakaan Digital

Bayangkan Anda menemukan typo di buku digital. Tanpa source maps, Anda harus mencari di file PDF final yang sudah diterjemahkan — sulit menemukan sumber aslinya. Dengan source maps, seperti memiliki tautan langsung dari halaman PDF ke file dokumen asli (.docx). Setiap kali Anda melihat teks di PDF, Anda tahu persis di baris mana di dokumen asli teks itu ditulis.

## Penjelasan Detail

Source maps adalah file yang memetakan kode CSS (atau JavaScript) yang telah dikompilasi kembali ke kode sumber Sass asli. Ketika Bootstrap Sass dikompilasi, baris CSS di file output bisa sangat berbeda dari sumber SCSS. Source maps menjembatani kesenjangan ini — browser DevTools akan menunjukkan file SCSS asli dan nomor baris yang sesuai, bukan file CSS yang sudah dikompresi. Untuk mengaktifkan source maps di Bootstrap, tambahkan opsi `--source-map` saat kompilasi Sass. Di Webpack, atur `devtool: 'source-map'`. Di Vite, source maps diaktifkan secara default di development. Pastikan file `.map` tidak dihapus saat deployment (atau nonaktifkan untuk production).

## Contoh Kode Implementasi

```json
{
  "scripts": {
    "build:dev": "sass src/scss/main.scss:dist/css/main.css --style=expanded --source-map --source-map-urls=relative",
    "build:prod": "sass src/scss/main.scss:dist/css/main.min.css --style=compressed --no-source-map",
    "watch:dev": "sass --watch src/scss:dist/css --style=expanded --source-map --source-map-urls=relative"
  }
}
```

```js
// webpack.config.js — Source maps di Webpack
module.exports = {
  mode: 'development',
  devtool: 'source-map', // inline-source-map, hidden-source-map, dll.
  module: {
    rules: [
      {
        test: /\.scss$/,
        use: [
          'style-loader',
          {
            loader: 'css-loader',
            options: { sourceMap: true },
          },
          {
            loader: 'sass-loader',
            options: { sourceMap: true },
          },
        ],
      },
    ],
  },
};
```

```js
// vite.config.js — Source maps di Vite
import { defineConfig } from 'vite';

export default defineConfig({
  css: {
    devSourcemap: true,
  },
  build: {
    sourcemap: true, // true untuk production, false untuk faster build
  },
});
```

```scss
// src/scss/main.scss — Source maps akan memetakan ke file ini
@import "bootstrap/scss/functions";

$primary: #e63946;
$custom-bg: #f1faee;

@import "bootstrap/scss/variables";
@import "bootstrap/scss/bootstrap";

.custom-section {
  background-color: $custom-bg;
  padding: 2rem;

  .custom-title {
    color: $primary;
    font-size: 2rem;
  }

  .custom-text {
    color: $gray-700;
    line-height: 1.8;
  }
}
// Di Chrome DevTools -> Sources -> file SCSS ini akan muncul!
```

## Poin Penting
- Source maps memungkinkan debugging langsung di file SCSS asli melalui browser DevTools
- Aktifkan source maps di development saja; nonaktifkan di production untuk performa
- Gunakan `--source-map-urls=relative` agar path source maps relative terhadap file CSS
- Di browser DevTools, pastikan "Enable CSS source maps" diaktifkan di Settings
