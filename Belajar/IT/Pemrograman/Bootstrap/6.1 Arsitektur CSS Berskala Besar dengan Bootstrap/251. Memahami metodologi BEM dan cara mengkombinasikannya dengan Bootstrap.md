# Memahami metodologi BEM dan cara mengkombinasikannya dengan Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital menggunakan sistem penamaan buku yang konsisten: "Rak-Fiksi-Pengarang-Judul". Setiap elemen memiliki nama yang jelas menunjukkan fungsi dan posisinya. BEM (Block Element Modifier) adalah sistem penamaan CSS yang serupa, di mana setiap kelas menunjukkan blok, elemen, dan modifikasinya.

## Penjelasan Detail

BEM adalah metodologi penamaan kelas CSS yang terdiri dari Block (komponen), Element (bagian dari block), dan Modifier (variasi). Contoh: `card__title--large` (block=card, element=title, modifier=large). Bootstrap tidak menggunakan BEM, tetapi Anda bisa mengkombinasikannya dengan cara: gunakan Bootstrap untuk layout dan utility, dan BEM untuk komponen kustom. Hindari override kelas Bootstrap langsung; buat kelas BEM terpisah yang menggunakan Bootstrap melalui `@extend` atau komposisi.

## Contoh Kode Implementasi

```scss
// BEM + Bootstrap: Pendekatan komposisi
// Block: book-card
// Element: title, author, actions
// Modifier: featured, compact

.book-card {
  // Komposisi Bootstrap
  @extend .card;
  @extend .shadow-sm;
  border: none;
  transition: transform 0.2s;

  &__title {
    @extend .card-title;
    @extend .h5;
    color: var(--bs-primary);
  }

  &__author {
    @extend .card-text;
    @extend .text-muted;
    font-size: 0.875rem;
  }

  &__actions {
    @extend .card-footer;
    @extend .d-flex;
    @extend .justify-content-between;
    @extend .align-items-center;
    background: transparent;
  }

  &--featured {
    border-left: 4px solid var(--bs-warning);
  }

  &--compact {
    .book-card__title {
      font-size: 1rem;
    }
  }
}
```

## Poin Penting
- Gunakan Bootstrap untuk layout dan utility, BEM untuk komponen kustom
- Komposisi (gunakan Bootstrap classes di dalam BEM) lebih baik dari `@extend`
- Hindari override kelas Bootstrap langsung; buat kelas terpisah
