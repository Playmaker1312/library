# Membuat dokumentasi komponen internal menggunakan Storybook bersama Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki etalase buku yang menampilkan sampul, sinopsis, dan ulasan untuk setiap judul — memudahkan pengunjung memahami isi buku sebelum meminjam. Storybook adalah etalase untuk komponen UI Anda. Setiap komponen memiliki "cerita" sendiri yang menampilkan berbagai varian, properti, dan contoh penggunaan — sebuah showroom interaktif untuk library komponen internal tim.

## Penjelasan Detail

Storybook adalah alat pengembangan frontend yang mengisolasi komponen UI dan memungkinkan dokumentasi interaktif. Untuk mengintegrasikannya dengan Bootstrap, Anda perlu mengkonfigurasi Storybook dengan webpack atau Vite, mengimport styles Bootstrap global, dan menulis stories untuk setiap komponen kustom. Setiap story mendefinisikan varian komponen dengan argumen berbeda (props). Storybook mendukung addons seperti Controls (untuk mengubah props secara interaktif), Accessibility (untuk memeriksa aksesibilitas), dan Viewport (untuk menguji responsivitas). Dokumentasi komponen internal menjadi lebih mudah karena komponen bisa dilihat, diuji, dan direview tanpa perlu menjalankan aplikasi penuh.

## Contoh Kode Implementasi

```js
// custom-alert.stories.js — Storybook story untuk CustomAlert component
import React from 'react';
import 'bootstrap/dist/css/bootstrap.min.css';
import './custom-alert.scss';

export default {
  title: 'Custom/CustomAlert',
  component: CustomAlert,
  argTypes: {
    variant: {
      control: 'select',
      options: ['primary', 'success', 'warning', 'danger', 'info'],
      description: 'Variant warna alert',
    },
    dismissible: {
      control: 'boolean',
      description: 'Menampilkan tombol dismiss',
    },
    children: {
      control: 'text',
      description: 'Konten alert',
    },
  },
};

function CustomAlert({ variant = 'primary', dismissible = false, children = 'Ini adalah alert custom' }) {
  return (
    <div className={`custom-alert custom-alert--${variant}`} role="alert">
      <span className="custom-alert__icon">
        {variant === 'danger' ? '⚠️' : variant === 'success' ? '✓' : 'ℹ️'}
      </span>
      <span className="custom-alert__body">{children}</span>
      {dismissible && (
        <button type="button" className="custom-alert__dismiss" aria-label="Close">&times;</button>
      )}
    </div>
  );
}

// Stories
export const Primary = {
  args: {
    variant: 'primary',
    children: 'Ini alert primary untuk informasi umum.',
  },
};

export const Success = {
  args: {
    variant: 'success',
    children: 'Data berhasil disimpan!',
  },
};

export const WithDismiss = {
  args: {
    variant: 'warning',
    dismissible: true,
    children: 'Perhatian: sesi akan berakhir dalam 5 menit.',
  },
};
```

## Poin Penting
- Storybook mengisolasi komponen sehingga bisa dikembangkan dan diuji secara independen
- Gunakan Controls addon untuk mengubah props komponen secara interaktif tanpa menulis kode
- Integrasikan Bootstrap styles global melalui `.storybook/preview.js`
- Storybook juga bisa digunakan untuk visual regression testing dengan Chromatic atau Percy
