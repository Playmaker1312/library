# Cara mengorganisasi file Sass dalam project Bootstrap berskala besar

## Analogi: Perpustakaan Digital

Perpustakaan digital besar memiliki sistem pengarsipan yang rapi: buku dikelompokkan berdasarkan genre, penulis, dan rak. Setiap buku memiliki tempat yang jelas. Organisasi file Sass dalam project Bootstrap besar memerlukan struktur yang sama: terpisah, terkelompok, dan mudah ditemukan.

## Penjelasan Detail

Struktur file Sass yang baik untuk project Bootstrap besar meliputi: `abstracts/` (variables, mixins, functions Bootstrap), `base/` (reset, typography), `layout/` (grid, header, footer), `components/` (komponen Bootstrap + kustom), `pages/` (style spesifik halaman), `themes/` (dark mode, brand variants), dan `vendors/` (Bootstrap, libraries). Gunakan partial files dengan prefix `_` dan import di `main.scss`. Manfaatkan `@use` dan `@forward` (Sass modern) untuk modularitas.

## Contoh Kode Implementasi

```
src/scss/
├── abstracts/
│   ├── _variables.scss         # Bootstrap variables override
│   ├── _functions.scss         # Bootstrap functions
│   ├── _mixins.scss            # Bootstrap mixins + custom mixins
│   └── _placeholders.scss      # Custom %placeholders
├── base/
│   ├── _reset.scss             # Bootstrap reboot
│   ├── _typography.scss        # Bootstrap type + custom fonts
│   └── _animations.scss
├── layout/
│   ├── _grid.scss              # Bootstrap grid
│   ├── _header.scss
│   ├── _footer.scss
│   └── _sidebar.scss
├── components/
│   ├── _buttons.scss           # Bootstrap buttons + custom
│   ├── _cards.scss             # Bootstrap cards + custom
│   ├── _navbar.scss
│   ├── _book-card.scss         # Custom component
│   └── _search-bar.scss
├── pages/
│   ├── _home.scss
│   ├── _catalog.scss
│   └── _admin-dashboard.scss
├── themes/
│   ├── _light.scss
│   ├── _dark.scss
│   └── _brand-a.scss
├── vendors/
│   ├── _bootstrap.scss         # Bootstrap imports
│   └── _fontawesome.scss
└── main.scss                   # Entry point
```

```scss
// main.scss - Entry point
// Abstracts (tidak menghasilkan CSS)
@use 'abstracts/variables';
@use 'abstracts/functions';
@use 'abstracts/mixins';

// Vendors
@use 'vendors/bootstrap';

// Base
@use 'base/reset';
@use 'base/typography';

// Layout
@use 'layout/grid';
@use 'layout/header';
@use 'layout/footer';

// Components
@use 'components/buttons';
@use 'components/cards';
@use 'components/book-card';

// Pages
@use 'pages/home';
@use 'pages/catalog';

// Themes
@use 'themes/light';
@use 'themes/dark';
```

## Poin Penting
- Pisahkan file Sass berdasarkan fungsinya (abstracts, base, layout, components)
- Gunakan `@use` dan `@forward` untuk modularitas yang lebih baik
- Partial files (prefix `_`) tidak menghasilkan file CSS terpisah
