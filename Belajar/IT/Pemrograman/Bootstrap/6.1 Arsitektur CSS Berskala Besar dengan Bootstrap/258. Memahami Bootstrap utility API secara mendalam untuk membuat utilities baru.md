# Memahami Bootstrap utility API secara mendalam untuk membuat utilities baru

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada mesin pencari universal yang bisa mencari buku berdasarkan judul, penulis, tahun, atau kategori. Alih-alih membuat halaman terpisah untuk setiap jenis pencarian, cukup konfigurasi mesin pencari dengan parameter yang berbeda. Bootstrap utility API adalah mesin pencari semacam itu — satu fungsi yang menghasilkan ratusan utility classes berdasarkan konfigurasi yang Anda berikan.

## Penjelasan Detail

Bootstrap utility API adalah sistem yang sangat kuat untuk menghasilkan utility classes secara dinamis dari peta konfigurasi. Utility API menggunakan fungsi Sass `generate-utility()` yang membaca peta properti CSS, nilai-nilai, dan opsi seperti `responsive`, `important`, `print`, dan `class`. Dengan menambahkan entri ke `$utilities` map, Anda bisa membuat utility baru tanpa menulis CSS manual. Anda bisa meng-extend utility yang sudah ada dengan `merge` atau menambah yang baru sepenuhnya. Utility API mendukung nilai breakpoint responsive, pseudo-class states, dan penggunaan CSS custom properties. Ini adalah fondasi dari pendekatan utility-first yang membuat Bootstrap sangat efisien.

## Contoh Kode Implementasi

```scss
// custom-utilities.scss — Menambahkan utility baru via Bootstrap Utility API
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/utilities";

// 1. Menambahkan utility opacity kustom
$custom-utilities: (
  "opacity": (
    property: opacity,
    values: (
      0: 0,
      25: .25,
      50: .5,
      75: .75,
      100: 1,
    ),
    class: o,
  ),
  // 2. Utility text-shadow
  "text-shadow": (
    property: text-shadow,
    values: (
      none: none,
      sm: "0 1px 2px rgba(0,0,0,0.1)",
      md: "0 2px 4px rgba(0,0,0,0.15)",
      lg: "0 4px 8px rgba(0,0,0,0.2)",
    ),
    class: text-shadow,
  ),
  // 3. Utility cursor (responsive)
  "cursor": (
    property: cursor,
    values: pointer grab grabbing zoom-in zoom-out not-allowed,
    responsive: true,
    class: cursor,
  ),
  // 4. Utility rotate
  "rotate": (
    property: transform,
    values: (
      0: rotate(0deg),
      90: rotate(90deg),
      180: rotate(180deg),
      270: rotate(270deg),
    ),
    class: rotate,
  ),
);

// Gabungkan dengan utility Bootstrap yang sudah ada
$utilities: map-merge($utilities, $custom-utilities);

@import "bootstrap/scss/utilities/api";
```

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Custom Utilities Demo</title>
  <link href="custom-utilities.css" rel="stylesheet">
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container py-4">
    <div class="o-25">Opacity 25%</div>
    <div class="o-75">Opacity 75%</div>
    <div class="text-shadow-lg p-3 mb-2 bg-light">Large text shadow</div>
    <div class="cursor-pointer" onclick="alert('Clicked!')">Klik saya — cursor pointer</div>
    <div class="cursor-not-allowed">Tidak bisa diklik — cursor not-allowed</div>
    <div class="rotate-90 d-inline-block bg-primary text-white p-2 m-1">Rotate 90°</div>
    <div class="rotate-180 d-inline-block bg-secondary text-white p-2 m-1">Rotate 180°</div>
  </div>
</body>
</html>
```

## Poin Penting
- Utility API membaca dari `$utilities` map dan menghasilkan class secara otomatis
- Setiap utility bisa memiliki opsi `responsive`, `print`, `important`, dan `css-var`
- Gunakan `map-merge` untuk menambahkan utility baru tanpa menghapus yang sudah ada
- Utility API sangat mengurangi penulisan CSS repetitif dan mempercepat prototyping
