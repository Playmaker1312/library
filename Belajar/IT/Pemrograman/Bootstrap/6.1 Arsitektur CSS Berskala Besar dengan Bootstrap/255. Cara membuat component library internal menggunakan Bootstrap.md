# Cara membuat component library internal menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital adalah kumpulan buku yang terorganisir dengan sistem katalog, rak virtual, dan label kategori yang memudahkan pencarian. Setiap buku memiliki tempat tetap dan dapat dipinjam oleh siapa saja dalam organisasi. Demikian pula, component library internal adalah kumpulan komponen UI yang terstandarisasi, terdokumentasi, dan dapat digunakan kembali di seluruh project perusahaan.

## Penjelasan Detail

Component library internal dengan Bootstrap memungkinkan tim mengembangkan dan memelihara komponen UI yang konsisten tanpa memulai dari nol setiap project. Bootstrap menyediakan fondasi variabel, mixin, dan utility classes yang dapat diperluas. Langkah pertama adalah membuat package npm internal yang mengekspor komponen-komponen kustom. Gunakan Bootstrap Sass variables untuk mengatur tema dasar, lalu bangun komponen baru di atasnya dengan menambahkan class prefix khusus. Struktur folder yang disarankan: `src/`, `dist/`, `scss/` untuk styles, `js/` untuk interaktivitas, dan `docs/` untuk dokumentasi. Setiap komponen harus memiliki file Sass sendiri yang mengimpor dari Bootstrap core. Pastikan library di-versioning dengan semantic versioning dan dirilis melalui registry npm privat atau langsung dari repo Git.

## Contoh Kode Implementasi

```scss
// _custom-alert.scss — Komponen alert kustom untuk library internal
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/mixins";

$custom-alert-padding: $alert-padding-y $alert-padding-x;
$custom-alert-border-radius: $alert-border-radius;
$custom-alert-font-size: $font-size-sm;

.custom-alert {
  padding: $custom-alert-padding;
  border-radius: $custom-alert-border-radius;
  font-size: $custom-alert-font-size;
  border: 1px solid transparent;
  display: flex;
  align-items: center;
  gap: $spacer * 0.5;

  @each $color, $value in $theme-colors {
    &--#{$color} {
      background-color: tint-color($value, 80%);
      border-color: tint-color($value, 60%);
      color: shade-color($value, 40%);
    }
  }

  &__icon {
    flex-shrink: 0;
    width: 1.25em;
    height: 1.25em;
  }

  &__body {
    flex: 1;
  }

  &__dismiss {
    @extend .btn-close;
    width: 0.75em;
    height: 0.75em;
  }
}
```

```js
// custom-alert.js — Initialisasi komponen alert kustom
class CustomAlert {
  constructor(element) {
    this.element = element;
    this.dismissBtn = element.querySelector('.custom-alert__dismiss');
    this._bindEvents();
  }

  _bindEvents() {
    if (this.dismissBtn) {
      this.dismissBtn.addEventListener('click', () => this.dismiss());
    }
  }

  dismiss() {
    this.element.classList.add('custom-alert--dismissing');
    setTimeout(() => {
      this.element.remove();
    }, 300);
  }

  static init(selector = '.custom-alert') {
    document.querySelectorAll(selector).forEach(el => new CustomAlert(el));
  }
}

document.addEventListener('DOMContentLoaded', () => CustomAlert.init());
```

## Poin Penting
- Gunakan Sass variable Bootstrap sebagai fondasi theming agar komponen konsisten dengan ekosistem Bootstrap
- Prefix class dengan namespace unik seperti `.custom-` untuk menghindari bentrok dengan Bootstrap native
- Versioning library dengan semantic versioning dan publish ke registry npm privat seperti GitHub Packages atau Verdaccio
- Sertakan dokumentasi interaktif menggunakan Storybook atau Bootstrap sendiri sebagai reference implementation
