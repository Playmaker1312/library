# Membuat design system menggunakan Bootstrap sebagai fondasi

## Analogi: Perpustakaan Digital

Perpustakaan digital tidak hanya memiliki buku, tetapi juga panduan desain yang konsisten: ukuran font, warna, spacing, dan komponen yang seragam di seluruh halaman. Design system adalah panduan tersebut, dan Bootstrap adalah fondasi yang mempercepat pembuatannya.

## Penjelasan Detail

Design system adalah kumpulan komponen, pattern, dan panduan yang memastikan konsistensi visual dan fungsional. Bootstrap menyediakan fondasi yang kuat untuk design system: sistem grid, typography, color palette, spacing scale, dan komponen siap pakai. Untuk membuat design system: (1) Tentukan design tokens (warna, font, spacing) melalui Bootstrap variables, (2) Buat komponen dasar dari Bootstrap, (3) Kembangkan komponen kompleks dengan utility Bootstrap, (4) Dokumentasikan semuanya di Storybook atau vitrine.

## Contoh Kode Implementasi

```scss
// _design-tokens.scss - Design tokens sebagai Bootstrap variables
// Brand colors
$primary: #6C5CE7;
$secondary: #A29BFE;
$success: #00B894;
$info: #74B9FF;
$warning: #FDCB6E;
$danger: #E17055;
$dark: #2D3436;
$light: #DFE6E9;

// Typography scale
$font-family-base: 'Inter', sans-serif;
$font-family-heading: 'Poppins', sans-serif;
$font-size-base: 1rem;
$h1-font-size: $font-size-base * 2.5;
$h2-font-size: $font-size-base * 2;
$h3-font-size: $font-size-base * 1.75;

// Spacing scale (berbasis Bootstrap)
$spacer: 1rem;
$spacers: (
  0: 0,
  1: $spacer * .25,
  2: $spacer * .5,
  3: $spacer,
  4: $spacer * 1.5,
  5: $spacer * 3,
  6: $spacer * 4.5,
  7: $spacer * 6,
);

// Border radius
$border-radius: 0.5rem;
$border-radius-lg: 0.75rem;
$border-radius-sm: 0.25rem;

// Shadows
$box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
$box-shadow-lg: 0 8px 32px rgba(0, 0, 0, 0.12);
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Design System Bootstrap</title>
  <link href="design-system.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1 class="display-4">Design System</h1>
    <!-- Komponen konsisten dengan design tokens -->
    <button class="btn btn-primary btn-lg">Primary Action</button>
    <button class="btn btn-secondary">Secondary Action</button>
    <div class="card shadow my-4" style="border-radius: var(--bs-border-radius-lg);">
      <div class="card-body">
        <h5 class="card-title">Card dengan design tokens</h5>
        <p class="card-text">Menggunakan spacing, color, dan shadow dari design system.</p>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Bootstrap variables adalah fondasi design tokens (warna, font, spacing)
- Kembangkan komponen kompleks di atas Bootstrap yang sudah dikustomisasi
- Dokumentasikan design system dengan Storybook atau vitrine
