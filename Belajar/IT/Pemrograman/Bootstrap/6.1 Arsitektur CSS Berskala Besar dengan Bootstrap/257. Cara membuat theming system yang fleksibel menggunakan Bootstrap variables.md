# Cara membuat theming system yang fleksibel menggunakan Bootstrap variables

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki tema tampilan yang bisa disesuaikan — mode terang untuk siang hari, mode gelap untuk malam hari, dan tema warna korporat untuk tampilan resmi. Setiap tema hanyalah kumpulan pengaturan yang mengubah warna latar, warna teks, dan dekorasi secara serempak. Sistem theming Bootstrap bekerja persis seperti itu: sekumpulan variabel yang jika diubah akan merambat ke seluruh komponen.

## Penjelasan Detail

Theming system yang fleksibel dengan Bootstrap memanfaatkan dua lapis variabel: Sass variables untuk kompilasi dan CSS custom properties untuk runtime. Mulailah dengan mendefinisikan peta `$theme-colors` kustom di Sass, lalu buat variasi tema menggunakan Sass map operations. Untuk theming multi-tenant atau white-label, gunakan CSS custom properties yang diinisialisasi berdasarkan class tema. Bootstrap 5.3 memperkenalkan `_variables.scss` yang sangat modular — Anda bisa menimpa variabel individual tanpa mengubah file inti. Strategi efektif adalah membuat file `_theme-variables.scss` terpisah untuk setiap tema, lalu mengimportnya berdasarkan konteks. Jangan lupa menangani komponen kustom agar tetap sinkron dengan tema Bootstrap.

## Contoh Kode Implementasi

```scss
// _theme-variables.scss — Sistem theming multi-tema
// Tema default (light)
:root {
  --theme-bg: #ffffff;
  --theme-text: #212529;
  --theme-surface: #f8f9fa;
  --theme-border: #dee2e6;
}

// Tema dark
[data-theme="dark"] {
  --theme-bg: #212529;
  --theme-text: #f8f9fa;
  --theme-surface: #343a40;
  --theme-border: #495057;
}

// Tema corporate (biru korporat)
[data-theme="corporate"] {
  --bs-primary: #0d6efd;
  --bs-primary-rgb: 13, 110, 253;
  --theme-bg: #f0f4ff;
  --theme-text: #1a1a2e;
  --theme-surface: #ffffff;
  --theme-border: #c8d6e5;
}

// Tema forest (hijau alami)
[data-theme="forest"] {
  --bs-primary: #2d6a4f;
  --bs-primary-rgb: 45, 106, 79;
  --theme-bg: #f0f7f4;
  --theme-text: #1b4332;
  --theme-surface: #d8f3dc;
  --theme-border: #95d5b2;
}
```

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Multi-theme Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <link href="theme.css" rel="stylesheet">
</head>
<body>
  <div class="container py-4" style="background: var(--theme-bg); color: var(--theme-text); min-height: 100vh;">
    <div class="btn-group mb-4" role="group">
      <button class="btn btn-outline-primary" onclick="setTheme('light')">Light</button>
      <button class="btn btn-outline-primary" onclick="setTheme('dark')">Dark</button>
      <button class="btn btn-outline-primary" onclick="setTheme('corporate')">Corporate</button>
      <button class="btn btn-outline-primary" onclick="setTheme('forest')">Forest</button>
    </div>
    <div class="card" style="background: var(--theme-surface); border-color: var(--theme-border);">
      <div class="card-body">
        <h5 class="card-title">Kartu Multi-tema</h5>
        <p class="card-text">Konten kartu mengikuti tema yang dipilih secara real-time.</p>
        <button class="btn btn-primary">Tombol Primary</button>
      </div>
    </div>
  </div>
  <script>
    function setTheme(theme) {
      document.documentElement.setAttribute('data-theme', theme);
    }
  </script>
</body>
</html>
```

## Poin Penting
- Pisahkan definisi tema ke file `_theme-variables.scss` terpisah untuk maintainability
- Gunakan HTML `data-theme` attribute sebagai selector tema utama
- Theme corporate dan forest menunjukkan bagaimana `--bs-primary` bisa diubah per tema
- Pastikan komponen kustom juga menggunakan CSS custom properties agar konsisten saat tema berubah
