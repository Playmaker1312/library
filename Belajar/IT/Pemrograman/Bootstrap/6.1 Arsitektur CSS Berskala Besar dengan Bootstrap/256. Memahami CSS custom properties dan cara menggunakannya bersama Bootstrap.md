# Memahami CSS custom properties dan cara menggunakannya bersama Bootstrap

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada papan pengumuman pusat yang menampilkan informasi penting seperti jam buka, aturan peminjaman, dan denda keterlambatan. Jika ingin mengubah jam buka, cukup ubah di papan pusat dan semua pengunjung melihat perubahan itu. CSS custom properties seperti papan pengumuman itu — satu sumber kebenaran yang nilai-nilainya bisa diubah di satu tempat dan langsung berefek ke seluruh halaman.

## Penjelasan Detail

CSS custom properties (CSS variables) memungkinkan deklarasi nilai yang dapat digunakan ulang dan diubah secara dinamis, baik melalui media queries, JavaScript, maupun pseudo-class seperti `:root`. Bootstrap 5.3 mulai mengadopsi CSS custom properties secara luas untuk theming, termasuk untuk dark mode. Ketika digunakan bersama Bootstrap, CSS custom properties bisa menimpa nilai Sass variables secara runtime tanpa perlu rekompilasi. Bootstrap menyediakan `--bs-*` variables untuk setiap komponen utama. Anda bisa mendefinisikan custom properties di elemen tertentu untuk mengubah tampilan secara lokal. Keunggulan utama dibandingkan variables Sass adalah CSS custom properties dapat diubah di browser, memungkinkan theming real-time tanpa build step.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS Custom Properties + Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    :root {
      --bs-primary: #6f42c1;
      --bs-primary-rgb: 111, 66, 193;
      --custom-bg: #f8f9fa;
      --custom-radius: 0.75rem;
    }

    .card-custom {
      background-color: var(--custom-bg);
      border-radius: var(--custom-radius);
      border: 1px solid var(--bs-primary);
    }

    .theme-dark {
      --custom-bg: #212529;
      color: #fff;
    }

    .theme-dark .card-custom {
      --custom-bg: #343a40;
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <button class="btn btn-primary mb-3" onclick="toggleTheme()">Toggle Theme</button>
    <div class="card-custom p-4">
      <h5 class="card-title">Kartu dengan CSS Custom Properties</h5>
      <p class="card-text">Warna primary diubah menjadi ungu melalui <code>--bs-primary</code>.</p>
      <button class="btn btn-primary">Tombol Ungu</button>
    </div>
  </div>
  <script>
    function toggleTheme() {
      document.body.classList.toggle('theme-dark');
    }
  </script>
</body>
</html>
```

## Poin Penting
- CSS custom properties bisa diubah runtime via JavaScript, Sass variables tidak bisa
- Bootstrap 5.3+ menyediakan `--bs-*` variables untuk setiap komponen utama
- Custom properties bersifat inheritable — nilai dari induk diwarisi ke anak
- Kombinasikan Sass variables untuk build-time dan CSS custom properties untuk runtime customization
