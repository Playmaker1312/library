# Memahami metodologi SMACSS dalam konteks project Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital mengatur buku ke dalam kategori: referensi umum, komponen rak, tata letak halaman, dan tema dekorasi. Setiap kategori punya aturan penyimpanan sendiri. SMACSS (Scalable and Modular Architecture for CSS) adalah pendekatan pengorganisasian CSS yang serupa.

## Penjelasan Detail

SMACSS membagi CSS menjadi lima kategori: Base (style default, Bootstrap reboot), Layout (grid, container Bootstrap), Module (komponen seperti card, navbar), State (kelas seperti active, disabled), dan Theme (warna, font). Bootstrap secara alami mengikuti struktur ini. Dalam project besar, Anda bisa mengelompokkan file sesuai SMACSS: `_base.scss`, `_layout.scss`, `_components.scss`, `_state.scss`, `_theme.scss`. Bootstrap diimpor di base dan layout, sementara komponen kustom di module.

## Contoh Kode Implementasi

```
styles/
├── 1-base/
│   ├── _reset.scss
│   ├── _typography.scss
│   └── _bootstrap-base.scss   # Bootstrap reboot, type, root
├── 2-layout/
│   ├── _grid.scss             # Bootstrap grid & containers
│   └── _header.scss
├── 3-modules/
│   ├── _book-card.scss        # Komponen kustom
│   ├── _search-bar.scss
│   └── _pagination.scss
├── 4-state/
│   ├── _states.scss           # .is-active, .is-loading
│   └── _animations.scss
├── 5-theme/
│   ├── _variables.scss        # Bootstrap variables override
│   └── _dark-mode.scss
└── main.scss                  # @import semua file
```

```scss
// main.scss - SMACSS structure with Bootstrap
// 1. Base
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
@import "1-base/typography";

// 2. Layout
@import "bootstrap/scss/containers";
@import "bootstrap/scss/grid";
@import "2-layout/header";

// 3. Modules
@import "bootstrap/scss/nav";
@import "bootstrap/scss/navbar";
@import "bootstrap/scss/card";
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/forms";
@import "3-modules/book-card";

// 4. State
@import "bootstrap/scss/transitions";
@import "4-state/states";

// 5. Theme
@import "5-theme/variables";
@import "5-theme/dark-mode";

// Utilities
@import "bootstrap/scss/utilities";
@import "bootstrap/scss/utilities/api";
```

## Poin Penting
- SMACSS membagi CSS menjadi Base, Layout, Module, State, Theme
- Bootstrap secara alami mengikuti struktur SMACSS
- Organisasi file berdasarkan SMACSS memudahkan scaling project
