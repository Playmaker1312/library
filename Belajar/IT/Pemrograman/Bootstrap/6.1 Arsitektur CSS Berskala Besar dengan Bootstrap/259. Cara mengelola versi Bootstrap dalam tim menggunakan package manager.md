# Cara mengelola versi Bootstrap dalam tim menggunakan package manager

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki sistem katalog terpusat yang memastikan semua cabang perpustakaan menggunakan edisi buku yang sama. Jika satu cabang menggunakan edisi lama, buku bisa tidak kompatibel dengan sistem peminjaman terbaru. Package manager seperti npm atau yarn adalah katalog terpusat untuk library — memastikan seluruh tim menggunakan versi Bootstrap yang identik, menghindari konflik "works on my machine".

## Penjelasan Detail

Mengelola versi Bootstrap dalam tim memerlukan strategi yang matang menggunakan package manager. Simpan Bootstrap sebagai dependency di `package.json` dengan semver range yang ketat seperti `"bootstrap": "5.3.2"` (exact) atau `"bootstrap": "~5.3.0"` (patch-only). Gunakan lockfile (`package-lock.json` atau `yarn.lock`) untuk mengunci versi dependency. Untuk tim besar, pertimbangkan monorepo dengan tools seperti Lerna atau Nx. Pastikan semua anggota tim menggunakan Node.js dan npm versi yang sama via `.nvmrc` atau `.node-version`. Integrasikan renovate bot atau Dependabot untuk update otomatis Bootstrap. Untuk keamanan, gunakan npm audit secara berkala dan simpulasikan upgrade Bootstrap di branch terpisah sebelum merge ke main.

## Contoh Kode Implementasi

```json
{
  "name": "bootstrap-project",
  "version": "1.0.0",
  "private": true,
  "engines": {
    "node": ">=18.0.0",
    "npm": ">=9.0.0"
  },
  "scripts": {
    "start": "vite",
    "build": "vite build",
    "preview": "vite preview",
    "lint": "stylelint 'src/scss/**/*.scss'",
    "audit": "npm audit --production"
  },
  "dependencies": {
    "bootstrap": "5.3.2",
    "@popperjs/core": "2.11.8"
  },
  "devDependencies": {
    "sass": "^1.69.0",
    "vite": "^5.0.0",
    "stylelint": "^15.10.0",
    "stylelint-config-standard-scss": "^11.0.0"
  }
}
```

```bash
# .npmrc — Konfigurasi npm untuk konsistensi tim
save-exact=true
fund=false
audit-level=high
engine-strict=true
scripts-prepend-node-path=true
```

```
# .nvmrc — Memastikan semua anggota tim pakai Node.js versi sama
18.18.0
```

```yaml
# .github/dependabot.yml — Update otomatis Bootstrap via Dependabot
version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"
      day: "monday"
    open-pull-requests-limit: 5
    labels:
      - "dependencies"
      - "bootstrap"
    allow:
      - dependency-name: "bootstrap"
      - dependency-name: "@popperjs/core"
    commit-message:
      prefix: "chore(deps)"
```

## Poin Penting
- Tetapkan versi Bootstrap eksak (tanpa `^` atau `~`) untuk mencegah perbedaan tak terduga antar anggota tim
- Commit lockfile ke repository agar dependency reproducible
- Gunakan renovate bot atau Dependabot untuk notifikasi update Bootstrap secara otomatis
- Selalu uji upgrade Bootstrap di branch terpisah dan lakukan visual regression testing
