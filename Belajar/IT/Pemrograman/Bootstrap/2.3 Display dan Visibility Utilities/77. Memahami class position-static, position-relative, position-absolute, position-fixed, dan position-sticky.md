# Memahami class position-static, position-relative, position-absolute, position-fixed, dan position-sticky

## Analogi: Perpustakaan Digital

Buku di perpustakaan bisa ditempatkan dengan berbagai cara: static seperti buku di rak biasa, relative seperti buku yang digeser sedikit dari posisi normalnya, absolute seperti buku yang ditempel di papan pengumuman, fixed seperti jam dinding yang selalu terlihat, sticky seperti label yang menempel di rak saat digulir. Bootstrap menyediakan class position untuk semua kebutuhan ini.

## Penjelasan Detail

Class position utility Bootstrap: `position-static` (default), `position-relative`, `position-absolute`, `position-fixed`, `position-sticky`. `position-relative` memungkinkan elemen digeser menggunakan top/bottom/start/end tanpa mempengaruhi elemen lain. `position-absolute` memposisikan elemen relatif terhadap parent terdekat yang relative. `position-fixed` memposisikan elemen tetap relatif terhadap viewport. `position-sticky` menggabungkan relative dan fixed: elemen mengalir normal hingga scroll mencapai threshold. Biasanya dikombinasikan dengan `top-0`, `bottom-0`, `start-0`, `end-0`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Position Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .parent { height: 200px; background: #f8f9fa; border: 2px dashed #dee2e6; margin-bottom: 1rem; }
        .box { width: 100px; height: 50px; color: white; display: flex; align-items: center; justify-content: center; }
    </style>
</head>
<body class="p-4" style="height:150vh;">
    <div class="container">
        <h1>Position Utilities</h1>
        <div class="parent position-relative">
            <div class="box bg-primary position-static">static</div>
            <div class="box bg-success position-relative top-2 start-2">relative</div>
            <div class="box bg-danger position-absolute top-0 end-0">absolute</div>
        </div>
        <div class="box bg-warning text-dark position-fixed bottom-0 start-0">fixed</div>
        <div class="box bg-info text-dark position-sticky top-0" style="z-index:100;">sticky</div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- position-relative untuk menggeser elemen dari posisi normalnya
- position-absolute relatif terhadap parent position-relative
- position-fixed tetap di viewport, position-sticky menempel saat scroll
