# Memahami class z-index utilities dalam Bootstrap

## Analogi: Perpustakaan Digital

Di perpustakaan, beberapa buku dan rak mungkin bertumpuk. Buku yang paling penting harus berada di atas tumpukan agar terlihat pertama. z-index utility Bootstrap mengatur lapisan tumpukan elemen, seperti menentukan buku mana yang berada di atas dalam tumpukan rak.

## Penjelasan Detail

Class z-index utility Bootstrap: `z-0`, `z-1`, `z-2`, `z-3`, dan `z-5`. Nilai yang lebih tinggi berarti elemen berada di lapisan lebih depan (lebih dekat ke pengguna). Class ini mengatur properti CSS `z-index`. z-index hanya berfungsi pada elemen dengan position non-static (relative, absolute, fixed, sticky). Bootstrap juga menggunakan z-index untuk komponen seperti modal (z-1050), offcanvas (z-1045), dropdown (z-1000), dan tooltip (z-1080). Nilai default adalah z-0. Class utility ini berguna untuk mengatur tumpukan elemen kustom.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Z-Index Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .parent { position: relative; height: 150px; background: #f8f9fa; border: 2px dashed #dee2e6; }
        .box { position: absolute; width: 100px; height: 60px; display: flex; align-items: center; justify-content: center; color: white; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Z-Index Utilities</h1>
        <div class="parent">
            <div class="box bg-danger z-0" style="top:10px; left:10px;">z-0</div>
            <div class="box bg-primary z-1" style="top:30px; left:30px;">z-1</div>
            <div class="box bg-success z-2" style="top:50px; left:50px;">z-2</div>
            <div class="box bg-warning text-dark z-3" style="top:70px; left:70px;">z-3</div>
            <div class="box bg-info text-dark z-5" style="top:90px; left:90px;">z-5 (teratas)</div>
        </div>
        <div class="position-relative mt-4 p-4 border" style="height:80px;">
            <div class="position-absolute bottom-0 end-0 bg-primary text-white p-2 z-3">z-3 di atas</div>
            <div class="position-absolute bottom-0 end-0 bg-danger text-white p-2 z-1" style="right:20px;">z-1 di bawah</div>
        </div>
        <p class="text-muted mt-2">z-index lebih tinggi tampil di depan.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- z-0 hingga z-5 dengan z-5 sebagai nilai tertinggi utility
- Hanya berfungsi pada elemen dengan position non-static
- Komponen Bootstrap seperti modal memiliki z-index sendiri (1050+)
