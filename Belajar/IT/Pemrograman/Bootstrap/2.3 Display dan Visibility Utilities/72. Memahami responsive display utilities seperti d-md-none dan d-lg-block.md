# Memahami responsive display utilities seperti d-md-none dan d-lg-block

## Analogi: Perpustakaan Digital

Perpustakaan memiliki rak yang bisa diatur kemunculannya berdasarkan ukuran pengunjung. Rak besar (d-lg-block) hanya muncul untuk pengunjung dengan layar lebar, rak kecil (d-md-none) disembunyikan saat layar medium. Seperti perabot perpustakaan yang bisa ditata ulang tergantung ruang yang tersedia.

## Penjelasan Detail

Responsive display utilities menggunakan format `d-{breakpoint}-{value}` untuk mengatur display pada breakpoint tertentu. Breakpoint: sm, md, lg, xl, xxl. Contoh: `d-md-none` menyembunyikan elemen pada layar md ke atas, `d-lg-block` membuat elemen block hanya pada lg ke atas. Class tanpa breakpoint (d-block) berlaku untuk semua ukuran. Pola umum: `d-none d-lg-block` untuk elemen yang hanya muncul di desktop, dan `d-block d-md-none` untuk elemen yang hanya muncul di mobile. Ini memungkinkan responsive design tanpa CSS media queries manual.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Display</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { padding: 1rem; text-align: center; margin-bottom: 0.5rem; color: white; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Responsive Display</h1>
        <div class="box bg-primary d-none d-sm-block">d-none d-sm-block (muncul dari sm ke atas)</div>
        <div class="box bg-success d-block d-md-none">d-block d-md-none (hilang di md ke atas)</div>
        <div class="box bg-warning text-dark d-none d-lg-block">d-none d-lg-block (hanya desktop lg+)</div>
        <div class="box bg-danger d-xl-none">d-xl-none (hilang di xl ke atas)</div>
        <div class="box bg-info text-dark d-none d-xxl-block">d-none d-xxl-block (hanya xxl+)</div>
        <hr>
        <p class="text-muted">Coba resize browser untuk melihat perubahan.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Format: d-{breakpoint}-{nilai} dengan breakpoint sm, md, lg, xl, xxl
- d-none d-lg-block = sembunyi di mobile, muncul di desktop
- d-block d-md-none = muncul di mobile, sembunyi di tablet/desktop
