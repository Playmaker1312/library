# Menggunakan class d-grid untuk mengaktifkan CSS grid

## Analogi: Perpustakaan Digital

Rak buku dengan sistem grid seperti rak yang terbagi dalam baris dan kolom, memungkinkan buku ditata dalam formasi tabel yang rapi. d-grid mengaktifkan layout grid dua dimensi pada container, seperti mengatur buku dalam baris dan kolom sekaligus, tidak hanya satu arah seperti flexbox.

## Penjelasan Detail

Class `d-grid` mengatur `display: grid` pada elemen. Setelah aktif, class utility grid Bootstrap seperti `gap-*`, `grid-cols-*` (di Bootstrap 5), dan properti grid CSS bisa digunakan. Bootstrap tidak menyediakan class grid utility sebanyak flexbox, tetapi d-grid memungkinkan penggunaan CSS Grid murni. Grid cocok untuk layout dua dimensi (baris dan kolom). Biasanya dikombinasikan dengan `grid-template-columns` CSS atau class `row-cols-*` Bootstrap. d-grid juga mendukung responsive breakpoint.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>d-grid</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #198754; color: white; padding: 1rem; text-align: center; border-radius: 4px; }
        .grid-demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>d-grid (CSS Grid)</h1>
        <div class="grid-demo d-grid" style="grid-template-columns: repeat(3, 1fr);">
            <div class="item">Kolom 1</div>
            <div class="item">Kolom 2</div>
            <div class="item">Kolom 3</div>
            <div class="item">Kolom 4</div>
            <div class="item">Kolom 5</div>
            <div class="item">Kolom 6</div>
        </div>
        <div class="grid-demo d-grid gap-3" style="grid-template-columns: 2fr 1fr;">
            <div class="item">2fr (lebih lebar)</div>
            <div class="item">1fr</div>
            <div class="item">2fr (turun ke baris baru)</div>
            <div class="item">1fr</div>
        </div>
        <div class="grid-demo d-grid d-md-grid" style="grid-template-columns: repeat(auto-fill, minmax(100px, 1fr));">
            <div class="item">A</div>
            <div class="item">B</div>
            <div class="item">C</div>
            <div class="item">D</div>
            <div class="item">E</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- d-grid mengaktifkan CSS Grid pada container
- Grid adalah layout dua dimensi (baris dan kolom sekaligus)
- Kombinasikan dengan CSS grid-template-columns untuk menentukan kolom
