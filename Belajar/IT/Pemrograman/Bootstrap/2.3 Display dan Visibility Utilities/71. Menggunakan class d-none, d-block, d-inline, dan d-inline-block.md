# Menggunakan class d-none, d-block, d-inline, dan d-inline-block

## Analogi: Perpustakaan Digital

Rak buku di perpustakaan bisa muncul atau hilang dari pandangan pengunjung. d-none membuat rak tidak terlihat dan tidak memakan ruang, d-block membuat rak tampil sebagai blok penuh, d-inline membuat rak sejajar dengan rak lain, dan d-inline-block menggabungkan sifat keduanya. Pustakawan bisa memilih mode tampilan yang sesuai.

## Penjelasan Detail

Class display utility Bootstrap mengatur properti CSS `display`. `d-none` menyembunyikan elemen (display: none), `d-block` membuat elemen sebagai block (display: block) yang memenuhi lebar parent, `d-inline` membuat elemen inline sejajar dengan teks, dan `d-inline-block` membuat elemen inline tapi bisa diatur lebar/tinggi. Class display bisa responsif dengan breakpoint: `d-md-block`, `d-lg-none`. d-none sering digunakan untuk menyembunyikan elemen pada ukuran layar tertentu. d-block berguna untuk membuat elemen seperti div tampil sebagai block. d-inline berguna untuk elemen dalam teks.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Display Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .demo { background-color: #e9ecef; border: 1px solid #ced4da; padding: 0.5rem; margin-bottom: 0.5rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Display Utilities</h1>
        <div class="demo d-block">d-block (lebar penuh)</div>
        <div class="demo d-inline">d-inline (sejajar)</div>
        <div class="demo d-inline">d-inline (juga inline)</div>
        <div class="demo d-inline-block" style="width:150px">d-inline-block (150px)</div>
        <div class="demo d-none">d-none (tidak terlihat)</div>
        <p class="mt-3">Elemen d-none di atas tidak memakan ruang.</p>
        <div class="d-block d-md-none bg-warning p-2">Hanya terlihat di layar kecil (d-md-none)</div>
        <div class="d-none d-md-block bg-info p-2">Hanya terlihat di layar md+</div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- d-none menyembunyikan elemen, d-block lebar penuh, d-inline sejajar teks, d-inline-block inline dengan dimensi
- Semua class display bisa dikombinasikan dengan breakpoint responsif
- d-none berbeda dengan invisible: d-none menghilangkan ruang elemen
