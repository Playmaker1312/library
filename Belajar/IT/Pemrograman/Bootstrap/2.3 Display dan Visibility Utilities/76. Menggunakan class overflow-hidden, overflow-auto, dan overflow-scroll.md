# Menggunakan class overflow-hidden, overflow-auto, dan overflow-scroll

## Analogi: Perpustakaan Digital

Rak buku yang terlalu penuh bisa diatur bagaimana menangani buku yang meluap. overflow-hidden memotong buku yang meluber, overflow-auto menambahkan scrollbar jika diperlukan, overflow-scroll selalu menampilkan scrollbar. Seperti pengelola rak yang memutuskan apakah buku yang menonjol dipotong, digulir, atau selalu siap digulir.

## Penjelasan Detail

Class overflow utility Bootstrap mengatur properti CSS `overflow`. `overflow-auto` menambahkan scrollbar otomatis saat konten meluap. `overflow-hidden` memotong konten yang melampaui batas elemen. `overflow-scroll` selalu menampilkan scrollbar. `overflow-visible` menampilkan konten yang meluap. Juga tersedia varian per sumbu: `overflow-x-auto`, `overflow-y-hidden`, dll. Sangat berguna untuk container dengan ukuran tetap yang berisi konten dinamis, seperti panel chat, card dengan teks panjang, atau tabel dalam container.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Overflow Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { width: 200px; height: 80px; background-color: #f8f9fa; border: 2px solid #dee2e6; display: inline-block; margin-right: 1rem; margin-bottom: 1rem; }
        .content { width: 300px; padding: 0.5rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Overflow Utilities</h1>
        <div>
            <div class="box overflow-auto">
                <div class="content">overflow-auto: scrollbar muncul jika perlu. Teks panjang ini akan membuat scrollbar.</div>
            </div>
            <div class="box overflow-hidden">
                <div class="content">overflow-hidden: teks panjang akan terpotong dan tidak terlihat.</div>
            </div>
            <div class="box overflow-scroll">
                <div class="content">overflow-scroll: scrollbar selalu ada.</div>
            </div>
            <div class="box overflow-visible" style="height:auto">
                <div class="content">overflow-visible: konten meluap keluar batas.</div>
            </div>
        </div>
        <div class="overflow-auto border mt-3" style="max-height:100px; width:300px;">
            <p>Paragraf 1: Lorem ipsum dolor sit amet.</p>
            <p>Paragraf 2: Konten tambahan.</p>
            <p>Paragraf 3: Lebih banyak konten.</p>
            <p>Paragraf 4: Masih ada lagi.</p>
            <p>Paragraf 5: Akhir dari konten.</p>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- overflow-auto: scrollbar otomatis saat konten meluap
- overflow-hidden: memotong konten yang meluap
- overflow-scroll: selalu menampilkan scrollbar
