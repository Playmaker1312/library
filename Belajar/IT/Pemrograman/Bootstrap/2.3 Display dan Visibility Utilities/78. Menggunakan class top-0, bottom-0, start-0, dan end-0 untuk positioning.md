# Menggunakan class top-0, bottom-0, start-0, dan end-0 untuk positioning

## Analogi: Perpustakaan Digital

Paku payung di papan pengumuman perpustakaan bisa ditempel di pojok kiri atas (top-0, start-0), pojok kanan bawah (bottom-0, end-0), atau di tengah. Bootstrap menyediakan class positioning untuk menempatkan elemen tepat di tepi container seperti paku payung yang ditempel di posisi presisi.

## Penjelasan Detail

Class `top-0`, `bottom-0`, `start-0`, dan `end-0` mengatur properti CSS `top`, `bottom`, `left`, `right` ke nilai 0. Class ini bekerja dengan elemen yang memiliki position non-static (relative, absolute, fixed, atau sticky). Juga tersedia `top-50` dan `start-50` untuk posisi 50%, serta `translate-middle` untuk centering sempurna. Kombinasi umum: `position-absolute top-0 end-0` untuk menempatkan elemen di pojok kanan atas, `position-absolute bottom-0 start-0` untuk pojok kiri bawah. Sangat berguna untuk badge, tombol close, overlay, dan elemen floating lainnya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Positioning Top Bottom Start End</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .parent { height: 200px; background: #f8f9fa; border: 2px solid #dee2e6; position: relative; margin-bottom: 1rem; }
        .badge-demo { width: 80px; height: 30px; display: flex; align-items: center; justify-content: center; color: white; font-size: 0.75rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Top, Bottom, Start, End</h1>
        <div class="parent">
            <div class="badge-demo bg-primary position-absolute top-0 start-0">top-0 start-0</div>
            <div class="badge-demo bg-success position-absolute top-0 end-0">top-0 end-0</div>
            <div class="badge-demo bg-danger position-absolute bottom-0 start-0">bottom-0 start-0</div>
            <div class="badge-demo bg-warning text-dark position-absolute bottom-0 end-0">bottom-0 end-0</div>
            <div class="badge-demo bg-info text-dark position-absolute top-50 start-50 translate-middle">center</div>
        </div>
        <div class="card" style="width:300px;">
            <div class="card-body position-relative">
                <h5 class="card-title">Card dengan Badge</h5>
                <p class="card-text">Badge di pojok kanan atas card.</p>
                <span class="badge bg-danger position-absolute top-0 end-0 translate-middle">99+</span>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- top-0, bottom-0, start-0, end-0 untuk menempelkan elemen ke tepi
- Harus dikombinasikan dengan position non-static
- top-50 + start-50 + translate-middle untuk centering sempurna
