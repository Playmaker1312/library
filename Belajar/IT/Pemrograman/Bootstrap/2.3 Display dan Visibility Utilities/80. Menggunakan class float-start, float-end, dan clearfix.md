# Menggunakan class float-start, float-end, dan clearfix

## Analogi: Perpustakaan Digital

Di perpustakaan, beberapa buku bisa ditempatkan mengapung di sisi kiri atau kanan rak, sementara buku lain mengalir di sekitarnya. float-start membuat elemen mengapung ke kiri, float-end ke kanan, seperti buku yang ditempel ke sisi rak. clearfix membersihkan gangguan float agar rak kembali normal.

## Penjelasan Detail

Class `float-start` mengatur `float: left`, `float-end` mengatur `float: right`. `clearfix` adalah class utility yang membersihkan float dengan pseudo-element CSS. Float berguna untuk membungkus teks di sekitar gambar atau elemen. Namun, flexbox dan grid lebih direkomendasikan untuk layout modern. Bootstrap juga menyediakan float responsif: `float-md-start`, `float-lg-end`. clearfix diterapkan pada parent container yang memiliki anak float. Tanpa clearfix, parent bisa collapse (tinggi 0).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Float dan Clearfix</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Float & Clearfix</h1>
        <div class="clearfix border p-3 mb-4 bg-light">
            <div class="float-start bg-primary text-white p-3 me-2">float-start</div>
            <div class="float-end bg-success text-white p-3 ms-2">float-end</div>
            <p>Teks ini mengalir di sekitar elemen float. Setelah clearfix, container tidak collapse.</p>
        </div>
        <div class="border p-3 mb-4 bg-light">
            <div class="float-start bg-warning text-dark p-3 me-2">Gambar Float</div>
            <p>Teks membungkus gambar yang difloat ke kiri. Tanpa clearfix, parent tetap memiliki tinggi karena konten teks.</p>
            <div class="clearfix"></div>
            <p class="mt-2">Setelah clearfix, float dibersihkan dan elemen berikutnya turun.</p>
        </div>
        <div class="float-none text-center">float-none (default)</div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- float-start = float: left, float-end = float: right
- clearfix membersihkan float pada parent container
- Float responsif: float-{breakpoint}-{start|end}
