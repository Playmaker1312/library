# Memahami class visible dan invisible untuk visibility

## Analogi: Perpustakaan Digital

Rak buku di perpustakaan bisa dibuat transparan sehingga pengunjung tahu ada rak di sana tapi tidak bisa melihat isinya. invisible menyembunyikan elemen secara visual tetapi tetap mempertahankan ruangnya, berbeda dengan d-none yang menghilangkan ruang. visible mengembalikan tampilan elemen seperti semula.

## Penjelasan Detail

Class `visible` mengatur `visibility: visible` dan class `invisible` mengatur `visibility: hidden`. Perbedaan utama dengan d-none: invisible menyembunyikan konten visual tetapi elemen tetap mempertahankan dimensi dan ruangnya di layout. d-none menghilangkan elemen sepenuhnya dari flow dokumen (display: none). invisible berguna saat ingin menyembunyikan elemen tetapi tetap mempertahankan tata letak halaman, misalnya untuk placeholder, loading state, atau animasi transisi. visible mengembalikan elemen ke keadaan tampak.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Visible dan Invisible</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { width: 120px; height: 60px; background-color: #0d6efd; color: white; display: inline-flex; align-items: center; justify-content: center; margin: 0.5rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Visible & Invisible</h1>
        <div class="d-flex align-items-center">
            <div class="box">Terlihat</div>
            <div class="box invisible">Invisible (ruang tetap)</div>
            <div class="box">Terlihat</div>
            <div class="box d-none">d-none (ruang hilang)</div>
            <div class="box">Terlihat</div>
        </div>
        <p class="mt-3">
            <button class="btn btn-primary me-2" onclick="this.nextElementSibling.classList.toggle('invisible')">Toggle Invisible</button>
            <span class="badge bg-success">Elemen ini bisa disembunyikan</span>
        </p>
        <p>
            <button class="btn btn-outline-secondary me-2" onclick="toggleBox()">Toggle Visible Class</button>
            <span id="toggleBox" class="badge bg-warning text-dark">Toggle saya</span>
        </p>
    </div>
    <script>
        function toggleBox() { document.getElementById('toggleBox').classList.toggle('invisible'); }
    </script>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- invisible = visibility: hidden (ruang tetap ada)
- d-none = display: none (ruang hilang)
- visible mengembalikan elemen ke tampilan normal
