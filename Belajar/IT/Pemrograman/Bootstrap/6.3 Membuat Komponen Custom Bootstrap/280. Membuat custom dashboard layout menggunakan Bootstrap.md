# Membuat custom dashboard layout menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki halaman admin yang menampilkan: ringkasan statistik (total buku, anggota, peminjaman), grafik tren, tabel data terbaru, dan notifikasi — semua dalam satu layar terorganisir. Dashboard adalah pusat kendali yang menyajikan informasi penting secara ringkas dan terstruktur.

## Penjelasan Detail

Dashboard layout dengan Bootstrap menggunakan kombinasi grid system, card, dan komponen Bootstrap lainnya. Layout umum dashboard terdiri dari: sidebar navigasi (kiri), header (atas dengan search dan user menu), main content area (tengah dengan grid card/kartu statistik), dan panel notifikasi (kanan, opsional). Gunakan Bootstrap offcanvas atau collapse untuk sidebar responsif di mobile. Kartu statistik menggunakan `col-sm-6 col-lg-3` untuk grid 4 kolom di desktop. Setiap kartu menampilkan ikon, angka, label, dan perubahan (trend). Grafik menggunakan Chart.js yang ditempatkan dalam card. Tabel data di bagian bawah dengan `.table-responsive`.

## Poin Penting
- Dashboard layout terdiri dari sidebar fixed, header, grid stat cards, chart, dan tabel
- Gunakan `col-sm-6 col-lg-3` untuk grid 4 kartu statistik yang responsif
- Sidebar menggunakan offcanvas/collapse pattern untuk mobile dengan toggle button
- Integrasi Chart.js dalam card Bootstrap untuk visualisasi data yang informatif
