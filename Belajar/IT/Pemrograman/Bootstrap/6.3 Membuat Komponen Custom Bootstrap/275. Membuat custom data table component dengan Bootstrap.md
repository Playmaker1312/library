# Membuat custom data table component dengan Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki katalog buku yang bisa diurutkan berdasarkan judul, penulis, atau tahun. Pengunjung bisa mencari buku, menyaring berdasarkan genre, dan melihat detail dengan cepat. Data table component adalah katalog interaktif untuk data tabular — bukan sekadar tabel statis, tapi alat pencarian, sorting, dan filtering data.

## Penjelasan Detail

Custom data table component melengkapi Bootstrap table dengan fungsionalitas interaktif. Fitur utama meliputi: sorting kolom (asc/desc), pencarian/search, pagination, row selection, dan responsive table (horizontal scroll di mobile). Gunakan Bootstrap table classes (`table`, `table-striped`, `table-hover`) sebagai dasar. Tambahkan event listener JavaScript untuk sorting dan searching. Untuk dataset besar, gunakan pagination dengan Bootstrap pagination component. Pastikan tabel tetap terbaca di layar kecil dengan `table-responsive` dan card-like layout untuk mobile. Pertimbangkan virtual scrolling untuk ribuan baris.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Custom Data Table</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    .data-table th {
      cursor: pointer;
      user-select: none;
      white-space: nowrap;
    }
    .data-table th .sort-icon {
      margin-left: 0.25rem;
      opacity: 0.4;
    }
    .data-table th.asc .sort-icon::after { content: ' ▲'; opacity: 1; }
    .data-table th.desc .sort-icon::after { content: ' ▼'; opacity: 1; }
    .data-table .search-box {
      max-width: 300px;
    }
    @media (max-width: 767px) {
      .data-table-card {
        border: 1px solid #dee2e6;
        border-radius: 0.5rem;
        padding: 1rem;
        margin-bottom: 1rem;
      }
      .data-table-card .label {
        font-weight: 600;
        color: #6c757d;
      }
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <div class="d-flex justify-content-between align-items-center mb-3">
      <h4 class="mb-0">📚 Daftar Buku</h4>
      <input type="text" class="form-control search-box" id="searchInput" placeholder="Cari judul/penulis...">
    </div>

    <div class="table-responsive">
      <table class="table table-hover align-middle data-table" id="bookTable">
        <thead class="table-light">
          <tr>
            <th data-sort="title">Judul<span class="sort-icon"></span></th>
            <th data-sort="author">Penulis<span class="sort-icon"></span></th>
            <th data-sort="year">Tahun<span class="sort-icon"></span></th>
            <th data-sort="rating">Rating<span class="sort-icon"></span></th>
            <th>Aksi</th>
          </tr>
        </thead>
        <tbody id="tableBody"></tbody>
      </table>
    </div>

    <nav><ul class="pagination justify-content-center" id="pagination"></ul></nav>
  </div>

  <script>
    const books = [
      { title: 'Bootstrap 5 Mastery', author: 'John Doe', year: 2024, rating: 4.8 },
      { title: 'Sass for Beginners', author: 'Jane Smith', year: 2023, rating: 4.5 },
      { title: 'JavaScript Deep Dive', author: 'Bob Johnson', year: 2024, rating: 4.9 },
      { title: 'CSS Architecture', author: 'Alice Williams', year: 2022, rating: 4.3 },
      { title: 'Web Accessibility Guide', author: 'Charlie Brown', year: 2023, rating: 4.7 },
    ];

    let currentSort = { key: null, dir: 'asc' };
    let filteredBooks = [...books];
    let currentPage = 1;
    const perPage = 3;

    function renderTable() {
      const search = document.getElementById('searchInput').value.toLowerCase();
      filteredBooks = books.filter(b =>
        b.title.toLowerCase().includes(search) || b.author.toLowerCase().includes(search)
      );
      if (currentSort.key) {
        filteredBooks.sort((a, b) => {
          let val = a[currentSort.key] > b[currentSort.key] ? 1 : -1;
          return currentSort.dir === 'asc' ? val : -val;
        });
      }
      const start = (currentPage - 1) * perPage;
      const pageItems = filteredBooks.slice(start, start + perPage);
      const tbody = document.getElementById('tableBody');
      tbody.innerHTML = pageItems.map(b => `<tr>
        <td>${b.title}</td><td>${b.author}</td><td>${b.year}</td>
        <td>${'★'.repeat(Math.floor(b.rating))} ${b.rating}</td>
        <td><button class="btn btn-sm btn-outline-primary">Detail</button></td>
      </tr>`).join('');
      renderPagination();
    }

    function renderPagination() {
      const totalPages = Math.ceil(filteredBooks.length / perPage);
      const ul = document.getElementById('pagination');
      ul.innerHTML = Array.from({length: totalPages}, (_, i) =>
        `<li class="page-item ${i + 1 === currentPage ? 'active' : ''}">
          <a class="page-link" href="#" data-page="${i + 1}">${i + 1}</a>
        </li>`
      ).join('');
    }

    document.querySelectorAll('[data-sort]').forEach(th => {
      th.addEventListener('click', function() {
        const key = this.dataset.sort;
        if (currentSort.key === key) currentSort.dir = currentSort.dir === 'asc' ? 'desc' : 'asc';
        else { currentSort.key = key; currentSort.dir = 'asc'; }
        document.querySelectorAll('[data-sort]').forEach(h => h.classList.remove('asc', 'desc'));
        this.classList.add(currentSort.dir);
        renderTable();
      });
    });

    document.getElementById('searchInput').addEventListener('input', () => { currentPage = 1; renderTable(); });
    document.getElementById('pagination').addEventListener('click', e => {
      if (e.target.dataset.page) { currentPage = +e.target.dataset.page; renderTable(); }
    });

    renderTable();
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan Bootstrap table classes dan pagination sebagai fondasi data table
- Tambahkan sorting kolom dengan click handler dan indikator panah (▲/▼)
- Filter data real-time dengan search input — cocok untuk dataset hingga ribuan baris
- Pastikan responsif dengan `table-responsive` dan pertimbangkan card layout untuk mobile
