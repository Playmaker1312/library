# Membuat custom pricing table menggunakan Bootstrap grid dan card

## Analogi: Perpustakaan Digital

Perpustakaan digital menawarkan paket keanggotaan: Basic (1 buku/bulan), Standard (5 buku/bulan), dan Premium (tanpa batas). Setiap paket ditampilkan dalam kartu yang menunjukkan fitur, harga, dan tombol daftar — dengan paket Premium disorot sebagai pilihan terbaik. Pricing table adalah perbandingan paket yang membantu pengunjung memilih.

## Penjelasan Detail

Pricing table adalah komponen UI yang menampilkan paket harga secara side-by-side. Bootstrap card dan grid adalah fondasi sempurna untuk pricing table. Mulai dengan `row` dan `col` untuk layout. Setiap paket adalah card dengan header (nama paket), body (daftar fitur dengan ikon centang/silang), footer (harga + tombol CTA). Paket unggulan (recommended) punya styling berbeda: border warna primary, badge "Popular", dan shadow lebih besar. Pastikan pricing table responsif — di mobile, kartu bertumpuk vertikal. Gunakan Bootstrap utilities untuk spacing, alignment, dan typography yang konsisten.

## Poin Penting
- Bootstrap card dan grid adalah fondasi pricing table yang solid dan responsif
- Paket recommended punya styling berbeda: border primary, scale 1.03, dan badge "Paling Populer"
- Fitur checklist dengan ikon centang (✓) dan silang (✗) warna success/danger
- Gunakan hover effect (translateY + shadow) untuk interaktivitas
