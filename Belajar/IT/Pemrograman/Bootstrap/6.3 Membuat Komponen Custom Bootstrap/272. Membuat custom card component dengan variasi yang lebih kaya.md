# Membuat custom card component dengan variasi yang lebih kaya

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki kartu buku standar yang menampilkan judul, penulis, dan sampul. Tapi untuk buku spesial — buku terlaris, edisi kolektor, atau buku interaktif — kartu buku perlu variasi yang lebih kaya: badge, rating bintang, indikator stok, atau link unduh. Custom card component adalah kartu buku yang diperkaya.

## Penjelasan Detail

Bootstrap card sudah solid, tapi untuk kebutuhan spesifik Anda perlu custom card dengan variasi lebih kaya. Contoh variasi: card dengan header image overlay, card horizontal dengan media, card dengan action footer, card dengan badge status, card dengan rating, dan card dengan progress bar. Gunakan Bootstrap grid, utilities, dan komponen existens untuk membangun variasi ini. Setiap variasi card harus tetap konsisten dengan spacing, tipografi, dan warna Bootstrap. Gunakan flex utilities untuk layout internal. Pastikan card responsif — ubah dari vertikal ke horizontal di breakpoint tertentu. Card custom bisa menggunakan CSS custom properties untuk fleksibilitas lebih.

## Contoh Kode Implementasi

```html
      transform: translateY(-2px);
    }

      object-fit: cover;
    }
    .card-custom__image--overlay {
      position: relative;
    }
    .card-custom__image--overlay .card-custom__overlay-text {
      position: absolute;
      bottom: 0;
      left: 0;
      right: 0;

      color: white;
      padding: 1.5rem 1rem 0.75rem;
    }
    .card-custom--horizontal {
      flex-direction: row;
    }
    .card-custom--horizontal .card-custom__image {
      width: 200px;
      height: 100%;
      flex-shrink: 0;
    }
    .card-custom__rating {
      color: #ffc107;
    }
    .card-custom__badge {
      position: absolute;
      top: 0.5rem;
      right: 0.5rem;
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <div class="row g-4">
      <!-- Card vertikal dengan image + badge -->
      <div class="col-md-4">
        <div class="card-custom position-relative">
          <span class="card-custom__badge badge bg-danger">HOT</span>
          <img class="card-custom__image" src="https://picsum.photos/400/250?random=1" alt="Thumbnail">
          <div class="p-3">
            <div class="card-custom__rating mb-1">★★★★★ 5.0</div>

            <p class="text-muted small">Belajar React dengan proyek nyata.</p>
            <div class="d-flex justify-content-between align-items-center">
              <span class="fs-5 fw-bold text-primary">Rp149k</span>
              <button class="btn btn-sm btn-outline-primary">Daftar</button>
            </div>
          </div>
        </div>
      </div>

      <!-- Card horizontal -->
      <div class="col-md-8">
        <div class="card-custom card-custom--horizontal d-flex">
          <img class="card-custom__image" src="https://picsum.photos/400/250?random=2" alt="Thumbnail">
          <div class="p-3 d-flex flex-column justify-content-between">
            <div>
              <h5 class="fw-bold">Buku Panduan Bootstrap 5</h5>

              <button class="btn btn-outline-secondary btn-sm">Bookmark</button>
            </div>
          </div>
        </div>
      </div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan Bootstrap utilities (flex, spacing, colors) untuk membangun variasi card
- Card horizontal menggunakan `flex-direction: row` dengan lebar image tetap
- Tambahkan efek hover seperti shadow dan translasi untuk interaktivitas
- Badge, rating, dan progress bar membuat card lebih informatif dan engaging
