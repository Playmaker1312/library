# Cara merencanakan dan mendesain custom component yang konsisten dengan Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital menambahkan rak baru untuk genre yang sedang populer. Rak baru harus memiliki dimensi, warna, dan sistem pelabelan yang sama dengan rak yang sudah ada, agar pengunjung tetap merasa familiar. Custom component dalam ekosistem Bootstrap harus mengikuti prinsip yang sama: konsisten dengan desain language Bootstrap, menggunakan spacing, warna, dan tipografi yang selaras.

## Penjelasan Detail

Sebelum membuat komponen kustom, rencanakan dengan matang. Mulailah dengan mengidentifikasi gap di Bootstrap — komponen apa yang tidak tersedia atau tidak cukup fleksibel. Dokumentasikan spesifikasi komponen: states (default, hover, active, disabled), variasi (size, color, layout), dan responsivitas. Komponen kustom harus menggunakan variabel Bootstrap (`$spacer`, `$font-size-base`, `$theme-colors`) agar konsisten. Ikuti pola CSS Bootstrap: gunakan BEM-like naming dengan prefix khas (misal `.custom-`). Pastikan komponen mendukung aksesibilitas (ARIA attributes, keyboard navigation). Buat prototype di HTML/CSS dulu sebelum JavaScript. Uji komponen di berbagai viewport dan browser.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Merencanakan Custom Component</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    :root {
      --custom-avatar-size-sm: 2rem;
      --custom-avatar-size-md: 3rem;
      --custom-avatar-size-lg: 4rem;
    }

    .custom-avatar {
      display: inline-flex;
      align-items: center;
      justify-content: center;
      width: var(--custom-avatar-size-md);
      height: var(--custom-avatar-size-md);
      border-radius: 50%;
      background-color: var(--bs-primary);
      color: white;
      font-weight: 600;
      font-size: calc(var(--custom-avatar-size-md) * 0.4);
      overflow: hidden;
      flex-shrink: 0;
    }

    .custom-avatar img {
      width: 100%;
      height: 100%;
      object-fit: cover;
    }

    .custom-avatar--sm {
      width: var(--custom-avatar-size-sm);
      height: var(--custom-avatar-size-sm);
      font-size: calc(var(--custom-avatar-size-sm) * 0.4);
    }

    .custom-avatar--lg {
      width: var(--custom-avatar-size-lg);
      height: var(--custom-avatar-size-lg);
      font-size: calc(var(--custom-avatar-size-lg) * 0.4);
    }

    @each $color, $value in $theme-colors {
      .custom-avatar--#{$color} {
        background-color: $value;
      }
    }
  </style>
</head>
<body>
  <div class="container py-4">
    <h2>Avatar Component — Rencana Desain</h2>
    <table class="table table-bordered">
      <thead><tr><th>Properti</th><th>Nilai</th></tr></thead>
      <tbody>
        <tr><td>Sizes</td><td>sm (2rem), md (3rem), lg (4rem)</td></tr>
        <tr><td>Variants</td><td>Semua $theme-colors Bootstrap</td></tr>
        <tr><td>Content</td><td>Inisial teks atau gambar (img)</td></tr>
        <tr><td>States</td><td>Default, active (border)</td></tr>
      </tbody>
    </table>
    <h3>Preview</h3>
    <div class="d-flex gap-3 align-items-center">
      <div class="custom-avatar custom-avatar--sm bg-primary">A</div>
      <div class="custom-avatar custom-avatar--sm bg-success"><img src="https://i.pravatar.cc/100" alt="User"></div>
      <div class="custom-avatar bg-warning text-dark">JD</div>
      <div class="custom-avatar custom-avatar--lg bg-danger">RZ</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Identifikasi gap di Bootstrap sebelum membuat komponen baru — jangan duplikasi yang sudah ada
- Gunakan variabel Bootstrap (`$spacer`, `$theme-colors`, dll.) untuk konsistensi visual
- Dokumentasikan spesifikasi: sizes, variants, states, dan responsive behavior
- Ikuti pola CSS Bootstrap dan gunakan prefix kustom (`custom-*`) untuk menghindari konflik
