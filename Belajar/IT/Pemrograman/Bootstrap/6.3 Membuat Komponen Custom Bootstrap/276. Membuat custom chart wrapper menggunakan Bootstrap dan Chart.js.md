# Membuat custom chart wrapper menggunakan Bootstrap dan Chart.js

## Analogi: Perpustakaan Digital

Perpustakaan digital menampilkan statistik peminjaman dalam bentuk grafik batang, garis, dan pie — memudahkan pengelola melihat tren bulanan, kategori populer, dan jam sibuk. Chart wrapper adalah komponen yang membungkus library chart (Chart.js) dengan styling dan layout Bootstrap, membuat grafik terintegrasi mulus dengan desain aplikasi.

## Penjelasan Detail

Chart.js adalah library JavaScript yang ringan untuk membuat grafik interaktif. Untuk mengintegrasikannya dengan Bootstrap, buat wrapper component yang mengatur canvas, merespons perubahan ukuran container, dan konsisten dengan tema Bootstrap. Gunakan CSS custom properties Bootstrap untuk warna grafik. Wrapper harus: (1) inisialisasi Chart.js instance, (2) update data secara reaktif, (3) destroy instance saat komponen tidak dipakai, (4) responsif terhadap ukuran container. Utility Bootstrap seperti `card`, `row`, dan `col` digunakan untuk layout dashboard. Kombinasikan beberapa chart dalam grid untuk dashboard analitik yang informatif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dashboard Chart</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js"></script>
  <style>
    .chart-card {
      border: 1px solid var(--bs-border-color);
      border-radius: var(--bs-border-radius-lg);
    }
    .chart-card .card-header {
      background: transparent;
      border-bottom: 1px solid var(--bs-border-color);
      font-weight: 600;
      padding: 1rem 1.25rem;
    }
    .chart-wrapper {
      position: relative;
      width: 100%;
      max-height: 300px;
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <h3 class="mb-4">📊 Dashboard Statistik</h3>
    <div class="row g-4">
      <!-- Bar Chart -->
      <div class="col-md-6">
        <div class="chart-card card">
          <div class="card-header">Peminjaman per Bulan</div>
          <div class="card-body">
            <div class="chart-wrapper"><canvas id="barChart"></canvas></div>
          </div>
        </div>
      </div>
      <!-- Line Chart -->
      <div class="col-md-6">
        <div class="chart-card card">
          <div class="card-header">Tren Pengunjung</div>
          <div class="card-body">
            <div class="chart-wrapper"><canvas id="lineChart"></canvas></div>
          </div>
        </div>
      </div>
      <!-- Pie Chart -->
      <div class="col-md-4">
        <div class="chart-card card">
          <div class="card-header">Kategori Populer</div>
          <div class="card-body">
            <div class="chart-wrapper" style="max-height: 250px;"><canvas id="pieChart"></canvas></div>
          </div>
        </div>
      </div>
      <!-- Doughnut Chart -->
      <div class="col-md-4">
        <div class="chart-card card">
          <div class="card-header">Status Buku</div>
          <div class="card-body">
            <div class="chart-wrapper" style="max-height: 250px;"><canvas id="doughnutChart"></canvas></div>
          </div>
        </div>
      </div>
      <!-- Stat card -->
      <div class="col-md-4">
        <div class="chart-card card">
          <div class="card-header">Ringkasan</div>
          <div class="card-body d-flex flex-column gap-3">
            <div><small class="text-muted">Total Buku</small><h4 class="mb-0">1,234</h4></div>
            <div><small class="text-muted">Peminjam Aktif</small><h4 class="mb-0">567</h4></div>
            <div><small class="text-muted">Denda Hari Ini</small><h4 class="mb-0 text-danger">Rp 45,000</h4></div>
          </div>
        </div>
      </div>
    </div>
  </div>

  <script>
    const COLORS = [
      getComputedStyle(document.documentElement).getPropertyValue('--bs-primary').trim() || '#0d6efd',
      getComputedStyle(document.documentElement).getPropertyValue('--bs-success').trim() || '#198754',
      getComputedStyle(document.documentElement).getPropertyValue('--bs-warning').trim() || '#ffc107',
      getComputedStyle(document.documentElement).getPropertyValue('--bs-danger').trim() || '#dc3545',
      getComputedStyle(document.documentElement).getPropertyValue('--bs-info').trim() || '#0dcaf0',
    ];

    new Chart(document.getElementById('barChart'), {
      type: 'bar',
      data: { labels: ['Jan','Feb','Mar','Apr','Mei','Jun'], datasets: [{ label: 'Dipinjam', data: [45, 59, 80, 72, 65, 90], backgroundColor: COLORS[0] }] },
      options: { responsive: true, maintainAspectRatio: false, plugins: { legend: { display: false } } }
    });

    new Chart(document.getElementById('lineChart'), {
      type: 'line',
      data: { labels: ['Minggu 1','Minggu 2','Minggu 3','Minggu 4'], datasets: [{ label: 'Pengunjung', data: [120, 190, 170, 210], borderColor: COLORS[1], tension: 0.4 }] },
      options: { responsive: true, maintainAspectRatio: false }
    });

    new Chart(document.getElementById('pieChart'), {
      type: 'pie',
      data: { labels: ['Programming', 'Design', 'Bisnis', 'Sains'], datasets: [{ data: [35, 25, 20, 20], backgroundColor: COLORS }] },
      options: { responsive: true, maintainAspectRatio: false }
    });

    new Chart(document.getElementById('doughnutChart'), {
      type: 'doughnut',
      data: { labels: ['Tersedia', 'Dipinjam', 'Perbaikan'], datasets: [{ data: [60, 30, 10], backgroundColor: [COLORS[0], COLORS[2], COLORS[3]] }] },
      options: { responsive: true, maintainAspectRatio: false }
    });
  </script>
</body>
</html>
```

## Poin Penting
- Chart wrapper menggunakan Bootstrap card dan grid untuk layout dashboard yang rapi
- Warna chart selaras dengan Bootstrap theme colors (`--bs-primary`, `--bs-success`, dll.)
- Setiap chart responsif dengan `maintainAspectRatio: false` dan container berbasis CSS
- Kombinasikan chart dengan stat card untuk dashboard analitik yang informatif
