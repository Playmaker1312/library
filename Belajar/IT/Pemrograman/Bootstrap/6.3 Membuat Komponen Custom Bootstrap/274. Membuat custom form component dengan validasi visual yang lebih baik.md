# Membuat custom form component dengan validasi visual yang lebih baik

## Analogi: Perpustakaan Digital

Saat pengunjung mengisi formulir peminjaman buku, sistem langsung memberi tahu jika ada field yang salah — dengan ikon centang hijau untuk input valid, silang merah untuk yang salah, dan pesan error yang jelas. Customs form component memberikan feedback visual real-time yang jauh lebih baik daripada validasi Bootstrap standar.

## Penjelasan Detail

Validasi form Bootstrap sudah baik, tapi bisa ditingkatkan dengan feedback visual yang lebih detail. Buat komponen form dengan: validasi real-time (saat mengetik), ikon status (check/x) di dalam input, pesan error yang spesifik, karakter counter, password strength meter, dan floating labels yang tetap di atas saat diisi. Gunakan CSS pseudo-class `:valid` dan `:invalid` bersama dengan `was-validated` class Bootstrap. Integrasikan dengan JavaScript untuk validasi kustom seperti format email, kekuatan password, dan kecocokan konfirmasi password. Pastikan warna dan icon feedback konsisten dengan tema Bootstrap (`$form-feedback-valid-color`, `$form-feedback-invalid-color`).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Custom Form Validation</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    .form-custom {
      max-width: 500px;
    }
    .form-custom .form-control {
      padding-right: 2.5rem;
    }
    .form-custom .input-status {
      position: absolute;
      right: 0.75rem;
      top: 50%;
      transform: translateY(-50%);
      font-size: 1.25rem;
      pointer-events: none;
    }
    .form-custom .input-status.valid {
      color: var(--bs-success);
    }
    .form-custom .input-status.invalid {
      color: var(--bs-danger);
    }
    .form-custom .password-strength {
      height: 4px;
      border-radius: 4px;
      background: #e9ecef;
      overflow: hidden;
      margin-top: 0.25rem;
    }
    .form-custom .password-strength-bar {
      height: 100%;
      width: 0%;
      transition: width 0.3s, background 0.3s;
      border-radius: 4px;
    }
    .form-custom .char-counter {
      text-align: right;
      font-size: 0.75rem;
      color: var(--bs-secondary-color);
    }
    .form-custom .char-counter.over {
      color: var(--bs-danger);
      font-weight: 600;
    }
    .input-group-custom {
      position: relative;
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <form class="form-custom needs-validation" novalidate>
      <!-- Email dengan status icon -->
      <div class="mb-4">
        <label class="form-label fw-semibold">Email</label>
        <div class="input-group-custom">
          <input type="email" class="form-control" id="email" placeholder="nama@email.com" required minlength="5">
          <span class="input-status" id="emailStatus"></span>
        </div>
        <div class="invalid-feedback">Masukkan email yang valid.</div>
      </div>

      <!-- Password dengan strength meter -->
      <div class="mb-4">
        <label class="form-label fw-semibold">Password</label>
        <div class="input-group-custom">
          <input type="password" class="form-control" id="password" placeholder="Min 8 karakter" required minlength="8">
          <span class="input-status" id="passwordStatus"></span>
        </div>
        <div class="password-strength"><div class="password-strength-bar" id="strengthBar"></div></div>
        <small class="text-muted" id="strengthText">Ketik password untuk melihat kekuatan</small>
        <div class="invalid-feedback">Password minimal 8 karakter.</div>
      </div>

      <!-- Bio dengan karakter counter -->
      <div class="mb-4">
        <label class="form-label fw-semibold">Bio</label>
        <textarea class="form-control" id="bio" rows="3" maxlength="200" placeholder="Ceritakan tentang diri Anda"></textarea>
        <div class="char-counter"><span id="charCount">0</span>/200</div>
      </div>

      <button class="btn btn-primary w-100" type="submit">Daftar</button>
    </form>
  </div>

  <script>
    // Validasi real-time email
    document.getElementById('email').addEventListener('input', function() {
      const status = document.getElementById('emailStatus');
      if (this.validity.valid && this.value.length > 0) {
        status.textContent = '✓';
        status.className = 'input-status valid';
        this.classList.add('is-valid');
        this.classList.remove('is-invalid');
      } else if (this.value.length > 0) {
        status.textContent = '✕';
        status.className = 'input-status invalid';
        this.classList.add('is-invalid');
        this.classList.remove('is-valid');
      } else {
        status.textContent = '';
        this.classList.remove('is-valid', 'is-invalid');
      }
    });

    // Password strength meter
    document.getElementById('password').addEventListener('input', function() {
      const bar = document.getElementById('strengthBar');
      const text = document.getElementById('strengthText');
      const val = this.value;
      let score = 0;
      if (val.length >= 8) score += 25;
      if (val.match(/[a-z]/) && val.match(/[A-Z]/)) score += 25;
      if (val.match(/\d/)) score += 25;
      if (val.match(/[^a-zA-Z0-9]/)) score += 25;
      bar.style.width = score + '%';
      if (score < 25) { bar.style.background = '#dc3545'; text.textContent = 'Lemah'; }
      else if (score < 50) { bar.style.background = '#ffc107'; text.textContent = 'Cukup'; }
      else if (score < 75) { bar.style.background = '#0d6efd'; text.textContent = 'Kuat'; }
      else { bar.style.background = '#198754'; text.textContent = 'Sangat Kuat'; }
    });

    // Character counter
    document.getElementById('bio').addEventListener('input', function() {
      const count = document.getElementById('charCount');
      count.textContent = this.value.length;
      count.parentElement.classList.toggle('over', this.value.length > 180);
    });

    // Bootstrap validation
    document.querySelector('.needs-validation').addEventListener('submit', e => {
      if (!e.target.checkValidity()) {
        e.preventDefault();
        e.stopPropagation();
      }
      e.target.classList.add('was-validated');
    });
  </script>
</body>
</html>
```

## Poin Penting
- Tambahkan ikon status (✓/✕) di dalam input untuk feedback visual instan
- Password strength meter memberikan indikasi kekuatan password secara real-time
- Character counter membantu pengguna tahu batas maksimum input
- Gunakan CSS pseudo-class `:valid`/`:invalid` dengan `was-validated` Bootstrap untuk integrasi seamless
