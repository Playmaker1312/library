# Membuat custom image gallery atau lightbox menggunakan Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki koleksi gambar sampul buku yang bisa dilihat dalam bentuk thumbnail grid. Saat diklik, gambar muncul dalam tampilan fullscreen dengan latar gelap, navigasi next/previous, dan tombol tutup — pengunjung bisa fokus melihat detail gambar. Lightbox adalah pengalaman melihat gambar secara imersif tanpa meninggalkan halaman.

## Penjelasan Detail

Lightbox adalah overlay yang menampilkan gambar dalam ukuran besar dengan latar belakang gelap. Bootstrap menyediakan modal yang bisa digunakan sebagai basis lightbox. Buat gallery grid menggunakan Bootstrap grid (`row-cols-*`) dengan thumbnail yang seragam. Saat thumbnail diklik, modal muncul menampilkan gambar ukuran penuh dengan navigasi. Komponen lightbox harus mendukung: navigasi keyboard (panah kiri/kanan, Escape), touch gesture (swipe) di mobile, loading state, caption gambar, dan tombol close. Untuk performa, gunakan lazy loading untuk gambar di gallery dan preload gambar adjacent di lightbox.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Image Gallery Lightbox</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    .gallery-thumb {
      aspect-ratio: 4 / 3;
      object-fit: cover;
      cursor: pointer;
      border-radius: var(--bs-border-radius);
      transition: transform 0.2s, box-shadow 0.2s;
      width: 100%;
    }
    .gallery-thumb:hover {
      transform: scale(1.03);
      box-shadow: 0 8px 20px rgba(0,0,0,0.15);
    }
    .lightbox-img {
      max-height: 80vh;
      object-fit: contain;
      width: 100%;
    }
    .lightbox-btn {
      position: absolute;
      top: 50%;
      transform: translateY(-50%);
      z-index: 1055;
      background: rgba(255,255,255,0.2);
      border: none;
      color: white;
      width: 48px;
      height: 48px;
      border-radius: 50%;
      font-size: 1.5rem;
      cursor: pointer;
      transition: background 0.2s;
    }
    .lightbox-btn:hover { background: rgba(255,255,255,0.4); }
    .lightbox-btn.prev { left: 1rem; }
    .lightbox-btn.next { right: 1rem; }
    .lightbox-caption {
      color: white;
      text-align: center;
      padding: 1rem;
      background: rgba(0,0,0,0.5);
      border-radius: 0 0 var(--bs-border-radius-lg) var(--bs-border-radius-lg);
    }
    .modal-content.lightbox-modal {
      background: transparent;
      border: none;
    }
  </style>
</head>
<body>
  <div class="container py-5">
    <h3 class="mb-4">📸 Galeri Sampul Buku</h3>
    <div class="row g-3 row-cols-2 row-cols-md-3 row-cols-lg-4" id="galleryGrid"></div>
  </div>

  <!-- Lightbox Modal -->
  <div class="modal fade" id="lightboxModal" tabindex="-1" data-bs-backdrop="static">
    <div class="modal-dialog modal-xl modal-dialog-centered">
      <div class="modal-content lightbox-modal">
        <div class="text-end mb-2">
          <button type="button" class="btn-close btn-close-white" data-bs-dismiss="modal" aria-label="Close"></button>
        </div>
        <div class="position-relative">
          <img class="lightbox-img" id="lightboxImage" src="" alt="">
          <button class="lightbox-btn prev" id="prevBtn">&lsaquo;</button>
          <button class="lightbox-btn next" id="nextBtn">&rsaquo;</button>
        </div>
        <div class="lightbox-caption" id="lightboxCaption"></div>
      </div>
    </div>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
  <script>
    const images = [
      { src: 'https://picsum.photos/800/600?random=1', thumb: 'https://picsum.photos/400/300?random=1', caption: 'Buku Programming #1' },
      { src: 'https://picsum.photos/800/600?random=2', thumb: 'https://picsum.photos/400/300?random=2', caption: 'Buku Design #2' },
      { src: 'https://picsum.photos/800/600?random=3', thumb: 'https://picsum.photos/400/300?random=3', caption: 'Buku Bisnis #3' },
      { src: 'https://picsum.photos/800/600?random=4', thumb: 'https://picsum.photos/400/300?random=4', caption: 'Buku Sains #4' },
      { src: 'https://picsum.photos/800/600?random=5', thumb: 'https://picsum.photos/400/300?random=5', caption: 'Buku Sejarah #5' },
      { src: 'https://picsum.photos/800/600?random=6', thumb: 'https://picsum.photos/400/300?random=6', caption: 'Buku Filsafat #6' },
    ];

    let currentIndex = 0;
    const galleryGrid = document.getElementById('galleryGrid');
    const lightboxImage = document.getElementById('lightboxImage');
    const lightboxCaption = document.getElementById('lightboxCaption');

    images.forEach((img, i) => {
      const col = document.createElement('div');
      col.className = 'col';
      col.innerHTML = `<img class="gallery-thumb" src="${img.thumb}" alt="${img.caption}" loading="lazy" data-index="${i}">`;
      col.querySelector('img').addEventListener('click', () => openLightbox(i));
      galleryGrid.appendChild(col);
    });

    function openLightbox(index) {
      currentIndex = index;
      updateLightbox();
      const modal = new bootstrap.Modal(document.getElementById('lightboxModal'));
      modal.show();
    }

    function updateLightbox() {
      const img = images[currentIndex];
      lightboxImage.src = img.src;
      lightboxCaption.textContent = `${currentIndex + 1} / ${images.length} — ${img.caption}`;
    }

    document.getElementById('prevBtn').addEventListener('click', () => {
      currentIndex = (currentIndex - 1 + images.length) % images.length;
      updateLightbox();
    });

    document.getElementById('nextBtn').addEventListener('click', () => {
      currentIndex = (currentIndex + 1) % images.length;
      updateLightbox();
    });

    document.addEventListener('keydown', e => {
      if (!document.getElementById('lightboxModal').classList.contains('show')) return;
      if (e.key === 'ArrowLeft') document.getElementById('prevBtn').click();
      if (e.key === 'ArrowRight') document.getElementById('nextBtn').click();
    });
  </script>
</body>
</html>
```

## Poin Penting
- Gunakan Bootstrap modal sebagai basis lightbox dengan kustomisasi background transparan
- Gallery grid menggunakan `row-cols-*` untuk responsivitas otomatis
- Navigasi prev/next dengan tombol panah di kiri-kanan gambar
- Dukungan keyboard (panah kiri/kanan, Escape) meningkatkan aksesibilitas
