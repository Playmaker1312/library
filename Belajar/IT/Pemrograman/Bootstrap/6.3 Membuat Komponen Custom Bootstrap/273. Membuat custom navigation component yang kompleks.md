# Membuat custom navigation component yang kompleks

## Analogi: Perpustakaan Digital

Perpustakaan digital besar memiliki sistem navigasi bertingkat: menu utama (kategori), submenu (subkategori), breadcrumb (posisi saat ini), tab (konten terkait), dan mega-menu (katalog lengkap). Setiap elemen navigasi membantu pengunjung tidak tersesat. Custom navigation component menggabungkan semua pola navigasi ini menjadi satu sistem yang kohesif.

## Penjelasan Detail

Navigasi kompleks seringkali membutuhkan kombinasi navbar, tabs, breadcrumb, dropdown, dan mega-menu. Bootstrap navbar dasar bisa diperluas dengan dropdown multi-level, mega-menu (grid di dalam dropdown), sticky header, dan navbar yang berubah saat scroll (shrink effect). Untuk navigasi tab yang kompleks, gunakan Bootstrap nav-tabs dengan JavaScript untuk konten dinamis. Breadcrumb bisa dikustomisasi dengan icon dan link aktif. Pastikan navigasi responsif: navbar collapse di mobile dengan hamburger menu, dan dropdown berubah menjadi accordion di layar kecil. Semua komponen harus accessible dengan keyboard navigation dan ARIA labels.

## Contoh Kode Implementasi

```html

<html lang="en">

  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <style>
    .navbar-custom {
      transition: padding 0.3s, background 0.3s;
    }
    .navbar-custom.scrolled {
      padding-top: 0.25rem !important;
      padding-bottom: 0.25rem !important;
      background: rgba(255,255,255,0.95) !important;
      backdrop-filter: blur(10px);
    }
    .mega-menu {
      width: 600px;
      padding: 1.5rem;
    }
    @media (max-width: 991.98px) {
      .mega-menu {
        width: 100%;
      }
    }
    .nav-tabs-custom .nav-link {
      border: none;
      color: var(--bs-secondary-color);
      padding: 0.75rem 1.25rem;
      position: relative;
    }
    .nav-tabs-custom .nav-link.active {
      color: var(--bs-primary);
      background: transparent;
    }
    .nav-tabs-custom .nav-link.active::after {
      content: '';
      position: absolute;
      bottom: 0;
      left: 1rem;
      right: 1rem;
      height: 3px;
      background: var(--bs-primary);
      border-radius: 3px 3px 0 0;
    }
    .breadcrumb-custom {
      background: transparent;
      padding: 0.5rem 0;
    }
    .breadcrumb-custom .breadcrumb-item + .breadcrumb-item::before {
      content: '›';
      font-size: 1.2em;
    }
  </style>
</head>
<body>
  <!-- Navbar dengan mega-menu -->
  <nav class="navbar navbar-expand-lg bg-white navbar-custom py-3 shadow-sm sticky-top">
    <div class="container">
      <a class="navbar-brand fw-bold fs-4" href="#">MyLibrary</a>
      <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarMain">
        <span class="navbar-toggler-icon"></span>
      </button>
      <div class="collapse navbar-collapse" id="navbarMain">
        <ul class="navbar-nav me-auto mb-2 mb-lg-0">
          <li class="nav-item dropdown">
            <a class="nav-link dropdown-toggle" href="#" data-bs-toggle="dropdown">Kategori</a>
            <div class="dropdown-menu mega-menu p-4">
              <div class="row">
                <div class="col-6">
                  <h6 class="fw-bold text-primary">Programming</h6>
                  <a class="dropdown-item px-0" href="#">JavaScript</a>
                  <a class="dropdown-item px-0" href="#">Python</a>
                  <a class="dropdown-item px-0" href="#">Java</a>
                </div>
                <div class="col-6">
                  <h6 class="fw-bold text-primary">Design</h6>
                  <a class="dropdown-item px-0" href="#">UI/UX</a>
                  <a class="dropdown-item px-0" href="#">Graphic</a>
                  <a class="dropdown-item px-0" href="#">Motion</a>
                </div>
              </div>
            </div>
          </li>
          <li class="nav-item"><a class="nav-link" href="#">Tutorial</a></li>
          <li class="nav-item"><a class="nav-link" href="#">Blog</a></li>
        </ul>
      </div>
    </div>
  </nav>

  <!-- Breadcrumb -->
  <div class="container">
    <nav aria-label="breadcrumb">
      <ol class="breadcrumb breadcrumb-custom">
        <li class="breadcrumb-item"><a href="#">Home</a></li>
        <li class="breadcrumb-item"><a href="#">Programming</a></li>
        <li class="breadcrumb-item active" aria-current="page">JavaScript Dasar</li>
      </ol>
    </nav>
  </div>

  <!-- Tabs -->
  <div class="container">
    <ul class="nav nav-tabs-custom border-bottom mb-4">
      <li class="nav-item"><a class="nav-link active" href="#desc">Deskripsi</a></li>
      <li class="nav-item"><a class="nav-link" href="#curriculum">Kurikulum</a></li>
      <li class="nav-item"><a class="nav-link" href="#reviews">Ulasan</a></li>
    </ul>
    <div class="tab-content">
      <div class="tab-pane active" id="desc">Konten deskripsi...</div>
      <div class="tab-pane" id="curriculum">Konten kurikulum...</div>
      <div class="tab-pane" id="reviews">Konten ulasan...</div>
    </div>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
  <script>
    window.addEventListener('scroll', () => {
      document.querySelector('.navbar-custom').classList.toggle('scrolled', window.scrollY > 50);
    });
  </script>
</body>
</html>
```

## Poin Penting
- Kombinasikan navbar, mega-menu, breadcrumb, dan tabs untuk navigasi yang lengkap
- Mega-menu menggunakan grid Bootstrap di dalam dropdown untuk layout multi-kolom
- Navbar shrink effect saat scroll meningkatkan pengalaman pengguna di halaman panjang
- Pastikan navigasi responsif: collapse di mobile dengan toggler dan dropdown jadi accordion
