# Membuat custom timeline component menggunakan Bootstrap utilities

## Analogi: Perpustakaan Digital

Perpustakaan digital menampilkan sejarah peminjaman buku sebagai garis waktu vertikal: Senin meminjam Bootstrap 5, Selasa mengembalikan CSS Dasar, Rabu meminjam JavaScript. Setiap event adalah titik pada garis dengan tanggal, konten, dan status. Timeline component adalah representasi kronologis event secara visual.

## Penjelasan Detail

Timeline adalah komponen yang menampilkan urutan event secara kronologis. Bootstrap utility classes seperti `d-flex`, `gap`, `border`, `rounded`, dan `shadow` digunakan untuk membangun timeline tanpa CSS kustom berlebihan. Timeline bisa vertikal (default) atau horizontal. Setiap item terdiri dari titik indikator (lingkaran dengan warna sesuai status), konten (judul, deskripsi, tanggal), dan garis penghubung. Untuk variasi, tambahkan ikon di titik timeline, efek animasi saat muncul (scroll reveal), dan dukungan responsive. Gunakan pseudo-element `::before` untuk garis vertikal dan `timeline-dot` untuk indikator.

## Poin Penting
- Buat timeline vertikal dengan pseudo-element `::before` untuk garis dan `timeline-dot` untuk indikator
- Timeline horizontal menggunakan flexbox dengan overflow-x auto untuk scroll
- Warna dot mencerminkan status: primary (selesai), warning (proses), success (berhasil), danger (belum)
- Gunakan Bootstrap utilities untuk styling card, badge, dan spacing yang konsisten
