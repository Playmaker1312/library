# Membuat Dropdown Menu di Dalam Navbar

## Analogi: Perpustakaan Digital

Di perpustakaan digital, menu "Kategori" mungkin memiliki sub-menu seperti "Fiksi", "Non-Fiksi", dan "Ilmiah". Ketika Anda mengarahkan kursor atau mengklik menu utama, sub-menu ini akan muncul ke bawah seperti laci yang terbuka. Inilah yang disebut dropdown menu. Bootstrap menyediakan komponen dropdown yang mudah diintegrasikan ke dalam navbar, memungkinkan Anda membuat menu bertingkat yang rapi dan interaktif.

## Penjelasan Detail

Untuk membuat dropdown di dalam navbar, Anda memerlukan struktur berikut: sebuah `nav-item` yang diberi class `dropdown`, berisi dua elemen utama. Pertama, `nav-link` dengan class `dropdown-toggle` dan atribut `data-bs-toggle="dropdown"` sebagai trigger. Kedua, sebuah `<ul>` dengan class `dropdown-menu` yang berisi `dropdown-item` untuk setiap sub-menu. Setiap `dropdown-item` adalah elemen `<a>` atau `<button>` yang mewakili satu opsi dalam dropdown. Anda juga bisa menambahkan `dropdown-divider` untuk memisahkan grup menu, dan `dropdown-header` untuk memberi label pada grup. Pastikan JavaScript Bootstrap sudah disertakan agar fungsi dropdown bekerja.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Navbar Dropdown</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
        <div class="container">
            <a class="navbar-brand" href="#">MyLibrary</a>
            <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navMain">
                <span class="navbar-toggler-icon"></span>
            </button>
            <div class="collapse navbar-collapse" id="navMain">
                <ul class="navbar-nav">
                    <li class="nav-item"><a class="nav-link" href="#">Beranda</a></li>
                    <li class="nav-item dropdown">
                        <a class="nav-link dropdown-toggle" href="#" data-bs-toggle="dropdown">
                            Kategori
                        </a>
                        <ul class="dropdown-menu">
                            <li><a class="dropdown-item" href="#">Fiksi</a></li>
                            <li><a class="dropdown-item" href="#">Non-Fiksi</a></li>
                            <li><hr class="dropdown-divider"></li>
                            <li><a class="dropdown-item" href="#">Semua Kategori</a></li>
                        </ul>
                    </li>
                    <li class="nav-item"><a class="nav-link" href="#">Tentang</a></li>
                </ul>
            </div>
        </div>
    </nav>
    <div class="container mt-4">
        <h1>Dropdown dalam Navbar</h1>
        <p>Klik menu "Kategori" untuk melihat dropdown.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Tambahkan class `dropdown` pada `nav-item` yang memiliki sub-menu.
- Gunakan `dropdown-toggle` pada `nav-link` sebagai trigger dropdown.
- `dropdown-menu` adalah wadah untuk daftar sub-menu.
- Setiap item dalam dropdown menggunakan class `dropdown-item`.
