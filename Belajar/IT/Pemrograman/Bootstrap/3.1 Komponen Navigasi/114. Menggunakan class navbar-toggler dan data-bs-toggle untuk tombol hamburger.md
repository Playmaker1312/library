# Menggunakan Class Navbar-toggler dan Data-bs-toggle untuk Tombol Hamburger

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada sebuah tombol "Buka Menu" yang hanya muncul ketika layar menyempit, seperti di ponsel. Tombol ini memiliki ikon tiga garis horizontal yang dikenal sebagai ikon hamburger. Ketika diklik, menu navigasi yang tadinya tersembunyi akan muncul. Bootstrap menyediakan class `navbar-toggler` untuk membuat tombol ini dan atribut `data-bs-toggle` untuk menghubungkannya dengan menu yang akan ditampilkan. Ikon hamburger dihasilkan oleh elemen dengan class `navbar-toggler-icon`.

## Penjelasan Detail

`navbar-toggler` adalah class yang diberikan pada elemen `<button>` untuk mengubahnya menjadi tombol hamburger di dalam navbar. Bootstrap memberikan styling khusus pada tombol ini, termasuk border, padding, dan warna yang sesuai dengan tema navbar. Atribut `data-bs-toggle="collapse"` memberi tahu Bootstrap bahwa tombol ini berfungsi untuk toggle (menampilkan/menyembunyikan) elemen collapse. Sementara `data-bs-target` (atau `href`) menunjukkan ID dari elemen yang akan di-toggle. Di dalam tombol, `navbar-toggler-icon` adalah sebuah `<span>` yang menampilkan ikon hamburger menggunakan CSS background-image. Tombol ini secara default hanya terlihat pada layar yang lebih kecil dari breakpoint `navbar-expand`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Navbar Toggler</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-expand-md navbar-dark bg-dark">
        <div class="container-fluid">
            <a class="navbar-brand" href="#">MyApp</a>
            <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#menuToggle">
                <span class="navbar-toggler-icon"></span>
            </button>
            <div class="collapse navbar-collapse" id="menuToggle">
                <ul class="navbar-nav">
                    <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
                    <li class="nav-item"><a class="nav-link" href="#">About</a></li>
                    <li class="nav-item"><a class="nav-link" href="#">Contact</a></li>
                </ul>
            </div>
        </div>
    </nav>
    <div class="container mt-4">
        <h1>Tombol Hamburger</h1>
        <p>Tombol hamburger muncul pada layar &lt; md (768px).</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `navbar-toggler` di aplikasikan pada elemen `<button>` di dalam navbar.
- `data-bs-toggle="collapse"` mengaktifkan fungsi toggle collapse.
- `data-bs-target` berisi CSS selector ID elemen collapse yang dituju.
- `navbar-toggler-icon` adalah span yang menampilkan ikon hamburger.
