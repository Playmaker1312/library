# Membuat Navbar Fixed-top dan Sticky-top

## Analogi: Perpustakaan Digital

Bayangkan Anda sedang menjelajahi perpustakaan digital yang sangat panjang. Di bagian atas layar, menu navigasi selalu terlihat meskipun Anda sudah scroll jauh ke bawah. Ada dua cara untuk mencapainya: `fixed-top` membuat navbar selalu menempel di atas layar seperti papan pengumuman yang dipaku di dinding, sementara `sticky-top` membuat navbar tetap di tempatnya sampai halaman di-scroll melewatinya, lalu navbar akan ikut bergerak ke atas. Keduanya memastikan navigasi selalu terjangkau tanpa harus scroll kembali ke atas.

## Penjelasan Detail

Class `fixed-top` pada navbar akan memposisikannya secara tetap di bagian atas viewport menggunakan CSS `position: fixed`. Navbar akan selalu terlihat meskipun halaman di-scroll, menimpa konten di belakangnya. Oleh karena itu, Anda perlu menambahkan padding-top pada `<body>` atau konten utama agar tidak tertutup navbar. Sementara `sticky-top` menggunakan `position: sticky` yang membuat navbar berperilaku seperti elemen biasa sampai scroll melewatinya, lalu menjadi fixed di bagian atas. Keuntungan `sticky-top` adalah tidak perlu padding tambahan karena navbar tetap dalam aliran dokumen normal. Pilih `fixed-top` jika ingin navbar selalu terlihat, dan `sticky-top` jika ingin navbar hanya muncul setelah pengguna mulai scroll.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Fixed vs Sticky Navbar</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>body { padding-top: 60px; }</style>
</head>
<body>
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark fixed-top">
        <div class="container">
            <a class="navbar-brand" href="#">Fixed Top Navbar</a>
        </div>
    </nav>
    <div class="container" style="height: 2000px;">
        <h1 class="mt-4">Fixed-top Navbar</h1>
        <p>Navbar ini tetap di atas meskipun halaman di-scroll.</p>
        <p>Scroll ke bawah untuk melihat efeknya.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `fixed-top` menggunakan `position: fixed` dan menimpa konten di belakangnya.
- Tambahkan `padding-top` pada body saat menggunakan `fixed-top`.
- `sticky-top` menggunakan `position: sticky` dan tetap dalam aliran dokumen.
- `sticky-top` tidak memerlukan padding tambahan pada body.
