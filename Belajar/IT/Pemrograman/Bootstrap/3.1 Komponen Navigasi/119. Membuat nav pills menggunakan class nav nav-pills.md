# Membuat Nav Pills Menggunakan Class Nav Nav-pills

## Analogi: Perpustakaan Digital

Di perpustakaan digital, ada tab navigasi berbentuk pil yang memisahkan koleksi berdasarkan jenisnya, seperti "Buku Populer", "Buku Baru", dan "Rekomendasi". Setiap pil terlihat seperti tombol yang bisa ditekan, dan pil yang aktif akan terlihat lebih menonjol dengan warna yang berbeda. Bootstrap menyediakan class `nav nav-pills` untuk membuat navigasi berbentuk pil yang elegan dan mudah digunakan, baik sebagai menu terpisah maupun diintegrasikan dengan konten tab.

## Penjelasan Detail

Class `nav nav-pills` mengubah daftar tautan menjadi navigasi bergaya pil. Setiap item menggunakan `nav-link` yang akan ditampilkan dengan latar belakang dan border membulat seperti pil. Class `active` pada `nav-link` akan memberikan warna latar yang solid (defaultnya biru) untuk menandai item yang sedang dipilih. Class `disabled` juga bisa digunakan untuk menonaktifkan pil tertentu. Nav pills dapat digunakan secara horizontal dengan menambahkan class `flex-column` untuk membuatnya vertikal. Anda juga bisa mengkombinasikan nav pills dengan komponen tab untuk menampilkan konten yang berbeda berdasarkan pil yang dipilih.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Nav Pills</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Nav Pills</h1>
        <ul class="nav nav-pills">
            <li class="nav-item">
                <a class="nav-link active" href="#">Buku Populer</a>
            </li>
            <li class="nav-item">
                <a class="nav-link" href="#">Buku Baru</a>
            </li>
            <li class="nav-item">
                <a class="nav-link" href="#">Rekomendasi</a>
            </li>
            <li class="nav-item">
                <a class="nav-link disabled" href="#">Coming Soon</a>
            </li>
        </ul>
        <div class="mt-3 p-3 border rounded">
            <p>Konten untuk Buku Populer ditampilkan di sini.</p>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `nav nav-pills` membuat navigasi berbentuk pil dengan border rounded.
- Class `active` menandai pil yang sedang aktif dengan warna solid.
- Gunakan `disabled` untuk menonaktifkan pil tanpa menghapusnya.
- Nav pills bisa dikombinasikan dengan JavaScript tab untuk konten dinamis.
