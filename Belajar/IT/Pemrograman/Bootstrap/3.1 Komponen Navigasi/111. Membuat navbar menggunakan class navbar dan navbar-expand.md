# Membuat Navbar Menggunakan Class Navbar dan Navbar-expand

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan digital yang memiliki menu navigasi utama di bagian atas halaman. Menu ini berisi tautan ke berbagai bagian seperti "Katalog Buku", "Peminjaman", dan "Profil". Seperti halnya perpustakaan yang membutuhkan struktur navigasi yang jelas agar pengunjung mudah menemukan rak buku yang dicari, sebuah website juga memerlukan navbar yang rapi dan responsif. Bootstrap menyediakan class `navbar` sebagai wadah utama dan `navbar-expand` untuk mengontrol perilaku navbar di berbagai ukuran layar.

## Penjelasan Detail

Class `navbar` adalah komponen dasar Bootstrap untuk membuat navigation bar yang responsif. Dengan menambahkan class ini ke elemen `<nav>`, Bootstrap akan menerapkan styling dasar seperti flexbox layout, padding, dan warna latar yang konsisten. Class `navbar-expand` diikuti dengan breakpoint (seperti `navbar-expand-lg`) menentukan kapan navbar akan ditampilkan secara horizontal penuh versus ketika menu akan di-collapse menjadi tombol hamburger. Semakin kecil breakpoint yang dipilih, semakin lama navbar akan tetap horizontal. Navbar secara default menggunakan `display: flex` dan `flex-wrap: wrap`, sehingga elemen-elemen di dalamnya akan mengatur diri secara otomatis. Anda dapat menempatkan teks, tautan, tombol, atau form di dalam navbar. Kombinasi class ini menjadi fondasi untuk membangun navigasi website yang modern dan responsif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Contoh Navbar</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-expand-lg navbar-light bg-light">
        <div class="container-fluid">
            <a class="navbar-brand" href="#">Navbar</a>
            <div class="collapse navbar-collapse">
                <ul class="navbar-nav">
                    <li class="nav-item">
                        <a class="nav-link active" href="#">Home</a>
                    </li>
                    <li class="nav-item">
                        <a class="nav-link" href="#">Features</a>
                    </li>
                    <li class="nav-item">
                        <a class="nav-link" href="#">Pricing</a>
                    </li>
                </ul>
            </div>
        </div>
    </nav>
    <div class="container mt-4">
        <h1>Contoh Navbar Bootstrap</h1>
        <p>Navbar di atas menggunakan class navbar dan navbar-expand-lg.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Class `navbar` adalah wadah utama yang harus ada pada elemen `<nav>`.
- `navbar-expand` diikuti breakpoint (sm, md, lg, xl, xxl) menentukan kapan navbar bersifat horizontal.
- Navbar menggunakan flexbox sehingga elemen di dalamnya dapat diatur dengan mudah.
- Selalu gunakan `container` atau `container-fluid` di dalam navbar untuk padding yang konsisten.
