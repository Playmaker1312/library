# Membuat Navbar Collapse untuk Menu Hamburger di Mobile

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan digital yang diakses dari ponsel. Layar yang sempit tidak bisa menampilkan semua menu navigasi secara horizontal. Maka perpustakaan menyediakan tombol kecil yang jika ditekan akan membuka daftar menu lengkap, mirip seperti lemari arsip yang tertutup rapi dan hanya dibuka saat dibutuhkan. Inilah yang disebut dengan menu hamburger. Bootstrap menyediakan mekanisme collapse untuk menyembunyikan menu pada layar kecil dan menampilkannya saat tombol hamburger diklik.

## Penjelasan Detail

Navbar collapse bekerja dengan menggabungkan class `collapse` dan `navbar-collapse` pada wadah yang berisi menu navigasi. Ketika layar berukuran besar (sesuai breakpoint `navbar-expand`), wadah ini akan ditampilkan secara horizontal. Pada layar yang lebih kecil, wadah ini akan tersembunyi dan hanya akan muncul ketika tombol hamburger ditekan. Tombol hamburger menggunakan class `navbar-toggler` dan dihubungkan ke wadah collapse melalui atribut `data-bs-target`. Bootstrap secara otomatis mengatur transisi animasi saat menu muncul dan menghilang. Pastikan Anda menyertakan JavaScript Bootstrap agar fungsi collapse dapat bekerja dengan baik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Navbar Collapse</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-expand-lg navbar-light bg-light">
        <div class="container-fluid">
            <a class="navbar-brand" href="#">Perpustakaan</a>
            <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarMenu">
                <span class="navbar-toggler-icon"></span>
            </button>
            <div class="collapse navbar-collapse" id="navbarMenu">
                <ul class="navbar-nav">
                    <li class="nav-item"><a class="nav-link active" href="#">Beranda</a></li>
                    <li class="nav-item"><a class="nav-link" href="#">Katalog</a></li>
                    <li class="nav-item"><a class="nav-link" href="#">Tentang</a></li>
                </ul>
            </div>
        </div>
    </nav>
    <div class="container mt-4">
        <h1>Navbar dengan Collapse</h1>
        <p>Resize jendela browser untuk melihat efek hamburger.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Bungkus menu navigasi dengan `div` berclass `collapse navbar-collapse`.
- Hubungkan tombol toggler ke wadah collapse menggunakan `data-bs-target`.
- Class `navbar-expand-lg` menentukan kapan menu mulai di-collapse.
- Animasi collapse diatur otomatis oleh Bootstrap JavaScript.
