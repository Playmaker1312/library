# Membuat Nav Tabs Menggunakan Class Nav Nav-tabs

## Analogi: Perpustakaan Digital

Di perpustakaan digital, Anda mungkin melihat deretan tab seperti pembatas buku yang menjulur keluar. Setiap tab mewakili bagian yang berbeda, seperti "Deskripsi", "Detail Buku", dan "Ulasan". Ketika sebuah tab diklik, kontennya akan muncul di bawahnya. Bootstrap menyediakan class `nav nav-tabs` untuk membuat navigasi berbasis tab yang mirip dengan tab pada binder atau folder fisik. Tabs memberikan tampilan yang rapi dan terorganisir untuk konten yang terbagi dalam beberapa kategori.

## Penjelasan Detail

Class `nav nav-tabs` membuat navigasi dengan tampilan tab yang memiliki border bawah. Tab yang aktif (`active`) akan terlihat seperti menonjol ke atas dengan border di bagian bawah yang dihilangkan, menciptakan ilusi bahwa tab tersebut terhubung dengan konten di bawahnya. Seperti nav pills, tabs dapat menggunakan class `nav-item` dan `nav-link` dengan struktur yang sama. Tabs paling sering digunakan bersama komponen tab JavaScript Bootstrap untuk menampilkan konten yang berbeda saat tab diklik. Setiap `nav-link` dihubungkan ke panel konten melalui atribut `data-bs-toggle="tab"` dan `data-bs-target`. Tabs juga bisa dibuat vertikal dengan menambahkan class `flex-column`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Nav Tabs</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Nav Tabs</h1>
        <ul class="nav nav-tabs">
            <li class="nav-item">
                <a class="nav-link active" data-bs-toggle="tab" href="#deskripsi">Deskripsi</a>
            </li>
            <li class="nav-item">
                <a class="nav-link" data-bs-toggle="tab" href="#detail">Detail Buku</a>
            </li>
            <li class="nav-item">
                <a class="nav-link" data-bs-toggle="tab" href="#ulasan">Ulasan</a>
            </li>
        </ul>
        <div class="tab-content mt-3">
            <div class="tab-pane fade show active" id="deskripsi">
                <p>Ini adalah deskripsi buku yang sedang dilihat.</p>
            </div>
            <div class="tab-pane fade" id="detail">
                <p>Penulis: John Doe | Tahun: 2024 | Halaman: 300</p>
            </div>
            <div class="tab-pane fade" id="ulasan">
                <p>Belum ada ulasan untuk buku ini.</p>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `nav nav-tabs` menampilkan navigasi dengan border-bottom khas tab.
- Tab aktif memiliki border-bottom putih (tersembunyi) yang menyatu dengan konten.
- Gunakan `data-bs-toggle="tab"` untuk menghubungkan tab dengan panel konten.
- Panel konten menggunakan class `tab-pane fade` dengan `show active` untuk panel yang tampil.
