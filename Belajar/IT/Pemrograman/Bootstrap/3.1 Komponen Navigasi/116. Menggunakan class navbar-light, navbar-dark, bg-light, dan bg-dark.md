# Menggunakan Class Navbar-light, Navbar-dark, bg-light, dan bg-dark

## Analogi: Perpustakaan Digital

Seperti perpustakaan yang memiliki tema warna tertentu — ada yang terang dengan dinding putih, ada yang gelap dengan suasana hangat — navbar website juga bisa memiliki skema warna yang berbeda. Bootstrap menyediakan class `navbar-light` untuk teks gelap di latar terang, dan `navbar-dark` untuk teks terang di latar gelap. Dengan menambahkan class utilities seperti `bg-light` atau `bg-dark`, Anda dapat dengan cepat mengubah tampilan navbar tanpa menulis CSS kustom.

## Penjelasan Detail

Class `navbar-light` mengatur warna teks dan elemen di dalam navbar menjadi gelap (dark text), cocok digunakan dengan latar belakang terang seperti `bg-light` atau `bg-white`. Sebaliknya, `navbar-dark` mengatur warna teks dan elemen menjadi terang (white text), cocok untuk latar belakang gelap seperti `bg-dark` atau `bg-primary`. Class background seperti `bg-light`, `bg-dark`, `bg-primary`, dan lainnya dapat dikombinasikan secara fleksibel. Perubahan warna ini tidak hanya memengaruhi teks, tetapi juga warna ikon toggler, border, dan efek hover pada nav-link. Kombinasi yang paling umum adalah `navbar-light bg-light` untuk tema terang dan `navbar-dark bg-dark` untuk tema gelap.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tema Navbar</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-expand-lg navbar-light bg-light mb-3">
        <div class="container">
            <a class="navbar-brand" href="#">Tema Terang</a>
        </div>
    </nav>
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark mb-3">
        <div class="container">
            <a class="navbar-brand" href="#">Tema Gelap</a>
        </div>
    </nav>
    <nav class="navbar navbar-expand-lg navbar-dark bg-primary">
        <div class="container">
            <a class="navbar-brand" href="#">Tema Biru</a>
        </div>
    </nav>
    <div class="container mt-4">
        <h1>Variasi Tema Navbar</h1>
        <p>Tiga navbar dengan kombinasi class berbeda.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `navbar-light` membuat teks dan elemen menjadi gelap (untuk latar terang).
- `navbar-dark` membuat teks dan elemen menjadi terang (untuk latar gelap).
- Kombinasikan dengan class `bg-*` untuk menentukan warna latar.
- Pilih kombinasi yang sesuai dengan desain dan brand website Anda.
