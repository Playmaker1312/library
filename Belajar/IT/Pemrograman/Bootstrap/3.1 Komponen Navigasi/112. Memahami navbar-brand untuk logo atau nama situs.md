# Memahami Navbar-brand untuk Logo atau Nama Situs

## Analogi: Perpustakaan Digital

Di sebuah perpustakaan digital, terdapat logo atau nama perpustakaan yang selalu tampil di sudut kiri atas setiap halaman. Logo ini menjadi identitas yang langsung dikenali oleh pengunjung, seperti halnya tanda selamat datang di pintu masuk perpustakaan fisik. Dalam Bootstrap, `navbar-brand` berfungsi seperti logo atau nama tersebut, menjadi elemen yang menonjol dan biasanya berisi tautan ke halaman utama. Ini memberikan konsistensi dan memudahkan pengguna untuk kembali ke beranda kapan saja.

## Penjelasan Detail

Class `navbar-brand` digunakan untuk menampilkan logo, nama situs, atau identitas merek di dalam navbar. Elemen ini biasanya ditempatkan langsung di dalam elemen dengan class `navbar` dan akan mendapatkan styling khusus seperti ukuran font yang lebih besar dan warna yang berbeda untuk membedakannya dari tautan navigasi biasa. `navbar-brand` bisa berupa teks biasa atau elemen `<img>` untuk logo. Jika menggunakan gambar, Bootstrap akan memberikan `height: auto` dan padding yang sesuai agar logo terlihat proporsional. Elemen ini juga mendukung class utilities seperti `me-auto` untuk mendorong elemen lain ke kanan. Sebaiknya bungkus `navbar-brand` dengan elemen `<a>` yang mengarah ke halaman beranda untuk aksesibilitas yang lebih baik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Navbar Brand</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-light bg-light">
        <div class="container">
            <a class="navbar-brand" href="#">
                <img src="https://via.placeholder.com/30x30" alt="" width="30" height="30" class="d-inline-block align-text-top">
                Perpustakaan Digital
            </a>
        </div>
    </nav>
    <div class="container mt-4">
        <h1>Navbar Brand dengan Logo</h1>
        <p>Logo dan nama situs menggunakan class navbar-brand.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `navbar-brand` digunakan untuk logo atau nama situs dan biasanya mengarah ke halaman utama.
- Dapat berupa teks biasa atau elemen `<img>` untuk logo.
- Gunakan `d-inline-block` dan `align-text-top` pada gambar agar sejajar dengan teks.
- Letakkan `navbar-brand` langsung di dalam elemen dengan class `navbar`.
