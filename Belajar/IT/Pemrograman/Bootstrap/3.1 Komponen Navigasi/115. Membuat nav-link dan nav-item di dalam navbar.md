# Membuat Nav-link dan Nav-item di Dalam Navbar

## Analogi: Perpustakaan Digital

Di rak-rak perpustakaan digital, setiap kategori buku ditempatkan dalam rak yang terpisah, dan setiap buku memiliki label yang jelas. Dalam navigasi website, `nav-item` adalah raknya, dan `nav-link` adalah label bukunya. Setiap item menu adalah sebuah `nav-item` yang membungkus `nav-link` sebagai tautan yang dapat diklik. Struktur ini membantu Bootstrap mengatur styling seperti padding, hover effect, dan warna aktif secara konsisten di seluruh menu navigasi.

## Penjelasan Detail

Dalam navbar Bootstrap, setiap tautan menu harus dibungkus dalam struktur berlapis: `<ul>` dengan class `navbar-nav` sebagai wadah utama, `<li>` dengan class `nav-item` untuk setiap item, dan `<a>` atau `<button>` dengan class `nav-link` untuk setiap tautan. Class `nav-link` memberikan styling seperti padding horizontal dan vertikal, warna teks yang sesuai dengan tema navbar, serta efek hover. Untuk menandai halaman yang sedang aktif, tambahkan class `active` pada `nav-link`. Jika ingin menonaktifkan tautan, gunakan class `disabled`. Class `navbar-nav` secara default menggunakan `flex-direction: column` pada layar kecil dan `flex-direction: row` pada layar besar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Nav Item dan Link</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <nav class="navbar navbar-expand-lg navbar-dark bg-primary">
        <div class="container">
            <a class="navbar-brand" href="#">E-Library</a>
            <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navMenu">
                <span class="navbar-toggler-icon"></span>
            </button>
            <div class="collapse navbar-collapse" id="navMenu">
                <ul class="navbar-nav">
                    <li class="nav-item">
                        <a class="nav-link active" href="#">Beranda</a>
                    </li>
                    <li class="nav-item">
                        <a class="nav-link" href="#">Katalog</a>
                    </li>
                    <li class="nav-item">
                        <a class="nav-link" href="#">Peminjaman</a>
                    </li>
                    <li class="nav-item">
                        <a class="nav-link disabled" href="#">Laporan</a>
                    </li>
                </ul>
            </div>
        </div>
    </nav>
    <div class="container mt-4">
        <h1>Nav-item dan Nav-link</h1>
        <p>Menu "Laporan" dinonaktifkan dengan class disabled.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `nav-item` adalah wadah untuk setiap elemen menu (biasanya `<li>`).
- `nav-link` adalah tautan atau tombol di dalam `nav-item` yang dapat diklik.
- Class `active` menandai halaman yang sedang aktif.
- Class `disabled` menonaktifkan tautan tanpa menghapusnya dari tampilan.
