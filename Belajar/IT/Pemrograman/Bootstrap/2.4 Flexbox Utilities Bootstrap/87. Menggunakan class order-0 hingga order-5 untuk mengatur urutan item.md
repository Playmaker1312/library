# Menggunakan class order-0 hingga order-5 untuk mengatur urutan item

## Analogi: Perpustakaan Digital

Di rak buku, pustakawan bisa mengatur ulang urutan buku tanpa memindahkan fisiknya, cukup dengan memberi nomor urut. order-0 sampai order-5 seperti memberikan nomor prioritas pada buku: buku dengan nomor lebih kecil akan ditempatkan lebih dulu. Bootstrap memungkinkan pengaturan ulang urutan flex items dengan class order.

## Penjelasan Detail

Class `order-{nilai}` mengatur properti CSS `order` pada flex items, dengan nilai 0-5. Item dengan order lebih kecil akan tampil lebih dulu dalam flex container. Default order adalah 0. Responsive: `order-md-1`, `order-lg-0`. Berguna untuk mengubah urutan tampilan berdasarkan ukuran layar, misalnya di mobile sidebar muncul di atas konten (order-1) tapi di desktop di samping (order-0). Urutan visual bisa berbeda dari urutan HTML, memudahkan mobile-first design.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Order pada Flex</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { padding: 0.75rem 1rem; border-radius: 4px; color: white; text-align: center; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; display: flex; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Order pada Flex</h1>
        <p><strong>Default (urutan HTML):</strong></p>
        <div class="demo">
            <div class="item bg-danger">Pertama (HTML)</div>
            <div class="item bg-success">Kedua (HTML)</div>
            <div class="item bg-primary">Ketiga (HTML)</div>
        </div>
        <p><strong>Dengan order:</strong></p>
        <div class="demo">
            <div class="item bg-danger order-2">HTML pertama, order-2</div>
            <div class="item bg-success order-1">HTML kedua, order-1</div>
            <div class="item bg-primary order-0">HTML ketiga, order-0 (paling awal)</div>
        </div>
        <p><strong>Responsive order (order-md-1 di tablet+):</strong></p>
        <div class="demo flex-column flex-md-row">
            <div class="item bg-primary order-md-2">Sidebar (order-md-2)</div>
            <div class="item bg-success flex-grow-1 order-md-1">Konten Utama (order-md-1)</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- order-0 hingga order-5 mengatur urutan tampilan flex items
- Nilai lebih kecil tampil lebih dulu
- Responsive: order-{breakpoint}-{nilai}
