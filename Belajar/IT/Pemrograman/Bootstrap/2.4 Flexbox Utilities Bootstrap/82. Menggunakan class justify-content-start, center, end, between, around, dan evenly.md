# Menggunakan class justify-content-start, center, end, between, around, dan evenly

## Analogi: Perpustakaan Digital

Rak buku bisa mengatur posisi buku secara horizontal: start (rata kiri), center (rata tengah), end (rata kanan), between (jarak merata antar buku), around (jarak merata termasuk tepi), evenly (jarak benar-benar sama). Pustakawan bisa memilih distribusi buku yang sesuai dengan class justify-content.

## Penjelasan Detail

Class `justify-content-*` mengatur distribusi flex items sepanjang sumbu utama (main axis). `start` (default) merapat ke awal, `center` ke tengah, `end` ke akhir, `between` jarak sama antar item tanpa margin tepi, `around` jarak sama dengan setengah jarak di tepi, `evenly` jarak benar-benar sama semua sisi. Responsive: `justify-content-md-center`, `justify-content-lg-between`. Class ini hanya bekerja pada flex container (d-flex). Sangat berguna untuk navigasi, toolbar, dan distribusi layout.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Justify Content</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #198754; color: white; padding: 0.5rem 1rem; border-radius: 4px; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; margin-bottom: 1rem; display: flex; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Justify Content</h1>
        <p>justify-content-start:</p>
        <div class="demo justify-content-start"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
        <p>justify-content-center:</p>
        <div class="demo justify-content-center"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
        <p>justify-content-end:</p>
        <div class="demo justify-content-end"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
        <p>justify-content-between:</p>
        <div class="demo justify-content-between"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
        <p>justify-content-around:</p>
        <div class="demo justify-content-around"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
        <p>justify-content-evenly:</p>
        <div class="demo justify-content-evenly"><div class="item">1</div><div class="item">2</div><div class="item">3</div></div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- justify-content mengatur distribusi items di sumbu utama flex
- Tersedia: start, center, end, between, around, evenly
- Responsive: justify-content-{breakpoint}-{value}
