# Menggunakan class flex-row dan flex-column untuk arah flexbox

## Analogi: Perpustakaan Digital

Rak buku bisa mengatur buku secara horizontal berjejer ke samping (flex-row) atau vertikal bertumpuk ke bawah (flex-column). Seperti perpustakaan yang bisa memajang buku berjajar di rak panjang atau menumpuknya di rak vertikal. Pustakawan menentukan arah dengan class flex-row atau flex-column.

## Penjelasan Detail

Class `flex-row` mengatur arah flexbox menjadi horizontal (default), dengan item berjejer dari kiri ke kanan. `flex-column` mengubah arah menjadi vertikal, item bertumpuk dari atas ke bawah. `flex-row-reverse` membalik urutan horizontal (kanan ke kiri), `flex-column-reverse` membalik urutan vertikal (bawah ke atas). Class ini hanya berfungsi pada elemen dengan `d-flex`. Responsive: `flex-md-row`, `flex-lg-column`. Pemilihan arah flexbox menentukan bagaimana justify-content dan align-items bekerja (sumbu utama dan sumbu silang berubah).

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flex Row dan Column</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #0d6efd; color: white; padding: 0.75rem 1rem; margin: 0.25rem; border-radius: 4px; text-align: center; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Flex Row & Column</h1>
        <p><strong>flex-row (default):</strong></p>
        <div class="demo d-flex flex-row">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
        </div>
        <p><strong>flex-column:</strong></p>
        <div class="demo d-flex flex-column" style="width:200px;">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
        </div>
        <p><strong>flex-row-reverse:</strong></p>
        <div class="demo d-flex flex-row-reverse">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
        </div>
        <p><strong>flex-column-reverse:</strong></p>
        <div class="demo d-flex flex-column-reverse" style="width:200px;">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- flex-row = horizontal (default), flex-column = vertikal
- Tersedia reverse: flex-row-reverse dan flex-column-reverse
- Arah flexbox menentukan perilaku justify-content dan align-items
