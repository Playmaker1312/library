# Membuat layout praktis menggunakan kombinasi flexbox utilities Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan modern membutuhkan berbagai tata letak: navbar di atas, sidebar di samping, konten utama di tengah, dan footer di bawah. Dengan menggabungkan berbagai class flexbox, pustakawan bisa membangun layout kompleks seperti navbar dengan logo kiri dan menu kanan, card grid, dan halaman penuh yang responsif.

## Penjelasan Detail

Flexbox utilities Bootstrap dapat dikombinasikan untuk membuat layout praktis sehari-hari. Contoh layout: navbar dengan logo kiri dan menu kanan (justify-content-between), card grid dengan wrap (flex-wrap + gap), sidebar dan konten utama (flex-grow-1), footer menempel bawah (mt-auto), centering konten (justify-content-center + align-items-center). Kombinasi flexbox dengan spacing utilities (margin, padding, gap) dan display utilities menghasilkan layout yang bersih dan responsif tanpa CSS kustom.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Layout Praktis Flexbox</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="d-flex flex-column min-vh-100">
        <nav class="navbar navbar-expand-lg bg-primary" data-bs-theme="dark">
            <div class="container d-flex justify-content-between align-items-center">
                <span class="navbar-brand mb-0">MyLibrary</span>
                <div class="d-flex gap-3">
                    <a href="#" class="text-white text-decoration-none">Beranda</a>
                    <a href="#" class="text-white text-decoration-none">Koleksi</a>
                    <a href="#" class="text-white text-decoration-none">Tentang</a>
                </div>
            </div>
        </nav>
        <div class="container flex-grow-1 d-flex flex-column flex-md-row gap-4 py-4">
            <aside class="bg-light p-3 rounded" style="min-width:200px;">
                <h5>Sidebar</h5>
                <ul class="list-unstyled">
                    <li>Kategori 1</li>
                    <li>Kategori 2</li>
                    <li>Kategori 3</li>
                </ul>
            </aside>
            <main class="flex-grow-1">
                <h1>Konten Utama</h1>
                <div class="d-flex flex-wrap gap-3">
                    <div class="card" style="width:200px;">
                        <div class="card-body">
                            <h5 class="card-title">Buku 1</h5>
                            <p class="card-text">Deskripsi buku.</p>
                        </div>
                    </div>
                    <div class="card" style="width:200px;">
                        <div class="card-body">
                            <h5 class="card-title">Buku 2</h5>
                            <p class="card-text">Deskripsi buku.</p>
                        </div>
                    </div>
                    <div class="card" style="width:200px;">
                        <div class="card-body">
                            <h5 class="card-title">Buku 3</h5>
                            <p class="card-text">Deskripsi buku.</p>
                        </div>
                    </div>
                </div>
            </main>
        </div>
        <footer class="bg-dark text-white text-center py-3 mt-auto">
            &copy; 2024 MyLibrary
        </footer>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Kombinasikan flexbox, spacing, dan display utilities untuk layout lengkap
- Gunakan mt-auto untuk footer menempel bawah
- flex-wrap + gap untuk card grid responsif
