# Menggunakan class flex-wrap, flex-nowrap, dan flex-wrap-reverse

## Analogi: Perpustakaan Digital

Rak buku yang penuh bisa mengatur apakah buku yang kelebihan akan turun ke baris baru (flex-wrap) atau tetap dipaksakan dalam satu baris (flex-nowrap). flex-wrap seperti rak yang otomatis menambahkan baris baru jika penuh, flex-nowrap memaksa semua buku dalam satu baris sehingga bisa meluber.

## Penjelasan Detail

Class `flex-wrap` mengatur `flex-wrap: wrap` sehingga flex items turun ke baris baru jika tidak cukup ruang. `flex-nowrap` (default) memaksa semua items dalam satu baris. `flex-wrap-reverse` membungkus ke baris baru dengan urutan terbalik. Berguna untuk layout responsif di mana item harus menyesuaikan jumlah kolom berdasarkan lebar layar. Responsive: `flex-md-wrap`, `flex-lg-nowrap`. Tanpa wrapping, item bisa menyusut (shrink) jika flex-shrink aktif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flex Wrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #fd7e14; color: white; padding: 0.75rem; border-radius: 4px; width: 120px; text-align: center; margin: 0.25rem; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; display: flex; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Flex Wrap</h1>
        <p><strong>flex-nowrap (default, overflow):</strong></p>
        <div class="demo flex-nowrap">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
            <div class="item">Item 4</div>
            <div class="item">Item 5</div>
            <div class="item">Item 6</div>
        </div>
        <p><strong>flex-wrap:</strong></p>
        <div class="demo flex-wrap">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
            <div class="item">Item 4</div>
            <div class="item">Item 5</div>
            <div class="item">Item 6</div>
        </div>
        <p><strong>flex-wrap-reverse:</strong></p>
        <div class="demo flex-wrap-reverse">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
            <div class="item">Item 4</div>
            <div class="item">Item 5</div>
            <div class="item">Item 6</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- flex-wrap: item turun ke baris baru jika penuh
- flex-nowrap: semua item dipaksa dalam satu baris
- flex-wrap-reverse: wrap dengan urutan baris terbalik
