# Menggunakan class align-content untuk mengatur alignment multi-baris

## Analogi: Perpustakaan Digital

Ketika buku berbaris dalam beberapa baris di rak, align-content mengatur bagaimana baris-baris tersebut didistribusikan secara vertikal. Seperti mengatur jarak antar baris buku: start (rapat ke atas), center (tengah), end (rapat ke bawah), between (jarak merata antar baris), around (jarak merata termasuk tepi), stretch (baris diregangkan).

## Penjelasan Detail

Class `align-content-*` mengatur alignment baris-baris flex items ketika ada multiple baris (wrapping). Nilai: `start`, `center`, `end`, `between`, `around`, `stretch` (default). Hanya berfungsi jika flex-wrap aktif dan ada lebih dari satu baris. Berbeda dengan align-items yang mengatur item dalam satu baris, align-content mengatur distribusi baris-baris dalam container. Responsive: `align-content-md-center`. Berguna untuk grid item yang membungkus ke baris baru.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Align Content</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #0d6efd; color: white; padding: 0.75rem; border-radius: 4px; width: 100px; text-align: center; margin: 0.25rem; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; height: 250px; display: flex; flex-wrap: wrap; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Align Content</h1>
        <p><strong>align-content-start:</strong></p>
        <div class="demo align-content-start">
            <div class="item">1</div><div class="item">2</div><div class="item">3</div>
            <div class="item">4</div><div class="item">5</div><div class="item">6</div>
        </div>
        <p><strong>align-content-center:</strong></p>
        <div class="demo align-content-center">
            <div class="item">1</div><div class="item">2</div><div class="item">3</div>
            <div class="item">4</div><div class="item">5</div><div class="item">6</div>
        </div>
        <p><strong>align-content-end:</strong></p>
        <div class="demo align-content-end">
            <div class="item">1</div><div class="item">2</div><div class="item">3</div>
            <div class="item">4</div><div class="item">5</div><div class="item">6</div>
        </div>
        <p><strong>align-content-between:</strong></p>
        <div class="demo align-content-between">
            <div class="item">1</div><div class="item">2</div><div class="item">3</div>
            <div class="item">4</div><div class="item">5</div><div class="item">6</div>
        </div>
        <p><strong>align-content-around:</strong></p>
        <div class="demo align-content-around">
            <div class="item">1</div><div class="item">2</div><div class="item">3</div>
            <div class="item">4</div><div class="item">5</div><div class="item">6</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- align-content mengatur distribusi baris, bukan item individual
- Hanya bekerja dengan flex-wrap dan multi-baris
- Tersedia: start, center, end, between, around, stretch
