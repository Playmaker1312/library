# Menggunakan class align-self untuk mengatur alignment item individual

## Analogi: Perpustakaan Digital

Dalam satu rak buku, sebagian besar buku mungkin rata tengah, tetapi satu buku tertentu bisa diatur lebih tinggi atau lebih rendah dari yang lain. align-self memungkinkan satu item flex memiliki alignment berbeda dari item lainnya. Seperti buku yang sengaja ditempatkan lebih tinggi untuk menarik perhatian.

## Penjelasan Detail

Class `align-self-*` mengatur alignment item flex individual, meng-override align-items dari container. Nilai: `start`, `center`, `end`, `baseline`, `stretch`. Hanya berlaku pada flex items (anak langsung dari flex container). Responsive: `align-self-md-center`. Berguna saat satu item perlu diposisikan berbeda dari yang lain, misalnya tombol "action" yang ingin diposisikan di bawah dalam card yang sama.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Align Self</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #6f42c1; color: white; padding: 0.5rem 1rem; border-radius: 4px; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; height: 150px; display: flex; align-items: center; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Align Self</h1>
        <div class="demo">
            <div class="item">Default (center)</div>
            <div class="item align-self-start">align-self-start</div>
            <div class="item align-self-center">center</div>
            <div class="item align-self-end">align-self-end</div>
            <div class="item align-self-stretch">stretch</div>
        </div>
        <div class="demo align-items-start">
            <div class="item">Parent: start</div>
            <div class="item align-self-end">align-self-end</div>
            <div class="item align-self-stretch">stretch</div>
        </div>
        <p class="text-muted">align-self meng-override align-items dari parent untuk item tertentu.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- align-self untuk alignment individual flex item
- Tersedia: start, center, end, baseline, stretch
- Meng-override align-items dari container
