# Menggunakan class align-items-start, center, end, baseline, dan stretch

## Analogi: Perpustakaan Digital

Rak buku vertikal bisa mengatur posisi buku secara vertikal: start (rata atas), center (rata tengah), end (rata bawah), stretch (memenuhi tinggi rak), baseline (sejajar garis dasar teks). Seperti buku yang diatur posisi tingginya di dalam rak, Bootstrap menyediakan class align-items untuk alignment vertikal.

## Penjelasan Detail

Class `align-items-*` mengatur alignment flex items sepanjang sumbu silang (cross axis). `start` ke tepi awal, `center` ke tengah, `end` ke tepi akhir, `baseline` sejajar dengan baseline teks, `stretch` (default) meregangkan items setinggi container. Sangat berguna untuk menyelaraskan item dengan tinggi berbeda. Responsive: `align-items-md-center`. Pada flex-row, sumbu silang adalah vertikal; pada flex-column, sumbu silang adalah horizontal.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Align Items</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #dc3545; color: white; padding: 0.5rem; border-radius: 4px; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; height: 120px; display: flex; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Align Items</h1>
        <p>align-items-start:</p>
        <div class="demo align-items-start">
            <div class="item" style="padding:1rem 0.5rem;">Item A</div>
            <div class="item" style="padding:2rem 0.5rem;">Item B</div>
            <div class="item" style="padding:0.5rem 0.5rem;">Item C</div>
        </div>
        <p>align-items-center:</p>
        <div class="demo align-items-center">
            <div class="item" style="padding:1rem 0.5rem;">Item A</div>
            <div class="item" style="padding:2rem 0.5rem;">Item B</div>
            <div class="item" style="padding:0.5rem 0.5rem;">Item C</div>
        </div>
        <p>align-items-end:</p>
        <div class="demo align-items-end">
            <div class="item" style="padding:1rem 0.5rem;">Item A</div>
            <div class="item" style="padding:2rem 0.5rem;">Item B</div>
            <div class="item" style="padding:0.5rem 0.5rem;">Item C</div>
        </div>
        <p>align-items-stretch (default):</p>
        <div class="demo align-items-stretch">
            <div class="item">Item A</div>
            <div class="item">Item B</div>
            <div class="item">Item C</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- align-items mengatur alignment items di sumbu silang flex
- Tersedia: start, center, end, baseline, stretch
- Responsive: align-items-{breakpoint}-{value}
