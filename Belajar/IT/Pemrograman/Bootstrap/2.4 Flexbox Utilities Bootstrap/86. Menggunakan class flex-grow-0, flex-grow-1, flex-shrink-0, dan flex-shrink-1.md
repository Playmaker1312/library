# Menggunakan class flex-grow-0, flex-grow-1, flex-shrink-0, dan flex-shrink-1

## Analogi: Perpustakaan Digital

Rak buku yang fleksibel: beberapa buku bisa tumbuh (grow) memenuhi ruang kosong, sementara yang lain tetap (grow-0). Beberapa buku bisa menyusut (shrink) jika ruang sempit, sementara yang lain tidak mau menyusut (shrink-0). Seperti buku yang bisa mengembang atau mengkerut sesuai ruang rak yang tersedia.

## Penjelasan Detail

Class `flex-grow-1` memungkinkan item tumbuh memenuhi ruang kosong yang tersedia di flex container. `flex-grow-0` (default) mencegah pertumbuhan. `flex-shrink-1` (default) memungkinkan item menyusut jika ruang tidak cukup. `flex-shrink-0` mencegah penyusutan. flex-grow berguna untuk membuat item mengisi sisa ruang, seperti sidebar dan konten utama. flex-shrink berguna untuk item yang tidak boleh mengecil, seperti logo atau ikon.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flex Grow dan Shrink</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #20c997; color: white; padding: 0.75rem; border-radius: 4px; text-align: center; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; display: flex; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Flex Grow & Shrink</h1>
        <p><strong>flex-grow-1 pada item tengah:</strong></p>
        <div class="demo">
            <div class="item">Kiri</div>
            <div class="item flex-grow-1">flex-grow-1 (mengisi sisa)</div>
            <div class="item">Kanan</div>
        </div>
        <p><strong>Semua flex-grow-1:</strong></p>
        <div class="demo">
            <div class="item flex-grow-1">grow-1</div>
            <div class="item flex-grow-1">grow-1</div>
            <div class="item flex-grow-1">grow-1</div>
        </div>
        <p><strong>flex-shrink-0 (tidak menyusut):</strong></p>
        <div class="demo" style="width:300px;">
            <div class="item flex-shrink-0" style="width:200px;">shrink-0 (200px)</div>
            <div class="item" style="background:#0d6efd;">Ini menyusut</div>
        </div>
        <p><strong>Kombinasi flex-grow-0 dan flex-grow-1:</strong></p>
        <div class="demo">
            <div class="item flex-grow-0" style="width:80px;">grow-0</div>
            <div class="item flex-grow-1">grow-1</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- flex-grow-1: item tumbuh mengisi ruang kosong
- flex-shrink-0: item tidak menyusut saat ruang sempit
- Kombinasi grow dan shrink untuk layout fleksibel
