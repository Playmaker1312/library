# Memahami responsive flexbox utilities seperti flex-md-row dan justify-content-lg-center

## Analogi: Perpustakaan Digital

Rak buku yang cerdas bisa mengubah arah dan posisinya tergantung ukuran ruangan. Di layar lebar, buku berjejer horizontal (flex-lg-row) dan rata tengah (justify-content-lg-center). Di layar sempit, buku bertumpuk vertikal (flex-column). Pustakawan cukup menentukan aturan untuk setiap ukuran ruang dengan class flexbox responsif.

## Penjelasan Detail

Semua class flexbox Bootstrap dapat digunakan secara responsif dengan format `{class}-{breakpoint}-{value}`. Breakpoint: sm, md, lg, xl, xxl. Contoh: `flex-md-row` mengatur arah row pada md ke atas, `justify-content-lg-center` rata tengah pada lg ke atas. Pola umum: `d-flex flex-column flex-md-row` untuk layout yang vertikal di mobile dan horizontal di desktop. Responsive flexbox sangat penting untuk mobile-first design, memungkinkan tata letak beradaptasi dengan mulus di semua ukuran layar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Flexbox</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .item { background-color: #0d6efd; color: white; padding: 0.75rem; border-radius: 4px; margin: 0.25rem; text-align: center; }
        .demo { background-color: #f8f9fa; border: 2px dashed #dee2e6; padding: 0.5rem; margin-bottom: 1rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Responsive Flexbox</h1>
        <p><strong>Mobile: column, Desktop: row (flex-column flex-md-row):</strong></p>
        <div class="demo d-flex flex-column flex-md-row">
            <div class="item">Item 1</div>
            <div class="item">Item 2</div>
            <div class="item">Item 3</div>
        </div>
        <p><strong>Mobile: start, Desktop: center (justify-content-center justify-content-lg-end):</strong></p>
        <div class="demo d-flex justify-content-center justify-content-lg-end">
            <div class="item">Kiri</div>
            <div class="item">Kanan</div>
        </div>
        <p><strong>Mobile: wrap, Desktop: nowrap (flex-wrap flex-lg-nowrap):</strong></p>
        <div class="demo d-flex flex-wrap flex-lg-nowrap">
            <div class="item" style="width:150px;">Item 1 (150px)</div>
            <div class="item" style="width:150px;">Item 2 (150px)</div>
            <div class="item" style="width:150px;">Item 3 (150px)</div>
            <div class="item" style="width:150px;">Item 4 (150px)</div>
        </div>
        <p class="text-muted">Resize browser untuk melihat perubahan pada setiap breakpoint.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Format responsive flexbox: {class}-{breakpoint}-{value}
- Gunakan d-flex flex-column flex-md-row untuk layout mobile-first
- Semua class flexbox (justify, align, flex, order) mendukung responsive
