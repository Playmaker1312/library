# Cara Memigrasikan Project dari Bootstrap 4 ke Bootstrap 5

## Analogi: Perpustakaan Digital

Migrasi Bootstrap 4 ke 5 adalah seperti merenovasi perpustakaan—rak buku lama diganti dengan yang baru, sistem klasifikasi diperbarui, dan beberapa bagian gedung diubah tata letaknya. Proses ini perlu perencanaan matang agar koleksi buku tidak rusak dan pengunjung tetap bisa menggunakan perpustakaan selama renovasi. Bootstrap 5 membawa banyak perubahan yang meningkatkan kinerja dan fleksibilitas.

## Penjelasan Detail

Perubahan utama Bootstrap 4 ke 5: (1) jQuery dihapus—Bootstrap 5 menggunakan JavaScript vanilla, (2) Internet Explorer 11 tidak lagi didukung, (3) Class `ml-*` dan `mr-*` diganti dengan `ms-*` dan `me-*` (karena RTL support), (4) `float-left`/`float-right` diganti `float-start`/`float-end`, (5) `form-group` dihapus, (6) `btn-block` diganti dengan `d-grid` + `w-100`, (7) `jumbotron` dihapus, (8) Custom form components diganti dengan CSS native (form-switch, form-select). Langkah migrasi: backup project, update CDN links, ganti class yang di-deprecate, test komponen, dan perbaiki JavaScript custom.

## Poin Penting
- Perubahan utama BS4 ke BS5: jQuery dihapus, class RTL, form-group dihapus, jumbotron dihapus.
- Gunakan checklist migrasi untuk memastikan semua perubahan tercakup.
- Selalu backup project dan lakukan testing menyeluruh setelah migrasi.
