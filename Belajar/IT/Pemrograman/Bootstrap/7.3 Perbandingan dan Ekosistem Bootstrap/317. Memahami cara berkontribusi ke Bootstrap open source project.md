# Memahami Cara Berkontribusi ke Bootstrap Open Source Project

## Analogi: Perpustakaan Digital

Berkontribusi ke Bootstrap open source seperti menjadi sukarelawan di perpustakaan umum. Anda bisa membantu merapikan rak (memperbaiki bug), menulis petunjuk untuk pengunjung (dokumentasi), atau menyarankan buku baru untuk koleksi (fitur baru). Setiap kontribusi, sekecil apapun, membantu perpustakaan menjadi lebih baik untuk semua pengunjung. Bootstrap adalah proyek open source yang menerima kontribusi dari siapa saja.

## Penjelasan Detail

Cara berkontribusi ke Bootstrap: (1) Laporkan bug di GitHub Issues—sertakan langkah reproduksi, browser, dan versi Bootstrap, (2) Perbaiki bug dengan mengirim pull request, (3) Tingkatkan dokumentasi—perbaiki typo, tambahkan contoh, atau terjemahkan, (4) Bantu menjawab pertanyaan di Stack Overflow atau GitHub Discussions, (5) Kontribusi kode: ikuti panduan kontribusi di CONTRIBUTING.md, jalankan build dan test lokal, (6) Bantu review pull request dari kontributor lain. Pastikan membaca code of conduct Bootstrap.

## Poin Penting
- Kontribusi ke Bootstrap bisa berupa laporan bug, perbaikan dokumentasi, atau kode.
- Ikuti panduan kontribusi di CONTRIBUTING.md dan jalankan test sebelum mengirim pull request.
- Mulailah dengan kontribusi kecil untuk memahami alur kerja kolaborasi open source Bootstrap.
