# Perbedaan Bootstrap 4 dan Bootstrap 5 Secara Menyeluruh

## Analogi: Perpustakaan Digital

Bayangkan dua edisi buku panduan membangun rumah. Edisi pertama (Bootstrap 4) membutuhkan alat khusus bernama jQuery untuk beberapa pekerjaan dan menggunakan sistem pengaturan yang kaku. Edisi kedua (Bootstrap 5) hadir dengan alat yang sudah terintegrasi tanpa perlu tambahan eksternal, sistem pengaturan yang lebih fleksibel, dan tata letak yang lebih modern. Perpustakaan digital ini terus menyempurnakan koleksinya agar pengunjung dapat membuat website dengan lebih cepat dan efisien.

## Penjelasan Detail

Bootstrap 5 membawa perubahan fundamental dari pendahulunya. Perbedaan paling signifikan adalah penghapusan dependensi jQuery, yang berarti ukuran file lebih kecil dan performa lebih baik. Bootstrap 5 juga mengganti library Popper.js yang lama dengan versi terbaru untuk tooltip dan popover. Dari segi grid, Bootstrap 5 menambahkan breakpoint xxl (1400px) dan mengubah gutter dari padding menjadi gap. Sistem utility pada Bootstrap 5 diperkenalkan sebagai Utility API yang memungkinkan pembuatan class utility kustom dengan mudah. Bootstrap 5 juga menambahkan dukungan untuk CSS custom properties, komponen offcanvas, dan floating labels yang tidak ada di Bootstrap 4.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Bootstrap 4 vs 5</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1 class="mb-4">Bootstrap 4 vs Bootstrap 5</h1>
        <table class="table table-bordered">
            <thead class="table-dark">
                <tr>
                    <th>Fitur</th>
                    <th>Bootstrap 4</th>
                    <th>Bootstrap 5</th>
                </tr>
            </thead>
            <tbody>
                <tr>
                    <td>jQuery</td>
                    <td class="text-danger">Wajib</td>
                    <td class="text-success">Tidak diperlukan</td>
                </tr>
                <tr>
                    <td>Grid</td>
                    <td>5 breakpoint</td>
                    <td>6 breakpoint + xxl</td>
                </tr>
                <tr>
                    <td>Gutter</td>
                    <td>Padding-based</td>
                    <td class="text-success">Gap-based</td>
                </tr>
                <tr>
                    <td>Utility</td>
                    <td>Terbatas</td>
                    <td class="text-success">Utility API</td>
                </tr>
            </tbody>
        </table>
        <div class="alert alert-info mt-3">Bootstrap 5 lebih ringan, lebih cepat, dan lebih modern.</div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Bootstrap 5 menghapus jQuery sehingga bundle size berkurang drastis
- Breakpoint xxl (1400px) ditambahkan untuk layar ultrawide
- CSS custom properties memungkinkan kustomisasi tema tanpa Sass
- Utility API memberikan fleksibilitas tak terbatas untuk class utility
