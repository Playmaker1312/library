# Struktur Folder dan File Bootstrap yang Wajib Dipahami

## Analogi: Perpustakaan Digital

Struktur folder Bootstrap seperti katalog perpustakaan yang terorganisir rapi. Setiap rak (folder) memiliki kategori buku tertentu: rak CSS berisi buku tentang tata letak dan gaya, rak JS berisi buku tentang interaksi dan animasi, dan rak SCSS berisi cetak biru untuk membuat buku baru. Memahami struktur ini membantu Anda menemukan dengan cepat apa yang Anda butuhkan tanpa membuang waktu.

## Penjelasan Detail

Setelah mengunduh Bootstrap, Anda akan melihat struktur folder utama: `css/`, `js/`, dan `scss/`. Folder `css/` berisi file bootstrap.css (versi tidak terminifikasi, mudah dibaca), bootstrap.min.css (versi terminifikasi untuk production), bootstrap-grid.css (grid system saja), bootstrap-reboot.css (normalisasi CSS), dan bootstrap-utilities.css (utility classes saja). Folder `js/` berisi bootstrap.js (JavaScript murni), bootstrap.min.js (terminifikasi), bootstrap.bundle.js (termasuk Popper.js), dan bootstrap.bundle.min.js. Folder `scss/` berisi file sumber Sass yang digunakan untuk kustomisasi. File `bootstrap.bundle.*` adalah yang paling umum digunakan karena sudah termasuk Popper.js untuk tooltip dan popover.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Struktur Folder Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Struktur File Bootstrap</h1>
        <ul class="list-group mt-3">
            <li class="list-group-item list-group-item-primary fw-bold">📁 css/</li>
            <li class="list-group-item ps-5">bootstrap.css</li>
            <li class="list-group-item ps-5">bootstrap.min.css <span class="badge bg-success">Production</span></li>
            <li class="list-group-item ps-5">bootstrap-grid.css</li>
            <li class="list-group-item ps-5">bootstrap-reboot.css</li>
            <li class="list-group-item list-group-item-primary fw-bold">📁 js/</li>
            <li class="list-group-item ps-5">bootstrap.bundle.min.js <span class="badge bg-info">Rekomendasi</span></li>
            <li class="list-group-item ps-5">bootstrap.min.js</li>
            <li class="list-group-item list-group-item-primary fw-bold">📁 scss/</li>
        </ul>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- File `.min.css` dan `.min.js` adalah versi terminifikasi untuk production
- `bootstrap.bundle.js` sudah termasuk Popper.js, tidak perlu install terpisah
- Folder `scss/` untuk kustomisasi lanjutan dengan Sass
- Gunakan file terpisah seperti bootstrap-grid.css jika hanya butuh grid saja
