# Cara Instalasi Bootstrap dengan Mengunduh File Langsung dari Situs Resmi

## Analogi: Perpustakaan Digital

Mengunduh Bootstrap langsung dari situs resmi seperti memfotokopi seluruh buku dari perpustakaan dan menyimpannya di lemari pribadi. Anda memiliki salinan lengkap yang bisa digunakan kapan saja tanpa perlu koneksi internet. Anda bisa mengatur sendiri bagaimana buku-buku tersebut disusun dan digunakan dalam proyek Anda. Metode ini memberi Anda kontrol penuh atas file yang digunakan.

## Penjelasan Detail

Situs resmi Bootstrap (getbootstrap.com) menyediakan opsi unduhan langsung dalam bentuk file ZIP. Setelah mengunduh, Anda perlu mengekstrak file ZIP tersebut ke dalam folder proyek Anda, biasanya dalam subfolder bernama css dan js. Folder css berisi bootstrap.css, bootstrap.min.css, dan file CSS Grid serta Reboot. Folder js berisi bootstrap.js, bootstrap.min.js, bootstrap.bundle.js, dan bootstrap.bundle.min.js. Anda kemudian menghubungkan file-file ini ke HTML menggunakan tag `<link>` dan `<script>` dengan path relatif. Meskipun metode ini tidak merepotkan, Anda harus memperbarui file secara manual setiap kali ada versi Bootstrap baru.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Instalasi Bootstrap via Download</title>
    <link href="css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container text-center py-5">
        <h1 class="text-success">Bootstrap via Download</h1>
        <div class="card mx-auto" style="max-width: 400px;">
            <div class="card-body">
                <h5 class="card-title">File Lokal</h5>
                <p class="card-text">File bootstrap.min.css dan bootstrap.bundle.min.js ada di folder proyek.</p>
                <span class="badge bg-success">Terinstal Lokal</span>
            </div>
        </div>
    </div>
    <script src="js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Unduh file ZIP dari getbootstrap.com lalu ekstrak ke folder proyek
- Tidak memerlukan koneksi internet setelah diunduh
- Harus memperbarui file secara manual untuk versi baru
- Cocok untuk proyek yang tidak terhubung internet atau offline
