# Apa itu Bootstrap dan Sejarah Perkembangannya dari Versi 1 hingga Versi 5

## Analogi: Perpustakaan Digital

Bootstrap seperti perpustakaan digital yang sudah memiliki ribuan buku siap pakai. Anda tidak perlu menulis setiap halaman dari awal, cukup meminjam buku yang sesuai kebutuhan dan menggabungkannya menjadi satu karya. Perpustakaan ini terus diperbarui dengan edisi baru yang lebih modern dan lengkap setiap beberapa tahun. Dari versi pertama yang sederhana hingga versi kelima yang sangat canggih, setiap edisi membawa perbaikan dan fitur baru.

## Penjelasan Detail

Bootstrap adalah framework CSS open-source yang dikembangkan oleh Mark Otto dan Jacob Thornton di Twitter pada tahun 2011. Awalnya bernama Twitter Blueprint, Bootstrap dirancang untuk menstandarisasi alat pengembangan front-end di perusahaan tersebut. Versi 1 (2011) memperkenalkan grid system dasar, komponen UI sederhana, dan JavaScript plugin. Versi 2 (2012) menambahkan responsive design dengan 12-column grid yang inovatif pada zamannya. Versi 3 (2013) mengadopsi pendekatan mobile-first dengan desain flat yang lebih modern. Versi 4 (2018) membawa perubahan besar dengan beralih ke Flexbox, menghilangkan dukungan untuk IE8, dan menggunakan Sass sebagai preprocessor. Versi 5 (2021) menghapus jQuery sebagai dependensi, menambahkan utility API, dan meningkatkan performa CSS custom properties.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sejarah Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1 class="text-center mb-4">Evolusi Bootstrap</h1>
        <div class="row">
            <div class="col-md-4 mb-3">
                <div class="card">
                    <div class="card-header bg-dark text-white">v1 - 2011</div>
                    <div class="card-body">
                        <p class="card-text">Grid system dasar, komponen UI sederhana, JavaScript plugin.</p>
                    </div>
                </div>
            </div>
            <div class="col-md-4 mb-3">
                <div class="card">
                    <div class="card-header bg-dark text-white">v3 - 2013</div>
                    <div class="card-body">
                        <p class="card-text">Mobile-first, desain flat, responsive grid 12 kolom.</p>
                    </div>
                </div>
            </div>
            <div class="col-md-4 mb-3">
                <div class="card">
                    <div class="card-header bg-dark text-white">v5 - 2021</div>
                    <div class="card-body">
                        <p class="card-text">Tanpa jQuery, Utility API, CSS custom properties.</p>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Bootstrap dibuat oleh pengembang Twitter untuk menstandarisasi alat front-end internal mereka
- Setiap versi membawa perubahan arsitektur yang signifikan, dari jQuery ke vanilla JS
- Versi 5 menghilangkan ketergantungan pada jQuery sehingga bundle size lebih kecil
- Bootstrap tetap menjadi framework CSS paling populer di dunia sejak dirilis
