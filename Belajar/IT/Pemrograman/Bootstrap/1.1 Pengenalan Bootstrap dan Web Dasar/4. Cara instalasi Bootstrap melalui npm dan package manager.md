# Cara Instalasi Bootstrap Melalui npm dan Package Manager

## Analogi: Perpustakaan Digital

Menginstal Bootstrap melalui npm seperti memiliki kartu anggota perpustakaan yang memungkinkan Anda meminjam buku untuk dibawa pulang. Anda bisa menyimpan buku-buku tersebut di rak pribadi (folder node_modules) dan mengelolanya dengan sistem katalog otomatis. Package manager adalah pustakawan digital yang mencatat semua buku yang Anda pinjam, versinya, dan memastikan tidak ada buku yang hilang atau bentrok satu sama lain.

## Penjelasan Detail

npm (Node Package Manager) adalah package manager standar untuk JavaScript. Untuk menginstal Bootstrap melalui npm, jalankan perintah `npm install bootstrap` di terminal proyek Anda. Setelah terinstal, Anda akan menemukan folder bootstrap di dalam node_modules. Untuk menggunakannya, Anda perlu mengimpor file CSS dan JS menggunakan bundler seperti Webpack, Vite, atau Laravel Mix. Bootstrap juga mendukung package manager lain seperti yarn, pnpm, dan Composer untuk proyek PHP. Metode ini ideal untuk proyek besar yang memerlukan kustomisasi mendalam melalui Sass dan membutuhkan manajemen dependensi yang terstruktur.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Instalasi Bootstrap via npm</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Instalasi via npm</h1>
        <p class="lead">Jalankan perintah berikut di terminal:</p>
        <div class="bg-dark text-success p-3 rounded mb-3">
            <code>npm install bootstrap@5.3.3</code>
        </div>
        <p>Kemudian import dalam file JavaScript Anda:</p>
        <div class="bg-dark text-success p-3 rounded">
            <code>import 'bootstrap/dist/css/bootstrap.min.css';<br>import 'bootstrap/dist/js/bootstrap.bundle.min.js';</code>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- npm install bootstrap@5.3.3 untuk versi spesifik
- Integrasi dengan module bundler seperti Webpack atau Vite
- Memungkinkan kustomisasi Sass Bootstrap secara penuh
- Wajib untuk proyek production berskala besar
