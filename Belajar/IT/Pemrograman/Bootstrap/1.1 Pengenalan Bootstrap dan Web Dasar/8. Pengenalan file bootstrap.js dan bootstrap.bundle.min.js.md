# Pengenalan File bootstrap.js dan bootstrap.bundle.min.js

## Analogi: Perpustakaan Digital

File JavaScript Bootstrap seperti buku panduan interaktif di perpustakaan. bootstrap.js adalah buku panduan utama yang berisi semua instruksi untuk membuat halaman web menjadi hidup. bootstrap.bundle.js adalah paket kombo yang sudah termasuk buku panduan tambahan (Popper.js) untuk fitur tooltip dan popover. Anda bisa meminjam buku panduan utama saja, atau paket lengkap yang sudah termasuk semua yang Anda butuhkan.

## Penjelasan Detail

bootstrap.js berisi semua komponen JavaScript Bootstrap seperti modal, dropdown, carousel, collapse, tabs, tooltips, popovers, dan scrollspy. File ini tidak menyertakan Popper.js, sehingga Anda harus menambahkannya secara terpisah jika menggunakan komponen yang membutuhkan positioning (tooltip, popover, dropdown). bootstrap.bundle.js adalah file yang sudah menyertakan Popper.js di dalamnya, sehingga Anda tidak perlu menginstal Popper.js terpisah. bootstrap.bundle.min.js adalah versi terminifikasi dari bundle. Rekomendasi resmi Bootstrap adalah menggunakan bootstrap.bundle.min.js untuk sebagian besar kasus, karena mencakup semua dependensi yang diperlukan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>File JavaScript Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5 text-center">
        <h1>Komponen JavaScript Bootstrap</h1>
        <div class="d-flex flex-wrap gap-2 justify-content-center mt-4">
            <button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#contohModal">Modal</button>
            <button class="btn btn-success" data-bs-toggle="collapse" data-bs-target="#demoCollapse">Collapse</button>
            <button class="btn btn-info" type="button" data-bs-toggle="dropdown">Dropdown</button>
            <ul class="dropdown-menu">
                <li><a class="dropdown-item" href="#">Action</a></li>
                <li><a class="dropdown-item" href="#">Another action</a></li>
            </ul>
            <div class="modal fade" id="contohModal">
                <div class="modal-dialog">
                    <div class="modal-content">
                        <div class="modal-header"><h5 class="modal-title">Modal</h5>
                        <button type="button" class="btn-close" data-bs-dismiss="modal"></button></div>
                        <div class="modal-body"><p>Bootstrap JS bekerja!</p></div>
                    </div>
                </div>
            </div>
        </div>
        <div class="collapse mt-3" id="demoCollapse">
            <div class="card card-body">Konten collapse!</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- bootstrap.bundle.js sudah menyertakan Popper.js
- Gunakan bootstrap.bundle.min.js untuk production
- Popper.js diperlukan untuk tooltip, popover, dan dropdown positioning
- Komponen seperti modal, collapse, tabs tidak memerlukan Popper.js
