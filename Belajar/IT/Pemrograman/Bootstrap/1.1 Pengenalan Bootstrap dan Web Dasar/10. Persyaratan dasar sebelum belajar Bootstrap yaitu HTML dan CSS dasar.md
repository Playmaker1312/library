# Persyaratan Dasar Sebelum Belajar Bootstrap yaitu HTML dan CSS Dasar

## Analogi: Perpustakaan Digital

Sebelum bisa membaca buku-buku di perpustakaan digital Bootstrap, Anda harus bisa membaca alfabet (HTML) dan memahami tata bahasa (CSS) terlebih dahulu. HTML adalah huruf-huruf yang membentuk kata dan kalimat, sedangkan CSS adalah aturan ejaan dan gaya penulisan. Tanpa memahami keduanya, Anda akan kesulitan memahami isi buku-buku Bootstrap yang lebih kompleks.

## Penjelasan Detail

Bootstrap dibangun di atas HTML dan CSS, sehingga pemahaman dasar tentang kedua teknologi ini sangat penting. HTML dasar yang perlu dikuasai meliputi struktur dokumen, tag semantik, atribut class dan id, serta cara membuat form dan tabel. CSS dasar meliputi selectors, properties, box model, display property, positioning, dan responsive design. Tanpa fondasi HTML dan CSS yang kuat, Anda akan mengalami kesulitan saat melakukan kustomisasi atau debugging komponen Bootstrap. Sebaiknya luangkan waktu setidaknya 2-4 minggu untuk mempelajari HTML dan CSS dasar sebelum memulai Bootstrap. Pengetahuan tentang Flexbox juga sangat membantu karena Bootstrap 5 menggunakannya sebagai basis grid system.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Prasyarat Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Prasyarat Belajar Bootstrap</h1>
        <div class="row mt-4">
            <div class="col-md-6">
                <div class="card border-warning h-100">
                    <div class="card-header bg-warning">HTML Dasar</div>
                    <div class="card-body">
                        <ul>
                            <li>Struktur dokumen HTML5</li>
                            <li>Tag semantik</li>
                            <li>Atribut class & id</li>
                            <li>Form & tabel</li>
                        </ul>
                    </div>
                </div>
            </div>
            <div class="col-md-6">
                <div class="card border-info h-100">
                    <div class="card-header bg-info text-white">CSS Dasar</div>
                    <div class="card-body">
                        <ul>
                            <li>Box model & display</li>
                            <li>Selectors & specificity</li>
                            <li>Flexbox dasar</li>
                            <li>Media queries</li>
                        </ul>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- HTML dan CSS dasar wajib dikuasai sebelum belajar Bootstrap
- Bootstrap hanya mempercepat, bukan menggantikan pengetahuan HTML/CSS
- Flexbox sangat penting karena menjadi basis grid Bootstrap 5
- Luangkan waktu untuk memahami CSS specificity dan box model
