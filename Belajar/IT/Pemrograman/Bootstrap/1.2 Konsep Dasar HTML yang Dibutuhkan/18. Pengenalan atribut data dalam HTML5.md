# Pengenalan Atribut Data dalam HTML5

## Analogi: Perpustakaan Digital

Atribut data dalam HTML5 seperti tempelan catatan kecil di sampul buku perpustakaan. Catatan ini bisa berisi informasi tambahan seperti "Buku ini populer di kalangan mahasiswa" atau "Review: 4.5/5". Catatan ini tidak terlihat oleh pengunjung biasa, tetapi bisa dibaca oleh sistem komputer untuk memproses informasi lebih lanjut. Di Bootstrap, atribut data digunakan untuk mengontrol interaksi komponen.

## Penjelasan Detail

Atribut data HTML5 adalah atribut kustom yang diawali dengan `data-` dan bisa diberi nama apa pun setelah tanda hubung. Contoh: `data-bs-toggle`, `data-bs-target`, `data-bs-dismiss`. Atribut data digunakan untuk menyimpan informasi tambahan dalam elemen HTML yang bisa diakses melalui JavaScript. Bootstrap 5 menggunakan atribut `data-bs-*` (bootstrap) untuk menginisialisasi dan mengontrol komponen JavaScript tanpa menulis kode JS manual. Misalnya, `data-bs-toggle="dropdown"` pada tombol akan mengaktifkan komponen dropdown. Nilai atribut data menentukan perilaku komponen: toggle untuk mengaktifkan/menonaktifkan, target untuk menentukan elemen target, dismiss untuk menutup komponen.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Atribut Data HTML5</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Atribut data-* HTML5</h1>
        <p class="lead">Bootstrap menggunakan data-bs-* untuk komponen interaktif.</p>
        <div class="d-flex gap-2 mb-3">
            <button class="btn btn-primary" data-bs-toggle="collapse" data-bs-target="#demo">
                Toggle dengan data-bs-toggle
            </button>
            <button class="btn btn-danger" data-bs-toggle="modal" data-bs-target="#dataModal">
                Modal dengan data-bs-target
            </button>
        </div>
        <div class="collapse" id="demo">
            <div class="card card-body">Konten ini muncul karena data-bs-toggle="collapse"!</div>
        </div>
        <div class="modal fade" id="dataModal">
            <div class="modal-dialog">
                <div class="modal-content">
                    <div class="modal-header">
                        <h5 class="modal-title">Atribut Data</h5>
                        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
                    </div>
                    <div class="modal-body">
                        <p>Modal diaktifkan oleh data-bs-target!</p>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Atribut data diawali dengan `data-` dan bisa diberi nama kustom
- Bootstrap 5 menggunakan prefix `data-bs-*` untuk komponen JS
- Atribut data memungkinkan komponen Bootstrap bekerja tanpa JavaScript manual
- Nilai atribut seperti "toggle", "target", "dismiss" mengontrol perilaku komponen
