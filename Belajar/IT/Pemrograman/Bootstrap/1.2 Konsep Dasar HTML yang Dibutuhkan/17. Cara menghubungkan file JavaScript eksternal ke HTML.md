# Cara Menghubungkan File JavaScript Eksternal ke HTML

## Analogi: Perpustakaan Digital

Menghubungkan file JavaScript ke HTML seperti menambahkan staf interaktif di perpustakaan. HTML adalah rak bukunya, CSS adalah papan petunjuknya, dan JavaScript adalah pustakawan yang bisa membantu pengunjung mencari buku (search), membuka pintu otomatis (modal), dan menampilkan buku rekomendasi (carousel). Pustakawan hanya dipanggil saat dibutuhkan, bukan saat pengunjung masuk.

## Penjelasan Detail

File JavaScript eksternal dihubungkan menggunakan tag `<script>` dengan atribut `src`. Posisi terbaik untuk tag script adalah di akhir `<body>`, sebelum tag `</body>` ditutup. Ini memastikan konten HTML sudah dimuat sebelum JavaScript dijalankan, mencegah blocking rendering. Atribut `defer` bisa ditambahkan jika script ditempatkan di `<head>` untuk menunda eksekusi hingga HTML selesai diurai. Atribut `async` digunakan untuk script independen yang tidak bergantung pada elemen DOM. Untuk Bootstrap, gunakan: `<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>` di akhir body.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hubungkan JS Eksternal</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5 text-center">
        <h1>JavaScript Eksternal</h1>
        <p class="lead">Klik tombol untuk melihat interaksi Bootstrap JS.</p>
        <button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#demoModal">
            Buka Modal
        </button>
        <div class="modal fade" id="demoModal">
            <div class="modal-dialog">
                <div class="modal-content">
                    <div class="modal-header">
                        <h5 class="modal-title">Bootstrap JS</h5>
                        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
                    </div>
                    <div class="modal-body">
                        <p>JavaScript Bootstrap berhasil dimuat!</p>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Letakkan tag `<script>` di akhir `<body>` untuk performa lebih baik
- Gunakan atribut `defer` jika script di `<head>`, `async` untuk script independen
- Bootstrap bundle.js sudah termasuk Popper.js
- Urutan script penting: library (Bootstrap) sebelum kode kustom
