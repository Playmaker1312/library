# Struktur Dasar Dokumen HTML5 yang Benar

## Analogi: Perpustakaan Digital

Struktur dasar HTML5 seperti kerangka bangunan perpustakaan. Ada fondasi (<!DOCTYPE html>), dinding penopang (html), ruang kepala untuk administrasi (head), dan ruang utama untuk koleksi buku (body). Setiap bagian memiliki fungsi spesifik dan harus ditempatkan pada posisi yang benar agar bangunan berdiri kokoh. Kerangka ini menjadi tempat Anda menempelkan komponen Bootstrap nantinya.

## Penjelasan Detail

Dokumen HTML5 memiliki struktur wajib yang terdiri dari beberapa elemen kunci. `<!DOCTYPE html>` adalah deklarasi yang memberi tahu browser bahwa dokumen menggunakan HTML5. Elemen `<html>` adalah root element yang membungkus seluruh konten. `<head>` berisi metadata seperti charset, viewport, title, dan link ke file CSS. `<body>` berisi semua konten yang ditampilkan ke pengguna. Dokumen HTML5 yang benar harus memiliki tag `<meta charset="UTF-8">` untuk encoding karakter dan `<meta name="viewport" content="width=device-width, initial-scale=1.0">` untuk responsive design. Struktur ini adalah fondasi yang harus ada di setiap halaman Bootstrap.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Struktur HTML5</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Struktur Dasar HTML5</h1>
        <p class="lead">Setiap dokumen HTML5 memiliki kerangka wajib.</p>
        <pre class="bg-light p-3 rounded border">
&lt;!DOCTYPE html&gt;
&lt;html lang="en"&gt;
  &lt;head&gt;
    &lt;meta charset="UTF-8"&gt;
    &lt;meta name="viewport" content="width=device-width, initial-scale=1.0"&gt;
    &lt;title&gt;Judul Halaman&lt;/title&gt;
  &lt;/head&gt;
  &lt;body&gt;
    &lt;!-- Konten di sini --&gt;
  &lt;/body&gt;
&lt;/html&gt;</pre>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `<!DOCTYPE html>` wajib untuk mengaktifkan mode standar browser
- Tag `<meta charset="UTF-8">` mencegah masalah karakter khusus
- Tag viewport diperlukan untuk responsive design di mobile
- Struktur ini adalah fondasi untuk semua halaman Bootstrap
