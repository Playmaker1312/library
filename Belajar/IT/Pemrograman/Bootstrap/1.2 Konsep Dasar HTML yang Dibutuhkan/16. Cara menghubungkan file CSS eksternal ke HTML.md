# Cara Menghubungkan File CSS Eksternal ke HTML

## Analogi: Perpustakaan Digital

Menghubungkan file CSS ke HTML seperti memasang papan petunjuk di perpustakaan. HTML adalah bangunan perpustakaannya sendiri, dan CSS adalah semua papan petunjuk, tanda arah, dan dekorasi yang membuat perpustakaan terlihat rapi dan mudah dinavigasi. Anda tidak perlu menulis petunjuk di setiap dinding (inline CSS), cukup buat satu papan besar (file CSS eksternal) yang dipasang di pintu masuk.

## Penjelasan Detail

File CSS eksternal dihubungkan ke HTML menggunakan tag `<link>` di dalam elemen `<head>`. Tag `<link>` memiliki atribut `rel="stylesheet"` untuk mendefinisikan hubungan, `href` untuk path file CSS, dan opsional `integrity` untuk keamanan. Untuk Bootstrap CDN, kodenya: `<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">`. File CSS ditempatkan di `<head>` agar gaya diterapkan segera saat halaman dimuat, mencegah FOUC (Flash of Unstyled Content). Anda bisa menghubungkan beberapa file CSS dengan menambahkan multiple `<link>` tags. Urutan file CSS penting: file yang lebih umum (seperti Bootstrap) sebaiknya di atas file CSS kustom Anda.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hubungkan CSS Eksternal</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .custom-style { background-color: #f0f8ff; padding: 20px; border-radius: 10px; }
    </style>
</head>
<body>
    <div class="container py-5">
        <h1>Menghubungkan CSS Eksternal</h1>
        <div class="custom-style">
            <p class="lead">Bootstrap dimuat dari CDN + style kustom inline di head.</p>
            <code>&lt;link href="bootstrap.min.css" rel="stylesheet"&gt;</code>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan tag `<link>` di dalam `<head>` untuk CSS eksternal
- Bootstrap CDN harus ditempatkan sebelum file CSS kustom
- Urutan file CSS mempengaruhi cascade dan specificity
- File CSS eksternal mencegah pengulangan kode dan memudahkan maintenance
