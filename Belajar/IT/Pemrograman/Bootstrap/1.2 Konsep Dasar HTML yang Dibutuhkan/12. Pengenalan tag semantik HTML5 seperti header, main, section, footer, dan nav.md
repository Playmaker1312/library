# Pengenalan Tag Semantik HTML5 seperti Header, Main, Section, Footer, dan Nav

## Analogi: Perpustakaan Digital

Tag semantik HTML5 seperti papan petunjuk di dalam perpustakaan. Ada papan "Ruang Baca" (main), "Rak Fiksi" (section), "Meja Sirkulasi" (header), "Toilet" (footer), dan "Katalog" (nav). Papan petunjuk ini membantu pengunjung memahami fungsi setiap area tanpa harus melihat isinya. Tag semantik membantu browser dan mesin pencari memahami struktur halaman web Anda.

## Penjelasan Detail

Tag semantik HTML5 adalah elemen yang memberikan makna pada struktur halaman web. `<header>` mewakili bagian kepala halaman atau section, biasanya berisi logo dan navigasi. `<nav>` berisi tautan navigasi utama. `<main>` adalah konten utama halaman yang unik. `<section>` mengelompokkan konten yang terkait tematis. `<article>` mewakili konten independen seperti posting blog. `<aside>` untuk konten sampingan seperti sidebar. `<footer>` adalah bagian kaki halaman berisi informasi hak cipta dan tautan. Penggunaan tag semantik meningkatkan aksesibilitas, SEO, dan maintainability kode. Bootstrap tidak mewajibkan tag semantik, tetapi sangat merekomendasikan penggunaannya.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tag Semantik HTML5</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <header class="bg-primary text-white p-4">
        <h1>Website Saya</h1>
        <nav>
            <a href="#" class="text-white me-3">Beranda</a>
            <a href="#" class="text-white me-3">Tentang</a>
            <a href="#" class="text-white">Kontak</a>
        </nav>
    </header>
    <main class="container py-4">
        <section class="mb-4">
            <h2>Artikel Terbaru</h2>
            <p>Konten utama halaman ini.</p>
        </section>
        <aside class="bg-light p-3 rounded">
            <h5>Info Sampingan</h5>
            <p>Sidebar dengan informasi tambahan.</p>
        </aside>
    </main>
    <footer class="bg-dark text-white text-center p-3">
        <p class="mb-0">Hak Cipta &copy; 2025</p>
    </footer>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Tag semantik meningkatkan SEO dan aksesibilitas
- header, main, section, footer, nav adalah tag semantik utama HTML5
- Tag semantik tidak mengubah tampilan, hanya struktur dan makna
- Bootstrap kompatibel dengan semua tag semantik HTML5
