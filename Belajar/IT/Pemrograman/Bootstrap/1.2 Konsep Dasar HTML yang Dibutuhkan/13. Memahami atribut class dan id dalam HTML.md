# Memahami Atribut Class dan Id dalam HTML

## Analogi: Perpustakaan Digital

Atribut class dan id seperti label buku di perpustakaan. Id adalah nomor ISBN unik — setiap buku hanya memiliki satu nomor yang tidak pernah sama dengan buku lain. Class adalah label kategori seperti "Fiksi", "Non-Fiksi", atau "Referensi" — banyak buku bisa memiliki label yang sama. Di Bootstrap, class adalah cara utama untuk menerapkan gaya dan komponen ke elemen HTML.

## Penjelasan Detail

Atribut `class` dan `id` adalah dua atribut HTML yang digunakan untuk mengidentifikasi elemen. `id` bersifat unik — hanya satu elemen dalam satu halaman yang boleh memiliki id tertentu. `class` bersifat reusable — banyak elemen bisa memiliki class yang sama. Dalam Bootstrap, hampir semua styling dilakukan melalui class, bukan id. Misalnya class `btn btn-primary` diterapkan pada tombol, dan banyak tombol bisa memiliki class yang sama. Id biasanya digunakan untuk target JavaScript, anchor link (`#section`), atau untuk elemen unik seperti modal. Perbedaan penting: selector CSS untuk id menggunakan `#` dan untuk class menggunakan `.`. Specificity id lebih tinggi dari class.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Class vs Id</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1 class="mb-4">Atribut Class vs Id</h1>
        <div id="header-section" class="bg-primary text-white p-4 rounded mb-3">
            <h2>Ini div dengan id="header-section"</h2>
            <p>Id bersifat unik dalam satu halaman.</p>
        </div>
        <div class="card mb-3">
            <div class="card-body">
                <h5 class="card-title">Banyak elemen bisa pakai class sama</h5>
                <button class="btn btn-primary me-2">Tombol 1</button>
                <button class="btn btn-primary me-2">Tombol 2</button>
                <button class="btn btn-primary">Tombol 3</button>
            </div>
        </div>
        <div class="alert alert-info">
            <strong>Ingat:</strong> id="..." untuk unik, class="..." untuk banyak elemen.
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- id unik untuk satu elemen per halaman, class bisa diulang
- Bootstrap menggunakan class sebagai mekanisme utama styling
- Selector CSS: `#` untuk id, `.` untuk class
- id memiliki specificity lebih tinggi daripada class
