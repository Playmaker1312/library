# Pengenalan Konsep DOM (Document Object Model) Secara Sederhana

## Analogi: Perpustakaan Digital

DOM (Document Object Model) adalah seperti peta interaktif perpustakaan. Setiap rak buku (tag HTML), setiap buku (elemen), dan setiap halaman dalam buku (teks) direpresentasikan sebagai objek dalam peta ini. Peta ini bisa dimanipulasi secara langsung — Anda bisa memindahkan rak, menambah buku baru, atau menghapus buku tanpa membangun ulang seluruh perpustakaan. JavaScript Bootstrap menggunakan DOM untuk memanipulasi halaman web secara real-time.

## Penjelasan Detail

DOM adalah representasi terstruktur dari dokumen HTML yang dibuat oleh browser. DOM memandang dokumen HTML sebagai tree of nodes, di mana setiap elemen HTML, atribut, dan teks adalah node yang bisa diakses dan dimanipulasi melalui JavaScript. Struktur DOM berbentuk pohon: `<html>` adalah root, bercabang ke `<head>` dan `<body>`, dan seterusnya. Bootstrap JavaScript menggunakan DOM API untuk menambahkan/menghapus class CSS, mengubah atribut, dan memanipulasi elemen. Misalnya, saat tombol modal diklik, Bootstrap menambahkan class "show" ke elemen modal dan class "modal-backdrop" ke body. Memahami DOM membantu Anda debugging dan kustomisasi komponen Bootstrap.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Konsep DOM</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5" id="app">
        <h1>Apa itu DOM?</h1>
        <p class="lead" id="description">Document Object Model &mdash; representasi pohon dari HTML.</p>
        <button class="btn btn-primary" onclick="ubahTeks()">Ubah Teks via DOM</button>
        <button class="btn btn-success mt-2" onclick="tambahClass()">Tambah Class via DOM</button>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
    <script>
        function ubahTeks() {
            document.getElementById('description').textContent = 'Teks berhasil diubah oleh manipulasi DOM!';
        }
        function tambahClass() {
            document.getElementById('app').classList.toggle('bg-light');
        }
    </script>
</body>
</html>
```

## Poin Penting
- DOM adalah representasi tree dari dokumen HTML yang bisa dimanipulasi
- Bootstrap JavaScript memanipulasi DOM untuk interaktivitas komponen
- Setiap elemen HTML adalah node dalam DOM tree
- Memahami DOM dasar membantu debugging komponen Bootstrap
