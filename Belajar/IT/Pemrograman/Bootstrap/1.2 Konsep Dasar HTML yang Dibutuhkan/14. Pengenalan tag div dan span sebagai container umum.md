# Pengenalan Tag Div dan Span sebagai Container Umum

## Analogi: Perpustakaan Digital

Tag `div` dan `span` seperti kotak penyimpanan di perpustakaan. `div` adalah kotak besar yang bisa menampung banyak buku dan kotak lain di dalamnya, biasanya diletakkan di rak yang berbeda baris. `span` adalah kotak kecil yang muat di sela-sela buku tanpa mengganggu tata letak baris. Keduanya adalah container serbaguna yang menjadi blok bangunan utama layout Bootstrap.

## Penjelasan Detail

`<div>` adalah elemen block-level yang digunakan sebagai container untuk mengelompokkan elemen lain. Secara default, div mengambil lebar penuh dan memulai baris baru. `<span>` adalah elemen inline yang digunakan untuk mengelompokkan teks atau elemen inline dalam satu baris. Dalam Bootstrap, div sangat penting karena digunakan untuk hampir semua komponen: container, row, col, card, navbar, dan lainnya. Bootstrap menambahkan berbagai class ke div untuk memberikan styling dan layout. Span jarang digunakan dalam Bootstrap karena kebanyakan komponen menggunakan div, tetapi span tetap berguna untuk teks inline yang perlu diberi gaya khusus.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Div dan Span</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Tag Div dan Span</h1>
        <div class="bg-light p-3 mb-3 rounded border">
            <p>Ini adalah <span class="bg-warning p-1 rounded">teks dalam span</span> dan sisanya di div.</p>
            <p class="mb-0">Span tidak memulai baris baru, div selalu memulai baris baru.</p>
        </div>
        <div class="row">
            <div class="col-md-6">
                <div class="card">
                    <div class="card-header bg-primary text-white">&lt;div&gt;</div>
                    <div class="card-body">
                        <p class="card-text mb-0">Block-level container</p>
                    </div>
                </div>
            </div>
            <div class="col-md-6">
                <div class="card">
                    <div class="card-header bg-success text-white">&lt;span&gt;</div>
                    <div class="card-body">
                        <p class="card-text mb-0">Inline container</p>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- div adalah block-level container, span adalah inline container
- Bootstrap sangat bergantung pada div untuk grid dan komponen
- div memulai baris baru, span tetap dalam baris yang sama
- Tambahkan class Bootstrap ke div dan span untuk styling
