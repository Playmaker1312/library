# Cara mengintegrasikan Bootstrap dengan vanilla JavaScript murni

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin menambahkan interaktivitas tanpa menggunakan kerangka kerja yang rumit. Mereka cukup menggunakan JavaScript murni untuk membuka dialog, memvalidasi form, atau mengubah tampilan. Bootstrap sendiri dibangun dengan vanilla JavaScript sehingga integrasi berjalan alami.

## Penjelasan Detail

Bootstrap 5 menggunakan vanilla JavaScript murni (tanpa jQuery) untuk semua komponen interaktif. Anda bisa mengintegrasikan Bootstrap dengan JavaScript biasa dengan memanggil konstruktor Bootstrap seperti `new bootstrap.Modal()`, `new bootstrap.Collapse()`, atau `new bootstrap.Tooltip()`. Data attributes (`data-bs-*`) adalah cara termudah, tetapi JavaScript API memberikan kontrol lebih. Pastikan untuk mengimpor `bootstrap.bundle.min.js` yang sudah termasuk semua plugin.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Vanilla JS + Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Vanilla JavaScript dengan Bootstrap</h1>
    <button id="openModalBtn" class="btn btn-primary">Buka Modal</button>
    <button id="showToastBtn" class="btn btn-success">Tampilkan Toast</button>
    <button id="toggleCollapseBtn" class="btn btn-warning">Toggle Collapse</button>

    <!-- Modal -->
    <div class="modal fade" id="myModal" tabindex="-1">
      <div class="modal-dialog">
        <div class="modal-content">
          <div class="modal-header">
            <h5 class="modal-title">Modal Vanilla JS</h5>
            <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
          </div>
          <div class="modal-body">Modal dibuka dengan JavaScript murni.</div>
        </div>
      </div>
    </div>

    <!-- Toast -->
    <div class="toast-container position-fixed bottom-0 end-0 p-3">
      <div id="myToast" class="toast" role="alert">
        <div class="toast-header">
          <strong class="me-auto">Notifikasi</strong>
          <button type="button" class="btn-close" data-bs-dismiss="toast"></button>
        </div>
        <div class="toast-body">Toast dengan JavaScript murni!</div>
      </div>
    </div>

    <!-- Collapse -->
    <div class="collapse mt-3" id="myCollapse">
      <div class="card card-body">Konten collapse menggunakan Bootstrap JS API.</div>
    </div>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  <script>
    // Vanilla JavaScript untuk Bootstrap
    document.addEventListener('DOMContentLoaded', function() {
      const modal = new bootstrap.Modal('#myModal');
      const toast = new bootstrap.Toast('#myToast');
      const collapse = new bootstrap.Collapse('#myCollapse', { toggle: false });

      document.getElementById('openModalBtn').addEventListener('click', () => modal.show());
      document.getElementById('showToastBtn').addEventListener('click', () => toast.show());
      document.getElementById('toggleCollapseBtn').addEventListener('click', () => collapse.toggle());
    });
  </script>
</body>
</html>
```

## Poin Penting
- Bootstrap 5 menggunakan vanilla JavaScript, bukan jQuery
- Gunakan konstruktor Bootstrap untuk kontrol programatik
- Data attributes (`data-bs-*`) adalah alternatif deklaratif
