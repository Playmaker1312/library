# Cara mengintegrasikan Bootstrap dengan Vue.js

## Analogi: Perpustakaan Digital

Perpustakaan digital yang menggunakan Vue.js perlu menggabungkan sistem rak Bootstrap dengan sistem reaktivitas Vue. Bootstrap classes bisa digunakan langsung di template Vue, dan ada pustaka khusus yang menyediakan komponen Vue untuk Bootstrap.

## Penjelasan Detail

Ada tiga cara mengintegrasikan Bootstrap dengan Vue.js: (1) Impor CSS Bootstrap langsung di `main.js` dan gunakan classes di template, (2) Gunakan `bootstrap-vue-next` untuk komponen Vue 3, (3) Gunakan Bootstrap JavaScript dengan Vue's lifecycle hooks. Untuk CSS saja, cukup `npm install bootstrap` dan impor di `main.js`. Bootstrap JavaScript API bisa dipanggil di `onMounted` hook dengan akses DOM via template refs.

## Contoh Kode Implementasi

```bash
# Install Bootstrap CSS
npm install bootstrap

# Install Bootstrap-Vue-Next (untuk Vue 3)
npm install bootstrap-vue-next
```

```javascript
// src/main.js - Impor Bootstrap CSS
import { createApp } from 'vue';
import App from './App.vue';
import 'bootstrap/dist/css/bootstrap.min.css';

const app = createApp(App);
app.mount('#app');
```

```vue
<!-- src/App.vue - Bootstrap classes langsung di template -->
<template>
  <div class="container mt-4">
    <h1 class="display-6 text-primary">Perpustakaan Vue</h1>
    
    <div class="row">
      <div v-for="book in books" :key="book.id" class="col-12 col-md-6 col-lg-4 mb-3">
        <div class="card h-100 shadow-sm">
          <div class="card-body">
            <h5 class="card-title">{{ book.title }}</h5>
            <p class="card-text text-muted">{{ book.author }}</p>
            <span :class="['badge', book.available ? 'bg-success' : 'bg-danger']">
              {{ book.available ? 'Tersedia' : 'Dipinjam' }}
            </span>
            <button class="btn btn-outline-primary btn-sm mt-2" @click="showDetail(book)">
              Detail
            </button>
          </div>
        </div>
      </div>
    </div>

    <!-- Bootstrap Modal via JavaScript API -->
    <div ref="detailModal" class="modal fade" tabindex="-1">
      <div class="modal-dialog">
        <div class="modal-content">
          <div class="modal-header">
            <h5 class="modal-title">{{ selectedBook?.title }}</h5>
            <button type="button" class="btn-close" @click="hideModal"></button>
          </div>
          <div class="modal-body">
            <p>Penulis: {{ selectedBook?.author }}</p>
          </div>
        </div>
      </div>
    </div>
  </div>
</template>

<script>
import { ref, onMounted } from 'vue';
import { Modal } from 'bootstrap';

export default {
  name: 'App',
  setup() {
    const books = ref([
      { id: 1, title: 'Bootstrap 5', author: 'Mark Otto', available: true },
      { id: 2, title: 'Vue.js 3', author: 'Evan You', available: false },
    ]);
    const selectedBook = ref(null);
    const detailModal = ref(null);
    let modalInstance = null;

    onMounted(() => {
      modalInstance = new Modal(detailModal.value);
    });

    function showDetail(book) {
      selectedBook.value = book;
      modalInstance?.show();
    }

    function hideModal() {
      modalInstance?.hide();
    }

    return { books, selectedBook, detailModal, showDetail, hideModal };
  }
};
</script>
```

## Poin Penting
- Bootstrap classes bisa langsung digunakan di template Vue dengan `class` binding
- Bootstrap JavaScript diinisialisasi di `onMounted` hook
- `bootstrap-vue-next` menyediakan komponen Vue 3 native
