# Pengenalan ng-bootstrap untuk Angular

## Analogi: Perpustakaan Digital

Perpustakaan digital yang dibangun dengan Angular membutuhkan rak buku yang dirancang khusus untuk Angular. `ng-bootstrap` menyediakan komponen Bootstrap yang ditulis sebagai komponen Angular asli, tanpa dependency jQuery atau Bootstrap JavaScript.

## Penjelasan Detail

`ng-bootstrap` (@ng-bootstrap/ng-bootstrap) adalah pustaka komponen Bootstrap native untuk Angular. Setiap komponen (`NgbModal`, `NgbNav`, `NgbCarousel`, `NgbAccordion`, dll.) adalah Angular Component atau Directive yang menggunakan Bootstrap CSS untuk styling tetapi Angular untuk logika interaktif. Tidak perlu Bootstrap JavaScript. Keuntungan: integrasi sempurna dengan Angular forms, Change Detection, Dependency Injection, dan TypeScript.

## Contoh Kode Implementasi

```typescript
// app.module.ts
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { NgbModule } from '@ng-bootstrap/ng-bootstrap';
import { AppComponent } from './app.component';

@NgModule({
  imports: [BrowserModule, NgbModule],
  declarations: [AppComponent],
  bootstrap: [AppComponent]
})
export class AppModule { }
```

```html
<!-- app.component.html -->
<div class="container mt-4">
  <h1>ng-bootstrap Demo</h1>

  <!-- Accordion -->
  <ngb-accordion #acc="ngbAccordion" activeIds="panel-1">
    <ngb-panel id="panel-1" title="Buku Fiksi">
      <ng-template ngbPanelContent>
        Daftar buku fiksi tersedia di perpustakaan.
      </ng-template>
    </ngb-panel>
    <ngb-panel id="panel-2" title="Buku Non-Fiksi">
      <ng-template ngbPanelContent>
        Daftar buku non-fiksi tersedia di perpustakaan.
      </ng-template>
    </ngb-panel>
  </ngb-accordion>

  <!-- Nav (Tab) -->
  <ul ngbNav #nav="ngbNav" class="nav-tabs mt-4">
    <li ngbNavItem>
      <a ngbNavLink>Semua</a>
      <ng-template ngbNavContent>Semua buku.</ng-template>
    </li>
    <li ngbNavItem>
      <a ngbNavLink>Populer</a>
      <ng-template ngbNavContent>Buku paling populer.</ng-template>
    </li>
  </ul>
  <div [ngbNavOutlet]="nav" class="mt-2"></div>

  <!-- Modal -->
  <button class="btn btn-primary" (click)="openModal()">Buka Modal</button>

  <!-- Rating -->
  <ngb-rating [(rate)]="currentRating" [max]="5"></ngb-rating>
  <p>Rating: {{ currentRating }}/5</p>
</div>
```

```typescript
// app.component.ts
import { Component } from '@angular/core';
import { NgbModal } from '@ng-bootstrap/ng-bootstrap';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent {
  currentRating = 3;

  constructor(private modalService: NgbModal) {}

  openModal() {
    const modalRef = this.modalService.open(ModalContentComponent);
    modalRef.componentInstance.title = 'Detail Buku';
  }
}
```

## Poin Penting
- `ng-bootstrap` adalah komponen Bootstrap native untuk Angular
- Tidak memerlukan Bootstrap JavaScript atau jQuery
- Integrasi penuh dengan Angular forms, DI, dan Change Detection
