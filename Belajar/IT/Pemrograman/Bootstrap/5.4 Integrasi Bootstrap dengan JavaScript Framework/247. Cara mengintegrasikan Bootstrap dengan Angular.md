# Cara mengintegrasikan Bootstrap dengan Angular

## Analogi: Perpustakaan Digital

Perpustakaan digital yang dibangun dengan Angular memiliki sistem komponen yang kuat. Bootstrap perlu diintegrasikan ke dalam arsitektur Angular, baik sebagai kelas CSS langsung maupun sebagai komponen Angular yang dibungkus.

## Penjelasan Detail

Integrasi Bootstrap dengan Angular dapat dilakukan dengan: (1) Menambahkan Bootstrap CSS ke `angular.json` styles array dan menggunakan classes di template, (2) Menginstal `ng-bootstrap` untuk komponen Angular native, (3) Menginstal `ngx-bootstrap` sebagai alternatif. Untuk CSS saja, tambahkan path ke `bootstrap.min.css` di `angular.json`. Bootstrap JavaScript tidak kompatibel langsung dengan Angular; gunakan ng-bootstrap sebagai gantinya.

## Contoh Kode Implementasi

```bash
# Opsi 1: Bootstrap CSS saja
npm install bootstrap

# Opsi 2: ng-bootstrap (rekomendasi)
npm install @ng-bootstrap/ng-bootstrap bootstrap @popperjs/core

# Opsi 3: ngx-bootstrap
npm install ngx-bootstrap bootstrap
```

```json
// angular.json - Tambahkan Bootstrap CSS
{
  "projects": {
    "my-app": {
      "architect": {
        "build": {
          "styles": [
            "node_modules/bootstrap/dist/css/bootstrap.min.css",
            "src/styles.css"
          ],
          "scripts": []
        }
      }
    }
  }
}
```

```typescript
// app.module.ts - Import NgbModule
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { NgbModule } from '@ng-bootstrap/ng-bootstrap';
import { AppComponent } from './app.component';

@NgModule({
  declarations: [AppComponent],
  imports: [BrowserModule, NgbModule],
  bootstrap: [AppComponent]
})
export class AppModule { }
```

```html
<!-- app.component.html - Template dengan Bootstrap & ng-bootstrap -->
<div class="container mt-4">
  <h1 class="display-6">Perpustakaan Angular</h1>

  <nav class="navbar navbar-dark bg-dark mb-4">
    <div class="container-fluid">
      <span class="navbar-brand">Library</span>
    </div>
  </nav>

  <!-- Bootstrap classes langsung -->
  <div class="row">
    <div class="col-md-4 mb-3" *ngFor="let book of books">
      <div class="card">
        <div class="card-body">
          <h5 class="card-title">{{ book.title }}</h5>
          <p class="card-text">{{ book.author }}</p>
          <span [class]="'badge ' + (book.available ? 'bg-success' : 'bg-danger')">
            {{ book.available ? 'Tersedia' : 'Dipinjam' }}
          </span>
          <button class="btn btn-primary btn-sm ms-2" (click)="openModal(book)">
            Detail
          </button>
        </div>
      </div>
    </div>
  </div>

  <!-- ng-bootstrap komponen -->
  <ngb-modal #modalRef>
    <ng-template ngbModalHeader>
      <h5>{{ selectedBook?.title }}</h5>
    </ng-template>
    <ng-template ngbModalBody>
      <p>Penulis: {{ selectedBook?.author }}</p>
      <p>{{ selectedBook?.description }}</p>
    </ng-template>
    <ng-template ngbModalFooter>
      <button type="button" class="btn btn-secondary" (click)="modalRef.dismiss()">Tutup</button>
    </ng-template>
  </ngb-modal>
</div>
```

## Poin Penting
- Bootstrap CSS diimpor via `angular.json` atau `styles.css`
- Gunakan `ng-bootstrap` untuk komponen Angular native
- Bootstrap JavaScript tidak kompatibel langsung dengan Angular
