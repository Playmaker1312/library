# Cara menggunakan Bootstrap classes di dalam JSX React

## Analogi: Perpustakaan Digital

Perpustakaan digital menggunakan sistem rak buku yang sudah ada, tetapi perlu mengintegrasikannya ke dalam lingkungan React. Mereka cukup menggunakan nama kelas Bootstrap langsung di JSX, sama seperti menggunakan kelas CSS biasa.

## Penjelasan Detail

Anda bisa menggunakan Bootstrap classes langsung di JSX React seperti biasa, dengan satu perbedaan: React menggunakan `className` bukan `class`. Semua utility Bootstrap seperti `container`, `row`, `col-md-4`, `btn btn-primary`, `d-flex`, dll. bisa langsung digunakan. Untuk conditional classes, gunakan template literals atau library seperti `classnames`. Bootstrap utility classes sangat cocok dengan pola styling React yang deklaratif.

## Contoh Kode Implementasi

```jsx
import 'bootstrap/dist/css/bootstrap.min.css';

// Conditional classes dengan template literals
function BookCard({ title, isAvailable, rating }) {
  const availabilityClass = isAvailable ? 'bg-success' : 'bg-danger';
  const ratingColor = rating >= 4 ? 'warning' : rating >= 3 ? 'info' : 'secondary';

  return (
    <div className="card shadow-sm mb-3">
      <div className="card-body">
        <h5 className="card-title text-truncate">{title}</h5>
        <span className={`badge ${availabilityClass} text-white me-2`}>
          {isAvailable ? 'Tersedia' : 'Dipinjam'}
        </span>
        <span className={`badge bg-${ratingColor} text-dark`}>
          {rating}/5
        </span>
        <div className="d-flex justify-content-between align-items-center mt-3">
          <small className="text-muted">Kategori: Fiksi</small>
          <button className="btn btn-outline-primary btn-sm">Detail</button>
        </div>
      </div>
    </div>
  );
}

// Utility classes dengan Bootstrap grid
function BookGrid() {
  return (
    <div className="container mt-4">
      <h1 className="display-6 mb-4 text-primary">Daftar Buku</h1>
      <div className="row g-4">
        <div className="col-12 col-sm-6 col-md-4 col-lg-3">
          <BookCard title="Bootstrap 5" isAvailable={true} rating={5} />
        </div>
        <div className="col-12 col-sm-6 col-md-4 col-lg-3">
          <BookCard title="React Programming" isAvailable={false} rating={4} />
        </div>
        {/* classnames library untuk conditional yang kompleks */}
        <div className={`col-12 col-sm-6 col-md-4 col-lg-3 ${rating > 4 ? 'order-first' : ''}`}>
          ...
        </div>
      </div>
    </div>
  );
}

// Inline styles dengan Bootstrap variables
const headerStyle = {
  backgroundColor: 'var(--bs-primary)',
  color: 'var(--bs-white)',
  padding: 'var(--bs-spacer)',
};
```

## Poin Penting
- Gunakan `className` bukan `class` di JSX React
- Template literals memudahkan conditional Bootstrap classes
- Bootstrap utility classes ideal untuk pola styling deklaratif React
