# Cara menginstal dan menggunakan Bootstrap di project React

## Analogi: Perpustakaan Digital

Perpustakaan digital yang dibangun dengan React perlu mengintegrasikan rak buku Bootstrap ke dalam sistem komponen React. Ada dua cara: mengimpor file CSS Bootstrap langsung, atau menggunakan pustaka komponen React yang sudah dibungkus.

## Penjelasan Detail

Ada tiga cara utama menggunakan Bootstrap di React: (1) Instal `bootstrap` via npm dan impor CSS-nya di `index.js` atau `App.js`, (2) Gunakan React-Bootstrap yang menyediakan komponen React murni, (3) Gunakan Bootstrap icons untuk ikon. Untuk CSS saja, cukup `npm install bootstrap` dan `import 'bootstrap/dist/css/bootstrap.min.css'`. Untuk JavaScript interaktif, Anda perlu menginstal `bootstrap` dan `@popperjs/core`, atau gunakan React-Bootstrap.

## Contoh Kode Implementasi

```bash
# Opsi 1: Bootstrap CSS + JS
npm install bootstrap @popperjs/core

# Opsi 2: React-Bootstrap
npm install react-bootstrap bootstrap

# Opsi 3: Bootstrap Icons
npm install bootstrap-icons
```

```jsx
// src/index.js - Opsi 1: Impor Bootstrap CSS global
import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap/dist/js/bootstrap.bundle.min.js';

// src/App.js - Opsi 2: React-Bootstrap components
import { Button, Modal, Navbar, Container, Nav, Card, Alert } from 'react-bootstrap';
import 'bootstrap/dist/css/bootstrap.min.css';

function App() {
  return (
    <div>
      <Navbar bg="dark" variant="dark">
        <Container>
          <Navbar.Brand href="#home">React Library</Navbar.Brand>
          <Nav className="ms-auto">
            <Nav.Link href="#home">Home</Nav.Link>
            <Nav.Link href="#books">Books</Nav.Link>
          </Nav>
        </Container>
      </Navbar>

      <Container className="mt-4">
        <Alert variant="info">Selamat datang di perpustakaan React!</Alert>
        
        <Card style={{ width: '18rem' }}>
          <Card.Body>
            <Card.Title>Bootstrap 5</Card.Title>
            <Card.Text>Panduan lengkap Bootstrap untuk React.</Card.Text>
            <Button variant="primary">Detail</Button>
          </Card.Body>
        </Card>
      </Container>
    </div>
  );
}

export default App;
```

## Poin Penting
- Impor `bootstrap/dist/css/bootstrap.min.css` di entry point React
- React-Bootstrap menyediakan komponen React yang lebih aman dari konflik
- Hindari DOM manipulation langsung Bootstrap di React; gunakan state React
