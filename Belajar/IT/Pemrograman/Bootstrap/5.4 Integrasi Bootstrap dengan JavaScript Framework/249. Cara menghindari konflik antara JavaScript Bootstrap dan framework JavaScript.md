# Cara menghindari konflik antara JavaScript Bootstrap dan framework JavaScript

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki dua sistem manajemen buku: satu dari Bootstrap dan satu dari React/Vue/Angular. Jika keduanya mencoba mengontrol rak yang sama, terjadi tabrakan. Penting untuk menentukan sistem mana yang bertanggung jawab atas setiap bagian.

## Penjelasan Detail

Konflik terjadi ketika Bootstrap JavaScript dan framework JavaScript (React, Vue, Angular) sama-sama memanipulasi DOM atau state. Bootstrap JS menggunakan DOM manipulation langsung, sementara framework menggunakan Virtual DOM atau data binding. Solusi: hindari Bootstrap JS di dalam komponen framework; gunakan CSS Bootstrap saja untuk styling, dan implementasi logika interaktif dengan framework. Alternatifnya, gunakan pustaka spesifik framework seperti React-Bootstrap, Bootstrap-Vue, atau ng-bootstrap yang tidak menggunakan Bootstrap JS.

## Contoh Kode Implementasi

```jsx
// ❌ BURUK - Bootstrap JS + React langsung
import { useEffect, useRef } from 'react';
import { Modal } from 'bootstrap';

function BadModal() {
  const modalRef = useRef();
  useEffect(() => {
    // Konflik: React mengelola DOM, Bootstrap JS juga mengelola DOM
    const modal = new Modal(modalRef.current);
    modal.show();
  }, []);
  return <div ref={modalRef} className="modal">...</div>;
}

// ✅ BAIK - React-Bootstrap (tanpa Bootstrap JS)
import { Button, Modal } from 'react-bootstrap';
import { useState } from 'react';

function GoodModal() {
  const [show, setShow] = useState(false);
  return (
    <>
      <Button onClick={() => setShow(true)}>Buka</Button>
      <Modal show={show} onHide={() => setShow(false)}>
        <Modal.Header closeButton>
          <Modal.Title>Modal React</Modal.Title>
        </Modal.Header>
        <Modal.Body>Konten dikelola React sepenuhnya.</Modal.Body>
      </Modal>
    </>
  );
}

// ✅ BAIK - Bootstrap CSS saja + state framework
function BootstrapCSSOnly() {
  const [isOpen, setIsOpen] = useState(false);
  return (
    <div>
      <button className="btn btn-primary" onClick={() => setIsOpen(true)}>Buka</button>
      {isOpen && (
        <div className="modal d-block show" tabIndex="-1">
          <div className="modal-dialog">
            <div className="modal-content">
              <div className="modal-header">
                <h5 className="modal-title">Modal CSS Only</h5>
                <button className="btn-close" onClick={() => setIsOpen(false)}></button>
              </div>
              <div className="modal-body">Dikelola sepenuhnya oleh React state.</div>
            </div>
          </div>
        </div>
      )}
    </div>
  );
}
```

## Poin Penting
- Hindari Bootstrap JS bersama framework; gunakan CSS saja atau pustaka framework
- React-Bootstrap, Bootstrap-Vue, ng-bootstrap menyelesaikan konflik ini
- Jika harus pakai Bootstrap JS, inisialisasi di luar komponen framework
