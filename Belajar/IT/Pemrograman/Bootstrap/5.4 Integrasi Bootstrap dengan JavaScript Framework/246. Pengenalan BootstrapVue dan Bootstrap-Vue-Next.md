# Pengenalan BootstrapVue dan Bootstrap-Vue-Next

## Analogi: Perpustakaan Digital

Perpustakaan digital yang menggunakan Vue.js tidak ingin merakit rak buku secara manual. Mereka menggunakan sistem rak yang sudah jadi, yang setiap komponennya sudah terintegrasi sempurna dengan Vue. BootstrapVue dan Bootstrap-Vue-Next adalah sistem rak tersebut untuk Vue 2 dan Vue 3.

## Penjelasan Detail

BootstrapVue adalah pustaka komponen untuk Vue 2 yang menyediakan lebih dari 85 komponen dan 15+ direktif. Dengan BootstrapVue, Anda menggunakan komponen seperti `<b-card>`, `<b-modal>`, `<b-navbar>` tanpa perlu Bootstrap CSS atau JavaScript terpisah. Bootstrap-Vue-Next adalah penerus untuk Vue 3, menawarkan komponen serupa dengan dukungan Composition API dan TypeScript. Keduanya mendukung theming, slots, dan event Vue standar.

## Contoh Kode Implementasi

```bash
# BootstrapVue untuk Vue 2
npm install bootstrap-vue bootstrap

# Bootstrap-Vue-Next untuk Vue 3
npm install bootstrap-vue-next
```

```vue
<!-- Vue 3 dengan Bootstrap-Vue-Next -->
<template>
  <div>
    <BNavbar variant="dark" bg="dark">
      <BNavbarBrand>Perpustakaan Digital</BNavbarBrand>
      <BNavbarNav>
        <BNavItem active>Home</BNavItem>
        <BNavItem>Katalog</BNavItem>
        <BNavItemDropdown text="Kategori">
          <BDropdownItem>Fiksi</BDropdownItem>
          <BDropdownItem>Non-Fiksi</BDropdownItem>
        </BNavItemDropdown>
      </BNavbarNav>
    </BNavbar>

    <BContainer class="mt-4">
      <BRow>
        <BCol v-for="book in books" :key="book.id" cols="12" md="6" lg="4" class="mb-3">
          <BCard :title="book.title" :sub-title="book.author">
            <BCardText>{{ book.description }}</BCardText>
            <template #footer>
              <BBadge :variant="book.available ? 'success' : 'danger'">
                {{ book.available ? 'Tersedia' : 'Dipinjam' }}
              </BBadge>
              <BButton variant="primary" size="sm" class="ms-2" @click="openModal(book)">
                Detail
              </BButton>
            </template>
          </BCard>
        </BCol>
      </BRow>
    </BContainer>

    <BModal v-model="showModal" :title="selectedBook?.title" ok-only>
      <p>Penulis: {{ selectedBook?.author }}</p>
      <p>{{ selectedBook?.description }}</p>
    </BModal>

    <BToast v-model="showToast" variant="success" autohide delay="3000">
      <template #title>Notifikasi</template>
      Buku berhasil dipinjam!
    </BToast>
  </div>
</template>

<script setup>
import { ref } from 'vue';

const books = ref([
  { id: 1, title: 'Bootstrap 5', author: 'Mark Otto', description: 'Panduan lengkap Bootstrap.', available: true },
  { id: 2, title: 'Vue.js 3', author: 'Evan You', description: 'Framework progresif.', available: false },
]);
const showModal = ref(false);
const showToast = ref(false);
const selectedBook = ref(null);

function openModal(book) {
  selectedBook.value = book;
  showModal.value = true;
}
</script>
```

## Poin Penting
- BootstrapVue untuk Vue 2, Bootstrap-Vue-Next untuk Vue 3
- Komponen seperti `<BCard>`, `<BModal>`, `<BNavbar>` tanpa CSS manual
- Dukungan penuh untuk Vue reactivity, slots, dan events
