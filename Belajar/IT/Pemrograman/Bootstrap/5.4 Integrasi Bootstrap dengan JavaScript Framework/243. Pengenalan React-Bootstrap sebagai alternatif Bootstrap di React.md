# Pengenalan React-Bootstrap sebagai alternatif Bootstrap di React

## Analogi: Perpustakaan Digital

Alih-alih menggunakan sistem rak buku standar, perpustakaan digital menggunakan sistem rak yang sudah diadaptasi khusus untuk React. Setiap rak adalah komponen React yang sudah terintegrasi dengan state dan props, tanpa perlu memanipulasi DOM secara langsung.

## Penjelasan Detail

React-Bootstrap adalah pustaka komponen yang membangun ulang komponen Bootstrap sebagai komponen React murni. Ini berarti tidak ada dependency JavaScript Bootstrap, tidak ada jQuery, dan tidak ada manipulasi DOM manual. Komponen seperti `<Button>`, `<Modal>`, `<Navbar>` menggunakan props React untuk konfigurasi. Keuntungan: kontrol state yang lebih baik, type safety dengan TypeScript, bundle size lebih kecil (tanpa Bootstrap JS), dan gaya deklaratif React yang konsisten.

## Contoh Kode Implementasi

```jsx
import { useState } from 'react';
import { Button, Modal, Navbar, Container, Nav, Card, Row, Col, Badge, Form, Toast, ToastContainer } from 'react-bootstrap';
import 'bootstrap/dist/css/bootstrap.min.css';

function BookCard({ title, author, rating }) {
  return (
    <Col md={4} className="mb-3">
      <Card>
        <Card.Body>
          <Card.Title>{title}</Card.Title>
          <Card.Subtitle className="mb-2 text-muted">{author}</Card.Subtitle>
          <Badge bg="warning" text="dark">Rating: {rating}/5</Badge>
        </Card.Body>
      </Card>
    </Col>
  );
}

function App() {
  const [showModal, setShowModal] = useState(false);
  const [showToast, setShowToast] = useState(false);

  return (
    <div>
      <Navbar bg="dark" variant="dark">
        <Container>
          <Navbar.Brand>React-Bootstrap Library</Navbar.Brand>
          <Nav>
            <Nav.Link onClick={() => setShowModal(true)}>Tentang</Nav.Link>
          </Nav>
        </Container>
      </Navbar>

      <Container className="mt-4">
        <h1>Katalog Buku</h1>
        <Row>
          <BookCard title="Bootstrap 5" author="Mark Otto" rating={5} />
          <BookCard title="React Design" author="Adam Boduch" rating={4} />
        </Row>
        <Button variant="success" onClick={() => setShowToast(true)}>
          Tampilkan Notifikasi
        </Button>
      </Container>

      <Modal show={showModal} onHide={() => setShowModal(false)}>
        <Modal.Header closeButton>
          <Modal.Title>Tentang Perpustakaan</Modal.Title>
        </Modal.Header>
        <Modal.Body>Perpustakaan digital React-Bootstrap.</Modal.Body>
        <Modal.Footer>
          <Button variant="secondary" onClick={() => setShowModal(false)}>Tutup</Button>
        </Modal.Footer>
      </Modal>

      <ToastContainer position="bottom-end" className="p-3">
        <Toast show={showToast} onClose={() => setShowToast(false)} autohide delay={3000}>
          <Toast.Header><strong>Sukses</strong></Toast.Header>
          <Toast.Body>Notifikasi berhasil ditampilkan!</Toast.Body>
        </Toast>
      </ToastContainer>
    </div>
  );
}
```

## Poin Penting
- React-Bootstrap adalah komponen React murni, tanpa jQuery atau Bootstrap JS
- Gunakan props React (show, onHide, variant) untuk kontrol komponen
- Lebih aman dari konflik karena tidak memanipulasi DOM langsung
