# Cara mengelola Bootstrap di monorepo atau project berskala besar

## Analogi: Perpustakaan Digital

Sebuah jaringan perpustakaan digital besar memiliki banyak cabang. Setiap cabang mungkin membutuhkan tampilan yang sedikit berbeda, tetapi semuanya harus menggunakan sistem rak buku yang konsisten. Monorepo Bootstrap membutuhkan strategi pengelolaan versi, theming, dan build yang terpusat.

## Penjelasan Detail

Dalam monorepo (satu repositori dengan banyak package/proyek), Bootstrap perlu dikelola secara terpusat. Strategi: (1) Simpan Bootstrap sebagai dependency di root package.json dengan `npm install bootstrap` di root, (2) Buat package `@company/ui` yang berisi konfigurasi Bootstrap kustom (Sass variables, komponen, utility custom), (3) Setiap sub-project mengimpor dari package UI tersebut, (4) Gunakan tools seperti Lerna, Nx, atau Turborepo untuk orchestrate build. Pastikan versi Bootstrap konsisten di semua project.

## Contoh Kode Implementasi

```
monorepo/
├── package.json          # bootstrap sebagai devDependency di root
├── packages/
│   ├── ui/               # Shared UI package
│   │   ├── package.json
│   │   ├── src/
│   │   │   ├── bootstrap-custom.scss  # Bootstrap customization
│   │   │   ├── components/
│   │   │   │   ├── Button.tsx
│   │   │   │   └── Card.tsx
│   │   │   └── index.ts
│   │   └── dist/
│   ├── web-app/          # Aplikasi web
│   │   ├── package.json  # depends on @company/ui
│   │   └── src/
│   └── admin-panel/      # Admin panel
│       ├── package.json  # depends on @company/ui
│       └── src/
```

```scss
// packages/ui/src/bootstrap-custom.scss
// Custom Bootstrap theme untuk seluruh organisasi
$primary: #6f42c1;  // Brand color
$font-family-base: 'Inter', sans-serif;
$enable-shadows: true;
$enable-gradients: true;

// Import Bootstrap
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
// ... komponen lainnya
@import "bootstrap/scss/utilities/api";
```

```json
// packages/ui/package.json
{
  "name": "@company/ui",
  "version": "1.0.0",
  "main": "dist/index.js",
  "style": "dist/bootstrap-custom.css",
  "peerDependencies": {
    "bootstrap": "^5.3.0",
    "react": "^18.0.0"
  },
  "scripts": {
    "build:sass": "sass src/bootstrap-custom.scss dist/bootstrap-custom.css",
    "build": "npm run build:sass && tsc"
  }
}
```

## Poin Penting
- Kelola Bootstrap sebagai dependency terpusat di root monorepo
- Buat shared UI package dengan konfigurasi Bootstrap kustom
- Gunakan tools seperti Nx, Turborepo, atau Lerna untuk build orchestration
