# Mobile-First Audit

## Penjelasan

Mobile-first audit adalah proses memeriksa tampilan website mulai dari ukuran layar terkecil (mobile) terlebih dahulu sebelum naik ke tablet/desktop. Pendekatan ini memastikan fondasi responsif kuat sejak awal.

## Fungsi

- Mendeteksi elemen yang overflow atau tersembunyi di layar kecil
- Memastikan touch target cukup besar untuk jari pengguna
- Mengidentifikasi konten yang perlu diatur ulang tata letaknya
- Mengoptimalkan pengalaman mobile terlebih dahulu

## Cara Pengimplementasian

Buka DevTools → pilih device toolbar (Ctrl+Shift+M) → set 375px (mobile standar).

```html
<!-- Contoh: tombol dengan ukuran touch target 44x44px -->
<button class="btn btn-primary" style="min-width: 44px; min-height: 44px; padding: 10px;">
  Kirim
</button>

<!-- Link dengan touch target layak -->
<a href="#" class="d-block p-2" style="min-height: 44px;">
  Baca Selengkapnya
</a>
```

```css
/* Memastikan touch target memenuhi standar WCAG */
.touch-target {
  min-width: 44px;
  min-height: 44px;
}

/* Jarak antar touch target minimal 8px */
.touch-spacing {
  margin-bottom: 8px;
}
```

## Analogi

Mobile-first audit = **inspeksi rumah untuk semua ukuran penghuni**. Sebelum mendekorasi untuk tamu tinggi besar (desktop), pastikan dulu anak kecil, kursi roda, dan semua penghuni bisa melewati pintu, meraih gagang, dan bergerak dengan nyaman di rumah tersebut.

## Dipakai untuk apa

- Memastikan tombol dan link bisa diketuk tanpa salah pencet
- Cek konten tidak terpotong di viewport 375px
- Validasi jarak antar elemen cukup untuk interaksi sentuh
- Memenuhi standar WCAG 2.1 Success Criterion 2.5.5

## Kesalahan umum yang sering terjadi

- **Hanya test di desktop lalu "harapnya" mobile ok** — Fatal, banyak layout broken
- **Touch target terlalu kecil** — Tombol 30x30px sulit dipencet jari
- **Beranggapan 375px cukup dengan zoom** — Zoom bukan solusi untuk UX buruk
- **Mengabaikan landscape mode** — Test juga di 667x375 (landscape)

## Koneksi dengan materi sebelumnya

Materi ini adalah gerbang sebelum menerapkan utility responsif Bootstrap (display, spacing, grid). Audit mobile-first menentukan masalah apa yang perlu diperbaiki, lalu class-class responsif Bootstrap menjadi solusinya.

## Soal latihan & jawaban

**Soal 1:** Berapa ukuran minimum touch target yang direkomendasikan WCAG?

**Jawaban:** 44 x 44 pixel (CSS pixels), sesuai WCAG 2.1 Success Criterion 2.5.5.

**Soal 2:** Sebutkan 3 hal yang harus diperiksa saat melakukan mobile-first audit di viewport 375px!

**Jawaban:**
1. Touch target ≥ 44×44px
2. Tidak ada elemen overflow horizontal
3. Teks tetap terbaca tanpa zoom

**Soal 3:** Tombol berikut bermasalah? Perbaiki agar memenuhi standar aksesibilitas mobile.
```html
<button style="width:32px;height:32px;">X</button>
```

**Jawaban:** Bermasalah — ukurannya 32×32px (< 44px). Perbaiki:
```html
<button style="min-width:44px;min-height:44px;">X</button>
```
