# Membuat Modal Dialog Menggunakan Class Modal, Modal-dialog, dan Modal-content

## Analogi: Perpustakaan Digital

Bayangkan di perpustakaan digital, ketika Anda ingin melihat detail sebuah buku, sebuah kotak informasi muncul di tengah layar, menutupi sementara halaman di belakangnya. Kotak ini disebut modal dialog. Modal digunakan untuk menampilkan konten penting yang memerlukan perhatian pengguna, seperti konfirmasi peminjaman, detail buku, atau formulir pendaftaran. Bootstrap menyediakan komponen modal yang terdiri dari tiga class utama: `modal` sebagai overlay, `modal-dialog` sebagai wadah tengah, dan `modal-content` sebagai konten aktual.

## Penjelasan Detail

Modal Bootstrap terdiri dari struktur berlapis: `modal` adalah lapisan overlay yang menutupi halaman dengan latar belakang semi-transparan. Di dalamnya, `modal-dialog` memposisikan kotak dialog di tengah layar. Kemudian `modal-content` berisi semua konten modal yang dibagi menjadi `modal-header`, `modal-body`, dan `modal-footer`. Modal dapat dipicu dengan atribut `data-bs-toggle="modal"` dan `data-bs-target="#myModal"` atau melalui JavaScript API. Bootstrap secara otomatis menangani fokus, keyboard trap (tombol Escape untuk menutup), dan scroll pada body saat modal terbuka.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Modal Dialog</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Modal Dialog Bootstrap</h1>
        <button type="button" class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#detailBuku">
            Lihat Detail Buku
        </button>
    </div>
    <div class="modal" id="detailBuku" tabindex="-1">
        <div class="modal-dialog">
            <div class="modal-content">
                <div class="modal-header">
                    <h5 class="modal-title">Detail Buku</h5>
                    <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
                </div>
                <div class="modal-body">
                    <p><strong>Judul:</strong> Pemrograman Web Modern</p>
                    <p><strong>Penulis:</strong> Andi Pratama</p>
                    <p><strong>Tahun:</strong> 2024</p>
                    <p>Buku ini membahas tentang pengembangan web modern menggunakan berbagai framework terkini.</p>
                </div>
                <div class="modal-footer">
                    <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Tutup</button>
                    <button type="button" class="btn btn-primary">Pinjam Buku</button>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `modal` adalah overlay penuh layar, `modal-dialog` adalah wadah tengah, `modal-content` adalah konten.
- Gunakan `data-bs-toggle="modal"` dan `data-bs-target` untuk memicu modal.
- Modal memiliki header, body, dan footer yang terstruktur.
- Tombol tutup menggunakan `data-bs-dismiss="modal"` untuk menutup modal.
