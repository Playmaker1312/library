# Membuat Dropdown Menggunakan Class Dropdown, Dropdown-toggle, dan Dropdown-menu

## Analogi: Perpustakaan Digital

Di perpustakaan digital, menu "Kategori" memiliki sub-menu yang muncul saat diklik, seperti "Fiksi", "Non-Fiksi", "Sains", dan "Teknologi". Ini adalah dropdown — daftar pilihan yang muncul saat pengguna berinteraksi dengan tombol atau tautan. Bootstrap menyediakan komponen dropdown yang terdiri dari tiga class utama: `dropdown` sebagai wadah, `dropdown-toggle` pada elemen pemicu, dan `dropdown-menu` sebagai wadah untuk daftar pilihan. Ini seperti laci arsip yang terbuka saat ditarik.

## Penjelasan Detail

Dropdown Bootstrap dimulai dengan elemen pembungkus (biasanya `<div>` atau `<li>`) yang memiliki class `dropdown`. Di dalamnya ada elemen pemicu (biasanya `<button>` atau `<a>`) dengan class `dropdown-toggle` dan atribut `data-bs-toggle="dropdown"`. Class `dropdown-toggle` menambahkan ikon panah kecil di sebelah teks. Elemen `<ul>` atau `<div>` dengan class `dropdown-menu` berisi daftar pilihan, masing-masing menggunakan class `dropdown-item`. Bootstrap JavaScript akan menangani show/hide dropdown saat pemicu diklik. Dropdown juga mendukung keyboard navigation dengan tombol panah.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dropdown</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Dropdown Bootstrap</h1>
        <div class="dropdown">
            <button class="btn btn-primary dropdown-toggle" type="button" data-bs-toggle="dropdown">
                Pilih Kategori
            </button>
            <ul class="dropdown-menu">
                <li><a class="dropdown-item" href="#">Fiksi</a></li>
                <li><a class="dropdown-item" href="#">Non-Fiksi</a></li>
                <li><a class="dropdown-item" href="#">Sains</a></li>
                <li><a class="dropdown-item" href="#">Teknologi</a></li>
                <li><a class="dropdown-item" href="#">Sejarah</a></li>
            </ul>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `dropdown` adalah wadah utama untuk komponen dropdown.
- `dropdown-toggle` pada elemen pemicu menambahkan ikon panah.
- `data-bs-toggle="dropdown"` mengaktifkan interaksi dropdown.
- `dropdown-menu` berisi daftar pilihan (`dropdown-item`).
