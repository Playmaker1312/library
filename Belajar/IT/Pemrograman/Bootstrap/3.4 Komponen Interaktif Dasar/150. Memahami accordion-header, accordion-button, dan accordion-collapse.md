# Memahami Accordion-header, Accordion-button, dan Accordion-collapse

## Analogi: Perpustakaan Digital

Setiap bagian dalam accordion FAQ perpustakaan digital memiliki tiga komponen penting: header sebagai judul yang bisa diklik, button sebagai area klik yang menampilkan indikator panah, dan collapse sebagai konten yang muncul saat dibuka. Ketiganya bekerja bersama seperti saklar lampu: header dan button adalah saklarnya, collapse adalah lampunya. Bootstrap memberikan class khusus untuk masing-masing komponen ini agar styling dan fungsionalitasnya konsisten.

## Penjelasan Detail

`accordion-header` adalah elemen heading (biasanya `<h2>` sampai `<h5>`) yang membungkus tombol trigger. Class ini tidak memberikan styling visual khusus, tetapi diperlukan untuk aksesibilitas dan struktur semantik. `accordion-button` adalah elemen `<button>` yang menjadi trigger untuk membuka/menutup konten. Class ini memberikan styling seperti latar belakang, padding, border, dan ikon panah yang berputar saat accordion dibuka. Saat accordion tertutup, tambahkan class `collapsed` pada button untuk mengatur orientasi panah. `accordion-collapse` adalah elemen pembungkus konten dengan class `collapse` yang akan ditampilkan/disembunyikan. Jika ingin accordion item terbuka secara default, tambahkan class `show` pada `accordion-collapse`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Accordion Struktur</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Struktur Accordion</h1>
        <div class="accordion" id="accStruktur">
            <div class="accordion-item">
                <h2 class="accordion-header">
                    <button class="accordion-button" data-bs-toggle="collapse" data-bs-target="#bagian1">
                        📖 Bagian 1: Pengertian Accordion
                    </button>
                </h2>
                <div id="bagian1" class="accordion-collapse collapse show" data-bs-parent="#accStruktur">
                    <div class="accordion-body">
                        Accordion adalah komponen UI yang memungkinkan pengguna menampilkan dan menyembunyikan konten secara bergantian.
                    </div>
                </div>
            </div>
            <div class="accordion-item">
                <h2 class="accordion-header">
                    <button class="accordion-button collapsed" data-bs-toggle="collapse" data-bs-target="#bagian2">
                        🔧 Bagian 2: Cara Penggunaan
                    </button>
                </h2>
                <div id="bagian2" class="accordion-collapse collapse" data-bs-parent="#accStruktur">
                    <div class="accordion-body">
                        Gunakan <code>accordion-header</code> untuk judul, <code>accordion-button</code> sebagai trigger, dan <code>accordion-collapse</code> untuk konten.
                    </div>
                </div>
            </div>
            <div class="accordion-item">
                <h2 class="accordion-header">
                    <button class="accordion-button collapsed" data-bs-toggle="collapse" data-bs-target="#bagian3">
                        💡 Bagian 3: Tips
                    </button>
                </h2>
                <div id="bagian3" class="accordion-collapse collapse" data-bs-parent="#accStruktur">
                    <div class="accordion-body">
                        Gunakan class <code>show</code> untuk membuka item secara default, dan <code>collapsed</code> pada button untuk mengatur arah panah.
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `accordion-header` adalah wadah heading untuk tombol trigger.
- `accordion-button` adalah tombol trigger dengan ikon panah.
- `accordion-collapse` adalah konten yang disembunyikan/ditampilkan.
- Class `show` menampilkan collapse secara default, `collapsed` pada button untuk state tertutup.
