# Membuat Dropdown-item dan Dropdown-divider

## Analogi: Perpustakaan Digital

Dalam menu dropdown perpustakaan digital, setiap opsi seperti "Pinjam Buku", "Kembalikan Buku", atau "Riwayat" adalah `dropdown-item`. Kadang Anda perlu memisahkan grup opsi dengan garis pemisah, seperti memisahkan menu "Pengaturan Akun" dari menu "Logout". Bootstrap menyediakan class `dropdown-item` untuk setiap opsi dan `dropdown-divider` (atau `<hr class="dropdown-divider">`) untuk garis pemisah horizontal di dalam dropdown menu.

## Penjelasan Detail

`dropdown-item` adalah class yang diterapkan pada elemen `<a>`, `<button>`, atau elemen lainnya di dalam `dropdown-menu`. Class ini memberikan styling seperti padding, hover effect, dan active state. Anda bisa menambahkan class `active` untuk menandai item yang sedang dipilih dan `disabled` untuk menonaktifkan item. `dropdown-divider` adalah garis pemisah horizontal tipis yang digunakan untuk memisahkan grup item dalam dropdown. Anda juga bisa menambahkan `dropdown-header` untuk memberi label pada grup item, dan `dropdown-item-text` untuk menampilkan teks biasa yang tidak bisa diklik dalam dropdown.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dropdown Item & Divider</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container mt-4">
        <h1>Dropdown Item, Divider, dan Header</h1>
        <div class="dropdown">
            <button class="btn btn-success dropdown-toggle" data-bs-toggle="dropdown">
                Akun Saya
            </button>
            <ul class="dropdown-menu">
                <li><h6 class="dropdown-header">Profil</h6></li>
                <li><a class="dropdown-item" href="#">Lihat Profil</a></li>
                <li><a class="dropdown-item" href="#">Edit Profil</a></li>
                <li><hr class="dropdown-divider"></li>
                <li><h6 class="dropdown-header">Perpustakaan</h6></li>
                <li><a class="dropdown-item" href="#">Buku Saya</a></li>
                <li><a class="dropdown-item active" href="#">Riwayat Peminjaman</a></li>
                <li><a class="dropdown-item disabled" href="#">Laporan (segera hadir)</a></li>
                <li><hr class="dropdown-divider"></li>
                <li><a class="dropdown-item text-danger" href="#">Keluar</a></li>
            </ul>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `dropdown-item` untuk setiap opsi yang bisa diklik dalam dropdown.
- `dropdown-divider` (atau `<hr class="dropdown-divider">`) untuk garis pemisah.
- `dropdown-header` untuk memberi label pada grup item.
- Gunakan `active` untuk item terpilih dan `disabled` untuk item non-aktif.
