# Menggunakan class w-25, w-50, w-75, w-100, dan w-auto untuk lebar

## Analogi: Perpustakaan Digital

Rak buku di perpustakaan bisa diatur lebarnya sebagai persentase dari total ruang yang tersedia. w-25 berarti rak menggunakan seperempat lebar ruangan, w-50 setengah, w-75 tiga perempat, dan w-100 seluruh lebar. Pustakawan bisa membagi ruang rak sesuai kebutuhan dengan class lebar Bootstrap.

## Penjelasan Detail

Class width utility Bootstrap menggunakan `w-{persentase}` untuk mengatur properti CSS `width` sebagai persentase dari parent container. Nilai yang tersedia: w-25 (25%), w-50 (50%), w-75 (75%), w-100 (100%), dan w-auto (width: auto). Class ini berguna untuk membuat elemen dengan lebar proporsional tanpa CSS kustom. w-auto mengembalikan lebar ke ukuran default berdasarkan konten. Untuk lebar berdasarkan viewport, gunakan vw-100. Class width ini bisa dikombinasikan dengan class lain untuk responsive design.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Width Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { background-color: #0d6efd; color: white; text-align: center; height: 40px; line-height: 40px; margin-bottom: 5px; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Width Utilities</h1>
        <div class="box w-25">w-25</div>
        <div class="box w-50">w-50</div>
        <div class="box w-75">w-75</div>
        <div class="box w-100">w-100</div>
        <div class="box w-auto" style="display:inline-block">w-auto (sesuai konten)</div>
        <hr>
        <div class="d-flex gap-2">
            <div class="box w-25">25%</div>
            <div class="box w-50">50%</div>
            <div class="box w-25">25%</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- w-25, w-50, w-75, w-100 dalam persentase dari parent
- w-auto mengembalikan lebar ke ukuran konten
- Berguna untuk membuat proporsi lebar tanpa CSS kustom
