# Menggunakan class h-25, h-50, h-75, h-100, dan h-auto untuk tinggi

## Analogi: Perpustakaan Digital

Rak buku juga bisa diatur tingginya secara proporsional. h-25 berarti rak setinggi seperempat dari total tinggi ruangan, h-100 memenuhi seluruh tinggi. Seperti rak yang bisa disesuaikan dengan tinggi langit-langit perpustakaan, Bootstrap menyediakan class tinggi untuk mengontrol ketinggian elemen.

## Penjelasan Detail

Class height utility Bootstrap menggunakan `h-{persentase}` untuk mengatur properti CSS `height` sebagai persentase dari parent container. Nilai: h-25 (25%), h-50 (50%), h-75 (75%), h-100 (100%), dan h-auto (height: auto). Class height membutuhkan parent yang memiliki tinggi pasti (misalnya vh-100 pada parent). Untuk tinggi berdasarkan viewport, gunakan class vh-100. h-auto mengembalikan tinggi ke ukuran default berdasarkan konten. Berguna untuk membuat kolom dengan tinggi proporsional, banner, atau section full-height.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Height Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .container-demo { height: 200px; background-color: #f8f9fa; border: 2px dashed #dee2e6; display: flex; gap: 5px; align-items: flex-start; }
        .box { background-color: #dc3545; color: white; text-align: center; width: 18%; display: flex; align-items: center; justify-content: center; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Height Utilities</h1>
        <div class="container-demo p-2">
            <div class="box h-25">h-25</div>
            <div class="box h-50">h-50</div>
            <div class="box h-75">h-75</div>
            <div class="box h-100">h-100</div>
            <div class="box h-auto" style="padding:10px">h-auto</div>
        </div>
        <div class="d-flex mt-3 gap-2" style="height:150px; background:#e9ecef;">
            <div class="bg-success text-white p-2 h-50">h-50</div>
            <div class="bg-success text-white p-2 h-100">h-100</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- h-25, h-50, h-75, h-100 dalam persentase dari parent
- Parent harus memiliki tinggi pasti agar class berfungsi
- h-auto mengembalikan tinggi ke ukuran konten
