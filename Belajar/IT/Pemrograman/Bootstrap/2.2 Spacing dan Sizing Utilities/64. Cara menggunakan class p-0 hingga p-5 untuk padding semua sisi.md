# Cara menggunakan class p-0 hingga p-5 untuk padding semua sisi

## Analogi: Perpustakaan Digital

Bayangkan sebuah bingkai foto yang memiliki jarak dari tepi bingkai ke foto di dalamnya. p-0 berarti foto menempel ke tepi, p-5 berarti ada jarak lebar antara foto dan bingkai. Bootstrap menyediakan padding seragam di semua sisi seperti bingkai dengan ketebalan yang bisa diatur.

## Penjelasan Detail

Class `p-{ukuran}` memberikan padding seragam pada semua sisi elemen (top, right, bottom, left). Skala ukuran: p-0 (0rem), p-1 (0.25rem), p-2 (0.5rem), p-3 (1rem), p-4 (1.5rem), p-5 (3rem). Padding berbeda dengan margin karena padding berada di dalam border elemen, sehingga mempengaruhi ukuran total elemen. Berguna untuk memberi ruang di dalam container, card, button, atau elemen lainnya. Padding sering dikombinasikan dengan background color agar konten tidak menempel ke tepi. Gunakan p-3 sebagai default yang paling umum untuk sebagian besar konten.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Padding Semua Sisi</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { background-color: #0d6efd; color: white; border: 2px solid #0a58ca; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Padding p-0 hingga p-5</h1>
        <div class="box p-0 mb-2">p-0 (tanpa padding)</div>
        <div class="box p-1 mb-2">p-1 (0.25rem)</div>
        <div class="box p-2 mb-2">p-2 (0.5rem)</div>
        <div class="box p-3 mb-2">p-3 (1rem)</div>
        <div class="box p-4 mb-2">p-4 (1.5rem)</div>
        <div class="box p-5 mb-2">p-5 (3rem)</div>
        <hr>
        <div class="card">
            <div class="card-body p-5">
                <h5 class="card-title">Card dengan p-5</h5>
                <p class="card-text">Padding besar memberikan ruang luas di dalam card.</p>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- p-0 hingga p-5 memberikan padding seragam di semua sisi elemen
- Padding berada di dalam border, mempengaruhi ukuran total elemen
- p-3 adalah ukuran default yang paling umum digunakan
