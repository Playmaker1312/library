# Memahami responsive spacing yaitu mt-md-3 dan px-lg-5

## Analogi: Perpustakaan Digital

Perpustakaan memiliki rak yang bisa diatur jaraknya berbeda untuk layar komputer dan layar ponsel. Di layar besar, jarak antar rak bisa lebar (mt-lg-5), tetapi di layar kecil jaraknya menyempit (mt-2). Bootstrap menyediakan spacing responsif yang menyesuaikan dengan ukuran viewport seperti rak yang otomatis mengatur jarak.

## Penjelasan Detail

Responsive spacing memungkinkan class spacing diterapkan hanya pada breakpoint tertentu atau lebih besar. Formatnya: `{property}{sisi}-{breakpoint}-{ukuran}`. Breakpoint Bootstrap: sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px), xxl (≥1400px). Contoh: `mt-md-3` berarti margin-top 1rem hanya pada layar md ke atas, di layar lebih kecil margin tidak diterapkan. `px-lg-5` berarti padding horizontal 3rem pada layar lg ke atas. Tanpa breakpoint, class berlaku untuk semua ukuran layar. Responsive spacing sangat penting untuk mobile-first design, memungkinkan tata letak yang rapat di ponsel dan lapang di desktop.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Spacing</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { background-color: #6f42c1; color: white; padding: 0.5rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Responsive Spacing</h1>
        <div class="box mt-2 mt-md-4 mt-lg-5 mb-3">
            mt-2 (default), mt-md-4, mt-lg-5
        </div>
        <div class="box px-3 px-md-4 px-xl-5 py-2">
            px-3 (default), px-md-4, px-xl-5
        </div>
        <div class="box mt-3 mt-lg-0 py-2 py-sm-4">
            mt-3 default, mt-lg-0 (hilang di lg+)
        </div>
        <div class="d-flex flex-column flex-md-row gap-2 mt-4">
            <div class="box p-2">Item 1</div>
            <div class="box p-2 ms-md-auto">ms-md-auto (di md ke atas)</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Format: {property}{sisi}-{breakpoint}-{ukuran}
- Breakpoint: sm, md, lg, xl, xxl
- Tanpa breakpoint = berlaku untuk semua ukuran layar
