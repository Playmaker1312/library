# Cara menggunakan class m-0 hingga m-5 untuk margin semua sisi

## Analogi: Perpustakaan Digital

Bayangkan buku-buku di perpustakaan yang memiliki jarak seragam dari semua tepi raknya. Class m-0 hingga m-5 seperti pengaturan jarak standar: m-0 berarti buku menempel penuh ke tepi, m-5 berarti buku memiliki jarak besar dari semua tepi. Pustakawan bisa memilih jarak yang sesuai untuk每种 jenis buku.

## Penjelasan Detail

Class `m-{ukuran}` memberikan margin pada semua sisi elemen (top, right, bottom, left) secara seragam. Ukuran 0 berarti margin 0rem, m-1 = 0.25rem, m-2 = 0.5rem, m-3 = 1rem, m-4 = 1.5rem, dan m-5 = 3rem. Class ini berguna untuk memberikan jarak konsisten di sekitar elemen. Nilai auto pada margin bisa digunakan dengan `m-auto` untuk menengahkan elemen secara horizontal di dalam container flex atau grid. Margin kumulatif: jika dua elemen berturut-turut memiliki margin-bottom 3 dan margin-top 3, jarak totalnya adalah 3rem (bukan 6rem) karena CSS margin collapsing.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Margin Semua Sisi</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .demo { background-color: #e9ecef; }
        .item { background-color: #0d6efd; color: white; padding: 0.5rem; text-align: center; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Margin m-0 hingga m-5</h1>
        <div class="demo p-1 mb-2"><div class="item m-0">m-0</div></div>
        <div class="demo p-1 mb-2"><div class="item m-1">m-1</div></div>
        <div class="demo p-1 mb-2"><div class="item m-2">m-2</div></div>
        <div class="demo p-1 mb-2"><div class="item m-3">m-3</div></div>
        <div class="demo p-1 mb-2"><div class="item m-4">m-4</div></div>
        <div class="demo p-1 mb-2"><div class="item m-5">m-5</div></div>
        <div class="border p-3 mt-4" style="width:200px">
            <div class="item m-auto" style="width:100px">m-auto</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- m-0 hingga m-5 memberikan margin seragam di semua sisi
- m-auto berguna untuk menengahkan elemen dalam container flex/grid
- Margin bersifat kumulatif dengan CSS margin collapsing
