# Menggunakan class vw-100 dan vh-100 untuk viewport sizing

## Analogi: Perpustakaan Digital

Perpustakaan memiliki layar digital yang lebarnya selalu menyesuaikan dengan lebar jendela browser pengunjung. vw-100 membuat elemen selebar layar penuh, vh-100 setinggi layar penuh. Seperti poster yang membentang dari ujung ke ujung jendela perpustakaan, tidak peduli seberapa besar jendelanya.

## Penjelasan Detail

Class `vw-100` mengatur `width: 100vw` yang membuat elemen selebar viewport (lebar layar), termasuk scrollbar. Class `vh-100` mengatur `height: 100vh` yang membuat elemen setinggi viewport. Berbeda dengan w-100 dan h-100 yang berdasarkan parent container, vw-100 dan vh-100 berdasarkan ukuran viewport browser. `min-vw-100` dan `min-vh-100` juga tersedia untuk versi min-width/min-height. vh-100 sering digunakan untuk hero section atau full-screen landing page. vw-100 berguna untuk elemen yang harus membentang penuh tanpa terpengaruh parent.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Viewport Sizing</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .half-viewport { background-color: #0d6efd; color: white; display: flex; align-items: center; justify-content: center; }
    </style>
</head>
<body>
    <div class="container-fluid p-0">
        <div class="vh-100 d-flex align-items-center justify-content-center bg-primary text-white flex-column">
            <h1>vh-100 Section</h1>
            <p>Full screen height (100% viewport height)</p>
        </div>
        <div class="bg-success text-white p-4">
            <h2>Konten Normal</h2>
            <p class="vw-100 bg-success bg-opacity-75 p-2">Elemen ini memiliki vw-100 (lebar viewport penuh)</p>
        </div>
        <div class="bg-info text-dark p-4" style="height:100px;">
            <div class="bg-warning h-50 w-50 p-2">w-50 h-50 (50% parent)</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- vw-100 = 100% lebar viewport, vh-100 = 100% tinggi viewport
- Berbeda dengan w-100/h-100 yang berdasarkan parent container
- Gunakan vh-100 untuk hero section, vw-100 untuk elemen full-width
