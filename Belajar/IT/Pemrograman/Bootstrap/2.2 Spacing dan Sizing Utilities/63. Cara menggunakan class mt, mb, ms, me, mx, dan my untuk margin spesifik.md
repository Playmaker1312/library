# Cara menggunakan class mt, mb, ms, me, mx, dan my untuk margin spesifik

## Analogi: Perpustakaan Digital

Rak buku tidak selalu membutuhkan jarak sama di semua sisi. Kadang perlu jarak di atas (mt) untuk judul, jarak bawah (mb) sebelum kategori berikutnya, atau jarak kiri (ms) untuk indentasi. Bootstrap menyediakan class margin spesifik seperti pustakawan yang mengatur jarak secara presisi per sisi.

## Penjelasan Detail

Class margin spesifik Bootstrap: `mt-*` (margin-top), `mb-*` (margin-bottom), `ms-*` (margin-start/left), `me-*` (margin-end/right), `mx-*` (margin kiri+kanan/horizontal), `my-*` (margin atas+bawah/vertical). Setiap class menggunakan skala 0-5 dan auto. Contoh: `mt-3` memberi margin atas 1rem, `ms-auto` mendorong elemen ke kanan dalam flex container, `mx-auto` menengahkan secara horizontal. Class spesifik sangat berguna untuk mengatur tata letak tanpa mempengaruhi sisi lain. Penggunaan umum: `mt-3` untuk jarak antar section, `mb-2` untuk jarak antar paragraf, `ms-4` untuk indentasi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Margin Spesifik</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { background-color: #0d6efd; color: white; text-align: center; padding: 0.5rem; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Class Margin Spesifik</h1>
        <div class="box mt-3">mt-3 (margin-top 1rem)</div>
        <div class="box mb-4">mb-4 (margin-bottom 1.5rem)</div>
        <div class="box ms-5">ms-5 (margin-start 3rem)</div>
        <div class="box me-2">me-2 (margin-end 0.5rem)</div>
        <div class="box mx-3">mx-3 (margin horizontal 1rem)</div>
        <div class="box my-4">my-4 (margin vertikal 1.5rem)</div>
        <div class="d-flex border p-2 mt-4">
            <div class="box">Kiri</div>
            <div class="box ms-auto">ms-auto (terdorong kanan)</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- mt (top), mb (bottom), ms (start/left), me (end/right), mx (horizontal), my (vertikal)
- Gunakan ms-auto untuk mendorong elemen ke kanan dalam flex container
- Class spesifik memungkinkan kontrol margin presisi per sisi
