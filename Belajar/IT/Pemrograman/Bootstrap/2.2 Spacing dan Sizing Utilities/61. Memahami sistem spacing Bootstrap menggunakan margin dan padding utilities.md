# Memahami sistem spacing Bootstrap menggunakan margin dan padding utilities

## Analogi: Perpustakaan Digital

Rak buku di perpustakaan memiliki jarak tertentu antara satu buku dengan buku lain (margin) dan jarak dari tepi rak ke isi buku (padding). Bootstrap menyediakan sistem spacing yang konsisten seperti penggaris standar perpustakaan, dengan ukuran 0 hingga 5 yang merepresentasikan jarak dalam satuan rem. Pustakawan cukup memilih ukuran jarak dari skala yang tersedia.

## Penjelasan Detail

Sistem spacing Bootstrap menggunakan skala 0-5 (plus auto) yang merepresentasikan nilai rem: 0 (0rem), 1 (0.25rem), 2 (0.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem). Format class spacing adalah `{property}{sisi}-{ukuran}`. Property terdiri dari `m` (margin) dan `p` (padding). Sisi terdiri dari `t` (top), `b` (bottom), `s` (start/left), `e` (end/right), `x` (horizontal), `y` (vertical), atau kosong untuk semua sisi. Contoh: `mt-3` memberikan margin-top 1rem, `p-4` memberikan padding 1.5rem di semua sisi. Nilai `auto` dapat digunakan untuk margin (ms-auto, me-auto, mx-auto) untuk centering otomatis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sistem Spacing Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { background-color: #e9ecef; border: 2px solid #0d6efd; }
        .inner { background-color: #0d6efd; color: white; text-align: center; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Sistem Spacing Bootstrap</h1>
        <div class="box p-3 mb-3">
            <div class="inner p-1">p-3 (padding 1rem semua sisi)</div>
        </div>
        <div class="box p-5 mb-3">
            <div class="inner p-1">p-5 (padding 3rem semua sisi)</div>
        </div>
        <div class="d-flex gap-3 mb-3">
            <div class="box p-2">Item 1</div>
            <div class="box p-2">Item 2</div>
            <div class="box p-2 ms-auto">Item 3 (ms-auto)</div>
        </div>
        <div class="bg-light p-4 rounded">
            <h3 class="mt-0">Margin Top 0</h3>
            <p class="mb-0">Margin Bottom 0 pada paragraf ini.</p>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Skala spacing: 0 (0rem), 1 (0.25rem), 2 (0.5rem), 3 (1rem), 4 (1.5rem), 5 (3rem)
- Format class: {m|p}{t|b|s|e|x|y|kosong}-{ukuran|auto}
- Margin auto (mx-auto, ms-auto) berguna untuk centering elemen
