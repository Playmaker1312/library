# Cara menggunakan class pt, pb, ps, pe, px, dan py untuk padding spesifik

## Analogi: Perpustakaan Digital

Tidak semua sisi bingkai perlu ketebalan sama. Kadang perlu padding tebal di atas (pt) untuk header, padding kiri (ps) untuk binding buku, atau padding kanan (pe) untuk catatan pinggir. Bootstrap class padding spesifik seperti pengaturan jarak per sisi yang presisi.

## Penjelasan Detail

Class padding spesifik Bootstrap: `pt-*` (padding-top), `pb-*` (padding-bottom), `ps-*` (padding-start/left), `pe-*` (padding-end/right), `px-*` (padding kiri+kanan/horizontal), `py-*` (padding atas+bawah/vertikal). Semua menggunakan skala 0-5. Contoh: `pt-4` memberi padding atas 1.5rem, `px-3` memberi padding kiri dan kanan 1rem. Class spesifik berguna saat ingin menjaga padding di sisi tertentu tanpa mempengaruhi sisi lain. Misalnya, `pt-5 pb-2 px-3` memberikan padding berbeda di setiap arah. Sering digunakan dalam layout card, section, dan form.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Padding Spesifik</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box { background-color: #198754; color: white; border: 2px solid #146c43; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Class Padding Spesifik</h1>
        <div class="box pt-4 mb-2">pt-4 (padding-top 1.5rem)</div>
        <div class="box pb-3 mb-2">pb-3 (padding-bottom 1rem)</div>
        <div class="box ps-5 mb-2">ps-5 (padding-start 3rem)</div>
        <div class="box pe-2 mb-2">pe-2 (padding-end 0.5rem)</div>
        <div class="box px-4 mb-2">px-4 (padding horizontal 1.5rem)</div>
        <div class="box py-3 mb-2">py-3 (padding vertikal 1rem)</div>
        <div class="box pt-5 pb-2 ps-4 pe-1 mb-2">
            pt-5 pb-2 ps-4 pe-1 (kombinasi)
        </div>
        <div class="bg-light p-4 rounded">
            <div class="box py-2 px-5">py-2 px-5 (umum digunakan)</div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- pt (top), pb (bottom), ps (start/left), pe (end/right), px (horizontal), py (vertikal)
- Skala 0-5 sama dengan padding semua sisi
- Kombinasikan beberapa class padding untuk kontrol presisi
