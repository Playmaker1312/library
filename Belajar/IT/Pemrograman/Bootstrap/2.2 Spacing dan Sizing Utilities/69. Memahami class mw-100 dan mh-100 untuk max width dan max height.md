# Memahami class mw-100 dan mh-100 untuk max width dan max height

## Analogi: Perpustakaan Digital

Rak buku di perpustakaan memiliki batas maksimal lebar dan tinggi agar tidak melebihi ruang yang tersedia. mw-100 membatasi lebar maksimal 100% dari parent, mh-100 membatasi tinggi maksimal 100%. Seperti rak yang tidak boleh lebih lebar dari dinding tempatnya ditempatkan.

## Penjelasan Detail

Class `mw-100` mengatur properti CSS `max-width: 100%`, memastikan elemen tidak pernah melebihi lebar parent container. Class `mh-100` mengatur `max-height: 100%`, membatasi tinggi maksimal elemen. Berguna untuk gambar, video, atau konten media agar tetap responsif dan tidak meluap dari container. Biasanya dikombinasikan dengan class lain seperti img-fluid. mw-100 sangat penting untuk gambar responsif agar tidak melampaui lebar layar pada perangkat kecil. mh-100 berguna untuk konten dalam container dengan tinggi tetap.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Max Width dan Max Height</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .parent { width: 300px; height: 150px; background: #f8f9fa; border: 2px solid #dee2e6; margin-bottom: 1rem; }
        .child { background: #0d6efd; color: white; text-align: center; }
    </style>
</head>
<body class="p-4">
    <div class="container">
        <h1>Max Width & Max Height</h1>
        <div class="parent p-2">
            <div class="child mw-100" style="width:400px">mw-100 (maks 300px)</div>
            <small class="text-muted">Lebar asli 400px, tapi dibatasi 100% parent (300px)</small>
        </div>
        <div class="parent p-2" style="height:100px">
            <div class="child mh-100" style="height:200px; padding:5px">mh-100 (maks 100px)</div>
            <small class="text-muted">Tinggi asli 200px, dibatasi 100% parent (100px)</small>
        </div>
        <div class="mt-3">
            <img src="https://via.placeholder.com/600x200" class="mw-100 border" alt="gambar responsif">
            <p class="text-muted">Gambar 600px dibatasi mw-100 agar tidak overflow</p>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- mw-100 = max-width: 100%, mencegah elemen melebihi parent
- mh-100 = max-height: 100%, membatasi tinggi maksimal
- Sangat berguna untuk gambar dan media responsif
