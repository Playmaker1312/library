# Membuat form yang aksesibel dengan label dan error message yang benar

## Analogi: Perpustakaan Digital

Formulir pendaftaran anggota perpustakaan digital harus jelas: setiap kolom punya label yang terbaca, instruksi pengisian mudah dipahami, dan pesan error memberitahu dengan tepat apa yang salah. Pengguna dengan screen reader harus bisa mengisi formulir tanpa hambatan.

## Penjelasan Detail

Form aksesibel memerlukan: setiap input memiliki `<label>` eksplisit dengan atribut `for` yang cocok dengan `id` input. Pesan error harus terhubung ke input via `aria-describedby`. Gunakan `aria-invalid="true"` untuk input yang salah. Bootstrap menyediakan kelas `form-label`, `form-control`, `form-text`, `invalid-feedback`, dan `is-invalid` untuk styling form yang aksesibel. Kelompokkan elemen terkait dengan `<fieldset>` dan `<legend>`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Accessible Form</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Form Pendaftaran Anggota</h1>

    <form novalidate>
      <!-- Input dengan label -->
      <div class="mb-3">
        <label for="nama" class="form-label">Nama Lengkap</label>
        <input type="text" class="form-control" id="nama" required 
               autocomplete="name" aria-describedby="namaHelp">
        <div id="namaHelp" class="form-text">Nama sesuai KTP.</div>
        <div class="invalid-feedback">Nama lengkap harus diisi.</div>
      </div>

      <!-- Input dengan error -->
      <div class="mb-3">
        <label for="email" class="form-label">Email</label>
        <input type="email" class="form-control is-invalid" id="email" 
               required aria-describedby="emailError" autocomplete="email"
               aria-invalid="true">
        <div id="emailError" class="invalid-feedback">
          Email tidak valid. Contoh: nama@email.com
        </div>
      </div>

      <!-- Fieldset untuk grup -->
      <fieldset class="mb-3">
        <legend class="col-form-label">Jenis Keanggotaan</legend>
        <div class="form-check">
          <input class="form-check-input" type="radio" name="jenis" id="reguler" checked>
          <label class="form-check-label" for="reguler">Reguler</label>
        </div>
        <div class="form-check">
          <input class="form-check-input" type="radio" name="jenis" id="premium">
          <label class="form-check-label" for="premium">Premium</label>
        </div>
      </fieldset>

      <!-- Checkbox -->
      <div class="mb-3 form-check">
        <input type="checkbox" class="form-check-input" id="setuju" required>
        <label class="form-check-label" for="setuju">Saya setuju dengan syarat & ketentuan</label>
        <div class="invalid-feedback">Anda harus menyetujui syarat dan ketentuan.</div>
      </div>

      <button type="submit" class="btn btn-primary">Daftar</button>
    </form>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Setiap input harus memiliki `<label>` dengan atribut `for`
- Hubungkan error message ke input dengan `aria-describedby`
- Gunakan `aria-invalid="true"` untuk input yang salah
