# Memastikan warna Bootstrap memenuhi standar kontras WCAG

## Analogi: Perpustakaan Digital

Perpustakaan digital memastikan teks di layar mudah dibaca dengan latar belakang yang cukup kontras. Teks abu-abu muda di atas putih mungkin terlihat stylish, tetapi pengguna dengan gangguan penglihatan akan kesulitan membacanya. Kontras warna yang memadai adalah syarat dasar aksesibilitas.

## Penjelasan Detail

WCAG 2.1 mensyaratkan rasio kontras minimum 4.5:1 untuk teks normal dan 3:1 untuk teks besar (>18px bold atau >24px). Warna Bootstrap secara default sudah memenuhi standar AA untuk sebagian besar kasus, tetapi pengkustomasian warna dapat melanggar ini. Gunakan alat seperti WebAIM Contrast Checker atau Accessibility Insights untuk memverifikasi kontras. Bootstrap's `$theme-colors` dapat disesuaikan untuk memastikan semua kombinasi memenuhi standar.

## Contoh Kode Implementasi

```scss
// Memastikan warna kustom memenuhi kontras WCAG
$custom-colors: (
  "primary": #0d6efd,      // Rasio 4.8:1 dengan putih (AA)
  "secondary": #6c757d,    // Rasio 4.2:1 dengan putih (AA)
  "success": #198754,      // Rasio 4.5:1 dengan putih (AA)
  "danger": #dc3545,       // Rasio 4.1:1 dengan putih (AA)
  "warning": #ffc107,      // Rasio 1.5:1 dengan putih (FAIL) -> gunakan teks gelap
  "info": #0dcaf0,         // Rasio 1.8:1 dengan putih (FAIL) -> gunakan teks gelap
  "light": #f8f9fa,        // Rasio 1.2:1 dengan putih -> jangan untuk teks
  "dark": #212529,         // Rasio 14.5:1 dengan putih (AAA)
);

// Untuk warning dan info, Bootstrap otomatis menggunakan teks gelap
// Verifikasi dengan alat kontras jika mengubah warna kustom
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>WCAG Contrast</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Uji Kontras Warna Bootstrap</h1>
    <div class="row">
      <div class="col-4 mb-2"><span class="badge bg-primary text-white">Primary (AA)</span></div>
      <div class="col-4 mb-2"><span class="badge bg-success text-white">Success (AA)</span></div>
      <div class="col-4 mb-2"><span class="badge bg-danger text-white">Danger (AA)</span></div>
      <div class="col-4 mb-2"><span class="badge bg-warning text-dark">Warning (AA)</span></div>
      <div class="col-4 mb-2"><span class="badge bg-info text-dark">Info (AA)</span></div>
      <div class="col-4 mb-2"><span class="badge bg-dark text-white">Dark (AAA)</span></div>
    </div>
    <!-- Tool kontras -->
    <p class="mt-3">Verifikasi kontras di <a href="https://webaim.org/resources/contrastchecker/" target="_blank">WebAIM Contrast Checker</a></p>
  </div>
</body>
</html>
```

## Poin Penting
- Standar WCAG AA: rasio kontras 4.5:1 untuk teks normal, 3:1 untuk teks besar
- Warna Bootstrap default sudah memenuhi AA untuk kombinasi yang tepat
- Gunakan teks gelap (`text-dark`) untuk warning dan info backgrounds
