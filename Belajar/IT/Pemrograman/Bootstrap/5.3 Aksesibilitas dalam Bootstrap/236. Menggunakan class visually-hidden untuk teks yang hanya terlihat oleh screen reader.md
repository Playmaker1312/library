# Menggunakan class visually-hidden untuk teks yang hanya terlihat oleh screen reader

## Analogi: Perpustakaan Digital

Perpustakaan digital menyediakan informasi tambahan yang hanya bisa "didengar" oleh pengunjung dengan keterbatasan penglihatan, seperti deskripsi tersembunyi di bawah kode QR yang hanya terbaca oleh alat pembaca khusus. Informasi ini tidak terlihat di layar tetapi tersedia untuk screen reader.

## Penjelasan Detail

Kelas `.visually-hidden` Bootstrap menyembunyikan elemen secara visual tetapi tetap membuatnya tersedia untuk screen reader. Ini berguna untuk: memberikan konteks tambahan pada icon-only button, mendeskripsikan gambar kompleks, memberikan instruksi tambahan, atau membuat heading yang hanya untuk screen reader. Bootstrap juga menyediakan `.visually-hidden-focusable` yang menyembunyikan elemen hingga di-focus (ideal untuk skip link). Jangan gunakan `display: none` atau `visibility: hidden` untuk elemen yang perlu dibaca screen reader.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Visually Hidden</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Visually Hidden Examples</h1>

    <!-- Icon button dengan teks untuk screen reader -->
    <button class="btn btn-outline-primary" aria-label="Cari">
      🔍 <span class="visually-hidden">Cari buku</span>
    </button>

    <!-- Progress bar dengan teks screen reader -->
    <div class="progress mb-3" role="progressbar" aria-label="Progres membaca" 
         aria-valuenow="60" aria-valuemin="0" aria-valuemax="100">
      <div class="progress-bar" style="width: 60%">
        <span class="visually-hidden">60% selesai baca</span>
      </div>
    </div>

    <!-- Informasi tambahan hanya untuk screen reader -->
    <div class="card">
      <div class="card-body">
        <h5 class="card-title">Judul Buku</h5>
        <p class="card-text">Deskripsi buku.</p>
        <span class="visually-hidden">Rating: 4 dari 5 bintang</span>
      </div>
    </div>

    <!-- Skip link dengan visually-hidden-focusable -->
    <a href="#main" class="visually-hidden-focusable">Skip ke konten utama</a>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `.visually-hidden` untuk teks yang hanya untuk screen reader
- Gunakan `.visually-hidden-focusable` untuk skip link
- Jangan gunakan `display: none` untuk elemen yang perlu dibaca screen reader
