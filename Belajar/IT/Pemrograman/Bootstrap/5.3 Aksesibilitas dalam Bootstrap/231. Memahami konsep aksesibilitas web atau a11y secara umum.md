# Memahami konsep aksesibilitas web atau a11y secara umum

## Analogi: Perpustakaan Digital

Perpustakaan digital harus bisa diakses oleh semua orang, termasuk pengguna dengan keterbatasan penglihatan yang menggunakan pembaca layar, pengguna yang tidak bisa menggunakan mouse, atau orang dengan gangguan pendengaran. Aksesibilitas web (a11y) adalah praktik merancang halaman agar dapat digunakan oleh semua orang tanpa terkecuali.

## Penjelasan Detail

Aksesibilitas web (disingkat a11y - "a" lalu 11 huruf lalu "y") memastikan penyandang disabilitas dapat mengakses, memahami, dan berinteraksi dengan web. Ini mencakup: konten yang bisa diakses pembaca layar (screen reader), navigasi keyboard, kontras warna yang cukup, teks alternatif untuk gambar, dan caption untuk video. WCAG (Web Content Accessibility Guidelines) adalah standar internasional dengan tiga level: A, AA, dan AAA. Bootstrap menyediakan fondasi aksesibilitas yang baik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Aksesibilitas Web</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Praktik Aksesibilitas Dasar</h1>
    
    <!-- Gambar dengan alt text -->
    <img src="https://via.placeholder.com/200" class="img-fluid" alt="Contoh gambar aksesibel">
    
    <!-- Link yang jelas -->
    <a href="#" class="btn btn-link">Baca selengkapnya tentang Bootstrap</a>
    
    <!-- Form dengan label -->
    <div class="mb-3">
      <label for="email" class="form-label">Alamat Email</label>
      <input type="email" class="form-control" id="email" placeholder="nama@email.com" autocomplete="email">
    </div>
    
    <!-- Error message yang jelas -->
    <div class="alert alert-danger" role="alert">
      Email yang Anda masukkan tidak valid. Silakan coba lagi.
    </div>
    
    <!-- Skip link untuk navigasi keyboard -->
    <a href="#main-content" class="visually-hidden-focusable">Langsung ke konten utama</a>
  </div>
</body>
</html>
```

## Poin Penting
- a11y adalah singkatan dari "accessibility" dengan 11 huruf di tengah
- Standar aksesibilitas web diatur dalam WCAG
- Bootstrap menyediakan fondasi aksesibilitas tetapi perlu pengaturan manual
