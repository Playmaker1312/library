# Cara melakukan audit aksesibilitas menggunakan tools seperti axe atau WAVE

## Analogi: Perpustakaan Digital

Setelah membangun perpustakaan digital, petugas melakukan inspeksi menyeluruh: memeriksa apakah rambu jelas, pintu cukup lebar, dan semua fitur bisa diakses. Tools audit aksesibilitas seperti axe dan WAVE adalah alat inspeksi yang memeriksa halaman web Anda untuk masalah aksesibilitas.

## Penjelasan Detail

axe DevTools (dari Deque) dan WAVE (dari WebAIM) adalah ekstensi browser yang mengaudit halaman web untuk masalah aksesibilitas. axe mendeteksi issue berdasarkan WCAG dan memberikan rekomendasi perbaikan. WAVE menampilkan overlay visual dengan ikon untuk setiap issue. Jalankan audit pada halaman Bootstrap Anda untuk memeriksa: kontras warna, label form, heading structure, ARIA attributes, focus order, dan alt text. Target: nol error kritis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Audit Aksesibilitas</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <!-- Halaman dengan struktur yang baik untuk audit -->
  <header>
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark" aria-label="Navigasi utama">
      <div class="container">
        <a class="navbar-brand" href="#">A11y Audit</a>
      </div>
    </nav>
  </header>

  <main class="container mt-4">
    <h1>Halaman untuk Audit Aksesibilitas</h1>
    
    <section aria-labelledby="formSection">
      <h2 id="formSection">Formulir Pemesanan</h2>
      <form>
        <div class="mb-3">
          <label for="nama" class="form-label">Nama</label>
          <input type="text" class="form-control" id="nama" required autocomplete="name">
        </div>
        <div class="mb-3">
          <label for="qty" class="form-label">Jumlah</label>
          <input type="number" class="form-control" id="qty" min="1" max="10" value="1">
        </div>
        <button type="submit" class="btn btn-primary">Pesan</button>
      </form>
    </section>

    <section aria-labelledby="gallerySection" class="mt-4">
      <h2 id="gallerySection">Galeri</h2>
      <div class="row">
        <div class="col-4">
          <img src="https://via.placeholder.com/300" class="img-fluid" alt="Sampul buku fiksi">
        </div>
        <div class="col-4">
          <img src="https://via.placeholder.com/300" class="img-fluid" alt="Sampul buku non-fiksi">
        </div>
      </div>
    </section>
  </main>

  <footer class="bg-light text-center py-3 mt-4">
    <small>&copy; 2026 Audit Page</small>
  </footer>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

  <!-- Programmatic audit dengan axe -->
  <script>
    if (window.__AXE_RUN) {
      axe.run().then(function(results) {
        console.log('Axe audit results:', results);
      });
    }
  </script>
</body>
</html>
```

```bash
# Audit aksesibilitas dengan axe-core via CLI
npx axe http://localhost:3000 --save report.json
```

## Poin Penting
- Gunakan axe DevTools atau WAVE untuk audit aksesibilitas otomatis
- Targetkan nol error kritis di semua halaman Bootstrap
- Audit harus mencakup kontras, label, heading, ARIA, dan focus order
