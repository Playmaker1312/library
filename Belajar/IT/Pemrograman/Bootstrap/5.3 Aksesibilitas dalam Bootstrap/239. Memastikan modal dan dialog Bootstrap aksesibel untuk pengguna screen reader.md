# Memastikan modal dan dialog Bootstrap aksesibel untuk pengguna screen reader

## Analogi: Perpustakaan Digital

Ketika perpustakaan digital menampilkan dialog konfirmasi "Apakah Anda yakin ingin menghapus buku ini?", pengguna dengan screen reader harus segera tahu bahwa dialog sedang terbuka, apa isinya, dan tombol apa yang tersedia. Fokus keyboard juga harus terperangkap di dalam dialog hingga ditutup.

## Penjelasan Detail

Bootstrap Modal sudah memiliki aksesibilitas bawaan: `role="dialog"`, `aria-modal="true"`, `aria-labelledby` merujuk ke judul modal, fokus terperangkap di dalam modal, dan menekan Escape menutup modal. Untuk aksesibilitas maksimal: pastikan modal memiliki judul dengan `aria-labelledby`, gunakan `aria-describedby` untuk deskripsi, kelola fokus dengan benar saat modal terbuka/tutup, dan jangan gunakan modal untuk informasi kritis yang memblokir akses.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Accessible Modal</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Modal Aksesibel</h1>
    <button type="button" class="btn btn-primary" data-bs-toggle="modal" 
            data-bs-target="#bookModal">
      Detail Buku
    </button>
  </div>

  <!-- Modal aksesibel -->
  <div class="modal fade" id="bookModal" tabindex="-1" 
       aria-labelledby="bookModalLabel" aria-describedby="bookModalDesc" aria-hidden="true">
    <div class="modal-dialog modal-dialog-centered">
      <div class="modal-content">
        <div class="modal-header">
          <h5 class="modal-title" id="bookModalLabel">Judul Buku: Bootstrap 5</h5>
          <button type="button" class="btn-close" data-bs-dismiss="modal" 
                  aria-label="Tutup dialog detail buku"></button>
        </div>
        <div class="modal-body" id="bookModalDesc">
          <p><strong>Penulis:</strong> Mark Otto</p>
          <p><strong>Tahun:</strong> 2021</p>
          <p><strong>Deskripsi:</strong> Buku ini membahas framework front-end Bootstrap 5 secara komprehensif.</p>
        </div>
        <div class="modal-footer">
          <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Tutup</button>
          <button type="button" class="btn btn-primary" id="pinjamBtn">Pinjam Buku</button>
        </div>
      </div>
    </div>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  <script>
    // Fokus management kustom
    document.getElementById('bookModal').addEventListener('shown.bs.modal', function() {
      document.getElementById('pinjamBtn').focus();
    });
  </script>
</body>
</html>
```

## Poin Penting
- Modal harus memiliki `aria-labelledby` yang merujuk ke judul modal
- Gunakan `aria-describedby` untuk deskripsi tambahan
- Bootstrap trap fokus di dalam modal secara otomatis
