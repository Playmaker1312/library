# Memahami role attribute dan penggunaannya bersama Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memberi tanda pada setiap area: "ini adalah navigasi", "ini adalah konten utama", "ini adalah dialog pencarian". Tanda ini membantu pengunjung, terutama yang menggunakan screen reader, memahami struktur halaman. `role` attribute adalah tanda tersebut dalam HTML.

## Penjelasan Detail

Atribut `role` mendefinisikan tujuan elemen bagi teknologi assistif. Contoh: `role="navigation"` untuk nav, `role="main"` untuk konten utama, `role="dialog"` untuk modal, `role="alert"` untuk pesan error. Bootstrap sudah menyertakan role yang sesuai untuk komponennya: `role="alert"` di alert, `role="dialog"` di modal, `role="tablist"` di nav tabs, dll. Gunakan semantic HTML5 (`<nav>`, `<main>`, `<dialog>`) sebagai alternatif untuk mengurangi kebutuhan role eksplisit.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Role Attributes</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <!-- Semantic HTML dengan role -->
  <nav class="navbar navbar-dark bg-dark" role="navigation" aria-label="Navigasi utama">
    <div class="container">
      <a class="navbar-brand" href="#">Library</a>
    </div>
  </nav>

  <main role="main" class="container mt-4">
    <h1>Contoh Role Attributes</h1>

    <!-- Alert dengan role -->
    <div class="alert alert-success" role="alert">
      Buku berhasil ditambahkan ke daftar bacaan!
    </div>

    <!-- Tab panel dengan role -->
    <ul class="nav nav-tabs" role="tablist">
      <li class="nav-item" role="presentation">
        <button class="nav-link active" id="tab1-tab" data-bs-toggle="tab" 
                data-bs-target="#tab1" type="button" role="tab" 
                aria-controls="tab1" aria-selected="true">Fiksi</button>
      </li>
      <li class="nav-item" role="presentation">
        <button class="nav-link" id="tab2-tab" data-bs-toggle="tab" 
                data-bs-target="#tab2" type="button" role="tab" 
                aria-controls="tab2" aria-selected="false">Non-Fiksi</button>
      </li>
    </ul>
    <div class="tab-content">
      <div class="tab-pane active" id="tab1" role="tabpanel" aria-labelledby="tab1-tab">
        Daftar buku fiksi.
      </div>
      <div class="tab-pane" id="tab2" role="tabpanel" aria-labelledby="tab2-tab">
        Daftar buku non-fiksi.
      </div>
    </div>

    <!-- Progress bar dengan role -->
    <div class="progress mt-3" role="progressbar" aria-label="Progres" aria-valuenow="50" aria-valuemin="0" aria-valuemax="100">
      <div class="progress-bar" style="width: 50%">50%</div>
    </div>
  </main>

  <footer role="contentinfo" class="bg-light text-center py-3">
    <small>&copy; 2026 Perpustakaan Digital</small>
  </footer>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- `role` memberi tahu screen reader tentang fungsi elemen
- Bootstrap sudah menyertakan role yang sesuai untuk komponennya
- Gunakan semantic HTML5 sebagai alternatif role eksplisit
