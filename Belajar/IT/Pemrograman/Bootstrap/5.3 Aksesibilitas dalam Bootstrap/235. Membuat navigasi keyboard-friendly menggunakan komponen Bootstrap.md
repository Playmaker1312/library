# Membuat navigasi keyboard-friendly menggunakan komponen Bootstrap

## Analogi: Perpustakaan Digital

Beberapa pengunjung perpustakaan digital tidak bisa menggunakan mouse dan hanya mengandalkan keyboard (tombol Tab, Enter, dan panah). Perpustakaan harus memastikan semua fitur bisa diakses hanya dengan keyboard: memilih buku dengan Tab, membuka detail dengan Enter, dan menavigasi menu dengan panah.

## Penjelasan Detail

Navigasi keyboard-friendly (keyboard accessibility) memungkinkan pengguna menavigasi halaman menggunakan keyboard saja. Bootstrap sudah mendukung ini secara default untuk komponen interaktif: `tabindex`, `role`, `aria-*`, dan event keyboard untuk dropdown, modal, carousel, dan tab. Pastikan: semua elemen interaktif dapat di-focus dengan Tab, fokus terlihat jelas (`:focus-visible`), urutan tab logis, tidak ada keyboard trap, dan semua fungsi mouse juga tersedia via keyboard.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Keyboard Navigation</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    /* Fokus style yang jelas */
    :focus-visible {
      outline: 3px solid #0d6efd !important;
      outline-offset: 2px;
    }
  </style>
</head>
<body>
  <!-- Skip link untuk keyboard -->
  <a href="#main" class="visually-hidden-focusable bg-primary text-white p-2">Langsung ke konten utama</a>

  <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
      <a class="navbar-brand" href="#">Library</a>
      <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarNav" 
              aria-controls="navbarNav" aria-expanded="false" aria-label="Toggle navigation">
        <span class="navbar-toggler-icon"></span>
      </button>
      <div class="collapse navbar-collapse" id="navbarNav">
        <ul class="navbar-nav ms-auto">
          <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
          <li class="nav-item dropdown">
            <a class="nav-link dropdown-toggle" href="#" id="dropdownMenu" role="button" 
               data-bs-toggle="dropdown" aria-expanded="false">Kategori</a>
            <ul class="dropdown-menu" aria-labelledby="dropdownMenu">
              <li><a class="dropdown-item" href="#">Fiksi</a></li>
              <li><a class="dropdown-item" href="#">Non-Fiksi</a></li>
            </ul>
          </li>
        </ul>
      </div>
    </div>
  </nav>

  <main id="main" class="container mt-4">
    <h1>Navigasi Keyboard</h1>
    <p>Tekan Tab untuk navigasi, Enter untuk aktivasi, Panah untuk dropdown.</p>
    <button class="btn btn-primary">Tombol 1</button>
    <button class="btn btn-secondary">Tombol 2</button>
  </main>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Pastikan semua elemen interaktif dapat di-focus (Tab)
- Bootstrap sudah mendukung keyboard navigation untuk komponennya
- Sediakan skip link untuk lompat ke konten utama
