# Memahami bagaimana Bootstrap menangani aksesibilitas secara default

## Analogi: Perpustakaan Digital

Perpustakaan digital sudah dirancang dengan fitur aksesibilitas dasar: pintu yang cukup lebar untuk kursi roda, rambu yang jelas, dan pencahayaan yang baik. Namun, beberapa pengguna mungkin masih memerlukan penyesuaian tambahan seperti kursi baca khusus atau teks besar.

## Penjelasan Detail

Bootstrap memiliki aksesibilitas bawaan yang baik: menggunakan semantic HTML5, mendukung `role` attributes, warna dengan kontras yang memadai, fokus styles yang jelas, dukungan `prefers-reduced-motion`, dan `visually-hidden` class. Bootstrap juga mengikuti standar WAI-ARIA untuk komponen interaktif seperti modal, tab, dan accordion. Namun, Bootstrap tidak sepenuhnya otomatis; pengembang tetap harus menggunakan komponen dengan benar, menyediakan label, dan menguji dengan screen reader.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bootstrap Accessibility</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Fitur Aksesibilitas Bawaan Bootstrap</h1>

    <!-- Accordion dengan ARIA attributes -->
    <div class="accordion" id="accordionExample">
      <div class="accordion-item">
        <h2 class="accordion-header">
          <button class="accordion-button" type="button" data-bs-toggle="collapse" 
                  data-bs-target="#collapseOne" aria-expanded="true" aria-controls="collapseOne">
            Accordion Item #1
          </button>
        </h2>
        <div id="collapseOne" class="accordion-collapse collapse show" data-bs-parent="#accordionExample">
          <div class="accordion-body">Konten akordion ini sudah memiliki ARIA attributes.</div>
        </div>
      </div>
    </div>

    <!-- Alert dengan role -->
    <div class="alert alert-warning alert-dismissible fade show" role="alert">
      <strong>Perhatian!</strong> Ini adalah alert yang aksesibel.
      <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
    </div>

    <!-- Close button dengan aria-label -->
    <button type="button" class="btn-close" aria-label="Tutup dialog"></button>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Bootstrap menggunakan semantic HTML dan role attributes secara default
- Komponen interaktif dilengkapi ARIA attributes bawaan
- Gunakan komponen Bootstrap sesuai dokumentasi untuk aksesibilitas optimal
