# Menggunakan atribut aria-label, aria-labelledby, dan aria-describedby dengan Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital memberi label pada setiap rak buku agar pengunjung tahu isinya. Untuk pengguna dengan keterbatasan penglihatan, label ini harus dibacakan oleh screen reader. `aria-label` seperti label tempel di rak, `aria-labelledby` seperti papan petunjuk yang merujuk ke tanda lain, dan `aria-describedby` seperti deskripsi tambahan di bawah rak.

## Penjelasan Detail

Atribut ARIA (Accessible Rich Internet Applications) memberikan informasi tambahan ke screen reader. `aria-label` memberikan label langsung ke elemen. `aria-labelledby` merujuk ke ID elemen lain yang berisi label (berguna untuk menghindari duplikasi teks). `aria-describedby` memberikan deskripsi tambahan. Dalam Bootstrap, gunakan `aria-label` pada tombol tanpa teks (icon-only), `aria-labelledby` pada modal atau dialog, dan `aria-describedby` pada input form dengan teks bantuan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>ARIA Attributes</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Penggunaan ARIA dengan Bootstrap</h1>

    <!-- aria-label pada icon-only button -->
    <button type="button" class="btn btn-primary" aria-label="Cari buku">
      🔍
    </button>

    <!-- aria-labelledby pada modal -->
    <div class="modal fade" id="infoModal" tabindex="-1" aria-labelledby="modalLabel" aria-hidden="true">
      <div class="modal-dialog">
        <div class="modal-content">
          <div class="modal-header">
            <h5 class="modal-title" id="modalLabel">Informasi Buku</h5>
            <button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="Tutup"></button>
          </div>
          <div class="modal-body">
            <p>Detail buku akan ditampilkan di sini.</p>
          </div>
        </div>
      </div>
    </div>

    <!-- aria-describedby pada input -->
    <div class="mb-3">
      <label for="password" class="form-label">Password</label>
      <input type="password" class="form-control" id="password" 
             aria-describedby="passwordHelp" autocomplete="current-password">
      <div id="passwordHelp" class="form-text">Password minimal 8 karakter.</div>
    </div>

    <!-- Tombol untuk membuka modal -->
    <button type="button" class="btn btn-info" data-bs-toggle="modal" data-bs-target="#infoModal">
      Info Buku
    </button>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan `aria-label` untuk tombol icon-only tanpa teks
- Gunakan `aria-labelledby` untuk modal dan dialog
- Gunakan `aria-describedby` untuk input form dengan teks bantuan
