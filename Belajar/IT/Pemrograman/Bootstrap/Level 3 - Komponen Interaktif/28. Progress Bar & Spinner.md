# Progress Bar & Spinner

## Penjelasan
**Progress Bar** dan **Spinner** adalah komponen Bootstrap untuk menunjukkan status pemuatan atau kemajuan suatu proses.

**Progress Bar** menampilkan persentase penyelesaian secara visual dalam bentuk batang horizontal yang terisi.

**Spinner** adalah indikator pemuatan berbentuk lingkaran berputar.

**Analogi: Meteran air / tangki terisi** — Bayangkan tangki air di rumah Anda. Saat air mengisi tangki, permukaan air naik secara bertahap — itulah progress bar. Sedangkan spinner seperti kincir angin kecil yang berputar saat air sedang dipompa, menandakan proses sedang berjalan tanpa tahu kapan selesai.

---

## Fungsi
- Memberi umpan balik visual tentang status proses
- Menenangkan pengguna bahwa halaman sedang memproses sesuatu
- Menunjukkan perkiraan sisa waktu (pada progress bar)
- Progress Bar untuk proses dengan durasi diketahui
- Spinner untuk proses yang durasinya tidak pasti

---

## Cara Pengimplementasian

### Progress Bar Dasar
```html
<div class="progress" role="progressbar" aria-valuenow="60" aria-valuemin="0" aria-valuemax="100">
  <div class="progress-bar" style="width: 60%;">60%</div>
</div>
```

### Tinggi Kustom
```html
<div class="progress" style="height: 30px;">
  <div class="progress-bar" style="width: 50%;">50%</div>
</div>
```

### Striped & Animated
```html
<div class="progress">
  <div class="progress-bar progress-bar-striped progress-bar-animated" style="width: 75%;">75%</div>
</div>
```

### Warna Varian
```html
<div class="progress">
  <div class="progress-bar bg-success" style="width: 40%;">Sukses</div>
  <div class="progress-bar bg-warning" style="width: 30%;">Peringatan</div>
  <div class="progress-bar bg-danger" style="width: 20%;">Bahaya</div>
</div>
```

### Spinner Border
```html
<div class="spinner-border" role="status">
  <span class="visually-hidden">Memuat...</span>
</div>

<!-- Warna -->
<div class="spinner-border text-primary"></div>
<div class="spinner-border text-success"></div>

<!-- Ukuran -->
<div class="spinner-border spinner-border-sm"></div>
```

### Spinner Grow
```html
<div class="spinner-grow" role="status">
  <span class="visually-hidden">Memuat...</span>
</div>

<div class="spinner-grow text-danger"></div>
<div class="spinner-grow spinner-grow-sm"></div>
```

## Analogi — Meteran Air / Tangki Terisi
| Komponen Bootstrap | Analogi Rumah |
|---|---|
| progress | Tangki air |
| progress-bar | Volume air di dalam tangki |
| width (style) | Tinggi permukaan air |
| aria-valuenow | Indikator angka di meteran |
| striped | Garis gelombang air |
| animated | Air bergelombang (pompa aktif) |
| spinner-border | Kincir angin di atas tangki |
| spinner-grow | Gelembung air yang membesar |
| bg-success / bg-danger | Warna air (hijau jernih / merah keruh) |

## Dipakai untuk apa
- **Progress Bar:** Upload file, pengisian form bertahap, unduhan, loading persentase
- **Spinner:** Loading halaman, menunggu respons API, proses login, pencarian data

---

## Kesalahan umum yang sering terjadi
1. **Lupa `role="progressbar"` dan atribut `aria-*`** — aksesibilitas hilang untuk screen reader.
2. **Nilai `aria-valuenow` tidak konsisten dengan `style="width"`** — misal width 50% tapi aria-valuenow 60.
3. **Progress bar tanpa `.progress` pembungkus** — styling tidak akan berfungsi tanpa class `progress`.
4. **Spinner tanpa `role="status"` dan `visually-hidden`** — pengguna screen reader tidak mendapat notifikasi.
5. **Spinner-border dan spinner-grow tidak dibedakan penggunaannya** — keduanya hanya berbeda animasi (rotasi vs membesar), pilih salah satu yang sesuai.

---

## Koneksi dengan materi sebelumnya
- **Warna & Background** (Level 1) → varian warna (bg-success, text-primary) digunakan di progress bar dan spinner
- **Utility** (Level 2) → `visually-hidden` untuk aksesibilitas
- **Button** (Level 2) → spinner sering dikombinasikan dengan button saat loading

## Soal Latihan & Jawaban

### Soal 1
Buat progress bar dengan lebar 80%, warna hijau (`bg-success`), dan memiliki efek strip bergerak (`progress-bar-striped progress-bar-animated`).

**Jawaban:**
```html
<div class="progress" role="progressbar" aria-valuenow="80" aria-valuemin="0" aria-valuemax="100">
  <div class="progress-bar progress-bar-striped progress-bar-animated bg-success" style="width: 80%;">80%</div>
</div>
```

### Soal 2
Buat spinner dengan tipe `spinner-border` berwarna biru (`text-primary`) berukuran kecil (`spinner-border-sm`).

**Jawaban:**
```html
<div class="spinner-border spinner-border-sm text-primary" role="status">
  <span class="visually-hidden">Memuat...</span>
</div>
```

### Soal 3
Apa perbedaan antara `progress-bar-striped` dan `progress-bar-animated`? Bisakah keduanya digunakan bersamaan?

**Jawaban:** `progress-bar-striped` menambahkan garis-garis diagonal (stripe) pada progress bar. `progress-bar-animated` membuat stripe tersebut bergerak dari kanan ke kiri. Keduanya bisa digunakan bersamaan — tambahkan kedua class tersebut pada elemen `progress-bar` untuk mendapatkan efek stripe yang bergerak.
