# Tab

## Penjelasan
Tab adalah komponen navigasi Bootstrap yang memungkinkan pengguna berpindah antar konten tanpa memuat ulang halaman. Tab disusun secara horizontal (atau vertikal dengan `nav-pills`) dan setiap tab menampilkan panel konten yang sesuai.

**Analogi: Rak buku dengan sekat/kategori** — Sebuah rak buku besar yang memiliki beberapa sekat: "Fiksi", "Non-Fiksi", "Ensiklopedia". Saat Anda memilih sekat "Fiksi", hanya buku-buku fiksi yang terlihat. Sekat lainnya tersembunyi sampai Anda memilihnya.

---

## Fungsi
- Mengorganisir konten dalam kategori yang berbeda
- Menghemat ruang halaman dengan menyembunyikan konten yang tidak aktif
- Memberikan navigasi yang cepat dan intuitif antar bagian

---

## Cara Pengimplementasian

### Nav Tabs
```html
<!-- Navigasi Tab -->
<ul class="nav nav-tabs" id="tabSaya" role="tablist">
  <li class="nav-item" role="presentation">
    <button class="nav-link active" id="home-tab" data-bs-toggle="tab"
            data-bs-target="#home" type="button" role="tab"
            aria-controls="home" aria-selected="true">
      Home
    </button>
  </li>
  <li class="nav-item" role="presentation">
    <button class="nav-link" id="profil-tab" data-bs-toggle="tab"
            data-bs-target="#profil" type="button" role="tab"
            aria-controls="profil" aria-selected="false">
      Profil
    </button>
  </li>
</ul>

<!-- Konten Tab -->
<div class="tab-content" id="tabSayaContent">
  <div class="tab-pane fade show active" id="home" role="tabpanel" aria-labelledby="home-tab">
    Konten Home
  </div>
  <div class="tab-pane fade" id="profil" role="tabpanel" aria-labelledby="profil-tab">
    Konten Profil
  </div>
</div>
```

### Nav Pills (gaya tombol)
```html
<ul class="nav nav-pills">
  <li class="nav-item">
    <button class="nav-link active" data-bs-toggle="pill" data-bs-target="#tabPill1">Pill 1</button>
  </li>
  <li class="nav-item">
    <button class="nav-link" data-bs-toggle="pill" data-bs-target="#tabPill2">Pill 2</button>
  </li>
</ul>
```

### Role Atribut (Aksesibilitas)
- `role="tablist"` — pembungkus navigasi tab
- `role="tab"` — setiap tombol tab
- `role="tabpanel"` — panel konten
- `aria-controls="idPanel"` — menghubungkan tombol ke panel
- `aria-selected="true/false"` — status terpilih
- `aria-labelledby="idTab"` — panel merujuk kembali ke tab

## Analogi — Rak Buku dengan Sekat/Kategori
| Komponen Bootstrap | Analogi Rumah |
|---|---|
| nav-tabs / nav-pills | Label sekat pada rak buku |
| nav-item | Satu sekat rak |
| nav-link (active) | Sekat yang sedang dipilih |
| tab-content | Isi seluruh rak buku |
| tab-pane | Isi satu kategori/sekat |
| fade | Efek buku tersusun rapi saat dipindah |

---

## Dipakai untuk apa
- Halaman profil dengan tab "Bio", "Foto", "Pengaturan"
 Dashboard dengan tab "Ringkasan", "Laporan", "Grafik"
- Dokumentasi API dengan tab "Request", "Response", "Contoh"
- Halaman produk dengan tab "Deskripsi", "Ulasan", "Saran"

---

## Kesalahan umum yang sering terjadi
1. **Lupa mencocokkan `data-bs-target` dengan `id` panel** — tab tidak menampilkan konten apapun.
2. **Tidak menambahkan class `active` pada salah satu panel** — tidak ada konten yang terlihat saat halaman dimuat.
3. **`tab-pane` tidak dibungkus dalam `tab-content`** — fungsi tab tidak berjalan.
4. **Role atribut tidak digunakan** — aksesibilitas berkurang, terutama untuk screen reader.
5. **Menggunakan `<a>` tanpa `href` yang benar** — lebih baik gunakan `<button>` untuk menghindari lompatan halaman.

---

## Koneksi dengan materi sebelumnya
- **Navbar** (Level 2) → tab adalah bentuk sederhana dari navigasi
- **Button** (Level 2) → nav-link adalah tombol yang distilasi sebagai tab
- **Fade** (Level 1) → utility fade memberikan efek transisi

## Soal Latihan & Jawaban

### Soal 1
Buat navigasi tab dengan 3 tab: "HTML", "CSS", "JavaScript". Tab "CSS" aktif secara default.

**Jawaban:**
```html
<ul class="nav nav-tabs" role="tablist">
  <li class="nav-item" role="presentation">
    <button class="nav-link" data-bs-toggle="tab" data-bs-target="#html"
            type="button" role="tab">HTML</button>
  </li>
  <li class="nav-item" role="presentation">
    <button class="nav-link active" data-bs-toggle="tab" data-bs-target="#css"
            type="button" role="tab">CSS</button>
  </li>
  <li class="nav-item" role="presentation">
    <button class="nav-link" data-bs-toggle="tab" data-bs-target="#js"
            type="button" role="tab">JavaScript</button>
  </li>
</ul>

<div class="tab-content">
  <div class="tab-pane fade" id="html" role="tabpanel">Konten HTML</div>
  <div class="tab-pane fade show active" id="css" role="tabpanel">Konten CSS</div>
  <div class="tab-pane fade" id="js" role="tabpanel">Konten JavaScript</div>
</div>
```

### Soal 2
Apa perbedaan utama antara `nav-tabs` dan `nav-pills`?

**Jawaban:** `nav-tabs` menampilkan tab seperti folder dengan garis bawah (border-bottom), sedangkan `nav-pills` menampilkan tab seperti tombol pil (berbentuk rounded). Keduanya berfungsi sama, hanya berbeda secara visual. `nav-pills` juga bisa digunakan secara vertikal dengan menambahkan class `flex-column`.

### Soal 3
Sebutkan 3 atribut `role` yang digunakan dalam komponen tab dan jelaskan fungsinya.

**Jawaban:**
1. `role="tablist"` — Menandai elemen sebagai wadah untuk daftar tab.
2. `role="tab"` — Menandai elemen sebagai tab yang bisa diklik.
3. `role="tabpanel"` — Menandai elemen sebagai panel konten milik sebuah tab.
