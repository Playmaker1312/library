# Bootstrap JavaScript API

## Penjelasan

Bootstrap JavaScript API menyediakan akses programatik ke semua komponen Bootstrap. Alih-alih hanya mengandalkan atribut `data-bs-*`, kamu bisa membuat, mengontrol, dan mendengarkan event dari komponen secara langsung melalui JavaScript.

## Fungsi

- Membuat instance komponen secara dinamis (modal, toast, scrollspy, dll)
- Mengontrol komponen dengan method seperti `.show()`, `.hide()`, `.toggle()`
- Menangani event lifecycle komponen (`show.bs.modal`, `hidden.bs.modal`, dll)
- Mendapatkan instance yang sudah ada dengan `getOrCreateInstance()` untuk menghindari duplikasi
- Mengintegrasikan komponen Bootstrap dengan logika aplikasi yang kompleks

## Cara Pengimplementasian

### 1. Bootstrap Modal via JavaScript

```javascript
// Membuat instance Modal
const modalEl = document.getElementById('exampleModal');
const modal = new bootstrap.Modal(modalEl, {
  backdrop: 'static',    // tidak bisa tutup dengan klik backdrop
  keyboard: false        // tidak bisa tutup dengan Escape
});

// Method
modal.show();       // buka modal
modal.hide();       // tutup modal
modal.toggle();     // toggle modal
modal.dispose();    // hancurkan modal

// Tutup otomatis setelah 3 detik
modal.show();
setTimeout(() => modal.hide(), 3000);
```

```html
<!-- Modal HTML -->
<div class="modal fade" id="exampleModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Modal via JS</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">
        <p>Modal ini dikontrol oleh JavaScript API.</p>
      </div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Tutup</button>
      </div>
    </div>
  </div>
</div>

<button id="openModalBtn" class="btn btn-primary">Buka Modal</button>

<script>
  document.getElementById('openModalBtn').addEventListener('click', () => {
    const modalEl = document.getElementById('exampleModal');
    const modal = new bootstrap.Modal(modalEl);
    modal.show();
  });
</script>
```

### 2. Toast dengan Delay dan Autohide

```javascript
// Toast dengan opsi kustom
const toastEl = document.getElementById('liveToast');
const toast = new bootstrap.Toast(toastEl, {
  autohide: true,       // otomatis hilang
  delay: 5000           // hilang setelah 5 detik (default 5000)
});

toast.show();

// Method lain
toast.hide();
toast.dispose();

// Toast tanpa autohide (harus ditutup manual)
const toastStatic = new bootstrap.Toast(toastEl, {
  autohide: false
});
toastStatic.show();

// Membuat toast secara dinamis
function showToast(message, type = 'success') {
  const toastWrapper = document.getElementById('toastContainer');
  const toastHtml = `
    <div class="toast align-items-center text-bg-${type} border-0" role="alert">
      <div class="d-flex">
        <div class="toast-body">${message}</div>
        <button type="button" class="btn-close btn-close-white me-2 m-auto"
                data-bs-dismiss="toast"></button>
      </div>
    </div>
  `;

  toastWrapper.insertAdjacentHTML('beforeend', toastHtml);
  const newToast = toastWrapper.lastElementChild;
  const bsToast = new bootstrap.Toast(newToast);
  bsToast.show();

  // Hapus dari DOM setelah tersembunyi
  newToast.addEventListener('hidden.bs.toast', () => newToast.remove());
}
```

```html
<!-- Container toast -->
<div id="toastContainer" class="toast-container position-fixed bottom-0 end-0 p-3">
  <!-- Toast akan ditambahkan di sini -->
</div>

<!-- Toast statis -->
<div id="liveToast" class="toast" role="alert" aria-live="assertive" aria-atomic="true">
  <div class="toast-header">
    <strong class="me-auto">Notifikasi</strong>
    <small>baru saja</small>
    <button type="button" class="btn-close" data-bs-dismiss="toast"></button>
  </div>
  <div class="toast-body">Halo! Ini adalah toast notifikasi.</div>
</div>

<button onclick="showToast('Data berhasil disimpan!', 'success')" class="btn btn-success">
  Sukses
</button>
<button onclick="showToast('Terjadi kesalahan!', 'danger')" class="btn btn-danger">
  Error
</button>
```

### 3. getOrCreateInstance()

```javascript
// getOrCreateInstance() mencegah duplikasi instance
// Alih-alih new bootstrap.Modal(el) setiap kali, gunakan:

const modalEl = document.getElementById('exampleModal');

// Tombol 1
document.getElementById('btn1').addEventListener('click', () => {
  const modal = bootstrap.Modal.getOrCreateInstance(modalEl);
  modal.show();
});

// Tombol 2 — tetap menggunakan instance yang sama
document.getElementById('btn2').addEventListener('click', () => {
  const modal = bootstrap.Modal.getOrCreateInstance(modalEl);
  modal.show();
});

// Berguna juga untuk Offcanvas, Toast, Tooltip, dll.
const toast = bootstrap.Toast.getOrCreateInstance(toastEl);
const offcanvas = bootstrap.Offcanvas.getOrCreateInstance(offcanvasEl);
```

### 4. Modal Events

```javascript
const modalEl = document.getElementById('exampleModal');

// show.bs.modal — dipicu sebelum modal ditampilkan
modalEl.addEventListener('show.bs.modal', (event) => {
  console.log('Modal akan ditampilkan', event);
  // Bisa mencegah dengan event.preventDefault() (jika didukung)
});

// shown.bs.modal — dipicu setelah modal selesai ditampilkan
modalEl.addEventListener('shown.bs.modal', () => {
  console.log('Modal sudah ditampilkan');
  // Cocok untuk fokus input
  document.getElementById('namaInput').focus();
});

// hide.bs.modal — dipicu sebelum modal ditutup
modalEl.addEventListener('hide.bs.modal', (event) => {
  console.log('Modal akan ditutup');
  // Validasi: jika form belum diisi, cegah penutupan
  const form = document.getElementById('myForm');
  if (!form.checkValidity()) {
    event.preventDefault();  // Cegah penutupan
  }
});

// hidden.bs.modal — dipicu setelah modal benar-benar tertutup
modalEl.addEventListener('hidden.bs.modal', () => {
  console.log('Modal sudah tertutup');
  // Reset form, kosongkan state, dll.
  document.getElementById('myForm').reset();
});

// hidePrevented.bs.modal — dipicu jika penutupan dicegah
modalEl.addEventListener('hidePrevented.bs.modal', () => {
  console.log('Penutupan modal dicegah');
});
```

### 5. Scrollspy via JavaScript

```javascript
// Scrollspy untuk navbar yang aktif otomatis saat scroll
const scrollSpyEl = document.getElementById('contentWrapper');
const scrollSpy = new bootstrap.ScrollSpy(scrollSpyEl, {
  target: '#navbarSpy',     // target navbar
  offset: 70                // offset dari atas (px)
});

// Method refresh — panggil setelah konten dinamis ditambahkan
scrollSpy.refresh();

// Event
scrollSpyEl.addEventListener('activate.bs.scrollspy', (event) => {
  console.log('Menu aktif berubah:', event.relatedTarget);
});
```

### 6. Programmatic Control Lengkap

```javascript
// Contoh aplikasi: Form yang muncul di modal, lalu toast konfirmasi
const formModalEl = document.getElementById('formModal');
const formModal = new bootstrap.Modal(formModalEl);

document.getElementById('btnBukaForm').addEventListener('click', () => {
  formModal.show();
});

document.getElementById('formSimpan').addEventListener('submit', (e) => {
  e.preventDefault();

  // Simpan data...
  formModal.hide();

  // Tampilkan toast sukses
  const toastEl = document.getElementById('suksesToast');
  const toast = new bootstrap.Toast(toastEl, { delay: 3000 });
  toast.show();
});

// Gabungan event modal + toast
formModalEl.addEventListener('hidden.bs.modal', () => {
  console.log('Form modal tertutup, siap untuk interaksi berikutnya');
});
```

## Analogi

**Membangun Rumah:**

Bootstrap JavaScript API seperti **remote control universal untuk semua perangkat rumah**. Setiap komponen Bootstrap adalah perangkat rumah yang punya remote masing-masing:

- `new bootstrap.Modal()` seperti **remote kontrol untuk pintu garasi** — kamu bisa buka (`show()`), tutup (`hide()`), dan tahu persis kapan pintu mulai bergerak (`show.bs.modal`) atau sudah tertutup rapat (`hidden.bs.modal`).

- `new bootstrap.Toast()` seperti **bel pintu otomatis** — muncul (`show()`) dengan durasi tertentu (`delay`), lalu hilang sendiri (`autohide`). Kamu bisa atur belnya bunyi 5 detik atau sampai kamu sentuh tombol dismiss.

- `getOrCreateInstance()` seperti **satu remote untuk satu perangkat** — tidak perlu membeli remote baru setiap kali mau buka pintu. Ambil remote yang sudah ada dari dinding.

- Modal events (`show.bs.modal`, `hidden.bs.modal`) seperti **sensor pintu** yang memberitahu kamu: "pintu mulai terbuka", "pintu sudah terbuka penuh", "pintu mulai tertutup", "pintu sudah tertutup". Kamu bisa pasang logika di setiap momen — misal nyalakan lampu saat pintu terbuka.

- Scrollspy seperti **papan navigasi lift** yang otomatis menyala sesuai lantai yang kamu lewati. Saat kamu naik ke lantai 2, tombol lantai 2 di lift menyala (`activate.bs.scrollspy`).

## Dipakai untuk apa

- Membuka modal secara otomatis setelah login berhasil
- Toast notifikasi real-time (chat, upload, error handling)
- Navigasi scrollspy di halaman dokumentasi panjang
- Form yang divalidasi sebelum modal boleh ditutup
- Integrasi dengan framework JS (React, Vue) melalui API programatik
- Aplikasi SPA (Single Page Application) yang perlu kontrol penuh komponen
- Dashboard dengan notifikasi yang muncul dari aksi pengguna

## Kesalahan umum yang sering terjadi

1. **Lupa mengimpor `bootstrap.bundle.min.js` atau hanya mengimpor `bootstrap.min.js` tanpa popper** — Toast dan tooltip tidak berfungsi.

2. **Membuat instance baru setiap kali tanpa `getOrCreateInstance()`** — Terjadi duplikasi event listener dan memory leak.

3. **Event listener dipasang setelah instance dibuat** — Event `show.bs.modal` harus dipasang *sebelum* `.show()` dipanggil.

4. **Tidak menghapus komponen dari DOM setelah dispose** — Toast dinamis menumpuk di DOM, memperlambat halaman.

5. **Salah mengenali event name** — Nama event Bootstrap menggunakan format `show.bs.modal` (bukan `onShow` atau `bs:show`). Awalan `bs` adalah namespace.

6. **Mencoba mengakses `.show()` pada elemen yang tidak memiliki komponen Bootstrap** — Pastikan elemen memiliki class yang sesuai (`.modal`, `.toast`, dll).

## Koneksi dengan materi sebelumnya

JavaScript API adalah **puncak dari semua materi Bootstrap** yang sudah dipelajari. Modal (Level 3) dan Offcanvas (file 43) yang sebelumnya hanya menggunakan `data-bs-*` sekarang bisa dikontrol penuh dengan JavaScript. Dark Mode Toggle (file 41) juga bisa diintegrasikan — misal, modal yang muncul di dark mode punya tampilan gelap otomatis karena CSS variables yang sudah di-override (file 42). Scrollspy sendiri terkait dengan **Navbar & Navs** (Level 3) untuk navigasi halaman.
