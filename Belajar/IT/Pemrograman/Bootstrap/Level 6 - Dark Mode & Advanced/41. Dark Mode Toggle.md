# Dark Mode Toggle

## Penjelasan

Dark mode toggle adalah fitur untuk mengganti tema website antara terang (light) dan gelap (dark). Bootstrap 5.3+ mendukung dark mode native melalui atribut `data-bs-theme` yang bisa dipasang di elemen `<html>`.

## Fungsi

- Mengubah tampilan website dari light ke dark dan sebaliknya
- Menyimpan preferensi pengguna agar tidak hilang saat halaman di-refresh (localStorage)
- Mendeteksi preferensi sistem operasi pengguna (`prefers-color-scheme`)
- Memberikan kontrol aksesibilitas dan kenyamanan visual

## Cara Pengimplementasian

### 1. Struktur HTML dengan Toggle Button

```html
<!DOCTYPE html>
<html lang="id" data-bs-theme="light">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dark Mode Toggle</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="min-vh-100 d-flex align-items-center justify-content-center">

  <div class="container text-center">
    <h1 class="mb-4">Selamat Datang di Rumah</h1>

    <!-- Toggle Button -->
    <div class="d-flex justify-content-center mb-4">
      <button id="darkModeToggle" class="btn btn-outline-secondary rounded-pill px-4">
        <span id="toggleIcon">☀️</span>
        <span id="toggleText">Mode Terang</span>
      </button>
    </div>

    <!-- Utility classes dark/light -->
    <p class="d-dark-none">Teks ini hanya muncul di mode terang</p>
    <p class="d-light-none">Teks ini hanya muncul di mode gelap</p>

    <p class="lead">Rumah ini bisa berubah suasana dengan satu saklar!</p>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  <script src="script.js"></script>
</body>
</html>
```

### 2. JavaScript untuk Toggle, localStorage, dan Deteksi Sistem

```javascript
// script.js
const html = document.documentElement;
const toggleBtn = document.getElementById('darkModeToggle');
const toggleIcon = document.getElementById('toggleIcon');
const toggleText = document.getElementById('toggleText');

// Fungsi untuk mengupdate tampilan tombol
function updateUI(theme) {
  if (theme === 'dark') {
    toggleIcon.textContent = '🌙';
    toggleText.textContent = 'Mode Gelap';
  } else {
    toggleIcon.textContent = '☀️';
    toggleText.textContent = 'Mode Terang';
  }
}

// Cek preferensi tersimpan di localStorage
const savedTheme = localStorage.getItem('theme');

// Jika tidak ada, cek prefers-color-scheme
if (!savedTheme) {
  const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
  html.setAttribute('data-bs-theme', prefersDark ? 'dark' : 'light');
  updateUI(prefersDark ? 'dark' : 'light');
} else {
  html.setAttribute('data-bs-theme', savedTheme);
  updateUI(savedTheme);
}

// Event klik toggle
toggleBtn.addEventListener('click', () => {
  const currentTheme = html.getAttribute('data-bs-theme');
  const newTheme = currentTheme === 'dark' ? 'light' : 'dark';

  html.setAttribute('data-bs-theme', newTheme);
  localStorage.setItem('theme', newTheme);
  updateUI(newTheme);
});

// Dengarkan perubahan prefers-color-scheme (jika pengguna tidak override)
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', (e) => {
  if (!localStorage.getItem('theme')) {
    const newTheme = e.matches ? 'dark' : 'light';
    html.setAttribute('data-bs-theme', newTheme);
    updateUI(newTheme);
  }
});
```

### 3. Menambahkan Transisi Smooth via CSS

```css
/* style.css */
html {
  transition: background-color 0.3s ease, color 0.3s ease;
}

html[data-bs-theme="dark"] {
  background-color: #212529;
  color: #f8f9fa;
}
```

## Analogi

**Membangun Rumah:**

Dark mode toggle seperti **saklar lampu utama rumah**. Saat siang (light mode), semua jendela terbuka lebar, cahaya matahari masuk, rumah terang dan segar. Saat malam (dark mode), kamu cukup menekan satu saklar — semua lampu meredup, tirai tertutup, suasana menjadi hangat dan nyaman. `localStorage` adalah **memori rumah** yang mengingat apakah kamu terakhir kali mematikan lampu atau tidak, jadi saat kamu pulang lagi, suasana rumah tetap sama seperti yang kamu tinggalkan. `prefers-color-scheme` seperti **sensor cahaya otomatis** di luar rumah — jika hari mulai gelap, rumah otomatis beralih ke mode malam tanpa perlu kamu sentuh.

Utility `d-dark-none` dan `d-light-none` seperti **perabot yang hanya dipakai di waktu tertentu**: kipas angin hanya muncul saat siang (`d-light-none: sembunyikan saat gelap`), selimut hanya muncul saat malam (`d-dark-none: sembunyikan saat terang`).

## Dipakai untuk apa

- Website berita yang ingin memberikan kenyamanan membaca malam hari
- Dashboard admin yang digunakan di berbagai kondisi pencahayaan
- Aplikasi sosial media dengan fitur tema gelap
- Portofolio pribadi yang ingin tampil modern dan ramah pengguna
- Semua website yang ingin mengikuti preferensi sistem operasi pengguna

## Kesalahan umum yang sering terjadi

1. **Tidak menyimpan preferensi di localStorage** — Setiap kali halaman di-refresh, tema kembali ke default, membuat pengguna frustrasi.

2. **Ikon tidak sinkron dengan tema** — Tombol menunjukkan "☀️ Mode Terang" tapi tema sedang dark. Selalu sinkronkan UI dengan tema setelah load.

3. **Mengabaikan prefers-color-scheme** — Website tidak menghormati preferensi sistem pengguna, memaksa tema tertentu tanpa deteksi awal.

4. **Tidak ada transisi** — Perpindahan tema terasa tiba-tiba dan kasar. Tambahkan `transition` CSS untuk pengalaman yang mulus.

5. **Hanya mengubah background, lupa teks dan komponen** — Bagian tertentu jadi tidak terbaca karena warna teks dan background tidak sesuai.

## Koneksi dengan materi sebelumnya

Di Bootstrap Level 1-5, kita menggunakan class utilities Bootstrap untuk styling. Dark mode toggle memperkenalkan pendekatan berbasis **atribut data** (`data-bs-theme`) yang mengontrol seluruh tema komponen secara otomatis. Ini terhubung dengan **Grid & Layout** (Level 2) karena struktur halaman tetap sama, hanya warnanya yang berubah. Juga terhubung dengan **Utilities** (Level 4) karena kita menggunakan utility `d-dark-none` dan `d-light-none` untuk mengontrol visibilitas elemen berdasarkan tema.

## Soal latihan & jawaban

### Soal 1
Buatlah tombol toggle dark mode sederhana yang saat diklik mengubah `data-bs-theme` pada elemen `<html>`.

<details>
<summary>Jawaban</summary>

```html
<button id="toggleBtn" class="btn btn-secondary">Toggle</button>

<script>
  document.getElementById('toggleBtn').addEventListener('click', () => {
    const html = document.documentElement;
    const theme = html.getAttribute('data-bs-theme') === 'dark' ? 'light' : 'dark';
    html.setAttribute('data-bs-theme', theme);
  });
</script>
```
</details>

### Soal 2
Tambahkan fitur localStorage agar tema yang dipilih tersimpan meskipun halaman di-refresh.

<details>
<summary>Jawaban</summary>

```javascript
const html = document.documentElement;

const saved = localStorage.getItem('theme');
if (saved) {
  html.setAttribute('data-bs-theme', saved);
}

document.getElementById('toggleBtn').addEventListener('click', () => {
  const current = html.getAttribute('data-bs-theme');
  const next = current === 'dark' ? 'light' : 'dark';
  html.setAttribute('data-bs-theme', next);
  localStorage.setItem('theme', next);
});
```
</details>

### Soal 3
Tampilkan elemen `<div class="alert alert-info">` hanya saat mode gelap menggunakan utility class Bootstrap.

<details>
<summary>Jawaban</summary>

```html
<div class="alert alert-info d-light-none">
  Tips: Kamu sedang dalam mode gelap. Matikan lampu untuk kenyamanan mata!
</div>
```

Class `d-light-none` membuat elemen ini tersembunyi saat `data-bs-theme="light"` dan muncul saat `data-bs-theme="dark"`.
</details>
