# Memahami data attributes API yaitu data-bs-toggle, data-bs-target, dll.

## Analogi: Perpustakaan Digital

Seperti memasang sensor otomatis di pintu perpustakaan — sensor cukup diberi label "buka jika ada gerakan" dan pintu akan merespons tanpa perlu diprogram ulang — data attributes Bootstrap memungkinkan elemen HTML berperilaku interaktif hanya dengan menambahkan atribut `data-bs-*`. Ini adalah cara deklaratif untuk menghidupkan komponen tanpa menulis JavaScript.

## Penjelasan Detail

Bootstrap menggunakan data attributes sebagai API deklaratif untuk menginisialisasi dan mengontrol komponen JavaScript. Atribut `data-bs-toggle` menentukan komponen apa yang akan diaktifkan (modal, dropdown, collapse, tooltip, popover, tab). `data-bs-target` menunjuk ke elemen target yang akan dimanipulasi (biasanya menggunakan CSS selector). `data-bs-dismiss` menutup komponen. Atribut konfigurasi lainnya: `data-bs-placement` (posisi tooltip/popover), `data-bs-html` (mengizinkan HTML), `data-bs-interval` (interval carousel). Data attributes memiliki prefix `data-bs-` (bukan `data-` seperti di Bootstrap 4) untuk menghindari konflik. Bootstrap secara otomatis menginisialisasi semua komponen dengan data attributes saat halaman dimuat.

## Contoh Kode Implementasi

```html
<!-- data-bs-toggle: menentukan jenis komponen -->
<button data-bs-toggle="modal" data-bs-target="#exampleModal">
  Buka Modal
</button>

<!-- data-bs-dismiss: menutup komponen -->
<button type="button" class="btn-close" data-bs-dismiss="modal"></button>

<!-- Tooltip dengan konfigurasi -->
<button data-bs-toggle="tooltip" 
        data-bs-placement="top" 
        data-bs-title="Tooltip di atas"
        title="">
  Hover saya
</button>

<!-- Dropdown -->
<div class="dropdown">
  <button data-bs-toggle="dropdown">
    Dropdown
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Action</a></li>
  </ul>
</div>

<!-- Collapse dengan multiple target -->
<button data-bs-toggle="collapse" data-bs-target="#collapseContent">
  Toggle Content
</button>
<div id="collapseContent" class="collapse">
  Konten yang bisa ditutup buka
</div>
```

## Poin Penting
- Prefix `data-bs-` digunakan di Bootstrap 5 (berbeda dengan `data-` di Bootstrap 4)
- `data-bs-toggle` menentukan jenis komponen, `data-bs-target` menunjuk elemen target
- `data-bs-dismiss` menutup komponen seperti modal, alert, offcanvas
- Bootstrap otomatis menginisialisasi komponen berdasarkan data attributes saat DOM ready
