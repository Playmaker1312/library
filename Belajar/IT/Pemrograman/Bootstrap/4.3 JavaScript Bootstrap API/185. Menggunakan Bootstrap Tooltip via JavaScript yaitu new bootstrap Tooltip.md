# Menggunakan Bootstrap Tooltip via JavaScript yaitu new bootstrap.Tooltip

## Analogi: Perpustakaan Digital

Seperti label informasi kecil yang muncul saat Anda mengarahkan kursor ke judul buku di rak — tooltip menampilkan teks bantuan singkat saat pengguna berinteraksi dengan elemen. Menggunakan JavaScript API memungkinkan Anda mengontrol tooltip secara programatik, termasuk inisialisasi massal, konten dinamis, dan konfigurasi lanjutan.

## Penjelasan Detail

Kelas `bootstrap.Tooltip` memungkinkan pembuatan tooltip melalui JavaScript. Constructor menerima elemen HTMLElement sebagai parameter pertama dan objek opsi sebagai parameter kedua. Opsi penting: `placement` (top, bottom, left, right, auto), `title` (konten tooltip — bisa string, fungsi, atau elemen), `html` (true/false — mengizinkan HTML di dalam tooltip), `trigger` ('hover focus' — event yang memicu tooltip), `delay` (delay show/hide dalam ms), `container` (elemen yang membungkus tooltip), `sanitize` (true/false — sanitasi HTML). Tidak seperti beberapa komponen lain, tooltip tidak aktif secara default — Anda harus menginisialisasinya dengan `new bootstrap.Tooltip(element)`. Untuk tooltip yang muncul saat hover saja, pastikan trigger diatur dengan benar.

## Contoh Kode Implementasi

```html
<button id="tooltipBtn" class="btn btn-info"
        data-bs-toggle="tooltip"
        data-bs-placement="right"
        title="Tooltip default">
  Hover Saya
</button>

<button id="dynamicTooltipBtn" class="btn btn-warning">
  Tooltip Dinamis
</button>

<script>
  // Inisialisasi tooltip dari data attributes
  const tooltipEl = document.getElementById('tooltipBtn');
  const tooltip = new bootstrap.Tooltip(tooltipEl);

  // Inisialisasi tooltip dengan opsi JavaScript
  const dynamicTooltipEl = document.getElementById('dynamicTooltipBtn');
  const dynamicTooltip = new bootstrap.Tooltip(dynamicTooltipEl, {
    title: 'Tooltip dibuat via JS',
    placement: 'bottom',
    html: true,
    delay: { show: 500, hide: 100 },
    trigger: 'hover'
  });

  // Update konten tooltip secara dinamis
  function updateTooltipContent(newContent) {
    dynamicTooltipEl.setAttribute('data-bs-title', newContent);
    dynamicTooltip.dispose();
    // Buat instance baru dengan konten terbaru
    const updatedTooltip = new bootstrap.Tooltip(dynamicTooltipEl, {
      title: newContent
    });
  }
  
  // Inisialisasi semua tooltip di halaman
  document.querySelectorAll('[data-bs-toggle="tooltip"]').forEach(el => {
    new bootstrap.Tooltip(el);
  });
</script>
```

## Poin Penting
- Tooltip harus diinisialisasi secara eksplisit — tidak aktif hanya dengan data attributes
- Opsi `html: true` mengizinkan HTML di dalam tooltip (gunakan dengan hati-hati)
- `delay` mengontrol waktu tunda muncul/menghilang tooltip
- Dispose tooltip sebelum memperbarui konten untuk mencegah masalah
