# Menggunakan Bootstrap Popover via JavaScript yaitu new bootstrap.Popover

## Analogi: Perpustakaan Digital

Jika tooltip adalah label kecil, popover adalah kartu informasi yang lebih besar — seperti brosur yang muncul saat Anda menekan tombol di rak buku, berisi sinopsis, detail penulis, dan informasi lainnya. Popover dapat menampung lebih banyak konten, termasuk HTML, gambar, bahkan daftar.

## Penjelasan Detail

`bootstrap.Popover` mirip dengan Tooltip tetapi dengan konten yang lebih kaya. Constructor menerima elemen dan objek opsi. Opsi spesifik popover: `content` (konten utama popover, bisa string/fungsi/element), `title` (judul popover), `placement` (top, bottom, left, right, auto), `html` (true/false), `trigger` ('click' default — popover biasanya muncul saat diklik). Popover membutuhkan inisialisasi eksplisit seperti tooltip. Method yang tersedia: `show()`, `hide()`, `toggle()`, `dispose()`, `enable()`, `disable()`, `toggleEnabled()`, dan `update()`. Popover mendukung sanitasi HTML untuk keamanan. Secara default, popover muncul saat diklik (bukan hover) untuk UX yang lebih baik, terutama di perangkat mobile.

## Contoh Kode Implementasi

```html
<button id="popoverBtn" class="btn btn-danger">
  Klik untuk Info
</button>

<script>
  // Inisialisasi popover dengan konten kaya
  const popoverEl = document.getElementById('popoverBtn');
  const popover = new bootstrap.Popover(popoverEl, {
    title: '<i class="bi bi-info-circle"></i> Informasi Penting',
    content: `
      <div class="popover-content">
        <p><strong>Judul Buku:</strong> Bootstrap 5 untuk Pemula</p>
        <p><strong>Penulis:</strong> Tim Pengembang</p>
        <p><strong>Tahun:</strong> 2024</p>
        <hr>
        <p class="mb-0 text-muted">Klik tombol di luar untuk menutup.</p>
      </div>
    `,
    html: true,
    placement: 'right',
    trigger: 'click',
    delay: { show: 200, hide: 0 }
  });

  // Method untuk toggle popover
  function togglePopover() {
    popover.toggle();
  }
  
  // Update konten popover
  function updatePopover(newTitle, newContent) {
    popover.dispose();
    const updatedPopover = new bootstrap.Popover(popoverEl, {
      title: newTitle,
      content: newContent,
      html: true
    });
  }
</script>
```

## Poin Penting
- Popover mirip tooltip tetapi dengan konten lebih besar dan kaya
- `trigger: 'click'` adalah default — popover muncul saat diklik
- Set `html: true` untuk menggunakan HTML dalam konten popover
- Popover harus diinisialisasi secara eksplisit dengan `new bootstrap.Popover()`
