# Cara mendengarkan Bootstrap events menggunakan addEventListener

## Analogi: Perpustakaan Digital

Seperti memasang alarm yang mendengarkan suara tertentu — alarm akan berbunyi saat mendengar bunyi "klik" tertentu. `addEventListener` adalah telinga yang mendengarkan peristiwa (events) yang dikirim oleh komponen Bootstrap, memungkinkan Anda bereaksi terhadap aksi pengguna atau perubahan status komponen.

## Penjelasan Detail

Bootstrap menggunakan native `CustomEvent` untuk semua events-nya. Ini berarti Anda bisa menggunakan `addEventListener` standar seperti pada event DOM biasa (click, submit, keydown). Cara mendengarkan: pilih elemen komponen, lalu panggil `addEventListener('eventName', callback)`. Nama event Bootstrap mengikuti pola `event.bs.component`. Contoh: `'show.bs.modal'`, `'hidden.bs.collapse'`, `'shown.bs.dropdown'`. Callback menerima objek `Event` yang memiliki properti `target` (elemen yang memicu event), `relatedTarget` (elemen terkait), dan `defaultPrevented` (apakah event dicegah). Anda juga bisa menggunakan `once: true` untuk event yang hanya dijalankan sekali, dan `removeEventListener()` untuk berhenti mendengarkan.

## Contoh Kode Implementasi

```html
<div id="myModal" class="modal fade" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Contoh Event Listener</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">
        <p id="logArea">Tidak ada event tercatat</p>
      </div>
    </div>
  </div>
</div>

<button id="openBtn" class="btn btn-primary">Buka Modal</button>
<button id="stopListeningBtn" class="btn btn-warning">Berhenti Mendengarkan</button>

<script>
  const modalEl = document.getElementById('myModal');
  const logArea = document.getElementById('logArea');
  const modal = new bootstrap.Modal(modalEl);
  
  // Fungsi pencatat event
  function logEvent(event) {
    const time = new Date().toLocaleTimeString();
    logArea.innerHTML = `<strong>${time}</strong>: ${event.type} terjadi`;
  }
  
  // Daftarkan event listeners
  modalEl.addEventListener('show.bs.modal', logEvent);
  modalEl.addEventListener('shown.bs.modal', logEvent);
  modalEl.addEventListener('hide.bs.modal', logEvent);
  modalEl.addEventListener('hidden.bs.modal', logEvent);
  
  // Event listener sekali jalan
  modalEl.addEventListener('shown.bs.modal', function() {
    console.log('Modal pertama kali ditampilkan!');
  }, { once: true });
  
  // Membuka modal
  document.getElementById('openBtn').addEventListener('click', function() {
    modal.show();
  });
  
  // Berhenti mendengarkan event
  document.getElementById('stopListeningBtn').addEventListener('click', function() {
    modalEl.removeEventListener('show.bs.modal', logEvent);
    modalEl.removeEventListener('shown.bs.modal', logEvent);
    modalEl.removeEventListener('hide.bs.modal', logEvent);
    modalEl.removeEventListener('hidden.bs.modal', logEvent);
    logArea.textContent = 'Event listener dihentikan';
  });
</script>
```

## Poin Penting
- Gunakan `addEventListener(eventName, callback)` standar untuk Bootstrap events
- Nama event: `show.bs.modal`, `shown.bs.collapse`, `hide.bs.dropdown`, `hidden.bs.tab`, dll.
- Opsi `{ once: true }` untuk event yang hanya dijalankan satu kali
- Gunakan `removeEventListener()` untuk berhenti mendengarkan event tertentu
