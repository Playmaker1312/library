# Menggunakan Bootstrap Modal via JavaScript yaitu new bootstrap.Modal

## Analogi: Perpustakaan Digital

Seperti membuka ruang rapat khusus di perpustakaan yang muncul saat dibutuhkan dan menghilang saat selesai — modal adalah elemen overlay yang menampilkan konten di atas halaman utama. Menggunakan JavaScript API memberikan kontrol penuh kapan modal muncul, konten apa yang ditampilkan, dan apa yang terjadi saat modal dibuka atau ditutup.

## Penjelasan Detail

Kelas `bootstrap.Modal` adalah konstruktor untuk membuat dan mengontrol komponen modal. Constructor menerima elemen HTML modal sebagai parameter pertama, dan objek opsi sebagai parameter kedua (opsional). Method utama: `show()` untuk menampilkan modal, `hide()` untuk menyembunyikan, `toggle()` untuk membalik status, `handleUpdate()` untuk memperbarui posisi jika konten berubah, dan `dispose()` untuk menghapus instance. Opsi modal meliputi: `backdrop` (true, false, atau 'static' — klik di luar modal), `keyboard` (true/false — tombol Escape), dan `focus` (true/false — auto focus). Modal dapat diisi konten secara dinamis menggunakan properti `innerHTML` pada elemen `.modal-body`.

## Contoh Kode Implementasi

```html
<div id="dynamicModal" class="modal fade" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Modal Dinamis</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">
        <!-- Konten akan diisi oleh JavaScript -->
      </div>
      <div class="modal-footer">
        <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">Tutup</button>
      </div>
    </div>
  </div>
</div>

<script>
  const modalEl = document.getElementById('dynamicModal');
  
  // Membuat instance modal dengan opsi
  const modal = new bootstrap.Modal(modalEl, {
    backdrop: 'static',  // Tidak bisa ditutup dengan klik backdrop
    keyboard: false       // Tidak bisa ditutup dengan Escape
  });
  
  // Fungsi untuk membuka modal dengan konten dinamis
  function openModal(title, bodyContent) {
    modalEl.querySelector('.modal-title').textContent = title;
    modalEl.querySelector('.modal-body').innerHTML = bodyContent;
    modal.show();
  }
  
  // Contoh penggunaan
  document.getElementById('showModalBtn').addEventListener('click', function() {
    openModal('Pemberitahuan', '<p>Data berhasil disimpan!</p><p>Silakan lanjutkan.</p>');
  });
</script>
```

## Poin Penting
- Constructor: `new bootstrap.Modal(element, options)`
- Method: `show()`, `hide()`, `toggle()`, `handleUpdate()`, `dispose()`
- Opsi `backdrop: 'static'` mencegah modal tertutup saat klik di luar
- Konten modal dapat diubah secara dinamis sebelum memanggil `show()`
