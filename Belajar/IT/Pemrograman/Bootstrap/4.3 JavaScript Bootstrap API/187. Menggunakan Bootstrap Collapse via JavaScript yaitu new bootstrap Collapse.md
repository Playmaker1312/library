# Menggunakan Bootstrap Collapse via JavaScript yaitu new bootstrap.Collapse

## Analogi: Perpustakaan Digital

Seperti rak buku dorong yang bisa dibuka dan ditutup — saat terbuka, Anda melihat semua buku; saat tertutup, rak menyembunyikan isinya. Collapse Bootstrap adalah mekanisme show/hide dengan animasi yang memungkinkan konten ditampilkan atau disembunyikan dengan mulus, ideal untuk FAQ, panel aksordeon, dan menu navigasi.

## Penjelasan Detail

Kelas `bootstrap.Collapse` mengontrol elemen yang dapat disembunyikan/ditampilkan dengan animasi. Constructor menerima elemen target dan objek opsi. Opsi: `toggle` (true/false — apakah collapse dimulai dalam keadaan terbuka), `parent` (selector — untuk behaviour accordion, hanya satu collapse dalam parent yang terbuka). Method: `show()` (buka collapse), `hide()` (tutup), `toggle()` (balik status). Berbeda dengan data attributes yang mengandalkan `data-bs-toggle="collapse"`, JavaScript API memberikan kontrol penuh. Collapse sangat berguna untuk implementasi accordion multi-section di mana hanya satu panel yang boleh terbuka. Animasi collapse menggunakan CSS transitions yang bisa dikustomisasi.

## Contoh Kode Implementasi

```html
<div class="accordion" id="myAccordion">
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button" id="section1Btn">Bagian 1</button>
    </h2>
    <div id="section1" class="accordion-collapse collapse show">
      <div class="accordion-body">Konten bagian 1</div>
    </div>
  </div>
  <div class="accordion-item">
    <h2 class="accordion-header">
      <button class="accordion-button collapsed" id="section2Btn">Bagian 2</button>
    </h2>
    <div id="section2" class="accordion-collapse collapse">
      <div class="accordion-body">Konten bagian 2</div>
    </div>
  </div>
</div>

<script>
  // Inisialisasi collapse via JavaScript
  const section1 = new bootstrap.Collapse('#section1', {
    toggle: false // Tidak otomatis toggle saat inisialisasi
  });
  
  const section2 = new bootstrap.Collapse('#section2', {
    parent: '#myAccordion' // Perilaku accordion: hanya satu yang terbuka
  });
  
  // Kontrol programatik
  document.getElementById('section1Btn').addEventListener('click', function() {
    section1.toggle();
  });
  
  document.getElementById('section2Btn').addEventListener('click', function() {
    section2.show();
  });
  
  // Method chaining
  function resetCollapse() {
    section2.hide();
    setTimeout(() => section1.show(), 300);
  }
</script>
```

## Poin Penting
- Constructor: `new bootstrap.Collapse(element, options)`
- Opsi `parent` mengaktifkan perilaku accordion (hanya satu panel terbuka)
- Method: `show()`, `hide()`, `toggle()`
- Gunakan `dispose()` saat elemen collapse dihapus dari DOM
