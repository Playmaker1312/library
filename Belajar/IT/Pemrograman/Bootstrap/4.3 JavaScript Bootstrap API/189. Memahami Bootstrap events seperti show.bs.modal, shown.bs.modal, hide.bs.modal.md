# Memahami Bootstrap events seperti show.bs.modal, shown.bs.modal, hide.bs.modal

## Analogi: Perpustakaan Digital

Bayangkan sensor di pintu perpustakaan yang mendeteksi setiap tahap: "pintu mulai terbuka", "pintu sudah terbuka penuh", "pintu mulai tertutup", "pintu sudah tertutup". Bootstrap events bekerja seperti sensor ini — mereka memberitahu Anda tentang berbagai tahap siklus hidup komponen, memungkinkan Anda menjalankan kode pada momen yang tepat.

## Penjelasan Detail

Setiap komponen Bootstrap memiliki serangkaian events yang terdiri dari dua jenis: `pre` event (saat aksi akan dimulai, bisa dicegah) dan `post` event (setelah aksi selesai). Pola penamaan: `show.bs.modal` (sebelum modal ditampilkan, bisa dicegah), `shown.bs.modal` (setelah modal tampil), `hide.bs.modal` (sebelum modal ditutup, bisa dicegah), `hidden.bs.modal` (setelah modal tertutup). Untuk collapse: `show.bs.collapse`, `shown.bs.collapse`, `hide.bs.collapse`, `hidden.bs.collapse`. Untuk dropdown: `show.bs.dropdown`, `shown.bs.dropdown`, dll. Event `pre` dapat dicegah dengan `event.preventDefault()` untuk membatalkan aksi. Events menggunakan `CustomEvent` dan properti `relatedTarget` berisi elemen yang memicu event.

## Contoh Kode Implementasi

```html
<div id="eventModal" class="modal fade" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Modal dengan Events</h5>
        <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">
        <p id="modalStatus">Status: —</p>
      </div>
    </div>
  </div>
</div>

<script>
  const modalEl = document.getElementById('eventModal');
  const statusEl = document.getElementById('modalStatus');
  const modal = new bootstrap.Modal(modalEl);

  // show.bs.modal — sebelum modal tampil (dapat dicegah)
  modalEl.addEventListener('show.bs.modal', function(event) {
    statusEl.textContent = 'Status: Modal akan dibuka...';
    // event.preventDefault(); // batalkan jika perlu
  });

  // shown.bs.modal — setelah modal tampil
  modalEl.addEventListener('shown.bs.modal', function() {
    statusEl.textContent = 'Status: Modal sedang terbuka';
  });

  // hide.bs.modal — sebelum modal ditutup (dapat dicegah)
  modalEl.addEventListener('hide.bs.modal', function(event) {
    const confirmClose = confirm('Tutup modal?');
    if (!confirmClose) {
      event.preventDefault(); // batalkan penutupan
    }
  });

  // hidden.bs.modal — setelah modal tertutup
  modalEl.addEventListener('hidden.bs.modal', function() {
    statusEl.textContent = 'Status: Modal tertutup';
  });
</script>
```

## Poin Penting
- Pola event: `show.bs.*` (pre), `shown.bs.*` (post), `hide.bs.*` (pre), `hidden.bs.*` (post)
- Event `pre` (show/hide) dapat dicegah dengan `event.preventDefault()`
- Gunakan `event.relatedTarget` untuk mengakses elemen pemicu
- Setiap komponen Bootstrap memiliki event yang sesuai dengan siklus hidupnya
