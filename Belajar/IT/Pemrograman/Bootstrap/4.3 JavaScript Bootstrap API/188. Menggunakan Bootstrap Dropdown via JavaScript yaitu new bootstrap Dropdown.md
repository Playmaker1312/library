# Menggunakan Bootstrap Dropdown via JavaScript yaitu new bootstrap.Dropdown

## Analogi: Perpustakaan Digital

Seperti menu kategori di perpustakaan digital yang memperlihatkan subkategori saat diklik — dropdown Bootstrap adalah menu tarik-turun yang berisi daftar opsi atau tautan. Menggunakan JavaScript API memberikan fleksibilitas untuk membuka, menutup, atau memperbarui dropdown secara programatik.

## Penjelasan Detail

Kelas `bootstrap.Dropdown` mengontrol komponen dropdown. Constructor menerima elemen toggle (biasanya tombol atau tautan) dan objek opsi. Opsi: `popperConfig` (objek — konfigurasi Popper.js untuk positioning), `offset` (array — offset posisi dropdown), `reference` (string 'toggle' atau elemen — elemen referensi positioning), `display` (string 'dynamic' atau 'static'). Method: `show()` (buka dropdown), `hide()` (tutup), `toggle()` (balik), `update()` (perbarui posisi), `dispose()` (hapus instance). Event: `show.bs.dropdown`, `shown.bs.dropdown`, `hide.bs.dropdown`, `hidden.bs.dropdown`. Dropdown secara otomatis menutup saat pengguna mengklik di luar (auto-close behavior). Anda bisa mengubah auto-close dengan atribut `data-bs-auto-close` (true, false, inside, outside).

## Contoh Kode Implementasi

```html
<div class="dropdown" id="myDropdown">
  <button class="btn btn-secondary dropdown-toggle" 
          id="dropdownBtn"
          type="button">
    Pilih Menu
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Profil</a></li>
    <li><a class="dropdown-item" href="#">Pengaturan</a></li>
    <li><hr class="dropdown-divider"></li>
    <li><a class="dropdown-item" href="#">Logout</a></li>
  </ul>
</div>

<script>
  const dropdownEl = document.getElementById('dropdownBtn');
  const dropdown = new bootstrap.Dropdown(dropdownEl, {
    offset: [0, 5],
    display: 'dynamic'
  });

  // Event listeners
  dropdownEl.addEventListener('show.bs.dropdown', function() {
    console.log('Dropdown akan dibuka');
    // Bisa memodifikasi konten dropdown sebelum ditampilkan
  });

  dropdownEl.addEventListener('shown.bs.dropdown', function() {
    console.log('Dropdown sudah terbuka');
  });

  // Method kontrol
  function openDropdown() {
    dropdown.show();
  }

  function closeDropdown() {
    dropdown.hide();
  }

  function refreshDropdown() {
    dropdown.update(); // Perbarui posisi jika konten berubah
  }

  // Update konten dropdown dinamis
  function updateDropdownItems(items) {
    const menu = dropdownEl.nextElementSibling;
    menu.innerHTML = items.map(item => 
      `<li><a class="dropdown-item" href="#">${item}</a></li>`
    ).join('');
    dropdown.update();
  }
</script>
```

## Poin Penting
- Constructor membutuhkan elemen toggle (bukan elemen menu)
- `offset` mengatur jarak dropdown dari toggle button
- Dropdown otomatis menutup saat klik di luar (auto-close)
- Gunakan `update()` jika konten dropdown berubah secara dinamis
