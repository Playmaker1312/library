# Memahami cara kerja Bootstrap JavaScript components

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang memiliki sistem otomatis: pintu geser yang terbuka saat sensor mendeteksi pengunjung, lampu yang menyala saat rak dibuka, dan bel yang berbunyi saat buku dipinjam. Bootstrap JavaScript components adalah seperti sistem otomatis ini — mereka menghidupkan elemen UI dengan perilaku interaktif seperti modal, dropdown, tooltip, dan carousel.

## Penjelasan Detail

Setiap Bootstrap JavaScript component adalah kelas JavaScript yang dapat diinstansiasi pada elemen DOM. Komponen-komponen ini dibangun di atas sistem event dan data attributes Bootstrap. Ada dua cara menggunakan komponen: melalui data attributes (deklaratif, tanpa menulis JavaScript) atau melalui JavaScript API (programatik, dengan kontrol penuh). Setiap komponen memiliki constructor, metode publik (show, hide, toggle, dispose), dan events (show.bs.modal, hidden.bs.collapse, dll). Bootstrap 5 menghilangkan ketergantungan pada jQuery, menggunakan JavaScript vanilla dengan ES6 classes. Komponen diinisialisasi dengan `data-bs-toggle` attribute atau dengan `new bootstrap.Modal(element)`.

## Contoh Kode Implementasi

```javascript
// Cara 1: Data Attributes (deklaratif)
// <button data-bs-toggle="modal" data-bs-target="#myModal">Buka Modal</button>

// Cara 2: JavaScript API (programatik)
// Inisialisasi komponen
const myModalEl = document.getElementById('myModal');
const modal = new bootstrap.Modal(myModalEl);

// Memanggil method
modal.show();
modal.hide();
modal.toggle();

// Mendengarkan events
myModalEl.addEventListener('show.bs.modal', function(event) {
  console.log('Modal akan ditampilkan');
});

// Membersihkan instance
modal.dispose();
```

## Poin Penting
- Bootstrap JavaScript components dapat digunakan via data attributes atau JavaScript API
- Setiap component memiliki constructor, methods, dan events
- Bootstrap 5 menggunakan JavaScript vanilla, tidak memerlukan jQuery
- Selalu dispose komponen saat elemen dihapus dari DOM untuk mencegah memory leak
