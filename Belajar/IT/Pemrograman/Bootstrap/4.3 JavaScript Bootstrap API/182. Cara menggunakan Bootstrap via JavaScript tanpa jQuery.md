# Cara menggunakan Bootstrap via JavaScript tanpa jQuery

## Analogi: Perpustakaan Digital

Dulu, mengoperasikan sistem perpustakaan memerlukan alat khusus bernama jQuery — seperti kunci pas universal yang bisa menangani berbagai jenis baut. Sekarang, Bootstrap 5 menggunakan alat bawaan (JavaScript vanilla) yang sudah tersedia di setiap browser modern. Ini seperti beralih dari kunci pas universal ke set kunci pas yang sudah sesuai dengan setiap baut secara spesifik.

## Penjelasan Detail

Sebelum Bootstrap 5, komponen JavaScript Bootstrap bergantung pada jQuery. Mulai Bootstrap 5, ketergantungan ini dihapus total. Semua komponen menggunakan JavaScript vanilla (plain JavaScript) dengan ES6 class, DOM API modern seperti `querySelector`, `addEventListener`, `classList`, dan `CustomEvent`. Untuk memilih elemen, gunakan `document.querySelector()` atau `document.getElementById()`. Untuk event, gunakan `element.addEventListener()`. Bootstrap menyediakan objek global `bootstrap` yang berisi semua kelas komponen. Anda perlu mengimpor Bootstrap JavaScript atau menyertakannya via CDN. Jika Anda sudah terbiasa dengan jQuery, transisi ke vanilla JS mungkin memerlukan penyesuaian, tetapi hasil akhirnya adalah kode yang lebih ringan dan cepat.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-5">
    <!-- Button trigger modal -->
    <button id="openModalBtn" class="btn btn-primary">Buka Modal</button>
    
    <!-- Modal -->
    <div id="myModal" class="modal fade" tabindex="-1">
      <div class="modal-dialog">
        <div class="modal-content">
          <div class="modal-header">
            <h5 class="modal-title">Judul Modal</h5>
            <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
          </div>
          <div class="modal-body">
            <p>Ini adalah modal tanpa jQuery!</p>
          </div>
        </div>
      </div>
    </div>
  </div>

  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
  <script>
    // Vanilla JavaScript — tanpa jQuery
    const modalEl = document.getElementById('myModal');
    const modal = new bootstrap.Modal(modalEl);
    
    document.getElementById('openModalBtn').addEventListener('click', function() {
      modal.show();
    });
  </script>
</body>
</html>
```

## Poin Penting
- Bootstrap 5 tidak memerlukan jQuery — hanya menggunakan JavaScript vanilla
- Gunakan `document.querySelector()` dan `addEventListener()` untuk manipulasi DOM
- Bootstrap JavaScript tersedia via CDN sebagai `bootstrap.bundle.min.js`
- Semua kelas komponen Bootstrap dapat diakses melalui objek global `bootstrap`
