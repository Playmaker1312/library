# Menggunakan Bootstrap Icons yaitu Koleksi Ikon Resmi Bootstrap

## Analogi: Perpustakaan Digital

Bootstrap Icons adalah seperti set stiker dan simbol yang tersedia di perpustakaan untuk menandai rak buku—ikon buku, ikon komputer, ikon jam, ikon orang. Stiker-stiker ini dirancang khusus oleh tim perpustakaan dengan gaya yang seragam, sehingga semua papan tanda terlihat konsisten. Bootstrap Icons adalah library ikon resmi yang dibuat oleh tim Bootstrap, dengan gaya yang selaras sempurna dengan framework.

## Penjelasan Detail

Bootstrap Icons adalah library ikon SVG open source yang berisi 1.900+ ikon. Cara menggunakan: (1) CDN: tambahkan link CSS, lalu gunakan elemen <i> atau <svg>, (2) NPM: `npm i bootstrap-icons`, (3) Download: download ZIP dari situs resmi. Ikon bisa dikustomisasi ukuran (font-size), warna (color), dan efek CSS lainnya. Bootstrap Icons terintegrasi sempurna dengan komponen Bootstrap—cocok untuk navbar, button, card, alert, dan form. Ikon juga tersedia dalam format SVG yang bisa diedit.

## Poin Penting
- Bootstrap Icons adalah library ikon resmi dengan 1.900+ ikon SVG yang selaras dengan framework.
- Ikon dapat digunakan dengan elemen <i> atau <svg> dan dikustomisasi ukuran/warna dengan CSS.
- Integrasi sempurna dengan komponen Bootstrap: button, card, navbar, alert, form.
