# Mempelajari Cara Berkontribusi Bug Report atau Feature Request ke Bootstrap

## Analogi: Perpustakaan Digital

Melaporkan bug ke Bootstrap adalah seperti memberitahu petugas perpustakaan bahwa ada rak buku yang rusak atau lampu yang mati. Dengan melaporkan, Anda membantu perpustakaan menjadi lebih baik untuk semua pengunjung. Feature request adalah seperti menyarankan buku baru untuk koleksi perpustakaan—ide Anda mungkin akan membantu banyak orang jika diimplementasikan.

## Penjelasan Detail

Cara melaporkan bug: (1) Buka github.com/twbs/bootstrap/issues, (2) Klik "New Issue", (3) Pilih template "Bug Report", (4) Isi detail: versi Bootstrap, browser, langkah reproduksi, expected behavior, actual behavior, (5) Lampirkan screenshot atau CodePen jika perlu, (6) Submit. Untuk feature request: (1) Pilih template "Feature Request", (2) Jelaskan masalah yang ingin diselesaikan, (3) Berikan contoh penggunaan yang diusulkan, (4) Jelaskan alternatif yang sudah dipertimbangkan. Tips: cari dulu apakah issue serupa sudah ada sebelumnya. Bug yang baik dilaporkan dengan kode minimal yang bisa direproduksi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bug Report & Feature Request Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container my-5">
    <h1 class="mb-4">Berkontribusi Bug Report & Feature Request</h1>

    <div class="row g-4 mb-5">
      <div class="col-md-6">
        <div class="card h-100 border-danger">
          <div class="card-header bg-danger text-white">🐛 Bug Report</div>
          <div class="card-body">
            <p>Laporkan bug yang Anda temukan di Bootstrap.</p>
            <h6>Informasi yang diperlukan:</h6>
            <ul class="small">
              <li>Versi Bootstrap</li>
              <li>Browser & OS</li>
              <li>Langkah reproduksi</li>
              <li>Expected behavior</li>
              <li>Actual behavior</li>
              <li>Screenshot/CodePen (opsional)</li>
            </ul>
          </div>
        </div>
      </div>
      <div class="col-md-6">
        <div class="card h-100 border-primary">
          <div class="card-header bg-primary text-white">💡 Feature Request</div>
          <div class="card-body">
            <p>Usulkan fitur baru untuk Bootstrap.</p>
            <h6>Informasi yang diperlukan:</h6>
            <ul class="small">
              <li>Masalah yang ingin diselesaikan</li>
              <li>Solusi yang diusulkan</li>
              <li>Contoh penggunaan</li>
              <li>Alternatif yang sudah dipertimbangkan</li>
              <li>Referensi (jika ada)</li>
            </ul>
          </div>
        </div>
      </div>
    </div>

    <!-- Contoh Bug Report -->
    <h2 class="mb-3">Contoh Bug Report yang Baik</h2>
    <div class="card shadow-sm mb-4">
      <div class="card-body">
        <div class="border-start border-danger border-4 ps-3">
          <h6><strong>Judul:</strong> Navbar toggler icon tidak muncul di Safari iOS 17</h6>
          <p><strong>Versi Bootstrap:</strong> 5.3.3</p>
          <p><strong>Browser:</strong> Safari iOS 17.2 (iPhone 14)</p>
          <p><strong>Langkah Reproduksi:</strong></p>
          <ol>
            <li>Buka halaman dengan navbar Bootstrap di iPhone Safari</li>
            <li>Resize ke viewport mobile</li>
            <li>Perhatikan navbar toggler icon</li>
          </ol>
          <p><strong>Expected:</strong> Ikon hamburger muncul</p>
          <p><strong>Actual:</strong> Ikon tidak muncul, hanya kotak kosong</p>
          <p><strong>Kode minimal:</strong></p>
          <pre class="bg-light p-2 rounded small">
&lt;nav class="navbar navbar-expand-lg navbar-dark bg-dark"&gt;
  &lt;button class="navbar-toggler" type="button" data-bs-toggle="collapse"&gt;
    &lt;span class="navbar-toggler-icon"&gt;&lt;/span&gt;
  &lt;/button&gt;
&lt;/nav&gt;</pre>
        </div>
      </div>
    </div>

    <!-- Contoh Feature Request -->
    <h2 class="mb-3">Contoh Feature Request yang Baik</h2>
    <div class="card shadow-sm">
      <div class="card-body">
        <div class="border-start border-primary border-4 ps-3">
          <h6><strong>Judul:</strong> Proposal: New "Timeline" component for Bootstrap</h6>
          <p><strong>Masalah:</strong> Banyak pengembang membuat timeline custom untuk menampilkan riwayat, tetapi tidak ada komponen standar Bootstrap.</p>
          <p><strong>Solusi:</strong> Tambahkan komponen Timeline baru dengan class .timeline, .timeline-item, .timeline-point.</p>
          <p><strong>Contoh penggunaan:</strong></p>
          <pre class="bg-light p-2 rounded small">
&lt;div class="timeline"&gt;
  &lt;div class="timeline-item"&gt;
    &lt;div class="timeline-point"&gt;&lt;/div&gt;
    &lt;div class="timeline-content"&gt;
      &lt;h6&gt;2024&lt;/h6&gt;
      &lt;p&gt;Deskripsi event&lt;/p&gt;
    &lt;/div&gt;
  &lt;/div&gt;
&lt;/div&gt;</pre>
          <p><strong>Alternatif:</strong> Saat ini menggunakan list-group dengan CSS kustom. Komponen resmi akan lebih konsisten.</p>
        </div>
      </div>
    </div>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan template GitHub Issues yang sudah disediakan untuk Bug Report atau Feature Request.
- Bug report harus menyertakan versi Bootstrap, browser, dan langkah reproduksi yang jelas.
- Cari issue yang sudah ada sebelum membuat baru untuk menghindari duplikasi.
