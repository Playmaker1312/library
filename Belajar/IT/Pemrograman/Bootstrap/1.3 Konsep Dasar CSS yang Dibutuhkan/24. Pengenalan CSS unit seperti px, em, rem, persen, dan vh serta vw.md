# Pengenalan CSS Unit seperti px, em, rem, Persen, dan vh serta vw

## Analogi: Perpustakaan Digital

CSS unit seperti berbagai alat ukur di perpustakaan. px (pixel) adalah penggaris kaku dengan ukuran tetap. em adalah ukuran yang menyesuaikan dengan ukuran font parent — seperti rak buku yang menyesuaikan ukuran buku di sekitarnya. rem adalah ukuran yang menyesuaikan dengan ukuran font root — seperti standar tinggi rak yang ditetapkan oleh arsitek perpustakaan. Persen, vh, dan vw adalah ukuran relatif terhadap ruang yang tersedia — seperti rak yang menyesuaikan dengan ukuran ruangan.

## Penjelasan Detail

CSS unit dikategorikan menjadi absolute dan relative. Absolute unit: px (1px = 1/96 inch), tidak berubah dalam kondisi apa pun. Relative unit: em (relatif terhadap font-size parent), rem (relatif terhadap font-size root/html, default 16px), % (persentase dari parent), vw (1% dari viewport width), vh (1% dari viewport height). Bootstrap 5 menggunakan rem sebagai unit utama untuk spacing, typography, dan komponen. Default root font-size adalah 16px, sehingga 1rem = 16px. Bootstrap menetapkan spacing scale dalam rem: 0.25rem, 0.5rem, 1rem, 1.5rem, 3rem. Penggunaan rem memastikan scaling yang konsisten saat pengguna mengubah ukuran font browser.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Units</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>CSS Units</h1>
        <div class="row text-center">
            <div class="col-md-4 mb-3">
                <div class="card">
                    <div class="card-header">px (pixel)</div>
                    <div class="card-body">
                        <div style="font-size: 24px;">Teks 24px</div>
                        <div style="width: 200px; height: 20px;" class="bg-primary mt-2"></div>
                        <small>Ukuran tetap, tidak berubah</small>
                    </div>
                </div>
            </div>
            <div class="col-md-4 mb-3">
                <div class="card">
                    <div class="card-header">rem (root em)</div>
                    <div class="card-body">
                        <div style="font-size: 1.5rem;">Teks 1.5rem = 24px</div>
                        <div style="width: 10rem; height: 1.25rem;" class="bg-success mt-2"></div>
                        <small>Relatif terhadap root font (16px)</small>
                    </div>
                </div>
            </div>
            <div class="col-md-4 mb-3">
                <div class="card">
                    <div class="card-header">vw / vh</div>
                    <div class="card-body">
                        <div style="width: 50vw; height: 20px;" class="bg-warning mt-2"></div>
                        <small>50vw = 50% lebar viewport</small>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- px: absolute, tidak berubah; rem: relatif terhadap root font (default 16px)
- Bootstrap menggunakan rem sebagai unit utama untuk spacing dan typography
- vw/vh relatif terhadap viewport, cocok untuk layout full-screen
- % relatif terhadap parent element
