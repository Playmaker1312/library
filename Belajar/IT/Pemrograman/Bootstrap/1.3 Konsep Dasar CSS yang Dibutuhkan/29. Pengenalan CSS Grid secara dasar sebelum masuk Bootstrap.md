# Pengenalan CSS Grid Secara Dasar Sebelum Masuk Bootstrap

## Analogi: Perpustakaan Digital

CSS Grid seperti rak buku dua dimensi — baris dan kolom sekaligus. Jika Flexbox adalah rak buku satu baris, CSS Grid adalah ruangan penuh dengan rak yang tersusun dalam baris dan kolom, membentuk grid yang teratur. Anda bisa menempatkan buku di sel tertentu, menggabungkan beberapa sel, atau mengatur jarak antar rak. Bootstrap juga menyediakan sistem CSS Grid opsional sebagai alternatif dari Flexbox grid.

## Penjelasan Detail

CSS Grid adalah model layout CSS dua dimensi yang memungkinkan Anda mengontrol baris dan kolom secara bersamaan. Properti utama CSS Grid: `display: grid`, `grid-template-columns` (definisi kolom), `grid-template-rows` (definisi baris), `gap` (jarak antar sel), `grid-column` dan `grid-row` (penempatan item). Berbeda dengan Flexbox yang satu dimensi, CSS Grid unggul untuk layout halaman kompleks seperti dashboard dan galeri foto. Bootstrap 5 menawarkan grid system berbasis CSS Grid sebagai opsi terpisah (bootstrap-grid.css) yang bekerja mirip dengan Flexbox grid tetapi menggunakan properti CSS Grid. CSS Grid juga bisa dikombinasikan dengan Bootstrap untuk layout tingkat halaman.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Pengenalan CSS Grid</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .grid-demo { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }
        .grid-demo > div { padding: 20px; text-align: center; border-radius: 8px; color: white; }
    </style>
</head>
<body>
    <div class="container py-5">
        <h1>CSS Grid Dasar</h1>
        <p class="lead">Grid 2 dimensi: baris dan kolom sekaligus.</p>
        <div class="grid-demo">
            <div class="bg-primary">Grid Item 1</div>
            <div class="bg-success">Grid Item 2</div>
            <div class="bg-warning">Grid Item 3</div>
            <div class="bg-danger">Grid Item 4</div>
            <div class="bg-info text-dark">Grid Item 5</div>
            <div class="bg-secondary">Grid Item 6</div>
        </div>
        <p class="mt-3">Bootstrap 5 juga punya CSS Grid: <code>bootstrap-grid.css</code></p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- CSS Grid = layout 2 dimensi (baris dan kolom), Flexbox = 1 dimensi
- CSS Grid unggul untuk layout halaman kompleks
- Bootstrap 5 menyediakan opsi CSS Grid terpisah
- CSS Grid bisa dikombinasikan dengan komponen Bootstrap
