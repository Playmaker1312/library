# Pengenalan Display Property yaitu Block, Inline, dan Inline-Block

## Analogi: Perpustakaan Digital

Display property seperti pengaturan tata letak buku di perpustakaan. Block seperti buku besar yang diletakkan sendiri di satu rak — memenuhi seluruh lebar rak dan memulai baris baru. Inline seperti buku kecil yang bisa berjejer dalam satu baris tanpa memulai baris baru. Inline-block seperti buku yang bisa berjejer tetapi tetap memiliki lebar dan tinggi yang bisa diatur. Bootstrap menyediakan utility class `d-*` untuk mengatur display property.

## Penjelasan Detail

Display property CSS menentukan bagaimana sebuah elemen ditampilkan dalam aliran dokumen. `block` membuat elemen mengambil lebar penuh dan memulai baris baru (contoh: div, p, h1). `inline` membuat elemen mengalir dalam teks tanpa memulai baris baru, lebar/tinggi tidak bisa diatur (contoh: span, a, strong). `inline-block` menggabungkan keduanya — elemen mengalir inline tetapi bisa diatur lebar/tingginya. Bootstrap memiliki utility class `d-block`, `d-inline`, `d-inline-block`, dan `d-flex`, `d-grid`. Display juga memiliki varian responsive: `d-md-block`, `d-lg-flex`, dll. Bootstrap 5 menggunakan Flexbox (`d-flex`) secara luas untuk layout komponen.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Display Property CSS</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Display: Block, Inline, Inline-Block</h1>
        <div class="bg-primary text-white p-2 mb-2 rounded d-block">d-block: Lebar penuh</div>
        <div class="bg-success text-white p-2 mb-2 rounded d-inline">d-inline: Sesuai konten</div>
        <div class="bg-success text-white p-2 mb-2 rounded d-inline">d-inline: Bisa sebaris</div>
        <div class="bg-warning p-2 mt-2 rounded d-inline-block" style="width: 200px;">d-inline-block: lebar 200px</div>
        <div class="bg-warning p-2 mt-2 rounded d-inline-block" style="width: 150px;">d-inline-block: lebar 150px</div>
        <p class="mt-3">Bootstrap 5 menggunakan <code>d-flex</code> untuk banyak komponen.</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Block: lebar penuh, mulai baris baru (div, p)
- Inline: mengalir dalam teks, tidak bisa diatur lebar (span, a)
- Inline-block: inline tapi bisa diatur lebar/tinggi
- Bootstrap: `d-block`, `d-inline`, `d-inline-block`, `d-flex`, `d-grid`
