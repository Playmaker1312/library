# Memahami Konsep CSS Specificity dan Cascade

## Analogi: Perpustakaan Digital

CSS specificity seperti aturan prioritas di perpustakaan. Aturan dari kepala perpustakaan (inline style) lebih penting daripada aturan dari supervisor (id selector), yang lebih penting dari aturan staf umum (class selector), yang lebih penting dari aturan kebijakan dasar (element selector). Cascade adalah proses ketika perpustakaan menerapkan aturan dari berbagai sumber dan menentukan aturan mana yang menang jika terjadi konflik.

## Penjelasan Detail

CSS specificity adalah sistem peringkat yang menentukan aturan CSS mana yang akan diterapkan ketika ada beberapa aturan yang menargetkan elemen yang sama. Urutan specificity dari tertinggi ke terendah: inline styles (gaya langsung di elemen), ID selectors (`#header`), Class/attribute/pseudo-class selectors (`.btn`, `[type]`, `:hover`), Element selectors (`div`, `p`). Cascade (cascading) adalah proses CSS menggabungkan semua stylesheet (browser default, user styles, external CSS, inline styles) dan menerapkan aturan dengan specificity tertinggi. Jika specificity sama, aturan yang ditulis terakhir akan menang. Bootstrap dirancang dengan specificity rendah agar mudah di-override dengan CSS kustom.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Specificity</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .teks { color: #198754 !important; }
        #spesial { color: #dc3545; }
        p { color: #0d6efd; }
    </style>
</head>
<body>
    <div class="container py-5">
        <h1>CSS Specificity &amp; Cascade</h1>
        <p class="teks">Paragraf dengan class "teks" (hijau via !important)</p>
        <p class="teks" id="spesial">Paragraf dengan class + id (merah via id selector)</p>
        <p>Paragraf biasa (biru via element selector)</p>
        <div class="alert alert-info mt-3">
            Specificity: !important &gt; inline &gt; id &gt; class &gt; element
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Specificity: !important > inline > id > class > element
- Bootstrap menggunakan class selector (specificity rendah) agar mudah di-override
- Jika specificity sama, aturan terakhir yang menang (cascade)
- Hindari !important, gunakan specificity yang tepat untuk override Bootstrap
