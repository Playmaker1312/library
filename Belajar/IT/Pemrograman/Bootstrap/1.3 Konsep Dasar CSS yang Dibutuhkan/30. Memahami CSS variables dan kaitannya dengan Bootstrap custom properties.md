# Memahami CSS Variables dan Kaitannya dengan Bootstrap Custom Properties

## Analogi: Perpustakaan Digital

CSS variables seperti papan pengumuman pusat di perpustakaan yang bisa diubah kapan saja. Jika Anda ingin mengganti warna semua rak buku dari biru menjadi hijau, Anda cukup mengubah satu catatan di papan pengumuman, dan semua rak akan berubah secara otomatis. Tanpa CSS variables, Anda harus mengecat setiap rak satu per satu. Bootstrap 5 menggunakan CSS custom properties untuk memudahkan kustomisasi tema.

## Penjelasan Detail

CSS variables (custom properties) adalah entitas yang menyimpan nilai CSS untuk digunakan kembali di seluruh dokumen. Sintaks: `--nama-variabel: nilai;` dideklarasikan di selector (biasanya `:root`), dan digunakan dengan `var(--nama-variabel)`. Bootstrap 5 memperkenalkan banyak CSS custom properties untuk warna, spacing, font, border-radius, shadow, dan lainnya. Contoh: `--bs-primary: #0d6efd;`, `--bs-body-bg: #fff;`, `--bs-border-radius: 0.375rem;`. Anda bisa mengubah tema Bootstrap hanya dengan me-override variabel-variabel ini tanpa memodifikasi file Bootstrap asli. CSS variables juga memungkinkan theming dinamis (misal: mode gelap) dengan JavaScript.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Variables Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        :root {
            --bs-primary: #6f42c1;
            --bs-success: #e83e8c;
            --bs-body-bg: #f8f9fa;
        }
    </style>
</head>
<body>
    <div class="container py-5">
        <h1>CSS Variables Bootstrap 5</h1>
        <p class="lead">Override variabel untuk kustomisasi tema tanpa mengubah file Bootstrap.</p>
        <button class="btn btn-primary">Primary (diubah jadi ungu)</button>
        <button class="btn btn-success">Success (diubah jadi pink)</button>
        <div class="alert alert-info mt-3">
            Bootstrap 5 menggunakan prefix <code>--bs-*</code> untuk custom properties.
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- CSS variables: `--nama: nilai` dideklarasikan di `:root`, dipanggil dengan `var(--nama)`
- Bootstrap 5 menggunakan prefix `--bs-*` untuk semua custom properties
- CSS variables memungkinkan kustomisasi tema tanpa mengubah file Bootstrap
- Mendukung dynamic theming (mode gelap, multiple themes) via JavaScript
