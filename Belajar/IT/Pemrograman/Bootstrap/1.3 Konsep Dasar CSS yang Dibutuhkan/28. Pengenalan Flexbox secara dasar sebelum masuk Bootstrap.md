# Pengenalan Flexbox Secara Dasar Sebelum Masuk Bootstrap

## Analogi: Perpustakaan Digital

Flexbox seperti rak buku ajaib yang bisa mengatur buku-buku secara otomatis. Anda bisa menentukan apakah buku berjejer dari kiri ke kanan (row) atau dari atas ke bawah (column). Rak ini bisa merapikan buku dengan jarak yang sama, menengahkan buku di rak, atau membalik urutan buku. Bootstrap 5 menggunakan Flexbox sebagai fondasi grid system dan hampir semua komponennya.

## Penjelasan Detail

Flexbox (Flexible Box) adalah model layout CSS satu dimensi yang mendistribusikan ruang dan menyelaraskan konten dalam suatu container. Container flex memiliki sumbu utama (main axis) dan sumbu silang (cross axis). Properti utama Flexbox: `display: flex` pada container, `flex-direction` (row/column), `justify-content` (penyelarasan sumbu utama), `align-items` (penyelarasan sumbu silang), dan `flex-wrap` (membungkus konten). Bootstrap mengimplementasikan Flexbox melalui class utility `d-flex`, `flex-row`, `flex-column`, `justify-content-center`, `align-items-center`, dan lainnya. Grid system Bootstrap menggunakan Flexbox untuk mengatur kolom. Memahami Flexbox dasar sangat membantu saat Anda perlu kustomisasi layout Bootstrap di luar grid standar.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Pengenalan Flexbox</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Flexbox Dasar</h1>
        <h5>justify-content-center + align-items-center</h5>
        <div class="d-flex justify-content-center align-items-center bg-light rounded p-3" style="height: 150px;">
            <div class="bg-primary text-white p-3 mx-1 rounded">1</div>
            <div class="bg-success text-white p-3 mx-1 rounded">2</div>
            <div class="bg-warning p-3 mx-1 rounded">3</div>
        </div>
        <h5 class="mt-4">flex-column</h5>
        <div class="d-flex flex-column bg-light rounded p-3 align-items-center">
            <div class="bg-primary text-white p-3 my-1 rounded">Atas</div>
            <div class="bg-success text-white p-3 my-1 rounded">Tengah</div>
            <div class="bg-warning p-3 my-1 rounded">Bawah</div>
        </div>
        <p class="mt-3">Bootstrap 5 built-in dengan Flexbox. Class: <code>d-flex</code>, <code>justify-content-*</code>, <code>align-items-*</code></p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Flexbox adalah layout 1 dimensi (row atau column)
- Properti utama: justify-content (main axis), align-items (cross axis)
- Bootstrap 5 menggunakan Flexbox untuk grid dan komponen
- Class Bootstrap: `d-flex`, `flex-row`, `justify-content-center`, `align-items-center`
