# Memahami Konsep Responsive Design Secara Umum

## Analogi: Perpustakaan Digital

Responsive design seperti perpustakaan yang bisa menata ulang rak bukunya secara otomatis tergantung ukuran ruangan. Di ruang besar (desktop), rak buku berjejer dalam beberapa baris. Di ruang sedang (tablet), rak buku berjejer lebih rapat. Di ruang kecil (ponsel), rak buku ditumpuk vertikal. Pengunjung tetap bisa mengakses semua buku dengan nyaman tanpa perlu scroll horizontal atau zoom.

## Penjelasan Detail

Responsive design adalah pendekatan desain web yang membuat halaman web tampil optimal di semua perangkat dan ukuran layar — dari desktop 1920px hingga ponsel 320px. Tiga komponen utama responsive design: flexible grid (layout berbasis persentase), flexible images (gambar yang menyesuaikan ukuran), dan media queries (CSS breakpoints untuk kondisi layar tertentu). Bootstrap menerapkan responsive design melalui grid system 12 kolom dengan breakpoints: xs (<576px), sm (>=576px), md (>=768px), lg (>=992px), xl (>=1200px), xxl (>=1400px). Class seperti `col-md-6` berarti kolom mengambil 6/12 lebar (50%) pada layar md ke atas, dan 100% pada layar lebih kecil.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Design</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <div class="container py-5">
        <h1>Responsive Design</h1>
        <p class="lead">Layout menyesuaikan ukuran layar secara otomatis.</p>
        <div class="row">
            <div class="col-12 col-md-6 col-lg-3 mb-3">
                <div class="card text-center">
                    <div class="card-body">
                        <h5 class="card-title">Kolom 1</h5>
                        <p class="card-text">100% / 50% / 25%</p>
                    </div>
                </div>
            </div>
            <div class="col-12 col-md-6 col-lg-3 mb-3">
                <div class="card text-center">
                    <div class="card-body">
                        <h5 class="card-title">Kolom 2</h5>
                        <p class="card-text">100% / 50% / 25%</p>
                    </div>
                </div>
            </div>
            <div class="col-12 col-md-6 col-lg-3 mb-3">
                <div class="card text-center">
                    <div class="card-body">
                        <h5 class="card-title">Kolom 3</h5>
                        <p class="card-text">100% / 50% / 25%</p>
                    </div>
                </div>
            </div>
            <div class="col-12 col-md-6 col-lg-3 mb-3">
                <div class="card text-center">
                    <div class="card-body">
                        <h5 class="card-title">Kolom 4</h5>
                        <p class="card-text">100% / 50% / 25%</p>
                    </div>
                </div>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Responsive design = tampil optimal di semua ukuran layar
- Bootstrap menggunakan grid system 12 kolom dengan 6 breakpoints
- Kombinasi class kolom (col-md-6 col-lg-3) untuk layout responsive
- Tanpa responsive design, website tidak nyaman diakses via mobile
