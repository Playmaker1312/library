# Pengenalan Media Queries dalam CSS

## Analogi: Perpustakaan Digital

Media queries seperti aturan bersyarat di perpustakaan: "Jika ruangan lebih lebar dari 768px, buku bisa diletakkan dalam dua baris; jika kurang, cukup satu baris." Aturan ini menyesuaikan tata letak berdasarkan kondisi lingkungan. Media queries memungkinkan perpustakaan digital Anda mengubah tampilan secara otomatis tergantung lebar layar, resolusi, atau bahkan preferensi pengguna seperti mode gelap.

## Penjelasan Detail

Media queries adalah fitur CSS3 yang memungkinkan penerapan gaya CSS berdasarkan kondisi tertentu seperti lebar viewport, tinggi viewport, orientasi perangkat, atau resolusi. Sintaks dasar: `@media (condition) { ... }`. Contoh: `@media (max-width: 768px) { .sidebar { display: none; } }`. Bootstrap menggunakan media queries di balik layar untuk breakpoints grid system-nya. Bootstrap juga menyediakan utility classes responsive seperti `d-none d-md-block` (sembunyi di mobile, tampil di md ke atas). Breakpoints Bootstrap: sm (576px), md (768px), lg (992px), xl (1200px), xxl (1400px). Dengan media queries, Anda bisa membuat pengaturan tampilan yang berbeda untuk setiap ukuran layar tanpa mengubah HTML.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Media Queries</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .mq-demo { padding: 20px; text-align: center; border-radius: 8px; }
        @media (max-width: 575.98px) { .mq-demo { background: #dc3545; color: white; } }
        @media (min-width: 576px) and (max-width: 991.98px) { .mq-demo { background: #ffc107; } }
        @media (min-width: 992px) { .mq-demo { background: #198754; color: white; } }
    </style>
</head>
<body>
    <div class="container py-5">
        <h1>Media Queries CSS</h1>
        <div class="mq-demo">
            <h3>Warna berubah berdasarkan lebar layar!</h3>
            <p class="mb-0">Resize browser untuk melihat efeknya.</p>
        </div>
        <p class="mt-3">Bootstrap breakpoints: sm=576px, md=768px, lg=992px, xl=1200px, xxl=1400px</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Media queries mengubah CSS berdasarkan kondisi layar (lebar, orientasi, dll)
- Bootstrap menggunakan media queries untuk grid breakpoints
- Utility classes responsive Bootstrap: `d-none d-md-block`, `col-md-6`, dll
- Media queries bisa menggunakan min-width (mobile-first) atau max-width
