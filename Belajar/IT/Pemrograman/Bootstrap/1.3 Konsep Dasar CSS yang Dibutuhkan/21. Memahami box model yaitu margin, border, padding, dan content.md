# Memahami Box Model yaitu Margin, Border, Padding, dan Content

## Analogi: Perpustakaan Digital

Box model CSS seperti buku yang dibungkus dalam beberapa lapisan. Content adalah isi buku (teks/gambar). Padding adalah lapisan busa pelindung di dalam sampul buku. Border adalah sampul bukunya sendiri. Margin adalah jarak antara buku ini dengan buku lain di rak. Setiap elemen HTML adalah kotak dengan keempat lapisan ini, dan Bootstrap menyediakan utility classes untuk mengontrol setiap lapisan.

## Penjelasan Detail

Box model adalah konsep fundamental CSS yang menyatakan bahwa setiap elemen HTML adalah kotak (box) yang terdiri dari empat area: content (isi), padding (ruang dalam antara konten dan border), border (garis tepi), dan margin (ruang luar antara elemen dengan elemen lain). Bootstrap menyediakan utility classes untuk padding (`p-*`, `pt-*`, `pb-*`, `ps-*`, `pe-*`) dan margin (`m-*`, `mt-*`, `mb-*`, `ms-*`, `me-*`) dengan skala 0-5 dan auto. Nilai 0 tidak ada spasi, 5 adalah spasi terbesar (3rem). Bootstrap juga memiliki class `border`, `rounded`, `shadow` untuk mengontrol border dan efek visual. Memahami box model sangat penting untuk mengatur tata letak dengan Bootstrap.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Box Model CSS</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
    <style>
        .box-model-demo { background-color: #e9ecef; }
        .content { background-color: #0d6efd; color: white; padding: 10px; }
        .padding { background-color: #ffc107; padding: 10px; }
        .border-area { background-color: #198754; padding: 10px; }
        .margin { background-color: #dc3545; padding: 10px; }
    </style>
</head>
<body>
    <div class="container py-5">
        <h1>CSS Box Model</h1>
        <div class="margin text-white text-center rounded">Margin (merah)
            <div class="border-area rounded">Border (hijau)
                <div class="padding">Padding (kuning)
                    <div class="content rounded">Content (biru)</div>
                </div>
            </div>
        </div>
        <p class="mt-3">Gunakan class Bootstrap: <code>p-*</code>, <code>m-*</code>, <code>border</code></p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Box model: content > padding > border > margin (dari dalam ke luar)
- Bootstrap menyediakan utility class `p-*`, `m-*`, `border`, `rounded`
- Skala Bootstrap 0-5: 0=0, 1=0.25rem, 2=0.5rem, 3=1rem, 4=1.5rem, 5=3rem
- Padding mempengaruhi ukuran total elemen, margin tidak
