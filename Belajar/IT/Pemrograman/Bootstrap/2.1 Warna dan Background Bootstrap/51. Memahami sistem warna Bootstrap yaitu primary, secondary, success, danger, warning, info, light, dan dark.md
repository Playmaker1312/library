# Memahami sistem warna Bootstrap yaitu primary, secondary, success, danger, warning, info, light, dan dark

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan digital yang menggunakan label warna berbeda untuk setiap kategori buku. Label primary (biru) untuk buku utama, success (hijau) untuk buku yang tersedia, danger (merah) untuk buku rusak, warning (kuning) untuk buku hampir jatuh tempo. Sistem ini memudahkan pengunjung mengenali status buku hanya dari warnanya. Bootstrap menggunakan pendekatan seragam dengan 8 warna semantic yang konsisten di semua komponen.

## Penjelasan Detail

Bootstrap memiliki sistem warna berbasis makna (semantic color) yang terdiri dari primary, secondary, success, danger, warning, info, light, dan dark. Warna primary biasanya biru dan mewakili warna utama brand atau tema. Secondary adalah abu-abu sebagai warna pendukung. Success (hijau) mengindikasikan operasi berhasil, danger (merah) untuk peringatan error, warning (kuning) untuk perhatian, info (biru muda) untuk informasi, light (putih/abu terang) untuk latar belakang terang, dan dark (hitam/abu gelap) untuk teks atau elemen gelap. Setiap warna tersedia dalam bentuk class untuk background, teks, border, dan komponen. Warna-warna ini konsisten di semua komponen seperti tombol, alert, badge, dan card. Bootstrap juga menyediakan variasi subtle dan emphasis pada versi 5.3.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Sistem Warna Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Warna Bootstrap</h1>
        <div class="d-flex flex-wrap gap-2 mb-3">
            <span class="badge bg-primary">Primary</span>
            <span class="badge bg-secondary">Secondary</span>
            <span class="badge bg-success">Success</span>
            <span class="badge bg-danger">Danger</span>
            <span class="badge bg-warning text-dark">Warning</span>
            <span class="badge bg-info text-dark">Info</span>
            <span class="badge bg-light text-dark">Light</span>
            <span class="badge bg-dark">Dark</span>
        </div>
        <div class="p-3 mb-2 bg-primary text-white">bg-primary</div>
        <div class="p-3 mb-2 bg-success text-white">bg-success</div>
        <div class="p-3 mb-2 bg-danger text-white">bg-danger</div>
        <div class="p-3 mb-2 bg-warning text-dark">bg-warning</div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Warna Bootstrap bersifat semantic, setiap warna memiliki makna fungsional tertentu
- Tersedia 8 warna dasar: primary, secondary, success, danger, warning, info, light, dan dark
- Class warna bisa digunakan di background (bg-*), teks (text-*), border (border-*), dan komponen
