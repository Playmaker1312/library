# Cara mengaktifkan dark mode menggunakan atribut data-bs-theme

## Analogi: Perpustakaan Digital

Saklar lampu utama perpustakaan dapat mengubah seluruh pencahayaan ruangan dari terang ke gelap. Cukup dengan satu sentuhan saklar, semua rak, meja, dan area baca berubah suasananya. Bootstrap menggunakan atribut `data-bs-theme` sebagai saklar untuk mengubah tema seluruh halaman atau bagian tertentu.

## Penjelasan Detail

Atribut `data-bs-theme` diterapkan pada elemen HTML untuk mengaktifkan color mode. Nilai yang tersedia adalah `light` (default) dan `dark`. Jika diterapkan pada elemen `<html>`, seluruh halaman akan mengikuti tema tersebut. Atribut juga bisa diterapkan pada elemen spesifik seperti `<div>` atau `<section>` untuk mengubah tema hanya di area tertentu. Bootstrap menggunakan CSS custom properties untuk menangani perubahan warna secara otomatis. Tema gelap mengubah warna background menjadi warna gelap, teks menjadi terang, dan semua komponen menyesuaikan. Dark mode juga dapat diaktifkan berdasarkan preferensi sistem menggunakan media query CSS `prefers-color-scheme`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dark Mode Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Aktifkan Dark Mode</h1>
        <div class="mb-3">
            <button class="btn btn-primary" onclick="toggleTheme('light')">Light</button>
            <button class="btn btn-dark" onclick="toggleTheme('dark')">Dark</button>
        </div>
        <div id="content" data-bs-theme="light" class="p-4 rounded border mb-3">
            <h2>Area dengan data-bs-theme</h2>
            <p>Teks dan komponen di sini mengikuti tema area ini.</p>
            <button class="btn btn-outline-primary">Tombol Outline</button>
            <div class="alert alert-warning mt-2">Alert warning dalam area ini.</div>
        </div>
        <form>
            <div class="mb-2">
                <label class="form-label">Email</label>
                <input class="form-control" placeholder="nama@email.com">
            </div>
            <div class="form-check form-switch">
                <input class="form-check-input" type="checkbox" id="darkSwitch" onchange="document.documentElement.setAttribute('data-bs-theme', this.checked ? 'dark' : 'light')">
                <label class="form-check-label" for="darkSwitch">Toggle Dark Mode</label>
            </div>
        </form>
    </div>
    <script>
        function toggleTheme(mode) {
            document.getElementById('content').setAttribute('data-bs-theme', mode);
        }
    </script>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Atribut `data-bs-theme` menerima nilai `light` atau `dark`
- Bisa diterapkan pada elemen root (html) atau komponen spesifik
- Dark mode mengubah semua warna secara otomatis melalui CSS custom properties
