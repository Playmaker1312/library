# Menggunakan text color utilities secara mendalam dengan semua variasi warna

## Analogi: Perpustakaan Digital

Seperti perpustakaan yang menggunakan warna huruf pada label rak untuk menunjukkan status, Bootstrap menyediakan class warna teks. Label biru untuk buku referensi, hijau untuk buku tersedia, merah untuk buku hilang. Pustakawan cukup memilih warna teks dari palet yang tersedia tanpa harus mengatur CSS manual.

## Penjelasan Detail

Class text color utility Bootstrap menggunakan format `text-{warna}` untuk mengubah warna teks elemen. Variasi meliputi text-primary, text-secondary, text-success, text-danger, text-warning, text-info, text-light, text-dark, text-body, text-muted, text-white, dan text-black-50. Bootstrap juga menyediakan text-opacity-* (25, 50, 75, 100) untuk mengatur opacity teks. Class text-reset mewarisi warna dari parent, text-decoration-none menghilangkan underline. Untuk dark mode, gunakan text-light pada latar gelap dan text-dark pada latar terang. Kombinasi dengan background sangat penting untuk aksesibilitas dan kontras.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Text Color Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Text Color Utilities</h1>
        <p class="text-primary">.text-primary</p>
        <p class="text-secondary">.text-secondary</p>
        <p class="text-success">.text-success</p>
        <p class="text-danger">.text-danger</p>
        <p class="text-warning bg-dark p-2">.text-warning</p>
        <p class="text-info">.text-info</p>
        <p class="text-light bg-dark p-2">.text-light</p>
        <p class="text-dark">.text-dark</p>
        <p class="text-body">.text-body</p>
        <p class="text-muted">.text-muted</p>
        <p class="text-white bg-dark p-2">.text-white</p>
        <p class="text-black-50">.text-black-50</p>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Class text-{warna} mengubah warna teks elemen secara instan
- Tersedia text-muted untuk teks secondary yang redup
- Kombinasikan dengan background yang tepat untuk menjaga kontras dan aksesibilitas
