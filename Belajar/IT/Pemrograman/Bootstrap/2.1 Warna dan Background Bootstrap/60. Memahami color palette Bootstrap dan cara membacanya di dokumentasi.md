# Memahami color palette Bootstrap dan cara membacanya di dokumentasi

## Analogi: Perpustakaan Digital

Setiap perpustakaan memiliki katalog warna yang menunjukkan semua cat yang tersedia untuk rak dan label. Katalog ini menampilkan kode warna, nama, dan contoh visual. Bootstrap memiliki dokumentasi color palette yang serupa, menampilkan semua warna yang tersedia, variasi tint dan shade, serta kode hex-nya untuk referensi pengembang.

## Penjelasan Detail

Dokumentasi Bootstrap menyediakan color palette lengkap yang dapat diakses di halaman Utilities > Colors. Palette menampilkan warna utama (primary, secondary, dll) beserta variasi tint (lebih terang) dan shade (lebih gelap) dalam skala 100-900. Warna-warna ini didasarkan pada CSS variables yang memudahkan kustomisasi. Setiap warna memiliki kode hex, RGB, dan HSL yang tercantum. Dokumentasi juga menunjukkan cara menggunakan warna dalam class utilities (bg-*, text-*, border-*), komponen, dan CSS kustom. Bootstrap juga menyediakan warna untuk kebutuhan spesifik seperti body, emphasis, dan muted. Memahami color palette penting untuk konsistensi desain dan kustomisasi tema.

## Poin Penting
- Color palette Bootstrap terdiri dari 8 warna semantic dengan variasi tint dan shade
- Setiap warna memiliki kode hex, RGB, dan CSS variables yang tercantum di dokumentasi
- Dokumentasi color palette ada di halaman Utilities > Colors pada getbootstrap.com
