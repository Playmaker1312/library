# Pengenalan color mode yaitu light mode dan dark mode pada Bootstrap 5.3

## Analogi: Perpustakaan Digital

Perpustakaan kini memiliki dua mode pencahayaan: mode terang untuk siang hari dengan lampu putih terang, dan mode gelap untuk malam hari dengan lampu redup. Pengunjung bisa memilih mode yang nyaman bagi mata mereka. Bootstrap 5.3 memperkenalkan sistem color mode serupa yang dapat diubah sesuai preferensi pengguna.

## Penjelasan Detail

Bootstrap 5.3 menghadirkan dukungan color mode bawaan yang memungkinkan tema gelap (dark mode) dan terang (light mode). Sistem ini menggunakan CSS custom properties dan atribut `data-bs-theme` pada elemen root. Secara default, Bootstrap menggunakan light mode. Dark mode mengubah warna background menjadi gelap dan teks menjadi terang, mengurangi ketegangan mata di lingkungan redup. Semua komponen Bootstrap secara otomatis menyesuaikan diri dengan color mode yang aktif. Pengembang dapat mengaktifkan dark mode secara global atau per-komponen. Sistem ini juga mendeteksi preferensi sistem pengguna melalui CSS `prefers-color-scheme`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Color Mode Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container" id="demo">
        <h1>Color Mode Demo</h1>
        <div class="mb-3">
            <button class="btn btn-primary" onclick="document.documentElement.setAttribute('data-bs-theme','light')">Light Mode</button>
            <button class="btn btn-dark" onclick="document.documentElement.setAttribute('data-bs-theme','dark')">Dark Mode</button>
        </div>
        <div class="card p-4">
            <h2 class="card-title">Contoh Card</h2>
            <p class="card-text">Card ini akan menyesuaikan warna dengan mode yang dipilih.</p>
            <button class="btn btn-success">Tombol Sukses</button>
        </div>
        <div class="alert alert-info mt-3">Alert info juga menyesuaikan tema.</div>
        <form class="mt-3">
            <input class="form-control mb-2" placeholder="Input teks">
            <select class="form-select">
                <option>Pilih opsi</option>
            </select>
        </form>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Color mode menggunakan atribut `data-bs-theme` pada elemen html
- Bootstrap mendukung light mode (default) dan dark mode
- Semua komponen otomatis menyesuaikan dengan color mode aktif
