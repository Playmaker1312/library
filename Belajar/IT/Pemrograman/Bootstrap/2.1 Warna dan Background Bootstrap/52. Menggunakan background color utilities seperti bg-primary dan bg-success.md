# Menggunakan background color utilities seperti bg-primary dan bg-success

## Analogi: Perpustakaan Digital

Seperti rak buku yang dicat dengan warna berbeda untuk menunjukkan bagian tertentu, Bootstrap menyediakan class background untuk mewarnai latar belakang elemen. Rak biru (bg-primary) untuk buku referensi utama, rak hijau (bg-success) untuk buku yang tersedia dipinjam. Petugas perpustakaan cukup mengecat rak dengan warna yang sudah ditentukan tanpa harus meracik cat sendiri.

## Penjelasan Detail

Class background utility Bootstrap menggunakan format `bg-{warna}` dan dapat diterapkan ke elemen HTML mana pun. Warna yang tersedia meliputi bg-primary (biru), bg-secondary (abu-abu), bg-success (hijau), bg-danger (merah), bg-warning (kuning), bg-info (biru muda), bg-light (putih/terang), bg-dark (hitam/gelap), dan bg-white (putih murni). Class ini mengatur properti CSS `background-color`. Saat menggunakan bg-warning atau bg-info yang terang, Anda perlu menambahkan class `text-dark` agar teks tetap terbaca. Bootstrap juga menyediakan bg-transparent dan bg-body untuk fleksibilitas lebih.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Background Color Utilities</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Background Color Utilities</h1>
        <div class="p-3 mb-2 bg-primary text-white">.bg-primary</div>
        <div class="p-3 mb-2 bg-secondary text-white">.bg-secondary</div>
        <div class="p-3 mb-2 bg-success text-white">.bg-success</div>
        <div class="p-3 mb-2 bg-danger text-white">.bg-danger</div>
        <div class="p-3 mb-2 bg-warning text-dark">.bg-warning</div>
        <div class="p-3 mb-2 bg-info text-dark">.bg-info</div>
        <div class="p-3 mb-2 bg-light text-dark">.bg-light</div>
        <div class="p-3 mb-2 bg-dark text-white">.bg-dark</div>
        <div class="p-3 mb-2 bg-body text-dark">.bg-body</div>
        <div class="p-3 mb-2 bg-white text-dark border">.bg-white</div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan class `bg-{warna}` untuk memberi warna latar belakang elemen
- Warna terang seperti warning dan info membutuhkan text-dark untuk kontras
- Tersedia juga bg-transparent, bg-body, dan bg-white untuk variasi tambahan
