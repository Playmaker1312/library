# Teknik hide dan show elemen di breakpoint tertentu menggunakan d-none d-md-block

## Analogi: Perpustakaan Digital

Perpustakaan digital mungkin menyembunyikan panel navigasi samping di layar ponsel karena sempit, tetapi menampilkannya di layar desktop yang lebih luas. Sebaliknya, tombol "hamburger menu" hanya muncul di layar kecil. Bootstrap menyediakan kelas utility `d-*` untuk mengontrol visibilitas elemen secara responsif.

## Penjelasan Detail

Kelas `d-none` menyembunyikan elemen, sementara `d-{breakpoint}-block` menampilkannya di breakpoint tertentu. Kombinasi seperti `d-none d-md-block` berarti "sembunyikan secara default, tampilkan di breakpoint md ke atas". Bootstrap juga menyediakan `d-*-none`, `d-*-inline`, `d-*-flex`, dan `d-*-table`. Untuk visibilitas terkait aksesibilitas, gunakan `visible` atau `invisible` yang menyembunyikan secara visual tanpa menghapus dari layout. Kelas display responsif sangat berguna untuk navigasi, sidebar, dan elemen dekoratif.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Hide Show Breakpoint</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <nav class="navbar navbar-light bg-light px-3">
    <!-- Tombol hamburger hanya di mobile -->
    <button class="navbar-toggler d-md-none" type="button">☰</button>
    <span class="fw-bold">My App</span>
    <!-- Navigasi desktop hanya di md ke atas -->
    <ul class="nav d-none d-md-flex ms-auto">
      <li class="nav-item"><a class="nav-link" href="#">Home</a></li>
      <li class="nav-item"><a class="nav-link" href="#">About</a></li>
      <li class="nav-item"><a class="nav-link" href="#">Contact</a></li>
    </ul>
  </nav>
  <div class="container mt-3">
    <!-- Sidebar hanya di desktop -->
    <div class="row">
      <aside class="d-none d-lg-block col-lg-3 bg-light">Sidebar Desktop</aside>
      <main class="col-12 col-lg-9">Konten utama</main>
    </div>
    <!-- Info hanya di mobile -->
    <div class="d-block d-md-none alert alert-info mt-3">
      Anda menggunakan perangkat mobile
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `d-none d-*-block` untuk menampilkan elemen mulai breakpoint tertentu
- Gunakan `d-*-none d-*-block` untuk kontrol yang lebih spesifik
- Hindari menyembunyikan elemen penting untuk aksesibilitas tanpa alternatif
