# Strategi menggunakan breakpoints secara efektif dalam project nyata

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki beberapa rak yang diatur berdasarkan ukuran buku. Rak kecil untuk buku saku, rak sedang untuk buku biasa, dan rak besar untuk ensiklopedia. Setiap rak baru dibangun di atas rak sebelumnya, bukan terpisah. Breakpoints Bootstrap bekerja dengan prinsip serupa, di mana setiap breakpoint yang lebih besar mewarisi gaya dari yang lebih kecil.

## Penjelasan Detail

Bootstrap menyediakan enam breakpoints: `xs` (default, <576px), `sm` (>=576px), `md` (>=768px), `lg` (>=992px), `xl` (>=1200px), dan `xxl` (>=1400px). Strategi efektif meliputi: memilih breakpoint berdasarkan konten bukan perangkat, menggunakan minimal breakpoint yang diperlukan, dan menguji tata letak di setiap breakpoint. Hindari membuat desain terpisah untuk setiap breakpoint; fokus pada titik di mana tata letak "pecah" dan perlu diubah.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Breakpoint Strategy</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container">
    <!-- Sidebar + konten utama -->
    <div class="row">
      <aside class="col-12 col-md-4 col-xl-3">Sidebar</aside>
      <main class="col-12 col-md-8 col-xl-9">Konten utama</main>
    </div>
    <!-- Card grid yang pecah di breakpoint berbeda -->
    <div class="row row-cols-2 row-cols-sm-3 row-cols-lg-4 row-cols-xl-6">
      <div class="col">Card</div>
      <div class="col">Card</div>
      <div class="col">Card</div>
      <div class="col">Card</div>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- Pilih breakpoint berdasarkan konten, bukan perangkat spesifik
- Gunakan `row-cols-*` untuk grid yang fleksibel secara otomatis
- Uji tata letak di setiap breakpoint untuk memastikan konsistensi
