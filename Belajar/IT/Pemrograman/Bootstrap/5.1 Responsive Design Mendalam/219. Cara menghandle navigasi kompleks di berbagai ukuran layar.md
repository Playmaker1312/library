# Cara menghandle navigasi kompleks di berbagai ukuran layar

## Analogi: Perpustakaan Digital

Sebuah perpustakaan digital memiliki menu besar: kategori buku, penulis favorit, daftar bacaan, pengaturan, dan profil. Di desktop, semua item bisa ditampilkan di navbar horizontal. Di tablet, beberapa item mungkin dipindahkan ke dropdown. Di ponsel, semua item harus disembunyikan di balik tombol hamburger. Navigasi kompleks memerlukan strategi adaptif yang matang.

## Penjelasan Detail

Bootstrap menyediakan beberapa komponen untuk navigasi responsif: `navbar` dengan `navbar-expand-*`, `nav` dengan `flex-column` dan `flex-*-row`, `dropdown`, `offcanvas`, dan `collapse`. Strategi umum meliputi: menggunakan `navbar-expand-lg` untuk mengontrol kapan navigasi menjadi collapse, menggunakan `dropdown` untuk sub-menu di desktop, menggunakan `offcanvas` untuk navigasi full-screen di mobile, dan menggunakan `nav-pills` untuk navigasi tab yang vertikal di mobile.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Responsive Navigation</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <!-- Navbar dengan offcanvas untuk mobile -->
  <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container-fluid">
      <a class="navbar-brand" href="#">Library</a>
      <button class="navbar-toggler" type="button" data-bs-toggle="offcanvas" data-bs-target="#offcanvasNavbar">
        <span class="navbar-toggler-icon"></span>
      </button>
      <div class="offcanvas offcanvas-end" id="offcanvasNavbar">
        <div class="offcanvas-header">
          <h5 class="offcanvas-title">Menu</h5>
          <button type="button" class="btn-close" data-bs-dismiss="offcanvas"></button>
        </div>
        <div class="offcanvas-body">
          <ul class="navbar-nav justify-content-end flex-grow-1 pe-3">
            <li class="nav-item"><a class="nav-link active" href="#">Home</a></li>
            <li class="nav-item dropdown">
              <a class="nav-link dropdown-toggle" href="#" data-bs-toggle="dropdown">Kategori</a>
              <ul class="dropdown-menu">
                <li><a class="dropdown-item" href="#">Fiksi</a></li>
                <li><a class="dropdown-item" href="#">Non-Fiksi</a></li>
                <li><hr class="dropdown-divider"></li>
                <li><a class="dropdown-item" href="#">Semua</a></li>
              </ul>
            </li>
            <li class="nav-item"><a class="nav-link" href="#">About</a></li>
          </ul>
        </div>
      </div>
    </div>
  </nav>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan `navbar-expand-lg` untuk mengontrol breakpoint collapse
- Manfaatkan `offcanvas` untuk navigasi mobile yang lebih baik
- Gunakan `dropdown` untuk mengelompokkan item di desktop
