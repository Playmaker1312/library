# Cara membuat typography yang responsif menggunakan responsive font size

## Analogi: Perpustakaan Digital

Perpustakaan digital menyesuaikan ukuran judul buku dan teks deskripsi berdasarkan layar pembaca. Di ponsel, judul mungkin berukuran 20px, tetapi di layar desktop yang lebih luas, judul bisa mencapai 36px. Bootstrap menyediakan fitur Responsive Font Size (RFS) untuk mengotomatiskan penyesuaian ukuran font secara proporsional.

## Penjelasan Detail

RFS adalah sistem yang terintegrasi dalam Bootstrap yang secara otomatis menskalakan `font-size` properti menggunakan kombinasi `calc()` dan `vw` units. Aktifkan RFS dengan mengatur `$enable-rfs: true` di Sass. Kelas heading seperti `h1` hingga `h6`, serta kelas `display-1` hingga `display-6` sudah menggunakan RFS secara default. RFS memastikan teks tidak terlalu kecil di mobile atau terlalu besar di desktop tanpa perlu menulis media query manual.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Responsive Typography</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    /* Contoh jika ingin menonaktifkan RFS */
    .no-rfs {
      font-size: 2.5rem; /* Ukuran tetap */
    }
    /* Contoh manual fluid typography */
    .fluid-text {
      font-size: clamp(1rem, 2.5vw, 2rem);
    }
  </style>
</head>
<body>
  <div class="container mt-4">
    <!-- Menggunakan heading Bootstrap dengan RFS -->
    <h1>Heading 1 dengan RFS</h1>
    <h2>Heading 2 dengan RFS</h2>
    <h3>Heading 3 dengan RFS</h3>
    <p class="lead">Lead paragraph yang juga menggunakan RFS untuk ukuran yang proporsional.</p>
    <!-- Display headings -->
    <h1 class="display-1">Display 1</h1>
    <h1 class="display-4">Display 4</h1>
    <!-- Fluid manual -->
    <p class="fluid-text">Teks dengan fluid typography manual menggunakan clamp().</p>
  </div>
</body>
</html>
```

## Poin Penting
- RFS aktif secara default di Bootstrap 5 untuk semua heading dan display
- Gunakan `$enable-rfs: false` jika ingin ukuran font tetap
- Kombinasikan dengan `clamp()` untuk fluid typography kustom
