# Menggunakan fluid typography dengan CSS clamp bersama Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital ingin judul buku terlihat proporsional di semua layar, dari ponsel 320px hingga monitor 2560px. Daripada menggunakan 5 breakpoint berbeda, perpustakaan menggunakan fungsi matematika yang menghitung ukuran font secara mulus berdasarkan lebar viewport. CSS `clamp()` adalah alat yang tepat untuk ini.

## Penjelasan Detail

Fungsi CSS `clamp()` mengambil tiga nilai: nilai minimum, nilai preferensi (fluid), dan nilai maksimum. Contoh: `font-size: clamp(1rem, 2vw + 1rem, 3rem)` menghasilkan ukuran yang bervariasi antara 1rem dan 3rem tergantung viewport. Bootstrap RFS sebenarnya menggunakan teknik serupa. Anda bisa mengkombinasikan `clamp()` dengan utility Bootstrap atau menulisnya di CSS kustom untuk kontrol yang lebih presisi.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS Clamp Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    .fluid-heading {
      font-size: clamp(1.5rem, 4vw + 0.5rem, 3.5rem);
      line-height: 1.2;
    }
    .fluid-body {
      font-size: clamp(0.875rem, 1vw + 0.5rem, 1.125rem);
    }
    .fluid-container {
      width: clamp(300px, 80vw, 1400px);
      margin: 0 auto;
    }
    .fluid-padding {
      padding: clamp(1rem, 3vw, 3rem);
    }
  </style>
</head>
<body>
  <div class="fluid-container">
    <h1 class="fluid-heading mt-4">Judul Fluid dengan Clamp</h1>
    <p class="fluid-body">Teks paragraf ini akan menyesuaikan ukuran secara mulus dari 0.875rem hingga 1.125rem tergantung lebar viewport. Kombinasikan dengan kelas Bootstrap seperti text-muted untuk hasil maksimal.</p>
    <div class="fluid-padding bg-light rounded">
      <p class="mb-0">Div ini memiliki padding yang juga fluid menggunakan clamp().</p>
    </div>
  </div>
</body>
</html>
```

## Poin Penting
- `clamp(min, preferred, max)` memberikan fluid typography tanpa breakpoint
- Kombinasikan dengan Bootstrap utility classes untuk styling tambahan
- Gunakan untuk properti seperti font-size, padding, margin, dan width
