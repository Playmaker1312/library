# Teknik membuat tabel kompleks yang tetap usable di mobile

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki katalog buku dengan banyak kolom: judul, penulis, tahun, ISBN, genre, rating, dan status. Di layar desktop, semua kolom bisa ditampilkan berdampingan. Namun di ponsel yang sempit, menampilkan semua kolom akan membuat tabel tidak terbaca. Perpustakaan perlu strategi khusus untuk menyajikan data ini di layar kecil.

## Penjelasan Detail

Ada beberapa teknik untuk membuat tabel responsif dengan Bootstrap. Pertama, gunakan `.table-responsive` yang membungkus tabel dengan scroll horizontal di layar kecil. Kedua, gunakan kelas `d-none d-md-table-cell` untuk menyembunyikan kolom tertentu di mobile. Ketiga, format ulang baris tabel menjadi kartu di mobile menggunakan CSS dan utility classes. Keempat, gunakan `table-stacked` pattern di mana setiap baris menjadi blok vertikal. Pilih teknik berdasarkan jenis data dan frekuensi akses.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Responsive Table</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <style>
    @media (max-width: 767.98px) {
      .table-stacked tr {
        display: flex;
        flex-direction: column;
        border: 1px solid #dee2e6;
        margin-bottom: 1rem;
        padding: 0.75rem;
      }
      .table-stacked td {
        border: none !important;
        padding: 0.25rem 0 !important;
      }
      .table-stacked td::before {
        content: attr(data-label);
        font-weight: bold;
        display: inline-block;
        width: 80px;
      }
    }
  </style>
</head>
<body>
  <div class="container mt-4">
    <!-- Opsi 1: Horizontal Scroll -->
    <div class="table-responsive">
      <table class="table">
        <thead>
          <tr>
            <th>Judul</th><th>Penulis</th><th class="d-none d-md-table-cell">Tahun</th>
            <th class="d-none d-lg-table-cell">ISBN</th><th>Rating</th>
          </tr>
        </thead>
        <tbody>
          <tr>
            <td>Bootstrap 5</td><td>Mark Otto</td>
            <td class="d-none d-md-table-cell">2021</td>
            <td class="d-none d-lg-table-cell">123-456</td><td>5/5</td>
          </tr>
        </tbody>
      </table>
    </div>

    <!-- Opsi 2: Stacked Cards -->
    <h2>Tabel Stacked (Mobile)</h2>
    <table class="table table-stacked">
      <tbody>
        <tr>
          <td data-label="Judul">Bootstrap 5</td>
          <td data-label="Penulis">Mark Otto</td>
          <td data-label="Tahun">2021</td>
          <td data-label="Rating">5/5</td>
        </tr>
      </tbody>
    </table>
  </div>
</body>
</html>
```

## Poin Penting
- Gunakan `.table-responsive` untuk scroll horizontal di mobile
- Sembunyikan kolom kurang penting dengan `d-none d-*-table-cell`
- Pertimbangkan stacked cards pattern untuk data yang sering diakses di mobile
