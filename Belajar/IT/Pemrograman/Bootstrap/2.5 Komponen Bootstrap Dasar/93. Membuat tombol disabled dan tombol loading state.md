# Membuat tombol disabled dan tombol loading state

## Analogi: Perpustakaan Digital

Stempel perpustakaan bisa dalam kondisi tidak aktif (disabled) saat petugas tidak berwenang menggunakannya, atau dalam kondisi "memproses" (loading) saat sedang mencetak stempel. Tombol disabled terlihat redup dan tidak bisa diklik, sementara loading state menunjukkan proses sedang berjalan dengan animasi spinner.

## Penjelasan Detail

Tombol disabled menggunakan atribut `disabled` pada elemen `<button>` atau class `disabled` pada `<a>`. Tombol disabled menjadi redup, cursor berubah, dan tidak merespon klik. Loading state menggunakan kombinasi class `btn` dengan elemen spinner Bootstrap: `<span class="spinner-border spinner-border-sm"></span>` atau `<span class="spinner-grow spinner-grow-sm"></span>`. Loading state memberi umpan balik visual bahwa aksi sedang diproses. Kedua state penting untuk UX yang baik.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Disabled dan Loading Tombol</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Disabled & Loading State</h1>
        <h5>Disabled Buttons:</h5>
        <div class="d-flex gap-2 mb-4">
            <button class="btn btn-primary" disabled>Primary Disabled</button>
            <button class="btn btn-secondary" disabled>Secondary Disabled</button>
            <a href="#" class="btn btn-success disabled">Link Disabled</a>
            <button class="btn btn-outline-danger" disabled>Outline Disabled</button>
        </div>
        <h5>Loading State:</h5>
        <div class="d-flex gap-2 mb-4">
            <button class="btn btn-primary" disabled>
                <span class="spinner-border spinner-border-sm" role="status" aria-hidden="true"></span>
                Loading...
            </button>
            <button class="btn btn-success" disabled>
                <span class="spinner-grow spinner-grow-sm" role="status" aria-hidden="true"></span>
                Menyimpan...
            </button>
        </div>
        <h5>Tombol dengan Loading Toggle:</h5>
        <button class="btn btn-primary" id="loadingBtn" onclick="simulateLoading(this)">
            Klik untuk Loading
        </button>
    </div>
    <script>
        function simulateLoading(btn) {
            btn.disabled = true;
            btn.innerHTML = '<span class="spinner-border spinner-border-sm"></span> Memproses...';
            setTimeout(() => {
                btn.disabled = false;
                btn.innerHTML = 'Klik untuk Loading';
            }, 2000);
        }
    </script>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan atribut `disabled` untuk tombol non-aktif
- Loading state menggunakan spinner + disabled
- Beri umpan balik visual untuk meningkatkan UX
