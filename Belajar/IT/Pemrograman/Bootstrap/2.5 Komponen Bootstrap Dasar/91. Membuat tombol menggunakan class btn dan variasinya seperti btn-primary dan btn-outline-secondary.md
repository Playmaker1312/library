# Membuat tombol menggunakan class btn dan variasinya seperti btn-primary dan btn-outline-secondary

## Analogi: Perpustakaan Digital

Tombol di perpustakaan digital seperti stempel yang digunakan petugas: stempel biru untuk peminjaman (btn-primary), stempel hijau untuk pengembalian (btn-success), stempel merah untuk denda (btn-danger). Setiap stempel memiliki warna dan gaya yang berbeda untuk menunjukkan fungsinya. Bootstrap menyediakan class tombol dengan berbagai variasi warna dan gaya.

## Penjelasan Detail

Class `btn` adalah class dasar untuk membuat tombol Bootstrap. Dikombinasikan dengan `btn-{warna}` untuk variasi warna: btn-primary, btn-secondary, btn-success, btn-danger, btn-warning, btn-info, btn-light, btn-dark, dan btn-link. Tersedia juga `btn-outline-{warna}` untuk tombol dengan gaya outline (border saja tanpa background). Tombol bisa diterapkan pada elemen `<button>`, `<a>`, atau `<input>`. Ukuran tombol: btn-lg (besar) dan btn-sm (kecil). Class `btn` mengatur padding, border, border-radius, dan hover effects.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tombol Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Tombol Bootstrap</h1>
        <h5>Solid Buttons:</h5>
        <div class="d-flex flex-wrap gap-2 mb-3">
            <button class="btn btn-primary">Primary</button>
            <button class="btn btn-secondary">Secondary</button>
            <button class="btn btn-success">Success</button>
            <button class="btn btn-danger">Danger</button>
            <button class="btn btn-warning">Warning</button>
            <button class="btn btn-info">Info</button>
            <button class="btn btn-light border">Light</button>
            <button class="btn btn-dark">Dark</button>
            <button class="btn btn-link">Link</button>
        </div>
        <h5>Outline Buttons:</h5>
        <div class="d-flex flex-wrap gap-2 mb-3">
            <button class="btn btn-outline-primary">Primary</button>
            <button class="btn btn-outline-secondary">Secondary</button>
            <button class="btn btn-outline-success">Success</button>
            <button class="btn btn-outline-danger">Danger</button>
        </div>
        <h5>Ukuran Tombol:</h5>
        <div class="d-flex gap-2 align-items-center">
            <button class="btn btn-primary btn-sm">Small</button>
            <button class="btn btn-primary">Default</button>
            <button class="btn btn-primary btn-lg">Large</button>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Class btn + btn-{warna} untuk tombol solid, btn-outline-{warna} untuk outline
- Tersedia 8 warna solid + btn-link
- Ukuran: btn-sm, default, btn-lg
