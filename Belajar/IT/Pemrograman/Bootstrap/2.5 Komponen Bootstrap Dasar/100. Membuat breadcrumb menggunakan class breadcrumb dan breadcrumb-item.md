# Membuat breadcrumb menggunakan class breadcrumb dan breadcrumb-item

## Analogi: Perpustakaan Digital

Navigasi jejak (breadcrumb) di perpustakaan seperti papan petunjuk yang menunjukkan posisi pengunjung: "Ruang Utama > Rak Fiksi > Rak Fiksi Ilmiah". Setiap level menunjukkan hierarki lokasi. Bootstrap menyediakan breadcrumb sebagai navigasi sekunder yang menunjukkan posisi halaman saat ini dalam struktur situs.

## Penjelasan Detail

Class `breadcrumb` membuat navigasi jejak dengan list horizontal dan pemisah (biasanya `/`). Setiap level menggunakan `breadcrumb-item`. Item terakhir otomatis diberi gaya `active` (aria-current="page") untuk menunjukkan halaman saat ini. Breadcrumb biasanya ditempatkan di bagian atas halaman setelah navbar. Pemisah dapat diubah dengan CSS kustom. Breadcrumb penting untuk SEO dan UX karena menunjukkan struktur situs dan memudahkan navigasi ke level atas.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Breadcrumb Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Breadcrumb</h1>
        <nav aria-label="breadcrumb">
            <ol class="breadcrumb">
                <li class="breadcrumb-item"><a href="#">Beranda</a></li>
                <li class="breadcrumb-item"><a href="#">Koleksi</a></li>
                <li class="breadcrumb-item active" aria-current="page">Buku Fiksi</li>
            </ol>
        </nav>
        <nav aria-label="breadcrumb" class="mt-3">
            <ol class="breadcrumb">
                <li class="breadcrumb-item"><a href="#">Home</a></li>
                <li class="breadcrumb-item"><a href="#">Produk</a></li>
                <li class="breadcrumb-item"><a href="#">Kategori</a></li>
                <li class="breadcrumb-item active" aria-current="page">Detail Produk</li>
            </ol>
        </nav>
        <nav aria-label="breadcrumb" class="mt-3">
            <ol class="breadcrumb bg-light p-3 rounded">
                <li class="breadcrumb-item"><a href="#">Dashboard</a></li>
                <li class="breadcrumb-item"><a href="#">Pengaturan</a></li>
                <li class="breadcrumb-item active" aria-current="page">Profile</li>
            </ol>
        </nav>
        <div class="mt-4 p-4 bg-light rounded">
            <nav aria-label="breadcrumb">
                <ol class="breadcrumb mb-0">
                    <li class="breadcrumb-item"><a href="#">MyLibrary</a></li>
                    <li class="breadcrumb-item"><a href="#">Katalog</a></li>
                    <li class="breadcrumb-item"><a href="#">Fiksi</a></li>
                    <li class="breadcrumb-item active" aria-current="page">Petualangan</li>
                </ol>
            </nav>
            <h2 class="mt-3">Buku Petualangan</h2>
            <p>Daftar buku dalam kategori petualangan.</p>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- breadcrumb untuk navigasi jejak, breadcrumb-item untuk setiap level
- Item terakhir mendapat class active dan aria-current="page"
- Pemisah otomatis (/) ditambahkan antar item
