# Membuat card dasar menggunakan class card, card-body, card-title, dan card-text

## Analogi: Perpustakaan Digital

Katalog buku di perpustakaan yang menampilkan sampul, judul, pengarang, dan deskripsi dalam satu kartu informatif. Card Bootstrap seperti kartu katalog yang membungkus konten dalam wadah rapi dengan border, padding, dan sudut membulat. Setiap card bisa berisi judul, teks, gambar, dan tombol.

## Penjelasan Detail

Class `card` membuat wadah dengan border, border-radius, dan shadow ringan. Di dalam card, `card-body` menyediakan padding, `card-title` untuk judul (font lebih besar dan bold), `card-text` untuk teks konten. Card juga mendukung `card-header` (atas), `card-footer` (bawah), `card-img-top` (gambar di atas), dan `card-img-bottom` (gambar di bawah). Card dapat diatur lebarnya dengan class width utility atau style inline. Beberapa card bisa dikelompokkan dengan `card-group` atau grid.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Card Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Card Bootstrap</h1>
        <div class="d-flex gap-3 flex-wrap">
            <div class="card" style="width:250px;">
                <div class="card-body">
                    <h5 class="card-title">Judul Buku</h5>
                    <h6 class="card-subtitle mb-2 text-muted">Pengarang</h6>
                    <p class="card-text">Deskripsi singkat tentang buku ini. Lorem ipsum dolor sit amet.</p>
                    <a href="#" class="btn btn-primary">Pinjam Buku</a>
                </div>
            </div>
            <div class="card" style="width:250px;">
                <div class="card-body">
                    <h5 class="card-title">Majalah</h5>
                    <p class="card-text">Edisi terbaru majalah teknologi.</p>
                    <a href="#" class="btn btn-outline-success">Baca</a>
                </div>
            </div>
            <div class="card" style="width:250px;">
                <div class="card-header">Header Card</div>
                <div class="card-body">
                    <h5 class="card-title">Card dengan Header</h5>
                    <p class="card-text">Card dengan header dan footer.</p>
                </div>
                <div class="card-footer text-muted">Footer Card</div>
            </div>
        </div>
        <div class="card mt-3">
            <div class="card-body text-center">
                <h5 class="card-title">Card Penuh</h5>
                <p class="card-text">Card ini memenuhi lebar container.</p>
            </div>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Card = wadah konten dengan border dan border-radius
- card-body untuk padding, card-title untuk judul, card-text untuk paragraf
- Dapat ditambahkan card-header, card-footer, card-img-top
