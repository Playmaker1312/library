# Memahami ukuran tombol yaitu btn-sm dan btn-lg

## Analogi: Perpustakaan Digital

Stempel di perpustakaan tersedia dalam tiga ukuran: stempel kecil (btn-sm) untuk nota kecil, stempel standar untuk dokumen biasa, dan stempel besar (btn-lg) untuk banner atau pengumuman. Pustakawan memilih ukuran stempel sesuai kebutuhan. Bootstrap menyediakan class ukuran tombol yang konsisten.

## Penjelasan Detail

Class ukuran tombol Bootstrap: `btn-sm` untuk tombol kecil dengan padding lebih kecil dan font lebih kecil, `btn-lg` untuk tombol besar dengan padding lebih besar dan font lebih besar. Tanpa class ukuran, tombol menggunakan ukuran default. btn-sm berguna untuk tombol aksi dalam tabel, toolbar, atau area padat. btn-lg berguna untuk call-to-action utama, hero section, atau tombol yang ingin ditonjolkan. Ukuran tombol bekerja dengan semua variasi btn dan btn-outline.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ukuran Tombol</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Ukuran Tombol Bootstrap</h1>
        <div class="d-flex align-items-center gap-3 mb-4">
            <div>
                <p class="mb-1"><strong>btn-sm</strong></p>
                <button class="btn btn-primary btn-sm">Small</button>
                <button class="btn btn-success btn-sm">Sukses</button>
                <button class="btn btn-outline-danger btn-sm">Hapus</button>
            </div>
            <div>
                <p class="mb-1"><strong>Default</strong></p>
                <button class="btn btn-primary">Default</button>
                <button class="btn btn-success">Sukses</button>
                <button class="btn btn-outline-danger">Hapus</button>
            </div>
            <div>
                <p class="mb-1"><strong>btn-lg</strong></p>
                <button class="btn btn-primary btn-lg">Large</button>
                <button class="btn btn-success btn-lg">Sukses</button>
                <button class="btn btn-outline-danger btn-lg">Hapus</button>
            </div>
        </div>
        <div class="d-flex flex-column gap-2" style="max-width:300px;">
            <a href="#" class="btn btn-primary btn-lg">Call to Action Besar</a>
            <a href="#" class="btn btn-secondary">Pelajari Lagi</a>
            <a href="#" class="btn btn-sm btn-outline-secondary">Detail Kecil</a>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- btn-sm untuk tombol kecil, btn-lg untuk tombol besar
- Tanpa class ukuran = ukuran default
- Ukuran bekerja dengan semua variasi btn dan btn-outline
