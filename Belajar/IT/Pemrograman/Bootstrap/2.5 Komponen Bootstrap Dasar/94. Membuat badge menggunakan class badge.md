# Membuat badge menggunakan class badge

## Analogi: Perpustakaan Digital

Label kecil di punggung buku yang menunjukkan nomor rak, status, atau kategori. badge adalah label kecil yang menempel pada elemen lain untuk menampilkan informasi tambahan seperti jumlah notifikasi, status, atau label. Seperti stiker kecil di perpustakaan yang memberi info cepat tentang buku.

## Penjelasan Detail

Class `badge` membuat label kecil dengan padding minimal, font-size kecil, dan border-radius bulat. Badge biasanya dikombinasikan dengan `bg-{warna}` atau `text-bg-{warna}`. Badge bisa ditempatkan di dalam tombol, heading, link, atau sebagai elemen mandiri. Badge juga bisa diposisikan absolut dengan `position-absolute top-0 start-100 translate-middle` untuk efek notifikasi. Tersedia `rounded-pill` untuk badge yang lebih bulat.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Badge Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Badge <span class="badge bg-primary">Baru</span></h1>
        <h2>Heading 2 <span class="badge bg-secondary">v2.0</span></h2>
        <h3>Heading 3 <span class="badge bg-success">Hijau</span></h3>
        <div class="d-flex gap-2 mb-3">
            <span class="badge bg-primary">Primary</span>
            <span class="badge bg-secondary">Secondary</span>
            <span class="badge bg-success">Success</span>
            <span class="badge bg-danger">Danger</span>
            <span class="badge bg-warning text-dark">Warning</span>
            <span class="badge bg-info text-dark">Info</span>
            <span class="badge bg-light text-dark border">Light</span>
            <span class="badge bg-dark">Dark</span>
        </div>
        <button class="btn btn-primary position-relative me-4">
            Notifikasi
            <span class="position-absolute top-0 start-100 translate-middle badge rounded-pill bg-danger">
                99+
                <span class="visually-hidden">pesan belum dibaca</span>
            </span>
        </button>
        <button class="btn btn-outline-secondary position-relative">
            Profile
            <span class="position-absolute top-0 start-100 translate-middle p-2 bg-danger border border-light rounded-circle">
                <span class="visually-hidden">online</span>
            </span>
        </button>
        <div class="mt-3">
            <span class="badge rounded-pill bg-primary">Pill Badge</span>
            <span class="badge rounded-pill bg-success">Sukses</span>
            <span class="badge rounded-pill bg-warning text-dark">Peringatan</span>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Badge untuk label kecil dengan informasi tambahan
- Kombinasikan dengan bg-{warna} atau text-bg-{warna}
- Gunakan rounded-pill untuk badge bulat, position-absolute untuk notifikasi
