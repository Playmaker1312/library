# Membuat dismissible alert menggunakan tombol close

## Analogi: Perpustakaan Digital

Papan pengumuman di perpustakaan yang bisa ditutup setelah dibaca. Pengunjung cukup menekan tombol silang (X) untuk menutup papan tersebut. Bootstrap menyediakan alert yang bisa ditutup dengan tombol close, memberikan kontrol kepada pengguna untuk menghilangkan notifikasi yang sudah tidak relevan.

## Penjelasan Detail

Dismissible alert menggunakan class `alert-dismissible` pada elemen alert, ditambah tombol `btn-close` dan atribut `data-bs-dismiss="alert"`. Untuk efek fade out, tambahkan class `fade` dan `show`. Tombol close diposisikan absolut di pojok kanan atas alert. Bootstrap JavaScript Bundle (bootstrap.bundle.min.js) diperlukan untuk fungsi dismiss. Animasi transparansi terjadi secara otomatis.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dismissible Alert</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Dismissible Alert</h1>
        <div class="alert alert-success alert-dismissible fade show" role="alert">
            <strong>Sukses!</strong> Data berhasil disimpan.
            <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
        </div>
        <div class="alert alert-warning alert-dismissible fade show" role="alert">
            <strong>Peringatan!</strong> Koneksi internet Anda lemah.
            <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
        </div>
        <div class="alert alert-danger alert-dismissible fade show d-flex align-items-center" role="alert">
            <div><strong>Error!</strong> File tidak ditemukan.</div>
            <button type="button" class="btn-close ms-auto" data-bs-dismiss="alert" aria-label="Close"></button>
        </div>
        <div class="alert alert-info alert-dismissible fade show" role="alert">
            <strong>Info:</strong> Update sistem akan dilakukan malam ini.
            <button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
        </div>
        <button class="btn btn-primary mt-3" onclick="showDemoAlert()">Tampilkan Alert Demo</button>
        <div id="demoAlertContainer"></div>
    </div>
    <script>
        function showDemoAlert() {
            const container = document.getElementById('demoAlertContainer');
            const alert = document.createElement('div');
            alert.className = 'alert alert-info alert-dismissible fade show mt-2';
            alert.role = 'alert';
            alert.innerHTML = 'Alert baru dibuat! ' +
                '<button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>';
            container.appendChild(alert);
        }
    </script>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Tambahkan class alert-dismissible dan tombol close dengan data-bs-dismiss
- Class fade show memberikan animasi transisi
- Membutuhkan Bootstrap JavaScript untuk fungsi dismiss
