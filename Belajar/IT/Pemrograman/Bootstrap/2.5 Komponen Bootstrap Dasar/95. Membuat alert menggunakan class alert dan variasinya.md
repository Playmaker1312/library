# Membuat alert menggunakan class alert dan variasinya

## Analogi: Perpustakaan Digital

Papan pengumuman di perpustakaan yang menunjukkan informasi penting: papan biru untuk info (alert-primary), hijau untuk sukses (alert-success), merah untuk kesalahan (alert-danger), kuning untuk peringatan (alert-warning). Setiap papan memiliki warna dan ikon yang sesuai dengan jenis pesannya. Bootstrap menyediakan komponen alert untuk notifikasi.

## Penjelasan Detail

Class `alert` dikombinasikan dengan `alert-{warna}` membuat kotak notifikasi dengan padding, border, dan warna background yang sesuai. Warna: alert-primary, secondary, success, danger, warning, info, light, dark. Alert bisa berisi teks, heading (`alert-heading`), dan link (`alert-link`). Alert dapat ditutup dengan tombol close jika menggunakan class `alert-dismissible`. Alert bersifat statis (tidak otomatis hilang) tanpa JavaScript tambahan.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Alert Bootstrap</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>Alert Bootstrap</h1>
        <div class="alert alert-primary" role="alert">Alert primary - informasi umum.</div>
        <div class="alert alert-secondary" role="alert">Alert secondary.</div>
        <div class="alert alert-success" role="alert">Alert success - operasi berhasil!</div>
        <div class="alert alert-danger" role="alert">Alert danger - terjadi kesalahan!</div>
        <div class="alert alert-warning" role="alert">Alert warning - peringatan!</div>
        <div class="alert alert-info" role="alert">Alert info - informasi tambahan.</div>
        <div class="alert alert-light border" role="alert">Alert light.</div>
        <div class="alert alert-dark" role="alert">Alert dark.</div>
        <hr>
        <div class="alert alert-success" role="alert">
            <h4 class="alert-heading">Selamat!</h4>
            <p>Anda berhasil login. <a href="#" class="alert-link">Klik di sini</a> untuk dashboard.</p>
        </div>
        <div class="alert alert-warning alert-dismissible fade show" role="alert">
            <strong>Perhatian!</strong> Ini alert yang bisa ditutup.
            <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Alert menggunakan class alert + alert-{warna}
- Gunakan alert-heading untuk judul, alert-link untuk link dalam alert
- alert-dismissible + btn-close untuk tombol tutup
