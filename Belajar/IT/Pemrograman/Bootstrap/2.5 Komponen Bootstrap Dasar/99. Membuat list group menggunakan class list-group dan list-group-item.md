# Membuat list group menggunakan class list-group dan list-group-item

## Analogi: Perpustakaan Digital

Daftar isi buku atau katalog perpustakaan yang menampilkan item-item dalam format daftar vertikal. List group Bootstrap seperti daftar isi yang rapi dengan border, hover effect, dan dukungan untuk badge, link, dan status aktif. Pustakawan bisa menampilkan daftar kategori buku dengan rapi.

## Penjelasan Detail

Class `list-group` membuat container daftar dengan border dan border-radius. `list-group-item` untuk setiap item dalam daftar. List group mendukung: `list-group-item-action` untuk efek hover pada item link/button, `active` untuk item aktif, `disabled` untuk item non-aktif, dan `list-group-item-{warna}` untuk variasi warna. Item bisa berupa `<li>`, `<a>`, atau `<button>`. List group juga bisa diberi nomor dengan `<ol>` atau horizontal dengan `list-group-horizontal`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>List Group</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="p-4">
    <div class="container">
        <h1>List Group</h1>
        <div class="row">
            <div class="col-md-4">
                <h5>List Group Dasar:</h5>
                <ul class="list-group">
                    <li class="list-group-item">Item 1</li>
                    <li class="list-group-item active">Item 2 (Active)</li>
                    <li class="list-group-item disabled">Item 3 (Disabled)</li>
                    <li class="list-group-item">Item 4</li>
                </ul>
            </div>
            <div class="col-md-4">
                <h5>List Group dengan Link:</h5>
                <div class="list-group">
                    <a href="#" class="list-group-item list-group-item-action">Link 1</a>
                    <a href="#" class="list-group-item list-group-item-action active">Link 2</a>
                    <a href="#" class="list-group-item list-group-item-action">Link 3</a>
                </div>
            </div>
            <div class="col-md-4">
                <h5>List Group dengan Warna:</h5>
                <ul class="list-group">
                    <li class="list-group-item list-group-item-primary">Primary</li>
                    <li class="list-group-item list-group-item-success">Success</li>
                    <li class="list-group-item list-group-item-danger">Danger</li>
                    <li class="list-group-item list-group-item-warning">Warning</li>
                </ul>
            </div>
        </div>
        <div class="mt-3">
            <h5>List Group Horizontal:</h5>
            <ul class="list-group list-group-horizontal">
                <li class="list-group-item">Item 1</li>
                <li class="list-group-item">Item 2</li>
                <li class="list-group-item">Item 3</li>
            </ul>
        </div>
        <div class="mt-3">
            <h5>List Group dengan Badge:</h5>
            <ul class="list-group" style="max-width:400px;">
                <li class="list-group-item d-flex justify-content-between align-items-center">
                    Notifikasi <span class="badge bg-primary rounded-pill">14</span>
                </li>
                <li class="list-group-item d-flex justify-content-between align-items-center">
                    Pesan <span class="badge bg-danger rounded-pill">3</span>
                </li>
            </ul>
        </div>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- list-group untuk container, list-group-item untuk setiap item
- list-group-item-action untuk efek hover pada link/button
- list-group-item-{warna} untuk variasi warna
