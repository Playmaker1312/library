# Cara Melakukan Aksesibilitas Testing Otomatis pada Project Bootstrap

## Analogi: Perpustakaan Digital

Aksesibilitas testing adalah seperti memastikan perpustakaan bisa digunakan oleh semua pengunjung—termasuk yang menggunakan kursi roda, yang buta, atau yang memiliki kesulitan membaca. Ramps, braille, pintu lebar, dan papan dengan font besar adalah elemen aksesibilitas fisik. Di web, aksesibilitas mencakup screen reader support, kontras warna, navigasi keyboard, dan label yang jelas. Bootstrap sudah memiliki aksesibilitas bawaan, tetapi perlu diverifikasi.

## Penjelasan Detail

Alat aksesibilitas testing otomatis: (1) axe DevTools (browser extension), (2) Lighthouse (bawaan Chrome DevTools), (3) WAVE Evaluation Tool, (4) pa11y (CLI). Untuk projekt Bootstrap, periksa: (1) Semua gambar memiliki alt text, (2) Kontras warna cukup (rasio minimal 4.5:1 untuk teks normal), (3) Form input memiliki label yang jelas, (4) Navigasi bisa dioperasikan dengan keyboard, (5) Modal dan dropdown memiliki ARIA attributes yang benar, (6) Fokus terlihat (visible focus ring). Bootstrap 5 sudah menyertakan ARIA attributes, tetapi implementasi pengguna bisa memperkenalkan masalah aksesibilitas.

<body>

            <div id="namaHelp" class="form-text">Nama sesuai KTP.</div>
          </div>
          <button type="submit" class="btn btn-primary">Kirim</button>
        </form>
      </div>
    </div>

    <!-- Checklist Aksesibilitas -->
    <div class="card shadow-sm">
      <div class="card-header bg-primary text-white">✅ Checklist Aksesibilitas Bootstrap</div>
      <div class="card-body">
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Semua gambar memiliki <code>alt</code> text deskriptif</label>
        </div>
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Kontras warna memenuhi rasio 4.5:1 (WCAG AA)</label>
        </div>
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Semua form input memiliki <code>&lt;label&gt;</code> yang terkait</label>
        </div>
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Navigasi dapat dioperasikan dengan keyboard (Tab, Enter, Escape)</label>
        </div>
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Modal memiliki <code>aria-labelledby</code> dan <code>aria-modal="true"</code></label>
        </div>
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Focus ring terlihat untuk semua elemen interaktif</label>
        </div>
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Heading hierarki logis (h1 → h2 → h3)</label>
        </div>
        <div class="form-check mb-2">
          <input class="form-check-input" type="checkbox">
          <label class="form-check-label">Error messages terkait dengan input menggunakan <code>aria-describedby</code></label>
        </div>
      </div>
    </div>

    <!-- Alat Testing -->
    <div class="row g-3 mt-4">
      <div class="col-md-4">
        <div class="card h-100">
          <div class="card-body text-center">
            <h5>🔍 axe DevTools</h5>

          </div>
        </div>
      </div>
      <div class="col-md-4">
        <div class="card h-100">
          <div class="card-body text-center">
            <h5>📊 Lighthouse</h5>
            <p class="small">Bawaan Chrome DevTools, skor aksesibilitas 0-100</p>
          </div>
        </div>
      </div>
      <div class="col-md-4">
        <div class="card h-100">
          <div class="card-body text-center">
            <h5>♿ WAVE</h5>
            <p class="small">Alat visual untuk mengidentifikasi masalah aksesibilitas</p>
          </div>
        </div>
      </div>
    </div>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>

## Poin Penting
- Gunakan axe DevTools, Lighthouse, atau WAVE untuk aksesibilitas testing otomatis.
- Bootstrap 5 sudah memiliki ARIA attributes bawaan, tetapi implementasi pengguna perlu diverifikasi.
- Periksa kontras warna, label form, navigasi keyboard, dan fokus ring.
