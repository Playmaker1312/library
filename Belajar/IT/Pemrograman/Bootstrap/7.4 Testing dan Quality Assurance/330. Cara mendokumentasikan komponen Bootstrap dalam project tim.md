# Cara Mendokumentasikan Komponen Bootstrap dalam Project Tim

## Analogi: Perpustakaan Digital

Dokumentasi komponen Bootstrap adalah seperti buku panduan perpustakaan yang menjelaskan cara menggunakan setiap rak, sistem katalog, dan prosedur peminjaman. Ketika ada petugas baru, mereka bisa membaca buku panduan ini untuk memahami bagaimana perpustakaan diorganisir. Tanpa dokumentasi, pengetahuan hanya ada di kepala beberapa orang dan sulit ditransfer ke anggota tim baru.

## Penjelasan Detail

Dokumentasi komponen Bootstrap dalam project tim mencakup: (1) Daftar komponen Bootstrap yang digunakan dan bagaimana kustomisasinya, (2) Panduan penggunaan variabel SCSS (warna, font, spacing), (3) Contoh kode untuk komponen yang sering digunakan beserta props/opsi, (4) Aturan penamaan class CSS kustom (BEM), (5) Informasi tentang plugin pihak ketiga yang diintegrasikan, (6) Panduan responsive breakpoints yang digunakan. Alat dokumentasi: Storybook (untuk component library), Markdown di repository, atau Wiki GitHub/GitLab. Dokumentasi living (hidup) seperti Storybook lebih baik karena sinkron dengan kode.

## Contoh Kode Implementasi

```html

  <style>

  </style>
</head>
<body>
  <div class="container my-5">

    <h2>Button</h2>
    <p>Gunakan class <code>.btn</code> dengan modifier color.</p>
    <div class="component-preview">
      <button class="btn btn-primary me-2">Primary</button>
      <button class="btn btn-secondary me-2">Secondary</button>
      <button class="btn btn-success me-2">Success</button>
      <button class="btn btn-danger me-2">Danger</button>

    </div>

&lt;button class="btn btn-primary"&gt;Primary&lt;/button&gt;
&lt;button class="btn btn-outline-primary"&gt;Outline&lt;/button&gt;</pre>

    <h2 class="mt-4">Card</h2>
    <p>Gunakan <code>.card</code> untuk container, <code>.card-body</code> untuk konten.</p>
    <div class="component-preview">
      <div class="card" style="max-width: 300px;">
        <div class="card-body">

    </div>

    <h2 class="mt-4">Alert</h2>
    <p>Gunakan <code>.alert</code> dengan modifier color. Alert bisa ditutup dengan class <code>.alert-dismissible</code>.</p>
    <div class="component-preview">
      <div class="alert alert-success alert-dismissible fade show">
        Data berhasil disimpan!
        <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
      </div>
    </div>

    <hr class="my-4">

    <!-- Panduan Kustomisasi -->
    <h2>🎨 Kustomisasi Tema</h2>
    <div class="card shadow-sm">
      <div class="card-body">
        <table class="table">
          <thead class="table-dark">
            <tr><th>Variabel SCSS</th><th>Nilai</th><th>Keterangan</th></tr>
          </thead>
          <tbody>
            <tr><td><code>$primary</code></td><td><span class="badge" style="background: #0d6efd;">#0d6efd</span></td><td>Warna utama brand</td></tr>
            <tr><td><code>$secondary</code></td><td><span class="badge" style="background: #6c757d;">#6c757d</span></td><td>Warna sekunder</td></tr>

          </tbody>
        </table>
      </div>
    </div>

    <!-- Struktur Folder -->
    <h2 class="mt-4">📁 Struktur Folder</h2>
    <div class="card shadow-sm">
      <div class="card-body">
        <pre class="mb-0">
src/
├── scss/
│   ├── custom/
│   │   ├── _buttons.scss
│   │   ├── _cards.scss
│   │   └── _variables.scss

```

## Poin Penting
- Dokumentasi komponen Bootstrap memudahkan onboarding anggota tim baru dan menjaga konsistensi.
- Gunakan Storybook untuk dokumentasi living yang sinkron dengan kode, atau Markdown untuk yang sederhana.
- Dokumentasi mencakup daftar komponen, kustomisasi, variabel SCSS, dan struktur folder.
