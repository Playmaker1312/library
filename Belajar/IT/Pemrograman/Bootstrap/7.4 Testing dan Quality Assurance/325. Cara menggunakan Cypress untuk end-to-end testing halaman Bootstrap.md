# Cara Menggunakan Cypress untuk End-to-End Testing Halaman Bootstrap

## Analogi: Perpustakaan Digital

End-to-end testing dengan Cypress adalah seperti memiliki asisten robot yang menguji seluruh pengalaman pengunjung perpustakaan: masuk pintu, mencari buku di katalog, meminjam buku, dan keluar. Asisten ini melakukan semua langkah secara otomatis, memastikan setiap proses berjalan lancar. Jika ada tombol rusak atau halaman error, asisten akan melaporkannya.

## Penjelasan Detail

Cypress adalah framework end-to-end testing yang berjalan di browser nyata. Untuk Bootstrap: (1) Instal Cypress: `npm install cypress --save-dev`, (2) Buat test file di cypress/e2e/, (3) Gunakan perintah Cypress untuk berinteraksi dengan komponen Bootstrap: `cy.get('.btn-primary').click()`, `cy.get('.modal').should('be.visible')`, (4) Test interaksi seperti klik navbar, buka dropdown, submit form, navigasi halaman, (5) Gunakan Cypress Dashboard untuk recording dan debugging. Cypress ideal untuk menguji komponen JavaScript Bootstrap seperti modal, carousel, dropdown, dan form validation.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Cypress E2E Testing</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
      <a class="navbar-brand" href="#">MyApp</a>
      <button class="navbar-toggler" data-bs-toggle="collapse" data-bs-target="#navbarNav">
        <span class="navbar-toggler-icon"></span>
      </button>
      <div class="collapse navbar-collapse" id="navbarNav">
        <ul class="navbar-nav">
          <li class="nav-item"><a class="nav-link active" href="#">Home</a></li>
          <li class="nav-item"><a class="nav-link" href="#about">About</a></li>
          <li class="nav-item"><a class="nav-link" href="#contact">Contact</a></li>
        </ul>
      </div>
    </div>
  </nav>

  <div class="container my-5">
    <h1 id="pageTitle">Cypress + Bootstrap E2E Testing</h1>
    <button class="btn btn-primary" id="showModalBtn" data-bs-toggle="modal" data-bs-target="#testModal">Buka Modal</button>

    <!-- Modal -->
    <div class="modal fade" id="testModal">
      <div class="modal-dialog">
        <div class="modal-content">
          <div class="modal-header"><h5 class="modal-title">Test Modal</h5><button class="btn-close" data-bs-dismiss="modal"></button></div>
          <div class="modal-body"><p>Ini adalah modal untuk di-test.</p></div>
          <div class="modal-footer"><button class="btn btn-secondary" data-bs-dismiss="modal">Tutup</button></div>
        </div>
      </div>
    </div>
  </div>

  <!-- Ilustrasi Cypress Test -->
  <div class="container mb-5">
    <div class="card shadow-sm">
      <div class="card-header">📝 Contoh Cypress Test (cypress/e2e/bootstrap.cy.js)</div>
      <div class="card-body">
        <pre class="bg-dark text-light p-3 rounded" style="font-size: 0.85rem;">
describe('Bootstrap Component Tests', () => {
  beforeEach(() => {
    cy.visit('/index.html');
  });

  it('should display the correct page title', () => {
    cy.get('#pageTitle').should('contain', 'Cypress');
  });

  it('should toggle mobile navbar', () => {
    cy.viewport('iphone-x');
    cy.get('.navbar-toggler').click();
    cy.get('#navbarNav').should('have.class', 'show');
  });

  it('should open and close modal', () => {
    cy.get('#showModalBtn').click();
    cy.get('#testModal').should('have.class', 'show');
    cy.get('#testModal').contains('Test Modal');

    // Tutup modal
    cy.get('#testModal .btn-close').click();
    cy.get('#testModal').should('not.have.class', 'show');
  });

  it('should navigate via navbar links', () => {
    cy.contains('About').click();
    cy.url().should('include', '#about');
  });

  it('should validate required form fields', () => {
    cy.get('form.needs-validation').within(() => {
      cy.get('button[type="submit"]').click();
      cy.get('input:invalid').should('have.length.at.least', 1);
    });
  });
});</pre>
      </div>
    </div>

    <div class="alert alert-success mt-3">
      Cypress memberikan video recording dari setiap test run, memudahkan debugging saat test gagal.
    </div>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Cypress menguji interaksi pengguna nyata dengan komponen Bootstrap di browser.
- Test komponen JavaScript Bootstrap: modal, carousel, dropdown, navbar toggler, form validation.
- Gunakan cy.viewport() untuk menguji responsive behavior komponen Bootstrap.
