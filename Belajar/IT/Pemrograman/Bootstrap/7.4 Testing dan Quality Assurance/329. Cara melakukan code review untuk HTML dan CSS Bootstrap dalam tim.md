# Cara Melakukan Code Review untuk HTML dan CSS Bootstrap dalam Tim

## Analogi: Perpustakaan Digital

Code review adalah seperti peer review artikel di jurnal perpustakaan—seorang editor memeriksa tulisan rekan kerja sebelum dipublikasikan untuk memastikan kualitas, konsistensi, dan tidak ada kesalahan. Dalam tim pengembang, code review memastikan kode HTML dan CSS Bootstrap memenuhi standar tim, mudah dipelihara, dan tidak mengandung bug.

## Penjelasan Detail

Code review untuk HTML/CSS Bootstrap: (1) Periksa apakah HTML menggunakan semantic HTML5, (2) Apakah class Bootstrap digunakan dengan benar (contoh: container → container-fluid, row → g-*), (3) Apakah ada CSS kustom yang sebenarnya sudah ada di Bootstrap, (4) Apakah struktur grid sesuai dengan mockup, (5) Apakah komponen JavaScript Bootstrap diinisialisasi dengan benar, (6) Apakah ada inline styles yang seharusnya menggunakan class, (7) Apakah responsive breakpoints tepat, (8) Apakah kode mengikuti konvensi penamaan (BEM jika menggunakan CSS kustom). Gunakan checklist review dan alat seperti Prettier untuk formatting otomatis.

## Poin Penting
- Code review memastikan HTML menggunakan semantic elements dan class Bootstrap dengan benar.
- CSS review memeriksa tidak ada duplikasi class Bootstrap, penggunaan variabel, dan konsistensi.
- Gunakan checklist dan alat seperti Prettier untuk standardisasi kode tim.
