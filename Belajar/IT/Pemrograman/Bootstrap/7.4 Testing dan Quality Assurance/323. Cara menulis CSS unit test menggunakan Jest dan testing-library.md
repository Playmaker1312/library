# Cara Menulis CSS Unit Test Menggunakan Jest dan Testing-Library

## Analogi: Perpustakaan Digital

CSS unit test adalah seperti memeriksa setiap rak buku di perpustakaan secara otomatis—apakah rak kokoh, apakah label sesuai, apakah buku-buku tersusun rapi. Dengan alat seperti Jest dan testing-library, komputer bisa memeriksa ribuan rak dalam hitungan detik, memastikan semuanya sesuai standar. Anda tidak perlu manual mengecek satu per satu.

## Penjelasan Detail

CSS unit test menguji bahwa class Bootstrap atau CSS kustom menghasilkan styling yang diharapkan. Gunakan Jest sebagai test runner dan @testing-library/jest-dom untuk matchers DOM. Prinsip: render komponen HTML dengan class Bootstrap, gunakan getComputedStyle untuk memeriksa properti CSS, atau periksa keberadaan class dengan toHaveClass. Contoh pengujian: pastikan button.btn-primary memiliki background biru, alert.alert-danger memiliki warna merah, atau grid.col-6 memiliki lebar 50%. Meskipun Bootstrap sudah teruji, CSS kustom yang menimpa Bootstrap perlu diuji.

// npm install --save-dev jest @testing-library/jest-dom

import '@testing-library/jest-dom';
import { screen } from '@testing-library/dom';

// Test Bootstrap default class
test('btn-primary should have blue background', () => {
  document.body.innerHTML = `&lt;button class="btn btn-primary"&gt;Tombol&lt;/button&gt;`;
  const btn = screen.getByText('Tombol');
  expect(btn).toHaveClass('btn-primary');
  expect(getComputedStyle(btn).backgroundColor).toBe('rgb(13, 110, 253)');
});

// Test custom CSS
test('custom button should have purple background', () => {
  document.body.innerHTML = `&lt;button class="btn btn-custom-primary"&gt;Tombol&lt;/button&gt;`;
  const btn = screen.getByText('Tombol');
  expect(btn).toHaveClass('btn-custom-primary');
  expect(getComputedStyle(btn).backgroundColor).toBe('rgb(111, 66, 193)');
});

// Test grid system

  &lt;/div&gt;&lt;/div&gt;`;
  const col = document.querySelector('.col-6');

## Poin Penting
- Jest + @testing-library/jest-dom dapat menguji CSS dengan memeriksa class dan computed style.
- Unit test CSS memastikan class Bootstrap dan CSS kustom menghasilkan styling yang benar.
- Test grid, button, alert, dan komponen lain untuk mencegah regresi saat perubahan CSS.
