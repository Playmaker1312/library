# Cara Melakukan Performance Testing Menggunakan WebPageTest

## Analogi: Perpustakaan Digital

Performance testing adalah seperti mengukur waktu yang dibutuhkan pengunjung untuk berjalan dari pintu masuk ke rak buku yang diinginkan. Apakah jalannya mulus? Apakah ada hambatan? Apakah papan petunjuk jelas? WebPageTest adalah seperti stopwatch digital yang mengukur setiap langkah—berapa lama halaman loading, berapa besar file yang diunduh, dan apa yang memperlambat proses.

## Penjelasan Detail

WebPageTest adalah alat analisis performa website gratis. Untuk project Bootstrap: (1) Masukkan URL halaman, (2) Pilih lokasi server dan browser, (3) Jalankan test, (4) Analisis hasil: First Contentful Paint (FCP), Largest Contentful Paint (LCP), Time to Interactive (TTI), Total Blocking Time (TBT), Cumulative Layout Shift (CLS). Bootstrap mempengaruhi performa melalui file CSS dan JS yang perlu dioptimasi. Tips optimasi: gunakan CDN, minify assets, tree-shake CSS Bootstrap yang tidak terpakai, lazy loading images, kurangi jumlah komponen JavaScript yang tidak perlu.

## Poin Penting
- WebPageTest mengukur metrik performa penting: FCP, LCP, TBT, CLS.
- Optimasi Bootstrap: gunakan CDN, minify, tree-shake, lazy loading images.
- Jalankan test dari lokasi server yang berbeda untuk simulasi pengguna global.
