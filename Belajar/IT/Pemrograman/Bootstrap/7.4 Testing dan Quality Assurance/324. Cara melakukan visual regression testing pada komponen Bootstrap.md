# Cara Melakukan Visual Regression Testing pada Komponen Bootstrap

## Analogi: Perpustakaan Digital

Visual regression testing adalah seperti membandingkan foto rak buku perpustakaan sebelum dan sesudah renovasi. Jika ada perubahan—rak yang tidak sengaja dicat ulang atau label yang bergeser—foto akan menunjukkan perbedaannya. Dengan alat visual regression, komputer secara otomatis mengambil screenshot halaman web, membandingkannya dengan screenshot baseline, dan menandai perbedaan visual yang tidak diinginkan.

## Penjelasan Detail

Visual regression testing membandingkan screenshot sebelum dan sesudah perubahan. Alat seperti Percy, Chromatic, atau Playwright Visual Comparisons dapat digunakan. Alur kerja: (1) Ambil screenshot baseline dari komponen Bootstrap yang sudah benar, (2) Setelah perubahan kode, ambil screenshot baru, (3) Bandingkan kedua screenshot, (4) Tandai perbedaan visual sebagai passing (perubahan yang diinginkan) atau failing (regresi). Testing ini penting saat mengubah variabel SCSS Bootstrap, menambahkan CSS kustom, atau mengupdate versi Bootstrap.

## Poin Penting
- Visual regression testing membandingkan screenshot komponen sebelum dan sesudah perubahan.
- Alat populer: Percy, Chromatic, Playwright Visual Comparisons.
- Testing ini penting saat mengubah variabel tema Bootstrap atau menambahkan CSS kustom.
