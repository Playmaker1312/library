# Memahami Bootstrap Sass variables dan cara mengubahnya

## Analogi: Perpustakaan Digital

Bayangkan sebuah perpustakaan yang memiliki aturan seragam: sampul buku berwarna biru, rak bertingkat lima, label putih dengan font Times New Roman. Variabel Sass Bootstrap adalah aturan-aturan ini. Dengan mengubah nilai variabel, Anda bisa mengubah seluruh tampilan perpustakaan — mengganti sampul menjadi hijau, rak menjadi tiga tingkat, dan label menjadi font Arial — tanpa menyentuh setiap buku satu per satu.

## Penjelasan Detail

Bootstrap menggunakan ratusan variabel Sass yang didefinisikan di `_variables.scss`. Variabel-variabel ini menggunakan prefix `$` dan dikelompokkan berdasarkan kategori: warna (`$primary`, `$secondary`), tipografi (`$font-family-base`, `$font-size-base`), spacing (`$spacer`), border (`$border-radius`), breakpoints (`$grid-breakpoints`), dan masih banyak lagi. Untuk mengubah variabel, Anda tidak perlu mengedit file Bootstrap langsung. Cukup deklarasikan ulang variabel tersebut di file kustom Anda SEBELUM mengimpor Bootstrap. Karena Sass menggunakan pendekatan "last declaration wins" untuk variabel default (`!default`), nilai Anda akan menggantikan nilai default Bootstrap. Perubahan akan diterapkan secara konsisten ke semua komponen yang menggunakan variabel tersebut.

## Contoh Kode Implementasi

```scss
// custom.scss — mengubah variabel Bootstrap

// 1. Override variabel SEBELUM mengimpor Bootstrap
$primary: #6610f2;        // ungu sebagai warna utama
$secondary: #20c997;      // teal sebagai warna sekunder
$font-family-base: 'Poppins', sans-serif;
$border-radius: 0.5rem;
$enable-shadows: true;

// 2. Impor Bootstrap
@import "../node_modules/bootstrap/scss/bootstrap";

// 3. CSS kustom (menggunakan variabel yang sudah diubah)
.btn-custom-primary {
  background-color: $primary;
  border-color: $primary;
}
```

## Poin Penting
- Variabel Bootstrap menggunakan flag `!default`, sehingga bisa ditimpa dengan deklarasi sebelumnya
- Tulis override variabel SEBELUM impor Bootstrap
- Kategori variabel meliputi warna, tipografi, spacing, breakpoints, dan komponen
- Perubahan pada variabel akan memengaruhi semua komponen yang mereferensikannya
