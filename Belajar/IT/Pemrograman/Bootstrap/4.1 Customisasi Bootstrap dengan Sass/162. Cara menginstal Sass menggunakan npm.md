# Cara menginstal Sass menggunakan npm

## Analogi: Perpustakaan Digital

Seperti memasang rak buku baru yang akan menampung koleksi khusus, menginstal Sass melalui npm (Node Package Manager) adalah langkah pertama dalam menyiapkan ruang kerja pengembangan. npm bertindak sebagai distributor resmi yang mengirimkan semua peralatan yang diperlukan, lengkap dengan buku panduan pemasangannya.

## Penjelasan Detail

Untuk memulai kustomisasi Bootstrap dengan Sass, Anda perlu menginstal Sass di proyek Anda. npm adalah package manager untuk JavaScript yang paling umum digunakan. Anda dapat menginstal Sass secara global atau lokal di dalam proyek. Instalasi lokal lebih disarankan karena memungkinkan versi Sass yang spesifik per proyek. Bootstrap sendiri juga diinstal melalui npm sebagai dependency. Setelah Sass dan Bootstrap terinstal, Anda dapat mulai membuat file `.scss` utama yang mengimpor Bootstrap dan menimpa variabel-variabelnya. Proses ini membutuhkan Node.js yang sudah terinstal di sistem Anda.

## Contoh Kode Implementasi

```bash
# Inisialisasi proyek npm
npm init -y

# Instal Bootstrap dan Sass sebagai devDependencies
npm install bootstrap
npm install -D sass

# Struktur folder yang disarankan
# project/
# ├── node_modules/
# ├── scss/
# │   ├── custom.scss
# │   └── variables.scss
# └── package.json
```

## Poin Penting
- Pastikan Node.js sudah terinstal sebelum menggunakan npm
- Instal Bootstrap sebagai dependency biasa, Sass sebagai devDependency
- Gunakan `npm install -D sass` untuk instalasi lokal
- Struktur folder yang rapi memudahkan proses kompilasi dan maintenance
