# Cara mengubah font family dan font size Bootstrap menggunakan Sass variables

## Analogi: Perpustakaan Digital

Seperti memilih jenis huruf dan ukuran teks untuk katalog perpustakaan — apakah Times New Roman klasik berukuran 12pt atau Helvetica modern berukuran 14pt — mengubah font family dan font size Bootstrap menentukan tampilan tipografi seluruh halaman web, dari judul artikel hingga teks paragraf.

## Penjelasan Detail

Bootstrap menyediakan variabel Sass untuk mengontrol tipografi secara global. `$font-family-sans-serif`, `$font-family-serif`, dan `$font-family-monospace` mendefinisikan font stack untuk setiap kategori. Untuk ukuran font, `$font-size-base` (default 1rem) adalah ukuran dasar yang digunakan oleh elemen `<body>` dan menjadi acuan untuk `$h1-font-size` hingga `$h6-font-size`. Bootstrap juga menyediakan `$headings-font-family`, `$headings-font-weight`, dan `$headings-line-height` untuk kontrol heading yang terpisah. Dengan mengubah variabel-variabel ini, seluruh tipografi di Bootstrap akan menyesuaikan secara konsisten.

## Contoh Kode Implementasi

```scss
// custom.scss — mengubah tipografi

// Font family
$font-family-sans-serif: 'Inter', system-ui, -apple-system, sans-serif;
$font-family-monospace: 'Fira Code', monospace;

// Ukuran font dasar dan heading
$font-size-base: 1.125rem; // 18px
$h1-font-size: $font-size-base * 2.5;
$h2-font-size: $font-size-base * 2;
$h3-font-size: $font-size-base * 1.75;
$h4-font-size: $font-size-base * 1.5;
$h5-font-size: $font-size-base * 1.25;
$h6-font-size: $font-size-base;

// Heading styling
$headings-font-family: 'Poppins', sans-serif;
$headings-font-weight: 700;
$headings-line-height: 1.2;

@import "../node_modules/bootstrap/scss/bootstrap";
```

## Poin Penting
- `$font-size-base` adalah ukuran font dasar yang memengaruhi seluruh komponen
- Ukuran heading (`$h1-font-size` dst.) biasanya dinyatakan sebagai kelipatan `$font-size-base`
- Font family dapat diubah per kategori: sans-serif, serif, dan monospace
- Heading memiliki variabel terpisah untuk kontrol yang lebih spesifik
