# Cara mengubah warna theme Bootstrap menggunakan Sass variables

## Analogi: Perpustakaan Digital

Seperti mengganti skema warna seluruh perpustakaan — dari dinding biru dengan rak abu-abu menjadi dinding hijau dengan rak kayu — mengubah warna tema Bootstrap mengubah tampilan semua komponen sekaligus. Setiap tombol, badge, alert, dan link akan menggunakan palet warna baru yang Anda tentukan.

## Penjelasan Detail

Bootstrap memiliki palet warna yang dikelola melalui Sass maps dan variabel. Warna utama terdiri dari `$primary`, `$secondary`, `$success`, `$danger`, `$warning`, `$info`, `$light`, dan `$dark`. Selain itu, ada `$theme-colors` map yang menggabungkan semua warna tema dalam satu struktur data. Untuk mengubah warna, Anda dapat mendefinisikan ulang variabel individu atau memodifikasi map `$theme-colors`. Bootstrap juga menyediakan fungsi Sass seperti `tint-color()` dan `shade-color()` untuk menghasilkan variasi warna secara otomatis. Warna kustom dapat ditambahkan sebagai entry baru di dalam `$theme-colors`. Pendekatan ini memastikan seluruh komponen Bootstrap menggunakan warna yang konsisten.

## Contoh Kode Implementasi

```scss
// custom.scss — mengubah warna tema

// Opsi 1: Ubah variabel individu
$primary: #0d6efd;
$success: #198754;

// Opsi 2: Ubah map $theme-colors (lebih komprehensif)
$theme-colors: (
  "primary":    #0d6efd,
  "secondary":  #6c757d,
  "success":    #198754,
  "info":       #0dcaf0,
  "warning":    #ffc107,
  "danger":     #dc3545,
  "light":      #f8f9fa,
  "dark":       #212529
);

// Opsi 3: Tambah warna kustom
$custom-color: #ff6b6b;
$theme-colors: map-merge($theme-colors, (
  "custom": $custom-color
));

@import "../node_modules/bootstrap/scss/bootstrap";
```

## Poin Penting
- Warna tema dikelola melalui `$theme-colors` map dan variabel individual
- Gunakan `map-merge` untuk menambahkan warna kustom ke palet tema
- Perubahan warna diterapkan ke semua komponen seperti button, badge, alert, dan link
- Bootstrap secara otomatis menghasilkan variasi warna (light/dark) menggunakan fungsi Sass
