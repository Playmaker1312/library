# Memahami Bootstrap maps dan cara memodifikasinya

## Analogi: Perpustakaan Digital

Bayangkan papan pengumuman di perpustakaan yang berisi daftar kategori buku dengan kode warnanya: Fiksi = Biru, Non-fiksi = Hijau, Biografi = Kuning. Dalam Sass, struktur seperti ini disebut map — kumpulan pasangan key-value yang memungkinkan data dikelola secara terpusat. Bootstrap menggunakan maps untuk warna tema, breakpoints, spacing, dan banyak lagi.

## Penjelasan Detail

Sass maps adalah struktur data yang mirip dengan objek atau dictionary. Bootstrap menggunakan maps untuk mengelompokkan variabel terkait. Contoh maps penting: `$theme-colors` (warna tema), `$grid-breakpoints` (breakpoints responsif), `$spacers` (skala spacing), `$font-sizes` (ukuran font utility), dan `$utilities` (konfigurasi utility API). Untuk memodifikasi map, gunakan fungsi Sass bawaan seperti `map-merge()` untuk menggabungkan map kustom dengan map default, `map-remove()` untuk menghapus key tertentu, dan `map-get()` untuk mengambil nilai. Bootstrap menerapkan `!default` pada maps, sehingga Anda dapat mendefinisikan ulang map sebelum impor Bootstrap.

## Contoh Kode Implementasi

```scss
// custom.scss — memodifikasi Bootstrap maps

// 1. Merge warna kustom ke theme-colors
$custom-color: (
  "tertiary": #6f42c1,
  "accent": #fd7e14
);
$theme-colors: map-merge($theme-colors, $custom-color);

// 2. Hapus breakpoint xxl
$grid-breakpoints: map-remove($grid-breakpoints, "xxl");

// 3. Ambil nilai dari map
$primary-color: map-get($theme-colors, "primary");

// 4. Tambah spacing kustom
$custom-spacers: (
  6: $spacer * 4,
  7: $spacer * 6
);
$spacers: map-merge($spacers, $custom-spacers);

@import "../node_modules/bootstrap/scss/bootstrap";
```

## Poin Penting
- Sass maps adalah pasangan key-value untuk data terstruktur
- Gunakan `map-merge()` untuk menambah/menggabungkan entry map
- Gunakan `map-remove()` untuk menghapus entry dari map
- Bootstrap menerapkan `!default` pada maps, sehingga nilai kustom didahulukan
