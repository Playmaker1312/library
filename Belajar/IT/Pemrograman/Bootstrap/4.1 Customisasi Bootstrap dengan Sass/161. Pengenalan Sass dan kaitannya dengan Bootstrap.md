# Pengenalan Sass dan kaitannya dengan Bootstrap

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan digital yang memiliki ribuan buku yang dapat diatur ulang sesuai kebutuhan. Sass adalah seperti sistem katalog yang memungkinkan pustakawan mendefinisikan kategori, subkategori, dan aturan pencarian secara terpusat. Bootstrap adalah koleksi buku yang sudah ditulis dengan mengikuti aturan katalog tersebut. Ketika aturan katalog diubah, semua buku dalam koleksi akan menyesuaikan secara otomatis tanpa perlu diedit satu per satu.

## Penjelasan Detail

Sass (Syntactically Awesome Style Sheets) adalah preprocessor CSS yang menambahkan fitur pemrograman seperti variabel, nesting, mixins, dan fungsi ke dalam CSS. Bootstrap dibangun di atas Sass, menjadikannya sangat mudah dikustomisasi. Alih-alih mengedit file CSS Bootstrap secara langsung (yang akan hilang saat update), Anda dapat mengubah variabel Sass Bootstrap sebelum dikompilasi. Dengan Sass, Anda bisa mendefinisikan warna utama, ukuran font, jarak (spacing), dan banyak lagi dalam satu tempat. Bootstrap menggunakan arsitektur modular dengan file-file `.scss` terpisah untuk setiap komponen. Pemahaman tentang Sass adalah kunci untuk memanfaatkan Bootstrap secara maksimal, terutama untuk kebutuhan branding dan desain yang unik.

## Contoh Kode Implementasi

```scss
// Variabel Sass dasar yang digunakan Bootstrap
$primary: #0d6efd;
$font-family-sans-serif: system-ui, -apple-system, "Segoe UI", Roboto;
$border-radius: 0.375rem;

// Nesting Sass — gaya penulisan yang digunakan Bootstrap
.card {
  border-radius: $border-radius;
  
  .card-header {
    background-color: $primary;
    color: white;
  }
}
```

## Poin Penting
- Sass adalah CSS preprocessor yang menambahkan logika pemrograman ke CSS
- Bootstrap 5+ dibangun dengan Sass, memudahkan kustomisasi tema
- Perubahan variabel Sass dilakukan sebelum kompilasi, bukan dengan mengedit file CSS langsung
- Kustomisasi Sass mencegah masalah saat upgrade Bootstrap ke versi baru
