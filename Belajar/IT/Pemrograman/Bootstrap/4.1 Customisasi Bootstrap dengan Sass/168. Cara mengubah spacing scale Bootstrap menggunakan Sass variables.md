# Cara mengubah spacing scale Bootstrap menggunakan Sass variables

## Analogi: Perpustakaan Digital

Seperti mengatur jarak antar rak buku — apakah rapat, standar, atau longgar — spacing scale Bootstrap menentukan jarak antar elemen di halaman web. Ini mencakup margin dan padding pada semua komponen, dari tombol hingga card, dari navbar hingga form.

## Penjelasan Detail

Bootstrap menggunakan variabel `$spacer` sebagai unit dasar spacing, dengan nilai default 1rem (16px). Dari `$spacer`, Bootstrap menghasilkan skala spacing: `0`, `1` (0.25rem), `2` (0.5rem), `3` (1rem), `4` (1.5rem), `5` (3rem), dan seterusnya. Skala ini digunakan oleh utility class `m-*` (margin) dan `p-*` (padding), serta oleh komponen-komponen Bootstrap secara internal. Anda dapat mengubah `$spacer` untuk menyesuaikan seluruh skala, atau mendefinisikan ulang map `$spacers` untuk kontrol yang lebih granular. Map `$spacers` menggunakan sintaks yang memungkinkan penambahan level kustom seperti `6` atau `7`.

## Contoh Kode Implementasi

```scss
// custom.scss — mengubah spacing scale

// Opsi 1: Ubah unit dasar (semua skala berubah)
$spacer: 1.25rem; // dari 1rem menjadi 1.25rem

// Opsi 2: Ubah map $spacers secara keseluruhan
$spacers: (
  0: 0,
  1: $spacer * .25,   // 0.3125rem
  2: $spacer * .5,    // 0.625rem
  3: $spacer,         // 1.25rem
  4: $spacer * 1.5,   // 1.875rem
  5: $spacer * 3,     // 3.75rem
  6: $spacer * 4,     // 5rem
  7: $spacer * 6      // 7.5rem
);

@import "../node_modules/bootstrap/scss/bootstrap";
```

## Poin Penting
- `$spacer` adalah unit dasar untuk seluruh sistem spacing Bootstrap
- Skala spacing menghasilkan utility class `mt-*`, `mb-*`, `pt-*`, `pb-*`, dll.
- Map `$spacers` dapat diperluas dengan level kustom tambahan
- Perubahan spacing memengaruhi komponen internal Bootstrap dan utility classes
