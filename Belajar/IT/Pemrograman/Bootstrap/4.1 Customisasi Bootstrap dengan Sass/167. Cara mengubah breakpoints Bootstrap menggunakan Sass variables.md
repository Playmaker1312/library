# Cara mengubah breakpoints Bootstrap menggunakan Sass variables

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang menyesuaikan tata letak rak berdasarkan ukuran ruangan. Di ruang besar, rak berjejer lima; di ruang sedang, tiga; di ruang kecil, hanya satu. Breakpoints Bootstrap adalah seperti ukuran ruangan ini — titik-titik di mana tata letak halaman berubah untuk menyesuaikan lebar layar pengguna.

## Penjelasan Detail

Breakpoints Bootstrap didefinisikan dalam map `$grid-breakpoints` di `_variables.scss`. Defaultnya adalah `xs: 0`, `sm: 576px`, `md: 768px`, `lg: 992px`, `xl: 1200px`, dan `xxl: 1400px`. Anda dapat mengubah nilai-nilai ini untuk menyesuaikan dengan kebutuhan desain. Misalnya, Anda ingin breakpoint tablet dimulai pada 800px alih-alih 768px. Perubahan breakpoints akan memengaruhi semua class responsive seperti `col-md`, `d-lg-flex`, `text-sm-center`, dan utility lainnya. Penting untuk juga menyesuaikan `$container-max-widths` jika mengubah breakpoints, agar ukuran container tetap proporsional.

## Contoh Kode Implementasi

```scss
// custom.scss — mengubah breakpoints

// 1. Ubah map breakpoints
$grid-breakpoints: (
  xs: 0,
  sm: 480px,
  md: 768px,
  lg: 1024px,
  xl: 1280px,
  xxl: 1600px
);

// 2. Sesuaikan container max-widths
$container-max-widths: (
  sm: 420px,
  md: 720px,
  lg: 960px,
  xl: 1140px,
  xxl: 1440px
);

@import "../node_modules/bootstrap/scss/bootstrap";
```

## Poin Penting
- `$grid-breakpoints` mendefinisikan titik perubahan layout responsif
- Nama (sm, md, lg) tetap sama, hanya nilai pixel yang diubah
- Selalu sesuaikan `$container-max-widths` jika mengubah breakpoints
- Perubahan memengaruhi semua class responsive Bootstrap
