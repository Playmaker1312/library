# Memahami struktur file Sass Bootstrap

## Analogi: Perpustakaan Digital

Bayangkan perpustakaan yang terorganisir dengan rak-rak khusus: rak untuk novel, rak untuk ensiklopedia, rak untuk majalah. Bootstrap Sass memiliki struktur direktori yang mirip, di mana setiap komponen memiliki file `.scss` sendiri. Ada juga file-file utama seperti `_variables.scss` yang berisi semua pengaturan tema, seperti katalog pusat yang mendefinisikan setiap kategori buku di perpustakaan.

## Penjelasan Detail

Struktur file Sass Bootstrap dirancang secara modular. Di dalam `node_modules/bootstrap/scss/`, Anda akan menemukan file `bootstrap.scss` sebagai entry point yang mengimpor semua komponen. File-file dengan awalan underscore (seperti `_variables.scss`, `_mixins.scss`, `_functions.scss`) disebut partials — tidak dikompilasi sendiri melainkan diimpor ke file lain. Folder `forms/` berisi partials untuk komponen form, folder `helpers/` untuk utility helpers, dan folder `utilities/` untuk utility classes. File `_variables.scss` adalah yang paling penting untuk kustomisasi karena berisi ratusan variabel yang mengontrol tampilan Bootstrap. Memahami struktur ini memungkinkan Anda mengimpor hanya komponen yang dibutuhkan dan menimpa variabel secara tepat.

## Contoh Kode Implementasi

```scss
// Struktur file di node_modules/bootstrap/scss/
// bootstrap.scss (entry point)
// _variables.scss    → variabel kustomisasi
// _functions.scss    → fungsi Sass Bootstrap
// _mixins.scss       → mixins Bootstrap
// _root.scss         → variabel CSS custom properties
// _reboot.scss       → CSS reset/normalize
// _type.scss         → tipografi
// _grid.scss         → sistem grid
// forms/             → komponen form
//   _labels.scss
//   _input-group.scss
// components/        → komponen UI
//   _buttons.scss
//   _cards.scss
//   _navbar.scss
// helpers/           → helper classes
// utilities/         → utility API
```

## Poin Penting
- File partials diawali underscore (`_variables.scss`) dan diimpor ke file utama
- `_variables.scss` adalah file kunci untuk kustomisasi tema Bootstrap
- Bootstrap memisahkan komponen ke dalam folder `components/`, `forms/`, `helpers/`, dan `utilities/`
- Entry point `bootstrap.scss` mengimpor semua komponen secara berurutan
