# Cara mengimpor Bootstrap secara parsial menggunakan Sass

## Analogi: Perpustakaan Digital

Seperti memilih hanya beberapa bab dari ensiklopedia untuk difotokopi, mengimpor Bootstrap secara parsial berarti mengambil hanya komponen yang benar-benar Anda butuhkan. Ini menghemat ruang penyimpanan (ukuran file CSS) dan mempercepat waktu pemuatan. Perpustakaan digital Anda hanya berisi bagian-bagian yang relevan dengan proyek Anda.

## Penjelasan Detail

Secara default, `bootstrap.scss` mengimpor semua komponen — mulai dari grid, buttons, cards, hingga carousel. Namun, Anda mungkin hanya membutuhkan sebagian kecil dari Bootstrap. Dengan Sass, Anda dapat membuat file kustom yang hanya mengimpor komponen tertentu. Caranya adalah dengan mengatur variabel `$enable-*` ke `false` atau dengan mengomentari baris `@import` yang tidak diinginkan. Pendekatan yang lebih baik adalah menggunakan `@use` dengan namespace. Setelah menentukan komponen mana yang diimpor, jalankan kompilasi Sass. Hasil CSS akan jauh lebih kecil, ideal untuk proyek yang membutuhkan performa tinggi.

## Contoh Kode Implementasi

```scss
// custom.scss — mengimpor hanya komponen yang dibutuhkan

// 1. Wajib: functions, variables, mixins
@import "../node_modules/bootstrap/scss/functions";
@import "../node_modules/bootstrap/scss/variables";
@import "../node_modules/bootstrap/scss/mixins";

// 2. Komponen yang diinginkan
@import "../node_modules/bootstrap/scss/root";
@import "../node_modules/bootstrap/scss/reboot";
@import "../node_modules/bootstrap/scss/type";
@import "../node_modules/bootstrap/scss/grid";
@import "../node_modules/bootstrap/scss/buttons";
@import "../node_modules/bootstrap/scss/forms";
@import "../node_modules/bootstrap/scss/card";
@import "../node_modules/bootstrap/scss/nav";
@import "../node_modules/bootstrap/scss/navbar";

// 3. Utilities (wajib jika menggunakan utility classes)
@import "../node_modules/bootstrap/scss/utilities";
@import "../node_modules/bootstrap/scss/utilities/api";
```

## Poin Penting
- Impor minimal: `functions`, `variables`, `mixins`, `root`, `reboot`, `utilities`, dan `utilities/api`
- Hanya impor komponen yang benar-benar digunakan di proyek
- Impor partials setelah variabel kustom ditentukan agar perubahan diterapkan
- Gunakan kompilasi untuk memeriksa ukuran file akhir
