# Cara menggunakan PurgeCSS atau PurgeBootstrap untuk menghapus CSS yang tidak terpakai

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki ribuan buku di katalog, tetapi hanya seratus yang paling sering dipinjam. Buku-buku lain hanya memenuhi ruang server. PurgeCSS seperti petugas yang memeriksa rak dan memindahkan buku yang tidak pernah dibaca ke gudang, sehingga ruang rak utama lebih efisien.

## Penjelasan Detail

PurgeCSS adalah alat yang menganalisis file HTML dan JavaScript Anda, lalu menghapus CSS yang tidak digunakan dari Bootstrap. Karena Bootstrap menyertakan banyak utility classes yang mungkin tidak Anda gunakan, PurgeCSS bisa mengurangi ukuran file CSS hingga 90%. Alat ini dapat diintegrasikan dengan Webpack, Vite, PostCSS, atau digunakan secara standalone. Pastikan untuk mengkonfigurasi `safelist` agar kelas yang ditambahkan secara dinamis oleh JavaScript tidak terhapus.

## Contoh Kode Implementasi

```javascript
// postcss.config.js dengan PurgeCSS
const purgecss = require('@fullhuman/postcss-purgecss')({
  content: [
    './src/**/*.html',
    './src/**/*.js',
    './src/**/*.jsx',
    './src/**/*.tsx',
  ],
  defaultExtractor: (content) => content.match(/[\w-/:]+(?<!:)/g) || [],
  safelist: {
    standard: [
      /^(bg|text|border)-/,
      /^btn-/,
      /^modal/,
      /^fade/,
      /^show/,
      /^active/,
    ],
    deep: [/^bs-/],
    greedy: [/tooltip/, /popover/],
  },
});

module.exports = {
  plugins: [
    require('autoprefixer'),
    ...(process.env.NODE_ENV === 'production' ? [purgecss] : []),
  ],
};
```

```bash
# Menggunakan PurgeCSS via CLI
npx purgecss --css bootstrap.min.css --content index.html about.html --output dist/css/
```

## Poin Penting
- PurgeCSS bisa mengurangi ukuran Bootstrap hingga 90% di production
- Safelist kelas yang ditambahkan JavaScript secara dinamis
- Jalankan PurgeCSS hanya di production, bukan di development
