# Cara menggunakan hanya bagian Bootstrap yang diperlukan untuk mengurangi ukuran file

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki koleksi besar buku, tetapi pengguna hanya ingin meminjam beberapa buku tertentu. Daripada membawa seluruh rak buku, pengguna cukup mengambil buku yang diperlukan. Bootstrap memungkinkan Anda memilih hanya komponen yang Anda butuhkan, mengurangi ukuran file CSS dan JavaScript yang harus diunduh.

## Penjelasan Detail

Bootstrap dibangun menggunakan Sass, yang memungkinkan Anda mengimpor hanya komponen yang diperlukan. Dengan mengatur variabel `$enable-*` ke `false` dan mengimpor file partial secara selektif, Anda bisa mengurangi ukuran CSS hingga 70%. File JavaScript juga bisa dipilih: Anda bisa menggunakan `bootstrap.bundle.min.js` untuk semua plugin, atau memilih plugin individual seperti `bootstrap.Collapse`, `bootstrap.Modal`, dll. Pendekatan ini sangat penting untuk meningkatkan performa halaman.

## Contoh Kode Implementasi

```scss
// custom-bootstrap.scss
// 1. Import functions dan variables
@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/variables-dark";
@import "bootstrap/scss/maps";
@import "bootstrap/scss/mixins";

// 2. Matikan komponen yang tidak diperlukan
$enable-caret: false;
$enable-rounded: true;
$enable-shadows: false;
$enable-gradients: false;
$enable-transitions: true;
$enable-reduced-motion: true;
$enable-grid-classes: true;
$enable-container-classes: true;
$enable-cssgrid: false;
$enable-button-pointers: true;
$enable-rfs: true;
$enable-validation-icons: true;
$enable-negative-margins: false;
$enable-deprecation-messages: false;
$enable-important-utilities: true;

// 3. Import hanya komponen yang digunakan
@import "bootstrap/scss/root";
@import "bootstrap/scss/reboot";
@import "bootstrap/scss/type";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/containers";
@import "bootstrap/scss/buttons";
@import "bootstrap/scss/forms";
@import "bootstrap/scss/nav";
@import "bootstrap/scss/navbar";
@import "bootstrap/scss/card";
@import "bootstrap/scss/utilities";
@import "bootstrap/scss/utilities/api";
```

## Poin Penting
- Impor hanya komponen Bootstrap yang benar-benar Anda gunakan dalam project
- Setel variabel `$enable-*` untuk mematikan fitur yang tidak diperlukan
- Gunakan selective import untuk JavaScript plugin secara individual
