# Mengukur performa halaman Bootstrap menggunakan Lighthouse

## Analogi: Perpustakaan Digital

Perpustakaan digital melakukan inspeksi rutin untuk memeriksa apakah rak buku mudah diakses, pintu masuk cepat terbuka, dan pengunjung tidak menunggu lama. Lighthouse adalah alat inspeksi performa untuk halaman web yang memberikan laporan detail tentang kecepatan, aksesibilitas, dan praktik terbaik.

## Penjelasan Detail

Lighthouse adalah alat open-source dari Google yang mengaudit performa, aksesibilitas, SEO, dan best practices. Untuk halaman Bootstrap, Lighthouse akan memeriksa: First Contentful Paint (FCP), Largest Contentful Paint (LCP), Time to Interactive (TTI), Cumulative Layout Shift (CLS), dan ukuran CSS/JavaScript. Jalankan Lighthouse di Chrome DevTools (tab Lighthouse), via CLI (`npx lighthouse <url>`), atau di PageSpeed Insights. Skor target: Performa > 90, Aksesibilitas > 90, SEO > 90.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Lighthouse Test Page</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
  <!-- Meta untuk SEO -->
  <meta name="description" content="Halaman Bootstrap yang dioptimasi untuk audit Lighthouse">
  <meta name="theme-color" content="#0d6efd">
</head>
<body>
  <!-- Konten dengan semantic HTML untuk SEO -->
  <header>
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
      <div class="container">
        <a class="navbar-brand" href="#">Lighthouse Test</a>
      </div>
    </nav>
  </header>
  <main class="container my-4">
    <h1>Halaman Audit Bootstrap</h1>
    <article>
      <p>Konten artikel dengan semantic HTML untuk SEO dan aksesibilitas.</p>
      <img src="https://via.placeholder.com/800x400" class="img-fluid" alt="Deskripsi gambar" loading="lazy" width="800" height="400">
    </article>
    <div class="ratio ratio-16x9 my-4">
      <iframe src="https://www.youtube.com/embed/dQw4w9WgXcQ" title="Video" allowfullscreen loading="lazy"></iframe>
    </div>
  </main>
  <footer class="bg-light py-3 text-center">
    <p class="mb-0">&copy; 2026 Bootstrap Optimized</p>
  </footer>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js" defer></script>
</body>
</html>
```

```bash
# Jalankan Lighthouse CLI
npx lighthouse http://localhost:3000 --view --preset=desktop
npx lighthouse http://localhost:3000 --view --preset=mobile
```

## Poin Penting
- Target skor Lighthouse: Performa > 90, Aksesibilitas > 90, SEO > 90
- Perhatikan metrik FCP, LCP, TTI, dan CLS
- Gunakan semantic HTML dan atribut `loading="lazy"` untuk nilai tambah
