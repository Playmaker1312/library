# Menggunakan lazy loading pada gambar di dalam komponen Bootstrap

## Analogi: Perpustakaan Digital

Perpustakaan digital menampilkan galeri sampul buku. Di desktop, semua sampul langsung terlihat. Di ponsel, pengguna harus scroll ke bawah untuk melihat lebih banyak. Daripada memuat semua 100 sampul buku sekaligus, perpustakaan hanya memuat yang terlihat di layar dan sisanya dimuat saat pengguna scroll. Ini adalah lazy loading.

## Penjelasan Detail

Lazy loading menunda pemuatan gambar hingga gambar tersebut mendekati viewport. Bootstrap 5 kompatibel dengan native lazy loading HTML (`loading="lazy"`) yang didukung semua browser modern. Untuk komponen Bootstrap seperti carousel atau card grid, tambahkan atribut `loading="lazy"` dan `decoding="async"`. Untuk browser lama, gunakan JavaScript Intersection Observer API. Dengan lazy loading, halaman awal lebih cepat dimuat dan konsumsi bandwidth berkurang.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Lazy Loading Bootstrap</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Galeri dengan Lazy Loading</h1>
    <div class="row">
      <!-- Lazy loading native -->
      <div class="col-6 col-md-4 col-lg-3 mb-4">
        <div class="card">
          <img src="https://via.placeholder.com/400x300?text=Gambar+1" 
               class="card-img-top" alt="Gambar 1" loading="lazy" decoding="async">
          <div class="card-body">
            <p class="card-text">Gambar 1 (lazy)</p>
          </div>
        </div>
      </div>
      <!-- Intersection Observer untuk carousel -->
      <div id="carouselLazy" class="carousel slide" data-bs-ride="carousel">
        <div class="carousel-inner">
          <div class="carousel-item active">
            <img data-src="https://via.placeholder.com/800x400?text=Slide+1" 
                 class="d-block w-100 lazy-carousel" alt="Slide 1">
          </div>
          <div class="carousel-item">
            <img data-src="https://via.placeholder.com/800x400?text=Slide+2" 
                 class="d-block w-100 lazy-carousel" alt="Slide 2">
          </div>
        </div>
      </div>
    </div>
  </div>
  <script>
    // Intersection Observer untuk carousel
    document.addEventListener('DOMContentLoaded', function() {
      const lazyImages = document.querySelectorAll('.lazy-carousel');
      const observer = new IntersectionObserver((entries) => {
        entries.forEach(entry => {
          if (entry.isIntersecting) {
            const img = entry.target;
            img.src = img.dataset.src;
            img.classList.remove('lazy-carousel');
            observer.unobserve(img);
          }
        });
      });
      lazyImages.forEach(img => observer.observe(img));
    });
  </script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js" defer></script>
</body>
</html>
```

## Poin Penting
- Gunakan atribut `loading="lazy"` untuk gambar di card dan grid
- Gunakan Intersection Observer untuk kontrol lazy loading kustom
- Lazy loading mengurangi waktu muat awal dan konsumsi data
