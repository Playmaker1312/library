# Memahami critical CSS dan cara menerapkannya dengan Bootstrap

## Analogi: Perpustakaan Digital

Ketika pengguna membuka perpustakaan digital, mereka ingin melihat konten utama (daftar buku favorit) secepat mungkin, meskipun gambar sampul dan animasi belum termuat. Critical CSS adalah teknik menyajikan CSS yang paling penting terlebih dahulu, seperti menyajikan judul buku sebelum desain rak yang rumit.

## Penjelasan Detail

Critical CSS adalah praktik mengekstrak CSS yang diperlukan untuk merender konten "above the fold" (bagian halaman yang terlihat tanpa scroll) dan menyisipkannya langsung di `<head>` dalam tag `<style>`. Sisanya dimuat secara asinkron. Untuk Bootstrap, critical CSS biasanya mencakup `reboot`, `grid`, `containers`, `type`, dan komponen yang terlihat di bagian atas halaman. Gunakan alat seperti `critical` (Node.js) atau `Penthouse` untuk mengekstrak critical CSS secara otomatis.

## Contoh Kode Implementasi

```javascript
// Menggunakan critical npm package
const critical = require('critical');

critical.generate({
  base: 'dist/',
  src: 'index.html',
  dest: 'index-critical.html',
  width: 1300,
  height: 900,
  inline: true,
  extract: true,
  ignore: {
    atrule: ['@font-face'],
    decl: [/font-/],
  },
  // Bootstrap-specific: hanya ekstrak yang diperlukan di atas fold
  penthouse: {
    forceInclude: [
      /bootstrap.*\.reboot/,
      /bootstrap.*\.container/,
      /bootstrap.*\.row/,
      /bootstrap.*\.navbar/,
    ],
  },
});
```

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Critical CSS Bootstrap</title>
  <!-- Critical CSS di-inline -->
  <style>
    /* Hasil extract critical CSS ditempatkan di sini */
    .container { width: 100%; padding-right: 15px; padding-left: 15px; }
    .row { display: flex; flex-wrap: wrap; }
    .navbar { display: flex; align-items: center; }
  </style>
  <!-- Non-critical CSS dimuat asinkron -->
  <link rel="preload" href="bootstrap.min.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
  <noscript><link rel="stylesheet" href="bootstrap.min.css"></noscript>
</head>
<body>
  <!-- konten -->
</body>
</html>
```

## Poin Penting
- Critical CSS mempercepat First Contentful Paint (FCP)
- Ekstrak CSS Bootstrap untuk bagian "above the fold" saja
- Gunakan `preload` dengan `onload` untuk memuat CSS non-critical secara asinkron
