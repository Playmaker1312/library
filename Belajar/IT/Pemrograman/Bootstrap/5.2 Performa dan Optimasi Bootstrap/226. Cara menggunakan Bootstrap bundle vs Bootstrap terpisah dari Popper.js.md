# Cara menggunakan Bootstrap bundle vs Bootstrap terpisah dari Popper.js

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki paket buku lengkap dengan kamus di dalamnya (bundle), atau buku terpisah dengan kamus yang harus diambil dari rak lain (separate). Keduanya berfungsi sama, tetapi bundle lebih praktis sementara separate memberikan kontrol lebih besar.

## Penjelasan Detail

Bootstrap menyediakan dua opsi JavaScript: `bootstrap.bundle.min.js` yang sudah termasuk Popper.js (library positioning untuk tooltip, popover, dropdown) dan `bootstrap.min.js` yang tidak termasuk Popper.js. Bundle lebih mudah digunakan karena hanya membutuhkan satu file. Opsi terpisah diperlukan jika Anda sudah memiliki Popper.js sendiri, atau ingin menggunakan versi Popper.js yang berbeda. Popper.js wajib untuk komponen: dropdown, tooltip, popover, dan offcanvas dengan positioning.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bundle vs Separate</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-4">
    <h1>Contoh Tooltip (membutuhkan Popper.js)</h1>
    <button type="button" class="btn btn-secondary" data-bs-toggle="tooltip" data-bs-placement="top" title="Tooltip example">
      Hover saya
    </button>
    <button type="button" class="btn btn-primary" data-bs-toggle="popover" title="Popover" data-bs-content="Isi popover">
      Klik saya
    </button>
  </div>

  <!-- Opsi 1: Bundle (termasuk Popper.js) - cukup 1 file -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

  <!-- Opsi 2: Separate - perlu Popper.js dulu baru Bootstrap -->
  <!-- 
  <script src="https://cdn.jsdelivr.net/npm/@popperjs/core@2.11.8/dist/umd/popper.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.min.js"></script>
  -->

  <script>
    // Inisialisasi tooltip dan popover
    document.addEventListener('DOMContentLoaded', function() {
      var tooltipTriggerList = [].slice.call(document.querySelectorAll('[data-bs-toggle="tooltip"]'));
      tooltipTriggerList.map(function(el) { return new bootstrap.Tooltip(el); });
      var popoverTriggerList = [].slice.call(document.querySelectorAll('[data-bs-toggle="popover"]'));
      popoverTriggerList.map(function(el) { return new bootstrap.Popover(el); });
    });
  </script>
</body>
</html>
```

## Poin Penting
- Bundle termasuk Popper.js, cocok untuk project sederhana
- Opsi terpisah diperlukan jika menggunakan Popper.js versi lain
- Tooltip, Popover, Dropdown, dan Offcanvas memerlukan Popper.js
