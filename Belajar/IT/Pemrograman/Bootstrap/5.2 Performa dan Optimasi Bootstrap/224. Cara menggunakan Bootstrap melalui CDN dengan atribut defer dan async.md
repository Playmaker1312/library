# Cara menggunakan Bootstrap melalui CDN dengan atribut defer dan async

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki beberapa skrip yang dijalankan saat halaman dimuat. Jika skrip dimuat secara berurutan, pengguna harus menunggu lebih lama sebelum bisa berinteraksi. Dengan `defer` dan `async`, perpustakaan bisa memuat skrip di latar belakang tanpa menghalangi tampilan konten utama.

## Penjelasan Detail

Atribut `async` dan `defer` pada tag `<script>` mengontrol bagaimana JavaScript dimuat dan dieksekusi. `async` mengunduh skrip paralel dan mengeksekusinya segera setelah selesai. `defer` mengunduh paralel tetapi mengeksekusi setelah HTML selesai diparses. Untuk Bootstrap, yang bergantung pada DOM dan Popper.js, gunakan `defer` untuk Bootstrap bundle agar memastikan DOM siap. Untuk analitik atau skrip pihak ketiga yang independent, gunakan `async`.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CDN Defer Async</title>
  <!-- CSS Bootstrap: selalu di head -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <!-- Konten halaman -->
  <div class="container">
    <h1>Halaman dengan Bootstrap</h1>
    <button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#exampleModal">Buka Modal</button>
    <div class="modal fade" id="exampleModal">
      <div class="modal-dialog">
        <div class="modal-content">
          <div class="modal-header"><h5 class="modal-title">Modal</h5></div>
          <div class="modal-body"><p>Konten modal</p></div>
        </div>
      </div>
    </div>
  </div>

  <!-- JavaScript Bootstrap dengan defer -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js" defer></script>
  
  <!-- Skrip analitik independent dengan async -->
  <script src="https://www.google-analytics.com/analytics.js" async></script>

  <!-- Skrip kustom yang membutuhkan Bootstrap -->
  <script src="script.js" defer></script>
</body>
</html>
```

## Poin Penting
- Gunakan `defer` untuk Bootstrap bundle karena bergantung pada DOM
- Gunakan `async` untuk skrip independent seperti analitik
- CSS selalu muat di `<head>`, JavaScript dengan `defer` di akhir `<body>`
