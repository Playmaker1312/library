# Memahami perbedaan bootstrap.css dan bootstrap.min.css dari sisi performa

## Analogi: Perpustakaan Digital

Perpustakaan digital memiliki dua versi katalog: satu dengan format rapi yang mudah dibaca manusia, dan satu lagi yang dikompresi tanpa spasi dan baris baru untuk menghemat ruang server. Keduanya berisi informasi yang sama, tetapi versi terkompresi lebih cepat diunduh oleh pengunjung perpustakaan.

## Penjelasan Detail

`bootstrap.css` adalah file CSS yang sudah diformat dengan indenasi, spasi, dan komentar untuk kemudahan debugging. Ukurannya sekitar 200-230KB. `bootstrap.min.css` adalah versi minified yang menghilangkan semua spasi, baris baru, komentar, dan mempersingkat nama variabel. Ukurannya sekitar 150-170KB. Proses minifikasi mengurangi ukuran file sekitar 20-30%, yang berarti waktu unduh lebih cepat, terutama di koneksi lambat. Di production, selalu gunakan `.min.css`. Gunakan file non-minified hanya saat development untuk debugging.

## Contoh Kode Implementasi

```html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS vs Minified CSS</title>
  <!-- Development: gunakan file non-minified -->
  <!-- <link href="bootstrap.css" rel="stylesheet"> -->
  
  <!-- Production: gunakan file minified -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <div class="container mt-5">
    <h1>Perbandingan Ukuran File Bootstrap 5</h1>
    <table class="table">
      <thead>
        <tr><th>File</th><th>Ukuran (approx)</th><th>Keterangan</th></tr>
      </thead>
      <tbody>
        <tr><td>bootstrap.css</td><td>~230KB</td><td>Dengan komentar dan spasi</td></tr>
        <tr><td>bootstrap.min.css</td><td>~175KB</td><td>Terminifikasi, tanpa komentar</td></tr>
        <tr><td>bootstrap.js</td><td>~80KB</td><td>JavaScript non-minified</td></tr>
        <tr><td>bootstrap.min.js</td><td>~45KB</td><td>JavaScript terminifikasi</td></tr>
      </tbody>
    </table>
  </div>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
```

## Poin Penting
- Gunakan `.min.css` untuk production dan `.css` untuk development
- Minifikasi mengurangi ukuran file 20-30% tanpa mengubah fungsionalitas
- CDN Bootstrap secara default menyediakan kedua versi
