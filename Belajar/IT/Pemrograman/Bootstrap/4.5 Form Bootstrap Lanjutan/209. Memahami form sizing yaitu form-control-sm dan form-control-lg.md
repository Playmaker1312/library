# Memahami form sizing yaitu form-control-sm dan form-control-lg

## Analogi: Perpustakaan Digital

Seperti formulir dengan ukuran font berbeda — ada formulir saku (kecil) untuk kartu anggota, formulir standar untuk pendaftaran, dan formulir besar (large print) untuk pengguna tunanetra. Bootstrap menyediakan class ukuran untuk form control agar sesuai dengan konteks dan kebutuhan desain.

## Penjelasan Detail

Bootstrap menawarkan tiga ukuran untuk form control: default (ukuran sedang), `.form-control-sm` (kecil), dan `.form-control-lg` (besar). Class ini mengubah padding, font-size, dan border-radius. Tersedia untuk: input text (`form-control-sm/lg`), select (`form-select-sm/lg`), input group (`input-group-sm/lg`), dan label (`col-form-label-sm/lg`). Ukuran default ideal untuk sebagian besar kasus. `.form-control-sm` cocok untuk form padat atau filter bar. `.form-control-lg` cocok untuk form di halaman utama atau mobile dengan target sentuh yang lebih besar. Konsistensi ukuran penting — gunakan ukuran yang sama untuk semua elemen dalam satu form.

## Contoh Kode Implementasi

```html
<div class="container mt-4">
  <h4>Ukuran Kecil (Small)</h4>
  <div class="mb-3">
    <input type="text" class="form-control form-control-sm mb-2" 
           placeholder="Input kecil (form-control-sm)">
    <select class="form-select form-select-sm mb-2">
      <option>Select kecil</option>
    </select>
    <div class="input-group input-group-sm mb-2">
      <span class="input-group-text">@</span>
      <input type="text" class="form-control" placeholder="Input group kecil">
    </div>
  </div>

  <h4>Ukuran Default (Sedang)</h4>
  <div class="mb-3">
    <input type="text" class="form-control mb-2" 
           placeholder="Input default (tanpa class size)">
    <select class="form-select mb-2">
      <option>Select default</option>
    </select>
    <div class="input-group mb-2">
      <span class="input-group-text">Rp</span>
      <input type="text" class="form-control" placeholder="Input group default">
    </div>
  </div>

  <h4>Ukuran Besar (Large)</h4>
  <div class="mb-3">
    <input type="text" class="form-control form-control-lg mb-2" 
           placeholder="Input besar (form-control-lg)">
    <select class="form-select form-select-lg mb-2">
      <option>Select besar</option>
    </select>
    <div class="input-group input-group-lg mb-2">
      <span class="input-group-text">🔍</span>
      <input type="text" class="form-control" placeholder="Input group besar">
    </div>
  </div>

  <h4>Perbandingan Langsung</h4>
  <div class="row align-items-center mb-3">
    <div class="col-4">
      <input type="text" class="form-control form-control-sm" placeholder="Small">
    </div>
    <div class="col-4">
      <input type="text" class="form-control" placeholder="Default">
    </div>
    <div class="col-4">
      <input type="text" class="form-control form-control-lg" placeholder="Large">
    </div>
  </div>

  <!-- Horizontal form dengan sizing -->
  <div class="row mb-3">
    <label class="col-sm-2 col-form-label col-form-label-sm">Label Kecil</label>
    <div class="col-sm-10">
      <input type="text" class="form-control form-control-sm">
    </div>
  </div>
  <div class="row mb-3">
    <label class="col-sm-2 col-form-label col-form-label-lg">Label Besar</label>
    <div class="col-sm-10">
      <input type="text" class="form-control form-control-lg">
    </div>
  </div>
</div>
```

## Poin Penting
- Class ukuran: `.form-control-sm` (kecil), default (sedang), `.form-control-lg` (besar)
- Tersedia untuk input, select, input-group, dan col-form-label
- Konsisten gunakan ukuran yang sama dalam satu form untuk tampilan rapi
- Ukuran besar (lg) meningkatkan target area sentuh untuk perangkat mobile
