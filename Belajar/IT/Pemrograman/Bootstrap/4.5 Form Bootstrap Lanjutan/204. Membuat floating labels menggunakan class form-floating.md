# Membuat floating labels menggunakan class form-floating

## Analogi: Perpustakaan Digital

Seperti label pada rak buku yang tampak mengambang di atas buku — saat tidak ada buku, label terlihat jelas; saat buku diletakkan, label "naik" ke atas. Floating labels Bootstrap adalah label input yang berada di dalam input field dan "naik" ke posisi di atas saat pengguna mulai mengetik atau input sudah terisi.

## Penjelasan Detail

Floating labels adalah pendekatan desain form di mana label ditempatkan di dalam area input. Saat input kosong, label terlihat di tempat placeholder; saat input diisi atau mendapat fokus, label bergerak ke atas dengan animasi. Implementasi: bungkus pasangan input+label dalam container `.form-floating`. Label ditempatkan SETELAH input di HTML. Input membutuhkan atribut `placeholder` (meskipun kosong) agar floating label berfungsi. Class ini mendukung semua tipe input: text, email, password, select, textarea. Floating labels memberikan tampilan yang lebih bersih dan modern dibandingkan label tradisional.

## Contoh Kode Implementasi

```html
<div class="container mt-4">
  <h3>Form Pendaftaran Anggota Perpustakaan</h3>

  <!-- Floating label text input -->
  <div class="form-floating mb-3">
    <input type="text" class="form-control" id="namaLengkap" 
           placeholder="Nama Lengkap" required>
    <label for="namaLengkap">Nama Lengkap</label>
  </div>

  <!-- Floating label email -->
  <div class="form-floating mb-3">
    <input type="email" class="form-control" id="emailAnggota" 
           placeholder="nama@email.com">
    <label for="emailAnggota">Alamat Email</label>
  </div>

  <!-- Floating label password -->
  <div class="form-floating mb-3">
    <input type="password" class="form-control" id="passwordAnggota" 
           placeholder="Password">
    <label for="passwordAnggota">Password</label>
  </div>

  <!-- Floating label select -->
  <div class="form-floating mb-3">
    <select class="form-select" id="kategoriAnggota" 
            placeholder="Pilih kategori">
      <option value="1">Pelajar</option>
      <option value="2">Mahasiswa</option>
      <option value="3">Umum</option>
    </select>
    <label for="kategoriAnggota">Kategori Anggota</label>
  </div>

  <!-- Floating label textarea -->
  <div class="form-floating mb-3">
    <textarea class="form-control" id="alamatAnggota" 
              placeholder="Alamat" style="height: 100px"></textarea>
    <label for="alamatAnggota">Alamat Lengkap</label>
  </div>

  <!-- Floating label dengan value default -->
  <div class="form-floating mb-3">
    <input type="text" class="form-control" id="kota" 
           placeholder="Kota" value="Jakarta">
    <label for="kota">Kota</label>
  </div>
</div>
```

## Poin Penting
- Bungkus input dan label dalam `<div class="form-floating">`
- Tempatkan label SETELAH input dalam urutan HTML
- Input WAJIB memiliki atribut `placeholder` (bisa string kosong)
- Label bergerak ke atas saat input diisi, mendapat fokus, atau memiliki value
