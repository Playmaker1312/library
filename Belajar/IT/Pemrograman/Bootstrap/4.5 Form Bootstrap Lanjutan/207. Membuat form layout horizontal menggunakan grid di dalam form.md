# Membuat form layout horizontal menggunakan grid di dalam form

## Analogi: Perpustakaan Digital

Seperti formulir cetak di perpustakaan di mana label berada di kolom kiri dan input di kolom kanan — form layout horizontal Bootstrap menggunakan sistem grid untuk menempatkan label dan input secara berdampingan, menghemat ruang vertikal dan memberikan tampilan yang lebih terstruktur.

## Penjelasan Detail

Bootstrap grid system dapat digunakan di dalam form untuk membuat layout horizontal. Gunakan class `.row` untuk baris, lalu atur kolom untuk label (biasanya `.col-md-*`) dan input (`.col-md-*`). Class `.col-form-label` diterapkan pada `<label>` untuk menyesuaikan alignment vertikal dengan input. Gunakan `.col-form-label-sm` atau `.col-form-label-lg` untuk ukuran yang sesuai. Untuk checkbox dan radio button horizontal, gunakan class `.col-form-label` kosong untuk alignment yang rapi. Row di dalam form bisa berisi multiple kolom input dalam satu baris. Form horizontal sangat cocok untuk halaman dengan banyak field seperti profil pengguna, pengaturan, atau entri data.

## Contoh Kode Implementasi

```html
<form>
  <!-- Baris dengan label dan input berdampingan -->
  <div class="row mb-3">
    <label for="namaBuku" class="col-sm-3 col-form-label">Judul Buku</label>
    <div class="col-sm-9">
      <input type="text" class="form-control" id="namaBuku">
    </div>
  </div>

  <div class="row mb-3">
    <label for="penulis" class="col-sm-3 col-form-label">Penulis</label>
    <div class="col-sm-9">
      <input type="text" class="form-control" id="penulis">
    </div>
  </div>

  <!-- Multiple field dalam satu baris -->
  <div class="row mb-3">
    <label for="tahun" class="col-sm-3 col-form-label">Tahun Terbit</label>
    <div class="col-sm-3">
      <input type="number" class="form-control" id="tahun" placeholder="Tahun">
    </div>
    <label for="halaman" class="col-sm-2 col-form-label">Halaman</label>
    <div class="col-sm-4">
      <input type="number" class="form-control" id="halaman" placeholder="Jumlah">
    </div>
  </div>

  <!-- Select horizontal -->
  <div class="row mb-3">
    <label for="kategoriBuku" class="col-sm-3 col-form-label">Kategori</label>
    <div class="col-sm-9">
      <select class="form-select" id="kategoriBuku">
        <option>Fiksi</option>
        <option>Non-Fiksi</option>
        <option>Referensi</option>
      </select>
    </div>
  </div>

  <!-- Textarea horizontal -->
  <div class="row mb-3">
    <label for="sinopsis" class="col-sm-3 col-form-label">Sinopsis</label>
    <div class="col-sm-9">
      <textarea class="form-control" id="sinopsis" rows="3"></textarea>
    </div>
  </div>

  <!-- Checkbox horizontal -->
  <div class="row mb-3">
    <div class="col-sm-3">Tersedia</div>
    <div class="col-sm-9">
      <div class="form-check">
        <input type="checkbox" class="form-check-input" id="tersedia" checked>
        <label class="form-check-label" for="tersedia">Buku tersedia untuk dipinjam</label>
      </div>
    </div>
  </div>

  <!-- Tombol -->
  <div class="row">
    <div class="col-sm-3"></div>
    <div class="col-sm-9">
      <button type="submit" class="btn btn-primary">Simpan</button>
      <button type="reset" class="btn btn-secondary">Reset</button>
    </div>
  </div>
</form>
```

## Poin Penting
- Gunakan `.row` dan `.col-*` untuk layout form horizontal
- Tambahkan `.col-form-label` pada label untuk alignment vertikal yang benar
- Atur lebar kolom label dan input dengan class grid (contoh: `col-sm-3` dan `col-sm-9`)
- Form horizontal menghemat ruang vertikal pada layar besar
