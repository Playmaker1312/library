# Menggunakan valid-feedback dan invalid-feedback untuk pesan error

## Analogi: Perpustakaan Digital

Seperti catatan penjelasan yang ditempelkan pada formulir — "Bagian ini harus diisi" atau "Nomor telepon sudah benar" — `.valid-feedback` dan `.invalid-feedback` adalah elemen yang menampilkan pesan penjelasan kepada pengguna tentang status validasi input mereka.

## Penjelasan Detail

`.valid-feedback` dan `.invalid-feedback` adalah elemen sibling (saudara) dari input yang menampilkan pesan berdasarkan state validasi. `.valid-feedback` muncul saat input valid (border hijau), `.invalid-feedback` muncul saat input tidak valid (border merah). Keduanya menggunakan display block/none berdasarkan class state pada input. Anda bisa menampilkan beberapa pesan error dalam satu `.invalid-feedback`. Untuk tooltip validation, gunakan `.valid-tooltip` dan `.invalid-tooltip` sebagai pengganti. Feedback messages hanya muncul jika input memiliki class `.is-valid`/`.is-invalid` atau form memiliki class `.was-validated`. Pesan default dapat dikustomisasi per input.

## Contoh Kode Implementasi

```html
<form class="needs-validation" novalidate>
  <!-- Input dengan multiple error messages -->
  <div class="mb-3">
    <label for="password" class="form-label">Password</label>
    <input type="password" class="form-control" id="password" 
           required minlength="8" pattern="(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).*">
    <div class="valid-feedback">
      Password kuat!
    </div>
    <div class="invalid-feedback">
      <ul class="mb-0">
        <li>Minimal 8 karakter</li>
        <li>Harus mengandung huruf besar</li>
        <li>Harus mengandung angka</li>
      </ul>
    </div>
  </div>

  <!-- Checkbox dengan feedback -->
  <div class="mb-3">
    <div class="form-check">
      <input type="checkbox" class="form-check-input" id="syarat" required>
      <label class="form-check-label" for="syarat">Saya setuju dengan syarat & ketentuan</label>
      <div class="valid-feedback">Terima kasih!</div>
      <div class="invalid-feedback">Anda harus menyetujui syarat & ketentuan.</div>
    </div>
  </div>

  <!-- Feedback menggunakan tooltip -->
  <div class="mb-3 position-relative">
    <label for="kodePos" class="form-label">Kode Pos</label>
    <input type="text" class="form-control" id="kodePos" required pattern="[0-9]{5}">
    <div class="valid-tooltip">Kode pos valid.</div>
    <div class="invalid-tooltip">Kode pos harus 5 digit angka.</div>
  </div>

  <button type="submit" class="btn btn-primary">Submit</button>
</form>
```

## Poin Penting
- `.valid-feedback`/`.invalid-feedback` adalah elemen sibling setelah input
- Multiple error messages bisa ditampung dalam satu `.invalid-feedback`
- Gunakan `.valid-tooltip`/`.invalid-tooltip` untuk tampilan tooltip (butuh `.position-relative`)
- Feedback hanya muncul saat input memiliki `.is-valid`/`.is-invalid` atau form memiliki `.was-validated`
