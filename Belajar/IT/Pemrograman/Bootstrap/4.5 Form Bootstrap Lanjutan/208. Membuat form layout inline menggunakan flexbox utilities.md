# Membuat form layout inline menggunakan flexbox utilities

## Analogi: Perpustakaan Digital

Seperti formulir cepat di meja sirkulasi — "Nama: [______] ID: [______] Cari" — di mana semua elemen berada dalam satu baris horizontal. Form inline Bootstrap menggunakan flexbox utilities untuk menampilkan beberapa form control dalam satu baris, ideal untuk search bar, filter cepat, atau form login sederhana.

## Penjelasan Detail

Bootstrap 5 tidak lagi memiliki class `.form-inline` (yang ada di Bootstrap 4). Sebagai gantinya, gunakan flexbox utilities untuk membuat form inline. Kombinasikan `d-flex`, `flex-row`, `align-items-center`, dan `gap-*` untuk mengatur tata letak. Setiap grup input dapat dibungkus dengan `div` dan diberi margin (`me-*`, `mb-*`) atau gap. Untuk form inline yang responsif, gunakan `flex-wrap` agar elemen turun ke baris baru saat layar sempit. Anda bisa mengkombinasikan input, select, tombol, dan label dalam satu baris. Form inline sangat efektif untuk filter bar, search form, toolbar aksi, dan form login cepat.

## Contoh Kode Implementasi

```html
<!-- Filter pencarian inline -->
<div class="d-flex flex-wrap gap-2 align-items-center p-3 bg-light rounded mb-4">
  <label for="searchInline" class="fw-bold me-2">Cari:</label>
  <input type="text" class="form-control" id="searchInline" 
         placeholder="Judul buku..." style="width: 200px;">
  
  <select class="form-select" style="width: 150px;">
    <option>Semua Kategori</option>
    <option>Fiksi</option>
    <option>Non-Fiksi</option>
  </select>

  <select class="form-select" style="width: 130px;">
    <option>Terbaru</option>
    <option>Populer</option>
    <option>Rating</option>
  </select>

  <button class="btn btn-primary">Cari</button>
  <button class="btn btn-outline-secondary">Reset</button>
</div>

<!-- Login form inline -->
<form class="d-flex flex-wrap gap-2 align-items-center">
  <label for="emailLogin" class="visually-hidden">Email</label>
  <input type="email" class="form-control" id="emailLogin" 
         placeholder="Email" style="width: 200px;">

  <label for="passwordLogin" class="visually-hidden">Password</label>
  <input type="password" class="form-control" id="passwordLogin" 
         placeholder="Password" style="width: 200px;">

  <div class="form-check me-2">
    <input type="checkbox" class="form-check-input" id="remember">
    <label class="form-check-label" for="remember">Ingat saya</label>
  </div>

  <button type="submit" class="btn btn-primary">Masuk</button>
</form>

<!-- Toolbar aksi inline -->
<div class="d-flex gap-1 align-items-center mb-3">
  <span class="fw-bold me-2">Aksi:</span>
  <button class="btn btn-sm btn-success">Tambah</button>
  <button class="btn btn-sm btn-warning">Edit</button>
  <button class="btn btn-sm btn-danger">Hapus</button>
  <span class="border-start mx-2" style="height: 24px;"></span>
  <select class="form-select form-select-sm" style="width: 130px;">
    <option>10 per halaman</option>
    <option>25 per halaman</option>
    <option>50 per halaman</option>
  </select>
</div>
```

## Poin Penting
- Bootstrap 5 tidak memiliki class `.form-inline` — gunakan `d-flex flex-wrap gap-*`
- `flex-wrap` memastikan elemen turun ke baris baru saat layar sempit (responsif)
- Gunakan `align-items-center` untuk alignment vertikal yang rapi
- `visually-hidden` pada label untuk aksesibilitas tanpa menampilkan label
