# Membuat form validation menggunakan class was-validated

## Analogi: Perpustakaan Digital

Seperti petugas perpustakaan yang memeriksa kelengkapan data pendaftaran anggota — "Nama harus diisi", "Email tidak valid", "Nomor telepon kurang" — form validation Bootstrap memberikan umpan balik visual instan kepada pengguna tentang input yang valid atau tidak valid setelah form dikirim.

## Penjelasan Detail

Bootstrap menyediakan sistem validasi form yang bekerja dengan HTML5 form validation API. Class `.was-validated` ditambahkan ke elemen `<form>` setelah form dikirim (submit), memicu tampilan state valid/invalid pada semua input. Setiap input menggunakan class `.is-valid` atau `.is-invalid` untuk menandai status secara visual. Elemen feedback seperti `.valid-feedback` (pesan sukses) dan `.invalid-feedback` (pesan error) ditampilkan sesuai state. Bootstrap juga mendukung validation tooltips untuk tampilan yang lebih modern. Untuk validasi kustom (di luar HTML5), Anda bisa memanipulasi class `.is-valid`/`.is-invalid` dan `.was-validated` secara manual.

## Contoh Kode Implementasi

```html
<form class="row g-3 needs-validation" novalidate id="registrationForm">
  <div class="col-md-6">
    <label for="nama" class="form-label">Nama Lengkap</label>
    <input type="text" class="form-control" id="nama" required minlength="3">
    <div class="valid-feedback">Nama valid!</div>
    <div class="invalid-feedback">Nama harus diisi minimal 3 karakter.</div>
  </div>

  <div class="col-md-6">
    <label for="email" class="form-label">Email</label>
    <input type="email" class="form-control" id="email" required>
    <div class="valid-feedback">Email valid!</div>
    <div class="invalid-feedback">Masukkan alamat email yang valid.</div>
  </div>

  <div class="col-12">
    <button class="btn btn-primary" type="submit">Daftar</button>
  </div>
</form>

<script>
  (function() {
    const form = document.getElementById('registrationForm');
    form.addEventListener('submit', function(event) {
      if (!form.checkValidity()) {
        event.preventDefault();
        event.stopPropagation();
      }
      form.classList.add('was-validated');
    }, false);
  })();
</script>
```

## Poin Penting
- Tambahkan `.was-validated` ke form setelah submit untuk menampilkan status validasi
- Gunakan `.valid-feedback` untuk pesan sukses dan `.invalid-feedback` untuk pesan error
- Setiap input membutuhkan atribut `required` atau pattern HTML5 untuk validasi
- Tambahkan `novalidate` pada form untuk menonaktifkan browser default validation popup
