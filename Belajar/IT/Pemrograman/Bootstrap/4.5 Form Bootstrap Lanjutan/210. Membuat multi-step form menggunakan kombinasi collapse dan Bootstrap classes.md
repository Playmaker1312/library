# Membuat multi-step form menggunakan kombinasi collapse dan Bootstrap classes

## Analogi: Perpustakaan Digital

Seperti proses pendaftaran anggota perpustakaan yang terdiri dari beberapa langkah: (1) isi data diri, (2) pilih jenis keanggotaan, (3) upload dokumen, (4) konfirmasi. Setiap langkah muncul bergantian — seperti membuka bab buku satu per satu — mengurangi kewalahan pengguna dengan memecah form panjang menjadi langkah-langkah kecil yang mudah diikuti.

## Penjelasan Detail

Multi-step form memecah form panjang menjadi beberapa langkah (step) yang ditampilkan satu per satu. Implementasi dengan Bootstrap menggunakan komponen Collapse untuk menampilkan/menyembunyikan setiap langkah, dikombinasikan dengan progress bar, tombol navigasi (Prev/Next), dan validasi per langkah. Setiap langkah adalah div dengan class `.collapse` yang dikontrol via JavaScript atau data attributes. Progress bar diperbarui setiap kali langkah berubah. Validasi dilakukan per langkah sebelum pindah ke langkah berikutnya. Gunakan class `.step-indicator` (atau CSS kustom) untuk menampilkan nomor langkah. Kombinasikan dengan grid, buttons, alerts, dan komponen Bootstrap lainnya untuk pengalaman yang lengkap.

## Contoh Kode Implementasi

```html
<div class="container mt-4">
  <h3>Pendaftaran Anggota Perpustakaan</h3>

  <!-- Progress bar -->
  <div class="progress mb-4" style="height: 8px;">
    <div id="progressBar" class="progress-bar" role="progressbar" 
         style="width: 25%" aria-valuenow="25" aria-valuemin="0" aria-valuemax="100"></div>
  </div>

  <!-- Step indicators -->
  <div class="d-flex justify-content-between mb-4">
    <span class="badge bg-primary" id="step1Badge">1. Data Diri</span>
    <span class="badge bg-secondary" id="step2Badge">2. Keanggotaan</span>
    <span class="badge bg-secondary" id="step3Badge">3. Dokumen</span>
    <span class="badge bg-secondary" id="step4Badge">4. Konfirmasi</span>
  </div>

  <!-- Step 1 -->
  <div class="collapse show" id="step1">
    <h5>Data Diri</h5>
    <div class="mb-3">
      <label class="form-label">Nama Lengkap</label>
      <input type="text" class="form-control" id="namaStep" required>
    </div>
    <div class="mb-3">
      <label class="form-label">Email</label>
      <input type="email" class="form-control" id="emailStep" required>
    </div>
    <button class="btn btn-primary" onclick="nextStep(1)">Lanjut</button>
  </div>

  <!-- Step 2 -->
  <div class="collapse" id="step2">
    <h5>Jenis Keanggotaan</h5>
    <div class="mb-3">
      <select class="form-select" id="jenisAnggota">
        <option>Pelajar</option>
        <option>Mahasiswa</option>
        <option>Umum</option>
      </select>
    </div>
    <button class="btn btn-secondary" onclick="prevStep(2)">Kembali</button>
    <button class="btn btn-primary" onclick="nextStep(2)">Lanjut</button>
  </div>

  <!-- Step 3 -->
  <div class="collapse" id="step3">
    <h5>Upload Dokumen</h5>
    <div class="mb-3">
      <input type="file" class="form-control">
    </div>
    <button class="btn btn-secondary" onclick="prevStep(3)">Kembali</button>
    <button class="btn btn-primary" onclick="nextStep(3)">Lanjut</button>
  </div>

  <!-- Step 4 -->
  <div class="collapse" id="step4">
    <h5>Konfirmasi</h5>
    <div class="alert alert-success">
      Data Anda akan diproses setelah verifikasi.
    </div>
    <button class="btn btn-secondary" onclick="prevStep(4)">Kembali</button>
    <button class="btn btn-success" onclick="submitForm()">Daftar</button>
  </div>
</div>

<script>
  let currentStep = 1;
  const totalSteps = 4;

  function updateProgress() {
    const percent = (currentStep / totalSteps) * 100;
    document.getElementById('progressBar').style.width = percent + '%';
    document.getElementById('progressBar').setAttribute('aria-valuenow', percent);
  }

  function updateBadges() {
    for (let i = 1; i <= totalSteps; i++) {
      const badge = document.getElementById('step' + i + 'Badge');
      badge.className = 'badge bg-' + (i <= currentStep ? 'primary' : 'secondary');
    }
  }

  function showStep(step) {
    for (let i = 1; i <= totalSteps; i++) {
      const el = document.getElementById('step' + i);
      if (i === step) {
        el.classList.add('show');
      } else {
        el.classList.remove('show');
      }
    }
  }

  function nextStep(step) {
    if (step < totalSteps) {
      currentStep = step + 1;
      showStep(currentStep);
      updateProgress();
      updateBadges();
    }
  }

  function prevStep(step) {
    if (step > 1) {
      currentStep = step - 1;
      showStep(currentStep);
      updateProgress();
      updateBadges();
    }
  }

  function submitForm() {
    alert('Pendaftaran berhasil! Silakan cek email untuk verifikasi.');
  }
</script>
```

## Poin Penting
- Gunakan Collapse Bootstrap untuk menampilkan/menyembunyikan setiap langkah
- Progress bar memberikan indikasi visual kemajuan pengguna
- Validasi per langkah memastikan data lengkap sebelum melanjutkan
- Tombol navigasi (Prev/Next) dan badge langkah meningkatkan usability
