# Membuat input group menggunakan class input-group untuk menggabungkan input dengan teks atau tombol

## Analogi: Perpustakaan Digital

Seperti kotak sirkulasi yang memiliki slot untuk kartu anggota, barcode scanner, dan layar monitor — beberapa elemen digabung menjadi satu unit fungsional. Input Group Bootstrap menggabungkan input field dengan teks tambahan, tombol, atau elemen lain dalam satu baris untuk membuat kontrol input yang lebih kompleks.

## Penjelasan Detail

Input Group menggunakan class `.input-group` sebagai container yang membungkus input dan elemen tambahan. Elemen tambahan menggunakan class `.input-group-text` (untuk teks atau ikon) atau class `btn` (untuk tombol). Input group mendukung prepend (elemen sebelum input) dan append (elemen setelah input). Anda bisa menggabungkan multiple elemen di kedua sisi. Input group juga bekerja dengan select dan textarea. Ukuran input group dapat diatur dengan class `.input-group-sm` atau `.input-group-lg`. Input group sangat berguna untuk: field dengan prefix (Rp, $, http://), field dengan suffix (kg, %, .com), search box dengan tombol, dan field dengan tombol aksi (tambah, cari, hapus).

## Contoh Kode Implementasi

```html
<div class="container mt-4">
  <!-- Input group dengan teks prepend -->
  <div class="input-group mb-3">
    <span class="input-group-text">Rp</span>
    <input type="number" class="form-control" placeholder="Jumlah">
    <span class="input-group-text">,00</span>
  </div>

  <!-- Input group dengan tombol -->
  <div class="input-group mb-3">
    <input type="text" class="form-control" placeholder="Cari buku...">
    <button class="btn btn-primary" type="button">Cari</button>
    <button class="btn btn-outline-secondary" type="button">Reset</button>
  </div>

  <!-- Input group dengan dropdown -->
  <div class="input-group mb-3">
    <button class="btn btn-outline-secondary dropdown-toggle" 
            data-bs-toggle="dropdown">Kategori</button>
    <ul class="dropdown-menu">
      <li><a class="dropdown-item" href="#">Semua</a></li>
      <li><a class="dropdown-item" href="#">Fiksi</a></li>
      <li><a class="dropdown-item" href="#">Non-Fiksi</a></li>
    </ul>
    <input type="text" class="form-control" placeholder="Judul buku...">
  </div>

  <!-- Input group dengan checkbox -->
  <div class="input-group mb-3">
    <div class="input-group-text">
      <input type="checkbox" class="form-check-input mt-0">
    </div>
    <input type="text" class="form-control" placeholder="Tandai sebagai preferensi">
  </div>

  <!-- Input group sizing -->
  <div class="input-group input-group-sm mb-3">
    <span class="input-group-text">Kecil</span>
    <input type="text" class="form-control">
  </div>

  <!-- Input group dengan multiple elemen -->
  <div class="input-group mb-3">
    <span class="input-group-text">http://</span>
    <input type="text" class="form-control" placeholder="nama-domain">
    <span class="input-group-text">.com</span>
  </div>
</div>
```

## Poin Penting
- Container `.input-group` membungkus input dan elemen tambahan
- `.input-group-text` untuk teks/ikon, class `btn` untuk tombol
- Mendukung prepend (kiri) dan append (kanan) secara simultan
- Class sizing: `.input-group-sm` dan `.input-group-lg`
