# Menggunakan class is-valid dan is-invalid pada input

## Analogi: Perpustakaan Digital

Seperti stempel hijau "VALID" atau stempel merah "INVALID" pada formulir pendaftaran anggota perpustakaan — class `.is-valid` dan `.is-invalid` memberikan indikasi visual langsung pada setiap input apakah data yang dimasukkan benar atau salah, bahkan sebelum form dikirim.

## Penjelasan Detail

Class `.is-valid` dan `.is-invalid` adalah class state yang dapat ditambahkan ke elemen form (input, select, textarea) untuk menampilkan status validasi secara visual. Class ini memberikan border hijau/merah dan ikon status (centang/silang) jika didukung. Berbeda dengan `.was-validated` yang bekerja pada form level, class ini bekerja pada elemen individual dan dapat diatur kapan saja via JavaScript. Ini berguna untuk validasi real-time (saat mengetik) atau validasi sisi server. Kombinasikan dengan `.valid-feedback` dan `.invalid-feedback` untuk menampilkan pesan. Bootstrap CSS menggunakan pseudo-class `:valid` dan `:invalid` CSS, namun class `.is-valid` dan `.is-invalid` meng-override pseudo-class tersebut untuk kontrol yang lebih eksplisit.

## Contoh Kode Implementasi

```html
<form>
  <!-- Input dengan validasi real-time -->
  <div class="mb-3">
    <label for="username" class="form-label">Username</label>
    <input type="text" class="form-control" id="username" 
           placeholder="Minimal 3 karakter" required>
    <div class="valid-feedback">Username tersedia!</div>
    <div class="invalid-feedback">Username sudah digunakan atau terlalu pendek.</div>
  </div>

  <!-- Select dengan state -->
  <div class="mb-3">
    <label for="kategori" class="form-label">Kategori</label>
    <select class="form-select is-invalid" id="kategori">
      <option value="">Pilih kategori</option>
      <option value="1">Fiksi</option>
      <option value="2">Non-Fiksi</option>
    </select>
    <div class="invalid-feedback">Silakan pilih kategori.</div>
  </div>

  <!-- Textarea dengan state -->
  <div class="mb-3">
    <label for="alamat" class="form-label">Alamat</label>
    <textarea class="form-control is-valid" id="alamat">Jl. Merdeka No. 10</textarea>
    <div class="valid-feedback">Alamat lengkap.</div>
  </div>
</form>

<script>
  const usernameInput = document.getElementById('username');
  
  // Validasi real-time saat mengetik
  usernameInput.addEventListener('input', function() {
    if (this.value.length >= 3) {
      this.classList.remove('is-invalid');
      this.classList.add('is-valid');
    } else {
      this.classList.remove('is-valid');
      this.classList.add('is-invalid');
    }
  });
</script>
```

## Poin Penting
- `.is-valid` menampilkan border hijau + ikon centang
- `.is-invalid` menampilkan border merah + ikon silang
- Class ini dapat ditambahkan/dihapus secara dinamis via JavaScript
- Gunakan untuk validasi real-time atau validasi sisi server
