# Membuat file upload input menggunakan class form-control type file

## Analogi: Perpustakaan Digital

Seperti kotak drop-off buku di perpustakaan — pengguna bisa "meletakkan" file (buku digital) ke dalam kotak (input) yang kemudian akan diproses oleh sistem. File upload input Bootstrap memungkinkan pengguna memilih file dari perangkat mereka dengan antarmuka yang konsisten dan elegan.

## Penjelasan Detail

Bootstrap menyediakan styling untuk input file dengan class `.form-control` pada `<input type="file">`. Input file secara default menampilkan tombol "Choose File" (atau "Browse") dan label nama file yang dipilih. Bootstrap meningkatkan tampilan ini dengan border, padding, dan warna yang konsisten. Untuk multiple file, tambahkan atribut `multiple`. Input file mendukung berbagai format: image, PDF, dokumen, dll. Atribut `accept` membatasi jenis file yang dapat dipilih (`accept="image/*"`, `accept=".pdf,.doc"`). Anda bisa mengkustomisasi tampilan dengan menyembunyikan input asli dan menggunakan label sebagai trigger. File yang dipilih dapat diakses via JavaScript `File` API.

## Contoh Kode Implementasi

```html
<div class="container mt-4">
  <h3>Upload Dokumen Perpustakaan</h3>

  <!-- File upload dasar -->
  <div class="mb-3">
    <label for="fileBuku" class="form-label">Upload File Buku (PDF)</label>
    <input type="file" class="form-control" id="fileBuku" accept=".pdf">
  </div>

  <!-- File upload dengan multiple files -->
  <div class="mb-3">
    <label for="fileGambar" class="form-label">Upload Sampul Buku (multiple)</label>
    <input type="file" class="form-control" id="fileGambar" 
           accept="image/*" multiple>
    <div class="form-text">Format: JPG, PNG. Maks 2MB per file.</div>
  </div>

  <!-- File upload dengan input group -->
  <div class="mb-3">
    <label class="form-label">Upload Dokumen Pendukung</label>
    <div class="input-group">
      <input type="file" class="form-control" id="fileDokumen" multiple>
      <button class="btn btn-outline-primary" type="button" id="uploadBtn">
        Upload
      </button>
    </div>
  </div>

  <!-- File upload dengan preview (JavaScript) -->
  <div class="mb-3">
    <label for="filePreview" class="form-label">Upload dengan Preview</label>
    <input type="file" class="form-control" id="filePreview" accept="image/*">
    <div id="previewContainer" class="mt-2">
      <img id="previewImage" src="" class="img-fluid d-none" 
           style="max-height: 200px;">
    </div>
  </div>
</div>

<script>
  // Preview gambar sebelum upload
  document.getElementById('filePreview').addEventListener('change', function(e) {
    const file = e.target.files[0];
    if (file) {
      const reader = new FileReader();
      reader.onload = function(e) {
        const img = document.getElementById('previewImage');
        img.src = e.target.result;
        img.classList.remove('d-none');
      };
      reader.readAsDataURL(file);
    }
  });

  // Tampilkan nama file yang dipilih
  document.getElementById('fileBuku').addEventListener('change', function(e) {
    const fileName = e.target.files[0]?.name || 'Tidak ada file dipilih';
    console.log('File dipilih:', fileName);
  });
</script>
```

## Poin Penting
- Gunakan `<input type="file" class="form-control">` untuk file upload Bootstrap
- Atribut `multiple` mengizinkan upload beberapa file sekaligus
- Atribut `accept` membatasi jenis file (contoh: `accept="image/*"`)
- Akses file yang dipilih via JavaScript `File` API untuk preview atau upload
