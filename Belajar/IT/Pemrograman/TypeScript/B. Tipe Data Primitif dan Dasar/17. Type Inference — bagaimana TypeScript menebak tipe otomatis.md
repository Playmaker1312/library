### 17. Type Inference — Bagaimana TypeScript Menebak Tipe Otomatis

Meskipun TypeScript adalah bahasa yang mementingkan tipe data, Anda tidak harus menuliskan tipe data di setiap baris kode. TypeScript cukup cerdas untuk "menebak" tipe tersebut sendiri.

---

### Definisi Singkat

**Type Inference** adalah kemampuan TypeScript untuk secara otomatis menentukan tipe data dari sebuah variabel berdasarkan nilai yang diberikan saat variabel tersebut pertama kali dideklarasikan. Jika Anda memberikan nilai awal, TypeScript akan mengunci variabel tersebut ke tipe tersebut tanpa perlu anotasi manual (`:`).

---

### Analogi

Bayangkan Anda sedang bekerja di sebuah **Pabrik Minuman**.

- **Type Annotation** adalah ketika Anda secara manual menempelkan label "Jus Apel" pada setiap botol kosong sebelum diisi.
    
- **Type Inference** adalah ketika Anda membiarkan botol lewat tanpa label, tetapi ada **Sensor Otomatis** di jalur produksi. Saat sensor melihat cairan berwarna merah keruh masuk ke botol, ia langsung menandai botol tersebut sebagai "Jus Apel" di sistem komputer. Anda tidak perlu memberi tahu sensornya; sensor itu tahu dari isinya.
    

---

### Poin-Poin Penting

- **Inisialisasi Nilai:** Inferensi terjadi saat variabel dideklarasikan sekaligus diberi nilai (_initialized_). Jika Anda hanya deklarasi tanpa nilai (`let x;`), tipenya akan menjadi `any`.
    
- **Best Common Type:** Saat Anda membuat array dengan berbagai macam isi, TypeScript akan mencoba mencari "tipe umum terbaik" yang mencakup semua anggota array tersebut.
    
- **Return Type Inference:** TypeScript juga bisa menebak tipe hasil kembalian sebuah fungsi berdasarkan logika `return` di dalamnya.
    
- **Kapan Harus Manual?** Anotasi manual tetap diperlukan jika variabel dideklarasikan kosong atau jika Anda ingin tipe yang sangat spesifik (misal: _Union Types_).
    

---

### Contoh Implementasi

**1. Inferensi Dasar:**

TypeScript

```
let nama = "Budi"; // TypeScript otomatis tahu ini 'string'
let angka = 42;    // TypeScript otomatis tahu ini 'number'

// @ts-expect-error
nama = 100; // Error: Type 'number' is not assignable to type 'string'.
```

**2. Inferensi pada Fungsi:**

TypeScript

```
function tambah(a: number, b: number) {
    return a + b; // TypeScript tahu fungsi ini mengembalikan 'number'
}

const hasil = tambah(5, 10); // 'hasil' otomatis bertipe 'number'
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan **Web Development**, _Type Inference_ sangat membantu untuk:

1. **Kode yang Bersih (Clean Code):** Anda tidak perlu memenuhi kode dengan `: string` atau `: number` di setiap tempat. Kode jadi lebih ringkas dan mirip JavaScript biasa namun tetap aman.
    
2. **State Management (React):** Saat menggunakan `useState(true)`, TypeScript otomatis tahu bahwa _state_ tersebut adalah `boolean`. Anda tidak perlu menulis `useState<boolean>(true)` kecuali jika _state_ tersebut bisa bernilai `null` nantinya.
    
3. **Library Integration:** Saat menggunakan library pihak ketiga, TypeScript sering kali bisa menebak tipe data dari objek yang dikembalikan oleh library tersebut, sehingga Anda mendapatkan fitur _autocomplete_ secara instan tanpa konfigurasi tambahan.
