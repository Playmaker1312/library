### 18. Literal Types (String, Number, dan Boolean Literal)

Jika tipe data biasa seperti `string` atau `number` adalah sebuah "kategori besar", maka **Literal Types** adalah "nilai spesifik" yang dijadikan sebagai tipe data itu sendiri.

---

### Definisi Singkat

**Literal Types** adalah fitur di mana Anda menggunakan nilai pasti (seperti `"sukses"`, `200`, atau `true`) sebagai tipe data dari sebuah variabel. Ini membatasi variabel tersebut agar hanya bisa menerima nilai yang persis sama dengan yang ditentukan, bukan sekadar tipe datanya saja.

---

### Analogi

Bayangkan Anda sedang memesan **Seragam Kantor**.

- **Tipe Biasa (`string`):** Aturannya adalah "Anda harus memakai baju berbahan kain". Anda boleh datang pakai kaos oblong, kemeja, atau daster (asal semuanya kain).
    
- **Literal Type (`"Kemeja Putih"`):** Aturannya adalah "Anda harus memakai Kemeja Putih". Jika Anda datang memakai kemeja biru (meskipun sama-sama kain), Anda akan dilarang masuk. Nilainya harus **persis** sesuai aturan.
    

---

### Poin-Poin Penting

- **Ketepatan Tinggi:** Memberikan keamanan ekstra karena mencegah nilai yang "masuk akal tapi salah" (misal: status `"loading"` tertulis `"loadin"`).
    
- **Kombinasi dengan Union:** Literal types hampir selalu digunakan bersama Union (`|`) untuk menciptakan daftar pilihan yang terbatas.
    
- **String Literal:** Paling sering digunakan untuk status, arah, atau konfigurasi.
    
- **Number Literal:** Sering digunakan untuk kode status HTTP atau ukuran tertentu.
    
- **Boolean Literal:** Jarang digunakan sendirian, biasanya untuk memastikan nilai harus `true` atau harus `false` dalam kondisi tertentu.
    

---

### Contoh Implementasi

**1. String Literal dengan Union (Kasus Paling Umum):**

TypeScript

```
type StatusPesanan = "dikemas" | "dikirim" | "diterima";

let statusSaatIni: StatusPesanan = "dikemas";

// @ts-expect-error: Typo atau nilai di luar daftar akan error
statusSaatIni = "dibatalkan"; 
// Error: Type '"dibatalkan"' is not assignable to type 'StatusPesanan'.
```

**2. Number Literal:**

TypeScript

```
type SkalaNilai = 1 | 2 | 3 | 4 | 5;

function beriRating(skor: SkalaNilai) {
    console.log(`Anda memberi rating: ${skor}`);
}

beriRating(5); // Oke
// beriRating(10); // Error!
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan **Web Development**, Literal Types sangat membantu untuk:

1. **UI Component Props:** Jika Anda membuat komponen `Button` di React, Anda bisa membatasi warnanya hanya `"primary" | "secondary" | "danger"`. Ini mencegah developer lain memasukkan warna yang tidak ada di desain sistem.
    
2. **API Response Handling:** Memastikan aplikasi hanya memproses status tertentu dari server (misal: `200 | 404 | 500`).
    
3. **Navigation/Routing:** Membatasi navigasi hanya ke halaman yang valid, misalnya `type Tab = "Beranda" | "Profil" | "Pengaturan"`.
