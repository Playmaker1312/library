### 5. Instalasi TypeScript (npm global vs lokal, npx)

Setelah memahami cara kerjanya, langkah selanjutnya adalah menyiapkan "pabrik" atau lingkungan kerja TypeScript di komputer Anda.

---

### Definisi Singkat

**Instalasi TypeScript** adalah proses mengunduh perangkat lunak TypeScript melalui **npm** (Node Package Manager) agar perintah `tsc` (TypeScript Compiler) tersedia di terminal Anda, baik untuk seluruh sistem (**global**) maupun hanya untuk proyek tertentu (**lokal**).

---

### Analogi

Bayangkan Anda adalah seorang koki yang butuh pisau khusus (TypeScript) untuk memotong bahan makanan.

- **Global:** Anda membeli pisau tersebut dan menaruhnya di pinggang Anda. Ke mana pun Anda pergi (proyek mana pun), pisaunya selalu ada. Namun, jika ada jenis pisau baru, Anda harus repot menggantinya sendiri.
    
- **Lokal:** Anda menaruh pisau tersebut di dalam kotak peralatan khusus untuk resep tertentu. Dapur lain tidak bisa memakai pisau itu. Ini bagus karena setiap resep bisa punya jenis pisau yang berbeda versinya tanpa tertukar.
    
- **npx:** Anda tidak membeli pisau. Anda hanya meminjamnya sebentar dari toko saat butuh, menggunakannya, lalu mengembalikannya.
    

---

### Poin-Poin Penting

- **npm install -g typescript (Global):**
    
    - Memasang TypeScript di tingkat sistem operasi.
        
    - Bisa dipanggil di folder mana saja.
        
    - _Kekurangan:_ Sulit mengelola versi yang berbeda untuk proyek yang berbeda.
        
- **npm install --save-dev typescript (Lokal):**
    
    - TypeScript hanya terpasang di dalam folder proyek tersebut (masuk ke `node_modules`).
        
    - Sangat disarankan untuk kerja tim agar semua orang menggunakan versi TypeScript yang sama.
        
    - Versi tercatat di file `package.json`.
        
- **npx tsc (Eksekusi Tanpa Instalasi Tetap):**
    
    - `npx` memungkinkan kita menjalankan perintah TypeScript tanpa harus memasangnya secara global. Ia akan mencari di `node_modules` lokal, jika tidak ada, ia akan mengunduhnya sementara.
        

---

### Contoh Implementasi

**1. Cara Instalasi (Terminal):**

Bash

```
# Instalasi Global
npm install -g typescript

# Instalasi Lokal (Di dalam folder proyek)
npm init -y
npm install --save-dev typescript
```

**2. Cara Menjalankan Compiler:**

Bash

```
# Jika global
tsc app.ts

# Jika lokal (menggunakan npx)
npx tsc app.ts

# Mengecek versi
npx tsc -v
```

---

### Koneksi dalam Bidang Web Development

Dalam alur kerja **Web Development** profesional:

1. **Project Portability:** Pengembang hampir selalu menggunakan **instalasi lokal**. Saat Anda mengunggah kode ke GitHub dan rekan tim melakukan `npm install`, mereka otomatis mendapatkan versi TypeScript yang sama persis dengan yang Anda gunakan.
    
2. **CI/CD Pipeline:** Saat aplikasi web Anda dideploy secara otomatis (misal ke Netlify atau Vercel), server tersebut akan menjalankan perintah melalui `npx` atau skrip npm lokal untuk mengubah file `.ts` menjadi `.js` sebelum ditampilkan ke publik.
    
3. **Modern Tools:** Tools seperti **Vite** atau **Create React App** biasanya sudah menangani instalasi ini secara lokal di balik layar, sehingga Anda tinggal fokus menulis kode.
