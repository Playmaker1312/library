### 8. TypeScript Playground — Eksperimen Online

Sebelum Anda repot-repot menginstal segala sesuatu di komputer lokal, TypeScript menyediakan "laboratorium" resmi berbasis web yang sangat canggih.

---

### Definisi Singkat

**TypeScript Playground** adalah editor kode berbasis browser resmi yang memungkinkan Anda menulis, berbagi, dan mempelajari TypeScript secara instan tanpa instalasi. Alat ini secara otomatis mengompilasi kode Anda ke JavaScript di sisi kanan layar secara _real-time_.

---

### Analogi

Bayangkan Anda ingin belajar mengemudi mobil manual.

- **Instalasi Lokal** adalah seperti membeli mobil, mengurus surat-suratnya, dan menyiapkan garasi di rumah Anda (memakan waktu).
    
- **TypeScript Playground** adalah seperti **Simulator Mengemudi** di pusat perbelanjaan. Anda cukup duduk, mulai menyetir, dan melihat hasilnya di layar. Jika Anda membuat kesalahan atau "menabrak", Anda tinggal menekan tombol _reset_ tanpa merusak apa pun di komputer Anda.
    

---

### Poin-Poin Penting

Fitur-fitur utama yang membuat Playground sangat berguna:

- **Side-by-Side View:** Anda bisa melihat kode TypeScript di kiri dan hasil JavaScript-nya di kanan secara langsung.
    
- **Version Switcher:** Anda bisa mencoba kode di berbagai versi TypeScript (dari versi lama hingga versi beta terbaru).
    
- **Config Manager:** Anda bisa mengubah pengaturan `tsconfig.json` (seperti `strict` mode atau `target`) melalui menu dropdown sederhana untuk melihat pengaruhnya pada kode.
    
- **Plugins:** Tersedia plugin untuk melihat _Abstract Syntax Tree_ (AST) atau memeriksa bagaimana tipe data bekerja secara mendalam.
    
- **Shareable Links:** Anda bisa menyalin URL yang berisi seluruh kode Anda untuk dikirimkan ke teman atau rekan kerja guna berdiskusi tentang _bug_.
    

---

### Contoh Implementasi

Anda bisa mencoba bereksperimen dengan fitur **Type Inference** di Playground:

1. Buka [typescriptlang.org/play](https://www.typescriptlang.org/play).
    
2. Ketik kode berikut:
    
    TypeScript
    
    ```
    let data = "Halo";
    // Coba ganti data menjadi angka
    data = 123; 
    ```
    
3. Lihat di panel kanan (JavaScript), kode tersebut tampak normal. Namun, di panel kiri (TypeScript), Anda akan melihat **garis merah** karena TypeScript tahu `data` seharusnya adalah sebuah `string`.
    
4. Klik menu **Config**, matikan opsi `strict`, dan lihat apakah perilakunya berubah.
    

---

### Koneksi dalam Bidang Web Development

Dalam keseharian **Web Development**, Playground digunakan untuk:

1. **Bug Reporting:** Saat Anda menemukan perilaku aneh pada library (seperti React atau Next.js), Anda biasanya diminta memberikan contoh kode di Playground agar orang lain bisa mereproduksinya dengan mudah.
    
2. **Mempelajari Fitur Baru:** Ketika TypeScript merilis versi baru (misalnya versi 5.x), Anda bisa langsung mencobanya di Playground tanpa harus memperbarui versi TypeScript di proyek utama Anda.
    
3. **Prototyping Logika Rumit:** Jika Anda kesulitan membuat _interface_ atau _type_ yang kompleks untuk data API, lebih mudah untuk "mengopreknya" di Playground terlebih dahulu sebelum memindahkannya ke dalam kode aplikasi nyata.
