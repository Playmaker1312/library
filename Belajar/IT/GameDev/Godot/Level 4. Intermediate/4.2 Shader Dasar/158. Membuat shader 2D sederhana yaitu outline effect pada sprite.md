# 158. Membuat shader 2D sederhana yaitu outline effect pada sprite

## Definisi Singkat
Outline effect adalah teknik shader yang menambahkan garis tepi berwarna di sekeliling sprite untuk membuat objek lebih menonjol dari latar belakang. Teknik ini bekerja dengan memeriksa pixel tetangga dan menggambar garis jika ditemukan tepi objek.

## Analogi
Bayangkan menggambar sticker. Outline seperti memberikan border atau garis tepi berwarna di sekitar gambar agar sticker terlihat lebih jelas dan menarik saat ditempel di tempat yang warnanya mirip.

## Struktur Node (Scene Tree)
```
Sprite2D
├── Texture (gambar sprite)
└── ShaderMaterial
    └── Shader (outline effect)
```

## Kode GDScript (Godot 4)
```gdscript
extends Sprite2D

func _ready():
    var shader_code = """
    shader_type canvas_item;

    uniform float outline_width = 2.0;
    uniform vec4 outline_color : source_color = vec4(0.0, 0.0, 0.0, 1.0);

    void fragment() {
        vec4 tex = texture(TEXTURE, UV);
        float outline = 0.0;

        for (int x = -1; x <= 1; x++) {
            for (int y = -1; y <= 1; y++) {
                vec2 offset = vec2(float(x), float(y)) * outline_width * TEXTURE_PIXEL_SIZE;
                float neighbor = texture(TEXTURE, UV + offset).a;
                if (neighbor > 0.5 && tex.a < 0.5) {
                    outline = 1.0;
                }
            }
        }

        if (outline > 0.5) {
            COLOR = outline_color;
        } else {
            COLOR = tex;
        }
    }
    """
    var shader = Shader.new()
    shader.code = shader_code
    var material = ShaderMaterial.new()
    material.shader = shader
    material.set_shader_parameter("outline_width", 3.0)
    material.set_shader_parameter("outline_color", Color(0.0, 0.0, 0.0, 1.0))
    self.material = material
```

## Kasus Penggunaan Nyata
Outline effect sangat umum digunakan dalam game RPG dan platformer untuk menunjukkan karakter yang sedang dipilih pemain. Efek ini juga digunakan pada item pickup untuk membuatnya lebih terlihat, dan pada enemy untuk menunjukkan status tertentu seperti sedang terkena efek debuff atau siap diserang.
