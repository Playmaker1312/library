# 162. Shader untuk efek air dan liquid sederhana dalam game 2D

## Definisi Singkat
Shader efek air dan liquid bekerja dengan mendistorsi tekstur menggunakan gelombang sine dan noise untuk meniru gerakan permukaan air yang realistis. Efek ini menciptakan ilusi cairan yang mengalir atau bergelombang melalui manipulasi UV coordinate secara dinamis.

## Analogi
Bayangkan memegang sebuah gambar di balik kaca bergerak. Gambar akan terlihat bergetar dan bergeser-geser mengikuti gerakan kaca. Shader air bekerja dengan cara yang sama, mendistorsi gambar latar belakang menggunakan pola gelombang yang terus berubah.

## Struktur Node (Scene Tree)
```
Node2D
├── Sprite2D (latar belakang yang akan didistorsi)
│   └── ShaderMaterial (water effect)
├── ColorRect (overlay air)
│   └── ShaderMaterial (wave pattern)
└── AnimationPlayer (mengontrol parameter shader)
```

## Kode GDScript (Godot 4)
```gdscript
extends Sprite2D

var time : float = 0.0

func _ready():
    var shader_code = """
    shader_type canvas_item;

    uniform sampler2D background_texture;
    uniform float wave_speed = 1.0;
    uniform float wave_amplitude = 5.0;
    uniform float wave_frequency = 10.0;
    uniform float time_offset = 0.0;
    uniform vec4 water_color : source_color = vec4(0.2, 0.5, 0.8, 0.6);

    void fragment() {
        vec2 uv = UV;

        float wave1 = sin(uv.x * wave_frequency + TIME * wave_speed) * wave_amplitude;
        float wave2 = sin(uv.y * wave_frequency * 0.8 + TIME * wave_speed * 1.2) * wave_amplitude * 0.6;
        float wave3 = cos((uv.x + uv.y) * wave_frequency * 0.5 + TIME * wave_speed * 0.7) * wave_amplitude * 0.4;

        vec2 distorted_uv = uv + vec2(wave1, wave2 + wave3) * TEXTURE_PIXEL_SIZE;

        vec4 bg = texture(background_texture, distorted_uv);
        float fresnel = pow(1.0 - abs(dot(vec2(0.0, 1.0), uv - 0.5)), 2.0);
        vec4 final_color = mix(bg, water_color, 0.3 + fresnel * 0.2);

        COLOR = final_color;
    }
    """
    var shader = Shader.new()
    shader.code = shader_code
    var material = ShaderMaterial.new()
    material.shader = shader
    material.set_shader_parameter("wave_speed", 1.5)
    material.set_shader_parameter("wave_amplitude", 3.0)
    material.set_shader_parameter("wave_frequency", 12.0)
    material.set_shader_parameter("water_color", Color(0.2, 0.5, 0.8, 0.5))
    self.material = material

func _process(delta):
    time += delta
```

## Kasus Penggunaan Nyata
Shader air digunakan pada area danau, sungai, dan laut dalam game 2D untuk menciptakan efek permukaan air yang dinamis. Efek liquid juga digunakan pada efek skill seperti water blast atau poison puddle, serta pada UI element seperti loading screen dengan efek cairan yang mengalir untuk memberikan kesan elegan dan modern.
