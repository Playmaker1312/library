# 160. Implementasi shader untuk efek glow dan bloom sederhana

## Definisi Singkat
Glow dan bloom adalah efek visual yang membuat objek tertentu terlihat memancarkan cahaya atau bersinar. Efek ini bekerja dengan memperbesar area terang pada sprite dan menambahkan diffusi cahaya di sekitarnya untuk menciptakan kesan objek yang bercahaya.

## Analogi
Bayangkan lampu neon di malam hari. Cahayanya tidak hanya terlihat pada lampu itu sendiri, tetapi juga menyebar ke area sekitarnya menciptakan lingkaran cahaya yang lembut. Bloom effect meniru fenomena ini pada objek game.

## Struktur Node (Scene Tree)
```
Node2D
├── Sprite2D (objek yang bersinar)
│   └── ShaderMaterial
│       └── Shader (glow effect)
└── ColorRect (optional, untuk effect full-screen bloom)
```

## Kode GDScript (Godot 4)
```gdscript
extends Sprite2D

func _ready():
    var shader_code = """
    shader_type canvas_item;

    uniform float glow_intensity = 1.5;
    uniform float glow_threshold = 0.7;
    uniform vec4 glow_color : source_color = vec4(0.5, 0.8, 1.0, 1.0);
    uniform float glow_spread = 4.0;

    void fragment() {
        vec4 tex = texture(TEXTURE, UV);
        vec4 glow = vec4(0.0);

        for (float x = -glow_spread; x <= glow_spread; x += 1.0) {
            for (float y = -glow_spread; y <= glow_spread; y += 1.0) {
                vec2 offset = vec2(x, y) * TEXTURE_PIXEL_SIZE;
                vec4 sample = texture(TEXTURE, UV + offset);
                float brightness = dot(sample.rgb, vec3(0.299, 0.587, 0.114));
                if (brightness > glow_threshold) {
                    glow += sample * glow_intensity;
                }
            }
        }

        glow /= pow(glow_spread * 2.0 + 1.0, 2.0);
        COLOR = tex + glow * glow_color;
    }
    """
    var shader = Shader.new()
    shader.code = shader_code
    var material = ShaderMaterial.new()
    material.shader = shader
    material.set_shader_parameter("glow_intensity", 2.0)
    material.set_shader_parameter("glow_threshold", 0.5)
    material.set_shader_parameter("glow_color", Color(0.5, 0.8, 1.0, 1.0))
    material.set_shader_parameter("glow_spread", 6.0)
    self.material = material
```

## Kasus Penggunaan Nyata
Glow dan bloom digunakan pada lampu dan sumber cahaya dalam game untuk menciptakan atmosfer yang lebih realistis. Efek ini juga digunakan pada item legendary atau rare untuk menunjukkan keistimewaannya, serta pada ability karakter seperti heal atau shield yang memiliki efek visual bercahaya untuk memberikan feedback visual yang jelas kepada pemain.
