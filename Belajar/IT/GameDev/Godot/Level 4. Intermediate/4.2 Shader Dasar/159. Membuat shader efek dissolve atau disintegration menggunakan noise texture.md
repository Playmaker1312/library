# 159. Membuat shader efek dissolve atau disintegration menggunakan noise texture

## Definisi Singkat
Dissolve effect adalah teknik shader yang membuat sprite secara bertahap menghilang atau terurai menjadi partikel kecil menggunakan noise texture sebagai pola acak. Efek ini sering digunakan untuk transisi kematian karakter atau pergantian scene yang dramatis.

## Analogi
Bayangkan sebuah foto yang terbakar dari satu sisi. Bagian yang terbakar menghilang secara bertahap membentuk pola yang tidak beraturan, mirip dengan bagaimana dissolve effect bekerja menggunakan noise texture sebagai pola pembakaran.

## Struktur Node (Scene Tree)
```
Sprite2D
├── Texture (gambar sprite)
├── ShaderMaterial
│   └── Shader (dissolve effect)
└── NoiseTexture2D (diproses oleh shader)
```

## Kode GDScript (Godot 4)
```gdscript
extends Sprite2D

var dissolve_amount : float = 0.0

func _ready():
    var shader_code = """
    shader_type canvas_item;

    uniform sampler2D noise_texture;
    uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.0;
    uniform vec4 edge_color : source_color = vec4(1.0, 0.5, 0.0, 1.0);
    uniform float edge_width = 0.1;

    void fragment() {
        vec4 tex = texture(TEXTURE, UV);
        float noise = texture(noise_texture, UV).r;
        float threshold = dissolve_amount;

        if (noise < threshold) {
            discard;
        }

        float edge = smoothstep(threshold, threshold + edge_width, noise);
        vec4 final_color = mix(edge_color, tex, edge);
        COLOR = final_color;
    }
    """
    var shader = Shader.new()
    shader.code = shader_code
    var material = ShaderMaterial.new()
    material.shader = shader
    var noise = NoiseTexture2D.new()
    var fast_noise = FastNoiseLite.new()
    fast_noise.noise_type = FastNoiseLite.TYPE_SIMPLEX_SMOOTH
    noise.noise = fast_noise
    material.set_shader_parameter("noise_texture", noise)
    material.set_shader_parameter("dissolve_amount", 0.0)
    material.set_shader_parameter("edge_color", Color(1.0, 0.5, 0.0, 1.0))
    self.material = material

func _process(delta):
    if Input.is_action_pressed("ui_accept"):
        dissolve_amount = min(dissolve_amount + delta * 0.5, 1.0)
        material.set_shader_parameter("dissolve_amount", dissolve_amount)
```

## Kasus Penggunaan Nyata
Dissolve effect digunakan dalam game saat karakter musuh dikalahkan dan menghilang secara dramatis, efek transisi antar area di map, dan efek skill atau ultimate ability yang menunjukkan kekuatan sihir. Efek ini juga populer dalam game horror untuk menunjukkan objek yang perlahan menghilang dari pandangan pemain.
