# 163. Menggunakan ShaderMaterial dan cara mengoper parameter dari GDScript ke shader

## Definisi Singkat
ShaderMaterial adalah jenis Material di Godot yang menghubungkan shader dengan node, memungkinkan pengoperan parameter dari GDScript ke shader melalui uniform variables. Parameter ini bisa diubah secara real-time selama runtime untuk membuat efek interaktif dan dinamis.

## Analogi
Bayangkan sebuah remote control TV. TV adalah shader yang menampilkan gambar, remote control adalah GDScript, dan tombol-tombol di remote adalah parameter uniform. Dengan menekan tombol berbeda, kamu bisa mengubah volume, kecerahan, atau channel tanpa perlu membuka casing TV.

## Struktur Node (Scene Tree)
```
Sprite2D
└── ShaderMaterial
    ├── Shader (kode shader)
    └── Parameter Properties (uniform values)
```

## Kode GDScript (Godot 4)
```gdscript
extends Sprite2D

@export var dissolve_speed : float = 0.3
@export var glow_color : Color = Color(1.0, 0.5, 0.0, 1.0)

var current_dissolve : float = 0.0
var material_shader : ShaderMaterial

func _ready():
    var shader_code = """
    shader_type canvas_item;

    uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.0;
    uniform vec4 glow_color : source_color = vec4(1.0, 0.5, 0.0, 1.0);
    uniform float glow_intensity : hint_range(0.0, 5.0) = 1.0;
    uniform bool use_grayscale = false;

    void fragment() {
        vec4 tex = texture(TEXTURE, UV);
        float noise = texture(TEXTURE, UV * 3.0 + TIME * 0.1).r;

        if (noise < dissolve_amount) {
            discard;
        }

        float edge = smoothstep(dissolve_amount, dissolve_amount + 0.05, noise);
        vec4 final_color = mix(glow_color * glow_intensity, tex, edge);

        if (use_grayscale) {
            float gray = dot(final_color.rgb, vec3(0.299, 0.587, 0.114));
            final_color = vec4(vec3(gray), final_color.a);
        }

        COLOR = final_color;
    }
    """
    var shader = Shader.new()
    shader.code = shader_code
    material_shader = ShaderMaterial.new()
    material_shader.shader = shader
    material_shader.set_shader_parameter("dissolve_amount", 0.0)
    material_shader.set_shader_parameter("glow_color", glow_color)
    material_shader.set_shader_parameter("glow_intensity", 1.5)
    material_shader.set_shader_parameter("use_grayscale", false)
    self.material = material_shader

func _process(delta):
    if Input.is_action_pressed("ui_accept"):
        current_dissolve = min(current_dissolve + dissolve_speed * delta, 1.0)
        material_shader.set_shader_parameter("dissolve_amount", current_dissolve)
    if Input.is_action_just_pressed("ui_cancel"):
        current_dissolve = 0.0
        material_shader.set_shader_parameter("dissolve_amount", 0.0)

func set_glow_intensity(value : float):
    material_shader.set_shader_parameter("glow_intensity", value)

func toggle_grayscale(enabled : bool):
    material_shader.set_shader_parameter("use_grayscale", enabled)

func set_dissolve(amount : float):
    current_dissolve = clamp(amount, 0.0, 1.0)
    material_shader.set_shader_parameter("dissolve_amount", current_dissolve)
```

## Kasus Penggunaan Nyata
Pengoperan parameter shader dari GDScript digunakan untuk membuat efek interaktif seperti perubahan warna saat karakter terkena damage, efek dissolve saat karakter mati, dan efek glow yang berubah intensitasnya berdasarkan status health. Dalam game RPG, parameter shader dikontrol oleh sistem buff/debuff untuk menampilkan efek visual yang sesuai dengan kondisi karakter secara real-time.
