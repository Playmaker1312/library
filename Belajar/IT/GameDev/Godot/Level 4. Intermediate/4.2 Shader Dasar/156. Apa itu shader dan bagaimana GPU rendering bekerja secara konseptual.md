# 156. Apa itu shader dan bagaimana GPU rendering bekerja secara konseptual

## Definisi Singkat
Shader adalah program kecil yang dijalankan oleh GPU (Graphics Processing Unit) untuk mengontrol bagaimana objek ditampilkan di layar, termasuk warna, posisi, dan efek visual. GPU bekerja secara paralel, menjalankan ribuan operasi matematika secara bersamaan untuk merender pixel-pixel di layar.

## Analogi
Bayangkan sebuah pabrik cat mobil dengan ribuan robot kecil (GPU cores). Setiap robot menerima instruksi (shader) yang sama untuk mewarnai satu bagian mobil. Karena ada ribuan robot, semua bagian mobil bisa dicat secara bersamaan dalam waktu singkat. Tanpa instruksi yang benar (shader), robot tidak tahu harus mewarnai apa dan bagaimana.

## Struktur Node (Scene Tree)
```
Node2D
├── Sprite2D          (objek yang akan di-render)
├── ColorRect          (untuk shader full-screen)
└── CanvasItemMaterial (opsional, untuk material override)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var sprite = $Sprite2D

func _ready():
    var shader = Shader.new()
    shader.code = """
    shader_type canvas_item;

    void fragment() {
        COLOR = vec4(1.0, 0.0, 0.0, 1.0);
    }
    """
    var material = ShaderMaterial.new()
    material.shader = shader
    sprite.material = material
```

## Kasus Penggunaan Nyata
Shader digunakan di hampir semua game modern untuk membuat efek visual seperti bayangan, refleksi air, efek glowing, dan animasi tekstur. Dalam game 2D, shader sering digunakan untuk membuat efek transisi antar scene, efek cuaca, dan manipulasi warna secara real-time. Tanpa pemahaman dasar shader, developer akan kesulitan membuat efek visual yang menarik dan performa game akan kurang optimal.
