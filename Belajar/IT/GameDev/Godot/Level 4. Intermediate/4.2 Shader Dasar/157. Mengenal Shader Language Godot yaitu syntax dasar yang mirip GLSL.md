# 157. Mengenal Shader Language Godot yaitu syntax dasar yang mirip GLSL

## Definisi Singkat
Godot Shader Language adalah bahasa shading yang digunakan oleh Godot Engine, mirip dengan GLSL (OpenGL Shading Language) namun dengan beberapa penyederhanaan. Bahasa ini menggunakan tipe data seperti `vec2`, `vec3`, `vec4`, `float`, `int`, dan `sampler2D` untuk manipulasi warna dan posisi pixel.

## Analogi
Bayangkan bahasa shader seperti resep masakan. `shader_type` adalah jenis masakan (canvas_item untuk 2D, spatial untuk 3D). `void vertex()` adalah langkah persiapan bahan, `void fragment()` adalah langkah memasak utama, dan variabel seperti `COLOR` adalah bumbu yang menentukan rasa (warna) akhir masakan.

## Struktur Node (Scene Tree)
```
Sprite2D
└── ShaderMaterial
    └── Shader
```

## Kode GDScript (Godot 4)
```gdscript
extends Sprite2D

func _ready():
    var shader_code = """
    shader_type canvas_item;

    uniform float brightness = 1.0;
    uniform vec4 tint_color : source_color = vec4(1.0, 1.0, 1.0, 1.0);

    void fragment() {
        vec4 tex = texture(TEXTURE, UV);
        COLOR = tex * tint_color * brightness;
    }
    """
    var shader = Shader.new()
    shader.code = shader_code
    var material = ShaderMaterial.new()
    material.shader = shader
    material.set_shader_parameter("brightness", 1.5)
    material.set_shader_parameter("tint_color", Color(1.0, 0.8, 0.8, 1.0))
    self.material = material
```

## Kasus Penggunaan Nyata
Shader Language Godot memungkinkan developer membuat efek visual tanpa harus mempelajari GLSL atau HLSL secara mendalam. Syntax yang mirip GLSL membuat transisi dari shader OpenGL ke Godot menjadi lebih mudah. Bahasa ini mendukung uniform variables untuk mengoper data dari GDScript ke shader, memungkinkan efek interaktif seperti perubahan warna secara real-time berdasarkan input pemain.
