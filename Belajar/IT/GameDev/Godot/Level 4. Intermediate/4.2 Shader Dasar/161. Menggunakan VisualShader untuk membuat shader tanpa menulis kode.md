# 161. Menggunakan VisualShader untuk membuat shader tanpa menulis kode

## Definisi Singkat
VisualShader adalah tool visual di Godot yang memungkinkan developer membuat shader menggunakan node graph tanpa harus menulis kode secara manual. Setiap node mewakili operasi tertentu seperti operasi matematika, sampling tekstur, atau kombinasi warna yang dihubungkan dengan connections.

## Analogi
Bayangkan membuat resep masakan dengan cara menyusun kartu-kartu resep. Setiap kartu berisi satu langkah (seperti "tambah gula" atau "aduk rata"), dan kamu menyusun kartu-kartu tersebut secara berurutan hingga resep selesai. VisualShader bekerja dengan cara yang sama, menyusun node operasi secara visual.

## Struktur Node (Scene Tree)
```
Sprite2D
└── ShaderMaterial
    └── VisualShader (diedit melalui Inspector)
```

## Kode GDScript (Godot 4)
```gdscript
extends Sprite2D

func _ready():
    var visual_shader = VisualShader.new()
    visual_shader.shader_type = "canvas_item"

    var tex_node = VisualShaderNodeTexture.new()
    tex_node.set_input_port_name(0, "UV")
    tex_node.set_output_port_name(0, "Color")
    tex_node.texture_type = 0

    var color_param = VisualShaderNodeUniform.new()
    color_param.uniform_name = "tint_color"
    color_param.uniform_type = VisualShaderNodeUniform.UNIFORM_TYPE_COLOR

    var multiply = VisualShaderNodeOpMultiply.new()
    multiply.set_input_port_name(0, "a")
    multiply.set_input_port_name(1, "b")
    multiply.set_output_port_name(0, "result")

    var output = VisualShaderNodeOutput.new()
    output.set_input_port_name(0, "Color")

    var graph = visual_shader.get_graph(VisualShader.TYPE_FRAGMENT)
    var tex_id = graph.create_node(tex_node)
    var color_id = graph.create_node(color_param)
    var mult_id = graph.create_node(multiply)
    var out_id = graph.create_node(output)

    graph.connect_nodes(tex_id, 0, mult_id, 0)
    graph.connect_nodes(color_id, 0, mult_id, 1)
    graph.connect_nodes(mult_id, 0, out_id, 0)

    var material = ShaderMaterial.new()
    material.shader = visual_shader
    material.set_shader_parameter("tint_color", Color(1.0, 0.5, 0.5, 1.0))
    self.material = material
```

## Kasus Penggunaan Nyata
VisualShader sangat berguna bagi developer yang tidak memiliki latar belakang pemrograman shader namun ingin membuat efek visual kustom. Tool ini juga digunakan untuk prototype cepat efek shader sebelum diimplementasikan dalam kode, dan untuk kolaborasi antara programmer dan artist yang lebih terbiasa dengan interface visual seperti node editor.
