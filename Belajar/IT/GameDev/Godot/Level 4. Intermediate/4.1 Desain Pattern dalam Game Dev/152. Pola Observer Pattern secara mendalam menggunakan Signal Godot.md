# 152. Pola Observer Pattern secara mendalam menggunakan Signal Godot

## Definisi Singkat
Observer Pattern memungkinkan objek (subject) memberi tahu objek lain (observer) tanpa mengetahui secara pasti objek apa yang sedang diberitahu. Di Godot, pattern ini diimplementasikan menggunakan sistem Signal yang memungkinkan komunikasi loose-coupling antar node.

## Analogi
Bayangkan sebuah stasiun radio. Stasiun radio (subject) mengirimkan sinyal ke udara. Siapa pun yang memiliki radio (observer) dan menyalakan frekuensi yang tepat akan menerima siaran tersebut. Stasiun radio tidak perlu tahu siapa yang mendengar, dan radio tidak perlu tahu siapa yang mengirim. Yang terpenting adalah frekuensi sinyal yang cocok.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Player (CharacterBody2D)
├── Enemy (CharacterBody2D)
├── HUD (CanvasLayer)
│   ├── HealthBar (ProgressBar)
│   ├── ScoreLabel (Label)
│   └── DamagePopup (Label)
└── GameManager (Node)
```

## Kode GDScript (Godot 4)

```gdscript
# GameManager.gd
extends Node

signal player_damaged(new_health: int)
signal player_healed(new_health: int)
signal enemy_killed(enemy_name: String, score_value: int)
signal score_changed(new_score: int)
signal game_over()

var player_health: int = 100
var max_health: int = 100
var score: int = 0

func _ready():
    pass

func take_damage(amount: int):
    player_health = clampi(player_health - amount, 0, max_health)
    player_damaged.emit(player_health)
    
    if player_health <= 0:
        game_over.emit()

func heal(amount: int):
    player_health = clampi(player_health + amount, 0, max_health)
    player_healed.emit(player_health)

func add_score(enemy_name: String, value: int):
    score += value
    enemy_killed.emit(enemy_name, value)
    score_changed.emit(score)
```

```gdscript
# Player.gd
extends CharacterBody2D

signal health_changed(new_health: int)
signal died()

@export var max_health: int = 100
var current_health: int

func _ready():
    current_health = max_health
    GameManager.player_damaged.connect(_on_player_damaged)
    GameManager.player_healed.connect(_on_player_healed)

func take_damage(amount: int):
    current_health = clampi(current_health - amount, 0, max_health)
    health_changed.emit(current_health)
    
    if current_health <= 0:
        died.emit()

func heal(amount: int):
    current_health = clampi(current_health + amount, 0, max_health)
    health_changed.emit(current_health)

func _on_player_damaged(new_health: int):
    current_health = new_health
    health_changed.emit(current_health)

func _on_player_healed(new_health: int):
    current_health = new_health
    health_changed.emit(current_health)
```

```gdscript
# Enemy.gd
extends CharacterBody2D

signal died(enemy_name: String)

@export var enemy_name: String = "Enemy"
@export var health: int = 30
@export var score_value: int = 100

func take_damage(amount: int):
    health -= amount
    
    if health <= 0:
        died.emit(enemy_name)
        GameManager.add_score(enemy_name, score_value)
        queue_free()
```

```gdscript
# HUD.gd
extends CanvasLayer

@onready var health_bar = $HealthBar
@onready var score_label = $ScoreLabel
@onready var damage_popup = $DamagePopup

func _ready():
    GameManager.player_damaged.connect(_on_player_damaged)
    GameManager.player_healed.connect(_on_player_healed)
    GameManager.score_changed.connect(_on_score_changed)
    GameManager.game_over.connect(_on_game_over)

func _on_player_damaged(new_health: int):
    health_bar.value = new_health
    _show_damage_popup("-10")

func _on_player_healed(new_health: int):
    health_bar.value = new_health
    _show_damage_popup("+" + str(new_health))

func _on_score_changed(new_score: int):
    score_label.text = "Score: " + str(new_score)

func _on_game_over():
    var game_over_label = Label.new()
    game_over_label.text = "GAME OVER"
    game_over_label.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
    game_over_label.vertical_alignment = VERTICAL_ALIGNMENT_CENTER
    game_over_label.set_anchors_preset(Control.PRESET_FULL_RECT)
    add_child(game_over_label)

func _show_damage_popup(text: String):
    damage_popup.text = text
    damage_popup.modulate = Color.WHITE
    
    var tween = create_tween()
    tween.tween_property(damage_popup, "modulate:a", 0.0, 1.0)
    tween.tween_callback(damage_popup.set.bind("modulate:a", 1.0))
```

```gdscript
# DamagePopup.gd
extends Label

func show_damage(amount: int, is_heal: bool = false):
    text = str(amount)
    
    if is_heal:
        modulate = Color.GREEN
    else:
        modulate = Color.RED
    
    var tween = create_tween()
    tween.tween_property(self, "position:y", position.y - 30, 0.5)
    tween.parallel().tween_property(self, "modulate:a", 0.0, 0.5)
    tween.tween_callback(queue_free)
```

## Kasus Penggunaan Nyata
Observer Pattern dengan Signal sangat penting dalam game untuk komunikasi antar sistem. Contoh nyata termasuk sistem health bar yang update secara real-time, notifikasi saat musuh mati, event saat player mencapai checkpoint, dan sistem achievement yang memantau pencapaian pemain. Pattern ini mengurangi dependensi antar komponen.
