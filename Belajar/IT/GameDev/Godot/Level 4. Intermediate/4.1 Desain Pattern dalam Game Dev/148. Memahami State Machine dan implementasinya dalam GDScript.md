# 148. Memahami State Machine dan implementasinya dalam GDScript

## Definisi Singkat
State Machine adalah desain pattern yang memungkinkan objek mengubah perilaku saat state internalnya berubah. State Machine terdiri dari state, transisi, dan aturan yang mengatur kapan transisi terjadi.

## Analogi
Bayangkan sebuah lampu lalu lintas. Lampu ini memiliki tiga state: Merah, Kuning, dan Hijau. Setiap state memiliki aturan kapan harus berpindah ke state berikutnya. Lampu tidak bisa langsung dari Merah ke Hijau tanpa melalui Kuning terlebih dahulu. Transisi ini diatur oleh timer atau kondisi tertentu.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── StateMachine (Node)
│   ├── IdleState (Node)
│   ├── RunState (Node)
│   └── JumpState (Node)
├── Sprite2D
├── CollisionShape2D
└── AnimationPlayer
```

## Kode GDScript (Godot 4)

```gdscript
# StateMachine.gd
class_name StateMachine
extends Node

signal state_changed(old_state: State, new_state: State)

@export var initial_state: State

var current_state: State
var states: Dictionary = {}

func _ready():
    for child in get_children():
        if child is State:
            states[child.name.to_lower()] = child
            child.transitioned.connect(_on_child_transition)
    
    if initial_state:
        initial_state.enter()
        current_state = initial_state

func _process(delta):
    if current_state:
        current_state.process(delta)

func _physics_process(delta):
    if current_state:
        current_state.physics_process(delta)

func _on_child_transition(new_state_name: String):
    if not states.has(new_state_name):
        return
    
    var old_state = current_state
    current_state.exit()
    current_state = states[new_state_name]
    current_state.enter()
    state_changed.emit(old_state, current_state)
```

```gdscript
# IdleState.gd
extends State

@export var actor: CharacterBody2D
@export var animation_player: AnimationPlayer

func enter():
    animation_player.play("idle")

func physics_process(delta: float):
    var input_direction = Input.get_vector("left", "right", "up", "down")
    if input_direction != Vector2.ZERO:
        transitioned.emit("run")
    
    if Input.is_action_just_pressed("jump"):
        transitioned.emit("jump")
```

## Kasus Penggunaan Nyata
State Machine sangat berguna untuk mengelola kompleksitas karakter player yang memiliki banyak animasi dan perilaku berbeda. Pattern ini juga digunakan untuk AI enemy, UI flow, dan transisi scene. Dengan State Machine, kode menjadi lebih terorganisir dan mudah di-maintain karena setiap state terisolasi dalam script terpisah.
