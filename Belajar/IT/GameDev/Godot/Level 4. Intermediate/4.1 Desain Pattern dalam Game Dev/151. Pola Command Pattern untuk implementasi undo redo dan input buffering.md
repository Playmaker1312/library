# 151. Pola Command Pattern untuk implementasi undo redo dan input buffering

## Definisi Singkat
Command Pattern mengubah sebuah request atau aksi menjadi sebuah objek yang berdiri sendiri. Pattern ini memungkinkan penyimpanan, logging, dan pembatalan aksi serta menjalankan aksi secara deferred atau delayed.

## Analogi
Bayangkan seorang koki restoran. Koki menerima pesanan dari pelanggan dalam bentuk kertas (objek pesanan). Kertas ini berisi informasi lengkap tentang apa yang harus dibuat. Koki dapat menyimpan pesanan, membatalkan pesanan, atau menjalankan pesanan nanti. Setiap pesanan adalah objek independen yang dapat dioperasikan secara terpisah.

```gdscript
# Command.gd
class_name Command
extends RefCounted

func execute():
    pass

func undo():
    pass
```

```gdscript
# MoveCommand.gd
class_name MoveCommand
extends Command

var player: CharacterBody2D
var old_position: Vector2
var new_position: Vector2

func _init(p: CharacterBody2D, old_pos: Vector2, new_pos: Vector2):
    player = p
    old_position = old_pos
    new_position = new_pos

func execute():
    player.global_position = new_position

func undo():
    player.global_position = old_position
```

```gdscript
# CommandManager.gd
class_name CommandManager
extends Node

var undo_stack: Array[Command] = []
var redo_stack: Array[Command] = []

func execute_command(command: Command):
    command.execute()
    undo_stack.append(command)
    redo_stack.clear()

func undo():
    if undo_stack.is_empty():
        return
    
    var command = undo_stack.pop_back()
    command.undo()
    redo_stack.append(command)

func redo():
    if redo_stack.is_empty():
        return
    
    var command = redo_stack.pop_back()
    command.execute()
    undo_stack.append(command)

func clear():
    undo_stack.clear()
    redo_stack.clear()
```

```gdscript
# InputHandler.gd
extends Node

@export var player: CharacterBody2D
@export var command_manager: CommandManager

var input_buffer: Array[Command] = []
var buffer_timer: float = 0.0
var buffer_duration: float = 0.2

func _ready():
    pass

func _process(delta):
    if buffer_timer > 0:
        buffer_timer -= delta
        if buffer_timer <= 0:
            input_buffer.clear()

func _unhandled_input(event: InputEvent):
    if event.is_action_pressed("move_right"):
        var old_pos = player.global_position
        var new_pos = old_pos + Vector2(100, 0)
        var command = MoveCommand.new(player, old_pos, new_pos)
        _buffer_command(command)
    
    elif event.is_action_pressed("move_left"):
        var old_pos = player.global_position
        var new_pos = old_pos + Vector2(-100, 0)
        var command = MoveCommand.new(player, old_pos, new_pos)
        _buffer_command(command)
    
    elif event.is_action_pressed("undo"):
        command_manager.undo()
    
    elif event.is_action_pressed("redo"):
        command_manager.redo()

func _buffer_command(command: Command):
    input_buffer.append(command)
    buffer_timer = buffer_duration
    
    if input_buffer.size() >= 3:
        _execute_buffered_commands()

func _execute_buffered_commands():
    for command in input_buffer:
        command_manager.execute_command(command)
    input_buffer.clear()
```

```gdscript
# UndoRedoUI.gd
extends CanvasLayer

@export var command_manager: CommandManager

@onready var undo_button = $UndoButton
@onready var redo_button = $RedoButton

func _ready():
    undo_button.pressed.connect(_on_undo_pressed)
    redo_button.pressed.connect(_on_redo_pressed)
    _update_buttons()

func _on_undo_pressed():
    command_manager.undo()
    _update_buttons()

func _on_redo_pressed():
    command_manager.redo()
    _update_buttons()

func _update_buttons():
    undo_button.disabled = command_manager.undo_stack.is_empty()
    redo_button.disabled = command_manager.redo_stack.is_empty()
```

## Kasus Penggunaan Nyata
Command Pattern sangat berguna untuk implementasi fitur undo/redo dalam game puzzle atau strategy. Input buffering memungkinkan pemain melakukan input cepat berturut-turut tanpa kehilangan aksi. Pattern ini juga digunakan untuk replay system, turn-based game, dan sistem aksi yang kompleks lainnya.
