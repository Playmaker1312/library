# 153. Pola Object Pool untuk mengoptimalkan instansiasi objek berulang seperti peluru

## Definisi Singkat
Object Pool adalah desain pattern yang mengelola kumpulan objek yang sudah diinstansiasi sebelumnya. Pattern ini mengurangi overhead instansiasi dan garbage collection dengan mengaktifkan dan menonaktifkan objek daripada membuat dan menghancurkannya berulang kali.

## Analogi
Bayangkan sebuah taksi di kota. Daripada setiap kali ada penumpang harus membeli mobil baru, lebih efisien menggunakan armada taksi yang sudah ada. Saat taksi kosong, taksi tersebut disimpan di pool (garasi). Saat ada penumpang, taksi diambil dari pool, digunakan, lalu dikembalikan ke pool saat selesai. Mobil tidak pernah dibuat baru atau dihancurkan.

```
BulletPool (Node2D)
├── Bullets (Node2D)

```

## Kode GDScript (Godot 4)

```gdscript
# Bullet.gd
extends Area2D

var speed: float = 500.0
var damage: int = 10
var direction: Vector2 = Vector2.RIGHT
var is_active: bool = false

func _ready():
    body_entered.connect(_on_body_entered)
    area_entered.connect(_on_area_entered)

func _physics_process(delta):
    if not is_active:
        return
    
    position += direction * speed * delta
    
    if position.x > 2000 or position.x < -2000:
        deactivate()
    if position.y > 2000 or position.y < -2000:
        deactivate()

func activate(spawn_pos: Vector2, dir: Vector2):
    global_position = spawn_pos
    direction = dir.normalized()
    is_active = true
    show()
    set_deferred("monitoring", true)
    set_deferred("monitorable", true)

func deactivate():
    is_active = false
    hide()
    set_deferred("monitoring", false)
    set_deferred("monitorable", false)

func _on_body_entered(body):
    if body.has_method("take_damage"):
        body.take_damage(damage)
    deactivate()

func _on_area_entered(area):
    if area.has_method("take_damage"):
        area.take_damage(damage)
    deactivate()
```

```gdscript
# BulletPool.gd
class_name BulletPool
extends Node2D

@export var bullet_scene: PackedScene
@export var pool_size: int = 50

var bullets: Array[Area2D] = []

func _ready():
    _initialize_pool()

func _initialize_pool():
    for i in range(pool_size):
        var bullet = bullet_scene.instantiate()
        add_child(bullet)
        bullet.deactivate()
        bullets.append(bullet)

func get_bullet() -> Area2D:
    for bullet in bullets:
        if not bullet.is_active:
            return bullet
    
    var new_bullet = bullet_scene.instantiate()
    add_child(new_bullet)
    bullets.append(new_bullet)
    return new_bullet

func spawn_bullet(spawn_pos: Vector2, direction: Vector2) -> Area2D:
    var bullet = get_bullet()
    bullet.activate(spawn_pos, direction)
    return bullet

func deactivate_all():
    for bullet in bullets:
        bullet.deactivate()
```

```gdscript
# Player.gd
extends CharacterBody2D

@export var bullet_pool: BulletPool
@export var fire_rate: float = 0.2
@export var bullet_speed: float = 500.0

var fire_timer: float = 0.0

func _ready():
    pass

func _process(delta):
    fire_timer -= delta
    
    if Input.is_action_pressed("shoot") and fire_timer <= 0:
        _shoot()
        fire_timer = fire_rate

func _shoot():
    var direction = Vector2.RIGHT
    if $Sprite2D.flip_h:
        direction = Vector2.LEFT
    
    bullet_pool.spawn_bullet(global_position, direction)
```

```gdscript
# EnemySpawner.gd
extends Node2D

@export var enemy_bullet_pool: BulletPool
@export var spawn_points: Array[Marker2D] = []
@export var spawn_interval: float = 2.0

var spawn_timer: float = 0.0

func _process(delta):
    spawn_timer -= delta
    
    if spawn_timer <= 0:
        _spawn_enemy_bullet()
        spawn_timer = spawn_interval

func _spawn_enemy_bullet():
    if spawn_points.is_empty():
        return
    
    var spawn_point = spawn_points[randi() % spawn_points.size()]
    var direction = Vector2.LEFT
    enemy_bullet_pool.spawn_bullet(spawn_point.global_position, direction)
```

## Kasus Penggunaan Nyata
Object Pool sangat efektif untuk objek yang sering diinstansiasi dan dihancurkan seperti peluru, efek partikel, musuh, atau item. Pattern ini mengurangi frame drop karena garbage collection dan mengurangi penggunaan memori. Game shoot 'em up atau bullet hell sangat menguntungkan dari pattern ini karena banyak peluru yang harus dikelola secara efisien.
