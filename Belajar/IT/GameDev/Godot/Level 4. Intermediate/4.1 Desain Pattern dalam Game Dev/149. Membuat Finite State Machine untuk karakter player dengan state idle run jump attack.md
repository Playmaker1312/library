# 149. Membuat Finite State Machine untuk karakter player dengan state idle run jump attack

## Definisi Singkat
Finite State Machine (FSM) adalah implementasi State Machine dengan jumlah state yang terbatas dan transisi yang telah ditentukan sebelumnya. Setiap state hanya dapat berpindah ke state tertentu sesuai aturan yang berlaku.

## Analogi
Bayangkan sebuah mesin vending. Mesin ini memiliki state: Idle (menunggu input), Memproses (menghitung uang), Mengeluarkan Barang, dan Selesai. Setiap state memiliki transisi yang jelas. Dari Idle, mesin bisa ke Memproses. Dari Memproses, bisa ke Mengeluarkan Barang atau kembali ke Idle jika uang tidak cukup. Tidak ada state yang bisa melompat ke state lain secara acak.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── StateMachine (Node)
│   ├── Idle (Node "Idle")
│   ├── Run (Node "Run")
│   ├── Jump (Node "Jump")
│   └── Attack (Node "Attack")
├── Sprite2D
├── CollisionShape2D
├── AnimationPlayer
└── AnimationTree
```

## Kode GDScript (Godot 4)

```gdscript
# Player.gd
extends CharacterBody2D

const SPEED = 300.0
const JUMP_VELOCITY = -400.0

var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

@onready var state_machine = $StateMachine
@onready var animation_player = $AnimationPlayer
@onready var sprite = $Sprite2D

func _physics_process(delta):
    if not is_on_floor():
        velocity.y += gravity * delta
    
    velocity = move_and_slide(velocity)
```

```gdscript
# Idle.gd
extends PlayerState

func enter():
    animation_player.play("idle")
    actor.velocity.x = 0

func physics_process(delta: float):
    var direction = Input.get_axis("move_left", "move_right")
    
    if direction != 0:
        transitioned.emit("Run")
    elif Input.is_action_just_pressed("jump") and actor.is_on_floor():
        transitioned.emit("Jump")
    elif Input.is_action_just_pressed("attack"):
        transitioned.emit("Attack")
```

```gdscript
# Run.gd
extends PlayerState

func enter():
    animation_player.play("run")

func physics_process(delta: float):
    var direction = Input.get_axis("move_left", "move_right")
    
    actor.velocity.x = direction * actor.SPEED
    
    if actor.velocity.x < 0:
        actor.sprite.flip_h = true
    elif actor.velocity.x > 0:
        actor.sprite.flip_h = false
    
    if direction == 0:
        transitioned.emit("Idle")
    elif Input.is_action_just_pressed("jump") and actor.is_on_floor():
        transitioned.emit("Jump")
    elif Input.is_action_just_pressed("attack"):
        transitioned.emit("Attack")
```

```gdscript
# Jump.gd
extends PlayerState

func enter():
    animation_player.play("jump")
    actor.velocity.y = actor.JUMP_VELOCITY

func physics_process(delta: float):
    var direction = Input.get_axis("move_left", "move_right")
    actor.velocity.x = direction * actor.SPEED
    
    if actor.is_on_floor():
        transitioned.emit("Idle")
    elif Input.is_action_just_pressed("attack"):
        transitioned.emit("Attack")
```

```gdscript
# Attack.gd
extends PlayerState

func enter():
    animation_player.play("attack")
    actor.velocity.x = 0
    animation_player.animation_finished.connect(_on_animation_finished, CONNECT_ONE_SHOT)

func exit():
    if animation_player.animation_finished.is_connected(_on_animation_finished):
        animation_player.animation_finished.disconnect(_on_animation_finished)

func _on_animation_finished():
    transitioned.emit("Idle")
```

```gdscript
# StateMachine.gd
extends Node

@export var initial_state: NodePath

var current_state: PlayerState
var states: Dictionary = {}

func _ready():
    for child in get_children():
        if child is PlayerState:
            states[child.name] = child
            child.transitioned.connect(_on_child_transition)
    
    if initial_state:
        current_state = get_node(initial_state)
        current_state.enter()

func _process(delta):
    if current_state:
        current_state.process(delta)

func _physics_process(delta):
    if current_state:
        current_state.physics_process(delta)

func _input(event):
    if current_state:
        current_state.handle_input(event)

func _on_child_transition(new_state_name: String):
    if not states.has(new_state_name):
        return
    
    current_state.exit()
    current_state = states[new_state_name]
    current_state.enter()
```

## Kasus Penggunaan Nyata
FSM dengan state idle, run, jump, dan attack adalah implementasi dasar untuk karakter platformer. Pattern ini memungkinkan developer menambahkan state baru seperti wall-slide, dash, atau crouch tanpa mengubah kode state lain. Setiap state terisolasi sehingga bug pada satu state tidak mempengaruhi state lainnya.
