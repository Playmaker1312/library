# 187. Menggunakan VisibilityNotifier2D untuk menonaktifkan objek di luar layar

## Definisi Singkat
VisibilityNotifier2D adalah node yang mendeteksi apakah area bounding box objek terlihat di dalam viewport kamera. Ketika objek keluar dari layar, sinyal `screen_exited` dipancarkan dan developer dapat menonaktifkan proses untuk menghemat CPU dan GPU.

## Analogi
Bayangkan seorang satpam yang berdiri di ujung panggung teater. Saat aktor keluar dari area panggung yang terlihat penonton, satpam memberi tanda agar aktor bisa istirahat dan tidak perlu berakting saat tidak ada yang melihat.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
└── VisibilityNotifier2D

Enemy (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
├── VisibilityNotifier2D
└── ProcessToggle (Node) [optional helper]
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var visibility_notifier: VisibilityNotifier2D = $VisibilityNotifier2D
@onready var sprite: Sprite2D = $Sprite2D
var is_on_screen: bool = true

func _ready() -> void:
	visibility_notifier.screen_entered.connect(_on_screen_entered)
	visibility_notifier.screen_exited.connect(_on_screen_exited)

func _on_screen_entered() -> void:
	is_on_screen = true
	sprite.visible = true
	set_physics_process(true)

func _on_screen_exited() -> void:
	is_on_screen = false
	sprite.visible = false
	set_physics_process(false)

func _physics_process(delta: float) -> void:
	if not is_on_screen:
		return
	move_and_slide()
	if velocity.length() > 0:
		velocity = velocity.normalized() * 300.0
	else:
		velocity = Vector2(randf_range(-1, 1), randf_range(-1, 1)).normalized() * 300.0
```

## Kasus Penggunaan Nyata
Dalam game dengan banyak objek seperti endless runner atau scrolling shooter, VisibilityNotifier2D membantu menghemat performa dengan menonaktifkan update logic untuk objek yang tidak terlihat. Misalnya, musuh yang sudah melampaui batas layar kamera tidak perlu lagi menjalankan pathfinding atau animasi, sehingga CPU bisa fokus ke objek yang benar-benar terlihat oleh pemain.
