# 186. Teknik Object Pooling untuk mengurangi biaya instansiasi dan penghapusan objek

## Definisi Singkat
Object Pooling adalah teknik di mana objek yang sudah tidak digunakan tidak dihapus, melainkan dinonaktifkan dan disimpan dalam pool (kumpulan). Ketika objek baru dibutuhkan, objek dari pool didaktifkan kembali alih-alih membuat instans baru dari scratch.

## Analogi
Bayangkan sebuah kursi di ruang tunggu. Tanpa pooling, setiap kali ada tamu baru, kursi lama dibuang dan kursi baru dibeli. Dengan pooling, kursi yang sudah ditinggal tamu cukup diamankan kembali dan diberikan ke tamu berikutnya — jauh lebih hemat waktu dan biaya.

## Struktur Node (Scene Tree)
```
BulletPool (Node2D)
├── Bullets (Node2D)
│   ├── Bullet (Area2D) [pool, mulai inactive]
│   ├── Bullet
│   ├── ...
│   └── Bullet
└── Timer (Timer)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@export var bullet_scene: PackedScene
@export var pool_size: int = 50
@onready var bullets_container: Node2D = $Bullets
var bullet_pool: Array[Area2D] = []
var current_index: int = 0

func _ready() -> void:
	for i in range(pool_size):
		var bullet = bullet_scene.instantiate()
		bullet.visible = false
		bullet.set_process(false)
		bullet.set_physics_process(false)
		bullet.set_deferred("monitoring", false)
		bullets_container.add_child(bullet)
		bullet_pool.append(bullet)

func get_bullet() -> Area2D:
	var bullet = bullet_pool[current_index]
	current_index = (current_index + 1) % pool_size
	return bullet

func spawn_bullet(pos: Vector2, direction: Vector2) -> void:
	var bullet = get_bullet()
	bullet.global_position = pos
	bullet.rotation = direction.angle()
	bullet.visible = true
	bullet.set_process(true)
	bullet.set_physics_process(true)
	bullet.set_deferred("monitoring", true)
	bullet.setup(direction)

func deactivate_bullet(bullet: Area2D) -> void:
	bullet.visible = false
	bullet.set_process(false)
	bullet.set_physics_process(false)
	bullet.set_deferred("monitoring", false)
```

## Kasus Penggunaan Nyata
Object pooling sangat efektif untuk objek yang sering muncul dan hilang seperti peluru (bullet), efek partikel, atau musuh dalam shoot-em-up game. Tanpa pooling, repeatedly calling `instantiate()` dan `queue_free()` akan menyebabkan frame drops karena garbage collection bekerja terlalu keras. Dengan pooling, alokasi memori dilakukan sekali di awal dan objek hanya diaktifkan/dinonaktifkan secara bergantian.
