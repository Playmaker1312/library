# 188. Memahami draw call dan cara menguranginya menggunakan atlasing

## Definisi Singkat
Draw call adalah perintah dari CPU ke GPU untuk menampilkan satu objek atau batch objek dengan material yang sama. Setiap draw call memiliki overhead komunikasi, sehingga semakin banyak draw call semakin berat beban rendering. Texture Atlas menggabungkan banyak gambar ke dalam satu atlas, sehingga banyak sprite bisa di-draw dalam satu draw call.

## Analogi
Bayangkan Anda memesan makanan di restoran. Setiap pesanan (draw call) membutuhkan pelayan yang bolak-balik ke dapur. Jika Anda memesan 20 piring satu per satu, pelayan akan kelelahan. Tapi jika semua piring diletakkan dalam satu nampan besar (atlas), pelayan hanya perlu sekali bolak-balik.

## Struktur Node (Scene Tree)
```
GameWorld (Node2D)
├── TileMap (TileMapLayer)
├── Players (Node2D)
│   └── Player (CharacterBody2D)
├── Enemies (Node2D)
│   └── Enemy (CharacterBody2D)
└── Projectiles (Node2D)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var sprite: Sprite2D = $Sprite2D
@onready var animation: AnimationPlayer = $AnimationPlayer

func _ready() -> void:
	sprite.texture = preload("res://assets/sprite_atlas.png")
	sprite.region_enabled = true
	sprite.region_rect = Rect2(0, 0, 64, 64)
	animation.play("idle")

func change_sprite_region(region: Rect2) -> void:
	sprite.region_rect = region

func _on_area_entered(area: Area2D) -> void:
	if area.is_in_group("player"):
		queue_free()

func _process(_delta: float) -> void:
	var draw_calls = Performance.get_monitor(Performance.RENDER_TOTAL_DRAW_CALLS)
	if draw_calls > 100:
		push_warning("Draw calls terlalu tinggi: %d" % draw_calls)
```

## Kasus Penggunaan Nyata
Dalam game 2D dengan banyak sprite berbeda seperti RPG atau platformer, setiap texture yang berbeda akan menghasilkan draw call terpisah. Dengan menggabungkan semua sprite ke dalam satu Texture Atlas (menggunakan tool seperti TexturePacker atau fitur bawaan Godot), banyak objek bisa di-render dalam satu batch. Ini mengurangi overhead GPU dan meningkatkan FPS secara signifikan, terutama di perangkat mobile.
