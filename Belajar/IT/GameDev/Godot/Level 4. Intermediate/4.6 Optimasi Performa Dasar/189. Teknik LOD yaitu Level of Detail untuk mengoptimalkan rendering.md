# 189. Teknik LOD yaitu Level of Detail untuk mengoptimalkan rendering

## Definisi Singkat
Level of Detail (LOD) adalah teknik yang mengganti model atau representasi visual objek dengan versi yang lebih sederhana berdasarkan jarak dari kamera. Semakin jauh objek dari kamera, semakin rendah detail yang ditampilkan, sehingga mengurangi beban rendering tanpa mengorbankan kualitas visual yang terlihat oleh pemain.

## Analogi
Bayangkan Anda melihat gedung pencakar langit dari kejauhan. Dari jarak 10 km, gedung hanya terlihat seperti kotak hijau. Dari jarak 1 km, Anda mulai melihat jendela-jendela. Dari jarak 10 meter, Anda bisa melihat detail arsitektur, tekstur dinding, dan ornamen. LOD bekerja dengan prinsip yang sama — tampilkan detail sesuai jarak pandang.

## Struktur Node (Scene Tree)
```
Environment (Node3D)
├── LODObject (Node3D) [script at root]
├── LOD_High (MeshInstance3D) [LOD 0, jarak dekat]
├── LOD_Medium (MeshInstance3D) [LOD 1, jarak menengah]
├── LOD_Low (MeshInstance3D) [LOD 2, jarak jauh]
└── LOD_Billboard (Sprite3D) [LOD 3, sangat jauh]
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@onready var camera: Camera3D = get_viewport().get_camera_3d()
@export var lod_distances: Array[float] = [10.0, 30.0, 60.0]
@onready var lod_nodes: Array[MeshInstance3D] = [
	$LOD_High,
	$LOD_Medium,
	$LOD_Low,
	$LOD_Billboard
]
var current_lod: int = -1

func _ready() -> void:
	for node in lod_nodes:
		node.visible = false
	lod_nodes[0].visible = true
	current_lod = 0

func _process(_delta: float) -> void:
	if camera == null:
		camera = get_viewport().get_camera_3d()
		return
	
	var distance := global_position.distance_to(camera.global_position)
	var new_lod := 0
	
	for i in range(lod_distances.size()):
		if distance > lod_distances[i]:
			new_lod = i + 1
	
	new_lod = clampi(new_lod, 0, lod_nodes.size() - 1)
	
	if new_lod != current_lod:
		lod_nodes[current_lod].visible = false
		lod_nodes[new_lod].visible = true
		current_lod = new_lod
```

## Kasus Penggunaan Nyata
LOD sangat penting dalam game 3D open world dengan banyak objek seperti pohon, bangunan, dan karakter NPC. Dari jarak jauh, ratusan pohon hanya dirender sebagai billboard 2D atau mesh sederhana dengan segitiga sedikit. Ketika pemain mendekat, sistem LOD beralih ke mesh yang lebih detail secara otomatis. Teknik ini bisa mengurangi jumlah polygon yang harus diproses GPU hingga 70-80% tanpa penurunan kualitas visual yang terlihat.
