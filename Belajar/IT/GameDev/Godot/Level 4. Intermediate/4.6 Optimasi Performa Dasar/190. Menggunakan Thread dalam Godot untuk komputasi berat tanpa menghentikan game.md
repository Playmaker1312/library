# 190. Menggunakan Thread dalam Godot untuk komputasi berat tanpa menghentikan game

## Definisi Singkat
Thread adalah jalur eksekusi terpisah yang memungkinkan komputasi berat dijalankan paralel dengan loop utama game. Di Godot, `Thread` class memungkinkan developer menjalankan fungsi berat seperti pathfinding, procedural generation, atau loading data di background tanpa membekukan frame game.

## Analogi
Bayangkan sebuah kafe dengan satu barista (single thread). Jika ada pelanggan memesan kopi rumit yang butuh waktu lama, pelanggan lain harus menunggu. Dengan menambah barista tambahan (thread), satu barista bisa melayani pesanan rumit sementara yang lain tetap melayani pelanggan biasa tanpa antrean.

## Struktur Node (Scene Tree)
```
GameManager (Node)
├── ThreadPool (Node)
│   ├── Thread1 (Thread) [handle pathfinding]
│   └── Thread2 (Thread) [handle data loading]
├── Timer (Timer) [polling interval]
└── UI (CanvasLayer)
    └── StatusLabel (Label)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var thread: Thread
var mutex: Mutex
var result_data: Variant = null
var is_computing: bool = false
@onready var status_label: Label = $UI/StatusLabel

func _ready() -> void:
	thread = Thread.new()
	mutex = Mutex.new()

func _process(_delta: float) -> void:
	if is_computing:
		status_label.text = "Menghitung..."
	else:
		status_label.text = "Siap"

func start_heavy_computation(input: Dictionary) -> void:
	if thread.is_started():
		return
	is_computing = true
	result_data = null
	thread.start(_compute_in_thread.bind(input))

func _compute_in_thread(data: Dictionary) -> Variant:
	var result := []
	for i in range(data.get("iterations", 1000000)):
		var value := sqrt(float(i)) * sin(float(i))
		result.append(value)
	return result

func _on_timer_timeout() -> void:
	if thread.is_started() and not thread.is_alive():
		mutex.lock()
		result_data = thread.wait_to_finish()
		mutex.unlock()
		is_computing = false
		_process_result(result_data)

func _process_result(data: Variant) -> void:
	if data == null:
		return
	status_label.text = "Selesai! %d item dihitung" % data.size()

func _exit_tree() -> void:
	if thread.is_started():
		thread.wait_to_finish()
```

## Kasus Penggunaan Nyata
Thread sangat berguna untuk operasi yang membutuhkan waktu lama seperti procedural terrain generation di open world game, A* pathfinding untuk ratusan NPC secara bersamaan, atau loading data save file yang besar. Tanpa thread, game akan freeze selama beberapa detik saat operasi berat berjalan. Dengan thread, loop utama tetap berjalan smooth di 60 FPS sementara komputasi berat selesai di background.
