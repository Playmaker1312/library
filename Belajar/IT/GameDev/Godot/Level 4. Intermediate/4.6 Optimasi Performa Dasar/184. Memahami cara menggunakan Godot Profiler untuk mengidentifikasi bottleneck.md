# 184. Memahami cara menggunakan Godot Profiler untuk mengidentifikasi bottleneck

## Definisi Singkat
Godot Profiler adalah tool bawaan yang menampilkan data performa real-time seperti waktu eksekusi script, rendering, dan physics per frame. Tool ini membantu developer menemukan bagian kode atau sistem yang menjadi bottleneck (penyebab utama perlambatan).

## Analogi
Bayangkan sebuah pabrik dengan banyak stasiun kerja. Godot Profiler seperti panel monitoring yang menunjukkan stasiun mana yang paling lambat memproses barang, sehingga manager tahu harus memperbaiki bagian mana terlebih dahulu.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Player (CharacterBody2D)
├── Enemies (Node2D)
│   ├── Enemy1 (CharacterBody2D)
│   ├── Enemy2 (CharacterBody2D)
│   └── ...
└── HUD (CanvasLayer)
    └── FPSLabel (Label)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@export var enemy_scene: PackedScene
@onready var fps_label: Label = $HUD/FPSLabel
var enemy_count: int = 0

func _ready() -> void:
	for i in range(50):
		spawn_enemy()

func _process(delta: float) -> void:
	fps_label.text = "FPS: %d" % Engine.get_frames_per_second()

func spawn_enemy() -> void:
	var enemy = enemy_scene.instantiate()
	enemy.position = Vector2(randf_range(0, 1024), randf_range(0, 600))
	add_child(enemy)
	enemy_count += 1

func _on_timer_timeout() -> void:
	if enemy_count < 200:
		spawn_enemy()
```

## Kasus Penggunaan Nyata
Profiling sangat penting ketika game mulai terasa lag di perangkat target. Dengan membuka **Debug > Profiler** atau menekan shortcut `F3`, developer bisa melihat graph waktu CPU dan GPU per frame, lalu drill-down ke fungsi atau node spesifik yang memakan waktu paling banyak. Data ini menjadi dasar keputusan optimasi apakah yang harus dilakukan terlebih dahulu.
