# 182. Procedural item generation menggunakan tabel loot dan bobot probabilitas

## Definisi Singkat
Procedural item generation adalah teknik membuat item secara acak menggunakan tabel loot yang berisi daftar item beserta bobot probabilitasnya, sehingga item langka memiliki peluang lebih kecil untuk muncul.

## Analogi
Bayangkan kamu sedang memainkan undian berhadiah. Ada tiket emas (peluang kecil), tiket perak (peluang sedang), dan tiket perunggu (peluang besar). Semakin langka tiket, semakin kecil kemungkinan kamu mendapatkannya, tetapi hadiahnya semakin besar.

## Struktur Node (Scene Tree)
```
LootSystem (Node)
├── LootTable (Resource)
└── ItemDatabase (Resource)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

class LootEntry:
	var item_name: String
	var weight: float
	var min_amount: int
	var max_amount: int

	func _init(p_name: String, p_weight: float, p_min: int = 1, p_max: int = 1) -> void:
		item_name = p_name
		weight = p_weight
		min_amount = p_min
		max_amount = p_max

class LootTable:
	var entries: Array[LootEntry]
	var total_weight: float = 0.0

	func add_entry(entry: LootEntry) -> void:
		entries.append(entry)
		total_weight += entry.weight

	func roll() -> Dictionary:
		var roll_val: float = randf() * total_weight
		var cumulative: float = 0.0
		for entry in entries:
			cumulative += entry.weight
			if roll_val <= cumulative:
				var amount: int = randi_range(entry.min_amount, entry.max_amount)
				return {"item": entry.item_name, "amount": amount}
		var last: LootEntry = entries[-1]
		return {"item": last.item_name, "amount": randi_range(last.min_amount, last.max_amount)}

	func roll_multiple(count: int) -> Array[Dictionary]:
		var results: Array[Dictionary] = []
		for i in range(count):
			results.append(roll())
		return results

func create_common_loot_table() -> LootTable:
	var table: LootTable = LootTable.new()
	table.add_entry(LootEntry.new("Health Potion", 50.0, 1, 3))
	table.add_entry(LootEntry.new("Mana Potion", 30.0, 1, 2))
	table.add_entry(LootEntry.new("Gold Coin", 70.0, 5, 20))
	table.add_entry(LootEntry.new("Iron Sword", 10.0, 1, 1))
	table.add_entry(LootEntry.new("Magic Staff", 3.0, 1, 1))
	table.add_entry(LootEntry.new("Dragon Armor", 1.0, 1, 1))
	return table

func create_boss_loot_table() -> LootTable:
	var table: LootTable = LootTable.new()
	table.add_entry(LootEntry.new("Epic Weapon", 20.0, 1, 1))
	table.add_entry(LootEntry.new("Rare Armor", 15.0, 1, 1))
	table.add_entry(LootEntry.new("Gold Coin", 40.0, 50, 100))
	table.add_entry(LootEntry.new("Legendary Gem", 5.0, 1, 1))
	table.add_entry(LootEntry.new("Health Potion", 30.0, 3, 5))
	return table

func get_loot(source_type: String) -> Array[Dictionary]:
	match source_type:
		"common_enemy":
			return create_common_loot_table().roll_multiple(randi_range(1, 3))
		"boss":
			return create_boss_loot_table().roll_multiple(randi_range(3, 6))
		"chest":
			return create_common_loot_table().roll_multiple(randi_range(2, 4))
		_:
			return []

func display_loot(loot: Array[Dictionary]) -> void:
	for item in loot:
		print(str(item["amount"]) + "x " + item["item"])
```

## Kasus Penggunaan Nyata
Sistem loot table digunakan dalam game Diablo dan Borderlands untuk menghasilkan item drop secara acak dengan tingkat kelangkaan yang berbeda. Game RPG seperti Skyrim menggunakan sistem serupa untuk menentukan hadiah dari peti harta karun, musuh, dan quest reward berdasarkan level pemain.
