# 183. Membuat endless runner level menggunakan chunk-based generation

## Definisi Singkat
Chunk-based generation adalah teknik membagi level menjadi potongan-potongan kecil (chunk) yang dihasilkan secara dinamis saat pemain bergerak, sehingga level dapat berlanjut tanpa batas tanpa memuat seluruh peta sekaligus.

## Analogi
Bayangkan kamu sedang mengendarai mobil di jalan raya. Jalan di depanmu selalu muncul saat kamu terus melaju, sementara jalan di belakangmu menghilang dari pandangan. Chunk-based generation bekerja dengan cara yang sama: membuat bagian baru di depan dan menghapus bagian lama di belakang.

## Struktur Node (Scene Tree)
```
EndlessRunner (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   └── CollisionShape2D
├── ChunkSpawner (Node2D)
└── Camera2D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

class Chunk:
	var position: Vector2
	var nodes: Array[Node2D]
	var is_active: bool = true

	func _init(p_position: Vector2) -> void:
		position = p_position

@export var chunk_width: float = 800.0
@export var chunk_height: float = 600.0
@export var chunks_ahead: int = 3
@export var chunks_behind: int = 2
@export var platform_scene: PackedScene
@export var obstacle_scene: PackedScene
@export var coin_scene: PackedScene

var chunks: Array[Chunk] = []
var player: CharacterBody2D
var chunk_spawner: Node2D
var last_chunk_x: float = 0.0

func _ready() -> void:
	player = $Player
	chunk_spawner = $ChunkSpawner
	generate_initial_chunks()

func _process(delta: float) -> void:
	check_and_update_chunks()

func generate_initial_chunks() -> void:
	for i in range(chunks_ahead + chunks_behind + 1):
		var chunk_pos: float = (i - chunks_behind) * chunk_width
		create_chunk(Vector2(chunk_pos, 0))

func check_and_update_chunks() -> void:
	var player_chunk_x: float = floor(player.global_position.x / chunk_width) * chunk_width
	for chunk in chunks:
		if chunk.position.x < player_chunk_x - chunk_width * chunks_behind:
			recycle_chunk(chunk)
		elif chunk.position.x > player_chunk_x + chunk_width * chunks_ahead:
			recycle_chunk(chunk)
	for i in range(chunks_behind + 1, chunks_behind + chunks_ahead + 1):
		var needed_x: float = (player_chunk_x / chunk_width + i - chunks_behind) * chunk_width
		if not chunk_exists_at(needed_x):
			create_chunk(Vector2(needed_x, 0))

func chunk_exists_at(x_pos: float) -> bool:
	for chunk in chunks:
		if abs(chunk.position.x - x_pos) < 1.0:
			return true
	return false

func create_chunk(pos: Vector2) -> Chunk:
	var chunk: Chunk = Chunk.new(pos)
	var platform_count: int = randi_range(3, 6)
	for i in range(platform_count):
		var platform_pos: Vector2 = Vector2(
			pos.x + randf_range(50, chunk_width - 50),
			randf_range(100, chunk_height - 100)
		)
		var platform: Node2D = platform_scene.instantiate()
		platform.position = platform_pos
		chunk_spawner.add_child(platform)
		chunk.nodes.append(platform)
		if randf() > 0.5:
			var obstacle_pos: Vector2 = platform_pos + Vector2(0, -50)
			var obstacle: Node2D = obstacle_scene.instantiate()
			obstacle.position = obstacle_pos
			chunk_spawner.add_child(obstacle)
			chunk.nodes.append(obstacle)
		if randf() > 0.3:
			var coin_count: int = randi_range(1, 3)
			for j in range(coin_count):
				var coin_pos: Vector2 = platform_pos + Vector2(randf_range(-30, 30), -30 - j * 20)
				var coin: Node2D = coin_scene.instantiate()
				coin.position = coin_pos
				chunk_spawner.add_child(coin)
				chunk.nodes.append(coin)
	chunks.append(chunk)
	return chunk

func recycle_chunk(chunk: Chunk) -> void:
	for node in chunk.nodes:
		if is_instance_valid(node):
			node.queue_free()
	chunk.nodes.clear()
	chunks.erase(chunk)

func get_chunk_index(pos: Vector2) -> int:
	return int(pos.x / chunk_width)
```

## Kasus Penggunaan Nyata
Chunk-based generation digunakan dalam game endless runner seperti Subway Surfers dan Temple Run untuk menghasilkan level yang terus berlanjut tanpa batas. Teknik ini juga digunakan dalam game open-world seperti No Man's Sky untuk memuat area dunia secara dinamis sesuai dengan posisi pemain, menghemat memori dan meningkatkan performa.
