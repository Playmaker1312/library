# 181. Menggunakan noise function FastNoiseLite untuk terrain generation

## Definisi Singkat
FastNoiseLite adalah kelas noise function bawaan Godot yang menyediakan berbagai jenis noise seperti Simplex, Perlin, dan Value noise untuk menghasilkan pola alami seperti terrain, awan, dan tekstur.

## Analogi
Bayangkan kamu sedang menatap permukaan laut dari atas. Ada gelombang besar dan kecil yang tumpang tindih menciptakan pola yang kompleks namun terlihat alami. Noise function bekerja dengan cara yang sama: menggabungkan beberapa lapisan frekuensi untuk menghasilkan pola yang natural.

## Struktur Node (Scene Tree)
```
TerrainGenerator (Node2D)
├── TileMap (TileMapLayer)
└── Camera2D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@export var map_size: Vector2i = Vector2i(64, 48)
@export var seed_value: int = 42
@export var frequency: float = 0.05
@export var octaves: int = 4
@export var lacunarity: float = 2.0
@export var gain: float = 0.5

var noise: FastNoiseLite
var tile_map: TileMapLayer

func _ready() -> void:
	tile_map = $TileMapLayer
	noise = FastNoiseLite.new()
	noise.seed = seed_value
	noise.noise_type = FastNoiseLite.TYPE_SIMPLEX_SMOOTH
	noise.frequency = frequency
	noise.fractal_octaves = octaves
	noise.fractal_lacunarity = lacunarity
	noise.fractal_gain = gain
	generate_terrain()

func generate_terrain() -> void:
	tile_map.clear()
	var moisture_noise: FastNoiseLite = FastNoiseLite.new()
	moisture_noise.seed = seed_value + 1000
	moisture_noise.noise_type = FastNoiseLite.TYPE_SIMPLEX_SMOOTH
	moisture_noise.frequency = 0.03
	for x in range(map_size.x):
		for y in range(map_size.y):
			var elevation: float = noise.get_noise_2d(float(x), float(y))
			var moisture: float = moisture_noise.get_noise_2d(float(x), float(y))
			var tile: Vector2i = get_tile_for_biome(elevation, moisture)
			tile_map.set_cell(Vector2i(x, y), 0, tile)

func get_tile_for_biome(elevation: float, moisture: float) -> Vector2i:
	if elevation < -0.3:
		return Vector2i(0, 0)
	elif elevation < -0.1:
		return Vector2i(1, 0)
	elif elevation < 0.2:
		if moisture > 0.1:
			return Vector2i(2, 0)
		else:
			return Vector2i(3, 0)
	elif elevation < 0.5:
		if moisture > 0.2:
			return Vector2i(4, 0)
		elif moisture < -0.2:
			return Vector2i(5, 0)
		else:
			return Vector2i(6, 0)
	else:
		if elevation > 0.7:
			return Vector2i(7, 0)
		else:
			return Vector2i(8, 0)

func _input(event: InputEvent) -> void:
	if event.is_action_pressed("ui_accept"):
		seed_value = randi()
		noise.seed = seed_value
		generate_terrain()
```

## Kasus Penggunaan Nyata
FastNoiseLite digunakan dalam game Minecraft untuk menghasilkan terrain alami dengan kombinasi elevation dan moisture maps. Game simulasi seperti Cities: Skylines menggunakan noise function untuk membuat bentuk lahan yang realistis dan menentukan zona perumahan, industri, dan komersial secara otomatis.
