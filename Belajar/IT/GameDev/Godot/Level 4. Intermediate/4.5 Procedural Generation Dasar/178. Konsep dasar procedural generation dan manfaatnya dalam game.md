# 178. Konsep dasar procedural generation dan manfaatnya dalam game

## Definisi Singkat
Procedural generation adalah teknik membuat konten game secara otomatis menggunakan algoritma dan aturan yang telah ditentukan, bukan dibuat secara manual oleh desainer.

## Analogi
Bayangkan kamu memiliki mesin pembuat kue yang bisa menghasilkan ratusan kue dengan berbagai rasa dan bentuk hanya dengan mengubah beberapa bahan dasar. Kamu tidak perlu membuat setiap kue satu per satu secara manual.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── TileMap (TileMapLayer)
├── Camera2D
└── UI (CanvasLayer)
    └── Label (menampilkan info seed)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@export var seed_value: int = 0
@export var map_width: int = 40
@export var map_height: int = 30
@export var wall_tile: Vector2i = Vector2i(0, 0)
@export var floor_tile: Vector2i = Vector2i(1, 0)

var noise: FastNoiseLite
var tile_map: TileMapLayer

func _ready() -> void:
	tile_map = $TileMapLayer
	noise = FastNoiseLite.new()
	noise.seed = seed_value
	noise.noise_type = FastNoiseLite.TYPE_SIMPLEX_SMOOTH
	noise.frequency = 0.08
	generate_map()

func generate_map() -> void:
	tile_map.clear()
	for x in range(map_width):
		for y in range(map_height):
			var noise_val: float = noise.get_noise_2d(float(x), float(y))
			if noise_val > 0.1:
				tile_map.set_cell(Vector2i(x, y), 0, floor_tile)
			else:
				tile_map.set_cell(Vector2i(x, y), 0, wall_tile)

func _input(event: InputEvent) -> void:
	if event.is_action_pressed("ui_accept"):
		seed_value = randi()
		noise.seed = seed_value
		generate_map()
```

## Kasus Penggunaan Nyata
Procedural generation digunakan dalam game seperti Minecraft untuk membuat dunia yang luas dan unik di setiap playthrough. Game roguelike seperti Spelunky menggunakan teknik ini untuk membuat level yang berbeda setiap kali pemain memulai petualangan baru, meningkatkan replayability secara signifikan.
