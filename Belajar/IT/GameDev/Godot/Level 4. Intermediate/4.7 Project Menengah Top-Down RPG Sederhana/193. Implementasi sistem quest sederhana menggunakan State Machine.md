# 193. Implementasi Sistem Quest Sederhana menggunakan State Machine

## Definisi Singkat
Sistem quest adalah mekanisme yang mengelola misi atau tugas yang harus diselesaikan pemain. Menggunakan State Machine memungkinkan quest memiliki状态 (states) berbeda seperti inactive, active, completed, dan failed dengan transisi yang terorganisir.

## Analogi
Bayangkan quest seperti resep masakan yang memiliki langkah-langkah. Setiap langkah memiliki kondisi tertentu sebelum bisa dilanjutkan ke langkah berikutnya. State Machine memastikan langkah diikuti secara urut dan tidak bisa dilompati.

## Struktur Node (Scene Tree)
```
QuestManager (Node)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node

class_name QuestState

enum State { INACTIVE, ACTIVE, COMPLETED, FAILED }

var quest_id: String
var quest_name: String
var description: String
var objectives: Array[Dictionary]
var rewards: Dictionary
var current_state: State = State.INACTIVE

signal state_changed(quest_id: String, old_state: State, new_state: State)
signal objective_updated(quest_id: String, objective_index: int, current: int, required: int)

func _init(id: String, name: String, desc: String, objs: Array[Dictionary], rews: Dictionary) -> void:
	quest_id = id
	quest_name = name
	description = desc
	objectives = objs.duplicate(true)
	rewards = rews

func activate() -> bool:
	if current_state == State.INACTIVE:
		var old_state = current_state
		current_state = State.ACTIVE
		state_changed.emit(quest_id, old_state, current_state)
		return true
	return false

func complete() -> bool:
	if current_state == State.ACTIVE and all_objectives_met():
		var old_state = current_state
		current_state = State.COMPLETED
		state_changed.emit(quest_id, old_state, current_state)
		return true
	return false

func fail() -> bool:
	if current_state == State.ACTIVE:
		var old_state = current_state
		current_state = State.FAILED
		state_changed.emit(quest_id, old_state, current_state)
		return true
	return false

func update_objective(index: int, amount: int = 1) -> void:
	if index >= 0 and index < objectives.size():
		var obj = objectives[index]
		obj["current"] = mini(obj["current"] + amount, obj["required"])
		objective_updated.emit(quest_id, index, obj["current"], obj["required"])

func all_objectives_met() -> bool:
	for obj in objectives:
		if obj["current"] < obj["required"]:
			return false
	return true

func get_progress() -> float:
	var total_required: int = 0
	var total_current: int = 0
	for obj in objectives:
		total_required += obj["required"]
		total_current += obj["current"]
	if total_required == 0:
		return 1.0
	return float(total_current) / float(total_required)
```

## Kasus Penggunaan Nyata
Sistem quest seperti ini digunakan di game "The Witcher 3" di mana setiap quest memiliki multiple objectives yang harus diselesaikan. Quest "Bloody Baron" memiliki berbagai tahap dengan kondisi berbeda yang harus dipenuhi pemain. State Machine memastikan quest berjalan secara terstruktur dan pemain tahu harus berbuat apa selanjutnya.
