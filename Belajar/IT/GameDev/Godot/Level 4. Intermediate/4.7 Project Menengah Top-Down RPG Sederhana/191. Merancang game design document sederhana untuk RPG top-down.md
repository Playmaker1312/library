# 191. Merancang Game Design Document Sederhana untuk RPG Top-Down

## Definisi Singkat
Game Design Document (GDD) adalah dokumen perencanaan yang mendeskripsikan konsep, mekanik, alur cerita, dan elemen gameplay dari sebuah game. Untuk RPG top-down sederhana, GDD berfungsi sebagai panduan agar pengembangan tetap terarah dan konsisten.

## Analogi
Membuat GDD seperti menyusun resep masakan sebelum mulai memasak. Tanpa resep, masakan bisa berantakan dan hasilnya tidak sesuai harapan. Dengan resep yang jelas, setiap langkah bisa diikuti dan hasilnya mudah diprediksi.

## Struktur Node (Scene Tree)
```
Game (Root - Node)
├── GameManager (Node) → Mengelola state global game
├── World (Node2D)
│   ├── Player (CharacterBody2D)
│   ├── NPCs (Node2D)
│   ├── Enemies (Node2D)
│   └── Items (Node2D)
├── UI (CanvasLayer)
│   ├── HUD (Control)
│   ├── Inventory (Control)
│   └── DialogBox (Control)
└── AudioManager (Node) → Mengelola musik dan sound effect
```

## Kode GDScript (Godot 4)

```gdscript
extends Node

class_name GameManager

enum GameState { MAIN_MENU, PLAYING, PAUSED, DIALOG, INVENTORY, GAME_OVER }

var current_state: GameState = GameState.MAIN_MENU
var player_data: Dictionary = {
	"max_health": 100,
	"health": 100,
	"attack": 10,
	"defense": 5,
	"speed": 150.0,
	"gold": 0,
	"level": 1,
	"experience": 0
}

var quest_log: Array[Dictionary] = []
var inventory: Array[Dictionary] = []

signal state_changed(new_state: GameState)
signal player_data_changed(data: Dictionary)

func change_state(new_state: GameState) -> void:
	current_state = new_state
	state_changed.emit(new_state)

func update_player_data(key: String, value: Variant) -> void:
	player_data[key] = value
	player_data_changed.emit(player_data)

func add_experience(amount: int) -> void:
	player_data["experience"] += amount
	var exp_needed: int = player_data["level"] * 100
	if player_data["experience"] >= exp_needed:
		player_data["experience"] -= exp_needed
		player_data["level"] += 1
		player_data["max_health"] += 10
		player_data["health"] = player_data["max_health"]
		player_data["attack"] += 2
		player_data["defense"] += 1
	player_data_changed.emit(player_data)

func add_quest(quest: Dictionary) -> void:
	quest_log.append(quest)

func complete_quest(quest_id: String) -> void:
	for i in range(quest_log.size()):
		if quest_log[i]["id"] == quest_id:
			quest_log[i]["status"] = "completed"
			break

func add_item(item: Dictionary) -> void:
	inventory.append(item)

func remove_item(item_id: String) -> bool:
	for i in range(inventory.size()):
		if inventory[i]["id"] == item_id:
			inventory.remove_at(i)
			return true
	return false

func has_item(item_id: String) -> bool:
	for item in inventory:
		if item["id"] == item_id:
			return true
	return false
```

## Kasus Penggunaan Nyata
GDD sangat penting saat mengembangkan RPG seperti "Stardew Valley" atau "Harvest Moon" di mana banyak sistem saling berinteraksi. Dengan GDD, developer bisa merencanakan sistem pertanian, pertarungan, dan interaksi NPC secara terstruktur. GDD juga membantu saat bekerja dalam tim agar semua anggota memiliki pemahaman yang sama tentang arah game.
