# 194. Membuat NPC dengan Dialog System dan Quest Trigger

## Definisi Singkat
NPC (Non-Player Character) adalah karakter yang dikendalikan oleh sistem game, bukan pemain. Dialog system mengelola percakapan antara pemain dan NPC, sedangkan quest trigger adalah area yang memicu quest tertentu saat pemain mendekatinya.

## Analogi
Bayangkan NPC seperti pemandu wisata yang bisa berbicara dengan pengunjung. Dialog system adalah skrip percakapan yang harus diikuti, dan quest trigger seperti papan informasi yang memberikan tugas saat pengunjung melewatinya.

## Struktur Node (Scene Tree)
```
NPC (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
├── InteractionArea (Area2D)
│   └── CollisionShape2D
├── DialogSystem (Node)
├── QuestTrigger (Area2D)
│   └── CollisionShape2D
└── AnimationPlayer
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

class_name NPC

@export var npc_name: String = "Villager"
@export var dialog_lines: Array[String] = []
@export var has_quest: bool = false
@export var quest_id: String = ""
@export var quest_objective_index: int = 0

var is_interacting: bool = false
var current_dialog_index: int = 0

signal dialog_started(npc_name: String)
signal dialog_ended(npc_name: String)
signal dialog_line_spoken(npc_name: String, line: String)
signal quest_offered(quest_id: String)

func _ready() -> void:
	$InteractionArea.body_entered.connect(_on_interaction_area_body_entered)
	$InteractionArea.body_exited.connect(_on_interaction_area_body_exited)
	if has_quest:
		$QuestTrigger.body_entered.connect(_on_quest_trigger_body_entered)

func start_dialog() -> void:
	if dialog_lines.is_empty():
		return
	is_interacting = true
	current_dialog_index = 0
	dialog_started.emit(npc_name)
	_show_next_line()

func _show_next_line() -> void:
	if current_dialog_index < dialog_lines.size():
		var line: String = dialog_lines[current_dialog_index]
		dialog_line_spoken.emit(npc_name, line)
		current_dialog_index += 1
	else:
		end_dialog()

func advance_dialog() -> void:
	_show_next_line()

func end_dialog() -> void:
	is_interacting = false
	current_dialog_index = 0
	dialog_ended.emit(npc_name)
	if has_quest and current_dialog_index >= dialog_lines.size():
		quest_offered.emit(quest_id)

func _on_interaction_area_body_entered(body: Node2D) -> void:
	if body is Player:
		start_dialog()

func _on_interaction_area_body_exited(body: Node2D) -> void:
	if body is Player and is_interacting:
		end_dialog()

func _on_quest_trigger_body_entered(body: Node2D) -> void:
	if body is Player and has_quest:
		var quest_data: Dictionary = {
			"id": quest_id,
			"name": npc_name + " Quest",
			"description": "Complete the task for " + npc_name,
			"objectives": [{"type": "interact", "target": npc_name, "current": 0, "required": 1}],
			"rewards": {"experience": 50, "gold": 25}
		}
		GameManager.add_quest(quest_data)
```

## Kasus Penggunaan Nyata
NPC dengan dialog system seperti ini digunakan di game "Stardew Valley" di mana setiap desa memiliki NPC unik dengan percakapan berbeda. Di "The Legend of Zelda: Ocarina of Time", NPC seperti Saria memberikan quest dan dialog yang memandu pemain melalui cerita utama. Quest trigger memungkinkan game memulai misi secara otomatis saat pemain mencapai lokasi tertentu.
