# 192. Membuat Sistem Karakter dengan Stats seperti Health, Attack, Defense, dan Speed

## Definisi Singkat
Sistem karakter RPG adalah komponen yang mengelola atribut dasar seperti health (kesehatan), attack (serangan), defense (pertahanan), dan speed (kecepatan). Setiap stat mempengaruhi cara karakter berinteraksi dengan dunia game dan menentukan keseimbangan gameplay.

## Analogi
Bayangkan karakter seperti karakter di game Mobile Legends. Health adalah nyawa, attack adalah damage yang diberikan, defense adalah ketahanan terhadap serangan, dan speed adalah seberapa cepat karakter bergerak. Semua stat ini bekerja sama untuk menentukan seberapa kuat karakter di medan pertempuran.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
├── AnimationPlayer
├── AnimationTree
├── HurtBox (Area2D)
│   └── CollisionShape2D
├── HitBox (Area2D)
│   └── CollisionShape2D
└── Stats (Node) → Script CharacterStats
```

## Kode GDScript (Godot 4)

```gdscript
extends Node

class_name CharacterStats

signal health_changed(current_health: int, max_health: int)
signal died
signal stats_changed

@export var max_health: int = 100
@export var attack: int = 10
@export var defense: int = 5
@export var speed: float = 150.0
@export var critical_chance: float = 0.1
@export var critical_multiplier: float = 1.5

var current_health: int
var is_alive: bool = true

func _ready() -> void:
	current_health = max_health

func take_damage(damage: int) -> int:
	var actual_damage: int = maxi(damage - defense, 1)
	current_health = maxi(current_health - actual_damage, 0)
	health_changed.emit(current_health, max_health)
	if current_health <= 0:
		is_alive = false
		died.emit()
	return actual_damage

func heal(amount: int) -> void:
	current_health = mini(current_health + amount, max_health)
	health_changed.emit(current_health, max_health)

func calculate_damage() -> int:
	var base_damage: int = attack
	var is_critical: bool = randf() < critical_chance
	if is_critical:
		base_damage = int(base_damage * critical_multiplier)
	return base_damage

func increase_stat(stat_name: String, amount: Variant) -> void:
	match stat_name:
		"max_health":
			max_health += amount
			current_health = maxi(current_health, max_health)
		"attack":
			attack += amount
		"defense":
			defense += amount
		"speed":
			speed += amount
		"critical_chance":
			critical_chance = minf(critical_chance + amount, 1.0)
	stats_changed.emit()

func reset_stats() -> void:
	current_health = max_health
	is_alive = true
	health_changed.emit(current_health, max_health)

func get_stat_summary() -> Dictionary:
	return {
		"health": str(current_health) + "/" + str(max_health),
		"attack": attack,
		"defense": defense,
		"speed": speed,
		"critical_chance": int(critical_chance * 100) + "%"
	}
```

## Kasus Penggunaan Nyata
Sistem stats seperti ini digunakan di hampir semua RPG populer seperti "Final Fantasy" atau "Dragon Quest". Di "Final Fantasy VII", Cloud memiliki stats yang berbeda dari Tifa atau Barrett, sehingga setiap karakter memiliki gaya bermain unik. Sistem stats juga penting dalam game seperti "Diablo" di mana pemain bisa menyesuaikan build karakter berdasarkan stat yang diinginkan.
