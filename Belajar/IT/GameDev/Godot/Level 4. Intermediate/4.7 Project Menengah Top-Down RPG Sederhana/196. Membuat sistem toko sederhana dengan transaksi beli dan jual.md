# 196. Membuat Sistem Toko Sederhana dengan Transaksi Beli dan Jual

## Definisi Singkat
Sistem toko adalah mekanisme yang memungkinkan pemain membeli dan menjual item menggunakan mata uang dalam game. Sistem ini harus menangani inventaris, harga, dan validasi transaksi dengan benar.

## Analogi
Bayangkan seperti toko kelontong di mana kamu bisa membeli barang dengan uang dan menjual barang yang tidak kamu butuhkan. Toko memiliki daftar barang (catalog), stok barang, dan sistem pembayaran yang harus dicatat dengan benar.

## Struktur Node (Scene Tree)
```
Shop (Node2D)
├── Sprite2D
├── InteractionArea (Area2D)
│   └── CollisionShape2D
├── Shopkeeper (CharacterBody2D)
└── ShopUI (CanvasLayer)
    ├── Background (ColorRect)
    ├── ShopPanel (VBoxContainer)
    │   ├── ShopTitle (Label)
    │   ├── ItemList (ScrollContainer)
    │   │   └── ItemEntry (HBoxContainer)
    │   │       ├── ItemName (Label)
    │   │       ├── ItemPrice (Label)
    │   │       ├── BuyButton (Button)
    │   │       └── SellButton (Button)
    │   └── GoldDisplay (Label)
    └── CloseButton (Button)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

class_name Shop

@export var shop_name: String = "General Store"
@export var shop_items: Array[Dictionary] = []
@export var buy_multiplier: float = 1.0
@export var sell_multiplier: float = 0.5

var is_open: bool = false

signal item_bought(item: Dictionary)
signal item_sold(item: Dictionary)
signal shop_opened
signal shop_closed

func _ready() -> void:
	$InteractionArea.body_entered.connect(_on_interaction_area_body_entered)
	$InteractionArea.body_exited.connect(_on_interaction_area_body_exited)

func open_shop() -> void:
	if is_open:
		return
	is_open = true
	shop_opened.emit()
	_update_shop_ui()

func close_shop() -> void:
	if not is_open:
		return
	is_open = false
	shop_closed.emit()

func buy_item(item_index: int) -> bool:
	if item_index < 0 or item_index >= shop_items.size():
		return false
	var item: Dictionary = shop_items[item_index]
	var price: int = int(item["price"] * buy_multiplier)
	var player_gold: int = GameManager.player_data["gold"]
	if player_gold >= price:
		GameManager.update_player_data("gold", player_gold - price)
		var bought_item: Dictionary = item.duplicate()
		bought_item["quantity"] = 1
		GameManager.add_item(bought_item)
		item_bought.emit(item)
		_update_shop_ui()
		return true
	return false

func sell_item(item_id: String) -> bool:
	var player_inventory: Array = GameManager.inventory
	for i in range(player_inventory.size()):
		if player_inventory[i]["id"] == item_id:
			var item: Dictionary = player_inventory[i]
			var price: int = int(item["price"] * sell_multiplier)
			GameManager.update_player_data("gold", GameManager.player_data["gold"] + price)
			GameManager.remove_item(item_id)
			item_sold.emit(item)
			_update_shop_ui()
			return true
	return false

func get_item_price(item: Dictionary, is_buying: bool) -> int:
	if is_buying:
		return int(item["price"] * buy_multiplier)
	return int(item["price"] * sell_multiplier)

func _update_shop_ui() -> void:
	var gold_label: Label = $ShopUI/GoldDisplay
	gold_label.text = "Gold: " + str(GameManager.player_data["gold"])
	var item_list: ScrollContainer = $ShopUI/ShopPanel/ItemList
	for child in item_list.get_children():
		child.queue_free()
	for i in range(shop_items.size()):
		var item: Dictionary = shop_items[i]
		var entry: HBoxContainer = _create_item_entry(item, i)
		item_list.add_child(entry)

func _create_item_entry(item: Dictionary, index: int) -> HBoxContainer:
	var entry: HBoxContainer = HBoxContainer.new()
	var name_label: Label = Label.new()
	name_label.text = item["name"]
	entry.add_child(name_label)
	var price_label: Label = Label.new()
	price_label.text = str(get_item_price(item, true)) + "G"
	entry.add_child(price_label)
	var buy_button: Button = Button.new()
	buy_button.text = "Buy"
	buy_button.pressed.connect(func(): buy_item(index))
	entry.add_child(buy_button)
	return entry

func _on_interaction_area_body_entered(body: Node2D) -> void:
	if body is Player:
		open_shop()

func _on_interaction_area_body_exited(body: Node2D) -> void:
	if body is Player:
		close_shop()
```

## Kasus Penggunaan Nyata
Sistem toko seperti ini digunakan di hampir semua RPG seperti "Final Fantasy" atau "Dragon Quest". Di "Stardew Valley", toko Pierre menjual benih dan alat pertanian. Sistem toko yang baik harus memungkinkan pemain membandingkan harga, melihat stok, dan melakukan transaksi dengan mudah tanpa mengganggu alur gameplay.
