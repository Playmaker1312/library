# 195. Implementasi Overworld Map dengan Transisi Antar Zone

## Definisi Singkat
Overworld map adalah peta utama yang menghubungkan berbagai zone atau area dalam game. Transisi antar zone memungkinkan pemain berpindah dari satu lokasi ke lokasi lain dengan animasi atau efek visual yang mulus.

## Analogi
Bayangkan seperti peta kereta api yang menghubungkan berbagai kota. Setiap kota adalah zone berbeda, dan stasiun kereta adalah titik transisi yang mengantarmu dari satu kota ke kota lain.

## Struktur Node (Scene Tree)
```
Overworld (Node2D)
├── Zone_Village (Node2D)
│   ├── TileMap
│   ├── NPCs (Node2D)
│   ├── Transitions (Node2D)
│   │   ├── TransitionToForest (Area2D)
│   │   └── TransitionToDungeon (Area2D)
│   └── Player (CharacterBody2D)
├── Zone_Forest (Node2D)
│   ├── TileMap
│   ├── Enemies (Node2D)
│   └── Transitions (Node2D)
│       └── TransitionToVillage (Area2D)
└── TransitionManager (CanvasLayer)
    └── TransitionEffect (ColorRect)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

class_name ZoneTransition

@export var target_zone: String
@export var spawn_position: Vector2
@export var transition_type: String = "fade"

var is_transitioning: bool = false

signal transition_started
signal transition_finished

func _ready() -> void:
	area_entered.connect(_on_area_entered)

func _on_area_entered(area: Area2D) -> void:
	if area.get_parent() is Player and not is_transitioning:
		start_transition()

func start_transition() -> void:
	is_transitioning = true
	transition_started.emit()
	var transition_manager = get_tree().get_first_node_in_group("transition_manager")
	if transition_manager:
		transition_manager.play_transition(transition_type)
		await transition_manager.transition_midpoint
		get_tree().change_scene_to_file("res://scenes/zones/" + target_zone + ".tscn")
	transition_finished.emit()
	is_transitioning = false
```

## Kode GDScript (Godot 4) - Transition Manager

```gdscript
extends CanvasLayer

class_name TransitionManager

@onready var color_rect: ColorRect = $TransitionEffect

var is_active: bool = false

signal transition_midpoint

func play_transition(type: String = "fade", duration: float = 0.5) -> void:
	if is_active:
		return
	is_active = true
	color_rect.visible = true
	match type:
		"fade":
			await _fade_transition(duration)
		"slide_left":
			await _slide_transition(duration, Vector2.RIGHT, Vector2.LEFT)
		"slide_right":
			await _slide_transition(duration, Vector2.LEFT, Vector2.RIGHT)
		"dissolve":
			await _dissolve_transition(duration)
	is_active = false

func _fade_transition(duration: float) -> void:
	var tween: Tween = create_tween()
	color_rect.color = Color(0, 0, 0, 0)
	tween.tween_property(color_rect, "color:a", 1.0, duration / 2)
	await tween.finished
	transition_midpoint.emit()
	var tween2: Tween = create_tween()
	tween2.tween_property(color_rect, "color:a", 0.0, duration / 2)
	await tween2.finished
	color_rect.visible = false

func _slide_transition(duration: float, from: Vector2, to: Vector2) -> void:
	color_rect.position = from * get_viewport_rect().size
	color_rect.visible = true
	var tween: Tween = create_tween()
	tween.tween_property(color_rect, "position", Vector2.ZERO, duration / 2)
	await tween.finished
	transition_midpoint.emit()
	var tween2: Tween = create_tween()
	tween2.tween_property(color_rect, "position", to * get_viewport_rect().size, duration / 2)
	await tween2.finished
	color_rect.visible = false

func _dissolve_transition(duration: float) -> void:
	color_rect.material.set_shader_parameter("progress", 0.0)
	color_rect.visible = true
	var tween: Tween = create_tween()
	tween.tween_method(_update_dissolve, 0.0, 1.0, duration / 2)
	await tween.finished
	transition_midpoint.emit()
	var tween2: Tween = create_tween()
	tween2.tween_method(_update_dissolve, 1.0, 0.0, duration / 2)
	await tween2.finished
	color_rect.visible = false

func _update_dissolve(value: float) -> void:
	if color_rect.material:
		color_rect.material.set_shader_parameter("progress", value)
```

## Kasus Penggunaan Nyata
Sistem transisi zone seperti ini digunakan di game "The Legend of Zelda" di mana pemain berpindah dari desa ke hutan atau dungeon. Di "Hollow Knight", transisi antar area menggunakan efek fade yang mulus. Transisi yang baik memberikan pengalaman visual yang konsisten dan membantu pemain memahami bahwa mereka telah berpindah ke lokasi baru.
