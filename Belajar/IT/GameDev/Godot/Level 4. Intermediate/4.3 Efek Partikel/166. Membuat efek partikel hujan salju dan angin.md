# 166. Membuat efek partikel hujan salju dan angin

## Definisi Singkat
Efek hujan, salju, dan angin adalah partikel kontinu yang jatuh atau bergerak dalam pola tertentu dari area di luar layar, menciptakan suasana lingkungan yang dinamis dan imersif.

## Analogi
Seperti melihat hujan dari balik jendela — tetesan datang dari atas secara konstan, jatuh ke bawah dengan sedikit variasi kecepatan, dan menghilang saat menyentuh tanah. Salju serupa tapi lebih lambat dan bergerak melayang.

## Struktur Node (Scene Tree)
```
Node2D (Root: WeatherSystem)
├── GPUParticles2D (named "Rain")
│   └── ParticleProcessMaterial
├── GPUParticles2D (named "Wind")
│   └── ParticleProcessMaterial
└── CPUParticles2D (named "Snow")
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var rain: GPUParticles2D = $Rain
@onready var snow: CPUParticles2D = $Snow
@onready var wind: GPUParticles2D = $Wind

var screen_size: Vector2

func _ready():
	screen_size = get_viewport_rect().size
	
	_setup_rain()
	_setup_snow()
	_setup_wind()

func _process(_delta: float):
	rain.position = Vector2(screen_size.x / 2, -20)
	snow.position = Vector2(screen_size.x / 2, -20)
	rain.process_material.emission_box_extents = Vector3(screen_size.x / 2, 0, 0)
	snow.emission_shape = CPUParticles2D.EMISSION_SHAPE_BOX
	snow.emission_box_extents = Vector2(screen_size.x / 2, 0)

func _setup_rain():
	rain.amount = 300
	rain.lifetime = 1.5
	rain.emitting = true
	var mat: ParticleProcessMaterial = rain.process_material
	mat.direction = Vector3(0, 1, 0)
	mat.spread = 5.0
	mat.initial_velocity_min = 400.0
	mat.initial_velocity_max = 600.0
	mat.gravity = Vector3(0, 200, 0)
	mat.scale_min = 0.3
	mat.scale_max = 0.6
	mat.color = Color(0.6, 0.8, 1.0, 0.7)

func _setup_snow():
	snow.amount = 100
	snow.lifetime = 4.0
	snow.emitting = true
	snow.direction = Vector2(0, 1)
	snow.spread = 30.0
	snow.initial_velocity_min = 30.0
	snow.initial_velocity_max = 80.0
	snow.gravity = Vector2(20, 50)
	snow.scale_amount_min = 0.5
	snow.scale_amount_max = 1.5
	snow.color = Color(1.0, 1.0, 1.0, 0.8)

func _setup_wind():
	wind.amount = 20
	wind.lifetime = 2.0
	wind.emitting = true
	wind.position = Vector2(-50, screen_size.y / 2)
	var mat: ParticleProcessMaterial = wind.process_material
	mat.direction = Vector3(1, 0, 0)
	mat.spread = 10.0
	mat.initial_velocity_min = 150.0
	mat.initial_velocity_max = 250.0
	mat.scale_min = 1.0
	mat.scale_max = 3.0
	mat.color = Color(1, 1, 1, 0.15)
```

## Kasus Penggunaan Nyata
Efek ini digunakan untuk membangun atmosfer di game RPG atau petualangan, seperti hujan di area hutan gelap, salju di pegunungan, atau angin berdebu di padang pasir. Elemen cuaca membantu pemain merasakan kondisi lingkungan secara visual tanpa perlu dialog atau teks.
