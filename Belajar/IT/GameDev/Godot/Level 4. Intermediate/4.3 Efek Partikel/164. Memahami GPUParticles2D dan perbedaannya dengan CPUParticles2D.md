# 164. Memahami GPUParticles2D dan perbedaannya dengan CPUParticles2D

## Definisi Singkat
GPUParticles2D adalah node partikel yang menggunakan GPU untuk menghitung dan merender ribuan partikel secara simultan, sangat efisien untuk efek visual kompleks. CPUParticles2D adalah alternatif yang mengandalkan CPU, cocok untuk partikel dalam jumlah kecil atau jika GPU tidak tersedia.

## Analogi
GPUParticles2D seperti ribuan penonton di stadion yang semuanya menyalakan lampu ponsel secara bersamaan — GPU mengatur semuanya sekaligus dalam satu frame. CPUParticles2D seperti seorang pemandu sorak yang mengkoordinasi satu per satu gerakan penonton — lebih lambat tapi lebih mudah dikontrol secara individual.

## Struktur Node (Scene Tree)
```
Node2D (Root)
├── GPUParticles2D
│   └── ParticleProcessMaterial
└── CPUParticles2D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var gpu_particles: GPUParticles2D = $GPUParticles2D
@onready var cpu_particles: CPUParticles2D = $CPUParticles2D

func _ready():
	gpu_particles.amount = 512
	gpu_particles.lifetime = 2.0
	gpu_particles.emitting = true
	
	cpu_particles.amount = 32
	cpu_particles.lifetime = 2.0
	cpu_particles.emitting = true

func _input(event):
	if event.is_action_pressed("ui_accept"):
		gpu_particles.restart()
		cpu_particles.restart()
```

## Kasus Penggunaan Nyata
GPUParticles2D digunakan untuk efek yang membutuhkan banyak partikel seperti ledakan besar, hujan, atau asap tebal di game action. CPUParticles2D lebih cocok untuk efek sederhana seperti percikan api kecil atau debu saat karakter berjalan, terutama saat target platform adalah perangkat mobile dengan GPU terbatas.
