# 168. Mengontrol emisi partikel dari GDScript secara dinamis

## Definisi Singkat
Kontrol dinamis partikel dari GDScript berarti mengubah properti emisi seperti jumlah partikel, warna, ukuran, kecepatan, dan status emitting secara real-time berdasarkan logika game.

## Analogi
Seperti mengontrol lampu panggung dari backstage — kamu bisa mengubah warna, intensitas, dan arah lampu sesuai adegan yang sedang berlangsung tanpa harus mengganti perangkat lampunya.

## Struktur Node (Scene Tree)
```
Node2D (Root: DynamicParticleController)
├── GPUParticles2D (named "DynamicParticle")
│   └── ParticleProcessMaterial
└── CanvasModulate
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var particles: GPUParticles2D = $DynamicParticle

var base_color: Color = Color(1.0, 0.5, 0.2)
var health_percent: float = 1.0

func _ready():
	particles.amount = 128
	particles.lifetime = 1.0
	particles.emitting = true
	_update_particle_color()

func set_health(percent: float):
	health_percent = clampf(percent, 0.0, 1.0)
	_update_particle_color()
	particles.amount = int(lerp(16.0, 128.0, health_percent))
	particles.process_material.initial_velocity_min = lerp(50.0, 200.0, health_percent)
	particles.process_material.initial_velocity_max = lerp(100.0, 400.0, health_percent)

func _update_particle_color():
	var low_color: Color = Color(1.0, 0.1, 0.1)
	var high_color: Color = Color(0.2, 1.0, 0.3)
	particles.process_material.color = low_color.lerp(high_color, health_percent)

func burst(count: int, position: Vector2):
	particles.amount = count
	particles.global_position = position
	particles.restart()
	particles.emitting = true

func set_emission_shape(circle_radius: float):
	particles.process_material.emission_shape = ParticleProcessMaterial.EMISSION_SHAPE_SPHERE
	particles.process_material.emission_sphere_radius = circle_radius

func toggle_particles():
	particles.emitting = not particles.emitting

func change_particle_texture(texture: Texture2D):
	particles.texture = texture
```

## Kasus Penggunaan Nyata
Kontrol dinamis digunakan untuk menyesuaikan efek partikel dengan kondisi game, seperti mengubah warna api dari oranye ke merah saat HP karakter rendah, meledakkan partikel saat musuh mati, atau mengubah ukuran percikan saat senjata ditingkatkan. Ini memungkinkan respons visual yang kontekstual dan interaktif.
