# 165. Membuat efek partikel ledakan menggunakan GPUParticles2D

## Definisi Singkat
Efek partikel ledakan adalah pelepasan partikel secara instan dari satu titik ke segala arah dengan kecepatan dan warna bervariasi untuk mensimulasikan serpihan, percikan, atau gelombang kejut.

## Analogi
Seperti meledakkan balon berisi confetti — semua isi keluar sekaligus, berterbangan ke berbagai arah dengan kecepatan berbeda, lalu perlahan menghilang seiring waktu.

## Struktur Node (Scene Tree)
```
Node2D (Root: ExplosionEffect)
├── GPUParticles2D (named "Explosion")
│   └── ParticleProcessMaterial
└── Timer (named "AutoFree")
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var explosion: GPUParticles2D = $Explosion
@onready var auto_free: Timer = $AutoFree

func _ready():
	explosion.one_shot = true
	explosion.emitting = false
	explosion.amount = 256
	explosion.lifetime = 1.5
	
	var material: ParticleProcessMaterial = explosion.process_material
	material.direction = Vector3(0, 0, 0)
	material.spread = 180.0
	material.initial_velocity_min = 200.0
	material.initial_velocity_max = 500.0
	material.gravity = Vector3(0, 400, 0)
	material.scale_min = 0.5
	material.scale_max = 2.0
	material.color = Color(1.0, 0.6, 0.1)
	
	auto_free.wait_time = 2.0
	auto_free.one_shot = true
	auto_free.timeout.connect(queue_free)
	auto_free.start()

func trigger_explosion():
	explosion.emitting = true
	explosion.restart()
	auto_free.start()
```

## Kasus Penggunaan Nyata
Efek ini digunakan saat musuh hancur, granat meledak, atau kotak pecah di game platformer. Partikel serpihan dan percikan memberikan feedback visual yang memuaskan kepada pemain tentang dampak serangan yang baru saja terjadi.
