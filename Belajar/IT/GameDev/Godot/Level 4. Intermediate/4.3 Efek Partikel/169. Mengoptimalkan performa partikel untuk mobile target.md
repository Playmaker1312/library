# 169. Mengoptimalkan performa partikel untuk mobile target

## Definisi Singkat
Optimasi partikel untuk mobile adalah teknik mengurangi beban GPU dan CPU dengan menyesuaikan jumlah partikel, ukuran tekstur, dan kompleksitas shader agar tetap terlihat baik di perangkat dengan spesifikasi rendah.

## Analogi
Seperti menyesuaikan lampu di rumah hemat energi — kamu tetap mendapat pencahayaan yang cukup tapi dengan watt lebih rendah agar listrik tidak membengkak.

## Struktur Node (Scene Tree)
```
Node2D (Root: MobileOptimizedParticles)
├── GPUParticles2D (named "OptimizedFire")
│   └── ParticleProcessMaterial
├── GPUParticles2D (named "OptimizedSmoke")
│   └── ParticleProcessMaterial
└── Node (named "PerformanceMonitor")
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var fire: GPUParticles2D = $OptimizedFire
@onready var smoke: GPUParticles2D = $OptimizedSmoke
@onready var monitor: Node = $PerformanceMonitor

var is_mobile: bool = false
var quality_level: int = 2

func _ready():
	is_mobile = OS.get_name() == "Android" or OS.get_name() == "iOS"
	if is_mobile:
		quality_level = 1
	else:
		quality_level = 2
	_apply_quality_settings()

func _apply_quality_settings():
	match quality_level:
		0:
			fire.amount = 16
			fire.lifetime = 0.5
			fire.explosiveness = 0.9
			smoke.amount = 8
			smoke.lifetime = 0.8
			fire.process_material.scale_min = 0.5
			fire.process_material.scale_max = 0.8
		1:
			fire.amount = 32
			fire.lifetime = 0.8
			fire.explosiveness = 0.7
			smoke.amount = 16
			smoke.lifetime = 1.2
			fire.process_material.scale_min = 0.8
			fire.process_material.scale_max = 1.2
		2:
			fire.amount = 64
			fire.lifetime = 1.0
			fire.explosiveness = 0.5
			smoke.amount = 32
			smoke.lifetime = 1.5
			fire.process_material.scale_min = 1.0
			fire.process_material.scale_max = 1.5

func set_quality(level: int):
	quality_level = clampi(level, 0, 2)
	_apply_quality_settings()

func get_fps() -> int:
	return Engine.get_frames_per_second()

func _process(_delta: float):
	if is_mobile and get_fps() < 30:
		quality_level = maxi(quality_level - 1, 0)
		_apply_quality_settings()

func create_optimized_explosion(pos: Vector2, size: int):
	var explosion: GPUParticles2D = GPUParticles2D.new()
	explosion.one_shot = true
	explosion.emitting = false
	explosion.position = pos
	explosion.amount = mini(size, 128 if not is_mobile else 32)
	explosion.lifetime = 1.0
	var mat: ParticleProcessMaterial = ParticleProcessMaterial.new()
	mat.spread = 180.0
	mat.initial_velocity_min = 150.0
	mat.initial_velocity_max = 350.0
	mat.gravity = Vector3(0, 300, 0)
	explosion.process_material = mat
	add_child(explosion)
	explosion.emitting = true
	await get_tree().create_timer(explosion.lifetime + 0.1).timeout
	explosion.queue_free()
```

## Kasus Penggunaan Nyata
Optimasi ini krusial saat game harus berjalan lancar di Android atau iOS. Dengan mengurangi jumlah partikel secara adaptif berdasarkan FPS, game tetap menampilkan efek visual yang menarik tanpa menyebabkan lag atau overheating pada perangkat mobile.
