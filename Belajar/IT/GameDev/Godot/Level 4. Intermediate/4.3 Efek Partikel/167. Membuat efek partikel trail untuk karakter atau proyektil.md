# 167. Membuat efek partikel trail untuk karakter atau proyektil

## Definisi Singkat
Trail adalah efek partikel yang mengikuti pergerakan objek secara real-time, menciptakan jejak visual seperti asap, api, atau cahaya yang tertinggal di belakang objek yang bergerak.

## Analogi
Seperti jejak cahaya yang tertinggal saat kamu mengayunkan tongkat di tempat gelap — setiap posisi baru meninggalkan bekas yang perlahan memudar seiring waktu.

## Struktur Node (Scene Tree)
```
CharacterBody2D (Root: Player)
├── Sprite2D
├── CollisionShape2D
├── GPUParticles2D (named "Trail")
│   └── ParticleProcessMaterial
└── AnimationPlayer
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var trail: GPUParticles2D = $Trail

var speed: float = 300.0
var trail_active: bool = false

func _ready():
	trail.emitting = false
	trail.one_shot = false
	trail.amount = 64
	trail.lifetime = 0.8
	var mat: ParticleProcessMaterial = trail.process_material
	mat.direction = Vector3(0, 0, 0)
	mat.spread = 0.0
	mat.initial_velocity_min = 0.0
	mat.initial_velocity_max = 0.0
	mat.gravity = Vector3(0, -50, 0)
	mat.scale_min = 0.5
	mat.scale_max = 1.0
	mat.color = Color(0.3, 0.5, 1.0)
	trail.local_coords = false

func _physics_process(_delta: float):
	var input_dir: Vector2 = Vector2.ZERO
	input_dir.x = Input.get_axis("ui_left", "ui_right")
	input_dir.y = Input.get_axis("ui_up", "ui_down")
	input_dir = input_dir.normalized()
	
	velocity = input_dir * speed
	move_and_slide()
	
	if input_dir.length() > 0.1:
		if not trail_active:
			trail.emitting = true
			trail_active = true
		trail.process_material.direction = Vector3(-input_dir.x, -input_dir.y, 0)
		rotation = input_dir.angle()
	else:
		if trail_active:
			trail.emitting = false
			trail_active = false

func shoot_bullet(bullet_scene: PackedScene):
	var bullet = bullet_scene.instantiate()
	bullet.position = global_position
	bullet.rotation = rotation
	get_tree().current_scene.add_child(bullet)
	var bullet_trail: GPUParticles2D = bullet.get_node_or_null("Trail")
	if bullet_trail:
		bullet_trail.emitting = true
```

## Kasus Penggunaan Nyata
Efek trail digunakan untuk jejak pedang saat karakter menyerang, asap di belakang roket atau proyektil, dan cahaya pada karakter yang berlari cepat. Trail memberikan kesan kecepatan dan dinamika gerakan yang memperkuat feedback visual dalam aksi game.
