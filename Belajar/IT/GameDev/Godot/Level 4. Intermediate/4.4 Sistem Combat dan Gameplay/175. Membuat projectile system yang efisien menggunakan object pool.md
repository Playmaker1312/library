# 175. Membuat projectile system yang efisien menggunakan object pool

## Definisi Singkat
Projectile system menggunakan object pool untuk mengelola objek peluru yang sering dibuat dan dihancurkan. Object pool menyimpan objek yang tidak digunakan dan mendaur ulangnya, mengurangi beban memori dan performa dari pembuatan objek berulang kali.

## Analogi
Seperti kolam renang dengan jumlah pelampung tetap. Ketika ada yang mengambil pelampung (menggunakan projectile), pelampung yang sudah tidak dipakai dikembalikan ke kolam (didaur ulang) daripada dibuat baru.

## Struktur Node (Scene Tree)
```
ProjectilePool (Node2D)
├── ProjectilePool (Node)
│   ├── Projectile_0
│   ├── Projectile_1
│   └── Projectile_2
└── ActiveProjectiles (Node2D)
```

## Kode GDScript (Godot 4)

**projectile.gd:**
```gdscript
extends Area2D

@export var speed: float = 500.0
@export var damage: int = 25
@export var lifetime: float = 3.0

var direction: Vector2 = Vector2.RIGHT
var velocity: Vector2 = Vector2.ZERO
var is_active: bool = false
var pool_manager: Node = null

func _ready() -> void:
    body_entered.connect(_on_body_entered)

func setup(start_pos: Vector2, dir: Vector2, pool: Node) -> void:
    global_position = start_pos
    direction = dir.normalized()
    velocity = direction * speed
    is_active = true
    pool_manager = pool
    rotation = direction.angle()
    show()

func _physics_process(delta: float) -> void:
    if is_active:
        position += velocity * delta
        lifetime -= delta
        if lifetime <= 0:
            deactivate()

func deactivate() -> void:
    is_active = false
    hide()
    if pool_manager:
        pool_manager.return_to_pool(self)

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("enemy") and is_active:
        body.take_damage(damage)
        deactivate()
```

**projectile_pool.gd:**
```gdscript
extends Node2D

const MAX_POOL_SIZE: int = 20
var pool: Array[Area2D] = []
var active_projectiles: Node2D

var projectile_scene: PackedScene = preload("res://scenes/projectile.tscn")

func _ready() -> void:
    active_projectiles = Node2D.new()
    active_projectiles.name = "ActiveProjectiles"
    add_child(active_projectiles)
    initialize_pool()

func initialize_pool() -> void:
    for i in range(MAX_POOL_SIZE):
        var projectile = projectile_scene.instantiate()
        projectile.hide()
        projectile.set_deferred("monitoring", false)
        add_child(projectile)
        pool.append(projectile)

func get_projectile() -> Area2D:
    if pool.size() > 0:
        var projectile = pool.pop_back()
        projectile.set_deferred("monitoring", true)
        return projectile
    return null

func spawn_projectile(start_pos: Vector2, direction: Vector2) -> void:
    var projectile = get_projectile()
    if projectile:
        projectile.setup(start_pos, direction, self)

func return_to_pool(projectile: Area2D) -> void:
    projectile.set_deferred("monitoring", false)
    pool.append(projectile)
```

**player.gd:**
```gdscript
extends CharacterBody2D

@onready var projectile_pool: Node2D = $ProjectilePool

func shoot() -> void:
    var direction = (get_global_mouse_position() - global_position).normalized()
    projectile_pool.spawn_projectile(global_position, direction)
```

## Kasus Penggunaan Nyata
Object pool digunakan di game seperti shmup (shoot 'em up) dan bullet hell seperti Touhou Project. Dengan ratusan peluru di layar, object pool memastikan performa tetap stabil tanpa lag akibat pembuatan dan penghancuran objek secara terus-menerus.
