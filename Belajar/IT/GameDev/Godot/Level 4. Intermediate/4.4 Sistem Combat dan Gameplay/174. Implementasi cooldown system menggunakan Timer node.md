# 174. Implementasi cooldown system menggunakan Timer node

## Definisi Singkat
Cooldown system adalah mekanisme yang membatasi penggunaan kemampuan atau serangan dalam interval waktu tertentu. Menggunakan Timer node untuk menghitung waktu tunggu sebelum kemampuan bisa digunakan kembali.

## Analogi
Seperti menunggu air mendidih. Setelah menekan tombol ketel, kita harus menunggu beberapa menit sebelum air benar-benar mendidih. Kita tidak bisa memaksa air mendidih lebih cepat, dan kita tidak bisa menggunakan air panas sebelum waktunya tiba.

## Struktur Node (Scene Tree)
```
Ability
├── CooldownTimer (Timer)
├── AnimationPlayer
└── CollisionShape2D
```

## Kode GDScript (Godot 4)

**cooldown_system.gd:**
```gdscript
class_name CooldownSystem
extends Node

signal cooldown_started(ability_name: String, duration: float)
signal cooldown_finished(ability_name: String)
signal cooldown_updated(ability_name: String, remaining: float)

@export var abilities: Dictionary = {}

var cooldown_timers: Dictionary = {}
var current_cooldowns: Dictionary = {}

func setup_ability(ability_name: String, cooldown_time: float, mana_cost: int = 0) -> void:
    abilities[ability_name] = {
        "cooldown": cooldown_time,
        "mana_cost": mana_cost
    }
    cooldown_timers[ability_name] = Timer.new()
    cooldown_timers[ability_name].one_shot = true
    cooldown_timers[ability_name].timeout.connect(_on_cooldown_finished.bind(ability_name))
    add_child(cooldown_timers[ability_name])

func can_use_ability(ability_name: String) -> bool:
    if ability_name not in abilities:
        return false
    return not cooldown_timers[ability_name].time_left > 0

func start_cooldown(ability_name: String) -> void:
    if ability_name in abilities:
        var duration = abilities[ability_name]["cooldown"]
        cooldown_timers[ability_name].start(duration)
        current_cooldowns[ability_name] = duration
        cooldown_started.emit(ability_name, duration)

func get_remaining_cooldown(ability_name: String) -> float:
    if ability_name in cooldown_timers:
        return cooldown_timers[ability_name].time_left
    return 0.0

func _process(delta: float) -> void:
    for ability in current_cooldowns:
        if cooldown_timers[ability].time_left > 0:
            cooldown_updated.emit(ability, cooldown_timers[ability].time_left)

func _on_cooldown_finished(ability_name: String) -> void:
    current_cooldowns.erase(ability_name)
    cooldown_finished.emit(ability_name)
```

**skill_button.gd:**
```gdscript
extends Button

@export var ability_name: String = ""
@onready var cooldown: CooldownSystem = get_parent().get_node("CooldownSystem")
@onready var cooldown_label: Label = $CooldownLabel

func _ready() -> void:
    cooldown.cooldown_updated.connect(_on_cooldown_updated)
    cooldown.cooldown_finished.connect(_on_cooldown_finished)

func _on_pressed() -> void:
    if cooldown.can_use_ability(ability_name):
        cooldown.start_cooldown(ability_name)
        print("Menggunakan ability: ", ability_name)

func _on_cooldown_updated(name: String, remaining: float) -> void:
    if name == ability_name:
        cooldown_label.text = str(ceil(remaining))
        disabled = true

func _on_cooldown_finished(name: String) -> void:
    if name == ability_name:
        cooldown_label.text = ""
        disabled = false
```

## Kasus Penggunaan Nyata
Cooldown system digunakan di game MOBA seperti League of Legends dan Dota 2. Setiap kemampulan champion memiliki waktu tunggu tertentu, memaksa pemain untuk memilih waktu yang tepat dalam menggunakan skill dan mengelola resource dengan bijak.
