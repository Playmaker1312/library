# 173. Membuat sistem combo attack dengan input buffer

## Definisi Singkat
Sistem combo attack memungkinkan pemain melakukan rangkaian serangan berurutan dengan menekan tombol attack secara tepat waktu. Input buffer menyimpan input pemain dan mengeksekusinya saat giliran yang tepat.

## Analogi
Seperti menari tango. Setiap langkah (serangan) harus dilakukan pada waktu yang tepat. Jika kita menekan tombol terlalu cepat atau terlalu lambat, combo akan terputus. Input buffer seperti ingatan tubuh yang mengingat gerakan berikutnya.

## Struktur Node (Scene Tree)

Player

## Kode GDScript (Godot 4)

**combo_system.gd:**
```gdscript
extends Node

signal combo_started(combo_index: int)
signal combo_finished
signal combo_failed

@export var combo_window: float = 0.5
@export var max_combo: int = 3

var current_combo: int = 0
var combo_timer: float = 0.0
var input_buffer: Array[String] = []
var is_combo_active: bool = false

func _process(delta: float) -> void:
    if is_combo_active:
        combo_timer -= delta
        if combo_timer <= 0:
            reset_combo()

func add_attack_input() -> void:
    if current_combo < max_combo:
        input_buffer.append("attack")
        if not is_combo_active:
            start_combo()
        else:
            execute_next_attack()

func start_combo() -> void:
    is_combo_active = true
    combo_timer = combo_window
    combo_started.emit(current_combo)

func execute_next_attack() -> void:
    if input_buffer.size() > 0:
        input_buffer.pop_front()
        current_combo += 1
        combo_timer = combo_window
        combo_started.emit(current_combo)

func reset_combo() -> void:
    current_combo = 0
    input_buffer.clear()
    is_combo_active = false
    combo_finished.emit()

func _on_attack_animation_finished() -> void:
    if input_buffer.size() > 0:
        execute_next_attack()
    else:
        reset_combo()
```

**player.gd:**
```gdscript
extends CharacterBody2D

@onready var combo: Node = $ComboSystem
@onready var anim: AnimationPlayer = $AnimationPlayer

func _ready() -> void:
    combo.combo_started.connect(_on_combo_started)

func _unhandled_input(event: InputEvent) -> void:
    if event.is_action_pressed("attack"):
        combo.add_attack_input()

func _on_combo_started(index: int) -> void:
    anim.play("attack_" + str(index + 1))
```

## Kasus Penggunaan Nyata
Sistem combo attack digunakan di game fighting seperti Street Fighter dan game action seperti Devil May Cry. Pemain bisa mengkombinasikan berbagai serangan untuk membentuk kombo yang kuat, memberikan kedalaman strategis dalam pertarungan jarak dekat.
