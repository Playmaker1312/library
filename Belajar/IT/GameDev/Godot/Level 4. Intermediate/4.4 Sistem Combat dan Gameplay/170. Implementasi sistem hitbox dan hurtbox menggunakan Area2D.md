# 170. Implementasi sistem hitbox dan hurtbox menggunakan Area2D

## Definisi Singkat
Hitbox adalah area yang mendeteksi serangan aktif dari sebuah objek, sedangkan hurtbox adalah area yang menerima damage saat terkena hitbox. Keduanya menggunakan Area2D dan collision layers untuk komunikasi antar objek.

## Analogi
Seperti tangan dan tubuh saat berkelahi. Tangan (hitbox) adalah bagian yang melakukan pukulan, sedangkan tubuh (hurtbox) adalah bagian yang bisa terkena pukulan. Dengan memisahkan keduanya, kita bisa menentukan bagian mana yang menyerang dan bagian mana yang bisa menerima serangan.

## Struktur Node (Scene Tree)
```
CharacterBody2D (Player/Enemy)
├── Sprite2D
├── CollisionShape2D (untuk fisik tubuh)
├── HurtBox (Area2D)
│   └── CollisionShape2D
└── HitBox (Area2D)
    └── CollisionShape2D
```

## Kode GDScript (Godot 4)

**hitbox.gd:**
```gdscript
class_name HitBox
extends Area2D

@export var damage: int = 10
@export var knockback_force: float = 200.0

var active: bool = false

func activate():
    active = true
    set_deferred("monitoring", true)

func deactivate():
    active = false
    set_deferred("monitoring", false)

func _on_area_entered(area: Area2D) -> void:
    if area is HurtBox and active:
        area.take_damage(damage, global_position, knockback_force)
```

**hurtbox.gd:**
```gdscript
class_name HurtBox
extends Area2D

signal damage_received(amount: int, from_position: Vector2, force: float)

@export var max_health: int = 100
var current_health: int

func _ready() -> void:
    current_health = max_health

func take_damage(amount: int, from_pos: Vector2, force: float) -> void:
    current_health -= amount
    damage_received.emit(amount, from_pos, force)
    if current_health <= 0:
        queue_free()
```

**player.gd:**
```gdscript
extends CharacterBody2D

@onready var hitbox: HitBox = $HitBox
@onready var hurtbox: HurtBox = $HurtBox

func _ready() -> void:
    hurtbox.damage_received.connect(_on_hurt)

func attack() -> void:
    hitbox.activate()
    await get_tree().create_timer(0.2).timeout
    hitbox.deactivate()

func _on_hurt(amount: int, from_pos: Vector2, force: float) -> void:
    var direction = (global_position - from_pos).normalized()
    velocity = direction * force
    print("Terkena damage: ", amount)
```

## Kasus Penggunaan Nyata
Sistem hitbox dan hurtbox digunakan di hampir semua game action seperti Dark Souls dan Hollow Knight. Pemain bisa menyerang musuh menggunakan hitbox, sementara musuh memiliki hurtbox untuk menerima damage. Pemisahan ini memungkinkan animasi serangan yang presisi tanpa mempengaruhi fisik objek.
