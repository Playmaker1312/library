# 177. Implementasi lock-on target system untuk combat

## Definisi Singkat
Lock-on target system adalah mekanisme yang memungkinkan pemain mengunci target musuh tertentu, membuat kamera dan serangan selalu mengarah ke target tersebut. Sistem ini memudahkan pertarungan one-on-one.

## Analogi
Seperti mata elang yang terus mengincar mangsa. Meskipun mangsa bergerak ke mana-mana, mata elang selalu mengikutinya. Lock-on bekerja sama, memastikan serangan pemain selalu mengenai target yang dipilih.

## Kode GDScript (Godot 4)

**lock_on_system.gd:**
```gdscript
extends Node2D

signal target_locked(target: Node2D)
signal target_lost

@export var detection_range: float = 300.0
@export var lock_on_offset: Vector2 = Vector2(0, -50)

var current_target: Node2D = null
var nearby_targets: Array[Node2D] = []
var is_locked: bool = false

@onready var indicator: Sprite2D = $LockOnIndicator
@onready var detection: Area2D = $DetectionArea

func _ready() -> void:
    indicator.hide()
    detection.body_entered.connect(_on_body_entered)
    detection.body_exited.connect(_on_body_exited)

func _process(delta: float) -> void:
    if is_locked and current_target:
        update_indicator_position()
        if not is_target_valid():
            unlock()

func toggle_lock_on() -> void:
    if is_locked:
        unlock()
    else:
        try_lock_nearest()

func try_lock_nearest() -> void:
    if nearby_targets.size() == 0:
        return
    var nearest = find_nearest_target()
    if nearest:
        lock_on(nearest)

func lock_on(target: Node2D) -> void:
    current_target = target
    is_locked = true
    indicator.show()
    target_locked.emit(target)

func unlock() -> void:
    current_target = null
    is_locked = false
    indicator.hide()
    target_lost.emit()

func find_nearest_target() -> Node2D:
    var nearest: Node2D = null
    var min_distance: float = detection_range
    for target in nearby_targets:
        var distance = global_position.distance_to(target.global_position)
        if distance < min_distance:
            min_distance = distance
            nearest = target
    return nearest

func update_indicator_position() -> void:
    if current_target:
        indicator.global_position = current_target.global_position + lock_on_offset

func is_target_valid() -> bool:
    return current_target and is_instance_valid(current_target) and current_target.is_in_group("enemy")

func get_lock_direction() -> Vector2:
    if is_locked and current_target:
        return (current_target.global_position - global_position).normalized()
    return Vector2.ZERO

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("enemy") and body not in nearby_targets:
        nearby_targets.append(body)

func _on_body_exited(body: Node2D) -> void:
    nearby_targets.erase(body)
```

**player.gd:**
```gdscript
extends CharacterBody2D

@onready var lock_on: Node2D = $LockOnSystem

func _unhandled_input(event: InputEvent) -> void:
    if event.is_action_pressed("lock_on"):
        lock_on.toggle_lock_on()

func _physics_process(delta: float) -> void:
    var move_dir = Input.get_vector("left", "right", "up", "down")
    if lock_on.is_locked:
        var lock_dir = lock_on.get_lock_direction()
        move_dir = move_dir.rotated(lock_dir.angle())
    velocity = move_dir * 200.0
    move_and_slide()
```

## Kasus Penggunaan Nyata
Lock-on target system digunakan di game seperti Dark Souls dan Zelda: Breath of the Wild. Sistem ini memungkinkan pemain fokus pada satu musuh, memudahkan manuver defensif dan serangan presisi dalam pertarungan satu lawan satu yang intens.
