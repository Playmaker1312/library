# 172. Implementasi knockback effect saat karakter terkena serangan

## Definisi Singkat
Knockback adalah efek yang mendorong karakter ke belakang saat terkena serangan, menciptakan jarak antara penyerang dan target. Efek ini menggunakan arah dan kekuatan yang dihitung dari posisi serangan.

## Analogi
Seperti saat kita mendorong seseorang. Arah dorongan berlawanan dengan arah kita mendorong, dan semakin kuat dorongan kita, semakin jauh orang tersebut terdorong ke belakang.

## Struktur Node (Scene Tree)
```
CharacterBody2D
├── Sprite2D
├── CollisionShape2D
└── KnockbackManager (Node)
```

## Kode GDScript (Godot 4)

**knockback_manager.gd:**
```gdscript
extends Node

signal knockback_finished

@export var character: CharacterBody2D
@export var friction: float = 1000.0
@export var knockback_duration: float = 0.3

var knockback_velocity: Vector2 = Vector2.ZERO
var is_knocked_back: bool = false
var knockback_timer: float = 0.0

func apply_knockback(from_position: Vector2, force: float) -> void:
    var direction = (character.global_position - from_position).normalized()
    knockback_velocity = direction * force
    is_knocked_back = true
    knockback_timer = knockback_duration

func _process(delta: float) -> void:
    if is_knocked_back:
        knockback_velocity = knockback_velocity.move_toward(Vector2.ZERO, friction * delta)
        character.velocity = knockback_velocity
        knockback_timer -= delta
        if knockback_timer <= 0 or knockback_velocity.length() < 10.0:
            is_knocked_back = false
            knockback_velocity = Vector2.ZERO
            knockback_finished.emit()
```

**hurtbox.gd:**
```gdscript
extends Area2D

@onready var knockback: Node = get_parent().get_node("KnockbackManager")

func take_damage(amount: int, from_pos: Vector2, force: float) -> void:
    knockback.apply_knockback(from_pos, force)
```

**enemy.gd:**
```gdscript
extends CharacterBody2D

@onready var knockback: Node = $KnockbackManager

func _physics_process(delta: float) -> void:
    if not knockback.is_knocked_back:
        velocity = Vector2.ZERO
    move_and_slide()
```

## Kasus Penggunaan Nyata
Knockback digunakan di banyak game seperti Super Smash Bros dan Monster Hunter. Efek ini memberikan feedback visual yang kuat saat serangan mengenai target, memisahkan lawan secara fisik, dan menciptakan jeda strategis dalam pertarungan.
