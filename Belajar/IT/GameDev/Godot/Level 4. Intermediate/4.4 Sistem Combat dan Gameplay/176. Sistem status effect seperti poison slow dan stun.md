# 176. Sistem status effect seperti poison slow dan stun

## Definisi Singkat
Sistem status effect adalah mekanisme yang menerapkan efek sementara pada karakter seperti kerusakan berkelanjutan (poison), pengurangan kecepatan (slow), atau pencegahan gerakan (stun). Setiap effect memiliki durasi dan efek yang berbeda.

## Analogi
Seperti obat yang diminum. Obat bisa memberikan efek sementara seperti rasa pusing (stun), rasa mual (poison), atau rasa lemas (slow). Efek ini tidak permanen dan akan hilang setelah waktu tertentu.

## Struktur Node (Scene Tree)
```
Character
├── StatusEffectManager (Node)
│   ├── PoisonEffect (Timer)
│   ├── SlowEffect (Timer)

└── Sprite2D
```

## Kode GDScript (Godot 4)

**status_effect.gd:**
```gdscript
class_name StatusEffect
extends Resource

enum EffectType { POISON, SLOW, STUN, BURN, FREEZE }

@export var type: EffectType
@export var duration: float = 3.0
@export var strength: float = 1.0
@export var tick_rate: float = 1.0

var elapsed_time: float = 0.0
var tick_timer: float = 0.0
var is_active: bool = false

func apply(target: Node) -> void:
    is_active = true
    match type:
        EffectType.POISON:
            target.modulate = Color(0.5, 0.0, 0.5)
        EffectType.SLOW:
            target.speed *= (1.0 - strength)
        EffectType.STUN:
            target.can_move = false
            target.can_attack = false

func update(delta: float, target: Node) -> void:
    if not is_active:
        return
    elapsed_time += delta
    tick_timer += delta
    if tick_timer >= tick_rate:
        tick_timer = 0.0
        _on_tick(target)
    if elapsed_time >= duration:
        remove(target)

func _on_tick(target: Node) -> void:
    match type:
        EffectType.POISON:
            target.take_damage(strength)
        EffectType.BURN:
            target.take_damage(strength * 2)

func remove(target: Node) -> void:
    is_active = false
    match type:
        EffectType.SLOW:
            target.speed /= (1.0 - strength)
        EffectType.STUN:
            target.can_move = true
            target.can_attack = true
        EffectType.POISON, EffectType.BURN:
            target.modulate = Color.WHITE
```

**status_effect_manager.gd:**
```gdscript
extends Node

signal effect_applied(effect: StatusEffect)
signal effect_removed(effect: StatusEffect)

var active_effects: Array[StatusEffect] = []
var target: Node = null

func _ready() -> void:
    target = get_parent()

func add_effect(effect: StatusEffect) -> void:
    for existing in active_effects:
        if existing.type == effect.type:
            existing.elapsed_time = 0.0
            return
    var new_effect = effect.duplicate()
    new_effect.apply(target)
    active_effects.append(new_effect)
    effect_applied.emit(new_effect)

func _process(delta: float) -> void:
    var effects_to_remove: Array[StatusEffect] = []
    for effect in active_effects:
        effect.update(delta, target)
        if not effect.is_active:
            effects_to_remove.append(effect)
    for effect in effects_to_remove:
        active_effects.erase(effect)
        effect_removed.emit(effect)

func has_effect(type: StatusEffect.EffectType) -> bool:
    for effect in active_effects:
        if effect.type == type and effect.is_active:
            return true
    return false
```

**poison_sword.gd:**
```gdscript
extends Node2D

const PoisonEffect = preload("res://resources/poison_effect.tres")
var poison_damage: float = 5.0
var poison_duration: float = 5.0

func _on_area_entered(area: Area2D) -> void:
    if area.name == "HurtBox":
        var target = area.get_parent()
        var effect = PoisonEffect.duplicate()
        effect.strength = poison_damage
        effect.duration = poison_duration
        target.get_node("StatusEffectManager").add_effect(effect)
```

## Kasus Penggunaan Nyata
Sistem status effect digunakan di game RPG seperti Skyrim dan The Witcher. Pemain bisa menggunakan racun, sihir es, atau mantra stun untuk memberikan efek sementara pada musuh, menambah kedalaman strategis dalam pertarungan.
