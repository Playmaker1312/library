# 171. Membuat sistem damage number yang melayang menggunakan instansiasi dinamis

## Definisi Singkat
Sistem damage number adalah UI yang menampilkan angka damage secara visual saat karakter terkena serangan. Angka tersebut diinstansiasi secara dinamis dan diatur agar melayang ke atas sebelum menghilang.

## Analogi
Seperti angka yang muncul saat kita memukul musuh di game RPG lama. Setiap pukulan menampilkan angka yang terbang ke atas dari posisi terkena serangan, membantu pemain memahami seberapa besar damage yang diberikan.

## Struktur Node (Scene Tree)
```
DamageNumber (PackedScene)
└── Label
    └── AnimationPlayer
```

## Kode GDScript (Godot 4)

**damage_number.gd:**
```gdscript
extends Node2D

@onready var label: Label = $Label
@onready var animation_player: AnimationPlayer = $AnimationPlayer

var velocity: Vector2 = Vector2.ZERO
var gravity: float = 200.0
var lifetime: float = 1.0

func setup(text: String, pos: Vector2, is_critical: bool = false) -> void:
    global_position = pos
    label.text = text
    if is_critical:
        label.modulate = Color.RED
        label.scale = Vector2(1.5, 1.5)
    animation_player.play("float_up")

func _process(delta: float) -> void:
    velocity.y -= gravity * delta
    position += velocity * delta
    lifetime -= delta
    if lifetime <= 0:
        queue_free()
```

**damage_spawner.gd:**
```gdscript
extends Node

const DamageNumber = preload("res://scenes/damage_number.tscn")

func spawn_damage(amount: int, position: Vector2, is_critical: bool = false) -> void:
    var damage = DamageNumber.instantiate()
    damage.setup(str(amount), position, is_critical)
    get_tree().current_scene.add_child(damage)
```

**hitbox.gd:**
```gdscript
extends Area2D

@export var damage: int = 10

func _on_area_entered(area: Area2D) -> void:
    if area.name == "HurtBox":
        DamageSpawner.spawn_damage(damage, global_position)
```

## Kasus Penggunaan Nyata
Sistem damage number umum digunakan di game RPG seperti Final Fantasy dan Borderlands. Setiap serangan menampilkan angka damage yang melayang, membantu pemain memahami efektivitas serangan mereka dan menambah kepuasan visual saat bertarung.
