# 324. Channel YouTube Terpilih untuk Belajar Godot seperti GDQuest, Brackeys era Godot, dan KidsCanCode

## Definisi Singkat
Channel YouTube untuk belajar Godot adalah saluran konten video tutorial yang menyediakan materi pembelajaran visual tentang cara menggunakan Godot Engine dalam pengembangan game. Channel populer seperti GDQuest, Brackeys, dan KidsCanCode menawarkan tutorial dari tingkat pemula hingga lanjutan dengan pendekatan yang berbeda-beda.

## Analogi
Channel YouTube untuk belajar Godot ibarat kelas kursus yang bisa diakses kapan saja. Siswa dapat menonton instruktur menjelaskan konsep sambil mendemonstrasikan langkah-langkah praktis secara langsung, berbeda dengan buku teks yang hanya berisi teks dan gambar statis.

## Struktur Node (Scene Tree)
Channel YouTube untuk belajar Godot dapat dikategorikan berdasarkan tingkat kesulitan dan topik:

## Kode GDScript (Godot 4)
```gdscript
extends Control

var channels: Dictionary = {
	"GDQuest": "https://youtube.com/@GDQuest",
	"Brackeys": "https://youtube.com/@Brackeys",
	"KidsCanCode": "https://youtube.com/@KidsCanCode"
}

func _ready() -> void:
	print("Channel YouTube untuk belajar Godot:")
	for channel_name in channels:
		print("- ", channel_name, ": ", channels[channel_name])

func open_channel(channel_name: String) -> void:
	if channels.has(channel_name):
		OS.shell_open(channels[channel_name])
		print("Membuka channel: ", channel_name)
	else:
		print("Channel tidak ditemukan: ", channel_name)

func get_recommended_playlists() -> Array[String]:
	var playlists: Array[String] = [
		"GDQuest - Learn GDScript From Zero",
		"Brackeys - How to make a Video Game",
		"KidsCanCode - Godot Recipes",
		"GDQuest - Godot 4 Marketing"
	]
	return playlists

func learn_gdscript_basics() -> void:
	print("Memulai pembelajaran GDScript dari dasar...")
	open_channel("GDQuest")

func learn_complete_game() -> void:
	print("Membuat game lengkap dari awal...")
	open_channel("Brackeys")

func learn_advanced_patterns() -> void:
	print("Mempelajari design patterns lanjutan...")
	open_channel("KidsCanCode")

func _on_gdquest_button_pressed() -> void:
	learn_gdscript_basics()

func _on_brackeys_button_pressed() -> void:
	learn_complete_game()

func _on_kidscancode_button_pressed() -> void:
	learn_advanced_patterns()
```

## Kasus Penggunaan Nyata
Channel YouTube seperti GDQuest sangat cocok untuk pemula yang ingin mempelajari GDScript dari nol dengan pendekatan interaktif. Brackeys memberikan tutorial lengkap pembuatan game dari awal hingga akhir, cocok untuk yang ingin langsung praktik membuat game sederhana. KidsCanCode lebih fokus pada konsep lanjutan seperti design patterns dan arsitektur game, cocok untuk pengembang yang sudah memiliki dasar pemrograman. Kombinasi ketiga channel ini memberikan jalur pembelajaran yang komprehensif dari dasar hingga mahir.
