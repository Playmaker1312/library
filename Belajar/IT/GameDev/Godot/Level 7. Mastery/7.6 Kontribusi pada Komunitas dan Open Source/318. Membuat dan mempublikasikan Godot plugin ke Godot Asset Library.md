# 318. Membuat dan mempublikasikan Godot plugin ke Godot Asset Library

## Definisi Singkat
Godot plugin adalah kumpulan script, scene, dan resource yang dapat dipakai ulang untuk menambahkan fitur khusus ke project Godot. Mempublikasikan ke Godot Asset Library berarti membagikan plugin tersebut agar developer lain dapat mengunduh dan menggunakannya secara gratis.

## Analogi
Bayangkan kamu membuat resep masakan yang enak. Daripada hanya dinikmati sendiri, kamu mempublikasikannya ke buku resep online agar orang lain bisa memasak hidangan yang sama. Plugin Godot seperti resep itu — kumpulan instruksi dan bahan (kode dan asset) yang bisa dipakai orang lain untuk membuat fitur serupa di game mereka.

## Struktur Node (Scene Tree)
```
addons/
└── my_plugin/
    ├── plugin.cfg
    ├── plugin.gd
    ├── nodes/
    │   └── custom_node.gd
    ├── tools/
    │   └── editor_plugin.gd
    └── icon.svg
```

## Kode GDScript (Godot 4)
```gdscript
# plugin.cfg
[plugin]
name="MyCustomPlugin"
description="Plugin contoh untuk Godot Asset Library"
author="Developer Name"
version="1.0.0"
script="plugin.gd"

# plugin.gd
@tool
extends EditorPlugin

func _enter_tree():
	add_custom_type(
		"CustomButton",
		"Button",
		preload("res://addons/my_plugin/nodes/custom_button.gd"),
		preload("res://addons/my_plugin/icon.svg")
	)

func _exit_tree():
	remove_custom_type("CustomButton")

# nodes/custom_button.gd
extends Button

@export var button_color: Color = Color.BLUE

func _ready():
	add_theme_stylebox_override("normal", create_stylebox())

func create_stylebox() -> StyleBoxFlat:
	var style = StyleBoxFlat.new()
	style.bg_color = button_color
	style.corner_radius_top_left = 8
	style.corner_radius_top_right = 8
	style.corner_radius_bottom_left = 8
	style.corner_radius_bottom_right = 8
	return style
```

## Kasus Penggunaan Nyata
Banyak game developer membangun tool khusus seperti system inventaris, dialogue system, atau procedural generation yang kemudian dipublikasikan ke Asset Library. Plugin populer seperti "Dialogic" atau "GodotSteam" menjadi sangat membantu bagi komunitas. Mempublikasikan plugin juga dapat menjadi portofolio yang menunjukkan kemampuan teknis kamu kepada calon employer atau klien freelance.
