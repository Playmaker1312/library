# 317. Cara berkontribusi pada Godot Engine repository di GitHub

## Definisi Singkat
Berkontribusi pada Godot Engine repository di GitHub berarti berpartisipasi dalam pengembangan open source dengan cara mengirimkan perubahan kode (patch), melaporkan bug, menulis dokumentasi, atau membantu review pull request. Kontribusi dapat berupa perbaikan bug kecil hingga fitur baru yang signifikan bagi engine.

## Analogi
Bayangkan Godot Engine adalah sebuah rumah besar yang dibangun bersama oleh ribuan orang. Setiap orang bisa membantu memperbaiki kusen pintu yang rusak (bug fix), menambah ruangan baru (fitur), atau menulis panduan cara menggunakan rumah tersebut (dokumentasi). Kamu tidak harus menjadi arsitek untuk berkontribusi — bahkan membersihkan halaman (typo fix) sudah sangat membantu.

## Struktur Node (Scene Tree)
```
Project
├── .github/
│   ├── ISSUE_TEMPLATE/
│   ├── PULL_REQUEST_TEMPLATE.md
│   └── workflows/
├── core/
├── editor/
├── modules/
├── platform/
└── doc/
```

## Kode GDScript (Godot 4)
```gdscript
extends SceneTree

func _init():
	print("Contoh kontribusi: membuat test case untuk fitur baru")
	print("1. Fork repository Godot di GitHub")
	print("2. Clone fork lokal: git clone https://github.com/username/godot.git")
	print("3. Buat branch baru: git checkout -b my-feature")
	print("4. Buat perubahan dan commit")
	print("5. Push dan buka Pull Request")

func _test_example():
	var node = Node.new()
	assert(node.get_class() == "Node", "Node class harus valid")
	print("Test passed untuk basic node creation")
```

## Kasus Penggunaan Nyata
Banyak developer profesional berkontribusi pada Godot untuk membangun reputasi di komunitas open source. Perbaikan kecil seperti memperbaiki dokumen yang salah atau menambahkan contoh kode dapat menjadi awal untuk kontribusi yang lebih besar. Beberapa kontributor kemudian menjadi bagian dari tim inti Godot dan mendapat kesempatan untuk membentuk arah masa depan engine.
