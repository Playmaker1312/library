# 321. Membangun portofolio game dev yang profesional untuk karir atau freelance

## Definisi Singkat
Portofolio game dev profesional adalah kumpulan proyek game, tool, dan kontribusi yang menunjukkan kemampuan teknis dan kreatif kamu kepada calon employer atau klien. Portofolio yang baik harus rapi, terorganisir, dan menampilkan karya terbaik kamu dengan penjelasan yang jelas tentang teknologi dan proses yang digunakan.

## Analogi
Bayangkan portofolio seperti galeri seni yang menampilkan karya terbaik kamu. Kamu tidak perlu menampilkan semua karya — cukup pilih yang paling mengesankan dan berikan penjelasan tentang teknik yang digunakan. Sebuah galeri yang terorganisir dengan pencahayaan baik (website profesional) akan menarik lebih banyak pengunjung (employer atau klien) daripada galeri yang berantakan.

## Kode GDScript (Godot 4)
```gdscript
extends Node

class_name PortfolioManager

var projects: Array[Dictionary] = []
var current_project_index: int = 0

func _ready():
	load_portfolio_data()

func load_portfolio_data():
	projects = [
		{
			"title": "Platformer Adventure",
			"description": "Game platformer 2D dengan sistem combat",
			"engine": "Godot 4.2",
			"features": ["AnimationTree", "StateMachine", "TileMap"],
			"screenshot_path": "res://assets/screenshots/platformer.png",
			"demo_url": "https://username.itch.io/platformer",
			"source_url": "https://github.com/username/platformer"
		},
		{
			"title": "Puzzle Master",
			"description": "Puzzle game dengan mekanik unik",
			"engine": "Godot 4.2",
			"features": ["Custom Shaders", "Signal Bus", "Save System"],
			"screenshot_path": "res://assets/screenshots/puzzle.png",
			"demo_url": "https://username.itch.io/puzzle",
			"source_url": "https://github.com/username/puzzle"
		}
	]

func get_project_data(index: int) -> Dictionary:
	if index >= 0 and index < projects.size():
		return projects[index]
	return {}

func get_project_count() -> int:
	return projects.size()

func add_project(project_data: Dictionary) -> void:
	if project_data.has("title") and project_data.has("description"):
		projects.append(project_data)

func get_portfolio_summary() -> String:
	var summary = "Portofolio Game Developer\n"
	summary += "Total Proyek: %d\n" % projects.size()
	for project in projects:
		summary += "- %s (%s)\n" % [project.title, project.engine]
	return summary
```

## Kasus Penggunaan Nyata
Developer game profesional seperti Tim Beauden (Brotato) dan Thomas Altenburger (Mundaun) membangun reputasi melalui portofolio yang kuat. Portofolio online diitch.io atau personal website menjadi kartu nama utama saat melamar kerja di studio game atau mencari klien freelance. Proyek Game Jam dan kontribusi open source di GitHub menjadi nilai tambah yang membedakan kamu dari kandidat lain.
