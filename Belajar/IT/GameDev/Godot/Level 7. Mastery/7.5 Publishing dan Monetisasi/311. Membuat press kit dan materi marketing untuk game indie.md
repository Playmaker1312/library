# 311. Membuat press kit dan materi marketing untuk game indie

## Definisi Singkat
Press kit adalah kumpulan materi promosi seperti logo, screenshot, trailer, dan deskripsi game yang diberikan kepada jurnalis, reviewer, dan content creator. Materi marketing mencakup semua konten visual dan teks yang digunakan untuk mempromosikan game di media sosial, toko digital, dan platform lainnya.

## Analogi
Bayangkan kamu membuka restoran baru. Press kit itu seperti menu lengkap beserta foto makanan, alamat, dan cerita tentang restoranmu yang kamu berikan ke food blogger supaya mereka mau menulis ulasan. Tanpa press kit yang rapi, blogger tidak tahu harus mulai dari mana dan mungkin tidak mau membahas restoranmu.

## Struktur Node (Scene Tree)
Tidak berlaku secara langsung, tetapi tool yang relevan:
- `FileDialog` — untuk export assets
- `HTTPRequest` — untuk upload ke hosting
- `Node` — sebagai root script generator press kit

## Kode GDScript (Godot 4)
```gdscript
extends Node

var press_kit_data: Dictionary = {
	"title": "My Awesome Game",
	"developer": "Indie Studio",
	"release_date": "2026-01-01",
	"genre": "Platformer",
	"platforms": ["Windows", "macOS", "Linux", "Steam"],
	"description_short": "A retro-inspired platformer with modern mechanics.",
	"description_long": "Embark on an adventure through hand-crafted levels...",
	"logo_path": "res://assets/logo.png",
	"screenshot_paths": [
		"res://assets/screenshots/screenshot_01.png",
		"res://assets/screenshots/screenshot_02.png",
		"res://assets/screenshots/screenshot_03.png"
	],
	"trailer_url": "https://youtube.com/watch?v=example",
	"social_links": {
		"steam": "https://store.steampowered.com/app/12345",
		"twitter": "https://twitter.com/myawesomegame",
		"discord": "https://discord.gg/example"
	},
	"contact_email": "press@mystudio.com"
}

func generate_press_kit_text() -> String:
	var text: String = ""
	text += "GAME: " + press_kit_data["title"] + "\n"
	text += "DEVELOPER: " + press_kit_data["developer"] + "\n"
	text += "RELEASE: " + press_kit_data["release_date"] + "\n"
	text += "GENRE: " + press_kit_data["genre"] + "\n"
	text += "PLATFORMS: " + ", ".join(press_kit_data["platforms"]) + "\n\n"
	text += "--- SHORT DESCRIPTION ---\n"
	text += press_kit_data["description_short"] + "\n\n"
	text += "--- LONG DESCRIPTION ---\n"
	text += press_kit_data["description_long"] + "\n\n"
	text += "--- LINKS ---\n"
	for key in press_kit_data["social_links"]:
		text += key.capitalize() + ": " + press_kit_data["social_links"][key] + "\n"
	text += "\n--- CONTACT ---\n"
	text += "Press inquiries: " + press_kit_data["contact_email"] + "\n"
	return text

func save_press_kit():
	var file = FileAccess.open("user://press_kit.txt", FileAccess.WRITE)
	if file:
		file.store_string(generate_press_kit_text())
		file.close()

func get_screenshot_paths() -> Array:
	return press_kit_data["screenshot_paths"]

func get_logo_path() -> String:
	return press_kit_data["logo_path"]
```
