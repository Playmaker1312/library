# 293. Merancang tutorial yang mengajarkan tanpa menggurui menggunakan show not tell

## Definisi Singkat
Show Not Tell dalam desain tutorial adalah pendekatan di mana pemain belajar mekanik game melalui pengalaman langsung dan eksplorasi alami, bukan melalui teks instruksi atau dialog panjang. Prinsip ini menciptakan tutorial yang immersive dan menghormati intelligensia pemain.

## Analogi
Bayangkan mengajari anak berenang. Anda bisa menjelaskan teori tentang bagaimana menggerakkan tangan dan kaki (Tell), atau Anda bisa melempar bola ke kolam dan membiarkan anak berenang untuk mengambilnya sambil Anda memberikan contoh (Show). Pendekatan kedua lebih efektif karena anak belajar melalui aksi langsung dan menemukan sendiri cara berenang. Tutorial game yang baik bekerja seperti guru renang yang sabar ini.

## Struktur Node (Scene Tree)
```
TutorialManager (Node)
├── TutorialZone (Area2D)
│   ├── HintTrigger (Area2D)
│   └── SkillPracticeZone (Area2D)
├── GuidedPath (Path2D)
│   ├── PathFollow2D
│   └── TutorialGuide (Sprite2D)
├── InteractiveHints (CanvasLayer)
│   ├── ActionHighlight (Control)
│   └── ContextualTip (Control)
└── ProgressTracker (Node)
    ├── CompletedLessons (Array[String])
    └── CurrentObjective (String)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

signal tutorial_completed(lesson: String)
signal hint_triggered(hint_type: String, position: Vector2)

var current_lesson: String = ""
var player_near_hint: bool = false
var nearby_hint_id: String = ""
var completed_lessons: Array[String] = []
var player_actions: Dictionary = {}

@export var tutorial_sequence: Array[Dictionary] = [
    {"lesson": "movement", "hint": "WASD to move", "objective": "reach_marker"},
    {"lesson": "jump", "hint": "Space to jump", "objective": "jump_over_obstacle"},
    {"lesson": "attack", "hint": "Click to attack", "objective": "defeat_target"}
]

func _ready() -> void:
    _start_next_lesson()

func _start_next_lesson() -> void:
    for lesson in tutorial_sequence:
        if lesson["lesson"] not in completed_lessons:
            current_lesson = lesson["lesson"]
            _show_contextual_hint(lesson["hint"])
            _spawn_objective_marker(lesson["objective"])
            break

func _show_contextual_hint(text: String) -> void:
    var hint = $InteractiveHints/ContextualTip
    hint.get_node("Label").text = text
    hint.visible = true
    hint.modulate.a = 0.0
    var tween = create_tween()
    tween.tween_property(hint, "modulate:a", 1.0, 0.5)

func _spawn_objective_marker(objective_type: String) -> void:
    var marker = $TutorialZone/HintTrigger
    match objective_type:
        "reach_marker":
            marker.position = Vector2(200, 0)
            marker.visible = true
        "jump_over_obstacle":
            var obstacle = $TutorialZone/SkillPracticeZone
            obstacle.visible = true
        "defeat_target":
            _spawn_practice_enemy()

func _spawn_practice_enemy() -> void:
    var enemy = preload("res://scenes/enemies/practice_enemy.tscn").instantiate()
    enemy.position = Vector2(300, 0)
    enemy.health = 1
    enemy.connect("defeated", _on_practice_enemy_defeated)
    add_child(enemy)

func _on_practice_enemy_defeated() -> void:
    _complete_current_lesson()

func _complete_current_lesson() -> void:
    completed_lessons.append(current_lesson)
    tutorial_completed.emit(current_lesson)
    $InteractiveHints/ContextualTip.visible = false
    _start_next_lesson()

func _on_player_action(action: String) -> void:
    if current_lesson not in player_actions:
        player_actions[current_lesson] = []
    player_actions[current_lesson].append(action)
    if _check_lesson_completion():
        _complete_current_lesson()

func _check_lesson_completion() -> bool:
    var required_actions = {
        "movement": ["move_left", "move_right", "move_up", "move_down"],
        "jump": ["jump"],
        "attack": ["attack"]
    }
    if required_actions.has(current_lesson):
        var actions = player_actions.get(current_lesson, [])
        for required in required_actions[current_lesson]:
            if required not in actions:
                return false
        return true
    return false

func _on_player_entered_hint_zone(body: Node2D) -> void:
    if body.is_in_group("player"):
        player_near_hint = true
        var hint_text = _get_hint_for_current_lesson()
        _show_contextual_hint(hint_text)

func _on_player_exited_hint_zone(body: Node2D) -> void:
    if body.is_in_group("player"):
        player_near_hint = false

func _get_hint_for_current_lesson() -> String:
    for lesson in tutorial_sequence:
        if lesson["lesson"] == current_lesson:
            return lesson["hint"]
    return ""
```

## Kasus Penggunaan Nyata
**Half-Life 2** adalah contoh masterclass dalam Show Not Tell. Pemain belajar menggunakan Gravity Gun bukan melalui tutorial text, tapi melalui urutan desain level yang memaksa pemain menggunakannya untuk menyelesaikan puzzle. Pemain belajar melompati rintangan karena tidak ada jalan lain, dan belajar bertarung karena musuh datang menyerang. Valve merancang setiap level sebagai pelajaran tersembunyi yang terasa seperti gameplay natural.
