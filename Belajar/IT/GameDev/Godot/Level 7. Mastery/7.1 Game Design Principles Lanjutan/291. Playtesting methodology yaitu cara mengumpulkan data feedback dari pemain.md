# 291. Playtesting methodology yaitu cara mengumpulkan data feedback dari pemain

## Definisi Singkat
Playtesting methodology adalah pendekatan sistematis untuk mengumpulkan, menganalisis, dan menggunakan data feedback dari pemain guna memperbaiki game. Metode ini melibatkan observasi langsung, pengumpulan data kuantitatif, dan wawancara untuk memahami pengalaman pemain secara menyeluruh.

## Analogi
Bayangkan seorang dokter yang memeriksa pasien. Playtesting adalah seperti pemeriksaan kesehatan untuk game Anda. Observasi adalah melihat gejala (pemain kesulitan di level tertentu), data kuantitatif adalah hasil laboratorium (waktu tempuh, jumlah kematian), dan wawancara adalah konsultasi langsung (mengapa pemain merasa frustrasi). Tanpa playtesting, Anda hanya menebak apa yang salah dengan game Anda.

## Kode GDScript (Godot 4)
```gdscript
extends Node

signal playtest_data_collected(session_id: String, data: Dictionary)
signal feedback_submitted(player_id: String, rating: int, comments: String)

var session_data: Dictionary = {}
var player_sessions: Array[Dictionary] = []
var current_session_id: String = ""

func start_playtest_session(player_id: String) -> void:
    current_session_id = player_id + "_" + str(Time.get_unix_time_from_system())
    session_data = {
        "player_id": player_id,
        "session_id": current_session_id,
        "start_time": Time.get_unix_time_from_system(),
        "deaths": 0,
        "items_collected": 0,
        "enemies_defeated": 0,
        "areas_explored": [],
        "input_events": []
    }

func log_death(position: Vector2, cause: String) -> void:
    session_data["deaths"] += 1
    session_data["input_events"].append({
        "type": "death",
        "position": position,
        "cause": cause,
        "timestamp": Time.get_unix_time_from_system()
    })

func log_area_explored(area_name: String) -> void:
    if area_name not in session_data["areas_explored"]:
        session_data["areas_explored"].append(area_name)

func log_input_event(event_type: String, details: Dictionary) -> void:
    session_data["input_events"].append({
        "type": event_type,
        "details": details,
        "timestamp": Time.get_unix_time_from_system()
    })

func end_playtest_session() -> Dictionary:
    session_data["end_time"] = Time.get_unix_time_from_system()
    session_data["duration"] = session_data["end_time"] - session_data["start_time"]
    player_sessions.append(session_data)
    playtest_data_collected.emit(current_session_id, session_data)
    return session_data

func submit_feedback(player_id: String, rating: int, difficulty: int, fun_factor: int, comments: String) -> void:
    feedback_submitted.emit(player_id, rating, comments)
    var feedback_data = {
        "player_id": player_id,
        "rating": rating,
        "difficulty": difficulty,
        "fun_factor": fun_factor,
        "comments": comments,
        "timestamp": Time.get_unix_time_from_system()
    }
    session_data["feedback"] = feedback_data

func generate_report() -> Dictionary:
    var total_sessions: int = player_sessions.size()
    var avg_deaths: float = 0.0
    var avg_duration: float = 0.0
    for session in player_sessions:
        avg_deaths += session["deaths"]
        avg_duration += session["duration"]
    if total_sessions > 0:
        avg_deaths /= total_sessions
        avg_duration /= total_sessions
    return {
        "total_sessions": total_sessions,
        "average_deaths": avg_deaths,
        "average_duration": avg_duration,
        "common_death_causes": _get_common_death_causes()
    }

func _get_common_death_causes() -> Dictionary:
    var causes: Dictionary = {}
    for session in player_sessions:
        for event in session["input_events"]:
            if event["type"] == "death":
                var cause = event["cause"]
                causes[cause] = causes.get(cause, 0) + 1
    return causes
```

## Kasus Penggunaan Nyata
**Hades** oleh Supergiant Games menggunakan playtesting methodology yang intensif selama pengembangan. Mereka mengumpulkan data dari ratusan playtester untuk memahami pola kematian pemain, balancing difficulty, dan testing narrative integration. Data kematian di berbagai room digunakan untuk menyesuaikan enemy placement dan reward distribution, menghasilkan game yang challenging namun fair.
