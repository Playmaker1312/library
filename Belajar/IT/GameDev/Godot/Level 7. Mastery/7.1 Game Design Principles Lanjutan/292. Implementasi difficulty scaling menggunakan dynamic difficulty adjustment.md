# 292. Implementasi difficulty scaling menggunakan dynamic difficulty adjustment

## Definisi Singkat
Dynamic Difficulty Adjustment (DDA) adalah teknik desain game yang secara otomatis menyesuaikan tingkat kesulitan berdasarkan performa pemain secara real-time. DDA bertujuan menjaga pemain tetap dalam zona flow, tidak terlalu mudah dan tidak terlalu sulit.

## Analogi
Bayangkan seorang instruktur yoga yang mengamati siswanya. Jika siswa terlihat terlalu mudah melakukan pose, instruktur menambahkan variasi yang lebih challenging. Jika siswa terlihat kewalahan, instruktur memodifikasi pose menjadi lebih sederhana. Instruktur tidak memberitahu siswa tentang penyesuaian ini, tapi secara natural menjaga agar latihan tetap productive dan enjoyable. DDA bekerja seperti instruktur ini untuk game.


## Kode GDScript (Godot 4)
```gdscript
extends Node

signal difficulty_changed(new_difficulty: float, reason: String)

@export var min_difficulty: float = 0.1
@export var max_difficulty: float = 1.0
@export var adjustment_speed: float = 0.1

var current_difficulty: float = 0.5
var player_performance: Dictionary = {
    "recent_deaths": 0,
    "recent_successes": 0,
    "average_reaction_time": 1.0,
    "completion_rate": 0.5
}
var performance_window: Array[Dictionary] = []
var window_size: int = 20

func update_performance(success: bool, reaction_time: float, completion_time: float) -> void:
    var performance_entry: Dictionary = {
        "success": success,
        "reaction_time": reaction_time,
        "completion_time": completion_time,
        "timestamp": Time.get_unix_time_from_system()
    }
    performance_window.append(performance_entry)
    if performance_window.size() > window_size:
        performance_window.pop_front()
    _recalculate_performance()
    _adjust_difficulty()

func _recalculate_performance() -> void:
    var total_entries: int = performance_window.size()
    if total_entries == 0:
        return
    var successes: int = 0
    var total_reaction_time: float = 0.0
    for entry in performance_window:
        if entry["success"]:
            successes += 1
        total_reaction_time += entry["reaction_time"]
    player_performance["recent_successes"] = successes
    player_performance["recent_deaths"] = total_entries - successes
    player_performance["average_reaction_time"] = total_reaction_time / total_entries
    player_performance["completion_rate"] = float(successes) / float(total_entries)

func _adjust_difficulty() -> void:
    var performance_score: float = player_performance["completion_rate"]
    var reaction_factor: float = 1.0 / max(player_performance["average_reaction_time"], 0.1)
    var combined_score: float = (performance_score * 0.7) + (min(reaction_factor, 2.0) * 0.3)
    var target_difficulty: float = clamp(combined_score, min_difficulty, max_difficulty)
    var old_difficulty: float = current_difficulty
    current_difficulty = lerp(current_difficulty, target_difficulty, adjustment_speed)
    current_difficulty = clamp(current_difficulty, min_difficulty, max_difficulty)
    if abs(current_difficulty - old_difficulty) > 0.05:
        var reason: String = "player_performance"
        if current_difficulty > old_difficulty:
            reason = "too_easy"
        else:
            reason = "too_hard"
        difficulty_changed.emit(current_difficulty, reason)

func get_enemy_multiplier() -> Dictionary:
    return {
        "health": 0.5 + (current_difficulty * 1.5),
        "damage": 0.3 + (current_difficulty * 1.7),
        "speed": 0.8 + (current_difficulty * 0.4)
    }

func get_reward_multiplier() -> Dictionary:
    return {
        "experience": 1.0 + ((1.0 - current_difficulty) * 0.5),
        "loot_quality": current_difficulty * 1.2,
        "currency_bonus": 1.0 + (current_difficulty * 0.3)
    }
```

## Kasus Penggunaan Nyata
**Resident Evil 4** menggunakan sistem DDA yang canggih di mana game memantau performa pemain dan menyesuaikan jumlah musuh, amunisi yang tersedia, dan keagresifan musuh secara real-time. Jika pemain sering mati, game akan mengurangi jumlah musuh di area berikutnya dan meningkatkan drop amunisi. Sistem ini tidak diketahui pemain dan menjaga pengalaman tetap intens tanpa menjadi frustasi.
