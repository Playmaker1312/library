# 289. Memahami MDA Framework yaitu Mechanics Dynamics dan Aesthetics dalam desain game

## Definisi Singkat
MDA Framework adalah pendekatan analitis untuk memahami game dengan memecahnya menjadi tiga komponen: **Mechanics** (aturan dan sistem), **Dynamics** (perilaku emergent dari mechanics), dan **Aesthetics** (pengalaman emosional pemain). Framework ini membantu desainer memahami bagaimana desain teknis menciptakan pengalaman bermain.

## Analogi
Bayangkan memasak sebuah hidangan. **Mechanics** adalah bahan-bahan dan resep (tepung, gula, suhu oven). **Dynamics** adalah apa yang terjadi saat bahan-bahan itu berinteraksi (adonan mengembang, gula caramel). **Aesthetics** adalah rasa dan pengalaman makan hidangan tersebut (nikmat, puas, nostalgia). Seorang koki yang baik memahami bahwa memilih bahan yang tepat akan menghasilkan pengalaman makan yang diinginkan.

## Struktur Node (Scene Tree)
```
GameRoot (Node2D)
├── MechanicsLayer (Node)
│   ├── PlayerController (CharacterBody2D)
│   ├── EnemySpawner (Node2D)
│   └── ItemSystem (Node)
├── DynamicsLayer (Node)
│   ├── CollisionSystem (Area2D)
│   ├── ScoreTracker (Node)
│   └── WaveManager (Timer)
└── AestheticsLayer (CanvasLayer)
    ├── UIManager (Control)
    ├── ParticleEffects (GPUParticles2D)
    └── AudioManager (AudioStreamPlayer)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var score: int = 0
var combo_multiplier: float = 1.0
var enemies_defeated: int = 0
var player_health: float = 100.0

signal aesthetics_triggered(emotion: String, intensity: float)

func _on_enemy_defeated(enemy_type: String) -> void:
    enemies_defeated += 1
    var base_points: int = 100
    if enemy_type == "boss":
        base_points = 500
    score += int(base_points * combo_multiplier)
    _update_dynamics()
    _trigger_aesthetics("satisfaction", combo_multiplier / 5.0)

func _update_dynamics() -> void:
    if enemies_defeated % 10 == 0:
        combo_multiplier = min(combo_multiplier + 0.5, 5.0)
        aesthetics_triggered.emit("excitement", 0.8)
    if player_health < 30.0:
        combo_multiplier = max(combo_multiplier - 0.2, 1.0)
        aesthetics_triggered.emit("tension", 0.6)

func _trigger_aesthetics(emotion: String, intensity: float) -> void:
    var particles = get_node("../AestheticsLayer/ParticleEffects")
    var audio = get_node("../AestheticsLayer/AudioManager")
    match emotion:
        "satisfaction":
            particles.emitting = true
            audio.pitch_scale = 1.0 + intensity * 0.3
        "excitement":
            particles.amount = int(50 * intensity)
            audio.pitch_scale = 1.5
        "tension":
            particles.modulate = Color.RED
            audio.pitch_scale = 0.8
```

## Kasus Penggunaan Nyata
**Celeste** menggunakan MDA Framework untuk menciptakan pengalaman yang menantang namun memuaskan. Mechanics seperti dash dan wall-jump menciptakan dynamics di mana pemain harus menguasai ritme pergerakan, yang menghasilkan aesthetik sense of accomplishment saat berhasil melewati level yang sulit. Desainer secara sadar merancang setiap mekanik untuk menghasilkan emosi tertentu pada pemain.
