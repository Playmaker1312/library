# 290. Merancang game economy yang seimbang menggunakan spreadsheet dan iterasi

## Definisi Singkat
Game economy design adalah proses merancang sistem pertukaran nilai (mata uang, item, sumber daya) dalam game yang seimbang, adil, dan menarik. Menggunakan spreadsheet dan iterasi memungkinkan desainer memodelkan, menghitung, dan memvalidasi keseimbangan ekonomi sebelum implementasi.

## Analogi
Bayangkan mengelola toko roti. Anda perlu menentukan harga jual roti, biaya bahan baku, dan gaji karyawan. Jika harga terlalu mahal, pelanggan tidak beli. Jika terlalu murah, Anda rugi. Spreadsheet adalah buku catatan keuangan Anda untuk menghitung semua variabel, dan iterasi adalah mencoba harga yang berbeda setiap minggu hingga menemukan harga yang tepat di mana toko tetap untung dan pelanggan tetap puas.

## Struktur Node (Scene Tree)
```
EconomySystem (Node)
├── CurrencyManager (Node)
│   ├── SoftCurrency (int)
│   └── HardCurrency (int)
├── ItemDatabase (Resource)
│   ├── WeaponList (Array[ItemData])
│   └── ConsumableList (Array[ItemData])
├── ShopSystem (Control)
│   ├── ShopUI (Control)
│   └── InventoryUI (Control)
└── BalanceTracker (Node)
    ├── IncomeRate (float)
    └── SpendingRate (float)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

signal currency_changed(currency_type: String, new_amount: int)
signal item_purchased(item_id: String, cost: int)
signal balance_warning(message: String)

var soft_currency: int = 1000
var hard_currency: int = 50
var purchase_history: Array[Dictionary] = []

@export var item_database: Dictionary = {
    "health_potion": {"cost": 50, "type": "soft", "value": 20},
    "mana_potion": {"cost": 75, "type": "soft", "value": 15},
    "legendary_sword": {"cost": 500, "type": "soft", "value": 100},
    "premium_skin": {"cost": 10, "type": "hard", "value": 1}
}

func purchase_item(item_id: String) -> bool:
    if not item_database.has(item_id):
        return false
    var item: Dictionary = item_database[item_id]
    var cost: int = item["cost"]
    var currency_type: String = item["type"]
    if currency_type == "soft" and soft_currency >= cost:
        soft_currency -= cost
        currency_changed.emit("soft", soft_currency)
        item_purchased.emit(item_id, cost)
        _record_purchase(item_id, cost, currency_type)
        return true
    elif currency_type == "hard" and hard_currency >= cost:
        hard_currency -= cost
        currency_changed.emit("hard", hard_currency)
        item_purchased.emit(item_id, cost)
        _record_purchase(item_id, cost, currency_type)
        return true
    balance_warning.emit("Not enough currency for " + item_id)
    return false

func _record_purchase(item_id: String, cost: int, currency_type: String) -> void:
    purchase_history.append({
        "item": item_id,
        "cost": cost,
        "currency": currency_type,
        "timestamp": Time.get_unix_time_from_system()
    })

func get_economy_balance() -> Dictionary:
    var total_spent: int = 0
    var total_earned: int = 0
    for record in purchase_history:
        total_spent += record["cost"]
    return {
        "current_soft": soft_currency,
        "current_hard": hard_currency,
        "total_spent": total_spent,
        "total_purchases": purchase_history.size()
    }

func simulate_economy(iterations: int, earn_rate: int, spend_pattern: Array) -> void:
    for i in range(iterations):
        soft_currency += earn_rate
        for spend in spend_pattern:
            if soft_currency >= spend["cost"]:
                purchase_item(spend["item"])
    var result = get_economy_balance()
    print("Simulation result: ", result)
```

## Kasus Penggunaan Nyata
**Genshin Impact** menggunakan sistem economy dengan mata uang dual (Primogems dan Mora) yang dirancang melalui iterasi spreadsheet. Desainer menghitung berapa Primogems yang pemain dapatkan per hari dari daily commissions, quest, dan探索, lalu membandingkan dengan biaya gacha pulls. Setiap patch update dilakukan re-balancing berdasarkan data spreadsheet dan feedback pemain untuk memastikan free-to-play player tetap bisa progression tanpa merasa dipaksa spending.
