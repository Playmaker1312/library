# 296. Merancang Sistem Roguelike dengan Permadeath Progression dan Replayability

## Definisi Singkat
Sistem roguelike dengan permadeath berarti pemain kehilangan semua kemajuan saat mati, namun tetap ada progresi jangka panjang melalui unlockable content. Replayability dirancang agar setiap run terasa unik meskipun mekanik dasar tetap sama.

## Analogi
Bayangkan seperti bermain catur. Setiap kali kalah, papan di-reset, tetapi pengalaman dan strategi yang dipelajari tetap tersimpan. Semakin sering bermain, semakin banyak bukaan (opening) baru yang bisa dipilih, membuat permainan tetap menarik meskipun aturan dasarnya sama.

## Kode GDScript (Godot 4)
```gdscript
extends Node

class_name RunManager

signal run_started(run_data: Dictionary)
signal run_ended(run_data: Dictionary)
signal player_died()

var current_run: Dictionary = {}
var run_history: Array[Dictionary] = []

func start_new_run(seed_value: int = -1) -> void:
    current_run = {
        "seed": seed_value if seed_value >= 0 else randi(),
        "floor": 1,
        "rooms_cleared": 0,
        "enemies_killed": 0,
        "items_collected": [],
        "gold_earned": 0,
        "time_elapsed": 0.0,
        "build": {},
        "start_time": Time.get_unix_time_from_system()
    }
    emit_signal("run_started", current_run)

func end_run(victory: bool) -> void:
    current_run["victory"] = victory
    current_run["time_elapsed"] = Time.get_unix_time_from_system() - current_run["start_time"]
    run_history.append(current_run.duplicate())
    _apply_meta_rewards(current_run)
    emit_signal("run_ended", current_run)
    current_run = {}

func add_kill(enemy_data: Dictionary) -> void:
    current_run["enemies_killed"] += 1
    current_run["gold_earned"] += enemy_data.get("gold_reward", 0)

func add_item(item_data: Dictionary) -> void:
    current_run["items_collected"].append(item_data["id"])
    _update_build_synergies(item_data)

func advance_floor() -> void:
    current_run["floor"] += 1
    current_run["rooms_cleared"] += 1

func player_died_handler() -> void:
    emit_signal("player_died")
    end_run(false)

func _apply_meta_rewards(run_data: Dictionary) -> void:
    var meta = get_node("/root/Main/MetaProgression")
    var score = _calculate_score(run_data)
    meta.add_currency(score)
    meta.check_unlocks(run_data)

func _calculate_score(run_data: Dictionary) -> int:
    var score = 0
    score += run_data["enemies_killed"] * 10
    score += run_data["floor"] * 50
    score += run_data["gold_earned"]
    if run_data["victory"]:
        score *= 2
    return score

func _update_build_synergies(item_data: Dictionary) -> void:
    var item_id = item_data["id"]
    current_run["build"][item_id] = current_run["build"].get(item_id, 0) + 1
```

## Kasus Penggunaan Nyata
Hades menggunakan sistem ini dengan sempurna: setiap run berakhir saat mati, tetapi koin Darkness tetap tersimpan untuk membeli permanent upgrades di House of Hades. Sistem ini menciptakan siklus "mati → belajar → upgrade → coba lagi" yang sangat adiktif dan membuat pemain merasa selalu maju meskipun kalah berulang kali.
