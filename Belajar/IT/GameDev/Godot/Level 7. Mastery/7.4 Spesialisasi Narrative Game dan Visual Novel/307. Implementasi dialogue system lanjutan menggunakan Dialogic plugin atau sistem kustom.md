# 307. Implementasi Dialogue System Lanjutan Menggunakan Dialogic Plugin atau Sistem Kustom

## Definisi Singkat
Dialogue system adalah kerangka kerja untuk mengelola percakapan antar karakter dalam game, termasuk teks, pilihan, dan efek khusus. Dialogic adalah plugin populer untuk Godot yang menyediakan fitur lengkap untuk visual novel dan RPG dialogue.

## Analogi
Dialogue system seperti naskah teater digital di mana setiap baris dialog memiliki aktor (karakter), dialog, dan instruksi khusus. Dialogic seperti sutradara yang mengatur semua elemen pertunjukan secara otomatis.

## Struktur Node (Scene Tree)
```
DialogicSystem (Node)
├── PortraitContainer (Control)
│   ├── LeftPortrait (TextureRect)
│   ├── CenterPortrait (TextureRect)
│   └── RightPortrait (TextureRect)
├── DialogueBox (PanelContainer)
│   ├── NameLabel (Label)
│   └── DialogueLabel (RichTextLabel)
├── ChoicesContainer (VBoxContainer)
├── Timer (Timer)
└── AudioPlayer (AudioStreamPlayer)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

signal dialogue_started()
signal dialogue_ended()
signal choice_made(choice_id: String)

@onready var name_label: Label = %NameLabel
@onready var dialogue_label: RichTextLabel = %DialogueLabel
@onready var choices_container: VBoxContainer = %ChoicesContainer
@onready var portrait_left: TextureRect = %LeftPortrait
@onready var portrait_right: TextureRect = %RightPortrait
@onready var timer: Timer = %Timer
@onready var audio_player: AudioStreamPlayer = %AudioPlayer

var dialogue_queue: Array[Dictionary] = []
var current_dialogue: Dictionary = {}
var is_typing: bool = false
var full_text: String = ""
var char_index: int = 0
var type_speed: float = 0.03
var character_portraits: Dictionary = {}

func _ready() -> void:
    timer.wait_time = type_speed
    timer.timeout.connect(_on_timer_timeout)
    dialogue_label.visible_characters = 0

func start_dialogue(dialogue_data: Array[Dictionary]) -> void:
    dialogue_queue = dialogue_data
    dialogue_started.emit()
    _show_next_dialogue()

func _show_next_dialogue() -> void:
    if dialogue_queue.is_empty():
        dialogue_ended.emit()
        return
    
    current_dialogue = dialogue_queue.pop_front()
    name_label.text = current_dialogue.get("speaker", "")
    full_text = current_dialogue.get("text", "")
    dialogue_label.text = full_text
    dialogue_label.visible_characters = 0
    
    _update_portraits(current_dialogue.get("speaker", ""))
    _play_voice(current_dialogue.get("voice", ""))
    
    var choices = current_dialogue.get("choices", [])
    if choices.is_empty():
        _start_typing()
    else:
        _show_choices(choices)

func _start_typing() -> void:
    is_typing = true
    char_index = 0
    timer.start()

func _on_timer_timeout() -> void:
    if char_index < full_text.length():
        char_index += 1
        dialogue_label.visible_characters = char_index
    else:
        is_typing = false
        timer.stop()
        if current_dialogue.get("auto_advance", false):
            await get_tree().create_timer(current_dialogue.get("advance_delay", 1.0)).timeout
            _show_next_dialogue()

func skip_typing() -> void:
    if is_typing:
        timer.stop()
        dialogue_label.visible_characters = -1
        is_typing = false

func advance_dialogue() -> void:
    if is_typing:
        skip_typing()
    elif current_dialogue.get("choices", []).is_empty():
        _show_next_dialogue()

func _show_choices(choices: Array) -> void:
    for child in choices_container.get_children():
        child.queue_free()
    
    for i in range(choices.size()):
        var choice = choices[i]
        var button = Button.new()
        button.text = choice.get("text", "")
        button.pressed.connect(_on_choice_selected.bind(choice.get("id", str(i))))
        choices_container.add_child(button)

func _on_choice_selected(choice_id: String) -> void:
    for child in choices_container.get_children():
        child.queue_free()
    choice_made.emit(choice_id)
    _show_next_dialogue()

func _update_portraits(speaker: String) -> void:
    if character_portraits.has(speaker):
        portrait_left.texture = character_portraits[speaker]
    else:
        portrait_left.texture = null

func _play_voice(voice_path: String) -> void:
    if voice_path != "" and ResourceLoader.exists(voice_path):
        audio_player.stream = load(voice_path)
        audio_player.play()

func register_portrait(character_name: String, portrait: Texture2D) -> void:
    character_portraits[character_name] = portrait
```

## Kasus Penggunaan Nyata
Dialogic plugin digunakan dalam banyak game indie populer seperti "Cassette Beasts" dan "Blossom Tales". Plugin ini mendukung fitur seperti portrait animation, conditional branches, dan integrasi dengan sistem inventory. Untuk game yang membutuhkan kontrol penuh,许多 developer membangun sistem kustom yang disesuaikan dengan kebutuhan spesifik game mereka.
