# 306. Merancang Branching Narrative Menggunakan Grafik dan Tools Seperti Twine

## Definisi Singkat
Branching narrative adalah teknik penulisan cerita di mana pemain dapat membuat pilihan yang menghasilkan jalur cerita berbeda. Tools seperti Twine membantu merancang struktur cerita secara visual sebelum diimplementasikan di Godot.

## Analogi
Bayangkan sebuah buku "Pilih Petualanganmu" di mana setiap halaman memiliki beberapa pilihan. Twine seperti peta yang menunjukkan semua kemungkinan jalur di buku tersebut, sehingga penulis bisa melihat seluruh jaringan cerita dalam satu tampilan.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── StoryManager (Node) → mengelola state cerita
├── UI (CanvasLayer)
│   ├── DialogueBox (PanelContainer)
│   ├── NameLabel (Label)
│   ├── DialogueLabel (RichTextLabel)
│   └── ChoicesContainer (VBoxContainer)
│       ├── ChoiceButton1 (Button)
│       ├── ChoiceButton2 (Button)
│       └── ChoiceButton3 (Button)
└── Background (TextureRect)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var story_data: Dictionary = {}
var current_node: String = "start"
var variables: Dictionary = {}

signal node_changed(node_id: String)
signal story_ended()

func _ready() -> void:
    load_story()

func load_story() -> void:
    story_data = {
        "start": {
            "text": "Anda berdiri di persimpangan jalan. Kiri menuju hutan, kanan menuju kota.",
            "speaker": "Narrator",
            "choices": [
                {"text": "Pergi ke hutan", "target": "forest", "conditions": {}},
                {"text": "Pergi ke kota", "target": "city", "conditions": {}},
                {"text": "Periksa peta", "target": "check_map", "conditions": {"has_map": true}}
            ]
        },
        "forest": {
            "text": "Hutan gelap dan menyeramkan. Anda menemukan sebuah gua.",
            "speaker": "Narrator",
            "set_flags": {"visited_forest": true},
            "choices": [
                {"text": "Masuk gua", "target": "cave", "conditions": {}},
                {"text": "Kembali", "target": "start", "conditions": {}}
            ]
        },
        "city": {
            "text": "Kota ramai dengan pedagang. Seorang penjual mendekati Anda.",
            "speaker": "Merchant",
            "choices": [
                {"text": "Beli peta", "target": "buy_map", "conditions": {"gold": 10}},
                {"text": "Tolak", "target": "city_refuse", "conditions": {}}
            ]
        },
        "cave": {
            "text": "Anda menemukan harta karun di dalam gua!",
            "speaker": "Narrator",
            "set_flags": {"found_treasure": true},
            "choices": [
                {"text": "Ambil harta dan keluar", "target": "ending_good", "conditions": {}}
            ]
        },
        "buy_map": {
            "text": "Anda membeli peta. Sekarang Anda bisa menjelajahi lebih jauh.",
            "speaker": "Merchant",
            "set_variables": {"has_map": true, "gold": -10},
            "choices": [
                {"text": "Kembali ke persimpangan", "target": "start", "conditions": {}}
            ]
        },
        "ending_good": {
            "text": "Anda berhasil menemukan harta karun dan kembali dengan selamat!",
            "speaker": "Narrator",
            "is_ending": true,
            "choices": []
        }
    }

func get_current_data() -> Dictionary:
    if story_data.has(current_node):
        return story_data[current_node]
    return {}

func make_choice(choice_index: int) -> void:
    var data = get_current_data()
    if data.is_empty() or not data.has("choices"):
        return
    
    var choices = data["choices"]
    if choice_index < 0 or choice_index >= choices.size():
        return
    
    var choice = choices[choice_index]
    
    if not check_conditions(choice.get("conditions", {})):
        return
    
    if data.has("set_flags"):
        for flag in data["set_flags"]:
            variables[flag] = data["set_flags"][flag]
    
    if data.has("set_variables"):
        for var_name in data["set_variables"]:
            if variables.has(var_name):
                variables[var_name] += data["set_variables"][var_name]
            else:
                variables[var_name] = data["set_variables"][var_name]
    
    current_node = choice["target"]
    node_changed.emit(current_node)
    
    var new_data = get_current_data()
    if new_data.get("is_ending", false):
        story_ended.emit()

func check_conditions(conditions: Dictionary) -> bool:
    for key in conditions:
        if not variables.has(key):
            return false
        if variables[key] != conditions[key]:
            return false
    return true

func reset_story() -> void:
    current_node = "start"
    variables = {}
    node_changed.emit(current_node)
```

## Kasus Penggunaan Nyata
Twine sering digunakan oleh developer indie game untuk merancang cerita branching sebelum diintegrasikan ke Godot. Game seperti "Night in the Woods" dan "Oxenfree" menggunakan pendekatan serupa di mana narasi dibangun dari graf node yang saling terhubung. Dengan mengimport data dari Twine ke Godot melalui JSON, tim bisa bekerja sama antara penulis cerita dan programmer.
