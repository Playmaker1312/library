# 222. Membuat shader untuk efek forcefield atau shield menggunakan rim lighting

## Definisi Singkat
Forcefield atau shield shader menggunakan rim lighting untuk menciptakan efek护盾 yang bersinar di tepi objek, sering digunakan untuk shield karakter atau area proteksi.

## Analogi
Bayangkan sebuah lampu neon yang diletakkan di tepi sebuah kaca: cahaya terlihat paling terang di bagian tepi kaca, memberikan kesan护盾 yang bersinar dan transparan.

## Struktur Node (Scene Tree)
```
MeshInstance3D (Shield Mesh)
├── Mesh: SphereMesh atau CapsuleMesh
├── Material: ShaderMaterial
│   └── Shader: Forcefield Shader
└── AnimationPlayer (untuk animasi pulse)
```

## Kode GDScript (Godot 4)

### Forcefield Shader Code (save as .gdshader):
```glsl
shader_type spatial;
render_mode blend_add, cull_disabled, unshaded;

uniform vec4 rim_color : source_color = vec4(0.0, 0.8, 1.0, 1.0);
uniform float rim_power: hint_range(1.0, 10.0) = 3.0;
uniform float rim_intensity: hint_range(0.0, 5.0) = 2.0;
uniform float pulse_speed: hint_range(0.0, 5.0) = 1.0;
uniform float pulse_intensity: hint_range(0.0, 1.0) = 0.3;
uniform float fresnel_offset: hint_range(0.0, 1.0) = 0.0;
uniform sampler2D noise_texture : filter_linear_mipmap;
uniform float noise_speed: hint_range(0.0, 2.0) = 0.5;

void fragment() {
    // RIM LIGHTING EFFECT
    vec3 view_dir = normalize(VERTEX);
    float fresnel = pow(1.0 - max(dot(view_dir, NORMAL), 0.0), rim_power);
    fresnel = clamp(fresnel + fresnel_offset, 0.0, 1.0);
    
    // PULSE ANIMATION
    float pulse = sin(TIME * pulse_speed) * pulse_intensity + 1.0;
    
    // NOISE UNTUK VARIASI
    vec2 noise_uv = UV * 3.0 + TIME * noise_speed;
    float noise = texture(noise_texture, noise_uv).r;
    noise = noise * 0.3 + 0.7;
    
    // KOMBINASI EFFECT
    vec3 final_color = rim_color.rgb * fresnel * rim_intensity * pulse * noise;
    
    ALBEDO = final_color;
    ALPHA = fresnel * rim_color.a * noise;
    
    // PROPERTY
    ROUGHNESS = 1.0;
    METALLIC = 0.0;
    EMISSION = final_color;
    EMISSION_ENERGY = 1.5;
}
```

### GDScript Controller:
```gdscript
extends MeshInstance3D

@export var shield_color: Color = Color(0.0, 0.8, 1.0)
@export var shield_active: bool = true
@export var activation_speed: float = 2.0

var current_alpha: float = 0.0
var target_alpha: float = 1.0
var shader_mat: ShaderMaterial

func _ready():
    shader_mat = ShaderMaterial.new()
    shader_mat.shader = load("res://forcefield_shader.gdshader")
    shader_mat.set_shader_parameter("rim_color", shield_color)
    set_surface_override_material(0, shader_mat)

func _process(delta):
    if shield_active:
        target_alpha = 1.0
    else:
        target_alpha = 0.0
    
    current_alpha = lerp(current_alpha, target_alpha, delta * activation_speed)
    shader_mat.set_shader_parameter("rim_intensity", current_alpha * 2.0)

func activate_shield():
    shield_active = true

func deactivate_shield():
    shield_active = false

func set_shield_color(new_color: Color):
    shield_color = new_color
    if shader_mat:
        shader_mat.set_shader_parameter("rim_color", new_color)
```

## Kasus Penggunaan Nyata
Shield shader digunakan untuk efek pelindung karakter, barrier di game, atau objek yang terlindungi. Rim lighting memberikan efek护盾 yang bersinar di tepi, noise texture menambah variasi visual, dan animasi pulse membuat shield terlihat hidup.
