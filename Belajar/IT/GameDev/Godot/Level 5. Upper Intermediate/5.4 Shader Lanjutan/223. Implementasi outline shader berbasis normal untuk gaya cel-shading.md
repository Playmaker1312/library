# 223. Implementasi outline shader berbasis normal untuk gaya cel-shading

## Definisi Singkat
Outline shader berbasis normal menggunakan perbedaan normal antara objek untuk menciptakan garis tepi, menciptakan gaya cel-shading atau kartun yang khas.

## Analogi
Bayangkan seperti menggambar komik: setiap objek memiliki garis tepi yang tebal dan jelas, menciptakan ilusi kedalaman dan definisi bentuk yang kuat.

## Struktur Node (Scene Tree)
```
MeshInstance3D
├── Mesh: Model 3D (karakter/objek)
├── Material: ShaderMaterial (Outline)
│   └── Shader: Outline Shader
└── Surface Material Override (untuk mesh utama)
```

## Kode GDScript (Godot 4)

### Outline Shader Code (save as .gdshader):
```glsl
shader_type spatial;
render_mode cull_front, unshaded;

uniform vec4 outline_color : source_color = vec4(0.0, 0.0, 0.0, 1.0);
uniform float outline_width: hint_range(0.0, 0.1) = 0.02;
uniform bool use_normal_outline = true;
uniform float normal_threshold: hint_range(0.0, 1.0) = 0.5;

void vertex() {
    if (use_normal_outline) {
        // OUTLINE BERDASARKAN NORMAL
        vec3 outline_offset = NORMAL * outline_width;
        VERTEX += outline_offset;
    } else {
        // OUTLINE SIMPEL BERDASARKAN POSISI
        VERTEX *= 1.0 + outline_width;
    }
}

void fragment() {
    ALBEDO = outline_color.rgb;
    ALPHA = outline_color.a;
}
```

### Cel-Shading Shader (save as .gdshader):
```glsl
shader_type spatial;

uniform sampler2D albedo_texture : source_color, filter_linear_mipmap;
uniform sampler2D ramp_texture : source_color, filter_nearest;
uniform int color_bands: hint_range(2, 10) = 4;
uniform float shadow_threshold: hint_range(0.0, 1.0) = 0.5;

void fragment() {
    ALBEDO = texture(albedo_texture, UV).rgb;
    
    // QUANTIZE WARNA UNTUK CEL-SHADING
    float light_intensity = dot(NORMAL, normalize(vec3(1.0, 1.0, 1.0)));
    light_intensity = light_intensity * 0.5 + 0.5;
    
    float band = floor(light_intensity * float(color_bands)) / float(color_bands);
    ALBEDO *= mix(vec3(0.3, 0.3, 0.4), vec3(1.0, 1.0, 1.0), band);
    
    ROUGHNESS = 1.0;
    METALLIC = 0.0;
}
```

### GDScript Controller:
```gdscript
extends MeshInstance3D

@export var outline_color: Color = Color.BLACK
@export_range(0.0, 0.1) var outline_width: float = 0.02
@export var use_outline: bool = true

var outline_mat: ShaderMaterial
var cel_mat: ShaderMaterial

func _ready():
    if use_outline:
        outline_mat = ShaderMaterial.new()
        outline_mat.shader = load("res://outline_shader.gdshader")
        outline_mat.set_shader_parameter("outline_color", outline_color)
        outline_mat.set_shader_parameter("outline_width", outline_width)
        set_surface_override_material(0, outline_mat)
    
    cel_mat = ShaderMaterial.new()
    cel_mat.shader = load("res://cel_shader.gdshader")
    set_surface_override_material(1, cel_mat)

func set_outline_color(new_color: Color):
    outline_color = new_color
    if outline_mat:
        outline_mat.set_shader_parameter("outline_color", new_color)

func set_outline_width(new_width: float):
    outline_width = new_width
    if outline_mat:
        outline_mat.set_shader_parameter("outline_width", new_width)

func toggle_outline():
    use_outline = !use_outline
    if use_outline:
        set_surface_override_material(0, outline_mat)
    else:
        set_surface_override_material(0, null)
```

## Kasus Penggunaan Nyata
Outline shader digunakan untuk game bergaya kartun seperti Zelda: Wind Waker atau Borderlands. Cel-shading memberikan tampilan flat color dengan gradasi sederhana, menciptakan estetika 2D pada objek 3D yang sangat populer di game indie dan anime-style games.
