# 221. Implementasi shader efek air realistis dengan normal map animation

## Definisi Singkat
Shader efek air realistis menggunakan kombinasi normal map yang dianimasikan,refleksi, refraksi, dan foam untuk menciptakan tampilan air yang hidup dan dinamis.

## Analogi
Bayangkan melihat permukaan kolam: air tidak diam tetapi selalu bergerak, memantulkan cahaya, dan membiarkan objek di bawahnya terlihat sedikit bengkok karena pembiasan cahaya.

## Struktur Node (Scene Tree)
```
MeshInstance3D (Water Plane)
├── Mesh: PlaneMesh (size besar)
└── Material: ShaderMaterial
    └── Shader: Water Shader
        ├── normal_map_1: Texture2D
        ├── normal_map_2: Texture2D
        ├── foam_texture: Texture2D
        └── Environment: WorldEnvironment
```

## Kode GDScript (Godot 4)

### Water Shader Code (save as .gdshader):
```glsl
shader_type spatial;

uniform sampler2D normal_map_1 : filter_linear_mipmap;
uniform sampler2D normal_map_2 : filter_linear_mipmap;
uniform sampler2D foam_texture : filter_linear_mipmap;

uniform vec4 deep_color : source_color = vec4(0.0, 0.1, 0.3, 1.0);
uniform vec4 shallow_color : source_color = vec4(0.0, 0.5, 0.7, 1.0);
uniform float normal_speed_1: hint_range(0.0, 2.0) = 0.5;
uniform float normal_speed_2: hint_range(0.0, 2.0) = 0.3;
uniform float normal_scale: hint_range(0.0, 10.0) = 1.0;
uniform float foam_threshold: hint_range(0.0, 1.0) = 0.8;
uniform float fresnel_power: hint_range(1.0, 10.0) = 4.0;

void fragment() {
    // ANIMASI NORMAL MAP
    vec2 uv1 = UV * normal_scale + TIME * normal_speed_1 * vec2(0.1, 0.05);
    vec2 uv2 = UV * normal_scale * 1.3 + TIME * normal_speed_2 * vec2(-0.05, 0.1);
    
    vec3 normal1 = texture(normal_map_1, uv1).rgb * 2.0 - 1.0;
    vec3 normal2 = texture(normal_map_2, uv2).rgb * 2.0 - 1.0;
    
    vec3 combined_normal = normalize(normal1 + normal2);
    NORMAL_MAP = combined_normal;
    
    // WARNA AIR BERDASARKAN KEDALAMAN
    float depth_factor = clamp(dot(normalize(VERTEX), vec3(0.0, 1.0, 0.0)), 0.0, 1.0);
    ALBEDO = mix(deep_color.rgb, shallow_color.rgb, depth_factor);
    
    // FOAM DI TEPI
    float foam = 1.0 - smoothstep(0.0, foam_threshold, depth_factor);
    vec3 foam_color = texture(foam_texture, UV * 5.0).rgb;
    ALBEDO = mix(ALBEDO, foam_color, foam * 0.5);
    
    // FRESNEL UNTUK REFLEKSI
    float fresnel = pow(1.0 - max(dot(normalize(VERTEX), NORMAL), 0.0), fresnel_power);
    ALBEDO = mix(ALBEDO, vec3(0.9, 0.95, 1.0), fresnel * 0.6);
    
    // PROPERTY MATERIAL
    ROUGHNESS = 0.1;
    METALLIC = 0.0;
    ALPHA = 0.85;
}
```

### GDScript Controller:
```gdscript
extends MeshInstance3D

@export var normal1_tex: Texture2D
@export var normal2_tex: Texture2D
@export var foam_tex: Texture2D
@export var wave_speed: float = 1.0
@export var deep_water_color: Color = Color(0.0, 0.1, 0.3)
@export var shallow_water_color: Color = Color(0.0, 0.5, 0.7)

func _ready():
    var mat = ShaderMaterial.new()
    mat.shader = load("res://water_shader.gdshader")
    
    if normal1_tex:
        mat.set_shader_parameter("normal_map_1", normal1_tex)
    if normal2_tex:
        mat.set_shader_parameter("normal_map_2", normal2_tex)
    if foam_tex:
        mat.set_shader_parameter("foam_texture", foam_tex)
    
    mat.set_shader_parameter("deep_color", deep_water_color)
    mat.set_shader_parameter("shallow_color", shallow_water_color)
    mat.set_shader_parameter("normal_speed_1", wave_speed)
    
    set_surface_override_material(0, mat)

func set_water_depth(depth: float):
    var mat = get_surface_override_material(0) as ShaderMaterial
    if mat:
        mat.set_shader_parameter("foam_threshold", 1.0 - depth)
```

## Kasus Penggunaan Nyata
Efek air realistis digunakan untuk game laut, sungai, atau kolam. Normal map animation memberikan gelombang tanpa mengubah geometri, foam menambah realisme di tepi air, dan fresnel memberikan efek pantulan cahaya yang natural.
