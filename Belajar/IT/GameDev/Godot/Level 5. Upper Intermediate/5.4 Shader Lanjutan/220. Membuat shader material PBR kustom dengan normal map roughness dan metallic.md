# 220. Membuat shader material PBR kustom dengan normal map roughness dan metallic

## Definisi Singkat
PBR (Physically Based Rendering) adalah teknik rendering yang mensimulasikan interaksi cahaya secara realistis menggunakan parameter normal map, roughness, dan metallic untuk menciptakan material yang realistis.

## Analogi
Seperti seorang pelukis realistis yang menggunakan berbagai teknik: normal map adalah Tekstur permukaan, roughness adalah seberapa berkilau atau buram permukaan, dan metallic adalah apakah material tersebut logam atau non-logam.

## Struktur Node (Scene Tree)
```
MeshInstance3D
├── Mesh: CylinderMesh atau Model 3D
└── Material: ShaderMaterial
    └── Shader: PBR Shader
        ├── albedo_texture: Texture2D
        ├── normal_texture: Texture2D
        ├── roughness_texture: Texture2D
        └── metallic_texture: Texture2D
```

## Kode GDScript (Godot 4)

### PBR Shader Code (save as .gdshader):
```glsl
shader_type spatial;

uniform sampler2D albedo_texture : source_color, filter_linear_mipmap;
uniform sampler2D normal_texture : filter_linear_mipmap;
uniform sampler2D roughness_texture : filter_linear_mipmap;
uniform sampler2D metallic_texture : filter_linear_mipmap;

uniform float normal_strength : hint_range(0.0, 2.0) = 1.0;
uniform float roughness_multiplier : hint_range(0.0, 2.0) = 1.0;
uniform float metallic_multiplier : hint_range(0.0, 2.0) = 1.0;

void fragment() {
    // ALBEDO (WARNA DASAR)
    ALBEDO = texture(albedo_texture, UV).rgb;
    
    // NORMAL MAP UNTUK DETAIL PERMUKAAN
    vec3 normal = texture(normal_texture, UV).rgb;
    normal = normal * 2.0 - 1.0;
    normal.xy *= normal_strength;
    NORMAL_MAP = normal;
    
    // ROUGHNESS (KEKASARAN PERMUKAAN)
    ROUGHNESS = texture(roughness_texture, UV).r * roughness_multiplier;
    
    // METALLIC (SIFAT LOGAM)
    METALLIC = texture(metallic_texture, UV).r * metallic_multiplier;
    
    // AMBIENT OCCLUSION (opsional)
    AO = texture(roughness_texture, UV).a;
    
    // SMOOTHNESS INVERSE
    SPECULAR = 0.5;
}
```

### GDScript Controller:
```gdscript
extends MeshInstance3D

@export var albedo_tex: Texture2D
@export var normal_tex: Texture2D
@export var roughness_tex: Texture2D
@export var metallic_tex: Texture2D
@export_range(0.0, 2.0) var normal_strength: float = 1.0
@export_range(0.0, 2.0) var roughness_mult: float = 1.0
@export_range(0.0, 2.0) var metallic_mult: float = 1.0

func _ready():
    var mat = ShaderMaterial.new()
    mat.shader = load("res://pbr_shader.gdshader")
    
    if albedo_tex:
        mat.set_shader_parameter("albedo_texture", albedo_tex)
    if normal_tex:
        mat.set_shader_parameter("normal_texture", normal_tex)
    if roughness_tex:
        mat.set_shader_parameter("roughness_texture", roughness_tex)
    if metallic_tex:
        mat.set_shader_parameter("metallic_texture", metallic_tex)
    
    mat.set_shader_parameter("normal_strength", normal_strength)
    mat.set_shader_parameter("roughness_multiplier", roughness_mult)
    mat.set_shader_parameter("metallic_multiplier", metallic_mult)
    
    set_surface_override_material(0, mat)
```

## Kasus Penggunaan Nyata
PBR shader digunakan untuk membuat material realistis seperti metal berkarat, kayu dengan tekstur, atau permukaan batu. Normal map memberikan detail tanpa menambah geometri, roughness mengontrol pantulan cahaya, dan metallic menentukan sifat logam material.
