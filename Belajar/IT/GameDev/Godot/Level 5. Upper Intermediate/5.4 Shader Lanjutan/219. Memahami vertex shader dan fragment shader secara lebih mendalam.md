# 219. Memahami vertex shader dan fragment shader secara lebih mendalam

## Definisi Singkat
Vertex shader adalah program yang berjalan di GPU untuk memproses setiap vertex (titik sudut) dari mesh, sedangkan fragment shader menentukan warna setiap pixel yang ditampilkan di layar.

## Analogi
Bayangkan sebuah pabrik roti: vertex shader adalah tukang yang membentuk adonan menjadi bentuk roti, sedangkan fragment shader adalah pemberi warna dan hiasan pada permukaan roti tersebut.

## Struktur Node (Scene Tree)
```
MeshInstance3D (dengan ShaderMaterial)
├── Mesh: QuadMesh atauPrimitiveMesh lainnya
└── Material: ShaderMaterial
    └── Shader: Shader (dengan kode GLSL)
```

## Kode GDScript (Godot 4)

### Vertex Shader Example (dalam shader code):
```glsl
shader_type spatial;

void vertex() {
    // MODIFIKASI POSISI VERTEX
    VERTEX.y += sin(TIME + VERTEX.x * 2.0) * 0.1;
    
    // MODIFIKASI NORMAL UNTUK PENCAHAYAAN
    NORMAL = normalize(NORMAL + vec3(0.0, sin(TIME + VERTEX.x), 0.0));
    
    // MODIFIKASI UV COORDINATE
    UV = VERTEX.xy * 0.5 + 0.5;
}

void fragment() {
    // AMBIL WARNA BERDASARKAN UV
    ALBEDO = vec3(UV.x, UV.y, 0.5);
    
    // ATUR PROPERTY MATERIAL
    ROUGHNESS = 0.8;
    METALLIC = 0.2;
}
```

### GDScript Controller:
```gdscript
extends MeshInstance3D

@export var wave_speed: float = 2.0
@export var wave_height: float = 0.1

func _ready():
    var material = get_surface_override_material(0)
    if material == null:
        material = ShaderMaterial.new()
        material.shader = load("res://wave_shader.gdshader")
        set_surface_override_material(0, material)

func _process(delta):
    var material = get_surface_override_material(0)
    if material is ShaderMaterial:
        material.set_shader_parameter("wave_speed", wave_speed)
        material.set_shader_parameter("wave_height", wave_height)
```

## Kasus Penggunaan Nyata
Vertex shader digunakan untuk membuat animasi air bergelombang, efek bendera berkibar, atau deformasi karakter. Fragment shader digunakan untuk membuat efek visual seperti glass, metal, atau efek post-processing di layar.
