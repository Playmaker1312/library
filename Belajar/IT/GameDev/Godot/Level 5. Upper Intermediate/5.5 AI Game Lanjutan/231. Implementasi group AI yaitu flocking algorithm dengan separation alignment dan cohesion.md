# 231. Implementasi group AI yaitu flocking algorithm dengan separation alignment dan cohesion

## Definisi Singkat
Flocking Algorithm adalah teknik AI yang meniru perilaku kelompok makhluk seperti burung atau ikan dengan menggabungkan tiga aturan dasar: Separation (menjaga jarak antar individu), Alignment (menyesuaikan arah gerak dengan kelompok), dan Cohesion (bergerak ke arah pusat kelompok).

## Analogi
Bayangkan sekawanan burung yang terbang bersama. Burung tidak menabrak satu sama lain karena menjaga jarak (Separation). Mereka terbang ke arah yang sama karena menyesuaikan kecepatan dan arah dengan burung di sekitarnya (Alignment). Dan mereka tetap berkumpul karena tertarik ke pusat kawanan (Cohesion). Tiga aturan sederhana ini menciptakan perilaku kelompok yang kompleks dan natural.

## Kode GDScript (Godot 4)
```gdscript
class_name Boid
extends CharacterBody3D

@export var max_speed: float = 5.0
@export var max_force: float = 0.5
@export var separation_radius: float = 3.0
@export var alignment_radius: float = 8.0
@export var cohesion_radius: float = 10.0
@export var separation_weight: float = 2.0
@export var alignment_weight: float = 1.0
@export var cohesion_weight: float = 1.0

var neighbors: Array[Boid] = []

func _ready() -> void:
    add_to_group("boids")

func _physics_process(delta: float) -> void:
    find_neighbors()
    var sep: Vector3 = separate()
    var ali: Vector3 = align()
    var coh: Vector3 = cohesion()
    
    sep *= separation_weight
    ali *= alignment_weight
    coh *= cohesion_weight
    
    var steering: Vector3 = sep + ali + coh
    steering = steering.limit_length(max_force)
    
    velocity += steering
    velocity = velocity.limit_length(max_speed)
    
    move_and_slide()
    
    if velocity.length() > 0.1:
        look_at(global_position + velocity.normalized(), Vector3.UP)

func find_neighbors() -> void:
    neighbors.clear()
    var all_boids: Array[Node] = get_tree().get_nodes_in_group("boids")
    for boid in all_boids:
        if boid == self:
            continue
        if boid is Boid:
            var distance: float = global_position.distance_to(boid.global_position)
            if distance < cohesion_radius:
                neighbors.append(boid)

func separate() -> Vector3:
    var steer: Vector3 = Vector3.ZERO
    var count: int = 0
    
    for neighbor in neighbors:
        var distance: float = global_position.distance_to(neighbor.global_position)
        if distance < separation_radius and distance > 0:
            var diff: Vector3 = global_position - neighbor.global_position
            diff = diff.normalized() / distance
            steer += diff
            count += 1
    
    if count > 0:
        steer /= count
        steer = steer.normalized() * max_speed
        steer -= velocity
        steer = steer.limit_length(max_force)
    
    return steer

func align() -> Vector3:
    var sum: Vector3 = Vector3.ZERO
    var count: int = 0
    
    for neighbor in neighbors:
        var distance: float = global_position.distance_to(neighbor.global_position)
        if distance < alignment_radius:
            sum += neighbor.velocity
            count += 1
    
    if count > 0:
        sum /= count
        sum = sum.normalized() * max_speed
        var steer: Vector3 = sum - velocity
        return steer.limit_length(max_force)
    
    return Vector3.ZERO

func cohesion() -> Vector3:
    var sum: Vector3 = Vector3.ZERO
    var count: int = 0
    
    for neighbor in neighbors:
        var distance: float = global_position.distance_to(neighbor.global_position)
        if distance < cohesion_radius:
            sum += neighbor.global_position
            count += 1
    
    if count > 0:
        sum /= count
        var desired: Vector3 = sum - global_position
        desired = desired.normalized() * max_speed
        var steer: Vector3 = desired - velocity
        return steer.limit_length(max_force)
    
    return Vector3.ZERO
```

## Kasus Penggunaan Nyata
Flocking Algorithm digunakan dalam game seperti Alien Swarm untuk pergerakan gerombolan alien, game simulasi laut untuk kawanan ikan, atau game strategi untuk pasukan unit yang bergerak secara kelompok. Di game FPS seperti Left 4 Dead, zombie menggunakan flocking untuk mengejar player secara massal sambil tetap menjaga formasi.
