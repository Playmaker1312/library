# 226. Memahami Behavior Tree sebagai arsitektur AI yang lebih fleksibel dari State Machine

## Definisi Singkat
Behavior Tree adalah arsitektur AI berbasis pohon hierarkis yang mengeksekusi child nodes dari kiri ke kanan dengan sistem priorititas yang jelas. Berbeda dari State Machine yang state-driven, Behavior Tree menggunakan composisi node (Selector, Sequence) untuk menentukan aksi AI secara deklaratif dan mudah diubah.

## Analogi
Bayangkan kamu adalah manajer restoran yang memiliki daftar tugas untuk karyawan. Alih-alih mengatakan "jika pelanggan datang, lakukan X; jika hujan, lakukan Y" (seperti State Machine), kamu membuat daftar prioritas: "coba layani pelanggan (Sequence: ambil pesanan → masak → sajikan). Jika tidak ada pelanggan, bersihkan meja. Jika semua selesai, istirahat." Setiap tugas adalah node dalam pohon yang dievaluasi secara hierarkis.

## Struktur Node (Scene Tree)
```
BehaviorTree (Node)
├── Root (Node)
│   └── Selector
│       ├── Sequence: Patrol
│       │   ├── Condition: IsPatrolPointAvailable
│       │   └── Action: MoveToPatrolPoint
│       ├── Sequence: Chase
│       │   ├── Condition: IsPlayerVisible
│       │   └── Action: ChasePlayer
│       └── Sequence: Idle
│           └── Action: IdleAnimation
```

## Kode GDScript (Godot 4)
```gdscript
class_name BehaviorTree
extends Node

enum State { RUNNING, SUCCESS, FAILURE }

class BTNode:
    var state: State = State.FAILURE
    
    func tick(delta: float) -> State:
        return State.FAILURE

class BTAction extends BTNode:
    var actor: Node3D
    var blackboard: Dictionary
    
    func tick(delta: float) -> State:
        return State.SUCCESS

class BTCondition extends BTNode:
    func tick(delta: float) -> State:
        return State.SUCCESS

class BTSequence extends BTNode:
    var children: Array[BTNode] = []
    var current_index: int = 0
    
    func tick(delta: float) -> State:
        while current_index < children.size():
            var result: State = children[current_index].tick(delta)
            if result == State.RUNNING:
                return State.RUNNING
            if result == State.FAILURE:
                current_index = 0
                return State.FAILURE
            current_index += 1
        current_index = 0
        return State.SUCCESS

class BTSelector extends BTNode:
    var children: Array[BTNode] = []
    
    func tick(delta: float) -> State:
        for child in children:
            var result: State = child.tick(delta)
            if result == State.RUNNING:
                return State.RUNNING
            if result == State.SUCCESS:
                return State.SUCCESS
        return State.FAILURE

var root: BTSelector = BTSelector.new()

func _ready() -> void:
    setup_tree()

func _process(delta: float) -> void:
    root.tick(delta)

func setup_tree() -> void:
    pass
```

## Kasus Penggunaan Nyata
Behavior Tree banyak digunakan dalam game AAA seperti FPS dan RPG untuk AI musuh yang kompleks. Contohnya, musuh di game stealth dapat menggunakan Behavior Tree untuk memutuskan apakah harus patrol, mengejar player, atau mencari tempat bersembunyi berdasarkan kondisi lingkungan secara real-time. Arsitektur ini juga memudahkan desainer game untuk memodifikasi perilaku AI tanpa mengubah kode secara signifikan.
