# 230. Membuat AI dengan field of view dan hearing radius untuk deteksi player

## Definisi Singkat
Field of View (FOV) adalah sudut pandang vertikal atau horizontal yang menentukan area di mana AI bisa melihat objek, sedangkan hearing radius adalah jarak maksimal di mana AI bisa mendengar suara. Kombinasi keduanya menciptakan sistem pendeteksian multi-indra yang realistis.

## Analogi
Bayangkan kamu berdiri di lapangan. Kamu bisa melihat benda di depan dalam sudut pandang tertentu (seperti kacamata yang tidak bisa melihat ke belakang), tapi kamu juga bisa mendengar suara dari segala arah dalam radius tertentu. AI dengan FOV dan hearing radius bekerja seperti manusia - melihat hanya di area tertentu tapi mendengar dari berbagai arah.

## Struktur Node (Scene Tree)
```
GuardAI (CharacterBody3D)
├── Head (Node3D) [untuk rotasi pandangan]
│   ├── MeshInstance3D [visual FOV cone]
│   └── RayCast3D [line of sight check]
├── HearingArea (Area3D)
│   └── CollisionShape3D [sphere]
├── CollisionShape3D
└── Sprite3D
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

@export var fov_angle: float = 90.0
@export var view_distance: float = 20.0
@export var hearing_radius: float = 15.0
@export var player_path: NodePath

var head: Node3D
var ray_cast: RayCast3D
var hearing_area: Area3D
var player: Node3D
var can_see_player: bool = false
var can_hear_player: bool = false

func _ready() -> void:
    head = $Head
    ray_cast = $Head/RayCast3D
    hearing_area = $HearingArea
    player = get_node(player_path) if player_path else null
    hearing_area.body_entered.connect(_on_hearing_area_body_entered)
    hearing_area.body_exited.connect(_on_hearing_area_body_exited)

func _process(delta: float) -> void:
    check_line_of_sight()

func check_line_of_sight() -> void:
    can_see_player = false
    if not player:
        return
    
    var to_player: Vector3 = player.global_position - global_position
    var distance: float = to_player.length()
    
    if distance > view_distance:
        return
    
    var forward: Vector3 = -head.global_transform.basis.z
    var direction_to_player: Vector3 = to_player.normalized()
    var angle: float = rad_to_deg(forward.angle_to(direction_to_player))
    
    if angle > fov_angle / 2.0:
        return
    
    ray_cast.target_position = to_player
    ray_cast.force_raycast_update()
    
    if ray_cast.is_colliding() and ray_cast.get_collider() == player:
        can_see_player = true

func is_player_in_fov() -> bool:
    return can_see_player

func is_player_in_hearing_range() -> bool:
    return can_hear_player

func get_player_direction() -> Vector3:
    if player:
        return (player.global_position - global_position).normalized()
    return Vector3.ZERO

func get_distance_to_player() -> float:
    if player:
        return global_position.distance_to(player.global_position)
    return INF

func _on_hearing_area_body_entered(body: Node3D) -> void:
    if body == player:
        can_hear_player = true

func _on_hearing_area_body_exited(body: Node3D) -> void:
    if body == player:
        can_hear_player = false

func alert_state() -> String:
    if can_see_player:
        return "alert_visual"
    if can_hear_player:
        return "alert_audio"
    return "patrol"
```

## Kasus Penggunaan Nyata
Sistem ini digunakan dalam game stealth seperti Metal Gear Solid dan Hitman di mana musuh memiliki zona penglihatan锥形 dan dapat mendengar langkah kaki. Di game horror seperti Amnesia, AI menggunakan hearing untuk mendeteksi pemain yang berlari, menciptakan ketegangan karena pemain harus bergerak pelan agar tidak terdeteksi.
