# 229. Implementasi sistem Steering Behaviors yaitu seek flee arrive dan wander

## Definisi Singkat
Steering Behaviors adalah kumpulan algoritma yang menghasilkan gerakan alami dan otonom untuk karakter dengan menghitung vektor steering (gaya kemudi) berdasarkan posisi target, kecepatan saat ini, dan parameter lingkungan. Implementasi ini mencakup empat behavior utama: Seek, Flee, Arrive, dan Wander.

## Analogi
Bayangkan kamu mengemudi mobil. Saat kamu ingin mengejar seseorang (Seek), kamu belok ke arah mereka. Saat kamu ingin menjauh (Flee), kamu belok ke arah berlawanan. Saat akan parkir (Arrive), kamu memperlambat perlahan. Saat jalan-jalan santai tanpa tujuan (Wander), kamu berbelok secara acak. Steering Behaviors meniru cara manusia mengemudi secara natural.

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

@export var max_speed: float = 10.0
@export var max_force: float = 5.0
@export var wander_distance: float = 4.0
@export var wander_angle_change: float = 0.3
@export var arrival_slow_radius: float = 5.0

var position: Vector2 = Vector2.ZERO
var velocity: Vector2 = Vector2.ZERO
var target: Vector2 = Vector2.ZERO
var wander_angle: float = 0.0

func _ready() -> void:
    position = Vector2(global_position.x, global_position.z)

func _physics_process(delta: float) -> void:
    pass

func seek(target_pos: Vector2) -> Vector2:
    var desired: Vector2 = (target_pos - position).normalized() * max_speed
    var steer: Vector2 = (desired - velocity).normalized() * max_force
    return steer

func flee(target_pos: Vector2) -> Vector2:
    var desired: Vector2 = (position - target_pos).normalized() * max_speed
    var steer: Vector2 = (desired - velocity).normalized() * max_force
    return steer

func arrive(target_pos: Vector2) -> Vector2:
    var to_target: Vector2 = target_pos - position
    var distance: float = to_target.length()
    var desired: Vector2
    
    if distance < arrival_slow_radius:
        desired = to_target.normalized() * max_speed * (distance / arrival_slow_radius)
    else:
        desired = to_target.normalized() * max_speed
    
    var steer: Vector2 = (desired - velocity).normalized() * max_force
    return steer

func wander() -> Vector2:
    var circle_center: Vector2 = velocity.normalized() * wander_distance
    var displacement: Vector2 = Vector2(cos(wander_angle), sin(wander_angle))
    wander_angle += (randf() - 0.5) * wander_angle_change
    return (circle_center + displacement).normalized() * max_force

func apply_steering(steer: Vector2, delta: float) -> void:
    velocity += steer
    if velocity.length() > max_speed:
        velocity = velocity.normalized() * max_speed
    position += velocity * delta
    global_position = Vector3(position.x, global_position.y, position.y)

func calculate_steering(target_pos: Vector2, behavior: String) -> Vector2:
    match behavior:
        "seek":
            return seek(target_pos)
        "flee":
            return flee(target_pos)
        "arrive":
            return arrive(target_pos)
        "wander":
            return wander()
        _:
            return Vector2.ZERO
```

## Kasus Penggunaan Nyata
Steering Behaviors digunakan dalam game racing untuk mobil AI yang mengejar target tanpa overshoot, game survival untuk zombie yang mengejar player secara natural, atau game simulasi seperti Spore untuk makhluk yang bergerak otonom. Behavior Wander sering digunakan untuk NPC di game open-world yang terlihat hidup dan tidak statis.
