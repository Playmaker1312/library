# 227. Implementasi Behavior Tree sederhana menggunakan Resource dan GDScript

## Definisi Singkat
Behavior Tree dapat diimplementasikan menggunakan sistem Resource Godot sehingga setiap node AI bisa dibuat sebagai resource yang reusable dan bisa diedit di Inspector tanpa mengubah kode. Pendekatan ini memisahkan data perilaku dari logika eksekusi.

## Analogi
Bayangkan kamu membuat resep masakan. Setiap bahan (Resource) seperti "Tepung", "Gula", "Telur" memiliki properti sendiri. Resep (BehaviorTree) menggabungkan bahan-bahan ini dalam urutan tertentu. Kamu bisa membuat "Kue Coklat" dan "Kue Vanila" menggunakan bahan yang sama tapi dengan pengaturan berbeda, tanpa harus membuat ulang bahan dari awal.

## Struktur Node (Scene Tree)
```
AICharacter (CharacterBody3D)
├── BehaviorTreePlayer (Node)
│   ├── Root (BTSelector)
│   │   ├── PatrolSequence (BTSequence)
│   │   │   ├── HasPatrolPoints (BTCondition)
│   │   │   └── MoveToPatrol (BTAction)
│   │   └── IdleAction (BTAction)
├── NavigationAgent3D
└── Sprite3D
```

## Kode GDScript (Godot 4)
```gdscript
class_name BTActionResource
extends Resource

@export var action_name: String = ""

func tick(actor: Node3D, blackboard: Dictionary, delta: float) -> int:
    return 0

func setup(actor: Node3D, blackboard: Dictionary) -> void:
    pass

class_name BTConditionResource
extends Resource

@export var condition_name: String = ""

func evaluate(actor: Node3D, blackboard: Dictionary) -> bool:
    return false

class_name BTSequenceResource
extends Resource

@export var children: Array[Resource] = []

func tick(actor: Node3D, blackboard: Dictionary, delta: float) -> int:
    for child in children:
        if child is BTSequenceResource:
            var result = child.tick(actor, blackboard, delta)
            if result != 0:
                return result
        elif child is BTConditionResource:
            if not child.evaluate(actor, blackboard):
                return 2
        elif child is BTActionResource:
            var result = child.tick(actor, blackboard, delta)
            if result != 0:
                return result
    return 0

class_name BTSelectorResource
extends Resource

@export var children: Array[Resource] = []

func tick(actor: Node3D, blackboard: Dictionary, delta: float) -> int:
    for child in children:
        if child is BTSelectorResource:
            var result = child.tick(actor, blackboard, delta)
            if result != 0:
                return result
        elif child is BTSequenceResource:
            var result = child.tick(actor, blackboard, delta)
            if result != 0:
                return result
    return 2

class_name BehaviorTreeRunner
extends Node

@export var tree_root: Resource
@export var actor_path: NodePath
var actor: Node3D
var blackboard: Dictionary = {}

func _ready() -> void:
    actor = get_node(actor_path)

func _process(delta: float) -> void:
    if tree_root:
        tree_root.tick(actor, blackboard, delta)
```

## Kasus Penggunaan Nyata
Pendekatan Resource-based memungkinkan desainer game membuat variasi AI musuh tanpa coding. Sebuah studio game indie bisa membuat 5 jenis musuh berbeda hanya dengan mengatur Resource di Inspector: satu musuh agresif dengan sequence "deteksi→kejar→serang", satu musuh defensif dengan "patrol→deteksi→kembali". Setiap konfigurasi bisa di-save dan di-load sebagai scene berbeda.
