# 228. Membuat AI yang menggunakan NavigationAgent3D untuk pathfinding di lingkungan 3D

## Definisi Singkat
NavigationAgent3D adalah node Godot yang menyediakan pathfinding otomatis untuk karakter 3D menggunakan NavigationServer. Agent ini menangani perhitungan jalur terpendek, penghindaran rintangan statis, dan dapat dikonfigurasi dengan parameter seperti radius dan kecepatan maksimal.

## Analogi
Bayangkan kamu menggunakan Google Maps di kota baru. Kamu memberikan titik awal dan tujuan, lalu aplikasi menunjukkan rute terbaik sambil memperhitungkan jalan yang macet, jalan one-way, dan area yang tidak bisa dilalui. NavigationAgent3D bekerja persis seperti itu untuk AI di dunia game - menemukan jalur terbaik melewati rintangan.

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

@export var speed: float = 5.0
@export var patrol_points: Array[Vector3] = []
@export var wait_time: float = 2.0

var navigation_agent: NavigationAgent3D
var current_patrol_index: int = 0
var is_waiting: bool = false
var wait_timer: float = 0.0

func _ready() -> void:
    navigation_agent = $NavigationAgent3D
    navigation_agent.path_desired_distance = 1.0
    navigation_agent.target_desired_distance = 1.5
    if patrol_points.size() > 0:
        set_target_position(patrol_points[0])

func _physics_process(delta: float) -> void:
    if is_waiting:
        wait_timer -= delta
        if wait_timer <= 0.0:
            is_waiting = false
            move_to_next_patrol_point()
        return
    
    if navigation_agent.is_navigation_finished():
        on_reached_point()
        return
    
    var next_path_position: Vector3 = navigation_agent.get_next_path_position()
    var direction: Vector3 = (next_path_position - global_position).normalized()
    
    velocity = direction * speed
    move_and_slide()
    
    if direction.length() > 0.1:
        look_at(global_position + direction, Vector3.UP)

func set_target_position(target_pos: Vector3) -> void:
    navigation_agent.target_position = target_pos

func on_reached_point() -> void:
    is_waiting = true
    wait_timer = wait_time

func move_to_next_patrol_point() -> void:
    if patrol_points.size() == 0:
        return
    current_patrol_index = (current_patrol_index + 1) % patrol_points.size()
    set_target_position(patrol_points[current_patrol_index])

func chase_target(target_pos: Vector3) -> void:
    set_target_position(target_pos)

func get_distance_to_target() -> float:
    return navigation_agent.distance_to_target()
```

## Kasus Penggunaan Nyata
NavigationAgent3D digunakan dalam game RPG dan strategy untuk NPC merchant yang berjalan antar kota, musuh yang mengejar player melewati labirin, atau companion yang mengikuti player tanpa tersangkut. Game seperti Skyrim dan Assassin's Creed menggunakan sistem serupa untuk karakter NPC yang bergerak di kota-kota besar dengan jalanan yang kompleks.
