# 218. Retargeting animasi untuk menggunakan animasi yang sama pada beberapa karakter

## Definisi Singkat
Retargeting animasi adalah teknik yang memungkinkan satu set animasi digunakan pada karakter dengan proporsi tubuh yang berbeda. Godot 4 mendukung retargeting melalui sistem Skeleton Profile yang memetakan tulang dari satu skeleton ke skeleton lainnya.

## Analogi
Seperti baju yang bisa dipakai oleh orang dengan postur tubuh berbeda. Retargeting adalah proses menyesuaikan potongan baju (animasi) agar tetap pas dikenakan oleh orang yang lebih tinggi, pendek, gemuk, atau kurus (karakter berbeda).

## Struktur Node (Scene Tree)
```
Root (Node3D)
├── Character_A (Node3D)
│   ├── MeshInstance3D
│   ├── Skeleton3D (skeleton asli)
│   └── AnimationPlayer
├── Character_B (Node3D)
│   ├── MeshInstance3D
│   ├── Skeleton3D (skeleton berbeda)
│   └── AnimationPlayer
└── AnimationRetargeter (Node)
    └── SkeletonProfile (pemetaan tulang)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@onready var character_a: Node3D = $CharacterA
@onready var character_b: Node3D = $CharacterB
@onready var skeleton_profile: SkeletonProfile = $SkeletonProfile

func _ready():
    retarget_animation(character_a, character_b, "walk")

func retarget_animation(source: Node3D, target: Node3D, anim_name: String) -> void:
    var source_skeleton: Skeleton3D = source.get_node("Skeleton3D")
    var target_skeleton: Skeleton3D = target.get_node("Skeleton3D")
    
    var source_anim: Animation = source.get_node("AnimationPlayer").get_animation(anim_name)
    
    if source_anim == null:
        return
    
    var new_anim := Animation.new()
    new_anim.resource_name = anim_name + "_retargeted"
    
    for track_idx in range(source_anim.get_track_count()):
        var track_name := source_anim.track_get_path(track_idx)
        var source_bone_name := track_name.get_name(0)
        
        var target_bone_name := map_bone_name(source_bone_name)
        if target_bone_name.is_empty():
            continue
        
        var new_track_idx := new_anim.add_track(source_anim.track_get_type(track_idx))
        new_anim.track_set_path(new_track_idx, target_skeleton.get_path_to(target_skeleton))
        
        for key_idx in range(source_anim.track_get_key_count(track_idx)):
            var key_time := source_anim.track_get_key_time(track_idx, key_idx)
            var key_value := source_anim.track_get_key_value(track_idx, key_idx)
            new_anim.track_insert_key(new_track_idx, key_time, key_value)
    
    target.get_node("AnimationPlayer").add_animation(anim_name + "_retargeted", new_anim)

func map_bone_name(source_bone: String) -> String:
    var bone_map := {
        "mixamorig_Hips": "Hips",
        "mixamorig_Spine": "Spine",
        "mixamorig_Head": "Head",
        "mixamorig_LeftArm": "LeftArm",
        "mixamorig_RightArm": "RightArm",
        "mixamorig_LeftLeg": "LeftLeg",
        "mixamorig_RightLeg": "RightLeg"
    }
    return bone_map.get(source_bone, "")
```

## Kasus Penggunaan Nyata
Sebuah game memiliki 10 karakter berbeda dengan model dan proporsi tubuh yang berbeda. Daripada membuat animasi walk, run, dan idle untuk masing-masing karakter (total 30 animasi), developer cukup membuat animasi sekali dan menggunakan retargeting untuk mengaplikasikan ke semua karakter. Ini menghemat waktu produksi secara signifikan dan memastikan konsistensi animasi di seluruh karakter.
