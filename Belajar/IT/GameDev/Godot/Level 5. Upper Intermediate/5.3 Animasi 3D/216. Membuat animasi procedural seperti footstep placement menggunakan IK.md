# 216. Membuat animasi procedural seperti footstep placement menggunakan IK

## Definisi Singkat
Animasi procedural footstep placement adalah teknik yang menggunakan raycast dan IK untuk menempatkan kaki karakter secara tepat pada permukaan terrain. Sistem ini menghitung posisi kaki secara real-time berdasarkan bentuk medan, menghasilkan animasi jalan yang lebih alami dan meyakinkan.

## Analogi
Seperti seseorang yang berjalan di tanah berbatu. Otak secara otomatis menghitung di mana harus meletakkan kaki berdasarkan bentuk batu yang terlihat. Sistem footstep placement bekerja sama - ia "melihat" terrain dan menempatkan kaki di posisi yang paling masuk akal.

## Struktur Node (Scene Tree)
```
Root (Node3D)
├── CharacterBody3D
│   ├── MeshInstance3D
│   ├── Skeleton3D
│   │   ├── BoneAttachment3D (LeftFoot)
│   │   └── BoneAttachment3D (RightFoot)
│   ├── SkeletonIK3D (LeftFootIK)
│   ├── SkeletonIK3D (RightFootIK)
│   ├── RayCast3D (LeftFootRay)
│   └── RayCast3D (RightFootRay)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

@onready var left_foot_ik: SkeletonIK3D = $LeftFootIK
@onready var right_foot_ik: SkeletonIK3D = $RightFootIK
@onready var left_foot_ray: RayCast3D = $LeftFootRay
@onready var right_foot_ray: RayCast3D = $RightFootRay
@onready var skeleton: Skeleton3D = $Skeleton3D

var left_foot_target: Vector3
var right_foot_target: Vector3

func _ready():
    left_foot_ik.start()
    right_foot_ik.start()

func _physics_process(delta: float) -> void:
    update_foot_ik(left_foot_ray, left_foot_ik, "LeftFoot", delta)
    update_foot_ik(right_foot_ray, right_foot_ik, "RightFoot", delta)

func update_foot_ik(ray: RayCast3D, ik: SkeletonIK3D, bone_name: String, delta: float) -> void:
    ray.force_raycast_update()
    
    if ray.is_colliding():
        var collision_point := ray.get_collision_point()
        var collision_normal := ray.get_collision_normal()
        
        var target_pos := collision_point
        target_pos.y += 0.1
        
        ik.get_parent().global_position = target_pos
        
        var bone_idx := skeleton.find_bone(bone_name)
        if bone_idx != -1:
            var bone_global_pose := skeleton.get_bone_global_pose(bone_idx)
            var up_vector := collision_normal
            var forward_vector := -global_transform.basis.z
            var right_vector := up_vector.cross(forward_vector).normalized()
            forward_vector = right_vector.cross(up_vector).normalized()
            
            var rotation_basis := Basis(right_vector, up_vector, forward_vector)
            skeleton.set_bone_pose_rotation(bone_idx, rotation_basis.get_rotation_quaternion())
```

## Kasus Penggunaan Nyata
Game petualangan dengan karakter yang berjalan di terrain bergunung, berbatu, atau berundak. Tanpa footstep placement, kaki karakter akan melayang atau menembus tanah. Dengan sistem ini, kaki selalu menyentuh permukaan dengan posisi yang benar, menciptakan pengalaman visual yang lebih imersif dan realistis.
