# 214. Menggunakan AnimationTree dengan StateMachine untuk blending animasi 3D

## Definisi Singkat
AnimationTree dengan StateMachine adalah sistem yang memungkinkan transisi halus antara beberapa animasi 3D berdasarkan state atau kondisi tertentu. Setiap state merepresentasikan satu animasi, dan transisi dikontrol oleh parameter seperti kecepatan atau input pemain.

## Analogi
Seperti remote control TV dengan beberapa channel. Setiap channel menampilkan acara berbeda (animasi berbeda). Ketika kamu menekan tombol channel (parameter state), TV berpindah ke acara baru dengan transisi yang mulus tanpa layar blank sejenak.

## Struktur Node (Scene Tree)
```
Root (Node3D)
├── CharacterBody3D
│   ├── MeshInstance3D
│   ├── Skeleton3D
│   └── AnimationTree
│       └── StateMachine (AnimationNodeStateMachine)
│           ├── Idle (AnimationNodeAnimation)
│           ├── Walk (AnimationNodeAnimation)
│           └── Run (AnimationNodeAnimation)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

@onready var animation_tree: AnimationTree = $AnimationTree

func _ready():
    animation_tree.active = true

func _physics_process(delta: float) -> void:
    var speed := velocity.length()
    
    if speed < 0.1:
        animation_tree["parameters/playback"].travel("Idle")
    elif speed < 3.0:
        animation_tree["parameters/playback"].travel("Walk")
    else:
        animation_tree["parameters/playback"].travel("Run")
    
    var direction := Input.get_vector("move_left", "move_right", "move_forward", "move_back")
    if direction != Vector2.ZERO:
        velocity.x = direction.x * 5.0
        velocity.z = direction.y * 5.0
    else:
        velocity.x = move_toward(velocity.x, 0, 5.0)
        velocity.z = move_toward(velocity.z, 0, 5.0)
    
    move_and_slide()
```

## Kasus Penggunaan Nyata
Game RPG dengan karakter yang memiliki animasi idle, walk, run, dan attack. AnimationTree StateMachine memastikan transisi antara animasi berjalan ke berlari terjadi mulus tanpa patah-patah. Parameter kecepatan dikontrol oleh input pemain sehingga animasi selalu sinkron dengan gerakan karakter.
