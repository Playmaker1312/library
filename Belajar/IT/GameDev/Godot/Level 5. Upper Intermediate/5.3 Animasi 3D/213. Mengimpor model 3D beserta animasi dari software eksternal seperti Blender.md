# 213. Mengimpor model 3D beserta animasi dari software eksternal seperti Blender

## Definisi Singkat
Proses membawa model 3D dan animasinya dari software modeling seperti Blender ke dalam Godot Engine menggunakan format seperti glTF/FBX. Godot mendukung impor langsung dengan pemetaan material, skeleton, dan animasi secara otomatis.

## Analogi
Seperti mengirim paket dari rumah teman ke rumahmu. Model 3D adalah isinya, format glTF adalah kotak kemasannya, dan Godot adalah kurir yang menerima dan membuka paket tersebut sehingga isinya bisa langsung digunakan.

## Struktur Node (Scene Tree)
```
Root (Node3D)
├── CharacterBody3D
│   ├── MeshInstance3D (model 3D)
│   ├── Skeleton3D (kerangka model)
│   ├── AnimationPlayer (mengelola animasi)
│   └── AnimationTree (opsional, untuk blending)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

@onready var animation_player: AnimationPlayer = $AnimationPlayer
@onready var skeleton: Skeleton3D = $Skeleton3D

func _ready():
    animation_player.play("idle")

func play_animation(anim_name: String) -> void:
    if animation_player.has_animation(anim_name):
        animation_player.play(anim_name)

func get_animation_names() -> PackedStringArray:
    return animation_player.get_animation_list()
```

## Kasus Penggunaan Nyata
Seorang developer game mengimpor karakter dari Blender yang sudah dianimasikan berjalan, lari, dan diam. Setelah impor, animasi tersebut bisa dipanggil langsung di Godot tanpa perlu membuat ulang. Format glTF 2.0 menjadi pilihan utama karena mendukung material PBR, morph targets, dan multiple animations dalam satu file.
