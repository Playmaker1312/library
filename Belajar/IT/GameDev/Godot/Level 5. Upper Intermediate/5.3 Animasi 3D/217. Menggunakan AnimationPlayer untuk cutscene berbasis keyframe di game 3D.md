# 217. Menggunakan AnimationPlayer untuk cutscene berbasis keyframe di game 3D

## Definisi Singkat
AnimationPlayer dapat digunakan untuk membuat cutscene 3D dengan menyetel keyframe pada properti node seperti posisi, rotasi, dan visibility. Setiap cutscene adalah satu animasi yang memainkan urutan event secara otomatis seperti film pendek dalam game.

## Analogi
Seperti membuat film stop-motion. Kamu menentukan posisi karakter di setiap frame tertentu (keyframe), dan AnimationPlayer akan menggerakkan karakter dari satu posisi ke posisi lain secara otomatis, menciptakan ilusi gerakan sinematik.

## Struktur Node (Scene Tree)
```
Root (Node3D)
├── CutsceneManager (Node3D)
│   ├── AnimationPlayer (mengelola cutscene)
│   ├── Camera3D (kamera sinematik)
│   ├── DirectionalLight3D
│   └── Characters (Node3D)
│       ├── Character1 (Node3D)
│       └── Character2 (Node3D)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@onready var animation_player: AnimationPlayer = $CutsceneManager/AnimationPlayer
@onready var camera: Camera3D = $CutsceneManager/Camera3D

var cutscene_playing := false

func play_cutscene(anim_name: String) -> void:
    if animation_player.has_animation(anim_name):
        cutscene_playing = true
        animation_player.play(anim_name)
        animation_player.animation_finished.connect(_on_cutscene_finished)

func _on_cutscene_finished(anim_name: String) -> void:
    cutscene_playing = false
    animation_player.animation_finished.disconnect(_on_cutscene_finished)

func skip_cutscene() -> void:
    if cutscene_playing:
        animation_player.stop()
        cutscene_playing = false

func _input(event: InputEvent) -> void:
    if event.is_action_pressed("skip_cutscene"):
        skip_cutscene()
```

## Kasus Penggunaan Nyata
Game RPG yang menampilkan cutscene pembuka saat pemain memulai permainan baru. AnimationPlayer mengontrol pergerakan kamera, posisi karakter, dan efek visual seperti layar fade-in/fade-out. Cutscene bisa diputar ulang dari menu atau dilewati oleh pemain yang sudah pernah menontonnya.
