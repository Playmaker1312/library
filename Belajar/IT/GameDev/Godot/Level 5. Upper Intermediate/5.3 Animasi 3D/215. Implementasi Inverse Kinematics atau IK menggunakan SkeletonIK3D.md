# 215. Implementasi Inverse Kinematics atau IK menggunakan SkeletonIK3D

## Definisi Singkat
Inverse Kinematics (IK) adalah teknik animasi yang menghitung posisi sendi-sendi skeleton dari posisi target (end effector) secara terbalik. SkeletonIK3D di Godot memungkinkan tangan atau kaki karakter mengikuti posisi objek tertentu secara real-time.

## Analogi
Bayangkan kamu memegang ujung tali yang terhubung ke tongkat. Ketika kamu menggerakkan ujung tali, seluruh bagian tongkat akan mengikuti dengan posisi yang alami. IK bekerja sama seperti itu - kamu menentukan posisi ujung (tangan/kaki), dan sistem menghitung bagaimana seluruh lengan/kaki harus ditekuk.

## Struktur Node (Scene Tree)
```
Root (Node3D)
├── CharacterBody3D
│   ├── MeshInstance3D
│   ├── Skeleton3D
│   │   ├── BoneAttachment3D (LeftHand)
│   │   └── BoneAttachment3D (RightFoot)
│   └── SkeletonIK3D (Target IK)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

@onready var skeleton_ik: SkeletonIK3D = $SkeletonIK3D
@onready var target_marker: Marker3D = $TargetMarker

func _ready():
    skeleton_ik.start()

func _physics_process(delta: float) -> void:
    skeleton_ik.get_parent().global_position = target_marker.global_position
    
    if Input.is_action_just_pressed("toggle_ik"):
        if skeleton_ik.is_running():
            skeleton_ik.stop()
        else:
            skeleton_ik.start()
    
    var target_pos := Vector3.ZERO
    if Input.is_action_pressed("move_ik_x"):
        target_pos.x += 1.0
    if Input.is_action_pressed("move_ik_z"):
        target_pos.z += 1.0
    
    target_marker.global_position += target_pos * delta * 2.0
```

## Kasus Penggunaan Nyata
Karakter dalam game perlu memegang senjata yang posisinya berubah-ubah, atau kaki karakter harus mengikuti kontur terrain yang tidak rata. IK memastikan tangan selalu berada di posisi yang tepat pada gagang senjata tanpa perlu membuat animasi manual untuk setiap kemungkinan posisi. Teknik ini juga digunakan untuk karakter yang berjalan di permukaan miring.
