# 211. Menggunakan SoftBody3D untuk Efek Kain atau Benda Lentur

## Definisi Singkat
**SoftBody3D** adalah node yang mensimulasikan benda lunak dan fleksibel seperti kain, karet, atau jeli dengan menggunakan sistem partikel yang saling terhubung. Berbeda dengan RigidBody3D yang kaku, SoftBody3D memiliki mesh yang bisa berdeformasi secara realistis saat berinteraksi dengan objek lain.

## Analogi
Bayangkan selembar kain yang dipegang di dua ujung:
- **SoftBody3D** = Kain itu sendiri yang bisa berombak, jatuh, dan menutupi objek.
- **Vertex** = Titik-titik pada kain yang bisa bergerak secara independen.
- **Edge** = Garis-garis tak terlihat yang menghubungkan titik-titik dan menentukan seberapa kencang kain itu.
- **Pressure** = Udara di dalam bantal yang membuatnya mengembang dan mempertahankan bentuk.

## Kode GDScript (Godot 4)

**SoftCloth.gd**
```gdscript
extends SoftBody3D

@export var simulation_quality: int = 5

func _ready() -> void:
    set_unique_name_in_owner(true)
    
    if mesh is PlaneMesh:
        mesh.subdivide_width = 10
        mesh.subdivide_height = 10
    
    simulation_precision = simulation_quality
    linear_stiffness = 0.5
    damping_coefficient = 0.01
    drag_coefficient = 0.0
    
    pressure = 0.0
    particle_mass = 1.0
    
    set_point_pinned(0, true)
    set_point_pinned(mesh.subdivide_width, true)

func set_point_pinned(point_index: int, pinned: bool) -> void:
    if pinned and point_index < get_point_count():
        pin_point(point_index)

func pin_point(index: int) -> void:
    set_point_pinned(index, true)

func unpin_point(index: int) -> void:
    set_point_pinned(index, false)

func apply_force_to_point(point_index: int, force: Vector3) -> void:
    if point_index < get_point_count():
        apply_force(point_index, force)
```

**SoftBall.gd**
```gdscript
extends SoftBody3D

@export var bounce_force: float = 5.0

func _ready() -> void:
    simulation_precision = 3
    linear_stiffness = 0.8
    damping_coefficient = 0.05
    drag_coefficient = 0.0
    pressure = 1.0
    particle_mass = 0.5

func bounce() -> void:
    apply_central_impulse(Vector3.UP * bounce_force)

func squash(amount: float) -> void:
    var vertices = mesh.get_faces()
    var center = Vector3.ZERO
    
    for vertex in vertices:
        center += vertex
    center /= vertices.size()
    
    for i in range(get_point_count()):
        var point_pos = get_point_position(i)
        var direction = (point_pos - center).normalized()
        apply_force(i, direction * amount)
```

**ClothSimulation.gd**
```gdscript
extends Node3D

@onready var soft_cloth: SoftBody3D = $SoftCloth
@onready var interaction_box: StaticBody3D = $InteractionBox

var wind_strength: float = 0.0
var wind_direction: Vector3 = Vector3.FORWARD

func _ready() -> void:
    setup_wind()

func _process(delta: float) -> void:
    if wind_strength > 0:
        apply_wind()

func setup_wind() -> void:
    wind_strength = 2.0
    wind_direction = Vector3(1, 0, 0).normalized()

func apply_wind() -> void:
    var wind_force = wind_direction * wind_strength
    
    for i in range(soft_cloth.get_point_count()):
        if not soft_cloth.is_point_pinned(i):
            soft_cloth.apply_force(i, wind_force)

func interact_with_cloth(object_position: Vector3, force: float) -> void:
    for i in range(soft_cloth.get_point_count()):
        var point_pos = soft_cloth.to_global(soft_cloth.get_point_position(i))
        var distance = point_pos.distance_to(object_position)
        
        if distance < 2.0:
            var direction = (point_pos - object_position).normalized()
            var applied_force = direction * force * (1.0 - distance / 2.0)
            soft_cloth.apply_force(i, applied_force)
```

## Kasus Penggunaan Nyata
**SoftBody3D** sangat berguna untuk membuat efek kain realistis seperti tirai yang berkibar tertiup angin, bendera di medan perang, atau jubah karakter yang bergerak dinamis. Dalam game survival horror, SoftBody3D bisa digunakan untuk membuat jaring laba-laba yang elastis atau organ-organ yang bergerak. Untuk game puzzle, objek seperti bola karet atau jeli bisa dibuat dengan SoftBody3D untuk mekanik gameplay yang unik. Tekanan internal (pressure) memungkinkan pembuatan bantal atau balon yang mengembang dan berinteraksi dengan lingkungan secara realistis.
