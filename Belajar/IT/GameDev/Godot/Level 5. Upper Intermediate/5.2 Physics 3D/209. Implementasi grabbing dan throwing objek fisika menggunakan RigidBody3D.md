# 209. Implementasi Grabbing dan Throwing Objek Fisika menggunakan RigidBody3D

## Definisi Singkat
Mekanik grabbing dan throwing memungkinkan pemain mengambil objek RigidBody3D, menahannya di depan karakter, dan melemparnya dengan kekuatan tertentu. Ini melibatkan penggunaan **Joint3D** atau **constraint** untuk menahan objek dan **apply_central_impulse** untuk melemparnya.

## Analogi
Bayangkan kamu bermain bowling:
- **Grabbing** = Mengambil bola bowling dari rak. Bola menempel di tanganmu dan mengikutimu saat bergerak.
- **Holding** = Membawa bola bowling sambil berjalan ke jalur lemparan. Bola tetap di posisi relatif terhadap tubuhmu.
- **Throwing** = Melempar bola ke arah pin. Bola terlepas dan bergerak berdasarkan kekuatan lemparanmu.

## Struktur Node (Scene Tree)
```
Player (CharacterBody3D)
├── Head (Node3D)
│   ├── Camera3D
│   └── GrabPoint (Node3D)
├── GrabRay (RayCast3D)
└── ThrowStrength: float = 20.0

GrabbableBox (RigidBody3D)
├── MeshInstance3D (BoxMesh)
└── CollisionShape3D (BoxShape3D)
```

## Kode GDScript (Godot 4)

**Player.gd**
```gdscript
extends CharacterBody3D

@export var speed: float = 6.0
@export var jump_force: float = 4.5
@export var throw_force: float = 20.0
@export var grab_distance: float = 3.0

@onready var head: Node3D = $Head
@onready var grab_point: Node3D = $Head/GrabPoint
@onready var grab_ray: RayCast3D = $GrabRay

var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")
var grabbed_object: RigidBody3D = null
var grab_joint: Generic6DOFJoint3D = null

func _ready() -> void:
    grab_ray.target_position = Vector3(0, 0, -grab_distance)

func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity.y -= gravity * delta

    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = jump_force

    var input_dir = Input.get_vector("move_left", "move_right", "move_forward", "move_backward")
    var direction = (head.transform.basis * Vector3(input_dir.x, 0, input_dir.y)).normalized()

    if direction:
        velocity.x = direction.x * speed
        velocity.z = direction.z * speed
    else:
        velocity.x = move_toward(velocity.x, 0, speed)
        velocity.z = move_toward(velocity.z, 0, speed)

    move_and_slide()
    update_grabbed_object()

func _unhandled_input(event: InputEvent) -> void:
    if event.is_action_pressed("grab"):
        toggle_grab()
    
    if event.is_action_pressed("throw") and grabbed_object:
        throw_object()

func toggle_grab() -> void:
    if grabbed_object:
        release_object()
    else:
        try_grab()

func try_grab() -> void:
    grab_ray.force_raycast_update()
    if grab_ray.is_colliding():
        var collider = grab_ray.get_collider()
        if collider is RigidBody3D and collider.is_in_group("grabbable"):
            grab_object(collider)

func grab_object(object: RigidBody3D) -> void:
    grabbed_object = object
    grab_joint = Generic6DOFJoint3D.new()
    add_child(grab_joint)
    
    grab_joint.node_a = self.get_path()
    grab_joint.node_b = object.get_path()
    
    grab_joint.set_param_x(Generic6DOFJoint3D.PARAM_LINEAR_LOWER_LIMIT, -0.1)
    grab_joint.set_param_x(Generic6DOFJoint3D.PARAM_LINEAR_UPPER_LIMIT, 0.1)
    grab_joint.set_param_y(Generic6DOFJoint3D.PARAM_LINEAR_LOWER_LIMIT, -0.1)
    grab_joint.set_param_y(Generic6DOFJoint3D.PARAM_LINEAR_UPPER_LIMIT, 0.1)
    grab_joint.set_param_z(Generic6DOFJoint3D.PARAM_LINEAR_LOWER_LIMIT, -0.1)
    grab_joint.set_param_z(Generic6DOFJoint3D.PARAM_LINEAR_UPPER_LIMIT, 0.1)
    
    grabbed_object.gravity_scale = 0.0
    grabbed_object.linear_damp = 10.0
    grabbed_object.angular_damp = 10.0

func release_object() -> void:
    if grabbed_object:
        grabbed_object.gravity_scale = 1.0
        grabbed_object.linear_damp = 0.0
        grabbed_object.angular_damp = 0.0
        
        if grab_joint:
            grab_joint.queue_free()
            grab_joint = null
        
        grabbed_object = null

func throw_object() -> void:
    if grabbed_object:
        var throw_direction = -head.global_transform.basis.z
        grabbed_object.gravity_scale = 1.0
        grabbed_object.linear_damp = 0.0
        grabbed_object.angular_damp = 0.0
        
        if grab_joint:
            grab_joint.queue_free()
            grab_joint = null
        
        grabbed_object.apply_central_impulse(throw_direction * throw_force)
        grabbed_object = null

func update_grabbed_object() -> void:
    if grabbed_object and is_instance_valid(grabbed_object):
        grabbed_object.global_position = grab_point.global_position
```

    mass = 5.0
    gravity_scale = 1.0
    linear_damp = 0.0
    angular_damp = 0.0

## Kasus Penggunaan Nyata
Mekanik grabbing dan throwing sangat umum dalam game puzzle dan survival horror. Contoh nyata termasuk game **Half-Life** di mana pemain bisa mengambil kotak dan melemparnya untuk menyelesaikan puzzle atau melawan musuh. Dalam game survival horror seperti **Alan Wake**, pemain bisa melempar objek lingkungan sebagai senjata sementara. Fitur ini juga digunakan dalam game VR untuk meningkatkan imersi, memungkinkan pemain secara natural mengambil dan melempar objek virtual dengan gerakan tangan nyata.
