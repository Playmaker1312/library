# 207. Perbedaan StaticBody3D, RigidBody3D, CharacterBody3D, dan AnimatableBody3D

## Definisi Singkat
Keempat node ini adalah tipe body utama dalam Godot Physics 3D yang memiliki perilaku simulasi fisika berbeda. **StaticBody3D** tidak bergerak, **RigidBody3D** sepenuhnya dikontrol oleh physics engine, **CharacterBody3D** dikontrol oleh kode pemain, dan **AnimatableBody3D** bergerak berdasarkan animasi namun tetap berinteraksi dengan fisika.

## Analogi
Bayangkan sebuah ruangan dengan berbagai objek:
- **StaticBody3D** = Tembok dan lantai. Tidak pernah bergerak, tapi objek lain bisa menabraknya.
- **RigidBody3D** = Bola sepak. Dilempar, jatuh, memantul — semuanya dihitung oleh fisika.
- **CharacterBody3D** = Karakter dalam game platformer. Bergerak sesuai input pemain, tidak terpengaruh gravitasi otomatis.
- **AnimatableBody3D** = Pintu geser yang dianimasikan. Bergerak karena animasi, tapi tubuh pemain bisa menahannya.

## Struktur Node (Scene Tree)
```
Main (Node3D)
├── Ground (StaticBody3D)
│   ├── MeshInstance3D (BoxMesh)
│   └── CollisionShape3D (BoxShape3D)
├── Wall (StaticBody3D)
│   ├── MeshInstance3D (BoxMesh)
│   └── CollisionShape3D (BoxShape3D)
├── Ball (RigidBody3D)
│   ├── MeshInstance3D (SphereMesh)
│   └── CollisionShape3D (SphereShape3D)
├── Player (CharacterBody3D)
│   ├── MeshInstance3D (CapsuleMesh)
│   └── CollisionShape3D (CapsuleShape3D)
└── MovingPlatform (AnimatableBody3D)
    ├── MeshInstance3D (BoxMesh)
    └── CollisionShape3D (BoxShape3D)
```

## Kode GDScript (Godot 4)

**StaticBody3D.gd**
```gdscript
extends StaticBody3D

func _ready():
    collision_layer = 1
    collision_mask = 0
```

**RigidBody3D.gd**
```gdscript
extends RigidBody3D

func _ready():
    mass = 2.0
    gravity_scale = 1.0
    linear_damp = 0.0
    angular_damp = 0.0

func _on_body_entered(body: Node3D) -> void:
    if body is CharacterBody3D:
        apply_central_impulse(-body.velocity.normalized() * 10.0)
```

**CharacterBody3D.gd**
```gdscript
extends CharacterBody3D

const SPEED = 5.0
const JUMP_VELOCITY = 4.5
var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")

func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity.y -= gravity * delta

    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VELOCITY

    var input_dir = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    var direction = (transform.basis * Vector3(input_dir.x, 0, input_dir.y)).normalized()
    
    if direction:
        velocity.x = direction.x * SPEED
        velocity.z = direction.z * SPEED
    else:
        velocity.x = move_toward(velocity.x, 0, SPEED)
        velocity.z = move_toward(velocity.z, 0, SPEED)

    move_and_slide()
```

**AnimatableBody3D.gd**
```gdscript
extends AnimatableBody3D

@onready var animation_player: AnimationPlayer = $AnimationPlayer

func _ready():
    sync_to_physics = true

func _on_area_entered(area: Area3D) -> void:
    if area.name == "ActivationZone":
        animation_player.play("move_platform")
```

## Kasus Penggunaan Nyata
**StaticBody3D** digunakan untuk level desain seperti lantai, dinding, dan platform statis. **RigidBody3D** cocok untuk objek yang perlu respons fisika realistis seperti granat yang meledak atau kendaraan yang bisa terbalik. **CharacterBody3D** adalah pilihan standar untuk karakter pemain yang membutuhkan kontrol presisi tanpa gangguan fisika. **AnimatableBody3D** berguna untuk platform bergerak atau pintu mekanis yang perlu berinteraksi dengan karakter pemain namun gerakannya ditentukan oleh animasi.
