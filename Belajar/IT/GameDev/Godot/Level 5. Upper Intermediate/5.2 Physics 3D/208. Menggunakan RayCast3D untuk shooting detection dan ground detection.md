# 208. Menggunakan RayCast3D untuk Shooting Detection dan Ground Detection

## Definisi Singkat
**RayCast3D** adalah node yang memancarkan sinar tak terlihat dari satu titik ke titik lain untuk mendeteksi objek di jalurnya. Sinar ini digunakan untuk shooting detection (mendeteksi apa yang tertembak) dan ground detection (mendeteksi apakah karakter berada di tanah).

## Analogi
Bayangkan kamu memegang laser pointer:
- **Shooting detection** = Kamca laser ke arah tembok. Di mana laser mengenai, di situlah peluru akan mengenai.
- **Ground detection** = Kamca laser ke bawah dari kaki karaktermu. Jika laser menyentuh sesuatu, berarti kamu sedang berdiri di tanah.

## Struktur Node (Scene Tree)
```
Player (CharacterBody3D)
├── Head (Node3D)
│   ├── Camera3D
│   └── ShootingRay (RayCast3D)
└── GroundRay (RayCast3D)
```

## Kode GDScript (Godot 4)

**Player.gd**
```gdscript
extends CharacterBody3D

@export var speed: float = 8.0
@export var jump_force: float = 5.0
@export var shoot_distance: float = 100.0

@onready var head: Node3D = $Head
@onready var shooting_ray: RayCast3D = $Head/ShootingRay
@onready var ground_ray: RayCast3D = $GroundRay

var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")

func _ready() -> void:
    shooting_ray.target_position = Vector3(0, 0, -shoot_distance)
    ground_ray.target_position = Vector3(0, -1.5, 0)

func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity.y -= gravity * delta

    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = jump_force

    var input_dir = Input.get_vector("move_left", "move_right", "move_forward", "move_backward")
    var direction = (head.transform.basis * Vector3(input_dir.x, 0, input_dir.y)).normalized()

    if direction:
        velocity.x = direction.x * speed
        velocity.z = direction.z * speed
    else:
        velocity.x = move_toward(velocity.x, 0, speed)
        velocity.z = move_toward(velocity.z, 0, speed)

    move_and_slide()

func _unhandled_input(event: InputEvent) -> void:
    if event is InputEventMouseMotion:
        rotate_y(-event.relative.x * 0.003)
        head.rotate_x(-event.relative.y * 0.003)
        head.rotation.x = clamp(head.rotation.x, -PI / 2, PI / 2)

    if event.is_action_pressed("shoot"):
        shoot()

func shoot() -> void:
    shooting_ray.force_raycast_update()
    if shooting_ray.is_colliding():
        var collider = shooting_ray.get_collider()
        var hit_point = shooting_ray.get_collision_point()
        var hit_normal = shooting_ray.get_collision_normal()
        
        if collider.has_method("take_damage"):
            collider.take_damage(25)
        
        spawn_hit_effect(hit_point, hit_normal)

func is_grounded() -> bool:
    ground_ray.force_raycast_update()
    return ground_ray.is_colliding()

func spawn_hit_effect(position: Vector3, normal: Vector3) -> void:
    var effect = preload("res://scenes/effects/hit_effect.tscn").instantiate()
    get_tree().current_scene.add_child(effect)
    effect.global_position = position
    effect.look_at(position + normal, Vector3.UP)
```

**ShootingRay.gd**
```gdscript
extends RayCast3D

func _ready() -> void:
    enabled = true
    collide_with_areas = false
    collide_with_bodies = true
    collision_mask = 1

func get_target_info() -> Dictionary:
    force_raycast_update()
    if is_colliding():
        return {
            "collider": get_collider(),
            "point": get_collision_point(),
            "normal": get_collision_normal(),
            "distance": global_position.distance_to(get_collision_point())
        }
    return {}
```

## Kasus Penggunaan Nyata
**Shooting detection** dengan RayCast3D sangat umum digunakan dalam game first-person shooter dan third-person shooter. Metode ini lebih efisien dan akurat dibandingkan menggunakan projectile fisika untuk setiap peluru karena tidak memerlukan objek fisika baru. **Ground detection** menggunakan RayCast3D memungkinkan karakter melakukan double jump hanya jika benar-benar menyentuh tanah, mencegah bug di mana pemain bisa melompat berulang kali di udara. Kombinasi keduanya sering digunakan dalam game aksi modern untuk mekanik pertempuran dan eksplorasi.
