# 212. Mengoptimalkan Physics 3D dengan Mengatur Collision Layer dan Mask secara Tepat

## Definisi Singkat
**Collision layer** dan **collision mask** adalah sistem biner 32-bit yang mengontrol objek mana yang bisa berinteraksi satu sama lain. **Layer** menentukan di layer mana objek berada, sedangkan **mask** menentukan layer mana yang bisa dideteksi oleh objek tersebut. Pengaturan yang tepat meningkatkan performa dan mencegah interaksi yang tidak diinginkan.

## Analogi
Bayangkan kamu memakai kacamata berwarna:
- **Collision layer** = Warna baju yang kamu kenakan. Kamu "ada" di warna tertentu.
- **Collision mask** = Filter kacamata yang kamu pakai. Kamu hanya bisa "melihat" warna tertentu.
- Jika warna baju dan filter kacamata cocok, interaksi terjadi. Jika tidak, objek saling menembus.

## Struktur Node (Scene Tree)
```
GameManager (Node)
├── CollisionSetup (Node)
└── DebugUI (Control)

Layer 1: Player
Layer 2: Enemy
Layer 3: Player Bullet
Layer 4: Enemy Bullet
Layer 5: Environment
Layer 6: Pickups
Layer 7: Trigger Zones
Layer 8: Vehicle

Player (CharacterBody3D) → Layer: 1, Mask: 2, 5, 6, 7
Enemy (CharacterBody3D) → Layer: 2, Mask: 1, 3, 5, 7
PlayerBullet (Area3D) → Layer: 3, Mask: 2, 5
EnemyBullet (Area3D) → Layer: 4, Mask: 1, 5
Environment (StaticBody3D) → Layer: 5, Mask: 0
Pickup (Area3D) → Layer: 6, Mask: 1
```

## Kode GDScript (Godot 4)

**CollisionManager.gd**
```gdscript
extends Node

enum CollisionLayer {
    PLAYER = 1,
    ENEMY = 2,
    PLAYER_BULLET = 4,
    ENEMY_BULLET = 8,
    ENVIRONMENT = 16,
    PICKUP = 32,
    TRIGGER = 64,
    VEHICLE = 128
}

static func setup_player(body: CharacterBody3D) -> void:
    body.collision_layer = CollisionLayer.PLAYER
    body.collision_mask = CollisionLayer.ENEMY | CollisionLayer.ENVIRONMENT | CollisionLayer.PICKUP | CollisionLayer.TRIGGER

static func setup_enemy(body: CharacterBody3D) -> void:
    body.collision_layer = CollisionLayer.ENEMY
    body.collision_mask = CollisionLayer.PLAYER | CollisionLayer.PLAYER_BULLET | CollisionLayer.ENVIRONMENT | CollisionLayer.TRIGGER

static func setup_player_bullet(area: Area3D) -> void:
    area.collision_layer = CollisionLayer.PLAYER_BULLET
    area.collision_mask = CollisionLayer.ENEMY | CollisionLayer.ENVIRONMENT

static func setup_enemy_bullet(area: Area3D) -> void:
    area.collision_layer = CollisionLayer.ENEMY_BULLET
    area.collision_mask = CollisionLayer.PLAYER | CollisionLayer.ENVIRONMENT

static func setup_pickup(area: Area3D) -> void:
    area.collision_layer = CollisionLayer.PICKUP
    area.collision_mask = CollisionLayer.PLAYER

static func setup_vehicle(body: VehicleBody3D) -> void:
    body.collision_layer = CollisionLayer.VEHICLE
    body.collision_mask = CollisionLayer.ENVIRONMENT | CollisionLayer.PLAYER | CollisionLayer.ENEMY
```

**OptimizedPlayer.gd**
```gdscript
extends CharacterBody3D

func _ready() -> void:
    CollisionManager.setup_player(self)

func _physics_process(delta: float) -> void:
    move_and_slide()
```

**OptimizedBullet.gd**
```gdscript
extends Area3D

@export var speed: float = 50.0
@export var damage: int = 10
@export var is_player_bullet: bool = true

func _ready() -> void:
    if is_player_bullet:
        CollisionManager.setup_player_bullet(self)
    else:
        CollisionManager.setup_enemy_bullet(self)
    
    body_entered.connect(_on_body_entered)

func _physics_process(delta: float) -> void:
    global_position += -global_transform.basis.z * speed * delta

func _on_body_entered(body: Node3D) -> void:
    if body.has_method("take_damage"):
        body.take_damage(damage)
    queue_free()
```

**CollisionDebugger.gd**
```gdscript
extends Node

func get_layer_name(layer: int) -> String:
    match layer:
        1: return "Player"
        2: return "Enemy"
        4: return "Player Bullet"
        8: return "Enemy Bullet"
        16: return "Environment"
        32: return "Pickup"
        64: return "Trigger"
        128: return "Vehicle"
    return "Unknown"

func print_collision_info(body: Node3D) -> void:
    var layer_names = []
    var mask_names = []
    
    for i in range(32):
        if body.collision_layer & (1 << i):
            layer_names.append(get_layer_name(1 << i))
        if body.collision_mask & (1 << i):
            mask_names.append(get_layer_name(1 << i))
    
    print("Object: ", body.name)
    print("Layers: ", ", ".join(layer_names))
    print("Masks: ", ", ".join(mask_names))

func debug_collision_interaction(obj_a: Node3D, obj_b: Node3D) -> bool:
    var a_can_see_b = (obj_a.collision_mask & obj_b.collision_layer) != 0
    var b_can_see_a = (obj_b.collision_mask & obj_a.collision_layer) != 0
    var will_interact = a_can_see_b and b_can_see_a
    
    print("Will ", obj_a.name, " and ", obj_b.name, " interact? ", will_interact)
    return will_interact
```

## Kasus Penggunaan Nyata
Pengaturan collision layer dan mask yang tepat sangat krusial dalam game action untuk mencegah peluru pemain menembak pemain lain atau peluru musuh menembak musuh lain. Dalam game RPG, pickup item hanya perlu mendeteksi pemain, bukan musuh atau lingkungan, sehingga mask-nya bisa dibuat spesifik. Untuk game racing, kendaraan perlu berinteraksi dengan lingkungan dan pemain tapi tidak dengan peluru. Optimasi ini mengurangi jumlah collision check yang tidak perlu, meningkatkan performa physics engine secara signifikan terutama dalam scene dengan banyak objek.
