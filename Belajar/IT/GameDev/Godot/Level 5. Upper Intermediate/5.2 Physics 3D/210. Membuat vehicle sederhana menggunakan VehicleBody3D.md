# 210. Membuat Vehicle Sederhana menggunakan VehicleBody3D

## Definisi Singkat
**VehicleBody3D** adalah node RigidBody3D khusus yang menyediakan simulasi kendaraan fisika dengan support untuk roda, suspensi, dan kontrol kemudi. Node ini bekerja bersama **VehicleWheel3D** untuk mensimulasikan perilaku kendaraan seperti mobil, truk, atau sepeda motor.

## Analogi
Bayangkan kamu sedang membuat mainan mobil remote control:
- **VehicleBody3D** = Bodi mobil remote control yang memiliki berat dan bisa bergerak.
- **VehicleWheel3D** = Roda mobil yang berputar, memiliki suspensi untuk menyerap guncangan, dan traction untuk menyalurkan tenaga.
- **Steering** = Setir mobil yang mengontrol arah roda depan berbelok.
- **Engine force** = Tombol gas yang membuat roda berputar dan mendorong mobil maju.

## Struktur Node (Scene Tree)
```
Car (VehicleBody3D)
├── CarBody (MeshInstance3D)
├── WheelFrontLeft (VehicleWheel3D)
├── WheelFrontRight (VehicleWheel3D)
├── WheelRearLeft (VehicleWheel3D)
├── WheelRearRight (VehicleWheel3D)
└── CameraPivot (Node3D)
    └── Camera3D
```

## Kode GDScript (Godot 4)

**Car.gd**
```gdscript
extends VehicleBody3D

@export var max_steer: float = 0.8
@export var engine_power: float = 300.0
@export var brake_power: float = 50.0

@onready var wheel_fl: VehicleWheel3D = $WheelFrontLeft
@onready var wheel_fr: VehicleWheel3D = $WheelFrontRight
@onready var wheel_rl: VehicleWheel3D = $WheelRearLeft
@onready var wheel_rr: VehicleWheel3D = $WheelRearRight
@onready var camera_pivot: Node3D = $CameraPivot

var steer_target: float = 0.0

func _ready() -> void:
    wheel_fl.steering = true
    wheel_fr.steering = true
    wheel_rl.steering = false
    wheel_rr.steering = false
    
    wheel_fl.use_as_traction = true
    wheel_fr.use_as_traction = true
    wheel_rl.use_as_traction = true
    wheel_rr.use_as_traction = true

func _physics_process(delta: float) -> void:
    handle_input()
    update_camera()

func handle_input() -> void:
    var steer_input = Input.get_axis("steer_left", "steer_right")
    steer_target = steer_input * max_steer
    steering = move_toward(steering, steer_target, 0.05)
    
    var throttle_input = Input.get_axis("brake", "accelerate")
    if throttle_input > 0:
        engine_force = throttle_input * engine_power
        brake = 0.0
    elif throttle_input < 0:
        engine_force = 0.0
        brake = abs(throttle_input) * brake_power
    else:
        engine_force = 0.0
        brake = 0.0

func update_camera() -> void:
    camera_pivot.global_position = global_position + Vector3(0, 3, 0)
    camera_pivot.look_at(global_position, Vector3.UP)
```

**VehicleSetup.gd**
```gdscript
extends Node

static func setup_vehicle(car: VehicleBody3D) -> void:
    car.mass = 1200.0
    car.gravity_scale = 1.0
    car.linear_damp = 0.1
    car.angular_damp = 2.0
    
    setup_wheel(car.get_node("WheelFrontLeft"), true)
    setup_wheel(car.get_node("WheelFrontRight"), true)
    setup_wheel(car.get_node("WheelRearLeft"), false)
    setup_wheel(car.get_node("WheelRearRight"), false)

static func setup_wheel(wheel: VehicleWheel3D, is_front: bool) -> void:
    wheel.radius = 0.35
    wheel.suspension_stiffness = 30.0
    wheel.damping_compression = 2.3
    wheel.damping_relaxation = 4.4
    wheel.wheel_friction_slip = 1.5
    wheel.roll_influence = 0.1
    
    if is_front:
        wheel.steering = true
        wheel.use_as_traction = true
    else:
        wheel.steering = false
        wheel.use_as_traction = true
```

## Kasus Penggunaan Nyata
**VehicleBody3D** adalah solusi ideal untuk game racing seperti **Need for Speed** atau **Forza Horizon** di mana fisika kendaraan realistis sangat penting. Node ini juga digunakan dalam game open-world seperti **GTA** untuk berbagai jenis kendaraan mulai dari mobil sport hingga truk. Untuk game yang lebih kasual, VehicleBody3D tetap memberikan kontrol yang mudah namun cukup fleksibel untuk disesuaikan dengan gaya permainan yang diinginkan. Setup suspensi dan traction yang tepat akan menghasilkan pengalaman berkendara yang memuaskan.
