# 239. Memahami Keamanan Dasar dalam Multiplayer: Validasi di Server Side

## Definisi Singkat
Keamanan server-side dalam multiplayer adalah praktik memvalidasi semua input dan aksi dari klien di sisi server sebelum menerapkannya ke game state. Klien tidak pernah dipercaya, dan server harus memastikan bahwa semua data yang diterima valid dan sesuai aturan permainan.

## Analogi
Bayangkan sebuah toko yang memiliki petugas keamanan di pintu masuk. Setiap barang yang dibawa oleh pengunjung (klien) harus diperiksa oleh petugas keamanan (server) sebelum boleh masuk ke dalam toko (game state). Jika pengunjung membawa barang palsu atau barang yang tidak diizinkan, petugas keamanan akan menolaknya. Tidak peduli seberapa meyakinkan pengunjung tersebut, petugas keamanan tetap memeriksa.

## Prinsip Keamanan Server-Side

| Prinsip | Deskripsi |
|---------|-----------|
| **Never Trust Client** | Selalu validasi input dari klien |
| **Server Authority** | Server adalah satu-satunya sumber kebenaran |
| **Input Validation** | Pastikan input dalam batas wajar |
| **Rate Limiting** | Batasi jumlah request per detik |
| **State Sanitization** | Bersihkan data dari klien sebelum diproses |

## Kode GDScript (Godot 4)

```gdscript
extends Node

var player_data: Dictionary = {}
var MAX_HEALTH: int = 100
var MAX_SPEED: float = 500.0
var MIN_SPEED: float = 50.0
var MAX_DAMAGE: int = 100
var rate_limits: Dictionary = {}
var RATE_LIMIT: int = 30

func _ready() -> void:
	multiplayer.peer_connected.connect(_on_peer_connected)
	multiplayer.peer_disconnected.connect(_on_peer_disconnected)

func _on_peer_connected(id: int) -> void:
	player_data[id] = {
		"health": MAX_HEALTH,
		"speed": 200.0,
		"position": Vector2.ZERO,
		"last_update": Time.get_ticks_msec(),
		"score": 0
	}
	rate_limits[id] = {"count": 0, "last_reset": Time.get_ticks_msec()}

func _on_peer_disconnected(id: int) -> void:
	player_data.erase(id)
	rate_limits.erase(id)

func validate_input(sender_id: int, input_data: Dictionary) -> bool:
	if not rate_limits.has(sender_id):
		return false
	var now = Time.get_ticks_msec()
	if now - rate_limits[sender_id]["last_reset"] > 1000:
		rate_limits[sender_id]["count"] = 0
		rate_limits[sender_id]["last_reset"] = now
	rate_limits[sender_id]["count"] += 1
	if rate_limits[sender_id]["count"] > RATE_LIMIT:
		print("Rate limit exceeded for player: ", sender_id)
		return false
	if input_data.has("speed"):
		var speed = input_data["speed"]
		if speed < MIN_SPEED or speed > MAX_SPEED:
			return false
	if input_data.has("damage"):
		var damage = input_data["damage"]
		if damage < 0 or damage > MAX_DAMAGE:
			return false
	return true

func validate_position(sender_id: int, new_position: Vector2, delta: float) -> bool:
	if not player_data.has(sender_id):
		return false
	var last_pos = player_data[sender_id]["position"]
	var speed = player_data[sender_id]["speed"]
	var max_distance = speed * delta * 1.5
	var distance = last_pos.distance_to(new_position)
	return distance <= max_distance

func process_damage(attacker_id: int, target_id: int, damage: int) -> bool:
	if not validate_damage(attacker_id, damage):
		return false
	if not player_data.has(target_id):
		return false
	player_data[target_id]["health"] -= damage
	player_data[target_id]["health"] = max(0, player_data[target_id]["health"])
	if player_data[target_id]["health"] <= 0:
		player_data[attacker_id]["score"] += 1
		rpc("player_died", target_id, attacker_id)
	rpc("update_health", target_id, player_data[target_id]["health"])
	return true

func validate_damage(attacker_id: int, damage: int) -> bool:
	if damage < 0 or damage > MAX_DAMAGE:
		return false
	if not player_data.has(attacker_id):
		return false
	return true

func process_movement(sender_id: int, new_position: Vector2, new_rotation: float, delta: float) -> void:
	if not validate_position(sender_id, new_position, delta):
		rpc_id(sender_id, "correction_required", player_data[sender_id]["position"])
		return
	player_data[sender_id]["position"] = new_position
	rpc("update_player_position", sender_id, new_position, new_rotation)

@rpc("authority", "call_local", "reliable")
func update_player_position(player_id: int, position: Vector2, rotation: float) -> void:
	var player = get_node_or_null("/root/Game/Players/" + str(player_id))
	if player:
		player.global_position = position
		player.rotation = rotation

@rpc("authority", "call_local", "reliable")
func update_health(player_id: int, health: int) -> void:
	var player = get_node_or_null("/root/Game/Players/" + str(player_id))
	if player:
		player.health = health

@rpc("authority", "call_local", "reliable")
func player_died(dead_id: int, killer_id: int) -> void:
	print("Player ", dead_id, " killed by ", killer_id)

@rpc("authority", "call_remote", "reliable")
func correction_required(correct_position: Vector2) -> void:
	global_position = correct_position
	print("Position corrected by server")

func sanitize_string(input: String) -> String:
	var forbidden = ["<", ">", "{", "}", "[", "]", ";", "'", "\""]
	var result = input
	for char in forbidden:
		result = result.replace(char, "")
	return result.left(50)

func validate_chat_message(sender_id: int, message: String) -> bool:
	if message.length() == 0 or message.length() > 200:
		return false
	var sanitized = sanitize_string(message)
	if sanitized != message:
		return false
	return true

func check_player_count() -> int:
	return player_data.size()

func kick_player(player_id: int) -> void:
	rpc_id(player_id, "kicked_from_server")
	player_data.erase(player_id)
	multiplayer.disconnect_peer(player_id)

@rpc("authority", "call_remote", "reliable")
func kicked_from_server() -> void:
	get_tree().change_scene_to_file("res://scenes/main_menu.tscn")
```

## Kasus Penggunaan Nyata
**Server-side validation** digunakan di Fortnite untuk memvalidasi setiap tembakan dan pergerakan pemain agar tidak ada yang menggunakan aimbot atau speed hack. Di Dota 2, server memvalidasi setiap ability yang digunakan untuk memastikan pemain memiliki mana yang cukup dan berada dalam jarak yang benar. Di game mobile seperti PUBG Mobile, server-side validation mencegah penggunaan wallhack dengan memverifikasi apakah pemain benar-benar bisa melihat musuh sebelum mengizinkan serangan.
