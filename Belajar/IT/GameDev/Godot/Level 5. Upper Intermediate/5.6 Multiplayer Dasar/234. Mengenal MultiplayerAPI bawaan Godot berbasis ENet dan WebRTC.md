# 234. Mengenal MultiplayerAPI Bawaan Godot Berbasis ENet dan WebRTC

## Definisi Singkat
MultiplayerAPI adalah sistem bawaan Godot yang menyediakan antarmuka untuk komunikasi multiplayer melalui berbagai transport layer. ENet adalah library UDP yang andal untuk game dedicated server, sedangkan WebRTC memungkinkan peer-to-peer multiplayer di browser tanpa plugin tambahan.

## Analogi
Bayangkan Anda ingin mengirim pesan ke teman. **ENet** seperti mengirim paket lewat ekspedisi yang memiliki sistem tracking — pesan mungkin sedikit terlambat tetapi pasti sampai dan bisa dikonfirmasi. **WebRTC** seperti video call langsung antar device — komunikasi terjadi langsung tanpa melewati server tengah, cocok untuk browser tetapi memerlukan signaling server untuk pertemuan pertama.

## Perbandingan Transport Layer

| Fitur | ENet | WebRTC |
|-------|------|--------|
| Protocol | UDP dengan reliability | UDP + TCP |
| Platform | Desktop, Mobile | Browser, Desktop |
| Max Peer | 32-256 | Bervariasi |
| Latency | Rendah | Sedang |
| Pengaturan | Port forwarding | STUN/TURN server |
| Godot Support | Built-in | Via plugin/extension |

## Kode GDScript (Godot 4)

```gdscript
extends Node

var peer: ENetMultiplayerPeer

func setup_enet_server(port: int, max_clients: int = 32) -> Error:
	peer = ENetMultiplayerPeer.new()
	var error = peer.create_server(port, max_clients)
	if error != OK:
		return error
	multiplayer.peer = peer
	configure_multiplayer()
	return OK

func setup_enet_client(address: String, port: int) -> Error:
	peer = ENetMultiplayerPeer.new()
	var error = peer.create_client(address, port)
	if error != OK:
		return error
	multiplayer.peer = peer
	configure_multiplayer()
	return OK

func configure_multiplayer() -> void:
	multiplayer.peer_connected.connect(_on_peer_connected)
	multiplayer.peer_disconnected.connect(_on_peer_disconnected)
	multiplayer.connected_to_server.connect(_on_connected)
	multiplayer.connection_failed.connect(_on_connection_failed)

func _on_peer_connected(id: int) -> void:
	print("Peer connected: ", id)

func _on_peer_disconnected(id: int) -> void:
	print("Peer disconnected: ", id)

func _on_connected() -> void:
	print("Connected to server. My ID: ", multiplayer.get_unique_id())

func _on_connection_failed() -> void:
	print("Connection failed")

func get_connected_peers() -> Array:
	return multiplayer.get_peers()

func get_server_address() -> String:
	if peer and peer.get_connection_status() == MultiplayerPeer.CONNECTION_CONNECTED:
		return peer.get_host().get_address()
	return ""
```

## Kasus Penggunaan Nyata
**ENet** digunakan di game dedikasi seperti Unturned dan Among Us versi PC karena stabil untuk koneksi jangka panjang dan mendukung banyak pemain. **WebRTC** digunakan di game browser seperti Slither.io dan Krunker.io yang memerlukan multiplayer instan tanpa instalasi, serta di Godot Web Export untuk membuat game kooperatif online.
