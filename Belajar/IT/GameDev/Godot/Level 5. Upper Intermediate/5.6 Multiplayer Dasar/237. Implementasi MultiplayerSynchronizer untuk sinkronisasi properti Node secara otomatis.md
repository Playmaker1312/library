# 237. Implementasi MultiplayerSynchronizer untuk Sinkronisasi Properti Node Secara Otomatis

## Definisi Singkat
MultiplayerSynchronizer adalah node bawaan Godot 4 yang secara otomatis menyinkronkan properti tertentu dari parent node antar peer tanpa perlu menulis kode RPC manual. Node ini mendukung berbagai mode sync seperti send/receive, dan bisa dikonfigurasi properti mana yang harus disinkronkan.

## Analogi
Bayangkan Anda dan teman sedang bermain game bersama. Daripada harus terus-menerus memberi tahu teman posisi Anda setiap detik (seperti menulis surat), MultiplayerSynchronizer seperti walkie-talkie yang secara otomatis memberi tahu teman Anda di mana Anda berada, seberapa banyak HP Anda, dan animasi apa yang sedang Anda jalankan. Anda cukup mengatur walkie-talkie-nya, dan sisanya berjalan otomatis.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── MultiplayerSynchronizer (Node)
├── CollisionShape2D
├── Sprite2D
├── AnimationPlayer
└── HealthBar (ProgressBar)
```

## Konfigurasi MultiplayerSynchronizer

### Via Inspector:
- **Sync Mode**: 
  - `Send and Receive` - Sinkronisasi dua arah
  - `Send Only` - Hanya mengirim perubahan
  - `Receive Only` - Hanya menerima perubahan

### Properties to Sync:
- `global_position` - Posisi node
- `rotation` - Rotasi node
- `animation_current` - Animasi aktif
- `health` - Nilai HP

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

@export var speed: float = 300.0
@export var health: int = 100
@export var player_name: String = "Player"

var sync_position: Vector2
var sync_rotation: float
var sync_animation: String = "idle"

func _ready() -> void:
	$MultiplayerSynchronizer.replication_config_changed.connect(_on_config_changed)
	setup_sync_config()

func setup_sync_config() -> void:
	var config = $MultiplayerSynchronizer.replication_config
	config.root_path = get_path()
	config.add_property("global_position", 1)
	config.add_property("rotation", 2)
	config.add_property("sync_animation", 3)
	config.add_property("health", 4)
	config.add_property("player_name", 5)

func _on_config_changed() -> void:
	pass

func _physics_process(delta: float) -> void:
	if is_multiplayer_authority():
		_control_player(delta)
	else:
		_interpolate_visuals(delta)

func _control_player(delta: float) -> void:
	var direction = Input.get_vector("move_left", "move_right", "move_up", "move_down")
	velocity = direction * speed
	move_and_slide()
	_update_animation(direction)

func _update_animation(direction: Vector2) -> void:
	if direction.length() > 0:
		if abs(direction.x) > abs(direction.y):
			sync_animation = "walk_right" if direction.x > 0 else "walk_left"
		else:
			sync_animation = "walk_down" if direction.y > 0 else "walk_up"
	else:
		sync_animation = "idle"
	$AnimationPlayer.play(sync_animation)

func _interpolate_visuals(delta: float) -> void:
	global_position = global_position.lerp(sync_position, 10.0 * delta)
	rotation = lerp_angle(rotation, sync_rotation, 10.0 * delta)

func _on_health_changed(new_health: int) -> void:
	health = new_health
	$HealthBar.value = health
	if health <= 0:
		die()

func die() -> void:
	visible = false
	set_physics_process(false)

func set_player_data(id: int, pname: String) -> void:
	player_name = pname
	set_multiplayer_authority(id)
	$MultiplayerSynchronizer.set_multiplayer_authority(id)

func get_sync_state() -> Dictionary:
	return {
		"position": global_position,
		"rotation": rotation,
		"animation": sync_animation,
		"health": health
	}

func apply_sync_state(state: Dictionary) -> void:
	global_position = state["position"]
	rotation = state["rotation"]
	sync_animation = state["animation"]
	health = state["health"]
	$AnimationPlayer.play(sync_animation)
	$HealthBar.value = health
```

## Kasus Penggunaan Nyata
MultiplayerSynchronizer digunakan di game seperti di game balap online untuk menyinkronkan posisi mobil secara real-time, di game survival seperti Rust untuk menyinkronkan posisi dan status pemain, serta di game mobile seperti Free Fire untuk mengatur posisi karakter di mode battle royale dengan latensi yang minimal.
