# 238. Menangani Lag Compensation dan Prediction Dasar dalam Multiplayer Game

## Definisi Singkat
Lag compensation adalah teknik untuk mengkompensasi latensi jaringan agar pengalaman bermain tetap adil bagi semua pemain. Prediction adalah teknik klien yang memprediksi hasil dari input pemain sebelum konfirmasi dari server diterima untuk mengurangi perasaan lag.

## Analogi
Bayangkan Anda sedang melempar bola ke teman yang ada di kejauhan. **Prediction** adalah Anda langsung melempar bola tanpa menunggu teman mengangkat tangan — Anda berharap dia akan menangkap. **Lag compensation** adalah ketika teman Anda terlambat menangkap bola, tetapi Anda tetap menganggap lemparan itu berhasil karena bola sudah sampai di tangan dia. Jika terjadi kesalahan (misalnya bola jatuh), server akan mengkoreksi posisi bola.

## Strategi Kompensasi Lag

| Strategi | Cara Kerja | Contoh Game |
|----------|------------|-------------|
| **Client Prediction** | Klien prediksi posisi lokal | Overwatch, CS2 |
| **Server Reconciliation** | Server verifikasi input | Fortnite, Apex |
| **Entity Interpolation** | Render posisi antar state | Battlefield, Dota 2 |
| **Lag Compensation** | Server putar ulang waktu | Counter-Strike, Valorant |

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

@export var speed: float = 300.0

var input_buffer: Array[Dictionary] = []
var max_buffer_size: int = 30
var server_position: Vector2
var predicted_position: Vector2
var last_confirmed_input: int = 0
var ping: float = 0.0

func _ready() -> void:
	server_position = global_position
	predicted_position = global_position

func _physics_process(delta: float) -> void:
	if is_multiplayer_authority():
		_control_and_sync(delta)
	else:
		_interpolate_visuals(delta)
		_display_ping()

func _control_and_sync(delta: float) -> void:
	var input = _get_input()
	var input_data = {
		"tick": last_confirmed_input + 1,
		"direction": input,
		"time": Time.get_ticks_msec()
	}
	input_buffer.append(input_data)
	if input_buffer.size() > max_buffer_size:
		input_buffer.pop_front()
	_apply_input(input_data)
	rpc("send_input", input_data)

func _get_input() -> Vector2:
	return Input.get_vector("move_left", "move_right", "move_up", "move_down")

func _apply_input(input_data: Dictionary) -> void:
	velocity = input_data["direction"] * speed
	move_and_slide()

func _interpolate_visuals(delta: float) -> void:
	var target_pos = predicted_position.lerp(server_position, 0.15)
	global_position = global_position.lerp(target_pos, 12.0 * delta)

func _predict_next_position(input: Vector2, delta: float) -> Vector2:
	var predicted_vel = input * speed
	return predicted_position + predicted_vel * delta

func _display_ping() -> void:
	var ping_label = get_node_or_null("LagIndicator/PingLabel")
	if ping_label:
		ping_label.text = "Ping: " + str(int(ping)) + " ms"
		if ping > 100:
			ping_label.add_theme_color_override("font_color", Color.RED)
		elif ping > 50:
			ping_label.add_theme_color_override("font_color", Color.YELLOW)
		else:
			ping_label.add_theme_color_override("font_color", Color.GREEN)

@rpc("any_peer", "call_remote", "reliable")
func send_input(input_data: Dictionary) -> void:
	var sender_id = multiplayer.get_remote_sender_id()
	_apply_input(input_data)
	rpc_id(sender_id, "confirm_input", input_data["tick"], global_position)

@rpc("authority", "call_remote", "reliable")
func confirm_input(tick: int, server_pos: Vector2) -> void:
	server_position = server_pos
	predicted_position = server_pos
	last_confirmed_input = tick
	_replay_unconfirmed_inputs()

func _replay_unconfirmed_inputs() -> void:
	for input_data in input_buffer:
		if input_data["tick"] > last_confirmed_input:
			_apply_input(input_data)
			predicted_position = _predict_next_position(input_data["direction"], 0.016)

func calculate_ping() -> void:
	rpc_id(1, "_server_ping_request", multiplayer.get_unique_id(), Time.get_ticks_msec())

@rpc("any_peer", "call_remote", "unreliable")
func _server_ping_request(sender_id: int, client_time: int) -> void:
	rpc_id(sender_id, "_client_ping_response", client_time)

@rpc("authority", "call_remote", "unreliable")
func _client_ping_response(client_time: int) -> void:
	ping = (Time.get_ticks_msec() - client_time) / 2.0

func get_snapshot() -> Dictionary:
	return {
		"position": global_position,
		"velocity": velocity,
		"tick": last_confirmed_input
	}

func apply_snapshot(snapshot: Dictionary) -> void:
	global_position = snapshot["position"]
	velocity = snapshot["velocity"]
	last_confirmed_input = snapshot["tick"]
	server_position = snapshot["position"]
	predicted_position = snapshot["position"]
```

## Kasus Penggunaan Nyata
**Lag compensation** digunakan di CS2 di mana server memutar ulang waktu saat pemain menembak untuk memvalidasi tembakan berdasarkan posisi yang dilihat pemain. **Prediction** digunakan di Overwatch untuk menggerakkan karakter secara responsif meskipun ada lag 50ms+. **Entity interpolation** digunakan di Battlefield untuk menampilkan posisi pemain lain secara halus di antara dua state yang diterima dari server.
