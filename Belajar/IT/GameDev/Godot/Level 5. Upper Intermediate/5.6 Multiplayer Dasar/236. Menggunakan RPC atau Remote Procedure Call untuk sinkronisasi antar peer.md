# 236. Menggunakan RPC (Remote Procedure Call) untuk Sinkronisasi Antar Peer

## Definisi Singkat
RPC adalah mekanisme yang memungkinkan satu peer memanggil fungsi yang dieksekusi di peer lain. Dalam Godot, RPC ditandai dengan annotation `@rpc` yang menentukan siapa yang bisa memanggil fungsi tersebut, bagaimana cara penanganannya, dan apakah harus reliable atau unreliable.

## Analogi
Bayangkan Anda sedang menelepon teman dan mengatakan "tolong nyalakan lampu di ruang tamu". Teman Anda menerima instruksi dan mengeksekusinya. RPC bekerja sama persis — Anda mengirim perintah ke peer lain, dan peer tersebut menjalankan fungsi yang dimaksud. Ada aturan siapa yang boleh menelepon (authority), apakah pesan harus sampai pasti (reliable), dan apakah harus dikirim ke semua orang atau hanya ke satu orang.

## Jenis RPC di Godot 4

| Multiplayer API | Fungsi | Keterangan |
|----------------|--------|------------|
| `any_peer` | Peer manapun bisa memanggil | Untuk input dari klien |
| `authority` | Hanya authority node yang bisa memanggil | Untuk perintah dari server |
| `call_remote` | Hanya dieksekusi di remote peer | Standar untuk sinkronisasi |
| `call_local` | Juga dieksekusi di peer pemanggil | Untuk efek yang harus terlihat semua |
| `reliable` | Dijamin sampai dengan urutan | Untuk perubahan penting |
| `unreliable` | Bisa hilang, tanpa urutan | Untuk data yang sering berubah |

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

var speed: float = 300.0
var health: int = 100

func _physics_process(delta: float) -> void:
	if not is_multiplayer_authority():
		return
	var direction = Input.get_vector("move_left", "move_right", "move_up", "move_down")
	velocity = direction * speed
	move_and_slide()
	rpc("update_position", global_position, rotation)

@rpc("any_peer", "call_remote", "reliable")
func update_position(pos: Vector2, rot: float) -> void:
	global_position = pos
	rotation = rot

@rpc("any_peer", "call_remote", "reliable")
func take_damage(amount: int, attacker_id: int) -> void:
	health -= amount
	if health <= 0:
		die()

func die() -> void:
	rpc("on_player_died", multiplayer.get_unique_id())

@rpc("call_local", "reliable")
func on_player_died(player_id: int) -> void:
	print("Player ", player_id, " died")
	visible = false
	set_physics_process(false)

@rpc("any_peer", "call_remote", "unreliable")
func sync_animation(anim_name: String) -> void:
	$AnimationPlayer.play(anim_name)

func attack() -> void:
	rpc("perform_attack")

@rpc("any_peer", "call_remote", "reliable")
func perform_attack() -> void:
	$AnimationPlayer.play("attack")
	$AttackArea.monitoring = true
	await get_tree().create_timer(0.3).timeout
	$AttackArea.monitoring = false

func _on_attack_area_body_entered(body: CharacterBody2D) -> void:
	if body.has_method("take_damage"):
		var attacker_id = multiplayer.get_unique_id()
		body.rpc("take_damage", 25, attacker_id)
```

## Kasus Penggunaan Nyata
RPC digunakan di Among Us untuk melaporkan jasad (kirim perintah ke semua pemain), di Valorant untuk menembak peluru (kirim data ke server yang memvalidasi lalu broadcast ke semua klien), dan di game kooperatif seperti Stardew Valley multiplayer untuk sinkronisasi aksi petani seperti menyiram tanaman atau memberi makan hewan.
