# 233. Memahami Konsep Multiplayer: Client-Server, Peer-to-Peer, dan Authoritative Server

## Definisi Singkat
Multiplayer adalah arsitektur di mana beberapa pemain terhubung melalui jaringan untuk bermain bersama. Terdapat tiga model utama: client-server (semua komunikasi melalui server pusat), peer-to-peer (setiap klien saling terhubung langsung), dan authoritative server (server mengontrol semua logika permainan sementara klien hanya mengirim input).

## Analogi
Bayangkan Anda bermain kartu di meja. Dalam **client-server**, ada seorang bandar yang membagi kartu dan menghitung skor — semua pemain hanya berinteraksi dengan bandar. Dalam **peer-to-peer**, tidak ada bandar, pemain langsung berurusan satu sama lain. Dalam **authoritative server**, bandar memiliki otoritas penuh atas aturan main, pemain hanya bisa mengajukan permintaan (seperti "saya mau pasang taruhan"), tetapi bandar yang memutuskan apakah permintaan itu valid.

## Arsitektur Jaringan

### Client-Server
```
[Klien A] ──┐
[Klien B] ──┼── [Server] ──┬── [Database]
[Klien C] ──┘              └── [Game Logic]
```

### Peer-to-Peer
```
[Klien A] ──┬── [Klien B]
            │
[Klien C] ──┘
```

### Authoritative Server
```
[Klien A] ── Input ──┐
[Klien B] ── Input ──┼── [Server Logic] ── State ──┬── [Klien A]
[Klien C] ── Input ──┘                             ├── [Klien B]
                                                   └── [Klien C]
```

## Kode GDScript (Godot 4)

```gdscript
extends Node

enum NetworkMode {
	CLIENT_SERVER,
	PEER_TO_PEER,
	AUTHORITATIVE_SERVER
}

var current_mode: NetworkMode = NetworkMode.AUTHORITATIVE_SERVER

func start_as_server(port: int = 7777) -> void:
	var peer = ENetMultiplayerPeer.new()
	peer.create_server(port, 10)
	multiplayer.peer = peer
	multiplayer.peer_connected.connect(_on_peer_connected)
	multiplayer.peer_disconnected.connect(_on_peer_disconnected)
	print("Server started on port ", port)

func start_as_client(address: String, port: int = 7777) -> void:
	var peer = ENetMultiplayerPeer.new()
	peer.create_client(address, port)
	multiplayer.peer = peer
	multiplayer.connected_to_server.connect(_on_connected_to_server)
	multiplayer.connection_failed.connect(_on_connection_failed)
	print("Connecting to ", address, ":", port)

func _on_peer_connected(id: int) -> void:
	print("Peer connected: ", id)

func _on_peer_disconnected(id: int) -> void:
	print("Peer disconnected: ", id)

func _on_connected_to_server() -> void:
	print("Connected to server with ID: ", multiplayer.get_unique_id())

func _on_connection_failed() -> void:
	print("Connection failed")

func is_server() -> bool:
	return multiplayer.is_server()

func get_my_id() -> int:
	return multiplayer.get_unique_id()
```

## Kasus Penggunaan Nyata
Model **authoritative server** digunakan di game kompetitif seperti Valorant dan CS2 untuk mencegah cheating, karena server yang memvalidasi setiap gerakan pemain. Model **peer-to-peer** sering digunakan di game kooperatif lokal seperti Overcooked karena tidak memerlukan server dedicated. **Client-server** standar digunakan di MMO seperti World of Warcraft untuk mengelola ribuan pemain secara terpusat.
