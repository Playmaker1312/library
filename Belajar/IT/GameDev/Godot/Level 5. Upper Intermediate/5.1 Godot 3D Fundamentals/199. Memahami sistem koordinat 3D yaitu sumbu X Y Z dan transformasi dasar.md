# 199. Memahami Sistem Koordinat 3D (Sumbu X, Y, Z) dan Transformasi Dasar

## Definisi Singkat
Sistem koordinat 3D menggunakan tiga sumbu: X (kanan/kiri), Y (atas/bawah), dan Z (depan/belakang) untuk menentukan posisi, rotasi, dan skala objek dalam ruang 3D. Transformasi dasar mencakup perubahan position, rotation, dan scale pada setiap node 3D.

## Analogi
Bayangkan kamu berdiri di dalam sebuah ruangan. Sumbu X adalah arah kiri-kanan, sumbu Y adalah arah atas-bawah (lantai ke langit-langit), dan sumbu Z adalah arah maju-mundur (depan ke belakang). Setiap benda di ruangan itu bisa dipindahkan (translate), diputar (rotate), atau diubah ukurannya (scale) terhadap tiga sumbu ini.

## Struktur Node (Scene Tree)
```
Node3D (Root)
├── MeshInstance3D (dengan posisi, rotasi, skala tertentu)
│   └── CollisionShape3D
└── Camera3D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

func _ready():
    var node = $MeshInstance3D
    node.position = Vector3(2.0, 1.0, -3.0)
    node.rotation = Vector3(0, deg_to_rad(45), 0)
    node.scale = Vector3(1.5, 1.5, 1.5)

func _process(delta):
    var node = $MeshInstance3D
    node.position.x += 1.0 * delta
    node.rotate_y(deg_to_rad(90) * delta)
```

## Kasus Penggunaan Nyata
Transformasi dasar digunakan untuk menempatkan objek di dunia 3D seperti meletakkan pohon di posisi tertentu dalam game open world, memutar karakter menghadap arah gerakan, atau mengubah ukuran props sesuai kebutuhan level design. Memahami sistem koordinat sangat penting karena Godot menggunakan koordinat tangan kiri (left-handed) yang mempengaruhi arah rotasi dan posisi objek.
