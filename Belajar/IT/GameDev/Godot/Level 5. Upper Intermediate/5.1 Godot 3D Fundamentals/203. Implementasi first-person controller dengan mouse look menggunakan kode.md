# 203. Implementasi First-Person Controller dengan Mouse Look Menggunakan Kode

## Definisi Singkat
First-person controller adalah sistem pergerakan kamera yang menempatkan sudut pandang pemain tepat di posisi karakter, dengan mouse look yang mengontrol arah pandang horizontal (yaw) dan vertikal (pitch) secara independen.

## Analogi
Bayangkan kamu memakai VR headset. Kepalamu menentukan arah pandang: menoleh kiri-kanan mengubah horizontal look, dan mengangguk ke atas-bawah mengubah vertical look. Tanganmu mengontrol pergerakan karakter maju-mundur, sementara pandanganmu bebas bergerak sesuai keinginan.

## Struktur Node (Scene Tree)
```
CharacterBody3D (Player)
├── Head (Node3D)
│   ├── Camera3D
│   └── RayCast3D (untuk interaksi)
├── CollisionShape3D
└── MeshInstance3D (opsional)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

const SPEED = 5.0
const JUMP_VELOCITY = 4.5
const MOUSE_SENSITIVITY = 0.002
var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")
var rotation_x = 0.0

@onready var head = $Head
@onready var camera = $Head/Camera3D

func _ready():
    Input.mouse_mode = Input.MOUSE_MODE_CAPTURED

func _unhandled_input(event):
    if event is InputEventMouseMotion:
        rotate_y(-event.relative.x * MOUSE_SENSITIVITY)
        rotation_x = clamp(rotation_x - event.relative.y * MOUSE_SENSITIVITY, deg_to_rad(-80), deg_to_rad(80))
        head.rotation.x = rotation_x
    if event.is_action_pressed("ui_cancel"):
        Input.mouse_mode = Input.MOUSE_MODE_VISIBLE

func _physics_process(delta):
    if not is_on_floor():
        velocity.y -= gravity * delta
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VELOCITY
    var input_dir = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    var direction = (transform.basis * Vector3(input_dir.x, 0, input_dir.y)).normalized()
    if direction:
        velocity.x = direction.x * SPEED
        velocity.z = direction.z * SPEED
    else:
        velocity.x = move_toward(velocity.x, 0, SPEED)
        velocity.z = move_toward(velocity.z, 0, SPEED)
    move_and_slide()
```

## Kasus Penggunaan Nyata
First-person controller dengan mouse look adalah standar untuk game FPS (First Person Shooter) seperti Counter-Strike atau Valorant, game eksplorasi seperti Minecraft, atau game horror seperti Amnesia. Mouse sensitivity yang dapat diatur memungkinkan pemain menyesuaikan sensitivitas sesuai preferensi, dan pembatasan pitch angle mencegah kamera berputar terlalu jauh ke atas atau bawah.
