# 200. Mengenal Node 3D Utama: Node3D, MeshInstance3D, CollisionShape3D, dan Camera3D

## Definisi Singkat
Node3D adalah base class untuk semua node 3D di Godot, MeshInstance3D menampilkan visual mesh 3D, CollisionShape3D mendefinisikan bentuk fisik untuk interaksi, dan Camera3D menentukan apa yang dilihat pemain di layar.

## Analogi
Bayangkan sebuah panggung pertunjukan: Node3D adalah fondasi panggung itu sendiri, MeshInstance3D adalah aktor atau properti yang terlihat oleh penonton, CollisionShape3D adalah batas fisik yang tidak bisa ditembus aktor, dan Camera3D adalah sudut pandang kamera yang merekam pertunjukan.

## Struktur Node (Scene Tree)
```
Node3D (Root / GameWorld)
├── Camera3D (kamera utama)
├── MeshInstance3D (objek visual)
│   └── CollisionShape3D (bentuk fisik)
├── DirectionalLight3D (pencahayaan)
└── CharacterBody3D (karakter)
    ├── MeshInstance3D (visual karakter)
    └── CollisionShape3D (fisik karakter)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

func _ready():
    var mesh_instance = MeshInstance3D.new()
    var box_mesh = BoxMesh.new()
    mesh_instance.mesh = box_mesh
    add_child(mesh_instance)

    var collision = CollisionShape3D.new()
    var box_shape = BoxShape3D.new()
    collision.shape = box_shape
    mesh_instance.add_child(collision)

    var camera = Camera3D.new()
    camera.position = Vector3(0, 3, 5)
    camera.look_at(Vector3.ZERO)
    add_child(camera)
```

## Kasus Penggunaan Nyata
Keempat node ini adalah blok bangunan utama dalam setiap scene 3D. MeshInstance3D menampilkan model 3D seperti karakter, senjata, atau environment. CollisionShape3D memungkinkan deteksi tabrakan untuk mekanik game seperti tembakan, puzzle, atau fisik. Camera3D mengontrol sudut pandang pemain, baik untuk game FPS, TPS, atau isometric. Node3D sebagai parent memudahkan pengelompokan dan manipulasi transformasi secara hierarkis.
