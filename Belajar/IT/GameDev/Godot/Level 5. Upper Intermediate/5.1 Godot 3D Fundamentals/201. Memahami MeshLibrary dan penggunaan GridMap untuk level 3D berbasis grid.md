# 201. Memahami MeshLibrary dan Penggunaan GridMap untuk Level 3D Berbasis Grid

## Definisi Singkat
MeshLibrary adalah kumpulan mesh yang dapat digunakan kembali, sedangkan GridMap adalah node yang memungkinkan pembuatan level 3D berbasis grid secara efisien dengan menggabungkan mesh-mesh dari MeshLibrary dalam susunan kotak-kotak.

## Analogi
Bayangkan seperti bermain Lego. MeshLibrary adalah kotak berisi berbagai jenis balok (dinding, lantai, tangga), dan GridMap adalah papan tempat kamu menempatkan balok-balok itu satu per satu ke dalam grid untuk membentuk sebuah bangunan atau level.

## Struktur Node (Scene Tree)
```
Node3D (Root)
├── GridMap (menggunakan MeshLibrary)
├── Player (CharacterBody3D)
└── Camera3D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@export var grid_map: GridMap

func _ready():
    grid_map.clear()
    for x in range(-5, 6):
        for z in range(-5, 6):
            grid_map.set_cell_item(Vector3i(x, 0, z), 0)
            if abs(x) == 5 or abs(z) == 5:
                grid_map.set_cell_item(Vector3i(x, 1, z), 1)

func _input(event):
    if event is InputEventMouseButton and event.pressed:
        var camera = $Camera3D
        var from = camera.project_ray_origin(event.position)
        var to = from + camera.project_ray_normal(event.position) * 100
        var space_state = get_world_3d().direct_space_state
        var query = PhysicsRayQueryParameters3D.create(from, to)
        var result = space_state.intersect_ray(query)
        if result:
            var cell = grid_map.local_to_map(result.position)
            grid_map.set_cell_item(cell, 0)
```

## Kasus Penggunaan Nyata
GridMap sangat efisien untuk membuat level dungeon, puzzle game 3D, atau game strategi berbasis grid. Dengan menggunakan MeshLibrary, kamu dapat menggabungkan banyak mesh menjadi satu draw call, meningkatkan performa secara signifikan. GridMap juga memudahkan level editing karena kamu dapat menggambar level langsung di editor menggunakan tool painting yang tersedia.
