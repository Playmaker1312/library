# 204. Implementasi Third-Person Controller dengan Spring Arm Camera

## Definisi Singkat
Third-person controller menempatkan kamera di belakang karakter dengan SpringArm3D yang secara otomatis menyesuaikan jarak kamera berdasarkan tabrakan dengan lingkungan, mencegah kamera tembus ke dalam objek atau dinding.

## Analogi
Bayangkan seperti kamera drone yang mengikuti kamu dari belakang. SpringArm3D adalah tali yang menghubungkan drone dengan tubuhmu. Jika ada dinding di belakangmu, tali itu memendek secara otomatis agar drone tidak menabrak dinding, tapi tetap menjaga jarak aman saat tidak ada halangan.

## Struktur Node (Scene Tree)
```
CharacterBody3D (Player)
├── MeshInstance3D (visual karakter)
├── CollisionShape3D
└── SpringArm3D
    └── Camera3D
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

const SPEED = 5.0
const JUMP_VELOCITY = 4.5
const MOUSE_SENSITIVITY = 0.002
const SPRING_ARM_LENGTH = 3.0
var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")

@onready var spring_arm = $SpringArm3D
@onready var camera = $SpringArm3D/Camera3D

func _ready():
    Input.mouse_mode = Input.MOUSE_MODE_CAPTURED
    spring_arm.spring_length = SPRING_ARM_LENGTH

func _unhandled_input(event):
    if event is InputEventMouseMotion:
        rotate_y(-event.relative.x * MOUSE_SENSITIVITY)
        spring_arm.rotation.x = clamp(spring_arm.rotation.x - event.relative.y * MOUSE_SENSITIVITY, deg_to_rad(-60), deg_to_rad(60))
    if event.is_action_pressed("ui_cancel"):
        Input.mouse_mode = Input.MOUSE_MODE_VISIBLE

func _physics_process(delta):
    if not is_on_floor():
        velocity.y -= gravity * delta
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VELOCITY
    var input_dir = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    var direction = (transform.basis * Vector3(input_dir.x, 0, input_dir.y)).normalized()
    if direction:
        velocity.x = direction.x * SPEED
        velocity.z = direction.z * SPEED
        look_at(position + direction, Vector3.UP)
    else:
        velocity.x = move_toward(velocity.x, 0, SPEED)
        velocity.z = move_toward(velocity.z, 0, SPEED)
    move_and_slide()
```

## Kasus Penggunaan Nyata
Third-person controller dengan SpringArm3D digunakan di game seperti Dark Souls, The Witcher, atau GTA. SpringArm3D secara otomatis mendeteksi tabrakan dan menyesuaikan jarak kamera, sehingga pemain tidak kehilangan pandangan karakter saat berada di area sempit atau di belakang objek besar. Ini menghemat banyak waktu dibandingkan menulis sistem collision camera manual.
