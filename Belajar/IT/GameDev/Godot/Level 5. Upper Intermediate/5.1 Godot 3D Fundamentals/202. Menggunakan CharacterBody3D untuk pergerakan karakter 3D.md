# 202. Menggunakan CharacterBody3D untuk Pergerakan Karakter 3D

## Definisi Singkat
CharacterBody3D adalah node khusus untuk karakter yang membutuhkan pergerakan kinematik (tanpa fisik penuh), mendukung fitur seperti gravity, move_and_slide, dan floor detection untuk karakter 2.5D atau 3D.

## Analogi
CharacterBody3D seperti遥控 mobil remote control. Bukan mobil sungguhan yang memiliki fisika penuh, tapi kendaraan yang bergerak sesuai perintahmu dengan kontrol penuh terhadap kecepatan, arah, dan gravitasi tanpa terpengaruh oleh objek fisik lain secara acak.

## Struktur Node (Scene Tree)
```
CharacterBody3D (Player)
├── MeshInstance3D (visual karakter)
├── CollisionShape3D (bentuk fisik)
└── Camera3D (opsional, bisa di parent terpisah)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody3D

const SPEED = 5.0
const JUMP_VELOCITY = 4.5
var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")

func _physics_process(delta):
    if not is_on_floor():
        velocity.y -= gravity * delta
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VELOCITY
    var input_dir = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    var direction = (transform.basis * Vector3(input_dir.x, 0, input_dir.y)).normalized()
    if direction:
        velocity.x = direction.x * SPEED
        velocity.z = direction.z * SPEED
    else:
        velocity.x = move_toward(velocity.x, 0, SPEED)
        velocity.z = move_toward(velocity.z, 0, SPEED)
    move_and_slide()
```

## Kasus Penggunaan Nyata
CharacterBody3D digunakan untuk karakter utama dalam game third-person, first-person, atau top-down 3D. Cocok untuk game petualangan, RPG, atau action di mana kamu ingin kontrol penuh atas pergerakan karakter tanpa terpengaruh simulasi fisika penuh seperti rigid body. Gravity dan floor detection memudahkan implementasi mekanik lompatan dan interaksi dengan permukaan.
