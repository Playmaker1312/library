# 206. Menggunakan WorldEnvironment dan Sky untuk Menciptakan Atmosfer Scene 3D

## Definisi Singkat
WorldEnvironment mengatur pengaturan lingkungan global seperti ambient light, fog, dan tone mapping, sedingga Sky adalah sumber cahaya ambient yang berasal dari langit, menciptakan atmosfer dan pencahayaan alami pada scene 3D.

## Analogi
Bayangkan WorldEnvironment adalah cuaca dan suasana kota: apakah cerah, berkabut, atau malam. Sky adalah langit itu sendiri yang memberikan cahaya ambient ke seluruh objek di kota, menciptakan bayangan lembut dan warna alami tanpa perlu menambahkan banyak lampu buatan.

## Struktur Node (Scene Tree)
```
Node3D (Root)
├── WorldEnvironment (pengaturan lingkungan)
├── DirectionalLight3D (matahari)
├── Player (CharacterBody3D)
└── Environment objects
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@onready var world_env = $WorldEnvironment

func _ready():
    var env = Environment.new()
    env.background_mode = Environment.BG_SKY
    var sky = Sky.new()
    var sky_material = ProceduralSkyMaterial.new()
    sky_material.sky_top_color = Color(0.2, 0.4, 0.8)
    sky_material.sky_horizon_color = Color(0.6, 0.7, 0.9)
    sky_material.ground_bottom_color = Color(0.1, 0.1, 0.1)
    sky_material.ground_horizon_color = Color(0.5, 0.5, 0.5)
    sky.sky_material = sky_material
    env.sky = sky
    env.ambient_light_source = Environment.AMBIENT_SOURCE_SKY
    env.ambient_light_energy = 0.5
    env.tonemap_mode = Environment.TONE_MAP_ACES
    env.ssao_enabled = true
    env.glow_enabled = true
    env.fog_enabled = true
    env.fog_light_color = Color(0.7, 0.8, 1.0)
    env.fog_density = 0.01
    world_env.environment = env

func _process(delta):
    var sky_material = world_env.environment.sky.sky_material
    sky_material.sky_top_color.h = fmod(sky_material.sky_top_color.h + 0.01 * delta, 1.0)
```

## Kasus Penggunaan Nyata
WorldEnvironment dan Sky digunakan untuk menciptakan suasana game yang kaya seperti langit senja yang hangat untuk game petualangan, atmosfer gelap untuk game horror, atau langit cerah untuk game kasual. Fitur seperti fog menambah kedalaman visual, SSAO (Screen Space Ambient Occlusion) menambah realisme bayangan, dan glow menambah efek cahaya yang lebih dinamis. Kombinasi ini mengubah tampilan game dari biasa menjadi profesional tanpa banyak usaha tambahan.
