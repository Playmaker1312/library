# 240. Menggunakan version control Git bersama Godot secara efektif

## Definisi Singkat
Version control Git adalah sistem pelacakan perubahan file yang memungkinkan beberapa pengembang bekerja pada project yang sama secara bersamaan. Godot memiliki integrasi native dengan Git untuk mengelola source code dan aset game.

## Analogi
Bayangkan Git seperti sistem revisi dokumen di Google Docs, tetapi lebih powerful. Setiap kali kamu menyimpan perubahan (commit), Git membuat "foto" kondisi project saat itu. Kamu bisa kembali ke versi mana pun sebelumnya, seperti fitur undo yang tak terbatas, dan bekerja bersama tim tanpa saling menimpa pekerjaan.

## Struktur Node (Scene Tree)
Tidak ada struktur node khusus untuk Git. Git bekerja di level file system di luar Godot editor.

```
project_folder/
├── .git/
├── .gitignore
├── project.godot
├── scenes/
│   ├── main.tscn
│   └── player.tscn
├── scripts/
│   ├── player.gd
│   └── enemy.gd
├── assets/
│   ├── sprites/
│   └── audio/
└── addons/
```

## Kode GDScript (Godot 4)

```gdscript
extends Control

var git_status_label: Label

func _ready() -> void:
    git_status_label = $StatusLabel
    _check_git_status()

func _check_git_status() -> void:
    var output: Array = []
    OS.execute("git", ["status", "--porcelain"], output)
    var changes: String = output[0] if output.size() > 0 else "No changes"
    git_status_label.text = "Git Status:\n" + changes

func _on_commit_button_pressed() -> void:
    var message: String = $CommitLineEdit.text
    if message.is_empty():
        return
    OS.execute("git", ["add", "."])
    OS.execute("git", ["commit", "-m", message])
    _check_git_status()

func _on_push_button_pressed() -> void:
    OS.execute("git", ["push"])
    _check_git_status()

func _on_pull_button_pressed() -> void:
    OS.execute("git", ["pull"])
    _check_git_status()
```

## Kasus Penggunaan Nyata
Tim pengembang game indie menggunakan Git untuk berkolaborasi dari rumah masing-masing. Programmer membuat perubahan pada script gameplay, sementara artist mengupdate aset sprite tanpa konflik. Ketika bug muncul di versi terbaru, tim bisa langsung revert ke versi stable sebelum bug diperkenalkan.
