# 243. Membuat editor tool sederhana menggunakan annotation tool

## Definisi Singkat
Annotation tool di Godot adalah fitur editor yang memungkinkan menambahkan visualisasi debug seperti garis, persegi, dan teks pada viewport tanpa mempengaruhi game yang running. Tool ini sangat berguna untuk debugging spatial dan visualisasi data gameplay.

## Analogi
Annotation tool seperti sticky notes transparan yang kamu tempel pada layar komputer. Notes ini hanya terlihat saat kamu bekerja (mode editor/debug), tapi tidak muncul saat user akhir memainkan game-mu. Kamu bisa menandai area, menunjukkan path, atau highlight masalah tanpa mengubah game itu sendiri.

## Struktur Node (Scene Tree)
Annotation bekerja pada node `CanvasItem` dan turunannya:

```
Node2D (Root)
├── Player
│   ├── Sprite2D
│   └── CollisionShape2D
├── Enemy
├── DebugDraw (script annotation)
└── Camera2D
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

var show_debug: bool = false
var enemy_positions: Array[Vector2] = []
var path_points: PackedVector2Array = PackedVector2Array()

func _ready() -> void:
    _gather_debug_data()

func _gather_debug_data() -> void:
    var enemies: Array[Node] = get_tree().get_nodes_in_group("enemies")
    for enemy in enemies:
        enemy_positions.append(enemy.global_position)

    var path_node: Path2D = get_node_or_null("../Path2D")
    if path_node and path_node.curve:
        path_points = path_node.curve.get_baked_points()

func _process(_delta: float) -> void:
    if show_debug:
        queue_redraw()

func _draw() -> void:
    if not show_debug:
        return
    _draw_enemy_positions()
    _draw_path()
    _draw_player_detection_radius()

func _draw_enemy_positions() -> void:
    for pos: Vector2 in enemy_positions:
        draw_circle(pos, 16.0, Color.RED)
        draw_arc(pos, 20.0, 0, TAU, 64, Color.RED, 1.0)

func _draw_path() -> void:
    if path_points.size() < 2:
        return
    for i: int in range(path_points.size() - 1):
        draw_line(path_points[i], path_points[i + 1], Color.CYAN, 2.0)

func _draw_player_detection_radius() -> void:
    var player: Node2D = get_node_or_null("../Player")
    if not player:
        return
    var radius: float = 120.0
    draw_arc(player.global_position, radius, 0, TAU, 64, Color.YELLOW, 2.0)
    draw_string(ThemeDB.fallback_font, player.global_position + Vector2(10, -10), "Detect Radius", HORIZONTAL_ALIGNMENT_LEFT, -1, 12, Color.YELLOW)

func _unhandled_input(event: InputEvent) -> void:
    if event is InputEventKey:
        if event.pressed and event.keycode == KEY_F3:
            show_debug = not show_debug
```

## Kasus Penggunaan Nyata
Developer platformer game menggunakan annotation tool untuk visualisasi pathfinding musuh saat debugging. Dengan menekan F3, semua jalur patrol musuh, radius deteksi player, dan collision area ditampilkan di viewport. Ini membantu developer memahami perilaku musuh dan menyeimbangkan gameplay tanpa perlu log teks ke konsol.
