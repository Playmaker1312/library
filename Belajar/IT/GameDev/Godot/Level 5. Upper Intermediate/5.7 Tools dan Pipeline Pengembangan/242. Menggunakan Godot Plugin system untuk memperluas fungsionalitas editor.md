# 242. Menggunakan Godot Plugin system untuk memperluas fungsionalitas editor

## Definisi Singkat
Godot Plugin system memungkinkan pengembang membuat ekstensi kustom yang terintegrasi langsung ke dalam editor. Plugin bisa menambahkan toolbar baru, dock panel, inspector custom, dan tool lainnya untuk mempercepat workflow pengembangan.

## Analogi
Plugin di Godot seperti aplikasi tambahan di smartphone-mu. HP tanpa aplikasi tambahan sudah berfungsi, tapi dengan aplikasi yang tepat (kamera, editor foto, maps), fungsionalitasnya jauh lebih powerful. Plugin Godot menambahkan fitur spesifik yang dibutuhkan project-mu.

## Struktur Node (Scene Tree)
Plugin terdiri dari struktur folder khusus:

```
addons/
└── my_plugin/
    ├── plugin.cfg
    ├── plugin.gd
    ├── scenes/
    │   └── custom_dock.tscn
    └── scripts/
        └── tool_scripts.gd
```

## Kode GDScript (Godot 4)

```gdscript
# plugin.cfg
[plugin]
name="My Custom Plugin"
description="Plugin untuk mempercepat workflow"
author="Developer"
version="1.0.0"
script="plugin.gd"
```

```gdscript
# plugin.gd
@tool
extends EditorPlugin

var dock_control: Control

func _enter_tree() -> void:
    dock_control = preload("res://addons/my_plugin/scenes/custom_dock.tscn").instantiate()
    add_control_to_bottom_panel(dock_control, "My Tools")
    add_tool_menu_item("Generate Level", _on_generate_level)

func _exit_tree() -> void:
    remove_control_from_bottom_panel(dock_control)
    remove_tool_menu_item("Generate Level")
    if dock_control:
        dock_control.queue_free()

func _on_generate_level() -> void:
    var editor_interface: EditorInterface = get_editor_interface()
    var root: Node = editor_interface.get_edited_scene_root()
    if not root:
        return
    var level_gen: Node = preload("res://addons/my_plugin/scripts/level_generator.gd").new()
    root.add_child(level_gen)
    level_gen.owner = root
```

```gdscript
# level_generator.gd
@tool
extends Node

func _ready() -> void:
    if not Engine.is_editor_hint():
        return
    _generate_level()

func _generate_level() -> void:
    var room_scene: PackedScene = preload("res://scenes/room.tscn")
    for x in range(5):
        for y in range(3):
            var room: Node = room_scene.instantiate()
            room.position = Vector2(x * 640, y * 360)
            add_child(room)
            room.owner = get_tree().edited_scene_root
```

## Kasus Penggunaan Nyata
Studio game menggunakan plugin untuk membuat tools level editor kustom. Level designer bisa placement objects dengan drag-and-drop langsung di editor tanpa harus edit scene file secara manual. Plugin juga bisa generate dungeon secara procedural langsung dari menu editor, mempercepat iterasi desain level dari jam ke menit.
