# 246. Teknik debugging lanjutan menggunakan Remote Debugger dan Breakpoint

## Definisi Singkat
Remote Debugger adalah fitur Godot yang memungkinkan debug game dari jarak jauh, sementara Breakpoint adalah titik henti eksekusi kode yang memungkinkan inspeksi variabel dan state saat runtime. Kombinasi keduanya adalah tools debugging paling powerful di Godot.

## Analogi
Remote Debugger seperti dokter yang bisa memeriksa pasien dari ruangan lain melalui monitor. Breakpoint seperti menekan tombol pause pada mesin waktu — kamu bisa melihat semua kondisi persis saat masalah terjadi, memeriksa setiap komponen, lalu melanjutkan atau memutar ulang.

## Struktur Node (Scene Tree)

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

@export var speed: float = 200.0
@export var jump_force: float = -400.0
var gravity: float = ProjectSettings.get_setting("physics/2d/default_gravity")
var is_debugging: bool = false

func _ready() -> void:
    is_debugging = OS.is_debug_build()
    if is_debugging:
        print("[DEBUG] Player initialized at: ", global_position)
        print("[DEBUG] Speed: ", speed, " | Jump Force: ", jump_force)

func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity.y += gravity * delta

    var direction: float = Input.get_axis("move_left", "move_right")
    velocity.x = direction * speed

    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = jump_force

    move_and_slide()

    if is_debugging and Engine.get_process_frames() % 60 == 0:
        _debug_print_state()

func _debug_print_state() -> void:
    var state: Dictionary = {
        "position": global_position,
        "velocity": velocity,
        "is_on_floor": is_on_floor(),
        "current_speed": absf(velocity.x)
    }
    print("[DEBUG] Frame ", Engine.get_process_frames(), ": ", state)

func _draw_debug_circle(center: Vector2, radius: float, color: Color) -> void:
    var points: PackedVector2Array = PackedVector2Array()
    var segments: int = 32
    for i: int in range(segments + 1):
        var angle: float = TAU * i / segments
        points.append(center + Vector2(cos(angle), sin(angle)) * radius)
    draw_polyline(points, color, 2.0)
```

```gdscript
# debug_breakpoint_example.gd
extends Node

var enemy_count: int = 0
var spawn_timer: float = 0.0

func _process(delta: float) -> void:
    spawn_timer += delta
    if spawn_timer >= 3.0:
        spawn_timer = 0.0
        _spawn_enemy()

func _spawn_enemy() -> void:
    enemy_count += 1
    if enemy_count > 10:
        push_warning("Too many enemies! Count: ", enemy_count)
        breakpoint
    print("Spawned enemy #", enemy_count)
```

## Kasus Penggunaan Nyata
Developer mengalami bug di mana player bisa melompat dua kali. Dengan Remote Debugger, mereka bisa inspect state `is_on_floor` saat lompatan kedua terjadi. Breakpoint di fungsi jump memungkinkan melihat nilai variabel persis saat bug terjadi. Remote Debugger juga berguna untuk debug game yang sudah di-export di device mobile, memungkinkan debug dari PC tanpa perlu layar device.
