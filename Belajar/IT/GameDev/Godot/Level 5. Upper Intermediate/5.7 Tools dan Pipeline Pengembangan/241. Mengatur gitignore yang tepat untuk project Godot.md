# 241. Mengatur gitignore yang tepat untuk project Godot

## Definisi Singkat
`.gitignore` adalah file konfigurasi yang memberitahu Git file dan folder mana yang tidak boleh dilacak. Untuk project Godot, file ini penting agar file biner besar, cache, dan file sistem tidak ikut ter committed ke repository.

## Analogi
Bayangkan `.gitignore` seperti filter sampah di rumahmu. Kamu tidak ingin membuang furniture ke tempat sampah umum, bukan? Sama dengan Git — file build output, cache, dan file temporary Godot tidak perlu masuk ke repository karena bisa di-generate ulang kapan saja.

## Struktur Node (Scene Tree)
Tidak berlaku untuk konfigurasi Git.

```
project_folder/
├── .git/
├── .gitignore
├── project.godot
├── scenes/
├── scripts/
├── assets/
├── .godot/          ← HARUS di-ignore (import cache)
├── export/          ← HARUS di-ignore (build output)
└── *.translation    ← HARUS di-ignore (generated files)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node

func _ready() -> void:
    _create_gitignore_if_missing()

func _create_gitignore_if_missing() -> void:
    var path: String = "res://.gitignore"
    if not FileAccess.file_exists(path):
        var content: String = _get_gitignore_content()
        var file: FileAccess = FileAccess.open(path, FileAccess.WRITE)
        file.store_string(content)
        file.close()

func _get_gitignore_content() -> String:
    return """# Godot
.godot/
*.tmp
*.tmp~
*.translation

# Builds
export/
builds/
*.pck
*.zip

# IDE
.vscode/
.idea/
*.swp
*.swo
*~

# OS
.DS_Store
Thumbs.db
desktop.ini

# Logs
*.log
logs/
"""
```

## Kasus Penggunaan Nyata
Tanpa `.gitignore` yang benar, repository Godot bisa membengkak hingga ratusan MB karena folder `.godot/` berisi cache import yang besar. Dengan `.gitignore` yang tepat, repository hanya berisi file sumber yang diperlukan, menghemat storage dan waktu clone untuk anggota tim baru.
