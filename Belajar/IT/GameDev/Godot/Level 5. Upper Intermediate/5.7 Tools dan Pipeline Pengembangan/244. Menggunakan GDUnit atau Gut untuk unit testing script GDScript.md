# 244. Menggunakan GDUnit atau Gut untuk unit testing script GDScript

## Definisi Singkat
GDUnit dan Gut adalah framework testing untuk Godot yang memungkinkan menulis dan menjalankan unit test pada script GDScript. Testing memastikan kode game berfungsi sesuai harapan dan mendeteksi regresi saat perubahan dilakukan.

## Analogi
Unit testing seperti menjalankan checklist inspeksi sebelum pesawat terbang. Setiap komponen diperiksa satu per satu (apakah mesin menyala? apakah sayap utuh? apakah sistem navigasi berfungsi?). Ketika semua test pass, kamu yakin game aman dari bug yang tidak terduga.

## Struktur Node (Scene Tree)
GDUnit tidak memerlukan struktur node khusus. Test files ditempatkan di folder terpisah:

```
project_folder/
├── scripts/
│   ├── player.gd
│   └── health_system.gd
├── tests/
│   ├── test_player.gd
│   ├── test_health_system.gd
│   └── test_enemy.gd
└── addons/
    └── gut/
        ├── gut.gd
        └── ...
```

## Kode GDScript (Godot 4)

```gdscript
# health_system.gd
extends Resource
class_name HealthSystem

signal health_changed(new_health: int)
signal died

var max_health: int = 100
var current_health: int = 100

func take_damage(amount: int) -> void:
    current_health = maxi(current_health - amount, 0)
    health_changed.emit(current_health)
    if current_health <= 0:
        died.emit()

func heal(amount: int) -> void:
    current_health = mini(current_health + amount, max_health)
    health_changed.emit(current_health)

func is_alive() -> bool:
    return current_health > 0
```

```gdscript
# test_health_system.gd
extends GutTest

var health: HealthSystem

func before_each() -> void:
    health = HealthSystem.new()
    health.max_health = 100
    health.current_health = 100

func test_initial_health() -> void:
    assert_eq(health.current_health, 100, "Health awal harus 100")

func test_take_damage() -> void:
    health.take_damage(30)
    assert_eq(health.current_health, 70, "Health setelah damage 30 harus 70")

func test_heal() -> void:
    health.take_damage(50)
    health.heal(20)
    assert_eq(health.current_health, 70, "Health setelah heal 20 harus 70")

func test_heal_does_not_exceed_max() -> void:
    health.take_damage(10)
    health.heal(50)
    assert_eq(health.current_health, 100, "Health tidak boleh melebihi max")

func test_take_lethal_damage() -> void:
    health.take_damage(150)
    assert_eq(health.current_health, 0, "Health harus 0 setelah damage fatal")
    assert_false(health.is_alive(), "Player harus mati")

func test_signal_died_emitted() -> void:
    watch_signals(health)
    health.take_damage(100)
    assert_signal_emitted(health, "died", "Signal died harus ter-emit")

func test_signal_health_changed() -> void:
    watch_signals(health)
    health.take_damage(25)
    assert_signal_emitted(health, "health_changed", "Signal health_changed harus ter-emit")
```

## Kasus Penggunaan Nyata
Tim pengembang RPG menggunakan GDUnit untuk menguji sistem inventory, stats karakter, dan combat mechanics. Setiap kali programmer mengubah formula damage, test suite otomatis memverifikasi bahwa semua perhitungan masih benar. Ini mencegah bug kritis seperti item yang bisa duplikasi atau damage yang tidak sesuai balance.
