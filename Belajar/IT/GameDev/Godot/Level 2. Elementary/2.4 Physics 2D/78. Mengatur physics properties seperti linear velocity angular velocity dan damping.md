# 78. Mengatur Physics Properties Seperti Linear Velocity, Angular Velocity, dan Damping

## Definisi Singkat
**Linear Velocity** adalah kecepatan translasi (gerak lurus), **Angular Velocity** adalah kecepatan rotasi, dan **Damping** mengontrol seberapa cepat objek kehilangan kecepatan (seperti gesekan udara).

## Analogi
**Linear Velocity** seperti mobil yang melaju ke depan. **Angular Velocity** seperti mobil yang berputar di tempat. **Damping** seperti menekan rem atau resistensi udara — semakin tinggi nilainya, semakin cepat objek berhenti tanpa ada yang menahannya.

## Kode GDScript (Godot 4)

**Linear velocity dan angular velocity dasar:**
```gdscript
extends RigidBody2D

func _ready():
    gravity_scale = 1.0
    linear_damp = 0.0
    angular_damp = 0.0

func apply_thrust(direction: Vector2, power: float):
    linear_velocity = direction * power

func apply_spin(rotations_per_second: float):
    angular_velocity = rotations_per_second * TAU
```

**Projectile dengan velocity constant:**
```gdscript
extends RigidBody2D

var direction: Vector2 = Vector2.RIGHT
var speed: float = 800.0

func _ready():
    gravity_scale = 0.0
    linear_damp = 0.0
    angular_damp = 0.0
    contact_monitor = true
    max_contacts_reported = 1

func launch(launch_direction: Vector2):
    direction = launch_direction.normalized()
    linear_velocity = direction * speed
    rotation = direction.angle()

func _on_body_entered(body):
    queue_free()
```

**Kontrol dampening dinamis:**
```gdscript
extends RigidBody2D

@export var normal_damping: float = 0.5
@export var ice_damping: float = 0.05
var is_on_ice: bool = false

func _ready():
    linear_damp = normal_damping
    angular_damp = normal_damping

func _process(delta):
    if is_on_ice:
        linear_damp = lerp(linear_damp, ice_damping, delta * 5.0)
    else:
        linear_damp = lerp(linear_damp, normal_damping, delta * 5.0)
```

**Top spinning dengan angular velocity:**
```gdscript
extends RigidBody2D

var spin_power: float = 50.0
var decay_rate: float = 2.0

func _ready():
    gravity_scale = 0.5
    physics_material_override = PhysicsMaterial.new()
    physics_material_override.friction = 0.1
    physics_material_override.bounce = 0.3

func spin(direction: float):
    angular_velocity = direction * spin_power

func _process(delta):
    if angular_velocity > 0:
        angular_velocity = max(0, angular_velocity - decay_rate * delta)
    elif angular_velocity < 0:
        angular_velocity = min(0, angular_velocity + decay_rate * delta)
```

**Car movement dengan physics:**
```gdscript
extends RigidBody2D

@export var engine_power: float = 500.0
@export var turn_speed: float = 3.0
@export var brake_force: float = 10.0

func _physics_process(delta):
    var throttle = Input.get_axis("brake", "accelerate")
    var steering = Input.get_axis("steer_right", "steer_left")

    var forward = transform.x
    linear_velocity += forward * throttle * engine_power * delta

    if abs(linear_velocity.x) > 10 or abs(linear_velocity.y) > 10:
        angular_velocity += steering * turn_speed * delta

    if Input.is_action_pressed("brake"):
        linear_velocity *= (1.0 - brake_force * delta)
```

## Kasus Penggunaan Nyata
Linear velocity berguna untuk projectile dan kendaraan. Angular velocity untuk objek berputar seperti propeller atau tops. Damping digunakan untuk membuat objek meluncur di es (damping rendah) atau berhenti cepat di aspal (damping tinggi). Kombinasi ketiganya memungkinkan physics yang realistis untuk berbagai jenis game.
