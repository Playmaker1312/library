# 72. Memahami Layer dan Mask pada Collision System Godot

## Definisi Singkat
**Collision Layer** menentukan di layer mana sebuah objek berada, sedangkan **Collision Mask** menentukan layer mana yang akan dideteksi oleh objek tersebut. Keduanya menggunakan bitmask untuk mengontrol interaksi physics.

## Analogi
Bayangkan kamu memakai kacamata hitam berwarna merah (Mask). Kamu hanya bisa melihat objek berwarna merah (Layer yang dimask). Jika objek berada di layer merah tapi kamu tidak memakai kacamata merah, kamu tidak akan melihatnya. Layer adalah "di mana aku berada", Mask adalah "apa yang aku lihat".

## Struktur Node (Scene Tree)

```
Node2D (Root)
├── Player (CharacterBody2D)
│   ├── CollisionShape2D (Layer: 1, Mask: 2,3)
├── Enemy (CharacterBody2D)
│   ├── CollisionShape2D (Layer: 2, Mask: 1,3)
├── Bullet (Area2D)
│   ├── CollisionShape2D (Layer: 3, Mask: 1,2)
└── Platform (StaticBody2D)
    ├── CollisionShape2D (Layer: 4, Mask: 1,2,3)
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

func _ready():
    collision_layer = 1
    collision_mask = 2 | 4

func toggle_collision():
    collision_layer ^= 1
    collision_mask ^= 2

func set_physics_layer(layer_bit: int, enabled: bool):
    if enabled:
        collision_layer |= (1 << layer_bit)
    else:
        collision_layer &= ~(1 << layer_bit)

func is_colliding_with_layer(layer_bit: int) -> bool:
    return (collision_mask & (1 << layer_bit)) != 0
```

**Setup collision di Inspector (alternatif kode):**
```gdscript
extends Node2D

func setup_layers():
    $Player.collision_layer = 1
    $Player.collision_mask = 2 | 4
    $Enemy.collision_layer = 2
    $Enemy.collision_mask = 1
    $Bullet.collision_layer = 4
    $Bullet.collision_mask = 1 | 2
```

## Kasus Penggunaan Nyata
Sistem Layer dan Mask sangat berguna untuk memisahkan interaksi physics. Contoh nyata: peluru player (Layer 4) hanya perlu mendeteksi musuh (Layer 2) dan tembok (Layer 1), tapi tidak perlu mendeteksi peluru musuh lain. Dengan masking yang tepat, kamu menghindari collision yang tidak perlu dan menghemat performa game.
