# 73. Menggunakan Area2D untuk Deteksi Overlap dan Trigger Zone

## Definisi Singkat
**Area2D** adalah node untuk mendeteksi saat objek memasuki, berada dalam, atau keluar dari area tanpa melakukan physics collision. Sering digunakan untuk trigger zone, pickup item, atau zona bahaya.

## Analogi
Bayangkan sebuah pintu sensor di mall. Ketika kamu melewatinya, alarm berbunyi tapi kamu tidak menabrak pintu tersebut. Area2D bekerja seperti sensor itu — mendeteksi kehadiran objek tanpa menahannya.

## Struktur Node (Scene Tree)

```
Node2D (Root)
├── TriggerZone (Area2D)
│   ├── CollisionShape2D
│   └── Sprite2D
├── Player (CharacterBody2D)
│   ├── CollisionShape2D
├── Coin (Area2D)
│   ├── CollisionShape2D
│   └── Sprite2D
└── Lava (Area2D)
    ├── CollisionShape2D
    └── AnimatedSprite2D
```

## Kode GDScript (Godot 4)

**Trigger Zone sederhana:**
```gdscript
extends Area2D

signal player_entered
signal player_exited

func _on_body_entered(body):
    if body.name == "Player":
        player_entered.emit()

func _on_body_exited(body):
    if body.name == "Player":
        player_exited.emit()
```

**Coin Pickup:**
```gdscript
extends Area2D

@export var score_value: int = 10

func _on_body_entered(body):
    if body.name == "Player":
        body.add_score(score_value)
        queue_free()

func _on_area_entered(area):
    if area.get_parent().name == "Player":
        area.get_parent().add_score(score_value)
        queue_free()
```

**Lava Damage Zone:**
```gdscript
extends Area2D

@export var damage: float = 10.0
var damage_timer: float = 0.0
const DAMAGE_INTERVAL: float = 0.5

func _process(delta):
    damage_timer += delta
    if damage_timer >= DAMAGE_INTERVAL:
        damage_timer = 0.0
        for body in get_overlapping_bodies():
            if body.name == "Player":
                body.take_damage(damage)
```

**Cara koneksi signal di GDScript:**
```gdscript
extends Area2D

func _ready():
    body_entered.connect(_on_body_entered)
    body_exited.connect(_on_body_exited)
    area_entered.connect(_on_area_entered)

func _on_body_entered(body):
    pass

func _on_body_exited(body):
    pass

func _on_area_entered(area):
    pass
```

## Kasus Penggunaan Nyata
Area2D cocok untuk pickup item seperti koin dan health pack yang menghilang saat disentuh. Trigger zone untuk cutscene, pintu yang terbuka otomatis, atau zona checkpoint. Juga berguna untuk zona bahaya seperti lava, radiasi, atau area yang memulai musik tertentu saat pemain masuk.
