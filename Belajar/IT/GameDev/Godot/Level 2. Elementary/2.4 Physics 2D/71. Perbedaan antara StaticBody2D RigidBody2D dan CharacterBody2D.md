# 71. Perbedaan antara StaticBody2D, RigidBody2D, dan CharacterBody2D

## Definisi Singkat
Tiga tipe physics body utama di Godot 2D: **StaticBody2D** untuk objek statis yang tidak bergerak, **RigidBody2D** untuk objek yang dikontrol oleh physics engine, dan **CharacterBody2D** untuk karakter yang dikontrol manual oleh pemain/program.

## Analogi
Bayangkan sebuah ruangan: dinding dan lantai adalah **StaticBody2D** (tidak pernah bergerak). Bola yang dilempar dan jatuh karena gravitasi adalah **RigidBody2D** (fisika mengontrolnya). Karakter pemain yang berjalan dan melompat adalah **CharacterBody2D** (kita yang mengontrol gerakannya).

## Struktur Node (Scene Tree)

```
Node2D (Root)
├── StaticBody2D (Dinding/Lantai)
│   ├── CollisionShape2D
│   └── Sprite2D
├── RigidBody2D (Bola)
│   ├── CollisionShape2D
│   └── Sprite2D
└── CharacterBody2D (Pemain)
    ├── CollisionShape2D
    └── Sprite2D
```

## Kode GDScript (Godot 4)

**StaticBody2D:**
```gdscript
extends StaticBody2D

func _ready():
    pass
```

**RigidBody2D:**
```gdscript
extends RigidBody2D

func _ready():
    gravity_scale = 1.0
    linear_damp = 0.0

func _on_body_entered(body):
    if body is CharacterBody2D:
        queue_free()
```

**CharacterBody2D:**
```gdscript
extends CharacterBody2D

const SPEED = 300.0
const JUMP_VELOCITY = -400.0
var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta):
    if not is_on_floor():
        velocity.y += gravity * delta
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VELOCITY
    var direction = Input.get_axis("ui_left", "ui_right")
    velocity.x = direction * SPEED
    move_and_slide()
```

## Kasus Penggunaan Nyata
**StaticBody2D** cocok untuk terrain statis seperti platform, dinding, dan lantai yang tidak akan pernah bergerak. **RigidBody2D** ideal untuk objek seperti mobil, granat, atau barang-barang yang jatuh dan terpengaruh gravitasi serta benturan. **CharacterBody2D** adalah pilihan utama untuk karakter pemain platformer karena memberikan kontrol penuh atas gerakan tanpa intervensi physics engine yang tidak diinginkan.
