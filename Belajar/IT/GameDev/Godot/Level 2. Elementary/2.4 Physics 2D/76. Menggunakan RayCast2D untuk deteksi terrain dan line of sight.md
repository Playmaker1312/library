# 76. Menggunakan RayCast2D untuk Deteksi Terrain dan Line of Sight

## Definisi Singkat
**RayCast2D** menembakkan garis invisible ke arah tertentu dan mendeteksi objek apa yang terkena. Digunakan untuk deteksi ground, wall check, line of sight musuh, dan verifikasi posisi karakter.

## Analogi
Bayangkan kamu memegang laser pointer dan menyorotkannya ke depan. Laser itu akan berhenti saat mengenai dinding. RayCast2D bekerja sama — menembakkan "laser" virtual untuk mendeteksi apa yang ada di jalurnya.

## Struktur Node (Scene Tree)

```
Player (CharacterBody2D)
├── CollisionShape2D
├── GroundRay (RayCast2D)        # Deteksi tanah
├── WallCheckRay (RayCast2D)     # Deteksi tembok
└── CeilingRay (RayCast2D)       # Deteksi langit-langit

Enemy (CharacterBody2D)
├── CollisionShape2D
└── LineOfSight (RayCast2D)      # Deteksi pemain
```

## Kode GDScript (Godot 4)

**Deteksi ground untuk platformer:**
```gdscript
extends CharacterBody2D

@onready var ground_ray: RayCast2D = $GroundRay

func _physics_process(delta):
    if ground_ray.is_colliding():
        var collision_point = ground_ray.get_collision_point()
        var normal = ground_ray.get_collision_normal()
        print("Tanah ditemukan di: ", collision_point)
```

**Wall check untuk movement:**
```gdscript
extends CharacterBody2D

@onready var wall_ray: RayCast2D = $WallCheckRay

func can_move_in_direction(direction: int) -> bool:
    wall_ray.target_position = Vector2(direction * 50, 0)
    wall_ray.force_raycast_update()
    return not wall_ray.is_colliding()

func _physics_process(delta):
    var direction = Input.get_axis("move_left", "move_right")
    if direction and can_move_in_direction(int(direction)):
        velocity.x = direction * 300.0
    else:
        velocity.x = move_toward(velocity.x, 0, 300.0)
    move_and_slide()
```

**Line of sight untuk musuh:**
```gdscript
extends CharacterBody2D

@onready var los_ray: RayCast2D = $LineOfSight
var player: CharacterBody2D = null
var can_see_player: bool = false

func _ready():
    player = get_tree().get_first_node_in_group("player")

func _physics_process(delta):
    if player:
        los_ray.target_position = to_local(player.global_position)
        los_ray.force_raycast_update()
        can_see_player = los_ray.is_colliding() and los_ray.get_collider() == player

        if can_see_player:
            print("Pemain terlihat!")
```

**Multiple raycast untuk deteksi terrain:**
```gdscript
extends Node2D

@export var ray_count: int = 8
@export var ray_length: float = 100.0
var rays: Array[RayCast2D] = []

func _ready():
    for i in range(ray_count):
        var ray = RayCast2D.new()
        ray.target_position = Vector2.from_angle(i * TAU / ray_count) * ray_length
        ray.enabled = true
        add_child(ray)
        rays.append(ray)

func get_terrain_info() -> Dictionary:
    var info = {"points": [], "normals": []}
    for ray in rays:
        if ray.is_colliding():
            info.points.append(ray.get_collision_point())
            info.normals.append(ray.get_collision_normal())
    return info
```

## Kasus Penggunaan Nyata
RayCast2D digunakan untuk ground check agar karakter tahu kapan menyentuh tanah. Wall check mencegah karakter masuk ke tembok. Line of sight memungkinkan musuh AI mendeteksi pemain hanya jika tidak ada penghalang, menciptakan gameplay stealth yang realistis.
