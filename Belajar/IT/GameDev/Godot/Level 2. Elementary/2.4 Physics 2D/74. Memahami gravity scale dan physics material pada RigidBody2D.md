# 74. Memahami Gravity Scale dan Physics Material pada RigidBody2D

## Definisi Singkat
**Gravity Scale** mengontrol seberapa kuat gravitasi mempengaruhi RigidBody2D (1.0 = normal, 2.0 = dua kali lebih berat). **Physics Material** mengontrol properti seperti gesekan (friction) dan pantulan (bounce) saat objek bertabrakan.

## Analogi
**Gravity Scale** seperti daya tarik gravitasi di planet berbeda. Di bulan gravitasi lemah (scale 0.17), di Jupiter sangat kuat (scale 2.5). **Physics Material** seperti memilih sepatu: sol licin (friction rendah) membuatmu meluncur, sol kasar (friction tinggi) memberikan grip. Bounce seperti memilih bahan bola — karet memantul kuat, bisbol tidak.

## Kode GDScript (Godot 4)

**Setup RigidBody2D dengan gravity scale:**
```gdscript
extends RigidBody2D

@export var gravity_multiplier: float = 1.0

func _ready():
    gravity_scale = gravity_multiplier
    physics_material_override = PhysicsMaterial.new()
    physics_material_override.friction = 0.3
    physics_material_override.bounce = 0.5
```

**Bola bouncing tinggi:**
```gdscript
extends RigidBody2D

func _ready():
    gravity_scale = 1.0
    physics_material_override = PhysicsMaterial.new()
    physics_material_override.friction = 0.0
    physics_material_override.bounce = 0.95
    linear_damp = 0.0
    angular_damp = 0.0

func apply_launch(force: Vector2):
    apply_central_impulse(force)
```

**Ice block dengan gesekan rendah:**
```gdscript
extends RigidBody2D

func _ready():
    gravity_scale = 1.0
    physics_material_override = PhysicsMaterial.new()
    physics_material_override.friction = 0.05
    physics_material_override.bounce = 0.1
    linear_damp = 0.5
    angular_damp = 2.0

func apply_push(direction: Vector2, power: float):
    apply_central_impulse(direction * power)
```

**Dinamis mengubah material:**
```gdscript
extends RigidBody2D

var normal_material: PhysicsMaterial
var ice_material: PhysicsMaterial
var is_on_ice: bool = false

func _ready():
    normal_material = PhysicsMaterial.new()
    normal_material.friction = 0.8
    normal_material.bounce = 0.2

    ice_material = PhysicsMaterial.new()
    ice_material.friction = 0.02
    ice_material.bounce = 0.1

func _on_ice_zone_entered():
    is_on_ice = true
    physics_material_override = ice_material

func _on_ice_zone_exited():
    is_on_ice = false
    physics_material_override = normal_material
```

## Kasus Penggunaan Nyata
Gravity Scale berguna untuk membuat efek gravitasi berbeda: bulan dengan gravitasi rendah, zone antigravitasi dengan scale negatif, atau boss yang sangat berat dengan scale tinggi. Physics Material digunakan untuk membuat lantai es (friction rendah), bola basket (bounce tinggi), atau platform karet yang memantulkan pemain ke atas.
