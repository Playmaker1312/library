# 53. Menggunakan Type Hints untuk Menulis Kode GDScript yang Lebih Aman dan Mudah Dibaca

## Definisi Singkat
Type hints adalah penanda tipe data pada variabel, parameter, dan return value fungsi. Type hints membantu IDE memberikan autocompletion dan mendeteksi error sebelum kode dijalankan.

## Analogi
Type hints seperti label pada wadah makanan. Label memberi tahu isi wadah tanpa perlu membukanya, sehingga kamu tidak salah mengambil isi.

## Struktur Node (Scene Tree)
Type hints tidak terikat node tertentu. Type hints bisa digunakan di semua variabel, parameter, dan return value dalam script.

## Kode GDScript (Godot 4)
```gdscript
extends Node

var nama: String = "Budi"
var umur: int = 25
var tinggi: float = 170.5
var aktif: bool = True
var posisi: Vector2 = Vector2(100, 200)
var warna: Color = Color.RED
var parent: Node = self

@export var kecepatan: int = 100
@export var nama_player: String = "Player"

func tambah(a: int, b: int) -> int:
    return a + b

func sapa(nama: String) -> String:
    return "Halo, " + nama

func get_posisi() -> Vector2:
    return position

func is_active() -> bool:
    return aktif

func get_items() -> Array[String]:
    return ["pedang", "perisai", "potion"]

func get_player_data() -> Dictionary:
    return {"nama": nama, "umur": umur}

func set_data(key: String, value: Variant) -> void:
    print(key + ": " + str(value))

func _ready() -> void:
    var hasil_tambah: int = tambah(5, 3)
    var sapaan: String = sapa("Andi")
    
    print(hasil_tambah)
    print(sapaan)
    
    var items: Array[String] = get_items()
    for item in items:
        print(item)
    
    var data: Dictionary = get_player_data()
    for key in data:
        print(key + " = " + str(data[key]))
    
    set_data("hp", 100)
    set_data("nama", "Budi")
    
    var numbers: Array[int] = [1, 2, 3, 4, 5]
    var nama_array: PackedStringArray = ["apel", "mangga"]
    var posisi_array: Array[Vector2] = [Vector2(0, 0), Vector2(100, 100)]
    
    print(numbers)
    print(nama_array)
    print(posisi_array)
```

## Kasus Penggunaan Nyata
Type hints memudahkan tim developer dalam memahami kode, mencegah bug akibat tipe data yang salah, dan mempercepat proses debugging. Type hints juga membantu IDE memberikan saran yang lebih akurat.
