# 54. Memahami Enumerasi atau Enum untuk Mendefinisikan Kumpulan Konstanta

## Definisi Singkat
Enum adalah tipe data yang mendefinisikan kumpulan konstanta bernama dengan nilai numerik. Enum membuat kode lebih readable dan mencegah kesalahan penggunaan nilai yang tidak valid.

## Analogi
Enum seperti lampu lalu lintas yang hanya bisa bernilai merah, kuning, atau hijau. Tidak ada nilai lain yang diperbolehkan, sehingga lebih aman dan jelas.

## Struktur Node (Scene Tree)
Enum bisa digunakan di script mana saja untuk mendefinisikan state, jenis serangan, atau kategori item.

## Kode GDScript (Godot 4)
```gdscript
extends Node

enum Direction {UP, DOWN, LEFT, RIGHT}
enum GameState {MENU, PLAYING, PAUSED, GAME_OVER}
enum WeaponType {SWORD, BOW, STAFF, SHIELD}
enum Rarity {COMMON, UNCOMMON, RARE, EPIC, LEGENDARY}

func _ready():
    var player_direction: Direction = Direction.UP
    var current_state: GameState = GameState.PLAYING
    var current_weapon: WeaponType = WeaponType.SWORD
    var item_rarity: Rarity = Rarity.EPIC
    
    match player_direction:
        Direction.UP:
            print("Berdgerak ke atas")
        Direction.DOWN:
            print("Berdgerak ke bawah")
        Direction.LEFT:
            print("Berdgerak ke kiri")
        Direction.RIGHT:
            print("Berdgerak ke kanan")
    
    match current_state:
        GameState.MENU:
            print("Di menu utama")
        GameState.PLAYING:
            print("Sedang bermain")
        GameState.PAUSED:
            print("Game dijeda")
        GameState.GAME_OVER:
            print("Game over")
    
    match current_weapon:
        WeaponType.SWORD:
            print("Senjata: Pedang")
        WeaponType.BOW:
            print("Senjata: Panah")
        WeaponType.STAFF:
            print("Senjata: Tongkat")
        WeaponType.SHIELD:
            print("Senjata: Perisai")
    
    match item_rarity:
        Rarity.COMMON:
            print("Common")
        Rarity.UNCOMMON:
            print("Uncommon")
        Rarity.RARE:
            print("Rare")
        Rarity.EPIC:
            print("Epic")
        Rarity.LEGENDARY:
            print("Legendary")
    
    print("Direction UP value: ", Direction.UP)
    print("Direction DOWN value: ", Direction.DOWN)
    print("Rarity LEGENDARY value: ", Rarity.LEGENDARY)
    
    var rarity_name: String = Rarity.keys()[item_rarity]
    print("Rarity name: ", rarity_name)
```

## Kasus Penggunaan Nyata
Enum digunakan untuk mendefinisikan state machine karakter, jenis senjata atau item, atau level kesulitan game. Enum membuat kode lebih terstruktur dan mengurangi risiko error karena nilai yang tidak valid.
