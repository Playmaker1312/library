# 55. Error Handling Dasar Menggunakan Assert dan Push Error dalam GDScript

## Definisi Singkat
Assert dan push error adalah alat untuk menangani dan mendeteksi error dalam kode. Assert memeriksa kondisi saat development, sedangkan push error mencetak pesan error ke output.

## Analogi
Assert seperti pemeriksa tiket di gerbang yang memastikan kamu memiliki tiket sebelum masuk. Push error seperti alarm yang berbunyi ketika ada masalah.

## Struktur Node (Scene Tree)
Error handling bisa digunakan di node mana saja untuk validasi input, debugging, dan memastikan kode berjalan sesuai harapan.

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
    var umur: int = 25
    assert(umur >= 0, "Umur tidak boleh negatif")
    print("Umur valid: ", umur)
    
    var nama: String = "Budi"
    assert(nama.length() > 0, "Nama tidak boleh kosong")
    print("Nama valid: ", nama)
    
    var skor: int = 150
    assert(skor >= 0 and skor <= 100, "Skor harus antara 0-100")
    
    var hp: int = -10
    if hp < 0:
        push_error("HP tidak boleh negatif: " + str(hp))
    
    var file_path: String = "res://data.json"
    if not FileAccess.file_exists(file_path):
        push_error("File tidak ditemukan: " + file_path)
    
    var kecepatan: int = -5
    if kecepatan < 0:
        push_warning("Kecepatan negatif, menggunakan nilai absolut")
        kecepatan = abs(kecepatan)
    
    var division_result: float
    var a: int = 10
    var b: int = 0
    assert(b != 0, "Pembagian dengan nol tidak diizinkan")
    division_result = float(a) / b
    
    var inventory: Array = []
    assert(inventory.size() < 10, "Inventory penuh")
    inventory.append("pedang")
    
    var items: Dictionary = {"pedang": 1, "perisai": 1}
    var item_name: String = "pedang"
    assert(items.has(item_name), "Item tidak ditemukan: " + item_name)
    items[item_name] += 1
    
    print("Semua validasi berhasil")
    
    push_error("Ini adalah contoh error message")
    push_warning("Ini adalah contoh warning message")
```

## Kasus Penggunaan Nyata
Assert digunakan untuk memastikan data yang masuk valid sebelum diproses, seperti memeriksa HP tidak negatif atau inventory tidak penuh. Push error dan push warning membantu developer menemukan masalah saat debugging tanpa menghentikan program.
