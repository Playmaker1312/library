# 46. Array dalam GDScript: Cara Membuat, Mengakses, dan Memanipulasi Data Array

## Definisi Singkat
Array adalah struktur data yang menyimpan sekumpulan nilai dalam satu variabel dengan indeks numerik. Dalam GDScript, Array bersifat dinamis dan dapat menampung berbagai tipe data sekaligus.

## Analogi
Array seperti rak sepatu dengan nomor di setiap slot. Kamu bisa meletakkan sepatu di slot tertentu, mengambil sepatu berdasarkan nomor slot, atau mengganti isi slot dengan sepatu baru.

## Struktur Node (Scene Tree)
Tidak memerlukan struktur node khusus. Array digunakan di mana saja dalam script.

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
    var fruits = ["apel", "mangga", "jeruk"]
    var mixed = [1, "dua", 3.0, true]
    
    print(fruits[0])
    print(fruits.size())
    
    fruits.append("pisang")
    fruits.insert(1, "melon")
    fruits.remove_at(0)
    
    fruits.shuffle()
    fruits.sort()
    
    var numbers = [5, 3, 1, 4, 2]
    var index = numbers.find(4)
    numbers.erase(1)
    
    var joined = ", ".join(fruits)
    print(joined)
    
    for fruit in fruits:
        print(fruit)
    
    var doubled = numbers.map(func(x): return x * 2)
    print(doubled)
```

## Kasus Penggunaan Nyata
Array digunakan untuk menyimpan daftar item inventory pemain, array musuh dalam satu level, atau daftar checkpoint yang sudah dilewati. Manipulasi array memungkinkan pengurutan skor, pencarian item, dan pengelolaan data secara efisien.
