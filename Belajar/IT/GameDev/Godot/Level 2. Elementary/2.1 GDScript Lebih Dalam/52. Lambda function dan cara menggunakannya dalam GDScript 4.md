# 52. Lambda Function dan Cara Menggunakannya dalam GDScript 4

## Definisi Singkat
Lambda function adalah fungsi anonim yang didefinisikan dalam satu baris tanpa nama. Lambda cocok untuk operasi sederhana yang hanya dipakai sekali atau sebagai parameter fungsi lain.

## Analogi
Lambda seperti catatan tempel yang ditulis cepat untuk tugas sekali pakai. Tidak perlu memberi nama formal, cukup tulis instruksi dan langsung digunakan.

## Struktur Node (Scene Tree)
Lambda tidak terikat node tertentu. Lambda sering digunakan dalam sinyal, fungsi callback, atau operasi array.

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
    var tambah = func(a, b): return a + b
    print(tambah.call(3, 5))
    
    var kuadrat = func(x): return x * x
    print(kuadrat.call(4))
    
    var angka = [5, 3, 1, 4, 2]
    var sorted_desc = angka.duplicate()
    sorted_desc.sort_custom(func(a, b): return a > b)
    print("Sorted desc: ", sorted_desc)
    
    var genap = angka.filter(func(x): return x % 2 == 0)
    print("Genap: ", genap)
    
    var ganjil = angka.filter(func(x): return x % 2 != 0)
    print("Ganjil: ", ganjil)
    
    var jumlah = angka.reduce(func(acc, x): return acc + x, 0)
    print("Jumlah: ", jumlah)
    
    var nama = ["Budi", "Andi", "Citra"]
    var upper_nama = nama.map(func(n): return n.to_upper())
    print("Upper: ", upper_nama)
    
    var ada_besar = angka.any(func(x): return x > 4)
    print("Ada yang > 4: ", ada_besar)
    
    var semua_positif = angka.all(func(x): return x > 0)
    print("Semua positif: ", semua_positif)
    
    var sapa = func(nama):
        print("Halo, " + nama + "!")
    
    sapa.call("Budi")
    sapa.call("Andi")
    
    $Button.pressed.connect(func(): print("Tombol ditekan!"))
```

## Kasus Penggunaan Nyata
Lambda berguna untuk callback sinyal tanpa membuat fungsi terpisah, operasi array seperti filter dan map, atau logika sementara yang tidak perlu diulang di tempat lain.
