# 47. Dictionary dalam GDScript: Cara Membuat, Mengakses, dan Mengiterasi Key-Value

## Definisi Singkat
Dictionary adalah struktur data yang menyimpan pasangan key-value, di mana setiap value diakses menggunakan key unik. Dictionary cocok untuk data yang memiliki hubungan nama-nilai.

## Analogi
Dictionary seperti kamus bahasa, di mana setiap kata (key) memiliki arti (value). Kamu mencari arti berdasarkan kata, bukan berdasarkan urutan halaman.

## Struktur Node (Scene Tree)
Tidak memerlukan struktur node khusus. Dictionary digunakan untuk data konfigurasi, state, atau metadata dalam script.

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
    var player = {
        "nama": "Budi",
        "level": 5,
        "hp": 100,
        "skills": ["tembak", "lari"]
    }
    
    print(player["nama"])
    print(player.get("mana", 0))
    
    player["mana"] = 50
    player["level"] = 6
    
    player.erase("skills")
    
    print(player.keys())
    print(player.values())
    print(player.has("nama"))
    
    for key in player:
        print(key + ": " + str(player[key]))
    
    for key in player.keys():
        var value = player[key]
        print(str(key) + " = " + str(value))
    
    var merged = player.merged({"guild": "Ksatria", "level": 7})
    print(merged)
    
    var has_all = player.has_all(["nama", "hp"])
    print(has_all)
```

## Kasus Penggunaan Nyata
Dictionary digunakan untuk menyimpan data profil pemain, konfigurasi level, atau properties sebuah objek game. Dictionary juga berguna untuk membuat sistem dialog berbasis key atau mapping input ke aksi.
