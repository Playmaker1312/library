# 49. Menggunakan Match Statement sebagai Alternatif If-Elif yang Lebih Bersih

## Definisi Singkat
Match statement adalah kontrol alur yang membandingkan sebuah nilai dengan beberapa pola sekaligus. Match lebih ringkas dan mudah dibaca dibandingkan rantai if-elif yang panjang.

## Analogi
Match seperti filter yang memisahkan surat berdasarkan kode pos. Setiap kode pos memiliki jalur pengiriman sendiri, dan kamu cukup melihat kode pos untuk menentukan tujuannya.

## Struktur Node (Scene Tree)
Match dapat digunakan di node mana saja untuk menangani input, state, atau jenis objek yang berbeda.

## Kode GDScript (Godot 4)
```gdscript
extends Node

enum State {IDLE, WALK, RUN, JUMP, FALL}

func _ready():
    var kondisi = "basah"
    match kondisi:
        "kering":
            print("Tidak basah")
        "basah":
            print("Sedang basah")
        "becek":
            print("Sangat basah")
        _:
            print("Kondisi tidak diketahui")
    
    var skor = 85
    match skor:
        90:
            print("Grade A")
        80:
            print("Grade B")
        70:
            print("Grade C")
        _:
            print("Grade lainnya")
    
    var state = State.IDLE
    match state:
        State.IDLE:
            print("Sedang diam")
        State.WALK:
            print("Sedang berjalan")
        State.RUN:
            print("Sedang berlari")
        State.JUMP:
            print("Sedang melompat")
        State.FALL:
            print("Sedang jatuh")
    
    var input_key = "ui_accept"
    match input_key:
        "ui_accept":
            print("Tombol accept ditekan")
        "ui_cancel":
            print("Tombol cancel ditekan")
        "ui_left":
            print("Gerak ke kiri")
        "ui_right":
            print("Gerak ke kanan")
        _:
            print("Input tidak dikenali")
    
    var angka = 2
    match angka:
        1, 3, 5:
            print("Ganjil")
        2, 4, 6:
            print("Genap")
        _:
            print("Di luar range")
```

## Kasus Penggunaan Nyata
Match cocok untuk menangani state machine karakter, memproses jenis serangan yang berbeda, atau menentukan aksi berdasarkan input pemain. Match membuat kode lebih terstruktur dan mudah dipelihara.
