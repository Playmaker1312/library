# 50. Konsep Class dalam GDScript: Mendefinisikan Class, Inner Class, dan Inheritance Dasar

## Definisi Singkat
Class adalah blueprint atau cetakan yang mendefinisikan properti dan perilaku suatu objek. Dalam GDScript, setiap file .gd secara otomatis adalah class, dan kamu bisa mendefinisikan inner class di dalamnya.

## Analogi
Class seperti cetakan kue. Dari satu cetakan kamu bisa membuat banyak kue dengan bentuk sama tapi isi berbeda. Inheritance seperti cetakan turunan yang mewarisi bentuk cetakan induk tapi bisa ditambah fitur baru.

## Struktur Node (Scene Tree)
Class bisa direpresentasikan sebagai node. Sebuah script yang melekat pada node menjadi perilaku node tersebut, dan class bisa diwarisi oleh script lain.

## Kode GDScript (Godot 4)
```gdscript
extends Node

class Mahasiswa:
    var nama: String
    var ipk: float
    
    func _init(nama_baru: String, ipk_baru: float):
        nama = nama_baru
        ipk = ipk_baru
    
    func tampilkan_info():
        return nama + " - IPK: " + str(ipk)
    
    func lulus():
        return ipk >= 2.0

class Sarjana extends Mahasiswa:
    var jurusan: String
    
    func _init(nama_baru: String, ipk_baru: String, jurusan_baru: String):
        super._init(nama_baru, ipk_baru)
        jurusan = jurusan_baru
    
    func tampilkan_info():
        return super.tampilkan_info() + " - " + jurusan

func _ready():
    var mhs1 = Mahasiswa.new("Andi", 3.5)
    print(mhs1.tampilkan_info())
    print("Lulus: ", mhs1.lulus())
    
    var mhs2 = Sarjana.new("Budi", 3.8, "Informatika")
    print(mhs2.tampilkan_info())
    print("Lulus: ", mhs2.lulus())
    
    var mhs3 = Mahasiswa.new("Citra", 1.8)
    print(mhs3.tampilkan_info())
    print("Lulus: ", mhs3.lulus())
```

## Kasus Penggunaan Nyata
Class digunakan untuk membuat template karakter musuh, item, atau NPC dengan属性 yang sama tapi nilai berbeda. Inheritance memungkinkan pembuatan musuh tipe tertentu yang mewarisi perilaku musuh dasar.
