# 48. Tipe Data Vector2 dan Vector3 serta Operasi Matematika Dasarnya

## Definisi Singkat
Vector2 dan Vector3 adalah tipe data yang merepresentasikan posisi, arah, atau ukuran dalam 2D dan 3D. Keduanya mendukung operasi matematika vektor seperti penjumlahan, pengurangan, dan normalisasi.

## Analogi
Vector seperti panah yang memiliki arah dan panjang. Vector2 adalah panah di atas kertas (ke atas, ke bawah, ke kiri, ke kanan), sedangkan Vector3 adalah panah di ruang nyata (tambah kedalaman).

## Struktur Node (Scene Tree)
Vector2 dan Vector3 digunakan di berbagai node seperti Position2D, Position3D, Node2D, Node3D, dan property transform lainnya.

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

var posisi = Vector2(100, 200)
var arah = Vector2(1, 0)
var kecepatan = 150.0

func _ready():
    var a = Vector2(3, 4)
    var b = Vector2(1, 2)
    
    var hasil_tambah = a + b
    var hasil_kurang = a - b
    var hasil_kali = a * 2
    var hasil_bagi = a / 2
    
    print("Panjang vektor: ", a.length())
    print("Panjang kuadrat: ", a.length_squared())
    
    var normalized = a.normalized()
    print("Normalized: ", normalized)
    
    var dot_product = a.dot(b)
    print("Dot product: ", dot_product)
    
    var distance = a.distance_to(b)
    print("Jarak: ", distance)
    
    var v3a = Vector3(1, 2, 3)
    var v3b = Vector3(4, 5, 6)
    var cross = v3a.cross(v3b)
    print("Cross product: ", cross)
    
    var posisi_3d = Vector3(10, 0, 5)
    var target_3d = Vector3(0, 0, 5)
    var arah_3d = posisi_3d.direction_to(target_3d)
    print("Arah 3D: ", arah_3d)

func _process(delta):
    var gerak = arah * kecepatan * delta
    posisi += gerak
    position = posisi
```

## Kasus Penggunaan Nyata
Vector2 dan Vector3 digunakan untuk menggerakkan karakter, menghitung jarak antar objek, menentukan arah pandang kamera, atau melakukan fisika sederhana seperti pantulan dan gravitasi dalam game 2D dan 3D.
