# 51. Memahami Static Variable dan Static Function dalam GDScript

## Definisi Singkat
Static variable adalah variabel yang dimiliki oleh class itu sendiri, bukan oleh instance objek. Static function adalah fung yang bisa dipanggil tanpa perlu membuat objek terlebih dahulu.

## Analogi
Static seperti nomor induk yang berlaku untuk semua siswa di sekolah. Tidak perlu tahu nama siswa tertentu untuk mengecek nomor induk, cukup akses data sekolah langsung.

## Struktur Node (Scene Tree)
Static variable dan function tidak terikat pada node tertentu. Mereka bisa diakses dari mana saja dalam project.

## Kode GDScript (Godot 4)
```gdscript
extends Node

class GameManager:
    static var skor_tertinggi: int = 0
    static var jumlah_player: int = 0
    static var instance_count: int = 0
    
    var nama_player: String
    
    static func tambah_skor(baru: int):
        if baru > skor_tertinggi:
            skor_tertinggi = baru
    
    static func get_skor():
        return skor_tertinggi
    
    static func reset_skor():
        skor_tertinggi = 0
    
    static func get_jumlah_player():
        return jumlah_player
    
    func _init(nama: String):
        nama_player = nama
        instance_count += 1
        jumlah_player += 1

func _ready():
    var p1 = GameManager.new("Budi")
    var p2 = GameManager.new("Andi")
    
    GameManager.tambah_skor(100)
    GameManager.tambah_skor(250)
    GameManager.tambah_skor(150)
    
    print("Skor tertinggi: ", GameManager.get_skor())
    print("Jumlah player: ", GameManager.get_jumlah_player())
    print("Jumlah instance: ", GameManager.instance_count)
    
    print("Player 1: ", p1.nama_player)
    print("Player 2: ", p2.nama_player)
    
    GameManager.reset_skor()
    print("Skor setelah reset: ", GameManager.get_skor())
```

## Kasus Penggunaan Nyata
Static variable berguna untuk menyimpan skor tertinggi global, jumlah musuh yang sudah dikalahkan, atau pengaturan game yang berlaku keseluruhan. Static function memudahkan akses tanpa perlu referensi objek tertentu.
