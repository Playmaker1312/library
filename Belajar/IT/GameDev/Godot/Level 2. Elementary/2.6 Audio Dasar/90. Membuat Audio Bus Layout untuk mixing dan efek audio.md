# 90. Membuat Audio Bus Layout untuk mixing dan efek audio

## Definisi Singkat
Audio Bus Layout adalah sistem manajemen audio di Godot yang memungkinkan kamu mengelola jalur-jalur audio terpisah dengan efek masing-masing. Setiap bus dapat memiliki efek seperti Reverb, EQ, dan Compressor untuk mengontrol kualitas suara secara terpisah.

## Analogi
Audio Bus Layout seperti mixing console di studio rekaman. Setiap fader mewakili satu jalur audio (bus) yang bisa dikontrol volumenya secara terpisah. Kamu bisa menambahkan efek pada setiap jalur seperti menambahkan plugin pada mixer untuk mengubah karakter suara.

## Struktur Node (Scene Tree)
```
Audio (Panel Audio Bus di Editor)
├── Master
├── Music
├── SFX
└── Voice
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

@onready var music_player: AudioStreamPlayer = $MusicPlayer
@onready var sfx_player: AudioStreamPlayer = $SFXPlayer

func _ready() -> void:
	music_player.bus = "Music"
	sfx_player.bus = "SFX"
	
	AudioServer.set_bus_volume_db(
		AudioServer.get_bus_index("Music"),
		linear_to_db(0.8)
	)
	AudioServer.set_bus_volume_db(
		AudioServer.get_bus_index("SFX"),
		linear_to_db(1.0)
	)
	
	var reverb: AudioEffectReverb = AudioEffectReverb.new()
	AudioServer.add_bus_effect(AudioServer.get_bus_index("SFX"), reverb)
```

## Kasus Penggunaan Nyata
Audio Bus Layout sangat berguna untuk game dengan banyak jenis suara. Kamu bisa membuat bus terpisah untuk musik, efek suara, dan dialog. Setiap bus bisa memiliki efek yang berbeda, seperti reverb untuk suara di dalam gedung atau equalizer untuk mengatur tone musik agar tidak mengganggu dialog karakter.
