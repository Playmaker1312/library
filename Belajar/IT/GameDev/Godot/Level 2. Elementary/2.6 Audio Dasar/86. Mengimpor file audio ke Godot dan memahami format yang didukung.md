# 86. Mengimpor file audio ke Godot dan memahami format yang didukung

## Definisi Singkat
Godot Engine mendukung beberapa format audio yang dapat diimpor langsung ke dalam project. Format yang paling umum digunakan adalah WAV, OGG Vorbis, dan MP3, masing-masing dengan kelebihan dan kekurangan tersendiri terkait kualitas dan ukuran file.

## Analogi
Mengimpor file audio ke Godot seperti memasukkan CD ke dalam pemutar musik. CD (WAV) memberikan kualitas terbaik tetapi ukurannya besar, MP3 seperti file musik digital yang sudah dikompres agar lebih kecil, dan OGG seperti format keseimbangan antara kualitas dan ukuran yang sering digunakan untuk game.

## Struktur Node (Scene Tree)
```
Node2D (Root)
├── AudioStreamPlayer (untuk musik latar)
├── AudioStreamPlayer2D (untuk efek suara posisional)
└── AudioStreamPlayer3D (untuk efek suara 3D)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var audio_player: AudioStreamPlayer = $AudioStreamPlayer

func _ready() -> void:
	var audio_stream: AudioStream = preload("res://assets/audio/music.wav")
	audio_player.stream = audio_stream
	audio_player.play()
```

## Kasus Penggunaan Nyata
Dalam pengembangan game, kamu akan sering mengimpor file audio untuk musik latar, efek suara tembakan, suara langkah kaki, dan dialog karakter. Pemilihan format yang tepat sangat penting untuk menjaga kualitas game tetap ringan tanpa mengorbankan kualitas audio yang signifikan.
