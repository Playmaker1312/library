# 91. Cara memutar menghentikan dan mengulang audio dari GDScript

## Definisi Singkat
GDScript menyediakan berbagai metode untuk mengontrol pemutaran audio seperti play(), stop(), dan berbagai properti untuk mengontrol perilaku audio. Kamu juga bisa menggunakan sinyal finished untuk mendeteksi kapan audio selesai diputar.

## Analogi
Mengontrol audio dari GDScript seperti mengoperasikan pemutar musik di ponsel. Kamu bisa menekan tombol play untuk memutar, pause untuk menjeda, stop untuk menghentikan, dan mengatur agar musik berulang secara otomatis atau berpindah ke lagu berikutnya.

## Struktur Node (Scene Tree)
```
Node2D (Root)
└── AudioStreamPlayer
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var audio_player: AudioStreamPlayer = $AudioStreamPlayer

func _ready() -> void:
	audio_player.stream = preload("res://assets/audio/music.wav")
	audio_player.finished.connect(_on_audio_finished)
	audio_player.play()

func play_audio() -> void:
	audio_player.play()

func stop_audio() -> void:
	audio_player.stop()

func pause_audio() -> void:
	audio_player.stream_paused = true

func resume_audio() -> void:
	audio_player.stream_paused = false

func set_loop(loops: bool) -> void:
	if audio_player.stream is AudioStreamWAV:
		(audio_player.stream as AudioStreamWAV).loop_mode = (
			AudioStreamWAV.LOOP_FORWARD if loops else AudioStreamWAV.LOOP_DISABLED
		)

func _on_audio_finished() -> void:
	audio_player.play()
```

## Kasus Penggunaan Nyata
Kontrol audio dari GDScript diperlukan untuk berbagai skenario game. Misalnya memutar suara efek saat pemain menembak, menghentikan musik saat pause, menjeda audio saat transisi scene, atau membuat musik berulang selama pemain berada di area tertentu.
