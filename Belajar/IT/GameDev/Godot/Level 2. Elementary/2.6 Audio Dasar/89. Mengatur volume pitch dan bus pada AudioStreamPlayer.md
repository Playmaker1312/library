# 89. Mengatur volume pitch dan bus pada AudioStreamPlayer

## Definisi Singkat
AudioStreamPlayer memiliki properti volume_db untuk mengatur kekerasan suara, pitch_scale untuk mengatur nada atau kecepatan audio, dan bus untuk menentukan jalur audio (audio bus) yang digunakan sebagai output.

## Analogi
Mengatur volume seperti mengatur keran air, semakin tinggi nilainya semakin keras suaranya. Pitch seperti memutar knob pada pemutar kaset, mempercepat atau memperlambat putaran yang mengubah nada suara. Bus seperti jalur khusus untuk jenis suara tertentu, misalnya jalur khusus untuk musik dan jalur khusus untuk efek suara.

## Struktur Node (Scene Tree)
```
Node2D (Root)
└── AudioStreamPlayer
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var audio_player: AudioStreamPlayer = $AudioStreamPlayer

func _ready() -> void:
	audio_player.stream = preload("res://assets/audio/sfx.wav")
	audio_player.volume_db = -6.0
	audio_player.pitch_scale = 1.2
	audio_player.bus = "SFX"
	audio_player.play()

func set_volume(linear_value: float) -> void:
	audio_player.volume_db = linear_to_db(linear_value)

func set_pitch(new_pitch: float) -> void:
	audio_player.pitch_scale = new_pitch
```

## Kasus Penggunaan Nyata
Pengaturan volume, pitch, dan bus sangat penting untuk mixing audio dalam game. Volume digunakan untuk mengatur keseimbangan antara musik dan efek suara, pitch untuk membuat variasi suara agar tidak monoton, dan bus untuk menerapkan efek seperti reverb atau echo pada kelompok suara tertentu.
