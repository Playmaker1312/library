# 87. Menggunakan AudioStreamPlayer untuk memutar musik latar

## Definisi Singkat
AudioStreamPlayer adalah node yang digunakan untuk memutar audio yang tidak terikat dengan posisi tertentu di dunia game, seperti musik latar atau efek suara global yang harus terdengar dari mana saja.

## Analogi
AudioStreamPlayer seperti speaker yang diletakkan di tengah ruangan besar. Suara dari speaker ini terdengar sama kerasnya dari sudut manapun di dalam ruangan tersebut, tidak peduli di mana kamu berdiri.

## Struktur Node (Scene Tree)
```
Node2D (Root)
└── AudioStreamPlayer
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var music_player: AudioStreamPlayer = $AudioStreamPlayer

func _ready() -> void:
	music_player.stream = preload("res://assets/audio/bgm.wav")
	music_player.volume_db = -10.0
	music_player.play()

func _on_audio_stream_player_finished() -> void:
	music_player.play()
```

## Kasus Penggunaan Nyata
AudioStreamPlayer sangat cocok untuk memutar musik latar di menu utama, musik tema di area permainan, atau efek suara global seperti suara angin yang terdengar di seluruh peta tanpa memperhatikan posisi pemain.
