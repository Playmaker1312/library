# 69. Membuat sistem input yang mendukung keyboard dan gamepad secara bersamaan

## Definisi Singkat
Sistem input multi-perangkat memungkinkan pemain menggunakan keyboard atau gamepad secara bergantian atau bersamaan tanpa konfigurasi ulang. Godot mendukung ini melalui Input Map yang bisa memiliki beberapa event untuk satu action, termasuk key binding dan joy button binding.

## Analogi
Bayangkan sebuah pintu dengan dua gagang — satu di kiri (keyboard) dan satu di kanan (gamepad). Kedua gagang terhubung ke mekanisme yang sama, jadi pemain bisa memilih gagang mana yang paling nyaman tanpa mengubah cara pintu membuka.

## Struktur Node (Scene Tree)
```
Root (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   └── AnimationPlayer
├── UI (CanvasLayer)
│   ├── InputPrompt (HBoxContainer)
│   │   ├── KeyboardPrompt (TextureRect)
│   │   └── GamepadPrompt (TextureRect)
│   └── HUD (VBoxContainer)
│       └── ScoreLabel (Label)
└── GameManager (Node)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node

var last_input_device: String = "keyboard"

signal input_device_changed(device: String)

func _input(event):
	if event is InputEventKey or event is InputEventMouse or event is InputEventMouseButton:
		if last_input_device != "keyboard":
			last_input_device = "keyboard"
			input_device_changed.emit("keyboard")

	elif event is InputEventJoypadButton or event is InputEventJoypadMotion:
		if last_input_device != "gamepad":
			last_input_device = "gamepad"
			input_device_changed.emit("gamepad")
```

```gdscript
extends Control

@export var keyboard_prompt: Texture2D
@export var gamepad_prompt: Texture2D

@onready var texture_rect: TextureRect = $TextureRect

func _ready():
	GameManager.input_device_changed.connect(_on_input_device_changed)
	_update_prompt(GameManager.last_input_device)

func _on_input_device_changed(device: String):
	_update_prompt(device)

func _update_prompt(device: String):
	match device:
		"keyboard":
			texture_rect.texture = keyboard_prompt
		"gamepad":
			texture_rect.texture = gamepad_prompt
```

```gdscript
extends CharacterBody2D

const SPEED = 300.0
const JUMP_VELOCITY = -450.0
const GAMEPAD_SPEED = 280.0

var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta):
	if not is_on_floor():
		velocity.y += gravity * delta

	if Input.is_action_just_pressed("jump"):
		velocity.y = JUMP_VELOCITY

	var direction = Vector2.ZERO
	direction.x = Input.get_axis("move_left", "move_right")

	if GameManager.last_input_device == "gamepad":
		var stick_input = Vector2(
			Input.get_joy_axis(0, JOY_AXIS_LEFT_X),
			Input.get_joy_axis(0, JOY_AXIS_LEFT_Y)
		)
		if stick_input.length() > 0.2:
			direction = stick_input.normalized()

	if direction.length() > 0:
		var current_speed = GAMEPAD_SPEED if GameManager.last_input_device == "gamepad" else SPEED
		velocity.x = direction.x * current_speed
		$Sprite2D.flip_h = direction.x < 0
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)

	move_and_slide()
```

## Kasus Penggunaan Nyata
Game seperti Hades dan Dead Cells mendukung keyboard dan gamepad secara bersamaan. Saat pemain menekan tombol gamepad, UI prompt langsung berubah menampilkan ikon gamepad. Jika pemain menekan tombol keyboard, prompt kembali ke ikon keyboard. Ini memberikan pengalaman seamless tanpa perlu restart atau rebind manual.
