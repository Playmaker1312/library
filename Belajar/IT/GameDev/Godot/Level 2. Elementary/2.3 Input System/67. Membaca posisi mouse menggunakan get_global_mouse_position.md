# 67. Membaca posisi mouse menggunakan get_global_mouse_position

## Definisi Singkat
Fungsi `get_global_mouse_position()` mengembalikan posisi mouse dalam koordinat world (global) pada node yang memanggilnya. Ini sangat berguna untuk membuat objek mengikuti kursor mouse, menembak ke arah mouse, atau menempatkan objek di posisi kursor.

## Analogi
Bayangkan kamu memegang senter di sebuah peta besar. Posisi tanganmu (node) bergerak di peta, dan senter (mouse) selalu menunjuk ke lokasi tertentu. `get_global_mouse_position` memberitahu lokasi pasti yang ditunjuk senter pada peta tersebut, terlepas di mana tanganmu berada.

## Struktur Node (Scene Tree)
```
Root (Node2D)
├── Player (CharacterBody2D)
│   └── Sprite2D
├── Turret (Node2D)
│   └── Sprite2D
├── BulletSpawn (Marker2D)
└── Projectiles (Node2D)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

@export var follow_speed: float = 10.0

func _process(delta):
	var mouse_pos = get_global_mouse_position()
	global_position = global_position.lerp(mouse_pos, follow_speed * delta)
```

```gdscript
extends Node2D

@export var bullet_scene: PackedScene
@export var fire_rate: float = 0.2
@export var bullet_speed: float = 500.0

var fire_timer: float = 0.0

func _process(delta):
	fire_timer -= delta
	var mouse_pos = get_global_mouse_position()
	var direction = (mouse_pos - global_position).normalized()
	rotation = direction.angle()

	if Input.is_action_pressed("shoot") and fire_timer <= 0:
		fire()
		fire_timer = fire_rate

func fire():
	var bullet = bullet_scene.instantiate()
	bullet.global_position = $BulletSpawn.global_position
	bullet.direction = (get_global_mouse_position() - global_position).normalized()
	bullet.speed = bullet_speed
	get_tree().current_scene.add_child(bullet)
```

```gdscript
extends CharacterBody2D

const SPEED = 300.0

func _process(delta):
	var mouse_pos = get_global_mouse_position()
	look_at(mouse_pos)
	if global_position.distance_to(mouse_pos) > 10:
		global_position = global_position.move_toward(mouse_pos, SPEED * delta)
```

## Kasus Penggunaan Nyata
Mekanik ini digunakan dalam game point-and-click seperti Machinarium di mana pemain mengklik lokasi untuk berpindah. Dalam game top-down shooter, turret otomatis menggunakan `get_global_mouse_position` untuk selalu mengarah ke kursor dan menembak ke arah yang tepat. Game tower defense juga menggunakannya untuk menempatkan menara di posisi kursor.
