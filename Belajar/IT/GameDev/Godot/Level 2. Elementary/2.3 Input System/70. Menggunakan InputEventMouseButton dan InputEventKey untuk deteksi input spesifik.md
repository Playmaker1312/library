# 70. Menggunakan InputEventMouseButton dan InputEventKey untuk deteksi input spesifik

## Definisi Singkat
`InputEventMouseButton` dan `InputEventKey` adalah class yang merepresentasikan event input spesifik dari mouse button dan keyboard key. Keduanya memungkinkan deteksi detail seperti tombol mana yang ditekan, apakah tombol modifier (Shift, Ctrl, Alt) aktif, dan posisi mouse saat klik terjadi.

## Analogi
Bayangkan kamu menerima surat pos. `InputEventMouseButton` seperti amplop yang berisi informasi: siapa pengirimnya (tombol mana), kapan dikirim (frame berapa), dan dari mana asalnya (posisi mouse). `InputEventKey` adalah amplop serupa untuk keyboard — berisi informasi tombol mana yang ditekan dan apakah ada kombinasi tombol lain yang ikut aktif.

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

var click_history: Array[Dictionary] = []

func _unhandled_input(event):
	if event is InputEventMouseButton:
		var info = {
			"button": event.button_index,
			"position": event.position,
			"pressed": event.pressed,
			"double_click": event.double_click,
			"shift": event.shift_pressed,
			"ctrl": event.ctrl_pressed,
			"alt": event.alt_pressed,
			"timestamp": Time.get_ticks_msec()
		}
		if event.pressed:
			click_history.append(info)
			if click_history.size() > 10:
				click_history.pop_front()
			_handle_click(event)

func _handle_click(event: InputEventMouseButton):
	match event.button_index:
		MOUSE_BUTTON_LEFT:
			if event.double_click:
				print("Double click at: ", event.position)
			else:
				print("Left click at: ", event.position)
		MOUSE_BUTTON_RIGHT:
			_show_context_menu(event.position)
		MOUSE_BUTTON_MIDDLE:
			print("Middle click - Pan camera")

func _show_context_menu(pos: Vector2):
	$ContextMenu.position = pos
	$ContextMenu.popup()
```

```gdscript
extends Node2D

var key_buffer: Array[String] = []
var max_buffer_size: int = 10

func _unhandled_input(event):
	if event is InputEventKey and event.pressed and not event.echo:
		var key_name = OS.get_keycode_string(event.keycode)
		var modifiers = []
		if event.ctrl_pressed:
			modifiers.append("Ctrl")
		if event.alt_pressed:
			modifiers.append("Alt")
		if event.shift_pressed:
			modifiers.append("Shift")
		if event.meta_pressed:
			modifiers.append("Meta")

		var full_key = "+".join(modifiers) + ("+" if modifiers.size() > 0 else "") + key_name
		key_buffer.append(full_key)
		if key_buffer.size() > max_buffer_size:
			key_buffer.pop_front()

		print("Key pressed: ", full_key)

		match event.keycode:
			KEY_ESCAPE:
				get_tree().quit()
			KEY_F5:
				get_tree().reload_current_scene()
			KEY_F11:
				if DisplayServer.window_get_mode() == DisplayServer.WINDOW_MODE_FULLSCREEN:
					DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_WINDOWED)
				else:
					DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_FULLSCREEN)

func get_key_history() -> Array[String]:
	return key_buffer
```

```gdscript
extends Area2D

signal item_clicked(item_name: String)
signal item_right_clicked(item_name: String, position: Vector2)

@export var item_name: String = "Unknown Item"

func _on_input_event(_viewport, event, _shape_idx):
	if event is InputEventMouseButton:
		if event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
			item_clicked.emit(item_name)
		elif event.button_index == MOUSE_BUTTON_RIGHT and event.pressed:
			item_right_clicked.emit(item_name, get_global_mouse_position())
```

## Kasus Penggunaan Nyata
Deteksi input spesifik digunakan dalam editor game seperti level editor di Godot sendiri — klik kiri untuk memilih, klik kanan untuk context menu, scroll untuk zoom. Dalam game RTS, click kiri memilih unit, shift+click menambahkan ke seleksi, dan double-click memilih semua unit sejenis. Shortcut keyboard seperti Ctrl+S untuk save juga bergantung pada deteksi modifier key.
