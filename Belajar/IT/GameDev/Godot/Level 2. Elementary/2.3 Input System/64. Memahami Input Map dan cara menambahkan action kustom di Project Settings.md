# 64. Memahami Input Map dan cara menambahkan action kustom di Project Settings

## Definisi Singkat
Input Map adalah sistem di Godot yang memetakan input fisik (tombol keyboard, tombol mouse, tombol gamepad) ke action kustom bernama. Dengan Input Map, kamu bisa mendefinisikan aksi seperti "jump" atau "shoot" dan menanganinya di code tanpa perlu hardcode kode input spesifik.

## Analogi
Bayangkan kamu memiliki remote control universal. Daripada mengingat tombol mana yang menghidupkan TV, tombol mana yang menyalakan AC, kamu cukup menuliskan label "Power TV" dan "Power AC" pada tombol-tombol. Input Map bekerja sama — kamu memberi label nama aksi pada kombinasi tombol input tertentu.

## Struktur Node (Scene Tree)
```
Root (Node2D)
├── Player (CharacterBody2D)
│   └── Sprite2D
└── HUD (CanvasLayer)
    └── Label
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

const SPEED = 300.0
const JUMP_VELOCITY = -400.0

var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta):
	if not is_on_floor():
		velocity.y += gravity * delta

	if Input.is_action_just_pressed("jump") and is_on_floor():
		velocity.y = JUMP_VELOCITY

	var direction = Input.get_axis("move_left", "move_right")
	if direction:
		velocity.x = direction * SPEED
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)

	move_and_slide()
```

**Cara menambahkan Action di Project Settings:**
1. Buka **Project > Project Settings**
2. Pilih tab **Input Map**
3. Ketik nama action baru di kolom **Add New Action** (contoh: `jump`, `move_left`, `move_right`)
4. Klik tombol **+** untuk menambahkan
5. Klik **Add Event** pada action yang baru dibuat
6. Pilih jenis input (Key, Joy Button, Mouse Button, dll.)
7. Tekan tombol/tombol yang diinginkan pada perangkat input
8. Ulangi untuk menambahkan alternatif input (misal: WASD dan arrow keys)

## Kasus Penggunaan Nyata
Input Map sangat penting dalam game yang mendukung berbagai jenis input. Sebuah game platformer bisa mendukung keyboard (WASD/Arrow), gamepad (D-pad/analog), dan touchscreen tanpa mengubah logika game. Developer cukup mendefinisikan action "jump" sekali dan menanganinya di code, sementara pemain bebas memilih perangkat input yang nyaman.
