# 65. Perbedaan antara Input is_action_pressed, is_action_just_pressed, dan is_action_just_released

## Definisi Singkat
Tiga fungsi ini mendeteksi status input action dengan perilaku berbeda: `is_action_pressed` mengembalikan `true` selama tombol ditekan terus-menerus, `is_action_just_pressed` mengembalikan `true` hanya pada frame pertama tombol ditekan, dan `is_action_just_released` mengembalikan `true` hanya pada frame pertama tombol dilepas.

## Analogi
Bayangkan kamu memencet bel pintu. `is_action_pressed` seperti sensor yang aktif selama jari kamu menekan tombol bel (bunyi terus-menerus). `is_action_just_pressed` hanya mendaftar detik pertama kamu menekan (bunyi sekali saat ditekan). `is_action_just_released` mendaftar saat kamu melepas tombol (bunyi sekali saat dilepas).

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

const SPEED = 300.0
const JUMP_VELOCITY = -400.0
const DASH_SPEED = 600.0

var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")
var can_double_jump = true

func _physics_process(delta):
	if not is_on_floor():
		velocity.y += gravity * delta
		if is_on_floor():
			can_double_jump = true

	if Input.is_action_just_pressed("jump"):
		if is_on_floor():
			velocity.y = JUMP_VELOCITY
		elif can_double_jump:
			velocity.y = JUMP_VELOCITY
			can_double_jump = false

	if Input.is_action_pressed("move_right"):
		velocity.x = SPEED
	elif Input.is_action_pressed("move_left"):
		velocity.x = -SPEED
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)

	if Input.is_action_just_pressed("dash"):
		velocity.x = DASH_SPEED * sign(velocity.x) if velocity.x != 0 else DASH_SPEED

	if Input.is_action_just_released("dash"):
		velocity.x = SPEED * sign(velocity.x) if velocity.x != 0 else 0

	move_and_slide()
```

## Kasus Penggunaan Nyata
Perbedaan ini krusial untuk gameplay. `is_action_just_pressed` cocok untuk melompat agar karakter tidak bisa spam lompat di udara. `is_action_pressed` cocok untuk berjalan terus-menerus selama tombol ditekan. `is_action_just_released` berguna untuk mekanik seperti menahan tombol untuk mengisi daya serangan (charge attack) dan melepas untuk melepaskannya.
