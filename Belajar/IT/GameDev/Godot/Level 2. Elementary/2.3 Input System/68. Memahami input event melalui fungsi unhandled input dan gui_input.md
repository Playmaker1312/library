# 68. Memahami input event melalui fungsi unhandled_input dan gui_input

## Definisi Singkat
`_unhandled_input(event)` dipanggil pada node yang menerima input yang belum ditangani oleh node lain (biasanya UI), sedangkan `_gui_input(event)` dipanggil pada Control node saat input terjadi di area控件 tersebut. Keduanya memungkinkan penanganan input pada level yang lebih spesifik dibandingkan `Input.is_action_*`.

## Analogi
Bayangkan sebuah gedung perkantoran. `_unhandled_input` seperti surat yang sampai ke meja resepsionis setelah tidak ada karyawan lain yang menerimanya. `_gui_input` seperti interkom langsung ke ruangan tertentu — pesan hanya diterima di ruangan/area yang dituju.

## Struktur Node (Scene Tree)
```
Root (Node2D)
├── GameWorld (Node2D)
│   ├── Player (CharacterBody2D)
│   └── Enemies (Node2D)
├── UI (CanvasLayer)
│   ├── InventoryPanel (PanelContainer)
│   │   ├── Slot1 (TextureRect)
│   │   ├── Slot2 (TextureRect)
│   │   └── Slot3 (TextureRect)
│   └── HUD (VBoxContainer)
│       └── HealthBar (ProgressBar)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

var selected_unit = null

func _unhandled_input(event):
	if event is InputEventMouseButton:
		if event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
			var space_state = get_world_2d().direct_space_state
			var query = PhysicsPointQueryParameters2D.new()
			query.position = get_global_mouse_position()
			var result = space_state.intersect_point(query)
			if result.size() > 0:
				selected_unit = result[0]["collider"]
				print("Selected: ", selected_unit.name)
			else:
				selected_unit = null
				print("Deselected")

	if event is InputEventKey and event.pressed and not event.echo:
		if event.keycode == KEY_DELETE and selected_unit:
			selected_unit.queue_free()
			selected_unit = null

	if event is InputEventMouseMotion and selected_unit:
		selected_unit.global_position = get_global_mouse_position()
```

```gdscript
extends PanelContainer

var slot_index: int = 0
var is_dragging: bool = false
var drag_offset: Vector2 = Vector2.ZERO

func _gui_input(event):
	if event is InputEventMouseButton:
		if event.button_index == MOUSE_BUTTON_LEFT:
			if event.pressed:
				is_dragging = true
				drag_offset = event.position
				print("Clicked slot: ", slot_index)
			else:
				is_dragging = false
				print("Released slot: ", slot_index)

		if event.button_index == MOUSE_BUTTON_RIGHT and event.pressed:
			print("Right click on slot: ", slot_index, " - Open context menu")

	if event is InputEventMouseMotion and is_dragging:
		global_position += event.relative
```

```gdscript
extends Button

func _gui_input(event):
	if event is InputEventMouseButton:
		if event.button_index == MOUSE_BUTTON_LEFT and event.pressed:
			modulate = Color(0.8, 0.8, 1.0)
		elif event.button_index == MOUSE_BUTTON_LEFT and not event.pressed:
			modulate = Color.WHITE

	if event is InputEventMouseMotion:
		if get_global_rect().has_point(get_global_mouse_position()):
			scale = Vector2(1.1, 1.1)
		else:
			scale = Vector2(1.0, 1.0)
```

## Kasus Penggunaan Nyata
`_unhandled_input` digunakan dalam strategi real-time untuk memilih unit dengan klik dan memerintahkan mereka. `_gui_input` digunakan dalam inventory system untuk drag-and-drop item antar slot, serta di button custom untuk efek hover dan press yang lebih interaktif dibandingkan menggunakan signal bawaan Button.
