# 66. Menangani input keyboard, mouse, dan gamepad dalam GDScript

## Definisi Singkat
Godot menyediakan cara seragam untuk menangani input dari berbagai perangkat — keyboard, mouse, dan gamepad — melalui sistem Input Map dan fungsi-fungsi input bawaan. Kamu bisa mendeteksi tombol spesifik dari setiap perangkat atau menggunakan action abstrak yang sudah didefinisikan di Input Map.

## Analogi
Bayangkan sebuah pesta dengan banyak pintu masuk — pintu depan untuk tamu VIP, pintu samping untuk tamu reguler, dan pintu belakang untuk staf. Kamu tidak perlu tahu tamu masuk dari pintu mana; kamu cukup tahu "ada tamu baru masuk". Sistem input Godot bekerja seperti penjaga yang memantau semua pintu sekaligus.

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

const SPEED = 300.0

var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta):
	if not is_on_floor():
		velocity.y += gravity * delta

	var input_dir = Vector2.ZERO
	if Input.is_action_pressed("ui_right"):
		input_dir.x += 1
	if Input.is_action_pressed("ui_left"):
		input_dir.x -= 1
	if Input.is_action_pressed("ui_up"):
		input_dir.y -= 1
	if Input.is_action_pressed("ui_down"):
		input_dir.y += 1

	if input_dir != Vector2.ZERO:
		velocity = input_dir.normalized() * SPEED
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)
		velocity.y = move_toward(velocity.y, 0, SPEED)

	move_and_slide()

func _unhandled_input(event):
	if event is InputEventKey and event.pressed:
		match event.keycode:
			KEY_F1:
				print("F1 pressed - Help")
			KEY_F2:
				print("F2 pressed - Inventory")

	if event is InputEventMouseButton and event.pressed:
		match event.button_index:
			MOUSE_BUTTON_LEFT:
				print("Left mouse click")
			MOUSE_BUTTON_RIGHT:
				print("Right mouse click")
			MOUSE_BUTTON_WHEEL_UP:
				print("Scroll up - Zoom in")
			MOUSE_BUTTON_WHEEL_DOWN:
				print("Scroll down - Zoom out")

	if event is InputEventJoypadButton and event.pressed:
		print("Gamepad button: ", Input.get_joy_button_string(event.button_index))

	if event is InputEventJoypadMotion and abs(event.axis_value) > 0.5:
		print("Gamepad axis: ", Input.get_joy_axis_string(event.axis), " = ", event.axis_value)
```

## Kasus Penggunaan Nyata
Game komersial seperti Celeste dan Hollow Knight mendukung keyboard, mouse, dan gamepad secara bersamaan. Dengan Godot, kamu bisa membuat game yang secara otomatis mendeteksi jenis input yang digunakan pemain dan menampilkan prompt UI yang sesuai (ikon tombol keyboard atau gamepad) tanpa perlu restart game.
