# 81. Menggunakan AnimatedSprite2D untuk animasi berbasis sprite sheet

## Definisi Singkat
AnimatedSprite2D adalah node yang dirancang khusus untuk memutar animasi dari sprite sheet (gambar berisi beberapa frame dalam satu file). Node ini memiliki built-in SpriteFrames yang memudahkan pengelolaan frame-by-frame animation.

## Analogi
AnimatedSprite2D seperti buku flipbook digital. Setiap halaman buku adalah satu frame gambar, dan ketika kamu membalik halaman dengan cepat, gambar seolah-olah bergerak. Sprite sheet adalah satu gambar besar yang dipotong-potong menjadi frame-frame kecil.

## Struktur Node (Scene Tree)
```
CharacterBody2D
├── AnimatedSprite2D
│   └── SpriteFrames (default_animation, walk, jump)
├── CollisionShape2D
└── AnimationPlayer (opsional, untuk property lain)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var sprite = $AnimatedSprite2D

func _ready():
	sprite.play("idle")

func _physics_process(delta):
	var direction = Input.get_axis("ui_left", "ui_right")

	if direction != 0:
		velocity.x = direction * 200
		sprite.play("walk")
		sprite.flip_h = direction < 0
	else:
		velocity.x = move_toward(velocity.x, 0, 200)
		sprite.play("idle")

	if Input.is_action_just_pressed("ui_accept") and is_on_floor():
		velocity.y = -400
		sprite.play("jump")

	move_and_slide()
```

## Kasus Penggunaan Nyata
AnimatedSprite2D sangat cocok untuk game 2D bergaya pixel art di mana animasi dibuat frame-by-frame dari sprite sheet. Kamu cukup mengimpor gambar sprite sheet, lalu memotongnya menjadi beberapa frame di editor SpriteFrames. Setiap animasi (idle, walk, attack) bisa memiliki jumlah frame dan kecepatan FPS yang berbeda.
