# 82. Mengontrol animasi dari script menggunakan play, stop, dan is_playing

## Definisi Singkat
AnimationPlayer dan AnimatedSprite2D menyediakan method `play()`, `stop()`, dan properti `is_playing()` untuk mengontrol pemutaran animasi secara dinamis dari GDScript sesuai kebutuhan gameplay.

## Analogi
Mengontrol animasi seperti mengoperasikan remote TV. `play()` adalah menekan tombol play, `stop()` adalah menekan pause/stop, dan `is_playing()` adalah mengecek apakah video sedang diputar atau tidak.

## Struktur Node (Scene Tree)
```
CharacterBody2D
├── AnimatedSprite2D
├── CollisionShape2D
└── AnimationPlayer
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var anim = $AnimationPlayer
@onready var sprite = $AnimatedSprite2D

func _ready():
	anim.play("idle")

func attack():
	if not anim.is_playing():
		anim.play("attack")
		await anim.animation_finished
		anim.play("idle")

func play_walk():
	anim.play("walk")

func stop_animation():
	anim.stop()
	sprite.stop()

func _on_hit():
	anim.stop()
	anim.play("hurt")
	await anim.animation_finished
	anim.play("idle")
```

## Kasus Penggunaan Nyata
Kontrol animasi dari script diperlukan saat animasi harus diputar berdasarkan event game seperti menembak, menerima damage, atau interaksi dengan NPC. Method `is_playing()` berguna untuk mencegah animasi tumpang tindih, dan `await anim.animation_finished` memungkinkan script menunggu animasi selesai sebelum melanjutkan aksi lain.
