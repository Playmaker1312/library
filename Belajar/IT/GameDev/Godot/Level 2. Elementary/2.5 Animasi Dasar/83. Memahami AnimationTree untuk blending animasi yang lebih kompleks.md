# 83. Memahami AnimationTree untuk blending animasi yang lebih kompleks

## Definisi Singkat
AnimationTree adalah node yang memungkinkan blending (penggabungan) beberapa animasi secara bersamaan menggunakan state machine atau blend tree. Node ini cocok untuk animasi karakter yang memiliki banyak状态 dan transisi kompleks.

## Analogi
AnimationTree seperti koki yang mencampur beberapa bahan masakan menjadi satu hidangan baru. Alih-alih hanya memilih satu animasi, kamu bisa mencampur animasi jalan dan animasi angkat senjata menjadi satu gerakan gabungan yang natural.

## Struktur Node (Scene Tree)
```
CharacterBody2D
├── AnimatedSprite2D
├── CollisionShape2D
├── AnimationPlayer (berisi semua animasi)
└── AnimationTree
    └── AnimationNodeStateMachine
        ├── idle
        ├── walk
        ├── run
        └── jump
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var anim_tree = $AnimationTree
@onready var state_machine = anim_tree.get("parameters/playback")

func _ready():
	anim_tree.active = true
	state_machine.start("idle")

func _physics_process(delta):
	var direction = Input.get_axis("ui_left", "ui_right")

	if direction != 0:
		velocity.x = direction * 200
		state_machine.travel("walk")
	else:
		velocity.x = move_toward(velocity.x, 0, 200)
		state_machine.travel("idle")

	if Input.is_action_just_pressed("ui_accept") and is_on_floor():
		velocity.y = -400
		state_machine.travel("jump")

	move_and_slide()

func attack():
	state_machine.travel("attack")
	await get_tree().create_timer(0.5).timeout
	state_machine.travel("idle")
```

## Kasus Penggunaan Nyata
AnimationTree sangat berguna untuk game dengan animasi karakter kompleks seperti RPG atau fighting game. State machine memungkinkan transisi antar animasi seperti idle, walk, run, attack, dan hurt dengan kondisi tertentu. Blend tree bisa digunakan untuk mencampur animasi Upper Body (tembak) dan Lower Body (jalan) secara terpisah.
