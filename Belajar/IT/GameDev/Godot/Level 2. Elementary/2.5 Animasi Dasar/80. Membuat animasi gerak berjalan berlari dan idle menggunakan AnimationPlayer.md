# 80. Membuat animasi gerak berjalan berlari dan idle menggunakan AnimationPlayer

## Definisi Singkat
Animasi gerak seperti walk, run, dan idle dibuat dengan mengatur perubahan property (posisi, frame, atau modulasi) pada frame waktu berbeda di AnimationPlayer. Setiap animasi disimpan sebagai named animation yang bisa dipanggil dari script.

## Analogi
Bayangkan kamu membuat film kartun simpel: pada detik ke-0 karakter berdiri diam (idle), detik ke-1 kaki mulai maju (walk), detik ke-2 langkah lebih cepat (run). AnimationPlayer merekam setiap pose ini dan memutarnya secara mulus.

## Struktur Node (Scene Tree)
```
CharacterBody2D
├── AnimatedSprite2D (untuk sprite frame)
├── CollisionShape2D
└── AnimationPlayer
    ├── idle (animasi diam)
    ├── walk (animasi berjalan)
    └── run (animasi berlari)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

const SPEED_WALK = 150.0
const SPEED_RUN = 300.0

@onready var anim = $AnimationPlayer

func _physics_process(delta):
	var direction = Input.get_axis("ui_left", "ui_right")
	var is_running = Input.is_action_pressed("ui_accept")

	if direction != 0:
		velocity.x = direction * (SPEED_RUN if is_running else SPEED_WALK)
		if is_running:
			anim.play("run")
		else:
			anim.play("walk")
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED_WALK)
		anim.play("idle")

	move_and_slide()
```

## Kasus Penggunaan Nyata
Dalam game platformer atau RPG, karakter memiliki variasi kecepatan gerak. Animasi walk digunakan saat berjalan normal, animasi run saat tombol sprint ditekan, dan idle saat berdiri diam. Animasi-animasi ini berjalan di atas sprite sheet yang sudah disiapkan sebelumnya di AnimatedSprite2D atau AnimationPlayer.
