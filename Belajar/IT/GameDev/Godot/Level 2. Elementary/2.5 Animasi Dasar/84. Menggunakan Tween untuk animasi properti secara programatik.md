# 84. Menggunakan Tween untuk animasi properti secara programatik

## Definisi Singkat
Tween adalah class di Godot yang digunakan untuk membuat animasi perubahan properti secara gradual dari waktu ke waktu tanpa perlu membuat keyframe di AnimationPlayer. Tween dibuat dan dikontrol sepenuhnya dari code.

## Analogi
Tween seperti efek transisi di PowerPoint. Kamu bisa membuat objek bergerak dari titik A ke B, berubah warna dari merah ke biru, atau memudar (fade) secara otomatis dalam durasi tertentu, semuanya hanya dengan beberapa baris kode.

## Struktur Node (Scene Tree)
```
Node2D
├── Sprite2D
├── Label
└── Button
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var sprite = $Sprite2D
@onready var label = $Label

func _ready():
	var tween = create_tween()
	tween.set_loops(2)
	tween.tween_property(sprite, "position", Vector2(400, 300), 1.0)
	tween.tween_property(sprite, "modulate", Color.RED, 0.5)
	tween.tween_property(sprite, "modulate", Color.WHITE, 0.5)
	tween.chain().tween_property(sprite, "scale", Vector2(2, 2), 0.5)
	tween.tween_property(sprite, "scale", Vector2(1, 1), 0.5)

func move_object(target_pos):
	var tween = create_tween()
	tween.tween_property(sprite, "position", target_pos, 0.3).set_ease(Tween.EASE_OUT).set_trans(Tween.TRANS_CUBIC)

func fade_out():
	var tween = create_tween()
	tween.tween_property(sprite, "modulate:a", 0.0, 0.5)

func shake():
	var tween = create_tween()
	for i in 5:
		tween.tween_property(sprite, "position:x", sprite.position.x + 10, 0.05)
		tween.tween_property(sprite, "position:x", sprite.position.x - 10, 0.05)
	tween.tween_property(sprite, "position:x", sprite.position.x, 0.05)
```

## Kasus Penggunaan Nyata
Tween cocok untuk animasi sederhana seperti efek UI (tombol membesar saat hover), pergerakan objek lintasan lurus, efek kilat saat serangan, atau transisi scene. Karena dibuat dari code, Tween sangat fleksibel dan tidak memerlukan setup di editor. Tween juga mendukung easing function dan interpolasi untuk hasil yang lebih natural.
