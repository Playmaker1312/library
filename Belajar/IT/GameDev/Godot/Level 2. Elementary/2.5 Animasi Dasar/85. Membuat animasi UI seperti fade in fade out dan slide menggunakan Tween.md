# 85. Membuat animasi UI seperti fade in, fade out, dan slide menggunakan Tween

## Definisi Singkat
Animasi UI seperti fade in, fade out, dan slide dibuat menggunakan Tween dengan mengubah property modulate, position, atau offset dari Control node secara gradual. Teknik ini menciptakan transisi visual yang halus antar layar atau elemen UI.

## Analogi
Animasi UI seperti efek transisi dalam presentasi slide. Fade in adalah layar yang perlahan muncul dari gelap, fade out adalah layar yang perlahan menghilang ke gelap, dan slide adalah elemen yang bergeser masuk atau keluar layar.

## Struktur Node (Scene Tree)
```
CanvasLayer
├── ColorRect (sebagai overlay transisi)
├── VBoxContainer (menu utama)
│   ├── Button Play
│   ├── Button Settings
│   └── Button Quit
└── Control (panel Settings, awalnya tersembunyi)
```

## Kode GDScript (Godot 4)
```gdscript
extends Control

@onready var overlay = $ColorRect
@onready var menu = $VBoxContainer
@onready var settings_panel = $SettingsPanel

func _ready():
	overlay.modulate = Color(0, 0, 0, 1)
	fade_in()

func fade_in():
	var tween = create_tween()
	tween.tween_property(overlay, "modulate:a", 0.0, 0.5)
	tween.tween_callback(overlay.hide)

func fade_out(callback: Callable):
	overlay.show()
	var tween = create_tween()
	tween.tween_property(overlay, "modulate:a", 1.0, 0.5)
	tween.tween_callback(callback)

func slide_in(node: Control, from: Vector2):
	node.position = from
	node.show()
	var tween = create_tween()
	tween.tween_property(node, "position", Vector2.ZERO, 0.3).set_ease(Tween.EASE_OUT).set_trans(Tween.TRANS_BACK)

func slide_out(node: Control, to: Vector2):
	var tween = create_tween()
	tween.tween_property(node, "position", to, 0.3).set_ease(Tween.EASE_IN).set_trans(Tween.TRANS_BACK)
	tween.tween_callback(node.hide)

func _on_play_pressed():
	fade_out(func(): get_tree().change_scene_to_file("res://game_scene.tscn"))

func _on_settings_pressed():
	slide_in(settings_panel, Vector2(500, 0))

func _on_back_pressed():
	slide_out(settings_panel, Vector2(500, 0))
```

## Kasus Penggunaan Nyata
Animasi UI dengan Tween digunakan untuk menu utama game seperti transisi antar halaman menu, efek munculnya dialog atau popup, notifikasi yang slide dari atas layar, atau efek screen shake saat menerima damage. Teknik ini memberikan polish pada UI game tanpa perlu membuat animasi manual di editor.
