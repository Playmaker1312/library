# 79. Mengenal AnimationPlayer dan cara membuat animasi keyframe di Godot

## Definisi Singkat
AnimationPlayer adalah node di Godot yang digunakan untuk membuat dan memutar animasi berbasis keyframe pada property node apapun dalam scene. Keyframe adalah titik waktu tertentu yang menyimpan nilai property pada saat itu.

## Analogi
AnimationPlayer seperti mesin waktu yang bisa merekam perubahan suatu objek pada waktu tertentu. Kamu bisa mengatur posisi, warna, atau ukuran objek pada detik ke-0, ke-1, ke-2, dan seterusnya. Godot akan mengisi perubahan di antara titik-titik tersebut secara otomatis (interpolasi).

## Struktur Node (Scene Tree)
```
CharacterBody2D
├── Sprite2D
├── CollisionShape2D
└── AnimationPlayer
    └── Animations: move_left, idle, jump
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var anim = $AnimationPlayer

func _ready():
	anim.play("idle")

func _physics_process(delta):
	var direction = Input.get_axis("ui_left", "ui_right")
	if direction != 0:
		velocity.x = direction * 200
		anim.play("walk")
	else:
		velocity.x = move_toward(velocity.x, 0, 200)
		anim.play("idle")
	move_and_slide()
```

## Kasus Penggunaan Nyata
AnimationPlayer digunakan untuk animasi karakter berjalan, menembak, atau interaksi objek seperti pintu yang terbuka. Animasi ini bisa di-trigger dari script berdasarkan input pemain atau event tertentu. AnimationPlayer juga bisa mengontrol property apapun seperti modulasi warna, skala, atau rotasi node.
