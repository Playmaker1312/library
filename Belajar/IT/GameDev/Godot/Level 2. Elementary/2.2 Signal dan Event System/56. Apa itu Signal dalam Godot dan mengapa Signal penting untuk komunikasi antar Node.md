# 56. Apa itu Signal dalam Godot dan mengapa Signal penting untuk komunikasi antar Node

## Definisi Singkat
Signal adalah mekanisme one-to-one atau one-to-many communication yang memungkinkan Node mengirimkan notifikasi kepada Node lain tanpa harus mengetahui referensi langsung satu sama lain. Dalam Godot, Signal berfungsi sebagai event handler yang menghubungkan emitter (pemancar) ke receiver (penerima) secara loosely coupled.

## Analogi
Bayangkan seperti sistem pengumuman di sekolah. Ketika bel masuk berbunyi (signal dipancarkan), semua siswa yang mendengarnya akan bereaksi (fungsi callback dijalankan) - ada yang masuk kelas, ada yang bergegas ke kelas. Siswa tidak perlu tahu siapa yang membunyikan bel, mereka hanya perlu mendengarkan dan merespons.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Player (CharacterBody2D)
│   └── Player.gd
├── Enemy (CharacterBody2D)
│   └── Enemy.gd
└── GameManager (Node)
    └── GameManager.gd
```

## Kode GDScript (Godot 4)

**Player.gd**
```gdscript
extends CharacterBody2D

signal player_died

var health: int = 100

func take_damage(amount: int) -> void:
    health -= amount
    if health <= 0:
        player_died.emit()
        queue_free()
```

**GameManager.gd**
```gdscript
extends Node

func _ready() -> void:
    var player = get_node("../Player")
    player.player_died.connect(_on_player_died)

func _on_player_died() -> void:
    print("Player telah kalah!")
    get_tree().reload_current_scene()
```

## Kasus Penggunaan Nyata
Signal sangat penting dalam pengembangan game karena memungkinkan arsitektur yang modular dan mudah dipelihara. Ketika Player mati, ia tidak perlu tahu siapa yang harus diberitahu - ia cukup memancarkan signal `player_died` dan Node lain yang berkepentingan (GameManager, UI, Audio) akan merespons. Pola ini memisahkan logika game dari presentasi dan memudahkan penambahan fitur baru tanpa mengubah kode yang sudah ada.
