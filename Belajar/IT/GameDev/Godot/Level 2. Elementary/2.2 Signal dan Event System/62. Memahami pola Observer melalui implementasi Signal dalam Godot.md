# 62. Memahami pola Observer melalui implementasi Signal dalam Godot

## Definisi Singkat
Pola Observer adalah behavioral design pattern di mana objek (subject) mempertahankan daftar dependen (observers) dan memberi tahu mereka secara otomatis tentang perubahan state. Signal dalam Godot adalah implementasi native dari pola Observer, memungkinkan banyak objek mengamati satu subjek tanpa coupling langsung.

## Analogi
Seperti layanan berlangganan YouTube. Ketika kreator mengunggah video baru (subject berubah), semua subscriber (observers) mendapat notifikasi otomatis. Subscriber tidak perlu mengecek secara manual, dan kreator tidak perlu mengirim notifikasi satu per satu ke setiap subscriber.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── EventManager (Node)
│   └── EventManager.gd
├── ScoreDisplay (Label)
│   └── ScoreDisplay.gd
├── AchievementSystem (Node)
│   └── AchievementSystem.gd
└── AudioManager (Node)
    └── AudioManager.gd
```

## Kode GDScript (Godot 4)

**EventManager.gd (Subject)**
```gdscript
extends Node

signal score_changed(new_score: int)
signal enemy_defeated(enemy_type: String)
signal level_completed(level: int)
signal player_died

var score: int = 0
var enemies_defeated: int = 0

func add_score(points: int) -> void:
    score += points
    score_changed.emit(score)

func defeat_enemy(enemy_type: String) -> void:
    enemies_defeated += 1
    enemy_defeated.emit(enemy_type)
    add_score(10)

func complete_level(level: int) -> void:
    level_completed.emit(level)
```

**ScoreDisplay.gd (Observer)**
```gdscript
extends Label

func _ready() -> void:
    var event_manager = get_node("/root/Main/EventManager")
    event_manager.score_changed.connect(_on_score_changed)

func _on_score_changed(new_score: int) -> void:
    text = "Score: " + str(new_score)
```

**AchievementSystem.gd (Observer)**
```gdscript
extends Node

var enemy_types_defeated: Dictionary = {}

func _ready() -> void:
    var event_manager = get_node("/root/Main/EventManager")
    event_manager.enemy_defeated.connect(_on_enemy_defeated)
    event_manager.level_completed.connect(_on_level_completed)

func _on_enemy_defeated(enemy_type: String) -> void:
    if not enemy_types_defeated.has(enemy_type):
        enemy_types_defeated[enemy_type] = 0
    enemy_types_defeated[enemy_type] += 1
    if enemy_types_defeated[enemy_type] >= 10:
        print("Achievement: Membunuh 10 ", enemy_type)

func _on_level_completed(level: int) -> void:
    print("Achievement: Menyelesaikan level ", level)
```

**AudioManager.gd (Observer)**
```gdscript
extends Node

func _ready() -> void:
    var event_manager = get_node("/root/Main/EventManager")
    event_manager.score_changed.connect(_on_score_changed)
    event_manager.player_died.connect(_on_player_died)

func _on_score_changed(_new_score: int) -> void:
    $CoinSound.play()

func _on_player_died() -> void:
    $GameOverSound.play()
```

## Kasus Penggunaan Nyata
Pola Observer melalui Signal sangat ideal untuk sistem event-driven game. Satu event seperti `enemy_defeated` dapat memicu update UI (ScoreDisplay), pengecekan achievement (AchievementSystem), dan pemutaran efek suara (AudioManager) secara bersamaan. Setiap observer berdiri sendiri dan dapat ditambahkan atau dihapus tanpa mempengaruhi sistem lain, sehingga codebase menjadi lebih modular dan mudah di-maintain.
