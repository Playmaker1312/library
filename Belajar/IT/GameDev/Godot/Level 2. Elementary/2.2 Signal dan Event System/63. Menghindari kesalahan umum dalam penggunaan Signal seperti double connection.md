# 63. Menghindari kesalahan umum dalam penggunaan Signal seperti double connection

## Definisi Singkat
Kesalahan umum dalam penggunaan Signal meliputi double connection (fungsi dipanggil dua kali), memory leak karena koneksi tidak dihapus, circular signal loops, dan mengakses node yang sudah queue_free(). Memahami jebakan ini krusial untuk sistem signal yang robust.

## Analogi
Seperti mendaftarkan nomor telepon ke layanan notifikasi dua kali. Ketika ada notifikasi, Anda akan menerima dua panggilan yang sama (double connection). Atau seperti lupa membatalkan langganan ketika sudah tidak membutuhkannya (memory leak), notifikasi tetap datang meskipun Anda sudah tidak ingin menerimanya.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Player (CharacterBody2D)
│   └── Player.gd
└── GameManager (Node)
    └── GameManager.gd
```

## Kode GDScript (Godot 4)

**Kesalahan: Double Connection**
```gdscript
extends Node

func _ready() -> void:
    var player = get_node("../Player")
    player.died.connect(_on_player_died)
    player.died.connect(_on_player_died)

func _on_player_died() -> void:
    print("Ini akan tercetak dua kali!")
```

**Solusi: Cek Koneksi Sebelum Connect**
```gdscript
extends Node

func _ready() -> void:
    var player = get_node("../Player")
    if not player.died.is_connected(_on_player_died):
        player.died.connect(_on_player_died)
```

**Solusi: Gunakan One-Shot Connection**
```gdscript
extends Node

func _ready() -> void:
    var player = get_node("../Player")
    player.died.connect(_on_player_died, CONNECT_ONE_SHOT)

func _on_player_died() -> void:
    print("Hanya dipanggil sekali meskipun emit berulang")
```

**Solusi: Disconnect saat Tidak Perlu**
```gdscript
extends Node

var player_died_connection: Callable

func setup_connection() -> void:
    var player = get_node("../Player")
    player_died_connection = _on_player_died
    player.died.connect(player_died_connection)

func cleanup_connection() -> void:
    var player = get_node("../Player")
    if player != null and player.died.is_connected(player_died_connection):
        player.died.disconnect(player_died_connection)
```

**Hindari: Akses Node Setelah Free**
```gdscript
extends Area2D

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("Player"):
        body.take_damage(10)
        body.queue_free()
        print(body.name)
```

**Solusi: Cek is_inside_tree()**
```gdscript
extends Area2D

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("Player"):
        body.take_damage(10)
        body.queue_free()
```

## Kasus Penggunaan Nyata
Double connection adalah bug paling umum yang sulit dideteksi karena tidak menyebabkan crash, hanya fungsi berjalan dua kali. Ini sering terjadi ketika scene di-reload atau node di-instantiate ulang. Memory leak terjadi ketika signal tidak di-disconnect saat scene destroyed, menyebabkan callback mencoba mengakses node yang sudah tidak ada. Selalu gunakan `is_connected()` sebelum connect dan bersihkan koneksi di `_exit_tree()` atau `queue_free()` untuk menjaga kebersihan sistem signal.
