# 61. Menggunakan Signal bawaan Node seperti body_entered, area_exited, dan timeout

## Definisi Singkat
Banyak Node bawaan Godot memiliki signal yang sudah terdefinisi untuk menangani event umum seperti kolisi (body_entered, body_exited), area (area_entered, area_exited), timer (timeout), dan animasi (animation_finished). Signal ini tidak perlu dideklarasikan dan siap digunakan.

## Analogi
Seperti sensor otomatis di gedung pintar. Sensor pintu (body_entered) akan mendeteksi ketika seseorang masuk, sensor ruangan (area_entered) mendeteksi objek di area tertentu, dan timer (timeout) berfungsi seperti alarm yang berbunyi secara berkala. Semua sensor ini bekerja otomatis tanpa konfigurasi tambahan.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Player (CharacterBody2D)
│   └── Player.gd
├── Collectible (Area2D)
│   ├── Sprite2D
│   ├── CollisionShape2D
│   └── Collectible.gd
├── DamageZone (Area2D)
│   ├── Sprite2D
│   ├── CollisionShape2D
│   └── DamageZone.gd
└── SpawnTimer (Timer)
    └── SpawnTimer.gd
```

## Kode GDScript (Godot 4)

**Collectible.gd**
```gdscript
extends Area2D

signal item_collected

func _ready() -> void:
    body_entered.connect(_on_body_entered)

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("Player"):
        item_collected.emit()
        queue_free()
```

**DamageZone.gd**
```gdscript
extends Area2D

var damage: int = 10

func _ready() -> void:
    body_entered.connect(_on_body_entered)
    body_exited.connect(_on_body_exited)

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("Player"):
        body.take_damage(damage)

func _on_body_exited(body: Node2D) -> void:
    if body.is_in_group("Player"):
        print("Player meninggalkan zona bahaya")
```

**SpawnTimer.gd**
```gdscript
extends Timer

var enemy_scene: PackedScene = preload("res://enemy.tscn")

func _ready() -> void:
    timeout.connect(_on_timeout)
    start(3.0)

func _on_timeout() -> void:
    var enemy = enemy_scene.instantiate()
    enemy.global_position = Vector2(randf_range(100, 800), randf_range(100, 600))
    get_parent().add_child(enemy)
```

## Kasus Penggunaan Nyata
Signal bawaan adalah fondasi dari interaksi dalam game. `body_entered` digunakan untuk deteksi kolisi player dengan item atau musuh, `area_exited` untuk mengetahui kapan player meninggalkan area tertentu seperti checkpoint atau zona aman, dan `timeout` untuk event berulang seperti spawning musuh, regenerasi health, atau cooldown kemampuan. Menggunakan signal bawaan sangat efisien karena sudah dioptimasi di tingkat engine.
