# 59. Cara menghubungkan Signal menggunakan kode dengan metode connect

## Definisi Singkat
Metode `connect()` memungkinkan Anda menghubungkan signal ke fungsi callback secara dinamis melalui kode GDScript. Koneksi dapat dilakukan kapan saja selama runtime dan mendukung berbagai konfigurasi seperti bind parameters dan one-shot connections.

## Analogi
Seperti mendaftarkan diri untuk mendapatkan notifikasi email. Anda memberitahu sistem (signal) alamat email mana (fungsi callback) yang harus diberitahu ketika ada pembaruan. Anda bisa mendaftar kapan saja dan bahkan bisa berlangganan hanya untuk satu notifikasi tertentu.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Spawner (Node)
│   └── Spawner.gd
├── Enemy (CharacterBody2D)
│   └── Enemy.gd
└── ScoreManager (Node)
    └── ScoreManager.gd
```

## Kode GDScript (Godot 4)

**Spawner.gd**
```gdscript
extends Node

signal enemy_spawned(enemy: CharacterBody2D)

var enemy_scene: PackedScene = preload("res://enemy.tscn")

func spawn_enemy() -> void:
    var enemy = enemy_scene.instantiate()
    add_child(enemy)
    enemy.died.connect(_on_enemy_died.bind(enemy))
    enemy_spawned.emit(enemy)

func _on_enemy_died(enemy: CharacterBody2D) -> void:
    enemy.queue_free()
```

**ScoreManager.gd**
```gdscript
extends Node

var score: int = 0

func _ready() -> void:
    var spawner = get_node("../Spawner")
    spawner.enemy_spawned.connect(_on_enemy_spawned)

func _on_enemy_spawned(enemy: CharacterBody2D) -> void:
    enemy.died.connect(_add_score)

func _add_score() -> void:
    score += 10
    print("Score: ", score)
```

**Koneksi One-Shot:**
```gdscript
enemy.died.connect(_on_first_death, CONNECT_ONE_SHOT)
```

## Kasus Penggunaan Nyata
Metode connect sangat powerful untuk hubungan signal yang kompleks dan dinamis. Contohnya, ketika Anda membuat sistem quest atau achievement yang harus terhubung ke berbagai event di berbagai node yang mungkin belum ada saat game dimulai. Anda juga bisa menggunakan `bind()` untuk meneruskan data tambahan ke callback, atau `CONNECT_ONE_SHOT` untuk koneksi yang hanya sekali dipanggil.
