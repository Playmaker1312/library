# 60. Cara memancarkan Signal menggunakan keyword emit

## Definisi Singkat
Signal dipancarkan menggunakan metode `emit()` atau `emit_signal()` yang akan memanggil semua fungsi callback yang terhubung ke signal tersebut. Emit dapat menerima parameter sesuai deklarasi signal dan akan diteruskan ke semua receiver.

## Analogi
Seperti menekan tombol bel rumah. Ketika Anda menekan tombol (memanggil emit), bel berbunyi di semua unit apartemen yang terhubung. Setiap unit (callback function) akan menerima informasi yang sama tentang siapa yang menekan bel.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── Player.gd
└── CollisionShape2D

Trap (Area2D)
├── Trap.gd
└── CollisionShape2D

UI (CanvasLayer)
├── DamagePopup (Label)
│   └── DamagePopup.gd
└── GameOver (Control)
    └── GameOver.gd
```

## Kode GDScript (Godot 4)

**Player.gd**
```gdscript
extends CharacterBody2D

signal damaged(amount: int, direction: Vector2)
signal healed(amount: int)
signal died

var health: int = 100

func receive_damage(amount: int, from_position: Vector2) -> void:
    health -= amount
    var direction = (global_position - from_position).normalized()
    damaged.emit(amount, direction)
    if health <= 0:
        died.emit()

func receive_heal(amount: int) -> void:
    var actual_heal = min(amount, 100 - health)
    health += actual_heal
    healed.emit(actual_heal)
```

**DamagePopup.gd**
```gdscript
extends Label

func _ready() -> void:
    var player = get_node("/root/Main/Player")
    player.damaged.connect(_on_player_damaged)

func _on_player_damaged(amount: int, _direction: Vector2) -> void:
    text = "-" + str(amount)
    modulate = Color.RED
    var tween = create_tween()
    tween.tween_property(self, "position:y", position.y - 30, 0.5)
    tween.tween_callback(queue_free)
```

**GameOver.gd**
```gdscript
extends Control

func _ready() -> void:
    hide()
    var player = get_node("/root/Main/Player")
    player.died.connect(_on_player_died)

func _on_player_dished() -> void:
    show()
    get_tree().paused = true
```

## Kasus Penggunaan Nyata
Emit adalah titik awal dari seluruh sistem event dalam game. Setiap kali terjadi sesuatu yang penting (kerusakan, kematian, item terkumpul, checkpoint tercapai), signal di-emit dan semua sistem yang berkepentingan akan merespons. Pola ini memungkinkan satu event memicu banyak efek tanpa kode yang saling tergantung.
