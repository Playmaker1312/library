# 57. Cara membuat Signal kustom menggunakan keyword signal dalam GDScript

## Definisi Singkat
Signal kustom dideklarasikan menggunakan keyword `signal` di bagian atas script GDScript. Signal dapat membawa parameter opsional yang akan diteruskan ke fungsi callback saat signal dipancarkan.

## Analogi
Mirip seperti membuat stasiun radio pribadi. Anda mendefinisikan frekuensi (nama signal) dan jenis siaran (parameter). Siapa pun yang menyetel ke frekuensi yang sama akan menerima pesan lengkap dengan informasi yang dikirim.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
└── Player.gd

UI (CanvasLayer)
└── HealthBar (ProgressBar)
    └── HealthBar.gd
```

## Kode GDScript (Godot 4)

**Player.gd**
```gdscript
extends CharacterBody2D

signal health_changed(new_health: int)
signal died
signal collected_item(item_name: String, item_value: int)

var health: int = 100
var score: int = 0

func take_damage(amount: int) -> void:
    health = max(health - amount, 0)
    health_changed.emit(health)
    if health <= 0:
        died.emit()

func collect(item_name: String, item_value: int) -> void:
    score += item_value
    collected_item.emit(item_name, item_value)
```

**HealthBar.gd**
```gdscript
extends ProgressBar

func _ready() -> void:
    var player = get_node("/root/Main/Player")
    player.health_changed.connect(_on_health_changed)

func _on_health_changed(new_health: int) -> void:
    value = new_health
```

## Kasus Penggunaan Nyata
Signal kustom memungkinkan Anda membuat API yang bersih untuk komunikasi antar komponen. Sebuah Player dapat memancarkan berbagai jenis event (perubahan health, kematian, item terkumpul) dan setiap sistem UI atau game logic dapat menangani event-event tersebut secara independen. Ini sangat berguna saat tim development terpisah antara programmer gameplay dan programmer UI.
