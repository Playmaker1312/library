# 58. Cara menghubungkan Signal ke fungsi menggunakan panel editor Godot

## Definisi Singkat
Panel Node di editor Godot menyediakan tab "Signals" yang memungkinkan Anda menghubungkan signal dari Node yang dipilih ke fungsi di Node lain melalui interface visual tanpa menulis kode koneksi secara manual.

## Analogi
Seperti memasang jalur pipa air di rumah. Anda memilih keran (signal) yang ingin dihubungkan, lalu memilih wastafel atau bak mandi (fungsi target) yang akan menerima aliran air. Semua dilakukan melalui panel kontrol sentral.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Button (Button)
│   └── Button.gd
└── Label (Label)
    └── Label.gd
```

## Kode GDScript (Godot 4)

**Button.gd**
```gdscript
extends Button

func _on_pressed() -> void:
    text = "Tombol sudah ditekan!"
    disabled = true
```

**Label.gd**
```gdscript
extends Label

func _on_button_pressed() -> void:
    text = "Selamat datang di Godot!"
    add_theme_color_override("font_color", Color.GREEN)
```

**Langkah di Editor:**
1. Pilih node Button di Scene Tree
2. Buka tab "Signals" di panel Node (sebelah kanan)
3. Cari signal `pressed()`
4. Klik ikon hubungan (link icon) di sebelah kanan signal
5. Pilih node Label sebagai target
6. Pilih fungsi `_on_button_pressed` atau buat baru
7. Klik "Connect"

## Kasus Penggunaan Nyata
Metode editor sangat ideal untuk hubungan signal sederhana seperti tombol UI, timer, atau event input. Metode ini memberikan visualisasi yang jelas tentang koneksi antar node dan memudahkan debugging karena semua koneksi terlihat di panel Signals. Cocok untuk prototyping cepat dan untuk programmer yang lebih nyaman dengan workflow visual.
