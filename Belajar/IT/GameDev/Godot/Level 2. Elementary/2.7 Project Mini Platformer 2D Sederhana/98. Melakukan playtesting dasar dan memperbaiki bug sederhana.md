# 98. Melakukan playtesting dasar dan memperbaiki bug sederhana

## Definisi Singkat
Playtesting adalah proses menguji game secara sistematis untuk menemukan bug, kesulitan yang tidak seimbang, dan masalah gameplay lainnya. Bug fixing adalah proses mengidentifikasi dan memperbaiki masalah yang ditemukan selama playtesting.

## Analogi
Bayangkan kamu sedang membangun rumah. Setelah rumah selesai dibangun, kamu harus memeriksa setiap ruangan: apakah pintu bisa dibuka dengan baik, apakah keran air mengalir, apakah listrik menyala. Playtesting seperti inspeksi rumah — menemukan masalah sebelum rumah digunakan. Bug fixing seperti memperbaiki keran yang bocor atau pintu yang macet.

## Struktur Node (Scene Tree)
```
TestScene (Node2D)
├── Player (CharacterBody2D)
├── Enemy (CharacterBody2D)
├── DebugUI (CanvasLayer)
│   ├── FPSLabel (Label)
│   ├── DebugConsole (LineEdit)
│   └── BugReportButton (Button)
└── TestLevel (TileMap)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

@onready var fps_label: Label = $DebugUI/FPSLabel
@onready var debug_console: LineEdit = $DebugUI/DebugConsole
@onready var bug_report_button: Button = $DebugUI/BugReportButton

var is_debug_mode: bool = true
var log_entries: Array[String] = []

func _ready() -> void:
    bug_report_button.pressed.connect(_on_bug_report_pressed)
    debug_console.text_submitted.connect(_on_console_submitted)
    setup_debug_mode()

func _process(_delta: float) -> void:
    if is_debug_mode:
        fps_label.text = "FPS: " + str(Engine.get_frames_per_second())
        fps_label.visible = true

func setup_debug_mode() -> void:
    fps_label.visible = is_debug_mode
    debug_console.visible = is_debug_mode
    bug_report_button.visible = is_debug_mode

func toggle_debug_mode() -> void:
    is_debug_mode = not is_debug_mode
    setup_debug_mode()

func log_message(message: String) -> void:
    var timestamp: String = Time.get_time_string_from_system()
    var log_entry: String = "[" + timestamp + "] " + message
    log_entries.append(log_entry)
    print(log_entry)

func _on_console_submitted(text: String) -> void:
    var command: String = text.strip_edges().to_lower()
    match command:
        "godmode":
            toggle_god_mode()
            log_message("God mode toggled")
        "debug":
            toggle_debug_mode()
            log_message("Debug mode toggled")
        "reset":
            get_tree().reload_current_scene()
            log_message("Scene reloaded")
        "quit":
            get_tree().quit()
        _:
            log_message("Unknown command: " + command)
    debug_console.clear()

func _on_bug_report_pressed() -> void:
    var report: String = "Bug Report:\n"
    report += "FPS: " + str(Engine.get_frames_per_second()) + "\n"
    report += "Player Position: " + str(get_player_position()) + "\n"
    report += "Active Nodes: " + str(get_tree().get_node_count()) + "\n"
    log_message(report)

func get_player_position() -> Vector2:
    var player: Node = get_tree().get_first_node_in_group("Player")
    if player:
        return player.global_position
    return Vector2.ZERO

func toggle_god_mode() -> void:
    var player: Node = get_tree().get_first_node_in_group("Player")
    if player and player.has_method("set_invincible"):
        var is_invincible: bool = player.is_invincible
        player.is_invincible = not is_invincible
```

## Kasus Penggunaan Nyata
Playtesting adalah tahap krusial dalam pengembangan game. Game seperti No Man's Sky mengalami masalah besar karena kurangnya playtesting sebelum launch, sementara game seperti Hades berhasil karena iterasi playtesting yang intensif. Dalam studio profesional, playtesting dilakukan oleh tim QA (Quality Assurance) secara teratur dan hasilnya didokumentasikan dalam bug tracking system seperti Jira atau Bugzilla.
