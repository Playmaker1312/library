# 97. Menambahkan efek suara dan musik latar ke dalam game platformer

## Definisi Singkat
Efek suara (sound effects) adalah audio pendek yang diputar untuk respons terhadap aksi tertentu seperti melompat, mengumpulkan koin, atau terkena damage. Musik latar (background music) adalah audio loop yang diputar terus-menerus untuk menciptakan atmosphere dan mood game.

## Analogi
Bayangkan kamu sedang menonton film. Musik latar adalah orkestra yang memainkan melodi sesuai mood adegan — romantis, tegang, atau heroik. Efek suara adalah bunyi langkah kaki, dentingan pedang, atau suara hujan yang menambah realisme. Tanpa kedua elemen ini, film akan terasa hening dan tidak hidup.

## Struktur Node (Scene Tree)
```
AudioManager (Node)
├── BGMPlayer (AudioStreamPlayer)
├── SFXPlayer1 (AudioStreamPlayer2D)
├── SFXPlayer2 (AudioStreamPlayer2D)
└── SFXPlayer3 (AudioStreamPlayer2D)

Player (CharacterBody2D)
├── JumpSFX (AudioStreamPlayer2D)
├── HurtSFX (AudioStreamPlayer2D)
└── CoinSFX (AudioStreamPlayer2D)

Level (Node2D)
└── BGM (AudioStreamPlayer)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node

var bgm_player: AudioStreamPlayer
var sfx_players: Array[AudioStreamPlayer2D] = []
var max_sfx_players: int = 8

func _ready() -> void:
    bgm_player = AudioStreamPlayer.new()
    bgm_player.bus = "Music"
    add_child(bgm_player)
    
    for i in range(max_sfx_players):
        var player: AudioStreamPlayer2D = AudioStreamPlayer2D.new()
        player.bus = "SFX"
        add_child(player)
        sfx_players.append(player)

func play_bgm(music: AudioStream, volume_db: float = -10.0) -> void:
    if bgm_player.playing:
        var tween: Tween = create_tween()
        tween.tween_property(bgm_player, "volume_db", -80.0, 0.5)
        await tween.finished
    
    bgm_player.stream = music
    bgm_player.volume_db = volume_db
    bgm_player.play()

func stop_bgm(fade_duration: float = 0.5) -> void:
    if not bgm_player.playing:
        return
    var tween: Tween = create_tween()
    tween.tween_property(bgm_player, "volume_db", -80.0, fade_duration)
    await tween.finished
    bgm_player.stop()
    bgm_player.volume_db = -10.0

func play_sfx(sfx: AudioStream, volume_db: float = -5.0) -> void:
    var player: AudioStreamPlayer2D = get_free_sfx_player()
    if player == null:
        return
    player.stream = sfx
    player.volume_db = volume_db
    player.play()

func get_free_sfx_player() -> AudioStreamPlayer2D:
    for player in sfx_players:
        if not player.playing:
            return player
    return sfx_players[0]

func set_master_volume(volume_percent: float) -> void:
    var volume_db: float = linear_to_db(clampf(volume_percent / 100.0, 0.0001, 1.0))
    AudioServer.set_bus_volume_db(0, volume_db)

func set_sfx_volume(volume_percent: float) -> void:
    var volume_db: float = linear_to_db(clampf(volume_percent / 100.0, 0.0001, 1.0))
    var sfx_bus: int = AudioServer.get_bus_index("SFX")
    AudioServer.set_bus_volume_db(sfx_bus, volume_db)
```

## Kasus Penggunaan Nyata
Audio adalah elemen krusial dalam game yang sering diabaikan oleh developer pemula. Game seperti Celeste menggunakan musik yang dinamis yang berubah sesuai level, sementara game horror seperti Resident Evil menggunakan silence dan sudden loud noises untuk menciptakan ketegangan. Dalam game profesional, audio sering direkam secara terpisah dan diintegrasikan menggunakan middleware seperti FMOD atau Wwise.
