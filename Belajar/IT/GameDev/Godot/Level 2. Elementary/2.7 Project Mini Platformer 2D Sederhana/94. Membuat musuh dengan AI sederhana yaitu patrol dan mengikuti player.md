# 94. Membuat musuh dengan AI sederhana yaitu patrol dan mengikuti player

## Definisi Singkat
AI patrol adalah perilaku musuh yang bergerak bolak-balik di antara titik-titik tertentu secara berulang. AI chase adalah perilaku musuh yang mengikuti posisi pemain dalam jarak tertentu. Kombinasi keduanya menciptakan musuh yang aktif dan menantang dalam game platformer.

## Analogi
Bayangkan anjing penjaga rumah. Ketika tidak ada orang asing, anjing tersebut berjalan mondar-mandir mengelilingi halaman (patrol). Namun, ketika ada orang asing mendekat (player masuk dalam jangkauan), anjing tersebut langsung berlari menghampiri orang asing tersebut (chase). Ketika orang asing menjauh, anjing kembali ke aktivitas patrolnya.

## Struktur Node (Scene Tree)
```
Enemy (CharacterBody2D)
├── CollisionShape2D
├── Sprite2D
├── PatrolPath (Path2D)
│   └── PathFollow2D
├── DetectionArea (Area2D)
│   └── CollisionShape2D
├── StateMachine (Node)
│   ├── Patrol (Node)
│   └── Chase (Node)
└── AnimationPlayer
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

enum State { PATROL, CHASE, ATTACK }

signal player_detected(player: Node2D)
signal player_lost

@export var patrol_speed: float = 60.0
@export var chase_speed: float = 120.0
@export var detection_range: float = 150.0
@export var attack_range: float = 40.0
@export var patrol_wait_time: float = 1.0

var current_state: State = State.PATROL
var current_target: Vector2
var patrol_points: Array[Vector2] = []
var current_patrol_index: int = 0
var wait_timer: float = 0.0
var is_waiting: bool = false
var player: CharacterBody2D = null

@onready var sprite: Sprite2D = $Sprite2D
@onready var detection_area: Area2D = $DetectionArea
@onready var anim_player: AnimationPlayer = $AnimationPlayer

func _ready() -> void:
    detection_area.body_entered.connect(_on_detection_area_body_entered)
    detection_area.body_exited.connect(_on_detection_area_body_exited)
    initialize_patrol_points()

func _physics_process(delta: float) -> void:
    match current_state:
        State.PATROL:
            patrol_behavior(delta)
        State.CHASE:
            chase_behavior(delta)
        State.ATTACK:
            attack_behavior()
    move_and_slide()

func initialize_patrol_points() -> void:
    patrol_points = [
        global_position + Vector2(-80, 0),
        global_position + Vector2(80, 0)
    ]
    current_target = patrol_points[0]

func patrol_behavior(delta: float) -> void:
    if is_waiting:
        wait_timer -= delta
        if wait_timer <= 0.0:
            is_waiting = false
        return
    
    var direction: Vector2 = (current_target - global_position).normalized()
    velocity = direction * patrol_speed
    
    if global_position.distance_to(current_target) < 5.0:
        current_patrol_index = (current_patrol_index + 1) % patrol_points.size()
        current_target = patrol_points[current_patrol_index]
        is_waiting = true
        wait_timer = patrol_wait_time
        velocity = Vector2.ZERO
    
    update_sprite_direction(direction)

func chase_behavior(delta: float) -> void:
    if player == null or not is_instance_valid(player):
        change_state(State.PATROL)
        return
    
    var distance_to_player: float = global_position.distance_to(player.global_position)
    
    if distance_to_player > detection_range:
        change_state(State.PATROL)
        emit_signal("player_lost")
        return
    
    if distance_to_player <= attack_range:
        change_state(State.ATTACK)
        return
    
    var direction: Vector2 = (player.global_position - global_position).normalized()
    velocity = direction * chase_speed
    update_sprite_direction(direction)

func attack_behavior() -> void:
    velocity = Vector2.ZERO
    anim_player.play("attack")
    
    if player == null or not is_instance_valid(player):
        change_state(State.PATROL)
        return
    
    var distance_to_player: float = global_position.distance_to(player.global_position)
    if distance_to_player > attack_range * 1.5:
        change_state(State.CHASE)

func change_state(new_state: State) -> void:
    current_state = new_state
    match new_state:
        State.PATROL:
            anim_player.play("patrol")
        State.CHASE:
            anim_player.play("chase")
        State.ATTACK:
            anim_player.play("attack")

func update_sprite_direction(direction: Vector2) -> void:
    if direction.x < 0:
        sprite.flip_h = true
    elif direction.x > 0:
        sprite.flip_h = false

func _on_detection_area_body_entered(body: Node2D) -> void:
    if body.is_in_group("Player"):
        player = body as CharacterBody2D
        change_state(State.CHASE)
        emit_signal("player_detected", player)

func _on_detection_area_body_exited(body: Node2D) -> void:
    if body.is_in_group("Player"):
        change_state(State.PATROL)
        player = null
        emit_signal("player_lost")

func take_damage(damage: int) -> void:
    anim_player.play("hurt")
    change_state(State.PATROL)
```

## Kasus Penggunaan Nyata
AI patrol dan chase digunakan secara luas dalam game seperti Mario Bros (koopa troopa patrol), Metroid (musuh mengikuti player), dan game stealth seperti Mark of the Ninja. Dalam game hori horror, musuh dengan AI patrol digunakan untuk menciptakan ketegangan saat pemain harus menghindari deteksi musuh.
