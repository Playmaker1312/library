# 96. Implementasi game over screen dan win screen dengan navigasi antar scene

## Definisi Singkat
Game over screen adalah tampilan yang muncul ketika pemain kehabisan nyawa atau gagal menyelesaikan level. Win screen adalah tampilan yang muncul ketika pemain berhasil menyelesaikan level. Keduanya menyediakan navigasi untuk memulai ulang atau kembali ke menu utama.

## Analogi
Bayangkan kamu sedang menonton film. Ketika film berakhir, ada dua kemungkinan layar yang muncul: layar kredit jika film berhasil ditonton hingga selesai (win screen), atau layar yang menunjukkan bahwa kamu harus memulai dari awal jika terjadi masalah teknis (game over screen). Keduanya memberikan opsi untuk memutar ulang film atau kembali ke daftar film.

## Struktur Node (Scene Tree)
```
GameOverScreen (Control)
├── Background (ColorRect)
├── GameOverLabel (Label)
├── FinalScoreLabel (Label)
├── ButtonContainer (VBoxContainer)
│   ├── RetryButton (Button)
│   └── MainMenuButton (Button)
└── AnimationPlayer

WinScreen (Control)
├── Background (ColorRect)
├── WinLabel (Label)
├── VictoryLabel (Label)
├── ScoreContainer (VBoxContainer)
│   ├── CoinCountLabel (Label)
│   └── TimeLabel (Label)
├── ButtonContainer (VBoxContainer)
│   ├── NextLevelButton (Button)
│   ├── RetryButton (Button)
│   └── MainMenuButton (Button)
└── AnimationPlayer
```

## Kode GDScript (Godot 4)

```gdscript
extends Control

@onready var game_over_label: Label = $GameOverLabel
@onready var final_score_label: Label = $FinalScoreLabel
@onready var retry_button: Button = $ButtonContainer/RetryButton
@onready var main_menu_button: Button = $ButtonContainer/MainMenuButton
@onready var anim_player: AnimationPlayer = $AnimationPlayer

func _ready() -> void:
    retry_button.pressed.connect(_on_retry_button_pressed)
    main_menu_button.pressed.connect(_on_main_menu_button_pressed)
    anim_player.play("fade_in")
    get_tree().paused = false

func set_final_score(score: int) -> void:
    final_score_label.text = "Skor Akhir: " + str(score)

func _on_retry_button_pressed() -> void:
    get_tree().reload_current_scene()

func _on_main_menu_button_pressed() -> void:
    get_tree().change_scene_to_file("res://scenes/main_menu.tscn")
```

## Kasus Penggunaan Nyata
Game over screen dan win screen adalah elemen dasar dalam semua game. Dalam game seperti Dark Souls, game over screen menjadi momen refleksi bagi pemain untuk mempelajari kesalahan. Dalam game mobile seperti Candy Crush, win screen sering menampilkan statistik detail dan opsi untuk membagikan pencapaian ke media sosial. Navigasi yang baik antar screen penting untuk menjaga flow game tetap smooth.
