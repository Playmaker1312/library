# 93. Mengimplementasikan sistem nyawa player dengan UI yang menampilkan health bar

## Definisi Singkat
Sistem nyawa (health system) adalah mekanik yang mengontrol berapa kali pemain bisa terkena damage sebelum game over. Health bar adalah elemen visual yang menampilkan status nyawa pemain secara real-time menggunakan Progress Bar atau Texture Progress.

## Analogi
Sistem nyawa seperti baterai pada ponsel. Ketika baterai penuh (100%), semua fungsi berjalan lancar. Setiap kali kamu menggunakan fitur tertentu (terkena damage), baterai berkurang. Jika baterai habis, ponsel mati (game over). Health bar adalah indikator baterai yang menunjukkan kondisi saat ini.

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

signal health_changed(new_health: int, max_health: int)
signal player_died

@export var max_health: int = 3
@export var invincibility_duration: float = 1.0

var current_health: int
var is_invincible: bool = false
var invincibility_timer: float = 0.0

@onready var sprite: Sprite2D = $Sprite2D
@onready var anim_player: AnimationPlayer = $AnimationPlayer

func _ready() -> void:
    current_health = max_health
    emit_signal("health_changed", current_health, max_health)

func _process(delta: float) -> void:
    if is_invincible:
        invincibility_timer -= delta
        if invincibility_timer <= 0.0:
            is_invincible = false
            modulate.a = 1.0

func take_damage(damage_amount: int) -> void:
    if is_invincible:
        return
    
    current_health = clampi(current_health - damage_amount, 0, max_health)
    emit_signal("health_changed", current_health, max_health)
    
    if current_health <= 0:
        die()
    else:
        start_invincibility()

func heal(heal_amount: int) -> void:
    current_health = clampi(current_health + heal_amount, 0, max_health)
    emit_signal("health_changed", current_health, max_health)

func start_invincibility() -> void:
    is_invincible = true
    invincibility_timer = invincibility_duration
    modulate.a = 0.5
    anim_player.play("hurt")

func die() -> void:
    emit_signal("player_died")
    anim_player.play("death")
    set_physics_process(false)

func reset_health() -> void:
    current_health = max_health
    is_invincible = false
    modulate.a = 1.0
    emit_signal("health_changed", current_health, max_health)
```

## Kasus Penggunaan Nyata
Sistem health bar digunakan di hampir semua game action, RPG, dan platformer. Contoh nyata adalah game Mario yang memiliki sistem nyawa tersembunyi (biasanya 3-5 nyawa), atau game Zelda yang menampilkan hearts di layar. Dalam game indie modern, health bar sering dikustomisasi dengan animasi, warna gradasi, dan efek visual untuk meningkatkan feedback kepada pemain.
