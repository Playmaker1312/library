# 92. Merancang level platformer sederhana menggunakan TileMap

## Definisi Singkat
TileMap adalah node dalam Godot yang digunakan untuk membuat level 2D dengan menyusun tile (kotak kecil) dari sebuah tileset secara efisien. TileMap memungkinkan developer membuat level yang luas tanpa perlu membuat setiap elemen secara individual.

## Analogi
Bayangkan kamu sedang merancang sebuah papan catur raksasa. Daripada menggambar setiap kotak satu per satu, kamu memiliki kertas bergaris siap pakai yang tinggal kamu isi dengan objek-objek yang berbeda. TileMap bekerja seperti kertas bergaris tersebut — tileset adalah pulpen atau pensil berwarna yang bisa kamu pilih, dan TileMap adalah kanvas tempat kamu menempatkan tile-tile tersebut untuk membentuk level.

## Struktur Node (Scene Tree)
```
Level (Node2D)
├── TileMap (TileMap)
│   ├── Layer: Terrain
│   └── Layer: Background
├── Player (CharacterBody2D)
├── Camera2D
└── SpawnPoints (Node2D)
    ├── PlayerSpawn (Marker2D)
    └── EnemySpawns (Node2D)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

@onready var tile_map: TileMap = $TileMap

func _ready() -> void:
    setup_level()

func setup_level() -> void:
    var layer_terrain: int = 0
    var layer_background: int = 1
    var atlas_source_id: int = 0
    
    var ground_tiles: Array[Vector2i] = [
        Vector2i(0, 10), Vector2i(1, 10), Vector2i(2, 10),
        Vector2i(3, 10), Vector2i(4, 10), Vector2i(5, 10)
    ]
    
    for tile_pos in ground_tiles:
        tile_map.set_cell(layer_terrain, tile_pos, atlas_source_id, Vector2i(0, 0))

func get_tile_position_at(world_pos: Vector2) -> Vector2i:
    return tile_map.local_to_map(world_pos)

func is_tile_solid(tile_pos: Vector2i) -> bool:
    var layer: int = 0
    var source_id: int = tile_map.get_cell_source_id(layer, tile_pos)
    return source_id != -1

func place_tile(world_pos: Vector2, atlas_coords: Vector2i) -> void:
    var tile_pos: Vector2i = tile_map.local_to_map(world_pos)
    tile_map.set_cell(0, tile_pos, 0, atlas_coords)

func remove_tile(world_pos: Vector2) -> void:
    var tile_pos: Vector2i = tile_map.local_to_map(world_pos)
    tile_map.erase_cell(0, tile_pos)

func get_world_position_from_tile(tile_pos: Vector2i) -> Vector2:
    return tile_map.map_to_local(tile_pos)

func clear_all_tiles() -> void:
    for layer in range(tile_map.get_layers_count()):
        tile_map.clear()
```

## Kasus Penggunaan Nyata
TileMap digunakan oleh hampir semua game 2D side-scroller dan platformer untuk membuat level yang luas dan efisien. Game seperti Celeste dan Hollow Knight menggunakan sistem tilemap untuk membuat level yang kompleks dengan ribuan tile yang dirender secara efisien. Dalam pengembangan game profesional, tilemap juga digunakan dengan sistem procedural generation untuk membuat level secara otomatis berdasarkan algoritma tertentu.
