# 95. Membuat sistem pengumpulan koin dan perhitungan skor

## Definisi Singkat
Sistem pengumpulan koin adalah mekanik yang memungkinkan pemain mengambil item koin di level untuk menambah skor. Sistem skor adalah penghitung yang mencatat total koin yang terkumpul dan menampilkannya di UI sebagai elemen gamification.

## Analogi
Bayangkan kamu sedang bermain game arcade di mana kamu mengumpulkan koin emas di sepanjang jalan. Setiap koin yang kamu ambil menambah nilai di papan skor di bagian atas layar. Semakin banyak koin yang kamu kumpulkan, semakin tinggi skor kamu. Koin seperti bintang yang kamu kumpulkan saat berjalan — setiap bintang bernilai satu poin dan ditampilkan di layar.

## Kode GDScript (Godot 4)

```gdscript
extends Area2D

signal coin_collected(value: int)

@export var coin_value: int = 1
@export var bob_speed: float = 2.0
@export var bob_height: float = 5.0

var start_position: Vector2
var time: float = 0.0

@onready var sprite: Sprite2D = $Sprite2D
@onready var anim_player: AnimationPlayer = $AnimationPlayer
@onready var audio_player: AudioStreamPlayer2D = $AudioStreamPlayer2D

func _ready() -> void:
    start_position = position
    body_entered.connect(_on_body_entered)

func _process(delta: float) -> void:
    time += delta
    position.y = start_position.y + sin(time * bob_speed) * bob_height

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("Player"):
        collect()

func collect() -> void:
    emit_signal("coin_collected", coin_value)
    anim_player.play("collect")
    audio_player.play()
    queue_free()
```

## Kasus Penggunaan Nyata
Sistem pengumpulan koin dan skor adalah mekanik dasar dalam game platformer seperti Mario Bros (koin), Sonic (ring), dan Crash Bandicoot (crystal). Sistem ini memberikan motivasi eksplorasi kepada pemain dan dapat digunakan sebagai gate untuk membuka level atau konten tambahan. Dalam game modern, sistem skor sering diintegrasikan dengan leaderboard online.
