# 5. Memahami jenis-jenis game berdasarkan genre dan platform target

## Definisi Singkat
Genre game adalah kategori berdasarkan gameplay seperti action, RPG, puzzle, atau simulation. Platform target adalah perangkat dimana game akan dimainkan seperti PC, mobile, konsol, atau web browser.

## Analogi
Genre game seperti jenis film (action, drama, komedi). Platform seperti media tayang (bioskop, TV, streaming). Sama seperti film action bisa tayang di semua media, genre tertentu bisa dibuat untuk semua platform.

## Struktur Node (Scene Tree)
Tidak ada struktur node spesifik untuk konsep ini.

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
	var genres = {
		"Action": "Permainan yang mengandalkan refleks dan keterampilan",
		"RPG": "Permainan dengan karakter yang berkembang dan cerita mendalam",
		"Puzzle": "Permainan yang menguji logika dan pemecahan masalah",
		"Simulation": "Permainan yang meniru aktivitas nyata",
		"Strategy": "Permainan yang membutuhkan perencanaan dan taktik",
		"Platformer": "Permainan dengan lompatan dan navigasi vertikal"
	}
	
	var platforms = {
		"PC": "Komputer desktop, kontrol presisi",
		"Mobile": "Smartphone dan tablet, touch controls",
		"Console": "PlayStation, Xbox, Nintendo Switch",
		"Web": "Browser, akses tanpa instalasi"
	}
	
	for genre in genres:
		print(genre, ": ", genres[genre])
	
	print("")
	for platform in platforms:
		print(platform, ": ", platforms[platform])
```

## Kasus Penggunaan Nyata
Memahami genre dan platform membantu dalam perencanaan game. Game action cocok untuk PC dan konsol dengan kontrol presisi. Game puzzle lebih fleksibel dan bisa dimainkan di semua platform. Game mobile biasanya dirancang sesi pendek dengan kontrol sentuh yang intuitif.
