# 6. Mengenal peran-peran dalam tim game development seperti programmer, artist, designer, dan sound designer

## Definisi Singkat
Programmer menulis kode untuk menjalankan game. Artist membuat aset visual seperti sprite, model, dan animasi. Game designer merancang mekanisme gameplay, aturan, dan pengalaman pemain. Sound designer menciptakan efek suara dan musik untuk game.

## Analogi
Tim game development seperti pembuatan film: programmer adalah teknisi yang memastikan semua alat berfungsi, artist adalah sinematografer dan desainer visual, game designer adalah sutradara dan penulis naskah, sound designer adalah komposer musik dan sound engineer.

## Struktur Node (Scene Tree)
```
Game Project
├── Code/ (Programmer)
│   ├── Player.gd
│   ├── Enemy.gd
│   └── GameManager.gd
├── Art/ (Artist)
│   ├── Sprites/
│   ├── Models/
│   └── Animations/
├── Design/ (Game Designer)
│   ├── LevelDesign/
│   └── GameMechanics/
└── Audio/ (Sound Designer)
    ├── Music/
    └── SFX/
```

## Kode GDScript (Godot 4)
```gdscript

var player_health = 100

```

## Kasus Penggunaan Nyata
Dalam studio besar, setiap peran spesialis dan fokus pada tugas masing-masing. Dalam indie development, satu orang mungkin memegang beberapa peran sekaligus. Godot membantu karena editor yang intuitif memungkinkan artist dan designer berkontribusi tanpa harus menguasai pemrograman sepenuhnya.
