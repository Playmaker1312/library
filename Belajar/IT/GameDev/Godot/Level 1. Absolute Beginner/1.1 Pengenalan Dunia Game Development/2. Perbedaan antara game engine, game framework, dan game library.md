# 2. Perbedaan antara game engine, game framework, dan game library

## Definisi Singkat
Game engine adalah software lengkap yang menyediakan tools untuk membuat game dari nol hingga deployment. Game framework adalah kumpulan kode dasar yang mempermudah pembuatan game tanpa menyediakan tools visual. Game library adalah kumpulan fungsi spesifik yang bisa dipanggil untuk membantu tugas tertentu dalam game.

## Analogi
Bayangkan membuat rumah: **game engine** adalah kontraktor utama yang menyediakan semua alat, material, dan tenaga kerja. **game framework** seperti tukang yang sudah punya alat sendiri tapi butuh arsitektur. **game library** adalah toko material yang hanya menyediakan bahan-bahan tertentu seperti cat atau semen.

## Struktur Node (Scene Tree)
Tidak ada struktur node spesifik untuk konsep ini.

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
	print("Contoh penggunaan game engine (Godot):")
	print("- Built-in physics engine")
	print("- Scene system")
	print("- Animation system")
	print("- Audio system")
	print("")
	print("Framework seperti LÖVE2D atau Pygame hanya menyediakan fungsi dasar rendering dan input handling.")
	print("Library seperti Pathfinding Library hanya menyelesaikan satu masalah spesifik.")
```

## Kasus Penggunaan Nyata
Jika kamu ingin membuat game dengan cepat dan sudah memiliki tools visual editor, gunakan game engine seperti Godot atau Unity. Jika kamu lebih suka kode murni dan ingin kontrol penuh atas setiap aspek, gunakan framework seperti Godot headless mode atau LÖVE2D. Jika hanya butuh fitur tertentu seperti audio processing atau networking, gunakan library yang sesuai.
