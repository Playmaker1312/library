# 8. Memahami perbedaan game 2D dan 3D serta kapan menggunakan masing-masing

## Definisi Singkat
Game 2D menggunakan sprite dan koordinat x,y untuk rendering visual datar. Game 3D menggunakan model mesh dan koordinat x,y,z untuk menciptakan kedalaman dan volume. Godot mendukung kedua mode dengan tools terpisah untuk 2D dan 3D.

## Analogi
Game 2D seperti buku komik atau kartun datar. Game 3D seperti diorama atau mainan action figure yang bisa dilihat dari berbagai sudut. Keduanya memiliki kelebihan masing-masing tergantung jenis pengalaman yang ingin diciptakan.

## Struktur Node (Scene Tree)
```
Game 2D:                          Game 3D:
Root Node2D                       Root Node3D
├── Sprite2D                      ├── MeshInstance3D
├── CollisionShape2D              ├── CollisionShape3D
├── TileMap                       ├── Camera3D
└── Camera2D                      ├── DirectionalLight3D
                                  └── WorldEnvironment
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

func _ready():
	print("Perbedaan Game 2D vs 3D:")
	print("")
	print("Game 2D:")
	print("- Koordinat x,y saja")
	print("- Sprite-based rendering")
	print("- PhysicBody2D untuk fisika")
	print("- TileMap untuk level design")
	print("- Performa lebih ringan")
	print("- Contoh: Celeste, Hollow Knight, Shovel Knight")
	print("")
	print("Game 3D:")
	print("- Koordinat x,y,z (kedalaman)")
	print("- Mesh-based rendering")
	print("- RigidBody3D untuk fisika")
	print("- Blender/Model editor untuk asset")
	print("- Membutuhkan hardware lebih kuat")
	print("- Contoh: Godot's own 3D demos")
	
	var is_2d_game = true
	
	if is_2d_game:
		print("Mode: 2D - Menggunakan Node2D sebagai root")
	else:
		print("Mode: 3D - Menggunakan Node3D sebagai root")
```

## Kasus Penggunaan Nyata
Pilih game 2D untuk game sederhana, pixel art, mobile games, atau ketika sumber daya terbatas. Pilih game 3D untuk game dengan visual realistis, dunia terbuka, atau pengalaman immersif. Godot memudahkan transisi antara 2D dan 3D karena editor dan scripting system yang serupa untuk kedua mode.
