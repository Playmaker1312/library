# 1. Apa itu game development dan bagaimana industri game bekerja secara umum

## Definisi Singkat
Game development adalah proses kreatif dan teknis dalam membuat video game, mulai dari konsep awal hingga produk akhir yang dapat dimainkan. Industri game mencakup ekosistem besar yang melibatkan publisher, developer, platform, dan komunitas pemain.

## Analogi
Bayangkan membuat film, tetapi penonton dapat berinteraksi dengan cerita. Game development seperti sutradara yang juga harus memikirkan bagaimana penonton (pemain) akan berinteraksi dengan setiap elemen cerita, aturan, dan tantangan.

## Kasus Penggunaan Nyata
Seorang developer indie memahami bahwa industri game memiliki berbagai jalur karir: menjadi programmer game di studio besar, mendirikan studio kecil, atau fokus pada pengembangan game mobile. Pengetahuan ini membantu dalam membuat keputusan strategis tentang platform target, model bisnis, dan strategi pemasaran game yang akan dibuat.
