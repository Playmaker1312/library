# 12. Memahami konsep Scene dan Node sebagai fondasi utama Godot

## Definisi Singkat
Dalam Godot, **Node** adalah unit terkecil yang memiliki fungsi spesifik seperti menampilkan grafis, memutar suara, atau mengatur logika. **Scene** adalah kumpulan node yang tersusun dalam hierarki tree, membentuk elemen-elemen game seperti karakter, level, atau UI.

## Analogi
Bayangkan Anda sedang membuat mainan robot. Setiap **Node** adalah satu komponen robot — ada komponen untuk mata (sprite), komponen untuk bergerak (character body), dan komponen untuk mendengar (audio listener). **Scene** adalah rangkaian komponen-komponen tersebut yang sudah dipasang menjadi satu kesatuan robot utuh. Anda juga dapat membuat scene kecil (misal: tangan robot) dan menggabungkannya ke dalam scene besar (robot utuh) seperti menyusun balok Lego.

## Konsep Dasar

### Node
- Unit terkecil dalam Godot
- Setiap node memiliki fungsi dan properti spesifik
- Contoh node: `Node2D`, `Sprite2D`, `CollisionShape2D`, `Label`, `Camera2D`

### Scene
- Kumpulan node dalam hierarki tree
- Disimpan sebagai file `.tscn` atau `.scn`
- Dapat di-reuse (digunakan kembali) dalam scene lain

### Scene Tree
- Struktur hierarki dari semua node dalam satu scene
- Root node adalah node paling atas
- Child node mewarisi properti dari parent node

## Struktur Node (Scene Tree)

```
Root Node (Node2D)
├── Background (Sprite2D)
├── Player (CharacterBody2D)
│   ├── Sprite (Sprite2D)
│   ├── Collision (CollisionShape2D)
│   └── Camera (Camera2D)
├── Enemies (Node2D)
│   ├── Enemy1 (CharacterBody2D)
│   └── Enemy2 (CharacterBody2D)
└── UI (CanvasLayer)
    ├── ScoreLabel (Label)
    └── HealthBar (ProgressBar)
```

## Kode GDScript (Godot 4)

### Membuat Scene Sederhana dari Code

```gdscript
extends Node2D

func _ready():
    var sprite = Sprite2D.new()
    sprite.texture = preload("res://assets/sprites/player.png")
    sprite.position = Vector2(200, 300)
    add_child(sprite)
    
    var label = Label.new()
    label.text = "Hello Godot!"
    label.position = Vector2(100, 50)
    add_child(label)
    
    var collision = CollisionShape2D.new()
    var shape = RectangleShape2D.new()
    shape.size = Vector2(64, 64)
    collision.shape = shape
    add_child(collision)
```

### Mengakses Node Lain

```gdscript
extends Node2D

@onready var sprite = $Player/Sprite
@onready var label = $UI/ScoreLabel

func _ready():
    print("Sprite position: ", sprite.position)
    label.text = "Score: 100"

func _process(delta):
    if Input.is_action_pressed("ui_right"):
        sprite.position.x += 200 * delta
```

## Perbedaan Scene dan Node
| Aspek | Node | Scene |
|-------|------|-------|
| Definisi | Unit tunggal | Kumpulan node |
| Penyimpanan | Tidak memiliki file tersendiri | Disimpan sebagai file `.tscn` |
| Reuse | Tidak dapat di-reuse secara terpisah | Dapat di-reuse dalam scene lain |
| Contoh | `Sprite2D`, `Label` | File `player.tscn`, `enemy.tscn` |

## Kasus Penggunaan Nyata
Dalam membuat game RPG, developer membuat scene terpisah untuk setiap elemen: scene `Player.tscn` berisi node karakter dengan sprite, collision, dan script; scene `Enemy.tscn` berisi musuh dengan perilaku AI; dan scene `UI.tscn` berisi elemen antarmuka. Scene-scene ini kemudian digabungkan ke dalam scene `Level.tscn` yang merupakan level utama game. Pendekatan modular ini memudahkan pengembangan dan pemeliharaan game.
