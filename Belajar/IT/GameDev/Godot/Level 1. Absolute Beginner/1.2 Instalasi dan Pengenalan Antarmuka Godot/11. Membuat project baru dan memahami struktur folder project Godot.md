# 11. Membuat project baru dan memahami struktur folder project Godot

## Definisi Singkat
Project Godot adalah container yang menyimpan semua aset, scene, script, dan konfigurasi game Anda. Setiap project memiliki struktur folder bawaan yang terorganisir untuk memudahkan pengelolaan file dan menjaga agar project tetap rapi.

## Analogi
Membuat project Godot seperti membuat Blueprint atau Rencana Kerja untuk membangun rumah. Folder project adalah lahan yang sudah ditandai batas-batasnya, dengan ruang khusus untuk material (aset), cetak biru (scene), rencana teknis (script), dan dokumentasi (konfigurasi). Semua elemen harus diletakkan di tempat yang benar agar rumah dapat dibangun dengan teratur.

## Struktur Folder Project

```
Project_Name/
├── project.godot          ← Konfigurasi utama project
├── export_presets.cfg     ← Konfigurasi export (opsional)
├── .godot/                ← Folder cache Godot (otomatis)
├── scenes/                ← Folder untuk file scene (.tscn)
├── scripts/               ← Folder untuk script GDScript (.gd)
├── assets/                ← Folder untuk aset game
│   ├── sprites/           ← Folder untuk gambar/sprite
│   ├── audio/             ← Folder untuk file audio
│   ├── fonts/             ← Folder untuk font
│   └── ui/                ← Folder untuk elemen UI
├── levels/                ← Folder untuk level game
└── addons/                ← Folder untuk plugin/addon
```

## Langkah Membuat Project Baru

### 1. Membuka Project Manager
```
1. Jalankan Godot Engine
2. Project Manager akan terbuka secara otomatis
3. Klik tombol "New Project"
```

### 2. Mengatur Project
```
1. Nama Project: Masukkan nama project Anda
2. Project Path: Pilih lokasi penyimpanan project
3. Renderer: Pilih renderer (Forward+ untuk kualitas tinggi)
4. Klik "Create & Edit"
```

### 3. Mengatur Folder Project
```
1. Buat folder untuk setiap kategori aset:
   - scenes/
   - scripts/
   - assets/sprites/
   - assets/audio/
2. Pindahkan file ke folder yang sesuai
3. Gunakan FileSystem panel untuk mengelola file
```

## File Konfigurasi Penting

### project.godot
- File konfigurasi utama project
- Berisi pengaturan seperti nama project, resolusi, input mapping
- Dapat diedit langsung atau melalui menu Project Settings

### export_presets.cfg
- Konfigurasi untuk mengeksport game ke platform berbeda
- Berisi preset untuk Windows, Linux, macOS, Android, iOS, Web

## Tips Pengelolaan Project
- **Naming Convention**: Gunakan nama yang konsisten untuk file dan folder
- **Folder Hierarchy**: Buat struktur folder sebelum mulai mengembangkan
- **Versi Control**: Gunakan Git untuk mengontrol versi project
- **Backup**: Selalu backup project secara berkala
- **Avoid Spaces**: Hindari spasi dalam nama file, gunakan underscore (_)

## Kasus Penggunaan Nyata
Seorang developer membuat game puzzle 2D dengan struktur folder yang terorganisir: folder `scenes/` berisi semua scene game, `scripts/` berisi semua kode GDScript, `assets/sprites/` berisi gambar karakter dan item, dan `assets/audio/` berisi musik dan efek suara. Struktur ini memudahkan tim developer untuk menemukan dan mengelola file saat project semakin besar.
