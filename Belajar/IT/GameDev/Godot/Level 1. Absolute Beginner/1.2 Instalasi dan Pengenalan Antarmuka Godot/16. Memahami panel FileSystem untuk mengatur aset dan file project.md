# 16. Memahami panel FileSystem untuk mengatur aset dan file project

## Definisi Singkat
Panel FileSystem adalah area di bagian bawah editor Godot yang menampilkan semua file dan folder dalam project. Panel ini berfungsi sebagai file manager bawaan untuk mengelola aset seperti gambar, audio, script, scene, dan resource lainnya.

## Analogi
Panel FileSystem seperti Lemari Arsip di kantor. Setiap folder adalah laci yang berisi jenis dokumen tertentu — ada laci untuk gambar (sprites), laci untuk dokumen audio, laci untuk rencana kerja (scene), dan laci untuk instruksi teknis (script). Anda dapat membuka, memindahkan, menghapus, dan menambahkan dokumen ke laci yang sesuai.

## Fitur Utama Panel FileSystem

### 1. Struktur Folder
```
res://                    ← Root folder project
├── scenes/               ← File scene (.tscn, .scn)
├── scripts/              ← File script (.gd)
├── assets/               ← Aset game
│   ├── sprites/          ← Gambar (.png, .jpg, .svg)
│   ├── audio/            ← Audio (.wav, .ogg, .mp3)
│   └── fonts/            ← Font (.ttf, .otf)
├── addons/               ← Plugin dan addon
└── project.godot         ← Konfigurasi project
```

### 2. Toolbar FileSystem
- **Path**: Menampilkan lokasi folder saat ini
- **Filter**: Filter file berdasarkan jenis atau nama
- **Sort**: Urutkan file berdasarkan nama, tanggal, atau ukuran
- **New Folder**: Buat folder baru
- **New Script**: Buat script baru
- **New Scene**: Buat scene baru

### 3. Operasi File
- **Import**: Import aset dengan menarik ke dalam panel
- **Rename**: Klik kanan > Rename atau F2
- **Delete**: Klik kanan > Delete atau Del
- **Copy/Paste**: Ctrl+C / Ctrl+V
- **Duplicate**: Ctrl+D

## Kode GDScript (Godot 4)

### Mengakses File dari FileSystem

```gdscript
extends Node2D

var player_texture = preload("res://assets/sprites/player.png")
var bgm_audio = preload("res://assets/audio/bgm.ogg")

func _ready():
    var sprite = Sprite2D.new()
    sprite.texture = player_texture
    add_child(sprite)
    
    var audio_player = AudioStreamPlayer.new()
    audio_player.stream = bgm_audio
    add_child(audio_player)
    audio_player.play()
```

### Memuat File secara Dinamis

```gdscript
extends Node2D

func _ready():
    var texture = load("res://assets/sprites/enemy.png")
    var sprite = Sprite2D.new()
    sprite.texture = texture
    add_child(sprite)

func load_scene(scene_path: String):
    var scene = load(scene_path)
    if scene:
        var instance = scene.instantiate()
        add_child(instance)
```

### Mengelola Aset di Runtime

```gdscript
extends Node2D

var loaded_textures: Dictionary = {}

func preload_texture(path: String) -> Texture2D:
    if loaded_textures.has(path):
        return loaded_textures[path]
    
    var texture = load(path)
    if texture:
        loaded_textures[path] = texture
    return texture

func _ready():
    var player_tex = preload_texture("res://assets/sprites/player.png")
    var enemy_tex = preload_texture("res://assets/sprites/enemy.png")
    
    var player_sprite = Sprite2D.new()
    player_sprite.texture = player_tex
    add_child(player_sprite)
```

## Tips Pengelolaan Aset

### 1. Organisasi Folder
```
- Gunakan folder terpisah untuk setiap jenis aset
- Buat subfolder untuk kategori (misal: sprites/player, sprites/enemies)
- Jangan campur file project dengan file aset
```

### 2. Naming Convention
```
- Gunakan huruf kecil dan underscore untuk nama file
- Contoh: player_idle.png, bgm_level1.ogg
- Hindari spasi dan karakter khusus
```

### 3. Import Settings
```
- Godot otomatis mengimpor aset saat pertama kali ditambahkan
- Pengaturan import dapat diakses di panel Inspector
- Atur kompresi, filter, dan parameter lain sesuai kebutuhan
```

### 4. Re-import
```
- Jika aset tidak ter-update, klik kanan > Reimport
- Berguna setelah mengedit file di luar Godot
- Pastikan format file kompatibel dengan Godot
```

## Format File yang Didukung

| Jenis | Format | Keterangan |
|-------|--------|------------|
| Gambar | PNG, JPG, SVG, WebP | Untuk sprite, texture, icon |
| Audio | WAV, OGG, MP3 | Untuk musik dan efek suara |
| Font | TTF, OTF, WOFF | Untuk font teks |
| 3D Model | GLTF, OBJ, DAE | Untuk model 3D |
| Video | Theora, WebM | Untuk video playback |

## Kasus Penggunaan Nyata
Seorang developer mengelola aset game RPG dengan struktur folder terorganisasi: folder `assets/sprites/characters/` untuk sprite karakter, `assets/sprites/tilesets/` untuk tileset level, `assets/audio/music/` untuk musik, dan `assets/audio/sfx/` untuk efek suara. Dengan panel FileSystem, ia dapat dengan mudah menemukan, mengimpor, dan mengelola ratusan file aset tanpa kebingungan.
