# 14. Cara menyimpan scene membuka scene dan mengatur scene utama project

## Definisi Singkat
Menyimpan scene berarti menyimpan susunan node ke dalam file `.tscn` atau `.scn`. Membuka scene berarti memuat file scene yang sudah ada. Mengatur scene utama berarti menentukan scene mana yang akan dimuat pertama kali saat game dijalankan.

## Analogi
Menyimpan scene seperti menyimpan Blueprint rumah ke dalam map tertentu. Membuka scene adalah mengambil Blueprint dari map untuk dilihat kembali. Mengatur scene utama seperti menentukan pintu masuk utama rumah — pintu pertama yang akan dilewati tamu saat datang.

## Menyimpan Scene

### 1. Menyimpan Scene Baru
```
1. Buat scene dengan menambahkan node
2. Klik menu Scene > Save Scene (Ctrl+S)
3. Pilih lokasi folder penyimpanan
4. Beri nama file (misal: player.tscn)
5. Klik Save
```

### 2. Menyimpan Scene sebagai Copy
```
1. Klik menu Scene > Save Scene As... (Ctrl+Shift+S)
2. Pilih lokasi dan nama baru
3. Klik Save
```

### 3. Menyimpan Semua Scene
```
1. Klik menu Scene > Save All Scenes (Ctrl+Shift+S)
2. Semua scene yang berubah akan disimpan
```

## Membuka Scene

### 1. Melalui FileSystem
```
1. Di panel FileSystem, cari file .tscn
2. Double-click file tersebut
3. Scene akan terbuka di editor
```

### 2. Melalui Menu
```
1. Klik menu Scene > Open Scene... (Ctrl+O)
2. Cari file scene yang diinginkan
3. Klik Open
```

### 3. Membuka Scene dalam Tab Baru
```
1. Ctrl + Klik file scene di FileSystem
2. Scene akan terbuka di tab baru
```

## Mengatur Scene Utama

### 1. Melalui Project Settings
```
1. Klik menu Project > Project Settings...
2. Tab General, bagian Application > Run
3. Di field "Main Scene", pilih scene utama
4. Klik OK
```

### 2. Melalui Tombol Play
```
1. Klik tombol Play (F5) di toolbar
2. Jika belum ada scene utama, Godot akan meminta Anda memilih
3. Pilih scene yang dijadikan scene utama
4. Klik Select
```

### 3. Mengubah Scene Utama
```
1. Buka scene yang ingin dijadikan utama
2. Klik menu Scene > Set as Main Scene
3. Atau Ctrl+Shift+F5
```

## Struktur Node (Scene Tree)

```
Project Root
├── MainScene.tscn ← Scene Utama (dijalankan pertama kali)
│   ├── Level1
│   ├── Player
│   └── UI
├── MenuScene.tscn ← Scene Menu
│   ├── Title
│   └── Buttons
└── GameOverScene.tscn ← Scene Game Over
    ├── Message
    └── RestartButton
```

## Kode GDScript (Godot 4)

### Beralih Antar Scene

```gdscript
extends Node2D

func _on_start_button_pressed():
    get_tree().change_scene_to_file("res://scenes/MainScene.tscn")

func _on_restart_button_pressed():
    get_tree().reload_current_scene()

func _on_menu_button_pressed():
    get_tree().change_scene_to_file("res://scenes/MenuScene.tscn")
```

### Memuat Scene sebagai Instance

```gdscript
extends Node2D

var enemy_scene = preload("res://scenes/Enemy.tscn")

func _ready():
    for i in range(5):
        var enemy = enemy_scene.instantiate()
        enemy.position = Vector2(randf_range(100, 800), randf_range(100, 500))
        add_child(enemy)
```

### Menyimpan Posisi Scene

```gdscript
extends Node2D

var current_level: int = 1
var level_paths = {
    1: "res://scenes/levels/Level1.tscn",
    2: "res://scenes/levels/Level2.tscn",
    3: "res://scenes/levels/Level3.tscn"
}

func load_level(level_number: int):
    if level_paths.has(level_number):
        current_level = level_number
        get_tree().change_scene_to_file(level_paths[level_number])
```

## Tips Penting
- **Penamaan Konsisten**: Gunakan naming convention yang konsisten untuk file scene
- **Folder Terorganisasi**: Simpan scene dalam folder yang sesuai kategorinya
- **Scene Utama**: Selalu tentukan scene utama sebelum mulai pengembangan
- **Instanced Scene**: Gunakan instanced scene untuk elemen yang sering di-reuse
- **Autoload**: Gunakan autoload untuk scene yang harus selalu ada (misal: AudioManager)

## Kasus Penggunaan Nyata
Developer membuat game dengan 3 scene utama: `Menu.tscn` sebagai scene pembuka, `Level1.tscn` sebagai level pertama, dan `GameOver.tscn` sebagai layar game over. Scene `Menu.tscn` diatur sebagai scene utama. Saat pemain menekan tombol Start, game berpindah ke `Level1.tscn`. Saat pemain kalah, game berpindah ke `GameOver.tscn`. Semua transisi scene menggunakan `change_scene_to_file()`.
