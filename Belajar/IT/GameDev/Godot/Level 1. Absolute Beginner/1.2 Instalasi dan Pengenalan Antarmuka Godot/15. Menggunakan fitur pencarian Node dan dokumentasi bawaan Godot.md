# 15. Menggunakan fitur pencarian Node dan dokumentasi bawaan Godot

## Definisi Singkat
Godot memiliki fitur pencarian Node untuk menemukan node tertentu dalam scene tree, dan dokumentasi bawaan yang dapat diakses langsung dari editor. Fitur-fitur ini membantu developer bekerja lebih efisien tanpa harus meninggalkan editor.

## Analogi
Fitur pencarian Node seperti menggunakan fitur "Find" di aplikasi pengolah kata — Anda mengetik nama dan langsung ditemukan. Dokumentasi bawaan Godot seperti buku panduan yang selalu tersamping, selalu siap dibuka saat Anda membutuhkan referensi tentang cara kerja suatu fitur atau node.

## Fitur Pencarian Node

### 1. Mencari Node di Scene Tree
```
1. Buka panel Scene
2. Tekan Ctrl+F atau klik ikon pencarian
3. Ketik nama node yang dicari
4. Node yang cocok akan ditampilkan dalam daftar
5. Klik node untuk memilihnya di scene tree
```

### 2. Mencari Node dari Script
```
1. Gunakan $NamaNode untuk akses langsung
2. Gunakan get_node() untuk akses dinamis
3. Gunakan find_children() untuk pencarian rekursif
```

### 3. Remote Inspector
```
1. Jalankan game (F5)
2. Buka panel Remote di Scene Panel
3. Lihat dan pilih node yang sedang berjalan
4. Inspeksi properti secara real-time
```

## Fitur Dokumentasi Bawaan

### 1. Membuka Dokumentasi
```
1. Tekan F1 atau klik menu Help > Search Help
2. Ketik nama class, fungsi, atau properti
3. Klik hasil pencarian untuk melihat dokumentasi
```

### 2. Akses Cepat dari Editor
```
1. Ctrl+Klik nama class/fungsi di script editor
2. Dokumentasi akan terbuka langsung
3. Atau klik kanan > Look Up Documentation
```

### 3. Builtin Reference
```
1. Di Inspector, klik ikon ? di sebelah properti
2. Penjelasan singkat properti akan muncul
3. Klik untuk melihat dokumentasi lengkap
```

## Struktur Node (Scene Tree)

```
Main (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite (Sprite2D)
│   ├── Collision (CollisionShape2D)
│   └── Camera (Camera2D)
├── Enemies (Node2D)
│   ├── Enemy1 (CharacterBody2D)
│   └── Enemy2 (CharacterBody2D)
└── UI (CanvasLayer)
    ├── ScoreLabel (Label)
    └── HealthBar (ProgressBar)
```

## Kode GDScript (Godot 4)

### Pencarian Node

```gdscript
extends Node2D

func _ready():
    var player = $Player
    print("Found player: ", player.name)
    
    var enemies = get_node("Enemies").get_children()
    print("Number of enemies: ", enemies.size())
    
    var score_label = find_child("ScoreLabel")
    if score_label:
        score_label.text = "Score: 0"
    
    var all_labels = find_children("*", "Label", true, false)
    for label in all_labels:
        print("Label found: ", label.name)
```

### Menggunakan Dokumentasi

```gdscript
extends CharacterBody2D

@export var speed: float = 200.0

func _physics_process(delta):
    var direction = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    velocity = direction * speed
    move_and_slide()
```

### Remote Inspector Access

```gdscript
extends Node2D

func _process(delta):
    if OS.is_debug_build():
        var remote_tree = get_tree()
        print("Current scene: ", remote_tree.current_scene.name)
        print("Node count: ", remote_tree.get_node_count())
```

## Shortcut Penting

| Shortcut | Fungsi |
|----------|--------|
| `Ctrl+F` | Cari node di Scene Panel |
| `F1` | Buka dokumentasi |
| `Ctrl+Klik` | Lihat dokumentasi item |
| `F5` | Jalankan game |
| `F6` | Jalankan scene saat ini |
| `Ctrl+Shift+F1` | Toggle full-screen viewport |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |

## Tips Efisiensi
- **Gunakan Remote Inspector**: Saat game berjalan, periksa node melalui Remote untuk debugging
- **Bookmark Dokumentasi**: Simpan halaman dokumentasi penting untuk referensi cepat
- **Ctrl+Klik**: Gunakan shortcut ini untuk melihat dokumentasi tanpa membuka Help
- **Search Pattern**: Gunakan wildcard `*` dalam pencarian untuk hasil yang lebih fleksibel
- **Recent Scripts**: Gunakan `Ctrl+Shift+O` untuk membuka file terakhir yang diedit

## Kasus Penggunaan Nyata
Seorang developer sedang mengerjakan game dan perlu mencari node `HealthBar` yang tersembunyi di dalam hierarki UI yang kompleks. Dengan fitur pencarian Node (`Ctrl+F`), ia mengetik "HealthBar" dan langsung menemukannya. Saat ingin mengetahui cara mengatur progress bar, ia menekan `F1`, mencari "ProgressBar", dan mendapatkan dokumentasi lengkap tentang properti dan method yang tersedia.
