# 10. Mengenal tampilan antarmuka Godot yaitu Viewport Scene Panel Inspector FileSystem dan Output

## Definisi Singkat
Antarmuka Godot terdiri dari beberapa panel utama yang masing-masing memiliki fungsi khusus untuk membantu proses pengembangan game. Panel-panel ini dirancang agar pengembang dapat melihat, mengedit, dan mengelola elemen game secara efisien.

## Analogi
Antarmuka Godot seperti bengkel kerja dengan meja kerja berbeda-beda: **Viewport** adalah area Anda meletakkan dan melihat objek kerja, **Scene Panel** adalah daftar komponen yang Anda pasang, **Inspector** adalah panel pengaturan detail setiap komponen, **FileSystem** adalah lemari penyimpanan alat dan bahan, dan **Output** adalah jendela untuk melihat hasil kerja atau pesan kesalahan.

## Struktur Panel Utama

```
┌─────────────────────────────────────────────────────┐
│                    Top Toolbar                       │
├──────────┬──────────────────────────────┬───────────┤
│          │                              │           │
│  Scene   │       Viewport               │ Inspector │
│  Panel   │       (2D / 3D View)         │   Panel   │
│          │                              │           │
│          │                              │           │
├──────────┴──────────────────────────────┴───────────┤
│                    Bottom Panel                      │
│  FileSystem │ Output │ Debugger │ Audio              │
└─────────────────────────────────────────────────────┘
```

## Penjelasan Panel

### 1. Viewport
- Area tengah yang menampilkan scene dalam mode 2D atau 3D
- Tempat Anda memposisikan, memutar, dan mengatur objek secara visual
- Memiliki toolbar khusus di bagian atas untuk mode editing

### 2. Scene Panel (kiri atas)
- Menampilkan struktur tree dari scene yang sedang aktif
- Menunjukkan hubungan parent-child antar node
- Tempat menambah, menghapus, dan mengatur node

### 3. Inspector Panel (kanan atas)
- Menampilkan properti dan pengaturan node yang dipilih
- Tempat mengatur parameter seperti posisi, ukuran, warna, dll
- Dapat di-scroll untuk melihat semua properti yang tersedia

### 4. FileSystem Panel (kiri bawah)
- Menampilkan semua file dan aset dalam project
- Tempat mengelola gambar, audio, script, dan resource lain
- Mendukung drag-and-drop ke dalam scene

### 5. Output Panel (kanan bawah)
- Menampilkan pesan dari sistem Godot
- Menampilkan error, warning, dan print output dari script
- Berguna untuk debugging dan melihat hasil eksekusi

## Tips Penggunaan
- **Toggle Panel**: Klik ikon untuk show/hide panel yang tidak diperlukan
- **Resize**: Geser tepi panel untuk mengubah ukuran
- **Layout**: Gunakan menu Layout untuk menyimpan konfigurasi panel favorit
- **Shortcuts**: Gunakan `Ctrl+Shift+F1` untuk toggle full-screen viewport

## Kasus Penggunaan Nyata
Ketika membuat game platformer 2D, seorang developer menggunakan **Viewport** untuk memposisikan karakter dan musuh di level, **Scene Panel** untuk melihat hierarki node game, **Inspector** untuk mengatur properti seperti kecepatan karakter, **FileSystem** untuk mengelola file sprite dan audio, dan **Output** untuk memantau pesan error saat menjalankan game.
