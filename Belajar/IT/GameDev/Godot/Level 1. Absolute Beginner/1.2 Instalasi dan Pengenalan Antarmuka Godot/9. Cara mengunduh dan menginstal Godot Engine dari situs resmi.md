# 9. Cara mengunduh dan menginstal Godot Engine dari situs resmi

## Definisi Singkat
Godot Engine adalah game engine open-source yang dapat diunduh secara gratis dari situs resminya. Proses instalasi sangat sederhana karena Godot tidak memerlukan instalasi tradisional — cukup ekstrak file dan langsung jalankan.

## Analogi
Menginstal Godot seperti mengunduh file ZIP portable untuk aplikasi editor. Tidak ada installer wizard yang rumit, cukup unduh, ekstrak ke folder pilihan Anda, dan jalankan executable-nya — mirip seperti membuka dokumen dari USB drive.

## Langkah Instalasi

### 1. Mengunduh Godot
1. Buka browser dan kunjungi **https://godotengine.org**
2. Klik tombol **Download** di halaman utama
3. Pilih versi **Godot 4** (stable release)
4. Pilih versi sesuai sistem operasi:
   - **Windows**: Unduh file `.zip`
   - **macOS**: Unduh file `.zip`
   - **Linux**: Unduh file `.zip` atau `.x86_64`

### 2. Mengekstrak File
```
1. Buka file .zip yang telah diunduh
2. Ekstrak seluruh isi ke folder pilihan (misal: C:\Games\Godot)
3. Pastikan Anda mengekstrak ke folder yang mudah diakses
```

### 3. Menjalankan Godot
```
1. Buka folder hasil ekstrak
2. Cari file bernama:
   - Windows: Godot_v4.x.x-stable_win64.exe
   - macOS: Godot
   - Linux: Godot_v4.x.x-stable_linux.x86_64
3. Double-click file tersebut untuk menjalankan
```

### 4. Mengatur Editor
```
1. Saat pertama kali dibuka, Godot akan meminta Anda memilih default editor
2. Pilih antara Godot (Forward+) atau Godot compatibility
3. Klik OK untuk melanjutkan
```

## Tips Penting
- **Tidak perlu instalasi**: Godot berjalan sebagai portable application
- **Versi Stable**: Selalu gunakan versi stable untuk pembelajaran
- **Ukuran File**: Godot hanya berukuran sekitar 30-40 MB, sangat ringan
- **Multiple Versions**: Anda dapat menjalankan beberapa versi Godot secara bersamaan
- **Export Templates**: Unduh export templates secara terpisah jika ingin mengeksport game ke platform lain

## Kasus Penggunaan Nyata
Seorang developer indie di Indonesia ingin membuat game 2D pertamanya. Dengan mengunduh Godot Engine dari situs resmi, ia mendapatkan game engine yang ringan dan gratis tanpa biaya lisensi. Proses instalasi yang cepat memungkinkannya langsung mulai belajar dan membuat game dalam waktu singkat.
