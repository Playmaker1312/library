# 13. Mengenal jenis-jenis Node dasar seperti Node2D Sprite2D CollisionShape2D dan Label

## Definisi Singkat
Godot menyediakan berbagai jenis node dasar yang masing-masing memiliki fungsi spesifik. **Node2D** adalah node dasar untuk objek 2D, **Sprite2D** menampilkan gambar/tekstur, **CollisionShape2D** mendefinisikan area tubuh fisik, dan **Label** menampilkan teks di layar.

## Analogi
Bayangkan Anda sedang mendekorasi ruangan. **Node2D** adalah lantai atau dinding tempat Anda meletakkan semua benda. **Sprite2D** adalah gambar poster atau lukisan yang Anda tempelkan di dinding. **CollisionShape2D** adalah kaca pembatas yang tidak terlihat tapi mencegah orang menyentuh lukisan. **Label** adalah papan nama atau tulisan yang menempel di dinding.

## Jenis-Jenis Node Dasar

### 1. Node2D
- Node dasar untuk semua objek 2D
- Memiliki properti `position`, `rotation`, `scale`
- Tidak memiliki visual sendiri, hanya sebagai container

### 2. Sprite2D
- Menampilkan gambar atau tekstur
- Memiliki properti `texture` untuk mengatur gambar
- Dapat diatur flip, offset, dan modulasi warna

### 3. CollisionShape2D
- Mendefinisikan area tubuh fisik untuk deteksi tabrakan
- Harus memiliki **Shape** (Rectangle, Circle, Capsule, dll)
- Tidak terlihat di layar, hanya untuk logika fisik

### 4. Label
- Menampilkan teks di layar
- Memiliki properti `text`, `font`, `font_size`, `color`
- Berguna untuk UI seperti skor, instruksi, dialog

## Struktur Node (Scene Tree)

```
CharacterBody2D (Root)
├── Sprite2D
│   └── texture: player.png
├── CollisionShape2D
│   └── shape: RectangleShape2D (32x64)
├── Label
│   └── text: "Player"
└── AnimationPlayer
```

## Kode GDScript (Godot 4)

### Menggunakan Node2D sebagai Parent

```gdscript
extends Node2D

@export var speed: float = 200.0
var velocity: Vector2 = Vector2.ZERO

func _process(delta):
    velocity = Vector2.ZERO
    
    if Input.is_action_pressed("ui_right"):
        velocity.x += 1
    if Input.is_action_pressed("ui_left"):
        velocity.x -= 1
    if Input.is_action_pressed("ui_down"):
        velocity.y += 1
    if Input.is_action_pressed("ui_up"):
        velocity.y -= 1
    
    position += velocity.normalized() * speed * delta
```

### Menggunakan Sprite2D

```gdscript
extends Sprite2D

@export var animation_speed: float = 5.0
var frame_index: int = 0

func _ready():
    texture_filter = CanvasItem.TEXTURE_FILTER_NEAREST

func _process(delta):
    if Input.is_action_just_pressed("ui_accept"):
        frame_index = (frame_index + 1) % hframes
        frame = frame_index
```

### Menggunakan CollisionShape2D dengan CharacterBody2D

```gdscript
extends CharacterBody2D

@export var speed: float = 300.0
@export var jump_force: float = -400.0
var gravity: float = 980.0

func _physics_process(delta):
    velocity.y += gravity * delta
    
    if is_on_floor() and Input.is_action_just_pressed("ui_accept"):
        velocity.y = jump_force
    
    var direction = Input.get_axis("ui_left", "ui_right")
    velocity.x = direction * speed
    
    move_and_slide()
```

### Menggunakan Label untuk UI

```gdscript
extends Label

var score: int = 0

func _ready():
    text = "Score: 0"

func add_score(value: int):
    score += value
    text = "Score: " + str(score)

func _process(delta):
    if Input.is_action_just_pressed("ui_accept"):
        add_score(10)
```

## Properti Penting Tiap Node

### Node2D
- `position: Vector2` — Posisi node
- `rotation: float` — Rotasi dalam radian
- `scale: Vector2` — Skala node
- `z_index: int` — Urutan render

### Sprite2D
- `texture: Texture2D` — Gambar yang ditampilkan
- `flip_h: bool` — Flip horizontal
- `flip_v: bool` — Flip vertical
- `modulate: Color` — Modulasi warna
- `hframes: int` — Jumlah frame horizontal (sprite sheet)
- `vframes: int` — Jumlah frame vertikal

### CollisionShape2D
- `shape: Shape2D` — Bentuk collision
- `disabled: bool` — Nonaktifkan collision
- `one_way: bool` — One-way collision

### Label
- `text: String` — Teks yang ditampilkan
- `font: Font` — Font yang digunakan
- `font_size: int` — Ukuran font
- `horizontal_alignment: HorizontalAlignment` — Alignment horizontal
- `vertical_alignment: VerticalAlignment` — Alignment vertical

## Kasus Penggunaan Nyata
Dalam membuat game platformer sederhana, developer menggunakan **CharacterBody2D** sebagai parent, **Sprite2D** untuk menampilkan karakter, **CollisionShape2D** dengan bentuk capsule untuk tubuh fisik karakter, dan **Label** untuk menampilkan jumlah nyawa di pojok layar. Kombinasi node-node ini membentuk satu karakter yang fungsional dan memiliki interaksi dengan dunia game.
