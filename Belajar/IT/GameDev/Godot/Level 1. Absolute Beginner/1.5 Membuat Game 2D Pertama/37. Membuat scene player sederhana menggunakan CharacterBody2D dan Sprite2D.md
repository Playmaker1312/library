# 37. Membuat scene player sederhana menggunakan CharacterBody2D dan Sprite2D

## Definisi Singkat
CharacterBody2D adalah jenis node yang dirancang khusus untuk karakter yang bergerak di game 2D dengan kontrol manual terhadap fisika. Sprite2D digunakan untuk menampilkan gambar atau tekstur karakter di layar.

## Analogi
Bayangkan kamu sedang membuat boneka tangan. CharacterBody2D adalah kerangka boneka yang menentukan bentuk dan posisi, sedangkan Sprite2D adalah kain dan warna yang membuat boneka terlihat menarik. Kamu perlu menggabungkan keduanya agar boneka bisa bergerak dan terlihat sempurna.

## Struktur Node (Scene Tree)

```
Player (CharacterBody2D)
├── Sprite2D (menampilkan gambar karakter)
└── CollisionShape2D (menentukan area tabrakan)
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

const SPEED = 300.0

func _ready() -> void:
    pass

func _physics_process(delta: float) -> void:
    var direction := Vector2.ZERO
    
    if Input.is_action_pressed("move_right"):
        direction.x += 1
    if Input.is_action_pressed("move_left"):
        direction.x -= 1
    if Input.is_action_pressed("move_down"):
        direction.y += 1
    if Input.is_action_pressed("move_up"):
        direction.y -= 1
    
    if direction.length() > 0:
        direction = direction.normalized()
    
    velocity = direction * SPEED
    move_and_slide()
```

## Kasus Penggunaan Nyata
Dalam game platformer seperti Super Mario, player dikontrol menggunakan tombol panah atau joystick. CharacterBody2D memastikan karakter tidak jatuh menembus tanah dan berinteraksi dengan objek lain di level. Sprite2D menampilkan animasi berjalan, melompat, atau berdiri sesuai aksi pemain.
