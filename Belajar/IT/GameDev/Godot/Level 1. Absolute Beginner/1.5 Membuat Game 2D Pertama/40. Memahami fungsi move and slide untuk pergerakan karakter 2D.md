# 40. Memahami fungsi move_and_slide untuk pergerakan karakter 2D

## Definisi Singkat
move_and_slide() adalah fungsi bawaan CharacterBody2D yang memindahkan karakter berdasarkan velocity dan secara otomatis menangani tabrakan dengan objek lain. Fungsi ini membuat karakter berhenti atau meluncur di sepanjang permukaan yang ditabrak.

## Analogi
Bayangkan kamu berjalan di lorong sempit. Saat tubuhmu menyentuh dinding, kamu tidak menembus dinding tetapi meluncur di sepanjang permukaannya. move_and_slide bekerja seperti itu - karakter akan bergeser di sepanjang objek yang ditabrak daripada menembusnya.

## Struktur Node (Scene Tree)

```
Player (CharacterBody2D)
├── Sprite2D
└── CollisionShape2D
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

const SPEED = 300.0
const ACCELERATION = 1500.0
const FRICTION = 1200.0

func _physics_process(delta: float) -> void:
    var direction := Vector2(
        Input.get_axis("move_left", "move_right"),
        Input.get_axis("move_up", "move_down")
    ).normalized()
    
    if direction:
        velocity = velocity.move_toward(direction * SPEED, ACCELERATION * delta)
    else:
        velocity = velocity.move_toward(Vector2.ZERO, FRICTION * delta)
    
    move_and_slide()
    
    if is_on_floor():
        pass
    if is_on_wall():
        pass
    if is_on_ceiling():
        pass
```

## Kasus Penggunaan Nyata
Dalam game fighting seperti Street Fighter, move_and_slide memastikan karakter meluncur di sepanjang arena saat bertarung tanpa menembus batas layar. Dalam platformer, fungsi ini membuat karakter berhenti tepat saat menyentuh platform atau dinding.
