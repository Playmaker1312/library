# 39. Menulis script pergerakan player dasar menggunakan input keyboard

## Definisi Singkat
Sistem input di Godot memetakan tombol keyboard menjadi action yang bisa dibaca oleh script. Kamu dapat mengakses input menggunakan fungsi Input.is_action_pressed() atau Input.is_action_just_pressed() untuk mendetiksi tombol yang ditekan.

## Analogi
Bayangkan remote control TV. Tombol-tombol pada remote adalah key, sedangkan fungsi seperti "Power", "Volume+", "Channel-" adalah action. Kamu tidak perlu tahu kode tombol fisik, cukup panggil nama action yang sudah kamu tentukan.

## Struktur Node (Scene Tree)

```
Player (CharacterBody2D)
├── Sprite2D
└── CollisionShape2D
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

const SPEED = 300.0
const JUMP_VELOCITY = -400.0
var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta: float) -> void:
    if not is_on_floor():
        velocity.y += gravity * delta
    
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = JUMP_VELOCITY
    
    var direction := Vector2(
        Input.get_axis("move_left", "move_right"),
        Input.get_axis("move_up", "move_down")
    ).normalized()
    
    velocity.x = direction.x * SPEED
    
    if direction.y != 0:
        velocity.y = direction.y * SPEED
    elif not is_on_floor():
        pass
    else:
        velocity.y = 0
    
    move_and_slide()
```

## Kasus Penggunaan Nyata
Dalam game puzzle seperti Tetris atau game strategi, pemain menggunakan keyboard untuk mengontrol arah jatuhnya blok atau memindahkan kursor. Input keyboard memberikan responsivitas tinggi dan presisi yang dibutuhkan untuk gameplay kompetitif.
