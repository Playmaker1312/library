# 42. Menambahkan kamera menggunakan Camera2D dan mengatur batas pergerakan kamera

## Definisi Singkat
Camera2D adalah node yang menentukan area pandang kamera di dalam game 2D. Kamu bisa mengatur batas (limit) agar kamera tidak bergerak keluar dari area level yang sudah ditentukan.

## Analogi
Bayangkan kamu sedang menonton pertunjukan teater dari kursi penonton. Camera2D adalah kursimu yang bisa bergeser ke kiri atau kanan mengikuti aksi di atas panggung. Limit kamera adalah batas dinding panggung yang menentukan seberapa jauh kursimu bisa bergeser.

## Struktur Node (Scene Tree)

```
Level (Node2D)
├── Camera2D
├── TileMapLayer
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   └── CollisionShape2D
```

## Kode GDScript (Godot 4)

```gdscript
extends Camera2D

@export var target: Node2D
@export var smooth_speed: float = 5.0
@export var offset_position: Vector2 = Vector2(0, -50)

func _ready() -> void:
    make_current()
    limit_left = 0
    limit_top = 0
    limit_right = 1920
    limit_bottom = 1080
    position_smoothing_enabled = true
    position_smoothing_speed = smooth_speed

func _physics_process(delta: float) -> void:
    if target:
        var target_pos = target.global_position + offset_position
        global_position = global_position.lerp(target_pos, smooth_speed * delta)
```

## Kasus Penggunaan Nyata
Dalam game Metroidvania seperti Hollow Knight, Camera2D mengikuti pergerakan pemain dengan batas-batas tertentu agar kamera tidak menampilkan area di luar level. Limit kamera memastikan pemain tidak melihat bagian kosong atau area yang belum selesai dibuat.
