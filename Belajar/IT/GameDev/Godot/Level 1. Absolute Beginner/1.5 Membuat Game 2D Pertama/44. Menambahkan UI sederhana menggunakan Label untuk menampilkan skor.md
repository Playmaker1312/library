# 44. Menambahkan UI sederhana menggunakan Label untuk menampilkan skor

## Definisi Singkat
Label adalah node UI yang digunakan untuk menampilkan teks di layar seperti skor, nyawa, atau pesan. Kamu bisa mengubah teks Label menggunakan script setiap kali nilai skor berubah.

## Analogi
Bayangkan skor adalah papan skor di pertandingan sepak bola. Label berfungsi seperti angka pada papan skor yang terus diperbarui setiap kali ada gol. Kamu hanya perlu mengubah angkanya dan papan akan otomatis menampilkan nilai terbaru.

## Struktur Node (Scene Tree)

```
UI (CanvasLayer)
├── ScoreLabel (Label)
├── HealthLabel (Label)
└── TimerLabel (Label)
```

## Kode GDScript (Godot 4)

```gdscript
extends CanvasLayer

@onready var score_label: Label = $ScoreLabel
@onready var health_label: Label = $HealthLabel
@onready var timer_label: Label = $TimerLabel

var score: int = 0
var health: int = 3
var time_remaining: float = 60.0

func _ready() -> void:
    update_score_display()
    update_health_display()
    update_timer_display()

func _process(delta: float) -> void:
    if time_remaining > 0:
        time_remaining -= delta
        update_timer_display()

func add_score(points: int) -> void:
    score += points
    update_score_display()

func take_damage() -> void:
    health -= 1
    update_health_display()
    if health <= 0:
        get_tree().reload_current_scene()

func update_score_display() -> void:
    score_label.text = "Skor: " + str(score)

func update_health_display() -> void:
    health_label.text = "Nyawa: " + str(health)

func update_timer_display() -> void:
    var minutes = int(time_remaining) / 60
    var seconds = int(time_remaining) % 60
    timer_label.text = "Waktu: %02d:%02d" % [minutes, seconds]
```

## Kasus Penggunaan Nyata
Dalam game arcade seperti Pac-Man, Label UI menampilkan skor yang terus bertambah setiap kali pemain mengambil titik. Dalam game racing, UI menampilkan posisi pemain dan waktu tempuh secara real-time menggunakan Label yang diupdate setiap frame.
