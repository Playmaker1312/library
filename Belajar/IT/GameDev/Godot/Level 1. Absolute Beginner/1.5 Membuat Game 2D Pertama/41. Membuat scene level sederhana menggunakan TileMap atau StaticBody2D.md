# 41. Membuat scene level sederhana menggunakan TileMap atau StaticBody2D

## Definisi Singkat
TileMap adalah node yang memungkinkan kamu menggambar level menggunakan grid tile dari TileSet yang sudah dibuat. StaticBody2D adalah objek statis yang tidak bergerak tetapi memiliki area fisik untuk tabrakan seperti dinding atau platform.

## Analogi
Bayangkan kamu sedang menyusun puzzle raksasa. TileMap seperti lembar puzzle kosong dengan kisi-kisi, dan setiap tile adalah kepingan puzzle yang kamu tempatkan untuk membentuk peta. StaticBody2D seperti batu-batu besar yang kamu taruh sebagai penghalang yang tidak bisa dilewati.

## Struktur Node (Scene Tree)

```
Level (Node2D)
├── TileMapLayer (Node2D)
│   ├── Ground (TileMapLayer)
│   └── Walls (TileMapLayer)
├── StaticBody2D (Dinding)
│   └── CollisionShape2D
├── Platforms (Node2D)
│   ├── Platform1 (StaticBody2D)
│   │   └── CollisionShape2D
│   └── Platform2 (StaticBody2D)
│       └── CollisionShape2D
└── Player (CharacterBody2D)
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

@onready var tile_map: TileMapLayer = $TileMapLayer
@onready var spawn_point: Marker2D = $SpawnPoint

func _ready() -> void:
    var player = preload("res://scenes/player.tscn").instantiate()
    player.global_position = spawn_point.global_position
    add_child(player)

func get_cell_tile_type(cell_position: Vector2i) -> int:
    return tile_map.get_cell_source_id(cell_position)

func is_tile_solid(cell_position: Vector2i) -> bool:
    var tile_data = tile_map.get_cell_tile_data(cell_position)
    if tile_data:
        return tile_data.get_custom_data("solid")
    return false
```

## Kasus Penggunaan Nyata
Dalam game platformer seperti Celeste, TileMap digunakan untuk membangun ratusan level dengan berbagai jenis tile seperti tanah, dinding, dan platform. StaticBody2D digunakan untuk objek yang tidak bergerak tetapi memiliki fisika seperti trampolin atau gerbang yang bisa dibuka.
