# 38. Menambahkan CollisionShape2D pada player untuk deteksi tabrakan

## Definisi Singkat
CollisionShape2D adalah node yang menentukan area atau bentuk fisik dari suatu objek untuk mendeteksi tabrakan dengan objek lain. Node ini wajib ada pada setiap PhysicsBody2D agar interaksi fisika dapat bekerja.

## Analogi
Bayangkan kamu sedang bermain paintball. CollisionShape2D adalah area tubuhmu yang menjadi target tembakan. Tanpa area ini, peluru tidak akan pernah mengenaimu karena sistem tidak tahu di mana tubuhmu berada.

## Struktur Node (Scene Tree)

```
Player (CharacterBody2D)
├── Sprite2D
└── CollisionShape2D (shape: RectangleShape2D atau CapsuleShape2D)
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

@onready var sprite: Sprite2D = $Sprite2D
@onready var collision: CollisionShape2D = $CollisionShape2D

func _ready() -> void:
    if collision.shape == null:
        var new_shape = RectangleShape2D.new()
        new_shape.size = Vector2(32, 64)
        collision.shape = new_shape

func _physics_process(delta: float) -> void:
    var direction := Vector2.ZERO
    
    if Input.is_action_pressed("move_right"):
        direction.x += 1
    if Input.is_action_pressed("move_left"):
        direction.x -= 1
    if Input.is_action_pressed("move_down"):
        direction.y += 1
    if Input.is_action_pressed("move_up"):
        direction.y -= 1
    
    if direction.length() > 0:
        direction = direction.normalized()
    
    velocity = direction * 300.0
    move_and_slide()

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("enemy"):
        queue_free()
```

## Kasus Penggunaan Nyata
Dalam game RPG, CollisionShape2D pada player digunakan untuk mendeteksi ketika pemain menyentuh treasure chest, NPC, atau musuh. Ketika tabrakan terjadi, kode tertentu akan dieksekusi seperti membuka dialog, mengambil item, atau mengurangi HP pemain.
