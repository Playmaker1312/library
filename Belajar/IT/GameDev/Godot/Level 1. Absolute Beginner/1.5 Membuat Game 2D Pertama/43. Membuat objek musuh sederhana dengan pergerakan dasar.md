# 43. Membuat objek musuh sederhana dengan pergerakan dasar

## Definisi Singkat
Musuh dalam game 2D biasanya menggunakan CharacterBody2D atau Area2D dengan script yang mengontrol pola pergerakan seperti patroli maju-mundur atau mengikuti pemain. Musuh dapat berinteraksi dengan player melalui sistem tabrakan.

## Analogi
Bayangkan musuh adalah penjaga gerbang yang berjalan bolak-balik di depan pintu. Setiap kali ia mencapai ujung jalurnya, ia berbalik arah. Jika kamu mendekatinya, ia akan mengubah pola dan bergerak ke arahmu.

## Struktur Node (Scene Tree)

```
Enemy (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
├── RayCast2D (untuk mendeteksi tepi)
└── Timer (untuk cooldown serangan)
```

## Kode GDScript (Godot 4)

```gdscript
extends CharacterBody2D

@export var speed: float = 100.0
@export var patrol_distance: float = 200.0
@onready var ray_cast: RayCast2D = $RayCast2D

var start_position: Vector2
var direction: float = 1.0
var is_chasing: bool = false

func _ready() -> void:
    start_position = global_position
    add_to_group("enemy")

func _physics_process(delta: float) -> void:
    if is_chasing:
        var player = get_tree().get_first_node_in_group("player")
        if player:
            var dir = (player.global_position - global_position).normalized()
            velocity = dir * speed * 1.5
    else:
        velocity.x = direction * speed
        velocity.y = 0
        
        if global_position.x > start_position.x + patrol_distance:
            direction = -1.0
            sprite.flip_h = true
        elif global_position.x < start_position.x - patrol_distance:
            direction = 1.0
            sprite.flip_h = false
    
    if not ray_cast.is_colliding() and is_on_floor():
        direction *= -1.0
    
    move_and_slide()

func _on_area_entered(area: Area2D) -> void:
    if area.is_in_group("player"):
        is_chasing = true

func _on_area_exited(area: Area2D) -> void:
    if area.is_in_group("player"):
        is_chasing = false
        is_on_floor()

@onready var sprite: Sprite2D = $Sprite2D
```

## Kasus Penggunaan Nyata
Dalam game survival horror seperti Five Nights at Freddy's, musuh memiliki pola pergerakan patrol yang bisa berubah menjadi agresif saat mendeteksi pemain. Di game side-scroller, musuh berjalan maju-mundur dan melompati rintangan untuk mengejar pemain.
