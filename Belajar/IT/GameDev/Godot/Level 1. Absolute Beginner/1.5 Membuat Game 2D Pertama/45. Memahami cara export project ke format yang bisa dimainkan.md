# 45. Memahami cara export project ke format yang bisa dimainkan

## Definisi Singkat
Export project adalah proses mengubah project Godot menjadi file executable yang bisa dijalankan di platform tertentu seperti Windows, Linux, Android, atau iOS tanpa memerlukan editor Godot.

## Analogi
Bayangkan kamu sedang membungkus hadiah. Project Godot adalah isinya, sedangkan export adalah kemasan luarnya. Kamu perlu memilih kemasan yang sesuai agar penerima hadiah bisa membukanya dengan mudah di perangkat mereka.

## Struktur Node (Scene Tree)

```
Project Godot
├── Main Scene (Node2D atau Control)
│   ├── Player
│   ├── Level
│   └── UI
```

## Kode GDScript (Godot 4)

```gdscript
extends Control

@onready var export_button: Button = $ExportButton
@onready var platform_option: OptionButton = $PlatformOption

func _ready() -> void:
    platform_option.add_item("Windows", 0)
    platform_option.add_item("Linux", 1)
    platform_option.add_item("Web (HTML5)", 2)
    platform_option.add_item("Android", 3)
    export_button.pressed.connect(_on_export_pressed)

func _on_export_pressed() -> void:
    var selected_platform = platform_option.get_item_text(platform_option.get_selected())
    print("Exporting to: " + selected_platform)
    
    var export_preset = "Windows Desktop"
    var export_path = "res://build/game.exe"
    
    EditorInterface.get_singleton("EditorExportPlatform").export_project(
        export_preset,
        export_path,
        false,
        []
    )

func get_export_platforms() -> PackedStringArray:
    var platforms = PackedStringArray()
    for preset in EditorInterface.get_export_platforms():
        platforms.append(preset)
    return platforms
```

## Kasus Penggunaan Nyata
Setelah menyelesaikan game indie, developer melakukan export ke多个平台 seperti Steam (Windows/Mac/Linux), itch.io (Web), dan mobile stores (Android/iOS). Proses export memastikan game bisa dimainkan oleh pemain di berbagai perangkat tanpa perlu menginstal Godot.
