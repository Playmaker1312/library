# 35. Menggunakan onready var untuk mereferensikan Node saat scene siap

## Definisi Singkat
`@onready var` adalah anotasi GDScript yang menunda inisialisasi variabel sampai scene siap (setelah `_ready()` dipanggil). Ini memastikan Node yang direferensikan sudah ada dalam scene tree saat variabel diakses.

## Analogi
Seperti janji temu: Anda membuat janji (deklarasi variabel) untuk bertemu seseorang (Node), tapi pertemuan itu baru terjadi setelah semua orang tiba di lokasi (scene siap). Anda tidak bisa bertemu sebelum orang lain sampai.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
├── AnimationPlayer
└── AudioStreamPlayer2D
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var sprite = $Sprite2D
@onready var collision = $CollisionShape2D
@onready var animation = $AnimationPlayer
@onready var audio = $AudioStreamPlayer2D

var speed = 200.0
var health = 100

func _ready():
    sprite.modulate = Color.GREEN
    print("Sprite ready: ", sprite.name)

func _physics_process(delta):
    var velocity = Vector2.ZERO
    
    if Input.is_action_pressed("move_right"):
        velocity.x += 1
    if Input.is_action_pressed("move_left"):
        velocity.x -= 1
    if Input.is_action_pressed("move_down"):
        velocity.y += 1
    if Input.is_action_pressed("move_up"):
        velocity.y -= 1
    
    velocity = velocity.normalized() * speed
    move_and_slide()
    
    if velocity.length() > 0:
        animation.play("walk")
    else:
        animation.play("idle")
```

## Kasus Penggunaan Nyata
Dalam game RPG, karakter pemain memiliki banyak komponen: sprite untuk visual, collision untuk deteksi tabrakan, animation player untuk animasi, dan audio player untuk efek suara. `@onready var` memastikan semua komponen ini siap digunakan saat game dimulai tanpa error null reference.
