# 29. Memahami hierarki Node dan hubungan Parent-Child dalam scene

## Definisi Singkat
Hierarki Node adalah struktur pohon di mana setiap Node memiliki parent (indak) kecuali Root, dan dapat memiliki banyak child (anak). Hubungan Parent-Child menentukan bagaimana Node berperilaku, bergerak, dan berinteraksi dalam scene tree.

## Analogi
Bayangkan sebuah perusahaan dengan struktur organisasi: Direktur (Root) memiliki manager (parent), dan manager memiliki karyawan (child). Jika manager dipindah ke departemen lain, semua karyawannya ikut pindah. Begitu juga dengan Node dalam Godot.

## Struktur Node (Scene Tree)
```
Root (Node2D/Node3D)
├── Parent (Node2D)
│   ├── Child1 (Sprite2D)
│   └── Child2 (CollisionShape2D)
└── Sibling (Label)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

func _ready():
    var parent = get_parent()
    var children = get_children()
    print("Parent: ", parent.name)
    print("Jumlah children: ", children.size())
    
    for child in children:
        print("Child: ", child.name)
    
    var root = get_tree().get_root()
    print("Root: ", root.name)
```

## Kasus Penggunaan Nyata
Dalam game platformer, karakter pemain (parent) memiliki child seperti sprite, collision shape, dan UI health bar. Ketika karakter bergerak, semua child ikut bergerak bersama. Hubungan parent-child memastikan komponen-komponen ini tetap terkait dan berperilaku sebagai satu kesatuan yang koheren.
