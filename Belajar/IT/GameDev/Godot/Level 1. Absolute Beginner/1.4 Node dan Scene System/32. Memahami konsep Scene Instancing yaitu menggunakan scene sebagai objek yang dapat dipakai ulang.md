# 32. Memahami konsep Scene Instancing yaitu menggunakan scene sebagai objek yang dapat dipakai ulang

## Definisi Singkat
Scene Instancing adalah teknik di mana satu scene dapat digunakan berulang kali dalam scene lain seperti template. Setiap instansi adalah salinan independen dari scene asli yang dapat dimodifikasi secara terpisah.

## Analogi
Seperti cetakan kue (cookie cutter): Anda membuat satu cetakan (scene), lalu menggunakannya untuk membuat banyak kue (instansi). Setiap kue memiliki bentuk yang sama tapi bisa diberi topping berbeda (properti berbeda).

## Struktur Node (Scene Tree)
```
MainScene (Node2D)
├── Player (CharacterBody2D)
├── Enemy1 (instansi dari Enemy.tscn)
├── Enemy2 (instansi dari Enemy.tscn)
├── Bullet1 (instansi dari Bullet.tscn)
└── Bullet2 (instansi dari Bullet.tscn)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

var enemy_scene = preload("res://scenes/Enemy.tscn")
var bullet_scene = preload("res://scenes/Bullet.tscn")

func _ready():
    var enemy1 = enemy_scene.instantiate()
    enemy1.position = Vector2(100, 100)
    add_child(enemy1)
    
    var enemy2 = enemy_scene.instantiate()
    enemy2.position = Vector2(200, 100)
    add_child(enemy2)

func spawn_bullet():
    var bullet = bullet_scene.instantiate()
    bullet.position = $Player.position
    add_child(bullet)
```

## Kasus Penggunaan Nyata
Dalam game shoot 'em up, peluru (bullet) adalah scene instancing. Setiap kali pemain menembak, sebuah instansi bullet baru dibuat dari template yang sama. Ini efisien karena tidak perlu membuat ulang seluruh scene dari awal untuk setiap peluru.
