# 33. Cara membuat dan menyimpan scene terpisah lalu menginstansiasinya di scene lain

## Definisi Singkat
Membuat scene terpisah berarti mengembangkan komponen game sebagai file scene独立 (`.tscn`) yang dapat diinstansikan di scene lain. Ini adalah prinsip modularitas dalam pengembangan game.

## Analogi
Seperti membuat LEGO: Anda membuat beberapa komponen standard (roda, badan mobil, sayap pesawat) sebagai unit terpisah, lalu menggabungkannya untuk membuat berbagai model. Setiap komponen bisa digunakan berkali-kali.

## Struktur Node (Scene Tree)
```
Project/
├── scenes/
│   ├── Main.tscn
│   ├── Player.tscn
│   ├── Enemy.tscn
│   ├── Bullet.tscn
│   └── Explosion.tscn
├── scripts/
│   ├── Player.gd
│   ├── Enemy.gd
│   └── Bullet.gd
└── assets/
    └── sprites/
```

## Kode GDScript (Godot 4)
```gdscript
# Main.gd
extends Node2D

var player_scene = preload("res://scenes/Player.tscn")
var enemy_scene = preload("res://scenes/Enemy.tscn")

func _ready():
    var player = player_scene.instantiate()
    player.position = Vector2(400, 300)
    add_child(player)
    
    for i in range(5):
        var enemy = enemy_scene.instantiate()
        enemy.position = Vector2(randi() % 800, randi() % 600)
        add_child(enemy)
```

## Kasus Penggunaan Nyata
Dalam game tower defense, setiap menara (tower) adalah scene terpisah dengan script dan visual sendiri. Saat pemain membeli menara baru, game menginstansiasi scene menara yang dipilih ke dalam posisi grid yang sesuai. Ini memudahkan pengembangan dan pemeliharaan setiap jenis menara.
