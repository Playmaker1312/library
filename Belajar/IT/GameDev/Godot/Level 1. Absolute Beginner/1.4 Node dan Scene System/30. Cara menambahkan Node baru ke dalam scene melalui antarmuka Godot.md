# 30. Cara menambahkan Node baru ke dalam scene melalui antarmuka Godot

## Definisi Singkat
Menambahkan Node baru ke dalam scene dapat dilakukan melalui antarmuka Godot dengan klik kanan di Scene TreeDock, memilih "Add Child Node", atau menggunakan tombol "+" di toolbar. Setiap Node memiliki fungsi spesifik dalam game.

## Analogi
Mirip dengan menambahkan objek baru di program desain grafis: Anda memilih jenis objek (Node), menentukan posisi dalam hierarki (parent), dan mengatur propertinya. Seperti menambahkan lapisan (layer) dalam Photoshop.

## Struktur Node (Scene Tree)
```
Root (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   ├── CollisionShape2D
│   └── Camera2D
└── UI (CanvasLayer)
    ├── HealthBar (ProgressBar)
    └── ScoreLabel (Label)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

func _ready():
    var new_sprite = Sprite2D.new()
    new_sprite.name = "NewSprite"
    add_child(new_sprite)
    
    var new_label = Label.new()
    new_label.text = "Hello Godot"
    new_label.position = Vector2(100, 100)
    add_child(new_label)
    
    var new_button = Button.new()
    new_button.text = "Click Me"
    new_button.position = Vector2(100, 150)
    add_child(new_button)
```

## Kasus Penggunaan Nyata
Dalam game RPG, saat pemain memasuki area baru, sistem secara dinamis menambahkan NPC, musuh, dan item ke dalam scene. Penambahan Node secara programatik memungkinkan konten game yang dinamis dan tidak terbatas pada apa yang sudah ada di editor.
