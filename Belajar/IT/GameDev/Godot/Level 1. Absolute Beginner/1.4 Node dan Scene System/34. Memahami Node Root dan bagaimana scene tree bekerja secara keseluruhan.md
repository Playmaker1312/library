# 34. Memahami Node Root dan bagaimana scene tree bekerja secara keseluruhan

## Definisi Singkat
Node Root adalah node paling atas dalam scene tree yang menjadi induk dari semua node lain. Scene tree adalah struktur hierarkis yang mengatur semua node dalam game, menentukan urutan proses, dan mengelola aliran data.

## Analogi
Bayangkan sebuah pohon raksasa: Root adalah batang utama, branch adalah parent node, dan daun adalah child node. Semua energi (data) mengalir dari akar ke daun, dan setiap bagian saling terhubung dalam satu sistem organik.

## Struktur Node (Scene Tree)
```
Root (Window)
├── Main (Node2D) - Scene aktif
│   ├── Player (CharacterBody2D)
│   │   ├── Sprite2D
│   │   └── CollisionShape2D
│   ├── Enemies (Node2D)
│   │   ├── Enemy1 (CharacterBody2D)
│   │   └── Enemy2 (CharacterBody2D)
│   └── UI (CanvasLayer)
│       ├── HealthBar (ProgressBar)
│       └── ScoreLabel (Label)
└── AutoLoad (Node) - Singleton global
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
    var root = get_tree().get_root()
    print("Root: ", root.name)
    print("Root children: ", root.get_child_count())
    
    var current_scene = get_tree().current_scene
    print("Current scene: ", current_scene.name)
    
    var scene_tree = get_tree()
    print("Scene tree nodes: ", scene_tree.get_node_count())
    
    var auto_load = scene_tree.get_node("/root/AutoLoad")
    print("AutoLoad: ", auto_load.name)
```

## Kasus Penggunaan Nyata
Dalam game dengan multiple levels, Root tetap sama tapi current scene berubah saat level berganti. AutoLoad (singleton) tetap ada di Root untuk menyimpan data global seperti skor, pengaturan, dan state game yang persisten antar scene.
