# 31. Cara mengakses Node lain dari script menggunakan dollar sign dan get node

## Definisi Singkat
Untuk mengakses Node lain dalam scene tree, gunakan operator `$` (dollar sign) atau method `get_node()` dengan path relatif atau absolut. Ini memungkinkan komunikasi antar Node dalam scene yang sama.

## Analogi
Seperti alamat rumah dalam sebuah kota: `$"ChildNode"` adalah alamat tetangga sebelah (relatif), sedangkan `get_node("/root/MainScene/ChildNode")` adalah alamat lengkap dari kota (absolut). Keduanya mengarah ke tempat yang sama.

## Struktur Node (Scene Tree)
```
MainScene (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   └── CollisionShape2D
├── Enemy (CharacterBody2D)
└── UI (CanvasLayer)
    └── HealthBar (ProgressBar)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var sprite = $Sprite2D
@onready var collision = $CollisionShape2D

func _ready():
    var player = $"../Player"
    var health_bar = get_node("/root/MainScene/UI/HealthBar")
    
    print("Sprite: ", sprite.name)
    print("Player: ", player.name)
    print("Health Bar: ", health_bar.name)
    
    var enemy = get_node("../Enemy")
    print("Enemy: ", enemy.name)
```

## Kasus Penggunaan Nyata
Dalam game fighting, karakter pemain perlu mengakses health bar UI untuk update HP, mengakses musuh terdekat untuk serangan, dan mengakses efek partikel untuk visual. Akses node memungkinkan komunikasi real-time antar komponen game yang berbeda.
