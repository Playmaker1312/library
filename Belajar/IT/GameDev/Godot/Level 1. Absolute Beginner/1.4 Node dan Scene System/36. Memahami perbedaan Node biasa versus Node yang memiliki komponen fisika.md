# 36. Memahami perbedaan Node biasa versus Node yang memiliki komponen fisika

## Definisi Singkat
Node biasa (seperti Node2D, Node3D) hanya menempati posisi dalam hierarki tanpa interaksi fisika. Node fisika (seperti CharacterBody2D, RigidBody2D, StaticBody2D) memiliki sifat fisika seperti gravitasi, kolisi, dan dinamika gerak.

## Analogi
Bayangkan dua jenis objek dalam dunia nyata: poster dinding (Node biasa) hanya menempel di dinding tanpa berinteraksi, sementara bola (Node fisika) jatuh karena gravitasi, memantul saat menabrak dinding, dan bergerak sesuai hukum fisika.

## Struktur Node (Scene Tree)
```
MainScene (Node2D)
├── Background (Sprite2D) - Node biasa
├── Player (CharacterBody2D) - Node fisika
│   ├── Sprite2D
│   └── CollisionShape2D
├── Platform (StaticBody2D) - Node fisika
│   ├── Sprite2D
│   └── CollisionShape2D
└── Coin (Area2D) - Node fisika sederhana
    ├── Sprite2D
    - CollisionShape2D
```

## Kode GDScript (Godot 4)
```gdscript
# Player.gd - CharacterBody2D
extends CharacterBody2D

var speed = 300.0
var jump_force = -400.0
var gravity = 800.0

func _physics_process(delta):
    if not is_on_floor():
        velocity.y += gravity * delta
    
    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = jump_force
    
    var direction = Input.get_axis("move_left", "move_right")
    velocity.x = direction * speed
    
    move_and_slide()

# Coin.gd - Area2D
extends Area2D

func _on_body_entered(body):
    if body.name == "Player":
        queue_free()
```

## Kasus Penggunaan Nyata
Dalam game platformer, karakter pemain (CharacterBody2D) bergerak dengan fisika realistis seperti gravitasi dan kolisi. Platform (StaticBody2D) tetap diam tapi memberikan bentuk kolisi. Koin (Area2D) mendeteksi tanpa bereaksi fisika. Pemilihan jenis Node fisika yang tepat menentukan perilaku objek dalam game.
