# 24. Struktur kondisional if, elif, dan else dalam GDScript

## Definisi Singkat
Struktur kondisional `if`, `elif`, dan `else` digunakan untuk menjalankan blok kode yang berbeda berdasarkan kondisi tertentu. `if` mengecek kondisi pertama, `elif` mengecek kondisi tambahan jika kondisi sebelumnya false, dan `else` menjalankan kode jika semua kondisi sebelumnya false.

## Analogi
Bayangkan kamu sedang memilih jalur di persimpangan. `if` seperti memilih jalan pertama jika kondisi terpenuhi. `elif` seperti mencoba jalan kedua jika jalan pertama tidak bisa dilalui. `else` seperti mengambil jalan terakhir yang tersisa.

## Struktur Node (Scene Tree)
```
- Node
  - Label (menampilkan hasil kondisi)
  - Sprite2D (berubah berdasarkan kondisi)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var nyawa := 60
var level := 12
var has_key := false

func _ready():
    if nyawa <= 0:
        print("Game Over!")
    elif nyawa <= 30:
        print("Nyawa kritis! Cari healing.")
    elif nyawa <= 60:
        print("Nyawa sedang. Hati-hati.")
    else:
        print("Nyawa aman. Lanjutkan petualangan!")
    
    if level >= 20 and has_key:
        print("Bisa masuk dungeon level atas!")
    elif level >= 10 or has_key:
        print("Bisa masuk area menengah.")
    else:
        print("Masih di area pemula.")
```

## Kasus Penggunaan Nyata
Struktur kondisional digunakan untuk menentukan perilaku karakter berdasarkan status seperti menampilkan UI berbeda berdasarkan nyawa, mengubah perilaku musuh berdasarkan jarak pemain, atau menentukan dialog NPC berdasarkan level pemain.
