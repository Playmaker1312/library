# 23. Operator logika yaitu and, atau, dan not dalam GDScript

## Definisi Singkat
Operator logika digunakan untuk menggabungkan beberapa kondisi boolean. `and` menghasilkan `true` jika kedua kondisi benar. `or` menghasilkan `true` jika salah satu kondisi benar. `not` membalik nilai boolean dari `true` ke `false` atau sebaliknya.

## Analogi
Bayangkan kamu sedang membeli snack. `and` seperti "Aku mau beli keripik DAN minuman" (keduanya harus tersedia). `or` seperti "Aku mau beli keripik ATAU minuman" (salah satu saja cukup). `or` seperti "Aku mau beli keripik ATAU minuman" (salah satu saja cukup). `not` seperti "Aku TIDAK mau beli keripik" (membalik keinginan).

## Struktur Node (Scene Tree)
```
- Node
  - Label (menampilkan hasil logika)
  - Area2D (mendeteksi tabrakan dengan kondisi)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var nyawa := 80
var level := 15
var has_weapon := true
var has_shield := false

func _ready():
    var can_attack := has_weapon and nyawa > 0
    var can_defend := has_shield or level >= 10
    var is_vulnerable := not has_shield
    
    print("Can attack: " + str(can_attack))
    print("Can defend: " + str(can_defend))
    print("Is vulnerable: " + str(is_vulnerable))

func _process(delta):
    if has_weapon and nyawa > 50:
        print("Siap menyerang!")
    elif has_shield or level >= 20:
        print("Siap bertahan!")
    elif not has_weapon and not has_shield:
        print("Tidak punya senjata atau perisai!")
```

## Kasus Penggunaan Nyata
Operator logika digunakan untuk menggabungkan kondisi seperti mengecek apakah pemain bisa menyerang (punya senjata DAN nyawa cukup), apakah bisa membuka pintu (punya kunci ATAU level cukup), atau apakah musuh dalam kondisi lemah (tidak punya perisai DAN nyawa rendah).
