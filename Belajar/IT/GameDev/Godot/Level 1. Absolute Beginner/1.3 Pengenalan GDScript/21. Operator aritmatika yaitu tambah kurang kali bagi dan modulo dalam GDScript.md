# 21. Operator aritmatika yaitu tambah, kurang, kali, bagi, dan modulo dalam GDScript

## Definisi Singkat
Operator aritmatika digunakan untuk melakukan operasi matematika dasar: penjumlahan (+), pengurangan (-), perkalian (*), pembagian (/), dan sisa bagi atau modulo (%).

## Analogi
Bayangkan kamu sedang berbelanja di pasar. `+` seperti menambah barang ke keranjang. `-` seperti membuang barang dari keranjang. `*` seperti membeli banyak barang sekaligus. `/` seperti membagi makanan dengan teman-teman. `%` seperti mengetahui sisa uang setelah membeli barang dengan harga tertentu.

## Struktur Node (Scene Tree)
```
- Node
  - Label (menampilkan hasil kalkulasi)
  - Timer (menggunakan operator untuk countdown)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var nyawa := 100
var damage := 25
var jumlah_musuh := 4
var pengalaman := 50

func _ready():
    var hasil_tambah := nyawa + 20
    var hasil_kurang := nyawa - damage
    var hasil_kali := damage * jumlah_musuh
    var hasil_bagi := pengalaman / jumlah_musuh
    var hasil_modulo := pengalaman % jumlah_musuh
    
    print("Nyawa + 20 = " + str(hasil_tambah))
    print("Nyawa - damage = " + str(hasil_kurang))
    print("Damage x musuh = " + str(hasil_kali))
    print("Exp / musuh = " + str(hasil_bagi))
    print("Exp mod musuh = " + str(hasil_modulo))
```

## Kasus Penggunaan Nyata
Operator aritmatika digunakan untuk menghitung damage, membagi pengalaman ke beberapa musuh, menghitung sisa nyawa, menentukan posisi berdasarkan kecepatan dan waktu, serta berbagai kalkulan game lainnya.
