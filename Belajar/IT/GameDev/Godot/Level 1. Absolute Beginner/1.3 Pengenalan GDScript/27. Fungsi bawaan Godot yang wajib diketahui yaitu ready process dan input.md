# 27. Fungsi bawaan Godot yang wajib diketahui yaitu _ready, _process, dan _input

## Definisi Singkat
Godot memiliki fungsi bawaan yang dipanggil secara otomatis oleh engine: `_ready()` dipanggil saat node siap, `_process(delta)` dipanggil setiap frame untuk update logic, dan `_input(event)` dipanggil saat ada input dari pemain.

## Analogi
`_ready()` seperti alarm yang berbunyi saat kamu bangun tidur dan siap memulai hari. `_process()` seperti detak jantung yang terus berjalan setiap saat untuk menjaga tubuh tetap hidup. `_input()` seperti telinga yang mendengar setiap suara di sekitar.

## Struktur Node (Scene Tree)
```
- Node2D
  - Sprite2D
  - CollisionShape2D
  - script.gd (menggunakan fungsi bawaan)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

var waktu := 0.0
var kecepatan := 200.0

func _ready():
    print("Node siap dimulai!")
    position = Vector2(100, 300)

func _process(delta):
    waktu += delta
    if waktu >= 1.0:
        print("Sudah berjalan " + str(int(waktu)) + " detik")
        waktu = 0.0
    
    var direction := Vector2.ZERO
    if Input.is_action_pressed("ui_right"):
        direction.x += 1
    if Input.is_action_pressed("ui_left"):
        direction.x -= 1
    position += direction * kecepatan * delta

func _input(event):
    if event.is_action_pressed("ui_accept"):
        print("Tombol ditekan!")
    if event is InputEventKey and event.pressed:
        print("Key pressed: " + event.as_text_physical_keycode())
```

## Kasus Penggunaan Nyata
`_ready()` digunakan untuk inisialisasi seperti memuat data atau mengatur posisi awal. `_process()` digunakan untuk game loop seperti menggerakkan karakter, update UI, atau animasi. `_input()` digunakan untuk menangkap input seperti menekan tombol atau menggerakkan mouse.
