# 19. Tipe data dasar dalam GDScript yaitu int, float, String, bool, dan null

## Definisi Singkat
GDScript memiliki beberapa tipe data dasar yang sering digunakan: `int` untuk bilangan bulat, `float` untuk bilangan desimal, `String` untuk teks, `bool` untuk nilai true/false, dan `null` untuk nilai kosong.

## Analogi
Bayangkan kotak penyimpanan berbeda. Kotak `int` hanya bisa menyimpan angka tanpa koma seperti 5 atau 100. Kotak `float` bisa menyimpan angka dengan koma seperti 3.14 atau 9.5. Kotak `String` menyimpan teks seperti "Hello". Kotak `bool` hanya berisi lampu yang bisa menyala (true) atau mati (false). `null` adalah kondisi kotak yang benar-benar kosong.

## Struktur Node (Scene Tree)
```
- Node
  - Label (menampilkan String)
  - Timer (menggunakan int untuk countdown)
  - ProgressBar (menggunakan float untuk persentase)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var nama := "Player One"
var level := 5
var experience := 99.5
var is_alive := true
var target := null

func _ready():
    print("Nama: " + nama)
    print("Level: " + str(level))
    print("Exp: " + str(experience))
    print("Alive: " + str(is_alive))
    print("Target: " + str(target))
```

## Kasus Penggunaan Nyata
Tipe data ini digunakan di seluruh sistem game. `int` untuk scoring dan level, `float` untuk kecepatan dan posisi, `String` untuk dialog dan UI text, `bool` untuk status seperti is_paused atau is_attacking, dan `null` untuk menandakan tidak ada referensi.
