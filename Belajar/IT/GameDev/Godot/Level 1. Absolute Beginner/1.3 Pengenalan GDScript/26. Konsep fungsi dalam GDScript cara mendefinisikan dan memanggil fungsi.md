# 26. Konsep fungsi dalam GDScript cara mendefinisikan dan memanggil fungsi

## Definisi Singkat
Fungsi adalah blok kode yang dapat dipanggil ulang untuk menjalankan tugas tertentu. Fungsi didefinisikan dengan kata kunci `func` dan bisa menerima parameter serta mengembalikan nilai.

## Analogi
Fungsi seperti resep masakan yang sudah jadi. Kamu bisa memanggil resep itu kapan saja untuk membuat masakan yang sama. Parameter seperti bahan yang bisa kamu sesuaikan setiap kali memanggil resep.

## Struktur Node (Scene Tree)
```
- Node
  - Label (menampilkan hasil fungsi)
  - Sprite2D (menggunakan fungsi untuk animasi)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

func tambah_nilai(a: int, b: int) -> int:
    return a + b

func sapa_pemain(nama: String) -> String:
    return "Selamat datang, " + nama + "!"

func hitung_damage(base_damage: int, multiplier: float) -> int:
    return int(base_damage * multiplier)

func _ready():
    var hasil := tambah_nilai(10, 20)
    print("Hasil tambah: " + str(hasil))
    
    var sapaan := sapa_pemain("Hero")
    print(sapaan)
    
    var total_damage := hitung_damage(50, 2.5)
    print("Total damage: " + str(total_damage))
```

## Kasus Penggunaan Nyata
Fungsi digunakan untuk mengorganisir kode seperti fungsi untuk menghitung damage, fungsi untuk menggerakkan karakter, fungsi untuk menyimpan game, atau fungsi untuk menampilkan UI. Penggunaan fungsi membuat kode lebih rapi dan bisa dipanggil berulang kali.
