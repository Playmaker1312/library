# 17. Apa itu GDScript dan mengapa GDScript dirancang khusus untuk Godot

## Definisi Singkat
GDScript adalah bahasa pemrograman scripting yang dirancang khusus oleh tim Godot Engine untuk membuat game di dalam engine tersebut. Bahasa ini menggunakan sintaksis yang mirip dengan Python sehingga mudah dipelajari oleh pemula.

## Analogi
Bayangkan GDScript seperti bahasa lokal di sebuah kota. Kamu bisa menggunakan bahasa lain seperti C# atau VisualScript di Godot, tapi GDScript adalah bahasa yang paling nyaman karena dibuat oleh penduduk asli kota itu sendiri. Semua fitur kota sudah terintegrasi sempurna dengan bahasa lokal tersebut.

## Struktur Node (Scene Tree)
GDScript tidak memiliki struktur node spesifik, namun script ini akan menempel pada node seperti berikut:

```
- Node2D
  - Sprite2D
    - AnimationPlayer
  - CollisionShape2D
  - GDScript (terpasang pada parent)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

var kecepatan := 200.0

func _ready():
    print("Game dimulai!")

func _process(delta):
    position.x += kecepatan * delta
    if position.x > 1100:
        position.x = -100
```

## Kasus Penggunaan Nyata
GDScript digunakan di hampir semua game yang dibuat dengan Godot Engine. Contoh nyata termasuk game platformer seperti Celeste-like, game puzzle, dan bahkan game 3D sederhana. Banyak developer indie memilih GDScript karena kemudahannya dalam prototyping dan iterasi cepat.
