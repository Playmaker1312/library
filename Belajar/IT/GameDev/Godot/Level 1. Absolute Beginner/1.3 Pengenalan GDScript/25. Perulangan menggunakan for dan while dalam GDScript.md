# 25. Perulangan menggunakan for dan while dalam GDScript

## Definisi Singkat
Perulangan digunakan untuk menjalankan blok kode secara berulang. `for` digunakan untuk iterasi dengan jumlah yang sudah diketahui, sedangkan `while` digunakan untuk iterasi selama kondisi tertentu masih true.

## Analogi
`for` seperti menghitung dari 1 sampai 10 dengan jelas tahu kapan berhenti. `while` seperti berlari selama masih punya tenaga, tidak tahu pasti kapan berhenti tapi berhenti saat kondisi tidak terpenuhi.

## Struktur Node (Scene Tree)
```
- Node
  - Label (menampilkan output perulangan)
  - Timer (menggunakan while untuk countdown)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

func _ready():
    for i in range(5):
        print("Iterasi for: " + str(i))
    
    for item in ["Pedang", "Perisai", "Potion"]:
        print("Item: " + item)
    
    var countdown := 5
    while countdown > 0:
        print("Countdown: " + str(countdown))
        countdown -= 1
    print("Waktu habis!")
```

## Kasus Penggunaan Nyata
`for` digunakan untuk iterasi seperti menampilkan semua item di inventory, membuat array musuh di level, atau mengulang animasi tertentu. `while` digunakan untuk kondisi yang berlanjut seperti menunggu input pemain, countdown timer, atau loop utama game.
