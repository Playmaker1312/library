# 20. Cara mendeklarasikan variabel menggunakan var dan const

## Definisi Singkat
`var` digunakan untuk mendeklarasikan variabel yang nilainya bisa berubah seiring waktu, sedangkan `const` digunakan untuk mendeklarasikan konstanta yang nilainya tetap dan tidak bisa diubah setelah dideklarasikan.

## Analogi
`var` seperti papan tulis yang bisa kamu hapus dan tulis ulang nilainya kapan saja. `const` seperti prasasti batu yang sudah diukir dan tidak bisa diubah isinya. Kamu bisa membaca prasasti tapi tidak bisa mengubah tulisan di atasnya.

## Struktur Node (Scene Tree)
```
- Node2D
  - script.gd (menempel pada Node2D)
  - Sprite2D
  - Area2D
    - CollisionShape2D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

var nyawa := 100
var nama := "Warrior"
var kecepatan := 200.0

const DAMAGE := 25
const MAX_LEVEL := 99
const NAMA_GAME := "RPG Adventure"

func _ready():
    print(NAMA_GAME)
    print("Nyawa awal: " + str(nyawa))

func _process(delta):
    if Input.is_action_just_pressed("ui_accept"):
        terima_damage()

func terima_damage():
    nyawa -= DAMAGE
    if nyawa < 0:
        nyawa = 0
    print("Nyawa tersisa: " + str(nyawa))
```

## Kasus Penggunaan Nyata
`var` digunakan untuk data yang berubah seperti nyawa pemain, skor, dan posisi. `const` digunakan untuk nilai yang konstan seperti batas maksimum level, damage tetap, atau nama game yang tidak akan berubah selama runtime.
