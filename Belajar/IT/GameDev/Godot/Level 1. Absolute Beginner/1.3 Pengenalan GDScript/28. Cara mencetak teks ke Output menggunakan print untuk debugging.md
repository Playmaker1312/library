# 28. Cara mencetak teks ke Output menggunakan print untuk debugging

## Definisi Singkat
Fungsi `print()` digunakan untuk mencetak teks atau nilai variabel ke panel Output di Godot Editor. Ini adalah cara paling dasar untuk debugging dan memantau nilai variabel saat runtime.

## Analogi
`print()` seperti mencatat di buku catatan. Setiap kali kamu memanggil `print()`, kamu menulis sesuatu yang bisa kamu baca nanti untuk mengetahui apa yang terjadi di dalam program.

## Struktur Node (Scene Tree)
```
- Node
  - script.gd (menggunakan print untuk debugging)
  - Label (menampilkan teks ke layar)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var nyawa := 100
var level := 5
var nama := "Player"

func _ready():
    print("=== DEBUG START ===")
    print("Nama pemain: " + nama)
    print("Level: " + str(level))
    print("Nyawa: " + str(nyawa))
    
    var data := {"hp": nyawa, "lv": level}
    print("Data: ", data)
    
    print("=== DEBUG END ===")

func _process(delta):
    if Input.is_action_just_pressed("ui_accept"):
        nyawa -= 10
        print("Nyawa berkurang! Sisa: " + str(nyawa))
        
        if nyawa <= 0:
            print("GAME OVER!")
            get_tree().reload_current_scene()
```

## Kasus Penggunaan Nyata
`print()` digunakan untuk melacak nilai variabel saat debugging seperti mengecek apakah fungsi dipanggil, memantau perubahan nyawa atau skor, mengetahui urutan event, atau memverifikasi data yang masuk dari sistem lain.
