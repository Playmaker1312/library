# 22. Operator perbandingan yaitu sama dengan, tidak sama dengan, lebih besar, dan lebih kecil

## Definisi Singkat
Operator perbandingan digunakan untuk membandingkan dua nilai dan menghasilkan nilai boolean (`true` atau `false`). Operator yang tersedia termasuk sama dengan (`==`), tidak sama dengan (`!=`), lebih besar (`>`), lebih kecil (`<`), lebih besar atau sama dengan (`>=`), dan lebih kecil atau sama dengan (`<=`).

## Analogi
Bayangkan kamu sedang membandingkan skor dengan teman. `==` seperti bertanya "apakah skorku sama dengan skormu?". `!=` seperti bertanya "apakah skorku berbeda dengan skormu?". `>` seperti bertanya "apakah skorku lebih tinggi?". `<` seperti bertanya "apakah skorku lebih rendah?".

## Struktur Node (Scene Tree)
```
- Node
  - Label (menampilkan hasil perbandingan)
  - Timer (untuk kondisi waktu)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var nyawa := 75
var nyawa_maks := 100
var level := 10
var target_level := 20

func _ready():
    var is_full := nyawa == nyawa_maks
    var is_different := nyawa != nyawa_maks
    var is_enough := nyawa > 50
    var is_low := nyawa < 30
    var is_max_level := level >= target_level
    var is_under_level := level <= target_level
    
    print("Full HP: " + str(is_full))
    print("Different: " + str(is_different))
    print("Enough HP: " + str(is_enough))
    print("Low HP: " + str(is_low))
    print("Max level: " + str(is_max_level))
    print("Under level: " + str(is_under_level))
```

## Kasus Penggunaan Nyata
Operator perbandingan digunakan untuk menentukan kondisi dalam game seperti mengecek apakah nyawa habis, apakah pemain mencapai level tertentu, apakah musuh sudah dikalahkan, atau apakah waktu permainan sudah habis.
