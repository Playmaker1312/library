# 18. Struktur dasar file GDScript yaitu extends, variabel, dan fungsi

## Definisi Singkat
Setiap file GDScript memiliki struktur dasar yang terdiri dari kata kunci `extends` untuk menentukan jenis node, deklarasi variabel untuk menyimpan data, dan fungsi untuk menjalankan blok kode tertentu.

## Analogi
Bayangkan sebuah resep masakan. `extends` seperti judul resep yang menentukan jenis masakan apa yang akan dibuat. Variabel seperti bahan-bahan yang dibutuhkan. Fungsi seperti langkah-langkah instruksi yang harus diikuti.

## Struktur Node (Scene Tree)
```
- CharacterBody2D
  - Sprite2D
  - CollisionShape2D
  - script.gd (menempel pada CharacterBody2D)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

var nama_pemain := "Hero"
var nyawa := 100
var kecepatan := 150.0

func _ready():
    mulai_game()

func _process(delta):
    gerak(delta)

func mulai_game():
    print("Selamat datang, " + nama_pemain)

func gerak(delta):
    var direction := Input.get_axis("ui_left", "ui_right")
    velocity.x = direction * kecepatan
    move_and_slide()
```

## Kasus Penggunaan Nyata
Struktur dasar ini digunakan di setiap script dalam game. Misalnya untuk karakter pemain yang perlu memiliki properti seperti nyawa dan kecepatan, serta fungsi untuk bergerak dan memulai permainan.
