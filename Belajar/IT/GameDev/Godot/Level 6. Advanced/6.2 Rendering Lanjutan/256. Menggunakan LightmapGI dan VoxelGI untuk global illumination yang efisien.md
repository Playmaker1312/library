# 256. Menggunakan LightmapGI dan VoxelGI untuk global illumination yang efisien

## Definisi Singkat
LightmapGI menggunakan tekstur lightmap yang sudah di-bake untuk menampilkan pencahayaan global statis, sedangkan VoxelGI menggunakan voxels untuk menampilkan pencahayaan global real-time.

## Analogi
LightmapGI seperti foto pencahayaan ruangan yang dicetak di dinding, pencahayaannya bagus tapi tidak berubah. VoxelGI seperti lampu pintar yang bereaksi terhadap perubahan posisi benda di dalam ruangan.

## Struktur Node (Scene Tree)
```
Root
├── WorldEnvironment
│   └── Environment (ssil_enabled, ssao_enabled)
├── DirectionalLight3D
├── LightmapGI (bake_lightmap)
│   └── LightmapProbe (opsional)
├── VoxelGI
│   └── VoxelGIVolume (data baked)
├── MeshInstance3D (dynamic objects, gi_mode = GI_MODE_DYNAMIC)
└── StaticBody3D (static objects, baked to lightmap)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@onready var lightmap_gi = $LightmapGI
@onready var voxel_gi = $VoxelGI

func _ready():
    if lightmap_gi:
        print("Lightmap baked: ", lightmap_gi.lightmap_state == LightmapGI.LIGHTMAP_STATE_BAKED)
        print("Lightmap quality: ", lightmap_gi.quality)
        print("Bake subdivisions: ", lightmap_gi.bake_subdivisions)
    if voxel_gi:
        print("Voxel data exists: ", voxel_gi.voxel_data != null)
        print("Extents: ", voxel_gi.extents)

func bake_lightmap():
    if lightmap_gi:
        lightmap_gi.bake()
        print("Lightmap baking started")

func bake_voxel_gi():
    if voxel_gi:
        voxel_gi.bake()
        print("VoxelGI baking started")

func _input(event):
    if event.is_action_pressed("ui_accept"):
        bake_lightmap()
    if event.is_action_pressed("ui_cancel"):
        bake_voxel_gi()
```

## Kasus Penggunaan Nyata
LightmapGI digunakan pada game level statis seperti game horror atau puzzle yang pencahayaannya tidak berubah untuk performa maksimal. VoxelGI digunakan pada game aksi dinamis yang membutuhkan refleksi pencahayaan nyata seperti game室内 interior dengan pintu yang dibuka/ditutup.
