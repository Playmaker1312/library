# 254. Memahami Rendering Pipeline Godot 4 yaitu Forward Plus Mobile dan Compatibility

## Definisi Singkat
Forward Plus, Mobile, dan Compatibility adalah tiga rendering pipeline di Godot 4 yang dioptimalkan untuk perangkat berbeda: desktop high-end, mobile, dan hardware lawas.

## Analogi
Seperti tiga jenis mesin mobil: Forward Plus adalah mesin V12 bertenaga penuh untuk gaming PC, Mobile adalah mesin hybrid untuk ponsel, dan Compatibility adalah mesin hemat bensin untuk mobil tua yang masih bisa jalan.

## Struktur Node (Scene Tree)
```
Root
├── WorldEnvironment
│   ├── Environment (background, ambient_light, tonemap)
│   └── Camera3D
├── DirectionalLight3D
├── MeshInstance3D (objek utama)
└── SubViewportContainer → SubViewport (untuk rendering terpisah)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

func _ready():
    var viewport = get_viewport()
    match RenderingServer.get_rendering_method():
        "forward_plus":
            print("Desktop high-end renderer")
            viewport.msaa_3d = Viewport.MSAA_4X
            viewport.screen_space_aa = Viewport.SCREEN_SPACE_AA_FXAA
        "mobile":
            print("Mobile optimized renderer")
            viewport.msaa_3d = Viewport.MSAA_2X
            viewport.screen_space_aa = Viewport.SCREEN_SPACE_AA_DISABLED
        "gl_compatibility":
            print("Compatibility fallback renderer")
            viewport.msaa_3d = Viewport.MSAA_DISABLED
            viewport.screen_space_aa = Viewport.SCREEN_SPACE_AA_DISABLED

func _input(event):
    if event.is_action_pressed("ui_accept"):
        var env = get_node("WorldEnvironment/Environment") as Environment
        if env:
            print("Tonemap mode: ", env.tonemap_mode)
            print("SSAO enabled: ", env.ssao_enabled)
            print("Glow enabled: ", env.glow_enabled)
```

## Kasus Penggunaan Nyata
Forward Plus digunakan untuk game PC dengan grafis tinggi seperti game first-person shooter. Mobile pipeline digunakan untuk game mobile agar tetap lancar di hardware terbatas. Compatibility digunakan untuk game web export atau perangkat dengan GPU lawas yang tidak mendukung Vulkan.
