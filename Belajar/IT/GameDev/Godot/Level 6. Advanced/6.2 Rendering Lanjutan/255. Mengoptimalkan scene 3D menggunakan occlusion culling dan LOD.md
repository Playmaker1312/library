# 255. Mengoptimalkan scene 3D menggunakan occlusion culling dan LOD

## Definisi Singkat
Occlusion culling menyembunyikan objek yang tertutup objek lain, dan LOD (Level of Detail) mengganti model kompleks dengan versi sederhana dari jarak jauh.

## Analogi
OC seperti menutup buku yang tidak terbaca agar tidak menghabiskan tempat. LOD seperti melihat orang dari kejauhan hanya terlihat silhouette, dari dekat terlihat detail wajah.

## Struktur Node (Scene Tree)
```
Root
├── WorldEnvironment
├── Player
├── OccluderInstance3D (occluder buatan)
├── Level
│   ├── Building_LOD0 (mesh detail penuh)
│   ├── Building_LOD1 (mesh sedang)
│   └── Building_LOD2 (mesh sederhana)
└── StaticBody3D dengan Occluder3D (auto occluder)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@export var lod_distances: Array[float] = [10.0, 25.0, 50.0]
@onready var lod_nodes: Array[MeshInstance3D] = []
var player: Node3D = null

func _ready():
    for child in get_children():
        if child is MeshInstance3D:
            lod_nodes.append(child)
    player = get_tree().get_first_node_in_group("player")
    if lod_nodes.size() > 0:
        _set_lod(0)

func _process(_delta):
    if player == null or lod_nodes.size() == 0:
        return
    var distance = global_position.distance_to(player.global_position)
    var active_lod = 0
    for i in range(lod_distances.size()):
        if distance >= lod_distances[i]:
            active_lod = i + 1
    active_lod = min(active_lod, lod_nodes.size() - 1)
    _set_lod(active_lod)

func _set_lod(index: int):
    for i in range(lod_nodes.size()):
        lod_nodes[i].visible = (i == index)
```

## Kasus Penggunaan Nyata
Occlusion culling digunakan dalam game open-world untuk menyembunyikan objek di balik gedung atau bukit, sehingga GPU tidak perlu merender yang tidak terlihat. LOD digunakan pada game dengan banyak objek jarak jauh seperti pohon atau karakter NPC untuk menjaga frame rate tetap stabil.
