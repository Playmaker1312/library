# 258. Menggunakan Decal untuk proyeksi tekstur pada permukaan 3D

## Definisi Singkat
Decal adalah node yang memproyeksikan tekstur ke permukaan objek 3D di sekitarnya tanpa mengubah mesh asli, seperti stiker digital yang ditempelkan pada benda.

## Analogi
Decal seperti proyktor film yang memproyeksikan gambar ke dinding, gambar menempel di permukaan dinding tapi tidak mengubah bentuk dinding itu sendiri.

## Struktur Node (Scene Tree)
```
Root
├── Camera3D
├── DirectionalLight3D
├── MeshInstance3D (terrain atau dinding)
├── Decal3D (decal projeksi)
│   └── Texture: albedo, normal, metallic, roughness
├── GPUParticles3D (efek debu, menggunakan decal material)
└── RemoteTransform3D (menggerakkan decal)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@onready var decal: Decal = $Decal3D
@export var decal_texture: Texture2D
@export var projection_size: Vector3 = Vector3(2.0, 2.0, 2.0)
@export var decal_lifetime: float = 3.0

func _ready():
    if decal and decal_texture:
        decal.albedo_texture = decal_texture
        decal.size = projection_size
        decal.cull_mask = 1
        decal.normal_fade = 0.5
        print("Decal initialized with size: ", decal.size)

func spawn_decal(position: Vector3, normal: Vector3):
    var new_decal = Decal.new()
    new_decal.albedo_texture = decal_texture
    new_decal.size = projection_size
    new_decal.cull_mask = 1
    new_decal.normal_fade = 0.5
    new_decal.global_position = position
    new_decal.look_at(position + normal, Vector3.UP)
    get_tree().current_scene.add_child(new_decal)
    var timer = get_tree().create_timer(decal_lifetime)
    timer.timeout.connect(new_decal.queue_free)

func move_decal_to_mouse(event: InputEvent):
    if event is InputEventMouseMotion:
        var cam = get_viewport().get_camera_3d()
        if cam:
            var ray_origin = cam.global_position
            var ray_dir = cam.project_ray_normal(event.position)
            var space_state = get_world_3d().direct_space_state
            var query = PhysicsRayQueryParameters3D.create(ray_origin, ray_origin + ray_dir * 100)
            var result = space_state.intersect_ray(query)
            if result:
                decal.global_position = result.position + result.normal * 0.1
                decal.look_at(result.position + result.normal, Vector3.UP)
```

## Kasus Penggunaan Nyata
Decal digunakan untuk menambahkan detail visual seperti noda darah, coretan grafiti, bekas ledakan, atau jejak kaki tanpa menambah mesh baru. Sangat berguna pada game FPS atau game action untuk efek visual yang dinamis dan ringan di performa.
