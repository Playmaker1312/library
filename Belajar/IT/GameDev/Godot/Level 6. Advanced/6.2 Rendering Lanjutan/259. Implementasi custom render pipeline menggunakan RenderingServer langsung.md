# 259. Implementasi custom render pipeline menggunakan RenderingServer langsung

## Definisi Singkat
RenderingServer adalah API-level singleton di Godot yang memungkinkan kontrol langsung terhadap rendering tanpa menggunakan node konvensional, memungkinkan custom pipeline dan optimasi mendalam.

## Analogi
RenderingServer seperti mesin mobil yang kamu bongkar sendiri, kamu bisa ganti komponen satu-sesuai keinginanmu tanpa terikat desain pabrik.

## Struktur Node (Scene Tree)
```
Root
├── Node3D (script mengontrol RenderingServer)
├── MeshInstance3D (manual mesh rendering)
├── Viewport (off-screen rendering)
└── SubViewportContainer (render texture display)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

var mesh_rid: RID
var material_rid: RID
var instance_rid: RID
var light_rid: RID

func _ready():
    mesh_rid = RenderingServer.mesh_create()
    var box = BoxMesh.new()
    box.size = Vector3(2, 2, 2)
    RenderingServer.mesh_set表面(mesh_rid, box.get_surface_override_material(0).get_rid() if box.get_surface_override_material(0) else Material.new().get_rid())

    material_rid = RenderingServer.material_create()
    var mat = StandardMaterial3D.new()
    mat.albedo_color = Color.CORNFLOWER_BLUE
    RenderingServer.material_set_shader(material_rid, mat.get_rid())

    instance_rid = RenderingServer.instance_create()
    RenderingServer.instance_set_base(instance_rid, mesh_rid)
    RenderingServer.instance_set_scenario(instance_rid, get_world_3d().scenario)
    RenderingServer.instance_set_transform(instance_rid, Transform3D(Basis.IDENTITY, Vector3.ZERO))

    light_rid = RenderingServer.directional_light_create()
    RenderingServer.instance_set_scenario(light_rid, get_world_3d().scenario)
    RenderingServer.instance_set_transform(light_rid, Transform3D(Basis.IDENTITY, Vector3(10, 20, 10)))

func _process(delta):
    var time = Time.get_ticks_msec() / 1000.0
    var transform = Transform3D(
        Basis(Vector3.UP, time * 0.5),
        Vector3(sin(time) * 3, 2, cos(time) * 3)
    )
    RenderingServer.instance_set_transform(instance_rid, transform)

func _exit_tree():
    RenderingServer.free_rid(mesh_rid)
    RenderingServer.free_rid(material_rid)
    RenderingServer.free_rid(instance_rid)
    RenderingServer.free_rid(light_rid)
```

## Kasus Penggunaan Nyata
RenderingServer digunakan oleh developer yang membangun custom game engine atau tool editor di Godot, seperti level editor 3D atau simulator khusus. Digunakan juga pada game yang membutuhkan rendering sangat spesifik seperti game strategi dengan ribuan unit atau game yang menggunakan compute shader untuk simulasi.
