# 260. Teknik batching dan instancing untuk rendering ribuan objek secara efisien

## Definisi Singkat
Batching menggabungkan beberapa objek menjadi satu draw call, dan instancing merender banyak salinan objek yang sama dalam satu draw call untuk mengurangi beban GPU.

## Analogi
Batching seperti mengirim 100 surat sekaligus dalam satu paket, instancing seperti mencetak 1000 foto dari satu template yang sama tanpa harus mendesain ulang masing-masing.

## Struktur Node (Scene Tree)
```
Root
├── MultiMeshInstance3D (ribuan objek instance)
├── MeshInstance3D (objek dasar untuk instancing)
├── GPUParticles3D (menggunakan instancing internal)
└── Node3D (batch controller script)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@export var instance_count: int = 1000
@export var spawn_range: float = 50.0
@onready var multimesh_instance: MultiMeshInstance3D = $MultiMeshInstance3D

func _ready():
    _setup_multimesh()

func _setup_multimesh():
    var multimesh = MultiMesh.new()
    multimesh.instance_count = instance_count
    multimesh.use_colors = true
    var mesh = BoxMesh.new()
    mesh.size = Vector3(0.5, 0.5, 0.5)
    multimesh.mesh = mesh
    multimesh.transform_format = MultiMesh.TRANSFORM_3D
    for i in range(instance_count):
        var position = Vector3(
            randf_range(-spawn_range, spawn_range),
            randf_range(0, spawn_range * 0.5),
            randf_range(-spawn_range, spawn_range)
        )
        var basis = Basis(Vector3(randf(), randf(), randf()).normalized(), randf() * TAU)
        multimesh.set_instance_transform(i, Transform3D(basis, position))
        multimesh.set_instance_color(i, Color(randf(), randf(), randf()))
    multimesh_instance.multimesh = multimesh
    print("Instanced ", instance_count, " objects")

func _process(delta):
    var time = Time.get_ticks_msec() / 1000.0
    var multimesh = multimesh_instance.multimesh
    for i in range(min(100, instance_count)):
        var transform = multimesh.get_instance_transform(i)
        transform.origin.y += sin(time + i) * delta * 0.5
        multimesh.set_instance_transform(i, transform)
```

## Kasus Penggunaan Nyata
Batching dan instancing digunakan pada game dengan banyak objek serupa seperti game strategi dengan ribuan unit, game simulasi kota dengan banyak bangunan, atau game particle-heavy seperti game dengan efek ledakan massal. Teknik ini memungkinkan render ribuan objek dengan satu draw call alih-alih ribuan draw call terpisah.
