# 257. Implementasi SDFGI yaitu Signed Distance Field Global Illumination untuk scene dinamis

## Definisi Singkat
SDFGI adalah teknik global illumination yang menggunakan signed distance field untuk menampilkan cahaya bounce real-time tanpa baking, mendukung scene yang sepenuhnya dinamis.

## Analogi
SDFGI seperti laser yang menembus cermin berkilau, cahaya memantul ke seluruh ruangan dan mengubah warna objek di sekitarnya tanpa harus menghitung setiap sudut secara manual.

## Struktur Node (Scene Tree)
```
Root
├── WorldEnvironment
│   └── Environment
│       ├── sdfgi_enabled = true
│       ├── sdfgi_use_occlusion = true
│       └── sdfgi_cascade0_distance = 128.0
├── DirectionalLight3D (sun_light)
├── WorldBoundaryShape3D (sdfgi bounds)
├── MeshInstance3D (dynamic objects)
└── StaticBody3D (static environment)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@onready var environment: Environment = $WorldEnvironment/Environment

func _ready():
    if environment:
        environment.sdfgi_enabled = true
        environment.sdfgi_use_occlusion = true
        environment.sdfgi_min_cell_size = 2.0
        environment.sdfgi_cascade0_distance = 128.0
        environment.sdfgi_lightprobe_intensity = 1.0
        environment.sdfgi_energy = 1.0
        print("SDFGI enabled with cascade distance: ", environment.sdfgi_cascade0_distance)

func _process(_delta):
    if environment and environment.sdfgi_enabled:
        var cam = get_viewport().get_camera_3d()
        if cam:
            environment.sdfgi_cascade0_distance = clamp(
                cam.global_position.distance_to(global_position) * 2.0,
                16.0, 256.0
            )

func toggle_sdfgi():
    if environment:
        environment.sdfgi_enabled = !environment.sdfgi_enabled
        print("SDFGI toggled: ", environment.sdfgi_enabled)

func _input(event):
    if event.is_action_pressed("ui_accept"):
        toggle_sdfgi()
```

## Kasus Penggunaan Nyata
SDFGI digunakan pada game open-world dinamis seperti game survival atau RPG yang memiliki perubahan waktu (siang-malam) dan cuaca. Cocok untuk game yang mengeksplorasi gua atau interior dengan pencahayaan berubah-ubah tanpa waktu bake yang lama.
