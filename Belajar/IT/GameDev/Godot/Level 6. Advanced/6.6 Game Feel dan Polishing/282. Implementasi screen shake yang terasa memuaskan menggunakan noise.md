# 282. Implementasi screen shake yang terasa memuaskan menggunakan noise

## Definisi Singkat
Screen shake adalah teknik yang menggeser posisi kamera secara acak untuk memberikan efek gempa pada layar, menciptakan rasa impact yang kuat pada saat-saat penting dalam game. Menggunakan noise function menghasilkan gerakan yang lebih natural dibandingkan gerakan acak murni.

## Analogi
Screen shake seperti gempa bumi mini yang terjadi pada saat-saat kritis. Seperti kamera dipegang oleh tangan yang gemetar saat ada ledakan besar - gerakannya tidak sepenuhnya acak, tapi mengikuti pola yang terasa organik dan realistis.

## Kode GDScript (Godot 4)
```gdscript
extends Camera2D

@export var shake_decay: float = 5.0
@export var shake_max_offset: float = 20.0
@export var shake_max_rotation: float = 0.5

var shake_intensity: float = 0.0
var shake_rotation: float = 0.0
var noise: FastNoiseLite

func _ready():
    noise = FastNoiseLite.new()
    noise.seed = randi()
    noise.noise_type = FastNoiseLite.TYPE_SIMPLEX_SMOOTH
    noise.frequency = 0.5

func add_shake(intensity: float):
    shake_intensity = min(shake_intensity + intensity, shake_max_offset)

func _process(delta):
    if shake_intensity > 0.01:
        var noise_x = noise.get_noise_1d(Time.get_ticks_msec() * 0.001)
        var noise_y = noise.get_noise_1d(Time.get_ticks_msec() * 0.001 + 100)
        
        offset.x = noise_x * shake_intensity
        offset.y = noise_y * shake_intensity
        
        rotation = noise.get_noise_1d(Time.get_ticks_msec() * 0.001 + 200) * deg_to_rad(shake_intensity * shake_max_rotation / shake_max_offset)
        
        shake_intensity = lerp(shake_intensity, 0.0, shake_decay * delta)
    else:
        offset = Vector2.ZERO
        rotation = 0.0
        shake_intensity = 0.0
```

## Kasus Penggunaan Nyata
Dalam game action seperti Doom Eternal, screen shake digunakan setiap kali senjata besar ditembak atau ledakan terjadi. Intensitas shake disesuaikan dengan kekuatan senjata - shotgun menghasilkan shake ringan, sedangkan BFG menghasilkan shake besar yang membuat seluruh layar bergetar kuat. Teknik noise membuat getaran terasa natural seperti gempa nyata.
