# 287. Teknik animasi squash and stretch untuk karakter yang ekspresif

## Definisi Singkat
Squash and stretch adalah prinsip animasi yang meregangkan dan memampatkan objek untuk memberikan kesan fleksibilitas, bobot, dan energi. Teknik ini membuat karakter terasa lebih hidup dan ekspresif dengan memanipulasi proporsi objek selama gerakan.

## Analogi
Bayangkan bola basket yang memantul - saat menyentuh tanah, bola tersebut menjadi pipih (squash), dan saat melompat ke atas, bola menjadi panjang (stretch). Prinsip yang sama diterapkan pada karakter game untuk memberikan kesan dinamis dan natural.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── Sprite2D
├── SquashStretchPivot (Node2D)
│   └── Sprite2D
├── AnimationPlayer
└── CollisionShape2D
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@export var squash_amount: float = 0.2
@export var stretch_amount: float = 0.3
@export var squash_speed: float = 10.0
@export var recovery_speed: float = 5.0

var target_scale: Vector2 = Vector2.ONE
var current_squash: float = 0.0

func _ready():
    target_scale = Vector2.ONE

func _physics_process(delta):
    var squash_x = 1.0 + current_squash * squash_amount
    var squash_y = 1.0 - current_squash * squash_amount
    
    $SquashStretchPivot.scale = Vector2(squash_x, squash_y).lerp(Vector2.ONE, recovery_speed * delta)
    
    current_squash = lerp(current_squash, 0.0, recovery_speed * delta)

func apply_squash(amount: float):
    current_squash = amount

func apply_stretch(direction: Vector2):
    var stretch_x = 1.0 + direction.x * stretch_amount
    var stretch_y = 1.0 + direction.y * stretch_amount
    $SquashStretchPivot.scale = Vector2(stretch_x, stretch_y)

func _on_jump():
    apply_stretch(Vector2(0, -1))

func _on_land():
    apply_squash(1.0)

func _on_dash(direction: Vector2):
    apply_stretch(direction.normalized())
```

## Kasus Penggunaan Nyata
Dalam game Rayman Legends, setiap gerakan karakter menggunakan squash and stretch secara ekstrem. Saat Rayman melompat, tubuhnya meregang vertikal. Saat mendarat, tubuhnya memampat horizontal. Saat berlari, tubuhnya meregang searah gerakan. Teknik ini membuat animasi terasa juicy dan menyenangkan tanpa memerlukan frame animasi yang rumit.
