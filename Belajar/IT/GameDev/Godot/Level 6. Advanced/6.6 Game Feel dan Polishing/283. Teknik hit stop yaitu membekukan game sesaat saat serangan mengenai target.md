# 283. Teknik hit stop yaitu membekukan game sesaat saat serangan mengenai target

## Definisi Singkat
Hit stop (atau hitlag) adalah teknik yang menghentikan waktu game sesaat saat serangan mengenai target, memberikan dampak visual yang kuat dan membiarkan pemain merasakan bobot dari setiap serangan. Teknik ini menciptakan momen dramatis sebelum aksi berlanjut.

## Analogi
Bayangkan seperti slow motion dalam film aksi saat pukulan terjadi. Hit stop adalah versi ekstremnya - bukan hanya memperlambat, tapi benar-benar membekukan segalanya sesaat, memberikan waktu bagi pemain untuk mengapresiasi dampak serangan mereka.

## Struktur Node (Scene Tree)
```
GameRoot (Node2D)
├── HitStopManager (Node)
│   └── Timer (Timer)
├── Player
├── Enemies
└── Projectiles
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var original_time_scale: float = 1.0
var is_frozen: bool = false

func _ready():
    process_mode = Node.PROCESS_MODE_ALWAYS

func apply_hit_stop(duration: float, time_scale: float = 0.05):
    if is_frozen:
        return
    
    is_frozen = true
    original_time_scale = Engine.time_scale
    Engine.time_scale = time_scale
    
    var timer = get_tree().create_timer(duration * time_scale)
    timer.timeout.connect(_on_hit_stop_end)

func _on_hit_stop_end():
    Engine.time_scale = original_time_scale
    is_frozen = false

func _exit_tree():
    Engine.time_scale = 1.0
```

## Kasus Penggunaan Nyata
Dalam game fighting seperti Street Fighter V, hit stop terjadi setiap kali serangan mengenai lawan. Durasi hit stop bervariasi - serangan ringan menghasilkan hit stop singkat (0.05 detik), sedangkan special move menghasilkan hit stop lebih lama (0.1 detik). Teknik ini memberikan waktu bagi kedua pemain untuk bereaksi dan membuat setiap serangan terasa berbobot.
