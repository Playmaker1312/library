# 284. Implementasi coyote time dan jump buffer untuk platformer yang responsif

## Definisi Singkat
Coyote time memberikanGrace period sesaat setelah karakter berjalan dari tepi platform sebelum jatuh, sementara jump buffer memungkinkan input lompatan yang terlambat tetap terdaftar jika mendarat dalam waktu singkat. Kedua teknik ini membuat kontrol platformer terasa lebih responsif dan adil.

## Analogi
Coyote time seperti berjalan di tepi tebing - ada sedikit toleransi sebelum benar-benar jatuh. Jump buffer seperti menekan tombol lift sedikit sebelum pintu terbuka - sistem tetap mendaftar input Anda meskipun waktunya belum tepat.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
├── CoyoteTimer (Timer)
├── JumpBufferTimer (Timer)
└── AnimationPlayer
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@export var speed: float = 300.0
@export var jump_velocity: float = -400.0
@export var coyote_time: float = 0.1
@export var jump_buffer_time: float = 0.15

var gravity: float = ProjectSettings.get_setting("physics/2d/default_gravity")
var was_on_floor: bool = false
var coyote_timer: float = 0.0
var jump_buffer_timer: float = 0.0

func _physics_process(delta):
    if not is_on_floor():
        velocity.y += gravity * delta
    
    if is_on_floor():
        was_on_floor = true
        coyote_timer = coyote_time
    elif was_on_floor:
        coyote_timer -= delta
        if coyote_timer <= 0:
            was_on_floor = false
    
    if Input.is_action_just_pressed("jump"):
        jump_buffer_timer = jump_buffer_time
    else:
        jump_buffer_timer -= delta
    
    if jump_buffer_timer > 0 and coyote_timer > 0:
        velocity.y = jump_velocity
        coyote_timer = 0
        jump_buffer_timer = 0
    
    var direction = Input.get_axis("move_left", "move_right")
    if direction:
        velocity.x = direction * speed
    else:
        velocity.x = move_toward(velocity.x, 0, speed)
    
    move_and_slide()
```

## Kasus Penggunaan Nyata
Dalam game seperti Hollow Knight, coyote time dan jump buffer sangat penting untuk membuat kontrol karakter terasa presisi. Pemain bisa melompat sesaat setelah berjalan dari platform (coyote time), atau menekan tombol lompat sedikit sebelum mendarat (jump buffer). Tanpa teknik ini, banyak momen lompatan yang seharusnya berhasil justru gagal karena timing yang terlalu ketat.
