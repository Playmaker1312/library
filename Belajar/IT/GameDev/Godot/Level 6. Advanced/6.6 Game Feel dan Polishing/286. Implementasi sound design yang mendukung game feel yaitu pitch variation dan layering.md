# 286. Implementasi sound design yang mendukung game feel yaitu pitch variation dan layering

## Definisi Singkat
Pitch variation adalah teknik mengubah frekuensi suara secara acak untuk menghindari repetisi, sedangkan layering adalah menggabungkan beberapa elemen suara bersamaan untuk menciptakan kedalaman dan kompleksitas audio. Kombinasi keduanya membuat sound design terasa lebih hidup dan dinamis.

## Analogi
Bayangkan suara hujan - bukan hanya satu suara "shhh" yang monoton, tapi kombinasi tetesan besar, tetesan kecil, dan suara angin. Setiap tetesan juga memiliki variasi pitch yang berbeda. Itulah yang dilakukan layering dan pitch variation - menciptakan simfoni dari elemen-elemen sederhana.

## Struktur Node (Scene Tree)
```
SoundManager (Node)
├── SFXPool (Node)
│   ├── SFX1 (AudioStreamPlayer2D)
│   ├── SFX2 (AudioStreamPlayer2D)
│   └── SFX3 (AudioStreamPlayer2D)
├── MusicPlayer (AudioStreamPlayer)
└── AmbientPlayer (AudioStreamPlayer2D)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

@export var sfx_pool_size: int = 8
@export var pitch_variation_range: Vector2 = Vector2(0.9, 1.1)

var sfx_pool: Array[AudioStreamPlayer2D] = []
var current_index: int = 0

func _ready():
    for i in range(sfx_pool_size):
        var player = AudioStreamPlayer2D.new()
        add_child(player)
        sfx_pool.append(player)

func play_sfx(stream: AudioStream, position: Vector2 = Vector2.ZERO, volume_db: float = 0.0):
    var player = sfx_pool[current_index]
    player.stream = stream
    player.volume_db = volume_db
    player.pitch_scale = randf_range(pitch_variation_range.x, pitch_variation_range.y)
    player.global_position = position
    player.play()
    
    current_index = (current_index + 1) % sfx_pool_size

func play_layered_sfx(streams: Array[AudioStream], position: Vector2 = Vector2.ZERO):
    for stream in streams:
        play_sfx(stream, position)

func play_sfx_with_random_pitch(stream: AudioStream, position: Vector2, min_pitch: float, max_pitch: float):
    var player = sfx_pool[current_index]
    player.stream = stream
    player.global_position = position
    player.pitch_scale = randf_range(min_pitch, max_pitch)
    player.play()
    
    current_index = (current_index + 1) % sfx_pool_size
```

## Kasus Penggunaan Nyata
Dalam game seperti Hades, setiap serangan memiliki beberapa layer suara - suara weapon swing, impact, dan efek elemental. Pitch variation membuat setiap hit terdengar unik meskipun menggunakan file suara yang sama. Saat pemain menggunakan pedang 50 kali berturut-turut, setiap hit tetap terasa segar berkat variasi pitch dan layering yang baik.
