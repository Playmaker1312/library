# 288. Implementasi camera techniques lanjutan seperti zoom on impact dan cinematic bars

## Definisi Singkat
Zoom on impact adalah teknik yang memperbesar kamera sesaat saat serangan mengenai target untuk memberikan fokus dan dampak, sedangkan cinematic bars menambahkan bar hitam di atas dan bawah layar untuk menciptakan tampilan sinematik dan dramatis. Kombinasi keduanya meningkatkan presentasi visual secara signifikan.

## Analogi
Zoom on impact seperti kamera yang mendekat saat adegan penting dalam film - memaksa penonton fokus pada momen krusial. Cinematic bars seperti frame pada lukisan - memberikan batasan yang membuat komposisi terasa lebih terarah dan profesional.

## Struktur Node (Scene Tree)
```
Camera2D
├── ZoomController (Node)
├── CinematicBars (CanvasLayer)
│   ├── TopBar (ColorRect)
│   └── BottomBar (ColorRect)
└── ScreenShakeManager (Node)
```

## Kode GDScript (Godot 4)
```gdscript
extends Camera2D

@export var default_zoom: Vector2 = Vector2.ONE
@export var zoom_speed: float = 10.0
@export var zoom_on_impact_scale: Vector2 = Vector2(1.2, 1.2)
@export var zoom_on_impact_duration: float = 0.2
@export var cinematic_bar_height: float = 80.0
@export var cinematic_transition_speed: float = 5.0

var target_zoom: Vector2 = Vector2.ONE
var cinematic_bars_visible: bool = false
var top_bar: ColorRect
var bottom_bar: ColorRect

func _ready():
    top_bar = ColorRect.new()
    top_bar.color = Color.BLACK
    top_bar.size = Vector2(get_viewport_rect().size.x, cinematic_bar_height)
    top_bar.position = Vector2(0, -cinematic_bar_height)
    
    bottom_bar = ColorRect.new()
    bottom_bar.color = Color.BLACK
    bottom_bar.size = Vector2(get_viewport_rect().size.x, cinematic_bar_height)
    bottom_bar.position = Vector2(0, get_viewport_rect().size.y)
    
    var canvas = CanvasLayer.new()
    canvas.name = "CinematicCanvas"
    add_child(canvas)
    canvas.add_child(top_bar)
    canvas.add_child(bottom_bar)

func _process(delta):
    zoom = zoom.lerp(target_zoom, zoom_speed * delta)
    
    if cinematic_bars_visible:
        top_bar.position.y = lerp(top_bar.position.y, 0.0, cinematic_transition_speed * delta)
        bottom_bar.position.y = lerp(bottom_bar.position.y, get_viewport_rect().size.y - cinematic_bar_height, cinematic_transition_speed * delta)
    else:
        top_bar.position.y = lerp(top_bar.position.y, -cinematic_bar_height, cinematic_transition_speed * delta)
        bottom_bar.position.y = lerp(bottom_bar.position.y, get_viewport_rect().size.y, cinematic_transition_speed * delta)

func zoom_on_impact():
    target_zoom = zoom_on_impact_scale
    var timer = get_tree().create_timer(zoom_on_impact_duration)
    timer.timeout.connect(func(): target_zoom = default_zoom)

func set_cinematic_bars(visible: bool):
    cinematic_bars_visible = visible

func flash_zoom(scale: Vector2, duration: float):
    target_zoom = scale
    var timer = get_tree().create_timer(duration)
    timer.timeout.connect(func(): target_zoom = default_zoom)
```

## Kasus Penggunaan Nyata
Dalam game seperti Devil May Cry 5, zoom on impact terjadi setiap kali combo mengenai musuh dengan kamera mendekat secara dramatis. Cinematic bars muncul saat cutscene atau boss intro untuk menciptakan pengalaman sinematik. Teknik ini mengubah momen gameplay biasa menjadi adegan yang terasa seperti film blockbuster, meningkatkan kepuasan visual pemain secara signifikan.
