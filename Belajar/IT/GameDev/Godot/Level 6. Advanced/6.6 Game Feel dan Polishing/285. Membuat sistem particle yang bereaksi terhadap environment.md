# 285. Membuat sistem particle yang bereaksi terhadap environment

## Definisi Singkat
Sistem particle yang reaktif adalah partikel yang berubah perilaku berdasarkan kondisi environment seperti gravitasi, angin, atau material permukaan. Partikel menjadi lebih realistis dan immersive ketika merespons dunia di sekitarnya.

## Analogi
Bayangkan daun jatuh dari pohon - daun tersebut tidak jatuh lurus ke bawah, tapi bergerak mengikuti angin, memantul saat menyentuh tanah, dan berputar mengikuti aliran udara. Particle yang reaktif bekerja seperti ini, merespons setiap kondisi dalam environment.

## Struktur Node (Scene Tree)
```
EnvironmentParticleManager (Node2D)
├── DustParticles (GPUParticles2D)
├── WaterParticles (GPUParticles2D)
├── LeafParticles (GPUParticles2D)
└── WindZone (Area2D)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@export var wind_strength: float = 0.0
@export var wind_direction: Vector2 = Vector2.RIGHT

var particles: Array[GPUParticles2D] = []

func _ready():
    for child in get_children():
        if child is GPUParticles2D:
            particles.append(child)

func _process(delta):
    var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")
    
    for particle in particles:
        if particle.emitting:
            var mat = particle.process_material
            if mat is ParticleProcessMaterial:
                mat.gravity = Vector3(
                    wind_direction.x * wind_strength,
                    gravity + wind_direction.y * wind_strength,
                    0
                )

func apply_wind(strength: float, direction: Vector2):
    wind_strength = strength
    wind_direction = direction.normalized()

func spawn_particles_at(position: Vector2, particle_type: String):
    var particle = GPUParticles2D.new()
    particle.global_position = position
    
    match particle_type:
        "dust":
            particle.texture = preload("res://particles/dust.png")
            particle.amount = 8
            particle.lifetime = 0.5
        "water":
            particle.texture = preload("res://particles/water_drop.png")
            particle.amount = 12
            particle.lifetime = 0.8
        "leaf":
            particle.texture = preload("res://particles/leaf.png")
            particle.amount = 5
            particle.lifetime = 2.0
    
    add_child(particle)
    particle.emitting = true
```

## Kasus Penggunaan Nyata
Dalam game seperti Ori and the Blind Forest, partikel bereaksi terhadap gerakan pemain, angin, dan air. Saat pemain berlari, debu beterbangan mengikuti arah gerakan. Saat angin bertiup, daun-daun berterbangan secara natural. Partikel air memercik saat karakter berinteraksi dengan air, menciptakan dunia yang hidup dan responsif.
