# 266. Teknik streaming level untuk open world yang besar

## Definisi Singkat
Level streaming adalah teknik membagi dunia game menjadi chunk atau zona yang di-load dan unload secara dinamis berdasarkan posisi player, sehingga hanya area di sekitar player yang aktif di memory pada satu waktu, memungkinkan dunia tanpa loading screen yang luas.

## Analogi
Bayangkan membaca buku tebal. Daripada membuka seluruh halaman sekaligus, Anda hanya melihat halaman yang sedang dibaca. Saat berpindah ke bab berikutnya, halaman sebelumnya ditutup dan halaman baru dibuka. Level streaming bekerja sama, memuat hanya "halaman" dunia game yang sedang dilihat player.

## Struktur Node (Scene Tree)
```
WorldManager (Node)
├── Player (CharacterBody2D)
├── StreamedChunks (Node2D)
│   ├── Chunk_0_0 (Node2D)
│   ├── Chunk_1_0 (Node2D)
│   └── Chunk_0_1 (Node2D)
└── ChunkLoader (Node)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@export var chunk_size: int = 256
@export var load_radius: int = 2
@export var unload_radius: int = 3

var loaded_chunks: Dictionary = {}
var chunk_scenes: Dictionary = {}
var player_chunk_pos: Vector2i = Vector2i.ZERO

func _ready():
    chunk_scenes["forest"] = preload("res://chunks/forest.tscn")
    chunk_scenes["city"] = preload("res://chunks/city.tscn")
    chunk_scenes["desert"] = preload("res://chunks/desert.tscn")

func _process(_delta):
    var player_pos = $Player.global_position
    var current_chunk = Vector2i(
        int(floor(player_pos.x / chunk_size)),
        int(floor(player_pos.y / chunk_size))
    )
    if current_chunk != player_chunk_pos:
        player_chunk_pos = current_chunk
        update_streamed_chunks()

func update_streamed_chunks():
    for x in range(player_chunk_pos.x - load_radius, player_chunk_pos.x + load_radius + 1):
        for y in range(player_chunk_pos.y - load_radius, player_chunk_pos.y + load_radius + 1):
            var chunk_key = "%d_%d" % [x, y]
            if not loaded_chunks.has(chunk_key):
                load_chunk(x, y, chunk_key)
    var chunks_to_unload = []
    for chunk_key in loaded_chunks:
        var parts = chunk_key.split("_")
        var cx = int(parts[0])
        var cy = int(parts[1])
        var distance = max(abs(cx - player_chunk_pos.x), abs(cy - player_chunk_pos.y))
        if distance > unload_radius:
            chunks_to_unload.append(chunk_key)
    for chunk_key in chunks_to_unload:
        unload_chunk(chunk_key)

func load_chunk(x: int, y: int, chunk_key: String):
    var chunk_type = get_chunk_type(x, y)
    if chunk_scenes.has(chunk_type):
        var chunk = chunk_scenes[chunk_type].instantiate()
        chunk.position = Vector2(x * chunk_size, y * chunk_size)
        $StreamedChunks.add_child(chunk)
        loaded_chunks[chunk_key] = chunk

func unload_chunk(chunk_key: String):
    if loaded_chunks.has(chunk_key):
        var chunk = loaded_chunks[chunk_key]
        chunk.queue_free()
        loaded_chunks.erase(chunk_key)

func get_chunk_type(x: int, y: int) -> String:
    var noise_value = sin(x * 0.5) * cos(y * 0.5)
    if noise_value > 0.3:
        return "city"
    elif noise_value < -0.3:
        return "desert"
    return "forest"
```

## Kasus Penggunaan Nyata
Game open world RPG dengan peta 16x16 km menggunakan level streaming untuk memuat area dalam radius 512m di sekitar player. Setiap chunk berisi 256x256m terrain dengan properti dan NPC. Tekni ini mengurangi memory usage dari 8GB (seluruh peta) menjadi 256MB (hanya area aktif), memungkinkan game berjalan smooth pada perangkat dengan RAM terbatas tanpa loading screen saat berpindah area.
