# 267. Profiling dan optimasi shader untuk mengurangi GPU overhead

## Definisi Singkat
Profiling shader melibatkan analisis kompleksitas fragment dan vertex shader menggunakan tools seperti RenderDoc atau Godot's built-in monitoring untuk mengidentifikasi instruksi yang mahal, texture fetch berlebihan, atau branching kompleks yang menyebabkan GPU bottleneck dan frame drops.

## Analogi
Bayangkan sebuah pabrik dengan jalur perakitan. GPU seperti mesin-mesin di pabrik tersebut. Jika satu mesin (shader) terlalu lambat atau melakukan terlalu banyak operasi, seluruh jalur perakitan menjadi lambat. Profiling shader seperti mengidentifikasi mesin mana yang menjadi bottleneck dan mengoptimasi prosesnya agar produksi berjalan lancar.

## Struktur Node (Scene Tree)

## Kode GDScript (Godot 4)
```gdscript
extends Node3D

@export var water_mesh: MeshInstance3D
@export var shader_stats_label: Label
var current_shader_complexity: int = 0

func _ready():
    if water_mesh and water_mesh.get_surface_override_material(0):
        var mat = water_mesh.get_surface_override_material(0)
        if mat is ShaderMaterial:
            analyze_shader(mat)

func analyze_shader(material: ShaderMaterial):
    var shader = material.shader
    if shader:
        var code = shader.code
        var complexity = calculate_complexity(code)
        current_shader_complexity = complexity
        if shader_stats_label:
            shader_stats_label.text = "Shader Complexity: %d instructions" % complexity

func calculate_complexity(code: String) -> int:
    var complexity = 0
    var lines = code.split("\n")
    for line in lines:
        if "texture(" in line:
            complexity += 10
        elif "if " in line or "else" in line:
            complexity += 5
        elif "for " in line or "while " in line:
            complexity += 15
        elif "sin(" in line or "cos(" in line or "tan(" in line:
            complexity += 3
        elif "normalize(" in line or "length(" in line:
            complexity += 2
        else:
            complexity += 1
    return complexity

func optimize_water_shader():
    if water_mesh and water_mesh.get_surface_override_material(0):
        var mat = water_mesh.get_surface_override_material(0) as ShaderMaterial
        if mat:
            var optimized_code = """
shader_type spatial;
render_mode blend_mix, depth_draw_opaque, cull_back;

uniform vec4 water_color : source_color = vec4(0.0, 0.3, 0.6, 0.8);
uniform float wave_speed = 0.5;
uniform float wave_height = 0.1;
uniform sampler2D wave_noise : filter_linear, repeat_disable;

void fragment() {
    vec2 uv = UV * 2.0 + TIME * wave_speed;
    float wave = texture(wave_noise, uv * 0.1).r;
    wave = wave * wave_height;
    ALBEDO = water_color.rgb;
    ALPHA = water_color.a;
    NORMAL = vec3(wave * 0.1, 1.0, wave * 0.1);
}
"""
            var new_shader = Shader.new()
            new_shader.code = optimized_code
            mat.shader = new_shader
            analyze_shader(mat)

func get_gpu_usage() -> Dictionary:
    var rendering_server = RenderingServer
    return {
        "draw_calls": Performance.get_monitor(Performance.RENDER_TOTAL_DRAW_CALLS_IN_FRAME),
        "vertices": Performance.get_monitor(Performance.RENDER_TOTAL_VERTICES_IN_FRAME),
        "objects": Performance.get_monitor(Performance.RENDER_TOTAL_OBJECTS_IN_FRAME)
    }
```

## Kasus Penggunaan Nyata
Game RPG dengan air dan vegetasi yang kompleks mengalami frame drops pada GPU integrated. Profiling mengungkap fragment shader air melakukan 8 texture fetches dan 3 trigonometric functions per pixel. Dengan mengganti ke noise texture procedural dan mengurangi branch statements, shader complexity berkurang 60%, memungkinkan frame rate naik dari 45fps ke稳定 60fps pada perangkat yang sama.
