# 265. Kapan dan bagaimana menggunakan GDExtension untuk kode performa kritis

## Definisi Singkat
GDExtension adalah sistem plugin Godot yang memungkinkan menulis kode dalam bahasa seperti C++, Rust, atau C# yang di-compile menjadi native code untuk performa 10-100x lebih cepat dari GDScript pada operasi matematika intensif, fisika custom, atau algoritma kompleks.

## Analogi
Bayangkan mengendarai sepeda (GDScript) vs mengendarai mobil sport (GDExtension). Untuk perjalanan pendek di kompleks perumahan, sepeda cukup efisien. Namun untuk perjalanan jarak jauh di jalan tol dengan kecepatan tinggi, mobil sport jauh lebih cepat dan efisien. GDExtension seperti mobil sport untuk kode yang membutuhkan performa maksimal.

## Struktur Node (Scene Tree)
```
Main (Node)
├── PhysicsSimulator (Node)
│   └── (GDExtension native node)
├── TerrainGenerator (Node)
│   └── (GDExtension native node)
└── Player (CharacterBody2D)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

@export var simulation_steps: int = 1000
@export var particle_count: int = 10000

var native_simulator = null
var is_simulating: bool = false

func _ready():
    if Engine.has_singleton("NativeSimulator"):
        native_simulator = Engine.get_singleton("NativeSimulator")
        print("Native simulator loaded")
    else:
        print("Fallback to GDScript implementation")

func run_simulation():
    if native_simulator:
        var positions = native_simulator.simulate_particles(particle_count, simulation_steps)
        apply_positions(positions)
    else:
        run_gdscript_fallback()

func run_gdscript_fallback():
    var positions = []
    for i in range(particle_count):
        var pos = Vector3.ZERO
        for step in range(simulation_steps):
            pos += Vector3(sin(step * 0.01), cos(step * 0.01), tan(step * 0.005)) * 0.1
        positions.append(pos)
    apply_positions(positions)

func apply_positions(positions: Array):
    for i in range(min(positions.size(), get_child_count())):
        get_child(i).position = positions[i]
```

## Kasus Penggunaan Nyata
Game simulator fisika cairan dengan jutaan partikel menggunakan GDExtension C++ untuk menjalankan Navier-Stokes solver real-time. Implementasi GDScript hanya mampu mengelola 10,000 partikel pada 30fps, sedangkan GDExtension mencapai 1,000,000 partikel pada 60fps. Game yang sebelumnya tidak playable menjadi smooth dan responsif dengan perpindahan ke native code.
