# 262. Menggunakan Thread dan WorkerThreadPool untuk komputasi paralel

## Definisi Singkat
Thread dalam Godot memungkinkan eksekusi kode secara asynchronous di luar main thread, sedangkan WorkerThreadPool menyediakan pool thread yang dapat digunakan untuk mendistribusikan tugas komputasi intensif secara paralel untuk memanfaatkan multiple CPU cores.

## Analogi
Bayangkan sebuah dapur dengan satu koki (main thread) yang harus memasak semua makanan sendirian. Dengan menambah koki lain (threads), beberapa makanan bisa dimasak bersamaan. WorkerThreadPool seperti manajer yang membagi tugas ke koki-koki yang tersedia secara efisien.

## Struktur Node (Scene Tree)
```
Main (Node)
├── ThreadPoolManager (Node)
├── World (Node2D)
│   ├── Player (CharacterBody2D)
│   └── ProceduralTerrain (Node2D)
└── UI (CanvasLayer)
    └── GenerateButton (Button)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var worker_pool: WorkerThreadPool
var terrain_mutex: Mutex
var is_generating: bool = false

func _ready():
    worker_pool = WorkerThreadPool.new()
    terrain_mutex = Mutex.new()

func generate_terrain_chunk(chunk_data: Dictionary):
    var noise = FastNoiseLite.new()
    noise.seed = chunk_data["seed"]
    noise.frequency = 0.01
    var width = chunk_data["width"]
    var height = chunk_data["height"]
    var offset_x = chunk_data["offset_x"]
    var offset_y = chunk_data["offset_y"]
    var height_map = []
    for x in range(width):
        var column = []
        for y in range(height):
            var value = noise.get_noise_2d(x + offset_x, y + offset_y)
            column.append(value)
        height_map.append(column)
    terrain_mutex.lock()
    emit_signal("chunk_generated", chunk_data["id"], height_map)
    terrain_mutex.unlock()

func generate_world_parallel(chunks: Array):
    if is_generating:
        return
    is_generating = true
    for chunk in chunks:
        worker_pool.add_task(Callable(self, "generate_terrain_chunk").bind(chunk))
    while worker_pool.get_completed_task_count() < chunks.size():
        await get_tree().process_frame
    worker_pool.wait_for_completion()
    is_generating = false

func _exit_tree():
    if worker_pool:
        worker_pool.free()
```

## Kasus Penggunaan Nyata
Game survival open world dengan terrain procedural yang luas menggunakan WorkerThreadPool untuk generate terrain chunk secara paralel saat player bergerak. Setiap chunk diproses di thread terpisah sehingga frame rate tetap stabil. Tanpa parallelisasi, stuttering terjadi setiap kali chunk baru di-generate karena memblokir main thread selama beberapa frame.
