# 263. Implementasi spatial partitioning menggunakan Octree atau QuadTree kustom

## Definisi Singkat
Spatial partitioning adalah teknik untuk membagi ruang game menjadi struktur hierarkis seperti QuadTree (2D) atau Octree (3D) sehingga query seperti collision detection dan rendering hanya memproses objek di area tertentu, mengurangi kompleksitas dari O(n) menjadi O(log n).

## Analogi
Bayangkan perpustakaan besar dengan ribuan buku. Tanpa sistem, untuk menemukan buku tertentu harus memeriksa semua buku satu per satu. Dengan rak-rak bertingkat dan kategori, Anda langsung pergi ke rak yang benar. QuadTree/Octree bekerja sama seperti sistem rak tersebut untuk objek-objek dalam game.

## Struktur Node (Scene Tree)
```
World (Node2D)
├── QuadTreeRoot (Node2D)
│   ├── Quadrant1 (Node2D)
│   ├── Quadrant2 (Node2D)
│   ├── Quadrant3 (Node2D)
│   └── Quadrant4 (Node2D)
├── Entities (Node2D)
│   ├── Enemy1 (CharacterBody2D)
│   └── Enemy2 (CharacterBody2D)
└── Player (CharacterBody2D)
```

## Kode GDScript (Godot 4)
```gdscript
class_name QuadTree
extends RefCounted

var boundary: Rect2
var capacity: int
var objects: Array[Dictionary] = []
var divided: bool = false
var northeast: QuadTree = null
var northwest: QuadTree = null
var southeast: QuadTree = null
var southwest: QuadTree = null

func _init(_boundary: Rect2, _capacity: int = 4):
    boundary = _boundary
    capacity = _capacity

func subdivide():
    var x = boundary.position.x
    var y = boundary.position.y
    var w = boundary.size.x / 2
    var h = boundary.size.y / 2
    northeast = QuadTree.new(Rect2(x + w, y, w, h), capacity)
    northwest = QuadTree.new(Rect2(x, y, w, h), capacity)
    southeast = QuadTree.new(Rect2(x + w, y + h, w, h), capacity)
    southwest = QuadTree.new(Rect2(x, y + h, w, h), capacity)
    divided = true

func insert(obj_pos: Vector2, obj_data: Dictionary) -> bool:
    if not boundary.has_point(obj_pos):
        return false
    if objects.size() < capacity:
        objects.append({"pos": obj_pos, "data": obj_data})
        return true
    if not divided:
        subdivide()
    if northeast.insert(obj_pos, obj_data):
        return true
    if northwest.insert(obj_pos, obj_data):
        return true
    if southeast.insert(obj_pos, obj_data):
        return true
    if southwest.insert(obj_pos, obj_data):
        return true
    return false

func query_range(range_rect: Rect2, found: Array = []) -> Array:
    if not boundary.intersects(range_rect):
        return found
    for obj in objects:
        if range_rect.has_point(obj["pos"]):
            found.append(obj["data"])
    if divided:
        northeast.query_range(range_rect, found)
        northwest.query_range(range_rect, found)
        southeast.query_range(range_rect, found)
        southwest.query_range(range_rect, found)
    return found

func clear():
    objects.clear()
    if divided:
        northeast.clear()
        northwest.clear()
        southeast.clear()
        southwest.clear()
        northeast = null
        northwest = null
        southeast = null
        southwest = null
        divided = false
```

## Kasus Penggunaan Nyata
Game strategi real-time dengan ribuan unit di peta besar menggunakan QuadTree untuk mempercepat collision detection dan seleksi unit. Saat pemain melakukan drag-select area, hanya unit dalam area tersebut yang di-query menggunakan QuadTree, mengurangi waktu seleksi dari milidetik menjadi mikrodetik. Tanpa spatial partitioning, frame rate turun drastis saat jumlah unit mencapai ribuan.
