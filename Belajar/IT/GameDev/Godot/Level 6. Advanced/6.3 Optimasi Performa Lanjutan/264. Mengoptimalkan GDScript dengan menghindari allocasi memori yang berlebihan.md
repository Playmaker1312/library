# 264. Mengoptimalkan GDScript dengan menghindari allocasi memori yang berlebihan

## Definisi Singkat
Optimasi memori dalam GDScript melibatkan penghindaran alokasi berulang pada hot path dengan menggunakan object pooling, pre-allocation, dan menghindari pembuatan objek baru di dalam `_process`. Teknik ini mengurangi garbage collection overhead yang dapat menyebabkan frame stuttering.

## Analogi
Bayangkan seorang koki yang selalu menggunakan piring baru untuk setiap hidangan dan membuang piring bekas setelah digunakan. Secara teratur ia harus membersihkan tumpukan piring kotor. Jika ia menggunakan piring yang bisa dipakai ulang (pool), ia tidak perlu terus membeli piring baru dan tempat cuci piring tidak akan menumpuk.

## Struktur Node (Scene Tree)
```
Main (Node)
├── BulletPool (Node)
│   ├── Bullet1 (Area2D)
│   ├── Bullet2 (Area2D)
│   └── Bullet3 (Area2D)
├── Player (CharacterBody2D)
└── UI (CanvasLayer)
    └── StatsLabel (Label)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var bullet_pool: Array[Area2D] = []
var active_bullets: Array[Area2D] = []
var bullet_scene: PackedScene = preload("res://bullet.tscn")
const POOL_SIZE: int = 100

func _ready():
    for i in range(POOL_SIZE):
        var bullet = bullet_scene.instantiate()
        bullet.set_process(false)
        bullet.set_physics_process(false)
        bullet.visible = false
        add_child(bullet)
        bullet_pool.append(bullet)

func get_bullet() -> Area2D:
    if bullet_pool.size() > 0:
        var bullet = bullet_pool.pop_back()
        bullet.set_process(true)
        bullet.set_physics_process(true)
        bullet.visible = true
        active_bullets.append(bullet)
        return bullet
    return null

func return_bullet(bullet: Area2D):
    bullet.set_process(false)
    bullet.set_physics_process(false)
    bullet.visible = false
    bullet.global_position = Vector2(-1000, -1000)
    active_bullets.erase(bullet)
    bullet_pool.append(bullet)

func fire_bullet(start_pos: Vector2, direction: Vector2):
    var bullet = get_bullet()
    if bullet:
        bullet.global_position = start_pos
        bullet.velocity = direction * 800.0
        bullet.connect("timeout", Callable(self, "return_bullet").bind(bullet), CONNECT_ONE_SHOT)

func _process(_delta):
    var stats_label = $UI/StatsLabel
    stats_label.text = "Active: %d | Pooled: %d" % [active_bullets.size(), bullet_pool.size()]
```

## Kasus Penggunaan Nyata
Game shoot-em-up yang menembakkan ratusan peluru per detik menggunakan object pooling untuk menghindari alokasi memori konstan. Tanpa pooling, garbage collector akan dipanggil secara teratur menyebabkan frame drops. Dengan pre-allocate 100 bullet objects dan reuse mereka, game maintain frame rate stabil 60fps meskipun banyak peluru aktif di layar.
