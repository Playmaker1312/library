# 261. Profiling mendalam menggunakan Godot Profiler dan RenderDoc

## Definisi Singkat
Godot Profiler adalah tool built-in untuk menganalisis performa CPU dan memory game secara real-time, sedangkan RenderDoc membantu debugging rendering pipeline pada level GPU. Keduanya bekerja sama untuk mengidentifikasi bottleneck performa di berbagai layer sistem.

## Analogi
Bayangkan sebuah restoran yang sedang sepi. Godot Profiler seperti manajer yang mencatat berapa lama setiap koki menyiapkan makanan (CPU profiling), sedangkan RenderDoc seperti kamera yang merekam bagaimana makanan tersebut dimasak di kompor (GPU profiling). Keduanya membantu menemukan koki atau peralatan mana yang menjadi penyebab antrian.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   └── CollisionShape2D
├── Enemies (Node2D)
│   ├── Enemy1 (CharacterBody2D)
│   └── Enemy2 (CharacterBody2D)
└── UI (CanvasLayer)
    └── HUD (Control)
        ├── FPSLabel (Label)
        └── ProfileButton (Button)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

var frame_times: Array[float] = []
var is_profiling: bool = false

func _ready():
    Engine.max_fps = 0
    Performance.set_process_time(true)

func _process(delta):
    frame_times.append(delta)
    if frame_times.size() > 60:
        frame_times.pop_front()
    var fps_label = $UI/HUD/FPSLabel
    if frame_times.size() > 0:
        var avg_ms = 0.0
        for ft in frame_times:
            avg_ms += ft
        avg_ms = (avg_ms / frame_times.size()) * 1000.0
        fps_label.text = "FPS: %d | Avg Frame: %.2f ms" % [Engine.get_frames_per_second(), avg_ms]

func _on_profile_button_pressed():
    if is_profiling:
        Performance.set_process_time(false)
        is_profiling = false
    else:
        Performance.set_process_time(true)
        is_profiling = true
    print("Profiling: ", is_profiling)

func get_memory_usage() -> Dictionary:
    var mem_info = OS.get_memory_info()
    return {
        "physical_total": mem_info.get("physical_total", 0),
        "physical_available": mem_info.get("physical_available", 0),
        "virtual_total": mem_info.get("virtual_total", 0),
        "virtual_available": mem_info.get("virtual_available", 0)
    }
```

## Kasus Penggunaan Nyata
Dalam pengembangan game RPG besar, profiler mengungkap bahwa fungsi pathfinding消耗80% waktu CPU karena dipanggil setiap frame untuk semua NPC. Dengan RenderDoc, ditemukan bahwa shadow map rendering menggunakan resolusi terlalu tinggi, menyebabkan GPU overhead signifikan pada perangkat mobile. Kombinasi keduanya memungkinkan developer mengoptimasi kedua bottleneck tersebut secara spesifik.
