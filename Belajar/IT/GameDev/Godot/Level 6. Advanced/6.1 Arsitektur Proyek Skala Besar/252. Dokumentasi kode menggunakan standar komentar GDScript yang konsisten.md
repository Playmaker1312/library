# 252. Dokumentasi kode menggunakan standar komentar GDScript yang konsisten

## Definisi Singkat
Standar dokumentasi kode adalah konvensi penulisan komentar dan dokumentasi yang konsisten dalam seluruh codebase, memudahkan kolaborasi tim, maintainability, dan penggunaan tools otomatis seperti editor tooltip dan API reference generator. Dalam GDScript, ini mencakup penulisan docstring untuk class, method, property, dan signal mengikuti format yang telah ditentukan.

## Analogi
Bayangkan sebuah peta hutan. Tanpa peta dan penanda yang jelas, pendaki akan tersesat. Dengan peta yang baik — menunjukkan jalur, sumber air, titik bahaya, dan landmark — perjalanan menjadi efisien dan aman. Dokumentasi kode yang baik adalah "peta" bagi developer lain (dan versi dirimu di masa depan) untuk memahami kode tanpa harus membaca setiap baris.

## Struktur Node (Scene Tree)

project_docs/

## Kode GDScript (Godot 4)

```gdscript
## Manager untuk mengelola semua musuh di arena pertarungan.
##
## Kelas ini bertanggung jawab untuk spawn, update, dan cleanup musuh.
## Menggunakan object pooling untuk mengoptimalkan performa.
class_name EnemyArenaManager
extends Node

## Event yang dipancarkan ketika semua musuh di arena telah dikalahkan.
signal arena_cleared()

## Event yang dipancarkan ketika jumlah musuh berubah.
##
## [param current_count] Jumlah musuh yang tersisa
## [param max_count] Jumlah maksimum musuh di arena
signal enemy_count_changed(current_count: int, max_count: int)

## Array yang berisi referensi ke semua musuh aktif di arena.
var active_enemies: Array[Node] = []

## Jumlah maksimum musuh yang bisa ada di arena secara bersamaan.
##
## Nilai default adalah 10, dan bisa diubah melalui
## method [method set_max_enemies].
@export var max_enemies: int = 10

## Template scene untuk musuh yang akan di-spawn.
##
## Harus berupa scene yang memiliki script musuh
## yang meng-extend [code]CharacterBody2D[/code].
@export var enemy_template: PackedScene

## Jarak minimum spawn musuh dari pemain.
##
## Musuh tidak akan di-spawn lebih dekat dari jarak ini
## untuk menghindari spawn yang tidak adil.
var min_spawn_distance: float = 200.0

## Jarak maksimum spawn musuh dari pemain.
##
## Ini menentukan batas luar area spawn musuh.
var max_spawn_distance: float = 500.0

## Menghitung total damage yang diterima semua musuh di arena ini.
##
## [return] Total damage dari semua musuh yang aktif
func get_total_damage_received() -> int:
    var total = 0
    for enemy in active_enemies:
        if enemy.has_method("get_damage_taken"):
            total += enemy.get_damage_taken()
    return total

## Menentukan apakah arena sudah cleared (tidak ada musuh tersisa).
##
## [return] [code]true[/code] jika tidak ada musuh aktif, [code]false[/code] jika masih ada
func is_arena_cleared() -> bool:
    return active_enemies.size() == 0

## Mengatur jumlah maksimum musuh di arena.
##
## [param new_max] Jumlah maksimum baru. Harus lebih besar dari 0.
## Jika kurang dari jumlah musuh aktif saat ini, musuh yang berlebihan
## akan di-remove secara acak.
func set_max_enemies(new_max: int) -> void:
    if new_max < 1:
        push_warning("max_enemies must be at least 1")
        return

    max_enemies = new_max

    while active_enemies.size() > max_enemies:
        var random_index = randi() % active_enemies.size()
        var enemy = active_enemies[random_index]
        remove_enemy(enemy)

## Menambahkan musuh baru ke arena.
##
## [param spawn_position] Posisi world dimana musuh akan di-spawn
## [param enemy_data] Dictionary yang berisi data musuh seperti health, damage, dll.
##
## [return] Node musuh yang berhasil di-spawn, atau [code]null[/code] jika gagal
func spawn_enemy(spawn_position: Vector2, enemy_data: Dictionary = {}) -> Node:
    if active_enemies.size() >= max_enemies:
        return null

    if enemy_template == null:
        push_warning("enemy_template not set")
        return null

    var enemy = enemy_template.instantiate()
    enemy.global_position = spawn_position

    if enemy_data.has("health"):
        enemy.set_meta("max_health", enemy_data.health)

    add_child(enemy)
    active_enemies.append(enemy)

    enemy.tree_exited.connect(_on_enemy_removed.bind(enemy))
    enemy_count_changed.emit(active_enemies.size(), max_enemies)

    return enemy

## Menghapus musuh dari arena secara paksa.
##
## [param enemy] Node musuh yang akan di-remove
##
## [codeblock]
## # Contoh penggunaan:
## var weak_enemies = get_enemies_with_low_health()
## for enemy in weak_enemies:
##     remove_enemy(enemy)
## [/codeblock]
func remove_enemy(enemy: Node) -> void:
    var index = active_enemies.find(enemy)
    if index != -1:
        active_enemies.remove_at(index)
        enemy.queue_free()

        enemy_count_changed.emit(active_enemies.size(), max_enemies)

        if active_enemies.size() == 0:
            arena_cleared.emit()

## Mendapatkan semua musuh dalam radius tertentu dari posisi tertentu.
##
## [param center] Posisi pusat pencarian
## [param radius] Jarak pencarian dalam pixel
##
## [return] Array berisi semua musuh yang ditemukan dalam radius
func get_enemies_in_radius(center: Vector2, radius: float) -> Array[Node]:
    var enemies_in_range: Array[Node] = []

    for enemy in active_enemies:
        var distance = enemy.global_position.distance_to(center)
        if distance <= radius:
            enemies_in_range.append(enemy)

    return enemies_in_range

## Callback ketika musuh di-remove dari scene tree.
##
## [param enemy] Musuh yang di-remove
func _on_enemy_removed(enemy: Node) -> void:
    var index = active_enemies.find(enemy)
    if index != -1:
        active_enemies.remove_at(index)
        enemy_count_changed.emit(active_enemies.size(), max_enemies)

        if active_enemies.size() == 0:
            arena_cleared.emit()
```

```gdscript
## Utility class untuk perhitungan matematika game.
##
## Berbagai fungsi matematika yang sering digunakan dalam game development,
## termasuk interpolation, randomization, dan clamp values.
class_name GameMath
extends RefCounted

## Melakukan linear interpolation antara dua nilai.
##
## [param a] Nilai awal
## [param b] Nilai akhir
## [param t] Faktor interpolasi (0.0 - 1.0)
##
## [return] Hasil interpolasi
##
## [codeblock]
## # Contoh penggunaan:
## var health_bar_value = GameMath.lerp_value(current_hp, max_hp, 0.5)
## [/codeblock]
static func lerp_value(a: float, b: float, t: float) -> float:
    return a + (b - a) * clamp(t, 0.0, 1.0)

## Menghitung distance antara dua point dalam 2D space.
##
## [param pos1] Posisi pertama
## [param pos2] Posisi kedua
##
## [return] Jarak dalam pixel
static func distance_2d(pos1: Vector2, pos2: Vector2) -> float:
    return pos1.distance_to(pos2)

## Menghasilkan angka random dalam range tertentu.
##
## [param min_val] Nilai minimum (inclusive)
## [param max_val] Nilai maximum (inclusive)
##
## [return] Angka random dalam range [param min_val] - [param max_val]
static func random_range(min_val: float, max_val: float) -> float:
    return randf_range(min_val, max_val)

## Memastikan nilai berada dalam range tertentu.
##
## [param value] Nilai yang akan di-clamp
## [param min_val] Batas bawah
## [param max_val] Batas atas
##
## [return] Nilai yang sudah di-clamp
static func clamp_value(value: float, min_val: float, max_val: float) -> float:
    return clamp(value, min_val, max_val)

## Menghitung persentase dari sebuah nilai terhadap total.
##
## [param current] Nilai saat ini
## [param total] Nilai total
##
## [return] Persentase dalam bentuk float (0.0 - 1.0)
##
## [error] Akan return 0.0 jika [param total] adalah 0 untuk menghindari division by zero
static func percentage(current: float, total: float) -> float:
    if total == 0.0:
        return 0.0
    return clamp(current / total, 0.0, 1.0)
```

```gdscript
## Unit manager untuk mengelola semua unit di战场.
##
## Setiap unit harus register ke manager ini untuk
## mendapatkan benefit seperti auto-cleanup dan central tracking.
class_name UnitManager
extends Node

## Enum untuk tipe unit yang didukung.
enum UnitType {
    ## Unit tipe warrior, melee attacker
    WARRIOR,

    ## Unit tipe mage, ranged attacker
    MAGE,

    ## Unit tipe support, healer
    SUPPORT,

    ## Unit tipe tank, damage absorber
    TANK
}

## Data structure untuk menyimpan informasi unit.
class UnitData:
    ## Referensi ke node unit
    var node: Node

    ## Tipe unit
    var type: UnitType

    ## Level unit
    var level: int

    ## Apakah unit masih aktif
    var is_active: bool

    func _init(unit_node: Node, unit_type: UnitType, unit_level: int = 1) -> void:
        node = unit_node
        type = unit_type
        level = unit_level
        is_active = true

## Dictionary yang menyimpan semua unit yang ter-register.
##
## Key adalah String ID unik, value adalah [code]UnitData[/code].
var units: Dictionary = {}

## Counter untuk generating unique ID.
var _next_id: int = 0

## Register unit baru ke manager.
##
## [param unit_node] Node unit yang akan di-register
## [param unit_type] Tipe unit dari enum [enum UnitType]
## [param unit_level] Level awal unit (default: 1)
##
## [return] String ID unik yang diberikan ke unit
func register_unit(unit_node: Node, unit_type: UnitType, unit_level: int = 1) -> String:
    var unit_id = "unit_%d" % _next_id
    _next_id += 1

    units[unit_id] = UnitData.new(unit_node, unit_type, unit_level)
    return unit_id

## Unregister unit dari manager.
##
## [param unit_id] ID unit yang akan di-unregister
##
## [code]true[/code] jika berhasil, [code]false[/code] jika ID tidak ditemukan
func unregister_unit(unit_id: String) -> bool:
    if units.has(unit_id):
        units[unit_id].is_active = false
        units.erase(unit_id)
        return true
    return false

## Mendapatkan semua unit dengan tipe tertentu.
##
## [param unit_type] Tipe unit yang dicari
##
## [return] Array berisi ID semua unit dengan tipe tersebut
func get_units_by_type(unit_type: UnitType) -> Array[String]:
    var result: Array[String] = []

    for unit_id in units:
        if units[unit_id].type == unit_type:
            result.append(unit_id)

    return result
```

## Kasus Penggunaan Nyata
Dalam proyek game dengan 50+ developer, dokumentasi yang konsisten sangat krusial. Tanpa standar komentar yang jelas, developer baru membutuhkan waktu berminggu-minggu untuk memahami codebase. Dengan docstring yang lengkap, mereka bisa memahami purpose setiap function hanya dari tooltip di editor. Godot 4 secara native mendukung docstring dengan format `##` untuk komentar dokumentasi, yang bisa diakses melalui editor tooltip dan bisa di-generate menjadi API reference. Banyak studio besar seperti Supergiant Games (Hades) dan Motion Twin (Dead Cells) menerapkan standar serupa untuk menjaga kualitas kode mereka.
