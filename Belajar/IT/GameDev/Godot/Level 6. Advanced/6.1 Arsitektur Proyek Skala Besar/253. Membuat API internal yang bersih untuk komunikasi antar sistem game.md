# 253. Membuat API internal yang bersih untuk komunikasi antar sistem game

## Definisi Singkat
API internal yang bersih adalah interface yang didefinisikan secara eksplisit untuk komunikasi antar sistem dalam game, memastikan setiap sistem hanya mengekspos method yang diperlukan dan menyembunyikan implementasi internal. Dalam Godot, ini dicapai melalui penggunaan class_name, interface classes, dan access modifier untuk menciptakan batas yang jelas antar modul.

## Analogi
Bayangkan sebuah gedung perkantoran. Setiap departemen (HR, Marketing, Finance) memiliki resepsionis yang menerima permintaan dari luar. Karyawan tidak bisa langsung masuk ke departemen lain dan meminta apapun — mereka harus melalui resepsionis yang tahu method apa yang tersedia. API internal yang bersih bekerja seperti resepsionis ini — menyediakan akses terkontrol dan terstruktur ke fungsionalitas setiap sistem.

## Struktur Node (Scene Tree)
```
GameAPI (Node) — Central API facade
├── CombatAPI — API untuk sistem pertarungan
├── InventoryAPI — API untuk sistem inventaris
├── QuestAPI — API untuk sistem quest
├── DialogueAPI — API untuk sistem dialog
├── AudioAPI — API untuk sistem audio
└── SaveAPI — API untuk sistem penyimpanan
```

## Kode GDScript (Godot 4)

```gdscript
## API facade untuk semua sistem game.
##
## Kelas ini berfungsi sebagai entry point tunggal untuk
## komunikasi antar sistem. Semua sistem lain harus mengakses
## fungsionalitas melalui API ini.
class_name GameAPI
extends Node

## Referensi ke CombatAPI
var combat: CombatAPI

## Referensi ke InventoryAPI
var inventory: InventoryAPI

## Referensi ke QuestAPI
var quest: QuestAPI

## Referensi ke DialogueAPI
var dialogue: DialogueAPI

## Referensi ke AudioAPI
var audio: AudioAPI

## Referensi ke SaveAPI
var save: SaveAPI

func _ready() -> void:
    _initialize_apis()

func _initialize_apis() -> void:
    combat = CombatAPI.new()
    add_child(combat)

    inventory = InventoryAPI.new()
    add_child(inventory)

    quest = QuestAPI.new()
    add_child(quest)

    dialogue = DialogueAPI.new()
    add_child(dialogue)

    audio = AudioAPI.new()
    add_child(audio)

    save = SaveAPI.new()
    add_child(save)

    combat.inventory_api = inventory
    combat.quest_api = quest
```

```gdscript
## API untuk sistem pertarungan.
##
## Menyediakan method untuk menghitung damage, manage health,
## dan koordinasi combat antar entity.
class_name CombatAPI
extends Node

signal damage_calculated(attacker: Node, target: Node, damage: float)
signal entity_defeated(entity: Node)

## Reference ke inventory API untuk item consumption
var inventory_api: InventoryAPI

## Reference ke quest API untuk kill tracking
var quest_api: QuestAPI

## Menghitung damage yang diterima target dari attacker.
##
## [param attacker] Node yang menyerang
## [param target] Node yang diserang
## [param base_damage] Damage dasar sebelum modifier
##
## [return] Damage akhir setelah perhitungan armor dan modifier
func calculate_damage(attacker: Node, target: Node, base_damage: float) -> float:
    var attacker_damage = attacker.get_meta("damage", 0.0)
    var target_armor = target.get_meta("armor", 0.0)

    var final_damage = max((base_damage + attacker_damage) - target_armor, 0.0)
    damage_calculated.emit(attacker, target, final_damage)
    return final_damage

## Menggunakan item untuk efek damage bonus.
##
## [param attacker] Node yang menggunakan item
## [param item_id] ID item yang digunakan
## [param damage_multiplier] Multiplier damage
##
## [return] [code]true[/code] jika item berhasil digunakan
func use_damage_item(attacker: Node, item_id: String, damage_multiplier: float = 1.5) -> bool:
    if inventory_api.consume_item(attacker, item_id, 1):
        var current_damage = attacker.get_meta("damage", 0.0)
        attacker.set_meta("damage", current_damage * damage_multiplier)
        return true
    return false

## Mendaftarkan kill untuk tracking quest.
##
## [param killer] Node yang melakukan kill
## [param defeated_entity] Node yang dikalahkan
## [param xp_reward] XP yang diberikan
func register_kill(killer: Node, defeated_entity: Node, xp_reward: int = 10) -> void:
    var entity_type = defeated_entity.get_meta("entity_type", "unknown")
    quest_api.update_kill_count(killer, entity_type, 1)
    entity_defeated.emit(defeated_entity)

    if killer.has_method("gain_experience"):
        killer.gain_experience(xp_reward)

## Menciptakan efek damage number floating di atas target.
##
## [param target] Node target yang ditampilkan damage number-nya
## [param amount] Jumlah damage yang ditampilkan
## [param is_critical] Apakah damage ini critical hit
func show_damage_number(target: Node, amount: float, is_critical: bool = false) -> void:
    EventBus.emit("damage_number_show", {
        "position": target.global_position,
        "amount": amount,
        "is_critical": is_critical
    })
```

```gdscript
## API untuk sistem inventaris.
##
## Mengelola item, stack, dan operasi inventaris lainnya.
class_name InventoryAPI
extends Node

signal item_added(item_data: Dictionary, slot_index: int)
signal item_removed(item_data: Dictionary, slot_index: int)

## Maksimum slot inventaris
var max_slots: int = 30

## Data inventaris per entity
var inventories: Dictionary = {}

## Mendapatkan inventaris dari entity tertentu.
##
## [param entity] Node yang memiliki inventaris
##
## [return] Array berisi data semua item di inventaris entity
func get_inventory(entity: Node) -> Array:
    var entity_id = _get_entity_id(entity)
    return inventories.get(entity_id, [])

## Menambahkan item ke inventaris entity.
##
## [param entity] Node yang akan menerima item
## [param item_data] Dictionary berisi informasi item (id, name, quantity, dll)
##
## [return] [code]true[/code] jika berhasil, [code]false[/code] jika inventaris penuh
func add_item(entity: Node, item_data: Dictionary) -> bool:
    var entity_id = _get_entity_id(entity)

    if not inventories.has(entity_id):
        inventories[entity_id] = []

    var inventory = inventories[entity_id]

    if inventory.size() >= max_slots:
        return false

    var existing = _find_item_stack(inventory, item_data.id)
    if existing and item_data.get("stackable", false):
        existing.quantity += item_data.get("quantity", 1)
        item_added.emit(item_data, inventory.find(existing))
        return true

    item_data.quantity = item_data.get("quantity", 1)
    inventory.append(item_data)
    item_added.emit(item_data, inventory.size() - 1)
    return true

## Mengkonsumsi item dari inventaris.
##
## [param entity] Node yang memiliki inventaris
## [param item_id] ID item yang akan dikonsumsi
## [param quantity] Jumlah item yang akan dikonsumsi
##
## [return] [code]true[/code] jika berhasil
func consume_item(entity: Node, item_id: String, quantity: int = 1) -> bool:
    var entity_id = _get_entity_id(entity)

    if not inventories.has(entity_id):
        return false

    var inventory = inventories[entity_id]
    var item = _find_item_stack(inventory, item_id)

    if item == null or item.quantity < quantity:
        return false

    item.quantity -= quantity
    if item.quantity <= 0:
        var index = inventory.find(item)
        inventory.remove_at(index)
        item_removed.emit(item, index)

    return true

## Mengecek apakah entity memiliki item tertentu.
##
## [param entity] Node yang dicek
## [param item_id] ID item yang dicari
## [param min_quantity] Jumlah minimum yang dimiliki
##
## [return] [code]true[/code] jika entity memiliki item dengan jumlah yang cukup
func has_item(entity: Node, item_id: String, min_quantity: int = 1) -> bool:
    var inventory = get_inventory(entity)
    var item = _find_item_stack(inventory, item_id)
    return item != null and item.quantity >= min_quantity

## Mendapatkan jumlah item tertentu di inventaris.
##
## [param entity] Node yang dicek
## [param item_id] ID item yang dicari
##
## [return] Jumlah item yang dimiliki
func get_item_count(entity: Node, item_id: String) -> int:
    var inventory = get_inventory(entity)
    var item = _find_item_stack(inventory, item_id)
    return item.quantity if item else 0

func _get_entity_id(entity: Node) -> String:
    return str(entity.get_instance_id())

func _find_item_stack(inventory: Array, item_id: String) -> Variant:
    for item in inventory:
        if item.get("id") == item_id:
            return item
    return null
```

```gdscript
## API untuk sistem quest.
##
## Mengelola quest state, objectives, dan rewards.
class_name QuestAPI
extends Node

signal quest_completed(quest_id: String)
signal objective_completed(quest_id: String, objective_id: String)

## Data quest yang aktif per entity
var active_quests: Dictionary = {}

## Data quest yang sudah selesai
var completed_quests: Dictionary = {}

## Quest templates
var quest_templates: Dictionary = {}

func _ready() -> void:
    _load_quest_templates()

## Mengaktifkan quest baru untuk entity.
##
## [param entity] Node yang mengaktifkan quest
## [param quest_id] ID quest yang akan diaktifkan
##
## [return] [code]true[/code] jika berhasil, [code]false[/code] jika quest sudah aktif atau completed
func activate_quest(entity: Node, quest_id: String) -> bool:
    var entity_id = _get_entity_id(entity)

    if not active_quests.has(entity_id):
        active_quests[entity_id] = {}

    if active_quests[entity_id].has(quest_id):
        return false

    if completed_quests.has(entity_id) and completed_quests[entity_id].has(quest_id):
        return false

    if not quest_templates.has(quest_id):
        return false

    active_quests[entity_id][quest_id] = {
        "template": quest_templates[quest_id],
        "progress": {},
        "is_complete": false
    }

    return true

## Memperbarui progress kill count untuk quest.
##
## [param entity] Node yang memiliki quest
## [param enemy_type] Tipe musuh yang dikalahkan
## [param count] Jumlah kill yang ditambahkan
func update_kill_count(entity: Node, enemy_type: String, count: int = 1) -> void:
    var entity_id = _get_entity_id(entity)

    if not active_quests.has(entity_id):
        return

    for quest_id in active_quests[entity_id]:
        var quest_data = active_quests[entity_id][quest_id]
        var objectives = quest_data.template.get("objectives", [])

        for objective in objectives:
            if objective.type == "kill" and objective.target_type == enemy_type:
                if not quest_data.progress.has(objective.id):
                    quest_data.progress[objective.id] = 0

                quest_data.progress[objective.id] += count

                if quest_data.progress[objective.id] >= objective.required:
                    objective_completed.emit(quest_id, objective.id)

                _check_quest_completion(entity, quest_id)

## Mengecek apakah quest sudah selesai.
##
## [param entity] Node yang memiliki quest
## [param quest_id] ID quest yang dicek
##
## [return] [code]true[/code] jika quest sudah selesai
func is_quest_complete(entity: Node, quest_id: String) -> bool:
    var entity_id = _get_entity_id(entity)

    if not active_quests.has(entity_id):
        return false

    if not active_quests[entity_id].has(quest_id):
        return false

    return active_quests[entity_id][quest_id].is_complete

func _check_quest_completion(entity: Node, quest_id: String) -> void:
    var entity_id = _get_entity_id(entity)
    var quest_data = active_quests[entity_id][quest_id]
    var objectives = quest_data.template.get("objectives", [])

    var all_complete = true
    for objective in objectives:
        var progress = quest_data.progress.get(objective.id, 0)
        if progress < objective.required:
            all_complete = false
            break

    if all_complete:
        quest_data.is_complete = true
        completed_quests[entity_id][quest_id] = quest_data
        active_quests[entity_id].erase(quest_id)
        quest_completed.emit(quest_id)

        var rewards = quest_data.template.get("rewards", {})
        _grant_rewards(entity, rewards)

func _grant_rewards(entity: Node, rewards: Dictionary) -> void:
    if rewards.has("xp") and entity.has_method("gain_experience"):
        entity.gain_experience(rewards.xp)

    if rewards.has("gold") and entity.has_meta("gold"):
        var current_gold = entity.get_meta("gold")
        entity.set_meta("gold", current_gold + rewards.gold)

func _load_quest_templates() -> void:
    var dir = DirAccess.open("res://data/quests/")
    if dir:
        dir.list_dir_begin()
        var file_name = dir.get_next()
        while file_name != "":
            if not dir.current_is_dir() and file_name.ends_with(".json"):
                var file = FileAccess.open("res://data/quests/" + file_name, FileAccess.READ)
                if file:
                    var json = JSON.new()
                    json.parse(file.get_as_text())
                    var quest_data = json.data
                    quest_templates[quest_data.id] = quest_data
            file_name = dir.get_next()

func _get_entity_id(entity: Node) -> String:
    return str(entity.get_instance_id())
```

```gdscript
## API untuk sistem dialog.
##
## Mengelola percakapan antara NPC dan pemain.
class_name DialogueAPI
extends Node

signal dialogue_started(npc_name: String)
signal dialogue_ended(npc_name: String)
signal choice_made(choice_id: String)

## Data dialog yang sedang berlangsung
var current_dialogue: Dictionary = {}

## History dialog yang sudah dilalui
var dialogue_history: Dictionary = {}

## Memulai dialog dengan NPC.
##
## [param npc_name] Nama NPC yang berbicara
## [param dialogue_data] Array berisi sequence dialog
##
## [return] [code]true[/code] jika dialog berhasil dimulai
func start_dialogue(npc_name: String, dialogue_data: Array) -> bool:
    if current_dialogue.has(npc_name):
        return false

    current_dialogue[npc_name] = {
        "sequence": dialogue_data,
        "current_index": 0,
        "is_active": true
    }

    dialogue_started.emit(npc_name)
    return true

## Mendapatkan dialog berikutnya.
##
## [param npc_name] Nama NPC yang berbicara
##
## [return] Dictionary berisi dialog info atau [code]null[/code] jika dialog selesai
func get_next_dialogue(npc_name: String) -> Variant:
    if not current_dialogue.has(npc_name):
        return null

    var dialogue = current_dialogue[npc_name]
    var index = dialogue.current_index

    if index >= dialogue.sequence.size():
        _end_dialogue(npc_name)
        return null

    var current = dialogue.sequence[index]
    dialogue.current_index += 1

    return current

## Mendapatkan pilihan dialog yang tersedia.
##
## [param npc_name] Nama NPC yang berbicara
##
## [return] Array berisi pilihan dialog atau [code]null[/code] jika tidak ada pilihan
func get_dialogue_choices(npc_name: String) -> Array:
    var dialogue_data = get_next_dialogue(npc_name)

    if dialogue_data and dialogue_data.has("choices"):
        return dialogue_data.choices

    return []

## Membuat pilihan dialog.
##
## [param npc_name] Nama NPC yang berbicara
## [param choice_id] ID pilihan yang dipilih
##
## [return] [code]true[/code] jika berhasil
func make_choice(npc_name: String, choice_id: String) -> bool:
    if not current_dialogue.has(npc_name):
        return false

    choice_made.emit(choice_id)

    if not dialogue_history.has(npc_name):
        dialogue_history[npc_name] = []

    dialogue_history[npc_name].append(choice_id)

    return true

## Mengecek apakah dialog dengan NPC sedang aktif.
##
## [param npc_name] Nama NPC yang dicek
##
## [return] [code]true[/code] jika dialog sedang aktif
func is_dialogue_active(npc_name: String) -> bool:
    return current_dialogue.has(npc_name) and current_dialogue[npc_name].is_active

func _end_dialogue(npc_name: String) -> void:
    if current_dialogue.has(npc_name):
        current_dialogue[npc_name].is_active = false
        current_dialogue.erase(npc_name)
        dialogue_ended.emit(npc_name)
```

## Kasus Penggunaan Nyata
Dalam game RPG kompleks dengan banyak sistem yang saling berinteraksi, tanpa API yang bersih, setiap sistem bisa langsung mengakses method internal sistem lain. Ini menciptakan tight coupling yang membuat perubahan kecil pada satu sistem bisa mempengaruhi seluruh game. Dengan API internal yang bersih, setiap sistem hanya mengekspos method yang benar-benar diperlukan. Contoh nyata adalah seri The Witcher di CD Projekt Red, di mana sistem alchemy, combat, crafting, dan quest memiliki API terpisah yang berkomunikasi melalui facade pattern, memungkinkan ribuan developer bekerja secara paralel tanpa konflik.
