# 270. Membuat class C++ sederhana yang dapat diakses dari GDScript

## Definisi Singkat
Membuat class C++ untuk GDExtension melibatkan penulisan header file (.h) yang mendefinisikan class dengan macro Godot, implementasi (.cpp) untuk logika, dan registrasi class agar dapat dikenali oleh engine dan diakses dari GDScript.

## Analogi
Membuat class C++ untuk GDExtension seperti membuat remote control untuk TV. Kamu mendesain tombol-tombolnya (method), memberinya label (properties), dan menghubungkannya ke TV (Godot engine) sehingga kamu bisa mengontrol TV dari jarak jauh (GDScript).

## Struktur Node (Scene Tree)

```
Main (Node2D)
├── MyCustomNode (my_custom_node) ← C++ class
│   └── Label (Label) ← Godot built-in
└── Button (Button) ← untuk trigger method C++
```

## Kode GDScript (Godot 4)

```gdscript
extends Node2D

var custom_node: MyCustomNode

func _ready():
    custom_node = MyCustomNode.new()
    custom_node.set_value(100)
    add_child(custom_node)
    print("Custom node value: ", custom_node.get_value())

func _on_button_pressed():
    custom_node.increment_value()
    print("After increment: ", custom_node.get_value())
    custom_node.custom_signal.emit(custom_node.get_value())

func _on_custom_signal(value):
    print("Signal received with value: ", value)
```

## Kode C++ (Header - my_custom_node.h)

```cpp
#ifndef MY_CUSTOM_NODE_H
#define MY_CUSTOM_NODE_H

#include <godot_cpp/classes/node.hpp>
#include <godot_cpp/core/class_db.hpp>

using namespace godot;

class MyCustomNode : public Node {
    GDCLASS(MyCustomNode, Node)

protected:
    static void _bind_methods();

private:
    int value = 0;

public:
    MyCustomNode();
    ~MyCustomNode();

    void set_value(int p_value);
    int get_value() const;
    void increment_value();

    CustomSignal my_signal;
};

#endif
```

## Kode C++ (Implementasi - my_custom_node.cpp)

```cpp
#include "my_custom_node.h"
#include <godot_cpp/core/class_db.hpp>
#include <godot_cpp/variant/utility_functions.hpp>

MyCustomNode::MyCustomNode() {
}

MyCustomNode::~MyCustomNode() {
}

void MyCustomNode::_bind_methods() {
    ClassDB::bind_method(D_METHOD("set_value", "p_value"), &MyCustomNode::set_value);
    ClassDB::bind_method(D_METHOD("get_value"), &MyCustomNode::get_value);
    ClassDB::bind_method(D_METHOD("increment_value"), &MyCustomNode::increment_value);

    ADD_PROPERTY(PropertyInfo(Variant::INT, "value"), "set_value", "get_value");

    ADD_SIGNAL(MethodInfo("my_signal", PropertyInfo(Variant::INT, "value")));
}

void MyCustomNode::set_value(int p_value) {
    value = p_value;
    emit_signal("my_signal", value);
}

int MyCustomNode::get_value() const {
    return value;
}

void MyCustomNode::increment_value() {
    value++;
}
```

## Kode C++ (Registrasi - register_types.cpp)

```cpp
#include "register_types.h"
#include "my_custom_node.h"

#include <gdextension_interface.h>
#include <godot_cpp/core/class_db.hpp>
#include <godot_cpp/core/defs.hpp>
#include <godot_cpp/godot.hpp>

using namespace godot;

void initialize_module(ModuleInitializationLevel p_level) {
    if (p_level != MODULE_INITIALIZATION_LEVEL_SCENE) return;
    ClassDB::register_class<MyCustomNode>();
}

void uninitialize_module(ModuleInitializationLevel p_level) {
    if (p_level != MODULE_INITIALIZATION_LEVEL_SCENE) return;
}

extern "C" {
    GDExtensionBool GDE_EXPORT my_extension_init(
        GDExtensionInterfaceGetProcAddress p_get_proc_address,
        const GDExtensionClassLibraryPtr p_library,
        GDExtensionInitialization *r_initialization
    ) {
        godot::GDExtensionBinding::InitObject init_obj(p_get_proc_address, p_library, r_initialization);
        init_obj.register_initializer(initialize_module);
        init_obj.register_terminator(uninitialize_module);
        init_obj.set_minimum_library_initialization_level(MODULE_INITIALIZATION_LEVEL_SCENE);
        return init_obj.init();
    }
}
```
