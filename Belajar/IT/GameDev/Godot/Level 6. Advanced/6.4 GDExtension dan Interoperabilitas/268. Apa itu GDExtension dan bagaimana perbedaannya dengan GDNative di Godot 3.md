# 268. Apa itu GDExtension dan bagaimana perbedaannya dengan GDNative di Godot 3

## Definisi Singkat
GDExtension adalah sistem di Godot 4 yang memungkinkan kamu menulis kode dalam bahasa pemrograman seperti C++, C#, atau Rust yang terintegrasi langsung ke mesin Godot tanpa perlu kompilasi ulang engine. GDNative adalah pendahulunya di Godot 3 yang memiliki keterbatasan dalam hal performa dan fitur.

## Analogi
Bayangkan Godot adalah sebuah restoran. GDNative (Godot 3) seperti pemasok bahan makanan dari luar yang dikirim setiap hari — bisa diganti, tapi prosesnya agak rumit dan terbatas. GDExtension (Godot 4) seperti koki tamu yang langsung bekerja di dapur restoran, bisa menggunakan semua peralatan dapur dan berkolaborasi langsung dengan koki utama tanpa batasan.

## Perbedaan Utama

| Aspek | GDNative (Godot 3) | GDExtension (Godot 4) |
|-------|-------------------|----------------------|
| Integrasi | Plugin-like, dimuat saat runtime | Terintegrasi penuh ke dalam engine |
| Performa | Overhead karena abstraction layer | Performa native tanpa overhead |
| API | Menggunakan Godot API wrapper | Menggunakan Godot internal API langsung |
| Kompatibilitas | Tidak kompatibel dengan Godot 4 | Standar baru untuk Godot 4+ |
| Binding | Menggunakan godot-cpp bindings | Menggunakan godot-cpp yang diperbarui |
| Stabilitas | Kadang breaking change antar versi | Lebih stabil dengan versi minor |

## Kode GDScript (Godot 4)

```gdscript
extends Node

func _ready():
    var custom_class = ClassDB.instantiate("MyCustomNode")
    if custom_class:
        add_child(custom_class)
        print("GDExtension class loaded successfully")
    else:
        print("Failed to load GDExtension class")

func _process(delta):
    var ext_node = get_node_or_null("MyCustomNode")
    if ext_node:
        ext_node.call_native_method()
```

## Kasus Penggunaan Nyata
GDExtension sangat cocok untuk mengintegrasikan library C++ yang sudah ada seperti OpenCV untuk pemrosesan gambar atau Bullet Physics untuk simulasi fisika canggih. Game profesional juga menggunakan GDExtension untuk menulis modul performa tinggi seperti sistem audio custom atau networking yang membutuhkan kontrol hardware langsung. Pengembang yang beralih dari Godot 3 ke Godot 4 dapat memigrasikan kode native mereka dari GDNative ke GDExtension dengan perubahan minimal.
