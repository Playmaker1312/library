# 271. Mengintegrasikan library pihak ketiga menggunakan GDExtension

## Definisi Singkat
Mengintegrasikan library pihak ketiga menggunakan GDExtension berarti membungkus library C/C++ eksternal agar dapat digunakan dari GDScript dengan membuat wrapper class yang mengekspos fungsi-fungsi library tersebut sebagai method Godot.

## Analogi
Mengintegrasikan library pihak ketiga seperti memasang remote control universal untuk perangkat elektronik. Library pihak ketiga (misalnya OpenCV) adalah remote asli yang kompleks, dan kamu membuat adapter (wrapper) agar remote itu bisa digunakan dengan TV Godot kamu.

## Kode GDScript (Godot 4)

```gdscript
extends Node

func _ready():
    var image_processor = ImageProcessor.new()
    var json_parser = JsonParser.new()
    
    var image_data = image_processor.load_image("res://assets/test.png")
    print("Image loaded: ", image_data)
    
    var json_text = '{"name": "Player", "health": 100}'
    var parsed = json_parser.parse_json(json_text)
    print("Parsed JSON: ", parsed)
    
    var exported = json_parser.export_json({"score": 500, "level": 5})
    print("Exported JSON: ", exported)
```

## Kode C++ (Wrapper untuk stb_image)

```cpp
#ifndef IMAGE_PROCESSOR_H
#define IMAGE_PROCESSOR_H

#include <godot_cpp/classes/image.hpp>
#include <godot_cpp/classes/ref_counted.hpp>
#include <godot_cpp/core/class_db.hpp>

using namespace godot;

class ImageProcessor : public RefCounted {
    GDCLASS(ImageProcessor, RefCounted)

protected:
    static void _bind_methods();

public:
    ImageProcessor();
    ~ImageProcessor();

    Ref<Image> load_image(const String &p_path);
    bool save_image(const Ref<Image> &p_image, const String &p_path);
    Ref<Image> resize_image(const Ref<Image> &p_image, int p_width, int p_height);
    Array get_image_info(const String &p_path);
};

#endif
```

## Kode C++ (Implementasi Wrapper)

```cpp
#include "image_processor.h"
#include <godot_cpp/core/class_db.hpp>
#include <godot_cpp/variant/utility_functions.hpp>

// Include stb_image headers
#define STB_IMAGE_IMPLEMENTATION
#include "third_party/stb_image/stb_image.h"
#define STB_IMAGE_WRITE_IMPLEMENTATION
#include "third_party/stb_image/stb_image_write.h"

ImageProcessor::ImageProcessor() {
}

ImageProcessor::~ImageProcessor() {
}

void ImageProcessor::_bind_methods() {
    ClassDB::bind_method(D_METHOD("load_image", "p_path"), &ImageProcessor::load_image);
    ClassDB::bind_method(D_METHOD("save_image", "p_image", "p_path"), &ImageProcessor::save_image);
    ClassDB::bind_method(D_METHOD("resize_image", "p_image", "p_width", "p_height"), &ImageProcessor::resize_image);
    ClassDB::bind_method(D_METHOD("get_image_info", "p_path"), &ImageProcessor::get_image_info);
}

Ref<Image> ImageProcessor::load_image(const String &p_path) {
    std::string path = p_path.utf8().get_data();
    int width, height, channels;
    unsigned char *data = stbi_load(path.c_str(), &width, &height, &channels, 4);
    
    if (!data) {
        UtilityFunctions::push_error("Failed to load image: " + p_path);
        return Ref<Image>();
    }
    
    PackedByteArray byte_array;
    byte_array.resize(width * height * 4);
    memcpy(byte_array.ptrw(), data, width * height * 4);
    stbi_image_free(data);
    
    Ref<Image> image = Image::create_from_data(width, height, false, Image::FORMAT_RGBA8, byte_array);
    return image;
}

bool ImageProcessor::save_image(const Ref<Image> &p_image, const String &p_path) {
    if (p_image.is_null()) return false;
    
    PackedByteArray data = p_image->get_data();
    std::string path = p_path.utf8().get_data();
    
    return stbi_write_png(path.c_str(), p_image->get_width(), p_image->get_height(), 
                          4, data.ptr(), p_image->get_width() * 4);
}

Ref<Image> ImageProcessor::resize_image(const Ref<Image> &p_image, int p_width, int p_height) {
    if (p_image.is_null()) return Ref<Image>();
    
    Ref<Image> resized = p_image->duplicate();
    resized->resize(p_width, p_height, Image::INTERPOLATE_BILINEAR);
    return resized;
}

Array ImageProcessor::get_image_info(const String &p_path) {
    Array info;
    std::string path = p_path.utf8().get_data();
    int width, height, channels;
    
    if (stbi_info(path.c_str(), &width, &height, &channels)) {
        info.push_back(width);
        info.push_back(height);
        info.push_back(channels);
    }
    
    return info;
}
```

## Kasus Penggunaan Nyata
Integrasi library pihak ketiga sangat berguna untuk mengembangkan game dengan fitur canggih seperti pemrosesan gambar menggunakan OpenCV untuk AR/VR, simulasi fisika menggunakan Bullet Physics, atau networking menggunakan libcurl untuk HTTP requests. Studio game profesional sering mengintegrasikan middleware FMOD atau Wwise untuk audio systems yang canggih.
