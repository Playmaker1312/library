# 274. Memahami Proses Export Godot ke Berbagai Platform

## Definisi Singkat
Proses export Godot adalah mekanisme mengonversi proyek menjadi executable atau package yang dapat dijalankan di platform target seperti Windows, macOS, Linux, Android, iOS, dan Web. Setiap platform memiliki export template dan konfigurasi khusus yang harus dikonfigurasi sebelum proses build dilakukan.

## Analogi
Bayangkan kamu memiliki sebuah desain arsitektur (proyek Godot). Untuk membangun rumah di berbagai kota (platform), kamu memerlukan izin bangunan yang berbeda (export template), material yang sesuai standar lokal (konfigurasi platform), dan cara konstruksi yang tepat (export preset). Proses export adalah proses mengubah desain menjadi bangunan fisik yang siap huni di kota tujuan.

## Kode GDScript (Godot 4)
```gdscript
extends Node

@export var platform_options: Array[String] = ["Windows", "macOS", "Linux", "Android", "iOS", "Web"]

var current_platform: String = ""
var export_config: Dictionary = {}

func _ready() -> void:
    _detect_platform()
    _load_export_presets()

func _detect_platform() -> void:
    current_platform = OS.get_name()
    print("Platform terdeteksi: ", current_platform)

func _load_export_presets() -> void:
    var presets = PackedStringArray()
    for preset_key in ProjectSettings.get_property_list():
        if preset_key.name.begins_with("export/presets/"):
            presets.append(preset_key.name)
    print("Export presets tersedia: ", presets.size())

func configure_export(platform: String) -> void:
    export_config = {
        "platform": platform,
        "debug": OS.is_debug_build(),
        "encrypt_pck": false,
        "export_path": _get_export_path(platform)
    }
    print("Konfigurasi export untuk: ", platform)

func _get_export_path(platform: String) -> String:
    var paths = {
        "Windows": "res://build/game.exe",
        "macOS": "res://build/game.app",
        "Linux": "res://build/game.x86_64",
        "Android": "res://build/game.apk",
        "iOS": "res://build/game.ipa",
        "Web": "res://build/game.html"
    }
    return paths.get(platform, "res://build/game")

func start_export() -> void:
    if current_platform == "":
        print("Error: Platform tidak terdeteksi")
        return
    print("Memulai export ke ", current_platform)
    _validate_project()
    _build_project()

func _validate_project() -> void:
    var required_settings = [
        "application/config/name",
        "application/config/version"
    ]
    for setting in required_settings:
        if not ProjectSettings.has_setting(setting):
            push_warning("Setting tidak ditemukan: ", setting)

func _build_project() -> void:
    print("Build dimulai...")
    print("Export path: ", export_config.get("export_path", ""))
    print("Debug mode: ", export_config.get("debug", false))
    print("Build selesai untuk platform: ", current_platform)

func get_platform_requirements(platform: String) -> Dictionary:
    var requirements = {
        "Windows": {"min_os": "Windows 7", "architecture": "x86_64"},
        "macOS": {"min_os": "macOS 10.13", "architecture": "Universal"},
        "Linux": {"min_os": "Ubuntu 18.04", "architecture": "x86_64"},
        "Android": {"min_sdk": 21, "target_sdk": 33, "architecture": "arm64-v8a"},
        "iOS": {"min_os": "iOS 12.0", "architecture": "arm64"},
        "Web": {"browser": "HTML5", "features": "WebGL2"}
    }
    return requirements.get(platform, {})
```

## Kasus Penggunaan Nyata
Studio game indie seperti Heartbound by Pirate Software menggunakan Godot untuk export ke Windows dan Linux secara bersamaan, memungkinkan distribusi luas tanpa perlu engine alternatif. Proses export batch juga digunakan oleh studio mobile untuk merilis game secara simultan ke Google Play dan App Store dalam satu codebase.
