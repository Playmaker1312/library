# 275. Mengoptimalkan Game untuk Mobile

## Definisi Singkat
Optimasi mobile adalah proses menyesuaikan aset game termasuk tekstur, shader, dan jumlah polygon agar dapat berjalan lancar di perangkat mobile dengan keterbatasan GPU, RAM, dan baterai. Godot menyediakan export preset dan kompresi tekstur bawaan untuk membantu proses ini.

## Analogi
Bayangkan kamu akan mengadakan pesta di ruangan kecil (perangkat mobile). Kamu tidak bisa membawa semua furnitur rumah besar (aset desktop), jadi kamu harus memilih furnitur yang ringkas (tekstur terkompresi), dekorasi sederhana (shader minimal), dan jumlah kursi terbatas (batas polygon) agar pesta berjalan nyaman tanpa sesak.

## Struktur Node (Scene Tree)
```
Main (Node2D)
├── OptimasiManager (Node)
│   ├── TextureOptimizer (Node)
│   ├── ShaderOptimizer (Node)
│   └── PolygonOptimizer (Node)
├── DebugUI (CanvasLayer)
│   ├── FPSCounter (Label)
│   ├── MemoryLabel (Label)
│   └── DrawCallsLabel (Label)
└── GameWorld (Node2D)
    ├── TileMap (TileMap)
    └── Entities (Node2D)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var fps_history: Array[float] = []
var max_fps_samples: int = 60

func _ready() -> void:
    _configure_mobile_optimizations()
    _optimize_textures()
    _setup_shader_quality()

func _configure_mobile_optimizations() -> void:
    RenderingServer.viewport_set_msaa_3d(0)
    RenderingServer.viewport_set_msaa_2d(0)
    RenderingServer.viewport_set_screen_space_aa(0)
    ProjectSettings.set_setting("rendering/renderer/rendering_method", "mobile")
    ProjectSettings.set_setting("rendering/quality/filters/texture_mipmap_bias", 0.0)

func _optimize_textures() -> void:
    var texture_nodes = get_tree().get_nodes_in_group("optimizable_texture")
    for node in texture_nodes:
        if node is Sprite2D or node is TextureRect:
            _compress_texture(node)

func _compress_texture(sprite: Node) -> void:
    var viewport_size = get_viewport().get_visible_rect().size
    var target_width = int(viewport_size.x * 0.5)
    var target_height = int(viewport_size.y * 0.5)
    if sprite is Sprite2D and sprite.texture:
        var image = sprite.texture.get_image()
        if image.get_width() > target_width or image.get_height() > target_height:
            image.resize(target_width, target_height, Image.INTERPOLATE_BILINEAR)
            var compressed = ImageTexture.create_from_image(image)
            sprite.texture = compressed

func _setup_shader_quality() -> void:
    var quality_settings = {
        "use_light_2d": false,
        "max_lights_per_object": 4,
        "shadow_quality": 0,
        "particle_amount_multiplier": 0.5
    }
    for key in quality_settings:
        ProjectSettings.set_setting("rendering/quality/2d/" + key, quality_settings[key])

func get_mobile_polygon_limit() -> int:
    var quality = _detect_device_quality()
    var limits = {
        "low": 10000,
        "medium": 30000,
        "high": 60000
    }
    return limits.get(quality, 10000)

func _detect_device_quality() -> String:
    var vulkan_features = RenderingServer.get_rendering_info(RenderingServer.RENDERING_INFO_TOTAL_TEXTURE_MEM_USED)
    var ram_mb = OS.get_memory_info().get("physical", 0) / 1048576
    if ram_mb < 3000 or vulkan_features < 500000000:
        return "low"
    elif ram_mb < 6000:
        return "medium"
    return "high"

func _process(_delta: float) -> void:
    var current_fps = Engine.get_frames_per_second()
    fps_history.append(current_fps)
    if fps_history.size() > max_fps_samples:
        fps_history.pop_front()

func get_average_fps() -> float:
    if fps_history.is_empty():
        return 0.0
    var total = 0.0
    for fps in fps_history:
        total += fps
    return total / fps_history.size()

func adjust_quality_for_performance() -> void:
    var avg_fps = get_average_fps()
    if avg_fps < 30.0:
        _reduce_quality()
    elif avg_fps > 55.0:
        _increase_quality()

func _reduce_quality() -> void:
    var current_scale = RenderingServer.get_default_texture_filter()
    if current_scale == RenderingServer.TEXTURE_FILTER_NEAREST:
        RenderingServer.set_default_texture_filter(RenderingServer.TEXTURE_FILTER_NEAREST)
    ProjectSettings.set_setting("rendering/quality/driver/driver_name", "GLES2")

func _increase_quality() -> void:
    ProjectSettings.set_setting("rendering/quality/driver/driver_name", "Vulkan")
```

## Kasus Penggunaan Nyata
Game mobile populer seperti "Downwell" dan "Vampire Survivors" berhasil berjalan di device low-end karena menggunakan tekstur terkompresi dan shader sederhana. Godot sendiri digunakan untuk game mobile seperti "Dungeon Quest" yang mengoptimalkan rendering untuk device dengan RAM rendah dan GPU terbatas.
