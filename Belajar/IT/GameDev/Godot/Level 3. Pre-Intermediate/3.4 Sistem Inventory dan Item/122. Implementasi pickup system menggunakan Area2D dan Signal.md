# 122. Implementasi Pickup System Menggunakan Area2D dan Signal

## Definisi Singkat
Pickup system adalah mekanisme untuk mengambil item dari dunia game menggunakan Area2D sebagai detektor tabrakan dan Signal untuk mengirim event ketika player menyentuh item.

## Analogi
Bayangkan seperti memungut koin di jalanan: Area2D adalah lingkaran tak terlihat di sekitar koin yang memberi tahu kamu saat tangan kamu menyentuhnya, lalu Signal seperti bel yang berbunyi memberi tahu sistem inventory bahwa ada item baru masuk.

## Struktur Node (Scene Tree)
```
PickupItem (Area2D)
├── CollisionShape2D
├── Sprite2D
├── AnimationPlayer
└── item_data : ItemData

Player (CharacterBody2D)
├── CollisionShape2D
├── Sprite2D
└── InventoryManager (Node)
```

## Kode GDScript (Godot 4)
```gdscript
extends Area2D
class_name PickupItem

signal item_picked_up(item_data: ItemData)

@export var item_data: ItemData = null
@export var pickup_delay: float = 0.5

var can_pickup: bool = false
var player_in_range: Node2D = null

func _ready() -> void:
	body_entered.connect(_on_body_entered)
	body_exited.connect(_on_body_exited)
	area_entered.connect(_on_area_entered)

func _input(event: InputEvent) -> void:
	if can_pickup and event.is_action_pressed("interact"):
		pickup()

func pickup() -> void:
	if item_data == null:
		return
	item_picked_up.emit(item_data)
	queue_free()

func _on_body_entered(body: Node2D) -> void:
	if body.is_in_group("player"):
		can_pickup = true
		player_in_range = body
		show_pickup_prompt()

func _on_body_exited(body: Node2D) -> void:
	if body.is_in_group("player"):
		can_pickup = false
		player_in_range = null
		hide_pickup_prompt()

func _on_area_entered(area: Area2D) -> void:
	if area.is_in_group("player_pickup_zone"):
		can_pickup = true
		player_in_range = area.get_parent()

func show_pickup_prompt() -> void:
	pass

func hide_pickup_prompt() -> void:
	pass
```

## Kasus Penggunaan Nyata
Pickup system digunakan di hampir semua game RPG dan adventure. Contohnya di Zelda atau Skyrim, pemain berjalan melewati item di tanah dan menekan tombol untuk mengambilnya, lalu item langsung masuk ke inventory.
