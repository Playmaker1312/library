# 120. Merancang Struktur Data Inventory Menggunakan Array atau Dictionary

## Definisi Singkat
Struktur data inventory adalah cara menyimpan dan mengelola data item dalam game, menggunakan Array untuk daftar item linear atau Dictionary untuk akses berbasis key seperti slot atau jenis item.

## Analogi
Bayangkan inventory seperti lemari penyimpanan: Array adalah rak dengan urutan tetap (slot 0, 1, 2...), sedangkan Dictionary seperti laci berlabel yang bisa kamu buka langsung dengan nama labelnya (misalnya "pedang", "ramuan").

## Struktur Node (Scene Tree)
```
InventoryManager (Node)
├── items : Array[Dictionary]
├── max_slots : int = 20
└── Methods:
    ├── add_item(item_data)
    ├── remove_item(index)
    ├── get_item(index)
    └── has_item(item_id)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node
class_name InventoryManager

signal inventory_changed

var items: Array[Dictionary] = []
var max_slots: int = 20

func add_item(item_data: Dictionary) -> bool:
	if items.size() >= max_slots:
		return false
	items.append(item_data)
	inventory_changed.emit()
	return true

func remove_item(index: int) -> bool:
	if index < 0 or index >= items.size():
		return false
	items.remove_at(index)
	inventory_changed.emit()
	return true

func get_item(index: int) -> Dictionary:
	if index < 0 or index >= items.size():
		return {}
	return items[index]

func has_item(item_id: String) -> bool:
	for item in items:
		if item.get("id", "") == item_id:
			return true
	return false

func get_item_count(item_id: String) -> int:
	var count: int = 0
	for item in items:
		if item.get("id", "") == item_id:
			count += 1
	return count

func clear_inventory() -> void:
	items.clear()
	inventory_changed.emit()
```

## Kasus Penggunaan Nyata
Inventory-based game seperti RPG atau survival membutuhkan sistem penyimpanan item yang efisien. Array cocok untuk inventory dengan slot tetap seperti Minecraft, sementara Dictionary lebih fleksibel untuk game dengan banyak jenis item berbeda yang perlu diakses cepat berdasarkan ID.
