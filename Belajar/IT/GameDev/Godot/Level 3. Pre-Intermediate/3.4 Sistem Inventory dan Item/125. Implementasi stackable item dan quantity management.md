# 125. Implementasi Stackable Item dan Quantity Management

## Definisi Singkat
Stackable item adalah item yang bisa ditumpuk dalam satu slot inventory berdasarkan batas maksimum, sedangkan quantity management adalah sistem untuk mengelola jumlah item dalam setiap tumpukan.

## Analogi
Bayangkan seperti botol obat di kotak P3K: beberapa obat bisa ditumpuk dalam satu kotak (misalnya max 99 pil), tetapi obat yang berbeda jenis tidak bisa ditumpuk bersama. Quantity management seperti menghitung sisa obat di setiap botol.

## Struktur Node (Scene Tree)
```
InventoryManager (Node)
├── items : Array[Dictionary]
│   └── { "data": ItemData, "quantity": int }
├── Methods:
│   ├── add_item(item_data, amount)
│   ├── remove_item(index, amount)
│   ├── stack_item(from_index, to_index)
│   └── split_stack(index, amount)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node
class_name StackableInventory

signal inventory_changed

var items: Array[Dictionary] = []
var max_slots: int = 20

func add_item(item_data: ItemData, amount: int = 1) -> bool:
	var remaining: int = amount
	for i in range(items.size()):
		if remaining <= 0:
			break
		if items[i]["data"].item_id == item_data.item_id:
			var max_stack: int = items[i]["data"].max_stack
			var can_add: int = max_stack - items[i]["quantity"]
			var to_add: int = mini(remaining, can_add)
			items[i]["quantity"] += to_add
			remaining -= to_add
	while remaining > 0 and items.size() < max_slots:
		var stack_size: int = mini(remaining, item_data.max_stack)
		items.append({"data": item_data, "quantity": stack_size})
		remaining -= stack_size
	inventory_changed.emit()
	return remaining == 0

func remove_item(index: int, amount: int = 1) -> bool:
	if index < 0 or index >= items.size():
		return false
	items[index]["quantity"] -= amount
	if items[index]["quantity"] <= 0:
		items.remove_at(index)
	inventory_changed.emit()
	return true

func stack_item(from_index: int, to_index: int) -> bool:
	if from_index < 0 or from_index >= items.size():
		return false
	if to_index < 0 or to_index >= items.size():
		return false
	if items[from_index]["data"].item_id != items[to_index]["data"].item_id:
		return false
	var max_stack: int = items[to_index]["data"].max_stack
	var can_add: int = max_stack - items[to_index]["quantity"]
	var to_move: int = mini(items[from_index]["quantity"], can_add)
	items[to_index]["quantity"] += to_move
	items[from_index]["quantity"] -= to_move
	if items[from_index]["quantity"] <= 0:
		items.remove_at(from_index)
	inventory_changed.emit()
	return true

func split_stack(index: int, amount: int) -> bool:
	if index < 0 or index >= items.size():
		return false
	if items[index]["quantity"] <= amount:
		return false
	if items.size() >= max_slots:
		return false
	var new_stack: Dictionary = {
		"data": items[index]["data"],
		"quantity": amount
	}
	items[index]["quantity"] -= amount
	items.insert(index + 1, new_stack)
	inventory_changed.emit()
	return true

func get_item_quantity(item_id: String) -> int:
	var total: int = 0
	for item in items:
		if item["data"].item_id == item_id:
			total += item["quantity"]
	return total
```

## Kasus Penggunaan Nyata
Stackable item sangat penting di game survival seperti Don't Starve atau Rust, di mana pemain mengumpulkan banyak item dalam jumlah besar seperti kayu, batu, atau makanan. Tanpa sistem stacking, inventory akan cepat penuh hanya dengan item-item dasar.
