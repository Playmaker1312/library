# 126. Menyimpan dan Memuat Data Inventory Menggunakan Sistem Save Game

## Definisi Singkat
Sistem save game untuk inventory adalah mekanisme menyimpan data item ke file dan memuatnya kembali saat game dimulai, menggunakan JSON atau binary format untuk persistensi data.

## Analogi
Bayangkan seperti menulis daftar belanja di kertas: kamu mencatat semua item yang kamu miliki (save), lalu saat butuh kamu baca kembali catatan itu (load) untuk mengetahui apa yang harus dibeli atau disimpan.

## Struktur Node (Scene Tree)
```
SaveManager (Node)
├── save_path : String = "user://save_game.json"
├── Methods:
│   ├── save_game()
│   ├── load_game()
│   ├── save_inventory(inventory)
│   └── load_inventory() -> Array
```

## Kode GDScript (Godot 4)
```gdscript
extends Node
class_name SaveManager

signal game_saved
signal game_loaded
signal save_error(message: String)

var save_path: String = "user://save_game.json"

func save_game(data: Dictionary) -> bool:
	var file := FileAccess.open(save_path, FileAccess.WRITE)
	if file == null:
		save_error.emit("Cannot open file for writing")
		return false
	var json_string: String = JSON.stringify(data, "\t")
	file.store_string(json_string)
	file.close()
	game_saved.emit()
	return true

func load_game() -> Dictionary:
	if not FileAccess.file_exists(save_path):
		return {}
	var file := FileAccess.open(save_path, FileAccess.READ)
	if file == null:
		save_error.emit("Cannot open file for reading")
		return {}
	var json_string: String = file.get_as_text()
	file.close()
	var json := JSON.new()
	var error: int = json.parse(json_string)
	if error != OK:
		save_error.emit("JSON parse error: " + json.get_error_message())
		return {}
	return json.data

func save_inventory(inventory: StackableInventory) -> bool:
	var save_data: Dictionary = {}
	save_data["max_slots"] = inventory.max_slots
	var items_data: Array[Dictionary] = []
	for item in inventory.items:
		var item_save: Dictionary = {
			"item_id": item["data"].item_id,
			"quantity": item["quantity"]
		}
		items_data.append(item_save)
	save_data["items"] = items_data
	var game_data: Dictionary = load_game()
	game_data["inventory"] = save_data
	return save_game(game_data)

func load_inventory(inventory: StackableInventory, item_database: Dictionary) -> void:
	var game_data: Dictionary = load_game()
	if not game_data.has("inventory"):
		return
	var inv_data: Dictionary = game_data["inventory"]
	inventory.max_slots = inv_data.get("max_slots", 20)
	inventory.items.clear()
	for item_save in inv_data.get("items", []):
		var item_id: String = item_save.get("item_id", "")
		var quantity: int = item_save.get("quantity", 1)
		if item_database.has(item_id):
			var item_data: ItemData = item_database[item_id]
			inventory.items.append({"data": item_data, "quantity": quantity})
	inventory.inventory_changed.emit()

func delete_save() -> bool:
	if FileAccess.file_exists(save_path):
		DirAccess.remove_absolute(save_path)
		return true
	return false
```

## Kasus Penggunaan Nyata
Sistem save/load inventory adalah fitur krusial di game single-player seperti Skyrim atau Stardew Valley. Pemain menghabiskan waktu berjam-jam mengumpulkan item dan mengharapkan data mereka tersimpan untuk sesi berikutnya tanpa harus mulai dari awal.
