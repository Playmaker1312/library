# 123. Membuat UI Inventory Menggunakan GridContainer dan ItemList

## Definisi Singkat
UI inventory adalah antarmuka visual yang menampilkan item pemain menggunakan GridContainer untuk tata letak grid atau ItemList untuk daftar item dengan ikon dan nama.

## Analogi
UI inventory seperti etalase toko: GridContainer adalah rak dengan kotak-kotak yang rapi, dan ItemList seperti daftar belanja yang menampilkan semua item beserta fotonya secara berurutan.

## Struktur Node (Scene Tree)
```
InventoryUI (Control)
├── PanelContainer
│   ├── VBoxContainer
│   │   ├── Label (Title)
│   │   ├── GridContainer (SlotGrid)
│   │   │   ├── InventorySlot (TextureRect) x N
│   │   │   └── ...
│   │   └── ItemDetails (VBoxContainer)
│   │       ├── Label (ItemName)
│   │       ├── Label (ItemDescription)
│   │       └── Label (ItemEffects)
│   └── CloseButton (Button)
```

## Kode GDScript (Godot 4)
```gdscript
extends Control
class_name InventoryUI

signal item_selected(index: int)
signal item_used(index: int)
signal inventory_closed

@onready var slot_grid: GridContainer = %SlotGrid
@onready var item_name_label: Label = %ItemName
@onready var item_desc_label: Label = %ItemDescription
@onready var item_effects_label: Label = %ItemEffects
@onready var close_button: Button = %CloseButton

var inventory_manager: InventoryManager = null
var selected_index: int = -1

func _ready() -> void:
	visible = false
	close_button.pressed.connect(_on_close_pressed)

func open_inventory(manager: InventoryManager) -> void:
	inventory_manager = manager
	visible = true
	refresh_slots()
	get_tree().paused = true

func close_inventory() -> void:
	visible = false
	selected_index = -1
	inventory_closed.emit()
	get_tree().paused = false

func refresh_slots() -> void:
	if inventory_manager == null:
		return
	for i in range(slot_grid.get_child_count()):
		var slot: TextureRect = slot_grid.get_child(i)
		if i < inventory_manager.items.size():
			var item: Dictionary = inventory_manager.items[i]
			slot.texture = item.get("icon", null)
			slot.modulate = Color.WHITE
		else:
			slot.texture = null
			slot.modulate = Color(1, 1, 1, 0.3)

func select_slot(index: int) -> void:
	selected_index = index
	if selected_index < inventory_manager.items.size():
		var item: Dictionary = inventory_manager.items[selected_index]
		item_name_label.text = item.get("name", "Unknown")
		item_desc_label.text = item.get("description", "")
		item_effects_label.text = str(item.get("effects", {}))
		item_selected.emit(index)

func use_selected_item() -> void:
	if selected_index >= 0 and selected_index < inventory_manager.items.size():
		item_used.emit(selected_index)

func _on_close_pressed() -> void:
	close_inventory()

func _input(event: InputEvent) -> void:
	if visible and event.is_action_pressed("ui_cancel"):
		close_inventory()
```

## Kasus Penggunaan Nyata
UI inventory dengan GridContainer sangat umum di game seperti Minecraft atau Stardew Valley, di mana pemain melihat item dalam bentuk grid kotak. ItemList lebih cocok untuk game dengan banyak item yang perlu diurutkan dan difilter berdasarkan kategori.
