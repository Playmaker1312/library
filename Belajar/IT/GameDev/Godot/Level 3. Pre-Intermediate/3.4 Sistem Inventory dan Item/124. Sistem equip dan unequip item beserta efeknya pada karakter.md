# 124. Sistem Equip dan Unequip Item Beserta Efeknya pada Karakter

## Definisi Singkat
Sistem equip/unequip adalah mekanisme untuk memakai dan melepas item dari slot equipment karakter, yang secara otomatis menerapkan atau menghapus efek item tersebut.

## Analogi
Bayangkan seperti memakai dan melepas baju: saat kamu memakai jaket (equip), kamu langsung merasa hangat (efek armor). Saat melepasnya (unequip), efek hangat hilang dan kamu kembali seperti semula.

## Struktur Node (Scene Tree)
```
CharacterEquipment (Node)
├── slots : Dictionary
│   ├── "head" : null
│   ├── "body" : null
│   ├── "legs" : null
│   ├── "weapon" : null
│   └── "accessory" : null
├── signal equipment_changed(slot: String, item: ItemData)
└── signal stats_updated
```

## Kode GDScript (Godot 4)
```gdscript
extends Node
class_name CharacterEquipment

signal equipment_changed(slot: String, item_data: ItemData)
signal stats_updated

var slots: Dictionary = {
	"head": null,
	"body": null,
	"legs": null,
	"weapon": null,
	"accessory": null
}

var base_stats: Dictionary = {
	"health": 100,
	"damage": 10,
	"defense": 5,
	"speed": 100
}

var current_stats: Dictionary = base_stats.duplicate()

func equip(item_data: ItemData, slot: String) -> ItemData:
	if not slots.has(slot):
		return null
	if not item_data.is_equipable:
		return null
	var previous_item: ItemData = slots[slot]
	if previous_item != null:
		unequip(slot)
	slots[slot] = item_data
	_apply_item_effects(item_data, true)
	equipment_changed.emit(slot, item_data)
	stats_updated.emit()
	return previous_item

func unequip(slot: String) -> ItemData:
	if not slots.has(slot) or slots[slot] == null:
		return null
	var item_data: ItemData = slots[slot]
	_apply_item_effects(item_data, false)
	slots[slot] = null
	equipment_changed.emit(slot, null)
	stats_updated.emit()
	return item_data

func _apply_item_effects(item_data: ItemData, add: bool) -> void:
	for effect_key in item_data.effects.keys():
		if current_stats.has(effect_key):
			var value: int = item_data.effects[effect_key]
			if add:
				current_stats[effect_key] += value
			else:
				current_stats[effect_key] -= value

func get_stat(stat_name: String) -> int:
	return current_stats.get(stat_name, 0)

func get_equipped_item(slot: String) -> ItemData:
	return slots.get(slot, null)

func is_slot_empty(slot: String) -> bool:
	return slots.get(slot, null) == null

func get_all_equipped() -> Dictionary:
	return slots.duplicate()
```

## Kasus Penggunaan Nyata
Sistem equip/unequip adalah fitur wajib di game RPG seperti Dark Souls atau Diablo. Pemain bisa memakai berbagai jenis armor dan senjata yang memberikan bonus stats berbeda, seperti armor yang menambah defense atau pedang yang meningkatkan damage.
