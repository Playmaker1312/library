# 121. Membuat ItemData sebagai Custom Resource dengan Properti Nama, Ikon, dan Efek

## Definisi Singkat
ItemData adalah Custom Resource yang mendefinisikan properti item seperti nama, ikon, deskripsi, dan efek, memungkinkan pembuatan item baru tanpa mengubah kode utama.

## Analogi
ItemData seperti kartu identitas item: setiap item punya kartu yang berisi nama, foto (ikon), dan efek khusus. Kamu bisa membuat banyak kartu berbeda tanpa mengubah mesin cetaknya.

## Struktur Node (Scene Tree)
```
ItemData (Resource)
├── item_name : String
├── item_id : String
├── icon : Texture2D
├── description : String
├── item_type : ItemType (enum)
├── max_stack : int
├── effects : Dictionary
└── is_equipable : bool
```

## Kode GDScript (Godot 4)
```gdscript
extends Resource
class_name ItemData

enum ItemType { WEAPON, ARMOR, CONSUMABLE, QUEST, MISC }

@export var item_name: String = ""
@export var item_id: String = ""
@export var icon: Texture2D = null
@export var description: String = ""
@export var item_type: ItemType = ItemType.MISC
@export var max_stack: int = 1
@export var effects: Dictionary = {}
@export var is_equipable: bool = false

func apply_effect(target: Node) -> void:
	for effect_key in effects.keys():
		match effect_key:
			"health":
				if target.has_method("heal"):
					target.heal(effects[effect_key])
			"speed":
				if target.has_method("modify_speed"):
					target.modify_speed(effects[effect_key])
			"damage":
				if target.has_method("modify_damage"):
					target.modify_damage(effects[effect_key])

func get_tooltip() -> String:
	var tooltip_text: String = item_name + "\n"
	tooltip_text += description + "\n"
	tooltip_text += "---\n"
	for effect_key in effects.keys():
		tooltip_text += effect_key.capitalize() + ": " + str(effects[effect_key]) + "\n"
	return tooltip_text
```

## Kasus Penggunaan Nyata
Dengan Custom Resource, designer game bisa membuat item baru secara langsung di editor Godot tanpa menulis kode. Misalnya, membuat pedang dengan damage 10 atau ramuan yang mengembalikan 50 HP, semuanya hanya dengan membuat file .tres baru dari ItemData.
