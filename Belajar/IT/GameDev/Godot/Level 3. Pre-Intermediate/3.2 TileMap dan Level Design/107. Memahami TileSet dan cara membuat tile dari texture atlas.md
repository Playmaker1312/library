# 107. Memahami TileSet dan cara membuat tile dari texture atlas

## Definisi Singkat
TileSet adalah resource yang berisi kumpulan tile (gambar kecil) yang digunakan oleh TileMap untuk membangun level. Texture atlas adalah satu gambar besar yang berisi banyak tile yang dijadikan satu, lalu dipotong-potong menjadi tile individual.

## Analogi
Bayangkan kamu punya lembar stiker besar (texture atlas) yang berisi banyak gambar kecil — tanah, rumput, batu, air. TileSet seperti buku panduan yang memberitahu program: "gambar di koordinat X,Y itu adalah tanah, gambar di koordinat A,B itu adalah air." TileMap kemudian menggunakan buku panduan ini untuk menempelkan stiker-stiker tersebut ke layar secara teratur.

## Struktur Node (Scene Tree)
```
Node2D (Root)
├── TileMap
│   └── (tile-tile ditempatkan di sini secara visual)
└── TileSet (resource, bukan node — di-assign ke TileMap via inspector)
```

## Kode GDScript (Godot 4)

### Membuat TileSet dari texture atlas secara manual via code
```gdscript
extends Node2D

func _ready() -> void:
	var tileset = TileSet.new()
	tileset.tile_size = Vector2i(16, 16)

	var atlas_texture = AtlasTexture.new()
	atlas_texture.atlas = preload("res://assets/tileset_atlas.png")
	atlas_texture.region = Rect2(Vector2.ZERO, Vector2(128, 128))

	var source = TileSetAtlasSource.new()
	source.texture = atlas_texture
	source.texture_region_size = Vector2i(16, 16)

	for x in range(8):
		for y in range(8):
			source.create_tile(Vector2i(x, y))

	tileset.add_source(source, 0)
	$TileMap.tile_set = tileset
```

### Menggunakan TileMap untuk menempatkan tile
```gdscript
extends Node2D

func _ready() -> void:
	var tilemap = $TileMap
	tilemap.set_cell(0, Vector2i(0, 0), 0, Vector2i(0, 0))
	tilemap.set_cell(0, Vector2i(1, 0), 0, Vector2i(1, 0))
	tilemap.set_cell(0, Vector2i(2, 0), 0, Vector2i(2, 0))
	tilemap.set_cell(0, Vector2i(0, 1), 0, Vector2i(0, 1))
	tilemap.set_cell(0, Vector2i(1, 1), 0, Vector2i(1, 1))
	tilemap.set_cell(0, Vector2i(2, 1), 0, Vector2i(2, 1))
```

## Kasus Penggunaan Nyata
Dalam game platformer seperti Celeste, seluruh level dibangun dari tileset sederhana yang berisi tile tanah, dinding, dan dekorasi. Dengan texture atlas, artist hanya perlu mengedit satu file gambar besar alih-alih ratusan file terpisah, sehingga workflow menjadi lebih efisien dan konsisten secara visual.
