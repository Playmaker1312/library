# 108. Menggunakan TileMap layer untuk memisahkan foreground background dan collision

## Definisi Singkat
TileMap layer memungkinkan kamu memisahkan tile menjadi beberapa lapisan terpisah — background untuk elemen dekoratif belakang, gameplay untuk elemen interaktif, dan foreground untuk elemen di depan pemain. Setiap layer bisa dikontrol rendering-nya secara independen.

## Analogi
Bayangkan membuat diorama di dalam kotak kaca: layer paling belakang adalah langit dan gunung (background), layer tengah adalah bangunan dan jalan tempat karakter berjalan (gameplay), dan layer depan adalah dedaunan atau efek transparan (foreground). Kamu bisa menghidupkan/mematikan setiap layer tanpa mengganggu layer lainnya.

## Struktur Node (Scene Tree)
```
Node2D (Root)
├── TileMap
│   ├── Layer "Background" (layer 0) — rendering order paling belakang
│   ├── Layer "Gameplay" (layer 1) — tile utama + collision
│   └── Layer "Foreground" (layer 2) — rendering order paling depan
```

## Kode GDScript (Godot 4)

### Setup layer pada TileMap
```gdscript
extends Node2D

func _ready() -> void:
	var tilemap = $TileMap

	tilemap.add_layer(0)
	tilemap.set_layer_name(0, "Background")
	tilemap.set_layer_z_index(0, -10)

	tilemap.add_layer(1)
	tilemap.set_layer_name(1, "Gameplay")
	tilemap.set_layer_z_index(1, 0)

	tilemap.add_layer(2)
	tilemap.set_layer_name(2, "Foreground")
	tilemap.set_layer_z_index(2, 10)
```

### Mengisi tile pada layer berbeda
```gdscript
extends Node2D

func _ready() -> void:
	var tilemap = $TileMap

	for x in range(20):
		tilemap.set_cell(0, Vector2i(x, 8), 0, Vector2i(3, 0))

	for x in range(20):
		tilemap.set_cell(1, Vector2i(x, 10), 0, Vector2i(0, 0))
		tilemap.set_cell(1, Vector2i(x, 11), 0, Vector2i(0, 1))

	tilemap.set_cell(2, Vector2i(5, 9), 0, Vector2i(4, 2))
	tilemap.set_cell(2, Vector2i(12, 9), 0, Vector2i(4, 3))
```

### Toggle visibilitas layer
```gdscript
extends Node2D

func _process(delta: float) -> void:
	if Input.is_action_just_pressed("toggle_bg"):
		var tilemap = $TileMap
		tilemap.set_layer_enabled(0, not tilemap.is_layer_enabled(0))

	if Input.is_action_just_pressed("toggle_fg"):
		var tilemap = $TileMap
		tilemap.set_layer_enabled(2, not tilemap.is_layer_enabled(2))
```

## Kasus Penggunaan Nyata
Game platformer seperti Hollow Knight menggunakan layer terpisah untuk parallax background (langit, awan), tile gameplay (platform, dinding), dan foreground (rumput, efek partikel). Pemisahan ini memudahkan developer mengontrol rendering order dan menambahkan efek parallax tanpa mempengaruhi gameplay collision.
