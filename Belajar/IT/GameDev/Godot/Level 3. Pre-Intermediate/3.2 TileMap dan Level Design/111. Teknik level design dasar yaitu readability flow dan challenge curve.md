# 111. Teknik level design dasar yaitu readability flow dan challenge curve

## Definisi Singkat
Readability adalah kemampuan pemain membaca dan memahami level secara visual, flow adalah urutan pergerakan dan pengalaman pemain dari awal hingga akhir level, dan challenge curve adalah grafik kesulitan yang meningkat secara bertahap seiring pemain maju melalui level.

## Analogi
Bayangkan sebuah buku cerita. Readability seperti tata letak huruf yang jelas sehingga mudah dibaca. Flow seperti alur cerita yang menarik — ada pembukaan, konflik, klimaks, dan penyelesaian. Challenge curve seperti peningkatan ketegangan dalam cerita — awalnya tenang, lalu semakin seru, dan mencapai puncak di bagian akhir.

## Struktur Node (Scene Tree)
```
Node2D (Root — Level Manager)
├── TileMap (terrain utama)
├── PlayerStart (Marker2D)
├── Checkpoints (Node2D)
│   ├── Checkpoint1 (Marker2D)
│   ├── Checkpoint2 (Marker2D)
│   └── Checkpoint3 (Marker2D)
├── Enemies (Node2D)
├── Collectibles (Node2D)
└── LevelEnd (Marker2D)
```

## Kode GDScript (Godot 4)

### Level flow controller
```gdscript
extends Node2D

@export var level_name: String = "Level 1"

var checkpoints_passed: Array[int] = []
var current_difficulty: float = 0.0
var total_enemies: int = 0
var enemies_defeated: int = 0

func _ready() -> void:
	total_enemies = get_tree().get_nodes_in_group("enemies").size()
	for checkpoint in get_tree().get_nodes_in_group("checkpoints"):
		checkpoint.checkpoint_reached.connect(_on_checkpoint_reached)

func _on_checkpoint_reached(checkpoint_id: int) -> void:
	if checkpoint_id not in checkpoints_passed:
		checkpoints_passed.append(checkpoint_id)
		current_difficulty = float(checkpoints_passed.size()) / 3.0
		print("Difficulty: ", current_difficulty)

func get_challenge_multiplier() -> float:
	return 1.0 + current_difficulty * 1.5

func get_spawn_rate() -> float:
	return 2.0 - current_difficulty * 0.8

func is_flow_interrupted() -> bool:
	return checkpoints_passed.size() < 2 and current_difficulty > 0.5
```

### Readability validator
```gdscript
extends Node2D

func _ready() -> void:
	var issues = analyze_readability()
	for issue in issues:
		print("Issue: ", issue)

func analyze_readability() -> Array[String]:
	var issues: Array[String] = []
	var tilemap = $TileMap
	var used_cells = tilemap.get_used_cells(0)

	for cell in used_cells:
		var neighbors = 0
		for dir in [Vector2i(1, 0), Vector2i(-1, 0), Vector2i(0, 1), Vector2i(0, -1)]:
			if tilemap.get_cell_source_id(0, cell + dir) != -1:
				neighbors += 1

		if neighbors == 0:
			issues.append("Isolated tile at " + str(cell))

		var float_count = 0
		for dir in [Vector2i(1, 0), Vector2i(-1, 0), Vector2i(0, 1), Vector2i(0, -1)]:
			if tilemap.get_cell_source_id(0, cell + dir) == -1:
				float_count += 1

		if float_count >= 3:
			issues.append("Possible floating tile at " + str(cell))

	return issues
```

### Challenge curve calculator
```gdscript
extends Node2D

func calculate_enemy_density(position_x: float, level_width: float) -> float:
	var normalized_x = position_x / level_width
	return 1.0 + normalized_x * 2.0

func calculate_platform_gap(position_x: float, level_width: float) -> int:
	var normalized_x = position_x / level_width
	return int(2 + normalized_x * 4)

func calculate_enemy_health(enemy_global_pos: Vector2, level_start: float, level_end: float) -> int:
	var progress = (enemy_global_pos.x - level_start) / (level_end - level_start)
	return int(1.0 + progress * 3.0)

func generate_level_params() -> Dictionary:
	var level_width = 3200.0
	var params = {
		"level_width": level_width,
		"easy_zone": Vector2(0, level_width * 0.3),
		"medium_zone": Vector2(level_width * 0.3, level_width * 0.7),
		"hard_zone": Vector2(level_width * 0.7, level_width)
	}
	return params
```

## Kasus Penggunaan Nyata
Super Mario Bros menggunakan readability yang sangat baik — pemain bisa langsung membedakan platform yang bisa diinjak (tanah coklat) dari dekorasi (awan, semak). Flow level dimulai dengan area aman untuk berlatih, lalu meningkatkan kesulitan dengan gap dan musuh, dan diakhiri dengan boss atau tantangan besar di akhir level.
