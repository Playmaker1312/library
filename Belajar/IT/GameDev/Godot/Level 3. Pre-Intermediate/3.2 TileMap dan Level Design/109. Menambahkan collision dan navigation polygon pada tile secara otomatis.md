# 109. Menambahkan collision dan navigation polygon pada tile secara otomatis

## Definisi Singkat
TileSet memungkinkan kamu menambahkan collision shape dan navigation polygon pada setiap tile secara otomatis sehingga tile tidak hanya sekadar gambar, tetapi juga memiliki fungsi fisik (tabrakan) dan navigasi (pathfinding) untuk AI atau player.

## Analogi
Bayangkan kamu punya papan permainan monopoli. Tanpa collision, token pemain bisa menembus kotak-kotak. Collision shape seperti dinding tak terlihat di setiap kotak yang mencegah token melewatinya. Navigation polygon seperti jalur pejalan kaki yang memberitahu NPC "kamu bisa berjalan dari kotak A ke kotak B melewati jalur ini."

## Struktur Node (Scene Tree)
```
Node2D (Root)
├── TileMap
│   └── TileSet (resource dengan collision & navigation)
├── CharacterBody2D (Player)
│   ├── CollisionShape2D
│   └── NavigationAgent2D
└── NavigationRegion2D
    └── TileMap (untuk pathfinding)
```

## Kode GDScript (Godot 4)

### Menambahkan collision shape ke tile secara otomatis
```gdscript
extends Node2D

func _ready() -> void:
	var tileset = TileSet.new()
	tileset.tile_size = Vector2i(16, 16)
	tileset.physics_layer_add_layer()

	var source = TileSetAtlasSource.new()
	source.texture = preload("res://assets/tileset.png")
	source.texture_region_size = Vector2i(16, 16)

	for x in range(8):
		for y in range(8):
			source.create_tile(Vector2i(x, y))

	for x in range(8):
		for y in range(8):
			var physics_layer_id = 0
			source.tile_set_physics_layer_collision_type(
				0, physics_layer_id,
				PhysicsServer2D.BODY_TYPE_STATIC_BODY
			)
			var shape = RectangleShape2D.new()
			shape.size = Vector2(16, 16)
			var shape_data = TileData.new()
			shape_data.set_physics_layer_polygon(
				physics_layer_id, 0,
				PackedVector2Array([
					Vector2(-8, -8), Vector2(8, -8),
					Vector2(8, 8), Vector2(-8, 8)
				])
			)

	tileset.add_source(source, 0)
	$TileMap.tile_set = tileset
```

### Menambahkan navigation polygon ke tile
```gdscript
extends Node2D

func _ready() -> void:
	var tileset = $TileMap.tile_set

	tileset.navigation_layer_add_layer()
	var nav_layer_id = 0

	var source_id = 0
	for x in range(8):
		for y in range(8):
			var tile_data = source.get_tile_data(Vector2i(x, y))
			if tile_data:
				var nav_polygon = NavigationPolygon.new()
				nav_polygon.add_outline(PackedVector2Array([
					Vector2(-8, -8), Vector2(8, -8),
					Vector2(8, 8), Vector2(-8, 8)
				]))
				nav_polygon.make_polygons_from_outlines()
				tile_data.set_navigation_polygon(nav_layer_id, nav_polygon)
```

### Menggunakan NavigationAgent2D untuk pathfinding
```gdscript
extends CharacterBody2D

@onready var nav_agent: NavigationAgent2D = $NavigationAgent2D
var path_target: Vector2 = Vector2.ZERO

func _ready() -> void:
	nav_agent.target_desired_distance = 4.0

func set_target(target_pos: Vector2) -> void:
	path_target = target_pos
	nav_agent.target_position = target_pos

func _physics_process(delta: float) -> void:
	if nav_agent.is_navigation_finished():
		return

	var next_pos = nav_agent.get_next_path_position()
	var direction = (next_pos - global_position).normalized()
	velocity = direction * 200.0
	move_and_slide()
```

## Kasus Penggunaan Nyata
Game RPG seperti Stardew Valley menggunakan collision pada tile tanaman dan dinding agar pemain tidak bisa berjalan menembus objek. Navigation polygon memungkinkan NPC seperti petani berjalan otomatis ke ladang, kandang, atau rumah pemain tanpa tersangkut di objek-objek yang ada.
