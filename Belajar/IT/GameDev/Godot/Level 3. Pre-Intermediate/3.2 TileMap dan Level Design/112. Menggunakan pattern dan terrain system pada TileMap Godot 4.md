# 112. Menggunakan pattern dan terrain system pada TileMap Godot 4

## Definisi Singkat
Pattern adalah template tile yang bisa dipakai berulang untuk mengisi area dengan cepat. Terrain system adalah sistem otomatis yang memilih tile yang tepat berdasarkan tetangga tile di sekitarnya, sehingga tepi tanah, sudut, dan transisi antar terrain ditampilkan secara natural tanpa manual.

## Analogi
Bayangkan kamu sedang menyusun puzzle. Pattern seperti stempel — kamu tekan satu kali dan langsung muncul pola 3x3 sekaligus. Terrain system seperti puzzle yang otomatis menyesuaikan bentongannya — kalau kamu taruh tanah di sebelah rumput, otomatis muncul tile transisi yang memadukan keduanya.

## Struktur Node (Scene Tree)
```
Node2D (Root)
├── TileMap
│   └── TileSet
│       ├── Terrain Set (dengan terrain types)
│       ├── Source 0 — Ground tiles
│       ├── Source 1 — Water tiles
│       └── Source 2 — Decoration tiles
└── BrushTool (Node2D untuk custom painting)
```

## Kode GDScript (Godot 4)

### Setup terrain set pada TileSet
```gdscript
extends Node2D

func _ready() -> void:
	var tileset = TileSet.new()
	tileset.tile_size = Vector2i(16, 16)

	tileset.add_terrain_set()
	var terrain_set_id = 0

	tileset.add_terrain(terrain_set_id, "Ground")
	tileset.add_terrain(terrain_set_id, "Water")
	tileset.add_terrain(terrain_set_id, "Grass")

	var source = TileSetAtlasSource.new()
	source.texture = preload("res://assets/terrain_atlas.png")
	source.texture_region_size = Vector2i(16, 16)

	source.create_tile(Vector2i(0, 0))
	source.create_tile(Vector2i(1, 0))
	source.create_tile(Vector2i(2, 0))
	source.create_tile(Vector2i(3, 0))

	var ground_center = source.get_tile_data(Vector2i(0, 0))
	ground_center.terrain_set = terrain_set_id
	ground_center.terrain = 0
	ground_center.terrain_set_bits = 0xF

	var ground_top = source.get_tile_data(Vector2i(1, 0))
	ground_top.terrain_set = terrain_set_id
	ground_top.terrain = 0
	ground_top.terrain_set_bits = 0x3

	var ground_corner = source.get_tile_data(Vector2i(2, 0))
	ground_corner.terrain_set = terrain_set_id
	ground_corner.terrain = 0
	ground_corner.terrain_set_bits = 0x5

	var water_center = source.get_tile_data(Vector2i(3, 0))
	water_center.terrain_set = terrain_set_id
	water_center.terrain = 1
	water_center.terrain_set_bits = 0xF

	tileset.add_source(source, 0)
	$TileMap.tile_set = tileset
```

### Menggunakan terrain brush untuk painting
```gdscript
extends Node2D

func _ready() -> void:
	var tilemap = $TileMap
	tilemap.set_terrain(0, Vector2i(0, 0), 0, 0)

	var cells_to_paint = [
		Vector2i(1, 0), Vector2i(2, 0), Vector2i(3, 0),
		Vector2i(0, 1), Vector2i(1, 1), Vector2i(2, 1), Vector2i(3, 1),
		Vector2i(0, 2), Vector2i(1, 2), Vector2i(2, 2), Vector2i(3, 2),
	]

	for cell in cells_to_paint:
		tilemap.set_terrain(0, cell, 0, 0)

	var water_cells = [
		Vector2i(5, 1), Vector2i(6, 1), Vector2i(7, 1),
		Vector2i(5, 2), Vector2i(6, 2), Vector2i(7, 2),
	]

	for cell in water_cells:
		tilemap.set_terrain(0, cell, 1, 1)

	tilemap.set_cells_terrain_connect(0, cells_to_paint + water_cells, 0)
```

### Painting dengan pattern
```gdscript
extends Node2D

func paint_pattern(pattern_cells: Array[Vector2i], terrain_id: int) -> void:
	var tilemap = $TileMap
	var base_pos = Vector2i(0, 0)

	var adjusted_cells: Array[Vector2i] = []
	for cell in pattern_cells:
		adjusted_cells.append(base_pos + cell)

	tilemap.set_cells_terrain_connect(0, adjusted_cells, terrain_id)
```

### Membuat pattern custom
```gdscript
extends Node2D

func create_house_pattern() -> Array[Vector2i]:
	return [
		Vector2i(0, 0), Vector2i(1, 0), Vector2i(2, 0),
		Vector2i(0, 1), Vector2i(2, 1),
		Vector2i(0, 2), Vector2i(1, 2), Vector2i(2, 2),
		Vector2i(3, 2),
	]

func create_platform_pattern() -> Array[Vector2i]:
	return [
		Vector2i(0, 0), Vector2i(1, 0), Vector2i(2, 0),
		Vector2i(3, 0), Vector2i(4, 0),
	]

func place_pattern(pattern: Array[Vector2i], position: Vector2i, terrain_id: int) -> void:
	var tilemap = $TileMap
	var adjusted_cells: Array[Vector2i] = []
	for cell in pattern:
		adjusted_cells.append(position + cell)
	tilemap.set_cells_terrain_connect(0, adjusted_cells, terrain_id)
```

## Kasus Penggunaan Nyata
Game seperti Terraria dan Stardew Valley menggunakan terrain system secara agresif — ketika pemain menggali atau menanam, game secara otomatis memilih tile yang tepat berdasarkan tetangganya. Ini menghasilkan visual yang natural dan konsisten tanpa developer harus menempatkan setiap transisi tile secara manual.
