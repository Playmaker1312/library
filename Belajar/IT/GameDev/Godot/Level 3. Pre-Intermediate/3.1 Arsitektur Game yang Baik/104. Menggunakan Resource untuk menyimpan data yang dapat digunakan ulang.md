# 104. Menggunakan Resource untuk menyimpan data yang dapat digunakan ulang

## Definisi Singkat
Resource di Godot adalah objek data yang dapat disimpan, dimuat, dan digunakan kembali di berbagai node atau scene. Resource memisahkan data dari kode, sehingga Anda dapat mengubah properti game tanpa mengedit script.

## Analogi
Resource seperti resep masakan. Anda menulis resep sekali (membuat resource), lalu dapat digunakan oleh siapa pun untuk memasak hidangan yang sama berulang kali. Jika ingin mengubah rasa, cukup edit resepnya dan semua orang yang menggunakan resep tersebut akan mendapat hasil yang diperbarui.

## Struktur Node (Scene Tree)
```
Player
├── Sprite2D (texture: player_sprite.tres)
├── CollisionShape2D (shape: player_collision.tres)
└── Stats (script menggunakan PlayerStats.tres)
```

## Kode GDScript (Godot 4)
```gdscript
# player_stats.gd - Custom Resource
extends Resource
class_name PlayerStats

@export var max_health: int = 100
@export var move_speed: float = 200.0
@export var jump_force: float = -400.0
@export var attack_damage: int = 20
```

```gdscript
# weapon_data.gd - Custom Resource
extends Resource
class_name WeaponData

@export var weapon_name: String = "Sword"
@export var damage: int = 10
@export var attack_range: float = 50.0
@export var attack_rate: float = 0.5
@export var weapon_icon: Texture2D
@export var attack_sound: AudioStream
```

```gdscript
# enemy_stats.gd - Custom Resource
extends Resource
class_name EnemyStats

@export var enemy_name: String = "Goblin"
@export var max_health: int = 50
@export var damage: int = 5
@export var move_speed: float = 80.0

```

```gdscript
# player.gd - Menggunakan Resource
extends CharacterBody2D

@export var stats: PlayerStats

@onready var sprite: Sprite2D = $Sprite2D
@onready var health_bar: ProgressBar = $HealthBar

var current_health: int

func _ready() -> void:
    if stats:
        current_health = stats.max_health
        health_bar.max_value = stats.max_health
        health_bar.value = current_health

func take_damage(amount: int) -> void:
    current_health -= amount
    health_bar.value = current_health
    if current_health <= 0:
        queue_free()

func heal(amount: int) -> void:
    current_health = clamp(current_health + amount, 0, stats.max_health)
    health_bar.value = current_health
```

```gdscript
# weapon.gd - Menggunakan WeaponData Resource
extends Node2D

@export var weapon_data: WeaponData

var attack_timer: float = 0.0

func _ready() -> void:
    if weapon_data:
        $Sprite2D.texture = weapon_data.weapon_icon

func _process(delta: float) -> void:
    attack_timer -= delta

func attack() -> bool:
    if attack_timer > 0:
        return false
    
    if weapon_data.attack_sound:
        AudioStreamPlayer.stream = weapon_data.attack_sound
        AudioStreamPlayer.play()
    
    attack_timer = weapon_data.attack_rate
    return true

func get_damage() -> int:
    return weapon_data.damage if weapon_data else 0
```

## Kasus Penggunaan Nyata
Dalam RPG, Anda membuat Resource WeaponData untuk setiap senjata. Sword.tres memiliki damage 15, attack_range 50.0, dan sword_icon.png. Bow.tres memiliki damage 8, attack_range 200.0, dan bow_icon.png. Script Weapon.gd menggunakan data dari Resource, sehingga dapat mendukung berbagai jenis senjata tanpa kode berulang.
