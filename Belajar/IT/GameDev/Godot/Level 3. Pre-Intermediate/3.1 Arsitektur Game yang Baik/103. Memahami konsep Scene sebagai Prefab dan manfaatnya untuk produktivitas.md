# 103. Memahami konsep Scene sebagai Prefab dan manfaatnya untuk produktivitas

## Definisi Singkat
Dalam Godot, Scene dapat berfungsi sebagai Prefab (template) yang dapat diinstansiasi berulang kali. Setiap scene adalah unit komponen yang dapat digunakan kembali, sehingga Anda tidak perlu membuat objek serupa dari nol berkali-kali.

## Analogi
Scene sebagai Prefab seperti cetakan kue. Anda membuat cetakan sekali (mendesain scene), lalu dapat mencetak kue sebanyak yang dibutuhkan tanpa harus membentuk adonan dari awal setiap kali. Jika ingin mengubah bentuk kue, cukup ubah cetakannya dan semua kue baru akan mengikuti bentuk baru.

## Struktur Node (Scene Tree)
```
Root
├── Player (instanced dari player.tscn)
├── Enemies
│   ├── Enemy1 (instanced dari enemy.tscn)
│   ├── Enemy2 (instanced dari enemy.tscn)
│   └── Enemy3 (instanced dari enemy.tscn)
└── Projectiles
    ├── Bullet1 (instanced dari bullet.tscn)
    └── Bullet2 (instanced dari bullet.tscn)
```

## Kode GDScript (Godot 4)
```gdscript
# enemy_spawner.gd
extends Node2D

@export var enemy_scene: PackedScene
@export var spawn_interval: float = 2.0
@export var max_enemies: int = 10

var spawn_timer: float = 0.0
var current_enemies: int = 0

func _ready() -> void:
    spawn_timer = spawn_interval

func _process(delta: float) -> void:
    spawn_timer -= delta
    if spawn_timer <= 0 and current_enemies < max_enemies:
        spawn_enemy()
        spawn_timer = spawn_interval

func spawn_enemy() -> void:
    if not enemy_scene:
        return
    
    var enemy = enemy_scene.instantiate()
    enemy.global_position = _get_random_spawn_position()
    add_child(enemy)
    current_enemies += 1
    
    enemy.tree_exited.connect(_on_enemy_died)

func _on_enemy_died() -> void:
    current_enemies -= 1

func _get_random_spawn_position() -> Vector2:
    var spawn_points = get_tree().get_nodes_in_group("SpawnPoint")
    if spawn_points.is_empty():
        return global_position
    var random_point = spawn_points[randi() % spawn_points.size()]
    return random_point.global_position
```

```gdscript
# bullet.gd - Script yang digunakan di scene bullet.tscn
extends Area2D

@export var speed: float = 500.0
@export var damage: int = 25
var direction: Vector2 = Vector2.RIGHT

func _ready() -> void:
    body_entered.connect(_on_body_entered)

func _physics_process(delta: float) -> void:
    global_position += direction * speed * delta

func _on_body_entered(body: Node2D) -> void:
    if body.has_method("take_damage"):
        body.take_damage(damage)
    queue_free()

func setup(new_direction: Vector2, new_damage: int) -> void:
    direction = new_direction.normalized()
    damage = new_damage
    rotation = direction.angle()
```

```gdscript
# weapon.gd
extends Node2D

@export var bullet_scene: PackedScene
@export var fire_rate: float = 0.2
@export var bullet_damage: int = 25

var fire_timer: float = 0.0

func _process(delta: float) -> void:
    fire_timer -= delta

func shoot() -> void:
    if fire_timer > 0:
        return
    
    if not bullet_scene:
        return
    
    var bullet = bullet_scene.instantiate()
    bullet.global_position = $Muzzle.global_position
    bullet.setup(Vector2.RIGHT, bullet_damage)
    get_tree().current_scene.add_child(bullet)
    fire_timer = fire_rate
```

## Kasus Penggunaan Nyata
Dalam game side-scroller, Anda membuat scene Bullet.tscn sekali dengan sprite, collision, dan script. Setiap senjata dapat menginstansiasi Bullet.tscn berulang kali tanpa membuat ulang. Jika ingin menambah efek trail pada peluru, cukup edit scene Bullet.tscn dan semua peluru di game akan memiliki efek tersebut secara otomatis.
