# 106. Prinsip komposisi versus inheritance dalam desain Node Godot

## Definisi Singkat
Komposisi adalah pendekatan di mana objek dibangun dengan menggabungkan node-node kecil yang independen, sedangkan inheritance adalah pendekatan di mana objek baru dibuat dengan memperluas class yang sudah ada. Godot lebih mengarah ke komposisi melalui scene tree yang fleksibel.

## Analogi
Inheritance seperti warisan keluarga - anak mewarisi semua sifat dari orang tua, termasuk sifat yang mungkin tidak dibutuhkan. Komposisi seperti toolkit perbaikan rumah - Anda memilih alat yang dibutuhkan (palu, obeng, gergaji) dan menggabungkannya sesuai pekerjaan. Komposisi lebih fleksibel karena Anda bisa mengganti alat tanpa mengubah alat lain.

## Struktur Node (Scene Tree)
```
# Menggunakan Komposisi
Player (CharacterBody2D)
├── MovementComponent (Node)
├── HealthComponent (Node)
├── CombatComponent (Node)
├── InventoryComponent (Node)
└── AnimationComponent (Node)

# Menggunakan Inheritance
Player (CharacterBody2D)
    extends Enemy (CharacterBody2D)
        extends NPC (CharacterBody2D)
            extends CharacterBody2D
```

## Kode GDScript (Godot 4)
```gdscript
# movement_component.gd - Komponen komposisi
extends Node

@export var speed: float = 200.0
@export var acceleration: float = 1000.0

var velocity: Vector2 = Vector2.ZERO

func get_movement_input() -> Vector2:
    var input = Vector2.ZERO
    input.x = Input.get_axis("ui_left", "ui_right")
    input.y = Input.get_axis("ui_up", "ui_down")
    return input.normalized()

func update_velocity(delta: float) -> void:
    var target_velocity = get_movement_input() * speed
    velocity = velocity.move_toward(target_velocity, acceleration * delta)

func apply_to_body(body: CharacterBody2D) -> void:
    body.velocity = velocity
    body.move_and_slide()
```

```gdscript
# health_component.gd - Komponen komposisi
extends Node

signal health_changed(current: int, maximum: int)
signal died

@export var max_health: int = 100
var current_health: int
var is_invincible: bool = false

func _ready() -> void:
    current_health = max_health

func take_damage(amount: int) -> void:
    if is_invincible:
        return
    current_health = clamp(current_health - amount, 0, max_health)
    health_changed.emit(current_health, max_health)
    if current_health <= 0:
        died.emit()

func heal(amount: int) -> void:
    current_health = clamp(current_health + amount, 0, max_health)
    health_changed.emit(current_health, max_health)

func set_invincible(duration: float) -> void:
    is_invincible = true
    await get_tree().create_timer(duration).timeout
    is_invincible = false
```

```gdscript
# combat_component.gd - Komponen komposisi
extends Node

signal attacked

@export var attack_damage: int = 10
@export var attack_range: float = 50.0
@export var attack_rate: float = 0.5

var attack_timer: float = 0.0
var can_attack: bool = true

func _process(delta: float) -> void:
    attack_timer -= delta
    if attack_timer <= 0:
        can_attack = true

func attack(target: Node2D) -> bool:
    if not can_attack:
        return false
    
    if target.has_method("take_damage"):
        target.take_damage(attack_damage)
    
    attack_timer = attack_rate
    can_attack = false
    attacked.emit()
    return true

func is_in_range(target: Node2D, source: Node2D) -> bool:
    return source.global_position.distance_to(target.global_position) <= attack_range
```

```gdscript
# player.gd - Menggunakan komposisi
extends CharacterBody2D

@onready var movement: Node = $MovementComponent
@onready var health: Node = $HealthComponent
@onready var combat: Node = $CombatComponent

func _ready() -> void:
    health.died.connect(_on_died)

func _physics_process(delta: float) -> void:
    movement.update_velocity(delta)
    movement.apply_to_body(self)

func _on_died() -> void:
    queue_free()

func take_damage(amount: int) -> void:
    health.take_damage(amount)
```

```gdscript
# enemy.gd - Menggunakan komposisi yang sama
extends CharacterBody2D

@onready var movement: Node = $MovementComponent
@onready var health: Node = $HealthComponent
@onready var combat: Node = $CombatComponent

var target: Node2D = null

func _ready() -> void:
    health.died.connect(_on_died)

func _physics_process(delta: float) -> void:
    if target and combat.is_in_range(target, self):
        combat.attack(target)
    else:
        movement.update_velocity(delta)
        movement.apply_to_body(self)

func _on_died() -> void:
    queue_free()
```

## Kasus Penggunaan Nyata
Dengan komposisi, Anda membuat MovementComponent, HealthComponent, dan CombatComponent sekali. Player, Enemy, dan NPC masing-masing menggunakan komponen yang sama dengan konfigurasi berbeda. Jika ingin menambah fitur "poison" pada musuh tertentu, cukup tambahkan PoisonComponent ke scene musuh tersebut tanpa mengubah kode base enemy. Ini lebih fleksibel dari inheritance yang kaku.
