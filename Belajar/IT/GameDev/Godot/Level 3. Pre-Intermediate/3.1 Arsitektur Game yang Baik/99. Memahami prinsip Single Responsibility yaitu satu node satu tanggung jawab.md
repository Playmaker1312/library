# 99. Memahami prinsip Single Responsibility yaitu satu node satu tanggung jawab

## Definisi Singkat
Single Responsibility Principle (SRP) adalah prinsip desain di mana setiap node atau class hanya memiliki satu tanggung jawab atau alasan untuk berubah. Dalam konteks Godot, ini berarti setiap node sebaiknya hanya menangani satu fungsi spesifik.

## Analogi
Bayangkan sebuah tim dapur restoran. Koki utama tidak mencuci piring, pelayan tidak memasak, dan kasir tidak menyajikan makanan. Setiap orang memiliki peran spesifik. Jika koki harus mencuci piring, dapur akan kacau karena koki terpecah fokusnya. Sama seperti node dalam game, jika satu node melakukan terlalu banyak hal, kode menjadi sulit dirawat dan debug.

## Struktur Node (Scene Tree)
```
Player (CharacterBody2D)
├── Sprite2D
├── CollisionShape2D
├── AnimationPlayer
├── PlayerMovement (Node) - hanya menangani pergerakan
├── PlayerHealth (Node) - hanya menangani HP
└── PlayerAttack (Node) - hanya menangani serangan
```

## Kode GDScript (Godot 4)
```gdscript
# player_movement.gd - Hanya menangani pergerakan
extends Node

@export var speed: float = 200.0
var velocity: Vector2 = Vector2.ZERO

func get_input() -> Vector2:
    var input = Vector2.ZERO
    input.x = Input.get_axis("ui_left", "ui_right")
    input.y = Input.get_axis("ui_up", "ui_down")
    return input.normalized()

func update_movement(delta: float) -> void:
    velocity = get_input() * speed
```

```gdscript
# player_health.gd - Hanya menangani kesehatan
extends Node

signal health_changed(current_health: int, max_health: int)
signal died

@export var max_health: int = 100
var current_health: int

func _ready() -> void:
    current_health = max_health
    health_changed.emit(current_health, max_health)

func take_damage(amount: int) -> void:
    current_health = clamp(current_health - amount, 0, max_health)
    health_changed.emit(current_health, max_health)
    if current_health <= 0:
        died.emit()

func heal(amount: int) -> void:
    current_health = clamp(current_health + amount, 0, max_health)
    health_changed.emit(current_health, max_health)
```

```gdscript
# player_controller.gd - Mengkoordinasi node-node lain
extends CharacterBody2D

@onready var movement = $PlayerMovement
@onready var health = $PlayerHealth

func _physics_process(delta: float) -> void:
    movement.update_movement(delta)
    velocity = movement.velocity
    move_and_slide()
```

## Kasus Penggunaan Nyata
Dalam proyek game RPG, pemisahan tanggung jawab memudahkan ketika ingin mengubah sistem pertarungan tanpa mempengaruhi sistem inventaris. Developer dapat fokus pada satu bagian kode tertentu tanpa khawatir merusak fitur lain yang tidak terkait. Ini juga memudahkan testing karena setiap komponen dapat diuji secara independen.
