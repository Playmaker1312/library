# 101. Pola desain Game Manager untuk mengontrol state permainan secara keseluruhan

## Definisi Singkat
Game Manager adalah pola desain di mana satu node atau class bertanggung jawab mengelola seluruh state dan alur permainan, termasuk transisi antar level, pengelolaan skor, dan koordinasi sistem-sistem lain dalam game.

## Analogi
Game Manager seperti sutradara dalam film. Sutradara tidak berakting, tidak mengatur kamera, dan tidak mengedit video, tetapi mengontrol kapan adegan berganti, siapa yang masuk scene, dan menjaga keseluruhan cerita tetap koheren. Tanpa sutradara, aktor dan kru tidak tahu apa yang harus dilakukan.

## Struktur Node (Scene Tree)
```
Root (GameManager - Autoload)
├── StateMachine
│   ├── MainMenuState
│   ├── PlayingState
│   ├── PausedState
│   └── GameOverState
└── EventHandlers
```

## Kode GDScript (Godot 4)
```gdscript
# game_manager.gd
extends Node

signal game_state_changed(new_state: GameState)
signal level_completed(level_name: String)
signal game_over

enum GameState { MENU, PLAYING, PAUSED, GAME_OVER, VICTORY }

var current_state: GameState = GameState.MENU
var current_level: int = 0
var player_data: Dictionary = {
    "score": 0,
    "lives": 3,
    "high_score": 0
}

func _ready() -> void:
    process_mode = Node.PROCESS_MODE_ALWAYS

func change_state(new_state: GameState) -> void:
    if current_state == new_state:
        return
    
    var old_state = current_state
    current_state = new_state
    _on_state_exit(old_state)
    _on_state_enter(new_state)
    game_state_changed.emit(new_state)

func _on_state_enter(state: GameState) -> void:
    match state:
        GameState.MENU:
            get_tree().paused = false
        GameState.PLAYING:
            get_tree().paused = false
        GameState.PAUSED:
            get_tree().paused = true
        GameState.GAME_OVER:
            _handle_game_over()
        GameState.VICTORY:
            _handle_victory()

func _on_state_exit(state: GameState) -> void:
    pass

func _handle_game_over() -> void:
    if player_data["score"] > player_data["high_score"]:
        player_data["high_score"] = player_data["score"]
    game_over.emit()

func _handle_victory() -> void:
    current_level += 1

func start_game() -> void:
    player_data["score"] = 0
    player_data["lives"] = 3
    current_level = 0
    change_state(GameState.PLAYING)
    get_tree().change_scene_to_file("res://scenes/levels/level_1.tscn")

func pause_game() -> void:
    change_state(GameState.PAUSED)

func resume_game() -> void:
    change_state(GameState.PLAYING)

func add_score(points: int) -> void:
    player_data["score"] += points

func lose_life() -> void:
    player_data["lives"] -= 1
    if player_data["lives"] <= 0:
        change_state(GameState.GAME_OVER)
```

```gdscript
# level_complete_zone.gd
extends Area2D

func _on_body_entered(body: Node2D) -> void:
    if body.is_in_group("Player"):
        GameManager.add_score(500)
        GameManager.level_completed.emit(get_tree().current_scene.name)
        GameManager.change_state(GameManager.GameState.VICTORY)
```

## Kasus Penggunaan Nyata
Game Manager memungkinkan transisi level yang mulus tanpa kehilangan data. Ketika pemain mengklik "Main Lagi" di layar game over, GameManager mereset semua data dan memuat ulang level pertama. Tanpa pola ini, state game akan tersebar di banyak script dan sulit dikontrol secara konsisten.
