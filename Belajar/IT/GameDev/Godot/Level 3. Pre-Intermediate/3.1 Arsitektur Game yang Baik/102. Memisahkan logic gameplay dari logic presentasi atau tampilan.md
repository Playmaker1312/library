# 102. Memisahkan logic gameplay dari logic presentasi atau tampilan

## Definisi Singkat
Pemisahan gameplay logic dari presentation logic berarti membedakan kode yang mengatur aturan game (data, mekanik, state) dari kode yang menangani tampilan visual (sprite, animasi, efek). Ini memungkinkan logika game berjalan tanpa依赖视觉isasi.

## Analogi
Bayangkan sebuah mobil. Mesin dan transmisi (logic gameplay) bekerja sama untuk menggerakkan roda, terlepas dari warna cat mobil, desain interior, atau speaker audio (presentation). Anda bisa mengganti warna mobil tanpa mengubah cara mesin bekerja. Pemisahan ini membuat mobil mudah dimodifikasi dan diperbaiki.

## Struktur Node (Scene Tree)
```
Enemy (Node2D) [Logic Layer]
├── EnemyData (Node) [Health, damage, speed]
├── EnemyAI (Node) [Decision making]
└── EnemyVisuals (Node2D) [Presentation Layer]
    ├── Sprite2D
    ├── AnimationPlayer
    └── Particles2D
```

## Kode GDScript (Godot 4)
```gdscript
# enemy_data.gd - Logic Layer
extends Node

signal health_changed(new_health: int)
signal died

@export var max_health: int = 100
@export var damage: int = 10
@export var move_speed: float = 100.0

var current_health: int
var is_alive: bool = true

func _ready() -> void:
    current_health = max_health

func take_damage(amount: int) -> void:
    if not is_alive:
        return
    current_health = clamp(current_health - amount, 0, max_health)
    health_changed.emit(current_health)
    if current_health <= 0:
        is_alive = false
        died.emit()
```

```gdscript
# enemy_visuals.gd - Presentation Layer
extends Node2D

@onready var sprite: Sprite2D = $Sprite2D
@onready var animation_player: AnimationPlayer = $AnimationPlayer
@onready var particles: GPUParticles2D = $DeathParticles

func _on_enemy_data_health_changed(new_health: int) -> void:
    var health_percent = float(new_health) / float(owner.get_node("EnemyData").max_health)
    sprite.modulate = Color.RED.lerp(Color.WHITE, health_percent)
    animation_player.play("hurt")
    particles.emitting = true

func _on_enemy_data_died() -> void:
    animation_player.play("death")
    await animation_player.animation_finished
    queue_free()
```

```gdscript
# enemy_ai.gd - Logic Layer
extends Node

@onready var data: Node = $"../EnemyData"
@onready var visuals: Node2D = $"../EnemyVisuals"

var target: Node2D = null
var direction: Vector2 = Vector2.ZERO

func _ready() -> void:
    data.died.connect(_on_died)

func _physics_process(delta: float) -> void:
    if not data.is_alive:
        return
    if target:
        direction = (target.global_position - owner.global_position).normalized()
        owner.global_position += direction * data.move_speed * delta

func _on_died() -> void:
    set_physics_process(false)
    queue_free()

func set_target(new_target: Node2D) -> void:
    target = new_target
```

```gdscript
# main.gd - Menghubungkan logic dan presentation
extends Node2D

func spawn_enemy(position: Vector2) -> void:
    var enemy = preload("res://scenes/enemy.tscn").instantiate()
    enemy.global_position = position
    add_child(enemy)
    
    var data = enemy.get_node("EnemyData")
    var visuals = enemy.get_node("EnemyVisuals")
    
    data.health_changed.connect(visuals._on_enemy_data_health_changed)
    data.died.connect(visuals._on_enemy_data_died)
```

## Kasus Penggunaan Nyata
Ketika tim artist ingin mengganti sprite musuh dari zombie menjadi robot, mereka hanya perlu mengubah visual tanpa menyentuh kode gameplay. Begitu juga ketika programmer ingin menambah fitur "critical hit", mereka hanya mengubah script logic tanpa khawatir merusak animasi atau efek visual yang sudah ada.
