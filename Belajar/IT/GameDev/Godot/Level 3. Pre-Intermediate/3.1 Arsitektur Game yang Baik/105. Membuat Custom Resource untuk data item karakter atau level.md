# 105. Membuat Custom Resource untuk data item karakter atau level

## Definisi Singkat
Custom Resource adalah Resource yang dibuat sendiri dengan properti dan metode khusus sesuai kebutuhan game. Ini memungkinkan Anda mendefinisikan struktur data khusus untuk item, karakter, level, atau elemen game lainnya.

## Analogi
Custom Resource seperti formulir pendaftaran yang didesain khusus. Formulir pendaftaran sekolah berbeda dengan formulir pendaftaran rumah sakit. Keduanya adalah formulir (Resource), tetapi memiliki field yang berbeda sesuai kebutuhan masing-masing. Custom Resource memungkinkan Anda membuat formulir data yang tepat untuk elemen game Anda.

## Struktur Node (Scene Tree)
```
Root
├── ItemDatabase (Node) [memuat semua ItemData]
├── Player
│   ├── Inventory (Node) [menyimpan array ItemData]
│   └── Equipment (Node) [menyimpan referensi ItemData]
└── Shop (Node) [menampilkan ItemData dari database]
```

## Kode GDScript (Godot 4)
```gdscript
# item_data.gd - Base Custom Resource
extends Resource
class_name ItemData

enum ItemType { CONSUMABLE, EQUIPMENT, QUEST, CURRENCY }

@export var id: String = ""
@export var item_name: String = ""
@export var description: String = ""
@export var icon: Texture2D
@export var item_type: ItemType = ItemType.CONSUMABLE
@export var max_stack: int = 1
@export var value: int = 0
```

```gdscript
# consumable_data.gd - Custom Resource untuk item konsumabel
extends ItemData
class_name ConsumableData

@export var heal_amount: int = 0
@export var mana_amount: int = 0
@export var duration: float = 0.0
@export var buff_effect: String = ""
```

```gdscript
# equipment_data.gd - Custom Resource untuk equipment
extends ItemData
class_name EquipmentData

enum EquipSlot { HEAD, BODY, FEET, HANDS, WEAPON, SHIELD }

@export var equip_slot: EquipSlot = EquipSlot.BODY
@export var defense: int = 0
@export var attack: int = 0
@export var magic_attack: int = 0
@export var requirements: Dictionary = {
    "level": 1,
    "strength": 0,
    "intelligence": 0
}
```

```gdscript
# level_data.gd - Custom Resource untuk data level
extends Resource
class_name LevelData

@export var level_id: String = ""
@export var level_name: String = ""
@export var scene_path: String = ""
@export var recommended_level: int = 1
@export var enemy_count: int = 0
@export var boss_required: bool = false
@export var music_track: AudioStream
@export var unlock_requirements: Array[String] = []
```

```gdscript
# inventory.gd - Menggunakan Custom Resource
extends Node

signal item_added(item: ItemData)
signal item_removed(item: ItemData)
signal inventory_full

@export var max_slots: int = 20

var items: Array[ItemData] = []

func add_item(item: ItemData) -> bool:
    if items.size() >= max_slots:
        inventory_full.emit()
        return false
    
    if item.max_stack > 1:
        for existing_item in items:
            if existing_item.id == item.id:
                item_added.emit(item)
                return true
    
    items.append(item)
    item_added.emit(item)
    return true

func remove_item(item: ItemData) -> bool:
    var index = items.find(item)
    if index != -1:
        items.remove_at(index)
        item_removed.emit(item)
        return true
    return false

func get_items_by_type(item_type: ItemData.ItemType) -> Array[ItemData]:
    var filtered: Array[ItemData] = []
    for item in items:
        if item.item_type == item_type:
            filtered.append(item)
    return filtered
```

## Kasus Penggunaan Nyata
Dalam game RPG, Anda membuat ConsumableData.tres untuk Health Potion dengan heal_amount 50, dan EquipmentData.tres untuk Iron Sword dengan attack 15. Resource-resource ini disimpan sebagai file .tres dan dapat di-assign ke node tanpa hardcoding. Tim artist dapat mengedit icon dan deskripsi melalui editor tanpa menyentuh kode.
