# 143. Implementasi pause menu dengan teknik pause tree yang benar

## Definisi Singkat
Pause menu adalah UI yang muncul saat permainan dijeda. Godot memiliki fitur built-in pause tree yang membekukan semua node kecuali yang dikonfigurasi untuk tetap berjalan saat pause.

## Analogi
Pause menu seperti saat kamu menekan tombol jeda pada remote TV. Gambar berhenti bergerak, tetapi kamu masih bisa menekan tombol untuk melanjutkan atau mengatur volume. Di Godot, pause tree bekerja dengan cara yang sama.

## Struktur Node (Scene Tree)
```
Control (Root - pause_mode = PROCESS)
├── VBoxContainer
│   ├── Label ("Paused")
│   ├── Button ("Resume")
│   ├── Button ("Settings")
│   └── Button ("Quit to Menu")
└── ColorRect (Background)
```

## Kode GDScript (Godot 4)
```gdscript
extends Control

func _ready():
	process_mode = Node.PROCESS_MODE_ALWAYS
	$VBoxContainer/ResumeButton.pressed.connect(_on_resume_pressed)
	$VBoxContainer/SettingsButton.pressed.connect(_on_settings_pressed)
	$VBoxContainer/QuitButton.pressed.connect(_on_quit_pressed)
	visible = false

func _input(event):
	if event.is_action_pressed("ui_cancel"):
		toggle_pause()

func toggle_pause():
	get_tree().paused = not get_tree().paused
	visible = get_tree().paused

func _on_resume_pressed():
	toggle_pause()

func _on_settings_pressed():
	pass

func _on_quit_pressed():
	get_tree().paused = false
	get_tree().change_scene_to_file("res://scenes/main_menu.tscn")
```

## Kasus Penggunaan Nyata
Pause menu penting untuk game single-player. Contoh nyata adalah pause menu di GTA V yang menampilkan peta dan opsi pengaturan. Dengan process_mode diatur ke PROCESS_MODE_ALWAYS, pause menu tetap responsif meskipun game dalam keadaan pause.
