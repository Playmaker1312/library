# 146. Membuat dialog box dan sistem percakapan sederhana

## Definisi Singkat
Dialog box adalah UI yang menampilkan percakapan antara karakter. Sistem dialog sederhana terdiri dari panel, nama karakter, teks dialog, dan indikator untuk melanjutkan ke dialog berikutnya.

## Analogi
Dialog box seperti buku komik. Ada kotak dialog yang menampilkan teks percakapan, nama karakter di atas kotak, dan panel berisi gambar atau teks. Pemain membaca dan menekan tombol untuk melanjutkan ke panel berikutnya.

## Struktur Node (Scene Tree)
```
Control (Root)
├── PanelContainer
│   ├── VBoxContainer
│   ├── Label ("Character Name")
│   ├── Label ("Dialog Text")
│   └── Label ("[Press to continue]")
└── Timer
```

## Kode GDScript (Godot 4)
```gdscript
extends Control

var dialogs = [
	{"name": "NPC", "text": "Welcome to the village!"},
	{"name": "Player", "text": "Thanks! What can I do here?"},
	{"name": "NPC", "text": "You can explore the forest or talk to the shopkeeper."}
]
var current_dialog: int = 0
var is_typing: bool = false
var full_text: String = ""

func _ready():
	$PanelContainer/VBoxContainer/NameLabel.text = ""
	$PanelContainer/VBoxContainer/TextLabel.text = ""
	$PanelContainer/VBoxContainer/ContinueLabel.visible = false
	show_dialog()

func _input(event):
	if event.is_action_pressed("ui_accept") and not is_typing:
		current_dialog += 1
		if current_dialog < dialogs.size():
			show_dialog()
		else:
			queue_free()

func show_dialog():
	var dialog = dialogs[current_dialog]
	$PanelContainer/VBoxContainer/NameLabel.text = dialog["name"]
	full_text = dialog["text"]
	$PanelContainer/VBoxContainer/TextLabel.text = ""
	is_typing = true
	$PanelContainer/VBoxContainer/ContinueLabel.visible = false
	$Timer.start()

func _on_timer_timeout():
	if $PanelContainer/VBoxContainer/TextLabel.text.length() < full_text.length():
		$PanelContainer/VBoxContainer/TextLabel.text += full_text[$PanelContainer/VBoxContainer/TextLabel.text.length()]
	else:
		$Timer.stop()
		is_typing = false
		$PanelContainer/VBoxContainer/ContinueLabel.visible = true
```

## Kasus Penggunaan Nyata
Dialog box digunakan di RPG, visual novel, dan game petualangan. Contoh nyata adalah dialog di game Undertale atau Doki Doki Literature Club. Sistem ini memungkinkan cerita tersampaikan melalui percakapan karakter dengan cara yang interaktif.
