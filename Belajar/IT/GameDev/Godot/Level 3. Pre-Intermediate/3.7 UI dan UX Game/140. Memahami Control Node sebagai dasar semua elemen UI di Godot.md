# 140. Memahami Control Node sebagai dasar semua elemen UI di Godot

## Definisi Singkat
Control Node adalah base class untuk semua elemen UI di Godot Engine. Setiap elemen seperti Button, Label, dan TextureRect merupakan turunan dari Control Node.

## Analogi
Bayangkan Control Node seperti kertas kosong di atas meja. Semua elemen UI yang kamu buat (tombol, teks, gambar) adalah benda-benda yang ditempatkan di atas kertas tersebut. Control Node menentukan di mana dan bagaimana benda-benda itu ditempatkan.

## Struktur Node (Scene Tree)
```
Control (Root)
├── Label
├── Button
├── TextureRect
└── Panel
```

## Kode GDScript (Godot 4)
```gdscript
extends Control

func _ready():
	var label = Label.new()
	label.text = "Hello UI!"
	label.position = Vector2(100, 100)
	add_child(label)
	
	var button = Button.new()
	button.text = "Click Me"
	button.position = Vector2(100, 150)
	button.pressed.connect(_on_button_pressed)
	add_child(button)

func _on_button_pressed():
	print("Button pressed!")
```

## Kasus Penggunaan Nyata
Control Node digunakan sebagai root node untuk semua scene UI. Saat membuat menu utama, HUD, atau pause menu, kamu selalu memulai dengan Control Node sebagai parent. Ini memungkinkan anchoring dan layout management yang tepat untuk berbagai ukuran layar.
