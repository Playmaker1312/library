# 145. Menggunakan theme untuk konsistensi visual UI di seluruh game

## Definisi Singkat
Theme adalah resource yang menyimpan pengaturan visual seperti font, warna, dan style untuk semua elemen UI. Theme memastikan tampilan konsisten di seluruh game tanpa perlu mengatur setiap elemen secara manual.

## Analogi
Theme seperti seragam sekolah. Semua siswa memakai baju dengan warna dan gaya yang sama. Dengan theme, semua tombol, label, dan elemen UI akan memiliki tampilan seragam.

## Struktur Node (Scene Tree)
```
Control (Root)
├── VBoxContainer
│   ├── Button ("Normal Button")
│   ├── Button ("Styled Button")
│   └── Label ("Styled Label")
└── Theme (resource)
```

## Kode GDScript (Godot 4)
```gdscript
extends Control

func _ready():
	var theme = Theme.new()
	
	var button_style = StyleBoxFlat.new()
	button_style.bg_color = Color(0.2, 0.6, 1.0)
	button_style.corner_radius_top_left = 8
	button_style.corner_radius_top_right = 8
	button_style.corner_radius_bottom_left = 8
	button_style.corner_radius_bottom_right = 8
	theme.set_stylebox("normal", "Button", button_style)
	
	var button_hover = StyleBoxFlat.new()
	button_hover.bg_color = Color(0.3, 0.7, 1.0)
	theme.set_stylebox("hover", "Button", button_hover)
	
	var label_color = Color.WHITE
	theme.set_color("font_color", "Label", label_color)
	
	theme = theme
	$VBoxContainer/Button.add_theme_font_size_override("font_size", 20)
```

## Kasus Penggunaan Nyata
Theme digunakan untuk memastikan konsistensi visual di seluruh game. Game profesional seperti Among Us atau Hollow Knight memiliki theme khusus yang membuat semua UI terlihat seragam. Dengan theme, kamu bisa mengubah seluruh tampilan UI hanya dengan mengedit satu resource.
