# 147. Implementasi loading screen dengan progress bar antar scene

## Definisi Singkat
Loading screen adalah UI yang ditampilkan saat scene baru dimuat. Loading screen memberikan umpan balik visual kepada pemain bahwa game sedang memuat data, biasanya dengan progress bar.

## Analogi
Loading screen seperti layar tunggu saat elevator bergerak. Kamu melihat angka lantai berubah, memberi tahu kamu berapa lama lagi elevator akan sampai. Loading screen bekerja dengan cara yang sama untuk memuat scene game.

## Struktur Node (Scene Tree)
```
Control (Root)
├── ColorRect (Background)
├── VBoxContainer
│   ├── Label ("Loading...")
│   ├── ProgressBar
│   └── Label ("Tip Text")
└── Timer
```

## Kode GDScript (Godot 4)
```gdscript
extends Control

var scene_path: String = ""
var progress: float = 0.0

func _ready():
	$VBoxContainer/ProgressBar.value = 0
	$VBoxContainer/ProgressBar.max_value = 100
	$VBoxContainer/TipLabel.text = get_random_tip()

func start_loading(path: String):
	scene_path = path
	ResourceLoader.load_threaded_request(scene_path)

func _process(delta):
	if scene_path == "":
		return
	
	var load_progress = []
	ResourceLoader.load_threaded_get_status(scene_path, load_progress)
	progress = load_progress[0] * 100
	$VBoxContainer/ProgressBar.value = progress
	
	if progress >= 100:
		var scene = ResourceLoader.load_threaded_get(scene_path)
		get_tree().change_scene_to_packed(scene)

func get_random_tip() -> String:
	var tips = [
		"Press WASD to move",
		"Collect coins for extra points",
		"Avoid enemies to stay alive"
	]
	return tips[randi() % tips.size()]
```

## Kasus Penggunaan Nyata
Loading screen digunakan saat transisi antar level atau scene besar. Contoh nyata adalah loading screen di game Skyrim yang menampilkan tips dan lore saat memuat dunia terbuka. Loading screen membantu pemain memahami mekanisme game sambil menunggu.
