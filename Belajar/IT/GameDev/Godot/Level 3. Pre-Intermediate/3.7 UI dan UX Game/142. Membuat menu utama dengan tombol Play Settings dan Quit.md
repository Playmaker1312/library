# 142. Membuat menu utama dengan tombol Play Settings dan Quit

## Definisi Singkat
Menu utama adalah UI pertama yang dilihat pemain saat memulai game. Menu ini berisi tombol untuk memulai permainan, mengatur pengaturan, dan keluar dari game.

## Analogi
Menu utama seperti pintu masuk gedung. Ada beberapa pilihan pintu: pintu utama untuk masuk (Play), pintu ruang pengaturan (Settings), dan pintu keluar (Quit). Pemain memilih mana yang ingin mereka tuju.

## Struktur Node (Scene Tree)
```
Control (Root)
├── VBoxContainer
│   ├── Label ("My Game")
│   ├── Button ("Play")
│   ├── Button ("Settings")
│   └── Button ("Quit")
└── ColorRect (Background)
```

## Kode GDScript (Godot 4)
```gdscript
extends Control

@export var game_scene: String = "res://scenes/game.tscn"
@export var settings_scene: String = "res://scenes/settings.tscn"

func _ready():
	$VBoxContainer/PlayButton.pressed.connect(_on_play_pressed)
	$VBoxContainer/SettingsButton.pressed.connect(_on_settings_pressed)
	$VBoxContainer/QuitButton.pressed.connect(_on_quit_pressed)

func _on_play_pressed():
	get_tree().change_scene_to_file(game_scene)

func _on_settings_pressed():
	get_tree().change_scene_to_file(settings_scene)

func _on_quit_pressed():
	get_tree().quit()
```

## Kasus Penggunaan Nyata
Menu utama ditemukan di hampir semua game. Contoh nyata adalah menu utama Minecraft dengan tombol Singleplayer, Multiplayer, dan Options. Setiap tombol mengarah ke scene atau menu yang berbeda sesuai fungsinya.
