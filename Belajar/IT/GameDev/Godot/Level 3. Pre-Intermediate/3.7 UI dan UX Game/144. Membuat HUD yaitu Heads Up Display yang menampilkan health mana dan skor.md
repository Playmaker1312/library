# 144. Membuat HUD yaitu Heads Up Display yang menampilkan health, mana, dan skor

## Definisi Singkat
HUD (Heads Up Display) adalah UI yang menampilkan informasi penting selama permainan berlangsung tanpa mengganggu gameplay. Biasanya menampilkan health bar, mana bar, dan skor.

## Analogi
HUD seperti panel instruksi di mobil. Kamu bisa melihat kecepatan, bahan bakar, dan suhu mesin tanpa harus mengalihkan pandangan dari jalan. Begitu pula HUD game menampilkan info penting tanpa mengganggu fokus pemain.

## Struktur Node (Scene Tree)
```
CanvasLayer (Root)
├── HBoxContainer
│   ├── VBoxContainer ("Health")
│   │   ├── Label ("HP")
│   │   └── ProgressBar
│   ├── VBoxContainer ("Mana")
│   │   ├── Label ("MP")
│   │   └── ProgressBar
│   └── Label ("Score")
```

## Kode GDScript (Godot 4)
```gdscript
extends CanvasLayer

var max_health: int = 100
var current_health: int = 100
var max_mana: int = 50
var current_mana: int = 50
var score: int = 0

func _ready():
	update_health_bar()
	update_mana_bar()
	update_score()

func update_health():
	current_health = clamp(current_health, 0, max_health)
	update_health_bar()

func update_mana():
	current_mana = clamp(current_mana, 0, max_mana)
	update_mana_bar()

func add_score(value: int):
	score += value
	update_score()

func update_health_bar():
	$HBoxContainer/VBoxHealth/ProgressBar.value = current_health

func update_mana_bar():
	$HBoxContainer/VBoxMana/ProgressBar.value = current_mana

func update_score():
	$HBoxContainer/ScoreLabel.text = "Score: " + str(score)
```

## Kasus Penggunaan Nyata
HUD digunakan di hampir semua genre game. Di game RPG seperti Final Fantasy, HUD menampilkan HP, MP, dan status party. Di game FPS seperti Call of Duty, HUD menampilkan ammunition, minimap, dan crosshair. HUD membantu pemain memantau kondisi karakter tanpa membuka menu.
