# 141. Menggunakan Container seperti HBoxContainer VBoxContainer dan GridContainer

## Definisi Singkat
Container adalah type Control Node yang secara otomatis mengatur posisi dan ukuran child nodes. HBoxContainer menyusun secara horizontal, VBoxContainer secara vertikal, dan GridContainer dalam format grid.

## Analogi
Container seperti rak penyimpanan. HBoxContainer adalah rak bertingkat horizontal, VBoxContainer adalah rak bertingkat vertikal, dan GridContainer adalah rak dengan kotak-kotak seperti kisi. Kamu hanya perlu meletakkan barang dan rak akan mengatur posisinya secara otomatis.

## Struktur Node (Scene Tree)
```
VBoxContainer (Root)
├── HBoxContainer
│   ├── Label ("Name:")
│   └── LineEdit
├── HBoxContainer
│   ├── Label ("Password:")
│   └── LineEdit
└── Button ("Submit")
```

## Kode GDScript (Godot 4)
```gdscript
extends VBoxContainer

func _ready():
	var hbox1 = HBoxContainer.new()
	var label1 = Label.new()
	label1.text = "Username: "
	var line_edit1 = LineEdit.new()
	line_edit1.placeholder_text = "Enter username"
	hbox1.add_child(label1)
	hbox1.add_child(line_edit1)
	add_child(hbox1)
	
	var hbox2 = HBoxContainer.new()
	var label2 = Label.new()
	label2.text = "Password: "
	var line_edit2 = LineEdit.new()
	line_edit2.secret = true
	hbox2.add_child(label2)
	hbox2.add_child(line_edit2)
	add_child(hbox2)
	
	var button = Button.new()
	button.text = "Login"
	add_child(button)
```

## Kasus Penggunaan Nyata
Container sangat berguna untuk membuat form login, inventory grid, atau toolbar. Dengan menggunakan Container, kamu tidak perlu mengatur posisi setiap elemen secara manual. Ketika ukuran layar berubah, Container akan otomatis menyesuaikan layout tanpa perlu kode tambahan.
