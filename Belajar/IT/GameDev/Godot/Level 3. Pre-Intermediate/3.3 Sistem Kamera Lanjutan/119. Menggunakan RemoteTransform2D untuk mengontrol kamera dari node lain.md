# 119. Menggunakan RemoteTransform2D untuk mengontrol kamera dari node lain

## Definisi Singkat
RemoteTransform2D adalah node yang memungkinkan pengontrolan transformasi (posisi, rotasi, skala) dari node lain secara remote. Dalam konteks kamera, RemoteTransform2D dapat digunakan untuk mengontrol posisi kamera dari node yang berbeda, memisahkan logika pergerakan kamera dari node kamera itu sendiri.

## Analogi
Bayangkan RemoteTransform2D seperti remote control TV. TV (kamera) berada di satu lokasi, tetapi Anda dapat mengontrol saluran, volume, dan lainnya dari sofa menggunakan remote (RemoteTransform2D). Remote tidak memindahkan TV, tetapi mengontrol apa yang ditampilkan TV.

## Struktur Node (Scene Tree)
```
Level (Node2D)
├── TileMap
├── Player (CharacterBody2D)
│   ├── RemoteTransform2D
│   └── CollisionShape2D
├── Camera2D
├── Follower (PathFollow2D)
│   └── RemoteTransform2D
└── CameraPath (Path2D)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var remote_transform = $RemoteTransform2D

func _ready():
	remote_transform.remote_path = Camera2D.get_path()

func _physics_process(delta):
	var direction = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
	velocity = direction * 200
	move_and_slide()
```

```gdscript
extends PathFollow2D

@onready var remote_transform = $RemoteTransform2D

func _ready():
	remote_transform.remote_path = Camera2D.get_path()

func _process(delta):
	progress += 50 * delta
```

## Kasus Penggunaan Nyata
RemoteTransform2D sangat berguna dalam game puzzle dan adventure di mana kamera perlu mengikuti objek tertentu yang bukan pemain, seperti lift, kendaraan, atau objek yang bergerak di jalur tertentu. Dalam game seperti Inside atau Limbo, teknik ini membantu menciptakan momen sinematik tanpa mengganggu struktur scene utama.
