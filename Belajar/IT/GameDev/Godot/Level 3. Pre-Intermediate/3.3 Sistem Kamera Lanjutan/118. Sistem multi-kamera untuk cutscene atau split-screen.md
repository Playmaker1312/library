# 118. Sistem multi-kamera untuk cutscene atau split-screen

## Definisi Singkat
Sistem multi-kamera memungkinkan penggunaan lebih dari satu kamera dalam satu scene, baik untuk cutscene (perubahan sudut pandang sinematik) maupun split-screen (dua pemain melihat area berbeda secara bersamaan). Setiap kamera dapat dikontrol secara independen dan diaktifkan sesuai kebutuhan.

## Analogi
Bayangkan seperti dalam film yang menggunakan beberapa kamera sekaligus. Kamera A merekam dari sudut pandang karakter utama, kamera B dari sudut samping, dan kamera C dari udara. Sutradara memilih kamera mana yang ditampilkan pada satu waktu untuk menceritakan kisah dengan lebih dramatis.

## Struktur Node (Scene Tree)
```
Level (Node2D)
├── TileMap
├── Player1 (CharacterBody2D)
│   └── Camera2D_P1
├── Player2 (CharacterBody2D)
│   └── Camera2D_P2
├── CameraCutscene (Camera2D)
└── CutscenePath (Path2D)
    └── PathFollow2D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@onready var camera_p1 = $Player1/Camera2D_P1
@onready var camera_p2 = $Player2/Camera2D_P2
@onready var camera_cutscene = $CameraCutscene

func _ready():
	camera_p1.enabled = true
	camera_p2.enabled = false
	camera_cutscene.enabled = false

func start_split_screen():
	camera_p1.enabled = true
	camera_p1.set_anchor_preset(Control.PRESET_TOP_LEFT)
	camera_p1.set_size_preset(Control.PRESET_TOP_LEFT)
	camera_p2.enabled = true
	camera_p2.set_anchor_preset(Control.PRESET_TOP_RIGHT)
	camera_p2.set_size_preset(Control.PRESET_TOP_RIGHT)

func play_cutscene():
	camera_p1.enabled = false
	camera_p2.enabled = false
	camera_cutscene.enabled = true
```

## Kasus Penggunaan Nyata
Multi-kamera digunakan dalam game seperti Portal 2 untuk cutscene sinematik, dan game seperti Diablo 3 atau Borderlands untuk mode split-screen co-op. Dalam game horror seperti Resident Evil, multi-kamera membantu memperlihatkan sudut pandang dramatis saat peristiwa menegangkan terjadi.
