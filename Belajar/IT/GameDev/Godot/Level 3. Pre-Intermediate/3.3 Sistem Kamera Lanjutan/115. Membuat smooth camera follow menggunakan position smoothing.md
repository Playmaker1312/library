# 115. Membuat smooth camera follow menggunakan position smoothing

## Definisi Singkat
Position smoothing adalah teknik yang membuat kamera bergerak mengikuti target dengan efek tertinggal (lag) secara halus, sehingga pergerakan kamera terasa lebih natural dan tidak kaku. Godot menyediakan fitur bawaan bernama `position_smoothing_enabled` untuk menerapkan efek ini tanpa kode tambahan.

## Analogi
Bayangkan kamera seperti seekor anjing yang diikat dengan tali elastis ke pemiliknya. Ketika pemilik bergerak, anjing tidak langsung berada di posisi yang sama, tetapi bergerak mendekati secara perlahan dengan sedikit jeda, menciptakan efek mengikuti yang halus.

## Struktur Node (Scene Tree)
```
Level (Node2D)
├── TileMap
├── Player (CharacterBody2D)
│   └── Camera2D
└── Environment
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var camera = $Camera2D

func _ready():
	camera.position_smoothing_enabled = true
	camera.position_smoothing_speed = 8.0

func _physics_process(delta):
	var direction = Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
	velocity = direction * 250
	move_and_slide()
```

## Kasus Penggunaan Nyata
Smooth camera follow banyak digunakan dalam game action dan RPG seperti The Legend of Zelda atau Hollow Knight. Efek ini membuat transisi pergerakan kamera terasa lebih cinematic dan memberikan kenyamanan visual saat pemain bergerak cepat atau melakukan lompatan jarak jauh.
