# 116. Implementasi camera shake menggunakan noise atau random offset

## Definisi Singkat
Camera shake adalah efek guncangan kamera yang digunakan untuk memberikan dampak visual pada peristiwa tertentu seperti ledakan, serangan, atau gempa. Efek ini dapat dihasilkan menggunakan NoiseTexture2D untuk guncangan alami atau offset acak untuk guncangan sederhana.

## Analogi
Bayangkan seperti saat Anda memegang kamera dan tangan Anda gemetar karena terkejut oleh suara keras. Kamera bergetar sebentar sebelum kembali stabil, memberikan kesan bahwa sesuatu yang kuat telah terjadi di sekitar Anda.

## Kode GDScript (Godot 4)
```gdscript
extends Camera2D

var shake_amount: float = 0.0
var shake_decay: float = 5.0
var noise = FastNoiseLite.new()

func _ready():
	noise.noise_type = FastNoiseLite.TYPE_SIMPLEX
	noise.frequency = 0.5

func _process(delta):
	if shake_amount > 0:
		shake_amount = lerpf(shake_amount, 0, shake_decay * delta)
		offset.x = noise.get_noise_1d(Time.get_ticks_msec() * 0.01) * shake_amount
		offset.y = noise.get_noise_1d(Time.get_ticks_msec() * 0.01 + 100) * shake_amount
	else:
		offset = Vector2.ZERO

func start_shake(amount: float):
	shake_amount = amount
```

## Kasus Penggunaan Nyata
Camera shake digunakan secara luas dalam game aksi dan shooter seperti Call of Duty atau Doom untuk menggambarkan dampak tembakan atau ledakan. Dalam game indie seperti Celeste, camera shake diterapkan saat mendarat dari ketinggian atau saat terjadi peristiwa signifikan lainnya.
