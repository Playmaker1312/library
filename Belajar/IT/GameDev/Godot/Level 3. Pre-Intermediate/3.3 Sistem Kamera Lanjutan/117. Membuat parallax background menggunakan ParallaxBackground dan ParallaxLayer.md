# 117. Membuat parallax background menggunakan ParallaxBackground dan ParallaxLayer

## Definisi Singkat
ParallaxBackground dan ParallaxLayer adalah node di Godot yang memungkinkan pembuatan efek parallax scrolling di mana latar belakang bergerak dengan kecepatan berbeda berdasarkan kedalaman, menciptakan ilusi kedalaman 3D pada game 2D.

## Analogi
Bayangkan Anda sedang dalam perjalanan mobil. Pohon di tepi jalan bergerak sangat cepat, bukit di kejauhan bergerak lambat, dan gunung di cakrawala hampir tidak bergerak sama sekali. Perbedaan kecepatan gerak objek berdasarkan jarak inilah yang disebut efek parallax.

## Struktur Node (Scene Tree)
```
Level (Node2D)
├── ParallaxBackground
│   ├── ParallaxLayer (Langit)
│   └── ParallaxLayer (Bukit)
├── TileMap
├── Player (CharacterBody2D)
│   └── Camera2D
└── Foreground
```

## Kode GDScript (Godot 4)
```gdscript
extends ParallaxBackground

@onready var langit = $ParallaxLayer_Langit
@onready var bukit = $ParallaxLayer_Bukit

func _ready():
	langit.motion_scale = Vector2(0.5, 1.0)
	langit.motion_mirroring = Vector2(1920, 0)

	bukit.motion_scale = Vector2(0.3, 1.0)
	bukit.motion_mirroring = Vector2(1920, 0)
```

## Kasus Penggunaan Nyata
Parallax background digunakan dalam game platformer klasik seperti Sonic the Hedgehog dan Mega Man X untuk menciptakan kedalaman visual. Game modern seperti Ori and the Blind Forest menggunakan parallax layer kompleks dengan beberapa lapis untuk menciptakan lingkungan yang sangat imersif dan indah.
