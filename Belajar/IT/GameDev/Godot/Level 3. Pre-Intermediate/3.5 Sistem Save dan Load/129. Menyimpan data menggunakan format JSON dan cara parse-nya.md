# 129. Menyimpan data menggunakan format JSON dan cara parse-nya

## Definisi Singkat
JSON (JavaScript Object Notation) adalah format data ringan yang mudah dibaca manusia dan digunakan secara luas untuk pertukaran data. Di Godot 4, JSON dapat di-parse dan di- stringify menggunakan class JSON untuk menyimpan dan memuat data save game.

## Analogi
JSON seperti formulir isian yang terstrurat dengan rapi. Setiap kolom memiliki nama (key) dan isi (value). Sama seperti kamu mengisi formulir pendaftaran dengan nama, alamat, dan nomor telepon, JSON menyimpan data dalam pasangan key-value yang tertata.

## Struktur Node (Scene Tree)
Tidak ada struktur node spesifik untuk JSON, tetapi data yang disimpan biasanya berasal dari node-game:

```
Main (Node2D)
├── Player (CharacterBody2D)
├── EnemyContainer (Node2D)
│   ├── Enemy1 (CharacterBody2D)
│   └── Enemy2 (CharacterBody2D)
└── SaveManager (Node)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var player_data = {
    "name": "Hero",
    "level": 10,
    "health": 100,
    "max_health": 150,
    "position": {"x": 250.0, "y": 400.0},
    "inventory": [
        {"id": "sword", "quantity": 1, "durability": 85},
        {"id": "potion", "quantity": 5, "durability": 100},
        {"id": "shield", "quantity": 1, "durability": 60}
    ],
    "quests_completed": ["quest_01", "quest_02", "quest_05"],
    "play_time_seconds": 3661
}

func save_to_json():
    var json_string = JSON.stringify(player_data, "\t")
    var file = FileAccess.open("user://player_save.json", FileAccess.WRITE)
    if file:
        file.store_string(json_string)
        file.close()
        print("JSON saved!")

func load_from_json():
    if not FileAccess.file_exists("user://player_save.json"):
        print("No save file!")
        return
    
    var file = FileAccess.open("user://player_save.json", FileAccess.READ)
    if file:
        var json_string = file.get_as_text()
        file.close()
        
        var json = JSON.new()
        var error = json.parse(json_string)
        
        if error != OK:
            print("JSON Parse Error: ", json.get_error_message())
            return
        
        var loaded_data = json.data
        print("Player: ", loaded_data["name"])
        print("Level: ", loaded_data["level"])
        print("Health: ", loaded_data["health"], "/", loaded_data["max_health"])
        print("Position: ", loaded_data["position"])
        
        for item in loaded_data["inventory"]:
            print("Item: ", item["id"], " x", item["quantity"])
        
        print("Completed Quests: ", loaded_data["quests_completed"])
        print("Play Time (seconds): ", loaded_data["play_time_seconds"])

func update_json_value(key, value):
    var file = FileAccess.open("user://player_save.json", FileAccess.READ)
    if file:
        var json_string = file.get_as_text()
        file.close()
        
        var json = JSON.new()
        if json.parse(json_string) == OK:
            var data = json.data
            data[key] = value
            
            var updated_json = JSON.stringify(data, "\t")
            var write_file = FileAccess.open("user://player_save.json", FileAccess.WRITE)
            if write_file:
                write_file.store_string(updated_json)
                write_file.close()
                print("Updated ", key, " to ", value)

func _ready():
    save_to_json()
    load_from_json()
    update_json_value("level", 15)
    load_from_json()
```

## Kasus Penggunaan Nyata
JSON sangat ideal untuk save game karena formatnya mudah di-debug dan dimodifikasi. Banyak game indie menggunakan JSON untuk menyimpan progres pemain karena dapat dengan mudah diperiksa menggunakan text editor. Namun, kelemahannya adalah data tersimpan dalam format teks yang rentan dimodifikasi oleh pemain yang ingin curang.
