# 131. Menggunakan ConfigFile untuk menyimpan pengaturan game seperti volume dan resolusi

## Definisi Singkat
ConfigFile adalah class di Godot yang dirancang khusus untuk menyimpan pengaturan konfigurasi dalam format INI-like dengan section dan key-value pairs. Cocok untuk menyimpan settings game seperti volume, resolusi, dan keybindings.

## Analogi
ConfigFile seperti buku catatan dengan bab-bab terpisah. Setiap bab (section) berisi daftar catatan (key) beserta nilainya (value). Misalnya bab "Audio" berisi catatan "Master Volume" bernilai 80, bab "Video" berisi "Resolution" bernilai "1920x1080".

## Struktur Node (Scene Tree)
```
SettingsMenu (Control)
├── VBoxContainer
│   ├── AudioSection
│   │   ├── MasterVolume (HSlider)
│   │   ├── MusicVolume (HSlider)
│   │   └── SFXVolume (HSlider)
│   ├── VideoSection
│   │   ├── ResolutionOption (OptionButton)
│   │   ├── FullscreenCheck (CheckBox)
│   │   └── VSyncCheck (CheckBox)
│   └── ApplyButton (Button)
└── SettingsManager (Node)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

const SETTINGS_PATH = "user://settings.cfg"

var settings = ConfigFile.new()

var default_settings = {
    "audio": {
        "master_volume": 80,
        "music_volume": 70,
        "sfx_volume": 90
    },
    "video": {
        "resolution_width": 1920,
        "resolution_height": 1080,
        "fullscreen": false,
        "vsync": true
    },
    "gameplay": {
        "language": "id",
        "difficulty": "normal",
        "auto_save": true
    }
}

func _ready():
    load_settings()

func save_settings():
    for section in default_settings:
        for key in default_settings[section]:
            if not settings.has_section_key(section, key):
                settings.set_value(section, key, default_settings[section][key])
    
    var error = settings.save(SETTINGS_PATH)
    if error == OK:
        print("Settings saved!")
    else:
        print("Error saving settings: ", error)

func load_settings():
    for section in default_settings:
        for key in default_settings[section]:
            settings.set_value(section, key, default_settings[section][key])
    
    if FileAccess.file_exists(SETTINGS_PATH):
        var error = settings.load(SETTINGS_PATH)
        if error == OK:
            print("Settings loaded!")
        else:
            print("Error loading settings, using defaults")
    
    apply_settings()

func get_setting(section: String, key: String):
    return settings.get_value(section, key, default_settings.get(section, {}).get(key))

func set_setting(section: String, key: String, value):
    settings.set_value(section, key, value)
    apply_settings()

func apply_settings():
    var master_vol = get_setting("audio", "master_volume")
    var music_vol = get_setting("audio", "music_volume")
    var sfx_vol = get_setting("audio", "sfx_volume")
    
    var width = get_setting("video", "resolution_width")
    var height = get_setting("video", "resolution_height")
    var fullscreen = get_setting("video", "fullscreen")
    var vsync = get_setting("video", "vsync")
    
    if fullscreen:
        DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_FULLSCREEN)
    else:
        DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_WINDOWED)
        DisplayServer.window_set_size(Vector2i(width, height))
    
    if vsync:
        DisplayServer.window_set_vsync_mode(DisplayServer.VSYNC_ENABLED)
    else:
        DisplayServer.window_set_vsync_mode(DisplayServer.VSYNC_DISABLED)
    
    print("Settings applied: ", width, "x", height, " FS:", fullscreen)

func reset_to_defaults():
    settings.clear()
    for section in default_settings:
        for key in default_settings[section]:
            settings.set_value(section, key, default_settings[section][key])
    save_settings()
    apply_settings()
    print("Settings reset to defaults")

func on_master_volume_changed(value: float):
    set_setting("audio", "master_volume", int(value))

func on_resolution_changed(index: int):
    var resolutions = [
        Vector2i(1280, 720),
        Vector2i(1920, 1080),
        Vector2i(2560, 1440)
    ]
    if index >= 0 and index < resolutions.size():
        set_setting("video", "resolution_width", resolutions[index].x)
        set_setting("video", "resolution_height", resolutions[index].y)

func on_fullscreen_toggled(pressed: bool):
    set_setting("video", "fullscreen", pressed)
```

## Kasus Penggunaan Nyata
ConfigFile sangat cocok untuk menyimpan pengaturan game karena formatnya mudah diedit manual oleh pemain jika diperlukan. Game seperti Hollow Knight dan Celeste menggunakan sistem serupa untuk menyimpan preferensi audio, video, dan kontrol. File konfigurasi ini juga berguna bagi developer untuk mengatur setting default sebelum game dirilis.
