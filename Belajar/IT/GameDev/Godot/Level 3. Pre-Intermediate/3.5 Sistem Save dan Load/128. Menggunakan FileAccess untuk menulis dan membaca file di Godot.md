# 128. Menggunakan FileAccess untuk menulis dan membaca file di Godot

## Definisi Singkat
FileAccess adalah class di Godot 4 yang menyediakan cara untuk membuka, membaca, menulis, dan menutup file di sistem file. Class ini menggantikan File yang ada di Godot 3 dengan API yang lebih konsisten.

## Analogi
FileAccess seperti kunci dan gagang pintu untuk mengakses ruang penyimpanan. Kamu perlu "membuka kunci" (open) terlebih dahulu sebelum bisa memasukkan atau mengambil sesuatu dari dalam ruang penyimpanan tersebut, dan jangan lupa "mengunci kembali" (close) setelah selesai.

## Struktur Node (Scene Tree)
Tidak ada struktur node spesifik karena FileAccess adalah class utility, bukan node:

```
Node (bisa ditempatkan di node mana saja)
└── FileAccess digunakan di script
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

func write_file():
    var file = FileAccess.open("user://data.txt", FileAccess.WRITE)
    if file:
        file.store_line("Hello, Godot!")
        file.store_line("Line 2 of data")
        file.store_var(42)
        file.store_var(Vector2(100, 200))
        file.close()
        print("File written successfully!")

func read_file():
    if not FileAccess.file_exists("user://data.txt"):
        print("File does not exist!")
        return
    
    var file = FileAccess.open("user://data.txt", FileAccess.READ)
    if file:
        while not file.eof_reached():
            var line = file.get_line()
            var number = file.get_var()
            var vector = file.get_var()
            print("Line: ", line)
            print("Number: ", number)
            print("Vector: ", vector)
        file.close()

func write_binary():
    var file = FileAccess.open("user://data.bin", FileAccess.WRITE)
    if file:
        file.store_8(255)
        file.store_16(1000)
        file.store_32(100000)
        file.store_float(3.14)
        file.store_double(2.718281828)
        file.close()

func read_binary():
    var file = FileAccess.open("user://data.bin", FileAccess.READ)
    if file:
        var byte = file.get_8()
        var short = file.get_16()
        var integer = file.get_32()
        var floating = file.get_float()
        var double = file.get_double()
        print("Byte: ", byte, " Short: ", short, " Int: ", integer)
        print("Float: ", floating, " Double: ", double)
        file.close()

func check_access():
    var file = FileAccess.open("user://test.txt", FileAccess.WRITE)
    if file:
        var can_read = file.file_exists("user://test.txt")
        var size = file.get_length()
        var position = file.get_position()
        var is_eof = file.eof_reached()
        print("Exists: ", can_read, " Size: ", size)
        print("Position: ", position, " EOF: ", is_eof)
        file.close()

func _ready():
    write_file()
    read_file()
    write_binary()
    read_binary()
    check_access()
```

## Kasus Penggunaan Nyata
FileAccess sering digunakan untuk membuat sistem logging yang mencatat aktivitas game untuk debugging. Developer dapat merekam waktu, posisi pemain, dan event penting ke dalam file teks atau biner. File log ini sangat membantu saat menelusuri bug yang hanya muncul dalam kondisi tertentu atau di perangkat pemain yang berbeda.
