# 127. Memahami cara kerja save game dan format data yang umum digunakan

## Definisi Singkat
Save game adalah proses menyimpan state atau kondisi permainan ke dalam file sehingga pemain dapat melanjutkan permainan dari titik terakhir yang tersimpan. Format data menentukan bagaimana informasi tersebut diorganisasi dan disimpan di storage.

## Analogi
Bayangkan kamu sedang membaca buku dan menggunakan buku jilid untuk menandai halaman terakhir yang kamu baca. Saat kamu ingin melanjutkan, kamu cukup membuka buku di halaman yang ditandai. Save game bekerja seperti buku jilid tersebut, hanya saja yang ditandai adalah seluruh kondisi permainan (posisi pemain, item, skor, dll).

## Struktur Node (Scene Tree)
Save game tidak memiliki node spesifik, tetapi melibatkan node yang state-nya perlu disimpan:

```
Main (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   └── CollisionShape2D
├── UI (CanvasLayer)
│   └── SaveLabel (Label)
└── GameManager (Node) ← Node yang mengatur logika save/load
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var game_state: Dictionary = {}

func save_game():
    var save_data = {
        "player_position": Vector2(100, 200),
        "player_health": 85,
        "score": 15000,
        "current_level": 3,
        "inventory": ["sword", "shield", "potion"]
    }
    
    var file = FileAccess.open("user://savegame.json", FileAccess.WRITE)
    if file:
        file.store_string(JSON.stringify(save_data))
        file.close()
        print("Game saved successfully!")

func load_game():
    if not FileAccess.file_exists("user://savegame.json"):
        print("No save file found!")
        return
    
    var file = FileAccess.open("user://savegame.json", FileAccess.READ)
    if file:
        var json_string = file.get_as_text()
        file.close()
        
        var json = JSON.new()
        var error = json.parse(json_string)
        
        if error == OK:
            game_state = json.data
            print("Game loaded: ", game_state)
        else:
            print("Error parsing save file!")

func _ready():
    save_game()
    load_game()
```

## Kasus Penggunaan Nyata
Dalam game RPG seperti Skyrim atau Witcher, sistem save game menyimpan ratusan variabel termasuk posisi pemain, quest yang sudah diselesaikan, item di inventory, dan status NPC. Tanpa sistem save yang handal, pemain harus memulai dari awal setiap kali menutup game, yang membuat pengalaman bermain menjadi frustrasi dan tidak praktis.
