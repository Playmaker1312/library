# 132. Teknik auto-save dan checkpoint system dalam game

## Definisi Singkat
Auto-save adalah sistem yang secara otomatis menyimpan progres pemain pada interval atau event tertentu tanpa perlu input manual. Checkpoint system adalah titik-titik spesifik dalam level di mana pemain akan respawn jika mati atau ingin load game.

## Analogi
Auto-save seperti kamera CCTV yang merekam secara berkala, sedangkan checkpoint seperti stasiun kereta di mana kamu bisa naik atau turun. Jika kamu "tersesat" (mati dalam game), kamu cukup kembali ke stasiun terakhir (checkpoint) daripada harus pulang dari awal.

## Struktur Node (Scene Tree)
```
Level (Node2D)
├── Player (CharacterBody2D)
├── CheckpointContainer (Node2D)
│   ├── Checkpoint1 (Area2D)
│   │   ├── Sprite2D
│   │   └── CollisionShape2D
│   ├── Checkpoint2 (Area2D)
│   │   ├── Sprite2D
│   │   └── CollisionShape2D
│   └── Checkpoint3 (Area2D)
│       ├── Sprite2D
│       └── CollisionShape2D
├── AutoSaveTimer (Timer)
└── SaveManager (Node)
```

## Kode GDScript (Godot 4)
```gdscript
extends Node

var auto_save_interval: float = 300.0
var last_checkpoint_id: int = -1
var current_level: String = ""
var is_saving: bool = false

func _ready():
    var timer = Timer.new()
    timer.wait_time = auto_save_interval
    timer.one_shot = false
    timer.timeout.connect(_on_auto_save_timer)
    add_child(timer)
    timer.start()

func _on_auto_save_timer():
    if not is_saving:
        perform_auto_save()

func perform_auto_save():
    is_saving = true
    var game_state = collect_game_state()
    game_state["save_type"] = "auto_save"
    game_state["timestamp"] = Time.get_datetime_string_from_system()
    
    var file = FileAccess.open("user://autosave.json", FileAccess.WRITE)
    if file:
        file.store_string(JSON.stringify(game_state, "\t"))
        file.close()
        print("Auto-save completed at ", game_state["timestamp"])
    
    is_saving = false

func save_to_checkpoint(checkpoint_id: int):
    last_checkpoint_id = checkpoint_id
    var game_state = collect_game_state()
    game_state["save_type"] = "checkpoint"
    game_state["checkpoint_id"] = checkpoint_id
    game_state["timestamp"] = Time.get_datetime_string_from_system()
    
    var path = "user://checkpoint_%d.json" % checkpoint_id
    var file = FileAccess.open(path, FileAccess.WRITE)
    if file:
        file.store_string(JSON.stringify(game_state, "\t"))
        file.close()
        print("Checkpoint saved: ", checkpoint_id)

func load_checkpoint() -> Dictionary:
    if last_checkpoint_id == -1:
        print("No checkpoint available!")
        return {}
    
    var path = "user://checkpoint_%d.json" % last_checkpoint_id
    if FileAccess.file_exists(path):
        var file = FileAccess.open(path, FileAccess.READ)
        if file:
            var json = JSON.new()
            if json.parse(file.get_as_text()) == OK:
                file.close()
                return json.data
            file.close()
    return {}

func load_auto_save() -> Dictionary:
    if FileAccess.file_exists("user://autosave.json"):
        var file = FileAccess.open("user://autosave.json", FileAccess.READ)
        if file:
            var json = JSON.new()
            if json.parse(file.get_as_text()) == OK:
                file.close()
                return json.data
            file.close()
    return {}

func collect_game_state() -> Dictionary:
    return {
        "player_position": {"x": 0, "y": 0},
        "player_health": 100,
        "level": current_level,
        "score": 0,
        "inventory": [],
        "enemy_states": []
    }

func on_player_respawn():
    var data = load_checkpoint()
    if data.is_empty():
        data = load_auto_save()
    
    if not data.is_empty():
        apply_game_state(data)
        print("Player respawned from save")

func apply_game_state(data: Dictionary):
    print("Game state applied: ", data.get("level", "unknown"))

func _on_checkpoint_entered(checkpoint_id: int):
    save_to_checkpoint(checkpoint_id)
    show_checkpoint_notification(checkpoint_id)

func show_checkpoint_notification(id: int):
    print("Checkpoint ", id, " activated!")
```

## Kasus Penggunaan Nyata
Auto-save dan checkpoint system digunakan di game seperti Dark Souls (bonfire), Celeste (tambourine), dan Skyrim (autosave saat area baru dimasukkan). Sistem ini penting untuk mencegah kehilangan progres yang signifikan saat pemain mengalami crash atau mati dalam game. Beberapa game bahkan menggunakan save-on-exit untuk memastikan progres terakhir selalu tersimpan.
