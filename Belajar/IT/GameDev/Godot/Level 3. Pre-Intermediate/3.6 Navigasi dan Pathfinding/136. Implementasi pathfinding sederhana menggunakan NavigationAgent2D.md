# 136. Implementasi pathfinding sederhana menggunakan NavigationAgent2D

## Definisi Singkat
`NavigationAgent2D` menyediakan API untuk menghitung jalur terpendek dari posisi karakter ke posisi target secara otomatis, dengan memperhitungkan rintangan di atas `NavigationMesh`.

## Analogi
Bayangkan Anda menggunakan GPS di mobil. Anda cukup memasukkan tujuan, dan GPS akan menghitung rute terbaik. `NavigationAgent2D` bekerja persis seperti GPS untuk karakter game — cukup tentukan posisi tujuan dan biarkan agen menghitung jalurnya.

## Struktur Node (Scene Tree)
```
Enemy (CharacterBody2D)
├── NavigationAgent2D
├── Sprite2D
└── CollisionShape2D
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var nav_agent = $NavigationAgent2D

const SPEED = 150.0

func _ready():
	nav_agent.path_desired_distance = 8.0
	nav_agent.target_desired_distance = 8.0
	nav_agent.debug_enabled = true

func _physics_process(delta):
	if nav_agent.is_navigation_finished():
		return

	var next_pos = nav_agent.get_next_path_position()
	var direction = (next_pos - global_position).normalized()

	velocity = direction * SPEED

	if nav_agent.distance_to_target() < nav_agent.target_desired_distance:
		velocity = Vector2.ZERO

	move_and_slide()

func set_target(pos: Vector2):
	nav_agent.target_position = pos

func _unhandled_input(event):
	if event is InputEventMouseButton and event.pressed:
		set_target(get_global_mouse_position())
```

## Kasus Penggunaan Nyata
Implementasi ini cocok untuk game RTS (Real-Time Strategy) di mana pemain mengklik suatu titik di peta dan unit musuh atau pasukan bergerak ke posisi tersebut dengan menghindari rintangan secara otomatis tanpa perlu menulis algoritma pathfinding manual.
