# 134. Memahami konsep NavigationRegion2D dan NavigationAgent2D

## Definisi Singkat
`NavigationRegion2D` adalah node yang mendefinisikan area mana saja yang bisa dilalui oleh AI untuk berjalan, sedangkan `NavigationAgent2D` adalah node yang digunakan oleh karakter AI untuk mencari jalur terbaik menuju target.

## Analogi
Bayangkan sebuah peta labirin. `NavigationRegion2D` adalah peta itu sendiri yang menandai lorong mana yang bisa dilewati dan tembok mana yang tidak bisa. `NavigationAgent2D` adalah si pemadam kebakaran yang harus mencari jalur tercepat dari pintu masuk ke posisi korban tanpa menabrak tembok.

## Struktur Node (Scene Tree)
```
MainScene (Node2D)
├── Player (CharacterBody2D)
├── Enemy (CharacterBody2D)
│   └── NavigationAgent2D
├── NavigationRegion2D
│   └── NavigationPolygonInstance
└── TileMap
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var nav_agent = $NavigationAgent2D

func _ready():
	nav_agent.path_desired_distance = 4.0
	nav_agent.target_desired_distance = 4.0

func _physics_process(delta):
	if nav_agent.is_navigation_finished():
		return

	var next_path_position = nav_agent.get_next_path_position()
	var direction = (next_path_position - global_position).normalized()
	velocity = direction * 200.0
	move_and_slide()

func set_target_position(target_pos: Vector2):
	nav_agent.target_position = target_pos
```

## Kasus Penggunaan Nyata
`NavigationRegion2D` dan `NavigationAgent2D` digunakan pada game RPG atau strategy untuk menggerakkan NPC agar berjalan mengikuti jalan di peta tanpa menabrak dinding atau objek. Misalnya, musuh dalam game tower defense yang bergerak mengikuti jalur tertentu dari spawn hingga base pemain.
