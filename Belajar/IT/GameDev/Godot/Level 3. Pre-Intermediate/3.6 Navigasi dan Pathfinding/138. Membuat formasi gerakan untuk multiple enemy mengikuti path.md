# 138. Membuat formasi gerakan untuk multiple enemy mengikuti path

## Definisi Singkat
Formasi gerakan adalah teknik di mana beberapa karakter AI bergerak secara bersamaan dalam pola tertentu (baris, segitiga, atau lingkaran) menuju target yang sama tanpa saling bertabrakan.

## Analogi
Bayangkan sekelompok tentara berbaris. Setiap prajurit memiliki posisi awal yang berbeda, tetapi mereka semua berjalan dalam formasi tertentu menuju medan perang. Meskipun rutenya berbeda-beda, mereka tetap menjaga posisi dalam barisan.

## Struktur Node (Scene Tree)
```
EnemyFormation (Node2D)
├── Enemy1 (CharacterBody2D)
│   └── NavigationAgent2D
├── Enemy2 (CharacterBody2D)
│   └── NavigationAgent2D
├── Enemy3 (CharacterBody2D)
│   └── NavigationAgent2D
└── Enemy4 (CharacterBody2D)
    └── NavigationAgent2D
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

@export var formation_target: Vector2 = Vector2.ZERO

var formation_offsets = [
	Vector2(0, 0),
	Vector2(32, 32),
	Vector2(-32, 32),
	Vector2(0, 64)
]

var enemies: Array[CharacterBody2D] = []

func _ready():
	for child in get_children():
		if child is CharacterBody2D:
			enemies.append(child)

func _unhandled_input(event):
	if event is InputEventMouseButton and event.pressed:
		formation_target = get_global_mouse_position()
		update_formation_targets()

func update_formation_targets():
	for i in range(enemies.size()):
		var enemy = enemies[i]
		var nav_agent = enemy.get_node("NavigationAgent2D")
		var offset = formation_offsets[i]
		nav_agent.target_position = formation_target + offset

func _physics_process(delta):
	for enemy in enemies:
		var nav_agent = enemy.get_node("NavigationAgent2D")
		if nav_agent.is_navigation_finished():
			enemy.velocity = Vector2.ZERO
			continue

		var next_pos = nav_agent.get_next_path_position()
		var direction = (next_pos - enemy.global_position).normalized()
		enemy.velocity = direction * 120.0
		enemy.move_and_slide()
```

## Kasus Penggunaan Nyata
Formasi gerakan digunakan dalam game RTS seperti Age of Empires atau StarCraft, di mana pasukan bergerak dalam formasi tertentu menuju titik yang diklik pemain. Formasi memastikan pasukan tetap terorganisir dan tidak menyebar secara acak saat bergerak.
