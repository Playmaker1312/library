# 139. Dynamic obstacle dan cara memperbarui navigation mesh secara runtime

## Definisi Singkat
`NavigationObstacle2D` adalah node yang dapat memblokir jalur navigasi secara dinamis saat runtime. Obstacle ini akan otomatis mempengaruhi jalur yang dihitung oleh `NavigationAgent2D` tanpa perlu membuat ulang seluruh navigation mesh.

## Analogi
Bayangkan sebuah jalur pedestrian yang ramai. Ketika ada pohon tumbang atau kendaraan parkir di tengah jalan, pejalan kaki akan secara otomatis menghindarinya dan mencari jalan lain. `NavigationObstacle2D` bekerja seperti pohon tumbang tersebut — memblokir jalur dan memaksa agen mencari rute alternatif.

## Struktur Node (Scene Tree)
```
MainScene (Node2D)
├── NavigationRegion2D
├── Player (CharacterBody2D)
│   └── NavigationAgent2D
├── DynamicObstacle (CharacterBody2D)
│   ├── NavigationObstacle2D
│   ├── Sprite2D
│   └── CollisionShape2D
└── Timer (Timer)
```

## Kode GDScript (Godot 4)
```gdscript
extends CharacterBody2D

@onready var nav_agent = $NavigationAgent2D
@onready var obstacle = $NavigationObstacle2D
@onready var timer = $Timer

const SPEED = 160.0

var move_direction = Vector2.RIGHT

func _ready():
	obstacle avoidance_enabled = true
	obstacle.radius = 16.0
	timer.timeout.connect(_on_timer_timeout)
	timer.wait_time = 2.0
	timer.start()

func _physics_process(delta):
	if nav_agent.is_navigation_finished():
		velocity = Vector2.ZERO
		return

	var next_pos = nav_agent.get_next_path_position()
	var direction = (next_pos - global_position).normalized()

	obstacle.velocity = velocity

	velocity = direction * SPEED
	move_and_slide()

func _on_timer_timeout():
	var random_offset = Vector2(
		randf_range(-300, 300),
		randf_range(-300, 300)
	)
	var new_target = global_position + random_offset
	nav_agent.target_position = new_target
	timer.start()
```

## Kasus Penggunaan Nyata
`NavigationObstacle2D` sangat berguna dalam game survival atau action di mana elemen lingkungan berubah secara dinamis. Misalnya, ketika pemain menjatuhkan peti kayu atau mengaktifkan jebakan yang menghalangi jalur musuh, obstacle akan otomatis memblokir area tersebut dan memaksa AI musuh mencari jalan lain.
