# 137. Menggunakan AStar2D untuk pathfinding kustom berbasis grid

## Definisi Singkat
`AStar2D` adalah implementasi algoritma A* (A-star) untuk pathfinding berbasis grid yang memungkinkan kontrol penuh atas cara node dihubungkan dan bagaimana jalur dihitung.

## Analogi
Bayangkan sebuah peta kota dengan persimpangan jalan. Setiap persimpangan adalah titik (node), dan jalan di antara persimpangan adalah jalur. `AStar2D` seperti tukang ojek yang tahu semua jalan tikus dan selalu memilih jalur tercepat dari lokasi Anda ke tujuan.

## Struktur Node (Scene Tree)
```
GridMap (Node2D)
└── TileMap
```

## Kode GDScript (Godot 4)
```gdscript
extends Node2D

const GRID_SIZE = Vector2i(16, 12)
const TILE_SIZE = 32

var astar = AStar2D.new()

func _ready():
	for x in range(GRID_SIZE.x):
		for y in range(GRID_SIZE.y):
			var point_id = Vector2i(x, y)
			var point_pos = Vector2(x, y) * TILE_SIZE + Vector2(TILE_SIZE / 2, TILE_SIZE / 2)
			astar.add_point(point_id, point_pos)

	for x in range(GRID_SIZE.x):
		for y in range(GRID_SIZE.y):
			var current = Vector2i(x, y)
			var neighbors = [
				Vector2i(x + 1, y),
				Vector2i(x - 1, y),
				Vector2i(x, y + 1),
				Vector2i(x, y - 1)
			]
			for neighbor in neighbors:
				if astar.has_point(neighbor) and not astar.has_point_between_points(current, neighbor):
					astar.connect_points(current, neighbor, false)

func find_path(start_pos: Vector2, end_pos: Vector2) -> PackedVector2Array:
	var start_id = Vector2i(start_pos / TILE_SIZE)
	var end_id = Vector2i(end_pos / TILE_SIZE)

	if not astar.has_point(start_id) or not astar.has_point(end_id):
		return PackedVector2Array()

	return PackedVector2Array(astar.get_point_path(start_id, end_id))
```

## Kasus Penggunaan Nyata
`AStar2D` sangat cocok untuk game puzzle, tower defense, atau game berbasis grid lainnya di mana Anda membutuhkan kontrol penuh atas koneksi antar titik. Misalnya, musuh pada game dungeon crawler yang bergerak kotak per kotak menghindari dinding peta.
