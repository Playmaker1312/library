# Model Memori Atkinson-Shiffrin - Sensory, Short-Term, Long-Term Memory

## Penjelasan
- Model memori Atkinson-Shiffrin (1968), juga dikenal sebagai modal model atau multi-store model, mengusulkan bahwa memori terdiri dari tiga sistem penyimpanan yang terpisah: sensory memory, short-term memory (STM), dan long-term memory (LTM).
- Sensory memory: menyimpan informasi sensorik dalam waktu sangat singkat (kurang dari 1 detik untuk visual, 2-4 detik untuk auditori). Fungsinya menahan informasi cukup lama untuk diproses lebih lanjut. Kapasitasnya besar tetapi durasi sangat pendek.
- Short-term memory: menyimpan informasi yang kita sadari secara aktif. Kapasitas terbatas (sekitar 7±2 item—Miller's Law) dan durasi terbatas (sekitar 15-30 detik tanpa rehearsal). Informasi bisa hilang karena decay atau displacement.
- Long-term memory: menyimpan informasi dalam kapasitas tak terbatas dan durasi yang sangat panjang (dari menit hingga seumur hidup). Informasi yang masuk ke LTM melalui proses encoding dan konsolidasi.
- Aliran informasi: informasi dari lingkungan masuk ke sensory memory, jika diperhatikan (attention) masuk ke STM, jika dielaborasi (elaborative rehearsal) masuk ke LTM. Retrieval mengambil informasi dari LTM kembali ke STM saat dibutuhkan.
- Model ini kemudian direvisi oleh berbagai peneliti, termasuk penggantian STM dengan working memory (Baddeley, file 76) yang lebih kompleks.

## Fungsi
Model ini menyediakan kerangka konseptual untuk memahami bagaimana informasi diproses oleh sistem memori manusia. Ini menjelaskan mengapa kita bisa mengingat beberapa hal tetapi melupakan yang lain—tergantung pada seberapa banyak perhatian dan elaborasi yang diberikan. Model ini juga menjadi dasar bagi banyak penelitian tentang memori dan membantu mengidentifikasi di mana kegagalan memori terjadi.

## Contoh Sehari-hari
- Sensory memory: Saat menyalakan korek api, Anda masih melihat jejak cahaya sesaat setelah api padam. Atau, Anda masih mendengar gema kata-kata beberapa detik setelah seseorang selesai berbicara.
- Short-term memory: Mengingat nomor telepon yang baru saja Anda dengar cukup lama untuk menekan tombol telepon. Jika terganggu, Anda lupa nomornya.
- Long-term memory: Mengingat nama guru SD Anda, alamat rumah masa kecil, atau cara mengendarai sepeda.

## Analogi (Taman & Berkebun)
Taman memiliki tiga area penyimpanan. Sensory memory seperti gerbang taman: setiap pengunjung (informasi) melewatinya sebentar, hanya cukup untuk melihat sekilas apakah mereka menarik atau tidak. Sebagian besar lewat tanpa jejak. Short-term memory seperti meja kerja tukang kebun di gudang—hanya bisa menampung beberapa alat sekaligus (7±2 item). Alat-alat ini yang sedang digunakan secara aktif. Jika ada alat baru datang, alat lama harus diletakkan. Tanpa pengulangan (rehearsal), alat-alat itu berdebu dan dilupakan. Long-term memory seperti gudang penyimpanan besar di belakang taman—bisa menyimpan ribuan benih, alat, pupuk, catatan, foto, dan kenangan taman. Kapasitasnya tak terbatas. Benih yang ditanam dengan hati-hati (elaborative rehearsal) akan tersimpan rapi dan bisa diambil kapan saja. Tukang kebun yang efisien tahu bahwa tidak semua informasi layak masuk gudang—hanya yang benar-benar penting dan dielaborasi dengan baik.

## Kegunaan
Model Atkinson-Shiffrin mengajarkan strategi belajar efektif: untuk memasukkan informasi ke LTM, kita perlu memberi perhatian penuh (attention) dan melakukan elaborasi. Teknik rehearsal (pengulangan) saja tidak cukup—harus ada elaborasi yang bermakna. Model ini juga membantu mendiagnosis masalah memori: apakah kegagalan terjadi di sensory (tidak mendengar dengan baik), STM (tidak memperhatikan), atau LTM (gagal menyimpan atau mengambil).

## Kesalahan Umum
Menganggap ketiga penyimpanan sebagai lokasi fisik di otak yang terpisah—padahal ini adalah model konseptual. Juga mengira bahwa kapasitas STM tepat 7 item yang absolut—padahal bisa bervariasi dengan chunking. Kesalahan lain: menganggap LTM permanen dan tidak bisa berubah—padahal LTM bisa berubah, direkonstruksi, dan bahkan dilupakan.

## Hubungan dengan Materi Sebelumnya
Modul 7 membahas berbagai bentuk belajar. Setelah belajar terjadi, informasi harus disimpan agar bisa digunakan kembali—inilah fungsi memori. Model Atkinson-Shiffrin adalah kerangka dasar untuk memahami bagaimana informasi dari pengalaman belajar (classical conditioning, operant conditioning, observational learning) disimpan dalam memori. Hubungan ke file 75: sensory memory akan diperdalam, file 76: short-term memory akan direvisi menjadi working memory, dan file 77-79 akan membahas encoding dan jenis LTM.

2. Berapa kapasitas short-term memory menurut Miller? Jawaban: 7 plus minus 2 item (7±2).
