# Sensory Memory - Iconic dan Echoic Memory

## Penjelasan
- Sensory memory adalah tahap pertama dalam sistem memori yang menahan informasi sensorik dalam waktu sangat singkat setelah stimulus fisik berakhir. Fungsinya memberi waktu bagi otak untuk memproses informasi yang masuk sebelum memutuskan apakah informasi itu penting atau tidak.
- Iconic memory (memori ikonik) adalah sensory memory untuk informasi visual. Durasi sangat singkat, sekitar 250-500 milidetik (setengah detik). George Sperling (1960) membuktikan keberadaannya melalui eksperimen dengan menampilkan susunan huruf selama 50 milidetik.
- Dalam eksperimen Sperling, partisipan yang diminta melaporkan semua huruf (whole report) hanya bisa mengingat 3-4 huruf. Namun, dengan partial report method (nada tinggi/sedang/rendah menandakan baris mana yang harus dilaporkan), partisipan bisa melaporkan 3-4 huruf dari baris mana pun, menunjukkan bahwa semua huruf tersimpan di iconic memory tetapi memudar terlalu cepat untuk dilaporkan semua.
- Echoic memory (memori ekoik) adalah sensory memory untuk informasi auditori. Durasi lebih panjang dari iconic, sekitar 2-4 detik. Ini memungkinkan kita mendengar gema suara setelah stimulus berakhir.
- Echoic memory memungkinkan kita memahami pembicaraan: ketika seseorang berbicara, kita masih memproses suku kata pertama saat mendengar suku kata berikutnya, dan echoic memory menahan informasi sehingga otak bisa menyatukannya menjadi kata dan kalimat yang utuh.

## Fungsi
Sensory memory berfungsi sebagai penyangga (buffer) yang menahan informasi cukup lama untuk diproses lebih lanjut. Iconic memory memberikan stabilitas pada dunia visual—tanpanya, setiap kali kita berkedip atau menggerakkan mata, dunia akan "hilang" dan harus dibangun ulang. Echoic memory memungkinkan kita memproses ucapan dan musik secara berurutan, menyatukan suara yang terpisah waktu menjadi pengalaman auditori yang koheren.

## Contoh Sehari-hari
- Iconic memory: Saat menonton film (24 frame per detik), iconic memory menyatukan frame-frame terpisah menjadi gerakan yang mulus. Jika Anda menyalakan dan mematikan lampu di ruangan gelap, Anda masih bisa "melihat" ruangan sesaat setelah lampu mati.
- Echoic memory: Seseorang berkata "Apa?" tetapi sebelum selesai menjawab, ia sudah memproses pertanyaan itu—echoic memory masih menyimpan bunyi pertanyaan. Atau, Anda masih "mendengar" lagu di kepala beberapa detik setelah musik berhenti.

## Analogi (Taman & Berkebun)
Sensory memory seperti kesan pertama saat memasuki taman. Iconic memory adalah kilatan sekilas taman ketika petir menyambar—Anda melihat semua detail taman dalam sekejap, tetapi gambar itu hilang dalam setengah detik. Jika ada bunga langka di sudut kiri, Anda hanya bisa mengingatnya jika Anda segera memindahkan pandangan atau memprosesnya secara sadar. Echoic memory seperti gemericik air mancur di taman—suaranya terus terdengar beberapa saat setelah angin berhenti bertiup, bergema di telinga Anda. Anda masih bisa "mendengar" pola tetesan air beberapa detik setelahnya. Kedua jenis sensory memory ini seperti gerbang taman: mereka menahan pengalaman sensorik cukup lama agar Anda bisa memutuskan apakah akan mengundang informasi itu masuk lebih dalam ke kesadaran (short-term memory) atau membiarkannya berlalu. Tanpa gerbang ini, taman akan terasa seperti fragmen-fragmen yang tidak nyambung.

## Kegunaan
Memahami sensory memory membantu dalam desain pembelajaran visual dan auditori. Presentasi visual yang terlalu cepat ( < 250ms) mungkin tidak diproses cukup baik oleh iconic memory. Dalam komunikasi, memberikan jeda singkat setelah informasi penting membantu echoic memory memproses. Juga relevan untuk memahami fenomena seperti "change blindness" (kita melewatkan perubahan visual karena iconic memory yang lemah) dan "cocktail party effect" (mendengar nama kita disebut di tengah keramaian karena echoic memory).

## Kesalahan Umum
Mengira iconic memory seperti foto yang disimpan sempurna—padahal iconic memory sangat rapuh dan cepat memudar. Juga menganggap echoic memory sebagai rekaman yang sama persis—padahal ada batasan durasi dan detail. Kesalahan lain: menyamakan sensory memory dengan persepsi—sensory memory adalah representasi sensorik pasca-stimulus, bukan persepsi sadar.

## Hubungan dengan Materi Sebelumnya
File 74 memperkenalkan sensory memory sebagai komponen pertama model Atkinson-Shiffrin. File ini memperdalam sensory memory dengan dua subtipe utamanya. Sensory memory adalah langkah pertama yang harus dilalui informasi sebelum bisa diproses oleh working memory (file 76). Kualitas informasi yang masuk ke working memory sangat tergantung pada seberapa baik sensory memory menangkapnya. Echoic memory juga berkaitan dengan bagaimana kita memproses informasi auditori saat belajar (misalnya mendengarkan kuliah).

## Soal Latihan
1. Apa perbedaan durasi antara iconic dan echoic memory? Jawaban: Iconic memory berdurasi 250-500 ms, echoic memory berdurasi 2-4 detik.
2. Jelaskan eksperimen Sperling dan apa yang dibuktikannya! Jawaban: Sperling menampilkan huruf selama 50 ms dan menggunakan partial report method untuk membuktikan bahwa semua informasi tersimpan di iconic memory tetapi memudar sangat cepat.
3. Mengapa echoic memory penting untuk memahami pembicaraan? Jawaban: Karena echoic memory menahan bunyi suku kata pertama cukup lama untuk digabungkan dengan suku kata berikutnya menjadi kata yang utuh.
4. Apa yang terjadi jika sensory memory tidak berfungsi normal? Jawaban: Dunia akan terasa terfragmentasi, informasi tidak bisa diproses secara berurutan, dan persepsi menjadi kacau.
5. Bedakan whole report dan partial report dalam eksperimen Sperling! Jawaban: Whole report meminta partisipan melaporkan semua huruf, partial report meminta hanya satu baris yang ditandai—partial report menunjukkan kapasitas iconic memory lebih besar dari yang terlihat di whole report.
