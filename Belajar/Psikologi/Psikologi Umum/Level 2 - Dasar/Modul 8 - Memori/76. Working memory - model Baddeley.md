# Working Memory - Model Baddeley

## Penjelasan
- Working memory adalah sistem kognitif yang secara aktif menyimpan dan memanipulasi informasi dalam jangka pendek untuk mendukung pemikiran, pemahaman, dan pengambilan keputusan. Ini adalah pengembangan dan revisi dari konsep short-term memory (STM) dalam model Atkinson-Shiffrin.
- Alan Baddeley dan Graham Hitch (1974) mengusulkan model working memory yang terdiri dari beberapa komponen, bukan satu STM tunggal. Model ini memiliki tiga komponen asli dan satu komponen tambahan.
- Central executive: komponen kontrol yang mengarahkan perhatian, mengoordinasikan informasi dari subsistem, dan memutuskan apa yang perlu diproses. Ini adalah "bos" dari working memory dengan kapasitas perhatian terbatas.
- Phonological loop: menangani informasi auditori dan verbal. Terdiri dari phonological store (menyimpan jejak auditori selama 1-2 detik) dan articulatory rehearsal process (mengulang secara subvokal). Bertanggung jawab pada efek "inner voice" saat membaca atau mengingat nomor.
- Visuospatial sketchpad: menangani informasi visual dan spasial. Memungkinkan kita membayangkan gambar, memutar objek dalam pikiran, dan menavigasi ruang. Sering disebut "inner eye".
- Episodic buffer (ditambahkan tahun 2000): sistem penyimpanan sementara yang mengintegrasikan informasi dari phonological loop, visuospatial sketchpad, dan LTM menjadi satu representasi episode yang koheren. Jembatan antara working memory dan long-term memory.

## Fungsi
Working memory adalah pusat kognisi sadar. Setiap aktivitas mental kompleks—membaca, berhitung, bercakap-cakap, memecahkan masalah, merencanakan—bergantung pada working memory. Model Baddeley menjelaskan mengapa kita sulit melakukan dua tugas yang melibatkan komponen yang sama secara bersamaan (misalnya membaca sambil mendengarkan radio—sama-sama menggunakan phonological loop).

## Contoh Sehari-hari
- Phonological loop: Mengulang nomor telepon dalam hati saat akan menekan tombol. Jika seseorang berbicara saat Anda mengulang, Anda lupa nomornya.
- Visuospatial sketchpad: Membayangkan rute perjalanan dari rumah ke kantor sambil memutar arah dalam pikiran. Atau, menghitung berapa banyak koper yang muat di bagasi mobil.
- Central executive: Mengatur strategi saat bermain catur—mempertimbangkan gerakan lawan, menghitung konsekuensi, memutuskan langkah terbaik.
- Episodic buffer: Mengingat apa yang Anda lakukan saat liburan lalu—menggabungkan visual (pemandangan), suara (ombak), dan emosi (senang) menjadi satu kenangan utuh.

## Analogi (Taman & Berkebun)
Working memory model seperti meja kerja utama tukang kebun yang lengkap. Central executive adalah tukang kebun itu sendiri—yang mengarahkan perhatian, memutuskan alat apa yang dipakai, dan beralih antar tugas. Phonological loop seperti buku catatan kecil di saku: mencatat instruksi verbal seperti "siram anggrek setiap 3 hari" atau "beli pupuk kalium"—informasi auditori yang diulang-ulang (rehearsal) agar tidak lupa. Visuospatial sketchpad adalah papan gambar di dinding gudang tempat tukang kebun membuat sketsa tata letak taman, menggambar di mana tanaman baru akan ditempatkan, memutar-mutar posisi pot dalam pikiran. Episodic buffer adalah meja penyusun di tengah gudang tempat tukang kebun mengumpulkan semua informasi: melihat catatan (phonological), melihat sketsa (visuospatial), dan mengambil pengalaman bertahun-tahun dari gudang belakang (LTM) untuk merencanakan taman baru secara utuh. Jika tukang kebun hanya punya satu meja kecil (STM model lama), ia akan kewalahan. Dengan meja kerja lengkap (working memory model), ia bisa bekerja multitasking yang efisien.

## Kegunaan
Model ini sangat berguna dalam pendidikan: guru harus menyadari bahwa working memory memiliki kapasitas terbatas—siswa tidak bisa menerima terlalu banyak informasi baru sekaligus. Instruksi yang panjang memberatkan phonological loop; diagram rumit memberatkan visuospatial sketchpad. Juga penting dalam diagnosis dan intervensi kesulitan belajar—anak dengan working memory lemah butuh strategi kompensasi.

## Kesalahan Umum
Menyamakan working memory dengan short-term memory—working memory lebih dari sekadar penyimpanan, ia melibatkan manipulasi aktif. Juga mengira bahwa central executive adalah "kesadaran" atau "diri"—padahal central executive adalah sistem kontrol, bukan entitas metafisik. Kesalahan lain: menganggap komponen working memory bekerja sepenuhnya independen—padahal mereka berinteraksi, terutama melalui episodic buffer.
