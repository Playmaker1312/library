# 93. Apa Itu Sprite Sheet

## Definisi Singkat
Sprite sheet adalah satu file gambar yang berisi banyak sprite atau frame animasi yang disusun dalam grid, memungkinkan game engine memuat satu file besar daripada banyak file kecil untuk efisiensi memori dan rendering.

## Analogi
Seperti lembar stiker—satu lembar kertas berisi banyak stiker yang bisa digunting dan digunakan satu per satu. Sprite sheet adalah lembaran itu, game engine adalah yang "menggunting" stiker di dalam kode.

## Poin-Penting
- **Efisiensi GPU**: memuat 1 file texture ke GPU lebih cepat daripada memuat 100 file kecil.
- **Ukuran texture**: game engine sering membatasi ukuran texture (contoh: 2048x2048 max). Pastikan sprite sheet tidak melebihi batas.
- **Grid vs irregular**: sprite sheet bisa grid teratur (setiap frame ukuran sama) atau irregular (frame ukuran berbeda, butuh metadata).
- **Metadata**: file JSON/XML/###.txt berisi posisi x, y, lebar, tinggi tiap sprite dalam sheet.
- **Bleeding**: masalah warna pixel tetangga di edge saat rendering—dicegah dengan padding/spacing.
- **Format penyimpanan**: PNG paling umum karena lossless dan alpha channel.

## Shortcut & Fitur Aseprite
- **Export Sprite Sheet**: tool utama untuk generate sprite sheet, **Shortcut:** Ctrl+Shift+X
- **Sprite Sheet Preview**: di dialog Export, ada preview grid sebelum export
- **Tags**: semua frame yang ditandai (tag) bisa diexport sebagai sprite sheet terpisah atau satu sheet dengan metadata tag
- **Trim**: buang area transparan di tiap frame biar sheet lebih kecil

## Contoh Kasus Nyata (Step-by-Step)

### Membuat Sprite Sheet Sederhana
1. **Buka file** karakter dengan 4 frame animasi (32x32 tiap frame).
2. **File > Export Sprite Sheet** (Ctrl+Shift+X).
3. Atur layout **Horizontal Strip**—4 frame berjajar ke kanan (128x32 total).
4. **Spacing**: 2 pixel antara frame.
5. **Output**: "karakter_sheet.png".
6. Klik Export.
7. Buka file PNG yang dihasilkan—akan terlihat 4 karakter berjajar dengan jarak 2 pixel.
8. Metadata opsional: centang "Output data" > pilih JSON > simpan "karakter_sheet.json" untuk informasi posisi tiap frame.
