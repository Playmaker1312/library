# 95. Export Sprite Sheet di Aseprite

## Definisi Singkat
Export Sprite Sheet di Aseprite adalah proses mengubah animasi multi-frame menjadi satu file PNG dengan pengaturan layout, spacing, border, trim, dan metadata yang bisa disesuaikan.

## Analogi
Seperti mencetak beberapa foto dalam satu lembar—kamu atur jumlah kolom, jarak antar foto, dan posisinya. Hasil akhir adalah satu lembar besar yang berisi semua foto.

## Poin-Penting
- **Dialog Export Sprite Sheet**: File > Export Sprite Sheet (Ctrl+Shift+X).
- **Layers**: pilih "All Layers" untuk export semua, "Merge Visible" untuk flatten, atau pilih layer spesifik.
- **Frames**: pilih "All Frames" atau "Tag" tertentu (misal hanya animasi walk, bukan idle).
- **Trim**: buang area transparan di tiap frame—sangat menghemat ukuran file.
- **Border**: tambah border pixel di sekeliling sheet (jarang dipakai).
- **Spacing**: jarak antar frame (krusial untuk hindari bleeding).
- **Metadata**: output data JSON/XML/### yang berisi nama frame, posisi x/y, lebar/tinggi.

## Shortcut & Fitur Aseprite
- **Export Sprite Sheet**: **Ctrl+Shift+X**
- **Preview di dialog**: tab "Preview" untuk lihat bagaimana hasil layout sebelum export
- **Save preset**: simpan pengaturan export sebagai preset untuk dipakai lagi
- **Recent exports**: Aseprite ingat pengaturan export terakhir

## Contoh Kasus Nyata (Step-by-Step)

### Export Lengkap dengan Metadata
1. **Buka file** karakter.aseprite dengan 6 frame (idle 3 frame + walk 4 frame = 7 frame total dengan overlap).
2. **Beri tag**:
   - Select frame 1-3, New Tag, rename "idle".
   - Select frame 4-7, New Tag, rename "walk".
3. **Buka Export**: File > Export Sprite Sheet (Ctrl+Shift+X).
4. **Tab Sprite**:
   - Layout: "Rows & Columns".
   - Columns: 4, Rows: 0 (otomatis).
   - Stitch: unchecked.
5. **Tab Output**:
   - File: "karakter_sheet.png".
   - Check "Output data": "karakter_sheet.json" (format JSON).
   - Check "List tags" (agar metadata include nama tag).
   - Check "Trim" dan "Trim padding" 1 pixel.
6. **Tab Preview**: lihat hasil susunan layout. Pastikan tidak ada frame terpotong.
7. **Tab Advanced** (opsional):
   - Atur "Border" 0, "Spacing" 2 pixel.
   - Pilih "Texture size" max 512x512.
8. Klik **Export**.
9. Hasil: karakter_sheet.png + karakter_sheet.json.
10. Buka JSON—akan terlihat data frame seperti:
    ```json
    {"frames": {"idle 0.aseprite": {"frame": {"x":0,"y":0,"w":32,"h":32}}}}
    ```

### Tips
- Selalu cek "Trim" jika sprite memiliki banyak area transparan.
- Jika game engine mendukung, export dengan layout "Packed" untuk efisiensi ruang maksimal.
- Simpan preset dengan nama "Export Game" agar tidak perlu atur ulang tiap export.
