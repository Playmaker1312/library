# 98. Impor Sprite Sheet ke Godot Engine

## Definisi Singkat
Impor sprite sheet ke Godot Engine melibatkan pemotongan PNG menjadi frame individual menggunakan animasi berbasis region atau autoslicing, lalu mengatur animasi di AnimationPlayer atau AnimatedSprite2D (Godot 4).

## Analogi
Seperti membawa lembar stiker ke meja kerja—kamu gunting setiap stiker dari lembaran (sprite sheet) lalu tempel di tempat yang sesuai (node game).

## Poin-Penting
- **Godot 4** menggunakan **AnimatedSprite2D** + **SpriteFrames** untuk animasi sprite sederhana, atau **AnimationPlayer** untuk kontrol lebih kompleks.
- **SpriteFrames** resource menyimpan semua frame animasi sebagai array, bisa diimpor langsung dari sprite sheet.
- **Hsplit/Vsplit**: di Import dock, set jumlah frame horizontal/vertikal agar Godot otomatis membagi sheet menjadi frame individual.
- **Metadata JSON**: jika sprite sheet punya metadata JSON (dari Aseprite), parsing JSON di Godot dengan ResourceLoader atau script GDScript.
- **Filter texture**: set **Texture Filter** ke **Nearest** di Godot agar pixel art tetap tajam (jangan bilinear!).

## Shortcut & Fitur Godot
- **AnimatedSprite2D**: node untuk sprite bergerak
- **SpriteFrames**: resource yang menampung frame animasi. Buat via **Resource > New SpriteFrames** lalu drag sprite sheet
- **Import > Texture > H/V Slices**: atur jumlah potongan horizontal/vertikal di tab Import setelah pilih file PNG
- **Texture Filter**: set ke "Nearest" di Import dock > Flags > Filter
- **AnimationPlayer**: alternatif dengan AnimationPlayer + AnimationTrack untuk kontrol frame-by-frame

## Contoh Kasus Nyata (Step-by-Step)

### Metode 1: AnimatedSprite2D dengan SpriteFrames
1. **Export dulu** sprite sheet horizontal 128x32 (4 frame @ 32x32) dari Aseprite.
2. **Copy** file PNG ke folder project Godot (`res://assets/sprites/karakter_sheet.png`).
3. **Di Godot**, pilih file PNG di FileSystem dock.
4. **Import tab** (muncul di samping):
   - **Texture Filter**: ubah ke **Nearest** (kunci untuk pixel art).
   - **Repeat**: disable.
   - **H Slices**: 4 (karena 4 frame horizontal).
   - **V Slices**: 1.
   - Klik **Reimport**.
5. **Buat node** AnimatedSprite2D di scene (Klik kanan > Add Child Node > pilih AnimatedSprite2D).
6. **Inspector > Frames**: klik dropdown > **New SpriteFrames**.
7. Jendela SpriteFrames terbuka:
   - Drag karakter_sheet.png dari FileSystem ke area frame.
   - Godot otomatis buat 4 frame (dari H Slices 4).
   - Rename animasi dari "default" jadi "idle".
   - Atur FPS (misal 12).
8. **Play scene**: karakter akan beranimasi idle.

### Metode 2: AnimationPlayer (Frame-by-Frame)
1. **Set up node**: Karakternya pake Sprite2D biasa.
2. **Buat AnimationPlayer** node.
3. **Buat animasi baru**: di AnimationPanel > Animation > New, rename "walk".
4. **Atur keyframe**:
   - Timeline > pilih waktu 0.0.
   - Klik ikon key di samping "Frame" property Sprite.
   - Atur frame jadi 0.
   - Pindah ke 0.1s, set frame jadi 1, klik key.
   - Pindah ke 0.2s, set frame jadi 2, klik key.
   - Pindah ke 0.3s, set frame jadi 3, klik key.
5. Loop: centang "Looping" di AnimationPlayer.
6. **Play**: panggil `animation_player.play("walk")` dari script.

### Tips Godot Pixel Art
- Atur **Rendering > Textures > Default Texture Filter** di Project Settings ke **Nearest** untuk seluruh project (jangan set satu-satu).
- Import sprite sheet dengan **Trim** untuk hemat memori.
- Jika ada JSON metadata dari Aseprite, parse dengan `ResourceLoader.load("res://karakter_sheet.json")` terus baca posisi frame dari data.
