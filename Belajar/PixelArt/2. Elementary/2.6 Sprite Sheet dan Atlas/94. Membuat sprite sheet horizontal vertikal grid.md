# 94. Membuat Sprite Sheet Horizontal, Vertikal, Grid

## Definisi Singkat
Sprite sheet bisa disusun dalam tiga layout utama—horizontal (baris tunggal ke kanan), vertikal (kolom tunggal ke bawah), atau grid (baris dan kolom). Pilihan layout tergantung pada game engine dan preferensi workflow.

## Analogi
Horizontal seperti lembaran klise film—gambar berjajar ke samping. Vertikal seperti rol film yang menggulung ke bawah. Grid seperti lembar perangko—beberapa baris dan kolom.

## Poin-Penting
- **Horizontal Strip**: semua frame berjajar ke kanan. Paling sederhana, cocok untuk karakter dengan sedikit frame (4-6). Ukuran lebar = jumlah frame x lebar sprite.
- **Vertikal Strip**: semua frame ke bawah. Kadang lebih nyaman untuk animasi vertikal (loncat, jatuh).
- **Grid (Rows & Columns)**: frame disusun dalam baris dan kolom. Paling efisien untuk banyak frame (8+). Contoh: 4 baris x 4 kolom = 16 frame.
- **Power of Two**: ukuran texture total sprite sheet sebaiknya power of two (256, 512, 1024) untuk performa GPU optimal.
- **Packing**: jika frame ukuran tidak seragam, gunakan "Pack" (Aseprite otomatis atur posisi frame untuk efisiensi ruang).
- **Pilih layout berdasarkan prioritas**: kecepatan kerja vs efisiensi ruang.

## Shortcut & Fitur Aseprite
- **Export Sprite Sheet**: **Ctrl+Shift+X**
- **Layout options**: di tab "Layout" ada dropdown: "Horizontal Strip", "Vertical Strip", "Rows & Columns", "Packed"
- **Rows & Columns settings**: atur jumlah baris (rows) atau kolom (columns) manual. Aseprite hitung otomatis jika salah satu diisi 0.
- **Pack**: pilih layout "Packed" untuk susun frame irregular secara otomatis

## Contoh Kasus Nyata (Step-by-Step)

### Layout Horizontal (Walk Cycle 4 Frame)
1. File > Export Sprite Sheet (Ctrl+Shift+X).
2. Layout: "Horizontal Strip".
3. Output: "walk_horizontal.png".
4. Hasil: gambar 128x32 (4 frame x 32 lebar).

### Layout Grid (Animasi 8 Frame)
1. File > Export Sprite Sheet.
2. Layout: "Rows & Columns".
3. Columns: 4, Rows: 2 (atau Columns: 2, Rows: 4).
4. Perhatikan preview: 4 frame di baris 1, 4 frame di baris 2.
5. Output: "animasi_grid.png" (128x64 jika frame 32x32).
6. Grid memudahkan game engine membaca frame dengan rumus: frameIndex = row * columns + col.

### Layout Packed (Frame Ukuran Berbeda)
1. Jika sprite memiliki ukuran berbeda (misal ledakan: 16x16, 24x24, 32x32).
2. Layout: "Packed".
3. Aseprite akan menyusun sprite berdekatan untuk meminimalkan area kosong.
4. **Wajib export metadata JSON** karena posisi tiap sprite tidak teratur—engine butuh data posisi untuk memotongnya.
