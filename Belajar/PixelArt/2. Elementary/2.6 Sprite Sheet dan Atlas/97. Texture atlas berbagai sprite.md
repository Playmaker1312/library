# 97. Texture Atlas (Berbagai Sprite)

## Definisi Singkat
Texture atlas adalah sprite sheet yang diperluas—satu file besar berisi semua aset visual game: karakter, musuh, item, tileset, UI, efek, semuanya dalam satu texture. Tujuannya meminimalkan jumlah draw call saat rendering.

## Analogi
Seperti lemari alat kerja—semua peralatan (palu, obeng, gergaji) disimpan dalam satu lemari besar. Kamu buka satu pintu, ambil alat yang diperlukan. Tanpa atlas, kamu harus buka banyak laci terpisah (file texture berbeda).

## Poin-Penting
- **Draw call**: game engine memerintah GPU menggambar. Satu texture atlas = 1 draw call untuk semua sprite di dalamnya. Banyak texture kecil = banyak draw call = lambat.
- **Ukuran maksimal texture atlas**: batasi sesuai engine (4096x4096 untuk Godot/Unity modern, lebih kecil untuk mobile).
- **Atur kategori**: jangan campur tileset (ukuran besar) dengan ikon UI (ukuran kecil) di atlas yang sama—susah diorganisir.
- **Packing algorithm**: susun sprite dengan ukuran berbeda secara efisien untuk meminimalkan ruang kosong.
- **Texture atlas tool**: Aseprite bisa untuk sprite sheet sederhana, tapi untuk atlas kompleks, butuh tool khusus (TexturePacker, Free Texture Packer).
- **Metadata wajib**: karena sprite tidak seragam, kamu harus export JSON/XML dengan posisi tiap sprite.

## Shortcut & Fitur Aseprite
- **Packed Layout**: di Export Sprite Sheet, pilih "Packed" untuk atur sprite otomatis dengan algoritma packing
- **Multiple Tags**: export beberapa tag sekaligus dalam satu sheet
- **Sprite Sheet Preview**: lihat packing di tab Preview sebelum export
- **Output Data**: export metadata JSON/XML, atur di tab Output > "Output data"

## Contoh Kasus Nyata (Step-by-Step)

### Membuat Texture Atlas Sederhana di Aseprite
1. **File > New >** buat canvas kosong besar, misal 256x256.
2. **Import beberapa sprite**:
   - Buka tiap file sprite (.aseprite).
   - Copy paste ke canvas atlas.
   - Atau drag-drop langsung ke dalam satu file Aseprite (masing-masing jadi layer terpisah).
3. **Beri tag** tiap layer sebagai frame (setiap layer = 1 frame di timeline).
   - Buka Timeline, setiap layer jadi frame berbeda (Pastikan di Timeline setiap sprite ada di frame terpisah).
4. **File > Export Sprite Sheet (Ctrl+Shift+X)**:
   - Layout: **Packed**—Aseprite akan menyusun sprite berdekatan secara otomatis.
   - Trim: centang.
   - Spacing: 2 pixel.
   - Output: "texture_atlas_game.png".
   - Output data: "texture_atlas_game.json" (JSON Array format).
5. **Export**. Hasil: satu PNG besar berisi semua sprite + JSON berisi data posisi tiap sprite.

### Penggunaan di Game
- Godot: impor texture atlas, buka JSON di script untuk potong-potong sprite.
- Unity: Unity punya Sprite Packer bawaan, tapi bisa juga manual dari JSON.
- Tips: jangan campur sprite dari resolusi yang sangat berbeda (16x16 campur 128x128) karena tidak efisien.
