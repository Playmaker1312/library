# 49. Konsep Layer di Aseprite

## Definisi Singkat
Layer adalah lapisan transparan tempat kamu menggambar pixel. Setiap layer bisa diisi dengan objek atau efek berbeda tanpa mengganggu layer lain.

## Analogi
Seperti lembaran kertas transparan yang ditumpuk. Kamu bisa menggambar latar di lembar bawah, karakter di lembar tengah, dan efek di lembar atas.

## Poin-Poin Penting
- Setiap layer independen — mengedit satu layer tidak memengaruhi layer lain
- Layer memiliki urutan yang memengaruhi tampilan akhir (atas menutupi bawah)
- Aseprite mendukung layer raster biasa dan layer referensi

## Shortcut & Fitur Aseprite
- **New Layer**: membuat layer baru, **Shortcut:** Shift+N
- **Delete Layer**: menghapus layer aktif, **Shortcut:** Shift+Delete
- **Layer Properties**: mengatur nama, opacity, blending mode

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite dan buat sprite baru (File > New).
2. Default sudah ada satu "Layer 1". Klik ikon **New Layer** di panel Layers (atau Shift+N) untuk menambah layer.
3. Gambar latar di Layer 1. Gambar karakter di Layer 2.
4. Perhatikan bahwa mengedit Layer 2 tidak mengubah Layer 1.
5. Gunakan ikon mata (eye icon) untuk menyembunyikan layer sementara.
