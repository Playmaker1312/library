# 55. Reference Layer

## Definisi Singkat
Reference layer adalah layer khusus yang tidak ikut diexport atau dianimasikan, berfungsi sebagai panduan visual saat menggambar.

## Analogi
Seperti gambar blueprint di meja kerja — kamu melihatnya sebagai referensi tapi tidak menjadi bagian dari hasil akhir.

## Poin-Poin Penting
- Konten reference layer tidak muncul di file export (PNG/GIF)
- Bisa berupa sketsa, foto referensi, atau panduan palette
- Diberi ikon pin khusus di panel Layers

## Shortcut & Fitur Aseprite
- **Toggle Reference Layer**: ikon pin di panel Layers (klik untuk mengaktifkan)
- Bisa diimpor dari file eksternal (File > Open as > Reference Layer)

## Contoh Kasus Nyata (Step-by-Step)
1. Buka foto referensi (File > Open).
2. Pilih menu **Layer > Reference Layer > Toggle Reference** atau klik ikon pin.
3. Foto berpindah ke panel Layers sebagai reference layer (ikon pin aktif).
4. Buat layer baru di atasnya.
5. Gambar dengan menjiplak referensi — foto tidak akan ikut saat export.
6. Sembunyikan referensi dengan mengklik ikon mata jika mengganggu.
