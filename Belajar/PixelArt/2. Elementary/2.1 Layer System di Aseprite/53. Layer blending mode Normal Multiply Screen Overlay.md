# 53. Layer Blending Mode — Normal, Multiply, Screen, Overlay

## Definisi Singkat
Blending mode menentukan bagaimana pixel layer ini berinteraksi dengan pixel di layer bawahnya, bukan sekadar menutupi.

## Analogi
Seperti filter kamera atau kertas warna: Multiply seperti menumpuk marker transparan (menggelapkan), Screen seperti memproyeksikan cahaya (mencerahkan).

## Poin-Poin Penting
- **Normal**: pixel atas menutupi pixel bawah (default)
- **Multiply**: menggelapkan — cocok untuk bayangan
- **Screen**: mencerahkan — cocok untuk efek cahaya
- **Overlay**: kontras lebih tinggi — menggabungkan efek Multiply dan Screen

## Shortcut & Fitur Aseprite
- **Blending Mode dropdown**: di panel Layers, ubah dari "Normal" ke mode lain

## Contoh Kasus Nyata (Step-by-Step)
1. Buat layer "Base" dengan warna abu-abu solid.
2. Buat layer "Bayangan" di atasnya, isi dengan warna biru gelap.
3. Atur blending mode layer "Bayangan" ke **Multiply** — warna biru gelap menyatu jadi bayangan natural.
4. Buat layer "Cahaya" di atas, isi dengan kuning muda.
5. Atur blending mode ke **Screen** — warna kuning membuat area terlihat menyala.
6. Buat layer "Kontras" di atas, isi gradien hitam-putih, atur ke **Overlay**.
