# 52. Layer Opacity / Transparansi

## Definisi Singkat
Opacity mengontrol seberapa tembus pandang suatu layer. Nilai 100% = solid, 0% = tidak terlihat sama sekali.

## Analogi
Seperti kertas mika: semakin rendah opacity, semakin transparan seperti kertas kalkus yang tembus pandang.

## Poin-Poin Penting
- Opacity layer memengaruhi seluruh konten di layer tersebut
- Berbeda dengan alpha pixel yang hanya memengaruhi pixel tertentu
- Mengurangi opacity berguna untuk efek bayangan atau referensi

## Shortcut & Fitur Aseprite
- **Layer Opacity Slider**: di panel Layers, slider default 100%
- Tidak ada shortcut default — atur di panel Layers Properties

## Contoh Kasus Nyata (Step-by-Step)
1. Buat layer "Referensi" dan gambar sketsa kasar.
2. Di panel Layers, klik layer "Referensi" untuk memilihnya.
3. Geser slider **Opacity** dari 100% ke 40%.
4. Sketsa menjadi transparan, memudahkan menjiplak di layer baru.
5. Buat layer baru di atas, gambar detail di atas referensi tembus pandang.
6. Setelah selesai, sembunyikan atau hapus layer referensi.
