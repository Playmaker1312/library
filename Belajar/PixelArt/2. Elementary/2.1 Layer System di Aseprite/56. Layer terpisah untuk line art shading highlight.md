# 56. Layer Terpisah untuk Line Art, Shading, Highlight

## Definisi Singkat
Memisahkan line art (garis tepi), shading (bayangan), dan highlight (cahaya) ke layer berbeda memudahkan revisi dan eksperimen.

## Analogi
Seperti proses produksi animasi tradisional: sketsa di kertas tipis, tinta di kertas lain, warna di sel terpisah.

## Poin-Poin Penting
- Line art di layer paling atas agar garis tidak tertutup cat
- Shading di layer dengan blending mode Multiply
- Highlight di layer dengan blending mode Screen atau Add

## Shortcut & Fitur Aseprite
- **New Layer**: Shift+N
- **Blending Mode**: dropdown di panel Layers
- **Lock Layer**: ikon gembok — cegah editing pada layer yang sudah selesai

## Contoh Kasus Nyata (Step-by-Step)
1. Buat layer "Line Art" — gambar outline karakter dengan warna gelap.
2. Buat layer di bawahnya "Base Color" — isi warna dasar.
3. Kunci layer "Line Art" (klik ikon gembok).
4. Buat layer "Shading" di atas "Base Color", atur blending ke **Multiply**.
5. Buat layer "Highlight" di atas "Shading", atur blending ke **Screen**.
6. Gunakan warna terang untuk highlight — hasilnya langsung menyatu.
