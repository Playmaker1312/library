# 68. Bentuk 3D — Sphere, Cube, Cylinder, Cone

## Definisi Singkat
Memahami cara shading bentuk geometris 3D dasar menggunakan prinsip cahaya dan bayangan dalam pixel art.

## Analogi
Seperti menggambar dengan pensil di kertas: teknik arsir yang sama (cross-hatching) diterapkan berbeda untuk bola, kubus, silinder, dan kerucut.

## Poin-Poin Penting
- **Sphere**: shadow melingkar, highlight di titik terdekat cahaya, midtone gradasi melingkar
- **Cube**: shading per sisi (face) — 3 sisi dengan value berbeda
- **Cylinder**: shadow gradasi vertikal, highlight garis vertikal
- **Cone**: shadow gradasi dari bawah ke atas, highlight di puncak menurun

## Shortcut & Fitur Aseprite
- **Circle tool**: untuk membuat lingkaran
- **Polygon tool (tersembunyi)**: untuk bentuk geometris
- **Shading manual**: dengan Pencil Tool pixel per pixel

## Contoh Kasus Nyata (Step-by-Step)
1. Buat 4 layer terpisah: Sphere, Cube, Cylinder, Cone.
2. **Sphere**: gambar lingkaran, isi midtone, tambah shadow setengah lingkaran bawah, highlight titik kecil di kanan atas.
3. **Cube**: buat kubus isometrik, 3 warna (terang, medium, gelap) untuk 3 sisi.
4. **Cylinder**: persegi panjang, shadow gradasi dari kiri ke kanan, highlight garis vertikal.
5. **Cone**: segitiga, shadow di kiri, midtone tengah, highlight kanan, gradasi naik ke puncak.
6. Bandingkan pendekatan shading yang berbeda untuk setiap bentuk.
