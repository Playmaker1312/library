# 92. Export Animasi GIF / Sprite Sheet

## Definisi Singkat
Export adalah proses menyimpan animasi pixel art ke format file yang bisa digunakan di game atau web: GIF (animasi ringan, transparan, untuk web/social) dan Sprite Sheet (satu gambar grid berisi semua frame, untuk game engine).

## Analogi
Seperti mencetak film seluloid—GIF seperti video pendek, Sprite Sheet seperti lembaran film strip yang dipotong-potong.

## Poin-Penting
- **GIF**:
  - Format lossless (kualitas pixel sempurna).
  - Mendukung transparansi (1 warna transparan saja).
  - Ukuran file besar jika banyak frame—kompres dengan mengurangi warna (max 256 warna).
  - Kecepatan animasi ditentukan oleh frame duration, bukan FPS.
- **Sprite Sheet**:
  - Satu file PNG berisi semua frame dalam grid (horizontal atau vertikal).
  - Digunakan di game engine (Godot, Unity, RPG Maker).
  - Metadata (ukuran frame, jumlah frame, FPS) disimpan terpisah (###.json atau di engine).
  - Format PNG lossless, ukuran kecil, transparansi penuh (alpha channel).

## Shortcut & Fitur Aseprite
- **Export Sprite Sheet**: **File > Export Sprite Sheet** (atau Ctrl+Shift+X / Cmd+Shift+X)
- **Save As GIF**: **File > Save As > pilih format GIF** (atau **File > Export > Save as GIF**)
- **Export Settings**: atur layout, padding, border, trim di dialog Export Sprite Sheet
- **Play Animation**: preview dulu sebelum export, **Shortcut:** Enter

## Contoh Kasus Nyata (Step-by-Step)

### Export ke GIF
1. **File > Export** (atau Save As > GIF).
2. Pilih **Output File**: "animasi_idle.gif".
3. Atur opsi:
   - **Loop**: centang untuk looping.
   - **Frame Duration**: pilih "From frames" (gunakan durasi yang sudah diatur di timeline).
   - **Transparent background**: centang jika ingin background transparan.
4. Klik **Export**. File GIF siap di-share.

### Export Sprite Sheet (Horizontal)
1. **File > Export Sprite Sheet** (Ctrl+Shift+X).
2. **Layout**: pilih "Horizontal Strip" (baris tunggal) atau "Vertical Strip" (kolom tunggal) atau "Grid" (rows & columns).
3. **Layers**: pilih "All layers" atau "Merge visible layers".
4. **Borders & Spacing**:
   - **Border**: 0 pixel.
   - **Spacing**: 2 pixel (untuk hindari bleeding di engine).
5. **Trim**: centang "Trim" jika ingin menghilangkan area transparan di sekitar sprite.
6. **Output file**: "sprite_sheet_karakter.png".
7. **Metadata** (opsional): centang "Output data" > pilih format JSON, atur "Filename". Aseprite akan generate file JSON berisi ukuran frame dan nama.
8. Klik **Export**. Sekarang punya sprite sheet PNG + data JSON.

### Tips Export
- Untuk Godot: export sebagai horizontal strip, import sebagai SpriteFrames.
- Untuk web: GIF dengan palet 64-128 warna (kurangi warna di Sprite > Color Mode > Indexed dulu).
- Selalu preview dengan Enter sebelum export untuk memastikan animasi benar.
