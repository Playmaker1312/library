# 85. FPS (Frame Per Second)

## Definisi Singkat
FPS (Frame Per Second) adalah jumlah frame yang ditampilkan setiap detik, menentukan kecepatan dan kehalusan animasi. Di pixel art, FPS rendah (6-18) sering digunakan untuk gaya retro, sementara FPS tinggi (24-60) untuk animasi halus.

## Analogi
Seperti kecepatan membolak-balik halaman flipbook. Semakin cepat kamu membalik halaman (semakin tinggi FPS), semakin halus gerakannya, tetapi kamu butuh lebih banyak halaman (frame) untuk durasi yang sama.

## Poin-Penting
- **Rumus**: durasi 1 frame (ms) = 1000 / FPS. Contoh: 12 FPS = 83.3 ms per frame.
- **12 FPS**: standar game retro NES/SNES, cukup untuk walk cycle dan animasi dasar.
- **24 FPS**: standar animasi film, sangat halus untuk pixel art modern.
- **30/60 FPS**: untuk game action modern, butuh banyak frame dan ukuran file besar.
- **Konsistensi**: semua frame harus memiliki durasi yang sama jika ingin FPS tetap, atau atur durasi berbeda untuk timing ekspresif.
- **FPS vs Frame Count**: 12 FPS dengan 6 frame = 0.5 detik animasi. 24 FPS dengan 6 frame = 0.25 detik.

## Shortcut & Fitur Aseprite
- **Frame Duration**: atur durasi per frame di dropdown Timeline atau di Frame Properties
- **Set All Frames Duration**: pilih semua frame > atur duration sekali untuk semua
- **FPS indicator**: tampil di sudut Timeline (misal: "12.00 fps")
- **Play Speed**: tidak ada shortcut langsung—atur via durasi tiap frame

## Contoh Kasus Nyata (Step-by-Step)

### Atur FPS Animasi Karakter
1. **Buka file animasi** karakter dengan 8 frame.
2. **Cek durasi**: klik frame 1, lihat angka durasi di Timeline (default 100ms = 10 FPS).
3. **Set 12 FPS**: double click pada angka durasi frame 1, ketik 83 (ms), Enter.
4. **Set semua frame sekaligus**:
   - Klik frame 1, Shift+Klik frame terakhir untuk select all.
   - Klik kanan > Frame Properties.
   - Set Duration: 83 ms, klik OK. Semua frame jadi 83ms = 12 FPS.
5. **Cek hasil**: Play (Enter). Animasi berjalan 12 frame per detik.
6. **Bandingkan**: set durasi 166 ms (6 FPS) untuk gaya retro kasar. Putar lagi—terlihat patah-patah seperti game lama.
7. **Export**: File > Export > set FPS di export options agar sesuai dengan durasi frame.
