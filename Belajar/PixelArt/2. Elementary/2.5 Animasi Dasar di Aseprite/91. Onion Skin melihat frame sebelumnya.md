# 91. Onion Skin (Melihat Frame Sebelumnya)

## Definisi Singkat
Onion Skin adalah fitur yang menampilkan transparansi frame sebelum dan sesudah frame aktif sebagai overlay, memungkinkan kamu melihat perubahan posisi antar frame secara langsung. Sangat penting untuk animasi yang mulus.

## Analogi
Seperti kertas kalkir yang dilapiskan di atas gambar sebelumnya—kamu bisa melihat gambar lama tembus pandang sehingga bisa menggambar perubahan kecil secara presisi.

## Poin-Penting
- **Previous frame**: terlihat dengan warna redup (biasanya merah) di belakang frame saat ini.
- **Next frame**: terlihat dengan warna berbeda (biasanya hijau) untuk antisipasi gerakan selanjutnya.
- **Opacity setting**: atur seberapa transparan onion skin—semakin transparan, semakin samar referensi.
- **Range setting**: berapa banyak frame sebelumnya/sesudah yang ditampilkan (default 1 frame).
- **Penggunaan umum**: walk cycle (posisi kaki), animasi squash/stretch, lip sync.
- **Non-destructive**: onion skin hanya untuk panduan, tidak mempengaruhi pixel di frame manapun.

## Shortcut & Fitur Aseprite
- **Toggle Onion Skin**: aktifkan/nonaktifkan, **Shortcut:** Ctrl+L
- **Onion Skin Settings**: atur opacity, range, warna, **Shortcut:** Alt+L (atau via Window > Onion Skin Settings)
- **Onion Skin Mode**: pilih "Relative" (default) atau "Absolute" di menu Onion Skin
- **Onion Skin Color 1 & 2**: atur warna untuk frame sebelumnya (Color 1, default merah) dan sesudah (Color 2, default hijau)

## Contoh Kasus Nyata (Step-by-Step)

### Menggunakan Onion Skin untuk Walk Cycle
1. **Buka file** walk cycle 4 frame.
2. **Aktifkan Onion Skin**: Ctrl+L.
3. **Buka settings** (Alt+L): set opacity 50%, range Previous: 1, range Next: 1.
4. **Pindah ke Frame 2**:
   - Onion skin menampilkan Frame 1 (merah transparan) di belakang Frame 2.
   - Kamu bisa melihat persis di mana posisi kaki kiri di frame sebelumnya.
   - Gambar kaki kiri di Frame 2 agar transisi dari Frame 1 mulus.
5. **Pindah ke Frame 3**:
   - Onion skin menampilkan Frame 2 (merah) dan juga Frame 4 (hijau) jika range next aktif.
   - Bantu pastikan posisi tangan Frame 3 berada di tengah antara Frame 2 dan Frame 4.
6. **Matikan Onion Skin** (Ctrl+L) untuk melihat hasil akhir bersih.
7. **Tips**: untuk animasi kompleks, set range ke 2 frame untuk melihat lebih banyak konteks.

### Pengaturan Warna
- Ubah Color 1 ke biru (lebih lembut di mata) dan Color 2 ke oranye di Onion Skin Settings.
- Gunakan Absolute mode jika ingin melihat frame spesifik (misal frame 3) terus sebagai referensi.
