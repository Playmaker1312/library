# 60. Color Ramp — Rangkaian Warna Gelap Terang

## Definisi Singkat
Color ramp adalah urutan warna dari tergelap hingga terang yang digunakan untuk shading, dibuat dengan hue shifting bertahap.

## Analogi
Seperti tangga nada: dari shadow tergelap (nada rendah) naik ke highlight (nada tinggi) dengan transisi mulus.

## Poin-Poin Penting
- Setiap color ramp punya 3-7 tingkatan warna
- Transisi harus mulus — jangan ada lompatan terlalu besar
- Semua warna dalam satu ramp berasal dari rona dasar yang sama dengan variasi hue/value/saturation
- Simpan color ramp sebagai palette untuk digunakan ulang

## Shortcut & Fitur Aseprite
- **Color Palette panel**: Window > Color Palette — tempat menyimpan ramp
- **Add Color to Palette**: klik kanan warna di Color panel > Add to Palette

## Contoh Kasus Nyata (Step-by-Step)
1. Pilih rona dasar: biru (#4488CC).
2. Buat 5 warna ramp secara manual:
   - Shadow terluar: #112244 (gelap, hue ke ungu)
   - Shadow: #224488
   - Midtone: #4488CC (warna dasar)
   - Highlight: #88BBEE
   - Highlight terang: #CCDDFF (terang, hue ke cyan)
3. Simpan ke palette: klik kanan di panel Color > Add to Palette.
4. Gunakan ramp ini untuk mewarnai sprite — urutkan dari gelap ke terang.
