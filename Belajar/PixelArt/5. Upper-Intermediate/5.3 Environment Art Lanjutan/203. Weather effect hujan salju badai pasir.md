# 203. Weather Effect — Hujan, Salju, Badai Pasir

## Definisi Singkat
Teknik menambahkan efek cuaca dinamis ke scene pixel art — partikel hujan, salju, badai pasir, kabut — untuk memperkuat atmosfer dan mood lingkungan.

## Analogi
Film tidak akan sama tanpa efek cuaca: adegan sedih lebih terasa dengan hujan, adegan Natal lebih hangat dengan salju. Cuaca adalah "emotion amplifier" untuk scene.

## Poin-Poin Penting
- Hujan: garis diagonal tipis (1x4 atau 1x6 pixel), multiple layer dengan kecepatan berbeda, riak air di tanah
- Salju: partikel putih bulat (2x2), gerakan zigzag turun lambat, akumulasi di permukaan
- Badai pasir: partikel coklat/kuning, opacity bervariasi, gerakan horizontal kencang, efek screen blur
- Kabut: layer semi-transparan dengan gradien, gerakan horizontal sangat lambat
- Jumlah partikel: cukup untuk memberi kesan cuaca, jangan sampai mengganggu gameplay readability
- Pengaruh cuaca ke palet: hujan membuat warna lebih gelap/desaturasi, badai pasir membuat warna kekuningan

## Shortcut & Fitur Aseprite
- Layer Groups untuk setiap partikel layer
- Cel animation: buat 3-4 frame partikel, loop terus
- Filter > RGB > HSV untuk shift warna scene (misal: tambah kuning untuk badai pasir)
- Layer Blend Mode: Screen untuk partikel terang, Multiply untuk bayangan
- Onion Skin untuk melihat pergerakan partikel antar frame

## Contoh Kasus Nyata (Step-by-Step)
Buat scene hujan di kota 64x48:

1. Buat background: bangunan, jalan, langit gelap (#2a2a4a)
2. Layer hujan 1: garis putih tipis (#8a8aaa, opacity 40%) — 4 frame, gerakan diagonal kiri bawah
3. Layer hujan 2: garis lebih tipis (#aaaacc, opacity 30%) — gerakan lebih lambat, frame berbeda
4. Layer splash: titik-titik kecil di tanah (genangan) — 2 frame
5. Efek atmosfer: layer semi-transparan (#1a1a2a, opacity 20%) di atas background
6. Animasi: loop 4 frame untuk hujan, 8 frame untuk splash
7. Test: apakah terasa seperti hujan? Jika terlalu ramai, kurangi partikel; jika kurang, tambah
8. Variasi: buat juga versi salju (ganti partikel putih bulat, hapus splash, gerakan turun vertikal zigzag)
9. Bandingkan: hujan vs salju — bagaimana mood kedua scene berbeda?
