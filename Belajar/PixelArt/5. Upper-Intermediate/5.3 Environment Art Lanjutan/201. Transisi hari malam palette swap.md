# 201. Transisi Hari-Malam — Palette Swap

## Definisi Singkat
Teknik mengubah scene dari siang ke malam (atau sebaliknya) dengan mengganti palet warna secara global, mempertahankan komposisi yang sama tetapi mengubah mood pencahayaan.

## Analogi
Seperti filter Instagram: foto yang sama bisa terasa hangat dengan filter "Valencia" atau dingin dengan "Lark". Palette swap adalah filter untuk pixel art — mengganti semua warna secara sistematis.

## Poin-Poin Penting
- Identifikasi masing-masing warna per kategori: langit, tanah, karakter, highlight, shadow
- Buat mapping: siang → malam untuk setiap warna
  - Langit biru (#4a8cc4) → langit malam (#0a0a2a)
  - Hijau rumput (#4a8c3f) → hijau malam (#1a3a1a)
  - Highlight putih (#ffffff) → highlight bulan (#8a8aff)
- Gunakan shift hue: geser hue ke biru/ungu (+30° di HSV), kurangi brightness (-40%)
- Ciptakan transisi bertahap: beberapa frame intermediate antara siang dan malam
- Efek pencahayaan malam: jendela berpendar, lampu jalan, pantulan bulan di air

## Shortcut & Fitur Aseprite
- Filter > RGB > HSV (Color Shift) untuk shift hue global
- Window > Color Palette (F9) — edit palet langsung untuk palette swap
- Sprite > Color Mode > Indexed — jika palet terbatas, ganti warna index satu per satu
- Edit > Tint (Shift+T) untuk tint global
- Layer Blend Mode untuk efek glow malam (Screen, Add)

## Contoh Kasus Nyata (Step-by-Step)
Buat scene kota sederhana dalam 3 waktu:

1. Scene: rumah 32x32, pohon, jalan, langit
2. Siapkan 3 frame di Timeline: frame 1 (siang), frame 2 (sore), frame 3 (malam)
3. Frame 1 (Siang): langit #4a8cc4, tanah #8c6b4a, pohon #2d5a27, highlight cerah
4. Frame 2 (Sore): langit #c4884a (oranye), tanah #6b4a2d, pohon #3a4a1a, shadow memanjang
5. Frame 3 (Malam): langit #0a0a2a, tanah #1a1a1a, pohon #0a1a0a, lampu jendela #ffcc00
6. Untuk transisi, buat frame intermediate: copy frame 1, geser hue sedikit, paste ke frame 1.5
7. Gunakan Onion Skin untuk memastikan transisi smooth
8. Play animasi (Space) — lihat bagaimana scene berubah dari siang ke malam
9. Refine: tambah bintang di malam, tambah highlight jendela
