# 195. Visual Storytelling — Kostum, Aksesori, Color Coding

## Definisi Singkat
Teknik menyampaikan cerita dan informasi tentang karakter melalui pilihan kostum, aksesori, dan warna — tanpa harus menggunakan dialog atau teks.

## Analogi
Di dunia nyata, seragam polisi, jas dokter, atau toga mahasiswa langsung bercerita tentang profesi seseorang. Di pixel art, kostum dan warna melakukan hal yang sama.

## Poin-Poin Penting
- Kostum menceritakan profesi: baju lapis baja = ksatria, jubah = mage, rompi = petualang
- Aksesori kunci: luka di wajah ( veteran), janggut panjang (bijaksana), cape robek (pelarian)
- Color coding: merah = agresif/kuat, biru = tenang/pintar, hijau = alam/penyembuh, hitam = misterius/jahat
- Gunakan asosiasi warna universal yang sudah dikenal pemain
- Tingkat detail kostum bisa menunjukkan status sosial: raja pakai emas, pengemis pakai kain lusuh
- Props di tangan langsung mengkomunikasikan peran: pedang = fighter, staf = mage, buku = scholar

## Shortcut & Fitur Aseprite
- Edit > Tint (Shift+T) untuk ganti skema warna cepat
- Window > Color Palette (F9) untuk kategorisasi warna per peran
- Layer Groups untuk kostum, aksesori, senjata terpisah
- Pencil (B) untuk detail kecil seperti luka atau emblem
- Selection > Move (M) untuk reposition aksesori

## Contoh Kasus Nyata (Step-by-Step)
Desain 2 versi karakter yang sama untuk menunjukkan character arc:

1. Karakter "Kai" versi awal: baju petani pudar, warna coklat/abu, tanpa alas kaki, tatapan ke bawah
2. Karakter "Kai" versi akhir: baju tempur biru/emas, cape merah, pedang di pinggang, tatapan tegap
3. Detail storytelling: luka di pipi (pengalaman), emblem di dada (affiliasi), warna lebih cerah (harapan)
4. Color coding: dari warna netral (tidak punya identitas) ke biru/merah (pemberani/heroik)
5. Buat side-by-side di Aseprite untuk perbandingan
6. Tanya: apa cerita yang bisa dibaca dari perubahan visual ini?
7. Refine: tambah detail kecil seperti gelang atau scar untuk memperkaya narasi
