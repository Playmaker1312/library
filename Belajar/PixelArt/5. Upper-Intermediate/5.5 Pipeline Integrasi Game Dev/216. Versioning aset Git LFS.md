# 216. Versioning Aset — Git LFS

## Definisi Singkat
Sistem manajemen versi untuk aset pixel art menggunakan Git dengan Git LFS (Large File Storage) — melacak perubahan file .aseprite, PNG, dan aset biner lainnya.

## Analogi
Git biasa seperti buku catatan perubahan untuk teks — bagus untuk kode. Tapi untuk file gambar besar (seperti foto), Git LFS seperti lemari arsip khusus yang menyimpan file besar di tempat terpisah, sementara Git hanya mencatat "lemari apa dan rak哪里".

## Poin-Poin Penting
- Git LFS diperlukan karena file .aseprite dan PNG bisa besar dan Git tidak handle binary well
- Tracking pattern: `*.aseprite`, `*.png`, `*.psd`, `*.gpl`, `*.ase` via Git LFS
- Keuntungan: bisa melihat history perubahan aset, revert ke versi lama, kolaborasi tim
- Git LFS punya kuota (free: 1GB storage, 1GB bandwidth/month di GitHub)
- Best practice: simpan aset final di repo, backup file kerja besar di cloud storage
- Jangan commit file generated (sprite sheet, export) — hanya source file (.aseprite)

## Shortcut & Fitur Aseprite
- Aseprite file (.aseprite) otomatis menyimpan layer, frame, tags — perfect untuk versioning
- File > Revert untuk kembali ke versi tersimpan terakhir
- File > Save As untuk membuat versi baru (manual versioning)
- Edit > Undo History — tapi ini tidak tersimpan di Git, hanya session
- Tips: simpan file .aseprite dengan nama `char_player_v1.aseprite`, `char_player_v2.aseprite`

## Contoh Kasus Nyata (Step-by-Step)
Setup Git LFS untuk project pixel art:

1. Install Git LFS: `git lfs install`
2. Di root project, tracking pattern aset:
   ```
   git lfs track "*.aseprite"
   git lfs track "*.png"
   git lfs track "*.gif"
   git lfs track "*.gpl"
   ```
3. Commit .gitattributes: `git add .gitattributes && git commit -m "setup git lfs"`
4. Kerja normal: edit .aseprite, save
5. Cek perubahan: `git status` — akan deteksi .aseprite berubah
6. Commit: `git add assets/ && git commit -m "update player idle animation"`
7. Push: `git push origin main` — file LFS akan diupload ke server LFS
8. Lihat history: `git log --oneline` untuk track perubahan aset
9. Jika teammate clone: `git lfs pull` untuk download aset
10. Revert jika perlu: `git checkout <commit> -- assets/char_player.aseprite`
