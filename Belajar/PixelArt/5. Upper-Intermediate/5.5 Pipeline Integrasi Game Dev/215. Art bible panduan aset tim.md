# 215. Art Bible — Panduan Aset Tim

## Definisi Singkat
Dokumentasi komprehensif yang berisi semua aturan visual, standar teknis, palet warna, dan panduan style untuk aset game — digunakan oleh seluruh tim agar konsistensi terjaga.

## Analogi
Art bible seperti buku resep keluarga: semua resep, teknik, dan rahasia masakan dicatat agar setiap anggota keluarga bisa memasak dengan rasa yang sama persis. Tanpa art bible, setiap artist akan membuat aset dengan gaya masing-masing.

## Poin-Poin Penting
- Art bible berisi: resolusi canvas, palet warna, teknik shading, aturan outline, proporsi, tipografi UI
- Sertakan contoh benar vs salah: tunjukkan apa yang boleh dan tidak boleh
- Dokumentasi teknis: format export, pivot point, tile size, grid settings
- Palet warna lengkap dengan kode hex dan nama warna — simpan sebagai .gpl atau .aseprite
- Character reference sheets: setiap karakter dari berbagai angle, ekspresi, proporsi
- Environment reference: palet per bioma, tile types, prop list
- Update art bible seiring proyek berkembang — versioning juga penting

## Shortcut & Fitur Aseprite
- File > Export > Export as PDF (dari Aseprite Notes jika ada) atau gunakan markdown eksternal
- Window > Notes untuk menulis catatan style langsung di file .aseprite
- Colors > Palette > Save Palette (.gpl) untuk menyertakan di art bible
- Window > Color Palette (F9) — screenshot untuk dokumentasi
- Sprite > Sprite Properties untuk dokumentasi resolusi

## Contoh Kasus Nyata (Step-by-Step)
Membuat art bible dasar (file markdown/docs):

1. Buat folder "docs/art_bible/" di project root
2. File 1: `01_palette.md`
   - Shared palette 32 warna dengan kode hex
   - Palet per bioma (forest, desert, dungeon)
3. File 2: `02_character_standards.md`
   - Resolusi karakter: 16x22 untuk NPC, 24x32 untuk hero
   - Outline: 1px hitam (#1a1a2e)
   - Shading: 3 tone (highlight, mid, shadow)
4. File 3: `03_environment_standards.md`
   - Tile size: 16x16
   - Tile types: ground, wall, water, decoration
5. File 4: `04_naming_convention.md`
   - Format: `[cat]_[name]_[state]_[size].png`
6. File 5: `05_export_settings.md`
   - Export format: PNG + JSON
   - Pivot: center-bottom untuk karakter
7. Bagikan ke tim via Git — pastikan setiap anggota baca sebelum mulai bekerja
