# 206. Platformer — Sprite, Tile, Silhouette

## Definisi Singkat
Teknik mendesain aset pixel art untuk game platformer — fokus pada sprite karakter yang jelas, tile environment yang seamless, dan siluet yang terbaca saat bergerak cepat.

## Analogi
Platformer seperti teater gerak cepat: penonton (pemain) harus langsung mengenali apa yang mereka lihat dalam sepersekian detik. Siluet hitam karakter harus cukup jelas untuk dikenali bahkan saat melompat atau jatuh.

## Poin-Poin Penting
- Sprite karakter: animasi walk, jump, fall, idle — minimal 4 arah (kiri/kanan bisa flip)
- Tile: seamless repeating pattern — gunakan tilemap 16x16 atau 32x32
- Siluet: uji karakter dalam posisi melompat — apakah terbaca sebagai karakter bukan kotak random?
- Kontras sprite vs background: karakter harus lebih terang/detail dari background
- Hitbox: pastikan sprite dan collision box konsisten (view > Show Collisions jika pakai plugin)
- Platform: bedakan visual antara platform solid, platform hancur, platform bergerak

## Shortcut & Fitur Aseprite
- View > Grid (Shift+G) untuk tile snapping
- File > Export > Export Sprite Sheet untuk sprite sheet karakter
- Onion Skin untuk animasi mulus
- Transform (Q) > Flip Horizontal untuk mirror sprite (hemat separuh frame)
- Window > Timeline (Ctrl+Tab) untuk animasi per frame

## Contoh Kasus Nyata (Step-by-Step)
Buat asset untuk game platformer sederhana:

1. Tile rumput 16x16: seamless pattern — rumput di atas (#4a8c3f), tanah di bawah (#8c6b4a)
2. Tile batu 16x16: abu-abu gelap (#6b6b6b), retakan kecil, variasi 3 tile
3. Karakter 16x22: outline 1px, warna kontras (#ff4444) agar beda dari background hijau
4. Animasi idle: 4 frame — kedip mata, helaan nafas (naik turun 1px)
5. Animasi walk: 6 frame — gunakan referensi walk cycle
6. Animasi jump: 3 frame — crouch, leap, fall
7. Siluet test: export frame tengah lompat, isi hitam — apakah bentuknya masih jelas?
8. Gabung semua tile dalam satu file tilemap 64x64 untuk test level
