# 210. Puzzle Game — Kejelasan Warna & State

## Definisi Singkat
Prinsip mendesain pixel art untuk game puzzle — fokus pada kejelasan warna, perbedaan visual antar state (aktif, tidak aktif, cocok, salah), dan feedback visual yang instan.

## Analogi
Puzzle game seperti rambu lalu lintas: merah berarti berhenti, hijau berarti jalan. Pemain puzzle harus bisa membaca state elemen dalam 0.1 detik tanpa berpikir. Warna adalah bahasa utama.

## Poin-Poin Penting
- Setiap state harus punya warna dan bentuk yang jelas berbeda:
  - Default: warna netral
  - Selected: highlight terang / border tebal
  - Matched/Correct: animasi glow / partikel
  - Wrong: merah / shake
- Gunakan asosiasi warna universal: merah = salah, hijau = benar, kuning = hati-hati
- Ukuran elemen cukup besar untuk readability — jangan terlalu kecil
- Animasi feedback: sentuhan, klik, cocok, salah — harus terasa responsif
- Aksesibilitas: jangan hanya andalkan warna — tambah icon atau pattern untuk color-blind

## Shortcut & Fitur Aseprite
- Window > Color Palette (F9) — buat palet state: default, hover, active, complete, error
- Cel animation untuk efek match/clear
- Layer Blend Mode: Screen untuk glow effect
- Edit > Tint (Shift+T) untuk preview cepat skema warna
- Window > Timeline untuk animasi state transition

## Contoh Kasus Nyata (Step-by-Step)
Buat elemen puzzle "Gem Match" 16x16:

1. Buat 4 jenis gem: merah (#ff4444), biru (#4488ff), hijau (#44ff44), kuning (#ffcc00)
2. Setiap gem punya icon kecil di dalam: bintang, hati, berlian, lingkaran (aksesibilitas)
3. State default: gem dengan warna solid, outline 1px gelap
4. State selected: gem dengan outline putih (#ffffff) tebal 2px + glow kuning tipis
5. State matched: gem pecah menjadi 4 partikel kecil — animasi 6 frame fade out
6. State wrong: gem berubah merah gelap (#cc0000) dan shake horizontal 2px
7. Transisi state: animasi 3-4 frame — default ke selected (scale up 1px), selected ke matched (partikel)
8. Test: apakah semua state bisa dibedakan dengan cepat? Jika biru dan hijau mirip, ubah hue atau tambah icon
9. Minta orang lain test: apakah mereka bisa membedakan state tanpa petunjuk?
