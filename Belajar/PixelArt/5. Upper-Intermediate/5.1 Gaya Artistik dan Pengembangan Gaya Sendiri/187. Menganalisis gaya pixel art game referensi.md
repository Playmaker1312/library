# 187. Menganalisis Gaya Pixel Art Game Referensi

## Definisi Singkat
Proses mempelajari dan membedah elemen visual pixel art dari game lain untuk memahami teknik, palet, resolusi, dan keputusan artistik yang digunakan.

## Analogi
Seperti seorang pelukis yang mempelajari lukisan master — bukan untuk menyalin, tapi untuk memahami mengapa sapuan kuas ditempatkan di situ, warna apa yang dipilih, dan bagaimana komposisi bekerja.

## Poin-Poin Penting
- Amati resolusi canvas — semakin kecil resolusi, semakin ikonik dan abstrak gayanya
- Ekstrak palet warna dari screenshot untuk melihat rentang hue dan value
- Perhatikan teknik shading: cel-shading, dithering, atau gradient smooth
- Analisis edge handling: anti-aliasing keras, outline hitam, atau tanpa outline
- Identifikasi konsistensi proporsi karakter terhadap environment
- Catat penggunaan detail vs simplifikasi di area tertentu

## Shortcut & Fitur Aseprite
- Color Picker (I) untuk mengambil warna referensi dari gambar
- Window > Timeline untuk mempelajari animasi frame-by-frame
- View > Grid (Shift+G) untuk menghitung resolusi aset
- Sprite > Sprite Size untuk melihat dimensi persis canvas
- File > Export > Export Sprite Sheet untuk mengekstrak aset

## Contoh Kasus Nyata (Step-by-Step)
Ambil screenshot dari game pixel art favorit (misal: Celeste, Stardew Valley, Hyper Light Drifter).

1. Import screenshot ke Aseprite (File > Open)
2. Zoom 800–1600% untuk melihat tiap pixel
3. Catat resolusi canvas: hitung width x height lewat Sprite > Sprite Size
4. Ekstrak 5–10 warna dominan dengan Color Picker
5. Buat swatch baru (Colors > New Swatch) simpan warna-warna tersebut
6. Analisis teknik shading: apakah karakter punya outline? Warna outline apa?
7. Perhatikan proporsi: berapa pixel tinggi karakter vs tinggi pohon?
8. Tulis catatan gaya di panel Notes (Window > Notes)
9. Coba replikasi 1 aset kecil (misal batu atau rumput) dengan palet dan teknik yang sama
