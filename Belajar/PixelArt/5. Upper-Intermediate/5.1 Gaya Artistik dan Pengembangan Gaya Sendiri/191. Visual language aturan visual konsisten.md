# 191. Visual Language — Aturan Visual Konsisten

## Definisi Singkat
Sistem aturan visual yang mendefinisikan bagaimana elemen dalam game digambarkan, termasuk proporsi, bentuk, warna, dan level detail, sehingga pemain dapat memahami dunia game secara intuitif.

## Analogi
Bahasa visual seperti alphabet: setiap huruf punya bentuk tetap. Jika A kadang ditulis dengan garis lengkung, kadang kotak, orang tidak bisa membaca. Begitu pula game — pemain perlu "membaca" aset dengan cepat.

## Poin-Poin Penting
- Tentukan "shape language": bulat (ramah), kotak (kokoh/kuat), segitiga (agresif/berbahaya)
- Aturan outline: konsisten untuk semua objek (hitam, berwarna, atau tanpa outline)
- Skala proporsi: manusia normal 4 kepala, karakter chibi 2 kepala — terapkan ke semua karakter
- Teknik rendering: semua objek pakai cel-shading atau semuanya pakai dithering
- Level detail: jangan ada satu objek super detail sementara objek lain sangat minimal
- Hierarki visual: elemen gameplay penting lebih menonjol dari background

## Shortcut & Fitur Aseprite
- Window > Color Palette (F9) untuk palet bersama
- Window > Notes untuk menulis aturan visual
- Layer Groups untuk mengorganisir aset per kategori
- Sprite > Sprite Size untuk standarisasi resolusi
- View > Symmetry Mode untuk bentuk simetris konsisten

## Contoh Kasus Nyata (Step-by-Step)
Membangun visual language untuk game platformer:

1. Tulis aturan di Notes:
   - Outline: 1px hitam (#1a1a2e) untuk semua objek
   - Proporsi: karakter 3 kepala tinggi
   - Shading: cel-shading 3 tone (highlight, mid, shadow)
   - Shape language: musuh pakai segitiga, karakter ramah pakai lingkaran
2. Buat karakter: lingkaran untuk kepala, tubuh bulat, outline 1px
3. Buat musuh pertama: bentuk segitiga (topi runcing, tubuh kotak), outline 1px
4. Buat platform: kotak persegi panjang, outline 1px
5. Review: apakah semua aset terlihat seperti dari game yang sama?
6. Jika ada yang aneh, sesuaikan — misal ubah ketebalan outline atau tambah anti-aliasing
7. Dokumentasikan aturan final di file art bible terpisah
