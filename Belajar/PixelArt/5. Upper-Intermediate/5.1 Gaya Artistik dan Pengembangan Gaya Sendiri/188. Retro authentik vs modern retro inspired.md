# 188. Retro Authentik vs Modern Retro Inspired

## Definisi Singkat
Perbandingan antara pixel art yang mengikuti batasan teknis era tertentu (retro authentik) dengan pixel art yang menggunakan estetika retro tetapi tanpa batasan ketat (modern retro inspired).

## Analogi
Retro authentik seperti membuat film dengan kamera 8mm — terbatas grain, warna pudar, durasi pendek. Modern retro inspired seperti film modern yang diedit pakai filter vintage — terlihat retro tapi punya resolusi高清, warna kaya, dan efek canggih.

## Poin-Poin Penting
- Retro authentik: palet terbatas (4–16 warna per sprite), resolusi rendah (16x16–32x32), teknik era tertentu (NES, SNES, GB, C64)
- Modern retro inspired: palet bebas, resolusi lebih tinggi, blending gradient, efek lighting modern
- Retro authentik lebih cepat di-render dan autentik untuk game dengan batasan performa
- Modern retro inspired lebih fleksibel dan menarik untuk pasar mainstream
- Banyak game modern menggabungkan keduanya: sprite retro dengan efek post-processing modern
- Pilih retro authentik jika target: nostalgia hardcore, game jam dengan batasan, atau homage spesifik

## Shortcut & Fitur Aseprite
- Sprite > Color Mode > Indexed untuk membatasi palet otomatis
- Colors > Palette > Preset > NES, PICO-8, Game Boy (retro authentik)
- Sprite > Sprite Size (resize dengan Nearest Neighbor untuk retro look)
- Filter > RGB > HSV (untuk shift warna gaya modern)
- Layer Blend Mode (untuk efek modern seperti glow, multiply)

## Contoh Kasus Nyata (Step-by-Step)
Buat satu sprite karakter dalam dua gaya:

1. Buat file baru 16x16, Color Mode: Indexed, palet PICO-8 (16 warna)
2. Gambar karakter kotak-kotak dengan outline hitam — ini retro authentik
3. Simpan sebagai "karakter_retro.aseprite"
4. Buat file baru 64x64, Color Mode: RGB
5. Gambar karakter yang sama tapi dengan detail lebih, shading smooth, highlight putih
6. Tambah layer efek: Layer baru > Blending Mode > Glow, cat highlight kuning tipis
7. Simpan sebagai "karakter_modern.aseprite"
8. Bandingkan keduanya — perhatikan perbedaan kesan, jumlah detail, dan mood
