# 248. Character Pack Animasi Lengkap

## Definisi Singkat
Character pack animasi lengkap adalah kumpulan sprite karakter dengan berbagai animasi (idle, walk, run, attack, hurt, death) dalam satu paket siap pakai untuk game.

## Analogi
Seperti action figure dengan berbagai aksesoris—satu karakter dasar bisa dipasangi berbagai pose dan ekspresi tanpa perlu beli karakter baru.

## Poin-Poin Penting
- Minimal animasi: idle (4-6 frame), walk (8 frame), run (6 frame), attack (6 frame), hurt (2-4 frame), death (6-8 frame)
- Semua animasi dalam satu spritesheet untuk efisiensi engine
- Setiap frame harus konsisten dalam ukuran dan posisi pivot point
- Sertakan hitbox data: bounding box untuk collision detection
- Variasi warna (palette swap) untuk multiple characters dari 1 sheet
- Format: .png spritesheet + .aseprite + .gif masing-masing animasi
- Dokumentasikan frame rate yang direkomendasikan per animasi
- Animasi harus loopable (frame pertama dan terakhir nyambung)

## Shortcut & Fitur Aseprite
- **Tab** — Buka/tutup timeline untuk animasi
- **Alt+N** — New frame di timeline
- **Onion Skin (tombol bawang)** — Lihat frame sebelumnya untuk referensi
- **Ctrl+C / Ctrl+V** — Copy-paste frame untuk mempercepat
- **Ctrl+Shift+T** — Timeline settings: ubah frame duration

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file 192x32 (6 animasi x 32px width)
2. Animasi 1: Idle — 4 frame (karakter diam, nafas sedikit bergerak)
3. Animasi 2: Walk — 8 frame (fase 1: kaki kiri maju, fase 2: kaki kanan maju)
4. Animasi 3: Run — 6 frame (gerakan lebih ekstrem dari walk)
5. Animasi 4: Attack — 6 frame (ready → swing → follow-through → back)
6. Animasi 5: Hurt — 2 frame (normal → kena damage → blinking)
7. Animasi 6: Death — 6 frame (stagger → jatuh → menghilang)
8. Export Sprite Sheet: File > Export > Sprite Sheet, set spacing 1px antar frame
9. Export masing-masing animasi sebagai GIF: File > Export > Export as GIF
10. Dokumentasi: tulis frame rate (idle: 8fps, walk: 12fps, run: 15fps, attack: 10fps)
11. ZIP + upload ke itch.io dengan harga $14.99
