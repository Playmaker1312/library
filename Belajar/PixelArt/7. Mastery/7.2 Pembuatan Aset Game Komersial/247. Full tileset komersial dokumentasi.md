# 247. Full Tileset Komersial Dokumentasi

## Definisi Singkat
Full tileset komersial adalah kumpulan tile yang dirancang untuk digunakan dalam game, lengkap dengan dokumentasi teknis seperti grid size, tile placement, collision data, dan panduan implementasi.

## Analogi
Seperti buku petunjuk LEGO—setiap balok (tile) punya ukuran dan fungsi spesifik, plus contoh bagaimana merangkainya jadi castle, village, atau dungeon.

## Poin-Poin Penting
- Tileset harus auto-tile ready: buat tile edge, corner, dan center
- Dokumentasi mencakup: ukuran tile (16x16/32x32), jumlah tile, palet warna
- Sertakan tilemap contoh: bagaimana tile ditempatkan di game engine
- Format file: .png spritesheet + .aseprite source + .json tile data
- Tile harus seamless: ujung kiri nyambung ke ujung kanan
- Beri nama tile secara konsisten: grass_1, grass_2, water_top, dll
- Sertakan legend/warna: merah=collision, biru=water, hijau=walkable
- Buat preview in-game screenshot sebagai referensi

## Shortcut & Fitur Aseprite
- **Ctrl+B** — Bersihkan selection untuk tile cropping presisi
- **View > Symmetry Mode** — Tile horizontal/vertical untuk seamless
- **File > Export Sprite Sheet** — Output tileset sebagai strip PNG
- **Sprite > Sprite Size** — Set ukuran konsisten (misal 128x128 untuk 4x4 tile)
- **Grid > Grid Settings** — 16x16 atau 32x32 sesuai tile size

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 128x128 (4x4 tile ukuran 32x32)
2. Gambar tile: grass (1), grass_flower (2), path (3), water (4), tree_base (5), tree_top (6), wall (7), door (8)
3. Atur layer: Layer 1 = base terrain, Layer 2 = dekorasi
4. Export Sprite Sheet: File > Export Sprite Sheet, atur columns=4, rows=2
5. Buka Notepad, buat dokumentasi TXT:
   - [0,0] grass — walkable
   - [1,0] grass_flower — walkable, dekoratif
   - [2,0] path — walkable
   - [3,0] water — non-walkable, slow
   - [0,1] tree_base — blocker
   - [1,1] tree_top — di atas karakter
6. Sertakan file .json dengan data collision: {"tiles":[{"id":0,"collision":false}, ...]}
7. ZIP semua file: spritesheet.png, source.aseprite, dokumentasi.txt, data.json
8. Upload ke itch.io dengan harga $9.99
