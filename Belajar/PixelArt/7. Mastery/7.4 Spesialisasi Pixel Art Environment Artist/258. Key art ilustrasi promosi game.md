# 258. Key Art Ilustrasi Promosi Game

## Definisi Singkat
Key art adalah ilustrasi pixel art ukuran besar yang berfungsi sebagai gambar wajah promosi game—digunakan di banner Steam, thumbnail YouTube, cover itch.io, dan poster.

## Analogi
Seperti poster film blockbuster—dalam satu gambar harus menceritakan genre, mood, karakter utama, dan dunia game. Orang memutuskan "nonton atau tidak" dari poster ini.

## Poin-Poin Penting
- Resolusi besar: 1920x1080 minimal (key art bukan pixel kecil, detail di-pixel dengan presisi)
- Hierarki visual: karakter utama di center/foreground, background menunjukkan environment
- Komposisi rule of thirds: grid 3x3, letakkan elemen penting di persimpangan garis
- Pencahayaan dramatis: backlight, rim light, atau vignette untuk depth
- Palet warna terbatas tapi kontras: gunakan palet yang mencerminkan mood game
- Sertakan logo game atau title (bisa teks pixel art)
- Hindari terlalu banyak detail—buat fokus ke satu visual hero
- Format final: PNG 32-bit dengan alpha untuk fleksibilitas placement

## Shortcut & Fitur Aseprite
- **Ctrl+N** — File baru 1920x1080, Color Mode: RGB (bukan Indexed untuk key art)
- **Layer > New Layer** — Layer: Background, Midground, Foreground, Character, Effects
- **Ctrl+T** — Transform elemen besar dengan Free Transform
- **Blending Mode (Screen, Multiply)** — Efek lighting dan shadow
- **View > Zoom Out (Ctrl+-)** — Cek komposisi keseluruhan secara berkala

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file 1920x1080, palet terbatas 32 warna
2. Layer 1 (Background): gradien langit senja (ungu ke oranye) — dithering untuk transisi
3. Layer 2 (Midground): silhouettes gunung dan hutan — warna gelap untuk depth
4. Layer 3 (Castle): bangunan kastil di tengah, detail jendela dan atap
5. Layer 4 (Character): hero utama di depan, pose dinamis (pedang terangkat)
6. Layer 5 (Foreground): bayangan gelap di pinggir (vignette) untuk frame
7. Layer 6 (Effects): particle cahaya (screen blending mode) + debu
8. Layer 7 (Text): judul game "REALM OF SHADOWS" di bagian bawah, font pixel art
9. Cek komposisi: zoom ke 25% untuk lihat key art secara utuh
10. Export PNG 32-bit RGBA: File > Export > PNG
11. Simpan .aseprite sebagai master file untuk revisi
