# 257. Full Tileset Biome Hutan Kastil Gua Kota

## Definisi Singkat
Full tileset biome adalah kumpulan tile untuk berbagai lingkungan game—hutan, kastil, gua, dan kota—yang didesain sebagai satu paket konsisten dengan transisi seamless antar biome.

## Analogi
Seperti set Lego tematik—dalam satu kotak besar ada bagian hutan (pohon, semak), kastil (batu bata, menara), gua (stalaktit, lava), dan kota (jalan, rumah). Semua bisa digabung karena ukuran dan gaya sama.

## Poin-Poin Penting
- Setiap biome minimal: 16 tile terrain + 8 tile dekorasi + 4 tile struktural
- Gunakan base tile yang bisa di-autotile: grass, dirt, stone, sand, water
- Transisi antar biome: tile edge yang nyambung (grass→dirt, dirt→stone)
- Palet warna konsisten antar biome (hindari perbedaan kontras mencolok)
- Tiap biome punya signature elements: hutan=daun, kastil=bendera, gua=kristal, kota=atap
- Pastikan tile bisa di-repeat horizontal dan vertikal (seamless)
- Dokumentasi: grid map per biome + collision data
- Size tile konsisten untuk semua biome (16x16 atau 32x32)

## Shortcut & Fitur Aseprite
- **Grid Settings** — Set grid 16x16 untuk presisi tile
- **Ctrl+Shift+X** — Crop tile individual untuk export terpisah
- **File > Export Sprite Sheet** — Output semua biome dalam satu sheet
- **View > Symmetry Mode** — Bikin tile simetris lebih cepat
- **Layer > Group** — Group per biome di layer panel

## Contoh Kasus Nyata (Step-by-Step)
1. Tentukan ukuran tile: 16x16, buat file 128x128 (8x8 tile per biome)
2. Biome 1 — Forest:
   - Grass tile (4 varian): grass_1, grass_2, grass_flower, grass_rock
   - Path: dirt_path_h, dirt_path_v, dirt_path_cross
   - Water: water_tile, water_edge, water_corner
   - Dekorasi: tree (2x2 tile), bush, flower, stump
3. Biome 2 — Castle:
   - Floor: stone_floor (4 varian), carpet_tile
   - Wall: wall_stone, wall_window, wall_door
   - Dekorasi: torch, banner, throne, pillar
4. Biome 3 — Cave:
   - Floor: cave_floor (4 varian)
   - Wall: cave_wall, stalactite, stalagmite
   - Lava: lava_tile, lava_edge, lava_glow
5. Biome 4 — Town:
   - Road: road_stone (4 varian)
   - Building: wall_house, roof_red, roof_brown, door_wood, window
6. Export: File > Export Sprite Sheet, set columns 16, rows 16
7. Buat dokumentasi per biome: grid posisi + fungsi tiap tile
8. Buat file .json collision: {"tiles": {"0": {"biome":"forest","type":"grass","walkable":true}, ...}}
