# 260. Kolaborasi Level Designer Tileset

## Definisi Singkat
Kolaborasi dengan level designer adalah proses kerja sama antara pixel artist dan perancang level untuk memastikan tileset mendukung gameplay, navigasi, dan estetika level game.

## Analogi
Seperti pembuat panggung teater dan sutradara—pembuat panggung (artist) menyediakan dekorasi, sutradara (level designer) mengatur posisi aktor dan properti. Keduanya harus sepakat ukuran panggung dan pintu keluar-masuk.

## Poin-Poin Penting
- Diskusikan tile grid dan collision requirements sebelum mulai menggambar
- Level designer butuh tile modular: tile yang bisa dikombinasi dalam berbagai konfigurasi
- Sediakan tile "empty" untuk area kosong dan tile "blocker" untuk batas level
- Buat tile dengan multiple variasi agar level tidak monoton
- Beri nama tile dengan sistem kode: T_GRS_01 (Terrain_Grass_01)
- Dokumentasi tile functions: walkable, climbable, deadly, slippery
- Test tileset langsung di game engine bersama level designer
- Siapkan template tilemap kosong untuk level designer mulai bekerja

## Shortcut & Fitur Aseprite
- **Ctrl+Shift+X** — Crop tile untuk export individual
- **File > Export Sprite Sheet** — Output tileset dengan format array
- **Layer > Group** — Group tile berdasarkan tipe: terrain, decoration, structure
- **Grid Settings** — Set grid sesuai ukuran tile (16x16/32x32)
- **View > Grid** — Toggle grid untuk verifikasi alignment

## Contoh Kasus Nyata (Step-by-Step)
1. Meeting dengan level designer: sepakati tile size 16x16, world size 256x240
2. Tentukan tile requirements:
   - Terrain: grass, dirt, stone, water, sand
   - Collision: walkable (hijau), blocker (merah), deadly (kuning)
   - Dekorasi: bush, rock, flower, lamp post
3. Buka Aseprite, buat file 80x64 (5 row x 4 col tile 16x16)
4. Row 1: grass (4 varian: plain, flower, rock, tall)
5. Row 2: dirt (4 varian: plain, path_h, path_v, cross)
6. Row 3: stone (4 varian: plain, wall, broken, platform)
7. Row 4: water (4 varian: still, flow_h, flow_v, deep)
8. Row 5: dekorasi (bush, rock, flower, lamp)
9. Export Sprite Sheet + JSON dengan tag per row
10. Kirim prototyping pack ke level designer: tileset.png + .json + dokumentasi
11. Level designer test di Tiled editor → feedback tile yang kurang
12. Iterasi: tambah tile berdasarkan kebutuhan gameplay (misal slope tile untuk ramp)
