# 270. Lospec Dot Com Platform Komunitas

## Definisi Singkap
Lospec.com adalah platform komunitas pixel art yang menyediakan palette list, tutorial, alat online, dan direktori sumber daya untuk pixel artist dari segala level.

## Analogi
Seperti perpustakaan umum digital—ada buku (tutorial), alat tulis (tools online), katalog warna (palette list), dan ruang baca (forum diskusi). Semua gratis.

## Poin-Poin Penting
- **Palette List** (lospec.com/palette-list): ribuan palet warna untuk pixel art
  - Filter: ukuran palet, warna dominan, popularitas
  - Unduh: .png, .hex, .aseprite, .gpl, .txt
- **Pixel Art Tools**: palette generator, color picker, dithering generator
- **Tutorial**: koleksi artikel dari dasar hingga lanjutan
- **Lospec Discord**: komunitas aktif, feedback, challenge
- **Pocket Palette**: ekstensi Chrome untuk akses palet langsung di browser
- **Format file palet**: .aseprite, .hex, .gpl (GIMP), .png, .txt
- Semua sumber daya gratis — didukung oleh donasi dan Patreon

## Shortcut & Fitur Aseprite
- **Windows > Palettes** — Panel palet di Aseprite
- **Palette > Load Palette** — Import palet dari Lospec (.aseprite, .hex, .gpl)
- **Palette > New Palette** — Buat palet baru dari referensi Lospec
- **File > Export > PNG** — Export palet untuk share
- **Sprite > Color Mode > Indexed** — Gunakan palet terbatas

## Contoh Kasus Nyata (Step-by-Step)
1. Buka browser → lospec.com → klik "Palette List"
2. Filter: "16 colors" + "Cool colors" + "All time popular"
3. Pilih palet "Nintendo Gameboy" (4 warna hijau)
4. Klik "Download" → pilih format .aseprite
5. Buka Aseprite → Windows > Palettes → Import → pilih file .aseprite
6. Buat sprite 16x16 dengan palet Gameboy
7. Coba buka palette "PICO-8" (16 warna) → download .png sebagai referensi
8. Buka Lospec > "Pixel Art Tutorials" → baca "Dithering Guide for Beginners"
9. Praktik teknik dithering dari tutorial ke sprite yang sedang dikerjakan
10. Buka Lospec > "Online Tools" → gunakan "Palette Generator" dari gambar referensi
11. Upload gambar → generate palette → download .aseprite → load di Aseprite
12. Join Lospec Discord → channel #pixel-art → post hasil + diskusi
