# 267. Dokumentasi Resmi Aseprite Wiki

## Definisi Singkat
Dokumentasi resmi Aseprite (community wiki) adalah sumber informasi paling otoritatif tentang fitur, shortcut, tools, dan workflow Aseprite yang dikelola oleh developer dan komunitas.

## Analogi
Seperti buku manual mobil—semua tombol, lampu indikator, dan prosedur perawatan ada di sana. Tidak perlu hafal semua, tapi tahu di mana mencarinya saat butuh.

## Poin-Poin Penting
- URL: github.com/aseprite/aseprite/wiki atau docs.aseprite.com
- Section penting: Tools (Pencil, Eraser, Fill), Layers, Frames, Tiles, Palettes, Color Modes
- Halaman "Keyboard Shortcuts" — daftar lengkap shortcut yang bisa dikustom
- "Sprite Sheet Export" — panduan export dengan JSON data
- "Tiled Mode" — dokumentasi tilemap dan tile editing
- "Scripting" — Lua API untuk automation dan custom tools
- "FAQ dan Troubleshooting" — solusi masalah umum
- Wiki dikelola komunitas: bisa berkontribusi/edit jika ada info kurang

## Shortcut & Fitur Aseprite
- **F1** — Buka help browser langsung di Aseprite (offline)
- **Ctrl+Shift+P** — Preferences untuk kustomisasi shortcut
- **Help > Keyboard Shortcuts Reference** — PDF cheat sheet
- **Help > About** — Cek versi Aseprite untuk kompatibilitas
- **Help > Scripting Help** — Dokumentasi API scripting

## Contoh Kasus Nyata (Step-by-Step)
1. Buka browser → buka docs.aseprite.com atau github wiki
2. Cari "How to export sprite sheet with metadata": buka page "Sprite Sheet Export"
3. Baca format JSON yang dihasilkan: frame width, height, position, duration
4. Cari "Tiled Mode": buka page "Tiles" → pelajari cara kerja tilemap
5. Coba praktik: buka Aseprite, aktifkan Tiled Mode (Edit > Tiled Mode > All Layers)
6. Gambar tile 16x16 dengan seamless pattern
7. Cek shortcut: buka page "Keyboard Shortcuts" → catat shortcut baru untuk workflow
8. Jika ada bug: cek page "FAQ" atau GitHub Issues
9. Untuk automation: buka "Scripting" → pelajari API Lua dasar
10. Contoh script: buat export semua frame otomatis dengan File > Export > Scripting
11. Kontribusi: jika ada info kurang, edit wiki via GitHub pull request
