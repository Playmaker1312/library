# 244. Rate Card Package Service Freelance

## Definisi Singkat
Rate card package service adalah dokumen resmi berisi paket layanan, harga, dan ketentuan yang ditawarkan pixel artist freelance kepada calon klien secara terstruktur.

## Analogi
Seperti paket internet—ada paket basic (cuma sprite), paket standard (sprite+animasi), dan paket premium (full game assets). Pelanggan tinggal pilih sesuai kebutuhan dan budget.

## Poin-Poin Penting
- Buat 3-4 paket berjenjang: Basic, Standard, Premium, Enterprise
- Setiap paket mencakup: jumlah aset, resolusi, animasi, revisi, lisensi
- Sertakan timeline estimasi per paket
- Harga paket biasanya diskon 10-20% dibanding beli satuan
- Rate card harus PDF profesional dengan branding
- Cantumkan metode pembayaran (PayPal, Crypto, Bank Transfer)
- Update rate card setiap tahun mengikuti inflasi dan skill improvement
- Sertakan portofolio singkat di halaman belakang

## Shortcut & Fitur Aseprite
- **Ctrl+Shift+E** — Export aset untuk sample preview di rate card
- **File > Save As > .png** — Preview aset di dokumen
- **Sprite > Properties** — Dokumentasi spesifikasi teknis
- **Ctrl+Shift+X** — Crop bersih untuk sample gambar
- **View > Grid** — Tampilkan grid sebagai watermark teknis

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Canva atau Google Docs, buat template rate card
2. Halaman 1: Header (nama, logo, tagline) + daftar paket
   - Basic: 5 sprite 16x16, 2 animasi, 1 revisi — $100
   - Standard: 10 sprite 32x32, 4 animasi, 2 revisi — $250
   - Premium: 20 sprite 64x64, 8 animasi, 3 revisi — $500
3. Halaman 2: Spesifikasi teknis per paket (format file, resolusi, lisensi)
4. Halaman 3: Terms & Conditions (revisi, refund, hak cipta, NDA)
5. Halaman 4: Portofolio contoh hasil per paket
6. Export sebagai PDF dari Canva (File > Download > PDF)
7. Upload ke Google Drive, set link ke public view-only
8. Siapkan teks singkat untuk DM: "Hi! Ini rate card saya untuk project pixel art. Jika ada yang cocok, kita diskusi lebih lanjut :)"
