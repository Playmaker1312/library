# 242. Pasar Kerja Pixel Artist Game Studio Freelance

## Definisi Singkat
Pasar kerja pixel artist mencakup peluang di studio game indie, menengah, dan platform freelance yang membutuhkan aset pixel art untuk proyek komersial.

## Analogi
Seperti pasar tradisional—ada lapak tetap (studio tetap), lapak musiman (game jam), dan pedagang keliling (freelance marketplace). Tiap pelanggan butuh pendekatan berbeda.

## Poin-Poin Penting
- Studio indie paling sering rekrut pixel artist lewat Twitter/X dan itch.io
- Platform freelance: Upwork, Freelancer, Fiverr, Pixel Joint
- Gaji freelance: $15-50/jam untuk pixel art menengah; $50-150/jam untuk senior
- Proyek umum: tileset, character sprites, UI assets, animasi
- Waktu kerja rata-rata: 2-6 minggu per proyek game indie
- Burning game studios menawarkan gaji tetap bulanan
- Networking di Discord server gamedev membuka peluang hidden job market

## Shortcut & Fitur Aseprite
- **Ctrl+N** — Buat file baru dengan preset umum (16x16, 32x32, dll)
- **Tab** — Toggle timeline untuk ngecek frame animation
- **Ctrl+Shift+N** — Layer baru untuk organisasi aset
- **View > Show > Layer Edges** — Lihat bounding box setiap layer
- **File > Export > Export as PNG** — Kirim preview cepat ke klien

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Twitter/X, cari hashtag #pixelart #lookingforwork #gamedev
2. Kunjungi itch.io → Jobs → cari "pixel artist" di bagian job board
3. Buka server Discord "Pixel Art Guild" atau "Game Developer League"
4. Di channel #freelance, post portofolio dengan rate card singkat
5. Cek Upwork → buat proposal untuk proyek "2D pixel art tileset"
6. Tulis cover letter: sebutkan tools (Aseprite), pengalaman, dan link portofolio
7. Negosiasi milestone: 30% DP, 40% progress, 30% final
8. Kirim contract via Google Docs yang menyebutkan hak lisensi dan revisi
