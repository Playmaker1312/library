# 255. Kolaborasi Programmer Game Mechanic

## Definisi Singkat
Kolaborasi dengan programmer adalah proses kerja sama antara pixel artist dan developer game untuk memastikan aset visual mendukung mekanik game secara teknis dan fungsional.

## Analogi
Seperti arsitek dan kontraktor—arsitek (artist) mendesain rumah (aset), kontraktor (programmer) membangun strukturnya. Jika desain tidak realistis secara teknis, rumah tidak akan berdiri kokoh.

## Poin-Poin Penting
- Komunikasikan pivot point dan origin setiap sprite sejak awal
- Beri nama aset sesuai konvensi yang programmer gunakan di code
- Sediakan spritesheet dengan grid spacing 1px untuk memudahkan slicing
- Buat collision box terpisah (hitbox, hurtbox) menggunakan layer warna
- Frame rate animasi harus disepakati bersama (biasanya 12fps atau 24fps)
- Gunakan version control (Git) untuk file .aseprite mentah
- Dokumentasi teknis minimal: ukuran, jumlah frame, nama file, animation tag
- Build dan test aset langsung di game engine secara berkala

## Shortcut & Fitur Aseprite
- **File > Export Sprite Sheet** — Output dengan data .json untuk engine
- **Tag (Ctrl+Shift+J)** — Beri nama tiap animasi (idle, walk, attack)
- **Layer > Group** — Kelompokkan layer untuk masing-masing state
- **View > Show > Slice** — Tampilkan slice untuk hitbox visual
- **File > Export > .gif** — Kirim animasi test ke programmer untuk review cepat

## Contoh Kasus Nyata (Step-by-Step)
1. Programmer request: "Karakter 32x32, animasi idle (4f), walk (8f), jump (5f)" dan file JSON
2. Buka Aseprite, buat file 96x64 untuk spritesheet (3 baris animasi)
3. Baris 1: idle (4 frame x 32px)
4. Baris 2: walk (8 frame x 32px)
5. Baris 3: jump (5 frame x 32px)
6. Gunakan Tag: blok frame idle → Ctrl+Shift+J → nama "idle"
7. Tag frame walk → "walk", tag frame jump → "jump"
8. Export Sprite Sheet: File > Export > Sprite Sheet
   - Atur columns=8 (max frame count)
   - Aktifkan "Output JSON" → pilih format "Hash" untuk data per tag
9. Kirim ke programmer: spritesheet.png + spritesheet.json
10. Test di Unity/Godot: minta programmer jalankan, cek apakah animasi sesuai tag
11. Iterasi: jika ada frame offset, adjust pivot di Aseprite dan re-export
