# 231. Texture Memory Optimasi Sprite Sheet

## Definisi Singkat
Teknik mengoptimasi penggunaan memori texture pada sprite sheet — mengurangi ukuran file dan VRAM usage tanpa mengorbankan kualitas visual signifikan.

## Analogi
Seperti packing koper: jika Anda memasukkan barang dengan rapi (dilipat, diatur), lebih banyak barang yang muat. Sprite sheet optimization adalah "packing" pixel ke dalam texture dengan efisien.

## Poin-Poin Penting
- **Texture size constraint**: ukuran harus power of 2 (POT) — 32, 64, 128, 256, 512, 1024, 2048px
- **Atlas efficiency**: isi area kosong seminimal mungkin, target >85% utilization
- **Format compression**: PNG (loseless) untuk pixel art, WebP (lossy) jika diizinkan
- **Color depth**: indexed PNG (8-bit) lebih kecil dari RGBA (32-bit) — kurangi 75% ukuran
- **Remove duplicate frames**: jika ada frame identik, gunakan reference/sprite reuse
- **Trim transparency**: crop area transparan di sekitar sprite — potong ukuran canvas
- **Mipmaps**: matikan untuk pixel art — mipmaps buat blur pada sprite kecil

## Shortcut & Fitur Aseprite
- `File → Export Sprite Sheet` (`Ctrl+Shift+E`): pengaturan output size, padding, trim
- Opsi "Trim" di export: hapus transparansi berlebih otomatis
- "Merge Cels" untuk gabung layer jadi satu
- "Border Padding": tambah 1-2px antar sprite untuk mencegah bleeding
- Output size: bisa paksa 512x512 atau 1024x1024
- `Sprite → Color Mode → Indexed`: konversi indexed untuk file lebih kecil

## Contoh Kasus Nyata (Step-by-Step)

### Optimasi Sprite Sheet Karakter
1. **Before**: 20 frame animasi @64x64 = 20 sprite terpisah = 320x640 canvas = 204800 piksel = ~80KB PNG
2. **Trim**: Hapus transparansi — crop ke ukuran sprite efektif (48x56 rata-rata)
3. **Arrange**: Susun rapi di atlas 256x256 = 65536 piksel
4. **Convert Indexed**: RGBA (32-bit) → Indexed 256 warna → ukuran turun ~75%
5. **After**: Satu file 256x256 indexed PNG = ~8-12KB — 85% lebih kecil

### Sprite Packing Rules
1. Frame statis di kiri atas, frame animasi berurutan
2. Sisakan padding 1px antar sprite
3. Jika ada sprite <16px, group jadi satu tile
4. Jangan campur sprite dengan palette berbeda dalam satu sheet
