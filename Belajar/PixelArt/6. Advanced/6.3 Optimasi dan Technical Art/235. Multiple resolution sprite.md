# 235. Multiple Resolution Sprite

## Definisi Singkat
Teknik menyediakan beberapa versi sprite dalam resolusi berbeda untuk mendukung berbagai ukuran layar dan device tanpa kehilangan kualitas visual pixel art.

## Analogi
Seperti mencetak foto: foto kecil (3x4) terlihat tajam, tapi jika diperbesar ke poster (A3) tanpa resolusi cukup, akan pecah. Multiple resolution sprite menyediakan ukuran "cetakan" yang sesuai untuk setiap layar.

## Poin-Poin Penting
- **Resolusi umum**: 16x16 (retro), 32x32 (standar), 48x48 (HD), 64x64+ (ultra HD)
- **Up-scaling pixel art**: jangan gunakan bilinear interpolation — pakai nearest neighbor
- **Down-scaling**: sprite resolusi tinggi di-downscale ke rendah — hasil lebih baik dari upscale
- **Floating-point pixel**: saat sprite di posisi sub-pixel, bisa terjadi jitter — perlu snap ke grid
- **3 metode**:
  1. Single resolution + nearest-neighbor scaling (paling umum)
  2. Multiple fixed resolutions (siapkan 16px, 32px, 48px versi)
  3. Vector-like pixel art (gambar di resolusi tinggi, scale down)
- **Base resolution**: tentukan base (misal 32x32) dan scale integer (1x, 2x, 3x)

## Shortcut & Fitur Aseprite
- `Sprite → Sprite Size` (`Ctrl+Shift+S`): resize entire sprite — pilih "Nearest Neighbor"
- `Edit → Transform → Scale` (`Ctrl+T`): scale selection
- Export at multiple sizes: `File → Export` → atur scale di export options
- Resize canvas + scale content untuk multiple resolution workflow
- Gunakan mode indexed agar warna konsisten setelah resize

## Contoh Kasus Nyata (Step-by-Step)

### Multiple Resolution untuk Mobile + Desktop
1. **Base**: Buat karakter di 64x64 (resolusi maksimal)
2. **Downscale** untuk resolusi lebih rendah:
   - 64x64: high-end desktop
   - 48x48: tablet
   - 32x32: mobile
   - 16x16: very low-end / retro mode
3. **Metode**: Resize sprite dari 64x64 ke 48x48 dengan Nearest Neighbor → manual touch-up
4. **Touch-up**: Setelah downscale, periksa detail kecil — mata mungkin hilang di 16x16, perlu digambar ulang

### Integer Scaling (Paling Aman)
1. Base sprite 32x32
2. Scale 2x = 64x64 (tambah piksel tanpa artefak)
3. Scale 3x = 96x96
4. Kelebihan: kualitas terjaga sempurna, tanpa blur
5. Kekurangan: ukuran layar terbatas ke kelipatan integer

### HD → Retro Conversion
1. Gambar di 128x128 dengan detail tinggi
2. Downscale ke 32x32
3. Manual refine: perbaiki piksel yang hilang
4. Hasil: sprite 32x32 dengan komposisi proporsional baik
