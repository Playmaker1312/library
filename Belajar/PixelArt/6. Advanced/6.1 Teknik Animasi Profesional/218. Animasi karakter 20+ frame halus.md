# 218. Animasi Karakter 20+ Frame Halus

## Definisi Singkat
Animasi karakter dengan jumlah frame sangat banyak (20-60+ frame per siklus) untuk menghasilkan gerakan super halus dan realistis, mendekati 60fps.

## Analogi
Seperti perbedaan video 15fps dengan 60fps — semakin banyak frame per detik, semakin cair gerakannya. Animasi 20+ frame adalah versi premium dari animasi standar 4-8 frame.

## Poin-Poin Penting
- Setiap frame hanya berbeda sedikit dari frame sebelumnya (incremental movement)
- Wajib menggunakan onion skin agar transisi antar frame terlihat
- Teknik smear frame membantu mengaburkan gerakan cepat tanpa perlu detail
- Timing chart diperlukan: frame padat di pose penting, lebih sedikit di gerakan cepat
- Animasi 20+ frame cocok untuk: idle breath, walk cycle cinematic, attack combo panjang
- Gunakan frame caching / tag frame di Aseprite untuk organisasi

## Shortcut & Fitur Aseprite
- Onion Skin: tombol onion di timeline atau `Ctrl+Shift+O` — aktifkan 2-3 frame sebelumnya
- New Frame: `Alt+B` atau `Shift+F5`
- Timeline tagging: klik kanan di timeline → "Add Tag" untuk group frame
- Copy Cels: `Alt+C` untuk duplikasi cel spesifik
- Auto cel linking matikan agar setiap frame bisa diedit independen

## Contoh Kasus Nyata (Step-by-Step)

### Membuat Idle Breathing 24 Frame
1. Buat karakter idle standar (8 frame pertama sebagai base)
2. Duplikasi jadi 24 frame: seleksi semua → `Alt+B` 3 kali
3. Frame 1-6: karakter tarik napas (dada naik, bahu sedikit naik)
4. Frame 7-12: puncak napas (tahan, hanya微妙 gerak)
5. Frame 13-18: buang napas (dada turun, bahu relaks)
6. Frame 19-24: bottom napas (tahan sebelum siklus baru)
7. Aktifkan onion skin 3 frame untuk memastikan transisi mulus
8. Gunakan smear tool (smudge) di frame gerak cepat jika ada

### Walk Cycle Cinematic 32 Frame
1. Buat 8 frame walk cycle standar
2. Interpolasi manual: sisipkan 3 frame di antara setiap 2 frame original
3. Total: 8 keyframe + 24 in-between = 32 frame
4. Perhatikan swing tangan, head bob, dan plant foot dengan detail
5. Test play di Aseprite dengan 60fps preview
