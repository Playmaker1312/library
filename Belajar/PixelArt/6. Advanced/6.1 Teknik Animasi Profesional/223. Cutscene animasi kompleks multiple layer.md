# 223. Cutscene Animasi Kompleks Multiple Layer

## Definisi Singkat
Pembuatan cutscene dalam game pixel art dengan multiple layer animasi — karakter, background, foreground, efek partikel, dan UI — yang bergerak simultan seperti film pendek.

## Analogi
Seperti panggung teater: ada aktor (karakter), latar belakang (background), properti (foreground), efek cahaya (partikel), dan layar subtitle (UI). Semua bergerak bersamaan membentuk satu adegan kohesif.

## Poin-Poin Penting
- **Layer hierarchy**: background → midground → karakter → foreground → efek → UI
- Setiap elemen punya timeline sendiri — perlu sinkronisasi timing
- **Camera movement**: scroll, pan, zoom bisa disimulasikan dengan menggeser seluruh group layer
- **Parallax cutscene**: background bergerak lebih lambat dari foreground
- **Scene transition**: dissolve, fade-to-black, wipe, slide antar scene
- Gunakan tag warna berbeda untuk tiap elemen di timeline
- **Lip sync**: jika ada dialog, sinkronkan frame mulut dengan teks

## Shortcut & Fitur Aseprite
- Group folders untuk tiap elemen: Background, Characters, FX, UI
- Timeline tagging warna: merah=karakter, biru=background, hijau=efek
- `Ctrl+E` untuk export as sprite sheet jika ingin dipakai di game engine
- Onion skin per-layer — hanya lihat layer yang ingin dicek
- `Alt+L` lock layer agar tidak tergeser saat edit layer lain
- Gunakan `Sprite → Sprite Size` untuk canvas lebih besar (256x144 atau 320x180 untuk cutscene)

## Contoh Kasus Nyata (Step-by-Step)

### Cutscene Sederhana "Pertemuan di Hujan" (120 frame / ~4 detik @30fps)
1. **Layer Background (slow scroll)**: Hutan hujan — layer pohon jauh (scroll pelan), layer pohon dekat (scroll cepat)
2. **Layer Karakter A**: Masuk dari kiri frame (frame 0-40), berjalan ke tengah
3. **Layer Karakter B**: Masuk dari kanan frame (frame 30-70), berhenti
4. **Layer Efek**: Hujan (partikel turun terus), kilat (frame 50-52 flash putih)
5. **Layer Foreground**: Daun/rintik air di lensa (frame 0-120)
6. **Timeline**: Tag frame 0-40 "Intro", 40-80 "Dialog", 80-120 "Outro"
7. Export frame sebagai PNG sequence untuk di-import ke engine

### Multi-layer Fight Cutscene
1. Background: cityscape sunset (parallax 3 layer)
2. Karakter A & B: animasi attack terpisah
3. Efek: dust kick, slash trail, impact spark
4. UI: damage numbers (opsional)
5. Transisi: fade to putih di akhir
