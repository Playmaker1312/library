# 238. Mixed Media Pixel Art Animasi Loop

## Definisi Singkat
Teknik menggabungkan pixel art dengan elemen media lain — grafis vektor, foto, efek 3D, tipografi, atau rekaman video — dalam satu animasi loop yang kohesif.

## Analogi
Seperti kolase digital: Anda bisa memotong kertas (foto), menambahkan cat air (vektor), dan menggambar komik (pixel art) dalam satu kanvas. Mixed media pixel art adalah kolase digital dengan pixel sebagai salah satu elemennya.

## Poin-Poin Penting
- **Pixel + Vektor**: pixel art karakter dengan background vektor gradien smooth
- **Pixel + Foto**: foto lingkungan nyata dengan overlay karakter pixel art (augmented reality feel)
- **Pixel + 3D**: render 3D low-poly + efek pixel art (shader atau overlay)
- **Pixel + Video**: rekaman video sebagai background, karakter pixel art di foreground
- **Konsistensi**: pastikan palette pixel art cocok dengan tone warna media lain
- **Resolusi**: media non-pixel perlu di-resize/resample agar cocok dengan estetika pixel
- **Integrasi**: gunakan efek pixelation parsial pada media non-pixel untuk transisi mulus

## Shortcut & Fitur Aseprite
- `File → Import → Image Sequence...`: import foto/video frame sebagai layer
- `Edit → Tint` (`Ctrl+Shift+T`): recolor imported image agar cocok palette
- Resize imported image: `Ctrl+T` → pilih "Nearest Neighbor" untuk pixelation effect
- Layer blending modes: Multiply, Screen, Overlay — penting untuk integrasi
- Gunakan opacity untuk transisi antara pixel dan non-pixel

## Contoh Kasus Nyata (Step-by-Step)

### Pixel Character + Real Photo Background (16 frame loop)
1. **Cari foto**: Ambil foto taman / street corner (resolusi 512x288)
2. **Import**: `File → Import → Image Sequence` — import sebagai frame tunggal
3. **Pixelation**: Resize foto ke 128x72 (Nearest Neighbor) → pixelated aesthetic
4. **Palette adjustment**: Tint foto agar warnanya match dengan palette pixel (kurangi saturasi)
5. **Buat karakter pixel**: Gambar karakter berjalan di taman (16 frame, 32x48)
6. **Composite**: Karakter di layer atas, foto di layer bawah
7. **Efek**: Tambah shadow pixel di bawah karakter

### Pixel + Vector Gradient Background
1. Buat background gradien di tool vektor (Figma/Illustrator) — export PNG
2. Import ke Aseprite sebagai layer bawah
3. Gambar pixel art cityscape di layer tengah
4. Karakter pixel di layer depan
5. Gunakan blending Screen untuk efek neon sign

### Pixel + 3D Loop
1. Render 3D scene sederhana (Blender) — export frame sequence
2. Import ke Aseprite
3. Gambar pixel art character overlay
4. Hasil: depth 3D dengan karakter pixel 2D
