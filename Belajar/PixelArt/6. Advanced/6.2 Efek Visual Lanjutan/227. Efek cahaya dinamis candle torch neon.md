# 227. Efek Cahaya Dinamis Candle Torch Neon

## Definisi Singkat
Teknik membuat ilusi pencahayaan dinamis pada pixel art — sumber cahaya yang mempengaruhi warna dan kecerahan area sekitarnya secara real-time atau frame-by-frame.

## Analogi
Seperti lampu hias: saat lilin dinyalakan, ruangan di sekitarnya tidak tetap gelap — ada lingkaran cahaya kuning yang berkedip, bayangan bergoyang, dan pantulan di benda mengkilap. Ini yang akan disimulasikan.

## Poin-Poin Penting
- **Tiga zona cahaya**: inti (terang), mid (cahaya pudar), outer (ambient)
- Warna cahaya tergantung sumber: candle (kuning-orange), torch (orange-merah), neon (pink/hijau/biru), moonlight (biru pucat)
- **Animasi flicker**: frame 4-8 untuk candle/torch perubahan intensitas
- **Gradient lighting**: gunakan dithering atau multiple shade untuk transisi smooth
- **Casting shadow**: objek di dekat sumber cahaya memproyeksikan shadow
- **Glow** pada neon: additive blending dengan layer terpisah
- Color palette terbatas per sumber cahaya — warna objek berubah di area terkena cahaya

## Shortcut & Fitur Aseprite
- Layer blending: Screen untuk glow, Multiply untuk shadow
- Gradient tool `G` untuk bikin transisi cahaya cepat
- Eyedropper `I` ambil warna dari area yang terkena cahaya untuk konsistensi
- Onion skin untuk animasi flicker
- Group layer "Lighting" di atas semua layer karakter
- Gunakan opacity layer untuk atur intensitas cahaya

## Contoh Kasus Nyata (Step-by-Step)

### Candle Flicker (8 frame)
1. **Frame 1**: Api lilin normal — layer glow kuning opacity 50%
2. **Frame 2**: Api mengecil — glow opacity 35%
3. **Frame 3**: Api besar — glow opacity 65%
4. **Frame 4**: Api normal — glow opacity 50%
5. **Frame 5-8**: Variasi serupa dengan timing berbeda
6. **Shadow**: Area bayangan di belakang lilin — layer Multiply opacity 30%

### Neon Sign (16 frame loop)
1. **Frame 1-4**: Neon menyala penuh — pink cerah + glow putih (Screen blending)
2. **Frame 5-6**: Neon berkedip — mati 2 frame (gelap total)
3. **Frame 7-12**: Neon menyala lagi dengan flicker cepat
4. **Frame 13-16**: Stabil menyala
5. Efek pantulan neon di lantai/kaca: layer terpisah dengan opacity rendah

### Dynamic Torch Lighting
1. Player memegang obor — area 30px radius di sekitar player jadi terang
2. Obor flicker: frame random perubahan intensitas
3. Wall di dekat player: warnai ulang area wall yang terkena cahaya dengan tone orange
4. Shadow player: bayangan memanjang ke arah berlawanan dari obor
