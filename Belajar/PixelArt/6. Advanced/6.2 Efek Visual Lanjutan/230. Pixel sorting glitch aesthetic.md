# 230. Pixel Sorting Glitch Aesthetic

## Definisi Singkat
Teknik efek visual pixel sorting (mengurutkan piksel berdasarkan warna/kecerahan dalam satu baris/kolom) untuk menciptakan aesthetic glitch, distorsi databend, dan efek visual digital yang unik.

## Analogi
Seperti file gambar yang corrupt — garis-garis warna acak, piksel tertukar, data visual rusak tapi indah. Pixel sorting adalah "kerusakan terkontrol" yang menghasilkan efek artistik.

## Poin-Poin Penting
- **Pixel sorting**: mengambil satu baris/kolom piksel, mengurutkannya berdasarkan brightness/hue/saturation
- **Direction**: horizontal sort, vertical sort, diagonal sort, radial sort
- **Threshold**: hanya piksel dalam rentang brightness tertentu yang di-sort (bisa batasi area)
- **Glitch effect** bisa juga: shift channel RGB, scanline, noise, block corruption
- **Interval sorting**: sort setiap N baris, sisanya tetap
- Kombinasi dengan efek lain: CRT scanline, chromatic aberration, VHS noise
- Pixel sorting manual di Aseprite memakan waktu — gunakan tool eksternal untuk batch

## Shortcut & Fitur Aseprite
- Tidak ada fitur pixel sorting native — tapi bisa manual:
  - Select satu baris piksel → Cut → Sort manual → Paste
  - Atau gunakan mode indexed palette untuk sorting warna
- Channel shift: duplicate layer → shift posisi layer merah/biru → blending mode Screen
- `Ctrl+M` (Merge) setelah efek jika puas
- Gunakan selection tool rectangular untuk area glitch spesifik

## Contoh Kasus Nyata (Step-by-Step)

### Glitch Portrait Manual (Aseprite)
1. **Base**: Karakter/portrait normal, selesai di-render
2. **Horizontal sort**: Select area 32x4 piksel di bagian mata → Cut → Paste ulang dengan offset 2px ke kanan
3. **Channel shift**: Duplikat layer karakter → layer atas blending "Screen" → geser 3px ke kiri → ubah hue ke merah
4. **Block corruption**: Pilih area 8x8 acak → fill dengan noise (pattern piksel acak)
5. **Scanline**: Buat layer baru → fill pattern garis horizontal setiap 2px dengan warna hitam → opacity 20%

### Pixel Sorting via External Tools
1. Export sprite sebagai PNG
2. Buka di Processing/Python dengan library PIL — script sorting sederhana
3. Import hasil kembali ke Aseprite sebagai layer efek
4. Campur dengan original (blending/opacity)

### Random Glitch Frame (untuk animasi)
1. Frame normal 1-3
2. Frame 4: glitch — pixel sort area kecil + channel shift
3. Frame 5-6: kembali normal
4. Hasil: efek glitch "sekilas" yang realistis
