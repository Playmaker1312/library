# 158. Animasi UI Transisi Menu Particle

## Definisi Singkat
Teknik menganimasi elemen UI (user interface) — tombol hover, transisi menu, partikel dekoratif — untuk memberikan pengalaman pengguna yang responsif dan memukau.

## Analogi
Seperti smartphone yang memberikan feedback visual saat tombol disentuh: efek riak, perubahan warna, atau animasi halus yang membuat interaksi terasa "hidup".

## Poin-Poin Penting
- Animasi UI harus cepat (<200ms) agar tidak membuat menunggu
- Tombol hover: 2-3 frame — scale up, color shift, atau glow
- Transisi halaman: fade, slide, atau wipe — 4-8 frame
- Partikel: muncul, bergerak, memudar — pastikan tidak mengganggu konten
- Particle count: 3-10 partikel per interaksi (tidak berlebihan)
- Warna UI konsisten dengan palet game

## Shortcut & Fitur Aseprite
- **Tag** — tandai animasi UI (Hover, Press, Release, Transition)
- **Cel duration pendek** (20-50ms) untuk animasi cepat
- **Onion Skin** — pastikan posisi konsisten
- **Layer blending: Screen** — efek glow/partikel
- **Pivot** — rotasi elemen UI (gear, loading spinner)

## Contoh Kasus Nyata (Step-by-Step)

### Tombol Hover:
1. Buat 3 frame: Normal → Hover → Press
2. Normal: tombol flat dengan bayangan
3. Hover: tombol sedikit terang (+glow subtle, 1-2 piksel border)
4. Press: tombol turun 1 piksel, bayangan hilang
5. Durasi: normal (hold), hover (50ms), press (30ms)

### Transisi Menu:
1. Buat 8 frame transisi fade dari Menu A ke Menu B
2. Frame 1-4: Menu A opacity 100% → 0%
3. Frame 5-8: Menu B opacity 0% → 100%
4. Tambah partikel bintang/lingkaran kecil menyebar

### Particle:
1. Buat 6-8 partikel ukuran 2x2 piksel
2. Path: bergerak ke atas dengan kurva melambat
3. Opacity: 100% → 0% dalam 6 frame
4. Warna: sesuai tema (emas untuk premium, biru untuk default)
