# 176. Script Color Ramp Otomatis

## Definisi Singkat
Script color ramp otomatis adalah skrip Lua yang menghasilkan gradasi warna (ramp) dari 2+ warna input, membuat transisi halus untuk shading, highlight, dan shadow secara prosedural.

## Analogi
Seperti mencampur cat di palet — dari warna biru tua ke biru muda, Anda mendapatkan gradasi 5 tingkat tanpa harus mencampur manual setiap level.

## Poin-Poin Penting
- Input: color A (shadow) dan color B (highlight), jumlah step (misal 5)
- Proses: interpolasi RGB atau HSV antara A dan B
- Output: palette entry baru atau langsung apply ke selection
- Mode HSV menghasilkan gradasi lebih natural untuk pixel art
- Bisa generate ramp dari sprite yang sudah ada (ekstrak warna)

## Shortcut & Fitur Aseprite
- **Color Palette Panel (F9)**: Lihat hasil ramp langsung di palette
- **Console (F12)**: Testing fungsi color interpolation
- **Edit Color (Shift+C)**: Edit manual hasil ramp jika perlu
- **Palette > Sort > By Color**: Urutkan ramp setelah generasi

## Contoh Kasus Nyata (Step-by-Step)

1. **Buka Lua Console (F12)** — Testing fungsi interpolasi
2. **Generate ramp 5 warna** — Dari merah gelap ke merah terang
3. **Script basis**:
   ```lua
   local function lerp(a, b, t)
     return math.floor(a + (b - a) * t)
   end
   local function ramp(c1, c2, steps)
     local colors = {}
     for i = 0, steps - 1 do
       local t = i / (steps - 1)
       local r = lerp(c1.red, c2.red, t)
       local g = lerp(c1.green, c2.green, t)
       local b = lerp(c1.blue, c2.blue, t)
       table.insert(colors, Color(r, g, b))
     end
     return colors
   end
   ```
4. **Test dengan warna** — `ramp(Color(50,50,200), Color(200,200,255), 5)`
5. **Output ke palette** — Iterasi colors[] dan `app.activeSprite.palette:setColor(index, color)`
6. **Apply ke selection** — Loop pixel selection, set warna sesuai posisi Y
7. **Simpan sebagai script permanen** — Buat file `color_ramp.lua` di scripts folder
8. **Buat dialog** — Tambah input untuk warna awal, akhir, dan jumlah step
9. **Shortcut** — Assign shortcut untuk akses cepat
10. **Test dengan sprite** — Pilih area, jalankan script, lihat gradasi terbentuk
