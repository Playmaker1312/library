# 177. Script Palette Manipulation Sort Shift

## Definisi Singkat
Script palette manipulation adalah skrip Lua untuk mengatur ulang warna dalam palette — sorting berdasarkan hue/saturation/brightness, shifting warna, atau remapping warna terpilih ke posisi baru.

## Analogi
Seperti mengatur lemari arsip — Anda bisa mengurutkan file berdasarkan abjad (hue), warna sampul (brightness), atau memindahkan sekelompok file ke rak baru.

## Poin-Poin Penting
- Sort by hue: urutkan berdasarkan nilai hue (0-360)
- Sort by brightness: berdasarkan luminance (0-255)
- Sort by saturation: berdasarkan intensitas warna
- Shift palette: geser semua warna ke kiri/kanan secara sirkuler
- Remap: ganti posisi warna tertentu tanpa mengubah nilai RGB

## Shortcut & Fitur Aseprite
- **Palette Panel (F9)**: Interface utama untuk manipulasi palette
- **Palette > Sort**: Sorting built-in (hue, saturation, brightness, luminance)
- **Palette > Shift**: Shift warna ke kiri/kanan
- **Edit > Remap Color**: Ganti satu warna dengan warna lain
- **Script Console (F12)**: Testing manipulasi palette via API

## Contoh Kasus Nyata (Step-by-Step)

1. **Buka palette manager** — Palette Panel (F9), lihat daftar warna
2. **Sort by brightness** — Palette > Sort > By Brightness
3. **Script sort custom**:
   ```lua
   local pal = app.activeSprite.palette
   local colors = {}
   for i = 1, #pal do
     colors[i] = pal:getColor(i)
   end
   table.sort(colors, function(a, b)
     return a.red + a.green + a.blue < b.red + b.green + b.blue
   end)
   for i = 1, #colors do
     pal:setColor(i, colors[i])
   end
   ```
4. **Shift palette sirkuler** — Geser semua warna 5 posisi ke kanan
5. **Script shift**:
   ```lua
   local pal = app.activeSprite.palette
   local shift = 5
   local colors = {}
   for i = 1, #pal do
     colors[i] = pal:getColor(i)
   end
   for i = 1, #pal do
     local newIdx = ((i - 1 + shift) % #pal) + 1
     pal:setColor(i, colors[newIdx])
   end
   ```
6. **Test sorting hue** — Ganti fungsi sort dengan perbandingan hue
7. **Extract unique colors** — Script untuk deduplikasi warna palette
8. **Remap selective** — Ganti hanya range warna tertentu (misal semua hijau)
9. **Simpan script** — Buat file `palette_tools.lua` dengan multiple functions
10. **Assign shortcut** — Buat shortcut terpisah untuk sort dan shift
