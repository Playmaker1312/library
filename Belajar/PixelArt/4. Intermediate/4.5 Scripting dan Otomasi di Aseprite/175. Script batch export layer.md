# 175. Script Batch Export Layer

## Definisi Singkat
Script batch export layer adalah skrip Lua yang mengekspor setiap layer (atau layer tertentu) dari sprite Aseprite menjadi file gambar terpisah (PNG, GIF, dll) secara otomatis.

## Analogi
Seperti mencetak halaman buku — setiap halaman (layer) dicetak sebagai file PDF terpisah tanpa harus buka dan save satu per satu.

## Poin-Poin Penting
- Gunakan `sprite:saveCopyAs(filename)` untuk export tiap layer
- Export bisa per layer atau per group layer
- Nama file otomatis berdasarkan nama layer
- Bisa filter layer tertentu (exclude background, invisible layer)
- Format output: PNG, GIF, JPEG sesuai ekstensi filename

## Shortcut & Fitur Aseprite
- **File > Scripts > Open Scripts Folder**: Tempat menyimpan script
- **File > Export Sprite Sheet (Ctrl+E)**: Alternatif manual untuk export
- **Console (F12)**: Testing potongan script sebelum full run
- **Command Line (CLI)**: Alternatif untuk batch processing tanpa GUI

## Contoh Kasus Nyata (Step-by-Step)

1. **Buat script baru** — Buka Open Scripts Folder, buat `export_layers.lua`
2. **Tulis kode dasar**:
   ```lua
   local s = app.sprite
   local path = s.filename:match("(.*\\)") or ""
   for i, layer in ipairs(s.layers) do
     if layer.isVisible then
       local fname = path .. layer.name .. ".png"
       s:saveCopyAs(fname)
       app.alert("Exported: " .. layer.name)
     end
   end
   ```
3. **Siapkan sprite multi-layer** — Buka file .aseprite dengan 5+ layer
4. **Jalankan script** — File > Scripts > pilih export_layers.lua
5. **Cek hasil** — Folder yang sama berisi file PNG per layer
6. **Modifikasi format GIF** — Ganti ".png" dengan ".gif" di script
7. **Filter layer tertentu** — Tambah `if layer.name:find("export")` untuk filter nama
8. **Assign shortcut** — Edit > Keyboard Shortcuts, assign F5 ke script
9. **Test dengan sprite baru** — Tekan F5, verifikasi export berjalan
10. **Simpan script untuk project** — Copy ke folder project untuk reuse
