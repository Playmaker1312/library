# 174. Aseprite Script API Lua

## Definisi Singkat
Aseprite Script API Lua adalah antarmuka pemrograman berbasis Lua yang memungkinkan pengguna membuat skrip untuk otomatisasi tugas, manipulasi sprite, palette, layer, dan animasi di Aseprite.

## Analogi
Seperti makro di Excel — serangkaian perintah otomatis yang bisa merekam dan menjalankan tugas berulang tanpa campur tangan manual.

## Poin-Poin Penting
- Script Aseprite ditulis dalam Lua 5.3
- API utama: `app`, `sprite`, `layer`, `cel`, `image`, `color`, `pixel`
- Jalankan script via File > Scripts > Rescan & pilih script
- Shortcut bisa di-assign ke script kustom
- Script bisa mengakses: active sprite, selection, palette, tool, preferences
- Dokumentasi API built-in: `app.help()` di console

## Shortcut & Fitur Aseprite
- **Console (F12)**: Buka Lua Console untuk testing perintah langsung
- **File > Scripts > Open Scripts Folder**: Buka folder tempat script disimpan
- **File > Scripts > Rescan**: Refresh daftar script setelah menambah baru
- **Edit > Keyboard Shortcuts**: Assign shortcut ke script kustom
- **Record Script**: Jalankan Console > record actions untuk generate script otomatis

## Contoh Kasus Nyata (Step-by-Step)

1. **Buka Lua Console (F12)** — Tampilan Console di bagian bawah Aseprite
2. **Tulis hello world** — `app.alert("Hello Pixel Art!")` lalu Enter
3. **Akses sprite aktif** — `local s = app.sprite` untuk referensi sprite
4. **Loop layer** — `for i,l in ipairs(s.layers) do app.alert(l.name) end`
5. **Buat layer baru** — `s:newLayer("Baru")` di Console
6. **Simpan script** — File > Scripts > Open Scripts Folder, buat file .lua
7. **Script sederhana**:
   ```lua
   local s = app.sprite
   local layer = s:newLayer("Auto Layer")
   local cel = s:newCel(layer, 1)
   ```
8. **Assign shortcut** — Edit > Keyboard Shortcuts, cari nama script
9. **Test jalankan** — Tekan shortcut, lihat layer baru muncul
10. **Iterate** — Edit script, Rescan, test lagi
