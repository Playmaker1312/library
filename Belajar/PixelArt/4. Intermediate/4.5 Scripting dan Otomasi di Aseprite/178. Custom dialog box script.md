# 178. Custom Dialog Box Script

## Definisi Singkat
Custom dialog box adalah skrip Lua yang membuat jendela dialog interaktif di Aseprite, memungkinkan input parameter (angka, teks, warna, dropdown) dari pengguna sebelum menjalankan proses otomatis.

## Analogi
Seperti mesin ATM — Anda memilih jenis transaksi, memasukkan nominal, dan mesin memproses sesuai input. Dialog box adalah antarmuka antara pengguna dan skrip.

## Poin-Poin Penting
- API dialog: `app.Dialog { title = "..." }`
- Widget: `entry` (teks), `slider` (angka), `color` (pemilih warna), `combobox` (menu)
- Bisa tambah `checkbox`, `button`, `separator`, `label`
- Dialog bersifat blocking — script menunggu sampai dialog ditutup
- Data dikembalikan sebagai table dengan key sesuai nama widget

## Shortcut & Fitur Aseprite
- **Console (F12)**: Testing dialog widget satu per satu
- **Script Editor**: Bisa edit script dan test dialog tanpa restart Aseprite
- **File > Scripts > Rescan**: Refresh script setelah edit
- **API Reference**: `app.help("Dialog")` di Console untuk dokumentasi

## Contoh Kasus Nyata (Step-by-Step)

1. **Buka scripts folder** — File > Scripts > Open Scripts Folder
2. **Buat file `resize_dialog.lua`** — Script dengan dialog box
3. **Tulis dialog dasar**:
   ```lua
   local dlg = app.Dialog("Resize Options")
   dlg:entry{ id = "scale", label = "Scale %:", text = "100" }
   dlg:slider{ id = "quality", label = "Quality:", min = 1, max = 10, value = 5 }
   dlg:button{ id = "ok", text = "OK" }
   dlg:button{ id = "cancel", text = "Cancel" }
   dlg:show()
   ```
4. **Tangani input** — Setelah `dlg:show()`, data ada di `dlg.data`
5. **Cek tombol** — Jika `dlg.data.ok` maka proses, jika `cancel` maka return
6. **Tambahkan color picker** — `dlg:color{ id = "fillColor", label = "Fill:", color = Color(255,0,0) }`
7. **Tambahkan combobox** — `dlg:combobox{ id = "mode", label = "Mode:", options = {"Normal", "Multiply", "Screen"} }`
8. **Gunakan input untuk resize** — Ambil `dlg.data.scale`, konversi ke angka, resize sprite
9. **Test jalankan** — File > Scripts > resize_dialog.lua, lihat dialog muncul
10. **Simpan sebagai template** — Copy struktur dialog untuk script lain
