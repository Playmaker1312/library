# 180. Shortcut Kustom Aseprite

## Definisi Singkat
Shortcut kustom Aseprite adalah pengaturan pintasan keyboard yang dapat disesuaikan untuk mengakses tool, menu, script, dan perintah tertentu dengan cepat, meningkatkan kecepatan workflow secara signifikan.

## Analogi
Seperti tombol cepat di keyboard gaming — Anda bisa memprogram satu tombol untuk kombo skill tertentu, bukan menekan 4 tombol berurutan.

## Poin-Poin Penting
- Buka pengaturan via Edit > Keyboard Shortcuts (Ctrl+Alt+Shift+K)
- Shortcut bisa di-assign ke: tool, menu item, perintah built-in, script kustom
- Cari perintah dengan kotak search di dialog Keyboard Shortcuts
- Shortcut bisa memiliki modifier: Ctrl, Shift, Alt, Win/Cmd
- Simpan konfigurasi ke file .cfg atau .json untuk backup/sharing

## Shortcut & Fitur Aseprite
- **Edit > Keyboard Shortcuts (Ctrl+Alt+Shift+K)**: Buka dialog shortcut
- **Search box**: Ketik tool/perintah yang ingin di-assign
- **Tombol Reset**: Kembalikan ke default jika kacau
- **Export/Import Shortcut**: Backup via user preferences folder
- **Konflik Detector**: Lingkaran merah menandakan shortcut bentrok

## Contoh Kasus Nyata (Step-by-Step)

1. **Buka Keyboard Shortcuts** — Edit > Keyboard Shortcuts (Ctrl+Alt+Shift+K)
2. **Search "Pencil"** — Cari tool Pencil, saat ini shortcut "B"
3. **Assign shortcut baru** — Klik "B", tekan "P" untuk ganti
4. **Search "Fill"** — Cari Fill tool, assign ke "G"
5. **Cari "Shading"** — Assign Shift+D jika belum ada
6. **Assign script custom** — Cari nama script, pilih, tekan shortcut (misal F9)
7. **Cari "Flip Horizontal"** — Assign Ctrl+H untuk mirror cepat
8. **Cari "Merge Down"** — Assign Ctrl+M untuk merge layer aktif dengan bawah
9. **Cek konflik** — Pastikan tidak ada lingkaran merah di list
10. **Simpan/backup** — Copy file `user.aseprite-keys` dari folder preferences
