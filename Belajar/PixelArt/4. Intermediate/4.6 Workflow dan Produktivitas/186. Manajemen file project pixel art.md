# 186. Manajemen File Project Pixel Art

## Definisi Singkat
Manajemen file project pixel art adalah sistem pengorganisasian aset, layer, palette, dan versi file dalam proyek pixel art untuk menjaga konsistensi, memudahkan kolaborasi, dan mencegah kehilangan data.

## Analogi
Seperti perpustakaan — setiap buku (file) punya rak (folder) sesuai kategori, label (nama file) jelas, dan sistem peminjaman (version control) untuk melacak siapa yang meminjam.

## Poin-Poin Penting
- Struktur folder standar: `project/assets/`, `project/exports/`, `project/source/`
- Naming convention: `char_walk_SE_01.aseprite` (object_action_angle_frame)
- Layer naming: `char_body`, `char_head`, `char_shadow`
- Palette global: simpan palette project (.aseprite atau .png) di folder root
- Version control: gunakan Git atau backup berkala dengan tanggal

## Shortcut & Fitur Aseprite
- **File > Save As (Ctrl+Shift+S)**: Simpan versi baru dengan nama berbeda
- **File > Export (Ctrl+E)**: Export aset ke folder exports/
- **Layer Group**: Group layer berdasarkan kategori (body, efek, bg)
- **Palette Panel (F9)**: Simpan palette project
- **Color Palette > Save Palette**: Export palette untuk reuse

## Contoh Kasus Nyata (Step-by-Step)

1. **Buat folder project** — `RPG_Game/` di direktori kerja
2. **Buat subfolder** — `source/`, `exports/`, `palettes/`, `backups/`
3. **Naming file karakter** — `hero_idle_SE.aseprite`, `hero_walk_SE.aseprite`
4. **Layer naming** — Rename layer: "body", "head", "weapon", "shadow"
5. **Group layer** — Group "hero_SE" berisi semua layer hero
6. **Simpan palette project** — Color Palette > Save Palette > `palettes/rpg_pal.aseprite`
7. **Export teratur** — Export PNG ke folder `exports/` setiap kali selesai
8. **Backup harian** — Copy folder project ke `backups/` dengan tanggal
9. **Gunakan Git** — `git init`, commit setiap milestone
10. **Dokumentasi** — Buat file `README.txt` berisi daftar aset dan palette
