# 166. Desain Sprite Game Mobile

## Definisi Singkat
Panduan mendesain sprite pixel art khusus untuk game mobile — mempertimbangkan layar sentuh, resolusi beragam, performa baterai, dan ukuran file yang terbatas.

## Analogi
Ikon aplikasi di HP: harus langsung dikenali meski kecil, tanpa teks, dengan warna kontras. Sprite game mobile juga harus "pop" di layar kecil dengan banyak gangguan cahaya.

## Poin-Poin Penting
- **Layar kecil & bervariasi**: desain untuk 720p ke atas, integer scaling
- **Kontras tinggi** — layar mobile sering terpakai di luar ruangan (sinar matahari)
- **Karakter besar**: minimal 32x32 agar terbaca di layar 5-7 inci
- **Animasi minimal**: 4-6 frame per gerakan untuk hemat CPU/baterai
- **Palet terbatas**: 16-32 warna per sprite — kurangi ukuran file
- **UI touch-friendly**: tombol minimal 44x44 piksel (after scaling)
- **Anti-aliasing** pada edge penting di layar OLED (kurangi color fringing)
- **Texture atlas**: gabung banyak sprite → kurangi draw calls

## Shortcut & Fitur Aseprite
- **Sprite Sheet export** (Ctrl+E) — export atlas
- **Palette > Reduce Palette** — optimasi warna untuk mobile
- **File > Export > PNG** — ukuran file kecil
- **Indexed color mode** — kurangi size PNG
- **Slice tool** — bagi sprite sheet menjadi frame individual

## Contoh Kasus Nyata (Step-by-Step)

1. Tentukan resolusi game: 480x270 (scale 2x untuk 960x540 di layar)
2. Karakter utama: 32x32, palet 16 warna
3. UI layout: joystick kiri (64x64), tombol aksi kanan (48x48)
4. Desain karakter dengan outline tebal 1px untuk keterbacaan
5. Buat texture atlas 512x512 berisi semua sprite (4 sheet terpisah)
6. Export dengan indexed color (PNG-8) — file size turun 60%
7. Tes di 3 ukuran layar: iPhone SE (750p), Android 1080p, Tablet 1440p
8. Optimasi animasi: idle hanya 4 frame, walk 6 frame — tidak perlu 8+ frame
