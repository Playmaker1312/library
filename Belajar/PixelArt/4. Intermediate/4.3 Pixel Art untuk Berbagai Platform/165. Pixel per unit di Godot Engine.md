# 165. Pixel per Unit di Godot Engine

## Definisi Singkat
Konsep **pixel per unit (PPU)** di Godot Engine — menentukan berapa banyak piksel sprite yang setara dengan 1 unit meter dalam physics engine, agar sprite berukuran konsisten di dunia game.

## Analogi
Peta: skala 1:1000 berarti 1 cm di peta = 10 meter di dunia nyata. PPU adalah skala yang sama antara piksel sprite dan unit physics Godot.

## Poin-Poin Penting
- PPU standar Godot: 1 unit = 1 piksel (jika tidak diatur)
- Untuk pixel art: set PPU agar 1 tile (16x16 atau 32x32) = 1 unit
- **Project Settings > Display > Window**: set Width/Height (320x180)
- **Project Settings > Rendering > Sprite > DefaultTextureFilter**: set ke **Nearest**
- **Project Settings > Rendering > Texture > CanvasTextures > DefaultTextureFilter**: Nearest
- **Node2D > Scale**: biarkan 1, atur texture import scale
- **Import > Sprite > Scale**: set sesuai PPU

## Shortcut & Fitur Godot
- **Project Settings** — konfigurasi global
- **Import Dock** — atur tiap aset
- **Viewport** — set game view ke 1:1
- **CanvasItem > modulate** — efek UI
- **TileMap > Cell Size** — set 16x16 atau 32x32
- **Camera2D > Zoom** — set integer multiplier (2, 3, dst)

## Contoh Kasus Nyata (Step-by-Step)

1. Buat proyek Godot baru dengan pixel art
2. Project Settings > Display > Window:
   - Width: 320, Height: 180
   - Stretch Mode: viewport, Aspect: keep
3. Import sprite karakter 16x16:
   - Texture Filter: Nearest
   - Repeat: Disabled
4. Hitung PPU: 1 tile = 16px → 16 PPU
5. TileMap: Cell Size (16, 16)
6. CharacterBody2D: ukuran collision shape = 8x16 (setengah tile)
7. Camera2D > Zoom: Vector2(4, 4) untuk scale 4x
8. Tes: pastikan sprite tajam dan collision akurat
