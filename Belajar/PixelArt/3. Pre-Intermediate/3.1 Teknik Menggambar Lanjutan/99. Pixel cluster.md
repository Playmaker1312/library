# 99. Pixel Cluster

## Definisi Singkat
Pixel cluster adalah kumpulan pixel yang saling terhubung membentuk satu massa visual, lawan dari pixel terisolasi. Teknik menggambar dengan cluster membuat bentuk lebih solid dan mudah dibaca.

## Analogi
Seperti menggambar dengan spidol tebal vs pulpen tipis — cluster ibarat goresan kuas lebar yang menghasilkan bentuk utuh, bukan titik-titik terpisah.

## Poin-Poin Penting
- Cluster minimal 2×2 pixel untuk menghindari "jagged noise"
- Setiap cluster harus punya koneksi tepi (edge-connected), bukan hanya pojok (corner-connected)
- Semakin besar cluster, semakin solid bentuknya; cluster kecil untuk detail halus
- Hindari "dithering berlebihan" yang memecah cluster menjadi titik-titik terisolasi

## Shortcut & Fitur Aseprite
- **Pencil Tool**: menggambar pixel cluster manual, **Shortcut:** B
- **Selection + Fill**: membuat cluster kotak besar cepat
- **Pixel Grid**: aktifkan View → Grid untuk melihat batas tiap pixel, **Shortcut:** Ctrl+Shift+G

## Contoh Kasus Nyata (Step-by-Step)
1. Buat canvas 32×32 dengan latar belakang gelap
2. Gambar lingkaran kecil diameter 6 pixel menggunakan pencil — jangan pakai fill
3. Perhatikan pixel-pixel terisolasi di tepi; hapus dan ganti dengan pixel yang bersambung
4. Sekarang gambar ulang lingkaran yang sama dengan cluster 2×2 di setiap lengkungan
5. Bandingkan hasilnya: cluster membuat tepi lebih halus dan bentuk lebih jelas
