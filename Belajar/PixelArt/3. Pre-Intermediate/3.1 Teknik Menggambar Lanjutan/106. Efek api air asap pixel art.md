# 106. Efek Api Air Asap Pixel Art

## Definisi Singkat
Teknik menggambar elemen alam (api, air, asap) dalam pixel art menggunakan bentuk organik, transisi warna tematik, dan pola gerakan yang khas untuk tiap elemen.

## Analogi
Seperti melukis elemen alam dengan cat air: api bergerak ke atas dengan lidah-lidah tajam, air mengalir dengan gelombang halus, asap meliuk tanpa bentuk tetap.

## Poin-Poin Penting
- **Api**: gradasi merah→kuning→putih, bentuk lidah meruncing ke atas, gerakan flicker
- **Air**: gradasi biru→biru muda→putih, bentuk gelombang melengkung, transparansi parsial
- **Asap**: gradasi abu-abu→transparan, bentuk gumpalan melingkar, tepi blur/anti-aliased
- Hindari outline hitam untuk elemen ini — gunakan warna lebih gelap dari warna elemen itu sendiri
- Gerakan animasi: api bergoyang cepat, air mengalir lambat, asap melayang sangat lambat

## Shortcut & Fitur Aseprite
- **Blur Tool**: untuk efek asap dan api yang halus, **Shortcut:** R
- **Opacity**: atur transparansi layer untuk air dan asap, **Shortcut:** Shift+Q
- **Onion Skin**: untuk animasi elemen, **Shortcut:** tombol onion skin di timeline
- **Celestial / Gradient maps**: buat palet gradasi otomatis untuk api

## Contoh Kasus Nyata (Step-by-Step)
1. Buat canvas 32×32 dengan 4 frame untuk animasi
2. **Api**: Frame 1: lidah api kecil (merah→kuning→putih). Frame 2: membesar ke atas. Frame 3: bergoyang kiri. Frame 4: kembali ke tengah
3. **Air**: Gambar gelombang biru melengkung dengan cluster 2×2, tambah highlight putih di puncak gelombang
4. **Asap**: Mulai dari gumpalan abu-abu kecil, gambar lingkaran cluster 3×3, tambah anti-aliasing di tepi
5. Animasi asap: setiap frame gumpalan membesar dan memudar opasitasnya
6. Jangan gunakan outline hitam untuk ketiganya — gunakan warna gelap dari keluarga warna masing-masing
