# 118. Basic Tileset Rumput Tanah Dinding Lantai

## Definisi Singkat
Basic tileset adalah kumpulan tile 16×16 yang membentuk material dasar game: rumput untuk outdoor, tanah untuk variasi, dinding untuk interior, dan lantai untuk alas dalam ruangan.

## Analogi
Seperti koleksi sampel material di katalog arsitek: ada contoh rumput, tanah, bata, dan kayu — masing-masing siap dipasang untuk membangun lingkungan.

## Poin-Poin Penting
- Tiap tile harus seamless (tileable) sendiri dan dengan tile lain dalam satu set
- Palet warna konsisten antar tile untuk menghindari perbedaan mencolok
- Rumput: base hijau, variasi dedaunan kecil, transisi ke tanah di tepi
- Tanah: base cokelat, variasi grain acak, bisa untuk bawah rumput (subsoil)
- Dinding: pola bata/batu berulang, shadow di bawah setiap bata
- Lantai kayu: garis papan horizontal, variasi warna antar papan

## Shortcut & Fitur Aseprite
- **Tile Preview**: lihat semua tile dalam grid, **Shortcut:** Ctrl+Shift+P
- **Save as Tilesheet**: File → Export → pilih format tilesheet
- **Indexed Mode**: konversi ke indexed color untuk memastikan palet terbatas, **Shortcut:** Ctrl+Shift+D
- **Grid View**: untuk melihat tile boundaries, **Shortcut:** Ctrl+Shift+G

## Contoh Kasus Nyata (Step-by-Step)
1. Buat canvas 64×64 yang berisi 4 tile (masing-masing 16×16)
2. **Tile Rumput**: base #4A7C3F, tambah pixel #5B8F4F acak untuk variasi
3. **Tile Tanah**: base #8B5E3C, tambah pixel #6B4226 dan #A0704F random
4. **Tile Dinding Bata**: base #8B4513, gambar garis horisontal #6B3410 setiap 4px, offset 2px di baris genap
5. **Tile Lantai Kayu**: base #C4A97D, garis horizontal tipis #B8986E, variasi warna 1px
6. Uji Tile Preview (3×3) untuk setiap tile — pastikan seamless
7. Atur dalam tilesheet grid 2×2 untuk siap pakai di game
