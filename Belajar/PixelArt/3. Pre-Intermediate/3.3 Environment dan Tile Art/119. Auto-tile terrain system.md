# 119. Auto-Tile Terrain System

## Definisi Singkat
Auto-tile adalah sistem di mana tile berubah secara otomatis berdasarkan tile tetangganya, menciptakan transisi alami antar material (misal rumput ke tanah) tanpa editing manual.

## Analogi
Seperti puzzle konektor: setiap sisi tile punya "konektor" yang cocok dengan tile lain — tile rumput di sisi kiri otomatis menyambung ke tile tanah di sisi kanan.

## Poin-Poin Penting
- Sistem 4-bit: tiap tile punya 16 varian berdasarkan koneksi di 4 arah (atas, kanan, bawah, kiri)
- Sistem 8-bit (lebih detail): 47 varian karena termasuk koneksi diagonal
- Tile transisi: tile yang punya 2+ material (misal setengah rumput setengah tanah)
- Auto-tile menghemat waktu besar saat membuat map besar
- Format umum: tilesheet dengan layout grid khusus sesuai rules

## Shortcut & Fitur Aseprite
- **Tileset Mode**: atur tile size untuk auto-tile, **Shortcut:** Sprite → Sprite Properties → Tile Width/Height
- **Grid Snapping**: aktifkan untuk posisi tile presisi, **Shortcut:** Ctrl+Shift+G
- **Export Tileset**: File → Export sebagai tilesheet dengan tata letak grid

## Contoh Kasus Nyata (Step-by-Step)
1. Buat tilesheet 48×48 yang berisi 9 tile 16×16 untuk auto-tile rumput→tanah
2. **Tile 1 (Full Rumput)**: semua sisi rumput
3. **Tile 2 (Full Tanah)**: semua sisi tanah
4. **Tile 3-8 (Transisi)**: kombinasi tepi rumput dan tanah (rumput di atas, tanah di bawah, dll)
5. **Tile 9 (Pojok)**: rumput di pojok kiri atas, tanah di sisa area
6. Di game engine (Tiled, Godot, dll), set aturan auto-tile berdasarkan kode bit
7. Test: buat area 10×10 tile — gambar beberapa tile rumput, lalu tanah di sekitarnya
8. Engine otomatis memilih tile varian yang tepat untuk transisi mulus
