# 121. Tile Isometric Lantai Dinding Objek

## Definisi Singkat
Tile isometrik adalah tile berbentuk diamond (lantai) atau paralelogram (dinding) yang disusun dalam grid 2:1 untuk membangun ruang isometrik. Satu set tileset isometrik mencakup lantai, dinding, dan objek.

## Analogi
Seperti rumah-rumahan dari balok mainan: ada balok alas (lantai), balok tegak (dinding), dan balok kecil (objek) — semua punya bentuk miring yang konsisten.

## Poin-Poin Penting
- Tile lantai isometrik: diamond 2:1, misal 32×16 atau 64×32 pixel
- Tile dinding: berdiri di atas tile lantai, tinggi 16-32 pixel dengan slope 2:1 di tepi
- Objek (meja, pohon, karakter): harus sejajar dengan grid isometrik
- Urutan render (Z-order): objek di belakang (Y lebih kecil) digambar dulu
- Palet warna: atap terang, dinding kiri mid, dinding kanan gelap

## Shortcut & Fitur Aseprite
- **Grid Settings**: atur lebar 2, tinggi 1 untuk panduan isometrik, **Shortcut:** View → Grid Settings
- **Snap to Grid**: untuk presisi penempatan tile, **Shortcut:** Ctrl+Shift+G
- **Pen Tool**: gambar garis 2:1 dengan snapping
- **Selection + Move Tool**: geser tile untuk menyusun map, **Shortcut:** V

## Contoh Kasus Nyata (Step-by-Step)
1. Buat tile lantai isometrik 32×16: gambar diamond berwarna abu-abu terang
2. Buat tile dinding 32×32: base 32×16 (seperti lantai) + tinggi 16px vertikal
3. Sisi kiri dinding: warna midtone (#888), sisi kanan: gelap (#666)
4. Susun 4 tile lantai (2×2) dalam canvas 64×64
5. Tempatkan 1 tile dinding di tile lantai belakang (Z-order bawah)
6. Gambar objek sederhana (kotak kayu 16×16) di atas tile lantai depan
7. Perhatikan urutan render: dinding → objek → tile lantai depan
8. Hasil: ruangan isometrik sederhana dengan kedalaman 3D
