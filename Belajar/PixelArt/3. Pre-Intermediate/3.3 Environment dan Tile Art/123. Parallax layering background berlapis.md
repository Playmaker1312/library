# 123. Parallax Layering Background Berlapis

## Definisi Singkat
Parallax layering adalah teknik memisahkan background menjadi beberapa lapis yang bergerak dengan kecepatan berbeda saat kamera bergeser, menciptakan ilusi kedalaman 3D.

## Analogi
Saat naik kereta, lihat ke luar jendela: pohon pinggir jalan (layer dekat) bergerak cepat, gunung di kejauhan (layer jauh) bergerak lambat, awan di cakrawala hampir tidak bergerak.

## Poin-Poin Penting
- Layer 1 (foreground): bergerak paling cepat — sejajar dengan game layer
- Layer 2 (midground): bergerak lebih lambat — 50% kecepatan kamera
- Layer 3 (background): bergerak sangat lambat — 10-25% kecepatan kamera
- Layer 4 (sky): hampir diam — 0-5% kecepatan kamera
- Semakin jauh layer, semakin buram/warnanya cenderung kebiruan (atmospheric perspective)
- Gunakan resolusi lebih lebar dari viewport untuk menghindari celah di tepi

## Shortcut & Fitur Aseprite
- **Layer Opacity**: untuk background blur efek, **Shortcut:** Shift+Q
- **UI → Color Mode**: gunakan indexed color untuk palet terbatas per layer
- **Export Layer**: File → Export → pilih "Selected Layer" untuk ekspor terpisah
- **Sprite Size**: buat sprite lebar (256×144 atau lebih) untuk parallax scroll

## Contoh Kasus Nyata (Step-by-Step)
1. Buat 4 layer dalam satu sprite (ukuran 256×144)
2. **Sky (Layer 4)**: gradasi biru + awan statis
3. **Gunung (Layer 3)**: siluet gunung biru-abu, gambarnya lebih simpel
4. **Hutan (Layer 2)**: pohon-pohon hijau sedang, lebih detail
5. **Rumput/Depan (Layer 1)**: rumput dan semak detail, warna lebih jenuh
6. Di game engine (Godot, Unity, dll): atur scroll speed:
   - Layer 1: 1.0x (ikuti kamera)
   - Layer 2: 0.5x
   - Layer 3: 0.2x
   - Layer 4: 0.05x
7. Saat kamera geser ke kanan, lapisan depan bergerak lebih cepat dari gunung
8. Ilusi kedalaman tercipta — dunia terasa luas
