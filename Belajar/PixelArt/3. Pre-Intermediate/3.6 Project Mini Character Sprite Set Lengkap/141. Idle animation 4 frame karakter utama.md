# 141. Idle animation 4 frame karakter utama

## Definisi Singkat
Idle animation adalah animasi saat karakter diam berdiri, biasanya 2-4 frame dengan gerakan halus seperti napas, rambut tertiup, atau kedipan mata agar karakter terasa hidup.

## Analogi
Seperti orang berdiri santai menunggu bus — badan tidak kaku total, ada gerakan kecil: napas naik-turun, pandangan berkedip, berat badan bergeser.

## Poin-Poin Penting
- 2 frame minimal untuk efek "hidup" (naik-turun badan 1px).
- 4 frame ideal: 2 frame napas + 2 frame blink atau aksen kecil.
- Gerakan subtil — perubahan 1-2 pixel sudah cukup.
- Pastikan loop mulus: frame terakhir transisi halus ke frame pertama.
- Jangan ubah posisi kaki (anchor point) agar tidak terlihat melayang.

## Shortcut & Fitur Aseprite
- **Timeline Panel**: kelola 4 frame idle, **Shortcut:** Alt+T
- **New Frame**: tambah frame baru, **Shortcut:** Shift+N
- **Onion Skin**: lihat frame sebelumnya untuk konsistensi, **Shortcut:** Alt+Shift+O
- **Loop Preview**: play animasi loop terus, **Shortcut:** Enter (di Timeline)
- **Cel Properties**: atur durasi frame (misal 200ms per frame)

## Contoh Kasus Nyata (Step-by-Step)
1. Buka file karakter KsatriaApi (dari file 140), duplikat sebagai "Idle".
2. Frame 1: posisi normal, badan tegak.
3. Frame 2: badan naik 1px (dadanya), bayangan kaki sedikit menyentuh tanah.
4. Frame 3: kembali ke posisi normal (sama seperti frame 1 atau variasi ringan).
5. Frame 4: karakter turun 1px, mata kedip (tutup mata 1 frame).
6. Atur durasi: Frame 1=300ms, Frame 2=150ms, Frame 3=300ms, Frame 4=150ms.
7. Preview (Enter) — pastikan loop halus.
8. Simpan sebagai "KsatriaApi_Idle.aseprite".
