# 143. Run cycle attack death animation

## Definisi Singkat
Run cycle, attack, dan death adalah animasi aksi karakter selain idle/walk. Run lebih cepat dan eksplosif, attack adalah momen serangan (1-2 frame impact), death adalah momen karakter tumbang.

## Analogi
Adegan film: lari (scene kejar-kejaran, langkah lebar dan cepat), serang (pukulan kena di frame impact, ada freeze moment), mati (jatuh perlahan atau collapse dramatis).

## Poin-Poin Penting
- **Run cycle**: 6-8 frame, badan lebih condong ke depan, step lebih lebar, durasi lebih cepat (100-120ms per frame).
- **Attack**: 3-5 frame — anticipation (1-2 frame), hit/impact (1 frame), recovery (1-2 frame).
- **Death**: 4-6 frame — reaksi kena damage (1 frame), jatuh/rebah (2-3 frame), diam (1-2 frame).
- Impact frame attack harus terlihat jelas — freeze 1 frame lebih lama.
- Death animation biasanya tidak looping.

## Shortcut & Fitur Aseprite
- **Tag**: buat tag terpisah per animasi, **Shortcut:** F7
- **New Frame**: tambah frame untuk tiap fase, **Shortcut:** Shift+N
- **Onion Skin**: referensi posisi dari frame sebelumnya, **Shortcut:** Alt+Shift+O
- **Cel Properties**: atur durasi frame (run: 120ms, attack impact: 200ms), **Shortcut:** Klik kanan cel
- **Move Tool**: geser tubuh saat lari, **Shortcut:** V

## Contoh Kasus Nyata (Step-by-Step)
1. **Run**: buat 8 frame baru setelah idle. Badan condong 15°, langkah lebar, tangan mengepal.
   - Atur durasi 100ms per frame. Tag: "Run".
2. **Attack**: 4 frame:
   - Frame 1: anticipation — tangan tarik ke belakang, badan sedikit putar.
   - Frame 2: swing — pedang ke depan.
   - Frame 3: impact — kontak, ada efek kilat 1 pixel putih.
   - Frame 4: recovery — kembali ke posisi idle.
   - Tag: "Attack", loop: false.
3. **Death**: 5 frame:
   - Frame 1: terkena damage — badan goyang ke belakang.
   - Frame 2-3: jatuh ke belakang atau lutut.
   - Frame 4: rebah di tanah.
   - Frame 5: diam (hold frame terakhir).
   - Tag: "Death", loop: false.
4. Simpan sebagai "KsatriaApi_Action.aseprite".
