# 133. Palette swapping variasi karakter

## Definisi Singkat
Palette swapping adalah teknik mengganti warna-warna tertentu dalam sprite secara cepat untuk membuat variasi karakter (misal: reskin warna) tanpa perlu menggambar ulang. Cukup mapping warna lama ke warna baru di palette index.

## Analogi
Seperti mewarnai buku gambar dengan nomor — kamu tinggal ganti krayon nomor 3 (merah) dengan biru, dan semua area bernomor 3 otomatis berubah warna. Tidak perlu menggambar ulang garisnya.

## Poin-Poin Penting
- Gunakan Indexed Color Mode agar setiap pixel merujuk ke slot palette index.
- Pastikan sprite terpisah per bagian (misal: rambut, baju, celana) di slot warna berbeda.
- Hindari 2 bagian berbeda berbagi index warna yang sama jika ingin di-swap terpisah.
- Palette swapping bisa dilakukan di Aseprite atau engine game saat runtime.

## Shortcut & Fitur Aseprite
- **Indexed Color Mode**: ubah dari RGB ke Indexed, **Shortcut:** Image > Color Mode > Indexed
- **Replace Color**: ganti satu warna spesifik cepat, **Shortcut:** Shift+R
- **Palette Editor**: edit slot warna, **Shortcut:** F4
- **New Palette**: simpan palette sebagai variasi, **Shortcut:** Palette > New Palette

## Contoh Kasus Nyata (Step-by-Step)
1. Buka sprite karakter yang sudah selesai (contoh: 64x64 px).
2. Ubah mode warna ke Indexed: Image > Color Mode > Indexed.
3. Identifikasi index warna baju (misal index #5 = merah).
4. Di Palette Editor, ubah index #5 jadi biru — seluruh baju berubah.
5. Simpan palette ini sebagai "Karakter_Biru.aseprite".
6. Kembalikan #5 ke merah, ubah index rambut (#9) jadi putih untuk variasi kedua.
7. Simpan sebagai palette terpisah. Loading palette berbeda di engine = karakter berbeda.
