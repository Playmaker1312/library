# 135. Indexed Color Mode mengurangi warna

## Definisi Singkat
Indexed Color Mode adalah mode warna di mana setiap pixel menyimpan index (nomor) yang merujuk ke palette warna terbatas, bukan nilai RGB langsung. Ini memaksa pengurangan warna otomatis dan menghemat memori.

## Analogi
Buku mewarnai dengan nomor: setiap area punya nomor (index), dan nomor itu merujuk ke warna tertentu di kotak krayon (palette). Tidak bisa pakai warna di luar kotak.

## Poin-Poin Penting
- Mode indexed membatasi jumlah warna per file (biasanya 16, 32, atau 256).
- Konversi RGB ke indexed akan mengurangi warna dengan algoritma dithering (opsional).
- Setiap perubahan palette langsung memengaruhi seluruh sprite — sangat efisien.
- Tidak bisa pakai efek gradient atau transparansi parsial (hanya on/off).
- Ideal untuk export ke engine retro atau platform dengan batasan VRAM.

## Shortcut & Fitur Aseprite
- **Set Color Mode**: Image > Color Mode > Indexed
- **Palette Editor**: kelola slot warna terbatas, **Shortcut:** F4
- **Dithering Options**: saat konversi, pilih dithering pattern, **Shortcut:** di dialog konversi
- **RGB to Indexed Preview**: lihat hasil sebelum apply, **Shortcut:** Image > Color Mode > Preview

## Contoh Kasus Nyata (Step-by-Step)
1. Buka sprite karakter 32x32 px yang sudah diwarnai (mungkin 50+ warna).
2. Buka Image > Color Mode > Indexed.
3. Set jumlah warna: 16 (untuk gaya retro).
4. Pilih dithering: None (tanpa dither) atau Pattern (jika ingin tekstur).
5. Klik OK — warna otomatis berkurang ke 16 slot.
6. Periksa area yang berubah: mungkin ada banding atau hilangnya detail.
7. Manual touch-up: haluskan transisi dengan pencil tool.
8. Palette sekarang siap untuk palette swapping atau export.
