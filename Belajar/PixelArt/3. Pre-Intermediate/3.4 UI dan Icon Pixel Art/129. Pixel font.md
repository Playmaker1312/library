# 129. Pixel font

## Definisi Singkat
Pixel font adalah tipografi yang dirancang dalam grid pixel, biasanya setinggi 5-8 pixel, di mana setiap huruf dibangun dari blok-blok pixel tanpa anti-aliasing.

## Analogi
Seperti papan skor di stadion olahraga — huruf tersusun dari lampu-lampu kecil yang menyala/mati, sangat terbatas tetapi harus terbaca dari jauh.

## Poin-Poin Penting
- Tinggi font standar: 5px (lowercase), 7px (dengan ascender/descender).
- Lebar huruf bervariasi: 3-5px per karakter.
- Hindari anti-aliasing — gunakan aliased 100%.
- Spasi antar karakter minimal 1px.
- Set karakter minimum: A-Z, a-z, 0-9, dan tanda baca umum.

## Shortcut & Fitur Aseprite
- **Text Tool**: untuk preview teks dengan font bawaan, **Shortcut:** T
- **Grid**: aktifkan grid 1px untuk presisi, **Shortcut:** Ctrl+Shift+G
- **Copy/Paste Cel**: duplikat karakter untuk konsistensi, **Shortcut:** Ctrl+C / Ctrl+V
- **Export Sprite Sheet**: ekspor font sebagai bitmap, **Shortcut:** Ctrl+Shift+X

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file 96x16 px (16 karakter x 6 lebar per karakter).
2. Set grid 1px, zoom 800-1600%.
3. Gambar huruf "A" di area 6x7 px: bentuk segitiga dengan celah tengah.
4. Lanjutkan huruf "B" di sampingnya dengan jarak 1px.
5. Buat semua huruf kapital A-Z, lalu angka 0-9.
6. Uji dengan menulis kata menggunakan Text Tool di canvas terpisah.
7. Ekspor sebagai sprite sheet untuk di-load engine game.
