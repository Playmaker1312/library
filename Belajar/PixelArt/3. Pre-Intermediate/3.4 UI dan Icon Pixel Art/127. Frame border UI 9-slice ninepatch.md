# 127. Frame border UI 9-slice ninepatch

## Definisi Singkat
Nine-patch adalah teknik membagi border UI menjadi 9 bagian (4 corner, 4 edge, 1 center) agar frame bisa diskalakan tanpa distorsi. Corner tetap statis, edge dan center direpetisi atau diregangkan.

## Analogi
Bingkai foto: keempat sudutnya tetap, sisi atas/bawah melebar secara horizontal, sisi kiri/kanan melebar vertikal, dan bagian tengah menyesuaikan ukuran konten.

## Poin-Poin Penting
- 4 corner tidak boleh stretch agar sudut tetap tajam.
- Edge hanya stretch pada satu sumbu (horizontal/vertikal).
- Center bisa stretch penuh atau di-fill dengan warna solid.
- Ukuran corner menentukan radius minimum border.
- Simpan slice area di Aseprite untuk ekspor nine-patch.

## Shortcut & Fitur Aseprite
- **Slice Tool**: buat area slice untuk menentukan region nine-patch, **Shortcut:** Shift+S
- **Sprite Sheet Export**: ekspor dengan slice data untuk engine, **Shortcut:** Ctrl+Shift+X
- **Pixel Grid**: aktifkan grid untuk alignment corner, **Shortcut:** Ctrl+Shift+G

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file 64x64 px dengan canvas transparan.
2. Gambar border frame 1-2 px di tepi luar.
3. Tandai sudut kiri atas 8x8 px sebagai corner — jangan stretch.
4. Buat Slice: kiri 8px, kanan 8px, atas 8px, bawah 8px sebagai region nine-patch.
5. Gambar center area kosong atau dengan texture subtle.
6. Ekspor sebagai sprite sheet dengan slice data untuk engine (Godot/Unity).
7. Uji di engine: ubah ukuran frame UI, pastikan corner tidak distorsi.
