# 36. Value (Gelap dan Terang)

## Definisi Singkat
Value adalah tingkat kecerahan suatu warna — seberapa terang atau gelap tampilannya, tanpa memandang hue-nya. Dalam pixel art, value menentukan volume, kedalaman, dan pencahayaan objek.

## Analogi
Seperti foto hitam-putih. Semua warna merah, biru, hijau akan terlihat sebagai abu-abu. Sebuah apel merah dan semangka hijau bisa memiliki value yang sama jika kecerahan warnanya setara. Fotografer mengatur value dengan cahaya, pixel artist mengaturnya dengan pemilihan warna.

## Poin-Poin Penting
- Value berbeda dari hue: kuning secara alami lebih terang dari biru pada value yang sama.
- Buat ramping (gradasi) value: dari gelap ke terang untuk shading realistis.
- Gunakan setidaknya 3 tingkat value: bayangan, midtone, highlight.
- Pixel art kuno (Gameboy) hanya punya 4 value — semua informasi disampaikan lewat value.
- Cek value dengan mengubah sprite ke grayscale — jika terbaca, value-nya sudah baik.

## Shortcut & Fitur Aseprite
- **Desaturate Preview**: View → Desaturate untuk melihat sprite dalam grayscale
- **Color Bar → Value slider**: atur Value saat di mode HSV
- **Remap Value**: Sprite → Color → Curves untuk menyesuaikan value

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite, buat file 16x16.
2. Gambar bola sederhana (lingkaran 12x12 pixel).
3. Pilih satu hue (misal: biru). Buat 4 variasi value biru:
   - Biru sangat gelap (#0a1c2e)
   - Biru gelap (#1a3a5c)
   - Biru sedang (#2d6a9f)
   - Biru terang (#5ba3d9)
4. Warnai bola: area kiri bawah dengan biru tergelap, kanan atas dengan biru terang.
5. Tekan `View → Desaturate` — lihat apakah gradasi abu-abu terlihat mulus.
6. Jika masih ada lompatan value yang terlalu kontras, tambah warna transisi.
