# 43. Sprite Karakter 16x16 Pixel

## Definisi Singkat
Sprite 16x16 pixel adalah ukuran standar untuk karakter dalam banyak game retro dan indie modern. Dengan 256 pixel, sprite ini memungkinkan detail lebih banyak seperti ekspresi, rambut, dan aksesoris tanpa kehilangan esensi pixel art.

## Analogi
Seperti membuat patung dari 256 balok Lego — 4 kali lipat dari 8x8. Sekarang Anda bisa menambahkan mata, mulut, rambut, baju, sepatu, dan senjata. Tapi tetap harus selektif; setiap balok masih berharga.

## Poin-Poin Penting
- Ukuran paling serbaguna: cukup detail untuk ekspresi, cukup kecil untuk workflow cepat.
- Alokasikan pixel: kepala 6-8px, badan 8-10px, kaki 4-6px.
- Gunakan 5-8 warna per karakter (termasuk outline dan highlight).
- Pertahankan silhouette yang kuat — jangan timbun detail yang tidak perlu.
- Mulai dengan sketsa 8x8 lalu perkaya di 16x16.

## Shortcut & Fitur Aseprite
- **Pencil Tool**: **Shortcut:** `B`
- **Eyedropper**: **Shortcut:** `I` (tahan `Ctrl` untuk pickup warna)
- **Symmetry**: **Shortcut:** `Shift+M` — gambar setengah karakter
- **Replace Color**: Sprite → Color → Replace Color — ganti warna cepat

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 16x16, Background: Transparent.
2. Aktifkan Symmetry Horizontal (`Shift+M`) — gambar hanya setengah karakter.
3. Sketsa outline karakter:
   - Kepala: baris 1-4, lebar 8px (simetris, jadi 4px per sisi).
   - Badan: baris 5-10, lebar 6px.
   - Kaki: baris 11-14, lebar 4px per kaki.
4. Isi warna dasar: kulit (#e8b87a), baju (#cc3333), celana (#333366).
5. Tambahkan shading: baju lebih gelap di sisi kiri (#992222), lebih terang di kanan (#dd4444).
6. Tambahkan mata (2 pixel putih + 1 pixel hitam), mulut (1 pixel).
7. Nonaktifkan Symmetry, periksa karakter secara utuh — perbaiki jika ada posisi aneh.
8. Simpan sebagai "Karakter 16x16.ase".
