# 42. Sprite Karakter 8x8 Pixel

## Definisi Singkat
Sprite 8x8 pixel adalah sprite beresolusi sangat kecil — hanya 64 pixel total. Ini adalah tantangan pixel art paling dasar: membuat karakter yang terbaca hanya dengan 64 kotak. Digunakan di game klasik seperti Space Invaders, Pac-Man, dan NES awal.

## Analogi
Seperti membuat patung dari 64 balok Lego. Anda tidak bisa membuat detail wajah — yang bisa dibuat hanya bentuk dasar: ini kepala, ini badan, ini kaki. Setiap balok harus ditempatkan dengan perhitungan matang.

## Poin-Poin Penting
- Hanya 64 pixel — setiap pixel sangat berharga. Tidak boleh ada pixel yang "terbuang."
- Abaikan detail kecil. Fokus pada: bentuk kepala, posisi mata, senjata/tanda pengenal.
- Gunakan maksimal 3-4 warna untuk sprite 8x8.
- Silhouette harus sangat kuat — jika tidak terbaca di 8x8, perbesar jadi 16x16.
- Pixel 8x8 paling sulit: makin kecil resolusi, makin susah membuatnya terbaca.

## Shortcut & Fitur Aseprite
- **Pencil Tool**: **Shortcut:** `B` — gambar pixel by pixel
- **Zoom 1600%**: **Shortcut:** `Ctrl+Shift++` — perbesar maksimal
- **Grid Overlay**: **Shortcut:** `Ctrl+Shift+G` — lihat setiap pixel
- **Symmetry**: **Shortcut:** `Shift+M` — mirror horizontal untuk karakter simetris

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 8x8 pixel, Background: Transparent.
2. Zoom 1600% (`Ctrl+Shift++`).
3. Pilih warna gelap (#000000 atau #333333).
4. Gambar bentuk manusia:
   - 2 pixel untuk kepala (baris 1-2), 4 pixel lebar.
   - 2 pixel badan (baris 3-4), 4 pixel lebar.
   - 2 pixel kaki (baris 5-6), @2 pixel per kaki.
5. Tambahkan 1 pixel putih untuk mata.
6. Tambahkan 1 pixel merah untuk topi/bendera pembeda.
7. Simpan sebagai "Karakter 8x8.ase".
8. Uji readability: zoom ke 100% — apakah masih terbaca sebagai karakter?
