# 46. Sprite Tile: Rumput, Tanah, Batu

## Definisi Singkat
Sprite tile adalah ubin (tile) yang dipasang berulang (tileable) untuk membentuk lantai, dinding, dan lingkungan dalam game. Tile harus seamless — saat dipasang berdampingan, sambungannya tidak terlihat. Rumput, tanah, dan batu adalah tile paling dasar.

## Analogi
Seperti memasang ubin keramik di lantai. Setiap ubin memiliki pola yang sama di tepinya sehingga saat dipasang bersebelahan, motifnya nyambung mulus. Tile rumput harus terlihat seperti satu hamparan rumput, bukan kotak-kotak terpisah.

## Poin-Poin Penting
- Tile harus seamless: tepi kiri = kebalikan tepi kanan; tepi atas = kebalikan tepi bawah.
- Hindari pola berulang yang terlalu jelas — tambah variasi kecil.
- Ukuran tile standar: 8x8, 16x16, 32x32.
- Batasi warna: 4-8 warna per tile.
- Tile rumput: dominan hijau dengan variasi dedaunan.
- Tile tanah: coklat, tekstur granular, bayangan halus.
- Tile batu: abu-abu, retakan, variasi value.

## Shortcut & Fitur Aseprite
- **Tile Mode**: View → Symmetry → Tile — **Shortcut:** `Shift+H` — lihat tile berulang
- **Offset**: Edit → Shift — **Shortcut:** `Ctrl+H` — untuk cek sambungan tile
- **Pencil Tool**: **Shortcut:** `B`
- **Grid Overlay**: **Shortcut:** `Ctrl+Shift+G`

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 16x16. Aktifkan Tile Mode (`Shift+H`).
2. **Tile Rumput**:
   - Base hijau (#4a8c3f) di seluruh tile.
   - Tambah variasi 3-4 pixel hijau lebih terang (#6ab84f) acak.
   - Tambah 2-3 pixel hijau gelap (#2d5e25) sebagai shadow.
   - Pastikan tidak ada pola berulang garis lurus di tepi.
3. Cek sambungan: aktifkan offset (`Ctrl+H`) — lihat apakah tepi nyambung.
4. **Tile Tanah**:
   - Base coklat (#8b6914).
   - Titik-titik kecil coklat gelap (#5c4510) dan terang (#a8842a).
5. **Tile Batu**:
   - Base abu-abu (#7a7a7a).
   - Retakan diagonal tipis dengan abu-abu gelap (#4a4a4a).
6. Simpan sebagai "Tiles.ase".
