# 15. Pixel Ratio 1:1 untuk Pixel Art Murni

## Definisi Singkat
Pixel ratio 1:1 berarti satu piksel pada canvas sama dengan satu piksel pada layar — tidak ada scaling atau stretching. Ini adalah pengaturan standar untuk pixel art murni agar setiap piksel tetap tajam dan persis.

## Analogi
Seperti ubin lantai berukuran 1×1 cm — setiap ubin adalah satu unit terkecil yang tidak bisa dipecah lagi.

## Poin-Poin Penting
- Pixel ratio 1:1 membuat setiap klik Pencil Tool menghasilkan satu piksel persis
- Pixel ratio selain 1:1 (misal 2:1) menghasilkan piksel persegi panjang — digunakan untuk efek spesifik (misal gaya MS Paint)
- Aseprite secara default menggunakan 1:1 untuk pixel art
- Pixel ratio bisa diubah di Sprite → Sprite Size → Pixel Ratio
- Pixel art murni SELALU menggunakan 1:1

## Shortcut & Fitur Aseprite
- **New File > Pixel Ratio**: atur di dialog pembuatan file baru
- **Sprite > Sprite Size**: ubah pixel ratio setelah file dibuat, **Shortcut:** Ctrl+R

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 16×16 px dengan Pixel Ratio 1:1
2. Gambar garis diagonal dari kiri atas ke kanan bawah — setiap langkah adalah 1 piksel
3. Buat file baru lain dengan Pixel Ratio 2:1
4. Gambar garis diagonal yang sama — piksel melebar horizontal (persegi panjang)
5. Bandingkan kedua hasil: 1:1 terlihat kotak proporsional, 2:1 terlihat stretched
6. Kembali ke 1:1 untuk pixel art normal
