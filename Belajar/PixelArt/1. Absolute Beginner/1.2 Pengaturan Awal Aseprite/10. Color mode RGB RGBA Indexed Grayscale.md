# 10. Color Mode: RGB, RGBA, Indexed, Grayscale

## Definisi Singkat
Color mode menentukan cara warna disimpan dalam file. RGBA (Red Green Blue Alpha) menyimpan jutaan warna plus channel transparansi. Indexed membatasi jumlah warna (seperti palet 8-bit). Grayscale hanya hitam-putih dan abu-abu.

## Analogi
RGB seperti kotak pensil warna 256 warna — Indexed seperti krayon 16 warna — Grayscale seperti pensil arang.

## Poin-Poin Penting
- **RGB/RGBA**: 16,7 juta warna, lengkap dengan transparansi (Alpha). Paling fleksibel
- **Indexed**: maksimal 256 warna, ukuran file lebih kecil, cocok untuk gaya retro
- **Grayscale**: 256 level abu-abu (tanpa warna). Untuk sketsa atau efek monokrom
- RGBA adalah pilihan terbaik untuk pemula
- Indexed penting untuk game dengan palet terbatas (platform retro)

## Shortcut & Fitur Aseprite
- **Change Color Mode**: ganti mode warna file aktif, ada di menu Sprite → Color Mode
- **Posterize**: kurangi jumlah warna file RGB ke jumlah tertentu, **Shortcut:** Shift+Ctrl+P

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file RGBA 32×32 px, gambar lingkaran warna-warni
2. Duplikat layer (Ctrl+D) lalu ubah mode ke Indexed (Sprite → Color Mode → Indexed)
3. Amati warna-warna yang berubah karena dibatasi palet
4. Buat file baru dengan mode Grayscale
5. Gambar dengan warna abu-abu saja — perhatikan Color Palette hanya menampilkan abu-abu
