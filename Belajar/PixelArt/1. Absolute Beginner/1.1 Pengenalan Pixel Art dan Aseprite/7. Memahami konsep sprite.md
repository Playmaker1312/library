# 7. Memahami Konsep Sprite

## Definisi Singkat
Sprite adalah gambar dua dimensi (biasanya karakter, objek, atau elemen UI) yang digunakan dalam game komputer dan animasi. Dalam pixel art, sprite biasanya berupa gambar independen dengan latar belakang transparan.

## Analogi
Seperti guntingan kertas tokoh wayang — Anda bisa memindahkannya di atas panggung tanpa mengubah latar belakang.

## Poin-Poin Penting
- Sprite biasanya memiliki latar transparan (bukan background solid)
- Satu sprite bisa memiliki beberapa frame untuk animasi
- Sprite sheet menggabungkan beberapa frame sprite ke dalam satu file besar
- Resolusi sprite diukur dalam piksel (misal 16×16, 32×32)
- Istilah "sprite" berasal dari era grafis komputer tahun 1970-an

## Shortcut & Fitur Aseprite
- **New Frame**: menambah frame baru untuk animasi, **Shortcut:** Alt+N
- **Sprite Sheet Export**: ekspor semua frame sebagai sprite sheet, **Shortcut:** Ctrl+E
- **Onion Skin**: melihat transparansi frame sebelumnya, **Shortcut:** Shift+O

## Contoh Kasus Nyata (Step-by-Step)
1. Buat file baru 32×32 px dengan background transparan
2. Gambar lingkaran merah sederhana di tengah
3. Tambahkan frame baru (Alt+N) — frame sebelumnya akan menjadi abu-abu (onion skin)
4. Pindahkan lingkaran sedikit ke kanan di frame baru
5. Ulangi hingga 4 frame — Anda telah membuat sprite beranimasi
6. Ekspor sebagai GIF untuk melihat animasi
