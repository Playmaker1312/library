# 6. Mengenal Antarmuka Aseprite: Canvas, Toolbar, Color Palette

## Definisi Singkat
Antarmuka Aseprite terdiri dari tiga area utama: Canvas (area kerja untuk menggambar), Toolbar (kiri, berisi alat-alat seperti pensil dan penghapus), dan Color Palette (bawah/kanan, untuk memilih dan mengelola warna). Memahami tata letak ini adalah langkah pertama sebelum menggambar.

## Analogi
Seperti meja kerja pelukis: kanvas di tengah, kuas dan alat di sisi kiri, cat air di sisi kanan atau bawah.

## Poin-Poin Penting
- Canvas adalah area persegi tempat piksel ditempatkan
- Toolbar berisi ikon alat-alat (Pencil, Eraser, Fill, dll.)
- Color Palette menampilkan warna-warna yang tersedia; bisa diubah dan ditambah
- Timeline berada di bawah canvas untuk animasi
- Status bar di bawah kiri menunjukkan koordinat piksel, zoom, dan ukuran canvas

## Shortcut & Fitur Aseprite
- **Toggle Timeline**: tampilkan/sembunyikan timeline, **Shortcut:** Tab
- **Toggle Color Palette**: tampilkan/sembunyikan palet, **Shortcut:** Shift+Tab
- **Toggle Toolbar**: sembunyikan toolbar untuk fokus menggambar, **Shortcut:** Ctrl+Shift+B

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite dan buat file baru 64×64 px
2. Identifikasi Canvas di tengah layar — coba scroll untuk zoom
3. Cari Toolbar di sebelah kiri — hover kursor di atas ikon untuk melihat nama alat
4. Cari Color Palette di sebelah kanan atau bawah — klik satu warna
5. Gambar satu piksel dengan warna itu menggunakan Pencil Tool
6. Perhatikan koordinat kursor di pojok kiri bawah canvas
