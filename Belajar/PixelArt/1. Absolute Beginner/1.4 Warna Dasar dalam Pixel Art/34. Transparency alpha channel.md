# 34. Transparency (Alpha Channel)

## Definisi Singkat
Alpha channel adalah kanal tambahan di setiap pixel yang menentukan tingkat transparansi. Nilai 0 = sepenuhnya transparan, 255 = sepenuhnya buram. Ini memungkinkan pixel art memiliki latar belakang tembus pandang.

## Analogi
Seperti stiker vinil. Bagian gambar yang ditempel buram (alpha 255), sedangkan area kosong di sekelilingnya bening dan tembus pandang (alpha 0). Saat ditempel di kertas warna apa pun, hanya gambar stiker yang terlihat.

## Poin-Poin Penting
- Pixel art biasanya disimpan dengan latar transparan (PNG), bukan latar putih.
- Checkerboard pattern di Aseprite menandakan area transparan.
- Alpha channel penting untuk: overlay sprite di background game, membuat bayangan, efek glow.
- Hindari transparansi parsial (anti-aliasing terhadap transparan) untuk pixel art murni.
- Format PNG mendukung alpha; JPG tidak — selalu export ke PNG.

## Shortcut & Fitur Aseprite
- **Toggle Alpha Background**: View → Alpha (atau **Shortcut:** `Shift+A`)
- **Checkerboard**: View → Checkered Background untuk melihat transparansi
- **Erase Alpha**: Eraser tool menghapus pixel menjadi transparan
- **Clear Layer**: Layer → Clear Layer untuk membuat seluruh layer transparan

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite, buat file baru 32x32 dengan **Background: Transparent**.
2. Canvas akan menampilkan pola checkerboard (kotak abu-abu) — itu area transparan.
3. Gambar lingkaran kecil merah di tengah.
4. Tekan `Shift+A` untuk toggle alpha background — area transparan jadi putih.
5. Gunakan Eraser tool untuk menghapus beberapa pixel merah — pixel itu kembali ke transparan.
6. Export: File → Export → pilih **PNG** → centang **Transparent Background**.
7. Buka file PNG hasil export di browser — hanya lingkaran merah yang terlihat, tanpa latar.
