# 28. HSV / HSB (Hue, Saturation, Value / Brightness)

## Definisi Singkat
HSV adalah model warna yang merepresentasikan warna berdasarkan tiga komponen intuitif: Hue (rona/warna dasar), Saturation (kejenuhan/keabuan), dan Value (kecerahan). Model ini lebih mudah dipahami manusia dibanding RGB.

## Analogi
Bayangkan sebuah silinder warna. Hue adalah posisi melingkar — merah, kuning, hijau, biru. Saturation adalah jarak dari pusat — makin ke tepi makin murni, makin ke pusat makin abu-abu. Value adalah ketinggian — makin ke atas makin terang, ke bawah makin gelap hingga hitam.

## Poin-Poin Penting
- Hue: 0°=merah, 120°=hijau, 240°=biru, kembali ke 360°=merah lagi.
- Saturation (0-100%): 0% = abu-abu, 100% = warna murni.
- Value (0-100%): 0% = hitam, 100% = warna paling terang.
- HSB identik dengan HSV; perbedaan hanya pada Brightness vs Value.
- Sangat berguna untuk memilih warna bayangan: turunkan Value saja tanpa mengubah Hue.

## Shortcut & Fitur Aseprite
- **HSV Sliders**: di Color Bar → gear icon → pilih **HSV**
- **Color Wheel**: Window → Color Wheel untuk pemilihan Hue visual
- **Remap Hue**: Sprite → Color → Hue/Saturation untuk mengubah warna semua pixel

## Contoh Kasus Nyata (Step-by-Step)
1. Di Aseprite, buka Color Bar → gear → pilih **HSV**.
2. Atur Hue ke 0 (merah), Saturation 100%, Value 100% — dapat merah terang.
3. Turunkan Value ke 50% — merah berubah jadi merah gelap.
4. Naikkan Value kembali, turunkan Saturation ke 20% — merah jadi merah pudar.
5. Gunakan Color Wheel (Window → Color Wheel) untuk melihat perubahan secara visual.
6. Praktik: buat gradasi 5 warna merah dari terang ke gelap hanya dengan mengubah Value.
