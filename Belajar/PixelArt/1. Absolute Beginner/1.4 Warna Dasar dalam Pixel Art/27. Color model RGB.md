# 27. Color Model RGB

## Definisi Singkat
RGB (Red-Green-Blue) adalah model warna aditif yang digunakan layar monitor, di mana setiap pixel menyala dengan kombinasi cahaya merah, hijau, dan biru. Setiap kanal memiliki nilai 0-255 (8-bit), total 16,7 juta warna.

## Analogi
Seperti tiga lampu sorot warna merah, hijau, dan biru yang diarahkan ke satu titik di panggung gelap. Makin terang masing-masing lampu, makin terang warna yang dihasilkan. Jika semua menyala penuh, hasilnya putih — bukan hitam.

## Poin-Poin Penting
- Model aditif: semakin besar nilai, semakin terang warnanya — kebalikan dari cat/cetak.
- Nilai RGB (0,0,0) = hitam, (255,255,255) = putih.
- Dalam pixel art, kombinasi RGB menentukan setiap pixel di sprite.
- Heksadesimal (#FF8800) adalah representasi kompak RGB; FF=merah, 88=hijau, 00=biru.
- Memahami RGB membantu pencocokan warna antar palette dan software.

## Shortcut & Fitur Aseprite
- **Color Picker**: klik Eyedropper di toolbar, **Shortcut:** `I`
- **RGB Sliders**: ubah mode di Color Bar dari dropdown menu, pilih RGB
- **Enter Hex Code**: ketik langsung nilai #RRGGBB di Color Bar

## Contoh Kasus Nyata (Step-by-Step)
1. Buka Aseprite dan buat file baru 32x32 pixel.
2. Arahkan kursor ke Color Bar (kanan bawah).
3. Klik ikon roda gigi (gear) di Color Bar → pilih **RGB** sebagai color mode.
4. Geser slider Red ke 255, Green ke 128, Blue ke 64 → lihat warna oranye keemasan muncul.
5. Catat nilai heksanya: #FF8040.
6. Gambar pixel di canvas dengan warna tersebut untuk melihat hasil langsung.
7. Ganti nilai Green ke 0, simpan kombinasi RGB lain dan bandingkan perbedaannya.
