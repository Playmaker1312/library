# 17. Pencil Tool

## Definisi Singkat
Pencil Tool adalah alat paling dasar dan paling penting dalam pixel art. Fungsinya menggambar satu piksel setiap kali klik (dengan ukuran 1px) atau beberapa piksel jika ukuran brush diperbesar.

## Analogi
Seperti pena ujung 0.1mm untuk menggambar titik — presisi, tanpa efek tambahan, hasilnya persis seperti yang Anda gambar.

## Poin-Poin Penting
- Pencil Tool TIDAK menghasilkan anti-aliasing — setiap piksel solid
- Ukuran brush bisa diubah (1px, 2px, 3px, dll.) tetapi untuk pixel art murni gunakan 1px
- Pencil Tool bisa digunakan dengan warna foreground (klik kiri) atau background (klik kanan)
- Mode pencil: Normal, Pixel-perfect, dan lainnya
- Ini adalah alat utama untuk 90% pekerjaan pixel art

## Shortcut & Fitur Aseprite
- **Pencil Tool**: pilih alat pensil, **Shortcut:** B
- **Brush Size**: ubah ukuran brush, **Shortcut:** [, ] (kurung siku)
- **Pixel-perfect mode**: gambar garis mulus tanpa celah, **Shortcut:** ada di options bar

## Contoh Kasus Nyata (Step-by-Step)
1. Pilih Pencil Tool (tekan B)
2. Atur ukuran brush ke 1px (tekan [ beberapa kali hingga 1)
3. Klik kiri di canvas — satu piksel muncul dengan warna foreground
4. Klik kanan — satu piksel muncul dengan warna background
5. Tahan Shift + klik — buat garis lurus dari titik awal ke titik klik
6. Gambar bentuk sederhana: kotak 3×3 piksel untuk latihan
