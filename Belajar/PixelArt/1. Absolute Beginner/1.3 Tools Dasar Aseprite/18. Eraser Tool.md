# 18. Eraser Tool

## Definisi Singkat
Eraser Tool (penghapus) berfungsi menghapus piksel dari canvas. Dalam pixel art, penghapus penting untuk mengoreksi kesalahan dan membersihkan tepi sprite.

## Analogi
Seperti penghapus karet pada pensil — digunakan untuk menghapus garis yang salah atau membersihkan area yang tidak diinginkan.

## Poin-Poin Penting
- Eraser menghapus ke transparan (jika layer transparan) atau ke warna background (jika layer solid)
- Ukuran eraser bisa diubah seperti Pencil Tool
- Eraser bisa digunakan dalam mode "Replace" (hapus total) atau "Alpha" (hapus dengan transparansi parsial)
- Untuk pixel art, gunakan mode Replace agar hapus bersih
- Alternatif: gunakan Pencil Tool dengan warna background untuk "menghapus" secara manual

## Shortcut & Fitur Aseprite
- **Eraser Tool**: pilih alat penghapus, **Shortcut:** E
- **Brush Size**: ubah ukuran eraser, **Shortcut:** [, ]
- **Toggle Eraser/Pencil**: gunakan Pencil Tool sambil tahan Ctrl untuk hapus sementara

## Contoh Kasus Nyata (Step-by-Step)
1. Gambar kotak 5×5 piksel dengan Pencil Tool
2. Tekan E untuk memilih Eraser Tool
3. Atur ukuran brush ke 3px
4. Hapus sebagian piksel dari kotak dengan klik kiri
5. Tahan tombol kanan mouse untuk menghapus area yang lebih luas
6. Gunakan Ctrl+Z jika kelebihan hapus (Undo: Ctrl+Z)
