# 20. Line Tool

## Definisi Singkat
Line Tool menggambar garis lurus dari satu titik ke titik lain. Dalam pixel art, alat ini berguna untuk membuat garis lurus sempurna, baik horizontal, vertikal, maupun diagonal.

## Analogi
Seperti penggaris untuk menggambar garis lurus di kertas — hasilnya rapi dan presisi tanpa goyangan tangan.

## Poin-Poin Penting
- Tahan Shift saat menggambar untuk mengunci sudut 45°/90°
- Mode Pixel-perfect membuat garis diagonal mulus tanpa celah (staircase halus)
- Ketebalan garis bisa diatur melalui Brush Size
- Line Tool bisa dikombinasikan dengan Fill untuk membuat bentuk geometris
- Untuk garis bebas, lebih baik gunakan Pencil Tool dengan Shift-klik

## Shortcut & Fitur Aseprite
- **Line Tool**: pilih alat garis, **Shortcut:** Shift+L
- **Pixel-perfect mode**: aktifkan di options bar untuk garis diagonal sempurna
- **Brush Size**: ubah ketebalan garis, **Shortcut:** [, ]

## Contoh Kasus Nyata (Step-by-Step)
1. Pilih Line Tool (Shift+L), atur Brush Size 1px
2. Klik di satu titik, lalu klik di titik lain — garis lurus terbentuk
3. Tahan Shift — coba klik ke berbagai arah, garis akan mengunci 45°/90°
4. Aktifkan Pixel-perfect mode di options bar
5. Gambar garis diagonal dari kiri bawah ke kanan atas
6. Nonaktifkan Pixel-perfect, gambar diagonal lagi — bandingkan perbedaan hasilnya
