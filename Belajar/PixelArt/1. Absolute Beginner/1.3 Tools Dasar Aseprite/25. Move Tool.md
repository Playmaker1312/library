# 25. Move Tool

## Definisi Singkat
Move Tool digunakan untuk memindahkan posisi layer, seleksi, atau piksel di dalam canvas. Berguna untuk mengatur tata letak sprite, merapikan posisi, atau membuat salinan bergerak.

## Analogi
Seperti menggeser stiker di atas meja — Anda bisa memindahkannya ke posisi baru tanpa merusak bentuknya.

## Poin-Poin Penting
- Move Tool memindahkan SELURUH layer aktif jika tidak ada seleksi
- Jika ada seleksi aktif (Marquee), hanya area terseleksi yang bergerak
- Tahan Shift saat memindahkan untuk mengunci gerakan horizontal/vertikal
- Gunakan tombol panah (arrow keys) untuk memindahkan 1 piksel secara presisi
- Tahan Shift + panah untuk memindahkan 10 piksel sekaligus

## Shortcut & Fitur Aseprite
- **Move Tool**: pilih alat pindah, **Shortcut:** V
- **Arrow Keys**: geser 1 piksel
- **Shift + Arrow Keys**: geser 10 piksel
- **Ctrl + Arrow Keys**: geser 1 piksel (jika Move Tool tidak aktif)

## Contoh Kasus Nyata (Step-by-Step)
1. Gambar kotak 10×10 di tengah canvas 32×32
2. Pilih Move Tool (V)
3. Klik pada kotak, drag ke pojok kiri atas
4. Gunakan tombol panah kanan untuk menggeser 3 piksel ke kanan
5. Shift + panah kanan untuk loncat 10 piksel
6. Buat seleksi pada setengah kotak, lalu pindahkan — hanya setengah kotak yang bergerak
