# 165. Inversion (Not only but also, Rarely, Seldom, Never, etc)

## Definisi & Target
Inversion adalah membalik posisi subject dan auxiliary verb untuk memberi penekanan. Biasanya dipakai setelah negative adverbs di awal kalimat. Target: menggunakan inversion dalam tulisan formal dan pidato.

## Analogi
Dalam bahasa sehari-hari kita bilang "Saya jarang ke mal." Tapi kalau mau dramatis: "Jarang sekali saya ke mal!" Nah, inversion di bahasa Inggris mirip — subjek dan kata kerja ditukar posisinya untuk efek dramatis.

## Pola & Struktur

| Adverb | Struktur | Contoh |
|--------|----------|--------|
| Never | Never + auxiliary + S + V | Never have I seen such beauty |
| Rarely / Seldom | Rarely + auxiliary + S + V | Rarely does he eat out |
| Not only | Not only + auxiliary + S + V, but also... | Not only did she win, but she also broke a record |
| Hardly / Scarcely | Hardly + had + S + V3 + when... | Hardly had we left when it started raining |
| No sooner | No sooner + had + S + V3 + than... | No sooner had he arrived than the meeting ended |
| Under no circumstances | Under no circumstances + auxiliary + S + V | Under no circumstances should you open the door |

## Contoh

1. **Not only did he finish first, but he also set a new record.** — Tidak hanya dia finish pertama, tapi dia juga mencetak rekor baru.
2. **Rarely do we see such dedication.** — Jarang kita melihat dedikasi seperti ini.
3. **Never have I been so embarrassed.** — Tidak pernah saya semalu ini.
4. **Seldom does she complain about anything.** — Jarang sekali dia mengeluh tentang apa pun.
5. **Hardly had I sat down when the phone rang.** — Baru saja saya duduk, telepon berdering.

## Latihan

1. Ubah "I have never experienced such kindness" menggunakan inversion.
2. Buat kalimat dengan "Not only... but also" tentang seseorang yang sukses.
3. Lengkapi: Seldom ___ we ___ (see) such talent in one person.
4. Ubah "You should not open this box under any circumstances."
5. Tulis kalimat menggunakan "No sooner... than" tentang kejadian kemarin.
