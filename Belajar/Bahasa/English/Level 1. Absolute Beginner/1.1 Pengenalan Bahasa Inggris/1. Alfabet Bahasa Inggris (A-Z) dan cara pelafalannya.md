# 1. Alfabet Bahasa Inggris (A-Z) dan cara pelafalannya

## Definisi & Target
Alfabet Bahasa Inggris terdiri dari 26 huruf (A-Z). Target: mampu mengenali dan melafalkan setiap huruf dengan benar sesuai English pronunciation.

## Analogi
Seperti mengenal 26 kunci berbeda — setiap huruf punya bunyi khas. Hafalkan seperti menghafal nama-nama teman sekelas.

## Daftar & Pelafalan

| Huruf | Pelafalan (IPA) | Cara Baca (Indonesia) |
|-------|-----------------|----------------------|
| A a   | /eɪ/            | "ey" seperti pada "say" |
| B b   | /biː/           | "bii" panjang |
| C c   | /siː/           | "sii" panjang |
| D d   | /diː/           | "dii" panjang |
| E e   | /iː/            | "ii" panjang |
| F f   | /ɛf/            | "ef" |
| G g   | /dʒiː/          | "jii" panjang |
| H h   | /eɪtʃ/          | "eich" |
| I i   | /aɪ/            | "ai" seperti pada "eye" |
| J j   | /dʒeɪ/          | "jey" |
| K k   | /keɪ/           | "key" |
| L l   | /ɛl/            | "el" |
| M m   | /ɛm/            | "em" |
| N n   | /ɛn/            | "en" |
| O o   | /oʊ/            | "ou" seperti pada "go" |
| P p   | /piː/           | "pii" panjang |
| Q q   | /kjuː/          | "kyuu" |
| R r   | /ɑːr/           | "aar" (dengan getaran) |
| S s   | /ɛs/            | "es" |
| T t   | /tiː/           | "tii" panjang |
| U u   | /juː/           | "yuu" |
| V v   | /viː/           | "vii" panjang |
| W w   | /ˈdʌbəl juː/    | "dabel yuu" |
| X x   | /ɛks/           | "eks" |
| Y y   | /waɪ/           | "wai" |
| Z z   | /ziː/ (US) atau /zɛd/ (UK) | "zii" atau "zed" |

## Contoh
- "My name is **B**udi." — huruf B dilafalkan /biː/
- "I live in **J**akarta." — huruf J dilafalkan /dʒeɪ/

## Latihan
1. Sebutkan alfabet dari A sampai Z dengan suara keras, 3 kali.
2. Eja nama lengkapmu huruf per huruf dalam Bahasa Inggris.
3. Dengarkan lagu "ABC Song" dan ikuti nyanyiannya.
4. Tebak huruf: guru menyebut pelafalan, kamu tulis hurufnya.
