# 130. Root words dari Latin dan Greek

## Definisi & Target
Mengenal akar kata (root words) dari bahasa Latin dan Yunani untuk menebak arti kata-kata baru dalam bahasa Inggris.

## Analogi
Seperti **batu bata Lego** — dari beberapa root kata, kita bisa membangun ratusan kata lain. "Dict" (Latin: berkata) melahirkan predict, dictionary, contradict, dictator.

## Daftar & Penjelasan

### Root dari Latin
| Root | Arti | Contoh |
|------|------|--------|
| **dict** | berkata | predict, dictionary, contradict |
| **port** | membawa | transport, export, portable |
| **struct** | membangun | construct, structure, destroy |
| **spect** | melihat | inspect, respect, spectator |
| **aud** | mendengar | audio, audience, audit |
| **rupt** | pecah | disrupt, interrupt, bankrupt |
| **scrib/script** | menulis | describe, script, prescription |
| **duct** | memimpin | conduct, introduce, produce |

### Root dari Greek
| Root | Arti | Contoh |
|------|------|--------|
| **tele** | jauh | telephone, television, telescope |
| **phono** | suara | microphone, symphony, telephone |
| **graph** | menulis | autograph, biography, paragraph |
| **bio** | hidup | biology, biography, antibiotic |
| **logos** | ilmu | psychology, biology, technology |

## Latihan
1. Dari root "spect", tebak arti: "circumspect"
2. Dari root "port", apa arti "portable"?
3. Jika "bio" = hidup dan "graph" = menulis, apa arti "biography"?
4. Temukan kata dengan root "dict" selain contoh di atas.
5. Jika "tele" = jauh dan "scope" = melihat, apa itu "telescope"?
