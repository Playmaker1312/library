# 139. Vocabulary Science and Technology (menengah)

## Definisi & Target
Memperkaya kosakata bahasa Inggris menengah tentang sains dan teknologi.

## Daftar & Penjelasan

| Vocabulary | Arti | Contoh |
|------------|------|--------|
| **artificial intelligence (AI)** | kecerdasan buatan | **AI** is changing many industries. |
| **algorithm** | algoritma | The **algorithm** predicts user preferences. |
| **data** | data | We need to analyze the **data**. |
| **database** | basis data | The information is stored in a **database**. |
| **software** | perangkat lunak | I installed new **software**. |
| **hardware** | perangkat keras | The computer **hardware** is outdated. |
| **experiment** | eksperimen | The scientist conducted an **experiment**. |
| **laboratory** | laboratorium | The **laboratory** is well-equipped. |
| **research** | penelitian | She is doing **research** on cancer. |
| **innovation** | inovasi | This is a great technological **innovation**. |
| **device** | perangkat | Smartphones are portable **devices**. |
| **network** | jaringan | The **network** was down yesterday. |
| **cybersecurity** | keamanan siber | **Cybersecurity** is very important. |
| **download** | mengunduh | You can **download** the app. |
| **update** | pembaruan | I need to **update** my system. |
| **virtual** | maya | We attended a **virtual** meeting. |

## Latihan
1. Lengkapi: "AI stands for ______ ______."
2. Apa beda "software" dan "hardware"?
3. Lengkapi: "The scientist conducted an ______ (eksperimen) in the lab."
4. Jelaskan "cybersecurity" dalam bahasa Inggris sederhana.
5. Buat kalimat dengan "innovation" tentang teknologi.
