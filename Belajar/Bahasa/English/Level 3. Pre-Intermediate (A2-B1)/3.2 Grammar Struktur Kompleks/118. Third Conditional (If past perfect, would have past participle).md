# 118. Third Conditional (If past perfect, would have past participle)

## Definisi & Target
Menyatakan **penyesalan di masa lalu** — situasi yang sudah terjadi dan tidak bisa diubah. Membayangkan hasil yang berbeda jika kondisi di masa lalu berbeda.

## Analogi
Seperti **"Seandainya saya belajar, saya akan lulus ujian"** — faktanya saya tidak belajar dan saya tidak lulus. Ini murni penyesalan, tidak bisa diubah karena sudah masa lalu.

## Pola & Struktur
| Pola | Rumus |
|------|-------|
| (+) | **If + S + had + V3, S + would + have + V3** |
| (-) | **If + S + hadn't + V3, S + wouldn't + have + V3** |
| Bisa dibalik | **S + would + have + V3 + if + S + had + V3** |

## Contoh
| English | Indonesia |
|---------|-----------|
| If I had studied, I would have passed the exam. | Seandainya saya belajar, saya akan lulus ujian (tapi saya tidak belajar). |
| If she had left earlier, she wouldn't have missed the bus. | Seandainya dia berangkat lebih awal, dia tidak akan ketinggalan bus. |
| They would have won if they had practiced more. | Mereka akan menang jika mereka berlatih lebih keras. |
| If you had told me, I could have helped you. | Seandainya kamu bilang, saya bisa membantu. |

## Latihan
1. Lengkapi: "If I ______ (know) about the traffic, I ______ (leave) earlier."
2. Buat kalimat penyesalan: "He didn't study. He failed."
3. Ubah ke negatif: "If she had called, I would have come."
4. Buat pertanyaan: "What / you / do / if you / see / the accident?"
5. Bedakan Second vs Third Conditional: "If I were rich, I would travel" vs "If I had been rich, I would have traveled."
