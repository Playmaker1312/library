# 117. Second Conditional (If past simple, would verb)

## Definisi & Target
Menyatakan situasi **imajiner atau tidak nyata** di masa sekarang atau masa depan. Kemungkinannya kecil atau mustahil terjadi.

## Analogi
Seperti **"Seandainya saya punya sayap, saya akan terbang ke Jepang"** — faktanya saya tidak punya sayap, jadi ini hanya khayalan. Gunakan Second Conditional untuk hal-hal yang tidak realistis atau sangat tidak mungkin.

## Pola & Struktur
| Pola | Rumus |
|------|-------|
| (+) | **If + S + V2, S + would + V1** |
| (-) | **If + S + didn't + V1, S + wouldn't + V1** |
| Bisa dibalik | **S + would + V1 + if + S + V2** |

**Catatan:** "were" digunakan untuk semua subjek (I, he, she, it — bukan "was" dalam conditional).

## Contoh
| English | Indonesia |
|---------|-----------|
| If I had a million dollars, I would travel the world. | Seandainya saya punya sejuta dolar, saya akan keliling dunia. |
| If she were taller, she could be a model. | Seandainya dia lebih tinggi, dia bisa jadi model. |
| If they studied harder, they would pass the exam. | Seandainya mereka belajar lebih giat, mereka akan lulus ujian. |
| He would buy a house if he saved more money. | Dia akan membeli rumah jika dia menabung lebih banyak. |

## Latihan
1. Lengkapi: "If I ______ (be) you, I ______ (apologize)."
2. Buat kalimat: "If she / have / more time / she / learn / piano."
3. Ubah ke negatif: "If he knew the answer, he would tell us."
4. Tulis 2 kalimat tentang impianmu menggunakan Second Conditional.
5. Bedakan: "If it rains, I will stay home" (First Conditional) vs "If it rained, I would stay home" (Second Conditional).
