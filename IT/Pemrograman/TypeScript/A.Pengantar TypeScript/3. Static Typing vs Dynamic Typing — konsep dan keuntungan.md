### 3. Static Typing vs Dynamic Typing — Konsep dan Keuntungan

Memahami perbedaan antara pengetikan statis dan dinamis adalah kunci untuk memahami mengapa TypeScript diciptakan untuk "memperbaiki" cara kita menulis JavaScript.

---

### Definisi Singkat

**Static Typing** adalah konsep di mana tipe data variabel diperiksa pada saat **kompilasi** (sebelum kode dijalankan), sedangkan **Dynamic Typing** adalah konsep di mana tipe data variabel diperiksa pada saat **runtime** (ketika kode sedang berjalan).

---

### Analogi

Bayangkan Anda sedang mengirimkan barang melalui ekspedisi.

- **Static Typing (TypeScript/Java):** Petugas ekspedisi memeriksa isi paket Anda **sebelum** dikirim. Jika Anda mencoba mengirim cairan dalam botol kaca tanpa pelindung, mereka akan menolak paket tersebut di loket. Anda tahu ada masalah sebelum barang meninggalkan tangan Anda.
    
- **Dynamic Typing (JavaScript/Python):** Petugas langsung menerima paket Anda tanpa diperiksa. Masalah baru diketahui ketika paket tersebut pecah di dalam truk **saat perjalanan** dan merusak paket lainnya. Anda baru tahu ada kesalahan setelah sistem "berjalan".
    

---

### Poin-Poin Penting

#### **Dynamic Typing (JavaScript)**

- **Fleksibilitas Tinggi:** Variabel yang awalnya berisi angka bisa diubah menjadi teks tanpa protes dari sistem.
    
- **Kecepatan Prototyping:** Menulis kode terasa lebih cepat karena tidak perlu menulis definisi tipe data.
    
- **Risiko Runtime Error:** Error seperti `TypeError: Cannot read property 'x' of undefined` sering muncul tiba-tiba saat aplikasi digunakan oleh user.
    

#### **Static Typing (TypeScript)**

- **Keamanan Kode:** Tipe data terkunci sejak awal. Jika variabel didefinisikan sebagai `number`, ia tidak bisa mendadak jadi `string`.
    
- **Prediktabilitas:** Anda selalu tahu bentuk data yang masuk dan keluar dari sebuah fungsi.
    
- **Dokumentasi Otomatis:** Tipe data berfungsi sebagai dokumentasi yang memberi tahu pengembang lain bagaimana cara menggunakan kode tersebut.
    

---

### Contoh Implementasi

**Dynamic Typing (JavaScript):**

JavaScript

```
let harga = 5000;    // Awalnya number
harga = "Gratis";    // Sah-sah saja di JS

let total = harga * 2; 
console.log(total); // Output: NaN (Not a Number) -> Error logika yang tidak terdeteksi
```

**Static Typing (TypeScript):**

TypeScript

```
let harga: number = 5000;

// @ts-expect-error
harga = "Gratis"; 
// Error: Type 'string' is not assignable to type 'number'.
// Program tidak akan bisa jalan sampai ini diperbaiki.
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan web modern, transisi dari Dynamic ke Static Typing sangat berpengaruh pada:

1. **Debugging:** Mengurangi waktu yang dihabiskan untuk mencari _bug_ kecil karena kesalahan pengetikan atau salah asumsi tipe data (misal: mengira data ID adalah `number` padahal dari API dikirim sebagai `string`).
    
2. **Autocompletion:** Editor (VS Code) bisa memberikan saran yang sangat akurat karena ia tahu persis properti apa saja yang tersedia dalam sebuah objek data.
    
3. **Refactoring Besar:** Saat Anda mengubah struktur data pada aplikasi web yang kompleks, Static Typing akan menunjukkan semua baris kode yang "rusak" akibat perubahan tersebut, sehingga Anda tidak akan melewatkan satu pun bagian yang perlu diperbaiki.
