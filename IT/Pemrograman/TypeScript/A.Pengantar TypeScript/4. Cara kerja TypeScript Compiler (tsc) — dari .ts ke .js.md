### 4. Cara Kerja TypeScript Compiler (tsc) — Dari .ts ke .js

Memahami proses "di balik layar" sangat penting karena komputer atau browser sebenarnya tidak bisa membaca file `.ts` secara langsung.

---

### Definisi Singkat

**TypeScript Compiler (tsc)** adalah alat yang mengubah kode TypeScript menjadi JavaScript standar melalui proses yang disebut **transpilasi**. Selama proses ini, compiler melakukan dua hal utama: mengecek kesalahan tipe data dan menghapus semua fitur khusus TypeScript agar kode bisa dijalankan di lingkungan JavaScript biasa.

---

### Analogi

Bayangkan Anda menulis sebuah naskah film dalam bahasa Inggris yang sangat formal dan penuh instruksi teknis kamera (TypeScript). Namun, aktor dan kru Anda hanya mengerti bahasa Indonesia yang santai (JavaScript).

**TypeScript Compiler** adalah penerjemah ahli. Sebelum memberikan naskah ke aktor, ia akan:

1. **Pengecekan:** Memastikan tidak ada instruksi yang mustahil dilakukan (misal: "Aktor terbang tanpa alat bantu"). Jika ada yang aneh, ia akan protes ke penulis.
    
2. **Pembersihan:** Menghapus semua istilah teknis kamera yang membingungkan bagi aktor, lalu menerjemahkannya ke bahasa Indonesia yang bersih agar bisa langsung diperankan.
    

---

### Poin-Poin Penting

Proses kerja `tsc` mengikuti alur berikut:

1. **Parsing:** Compiler membaca kode `.ts` dan mengubahnya menjadi struktur data yang disebut _Abstract Syntax Tree_ (AST).
    
2. **Type Checking:** Compiler memeriksa AST untuk memastikan aturan tipe data dipatuhi (misal: variabel `number` tidak diisi `string`). Jika ada pelanggaran, proses akan berhenti dengan pesan error.
    
3. **Transformation:** Fitur-fitur masa depan (seperti _Decorators_ atau _Enums_) diubah menjadi kode JavaScript yang setara agar kompatibel dengan versi JavaScript yang lebih lama (seperti ES5 atau ES6).
    
4. **Code Generation (Emit):** Compiler menghapus semua anotasi tipe (seperti `: string`, `interface`, dll) dan menghasilkan file `.js` murni.
    

---

### Contoh Implementasi

Misalkan Anda memiliki file bernama `app.ts`:

**Input (`app.ts`):**

TypeScript

```
const sapa = (nama: string): string => {
    return `Halo, ${nama}`;
};

console.log(sapa("Budi"));
```

Setelah Anda menjalankan perintah `tsc app.ts` di terminal, compiler akan menghasilkan file JavaScript:

**Output (`app.js`):**

JavaScript

```
// Perhatikan bahwa tipe data ': string' telah hilang sepenuhnya
var sapa = function (nama) {
    return "Halo, ".concat(nama);
};

console.log(sapa("Budi"));
```

---

### Koneksi dalam Bidang Web Development

Dalam pengembangan web modern, pemahaman tentang `tsc` membantu dalam:

1. **Build Pipeline:** Di proyek besar, `tsc` biasanya diintegrasikan ke dalam alat seperti Webpack, Vite, atau Next.js. Mengetahui cara kerja compiler membantu Anda mengatur konfigurasi `tsconfig.json` (seperti target versi JavaScript).
    
2. **Cross-Browser Compatibility:** Anda bisa menulis kode menggunakan fitur JavaScript terbaru (ES2023+), dan `tsc` akan otomatis mengubahnya menjadi kode yang bisa berjalan di browser lama (seperti IE11 atau Chrome versi lama).
    
3. **Debugging:** Anda belajar bahwa error TypeScript terjadi saat _compile-time_, sehingga mencegah aplikasi "pecah" saat sudah di-deploy ke server produksi.
