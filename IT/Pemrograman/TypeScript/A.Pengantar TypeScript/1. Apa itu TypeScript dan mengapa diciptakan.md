## 1. Apa itu TypeScript dan Mengapa Diciptakan

### Definisi Singkat

**TypeScript** adalah bahasa pemrograman berbasis teks yang merupakan _superset_ dari JavaScript, yang menambahkan fitur **static typing** (pengetikan statis) opsional ke dalam bahasanya. Sederhananya, TypeScript adalah JavaScript yang memiliki "pemeriksa aturan" untuk memastikan data yang Anda gunakan sudah sesuai tipenya sebelum kode dijalankan.

---

### Analogi

Bayangkan Anda sedang merakit sebuah furnitur dari toko furnitur ternama.

- **JavaScript** adalah instruksi perakitan yang hanya berisi gambar. Anda bebas memasang baut mana saja ke lubang mana saja. Masalahnya, Anda mungkin baru menyadari bautnya salah ukuran setelah furniturnya hampir jadi dan tiba-tiba roboh.
    
- **TypeScript** adalah instruksi perakitan yang setiap baut dan lubangnya diberi label warna dan ukuran yang spesifik (misal: "Baut A1 hanya untuk Lubang A1"). Jika Anda mencoba memasukkan baut yang salah, instruksi tersebut akan langsung "berteriak" atau memperingatkan Anda sebelum Anda sempat memasangnya.
    

---

### Poin-Poin Penting

- **Superset dari JavaScript:** Semua kode JavaScript yang valid adalah kode TypeScript yang valid. Anda tidak perlu mengubah kode lama untuk mulai menggunakan TypeScript.
    
- **Static Typing:** Anda bisa menentukan tipe data (seperti `string`, `number`, atau `boolean`) pada variabel, parameter fungsi, dan objek.
    
- **Type Checking saat Kompilasi:** Kesalahan (error) dideteksi saat Anda menulis kode atau saat proses _build_, bukan saat aplikasi sudah berjalan di tangan pengguna (_runtime_).
    
- **Tooling yang Kuat:** Memberikan fitur _autocomplete_ (IntelliSense) yang sangat akurat dan navigasi kode yang lebih mudah di dalam _code editor_ seperti VS Code.
    
- **Transpiler:** Browser tidak bisa menjalankan TypeScript secara langsung. Kode TypeScript harus diubah (ditranspilasi) menjadi JavaScript standar agar bisa dibaca oleh browser atau Node.js.
    

---

### Contoh Implementasi

Berikut adalah perbandingan sederhana bagaimana TypeScript mencegah kesalahan yang sering terjadi di JavaScript:

**JavaScript (Potensi Error Tersembunyi):**

JavaScript

```
function tambah(a, b) {
    return a + b;
}

console.log(tambah(5, "10")); // Output: "510" (Bukan 15, karena dianggap penggabungan teks)
```

**TypeScript (Error Terdeteksi Sejak Awal):**

TypeScript

```
function tambah(a: number, b: number): number {
    return a + b;
}

// @ts-expect-error: TypeScript akan memberikan garis merah di bawah "10"
console.log(tambah(5, "10")); 
// Error: Argument of type 'string' is not assignable to parameter of type 'number'.
```

---

### Koneksi dalam Bidang Web Development

Dalam dunia **Web Development**, TypeScript kini telah menjadi standar industri (terutama pada _frontend_ seperti React, Vue, Angular, dan _backend_ seperti NestJS).

Hubungannya sangat krusial karena:

1. **Skalabilitas:** Saat aplikasi web tumbuh besar dengan ribuan file, TypeScript memastikan perubahan di satu komponen tidak merusak komponen lain secara tidak sengaja.
    
2. **Kolaborasi Tim:** Kode menjadi dokumentasi mandiri. Programmer lain bisa langsung tahu jenis data apa yang diharapkan oleh sebuah fungsi tanpa harus membaca seluruh isi kodenya.
    
3. **Maintenance:** Memudahkan proses _refactoring_ (mengubah struktur kode) dengan aman, karena TypeScript akan menunjukkan semua bagian kode yang terdampak oleh perubahan tersebut.
