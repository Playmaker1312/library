### **Soal 1: Membuat Profil Pengguna (Manipulasi String & Number)**

Buatlah variabel untuk menyimpan data seorang pengguna. Anda harus menggunakan tipe data yang sesuai untuk setiap variabel.

**Tugas:**

1. Buat variabel `namaDepan` dan `namaBelakang`.
    
2. Buat variabel `umur`.
    
3. Gabungkan kedua nama tersebut ke dalam variabel baru bernama `namaLengkap`.
    
4. Tampilkan hasilnya ke terminal dengan format: _"Halo, nama saya [namaLengkap] dan saya berumur [umur] tahun."_

### **Soal 2: Kalkulator Diskon Sederhana (Integer & Float)**

Dalam soal ini, Anda akan mempraktikkan bagaimana tipe data angka bekerja dalam simulasi belanja.

**Tugas:**

1. Buat variabel `hargaBarang` dengan nilai **150000**.
    
2. Buat variabel `persentaseDiskon` dengan nilai **0.15** (ini mewakili 15%).
    
3. Buat variabel `totalDiskon` yang menghitung hasil perkalian `hargaBarang` dengan `persentaseDiskon`.
    
4. Buat variabel `hargaAkhir` untuk menyimpan harga setelah dikurangi diskon.
    
5. Tampilkan `hargaAkhir` ke terminal.

### **Soal 3: Logika Akses Dashboard (Boolean)**

Soal ini akan menguji pemahaman Anda tentang bagaimana Boolean mengontrol alur program sederhana.

**Tugas:**

1. Buat variabel `isLoggedIn` dan beri nilai `true`.
    
2. Buat variabel `username` dan beri nilai nama Anda.
    
3. Gunakan kode berikut untuk mengecek hasilnya di terminal:
    

JavaScript

```
if (isLoggedIn) {
    console.log("Selamat datang, " + username + "!");
} else {
    console.log("Silahkan login terlebih dahulu.");
}
```

4. **Tantangan:** Ubah nilai `isLoggedIn` menjadi `false`, simpan file, dan jalankan kembali di VS Code. Lihat apa yang berubah.
