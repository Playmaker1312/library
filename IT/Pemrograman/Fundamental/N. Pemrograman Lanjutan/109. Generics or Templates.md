Selamat! Anda telah sampai di materi yang akan mengubah cara Anda menulis kode dari yang bersifat "kaku" menjadi **Sangat Fleksibel**. Jika sebelumnya Anda membuat fungsi yang hanya bisa menerima angka, dengan **Generics** (di Java, C#, TypeScript) atau **Templates** (di C++), Anda bisa membuat fungsi yang bisa menerima tipe data apa pun tanpa kehilangan keamanan data (_Type Safety_).

Ini adalah rahasia di balik pembuatan _Library_ dan _Framework_ kelas dunia.

---

## 1. Apa itu Generics?

**Generics** adalah fitur yang memungkinkan Anda mendefinisikan kelas, antarmuka (_interface_), atau metode dengan **parameter tipe**.

Bayangkan tipe data sebagai sebuah "lubang". Biasanya, Anda menentukan lubang itu berbentuk kotak (Integer). Dengan Generics, Anda membuat lubang yang bisa berubah bentuk mengikuti benda apa pun yang Anda masukkan, asalkan benda itu konsisten.

### Mengapa Kita Butuh Generics?

Tanpa Generics, jika Anda ingin membuat fungsi "Pembalik Daftar" (_Reverse List_):

1. Anda buat fungsi untuk daftar Angka.
    
2. Anda buat fungsi lagi untuk daftar String.
    
3. Anda buat fungsi lagi untuk daftar User. Ini melanggar prinsip **DRY** (Don't Repeat Yourself). Dengan Generics, Anda cukup membuat **satu fungsi** untuk semua tipe.
    

---

## 2. Analogi: Botol Air vs Botol Susu

- **Tanpa Generics:** Anda punya "Botol Air" yang hanya bisa diisi air. Jika Anda ingin minum susu, Anda harus membeli "Botol Susu" yang baru, meskipun bentuk botolnya sama persis.
    
- **Dengan Generics:** Anda memiliki sebuah **"Botol<T>"**. Huruf **T** adalah singkatan dari _Type_.
    
    - Anda bisa menjadikannya `Botol<Air>`.
        
    - Anda bisa menjadikannya `Botol<Susu>`.
        
    - Isi di dalamnya berbeda, tapi cara Anda memegang botol, membuka tutupnya, dan meminumnya tetap sama.
        

---

## 3. Contoh Implementasi (TypeScript)

Mari kita lihat perbedaan kode yang kaku vs kode yang menggunakan Generics.

### A. Kode Kaku (Tanpa Generics)

Fungsi ini hanya bisa mengambil elemen pertama dari _array_ angka.

TypeScript

```
function ambilPertamaAngka(item: number[]): number {
    return item[0];
}
```

### B. Kode Fleksibel (Dengan Generics)

Kita gunakan simbol `<T>` sebagai penanda bahwa tipe data akan ditentukan saat fungsi dipanggil.

TypeScript

```
function ambilPertama<T>(item: T[]): T {
    return item[0];
}

// Penggunaan:
const angka = ambilPertama<number>([10, 20, 30]); // Hasilnya number
const nama  = ambilPertama<string>(["Budi", "Siti"]); // Hasilnya string
```

---

## 4. Keuntungan Utama Generics

1. **Type Safety (Keamanan Tipe):** Berbeda dengan tipe `any` (yang mematikan deteksi kesalahan), Generics tetap memberitahu editor kode Anda jika ada kesalahan tipe data.
    
2. **Code Reusability:** Anda menulis logika satu kali, dan logika tersebut bisa dipakai oleh ribuan tipe data berbeda di masa depan.
    
3. **Kinerja (Performance):** Di beberapa bahasa seperti C++, Templates bekerja sangat cepat karena kode khusus untuk tipe tersebut dibuat saat proses _compile_.
    

---

## 5. Generic Constraints (Batasan)

Terkadang Anda tidak ingin fungsi Anda menerima _semua_ hal. Anda ingin membatasi: _"Boleh apa saja, asalkan dia punya properti .length"_. Di TypeScript, kita menggunakan kata kunci `extends`.

TypeScript

```
function cetakPanjang<T extends { length: number }>(item: T) {
    console.log(item.length);
}
```

---

## 6. Kesimpulan

Generics adalah alat untuk **Abstraksi**. Jika Anda merasa sedang menulis kode yang fungsinya mirip tapi hanya beda tipe datanya saja, itu adalah sinyal kuat bahwa Anda harus menggunakan Generics.

Dengan menguasai Generics, Anda kini siap membaca kode sumber (_source code_) dari _library_ besar seperti **React** (misal: `useState<string>()`) atau **ArrayList** di Java dengan penuh pemahaman.

Apakah Anda ingin mencoba tantangan membuat sebuah kelas **"KotakPenyimpanan"** yang bisa menyimpan benda apa pun menggunakan Generics?
