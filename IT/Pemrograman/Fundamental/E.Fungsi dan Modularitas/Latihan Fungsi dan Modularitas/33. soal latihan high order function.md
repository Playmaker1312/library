### **Soal 1: Transformasi Data Produk (MAP)**

Bayangkan Anda menerima daftar harga dalam bentuk angka mentah, dan Anda harus mengubahnya menjadi teks mata uang yang rapi untuk ditampilkan di website.

**Tugas di VS Code:**

1. Buat Array: `let hargaProduk = [15000, 20000, 35000, 50000];`
    
2. Gunakan `.map()` untuk membuat array baru bernama `formatRupiah`.
    
3. Di dalam `map`, gunakan **Template Literals** untuk mengubah setiap angka menjadi string: `"Rp" + harga`.
    
4. Tampilkan `formatRupiah` ke terminal. (Hasil: `["Rp15000", "Rp20000", ...]`).

### **Soal 2: Seleksi Stok Barang (FILTER)**

Anda adalah admin gudang. Anda hanya ingin menampilkan barang-barang yang stoknya hampir habis (di bawah 10 unit).

**Tugas di VS Code:**

1. Buat Array of Objects (Data yang lebih nyata):
    
    JavaScript
    
    ```
    let stokGudang = [
        { nama: "Kertas A4", jumlah: 50 },
        { nama: "Tinta Printer", jumlah: 8 },
        { nama: "Pulpen Hitech", jumlah: 25 },
        { nama: "Penghapus", jumlah: 3 }
    ];
    ```
    
2. Gunakan `.filter()` untuk membuat array baru `stokKritis`.
    
3. Syarat filternya: `item.jumlah < 10`.
    
4. Tampilkan `stokKritis` ke terminal.

### **Soal 3: Kalkulator Kasir Otomatis (REDUCE)**

Mari kita hitung total belanjaan, tapi kali ini setiap item punya jumlah (kuantitas).

**Tugas di VS Code:**

1. Buat Array keranjang belanja:
    
    JavaScript
    
    ```
    let keranjang = [
        { produk: "Sabun", harga: 5000, qty: 3 },
        { produk: "Susu", harga: 15000, qty: 2 },
        { produk: "Roti", harga: 12000, qty: 1 }
    ];
    ```
    
2. Gunakan `.reduce()` untuk menghitung `totalBayar`.
    
3. **Logika**: `totalSementara + (item.harga * item.qty)`. Jangan lupa berikan nilai awal `0` di akhir fungsi reduce.
    
4. Tampilkan: `"Total Belanja: Rp" + totalBayar`.
    

---

### **Pesan dari Mentor IT:**

- **MAP**: Gunakan jika Anda butuh Array baru dengan ukuran yang **sama**.
    
- **FILTER**: Gunakan jika Anda ingin **membuang** data yang tidak perlu.
    
- **REDUCE**: Gunakan jika Anda ingin **menggabungkan** semuanya menjadi satu kesimpulan (total, rata-rata, atau bahkan satu string panjang).
    

Silakan buat file `data_manipulation.js` dan jalankan dengan `node data_manipulation.js`. Jika Anda berhasil menghitung total belanja di Soal 3, Anda sudah siap bekerja dengan data asli dari database!
