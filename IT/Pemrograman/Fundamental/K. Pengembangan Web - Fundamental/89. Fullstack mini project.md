## 1. Arsitektur Proyek

Proyek ini akan memiliki tiga bagian utama yang saling berkomunikasi:

1. **Database (Penyimpanan):** Kita akan menggunakan **MongoDB** (NoSQL) untuk menyimpan daftar tugas secara permanen.
    
2. **Backend (Otak):** Menggunakan **Node.js & Express.js** untuk menyediakan REST API.
    
3. **Frontend (Wajah):** Menggunakan **Vue.js** untuk menampilkan data dan berinteraksi dengan pengguna.
    

---

## 2. Tahap 1: Backend (Express + MongoDB)

Pertama, kita buat "pabrik" datanya. Kita butuh dua rute utama: mengambil semua tugas dan menambah tugas baru.

**File: `server.js`**

JavaScript

```
const express = require('express');
const mongoose = require('mongoose');
const cors = require('cors'); // Agar Frontend bisa akses Backend

const app = express();
app.use(express.json());
app.use(cors());

// Koneksi ke MongoDB
mongoose.connect('mongodb://localhost:27017/miniproject');

// Skema Data
const Task = mongoose.model('Task', { teks: String, selesai: Boolean });

// API: Ambil semua tugas (GET)
app.get('/tasks', async (req, res) => {
    const tasks = await Task.find();
    res.json(tasks);
});

// API: Tambah tugas baru (POST)
app.post('/tasks', async (req, res) => {
    const task baru = new Task({ teks: req.body.teks, selesai: false });
    await taskbaru.save();
    res.json(taskbaru);
});

app.listen(3000, () => console.log("Backend jalan di port 3000"));
```

## 3. Tahap 2: Frontend (Vue.js + Axios)

Sekarang kita buat tampilannya yang akan "menembak" API di atas.

**File: `App.vue` (atau di HTML dengan CDN)**

HTML

```
<div id="app">
  <h1>Daftar Tugas Saya</h1>
  
  <input v-model="tugasBaru" placeholder="Ketik tugas baru...">
  <button @click="simpanTugas">Tambah</button>

  <ul>
    <li v-for="t in daftarTugas" :key="t._id">
      {{ t.teks }}
    </li>
  </ul>
</div>

<script>
export default {
  data() {
    return {
      tugasBaru: '',
      daftarTugas: []
    }
  },
  methods: {
    // FUNGSI UTAMA: Mengambil data dari Backend
    async ambilData() {
      const res = await axios.get('http://localhost:3000/tasks');
      this.daftarTugas = res.data;
    },
    // FUNGSI UTAMA: Mengirim data ke Backend
    async simpanTugas() {
      await axios.post('http://localhost:3000/tasks', { teks: this.tugasBaru });
      this.tugasBaru = ''; // Kosongkan input
      this.ambilData();    // Refresh daftar
    }
  },
  mounted() {
    this.ambilData(); // Jalankan saat aplikasi dibuka
  }
}
</script>
```

## 4. Aliran Data (Data Flow)

Pahami bagaimana data "berenang" di aplikasi Anda:

1. **Input:** User mengetik "Belajar Database" di **Vue.js**.
    
2. **Request:** User klik "Tambah", Vue mengirim surat **HTTP POST** berisi JSON ke **Express.js**.
    
3. **Process:** Express menerima surat tersebut, lalu memerintahkan **Mongoose** untuk menyimpannya di **MongoDB**.
    
4. **Response:** Express membalas "Sukses!", lalu Vue melakukan **GET** ulang untuk mengambil daftar terbaru dan memperbarui layar secara otomatis (**Reaktivitas**).
