### **Soal 1: Mengelola Daftar Kontak (Create & Read)**

Kita akan mensimulasikan sebuah buku telepon sederhana di dalam Array.

**Tugas di VS Code:**

1. Buat Array bernama `daftarKontak` yang berisi tiga nama: `"Budi"`, `"Sinta"`, dan `"Anto"`.
    
2. Gunakan perintah `.push()` untuk menambah nama baru `"Rani"` ke urutan paling belakang.
    
3. Tampilkan nama pertama (indeks 0) ke terminal.
    
4. Tampilkan seluruh isi Array untuk melihat apakah "Rani" sudah masuk.
    
5. **Bonus:** Tampilkan jumlah total kontak menggunakan `daftarKontak.length`.

### **Soal 2: Update Stok Minimarket (Update)**

Bayangkan Anda adalah admin gudang yang harus memperbarui data barang yang salah input.

**Tugas di VS Code:**

1. Buat Array: `let stokBarang = ["Sabun", "Pasta Gigi", "Sampo", "Sikat Gigi"];`
    
2. Ternyata "Sampo" habis dan diganti dengan "Sabun Cuci Muka".
    
3. Cari tahu "Sampo" ada di indeks ke berapa (0, 1, atau 2?).
    
4. Lakukan **Update** pada indeks tersebut dengan nilai baru `"Sabun Cuci Muka"`.
    
5. Tampilkan hasilnya: `"Stok terbaru: " + stokBarang`.

### **Soal 3: Membersihkan Keranjang Belanja (Delete)**

Simulasikan fitur "Hapus Barang" pada aplikasi e-commerce.

**Tugas di VS Code:**

1. Buat Array: `let keranjang = ["Laptop", "Mouse", "Keyboard", "Monitor"];`
    
2. Gunakan perintah `.pop()` untuk menghapus barang terakhir ("Monitor").
    
3. **Tantangan Tambahan:** Gunakan perintah `.shift()` (cari di dokumentasi atau coba saja) untuk menghapus barang pertama ("Laptop").
    
4. Tampilkan isi `keranjang` sekarang. Seharusnya hanya tersisa "Mouse" dan "Keyboard".

### **Tips Profesional: Perpaduan Array & Loop**

Di dunia nyata, kita jarang membaca Array satu per satu seperti `[0]`, `[1]`. Kita biasanya menggunakan **For Loop** untuk membongkar seluruh isi rak. Contohnya:

JavaScript

```
for (let i = 0; i < keranjang.length; i++) {
    console.log("Barang ke-" + (i+1) + " adalah: " + keranjang[i]);
}
```
