### **Soal 1: Gembok Rahasia Akun Media Sosial (Private Attribute)**

Kita akan membuat sistem profil pengguna di mana kata sandi (_password_) benar-benar tersembunyi.

**Tugas di VS Code:**

1. Buat Class `UserAccount`.
    
2. Gunakan simbol `#` untuk membuat atribut **Private**: `#password`.
    
3. Buat atribut **Public**: `username`.
    
4. Di dalam `constructor`, terima parameter `username` dan `password`.
    
5. Buat sebuah **Method Public** `checkLogin(inputUser, inputPass)`.
    
    - Jika `inputUser === this.username` dan `inputPass === this.#password`, tampilkan `"Login Berhasil!"`.
        
    - Jika salah, tampilkan `"Akses Ditolak!"`.
        
6. **Uji Coba**: Instansiasi objek `user1`. Coba akses `console.log(user1.#password)` dari luar class. Apa yang terjadi? (Seharusnya Error).

### **Soal 2: Kendali Kecepatan Mobil (Setter & Validation)**

Mari kita buat sistem keamanan pada mobil agar kecepatannya tidak bisa diatur ke angka yang berbahaya (misal: negatif).

**Tugas di VS Code:**

1. Buat Class `MobilAman`.
    
2. Atribut Private: `#kecepatan` (default: 0).
    
3. Buat **Method Setter** `setKecepatan(nilai Baru)`.
    
    - **Logika**: Jika `nilaiBaru` kurang dari 0 atau lebih dari 200, tampilkan `"Kecepatan tidak masuk akal!"`.
        
    - Jika valid, ubah `#kecepatan` menjadi `nilaiBaru`.
        
4. Buat **Method Getter** `getKecepatan()` untuk mengembalikan nilai `#kecepatan`.
    
5. **Eksekusi**: Coba set kecepatan ke `-50`, lalu ke `120`, dan tampilkan hasilnya menggunakan getter.

### **Pesan dari Mentor IT:**

- **Hashtag `#`**: Ingat, di JavaScript modern, `#` harus dideklarasikan di bagian paling atas class sebelum constructor jika ingin digunakan sebagai private field.
    
- **Getter & Setter**: Gunakan getter/setter agar Anda punya kendali penuh. Ibaratnya, jangan biarkan orang masuk lewat jendela (akses langsung), suruh mereka lewat pintu (metode) agar Anda bisa mengecek identitas mereka dulu.
    

Silakan buat file `enkapsulasi.js` dan jalankan dengan `node enkapsulasi.js`. Jika Anda sudah berhasil melihat pesan error saat mencoba mengakses atribut `#` secara langsung, selamat! Anda sudah berhasil mengamankan data aplikasi Anda.
