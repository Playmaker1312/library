Memahami perbedaan antara **Saving** (Menyimpan) dan **Publishing** (Mempublikasikan) adalah hal krusial. Tanpa ini, kamu mungkin merasa sudah bekerja berjam-jam, tetapi saat temanmu mencoba masuk ke game-mu, dunianya masih kosong atau versi lama.

---

## **Tujuan Akhir**

Mampu mengamankan progres kerja di _cloud_ (server Roblox), mempublikasikan game agar bisa dimainkan orang lain secara publik, dan memahami cara mengelola pengaturan dasar _Experience_.

---

## **Tools & Persiapan**

- **Menu File:** Terletak di pojok kiri atas Roblox Studio.
    
- **Game Settings:** Ikon gir di tab **Home**.
    
- **Creator Dashboard:** Situs web [create.roblox.com](https://create.roblox.com/) untuk manajemen tingkat lanjut.
    

---

## **Langkah-Langkah (Step-by-Step)**

### **1. Save vs. Publish (Penting!)**

- **Save to Roblox (Ctrl + S):** Menyimpan progres ke server Roblox sehingga kamu bisa membukanya dari komputer mana pun. **Belum terlihat oleh pemain.**
    
- **Publish to Roblox (Alt + P):** Memperbarui versi game yang sedang berjalan. **Pemain akan melihat perubahan ini saat mereka masuk ke server baru.**
    
- _Tips:_ Biasakan **Publish** setiap kali kamu menyelesaikan satu fitur besar.
    

### **2. Proses Publikasi Pertama Kali**

1. Klik **File** > **Publish to Roblox**.
    
2. Beri nama game kamu (misal: "Petualangan Pertamaku").
    
3. Pilih **Creator** (biasanya namamu sendiri).
    
4. Klik **Create**. Sekarang game-mu sudah memiliki ID unik di database Roblox.
    

### **3. Mengelola Pengaturan (Game Settings)**

Setelah dipublikasikan, klik tombol **Game Settings** (ikon roda gigi):

- **Permissions:** Ubah dari _Private_ ke _Public_ agar orang lain bisa menemukan game-mu.
    
- **Avatar:** Mengatur apakah pemain menggunakan karakter R6 (klasik) atau R15 (modern).
    
- **Security:** Aktifkan **Allow HTTP Requests** atau **Enable Studio Access to API Services** jika nanti kamu belajar sistem _DataStore_ (simpan data poin/level).
    

### **4. Mengelola Lewat Web (Creator Dashboard)**

Jika ingin mengganti ikon game atau foto _thumbnail_:

1. Buka [create.roblox.com](https://create.roblox.com/).
    
2. Pilih **Dashboard** > **Experiences**.
    
3. Klik game-mu untuk mengatur deskripsi, harga (jika berbayar), dan melihat statistik pemain.
    

---

## **Troubleshooting (Masalah Umum)**

1. **"Saya sudah edit, tapi di aplikasi Roblox kok tidak berubah?"**
    
    - _Sebab:_ Kamu hanya menekan **Save**, bukan **Publish**.
        
    - _Solusi:_ Selalu tekan `Alt + P` (Publish) untuk memperbarui versi yang bisa dimainkan publik.
        
2. **Lupa Simpan dan Studio Crash:**
    
    - _Sebab:_ Komputer mati atau internet terputus.
        
    - _Solusi:_ Roblox Studio punya fitur **Auto-Recovery**. Saat kamu membuka kembali Studio setelah crash, biasanya akan muncul jendela di sebelah kanan yang menawarkan file _recovery_ terakhir.
        

---

## **Tantangan Kecil**

Mari coba siklus manajemen ini:

1. Ubah warna lantai (Baseplate) kamu menjadi Merah.
    
2. Lakukan **Publish to Roblox** (Alt + P).
    
3. Tutup Roblox Studio, lalu buka kembali.
    
4. Ubah warna lantai menjadi Hijau, tapi kali ini cukup lakukan **Save to Roblox** (Ctrl + S) saja.
    

**Pertanyaan:** Jika kamu membuka game tersebut melalui aplikasi Roblox (sebagai pemain), warna apa yang akan kamu lihat pada lantai tersebut? Merah atau Hijau? Mengapa?

Coba jawab berdasarkan perbedaan fungsi Save dan Publish yang baru saja kita bahas!
